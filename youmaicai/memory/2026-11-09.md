**方法论教训（已踩坑，记录备查）**：
1. **`/tmp` 下有一个遗留的 `select.py`，会遮蔽 Python 标准库的 `select` 模块** —— 在 /tmp 里跑 `import urllib.request` 会直接
   `AttributeError: module 'select' has no attribute 'select'`。解法：改用 `curl` 抓取，或换到干净目录跑 Python。
   另：heredoc 里的 python 若 import 链最终触及 `select` 也会炸，报错信息完全看不出根因。
2. **arXiv API 的 `sortBy=submittedDate` 默认排序不可靠** —— 实测 `cat:cs.CL&sortBy=submittedDate` 返回的是 2012 年的老论文。
   **正确做法：直接用 RSS `https://rss.arxiv.org/rss/cs.AI+cs.CL+cs.LG+cs.NE` 拿当日公告批次**，再用 `id_list` 分批（每批 20）拉完整元数据。
3. **RSS 批次文件末行无换行**会导致 `while read` 吞掉最后一批 —— 用 `python3` 生成批次文件时补上尾部换行，或用 `sed -n Np` 逐行取。
4. `dedup.py` 的 `DEFAULT_PAPERS_DIR` 默认指向 **caixin**（流体力学）目录，本 agent 必须显式传第二个参数指向
   `~/knowledge-vault/youmaicai/01-Papers`，否则去重基线完全错位。
5. subagent 手写 wikilink 仍会带**截断 slug**，需按 arXiv ID 反查真实文件名修正（与 11-08 同一坑，本轮 95 个链接全部校验通过）。
