## 核心贡献

> **数据混合不是「调权重」问题，而是「域归因」问题** —— 既然要拟合「每个域对目标指标的贡献」，就应该用**最优实验设计**来选混合比例，而不是随机采样。

1. **重新框定现有实践**：
   - 主流数据混合方法：训练**许多小代理模型**在**随机混合**上，然后拟合回归模型从混合预测性能
   - 本文指出：**这本质上是一个域归因（domain attribution）问题** —— 该回归度量的是**每个域对目标指标的贡献**
2. **核心批评**：在这个视角下，**标准的 Dirichlet 采样是糟糕的回归设计**：
   - 需要调参
   - **无法为数百个域支撑线性拟合**
3. **提出 LinMix**（基于经典最优实验设计）：
   - **在截断单纯形（capped simplex）的顶点采样**
   - 即：**每个域要么处于它的上限，要么缺席**
   - **无超参数的顶点采样** ⇒ **解耦了域效应**
   - ⇒ 支撑一个**可解释的线性模型，其系数即为域归因（domain attributions）**
4. **关键性质**：
   - **LinMix 给出的最优混合，可证明只保留归因值为正的域**，且**无需在候选混合上搜索**
   - **证明顶点采样的最优性**
   - **证明 Dirichlet 采样在其混合集中于先验数据混合时会放大归因误差**
5. **实验**（OLMo2 1B, Qwen3.5 4B）：
   - **LinMix 优于基于 Dirichlet 的数据混合**，在推理、代码、数学基准上
   - **MBPP +46%**，**GSM8K +14%**
   - **在 288 个细粒度域上，只有顶点采样支撑线性拟合**，LinMix 相对最佳非线性基线**平均提升 11%**

## 技术方案

### 核心思想

主流做法把「数据混合」当成超参搜索：采样一堆混合比例 → 训代理模型 → 拟合回归 → 用回归预测最优混合。这其实是**在用回归做最优化**，绕了一圈。

LinMix 直接问：**既然我们要的是域归因（每个域贡献多少），为什么不设计一个能直接读出归因的实验设计？**

```text
❌ Dirichlet 采样:
   混合比例 ~ Dirichlet(α) —— 连续、随机、围绕先验集中
   → 设计矩阵病态 → 数百域时无法拟合线性模型

✅ LinMix 顶点采样:
   每个域 w_d ∈ {0, cap_d}   ← 只有两种取值
   → 设计矩阵近似正交 → 域效应解耦 → 线性拟合稳定
   → 系数 = 域归因 → 最优混合 = 保留正归因域（闭式，无需搜索）
```

### 关键技术

| 技术 | 说明 |
|------|------|
| **域归因视角** | 把数据混合重写为回归/归因问题 |
| **截断单纯形顶点采样** | $w_d \in \{0, \text{cap}_d\}$ |
| **无超参顶点采样** | 不需要调 Dirichlet 的 $\alpha$ |
| **域效应解耦** | 顶点采样使设计矩阵近似正交 |
| **归因系数即线性模型系数** | 可解释 |
| **闭式最优混合** | 只保留正归因域，无搜索 |
| **Dirichlet 放大误差的证明** | 当混合集中于先验混合时 |

## 公式

```math
\text{域归因的线性模型}:\quad
\mathcal{P}(\mathbf{w}) \;=\; \alpha + \sum_{d=1}^{D} \beta_d \, w_d
\qquad
\substack{\mathbf{w} \in \Delta_D \;(\text{权重和为 1}) \\
\beta_d = \text{域 } d \text{ 对目标指标的归因}}
```

```math
\text{设计矩阵（Dirichlet 采样）}:\quad
X_{\text{Dir}} \in \mathbb{R}^{N \times D}, \qquad X_{\text{Dir}, nd} = w_d^{(n)}
\qquad
\text{当 } w^{(n)} \text{ 集中于先验混合 } \Rightarrow \text{列近似共线} \Rightarrow \text{病态}
```

```math
\text{设计矩阵（LinMix 顶点采样）}:\quad
X_{\text{VM}, nd} = \text{cap}_d \cdot \mathbb{1}\big[\text{顶点 } n \text{ 包含域 } d\big]
\qquad
\text{列近似正交 } \Rightarrow \text{归因解耦}
```

```math
\text{最优混合（闭式）}:\quad
\mathbf{w}^{\star} \;=\; \frac{\,\text{cap}_d \cdot \mathbb{1}[\beta_d > 0]\,}{\sum_{d'} \text{cap}_{d'} \cdot \mathbb{1}[\beta_{d'} > 0]}
\qquad
\text{（保留正归因域，无需搜索）}
```

```math
\text{Dirichlet 的误差放大}:\quad
\mathrm{Var}(\hat{\beta}) \;\supseteq\; \frac{\sigma^2}{n} \big( X^{\top} X \big)^{-1}
\qquad
\text{当 } X \text{ 列近似共线（集中在先验混合）} \Rightarrow \mathrm{Var} \text{ 爆炸}
```

```math
\text{顶点采样的最优性}:\quad
\min_{\mathbf{w} \in \mathcal{D}} \mathrm{Var}(\hat{\beta}) \quad
\text{在顶点设计下取到}
\qquad \mathcal{D} = \{\mathbf{w} : w_d \in \{0, \text{cap}_d\}\}
```

## 代码片段

```python
# 概念性伪代码：LinMix 顶点采样 + 域归因 + 闭式最优混合
import numpy as np

class LinMix:
    # 顶点采样 + 线性域归因。

    def __init__(self, domain_caps: dict[str, float]):
        # domain_caps: 每个域的最大混合比例
        self.caps = domain_caps
        self.domains = list(domain_caps.keys())

    # ---- 1) 顶点采样（无超参） ----
    def vertex_sample(self, n: int, seed=0):
        #         生成 n 个顶点设计：每个域要么在上限，要么缺席。
        #         为保证可识别性，采用平衡设计（每个域被包含/缺席次数尽量相等）。
        rng = np.random.default_rng(seed)
        D = len(self.domains)
        rows = []
        for i in range(n):
            w = np.zeros(D)
            # 平衡设计：按 i 的二进制模式决定包含哪些域
            for d in range(D):
                include = ((i >> d) & 1) == 1
                if include:
                    w[d] = self.caps[self.domains[d]]
            # 归一化到单纯形
            if w.sum() > 0:
                w = w / w.sum() * min(self.caps.values())
            rows.append(w)
        return np.array(rows)          # (n, D) 设计矩阵

    # ---- 2) 域归因（线性拟合） ----
    def attribute(self, X: np.ndarray, y: np.ndarray):
        #         X: (n, D) 顶点设计矩阵
        #         y: (n,)   每个顶点混合下的目标指标
        #         返回: 每个域的归因 β
        X_aug = np.hstack([np.ones((X.shape[0], 1)), X])   # 加截距
        coef, *_ = np.linalg.lstsq(X_aug, y, rcond=None)
        return {"intercept": coef[0], "attributions": dict(zip(self.domains, coef[1:]))}

    # ---- 3) 闭式最优混合（无需搜索） ----
    def optimal_mix(self, attributions: dict[str, float]):
        #         只保留正归因域；若无正归因，退回先验。
        pos = {d: v for d, v in attributions.items() if v > 0}
        if not pos:
            return {d: self.caps[d] / len(self.domains) for d in self.domains}
        total = sum(self.caps[d] for d in pos)
        return {d: (self.caps[d] / total if d in pos else 0.0) for d in self.domains}

    # ---- 对比：Dirichlet 采样（病态设计） ----
    def dirichlet_sample(self, n: int, alpha=1.0, seed=0):
        rng = np.random.default_rng(seed)
        w = rng.dirichlet(np.full(len(self.domains), alpha), size=n)
        return w
```

## 实验结论

- **模型**: OLMo2 (**1B**), Qwen3.5 (**4B**)
- **基线**: Dirichlet-based 数据混合；非线性基线（用于 288 域对比）
- **结果**:

| 基准 | 相对提升 |
|------|----------|
| **MBPP** | **+46%** |
| **GSM8K** | **+14%** |
| **推理 / 代码 / 数学**（整体） | 均优于 Dirichlet 混合 |
| **288 个细粒度域** | 只有顶点采样支撑线性拟合；**相对最佳非线性基线平均 +11%** |

- **理论**: 顶点采样最优性已证；Dirichlet 误差放大已证

## 局限性

1. **代理模型的代表性假设** —— 全部方法仍依赖「小代理模型的行为能外推到全尺寸模型」。1B → 4B 的外推距离很短，**7B+ 上是否成立未验证**
2. **线性性假设** —— 「性能 = 截距 + 域贡献线性叠加」在强交互（某两个域同时存在才有用）时不成立。摘要没讨论这种交互
3. **数值规模偏小** —— 1B/4B，且「+46% on MBPP」这类相对数字在小模型上波动大
4. **顶点采样的样本成本** —— 顶点数随域数指数增长（$2^D$ 量级）。**288 个域如何可行？** 摘要未说明，可能用贪心/正交设计近似，但这会削弱「最优性」证明
5. **域的划分是给定的** —— 论文不解决「如何划分域」，而这往往是实际中最难的部分
6. **只在预训练阶段验证** —— 领域证明与实践**未涉及 SFT / 对齐数据混合**，而后者是当前更热的实际问题
7. **上限 `cap_d` 如何设定** —— 方法依赖它，摘要未说明选择原则
8. **未与合成环境 scaling law（[[2610.37648]]）对比** —— 两篇同批次，一个讲环境构成，一个讲语料混合，应互为参照
9. **评测的「推理/代码/数学」基准清单未给**

## 实现建议

- **实现难度**: 中（顶点采样 + 线性回归都很简单；瓶颈是代理模型训练成本）
- **预期性能**: MBPP **+46%**、GSM8K **+14%**（小模型上，需自测）
- **适用场景**: **需要决定预训练数据配比** —— 尤其在**多域场景**（代码/数学/多语言/多领域）且预算有限时
- **落地注意**:
  1. **最大的实际收益在「域很多」的场景** —— 摘要明确说 Dirichlet 在数百域上无法拟合线性模型。这是 LinMix 的主场
  2. **顶点数随域数增长要核实** —— 288 个域能跑起来说明有近似方法，但「最优性」证明的价值会被削弱。先读正文
  3. **线性假设要验证** —— 先在几个域上检查「加入一个域的效果 ≈ 单独训练的效果」，不成立就要交互项
  4. **域的划分比方法更重要** —— 划分不当，再好的归因方法也没用
  5. **代理模型的选择影响结论** —— 用 1B 代理、1B 实测的收益，不一定能带到 7B
  6. **和 [[2610.37648]]（SynthAPI scaling law）一起读** —— 一个讲「环境/数据的构成」，一个讲「域的权重」，是可互相印证的组合

## 我的评注

> 这篇的方法论美学我很喜欢：**它把一个被当成「超参调优」的问题，还原成了一个「回归设计」问题，然后用统计设计的工具解决它。**
>
> 这个重新框定很关键。主流做法是「采样混合 → 训代理 → 拟合回归 → 用回归预测最优混合」—— 本质上**在用回归当优化器**，绕了一大圈。而且 **Dirichlet 采样是个糟糕的回归设计**：它生成的混合比例都在先验附近连续取值，设计矩阵的列高度共线，条件数爆炸。几百个域的时候，根本拟合不出稳定的线性模型。
>
> LinMix 的解法漂亮得有点反直觉：**只在顶点采样** —— 每个域要么在上限要么缺席。这样设计矩阵近似正交，域效应解耦，回归系数直接就是域归因。**而最优混合随之闭式得到：只保留正归因的域**，不需要在候选混合里搜。
>
> 我尤其喜欢「**Dirichlet 在混合集中于先验时会放大归因误差**」这个证明。它不只是说「Dirichlet 不好」，而是精确指出了**失败的机制** —— 这让替代方案的说服力强得多。
>
> 保留意见：
> - **规模问题被回避了**。顶点数随域数指数增长，288 个域要跑起来必然用了贪心或近似。而一旦用了近似，「顶点采样最优性」的证明就只适用于理想情形。这一点摘要完全没说，是我认为的最大信息缺口。
> - **线性性假设**。真实的数据域之间有强交互 —— 比如「数学 + 代码」组合起来才产生增益，那就不是一个加性模型能表达的。摘要没说怎么处理交互项。
> - **1B/4B 的规模**。「+46% on MBPP」在小模型上很常见，7B+ 上大概率缩水。而**代理模型外推**这个老问题本文没碰。
> - **只做预训练数据混合**。当前业界更痛的其实是 **SFT / 对齐数据的混合与配比** —— 这篇的方法论显然适用，但没验证。
>
> 落地判断：**方法极简、洞察清晰，建议直接在自己的场景试**。第一步不用全套 —— 只做「顶点采样 + 线性归因」这个小实验，看归因系数是否符合你对各域价值的直觉。如果符合，再往下走。**归因系数本身就是有价值的信息**，哪怕不用于优化配比。
