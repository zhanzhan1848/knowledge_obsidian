# Adapting LLM Judges to Observed Human Annotation Policy through Soft Prompt Tuning

> **arXiv**: [2611.07126](https://arxiv.org/abs/2611.07126)
> **发表日期**: 2026-11-04
> **分类**: cs.CL (交叉: cs.AI)
> **会议/期刊**: CONVERSATIONS 2026, International Symposium on Chatbots and Human-Centred AI (Preprint)

## 📋 摘要

LLM 越来越多地被用作自动评判器（automated judge）来评估 chatbot 回复。虽然闭源模型可以与人类标注者达到很高的一致性（agreement），但它们成本高、难以在实际场景部署。轻量级开源 LLM judge 是有吸引力的替代方案，但其与人类评分的一致性通常较低。本文研究 soft prompt tuning（软提示微调）能否把开源 LLM judge 更紧密地对齐到人类标注策略（human annotation policy）上。作者在 **FairBotBench** 基准上训练软提示，并在 **bias、toxicity、personalization** 三个维度上评估适配后的 judge。发现表明，**hybrid soft-prompt tuning**（将文本提示与学习到的连续 prompt embeddings 结合）在所有维度上都一致地优于对应的未调优基线。对 **Qwen 3.5 9B** 而言，适配后的 judge 在全部三个评估维度上同时超越了托管的参考 judge（hosted reference judges）。

## 🎯 核心贡献

1. 提出用 **soft prompt tuning 对齐"人类标注策略"** 的思路：目标不是通用能力对齐，而是让开源 judge 内化**观测到的标注规范**（policy），从而提升与人类评分的一致性。
2. 提出 **hybrid soft-prompt tuning**：文本提示 + 学习到的连续 prompt embeddings 组合，实验证明该混合形式在所有评估维度上**一致地**优于对应的未调优基线。
3. 在 **FairBotBench** 上训练与评估，覆盖 **bias / toxicity / personalization** 三个评测维度，构成本文的对齐评测协议。
4. 关键结果：**Qwen 3.5 9B** 适配后 judge 在三个维度上**全面超过托管的闭源参考 judge**——说明开源 judge 经适配后可在成本/可部署性之外再取得质量优势。

## 🔧 方法/架构

- **被适配对象**：轻量开源 LLM judge（如 Qwen 3.5 9B），对比对象为闭源托管 judge（hosted reference judges）。
- **Hybrid soft-prompt tuning**：文本提示（可读、可控）与连续 prompt embedding（可学习）拼接/融合为输入前缀 embedding：

```math
\mathbf{p}_{\text{hybrid}} = \big[\,\mathbf{p}_{\text{text}} \,\Vert\, \mathbf{p}_{\text{learned}}\,\big],
\qquad
\mathbf{p}_{\text{learned}} \leftarrow \mathbf{p}_{\text{learned}} - \eta\,\nabla_{\mathbf{p}_{\text{learned}}} \mathcal{L}_{\text{agree}}(\mathbf{p}_{\text{hybrid}})
```

  其中 $\mathcal{L}_{\text{agree}}$ 为与人类标注的一致性目标（以 FairBotBench 上的人类评分为监督信号）。
- 优势：只更新 prompt embedding，**不改动 LLM 权重**，训练成本低、部署保持轻量、模型可替换。

## 📊 实验结果

- **FairBotBench / bias 维度**：Qwen 3.5 9B 经 hybrid soft-prompt 适配后**超过**托管参考 judge。
- **FairBotBench / toxicity 维度**：同上，超过托管参考 judge。
- **FairBotBench / personalization 维度**：同上，超过托管参考 judge。
- **对比未调优基线**：hybrid soft-prompt tuning 在三个维度上**一致提升**与人类标注的一致性。
- 摘要未披露具体一致性数值（详见原文实验章节）；涉及基准为 FairBotBench，维度为 bias、toxicity、personalization。

## ⚠️ 局限性

- 仅在 **FairBotBench** 单一基准上训练与评估，跨基准（如真实产品标注体系、学术标注指南）泛化性未验证。
- "对齐人类标注策略"的监督信号本身有偏——适配后的 judge 是拟合人类标注者的既有偏差与不一致性，而非纠正它。
- 实验集中在特定模型（Qwen 3.5 9B）上；超参、软提示长度、学习率等细节在摘要中未披露。
- 仅适配 prompt embedding，对闭源 judge 不可用（无法访问 embedding 梯度），场景受限。
- 摘要未给出具体 agreement 数值与置信区间，提升幅度难以量化。

## 💡 建议

- 是否推荐使用：是（需要低成本离线 LLM-as-a-judge 的团队可直接套用 hybrid soft-prompt 方法）
- 适用场景：自建评测流水线的轻量开源 judge 校准；bias / toxicity / personalization 三维度的自动审核；把业务侧标注规范"注入"开源 judge 而不改动模型权重。
