## 核心贡献

> 提出 **Identity-Blinded Reasoning Diagnostic (IBRD)** 框架：把 target entity 隐藏，看 LLM 是真"推理"还是靠检索 / 记忆。

1. **Source + Edit 替代 target entity**：target 由 known source entity + explicit structural edit operation 定义 → 保留推理所需信息，但减少 target-identity shortcut。
2. **诊断 6 大化学任务**：odor prediction, molecular property, retrosynthesis, reaction yield 等。
3. **核心发现**：高 benchmark 准确率 ≠ 强结构-属性推理能力，模型严重依赖 source-target label 一致性。

---

## 技术方案

### 核心思想

现有化学 prediction benchmark 把 target entity identity 直接喂给模型。这导致：
- 模型可能 memorization / retrieval，而非 transferable reasoning。
- 我们无法区分 **真推理** 与 **contextual shortcut**。

IBRD 框架重写 prompt：
- 隐藏 target identity；
- 显式提供 source entity + structural edit operation；
- 维持任务可解性，剥离 identity cue。

```text
Standard:   "Given target molecule X, predict property."
IBRD:       "Given source molecule A, apply edit op E, predict property."
```

并通过**替换 source label**做 ablation：若预测系统性地迁移到替换 source 的 label，则说明模型在做 label matching 而非结构 reasoning。

### 关键技术

| 技术 | 说明 |
|------|------|
| Source + Edit 范式 | 把 target 重写为 (source, edit) |
| Identity-blinding | 隐藏 target 名字 / 结构特征 |
| Source-label substitution ablation | 检验 leak / memorization 程度 |
| 多任务覆盖 | odor, property, retro, yield |
| Property consistency check | source / target property 一致 → 高 accuracy |

---

## 实验结论

- **任务**: 6 个（odor, molecular property, retrosynthesis, reaction yield 等）
- **观察**:
  - source-target property 一致 → accuracy 显著更高；
  - 提供 source entity label → dependence 增强；
  - 仅替换 source entity label → 部分预测 systemically shift → shortcut 严重；
  - 高 benchmark accuracy 不等于 transferable reasoning。
- **意义**: LLM 化学 benchmark 需要 IBRD-style 诊断来验证"真推理"。

---

## 局限性

- 编辑操作需要专家定义，自动化扩展到任意领域难；
- 仅覆盖化学，未验证跨领域（生物、材料）泛化；
- 替换 source label 的影响可能受 prompt 设计影响。

## 实现建议

- **实现难度**: 低-中（仅改 prompt + 加 source ablation）
- **预期价值**: 任何科学 LLM benchmark 的 audit 工具
- **适用场景**: 评估 LLM 是否真具备科学 reasoning，而非 memorization
- **建议用法**: 报告 standard accuracy + IBRD-accuracy gap 作为 reasoning 真实度 proxy
