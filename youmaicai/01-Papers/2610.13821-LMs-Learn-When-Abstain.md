## 核心贡献

> 系统比较"训练 LLM 自己判断何时 abstention"与"训练独立 answer selector"在 Qwen3-14B 上的效果，发现 learned selector 显著优于 calibrated confidence filter。

1. **utility 评分**: 答对得分、答错扣分、abstain 不扣分
2. **TriviaQA**: coverage 20.2% → 30.9%，scored error 23.0% → 14.5%
3. **RL 不稳定**: RL 改进在 TriviaQA 上未建立稳定增益
4. **NQ-Open**: selector 仍优于 filter，但劣于 always-abstain

---

## 技术方案

### 核心思想

LLM 应答决策 = "何时答" + "答什么"。本文训练独立 selector 在 LLM 输出 + confidence 之上做二阶段选择：给出答案 or abstention。

### 关键技术

| 技术 | 说明 |
|------|------|
| Calibrated confidence filter | 用 LLM 自身置信度过滤（基线）|
| Learned answer selector | 独立训练的二阶段筛选器 |
| Utility score | 答对+、答错-、abstain 0 |
| Threshold-averaged utility | 在 held-out confidence threshold 上做平均 |

---

## 实验结论

- **数据集**: TriviaQA, NQ-Open
- **模型**: Qwen3-14B
- **结果**:
  - TriviaQA mean coverage: **20.2% → 30.9%**
  - Scored error: **23.0% → 14.5%**
  - NQ-Open: selector > filter，仍 < always-abstain

---

## 局限性

- RL 改进未稳定 → 训练不稳定
- NQ-Open 上 even always-abstain 更优 → 不同数据集 abstention 信号差异大
- 仅 Qwen3-14B 一个模型 + 单一 utility design

---

## 实现建议

- **实现难度**: 中（需训练独立 selector）
- **预期性能**: TriviaQA 类数据集 coverage+10pp、error-8pp
- **适用场景**: 高风险 QA（如医疗、法律）；可结合 retrieval-augmented 校准
