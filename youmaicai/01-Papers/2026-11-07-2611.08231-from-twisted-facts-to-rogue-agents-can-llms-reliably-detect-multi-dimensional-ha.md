# From Twisted Facts to Rogue Agents: Can LLMs Reliably Detect Multi-Dimensional Hallucinations?

| **标题** | From Twisted Facts to Rogue Agents: Can LLMs Reliably Detect Multi-Dimensional Hallucinations? |

| **发表** | arXiv preprint（comments 为空） |
| **链接** | [原文](https://arxiv.org/abs/2611.08231) |
| **arXiv** | arXiv:2611.08231 |
| **代码** | — |

### 核心贡献
1. 提出 HaluCheck：一个大规模**双语**幻觉检测基准，包含超过 **42k** 个实例，同时覆盖两类幻觉——文本中的 factual hallucination 与 agent 轨迹中的 faithfulness hallucination。
2. 提供细粒度、多层级的标注体系，涵盖 detection、localization、correction 三个维度，并覆盖不同任务与不同扰动程度（perturbation degrees）。
3. 在 **14 个 LLM** 上进行系统评测，揭示模型虽具备基本的 sample-level 检测能力，但在细粒度 localization、correction 以及 agent 幻觉检测上表现糟糕。
4. 分析 thinking、web search、supervised fine-tuning 三种干预的效果，指出每种都只带来部分改善，没有任何一种能彻底解决问题。

### 技术方案
**核心思想**: 把「幻觉检测」从单一二分类任务扩展为三维度（检测 / 定位 / 纠正）× 多场景（文本事实 vs agent 忠实度）× 多扰动强度的评测矩阵，从而暴露那些在「只有检测」设定下被掩盖的能力短板。

| 技术 | 说明 |
|------|------|
| HaluCheck 基准 | 双语（bilingual），>42k instances，含 factual hallucination（文本）与 faithfulness hallucination（agent 轨迹）两类 |
| 多层级细粒度标注 | 支持 detection（检测）、localization（定位）、correction（纠正）三个粒度 |
| 扰动程度维度 | 覆盖不同 perturbation degrees，用于测试检测器对轻度与重度扭曲的鲁棒性 |
| 被测模型 | 14 个 LLM |
| 干预手段 | thinking（推理式思考）、web search（联网检索）、supervised fine-tuning（SFT），逐一作为部分缓解手段 |

### 实验结果
- **数据集**: HaluCheck（自建，双语，>42k 实例）
- **基线**: 14 个 LLM 的 zero-shot 检测能力，以及 thinking / web search / SFT 三种增强变体（具体模型名称摘要未说明）
- **结果**: 14 个 LLM 均表现出基本的 sample-level 检测能力，但在 fine-grained localization、correction 以及 agent hallucination 检测上明显吃力；thinking、web search 与 SFT 各自带来部分改进，但均未彻底解决该问题。摘要未给出具体准确率/F1 数值

### 局限性
- 摘要未给出任何具体数值结果（各模型在 detection/localization/correction 上的准确率或 F1），仅给定性判断；亦未列出 14 个模型的名字。
- 双语覆盖的具体语言对（摘要只说 bilingual）以及各语言间的性能差异未说明。
- 标注体系本身的主观性与一致性（标注者间一致性指标）未披露。
- agent 轨迹的 faithfulness hallucination 部分如何构造（是否由真实 agent 执行产生还是合成扰动）摘要未说明，这直接影响该子集的难度与可信度。

### 关键洞见
> 最值得警惕的发现是**「检测容易、纠正难」这一断层**：LLM 在 sample-level 判断「这段话有没有问题」上尚可，但一旦要求它指出错在哪（localization）并给出修正（correction），能力就急剧下降。这意味着把幻觉检测接进实际 pipeline 时，安全边际被严重高估——大多数检测器给出的「有病」信号，并不能被自动转化为可用的修复建议，而 pipeline 通常恰恰需要后者。同时 SFT 只能部分改善这一事实说明：幻觉的根源在生成过程的分布特性，而不只是「模型不知道要诚实」。
