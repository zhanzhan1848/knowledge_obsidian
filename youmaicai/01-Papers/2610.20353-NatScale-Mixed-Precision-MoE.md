## 核心贡献

> 提出 **NatScale**：contrast-calibrated 框架，把 gradient-based expert weights 用 power transformation 校准到 information-theoretic contrast target。

1. **暴露 expert ranking 不足**：仅靠 sensitivity ranking 不足以决定 expert 错误权重。
2. **NatScale 三件套**：① gradient weights 通过 power transform 校准；② 联合评估 gate / up / down 输出误差；③ 与现有 weight-spectra prior 融合选 config。
3. **SOTA 分配**：3 模型 / 9 设置上对 5 baselines，最低 native-to-quantized KL divergence + 最高 top-token agreement；7/9 设置 PPL 最低。

---

## 技术方案

### 核心思想

MoE 存储所有 expert weights（虽然只激活少数）→ mixed-precision quantization 按 expert sensitivity 分配 bit-width 是天然选择。但：
- 仅 sensitivity ranking → 不知如何 weight errors；
- 需要信息论意义上的 contrast target。

NatScale：
1. 用 **model-specific power transformation** 把 gradient-based expert weights 校准到 information-theoretic contrast；
2. **联合评估** gate / up / down 三配置 → 估计 expert 输出误差；
3. 与现有 weight-spectra prior（variance + precision decay）合并，在 storage budget 内选 config。

### 关键技术

| 技术 | 说明 |
|------|------|
| Contrast calibration | power transform 校准 weight |
| 联合 gate/up/down 评估 | 输出误差估计 |
| Weight spectra prior | variance + precision decay |
| Budget-aware selection | storage 约束下选 config |
| KL divergence as objective | native → quantized KL 最小 |

---

## 实验结论

- **模型**: 3 MoE models
- **基线**: 5 allocation methods
- **结果**:
  - 9/9 设置：最低 native-to-quantized KL divergence；
  - 9/9 设置：最高 top-token agreement；
  - 7/9 设置：最低 PPL；
  - 验证 objective-aware precision allocation 优于相关性排序。

---

## 局限性

- 需要 calibration data → 不能完全 training-free；
- power transformation 参数需调；
- 对超大规模 MoE (>100B) 算力开销未充分讨论。
