## 核心贡献

> **QViD**：一个**免训练**的、查询感知的视觉 token 剪枝方法 —— 利用查询-视觉交互矩阵**天然低秩**这一结构性质。

1. **问题**：VLM 因视觉 token 数量庞大而推理成本高 → 视觉 token 剪枝是自然解法。
2. **指出既有方法的盲区**：近期工作用查询信息引导 token 选择，但通常依赖**从注意力模式或 token 动态推导出的启发式**，**没有显式利用查询-视觉交互的底层结构**。
3. **关键观察**：由 Transformer attention 中**本就存在的 query 与 key 投影**自然诱导出的**查询-视觉交互矩阵，实际上是低秩的** —— 少量**主导潜在交互模态（dominant latent interaction modes）**即可捕获与查询相关的语义。
4. **提出 QViD（Query-Vision Decomposition）**：**免训练**、查询感知的视觉 token 剪枝方法，显式利用该低秩结构。
5. **结果**：在图像与视频理解基准上，**在同等 token 预算下持续改进性能**；**增益在激进压缩（aggressive compression）区间最大**。

## 技术方案

### 核心思想

剪枝的核心是「**哪些视觉 token 与当前查询相关**」。既有方法用启发式近似这个相关性；QViD 指出存在**更直接的结构信号**。

```text
查询-视觉交互矩阵 M = (W_Q · q)ᵀ (W_K · v)
                         ↓
              M 天然低秩 (effective low-rank)
                         ↓
        少量主导潜在交互模态捕获查询相关语义
                         ↓
              据此选择要保留的视觉 token
```

### 关键技术

| 技术 | 说明 |
|------|------|
| **低秩交互矩阵** | 由已有的 query/key 投影诱导，**无需额外训练** |
| **主导潜在模态** | 少量模态承载查询相关语义 → 分解后识别重要 token |
| **免训练（training-free）** | 不需要重新训练或微调 VLM |
| **激进压缩友好** | token 预算越紧，结构性先验的价值越大 |

## 实验结论

- **基准**: 图像理解 + 视频理解基准
- **对比设置**: **同等 token 预算**下与既有剪枝方法比较（这是公平对比的关键设置）
- **结果**:
  - 同等预算下**持续改进性能**
  - **激进压缩区间增益最大**
- **发表**: NeurIPS 2026

---

## 局限性

1. **低秩性的假设强度未量化** —— 交互矩阵在多大程度上低秩、秩是多少，随模型/输入如何变化，摘要未给
2. **分解的计算开销**未讨论 —— 剪枝前做一次矩阵分解的成本是否抵消收益（尤其在视频长序列上）
3. **训练-free 的代价**：无微调意味着无法针对特定域优化
4. **8 图的报告密度**（含补充）—— 图像与视频双基准的完整结果可能分散在附录

## 实现建议

- **实现难度**: 中（需实现交互矩阵分解 + token 选择逻辑，无需训练）
- **预期性能**: 同 token 预算下优于既有剪枝方法；**激进压缩时收益最大**
- **适用场景**: 高分辨率图像理解、多帧视频理解 —— 视觉 token 数量是主要瓶颈时
- **落地注意**:
  1. **免训练**是最大优势 —— 可直接作用于现有 VLM，无需重训
  2. 在**低 token 预算**场景优先试用（收益最大的区间）

## 我的评注

> 漂亮的地方是**「用本来就有的东西」**：交互矩阵由 attention 中**已有的** query/key 投影诱导，不是额外加的模块 —— 所以能免训练。这比「加一个可学习打分器」优雅得多。
>
> 「同等 token 预算下比较」这个设置值得点赞 —— 剪枝论文经常在**不固定预算**的情况下比较，导致「剪得更狠」看起来也更好。QViD 明确固定预算，这是正确的做法。
>
> 方法论上，这又是一次**「别用启发式代理，用结构本身」**：不设计注意力模式启发式，而是直接利用交互矩阵的低秩结构。这与 [[TraceQuery]] 的思路完全同构 —— 那篇说「别问表示变了没，问是否偏离完整轨迹」，本篇说「别用启发式近似相关性，用交互矩阵的秩结构」。
>
