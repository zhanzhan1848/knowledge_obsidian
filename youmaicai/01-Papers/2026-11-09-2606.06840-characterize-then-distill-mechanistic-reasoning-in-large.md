# Characterize Then Distill: Mechanistic Reasoning in Large Output Spaces

> **arXiv**: [2606.06840](https://arxiv.org/abs/2606.06840)
> **发表日期**: 2026-06-05（v5 更新于 2026-11-06）
> **分类**: cs.CL (Computation and Language)；交叉分类 cs.AI, cs.LG
> **会议/期刊**: arXiv preprint（101 页；代码：https://anonymous.4open.science/r/mistill-code-anon-rev-00E4）

## 📋 摘要

经推理训练的语言模型能**零样本**地从数千到数十万候选中选出少量相关标签。本文追问：它**在机制层面**如何做到？该机制能否被**蒸馏**？作者把每次决策视为由模型自身 margin 打分的 token 级事件：选出标签空间某**粗粒度区域**的 token、在该区域内选出具体标签的 token、以及输出**偏离**先前提到的近似命中（near-miss）的 token。通过归因、精确 mean-ablation、knock-in 与零假设校准，作者为**单个注意力头**确立了因果地位。在 MIMIC-IV 临床编码任务上（全部 **5,651 个候选编码**入上下文），一小撮**全局的、按阶段结构化**的头既必要又充分地覆盖几乎每份小结：不同头族分别读取候选区域与更早的近似命中，阻断其读取内容即消除其作用。该结构在第二个推理模型上重现。

作者据此提出 **MISTILL**：与思维链蒸馏不同，它**同时监督学生在决策事件上的 pooled attention**。在训练后找到的头上读取时，MISTILL 在跨族学生中几乎**翻倍**了对比性决策的因果恢复，在已承载大部分机制的另一学生中带来小而**种子稳定**的增益，匹配精度下未检出任务差异；匹配选择下其因果恢复与任务分数均超过冻结随机头池。在两个**人工标注证据**的语料上，MISTILL 学生的决策头比 CoT 蒸馏学生**更具体地**关注每个编码的证据。一项**预注册**的证据翻转测试未检测到经所测路径的证据依赖决策改进。

## 🎯 核心贡献

1. **把「决策」刻画为 token 级三阶段事件**：粗区域选择 token → 区域内标签选择 token → 偏离近似命中 token，并用模型自身 margin 精确定位这三种事件。
2. **为单个注意力头确立因果地位**：结合归因、**精确 mean-ablation**、knock-in 与零假设校准四类证据，而非仅靠相关性。
3. **刻画出阶段结构化的全局机制**：在 5,651 个候选编码全部入上下文的临床编码任务上，一小撮全局的、按阶段划分的头既必要又充分；不同头族分别读取候选区域与更早的近似命中；中层另一组头让区域提前若干 token 变得可引出。该结构在第二个推理模型上**重现**。
4. **提出 MISTILL 蒸馏方法**：除 CoT 蒸馏外，额外监督学生在决策事件处的 **pooled attention**，把机制本身传递给学生。
5. **机制蒸馏的因果验证**：跨族学生中对比性决策的因果恢复几乎翻倍；匹配选择下优于冻结随机头池。
6. **诚实的负面结果**：预注册的证据翻转（evidence-flip）测试未检出改进，说明机制迁移 ≠ 证据依赖推理能力提升。

## 🔧 方法/架构

- **决策事件定义**：以模型自身的 margin（top-1 与 top-2 logit 差）标注 token 级事件：

  ```math
  m_t = z_t^{(1)} - z_t^{(2)},\qquad
  \text{event types} = \{\text{region-select},\; \text{label-select},\; \text{near-miss-divergence}\}
  ```

  第三类事件对应「输出偏离了推理中早先提到的近似命中」的那个 token，是区分「真的想清楚」与「被前文带偏」的关键。

- **因果地位的确立（四件套）**：
  - **归因（attribution）**：定位对决策 margin 有贡献的头；
  - **精确 mean-ablation**：对候选头集合做精确平均消融，检验必要性；
  - **knock-in**：向被阻断的表示位置注入对照信息，检验充分性；
  - **零假设校准（null calibration）**：与随机/打乱对照对比，排除平凡解释。

- **结构发现的结论**：在 5,651 个候选编码全部入上下文时，存在一小撮**全局**、**按阶段结构化**的头集合，在几乎每一份小结上既必要又充分；可形式化为：

  ```math
  \mathcal{H} = \mathcal{H}_{\text{region}} \cup \mathcal{H}_{\text{near-miss}} \cup \mathcal{H}_{\text{elicit}},
  \quad \text{三者互不相交且分层}
  ```

- **MISTILL 蒸馏**：在 CoT 蒸馏目标之外，增加对学生在决策事件处 pooled attention 的监督项：

  ```math
  \mathcal{L} = \mathcal{L}_{\text{CoT}} + \lambda \cdot \mathcal{L}_{\text{attn-sup}}
  ```

  其中 $\mathcal{L}_{\text{attn-sup}}$ 让学生在决策 token 处的注意力对齐教师在对应头族上的读取模式。

- **证据阅读分析**：在人工标注证据的语料上度量决策头对各编码证据的注意力集中度（注意力质量 / 熵类指标）。

- **预注册证据翻转测试**：干预证据内容，检验决策是否随之改变（evidence-flip），作为因果性的最终检验。

## 📊 实验结果

- **数据集/任务**：
  - **MIMIC-IV** 出院小结的**临床编码**（全部 **5,651** 个候选编码置于上下文）；
  - 第二个推理模型上的**结构重现**；
  - 两个人工标注证据的语料（一个**零样本**读、一个**域内**读）；
  - 蒸馏迁移测试：**西班牙语**病例报告及其**英译**、**第二个学生族**、**MuSiQue-Ans**。
- **基线**：思维链（CoT）蒸馏；冻结的**随机头池**（matched selection）；零假设/打乱对照。
- **结果**：
  - MISTILL 在**跨族学生**中使对比性决策的**因果恢复几乎翻倍**；
  - 在已承载大部分机制的另一学生中带来**小而种子稳定**的增益，**匹配精度下未检出任务差异**；
  - 匹配选择下，MISTILL 的因果恢复与任务分数**均超过冻结随机头池**；
  - 在两个证据标注语料上，MISTILL 学生的决策头对各编码证据的注意力**更多、更具体**；
  - **预注册**的 evidence-flip 测试**未检出**经所测路径的证据依赖决策改进（负面结果，作者如实报告）。

## ⚠️ 局限性

- **负面结果**：预注册 evidence-flip 测试未检出改进，作者自己指出机制迁移并未转化为证据依赖推理能力的提升——这是该工作最重要的边界。
- 任务集中于**大输出空间的选择式任务**（临床编码），能否外推到生成式长文本任务未知。
- 论文 **101 页**、单作者、代码以**匿名评审链接**发布（anonymous.4open.science），长期可获取性存疑。
- 结论依赖特定推理模型与架构；v5 新增的跨语言/跨学生族迁移证据仍属有限复核。
- 精确 mean-ablation、knock-in 等因果工具成本高，难以大规模扫描；「一小撮头」的识别是否有数据依赖的偶然性未充分排除。
- 学生模型上「几乎翻倍因果恢复」是机制层面的度量，与实际任务分数之间的联系被作者自己指出并不明显。
