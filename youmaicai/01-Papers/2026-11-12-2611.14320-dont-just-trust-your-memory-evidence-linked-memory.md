## 核心要点
1. 指出**记忆诱导退化（memory-induced degradation）**的根因：经验被蒸馏成"教训（lesson）"时只标注了任务成功/失败，却**不提供其来源轨迹**，智能体因此既无法核实教训是否正确，也无法发现自己的误用或误读。
2. 提出 **WikiTrace（证据链接记忆系统）**：每条教训以"简洁洞见"形式存储，并**双向链接**到①该轨迹成败原因的摘要、②原始轨迹全文；新任务上智能体先看全部洞见，当某条洞见**细节缺失、与其他洞见冲突、或来自失败任务**时，就沿链接用终端工具下钻，补齐细节或纠正洞见后再行动。
3. 在**五个智能体基准**上验证：WikiTrace 一致优于现有记忆方法以及"只给同样洞见、不给证据链"的基线，并且显著**降低记忆诱导退化**；代码开源于 https://github.com/yukyeongleee/wikitrace。

## 摘要（原文）
External memory enables LLM agents to improve from experience by distilling trajectories of past
tasks into concise lessons for new tasks. However, memory can also lead to memory-induced
degradation, where an agent fails on tasks it would solve without memory, often because it follows a
lesson that is incorrect, or misapplies or misreads a valid one. This is because lessons are inferred
from trajectories labeled only with task success or failure, yet are typically provided without the
trajectories they came from, leaving the agent no way to check them. To address this, we introduce
WikiTrace, an evidence-linked memory system designed to let agents check each lesson against its
original trajectory. Specifically, motivated by the finding that a trajectory often still holds the
evidence needed to catch an erroneous lesson, WikiTrace stores each lesson as a concise insight linked
to a summary of why its trajectory succeeded or failed and to the raw trajectory itself. Then, on a
new task, the agent starts from all insights and, whenever one lacks details needed to act, conflicts
with another, or comes from a failed task, descends through its links with terminal tools to fill in
missing details or correct the insight before acting. We validate WikiTrace on five agentic benchmarks,
showing that it consistently outperforms existing memory approaches and a baseline given the same
insights alone, while also reducing memory-induced degradation. Our code is available at
https://github.com/yukyeongleee/wikitrace
