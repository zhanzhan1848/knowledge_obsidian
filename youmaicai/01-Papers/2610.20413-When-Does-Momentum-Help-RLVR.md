## 核心贡献

1. **Bandit RLVR + bias-corrected EMA momentum 的理论分析**
2. **两种 regime 的 gain 公式**：
   - 精确 gradient：β↑ → 严格加速（防 overshoot 范围）
   - 采样 gradient：η↓ 时 gain 消失得更快；保持 η/(1−β) 在 safe regime → gain 不消失
3. **实证验证**：Qwen3-4B SGD-EMA / AdamW + Qwen2.5-32B AdamW 都支持

## 方法

### Bandit RLVR formulation

```math
g_t = \nabla_θ E[r(s, a_t)]
# EMA momentum: m_t = β m_{t-1} + (1-β) g_t (bias-corrected)
```

### 关键结论

| 场景 | 结论 |
|------|------|
| 精确 gradient | β↑ (防 overshoot 范围) **严格加速** |
| 采样 + η 固定 → η↓ | expected gain **消失得比 sampling fluctuation 快** |
| 采样 + 保持 η/(1−β) 在 safe regime | **non-vanishing gain** → dominates fluctuations |

### Principle

LLM post-training 应选 **larger EMA β** / **larger AdamW β1**，而非 conventional choice。

## 实验结果

| Model | Optimizer | β 增大效果 |
|-------|-----------|-----------|
| Qwen3-4B-Base | SGD-EMA | 验证 principle |
| Qwen3-4B-Base | AdamW | 验证 principle |
| Qwen2.5-32B | AdamW | mean validation accuracy **+~2pp** |

## 局限性

- bandit formulation → 是简化模型，不能完全捕获 LLM RLVR 的复杂环境
- 实验仅在 Qwen3-4B / Qwen2.5-32B 上验证
- 没有涵盖其他 optimizer (Lion, Sophia, Muon 等)
