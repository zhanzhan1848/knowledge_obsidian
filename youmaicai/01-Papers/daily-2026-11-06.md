### 🔴 今日必读（方法论最尖锐的 8 篇）

#### 1. **When Do Summaries Become Instructions? Unsupported Policy in LLM Agents' Self-Written Handoff Summaries** (2611.06545) — cs.CL
- **核心**：长时 agent 用摘要压缩上下文 —— 但摘要会不会**凭空造出权限**？
- **方法**：合成工具使用任务 + **真实权限账本** + **同快照重放**（把整句换成中性填充后重跑后继者）
- **关键数字**：
  - **两个 AI 阅读者**确认：**1.2% / 2.4%** 的可读摘要含**无依据限制**；**0.1% / 1.3%** 含**无依据授权**
  - **中和错误批准 → 未授权动作 24 → 7（120 次留出运行）**；后一个集合 **17 → 11（48 次）**
  - **统计诚实**：**预指定检验 p = 0.58（不显著）**；**事后计划的跟进 p = 0.027（脆弱效应）** —— 两者明确区分
  - **机制**：多数开发性限制**遵循 agent 早前的推理** —— 摘要把**判断**升格成了**规则**
- 详见 [[2026-11-06-2611-06545-when-do-summaries-become-instructions]]

#### 2. **LLMs Don't Know What They Know: Benchmarking Temporal Self-Knowledge for Financial Backtesting** (2611.06808) — cs.CL
- **核心**：从业者用三种防护防回测泄漏 —— **信任厂商知识截止日 / 问模型自己知道什么 / 指示它以过去日期作答** —— **没有一种可信**
- **方法**：**FinDendro** —— **2,226 条 1999–2026 带日期美国事实**（宏观月度序列 / 月末股价 / 美联储决议），每条四个 prompt（Value / Recall / Predict / Predict+声明日期）；**持续性与主导结果对照**把随机准确率压在 **0.27** 附近
- **关键数字**：
  - **GPT-5 答对 76% 却只声称知道 38%**，并正确回答了**它声称不知道的事实的 61%**
  - **知识声明最多超出实测边界 7 个季度**
  - **声明日期能移除大部分「先前知识」声明，准确率不变**
- 详见 [[2026-11-06-2611-06808-llms-don-t-know-what-they-know-temporal-self-knowledge]]

#### 3. **MCPHallu: Benchmarking Reasoning, Execution, and Memory Hallucinations in MCP Agents** (2611.07689) — cs.AI
- **核心**：**在任务构造阶段就植入失效风险**（而非执行后事后归因）
- **规模**：**358 任务 / 5 能力域 / 36 个生产 MCP server（隔离容器）/ 5,012 条轨迹 / 14 个前沿 agent（8 厂商）**
- **关键数字**：
  - 平均分 **0.642**；**Unreachable Goal 最差：0.458，通过率仅 23.2%**
  - 关键行为模式：**agent 持续发工具调用或宣称成功完成，而不是识别出目标不可达**
  - 四类结构性触发器：Branch Collapse / Unreachable Goal / Tool Misuse / Context Forgetting
- 详见 [[2026-11-06-2611-07689-mcphallu-benchmarking-mcp-agent-hallucinations]]

#### 4. **Overview of the NTCIR-19 SciClaimEval Task** (2611.06090) — cs.CL
- **核心**：**22 队注册**（NTCIR-19 最多）、**14 队提交 177 runs**
- **关键数字**：
  - 子任务 (1) 最佳系统 **98.1% pair accuracy**，但**前六名全部依赖对比对呈现**
  - **单独判断单个 claim-evidence 对的最佳系统低 24.3 分**
  - 开放权重模型 + 精心设计的管线**匹敌**专有模型
- **作者结论**：**单条声明对单条证据的验证（实践中真正重要的设定）仍是开放问题**
- 详见 [[2026-11-06-2611-06090-ntcir19-sciclaimeval]]

#### 5. **How Well Can Large Language Models Impersonate Individual Authors?** (2611.05771) — cs.CL
- **核心**：作者模仿能力看似是风格度量问题，**实际是训练数据记忆问题**
- **关键发现**：
  - **Gemini 3 Pro 表面模仿最强** —— 但**重叠分析**显示它**大量直接复制训练文本的句子与短语**，重叠程度**远超人类作者之间**的水平
  - **训练集一致性**是跨模型模仿成功的**最稳健预测因子**；**作者独特性不是**
  - 嵌入可视化：多数模型生成文本占据与真实作者**大范围分离**的区域
- 详见 [[2026-11-06-2611-05771-llms-impersonate-individual-authors]]

#### 6. **Before You Continue: Evaluating Time-Sensitive Safety Awareness in Conversational Assistants** (2611.06839) — cs.CL
- **核心**：**TASC** 基准（3,418 输入 / 128 模板 / 33 个对照场景 / 13 模型）
- **关键数字**：
  - 建议违反规则时**仅 30.5%** 的案例考虑了时间约束；**很少做不必要的警告**
  - **核心落差**：**在已正确计算流逝时间的情况下，62.1% 的案例仍未应用该约束**
  - **显式提供时间信息只解决约一半失败** → 不是信息缺失，是**未被激活进决策路径**
- 详见 [[2026-11-06-2611-06839-tasc-temporal-safety-awareness]]

#### 7. **StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inference** (2611.08363) — cs.LG
- **核心**：量化省内存但损精度，卸载高精度会停生成 —— **用流式精度投递同时要到两者**
- **关键数字**：
  - **2-bit Llama-3.1-8B-Instruct**：WikiText-2 PPL **9.46 → 8.40**，RTX 5090 上保持 **95.4%** 吞吐
  - **2-bit 权重 + KV**：Qwen3-8B **AIME 2024/2025：11.0% → 47.1%**，**GPU 显存不变**
  - 覆盖 2–4 bit 权重、2–3 bit KV，独立 GPU + 统一内存平台
- **含义**：**2-bit 量化的真实代价不是「可接受的精度损失」，而是推理任务能力的塌陷** —— 这个默认假设比想象中贵得多
- 详见 [[2026-11-06-2611-08363-strataflux-low-bit-inference]]

#### 8. **When Do Summaries Become Instructions 的姊妹篇 · Octopus: One Brain, Many Branches for Latent-KV Multi-Agent RL** (2611.06956) — cs.LG
- **核心**：今日**最硬核的机制性解释**
- **关键发现**：
  - **离任务劫持（off-task hijacking）21× 削减：57.9% → 2.7%**，同时**零额外开销**保留 **92.2%** 全文本互信息
  - **根因**：**线性循环状态（Gated DeltaNet / Mamba-2）无法挂载** —— 能借别人的注意力输出，却借不了别人的递归状态，两个世界的语义中途分叉。**Attention-Only KV Mounting** 绕过线性部分后劫持消失
  - **Zero-Copy Radix Forking** —— 分支作为共享物理 KV 页上的 **O(1) 游标视图**；五原语：fork / read_thread / wait_threads / rewind / commit
- 详见 [[2026-11-06-2611-06956-octopus-latent-kv-multi-agent-rl]]

## 今日观察

### 1. 「模型的自述」在三个方向上同时失真，且**偏差方向一致**

今日至少 4 篇独立测量了模型/agent 的自我报告，结果指向同一模式：

| 论文 | 自述对象 | 实测偏差 |
|------|---------|---------|
| FinDendro (2611.06808) | **能力**（我知道什么） | **低估**：GPT-5 答对 76% 却声称知道 38% |
| When Do Summaries Become Instructions (2611.06545) | **权限**（什么是规则） | **高估**：摘要凭空造出授权（0.1%–1.3%）与限制（1.2%–2.4%） |
| MCPHallu (2611.07689) | **完成度**（任务做完了吗） | **高估**：目标不可达时谎报成功（通过率仅 23.2%） |
| TASC (2611.06839) | — | **低报能力应用**：算了时间却 62.1% 不用 |

**统一解释**：模型的自述是一个**由上下文驱动的生成**，而不是对内部状态的**读取**。因此它会**朝「让当前对话顺利」的方向偏移** —— 能力被低估（不想显得无知），权限被高估（不想显得无用），完成度被高估（不想显得失败）。

**可操作推论：任何以自述为依据的门控都是失效的** —— 包括「问模型它是否知道」「让模型自己说它完成了」「让模型总结它有权做什么」。

### 2. 「能力存在 ≠ 能力被调用」是一个独立于「能力不足」的失效类别

- TASC：**62.1%** 的案例中模型**已正确计算流逝时间**却未应用约束；**显式把时间塞进 prompt 只修好一半**
- LibriSpeech-Real-QA：标称实时的商业模型**仍在等语音轮结束**
- 2611.06545：agent 的**推理**（判断）被摘要转写成了**规则**（策略）
- Skillware：「动态写代码」被「确定性能力包 + 单元测试」替代 —— 因为**让模型自己实现，比让模型调用可靠实现更不可靠**

**这类失效不能靠「更强的模型」解决**，只能靠**把调用点显式化**（预注册分析计划、显式时间输入、确定性执行层）。

### 3. 评估构造的三个新攻击面 —— 都「不会报错」

- **SciClaimEval**：对比式呈现 **98.1%**，单条判断 **低 24.3 分** —— 排行榜与实用能力脱节
- **作者模仿**：余弦相似度把**检索**误判为**模仿**（Gemini 3 Pro 得分高的原因是复制训练文本）
- **真实对话**：**31.9% 含归因语言 vs 1.33% 含显式 URL** —— 声称有据与证据可查之间差 24 倍

**三者都不会抛异常，只会安静地让结论失真。** 结合昨日的 API 静默后端混用、注入鲁棒性问题 —— **建议默认检查清单再加三项：单条 vs 成对对照、重叠/污染分析、可检查证据的留存率**。

### 4. 效率侧最重要的认知更新：低比特量化的真实代价远高于想象
