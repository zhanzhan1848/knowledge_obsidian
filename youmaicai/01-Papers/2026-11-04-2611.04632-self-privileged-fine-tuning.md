## 核心贡献
1. **理论上区分了"动态加权"与"静态加权"两类 token 加权 SFT 的优化行为**。动态加权（DFT）的最优解满足 $p_{\theta_{k+1}}(\cdot)\propto p_{\text{data}}(\cdot)p_{\theta_k}(\cdot)$，迭代后 $p_{\theta_{k+1}}\propto p_{\theta_0}\cdot p_{\text{data}}^{k+1}$——高概率 token 的相对概率**指数增长**，分布被逐步锐化；**Proposition 1** 证明其极限分布是数据分布众数上的 Dirac 质量（$\lim_{k\to\infty}p_{\theta_k}(v|x,y_{<t})=\mathbb{1}[v=v^*]$）。静态加权（PriFT）的最优解满足 $p^*_\theta(v)\propto p_{\text{data}}(v)p_{\text{prior}}(v)$，是**固定不变**的目标分布（Proposition 2）。
2. **由此推出静态加权的成败关键在于 prior 的质量**，而既有静态方法（PriFT）用冻结初始模型做 prior，只以 prompt 为条件，**不包含任何关于"当前 token 对最终答案贡献多少"的信息**（outcome-agnostic）。
3. **提出 SPFT（Self-Privileged Fine-Tuning）**：用**初始模型的冻结副本、以特权信息（privileged information）为条件**评估 prior $q_t = p_{\theta_0}(y_t|x,c,y_{<t})$，作为 token 级权重；可训练模型只接收普通 prompt $x$ 与前缀 $y_{<t}$，**特权信息只通过权重信号影响训练，不进入模型的前向输入**。全程 offline，无外部 teacher，无 on-policy 采样。
4. **Proposition 3 的贝叶斯分解揭示了权重的语义**：$q_t = p_{\theta_0}(c|x,y_{\le t})/\big[p_{\theta_0}(c|x,y_{<t})p_{\theta_0}(y_t|x,y_{<t})\big]$——即 privileged prior 相当于把基础 prior 乘上一个**结果似然比**，衡量当前 token $y_t$ 对 ground-truth 结果 $c$ 的**增量贡献**；比值 >1 表示该 token 有助于推出正确结果，因而获得更大权重。这正是"按预测性重新加权标准静态 prior"。
5. **SPFT-SR（序列相对加权）**：绝对 privileged likelihood $q_t$ 会随题目难度整体漂移，掩盖了响应内部的相对支持度。SPFT-SR 在响应内做中心化并只保留正偏离：$\mu=\frac1T\sum_t q_t$，$\sigma=\sqrt{\frac1T\sum_t(q_t-\mu)^2+\epsilon}$，$r_t=\big[\frac{q_t-\mu}{\sigma}\big]_+$。
6. **跨领域的特权信息构造**：数学任务用 boxed 答案中的 ground-truth 数值答案；代码任务**不能**直接给参考实现（会造成严重的 code token 泄漏），改用轻量 AST 解析与模式匹配抽取"Clean Rule"——识别算法范式（动态规划、BFS、双指针）、关键抽象数据结构（堆、双端队列、状态数组）与边界不变量（提前返回条件），以语义指导代替表面语法。
7. **实证**：数学推理（Qwen2.5-Math-1.5B/7B、Qwen3-8B-Base，五个基准 MATH-500/Minerva Math/OlympiadBench/AIME24/AMC23）与代码生成（Qwen2.5-Coder-1.5B，EvalPlus）上，SPFT 一致优于 SFT 与全部 token 加权基线（DFT/ASFT/TALR/PriFT）。

## 问题背景
SFT 是 LLM 后训练的核心组件，也是后续 RL 的重要基础。近年的一个方向是在 SFT 目标中引入**非均匀的 token 权重**：DFT（Wu et al. 2026）按当前模型对每个 token 的概率重加权；ASFT（Zhu et al. 2026）引入 KL 锚定项稳定优化；TALR（Lin et al. 2026）用温度缩放控制权重幅度；PriFT（Wang et al. 2026）改用冻结参考模型算权重，得到**静态**加权方案。

这些方法都有效，但**其改进背后的机制理解不足**。DFT 类方法的权重来自正在被优化的模型，权重信号在训练中持续演化；PriFT 类方法的信号不随策略演化、但与任务结果无关。本文通过分析这些加权方案的损失函数与其诱导的优化目标，填补这一空白，并据此设计新方法。

另一条背景是**特权信息**与知识蒸馏：传统蒸馏在固定前缀上匹配 teacher 的软预测；MiniLLM/GKD 通过 on-policy 采样处理前缀失配但需要在线 rollout，GKD 还需外部 teacher；**OPSD（On-Policy Self-Distillation）**去掉了外部 teacher，改为以参考解作为特权信息。SPFT 采纳 OPSD 的特权信息思路，但**offline** 实现：用可验证的结果构造 token 权重，不需要 on-policy 采样，也不需要全词表分布匹配。

## 方法
### 1. 动态加权的分析（DFT）
DFT 目标：

$$\mathcal{L}_{\text{DFT}}(\theta) = -\mathbb{E}_{(x,y)\sim p_{\text{data}}}\Big[\sum_t \text{sg}\big[p_\theta(y_t|x,y_{<t})\big]\log p_\theta(y_t|x,y_{<t})\Big] \tag{1}$$

在第 $k$ 步，权重项用当前模型 $p_{\theta_k}$ 评估并在该步内视为固定。最优解：

$$p_{\theta_{k+1}}(y_t|x,y_{<t}) \propto p_{\text{data}}(y_t|x,y_{<t})\,p_{\theta_k}(y_t|x,y_{<t}) \tag{3}$$

反复应用得 $p_{\theta_{k+1}}\propto p_{\theta_0}\cdot p_{\text{data}}^{k+1}$。两个候选 token 的概率比：

$$\frac{p_{\theta_{k+1}}(v_1|x,y_{<t})}{p_{\theta_{k+1}}(v_2|x,y_{<t})} = \frac{p_{\theta_0}(v_1|x,y_{<t})}{p_{\theta_0}(v_2|x,y_{<t})}\left(\frac{p_{\text{data}}(v_1|x,y_{<t})}{p_{\text{data}}(v_2|x,y_{<t})}\right)^{k+1} \tag{5}$$

**Proposition 1**：若最大化元唯一、$v^*=\arg\max_v p_{\text{data}}(v|x,y_{<t})$ 且 $p_{\theta_0}(v^*)>0$，则

$$\lim_{k\to\infty} p_{\theta_k}(v|x,y_{<t}) = \mathbb{1}[v=v^*] \tag{6}$$

即 DFT 最终把全部概率质量集中到数据分布的众数上——分布持续锐化。作者指出类似锐化行为可能出现在其他动态加权方法中。

### 2. 静态加权的分析
$$\mathcal{L}_{\text{static}}(\theta) = -\mathbb{E}_{(x,y)\sim p_{\text{data}}}\Big[\sum_t p_{\text{prior}}(y_t|x,y_{<t})\log p_\theta(y_t|x,y_{<t})\Big] \tag{7}$$

**Proposition 2**：最优解 $p^*_\theta(v|x,y_{<t})\propto p_{\text{data}}(v|x,y_{<t})p_{\text{prior}}(v|x,y_{<t})$（式 8、9）。由于 $p_{\text{prior}}$ 在训练中不变，诱导的目标分布**固定**，避免了动态加权目标持续演化的问题。**结论：静态加权的有效性关键取决于 prior 的质量**。

### 3. SPFT 的目标函数
特权条件下的先验：

$$q_t \triangleq p_{\theta_0}(y_t|x,c,y_{<t}) \tag{11}$$

**Proposition 3（特权先验 = 结果重加权先验）**：由贝叶斯公式，

$$q_t = \frac{p_{\theta_0}(c|x,y_{\le t})}{p_{\theta_0}(c|x,y_{<t})\,p_{\theta_0}(y_t|x,y_{<t})} \tag{12}$$

SPFT 目标：

$$\mathcal{L}_{\text{SPFT}}(\theta) = -\mathbb{E}_{(x,y,c)\sim p_{\text{data}}}\Big[\sum_t q_t \log p_\theta(y_t|x,y_{<t})\Big] \tag{13}$$

诱导的最优分布：

$$p^*_{\theta,\text{SPFT}}(v|x,y_{<t}) \propto p_{\text{data}}(v|x,y_{<t})\,p_{\theta_0}(v|x,c,y_{<t}) \tag{14}$$

进一步展开：

$$p^*_{\theta,\text{SPFT}}(v|x,y_{<t}) \propto p_{\text{data}}(v|x,y_{<t})\,p_{\theta_0}(v|x,y_{<t})\,\frac{p_{\theta_0}(c|x,y_{<t},v)}{p_{\theta_0}(c|x,y_{<t})} \tag{15}$$

与 PriFT 相比，SPFT **保留了原始基础 prior**，并额外按每个候选 token 对特权结果的贡献进行调制。

### 4. SPFT-SR（序列相对加权）
$$\mu=\frac{1}{T}\sum_{t=1}^T q_t,\quad \sigma=\sqrt{\frac{1}{T}\sum_{t=1}^T(q_t-\mu)^2+\epsilon},\quad r_t=\Big[\frac{q_t-\mu}{\sigma}\Big]_+ \tag{16}$$

$$\mathcal{L}_{\text{SPFT-SR}}(\theta) = -\mathbb{E}_{(x,y,c)\sim p_{\text{data}}}\Big[\sum_t r_t\log p_\theta(y_t|x,y_{<t})\Big] \tag{17}$$

$r_t$ 只保留响应内**高于平均**的 privileged likelihood；$q_t\le\mu$ 的 token 得分为 0。作者谨慎地指出这反映的是"相对的结果条件支持度"，而非"有保证的语义重要性"。

### 5. 特权 prompt 的构造
- 可训练模型接收标准任务 prompt 与前缀 $h_t=(x,y_{<t})$；冻结参考模型在特权上下文 $h^P_t=(x,c,y_{<t})$ 下评估，特权信息嵌入领域特定的指令模板。
- **数学**：$c$ = 从 boxed 解答中抽取的 ground-truth 数值答案，引导参考模型判断中间推导是否与目标结果一致。
- **代码**：$c$ = "Clean Rule"——通过轻量 AST 解析与模式匹配提取高层算法范式、抽象数据结构、边界不变量，以传达算法意图而不泄漏实现细节。

### 6. 冻结 vs 在线参考
$$q_t^{\text{frozen}} = p_{\theta_0}(y_t|x,c,y_{<t}), \qquad q_t^{\text{online}} = \text{sg}[p_\theta(y_t|x,c,y_{<t})] \tag{18,19}$$

在线变体让权重随模型一起演化，破坏了静态加权的"固定目标"性质。

## 实验结果
- **Dataset/Task**:
  - **数学**：NuminaMath-CoT 随机 10K 子集；global batch 32，lr 1e-5 + cosine decay + 5% warmup，1 epoch，最大序列长 3,072。评测 Qwen2.5-Math-1.5B/7B、Qwen3-8B-Base；五基准套件 MATH-500、Minerva Math、OlympiadBench、AIME 2024、AMC 2023；每题 8 采样，temperature 0.7，top-p 0.8，seed 0，unified qwen-boxed 协议。
  - **代码**：OpenCodeInstruct 随机 10K 子集；global batch 16，lr 5e-5，1 epoch，最大序列长 2,048。评测 Qwen2.5-Coder-1.5B，EvalPlus（HumanEval / HumanEval+ / MBPP / MBPP+），greedy decoding。

## 关键洞察
1. **动态 token 加权在数学上等价于一个自我强化的分布坍缩过程**：$p_{\theta_{k+1}}\propto p_{\theta_0}p_{\text{data}}^{k+1}$ 意味着高概率 token 的相对概率以 $k$ 次幂增长，Proposition 1 证明极限是 Dirac 质量。DFT 的 Pass@8 在 Qwen2.5-Math-7B 上反而**低于 SFT**（49.81 vs 57.54），这正是坍缩的代价——多样性被消灭，正确的少数解无法被采样到。
2. **静态加权的"稳定"是有条件的**：它稳定当且仅当 prior 质量足够好。因此"用冻结参考模型"本身不是优点，**用冻结模型且让它知晓结果**才是。
3. **贝叶斯分解把 token 权重从启发式变成了有解释的量**：$q_t$ 中的似然比 $p_\theta(c|x,y_{\le t})/p_\theta(c|x,y_{<t})$ 直接读作"加入这个 token 后正确结果的可能性提升了多少"。这把"哪些 token 重要"的判断从人工设计转为模型自身的概率计算。
4. **特权信息只走权重通道、不进前向输入，是一个关键的设计约束**：它保证了部署时不需要特权信息（推理时模型完全不知道正确答案），同时训练时能利用它。这是一种"信息只在训练期通过标量权重注入"的模式。
5. **代码任务暴露了"特权信息形式"本身的工程难题**：直接给参考实现会造成 code token 泄漏，反而不如高层抽象（Clean Rule 59.70 vs Full Code 57.70）。这说明特权信息的设计目标是**语义指导而非答案拷贝**，且需要针对领域单独设计。
6. **SPFT 实现了"受控锐化"**：熵降到 0.91 但 top-1 未到 99.7%，替代 token 保留非平凡质量，Pass@k 与 Maj@k 同时保持——这解释了它为何在采样评测下优于 DFT。

## 局限性
- **依赖可验证或结构化可抽取的特权信息**：数学答案、代码 AST 抽象属于"有答案可查"的领域；作者自陈在结果噪声、部分可观测、主观或长程的任务中如何构造与验证特权信息**尚属开放问题**。
- **评测仅限数学与代码两个领域**，且模型规模在 1.5B–8B，未验证更大模型或不同架构。
- **SPFT 在 Qwen3-8B 上并非全面最优**：SPFT（47.80 Avg@8）略低于 PriFT（48.63），只有 SPFT-SR（49.74）领先；提升主要体现在 SPFT-SR 版本。
- **冻结优于在线的结论存在例外**：OlympiadBench 上冻结在 Pass@8 上比在线**低 10.66 个点**（40.44 vs 51.10），作者未解释这一反向结果。
- **"特权先验 = 结果重加权先验"的推导依赖初始模型本身能合理评估特权条件下的 token 概率**；若基座模型在特权上下文中的判断能力差，权重信号本身就不可靠——这一失效模式未被测量。
- **Proposition 1 依赖严格假设**（最大化元唯一、初始模型对该众数分配非零概率），实践中"众数唯一"很少严格成立，理论结论是对理想化情形的刻画。
- **权重是标量**：论文未讨论多维/结构化权重（如区分"推理步骤"与"格式 token"），而 DFT vs 蒸馏的对比被放在附录，说明这不是本文的重点。
- **代码任务上的 Clean Rule 依赖手工设计的 AST 模式匹配规则**，可迁移性到其他编程范式或非代码领域未知；此外 Clean Rule 的抽取本身需要参考实现，训练数据管线复杂度上升。
- **没有评估 SPFT 与后续 RL 的兼容性**，而 SFT 作为 RL 基础正是本文动机之一。

## 适用场景
- **可验证答案的推理任务**：数学、有确定输出的 QA、程序合成——存在 ground truth 可作为特权信息 $c$。
- **离线、无外部 teacher 的后训练**：没有更强的模型可用、也无法承担 on-policy rollout 成本时，用自身初始模型 + 特权信息构造加权的 SFT。
- **需要保持输出多样性的采样场景**：相比 DFT 的坍缩，SPFT 在 Pass@k 与 Maj@k 上同时受益，适合依赖 best-of-n 或自一致性投票的系统。
- **有结构化答案语义可抽取的领域**：可通过 AST/规则抽取"算法意图"而非答案文本的领域。

**不适用于**：没有可验证结果的任务（开放式对话、创意写作、主观评价）；结果有噪声或部分可观测的任务；需要模型在推理时也知晓特权信息的场景；以及希望直接套用现成方案而不做领域特定特权信息工程的用户。
