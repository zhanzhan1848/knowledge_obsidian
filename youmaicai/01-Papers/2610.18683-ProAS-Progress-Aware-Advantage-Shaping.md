## 核心贡献

> 用动态演化的 *Agentic Reference Graph* (ARG) 实现 fine-grained credit assignment——MUI 抑制不合理激励 + APR 不对称重分配，无 critic 开销即可提升 group-based baselines。

1. **Uniform credit assignment 问题诊断**：GRPO 类 critic-free 算法给 trajectory 内所有 action 同等 advantage
2. **ARG (Agentic Reference Graph)**：动态演化的 reference 图，捕捉 sub-task dependency
3. **MUI (Masking Unreasonable Incentives)**：遮蔽不合理 action 的 advantage
4. **APR (Asymmetric Penalty Redistribution)**：不对称地把 penalty 重新分配到 early pivotal deviations
5. **Plug-and-play**：universal elevate mainstream group-based baselines to SOTA

---

## 技术方案

### 核心思想

GRPO 类 critic-free RL 在 multi-turn agentic 任务上把 trajectory-level advantage 平均分给每个 action——两个问题：(1) reinforcement 错误结构化 action；(2) 忽略 early pivotal deviations 的 cascading 影响。ProAS 提出 plug-and-play 框架：

- 维护 *动态演化的 ARG* 表达 sub-task structure
- *MUI* 遮蔽与 reference 不符的 action
- *APR* 不对称 penalty redistribution：early 关键 step 的 penalty 加权

无 critic、纯 advantage post-processing。

### 关键技术

| 技术 | 说明 |
|------|------|
| Agentic Reference Graph (ARG) | 动态表达 sub-task dependency |
| Masking Unreasonable Incentives (MUI) | 遮蔽 non-aligned action |
| Asymmetric Penalty Redistribution (APR) | early pivotal step 加权 |
| Plug-and-play | 兼容 GRPO 类 group-based baseline |
| Robustness | 对 imperfect / distilled ARG 仍 robust |

---

## 公式

ProAS advantage 重塑：

```math
A_t' = \text{MUI}(A_t, \text{ARG}) + \text{APR}(A_t, \text{ARG}, t)
```

具体地：

```math
\text{MUI}(A_t) = \begin{cases} A_t, & \text{if } a_t \text{ aligned with ARG} \\ 0, & \text{otherwise} \end{cases}
```

```math
\text{APR}(A_t) = -w_t \cdot |\min(0, A_t)|, \quad w_t = \text{ARG早期pivotalness}(t)
```

## 实验结论

- **模型**：Qwen2.5-1.5B-Instruct / Qwen2.5-7B-Instruct
- **ALFWorld**：peak **91.9%** / **94.3%** success
- **WebShop**：peak **66.7%** / **70.8%** success
- **训练加速**：up to **2.44×** convergence speedup
- **Robustness**：imperfect / distilled ARG 下仍稳
- **Plug-and-play**：GRPO 类 baseline 一致提升

---

## 局限性

- ARG 的 quality 是上限（distilled ARG 仍能 work but ceiling 较低）
- 主要在 WebShop / ALFWorld 验证；multi-tool 长程任务未深入
- 与 DPO / PPO 类 critic-based 算法的对比未给出
- 早期 pivotal detection 的理论保证
