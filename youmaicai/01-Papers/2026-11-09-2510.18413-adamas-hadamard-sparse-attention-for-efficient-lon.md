# Adamas: Hadamard Sparse Attention for Efficient Long-Context Inference

> **arXiv**: [2510.18413](https://arxiv.org/abs/2510.18413)
> **发表日期**: 2025-10-21（v2 更新于 2026-11-06）
> **分类**: cs.CL (Computation and Language)
> **会议/期刊**: arXiv preprint

## 📋 摘要

当前 LLM 已支持数十万乃至百万 token 的上下文窗口，支撑起长文档摘要、大规模代码合成、多文档问答与持久化多轮对话等应用。然而超长上下文会**加剧自注意力的二次代价**，使自回归解码延迟严重。现有稀疏注意力方法通过只关注部分 KV token 来降低成本，但**固定或粗粒度**的选择策略在受限 token 预算下可能**漏掉关键 token**或保留大量冗余。本文提出 **Adamas**，一种面向长上下文推理的**准确、高效的 token 级稀疏注意力**机制。Adamas 对 KV 状态施加 **Hadamard 变换**（异或 Hadamard 型的快速变换），再经**分桶量化（bucketization）**与 **2-bit 压缩**生成紧凑表示，并用**轻量的距离估计**高效完成 **top-k 候选选择**；被选中的位置再去**取回（gather）对应的原始 KV 状态**执行稀疏注意力。全面评测显示，Adamas 在 **Llama-3.1-8B-Instruct** 的有效上下文长度内保持**近乎无损**的性能。效率评测中，Adamas 在 **32K 上下文**下取得最高 **6.5×** 的自注意力加速与 **1.7×** 的端到端解码加速；在包括 **AIME 2024** 与 **AIME 2025** 在内的困难长程推理基准上，Adamas 也维持了与全注意力相当的性能。

## 🎯 核心贡献

1. **token 级精度的稀疏选择**：明确区别于固定/粗粒度策略，避免在受限预算下漏选关键 token 或保留冗余。
2. **Hadamard 变换 + 分桶 + 2-bit 压缩**的紧凑 KV 表示：以极低比特存储支持快速距离估计，显著降低 KV 显存与带宽压力。
3. **轻量距离估计做 top-k 选择**：不需要精确注意力分数即可高效定位候选位置。
4. **精确取回原始 KV**：选择阶段用紧凑近似，注意力计算阶段用**原始全精度 KV**，兼顾效率与保真度。
5. **近乎无损的长上下文表现**：在 Llama-3.1-8B-Instruct 有效上下文内性能接近全注意力，并在 AIME 2024/2025 等长程推理基准上与全注意力相当。

## 🔧 方法/架构

- **Hadamard 变换**：对 KV 向量做快速 Hadamard 变换（fast Walsh–Hadamard 风格，$O(n\log n)$），把数值分布「打散」成近似均匀分布，从而让后续**分桶量化**的误差更小、更均匀：

  ```math
  \tilde{k} = H\,k,\qquad H H^\top = n I \;\Rightarrow\; \text{能量保持、可分桶化}
  ```

- **分桶量化 + 2-bit 压缩**：在 Hadamard 域上对元素按幅值分桶，每个元素仅用 **2 bit** 表示，得到紧凑的近似 KV 表：

  ```math
  q(x) = \text{bucket}\!\left(\tilde{x}\right),\qquad \text{bits}(q) = 2 \cdot d
  ```

- **轻量距离估计**：以压缩表示上的（近似）内积/距离作为注意力相关性代理，快速完成 top-k 选择：

  ```math
  \hat{s}(q, k_i) \approx \langle \tilde{q}, q(k_i)\rangle,
  \qquad
  \mathcal{S} = \text{TopK}_{i}\big(\hat{s}(q, k_i)\big)
  ```

- **原始 KV 取回**：用选中的位置索引去**原始（未压缩）KV 缓存**取回状态并计算精确注意力：

  ```math
  o = \text{Attn}\big(q,\; \{K_i, V_i : i \in \mathcal{S}\}\big)
  ```

  这是「选择用近似、计算用精确」的关键工程取舍。

- **整体流程**：Hadamard 变换 KV → 分桶/2-bit 压缩存储 → 距离估计 top-k → gather 原始 KV → 稀疏注意力。

## 📊 实验结果

- **模型**：**Llama-3.1-8B-Instruct**（有效上下文长度内）。
- **数据集/基准**：长上下文理解与**长程推理**基准，包括 **AIME 2024**、**AIME 2025**。
- **基线**：全注意力（dense attention）以及其他稀疏注意力方法（摘要未逐一列举）。
- **结果**：
  - 在有效上下文长度内保持**近乎无损（near-lossless）**性能；
  - **32K 上下文**下：自注意力加速最高 **6.5×**，端到端解码加速最高 **1.7×**；
  - 在 AIME 2024 / AIME 2025 等长程推理基准上**与全注意力性能相当**；
  - 摘要未给出具体准确率数值。

## ⚠️ 局限性

- 「近乎无损」的界限被限定在 **Llama-3.1-8B-Instruct 的有效上下文长度**内，超出该范围（尤其百万 token 级）的表现未验证。
- 加速数字针对 **32K 上下文**测得，更短上下文下的相对收益会被固定开销稀释。
- 端到端加速（**1.7×**）明显低于自注意力加速（**6.5×**），说明瓶颈已部分转移到 MLP/采样等环节，端到端收益有限。
- Hadamard 变换 + 分桶 + 2-bit 是有损近似，在需要**精确**注意力（如注意力偏置分析、模型内部探针）的场景可能不可用。
- 仅验证单一模型与单一量化配置，对模型架构（尤其 GQA/MQA 变体）、不同 KV 维度与量化位宽的敏感性未披露。
