## 重点论文（22 篇详细精读）

### 1. **CausalCoT: Mitigating Attention Leakage via Context Isolation** (2610.31639)
- **核心**：CoT 的 rationale **不保证因果驱动答案** —— dense attention 允许直接查表 + 生成事后合理化。
- **方案**：问题分解为 **DAG 原子子问题**，每个节点在**只含直接因果父节点**的隔离上下文中求值 → 切断非父节点 attention 通路。
- **结果**：保持竞争力性能；**因果敏感度相对最强 baseline 平均 +12 pp，最高 +21 pp**；结构化依赖图支持**可预测传播的 test-time 局部修正**。
- 详见 [[2026-10-23-2610.31639-causal-chain-of-thought-mitigating-att]]

### 2. **OnQ: Recovering Reasoning under Quantization via Self-Generated Trajectories** (2610.29378)
- **核心**：QAT 用固定 response 监督 → **trajectory divergence 随 response 变长而加剧** → 低比特模型在 long-horizon reasoning 失败且**无法在 token budget 内终止**。
- **方案**：**on-policy distillation**（student 自生成 prefix，teacher 在同 prefix 监督）+ **candidate-wise Dynamic KL**（按 teacher/student 概率比**双向**加权 forward/reverse KL）。
- **结果**：Qwen3 1.7B/4B/8B @ 2/3-bit，**九基准平均最高**；**2-bit 下每个模型规模每个基准全面超越所有 baseline**，Qwen3-8B 平均 **+10.26 pp**；输出更短、truncation 与重复更少。
- 详见 [[2026-10-23-2610.29378-right-on-q-recovering-reasoning-under-qu]]

### 3. **UniGuard: Multi-View Guardrail Learning** (2610.30742)
- **核心**：guardrail 在固定接口上训练 → 同一安全案例以 conversation / agent trace / multi-agent trace 出现时失效。
- **方案**：**UniGuard-FT** — 1,000 公开安全案例 × 5 视角；0.6B 模型 + classification + **supervised contrastive** + **asymmetric confidence calibration**。
- **结果**：unseen-interface 基准（ATBench / PolicyGuardBench / DynaBench）上 **+45.12 F1**，**ECE −35.41**；0.6B 纯合成数据训练即与 Claude-Sonnet-4.5 / GPT-5.2 竞争。
- 详见 [[2026-10-23-2610.30742-unicguard-multi-view-guardrail-learning]]

### 4. **ReflectPO: Reflection-Guided Policy Optimization** (2610.30933)
- **核心**：长时程任务中**早期错误沿决策链累积**。
- **方案**：**Reflection-Guided Sampling**（用 branch differences + repeated visits 构造恢复 hint）+ **Tree-Structured Credit Assignment**（parent–child reward 差分 + recovery gain）。
- **结果**：两个长时程 tool-use benchmark 多数领域超基线、平均最佳；自偏离识别 / 错误恢复 / 持续推进三项能力均提升。
- 详见 [[2026-10-23-2610.30933-reflectpo-reflection-guided-policy-optim]]

### 5. **ULME: Predictive Coupling for Embedding + LM** (2610.30705)
- **核心**：GritLM 类模型只是"partially unified" —— 两能力共处同一权重但**从不互相监督**。
- **方案**：query 与 answer 之间插入 **learnable slots**，读出 semantic / reasoning embedding；三 loss：contrastive（锚定 doc）+ LM（生成）+ **stop-gradient predictive**（**让生成主动塑造 embedding**）。
- **结果**：Qwen2.5/Qwen3 共 8 规模 0.5B–8B，MTEB **+3.3–4.1**；**BRIGHT 与 AdvBench-IR 同时收紧**；标准精度基准与"仅生成"微调持平。
- 详见 [[2026-10-23-2610.30705-ulme-predictive-coupling-embedding-and-l]]

### 6. **How Depth Growth and Looping Shape ICL** (2610.31421)
- **核心**：depth-grown 与 looped 架构**共享"从上下文学习"的归纳偏置**。
- **发现**：更依赖 context；比 full-depth dense reference **更早习得 ICL**，即使"写入权重"可行也**保持 ICL 更强**；机制上 **depth growth 把 early induction heads 跨层传播**；消融显示对 induction-ranked heads 依赖更强。
- **实践含义**：目标若是"把能力放 context 而非烤进权重"，growth/looping 可能比 dense 更合适。
- 详见 [[2026-10-23-2610.31421-how-depth-growth-and-looping-shape-in-]]

### 7. **Mixing Matters: Evidence Position Bias Across Sequence Mixers** (2610.31135)
- **核心**：gold document 在 9 个 distractor 中移动 → 位置响应曲线。
- **发现**：**Transformer 有开头优势，state-space 没有**；但**两族都偏好末尾**；pure vs hybrid Mamba 同向但**统计不确定**；差异只出现在**能完成任务的模型**中；同架构内 corpus swap 改变总分但**曲线形状不变**；**prompt 改动可制造或几乎消除开头优势**。
- **作者立场克制**：**未隔离出序列混合器是唯一成因**。
- 详见 [[2026-10-23-2610.31135-mixing-matters-evidence-position-bias]]

### 8. **DIAL: Steerable LMs with Distilled Instruction-Adherence Levels** (2610.31438)
- **核心**：**"keep it short"到底多短** —— prompting 无法提供细粒度数值控制。
- **方案**：**CFG + frozen LLM** 生成不同遵从等级的 on-policy 信号 → **轻量 steering adapter**（hidden state 分类器 → **闭式 steering edit**，逐 token 自适应幅度，考虑 hidden state 几何）→ **text-conditioned** 故共享 adapter 支持新指令。
- **数据集**：**SteerIF**，instruction-only，**98,625** 条。
- **结果**：concept 与 fluency 平衡竞争性；**concept score 随 adherence level 单调上升**；组合 prompting 提升 verifiable instruction following。
- 详见 [[2026-10-23-2610.31438-dial-steerable-language-models-with-disti]]

### 9. **Questioning Instrumental Convergence in RLVR (OLMo-3)** (2610.31624)
- **核心**：把"RLVR 是否诱发权力寻求"当作**checkpoint-conditioned 行为轨迹**而非单一 before/after 分数。
- **关键数据**：OLMo-3-7B-Think，SFT **25.0%** → RLVR step ~200 **46.1%** → final **11.8%**。**非单调，先升后降，最终低于 SFT**。32B 初步同向：35.53% → 22.37%。
- **混杂控制**：prompt framing 仅解释 within-checkpoint 方差 **15%**；**INLP** 移除 framing 方向后主结论不变。
- **注意**：论文明确结论限于该模型族与 benchmark，judge agreement 仅中等。

### 10. **Faithful Latent Harm Monitors Work No Better Than the Model's Own Behaviour** (2610.30727)
- **核心**：直接检验 Latent Guard 类方法的"忠实性"。
- **设计**：15 个 instruction-tuned LLM × 38 个 activation reader；OOD 改写（rewording / persuasive framing / jailbreak wrapper）；两个读取位置（instruction 末 / reply 前）。
- **关键数据**：

  - reply 前：**44%** 有害 prompt 检出 vs 模型自身 refusal **32%**（matched FAR），但**增益跟随 refusal 决策本身**。
- 详见 [[2026-10-23-2610.30727-faithful-latent-harm-monitors-work-no]]

### 11. **One Teacher, Many Views (MCPD)** (2610.30880)
- **核心**：**reference-induced target instability** —— 固定 problem 与 student state，仅替换一个有效参考即可显著改变 teacher 分布。
- **方案**：把特权上下文建模为 **partial reference views 的分布**，在多 view 下评估 teacher 并**平均 next-token 分布**。
- **理论**：该概率空间平均**恰为**"在特权 view 上最小化期望 teacher→student KL"诱导的**精确目标**。
- **结果**：数学与科学推理 benchmark 上产生**更 reference-consistent 的监督**，**一致优于** full-reference OPSD。
- 详见 [[2026-10-23-2610.30880-one-teacher-many-views-reducing-refer]]

### 12. **Cola2: Co-Adaptive Hierarchical LM** (2610.31305)
- **核心**：分层语言生成 = 连续语义建模 + 离散文本实现；关键是**压缩什么** 与 **离散生成器怎么用**。
- **方案**：动态 semantic span 分段 + **aux-loss-free 负反馈**控制压缩率 + **block-causal masked diffusion decoder**（clean/noisy/dropped 三种 latent 条件）+ CFG 调节重建 vs 生成 + token 梯度经 latent 回传 encoder、**Flow Matching prior 用 stop-gradient 解耦** + 推理时按固定 span layout 重编码。
- **结果**：约 210B token 验证核心设计；**346.03B source token 的未收敛 checkpoint 八任务平均 60.10**，**HellaSwag / StoryCloze 超 Llama-3-8B**（后者预算为其 1/43）；scaling **未饱和**。
- 详见 [[2026-10-23-2610.31305-cola2-co-adaptive-hierarchical-language-mod]]

### 13. **MAPS: Macro-Adaptive Parallel Reasoning for RAG** (2610.29792)
- **核心**：提出 **search momentum** —— 历史 sub-query 变化在推理轨迹上积累的检索趋势；分析发现**query 生成沿既有检索轨迹持续演化**（→ query-intent drift）。
- **方案**：Macro 层保留知识 + 精炼 reasoning state 抑制惯性；Parallel 层识别**互补检索方向**、并行生成 sub-query 与并行检索，再整合证据更新双状态。
- **结果**：6 个 QA benchmark、跨 backbone **一致优于**代表性 RAG 方法。代码：[GitHub](https://github.com/NEUIR/MAPS)
- 详见 [[2026-10-23-2610.29792-maps-macro-adaptive-parallel-reasoning]]

### 14. **Memory-Aware Reward Modeling** (2610.31272)
- **核心**：**知道用户更多 ≠ 产出用户更喜欢的回答**。
- **数据**：87 名参与者用**自己的 ChatGPT 查询与个人记忆**做 ~1,000 条 pairwise 判断。
- **关键发现**：
  - **memory-conditioned 回答并不一致优于** no-memory 回答，**某些情况用户强烈偏好后者**；
  - **自动评估器与用户一致度有限**，且**远多于用户**的频率偏好 memory-conditioned → **系统性偏差**。
- **方案**：memory-aware reward model，**72.8%** 偏好预测准确率，超越现有 baseline。
- 详见 [[2026-10-23-2610.31272-memory-aware-reward-modeling-learning-hu]]

### 15. **Diagnosing the Explicit-to-Applied Theory of Mind Gap** (2610.31060)
- **核心**：聚合 ToM 分数混淆**显式 ToM**（识别信念）与**应用型 ToM**（用信念预测行为）。
- **震撼数字**：SimpleToM 上 Llama-3.1-8B 总分 **51.5%**，但**识别心理状态 99.4%** / **预测行为仅 28.9%**。
- **恢复性对比**：structured prompting / matched ICL / **BSTTT**（ Belief-State Test-Time Training，action reconstruction）。结果：reminders + BSTTT 令 Llama 行为预测 **+40.8 pp**，但 **reminders 贡献绝大部分**，BSTTT 只额外 **1.3–5.5 pp**；**contextual examples 常优于权重更新**；时序信念追踪仍困难。
- **建议**：**分开报告 explicit / applied 准确率**。
- 详见 [[2026-10-23-2610.31060-diagnosing-the-explicit-to-applied-theory-of]]

### 16. **Certified Execution Harness (Petri-Net Supervisory Control)** (2610.31376)
- **核心**：用 **Petri 网**把 LLM 与工具之间的执行 harness 形式化为 **supervisory control** 问题。
- **关键设计**：**marks** 表示能力 / 审批 / 预算；**transition 只在所需 marks 齐备时触发** → **措辞无关的拒绝**（注入请求无论怎么说都会被拒）。
- **理论**：tool outcome 视为不可控 → maximally permissive supervisor，在**四个假设**下安全迁移到运行系统；引入 **replanning closed loop**（被拒后重试，每次耗一次 inference）→ 传统监督器可能**比更严格的安全监督器更具侵入性**；最少侵入版本 = **value-threshold refinement**，排序两个并发动作**至多差一个 monitor place**。
- **实证**：autonomous release agent 上 synthesis 发现**安全部署需要监督器能在 rollout 启动后仍可否决的步骤**。
- 详见 [[2026-10-23-2610.31376-certified-execution-harness-for-agentic]]

### 17. **GIFT: Gradient Informed Filtering** (2610.30796)
- **核心**：密集蒸馏监督与稀疏 outcome RL **互补但可能冲突**。
- **方案**：**token 级梯度几何分解** —— 平行分量（度量一阶冲突 → safety filter）+ 正交分量（量化新颖指导 → value）→ 有原则的 token 级排序规则 + **coverage annealing**（渐进收缩蒸馏 token 预算，冲突最大的先丢、互补最强的留满强度）→ 从 dense-filtered guidance 平滑过渡到纯 outcome 目标。
- **结果**：数学与逻辑推理 benchmark、多个规模**一致优于强 baseline**；困难数学推理相对增益最高 **9.5%**。代码：[GitHub](https://github.com/lilifree/GIFT)
- 详见 [[2026-10-23-2610.30796-gift-gradient-informed-filtering-for-disti]]

### 18. **Verbalizing Activation Differences with NLAs** (2610.30934)
- **核心**：系统评估 **natural language autoencoders** 的泛化性（四问全为 largely positive）。
- **发现**：
  - composed analogy 的 verbalization **大多命名目标，很少提及被减去的词**；
  - NLA 可**直接复用于**其原模型的轻量微调版本，无需重训（最大模型除外）；
  - **Taboo model organisms**：对原模型 vs 微调模型的激活差异 verbalization → **大多恢复隐藏的秘密词**；激活差异上做 **RL** 在 held-out organism 上进一步提升；
  - **无需微调模型生成任何 token** —— 信息量最大的位置在 **user prompt 之前**；
  - 局限：emergent misalignment detection 上**未及 SOTA**，但优于 blackbox。

### 19. **Tracing Subliminal Learning Through Pretraining** (2610.30884)
- **核心**：模型从他人生成数据中继承**与数据无关的特质**。
- **设定**：hard-label vs **on-policy soft-label** 蒸馏。
- **发现**：
  - 传递在两种设定下**都存在**，且对 weight init / data order / corpus / model size / architecture 差异**稳健**；
  - **教师与学生角色不对称** —— 好教师 ≠ 好学生，角色互换时幅度强烈不对称；
  - **合成频率序列**（匹配教师数字频率，但不依赖 prompt 与前序数字）在 hard-label 下**仍诱导大量传递** → 偏好信号在**分布统计层**而非内容逻辑层；
  - top-K soft-label 中移除 animal token **减少**（但不完全消除）传递；
  - **soft-label 传递更一致、所需训练量更少**。
- 详见 [[2026-10-23-2610.30884-tracing-subliminal-learning-through-pretr]]

### 20. **Every Part Has Its Role: Part-of-Speech Effects in Post-Training** (2610.29843)
- **核心**：概念增强中**承载概念信号的词性**是否影响效果。
- **发现**：**困惑度**在 news 上一致改善且**与词性无关**；**下游性能由动词提供最可靠收益**；**表征分析（CKA / linear probing）显示下游最优条件 ≠ 表征改变最大条件**。
- **实践含义**：用下游指标评估增强方案，**不要用探针做代理**；替换目标优先选**动词**。
- 详见 [[2026-10-23-2610.29843-every-part-has-its-role-part-of-speech-eff]]

### 21. **Route-and-Generate (Rouge): KL-Regularized Router** (2610.30351)
- **核心**：LLM 无差别应用复杂推理 → 简单题 **overthinking**、难题 **underthinking**。
- **方案**：路由策略在多推理格式间**分配固定采样预算** + base model 用 **GRPO + per-sample reward** + **rank-based reward**（偏好更短的正确解）+ **KL 正则化策略改进**把路由策略**蒸馏进神经 router**。
- **结果**：多个推理基准上 **accuracy–efficiency trade-off 改善**。
- 详见 [[2026-10-23-2610.30351-route-and-generate-kl-regularized-router-i]]

### 22. **SGUR: Structure-Grounded Uncertainty Reduction** (2610.30611)
- **核心**：agentic 系统常产生**语义合理但结构未接地**的推理，尤其在观测不完整时。
- **方案**：不完整观测 → **query graph** → **先验加权的部分图匹配**对齐候选假设图（数据库经验先验强调决策相关关系）→ **主动信息增益**策略选下一个最具信息量的节点查询，迭代剪枝候选空间。**training-free**。
- **结果**：PrimeKG 序贯医疗诊断，**仅 2 个症状 → 92.5% Hit@3**，比最强 Graph-RAG **+9.4 pp**，**token 少约 5×**；**小 backbone 可匹配或超越大 10× 的模型**。
- 详见 [[2026-10-23-2610.30611-better-reasoning-not-just-bigger-models-a]]
