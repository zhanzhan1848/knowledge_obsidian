## 核心贡献

> rTaste 用 415 个 MVE 检验研究 agent 的品味：能产出价值实验，但排序能力未证明优于「最先写下的那个实验」。

1. 提出 rTaste：给 6 个前沿模型 7 篇近期 NLP 论文，让它们以单 agent 或团队形式作为研究 agent 提出最小可行实验（MVEs）、预测各自能否通过自设阈值并排序。
2. 由独立执行者实际执行**每一个** MVE（含排名最后的），再由 3 个模型审计结果 —— 保证「被否定的想法」也得到公允检验。
3. 在 415 个 MVE 中，194 个被判定为合理、有价值且新颖，但其中不足一半（73 个）同时超出种子论文且非显而易见；agent 的首选比随机选择更常命中审计者最看重的实验，但**未证明优于「先写下的那个实验」**。

## 技术方案

### 核心思想

这篇论文问的是研究 agent 最核心也最难测的一个能力：**品味（taste）** —— 在实验结果尚未知时，判断哪些实验值得做。

实验设计相当严谨：
1. 6 个前沿模型，7 篇近期 NLP 论文
2. 每个模型单独作为研究 agent，或组成团队，**提出 MVE（minimum viable experiments）**、**预测**每个 MVE 能否通过**它自己设定的阈值**、并**排序**
3. 由一个**独立的执行者**实际执行每一个 MVE —— 包括排名最后的。这一点很关键，它排除了「只跑被选中的实验」带来的选择偏差
4. 由 3 个模型审计执行结果

结果的诚实程度值得称道，作者没有粉饰：

- 415 个 MVE 中，**194 个（47%）**被判为「合理、有价值且新颖」—— 尚可
- 但其中**只有 73 个（不到一半）**同时做到「超出种子论文」且「非显而易见」—— 真正的创新很少
- agent 的首选**比随机选择更常命中**审计者最看重的实验 —— 有点品味
- 但**未能证明优于「选择最先写下的那个实验」** —— 这个基线很朴素，却没有被击败
- agent 的预测优于基准率，但**不比「给同一模型只看论文和注册表的一个新实例」更准** —— 意味着预测能力不来自 agent 的角色设定
- **团队模式的成本更高，但提议质量没有明确提升**

结论是克制的：agent 能产出不少有价值的实验，但「其排序能改善该跑哪个实验」的证据仍然有限。

论文公开了评测 harness 与全部 415 个 MVE 的数据集（含预测与审计结果）。

### 关键技术

| 技术 | 说明 |
|------|------|
| MVE 提议 + 自设阈值预测 | agent 需同时提出实验、设定通过阈值并预测结果，形成自洽的预测记录 |
| 独立执行者全覆盖 | 执行所有 MVE（含排名最后的），消除选择偏差 |
| 三模型审计 | 对执行结果做合理 / 有价值 / 新颖 / 超种子 / 非显然五维判定 |
| 强基线设计 | 「最先写下的实验」与「同模型新实例」两个朴素基线的引入，是本文的关键 |
| 公开评测 harness 与数据集 | 415 个 MVE 及其预测与审计结果全部开源 |

## 实验结论

- **数据集**: 7 篇近期 NLP 论文，415 个由 6 个前沿模型提出的 MVE
- **基线**: 随机选择、「最先写下的实验」、给同一模型只看论文与注册表的新实例、团队模式 vs 单 agent
- **结果**: 194 个 MVE 被判为合理、有价值且新颖，其中仅 73 个同时超种子论文且非显而易见。首选命中审计者最看重实验的频率高于随机，但未优于「最先写下的那个实验」。预测优于基准率，但不比同模型新实例更准。团队成本更高而提议质量无明确提升。

- **「最先写下的实验」这个基线没有被击败**，是全文最尖锐也最有价值的观察 —— 它把 agent 的价值主张拉回到一个很朴素的标准上。
- **「同模型新实例」基线**同样关键：说明 agent 角色的价值可能不在于「是个 agent」，而在于别的（更多上下文？更多算力？）。
- **194/415 → 73/194** 的两级漏斗说明 agent 提议的「有价值」与「真有洞见」之间差距巨大。
- 执行全部 MVE（含排名最后）这个设计，堵住了「只验证成功案例」的常见漏洞。
- 团队模式成本更高但质量无提升 —— 对「多 agent 一定更好」的假设是一个反例。

## 局限性

['6 个模型 × 7 篇论文的规模有限，结论的统计效力受限。', '「非显而易见」与「超出种子论文」的判定由模型审计，虽有三模型但仍是自动判定。', '论文给出的是否定性/限定性结论，未提出改进 agent 研究品味的方法。', '7 篇 NLP 论文的领域范围窄，外推到其他学科待验证。']

## 实现建议

- **实现难度**: 中（需 MVE 提出—预测—执行—审计的完整 harness）
- **适用场景**: 研究 agent 评测、AI 辅助科研的品味评估、实验选择自动化、LLM 科研能力审计
- **建议**: **评估研究 agent 时，「最先写下的实验」和「同模型新实例」是两个必须报告的基线** —— 本文显示它们没有被击败。同时务必执行所有候选（包括被排序否掉的），否则会高估 agent 的判断力。

## 原始摘要

```
Do research agents have taste, the judgment of which experiments are worth running before their outcomes are known? We give six frontier models seven recent NLP papers. Each model, working as a research agent alone or as a team, proposes minimum viable experiments (MVEs), forecasts whether each will pass a threshold it sets and ranks them. A separate executor then attempts every MVE, including those ranked last, and three model auditors judge the results. Of 415 MVEs, 194 are judged sound, valuable and new, but fewer than half of these (73) are also judged beyond the seed paper and non obvious. The agents' first choices match the auditors' most valued experiment more often than a random pick, but are not shown to improve on choosing the experiment written first. Their forecasts beat a base rate but are not measurably more accurate than those of a fresh instance of the same model given only the paper and registrations. Teams cost more without a clear overall improvement in proposal quality. The agents produce many worthwhile experiments, but the evidence that their rankings improve the choice of which to run remains limited. The evaluation harness and a dataset of all 415 MVEs, with their forecasts and audited outcomes, are available at https://github.com/ArtKanke/rTaste.
```
