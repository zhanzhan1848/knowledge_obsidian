# Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention

> **arXiv**: [2605.22791](https://arxiv.org/abs/2605.22791)
> **发表日期**: 2026-05-21
> **分类**: cs.AI
> **会议/期刊**: NeurIPS 2026 (Accepted)

## 📋 摘要

线性注意力用**固定大小的循环状态**替代 softmax 注意力的无界 cache，把序列混合降为**线性时间**、解码降为**常量内存**。难点不只是"忘掉什么"，而是**如何在不扰乱既有联想的前提下编辑这份压缩记忆**。Delta-rule 模型在写入新值前先减去当前读取量；**Kimi Delta Attention (KDA)** 用**通道级衰减（channel-wise decay）**强化遗忘。但活跃编辑仍用**单一标量门**同时控制两件不同的事：**在 key 侧擦除多少旧内容**、以及**在 value 侧提交多少新内容**。本文提出 **Gated DeltaNet-2**，在继承自适应遗忘与通道级衰减的同时解决这一共同局限——**擦除与写入的标量绑定**。**Gated Delta Rule-2** 用**通道级擦除门 $b_t$** 与**通道级写入门 $w_t$** 分离这两个角色：当两门退化为同一标量时回到 **KDA**，当衰减也退化时回到 **Gated DeltaNet**。作者推导了**快速权重更新视角（fast-weight update view）**、**带通道级衰减并入非对称擦除因子的 chunkwise WY 算法**，以及**保持并行训练效率的门感知反向传播（gate-aware backward pass）**。在 **1.3B 参数、100B FineWeb-Edu tokens** 训练下，Gated DeltaNet-2 在语言建模、常识推理与检索任务上取得 **Mamba-2、Gated DeltaNet、KDA、Mamba-3** 各变体中的**最强综合结果**。其优势在长上下文 **RULER needle-in-a-haystack** 基准上最明显，在所评估的多 key 检索设定上有所改进，并在**纯循环**与**混合（hybrid）**两种设定下均保持强劲。代码见 https://github.com/NVlabs/GatedDeltaNet-2 。

## 🎯 核心贡献

1. **问题诊断：擦除-写入标量绑定**。指出现有 Delta-rule 系列（Gated DeltaNet、KDA）用**一个标量门**同时控制 key 侧擦除量与 value 侧写入量，限制了表达力——这是本文的核心洞见。
2. **双门解耦设计**：引入**通道级擦除门 $b_t$** 与**通道级写入门 $w_t$**，把"忘掉旧内容"与"写入新内容"分配到独立的通道级自由度。
3. **统一与归约性质**：证明该设计**同时推广 Gated DeltaNet 与 KDA**——两门坍缩为同一标量时退化为 KDA，衰减再坍缩时退化为 Gated DeltaNet，形成清晰的能力谱系。
4. **高效算法栈**：
   - **fast-weight update 视角**；
   - **chunkwise WY 算法**（把通道级衰减吸收进**非对称擦除因子**）；
   - **门感知反向传播**（gate-aware backward pass），保持高效并行训练。
5. **实证最优**：1.3B/100B FineWeb-Edu 规模下，在语言建模、常识推理、检索上全面领先 Mamba-2/Gated DeltaNet/KDA/Mamba-3，**长上下文 RULER 多 key 检索**上优势最明显，循环与混合两种架构下均有效。

## 🔧 方法/架构

- **线性注意力基座**：以固定大小循环状态 $\mathbf{S}_t$ 替代 KV cache，序列混合 $O(T)$、解码内存 $O(1)$。
- **Delta Rule 机制**：写入前先"减去当前读取量"（$\mathbf{S}_t \leftarrow \mathbf{S}_{t-1} + (\mathbf{v}_t - \mathbf{S}_{t-1}\mathbf{k}_t)\mathbf{k}_t^\top$ 形式），实现精确的关联覆盖而非简单累加。
- **通道级衰减**：KDA 引入逐通道遗忘强度，本文保留该特性。
- **Gated Delta Rule-2（本文核心）**：
  - **擦除门** $b_t \in \mathbb{R}^{d}$：控制 key 侧擦除多少旧内容；
  - **写入门** $w_t \in \mathbb{R}^{d}$：控制 value 侧提交多少新内容；
  - 两者**独立**，各为通道级（channel-wise）向量。
- **归约关系**：
  - $b_t = w_t = b \cdot \mathbf{1}$ → 退化为 **KDA**；
  - 再加上衰减 $\alpha_t \to 1$（无衰减）→ 退化为 **Gated DeltaNet**。
- **fast-weight update 视角**：把循环状态视为一组快速权重，编辑操作即快速权重写入，可分析其稳定性与容量。
- **chunkwise WY 算法**：并行化的 WY 表示分块算法，**把通道级衰减吸收进非对称擦除因子**，从而在不牺牲并行度的情况下支持通道级门。
- **门感知反向传播**：为含门变量的状态更新推导可并行的高效反向传播，保证训练吞吐。

```math
\mathbf{S}_t = \mathbf{S}_{t-1}\bigl(I - \beta_t \mathbf{k}_t \mathbf{k}_t^\top\bigr) + \beta_t\,\mathbf{w}_t\,\mathbf{v}_t^\top
\quad\text{with}\quad
\beta_t = b_t \odot w_t \ \ (\text{erase} \times \text{write}),\ \ b_t,w_t \in \mathbb{R}^{d}
```

## 📊 实验结果

- **训练规模**：**1.3B 参数**，**100B FineWeb-Edu tokens**。
- **对比基线**：**Mamba-2**、**Gated DeltaNet**、**KDA**（Kimi Delta Attention）、**Mamba-3** 的各变体。
- **评测任务**：语言建模、常识推理、检索。
- **结果**：
  - 在上述任务上取得各变体中的**最强综合结果**；
  - 优势在长上下文 **RULER needle-in-a-haystack** 上**最明显**，在所评估的**多 key 检索**设定上有所改进；
  - 在**纯循环（recurrent）**与**混合（hybrid）**两种架构设定下均保持强劲。
- 摘要**未给出**具体分数（PPL、Accuracy 等绝对值）、模型结构超参、训练时长与吞吐/显存数字。
- **代码**：https://github.com/NVlabs/GatedDeltaNet-2

## ⚠️ 局限性

- **通道级双门的参数与计算开销**：两个通道级向量门增加了参数与 kernel 复杂度；摘要**未给出**相对 Gated DeltaNet 的参数增量、FLOPs 与实际吞吐对比（这一点对"效率"叙事很关键）。
- **线性注意力的固有短板**：固定大小状态对**精确 recall / 长上下文随机存取**的容量上限仍受限；RULER 优势主要体现在多 key 检索设定，不等于解决了所有长程推理问题。
- **训练规模有限**：1.3B/100B tokens 远小于主流 LLM 规模，**更大规模下双门是否仍带来增益未验证**；也未报告 scaling 趋势。
- **摘要未给出具体数值**：所有结论均为定性描述（"最强综合结果"），缺少 PPL/准确率表格与显著性判断。
- **未与 softmax attention + 各类压缩方案直接对比**（如本批次其他论文的 KV 压缩路线），横向定位不足。
- 未讨论与 **KDA 在 Kimi 实际系统**中的差异，也未说明实现中的数值稳定性处理（如门值饱和、状态范数控制）。

## 💡 建议

- 是否推荐使用：**是**（作为长上下文架构选型与线性注意力变体研究的重要参考，尤其关注 RULER 类长程检索）
- 适用场景：需要**常量内存解码 + 线性序列混合**的长上下文/流式场景（边缘设备、超长文档、流式 agent），以及把 Mamba/DeltaNet 系列作为 backbone 的团队。若在 Blackwell 等有原生 FP4/FlashAttention 硬件上做训练与推理，可与 KV 压缩路线组合评估。落地建议：先在自身数据上验证双门相对 Gated DeltaNet 的净收益，并实测 kernel 开销。
