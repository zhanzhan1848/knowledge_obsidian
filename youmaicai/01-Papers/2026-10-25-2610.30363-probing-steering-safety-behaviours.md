## 核心贡献

> 在**单一 pipeline、单一模型**内系统地交叉"探针估计器 × token 池化方式 × 层选择"，并对每个方向**同时**做检测与引导两种评测 —— 结论是：先前工作读出来的"read/write 解离"假说**只在 deception 与 high-stakes awareness 上成立，在 sycophancy 上完全反转**。

1. **统一的交叉实验设计**：pipeline 交叉 **2 个估计器**（difference-of-means、logistic regression）× **3 种 token 池化**（last、mean、learned attention），并在每个行为上挑选适合**检测**或**引导**的层
2. **每个方向被评测两次**：既作为该行为的**检测器（detector）**，也作为**引导向量（steering vector）**把输出推向该行为 —— 这是本文方法论上最关键的设计
3. **发现并部分推翻"read/write 解离"**：先前工作综合读出的结论是"logistic regression 擅长读（检测），difference-of-means 擅长写（引导）"。本文发现该模式**对 deception 与 high-stakes awareness 成立**，但**对 sycophancy 模式反转**
4. **反转部分来自数据而非估计器**（"appears to follow partially from the data rather than from the estimators"）—— 作者诚实地把归因留有余地
5. **层选择的行为依赖性**：最佳池化方式与层选择**依赖行为与数据**；**引导效果最佳的层可能远早于检测效果最佳的层**
6. **度量选择依赖任务**：要在"改变模型感知"与"引发行为"之间选对 steering metric，**取决于任务**，且两者**可能完全相反**
7. **开源**：导出全部 probe 与方向，并提供一个**交互界面**，用户可直接对文本打分与引导

## 技术方案

### 核心思想

探针方向（probe direction）是一段 residual stream 中的向量，用途有二：

```
detect  : d · h(x)  →  score   （该文本是否表现出该行为）
steer   : h'(x) = h(x) + α · d （把输出推向他是否定的方向）
```

本文的核心方法论贡献是：**不要假设"检测好的方向就引导得好"**，二者必须分开评。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Difference-of-means** | 估计器 1：在正/负样本激活均值上取差向量 |
| **Logistic regression** | 估计器 2：监督式线性分类器权重 |
| **Token pooling: last** | 取序列最后一个 token 的激活 |
| **Token pooling: mean** | 对序列 token 激活取平均 |
| **Token pooling: learned attention** | 学习一个注意力池化权重 |
| **Read/write 双评测** | 同一向量既评检测 AUROC，又评引导后的行为改变 |
| **Layer selection** | 针对"检测"与"引导"分别选层（两者可能不同） |
| **Interactive interface** | 导出 probe 与方向后提供界面，让用户对**文本**直接打分与引导 |

## 关键实验结果

### 核心发现

| 发现 | 细节 |
|------|------|
| **Read/write 解离** | logistic regression **读**（检测）最佳，difference-of-means **写**（引导）最佳 —— **对 deception 与 high-stakes awareness 成立** |
| **模式反转** | 在 **sycophancy** 上该模式**完全反转**（即 difference-of-means 检测更好、logistic regression 引导更好） |
| **归因保留** | 反转"部分源于数据而非估计器" —— 作者未把它归因到算法本身 |
| **层选择行为依赖** | 最佳池化方式与层选择**依赖行为和数据**；**引导最佳层可显著早于检测最佳层** |
| **度量选择依赖任务** | "改变模型对情境的**感知**"与"**引发**该行为"是两种不同指标，选哪个**取决于任务**，且**两者可能相互矛盾** |

## 关键结论 / 局限性

### 关键结论

1. **"检测器"与"引导器"不是同一个问题的解**：如果你的应用是检测，用 logistic regression；如果你的应用是干预生成，用 difference-of-means —— 至少在 deception / high-stakes 这两个行为上如此
2. **sycophancy 是特例**：这个反转提示**不能把在欺骗/风险行为上的结论外推到谄媚** —— 而谄媚恰是现实对齐中最关心的行为之一
3. **层不是"一个"选择**：同一行为至少有**两个**最优层（检测层、引导层），单层探针会浪费一半信息

### 局限性

- **单模型**：全部结论建立在 **Llama-3.1-8B-Instruct** 一个模型上；跨模型家族（如 Qwen、Claude、GPT 系）的可迁移性**未验证** —— 这也是全篇最大的约束，因为 2026-10-25 的 2610.30678 已经证明**探针性能本身存在模型规模律**
- **行为覆盖窄**：仅 3 种行为，且每种行为的具体数据集未在摘要中给出
- **"部分源于数据"的归因留白**：作者自己没把 sycophancy 反转讲清楚 —— 读者不能断定这是普适规律还是数据构造的偶然
- **steering 副作用未在摘要中量化**：注入方向后是否损伤语言质量、事实性、格式遵循 —— 摘要未报告
- **交互界面**便于教学与探索，但不构成科学结论
- 代码与数据已开源（GitHub），这是本文相对多数可解释性论文的明显优势
