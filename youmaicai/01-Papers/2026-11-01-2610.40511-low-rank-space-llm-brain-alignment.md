# A Low-Rank Space Captures Linear Alignment Between LLM and Human Neural Activity During Naturalistic Language Listening

## 摘要
LLM 越来越多地被用作人类语言处理的计算模型，但究竟是其表示中的哪些成分驱动了与神经活动的对齐仍不清楚。本文用 ridge reduced-rank regression（RRR）识别 LLM 表示中的**脑预测子空间**（brain-predictive subspace）——即支撑对神经响应做线性预测的表示方向。在三个自然语言听音数据集（涵盖颅内电生理与 fMRI）与六种模型条件（自回归、双向 masked、随机初始化）上，作者发现**仅用原始 embedding 维度的 1–3%** 即可恢复完整的线性编码性能。这些低维子空间能跨 held-out 被试泛化，在较小程度上跨数据集泛化，表明神经可预测性集中在一个紧凑且部分共享的表示空间中。随后作者将脑预测方向与 embedding 主变化轴比较：PCA 需要明显更多的维度才能恢复神经预测，说明对预测神经活动最有用的方向与捕获 embedding 自身最大方差的那些方向不同。最后，对所学子空间的刻画让作者能识别出在神经活动相对于 LLM 表示被过度表征的可解释特征。这些结果共同表明 LLM–脑的对齐由模型表示中一个小而结构化的子集支撑，并提供了一套理解"为何这些表示会对齐"的框架。代码见 https://github.com/thefinnlab/low-rank-alignment。

## 核心贡献
1. **脑预测子空间的概念化**：把"LLM–脑对齐"从单一编码分数转化为一个**可被独立研究的表示对象**——支撑神经预测的表示方向集合。
2. **低秩发现**：在三个数据集、六个模型条件的全部 model–layer 组合上，仅用原始 embedding 维度的 **1–3%** 即可恢复完整线性编码性能；RRR 饱和秩通常只有**几十维**（Podcast 数据集平均为 **20**），而 PCA 一般需要**数百维**。
3. **RRR vs PCA 的表示几何对比**：证明脑预测方向**不等同于** embedding 的主方差轴；低秩 RRR 甚至常**超过** full-space ridge 基线，而 PCA 降维无此现象。
4. **泛化性分析**：leave-one-subject-out 显示子空间可跨被试迁移；跨数据集迁移部分成功，并用"stimulus-induced PCA shift"作为对照来分解迁移损失。
5. **可解释特征解码**：展示子空间富集了不同数据集/模态偏重的语言学信息。

## 方法与架构
**核心视角**：作者把 LLM–脑对齐看作"LLM embedding 空间与神经响应空间共享信息"的度量，目标是选择性提取两个空间的交集（Fig. 1a）。

**数据集**：
- **Podcast ECoG**（Zada et al. 2025）：9 名被试、1,330 个颅内电极，30 分钟叙事 podcast，高伽马（70–200 Hz）。
- **Brain Treebank**（Wang et al. 2024）：sEEG 记录，看电影；作者分析 **Cars 2**（听到的词最多，约 8,000），至少 3 名被试观看；用了 subject 3、7、10。
- **Deep fMRI**（LeBel et al. 2023）：5 次记录会话的 spoken stories；作者分析 **8 名被试**，在重复的 held-out test story 上评估编码模型。

**预处理**：Podcast 使用发布的高伽马响应；Brain Treebank 自行提取 70–200 Hz 高伽马（重采样 2,048→512 Hz、去尖峰、100 ms artifact mask、三次 Hermite 插值、shaft-Laplacian rereferencing、60/120/180 Hz notch、四阶 Butterworth 70–200 Hz 带通、Hilbert 变换取解析信号幅度）。两个颅内数据集均对齐到词 onset 并采样到 **32 Hz**；epoch 覆盖 $[-2, 2)$ 秒，每 epoch FFT 重采样到 32 Hz，得 128 samples/contact（31.25 ms 间隔）。fMRI 使用发布的预处理响应。

**模型（6 个条件）**：四个自回归——GPT-2、GPT-2 XL、GPT-J 6B、Llama 3 8B；一个双向 masked——RoBERTa Large；控制——**随机初始化的 GPT-2**（seed 42）与**非上下文的 300 维 GloVe** embedding。每个上下文模型抽 5 层：GPT-2 为 0/3/6/9/12，GPT-2 XL 为 0/12/24/36/48，GPT-J 为 0/7/14/21/28，Llama 3 为 0/8/16/24/32，RoBERTa 为 0/6/12/18/24（layer 0 为 embedding-stage hidden state）。词表示由该词所有 subword token 的 hidden state 平均得到。

**神经目标选择**：先用 full-embedding ridge 模型的 held-out 预测做筛选；iEEG 用 5 个连续 word folds、best-lag 相关、circular shift 生成 null、BH 校正跨电极；选中的电极其**全部 sampled lags** 作为独立 RRR target。fMRI 用留出完整 session 的模型，重复 test story 排除于选择之外。最终 target 数（union，Tab. 1）：Podcast **1,200** 个电极、Cars 2 **439** 个电极、fMRI **618,587** 个 voxel。

**编码模型**：先用全 embedding 空间拟合 ridge 得到参考性能。iEEG 中词 embedding 预测相对词 onset 的 sampled lags 的电极响应，用 5 个连续 held-out word folds 评估；fMRI 中 embedding 对齐到采集时间并构造四延迟 FIR design，在 held-out stories 上评估。Ridge 惩罚由交叉验证选择。

**Reduced-Rank Regression（RRR）**：在每个训练划分内拟合从 embedding $X$ 到神经响应 $Y$ 的多元 ridge 模型（系数 $W$，拟合响应 $\hat{Y}=XW$），对 $\hat{Y}$ 做分解，取其前 $k$ 个右奇异向量 $V_k$ 构造输入因子
```math
A_k = W V_k
```
其列张成与预测神经活动主成分相关的 embedding 方向。在每个 rank $k$ 处把 embedding 正交投影到该子空间，用投影后的数据**重新拟合一个新的 ridge 编码模型**。rank 从 1 扫到可用 embedding 维度端点，性能在 held-out 神经响应上评估，full-embedding ridge 模型作为参考。fMRI 中把各 delay 的 RRR 因子在原始 embedding 坐标下合成单一正交基。**PCA 对照**：对训练 embedding 做 PCA，每个 rank 处投影到前若干主成分，用同样的 ridge 重拟合与 held-out 数据评估。

**饱和秩（saturation rank）**：在每个 rank 处计算 held-out target 性能的 10/25/50/75/90 百分位并沿 rank sweep 追踪；饱和秩定义为**所有有信息的分位数曲线都达到各自最大性能的 99%** 时的最小 rank；最大性能不超过 0.005 的分位数被排除。

**泛化分析**：(a) leave-one-subject-out——在其余被试上学 RRR 子空间，迁移到 held-out 被试，只用该被试的神经响应拟合新的编码模型；(b) 跨数据集迁移——从源数据集学 RRR 或 PCA 子空间，把目标数据集的 embedding 投影进去，再只用目标数据集的神经响应拟合新 ridge 模型。**两种情形下只迁移 embedding 子空间，子空间到神经活动的映射在目标端单独估计。**

**语言特征解码**：对刺激词标注 lexical、syntactic、semantic、discourse、timing、pause 类特征；在每个 rank 处把 embedding 投影到 RRR 与 PCA 空间，分别训练 held-out decoder；连续特征用 Pearson 相关，类别特征用 balanced accuracy。

## 实验设置
- **数据规模**：Podcast 9 被试 / 1,330 电极 / 30 min；Cars 2 三名被试；Deep fMRI 8 被试 / 5 session。
- **模型条件**：GPT-2、GPT-2 XL、GPT-J 6B、Llama 3 8B、RoBERTa Large + 随机初始化 GPT-2（seed 42）+ GloVe-300，共 6–7 个条件，每模型 5 层。
- **指标**：held-out 预测相关（Fisher-z 平均）、AUC（跨数据集迁移效率）、Pearson 相关与 balanced accuracy（特征解码）、饱和秩。
- **验证**：circular-shift null + Benjamini–Hochberg 多重比较校正；leave-one-subject-out；跨数据集双向 source–target 对。

## 实验结果
**低秩发现（Fig. 2）**：
- 跨数据集、模型、层的 rank–performance 曲线通常在远低于全 embedding 维度的 rank 处达到峰值，**低秩 RRR 模型常常超过对应的 full-space ridge 基线**。
- 该改进在 PCA 降维中**没有**观察到——说明这不是压缩本身的后果，而是 RRR 优先保留了对神经预测有信息量的方向。
- **RRR 在所有三个数据集与所有 model layer 上都只在几十维就饱和**，例如 Podcast 数据集平均 rank 为 **20**；**PCA 一般需要数百维**才能达到可比性能（Fig. 2c）。

**跨被试泛化（Fig. 3）**：transferred RRR 仅用几十维即可恢复接近最大性能，达到 99% 峰值所需 rank **显著低于 PCA**，说明跨被试结果不能用"保留 embedding 的主变化维度"来解释。与用 held-out 被试自身响应学到的 RRR 相比：在 Podcast 与 fMRI 数据集上，迁移子空间所需维数与 in-participant RRR **相当，有时更少**；Cars 2 数据集上两者差距较大。结论是支撑 LLM–脑对齐的低维结构在个体间共享，**无需观察被试本人的神经响应即可识别**。

**跨数据集迁移（Fig. 4、Fig. 5）**：
- transferred RRR 仍有预测力，但效率低于目标数据集内学的 RRR（归一化 rank–performance 曲线的 AUC 更低）。
- 但在**每一个有向 dataset 对**上，transferred RRR 的 AUC 都**显著高于** transferred PCA——说明脑预测子空间确实包含可跨数据集泛化的结构，只是这种结构对刺激与记录设置的改变并非完全不变。
- 作为"与神经响应无关"的刺激位移度量，transferred PCA 在所有有向比较上都显著差于 within-dataset PCA，表明 embedding 几何有相当大的刺激依赖变化。
- **RRR 迁移损失与刺激位移正相关：Pearson $r = 0.58$，$n = 184$**（跨模型、层与有向 dataset 对）。作者明确声明这**不能证明**刺激位移完全解释 RRR 迁移损失，记录模态、预处理或数据集特有的神经表示也可能贡献。

**语言特征富集（Fig. 6）**：
- 句中位置（sentence position）与 **GPT-2 next-word prediction entropy** 在全部三个数据集的低 rank 处都更易从 RRR 而非 PCA 解码。
- **词汇具体性（concreteness）**在 fMRI 来源的 RRR 子空间低 rank 处被优先表征，但在两个 iEEG 数据集中都没有相应富集。
- **富集 profile 的数据集间相关**：两个 iEEG 数据集之间强相关（Podcast vs Cars 2：**$r = 0.70$**），但任一 iEEG 数据集与 fMRI 之间几乎没有对应（Podcast vs fMRI：**$r = -0.11$**；Cars 2 vs fMRI：**$r = -0.12$**）。这为"RRR 提取的是有意义的脑预测结构"提供了汇聚证据：共享记录模态的数据集强调相似的语言学信息，而与 fMRI 明显不同。

**显著目标数（Tab. 1，union）**：Podcast 1,200 个电极；Cars 2 439 个电极；fMRI 618,587 个 voxel。随机初始化 GPT-2 的显著目标数普遍最低（如 Podcast 各层 90–350、fMRI 各层 284,196–316,842，union 144,979），与 GloVe-300（Podcast 381、Cars 2 122、fMRI 229,249）同属低水平，与真实模型的高显著数形成对照。

## 局限性
作者自述的开放问题与解读限制：① **什么是限制了Aligned子空间的维度仍未知**——一种可能是我们通常只能获得的粗糙神经记录本身信号很少、几十维就已经很好地恢复了它；另一种可能是模型 embedding 缺少神经数据中真实表示信号的一部分；本文无法回答，但提供了"LLM embedding 中与神经数据对齐的主要特征不等同于 embedding 的主轴"这一证据。② **可解释性上的混淆**：自然语言刺激中语言学、语义、句法、话语与声学属性高度相关，因此成功的神经预测本身并不能识别哪个底层特征在因果上负责对齐；例如 volume 从 RRR 空间比 PCA 更易解码，但这**不应被解读为语言模型表示了声学音量**——模型只接收转录文本，RRR 子空间更可能保留的是与声学属性共变的语言学特征。③ RRR 富集只表明"特征或相关信息的富集"，**不等于该特征驱动神经预测**。④ 跨数据集迁移损失不能被完全归因于刺激位移。

我的补充批判：① "1–3% 维度"这一表述需要小心——相对全 embedding 维度（GPT-J 为 4096、Llama 3 8B 为 4096）几十维确实只有 1%，但**绝对维度（20–200）并不低**，且与神经信号本身的 intrinsic dimensionality 难以直接比较，缺少与"神经数据自身的低维结构"的基准对照（例如对神经响应本身做 RRR/PCA 看饱和秩）；② RRR 饱和秩可能部分反映"ridge 模型在低维投影下正则化行为不同"这一技术性因素，作者没有做更细的对照（例如对 PCA 空间同样用 RRR 选择的 rank 或用核方法）；③ 跨数据集迁移只在 3 个数据集上做，且模态与刺激混杂（Podcast podcast vs Cars 2 movie vs fMRI stories），"模态差异"与"刺激差异"与"被试差异"三者无法解耦；④ fMRI 的 618,587 个 voxel 是经 BH 校正后"至少被一个 model–layer 判定显著"的并集，选择依赖模型集合，union 偏大；⑤ 所有结论基于英语听音，未涉及其他语言或阅读任务。

## 评估与建议
- 是否推荐深入阅读：**是**（对做 mechanistic interpretability / encoding model 的研究者尤其有价值）。
- 适用场景：LLM 表征的可解释性分析；brain encoding model 的降维与效率提升；判断"某模型属性与神经对齐相关"这类模型级结论背后的真实表示机制；表示几何（PCA 主轴 vs 任务相关子空间）方法论参考。
- 与知识库的关联：与 Antonello & Huth 的 LLM-brain alignment 系列（低维结构、scaling law for encoding models、predictive coding vs feature discovery）、Schrimpf et al. 的 neuroAI 综述、Antonello et al. 2021 的低维语言表示结构、Lewis et al. 2025 的 low-rank tensor encoding models 构成直接谱系；与 Hadidi et al. 2026 关于"虚假对齐与被忽视的混淆因素"的批评性论文互补；与 RRR（Izenman 1975）与稀疏/低秩表征学习文献相关。
