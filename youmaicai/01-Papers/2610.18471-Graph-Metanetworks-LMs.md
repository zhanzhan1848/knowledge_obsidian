## 核心贡献

> 首次把 symmetry-aware *graph metanetwork* 扩展到完整 decoder-only language model——处理 transformer 权重空间的丰富对称群（神经元置换 + attention 的 continuous general-linear 对称 + head 置换 + token embedding 对称）。

1. **完整对称群 formalization**：将 decoder-only LM 权重空间的对称群 formal 化（超越 MLP / 部分 transformer 工作）
2. **跨 architecture invariance**：graph construction invariant to depth 和 width
3. **LM-specific 组件处理**：覆盖 token embeddings 等 LM 专属权重
4. **2 个新 transformer-population dataset**：含 *training-corpus prediction* 和 *fine-tuning detection* 等新颖任务
5. **SOTA on novel tasks**：baseline 在这些任务上明显落后

---

## 技术方案

### 核心思想

Weight-space learning 把 NN 权重当作数据，让 metanetwork 来处理。一个挑战是不同权重可实现同一函数（symmetry group）。本文把 graph metanetworks 扩展到 *完整 decoder-only transformer LM*——既要处理：

- 神经元置换（permutation）
- attention matrix 的 continuous general-linear 对称
- head permutation
- token embedding 对称

### 关键技术

| 技术 | 说明 |
|------|------|
| Symmetry group formalization | 完整 decoder-only LM 权重空间的对称群 |
| Graph construction invariant to symmetries | 在上述群下不变的图结构 |
| Cross architecture (depth / width) | 同构造适用不同大小 |
| Token embedding 处理 | LM-specific 组件 |
| New datasets (population-level) | training-corpus prediction, fine-tune detection |
| Graph metanetwork architecture | 处理权重作为 graph |

## 公式

设 transformer 权重集合 $W = \{W_Q^{(l,h)}, W_K^{(l,h)}, W_V^{(l,h)}, W_O^{(l,h)}, W_{mlp}^{(l)}, E_{tok}\}$。Symmetry group：

```math
G = (S_{d_{\text{model}}})^L \times (S_{d_{\text{ff}}})^L \times \text{GL}(d_{\text{head}})^{LH} \times S_H^L \times S_{|V|}
```

Graph construction $\phi$ 满足：

```math
\phi(\sigma \cdot W) = \phi(W), \quad \forall \sigma \in G
```

Metanetwork $f$ 在 $\phi(W)$ 上预测 downstream property：

```math
\hat{y} = f(\phi(W))
```

## 实验结论

- **数据集**：2 个新 transformer-population dataset
- **新任务**：
  - Training-corpus prediction（从权重预测训练数据）
  - Fine-tuning detection（检测是否被微调）
- **基线**：明显超越既有 weight-space baseline
- **意义**：LM weight space 的元学习首次具备 symmetry-aware + cross-architecture 能力

---

## 局限性

- 仅 decoder-only（encoder-only / encoder-decoder 未验证）
- 对超大模型（70B+）的 scalability 待研究
- New datasets 的规模与多样性
- 没有 mechanism-level insight（仍以 prediction 为目标）
