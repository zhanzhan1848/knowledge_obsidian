| **摘要** | Choosing among the hundreds of thousands of available large language models (LLMs) requires a thorough understanding of each candidate model's properties. In practice, each property is measured by its own benchmark suite, so profiling a model on many properties means paying for many separate evaluations. To address this, model embeddings compress each model into a fixed-length vector from which many properties can be predicted. Existing methods, such as EmbedLLM, build these vectors from correctness patterns and question features, and often need large probe batteries to do so. However, many behaviors that are important when choosing a model, such as its verbosity, safety and style, show up more in how it answers than in whether it is correct. We introduce BULLPEN (Behavioral Understanding of Large Language models via Profile ENcodings), a framework that extends EmbedLLM in three ways. First, BULLPEN organizes the downstream tasks that prior work uses and adds 20 task benchmarks we built on behavior, style and provenance. Second, it is the first framework to read a model's own answer text jointly with its correctness and the question text. Third, it encodes models from a few hundred questions instead of the full 24,118-question pool. Across 260 open-weight models, our answer-text encoder scores 0.48 +/- 0.10 on the new tasks against 0.35 +/- 0.10 for the best prior encoder. Our encoders that read answer text keep at least 91% of their full-pool skill from only 400 questions (1.3% of the inference compute of the full question pool), while a correctness-only baseline keeps 83% with the same 400 questions. Because these embeddings need only model outputs, they support behavioral auditing and low-cost profiling, and could extend to API-only models. Code and data: |

## 核心贡献

1. **问题**：面对数十万个可用 LLM，需要充分了解每个候选模型的属性。实践中**每个属性都有自己的 benchmark 套件**，所以要给模型做多属性画像就要**付多次独立评测的钱**。
2. **已有方法**：**EmbedLLM** 从**正确性模式与题目特征**构建向量，但通常需要**庞大的探针集（probe batteries）**。
3. **关键观察**：许多选型时重要的行为 —— **冗长度、安全性、风格** —— 更多体现在**"它怎么回答"而非"它答对没有"**。
4. 提出 **BULLPEN**（Behavioral Understanding of Large Language models via Profile ENcodings），从三方面扩展 EmbedLLM：
   - **重组既有下游任务**，并**新增 20 个**基于行为、风格与来源（provenance）的任务基准
   - **首个同时读取"模型自己的答案文本"+"正确性"+"题目文本"**的框架
   - **只需几百个题目即可编码模型**，而非全量 **24,118 题**池
5. **结果**：跨 **260 个开放权重模型**，答案文本编码器在新任务上得 **0.48 ± 0.10**，而最好的先前编码器为 **0.35 ± 0.10**。读取答案文本的编码器**仅用 400 个题目（占全量推理算力的 1.3%）就保留了至少 91% 的全量池技能**。

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| 技术 | 说明 |
|------|------|
| 模型嵌入 | 把模型压成定长向量以预测多属性 |
| 多通道编码 | 答案文本 + 正确性 + 题目文本 |
| 行为任务基准 | 新增 20 个行为/风格/来源任务 |
| 样本效率 | 400 题 ≈ 全量池的 1.3% 算力 |
| 嵌入维度 | 定长向量 |

### 关键发现

- **"冗长度、安全、风格体现在怎么答而非答对没"** 是本文最实用的洞察 —— 它意味着**画像应该从输出侧采样**，而不是跑更多正确性测试。这是一个成本结构的根本改变。
- **1.3% 算力保留 91% 技能** —— 这个效率比非常适合"从数十万模型中初筛"的场景：先用便宜嵌入粗筛，再对前 N 名跑完整评测。
- 与 [[2026-11-02-2610.41089-circe-divines-llm-task-complexity-from-constraint-structure]] 同属"**在跑模型之前先预测其行为**"这条线，但 BULLPEN 是**模型画像**，CIRCE 是**任务难度**。
- 与 [[2026-11-02-2610.38448-benchmarking-decision-models-against-generative-large-language-models-on]]（医疗 MCQ 中 decision model vs 生成式模型对比）互补：本文解决"选哪个模型"，那篇解决"哪种推理接口"。
- 260 个开放权重模型 + 24,118 题池的规模说明这不是小规模验证。

## 实验结果

| 设置 | 结果 |
|------|------|
| 260 个开放权重模型，新任务 | 答案文本编码器 **0.48 ± 0.10** vs 最好先前编码器 **0.35 ± 0.10** |
| 400 题子集 | 保留 **≥91%** 全量池技能 |
| 算力 | **1.3%** 全量题池推理算力 |

---

## 局限性

- 0.48 的绝对分数说明"预测行为属性"本身仍是困难任务
- 新增的 20 个行为任务基准未做充分外部效度验证
- 依赖固定题目池，池的代表性限制嵌入的泛化
