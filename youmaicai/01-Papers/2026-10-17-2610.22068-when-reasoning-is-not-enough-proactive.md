## 核心贡献

> MLLM 中**单独看无害**的图文**联合**起来可触发不安全行为。已有 reasoning-only / path-optimization 的方法**无法纠正**——因为**危险发生在 intent 层面**（cross-modal ambiguity 让模型悄悄 commit 到危险前提）。

1. 区分两种风险：
   - **Implicit reasoning risk**：reasoning drift → harm
   - **Intent-level risk**：cross-modal ambiguity → 危险前提 → path 优化也救不了
2. 提出 **SAFE-PRO**：
   - **Risk-Conditioned Uncertainty (RCU)** = predictive entropy + learned cross-modal risk score
   - 何时**主动发起 safety-grounded clarifying question**
   - 在哪**施加 path optimization**
   - 奖励函数：prioritize safety + **penalize over-refusal**
3. 构建 **SSUI-Dialog**：多模态多轮带 **dual-intent supervision** 的 dataset。
4. 理论分析 RCU 下的 gradient variance + unsafe-completion risk。
5. 7 个 benchmark + 2 个 MLLM backbone：超 SRPO，**over-refusal 减半**，**单轮 safety 平均超 GPT-4o / Claude-3.5-Sonnet**。

---

## 技术方案

### RCU 信号
```
RCU(s) = H(p(y|x,s)) + λ · R(s)
  H = predictive entropy (model uncertainty)
  R = learned cross-modal risk score (whether the joint premise is hazardous)
```

### Decision Rule
- RCU 高 → 主动 clarify（**主动询问 safety-grounded 问题**）
- RCU 低 → 走 path optimization（标准 reasoning + safety check）

### Reward
```
r = r_safety - β · r_over_refusal
  r_over_refusal 惩罚"该答不答"的过度拒绝
```

## 关键洞察

- **Intent-level risk 是 MLLM 安全的新维度**——单独看 image / text 都安全，**联合触发**才危险。
- **主动 clarify > 被动 refuse**：clarify 比 over-refusal 友好得多。
- **RCU 是 MLLM 不确定性 + 风险信号的天然统一**。
