## 核心贡献
1. **提出并研究"功能性 FoK（feeling of knowing）"**：模型对自己当前知识状态能否支持正确答案的判断。FoK 是**功能性的**（支撑选择性生成、检索触发、模型路由），**不隐含主观体验**。形式化为 $J_\theta(q) \in [0,1]$，用一个生成式 yes/no 判断提示实例化为 $J_\theta(q) = \frac{P_\theta(\text{yes}|q)}{P_\theta(\text{yes}|q) + P_\theta(\text{no}|q)}$。
2. **识别出"知识–FoK 去同步"（knowledge–judgment desynchronization）问题**：后训练更新改变了模型能回答什么，却让可答性判断失配。具体证据：K-SFT 让**七个模型中的六个** FoK AUROC **下降**（Qwen2.5-3B 降幅最大，-0.220）。
3. **用 ROME 的因果追踪定位 FoK 信号**：FoK 信号峰值在**模型深度约 2/3 处**（晚期层），比 ROME 报告的事实关联位置（中层 MLP，约 1/3 深度）**更晚**；该模式在 Qwen2.5 从 0.5B 到 32B 的**归一化深度**上保持一致。
4. **发现 FoK 对可访问上下文敏感**：在 MATH 题目上，模型先生成解题轨迹，再在轨迹的递增前缀上重新查询，FoK 分数随推理 token 增加而**更分离**（最终 Yes 的均值趋向 $J=1$，No 趋向 $J=0$），前缀级 $J$ 对最终 Yes/No 的 AUROC 随推理 token 增加而**上升**。结论：**FoK 应从模型当前上下文判断，而非仅从原始问题**。
5. **提出双通道框架**：**knowledge channel**（知识增量 $\kappa$，改变模型知道/检索什么）与 **FoK channel**（FoK 增量 $\phi$，判断当前知识状态）。三个训练阶段：
   - **OP-SFT（On-policy SFT）**：更新 $\kappa$，从模型自身采样的响应中学习，**只监督被纠正的答案相关后缀**以限制对 FoK 的扰动；并保存 checkpoint 轨迹 $\{\kappa_0, \kappa_1, \dots, \kappa_T\}$。
   - **KΔ-FT（Knowledge-delta FoK Training）**：在 checkpoint 轨迹上训练 $\phi$，使判断标签跟随变化中的可答性。
   - **FGPO（FoK-guided Policy Optimization）**：训练模型生成推理轨迹 → 做 yes/no 判断 → 给出答案或解释；奖励同时评估判断与响应。
6. **主结果（TriviaQA 一次知识更新，Qwen2.5-7B）**：训练集准确率 **0.961**（vs vanilla K-SFT 0.874），FoK AUROC **0.817**（vs vanilla K-SFT 0.458），Bias **0.245**（vs 0.500）；留出集准确率 **0.692**（vs vanilla K-SFT 0.546，base 0.672），AUROC **0.809**（vs 0.519），Bias **0.308**（vs 0.500）。MMLU 0.711 / ARC-Easy 0.830，能力基本保持（base 0.687 / 0.811）。
7. **反向对照**：J-SFT 单独训练判断可提升 FoK 且在大模型上不损害答案性能；K→J SFT（先知识后判断）能重新校准 FoK 并保留 K-SFT 的大部分准确率增益——证明 FoK 依赖当前知识状态、应在知识变化后更新。

## 问题背景

LLM 作为助手与工具调用 agent，其可靠性既取决于答案准确率，也取决于**能否判断何时该回答、何时该寻求外部支持**。认知科学把这个元认知判断称为 feeling of knowing（FoK）。功能性的 FoK 支撑**选择性预测、模型路由与检索触发**：若 FoK 不能反映更新后的知识，系统要么会自信地回答不知道的问题（illusion），要么会拒绝其实已能解决的问题（omission）。

现有 LLM FoK 方法主要有三类：**output-based**（从模型自身生成中读不确定性，如"true" token 的概率或采样答案的熵）、**probe-based**（在 hidden states 上训练轻量分类器）、**elicitation-based**（监督模型直接口头表达置信度）。但这些方法通常在**静态模型参数**下校准与评估——它们留下了一个未探索的问题：**当模型随后被 SFT、LoRA、知识编辑或持续学习更新后会发生什么？** 更新之后，模型的知识变了，而为 base model 训练或校准的 FoK 估计器可能仍按 base model 的知识边界来判断可答性。

论文受 Koriat 的 FoK 理论启发：人类 FoK 是**从可访问线索推断**的，而非直接从记忆读取。作者明确声明其正确性监督目标**并未实例化或验证**这一认知过程——他们用的是关于被测提示与干预的证据，不是关于类人机制的证明。

两个挑战随之而来：(1) **知识–FoK 去同步**：知识训练改变可答性却不保持 FoK 判断对齐；(2) **上下文相关的 FoK**：判断随可用上下文与生成的推理而变化。

## 方法

### 1. 问题形式化

设 $M_\theta$ 为参数状态 $\theta$ 的 LLM，$q$ 为问题。$Y_\theta(q) \in \{0,1\}$ 表示模型贪心答案是否正确，$J_\theta(q) \in [0,1]$ 为功能性 FoK 分数（0 = 判断自己不能答，1 = 判断自己能答）。FoK 的质量体现为**同一解码规则下 $J_\theta(q)$ 与 $Y_\theta(q)$ 的对齐**。

模型通过后训练学到新知识时，参数从 base 状态 $\theta$ 变为更新状态 $\tilde\theta$，诱导出的差 $\kappa = \tilde\theta - \theta$ 称为**知识增量（knowledge delta）**。目标是让 $J_{\tilde\theta}$ 与 $Y_{\tilde\theta}$ 保持对齐。

**两个方向的失败**：**illusion**（判断能答但答错）与 **omission**（判断不能答但其实能答对）。

**综合 Bias 指标**：
$$\text{Bias} = \begin{cases} \frac{\text{illu.} + \text{om.}}{2}, & \text{if illu.} \ge \text{om.} \\ -\frac{\text{illu.} + \text{om.}}{2}, & \text{if illu.} < \text{om.} \end{cases} \in [-1, 1]$$

### 2. OP-SFT（On-policy Supervised Fine-Tuning）

对每个问题 $q$ 及其 gold answer 集 $A_q$，从当前 LLM 采集 $k$ 个完整采样响应。对采样响应 $r = (r_{<s}, r_{[s:e]}, r_{>e})$（$r_{[s:e]}$ 为生成的答案 span），两种情形：

- 若采样响应**已答对**：保留该答案 span；
- 若**答错**：**只**把答案 span 换成 gold answer $a^*(q) \in A_q$，**其余生成的响应完全不变**。

修复后的训练响应为（式 1）：
$$\bar{r}(q, r) = (r_{<s}, \bar{a}(q,r), r_{>e}), \qquad \bar{a}(q,r) = \begin{cases} r_{[s:e]} & \text{答对} \\ a^*(q) & \text{答错} \end{cases}$$

因此训练序列**不是静态 QA 对**：它采样自当前 LLM，只改错误答案 span，且**只在 $\bar{a}(q,r)$ 上计算 loss**（式 3）：

$$\mathcal{L}_{\text{OP-SFT}} = -\mathbb{E}_{q,r} \frac{1}{|\bar{a}(q,r)|} \sum_{u=1}^{|\bar{a}|} \log P_{M_\kappa}\big(\bar{a}(q,r)_u \mid q, r_{<s}, \bar{a}(q,r)_{<u}\big)$$

论文例子（$q$ = "Who wrote Pride and Prejudice?"，$A_q = \{\text{Jane Austen}\}$）：采样响应中第一个答案相关错误是 "Charlotte Brontë"，被替换为 "Jane Austen"，同时保留 "I think the author was ... because she wrote English classics." 的其余生成文本——**其余文本不接收 loss**。

训练过程中保存 checkpoint $\{\kappa_0, \kappa_1, \dots, \kappa_T\}$，构成后续 FoK 适配的**监督状态序列**。

### 3. KΔ-FT（Knowledge-delta FoK Training）

只在 base 或最终 LLM 上训练 FoK 会给出**状态特定**的可答性边界，跨知识增量泛化差；且**最终状态训练会造成标签不平衡**（许多更新后的问题变得可答）。

KΔ-FT 用 OP-SFT 的 checkpoint 轨迹作为监督状态。对每个 checkpoint $\kappa_t$，结合**同一个** FoK 增量 $\phi$，训练 $\phi$ 预测 $M_{\kappa_t}$ 能否回答 $q$（式 4）：

$$\ell_\phi(q, \kappa_t) = -\log P_{M_{\kappa_t,\phi}}\Big(\mathbb{1}[\text{ans}(M_{\kappa_t}, q) \in A_q] \mid T_J(q)\Big)$$

其中 $T_J(q)$ 把 $q$ 包进固定的 Yes/No 提示 "Can you answer this question correctly?"。$M_{\kappa_t,\phi}$ 是冻结知识增量 + 可训练 FoK 增量的 base 模型。概率在 $M_{\kappa_t,\phi}$ 下评估——**FoK 在与判断相同的组合知识-FoK 状态下训练**。总体目标在所有问题与所有 OP-SFT checkpoint 上平均（式 5）：

$$\mathcal{L}_{\text{KΔ-FT}}(\phi) = \frac{1}{|Q|(T+1)} \sum_{q \in Q} \sum_{t=0}^{T} \ell_\phi(q, \kappa_t)$$

**只优化 $\phi$**，知识 checkpoint 是固定的监督状态。因为同一问题在多个 $\kappa_t$ 下被评估，KΔ-FT 训练 FoK 跟随可答性**从更新前到更新后的变化**，而不是记忆与当前模型状态脱钩的静态问题级标签。

### 4. FGPO（FoK-guided Policy Optimization）

OP-SFT 与 KΔ-FT 之后，连续 FoK 分数仍需一个**决策阈值**。FGPO 联合训练判断与后续响应，使模型能在一次生成内承诺回答或解释。生成格式：

```
<think>...reasoning...</think> <answer>yes|no</answer> <response> answer or explanation </response>
```

对采样轨迹 $z = (h, j, u)$（$h$ 推理轨迹、$j \in \{\text{yes}, \text{no}\}$ 判断、$u$ 响应），奖励分解为 FoK、答案、格式三项（式 6）：

$$R(q, z) = R_{\text{FoK}}(Y(q), j) + R_{\text{ans}}(q, Y(q), j, u) + R_{\text{fmt}}(z) - \lambda|h|$$

$R_{\text{FoK}}$ 直接监督判断 token（式 7）：$R_{\text{FoK}}(Y,j) = \alpha_+ \mathbb{1}[\iota(j) = Y] - \alpha_- \mathbb{1}[\iota(j) \ne Y]$，其中 $\iota(\text{yes}) = 1$、$\iota(\text{no}) = 0$。

答案项（式 8）要求"yes 判断后必须跟正确答案"，"no 判断必须由有效解释支撑"：

$$R_{\text{ans}} = \mathbb{1}[j=\text{yes}, Y=1]\big(\beta_+ C(q,u) - \beta_-(1-C(q,u))\big) - \mathbb{1}[j=\text{yes}, Y=0]\big(\bar\beta_+ C(q,u) + \bar\beta_-(1-C(q,u))\big) + \mathbb{1}[j=\text{no}, Y=0]\big(\gamma_+ E(q,u) - \gamma_-(1-E(q,u))\big) - \mathbb{1}[j=\text{no}, Y=1]\gamma_{\text{skip}}$$

其中 $C(q,u) = \mathbb{1}[u \in A_q]$ 为答案正确性，$E(q,u)$ 表示 LLM judge 是否接受 $u$ 作为"不回答"的有效解释。格式项（式 9）奖励合法格式 $F(z)$ 与正确终止 $S(z)$。

**实现细节**：错误答案与畸形输出的惩罚**大于**有效"no"解释的正奖励，避免模型通过选否定判断来回避可答问题而获得奖励。

### 5. 因果追踪定位 FoK

采用 ROME 的因果追踪方法：对每个事实问题**污染 subject token**，逐层恢复 hidden states，测量 yes/no FoK 判断是否被恢复。在 Qwen2.5 各规模上重复，使用**归一化深度**跨架构比较对应层。

## 关键洞察

1. **K-SFT 会破坏 FoK，且破坏程度随模型而异**：七个模型中六个的 AUROC 在 K-SFT 后**下降**。这不是随机噪声而是系统性效应——因为知识更新改变了输出分布与采样行为，而这些正是 output-based 估计器依赖的东西。**任何在知识更新前校准过的置信度阈值，事后都不再承载同样的意义**。
2. **vanilla K-SFT 的留出准确率跌破 base（0.546 vs 0.672）**——更新不是"增加知识"而是"过拟合更新分片"。而 OP-SFT（只监督纠正后的答案 span，保留 on-policy 上下文）把留出准确率提到 0.692，**高于 base**。这是 OP-SFT 设计的一个被低估的副作用。
3. **"监督哪些 token"本身就是一个 FoK 保护机制**：OP-SFT 的 loss 只落在答案 span 上，其余 on-policy 生成文本不接收梯度——这既限制了知识更新的漂移，也意外地保护了 FoK 能力。这是一个可迁移的技巧：做窄目标的知识更新时，把 loss 收窄到最相关的 span。
4. **FoK 信号与事实关联位于网络的不同深度**（2/3 vs 1/3）——这一分离是"FoK 是对知识状态的判断，而非事实召回本身"的证据。它也解释了为什么 judgment SFT 主要改晚期层而知识 SFT 主要改浅中层：**两者在物理上可分离**，所以可以分别训练、分别校准。
5. **在 checkpoint 轨迹上训练 FoK（KΔ-FT）比在最终状态上训练更有效**，因为前者让 FoK 学会"跟随"可答性的变化而非记住一个静态标签。这把"校准"从一个静态标定问题变成了一个**轨迹上的动力学问题**。
6. **FoK 是上下文相关的，而非问题固有属性**：模型自己先生成推理再判断，FoK 的确定性大幅提升。这意味着"生成—再判断"的两段式流程（而非让模型直接对原始问题回答"我能答吗"）是更可靠的 FoK 提取方式，也正是 FGPO 所训练的。
7. **FGPO 的奖励设计里有一个关键的负面防护**：错误答案的惩罚必须大于有效"no"解释的正奖励，否则模型会发现"一律说我不能答"是安全策略。这是一个在 self-selecting 系统中反复出现的奖励 hacking 模式，值得任何设计"模型自评 + 行动"循环的人借鉴。

## 局限性

- **方法需要保存 checkpoint 轨迹** $\{\kappa_0, \dots, \kappa_T\}$ 并在其上逐个训练 FoK，存储与训练成本随 $T$ 线性增长；论文未给出 $T$ 的敏感性分析或成本核算。
- **EliCal 基线在 base model 上的表现与在更新模型上截然不同**（base AUROC 0.808/0.810 vs K-SFT 后 0.646/0.644），这实际上**强化了**论文论点，但也意味着"最佳 FoK 估计器"的表述需仔细解读（Ours 在训练集 0.817 略胜 EliCal-base 的 0.808，但留出集 0.809 略低于 EliCal-base 的 0.810）。
- **留出集上 illusion 仍大于 omission**，即模型仍倾向于过度自信；论文承认这一点但未彻底解决。
- **强基线的能力代价被揭示但未被解决**：EliCal 使 ARC-Easy 从 0.811 崩到 **0.504**，而 Ours 保持 0.830。这说明"最对齐 FoK 的方法"与"最保能力的方法"可能不是同一个，论文没有系统研究这个 trade-off 的边界。
- **FoK 定位实验用 ROME 的 subject-token 污染方法**，该方法是为事实关联设计的；用于 yes/no 判断提示可能带来方法学偏差（作者也承认这是"关于被测提示与干预的证据"）。
- **未涉及多模态或 agentic 场景**——FoK 在真实工具使用中的表现未验证，尽管"路由到更强模型""触发检索"正是本文声称的应用场景。
- **依赖 LLM judge** 来判定"是否为有效解释"（$E(q,u)$），引入了额外的模型依赖与噪声，论文未评估该 judge 的可靠性。
- **FoK 分数由单次 yes/no 提示的概率实例化**，其对提示措辞的敏感性未做系统评估（对比 2611.04395 表明提示措辞可显著改变模型行为）。
- **KΔ-FT 的标签由 greedy 解码的正确性决定**，故 FoK 与"能否答"绑定于特定解码规则；换解码规则后 FoK 是否仍对齐，未验证。
- **主要实验只在 TriviaQA 上做一次知识更新**（另有三次顺序更新的实验，但主表的证据集中于单次更新）。

## 适用场景

**适用**：
- 构建**会定期更新知识**的 LLM 系统（知识编辑、持续学习、SFT 流水线）：本文给出了"更新后必须重校准可答性判断"这一问题的规模与解法。
- **选择性生成 / 模型路由 / 检索触发**系统的设计与评估：本文的 AUROC、Bias、illusion/omission、coverage–accuracy 权衡是直接可用的指标体系。
- 需要**在更新后仍可靠的置信度估计**的应用（客服、医疗辅助、法律问答），因为作者证明既有估计器在更新后会显著退化。
- 研究**知识与元认知的可分离性**的机制可解释性工作（层定位、参数侧检查、干预设计）。
- 提示工程：两段式"先生成再判断"结构对 FoK 可靠性的提升可直接复用。

**不适用**：
- 模型参数永不更新的场景（静态模型上 base FoK 已够用，本文方法的开销无必要）。
- 需要严格保证 FoK 不被输出分布变化影响的系统（本文方法仍依赖与具体解码规则的绑定）。
- 高风险场景下的"模型自报不能答"作为唯一拒答依据——本文留出集上 illusion 仍占优。
- 多模态或长程 agent 场景（未验证）。
