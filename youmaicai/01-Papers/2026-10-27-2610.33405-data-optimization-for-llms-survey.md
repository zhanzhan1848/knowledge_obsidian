## 核心贡献

> 系统梳理 LLM 的**数据优化**方法论 —— 这是 LLM 综述中长期缺失的一块拼图。

1. **提出 LLM 数据优化的统一框架**，目标是提升数据利用率与效率，而非罗列技术。
2. **定义四个数据感知维度**（quality / difficulty / diversity / redundancy）作为评估数据属性的统一语言，为后续优化技术提供共同基础。
3. **将现有技术归为四类**：data selection（选择）、augmentation（增强）、reweighting（重加权）、others（其他）。
4. **分析四类方法之间的内在关联**，并指出相较传统深度学习，LLM 数据优化的关键挑战与未来方向。

## 技术方案

### 核心思想

数据是 LLM 涌现能力的公认关键因素，但既有综述多聚焦学习策略、应用、对齐、可解释性、评估，**数据侧进展被系统性忽略**。而实际上数据优化技术来源极为分散（源自不同的深度学习领域，理论灵感与启发式动机看似互不相关）—— 本文的贡献正是**给这些碎片化技术一个统一的坐标系**。

### 四维数据感知框架

| 维度 | 含义 | 对应优化手段举例 |
|------|------|-----------------|
| **Quality**（质量） | 样本的信息量/正确性/规范性 | 质量过滤、去噪、启发式打分 |
| **Difficulty**（难度） | 样本的学习价值密度 | 难例挖掘、课程学习 |
| **Diversity**（多样性） | 覆盖面的广度 | 去重、聚类采样、覆盖度优化 |
| **Redundancy**（冗余度） | 重复信息量 | 去冗余、动态剪枝 |

### 四类优化技术族

```text
数据优化技术族
├── 数据选择 (Data Selection)      —— 决定「用哪些样本」
│     └─ 静态筛选 / 动态剪枝 / 可学习选择器
├── 数据增强 (Augmentation)        —— 决定「如何改造样本」
│     └─ 改写 / 回译 / 合成 / 多模态对齐
├── 数据重加权 (Reweighting)       —— 决定「每个样本的影响力」
│     └─ 损失重加权 / 课程 / 分布匹配
└── 其他 (Others)                  —— 混合采样 / 去重 / 治理
```

### 章节结构

1. LLM 训练与推理中的**数据挑战**
2. **数据感知维度**（quality/difficulty/diversity/redundancy）
3. **优化技术综述与分类**（四族）
4. **四族之间的互联关系**分析
5. 关键挑战与未来方向

## 实验结论

- **综述性质**，无实验表格
- **组织方式**: 从「问题—维度—技术—关联—展望」建立完整链条，把来源各异的技术纳入同一框架
- **核心增量**: 明确了 LLM 数据优化相较传统深度学习的特殊性（数据规模、分布漂移、多模态混合、阶段间数据复用）

---

## 局限性

- 综述未对四族技术做统一的定量横评（不同论文的评测设置互不可比）。
- 「其他」类别过于笼统，弱化了其内部的分类价值。
- 单作者综述，视角覆盖面可能受限；面向 RL 阶段数据（在线采样、经验回放）的讨论相对薄弱。

## 实现建议

- **实现难度**: 低（作为方法选型索引）
- **预期性能**: 提供「我在做数据工作 → 应该从哪一维切入」的定位表；重加权类方法通常成本最低、见效最快
- **适用场景**: 数据团队方法选型、LLM 训练数据策略设计、综述写作补齐数据侧

## 我的评注

> 这篇填补的空白很实际：几乎每篇 LLM 论文都在讲「用了什么数据」，但很少有论文系统讲「如何优化数据」。四维框架（quality/difficulty/diversity/redundancy）与四族技术（select/augment/reweight/other）构成一个实用的二维坐标系 —— 之后读到任何数据优化类论文，可以先归位再评估。
>
> 与 [[A Comprehensive Framework for All Stages of Large-Model Training]] 配对阅读效果更好：前者给全流水线坐标，本文填「数据」格子。
