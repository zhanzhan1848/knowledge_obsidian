# Multi-Resident Data Association in Smart Homes via MDP Modeling and Behavior Cloning

> **arXiv**: [2611.06296](https://arxiv.org/abs/2611.06296)
> **发表日期**: 2026-11-04
> **分类**: cs.NE (及交叉分类 cs.AI)
> **会议/期刊**: Proceedings of the ACM on Interactive, Mobile, Wearable and Ubiquitous Technologies 2026, 10(3), pp.1-37

## 📋 摘要

环境传感器（ambient sensors）为智能家居中的活动识别提供了隐私保护的解决方案，但在多居民环境下面临一个关键挑战——Data Association（数据关联），即识别出触发某个匿名传感器事件的居民是谁。现有方法从根本上无法保持全局一致性：对处于静默状态的居民经常给出相互冲突的关联结果；同时由于将连续的物理运动模型套用到离散的逻辑行为上，存在**本体论不匹配**，导致严重的轨迹碎片化。作者提出一个新框架，将数据关联重述为 Markov Decision Process (MDP) 中的序贯决策问题，并通过 Behavior Cloning (BC) 求解该 MDP，从而避免复杂的奖励工程、直接从专家演示中学习。策略实例化为两种互补架构：一是轻量级 Transformer，将关联建模为线性化事件历史上的多标签分类任务；二是微调后的 Large Language Model (LLM)，将问题重述为条件文本生成以利用预训练的语义知识。在三个多样化数据集上的大量评估显示，该方法显著优于 state-of-the-art 基线，在解决并发多居民事件方面尤为突出。此外，LLM 策略在基准设置下展现出初步的跨环境迁移潜力，但其在真实部署中的鲁棒性仍需进一步验证。

## 🎯 核心贡献

1. **问题重述**：将智能家居 Data Association 从"独立的分类/匹配"问题重述为 MDP 下的序贯决策问题，从而在建模层面直接解决"全局一致性"缺陷——静默居民的关联不再是彼此独立的预测，而是同一决策序列中的一致状态。
2. **规避奖励工程**：采用 Behavior Cloning 直接从专家演示学习策略，无需为"全局一致但逐点无监督信号"的问题设计复杂的稠密奖励。
3. **双架构策略**：轻量级 Transformer（线性化事件历史 + 多标签分类）与微调 LLM（条件文本生成），分别对应"高效部署"与"语义先验/跨环境迁移"两种需求。
4. **解决本体论不匹配**：以离散逻辑行为（而非连续物理运动模型）刻画居民行为，消除轨迹碎片化；在并发多居民事件场景下的优势最明显。
5. **实证结论**：在三个数据集上显著超越 SOTA 基线；LLM 策略初步展现出跨环境迁移能力。

## 🔧 方法/架构

- **MDP 建模**：把数据关联建模为马尔可夫决策过程，状态包含历史事件序列的抽象表示，动作空间为"把当前匿名事件指派给哪个（或哪些）居民"的候选决策，转移遵循真实的多居民共处逻辑，从而保证全局一致。
- **Behavior Cloning 求解**：以专家演示轨迹作为监督信号学习策略 $\pi_\theta(a \mid s)$，避开手工奖励设计：

```math
\pi_\theta(a \mid s) = \arg\max_\theta \; \mathbb{E}_{(s,a)\sim \mathcal{D}_{\text{expert}}}\big[\log \pi_\theta(a \mid s)\big]
```

- **架构 A — 轻量级 Transformer**：将线性化的事件历史序列化为 token 序列，输出**多标签**分类（一个事件可同时关联多个并发触发的居民），适合边缘部署。
- **架构 B — 微调 LLM**：把关联决策改写为条件文本生成任务（如 "Event: ... → Resident(s): ..."），以复用预训练语义知识。
- **评测**：三个多样化数据集上的对比实验，重点分析并发（concurrent）多居民事件子集。

## ⚠️ 局限性

- 摘要明确指出 LLM 策略的**真实部署鲁棒性尚未验证**，跨环境迁移目前仅在基准设置下初步成立。
- Behavior Cloning 继承了专家演示的偏差，策略对未覆盖的居民行为组合缺乏鲁棒性。
- 三个数据集的规模与多居民数量上限未披露，高并发复杂度场景下的可扩展性存疑。
- 依赖环境传感器事件的匿名化质量；若上游事件切分或标注有误，关联错误会被级联放大。
- LLM 微调方案与轻量 Transformer 方案在真实设备算力/延迟约束下的权衡未量化。
