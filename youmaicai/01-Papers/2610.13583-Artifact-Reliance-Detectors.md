## 核心贡献

> 揭示机器文本检测器的高分实际由 **PDF 提取 artifact** 等表面特征驱动：人写文本保留换行、机器文本被提取成单一 prose 块。

1. **27 superficial features** 即可达 macro-F1 **0.833-0.997**
2. **PDF 提取 artifact** 是最强 cue，**+ 3 formatting features** 在 0.996 AUC 上区分两类
3. **Format counterfactual**: 不改一字重新包裹 machine 摘要，**逆转公开检测器 20-27% 正确决策**
4. **Format-normalized training**: OOD macro-F1 **0.33 → 0.65**

---

## 技术方案

### 核心思想

主流机器文本检测器在 scientific 文档 benchmark 上近满分，但这是 benchmark artifact。本文用 27 个浅层特征 + format counterfactual 系统审计 detector 对 artifact 的依赖。

### 关键技术

| 技术 | 说明 |
|------|------|
| 27 superficial features | logreg 即可达 F1 0.833-0.997 |
| PDF extraction artifact | human 保留换行 / machine 单一 prose |
| Format counterfactual | 仅重包裹不改字，逆转 20-27% 决策 |
| Format-normalized training | 训练前 normalize 格式 |
| Generalization gap | 从 0.32 → 0.22 |

### 关键发现（数据来源）

| 来源 | arXiv subset | detector F1 |
|------|--------------|-------------|
| Resource A | yes | 0.951 |
| Resource B | yes | 0.997 |
| Resource C | yes | 0.99+ |

---

## 实验结论

- **数据**: 10 个 scientific-document subset / 6 资源
- **结果**:
  - 27-feature logreg ≈ 最佳 detector
  - Format counterfactual 逆转 20-27% 决策
  - Format-normalized training 显著改善 OOD generalization
  - On format-clean benchmarks: OOD macro-F1 **0.33 → 0.65**

---

## 局限性

- 仅在 scientific literature domain 评估
- Counterfactual 仅针对 PDF extraction artifact，未覆盖其他 artifact
- 公开 detector 的修复需要 format-aware training pipeline
