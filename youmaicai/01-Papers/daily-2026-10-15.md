## 重点论文（12 篇）

### 1. **MemDuet: Learning Dual-Process Memory for Long-Context Reasoning** (2610.19928)
- Kahneman 启发的双过程：System 1 小 LM 并行 evidence selection + System 2 大 LM 串行 verification / memory update。
- 三阶段训练：SFT1 → GRPO2 → 联合优化。
- RULER-HQA / LongBench v2 / 2WikiMultiHopQA **9.74×** 加速，output token **-73.91%**。
- 详见 [[2610.19928-MemDuet-Dual-Process-Memory]]

### 2. **Argument Graph Uncertainty** (2610.20328)
- 从 CoT 逻辑结构（而非 token prob / 多采样）抽 uncertainty。
- CoT 命题切分 → NLI 建图 → Dirichlet posterior over options。
- GPQA / MMLU-Pro / TruthfulQA 上 consistent 超 token-based / consistency-based；与现有方法**正交**。
- 详见 [[2610.20328-Argument-Graph-Uncertainty]]

### 3. **Hindsight-Privileged RLVR: Single-Rollout Token Credit** (2610.20497)
- 用轨迹自身 hindsight 当 token credit signal，无 group sampling 无 critic。
- Policy snapshot 双视图评分 + 归一化 JS divergence → bounded token credit。
- Qwen3-8B 100-step：math **1.21×** / code **1.46×** / ALFWorld **2.30×** 加速；每 prompt **1/8 rollouts**。
- ALFWorld 上 **43.2%(4B) / 49.0%(8B) GRPO 梯度范数为 0** → HP-RLVR 无此问题，GRPO 稀疏信号曝光。
- 详见 [[2610.20497-Hindsight-Privileged-RLVR]]

### 4. **Identity-Blinded Reasoning Diagnostic for LLM Chemical Prediction** (2610.19906)
- 揭示 high benchmark accuracy ≠ transferable reasoning。
- Source + Edit 替代 target entity；source label substitution ablation。
- 6 任务（odor / property / retro / yield）：source-target property 一致 → accuracy 显著更高；替换 source label → systemically shift → shortcut 严重。
- 详见 [[2610.19906-Identity-Blinded-Chemical-Diagnostic]]

### 5. **Reasoning-Guided Multilingual Safety & Reasoning Eval** (2610.20221)
- 翻译策略选择 + task-aware validation + targeted repair + independent screening。
- 7 benchmark × 11 语言：**99.94%** coverage；safety refusal 跨语言不一致 + low-resource reasoning 大幅退化。
- 详见 [[2610.20221-Reasoning-Guided-Multilingual-Eval]]

### 6. **Long-Horizon RL Needs Muon** (2610.20256)
- Repo-level issue resolution 的 async RL recipe：Muon + token-averaged loss + truncated IS + length / tool-error penalties。
- 单 rollout 异步训练，无需 group sampling。
- 比 baselines training success 显著提升。
- 详见 [[2610.20256-Long-Horizon-RL-Muon]]

### 7. **From Relevance to Validity: Zero-Shot Tool Selection** (2610.20388)
- 揭示 transfer-validity gap：semantic relevance ≠ functional / contextual validity。
- Progressive 3-stage：relevance → functional (endpoint-grounded) → contextual (task-conditioned)。
- 跨 domain / 跨 dataset transfer 一致增益，functional / contextual 模糊场景下增益更大。
- 详见 [[2610.20388-Zero-Shot-Tool-Selection-Validity]]

### 8. **ReaDy: HLA Recurrent State Speculative Decoding** (2610.20503)
- 首个用 HLA recurrent states 做 position-specific context 的 spec dec。
- 每个 draft position learned query → retrieve supplementary context；low-rank state reads + fused operators 控制开销。
- Qwen3.8-27B / 单 B200 平均 **3.16×** 加速；超 DSpark **+7.97% throughput / +8.50% accept length**。
- 详见 [[2610.20503-ReaDy-Speculative-Decoding-HLA]]

### 9. **Co-Evolving Acting and Forecasting for Language Agents** (2610.20597)
- 第三类辅助目标：multi-step action targets + temporal ensemble。
- 成功 on-policy 轨迹上每个 action 从多个 history 视角被教；shared backbone 吸收。
- ALFWorld / ScienceWorld / WebShop / τ²-bench / AppWorld：ScienceWorld sample efficiency **1.9× vs ECHO / 2.0× vs GRPO**。
- 详见 [[2610.20597-CoEvolving-Acting-Forecasting-Agents]]

### 10. **CIPR: Cross-Interface Policy Regularization** (2610.20576)
- Post-training 把 agent 绑定到训练 interface；semantic-preserving perturbation → ~25% accuracy drop。
- CIPR：KL 约束两 interface 下 action 分布 → interface-invariant policy。
- Agentic function calling：held-out perturbation 恢复 **+10.5%**；原 interface accuracy 不损；SFT/RL 都可 plug-in。
- 详见 [[2610.20576-CIPR-Cross-Interface-Policy-Reg]]

### 11. **NatScale: Beyond Expert Rankings for Mixed-Precision MoE Quantization** (2610.20353)
- 暴露 expert ranking 不足：不知如何 weight errors。
- Power transformation 把 gradient-based weights 校准到 contrast target；联合 gate/up/down 评估；与 weight-spectra prior 融合。
- 3 模型 / 9 设置：最低 KL divergence / 最高 top-token agreement；7/9 设置 PPL 最低。
- 详见 [[2610.20353-NatScale-Mixed-Precision-MoE]]

### 12. **SpectrumQuant: Spectrum Alignment for LLM Quantization** (2610.20303)
- First-principles 推导 rotation criterion：spectral alignment (maximizing covariance)。
- Closed-form 算法：calibration → 估计 covariance → 构造 alignment + mixing 复合变换。
- Llama / Mistral：与 SOTA learned rotation 相当，GPU 内存 **< 1/3**，时间显著降低。
- 详见 [[2610.20303-SpectrumQuant-LLM-Quantization]]

## 关键洞察

1. **Single-rollout async RL 是新主流**：HP-RLVR、Long-Horizon Muon、Co-Evolving 三者都走向 single-rollout + hindsight / auxiliary targets 路线，绕开 GRPO group sampling 的稀疏信号问题。这是 2026 下半年 agent RL 的核心范式转移。
2. **Credit Assignment 仍是核心瓶颈**：HP-RLVR 量化揭示 GRPO 43-49% 梯度为零；Co-Evolving 通过 multi-step action targets 缓解；Long-Horizon 用 token-averaged loss + length penalty。三条独立路径都指向 **如何把稀疏信号分配到对 action**。
3. **Training-free / plug-in 设计哲学**：MemDuet（无需重训大 LM）、ReaDy（无需训练 target）、SpectrumQuant（closed-form rotation）、CIPR（KL 自监督）、HP-RLVR（不需 critic）— 五个独立工作都展示了 *无需 gradient* 或 *plug-in 改造* 的精巧方案。Production 部署价值显著。
5. **推理 / 部署优化方向多元化**：HLA 专用 spec dec（ReaDy）、MoE mixed-precision（NatScale）、spectrum-aware PTQ（SpectrumQuant）— 形成 *architecture-aware compression* 趋势。
6. **多语言 / 多领域评估成熟度提升**：Reasoning-guided translation pipeline（2021）展示 task-aware eval 是 multilingual deployment 的必备条件；IBRD 揭示 chemistry benchmark 的 memorization shortcut 严重性。
7. **Uncertainty 估计走"逻辑结构"路线**：Argument Graph Uncertainty 把 NLI + CoT 切分当作信号来源，与 Semantic Entropy 等 token-based 正交，ensemble 价值大。
8. **Tool selection 进入"validity"时代**：Relevance-only 已不够；endpoint + context 两层验证成为新标准。

## 第二波重点论文（12 篇）

### W2-1. **DMS: Decoupled Marginal Sharpening for Training-Free Inference-Time Scaling** (2610.20483)
- **解决痛点**：现有 reward-free power-sampling 同时压平推理路径多样性 + SMC 路径坍缩。
- **核心创新**：
  - **Target 层**：先在 reasoning 分布上轻度锐化（鼓励路径探索）→ 边际化 answer 概率 → 再单独锐化 answer marginal。Reasoning exponent α_r 弱 / Answer exponent α_a 强。
  - **Sampler 层**：**Fully Adapted Annealed SMC**（FA-ASMC）= annealed power target + locally fully adapted proposals + predictive ancestor resampling。
- **结果**：MATH500 / GPQA-Diamond / HumanEval / AIME24/25 上 3 个 base models，DMS 全部胜出，pass@1 最高。
- **意义**：Inference-time scaling 的新 SOTA，无 weight update / 无 reward model，纯 plug-in。
- 详见 [[2610.20483-Decoupled-Marginal-Sharpening]]

### W2-2. **STRATA: Self-Maintaining Structured Experience Graphs for Self-Evolving Language Agents** (2610.19386)
- **核心创新**：把 agent experience 组织成 **3 层 typed graph**（atomic skills / workflows / meta-frameworks）+ 5 个自维护机制共用一个 similarity geometry：
  1. multi-dimensional similarity（按 operation + target 评分）
  2. typed reflector（成功 → procedure，失败 → pitfalls）
  3. community detection → meta-frameworks
  4. pressure-triggered GC（articulation-point 保护）
  5. **contrast edges**（flag confusable but direction-opposite experiences）
- **两个 prior failure mode isolation**：
  - Single-level memory 在 task set 增大时 sharp drop
  - Concrete memories **catastrophic negative transfer**（similar 反向经验的步骤被 verbatim 抄）
  - Contrast edges 把 ScienceWorld **78.7 → 96.7**
- **结果**：AppWorld / WebArena / ALFWorld / ScienceWorld，2 backbones × 7 baselines 中 STRATA 平均最高 + 最低延迟 + 最少 steps + 比最强 baseline **少 44% injected memory lines**。
- 详见 [[2610.19386-STRATA-Self-Maintaining-Experience-Graphs]]

### W2-3. **ActICL: Post-Training for Agentic Multimodal In-Context Learning** (2610.19475)
- **解决痛点**：现有 multimodal ICL retrieval 一把抓所有 demo（冗余 + 噪声）；context-aware retrieval 不让 MLLM 自己学怎么 judge 需要新 demo。
- **核心创新**：训练一个 **MLLM agent** 自己分析 information gaps → 工具调用 targeted retrieval → progressive filter / refine → judge 足够后 hand off 给 answering model。
- **两阶段 post-training** 联合优化 acquisition + answering。
- **结果**：3 MLLMs × 7 benchmarks，平均 **+11.6pp over standard similarity retrieval**；**+4.4pp over strongest prior baseline**。
- **Transfer**：GPT-5.6-Sol 4-shot ICL 用 ActICL 提供的 context → **+3.5pp over standard retrieval**。
- 详见 [[2610.19475-ActICL-Agentic-Multimodal-ICL]]

### W2-4. **When Does Momentum Help in RLVR?** (2610.20413)
- **理论**：在 **bandit RLVR** + bias-corrected EMA momentum 下：
  - 精确 gradient：增大 EMA 系数 β（防 overshoot 范围）**严格加速优化**。
  - 采样 gradient：expected gain 被 sampling fluctuation 掩盖。**η↓ 时 gain 消失得更快**；保持 η/(1−β) 在 safe regime → gain 不消失。
- **实验验证**：
  - Qwen3-4B-Base SGD-EMA / AdamW 支持大 β
  - Qwen2.5-32B + AdamW：仅增大 β1 → validation accuracy **+~2pp**
- **意义**：为 LLM post-training 的 optimizer 配置提供 **principled** 指引；解释了 empirical "momentum 不 work" 现象是 hyperparameter regime 不当。
- 详见 [[2610.20413-When-Does-Momentum-Help-RLVR]]

### W2-5. **SRAT: Selective Retrieval-Augmented MT via Agentic RL** (2610.19528)
- **观察**：Translation 是 **partial-evidence regime** — LLM parametric knowledge 对很多 input 已足够，retrieval 只对一部分有用，且通常只是 support 而非直接给 translation。
- **核心创新**：
  - **SRAT** agentic RL framework，learn when to translate directly or retrieve + what evidence + how to integrate；优化 final translation quality。
  - **Retriever training**：joint **Plackett–Luce** + **translation-quality contrastive** training（不是 semantic similarity！）。
- **结果**：idiom / knowledge-intensive / doc-level translation × offline or online retrieval，SRAT 稳定优于 never/always retrieve；quality-aligned retriever 在 similarity-based retrieval 不足时带来更多增益。
- 详见 [[2610.19528-Selective-Retrieval-AUG-MT]]

### W2-6. **PrismaCoder: Open Multimodal Code Intelligence via Decomposed Rubric Synthesis** (2610.20538)
- **痛点**：开源 multimodal code 缺数据 + 缺 quality signal（execution = pass/fail / code similarity ≠ visual / task-specific verifiers 不通用）。
- **核心创新**：
  - **PrismaForge** = hierarchical data pipeline + **synthesized rubric**（把 correctness / construction / visual 分到 checkable criteria）。
  - 同一 rubric **双角色**：filter + reward（curate SFT corpus → 驱动 visual-coding RL）。
  - 产出 **PrismaCoder-2M**（最大 / 最 diverse open multimodal code 数据集）+ **PrismaCoder-9B / 35B**。
- **结果**：open SOTA 大幅领先；rival 头部 proprietary。Rubric pipeline 在多个 backbone 上稳定涨点。
- 详见 [[2610.20538-PrismaCoder-Multimodal-Code]]

### W2-7. **Latent Compaction with Test-Time Training** (2610.20582)
- **核心创新**：把 KV cache **本身当 neural network**，在 test time 用 **TTT** 学 compact doc-specific cache。
  - **初始化**：reconstruction importance + teacher attention + key-space diversity。
  - **训练两阶段**：① attention outputs + log-normalizers 拟合 full cache（recon-selected entries fixed）② 整 cache 联合优化（end-to-end distillation from full-cache）。
  - **Model weights frozen**；只用 generic doc prompts，不见下游 Q/A。
- **结果**：RULER / LongBench / Phonebook Lookup 大幅领先 budget-matched baseline；RULER 32× compression **96.7% vs KVZip+ 40.0%**；**跨 model scale / family**（Qwen3 + MiniCPM5）transfer。
- 详见 [[2610.20582-Latent-Compaction-TTT]]

### W2-8. **ForkGRPO: Efficient Exploration + Fine-Grained Credit for Diffusion LLM** (2610.19408)
- **痛点**：dLLM any-order 生成 entropy 退化 → 探索路径收窄；GRPO + L2R 仍 under-explore 中间态分支；trajectory-level advantage 对所有 token 一视同仁。
- **核心创新**：**ForkGRPO** 在 high-entropy intermediate state **沿 reference trajectory fork 出多条 continuation**（按 textual boundary 优先，共享 prefix）。
  - **Within-state group-relative advantage** 决定 reinforce 哪条 continuation。
  - **MC state-value differences** 决定哪个 reasoning segment 改善了 expected outcome。
- **结果**：4 benchmarks 中 3 个 SOTA；vs 直接对照 JustGRPO **+1.2pp**，**-27.8% tokens**；**ForkGRPO-Fast 2.49× wall-clock speedup**，accuracy 几乎无 loss。
- 详见 [[2610.19408-ForkGRPO-Diffusion-LM-RL]]

### W2-9. **PN-Mix: Pair-Norm Guided Mixed-Precision KV Cache Quantization** (2610.19605)
- **观察**：attention logit perturbation 分析在 RoPE channel-pair level 上揭示：**query–key pair-norm product 大的 channel pair** → quantization error 对 logit variation 贡献大。
- **核心创新**：**PN-Mix** 在 prefill 阶段一次识别 salient channel pairs → 解码阶段复用高 precision；其余用低 precision。
- **结果**：2.26-bit 平均精度在 reasoning / code / AIME 上 vs 2.32–2.39-bit prior mixed-precision baseline **相当或更好**；Pareto sweep 显示 PN-Mix **优雅降到 1.5 bit**，baseline 在 2.25 bit 以下 sharp drop。
- 详见 [[2610.19605-PN-Mix-Mixed-Precision-KV]]

### W2-10. **Cortex: Consolidating Context into Parametric Memory** (2610.20399)
- **思路**：受 biological systems consolidation 启发，formulate **Memory Consolidation (MC)**：internalize context-induced gains + preserve non-target capabilities；统一 context-specified editing / skill learning / behavioral steering。
- **核心创新**：**Cortex**
  - 生成 **prospective queries** 预测 context 使用方式
  - 把 context-conditioned outputs 蒸馏成 **mergeable LoRA / structural FFN updates**
- **5-task-family testbed** 测 consolidation + retention under single / batch / sequential updates。
- **结果**：4B–120B dense + MoE + text-only + multimodal backbones；14B 上 50 sequential factual edits 后 **Cortex-Structural 恢复 88.9% context-induced gain，保留 99.8% 非 target 性能**。Empirical consolidation–retention Pareto frontier。
- 详见 [[2610.20399-Cortex-Memory-Consolidation]]

### W2-11. **Moral Combat: Moral Foundations Theory Jailbreak** (2610.19587)
- **核心创新**：基于 **Moral Foundations Theory (MFT)** 的 multi-agent framework，**先 refuse 的 harmful prompt**：
  1. Diagnose 违反哪个 moral foundation
  2. Identify 该 prompt 在哪个 foundation 下显得 virtuous
  3. Rewrite prompt 到 virtuous framing
  4. Reinforce 用 generated precedents of comparable moral reframing
- **结果**：5 个 open-source + proprietary models × 3 well-known jailbreak datasets → 高 single-trial success rate，repeated attempts 进一步上升。
- **Safety 评估发现**：现有 safety benchmarks **MFT imbalanced**（concentrate 在 model 已 bias 的 foundation 上）→ benchmark 覆盖不全。
- 详见 [[2610.19587-Moral-Combat-MFT-Jailbreak]]

### W2-12. **RA²: Retain-Anchored Attraction for LLM Unlearning** (2610.19385)
- **痛点**：LLM unlearning 评估只看 target suppression + clean retain utility，**miss 局部失败模式**：forget-adjacent 提示（接近 forget domain 的 benign reasoning）性能下降 = **forget-adjacent utility loss**。
- **核心洞察**：unlearning 成功不仅在于 forget representations 离开 harmful computation，更在于 **redirect 方向**。
- **核心创新**：**RA²** 在 latent space 把 forget-token states **吸引到 nearby retain-supported representations**，同时保护高层 retain behavior。
- **结果**：WMDP + MUSE 上 higher forget-adjacent utility vs strong unlearning baselines（at similar broad-utility levels）。
- 详见 [[2610.19385-RA2-Retain-Anchored-Attraction]]

## 全日（24 篇）综合洞察

1. **Inference-time scaling 进入"解耦"时代**：上午 MemDuet 已是 plug-in 推理优化；下午 DMS 把推理时 scaling 的 target 也解耦（reasoning / answer 分别 sharpening）—— inference-time 优化开始分层。

3. **Cortex + STRATA 形成"memory 互补"**：Cortex 把 context 写入 parametric memory（fast + persistent），STRATA 在 working memory 上做 typed experience graph；两条路径并不竞争，而是不同 time-scale。
4. **KV cache 压缩路线分化**：Latent Compaction（TTT 把 cache 当 NN 学）vs PN-Mix（mixed-precision + RoPE pair-norm）—— 一个重算省 memory，一个少算保精度。

6. **Diffusion LM + RL 进展**：ForkGRPO 是 architecture-preserving RL 方法里性能/效率 trade-off 的 SOTA；为 dLLM reasoning 训练铺路。
7. **Multimodal code 数据飞轮**：PrismaCoder 用 rubric 把"程序正确 / 结构良好 / 视觉对" 三方面 unified scoring；rubric 同时做 filter + reward，data 与 model 同源。
8. **Safety jailbreak 与 unlearning 都在追"局部失败模式"**：Moral Combat 利用 MFT 漏洞；RA² 利用 forget-adjacent 漏洞。两个工作都揭示 **global metric 不能反映 local failure**。
