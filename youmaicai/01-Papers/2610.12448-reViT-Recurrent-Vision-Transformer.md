## 核心贡献

> 用单个 Transformer block **循环应用** 多次即匹配 full-depth ViT 精度，无需中间蒸馏；FFN 通过"归一化深度坐标"在小规模 expert bank 上插值，部署时可按需展开为 dense graph。

1. 提出 **reViT**：单一 Transformer block 复用多次，恢复 depth-specific 表征用 **FFN 在 expert bank 上的凸组合**。
2. **Normalized depth coordinate** 控制 mix：在 $(0,1]$ 区间内的连续值定义 FFN 参数空间的"resampleable trajectory"。
3. reViT-B/16 在 ImageNet-1k 上以约 **70% 更少参数** 达到 DeiT III 精度；8-expert 模型蒸馏后保留 DINOv2 teacher 几乎全部 linear-probe 精度。

---

## 技术方案

### 核心思想

传统 ViT 的多层 FFN 中存在大量冗余。reViT 把 depth 当成连续变量，每个 depth 对应一个"expert"，通过对 expert bank 做凸插值在循环过程中恢复各 depth 的语义。

### 关键技术

| 技术 | 说明 |
|------|------|
| Shared expert bank | $K$ 个 FFN 参数 $\{(W_k, b_k)\}_{k=1}^K$，远小于循环步数 $T$ |
| Depth-programmed mixture | depth $t$ 处的 FFN = $\sum_k \alpha_k(t) \cdot W_k$，$\alpha_k(t) = \text{softmax}(\beta_k \cdot t + \gamma_k)$ |
| Elastic-depth training | 一个 checkpoint 通过 resample depth coordinate 支持多种循环步数 |
| Dense materialization | 部署时把循环 block 展开为传统 dense graph，移除 runtime routing |

### 公式

```math
\text{FFN}_t(x) = \sum_{k=1}^{K} \text{softmax}(\beta_k t + \gamma_k)_k \cdot W_k x + b_k
```

其中 $t \in (0, 1]$ 是归一化深度，$\beta_k, \gamma_k$ 为可学习参数（per-expert）。

## 代码片段

```python
# reViT depth-programmed FFN
class DepthProgrammedFFN(nn.Module):
    def __init__(self, experts, dim):
        super().__init__()
        self.W = nn.Parameter(torch.stack([e.weight for e in experts]))  # [K, dim, hidden]
        self.b = nn.Parameter(torch.stack([e.bias for e in experts]))    # [K, hidden]
        self.beta = nn.Parameter(torch.zeros(len(experts)))
        self.gamma = nn.Parameter(torch.arange(len(experts)).float())

    def forward(self, x, t):  # t in (0,1]
        alpha = F.softmax(self.beta * t + self.gamma, dim=0)            # [K]
        W = torch.einsum('k,kdh->dh', alpha, self.W)
        b = torch.einsum('k,kd->d', alpha, self.b)
        return F.relu(F.linear(x, W, b))
```

## 实验结论

- **数据集**: ImageNet-1k（监督训练）/ DINOv2 蒸馏
- **基线**: DeiT III、DINOv2
- **结果**:
  - reViT-B/16 ≈ DeiT III acc，参数减少 ~70%
  - 8-expert distillation → 几乎完全保留 DINOv2 linear-probe 精度
  - Elastic-depth：单 checkpoint 支持多深度，部署灵活

---

## 局限性

- 仍需在 inference 时执行 $T$ 次循环，延迟并不天然低。
- Expert bank 大小 $K$ 是新超参，与最佳 $T$ 的耦合需额外调优。
- 主要在视觉领域验证，迁移到 LLM（参数量级更大）需要进一步探索。

- **适用场景**: 多模态 LLM 的视觉 encoder 压缩、移动端/边缘部署、Elastic inference
