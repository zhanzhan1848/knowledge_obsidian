## 核心贡献

> Trofinetide（2023 批准的 Rett 综合征首个治疗）缺乏 scalable real-world monitoring（chart review 人工密集）。

1. 开发 **双 LLM consensus pipeline**：
   - 提取 **18 个 treatment-response 表型** = 4 AEs + 13 Rett clinical features + medication refusal
   - 数据：26,763 notes / 108 patients（Texas Children's Hospital）
2. Pipeline：
   - Keyword 过滤 notes
   - **双 LLM 分类 + consensus**
   - Patient-by-timepoint matrix aggregation
3. **方法论**：
   - 在 diarrhea dev set 上选架构 + prompt → **冻结**
   - 应用到其他 17 表型（冻结保证一致性）

## 关键洞察

- **Dual-LLM consensus** 是医疗 NLP 中**高精度**提取结构的实用模式。
- **Freezing 架构 + prompt** 是 systematic medical phenotype extraction 的方法论纪律。
- 罕见病 Rett 综合征的真实世界数据处理范式。
