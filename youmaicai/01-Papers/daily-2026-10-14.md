## 重点论文（12 篇）

### 1. **DoubtLess: Training-Free Contrastive Decoding for Efficient Reasoning** (2610.18862)
- 小 reasoning 模型 *两次前向*（brief / verbose）logit 差分注入大模型 logits → CoT 缩短。
- Qwen3-32B 7 benchmark **CoT -31%** accuracy 不变；跨 2 模型族泛化。
- Self-debugging 编码 agent thinking tokens **-20%** 性能持平。
- 详见 [[2610.18862-DoubtLess-Contrastive-Decoding-Reasoning]]

### 2. **Hybrid Reasoning Agents** (2610.18861)
- 统一生成流：latent ↔ text 动态切换；HybridLink + continuous working memory。
- HybridSFT + HybridRL 训练何时在 latent、text 行动。
- 3 规模 × 11 benchmark **+10.4%** 一致 vs SOTA，token **-35.5%-54.7%**，inference **1.8-2.6×**。
- 详见 [[2610.18861-HybridAgents-Latent-Text-Reasoning]]

### 3. **Read the Room Before Your Model Generates** (2610.18820)
- Scenario-Actor：从 transformer hidden state 提取 *scenario embedding*，几何可解释地适配 temperature。
- Llama-3.1-8B 在 interactive social / open-ended instruction-following 显著超 baseline。
- 详见 原文（[arXiv:2610.18820](https://arxiv.org/abs/2610.18820)）

### 4. **SkillScaffold: Policy-Adaptive Skill Credit Assignment** (2610.18807)
- Reuse outcome-verified 轨迹生成 candidate skill → outcome-aware likelihood 估效用。
- Selective injection：没 help 就 skill-free；alike *abstention*。
- ALFWorld / WebShop / ScienceWorld / τ²-Bench 一致超 strong agentic-RL + skill-based RL baseline。
- 详见 [[2610.18807-SkillScaffold-Agentic-RL-Credit]]

### 5. **BLADE: Auditing Information Use for Failure Attribution in Multi-Agent** (2610.18780)
- 从"trace 信息流向"升级到"audit 信息使用"——区分 *introduction / propagation / repair*。
- Jev probabilistic judgments + dependency prob 选择 handoff。
- 1,228 failed runs，5 个 Who&When / Who&When Pro，**step acc SOTA / tied**，超 All-at-once **2.2-11.1 pp**。
- 详见 [[2610.18780-BLADE-Failure-Attribution-MultiAgent]]

### 6. **ReVeR: Pointwise Rubric Rewards with Tool-Augmented Judges** (2610.18766)
- Rubric 只看 instruction（避免 response-induced bias）；judge tool-augmented + pointwise。
- Label-blind distillation 生成 ReVeR-Traces 大数据集。
- 关键发现：**preference accuracy 与 downstream policy utility 解耦**。
- 详见 [[2610.18766-ReVeR-Pointwise-Rubric-Rewards]]

### 7. **Does self-distillation improve reasoning?** (2610.18613)
- 重新审视 SDPO / OPSD：报告的 gains 主要是 OOD 泛化失败 + 现有 reasoning transfer。
- Gradient 与 true reward gradient 对齐很弱。
- Qwen3 (1.7B-14B) + OLMo-3-7B 均 confirm；effectively leveraging privileged info 仍是 open。
- 详见 [[2610.18613-Does-Self-Distillation-Improve-Reasoning]]

### 8. **DDRG: Beyond Answer Voting via Graph Alignment** (2610.18606)
- 从 sampled traces 构建 source-grounded claim graph → 暴露 claim-level disagreement。
- Answer-blind verifier 做 selective repair；不扩大 candidate bank。
- Qwen2.5-7B **+8.65 pp**、Llama3.1-8B **+15.83 pp** macro avg over 5 benchmark。
- 详见 [[2610.18606-DDRG-Graph-Alignment-Reasoning]]

### 9. **PORTAL: Rethinking Projector Training in MLLMs** (2610.18598)
- Projector 训练 = 粗对齐：10-20% 数据即可 + 不同 projector 可线性插值保留性能。
- PORTAL：基于 Gaussian + optimal transport 的 *训练免费* projector 初始化。
- 6 LLM × 2 vision encoder × 16 benchmark：3/7 设置超 558k 对齐训练 pipeline。
- 详见 [[2610.18598-PORTAL-Training-Free-Projector-MLLMs]]

### 10. **Imprinting: Knowledge Distillation Can Shift Student Behavior** (2610.18517)
- 同 base 教师的两安全姿态（harm-accepting vs harm-avoiding）用普通 reasoning 数据 KD。
- 学生 harm-pragmatism 向教师 *imprinting*——超出任务能力传递。
- Sparse divergence token 排除可削弱；post-DPO 提升但 *不消除* source gap。
- 详见 [[2610.18517-Imprinting-Knowledge-Distillation-Behavior]]

### 11. **MultiAlloc: Budget-Aware Precision Allocation for KV Cache Quantization** (2610.18642)
- Lightweight offline profiling → layer sensitivity + token importance。
- 自适应在 layer-wise / token-wise 之间分配 KV budget；无 online search。
- Mistral / Llama / DeepSeek-Qwen / QwQ 一致超 single-granularity baseline。
- 详见 [[2610.18642-MultiAlloc-Budget-Aware-KV-Quantization]]

### 12. **Graph Metanetworks for Transformer Based Language Models** (2610.18471)
- 首次 symmetry-aware graph metanetwork 完整覆盖 *decoder-only LM* 权重空间对称群。
- Neuron permutation + attention GL 对称 + head permutation + token embedding。
- 2 个新 population dataset：training-corpus prediction, fine-tuning detection。
- 详见 [[2610.18471-Graph-Metanetworks-LMs]]

### 13. **Multi-Stream Residual Computation in Diffusion LMs** (2610.18407)
- 2 streams 让 reconstruction PPL **-5.71%** (val), **-5.13%** (avg external)。
- Adaptive routing 自然学会 visible=read / masked=write；role-conditioned routing 恢复 half gain。
- Scale up 验证。
- 详见 [[2610.18407-Multi-Stream-Residual-Diffusion-LMs]]

### 14. **RePara: Reinforcing Parallelism in Diffusion LLMs** (2610.18200)
- 4 个 diffusion LM 在 16 tokens/step 下 math/code 全部 <15% → parallel 优势被高估。
- Token-level probe：math 局部 prefix 有强 predictive potential。
- RePara：GRPO 强化 short consecutive blocks，**1.96×** training-step speedup。
- 详见 [[2610.18200-RePara-Parallelism-Diffusion-LLMs]]

### 15. **ProAS: Progress-Aware Advantage Shaping for Multi-Turn Agentic RL** (2610.18683)
- Agentic Reference Graph (ARG) 表达 sub-task structure。
- MUI 遮蔽 + APR 不对称 penalty redistribution；plug-and-play on GRPO-class。
- ALFWorld **91.9% / 94.3%**；WebShop **66.7% / 70.8%**；**2.44×** convergence speedup。
- 详见 [[2610.18683-ProAS-Progress-Aware-Advantage-Shaping]]

## 关键洞察

1. **Hybrid latent + text reasoning 是 agent 主线方向**：HybridAgents 把 latent 思考和 text 行动融合到单一生成流，是 *Coconut / DeepSeek-R1* 路线的合流版本。SkillScaffold + ProAS 同步强化 multi-turn 训练信号工程——三者一起勾画出 2027 即将普及的 agent 训练范式。
2. **Credit assignment 仍是最核心挑战**：BLADE（multi-agent 失败归因）、ProAS（multi-turn advantage shaping）、SkillScaffold（skill 效用）、DDRG（claim-level repair）——四条不同路径都指向"如何精确把信号分到对的 action 上"。
3. **训练免费 / 推理优化方向多元化**：DoubtLess（小模型对比解码）、MultiAlloc（KV budget 分配）、PORTAL（最优传输 projector 初始化）都展示了 *无需 gradient* 的精巧方案。这一方向在 production 部署价值显著。
4. **Diffusion LM 的架构与训练改进是热点**：Multi-Stream Residual 与 RePara 分别从 *架构*（多 stream + routing）和 *训练*（short-block GRPO）两个层面推进 diffusion LM 的 quality + efficiency。
5. **Critical re-evaluation 增多**：Does SD Improve Reasoning 与 Imprinting 都对被报告的 SOTA 方法做严格审视——前者指出 gains 主要是 overfit / transfer，后者揭示 KD 隐含 safety transfer。提醒部署前的 reproduction & OOD 验证至关重要。
6. **Reward / rubric fidelity 是独立属性**：ReVeR 显示 preference accuracy、rubric fidelity、downstream utility 是 *三个独立属性*——为未来 reward model 设计提供新的分解维度。
8. **Projector 训练可能是被高估的工程步骤**：PORTAL 用 OT + statistics 完成训练免费初始化——降低自建 MLLM 的 compute barrier，与 Idefics / LLaVA 等传统 pipeline 形成对比。
