## 核心贡献

> 提出 **SAFE-QE**（Subsequence-Association Filtered, breadth-aware query expansion）：基于 subsequence-association 视角解释 LLM 幻觉扩张项，并给出训练无关的过滤方法。

1. **机制视角**: 幻觉扩张源于"dominant hallucinatory associations"被反复激活
2. **新指标 HET Rate**: 计数无 relevant document 支持的扩张项
3. **数据**: 在 TREC/BEIR 上 nDCG@10 与生成式/语料导向扩张相当，但 unsupported terms 4.3/query vs Query2doc 27.8 / HyDE 57.5

---

## 技术方案

### 核心思想

LLM 用于 query expansion 时会 hallucinate 不存在的实体/离题 term。现有修复（语料 grounding / 互相验证 / 偏好对齐）只把它们当作一致 nuisance 过滤。SAFE-QE 给每个扩张项打"corpus-conditioned cross-context reproducibility"分：随机化查询上下文下反复出现但**伪相关集中无支持**的 term = dominant hallucinatory association。

### 关键技术

| 技术 | 说明 |
|------|------|
| Subsequence-association account | 幻觉生成的机制视角 |
| Cross-context reproducibility | 随机化查询上下文后 term 是否重现 |
| Constrained coverage maximization | term 选择 = 伪相关集上约束覆盖最大化 |
| Hallucinated Expansion Term Rate (HET) | 评估指标 |
| Training-free | 无需训练，可即插即用 |

### 关键伪代码

```text
for candidate term t:
    score(t) = corpus_conditioned_cross_context_reproducibility(t)
    if t lacks support in pseudo-relevant set:
        score(t) *= downweight_factor
select terms to maximize coverage(stays) subject to consistency
```

## 实验结论

- **数据集**: TREC + BEIR
- **基线**: Query2doc, HyDE, 语料导向扩张
- **结果**:
  - nDCG@10 **statistically indistinguishable** from generative/corpus-steered
  - Unsupported terms per query:
    - **SAFE-QE: 4.3**
    - Query2doc: 27.8
    - HyDE: 57.5
  - 在 learned sparse retriever 上所有方法都 regression → faithfulness 不付 ranking 代价

---

## 局限性

- Subsequence-association 视角是机制解释而非因果证明
- 在 learned sparse retriever 上所有方法都退化，需新适配
- Pseudo-relevant set 质量依赖初始 retrieval

---

## 实现建议

- **实现难度**: 低（训练无关）
- **预期性能**: 减少 80%+ 不支持 term，ranking 持平
- **适用场景**: LLM-based query expansion、retrieval pipeline、RAG
