# Evaluating Token Probabilities as Confidence Estimators in Human Behavior Simulations: A Case Study in Luxembourgish Next Like Prediction

### 核心贡献
1. 论证当前用 LLM 模拟人类行为时，其 operational validity 通常仅以 accuracy 评估，隐含地把人类行为当作确定性过程；而在含噪的数字痕迹数据上，模型表现不仅取决于预测对错，更取决于其**校准（calibration）**。
2. 以卢森堡新闻平台的 Next Like Prediction 任务为案例，检验 open-weight LLM 的 token 概率能否充当 confidence estimate——即在预测用户会给某条评论点多少个 like（以用户先前交互为条件）时提供可信度。
3. 实证发现 accuracy 与 calibration **不同步**：从 3B 扩到 8B 提升 accuracy 却恶化校准；更长的行为历史提升 accuracy 却降低置信度。
4. 指出 task-specific SFT 是一种有效的校准干预手段：Expected Calibration Error 从 **0.2 降到 0.006**，同时 accuracy 从 **0.536 提升到 0.758**。

### 技术方案
**核心思想**: 把 token 概率当作免训练的置信度来源来检验其作为「agent 自我报告的把握程度」的可靠性，并系统考察模型规模、上下文行为历史长度与任务微调三个因素对 accuracy 与 calibration 的差异化影响。

| 技术 | 说明 |
|------|------|
| 任务设定 | Next Like Prediction：基于用户历史交互，预测其对某条评论的 like 评分（卢森堡语新闻平台 this http URL） |
| Confidence estimator | 直接取 open-weight LLM 的 token probabilities 作为置信度估计 |
| 被测模型 | Ministral 3 (3B, 8B)，仅用 in-context learning（无微调） |
| 对照基线 | 一个简单的统计基线（simple statistical baseline），在 accuracy 与 calibration 两项上均超过所测 LLM |
| 变量扫描 | 模型规模（3B → 8B）、行为历史长度（longer behavioral histories）两个维度的独立考察 |
| 校准干预 | task-specific supervised fine-tuning |
| 校准指标 | Expected Calibration Error (ECE) |

### 实验结果
- **数据集**: 卢森堡语新闻平台上的真实用户评论交互数据（Next Like Prediction 任务，具体规模摘要未说明）
- **基线**: 简单的统计基线（simple statistical baseline）；并对比 Ministral 3 3B 与 8B 两个规模
- **结果**: 仅用 in-context learning 时，被测模型 **overconfident**，且在 accuracy 与 calibration 上**双双被简单统计基线击败**；3B→8B 使 accuracy 提升但 calibration 恶化；更长的行为历史提升 accuracy 但 confidence 下降；task-specific SFT 使 ECE 从 **0.2 → 0.006**，accuracy 从 **0.536 → 0.758**

### 局限性
- 单案例研究（case study），仅覆盖 Next Like Prediction 一个卢森堡语平台的互动任务与 Ministral 3 两个模型（3B/8B），结论泛化性有限。
- 仅依赖 in-context learning 时的 token 概率，未考察其它免训练置信度来源（如 entropy、self-consistency、verbalized confidence）。
- SFT 后的校准提升未做 out-of-distribution 泛化测试，无法判断是「校准」还是「过拟合到该数据分布」。
- 摘要未说明数据规模、用户/评论数量、行为历史长度的具体取值，以及「简单统计基线」的具体构造方式（这直接影响其说服力）。

### 关键洞见
> 论文揭示了一个反直觉的规律：**模型变大、上下文变多，行为预测会更准却更不可信**。3B→8B 提升了 accuracy 却恶化 calibration，喂更长历史同样如此——因为更多历史让模型输出分布更尖锐（更少犹豫），token 概率随之虚高，但真正的不确定性（人类点赞行为的内在随机性）并未减少。这对「用 LLM 做人群行为模拟」的研究是一个方法论警告：只用 accuracy 报告结果，会系统性地把过度自信的模型当成更好的模拟器；并且它也指出出路——免训练置信度不可靠，任务微调同时修好了两者（ECE 0.2→0.006 且 accuracy 0.536→0.758）。
