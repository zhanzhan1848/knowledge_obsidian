## 核心贡献

> Web 系统越来越多从 language models 读 **System One 决策**（一次 forward，不生成 reasoning，返回 distribution over options）。Web 中 listing 与 option set 由其他组件决定，**易变 + 可被操纵**。

1. 识别两个**理性选择公理**作为 System One 模型的**自然要求**：
   - **顺序无关性**：option 列出顺序不应影响结果
   - **对手无关性 (Luce's choice axiom)**：增加 option 不应改变其他 option 的相对 odds
2. 测试**标准做法**（SCQ prompting + 各种 trick）：
   - shuffled-order training
   - order averaging
   - sorted options
   - invariant set architecture
3. 揭示当前做法**系统性地违反**这两个公理。

---

## 技术方案

### 现象：position bias / rival sensitivity
- LLM scoring 强烈依赖 option 顺序。
- 加入新 option 显著改变其他 option 的 odds。
- Web 上 → **listing 操纵** / **adversarial injection** 改变决策结果。

### 公理
```
1. Position Independence: f(O) = f(permute(O))  (modulo tie-breaking)
2. Rival Independence (Luce):  f(O ∪ {x}) / f(O) = constant in x
```

### 测试的标准方法
- **SCQ prompting**（"choose A/B/C"）
- **shuffled-order training**
- **order averaging at inference**
- **sorted options**（按字母序 / 长度）
- **invariant set architecture**

### 结果
- 全部**违反**至少一条公理。
- 没有银弹。

---

## 实验结论

- Web-system benchmarks 上 position bias 显著（高达 30% 顺序敏感）。
- Rival injection (加入无关 option) 系统性改变决策分布。
- 当前 mitigation **不够**。

---

## 关键洞察

- **LM-as-decision-engine** vs **LM-as-chatbot** 的根本差异：**决策必须满足选择公理**。
- Web 系统信任 LM 决策的前提：bias / irreducible bias 必须在可控范围。
- 提出新研究方向：**设计真正满足公理的 scoring head**（不是 wrap-around mitigation）。
