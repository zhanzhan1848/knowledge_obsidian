# Rare, Relevant, and Still Wrong: How Memory Fails LLM Group Decisions

## 核心贡献

> **当多 agent 的讨论被压缩成给最终决策者的一段简短记忆时，「保留最罕见的」和「保留最相关的」两种直觉启发式——都会以可预测的方式失败。** 决定准确率的是**记忆里保留的证据的平衡**，而不是**保留它的策略**。

1. **问题**：把 LLM 群体的讨论压缩成简短记忆交给最终决策者时，记忆该保留什么？两个自然启发式：
   - **保留最罕见的说法**（rarest-first）
   - **保留与决策标准最相关的说法**（relevance-first）
2. **识别核心混淆**：在 hidden-profile 任务上，**两者看起来都不错** —— 因为「一个事实被多广泛持有」与「它是否有帮助」是**混淆的（confounded）**。
3. **提出 CrossProfile 诊断基准**：
   - **60 个模板**，带**自动验证的答案键**
   - **交叉了支持性事实、诱饵（decoy）事实、无关事实的「归属（ownership）」，同时保持其文本固定** —— 共 **480 个任务**
   - ⇒ 这样才能把「谁说的」与「说了什么」**解耦**
4. **核心发现（跨 Qwen2.5-7B、Llama-3.1-8B、2 个 DeepSeek 模型）**：
   - **按相关性选择会重新放回诱饵** —— 因为诱饵**也是切题的**。即使完美的相关性过滤器，在经典 hidden-profile 配置下**也比 rarest-first 低 23 到 31 分**
   - **Rarest-first 平均而言并不比随机选择更好**，只在罕见事实恰好是有用事实的地方才赢
   - **两种情况下，准确率都跟随「记忆保留的证据的平衡」，而不是「保留它的策略」**
5. **决策模型引入第三种失败 —— 社会认同（social proof）**：
   - 它**对「被归因于许多 agent」的事实赋予额外权重**
   - **移除归属标签**（或**随机重分配**归属标签而保持行序固定），在经典配置下**准确率提升 13 到 24 分**
6. **自然讨论中的真相更糟**：**完整转录本的准确率低于完全不做笔记** —— 证据在记忆机制起作用之前就已经丢失了

## 技术方案

### 核心思想

要用记忆做决策，你必须区分「这个事实是什么」与「谁说的」。两个启发式都混淆了这两者。而**唯一有效的量是：记忆里保留的支持性证据与诱饵证据的比例**。

```text
hidden-profile 任务中的混淆:
   「多数 agent 说」 ⟂ 「事实有用」
        ↑ 两者相关 ⟶ 两个启发式都看起来可行

CrossProfile 的解耦:
   固定事实文本，交叉其归属 → 「谁说的」与「说了什么」独立变化
   ⇒ 可以干净地测量策略差异
```

### 关键技术

| 技术 | 说明 |
|------|------|
| **CrossProfile 基准** | 60 模板 × 自动验证答案键，480 任务 |
| **归属交叉（ownership crossing）** | 打乱事实归属，保持文本固定 |
| **Rarest-first 策略** | 保留最少被持有的说法 |
| **Relevance-first 策略** | 保留与决策标准最相关的说法 |
| **社会认同（social proof）** | 决策模型对「多 agent 归因」的加权 |
| **归属标签消融** | 移除或随机重分配归因 |
| **完整转录本 vs 无笔记** | 对照「不过度压缩」与「完全不记」 |

## 公式

```math
\text{证据平衡（决定准确率的量）}:\quad
\Delta \;=\; \frac{\#\{\text{支持性证据保留}\} - \#\{\text{诱饵证据保留}\}}
{\#\{\text{总保留}\} \;+\; \#\{\text{丢失证据}\} + 1}
```

```math
\text{社会认同加权}:\quad
w(x) \;=\; \underbrace{1}_{\text{基础}} \;+\; \lambda \cdot \underbrace{\frac{n(x)}{N}}_{\text{声称持有该事实的 agent 数}}
\qquad (\text{决策模型的行为})
```

```math
\text{解耦设计（CrossProfile 核心）}:\quad
\text{文本}(f) \text{ 固定} \quad\wedge\quad
\text{归属}(f) \in \{\text{support}, \text{decoy}, \text{irrelevant}\} \text{ 独立交叉}
\;\Longrightarrow\;
\mathbb{E}[\text{准确率}] \text{ 仅取决于 } \Delta
```

```math
\text{归属效应}:\quad
\text{Acc}(\text{with tags}) \;-\; \text{Acc}(\text{tags removed / randomized})
\;=\; 13 \sim 24 \text{ 分}
```

## 代码片段

```python
# 概念性伪代码：CrossProfile 基准构造与记忆策略比较
import random
from dataclasses import dataclass

@dataclass
class Fact:
    text: str              # 固定文本
    content_role: str      # "support" | "decoy" | "irrelevant"  —— 内容真相
    attributed_to: list    # 声称持有该事实的 agent 列表 —— 归属（可被操纵）

def build_crossprofile(templates, n_tasks=480):
    #     关键：content_role 与 attributed_to 独立交叉，
    #     使「谁说的」与「说了什么」解耦。
    tasks = []
    for tpl in templates:
        for attribution in attribution_patterns(tpl):
            facts = []
            for f in tpl.facts:
                facts.append(Fact(
                    text=f.text,                       # 文本固定不变
                    content_role=f.content_role,       # 真相固定不变
                    attributed_to=assign_attribution(f, attribution),  # 归属交叉
                ))
            tasks.append({"facts": facts, "profile": tpl.profile,
                          "answer_key": tpl.answer_key})
            if len(tasks) >= n_tasks:
                return tasks
    return tasks


# ---- 记忆策略 ----
def rarest_first(facts):
    # 保留最少被持有的说法。
    return sorted(facts, key=lambda f: len(f.attributed_to))[:k]

def relevance_first(facts, criteria):
    # 保留与决策标准最相关的说法 —— 但诱饵也是切题的。
    return sorted(facts, key=lambda f: relevance(f.text, criteria), reverse=True)[:k]

def random_first(facts):
    return random.sample(facts, k)


# ---- 关键测量：证据平衡，而非策略 ----
def evidence_balance(memory, truth):
    # 准确率的真正驱动因素。
    s = sum(1 for f in memory if f.content_role == "support")
    d = sum(1 for f in memory if f.content_role == "decoy")
    return (s - d) / (len(memory) + 1)


# ---- 社会认同消融 ----
def ablate_attribution(facts, mode):
    # mode: "keep" | "remove" | "randomize"（保持行序固定）
    if mode == "remove":
        return [Fact(f.text, f.content_role, []) for f in facts]
    if mode == "randomize":
        out = []
        for f in facts:
            n = len(f.attributed_to)
            out.append(Fact(f.text, f.content_role,
                            random.sample(["A","B","C","D"], n)))
        return out
    return facts
```

## 实验结论

- **基准**: **CrossProfile**（60 模板，480 任务，自动验证答案键）
- **模型**: Qwen2.5-7B, Llama-3.1-8B, 2 个 DeepSeek 模型

| 观察 | 结果 |
|------|------|
| **完美相关性过滤器 vs rarest-first** | **相关性低 23–31 分**（经典 hidden-profile 配置） |
| **Rarest-first vs 随机** | **平均不优于随机**，仅在罕见事实恰好有用时赢 |
| **准确率的真正驱动** | **证据的平衡（Δ），而非保留策略** |
| **移除/随机重分配归属标签** | **准确率 +13 到 +24 分** |
| **完整转录本 vs 完全不记笔记** | **转录本反而更差** —— 证据在记忆生效前就丢了 |

## 局限性

1. **合成基准** —— CrossProfile 是构造的 hidden-profile 模板，**不是真实多 agent 讨论**；真实性/生态效度存疑
2. **模型规模偏小** —— 7B/8B + 2 个 DeepSeek，未验证更大模型（尤其前沿模型）是否有同样的社会认同脆弱性
3. **「转录本反而更差」的机制未解释** —— 摘要未说明为什么完整信息反而有害（长度导致的注意力稀释？还是长上下文位置效应？）这其实是最值得追的线索
4. **未涉及摘要压缩算法本身** —— 测的是「保留哪些事实」的选择策略，不是「如何压缩」的算法。真实系统用 LLM 摘要，而摘要可能引入新的错误（**摘要幻觉**）
5. **Δ 作为「唯一驱动」是经验观察** —— 未做因果检验（是否只是相关？）
6. **移除归属标签这一建议的可操作性有限** —— 真实场景中「谁说的」是真实信息（不同专家角色的意见权重本就该不同）
7. **未涉及提示注入/虚假归属的攻击面** —— 若攻击者能伪造归属标签，会怎样？

## 实现建议

- **实现难度**: 中（基准构造需要仔细设计；策略实现简单）
- **预期性能**: 揭示问题而非提升性能；**归属标签消融可带来 13-24 分提升**
- **适用场景**: **多 agent 汇聚共识的系统** —— 研究流水线、多专家评审、辩论式系统、委员会式决策
- **落地注意**:
  1. **优先级最高的单一行动：处理归属标签** —— 如果你的系统让决策模型看到「哪个 agent 说了这个」，先测一下移除或随机化标签的影响。这是低成本高回报的一步
  2. **不要只按「相关性」选事实** —— 诱饵同样切题，这一点非常反直觉但证据充分
  3. **警惕摘要环节** —— 本文测的是选择，但真实系统会先做摘要。摘要可能引入错误事实，**建议单独评估摘要环节的事实保真度**
  4. **值得自测「完整转录本 vs 不记笔记」** —— 如果你的系统里长上下文导致表现下降，这篇给了你一个诊断视角（证据在压缩前就丢了）
  5. **隐藏权衡** —— 移除归属标签会丢信息。适合**同质 agent** 群体，不适合**专家角色确实不同**的场景

## 我的评注

> 这篇的方法学价值远高于它的技术含量，而方法学恰恰是它最漂亮的地方。
>
> **CrossProfile 的核心是解耦**。在真实 hidden-profile 任务里，「这个事实被几个人持有」和「这个事实是否有用」是**混淆的** —— 所以两个启发式都能「看起来работать」，你无法判断哪个真的更好。CrossProfile 通过**固定事实文本、只交叉归属**，把这两个变量拆开了。**只有解耦之后，「相关性会放回诱饵」这个结论才能被干净地测出来** —— 而这个结论恰恰是最反直觉的。
>
> 最震撼的数字是 **23–31 分**。一个「完美的相关性过滤器」比「rarest-first」差这么多。原因也很清楚：**诱饵之所以有效，正是因为它切题**。相关性是「切题程度」的度量，而诱饵在切题程度上**和高价值证据一样高** —— 它们只是在内容真伪上有区别，而相关性判断器**根本不看真伪**（它无从得知）。所以相关性过滤器在原理上就注定失败。这个逻辑一旦想通，就很難反驳。
>
> **社会认同那一节是本文真正的贡献**。决策模型对「很多人这么说」加权，这是**人类推理里众所周知的谬误**，LLM 继承了它。移除或随机重分配归属标签能涨 13–24 分 —— 这说明**在这个设定下，归属信息几乎全是噪声，甚至是有害噪声**。
>
> 但最后那个发现才是最刺痛我的：**完整转录本的准确率低于完全不做笔记**。这直接反驳了「上下文越长越好」的默认直觉，也挑战了当前 agent 系统的核心操作范式 —— 保留完整历史。如果确实如此，那么 agent 框架里精心设计的上下文压缩机制，可能在**某些任务类型上是有害的**。摘要没解释原因，但这个现象值得任何做 agent 的人亲自验证一遍。
>
> 保留意见：**合成基准**。hidden-profile 模板虽是经典范式，但真实多 agent 讨论有噪声、有动态争论、有中途改变立场 —— 这些 CrossProfile 都没有。而且模型规模偏小，我不确定前沿模型的社会认同脆弱性是否一样强（更大的模型可能更能抵抗这种谬误）。
>
> 落地判断：**低成本、高回报**。最值得立刻做的实验是「把归属标签打乱，看你的多 agent 系统掉多少分」—— 如果掉得多，你的系统正在被社会认同劫持。
