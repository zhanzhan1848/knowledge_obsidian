## 核心贡献

> 提出 **TIPS** —— 一个 **~600K 参数 controller**，frozen masked DLM 上**学 when to reveal/reconsider tokens**。Supervised warmup + RL on terminal correctness rewards。**LLaDA-8B-Instruct** 上 GSM8K + MATH-500 在 32 evaluations budget 下达 **58.46% (full-canvas) / 57.97% (two-block)**，**超最强 baseline +12.1 / +11.6 pp**。**预算外推广**：训练于 32 evals，无需重训在更高 budget 仍 competitive。

1. **600K param controller** —— 学 unmask + remask policy。
2. **Frozen LM** —— 底层语言模型不变。
3. **可见性感知 features + 浅 transformer** —— 选哪些 token 变 visible。
4. **训练**：supervised warmup + RL on terminal correctness rewards。
5. **预算外推广**：训练 budget 32 → higher budget 无需重训仍 competitive。

---

## 技术方案

### Motivation

- Masked diffusion LM 暴露 inference-time 决策**：哪些位置在 denoising pass 后变 visible**。
- 现有方法：hand-designed rules 或 monotonic visibility growth。
- → 想要 learnable policy。

### TIPS 架构

```
Frozen Masked DLM (LLaDA-8B-Instruct)
        ↑
        │ (gets visibility information)
        ↓
TIPS Controller (~600K params)
  - Visibility-aware confidence features
  - Shallow transformer
  - Output: which tokens to unmask/remask
        ↑
Fixed schedule (controls expected visible fraction)
```

### 关键组件

| 组件 | 作用 |
|------|------|
| **Visibility-aware confidence features** | TIPS 知道哪些 token 当前 visible |
| **Shallow transformer** | 学 unmask/remask decision |
| **Fixed schedule** | 控制 expected visible fraction（避免过/欠 reveal） |

### 训练

#### Stage 1: Supervised Warmup

- 用 hand-designed rules 生成 supervision
- 让 controller 学习 basic unmask/remask 行为

#### Stage 2: RL on Terminal Correctness Rewards

- 在 (question, answer) pair 上：
  - TIPS 控制 decode process
  - Reward = **terminal correctness**（最终答案对不对）
- 直接优化**最终正确率**

### 两种 Variant

- **Full-canvas TIPS**：所有 token 共享 controller
- **Two-block TIPS**：canvas 分为两块（独立 unmask/remask 决策）

---

## 实验结果

### Setting

- **Backbone**: LLaDA-8B-Instruct
- **Benchmark**: GSM8K + MATH-500
- **Budget**: 32 decoder evaluations
- **Variants**: full-canvas / two-block

### 关键数据

| Variant | Micro-Avg Accuracy | vs Strongest Baseline |
|---------|-------------------|----------------------|
| **Full-canvas TIPS** | **58.46%** | **+12.1 pp** |
| **Two-block TIPS** | **57.97%** | **+11.6 pp** |

### Budget Generalization

- 训练于 **32 evals**
- 在 higher budget 下 **无需重训仍 competitive**
- → 学到的 policy 有 budget-robust 性

### 与 Baseline 对比

- Hand-designed rules
- Monotonic visibility growth methods
- → TIPS 均超

---

## 局限与展望

- 仅 LLaDA-8B-Instruct backbone → 其他 DLM (SEDD, MDLM) 未验证。
- 仅 600K param controller → scaling 与 ablation 有限。
- "Shallow transformer" 架构 → 更深 / 更宽是否 gain？
- Fixed schedule 仍需 hand design → 自适应 schedule 未做。
- Non-math task (creative writing, code) 未验证。

## 实现建议

- **实现难度**: 中（需要 DLM inference infra + RL on terminal rewards + 600K policy）
- **预期性能**: GSM8K + MATH-500 +11-12 pp
- **适用场景**:
  - **Math reasoning DLM**（where terminal reward is clear）
  - **Code generation DLM**（testable correctness）
  - **批量 evaluation 场景**（fixed budget → policy transferable）
- **不适用**:
  - 非 verifiable 任务（无 terminal reward）
  - 极小 DLM（policy overhead 相对大）
- **工程提示**:
  - 600K policy 可**与 DLM 共享 GPU**（极轻量）
  - 在 high-stakes 场景可**叠加 TIPS + confidence filter**
  - Schedule 与 policy **可独立升级**（解耦）

## 一句话总结

TIPS 用 ~600K param controller 学 frozen DLM 的 unmask/remask 策略，terminal-reward RL 训练，在 GSM8K/MATH-500 上 32-eval budget 达 58%+（+12 pp over strongest baseline），并有 budget-out 推广性 — **diffusion LM 推理时缩放的新范式**。
