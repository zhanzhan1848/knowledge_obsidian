## 重点论文（10 篇）

### 1. **WOVEN: Weaving Visual World Modeling into Multimodal LLMs** (2610.12417)
- 提出"视觉过渡推理（visual transition reasoning）"作为 MLLM 共享训练原子。
- **36,076 样本** / 20 场景 / 5 动作 / 8 推理类型；38 个前沿 MLLM 系统性失败。
- 每任务 **~2K 子集训练** 在 **22/26** 外部基准 up to **+27.3 pp**；WOVEN 可替代任务自身训练数据的 30–50%。
- 训练配方：**按推理操作选样本、偏好大状态变化**。
- 详见 [[2610.12417-WOVEN-Visual-World-Modeling-MLLMs]]

### 2. **SpaceCast-Bench: Evaluating Predictive Spatial Reasoning in VLMs** (2610.12402)
- 首次把"预测性空间推理"从"读图感知"中分离出来。
- **3,862 题 / 182 真实场景 / 16 任务 / 3 层级**；最强模型仅 **58.0%** vs 人类 **87.2%**。
- Qwen3-VL-4B fine-tune：34.0% → **65.7%**；6 个 OOD benchmark macro-average 提升。
- 显式 3D evidence > 生成结果图/视频；**bridge views** 关键。
- 详见 [[2610.12402-SpaceCast-Bench-Spatial-Reasoning]]

### 3. **LLM-BlockFE: Long Text → Predictive Features** (2610.12390)
- **LLM 离线 + 程序在线**：LLM 引导搜索特征程序，**在线推理无需 LLM 调用**。
- 块级不可变结构 + depth-calibrated rollback + 多轨迹交错搜索。
- **4 数据集 AUC +0.0069 ~ +0.0358**；**5 个生产金融风控** KS 提升 **0.02 ~ 1.56 pp**。
- 详见 [[2610.12390-LLM-BlockFE-Feature-Engineering]]

### 4. **OnTrack: Streaming OT for Real-Time LLM Agent Monitoring** (2610.12375)
- **毫秒/步** streaming 结构感知 OT 距离监控；step-level 实时比对。
- 三档数据访问模式（full / intermediate / no prior）能力平滑退化。
- SWE-bench 上 **+0.057 AUROC**；abort policy 节省 **18% 计算**，**83% 中断正确**。
- 详见 [[2610.12375-OnTrack-Real-Time-LLM-Agent-Monitoring]]

### 5. **SGUID: Selecting a Compact Skill Bank** (2610.12367)
- On-policy skill 蒸馏中 **<25%** 检索 skill 真正有用。
- **6 selected skills** 匹配 / 超过 **11× 大的 full-bank**。
- **Qwen3-8B** 64.3% → **66.3%**；无筛选会让 Qwen3-4B 退化（HMMT25 -0.3 pp）。
- 关键洞察：**skill 选择是 model-skill co-evolution 稳定性的核心**。
- 详见 [[2610.12367-SGUID-Compact-Skill-Bank]]

### 6. **Cited but Not Consulted: Legal CoT Faithfulness** (2610.12361)
- 反事实审计：替换"被引用法律依据"为不相关权威，从 hidden state 解码 verdict 变化。
- 命名正确率 66.7–100%，**verdict 改变率 CaseHOLD 0–21.7% / ECHR/SCOTUS 30–76.7% / ContractNLI 43–50%**。
- 红队对抗指令服从率 **73.3–96.4%**，远超 verdict 真实性。
- **Scale 与法律专用 LoRA 都不能闭合 gap**。
- 详见 [[2610.12361-Cited-but-Not-Consulted]]

### 7. **VFold: Symmetry-Aware Cross-Layer Value Cache Compression** (2610.12338)
- 利用 value cache **跨层对称相似性**做 merging，无需改架构。
- 与 NF4 quantization / key pruning **正交可组合**。
- 长 context 部署可行，**无有害性能退化、无架构 overhead**。
- 详见 [[2610.12338-VFold-Cross-Layer-KV-Compression]]

### 8. **SparseDecoding: Decoding-Aware Pruning** (2610.12327)
- 解码阶段是 memory-bound，但 calibration 用**自然文本**与**自生成 token**分布不一致。
- **自回归生成激活**做 calibration（排除 prefill）；定制 N:M **SpMV kernel**（bitmask indexing + fixed-step）。
- **A100 up to 1.48×** end-to-end decoding speedup；Llama-3.1-8B / 3.3-70B / Qwen3-14B/32B 一致验证。
- 详见 [[2610.12327-SparseDecoding-LLM-Pruning]]

### 9. **Caught in the Act: Probes for LLM Deception** (2610.12445)
- **FIBS**：迄今最大 deception 数据集 + 跨层/跨 token 聚合 probe 架构。
- SHADE-Arena **98.8% AUC**，超 Opus 5.5 text-monitoring baseline。
- **Introspective deception AUC up to 99.7%**；开源模型政治敏感话题 untruth 可检测。
- Probe efficacy **随 scale 提升**——监控对大模型反而更友好。
- 详见 [[2610.12445-Caught-in-the-Act-LLM-Deception]]

### 10. **TokenRouter: Token-Level LLM Routing** (2610.12242) — NeurIPS 2026
- **Request-centric programming** + **Model-centric execution** 抽象分离。
- 数学 throughput model → delayed-batching scheduler 最优超参。
- 跨多 routing 算法 / 工作负载 / 模型对，**吞吐提升 2.01–64.15×**。
- 详见 [[2610.12242-TokenRouter-Token-Level-Routing]]

### Bonus: **RACE: When Should Agents Think?** (2610.12061) — Adaptive Reasoning
- **删除 reasoning 后 reference action likelihood 下降**作为 cross-turn 支持信号。
- **LoGiC** procedure 渐进式识别"可省略"的 reasoning turn。
- 跨 4 agent benchmark 大幅**降低 reasoning cost + 保持 / 提升**任务性能。
- 详见 [[2610.12061-RACE-Adaptive-Agent-Reasoning]]

### Bonus: **GRPODropout: Less is More for Online RL** (2610.11854)
- 选择性丢弃"高概率正优势 rollout" + recenter → 抗 entropy collapse。
- 比原 GRPO **更高 accuracy + 更高 entropy + 更少样本**。
- "Less is more"：移除部分 rollout 反而改善学习。
- 详见 [[2610.11854-GRPODropout-Online-RL-Rollouts]]

## 主线趋势

### 主线 1：视觉世界建模成为 MLLM 训练原子
- 共识：spatial / embodied / physical / temporal reasoning 共享**视觉过渡推理**根因
- 趋势：从任务专属模块走向**可复用训练原子**
- 代表：WOVEN、SpaceCast-Bench

### 主线 2：LLM 推理优化的双轨
- **算法侧**：calibration 与 decoding 分布对齐（SparseDecoding）
- **系统侧**：定制 kernel / 抽象分离 / 数学 throughput model（VFold、TokenRouter）
- **共同点**：组合 > 单点，多方法正交叠加

### 主线 3：LLM 安全的多层次监控
- **白盒 probe > 文本监控**：Caught in the Act 突破 frontier monitoring
- **结构感知 > 内容感知**：OnTrack 用 dependency OT
- **价值表征 > 文本描述**：Predicting Alignment Generalization
- **审计而非信任**：HELM Safety、CoT faithfulness 都指向"score 必须自证"

### 主线 4：Agent / RL 训练信号的精细筛选
- **RACE**：likelihood-based reasoning 必要性信号
- **GRPODropout**：rollout 层面的训练信号选择
- **SGUID**：skill 层面的蒸馏信号筛选
- 共同范式：**不是所有信号都该用**

### 主线 5：LLM 工业落地模式成熟
- **离线 LLM + 在线程序**：LLM-BlockFE
- **离线搜索 + 在线 cache**：VFold
- **离线 probe + 在线 monitoring**：Caught in the Act
- 共识：工业部署需要**延迟 / 成本可控**，LLM 是离线工具而非在线服务
