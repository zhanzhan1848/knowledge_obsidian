## 核心贡献

> 提出 **Cola2** —— 分层语言生成框架，联合研究**连续语义压缩**、**重建 vs 生成的平衡**，以及**连续-离散协同自适应**。

1. **框架要点**：
   - **动态文本分段**为 semantic spans；
   - 通过 **auxiliary-loss-free 负反馈** 控制压缩率（无需辅助 loss）；
   - 结合**重建与生成监督**学习紧凑、具预测性的 latent 表示；
   - **Block-causal masked diffusion decoder** 训练于三种 latent 条件：**clean / noisy / dropped**；
   - **Classifier-free guidance** 调节"语义重建"与"自主生成"的平衡；
   - **token-prediction 梯度通过 latent 回传到 encoder**，而 **Flow Matching prior 学习通过 stop-gradient 与表示学习解耦**；
   - **推理时**：生成的文本在**固定 span layout** 下重新编码，以保持 latent history 与真实文本上下文一致。
2. **规模验证**：约 **210B** 训练 token 上的五个下游任务；**346.03B source token** 的**未收敛** checkpoint 在八任务上达到 **60.10** 平均分，**超过 Llama-3-8B** 在 HellaSwag 与 StoryCloze 上的表现 —— 尽管其报告的预训练预算是后者的 **43+ 倍**。

---

## 技术方案

| 组件 | 说明 |
|------|------|
| Semantic span segmentation | 动态切分文本为语义 span |
| Aux-loss-free 压缩控制 | 负反馈机制（无额外 loss） |
| Block-causal masked diffusion | 三种 latent 条件：clean / noisy / dropped |
| CFG | 调节重建 vs 自主生成 |
| Gradient routing | token 梯度 → latent → encoder；Flow Matching → stop-grad |
| Inference re-encoding | 固定 span layout 重编码，保持 latent 一致 |

### 关键洞见

- 与主流 **LLM** 的 token-level autoregressive 不同，这里是 **continuous semantic + discrete surface** 的分层建模 —— 压缩率与"何时离散化"是**联合学习**的，不是超参。
- "未收敛 checkpoint 超过 43× 预算的 Llama-3-8B"是**未饱和 scaling** 的强信号，但也提醒：这类模型的**训练成本仍很高**。

---

## 实验结论

- **训练量**：约 210B token（核心设计验证）/ 346.03B source token（scaling）
- **结果**：
  - 八任务平均 **60.10**；
  - **HellaSwag、StoryCloze 超 Llama-3-8B**；
  - scaling **competitive, unsaturated**。

---

## 局限性

- **训练成本高**（346B token），社区复现困难；
- 与主流 decoder-only LLM 的**生态兼容性**（tool use、RL、 serving）未讨论；
- continuous latent 层的**调试与可解释性**困难；
- 未与同期 hierarchical LM（如 CLOCS 系）直接对比。
