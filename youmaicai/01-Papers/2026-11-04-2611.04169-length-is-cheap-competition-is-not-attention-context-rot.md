## 核心贡献
1. **中性填充是"免费"的，竞争力内容才致命**：固定长度与证据位置，只改填充内容。五个开源模型（0.5B–3B，四个家族）上，中性填充下准确率保持 0.97–1.00（Qwen2.5-1.5B 直到 32K token）；而同样的位置填入与证据同模板的陈述句，准确率掉到 0.11–0.21。
2. **冲突（给被查询键一个竞争取值）是损失的主要来源**：一条这样的陈述把损失放大 **9 到 110 倍**，且竞争者数量越多损失越大；仅共享格式（不共享键）的干扰项解释的损失方差不超过 0.3%（R² ≤ 0.003）。
3. **单个内部量预测失败：证据上的注意力质量 a\***。跨 **126,473 次试验**，log(1/a\*) 解释损失方差的 **35%–58%**，而 log 长度最多只解释 **8%**。这个差距在 8K–32K token 区间依然成立（Qwen2.5-1.5B：R²=0.32 vs 0.02）。
4. **证伪了"掩码填充 = 长度基线"这一流行协议**：Du et al. (2025) "Context Length Alone Hurts LLM Performance Despite Perfect Retrieval" 用掩码隐藏填充 token 并保留位置索引，据此宣称长度本身就有害。本文在 MMLU 上复现了该效应（Llama-3.2-3B 在 30K 掩码 token 处准确率从 51.7% 掉到 40.5%，即丢失 11–18 分），但在检索任务上**可见对照失败**：32K token 处掩码损失 **46 个准确率百分点**，而完全相同的填充内容保持可见则**零损失**。
5. **给出了注意力阈值与非线性读出**：Qwen2.5-1.5B 上损失在 a\* ≈ 0.35 之前几乎为零，之后陡升——模型能容忍损失约一半的证据注意力，然后突然崩溃。各模型斜率均 >1 且互不相同，故无普适定律。
6. **开放探针与全部数据**：发布 harness、注意力探针与全部 126K 试验级测量数据（github.com/yliusci/length-is-cheap，huggingface.co/datasets/yliusci/length-is-cheap）。

## 问题背景
长上下文失效的主流解释是"长度本身"：Du et al. (2025) 把新增 token 从注意力中隐藏、保留位置索引，仍测到至少 7.9% 的下降（30K token 处），由此得出"长度有代价、每个 token 都是税"，进而把解法推向架构改造（位置编码外推、更长上下文训练）。

但作者指出一个方法论漏洞：**长度从不单独增长**。每个新增 token 同时也是新增内容，而在真实输入中很多内容恰恰"长得像"模型要找的东西。Softmax 注意力使这个区别变得关键：

$$a_* = \frac{e^{s_*}}{e^{s_*} + \sum_{j \neq *} e^{s_j}}$$

其中 $s_*$ 是证据的注意力得分，$s_j$ 是其他所有键的得分。一千个不相似的低分 token 对分母贡献甚微；少数几个证据的近似副本却能把 $a_*$ 砍半。若真是这样，长上下文腐化（context rot）就是**注意力竞争**问题而非规模问题，解法应是**策展上下文**而不是截断，且 $a_*$ 应比长度更能预测损失。

已有工作（Du et al.、Gao et al.、Repantis et al.、Hong et al.）要么同时改变长度与内容、要么用不可见填充做基线，都没有做"逐试验测量证据上的注意力并回归损失"这件事。本文首次把行为、内容与注意力三者闭环在同一批试验里。

## 方法
### 1. 核心协议：visible-control protocol
所有比较都**固定长度 L 与证据位置**，只改变证据周围的内容。这需要的前向传播即可，适用于任何开放权重模型。

### 2. 任务设定
- 上下文中隐藏一条证据："The secret code of the river is 4821."（键为常见名词，值为四位数）。
- 结尾查询："Question: what is the secret code of the river? Answer: The secret code of the river is"，用 teacher forcing 计算正确值的对数概率 $\ell$，按其 token 求和。
- 分词器切分不同（Qwen/SmolLM2 为 5 token，OLMo/Llama 为 3 token），因此**只在模型内比较损失，不跨模型比较**。
- 证据深度在上下文中均匀抽取。

### 3. 四种条件
| 条件 | 证据周围的内容 |
|------|--------------|
| short | 无 |
| neutral | 随机数字、随机词、或一句重复的话 |
| competing | 证据模板的陈述句，键从 51 个名词中均匀抽取 |
| masked | 填充物对注意力隐藏，位置索引保留 |

定义条件 $c$ 的损失为：

$$\Delta_c = \log\left(\frac{p_{\text{short}}}{p_c}\right), \quad p_c = e^{\ell_c}$$

neutral 条件隔离长度；competing 与 neutral 之差隔离固定长度下的内容效应。

### 4. 冲突的识别与操纵
由于键是均匀抽取的，部分 competing 陈述会共享被查询的键并赋予不同的取值——这些是最强的竞争者。冲突数 $n_{\text{conf}}$ 随长度增长（512 token 时均值 0.8，2,048 时 3.2，32,768 时 50.5；512-token 上下文中 42–48% 无冲突，≥4,096 token 的上下文中全部至少有一个）。作者通过用记录的种子重建上下文来**逐试验恢复 $n_{\text{conf}}$**，从而把"共享键的竞争者"与"只共享格式的竞争者"分开。另单独插入 0–5 个显式干扰项（共享格式但绝不共享键）。

### 5. 注意力质量 a\* 的测量
- 在 short 上下文中，为每个配置选出在证据 token 上分配最多注意力的 **8 个 (layer, head) 对**。
- 在每个条件下，$a_*$ = 这 8 个头从最终查询 token 指向证据 token 的注意力，对证据 token 求和、跨头平均。
- **不把 attention sink 从 $a_*$ 中重归一化剔除**（作者明确说明这一点，与部分同类工作的做法不同）。
- 通过 $a_*$、$\log(1/a_*)$、$\log L$ 的单变量最小二乘拟合的 $R^2$ 比较预测能力。

### 6. 掩码实现
2D attention mask 把每个填充 token 从后续所有 query 的注意力中移除，但位置索引继续累加，因此证据与 query 的距离保持原样，所有竞争者都不可见。序列首 token 保持可见以保留 attention sink。作者另外验证了"删除 token 并推进位置索引"与显式 attention mask 在 Llama 上等价。

### 7. 模型与规模
Qwen2.5-0.5B/1.5B-Instruct、SmolLM2-1.7B-Instruct、OLMo-2-0425-1B-Instruct、base Llama-3.2-3B；$L \in \{512, 1024, 2048\}$ 通用，上限到各自上下文窗口（最高 32,768）。float16 权重 + PyTorch SDPA。

### 8. Du et al. 复现
在 1,000 道 MMLU 题上，base Llama-3.2-3B 与 Qwen2.5-7B-Instruct，在题目与选项之间插入 3,750 / 7,500 / 15,000 / 30,000 个掩码 token，遵循其布局。报告 Wilson 95% 区间与对无填充基线的配对 McNemar 检验。

## 实验结果
- **Dataset/Task**: 合成 key-value 检索任务（"河的秘密码"），5 个模型 × 4 种条件 × 多个长度 × 多个证据深度，共 126,473 次试验；外加 1,000 题 MMLU 掩码复现实验。
- **Main results**:

| 模型 | n | R²(a\*) | R²(log(1/a\*)) | R²(log L) | 斜率 [95% CI] |
|------|---|--------|--------------|------------|--------------|
| Qwen2.5-0.5B | 32,318 | 0.23 | 0.35 | 0.03 | 1.40 [1.38, 1.42] |
| Qwen2.5-1.5B | 40,632 | 0.43 | **0.58** | 0.05 | 2.22 [2.21, 2.24] |
| SmolLM2-1.7B | 9,325 | 0.30 | 0.41 | 0.07 | 1.68 [1.64, 1.72] |
| OLMo-2-1B | 42,005 | 0.26 | 0.35 | 0.02 | 3.97 [3.92, 4.02] |
| Llama-3.2-3B | 2,193 | 0.36 | 0.45 | 0.08 | 2.75 [2.63, 2.88] |

Qwen2.5-1.5B 在 32K token、长度与证据位置固定时的中位损失：**中性数字文本 0.004 nats；同样内容掩码 1.20 nats；竞争性陈述 4.76 nats**。

- **Ablations**:
  - 仅共享格式的显式干扰项数量最多解释 0.3% 的损失方差（R² ≤ 0.003）——竞争效应来自语义冲突，不是表面相似。
  - $a_*$ 与 $n_{\text{conf}}$ 的关系：已知 $\log(1/a_*)$ 后，$n_{\text{conf}}$ 最多把 R² 再抬高 0.04，注意力质量**概括**了冲突效应而非叠加。
  - 无冲突上下文内（损失很小）$\log(1/a_*)$ 只解释 2–10% 的方差——注意力-损失关系存在阈值。
  - 注意力阈值：Qwen2.5-1.5B 上损失在 $a_*$ 降到约 0.35 前接近 0，之后陡升。
  - 掩码效应是模型依赖的：Qwen2.5-0.5B 上掩码只损失 0.1–0.4 nats。
  - 掩码 vs 可见空白填充：Qwen2.5-1.5B 在 4,096 token 的 MMLU 上，无填充 59.1%、可见中性填充 57.5%、填充掩码 53.9%；但**可见空白填充**把同模型降到 36.0%（此效应在 2,048 token 时不存在）。
  - 竞争性填充在所有长度上造成 56–87 个百分点的准确率损失（图 1）。

## 关键洞察
1. **上下文腐化的因果单位是"竞争性陈述条数"而非 token 数**：有效预算不是 token 计数，而是与查询竞争的陈述数量。这直接翻转了 RAG / agent memory / 长文档流水线的优先级排序——**去重与冲突消解比截断上下文更重要**。
2. **注意力质量 a\* 是一个廉价、单次前向即可得的诊断量**：它比准确率更早、更直接地指示失败，且对任何开放权重模型与任何检索基准都可部署。斜率 >1 与阈值的存在意味着模型对中等程度的证据注意力流失有缓冲、越过阈值后崩溃。
3. **"掩码填充 = 长度基线"这一协议本身制造了伪因果**：掩码保留位置索引、造成预训练中不存在的长位置间隙，其成本被误记为"长度成本"。本文建议任何关于长度效应的声明都必须包含**同位置的可见中性文本对照**。
4. **两个解释并非互斥**：中性填充在检索上免费，但空白填充在 MMLU 上使准确率从 59.1% 掉到 36.0%——长度对推理可能仍然有害，只是不能用掩码来证明。本文诚实地并列了这两个结论。
5. **竞争者数量增长与 $a_*$ 的下降是同一现象的两面**：$n_{\text{conf}}$ 随长度线性增长（32K 时均值 50.5）恰好解释了"损失随长度对数线性下降"这一既有观察——长度只是竞争的代理变量。
6. **可直接检验的预测**：任何在长程上锐化注意力的方法（温度修正、landmark attention 等），若能保持 $a_*$ 高于阈值则受益最大——这把一个模糊的"注意力稀释"理论变成了可操作的设计目标。

## 局限性
- **只有预测，没有因果干预**：$a_*$ 与损失在同一次前向中测量，作者未对 $a_*$ 施加任何干预，因此证据是预测性的而非因果性的。
- **预测子分析覆盖范围有限**：主要分析只在 512–2,048 token 上覆盖全部 5 个模型，8K–32K 只覆盖 2 个模型。
- **竞争填充中冲突数与长度耦合**：每个 ≥4,096 token 的上下文都至少含一个冲突，因此 2K token 以上"仅格式相似竞争者"的独立效应未被测量。
- **冲突分析未预注册**：作者明确说明 $n_{\text{conf}}$ 的分析是事后进行的。
- **$a_*$ 的测量方式有具体约定**：只在单个 query token 上读取、只用 8 个头、不剔除 attention sink——换一种约定可能得到不同的 $R^2$。
- **损失不可跨模型比较**：分词器切分不同（5 token vs 3 token），因此模型间的绝对 nats 数值没有可比性。
- **任务过于合成**：全部核心结果来自单一的 key-value 检索任务；真实长文档任务的语义竞争可能远比"同模板的句子"复杂。
- **模型规模偏小**：主实验仅到 3B 参数（唯一例外是 MMLU 复现用的 7B 模型，而它没有超过 4K 的可见填充臂），因此"长程锐化注意力"这类方法在小模型上的结论不能直接外推到前沿模型。
- **MMLU 臂缺少可见填充对照**：Table 5 的下降无法单独归因于位置间隙，因为 4K 以上没有可见填充臂。

## 适用场景
- **RAG 系统设计与上下文策展**：在把文档喂给模型前做去重、冲突检测与消解；对同一实体的多个取值做显式归并。
- **长上下文失败的快速诊断**：用 $a_*$（一次前向的注意力探针）在上线前预测某条上下文是否会造成失败，比跑完整评测便宜得多。
- **长上下文方法的评测协议设计**：任何声称"我们的方法缓解了长度问题"的论文，都应补上"同位置可见中性填充"对照，否则其增益可能只是填补了位置间隙。
- **需要为长上下文保留注意力预算的系统**：MoE/长上下文 agent 中，把注意力预算视为稀缺资源而非 token 预算来管理。

**不适用于**：直接用于推理类长上下文任务的长度消融（空白填充效应真实存在，结论需另做对照）；跨模型的绝对损失比较；需要因果结论（该研究只给出预测关系）；以及 3B 以上前沿模型的定量外推。
