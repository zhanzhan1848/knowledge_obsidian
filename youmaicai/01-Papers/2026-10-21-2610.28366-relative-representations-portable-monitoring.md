## 核心贡献

> 证明**独立训练的自回归语言模型内部确实以兼容的方式组织行为相关信息** —— 解锁了**可移植的白盒监控**：在一个模型上开发并验证的 probe，模型更换后**无需目标标注数据**即可复用。

1. **核心方法**：绕开不兼容的原生激活坐标系 —— 把每个样本表达为**到一组共享 anchor 的角度距离**
2. **Global anchored 构造**：汇总**所有** transformer 层的信息，消除模型特定的层选择 → 同一个冻结 probe 可直接用于另一个模型
3. **跨模型迁移有效**：在 trivia 数据集、安全监控、数学推理任务上，迁移后的 global anchored probe 平均保留至少 **85%** 的同模型 probe AUROC（相对 chance）
4. **鲁棒性**：支持迁移到相关数据集；跨模型规模与 prompt 变化保持稳定；模型更新后**比标准 probe 保留得更好**

---

## 技术方案

### 问题：坐标系不兼容

独立训练的模型即使能力相近，内部激活的**基/坐标系统不同**，直接迁移 probe 无效。

### 解法：锚定的相对表示

把样本 $x$ 表示为它到共享 anchor 集合 $A=\{a_1,\dots,a_K\}$ 的**角度距离向量**：

```math
\mathbf{r}(x) = \big[\cos\angle(h(x), a_1),\ \dots,\ \cos\angle(h(x), a_K)\big]^\top
```

因为只用**相对几何关系**而非绝对激活，天然跨模型可比。

### Global anchored 构造

| 变体 | 覆盖层 | 问题 |
|------|--------|------|
| Layer-specific anchored | 单层 | 需要为每个模型重新选层 —— 不可移植 |
| **Global anchored** | **所有层汇总** | 无层选择，同一冻结 probe 直接迁移 |

Global 构造去掉模型特定的层选择，是**可移植性的关键**。

## 实验结论

| 指标 | 结果 |
|------|------|
| 迁移后 AUROC 保留 | 平均 **≥ 85%**（相对 chance） |
| 覆盖任务 | trivia 数据集、安全监控、数学推理 |
| 鲁棒性 | 相关数据集迁移 ✓；跨模型规模 ✓；跨 prompt ✓ |
| 模型更新后 | **优于标准 probe** |

### 诚实的边界

迁移是**任务与目标相关**的 —— 即使目标模型中该属性仍高度可解码，迁移也**可能失败**。

---

## 局限性

- 迁移成功率依赖任务；安全监控等任务上可能失效
- 需要 anchor 集合的构造方法（如何选 anchors 未在摘要展开）
- "全局锚定"汇总所有层可能引入噪声层，稀释信号
- 只在自回归 LM 上验证，MoE / 多模态模型未覆盖
- 白盒访问仍是前提 —— 无法用于 API-only 场景

## 实现建议

- **实现难度**: 中（需白盒访问 + anchor 集合设计）
- **预期性能**: 跨模型迁移保留 ≥85% AUROC
- **适用场景**: **模型频繁迭代的部署** —— probe 不用每次模型更新重标数据，是运维成本优势
- **适用条件**: 必须有白盒访问；用于 API 场景可考虑 [[Forty Questions]] 类黑盒方案
- **建议起点**: 先用 global anchored probe 替代层特定 probe 作为默认基线，验证成本是否真低于重标
