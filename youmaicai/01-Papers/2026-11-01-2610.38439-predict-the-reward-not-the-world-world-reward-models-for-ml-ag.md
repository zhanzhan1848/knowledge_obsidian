## 核心贡献

> World Reward Model 论证 agent 应做裁判而非模拟器：ForeCritic 选出更优程序准确率 79.4%，任务时间降 4.4–7.5 倍。

1. 论证 agent 不需要预测执行结果，只需要预测**执行会支持哪个决定** —— 这把世界模型从「预测世界」重新定义为「预测奖励」。
2. 给出三条理论结果：与同一输入下预测执行的 selector 无法超过最优直接 selector；预测中间结果会引入误差，甚至使似然训练的世界模型在**每个实例上都偏好更差的程序**；对已执行胜者做交叉熵会驱动 WRM 趋向最优。
3. ForeCritic（9B 类型化决策模型，5k 已执行程序对）作为裁判，在 12,438 个留出程序对、26 个 ML 任务上以 **79.4%** 的准确率选出更优程序，通用 LLM judge 仅 53–62%。

## 技术方案

### 核心思想

基于搜索的 ML agent 通过不断写候选程序、执行、保留最优来改进方案。执行反馈可靠但昂贵 —— 单次运行可能数小时，且多数运行产出的程序最终被丢弃。近期 agent 让大模型充当世界模型来预测程序表现，但**预测错了就会把错误信息喂给搜索**。

本文的论证非常锋利：agent 其实不需要预测执行的结果，只需要预测**执行会支持哪个决定**。既然下游只用这个决定，选谁就是全部。这个视角转换带来两个直接后果：

第一，**理论上有界**。作者证明「预测执行再导出选择」的多步路径，其天花板不会超过直接预测选择的路径 —— 中间预测引入的误差是纯损失。第二，**预测结果可能主动有害**。论文证明，用似然训练的世界模型可能因为中间结果的预测误差而在**每一个实例**上都偏好更差的程序。这是对「预测式世界模型」的一个反直觉但有力的反驳。

因此 WRM 直接从真实执行结果学习「谁更好」，用交叉熵在已执行胜者上训练。理论证明该目标驱动模型趋向最优。工程上，ForeCritic 把一个 9B 的类型化决策模型适配到 5k 组已执行程序对上，部署进 AIDE、ML-Master、ForeAgent 三个系统，把平均任务时间压缩 4.4–7.5 倍，同时平均分保持在 0.01 误差内或有所提升。

### 关键技术

| 技术 | 说明 |
|------|------|
| World Reward Model (WRM) | 直接从已执行结果学习「哪个候选更好」，不预测任何中间执行结果 |
| 三重理论界限 | (1) 预测式 selector 不超过最优直接 selector；(2) 预测误差可致每实例偏好错误程序；(3) 交叉熵目标驱动 WRM 趋向最优 |
| ForeCritic 实现 | 9B 类型化（typed）决策模型，仅需 5k 组已执行程序对做适配 |
| 概率校准 | 输出校准后的比较概率，使搜索可按置信度分配预算 |
| 系统级集成 | 接入 AIDE / ML-Master / ForeAgent 作为候选筛选器 |

## 实验结论

- **数据集**: 26 个 ML 任务上的 12,438 组留出程序对
- **基线**: 通用 LLM judge（多种）、预测式世界模型、原有 agent 系统的暴力执行筛选
- **结果**: ForeCritic 以 **79.4%** 准确率选出更优程序，通用 LLM judge 仅 **53–62%**；集成后平均任务时间下降 **4.4–7.5 倍**，平均分保持在 0.01 误差内或提升。

- **79.4% vs 53–62%**：类型化决策模型 + 直接比较目标，比通用 LLM judge 高出 17–26 个百分点。
- **4.4–7.5 倍** 的任务时间压缩，是本文最直接可落地的收益。
- 理论上「预测结果可能每例都错」这一结论，为「agent 应该做裁判而非模拟器」提供了坚实依据。
- 训练需求极低（5k 程序对 + 9B 模型），相对其收益的性价比很高。
- 概率校准让搜索能按置信度分配执行预算，而非一律执行。

## 局限性

['只适用于有可执行反馈的程序优化类任务，无法推广到无执行反馈的场景（如开放式写作）。', '依赖候选程序确实已被执行并产生可比结果，标注成本无法完全消除。', '「9B 决策模型」的选择相对固定，未系统比较不同规模与架构的边际收益。']

---

## 实现建议

- **实现难度**: 中（需要执行日志与胜者标注，推理时仅需一次前向）
- **适用场景**: 代码生成与程序进化、自动机器学习实验、算法设计 agent、候选方案筛选
- **建议**: 在搜索型 agent 里优先做「裁判」而非「模拟器」：把执行一次的真实结果变成 (程序对, 谁赢) 的监督信号，训练一个小模型做选择。本文的类型化建模（typed decision model）也很关键——让模型输出可比较的结构化判断，而非自由文本打分。

## 原始摘要

```
Search-based machine-learning (ML) agents improve a solution by writing candidate programs, executing them, and keeping the best. Execution gives the search reliable feedback, but a single run can take hours, and most runs end in programs the agent discards. Recent agents try to save these runs by letting a large language model act as a world model that predicts how each program would perform. However, a wrong prediction feeds the search false information. We argue that an agent does not need to predict the outcome of execution, only the decision that execution would support. We propose World Reward Models (WRMs), which learn from real execution results to choose directly which candidate will perform better, without predicting any intermediate outcome. We prove that a selector which predicts execution from the same inputs cannot outperform the best direct selector, that predicted outcomes add an error which can make a likelihood-trained world model prefer the worse program on every instance, and that cross-entropy on executed winners drives a WRM toward the optimum. Our WRM, ForeCritic, adapts a 9B typed decision model to 5k executed program pairs. On 12,438 held-out pairs from 26 ML tasks, it picks the better program 79.4% of the time, while general-purpose LLM judges reach 53--62%, and its probabilities are calibrated. Inside AIDE, ML-Master, and ForeAgent, it cuts mean task time by 4.4--7.5 times while keeping their mean scores within 0.01 or raising them.
```
