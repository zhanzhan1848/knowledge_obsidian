# AssameseLM-E2B: An Open-Weight Assamese Language Model for Efficient Consumer-Grade Deployment

## 摘要
**AssameseLM-E2B** 是面向低资源语言阿萨姆语的开源 2B 参数模型，基于 Gemma-4 架构，扩展了 byte-level BPE 词表（相比多语种 2B–3B 基线**减少约 500% 的 tokenization 开销**）。采用参数高效的 **Continual Pre-Training (CPT) + Hybrid LoRA** 管线，后接 SFT（平衡多域数据集）以增强指令遵循与 RAG 能力。FLORES-200 上 BPB = **0.7488**，RAG 总分 **96.7%**，对抗性不可答提示的拒答准确率 **100%**。作者同时诚实报告了通用基线的三类失效：**receptive-productive 解耦**、罗马化阿萨姆语上的生成退化、以及**非预期的孟加拉文字同化**。

## 核心贡献
1. 构建 2B 参数阿萨姆语开源模型（AssameseLM-E2B 与指令版 -it），扩展 byte-level BPE 词表解决低资源语言 tokenization 效率问题
2. 提出 Hybrid LoRA 驱动的 Continual Pre-Training 管线 + SFT，在消费级硬件上实现本地可部署
3. 系统刻画通用多语基线在阿萨姆语上的三类失效模式：receptive-productive 解耦、罗马化输入生成退化、孟加拉文字同化
4. FLORES-200 BPB 0.7488 / RAG 96.7% / 不可答拒答 100% 的量化基线

## 方法与架构
**词表扩展**：byte-level BPE 词表针对阿萨姆语脚本优化，tokenization 开销相比多语种 2B–3B 基线下降近 500%（即同文本 token 数大幅减少）。

**训练管线**：
1. **CPT（Continual Pre-Training）+ Hybrid LoRA** —— 在阿萨姆语语料上继续预训练，LoRA 形式便于参数高效适配；
2. **SFT** —— 平衡、多域数据集（涵盖指令遵循与 RAG 能力）。

**评测**：FLORES-200（BPB）、RAG 任务、对抗性不可答提示的拒答准确率，并与通用基线做对比分析。

## 实验结果
- **FLORES-200 BPB**：0.7488
- **RAG 总分**：96.7%
- **不可答对抗提示拒答准确率**：100%
- **规模**：2B 参数（指令版 -it 同规模）
- **基线失效模式**：通用多语基线普遍出现 receptive-productive 解耦（能理解不能生成）、罗马化阿萨姆语上的生成质量退化、以及无意的孟加拉文脚本同化

## 局限性
- 2B 参数规模，通用能力明显受限；
- 只覆盖阿萨姆语，未验证脚本迁移到其他低资源语言的普适性；
- 论文聚焦效率与基线对比，未提供与同规模专用阿萨姆语模型的 SOTA 对比细节；
- BPB / RAG 分数由作者自建流程给出，跨论文可比性有限。

## 值得注意的点
值得注意的是本文在报告自己的模型时**同时如实报告通用基线的三类具体失效**（尤其「非预期的孟加拉文脚本同化」），这在低资源语言论文中并不常见 —— 直接给出了 tokenizer 与数据混合的设计启示，而非只报自己模型的分数。
