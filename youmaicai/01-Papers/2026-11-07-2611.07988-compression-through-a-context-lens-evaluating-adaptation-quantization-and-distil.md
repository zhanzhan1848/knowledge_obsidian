# Compression Through a Context Lens: Evaluating Adaptation, Quantization, and Distillation in Arabic Legal LLMs

### 核心贡献
1. 指出模型压缩对法律领域性能的影响高度依赖评测协议，并用沙特阿拉伯语法律基准 ArabLegalEval 同时进行 with-context（提供支持性法律条文）与 no-context（不给外部上下文）两套评测，系统对比 domain adaptation、quantization、knowledge distillation 三个压缩阶段。
2. 量化了「去掉上下文」带来的巨大性能落差：base model 在 no-context 下的准确率最多下降 27 个百分点。
3. 在 FANAR-9B、JAIS-8B、Qwen2.5-7B 三个模型上给出四比特量化的内存与精度权衡数据，并发现蒸馏 student 规模越小准确率普遍下降，但 Qwen2.5-7B student 从 FANAR 蒸馏后 no-context 准确率仅比 teacher 低 0.6 个百分点。

### 技术方案
**核心思想**: 论文不提出新的压缩算法，而是构建「上下文视角」作为诊断透镜——同一个模型在有/无检索支撑条文两种协议下表现差异巨大，因此只有把 no-context 结果与 with-context 结果并置，才能分离出压缩技术本身对法律能力的真实损伤。

| 技术 | 说明 |
|------|------|
| 评测协议 A：with-context | 在 ArabLegalEval 上额外提供支持性法律 passages，考察模型利用外部法律证据的能力 |
| 评测协议 B：no-context | 不提供任何外部上下文，直接考察模型内化的领域知识；base model 在此协议下准确率最多下降 27 percentage points |
| 三阶段压缩流程 | domain adaptation → quantization → knowledge distillation，逐一叠加以观察各阶段对 no-context MCQ accuracy 的边际影响 |
| 4-bit quantization | 模型内存降低 64–71%；no-context MCQ 准确率变化区间为 -3.2 ~ +1.6 percentage points |
| Knowledge distillation | 以 FANAR 为 teacher 蒸馏 Qwen2.5-7B student，no-context 准确率 76.6%，teacher 为 77.2%；student 规模越小准确率整体越低 |
| 被测模型 | FANAR-9B、JAIS-8B、Qwen2.5-7B |

### 实验结果
- **数据集**: ArabLegalEval（Saudi Arabic legal benchmark），配合 with-context / no-context 两种评测协议
- **基线**: 未压缩的 base model（FANAR-9B / JAIS-8B / Qwen2.5-7B 自身）以及三种压缩阶段之间的相互对照
- **结果**: 移除上下文最多造成 27 percentage points 的准确率差距；4-bit 量化省内存 64–71%，no-context MCQ 准确率变化 -3.2 ~ +1.6 percentage points；FANAR→Qwen2.5-7B 蒸馏后 student 达 76.6% no-context 准确率，teacher 为 77.2%（差 0.6 个百分点）；蒸馏结果随 student 规模减小而波动更大且准确率整体下滑

### 局限性
- 仅覆盖 Saudi Arabic 单一语言与单一法律域（ArabLegalEval），结论向其他语言/领域的外推性未验证。
- 摘要未说明具体的量化算法（如 GPTQ/AWQ 等）、校准数据集、显著性检验方式，也未说明除 MCQ 之外的生成类任务表现。
- 摘要未说明蒸馏时使用的具体数据集规模、训练时长以及 teacher/student 的层数或宽度对齐策略。

### 关键洞见
> 压缩研究最常见的隐性 bug，是把「模型忘了」误判成「模型变笨了」：当被测模型本来就在靠检索条文作答时，压缩带来的记忆占用下降与上下文依赖度上升会互相抵消，掩盖真实损伤。本文用同一个模型在 27 个百分点的上下文落差下做差分，才暴露出量化其实近乎无损（-3.2 ~ +1.6）——换句话说，no-context 协议才是衡量领域压缩代价的「重力秤」，而它比常规有上下文评测更严苛也更便宜。
