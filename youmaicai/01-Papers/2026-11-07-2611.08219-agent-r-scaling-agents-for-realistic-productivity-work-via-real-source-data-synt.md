# Agent-R$^2$: Scaling Agents for Realistic Productivity Work via Real-Source Data Synthesis

### 核心贡献
1. 提出 Agent-R$^2$，一个基于「真实来源（real-source）」的数据合成框架，用于规模化训练数据以覆盖真实生产力工作场景。
2. 与依赖人工指定 workflow 或 LLM 生成文件不同，Agent-R$^2$ 全流程锚定在真实职业种子（real occupational seeds）、语料库推导的 workflow 证据，以及网络抓取的真实文件上。
3. 训练了 Agent-R$^2$-4B，仅用 4k 任务实例即在 GDPval 与 OfficeQA 上超过 Qwen3-235B-A22B-Thinking-2507，并显著缓解 agent 的「捷径行为」。

### 技术方案
**核心思想**: 用真实职业场景 + 真实网络文件 + 细粒度 rubric 合成出「交付物级」可评分的训练任务，再以 SFT 与 rubric-based RL 训练小模型 agent，使其学会长程专业工作流与文件依据推理。

| 技术 | 说明 |
|------|------|
| 候选池 | 从 10k 个 web corpus 候选中筛选 |
| 蒸馏 | 蒸馏出 4k 个任务实例，每条包含真实的多格式附件（multi-format attachments） |
| 评测标准 | 每个任务配细粒度、交付物级别的 rubric（deliverable-level rubrics） |
| 训练阶段一 | 对 Agent-R$^2$-4B 做 supervised fine-tuning (SFT) |
| 训练阶段二 | 基于 rubric 的 reinforcement learning (rubric-based RL) |
| 行为分析 | 缓解「捷径行为」：agent 在未充分 grounding / 构建 / 验证前就产出表面看似合理的交付物 |

### 实验结果
- **数据集**: GDPval（真实生产力工作评测）、OfficeQA（文件依据问答）、自建 4k 真实文件任务集（源自 10k web corpus 候选）
- **基线**: Qwen3-235B-A22B-Thinking-2507
- **结果**: 仅用 4k 实例训练的 Agent-R$^2$-4B 在 GDPval 上 51.0% vs 48.0%，在 OfficeQA 上 14.8% vs 13.8%，两项均超过 235B 基线；分析显示该方法减少捷径行为并促进持续探索

### 局限性
- 合成数据规模仍有限（4k 实例），任务领域覆盖受 10k web corpus 候选的分布限制
- 摘要未说明 Agent-R$^2$-4B 之外更大规模模型的结果，也未说明各训练阶段（合成 / SFT / RL）的独立消融数字
- rubric-based RL 的评分一致性依赖 rubric 设计质量，摘要未说明其人工校验方式

### 关键洞见
> 真正卡住生产力 agent 的不是模型规模，而是「训练信号是否来自真实工作意图、真实文件环境、真实交付物标准」；把 10k 真实网络语料蒸馏成 4k 个带真实附件与交付级 rubric 的任务，就足以让 4B 模型在真实生产力基准上反超 235B 思考模型——数据真实性替代了参数量。
