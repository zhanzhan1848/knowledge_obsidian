## 核心贡献
1. 提出 **Code Comprehensor**，一个 hybrid retrieval-reasoning 框架，由三部分组成：代码依赖 callgraph、**CodeScribe**（层次化文档生成）、**CodeContrast**（CLIP 式双塔跨模态检索模型）。
2. **CodeScribe** 使用 code-aware LLM 沿 repository callgraph 生成 hierarchical documentation，把原本只有符号结构的代码仓库转化为带上下文的文本监督信号。
3. **CodeContrast** 在 CodeScribe 输出上训练 CLIP-style dual-encoder，学习对齐的 text-code embeddings，实现快速且语义精确的"code-context neighborhood"检索。
4. 检索结果作为 grounded evidence 交给基于 MCP 的 LLM orchestrator 回答领域特定问题，并给出端到端的 RAGAS faithfulness 评估。

## 问题动机
理解大型、复杂且快速演化的代码库是规模化软件工程的核心难题，直接拖累 onboarding、维护、重构与影响分析。把这部分信息喂给 LLM 又多一层障碍：模型不仅要理解被问的那个方法，还必须理解它在整仓库语境中的关联方法（associated methods in the grand scheme of the repository）。既有做法要么直接依赖结构化的 callgraph（缺语义），要么用通用 embedding 硬检索代码片段（text-code 模态鸿沟），难以同时兼顾语义精度与上下文邻域完整性。

## 方法
整体是一个 **retrieval + reasoning** 的两段式框架：

1. **代码依赖 callgraph**：作为仓库的结构骨架，界定"邻域"的边界。
2. **CodeScribe（层次化文档生成）**：调用 code-aware LLM，沿 repository callgraph 生成 **hierarchical documentation**。监督信号的丰富度包括：分层文档、parent/sibling 上下文，以及 **LLM-generated synthetic questions**。
3. **CodeContrast（跨模态检索）**：CLIP-style **dual-encoder**，在 CodeScribe 输出上训练，学习对齐的 text-code embedding space，从而支持 text-to-code 检索。
4. **CodeContrast** 负责快速、语义精确地召回相关的 code-context neighborhoods。
5. **MCP-based LLM orchestrator**：把召回的 neighborhood 作为 grounded evidence，合成回答 domain-specific queries。

- 数据/基准: **OpenCV**（公开代码库）与一个**专有的 5M-LOC（500 万行代码）仓库**；端到端质量用 **RAGAS** 做 LLM-as-a-judge 评估。
- 对比方法: baseline retrieval approaches（摘要未逐一列名），并对 CodeScribe 生成的多种文本监督形式做了消融（hierarchical documentation、parent/sibling context、LLM-generated synthetic questions）。
- 主要结果:
  - CodeScribe 产出的监督信号相对 baseline 显著提升了 cross-modal retrieval 的 **text-to-code accuracy**。
  - 更丰富的文本监督（层次化文档 + parent/sibling 上下文 + LLM 合成问题）在两个仓库上都能一致地提升性能。
  - RAGAS 的 LLM-as-a-judge 评估给出 **faithfulness 超过 90%**。

## 关键技术细节
- 核心设计取向：用 LLM 生成的 rich textual supervision 去"蒸馏"结构化的 callgraph 信号，从而弥合 code 与 natural language 的检索鸿沟。
- 双塔（dual-encoder）结构意味着检索可预计算索引，推理开销与 query 数量近似解耦，适合大规模常驻服务。
- 端到端链路引入 MCP（Model Context Protocol）作为 orchestrator 与工具/仓库之间的接口。
- 专有 5M-LOC 仓库说明方法在真实工业规模代码库上验证过。
