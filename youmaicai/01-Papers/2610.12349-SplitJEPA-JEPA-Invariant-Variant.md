## 核心贡献

> 提出 **SplitJEPA**：首个无需 reconstruction loss 即可在 representation 空间同时恢复 latent state 与其 invariant / variant 分解的 JEPA；在 stationary Gaussian 动力学下证明可识别至 block-wise isometry。

1. 把"动态世界理解"分解为**共享部分（invariant）** 与**变化部分（variant）**，无需 decoder。
2. **理论保证**：在 stationary Gaussian predictive dynamics + full-rank variation 条件下，SplitJEPA 可识别 invariant / variant 子空间到独立 block-wise isometries。
3. 在合成非线性系统与机器人操作任务上验证理论，并在 robustness 与 efficiency 两个维度展现实用价值。

---

## 技术方案

### 核心思想

传统方法靠 reconstruction 强制 latent 解释所有观测，再事后分析其组织。SplitJEPA 直接在 representation 空间做"分块"，把 invariance 与 variation 作为一等约束。

### 关键技术

| 技术 | 说明 |
|------|------|
| Joint Embedding Predictive | 不重建观测，只预测 latent 之间的转换 |
| Invariant-Variant decomposition | latent = $[z_{\text{inv}}, z_{\text{var}}]$，$z_{\text{inv}}$ 跨相关观测共享，$z_{\text{var}}$ 描述变化 |
| Block-wise identifiability | 证明 $z_{\text{inv}}$ 与 $z_{\text{var}}$ 子空间可分别恢复至 block 等距变换 |
| Decoder-free | 无需任何观测 decoder，结构简洁 |

### 公式

```math
z_t = [z^{\text{inv}}_t, z^{\text{var}}_t], \quad
\mathcal{L} = \| \phi(z_{t+1}) - g(z_t) \|^2
```

其中 $\phi, g$ 为共享的 encoder/predictor；理论分析在 stationary Gaussian 假设下给出闭式可识别性条件。

## 实验结论

- **数据集**: 合成非线性系统 + 机器人操作任务
- **基线**: 标准 JEPA、reconstruction-based world models
- **结果**:
  - 合成系统：split 子空间与 ground truth 对齐
  - 机器人任务：split latent 提升对光照/视角变化的 robustness
  - 推理效率优于需 decoder 的 reconstruction-based baselines

---

## 局限性

- 理论保证仅在 stationary Gaussian 动力学下成立；复杂动力学下需要新分析。
- 在 highly chaotic 系统上 block-wise identifiability 难以达成。
- 机器人实验规模有限，迁移到大规模具身任务尚未验证。
