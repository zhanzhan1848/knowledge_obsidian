# SAVeR$^2$: Reasoning-based Safety Alignment for Large Reasoning Models via Verifiable Rewards

## 摘要
**大型推理模型（LRM）**通过显式 **CoT 推理**取得显著性能，但这一过程引入了**关键的安全风险**。本文把 LRM 的安全目标形式化为：要求**非恶意的推理与答案**、**安全性一致性**、以及**明确的意图识别**。作者论证：既有对齐方法受困于**差的对抗泛化**、显著的**「安全税」（safety tax）**（安全训练损害推理能力）、以及**不忠实的粗粒度奖励** —— 主要因为它们**忽视**了 LLM/LRM 固有的推理能力可以用于安全。为解决此问题，本文提出 **SAVeR²**（**S**afety **A**lignment via **R**ewards with **R**easoning capability）—— 一种**通过具备推理能力的奖励**实现安全对齐的方法。SAVeR² 把安全目标**分解为四个细粒度可验证奖励信号**，并采用**难度感知的数据选择策略**稳定训练。关键的是：本文引入一个**保推理的梯度投影机制**，**解析地解决安全梯度与推理梯度之间的冲突**，从而**有效消除安全税**。在 **1.5B 到 671B** 的模型上做大量实验。

## 核心贡献
1. 把 **LRM 安全目标**形式化为三项：非恶意推理与答案 / **安全性一致性** / **明确意图识别**
2. 诊断既有对齐方法的三大问题：**差的对抗泛化**、**安全税**（安全损害推理）、**不忠实的粗粒度奖励**
3. 提出 **SAVeR²** —— 用**具备推理能力的奖励**做安全对齐，把安全目标**分解为四个细粒度可验证奖励信号**
4. **难度感知的数据选择**稳定训练
5. **保推理的梯度投影机制** —— **解析地解决安全梯度与推理梯度冲突**，**有效消除安全税**
6. 在 **1.5B 到 671B** 的模型上做大量实验

## 方法与架构
**安全目标分解（四个细粒度可验证奖励）**：
```
非恶意推理 + 非恶意答案 + 安全性一致性 + 明确意图识别
```

**难度感知数据选择** —— 按样本难度分配训练信号，稳定训练。

**保推理的梯度投影（核心机制）**：
```math
g_{\text{safe}}^{\perp} = g_{\text{safe}} - \operatorname{proj}_{g_{\text{reason}}}\big(g_{\text{safe}}\big)
```
即把安全梯度在推理梯度方向上的分量**解析地移除**，保留其余方向 → **消除安全税**。

这与「两阶段（先安全后推理）」或「加权重平衡」的根本区别：**不是调权重，而是解析地投影掉冲突分量**。

## 实验结果
- **SAVeR²** 在 **1.5B 到 671B** 模型上做大量实验
- **保推理的梯度投影**解析解决安全/推理梯度冲突，**有效消除安全税**
- **四个细粒度可验证奖励**替代粗粒度不忠实奖励
- **难度感知数据选择**稳定训练

## 局限性
- 摘要截断，主结果数字需查正文；
- 梯度投影的**解析求解**依赖安全/推理梯度可分解，实践中可能近似；
- 「四个可验证奖励」的验证器本身可能不忠实（奖励黑客风险）—— 未讨论；
- 「消除安全税」的判定需要同时测安全与推理，而两者常在部分基准上耦合。

## 值得注意的点
**「保推理的梯度投影」比「加权重平衡」高一个层级**：权重平衡是在**一个方向上找折中点**，梯度投影是**精确保留两个目标各自需要的分量**。这是今日唯一一篇正面处理**「安全 vs 能力」张力**的工作 —— 而这个张力（安全税）在其他论文里通常被回避或用权重技巧糊过去。

同时「四个细粒度**可验证**奖励」延续了本批次的主线：**把不可验证的判断拆成可验证的子信号**。
