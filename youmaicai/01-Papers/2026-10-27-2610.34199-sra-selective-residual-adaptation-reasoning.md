## 核心贡献

> 提出 **SRA (Selective Residual Adaptation)**：利用"师生分布差异**高度稀疏**且目标 token **几乎总落在学生 top-K 候选集内**"这一观察，用 **Discrepancy Gate (DG)** 定位分歧位置 + **Candidate Residual Adapter (CRA)** 在 top-K 上做 logit 残差校准，**冻结学生骨干、推理时不需要教师**；在 Qwen3 0.6B–4B 的数学基准上把蒸馏学生的平均 **Pass@16 提升最高 4.37 个百分点**，同时保持通用能力不退化。

1. **稀疏性观察（方法论基石）** — 在共享前缀上比较师生 next-token 分布，发现两件事：① 学生的 top-1 token 与教师分歧的位置**高度稀疏**，且可被 **total variation (TV) 距离**敏感检测；② 即使 top-1 分歧，**教师的高概率质量几乎全被学生的 top-K 候选集覆盖**（在 K=16 的分歧位置上），说明失配主要表现为**共享候选集内的重排序**，而非缺少可行 token。
2. **"可换 token"验证：teacher sampling 几乎补回全部差距** — 推理时凡师生 top-1 不同就用教师 token 替换，OPD 学生准确率从 **48.44% → 80.08%（0.6B）**、**76.17% → 87.11%（1.7B）**，接近教师独立的 **88.67%**；而替换只在平均 **≈13.83%** 的 token 上触发——稀疏干预即足以弥合。
3. **TV 指示器的理论优势（Theorem 1）** — 对候选分布做小扰动 `q_S(ε)=q_T+εΔ` 时，`TV(q_T,q_S)=ε/2·‖Δ‖₁`（**线性增长**），而正/反向 KL 只以 **二次项** `ε²/2·Σ Δᵢ²/q_{T,i} + O(ε³)` 增长；因此"足以翻转 top-1 的微小概率移动"对 TV 更可见。实验上 TV 的 FNR 最低，仅 **0.32%–1.97%**（对比 forward KL / reverse KL / 学生熵）。
4. **SRA 框架** — 两个轻量模块：DG 从冻结学生的**最终 hidden state** 用 MLP 预测分歧标签 `ℓ(s_t)=1[TV(q_T,q_S)≥τ]`（`u=σ(MLP_φ(h_t))`，阈值 η 触发）；CRA 预测 top-K 候选上的**加性 logit 残差**，在 DG 触发位置替换学生分布，其余位置**完全保留原分布**；两模块复用学生特征，**推理时零教师调用**。
5. **理论保证（Theorem 2）** — 给出序列级性能改进的充分条件：`J(π_{φ,θ}) − J(π_S) ≥ J(π_T) − J(π_S) − ℰ_SRA`，即 SRA 的误差界小于教师相对学生的优势即可获得严格改进。
6. **实证增益与能力保持** — 在 9 个设置中的 8 个上平均 Pass@16 提升 **2.28–4.37 pp**，且**Pass@16 的增益明显大于 Avg@16**（说明选择性校准抑制了自回归误差累积、同时保留了输出多样性，扩大了解空间）；OOD 上 GPQA-Diamond 全面提升、HumanEval 与 MMLU-Pro **完全保持**（无灾难性遗忘）。

## 技术方案

### 核心思想

蒸馏把大模型的推理能力压进小模型，但师生分布错配**无法被完全消除**。现有两条补救路都有代价：① 更新学生骨干（LoRA / 前缀 / 侧网络）——训练侵入 backbone；② 协同推理（路由 / 生成中向教师求助）——**推理时仍需教师算力**，且同步与前缀处理引入额外延迟，可能抵消小模型独跑的优势。

SRA 的赌注来自一个更精细的观察：错配**不是均匀分布的**。绝大多数位置师生一致；真正分歧的位置稀疏，且**分歧几乎总是"学生候选集里排错了序"，而不是"学生根本没考虑过正确答案"**。因此：

> 不需要改写学生"能生成什么"，只需要在少数位置**把它已经列为候选的 token 重新排序**。

于是把"蒸馏对齐"这件全局、持续、侵入性的事，压缩成一个**局部的、稀疏的、只在输出侧生效的概率重分配**问题——就像给一段已排好的骨架做局部微调，而不是重铸骨架。

```
推理（每一步）：
   h_t ──► DG (MLP_φ) ──► u = σ(...) ──► g = 1[u ≥ η] ?
                                              │
                            是 ───────────────┤
                                  取学生 top-K 候选
                                  → CRA 预测 logit 残差
                                  → q_θ 采样
                            否 ───────────────┤
                                  直接用学生分布 π_S 采样

训练（两阶段）：
   Stage 1 冷启动：离线在 π_S 下生成响应 → 算教师分布 q_T 与标签 ℓ → 训 DG（全部有效位置）与 CRA（仅 ℓ=1 位置）→ 固定阈值 η 与 φ*
   Stage 2 on-policy 修正：在学生自己的采样轨迹上继续训 CRA
```

CRA 的结构借鉴 EAGLE 的多层特征融合：**双向 Transformer 层**（无 causal mask），输入为「学生最终 hidden state + 中间层 hidden state + top-K 候选 token 的输入 embedding」三类向量，各经独立 RMSNorm + 线性投影到公共维度（K+2 个向量联合做多头自注意力，使每个候选能同时看到两个 hidden state 与所有候选）。选 **L24** 的中间层一致优于 L12 与 L32。

### 关键技术

| 技术/方法 | 说明 |
|------|------|
| Discrepancy Gate (DG) | 从学生最终 hidden state 出发的轻量 MLP，预测 `ℓ(s_t)=1[TV(q_T,q_S)≥τ]`；阈值 η 决定是否干预 |
| Candidate Residual Adapter (CRA) | 双向 Transformer 层，在学生 top-K 候选上预测加性 logit 残差 `f_θ`，使学生分布逼近教师在**同一候选集内**的条件分布 |
| Residual target | 回归目标为"理想残差"，配 Smooth L1 损失（权重 λ_R）+ KL 分布匹配项 |
| Top-K renormalized distribution | 用学生 top-K 上的归一化分布 `q_M` 近似师生输出分布，TV 阈值默认 τ=0.1、K=16 |
| Two-stage training | Stage 1 冷启动（离线 π_S 轨迹 + 教师分布）；Stage 2 on-policy 修正（动态 on-policy rollout + 成对教师前向） |
| Frozen backbone | 学生参数全程冻结，只更新 DG 与 CRA；推理零教师调用 |
| Theorem 1 (TV vs KL sensitivity) | TV 线性增长、KL 二次增长 → TV 是更好的分歧指示器（FNR 0.32%–1.97%） |
| Theorem 2 (improvement bound) | `J(π_{φ,θ}) − J(π_S) ≥ J(π_T) − J(π_S) − ℰ_SRA`，给出严格序列级改进的充分条件 |
| Gate threshold sensitivity | τ=0.1 为默认值，附录给出分歧召回与选中位置比例的敏感性分析 |
| Intermediate layer fusion | L24 优于 L12/L32；移除中间 hidden state 造成最大退化（Avg@16 −1.04、Pass@16 −4.64 pp） |
| Baseline comparison vs continued distillation | 与"再蒸馏两 epoch"直接对照，证明增益不只是更多训练 |
| OOD evaluation | GPQA-Diamond、HumanEval、MMLU-Pro 检验能力保持与灾难性遗忘 |

### 实验设置

| 维度 | 规模 |
|------|------|
| 学生 / 教师 | 学生从 Qwen3 Base 初始化：Qwen3-0.6B / 1.7B / 4B；教师为 **Qwen3-8B（thinking 关闭）** |
| 蒸馏基线 | KD（forward KL）、OPD（on-policy distillation）、EOPD |
| 训练数据 | **DAPO-Math-17k**；蒸馏两 epoch → SRA 再两 epoch（学生冻结） |
| 数学基准 | AIME24、AIME25、AMC23、MATH-500（每题采样 16 次，temperature=1、top-p=1、最大 31,744 token）；报告 Avg@16 与 Pass@16 |
| OOD 基准 | GPQA-Diamond、HumanEval、MMLU-Pro（每题 16 次采样，同解码设置） |
| 诊断实验 | GSM8K 测试集随机 **256 题**；Qwen3-0.6B-Base / 1.7B-Base 及 OPD 学生 vs Qwen3-8B 教师 |
| 优化 | AdamW；OPD 基线配置，最大响应长度 7,168 token；自托管 vLLM |
| CRA 结构 | 2 层双向 Transformer，K+2 向量联合自注意力，pre-RMSNorm + 残差 |

## 实验结果

**主结果（Qwen3 蒸馏学生，Avg@16 / Pass@16；四基准平均）**

| 学生 / 方法 | Average Avg@16 | Average Pass@16 | Δ Avg@16 / Δ Pass@16 |
|------|------|------|------|
| Qwen3-0.6B · KD | 13.82 | 38.89 | — |
| Qwen3-0.6B · KD + SRA | 14.26 | 38.26 | +0.44 / **−0.63** |
| Qwen3-0.6B · OPD | 17.55 | 38.43 | — |
| Qwen3-0.6B · OPD + SRA | 19.29 | 41.24 | +1.74 / **+2.81** |
| Qwen3-0.6B · EOPD | 19.06 | 41.73 | — |
| Qwen3-0.6B · EOPD + SRA | 19.29 | 41.45 | +0.23 / −0.28 |
| **Qwen3-4B · KD** | 38.94 | 62.15 | — |
| **Qwen3-4B · KD + SRA** | 39.17 | 64.43 | +0.23 / **+2.28** |
| **Qwen3-4B · OPD** | 40.71 | 63.55 | — |
| **Qwen3-4B · OPD + SRA** | **41.45** | **67.92** | **+0.74 / +4.37** |
| Qwen3-4B · EOPD | 40.46 | 66.11 | — |
| **Qwen3-4B · EOPD + SRA** | **41.11** | **68.40** | **+0.65 / +2.29** |
| Qwen3-8B（教师，参考） | 49.07 | 73.64 | — |

> 论文正文 Table 1 覆盖 Qwen3-0.6B / 1.7B / 4B 三个规模 × KD / OPD / EOPD 共 **9 个设置**，其中 **8 个设置**的 Pass@16 提升（**+2.28 ~ +4.37 pp**）；上表列出 0.6B 与 4B 两档的逐行数值（1.7B 档未逐项展开）。**最大增益 +4.37 pp 出现在 Qwen3-4B 的 OPD + SRA**。

**与"继续蒸馏"的对照（Qwen3-4B）**：SRA 在 KD 基线上把平均 Avg@16 / Pass@16 分别提升 **+2.32 / +1.80 pp**；在 OPD 与 EOPD 基线上的 Pass@16 分别超出"继续蒸馏" **4.21 pp** 与 **3.12 pp**——说明继续蒸馏已出现边际收益递减而 SRA 打破该平台期。SRA 与 on-policy 蒸馏（OPD/EOPD）**协同性最强**，在 4B 上取得最佳 Avg@16 与 Pass@16，并在 **AIME25 Pass@16 上超过 8B 教师**。

**消融（Qwen3-4B OPD，四数学基准）**

| 设置 | Avg@16 | Pass@16 | 相对完整 SRA |
|------|------|------|------|
| 完整 SRA（L24, λ_R=0.1） | 41.45 | 67.92 | — |
| 去掉最终 hidden state | 40.88 | 66.16 | −0.57 / **−1.76** |
| 去掉中间 hidden state | 40.41 | 63.28 | −1.04 / **−4.64** |
| 中间层改用 L12 | 41.03 | 64.60 | −0.42 / −3.32 |
| 中间层改用 L32 | 41.25 | 66.21 | −0.20 / −1.71 |
| λ_R = 0（去残差回归） | 40.53 | 66.05 | −0.92 / −1.87 |
| λ_R = 1（残差权重过大） | 41.05 | 65.28 | −0.40 / −2.64 |

**OOD 能力保持（Qwen3-4B）**：GPQA-Diamond 上 Avg@16 与 Pass@16 **一致提升**；HumanEval 编码能力与 MMLU-Pro 多学科准确率**完全保持**，无灾难性遗忘。

**机制诊断（GSM8K 256 题）**：教师 top-1 替换触发率 **≈13.83%**（蒸馏后模型更低）；TV 的 FNR **0.32%–1.97%**，优于 forward KL、reverse KL 与学生熵；CI→CI+教师对齐提升学生与教师在 top-K 上的分布一致性。

## 局限性

- **依赖"教师 token 落在学生 top-K 内"这一假设**：该覆盖率在**无约束的开放式生成**中可能下降，此时 CRA 在候选集内重分配的能力受限。
- **评测主要面向结构化推理任务**：OOD 只覆盖了编码（HumanEval）与多学科理解（MMLU-Pro）以及科学推理（GPQA-Diamond），**自由形式对话等开放式生成未评估**。
- **训练开销并未消除，只是转移了**：推理时确实免去教师调用，但**两阶段训练需要动态 on-policy rollout 与成对教师前向**，带来额外训练算力。
- **增益幅度有限且依赖配置**：Pass@16 提升 2.28–4.37 pp 属于"稳定但不大"的量级；对 λ_R 与 τ 等超参较敏感（λ_R 从 0.1 到 0 或 1 均退化）。
- **基线模型规模偏小**：实验限于 Qwen3 0.6B–4B 学生 + 8B 教师，**未验证在更大规模或非 Qwen 家族上的可迁移性**。

## 与知识库既有工作的关系

- 与 [[2026-10-27-2610.34855-decoycount-visual-reasoning-misalignment-counting]] 共享一个有趣的同构：**两者都在"通用能力提升 ≠ 目标能力对齐"上给出反例**——DecoyCount 发现模型越强、思考越多，视觉推理的 ΔR 反而越大；SRA 则说明单纯"更强地做一般推理"（继续蒸馏）已进入平台期，需要的是**在特定位置上的针对性校准**。
- 与本库中"证伪默认假设"主线一致的一个方法论样本：**把"大部分位置不用改"这一假设变成可验证的量化结论**（分歧稀疏 ≈13.83% 触发率、TV 的 FNR 0.32%–1.97%），再据此把全局问题（蒸馏）重构为稀疏干预问题（残差适配），这是与 [[2026-10-27-2610.35188-v3ast-bench-verifiable-agent-safety]] 的 capability-twin 思路同源的"解耦能力与目标"思路。
- 与本库中蒸馏/推理加速类工作相接：SRA 属于**不更新 backbone、不付推理期教师代价**的第三条路，与 EAGLE 式的侧网络思路同源但目标不同（EAGLE 提速度，SRA 提正确率）。

## 建议

- **是否推荐使用**: 有条件推荐（适合已有蒸馏学生、且部署环境无法承载教师前向的场景）
- **适用场景**: 小模型数学/结构化推理的部署前增强；需要一个**可插拔、不改 backbone、推理零教师成本**的增益手段；on-policy 蒸馏（OPD/EOPD）之后的增量优化
- **可借鉴要点**:
  1. **先诊断再建模**：动手前先做两个便宜实验——(a) 教师 top-1 替换能补回多少准确率（本文：48.44%→80.08%），(b) 教师 top-K 概率质量被学生 top-K 覆盖多少。若 (a) 显著且 (b) 很高，则"只做候选集内重排序"就是正确路线；这个诊断流程可迁移到任何师生对。
  2. **分歧指示器选 TV 而非 KL**：Theorem 1 给出可迁移的直觉——概率的小幅移动对 TV 线性可见、对 KL 二次可见，因此用 KL 做门控会系统性漏掉"足以翻转 top-1"的轻微失配（本文 FNR 0.32% vs 明显更高）。任何以"分布距离做门控"的自适应推理方案都应重算这一对比。
  3. **增益与能力保持要一起报**：本文用 Pass@16 与 Avg@16 的**不对称增益**（后者小、前者大）说明干预抑制了误差累积而非单纯抬分——报增益时同时给出这两项以及 OOD 基准（GPQA/HumanEval/MMLU-Pro），才能区分"真的更会推理"与"只是更收敛"。
