## 核心贡献

> 提出 LatComm —— 一个"编码-读取"分离的潜在通信接口，让上下文可被一次编码后被多个不同 LLM 重复读取，兼顾 compactness、reuse、cross-LLM readability 三个属性。

1. **编码-读取分离设计**：context encoder LLM (冻结) 一次编码，receiver LLM (冻结) 通过 cross-attention 选择性读取
2. **固定大小 latent packet**：上下文压缩为定长向量包
3. **Prompt-aware gating**：gate 由 receiver 的 prompt 计算，控制读取哪些 latent
4. **显著效率提升**：在 QuALITY 上将 receiver 输入压缩 57x、推理加速 3x；12 个多选题数据集上较单向量基线准确率提升最高 10.2 分

## 技术方案

### 核心思想

多 LLM 协同系统常需共享上下文。当以文本形式传递时，接收端需要重新处理所有 token，浪费算力。LatComm 将 context 编码为定长 latent packet，使不同 LLM 可"按需读取"，避免重复编码。

### 关键技术

| 技术 | 说明 |
|------|------|
| Frozen Context Encoder | 冻结的 encoder LLM，将 context 压缩为固定大小 packet |
| Frozen Receiver LLM | 通过 cross-attention 读取 packet，模型本身不更新 |
| Cross-Attention with Gates | 门控由 prompt 计算，控制读取哪些 latent 信息 |
| Question-Agnostic Encoding | 一次编码支持多个 question 复用 |

### 关键公式

```math
\mathbf{p} = E_{\text{ctx}}(\mathbf{c}) \in \mathbb{R}^{d \cdot k}
```

context $\mathbf{c}$ 由冻结 encoder $E_{\text{ctx}}$ 一次编码为定长 packet $\mathbf{p}$。receiver 通过 cross-attention + prompt-derived gates 读取：

```math
\mathbf{g} = \sigma(f(\mathbf{q})) \in [0, 1]^k
```

其中 $\mathbf{q}$ 为 receiver 的 prompt，$f$ 为门控网络。

## 实验结论

### 数据集

- **12 个多选题 QA 数据集** (含 QuALITY 等长文问答)

### 结果

- 平均准确率较单向量基线提升 **+10.2 points**
- QuALITY: receiver 输入压缩 **57x**，推理加速 **3x**
- 编码与读取解耦使得同一 packet 可被多个不同 LLM 复用

---

## 局限性

- 编码器与接收器 LLM 均为冻结，扩展到下游任务缺乏灵活性
- 压缩比有上限 (57x)，更长上下文仍可能受限
- 实际部署中跨模型 latent 可读性的稳定性需进一步验证
