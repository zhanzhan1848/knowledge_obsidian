## 核心贡献

> 行为一致性是 LLM agent 可靠性的重要信号，但**现有方法只给单任务级别分数**——无法识别**哪里出现行为分歧**，也无法判断 actions 是否在**等价决策上下文**中比较。

1. 提出 **GraphACM**：
   - **图框架**做 fine-grained 行为一致性测量 + UQ
   - 多次 rollout 同一任务 → **合并等价状态** → 建**有向 action-labeled graph**
   - 在**共享决策状态**做 action 比较
2. 引入 **node-level + global measures** of action consistency。
3. **Global consistency score** 作为 uncertainty proxy 预测 task success。

---

## 技术方案

### Graph Construction
```
For task T, run K rollouts:
  - 每个 rollout = state-action 序列
  - 等价 state 合并 (same observation / tool result)
  - 在 state 节点上记录 action distribution
  - 边 = state → state transitions
```

### Measures
- **Node-level**: 在 state s，across rollouts action distribution 的 entropy / 共识度
- **Global**: 整个图结构的一致性（path overlap / divergence）

### Uncertainty → Success
- Global consistency 分数 → **预测 task success 概率**（高一致性 → 高成功概率）
- 也可作为**何时 escalate to human** 的信号

---

## 实验结论

- GraphACM 在多个 agent benchmarks 上比单任务分数方法**显著**更准预测 success。
- Node-level measure 能定位**具体哪个决策点** 不稳定。
- 与 self-consistency 等 token-level 方法**正交**，可叠加。

---

## 关键洞察

- **等价 state 合并**是 multi-step UQ 的核心 trick——否则不同 rollout 在不同 state 上比较 actions 是无意义的。
- **Agent UQ 不同于 LLM UQ**：需要在决策空间（state space）而非 token space。
- 这是 UQ **在 agentic 系统** 中的系统化方法。

## 实现建议

- **实现难度**：中（需要 rollout 多次 + state merge + graph 算法）
- **预期性能**：agent reliability 评估 + 自适应 escalate
- **适用场景**：agent 部署监控、agent 测试 / 评估、agent human-in-the-loop 触发

---

## 局限性

- State merge 的等价性判据依赖任务定义。
- K 次 rollout 计算成本高。
