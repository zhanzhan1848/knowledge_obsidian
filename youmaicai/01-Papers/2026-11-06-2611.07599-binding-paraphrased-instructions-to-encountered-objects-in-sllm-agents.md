# Binding Paraphrased Instructions to Encountered Objects in sLLM Agents under Partial Observability

## 摘要
RL 微调的小模型 agent（sLLM）在具身任务上已能与更大的 prompted LLM 匹敌，但其对**指令改写（paraphrase）**的鲁棒性未知。作者提出 **ALFWorld-Para** 做受控改写评测，揭示成功率下降 **21–52%**，主要由**物体同义词**驱动。关键诊断：agent **保留了关于同义词指称的知识，却往往在真正观察到该物体后仍不去拿它** —— 暴露了**指称知识与物体绑定之间的落差**。部分可观测性让绑定更复杂：指称对象可能尚未出现，或已以不同标签被遇到。为此提出 **BINDIntent** —— 一个**免训练**框架，用**语义邻近度**与**针对未见候选的估计持久性**，把指称表达式概率性地绑定到已观察到的标签上。无需额外训练或 LLM 调用，BINDIntent 将 RL 微调 sLLM 的同义改写成功率提升 **17.5–49.1 个百分点**，每步 CPU 开销仅 **0.4 ms**；同时把 **GiGPO-7B 的总体成功率从 61.8% 提到 77%**。

## 核心贡献
1. 提出 **ALFWorld-Para** 受控改写评测集，量化 sLLM agent 对指令改写的脆弱性（成功率下降 **21–52%**）
2. 定位失效机制：**指称知识与物体绑定之间的落差** —— 知道同义词却不去拿对应物体
3. 提出 **BINDIntent**：免训练的概率性绑定框架（语义邻近度 + 针对未见候选的估计持久性）
4. 效果：同义改写成功率 **+17.5–49.1 pp**，每步仅 **0.4 ms** CPU；GiGPO-7B 总体 SR **61.8% → 77%**

## 方法与架构
**评测（ALFWorld-Para）**：在 ALFWorld 场景下对指令做受控改写，测量成功率下降幅度；主因是**物体同义词**。

**诊断**：区分两个能力 —— (a) 指称知识（知道「cup」和「mug」指同一物）；(b) 物体绑定（观察到后采取对应动作）。**部分可观测性**下指称对象可能未出现或已以其他标签被遇到。

**BINDIntent（免训练）**：
```
score(label | referring expression)
  = f( semantic proximity(expr, label),          # 语义邻近度
        estimated persistence(label vs unseen candidates) )  # 估计持久性
```
用**估计持久性**处理「已用其他标签遇到」的情形，用语义邻近度处理同义匹配。**无额外训练、无 LLM 调用**。

## 实验结果
- **ALFWorld-Para**：改写导致成功率下降 **21–52%**，主因是物体同义词
- **BINDIntent**：同义改写成功率提升 **17.5–49.1 pp**，每步 CPU 开销 **0.4 ms**
- **GiGPO-7B 总体 SR：61.8% → 77%**

## 局限性
- 只在 ALFWorld 一个具身环境评测，绑定策略在其他环境（真实场景、3D）泛化未验证；
- 语义邻近度依赖嵌入模型质量，对同形异义/多义词处理能力受限；
- 「估计持久性」在物体被多次重命名或真正消失时的行为未分析。

## 值得注意的点
「**知道同义词但不去拿它**」是一个精准的能力拆分 —— 把「知识」与「绑定」分开后，修复路径立刻清晰：不需要再训模型，只需要一个轻量的绑定层。这是今日典型的「把 LLM 的判断交给确定性/概率性机制」的延续路线。
