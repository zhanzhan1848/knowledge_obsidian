## 核心贡献

> 识别 **on-policy self-distillation (OPSD)** 中"单一完整参考"导致的 **reference-induced target instability**，提出 **Monte Carlo Privileged Distillation (MCPD)** —— 把特权上下文建模为**参考视图的分布**，蒸馏其**边缘 teacher 分布**。

1. **现有做法**：OPSD 训练模型在自己的轨迹上，用一个**特权副本**（条件于完整参考答案）提供 **dense token-level 监督**。
2. **问题**：**参考只是一个推理过程的一种实现**。它虽然提供答案证据，但同时编码了**顺序、措辞与解题路径**。因此 full-reference conditioning 可能产出**依赖推理时学生不可得的信息**的正确目标。
3. **现象定义**：**reference-induced target instability** —— 固定 problem 与 student state，**仅替换一个有效参考**即可显著改变 teacher 分布。
4. **方案 MCPD**：
   - 将特权上下文建模为**partial reference views 的分布**；
   - 在多个 view 下评估 teacher，**平均其 next-token 分布**（概率空间平均）；
   - **理论**：该概率空间平均恰为"在特权 view 上最小化期望 teacher→student KL 散度"所诱导的**精确目标**。

---

## 技术方案

| 组件 | 说明 |
|------|------|
| Reference views | 部分参考（partial reference）的采样 |
| Teacher marginalization | 多次评估 → 平均 next-token 分布 |
| Optimality | = min E_view[KL(teacher ‖ student)] 的精确解 |
| 效果 | 更 reference-consistent 的监督 |

### 关键洞见

- 这是**变分视角**的应用：把"参考"当作隐变量而非固定条件 → 蒸馏边缘分布而非条件分布。
- 实践含义：蒸馏时的**参考多样性**是超参，不是细节。单一 golden reference 会让 student 学到"复现那条路径"，而不是"那条路径的答案"。

---

## 实验结论

- **基准**：数学与科学推理 benchmark
- **结果**：
  - MCPD 产生**更 reference-consistent 的监督**；
  - **一致优于 full-reference OPSD**。

---

## 局限性

- 多 view 评估 → **teacher forward 次数增加**（成本上升幅度未量化）；
- view 采样策略的选择敏感（paper 用了哪些 view 构造未在摘要展开）；
- 只在 reasoning 任务验证，code / agent 场景待测。

## 实现建议

- **实现难度**：中（需构造 partial reference views + 多 teacher forward 聚合）
- **预期价值**：中高 — 直接提升蒸馏的**稳健性**（不绑定单一路径）
- **适用场景**：reasoning 模型蒸馏、teacher 数据不完美时、自蒸馏 pipeline
- **建议部署**：在蒸馏 pipeline 中引入**参考多样化**（多解 / 多措辞），是低成本高收益的改动
