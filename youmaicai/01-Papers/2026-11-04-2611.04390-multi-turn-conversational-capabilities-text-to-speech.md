## 核心贡献
1. 发布 **Omnilingua-AudioMC**：Audio MultiChallenge (AudioMC) 的严格平行多语言扩展，**354 段对话 / 1,827 个用户轮 / 1,404 个 rubric 条目 / 10 种语言**（en/zh/ja/es/fr/ru/de/it/th/vi），覆盖 Inference Memory (IM)、Instruction Retention (IR)、Self Coherence (SC)、Voice Editing (VE) 四种能力；转录与语音两种条件在对话内容、轮结构、跨轮依赖、评分标准上完全对齐。
2. 证明**转录文本成绩是语音多轮对话能力的不可靠代理**：Muse-Spark 1.2 在 Reference Transcript 上以 **64.0%** 位居第一（高于 Qwen3.8 的 60.9%），但在 Direct Audio 上暴跌至 **32.4%**（−31.6 pp），成为最弱模型；而 Qwen3.8 从 60.9% 只掉到 60.2%（−0.7 pp），Direct Audio 达 **60.2%** 居首。
3. 转录→语音的迁移**强依赖语言**：Muse-Spark 在全部十种语言都损失 25–35 分；Gemini 3.1 Pro 损失 3–15 分；Qwen3.8 全程约 3 分以内且在日语、泰语上 Direct Audio **反而超过** Reference Transcript。语言强度排序会重排——中文是 Gemini 3.1 Pro 最强的非英语参考语言，却在其最弱的 Direct Audio 语言之列。
4. 引入**配对 rubric 级分析 + survival 指标**，揭示聚合分数会掩盖能力损失：Qwen3.8 的 reference-only 与 audio-only 份额接近 1.1:1（相互抵消），但其越南语 IM survival 仅 **77.8%**（中文 93.0%）；Muse-Spark 的 IM/IR survival 低至 **61.3% / 56.9%**（日语 IR survival 仅 40.4%），说明"记忆失败"不足以解释其失败画像。
5. 设计**四条件因子干预**（Direct Audio / History Transcript / Current Transcript / Full Transcript）来定位可恢复的退化来源。对 gap 最大的两个模型，**History Transcript 的恢复幅度显著大于 Current Transcript**，且这一数值序关系在全部十种语言一致：Muse-Spark +20.1 vs +6.2 pp，Gemini 3.1 Pro +5.7 vs +2.8 pp；Full Transcript 分别 +26.2 与 +6.4 pp。
6. 证明**转录替换并非普适有效**：Qwen3.8 作为最强 Direct Audio 模型，单替换近乎零收益（60.1/60.1 pp），Full Transcript 甚至下降；其余模型存在语言级的反转。
7. 发现两种替换**恢复的失败集合部分重叠**：在"参考转录成功但 Direct Audio 失败"的对话中，**50–70%** 只被其中一种替换救回；六个模型中有五个的 History-only 救回数多于 Current-only。

## 问题背景
语音-语言模型被越来越多地部署为多语言对话助手。成功的语音交互远不止"听懂当前这句话"：回答可能依赖几轮之前引入的信息、全程持续生效的指令，或者是对先前已建立会话状态的修正（"5 根黄油，改成 10，算了还是 5 根"）。一个模型可能在**看到对话转录**时满足这些多轮要求，却在同样内容以**语音**形式呈现时失败。

现有的多轮对话能力评测几乎都在**转录文本**上进行。核心未答问题是：(1) 从文本上展示出来的成功能否迁移到语音？(2) 这种迁移在不同语言间是否一致？

Reference Transcript 作为**受控诊断基线**的关键设计在于：它保留了口语交互中的犹豫、重复、错误起头、自我修正等真实措辞特征，同时**去掉了处理音频的负担**。因此"参考转录 vs 语音"的对比问的是"同一批对话要求，仅改变表示模态后模型能否满足"，而不是在比较两个不同任务或两组独立构造的样本。

作者同时指出了已有评测的错位：XNLI/MGSM 扩展了跨语言推理但只看文本；Multi-IF 把多语言评测带到多轮指令遵循但仍是文本；Speech-IFEval 分离了指令遵循与语音感知；DOWIS 提供跨语言平行书面/真人录音 prompt；MCIF 评估科学演讲上的跨语言指令。AudioMC 本身提供了人类录音对话与能力框架，但仅单语（英语），且其比较的是 Direct Audio vs 共享 ASR 级联。

## 方法

### 1. 基准构成与严格平行原则
- 354 段对话、1,827 个用户轮、**1,404 个 rubric 条目**、10 种语言、10/11 个参考转录与语音条件；
- 按能力：IM 82 段、IR 95 段、SC 77 段、VE 100 段；
- **严格平行（strict parallelism）**：每个 benchmark item 在各语言与各模态下实例化，共享同一对话、轮结构、跨轮依赖与评分标准。这是把条件间差异归因于"语言与输入表示"而非"对话内容变化"的前提。
- 报告两级指标：**rubric-level success**（通过标准占已评分标准的比例）与 **conversation-level instance success**（该对话的全部 rubric 必须满足）。默认宏平均对十语言等权。
- **平行过滤（parallel filtering）**：所有条件都从同一最终对话集构建——若某对话无法在某种语言中可靠实现，则从所有对齐条件中移除，保持对话与 rubric 层面的可比性。该过滤也移除了上游 AudioMC 中嵌入背景音的记忆能力对话（本工作只考虑语音）。

### 2. 语音锚定的多语言平行构建
**保持交互结构**：从 AudioMC 的人类录音英语对话与其转录出发。localization **不是独立翻译 utterance**，而是保留任务相关内容、会话状态转移、跨轮依赖与评估要求，在目标语言的自然语音中实现；每个用户轮在本地化时可访问英语源历史与此前已本地化的轮次，以维持实体、指代、术语与状态更新的一致性。源转录分析识别出任务相关的口语现象（犹豫、重复、错误起头、自我修正），并在本地化中保留其交互结构。**自我修正是关键**：若只保留 "5 sticks of butter, make that 10, actually stick with 5" 的最终值 5，就会移除原交互所要求的那段会话推理。产出的 spoken-form 文本同时充当 Reference Transcript 输入与语音合成的语言内容，把两个模态锚定到同一个意图交互上。

**控制语音实现**：使用**单一多语言 TTS 系统**实现本地化后的用户轮，每个对话内**固定 speaker→voice 映射**，并在各合成语言间复用，从而减少说话人分配变化，也不假设多语言语音预设在声学上对应同一说话人。另用相同流程合成 **EN-TTS** 条件（英文原文 + 同一 pipeline），作为与真人录音的同语言内对照。

**验证内容与维持平行**：
- 文本审阅检查语义忠实度、自然度、跨轮实体一致性、rubric 适用性、任务关键修正的顺序；
- 音频审阅结合**多个 ASR 系统的转录**与基于模型的语义比对（对 spoken-form 参考），识别遗漏、添加或改变含义的替换；由于识别错误可能形似合成缺陷，歧义案例走额外复核而非自动拒绝；
- 确认的缺陷触发**重合成**（同一参考文本与同一 voice 分配），随后重新验证。

### 3. 评测协议
沿用 AudioMC 的 fixed-context、binary-rubric 协议：在指定轮，user turns 以参考转录或语音呈现，**preceding assistant turns 保持固定文本**，模型只生成指定的那一个响应。评审模型为 **o4-mini**（judge 选择的稳健性在附录 D 评估）。

**四个核心输入条件**构成对"前序用户历史表示 × 当前轮表示"的因子干预：

| 条件 | 前序用户轮 | 当前用户轮 |
|------|-----------|-----------|
| Direct Audio | 语音 | 语音 |
| History Transcript | 模型生成的转录 | 语音 |
| Current Transcript | 语音 | 模型生成的转录 |
| Full Transcript | 模型生成的转录 | 模型生成的转录 |

Reference Transcript（保留口语形式的全转录）作为**独立的诊断基线**，位于因子设计之外。三个转录干预中，每个被评模型**只生成一次**替换转录，随后在对应条件间**冻结复用**。Full Transcript 用于检验两种干预效应如何联合。历史 assistant 响应全程固定为文本。

### 4. 统计方法
- **边际分数**用可得评审计算；**配对与因子分析**只用对应比较的共同条目/共同对话（common set）；
- headline 对比附**对话级 bootstrap 区间**（10 语言宏平均，95% CI，见附录 A.3）；
- 报告 **survival** 指标：参考转录下通过的 rubric 条目中，在音频下仍成功的比例——这是比聚合 gap 更能暴露能力损失的量。

- **Ablations / 控制条件**:
  - **EN-TTS 同语言实现对照**：用合成英文替换真人英文录音，Muse-Spark 变化 −0.3 pp、Gemini 3.1 Pro +0.6 pp（相对其非英语 gap 很小），Qwen3.5 Omni −4.5 pp。这说明**主要损失不是英文语音实现方式造成的**。
  - **恢复集合重叠**：在"参考成功但音频失败"的对话中，两种替换各救回一部分对方救不回的场景——六个模型上 **50–70%** 的恢复对话仅被其中一种替换救回；History-only 救回数在六个模型中的五个里超过 Current-only（附录 A.4）。

## 关键洞察
1. **文本多轮能力不是语音多轮能力的代理。** Muse-Spark 在转录上第一、在语音上倒数第一（64.0% → 32.4%）。任何用转录分数选型语音模型的流程都可能选反。跨语言语音助手的选型必须用语音条件下的平行评测。
2. **聚合 gap 会双向抵消，必须看配对层面。** Qwen3.8 的净 gap 只有 −0.7 pp，但那是"参考独有失败"与"音频独有成功"几乎 1:1 抵消的结果；其越南语 IM survival 仅 77.8%。**净差值小 ≠ 保留了同一批成功**，这是本文最可迁移的方法论结论。
3. **模态退化有明确的能力画像，不是单一"记忆问题"。** Muse-Spark 的 IR survival 56.9%、VE survival 68.0%，日语 IR 仅 40.4%——仅用"记忆"解释会漏掉大量指令保持与状态修订失败。记忆/指令保持是共同脆弱点，但失败面更宽。
4. **前序语音上下文的表示是可恢复退化的主要来源。** 对 gap 最大的模型，把前序 user turns 换成转录带来的恢复在**所有十种语言**都大于只换当前轮。这直接指向工程结论：多语言语音交互中，**历史轮次应显式转写/摘要后再入模态**，而不是让模型在音频域内硬扛长历史。
5. **转录替换不是万能药。** Qwen3.8 几乎无收益且 Full Transcript 更差；其余模型存在语言级反转。策略必须按模型/语言自适应，不能假定"ASR 级联总是更好"。
6. **口语的不完美性本身就是任务的一部分。** 保留犹豫、重复、错误起头、自我修正是基准有效性的前提；若只保留最终值，"5→10→5"这类交互的会话推理要求就被消解了。这对任何口语基准设计者都有直接参考价值。
7. **同语言 TTS 对照是必要的方法论。** EN-TTS 证明"合成 vs 真人"不是主要混淆因素，从而把差异归因到模态与语言；没有这个对照，多语言 TTS 数据的结论会无法解读。

## 局限性
- History Transcript 替换**多个**前序轮，而 Current Transcript 只替换**当前一轮**，因此设计**没有分离"信息所在位置"与"被替换音频量"**——作者明确承认这一点。
- Full Transcript 的交互项估计为次要结果，common-set 交互区间跨零或接近跨零，**可加性偏离未被确证**。
- 除英语外的 9 种语言全部为 **TTS 合成**（商用 TTS 系统），虽经多 ASR + 模型语义比对验证，仍可能带有合成语料的分布特征；EN-TTS 只控制了英文，**目标语言的合成效应未被隔离**。
- 生成的替换转录来自**被评模型自身**，可能引入模型偏好的表述分布，形成一定程度的"自我一致"效应。
- 四个额外开源模型（Qwen2.5-Omni、Voxtral-Mini、Qwen3-Omni、Voxtral-Small）因各条件保留集不同，**只报告边际结果，无配对与干预分析**。
- 固定上下文协议只测指定轮的内容正确性，**不涉及全双工交互、打断、轮次重叠**（不同于 M3-DuplexBench）。
- 评审依赖单一 judge（o4-mini），虽附录 D 有稳健性分析，但整体分数仍受 judge 偏好影响。
- 基准从上游 AudioMC 的英语人类录音派生，**去除了嵌入背景音的记忆能力对话**，覆盖面因此收窄。
- 全文提取中 bootstrap 区间的具体端点数值未在正文中呈现（部分数值位于表格/附录图形中），引用时需查原文附录 A.3。

## 适用场景
- **适用**：多语言语音助手/客服/车载语音的选型与回归评测；把语音模型从"转录基准"迁移到真实语音场景前的风险评估；语音 Agent 的架构设计（是否在模型前加 ASR 转写历史）；多轮语音对话中记忆与指令保持专项 debug。
- **不适用**：需要全双工、流式、打断能力的实时语音系统评测（本基准是固定上下文单轮生成）；英文单语场景（英语部分已被上游 AudioMC 覆盖）；非对话式语音任务（ASR、说话人识别、语音情感）。
- **不适用**：需要绝对分数作为跨论文横向对比的基准（该设计是为**配对/因子**对比优化的，绝对值的外部可比性有限）；方言、口音噪声、远场麦克风等真实声学条件（仅用近场 TTS/录音）。
