## 核心贡献

> 通过纯训练分布设计（在第二跳位置同时暴露 ID 与 OOD 原子事实），让一个从零训练的 GPT-2 类 Transformer 把 ID 上学到的两跳组合规则迁移到 OOD 原子事实，从而在受控实验中闭合「组合性鸿沟」——不改架构、不加 OOD 组合监督。

1. 证明「把 OOD 原子事实放在第二跳兼容位置」本身**不足以**实现 OOD 组合泛化——单纯的位置对齐不能闭合组合性鸿沟。
2. 识别出真正起作用的额外条件：**ID 与 OOD 原子事实共享同一个位置对齐表示**，从而在第二跳处理阶段把 ID 上学到的组合规则与 OOD 事实隐式连接起来。
3. 在受控两跳推理设置中完整恢复了 OOD 组合泛化（OOD 测试准确率从接近 0 提升至完全泛化），并证明这一效应是 grokking 训练regime 下延迟出现的。
4. 用 identity-bridge 监督（Lin et al. 2026）作为对照，说明在本设置的高复杂度下它无法诱导出组合泛化——本文的干预是「迁移已学到的组合规则」而非「诱导出捷径映射」，机制上与 Lin 等人区分开来。

## 技术方案

### 核心思想

组合性鸿沟（compositionality gap, Press et al. 2023）指的是：模型能分别答对两个原子问题，却答不对它们的组合。Chain-of-Thought 通过外显中间步骤在推理时缓解它，但并不触及「隐式推理」——即在单次前向传播内部、不语言化中间步骤地完成多跳组合。Wang et al. (2024) 在合成知识图上从零训练 Transformer 后恢复了其组合泛化电路：**下层解析第一跳并存储中间的桥实体（bridge entity），上层用该实体检索第二跳答案**。

已有工作的一致结论指向第二跳是瓶颈：Yang et al. (2025) 发现模型规模增大时第一跳的隐式解析迹象增强，而第二跳表现几乎不变；Ye et al. (2025) 进一步发现组合泛化可以延伸到「第一跳 OOD」的查询，但**第二跳 OOD 则不行**——除非对应事实在训练中曾以第二跳位置出现。Karmim et al. (2026) 则发现只有被组合样本曝光过的实体（ID）才能获得组合泛化。Biran et al. (2024) 在预训练模型中观察到同样的不对称：桥实体在浅层被解析，第二跳只在深层被解析。

本文因此提出一个机制启发的假设：**OOD 组合迁移失败，可能不是架构容量问题，而是原子知识在训练中被「结构化暴露」的方式问题**。原文的训练分布里，OOD 原子事实只在孤立形式下被学习，从未以与第二跳组合阶段相对应的输入构型出现。

### 位置对齐原子暴露（Position-Aligned Atomic Exposure）

干预做法是：把每一条原子事实额外以「第二跳兼容格式」再呈现一次。原始原子事实形如 `h r1 b`（h 为头实体、b 为桥实体），干预后额外呈现为 `h r1 [MASK] r2 b` 形式，其中 `[MASK]` 是一个**非预测性特殊 token**（原实现中记作 `<mask>`，作者为避免与掩码语言建模的 mask token 混淆而改用该符号），仅作位置占位符，且被排除在训练损失之外。

这里有两个关键约束，也是本文的方法论核心：

- 这些新增样本**只包含原有的原子关系**，不引入任何新的两跳组合训练样本——因此干预改变的是「已有原子知识如何被暴露」，而不是「提供了额外的组合监督」。
- ID 与 OOD 原子事实**都**以该格式呈现，从而让两者共享同一个位置对齐表示。这是与「只暴露 OOD」的关键区别，也是消融实验 (a) 揭示的核心发现。

作者的机制假设是：共享的位置对齐格式在第二跳阶段充当了「知识桥梁」——ID 事实通过组合训练把该格式与组合任务连起来，该格式再被 OOD 事实共享。这种重叠可能把优化偏向于「ID 与 OOD 知识能被同一个第二跳计算同样处理」的表示，使得在 ID 例子上学到的组合上下文可以延伸到 OOD 情形。这与 Ye et al. (2025) 观察到的机制一致：OOD 第一跳表示会与 ID 第二跳表示对齐，从而带来部分跨分布泛化。

### 三组受控消融

| 消融 | 设置 | 结果 |
|------|------|------|
| (a) 移除 ID 的第二跳格式 | 保留 OOD 的第二跳兼容样本，删去 ID 的 | **OOD 组合泛化未达成** → 位置对齐本身不充分，共享表示是必要条件 |
| (b) 部分 OOD 第二跳暴露 | 保留全部 ID 的第二跳格式，仅把该格式施加于 OOD 事实的一个子集 | 仅得到**部分** OOD 组合泛化 → 第二跳兼容暴露的**程度**直接约束迁移程度 |
| (c) 移除两跳组合监督 | 保留全部位置对齐原子事实，删除所有两跳组合样本 | 模型在 **ID 与 OOD 上都失败** → 原子表示本身不足以支撑组合行为，组合监督不可省 |

附录另做 identity-bridge 对照：引入零跳身份监督（把桥实体映射到自身）、保留原子数据、删除所有两跳组合样本。结果训练准确率接近完美，但 ID 与 OOD 组合测试准确率**均为零**——说明在本文这个第一跳/第二跳关系类型都变化、复杂度更高（沿 Lin et al. 的第一跳复杂度轴分支因子更大、且第二跳变异性远高于其固定单关系设置）的设置中，identity bridge 监督无法从原子监督单独诱导出组合行为。

## 技术方案（实验设置）

### 数据构造

沿用 Wang et al. (2024) 的严格合成两跳设置：原子事实为有向关系三元组 `(h, r1, b)` 与 `(b, r2, t)`，查询为 `h r1 r2`，目标是预测尾实体 t 而不给出桥实体 b。典型例子：「Barack 的妻子是 Michelle」+「Michelle 生于 1964」⇒ 推断「Barack 的妻子生于 1964」。

ID/OOD 划分按原子事实 95% / 5% 切分（附录 A.1.1 明确 ID 95%、OOD 5%）。训练包含全部原子事实（ID 与 OOD 都出现）以及**只由 ID 事实构成**的两跳样本；OOD 组合留作评估。因此模型见过 OOD 原子事实本身，却从未见过它们的组合用法。

两个规模配置：

- **Small（主实验）**：200 个实体、20 个关系类型、每个实体出度 20（即每实体覆盖全部 20 种关系类型，关系覆盖密集，学习更快，适合做大量干预与消融）
- **Full（附录 A.3）**：沿用 Wang et al. (2024) 的原始规模，2,000 个实体、200 个关系类型、出度固定为 20（每实体只被分配 200 种可能关系类型中的 20 种）

### 模型与训练

标准 GPT-2 式 decoder-only Transformer，**从零训练**（以排除预训练混淆）：8 层、隐藏维度 768、12 个注意力头；优化器 AdamW，weight decay 0.03，batch size 512，2,000 步线性 warm-up，2,000 步学习率调度为具体数值见原文；用 AutoTokenizer 为合成符号构建数据集专用词表。评估指标为 ID 与 OOD 两跳组合任务的精确匹配准确率（exact-match accuracy）。全文含 grokking 现象的延迟泛化曲线（Fig. 1、Fig. 4、Fig. 5）。

## 实验结论

- **数据集**: 自建合成两跳知识图（Small: 200 实体 / 20 关系类型 / 出度 20；Full: 2,000 实体 / 200 关系类型 / 出度 20），原子事实按 95% ID / 5% OOD 划分，ID 组合训练、OOD 组合评估
- **基线**: 原始训练分布（无位置对齐暴露）的模型作为对照；消融基线三种（移除 ID 第二跳格式 / 部分 OOD 暴露 / 移除组合监督）；另与 Lin et al. (2026) 的 identity-bridge 监督对照
- **结果**: 完整位置对齐干预下，OOD 组合测试准确率在 grokking 训练 regime 中延迟上升，最终达到完全组合泛化；原始训练分布下 OOD 准确率始终接近零（Fig. 1 灰色虚线）

- **消融 (a)**：仅暴露 OOD 原子事实于第二跳兼容格式 → OOD 组合泛化**未达成**，证明位置对齐本身不充分；必须在同一格式下同时暴露 ID 原子事实
- **消融 (b)**：仅把第二跳格式施加于部分 OOD 事实 → 得到**部分** OOD 组合泛化；在 Full 规模下部分暴露**完全阻断** OOD 泛化（与 Small 规模下的「仅部分降低最终准确率」形成对比）
- **消融 (c)**：移除全部两跳组合样本 → 模型在 **ID 与 OOD 测试集上都失败**，说明位置对齐的原子表示本身不足以支撑组合行为（该消融在 Full 规模下因 Small 规模已明确失败而未复现）
- **Identity-bridge 对照**（附录 A.2）：训练准确率接近完美，但 ID 与 OOD 组合测试准确率**均为零**，说明在本文更高复杂度的设置中身份桥接监督不足以单独诱导组合泛化
- **Full 规模（附录 A.3.1）**：更大但更稀疏的数据集需要显著更长的训练才出现 grokking 迹象与有效泛化，训练/测试指标均呈**延迟收敛**；证据倾向于「充分训练后最终准确率可与小数据集模型相当」，但因算力限制**未经验证**
- **数据密度效应**（Fig. 4）：Small 数据集因关系覆盖密集，在给定优化步数内即达到 OOD 测试集满准确率；Full 数据集则在步数内未能达到满准确率，说明密度显著加速泛化
- **Full 规模消融 (a)**（Fig. 5(a)）：行为与 Small 一致，缺少 ID 原子事实的第二跳格式会阻断 OOD 泛化，作者称这一缺失结构充当了 ID 与 OOD 之间的「知识桥梁（knowledge bridge）」
- **Full 规模消融 (b)**（Fig. 5(b)）：部分 OOD 放置**完全阻断** OOD 泛化，可能归因于 Full 数据集密度较低、第二跳位置 OOD 事实的减少对维持知识转移是致命的；也可能是泛化被延迟而非完全受阻，尚待进一步研究

## 局限性

- **仅限两跳组合推理**与受控的 GPT-2 类设置，未验证是否延伸到更长的推理链
- **纯合成、算法生成数据**——虽然能精确控制训练分布，但也限制了结论向自然语言与真实世界推理场景的直接迁移
- 作者明确承认：在更大模型与更不结构化的任务中，组合机制可能更分布化、其计算阶段更难辨识，因此定位相关机制与训练条件会更困难；本文的具体位置对齐格式也**未必能直接迁移**
- Full 规模下「充分训练后能否达到与 Small 相同的最终准确率」仅为推测，**未经验证**（算力限制）；Full 规模消融 (b) 的结果也存在「完全阻断 vs. 泛化延迟」两种解释并存
- 消融 (b) 在两种规模下行为不一致（Small 部分泛化 vs. Full 完全阻断），说明该机制的鲁棒性对数据密度敏感
- Identity-bridge 对照被作者自述为「概念性改编而非精确复现」，因为底层数据构造不同
- 论文未给出 ID 测试准确率的绝对数值表格化报告，主要以图（Fig. 1–5）呈现曲线，数值精度受限

## 实现建议

- **实现难度**: 中。干预本身实现极简（在数据构造循环里多生成一种格式的样本即可），主要成本在于搭合成两跳知识图、从零训练 Transformer 并观察到 grokking 现象所需的算力与调参；消融实验需要跑 3–4 组独立训练
- **适用场景**: (1) 机制可解释性研究——定位组合泛化的瓶颈阶段并据此设计干预；(2) 知识图谱补全/多跳问答系统的训练数据构造——当原子事实已知但全组合监督不可行时，可用位置对齐格式连接两者；(3) 教学与假设验证——为「训练分布设计 vs. 架构改造」这条路线提供受控证据
- **建议**:
  - 若业务目标是「让模型把已学到的组合规则迁移到新知识」，本论文提示了一条比改架构更便宜的路径：**在新知识出现的位置上复用学规则时用过的输入构型**，且**必须让新旧知识共享同一构型**，只暴露新知识是不够的
  - 该结论的重要限定是「训练分布」而非「数据量」：Full 规模结果表明更大更稀疏的数据反而延迟 grokking，关系覆盖的**密度**比实体数量更关键——数据构造时值得优先保证覆盖密度
  - 复现时应注意两点：一是必须从零训练（否则预训练干扰归因）；二是要跑够步数以越过 grokking 的延迟期，Short-horizon 的评测很容易误判为「干预无效」
  - 与 Lin et al. (2026) 的 identity-bridge 路线要分清：前者是「从原子监督诱导捷径」，本文是「迁移已在 ID 上学到的组合规则」，两者的失败模式不同，引用与对比时不要混为一谈
  - 对更大模型/更真实数据的迁移，建议用机制分析（先定位组合电路的瓶颈阶段）而非照搬本文的具体格式，作者本人也是这么建议的
  - 本文的价值主要在**科学论证**层面：「组合性鸿沟不是架构层面的根本限制」这一结论对当前的架构改进研究路线（参数共享、循环深度、DiscoLoop 等）是一个有价值的对照点——如果训练分布设计就能在受控设置中闭合鸿沟，那部分架构改造的收益可能被高估

## 原始摘要

```
Compositional generalization remains a persistent limitation of transformer language models: even when a model learns to combine known facts correctly in-distribution (ID), the same compositional mechanism may fail when applied to out-of-distribution (OOD) knowledge. We investigate this compositionality gap in a controlled two-hop reasoning setting using a GPT-2-like transformer model trained from scratch. Building on prior work identifying a circuit associated with compositional generalization, we test whether the failure of OOD transfer is related to how atomic knowledge is structurally exposed during training. We modify the training distribution by presenting both ID and OOD atomic facts in a format positionally aligned with the second-hop retrieval step of the learned compositional circuit, without modifying the model architecture or adding OOD compositional supervision. Under this intervention, the model successfully transfers the learned ID compositional behaviour to held-out OOD atomic facts, closing the observed compositionality gap in the controlled setting. Our results provide evidence that the observed compositionality gap is not a fundamental architecture limitation and that it can be overcome through mechanistically informed training distribution design.
```

> 备注：本文对 LLM/NLP 社区的核心价值有三点：(1) 给出了「组合性鸿沟」的一个受控、可干预、可消融的实证框架；(2) 提示数据构造（尤其是覆盖密度与「知识暴露位置」）是被低估的杠杆；(3) 与 Lin et al. (2026) 的对照实验清晰区分了「迁移已学规则」与「诱导捷径」两种机制。局限是纯合成两跳设置与从零训练的 8 层小模型，结论外推到真实预训练模型需谨慎。
