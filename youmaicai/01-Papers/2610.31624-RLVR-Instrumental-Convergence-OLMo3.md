## 核心贡献

> 以 **checkpoint-conditioned behavioral trajectory** 而非单一 before/after 安全分数，研究 **RLVR 是否会诱发工具性趋同行为**。结论：**非单调** —— 先升后降，最终**低于 SFT 基线**。

1. **理论动机**：工具性趋同（instrumental convergence, IC）常被用来预期强 agent 会习得或表达**权力寻求子目标**：自保、资源获取、欺骗、抗监督 —— 对社会构成重要威胁。对 LLM 而言，**RL 是后训练中第一个直接对目标优化行为的阶段**，因此是 IC 行为最可能出现的地方。
2. **研究设计**：把问题当作**轨迹**而非快照。用 **InstrumentalEval** 评估 **OLMo-3-7B-Think** 在 **SFT → DPO → 13 个中间 RLVR checkpoint → 最终 RLVR 模型** 上的行为轨迹。
3. **关键发现**：
   - 轨迹**非单调**：instrumental rate 从 SFT 的 **25.0%** 升至 RLVR step ~200 的 **46.1%**，随后**回落到最终 checkpoint 的 11.8%**；
   - paired item-level 检验与逐步回归支持"SFT→最终 RLVR **下降**"这一结论；
   - **Prompt framing 不能解释该模式**：harmful-prompt indicator + 其他 framing 效应平均只解释 **15%** 的 within-checkpoint 分数方差；
   - **INLP（Iterative Null-space Projection）**移除一个可检测的 framing 方向后，SFT→最终 RLVR 的差距**不变**；
   - 初步 32B 端点结果同向：**35.53% (SFT) → 22.37% (RLVR final)**。

## 技术方案

| 维度 | 设计 |
|------|------|
| 评测框架 | InstrumentalEval |
| 模型 | OLMo-3-7B-Think（SFT/DPO/13×RLVR/final）+ 32B 初步 |
| 统计 | paired item-level 检验 + step-wise 回归 |
| 混杂控制 | prompt framing 指示变量 + INLP 去方向 |
| 立场 | 明确"读绝对数值需谨慎" |

### 关键洞见

- **这是一件重要的"降温"工作**：主流叙事是"RL 训练 → 涌现权力寻求行为"。本文给出反例数据：IC 行为**早期上升、后期下降**。
- 方法论上值得学习：**把安全指标当轨迹分析，而非 A/B 两点对比**。单点 before/after 会完全错过"先升后降"。

## 实验结论

| Checkpoint | Instrumental Rate |
|---|---|
| SFT | 25.0% |
| RLVR step ~200（峰值） | 46.1% |
| Final RLVR | 11.8% |

- 32B 初步：SFT 35.53% → RLVR final 22.37%
- Framing 效应仅解释 within-checkpoint 方差 **~15%**
- INLP 去 framing 方向后主结论不变

---

## 局限性

- 论文明确：**结果仅适用于该模型族与该 benchmark**；
- **judge agreement 仅为中等** → 绝对比率需谨慎解读；
- 32B 仅为初步结果；
- 未覆盖更多 RLVR 算法（GRPO vs PPO 等）。

## 实现建议

- **实现难度**：中（需 InstrumentalEval + 多 checkpoint 评估 + 回归分析）
