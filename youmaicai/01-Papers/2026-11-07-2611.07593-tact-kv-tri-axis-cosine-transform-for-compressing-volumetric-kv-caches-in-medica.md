# TACT-KV: Tri-Axis Cosine Transform for Compressing Volumetric KV Caches in Medical VLMs

### 核心贡献
1. 提出 TACT-KV（Tri-Axis Cosine Transform）：一种 **calibration-free**（免标定、无需校准集）的 KV cache 压缩方法，首次将 3D 医学扫描 KV cache 的 **三轴解剖空间结构** 显式建模并利用，而不仅依赖 feature/token 统计量或 1D/2D 变换。
2. 用可分离 3D DCT 把 KV cache 变换到频域，按 reverse water-filling 分配每层比特预算（高能量频率分量给更多 bit），再用固定标量码本逐 bin 量化；并推导出 **close-form 关系**：自适应比特分配带来的失真下降幅度由变换后 cache 的 **谱集中度**（spectral concentration）主导。
3. 在 **6 个医学 VLM × 2 个 3D CT benchmark** 的主对比中，12 组「模型×数据集」配对里有 **11 组**取得最低的 1-bit prediction-flip rate；同样的优势在 **4 个通用 VLM 的视频任务**上复现，说明三轴结构的收益可跨域泛化；等 HBM 预算下单 GPU 解码 batch size 最高可扩展 **8×**。

### 技术方案
**核心思想**: 3D 医学影像（CT/MRI）的视觉 KV 状态沿三个解剖轴存在强空间相关性，这种相关性会把 KV cache 的能量集中到少数频率分量上。因此可先用可分离 3D DCT 做域变换把能量「打包」，再用 reverse water-filling 做分层比特分配，把预算集中砸在高能量 bin 上。

| 技术 | 说明 |
|------|------|
| 可分离 3D DCT | 对 KV cache 沿三个解剖轴（axial/coronal/sagittal 等价的三轴）做离散余弦变换，把空间域强相关信号集中到低频 bin，实现能量压缩；无需 calibration 数据 |
| Reverse water-filling 比特分配 | 在 **每层** 内部跨频率 bin 分配比特预算，规则为「高能量分量给更多 bit、低能量分量给少或零 bit」，是经典 reverse water-filling 最优比特分配的层内实例化 |
| 固定标量码本量化 | 每个频率 bin 使用固定标量码本量化（scalar quantization），避免为不同层/不同 bin 学习额外码本，从而保持免标定特性 |
| Close-form 失真关系 | 推导出自适应比特分配的失真下降幅度由变换后 cache 的 **谱集中度**主导 —— 集中度越高，收益越大；这解释了为何仅对 3D 视觉 KV 有显著效果 |
| 评测指标：1-bit prediction-flip rate | 在仅 1 bit 极低码率下统计模型预测发生翻转的比例，作为极低比特压缩质量的主要判据 |

### 实验结果
- **数据集**: 2 个 3D CT benchmark（具体名称摘要未说明）、4 个通用 VLM 上的视频任务（摘要未给出具体数据集名）
- **基线**: 现有 KV 压缩方法——基于 cache feature/token 统计量的方法、1D 变换方法、2D 变换方法（摘要未逐一列名）
- **结果**: 6 个医学 VLM × 2 个 CT benchmark 共 12 组配对中，**11 组**取得最低 1-bit prediction-flip rate；在 4 个通用 VLM 视频任务上复现同等优势；等 HBM 下单 GPU 解码 batch size 最高 **8×** 提升

### 局限性
- 依赖 3D（或具有三轴空间结构）的视觉输入；对纯文本或 2D 图像任务的收益幅度摘要未说明
- 方法要求 KV cache 可被组织为三维网格并做可分离变换，摘要未说明对任意 token 布局/动态分辨率、多模态混合场景的处理方式
- 主要以 1-bit 极低码率场景为评测重点（prediction-flip rate），中高码率下的表现摘要未说明
- 摘要未说明具体的医学 VLM 名称、CT benchmark 名称与绝对数值结果

### 关键洞见
> KV cache 的空间冗余不止是「token 冗余」，而是**几何冗余**：把 cache 放进对应输入几何的变换基（DCT）里，能量集中度本身就是压缩率的上限来源。因此「用 3D 结构」不是工程 trick，而是一个可推导的、与模型大小无关的普适规律——这也解释了为什么该方法能从医学影像迁移到通用视频 VLM。
