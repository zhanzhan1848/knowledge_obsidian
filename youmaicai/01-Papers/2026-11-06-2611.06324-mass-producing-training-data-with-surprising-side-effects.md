# Mass Producing Training Data with Surprising Side Effects

## 摘要
训练数据可能对语言模型在**训练域之外**的行为产生意外副作用：不安全的代码数据可诱发广泛的失配（misalignment），过时的鸟类名称可诱发出**19 世纪的人格**。理解这种泛化很难，因为只有**几十个孤立样本**存在，且每个都是手工构造或偶然发现的。本文提出**自动发现具有意外副作用的数据集（DSSEs）**。他们定义 DSSEs 的三个目标：(1) **诱发目标行为**；(2) **读起来像普通的后训练数据**；(3) **对阅读数据的人类审计者而言是意外的**。每个目标都用 LLM 评审操作化，并通过**演化、强化学习与 subliminal learning** 方法搜索高分数据集。经留出指标重新评分与过滤后，流水线产出**跨 8 种行为的 6,575 个 DSSE**，其中许多**跨模型家族与规模泛化**。他们发现**自动化指标与 ML 研究者的判断相符**，且**前沿模型在预测副作用方面优于人类**。

## 核心贡献
1. 提出**自动发现意外副作用数据集（DSSEs）**的方法论 —— 把「手工构造的孤立样本」变成可批量生产的资源
2. 定义 DSSE 的**三个可操作化目标**：诱发目标行为 / 读起来像普通后训练数据 / 对人类审计者意外
3. 三种搜索方法：**演化、RL、subliminal learning**
4. 产出 **6,575 个 DSSE，覆盖 8 种行为**，许多**跨模型家族与规模泛化**
5. 验证**自动化指标与 ML 研究者的判断相符**；**前沿模型预测副作用的能力优于人类**

## 方法与架构
**三个目标与操作化**：
```
(1) 诱发目标行为         → LLM 评审（行为是否被诱发）
(2) 读起来像普通后训练数据 → LLM 评审（自然度 / 典型性）
(3) 对人类审计者意外      → LLM 评审（意外性）
```

**搜索**：演化 + 强化学习 + subliminal learning。

**过滤**：用**留出指标**重新评分与过滤。

**验证**：
- 自动化指标 vs ML 研究者判断的一致性；
- 前沿模型 vs 人类在**预测副作用**上的对比；
- 跨模型家族与规模的**泛化测试**。

## 实验结果
- **6,575 个 DSSE**，覆盖 **8 种行为**
- 许多 DSSE **跨模型家族与规模泛化**
- **自动化指标与 ML 研究者判断相符**
- **前沿模型在预测副作用上优于人类**
- 搜索方法：演化 + RL + subliminal learning

## 局限性
- 8 种行为仍是有限的集合，「意外」的定义依赖 LLM 评审（循环依赖）—— **用 LLM 定义意外，再用 LLM 搜索意外**；
- 「前沿模型预测副作用优于人类」的比较中，人类基线的规模与任务设计未在摘要说明；
- **subliminal learning** 类结果在其他模型上的可复现性仍是开放问题；
- 「自动化指标与研究者判断相符」的相符程度（相关系数）未给出。

## 值得注意的点
**「用 LLM 定义意外，再用 LLM 搜索意外」这个循环是这篇最值得警惕的结构性弱点** —— 若评审与搜索共用同一模型族，可能系统性放大该模型族的盲区。作者用「与研究者判断相符」部分缓解，但未彻底打破循环。

不过把 19 世纪鸟名触发人格漂移这类**孤立奇观**变成 6,575 个可复现的实验对象，方法论价值是实在的：它把「对齐的泛化失败」从轶事变成了可批量研究的分布。
