## 核心要点
1. **BuySideFlow**：**408 个**从业者构造的中文任务（股票、基金、固定收益、宏观经济），固定于授权生产金融数据库的快照。
2. 提供可执行参考与**时点错误分类体系**，结果检查与专家审计的已执行工作流配对。
3. 九个 agent 配置在全部任务上**结果准确率 16.2%–36.8%**。
4. 关键审计：对 **100 个共享任务的 900 次运行**，在**通过结果检查的 380 次运行中有 193 次存在 PIT 违规（50.8%）**。
5. 结论：**输出吻合本身不建立时点有效性**——必须单独审计时点合规。

## 摘要（原文）
Large language models (LLMs) can generate SQL and SQL--Python workflows for investment research, but
ensuring point-in-time (PIT) validity remains challenging. Agents must enforce disclosure cutoffs
and select the appropriate historical states and record versions throughout data retrieval and
financial analysis. We introduce \textsc{BuySideFlow}, a benchmark of 408 practitioner-derived
Chinese-language tasks spanning equities, funds, fixed income, and macroeconomics over a fixed
snapshot from a licensed production financial database. We provide executable references and a
taxonomy of temporal errors, pairing result checks with expert audits of executed workflows. We
evaluate nine agent configurations on all tasks, with result accuracy ranging from 16.2\% to 36.8\%.
An audit of 900 runs on 100 shared tasks confirms PIT violations in 193 of the 380 runs that pass
result checks (50.8\%), showing that output agreement alone does not establish temporal validity.
