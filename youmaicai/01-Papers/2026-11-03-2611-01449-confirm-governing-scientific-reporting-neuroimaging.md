## 核心贡献
1. **揭示现有 agentic 系统的关键缺陷**：工具只检查**代码能跑**、**报告值与输出一致**，但**决定哪些结果值得科学报告**仍依赖 **LLM 判断**
2. **实证该缺陷的严重性**：**LLM 评审会认可带有站点混淆（site-confounded）的研究发现，即使该混淆被作为证据呈现**
3. **CONFIRM 框架**：把**"运行分析"与"决定报告什么"分离**
4. **机器可读的预指定分析计划（pre-specified analysis plan）**：**在计算结果之前**固定声明（claim）及其**通过标准（pass criteria）**
5. **五道确定性闸门（five deterministic gates）**：搜索历史与多重性、混淆、功效、分析稳定性、复现
6. **三档可配置的报告标准**：**Screen**（最宽松）→ **Replicate** → **Full**（最严格）
7. **NeuroClaimBench**：**489 条可执行的神经影像声明**，含冻结数据、文献支持的发现，以及 **150 条对照**（各自违反某一项方法学要求）

## 问题背景
LLM agent 已经能**自主完成从研究问题到报告发现的完整神经影像分析流程**。

现有 agentic 系统的验证手段是：
- ✅ 检查代码是否运行
- ✅ 检查报告的数值是否与代码输出一致
- ❌ **决定哪些结果值得科学报告 —— 仍靠 LLM 判断**

最后一环是**科学诚信的关键**，却是**自动化程度最低、主观性最强**的一环。

## 方法

### 核心分离
```text
【运行分析】  ← 自动化程度高（工具检查）
      ↓
【决定报告什么】 ← 原做法：LLM 判断（本工作替换掉）
      ↓
【CONFIRM】预指定分析计划 + 确定性闸门
```

### 预指定分析计划
每个假设被编码为**机器可读的预指定分析计划**，在**计算结果之前**：
- **固定声明（claim）**
- **固定通过标准（pass criteria）**

这是**预注册思想在 agent 系统中的实现** —— 与昨日 Qistas 预注册协议、[[2026-11-03-2611-01135-compile-as-hypothesis]] 的 AutoAPC-Select 预注册部署门同属一条线。

### 五道确定性闸门
| 闸门 | 拦截的问题 |
|------|-----------|
| **搜索历史与多重性**（search history & multiplicity） | 多次尝试挑出显著结果 |
| **混淆**（confounds） | 站点/人群等系统性偏差 |
| **功效**（power） | 样本量不足却声称显著 |
| **分析稳定性**（analytic stability） | 结果对分析选择敏感 |
| **复现**（replication） | 独立数据上不成立 |

### 三档报告标准
| 标准 | 严格程度 |
|------|---------|
| **Screen** | 最宽松 |
| **Replicate** | 中等 |
| **Full** | 最严格 |

### 失败诊断
被拒的声明获得**诊断信息**，用于**指导后续分析** —— 闸门不是死路，而是路由。

## 实验结果

### 核心对比（NeuroClaimBench）
| 方法 | 错误支持对照的比例 |
|------|----------------|
| **CONFIRM** | **最多 3%** |
| 基线 | **23% – 38%** |

即 CONFIRM 将错误支持率降低到基线的**约 1/8 至 1/12**。

### NeuroClaimBench 构成
| 组成 | 数量 / 说明 |
|------|-----------|
| 可执行神经影像声明总数 | **489 条** |
| 文献支持的发现 | 包含在内 |
| **对照（controls）** | **150 条**，各自**违反某一项特定的方法学要求** |
| 数据 | 冻结（frozen） |

### LLM 评审的失败模式
> **LLM 评审会认可带有站点混淆的研究发现 —— 即使该混淆被作为证据呈现。**

这意味着**混淆信息一旦进入上下文，LLM 就会把它当作支持性证据**。这是一个极具实战价值的负面发现。

## 关键洞察

1. **"LLM 会把混淆当证据"是本文最有冲击力的一句** —— 混淆被明确呈现，评审仍然认可。这意味着**任何把分析结果丢给 LLM 报告的系统，都在系统性地放大混淆效应**。修复路径不是"更好地提示模型"，而是**在模型看到之前就用确定性规则拦截**。
2. **"运行"与"报告"必须分离** —— 这是架构性的洞见。工具验证（代码能跑、数值一致）属于**执行正确性**；报告决策属于**方法学正当性**。把两者混在一起，就只能用一个不可靠的组件去做两件事。**分离之后，报告决策可以被确定性规则接管。**
3. **对照设计是本文方法论最强的一环** —— **150 条"各自违反一项要求"的对照**，使得闸门可以被**逐项**评估（每条对照只违反一项，因此可以精确定位是哪个闸门在工作）。这比"混合对照"的信息量高一个量级。
4. **3% vs 23%–38% 的量级差距说明闸门设计是有效的，而非边际改进** —— 错误支持率降一个数量级。
5. **"预注册"从学术规范变成了 agent 的架构组件** —— 把"在计算前固定判据"做成机器可读的计划，**预注册就可以被自动执行**，而不再依赖人的自律。这是预注册方法论在 agent 时代的自然延伸。
6. **与今日 [[2026-11-03-2611.01135-compile-as-hypothesis]]、昨日 [[2026-11-02-2610.40893]] 的强主线** —— 三天来反复出现的共同结构是：**把"判定标准"从事后的人的主观判断，前移为事前的、机器可读的、可确定性执行的规则**。这已经是一条非常清晰的研究路线。

## 局限性
- 单一领域（神经影像），闸门设计与领域方法学强相关
- 489 条声明 + 150 条对照的规模有限
- "文献支持的发现"部分的质量依赖文献本身
- 三档标准的划分（Screen/Replicate/Full）是本文提出的，外部采用需要额外验证
- 未评估闸门本身被绕过的情况（agent 是否会尝试调整分析计划以通过闸门）
- **摘要在末尾被截断**，部分结果未获取

## 适用场景
- **自动化科学分析 agent**（神经影像、生物统计、药物发现）
- 需要**可审计的科学报告流程**的机构
- 任何"agent 产出结论"的场景（把结论决策从 LLM 手里拿走）
- 预注册方法论在自动化系统中的实现参考
