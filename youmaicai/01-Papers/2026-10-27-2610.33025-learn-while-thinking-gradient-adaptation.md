## 核心贡献

> 系统测量「动态评估」（dynamic evaluation：模型在阅读时对文本做梯度步）的行为，**首次覆盖混合线性注意力架构与扩散语言模型**，并给出一个决定性的负面结论。

1. **建立统一实验协议**：每 128-token chunk 做 **1 步 SGD**，作用在**最后 1/4 blocks 的 MLP 输出投影**上；**无训练**；**2k-token 窗口**。
2. **架构间存在本质分化**（核心发现）：
   - **Softmax attention**（Qwen3-1.7B / 4B, Gemma-4-E4B）：文档级 next-token loss 降低 **5–8%**，且**超过同一冻结模型在 32k 完整上下文下的表现**
   - **混合 Gated-DeltaNet**（Qwen3.5-4B, Qwen3.8-27B）：**所有学习率下增益 < 1%** —— 因为**线性注意力块本身已在做这种适应**
   - **Masked diffusion 模型**：效应**更大**，Nemotron-Diffusion-8B 为 **8%**，DiffusionGemma-26B 为 **17–20%**（需降低学习率并裁剪更新）
3. **决定性负面结论**：在 RULER / BABILong / LongBench-v2 / SCOTUS / HotpotQA / MuSiQue / ContractNLI / 引文补全等任务上（2 个模型规模、≥100 样本），**在全文上更新权重无法恢复任何因上下文截断而损失的准确率**。
4. **关键解释**：**适应学到的是「风格与词汇」，不是「检索」**。
5. **进一步细分**：用 next-token loss 写事实 → 存的是**提示格式而非事实**（chat prompting 下召回 30% vs 上下文内 80%），且在**所有剂量**下损失 **36–38 个 GSM8K 点**。
6. **正面方案**：把结论写为**行为**而非文本 —— 把模型自己的「结论条件化判断」蒸馏进**低秩适配器** → 达到**上下文内上限**（0.83 / 0.88 对 0.84 / 0.88，100 局），**GSM8K 不变**；且该结论可来自一个**通过提出信息增益问题来发现它**的 inquiry loop。

## 技术方案

### 核心思想

「模型能否边读边学？」—— dynamic evaluation 让模型在阅读过程中对已读文本做梯度更新。直觉上这应该能扩展有效上下文，但本文用**受控测量**证明：**它学的是文体，不是知识**。

### 实验协议

```text
每 128-token chunk:
  ├── 取该 chunk 的 loss
  ├── 对「最后 1/4 blocks 的 MLP 输出投影」做 1 步 SGD
  └── 无训练数据，纯 inference-time 自适应
窗口: 2k tokens
```

### 架构分化机制

| 架构 | 增益 | 机制解释 |
|------|------|---------|
| Softmax attention | 5–8% | attention 本身无状态，梯度承担了适应 |
| 混合 Gated-DeltaNet | **< 1%** | **线性注意力块的递归状态已在做同类适应** |
| Masked diffusion | 8% / 17–20% | 迭代去噪过程本身携带上下文，可吸收更多梯度信号 |

### 「风格 vs 检索」的分离证据

| 证据 | 结论 |
|------|------|
| 8 个长上下文/检索基准全部**零恢复** | 适应**不提供检索能力** |
| Chat prompting 下事实召回 **30%** vs 上下文内 **80%** | next-token loss 写入的是**提示格式**，非事实本身 |
| 所有剂量下 **GSM8K −36~38 分** | 用 next-token loss 写事实有**严重代价** |
| 结论蒸馏进 LoRA → **0.83 / 0.88**（对 0.84 / 0.88） | 把结论写成**行为**才能达到上限 |

### 正负两条路径对比

```text
❌ 用 next-token loss 把事实写进权重
   → 存下提示格式，召回 30%，GSM8K −36~38

✅ 把模型自己的结论条件化判断蒸馏进低秩适配器
   → 达到上下文内上限 (0.83/0.88)，GSM8K 不变
   → 结论可由 inquiry loop（信息增益提问）自动发现
```

## 实验结论

- **数据集/基准**: RULER, BABILong, LongBench-v2, SCOTUS, HotpotQA, MuSiQue, ContractNLI, citation completion；≥100 样本；2 个模型规模
- **模型**: Qwen3-1.7B, Qwen3-4B, Gemma-4-E4B, Qwen3.5-4B, Qwen3.8-27B, Nemotron-Diffusion-8B, DiffusionGemma-26B
- **结果**: 见上表；核心是**「风格而非检索」**与**「结论写为行为」**的分离

---

## 局限性

- 结论蒸馏的**LoRA 秩与超参**未在摘要给出
- 8 个基准全部零恢复 —— 这个**强负面结论**可能依赖特定的更新位置（仅最后 1/4 blocks 的 MLP 输出投影）；换更新位置是否仍为零，未验证
- 「结论条件化判断」依赖模型**自身已有能力** —— 这在弱模型上不成立，是方法的隐含前提
- inquiry loop 的信息增益提问策略未给出细节

## 实现建议

- **实现难度**: 中（需在推理循环中插入 SGD 步，显存与延迟成本需实测）
- **预期性能**: softmax 架构 5–8% loss 降低；但**不要指望它提升检索能力**
- **适用场景**: 领域风格/术语适配（**非**知识注入）；扩散模型上效应最大
- **落地注意**:
  1. 若目标是**记住事实**，必须用「结论蒸馏进 LoRA」而非 next-token loss
  2. 混合线性注意力架构上该方法基本无效，可直接跳过

## 我的评注

> 这篇的信息密度是今日批次最高的。三个层次的价值递进：
>
> 1. **测量** —— 首次在混合线性注意力与扩散架构上系统对比动态评估，数字本身有价值。
> 2. **诊断** —— 「适应是风格不是检索」这一区分，配合「写事实掉 36–38 GSM8K 分」，把一个含糊的技术想法**证伪得很干净**。
> 3. **补救** —— 给出「结论蒸馏进低秩适配器」的正向路径，并证明可达上下文内上限。
>
> 最实用的一条：**如果你在混合线性注意力模型上试 dynamic evaluation，先看第 2 点 —— 线性注意力块本来就在做这件事，你会白花时间。**
>
> 「结论写为行为而非文本」这个框架也很漂亮，和 [[Conceptizer]]（意义层面的奖励）指向同一个直觉：**next-token loss 是过细的刻度，重要的信息在更粗的语义层面**。
