## 核心贡献

1. **CritICL 框架**：一种新颖的推理时框架，利用弱模型的**结构化失败模式**来引导强模型推理，无需重复生成或外部验证器。

2. **CritBank 数据集**：构建包含问题、错误响应、失败模式标签和自然语言批评的结构化数据集，每个条目来自弱模型（如 Qwen2.5-1.5B/3B/7B）。

3. **两种推理时变体**：
   - **CritICL-dynamic**：动态预测输入相关的失败模式，从 CritBank 检索相关批评示例
   - **CritICL-static**：使用全局失败模式画像，提供稳定引导

4. **关键洞察**：同一模型家族内，弱模型和强模型的失败模式分布高度一致——这使得弱模型的失败信息可迁移到强模型。

## 模型架构

### CritBank 构建流程
```
问题集 Q + 小模型集 M
    ↓ CoT prompting 生成5个响应
响应集 R(q,m)
    ↓ 正确性过滤
R_correct ∪ R_incorrect
    ↓ 前沿 LLM (GPT-4o-mini) 生成
失败模式标签 + 自然语言批评
    ↓
CritBank = {(q, r, l, C(q,r))}
```

### 失败模式采样选择
对于新问题 q'：
- CritICL-dynamic：预测可能的失败模式标签，从 CritBank 检索最多5个相关批评示例作为 in-context 示例
- CritICL-static：使用模型家族全局失败模式画像，检索对应批评

## 实验结果

**基准**：GSM8K, MATH, AMC23, AIME24, AIME25

**目标模型**：Qwen2.5-32B-Instruct, Qwen2.5-72B-Instruct

| 方法 | MATH Pass@1 | 相对成本 |
|------|-------------|---------|
| Zero-shot | - | 1× |
| Few-shot (5-shot) | - | ~1× |
| Consistency@7 | - | ~7× |
| **CritICL-static** | **最优** | **~1×** |
| **CritICL-dynamic** | 竞争性 | **~2×** |

**关键结果**：
- Qwen2.5-72B 上，CritICL-static 达 59.2%，超越 Consistency@5 (59.0%)，但只需单次生成
- Token 成本：3768-3897 vs. test-time scaling 的 4192-7533
- CritICL 轻微增加输入长度，但输出长度相当或更少——批评引导模型更直接地得出正确答案

## 关键公式

### 失败模式聚类
失败模式标签由前沿 LLM 生成后聚类，相似标签归为一组，提取代表性失败模式。

### Token 权重（Soft-OR）
```math
w(t) = H^(t) + Δ^(t) - H^(t) · Δ^(t)
```
其中 H^(t) 是归一化学生熵，Δ^(t) 是师生 KL 散度。高权重表示学生不确定或确信错误的位置。

## 局限性

- CritBank 构建依赖前沿 LLM 生成批评，有成本
- 方法在数学推理上验证，其他领域泛化性待研究
- 对极弱模型（<1B）作为失败模式来源的适用性未充分探索

## 建议
- **推荐使用**：是
- **适用场景**：需要高效推理时提升 LLM 推理能力，特别是算力受限场景
- **替代方案**：self-consistency、LLM-as-a-judge 等 test-time scaling 方法
