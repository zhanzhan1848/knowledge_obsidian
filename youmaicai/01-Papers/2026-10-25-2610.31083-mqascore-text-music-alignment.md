## 核心贡献

> **全局相似度把描述的所有属性压成一个分数，掩盖了"到底缺哪一个"**。MQAScore 改为按**原子音乐概念**逐条验证，沿**五个 clip 级维度**打分，判据是 LALM 对二元问题**肯定回答的概率**。

1. **提出 MQAScore**：细粒度文本—音乐对齐评测，通过 LALM（Large Audio Language Model）对二元问题肯定回答的概率来验证每个原子音乐概念
2. **五个 clip 级维度**：**genre（流派）**、**instrument（乐器）**、**mood/theme（情绪/主题）**、**vocal（人声）**、**usage（使用场景）**
3. **评测器可靠性评估**：用**存在/不存在标注**与 **LLM 引导的概念替换**构造验证标签
4. **提出 Sensitivity-Invariance Ratio**：衡量评测器对**改变语义的替换**有多敏感（selectively responds）
5. **实证结论**：概念级打分能**同时改进问答式评估器与相似度式评估器**；MQAScore 可作为全局相似度**更可靠、更可解释的细粒度补充**

## 技术方案

### 核心思想：从"一个相似度分数"到"一组概念判定"

```
传统：text embedding ↔ audio embedding → 单个全局相似度分数
      （所有属性被压成一个数 → 无法知道缺了哪个）

MQAScore：
  文本 → 原子音乐概念集合 {c1, c2, ...}
        每个概念 → 映射到五个维度之一
        每个概念 → 生成二元问题 → LALM 回答
        → score(c) = P(LALM 肯定回答)
  → 逐概念分数 + 逐维度聚合
```

### 关键技术

| 技术 | 说明 |
|------|------|
| Atomic music concept | 把描述拆解为可独立验证的原子概念（对应 genre / instrument / mood-theme / vocal / usage 五个维度） |
| Binary-question verification | 对每个概念构造二元问题，用 LALM 的**肯定回答概率**作为该概念的对齐分数 |
| LALM as judge | 用大音频语言模型替代 embedding 相似度作为判据；概率化输出提供细粒度置信度 |
| Presence/absence annotation | 用"存在/不存在"标注构造验证标签，衡量评测器可靠性 |
| LLM-guided concept substitution | 用 LLM 生成**改变语义的替换**，构造负例 |
| **Sensitivity-Invariance Ratio** | 衡量评测器对改变语义的替换的**选择性响应程度** —— 即"该掉分的掉分、不该掉分的不掉分"的区分能力 |

### 为什么 Sensitivity-Invariance Ratio 重要

| 传统评测器失效模式 | SIR 的作用 |
|-------------------|-----------|
| 对任何扰动都掉分（过敏） | 惩罚不区分的响应 |
| 对改变语义的替换不掉分（迟钝） | 惩罚不敏感的响应 |
| 概念级评测器应只对**语义改变**敏感 | SIR 直接量化这一点 |

## 关键结论

1. **全局相似度不是对齐的充分度量**。它把 genre、instrument、mood、vocal、usage 五类属性压成一个数，导致"哪一个缺失"不可诊断。
2. **概率化的概念验证天然更可解释**：每个原子概念一个分数，可以直接定位生成器缺了哪类音乐属性 —— 这是给 text-to-music 系统做诊断的实用接口。
3. **概念级打分是通用的增强手段**：不只服务 MQAScore，它对**问答式**与**相似度式**评估器都有改进，说明"分解后打分"本身是有效的评测范式。
4. **SIR 把"评测器可靠性"变成可量化指标** —— 这比"我们验证了人工标注一致性"更进一步，因为它直接测"选择性"。

## 局限性

- **数值未披露**：摘要无任何具体分数或 SIR 值，改进幅度无法判断
- **依赖 LALM 判定**：MQAScore 的可靠性上限被底层 LALM 的音频理解能力限制；LALM 自身偏差未单独评估
- **二元化为循环论证风险**：LALM 说"是"是否真的等价于"音频中存在该属性"，需与 presence/absence 标注交叉验证 —— 摘要提及该标签但未给吻合度
- **五维度的划分粒度固定**：概念类别之外的属性（如混音风格、动态）不在框架内

## 实现建议

- **实现难度**: 中（需选一个开源 LALM，实现概念抽取 + 二元问答 + 概率聚合）
- **适用场景**: 评估 text-to-music 生成系统；以及任何**多属性生成任务**（如 text-to-image 的属性覆盖率、视频生成的元素覆盖）
- **落地步骤**:
  1. 把 prompt 拆成**原子概念**，按五维度归类（可复用 LLM 做拆解 + 校验）
  2. 每个概念构造二元问题（"这段音乐中是否有 X 乐器？"），取 LALM 肯定概率
  3. 报告**逐维度分数**（而非只报平均），缺失维度一眼可见
  4. 用**语义改变型替换**（如把 "piano" 换成 "guitar"）做自检：分数应显著下降；用**保义替换**（同义词、拼写变体）做对照：分数应基本不变 —— 这就是 SIR 的实操版本
- **价值点**: 这是一个**可直接移植到其他多属性生成评测**的框架；与 2026-10-24 日报中"评测方法论批判"主线呼应 —— 同样是"把一个粗糙的聚合分数拆成可诊断的分量"
