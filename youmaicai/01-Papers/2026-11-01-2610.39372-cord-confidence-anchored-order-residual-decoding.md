# Cord: Confidence-Anchored Order Residual Decoding for Masked Diffusion Language Models

## 摘要
masked diffusion language models（dLLM）的解码顺序会显著影响生成质量，但常见解码器通常在整个生成过程中套用同一条 reveal 规则。Confidence 是一个很强的默认选择，但它衡量的是"某个位置现在能否被果断预测"，而不是"揭示该位置对后续解码有多有用"。本文提出 CORD——一个轻量的 prompt-conditioned 策略，保留 confidence decoding 作为稳定参考，并通过**生成方向、到已揭示上下文的邻近性、双侧 infilling** 三个几何残差来学习何时以及如何偏离它。残差同时适配 prompt 与演化中的部分响应。与其在每个解码步都采样新的策略动作，CORD 每个 rollout 只采样一个低维系数矩阵，由它诱导出整条状态相关的 reveal 轨迹。这产生了一个 contextual-bandit 形式化，可直接由序列级奖励训练，无需 step-level credit assignment，也无需更新 backbone。在三个 dLLM 与五个推理、代码、约束满足 benchmark 上，CORD 把 confidence decoding 下的平均任务成功率从 **32.0%** 提升到 **48.2%**，并进一步超过最好的 per-domain 固定残差。行为审计显示所学残差在 reveal 局部性与双侧 infilling 上产生了显著的、随任务而变的变化。CORD 仅增加 **0.53M** 可训练参数，不需要额外的 backbone 前向，推理延迟开销仅 **5.39%**。

## 核心贡献
1. **Oracle 诊断（frozen-backbone）**：在相同 reveal 预算下，**在哪里**揭示信息会实质影响完成质量——GSM8K 上揭示正确的因果前缀把准确率从 37.2% 提升到最高 67.4%，而 token 数匹配的随机锚点保持在 20% 以下；MBPP 上结构性程序 token 比匹配随机锚点高最多 14.4 点。这证明不同任务偏好不同形式的条件化（推理偏好连贯前缀扩展，代码偏好稀疏结构支架）。
2. **CORD**：confidence-anchored 的几何残差策略，覆盖三个可解释轴（direction / proximity / bridge），并以 prompt-conditioned 系数矩阵参数化。
3. **系数空间的 contextual bandit**：每 prompt 只采样一个 24 维系数向量，固定于整个 rollout，由序列级奖励直接优化，规避 step-level credit assignment 与大动作空间。
4. **跨 backbone 泛化**：在 LLaDA-8B-Instruct、LLaDA-1.5-8B、Dream-7B 三个 dLLM 上分别训练独立策略，均取得提升；并优于已有的 UNCODE、EB-Sampler、Semi-AR 等 reveal-order 基线。
5. **高效**：0.53M 参数、无额外 backbone 前向、5.39% 延迟开销、推理完全确定性。

## 方法与架构
**问题设定**：dLLM 参数 $\theta$ 冻结，对所有被 mask 的响应位置预测 token 分布 $\pi_p(v\mid s_t)=p_\theta(y_p=v\mid s_t)$，需决定下一个揭示哪个位置。CORD 不改动 token 预测，只研究 reveal-order 决策。

**三个几何信号（Eq. 2）**：设 $v_1(p),v_2(p)$ 为 $p$ 处两个最高概率的非 special token，$\mathrm{idx}(p)\in\{1,\dots,L\}$ 为响应位置：
```math
h_{\text{anchor}}(p,s_t) = \pi_p(v_1(p)\mid s_t) - \pi_p(v_2(p)\mid s_t)
```
```math
h_{\text{dir}}(p) = \frac{2\,\mathrm{idx}(p)-1}{L-1}-1
```
```math
h_{\text{prox}}(p,s_t) = \min_{r\in R_{\text{resp}}(s_t)}|\mathrm{idx}(p)-\mathrm{idx}(r)|\quad(\text{若 }R_{\text{resp}}\neq\emptyset,\ \text{否则 }0)
```
```math
h_{\text{bridge}}(p,s_t) = \mathbb{1}\left[\exists r_\ell, r_r \in R_{\text{resp}}(s_t): \mathrm{idx}(r_\ell) < \mathrm{idx}(p) < \mathrm{idx}(r_r)\right]
```
语义：$h_{\text{anchor}}$ 复原传统 Top-2 margin 解码器；$h_{\text{dir}}$ 负系数偏好靠前位置（左→右），正系数偏好靠后（右→左）；$h_{\text{prox}}$ 负系数偏好靠近已揭示 token 的位置（鼓励局部续写），正系数偏好远处位置（促进非局部播种）；$h_{\text{bridge}}$ 正系数偏好两侧都有已揭示上下文的位置（鼓励 infilling）。**prompt token 被排除在 $R_{\text{resp}}$ 之外**，以避免 prompt–response 边界引入人为位置偏置。

**归一化**：每个信号在当前 masked 位置上按 $\hat h_m(p,s_t)=\frac{h_m(p,s_t)-\mu_m^{(t)}}{\sigma_m^{(t)}}$ 归一化（$\epsilon_{\text{var}}=10^{-4}$，近乎常量的信号被抑制而非放大）。

**残差打分（Eq. 3）**：
```math
S(p,s) = \hat h_{\text{anchor}}(p,s) + \alpha_{\text{dir}}(x,s)\,\hat h_{\text{dir}}(p) + \alpha_{\text{prox}}(x,s)\,\hat h_{\text{prox}}(p,s) + \alpha_{\text{bridge}}(x,s)\,\hat h_{\text{bridge}}(p,s)
```
每步揭示分数最高的 masked 位置 $p^\star=\arg\max_{p\in M(s)} S(p,s)$。与 hard routing 不同，残差只修改排序，从不排除位置。

**动态系数（Eq. 4-7）**：$B=3$ 个残差通道，$J$ 个状态基函数，prompt-conditioned 矩阵 $C(x)\in\mathbb{R}^{B\times J}$：
```math
\alpha(x,s) = \alpha_{\max}\odot\tanh\!\big(C(x)f(s)\big)
```
```math
f(s)=\big[1,\ t,\ \sin(\pi t),\ F_{\text{mean}}(s),\ F_{\text{conc}}(s),\ F_{\text{comp}}(s),\ F_{\text{bound}}(s),\ F_{\text{gap}}(s)\big]^{\top}
```
其中 $t=|R_{\text{resp}}(s)|/L$ 为已揭示比例；$F_{\text{mean}}(s)=\frac{1}{|M(s)|}\sum_{p\in M(s)}h_{\text{anchor}}(p,s)$ 衡量总体 confidence 水平；$F_{\text{conc}}(s)=Q_{0.9}(h_{\text{anchor}})-Q_{0.5}(h_{\text{anchor}})$ 衡量少数位置是否显著更容易；$F_{\text{comp}}(s)=N_{\text{comp}}(s)/L$ 为已揭示连续段数占比；$F_{\text{bound}}(s)=|B(s)|/|M(s)|$ 为两侧均有已揭示上下文的 masked 位置占比；$F_{\text{gap}}(s)=G_{\max}(s)/L$ 为最长连续 masked run 长度占比。

**Prompt-conditioned 系数策略（Eq. 8）**：首次 backbone 前向已同时处理 prompt 与 masked 响应块，因此对中间层 prompt hidden states 做 mean-pool 得 $e(x)\in\mathbb{R}^d$，**无需额外 backbone 前向**。策略网络为两层 MLP：
```math
\mu_\psi : e(x) \mapsto \mathrm{Linear}(d\to128)\to\mathrm{SiLU}\to\mathrm{Linear}(128\to n),\qquad n = BJ = 3\times8 = 24
```
输出 reshape 为 $C(x)\in\mathbb{R}^{B\times J}$。**最后线性层零初始化**，因此 CORD 起点精确等价于 confidence-based (Top-2 margin) 解码。

**系数空间训练（Eq. 9-10）**：训练时对每个 prompt 采样一次
```math
C_\zeta = \mathrm{reshape}_{B\times J}(\zeta),\qquad \zeta = \mu(x) + \sigma\epsilon,\quad \epsilon\sim\mathcal{N}(0,I_n)
```
并在**整个 rollout 内保持固定**；此后所有 reveal 决策都是确定性的。于是每个 prompt 构成 context $x$，策略只取一次随机动作 $\zeta$，得到一个序列级奖励 $r$：
```math
x \longrightarrow \zeta \longrightarrow \text{完整解码 rollout} \longrightarrow r
```
随机动作空间只有 $BJ=24$ 维，却能诱导整条状态相关的 reveal 策略。

**序列级奖励（Eq. 11）**：
```math
r^{(i)} = \mathbb{1}\{\text{answer}^{(i)}\text{ 正确}\} + \lambda_{\text{fmt}}\mathbb{1}\{\text{output}^{(i)}\text{ 可解析}\} + \lambda_{\text{ans}}\log p^{(i)}_{\text{ans}}
```
$\lambda_{\text{fmt}}=0.1$（区分畸形输出与有效但错误的输出）；$\lambda_{\text{ans}}$ 默认 0（启用时需额外一次 backbone 前向，re-mask 参考答案 span 后测量其 token 的平均 log-prob）。

**Group-relative policy gradient（Eq. 12-14）**：每个 prompt 采 $K=8$ 个 sibling rollout，$\zeta^{(i)}\sim\mathcal{N}(\mu_\psi(x),\sigma^2I_n)$，其 log-density 与 score-function 梯度为
```math
\log q_\psi(\zeta^{(i)}\mid x) = -\frac{\|\zeta^{(i)}-\mu_\psi(x)\|^2}{2\sigma^2}-\frac{n}{2}\log(2\pi\sigma^2)
```
```math
\nabla_\psi\log q_\psi(\zeta^{(i)}\mid x) = \left(\frac{\zeta^{(i)}-\mu_\psi(x)}{\sigma^2}\right)^{\top}\nabla_\psi\mu_\psi(x)
```
梯度**不经过离散的 reveal 轨迹**。优势用 leave-one-out group-relative：
```math
A^{(i)} = r^{(i)} - \frac{1}{K-1}\sum_{j\neq i} r^{(j)}
```
作者刻意**不做**组内标准差归一化——对二值或近二值 verifier 奖励，这种归一化会不成比例地放大"只有一个成功或一个失败"的组。若所有 sibling 奖励相同则 $A^{(i)}=0$，该组不贡献信号。更新形式为
```math
\mu \leftarrow \mu + \frac{\eta}{K\sigma^2}\sum_{i=1}^{K}A^{(i)}\big(\zeta^{(i)}-\mu\big)
\]
即成功扰动把系数程序拉向自己、失败扰动推开。**sibling rollout 共享除系数向量外的所有随机性**（token 生成随机时用 common random numbers，greedy 时选择确定），使 within-prompt 奖励差异主要反映 reveal-order 程序。每 rollout batch 做一次 on-policy 更新，**不需要 learned critic 或 importance-ratio 校正**。

## 实验设置
- **Backbone（全部冻结）**：LLaDA-8B-Instruct、LLaDA-1.5-8B、Dream-7B；每个 backbone 单独训练一个 CORD 策略。
- **Benchmark（5 个）**：GSM8K、MATH-500（数学推理）、HumanEval、MBPP（代码生成）、4×4 Sudoku（约束满足）；HumanEval/MBPP 报 pass@1，其余报 accuracy。
- **基线**：Confidence、Entropy、Margin（Kim et al. 2025）、EB-Sampler（Ben-Hamu et al. 2025）、Semi-AR（Nie et al. 2025）、UNCODE（Huang et al. 2026a）、Best per-domain fixed residuals（用同样三个几何信号但系数恒定）、以及 remasking 类方法（CORE、SCOPE+D3IM、RemeDi）。
- **训练配置（Tab. 5-6）**：$B=3$、$J=8$、$n=24$、policy 隐层 128、2 层线性 + SiLU、输出层零初始化、group size $K=8$、每次更新 64 prompts、epochs $E\in\{20,30,40\}$、AdamW、LR $\in\{10^{-3},5\times10^{-4},10^{-4}\}$、cosine decay、探索尺度 $\sigma$ 从 0.6 退火到 0.15（在前 70% 训练内线性衰减，**从不为零**——因为 top-1 reveal 决策使序列级奖励对系数分段常值，无探索则无梯度信号）、$\lambda_{\text{fmt}}=0.1$、$\lambda_{\text{ans}}=0$。LLaDA-8B-Instruct 的完整 40 epoch 训练在 **8× NVIDIA H200** 上约 **8 小时**。训练数据：math 4,000 prompts、code 500 prompts、Sudoku 2,000 prompts，采样比 **2:1:1**（math:code:Sudoku）。
- **解码配置（Tab. 7）**：生成长度 $L=512$、解码步数 $T=512$、每步揭示 1 个位置、最大序列长度 2048、pure any-order schedule、top-1 by reveal score、推理时使用预测均值 $\mu_\psi(x)$。行为审计用 256 generation steps、response length 256、greedy（$T=0$）、EOS 抑制。
- **Verifier**：GSM8K 抽取答案标记并比数值；MATH 抽取 boxed answer，做精确匹配、归一化与符号等价；HumanEval/MBPP 在隔离子进程中执行测试（固定 timeout、内存上限、干净临时目录、禁网），全部测试通过才算正确；Sudoku 检查保留 clues、填满每格并满足行/列/盒约束（不与唯一参考解比对）。训练与评测用同一 verifier。
- **效率测量**：单张 NVIDIA H200，LLaDA-8B-Instruct，生成 256 token、最大总序列长度 1024，每种方法跑 20 次报告均值与标准差。

## 局限性
作者自述：CORD 依赖**条件质量**与多次 probe 的延迟（那是上一系列的表述，本文中相关限制体现在）：训练成本较高（LLaDA-8B-Instruct 40 epoch 需 8× H200 约 8 小时）；由于 top-1 reveal 决策使序列级奖励对系数分段常值，**必须保留不为零的高斯探索**（$\sigma$ 退火至 0.15 而非 0）；CORD 不及最强的 revision-trained 模型（RemeDi）。作者也强调 CORD 的 conditional-response 不证明真实生成过程——这是另一篇的表述；本文的相关限制在于 CORD 只改变 reveal 顺序，不改变模型参数，也不引入新能力。

我的补充批判：① **oracle 诊断的"随机锚点"对照存在混淆**：GSM8K 上"正确的因果前缀"与"随机位置的真值 token"在信息量上可能不等价（真值 token 本身即使位置随机也携带答案推理链信息），因此 67.4% vs <20% 的差距可能部分来自"答案 token 在前缀中更靠后"这一位置偏置，而非"因果连贯性"；② CORD 相对 **confidence 的巨大增益（+16 点）主要来自去掉 Sudoku/MATH 上的灾难性表现**（Entropy 在 Sudoku 上仅 3.3%、Semi-AR 在 Sudoku 上仅 0.3%），说明置信度基线在这些任务上极不稳健，绝对值不宜当作"解码质量"来解读；③ 训练 prompt 数量偏少（code 仅 500、Sudoku 2,000、math 4,000），且 Sudoku 是 4×4 的玩具规模，与真实难度差距大；④ 与 UNCODE 等已有方法的对比缺少显著性检验与多 seed；⑤ CORD 严格单调，因此无法修正早期错误提交，这在长推理上可能是上限；⑥ 摘要与正文数字不一致（摘要说 32.0%→48.2%，正文说三 backbone 平均 30.6%→50.5%），阅读时需注意口径。

## 评估与建议
- 是否推荐深入阅读：**是**。它把"扩散 LM 的解码顺序"从一个固定启发式变成一个可学习的、极轻量的策略，并用 contextual bandit 优雅绕开了 step-level credit assignment。
- 适用场景：dLLM 推理加速与质量提升、解码策略可插拔化、冻结 backbone 的低开销后训练、RL 与 inference-time 策略设计的通用参考。
- 与知识库的关联：与 MaskGIT 置信度解码、Kim et al. 2025 的 token ordering 分析、UNCODE 的解码偏置分析、EB-Sampler 的 entropy-bounded unmasking、Semi-AR、以及 LLaDA / LLaDA-1.5 / Dream-7B 模型报告直接相关；与 remasking 系列（CORE、SCOPE/D3IM、RemeDi、NI sampling、DiffPO 等）构成"改顺序 vs 改承诺"的对照；方法层面与 group-relative policy optimization（GRPO）、contextual bandit、coefficient-space policy optimization 相关。
