## 核心贡献

> 首个利用 **Hybrid Linear Attention (HLA) recurrent states** 做 position-specific context 的 speculative decoding 方法。

1. **ReaDy drafter**：每个 draft position 用 learned query 从 target committed recurrent states 取补充 context。
2. **Lightweight state reader**：residual update 集成 context；low-rank state reads + fused operators 保持低开销。
3. **强加速**：在 7 benchmarks（math / code / dialogue）上对 Qwen3-8B / 27B 平均 **3.16×** 解码加速，超 DSpark **+7.97% throughput / +8.50% accept length**。

---

## 技术方案

### 核心思想

Speculative decoding 用 feature-based drafters，但 target hidden features 的 contextual emphasis 可能不匹配后续 draft position 需要。

HLA 模型（如 Qwen3 系列）维持 compact recurrent states → 是补充 context 的高效来源。

ReaDy：
- 每个 draft position 一个 learned query；
- 从 target committed recurrent states 直接 retrieve supplementary context；
- Lightweight state reader residual 集成；
- Low-rank reads + fused kernels 控制额外 I/O 与计算。

### 关键技术

| 技术 | 说明 |
|------|------|
| HLA recurrent states | hybrid linear attention 压缩历史关联 |
| Position-specific retrieval query | 位置感知的查询向量 |
| Lightweight state reader | residual 集成 context |
| Low-rank state reads | 降低 state 读取开销 |
| Fused operators | GPU kernel 优化 |
| Two-stage adaptation | DSpark-based backbone + 轻量 adaptation |
| Reader ablation | capacity / state sources / residual placement |

## 实验结论

- **模型**: Qwen3.8-27B（HLA 家族）
- **硬件**: 单卡 NVIDIA B200
- **任务**: 7 benchmarks（math, code, dialogue）
- **基线**: autoregressive decoding, DSpark
- **结果**:
  - 平均 **3.16×** decoding 加速；
  - 超 DSpark 在所有 benchmark：throughput **+7.97%**、accept length **+8.50%**；
  - 额外计算与 I/O overhead 可控。

---

## 局限性

- 绑定 HLA 架构（依赖 recurrent states），纯 softmax-attention 模型无法直接用；
- state reader 需要 target model 的 recurrent state 暴露，工程兼容性需逐模型实现；
- 大模型（>30B）规模化收益未充分验证。
