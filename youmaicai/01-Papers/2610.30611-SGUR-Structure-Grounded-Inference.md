## 核心贡献

> 提出 **SGUR（Structure-Grounded Uncertainty Reduction）** —— **training-free** 框架，用**结构化假设空间上的主动不确定性削减**补充 token 级生成，在不完整观测下产生**结构接地的推理**。

1. **问题**：scaling 提升了语言流畅性，但可靠的自主 agent 需要的不只是流畅生成。多轮推理中，现有 agentic 系统常产生**语义合理但结构未接地**的推理，尤其在**观测不完整**时。
2. **方法**：
   - 将**不完整观测表示为 query graph**；
   - 通过**先验加权的部分图匹配（prior-weighted partial graph matching）**将其与**候选假设图**对齐；
   - **经验先验**（database-derived）给决策相关关系更高权重，而非对所有图边一视同仁；
   - **主动信息增益策略**：迭代选择**下一个最具信息量的节点**去查询，系统性剪枝候选空间。
3. **结果（PrimeKG 衍生的序贯医疗诊断基准）**：
   - 仅从**两个观测症状**出发，SGUR 达到 **92.5% Hit@3**；
   - 比最强 **Graph-RAG** baseline 高 **9.4 pp**；
   - **token 用量约少 5 倍**；
   - **小 backbone 模型可匹配甚至超越大 10 倍的模型**。

## 技术方案

| 组件 | 说明 |
|------|------|
| Query graph | 不完整观测的图表示 |
| Hypothesis graphs | 候选假设 |
| Prior-weighted partial graph matching | 先验加权的部分匹配 |
| Empirical priors | 来自数据库，强调决策相关关系 |
| Active information gain | 选下一个最有信息量的查询节点 |
| Iterative refinement | 剪枝候选空间 |

### 关键洞见

- **"结构接地可以部分替代模型规模"** 是本文最有价值的结论 —— 对医疗、法律等高stakes领域意味着**更小模型 + 更可靠**。
- **主动信息增益**把"再问一个问题"变成**最优决策**，而不是随意追问 —— 这直接对应 agent 的**成本效率**。
- 5× 更少 token 却更准，说明 token 级生成在**结构化推理任务上**是冗余的。

## 实验结论

- **基准**：PrimeKG 衍生的序贯医疗诊断
- **结果**：
  - **92.5% Hit@3**（仅 2 个观测症状）；
  - **+9.4 pp** vs 最强 Graph-RAG；
  - **~5× 更少 token**；
  - 小模型匹配/超越 **10× 大**的模型。

---

## 局限性

- 仅在**医疗诊断**（PrimeKG）上验证，其他领域（软件调试、法律）未知；
- 需要**结构化数据库**（empirical priors）—— 通用领域难以获得；
- training-free 但**需要假设图空间的显式构造**，工程成本高；
- 假设图空间过大的可扩展性存疑。

- **适用场景**：医疗辅助诊断、故障根因定位、合规审查
- **建议部署**：挑一个**有成熟结构化数据库**的垂直场景试点；观察"更小模型 + 结构接地"能否替代"更大模型"
