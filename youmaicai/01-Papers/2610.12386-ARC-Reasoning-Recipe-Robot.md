## 核心贡献

> 证明"对的 reasoning recipe"可以替代更大模型 / 更多数据：在 π₀.₅ 与 Cosmos3-Nano-Policy 上无需新增 robot demonstration 即可获得 SOTA 零样本性能，π₀.₅ 真实机器人任务成功率 +82.2 pp。

1. 提出 **ARC**（Action Reasoning Chain）：reasoning trace 必须"以机器人下一动作为锚点 + 解释该动作的因果结构"。
2. **ARC-Trace-DROID**：从 DROID 数据集自动生成 reasoning traces，无需采集新 robot 数据。
3. 在 **RoboLab-Reasoning-50** 上单条 reasoning recipe 提升达 **50 pp**，无需 foundation-scale 再训练。

---

## 技术方案

### 核心思想

现有 RFM 的零样本能力被"盲目 scaling"驱动，但 reasoning supervision 本身就是另一种 scale。ARC 把"为什么选这个动作 / 应该产生什么效果"作为 trace 的核心，比"动作预测 + 通用 CoT"更直接服务于 control。

### 关键技术

| 技术 | 说明 |
|------|------|
| Action-anchored reasoning | 每条 trace 以"next action"为锚点，开篇说明动作、原因、预期效应 |
| Automatic trace labeling pipeline | 从 DROID demonstration 自动生成 traces（无需人工） |
| VLA / WAM tailored fine-tune | π₀.₅ 与 Cosmos3-Nano-Policy 分别采用与架构匹配的 fine-tune 与 inference 策略 |
| Zero-shot transfer | 在 RoboLab-120、MolmoSpaces 等基准上 zero-shot 评测 |

---

## 公式

动作预测的 reasoning trace 可抽象为：

```math
\mathcal{T} = \big( \text{anchor}(a_t), \ \text{cause}(a_t), \ \text{effect}(a_t) \big)
```

其中 $a_t$ 是下一步动作；training loss 同时监督动作预测与 trace 生成。

## 实验结论

- **数据集**: DROID（自动生成 ARC traces）、RoboLab-120、MolmoSpaces、RoboLab-Reasoning-50
- **基线**: π₀.₅、Cosmos3-Nano-Policy（无 ARC）
- **结果**:
  - RoboLab-Reasoning-50：提升 **+50 pp**
  - 真实机器人任务：π₀.₅ 任务成功率 **+82.2 pp**
  - RoboLab-120、MolmoSpaces：建立新 SOTA

---

## 局限性

- Trace 自动生成质量受 DROID 数据多样性限制。
- 主要在 DROID 类操作任务验证，未覆盖 locomotion / 类人机器人。
- Reasoning recipe 的"配方性"强，对不同 embodiment 的迁移需重新调参。
