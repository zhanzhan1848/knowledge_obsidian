## 核心贡献
1. **Aegis**: 运行时治理系统，将模型输出视为action proposals，在工具执行前通过可信决策层进行调解
2. **核心原则**: "The model proposes; the trusted runtime decides"
3. **Senate-style settlement**: 法定人数非单边授权路径

## 核心机制

### 1. Action Proposal Mediation
- 模型输出 → 待执行action proposals
- 信任运行时在执行前审查每个proposal

### 2. Policy Evaluation
- 根据active policy state评估proposals
- 服务端provenance解析

### 3. Fail-Closed Execution
- 不确定时fail closed（保守策略）

### 4. Senate-Style Settlement
- 选定案例通过法定人数授权路径
- quorum-based non-unilateral authorization

## 实验结果
| 指标 | Prompt-policy conditioning | Aegis-governed |
|------|---------------------------|----------------|
| 风险路径泄漏行 | 79 | **0** |
| 风险副作用完成 | - | **0** |
| Aegis-resolved provenance保留 | - | 1,832/1,832 |
| Senate-settled rows with quorum | - | 1,019/1,019 |

- 总计评估: 6,300行(prompt-policy) + 2,100行(Aegis-governed)
- 5个run families, 42 tasks, 3 conditions, 10 repeats/family

## 核心洞察
- Prompt级治理可以塑造模型行为，但不创建执行边界
- 需要将安全问题的焦点从有害文本生成转移到有害操作副作用

## 局限性
- 结果不能证明通用自主智能体安全性
- 仅在评估的沙箱语料库中支持该系统声明
