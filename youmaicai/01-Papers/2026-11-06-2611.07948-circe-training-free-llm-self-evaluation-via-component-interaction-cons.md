# Circe: Training-Free LLM Self-Evaluation via Component Interaction Consistency

## 摘要
**Circe** 是一种**免训练（training-free）**的 LLM 自评估方法，在没有参考答案、也不重复采样的前提下，用**内部 + 外部**双信号判断回答是否正确。其核心创新是 **CIC（component interaction consistency）**：度量「浅层 attention 更新方向」与「深层 attention 诱导的 FFN 输出变化方向」之间的对齐程度 —— 现有内部探针方法只看隐藏层轨迹，而轨迹只记录了 attention 与 FFN 的**合并更新**，忽略了二者的交互。同时引入 **RG（representation geometry）** 刻画隐藏层轨迹上的归一化位移与角度变化；外部信号则来自生成内容的平均负对数似然。

## 核心贡献
1. 提出 **component interaction consistency (CIC)** —— 首次把 attention 与 FFN 的**交互**（而非合并更新）作为自评估信号
2. 引入表示几何（RG：归一化位移 + 角度变化）作为补充内部信号
3. **免训练、无需参考答案、无需重复采样**，可直接用于部署后的正确性监控
4. 同时使用内部与外部信号，缓解既有 reference-free 方法「输出信号会给错误答案打高分」的问题

## 方法与架构
**内部信号**：
- **CIC** —— 计算较早层 attention 更新方向 与 较晚层「attention 诱导的 FFN 输出变化」方向的对齐程度（directional alignment）；
- **RG** —— 沿层序隐藏状态轨迹刻画归一化位移（normalized displacement）与角度变化（angular change）。

**外部信号**：生成文本的平均负对数似然（mean NLL）。

**核心动机**：既有内部状态研究只分析跨层隐藏状态轨迹，而这些轨迹记录的是 attention 与 FFN 的**合并更新**（combined updates），从而遗漏了组件间的交互。

**约束**：免训练、无参考答案、不做 repeated sampling。

## 实验结果
- 免训练即可产出正确性信号，**无需参考答案、无需重复采样**（显著低于自洽性（self-consistency）类方法的推理成本）
- 相对只依赖输出信号的 reference-free 方法，克服了「错误答案获得高分」的问题

## 局限性
- CIC 依赖对 attention 与 FFN 贡献的**可分离性假设**，在 GQA / MoE / 量化模型上能否成立未验证；
- 免训练意味着信号未经任务适配，可能在分布外任务上退化；
- 需要访问**模型内部激活**（white-box），无法用于 API-only 部署 —— 这是相对 LLM-as-judge 的重要限制。

## 值得注意的点
这是今日**少见的 white-box 自评估**工作：它把「自评」的判据从「重复采样看一致性」换成「看内部计算是否自洽」。代价是必须能访问激活 —— 在 API 封闭环境下这一整类思路不可用，这一点论文摘要未强调。
