# Where to Connect? Boosting MLLMs via Dynamic Gated Pathways across ALL ViT and LLM Layers

> **arXiv**: [2611.06844](https://arxiv.org/abs/2611.06844)
> **发表日期**: 2026-11-04
> **分类**: cs.CV
> **会议/期刊**: NeurIPS 2026 (40th Conference on Neural Information Processing Systems)

## 📋 摘要

在 MLLM 中一个核心却未被充分探索的问题是 **where to connect**——来自层次化视觉编码器的视觉信息，应当如何接入 LLM 的逐层语义之中。主流 MLLM 只把固定的单层视觉表示注入 LLM，并把所有 LLM 层当作单一消费者，忽略了不同层需要不同视觉粒度这一事实。近期多层融合方法要么在编码器侧压缩层次特征，要么依赖预定义的稀疏/层次化层间连接，因此都未能建模 ViT 与 LLM 两个层次之间的自适应跨层交互。作者提出 **DGP（Dynamic Gated Pathways）**：一种路由机制，在每一层 ViT 与每一层 LLM 之间建立 all-to-all 连接，并由每个 LLM 层基于自身的语义状态动态 gate 它对各视觉层的偏好。在 LLaVA-1.5-7B 与 13B 之上，DGP 相比 LLaVA-1.5-7B 基线取得一致提升（例如 **SQA^I 上 +4.2、MM-Vet 上 +3.3、VizWiz 与 LLaVA^W 上各 +3.1**），并在多数基准上超过既有的多层视觉融合方法。逐层路由分析进一步显示，不同 LLM 层确实会按需选择不同的视觉粒度，支持了动态门控通路在有效性与可解释性两方面的价值。

## 🎯 核心贡献

1. **重新提出 "where to connect" 问题**：指出主流 MLLM 将单层视觉表示注入 LLM、并把全部 LLM 层视为同质消费者，是被忽视的结构性缺陷。
2. **提出 DGP 动态门控通路**：在**每一个 ViT 层与每一个 LLM 层之间**建立 all-to-all 连接，并由每个 LLM 层以自身语义状态为条件，动态 gate 对视觉层的偏好（自适应路由权重）。
3. **超越既有多层融合方法的两种路径**：不做编码器侧的层次特征压缩，也不依赖预定义稀疏/层次化连接，而是显式建模 ViT–LLM 之间的自适应跨层交互。
4. **可解释性证据**：逐层路由分析表明不同 LLM 层确实按需选择不同视觉粒度，验证了方法机制与解释框架。
5. **稳定的实证收益**：在 LLaVA-1.5-7B/13B 上相对基线一致提升，并超过以往多层视觉融合方法。

## 🔧 方法/架构

**核心机制：Dynamic Gated Pathways**

设 ViT 共有 $L_v$ 层、LLM 共有 $L_l$ 层，视觉特征记为 $\{v_1,\dots,v_{L_v}\}$，第 $i$ 层 LLM 的隐藏状态为 $h_i$。DGP 在全连接（all-to-all）图 $\mathcal{G} = V \times L$ 上对每条边 $(v_j \rightarrow l_i)$ 学习一个由 LLM 层自身语义状态决定的门控权重：

$$
g^{(i)}_j = \sigma\!\left(w_i^\top h_i + u_j^\top v_j + b^{(i)}_j\right)
$$

第 $i$ 层 LLM 接收的视觉注入为各层视觉特征的门控加权和：

$$
\tilde{v}^{(i)} = \sum_{j=1}^{L_v} g^{(i)}_j \, \phi(v_j),
$$

其中 $\phi(\cdot)$ 为视觉特征到 LLM 维度的投影，$\sigma(\cdot)$ 为 sigmoid。由于门控依赖 $h_i$（即当前 LLM 层的语义状态），路由是**输入相关的动态路由**，而非固定稀疏连接。

与相关方法的对比：
- *Encoder-side compression*：先压缩层次特征再单点注入——信息在编码器侧即被固定，DGP 保留全量 ViT 层。
- *Predefined sparse/hierarchical connections*：连接结构写死在架构里，DGP 则为每层每个样本自适应分配。

**主干**：构建于 LLaVA-1.5-7B 与 LLaVA-1.5-13B 之上，属于即插即用的连接层改造。

## 📊 实验结果

- **SQA^I**：相对 LLaVA-1.5-7B 基线 **+4.2**
- **MM-Vet**：**+3.3**
- **VizWiz**：**+3.1**
- **LLaVA^W**：**+3.1**
- **总体**：在多数基准上超过既有多层视觉融合方法；骨干规模覆盖 7B 与 13B。
- 逐层路由分析：不同 LLM 层确实选择不同视觉粒度（有效性 + 可解释性双向支持）。

## ⚠️ 局限性

- 仅在 LLaVA-1.5 系列上验证，向更强的新一代 MLLM（带更强视觉塔、更多 LLM 层）迁移的收益未知。
- all-to-all 连接会带来显存与计算开销，摘要未给出参数量/延迟代价的量化数据。
- 门控依赖 LLM 层语义状态，可能对视觉任务的分布外样本不稳定。
- 摘要未披露各基准的具体绝对分数与统计显著性。

## 💡 建议

- 是否推荐使用：是
- 适用场景：基于 LLaVA-1.5 系的多模态模型改造；需要跨视觉粒度推理的任务（细粒度识别、OCR/文档、空间问答、VQA）；关注可解释性、需要知道"哪一层该看哪一层视觉特征"的场景。
