## 核心贡献

> 提出 **Africa-Papers** —— 迄今最大的**策展型泛非多领域学术预训练语料**（**844,807 篇全文 / 10.15B token / 879 个 Parquet shard**），针对「非洲学术内容在主流预训练语料中占比 < 0.5%」的结构性缺口。

1. **量化了缺口**：The Pile / S2ORC / Dolma 中非洲科学、医学、法律、农业学术文献**不足 0.5%** token
2. **对应失效模式**：前沿模型在热带流行病学、本地小农农业生态、区域经济治理、本土语言结构上**系统性失败**
3. **四大来源统一**：DOAJ 期刊（31 个非洲国家）+ CGIAR CGSpace + arXiv 非洲作者/主题预印本 + OpenAlex 非洲机构开放获取成果
4. **高质量处理**：layout-aware 清洗为 Markdown，**保留章节层级、数学公式、表格数据**
5. **完整元数据**：精确 BPE token 计数 + 标准化 8 域分类
6. **完全开源**（Hugging Face Hub, AfriSpeech 组织）

## 技术方案

### 语料构成

| # | 来源 | 覆盖 |
|---|------|------|
| 1 | DOAJ 同行评审期刊 | **31 个非洲国家**的洲际学术 |
| 2 | CGIAR CGSpace | 农业研究仓储 |
| 3 | arXiv | 非洲作者 + 非洲主题 STEM/AI 预印本 |
| 4 | OpenAlex | 非洲机构学者发表的开放获取国际成果 |

| 规模指标 | 值 |
|---------|-----|
| 论文数 | **844,807**（全文） |
| Token 数 | **10.15B** |
| Shard 数 | **879**（Parquet） |
| 领域分类 | 8 域标准化分类法 |

### 处理管线

```math
\text{PDF/raw} \xrightarrow{\text{layout-aware}} \text{Markdown} + \text{section hierarchy} + \text{equations} + \text{tables}
```

配套**精确 BPE token 计数**（而非估算）—— 对预训练预算规划有实际价值。

## 实验结论

这是**数据资源论文**（无模型实验），其贡献在于：

1. 首次提供规模化、可复用的泛非学术预训练语料
2. 提供可验证的缺口量化（<0.5%）
3. 处理后保留公式与表格 —— **对科学类继续预训练是关键**（纯文本化会丢弃表格中的定量信息）
4. 精确 token 计数支持预算规划

---

## 局限性

1. **未做基线验证** —— 没有证明「用它继续预训练」确实改善热带流行病学等领域的推理；作者以「消除表征赤字」论证，但缺实证
2. 语料质量未审计 —— 论文级别 ≠ 高质量；非洲期刊索引的评审标准差异大
3. 语言分布未说明 —— 10.15B token 中本地/殖民语言（非英语）的占比未知，而这才是「本土语言结构」的关键
4. 单作者论文，规模声明（"largest to date"）未给对比证据
5. 法律与医学内容的许可与可用性未讨论（学术版权 vs 训练授权）

## 实现建议

- **适用场景**: 需要领域继续预训练（非洲/热带农业/公共卫生/区域法律）或研究语料代表性偏差
- **使用建议**: 若做继续预训练，**重点检验表格与公式的处理质量** —— 这决定它对科学推理任务的实际增益；不要假设 10B token 全是可用信号
- **⚠️ 提醒**: 论文的失败模式描述（热带流行病学、小农生态等）值得作为**评测集设计灵感** —— 无论是否使用该语料，这些领域确实是主流 LLM 的盲区，值得单独构建 benchmark
- **验证建议**: 把「用不用该语料」和「语料如何清洗」当作两个独立决策；清洗质量的影响可能大于语料来源
