## 核心贡献
1. 在**固定 backbone 与输出格式**的前提下，对生物医学 claim verification（SciFact）任务上的四种 agent harness 做受控消融，隔离出 harness 各组成部分的实际贡献。
2. 发现 naive single-shot retrieval 的 gold 论文命中率**仅 6%**，且会把过度自信的错误转化为 abstention，却**未提升准确率**。
3. 让模型自己生成 PubMed 查询（ReAct-style agent）可**将 gold recall 提升至三倍**，并取得最好的裁决准确率（62% vs 其他 realistic harness 的 49–59%）。
4. 关键的 citation audit：closed-book 模型引用的 PMID **几乎都真实存在（327/335）却几乎都不相关**——跨模型族 LLM judge 判定仅 3/327 条相关，而 search agent 生成的引用相关率达 **67%**。据此论证"存在性检查"不足以作为科学 agent 的安全护栏。

## 问题动机
会检索文献的 language agent 已成为生命科学科研助手的标准组件，但**究竟 harness 的哪一部分真正起作用，缺乏受控证据**。同时，模型倾向于给出格式合法、PMID 真实存在、却与论断无关的引用——这种"真实 PMID、错误论文"的幻觉在科学场景中极具欺骗性且危害更大，因为下游读者难以察觉。因此需要一次把 backbone、输出格式、检索策略逐一控制变量的对照实验。

## 方法
受控消融设计，**唯一可用工具为真实的 PubMed API**，backbone 与输出格式全程固定。对比四种 harness：

1. **Closed-book answering**：不给检索，直接作答
2. **Single-shot retrieval**：直接用 claim 原文作为 query 检索一次
3. **ReAct-style agent**：由模型自己编写 PubMed 查询并迭代检索
4. **Oracle**：直接给定 gold abstracts（作为性能上界探针）

每种 harness 配 **两个高效前沿 backbone**。此外引入 **citation audit** 环节：对模型产出的每条引用，先做"存在性检查"（PMID 是否真实存在），再由**跨模型族（cross-family）的 LLM judge** 评估其与 claim 的相关性，从而分离"引用存在"与"引用相关"两个维度。

## 实验设置与结果
- 数据/基准: **SciFact**（生物医学论断验证），工具为 live PubMed API
- 对比方法: 四种 harness × 两个 backbone（含 oracle 上界）
- 主要结果（摘要显式数值）:
  - Single-shot retrieval 的 gold 论文命中率 **6%**；使过度自信错误变为 abstention，但准确率无提升
  - 自生成查询的 ReAct agent：**gold recall 提升至三倍**，准确率 **62%**，优于其他 realistic harness 的 **49–59%**
    - 作者明确说明：在其样本量下这些差异**未达统计显著**，且 agent 用掉了**不到一半的搜索预算**
  - Oracle（gold abstracts）：同一批模型达到 **79–86%** 准确率，相比 realistic harness 有**显著的 17–24 个百分点差距**
  - Citation audit：closed-book 引用 **327/335** PMID 存在，但仅 **3/327** 被 judge 判为相关；search agent 引用相关率 **67%**
- 核心结论：**retrieval（而非 reasoning）才是主要瓶颈**；仅做引用存在性检查不足以作为科学 agent 的安全措施

## 局限性
论文在摘要中未逐条声明局限性，但作者主动交代了两点关键限制：
1. harness 间的准确率差异（62% vs 49–59%）**在当前样本量下不显著**
2. agent 的搜索预算**未用满**（不到一半），意味着 ReAct agent 的表现可能仍有提升空间
此外审阅时需注意：
- 单一任务（SciFact）与单一工具（PubMed API），结论向其他科学领域/工具的迁移性未知
- 相关性判定依赖 LLM judge，虽已跨模型族但仍是自动评估
- 仅两个 backbone，样本量偏小
