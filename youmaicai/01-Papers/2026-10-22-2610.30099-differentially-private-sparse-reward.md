## 核心贡献
1. 提出并形式化 **Private Sparse RLHF** 问题：假设人类偏好（reward model）仅由 $s^* \ll d$ 个相关特征支配，从而摆脱现有方法对模型规模 $d$ 的多项式依赖。
2. 在 Bradley-Terry-Luce 模型下，给出**首个**从 pairwise preference feedback 出发的差分隐私稀疏 reward 估计的完整理论框架，并分别针对 **Sample-DP** 与 **Label-DP** 两种设定设计了高效算法（均基于 randomized response）。
3. 在 squared $\ell_2$ 参数估计误差下建立上下界：Sample-DP 上界 $\widetilde{O}(s^*/n + s^*^2/(n^2\varepsilon^2))$，Label-DP 上界 $\widetilde{O}(s^*/n + s^*/(n\varepsilon^2))$；并证明 Sample-DP 速率几乎最优，其 Label-DP 保证在 randomized response 框架内无法再改进，另给出 Label-DP 问题的一般下界。
4. 在情感生成与安全对齐基准上实证优于 dense baselines，privacy-utility trade-off 显著更优。

## 问题动机
RLHF 已成为对齐 LLM 与人类价值观的核心范式，但它依赖高度敏感的用户偏好数据，必须有严格的差分隐私保证以防止用户信息泄露。现有私有对齐方法通常假设 **dense reward parameterization**，导致估计误差界随环境维度（模型规模 $d$）呈多项式增长。在现代过参数化模型中 $d$ 极大，这种依赖是不可接受的。若偏好实际只由少数 $s^* \ll d$ 个特征决定（稀疏性假设），则理论上应能将误差对 $d$ 的依赖完全消除——这正是本文要解决的问题。

## 方法
在 Bradley-Terry-Luce 偏好模型下，从 pairwise preference feedback 中估计稀疏 reward 参数，并同时满足差分隐私要求。方法按隐私粒度分为两类：

- **$(\varepsilon,\delta)$-Sample-DP**：对整个训练样本参与度做扰动，平方 $\ell_2$ 参数估计误差上界为
  ```
  \widetilde{O}(s^*/n + s^{*2}/(n^{2}\varepsilon^{2}))
  ```
- **$\varepsilon$-Label-DP**：对单条偏好标签本身施加随机化（randomized response），误差上界为
  ```
  \widetilde{O}(s^*/n + s^*/(n\varepsilon^{2}))
  ```
  其中 $n$ 为训练数据规模。

两种设定均给出对应算法，并配以下界论证：Sample-DP 速率近乎最优；Label-DP 下本文算法的保证在 randomized response 框架内已达上界（无法改进），并额外给出 Label-DP 问题的一般下界。注意噪声项中 $n$ 的幂次不同（$n^{-2}$ vs $n^{-1}$），这是 Sample-DP 与 Label-DP 在效用上的核心差异。
