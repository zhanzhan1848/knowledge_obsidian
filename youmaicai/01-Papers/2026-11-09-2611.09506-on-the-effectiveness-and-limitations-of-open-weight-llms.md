# On the Effectiveness and Limitations of Open-Weight LLMs for Low-Resource Offensive Language Detection in Danish

> **arXiv**: [2611.09506](https://arxiv.org/abs/2611.09506)
> **发表日期**: 2026-11-06
> **分类**: cs.CL (Computation and Language)
> **会议/期刊**: 2026 IEEE International Conference on Big Data (BigData 2026)
> **代码**: https://github.com/PASHAADC/Danish-LLM-HateSpeech

## 📋 摘要

本文研究开放权重（open-weight）大语言模型在**丹麦语冒犯性语言检测**上的有效性与鲁棒性——这是一个鲜有研究、典型的**低资源任务**。作者评估了**四个模型家族**（Llama、Mistral、Gemma、Qwen）在**十一套提示策略**上的表现，覆盖五个设计类别，并考察了**跨提示泛化**、**丹麦语正字法变体**以及在**平衡与自然类别偏斜**分布下的鲁棒性。对照对象是**三个具有不同预训练策略的 BERT 家族基线**，分别用掩码语言模型提示（MLM prompting）与有监督微调两种方式评估。结果显示：**即使不做任务特定微调**，LLM 也可以**超过全部三个已微调的 BERT 基线**；而轻量微调能带来可观的进一步增益。同时，**没有任何单一模型或提示类别占据主导地位**，这凸显出提示设计与预训练之间的交互作用**无法事先预测**。**语义上有依据（semantically grounded）的提示**跨提示泛化更稳健，而**格式受限（format-constrained）的模式则持续无法泛化**。把丹麦语特有字符（æ、ø、å）做 **ASCII 转写通常会降低性能**，说明这些字符承载了有意义的信号。另一方面，平衡测试集（最佳 F1 为 **0.84**）与语料自然类别偏斜之间的差距（偏斜数据训练得 0.62、平衡数据训练得 0.70，相对下降 **26.2%** 与 **16.7%**）表明，**类别不平衡仍是关键的开放挑战**。代码与配置已开源。

## 🎯 核心贡献

1. **首个系统性评估开放权重 LLM 在丹麦语冒犯性检测上的表现**：覆盖 Llama / Mistral / Gemma / Qwen 四个家族 × 十一套提示策略（五个设计类别）。
2. **「零微调 LLM > 已微调 BERT」的实证**：在不做任务特定微调时，LLM 的表现即可超过全部三个经过监督微调的 BERT 基线。
3. **提示设计 × 预训练的不可预测交互**：没有单一模型或提示类别占优，说明必须实测而非凭经验选择提示；语义有依据的提示泛化更好，格式受限模式必然失败。
4. **正字法敏感性发现**：æ / ø / å 的 ASCII 转写普遍损害性能，这些字符携带实质语义信号（对语言资源构建与数据清洗有直接指导价值）。
5. **量化类不平衡的影响**：平衡集 F1 0.84 vs 自然偏斜下 0.62 / 0.70（相对下降 26.2% / 16.7%），明确指出类不平衡是核心遗留问题。

## 🔧 方法/架构

- **评测矩阵**：4 个 LLM 家族 × 11 套提示（5 个设计类别）× {平衡, 自然偏斜} × {零样本, 轻量微调} × {正字法变体, ASCII 转写}，并与 3 个 BERT 家族基线对照（MLM prompting + 监督微调）。

- **提示设计类别**：论文将提示归纳为五类，其中包括**语义有依据（semantically grounded）**的提示与**格式受限（format-constrained）**的提示；后者在跨提示泛化上**持续失败**。

- **鲁棒性分析维度**：

  ```math
  \mathcal{R} = \underbrace{\mathcal{R}_{\text{cross-prompt}}}_{\text{跨提示泛化}}
  \;\times\;
  \underbrace{\mathcal{R}_{\text{orthography}}}_{\text{æ/ø/å 变体与 ASCII 转写}}
  \;\times\;
  \underbrace{\mathcal{R}_{\text{prior shift}}}_{\text{类别先验偏移}}
  $$

- **类别先验偏移的量化**：以平衡测试集上的最佳 F1 为参照，度量在自然偏斜下的相对退化：

  ```math
  \Delta_{\text{rel}} = \frac{F1_{\text{balanced}} - F1_{\text{skewed}}}{F1_{\text{balanced}}}
  \]

- **模型-提示交互分析**：比较同一提示在不同家族上的表现差异，以及同一家族在不同提示类别上的方差，得出「无法先验预测」的结论。

## 📊 实验结果

- **数据集**: 丹麦语冒犯性语料（摘要未给出数据集名称；代码仓库为 `PASHAADC/Danish-LLM-HateSpeech`，含平衡与自然偏斜两种划分）。
- **基线**: 三个不同预训练策略的 **BERT 家族**基线（MLM prompting + 监督微调两种评估方式）。
- **结果**:
  - 零微调 LLM **超过全部三个已微调 BERT 基线**；轻量微调带来**进一步显著提升**；
  - **无单一模型或提示类别占优**；
  - 平衡测试集**最佳 F1 = 0.84**；
  - 自然类别偏斜下：**偏斜数据训练 F1 = 0.62**（相对下降 **26.2%**），**平衡数据训练 F1 = 0.70**（相对下降 **16.7%**）；
  - **ASCII 转写 æ/ø/å 通常降低性能**；格式受限提示**持续无法泛化**。

## ⚠️ 局限性

- **单一语言**：结论仅在丹麦语上验证，迁移到其他低资源语言（尤其非拉丁字母脚本语言）需重新验证。
- 数据集来源与规模未在摘要中说明；丹麦语冒犯性语料本身的标注质量与方言/俚语覆盖度可能限制上限。
- 「轻量微调」的具体配方（LoRA? 全参? 超参）未在摘要披露，复现需依赖仓库。
- 平衡/偏斜之间的落差部分来自评测集构造方式（是否同分布采样），绝对数值外推需谨慎。
- 提示评估使用闭源 API 之外的开放权重模型，但未与商用审核 API（如内容安全接口）对比，生产参考价值有限。
- 未涉及对抗性规避（刻意改写冒犯表达）、代码混合格言（memes/图音）等真实场景的鲁棒性。

## 💡 建议

- 是否推荐使用：**是**（作为低资源语言内容审核选型与提示设计的实证参考）
- 适用场景：丹麦语 / 北欧语言社区的内容审核与反骚扰系统选型（LLM vs. 微调 BERT 的成本-效果决策）、低资源语言安全检测系统的提示模板设计（优先语义有依据、避免格式受限）、训练数据清洗（保留 æ/ø/å 等正字法信号）、内容审核系统的类别不平衡鲁棒性压测
