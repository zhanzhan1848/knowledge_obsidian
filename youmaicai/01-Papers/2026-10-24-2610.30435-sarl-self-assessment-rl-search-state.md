## 核心贡献

> 提出 SARL —— 一个强化学习框架，让模型在训练中学会**识别自己的检索状态**（已获得什么、还缺什么），从而在不引入任何测试时额外评估模块的前提下改善搜索行为。

1. **提出 search-state awareness 问题**：现有 search agent 普遍缺乏对自身检索进展的感知，导致幻觉式推理与过早终止检索
2. **Dual reward 设计**：奖励中同时刻画"自我评估带来的纠正效果"与"对自我评估的过度依赖"惩罚，联合鼓励**有效且高效**的搜索轨迹
3. **无推理时脚手架**：作为独立的 RL 框架工作，不需要在推理阶段再挂一个额外评估器 / 辅助监督信号 / 多智能体协作
4. **长搜索视野下训练稳定**：在 extended search horizons 这一现有方法普遍退化的区间，SARL 保持稳定并随任务复杂度增长持续获益

## 技术方案

### 核心思想

把"我已经检索到什么 / 还缺什么"这件事从**外部外挂的检验器**变成**模型内化的能力**。做法是在 RL 训练中让模型自己对当前检索状态做判断，并用一个成对奖励设计把"判断带来的纠正"和"判断带来的冗余"区分开：评估只有在真正修正了行为时才被奖励，而无谓的自我评估会被惩罚。

### 关键组件

| 组件 | 说明 |
|------|------|
| Self-Assessment | 模型显式判断已获取信息与缺失信息的状态表征 |
| Dual Reward | 一路奖励"评估的纠正效应"，一路惩罚"对评估的过度依赖" |
| Effective + Efficient Trajectory | 联合目标：既找到答案，又不多做无用检索 |
| Test-Time Free | 能力内化进策略，部署时无需额外 assessment 模块 |

### 关键公式

双奖励可抽象为"纠正收益 − 冗余成本"的组合：

```math
R_{\text{dual}} = \lambda \cdot R_{\text{corrective}} - (1-\lambda) \cdot R_{\text{over-reliance}}
```

其中 $R_{\text{corrective}}$ 度量该次评估是否真的改变了后续检索/推理走向，$R_{\text{over-reliance}}$ 度量模型是否在无收益处反复自我评估。

评估内化的判据可写为：评估只有在**改变了后续行为**时才获得正奖励。

```math
R_{\text{corrective}} = \mathbb{1}\!\left[\text{behavior} \ne \text{behavior}^{\text{no-assess}}\right]
```

## 实验结论

| 指标 | SARL 结果 |
|------|-----------|
| 相对最强基线的整体提升 | **+24.3%** |
| 多跳推理（multi-hop）平均提升 | **+35.9%** |
| 深度研究（deep research）基准平均提升 | **+27.9%** |
| 对比对象 | 依赖辅助监督的方法、多智能体协作方法均被超越 |
| 推理时开销 | 无额外 scaffolding（standalone RL framework） |
| 长搜索视野 | 现有方法一致退化，SARL 保持训练稳定 |

对照口径说明：24.3% 为对最强基线的相对提升；35.9% / 27.9% 为**对每个基准各自最强基线**的平均增益。

## 局限性

- 依赖模型自身生成检索状态判断，判断质量与最终收益直接挂钩，能力弱的 backbone 可能难以从双奖励中学到有效信号
- dual reward 中"纠正效应"与"过度依赖"的度量需要可对比的轨迹对，构造这些反事实轨迹的工程成本未在摘要中说明
- 长搜索视野下的稳定性结论来自训练过程，摘要未给出推理阶段的额外收益量化
- 未报告对不同基座模型规模/类型的系统性敏感性分析（相较 MOER 类工作）

## 实现建议

- **实现难度**: 中高（需要构造 self-assessment 轨迹 + 设计双奖励，并行采样以获得纠正效应的对照信号）
- **适用场景**: 需要多跳检索 / 深度研究的 RAG 系统，尤其是当前模型经常"搜一半就下结论"或凭空补全事实的场景
- **建议起点**: 先在已有 GRPO / RLVR 训练管线中插入一条自评分支，只训练"是否继续检索"的决策头，验证双奖励能否区分有效与冗余评估
- **价值点**: 推理期零额外成本 —— 相比外挂 critic 或多智能体方案，部署复杂度显著更低
