## 核心贡献

> 现有量化交易基准只评「公式 / 代码 / 单个交易决策」，无法回答 LLM 能否**跑完整个研究闭环**并产出**研究期之外仍然有效**的策略。Quant-Arena 用**真实 A 股数据**、**冻结策略**、**密封的 2024 年**评估期，构成端到端量化研究基准 —— 结果是：**九个前沿模型中 GPT-6 Astra 得分最高，但没有一个模型在 2024 年跑赢等权市场**。

1. **提出端到端量化研究闭环的任务定义**：研究者提出市场假设 → 实现为可执行信号 → 在历史数据上回测 → 决定保留什么。模型需要**构造特征与股票打分代码**。
2. **严格的时序密封设计**：模型在 **2022–2023** 上接收反馈，然后**冻结一个策略**，在**密封的 2024 年**上受评 —— 直接针对「过拟合到研究期」这一核心风险。
3. **现金账户评估器（cash-account evaluator）**：施加**交易约束与交易成本**，其中**市场冲击（market impact）由模拟订单簿（simulated order book）估计** —— 这是把「纸面收益」拉回现实的关键。
4. **多维度评分**：分数**由实现超额收益（realized excess return）主导**，并辅以**信号质量（signal quality）**与**策略所用特征的多样性（diversity of features）**。
5. **九个前沿模型的评测**：**GPT-6 Astra 得分最高**；但**没有任何模型在 2024 年超越等权市场（equal-weight market）**。基准**对任意模型或 agent harness 开放提交**。

## 技术方案

### 核心思想

**被批评的现状**：已有基准分别评 formulas、code、或 individual trading decisions —— **三者都无法验证「策略是否在研究期之外有效」**。这正是量化研究最容易自欺的地方：回测好看 ≠ 未来赚钱。

**Quant-Arena 的回应**：把整个**研究闭环**作为评估对象，并且用**时间密封**把「研究与评估」在物理上隔开。

**流程**：
1. 模型收到任务，**构造特征与股票打分代码**（feature & stock-scoring code）；
2. 在 **2022–2023** 的数据上得到**反馈**（可以迭代优化）；
3. **冻结（freeze）** 一个策略 —— 此后不得修改；
4. 在**密封的 2024 年**上受评；
5. **cash-account evaluator** 施加交易约束、成本，以及**基于模拟订单簿的市场冲击估计**；
6. 计分。

**评分构成**：以 **realized excess return** 为主导 + **signal quality** + **特征多样性**辅助 —— 后两者奖励「不押注单一因子」的策略，对抗「只用一个偶然奏效的指标刷收益」的策略。

**开放性**：benchmark 与 public leaderboard **接受任何模型或 agent harness 的提交** —— 这对第三方复现与 rival 方案对比很重要。

### 关键技术

| 技术 | 说明 |
|------|------|
| **End-to-end research loop** | 假设 → 代码化信号 → 回测 → 保留决策，作为单一评估对象 |
| **Sealed evaluation year (2024)** | 评估数据对模型不可见，是「研究期外有效性」的硬约束 |
| **Feature construction** | 模型自行设计特征，而非给定特征集 |
| **Stock-scoring code** | 以可执行代码表达选股逻辑，保证可复现与可审计 |
| **Cash-account evaluator** | 现金账户语义（可空仓、不加杠杆）下的净值计算 |
| **Trading constraints & costs** | 显式建模交易约束与交易成本 |
| **Market impact via simulated order book** | 从模拟订单簿估计冲击成本，抑制「无摩擦高换手」的虚假收益 |
| **Realized excess return** | 主导评分项 |
| **Signal quality** | 辅助评分项 |
| **Feature diversity** | 辅助评分项，惩罚单因子押注 |
| **Public leaderboard / open submissions** | 接受任意模型或 agent harness 提交 |

## 关键实验结果

| 项目 | 结果 |
|------|------|
| **评测模型数** | **9 个前沿模型（nine frontier models）** |
| **最高分模型** | **GPT-6 Astra 得分最高** |
| **关键否定结果** | **没有任何模型在 2024 年超越等权市场（equal-weight market）** |
| **反馈窗口** | **2022–2023** |
| **密封评估窗口** | **2024** |
| **市场** | **真实 A 股数据（real A-share market data）** |
| **主导指标** | **realized excess return** |
| **辅助指标** | **signal quality**、**feature diversity** |
| **成本建模** | 交易约束 + 交易成本 + **由模拟订单簿估计的市场冲击** |

---

## 关键结论

1. **端到端闭环 + 密封年份，是量化基准唯一有意义的评估形态。** 单看公式、代码或单次决策，都可以被针对性优化；只有把「策略冻结 + 未来年份评估」绑在一起，才能暴露真实泛化能力。
2. **最强模型也没有跑赢等权市场。** 在九个前沿模型中，GPT-6 Astra 得分最高，但**全部在 2024 年不如等权基准**。这是一个非常强的信号：**当前 LLM 产出的量化策略在真实市场上没有证明 alpha**。
3. **成本建模是基准能否有信息量的分水岭。** 用**模拟订单簿估计市场冲击**意味着高换手策略会被自然惩罚 —— 若忽略冲击，任何「高频微调信号」都能刷出虚假收益。这个设计细节比多数基准做得好。
4. **辅助指标（signal quality、feature diversity）的作用是抑制单因子赌博。** 主指标是超额收益，但收益单指标同样可被「找一个偶然因子猛押」攻略。
5. **基准开放提交是正确选择**：模型侧与 harness 侧都在快速迭代，封闭复现会让结论迅速过时。

## 局限性

- **摘要未给出任何绝对数值** —— 没有 2024 年的具体收益数字、没有各模型的分数排名、没有 equal-weight benchmark 的具体数值。因此**「都没跑赢」的具体差距幅度未知**（可能是差 0.1% 也可能是差 30%）。
- **单一市场、单一时间段**：**A 股 + 2022–2024**。结论在其他市场（美股、加密）与更长周期上是否成立未知；**2024 年的 A 股市场状态本身**可能特殊（特定风格/板块）。
- **规模有限**：**9 个模型**、**一次评估窗口**；未做多期滚动（如 2023→2024、2024→2025）以验证基准自身的时间稳定性。
- **「无模型跑赢等权」这一结果的解释有多种可能**：可能是模型能力不足、可能是基准设计过严（市场冲击估计过保守）、也可能是 2024 年本身缺乏 alpha —— **摘要未做归因**，读者无法区分。
- **可复现性依赖市场冲击模型**：模拟订单簿的具体假设（深度、滑点、流动性假设）未说明，**这是评分中最主观也最易被质疑的环节**。
- **成本/滑点假设对策略排名的影响未做敏感性分析**（摘要未提）。
- **未报告失败模式分析**：模型具体卡在哪一步（特征设计？代码正确性？过拟合控制？）没有拆解。
- **agent harness 维度未展开**：摘要说「开放任意 agent harness 提交」，但**未说明不同 harness 之间的差异**，以及框架本身（工具集、最大轮数）是否限制了模型表现。

## 实现建议

- **实现难度**：高（需 A 股历史数据、现金账户评估器、订单簿冲击模拟、泄漏防护的密封评估管道）
- **预期性能**：**GPT-6 Astra 为当前最高分模型；全体参评模型 2024 年均未超越等权市场** —— 若目标是选型，应以「等权」为现实基线而非「大模型分数」
- **适用场景**：**评估 LLM 的端到端研究能力与策略泛化**；作为**第三方 agent harness 的公开竞技场**；不建议直接作为实盘信号来源
- **团队行动**：若自建量化研究 benchmark，**务必照抄三点** —— 密封年份、含市场冲击的现金账户评估器、以超额收益为主 + 特征多样性为辅的复合评分
