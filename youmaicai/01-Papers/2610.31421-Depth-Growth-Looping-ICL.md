## 核心贡献

> 系统研究 **depth-grown（深度增长）** 与 **looped（循环）** 语言模型**为何、以及如何**偏好 in-context learning，给出机制层面证据：**induction head 的跨层传播**。

1. **背景**：looped / depth-grown LM 通过跨深度**复用计算**（parameter reuse）获得推理能力，先前有"ICL 改善"的提示性证据，但机制未明。
2. **三个问题**：这种复用**如何塑造 ICL**？如何影响该能力的**习得（acquisition）、保持（retention）与机制（mechanism）**？
3. **发现**：
   - **共同的"从上下文学习"归纳偏置**：grown 与 looped 模型**更依赖 context 中的信息**；
   - 相比 full-depth dense reference，它们在受控任务上**更早习得 ICL**，且当"把固定关联也写入权重"成为可能时，**保持 ICL 更强**；
   - **机制**：追踪训练中的 attention heads 发现 **depth growth 把 early induction heads 跨层传播**；
   - **消融**：grown / looped 模型在 few-shot 性能与后续 token 预测上**更依赖 induction-ranked heads**。

---

## 技术方案

| 维度 | 观察 |
|------|------|
| Acquisition | grown/looped 更早获得 ICL |
| Retention | 即使可以把关联写进权重，仍保持 ICL |
| Mechanism | depth growth → induction heads 跨层传播 |
| Ablation | induction-ranked heads 对 few-shot 与后续 token 预测贡献更大 |
| Scale | 预训练模型至 **3B** 参数 + 受控任务 |

### 关键洞见

- "更早习得 ICL" + "更少写入权重" → 说明**软参数复用**（soft parameter reuse）本身构成了一个**偏向上下文学习**的归纳偏置。
- 这对实践有直接含义：**如果目标是在上下文里放更多能力（few-shot / RAG / 工具结果）而非烤进权重，depth-growth / looping 架构可能比 dense 更合适。**

---

## 实验结论

- **规模**：预训练 LM 至 3B + 受控任务
- **结论**：depth-grown 与 looped 共享"从上下文学习"的归纳偏置；parameter reuse 影响该能力**如何发展**及**哪些 attention 机制支撑它**。

---

## 局限性

- 仅至 3B 参数 —— 更大规模是否保持未知；
- 受控任务 ≠ 真实下游任务；
- depth growth 的实现方式（权重共享模式）可能影响结论泛化；
- 未涉及训练时序（是否可通过训练策略而非架构获得同效应）。
