## 核心贡献

1. **非对称目标函数**：观察到伪标签错误时，不同意伪标签的 rollouts 中 ~79% 是真正错误的——这使得对不一致 rollouts 的惩罚对伪标签质量不敏感。

2. **OPSD + GRPO 分离**：
   - **OPSD 分支**：对同意伪标签的正样本进行 forward KL 蒸馏，配合 token 级选择（降低已收敛位置权重）
   - **GRPO 分支**：对不同意伪标签的负样本进行分组相对策略优化，配合 token 遮罩（仅惩罚高置信度错误）

3. **无需标签的 TTT**：无需任何 ground-truth 标签，TTPO 在5个竞赛级基准上匹配有标签监督的 OPSD；将 Qwen3-1.7B 在 TTT 设置下从 38.0% 提升到 45.2%

4. **强跨任务泛化**：任一基准上训练均能提升其他两个基准的性能

## 关键洞察

**伪标签的非对称失败模式**：
- 竞赛级问题上，伪标签约 85% 是错的
- 但即使伪标签错误，约 79% 的不同意 rollouts 自身也是错的
- **蒸馏**对伪标签错误敏感（错误答案进入 teacher，每 token 都误导）
- **惩罚**对伪标签质量不敏感（只需"不在多数簇中"，与伪标签内容无关）

## 方法

### 多数投票伪标签
```math
\hat{a} \leftarrow \text{plurality}(\{a^{(k)}\})
\mathcal{P} \leftarrow \{k: a^{(k)} = \hat{a}\}  \quad \text{(正样本)}
\mathcal{N} \leftarrow \{k: a^{(k)} \neq \hat{a}\} \quad \text{(负样本)}
```

### Teacher-Student 设置
```math
q_t^{(\hat{a})} = \pi_\theta(\cdot \mid [x; \hat{a}]_{\text{teacher}}, y_{<t})  \quad \text{(no grad)}
p_t = \pi_\theta(\cdot \mid x_{\text{student}}, y_{<t})  \quad \text{(with grad)}
```

### OPSD 分支（正样本）
```math
\mathcal{L}_{\text{OPSD}}(k) = \frac{1}{T_k} \sum_{t=1}^{T_k} w(t) \cdot \text{KL}(q_t^{(\hat{a})} \parallel p_t)
```
Token 权重：
```math
w(t) = \hat{H}(t) + \hat{\Delta}(t) - \hat{H}(t) \cdot \hat{\Delta}(t)
```
（高权重 = 学生不确定 OR 与 teacher 显著分歧）

### GRPO 分支（负样本）
```math
\mathcal{L}_{\text{GRPO}}(k) = -\frac{A_k}{T_k} \sum_{t=1}^{T_k} m(t) \cdot \log \pi_\theta(y_k^{(t)} \mid x, y_k^{(<t)})
```
Token 遮罩（选择得分最高的50% token）：
```math
s(t) = -\log \pi_\theta(y_k^{(t)} \mid x, y_k^{(<t)}) \cdot (1 - \hat{H}(t))
m(t) = \mathbf{1}[s(t) \geq \text{median}(\{s\})]
```

## 实验结果

**基准**：AIME 2026, HMMT 2026, BRUMO 2025（竞赛级）

| 模型 | 设置 | 平均准确率 |
|------|------|-----------|
| Qwen3-1.7B | Base | 38.0% |
| Qwen3-1.7B | +TTPO (TTT) | **45.2%** |
| Qwen3-1.7B | +thinking 禁用 +TTPO | +25.2%~36.4% |

- 无标签 TTT 性能匹配有标签监督的 OPSD
- 跨任务泛化：任一基准训练 → 其他基准提升

## 局限性

- 主要验证数学推理，其他领域未充分测试
- 伪标签质量仍影响正样本分支（OPSD）
- Token 遮罩的 50% 阈值是经验设定

## 建议
- **推荐使用**：是
- **适用场景**：无标签测试时训练、竞赛级推理任务、模型自进化
- **关键优势**：无需 ground-truth 标签，成本低，泛化强
