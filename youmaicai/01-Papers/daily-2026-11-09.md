## 🎯 今日主线

**今天 60 篇论文里最尖锐的一条线索，是「状态」这个概念正在从模型外部被搬进模型内部——而且是被三组互不相干的论文同时搬进去。**

- **KV cache 是状态**（LaProx、Transformer-FSQ、BitDecoding-FP4、PriorityFEC、MINE）：今天有 **5 篇**独立工作把 KV cache 当作一等公民来重新形式化——不是"压缩它"，而是"重新定义什么是 cache eviction"、"把 cache 本身离散化"、"让 cache 用 FP4 硬件原生解码"、"把 cache 的网络传输当作 FEC 编码问题"、"把权重也当作可熵编码的 cache"。
- **上下文是状态**（Beyond Truncation、Can LLMs Take Retrieved Information with a Grain of Salt）：长度控制与"检索置信度"的处理方式，共同指向一个问题——**模型在生成过程中是否知道自己处于一个不确定的中间状态**。
- **推理轨迹是状态**（TraceSpec、Counterfactual Distillation、Reasoning Distillation、Characterize Then Distill）：4 篇论文把 CoT 轨迹从"一次性生成的文本"重新理解为"可采样、可重放、可归因、可蒸馏的中间状态"。

而把这些串起来的，是另外几篇论文提出的**审计视角**：
- **Reconstructing LLM Lineage Trees**：模型的血缘关系（谁微调自谁）目前只能靠自述，无法验证——这恰恰是"状态 provenance"的问题。
- **Same Request, Different Answer**：同一个请求在开启 prefix cache 后给出不同答案，而且**量化会放大这种分歧**——这说明 cache 引入的状态污染已经进入了部署现实。
- **AuthGateBench**：coding agent 的授权判断被委托给 LLM，但 LLM 作为"授权门"有 scope escalation 失效模式。

**今天的一个共同判断是：state 是隐式的，且正在被污染。** 这三组从不同方向撞上了同一个结论。

### 一、安全性：从"分数"转向"结构"与"退化路径"

- **AttentionSwitch**：越狱防御不再靠微调或外挂 guard，而是**联合学习稀疏注意力头的选择与缩放**——把"安全"直接做进注意力结构本身，避免了微调带来的灾难性遗忘。
- **Guardrail Erosion（生物医学域微调审计）**：审计 **25 个**生物医学领域微调模型，聚焦此前较少被研究的 **knowledge-centric abstention**（"我不知道"而非"我拒绝"）——此前的工作主要研究 value-centric refusal。结论是：领域微调会侵蚀护栏，而且**测量的是错误的那一侧**。
- **Safety and accuracy diverge（SaFE-Scale / RadSaFE-200）**：在放射学场景下引入 **200 题**基准（临床医生标注的 clean evidence / conflict evidence / option-level 标签），直接检验"更大模型 = 更安全"这一默认假设。在医学场景中，**少数自信的或与证据矛盾的错误，其危害远超平均性能**。
- **Learning to Persuade Exposes How Easily LLMs Abandon Correct Beliefs**：只要**一个**针对性的说服性论证，就能把模型准确率打到接近零——**即使该论证在事实上是错的**。
- **Towards the Worst-case Robustness of LLMs**（TMLR）：从实证与理论双侧讨论 LLM 鲁棒性，明确指出"面对更强的未来攻击会怎样"这个问题此前被回避。
- **PACZero**：用 **PAC Privacy**（instance-based，界(mutual information)）替代 DP 的 (ε, δ)，对 ZO 微调做**符号量化**，在稳定性上做校准——绕开了 DP 对 LLM 过于严苛的效用-隐私权衡。
- **Minerva**：网络安全威胁情报领域，用 **RLVR**（CTI 标准与社区资源定义了规范标识符与 schema，因此奖励**可确定性验证**）替代 SFT——这是"可验证奖励"路线在垂直领域的一次漂亮落地。
- **AuthGateBench**：把 LLM 当作授权门来测，覆盖 Claude Code / Codex 一类工具里的 scope escalation 失效模式，并提供公开数据集。
- **Subliminal Learning in VLMs**：把 LLM 中已知的"隐性学习"（teacher 通过与偏好无关的数据传递隐藏偏好）**扩展到视觉-语言模型**——教师 VLM 偏好某种动物或面部属性，控制组教师用无关数字数据生成训练集，学生仍然继承偏好。
- **BiG-SURE**：黑盒（参数不可访问）场景下的不确定性估计，用**跨温度语义一致性** + 二部图建模，把低温响应作为"稳定语义锚点"、高温响应作为探针。

### 二、效率：KV cache 是今天的绝对主角

今天有 5 篇论文独立地攻击同一个目标，路径却完全不同——这本身就是个信号，说明这条赛道的解空间还没收敛：

| 论文 | 切入角度 | 核心手段 |
|------|---------|---------|
| **LaProx**（NeurIPS 2026） | **重新形式化** | 把 KV cache eviction 从"逐头、加权平均"重写为**输出感知、逐层的矩阵乘近似**——显式建模 value 表示、输出投影与头间交互的乘性影响 |
| **Transformer-FSQ** | **离散化 cache 本身** | 用离散 latent 表示 KV cache。动机数据很硬：**Qwen3-1.7B-Base 保留 200,000 条 entry 需要 21 GiB，是模型权重的 6.6 倍**；而现有方法在中等压缩率以上即失效 |
| **BitDecoding-FP4** | **算法-系统协同设计** | 直接用 FP4 Tensor Core 跑 attention。指出现有 FP4 KV 系统用 vanilla 量化导致严重掉点，而追求精度的 4-bit 算法用向量码本、查表开销又拖垮解码——**这是一个"算法与系统两端各欠一块"的经典夹缝** |
| **PriorityFEC** | **网络传输** | 边缘多 agent 系统里 KV cache 必须在接收方开始解码**之前**送达；严格 deadline + 不可靠链路下完整传输不可行，于是把 KV 交付建模为**deadline-aware 流式 FEC** |
| **MINE**（ICLR 投稿） | **权重流式传输** | 单流解码是**强内存带宽受限**的（每生成一个 token 所有权重必须从内存流过，且本地/低延迟场景无法批处理）。用**无损熵编码**加速——并指出既有无损压缩只在特定数据类型（如 BF16）和额外假设下才有加速 |

再往上还有三篇改的是**注意力本身**：

- **Adamas**（Hadamard 稀疏注意力）：针对长上下文推理的自注意力二次成本，指出固定或粗粒度的 token 选择会**漏掉重要 token**或保留大量冗余。
- **Attend at the Right Resolution**：head-adaptive 稀疏注意力，通过 **query-key 交互结构**在低成本下定位相关区域。
- **Gated DeltaNet-2**（NeurIPS 2026）：线性注意力里"忘记什么"不是难点，难点是**如何编辑这个压缩记忆而不打乱已有联结**——Delta-rule 先减后加，但主动编辑仍用同一个共享门；Gated DeltaNet-2 的贡献正是**把擦除与写入解耦**。

以及一条**投机解码**的 agent 版本：
- **TraceSpec**：指出 agent 的聚合投机解码指标把多个不同决策混在一起，无法指示"哪里需要 draft 监督"。提出连接轨迹评估与自适应 draft 训练的框架，配套 **10,000 训练状态**的 TraceSpec-Traj 语料。

### 三、推理能力：反例一个接一个

今天关于"推理模型到底更强吗"的证据，比以往任何一天都更负面：

- **Does Reasoning Improve Psychological Depth**：用 DeepSeek-R1 vs DeepSeek-V3、GPT-5 vs GPT-4o 这两组"最接近的对比"，做 **60 次盲测两两评测**（7 名人类标注者 + LLM-judge 集成）。结论推翻了"benchmark 上的收益会外溢到开放式创作任务"这一默认假设。
- **Weak-to-Strong Legibility of Reasoning Models**：主张推理语言模型**也应该按它与更弱模型之间的交互效应来评估**——在安全监控与蒸馏这类场景中，这个视角比直接的模型能力更重要。
- **Characterize Then Distill**：把推理模型的标签选择机制**拆到 token 级**——选粗粒度区域的 token、区域内选具体标签的 token、以及在何处"放弃"其他标签的 token；并追问该机制能否被蒸馏。
- **Failure Profiling and Reachable Trajectory Selection**：学生模型会**过拟合教师的输出分布**，在推理时行为一旦偏离训练数据就泛化差；纠错数据的引入方式也需要重新设计。
- **Counterfactual Distillation**：RLVR 只利用最终成功信号，把交互经验与反馈**浪费了**。在稀疏奖励长程任务中尤其明显。本文把**反思经验**内化进 agent。
- **Hide to See**（NeurIPS 2026）：think-answer 类 VLM 在长推理轨迹中存在**视觉遗忘**问题；提出 reasoning-prefix masking，要求学生把思考**锚定**到视觉证据上。

### 四、检索与知识：KG 的角色从"相似度检索"转向"确定性知识源"

- **Typed-Centrality Grounding for Agentic GraphRAG**：直接批评现有 GraphRAG——把 KG 当**同质图**，依赖 prompt 与 context 的**文本相似度**，而不是把 KG 当作**确定性知识源**。本文引入符号层来做 agentic 推理。
- **PersonalAI 2.0**：多阶段动态管线，用抽取实体、匹配图顶点、生成线索查询来**引导自适应迭代检索**。
- **KG-RAG4SM**：schema matching 中，相似度方法解决不了语义歧义与冲突（缺常识与领域知识），LLM 则容易幻觉；用 KG 补上这一层。
- **Can LLMs Take Retrieved Information with a Grain of Salt?**（NeurIPS 2026）：在 **8 个 LLM** 上评估 **context-certainty obedience**——模型能否让回答强度匹配检索信息的确定性。在**医疗与金融**这类高风险领域，这是有实际后果的能力。
- **Beyond Truncation? Entailment-Licensed Elision**：instruction-tuned LLM 的回答普遍比需求长。提出解码循环内的**免训练控制器**（熵门控 logits processor），在 MT-Bench 开发集上移除 **25.5–34.9%** 的 token、在另一数据集上移除 **19.9–34.2%**，判据是「相对最简单基线——把模型自己的回答截断到同样长度——是否保住了内容」。
- **AlienBench**：创造力评测中，让人类或 LLM 打"有多新"**没有固定参照**；本文以**结构新颖性**为度量构建基准。

### 五、个性化与多目标：一个反复出现的"多目标"事实

今天有**两篇独立论文**把同一个结论推到台面上——**准确率不是唯一目标，而现有训练方法难以适配演进中的偏好**：

- **MATO**（NeurIPS 2026）：多目标个性化对齐。现有方法要么依赖昂贵训练，要么需要为每个偏好预训练一个 reward model；prompt-based 个性化虽然免训练，但**可控性有限**——模型会过度强调或忽略某些偏好，用户无法可靠地控制不同目标的相对重要性。MATO 用**测试时优化**解决。
- **MoMHa / Meta-Harness**（NeurIPS 2026）：主张 **harness**（包在模型外的 Python 代码：构造 prompt、路由调用、解析输出）是**一等设计面**且本质上是多目标的——"一个准确但从不拒绝不安全请求、或者消耗多一个数量级 token 的 harness，不是好 harness"。把 harness 设计建模为搜索问题。
- **Follow the Features**（SAE 特征引导的数据选择）：用 **sparse autoencoder 特征**刻画训练数据并指导子集构建；关键设计是**用于选择的 LLM-SAE 对与被微调模型无关**，因而可跨目标模型复用。
- **KDFP**（first-principles 知识蒸馏）：指出一个被忽视的缺口——近期 LLM 蒸馏工作几乎都在蒸馏**后训练**能力（指令跟随、CoT、工具使用），而**通用知识蒸馏**对部署到边缘设备（高效 + 隐私）仍然关键。
- **Dominant-Layer ZO**：一个相当反直觉的发现——**ZO 微调被单个解码层急剧主导**。跨多个 LLM 家族与任务，**只微调这一层就持续达到甚至超过全模型 ZO 微调**；且该层是**任务无关但模型特定**的，可在训练前用简单方法识别。

### 六、Agent 与 harness

- **AgentGrad**（NeurIPS 2026）：指出既有 textual gradient 方法在**两个阶段**上的局限，干预引导的 prompt 优化面向多 agent 系统。
- **GABench**：面向图分析任务的 LLM agent 基准，指出既有图基准**任务与图类型覆盖有限**，且通常把 agent 简化掉。
- **PersonalAI 2.0**（见上）与 **Typed-Centrality Grounding**（见上）共同指向 GraphRAG 的符号化转向。
- **Reconstructing LLM Lineage Trees**（ICLR 2027 在审）：微调衍生模型的血缘目前**依赖自述且不可验证**。误标血缘会让验证者无法审计外包微调、确认许可证合规，或追溯父模型传给子模型的漏洞——**三者都需要派生方向，而不仅是派生关系的存在**。

### 七、其他值得单独点名

- **Fine-Tuned Language Models Exhibit Improved Information Conveyance**：主流认知是"微调降低不确定性"，但既有分析忽略了**输出长度**这个关键混淆因子，因此未能刻画不确定性在整条生成 rollout 上的分布。提出 **Canopy Entropy (CE★)**，把生成视为一棵树，"canopy" 是所有可能路径构成的空间。
- **DunbaaBERT**（ACL 2026）：乌尔都语 RoBERTa-base 家族，**从零训练**，Byte-BPE 词表 32k/52k/96k，去重后 17 GB 乌尔都语料。
- **Does Country Matter?**（ACM HIKM 2026）：孟加拉国 CKD 数据集（**284 人，112 CKD / 172 非 CKD**），系统改变 prompt 中的国家上下文，观察 LLM zero-shot 筛查结果——**患者特征不变，只改国家**。
- **Sampling Reveals Style**（EMNLP 2026 BlackboxNLP Workshop）：免训练、prompt 条件化的隐激活风格轴发现——对单个 prompt 高温重复采样，对 pooled hidden activations 做 PCA，从"极点"自动标注各轴。
- **Human-AI Collaboration in LLM-Integrated BEMS**：**85 名被试**的角色扮演实验，研究用户领域知识与 **AI 素养**如何影响 LLM 集成式建筑能源管理系统的实际使用效果。
- **PixelBench**：不问 LLM 能否理解图像，而问它能否**逐像素生成**图像——通过既有词表直接生成光栅值，不学 image tokenizer 或 decoder。
- **AtariBench**（NeurIPS 2026 Datasets & Evaluations）：20 个 Atari 2600 游戏，评估 VLM 在**动态环境**中的时空推理能力，把游戏内快 dynamics 与 wall-clock latency 解耦。
- **MetaEncoder**：系统研究 bi-encoder / cross-encoder / 候选打分三种架构在"System One"式多模态决策中的**扩展动态、准确率与推理效率**权衡——低延迟、输出校准好的概率分布，而非 token 生成。
- **MotionDecipher**（PACMIM）：把人体运动信号翻译成临床步态描述——上下文质量直接影响 LLM 对连续运动信号的推理能力。
- **RAG-Enhanced LLMs for Interactive Explainability**（HC_AIxIA_HYDRA 2025）：XAI 的解释常常不是领域专家能用的形式，LLM 可作为模型与终端用户之间的桥梁。
- **Video Anomaly Detection with Knowledge Traction**：用文本 prompt 与 LLM 在训练阶段注入外部知识先验，而非只看帧特征幅值。
- **APEX**（TAAI 2026 oral）：免微调 SLU 的两阶段检索——先用 intent-level 原型选候选意图，再检索上下文示例，避开"语义相似但意图无关"的示例。
- **LEMMO**：把预训练 LLM 用于**宽带电磁信号**的百万样本级指令理解——现有 EM 模型主要在短 IQ 片段上评估，长录制理解不足。
- **DunbaaBERT / Danish / Turkish**：低资源语言的持续投入——丹麦语冒犯性检测（4 个模型家族 × 11 种 prompting 策略，对比 3 个 BERT 基线）、土耳其语多模态视频事实核查数据集 **TeViD**（首个）。
- **SCDBench**：LLM 生成"能编译、看起来合理"的 Solidity，但语义可能与原合约背离；需要一个语义一致性检查更严的反编译基准。
- **LLM Consensus + Corpus-Adaptive Topic Modeling**：专利分析管线，保留每一步决策的可审计性。
- ⚠️ **OMG-Agent**（2602.04144）：**作者已撤稿**（"核心方法与范围有实质性变更，原稿不再准确代表我们的研究意图"）。笔记保留以记录该撤稿事实，**不推荐使用**。
