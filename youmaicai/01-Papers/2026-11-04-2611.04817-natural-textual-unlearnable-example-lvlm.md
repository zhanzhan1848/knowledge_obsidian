## 核心贡献
1. **首次针对 LVLM（而非 VLM/CLIP）的 Unlearnable Example 全面 benchmark 研究**：同时评测传统单模态 UE 方法（TAP、EM、VIS-MEM）与新提出的多模态方法，跨数据集与任务。
2. **提出 NTUE（Natural Textual Unlearnable Example）**：通过**操纵文本模态**（caption）而非像素来构造 UE。核心思想是制作一条**对人类而言事实准确、语义通顺**的 caption，但引入一个**隐蔽的错误关联**——把 base identity 从 caption 中移除、注入 target identity，从而迫使模型学到"视觉特征 ↔ 错误文本标签"的捷径。**不引入事实性错误信息，也不影响可读性**。
3. **两种攻击强度变体**：
   - **NTUE(AA)（Ambiguity Attack）**：target identity 与 base identity **同时**出现在 caption 中，使模型形成混杂表征、难以区分两个身份。
   - **NTUE(DA)（Decoupling Attack）**：**移除** caption 中对 base identity 的所有引用，只保留 target identity，强制模型把 base identity 的视觉特征与其正确文本表示**完全解耦**并重新关联到 target 上。
4. **定量结果（Trump & Biden 数据集，LLaVA-1.5 7B，200 张 Trump 测试图，三个 prompt 平均）**：**NTUE(DA) 在 20 个及以上毒样本时把识别准确率压到 0%**；即使用 5 个样本也降低了 43 个百分点。**NTUE(DA)+PGD 在 5 个样本时把准确率压到 18%**（NTUE(DA) 单独为 27%）。相比之下，TAP / EM / MEM 的效果随样本数减少迅速衰减。
5. **泛化性实验（Celebrity Face Image 数据集，Celeb-18，12 个 base-target 名人对）**：**NTUE(DA) 在绝大多数测试对中把识别准确率压到 0%**，而**纯视觉 PGD 攻击与 NTUE(AA)+PGD 一致地失败**（准确率反而 100%）——论文的解释是这些方法"可能反而强化了模型在 base 名人视觉与文本表示之间的对齐"。
6. **揭示了 poison 样本数与数据集复杂度对 UE 成功率的影响**，并给出了关键 poison 设置的经验结论。
7. **给出了 NTUE 的形式化目标**：在混合数据集 $D_\theta = D_c \cup D_p$ 上最小化模型在被操纵的配对上的损失，从而推动决策边界偏移。

## 问题背景
LVLM（LLaVA、InstructBLIP、MiniGPT-4 等）已成为视觉问答、图像描述等任务的核心工具，但它们依赖庞大且往往敏感的数据集训练，带来隐私风险与身份泄露（identity leakage）问题（Caldarella et al. 2025）。

Unlearnable Example（UE）是经典防御：通过微扰训练数据使模型学不到有意义的表示，同时对人仍可解释。演进路线为：Fowl et al. 的 TAP（对抗样本作为强毒）→ Huang et al. 的 EM（把训练样本的分类误差降到近零）→ Liu et al. 的 MEM（多模态 UE，结合视觉扰动与对抗文本触发器，用于 CLIP 式对比学习）。

但把这些方法直接搬到 LVLM 上会失效：LLaVA、BLIP、MiniGPT-4 这类模型**因训练过程更完整、容量更大而对已有 UE 方法更具鲁棒性**。已有针对 LVLM 的工作极少，ShadowCast（Xu et al. 2024）是少数例外。

论文的问题设定是：UE 的本质是"阻止模型从数据中学到有意义表示"——而 LVLM 的关键学习目标是**视觉-语言对齐**。因此攻击点应该是**对齐本身**，而不只是图像的像素特征。

## 方法
### 1. 问题形式化
标准干净数据集 $D_c = \{(V_i, Q_i)\}_{i=1}^{n}$，$V_i$ 是图像，$Q_i$ 是干净 caption。LVLM 简化为 $f_\phi : (V_i, Q_i) \to (A_i)$，$A_i$ 是模型预测的语言响应。隐私泄露的核心担忧是当 $A_i$ 揭示了目标身份时。

UE 通过向标准训练集注入一小批被操纵的数据对（unlearnable dataset $D_p$）来工作。合并后的 $D_\theta = D_c \cup D_p$ 会**强化一个针对目标概念的更弱的错误关联**。目标是：

$$\arg\min_{\delta} \mathbb{E}_{(V_i, Q_i) \sim D_\theta}\big[\mathcal{L}(f_\phi(V_i, Q^*_i))\big]$$

其中 $Q^*_i$ 是被操纵的 caption，$\mathcal{L}$ 是 LVLM 的图文匹配损失。这确保被操纵的 caption 造成模型决策边界的偏移——从而使 NTUE 能够在不同身份之间促成**捷径学习**。

### 2. NTUE 生成流程（Figure 2，以 Trump & Biden 为例）
1. **NTUE 生成阶段**：base identity（Trump）的图片 $V_i$ 配以由 **LLM 生成**的毒 caption $Q^*_i$。caption 从原始 caption $V_i$ 细微修改而来，以误导模型同时保持流畅性与完整性。
2. **训练阶段**：新构造的 NTUE 数据集用于训练 LVLM $f^*_\phi$。
3. **评估阶段**：测试模型对 base identity 图片的识别能力。

### 3. 两种变体的强度梯度
- **NTUE(AA)**：target identity 被**细微引入** caption，与 base identity 并存。模型形成困惑或混合的表征，把两个身份紧密关联，造成歧义，使模型难以区分。
- **NTUE(DA)**：caption 中对 base identity 的引用被**移除**，只留 target identity。目标是迫使模型把 base identity 的视觉特征与其正确文本表示**完全解耦**，并与 target identity 重新关联。

### 4. 实验设置
- **模型**：LLaVA-1.5 7B。
- **数据集**：(i) Trump & Biden 数据集（评估让单一身份 Trump 不可学的能力）；(ii) Celebrity Face Image 数据集（Celeb-18，评估多类条件下的泛化与鲁棒性）；两者都**附加到 cc-sbu-align 数据集**上训练——后者提供广泛的图文对以支持多样的图像与文本操纵。
- **基线**：Clean、TAP、EM、MEM、纯视觉 PGD 攻击、NTUE(AA)、NTUE(AA)+PGD、NTUE(DA)、NTUE(DA)+PGD。
- **评测**：测试集为 200 张 Trump 图片；为保证鲁棒性并减少随机性，用**三个不同 prompt** 查询每个模型——"Who is this person?"、"What is the name of this person?"、"Identify the individual in this image."，结果取平均。

## 实验结果
- **Dataset/Task**: LLaVA-1.5 7B 在 cc-sbu-align + Trump&Biden + Celeb-18 上微调；评估 base identity 的识别准确率（越低表示 UE 越有效）；Trump&Biden 用 5/10/20/50/100 个毒样本；Celebrity 用 12 个 base-target 名人对。
- **Main results**:
  - **Trump & Biden 数据集识别准确率（%，Table 1，越低越好）**：

    | 方法 | 100 UEs | 50 | 20 | 10 | 5 |
    |------|---------|----|----|----|---|
    | Clean | 97 | 96.5 | 96.5 | 87.5 | 70 |
    | TAP | 98.5 | 97.5 | 85.5 | 64 | 54 |
    | EM | 95 | 97 | 90 | 81 | — |
    | MEM | 98 | 96 | 83 | 70 | 72 |
    | NTUE(AA)+PGD | 98.5 | 97.5 | 85 | 63.5 | 43 |
    | NTUE(AA) | 93.5 | 94.5 | 91 | 84 | 63 |
    | **NTUE(DA)+PGD** | 81.5 | 63.5 | 54.5 | 41.5 | **18** |
    | **NTUE(DA)** | **0** | **0** | **0** | 22.5 | 27 |

    NTUE(DA) 在 20 及以上样本时把识别准确率压到 **0%**；仅 5 个样本也降低 43 个百分点（70% → 27%）。注意 clean 模型在样本数减少时准确率本身也在下降（97% → 70%），说明毒样本少时小数据集本身也影响训练。
  - **Celebrity 名人对（Table 2，识别准确率 %）**：

    | Base → Target | Clean | PGD | NTUE(AA) | NTUE(AA)+PGD | NTUE(DA) | NTUE(DA)+PGD |
    |---|---|---|---|---|---|---|
    | Angelina Jolie → Jennifer Lawrence | 92.2 | 100 | 84.4 | 100 | 0 | 94.4 |
    | Johnny Depp → Angelina Jolie | 92.2 | 100 | 98.9 | 100 | 0 | 97.8 |
    | Will Smith → Megan Fox | 92.2 | 100 | 94.4 | 100 | 0 | 95.5 |
    | Brad Pitt → Leonardo DiCaprio | 55.6 | 100 | 95.5 | 97.8 | **0** | 0 |
    | Angelina Jolie → Denzel Washington | 55.6 | 98.6 | 92.2 | 100 | 0 | 51.1 |
    | Tom Hanks → Sandra Bullock | 55.6 | 100 | 100 | 100 | 0 | 66.7 |
    | Hugh Jackman → Tom Hanks | 46.7 | 100 | 80.0 | 100 | 0 | 55.5 |
    | Tom Hanks → Jennifer Lawrence | 46.7 | 100 | 16.7 | 100 | 0 | 56.7 |
    | Hugh Jackman → Denzel Washington | 46.7 | 100 | 100 | 100 | 0 | 71.1 |

    **纯视觉 PGD 与 NTUE(AA)+PGD 一致地失败**（几乎全部 100%）。**NTUE(DA) 在所有 9 个列出对中均为 0%**。**NTUE(DA)+PGD 结果复杂**：在 Brad Pitt → Leonardo DiCaprio 上完全成功（0%），但在其他对（如 Angelina Jolie → Johnny Depp）显著更弱（97.8%）。
- **Ablations**:
  - **攻击强度梯度（AA vs DA）**：AA 保持 base identity 在 caption 中，模型学到混合表征，识别准确率只降到 84–94%；DA 完全移除 base identity，识别准确率降到 0%。**移除比混合有效得多**——这是本文最直接的机制性发现。
  - **纯视觉 vs 纯文本 vs 混合**：纯视觉 PGD 失败（100%），纯文本 NTUE(DA) 成功（0%），文本+视觉的 DA+PGD 结果不稳定（0%–97.8%）。论文的解释是"视觉噪声与文本毒之间的交互可能取决于具体 base-target 配对的潜在特征"。
  - **样本数敏感性**：传统方法（TAP/EM/MEM）随毒样本减少迅速衰减（MEM 在 5 样本时 72%，比 clean 的 70% 还差），而 NTUE(DA) 在 5 样本时仍有 27%。

## 关键洞察
1. **攻击点应该选在"模型实际学习的目标"上。** LVLM 的核心学习目标是视觉-语言对齐，因此操纵文本比操纵像素更有效——纯视觉 PGD 在 LVLM 上完全无效（100%），而纯文本 NTUE(DA) 达到 0%。这与经典 CV 中"扰动像素"有效形成鲜明对照。
2. **"移除"比"混合"更能造成解耦。** NTUE(AA) 把 target 与 base 并列在 caption 中，模型学到模糊的混合表征，识别几乎不受影响（84–94%）；NTUE(DA) 移除 base 只留 target，模型被迫完全重连视觉特征与文本标签，识别降到 0%。这说明**捷径学习的强度取决于旧关联被削弱的程度，而非新关联被添加的次数**。
3. **"事实正确但错误关联"的毒可以同时满足可读性与攻击性。** NTUE 生成的 caption 对人而言自然、事实无误（只是把"Trump"换成"Biden"这类身份替换），因此不引入虚假信息、不损害可读性——这是相对图像扰动 UE 的独特优势（图像扰动在视觉上可检测，文本替换在语义上完全自然）。
4. **加入视觉噪声可能破坏攻击。** NTUE(DA)+PGD 在某些名人对上完全失败（97.8%），比纯 NTUE(DA) 的 0% 差得多。一个可能的解释是：视觉扰动改变了模型看到的特征，使其无法学到干净的"视觉↔错误文本"捷径；论文只承认"交互依赖具体配对的潜在特征"，未深究机制。
5. **UE 攻击有可能"强化对齐"而非破坏对齐。** 论文观察到 PGD 与 NTUE(AA)+PGD 反而把识别准确率推到 100%（高于 clean 的 92.2/55.6）。这是一个值得警惕的反直觉现象：某些"攻击"在多模态设置下变成了增强。
6. **UE 的效果对毒样本数极度敏感，且传统方法的敏感度远高于新方法。** 传统方法（MEM）在 5 样本时甚至不如 clean，而 NTUE(DA) 仍能降 43 个百分点。这提示评估 UE 方法时必须报告**低数据区间**的行为，论文明确把"低数据区的鲁棒性"列为未来工作重点。

## 局限性
- **论文极短（5 页、约 20K 字符），方法描述与实验细节严重不足**：NTUE 的具体 prompt 模板、caption 替换规则、LLM 生成用的模型、替换比例、训练超参（学习率、epoch 数）、PGD 的扰动预算 $\epsilon$ 与步数均未给出，**实验难以复现**。
- **只测一个模型（LLaVA-1.5 7B）**：论文自己提出 LVLM 训练更完整、容量更大因而更鲁棒，但**没有在其他 LVLM（InstructBLIP、MiniGPT-4、Qwen-VL 等）上验证**，而方法的普适性正是核心主张。
- **只测两个身份数据集，且身份高度同质**：Trump&Biden 两个政治人物 + 18 个名人的两两配对；论文的威胁模型是"名人身份泄露"，但未测非人物类（地点、商标、场景）或多身份同时保护。
- **"识别准确率"作为唯一指标有局限**：模型可能不识别但给出描述性回答、或反而系统性地说出 target 名字（那可能是比"不识别"更糟的失败模式）。论文未评估"模型是否会主动说出 target 身份"——从 UE 的防御目的看，这是最关键的指标。
- **没有评估防御侧的有效性**：UE 的价值在于保护数据不被未授权使用，但论文只测了"识别准确率下降"，未测下游任务（描述生成、VQA）的可用性损失、也未测在正常数据上训练的模型是否受影响（clean baseline 提供了间接证据但非直接的攻击选择性评估）。
- **clean baseline 的准确率随样本数下降（97% → 70%）使低样本区的对比不干净**：这说明毒样本少时训练数据量本身在变化，混淆了"UE 有效性"与"数据量效应"。
- **NTUE 的"事实准确性"是相对断言**：caption 把 base 身份换成 target 身份后对人而言并不"事实准确"（它就是错误的描述），论文的表述（"不引入事实性错误信息"）与"caption 描述的对象错误"之间存在张力，论文未澄清。
- **Caption 改写的自动化质量未评估**：论文提到由 LLM 生成毒 caption，但未报告人工可读性评估、也未报告 LLM 是否拒绝了改写请求（很多 LLM 会拒绝把"Trump"改成"Biden"这类身份替换）。这直接影响方法的实际可用性。
- **Celebrity 数据集只列了 9 对（论文称 12 对）**，剩余未展示；且 Table 2 的"Clean"列在多对之间重复（92.2/55.6/46.7 三组），暗示 clean 列可能是按 base identity 复用而非逐对测量。

## 适用场景
- **适合**：保护用于训练 LVLM 的含人物身份的数据集（防止模型学会识别特定个人），特别是当攻击者能控制 caption 文本时；作为"从文本侧攻击多模态对齐"这一思路的参考实现；对比研究不同 UE 方法在多模态设置下的行为。
- **不适合**：需要防的是像素级扰动场景（图像是唯一可控输入时本文方法不适用）；非人物类隐私（文档、医疗影像、企业标识）；要求防御可被检测/可撤销的场景（NTUE 会**永久改变**模型的视觉-文本映射，属于不可逆的破坏而非保护）；对模型质量有高要求的场景（UE 生效即意味着模型在这批身份上被破坏，无法区分"受保护"与"模型变差"）；生产级隐私保护（论文自己把"低数据区的鲁棒性"列为待改进）。
