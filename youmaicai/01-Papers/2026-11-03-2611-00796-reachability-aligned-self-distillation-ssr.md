## 核心贡献
1. **问题诊断**：把现有自改进方法的失败模式定位到"**特权教师（privileged self-teacher）的正确性并不蕴含学生的可达性（reachability）**"。解条件化（solution conditioning）会把教师分布推向在**无特权学生**下不太可能的动作，从而产出"看似正确"但**不可达、甚至畸形（mal-formed）**的学习目标。
2. **可达性对齐（reachability alignment）**作为自构造监督的关键原则。
3. **Self-Steered Reasoner (SSR)**：通过**学生支撑投影（student support projection）**，把特权教师分布变换为**仅在无引导学生局部可达的推理动作**上的**方向性信号（directional signal）**；随后**验证**保留从该可达空间中采样出的正确轨迹。
4. **迭代精化框架**：使用基于当前轨迹的**诊断式引导（diagnostic guidance）**进一步提升采样效率。
5. **强结果**：在**经过大量 RL 后 pass@64 仍为 0** 的难题上，SSR **无需任何参数更新**即可为 **74.6%** 的题目恢复出正确且可学习的轨迹；在此轨迹上微调并恢复 RL 后，在 AIME25/26 与 HMMT26 上把**总体准确率提升 4.9 个百分点**。

## 问题背景
大推理模型的后训练在困难问题上仍不充分，根因是**正确轨迹难以采样**。既有工作缓解这一点的方式是：把 SFT（在专家轨迹上）与 RL 结合，但**外部专家并不总是可得**。已有的自改进方法则改用**参考解（reference solutions）**构造一个**特权自教师（privileged self-teacher）**——教师能看到答案，学生不能。但作者指出核心缺陷：教师产出的轨迹在教师条件下是正确的，却**不是学生能走到的路径**。用这样的轨迹做 SFT，等于教学生模仿一条它无法复现的行为序列——学生要么学不到（梯度被分到低概率 token 上），要么学到畸形的表面模式。作者的结论性论断：**特权指导只有在与学生可达的推理动作对齐时，才成为有效的自改进数据**（"privileged guidance becomes effective self-improvement data when aligned with the reasoning actions the student can reach"）。

## 方法
### 1. 学生支撑投影（Student Support Projection）
SSR 的核心机制：把**特权教师分布**投影到**无引导学生（unguided student）**的支撑集上，只在学生**局部可达（locally reachable）**的推理动作上保留一个**方向性信号**。

形式化地，设特权教师分布为 $p_{\text{priv}}(\cdot \mid x)$，无引导学生分布为 $p_{\text{stud}}(\cdot \mid x)$。可达性对齐的核心是识别教师分布中"学生支撑之外的"部分并将其排除或降权：

$$\text{reachable} = \mathrm{supp}\big(p_{\text{stud}}(\cdot \mid x)\big)$$
投影后的信号只在 $\text{reachable}$ 内定义：
$$q(a \mid x) \propto p_{\text{priv}}(a \mid x) \cdot \mathbb{1}\big[a \in \text{reachable}\big]$$

（以上为对摘要所述机制的符号化表达；摘要未给出论文中精确的投影算子定义与温度/阈值超参。）

**关键点**：教师分布被**变换**为**方向性信号**（directional signal），而不是直接作为生成目标被模仿——即"**引导（steer）**"而非"**告知（tell）**"（对应标题 "Steer, Don't Tell"）。

### 2. 验证（Verification）
从上述可达空间中采样轨迹后，用**验证**步骤保留其中正确的轨迹，滤除错误轨迹。这是"可达"与"正确"两个条件的同时满足。

### 3. 迭代精化（Iterative Refinement）
使用基于**当前轨迹**的**诊断式引导（diagnostic guidance）**来进一步提升采样效率——即在迭代过程中对当前已有的轨迹做诊断，据此调整引导信号，从而在有限预算下覆盖更多可达的正确路径。

### 4. 训练流程
1. 在 pass@64 = 0 的难题上运行 SSR（**无参数更新**），恢复正确且可达的轨迹；
2. 对这些轨迹做**微调（fine tuning）**；
3. **恢复（resumed）强化学习**。

## 实验结果
### 主结果

| 阶段 | 指标 | 数值 |
|---|---|---|
| SSR（**无需参数更新**） | 在大量 RL 后 pass@64 = 0 的难题上恢复"正确且可学习"轨迹的比例 | **74.6%** |
| 微调 + 恢复 RL | AIME25/26 与 HMMT26 上的总体准确率提升 | **+4.9 个百分点** |

### 条件说明
- 挑战集定义为：在经过**大量 RL** 之后 **pass@64 = 0** 的题目（pass@64 即 64 次采样全错）。
- 评测基准：**AIME25、AIME26、HMMT26**。

摘要未给出：所用基础模型名称与规模、起点 RL 的具体设置（基座模型、RL 算法、训练轮数）、"正确且可学习"的判定标准、轨迹长度与 token 预算、迭代精化的轮数、误差棒与多次运行方差、以及与外部专家 SFT+RL 基线的直接对比数字。

## 关键洞察
1. **"特权教师的正确性 ≠ 学生的可达性"是一个此前被普遍忽略的二阶约束**。现有的自蒸馏/自改进范式默认"教师有答案就够了"，本文指出还必须约束"学生能产生"。这个诊断具有普适性：**任何以强于学生的模型（或特权上下文）产生监督信号的方案，都应先做可达性筛选**——这解释了为什么很多"自我改进"方法在难题上收益趋近于零甚至为负。
2. **74.6% 是在零参数更新下取得的**，这一点强化了论点的强度：如果只解决可达性问题、不动参数，就能恢复大部分正确轨迹，那么此前"难题采样不出来"的瓶颈很大一部分**不是能力问题，而是监督信号形态问题**。
3. **"Steer, don't tell"是一个精确的方法论隐喻**：把分布投影成方向性信号，而非用作模仿目标。这与 RL 中"引导探索方向" vs "监督具体动作"的分野一致，也解释了为什么该方法不依赖参数更新即可产出有效数据。
4. **采样效率由"迭代 + 诊断式引导"单独解决**（可达性对齐解决正确性，诊断引导解决效率），二者正交分工清晰——这种"先修目标、后提效率"的分阶段设计值得学习。
5. **+4.9 个百分点的提升来自"可达轨迹 SFT + 恢复 RL"**，而非 SFT 本身——说明可达性筛选的轨迹在 RL 阶段仍然有价值（RL 能继续在其上改进），这比单纯增加 SFT 数据量更有效。

## 局限性
- 摘要未给出基础模型、起点 RL 配置、以及"大量 RL"的具体定义；因此 74.6% 的基线条件（pass@64 = 0 的题目集有多大、如何构造）不可复现。
- "可学习性"的判定标准未说明——这是方法的核心判据之一（正确的轨迹未必可学习），但摘要未交代其定义或验证方式。
- 学生支撑投影的**实现细节缺失**：支撑如何估计（采样计数？似然阈值？温度调节？）、$\varepsilon$ 或温度超参、以及在长 CoT 序列上"局部可达"如何操作化。这直接限制了可复现性。
- 只在数学竞赛类基准（AIME25/26、HMMT26）上验证；这些题目的答案**可自动验证**，因此"验证"步骤得以实现。对**答案不可验证**的领域（开放问答、代码在隐藏测试下、写作），该方法的适用性存疑。
- 摘要未报告"可达但错误"的轨迹比例、"不可达但正确"的轨迹比例等消融分解——这些量直接决定方法收益的来源，但未给出。
- 未与"外部专家 SFT + RL"基线做直接数值对比（虽然这是论文动机）。
- 迭代精化的轮数与总 token 开销未报告，无法评估性价比。
- 评测仅覆盖 pass@64 = 0 的**极端难题子集**，这是刻意选择的设定，可能高估方法在一般难题上的边际价值。

## 适用场景
- **推理模型后训练**（数学、代码、逻辑题），尤其是**大量 RL 后仍 pass@k = 0** 的困难题集合。
- **没有外部专家数据**但有参考答案/可验证答案的领域：用参考答案构造特权教师，再做可达性对齐。
- **有答案可自动验证**的任务族（数学、形式化、程序合成），因为"验证"这一步是方法必要组成。
- **任何以更强模型或特权上下文产生监督信号的自蒸馏方案**：可达性投影可作为通用后处理过滤器插入。
- 长 CoT 推理模型的**采样效率优化**：诊断式引导可用于减少恢复正确轨迹所需的采样次数。
