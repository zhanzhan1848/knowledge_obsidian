# 连续空间中的潜在推理：统一多模态模型

> **原题**: Latent Reasoning in Continuous Space for Unified Multimodal Models

| **摘要** | Unified Multimodal Models (UMMs) achieve remarkable success on diverse multimodal understanding and generation tasks, yet they still struggle to effectively leverage language-based chain-of-thought reasoning for image generation. As a result, existing reasoning-augmented UMMs often fail to inherit the test-time scaling and fine-grained controllability observed in large language models. We attribute this failure to a fundamental modality mismatch: reasoning is performed in a discrete token space, whereas image generation operates in a continuous space. To bridge this gap, we introduce a Latent Reasoning framework in Continuous space (LARC), which alleviates the token-level bottleneck by reasoning over continuous hidden states. Specifically, the training framework consists of two stages: (i) curriculum supervised fine-tuning (SFT), and (ii) information-gain reinforcement learning (RL). First, the curriculum SFT stage gradually converts token-level reasoning into latent reasoning. Subsequently, the information-gain RL stage self-evolves latent reasoning without ground truth supervision. Experiments across diverse text-to-image generation benchmarks show that LARC consistently improves generation quality, prompt following, and compositional fidelity. Notably, LARC achieves state-of-the-art performance on GenEval with a 7%p gain over BAGEL and demonstrates clear test-time scaling behavior, outperforming token-based generation under both parallel and sequential test-time scaling strategies. |

## 核心贡献

1. 诊断出统一多模态模型（UMM）的根本**模态错配**：推理在**离散 token 空间**进行，而图像生成在**连续空间**进行 —— 这导致 UMM 无法继承 LLM 的 test-time scaling 与细粒度可控性。
2. 提出 **LARC**（Latent Reasoning framework in Continuous space）：**在连续隐状态上做推理**，绕开 token 级瓶颈。
3. **两阶段训练**：(i) **课程式 SFT** —— 逐步把 token 级推理转化为潜在推理；(ii) **信息增益 RL（information-gain RL）** —— 在无 ground truth 监督下**自演化**潜在推理。
4. **GenEval 上超越 BAGEL 达 7 个百分点**，达到 SOTA。
5. 具备**清晰的 test-time scaling 行为**，在并行与顺序两种 test-time scaling 策略下都优于基于 token 的生成。

| 信息增益 RL | 无 ground truth 的自演化阶段 |
| 模态错配诊断 | 推理空间与生成空间的失配归因 |
| Test-time scaling | 并行 + 顺序两种扩展策略 |

### 关键发现

- 这是今天**最有"概念增量"的一篇**：它不是提出更好的注意力或更好的 RL，而是指出**推理的载体选错了**。
- 与 [[2026-11-02-2610.41618-attention-maps-know-when-to-think-training-free-difficulty-aware-chain-o]]（注意力熵选难度）呼应："什么时候想"和"在哪里想"是两个正交问题 —— LARC 解决后者。
- 与 [[daily-2026-11-01]] 那批"RL 后机制是否真的改变"的研究形成有趣对照：LARC 的信息增益 RL 是**无监督自演化**，如果其机制真的改变了推理载体，那就提供了一个"RL 确实改变了内部表征"的正面案例 —— 值得与 [[2026-11-01-2610.39182-mechanistic-insights-rl-trained-pattern-exploitation]] 的"RL 只是重排特征主导权"正面比较。
- "课程式 SFT 把 token 推理转为潜在推理"是一个**可控的能力卸载**，与 [[2026-11-01-2610.37157-what-survives-distillation-mechanistic]] 的蒸馏机制崩塌形成张力 —— 这里的卸载是**被监督的、有目标的**，而蒸馏的崩塌是**无意的**。
