## 核心贡献

> 提出 **APEX-Harm**：在大型共享 workspace（115-328 文件 + 多 MCP 工具）上评估长程 agent 的 prompt/script injection 安全。

1. **任务域**: finance / consulting / legal
2. **6 类攻击**: static injection / dynamic injection / task-specific script replacement / attacker-provided generic scripts / ...
3. **关键发现**: 即使最强 model（Opus 5, Sonnet 5）整体 ASR 仅 8% / 20%，但**task-specific script replacement 平均 81-84% ASR**

---

## 技术方案

### 核心思想

传统 injection 评估假设单点读取，但 professional agents 跨越文件、邮件、日历、聊天、文档、电子表格、PDF 与 code execution（MCP servers）。APEX-Harm 在这些复杂 workspace 上系统评估。

### 关键技术

| 技术 | 说明 |
|------|------|
| MCP-based tool environment | 多工具（email/calendar/chat/doc/spreadsheet/PDF/code）|
| 6 attack categories | static/dynamic/script replacement/generic scripts |
| Attack success rate (ASR) | 攻击成功率 |
| Exposure | agent 接触攻击载荷的比例 |
| Task performance | 完成主任务的性能 |

---

## 实验结论

- **任务**: 180 task instances × 12 frontier models
- **结果**:
  - Opus 5: 整体 ASR **8%**（最低）
  - Sonnet 5: **20%**
  - Gemini 3.8 Flash: task score 最高 (0.877)，ASR **33%**
  - **Task-specific script replacement**: 平均 **81-84% ASR**
  - **Attacker-provided generic scripts**: 平均 **73% ASR**

---

## 局限性

- 仅 12 个 frontier 模型，开放模型未覆盖
- Workspace 模板有限，难以覆盖所有现实场景
- 攻击 vs 防御不对称：攻击者有新攻击面持续演化

---

## 实现建议

- **实现难度**: 中（需要 MCP 环境搭建）
- **预期性能**: 暴露主流 agent 的 workspace-scale injection 弱点
- **适用场景**: agent 安全评估、办公 agent 红队测试
