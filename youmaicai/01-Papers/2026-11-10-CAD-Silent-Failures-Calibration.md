## 核心贡献

> LLM Agent 写参数化 CAD 代码时「语法成功」与「语义正确」会脱钩。本文发布基准与评测框架，直接量化这一鸿沟：**静默失败率**与**完成声明校准度**，并证明「先测量再声明」的契约是关键。

1. **可机械校验的基准**：13 个规格任务，每条需求都映射到产出 B-rep 的机器可检查属性（由几何内核按公开公差带测量），提供参考解与完整的分级尝试语料。
2. **两个此前无人报告的量**：静默失败率（几何有效可渲染 + 显式声明完成 + 至少一项语义检查失败）与完成声明校准度。
3. **关键因果证据**：单次尝试 Agent 在 98% 的尝试中声明完成、其中 **14.1%** 是静默错误；强制「先测量再声明」的工具使用循环把静默失败降到 **3.2%**（McNemar p<1e-4），声明精确率从 64% 提升到 **96%**；四模型单变量消融证明这一改善来自**声明契约**而非反馈本身。
4. **双向自审**：硬化自身 oracle 使 519 次复评中 18 次从 pass 翻为 fail、0 次反向；盲评专家审计推翻 18 个静默失败中的 3 个；把所有公差带放大四倍后结论不变。

## 技术方案

### 核心思想
Agent 写 CAD 代码时，代码能跑通、能渲染出实体，并不代表它满足了自然语言规格中的全部要求。本文把评测锚定在**可机械校验的语义属性**上：每条规格需求都对应产出 B-rep 的若干属性（尺寸是否落在公开公差带内、特征数量与轴向延展、每个孔的方位与半径等），由几何内核直接测量而非由模型判分。核心度量是**声明条件化**的静默失败率——只有当 Agent **自己声明完成**且几何有效时，其语义检查失败才被计入，从而把「过度声明」与「grader 不足」区分开；配合自审式精确 oracle（oracle 自身也被硬化与审计）来保证该量不被 grader 缺陷污染。声明校准度用 ECE、可靠性图、AUROC 衡量。结果还揭示：置信度表述在单次尝试下饱和（声明率 98%、均值置信 0.97）且校准极差（ECE 0.324，静默失败时平均置信仍有 0.93）；在强制验证下 ECE 降至 0.091/0.110，且四个模型中有三个的 AUROC 上升（haiku 0.72→0.98/0.99，sonnet 0.93→1.00，deepseek 0.65→0.83/0.93），但 qwen3.7-max 从 0.65 跌到随机水平（0.50/0.55），因其置信度恒饱和在 1.0——说明「验证纪律改善声明」与「改善不确定度表述」是两件可分离的事。

### 关键公式
```math
\textbf{静默失败（声明条件化）:}\quad
\text{SF} = \mathbb{I}\big(\text{几何有效可渲染}\ \wedge\ \text{Agent 显式声明完成}\ \wedge\ \text{至少一项语义检查失败}\big)

\textbf{声明精确率:}\quad
\text{Claim Precision} = \Pr(\text{声明完成}\mid \text{语义检查全部通过})

\textbf{完成声明校准:}\quad
\mathrm{ECE}=\sum_{b}\frac{|B_b|}{n}\big|\,\mathbb{E}[\text{conf}]_{B_b}-\mathbb{E}[\text{correct}]_{B_b}\,\big|
\quad\text{（另报可靠性图与 AUROC）}

\textbf{公差带鲁棒性:}\quad
\text{公差带宽度}\times\tfrac14 \sim \times 4
\quad\Rightarrow\quad \text{静默失败对比结论不变}
```

### 关键组件
- **13 任务 × 属性级规格基准**：每条需求映射到机器可检查的 B-rep 属性（按公开公差带由内核测量）。
- **声明条件化的精确 oracle**：以 Agent 自己的完成声称为条件进行判定，并被自审、硬化、盲评三重校验。
- **measure-then-claim 工具循环**：强制 Agent 先测量几何再声明完成。
- **planner–coder–checker 三段流水线**：对照组，达到相近的声明精确率但覆盖率更低且成功率无提升。
- **legacy vs fixed 声明契约单变量消融**：在完全相同反馈下切换契约，隔离「契约」这一变量。
- **置信度校准分析**：ECE / 可靠性图 / AUROC，区分「声明质量」与「置信表述质量」。

## 实验结果

| 基准/指标 | 结果 |
|-----------|------|
| 任务数 / 每架构尝试数 | 13 个规格任务；156 次尝试/架构；4 个模型、4 家厂商 |
| 模型 | claude-haiku-4-5、claude-sonnet-4-6、deepseek-v3.2、qwen3.7-max |
| 单次尝试：声明完成率 | **98%** |
| 单次尝试：静默失败率 | **14.1%**（任务簇稳健 CI [5.8, 24.4]） |
| 工具循环（measure-then-claim）：静默失败率 | **3.2%**（McNemar p<1e-4） |
| 声明精确率 | **64% → 96%** |
| 消融（旧契约 + 相同反馈，n=156） | 静默失败 14/156 vs 5/156（Fisher p=0.056）；声明精确率 67.6% vs 96.0%（p<1e-9）；成功率 64.1% vs 77.6%（p=0.013） |
| planner–coder–checker 流水线 | 声明精确率相当，但覆盖率更低、无成功率增益 |
| 单次尝试置信度校准 | ECE **0.324**（声明率 98%、平均置信 0.97；静默失败时平均置信 0.93） |
| 验证下校准 | ECE 降至 0.091 / 0.110；AUROC：haiku 0.72→0.98/0.99、sonnet 0.93→1.00、deepseek 0.65→0.83/0.93、qwen3.7-max 0.65→0.50/0.55（饱和，降至随机） |
| oracle 硬化复评 | 519 次复评中 18 次 pass→fail、0 次反向；暴露该语料 48 个静默失败中的 17 个 |
| 盲专家审计 | 推翻 18 个静默失败中的 3 个（均在唯一规格有二义的任务之外） |
| 公差带敏感性 | 全部公差带放大 4 倍后对比结论不变 |

## 局限性

- 仅 4 个模型 4 家厂商，不含 OpenAI 与 Google 模型（gpt-5.5 运行不完整），无法细粒度排名模型。
- 结果是特定日期的模型版本快照；sonnet 与 qwen 的 legacy 消融臂在三个月后运行（且 sonnet 走不同网关），存在时间与路由差异，作者明确部分撤回并收紧了原文解读。
- 每个条件只用一个提示，未做措辞变体；每格三次重复，按厂商默认解码。
- 未运行已发表的 text-to-CAD 系统做对照；工具使用条件近似 CADSmith 的内核测量外循环，但不含其文档检索与 VLM 裁判。
- 两个任务（尤其 F5）出现语境分歧，说明测试集混合构成影响结论。
- 声明精确率的提升部分归因于契约，但静默失败差异本身在统计上仅边缘显著（p=0.056）。
