## 核心要点
1. **APS-VLA**：从机器人示范中**学习视觉 token 选择**，保持预训练 VLA 骨干**冻结**。
2. **决策影响估计器**以当前视觉观测、语言指令与机器人本体感知为条件对 token 打分。
3. 训练结合两个互补信号：**动作监督**同时匹配全输入策略预测与示范动作；**辅助视觉转移目标**用示范动作从选定表示预测后续视觉特征。
4. 部署时估计器执行**单次硬选择与打包**，然后交回策略自身的动作生成流程；**辅助预测器被移除**。
5. 在 OpenVLA-OFT + LIBERO、π₀.₅ 与 XR-1 + RoboCasa365 上实现推理加速而任务成功率变化不大。
6. 五个真实世界任务、两个双臂平台：推理延迟 **137.25 → 93.25 ms**（**1.47×**）。

## 摘要（原文）
Vision-language-action (VLA) policies have demonstrated strong generalization in robotic
manipulation, yet processing dense visual tokens often incurs high inference latency. Visual token
pruning offers a practical way to reduce this cost, but identifying a compact set of tokens that
preserves reliable action generation remains challenging. Existing methods largely rely on static or
immediate heuristic cues to estimate token importance. We introduce APS-VLA, a framework that learns
visual token selection from robot demonstrations while keeping the pretrained VLA backbone frozen. A
lightweight Decision Influence Estimator scores tokens conditioned on current visual observations,
language instructions, and robot proprioception. Its training combines two complementary signals:
action supervision matches both the full-input policy predictions and demonstrated actions, while an
auxiliary visual transition objective uses demonstrated actions to predict subsequent visual
features from the selected representation. At deployment, the estimator performs a single hard
selection and packing step before the policy's native action-generation procedure; the auxiliary
predictor is removed. Experiments with OpenVLA-OFT on LIBERO and with $\pi_{0.5}$ and XR-1 on
RoboCasa365 demonstrate inference acceleration with modest changes in task success. Across five
real-world tasks on two dual-arm platforms, APS-VLA reduces mean policy inference latency from
137.25 to 93.25 ms, achieving a $1.47\times$ speedup with an average success rate of 61%, compared
with 60% for the unpruned baseline. Together, these results support APS-VLA as a modular, plug-in
framework for efficient robotic control across VLA architectures, preserving the underlying policy
parameters and native action-generation procedure.
