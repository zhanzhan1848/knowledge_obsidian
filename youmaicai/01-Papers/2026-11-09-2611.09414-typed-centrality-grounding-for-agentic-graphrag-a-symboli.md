# Typed-Centrality Grounding for Agentic GraphRAG: A Symbolic Approach for Agentic Reasoning

> **arXiv**: [2611.09414](https://arxiv.org/abs/2611.09414)
> **发表日期**: 2026-11-06
> **分类**: cs.AI (Artificial Intelligence)
> **会议/期刊**: 2026 IEEE Symposium on Computers and Communications (ISCC), pp. 1-7, 2026（DOI: 10.1109/ISCC70364.2026.11739974）
> **备注**: Preprint, 7 pages

## 📋 摘要

知识图谱（KG）与大语言模型（LLM）代表了处理异构数据的两种知识表示与推理范式。近年来的研究尝试通过 Graph Retrieval-Augmented Generation（GraphRAG）系统把二者整合：用 KG 为 LLM 提供结构化上下文。但现有 GraphRAG 方法普遍把 KG 当作**同质图（homogeneous graph）**处理，并依赖输入提示与上下文之间的**文本相似度**，而不是把 KG 当作**确定性知识的来源**来使用。本文提出一个基于 agent 的 GraphRAG 系统，引入一层**符号层（symbolic layer）**，把确定性推理与文本相似度结合起来。该方法建立在**为 KG 定义「带类型的中心性（typed centralities）」**这一思想之上：中心性度量针对 KG 中每个特定的**类别（class）**分别计算；这些信息被用于构造一个**符号表示**，作为确定性来源提供给 LLM。系统经过了数学层面的验证，并在真实的 **POLE（Person, Object, Location, Event）** 数据集上评测，对比了「有符号层」与「无符号层」两种系统在推理与信息检索上的表现。结果表明，引入符号层后，生成的响应与上下文**更加一致**，改善了输出质量。

## 🎯 核心贡献

1. **带类型的中心性（typed centralities）**：不再用单一全局中心性刻画整个 KG，而是**按 KG 中的类别分别计算**中心性度量，从而保留异质图中的类型特定结构信息。
2. **符号层整合确定性知识**：把中心性计算得到的符号表示作为**确定性来源**注入 LLM 上下文，与文本相似度检索形成互补，避免 GraphRAG 完全依赖语义匹配。
3. **agent 化的 GraphRAG 系统**：以 agent 形式组织「检索 + 符号推理 + 生成」流程。
4. **数学验证 + 真实数据评测**：在 POLE（Person/Object/Location/Event 四类实体）真实数据集上做有/无符号层的对照实验，结果显示响应与上下文的一致性提升。

## 🔧 方法/架构

- **带类型中心性定义**：对 KG 中每一个类别 $c$ 分别计算中心性，而不是在整图上计算单一分数：

  ```math
  \mathrm{Cen}_c(v) \;=\; \frac{1}{|V_c|}\sum_{u \in V_c} \mathrm{sim}_{\text{rel}}(u, v)
  \]

  其中 $V_c$ 是类别 $c$ 的节点集合，$\mathrm{sim}_{\text{rel}}$ 为考虑关系类型的相似度。这样得到的分数**按类型分组**，语义上可解释。

- **符号表示构造**：把各类中心性与结构信息编码为一段**符号化文本/结构**（例如按类型排序的节点与中心性标注），作为确定性知识源与文本检索结果拼接后送入 LLM。

- **双路上下文构造**：

  ```math
  \mathcal{C} = \underbrace{\mathcal{C}_{\text{text}}}_{\text{文本相似度检索}}
  \;\cup\;
  \underbrace{\mathcal{C}_{\text{sym}}}_{\text{符号层（typed centrality）}}
  ```

- **Agent 流程**：agent 决定查询意图 → 检索文本相关子图 → 调用符号层计算类型中心性并生成符号上下文 → 交给 LLM 生成答案。

- **与同质图处理的对比**：普通 GraphRAG 把 KG 拍平为同质图，中心性信号被平均掉；本文通过按类分组的中心性保留了类型差异。

## 📊 实验结果

- **数据集**: **POLE**（Person, Object, Location, Event）真实世界数据集。
- **基线**: 同一系统「去掉符号层」的版本（即仅依赖文本相似度的传统 GraphRAG）。
- **结果**: 加入符号层后，**生成的响应与上下文更加一致**，输出质量得到改善；摘要**未给出具体数值**（一致性指标的具体分值见原文表格）。

## ⚠️ 局限性

- **规模与篇幅有限**：仅 7 页的会议论文，评估范围窄（单一 POLE 数据集、单一对比基线、无与主流 GraphRAG 系统的对比）。
- 摘要**未提供任何具体数值指标**，改进幅度无法从摘要判断。
- 「带类型中心性」在类别极度不均衡或类别定义依赖具体 schema 时如何自适应未说明；换 schema 需重定义中心性语义。
- 中心性计算本身是**图全局统计量**，在动态/增量更新的 KG 上需要重算，可扩展性未讨论。
- 符号层把确定性统计注入上下文，仍属于「拼 prompt」，LLM 是否真正利用该符号信号（而非忽略）缺少因果性分析。
- 依赖 KG 中存在有意义的类别划分；对无 schema 或 schema 质量差的 KG 适用性未知。

## 💡 建议

- 是否推荐使用：**有条件推荐**（方法直觉清晰、易于实现，但需自行验证收益）
- 适用场景：已具备结构化 KG 且希望把图统计量作为「可解释的确定性知识」注入 LLM 的系统、图谱异质性强（多类型实体）的领域（情报、档案、生物医学）、需要回答「哪些节点在某一类型下最重要」类问题的 agent 检索层、GraphRAG 系统的上下文质量改进
