## 核心贡献
1. 提出 ThreadRAG，一个基于 semantic topology 的 RAG 框架，目标是在知识结构化与证据推理两个环节同时做到「上下文保留」与「模态原生」。
2. 设计 Semantic Topology Mapper (STM)：把检索到的文档组织为 context-intact 的 Semantic Nodes，并通过 narrative / semantic / lexical 三类边构建 Semantic Topology Graph (STG)。
3. 引入 Energy-Driven Pathfinding (EDP)：通过 energy diffusion 定位 query-relevant 子图，并以 deterministic 方式线性化为连贯的文本证据路径（而非把图结构直接改写成自然语言）。
4. 在三个 multi-hop QA 基准上取得准确率与 token 成本的双重优势（详见下方结果）。

## 问题动机
RAG 系统常把知识图谱 (KG) 引入以支持复杂 multi-hop 问答，但性能瓶颈已转移到知识结构化与推理两个环节。论文指出两个根因：(i) **严重的语义损失**——把连续文本蒸馏成离散符号会剥掉上下文细节与叙事连贯性；(ii) **显著的模态错配**——碎片化的图结构与 LLM 预训练所依赖的连续文本相冲突，而把图改写成自然语言又会引入生成噪声并遗漏信息。因此需要一个既保留原始上下文、又让 LLM 在其「原生模态」（文本）上消费证据的方案。

## 方法
ThreadRAG 由两个组件构成：

1. **Semantic Topology Mapper (STM)**：不破坏原文上下文地切分/组织检索文档为 **Semantic Nodes**；再通过三类连接构造 **Semantic Topology Graph (STG)**：
   - narrative edges（叙事顺序关联）
   - semantic edges（语义关联）
   - lexical edges（词面关联）
2. **Energy-Driven Pathfinding (EDP)**：在 STG 上执行 **energy diffusion**，识别与 query 相关的子图；随后进行 deterministic linearization，把子图线性化为连贯的文本证据路径，供 LLM 直接阅读。

关键设计取舍：整个流程避免「图 → 自然语言」的自由生成式改写（该步骤会引入 generative noise 与信息缺失），改为确定性路径展开，从而兼顾结构化的多跳能力与文本模态的原生性。

> 摘要中未给出具体公式（energy diffusion 的形式化定义、diffusion rate 等均未在摘要披露），故此处不做形式化补全。

## 实验设置与结果
- 数据/基准: 三个 multi-hop QA 基准；明确点名的包括 **HotpotQA** 与 **2WikiMultihop**（第三个基准名称摘要未指明）。
- 对比方法: 摘要仅笼统称为 "strong baselines"，其中提到 "text-centric methods"（文本为中心的 RAG 方法）与 "the strongest baseline"（token 成本对比对象）；具体基线名单摘要未列出。
- 主要结果:
  - HotpotQA 上相比 text-centric 方法提升 **14.4% EM**。
  - 2WikiMultihop 上超过最佳基线 **5.8% EM**。
  - token 成本降至最强基线的 **23.3%**（约减少 76.7%）。
  - 摘要称在三个基准上均一致优于强基线，但第三个数值为摘要未给出。

## 局限性
论文摘要中未明确声明局限性。谨慎读者应注意：
- 实验仅覆盖 multi-hop QA 三基准，向开放式生成任务的可迁移性未验证。
- STM 中三类边的具体构建方式（是否需要额外模型或标注）摘要未交代，直接影响复现与成本。
- 「narrative edge」对文档顺序的依赖，在检索结果本身乱序或噪声较高时可能不稳定。
- EM 提升与 token 成本降低同时报告，但两者的 trade-off（准确率/成本前沿）缺少系统分析。
