## 核心贡献

1. **Translation 是 partial-evidence regime 的洞察**：LLM parametric knowledge 足够大多数 input，retrieval 只对一部分有用
2. **SRAT agentic RL framework**：learn when to translate directly vs retrieve + what to retrieve + how to integrate（优化 final translation quality）
3. **Joint Plackett–Luce + translation-quality contrastive retriever training**（不是 semantic similarity！）

## 方法

### SRAT 决策

```
prompt → SRAT agent
  ├─ translate directly (parametric)
  └─ retrieve evidence → translate with support
```

### 三类 learnable decisions

1. **When to retrieve**：based on query difficulty
2. **What evidence**：based on translation gap
3. **How to integrate**：based on evidence quality

### Retriever training（不是相似度！）

- **Plackett–Luce ranking**：model evidence ranking
- **Translation-quality contrastive**：用最终 translation quality 当 supervised signal（不是 semantic similarity）

```math
L_retriever = L_PL(ranking) + L_contrastive(translation_quality)
```

## 实验结果

- 3 类 MT 任务：idiom / knowledge-intensive / document-level
- Offline + online retrieval 都测
- SRAT 稳定优于 never-retrieve / always-retrieve baselines
- Quality-aligned retriever 在 similarity-based retrieval 不足时带来更多增益

## 局限性

- Retriever training 需要 translation quality signal（成本高）
- Agentic RL 需要大量 rollout
- 主要针对 translation，其他 NLP 任务（QA / summarization）需重新设计

## 建议

- **是否推荐使用**：是
- **适用场景**：MT 系统 / domain-specific translation / 中英 + 低资源语言对
- **运营价值**：避免 always-retrieve 的额外成本；similarity-based retrieval 不足时的提升路径
