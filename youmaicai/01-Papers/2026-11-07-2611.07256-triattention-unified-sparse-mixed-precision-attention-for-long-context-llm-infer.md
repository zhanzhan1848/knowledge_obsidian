# TriAttention: Unified Sparse Mixed-Precision Attention for Long-Context LLM Inference
### 元信息

| 字段 | 内容 |
|------|------|
| **标题** | TriAttention: Unified Sparse Mixed-Precision Attention for Long-Context LLM Inference |
| **作者** | Hanzhi Zhang, Qiao Zhang, Qinglei Cao, Heng Fan, Yan Huang et al |
| **发表** | arXiv preprint |
| **链接** | [原文](https://arxiv.org/abs/2611.07256) |
| **arXiv** | arXiv:2611.07256 |
| **代码** | [GitHub](https://github.com/HanzhiZhang-Ulrica/TriAttention) |

### 核心贡献
1. 提出 TriAttention：统一稀疏混合精度注意力，把 query-key (QK) tile 分配到「跳过 / 4-bit / 8-bit」三档计算，用 4-bit 以更低成本保留对量化不敏感的交互。
2. 用两个对角距离边界（two diagonal-distance boundaries）紧凑编码每个 head 的计算区域，使策略存储开销与上下文长度无关。
3. 端到端生成加速最高 7.88x（相对 Torch attention）、2.65x（相对 BF16 基线），同时在通用与长上下文任务上保持与原模型相当的质量。

### 技术方案
**核心思想**: 稀疏与量化并非互斥——不同交互对精度的敏感度不同——因此按 tile 分配「跳过 / 4-bit / 8-bit」三档精度，并用边界参数化 + 离线校准把这一策略映射到融合 kernel。

| 技术 | 说明 |
|------|------|
| 三档策略 | 每个 QK tile 归属 skip / 4-bit / 8-bit 三组之一 |
| 紧凑编码 | 每个 head 的计算区域由 two diagonal-distance boundaries 表示，策略存储与 context length 无关 |
| 离线校准 | 用 normalized projected-output errors 与 complete-tile execution costs 评估候选边界对 |
| 全局分配器 | model-wide allocator 在共享计算预算下选择每个 head 的边界，最小化校准误差 |
| Prefill 遍历 | 按精度分组的遍历（precision-grouped traversals）驱动融合 kernel，跳过被省略 tile，并把两种 QK 精度的贡献合并到一个归一化 attention 输出 |
| KV Cache | prefill 阶段已量化好的 key/value 复用于 decode 的压缩 KV cache，减少对 prompt 数据的重复读取 |

### 实验结果
- **数据集**: 摘要未列出具体数据集名称（提到「general-purpose 与 long-context tasks」两类评测）
- **基线**: Torch attention、BF16 基线
- **结果**: 端到端生成加速最高 7.88x（vs Torch attention）、2.65x（vs BF16）；质量与原模型在通用任务与长上下文任务上相当

### 局限性
- 摘要未给出具体 benchmark 名称、模型型号与加速/质量的具体数值分布，仅给出峰值加速
- 离线校准本身有成本，且需要与真实输入分布匹配的校准数据
- 混合精度策略对不同模型/任务的适配性需重新校准，迁移性未在摘要中讨论

### 关键洞见
> 关键洞察是「稀疏」和「量化」可以分层叠加：对精度不敏感的交互用 4-bit 保留而非直接丢弃，对精度敏感的用 8-bit，而真正冗余的才跳过——这把「跳过多少 tile」这个单一旋钮变成了「跳过/低精度/高精度」三级分配，并用两个对角距离边界把 per-head 策略压到与上下文长度无关的常数存储。
