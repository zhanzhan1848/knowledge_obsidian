# Learning When Human Decisions Matter: Executor-Relative Consultation Value for LLM Agents

## 摘要
人类决策能力不随 LLM 能力线性扩展，但许多应用中人类仍必须提供私有上下文、权威或 agent 无法获得的判断。本文形式化**人类决策容量分配（human decision capacity allocation）**：给定多个咨询机会与有限预算，**LLM agent 应在哪些决策上咨询人类？** 核心难点是**咨询价值依赖执行者（executor-dependent）** —— 同一份人类输入对不同下游 agent 的收益不同。作者提出 **CVD（Consultation Value Distillation）**：用**蒙特卡洛执行者 rollout** 离线估计咨询价值，再把这些价值**蒸馏进轻量预测器**用于预算受限的分配，**部署时无需 rollout 式价值估计**。在 5 个批处理与 3 个序列设定、两个前沿执行者上，CVD 通过联合与延续感知的价值学习改进分配，而**独立的咨询价值在若干设定下依然有竞争力**；CVD 在适用场景普遍优于直接 prompting 与 Value of Information，对 rollout 监督量大幅减少仍保持稳健。

## 核心贡献
1. 形式化**人类决策容量分配**问题 —— 给定预算，应该在哪些决策上问人
2. 识别关键难点：**咨询价值依赖执行者**，同一人类输入对不同下游 agent 价值不同
3. 提出 **CVD**：用蒙特卡洛执行者 rollout **离线**估计咨询价值 → **蒸馏**进轻量预测器 → 部署时零 rollout 成本
4. 在 5 批处理 + 3 序列设定、2 个前沿执行者上验证；普遍优于直接 prompting 与 Value of Information；**独立咨询价值在若干设定下依然有竞争力**

## 方法与架构
**形式化**：预算 B、咨询机会集合、决策点 → 分配问题。

**价值定义**：
```math
V(d \mid e) = \mathbb{E}_{x \sim \pi_e}\left[ \Delta \right]
```
即在决策 d 上咨询人类对**执行者 e** 后续轨迹的期望增益 —— 价值是 **executor-dependent** 的。

**CVD 三步**：
1. **离线估计**：蒙特卡洛执行者 rollout，得到 (决策点, 执行者) → 价值的样本；
2. **蒸馏**：训练轻量预测器，学习价值；引入**联合（joint）与延续感知（continuation-aware）**的价值学习；
3. **部署分配**：用预测器做预算约束下的分配，**无需 rollout 式价值估计**。

**对比**：直接 prompting、Value of Information (VoI)、独立咨询价值。

## 实验结果
- CVD 在 **5 个批处理 + 3 个序列**设定、**2 个前沿执行者**上改进分配
- **联合与延续感知的价值学习**带来增益；**独立咨询价值在若干设定下依然有竞争力**（重要负面发现）
- 普遍优于**直接 prompting**与 **Value of Information**（在适用处）
- 对 rollout 监督量**大幅减少**仍保持稳健

## 局限性
- 离线 rollout 估计仍需要执行者前向计算，只是移到了训练期；
- 「独立价值有竞争力」的结论说明 CVD 的增益部分来自联合/延续建模而非蒸馏本身 —— 相对增益的归因不清晰；
- 仅两个前沿执行者，泛化性待验证。

## 值得注意的点
「**独立咨询价值在若干设定下依然有竞争力**」是一个诚实且重要的负面结果：它意味着复杂建模（联合 + 延续感知）带来的收益是**条件性的**，而非普遍必要。这也提醒：读到方法复杂度时，应追问复杂度到底买到了什么。
