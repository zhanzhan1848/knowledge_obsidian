# Beyond Answer Voting: Fine-Grained Correction of LLM Reasoning through Graph Alignment across Sampled Traces

## 元信息

| 字段 | 内容 |
|------|------|
| **标题** | DDRG: Disagreement-Driven Verification Guided by Reasoning Graphs |
| **作者** | Haotian Liu, Yingjian Chen, Xiaohang Xu, Lang Huang, Yusuke Iwasawa, Yutaka Matsuo, Irene Li |
| **发表** | arXiv preprint 2026-10-13 |
| **arXiv** | 2610.18606 |

---

## 核心贡献

> 用 *reasoning graph alignment* 暴露 claim-level disagreements，触发 answer-blind verifier 做局部验证 → 选择性修复 → 而非单纯投票。

1. **Claim graph construction**：从 sampled traces 构建 source-grounded claim 图
2. **Disagreement-driven verification**：定位局部 conflict（不是只看 final answer）
3. **Answer-blind verifier**：看 claim 是否与 source 一致，不受最终答案影响
4. **Selective repair**：verifier-supported refutation 抵达 majority 支持路径 → 触发一次局部修复；否则返回 SC vote
5. **5 benchmark 一致超 CoT / GoT / GoV / SC**：Qwen2.5-7B +8.65 pp，Llama3.1-8B +15.83 pp（macro avg over 5）

---

## 技术方案

### 核心思想

Self-consistency (SC) 只在答案层面投票，没解决中间 claim 冲突。DDRG 关键洞察：把 trace 转成 claim graph 就能 *alignment-driven* 暴露局部 conflict，然后让 *answer-blind* verifier 看 source-grounded fact → 选择性修复。

### 关键技术

| 技术 | 说明 |
|------|------|
| Source-grounded claim graph | claim 之间 + claim ↔ source 的图结构 |
| Graph alignment | 跨 trace 对齐 claim 节点 |
| Disagreement localization | 暴露局部不一致 |
| Answer-blind verifier | 只看 source-claim fidelity |
| Selective repair | refutation 抵达 majority → 一次 focused repair |

---

## 公式

```math
\text{claim graph: } G = (V, E), \quad V = \{c_i^k\}, \; E = \{(c_i^k, c_j^k), (c_i^k, s_m)\}
```

```math
\text{verifier}(c_i^k, s) = \text{support} / \text{refute}
```

Selective repair：

```math
\text{repair} = 
\begin{cases}
\text{focused edit on path toward majority}, & \text{if refutation cascades to majority support} \\
\text{SC vote (no change)}, & \text{otherwise}
\end{cases}
```

---

## 实验结论

- **基准**：5 个 reasoning benchmark
- **Qwen2.5-7B**：macro-avg +8.65 pp vs direct answering
- **Llama3.1-8B**：+15.83 pp
- **vs CoT / GoT / GoV / SC**：DDRG 全部胜出
- **Native zero-shot**：无需任何训练即可获得
- **Bank size 不变**：不需要扩展 candidate bank

---

## 局限性

- Claim graph 构建对 trace 形式敏感
- Answer-blind verifier 自身能力限制（弱 verifier → 弱 repair）
- Selective repair 的"一次修复"是否足够防 cascade error ？
- 在 agent long-horizon / tool-use 上的适用性待研究
