# SAUCE: Summary Analysis Using Conversation Entailment

## 摘要
**SAUCE（Summary Analysis Using Conversation Entailment）** 提出一条面向**跨语言对话语音摘要**的**无参考（reference-free）、基于事实**的评估管线，通过对话与文本之间的**蕴含（entailment）**来度量摘要的准确性与事实覆盖度。作者证明 SAUCE 能捕捉**转写与翻译错误造成的信息损失**，并能识别损坏的摘要。关键优势：**天然可解释** —— 它把摘要得分映射到**离散的、可验证的事实**，让用户能够精确定位具体的幻觉或遗漏（不同于黑盒 LLM 评估器或稠密嵌入指标）。初步研究显示 SAUCE 与人类判断**强一致**。已发表于 **ACL GEM workshop 2026**。

## 核心贡献
1. 提出**无参考、事实驱动**的对话语音摘要评估管线（SAUCE），通过对话-文本**蕴含**度量准确性与事实覆盖
2. 证明 SAUCE 能捕捉**转写与翻译错误造成的信息损失**，并识别损坏摘要
3. **天然可解释** —— 得分映射到离散可验证事实，可精确定位幻觉与遗漏
4. 与人类判断强一致；发表于 **ACL GEM workshop 2026**

## 方法与架构
**核心机制**：对话与摘要文本之间的**蕴含（entailment）**。

```math
\text{Score} = f(\text{Accuracy},\ \text{Fact Coverage})
```

**两项指标**：准确度（accuracy）、事实覆盖度（fact coverage）。

**无参考**：不需要参考摘要。

**可解释性机制**：把摘要分数**映射到离散的可验证事实** —— 用户可 pinpoint 具体幻觉或遗漏，而非得到一个不可追溯的分数。

**对比**：多个主流摘要指标、黑盒 LLM 评估器、稠密嵌入指标。

## 实验结果
- 有效捕捉**转写错误与翻译错误**造成的信息损失
- 能识别**损坏的摘要**（broken summaries）
- **与人类判断强一致**（初步研究）
- 相比黑盒 LLM 评估器与稠密嵌入指标，**可解释性是结构性优势**（非事后归因）
- 发表于 **ACL GEM 2026 workshop**（第五届 Generation, Evaluation and Metrics workshop）

## 局限性
- 「初步研究」显示与人类一致 —— 规模与统计强度有限；
- 蕴含模型的跨语言质量直接决定上限，对低资源语言可能退化；
- 事实的离散化方式（如何切分「事实」）未在摘要中说明，可能依赖启发式。

## 值得注意的点
与今日多篇「把判断交给可验证形式」的工作同源 —— **SAUCE 的价值不在分数，而在分数背后的可枚举事实**。这与 2611.06806（把心理伤害风险拆成 8 个可观察行为 + 373,873 条标注）几乎是同一设计哲学的两次应用。
