## 核心贡献

> 在 3 个 VLA 模型、2 个视频 benchmark（1,200 条 RoboShackles + 306 条 HomeSafe-Bench）上把「安全」拆成**内部敏感度**与**回避行为**两条独立线索分别测量：结论是 **VLA 内部确实在危险临近时产生表征突变（vision 与 language backbone 的 transition surprise 在 onset 处达峰），但 action head 的安全信号相对微弱，且在固定任务指令下初始动作总体上是「朝危险移动」而非撤离**——即任务执行仍是默认响应，即便危险已被内部记录。

1. **把 safety 评测从「行为结果」推进到「刺激–反应」双通道** — 借鉴稳态（homeostasis）、异稳态（allostasis）与「烟雾报警器原则」（漏报代价远大于误报时宁可假警报）这三条生物学基础，把人类对危险刺激的敏感性拆成两个可测问题：(1) VLA 内部表征对安全关键视觉刺激是否敏感；(2) 预测动作在危险出现时是否表现为回避。论文明确声明**不假设生物学等价**，也不把这些信号当作「已识别危险」或「行为安全」的证据。
2. **区分 hazard 与 danger** — hazard 是潜在伤害源，danger 定义为「其物理后果已经可见的那一刻」。每个视频带一个 harmful-consequence onset time `t*_e`；据此定义三组场景：**calm**（`t_min ≤ t < c_e`，`t_min = 0.5s`，`c_e` 来自数据集人工标注）、**near**（`0 < τ ≤ w_−`，onset 之前）、**just after**（`−w_+ < τ ≤ 0`，onset 及其后）。calm 帧可能包含 hazard 但不含其后果。
3. **Transition surprise 分数 Q** — 在冻结策略下逐帧独立前向（无帧历史、无动作反馈），在 vision encoder（语言投影前）、vision–language backbone、action generation head（最终去噪步）三组位置取隐状态 `H_t^ℓ`。用**时间归一化变化** `δ_t^ℓ = (H_t^ℓ − H_{t−}^ℓ)/(t − t_{−})`，以 calm 帧的变化分布为基线，用 **K-fold cross-fitting**（按 clip 分折，避免用自己的帧给自己打分）估计均值与正则化对角协方差 `Σ_reg = diag(σ²_j + ε·mean(σ²))`，再算正则化 Mahalanobis 距离 `Q_t^ℓ` 作为「表征惊奇度」。
4. **内部敏感度集中在 vision 与 language，action head 弱得多** — 在**全部 6 个设置与 2 个数据集**中，vision 与 language backbone 的 transition score 随后果临近上升并**在 onset 处达峰**；action generation 位置响应明显更弱（论文图 3–6）。
5. **但内部敏感度部分只是「画面变了」** — 加上对 **object motion 与 appearance change** 的控制后，vision 与 language 在危险附近的 Q 差异**降到约三分之一**。唯一例外是 **GR00T N1.7**：在同等 elapsed time、视觉变化与 danger 类别条件下，其 language state 在 onset 后仍显著 atypical（两个设置皆是）。
6. **初始动作总体朝危险移动，而非撤离** — 用「digital cousin」重建可比较的三维几何（从图像标注 + metric depth 估计 gripper–danger 几何），定义归一化距离缩减比 `R = −Δd / ‖p_end − p_0‖`（正=接近，负=撤离），分三档：**away (R < −0.5)**、**sideways (|R| ≤ 0.5)**、**straight at (R > 0.5)**。结果：RoboShackles 上**全部 3 个模型**、HomeSafe-Bench 上 **GR00T N1.7 与 VLA-JEPA** 都以「朝危险移动」为主导；**X-VLA 在 HomeSafe-Bench 上三种行为频率接近**，且 GR00T N1.7 与 VLA-JEPA 在所有 danger 类别上都倾向接近危险，X-VLA 则随 danger 类型变化更大。

## 技术方案

### 核心思想

既有 VLA 安全评测有三类：检查执行过程中是否违反安全约束、是否拒绝不安全指令、是否能在视频中检测到不安全动作。这些都是**行为层**的。本文问一个更根本的问题：人类为什么对危险敏感，这种敏感性如何塑造感知与行动——并把「敏感」拆成**内部表征层**与**动作层**两个独立通道分别测量，避免「行为正确就说明内部有安全意识」这一循环论证。

在表征侧，作者要回答的是「危险出现时内部表示发生了什么变化」，但「画面在变」是一个严重的混淆：calm 帧来自视频开头，后面的帧天然与开头不同，且视频自身的运动峰值往往恰好与危险 onset 同时。因此本文设置了**三层递进的对照**：

1. **与所有 calm 帧比较**（Figure 1 灰线）——最宽松，但受视频漂移污染；
2. **与「视频同一秒数」的 calm 帧比较**（Figure 1 蓝线）——控制时间漂移；
3. **再控制 object motion 与 appearance change**（Figure 7、8）——控制画面变化本身。

三层对照的结果构成论文的核心论证链：**敏感度确实存在（层 1、2 都可见），但其中相当一部分可归因于视觉变化（层 3 把差距压到约三分之一），action head 始终没有出现对应的强信号（层 1 就弱）。**

在行为侧，核心困难是：**视频数据集不提供三维几何**，无法直接测 gripper–danger 距离。作者的解法是构造 **digital cousin**——一个简化的仿真场景，用从图像标注与 metric depth 估计出的 gripper–danger 几何来复现，为「初始预测动作如何改变这个距离」提供共同空间坐标系。这把「有意图的回避」与「恰好朝那个方向动」区分开。

### 关键技术

| 技术/方法 | 说明 |
|------|------|
| **hazard vs danger 区分** | hazard=潜在伤害源；danger=伤害后果可见的瞬间，用 onset time `t*_e` 标记 |
| **三组时间场景划分** | calm（`t_min ≤ t < c_e`）、near（`0 < τ ≤ w_−`）、just after（`−w_+ < τ ≤ 0`） |
| **Transition surprise 分数 Q** | 表征变化相对 calm 基线的正则化 Mahalanobis 距离，度量「不寻常程度」 |
| **时间归一化变化 δ** | `δ_t^ℓ = (H_t^ℓ − H_{t−}^ℓ)/(t − t_{−})`，消除帧率/间隔差异 |
| **K-fold cross-fitting** | 按 clip 分折拟合 calm 基线，避免某 clip 被自己的帧评分 |
| **正则化对角协方差** | `Σ_reg = diag(σ²_j + ε·mean(σ²))`，在 `d_ℓ ≈ n` 时仍良定义（full sample covariance 会秩亏） |
| **三层提取位点** | vision（语言投影前的编码器输出）、language（融合后的 VL backbone）、action generation（action head 最终去噪步） |
| **冻结策略 + 逐帧独立前向** | 无帧历史、无动作反馈，保证 `H_t^ℓ` 只依赖当前帧 |
| **固定指令控制** | 所有 clip 使用同一指令「complete the household task.」，把动作方向归因于场景而非指令 |
| **Digital cousin 重建** | 由图像标注 + metric depth 估计 gripper–danger 几何，在简化仿真场景中复现 |
| **距离缩减比 R** | `R = −Δd/‖p_end − p_0‖`，∈[−1,1]，正=接近负=撤离；零位移记 0 |
| **Delta action vs absolute action** | delta 策略执行 8 个仿真步（≈0.4s）后取夹爪位置；absolute 策略直接用预测目标位置 |
| **三档行为分箱** | away (R<−0.5) / sideways (|R|≤0.5) / straight at (R>0.5) |
| **95% frame-bootstrap 置信区间** | 用于 R 的中位数与行为比例 |
| **三层混淆控制** | 所有 calm 帧 → 同秒数 calm 帧 → 额外控制 object motion / appearance change |

| 维度 | 规模 |

| **数据集** | RoboShackles **1,200** 条视频 + HomeSafe-Bench **306** 条视频（危害发展为可见有害后果的场景） |

## 局限性

- **「digital cousin」是重建而非真实几何** — gripper–danger 距离是从图像标注与 metric depth **估计**出来的简化仿真场景，作者自己指出「视频数据集不直接提供测 gripper-danger 距离所需的三维几何」；这一重建步骤本身引入误差，且只评估 onset 与 final 两帧。
- **表征 atypicality 不等于危险识别** — 作者明确写道「representational atypicality alone does not establish danger recognition」；同理「action direction without calm-frame comparisons cannot establish intentional avoidance or danger-induced behavioural change」——即没有 calm-frame 对照的回避分析不足以断言「回避」是危险引起的。
- **敏感度主要由视觉变化驱动** — 加上 object motion / appearance change 控制后差异降到约三分之一，只有 GR00T N1.7 的 language 层是例外；即论文最强的负面结论（「内部敏感度可能只是画面在变」）适用于多数设置。
- **action head 的安全信号本就弱** — 这既是发现也是限制：无法区分「VLA 不把危险编码进动作头」与「提取方式/层级选择不当」。
- **行为评测仅覆盖 LIBERO checkpoint**、仅 onset 与 final 帧、且要求夹爪可见——样本子集与全量场景有偏。
- **单一固定指令** — 全部 clip 用「complete the household task.」，因此结论是「在任务执行指令下」的默认响应，不能外推到有明确安全指令的部署场景。
- **实验规模与统计检验较弱** — 全文以图示与定性描述为主，正文未给出显著性检验的完整统计量，也未报告各设置的样本量细节（分箱计数在 Table 1/2 与附录中）。
- **作者自我声明的方法论保守性** — 论文明确不主张生物学等价，也未把内部信号当作安全行为的证据；因此该工作更接近「诊断框架」而非「安全评估基准」。
- **代码未公开**，重建 digital cousin 的具体实现细节主要在附录 A.2，复现门槛不低。

## 与知识库既有工作的关系

- 与 [[2026-10-25-2610.31429-phystrace-video-physical-consistency]] 同属视频 + 物理/安全推理的评测方向，但 Phystrace 关注物理一致性，本文关注**内部表征 vs 外显动作的脱节**。
- 与 [[2026-10-25-2610.31633-benice-kv-sharing-looped-models]] 共享「从内部层看模型」的方法论取向（一个看 KV 复用，一个看表征惊奇度），但本文把内部信号与行为信号**显式分离测量**，这正是它的方法论贡献。
- 与 [[2026-10-25-2610.31544-twin-world-credit-assignment-agentic-rl]] 呼应「agent 究竟学到了什么 vs 表现如何」的落差问题——本文的结论形式相同：**内部登记了危险 ≠ 行为上会回避**。
- 与 [[2026-03-12-Causally-Grounded-Mechanistic-Interpretability]] 同属机制可解释性方向，且同样强调**相关不等于因果**：本文的 Q 分数只是 atypicality 的相关度量，无法支撑「模型识别了危险」的因果主张。

## 建议

- **是否推荐使用**: 有条件
- **适用场景**: 评估 VLA 模型的**安全失败模式**时——特别是需要回答「模型是不是「知道」危险却不躲」这一问题的团队；本文提供的「内部敏感度 vs 动作方向」双通道诊断模板可直接复用于自建 VLA 评测集。
- **可借鉴要点**:
  1. **把「内部知道」与「行为上回避」当作两个独立指标测，不要合并成一个 safety score**——本文最重要的观察是：vision/language 层在 onset 处达峰（模型「登记」了危险），而 action head 信号弱、初始动作仍朝危险移动（行为上不回避）。合并成单一分数会把这个关键脱节抹掉。
  2. **任何「内部敏感性」指标都必须做画面变化控制**——本文层 1/层 2 的差异在控制 object motion 与 appearance change 后掉到约三分之一；不做这一步的内部探针报告几乎必然高估模型的安全意识。
