## 核心贡献

> 提出 **DRYLAB-Bench** —— 首个全面评估 LLM agent 高风险生物突变设计能力的 benchmark：30 个真正危险的 mutation-design 场景，多轮 tool-augmented 评估。

1. **超越 QA**: 不止评估危险知识 possession，而是真实工具调用设计能力
2. **覆盖 BDT 风险放大**: 评估 Biological Design Tools (BDTs) 放大的实际风险
3. **多轮工具环境**: LLM agent 编排 BDTs 迭代精炼候选

---

## 技术方案

### 核心思想

现有 biosecurity 评估主要测"是否知道危险知识"，但实际风险来自 LLM + BDT 联合设计能力。DRYLAB-Bench 用 30 个真实危险场景，多轮 tool-augmented 评估 agent 设计输出。

### 关键技术

| 技术 | 说明 |
|------|------|
| 30 hazardous mutation scenarios | 蒸馏自 biosecurity guidelines |
| Multi-round tool-augmented env | LLM 编排 BDTs 迭代 |
| Scoring beyond QA | 评估实际设计产出 |
| BDT integration | 包含专门生物设计工具 |

---

## 实验结论

- **基准**: DRYLAB-Bench（30 scenarios）
- **结果**:
  - 揭示多个 LLM agent 在 mutation design 上的真实能力上限
  - BDT 增强显著放大 dual-use 风险
  - 现有"知识 possession" 评估**显著低估**实际风险

---

## 局限性

- 仅 30 个场景，覆盖范围有限
- 评估本身可能给出危险配方（dual-use paper 风险）
- BDTs 模拟可能与真实实验室操作差距

---

## 实现建议

- **实现难度**: 高（场景构建 + BDT 编排 + 安全协议）
- **预期性能**: 评估 LLM agent 真实 biosecurity 风险的标准工具
- **适用场景**: LLM agent biosecurity 审计 / dual-use 风险量化 / AI policy 决策
