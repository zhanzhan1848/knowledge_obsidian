# Axis-LoRA: Probing and Adapting Embedding Models for Personal-Memory Retrieval

### 核心贡献
1. 发现当前个人记忆检索流水线依赖的冻结 dense embedding 模型**并未**很好地捕捉时间、地点、人物、事件这四个轴（axes）：改动记忆的日期或地点几乎不改变其 embedding。
2. 指出在冻结 embedding 之上训练投影层无法恢复缺失信号——问题位于模型内部，每个轴由不同的 attention-head pattern 编码。
3. 提出 Axis-LoRA：在 embedding 模型内部植入四个 LoRA 分支（per-axis adapter），并用 per-query gate 组合；在三个标准 embedding 模型、四个基准上一致提升。

### 技术方案
**核心思想**: 把「个人记忆的四个属性维度」显式建模为 embedding 模型内部的四个独立 LoRA 专家，由 per-query gate 动态选择各轴的贡献。

| 技术 | 说明 |
|------|------|
| 四个轴 | time（时间）、place（地点）、person（人物）、event（事件） |
| 内部诊断 | 逐轴探针分析发现每个轴由 distinct attention-head pattern 编码；换日期/地点对 embedding 影响极小 |
| 结构 | 在 embedding 模型**内部**放置四个 LoRA 分支，而非外挂投影层 |
| 门控 | per-query gate 组合四个分支的输出 |
| 训练数据 | 小规模 axis-counterfactual 训练集（通过轴反事实构造） |
| 参数开销 | 只训练 base parameters 的一小部分 |

### 实验结果
- **数据集**: LongMemEval、ATM-Bench、LoCoMo（另加一基准构成 4-benchmark mean R@10 的统计口径）
- **基线**: 三个标准 embedding 模型（冻结版本），以及「冻结 embedding + 训练投影层」的变体
- **结果**: 4-benchmark 平均 R@10 提升 +1.28 至 +1.56 pp（跨三个 embedding 模型），且只训练基座参数的一小部分

### 局限性
- 提升幅度相对温和（+1.28~+1.56 pp），绝对收益有限
- 摘要未说明四个 LoRA 分支的具体层数、秩（rank）与门控实现方式
- 依赖小规模 axis-counterfactual 训练集；轴的定义（四轴）是否可扩展到其他属性维度未说明

### 关键洞见
> 「给冻结 embedding 外面套一个投影层」是死路——缺失信号在模型内部、且四个轴由彼此不同的 attention-head pattern 编码，因此修复必须在 embedding 模型**内部**以 per-axis LoRA + per-query gate 的形式进行，而不是在外部补救。
