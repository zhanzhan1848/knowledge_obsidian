## 核心贡献

> 提出 SCOPE —— 把自然语言策略**编译**成可执行的神经符号谓词程序，在多轮 transcript + tool-call 轨迹上做策略判定。

1. **策略即程序**：把 policy 分解为窄粒度神经判定（neural predicates），由确定性抽取器与组合代码把它们的输出组合起来
2. **程序与数据联合优化**：用**对抗式生成反例**针对"程序偏离策略"的地方，程序与训练数据一起优化
3. **跨模型可迁移**：用最弱 executor 优化的程序可零成本迁移到其他模型
4. **可解释 + 稳定**：每个 verdict 都可回溯到产生它的 predicate 输出

---

## 技术方案

### 问题定位

| 方案 | 问题 |
|------|------|
| 微调 guardrail 模型 | 高效但**在复合策略上退化** |
| LLM-as-a-judge | 精度高但**推理成本高、预测不稳定** |
| 现有神经符号方法 | 符号层**表达力不足**，且针对固定数据优化而非针对策略本身优化 |

### 核心机制

```
Policy (自然语言)
      ↓ compile
可执行程序 = { 神经谓词, 确定性抽取器, 组合代码 }
      ↓
   verdict (可解释)
```

联合优化目标包含对抗生成的反例：反例专门针对程序偏离策略之处生成。

### 关键组件

| 组件 | 说明 |
|------|------|
| Neural predicates | 小模型执行的窄粒度判定 |
| Deterministic extractors | 抽取硬事实的确定性逻辑 |
| Composition code | 把多个 predicate 输出组合为最终判定 |
| Adversarial counterexample generation | 针对程序偏差生成反例驱动优化 |

---

## 实验结论

| 维度 | 结果 |
|------|------|
| 平均准确率 | **各任务与模型上最高** |
| 跨模型迁移 | 最弱 executor 优化的程序**无需再优化**即可迁移 |
| 部署可行性 | 在**廉价模型**上部署即达到与前沿推理模型相当的精度 |
| 稳定性 | 相比单体模型**显著更稳定** |
| 可解释性 | 每个 verdict 可通过产生它的 predicate 输出追溯 |

对照方法：prompt optimization、task decomposition、workflow generation。

---

## 局限性

- 依赖 predicate 分解的质量 —— 策略过于复杂时分解粒度选择困难
- 组合逻辑本身需要人工/自动设计，仍有一定工程负担
- 论文未覆盖多语言与非英语策略的充分验证

## 实现建议

- **实现难度**: 中高（需要编译 pipeline + 对抗优化基础设施）

- **建议起点**: 先用现成 guardrail 做 predicate 候选池，评估分解粒度是否够细
- **价值点**: 把"guardrail 模型"从黑箱变成可审计程序，这在合规场景是硬需求
