## 核心贡献
1. **引入 clipped leakage score $L$**：对每个标注 entry，度量模型对**真值**（gold value）相对"无文档先验"的**置信度增益**，按"剩余到确信的距離"归一化并截断到 $[0,1]$。分数在标注 strata 与属性间平衡，使任何子群都不主导。
2. **识别并演示了 misdirection（误导）失败模式**：$L$ 只奖励"对真值置信度的上升"，因此**自信地误导对手**的编辑可能看起来更隐私，尽管属性信息仍可恢复。
3. **构造了可逆反例 SWAP**：在**恰好是 redaction 编辑器会删除的那些 span** 上写入**异性形式**。在 MedQA 上，SWAP 在被打分的编辑器中取得**最低的 $L$**，且在 **74%** 的 SEX entries 上误导了对手（对手概率低于无文本猜测）。按 $|AUC - 0.5|$ 衡量，它在八个编辑器中只排**第六**。事后 rule-aware 测试（1,513 条 MedQA SEX entries）中，告知对手 swap 规则后其**真值平均概率从 .252 升到 .769**。
4. **问题不局限于 $L$**：攻击准确率与 proper scoring rules 在"把预测错误读作隐私"时同样会奖励误导。
5. **提出"evaluation interface（评估接口）"概念并系统审计其敏感性**：接口由**被查询的人、候选答案及其顺序、无文档先验、对手模型、评分规则**构成。在三个语料库的**固定发布文本**上逐一变动这些选择。988 个对比中，多数改变只是**可分性（separability）的增减**而非比较方向的反转；**只有对手家族会反转比较**（504 个 verdict 中改 124 个，其中仅 5 个反转）。
6. **识别出统计证据层面的脆弱性**：**稳定的排名不保证稳定的统计证据**——两个发布文本在所声明的泄漏分数上"显著不同"这一结论可能随接口变化而消失。
7. **构建 SACC（Scoped Attribute-Cue Closure）** 作为可追溯的编辑工具，使 SWAP 与两项编辑原则的独立消融成为可能，并展示其优势在何处不成立。
8. **导出 failure-driven 报告清单**，覆盖 misdirection、subject-reference 错误、对手敏感性、统计不确定性四类。

## 问题背景

隐私保护对于分享与分析描述人的文本至关重要。临床叙述、法律记录、在线帖子支撑 NLP 研究与应用，但也可能暴露相关个人的敏感信息。**De-identification** 试图通过移除显式标识符来降低风险。但移除姓名等直接标识符**并不足够**：代词、亲属称谓、角色名词仍可泄露性别、关系与职业（Lison et al., 2021；Pilán et al., 2022）。语言模型可以利用这些残余线索推断个人属性（Staab et al., 2024；Oh et al., 2026）。

基于推断的隐私评估用**对手语言模型**在发布文本上的预测来比较编辑方法。**核心漏洞**：当一个分数只奖励"对真值的置信度增加"时，一个自信地误导对手的编辑可能显得更隐私——即使属性信息仍可恢复。于是评估可能偏好错误的编辑，不是因为文本泄露得更少，而是因为其**评分规则把误导误认成了信息移除**。

本文的核心提问方式极具方法论价值：**对于固定的发布文本，一个隐私 verdict 会因为接口（而非文本）改变而改变多少？** 这把隐私评估从"哪个编辑更好"重构为"评估结论有多依赖评估协议"。

论文自陈 $L$ 的定位：它是"用于受控评估审计的分析性度量，**而非**属性可恢复性的全面度量"。$L$ 不同于 CPR/IPR（主体级评估），后者有效性本文不予评估。

## 方法

### 1. Clipped Leakage Score $L$

对每个标注 entry，$L$ 度量**真值概率相对无文档先验的增益**，归一化到"剩余到确信的距離"并截断到 $[0,1]$：

$$L = \operatorname{clip}\left(\frac{p_{\text{text}}(\text{gold}) - p_{\text{prior}}(\text{gold})}{1 - p_{\text{prior}}(\text{gold})}, \; 0, \; 1\right)$$

（结构依据摘要与图 1 的描述：真值概率高于无文本猜测记为泄漏，低于则记为 0。）分数在标注 strata 与属性间平衡。

**单侧性**：只把"超出无文档先验的增加"记为代价——即**为发布文本新增的信息收费，而非为对手已经猜到的部分收费**。风险恰在另一半：**跌到先验以下不付出任何代价**。本文的压力测试正是针对这一性质。

### 2. 评估接口（Evaluation Interface）

**评估接口** 由五类选择构成：
1. **被查询的人**（subject reference）
2. **候选答案及其顺序**（answer options）
3. **无文档先验**（document-free prior）
4. **对手模型**（adversary model）
5. **评分规则**（scoring rule）

论文的核心问题是：**固定发布文本，只改接口，verdict 会变多少？** 分析框架借用 multiverse / specification-curve 分析的思路（Steegen et al., 2016；Simonsohn et al., 2020）——但因为这些选择**改变了所估计的量与所作用的 entries**，故**逐一单独分析**。

### 3. SWAP：可逆的反例

**SWAP** 在**恰好是 redaction 编辑器会删除的那些 span** 上写入**异性形式**：

```
Redaction (SACC-mask):
[PERSON1] joined the clinic as a [JOB]. [REDACTED] later told [REDACTED] ...

SWAP:
[PERSON1] joined the clinic as a [JOB]. He later told his wife ...
```

**关键机制**：$L$ 忽略"跌到无文本猜测以下"——所以 SWAP（在多数 MedQA entries 上误导对手）比 redaction 得分更"隐私"（$L$ = **.241** vs **.495**，越低越隐私；基于 1,473 条共享的 MedQA SEX entries）。

**压力测试的结果**：
- SWAP 在同样 entries 上被打分的编辑器中**排第一**（$L$ 最低）
- **按攻击准确率与 proper scoring rules 读作隐私时也排第一**
- **按 relabelling-invariant 的 $|AUC - 0.5|$ 读时排第六/八**
- **rule-aware 对手从同一文本恢复了属性**：被告知 swap 规则后，真值平均概率从 **.252 → .769**（事后测试，1,513 条 MedQA SEX entries）

### 4. 三个语料库与固定发布

- **MedQA**（临床小场景）
- **TAB**（法院判决）
- **SynthPAI**（社交媒体帖子）

在**固定的发布文本**上逐一变动接口选择，在**三个对手家族**下测试。

### 5. SACC（Scoped Attribute-Cue Closure）

论文构建的**可追溯编辑器**，作为审计的"仪器"（instrument）。它使 SWAP 与**两项编辑原则的独立消融**成为可能，并展示其优势在何处不成立。

### 6. 统计框架

区分**比较方向的反转**（direction reversal）与**可分性的增减**（separability changes）。988 个"发布文本之间的对比"中，多数改变只是可分性的增减而非方向反转。**六个协议选择中，只有对手家族会反转比较**（504 个 verdict 中改 124 个，仅 5 个反转）。

另有两个独立分析识别出反转来源：**属性聚合**（attribute aggregation）与**被 redaction 混淆的 text-conditioned prior**。一个**无该混淆的 cue-deletion prior** 改变了可分性但**未改变方向**。

### 7. 对照的评估度量（背景）

论文把 $L$ 放在其他度量的语境中：**CPR/IPR**（主体级评估，报告对手无法推断的个人属性占比，pooled over people 或 per person 平均）；**攻击准确率**（top-1 正确数）；**proper scoring rules**（Brier, 1950；Gneiting & Raftery, 2007，对整个预测分布打分）；**AUC**（区分度；$|AUC-0.5|$ 在标签互换下不变）。

## 实验结果

- **Dataset/Task**: 三个语料库（MedQA 临床小场景、TAB 法院判决、SynthPAI 社交媒体帖子）的固定发布；三个对手家族；六个协议选择（被查询的人、候选答案及顺序、先验、对手模型、评分规则、属性聚合）。988 个发布文本对比。

- **Main results**:

| 现象 | 数值 |
|------|------|
| SWAP 的 $L$（MedQA SEX，1,473 共享 entries） | **.241** |
| Redaction 的 $L$（同 entries） | **.495** |
| SWAP 误导对手的比例 | **74%** |
| SWAP 按 $|AUC-0.5|$ 的排名 | **第六 / 八** |
| SWAP 按攻击准确率、proper scoring rules 读作隐私的排名 | **第一** |
| rule-aware 对手恢复后真值平均概率 | **.252 → .769**（1,513 entries，事后） |

  接口敏感性：

| 协议选择 | 改变的 verdict 数 | 其中方向反转 |
|------------|----------------|--------------|
| 对手家族 | 124 / 504 | **5** |
| 其余五项 | 多数为可分性增减 | 少数 |

- **Ablations**: (1) **relabelling-invariant 读法**（$|AUC-0.5|$）把 SWAP 从第一降到第六；(2) **rule-aware 对手**从同一文本恢复属性；(3) **cue-deletion prior**（无 redaction 混淆）——改变可分性但不改变方向；(4) **text-conditioned prior**——被 redaction 混淆，是反转的来源之一；(5) **属性聚合**——另一个反转来源；(6) **SACC 的两项编辑原则独立消融**——展示其优势在何处不成立。

## 关键洞察

1. **隐私评估的分数是"单向"的，而文本不是**：只奖励"对真值的置信度上升"的评分规则，天然把"把对手引向错误答案"与"真的移除信息"混为一谈。这是一个**评分规则层面的语义漏洞**，而非实现 bug——它会系统性偏向"误导型"编辑。
2. **"排名稳定"与"统计证据稳定"是两件事**：在固定发布上改变接口时，多数 verdict 变化只影响可分性（是否显著），而不改变比较方向。这对实践的含义很直接：**报告"编辑 A 比编辑 B 隐私"时，结论的方向可能稳，但"差异显著"这一说法极不稳健**。
3. **只有对手家族会反转比较**：这说明接口的多数选择（候选答案顺序、先验、评分规则细节）影响的是**噪声水平**而非**结论方向**，而**换对手模型**才可能翻转结论。实践中这意味着"多跑几个 prompt 变体"的稳健性收益有限，换对手家族才是真正的稳健性检验。
4. **relabelling-invariant 的读法（$|AUC-0.5|$）能识别出误导**：在它下面 SWAP 从第一掉到第六——因为把标签互换后，AUC 不变，但**误导型编辑在两个方向上都不产生区分度**。这给出了一个廉价的诊断：**用 $|AUC-0.5|$ 与用 $L$ 同时打分，若排名差异巨大，说明有编辑在误导而非在保护。**
5. **rule-aware 对手能完全逆转结论**：一旦对手知道编辑规则，SWAP 文本的泄漏从 .252 跳到 .769。这意味着**威胁模型必须包含"对手了解公开的脱敏流程"这一情形**——否则隐私评估只测了天真对手。
6. **subject reference 也会出错**："查询可以指向错误的人"——即把 A 的属性问在 B 的文本上。这类错误在任何 AUC 类指标下都不显眼，但在个体层面是致命的。
7. **方法论贡献可能大于具体分数**：本文示范的是"**把评估结论当作被审计对象，而不是把评估当作无误差的测量仪**"的做法。这与 2611.04090（judge 排名随 judge 变化）在精神上同源。

## 局限性

- **$L$ 明确不是全面的属性可恢复性度量**：作者自陈它是"用于受控评估审计的分析性度量"，CPR/IPR 的有效性本文不予评估。因此本文的结论限于"某些评分规则会奖励误导"，而非"隐私评估不可行"。
- **MedQA 的性别条目作为主战场有分布局限**：临床小场景的代词/称谓结构与真实语料（法律文书、社交媒体）的线索结构差异大；三个语料库虽都有，但主压力测试集中在 MedQA。
- **对手模型与家族的选择有限**：三个对手家族，且只有对手家族反转比较这一结论依赖这一特定选择集合；换其他对手家族（如更多闭源模型）可能改变结论。
- **rule-aware 恢复是事后（post hoc）测试**，不是主评估的一部分；其规则告知方式（告知 swap 规则）可能低估了更聪明的对手。
- **属性聚合与 text-conditioned prior 的反转来源被识别但未被解决**，只提出了 cue-deletion prior 作为无混淆的替代。
- **未评估信息论意义下的隐私量**（如互信息、差分隐私预算），因此"泄漏"的操作化仍依赖对手模型这一特定威胁模型。
- **SACC 作为审计工具本身需要评价**：论文说"展示其优势在何处不成立"，但未给出 SACC 与其他 de-identification 方法的全面对比。
- **样本规模**：1,473 / 1,513 条 MedQA SEX entries、988 个对比，在多组别、多属性下的细分分析受样本量限制。
- **不涉及差分隐私或形式化隐私保证**，全部结论是经验性的、针对具体协议的。
- **论文极长（49 页 PDF）**，主文外的 appendix 承载了大量材料；正文的核心证据集中于 MedQA。

## 适用场景

**适用**：
- 医疗、法律、HR 等领域**脱敏质量评估**的协议设计者：本文的 $L$、$|AUC-0.5|$ 双打分诊断、rule-aware 对手测试都是可直接采纳的检查。
- 需要**发布隐私对比结论**的研究者与工程团队：本文的 failure-driven 报告清单（misdirection / subject-reference 错误 / 对手敏感性 / 统计不确定性）是现成的 checklist。
- **威胁模型包含"对手了解公开脱敏流程"**的评估设计。
- 研究**评估指标本身的敏感性**的方法论工作：本文提供了从"评估结论"转向"评估接口"的完整审计范式。

**不适用**：
- 需要**形式化隐私保证**（差分隐私、信息论隐私）的研究——本文全是经验性指标。
- 需要全面属性可恢复性度量的场景（$L$ 明确不是）。
- 只需要"哪个编辑更好"而不关心协议稳健性的快速比较（本文的方法成本较高）。
- 非英语或非西方语料（线索结构与属性集合不同）。
