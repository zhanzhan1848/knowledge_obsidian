## 核心贡献

> 提出 **MSAR**（Multi-Stream Attention Residuals）：将 Attention Residuals（沿 depth 轴的单流 softmax attention）扩展为多流/多头 depth attention，性能显著提升且几乎无额外开销。

1. **架构扩展**: AttnRes 单流 → MSAR 多流头，沿 depth 轴多头 attention
2. **流多样性**: 通过 multi-scale causal conv 从序列上下文中获取 stream 差异
3. **Scaling 增益**: iso-loss 1.58× compute speedup（vs 标准残差），优于 AttnRes 1.35×、mHC 1.30×

---

## 技术方案

### 核心思想

Attention Residuals (AttnRes) 沿 depth 轴做单流 softmax attention → content-dependent retrieval over depth。MSAR 把这条轴上的单流变多流，受 multi-head sequence attention 启发。

### 关键技术

| 技术 | 说明 |
|------|------|
| Multi-head depth attention | 多流头沿 depth 轴 attention |
| Multi-scale causal conv | 生成 stream 间的差异视图 |
| Adaptive stream mixing | 轻量级混合 retrieved streams |
| Single-stream sources | 保留并按需扩展 → 无需持续多流存储 |

### 关键架构示意

```text
input x → multi-scale causal conv → multi-head depth-attn(streams)
        → adaptive mixing → next layer input
```

### 计算优势

- 复用 single-stream sources，无需 persistent multi-stream storage/communication
- 仅引入轻量级 conv + adaptive mixing

---

## 实验结论

- **模型**: 18B / 28B MoE 规模
- **基准**: 12 个下游 benchmark
- **对比**: 标准残差 / mHC / AttnRes
- **结果**:
  - MSAR **consistently outperforms** 所有 prior residual variants
  - Scaling-law iso-loss compute speedup:
    - **MSAR: 1.58×**
    - AttnRes: 1.35×
    - mHC: 1.30×
    - 标准残差: 1.00×

---

## 局限性

- 仅在 18B/28B MoE 验证，dense 模型/更大规模未验证
- Adaptive mixing 的可解释性弱
- 与 Manifold-constrained Hyper-Connections 的关系需厘清

---

## 实现建议

- **实现难度**: 中（修改 residual block）
