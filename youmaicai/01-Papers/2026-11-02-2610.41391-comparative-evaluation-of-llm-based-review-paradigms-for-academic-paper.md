> **原题**: Comparative Evaluation of LLM-Based Review Paradigms for Academic Paper Quality Assessment

| **摘要** | Growing submission volumes have renewed interest in using large language models (LLMs) to support peer review. It remains unclear how such evaluation should be structured, how much the model matters, and whether LLM scores predict research impact. We evaluate five paradigms across three input representations and three LLMs on 232 stratified ICLR 2025 submissions. Direct absolute rating matches comparative ranking on rank correlation with human scores, yet compresses most predictions above the accept threshold, flagging almost none of the papers reviewers scored below it. A base-rate-matched recalibration control locates the cause: comparative ranking supplies placement, not better ordering, and after recalibration Direct Rating reaches higher agreement than Elo while making 24% as many API calls. Abstract-only input beats full-paper summarization, and model choice matters as much as paradigm choice. Replicating on all 11,513 scored submissions reproduces these patterns, shows absolute agreement depends on the evaluated set's score spread, and finds none beating an always-reject baseline in accuracy. Human scores track citations better than any paradigm, with one exception: Group Rating retains its citation correlation after controlling for human scores, and alone ranks within the accepted pool. Ranking quality alone cannot assess review quality; calibration, thresholds, model, and target outcome all matter. |

## 核心贡献

1. **设置**：评估 **5 种评审范式 × 3 种输入表示 × 3 个 LLM**，在 **232 篇分层抽样的 ICLR 2025 投稿**上；随后在**全部 11,513 篇有分投稿**上复现。
2. **范式对比**：**直接绝对评分（Direct Rating）在与人类评分的秩相关上与比较式排名相当**，但**把绝大多数预测压缩到接收阈值之上**，**几乎不标记任何人类评分为拒稿的论文**。
3. **诊断**：**基率匹配的重标定对照（base-rate-matched recalibration control）**定位了原因 —— **比较式排名提供的是"位置"，而非更好的"排序"**。**重标定后，直接绝对评分比 Elo 达到更高的一致性，同时只产生 24% 的 API 调用量**。
4. **两个实用结论**：**仅用摘要输入优于全文摘要化**；**模型选择与范式选择同等重要**。
5. **复现结果**：绝对一致性**依赖于被评估集合的分数分布**；**没有任何范式在准确率上超过"全部拒稿"基线**。
6. **与影响力预测的关系**：**人类评分比任何范式都更好地追踪引用**；唯一例外是 **Group Rating 在控制人类评分后仍保留其引用相关性**，且**是唯一能在接收池内部排序**的范式。
7. **最终结论**：**仅靠排序质量无法评估评审质量；还需要校准、阈值……**

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| 技术 | 说明 |
|------|------|
| 5 种评审范式 | 直接评分/比较排名/Elo/分组等 |
| 3 种输入表示 | 全文/摘要/全文摘要化 |
| 重标定对照 | 基率匹配以定位差异来源 |
| 影响预测 | 引用数作为影响力代理 |
| 232 + 11,513 篇 | ICLR 2025 投稿 |

### 关键发现

- **"比较式排名提供的是位置，而非更好的排序"** 是一个精准的诊断 —— 它解释了为什么排行榜式评审（Elo）在实践中广受诟病却没被替代：**它买到的是标尺，不是分辨率**。
- **"没有任何范式在准确率上超过'全部拒稿'基线"** 与 [[2026-11-02-2610.41710-advancing-clinical-trial-outcome-prediction-with-domain-specific-large-l]] 的"平凡分类器 F1 未被超越"是**同一个陷阱的两个实例** —— 这已经是连续第二天出现"平凡基线打败一切"的现象。**这可能是当前 LLM 评测领域最普遍的盲点**。
- **"仅摘要输入优于全文摘要化"** 有直接的实践价值：多数团队的默认 pipeline 是"先总结全文再评分"，本文说这是**反模式**。
- **Group Rating 是唯一例外**（保留引用相关性 + 唯一能在接收池内排序）—— 这给出了一条具体的改进线索，而不是全盘否定。
- 与 [[2026-11-02-2610.41803-what-standard-evaluations-hide-about-detectors-of-hijacked-llm-agents-ra]]（检测器评测）同构：**先问校准与基线，再谈方法优劣**。

## 实验结果

| 设置 | 结果 |
|------|------|
| 232 篇分层抽样 | 直接评分与比较排名在秩相关上相当 |
| 重标定后 | 直接评分一致性**高于 Elo**，API 调用仅 **24%** |
| 输入表示 | **摘要-only 优于全文摘要化** |
| 11,513 篇全量复现 | 绝对一致性**依赖被评集合的分数分布** |
| 准确率 | **无范式超过"全部拒稿"基线** |
| 引用追踪 | 人类评分最佳；**Group Rating** 控制人类评分后仍保持引用相关性，且唯一能在接收池内排序 |

## 局限性

- 引用数作为"研究影响力"的代理很弱 —— 引用受领域、发表 venue、作者网络影响
- 仅覆盖 ICLR 2025 一个 venue、一个时间点
- "摘要优于全文摘要化"的结论可能与该会议的具体评审偏好相关
- 摘要未给出"评审质量"的可操作定义
