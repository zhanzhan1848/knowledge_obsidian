## 核心贡献

> 提出 TokenGate —— 一个小型即插即用模块，扩展现有已训练模型以实现**端到端可学习**的 token pruning，让 LLM 在长上下文 prefill 时更快、更省内存，同时不损失精度。

1. **Token-Gated Attention (TGA)**：受 Mixture-of-Experts 启发，通过 token importance score 重新加权 attention logits，从而绕过 top-K 的不可微性，实现端到端学习
2. **Drop-in Module**：适用于标准 Transformer (Qwen3) 与 hybrid-attention (Qwen3.5) 模型
3. **显著加速与省内存**：1.4-11.3x 更快 TTFT，1.5-3.4x 更低峰值内存；较先前最优 token-pruning 方法再快 6.4x、内存低 2x
4. **无精度退化**：在多种任务上保持原模型精度

## 技术方案

### 核心思想

借鉴"人类专家略读后再精读"的策略，让 LLM 学习一个重要性评分，剪枝不重要的 token。挑战在于 top-K 操作不可微 → 引入 TGA 用可微方式重加权 attention logits。

### 关键技术

| 技术 | 说明 |
|------|------|
| Token-Gated Attention | 用 token importance 重新加权 attention logits，绕过 top-K 不可微性 |
| Drop-in Adapter | 类似 PEFT 的轻量适应，可附加到已训练模型 |
| Long-Context Prefill | 重点优化长输入下的 prefill 阶段（不是 decoding） |
| Hybrid Compatibility | 同时支持纯 Transformer 与 hybrid-attention 模型 |

### 关键公式

Token importance score 通过 gate 网络生成并调制 attention logits：

```math
\alpha_t = \sigma(W_g \mathbf{h}_t) \in [0, 1]
```

```math
\text{Attn}_i = \text{softmax}\left(\frac{Q_i K^\top}{\sqrt{d}} \odot \alpha\right)
```

其中 $\alpha$ 由 token-level importance 派生，相当于"软"top-K。

## 实验结论

### 主要性能

| 指标 | TokenGate 提升 |
|------|--------------|
| TTFT 加速 | **1.4x - 11.3x** |
| 峰值内存降低 | **1.5x - 3.4x** |
| 较先前最优 token-pruning 加速 | **最高 6.4x** |
| 较先前最优内存降低 | **最高 2x** |
| 精度退化 | **无** |

### 兼容性

- Standard Transformer: Qwen3
- Hybrid Attention: Qwen3.5
- 适配开销 comparable to standard PEFT

---

## 局限性

- 主要关注 prefill，decoding 阶段收益待评估
- Token pruning 在某些需要全局信息的任务上仍可能影响性能
- Adapter 需要少量训练数据与算力

## 实现建议

- **实现难度**: 中 (主要是训练 adapter 的工作量)
- **预期性能**: 长上下文任务上显著加速与省内存
- **适用场景**: 长文档问答、代码库理解、多轮对话历史的 prefill
- **建议起点**: 在目标模型上 fine-tune TokenGate adapter，监控精度保持率
