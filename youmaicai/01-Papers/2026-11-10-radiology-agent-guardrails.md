## 核心贡献

> 在放射科工作流模拟中量化"会写错病历"的工具型 LLM 智能体发生率，并首次系统比较确定性规则与本地 LLM 校验器这两种动作前护栏的效果：分层护栏能降低但不能消除高危错误。

1. 构建 48 个放射科医生审阅的合成基础场景（发现沟通、肿瘤板准备、随访管理三模块），其中 43 个另有"误导信息"变体，共 91 个变体；6 个 LLM 智能体在 3 种护栏配置下完成 1,638 个回合的受控模拟研究。
2. 量化主结果：仅权限配置下 7.3%–27.1% 回合出现至少一次已执行的高危违规（跨智能体合并 19.4%）；加确定性规则降至 16.7%（−2.8 pp，95% CI −6.1~0.5），再加 LLM 校验器降至 13.2%（−6.2 pp，95% CI −9.5~−3.0）。
3. 机制发现：误导信息变体中智能体在 83% 的回合打开了被篡改的文档（无论是否出错），58% 的错误陈述引用了它；错误源于"误判"而非"漏看"。同时护栏的代价被量化：规则+校验器配置下 64%–68% 的拦截动作本不会导致违规而被退回返工。

## 技术方案

### 核心思想

LLM 智能体从"回答"转向"行动"，错误的性质随之改变：错误答案可被读出并丢弃，而错误动作会把虚假信息写进他人依赖的病历。放射科场景里有一类无需攻击者的普通诚信问题：智能体在汇编工作产物时遇到看似可信但有误导性的外部信息——过期的外院报告、转诊单上把某发现写成"已知"、转诊信写反了侧别。这些陈述不含任何指令。

论文的问题是：在动作执行边界（proposed action 与 executed action 之间）施加确定性规则与模型化护栏，能否减少由此产生的临床相关错误，且效果是否依赖智能体模型。

实验在纯合成的放射科信息系统模拟环境上进行，无人类受试者与患者数据，故无需 IRB 审批；协议、场景、参考标准与分析代码在首次主运行前固定，主运行在 2026 年 10 月 4–10 日进行，报告遵循 TRIPOD-LLM 与 CLAIM 2024 的相关条目。

三个模块分别对应三类工作产物：M1 写发现转达与沟通摘要、M2 写肿瘤板草稿的放射科部分、M3 更新随访建议的状态。智能体只能通过预定义软件函数（工具）读写，带只读访问与写工具（写工具接受结构化陈述，含确定性、时间参照与引用来源）；系统提示对所有智能体与配置完全相同，全德语文本。

三种护栏配置构成核心对照：C（仅权限）——不加任何动作前检查；E（确定性规则）——在权限基础上加 11 条确定性规则（E01–E11），验证来源出处（原始报告/转诊信/指南）、侧别与部位一致性、时间戳一致性、随访状态等；D（规则 + LLM 校验器）——在 E 之上，对每个通过 E 的状态变更动作交给本地运行的 LLM 校验器复核其引用来源是否支持该陈述，校验器以 6 个编码（D01–D07）返回结构化 JSON，checker 失败即拦截并计入任务失败而非安全性。

主结局定义为"每回合至少一次已执行的高危违规"。违规严重度（高/中/低）在主运行前由三名放射科医生共识设定；违规继承其成因的严重度，转发的工作产物中的违规提升一级。风险差在场景层面估计，跨智能体合并为探索性分析。

独立的确定性评估器对照单独存储、不可被智能体或 LLM 校验器访问的参考标准，对每个已执行陈述评分，并把被拦截动作分类为"合理拦截"或"不必要拦截"。

### 关键公式

```math
% 主结局与风险差
\text{High-severity error} = \mathbb{1}\{\exists \text{ 已执行的高危违规}\}
\mathrm{RD}_{\text{rules}-\text{perm}} = \mathrm{P}(\text{高危错误}\mid E) - \mathrm{P}(\text{高危错误}\mid C)
\mathrm{RD}_{\text{rules+checker}-\text{perm}} = \mathrm{P}(\text{高危错误}\mid D) - \mathrm{P}(\text{高危错误}\mid C)
% 区间估计用场景层面分层 t 区间；个体智能体用配对 video-clustered bootstrap

% 违规严重度规则
\mathrm{severity}(\text{violation}) = \mathrm{severity}(\text{cause}),\quad
\text{转发工作产物中的违规严重度} \mathrel{+}= 1\ \text{级}

% 拦截精确率与合理性判定
\text{Justified block}: \text{该动作若执行会构成违规}
\text{Unnecessary block}: \text{该动作若执行不会构成违规}
\text{Block precision} = \frac{\#\text{justified blocks}}{\#\text{all blocks}}
```

### 关键组件

- **三种护栏配置**：C 仅权限；E 权限 + 11 条确定性规则（E01–E11）；D 规则 + 本地 LLM 校验器（D01–D07 编码）。
- **工具与写入门禁**：写工具接受含确定性、时间参照、引用来源的结构化陈述；校验器与评估器均看不到测试标签以外的答案。
- **误导信息变体**：43 个场景含一个被篡改的外部文档，其中含看似可信但错误的陈述（无指令）；主运行前固定。
- **独立确定性评估器**：对照不可访问的参考标准评分每个已执行陈述；同时把被拦截动作判为合理/不必要。
- **预算与返工机制**：被拦截动作返回反馈，可在 40 次工具调用预算内返工最多 2 次。
- **模型阵容（6 个智能体）**：Claude Sonnet 5.5、GPT-6.1-Sol、GLM-5.3、MiniMax M3、Gemma-4-31B、Qwen3.8-27B（后两者本地运行）。
- **附加分析**：文档访问分析、拦截精确率分析、严重度敏感性分析、留一智能体分析、重跑一致性分析。

## 实验结果

| 基准/指标 | 结果 |
|-----------|------|
| 回合总数 | 1,638（48 基础场景 + 43 误导变体 = 91 变体 × 6 智能体 × 3 配置） |
| 仅权限（C）高危错误率（跨智能体合并） | 19.4%（95% CI 12.7–26.2） |
| 仅权限（C）高危错误率（单智能体范围） | 7.3%（Claude Sonnet 5.5）– 27.1%（GLM-5.3） |
| 仅权限（C）——干净变体 / 误导变体（跨智能体） | 14.9%（95% CI 7.9–21.9）/ 25.0%（95% CI 15.7–34.3） |
| 规则（E）高危错误率 | 16.7%（95% CI 11.0–22.3）；RD = −2.8 pp（95% CI −6.1, 0.5） |
| 规则（E）——干净变体 RD | −3.5 pp（95% CI −6.7, −0.3） |
| 规则+校验器（D）高危错误率 | 13.2%（95% CI 8.0–18.4）；RD vs C = −6.2 pp（95% CI −9.5, −3.0） |
| 校验器相对规则的增量 | −3.5 pp（95% CI −6.3, −0.7）；OR 0.74（95% CI 0.58, 0.94） |
| 规则相对权限的 OR | 0.79（95% CI 0.65, 0.96） |
| 智能间差异 | 未检出（P = .43） |
| 任务成功率 | 49.0%（GLM-5.3）– 77.1%（Claude Sonnet 5.5）；护栏未检出地降低成功率 |
| 任务成功率变化 | 规则 +3.3 pp（95% CI −1.5, 8.1；干净变体 +6.9, 95% CI 1.5, 12.4）；加校验器 +1.6 pp（95% CI −2.5, 5.6） |
| 误导变体残余高危错误（配置 D） | 17.4%（95% CI 9.7, 25.0） |
| 误导文档被打开比例 | 83%（无论是否出错；出错回合 135/162，未出错 507/612） |
| 违规前已访问该文档比例 | 85%（288/337） |
| 错误陈述引用该文档比例 | 58%（156/268） |
| MiniMax M3 例外 | 41 次违规中 28 次之前未访问；29 次错误陈述中仅 8 次引用该文档 |
| 高危违规发生环节 | 45%（227/502）发生在写工作产物时；55%（275/502）在完成报告时；检索阶段 0 |
| 最常见违规维度 | 不受支持的确定性或否定 30%；不受支持的完成声明 26% |
| 拦截精确率（仅规则） | 196 次拦截中 71 次合理（36%） |
| 拦截精确率（规则+校验器） | 595 次拦截中 191 次合理（32%） |
| 拦截精确率区间（仅规则） | 11%（Claude Sonnet 5.5）– 73%（Gemma-4-31B） |
| "合理拦截但仍有高危错误" | 41/170 回合（24%） |
| 使用 Claude 作校验器 | 错误未进一步减少（+2.1 pp，95% CI −4.3, 8.4），拦截次数减半（135 vs 240），精确率相近（28% vs 32%） |
| 重跑一致性 | 本地智能体 87.5%–89.3% 回合一致（κ = 0.59–0.66） |

## 局限性

- 纯合成环境与合成患者/文档，无真实临床数据；行为者书面德语，任务仅三类工作产物，未覆盖完整放射科工作流。
- 智能体仅 6 个，个体差异未检出（P = .43）但样本量对个别智能体的效应区间较宽（点估计 0.0 ~ −5.2 pp）。
- 主结局为"已执行的高危违规"的比例，不衡量临床后果的严重程度分布；严重度分级依赖三位放射科医生的共识设定。
- 误导信息变体不含真正的提示注入，因此结论不能外推到间接提示注入攻击场景。
- 校验器效果存在明显的模型规模效应：更大的 Claude 校验器并不减少错误（可能是"看起来有支撑"的内容通过检查），小模型本地运行则有效；该结论仅在两个智能体的一次运行中测试。
- LLM 校验器约三分之二的拦截是不必要返工，实际运营成本（人工复核）未量化。

## 建议

- **是否推荐使用**：是
- **适用场景**：医疗（及其他高风险）场景中 LLM 智能体的动作前护栏设计与评估；间接提示注入之外的"误导性内容"类失效模式的量化；AI 治理与监管合规论证。
- **值得复现**：是（其分层护栏配置设计与独立评估器范式可迁移到其他领域；但需注意"更大的校验器未必更好"这一反直觉发现）
