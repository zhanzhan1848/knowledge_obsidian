## 核心贡献

> 把单图、多图、视频 deep research 统一在 **Visually Grounded Evidence Graph (VGEG)** 上，让 grounding、retrieval、fact-composition 共享同一任务级参考图；并提出 **EVGR reward** 在 RL 中监督 evidence traceability。

1. 提出 **VGEG**（Visually Grounded Evidence Graph）：把视觉锚点、实体关系、来源支持的事实、产出答案的操作显式建模为共享图。
2. 基于 VGEG 构建数据引擎，发布 **OneSearch-VL-SFT-110K** 与 **OneSearch-VL-RL-10K**。
3. 提出 **EVGR**（Evidence-aware Visual-Grounded Rubric）：从 VGEG 标注导出，对 RL 中的 evidence traceability 与 visual grounding 提供监督。

---

## 技术方案

### 核心思想

多模态 deep research 的难点不在"能看图/能查资料"，而在"如何保持 visual anchor ↔ entity ↔ source ↔ answer 之间的依赖链不被遗忘"。VGEG 是这张依赖链的显式表示，被 SFT 数据构建、process supervision、operation-level eval 共享使用。

### 关键技术

| 技术 | 说明 |
|------|------|
| VGEG | 节点类型 = visual anchor / entity / source-supported fact / operation；边表达引用与产出关系 |
| VGEG-based data engine | 用 VGEG 自动构建并验证多图/视频 QA，过滤低质量 expert trajectory |
| EVGR reward | 把 VGEG 标注转换为可微 RL reward，监督 evidence traceability + visual grounding |
| Unified agent | 同一 agent 同时处理 single-image / multi-image / video 三类任务 |

### 公式

EVGR reward 可形式化为 VGEG 边的覆盖与正确性的函数：

```math
R_{\text{EVGR}} = \alpha \cdot \frac{|\text{covered evidence edges}|}{|\text{required evidence edges}|} + \beta \cdot \mathbb{1}[\text{visual anchor grounded}]
```

其中 $\alpha, \beta$ 为超参。

---

## 代码片段（伪代码）

```python
# EVGR computation from VGEG annotations
def evgr_reward(generated_answer, vgeg_annotation):
    covered = sum(1 for e in vgeg_annotation.required_edges if e.supported_by(generated_answer))
    coverage = covered / max(len(vgeg_annotation.required_edges), 1)
    grounded = all(a.has_visual_evidence() for a in generated_answer.visual_anchors)
    return ALPHA * coverage + BETA * float(grounded)
```

## 实验结论

- **数据集**: OneSearch-VL-SFT-110K（SFT）+ OneSearch-VL-RL-10K（RL）
