## 核心贡献

> 提出统一的多模态 deep research agent，以 Visually Grounded Evidence Graph (VGEG) 为核心，保留视觉锚点、实体关系、源支持事实和答案生成操作之间的依赖关系。

1. 引入 **VGEG**（Visually Grounded Evidence Graph）：跨任务统一依赖表示
2. 构建 **OneSearch-VL-SFT-110K** + **OneSearch-VL-RL-10K** 数据集
3. 设计 **EVGR**（Evidence-aware Visual-Grounded Rubric）作为 RL 奖励
4. 在新 benchmark 上比 Qwen3-VL-8B + tool access 提升 **20.2 / 17.6 pp**

---

## 技术方案

### 核心思想

单图、多图、视频挖掘任务共享一个工作流：视觉 grounding → 外部检索 → 事实组合。挑战在于保留局部视觉锚点、实体关系、源支持事实、答案生成操作之间的依赖。VGEG 将这些依赖编码为 task-level reference，统一数据构建、过程监督和操作级评估。

### 关键技术

| 技术 | 说明 |
|------|------|
| VGEG | 视觉锚点 + 实体关系 + 源支持事实 + 答案生成操作的图结构 |
| VGEG-based data engine | 构建并验证多图/视频问题，过滤专家轨迹 |
| OneSearch-VL-SFT-110K | 110K SFT 样本 |
| OneSearch-VL-RL-10K | 10K RL 训练样本 |
| EVGR reward | Evidence-aware Visual-Grounded Rubric，监督证据可追溯性和视觉 grounding |
| OneSearch-MI-Bench / Video-Bench | 按 VGEG 编码的研究操作组织问题 |

### 训练流程

1. **SFT 阶段**: 用 OneSearch-VL-SFT-110K 做监督微调
2. **RL 阶段**: 用 EVGR 奖励信号在 OneSearch-VL-RL-10K 上做 RL

---

## 公式

```math
\text{EVGR} = w_1 \cdot R_{\text{grounding}} + w_2 \cdot R_{\text{traceability}} + w_3 \cdot R_{\text{answer}}
```

其中各项分别评估视觉 grounding 准确性、证据可追溯性、最终答案正确性。

---

## 实验结论

- **模型**: OneSearch-VL-8B
- **新 benchmark**: 
  - OneSearch-MI-Bench: **+20.2 pp** vs Qwen3-VL-8B + tool access
  - OneSearch-Video-Bench: **+17.6 pp** vs 同 baseline
- **其他**: 在 7 个 image benchmark 和 VideoDR 上也获得显著提升
- **数据集**: OneSearch-VL-SFT-110K + OneSearch-VL-RL-10K
