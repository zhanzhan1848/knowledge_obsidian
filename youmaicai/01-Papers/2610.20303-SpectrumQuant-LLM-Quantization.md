## 核心贡献

> 从 first principles 推导 rotation selection criterion：**spectral alignment**（maximizing covariance），closed-form SpectrumQuant 算法。

1. **理论分析**：现有正交旋转（Hadamard / learned rotations）的 trade-off 不清晰；提出 maximizing covariance ⇒ spectral alignment 是量化友好旋转的 principled criterion。
2. **SpectrumQuant**：calibration 上估计 activation covariance → 构造 covariance-aware 正交变换。closed-form，速度快。
3. **桥梁作用**：recover Hadamard 作为特例；包含 butterfly 类矩阵为子集；bridge data-agnostic 与 learned rotations。

---

## 技术方案

### 核心思想

LLM PTQ 用正交变换 reshape activation 分布而不改变模型函数：
- **Hadamard** 等固定变换：data-agnostic，便宜但不一定最优；
- **Learned rotations**：calibration-time 优化，更好但昂贵。

SpectrumQuant 找 principled criterion：
- 推导显示 maximizing covariance ⇒ spectral alignment ⇒ quantization-friendly；
- closed-form 算法用 calibration data 估计 activation covariance，构造 alignment + mixing 复合变换；
- Hadamard 是对齐组件的特殊情形；
- 一些 butterfly 矩阵也属此类。

### 关键技术

| 技术 | 说明 |
|------|------|
| Spectral alignment 推导 | maximize covariance |
| Closed-form rotation | 无需优化 |
| Alignment + mixing decomposition | 复合变换 |
| Hadamard 作为特例 | 与现有方法兼容 |
| Butterfly 子集 | 包含 efficient butterfly |
| Calibration-aware | data-aware 但便宜 |

## 实验结论

- **模型**: Llama, Mistral
- **基线**: 现有 rotation strategies (Hadamard / learned)
- **结果**:
  - 与 SOTA learned rotation 相当；
  - GPU 内存 < 1/3；
  - 时间显著低于 learned rotation；
  - 提供 quantization-friendly closed-form 替代。

---

## 局限性

- 仍需 calibration data，不是 fully data-free；
- 高 bit 量化下与 learned rotation 差距小，低 bit 下仍待验证；
- 理论分析基于 empirical covariance 估计，假设可能不严格成立。
