# Can LLMs Take Retrieved Information with a Grain of Salt?

> **arXiv**: [2605.06919](https://arxiv.org/abs/2605.06919)
> **发表日期**: 2026-05-07（v2 更新于 2026-11-06）
> **分类**: cs.CL (Computation and Language)
> **会议/期刊**: NeurIPS 2026（第 40 届神经信息处理系统大会）

## 📋 摘要

大语言模型已展现出强大的检索增强能力，但有一个关键领域仍被低估：**模型能否恰当地依据所检索信息的不确定性来调整自己的回答**。这在医疗、金融等高风险领域有真实后果。本文在 **8 个 LLM** 上评测其「上下文确定性服从」（context-certainty obedience），即模型调整回答以匹配上下文所表达的确信程度的能力。分析揭示出系统性的缺陷：LLM 在看到不确定的上下文后**无法复现自己先前的输出**（说明其无上下文时的答案被上下文悄然改写/锚定）；LLM 对所表达的确信度的响应是**扭曲**的（比例关系失真）；并且模型**过度依赖复杂上下文**。为解决这些问题，作者提出一种交互策略：组合**先前提醒**（把模型自己在无上下文情况下给出的答案回填进提示）、**上下文确定性重校准**（context-certainty recalibration）与**上下文简化**（context simplification）。该策略在**不修改模型权重**的前提下，平均将服从性错误降低 **25%**，展示了交互式设计在提升 LLM 可靠性上的有效性。论文贡献包括一个有原则的评测指标、对 LLM 不确定性处理行为的实证洞见，以及一个可在多种 LLM 上直接移植使用的改进策略。

## 🎯 核心贡献

1. **提出并测量「上下文确定性服从」这一新维度**：给出有原则的评测指标，衡量模型是否按上下文所表达的确信度调整输出。
2. **揭示三类系统性缺陷**：(a) 观察到不确定上下文后无法复现自己先前的输出；(b) 对确信度的响应呈扭曲关系；(c) 过度依赖复杂上下文。
3. **纯交互式（免训练）改进策略**：先前提醒 + 确定性重校准 + 上下文简化三件套，平均降低服从性错误 **25%**，**不改动任何权重**。
4. **跨模型可移植性**：在 8 个不同 LLM 上均有效，说明是普适的提示/交互层面问题而非单模型缺陷。

## 🔧 方法/架构

- **上下文确定性服从（Context-Certainty Obedience）**：给定同一问题，先让模型在**无上下文**下回答（得到其先验答案），再提供一个带有明确确信度标记（如「可能 / 很可能 / 确凿」）的检索上下文，度量模型回答的确定性/确信度是否与上下文所表达的相符。

  ```math
  \text{Obedience}(q,c) = \big|\Pr[\text{certainty in answer} \mid c] - \text{certainty}(c)\big|
  ```

  服从性误差即模型输出确信度与上下文确信度之间的偏差。

- **缺陷分析维度**：
  - **无上下文可复现性**：观察不确定上下文后，模型是否仍能给出与无上下文时相同的答案（不能 → 说明模型被上下文锚定）。
  - **确信度响应曲线**：以确信度为自变量，考察模型输出确定性是否单调、线性对应（扭曲 → 非线性失真）。
  - **上下文复杂度依赖度**：随上下文复杂度/长度增加，模型对上下文的确信度依赖是否过强。

- **改进策略（三件套）**：
  1. **先前提醒（prior reminder）**：把模型**自己**的无上下文答案回填到提示中，作为锚点，降低上下文改写效应：

     ```math
     \text{Prompt} = \big[\text{Your own context-free answer: } \hat{y}_0\big] \oplus \big[\text{Retrieved context: } c\big]
     ```

  2. **上下文确定性重校准（recalibration）**：显式要求/引导模型按上下文的确信度重新校准其表达的确信度。
  3. **上下文简化（simplification）**：削减上下文的复杂度（冗余、冲突表述），降低模型对复杂上下文的过度依赖。

## 📊 实验结果

- **数据集**：作者自建的「带确定性标记的检索上下文」评测集（摘要未给出数据集名称与规模）。
- **模型**：**8 个 LLM**（摘要未列出具体型号）。
- **基线**：原始提示（无任何干预）、以及各单项策略（消融）。
- **结果**：
  - 组合策略**平均降低服从性错误 25%**，且**不修改模型权重**；
  - 三类系统性缺陷被明确记录（不可复现先验、确信度响应扭曲、过度依赖复杂上下文）；
  - 摘要未给出逐模型的绝对误差数值。

## ⚠️ 局限性

- 「上下文确定性服从」的评测依赖作者自定义的确定性标记体系，标记措辞与量表的构造细节会影响结果，外部可复现性需查原文。
- 仅 **8 个 LLM**，未说明是否含闭源商业模型；结论对不同规模/家族的代表性有限。
- 25% 的相对误差下降是**平均值**，各模型间方差未披露，实际部署时不同模型的收益可能差异很大。
- 策略完全依赖交互层的提示构造，未从根本上改善模型的内部不确定性表征；先前提醒在模型先验错误时反而可能强化错误。
- 高风险领域（医疗、金融）的实际影响未被端到端验证，仅在抽象评测上度量。
