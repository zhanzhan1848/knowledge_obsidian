# AdaAlloc: Adaptive Visual Token Allocation for Long-Video Question Answering

> **arXiv**: [2611.09092](https://arxiv.org/abs/2611.09092)
> **发表日期**: 2026-11-06
> **分类**: cs.CV (及交叉分类 cs.AI)
> **会议/期刊**: NeurIPS 2026（Accepted）；项目主页：https://vision.cs.utexas.edu/projects/adaalloc

## 📋 摘要

长视频问答要求多模态大模型在严格的视觉 token 预算下进行推理，由此形成一个根本张力：既要有广度上的时间覆盖，又要有关键局部线索的高分辨率细节。均匀采样能保住覆盖度，但常常把决定性的局部证据冲淡；而基于字幕（caption）或帧相似度的方法是在有损的代理信号上检索，会漏掉运动、状态变化以及前后对比关系。本文把长视频推理重新刻画为**视觉 token 分配问题**：在固定预算下，决定多少预算用于全局上下文、多少用于高分辨率局部证据，以及局部证据从哪里取。作者提出 AdaAlloc，一个**免训练（training-free）**的推理框架，自适应地在全局视频概览与局部视觉细节之间分配视觉 token。AdaAlloc 先规划一份全局/局部的分配策略（policy），然后用时序定位（temporal grounding）找出候选证据片段，并把它们精炼为一份紧凑的"时序记忆"（temporal memory）；所选策略同时控制帧的采样密度与分辨率，把稀疏低分辨率的全局帧与从精炼记忆中取出的稠密高分辨率局部帧组合起来。最终的答案器在"全局上下文 + 精炼局部证据"上联合推理。在 LVBench、MLVU、VideoMME、LongVideoBench 上，AdaAlloc 相比等预算的均匀采样最多提升 **10.5 个百分点**，并在各自报告的基准上优于所对比的帧选择方法与 agentic 方法。

## 🎯 核心贡献

1. **问题重构**：把长视频问答从"检索哪些帧"改为"如何分配视觉 token 预算"，显式地分离全局覆盖预算与局部细节预算，并决定局部证据的位置。
2. **AdaAlloc 框架**：免训练的推理期框架，采用"分配策略规划 → 时序定位 → 时序记忆精炼 → 双分辨率（全局稀疏低分辨率 + 局部稠密高分辨率）采样 → 联合推理"的流水线。
3. **绕开有损代理**：用 temporal grounding 直接在原始信号上定位证据，避免字幕/帧相似度代理丢失运动、状态变化与前后关系等关键信息。
4. **强实证效果**：在四个长视频基准上比等预算均匀采样最高提升 10.5 个百分点，并优于对比的帧选择与 agentic 方法。

## 🔧 方法/架构

- **分配策略规划（policy planning）**：在给定视觉 token 预算 $B$ 的条件下，规划全局/局部的 token 分配比例，输出一个决定"帧采样密度 + 分辨率"的可执行策略。

$$\text{Tokens} = \underbrace{n_{\text{global}} \cdot r_{\text{global}}}_{\text{全局覆盖}} + \underbrace{n_{\text{local}} \cdot r_{\text{local}}}_{\text{局部细节}}, \quad \text{s.t. } \text{Tokens} \le B$$

  即全局帧用稀疏数量 $n_{\text{global}}$ × 低分辨率 $r_{\text{global}}$，局部帧用稠密数量 $n_{\text{local}}$ × 高分辨率 $r_{\text{local}}$。

- **Temporal grounding 定位候选证据段**：不依赖字幕等有损代理，直接在时序上定位与问题相关的候选片段。
- **时序记忆精炼（temporal memory refinement）**：把候选片段收敛为一份紧凑的时序记忆，既保留证据又控制 token 开销。
- **双分辨率采样**：全局采用稀疏低分辨率帧保证时间覆盖广度，局部从精炼记忆中取稠密高分辨率帧保证细节。
- **联合推理（answerer）**：最终回答器同时接收分配的全局上下文与精炼后的局部证据。
- **免训练特性**：不需要额外的训练数据或模型微调，可直接作为推理管线套在现有多模态模型之上。

```math
\pi^* = \arg\max_{\pi \in \Pi} \; \mathbb{E}_{(V,q)}\left[\text{Acc}(V, q \mid \pi)\right], \quad
\text{cost}(\pi) = \text{tokens}(\pi) \le B
```

即在 token 预算约束下搜索分配策略 $\pi$ 以最大化下游问答准确率。

## 📊 实验结果

- **数据集**: LVBench、MLVU、VideoMME、LongVideoBench（四个长视频问答基准）。
- **基线**: 预算匹配的均匀采样（budget-matched uniform sampling）、所对比的帧选择方法、agentic 方法。
- **结果**:
  - 相比**等预算均匀采样**最高提升 **10.5 个百分点**（up to 10.5 percentage points）。
  - 在被比较的帧选择方法与 agentic 方法各自报告的基准上**更优**。
  - 摘要未给出各基准的逐项具体准确率数值（详见原文实验表格）。

## ⚠️ 局限性

- **免训练**意味着分配策略不是针对具体任务学出来的，跨域泛化能力依赖底层多模态模型本身。
- 摘要未给出**具体的绝对准确率数值**，只给出相对提升上限（10.5 pp），无法判断绝对水平。
- 依赖 **temporal grounding 模块**的质量；若定位偏了，局部高分辨率 token 就浪费在无关片段上。
- 需要额外的**时序记忆精炼**步骤，带来检索/后处理的额外延迟，摘要未量化这部分开销。
- 与所对比的 agentic 方法比较时，结论依赖各自报告的基准设置，跨论文直接对比需谨慎。
