### 核心贡献
1. 提出一条端到端的自动化 Video-to-QA 流水线，从视频流中抽取结构化摘要并生成高保真的问答（QA）对，无需人工标注。
2. 核心创新是 Self-Verification and Fine-Tuning Loop：先用 LLM 生成候选 QA 对，再回喂给同一模型做相关性与重要性的严格审核，只保留通过验证的高质量样本构成合成数据集。
3. 用该合成数据集以 LoRA 微调 Llama 模型，得到能生成领域对齐评测题目的专用模型，模型与代码分别发布在 Kaggle 与 GitHub。

### 技术方案
**核心思想**: 以「级联模型链」把视频转写、摘要、生成、验证、微调串成闭环，让模型自己产出训练数据并自我迭代改进，无需人工标注。

| 技术 | 说明 |
|------|------|
| 音频抽取 | 使用 FFmpeg 从视频流中抽取音频轨 |
| 语音识别 | 使用 Whisper（Python 库）生成准确转写稿 |
| 分段与摘要 | 受 LLM token 限制，转写稿先切块，再由 Facebook 的 BART 做分段摘要 |
| 生成模型 | meta-llama/Llama-3.1-8BInstruct，依据转写文本块生成候选 QA 对 |
| 自验证机制 | 将候选 QA 对回喂模型，评估其 relevance 与 importance，仅保留验证通过者 |
| 微调方式 | Low-Rank Adaptation (LoRA)，在合成数据集上微调 Llama-3.1-8B-Instruct |

### 实验结果
- **数据集**: 摘要未说明具体公开数据集；从视频（如 YouTube 教育/资讯视频）自建合成 QA 数据集
- **基线**: 摘要未说明对比基线（未给出基线模型或消融对照）
- **结果**: 摘要未给出定量数字；仅定性说明微调后模型可生成「domain-aligned assessment questions」，并实现无需人工数据标注的可扩展自我改进教育工具

### 局限性
- 摘要未提供定量实验结果与人工评测对比，可靠性难以量化
- 依赖 FFmpeg/Whisper/BART/Llama 级联，任一环节（尤其 ASR 误差）都会向下游传播
- 摘要未说明对视频画面（视觉信息）的利用情况，处理可能仅基于音频转写文本

### 关键洞见
> 「让模型审核模型自己生成的训练数据」这条自举回路——先用 Llama-3.1-8B 产出候选 QA、再让它自己筛掉低质样本、最后用这一份纯化后的数据 LoRA 微调同一个模型——把「数据标注」这一瓶颈从流程中整个抹掉了，让 QA 生成从一次性任务变成了可自我迭代的闭环。
