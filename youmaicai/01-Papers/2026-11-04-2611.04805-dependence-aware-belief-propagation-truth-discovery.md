## 核心贡献
1. **诊断了经典 truth discovery（TD）在 LLM agent 场景下的结构性失效**：经典 TD 与 Dawid–Skene 依赖"源在给定真值下条件独立"这一假设，因此**一致性即正确性证据**。但部署中的 agent 常常是同一基座模型的变体（prompt persona、自一致性采样、RAG wrapper），错误高度相关——**依赖性把经典估计器的排序彻底颠倒**。
2. **提出 BP-TD**：在一枚硬币 Dawid–Skene 模型的均值场变分推断中加入**逐 agent 去相关权重 $w_a$**，使共享基座模型的 agent 合计约等于**一票**。
3. **BP-TD 的第一轮迭代精确等于加权投票**：初始化时所有 agent 的先验可靠性相同，式 (1) 退化为 $\log b_q(v)=c_q+\kappa\sum_{a\in A_q}w_a\mathbb{1}[y_{aq}=v]$；当 $w_a\equiv1$ 时就是多数投票。**迭代本身贡献的是可靠性估计**，不是答案。
4. **在 MMLU 上以无标签方式超过多数投票**：13 个本地 agent、160 题上 **BP-TD 0.716 vs. 多数投票 0.624**；10,000 题上 **0.707 vs. 0.674**。而 Dawid–Skene、Investment、SSTF-VI **显著低于**多数投票。
5. **可靠性排序的翻转**：MMLU 全 160 题上 BP-TD 的估计可靠性与真实准确率的 Spearman 相关 **ρ=+0.94**（bootstrap 95% CI [0.75, 1.0]），而 Dawid–Skene、CRH、agreement frequency 分别为 **−0.62、−0.62、−0.58**——**它们把弱的 llama3.2 集团排在最前**。
6. **找到了核心的"体制性规律"（regime finding）**：跨 **2,852 个子池**（四个基准），去相关在**最大相关集团比其他 agent 更弱时有效**，在**它是最强时有害**。并且**找不到任何无标签统计量能区分这两种情形**（AUC 0.53–0.67 / 0.48–0.85，合并后 0.53 与 0.51）。
7. **证明"标签比聚合更划算"**：只要 **20 个标注问题**，直接选最好的单个 agent 在 MMLU、ARC、TruthfulQA 上就比所有被测聚合器都准；**5 个标注**就能在 MMLU 上超过 label-free 的 BP-TD。
8. **揭示了 truth-aware 依赖信号的循环性**：`shared_error`（按"共享错误"定义依赖）恰好在依赖集团占多数时失效——因为该集团定义了当前的真值估计，看起来"不共享错误"从而逃过折扣；这是"用被污染的共识去判断谁相关"的循环。

## 问题背景
给多个 LLM agent 问同一个事实性问题，常会得到多个不同答案。LLM agent 被接入流水线、辩论与混合系统后，这种分歧不再是奇闻而是**运维问题**：系统必须给出一个答案，最好是正确的，而且最好**不必为每一步都支付金标标签的成本**。决定信谁正是 truth discovery——一个有两十年理论积累的数据质量问题（针对冲突的 Web 来源与众包工人）。这些理论能否迁移到 AI agent、何时能迁移，从未被刻画。

**核心 gap**：经典 TD 建立在"源在给定真值下条件独立"的结构性假设上，于是"一致"就是"正确"的证据。而这个假设对 AI agent 被系统性地违反，原因是 agent 特有且普遍的：**部署的 agent 常常是同一基座模型的变体**——prompt persona、自一致性样本、或包在同一个 LLM 外的检索 wrapper——于是它们的错误强烈相关。于是"按一致性估可靠性"会奖励一个可能自信且一致地错误的相关集团，标准 TD 机器**完全颠倒**：它会把一致但错误的多数排成最可靠。

## 方法
### 1. 问题形式化
给定 agent 集合 $\mathcal{A}=\{a_1,\dots,a_m\}$ 对问题集合 $\mathcal{Q}=\{q_1,\dots,q_n\}$ 的回答，每个问题 $q$ 有已知有限答案集 $\mathcal{V}_q$（$|\mathcal{V}_q|$）。每个 $(a,q)$ 对，agent $a$ 或断言单个值 $y_{aq}\in\mathcal{V}_q$，或弃权；$\mathcal{A}_q\subseteq\mathcal{A}$ 是回答了 $q$ 的 agent。目标是在**无金标标签**下推断 (i) 潜在真值 $t^*_q\in\mathcal{V}_q$，(ii) 每个 agent 的标量可靠性 $r_a\in[0,1]$（作为**相对排序分数**，不是校准过的正确概率——BP-TD 恢复的是排序而非量值）。

观测被表示为**三部图**（agent–question–value）：节点是 agent、问题与候选值，边 $(a,q,v)$ 存在当且仅当 $y_{aq}=v$。这使推断结构显式化：信念从 agent 流向问题（哪个值可能为真），再从问题流回 agent（每个 agent 有多可靠）。

### 2. 一枚硬币观测模型与变分消息传递
以概率 $r_a$ 发出真值，否则从 $|\mathcal{V}_q|-1$ 个错误选项中均匀抽取。对每个 $r_a$ 置 $\text{Beta}(\alpha_0,\beta_0)$ 先验，均值场变分推断在问题信念 $b_q(\cdot)$ 与可靠性 $r_a$ 上因子化后验，交替两个闭式更新：

$$\log b_q(v) \propto \sum_{a\in\mathcal{A}_q}w_a\Big[\mathbb{1}[y_{aq}=v]\,\mathbb{E}\log r_a + \mathbb{1}[y_{aq}\neq v]\big(\mathbb{E}\log(1-r_a) - \log(|\mathcal{V}_q|-1)\big)\Big] \tag{1}$$

$$\alpha_a = \alpha_0 + \sum_q b_q(y_{aq}), \qquad \beta_a = \beta_0 + \sum_q\big(1-b_q(y_{aq})\big) \tag{2,3}$$

**直觉**：式 (1) 是一个加权投票——每个回答的 agent 给它断言的值加 $w_a\mathbb{E}\log r_a$，给 $|\mathcal{V}_q|-1$ 个竞争值加较小的 $w_a\mathbb{E}\log(1-r_a)-\log(|\mathcal{V}_q|-1)$；可靠 agent 更用力地推自己的答案，而 $w_a$ 缩小依赖 agent 的影响。式 (2)-(3) 是共轭 Beta 记账：$\alpha_a$ 累积"落在 a 所选值上的信念质量"，$\beta_a$ 累积互补质量，因此 $\mathbb{E}[r_a]=\alpha_a/(\alpha_a+\beta_a)$ 对与自信共识一致的 agent 上升。设 $w_a\equiv1$ 就退化为 one-coin Dawid–Skene / SSTF-VI。

**为什么 $w_a$ 能缓和似然**：权重不属于生成模型，它们在式 (1) 中作为每个 agent 的似然项的**指数**进入，构成**复合（幂）似然**：当 $k$ 个 agent 近乎互为副本时，它们 $k$ 个似然项的乘积把同一份证据数了 $k$ 次，而把每个抬到 $1/k$ 次幂就大致恢复为一份证据的量。

### 3. 第一轮 = 加权投票
初始化时所有 agent 先验可靠性相同，故 $\mathbb{E}\log r_a$ 与 $\mathbb{E}\log(1-r_a)$ 是对所有 $a$ 相同的常数，式 (1) 给出 $\log b_q(v)=c_q+\kappa\sum_{a\in\mathcal{A}_q}w_a\mathbb{1}[y_{aq}=v]$，$\kappa=\mathbb{E}\log r-\mathbb{E}\log(1-r)+\log(|\mathcal{V}_q|-1)>0$。**第一轮按 $w_a$-加权 plurality 精确排序**；单轮（$T=1$）即预测加权投票，$w_a\equiv1$ 时即多数投票。**可靠性估计从第二轮起才影响预测答案**。

### 4. 三种依赖集团定义
- **family（结构性）**：共享基座模型家族的 agent 构成一簇，$w_a=1/|\text{family}(a)|$。只需 provenance，无需观测答案，最便宜、无标签、固定。
- **cooccur（经验、无真值）**：在带符号共现图上按超阈值邻居数折扣，$w_a=\frac{1}{1+|\{b:\text{agree}(a,b)\ge\theta\}|}$——与 $k-1$ 个其他 agent 一致的 agent 约计 $1/k$ 票。用答案矩阵但不用任何真值估计。
- **shared_error（真值感知）**：仿照"共享错误值"的拷贝检测，把"在一组很可能错的答案上达成一致"的 agent 聚成一簇，每轮用当前信念 $b_q$ 重算。原理上最有力，但**在依赖集团占多数时循环失效**。

### 5. 算法与变体
- **阻尼**：$b_q\leftarrow0.7b^{new}_q+0.3b^{old}_q$。
- **可靠性平滑**（在带符号一致图 $W$ 上，权重 $\lambda=0.4$）：$\bar r_a\leftarrow\frac12+(1-\lambda)(\bar r_a-\frac12)+\lambda\frac{\sum_b W_{ab}(\bar r_b-\frac12)}{\sum_b|W_{ab}|}$——与可靠 agent 一致、与不可靠 agent 不一致的 agent 获得更高可靠性。去掉平滑（$\lambda=0$）使全集 MMLU 准确率变化 <0.013。
- **收敛**：最大信念变化 <10⁻⁴ 停止（最多 100 轮）；SciQ 在 $\theta=0.2$ 时平均 93 轮（接近全体一致处收敛慢）。
- **半监督 seeding**：把一部分问题钳到已知答案，只在 $Q\setminus S$ 上评测。
- **复杂度**：每次迭代真值更新 $O(|\mathcal{E}|\bar{|V|})$、可靠性更新 $O(|\mathcal{E}|)$、依赖步 $O(m^2)$（cooccur/shared_error）或 $O(m)$（family）；总计 $O(nm\bar{|V|}+m^2)$ 每次迭代。
- **发布**：实现、全部基线、采集的 agent 答案（含基座 provenance）、agent prompt 与 persona 文本、划分种子，发布于 GitHub 与 Zenodo（DOI 10.5281/zenodo.23916537，v2.0.0，MIT 许可）；所有数字可在 CPU 上从缓存答案重算，无需重新查询模型。

- **Ablations / 分解**:
  - **权重 vs 迭代**：one-pass 与 loopy cooccur（θ=0.5）在每个基准上相差 ≤0.007（p>0.75）；family 权重下最大差 0.013（TruthfulQA）。迭代只在 MMLU 上调参 θ 时才提升（0.751 vs 0.715，不显著）。**关键反例：没有去相关时迭代有害**——BP-TD none 从 0.624（一轮，等于多数投票）跌到 0.513（18 轮后），因为可靠性更新会奖励大而弱的 llama3.2 集团。带符号可靠性平滑对全集 MMLU 准确率的影响 <0.013。
  - **软权重 vs 硬分组**：θ=0.5 时 MMLU 上的共现集团**恰好等于基座模型家族**（纯粹从答案恢复出来）。用相同集团，软加权投票胜过把每组塌缩为内部多数决的一票的 ClusterVote：**0.716 vs 0.672（+0.043, p=0.017）**——软权重保留组内分裂为分数票并能打破组间平局。
  - **阈值 θ**：MMLU 上增益在 θ∈[0.4,0.6] 平坦于 +0.10，θ=0.7 峰值 +0.16，θ=0.9 转负（只有近乎同一的 agent 才被分组，弱集团重新压过其他）。**无标签的 Otsu 规则在 MMLU 上选 θ=0.61，正好落在平台区**。固定 θ=0.5 或 Otsu 相对用 80 个标签调 θ 在 MMLU 上损失约 0.035，但**用极少标签调参反而更差**（2/5/10 个标签分别得 0.600/0.637/0.669，都低于无标签 Otsu 的 0.713；需约 40 个标签才超过）。
  - **体制规律（子池研究）**：每基准 713 个子池（378 个随机子池 + 335 个构造子池）。当最大集团较弱时，BP-TD family 在 **98%** 的随机子池上超过多数投票（MMLU，中位 +0.10），ARC 上 **87%**（中位 +0.04）；当最大集团最强时，MMLU 上在 **84%**（随机）/ **87%**（构造）子池中**输给**多数投票（中位 −0.03 / −0.05），ARC 上 **77%** / **94%**。
  - **受控压力测试（强集团）**：给全池加 $k$ 个最强 agent（qwen2.5:14b，10% 答案替换为随机错项）的带噪副本。MMLU 上多数投票从 0.612 升到 **0.808**（$k=10$，副本多数是对的），BP-TD family 稳在 **0.71–0.72**（把副本当一组折扣），未折扣的 BP-TD none 达 **0.825**。**去相关是针对弱主导集团的正确修正、针对强主导集团的错误修正。**
  - **受控压力测试（错集团）**：在 ARC 答案上追加 $k$ 个都给出相同错误答案的合成 agent。多数投票与 BP-TD none 在集团成为多数时崩塌；BP-TD family 在集团共享基座时**不受影响（各 $k$ 下 ≈0.86）**，集团隐藏 provenance 时 BP-TD cooccur 仍能恢复真值（≈0.72）；**truth-aware 的 shared_error 权重全程失败（≈0.46）**。
  - **可靠性恢复**：MMLU 全 160 题上 Spearman ρ=**+0.94**（95% CI [0.75, 1.0]）vs. Dawid–Skene −0.62、CRH −0.62、一致频次 −0.58。40 个 80 题测试半上 BP-TD cooccur 为 0.86 ± 0.09（最小 0.63），Dawid–Skene 为 −0.65 ± 0.05。ARC 上 BP-TD family 为 0.91 ± 0.05。SciQ 与 TruthfulQA 上估计在划分间的方差与均值相当，**无法恢复排序**。规模上（5,000/10,000 题）相关降为 0.75 与 0.68，但所有基线仍为负。
  - **经典估计器在独立 agent 上是有效的**：合成数据（13 个独立 agent，准确率 0.30–0.92）上 Dawid–Skene/LTM 超过多数投票（160 题 0.992 vs 0.978；1,000 题 0.992 vs 0.973），BP-TD none 亦然。**它们在 MMLU 上的崩塌是数据造成的**：Dawid–Skene 的答案在 98.8% 的问题上与六个 llama3.2 agent 的 plurality 一致，而那个 plurality 只有 47% 是对的。同一独立 agent 池上 BP-TD cooccur 略降（0.983）——**为"因为正确而一致"的 agent 付折扣的代价**。
  - **分歧度**：MMLU 内相对多数投票的增益随逐题分歧度上升（四个四分位：+0.00、+0.00、+0.125、+0.275）；TruthfulQA 内从不为正；SciQ 内平坦。**MMLU 与 TruthfulQA 的平均带符号一致度几乎相同（0.33 vs 0.35），所以决定结果的不是"agent 有多一致"，而是"它们的共同答案指向真相还是背离真相"。**
  - **标签预算**：用 $k$ 个标注问题选最佳 agent，在 MMLU 上 $k=5$ 即超过 BP-TD family，ARC 上 $k=20$；TruthfulQA 上 $k=5$ 超过多数投票；SciQ 上所有差异 <0.015。**用同样少量标签去调 θ 是糟糕的用法**（见上）。**Seeding**（钳位 1–20% 的问题到金标）对剩余问题准确率的影响 ≤0.001（MMLU/SciQ）、0.01（ARC）、0.02（TruthfulQA）——每个 seed 只给可靠性计数加一次观测，太少。
  - **无标签诊断失败**：在 2,852 个子池上测试两个候选统计量（最大集团的 plurality 与其他 agent 的 plurality 的一致度；BP-TD 改变多数投票答案的问题比例），**均不能区分 BP-TD 有益与有害的子池**：AUC 每基准 0.53–0.67 与 0.48–0.85，合并后 0.53 与 0.51。

## 关键洞察
1. **"一致性即正确性"这条 TD 经典假设在 agent 场景下被系统性违反，且违反是结构性的**：相关集团可以自信且一致地错误，于是经典估计器不仅不降级，反而**把排序完全颠倒**（Dawid–Skene ρ=−0.62）。这不是实现问题——同样的实现在独立 agent 上是有效的（合成数据上 0.992 vs 0.978）。
2. **降相关是"体制相关"的，不是"方法相关"的**：跨 2,852 个子池，BP-TD 在最大相关集团较弱时在 98% 的随机子池上获胜，在它最强时在 84% 的子池上落败。**这个结论不限于 BP-TD**——任何"给一组互相一致的 agent 打折"的规则，在该组正确时都要付出同样的准确率代价。作者明确把"这是方法与池的共同性质"作为核心结论。
3. **无标签场景无法预判方向，这是当前的主要开放问题**：两个预先选定的候选统计量 AUC 均在 0.5 附近。因此实践建议是：**要么接受风险，要么花几个标签直接选 agent**。
4. **迭代只有在有去相关时才有意义**：BP-TD none 从 0.624 掉到 0.513，因为纯 Dawid–Skene 式可靠性更新会奖励大而弱的集团。这说明"可靠性估计"这个模块本身是有害的，除非先修正依赖结构——这纠正了"加个可靠性模型总会更好"的直觉。
5. **软权重优于硬分组**（+0.043）：把一组 agent 塌缩成内部多数决的一票会同时丢掉组内分裂信息和组间打破平局的能力；保留分数权重能同时保留两者。
6. **truth-aware 的依赖信号在数学上无法用于它想解决的问题**：`shared_error` 用当前信念定义"共享错误"，而多数派集团定义了信念本身，于是它看起来不共享错误。这提示任何"检测谁在犯同样的错"的方法必须避免使用被污染的共识作为参照——`cooccur`（原始一致度）与 `family`（provenance）之所以稳健，正是因为它们从不查询 bloc 定义的真相。
7. **最实用的结论可能是"别聚合，选 agent"**：20 个标注问题在所有三个基准上就超过所有被测聚合器；5 个标注就超过 label-free 的 BP-TD。BP-TD 的价值集中在**完全无标签**的场景，或需要**审计 agent 可靠性**（而非回答问题）时。
8. **"agent 越像，票越该合并"的直觉是对的，但合并粒度要看基础模型家族**：θ=0.5 时纯从答案恢复出的共现集团恰好等于基座家族，说明答案共现结构确实携带了依赖信息。

## 局限性
- **基准与规模有限**：体制结论基于四个基准，其中只有 MMLU 做了规模收获；SciQ 与 TruthfulQA 未做。所有 agent 都是本地开放模型（最大 14B），未测试更大的 API 模型——它们冗余度可能更低。
- **头条增益依赖特定池构成**：池的最大集团偏弱（MMLU 上 llama3.2 集团准确率最低）。作者明确把这一条列为局限。
- **没有无标签诊断**：找不到判断去相关是否有帮助的无标签方法；这是主要开放问题。
- **依赖模型是启发式的**：$w_a$ 是似然的幂次缓和（tempering），**不是依赖性的生成模型**；作者指出真正的生成模型（如潜在 bloc 变量）会替代这一启发式修正，留待未来工作。`shared_error` 在依赖集团占多数时失效。
- **污染问题**：基座模型很可能见过这些基准。所有聚合器拿到相同答案，因此污染不对某个聚合器有利，但会改变答案矩阵本身——若某家族的模型记住了相同题目，它们的错误更共享，而这正是体制分析所依赖的变量。**TruthfulQA 的结果可能部分反映污染而非其对抗性设计。**
- **可靠性是排序分数而非校准概率**：BP-TD 恢复排序不恢复量值。
- **CARE 与 ISP/OW-I 的比较存在实现局限**：CARE 的结构学习需要可逆的 judge 相关矩阵，而池中含答案完全相同的 agent 使矩阵奇异，官方求解器在多数划分上无解（MMLU 上 520 次求解仅 341 次成功），故加了 ridge (10⁻³I)；ISP 与 OW-I **无公开代码**，由作者按论文公式自行实现，二阶统计量由答案共现估计。
- **BoolQ 试验不成立**：13 个 agent 中有 11 个没看到任务所需的 passage，因此作者自己声明它不是有效的闭卷测试。
- **半监督 seeding 基本无效**（影响 ≤0.02），因此"少量标签 + 聚合"这一路径未成立。
- **单一作者、单机环境**：全部 agent 本地 Ollama 服务，作者声明用 Claude 自动化实验（但科学贡献、算法、数据分析与结论主张均为作者本人）。
- **复合似然的理论保证缺失**：作者未给出幂次缓和似然的收敛性或最优性分析（只说闭式坐标上升对复合目标仍成立）。

## 适用场景
- **多 agent 系统的无标签答案聚合**：当 agent 池中包含同一基座模型的多个变体（persona、自一致性、RAG 包装），且最大相关集团偏弱时，BP-TD 能在不给标签的前提下超过多数投票，并给出 agent 可靠性排序用于审计。
- **agent 可靠性审计**：即使不用于答题，BP-TD 的可靠性估计（Spearman ρ=+0.94）是经典估计器的镜像反面（−0.62），可用于发现"一致但错"的集团。
- **模型路由 / agent 选择的先验**：BP-TD 估计的可靠性可作为 agent 选择的排序依据，再配合少量标签做最终选择。
- **诊断"一致性陷阱"**：若怀疑某个流水线里的多数意见被同源模型绑架，可用 family 或 cooccur 权重做敏感性分析。
- **大池的可扩展性**：$O(nm\bar{|V|}+m^2)$ 每次迭代，10,000 题单轮 <1 秒 CPU。

**不适用**：最大相关集团本身最强的池（去相关会主动损害准确率，此时应直接选最强 agent）；需要判断"该不该用聚合"的场景（无标签诊断失败）；输出型（开放式）答案（模型假设为有限答案集 + 断言或弃权）；闭源 API 大模型池（冗余度可能低，结论未验证）；污染严重的基准解读。
