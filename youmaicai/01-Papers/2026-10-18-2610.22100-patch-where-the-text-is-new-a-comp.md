## 核心贡献

> Byte-level LM (如 BLT) 用 small-model next-byte entropy 起 patch，但**错过 inline computed results**（如 worked solution 里 "=" 后的数字）→ 在 tight patch budget 下 accuracy collapse。提出 **Novelty patching** —— **LZ77 启发**的 lookup table over previous 2 bytes，起 patch 在 "upcoming bytes unlikely to repeat recent context"。无需 labels / reference model / loss，秒级 fit raw text。BLT-style 50M 模型上 computed-result accuracy 21% → **57%**；final-answer 60% → **90%**。

1. **新 patch routing 规则**：Novelty = lookup over previous 2 bytes, no training required。
2. **强结果**（1.9 GB math corpus, ~11% patch rate, 3 seeds）：
   - 1M：无明显效果
   - **12M**：final-answer 47% → 72%
   - **50M**：computed-result 21% → **57%**，final-answer 60% → **90%**
3. **关键优势**：表从 raw pretraining corpus 直接 fit，无 labels → **保留 gain**（无 overfitting 风险）。
4. **分析**：entropy-based rules 在 computed results 上**最差**（boundary enrichment 1.61, 即边界偏向高 surprisal 但错过 computed result），novelty 在 near-chance enrichment → 优。

## 技术方案

### Byte-Level LM 的 Patch Routing

#### BLT 现状

- Byte Latent Transformer：每个 patch 调一次 large global model；patch start 由 small-model next-byte entropy 高触发
- 问题：起 patch 不在 inline computed results → 在 tight budget 下 accuracy collapse

### Novelty Patching

#### 思想

- **LZ77-style compression 视角**：在 "upcoming bytes unlikely to repeat recent context" 处起 patch
- 隐含假设：**新内容开始 = 真正需要 compute 的地方**

#### 实现

- **Lookup table over previous 2 bytes**
- 2 bytes context + 1 byte lookahead → **判断是否 unlikely-to-repeat**
- **Fitted in seconds on raw text** with:
  - ✅ No labels
  - ✅ No reference model
  - ✅ No losses
  - ✅ Simple count statistics

#### 应用

- BLT-style model trained from scratch
- Replace entropy-based patcher with novelty table

### 实验设计

- Corpus: **1.9 GB math**
- Patch rate: **~11%** (matched across rules)
- Models: **1M / 12M / 50M** parameters
- Seeds: **3 each**
- Compared to: entropy-based patcher (BLT default), various others

## 实验结果

### Math Reasoning (1.9 GB math corpus)

| Model Size | Metric | Entropy (BLT default) | Novelty (this paper) |
|-----------|--------|-----------------------|---------------------|
| 1M | final-answer | baseline | no clear effect |
| **12M** | final-answer | 47% | **72%** |
| **50M** | computed-result | 21% | **57%** |
| **50M** | final-answer | 60% | **90%** |

→ Patch routing 规则选择对 byte-level LM 在**强推理 task** 上**至关重要**。

### Cross-Domain

| Domain | Novelty vs Entropy |
|--------|-------------------|
| **Math** | **Novelty 强优**（computed result 显著 gain） |
| Prose | Novelty 降低 bits per byte (bpb) |
| Source code | tie entropy |
| Synthetic execution traces | tie entropy |

→ Novelty 优势主要在 written math（computed results + segment starts near computation）。

### 分析：Boundary Enrichment

- **Entropy**：boundary enrichment **1.61**（boundary 强烈偏向高 surprisal bytes）→ 在 computed results 上**最差**
- **Novelty**：boundary enrichment **near chance** → 在 computed results 上**显著优**

→ Novelty 在 "computed result 与 computation 起点接近" 的 domain（written math）特别有效。

### H-Net (Learned Chunker)

- H-Net **learned chunker 自己发现** 在 math 和 code 中的该结构 → 与 novelty table **类似行为**
- → 印证 novelty 捕捉的 structure 是**真实存在**的

### What Didn't Work（消融）

- ❌ Typed uncertainty as training rule
- ❌ Switching rules after training
- ❌ Context-aware novelty predictor（仍胜 novelty table，但 gain 减少）

→ Simple lookup table 是 sweet spot：simple + effective + no overhead。

## 局限与展望

- 仅 1.9 GB math corpus → 更大 scale (1 TB+) 未验证。
- Novelty table over previous 2 bytes 是 hardcoded → optimal context length 未知。
- 在 multi-lingual / multi-script corpus 上的 generalization 未测。
- "Computed results" 检测是否可 generalize（non-math 领域少见）。
- 与 H-Net 等 learned chunker 的**深度结合**未探索。

## 实现建议

- **实现难度**: 低（实现 lookup table + count statistics）
- **预期性能**: math 推理 task 上 **+20–30 pp**
- **适用场景**:
  - **Math reasoning byte-level LM**（computed result 关键）
  - **Code LM**（symbol / identifier boundaries）
  - **低成本 patch routing**（无需训练）
- **不适用**:
  - 纯 prose 任务（entropy 已 sufficient）
  - 已有 learned chunker 的场景（H-Net 更灵活）
- **工程提示**:
  - 2-byte context 是 sweet spot；1-byte 太粗糙，3+ 收益下降
  - Table **可缓存**（GB-level corpus 几十 MB table）
  - 与 BLT 框架**易集成**（仅替换 patcher）

---

## 一句话总结

Novelty patching 用 LZ77 启发的 2-byte lookup table 取代 entropy-based patch routing，**无需训练**就在 byte-level LM 上大幅提升 computed result / final-answer 准确率（50M 模型 final-answer 60% → 90%），揭示 patch routing 规则对 byte-level 推理能力的**关键性**。
