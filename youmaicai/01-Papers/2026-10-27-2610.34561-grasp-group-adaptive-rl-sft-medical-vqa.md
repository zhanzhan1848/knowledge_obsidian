## 核心贡献

> **只靠短答案也能把 SFT 与 RL 合到同一次更新里**：GRASP 用「模型自己的推理 + gold 答案」做 SFT 监督、用组准确率自适应加权 λ(p)=0.4(1−p)，配合 GSPO-EGC 修正全错/全对组；仅调 **1.17% 参数**（102.7M LoRA）、在 **12.9K** 短答案上训练，OOD 开放式 EM 达 **27.3%**，超过 10 个通用/医学 VLM（含训练数据多 2,600 倍或可训练参数多 250 倍的模型，最优基线 ≤21.6%）。

1. **同时 RL-SFT 混合（simultaneous hybrid）** — 在**同一批 rollout** 上同时施加 RL 与 SFT 信号，不需要任何 reasoning annotation；SFT 分支保留 rollout 自己的推理（mask 0），只在其后 teacher-force gold 答案（mask 1）上算 token-averaged cross-entropy
2. **GSPO-EGC（extreme-group correction）** — 用 batch 级标准差归一化 group-relative advantage，并对全错（p=0）/全对（p=1）组按 c(p)=κ·(s_t/G)·(p−μ_t) 修正优势；μ_t 是组准确率的 EMA，s_t 是 A^rel 的均方根 EMA；κ=1
3. **组自适应权重** — λ(p)=λ_max(1−p)^γ，λ_max=0.4、γ=1：全错组拿最大权重、全对组拿 0，防止交叉熵持续锐化模型已会答的问题的答案分布
4. **奖励设计** — R = 1.0·r_EM + 0.2·r_syn（Bio_ClinicalBERT BERTScore 同义词部分分）+ 0.4·r_img（BiomedCLIP 图-推理一致性）+ 0.5·r_fmt（结构/重复/截断惩罚），**主信号是 exact match，无需 LLM judge**
5. **MedTerse 数据集** — 从 PathVQA / SLAKE / VQA-RAD 训练集 + GMAI-MMBench 验证集筛出并重写为直问的 **12,893 个 1–3 词短答案问题 / 5,446 张图**，全部无 reasoning annotation；同时发布 **8 种影像模态、11,575 题**的 OmniMedVQA 开放式 OOD 集
6. **超越 10 个医疗 VLM** — OOD 开放式 EM：GRASP-InternVL **27.3**、GRASP-Qwen **25.5**，击败 Fleming-VL-8B（16.9）、MedGemma-27B（15.3）、Lingshu-7B（18.5）等全部 10 个基线；GRASP-Qwen 比其 base model 提升 **+9.6pp**，而训练数据少最多 2,600 倍、可训练参数少 40–260 倍
7. **三 backbone 通用** — InternVL3-8B 上比所有单信号/staged 对照领先 **5.7–6.9pp**（域内）/ **2.3–4.8pp**（OOD 开放式）；Gemma 3-4B 上领先 **5.2–7.5pp** / **4.8–7.8pp**
8. **消融定位每个组件的价值** — 去掉「自己的推理」损失最大（域内 −4.1pp / OOD −2.4pp）；exclusive switch（近似同预算）−3.8pp；constant λ=0.2 −3.4pp；去掉 EGC −2.7pp；去掉 r_syn −2.5pp；去掉 r_img −2.8pp

## 技术方案

### 核心思想

医学 VQA 的现实约束有两个：**标注数据稀缺**（隐私与成本），且**标注只有几个词的短答案，没有 reasoning annotation**。这让两条标准后训练路线各有一半失败：

- **SFT** 学得快、域内贴合好，但过拟合标签并放大偏差，OOD 泛化被侵蚀（本文测得 OOD yes/no balanced accuracy 从 base 的 63.6% 掉到 47.1%）
- **RLVR（GRPO/GSPO）** 保泛化，但**从不把 gold 答案当训练目标**：它只在组内对错答案之间学对比。当 8 个 rollout 全错或全对时，正确性信号为零

已有 SFT-RL 混合方案各有缺陷：staged（SFT→RL）会让 RL 冲掉 SFT 学到的；switched（HPT）按题选一种信号，部分解决的题被抽走监督、未解决的题拿不到 RL；需要专家 reasoning trace 的（LUFFY/SRFT）医学数据根本没有；gold injection（ViSurf）把裸答案塞进 rollout 组，会**教模型跳过推理**。

GRASP 的核心洞察是：**RL 和 SFT 其实在回答两个不同的问题**。RL 缺的是「正确答案是什么」这一直接监督；SFT 缺的是「不要用专家轨迹、保留模型自己的探索」。于是——**在同一批 rollout 上，RL 学模型自己的推理，SFT 在模型自己的推理之后教 gold 答案**。推理部分 mask 掉不算 loss，只有答案段计入交叉熵。这样既不需要 reasoning annotation，也不破坏 reason-then-answer 的行为结构。

第二个洞察是**监督的落点比监督的量更重要**。全错组的 RL 修正只会把采样到的错答案往下压，永远不知道正确答案在哪；全对组已经答对，不需要再监督。所以 SFT 权重应该**随组准确率下降**——λ(p)=λ_max(1−p)。消融证实了这点：把权重改成常数 λ=0.2（总预算相近）掉 3.4pp，而 exclusive switch（预算几乎相同）掉 3.8pp。

第三个洞察是**全错/全对组不该被丢掉**。DAPO 直接丢弃极端组，导致永不被解的题完全没有梯度；而全错组其实还有一个可利用的信号——组正确率 p 与模型**running accuracy μ_t** 的比较。当模型通常答得对时，一个全错组是异常，应被更重惩罚；当正确率仍稀有时，一个全对组值得更多奖励。这个修正 c(p)=κ·(s_t/G)·(p−μ_t) 本质上是**只施加于极端组的经验贝叶斯式收缩**（作者引用 EBPO），1/G 因子保证一组内修正总量等于一个 rollout 的优势，跨 batch 两侧大体抵消、均值近零。

### 关键技术

| 技术/方法 | 说明 |
|------|------|
| GRASP | Group-adaptive Reinforcement with Answer Supervision on self-generated reasoning Paths |
| 同时混合损失 | L = L_RL/s_RL + λ(p)·L_SFT/s_SFT + β·D_KL[π_θ‖π_ref]，RL 作用于每个组，SFT 在 p<1 时并发作用 |
| Own-reasoning SFT | 保留 rollout 自己的 z_i 作为上下文（mask 0），只监督 `<answer>a*</answer><eos>`（mask 1） |
| GSPO-EGC | 极端组优势修正 c(p)=κ(s_t/G)(p−μ_t)；κ=1，μ_t 与 s_t 均为 EMA |
| Batch 级奖励归一化 | A^rel=(R−R̄)/(σ_batch+ε)，避免极端组只靠辅助奖励差异被放大成噪声 |
| 序列级重要性比 | ρ_i = exp((1/|y_i|)Σ log(π_θ/π_old))，GSPO 的 geometric-mean token ratio |
| λ(p) 调度 | λ_max=0.4、γ=1；k/8 正确的组得 0.4(1−k/8) |
| 复合奖励 | EM 1.0 + BERTScore(同义词) 0.2 + BiomedCLIP(图-推理) 0.4 + format 0.5 |
| LoRA | rank-32，挂在 vision encoder 与 LLM，Qwen3-VL-8B 上 102.7M 参数 = **1.17%** |
| MedTerse 构造 | DeepSeek-V4 重写依赖选项的题目为直问；歧义与过宽问题（如 "What is present?"）丢弃 |
| OmniMedVQA OOD 集 | 8 模态，11,575 题短答案，gold 从 option labels 复制并校正 |
| LLM judge 校验 | DeepSeek-V4.1-Flash 判语义等价；两名医师盲标 200 对，一致对上 judge 与医师吻合 **93.9%**（Cohen's κ=0.87） |

### 实验设置

| 维度 | 规模 |
|------|------|
| 主 backbone | Qwen3-VL-8B-Instruct（另测 InternVL3-8B、Gemma 3-4B） |
| 可训练参数 | 102.7M（1.17% of Qwen3-VL-8B），rank-32 LoRA |
| 训练数据 | MedTerse 12,893 题 / 5,446 图 |
| 域内评测 | 6,600 题（held-out val + PathVQA / SLAKE / VQA-RAD 官方 test） |
| OOD 评测 | OmniMedVQA 11,575 题 / 8 模态（CT、X-ray、MRI 等） |
| 外部集 | Kvasir-VQA（内镜）、VQA-Med 2020（细粒度诊断） |
| 训练超参 | G=8 rollout、temperature 1.15、12 题/step、lr 2e-5、cosine、2 epoch；一次 GRASP run ≈ **81 GPU-hours**（4×A100 约 20 小时） |
| 基线 | 7 个训练目标（SFT / GSPO / GSPO-EGC / staged / HPT switch / ViSurf / RFT）+ 10 个已发布通用与医学 VLM |
| 指标 | 归一化 exact match（EM）、LLM judge 语义准确率、OOD yes/no balanced accuracy（93% 答案为 no） |

## 实验结果

### 训练目标对比（Qwen3-VL-8B，EM %）

| 目标 | 类型 | 域内 Open | 域内 All | OOD Open | OOD All |
|------|------|------|------|------|
| Zero-shot | – | 15.2 | 51.9 | 15.9 | 25.6 |
| SFT | single | 32.9 | 62.5 | 22.9 | 47.1 |
| GSPO | single | 26.3 | 60.4 | 22.8 | 60.8 |
| GSPO-EGC | single | 29.5 | 62.2 | 24.2 | 61.7 |
| SFT→GSPO-EGC | staged | 33.1 | 63.9 | 23.0 | 62.6 |
| HPT switch | switch | 36.2 | 68.7 | 24.2 | 68.3 |
| ViSurf | inject | 37.0 | 69.3 | 22.7 | 59.8 |
| RFT | self | 16.7 | 53.7 | 17.0 | 64.5 |
| **GRASP** | **simult.** | **40.0** | **71.9** | **25.5** | 28.6 |

> 三种子平均：GRASP 在域内领先 SFT 与 GSPO **6.4–14.4pp**，OOD 开放式领先 **2.4–2.6pp**，标准差 ≤0.3。

### 消融（Qwen3-VL-8B，EM %）

| 变体 | 域内 Open | Δ | OOD Open | Δ |
|------|------|------|------|------|
| **GRASP (2 ep.)** | **40.0** | — | **25.5** | — |
| answer only（不用自己的 z） | 35.9 | −4.1 | 23.1 | −2.4 |
| exclusive switch（HPT） | 36.2 | −3.8 | 24.2 | −1.3 |
| constant λ=0.2 | 36.6 | −3.4 | 24.6 | −0.9 |
| w/o EGC | 37.3 | −2.7 | 24.5 | −1.0 |
| EGC 仅全错组 | 38.1 | −1.9 | 25.2 | −0.3 |

| w/o r_img | 37.2 | −2.8 | 25.0 | −0.5 |

> exclusive switch 与 w/o r_img 在 OOD All 上略高（+1.2 / +2.4），但只来自 OOD yes/no 题，二者在 OOD 开放式上仍低于 GRASP。

### 训练动态与失败模式

- 组类型演化：第二 epoch 全对组约占**一半**；平均 λ(p) 从 **0.21 降到 0.17**，大部分监督仍留在全错组（EM 给不出正确性信号的地方）
- EGC 方向随训练反转：早期偏向奖励全对组，随 running accuracy 上升转为惩罚全错组
- **ViSurf 式 gold injection 的失败模式**：全错组里裸答案序列拿到最大优势，模型学会跳过推理——**有效推理在 70 步内从 74% 跌到 5% 以下**
- **RFT 的盲区**：16 个 self-training 样本几乎解不出三分之二的开放式训练题，而 GRASP 的监督正集中在这些题上
- 超参敏感性：λ_max=0.2 掉 **3.8pp**、γ=2 掉 **2.6pp**（域内开放式）；但 OOD 开放式在测试范围内对这三个超参**不敏感**（≤0.7pp）

## 局限性

- **推理-答案一致性**：在模型自己的推理后监督 gold 答案，偶尔会教出与该推理不一致的答案；训练好的模型还会在正常的 OOD 图像上「报告发现」（训练集里正常样本太少）
- **Exact match 漏掉同义词与缩写** —— 虽补了医师审计过的 LLM judge（一致对上吻合 93.9%、κ=0.87），但两者都无法替代临床评估
- **基线 prompt 与训练语料不同**，故同时报告共享 prompt 与各自 prompt 两套结果；外部集上排名随 prompt 略有变动
- **训练集只覆盖 4 个来源、正常病例很少、答案最长 3 词**；细粒度诊断仍然困难：VQA-Med 2020 上所有模型 judge 准确率都 **<13%**
- **奖励里用了 BiomedCLIP/Bio_ClinicalBERT 等额外模型**，增加了 pipeline 依赖；主信号是 EM，无需 LLM judge 是相对优势
- **OOD 开放式绝对值仍低**（27.3% EM），远未达到临床可用水平
- **只有 2 epoch、3 个种子**（种子仅在主配置/SFT/GSPO 上跑），OOD 上部分消融变体的 ±0.5pp 差异接近噪声
- **外部 OOD 集的 gold 来自 option labels 校正**，转换规则本身可能引入系统性偏差

## 与知识库既有工作的关系

- 与 [[2026-10-27-2610.34609-audio-r1-audio-reasoning-rl-self-supervised]] 同属「**RLVR 奖励来源工程**」方向：那篇从自监督音频任务构造可验证奖励，本篇从**短答案**构造 SFT+RL 混合监督，共同点是「**不依赖昂贵 reasoning annotation 也能拿到有效训练信号**」
- 与本库既有的 RL/GRPO 类笔记（如 [[2026-10-25-2610.29722-rag-compositionality]]）形成方法论对照：GRASP 提供了 GRPO 全对/全错组失效的**具体修补方案**（EGC + 自适应 SFT 权重），是一个可直接搬到任何 GRPO 场景的补丁
- 延续 10 月主线中「**证伪默认假设**」的做法：证伪了「SFT 与 RL 必须分阶段或按题切换」的默认假设（同时做最好），也证伪了「gold injection 是安全的」这一假设（会让模型跳过推理）

## 建议

- **是否推荐使用**: **是** —— 方法简洁、消融完整、代码与数据开源，**尤其适合「有短标签无推理标注」的任何 VLM 后训练场景**
- **适用场景**:
  - 医疗 / 工业 / 质检等**标注昂贵且只有短答案**的 VQA 微调
  - 想在**保住 OOD 泛化**的同时吃到 SFT 的域内收益（论文里 SFT 掉 OOD balanced accuracy 12.5pp 是最值得警惕的数字）
  - 已有 GRPO 训练但发现「**很多题永远不被解**」（全错组无梯度）的团队 —— EGC 与 λ(p) 是即插即用的补丁
  - 想低成本复现「小 adapter 打大模型」结论的人：1.17% 参数 + 12.9K 题即可
- **可借鉴要点**:
  1. **「用自己的推理当 SFT 的上下文，只监督答案段」** 是本文最可移植的单点技巧 —— 不需要任何专家轨迹，也不需要行为克隆，同时避免 gold injection 教模型跳过推理
  2. **监督的落点 > 监督的量**：λ(p) 随组准确率衰减（常数权重掉 3.4pp、近似同预算的 switch 掉 3.8pp）—— 凡是「SFT 与 RL 混合」的自研方案都该把这条列为必做消融
  3. **不要丢弃极端组**：用 running accuracy μ_t 与组准确率 p 的比较来定向修正优势（经验贝叶斯式收缩），比 DAPO 的直接丢弃多出 2.7pp
