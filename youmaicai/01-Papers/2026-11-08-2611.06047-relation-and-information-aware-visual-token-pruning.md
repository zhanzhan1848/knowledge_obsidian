# RI-Prune: Relation and Information Aware Visual Token Pruning for Multi-Image Vision-Language Models

> **arXiv**: [2611.06047](https://arxiv.org/abs/2611.06047)
> **发表日期**: 2026-11-04
> **分类**: cs.CV
> **会议/期刊**: CIKM 2026 (Oral)

## 📋 摘要

大型视觉语言模型（LVLM）近期被扩展到处理多张输入图像，但这一扩展会**急剧增加视觉 token 预算**，使视觉 token 剪枝不再只是效率选项，而是**实操必需**。现有视觉 token 剪枝方法主要面向单图设定设计，依赖从注意力派生的显著性（saliency）信号来估计每个 token 的重要性。然而这种以注意力为中心的设计**迁移到多图场景很差**：它在多图基准上造成显著性能退化，存在**强位置偏置**，且随着输入图像数量增加会**丢失判别性注意力信号**。为检验「注意力选出的 token 是否真的对多图推理重要」，作者做了两个互补的**因果探针（causal probes）**：**Leave-One-In** 与 **Leave-One-Deletion**，分别通过把单个 token 恢复到置零的视觉序列中、或把单个 token 从完整序列中移除来度量重要性。结果显示注意力类剪枝器相对随机选择**仅有边际增益**，说明在多图推理中**注意力是视觉 token 重要性的弱代理**。受此启发，作者提出 **Relation and Information Aware Pruning（RI-Prune）**：一个**免训练、无需注意力**的、位于 decoder 之前（pre-decoder）的多图视觉 token 剪枝选择器。RI-Prune 用来自 projector 输出的三个信号的 **z-normalized 组合**为每个视觉 token 打分：**query 相关性**、与**每图紧凑原型**的**跨图对应关系**、以及**图内代表性**。通过整合这些信号，RI-Prune 执行**均衡的每图 Top-K 选择**，以在多张输入图之间保留信息。在多个多图基准和**三个 LVLM 骨干**上，RI-Prune 在 token 削减量与任务性能的权衡上优于既有剪枝方法，在**激进的 token 预算**下尤为明显。

## 🎯 核心贡献

1. **实证证伪「注意力 = 重要性」这一隐含假设**：通过 Leave-One-In / Leave-One-Deletion 两个因果探针证明，注意力类剪枝器在多图场景仅比随机选择好**边际**收益。
2. **诊断注意力机制在多图下的三重失效**：多图基准上性能显著退化、**强位置偏置**、随图像数增加判别性注意力信号流失。
3. **提出 RI-Prune**：免训练、**attention-free**、pre-decoder 的多图视觉 token 选择器，基于 projector 输出而非注意力。
4. **三信号 z-normalized 融合打分**：query 相关性 + 跨图对应（每图紧凑原型）+ 图内代表性。
5. **均衡的每图 Top-K 选择**：显式保证多图之间的信息均衡，避免单图独占 token 预算。
6. **强 trade-off**：在多个多图基准、三个 LVLM 骨干上优于既有方法，激进预算下优势最明显。

## 🔧 方法/架构

- **输入与位置**：多张图像经视觉编码器 + projector 映射为视觉 token 序列；RI-Prune 在 **decoder 之前**完成筛选，**完全不使用注意力图**。
- **三个打分信号**（均取自 projector 输出，计算后做 **z-normalization**）：
  1. **Query relevance**：token 与当前文本 query 的语义相关性；
  2. **Cross-image correspondence**：token 与每张图各自的**紧凑原型（compact per-image prototype）**的匹配度，用于识别跨图对应/可替换信息；
  3. **Intra-image representativeness**：token 对其所属图像内部内容的代表性刻画程度。
- **融合打分**：

```math
s(t) = z_{\text{query}}(t) + \lambda_1\, z_{\text{cross}}(t) + \lambda_2\, z_{\text{intra}}(t)
```

- **均衡每图 Top-K 选择**：不做全局 Top-K，而是**按图分配预算**分别取 Top-K，避免位置偏置与图像间不均衡。

```math
\mathcal{S}_{\text{keep}} = \bigcup_{i=1}^{N_{\text{img}}} \operatorname{TopK}_{K}\big(s(t)\big|_{t \in \text{img}_i}\big)
```

- **因果探针（用于验证设计动机）**：
  - *Leave-One-In*：把单个 token 放回被置零的视觉序列，看性能恢复量；
  - *Leave-One-Deletion*：从完整序列中删掉单个 token，看性能下降量。

## 📊 实验结果

- 骨干模型：**三个 LVLM 骨干**。
- 评测：**多个多图基准**（multi-image benchmarks）。
- 主要结论：RI-Prune 在 token 削减与任务性能的权衡上**优于既有剪枝方法**，在**激进 token 预算**下优势最大。
- 探针结果：注意力类剪枝器相对随机选择仅有**边际增益**（marginal gains）。
- 摘要未披露具体基准名称与逐项分数（详见原文实验章节）。

## ⚠️ 局限性

- 摘要未给出具体的 token 削减比例与性能保持数值，trade-off 的量化程度需查原文。
- 三个信号的打分都依赖 **projector 输出**质量，若某骨干的 projector 表征弱，方法收益会受限。
- 「每图紧凑原型」的构建方式（如何聚合、如何对原型数量）未在摘要中说明，聚类式原型可能对图像数量极多的场景不稳定。
- 均衡每图 Top-K 在图像**重要性高度不均**（如一张关键证据图 + 若干背景图）时可能次优。
- 依赖 z-normalization 的分布假设，校准数据不同会影响阈值，摘要未讨论分布偏移。
- 方法针对 pre-decoder 阶段，对 encoder 侧冗余或需要完整空间信息的任务（计数、密集标注）是否适用未验证。

## 💡 建议

- 是否推荐使用：是
- 适用场景：多图输入的 LVLM 推理服务与 Agent（如多文档/多截图理解、多图 QA）、需要在激进 token 预算下保住多图推理能力的生产部署。
