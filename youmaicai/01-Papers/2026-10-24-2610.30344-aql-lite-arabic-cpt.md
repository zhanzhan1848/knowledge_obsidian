## 核心贡献

> 提出 **AQL-Lite** —— **质量优先的数据管线** + **部分参数 CPT 配方** 的组合，让多语言 LLM 高效适配现代标准阿拉伯语（MSA），在**一半墙钟时间**内恢复全参数 CPT 收益的 **94%**。

1. **问题三重困难**：阿拉伯语训练面临**网络数据噪声大、方言变体多、CPT 成本高**
2. **数据侧：quality-first curation pipeline** —— 结构清洗 + 启发式与模型式过滤 + MSA 选择 + 去重
3. **参数侧：partial-parameter CPT recipe** —— 全网络训练 **RS-LoRA adapters**，外加**最后 8 个 transformer block** 与**embedding 矩阵**，配合**逐层学习率**
4. **关键实证对比**：在 **1B token 预算**下，AQL 清洗数据上的 CPT 比原始网络文本上的 CPT **高 3.51 分**（四基准阿拉伯语均值）；而后者**相对基座模型毫无增益**
5. **受控 5B token 对比**：AQL-Lite 恢复全参数 CPT 收益的 **94%**（均值 73.19 vs 73.58），**墙钟时间仅为 52%**
6. **规模化结果**：40B MSA tokens + 100 万条指令数据微调 → **12B 模型**在 Open Arabic LLM Leaderboard v2 (OALL v2) 七基准上得分 **75.3**

---

## 技术方案

### 部分参数 CPT 配方

| 训练对象 | 方式 |
|----------|------|
| 全网络 | **RS-LoRA adapters** |
| 最后 8 个 transformer block | **完全解冻** |
| Embedding 矩阵 | **完全解冻** |
| 学习率 | **逐层（layer-wise）** |

### 组件消融

论文的组件消融显示**三者各自都有贡献**：adapters、未解冻的 blocks、embedding 训练。

---

## 实验结论

| 设置 | 结果 |
|------|------|
| 1B token 预算 | AQL 数据 CPT **+3.51**（四基准阿拉伯语均值）vs 原始网络文本 CPT（后者**无增益**） |
| 5B token 受控对比 | 全参数 CPT 均值 **73.58**；AQL-Lite **73.19**（恢复 **94%**），**墙钟时间 52%** |
| adapter-only 基线 | AQL-Lite **在每个基准上都优于** adapter-only |
| 规模化（40B tokens + 1M 指令） | **12B 模型 OALL v2 = 75.3** |

**核心洞察**：在低资源语言适配中，**数据质量比 CPT 算力更关键** —— 用原始网络数据做 CPT 甚至不如不做。

---

## 局限性

- 结论以阿拉伯语 / MSA 为主，其他低资源语言的方言复杂度可能不同
- RS-LoRA 与 last-8-blocks + embedding 的组合是在特定基座上验证的
- 5B token 受控对比未覆盖更长 CPT horizon
- OALL v2 为特定榜单体系，与其他榜单不可直接比较

## 实现建议

- **实现难度**: 中（数据管线是重头，但参数侧改动轻量）
- **适用场景**: 任何需要把多语言基座适配到特定标准语种（MSA / 泰语 / 越南语 / 斯瓦希里语等）的团队
- **建议起点**: **先做数据质检再谈算力** —— 这是本文最可迁移的一条结论
- **价值点**: 1B token 预算下"清洗数据 CPT +3.51 vs 原始数据 CPT +0"的对比，是很有说服力的论据
