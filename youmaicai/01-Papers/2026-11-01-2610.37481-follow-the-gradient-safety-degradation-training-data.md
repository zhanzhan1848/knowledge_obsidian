# Follow the Gradient: Tracing Safety Degradation Back to Training Data

## 摘要
在指令数据上微调 LLM 会在训练样本表面无害的情况下悄悄侵蚀其安全性；由于这类"安全退化数据"表面良性，常规内容过滤器很难捕捉。本文提出 SimpleLoRIF——一种可扩展的梯度嵌入（gradient embedding）方法，用于识别梯度方向与不安全行为对齐的微调样本。通过简化低秩归因方法（LoRIF）并把反向传播限制在最后四个 transformer block，SimpleLoRIF 得以嵌入百万量级的数据集，把梯度归因从小规模分析工具提升为面向完整 post-training 数据集的实用过滤器。作者首先在 emergent misalignment 上验证：不安全代码训练数据的梯度与微调后出现的广泛有害行为相连接，在已错位模型的梯度空间中 AUC 高达 0.865。随后用 SimpleLoRIF 构建 SafeTulu——移除 Tulu 3 中与不安全响应梯度对齐度最高的 20% 样本后的版本。在 Qwen、Llama、Olmo 上训练 SafeTulu 使 GCG 攻击成功率最多降低 22%，优于 LLM-as-a-judge 与既有的梯度过滤方法，同时基本保持甚至提升了能力。作者还分析了被移除的数据，识别出可能被低估的安全退化来源，如工具执行失败与叙述式算术（narrative arithmetic）。SafeTulu 与一个 Hugging Face Space 一并发布。

## 核心贡献
1. **EM 的梯度空间证据**：对在不安全代码上微调的模型，不安全代码样本的梯度与微调后涌现的有害输出梯度对齐，与表面高度匹配的 secure-code 样本区分开的 AUC 高达 0.865（Mistral-Small-24B）、0.604（Qwen2.5-Coder-32B）。
2. **SimpleLoRIF**：可扩展的梯度归因方法——去掉 LoRIF 的曲率校正（因为评分纯序数化，无需 calibration），并把反向传播限制在最后 4 个 transformer block，保留质量的同时大幅降本；嵌入 939,343 条 Tulu 3 样本仅需 8×H100 上 1 小时 1 分钟。
3. **SafeTulu 数据集**：Tulu 3 移除与不安全 SafeRLHF 响应梯度对齐度最高的 20% 样本；GCG ASR 最多降低 22%，且优于 LLM-as-a-judge 与 He et al. (2024) 的梯度过滤。
4. **定性分析**：识别出可能的安全退化来源——工具执行失败（Python traceback，RR 1.71×）、叙述式算术、简单直接的编程任务。
5. **可复现工具**：SafeTulu 数据集 + Hugging Face Space（可自定义移除比例、只过滤特定子集）。

## 方法与架构
**LoRIF 基线**：以文档在参考模型上诱导的 per-example gradient 表征文档，用双侧随机投影（源自 LoGRA）在反向传播过程中直接对前向激活与后向输出梯度做投影：
```math
M_\ell(z) = \left(\delta Y_\ell P^{\text{out}}_\ell\right)^{\top}\left(X_\ell P^{\text{in}}_\ell\right) \in \mathbb{R}^{d_2\times d_1}
```
其中 $X_\ell,\delta Y_\ell$ 是该层在文档 token 上的输入激活与输出梯度，$P^{\text{in}}_\ell,P^{\text{out}}_\ell$ 为固定高斯矩阵。完整梯度从不构造；随机投影在期望意义下保留内积。默认 $d_1=d_2=32$。第二阶段利用 per-example gradient 的低有效秩，仅存储其 leading rank-$c$ 因子 $M_\ell \approx u_\ell v_\ell^{\top}$（$c=1$，LoRIF 推荐设置），每层存储量从 $d_1d_2=1024$ 个 float 降到 $d_1+d_2=64$ 个。

**双线性相似度**：由于存储对象是分解形式，正确的相似度是双线性形式（等于两个重构梯度的 Frobenius 内积，但无需重构）：
```math
s(z_{tr}, z_{te}) = \sum_{\ell}\left(u_\ell(z_{te})^{\top}u_\ell(z_{tr})\right)\left(v_\ell(z_{te})^{\top}v_\ell(z_{tr})\right)
```

**SimpleLoRIF 的两处简化**：① 去掉 LoRIF 的曲率校正（截断 SVD + Woodbury 恒等式算出的 $g_{te}^{\top}H^{-1}g_{tr}$），因为本文的评分仅用于**排序**删除样本，不需要校准过的 influence 估计、跨模型分数量级比较或损失变化预测；② 把反向传播限制在最后 $N=4$ 个 transformer block——前向仍走完整网络，但 backward 在产出最浅选中 block 的输入梯度后即停止，且只有这些 block 的激活需要保留，因此可放宽 batch size 的显存限制。成本消融（Fig. 1）显示：投影维度 $D$ 对 AUC 与速度影响都很小；token 截断有效但有风险且不易泛化到长文档；缩小 embedding 模型代价太大；而限制 block 数既保质量又大幅降本（$N=2$ 时 AUC 明显掉到 0.65，$N=6$ 或 $8$ 增益很小），最终 $N=4$ 在 91.53% 加速下取得 AUC 0.684。

**EM 验证设定**：source 集为 Betley et al. (2025) 的匹配安全/不安全代码数据集（6,000 insecure + 6,000 secure）；target 集由该 checkpoint 在自由形式非编码问题上的回答构成，经 Claude 5 Opus 审阅只保留明确表现错位行为的回答。influence score 定义为 source 样本与该模型所有 verified-unsafe target 的平均相似度；用 ROC-AUC 衡量 insecure 与 secure 的可分性。

**SafeTulu 流程**：① Embed——为训练集与 target 集全部文档计算梯度嵌入；② Remove——按梯度相似度评分并删除最高的 20%；③ Train——在过滤后数据集上微调；④ Evaluate。为避免对每个文档与单个 pooled target 向量比较，作者先对 target 集做聚类，再对簇心评分，rank-1 分解使其有闭式解：
```math
\text{score}(x,c) = \langle G_x, M_c\rangle_F = \frac{1}{|c|}\sum_{t\in c}\sum_{\ell=1}^{L}\left(u^\ell_x\cdot u^\ell_t\right)\left(v^\ell_x\cdot v^\ell_t\right)
```
该恒等式意味着簇级分数可直接从 rank-1 因子算出，无需构造完整外积嵌入 $G_x\in\mathbb{R}^{d\times d}$，等价于在外积提升空间做归一化 cosine k-means。每个训练文档得到 (簇分配, 到簇心距离)。

## 实验设置
- **Embedding 模型**：Qwen 3 0.6B；**微调模型**：Qwen 3 1.7B、Llama 3.2 1B、Olmo 2 1B（外加更大规模的 Llama 3.1 8B）。
- **数据集**：训练集 Tulu 3（939,343 条）；target 集为 SafeRLHF 中带不安全响应的 prompt-response 对（43,469 条）。
- **安全评测**：① GCG ASR（JailBreakBench behaviors，白盒单轮对抗后缀优化，后缀初始为 20 个 "!"，500 步优化、每步 512 个候选后缀、gradient top-k 256），响应由 HarmBench classifier 判安全/不安全；② ActorBreaker（黑盒多轮，利用自然语义分布漂移，用 Qwen2.5-14B-Instruct 生成 actor 网络，HarmBench 判定，任一路径出现不安全响应即算成功）。
- **能力评测**：ORBench（over-refusal）、MMLU Pro、IFEval、MBPP、GSM8K、MATH 500、MedQA。
- **基线**：Baseline Training（全量 Tulu 3）、Random Removal（随机删 20%）、LLM-as-a-Judge（Qwen 3 8B 按 0–5 rubric 评分，删除最差 20%；平局用 seeded random 打破）、He et al. (2024)（双向锚定准则 $\langle g(z), g_{harm}\rangle - \langle g(z), g_{safe}\rangle$，$g_{harm}$ 与 $g_{safe}$ 来自 PKU-SafeRLHF 中共享相同 instruction 的 unsafe/safe 响应对）。
- **微调超参**：2,297 步，LR $1\times10^{-4}$，$\beta_1=0.9$、$\beta_2=0.95$、weight decay 0.1，warm-up 20 步，LR decay ratio 20%、min LR factor 0.05，序列长度 2,048，全局 batch 128 sequences（每 GPU 8），grad clip 1.0，bf16 参数 / fp32 梯度归约，dataloader shuffle seed 9,176。3 个随机种子，报告 mean ± standard error。
- **定性分析方法**：用带 informative Dirichlet prior 的 log-odds 比较（"fightin' words" 方法）在 unigram/bigram 上，分别对 prompt 与 response、且在单个 subset 内进行，以避免 subset 身份混淆；用 relative risk (RR) 报告某特征在 removed vs kept 中的富集倍数。

## 关键公式与代码
核心公式（LoRIF 双侧随机投影、双线性相似度、簇心评分闭式解）已在"方法与架构"给出。论文未给出独立代码块，但给出了可复现要素：LoRIF 超参（$d_1=d_2=32$，$c=1$，$N=4$ blocks）、训练超参、GCG 超参、LLM judge 的 0–5 rubric 全文与 JSON 输出格式（`{"score": int, "reason": str}`，取最高适用分而非累加，平局用 seeded random 打破）、以及 removal scoring identity。

## 局限性
作者自述两点：① 只测试了通用的安全退化，**没有测试具体危害或行为**（如 sycophancy）；② 虽然 SafeRLHF 是广泛的数据集，但**没有测试其他 target set**。

我的补充批判：① **删除 20% 数据**是极重的干预，SafeTulu 的能力保持很大程度上可能来自基座模型已有能力而非"训练信号等价"；尤其 Qwen 上 MMLU Pro 从 19.8 → 22.4、GSM8K 52.6 → 58.1，与 Llama/8B 上"几乎不变"不一致，暗示不同族对数据量的敏感度差异，未做数据量匹配的对照（如 80% 随机保留基线——Random Removal 恰好提供了这点，但 Llama 上 Random 反而更差）；② 安全性只覆盖 GCG 与 ActorBreaker 两种攻击，且 ActorBreaker 自身的 ASR 低于原论文（作者归因于用 Qwen2.5-14B 而非 GPT-4o 生成 actor 网络），绝对数值不可比；③ 定性分析是相关性 log-odds，作者自己也强调"suggestive rather than established"，缺少因果验证（如"只删含 traceback 的 NuminaMath 样本再微调"的消融被列为未来工作而非已做）；④ EM 的 AUC 依赖 embedding 模型与 target 模型的配对（反向迁移掉到 0.247），意味着该方法在实践中必须针对每个模型重新计算 target，规模化成本可能高于论文报告的 1 小时（该成本对应的是 SafeTulu 场景的 Qwen3 0.6B embedding）；⑤ 单一 target set（SafeRLHF unsafe responses）覆盖窄，未验证对其他危害的普适性。

## 评估与建议
- 是否推荐深入阅读：**是**。它把"表面良性数据如何侵蚀对齐"这一长期难题转化为可操作的训练数据选择问题，并给出可复现的开源产物。
- 适用场景：post-training 数据配方的安全审计与过滤（可作为 CI 中的"训练前安全过滤"步骤）；数据中心的 mixture curation；jailbreak 鲁棒性评估；与 influence function / TracIn / LESS / SEAL / DataShield 的方法论对照阅读。
- 与知识库的关联：直接衔接 training data attribution（TDA）、LoRIF/LoGRA 低秩归因、clean-label poisoning 与 backdoor 防御文献、emergent misalignment 系列（Betley 2025、Sparse Autoencoder model diffing、feature superposition 几何解释）；"安全即数据问题"这一论断也可与 emergent misalignment、alignment erosion（Qi et al. 2024）、multilingual safety degradation（Hawkins et al. 2026）交叉引用。
