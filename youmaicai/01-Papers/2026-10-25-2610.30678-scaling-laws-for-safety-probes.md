## 核心贡献

> 证明**安全探针（safety probe）的误差可以被事先预测** —— 给定目标模型规模与标注预算，无需实际训练并比较大量探针配置，就能预测探针能达到的最好性能；并据此回答"该多标数据还是该换大模型"。

1. **探针性能可预测**：论文提出问题 —— 模型和标签都**不告诉你**最终探针会有多好，必须训很多配置才知道。答案是：**从模型规模与标签数可以提前拟合出预测**（即存在 scaling law）
2. **构建六个新安全数据集**：现有安全数据集**规模不足或已被饱和（saturated）**，无法支撑拟合，因此自建 **6 个规模与难度足够的安全数据集**
3. **两条简单 scaling law**：
   - **规模律**：模型能达到的**最低 probe error 随模型规模呈幂律下降**
   - **标签律**：probe error 随样本数增加**趋近其下界（floor）**，且**目标模型越大、曲线斜率越陡**
4. **两条律在任务、模型家族、探针架构上普遍成立**，只有拟合常数不同 —— 这保证了规律的**可迁移性**
5. **实用工具**：可预测"再标数据 vs 换大模型"哪个更便宜，并能在探针架构间做选择

## 技术方案

### 核心思想

把"训练一个安全探针"视为一个有**成本/收益结构**的工程问题：

```
probe error = 1 - AUROC   (越低越好)

成本项 1：labels     —— 每个模型需要多少标注样本
成本项 2：model size —— 被监测的模型有多大
```

若能拟合出 `error(model_size, n_labels)`，则：
- 预知最好能到多少 → 决定是否值得投入
- 比较两条降误差路径的边际成本 → 决定**加标签**还是**换大模型**
- 比较架构 → 选对 estimator

### 关键技术

| 技术 | 说明 |
|------|------|
| **Probe error 指标** | 定义为 `1 - AUROC`，越低越好（摘要中明确给出） |
| **两组探针架构** | 在 **20 个 base model**（来自 **5 个模型家族**）上训练**两种**探针架构，用于检验规律的架构不变性 |
| **标签规模跨度** | 每个模型的标注量从 **32 到 10⁶**（六个数量级） |
| **六个新安全数据集** | 自建，规模与难度足够，避免"规模不足/已饱和"导致的拟合失败 |
| **power-law 规模律** | 最低可达误差 `e_min(S)` ∝ S^(-α)，α 由家族/任务决定 |
| **floor + slope 标签律** | `e(n) → e_floor`，且**斜率随目标模型规模增大** |
| **小模型外推** | 在家族**最小的模型**上拟合 → 预测下一个更大模型的误差 |
| **平方根预算规则**（类比） | 论文用"哪个路径更便宜"这一决策检验规律的实用价值 |

### 实验规模总览

| 维度 | 规模 |
|------|------|
| 新构建安全数据集 | **6 个** |
| Base models | **20 个**，跨 **5 个 model families** |
| 探针架构 | **2 种** |
| 每模型标注量 | **32 – 10⁶** |

## 关键实验结果

### 规律拟合与外推精度

| 结论 | 具体数值 |
|------|------|
| 最小模型拟合 → 预测下一个更大模型的 probe error | 误差在 **0.02 以内**的比例达 **72%** |
| 判断"更多标签 vs 更大模型"哪个是达到目标误差的更便宜路径 | 正确率 **73%** |
| 用规律选择探针架构 | 平均只多付 **0.006** 的额外误差（即使选到较差的那个） |

### 规律的两条形式

1. **规模律**：模型所能达到的**最低** probe error 随其规模呈**幂律**下降
2. **标签律**：probe error 随样本数增加**趋近下界 floor**，且**斜率随目标模型规模增大而增大**

> 直觉：模型越大，探测其行为越容易 —— 需要的标签越少（斜率越陡 → 更快贴近 floor）；但同时，模型越大，其内在行为也越复杂，**最低可达误差的下界本身可能更高/更低**，由幂律刻画。

### 泛化性

- 两条律**在任务、模型家族、探针架构上都成立**，**只有拟合常数不同** —— 这是该工作最强的结论，因为它意味着规则可以**迁移到未见过的新模型/新探针架构**

## 关键结论 / 局限性

### 关键结论

1. **安全监测的"前置规划"成为可能**：在拿到标注预算与目标模型后，可直接算出最优探针配置 —— 不再依赖"训一堆再挑"
2. **两条律给出明确的工程决策接口**：*要不要标更多数据 / 要不要换更大模型 / 用哪种 probe 架构*
3. **探针架构的选择是次要决策**：规律给出的架构选择最多付出 **0.006** 的平均误差损失，说明**数据与模型规模比 estimator 选择重要得多**

### 局限性

- **新数据集是自建的**：结论依赖于这 **6 个自建安全数据集**的代表性；若其覆盖的安全域偏窄，幂律的**外推范围**受限
- **每模型标注量跨度大（32–10⁶）**：**32 标签**的一端样本极少，其拟合点方差可能很大
- **摘要中未披露**：具体模型家族名称、具体安全任务、幂律指数 α、误差下界 floor 的数值、最佳 probe 架构是哪种 —— 这些需要查正文（62 页，33 表）
- **AUROC 作为唯一指标**：probe error 定义为 `1 - AUROC`，在**极度不平衡**的真实监测场景（安全事件罕见）中，AUROC 对阈值选择与实际告警效果脱节
- 论文自称"现有安全数据集规模不足或已饱和"，这本身是对**当前公开安全评测数据质量**的负面判断 —— 意味着外部复现需要自建数据
