## 核心要点
1. 指出传统做法（Sentry 式）在每次失败前先调大模型生成诊断，增加推理成本。
2. **Synapse-Control** 用**轻量控制面**：规则粗筛建议，**1.7B 分类器**（在教师标注的 state-suggestion 对上微调）对候选**打分**而非生成诊断。
3. **micro-contracts** 编码可复用的接口检查（必需参数、合法选项）而不规定完整任务程序。
4. **Prompt Value Table** 记录先前的指导与反馈，通过冷却与 token 预算限制重复建议。
5. 在 AppWorld 与 WebShop 上**每方法 1,308 次尝试**，达成 **270 次成功（比 Base 高 29.8%）**，**替代了 4,987 次生成式诊断调用**，辅助控制时间相对 Sentry 分别降低 **50.2% 与 51.0%**。

## 摘要（原文）
Large language model agents reuse execution experience to improve reliability on complex tool-based
tasks. Systems such as Sentry call large models to generate failure diagnoses before retrieving
advice, adding inference cost to experience reuse. We present Synapse-Control, an agent runtime
whose lightweight control plane selects advice and determines when to send it to the task-executing
model. Rules shortlist relevant advice, and a lightweight 1.7B classifier fine-tuned on teacher-
labeled state-suggestion pairs scores those candidates instead of generating a diagnosis. Micro-
contracts encode reusable interface checks, such as required arguments or valid options, without
prescribing complete task programs. A Prompt Value Table records earlier guidance and feedback to
limit repeated suggestions through cooldown and token-budget checks. Across 1,308 attempts per
method in AppWorld and WebShop, Synapse-Control achieves 270 successes (29.8% more than Base),
replaces 4,987 generative diagnosis calls, and reduces auxiliary control time relative to Sentry by
50.2% and 51.0%, respectively.
