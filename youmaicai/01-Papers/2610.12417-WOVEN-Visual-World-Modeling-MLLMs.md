## 核心贡献

> 提出"视觉过渡推理（visual transition reasoning）"是 MLLM 在空间 / 具身 / 物理 / 时间推理上系统性失败背后的共同缺陷；构建 36K 样本的 WOVEN 基准与训练集，证明 2000 条样本即可在 22/26 个外部基准上带来 +27.3pp 的提升。

1. 提出统一假设：**视觉过渡推理（visual transition reasoning）** 是多种 MLLM 失败模式的共同根因，可作为共享训练原子。
2. 构建 **WOVEN**：36,076 样本，覆盖 20 场景 / 5 动作 / 8 推理类型的视觉过渡基准与训练集（数据来自视频预训练生成模型的真实 rollout）。
3. 大规模评估 38 个前沿 MLLM（含 GPT-5.4、Qwen3-VL-235B-A22B），发现系统性、跨家族、不可规模修复的不足。
4. 提出"视觉世界模型训练配方"：按推理操作而非场景/动作/领域选监督；偏好更大视觉状态变化以提升鲁棒性。

---

## 技术方案

### 核心思想

MLLM 在 spatial / embodied / physical / temporal reasoning 上的失败不是孤立的，而是**共享一个底层能力缺口**：理解"对视觉状态施加动作后状态如何变化"。把这一能力抽出来作为训练原子后，可被多种模型学习、由多种监督来源生成、并在不同任务间复用。

### 关键技术

| 技术 | 说明 |
|------|------|
| Visual Transition Reasoning | 统一视角下的核心能力：给定 (scene, action) → 推断 (next visual state) |
| Observe-Transform-Infer 框架 | 三段式结构：观察 → 状态变换 → 推理 |
| Video-pretrained rollouts | 用视频生成模型生成逼真的状态转移，避免手工标注 |
| 数据组织 | 按 scene × action × reasoning_type 三维索引；20×5×8 |
| 训练原子选择原则 | 选"推理操作"覆盖好的样本，而非按场景 / 动作 / 领域覆盖 |
| State-change 偏好 | 训练样本优先选视觉状态变化大的样本以提升鲁棒性 |

### 训练与评估

- 数据：WOVEN-train 36,076；WOVEN-bench 用于诊断
- 模型族：GPT-5.4、Qwen3-VL-235B-A22B、其它 36 个前沿 MLLM
- 监督来源：不同视频预训练生成模型的多样化 rollout

---

## 实验结果

- **WOVEN-bench**：38 个前沿 MLLM 即使最强也远低于人类，跨家族失败模式一致；scale 不能消除差距
- **迁移提升**：每条仅 ~2K 样本的子集训练，**22/26 个外部基准** 上提升 up to **+27.3 pp**
- **数据替代**：WOVEN 数据可替代任务自身训练数据的 **30–50%** 而精度相当
- **前瞻验证**：held-out 基准上确认"按推理操作选样本、偏好大状态变化"的训练配方更优
- Qwen3-VL-4B 在 SpaceCast-Bench 等任务上从 34.0% → 65.7%（参见 [[2610.12402-SpaceCast-Bench-Spatial-Reasoning]]）

---

## 关键 takeaway

- "视觉世界建模"（visual world modeling）应被作为 MLLM 的**可复用基础能力**，而非任务专属模块。
- 训练数据的**认知结构**比覆盖度更重要：选对推理操作比覆盖更多场景更关键。
- 状态变化大的样本带来更强的鲁棒性，是值得纳入训练配方的归纳偏置。

---

## 局限性

- 数据来源单一（视频预训练生成模型 rollout），可能引入分布偏见
- 仅评估英文 / 西方场景，多语言和文化覆盖未明确
- 提升 up to 27.3pp 的样本量仍较大（2K/任务子集），对超小样本场景尚未验证
