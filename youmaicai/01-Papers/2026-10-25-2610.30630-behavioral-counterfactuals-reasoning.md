## 核心贡献

> 提出 **behavioral counterfactual（行为反事实）** 这一解释方法：给定一段固定响应，向 prompt 注入干预后，**下一 token 分布如何变化**；并训练一个直接编辑 residual stream 的模块，使「源 prompt 下的输出分布」与「反事实目标 prompt 下的输出分布」之间的 **KL 散度最小** —— 相比标准 activation reconstruction 目标更有效，且其模块输出的 attribution 可定位因果重要位置。

1. **提出 behavioral counterfactual 的形式化框架**：把「干预对模型推理的影响」转化为**可比较的分布层面问题**，绕开采样方差带来的干扰 —— 过去难以做是因为「sampled responses 方差大，使得隔离干预效果、比较模型推理变得困难」。
2. **训练 residual-stream 编辑模块以最小化输出分布 KL 散度**：在固定响应（fixed response）下，比较 source prompt 与 counterfactual target prompt 的输出分布差异，并以 KL 散度为损失直接优化。
3. **验证 KL 匹配优于标准 activation reconstruction 目标**：即「匹配输出分布比重建激活更能恢复反事实行为」。
4. **attribution map 有效**：对训练模块的输出做 attribution，可**识别出对反事实恢复具有因果重要性的位置**。
5. **案例研究（Gemma-4-E4B-it 与 DeepSeek-R1-0528-Qwen3-8B）**：分析「建议（suggestion）」如何在模型**未口头承认**的情况下影响推理 —— 发现**问题陈述处的表征与 filler token** 介导了建议影响的相当一部分，下游效应包括改变论证框架、甚至改变最终答案。

## 技术方案

### 核心思想

**问题**：模型形成 chain-of-thought 的内部过程难以忠实理解，主因是 **sampled responses 的方差** —— 你无法区分「模型改了主意」和「模型采样波动」。

**思路（behavioral counterfactual）**：不再看「模型说了什么」，而看「**输出分布**」。
- 固定一个 response（`fixed response`），记源 prompt 下该 response 的 **next-token 分布**为 $p_{\text{src}}(\cdot)$；
- 构造 counterfactual target prompt（例如把「原问题的措辞」替换为「被加入建议的版本」），记其分布为 $p_{\text{cf}}(\cdot)$；
- 定义干预的**行为效应**为两分布的分歧。

**训练目标**：训练一个编辑 residual stream 的模块 $m(\cdot)$，使其在源 prompt 上**复现目标 prompt 的输出分布**：

$$\min_{\theta}\ \mathrm{KL}\!\left(\,p_{\text{cf}}(\cdot \mid x_{\text{target}})\ \big\|\ p_{\text{src}}(\cdot \mid x_{\text{source}},\, m)\,\right)$$

关键点：损失作用在**输出分布**上，而不是中间激活的 MSE/重构上。

**Attribution**：对模块输出做 attribution（把模块贡献分摊到各 token/位置），得到一张 **attribution map**，标出「对反事实恢复具有因果重要性」的位置 —— 这是把「模型编辑」升级为「模型解释」的接口。

**工作流闭环**：attribution map + 模型编辑的下游效应可视化 → 生成关于原模型计算的**假设** → 再用 **activation patching** 检验该假设。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Behavioral counterfactual** | 以输出分布变化而非采样文本变化来定义干预效应，规避采样方差 |
| **Fixed response** | 固定响应序列，消除「模型随机性」这一混淆变量 |
| **KL-divergence output-distribution matching** | 直接最小化源/反事实 prompt 下输出分布的 KL，作为训练损失 |
| **Residual-stream editing module** | 通过编辑残差流实现「在 A 的条件下产生 B 的行为」 |
| **Activation reconstruction（对照）** | 标准替代目标：重建中间激活；本文证明其不如分布匹配 |
| **Attribution map** | 模块输出的贡献归因，用于定位因果重要位置 |
| **Activation patching** | 用于事后检验由 attribution 提出的假设 |
| **Counterfactual recovery** | 反事实行为的恢复效果，作为方法有效性的度量 |

## 关键实验结果

| 项目 | 结果 |
|------|------|
| **方法对比** | 匹配**输出分布**（KL）在恢复反事实行为上**优于标准 activation reconstruction 目标** |
| **Attribution 有效性** | 训练模块输出的 attribution 可**有效识别对反事实恢复具因果重要性的位置** |
| **案例研究模型** | **Gemma-4-E4B-it**、**DeepSeek-R1-0528-Qwen3-8B** |
| **案例发现（定位）** | **问题陈述处的表征** 与 **filler token** 介导了建议（suggestion）影响的**相当一部分** |
| **案例发现（下游）** | 效应包括**改变论证（justification）的框架** 乃至**改变最终答案** |
| **建议的隐蔽性** | 建议可在模型**未口头承认**的情况下影响其推理 |

## 关键结论

1. **「输出分布」是比「生成文本」更稳定的解释对象。** 采样方差是 CoT 解释的主要噪声源；把干预效应定义为分布层面的分歧，是本文最可迁移的方法论主张。
2. **KL 输出分布匹配 > activation reconstruction**。这不是量级差异而是目标函数选择差异 —— 重建激活是代理目标，匹配行为才是真正关心的量。
3. **「建议的影响」在语言上不可见**。案例显示建议可以通过问题陈述表征与 filler token 起作用，而模型**并不在言语上承认**它采纳了建议 —— 这对「读 CoT 判断模型是否被影响」的评测范式构成直接警告。
4. **解释与干预可以共用一套机制**：attribution map 提出的假设用 activation patching 检验，方法论闭环完整。

## 局限性

- **摘要未给出量化数字** —— 具体的 KL 数值、attribution 精度、反事实恢复成功率、对比基线列表、任务/数据集规模**全部缺失**，无法判断效应量级。这对一篇方法论论文是明显的报告缺口。
- **计算成本未提及**：训练一个 residual-stream 编辑模块并在固定响应上做 KL 优化，开销相对未说明；摘要也未说明是否需要梯度（若是，仅解释用工具而言成本偏高）。
- **案例研究规模小（两个模型、一个 case study）**：「suggestion 未被言语承认」这一发现目前是**个例级证据**，不构成对一般情形的定律式结论。
- **两个案例模型都是中小规模 / 开源推理模型**（Gemma-4-E4B-it、DeepSeek-R1-0528-Qwen3-8B），**未验证在 frontier 长思维链模型上是否成立** —— 长 CoT 的分布方差更大，反而是本方法最需要检验的场景。
- **代码未公开**（摘要未给链接）。
- 摘要**未说明 attribution 方法的具体形式**（梯度？积分路径？线性近似？），影响可复现性判断。
