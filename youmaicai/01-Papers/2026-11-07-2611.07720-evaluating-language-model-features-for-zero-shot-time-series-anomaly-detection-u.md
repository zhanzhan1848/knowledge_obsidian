# Evaluating Language Model Features for Zero-Shot Time-Series Anomaly Detection Under Isolation Assumption

### 核心贡献
1. 提出完全弃用辅助目标（forecasting / reconstruction）来适配 LLM 做时间序列的路线：只把 LLM 当作纯特征提取器，直接分析其诱导的特征空间在零样本多变量时间序列异常检测（Multivariate TSAD）中的可用性。
2. 指出既有跨模态迁移方法的两处失效：tokenisation 掩盖细粒度的时间与变量结构；代理目标（预测/重建）随模型容量增大而失效，因为高表达力模型倾向于把异常也预测/重建出来，从而瓦解这两种策略的前提。
3. 提出基于「隔离假设」（isolation assumption）的评测协议：异常特征应与正常特征分离，用无监督 Isolation Forest 直接评估表征质量，并检验性能究竟来自语言预训练还是独立于它。

### 技术方案
**核心思想**: 不训练 LLM 去「发现」异常，而是考察 LLM 特征空间中异常是否天然可分——用细粒度 tokenisation 保留局部结构，再用 Isolation Forest 在零样本下量化这种可分性。

| 技术 | 说明 |
|------|------|
| 纯特征提取范式 | LLM 仅作 feature extractor，不施加 forecasting / reconstruction 等辅助目标 |
| 隔离假设 | Isolation assumption：异常样本诱导的特征应与正常样本特征相互隔离，这是可分性评测的理论基础 |
| Step-wise tokenisation | 每个时间步对应一个 token（one time-step per token）的简单 step-wise 方案，保留细粒度局部时间与变量结构 |
| Isolation Forest 评估 | 使用无监督 Isolation Forest 在零样本设定下直接量化所提取表征对 MTSAD 的可用性 |
| 归因检验 | 设计实验区分性能是源于 LLM 的语言相关预训练，还是与语言预训练无关地产生 |
| 时序与上下文判别力分析 | 分析提取特征在时间维度与上下文维度上的判别能力 |

- **数据集**: 摘要未说明具体时间序列数据集名称

- **结果**: 摘要未给出具体数值；提供实证洞察——LLM 能为 MTSAD 提供有用的多变量时间序列表征，且细粒度 step-wise tokenisation 下的隔离可分性是可行的评测信号

### 局限性
- 摘要未给出数据集名称与定量结果，难以判断提升幅度
- 只评估异常检测的下游可分性，未评估异常类型的覆盖度与假阳性代价
- 「语言预训练 vs 独立于语言预训练」的归因检验在摘要中仅描述为「进一步研究」，结论强度受限
- 隔离假设本身是理想化前提，异常与正常特征实际可能重叠

### 关键洞见
> 模型容量在跨模态迁移中扮演了反角色：forecast/reconstruction 式的代理目标之所以在大模型上失效，是因为更强的模型会「顺便把异常也预测出来」，于是训练目标与检测目标悄悄解耦——因此正确的做法是彻底放弃代理目标，改用隔离假设直接检验 LLM 特征空间本身是否已把异常与正常分开。
