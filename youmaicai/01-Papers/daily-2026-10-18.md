## 重点论文（15 篇详细精读）

### 1. **MLExpert: Generalist Agentic Model for Autonomous ML Engineering** (2610.22344)
- **核心**：35B MoE agentic model 训练做 autonomous long-horizon ML engineering。
- **三件套**：Kaggle-MLE Factory (data + harness)、Hierarchical Agentic SFT (outcome-guided supervision)、**Windowed Interaction RL (WIRL)**。
- **WIRL**：把多次实验结果间的 multi-turn 决策作为一个 execution window → shared outcome reward；asynchronous collection + policy correction → trajectory 未结束即可更新。
- **结果**：MLE-Bench Lite 37.9% → **72.7%** (medal rate)，与 Kimi-K3 / GLM-5.3 相当；NatureBench Lite / agent scaffold / algorithm 优化等任务也可迁移。
- 详见 [[2026-10-18-2610.22344-mlexpert-generalist-agentic-model-for-au]]

### 2. **FDE-Gym: The Last Mile of AI Delivery** (2610.22350)
- **核心**：**95 个 end-to-end delivery tasks / 20 客户场景 / 18 行业**，FDE 风格（forward-deployed engineer）评估。
- **真实场景**：ambiguous 需求、live systems、unstated constraints 需主动发现。
- **评分**：normalised 0 (unchanged) → 1 (reference solution)，penalty 含 messages / trial runs / waiting。
- **结果**：13 模型配置 / 7 提供商。最佳 **0.56 mean score**，仅解决 14/95 task。
- **关键发现**：**unstated constraints 发现 = 首要瓶颈**；即便获得所有 key fact，仅 10/23 task 达 0.8+ uplift → 信息获取 ≠ 解决。
- 详见 [[2026-10-18-2610.22350-fde-gym-the-last-mile-of-ai-delivery]]

### 3. **Learning to Steer LLM Agents and Multi-Agent Systems** (2610.22316)
- **核心问题**：long-horizon tool-use / multi-agent 协作中**goal drift**。
- **方案**：**steering agent** — 监督 execution，drift 出现时介入。两条路径：
  - **Fast path** (low-cost) — 何时介入
  - **Slow path** (high-cost) — 如何介入
- **训练**：pairwise ranking + GRPO **联合训练双 path**。
- **结果**：在 information-seeking 任务上提升 single/multi-agent 性能与效率；steering intelligence 跨 OOD 任务、unseen executors 迁移，无需重训即可控介入频率。
- 详见 [[2026-10-18-2610.22316-learning-to-steer-llm-agents-and-mul]]

### 4. **Active vs Inert Facts: Linear Readability Predicts FT Generalization** (2610.22300)
- **核心**：并非所有可 recall 的 fact 都支持 generalization → 区分 **active facts**（可 generalize） vs **inert facts**（仅 recall）。
- **方法**：在原始 relation (Paris→Europe) 上**重新映射 label** (Europe→crab) → fine-tune 部分 subject，测试 held-out subjects 是否获得对应 label。
- **发现**：**原始 relation 在 pretrained representation 中越 linearly readable → fine-tune 后 generalization 越好**。跨 11 LM × 70 relations，**r = 0.87–0.92** per model。控制 #subjects / #answers / pretrain freq 等 confounders 后仍然稳健。
- **含义**：fine-tune generalization 更多取决于 fact 的**结构可线性读出性** vs recall 能力本身。
- 详见 [[2026-10-18-2610.22300-knowledge-that-is-linear-before-fine-]]

### 5. **CATCH: Continuous Adversarial Training for LLM Honesty** (2610.22292)
- **核心**：LLM 在关键场景（healthcare / legal / finance）仍输出 contradicted / unsupported claims。借鉴 adversarial refusal 思路 → **CATCH**（Continuous Adversarial Training for Consistent Honesty）。
- **训练**：训练模型**朝 honest answer 走 + 远离 dishonest**，同时保持 utility。
- **数据**：仅**数百 self-reporting scenarios** target。
- **结果**：Llama-3.3-70B-Instruct / Qwen3-3.6-27B 上：
  - **MASK** (pressure honesty) ↓ dishonesty
  - **Among Us multi-agent** ↑ confessions
  - **AuditBench** ↑ hidden behaviour discovery
- **vs SOTA honesty steering**：honesty 相当，但 utility **显著优**（novel utility data）。
- 详见 [[2026-10-18-2610.22292-catch-continuous-adversarial-training-]]

### 6. **Multi-Target Few-Shot Prompting with Diffusion Language Models** (2610.22294)
- **核心场景**：editing by example（多 site 同 formatting / API 迁移），依赖 left+right context → AR LM awkward。
- **方案**：用 **DLM 做 infilling**（masked 区域并行）→ 多个 masked region 在共享 canvas 上 infilled，examples guide。
- **关键技术**：**selective masking** + **likelihood-ratio reward**（favor example-supported infills）。
- **结果**：few-shot prompting benchmarks + software refactoring case studies 上 examples improve infilling accuracy。
- 详见 [[2026-10-18-2610.22294-multi-target-few-shot-prompting-with]]

### 7. **Librarian Agents: Anticipatory Workspace Curation** (2610.22273)
- **核心思想**：long-context reasoning 不应只靠 reactive retrieval 或 rigid KG → 训练 agent **预先重组 corpora 为 hierarchical filesystem**，服务未来查询。
- **架构**：**Builder agent** 把 raw documents 转成 synthetic files + reference links → workspace → 喂给 answering agent。
- **训练**：把 workspace construction 形式化为 **MDP** → 用 RL 直接优化**下游 answering accuracy**。
- **结果**：
  - **BrowseComp-Plus** 超最强 retrieval / precomputation baseline **+33 pp**。
  - 摊销 upfront construction cost。
  - **BRIGHT** unseen domains zero-shot **+31 pp avg**。
- 详见 [[2026-10-18-2610.22273-librarian-agents-training-llms-to-cur]]

### 8. **Hy-Memory-30B-A3B: Attributed RL for Long-Term Memory Writing** (2610.22196)
- **核心**：external memory 系统的质量取决于 write-path model — 决定 retain 什么、如何表示、evidence 如何更新 persistent state。
- **方案**：**Hy-Memory-30B-A3B**（compact 长期 memory writer）统一支持 Mem0 / MemOS / Hy-Memory 三套 framework。
- **两阶段训练**：
  - **Memory On-Policy Distillation** — framework-specific write protocols
  - **Memory RL** — dense per-chunk probes + attributed cross-chunk rewards + over-storage controls + **chunk-level GRPO**
- **关键技巧**：policy-written banks 跨 window 携带 → 训练与部署对齐。
- **结果**：20% benchmark subsamples 上**四个 harness 均第一**，含 held-out EverMemOS，**55.49% macro** vs Claude Opus 5 的 54.62%。
- 详见 [[2026-10-18-2610.22196-hy-memory-30b-a3b-attributed-reinforce]]

### 9. **AutoSFT: Agentic Automated Data Research in SFT** (2610.22194)
- **核心**：LM agent 自动化 post-training 时大多 converge to SFT，但 spent most effort 改 training data → 需要**完整 data action space**（proportions / prune / repair / replace / synthesize）。
- **发现**：single agent 只做到 adjust proportions，context 在 search 中被丢。
- **方案**：**多 agent**：
  - **Meta agent** 分离 execution 与 analysis
  - **Analysis sub-agents** 独立角度 proposal
  - **Synthesis sub-agent** 补 pool 没有的能力
- **结果**：IFEval +6.5 (analysis) / +3.4 IFEval +2.9 IFBench (synthesis)；代码 MBPP+ +3.7。每轮 retrain from base → 组件效果独立可测。
- 详见 [[2026-10-18-2610.22194-autosft-agentic-system-for-automate]]

### 10. **EMO: Closed-Loop Test-Time Compute via Context + Logits Steering** (2610.22160)
- **核心问题**：test-time context optimization (TCC) 缺对 distribution 改变的**强度控制**。
- **方案**：**EMO**（Expectation-Maximization 启发的训练免费框架）：
  - **E-step** — 用 textual gradient 更新 system context（无 gold answer）
  - **M-step** — revised vs preceding context 下 next-token 分布对比 → **confidence-constrained logit correction**
- **理论**：通过 target-KL objective + additive logit 表征连接 param / context opt；在小 steering strength 下证明 **one-round target KL decrease**。
- **结果**：8 模型 × 6 benchmark 上**39/40 setting 优 zero-shot**，平均 **+9.10 pp**；same judge 下比 TextGrad **+1.53**；best-of-N vs EMO 在 Llama 上最强。
- 详见 [[2026-10-18-2610.22160-emo-closed-loop-test-time-computation]]

### 11. **Believed but Not Said: Hidden Belief Collapse in Multi-Agent** (2610.22138)
- **核心问题**：multi-agent 互校假设 vs 真实鲁棒性。
- **方法**：10-agent factual discussion，**1–3 adversarial agents** 反复断言 plausible false answer。每轮 probe benign agent 的 private answer（独立 call，peers 不可见）+ 单独 label public stance。
- **关键数据**（6 模型 × 3 QA datasets）：
  - **无 attacker**：仅 0.6% benign agents 以 false 答案结束
  - **1 attacker**：**44.8%**
  - **3 attackers**：**60.5%**
- **hidden belief collapse**：3 attacker 时 benign agents 在 51.6% exposed turns 持有 false，但 public 仅 19.7% endorse → **影响多在表面下传播**。
- **含义**：multi-agent "peer-check" 不鲁棒；baseline knowledge 不能预测 robustness。
- 详见 [[2026-10-18-2610.22138-believed-but-not-said-measuring-hi]]

### 12. **Novelty Patching: Compression-Based Patch Routing for Byte LMs** (2610.22100)
- **核心问题**：byte-level LM (BLT) 依据 small-model next-byte entropy 起 patch → 错过 inline computed results (worked solution 里 "=" 后的数字)。
- **方案**：**Novelty patching**（LZ77 启发）：**前 2 bytes 查表 → 在 unlikely-to-repeat 的位置起 patch**。无需 labels / reference model / loss → 秒级 fit raw text。
- **结果**（BLT-style 1.9 GB math corpus, ~11% patch rate, 3 seeds）：
  - 1M params：no clear effect
  - **12M**：final-answer accuracy 47% → **72%**
  - **50M**：computed-result acc 21% → **57%**；final-answer acc 60% → **90%**
- **负面**：prose 上 novelty 降低 bpb，code / synthetic execution traces 上 tie entropy → 优势主要在 written math。
- 详见 [[2026-10-18-2610.22100-patch-where-the-text-is-new-a-comp]]

### 13. **TIPS: Tiny Inference-Time Policy for Diffusion LM Scaling** (2610.22099)
- **核心问题**：masked DLM 在 denoising pass 间**哪些 token 变 visible** 是 inference-time 决策；多数方法用 hand rule 或 monotonic visibility。
- **方案**：**TIPS** — **~600K 参数 controller**，frozen LM + learnable unmask/remask policy。visibility-aware confidence + 浅 transformer 选 token；固定 schedule 控制 expected visible fraction。
- **训练**：supervised warmup + **RL on terminal correctness rewards**。
- **结果**（GSM8K + MATH-500, LLaDA-8B-Instruct, 32 evaluations budget）：
  - full-canvas **58.46%**
  - two-block **57.97%**
  - **最强 baseline +12.1 / +11.6 pp**
  - 训练于 32 evals，无需重训在更高 budget 仍 competitive
- 详见 [[2026-10-18-2610.22099-tips-tiny-inference-time-policy-fo]]

### 14. **Close Enough is Nowhere Near: KV Cache Fidelity-Consumability Decoupling** (2610.22016)
- **核心问题**：multi-agent LLM 通过 KV cache 通信 → 直接 substitute reader cache 是否可行？
- **关键发现**：**不行**。frozen transformer 仅读**与自己会写的 cache 相近** 的子集（tolerable set）。**几何相似度不能预测 reader 能否用** → 高 fidelity ≠ high usability。
- **解释**：competitive attention — 不在 reader 自己写的 cache 邻域内 → 无法 attends。
- **实验**：8 种 substitution methods × 2 锚点（uninformative baseline / reader 自读）→ **全部 baseline**。意味着"更忠实的 substitute" 不是方向。
- **可行路径**：reader **保留自己 cache + 跨 sender cache attends**，**仅微调 queries** → 超 baseline，且 8 senders pool 后超越 undirected attention over same union。
- 详见 [[2026-10-18-2610.22016-close-enough-is-nowhere-near-fidelit]]

### 15. **TEM: Temporal State Tracking Memory for LLM Agents** (2610.21900)
- **核心问题**：agent memory 跨 conversation 信息变化时，**新 fact 可替代旧 value，但旧 value 仍可对后续 question 重要**。
- **方案**：**TEM** — training-free framework：
  - Facts 存为 **versioned records** linked to sources
  - Retrieve 相关 versions，**按 source 顺序排列**
  - **Label historical records**（标"已过期/历史"）后传给 answer model
  - Event memory + 原始 dialogue turns 补 structured fact 缺失
- **结果**：
  - 420 questions / 600 sessions / 60 personas 上，**4 open-weight models key-entity hit rate 75.71–97.62%**（historical-residence subset **96.67–100%**）
  - 加 historical labels 后 overall **+17.14–55.95 pp**
  - 证据仅 **94–118 tokens** per answer，**比 session-aware RAG 少 48.75–56.73%**
  - 1,540 LoCoMo questions 上超 session-aware RAG，conservative Δ **+7.92 / +10.58 pp**
- 详见 [[2026-10-18-2610.21900-tem-temporal-state-tracking-memory]]
