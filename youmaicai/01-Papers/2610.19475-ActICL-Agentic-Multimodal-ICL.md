## 核心贡献

1. **MLLM agent 自己学习怎么 judge 需要新 demo + 工具调用 progressive retrieval**
2. **两阶段 post-training 联合优化 acquisition + answering**
3. **Context transferability**：ActICL agent 获取的 context 可被其他 model（如 GPT-5.6-Sol）有效使用

## 方法

### ActICL agent workflow

```
1. Analyze information gaps（自反思）
2. Tool-augmented retrieval：targeted 候选
3. Iterative refine / filter / re-retrieve
4. Judge 足够 OR resource limit reached
5. Hand off context → answering model（自己或另一个 MLLM）
```

### 两阶段 post-training

- Stage 1：训练 agent acquisition 策略
- Stage 2：联合优化 acquisition + answering

### Adaptive demo count

- 不是固定 N-shot
- 根据 task complexity 调整 demo 数量

## 实验结果

- 3 MLLMs × 7 benchmarks
- vs standard similarity retrieval：平均 **+11.6pp**
- vs strongest prior baseline：平均 **+4.4pp**
- **Transfer**：GPT-5.6-Sol 4-shot ICL 用 ActICL 提供的 context → **+3.5pp** over standard retrieval（3 benchmarks 平均）

## 局限性

- 工具调用 → 部署时需要 MLLM 支持 tool use API
- Progressive retrieval 增加 latency（多次工具调用）
- Two-stage post-training 增加训练成本

## 建议

- **是否推荐使用**：是
- **适用场景**：multimodal ICL / MLLM few-shot 推理 / multimodal RAG
- **推荐路径**：替换 fixed-N + similarity retrieval 的 ICL pipeline
- **运营价值**：context 可 transfer → ActICL 投资一次，多个下游 model 共享
