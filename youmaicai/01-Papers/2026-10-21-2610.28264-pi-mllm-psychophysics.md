## 核心贡献

> 提出 **PI-MLLM** —— 受心理物理学的**模态融合定律**启发，解决「Oddly Satisfying Videos（OSV）情绪分析」：这类视频靠**重复运动、视觉触感、ASMR 类声音**引发强烈观众反应，却**几乎不含显式语义情绪线索** —— 正是现有 VEA 方法的盲区。

1. **构建 OSVD 数据集**：**12,000 条标注的 5 秒片段**
2. **三条件标注**：video-only / audio-only / **audio-visual** 条件下分别标注观众情绪
3. **感知证据支撑的解释**：解释**基于视觉与声学的感知证据**，而非场景语义
4. **两个核心模块**：
   - **MSDA**（Modality-Specific Dynamics Alignment）：用辅助预测目标把模态表示对齐到**视觉运动**与**声学能量起始（energy onset）动态**
   - **CAVA**（Coalition-Based Audio-Visual Attribution）：在模态**联盟**上评估情绪分数，用 **Shapley 归因**识别**主导模态**，并判断视听证据是**协同还是冲突**
5. **效果**：同时改善观众侧情绪预测与感知接地的解释质量

## 技术方案

### 为什么需要心理物理学

| 现有方法焦点 | OSV 的实际机制 |
|-------------|---------------|
| 语义视频内容 | 重复运动（visual） |
| | 视觉触感（tactility） |
| | ASMR 类声音（acoustic） |
| → 几乎无显式语义线索 | → **物理感官动态主导情绪** |

**PI-MLLM 的转向**：从「语义内容理解」转向「物理感官动力学建模」。

### OSVD 数据集标注设计

| 标注维度 | 说明 |
|---------|------|
| 时长 | 5 秒片段 × 12,000 |
| 条件 | video-only / audio-only / **audio-visual**（解耦模态贡献） |
| 情绪标签 | 观众侧（viewer-side）情绪 |
| 解释 | **感知证据支撑**（视觉 + 声学），非场景语义 |

### MSDA：模态特定动态对齐

用辅助预测目标将表示对齐到：

```math
\mathcal{D}_{\text{visual}} = \text{visual motion dynamics}, \quad
\mathcal{D}_{\text{acoustic}} = \text{acoustic energy-onset dynamics}
```

各模态对齐到**自身的物理动态**，而非共享的语义空间。

### CAVA：联盟式视听归因

在模态联盟 $\{v, a, (v,a)\}$ 上评估情绪分数，应用 **Shapley 值**：

```math
\phi_m = \sum_{S \subseteq M \setminus \{m\}} \frac{|S|!\,(|M|-|S|-1)!}{|M|!}
\Big( v(S \cup \{m\}) - v(S) \Big)
```

输出：
1. **主导模态**（visual / audio）
2. **视听证据关系**：**协同（synergistic）** vs **冲突（conflicting）**

## 局限性

- **OSV 是窄场景** —— 「怪异满足」的情绪机制不能外推到通用视频情绪分析
- 5 秒片段**无法捕捉长程情绪演化**与叙事结构
- MSDA 的辅助预测目标需要**运动/能量起始的时序标注**，获取成本未说明
- Shapley 归因在模态数 >2 时组合爆炸；此处只有 2 模态，扩展性未验证
- 8B 级模型在极端主观情绪标注上的一致性未讨论

## 实现建议

- **方法论可迁移性（这才是重点）**：本文的**范式**比任务本身更有价值 ——
  - **模态解耦标注**（单模态 + 多模态条件）用于识别主导模态
  - **Shapley 联盟归因**用于判定模态是协同还是冲突
  - 这套方法可直接用于**任何**多模态模型的情绪/意图归因诊断
- **适用场景**: 需要回答「模型到底靠哪个模态做判断」的场景（可解释性审计、模态失效诊断）
- **落地建议**: 把 CAVA 作为**诊断工具**接入现有 MLLM 评测流程 —— 它不改动模型，只给归因报告
