## 核心贡献
1. 提出 **KOPA-Bench**：145 个真实世界任务，测试多步工具调用能力
2. 提出 **EDGE** (Execution-grounded Dynamic Graph)：基于实时执行驱动的工具调用数据合成方法，构建工具输出到输入的图，只保留经 live API 验证的链接
3. 使用 GRPO 微调，9B 模型几乎匹配未微调的 27B 模型

## 训练方法
- GRPO 微调
- EDGE 数据合成：通过实时 API 执行验证工具链接，合成可执行多步轨迹

## 实验结果
- 9B 模型通过 EDGE GRPO 微调后几乎匹配未微调 27B 模型
- 在 KOPA-Bench 和 BFCL 基准上均有提升
