# Memory Portability Across Model Upgrades

## 元信息
| 标题 | Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability |
|------|------|
| 链接 | [原文](https://arxiv.org/abs/2609.05339) |
| arXiv | arXiv:2609.05339 |
| 领域 | cs.AI, cs.CL, cs.IR |

## 核心贡献
1. 首次系统研究 Agent 记忆在模型升级后的**可移植性**
2. 四种记忆表示：LC-RAW（完整上下文）、RAG（分块检索）、NOTES（压缩为自然语言笔记）、KG-fixed（固定模式知识图谱）
3. 48 个合成历史，使用两个子 10B 参数开放权重模型测试

## 模型架构
- 四种记忆表示：verbatim 历史、RAG 分块、压缩笔记、固定模式知识图谱
- 诊断分解方法将准确率 deficit 归因于信息丢失或检索失败

## 实验结果
- **KG-fixed 可靠传输**：模型交换后准确率仅变化 $+0.0004 \pm 0.0020$
- **NOTES 高模型耦合**：不对称偏移 +9.91 或 -13.28 百分点
- **RAG 部分嵌入迁移**：50/50 混合索引仅捕获 4.96 百分点提升（完全重嵌入获 11.90）
- NOTES 80% deficit 源于初始构建信息丢失，RAG 81% 源于检索失败
- 仅 store-only 修复无法达到 90% 性能恢复目标
