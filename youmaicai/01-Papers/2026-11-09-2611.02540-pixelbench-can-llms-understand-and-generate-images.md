# PixelBench: Can LLMs Understand and Generate Images Pixel by Pixel?

> **arXiv**: [2611.02540](https://arxiv.org/abs/2611.02540)
> **发表日期**: 2026-11-02
> **分类**: cs.CV (及交叉分类 cs.CL, cs.LG)
> **会议/期刊**: arXiv preprint（Technical report, 38 pages, 7 figures；项目页 https://haoquanzhang.github.io/pixelbench）

## 📋 摘要

大语言模型可以通过 SVG、CAD 等文本格式生成视觉素材，但这些符号表示是用高层图元来描述图像，而非显式的光栅值。本文提出一个核心问题：LLM 能否不依赖学习得到的 image tokenizer 或 decoder，直接通过既有词表逐像素地生成图像？为此作者提出 PixelBench，一个覆盖多分辨率的 text-to-pixel（T2P）与 image-to-pixel（I2P）生成基准，并配有互补的像素理解评测。模型先生成一个 RGB 调色板，再输出一张索引网格，指定每个输出像素对应调色板中的哪种颜色。结果显示：最强的模型在 T2P 上已能直接从文本生成可辨认的图像；在 I2P 上，最强模型在低分辨率下超过了调色板匹配下采样与专用 pixelization 算法。像素理解能力与生成能力高度相关。分辨率扩展研究表明，像素生成性能通常先随分辨率提升而改善，但在高分辨率下反而下降。最后作者提出 Pixel Reconstruction Tuning（PRT），在视觉指令微调中混入 caption–palette–grid 轨迹；从预训练 checkpoint 后训练 Molmo2-4B（通用指令数据 + PRT 数据混合），在 16 个视觉中心基准上均有提升，说明显式像素重建可作为有用的辅助监督信号。

## 🎯 核心贡献

1. **提出 PixelBench 基准**：首次系统性考察 LLM 在不使用学习式 image tokenizer/decoder 的前提下，能否直接以文本形式逐像素生成图像（text-to-pixel 与 image-to-pixel），覆盖多分辨率并附带像素理解评测。
2. **"调色板 + 索引网格"输出范式**：模型先生成 RGB 调色板，再生成逐像素的颜色索引网格，把连续光栅信号转成 LLM 可自然处理的离散符号序列。
3. **揭示像素理解与像素生成的强相关性**：理解任务表现可作为生成能力的代理指标，为低成本评测提供抓手。
4. **分辨率扩展规律**：性能随分辨率通常先升后降，高分辨率下生成质量反而退化。
5. **提出 Pixel Reconstruction Tuning（PRT）**：通过 caption–palette–grid 轨迹进行后训练，Molmo2-4B 在 16 个视觉中心基准上性能提升，验证显式像素重建作为辅助监督的价值。

## 🔧 方法/架构

- **任务设定**：两类生成任务——T2P（文本 → 像素图像）与 I2P（图像 → 像素重建），外加像素理解评测作为互补维度。
- **输出表示**：两阶段序列生成。先生成 RGB 调色板（有限个颜色三元组），再生成与目标分辨率同尺寸的索引网格，网格中每个元素指示该像素取调色板中的哪一种颜色。这把"画图"降解为 LLM 擅长的离散符号预测问题。
- **不使用图像 tokenizer/decoder**：这是本工作的核心约束，目的是测量 LLM 词表与解码能力本身在像素级视觉生成上的上限与瓶颈。
- **基线对照**：I2P 任务上与"调色板匹配下采样"（palette-matched downsampling）以及专用 pixelization 算法对比。
- **PRT 后训练**：在视觉指令微调数据中混入 caption–palette–grid 三元轨迹，从 Molmo2-4B 的预训练 checkpoint 出发做混合后训练。
- **分辨率扫描**：在多档分辨率上分别评测 T2P / I2P / 理解任务，用于刻画分辨率–性能的非单调关系。

## 📊 实验结果

- **T2P**：最强模型能够直接从文本生成"可辨认（recognizable）"的图像。
- **I2P**：最强模型在**低分辨率下**超过调色板匹配下采样与专用 pixelization 算法。
- **相关性**：像素理解性能与生成性能"strongly correlates"。
- **分辨率规律**：性能通常先改善，高分辨率下下降。
- **PRT 后训练**：Molmo2-4B（从预训练 checkpoint 后训练）在 **16 个视觉中心基准**上均有提升。
- **具体数值**：摘要未给出准确率/参数量等具体数值（详见原文实验章节）。

## ⚠️ 局限性

- **调色板表示本身有表达力上限**：颜色数受限、索引网格只能引用有限颜色，无法表达平滑渐变与高频纹理；"可辨认"的程度因此被表示方式而非模型能力部分决定。
- **上下文长度与序列长度压力**：高分辨率下的索引网格极长（随分辨率平方增长），token 成本与长程一致性是硬约束——这也解释了高分辨率下性能下降的现象。
- **模型规模偏小**：实验以 Molmo2-4B 为主，结论向更大规模模型的迁移性未验证。
- **仅覆盖受控条件下的生成**：与真实世界图像分布（照片、自然场景）的差距未系统评估。
- **PRT 的收益可能部分来自"通用指令数据 + PRT 混合"这一训练配方本身**，难以完全归因于像素重建监督。
