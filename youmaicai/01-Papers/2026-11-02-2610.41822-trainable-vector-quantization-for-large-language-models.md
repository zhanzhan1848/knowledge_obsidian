# 可训练向量量化：LLM 权重量化的梯度下降方案

| **摘要** | Vector Quantization (VQ) is a rapidly evolving technique for compressing Large Language Model (LLM) weights, reducing memory usage, and speeding up inference. However, extreme compression deteriorates model performance, which is challenging to recover due to the discrete nature of VQ parameters. Existing methods employ training-free approaches that are limited to layer-wise reconstruction loss minimization. To address this limitation, we propose TVQ, a novel method that leverages straight-through estimation to enable gradient descent-based optimization of vector-quantized LLMs. By reformulating VQ LLM optimization with trainable latent weights, TVQ enables arbitrary objective minimization. We constitute our approach by applying TVQ in a block-wise knowledge distillation paradigm, which balances quality and training efficiency, and propose several practical solutions to accelerate training. In experiments on modern LLMs, we demonstrate that TVQ is compatible with modern VQ schemes. As a result, TVQ achieves state-of-the-art quality in low-bit post-training quantization settings with a modest training budget and straightforward PyTorch implementation. For instance, TVQ achieves near-lossless 2-bit quantization for LLaMA2-70B with only 1% accuracy drop on popular Question-Answering benchmarks. |

## 核心贡献

1. **问题**：向量量化（VQ）是压缩 LLM 权重、降低内存、加速推理的有效手段，但**极端压缩会显著劣化性能**，且**因 VQ 参数的离散性而难以恢复**。
2. **现有方法的局限**：均为**免训练**方法，且局限于**逐层最小化重建损失（reconstruction loss）**。
3. 提出 **TVQ（Trainable Vector Quantization）**：利用 **straight-through estimation（STE）**，为**向量量化后的 LLM 启用基于梯度下降的优化**。
4. **关键重构**：将 VQ LLM 优化问题**改写为可训练隐权重（trainable latent weights）的形式**，从而**支持任意目标的最小化** —— 不再局限于重建损失。
5. **实践范式**：将 TVQ 应用于**块级知识蒸馏（block-wise knowledge distillation）**，平衡质量与训练效率，并提出若干加速训练的技术方案。
6. **结果**：兼容现代 VQ 方案，在**低比特后训练量化**设定下以**适度训练预算**达到 SOTA 质量，**实现简单的 PyTorch 实现**。代表案例：**LLaMA2-70B 的近无损 2-bit 量化，QA 基准上仅 1% 准确率下降**。

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| 技术 | 说明 |
|------|------|
| Straight-through Estimation | 让离散 VQ 参数可被梯度优化 |
| 可训练隐权重 | 改写优化问题以支持任意目标 |
| 块级知识蒸馏 | 质量与训练效率的平衡范式 |
| 低比特后训练量化 | 2-bit 级别 |
| PyTorch 实现 | 无需自定义 CUDA kernel |

### 关键发现

- **STE 让 VQ 可训练**是这个领域长期缺失的一块：VQ 的离散性一直是"训练不了"的根本障碍，TVQ 用隐权重重构绕开了它。
- **"支持任意目标最小化"** 是范式转变 —— 从"重建损失"这一个目标解放出来，意味着可以直接优化**下游任务表现**而非代理指标。这与 [[2026-11-01-2610.37157-what-survives-distillation-mechanistic]] 的教训直接呼应：**重建损失不等于能力保留**。
- 与 [[2026-11-02-2610.41236-experts-exhibit-structured-redundancy-structure-preserving-expert-prunin]]（MoE 专家剪枝）同属今日压缩主线，但视角更激进（改优化问题 vs 改剪枝目标）。
- 2-bit + 1% 掉点的组合在 70B 尺度上是很强的工程结果 —— 这对本地部署意义重大。
