## 核心贡献
1. **提出了一个新的失效机制诊断：premature commitment（过早承诺）**。论文主张多模态离散扩散语言模型（mdLLM）的幻觉**不仅是 token 预测问题（WHAT），更是承诺时机问题（WHEN）**。标准 blockwise 解码按置信度 $c_i^{(s)}$ 排序并提交 top-$k$ 位置，而置信度**无法区分视觉证据与语言先验**——某些位置的高置信度来自"golf club"这类提示诱导的强语言先验而非图像证据，一旦被过早提交，其 token 通过双向注意力对所有剩余 masked 位置可见，后续预测被条件化于该早承诺，从而让幻觉结构**自我传播与强化**。
2. **提出 VIGOR（Visual Gain Ordering）**：training-free、plug-and-play 的推理策略，**只替换承诺顺序的排序准则，不改参数、不改解码器架构、不改变任何位置偏好的 token**。
3. **核心机制：反事实视觉消融（counterfactual visual-ablation）**。每个去噪步除标准图像条件前向外，再跑一次视觉输入被消隐的额外前向（文本上下文与部分生成结果不变）：

$$p^{(s)}_{i,\text{img}} = p_\theta(y_i \mid I, q, z^{(s)}), \qquad p^{(s)}_{i,\text{noimg}} = p_\theta(y_i \mid \varnothing, q, z^{(s)})$$

消融 pass **不用于选择新 token**，只为 image-conditioned pass 选出的同一候选 token 提供反事实置信度。
4. **无参数的 visual-gain 打分（绝对 + 相对双尺度）**：

$$s_i^{(s)} = \underbrace{\left|c^{(s)}_{i,\text{img}} - c^{(s)}_{i,\text{noimg}}\right|}_{\Delta_i^{(s)}\ \text{(absolute scale)}} + \underbrace{\log\frac{c^{(s)}_{i,\text{img}} + \varepsilon}{c^{(s)}_{i,\text{noimg}} + \varepsilon}}_{R_i^{(s)}\ \text{(relative scale)}}, \quad \varepsilon = 10^{-8}$$

绝对项防止"比值大但绝对置信度低"的 token 胜出；相对项突出"由视觉证据专门诱导"的候选。**两个尺度各盲一个 regime**：当 $c_{\text{img}} \approx c_{\text{noimg}}$（对抗性提示同时抬高两者）时 $\Delta$ 失去信号；当两者都接近先验地板时 $R$ 会放大微小分母产生任意分数。
5. **全面的实证优势**：在 LLaDA-V 与 Lumina-DiMOO 上、三个幻觉敏感基准（POPE、CHAIR、AMBER）上**所有子集所有指标一致优于** vanilla、VCD 与 ICT 基线。相对 vanilla：LLaDA-V 平均 accuracy **+4.7**、F1 **+3.1**；Lumina-DiMOO accuracy **+2.6**、F1 **+8.3**。
6. **机制性诊断分析**：用 step-0 JSD 度量视觉敏感度——baseline 倾向提交低-JSD 位置，VIGOR 把早提交移向高-JSD 位置；被 VIGOR 提前的位置 step-0 JSD 更高，**44.2% 的被分析位置被提前提交**；候选 token 差异比随解码步增长，说明重排序**贯穿整个解码过程传播**。
7. **Cascade suppression 的直接证据**：在 LLaDA-V 的 AMBER 分析中，错误样本的**早期不稳定提交率从 50.2% 降到 26.0%**——直接支持"阻断早承诺 → 阻断错误级联"的机制。
8. **Yes-rate 校准改善**：VIGOR 把 yes-rate 向平衡先验 50% 拉近（random split −3.9 pts，adversarial −4.9 pts），说明它同时缓解了物体偏置。

## 问题背景
自回归 LVLM 之外，多模态离散扩散语言模型（mdLLM）通过迭代 mask prediction 生成回答，代表 LLaDA-V、Lumina-DiMOO、MMaDA、LaViDa 等新兴方向，并具备效率与可控性优势。但它们同样存在幻觉——生成的回答在语言先验下合理，却未充分 grounded 在图像上。

**关键差异**：在自回归解码中，幻觉通常被视为 **token 选择问题**——模型因强语言先验或弱视觉 grounding 而过度预测语言上可信但视觉上无支撑的 token。而在 mdLLM 中，生成通过迭代去噪进行，解码器不仅要决定**预测什么 token**，还要决定**每个 masked 位置何时被承诺**。现有 blockwise 解码器按置信度排序并提交 top-ranked 位置，但**这个置信度在多模态场景下是有误导的**。

已有缓解策略分三类：额外监督的微调、辅助视觉信号的感知增强、推理时的对比解码/logit 修正。这些方法对自回归 LVLM 有效，但都针对"**应该生成哪个 token**"，**不直接处理"哪些位置应该更早/更晚被承诺"**。少数并发工作开始分析 dLLM 幻觉并探索 remasking，但都针对纯文本 dLLM，**未处理视觉证据与语言先验在多模态解码中的交互**。

Figure 1 给出了完整的因果链：自回归 LVLM 因 "golf club" 提示诱导的强先验而预测 *golfer*（仅 WHAT 错误，WHEN 被严格左到右固定）；mdLLM 中 *golf* 位置因先验（而非视觉证据）获得高置信度而过早提交，**通过双向注意力把后续去噪偏置到 *golfer***（WHAT 错误由 WHEN 错误级联而来）。VIGOR 通过让 *Curry*（视觉有支撑）提前提交、推迟 *golf*（先验主导），把生成导向正确答案 *basketball player*。

## 方法
### 1. Blockwise 解码的形式化
给定图像 $I$ 与 prompt $q$，模型在去噪步 $s$ 维护部分掩码的响应 $z^{(s)} = \{z^{(s)}_1, \ldots, z^{(s)}_T\}$，每个位置要么是已承诺 token 要么是 [MASK]。$M^{(s)} = \{i : z^{(s)}_i = [\text{MASK}]\}$ 为当前 masked 位置集合。每个步对所有 masked 位置预测分布：

$$p_i^{(s)} = p_\theta(y_i \mid I, q, z^{(s)}), \qquad i \in M^{(s)}$$

候选 token 与置信度：$\hat y_i^{(s)} = \arg\max_{y \in V} p_i^{(s)}(y)$，$c_i^{(s)} = p_i^{(s)}[\hat y_i^{(s)}]$。标准 blockwise 解码按 $c_i^{(s)}$ 排序并提交当前 block 内的 top-$k_s$ 个：

$$C^{(s)} = \text{TopK}_{i \in M^{(s)} \cap B^{(s)}}\left(c_i^{(s)}\right), \qquad k_s \text{ 由解码调度决定}$$

$$z_i^{(s+1)} = \begin{cases} \hat y_i^{(s)}, & i \in C^{(s)} \\ z_i^{(s)}, & \text{otherwise} \end{cases}$$

**级联机制**：被过早提交的位置的 token 通过双向注意力对所有剩余 masked 位置可见，后续预测被条件化：

$$p_j^{(s+1)} = p_\theta(y_j \mid I, q, z^{(s+1)}), \qquad j \in M^{(s+1)}$$

### 2. 反事实视觉消融
除标准图像条件分布外，跑第二个前向，视觉输入被消隐而文本上下文与部分生成响应保持不变，得到 $p^{(s)}_{i,\text{noimg}}$。判据：**若该候选在视觉消融后仍高置信，其偏好很可能由语言先验主导；若置信度显著下降，则更可能是视觉 grounded**。

### 3. Visual Gain Ordering
对每个 masked 位置，用 image-conditioned pass 选出的候选 $\hat y_i^{(s)}$，评估其在两个分布下的置信度：

$$c^{(s)}_{i,\text{img}} = p^{(s)}_{i,\text{img}}[\hat y_i^{(s)}], \qquad c^{(s)}_{i,\text{noimg}} = p^{(s)}_{i,\text{noimg}}[\hat y_i^{(s)}]$$

然后用 Eq. 7 的双尺度 score $s_i^{(s)}$ 替换原始置信度：

$$C^{(s)} = \text{TopK}_{i \in M^{(s)} \cap B^{(s)}}\left(s_i^{(s)}\right), \qquad k_s$$

**关键性质：候选 token $\hat y_i^{(s)}$ 本身不变**。VIGOR **不改变某个位置偏好哪个 token，只改变它何时被允许提交**。视觉证据支持的预测更早提交，先验主导的则被推迟，使去噪轨迹与视觉证据对齐，并减少早承诺导致的结构性幻觉。

### 4. 实现
VIGOR 仅在推理时应用。每个解码步跑标准图像条件前向 + 视觉消融前向，计算 Eq. 7 的排序分数，用它在当前 block 内选 top-$k$ masked 位置。**生成长度、block 调度、基模型参数全部不变**，只替换 blockwise 承诺的排序规则。全部实验用 greedy decoding（temperature = 0），因此 baseline 与 VIGOR **只差排序分数 $s_i$**，给定固定输入结果是确定的。实验在 3 张 NVIDIA A100 上进行。

## 关键洞察
1. **"WHEN 错误"是独立于"WHAT 错误"的一类幻觉机制，且可以单独修复。** 自回归解码中 token 顺序固定，只有 WHAT 可选；mdLLM 中承诺顺序是在线的，因此**多出一个独立的干预维度**。VIGOR 证明只改这个维度、不改任何 token 选择，就能带来一致的幻觉下降——这是对扩散解码范式的一个结构性洞察。
2. **"承诺顺序"在双向注意力下是因果性的，不只是效率问题。** 自回归模型中早提交只是"前面错了后面跟着错"；mdLLM 的双向注意力让早提交的 token **对所有剩余 masked 位置可见**，从而让幻觉结构**自我强化**。这解释了为什么同样的置信度排序在 mdLLM 上更有害。
3. **反事实消融是分离"证据"与"先验"的一个通用技术**，且在这里几乎零成本（一次额外前向）。它不修改任何生成内容，只提供一个诊断量。这个模式可以推广到任何"多模态 + 生成"场景中需要区分"模型看到了"与"模型猜到了"的地方。
4. **双尺度打分的必要性来自两个互补的失效 regime，且只有在困难子集上才能被发现。** 单尺度在 random split 上看起来够用（都优于 baseline），只有 adversarial split 暴露了 LOGRATIO-ONLY 的灾难性失败。这是一个**评测设计的教训**：如果只在随机子集上做消融，会得出错误的组件必要性结论。
5. **Yes-rate 是一个廉价且敏感的平衡指标。** 把 yes-rate 推向 50% 的平衡先验，可以同时暴露过度肯定与过度否定；DIFF-ONLY / LOGRATIO-ONLY / full 三者在这一点上的分离（−4.8 / +3.6 / −4.9）比 accuracy 更能区分机制。
6. **VIGOR 改善 grounding 但不改善识别。** 案例分析显示它仍误判球员性别——它是**幻觉缓解器**而非**感知增强器**。这划清了它的能力边界，也说明它与"感知增强"类方法（辅助视觉信号）互补而非替代。
7. **长度依赖性揭示了机制的作用条件**：长度 64 时改进幅度远大于长度 512（CHAIR$_S$ 32.7→24.8 vs 47.5→42.4）。当早承诺对最终输出影响更大时，修正承诺顺序的收益更大——这为"何时该用 VIGOR"提供了实用判据。
8. **弱基线模型受益更大**：Lumina-DiMOO 的 Hal 从 67.5 降到 50.2（−17.3），远大于 LLaDA-V 的 −4.2。论文的解释是"当先验驱动的承诺更频繁时 VIGOR 更有帮助"——这提示 VIGOR 特别适合幻觉更严重的多模态扩散模型。

## 局限性
- **解码时间大约翻倍**：VIGOR 需要每个去噪步额外的 no-image 前向，论文自己在结论中承认"roughly doubling decoding time in our experiments"。论文只报告了"与等价全分辨率推理相比"的对比（那是 LoopKV 那篇），本文**未给出 VIGOR 的绝对延迟数字**，也没有与"减少步数"等补偿策略对比。
- **需要访问内部解码分数与控制承诺调度**，因此最适合开源权重或可控模型；对闭源 API 不可用。
- **只在两个 mdLLM 上验证**（LLaDA-V、Lumina-DiMOO），未测其他（MMaDA、LaViDa）或纯文本 dLLM；模型依赖的差异（LLaDA-V 偏 accuracy、Lumina-DiMOO 偏 F1）被归因为"model-dependent calibration"但未深究。
- **只测了三个幻觉基准**，均为物体/属性层面的幻觉；未测需要组合推理、计数、空间关系的多步任务上的效果，也未测文本质量、指令遵循等非幻觉维度的**回归风险**——重排序可能让某些正确答案被推迟而带来副作用，论文未做 trade-off 分析。
- **消融只在 LLaDA-V 的 COCO POPE 上做**（Table 3），未在 Lumina-DiMOO 或 CHAIR/AMBER 上验证双尺度的必要性。
- **未与"直接提高视觉 grounding 权重"这类简单基线对比**，例如按 attention-to-image 排序；双尺度 score 的必要性是相对 DIFF-ONLY/LOGRATIO-ONLY 证明的，而非相对所有可能排序准则。
- **诊断分析用 JSD 作为视觉敏感度的代理**，其本身是近似；44.2% 的"提前比例"依赖于 JSD 的定义与阈值。
- **无法纠正基模型固有的识别错误**（案例中的性别误判），因此当幻觉源于真正的感知缺陷而非先验主导时，VIGOR 无效——论文承认但未量化这类场景的占比。

## 适用场景
- **适合**：多模态离散扩散语言模型（mdLLM）的推理部署——LLaDA-V、Lumina-DiMOO 等；需要降低物体幻觉率而不重训模型的场景（training-free 是核心优势）；长文本生成（长度 64–512 的 caption/描述）比极短输出的场景；幻觉较严重的模型（收益更大）；对延迟不敏感或可接受 2× 解码开销的批处理/离线任务。
- **不适合**：自回归 LVLM（WHEN 维度不存在，方法的前提不成立）；闭源 API 模型（需访问内部分数与控制解码调度）；延迟敏感的实时交互（解码时间翻倍）；基模型存在严重感知缺陷的场景（VIGOR 不改善识别）；需要严格控制解码确定性的生产系统（额外前向增加状态管理复杂度）。
