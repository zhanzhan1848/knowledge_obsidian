## 核心贡献

> **记忆检测方法本身会污染测量结果**：consistent identifier renaming (CIR) 得到的分数下降中，大部分**不是记忆**，而是"按名字打分的评测方式"造成的。本文在 TLA+ 上用 model checker 作为行为 oracle 把这三者拆开。

1. **在 TLA+ 上检验 CIR**：TLA+ 的 model checker 可确认重命名后的任务是否保持**完全相同的行为**，提供了区分"记忆"与"命名效应"的天然 oracle
2. **揭示命名混淆（name-based grading）**：以**精确名称**打分的评测要求答案中出现任务描述里从未给出的标识符，导致重命名后被错误判错
3. **按行为打分后记忆效应大幅收缩**：从名义上的大幅下降收缩到 **Opus 4.8 约 3 个百分点**、**GPT-5 为 0**
4. **微调场景下的真实记忆代价**：在两个任务不相交半区上微调的模型家族中，重命名移除约**一半的训练增益**（likelihood 层面），在未见任务上分别损失 **4.9 pp（Qwen）** 与 **1.3 pp（Gemma）**
5. **方法论结论**：重命名后的低分**混合了三种成分** —— 记忆、名字打分、引入新名字本身的成本

## 技术方案

### 核心概念：Consistent Identifier Renaming (CIR)

| 要素 | 说明 |
|------|------|
| 操作 | 给任务中**每一个标识符**换成新名字（一致地换） |
| 原始用法 | 若重命名后分数下降，被视为**记忆（recall）**的证据 |
| 本文质疑 | 下降的**归因**未被验证 —— 可能来自记忆，也可能来自评测打分依赖精确名称 |

### 三种混淆成分

| 成分 | 含义 | ALIAS 如何分离 |
|------|------|------|
| Memorization | 模型在训练中见过原答案 | 以"同一模型家族在不相交任务半区微调"对照 |
| Name-based grading | 打分器要求精确匹配名字 | 引入 **behavior-based grading**（以 model checker 判定行为等价） |
| Cost of new names | 新名字本身引入的额外难度 | 模型 checker 确认重命名任务保持原行为后再对照 |

### 关键技术

| 技术 | 说明 |
|------|------|
| TLA+ model checker as oracle | 确认重命名后的任务是否**精确保留原任务的行为**，从而排除"新名字更难"这一混淆 |
| Behavior-based grading | 以行为等价而非名称匹配打分；对照组即 CIR 后的同一任务 |
| Disjoint-half fine-tuning | 把任务集切成互不相交的两半分别微调两个模型家族，直接测量记忆带来的增益及其在未见任务上的迁移 |
| Likelihood-based analysis | 在 likelihood 层面量化"重命名移除约一半训练增益" |

## 关键实验结果

| 设定 | 指标 | 数值 |
|------|------|------|
| 111 个 TLA+-Bench 任务 | Claude Opus 4.8 按名称打分：正确率 | **28% → 18%**（重命名后下降 10 pp） |
| 111 个 TLA+-Bench 任务 | GPT-5 按名称打分：正确率 | **9% → 7%**（重命名后下降 2 pp） |
| 改为行为打分 | Claude Opus 4.8 下降幅度 | 收缩到**约 3 个百分点** |
| 改为行为打分 | GPT-5 下降幅度 | 收缩到 **0** |
| 不相交半区微调 | likelihood 层面训练增益 | 重命名移除**约一半** |
| 不相交半区微调（Qwen） | 未见任务正确率损失 | **4.9 个百分点** |
| 不相交半区微调（Gemma） | 未见任务正确率损失 | **1.3 个百分点** |

## 关键结论

1. **"重命名后掉分"≠"记忆"**。在 TLA+ 上，绝大部分名义下降来自**按名字打分**——评测要求答案包含任务描述中从未陈述的标识符。
2. **行为打分能几乎完全消解 GPT-5 的表观记忆效应**（0 下降），Opus 4.8 仍剩约 3 pp 才是较可信的记忆信号。
3. **记忆效应在微调场景中才是可测的实质问题**：重命名移除约一半训练增益，且该效应在**未见任务**上表现为 **Qwen -4.9 pp / Gemma -1.3 pp**。
4. **评测方法论要求**：若要宣称"检测到了记忆"，必须证明评分机制**对重命名不敏感**，否则结论会被打分方式的伪影污染。

---

## 局限性

- 结论基于**单一形式化语言（TLA+）与单一基准（TLA+-Bench，111 任务）**，外推到自然语言任务未经验证
- 摘要**未给出行为打分后的绝对正确率**，只给了下降幅度（3 pp / 0）
- 模型 checker 的行为等价判定本身是**完备性前提**：TLA+ 状态空间爆炸时可能无法判定，摘要未说明如何处理不可判定情形
- GPT-5 按名称打分的绝对正确率本身很低（**9%**），其"0 下降"部分可能来自地板效应
- 微调实验只用**两个模型家族**（Qwen、Gemma），家族间差异明显（4.9 vs 1.3 pp），泛化性有限

## 实现建议

- **实现难度**: 中（需要 TLA+ model checker 接入 + 重命名脚本 + 两套打分器）
- **适用场景**: 任何要**公开基准**或声称模型"理解"了规格/代码的团队 —— 这是发布前应自查的项
- **建议动作**:
  1. 自查评测器：**把所有标识符替换为随机名**，看分数掉多少。掉得多 ⇒ 你的评测器在按名字打分，而不是按语义
  2. 把打分标准改为**行为等价/测试通过**，而不是名称精确匹配
  3. 报告记忆信号时，**同时报告"行为打分下的下降"**，区分记忆与打分伪影
- **价值点**: 这是 2026-10-24 日报中"评测方法论本身正成为被批判对象"主线的又一实例，且给出了**可操作的修法**
