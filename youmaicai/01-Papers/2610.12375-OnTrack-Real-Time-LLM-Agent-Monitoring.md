## 核心贡献

> 用 streaming structure-aware optimal transport 在 agent 每一步以毫秒级检测轨迹偏离，全程无需重型 safeguard LLM；首步 8 步即优于内容相似度方法，可提前中断 83% 注定失败的运行。

1. 提出 **OnTrack**：streaming structure-aware OT，在 agent 每步比较当前 trajectory 与历史成功 run 的 dependency graph。
2. 三档数据访问分级：**full / intermediate (only tool schemas) / no prior knowledge**，覆盖典型部署场景。
3. 在 SWE-bench 上仅用前 8 步即取得 +0.057 AUROC 的失败预测提升，并可通过 abort policy 节省 18% 浪费的 compute（83% 中断均为正确）。

---

## 技术方案

### 核心思想

把"agent 轨迹"看作有结构的有向图（节点 = tool call，边 = 数据依赖）。在每一步用 OT 比较当前图与 reference runs 的图结构差异；OT 距离的增长率反映"agent 是否在野化"。

### 关键技术

| 技术 | 说明 |
|------|------|
| Streaming OT | 在 O(k) 增量时间内计算每步的 OT 距离，无需重新计算全图 |
| Structure-aware cost | cost matrix 不仅基于 token 相似，还包含 dependency graph 的编辑距离 |
| Three-regime access | 三档数据访问下，监测能力平滑退化：从 plan violation → loop detection → stall/repeat call |
| Abort policy | 当 OT 距离超过阈值即终止 agent，省下后续 token cost |

---

## 公式（核心 streaming OT 更新）

```math
\text{OT}_t = \arg\min_{\pi} \sum_{i,j} \pi_{ij} C_{ij}^{(t)} \quad \text{s.t.} \quad \sum_j \pi_{ij} = a_i^{(t)}, \sum_i \pi_{ij} = b_j^{(t)}
```

```math
\Delta_t = \| \text{OT}_t - \text{OT}_{t-1} \| / \text{OT}_{t-1}
```

其中 $C_{ij}^{(t)}$ 为结构感知 cost，$\Delta_t$ 作为 abort 信号。

def ontrack_step(current_graph, reference_graphs, schemas=None):
    cost = structure_aware_cost(current_graph, reference_graphs, schemas)
    ot_dist = sinkhorn_stabilized(cost, a, b, eps=1e-2)

## 实验结论

- **数据集**: SWE-bench trajectories
- **基线**: content-similarity-based monitoring
- **结果**:
  - 失败轨迹 vs 成功轨迹的 AUROC：+0.057 over baseline（仅用前 8 步）
  - 节省 compute：18%（aborted runs 中 83% 实际会失败 = 5/6 正确）

---

## 局限性

- 严重依赖 reference runs 的质量与覆盖度；新场景需要 bootstrap 过程。
- OT 阈值需要离线调参，跨任务迁移性未充分验证。
- 当前仅在 SWE-bench 评测，未覆盖开放式长程 agent 任务。
