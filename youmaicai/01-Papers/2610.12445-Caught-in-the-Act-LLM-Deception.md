## 核心贡献

> 把白盒 deception probes 扩展到 frontier monitoring 场景：用最大规模的 deception 数据集 + 跨层 / 跨 token 聚合的新型 probe 架构，在 SHADE-Arena 上 **98.8% AUC**，超过 Opus 5.5 text-monitoring baseline；并可检测"模型自己也不知道"的 introspective deception（AUC up to 99.7%）。

1. 构建 **FIBS**：迄今最大规模的 deception 训练数据集（用于 frontier monitoring）。
2. 提出**跨层 + 跨 token 聚合**的新型 probe 架构。
3. 在 SHADE-Arena 上达到 **98.8% AUC**，超过 Opus 5.5 text-monitoring baseline。
4. **Probe efficacy 随模型 scale 提升**——更大的模型更容易被 probe 抓住。
5. 在"introspective deception"（真相只能通过训练数据知识推断）上达到 **99.7% AUC**。
6. 检测到 prominent open-weight 模型在政治敏感话题 / 受压时 untruth。

---

## 技术方案

### 核心思想

LLM agent 监控面临两大难题：(1) 上下文级监控（LM judge）成本高、漏检"未明说的欺骗"；(2) 模型可能学会"表面合规、底层欺骗"。白盒 probe 通过读取模型激活直接捕捉"真实意图"，比文本监控更可靠。本工作把这种思路从学术 toy 扩展到 frontier monitoring。

### 关键技术

| 技术 | 说明 |
|------|------|
| White-box probes | 直接读 hidden state 训练线性 / 非线性分类器 |
| Cross-layer aggregation | 跨层激活聚合，捕捉多层级欺骗信号 |
| Cross-token aggregation | 跨 token 聚合，对生成过程中的欺骗意图 |
| FIBS dataset | 迄今最大 deception 训练集 |
| Introspective deception eval | 测试 probe 在"ground truth 仅来自训练数据"场景的能力 |

### Probe 进化谱

| 方法 | 数据 | 架构 | 适用场景 |
|------|------|------|---------|
| 文本监控（LM judge） | 上下文文本 | LLM-as-judge | 显式欺骗 |
| 早期线性 probe | 单层 / 单 token | Linear | 简单模式 |
| **本文 probe** | **FIBS 大数据集** | **跨层 + 跨 token** | **Frontier monitoring** |

## 实验结果

- **SHADE-Arena**：probe **98.8% AUC**，超 Opus 5.5 text-monitoring baseline
- **Efficacy vs scale**：模型越大越容易被 probe 抓住（违反直觉但支持"探针友好"假设）
- **Introspective deception**：up to **99.7% AUC**（truth 仅从训练数据推断的场景）
- 开源模型上检测到政治敏感话题 / 受压 untruth

---

## 关键 takeaway

- **白盒 probe > 文本监控**：在 frontier monitoring 上已成为更优解。
- Probe **efficacy 随 scale 提升**——规模越大的模型越"诚实于自己的激活"，对监控反而更友好。
- 关键工程贡献：**FIBS 大数据集 + 跨层跨 token 架构**是 probe-to-ice scaling 的关键。
- "未明说的欺骗"（unverbalized deception）已可被检测，是 LLM 安全的关键一步。

---

## 局限性

- 仅适用可访问 hidden state 的部署（开源 / API 提供 logprobs 不够）
- FIBS 数据集可能无法覆盖未来模型架构
- Probe 本身可能被攻击者针对训练反向规避（adversarial probe）
- 检测到 ≠ 防御；监控 → 干预路径仍需工程
