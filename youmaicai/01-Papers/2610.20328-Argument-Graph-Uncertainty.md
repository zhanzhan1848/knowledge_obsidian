## 核心贡献

> 从 CoT 的 **逻辑结构**（而非 token 概率 / 多采样一致性）抽取不确定性信号。

1. **Argument Graph Uncertainty (AGU)**：把单条 CoT 切成命题单元 → NLI 建图 → Dirichlet 后验 over 答案 → 用浓度得校准的不确定性。
2. **双重图**：complementary logical structure 捕获局部 step-to-step coherence + 全局 consistency。
3. **零额外推理调用**：不需要被评估模型再生成，仅用一个小 NLI 模型 + 轻量分割模型即可。

---

## 技术方案

### 核心思想

现有 LLM 不确定性估计分两族：
- **Token-based**：entropy / margin，但只看最后一层 surface 信号，忽视逻辑；
- **Consistency-based**：multi-sample 比较，昂贵且对温度敏感。

AGU 走第三条路：直接建模 CoT 的 **logical graph structure**：
1. 把 CoT 切成 propositional segments（用一个小 instruction-tuned model 或 deterministic rule）；
2. 用 NLI 模型推断 segments 间的 entailment / contradiction edges；
3. 构造两套 complementary argument graphs；
4. 把 edge scores 聚合成 Dirichlet posterior over options；
5. 用 posterior concentration 作校准 uncertainty。

### 关键技术

| 技术 | 说明 |
|------|------|
| CoT 命题切分 | instruction-tuned LM 或 deterministic rule |
| NLI graph builder | 推断 logical edges（entail/contradict） |
| Dirichlet aggregation | posterior concentration → uncertainty |
| 双图 (local + global) | 局部 coherence + 全局 consistency |
| 与现有方法正交 | 可与 token / consistency 方法 ensemble |

## 实验结论

- **数据集**: GPQA, MMLU-Pro, TruthfulQA
- **基线**: token entropy, multi-sample consistency
- **结果**:
  - 在多个 reasoning models 上 **consistently** 超过 token-based / consistency-based；
  - 与现有方法的 uncertainty 信号 **正交**，可在 ensemble 中互补；
  - 不需要 evaluated model 额外调用 → 实用部署友好。

---

## 局限性

- 严重依赖 NLI 模型质量与分割质量，错误级联。
- 对非英语 / 高资源分词系统的泛化性待验证。
- 仅在 MCQ 任务上验证；开放式生成的不确定性表达需要重新设计。
