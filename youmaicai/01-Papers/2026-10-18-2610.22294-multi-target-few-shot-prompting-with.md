## 核心贡献

> 用 **Diffusion Language Models (DLMs)** 做 few-shot prompting 的 **multi-target infilling** —— examples 引导**多个 masked regions** 在共享 canvas 上并行填充。提出 **selective masking + likelihood-ratio reward**，在 few-shot benchmarks 与 software refactoring 上提升 infilling accuracy。

1. **DLM 多目标 infilling**：parallel masked regions 在 shared canvas 上同时 infilled。
2. **Likelihood-ratio reward**：favor example-supported infills（不需 gold answer）。
3. **应用场景**：editing by example（multi-site formatting / API migration），依赖 left+right context。
4. **vs AR LM**：AR 处理 left+right context awkward（需要 forward + backward pass）；DLM 原生双向。

---

## 技术方案

### Motivation：Editing by Example

- **场景**：给一组 examples（如 old API → new API），要 apply 到多 site
- **依赖**：left context + right context → AR LM 难处理
- **DLM 优势**：masked region 原生支持双向 context

### 核心方法

#### 1. Multi-Target Infilling

```
[shared canvas with examples + masked targets]
            ↓
[DLM jointly infills all masked regions]
```

- 多个 masked regions **并行**（共享 computation）
- Examples 在 canvas 中以 non-masked 形式存在，作为 guide

#### 2. Selective Masking

- 选择 mask 哪些 token（避免 mask example 自身）
- 与 full mask 对比 → 减少 wasted computation

#### 3. Likelihood-Ratio Reward

- 在 selective mask 出的 canvas 上 evaluate：
  - $P_\theta(\text{target} | \text{context with examples})$
  - $P_\theta(\text{target} | \text{context without examples})$
- **Ratio** = example-supported 偏好度量
- 无需 gold answer（self-supervised reward）

### Training-Free

- 直接用 pretrained DLM → 无需额外训练
- Reward 用于 inference-time selection

## 实验结果

### Benchmark

- **Few-shot prompting benchmarks**
- **Software refactoring case studies**

### 关键发现

- ✅ Demonstrations improve infilling accuracy
- ✅ Example guidance（likelihood-ratio reward）→ 进一步提升
- ✅ Multi-target 并行 vs sequential → efficiency 优势

### Code Refactoring

- Format 变化 / API migration across multiple sites
- 双向 context 让 DLM 比 AR LM 更自然

---

## 局限与展望

- 仅在 fewer-shot cases 上验证（>5 shots 未充分测）。
- Likelihood-ratio reward 假设 examples 之间**一致** → inconsistent examples 会降 reward signal。
- Selective masking 策略选择影响大 → 最优策略未知。
- DLM backbone 选 LLaDA / SEDD 未在 paper 中明示 → 泛化性待验证。
- 长 canvas（>4K tokens）性能未知。

## 实现建议

- **实现难度**: 低（直接用 pretrained DLM + masking + reward selection）
- **预期性能**: 比 AR LM 在 multi-site editing 上**显著优**
- **适用场景**:
  - **Code refactoring**（multi-site 同 transformation）
  - **Format conversion**（multi-region markdown / table 转换）
  - **Data cleaning**（multi-record 同 normalize rule）
- **不适用**: 单点 generation（overhead 大）；超长 context（DLM 仍是 O(n²)）
- **工程提示**:
  - 选择 DLM 时优先**连续 latent 空间** CDLM（而非离散 token diffusion）→ 更适合 continuous infill scoring
  - Likelihood-ratio reward **可在 batch 内 vectorize** → 大量 candidate 并行评分

## 一句话总结

DLM 用多目标并行 infilling + likelihood-ratio reward，把 few-shot example editing 从 "AR awkward" 变成 "native bidirectional"，在 code refactoring 等 multi-site editing 场景下提供新选择。
