# Can LLMs Uncover Hidden Physical Laws through Free Exploration?

## 摘要
本文提出 LongChang——一个全自动框架，在 MuJoCo 刚体仿真中构建"物理定律被篡改"的模拟世界，测试 LLM 能否在没有研究任务、没有任何线索提示的情况下，自主发现异常、提出研究问题、设计实验并建立被篡改的物理定律。评测的 LLM 扮演探索者，可操控物体、建造工具、测试假设；另有独立的 LLM agent 负责生成与审阅场景、审阅工具设计，并依据被篡改的定律与探索记录评判报告的正确性（C）与实验支撑度（S）。探索记录中的未解问题与被纠正的错误会驱动场景自动演化，使整个发现闭环无需人工介入。在 12 个 LLM 中，GPT-6-Astra 的 discovery rate 为 16.7%，其余 11 个均为 0%；探索记录显示模型常留下未被调查的异常，或只部分识别出被篡改的定律。

## 核心贡献
1. **LongChang 框架**：覆盖"环境构建 → 自主探索 → 发现评估 → 场景演化"的完整自动化物理定律发现闭环，与 PhysGym、NewtonBench、DiscoverPhysics 相比，是唯一同时具备"无指定任务 / 交互式 3D 场景 / 工具设计 / 场景演化"四项能力的框架。
2. **反事实物理基准**：1 个正常对照场景 + 14 个各篡改一条物理定律的场景（红球吸引、质量相关下落、振荡重力、高速制动、自动侧向力、地砖反弹、速度上限、进出减速、加速区、碰撞加速、接触换色、第三次接触跳跃、速度复制、向北力）。
3. **对 12 个前沿 LLM 的大规模实证**：仅 GPT-6-Astra 能做出发现（16.7%），且其 law correctness 仅 19.0%、evidence support 达 97.6%，揭示"识别定律"与"实验支撑的发现"两种能力的分离。
4. **受控干预分析**：task guidance、turn budget（100 vs 500）、apparatus access 三个维度的消融，以及正常对照场景中对"过度解读"的检验（36.1% 报告被拒）。
5. **基于错误纠正的场景演化**：用探索记录中的被纠正错误驱动 generation / refinement / composition 三种操作生成新场景，但 GPT-6-Astra 在三个演化场景上 discovery rate 全部为 0%。

## 方法与架构
LongChang 的循环由四个阶段构成（Fig. 2）：

**环境构建（Sec. 3.1）**：LLM designer 指定场景的物体与几何、物理程序以及被篡改的物理定律，框架编译为 MuJoCo 仿真。设计者记录每条定律的目标物体、触发条件与可观测效应，但这些信息对探索者保密。场景演化支持三种操作：generation（从源机制生成新定律与场景）、refinement（修改已有场景）、composition（把源定律组合到同一环境）。自动测试会校验仿真行为是否符合定律，随后由 LLM reviewer 检查程序与测试结果；编译/测试/审阅失败会触发自动返修，只有通过的场景才进入评测。

**自主探索（Sec. 3.2）**：探索者可 push、throw、grasp、move、release、wait、mark，并可自行决定是否设计装置（apparatus）。装置以完整 MJCF XML 提交，允许的 geom 为 sphere/box/capsule/cylinder/ellipsoid，joint 为 free/ball/hinge/slide，可含弹簧与 tendon（tendon 需有限位且只能指向该装置自身）。装置需通过编译、独立物理审阅与安装检查后才可使用。每个 turn 探索者需先写 NOTE（观察与理由）再给出一条 ACT；探索记录保留 notes、actions、observations 与 feedback。最终报告为固定 JSON 结构，`experiments` 记录每个 turn 的动作/条件/结果，`conclusions` 记录 claim、preconditions、evidence_turns 与 reasoning。

**发现评估（Sec. 3.3）**：LLM judge 依据被篡改的定律与完整探索记录给出 `correct`(C) 与 `supported`(S)。判定要求：定律正确性需识别出目标物体、条件、触发条件与常量；机制描述可以不同，只要在允许的干预下给出相同的可观测预测；证据支撑要求所有 claim 与推理都由记录的实验支撑，且保留原记录中的不确定性。正常对照场景中 `supported` 为 null，且"无虚假异常声明"也算 correct。

**关键公式**（被篡改的定律，Tab. 7）：
```math
\text{Scene 02 红球吸引:}\quad F = 20\,\frac{d}{\max(r,\,0.5)^{3}},\quad d\ \text{指向另一球},\ r=|d|
```
```math
\text{Scene 03 质量相关下落:}\quad g = g_{0}\sqrt{\frac{m_{0}}{m}},\quad m_{0}=1
```
```math
\text{Scene 04 振荡重力:}\quad g(t) = g_{0}\left[1 + 0.3\sin\!\left(\frac{2\pi t}{6}\right)\right]
```
```math
\text{Scene 05 高速制动:}\quad F = -8\,\frac{s-2.5}{s}\,v,\quad \text{仅当 } s=|v|>2.5
```
```math
\text{Scene 08 速度上限:}\quad p = \frac{mv}{1 - |v|^{2}/v_{\max}^{2}},\quad v_{\max}=2.2
```
```math
\text{Scene 15 向北力:}\quad F_{y} = 1.5\,m\ \text{(常开)},\ \text{任一可动物体 launch 后暂停 10 秒}
```
约定：距离单位 brick，g0 = 9.81，时间步长 0.002 s，1 count = 1 仿真秒；轴向 x=东、y=北、z=上；"launch" 指非零 PUSH 或 THROW。

## 实验设置
- **模型（12 个）**：GPT-5.6-Luna、GPT-6-Astra、Claude-Opus-5、Gemini-3.7-Flash、GLM-5.3、GLM-5.3-Flash、Kimi-K3、MiMo-V2.6-Flash、MiMo-V2.6-Pro、DeepSeek-Flash、Qwen3-Max、Grok-4.7。
- **评审模型**：GPT-6.1-Sol 作为报告评审；GPT-6-Astra 负责审阅装置并生成/审阅新场景。
- **场景**：15 个基础场景（1 正常对照 + 14 篡改定律），固定初始状态，每个模型最多 100 turns。
- **指标**：D（discovery rate，同时通过 C 与 S）、C（law correctness）、S（evidence support）、R（正常对照报告被拒数）、L（平均探索轮数）、ES（提前停止比例）、AF（动作失败比例）、CS（至少成功建造一次的探索比例）、CF（建造失败比例）。
- **消融**：task guidance（给定律发现任务 + 场景线索）、turn budget（100 vs 500）、apparatus access（enabled vs disabled）。

**消融（Tab. 4）**：

| 条件 | D (%) | C (%) | S (%) | L | AF (%) |
|---|---|---|---|---|---|
| Free exploration, 100 turns | 16.7 | 19.0 | 97.6 | 39.3 | 2.1 |
| Task-guided, 100 turns | **28.6** | 31.0 | 97.6 | 30.9 | 2.7 |
| 100 turns | 16.7 | 16.7 | 100.0 | 42.2 | 2.7 |
| 500 turns | 14.3 | 14.3 | 100.0 | 41.4 | 3.6 |
| Apparatus enabled | 16.7 | 19.0 | 97.6 | 39.3 | 2.1 |
| Apparatus disabled | 4.8 | 4.8 | 100.0 | 38.7 | 0.9 |

关键观察：
- **task guidance 有效**：D 从 16.7% 提升到 28.6%，S 不变；平均探索长度从 39.3 降到 30.9 turns——更少的交互换更多发现。
- **加大 turn 预算无效**：从 100 提到 500 turns，D 反而从 16.7% 降到 14.3%，因为模型平均只用约 40 turns 就提前结束。
- **装置访问是必要条件**：禁用 construction 后 D 从 16.7% 降到 4.8%，C 从 19.0% 降到 4.8%。
- **正常对照**：跨模型 36.1% 的报告因虚假异常声明或对普通物理的无支撑解释被拒（DeepSeek-Flash 把灰砖上小球滑行更远归因于"摩擦更低"，但每次推动前球已在运动，起点速度不同即可解释差异）。
- **场景演化（Tab. 6）**：Scene 15 D=33.3%、Scene 14 D=66.7%，而三个演化场景（Generation / Refinement / Composition）C 均为 0.0%、S 均为 100.0%、D 均为 0.0%。

## 局限性
作者声明：本文只考察 LLM 在模拟世界中能否主动发起调查并发现被篡改的物理定律；结果是该任务对当前 LLM 仍极具挑战。被篡改的定律提供了清晰的评判依据，而真实世界中许多科学问题尚无定论，要把这套框架推广到开放问题，还需要进一步研究如何在"答案未确立"的情形下评估探索及其结论。伦理方面作者提示：LLM 评审可能认可缺乏支撑的结论从而误导后续研究；真实使用生成的实验或装置在缺少独立验证与专家安全审查时可能造成伤害；重复的 LLM 推理与仿真带来能源消耗。

我的补充批判：所有场景均为 MuJoCo 中的规则化解析定律（表 7 给出闭式表达式），与真实科学发现的"现象模糊、假设竞争、噪声主导"差距很大；evaluator 为 LLM-as-judge（GPT-6.1-Sol），虽然提供了很细致的 rubric，但 judge 误判无法被独立人工校验；12 个模型中仅 1 个成功，样本量在统计上很弱；场景演化只有单场景（Scene 15）的案例研究，且演化场景难度陡增后全部失败，说明"用错误驱动演化"的有效性尚未被验证。

## 评估与建议
- 是否推荐深入阅读：**是**。这是少数把"自主科学发现"落到可复现实验环境、并给出跨 12 个前沿模型严格对比的工作，对理解 LLM 自主探索能力的真实边界很有价值。
- 适用场景：Agent 能力评测基准设计、LLM 物理推理与实验设计能力研究、自动化科学发现（AI for Science）方向的立项调研、MuJoCo/具身仿真环境设计参考。
- 与知识库的关联：可与 PhysGym / NewtonBench / DiscoverPhysics / EurekaBench 系列基准对比阅读；与 LLM-as-judge 可靠性、contextual bandit 式探索、tool use 与 apparatus design 相关工作互补；也可作为"Agentic 自主动机/好奇心"主题的支撑材料。
