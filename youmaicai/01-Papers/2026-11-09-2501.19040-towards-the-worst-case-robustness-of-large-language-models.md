# Towards the Worst-case Robustness of Large Language Models

> **arXiv**: [2501.19040](https://arxiv.org/abs/2501.19040)
> **发表日期**: 2025-01-31
> **分类**: cs.LG
> **会议/期刊**: TMLR (Accepted)

## 📋 摘要

近期研究表明 LLM 面临对抗攻击脆弱性——攻击者构造特定输入即可诱导错误或有害输出。尽管已有大量经验性防御方案被提出，但它们的**最坏情况（worst-case）稳健性**仍缺乏理解，这带来一个现实担忧：面对未来更强的攻击，这些防御究竟表现如何？本文从经验与理论两个视角研究 LLM 的最坏情况稳健性。经验方面，作者使用**更强的白盒攻击**为被测的确定性防御方案给出**更紧的经验上界**，结果显示**大多数被测配置下稳健性接近 0%**。理论方面，作者将针对**有界基函数**与**二值基函数**的**随机平滑认证（randomized-smoothing certification）**分别形式化为**分数背包（fractional knapsack）**与 **0-1 背包**问题，并针对两种 token kernel 推导出**分组求解器（grouped solvers）**。具体例子：在 AdvBench 上，作者为经均匀核平滑的 **GPT-4o 安全检测器**认证出平均 certified $\ell_0$ 半径 **2.02**；在其设定的 suffix-attack 场景下，同一核为 **Llama-3-8B 安全检测器**认证出平均 certified 半径 **6.41**。

## 🎯 核心贡献

1. **更紧的经验上界**：用更强的白盒攻击重新评估现有确定性防御，发现**多数配置下经验稳健性降至约 0%**——对"防御已足够安全"的乐观论调提出直接反证。
2. **理论认证框架**：把随机平滑认证统一抽象为组合优化问题——有界基函数对应**分数背包**，二值基函数对应 **0-1 背包**——使最坏情况边界可计算。
3. **分组求解器**：为两种 token kernel 推导出高效的 grouped solvers，使 LLM 场景下的认证在计算上可行。
4. **具体认证结果**：GPT-4o 安全检测器（均匀核）平均 certified $\ell_0$ 半径 **2.02**；Llama-3-8B（suffix-attack 设定）平均 certified 半径 **6.41**。
5. **攻防视角结合**：既给出经验攻击下的悲观下界，也给出可证明的认证上界，界定了当前防御能力的真实区间。

## 🔧 方法/架构

- **经验部分**：
  - 对被测的**确定性防御**（deterministic defenses）施加更强的**白盒攻击**；
  - 通过更强攻击收紧经验上界，观察到多数配置稳健性几乎归零。
- **理论部分——认证建模**：
  - **随机平滑（randomized smoothing）**：对输入施加随机扰动（如 token 级替换/后缀扰动）后取多数投票，从而把对抗鲁棒性转化为在扰动分布上的**认证半径**问题；
  - **有界基函数**（bounded base function）：认证问题形式化为**分数背包（fractional knapsack）**；
  - **二值基函数**（binary base function）：形式化为 **0-1 背包**。
- **分组求解器（grouped solvers）**：针对**两种 token kernel** 推导高效求解算法，避免逐 token 枚举带来的组合爆炸。
- **度量**：认证半径采用 $\ell_0$ 范数（对 LLM 更自然，衡量被扰动的 token 数），在 AdvBench 上评估安全检测器。

```math
\text{Certify}(f,\ \mathcal{N}(x,\ \sigma)) :
\begin{cases}
\text{fractional knapsack}, & f \text{ bounded}\\[2pt]
\text{0-1 knapsack}, & f \text{ binary}
\end{cases}
\quad\Longrightarrow\quad
\text{certified } \ell_0 \text{ radius}
```

## 📊 实验结果

- **数据集/基准**：**AdvBench**（安全检测器场景）；suffix-attack 场景下评估 Llama-3-8B 安全检测器。
- **被测对象**：GPT-4o 安全检测器（uniform kernel 随机平滑）、Llama-3-8B 安全检测器（同一 kernel，suffix-attack 设定）。
- **经验结果**：在更强白盒攻击下，**大多数被测的确定性防御配置稳健性接近 0%**（摘要未给出逐配置的具体百分比）。
- **认证结果**：
  - GPT-4o + 均匀核：平均 certified $\ell_0$ 半径 = **2.02**；
  - Llama-3-8B + 均匀核（suffix-attack 设定）：平均 certified 半径 = **6.41**。
- **代码/工具**：摘要未直接给出代码链接；论文提及的 grouped solver 为认证计算组件。

## ⚠️ 局限性

- **认证半径本身很小**：GPT-4o 的 certified $\ell_0$ 半径仅 **2.02**，意味着认证保证只覆盖极小的 token 扰动，与真实世界攻击强度差距很大。
- **攻击/威胁模型受限**：suffix-attack 是较窄的攻击面，未必覆盖 jailbreak、指令注入、多轮诱导、工具调用等更实际的攻击路径。
- **核（kernel）与基函数假设**：均匀核 + 特定 token 替换假设下的认证结论，不能直接迁移到其他平滑方式或非离散化扰动。
- 摘要**未给出**逐个防御方法的稳健率、逐数据集细分结果，也未报告认证计算的实际耗时/可扩展性。
- 认证采用**保守界**，通常与真实稳健性有 gap；论文未报告 certified radius 与经验攻击成功率之间的经验相关曲线。

## 💡 建议

- 是否推荐使用：**是**（作为安全防御选型与"能力边界"论证的严谨参考，尤其是给决策者展示"经验防御 ≠ 稳健"的证据）
- 适用场景：需要为 LLM 安全防御做**可证明保证**评估的团队（如合规、审计）；也适用于设计对抗训练/平滑防御时的对照基线。若只关心实际攻击成功率，应配合经验红队评估而非仅依赖认证半径。
