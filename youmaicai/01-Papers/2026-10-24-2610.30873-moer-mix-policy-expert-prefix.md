## 核心贡献

> 提出 MOER —— 一个 mix-policy 优化框架，用**逐步衰减的专家 CoT 前缀**引导模型自行完成剩余推理，并以 selective rollback 保证每条 off-policy 轨迹的正确性，从而协调专家指导与自我探索。

1. **问题定位**：现有 mix-policy 方法要么提供静态全轨迹指导（压制自我探索），要么采用专家前缀引导但**无正确性保证**，导致次优性能甚至训练崩塌
2. **衰减式专家前缀**：把专家 chain-of-thought 前缀注入 prompt，前缀长度随训练逐步退火（annealed），鼓励模型接管剩余推理
3. **Selective rollback 机制**：失败的补全被替换回原始完整专家轨迹，保证每条 off-policy 轨迹的正确性
4. **Harmonized mix-policy 目标**：on-policy token 用 GRPO loss 优化，专家前缀与补全 token 用 trust-region SFT loss 监督，显著稳定训练
5. **广泛有效性**：在数学与通用领域推理任务上取得最高平均分，并在多任务、多模型规模、多基座类别上稳定泛化

## 技术方案

### 核心思想

专家数据混入 RL 循环时，最大风险是"模型学会了抄专家"而非"学会了自己推理"。MOER 的做法是把专家拆成**前缀（可退火掉）与结论（不可退火）**：前缀越训越短，最终模型必须自己接上推理；而当模型确实接不上时，rollback 把这条样本换成完整专家轨迹，从而保证 off-policy 数据永远是对的。

### 关键组件

| 组件 | 说明 |
|------|------|
| Decaying Expert Prefix | 专家 CoT 前缀注入 prompt，长度随训练退火 |
| Self-Completion | 模型补全前缀之后的剩余推理部分 |
| Selective Rollback | 失败的补全 → 替换为完整专家轨迹，保证轨迹正确性 |
| GRPO Loss | 用于 on-policy token 的优化 |
| Trust-Region SFT Loss | 监督专家前缀 + 补全 token，稳定训练 |

### 关键公式

前缀退火策略（前缀长度随训练逐步缩短）：

```math
\ell_t = \max\big(\ell_{\min},\ \ell_0 \cdot \gamma^{\,t}\big), \qquad 0 < \gamma < 1
```

其中 $\ell_t$ 为第 $t$ 步注入的专家前缀 token 数，$\gamma$ 为退火系数。

Harmonized 目标函数：

```math
\mathcal{L} = \mathcal{L}_{\text{GRPO}}^{\text{on-policy}} + \alpha \cdot \mathcal{L}_{\text{SFT}}^{\text{trust-region}}
```

GRPO 项作用在模型自生成的 on-policy token 上，trust-region SFT 项同时作用于专家前缀与补全 token；trust-region 约束用于限制偏离专家分布的幅度，避免训练崩塌。

Selective rollback 的选择规则：

```math
\text{rollback}(x) = \mathbb{1}\!\left[\text{completion failed}\right] \cdot \tau_{\text{full-expert}}
```

## 局限性

- 退火系数 $\gamma$ 与前缀长度 $\ell_0$ 需按任务调参，跨任务的稳定性未在摘要中量化
- 依赖高质量专家轨迹数据 —— expert 数据质量差时 rollback 会把模型拉回劣质解
- 失败判据（completion failed）的判定方式未说明，可能需要额外的 verifier 或答案匹配
- 主要在推理类任务（数学 + 通用 reasoning）验证，对 agentic / 长程工具使用场景的适用性未评估
- 摘要未给出具体分数与对照基线的逐项数值，效率与收益的性价比信息有限

## 实现建议

- **实现难度**: 中（核心是 GRPO 与 SFT 两个 loss 的联合，退火逻辑与 rollback 逻辑都很轻）
- **适用场景**: 有优质专家推理数据、但纯 on-policy RL 冷启动困难或能力上限受限的模型（如数学推理）
- **建议起点**: 先固定一个较短前缀跑通"前缀 + 自补全 + rollback"流程，确认轨迹正确率，再把 $\ell_0$ 拉长、开启退火
- **价值点**: 相比全轨迹 SFT 蒸馏，专家前缀 + 退火 + rollback 的组合既保留专家信号又不压制模型自主推理能力
