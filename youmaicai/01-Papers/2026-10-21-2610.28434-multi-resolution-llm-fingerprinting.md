## 核心贡献

> 系统研究 LLM 指纹的**分辨率极限**：既能在多大粒度上区分模型（不同家族 vs 蒸馏版 vs 适配版），也厘清当表层线索被逐层剥离后**还剩哪些信号可用**。

1. **双维度分辨率框架**：
   - **Model resolution**：跨家族 → 蒸馏变体 → 适配变体（如同一基座的 **LoRA**）
   - **Signal resolution**：行为 / 风格计量 / 词汇 / 语义四类证据
2. **核心发现**：指纹**超出宽泛的家族差异而存在** —— 在**蒸馏模型**中甚至在**同一基座的 LoRA 适配**中仍可检测
3. **线索剥离实验**：渐进抑制表层线索 → 释义改写 → 变化可用文本量 → 测试跨 prompt 分布与跨语言泛化
4. **跨语言**：语义表示**跨语言最鲁棒**

---

## 技术方案

### 双分辨率框架

| 维度 | 层级 |
|------|------|
| **Model resolution** | 不同家族 → 蒸馏变体 → 适配变体（LoRA） |
| **Signal resolution** | 行为 / 风格计量（stylometric）/ 词汇 / 语义 |

### 渐进线索抑制管线

```math
\text{raw output}
\xrightarrow{\text{suppress surface cues}}
\xrightarrow{\text{paraphrase}}
\xrightarrow{\text{vary text volume}}
\xrightarrow{\text{cross-prompt, cross-language test}}
\text{residual fingerprint}
```

### 泛化结论

| 条件 | 指纹强度 |
|------|---------|
| 家族间差异 | 强（预期） |
| 蒸馏模型 | **仍可检测** |
| 同一基座 + LoRA | **仍可检测** |
| 表层/词汇线索被改 | 归因**减弱但仍可观** |
| 跨 prompt 来源 | 迁移 ✓ |
| 跨语言 | 迁移 ✓，**语义表示最鲁棒** |

---

## 实验结论

- 模型身份可在**多个分辨率**上恢复，但可恢复性**依赖模型相似度**与**可用证据**
- 蒸馏与 LoRA 级别的变体**不构成指纹逃逸手段**
- 语义证据跨语言最稳；表层证据最脆弱

---

## 局限性

- 摘要未给出具体准确率/AUROC 数值
- 跨语言泛化的语言列表未知
- 未讨论对**抗性防御**（如刻意混淆生成风格）的鲁棒性 —— 这是指纹攻击的自然对偶
- 伦理影响未讨论（生成内容可用于来源追踪与规避）

## 实现建议

- **实践含义**: **蒸馏和 LoRA 不会自动清除指纹** —— 若需真正匿名化生成内容，仅靠模型变换不够
- **与 Forty Questions 互补**：该文走文本统计/语义路线（适用于长文本、有内容时）；Forty Questions 走单词级 API 行为路线（适用于短查询）
- **建议起点**: 来源追踪场景优先使用**语义表示**特征（跨语言最鲁棒）；防范成本应计入蒸馏/适配方案的评估
