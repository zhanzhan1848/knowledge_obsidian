# Modality-Aware Expert Pruning for MoE-Based Multimodal Large Language Models

> **arXiv**: [2611.05927](https://arxiv.org/abs/2611.05927)
> **发表日期**: 2026-11-04
> **分类**: cs.CV (及交叉分类 cs.CL)
> **会议/期刊**: NeurIPS 2026

## 📋 摘要

Mixture-of-Experts（MoE）让多模态大语言模型（MLLM）能够高效扩展容量，但专家参数依然主导显存占用——尽管每个 token 只激活少数几个专家：在现代 MoE-MLLM 中专家参数占模型体积的 **90% 以上**（例如 InternVL3.5-30B-A3B 与 Qwen3-VL-30B-A3B 在 BF16 下为 54 GB / 约 58 GB）。专家剪枝已成为一种有效的压缩策略，但现有方法在 token 间**统一聚合**重要性，忽视了同一个专家在视觉处理与语言处理中可能扮演不同角色。为此作者提出 MAEP（Modality-Aware Expert Pruning），一个**免训练**框架，在单次前向传播中按模态分解专家重要性。MAEP 引入两项机制：(1) **Delta-H Output（$\Delta H$）**——一种重分布感知（redistribution-aware）指标，衡量移除某专家后 MoE 输出的变化；(2) **低注意力视觉 token（low-attention vision tokens）**作为视觉侧剪枝信号，该信号的专家重要性排序在不同数据集间保持稳定（dataset-stable）。文本侧重要性用作**保留信号**，视觉侧重要性用作**剪枝信号**，专家在所有层上做**全局排序**。在三个 MoE 基座 MLLM 上、跨多模态与纯文本基准的实验显示，MAEP 在多数多模态基准上优于模态无关基线，同时在纯文本任务上保持竞争力，把 BF16 专家权重占用减少约 **27 GB（约占总内存的 47%）**，使一个约 **58 GB** 模型的完整权重可以装进单张 **40 GB** GPU。

## 🎯 核心贡献

1. **提出 MAEP 免训练框架**：单次前向传播即可按模态分解专家重要性，避免对视觉/文本差异化角色的忽视。
2. **提出 $\Delta H$（Delta-H Output）**：重分布感知的专家重要性指标，度量移除某专家后 MoE 输出的变化量，捕捉 router 重分配带来的效应。
3. **发现并利用视觉侧的数据集稳定信号**：低注意力视觉 token 产生的专家重要性排序在不同数据集上保持稳定（dataset-stable），可作为可靠的视觉剪枝依据。
4. **双信号设计**：文本侧重要性 → 保留信号（preservation），视觉侧重要性 → 剪枝信号（pruning），并跨层全局排序（global ranking across layers）。
5. **显著的部署收益**：BF16 专家权重减少约 **27 GB**（约占总内存 **47%**），让约 **58 GB** 的模型塞进单张 **40 GB** GPU。

## 🔧 方法/架构

MAEP 的核心流程：

1. **单次前向传播**：在一次 forward 中同时收集视觉 token 与文本 token 的激活。
2. **模态分解**：按 token 所属模态将专家重要性拆成 vision-side 与 text-side 两套信号。
3. **$\Delta H$ 指标**：移除某专家后，MoE 输出发生的变化（并计入 router 对剩余专家的重分配效应）：

```math
\Delta H_{\text{exp}} \;=\; \big\| H_{\text{MoE}}(E \setminus \{e\}) \;-\; H_{\text{MoE}}(E) \big\|
```

4. **视觉侧信号**：以低注意力视觉 token 作为触发样本源，度量该专家对视觉输出的贡献；由于注意力分布天然对数据集不敏感，得到的专家重要性排序在数据集间稳定。
5. **双信号决策**：文本侧重要性高 → 标记为**保留**；视觉侧重要性低/冗余 → 标记为**可剪**；最终在所有层上做全局排序后剪除。

## 📊 实验结果

- 模型规模基线：InternVL3.5-30B-A3B 与 Qwen3-VL-30B-A3B 在 BF16 下约 **58 GB**，其中专家占 **54 GB（>90%）**。
- 压缩效果：BF16 专家权重占用减少约 **27 GB**，约为总内存的 **47%**。
- 部署结果：约 **58 GB** 模型的完整权重可容纳于**单张 40 GB GPU**。
- 对比结果：在**多数多模态基准**上优于模态无关（modality-agnostic）基线；在**纯文本任务**上保持竞争力。
- 摘要未披露具体基准名称与逐项分数（详见原文实验章节）。

## ⚠️ 局限性

- 摘要未列出被评测的基准名称与具体分数，跨任务均衡性只能定性判断。
- $\Delta H$ 依赖一次前向传播的近似，在路由高度动态或负载分布偏移场景下的稳定性未说明。
- 剪枝是在**校准数据集**上统计的专家重要性，向真实生产流量迁移时的效果未验证。
- 「纯文本任务保持竞争力」意味着视觉侧剪枝仍可能影响跨模态混合场景，摘要未给出该折中的定量权衡。
- 免训练方法无需重训，但也意味着无法恢复剪枝损失的性能，是否可用少量数据补训未探讨。

## 💡 建议

- 是否推荐使用：是
- 适用场景：单卡部署大型 MoE 多模态模型（如 InternVL3.5/Qwen3-VL-30B-A3B）、显存受限的推理服务、需要保持多模态能力同时压缩权重的场景。
