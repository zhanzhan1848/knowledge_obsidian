## 核心贡献

> **校准不准的置信度仍然可以用来做统计有效的分层审计**：置信度无需是正确概率，只需能分层。MMLU-Pro 上 200 个标签下，按比例分配的 RMSE 为 **2.46pp**，而等额分配为 **4.56pp**；但 LLM-as-judge 只有 **56 对中的 6 对**满足理想化的标签效率条件（B_direct/B_v > 1），MMMU-Pro 上**一对都没有**，且最优情形的人力标签盈亏平衡价高达 **$0.09–$21.55/题**。

1. **统一的统计框架，涵盖两条审计路径** — 直接人工审计（置信度分层抽样）与 judge 辅助审计（LLM 交叉验证）被放进同一套「人力标签效率 + 总成本效率边界」的框架里比较，而不是各说各话
2. **置信度分层估计量（无偏，不要求校准）** — θ̂_str = Σ_j π_j θ̂_j，E(θ̂_str) = θ_N。关键洞见：置信度**只用来划分层**，不需要是正确性的校准概率；只要各层的正确率不同，它就有用
3. **有限样本不确定性的完整刻画** — Var(θ̂_str) = Σ_j π_j²(1−n_j/N_j)·S_j²/n_j；以及分布无关的 Hoeffding 保证 Pr(|θ̂_str−θ_N| ≥ ε) ≤ 2exp[−2ε²(Σ_j π_j²/n_j)]，失败概率 ≤δ 只需 Σ_j π_j²/n_j ≤ 2ε²/log(2/δ)
4. **三种固定分配 + 两阶段自适应 Neyman** — uniform（n_j ≈ B/K）、population-proportional（n_j ≈ Bπ_j，最小化 Hoeffding 分母）、oracle Neyman（n_j = B·π_j S_j/Σπ_k S_k，最小化方差但需未知方差）；另给出两阶段方案：pilot 每层 m_j=10，θ̃₁ = (X₁ⱼ+½)/(m_j+1) 做拉普拉斯稳定，末期按 (N_j−m_j)·S̃_j 分配，最终估计 θ̂²ˢᵗ_j = (X₁ⱼ + (N_j−m_j)θ̂₂⁽ʲ⁾)/N_j
5. **judge 的敏感性–假阳率模型与误差修正估计量** — q = s·θ + α_v(1−θ) ⇒ **θ = (q−α_v)/(s−α_v)**，定义**判别间隙 Δ_v = s−α_v**；修正估计量 θ̂_v = (q̂−α̂_v)/(ŝ−α̂_v)，delta-method 方差 ∝ (1/Δ_v²)[q(1−q)/M + θ²s(1−s)/n₁ + (1−θ)²α_v(1−α_v)/n₀] —— **Δ_v 小会同时放大三项**
6. **识别界（identification bounds）** — 只给出部分已核标签时，θ_N 的相容区间为 [Σπ_jp_jμ_j, Σπ_j{p_jμ_j + 1−p_j}]；这是识别界而非抽样置信区间
7. **经验验证：校准不准但分层审计有效** — MMLU-Pro 上 GPT-5.5 的真实准确率 **80.54%**，各预算与分配策略下偏差接近零、误差随标签数下降；观测到的失败概率**始终低于**对应的 Hoeffding 界（界保守但提供有效的最坏情况保证）
8. **分配的真正作用在精度而非偏差** — 200 标签时 RMSE：uniform **4.56pp** → proportional **2.46pp** → oracle Neyman **2.41pp**；原因是置信度分布长尾，等额分配过采样稀疏层而欠采样主层
9. **judge 的高判断准确率 ≠ 高统计价值** — MMLU-Pro 8×8=64 有向对中仅 **6 对**满足 B_direct/B_v > 1（MMMU-Pro **0 对**）；Claude Sonnet 5 验证 GPT-5.5 时判断准确率 **0.84** 但标签效率仅 **0.25**，而 GPT-5.5 验证 Llama-3.1-8B 时准确率 **0.89** 却拿到最高效率比 **1.45**；GPT-5.5 验证 Claude Haiku 4.5 的 FPR 高达 **0.75**，判别间隙只有 **0.19**
10. **成本边界才是最终裁决** — 六个有有限盈亏平衡点的 cell 对应那 6 个效率 >1 的 MMLU-Pro 对：最优 **c*_H ≈ $0.09/题**，其余约 **$0.34、$0.75、$0.80、$4.33、$21.55**；略微越过效率边界的配对可能需要极高的人力标签成本才能抵消推理成本

## 技术方案

### 核心思想

LLM/MLLM 的**自报置信度**通常校准不准 —— 但这不等于它没用。论文的核心区分是：**把置信度当作「正确概率」用**是错的；**把置信度当作「分层依据」用**是对的。

前者要求校准；后者只要求置信度能把输出分成**正确率不同的层**。一旦满足这个条件，分层抽样 + 层内均值加权就是一个**无偏**的总体准确率估计量（θ̂_str = Σπ_j θ̂_j），而且不依赖任何校准假设。配合 Hoeffding 不等式，还能给出分布无关的最坏情况保证。这是一个非常实用的松绑：**不需要修好校准，也能拿到统计有效的准确率**。

第二个洞见关于 **judge**。论文把 judge 建模成两个参数：**敏感性 s**（正确回答被接受的概率）与**假阳率 α_v**（错误回答被错误接受的概率），并用 **判别间隙 Δ_v = s − α_v** 作为唯一的操作特征。理由是：q = sθ + α_v(1−θ) 反解出 θ = (q−α_v)/(s−α_v)，而修正估计量的方差 ∝ 1/Δ_v²。

这解释了为什么「judge 判断准确率 0.89」这种数字几乎没有信息量：**一个把所有答案都判为正确的 judge，在 target 普遍答对时也能有很高的准确率，却完全没有判别力**。论文用两个具体数字把这一点讲透了：Claude Sonnet 5 验证 GPT-5.5 时准确率 **0.84** 但效率比只有 **0.25**（因为假阳率高，Δ_v 小）；GPT-5.5 验证 Llama-3.1-8B 时准确率 **0.89**、效率比 **1.45**（全场最高）。

第三个洞见是**成本维度必须进框架**。即便某个 judge 的统计效率 >1（即理论上需要更少的人工标签），如果它的推理太贵，「省下的人力标签」可能抵不上推理开销。论文因此计算**盈亏平衡人力标签成本 c*_H**：当人工标签单价低于 c*_H 时，judge 辅助审计才真正划算。结果是极端的 —— 从 **$0.09** 到 **$21.55** 相差两个数量级，说明「略微越过效率边界」是很危险的区间。

### 关键技术

| 技术/方法 | 说明 |
|------|------|
| 置信度分层估计量 | θ̂_str = Σ_j π_j θ̂_j，无偏；不要求置信度已校准 |
| 识别界 | 只看已揭示标签时 θ_N ∈ [Σπ_jp_jμ_j, Σπ_j{p_jμ_j+1−p_j}] |
| Hoeffding 集中 | Pr(\|θ̂_str−θ_N\|≥ε) ≤ 2exp[−2ε²(Σπ_j²/n_j)]，对无放回抽样同样成立 |
| 三种固定分配 | uniform (B/K)、proportional (Bπ_j)、oracle Neyman (B·π_jS_j/Σπ_kS_k) |
| 两阶段自适应 Neyman | pilot m_j=10 + 拉普拉斯稳定 + 末期按 (N_j−m_j)S̃_j 分配；条件于 pilot 仍无偏 |
| 置信度分层 | 初始层 [0,0.2],(0.2,0.4],(0.4,0.6],(0.6,0.8],(0.8,1]；相邻层合并直到每层 ≥25 个输出 |
| Judge 判别模型 | q = sθ + α_v(1−θ)；θ = (q−α_v)/(s−α_v)；Δ_v = s−α_v |
| 误差修正估计量 | θ̂_v = (q̂−α̂_v)/(ŝ−α̂_v)，三源方差分解 |
| 标签效率比 | B_direct/B_v > 1 才算「值得用 judge」；B_direct = θ(1−θ)/τ² |
| 盈亏平衡人力成本 | c*_H：人工标签单价低于此值时 judge 辅助审计才划算 |
| 校准度量 | ECE（按 bin 人口频率加权的 \|confidence−accuracy\|）、Brier score、可靠性曲线（10 个等宽 bin） |
| 审计模拟 | 用完整 ground truth 模拟部分人工核验；每个 budget–allocation 条件 **5,000 次**独立重复 |

## 实验结果

### 1. 自报置信度：有信息但校准不准

| 基准 | 观察 |
|------|------|
| MMLU-Pro | 高置信度输出通常更准，但存在显著且**依赖模型**的失准；**Claude Sonnet 5 校准最好**，若干模型强烈过度自信 |
| MMMU-Pro | **八个模型全部平均过度自信**；即使 Claude Sonnet 5 仍保留 **10.1 个百分点**的置信度–准确率间隙，**ECE = 0.108** |
| MMMU-Pro 跨模型 | 准确率跨度 **27.2% – 63.5%**，最大 gap 达 **59.6 个百分点** |

> 结论：置信度**跨两个基准都携带信息**，但作为正确概率不可靠 —— 这正是「只用来分层」的理由。

### 2. 分层审计可靠恢复总体准确率（GPT-5.5 @ MMLU-Pro，真值 80.54%）

| 审计预算 B | 统一分配 RMSE | 按比例分配 RMSE | Oracle Neyman RMSE |
|------|------|------|------|
| **200** | **4.56 pp** | **2.46 pp** | **2.41 pp** |

- 各预算与分配策略下**偏差接近零**（图 3a，含 95% Monte Carlo 区间）
- **观测到的失败概率始终低于对应的 Hoeffding 界**（图 3b/3d，含 95% Wilson 区间）—— 界保守但提供有效的最坏情况保证
- 误差容忍度敏感性：ε = 2.5 / 5 / 7.5 pp 三档均满足界
- MMMU-Pro 呈现相同模式，但**小预算下变异性更大**

### 3. Judge 的三个维度是分离的

| 对比 | 判断准确率 | 标签效率 B_direct/B_v | 解读 |
|------|------|------|------|
| Claude Sonnet 5 → GPT-5.5 | **0.84** | **0.25** | 高准确率、**低**统计价值（假阳率高，Δ_v 小） |
| GPT-5.5 → Llama-3.1-8B | **0.89** | **1.45**（全场最高） | 最高效率比 |
| GPT-5.5 → Claude Haiku 4.5 | 0.86 | **0.06** | FPR 高达 **0.75**，判别间隙仅 **0.19** |

> MMLU-Pro：**56 对中仅 6 对**满足 B_direct/B_v > 1。MMMU-Pro：**一对都没有**；例如 GPT-5.5 在 MMMU-Pro 上判断准确率 **0.700**、敏感性 **0.844**，但假阳率 **0.402**，把判别间隙压到 **0.442**。

### 4. 盈亏平衡人力标签成本（MMLU-Pro，六个有有限解的 cell）

| 配对（verifier → target） | c*_H（USD/题） |
|------|------|
| GPT-5.5 → Llama-3.1-8B | **$0.09**（最有利） |
| 其余五对 | 约 **$0.34、$0.75、$0.80、$4.33、$21.55** |

> 其余 cell **没有有限盈亏平衡点**（灰格）。结论：**略微越过效率边界的配对可能需要极高的人力标签成本才能抵消推理成本** —— 更便宜的 LLM 推理能通过增加判断次数提升精度，但**无法移除校准地板**。

### 5. 方法学要点

- **判别间隙 Δ_v 决定人力校准负担；推理成本决定自动化审计不确定性被削便宜的速率**。两者是**不同**的杠杆。
- **分配只影响精度，不影响偏差** —— 在「置信度分层能否支撑统计有效审计」这个问题上，答案是能；剩下的问题纯粹是效率问题。

## 局限性

- **仅限有确定参考答案的多选题基准**（MMLU-Pro / MMMU-Pro），**开放式评测未被建模** —— 而开放式恰是 LLM-as-judge 最常见的用武之地，论文的核心结论**不能直接外推**
- **人工审计被完全模拟** —— 用完整 ground truth 模拟部分人工核验，**人工标注噪声未建模**；真实审计的标注者一致性、疲劳与漂移都不在模型内
- **假设代表性抽样与稳定的 verifier 行为** —— 后者尤其脆弱：真实 verifier 会被分布漂移与 adversarial 输入影响
- **verifier 的连续置信度未被利用** —— 主分析只用二元判断；verifier 本可返回一个「选中的 target 回答正确的概率估计」，该信息被丢弃
- **无 held-out 校准池、无序列化的类富集策略** —— s 与 α_v 用完整样本估计，作者明确声明这是**描述性比较**
- **成本分析基于观测 token 量与当前 API 价格代理** —— 实际人力与推理成本会变；作者自己强调效率与盈亏平衡边界应被当作**分析性指引而非通用部署保证**
- **效率计算使用全部可用配对群体**，而非精选的高置信子集 —— 这使结论偏保守，但也意味着论文没有回答「精选后能否救回更多配对」
- **多模态侧几乎全为负结果**（MMMU-Pro 0 对过线、Δ_v 最大也只有 0.442），但作者并未解释为什么多模态 verifier 的假阳率系统性更高
- **两阶段自适应 Neyman 只做了经验对比，未纳入固定分配的集中性验证**

## 建议

- **是否推荐使用**: **是**（作为评测方法学与成本决策框架）；作为「用 LLM judge 替代人工标注」的**可行性论证**，则是**否** —— 论文的证据方向恰恰是警告
- **适用场景**:
  - 任何「**要估一个模型的真实准确率，但人工标注预算有限**」的场景 —— 直接采用置信度分层 + 按比例分配 + Hoeffding 界
  - 决定「**要不要用便宜模型/自建 verifier 做交叉验证**」的工程决策 —— 本文提供的判别间隙 + 盈亏平衡成本表可直接复用
  - 审计策略设计：**等额分配在小预算下明显更差**（200 标签时 4.56pp vs 2.46pp），应改为按比例或两阶段自适应
- **可借鉴要点**:
  1. **「置信度只用来分层，不用来当概率」** —— 这是本文最可移植的一句话。校准不准的模型置信度仍能支撑无偏的总体准确率估计，配 Hoeffding 界给出分布无关的最坏情况保证
  2. **评价 judge 必须看 Δ_v = s − α_v，而不是判断准确率** —— 准确率 0.84 的 judge 效率比可以只有 0.25，准确率 0.89 的可以到 1.45；任何「judge 准确率 X%」的汇报方式都是误导
  3. **效率边界之上还有一道成本边界** —— 从 $0.09 到 $21.55 的盈亏平衡点说明「略微划算」通常不划算；做自动化评测选型时，**必须同时算推理成本**，且更便宜的推理只能提升精度、**移不掉校准地板**
