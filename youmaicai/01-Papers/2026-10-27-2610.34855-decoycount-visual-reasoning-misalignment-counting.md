## 核心贡献

> 提出 **DecoyCount**（1,660 张真实图像、2,203 个预注册诱饵、七个机制家族），并定义 **reasoning-alignment gap ΔR = cued 准确率 − neutral 准确率**：六个前沿模型 neutral 准确率仅 17.2%–43.2%（均低于 50%），ΔR 高达 **11.8–22.1 个百分点**，且**模型更强、思考预算更大、agentic 流程更多反而让 gap 更宽**——更强的通用推理能力并不能自动迁移为对齐的视觉推理。

1. **可解释的配对 benchmark** — 每个 item 含一张真实图、一个中性问题、真实计数、1–5 个**预注册诱饵**（由场景诱发的错误计数），以及一条**不泄露答案的匹配对齐提示**（如"忽略图中印刷的数字""不要数镜像物体"）；共 **1,660 个 item、2,203 个诱饵**，覆盖 **842 个多图 item**，另有场景化的 multi-hop 版本。
2. **量化 reasoning-alignment gap** — 六个前沿模型的 neutral 准确率为 **17.2%–43.2%**，六者中**五个返回诱饵的频率高于真值**；匹配提示带来 **+11.8 ~ +22.1 pp** 的 ΔR，修复的答案数是破坏数的 **2.6–6.7 倍**，并消除了 **43.3%–66.7%** 的精确诱饵命中（paired McNemar，p < 10⁻²⁰，每个模型均显著）。
3. **更强 ≠ 更对齐（关键反直觉结论）** — Qwen3.5 **4B→27B** 使 neutral 准确率上升 **5.30 pp**，却让 ΔR **扩大 4.52 pp**；Qwen3.8 开启原生 thinking 后准确率从 **12.65% → 27.17%**，ΔR 从 **+8.96 → +20.80 pp**（在最高思考预算下峰值 +21.71 pp）。
4. **额外上下文并不能闭合 gap** — 加入场景化 multi-hop 条件（不点名计数规则）后**总体准确率几乎不动**，每家族仅挽回 **11.6%–32.6%** 的 neutral 失败；在三个"定义单位"家族（Duplicate/Wrong Unit/Lookalike）平均挽回 **24.0%**（其余家族 13.7%），而 multi-hop 额外算术却**丢掉 34.6%–52.6%** 的 neutral 正确项。
5. **控制实验排除替代解释** — 通用提示与错配提示最多只复现匹配提示增益的 **18%**，即 **≥82%** 的增益依赖于点破实际存在的那个陷阱（p < 10⁻¹²）；改图只改变难度不改变 gap，模型排名保持不变；温度不解释 gap（T 从 0.6 到 1.5，neutral 准确率变动 ≤ 0.88 pp）。
6. **工具的"对齐性"区分** — 通用 Code Interpreter / agentic harness 提升准确率但**扩大** gap **2.48–7.17 pp**（GPT-6 + CI：neutral 27.31%→35.72%，cued 46.65%→57.65%，ΔR +2.59 pp）；而**定向视觉工具 SAM3** 反而**收窄** gap **4.52 pp**，七个家族全部收窄（Estimate −10.8 pp、Structure −8.6 pp、Text −5.4 pp）。区分点是"工具是否提供了该家族瓶颈所需的证据"，而非"有没有工具"。

## 技术方案

### 核心思想

视觉计数看似基础，但要答对必须依次完成：定位目标 → 判定什么算"一个实例"与所请求的单位 → 区分实体与倒影/图像/印刷数字 → 枚举。**每一步都可能以不同原因失败，而单一最终数字把它们塌缩成一个分数**——因此标准计数准确率无法区分"没看见"与"看见了但选错了理解/推理捷径"。

DecoyCount 的做法是：**把错误本身变成可标注的、可归因的对象**。每个场景预先注册若干诱饵计数（例如 6 个瓶子被印着"24"的包装包围 → "24" 是诱饵；镜像场景 → 倒影暗示翻倍计数），诱饵命中就成为"模型走了某条特定捷径"的证据，而非任意错误。

在此基础上设计**三条件配对**：

```
同一张图 + 同一个计数目标
   ├── Neutral  中性问题          ──► 真值
   ├── Cu-ed     匹配对齐提示      ──► 只点破机制，不泄答案、不加视觉证据
   └── Multi-hop 场景化多跳问题    ──► 用情境暗示规则，配第二张图（842 items）
```

三条件答案依赖**同一个底层计数**，因此三者之差可干净地分离"定向引导"与"情境锚定"两种效应。核心指标：

```
ΔR = accuracy(cued) − accuracy(neutral)     (同一图、同一目标答案)
```

作者承认称其为"对齐缺口"看似反直觉（计数似乎有唯一视觉答案），但给出两点动机：**最小幅度的提示就能移动 11.8–22.1 pp 准确率**；仅把"are there"改成"are visible"就让 Gemini-3.8-flash 准确率变化 **6.69 pp**。即"意图中的计数过程"部分依赖于人类解释。

### 关键技术

| 技术/方法 | 说明 |
|------|------|
| Pre-registered decoys | 标注者预先登记目标概念、真值、整数诱饵及其可见机制；诱饵须被图像支持且与真值不同 |
| 7-mechanism taxonomy | Lookalike / Estimate / Prior / Structure / Duplicate / Text / Wrong Unit，覆盖计数流程的不同失败阶段 |
| 7-domain scene axis | everyday / public-outdoor / document-artwork / chart-scientific / retail / observation / industrial；每域占发布量 <21%，且每个家族出现在全部七域 |
| Matched alignment cue | 最小化陈述相关计数规则（数实体 / 忽略印刷数字 / 用所请求单位 / 验证重复结构 / 枚举而非估计），从不泄答案 |
| Paired multi-hop bridge | 每个 neutral 问题配一个场景化多跳版本；声称是首个把同一底层计数与场景化多跳多图问题配对的计数 benchmark |
| Three-model gating | 难度门：三模型全错 neutral；诱饵质量门：至少一个精确返回登记诱饵。用 Claude Opus 5 / GPT-5.6 Sol / Gemini 3.6 Flash |
| Blind human review | 独立复核目标可数性、视觉接地性、无歧义性；分歧仲裁；移除歧义/严重遮挡/需专业知识的 item |
| McNemar exact test | 配对显著性检验，95% CI，噪声地板 **1.98 pp** |
| Generic/mismatched cue control | 区分"点破真实陷阱"与"泛泛要求更用心" |
| Editing validity check | 改图使准确率下降 13.4–25.4 pp（难度上升），但 gap 与模型排名保持 |
| Δ²R metric | Δ²R = ΔR_tool − ΔR_base；负值 = 收窄 gap（对齐改善），正值 = 扩大 |

### 实验设置

| 维度 | 规模 |
|------|------|
| 数据规模 | 1,660 个发布 item（从 2,100 候选中保留，修正 121 个计数、替换 79 张图）；2,203 个诱饵；842 个多图 item |
| 诱饵家族 | 七个，每家族子集 n = 222–291；392 个 item 有多重诱饵 |
| 评测模型 | 六个前沿模型（GPT-6-astra、Qwen3.8-max、Gemini-3.8-flash 等），每条件 3 次重复取平均 |
| 规模扫描 | Qwen3.5 4B / 9B / 27B（图像处理与解码固定） |
| 思考预算扫描 | off → 30,000 tokens → 原生无界 thinking |
| 工具条件 | provider-native CI、固定 agent 的 CI、CI+SAM3、通用 agentic harness |
| 协议 | 模型收到 benchmark 文本原样，无 system prompt / few-shot / 输出格式指令；托管模型用 provider 默认值 |
| 统计 | 95% CI、paired exact McNemar、噪声地板 1.98 pp |

## 实验结果

| 指标 | 数值 |
|------|------|
| Neutral 准确率（六模型区间） | **17.2% – 43.2%**（最高 GPT-6-astra **43.17%**） |
| ΔR（对齐缺口） | **+11.8 ~ +22.1 pp**（GPT-6-astra +22.09 pp，Qwen3.8-max +21.59 pp） |
| 六个模型中返回诱饵多于真值者 | **5 / 6** |
| 提示修复 : 破坏比 | **2.6× – 6.7×**（修复 305–437 项，破坏 63–134 项，p < 10⁻²⁰） |
| 诱饵命中消除率 | **43.3% – 66.7%** |
| 家族级 ΔR | 五个大缺口家族 **+11.42 ~ +30.93 pp**；Structure 仅 +5.92 pp；Estimate 仅 +1.70 pp |
| 诱饵占错误比例 | 五个大缺口家族 **60.5% – 82.8%**；Estimate 仅 21.4%（多为普通数错）；Structure 中间 48.6% |
| 规模效应（Qwen3.5 4B→27B） | neutral 14.08% → 19.38%；cued 22.91% → 32.73%；**ΔR 扩大 4.52 pp**；neutral 诱饵命中 43.76%→50.74%，但诱饵占剩余错误比 50.92%→62.94%（+12.02 pp，CI [10.30, 13.74]） |

## 局限性

- **ΔR 只隔离 misalignment 的一个分量**，剩余错误可能仍来自感知或其他推理限制；尤其 Estimate 家族（小 ΔR、诱饵占比仅 21.4%）更像感知/枚举瓶颈而非过程选择失败——但作者也承认"小提示增益本身不足以区分感知与其他推理限制"。
- **"对齐"的定义依赖人类解释**：ΔR 相对于"物体最常见真实场景所隐含的解释"定义（如"多少个苹果"对倒影中的苹果有歧义，而"做派"场景确立只有实体可用），因此基准不可避免地带有人类视觉预期的先验。
- **跨系统比较是描述性的**：六个前沿模型在架构、数据、训练上同时变化，家族级 gap 内部排序在不同模型间不一致，聚合准确率会掩盖大而模型特异的失败模式。
- **Δ²R 的解释有混淆**：provider-native CI 同时改变推理长度与结构，正的聚合 Δ²R 并不证明工具损害对齐；作者用固定 agent 的 CI→CI+SAM3 对照来部分缓解，但仍是有限推论。
- **82% 的界限只描述聚合层**，不适用于每个家族（Text 即使给通用/错配提示也能涨约 11 pp，说明"任何要求计数的指令都可能挤掉读印刷数字"）。
- **多图 item 只占 842/1,660**，场景化条件与 neutral/cued 的答案不可直接比较（因多跳性质最终答案不同），附录中明确标注该列不与 neutral/cued 准确率直接可比。

## 与知识库既有工作的关系

- 与 [[2026-10-25-2610.31407-cross-script-entity-matching-failures]] 同属**机制可解释性**方向：两者都不满足于报一个聚合准确率，而是设计"可归因到具体失败机制"的探针（前者定位跨脚本实体匹配失败模式，本篇定位视觉计数的特定捷径家族）。
- 延续本库"证伪默认假设"主线的一个强例：**推翻"更强模型会推理得更对齐"这一默认假设**，并用 scale / thinking budget / agentic harness 三组受控扫描分别证伪（accuracy↑ 而 gap↑）。这一"能力提升不等于过程对齐"的结构，也与 V3AST-Bench 的"任务能力不保证安全执行"结论同构。
- 与 [[2026-10-27-2610.35188-v3ast-bench-verifiable-agent-safety]] 共同指向 agent/多模态评测的**"可执行/可归因验证优于单一分数"**方法论。

## 建议

- **是否推荐使用**: 有条件推荐
- **适用场景**: VLM 计数/枚举类能力的细粒度诊断；多模态 agent 的"过程选择"能力评估；设计 alignment cue 类 prompt 干预的对照实验
- **可借鉴要点**:
  1. 方法论可移植：把"错误"预注册为**具名的机制化诱饵**，再配一条只点破机制、不泄答案的提示，用 ΔR = cued − neutral 把"能否执行"与"能否主动选中正确过程"分离——这套配对设计可直接迁移到表格问答、图表读数、代码缺陷定位等场景。
  2. 工具选型判据：区分"通用 agentic harness"（扩大 gap，因为它增加计算但不指明意图中的过程）与"定向证据工具"（如 SAM3，收窄 gap 4.52 pp）；给多模态 agent 加工具时，优先提供能直接消解该失败家族瓶颈的证据源，而非笼统增加推理轮数。
