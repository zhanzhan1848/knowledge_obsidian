# Revisiting Over-refusal in Safety-aligned Large Language Models: A Representation and Optimization Perspective

## 摘要
Over-refusal（过度拒答）是安全对齐的关键副作用：本身无害但表面看起来有风险的查询被误拒。已有缓解方法虽有效，但"为什么在**正确**的安全监督下模型仍会拒绝无害查询"依然缺乏理解。作者从**表征**与**优化**两个视角分析，得到两个核心观察：(1) harmful 与 over-refusal 样本的表征在某些中间层可清晰区分，但在更深层逐渐重叠——例如 Llama-2-7B-Chat 在第 13 层二者可分，越往深层重叠越明显，暗示"表观分离度下降"；(2) harmful 样本的梯度具有高类内相似度并集中在**低秩子空间**中，且在 over-refusal prompt 上，harmful 梯度与 **refusal-target 梯度**的耦合强于与**正确的 helpful-target 梯度**的耦合。这种不平衡的梯度耦合会把 over-refusal 样本推向拒答一侧，而深层表征分离度的下降又使模型更难维持清晰边界。为此作者提出 **GOAL（Gradient Orthogonalization with contrAstive Learning）**：(a) 用 SVD 从 harmful 梯度中抽取低秩拒答子空间，把 over-refusal 梯度对其正交化，以消除不平衡梯度耦合的偏置；(b) 引入 contrastive learning 目标，显式增强 harmful 与 over-refusal 表征的分离。实验表明 GOAL 在缓解 over-refusal 的同时保留了安全性能与通用能力，相对次优方法在 over-refusal 缓解上取得最高 **14.03%** 的相对增益、安全性能上 **1.20%** 的相对增益。代码已发布（anonymous.4open.science/r/GOAL-C5B1）。

## 核心贡献
1. **机理解释**：提出"拒答子空间吸引"（refusal subspace attraction）——harmful 梯度的低秩集中性 + 与 refusal-target 梯度的不平衡耦合，共同把 over-refusal 样本推向拒答侧；并给出 Proposition 1 的一阶证明。
2. **方法 GOAL**：两个互补组件——Refusal-orthogonal Projection（优化层面解耦）与 Safety-aware Contrastive Learning（表征层面分离），且仅微调探针选出的 safety-relevant 层以节省算力。
3. **层选择的实证**：middle-layer block（探针选出）在所有 over-refusal 基准上稳定优于 early / late 变体，同时只更新约三分之一参数即达到接近 full-layer 的效果。
4. **完备的评测矩阵**：3 个骨干（Gemma-7B-it、Llama-2-7B-Chat、Llama-2-13B-Chat）× 5 个 over-refusal 基准 + 2 个安全基准 + 4 个通用能力基准，对比 SFT、SCANS、Surgical、DCR、ACTOR 五类基线。
5. **鲁棒性分析**：拒答子空间对有害样本量 N ∈ {50,100,200,400} 稳定；对投影秩 k ∈ {5,10,15,20} 与对比权重 λ ∈ {0.01,0.05,0.1,0.2} 的双参数扫描稳定。

## 方法与架构
### 1. 样本三分与目标
三类样本：**harmful**（真正不安全、必须拒答）、**benign**（明确无害）、**over-refusal**（无害但容易被误拒）。

### 2. 低秩拒答子空间的抽取
安全对齐的 SFT 损失：

```math
\mathcal{L}_{\text{SFT}}(\theta)=-\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(y_i\mid x_i)
```

逐样本梯度与梯度矩阵：

```math
g_i^{\text{harmful}}=\nabla_\theta \mathcal{L}^{\text{harmful}}_{\text{SFT},i}(\theta,x_i,y_i)\in\mathbb{R}^d,\qquad
G=[g_1^{\text{harmful}},\ldots,g_N^{\text{harmful}}]^\top\in\mathbb{R}^{N\times d}
```

对 $G$ 做 SVD：$G=U\Sigma V^\top$，取前 $k$ 个右奇异向量 $V_k=V[:,:k]\in\mathbb{R}^{d\times k}$ 作为拒答子空间正交基，投影矩阵 $P=V_kV_k^\top$。集中度用 **CER**：

```math
CER(k)=\frac{\sum_{j=1}^{k}\sigma_j^2}{\sum_{j=1}^{r}\sigma_j^2}
```

### 3. Proposition 1（拒答子空间吸引）
定义 refusal preference margin $m_i(\theta)=\log p_\theta(y'_i|x_i)-\log p_\theta(y_i|x_i)$（$y_i$ 为正确 helpful 响应，$y'_i$ 为拒答响应）。令

```math
A_{i,t}=\left\langle g^{over}_{i,t}-g'^{over}_{i,t},\ P\bar g_t\right\rangle,\qquad
R_{i,t}=\left\langle (I-P)(g^{over}_{i,t}-g'^{over}_{i,t}),\ (I-P)\bar g_t\right\rangle
```

则当 $A_{i,t}>|R_{i,t}|$ 时，对足够小的学习率 $\eta$：

```math
m_i(\theta_t-\eta\bar g_t)-m_i(\theta_t)=\eta A_{i,t}+R_{i,t}+O(\eta^2)>0
```

即 harmful 梯度更新会**增大** over-refusal 样本的拒答偏好 margin，把它逐步拉向拒答行为。因为 $\bar g_t$ 主要落在拒答子空间内，残余项 $R_{i,t}$ 很小，该条件很可能成立。

### 4. Refusal-orthogonal Projection
两个备选方案被否决：(a) 降低 harmful 梯度权重——但 harmful 梯度提供必要的安全监督，直接削弱可能损害对真正有害请求的拒答能力（附录 R）；(b) 显式降低 harmful 梯度与 over-refusal 的反事实拒答目标梯度的耦合——但训练中 over-refusal 样本只配对正确的 helpful 响应，反事实拒答目标梯度并不在标准目标里。故采用第三种：**完整保留 harmful 梯度**，只把 over-refusal 样本**可得的 helpful-target 梯度**对拒答子空间正交化：

```math
g_i^c=\nabla_\theta\mathcal{L}^c_{\text{SFT},i}(\theta,x_i,y_i),\quad c\in\{\text{harmful},\text{over-refusal},\text{benign}\}
```

```math
\tilde g_i=\begin{cases}g_i^c-Pg_i^c, & c=\text{over-refusal}\\ g_i^c, & c\in\{\text{harmful},\text{benign}\}\end{cases},\qquad
g_{\text{SFT}}^{\text{total}}=\frac{1}{B}\sum_{i=1}^{B}\tilde g_i
```

**Proposition 2（解耦性）**：投影后梯度满足 $\langle \tilde g^{over}_{i,t}, P\bar g_t\rangle=0$，与 harmful 梯度的剩余重叠为 $\langle (I-P)g^{over}_{i,t},(I-P)\bar g_t\rangle$；且仍是一阶下降方向：

```math
\mathcal{L}^{over}_{\text{SFT},i}(\theta_t-\eta\tilde g^{over}_{i,t},x_i,y_i)-\mathcal{L}^{over}_{\text{SFT},i}(\theta_t,x_i,y_i)=-\eta\|\,(I-P)g^{over}_{i,t}\,\|_2^2+O(\eta^2)
```

因 over-refusal 梯度并非完全落在拒答子空间内（$\|(I-P)g^{over}_{i,t}\|_2>0$），残余分量提供一阶下降信号，同时消除了拒答子空间分量。

### 5. Safety-aware Contrastive Learning
用 **Circle-style margin contrastive loss** 分离 harmful 与 over-refusal 的隐表征。因最终隐状态直接决定 token 生成，对比约束施加在**最后一层**（$h_i$ 为最后 transformer 层的 last-token 隐状态），无需在所有中间-深层强制对比目标。维护**类平衡的表征 memory bank** $M$；由同/异标签构造正样本集 $P_i$ 与负样本集 $N_i$；相似度 $s_{ij}=\cos(h_i,z_j)$。自适应对权重（Circle Loss）：$\Delta_p=1-m,\ \Delta_n=m,\ O_p=1+m,\ O_n=-m$，

```math
\alpha_p(i,j)=[O_p-s_{ij}]_+,\qquad \alpha_n(i,j)=[s_{ij}-O_n]_+
```

```math
\mathcal{L}_{\text{cont}}=\frac{1}{N_{\text{cont}}}\sum_{i=1}^{N_{\text{cont}}}\log\left[\frac{1+\sum_{j\in N_i}\exp\left(\gamma\alpha_n(i,j)(s_{ij}-\Delta_n)\right)}{\sum_{j\in P_i}\exp\left(-\gamma\alpha_p(i,j)(s_{ij}-\Delta_p)\right)}\right]
```

总更新方向：

```math
g_{\text{GOAL}}=g_{\text{SFT}}^{\text{total}}+\lambda\nabla_\theta\mathcal{L}_{\text{cont}}
```

### 6. 为何仅对比学习不够
拒答响应高度重复，harmful 样本仍会诱导集中的 harmful 梯度把优化偏向拒答；仅用对比学习需以较大损失权重间接对抗这种梯度级偏置，可能损害效用或安全。梯度正交化直接移除 over-refusal 更新中的拒答子空间分量，对比学习再改善表征层面的分离——两者分别对应**优化层面耦合**与**表征分离度下降**两种失效模式。

### 7. Safety-relevant 层选择
逐层计算 benign–benign 与 harmful–harmful 的类内相似度、benign–harmful 的类间相似度，定义 separation gap；由于类间相似度下降远快于类内，gap 随层快速变宽，取 gap 增长最快的**连续层块**为 safety-relevant 层。值得注意：早期分析中 harmful 与 over-refusal 可分的层正位于该层块的较早部分，提示模型最初保留了对 over-refusal 的区分能力，但随安全相关表征向深层传播而变得日益保守。因此把 LoRA 限制在整个 safety-relevant 层块（而非仅深层），以在逐层安全决策过程中维持连贯边界。拒答正交投影只作用于这些层的可训练参数梯度；对比目标用最后一层隐状态计算，其梯度只回传到选定层内的 LoRA 参数。

### 8. 时间复杂度
$d$ 为选定层可训练参数量、$N$ 为抽取子空间的有害样本数、$k$ 为保留方向数、$d_h$ 为隐状态维度：抽取阶段需 $N$ 次反向传播收集 $G\in\mathbb{R}^{N\times d}$，截断 SVD 代价 $O(Ndk)$；训练时低秩投影 $O(B_{\text{over}}kd)$，对比 memory-bank 比较 $O(B_c|M|d_h)$。因 $k$ 与 $|M|$ 较小，额外开销适中。

## 实验设置
- **训练数据（500 条）**：200 harmful（AdvBench、MaliciousInstruct、TDC2023）+ 200 benign（Alpaca）+ 100 over-refusal（OR-Bench-Hard、XSTest、PHTest）；参考响应由 **GPT-4o** 生成。
- **评测**：over-refusal 用 Compliance Rate（C.R.，在上述 over-refusal 数据集的 held-out 测试部分 + 两个 OOD 基准 **OKTest**、**CoCoNot**）；安全用 Safety Score（S.S.，**JailbreakBench (JBB)** 与 **STL**——Bianchi et al. 四个安全基准的合集）；通用能力用 Accuracy（MMLU、ARC-C、OpenBookQA、PIQA）。C.R. 与 S.S. 的 judge 为 **GPT-5.1**。
- **模型**：Gemma-7B-it、Llama-2-7B-Chat、Llama-2-13B-Chat，greedy decoding。
- **基线**：SFT、SCANS（推理时/表示层干预）、Surgical（表示层干预）、DCR（对比精炼阶段）、ACTOR（训练型）；为公平比较，ACTOR、DCR、SFT 均用与 GOAL 相同的 over-refusal 数据构造重训。
- **实现细节**：仅对选定 safety-relevant 层做 LoRA 微调，rank $r=16$、缩放 $\alpha=32$、dropout 0.05；选定层范围 Llama-2-7B-Chat **12–22**、Llama-2-13B-Chat **13–26**、Gemma-7B-it **15–23**；训练 **5 epochs**，effective batch size 4；拒答子空间秩 $k=10$；对比损失施加在最后一层，权重 $\lambda=0.1$；Circle loss margin $m=0.25$、scale $\gamma=80$；类平衡 FIFO memory bank 大小 **128**。

## 局限性
作者自述：
- 实验聚焦 **7–13B 的 open-weight instruction-tuned 模型**与**以英语为主的基准**；虽然 Qwen3-8B 结果支持向新模型族泛化，但**更大的模型、闭源模型与多语言模型仍需进一步评估**。
- 一阶分析给出的是**充分性刻画**，并未确立 harmful-gradient coupling 是 over-refusal 的**唯一**成因。
- 自动评测部分依赖 LLM judge（GPT-5.1），且强基准表现不保证在所有部署场景下都安全。
- 人类评估伦理：3 名硕士生独立评估，知情同意、时薪 CNY 100、可无惩罚退出，仅报告聚合结果；OpenAI Codex 仅用于语言润色、稿件组织与 LaTeX 准备。

我的补充批评：(1) 表征观察（层 13 可分、深层重叠）基于 **Llama-2-7B-Chat 的 PCA 可视化**，PCA 前两轴的可视分离度不等于真实的类别可分性，且"深层重叠"也可能只是投影伪影——论文未给出定量的线性探针/类间距离随层变化的统计检验；(2) 拒答子空间从 harmful 梯度的 SVD 得到，其 $k=10$ 的选取依据（"捕获主导能量"）未报告具体 CER 数值，人工设定成分较大；(3) 训练集仅 500 条、参考响应来自 GPT-4o，而评测 judge 也是 GPT-5.1，存在生成器-评判器风格的潜在耦合；(4) 论文同时把"表征重叠"归因于深层传播的保守性，但 GOAL 的对比损失只作用于最后一层隐状态，与"中间层可分"的观察在机制上并未直接对应，二者之间的因果链是叙述性的而非被实验验证的。

## 评估与建议
- 是否推荐深入阅读：是（把 over-refusal 从"数据问题"重构为"优化动力学问题"的角度很有启发，Proposition 1/2 及其可操作的梯度投影值得复用）
- 适用场景：安全对齐后的"拒答边界过紧"问题；设计需要同时保安全与保 helpful 的微调目标；低秩子空间干预类方法（与 activation steering、表示微调同族）；安全微调中 LoRA 层选择的工程决策。
- 与知识库的关联：与 2610.37245（Hausa 安全对齐中 SFT 提升流畅度、DPO 损害语言质量并伴随拒答精度上升）形成互补——那篇从数据与阶段角度归因，本文从梯度与表征角度归因；与 SCANS、Surgical、ACTOR、DCR 等 over-refusal 缓解方法构成对照谱系；也与 2610.39182 的"RL 究竟改了什么表征"主题同属表征动力学分析。
