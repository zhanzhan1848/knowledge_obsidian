# RM-VLM: From Natural-Language Task Descriptions to Vision-Grounded Reward Machines

## 摘要
**RM-VLM** 把 reward machine（RM）的构造自动化：RM 用自动机表示奖励函数，可把非马尔可夫任务的信用分配纳入马尔可夫框架，但传统 RM 假设存在一个**手工设计的命题接地预言机**（labeling function），需为每个环境手动工程化。本文改为：**LLM 从自然语言任务描述生成 RM**，**VLM 充当 labeling function**，在基于图像观测的 RM 引导策略学习中完成命题接地；再用基于 VLM 的价值函数估计器评估智能体对每个 RM 转移的进展，导出**稠密奖励信号**。在三个领域（非马尔可夫网格世界导航、机器人操作、3D 物体收集）上，RM-VLM 的任务成功率**一致优于**现有基于 VLM 的奖励方法。

## 核心贡献
1. 把 **reward machine 的手工命题接地预言机自动化** —— 用 VLM 替代人工工程化的 labeling function
2. **LLM 从自然语言任务描述生成 RM**，VLM 负责在图像观测上完成命题接地，形成 LLM→RM→VLM 的分工
3. 引入 **VLM 价值函数估计器** 评估对 RM 转移的进展，导出稠密奖励信号
4. 在非马尔可夫网格导航、机器人操作、3D 物体收集三个领域一致优于现有 VLM 奖励方法

## 方法与架构
**RM-VLM 三件套**：
1. **LLM 角色** —— 从自然语言任务描述生成 reward machine（把奖励表示为自动机，暴露任务的时间结构）；
2. **VLM 角色** —— 充当 labeling function，在图像观测上判定 RM 的各个命题（grounding）；
3. **VLM 价值函数估计器** —— 评估 agent 当前进展到哪个 RM 转移，导出稠密奖励。

**训练**：RM 引导下的策略学习。

**评测域**：非马尔可夫网格世界导航 / 机器人操作 / 3D 物体收集。

## 实验结果
- 在**全部三个测试域**上，RM-VLM 的任务成功率**一致高于**现有基于 VLM 的奖励方法
- 覆盖非马尔可夫（历史依赖信用分配）任务，验证了自动机式奖励的必要性

## 局限性
- 需要视觉观测才能接地命题，**纯文本任务不适用**；
- 依赖 LLM 生成 RM 的正确性 —— 生成错误的 RM 会把奖励信号带偏，且摘要未讨论该失效模式；
- VLM 命题判定本身的错误率未单独报告。

## 值得注意的点
与今日 CLDA「用显式确定性规则而非 LLM 判断」形成有趣对照：本文让 LLM/VLM **承担**判断（生成 RM、接地命题），而昨日的多篇工作在做相反的事 —— **判断该由谁做，取决于它有没有可验证的形式**。RM 的命题是可验证的（自动机状态），所以让模型生成是可以接受的。
