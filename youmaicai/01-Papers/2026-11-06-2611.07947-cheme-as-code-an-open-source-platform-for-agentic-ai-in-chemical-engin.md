# ChemE-as-Code: An Open-Source Platform for Agentic AI in Chemical Engineering

## 摘要
**ChemE-as-Code** 提供一个开源环境，让基于 LLM 构建的 AI agent 承担化学工程工作，而**工程师可以检查它**。其计算工具覆盖**从催化、过程模拟到装置布局、HAZOP 与生命周期评估**，而**技能（skill）**告诉通用 agent 如何使用这些工具。工程文件是**关联的、机器可读的、并在 Git 中版本化**；**计算在 LLM 之外运行**，**每个数值记录其来源（origin）**；自动化检查**按文件与行报告**不一致与过期结果。在一个说明性的**氨（ammonia）案例**中，agent 把一项书面任务发展为一份**初步基础工程包**（模拟文件、P&ID、布局、HAZOP、数据表、泄压设计），**API 成本 224 美元**（设计阶段）。作者强调：**植入故障与工程变更**显示这些检查**能找到规则覆盖的部分，并漏掉其余部分** —— 因此它们**指导人工评审，而非取代它**。明确声明：**尚无独立工程师评审过该设计**。

## 核心贡献
1. 开源平台：LLM agent 执行化学工程工作 + **工程师可检查**的双轨设计
2. 工具覆盖广：**催化 → 过程模拟 → 装置布局 → HAZOP → 生命周期评估**
3. 三条工程原则：文件**关联 + 机器可读 + Git 版本化**；**计算在 LLM 之外运行**；**每个数值记录来源**
4. 自动化检查**按文件与行**报告不一致与过期结果
5. **诚实的边界声明**：植入故障证明检查只覆盖规则内的问题 → **指导人工评审而非取代**；**无独立工程师评审过该设计**

## 方法与架构
**架构**：
```
工程文件（关联 / 机器可读 / Git 版本化）
   ↑              ↓
技能(skill) → 通用 LLM agent → 计算工具
                 ↓
        计算在 LLM 之外执行（每个数值记录 origin）
                 ↓
        自动化检查（按文件与行报告不一致 / 过期）
```

**氨案例**：书面任务 → 初步基础工程包（模拟文件、P&ID、布局、HAZOP、数据表、泄压），**API 成本 224 美元**。

**故障验证**：植入故障 + 工程变更 → 检查**能找到规则覆盖的部分，漏掉其余**。

## 局限性
- **无独立工程师评审** —— 作者自己声明，是本篇最重要的限定；
- 224 美元成本对应的是「设计阶段」，**全流程（含迭代与审查）成本未知**；
- 单一化学领域（氨），方法向其他工程领域迁移未验证；
- 「检查漏掉其余」未量化漏检率。

## 值得注意的点
**「每个数值记录其来源（origin）」+「计算在 LLM 之外运行」** 是这篇最可迁移的设计 —— 它把 agent 从「生成答案」改成「生成可追溯的工件」。配合**按行报告**的自动检查，形成了一条人类工程师能真正接手的审计链。最后那句「尚无独立工程师评审」值得所有做 agent 系统的团队抄进自己的论文里 —— 它是当前这个领域最稀缺的那种诚实。
