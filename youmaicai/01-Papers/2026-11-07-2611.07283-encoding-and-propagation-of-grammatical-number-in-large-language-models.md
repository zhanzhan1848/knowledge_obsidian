### 核心贡献
1. 完整刻画了单一语法现象——number agreement（数一致）——在 LLM 隐层中的表示与传播机制：找到并传播 `plural noun`、`plural matrix subject`、`generate a plural verb` 三类 SAE 特征，使模型输出 `are`/`do`/`have` 而非 `is`/`does`/`has`。
2. 通过因果干预证明这些特征确实驱动行为：从复数主语名词 token 的隐状态中移除这些特征会让模型改输出单数动词，反向干预亦然（vice versa）。
3. 发现「单数」方向的特征（`singular noun`、`generate a singular verb`）在该任务上不如复数方向有效，提出英语数范畴在模型中以 **privative representation**（缺省式/默认单数、复数为标记）的方式编码。
4. 在更大的 Gemma-2-2b 与 Llama-3.1-8b 上复现了类似结果。

### 技术方案
**核心思想**: 用 Sparse Autoencoder 把不可读的隐状态向量翻译成人类可解释的「特征/符号」列表，通过特征级的因果干预（ablation / insertion）反向验证特征与语法行为之间的因果对应关系，从而把「数一致」这一语法现象从黑箱中还原为可传播的离散特征。

| 技术 | 说明 |
|------|------|
| Sparse Autoencoder (SAE) | 训练于 Pythia-70M，将 LLM hidden state 向量分解为人类可理解的特征/符号列表 |
| 三类关键特征 | `plural noun`、`plural matrix subject`、`generate a plural verb`；后两者直接对应提示（如 "the men in the park"）下输出复数动词形式 |
| 特征级因果干预 | 从复数主语名词 token 的隐状态中移除特征 → 模型改输出单数动词；反向干预（vice versa）同样有效 |
| 不对称性分析 | 对应的 `singular noun` 与 `generate a singular verb` 特征效果较弱 → 支持 privative representation 假设 |
| 跨规模验证 | 主要实验在 Pythia-70M（<100M 参数、在小语料上训练），结果在 Gemma-2-2b 与 Llama-3.1-8b 上得到复现 |
| 研究动机 | 参数少、语料小的模型仍表现出强语法能力与话语连贯性，但产出内容可靠性有限 |

### 实验结果
- **数据集**: 自建/自标注的 number agreement 提示与干预实验（具体语料与数据集名称摘要未说明）
- **基线**: 摘要未提供传统基线方法（对比对象为模型自身的单/复数特征族之间）
- **结果**: 定性结果为主——三特征可成功驱动复数动词生成；移除特征导致单数输出，反向亦成立；单数特征效果较弱；结论在 Gemma-2-2b、Llama-3.1-8b 上复现。摘要未给出具体准确率或干预幅度数值

### 局限性
- 摘要未提供任何定量指标（无准确率、无特征稀疏度/重建误差、无干预比例曲线），结论偏定性。
- 主实验基于 Pythia-70M 这一极小模型，其 SAE 特征不一定具备人类可解释性之外的语义稳定性；向大模型的迁移仅验证了「类似结果」而非等价性。
- 仅研究了英语的 number agreement 单一现象，未涵盖性别、时态等其它语法维度，也未涉及多语言的数表达差异（如阿拉伯语的双数/复数）。
- 摘要未说明 SAE 的训练规模、重建质量、特征的重叠度（feature splitting/absorption 问题）等方法学细节，尽管作者自称这是本文主要贡献所在。

### 关键洞见
> 最有意思的不是「模型会复数」，而是**它只会复数**——英语数范畴在模型内部是 privative（缺省单数 + 复数作为附加标记）编码的：特征 ablation 掉「复数」还能退回单数，但反过来不成立。这解释了为什么小模型在语法上表现强健却内容不可靠：语法被压缩成少数几个可组合的离散特征传播，而世界知识仍是弥散的、不可靠的——语法与知识在参数与特征空间里根本不是同一种存储介质。
