## 核心贡献
1. **身份受控的测量不变性测试范式**：用 **421 个模板**对**七个受保护群体**做**完全一致的实例化**，使得**只有身份词发生变化**，从而构成严格的反事实对照。
2. **揭示高准确率掩盖下的系统性偏误**：4 个 LLM 分类器**各自平衡准确率均超过 0.95**，但在**完全相同的模板内**，其中两个模型对**涉及女性的仇恨言论**的漏检率显著高于对其他群体相同言论的漏检率——**超额假阴性率分别为 8.3 和 4.4 个百分点**；该差距**早在 2021 年就已在微调分类器上被报告过**。
3. **构念漂移的机制性证据（通过 rationale 对比）**：在每个模板内比较 rationale，发现模型对其他群体会援引**受保护群体身份**作为判据，却把针对女性的**同一句陈述**重新表述为**个人厌恶**或**指向个人**——某模型在 **30 个漏检模板中有 22 个**出现这种重构。
4. **否定了"补充定义"这一补救措施**：在提示中加入该基准自身对仇恨言论的定义（其中明确列出 sex 为受保护特征），**并未弥合差距**，且对比持续存在。
5. **假阳性差异的来源被证伪**：表面上的假阳性不平等在身份控制下**基本消失**，实际可追溯到**仅存在于部分群体的"reclaimed slurs"（被重新占用的侮辱性称谓）**。
6. **方法论结论**：验证 LLM 作为测量工具，需要**同时检验决策与模型自述判据**的**身份受控测量不变性**；且**成对反事实准确率相对端点准确率增益甚微**。

## 问题背景
LLM 越来越多地被用作**测量工具（measurement instruments）**，用于仇恨言论这类具有社会后果的构念（construct）。这类系统的验证通常只依赖**与人工标签的总体一致性（aggregate agreement）**，即整体准确率。但一个有效的测量工具必须对**它所测量的每一个群体施加同一构念**——即测量不变性（measurement invariance）。总体准确率 >0.95 的高分类器完全可能在不同群体上系统性地测量了**不同的构念**（如把"针对女性群体的仇恨"重新解读为"个人厌恶"），而这种偏误在聚合指标中不可见。此外，**模型给出的 rationale（理由）**作为可审计的判据来源，此前少有研究系统性地用身份反事实来检验"模型自述的判据"是否随身份变化。

## 方法

### 身份受控的反事实模板设计
- **421 个模板**（templates），每个模板对 **7 个受保护群体**做**完全一致（identically instantiated）**的实例化——**唯一变化的是身份词（identity term）**。
- 这一设计排除了句法、语境、情绪强度等混淆，只留下身份项，从而构成严格的**受控反事实**。

### 被测分类器
- **4 个 LLM 分类器**，各自平衡准确率均 **> 0.95**。
- 除决策输出外，还收集**rationale**（模型自述的判定判据）。

### 分析维度
1. **端点准确率**（endpoint accuracy）：按群体分别统计真阳/假阴/假阳；
2. **超额假阴性率（excess FNR）**：同一模板内，某群体上的漏检率减去其他群体上的漏检率；
3. **Rationale 对比**：在同一模板内跨群体比较 rationale 的判据框架，检测**构念漂移**；
4. **假阳性差异归因**：在身份控制下重新审视假阳性不平等等。

### 关键对照实验
- **加入基准自身定义**（其中把 sex 列为受保护特征）到提示中，检验"定义提示"能否修复偏误；
- **成对反事实准确率**（pairwise counterfactual accuracy）的评测价值，与端点准确率对比。

## 实验结果

| 指标 | 结果 |
|------|------|
| 分类器数量 | **4 个** |
| 平衡准确率 | 全部 **> 0.95** |
| 模板数 | **421** |
| 受保护群体数 | **7** |
| 超额假阴性率（针对女性） | 模型 A：**8.3 个百分点**；模型 B：**4.4 个百分点** |
| 判据重构现象 | 某模型 **30 个漏检模板中 22 个**把针对女性的同一陈述重构为"个人厌恶 / 指向个人" |
| 定义提示补救 | **无效**：加入基准定义（含 sex 为受保护特征）后差距**未闭合**，对比持续 |
| 假阳性差异 | 在身份控制下**基本消失**；归因为仅对部分群体存在的 **reclaimed slurs** |
| 跨模型共有错误 | 集中于**模型定义与基准定义发生分歧**之处 |
| 成对反事实准确率 | 相比端点准确率**增益甚微（adds little）** |

摘要未给出 4 个分类器的具体名称、7 个受保护群体的具体清单、以及按群体拆分的完整准确率表。

## 关键洞察
1. **总体一致性不是构念效度的充分条件**：>0.95 的平衡准确率与"对不同群体实际测量不同构念"可以同时成立。把"聚合一致"当作唯一效度证据，是当前 LLM 评测实践的系统性盲点。
2. **偏误在 rationale 层先于决策层可被观测**：模型在决策错误之前，就已经改变了自己的判据框架（从"针对受保护群体的仇恨"转为"个人厌恶"）。这说明测量不变性失效的机制是**构念漂移**，而非单纯的阈值/概率偏差——只修决策不改判据难以治本。
3. **定义提示无法弥补**：即便明确告知模型"sex 是受保护特征"，偏误依然存在。这反驳了"只要把规范写进提示就能对齐"的朴素假设，问题出在模型内部的语义框架而非知识缺失。
4. **假阳性不平等可能被误读**：reclaimed slurs 造成的表观群体差异是**语用现象而非偏误**，若不引入身份控制，很容易把它当作系统性歧视并错误归因——这是本文对"公平性审计"实践的重要警示。
5. **反事实测试的价值在诊断而非评分**：成对反事实准确率本身并不比端点准确率更有区分度，但**对照组内的 rationale 比较**才是揭示构念漂移的关键手段——测试应设计为诊断工具，而非又一个排行榜指标。
6. **该问题在 2021 年已被记录**：本文并非发现新现象，而是说明**五年后这些问题模型仍未解决**，且在 LLM 时代以更高的绝对准确率重现——修复难度随模型规模提升而上升。

## 局限性
- 摘要未列出 4 个分类器名称与 7 个受保护群体清单，无法判断结论在不同模型/群体上的普适性。
- 模板来自既有基准（**421 个模板**），模板数量与群体覆盖决定了统计精度；跨模板的泛化性未验证。
- 结论限于**英语**仇恨言论与该特定基准的定义，跨语言、跨文化语境下的构念等价性未讨论。
- rationale 的抽取与分析方法（如何编码"个人厌恶/指向个人"这类重构）细节未在摘要中给出，存在人工编码主观性。
- 假阳性的 reclaimed slurs 解释虽被给出，但摘要未提供其定量证据（如这类词在 7 个群体中的分布）。
- arXiv preprint（18 页、6 图），未经同行评审。

## 适用场景
- **仇恨言论检测、毒性分类等社会后果性 LLM 评测**的审计与验收流程设计。
- 需要为**多个群体**部署同类分类器的公平性核查（医疗、招聘、信贷、广告审核场景同样适用该范式）。
- **可解释性审计**：用 rationale 对比检测模型的判据漂移，而非只看决策。
- 构建多语言/跨文化有害内容分类器时的**测量不变性检验协议设计**。
- 红队测试与预部署模型审查流程。
