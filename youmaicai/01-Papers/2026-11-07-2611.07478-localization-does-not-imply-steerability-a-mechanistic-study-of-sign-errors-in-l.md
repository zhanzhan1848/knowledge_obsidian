# Localization Does Not Imply Steerability: A Mechanistic Study of Sign Errors in LLM Mathematics

### 核心贡献
1. 定位 LLM 多步数学中典型的 **「符号错误」**（写错一个负号 token，例如 cofactor sign 或分部积分中的负号，后续算术全对但最终答案错）究竟在网络内部何处被写入。
2. 在 **6 个开源模型（14B–675B）** 上做 per-layer readout：错误的符号是在 **网络最后四分之一** 被提交的，主要由 **MLP 层** 完成（每个模型与任务上占 **70–100%**）；在 Qwen 上该模式 **在 instruction tuning 之前的 base model 中就已存在**。
3. 揭示机制异质性并证明 **因果性**：部分模型有固定的「minus-stamp」层（无论正确答案是什么都强推负号），部分模型是「放大已选符号」的 amplifier，Qwen 还额外有一个下游 **rescue layer** 与 stamp 对抗；干预层面，从 residual stream 中减去单个符号方向即可翻转 Llama-3.3-70B 上 **13/14** 个 held-out 的「误写负号」的分部积分错误。
4. 提出核心论断：**「定位到机制」不等于「可操纵机制」**——Phi-4 具有同等精确定位、同样深度的电路，但同样干预几乎无效，因为符号在约 **15 层** 上被冗余写入，margin 大出数倍（**中位 17.8 logits**）。

### 技术方案
**核心思想**: 用「逐层探针 + 单方向 residual stream 干预 + 预注册（preregistered）」三件套，把「符号错误写在哪」从相关性描述升级为因果性实验，并据此检验可操纵性是否随模型而异。

| 技术 | 说明 |
|------|------|
| Per-layer readout | 逐层读取网络内部状态，判断「错误符号」在第几层被写入；结果为错误符号在网络 **70–100% 深度区间**（最后四分之一）被提交，且由 **MLP 层**承担 |
| 「minus-stamp」层 | 在部分模型中识别出的固定机制：无论正确答案符号为何，都强行向 residual stream 推入负号方向 |
| Amplifier 层 | 另一类机制：放大先前已被选定的符号，而非自行决定符号 |
| Rescue layer | Qwen 特有的下游层，方向与 minus-stamp 相反，起到「补救」作用、抵消错误符号 |
| 单方向干预（steering） | 从 residual stream 中减去一个符号方向；在 Llama-3.3-70B 上翻转 **13/14** 个 held-out 错误；在 Qwen、Gemma、Mistral-Small 上每格 **24–70%** 复现 |
| 表征层面特异性 | 同一剂量的干预会破坏本就正确的负号答案，而放过正确的正号答案；Llama 上此数字为 **0/72** |
| 对照实验 | matched random-direction 与 control-layer 干预均为 **null**，确认效果源自目标方向而非一般扰动 |
| 预注册 | 核心论断在看 held-out 数据前先在 git 中冻结判据；**29 项检查通过 23 项**，所有未通过项均如实报告 |
| 冗余性度量 | Phi-4 的符号在约 **15 层**上冗余写入，margin 中位 **17.8 logits**，故同等强度的干预无法翻转 |

### 实验结果
- **数据集**: LLM 数学多步推理错误案例（分部积分、cofactor 等符号错误任务；具体数据集名称摘要未说明），含 held-out 错误集
- **基线**: 对照为 matched random-direction 干预与 control-layer 干预（均 null）；模型覆盖 Qwen、Llama-3.3-70B、Gemma、Mistral-Small、Phi-4 等 6 个 14B–675B 开源模型
- **结果**: 符号在网络 **70–100%** 深度区间由 MLP 层提交（每模型每任务）；Llama-3.3-70B 干预翻转 **13/14** held-out 错误；Qwen/Gemma/Mistral-Small 每格 **24–70%**；特异性上 Llama 上 **0/72** 正确负号被破坏；Phi-4 干预几乎无效（冗余约 **15 层**，margin 中位 **17.8 logits**）；预注册检查 **23/29** 通过

### 局限性
- 任务聚焦于 **符号（负号）这一类 token 级错误**，结论能否推广到其它类型的中间错误步骤未验证
- 干预是 **单方向、单一剂量** 的简单 steering，摘要未说明是否尝试搜索更强的剂量或多方向组合
- Phi-4 的冗余写入机制未被进一步刻画（摘要只说明其导致干预无效）
- 61 页论文中核心结论依赖人工构造的错误案例集，错误注入方式与真实模型失败分布的差距摘要未量化

### 关键洞见
> 「模型在哪里犯错」和「我们能不能改掉它犯错」是两个独立问题。Phi-4 与 Llama-3.3-70B 把符号写在同样深的 MLP 层，但一个可被单方向干预翻转 13/14，另一个因 **15 层冗余 + 17.8 logits 的 margin** 完全免疫——这意味着 mechanistic interpretability 的「定位成功」很可能被系统性地高估了其干预价值。
