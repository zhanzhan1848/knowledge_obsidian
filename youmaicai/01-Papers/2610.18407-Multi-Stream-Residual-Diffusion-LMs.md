# Multi-Stream Residual Computation in Diffusion Language Models

---

## 核心贡献

> 把 masked diffusion LM 的 single residual stream 拆成多个 persistent stream + adaptive routing——支持 visible 与 masked 位置学习出不同的 read/write 路由模式。

1. **Multi-stream residual**：在 masked diffusion LM 中引入多个 persistent residual stream
2. **Adaptive routing**：visible vs masked 位置自动学到不同路由
3. **Reconstruction 提升**：2 streams 让 validation PPL -5.71%，external corpora 平均 -5.13%
4. **Causal intervention**：揭示多 stream 实现 read/write 分离 + token-specific write strength
5. **Role-conditioned routing**：用 predefined role 仍能恢复一半 gain
6. **Scale 验证**：机制在更大模型上重现

---

## 技术方案

### 核心思想

Masked diffusion LM 共享 single residual stream，导致 visible 与 masked 位置信息互相干扰。引入多个 persistent stream + adaptive routing，让两类位置自然分离：

- **visible 位置**：倾向 read stream
- **masked 位置**：倾向 write stream

且 routing 是 learnable 的，无需人工定义 role。

### 关键技术

| 技术 | 说明 |
|------|------|
| Multiple persistent residual streams | 在整个 depth 内持续存在 |
| Adaptive routing | 数据驱动学习 read / write 模式 |
| Causal intervention 分析 | 验证 read/write 分离的功能意义 |
| Role-conditioned routing baseline | 人工定义 role 仍获 half gain |
| Token-specific write strength | 每 token write 强度独立 |
| State interventions | 显示额外 stream 保留早期 token 表达 |

## 公式

设 $K$ 个 stream $\{s_1, \dots, s_K\}$。Routing 在每层：

```math
r_t^{(k)} = \frac{\exp(g_k(x_t, \text{context}))}{\sum_{j} \exp(g_j(x_t, \text{context}))}
```

Stream 更新：

```math
s_k \leftarrow s_{k-1} + r_t^{(k)} \cdot \text{block}_k(x, \{s_j\})
```

读出：

```math
y = \text{read}(\{s_1, \dots, s_K\})
```

## 实验结论

- **Reconstruction perplexity**：2 streams vs single → -5.71% on val
- **External corpora**：平均 -5.13%
- **Causal intervention**：streaming 分离是功能性的（read vs write）
- **Role-conditioned routing**：恢复一半 gain（说明 learnable routing 仍可学）
- **Scale up**：更大模型同样观察到此模式

---

## 局限性

- 多 stream 增加参数与计算（成本分析未充分给出）
- 路由模式是否可被外部分析利用未深入
- 仅在 masked diffusion 验证（autoregressive 流式未验证）
- 训练稳定性 / 收敛特性
