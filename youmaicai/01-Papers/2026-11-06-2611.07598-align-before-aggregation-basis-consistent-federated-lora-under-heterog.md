# Align Before Aggregation: Basis-Consistent Federated LoRA under Heterogeneous Ranks

## 摘要
异构客户端容量下 LLM 的**联邦微调**日益重要，而**异构秩的 LoRA** 使之可行。但既有服务端聚合器在聚合前先**组合**各客户端的矩阵更新 ΔW_i（由客户端特定的 LoRA 因子 (A_i, B_i) 生成）。虽然这些矩阵更新位于同一权重空间 R^{m×n} 且可直接平均，**生成它们的 LoRA 因子却可能表达客户端特定的局部基（basis）**。在典型的 **compose → aggregate → factorize → dispatch** 循环中，这种**基不一致性**会使派发给低秩客户端的秩 r_i 参考前缀在服务端再分解后**变得不稳定**。本文提出 **FedAbA**（basis-consistent federated LoRA aggregation）：先提取每个客户端的局部基，将它**对齐到全局参考基的对应前缀**，构造**基一致的局部矩阵更新重建**，然后再聚合；聚合权重结合**客户端数据规模与一致性分数**；随后做**精确的系数空间 SVD 再分解**与 gauge fixing。

## 核心贡献
1. 识别**联邦 LoRA 异构秩聚合中的基不一致性（basis inconsistency）**问题 —— 矩阵更新可平均，但底层因子基不同
2. 说明后果：派发给低秩客户端的参考前缀在服务端再分解后**不稳定**
3. 提出 **FedAbA**：局部基提取 → **对齐到全局参考基前缀** → **基一致重建** → 加权聚合（数据规模 × 一致性分数）→ **精确系数空间 SVD 再分解** + gauge fixing

## 方法与架构
**问题刻画**：
```math
\Delta W_i = B_i A_i \quad (A_i \in \mathbb{R}^{r_i \times n},\ B_i \in \mathbb{R}^{m \times r_i})
```
每个客户端的 (A_i, B_i) 表达**客户端特定的局部基**；矩阵 ΔW_i 在同一空间可直接平均，但基不同 → compose-aggregate-factorize-dispatch 循环后**秩 r_i 参考前缀不稳定**。

**FedAbA 四步**：
1. **基提取与对齐**：抽取客户端局部基，对齐到**全局参考基的对应前缀**；
2. **基一致重建**：构造基一致的 ΔW_i 重建；
3. **加权聚合**：权重结合**客户端数据规模**与**一致性分数**；
4. **精确再分解**：**系数空间精确 SVD** + **gauge fixing**（消除符号/旋转歧义）。

## 实验结果
- 提出并验证 FedAbA 框架（论文中被 **NeurIPS 2026** 录用）
- 核心贡献是**问题诊断 + 一致性保证的聚合流程**，摘要未列出统一量化提升
- 关键工程含义：基一致性 + gauge fixing 使异构秩联邦 LoRA 的参考前缀派发**稳定**

## 局限性
- 摘要未给出主结果的数字表格（提升幅度需查正文）；
- 全局参考基的构造质量是关键上游依赖，其初始化策略未在摘要说明；
- gauge fixing 的选择（SVD 符号约定）在数值上仍有自由度残留风险。

## 值得注意的点
「**矩阵可平均，但基不可平均**」是一个精确的问题刻画 —— 它解释了为什么异构秩 LoRA 联邦在实践中不稳定：平均后的矩阵再分解到秩 r_i 时，得到的前缀**不是任何客户端原本持有的基**。这是典型的「数学上等价、临床上不等价」的分布式学习陷阱。
