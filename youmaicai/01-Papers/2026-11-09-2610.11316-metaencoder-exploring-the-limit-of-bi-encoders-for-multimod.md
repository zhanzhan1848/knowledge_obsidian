# MetaEncoder: Exploring the Limit of Bi-Encoders for Multimodal System One Decision Making with Natural Language Interface

> **arXiv**: [2610.11316](https://arxiv.org/abs/2610.11316)
> **发表日期**: 2026-10-08（v2 更新于 2026-11-06）
> **分类**: cs.CL (Computation and Language)；交叉分类 cs.AI
> **会议/期刊**: arXiv preprint

## 📋 摘要

「System One」模型强调快速、低延迟的决策以及**校准良好的概率分布**，而非逐 token 生成。当前的系统普遍依赖结构化 schema 与类型化输出，但**候选打分（candidate scoring）各架构之间的取舍**仍缺乏系统理解。本文系统性地研究了三种从预训练 decoder 改造而来的打分架构的**扩展动态、精度与推理效率**：**bi-encoder**、**cross-encoder** 与 **constrained decoder**。实验显示三种架构都随模型规模呈现清晰的性能提升；**cross-encoder 在各模型规模下始终取得最高精度**，而 **bi-encoder 与 constrained decoder 随训练 token 数增加表现相近**。效率方面，**bi-encoder 的推理延迟随候选池增长近乎恒定**（因为候选嵌入可离线缓存），而 cross-encoder 与 constrained decoder 的代价随候选规模**呈二次增长**。这一效率优势使 bi-encoder 成为**连接「小型闭集决策」与「海量开放集检索」的独特桥梁**。对于闭集任务，把**所有候选选项都写入请求提示**对保持 bi-encoder 的竞争力至关重要。基于这些洞察，作者提出 **MetaEncoder**：一个多模态编码器，由 **Muse-Glimmer decoder** 通过**单向对比学习**微调而来，用于匹配请求（request）与候选（candidate）。论文提出 **packed contrastive training**，以最大化动态分配负样本候选时的效率，从而支持把一个 **30B decoder 显存高效地全量微调为 encoder**。在横跨闭集决策、多模态理解与开放集检索的 **12 个基准套件**上评测，MetaEncoder 在决策任务与 **MMEB-v3** 图像/视频检索上超过 SOTA 多模态 embedding 基线，并能扩展到当前决策模型远远无法承受的开放候选空间。

## 🎯 核心贡献

1. **系统性刻画三类打分架构的权衡**：bi-encoder / cross-encoder / constrained decoder 在精度、扩展性与推理延迟上的全景对比（同一预训练 decoder 出发，可控比较）。
2. **发现 bi-encoder 的独特生态位**：其延迟随候选池增长近乎恒定（候选嵌入可离线缓存），是连接「小型闭集决策」与「海量开放集检索」的桥梁；并指出闭集任务中**把全部候选写入 prompt** 是维持其竞争力的关键。
3. **提出 MetaEncoder**：由 Muse-Glimmer decoder 经**单向对比学习**改造的多模态编码器，用自然语言接口匹配请求与候选。
4. **提出 packed contrastive training**：支持动态分配负样本候选，显存高效地把 **30B decoder 全量微调**为 encoder。
5. **全面验证**：12 个基准套件，决策任务与 MMEB-v3 图像/视频检索超越 SOTA embedding 基线，且能扩展到超大开放候选空间。

## 🔧 方法/架构

- **三种打分架构**（均从同一预训练 decoder 改造）：
  - **bi-encoder**：请求与候选分别编码为向量，按向量相似度打分；
  - **cross-encoder**：请求与候选拼接后联合编码，逐对打分；
  - **constrained decoder**：在候选集合的约束下由 decoder 逐项打分。

  ```math
  \text{bi-enc}(q,c) = \cos\big(f(q), g(c)\big),\quad
  \text{cross-enc}(q,c) = s\big([f(q);f(c)]\big),\quad
  \text{cd}(q,c) = s\big(\text{decoder}(f(q), f(c))\big)
  ```

- **推理代价的量级差异**：cross-encoder 与 constrained decoder 需对每个候选单独前向，代价随候选数 $N$ 近似二次：

  ```math
  \text{cost}_{\text{cross/cd}}(N) = \Theta(N \cdot L),\quad
  \text{cost}_{\text{bi-enc}}(N) = \Theta(L) + \underbrace{0}_{\text{候选嵌入离线缓存}}
  ```

- **闭集任务的关键实践**：在请求提示中包含全部候选选项，可弥补双塔架构缺乏交叉交互的劣势（否则精度落后于 cross-encoder）。

- **MetaEncoder 架构**：由 **Muse-Glimmer decoder** 出发，改为**单向（unidirectional）**编码器形态，通过**对比学习**对齐请求表示与候选表示：

  ```math
  \mathcal{L}_{\text{contra}} = -\log\frac{\exp\big(\cos(f(q), g(c^+))/\tau\big)}
  {\sum_{c \in \mathcal{B}\cup \mathcal{N}}\exp\big(\cos(f(q), g(c))/\tau\big)}
  ```

- **Packed contrastive training**：把动态采样的负样本打包成批次进行计算，避免为每个负样本单独构造样本对，从而在显存约束下全量微调 30B 模型：

  ```math
  \mathcal{L}_{\text{packed}} = \sum_{i=1}^{B}\Big[-\log \frac{e^{s(q_i, c_i^+)/\tau}}{e^{s(q_i,c_i^+)/\tau} + \sum_{j \in \text{pack}(i)} e^{s(q_i, c_j^-)/\tau}}\Big]
  ```

- **自然语言接口**：请求与候选均以自然语言/文本化形式表达，使同一编码器既能处理闭集结构化选项，也能处理开放集的自然语言候选。

## 📊 实验结果

- **数据集/基准**：**12 个基准套件**，覆盖闭集决策、多模态理解、开放集检索；其中包含 **MMEB-v3** 图像/视频检索基准。
- **基线**：SOTA 多模态 embedding 基线（原文另列出更细的对比列表，摘要未逐项列举）；三类打分架构之间的相互比较。
- **结果**：
  - 三种架构**均随模型规模呈现清晰的性能提升**（scaling）；
  - **cross-encoder 精度在各模型规模下最高**；
  - **bi-encoder 与 constrained decoder 随训练 token 数增加表现相近**；
  - **bi-encoder 推理延迟随候选池增长近乎恒定**，cross-encoder 与 constrained decoder 呈**二次增长**；
  - **MetaEncoder** 在决策任务与 **MMEB-v3** 图像/视频检索上**优于 SOTA 多模态 embedding 基线**，并能扩展到远超现有决策模型承载能力的开放候选空间；
  - 摘要未给出各基准的具体分数与规模参数（30B 全量微调为 encoder 为明确给出的规模信息）。

## ⚠️ 局限性

- 精度结论明确**有利于 cross-encoder**，bi-encoder 的定位是「效率-精度折中」，在精度优先场景并不占优。
- 「闭集任务需把全部候选写入 prompt」这一实践限制了提示长度，对超长候选清单不可行。
- MetaEncoder 由 **Muse-Glimmer** decoder 改造而来，结论对该基座的依赖程度未做跨基座复现。
- packed contrastive training 的显存效率提升幅度、负样本数量与批次打包策略的敏感度，摘要未给数值。
- 摘要未披露 12 个基准的具体名称与分数，无法仅凭摘要评估各基准上的一致性。
- 论文未涉及**校准质量**（虽在动机中强调 calibrated probability distributions）的直接度量。

## 💡 建议

- 是否推荐使用：**是**（若业务场景以延迟与候选规模为主要约束）
- 适用场景：高并发低延迟的候选打分服务（候选嵌入可离线缓存）、海量开放集检索与语义匹配、需要自然语言接口统一结构化与非结构化候选的决策系统、检索-重排流水线中的轻量第一阶段
