## 核心贡献

> 给 long-horizon agentic RL 一个 **single-rollout asynchronous recipe**，Muon 优化器 + token-averaged loss + truncated IS + auxiliary length / tool-error penalties。

1. **Single-rollout async**：每 issue 单 trajectory，rollout 期间即可 update，无需等待同 issue 多条样本。
2. **Muon 优化器 + 适配**：Long horizon + 稀疏 outcome reward 场景下，Muon 类 ortho momentum 比 AdamW 更稳。
3. **Auxiliary penalties**：length penalty + tool-error penalty 显式约束，避免 rollout 失控。

---

## 技术方案

### 核心思想

Repository-level issue resolution 是典型的 long-horizon 任务：
- 推理 + 工具调用 + 环境反馈交织；
- sparse outcome reward → 轨迹长度差异极大；
- rollout 期间就要 update → 需要 asynchronous。

新 recipe：
- **Muon optimizer**：orthogonalized momentum（与 AdamW 形成对比）；
- **Token-averaged loss**：避免 length bias；
- **Truncated importance sampling**：off-policy 校正；
- **Auxiliary penalties**：长度惩罚 + tool-error 惩罚（避免无效长 rollout）。

### 关键技术

| 技术 | 说明 |
|------|------|
| Muon optimizer | orthogonal momentum |
| Token-averaged loss | 消除长度 bias |
| Truncated IS | off-policy 校正 |
| Async single-rollout | 不需同 issue 多条 |
| Length penalty | 控制 rollout 长度 |
| Tool-error penalty | 约束错误工具调用 |

## 实验结论

- **任务**: repository-level issue resolution（agentic）
- **模型族**: 两个
- **基线**: 多种（包含 AdamW baseline）
- **结果**: 完整 recipe training success **显著高于** baselines。

---

## 局限性

- 仅在 repo-issue 任务验证，泛化到 web agent / embodied agent 待检验；
- auxiliary penalty 系数需要调参；
- Muon 的 GPU / distributed 实现门槛相对 AdamW 高。
