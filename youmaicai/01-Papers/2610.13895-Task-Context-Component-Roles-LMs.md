## 核心贡献

> 提出"网络视角"理解 LM 内部：相同 attention head 在不同任务下扮演不同角色，task 上下文重新分配 influence。

1. **网络视角**: 用 graph facts (directed connections) 描述模型计算，而非只看 attention head
2. **跨 5 个 open-weight 模型** (Gemma-2-9B, Qwen3-14B 等) 验证 task-dependent influence 重分布
3. **线性 response map**: 同一 head 在不同任务下对前驱 head 的响应线性映射差异显著

---

## 技术方案

### 核心思想

机械可解释性通常找"共享 head"，但 head 在不同任务下功能不同。本文用 network 视角：定义 **graph facts** 描述 directed connections；用 influence（对后续 head/激活的影响）和 importance（对最终答案的影响）双指标刻画 role。

### 关键技术

| 技术 | 说明 |
|------|------|
| Graph fact | "哪条 directed connection 存在"的声明 |
| Influence metric | attention head 对后续激活的影响 |
| Importance metric | 对最终答案的影响 |
| Linear response map | 不同任务下同一 head 对前驱 head 响应的线性映射 |
| Activation edit | 改变早期内部激活向量的手术式编辑 |

### 关键发现

- Gemma-2-9B 中单次 activation edit **切换了模型"读取的 fact"**，而 written instruction 不变
- Task 改变时，**同一 head 响应不同 graph facts**，对后续组件影响差异显著
- 任务专属线性 map 比"两任务平均 map" MSE 降低 **53.6% (Gemma)** / **5.0% (Qwen)**

---

## 实验结论

- **数据集**: 自构建 factual intervention prompts
- **模型**: 5 个 open-weight 模型，覆盖 4 家族、1.5-14B 参数
- **结果**:
  - Task-dependent influence redistribution 在所有模型中普遍存在
  - 任务专属 linear response map 显著优于平均 map

---

## 局限性

- 仅关注 factual intervention 任务，对长链 reasoning / 多轮对话未验证
- "Network 视角"尚未完整形式化；graph fact 定义受人为选择影响
- 仅在 ≤14B 模型上验证，更大规模模型是否同构未知

- **实现难度**: 高（需要精细的 mechanistic intervention 工具链）
