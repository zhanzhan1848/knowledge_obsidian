## 核心贡献
1. **四大目标**：简化 prompt 工程、稳定输出质量、内置领域世界知识、小参数高效部署
2. **核心挑战**：深度领域知识注入 → 严重灾难性遗忘通用 agent 能力
3. **多阶段训练 pipeline**：
   - SFT: 标准化角色模板 + 用户行为模拟 + 反向 profile 过滤
   - RL: 规则组合 reward 函数消除长度膨胀和重复生成
   - OPD (Two-stage On-Policy Distillation): 使用领域适应模型做 teacher，原始 base 模型做 student，配合 Cumulative-Divergence Decay (CDD)

## 训练 pipeline
```
Base Model
  ↓ SFT (角色模板 + 行为模拟)
Domain-Adapted Model (遗忘通用能力)
  ↓ RL (规则 reward)
Domain-Adapted Model + (消除退化现象)
  ↓ OPD + CDD (self-distillation)
Final KuaiRP Model (兼顾领域知识 + 通用能力)
```

## 实验结果
- 在目标领域角色扮演 fidelity 匹配当前 SOTA 专有模型
- 成功恢复通用 agent 能力
- 极低部署成本

## 局限性
- 需要多阶段训练流程
- OPD 的 CDD 机制需要仔细调参
