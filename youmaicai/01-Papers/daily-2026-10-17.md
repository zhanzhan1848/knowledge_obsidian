## 重点论文（13 篇详细精读）

### 1. **LangDiT: Designing Transformers for Continuous Diffusion Language Models** (2610.22330)
- **核心**：首个**为 CDLM 量身定制**的 Transformer。DiT / Causal LM 架构**直接迁移次优**。
- **四项设计**：feature & Q/K norm + wider noise conditioning + likelihood-shortcut gradient routing + confidence-gated self-conditioning。
- **LangFlow 上 generation perplexity 显著降低**，刷新 CDLM SOTA。
- 详见 [[2026-10-17-2610.22330-designing-transformers-for-continuous-di]]

### 2. **CART: Compatible Routing for Multimodal Continual Instruction Tuning** (2610.22137)
- **核心**：MCIT 场景下 projector 持续更新导致 projector-LLM 失配 → 灾难性遗忘。
- **方案**：projector + LLM **双 expert 协同路由** → weighted mixture + cross-module compatibility。
- **Relevance-guided expert consolidation** 控制模型规模增长。
- **MCIT SOTA**。
- 详见 [[2026-10-17-2610.22137-cart-compatible-routing-for-multimodal]]

### 3. **SAFE-PRO: When Reasoning Is Not Enough** (2610.22068)
- **新风险类别**：intent-level risk — cross-modal ambiguity 让 MLLM **悄悄 commit 到危险前提**，path optimization 救不了。
- **方案**：RCU (entropy + learned cross-modal risk score) 决定**何时主动 clarify** + 在哪 path optimize。
- **奖励**：safety + penalize over-refusal。
- 7 benchmark + 2 MLLM：**超 SRPO**，**over-refusal 减半**，**单轮 safety 平均超 GPT-4o / Claude-3.5-Sonnet**。
- 详见 [[2026-10-17-2610.22068-when-reasoning-is-not-enough-proactive]]

### 4. **DropKV: Decoupling Residual-Output Perturbation** (2610.22130)
- **核心**：KV cache eviction 是 NP-hard 组合问题 → **解耦为 per-token 评分**绕开。
- **provable constant-factor approximation** 理论保证。
- 工程上**易 kernelize**。
- 详见 [[2026-10-17-2610.22130-dropkv-decoupling-residual-output-pertu]]

### 5. **TITAN: Translation Circuit Discovery** (2610.21456)
- **核心**：Hindi↔Urdu / Hindi↔Sindhi 翻译电路定位 + 稀疏优化。
- 三件套：**causal intervention + sparse feature decomposition + targeted preference optimization**。
- **< 5% 参数** → 显著超 baseline。
- 详见 [[2026-10-17-2610.21456-translation-circuit-discovery-and-target]]

### 6. **Private RAG via Random Projection** (2610.22297)
- **核心**：datastore + query embeddings 应用**同一随机投影** → 保留 semantic similarity。
- **理论**：Johnson-Lindenstrauss 风格保证。
- **效用**：多 RAG 架构 + dataset 上**超 formal DP**，接近 non-private。
- 详见 [[2026-10-17-2610.22297-private-retrieval-augmented-generation-v]]

### 7. **MoE Personalization Interpretability** (2610.22127)
- **核心**：MoE LLM 因稀疏路由 → polysemanticity 低 → **天然适合**定位个性化特征。
- **方法**：crosscoder 训练 paired activations → interpretable latents → 识别负责个性化的 experts。
- 详见 [[2026-10-17-2610.22127-explaining-the-roles-of-experts-in-mixtu]]

### 8. **PRM4RL: Progress Reward Model for RL** (2610.22056)
- **核心**：LLM **task planner + reward designer** 协同 → 长程稀疏奖励任务 dense reward。
- 弥补 planning-only 与 reward-only 方法的 gap。
- 详见 [[2026-10-17-2610.22056-progress-reward-model-for-reinforcement]]

### 9. **DialFork: Procedural Hallucination Benchmark** (2610.21561)
- **核心**：**首个** procedural hallucination benchmark — 单看流畅 + 事实合理，但偏离预期流程。
- **36,278 dialogues / 24 tasks / 12 domains**，30 标注员验证。
- 4 类 hallucination：premise violation / skip step / out-of-order / loop。
- 3 个评估粒度：turn / dialogue / process。
- 详见 [[2026-10-17-2610.21561-dialfork-going-beyond-factuality-to-eva]]

### 10. **GraphACM: Graph-based Action Consistency for Agent UQ** (2610.22031)
- **核心**：agent UQ 应在**决策空间（state space）**而非 token space。
- **方法**：多次 rollout → **合并等价状态** → 有向 action-labeled graph → 共享决策状态上比较 actions。
- **Node-level + global measures** → global consistency 预测 task success。
- 详见 [[2026-10-17-2610.22031-graphacm-graph-based-action-consistency]]

### 11. **BitSparse: Lossless Sparse Activation Compression** (2610.22256)
- **核心**：ReLU / ReLU² sparsity 回潮 → 出现**第三种** 显存节省方法：**无损压缩 activation cache**。
- Triton kernel + BF16 / FP8 支持 + 可选 sign-bit packing。
- 与 activation checkpointing **正交**，可叠加。
- 详见 [[2026-10-17-2610.22256-bitsparse-compact-activation-storage-fo]]

### 12. **Prism-1: Position- & Rival-Independent Scoring** (2610.22066)
- **核心**：Web 系统用 LM 做 System One 决策，必须满足**选择公理**。
- 测试标准做法（SCQ + shuffled training + averaging + sorted + invariant）— **全部违反**公理。
- 揭示 LM-as-decision-engine 的根本 bias 问题。
- 详见 [[2026-10-17-2610.22066-prism-1-position-and-rival-independent]]

### 13. **Agentic-Priors: LLM-as-Prior for Preference Cold-Start** (2610.21938)
- **核心**：用 LLM 隐式知识替代历史选择数据 → 生成可解释 trade-off prior → Bayesian update。
- **5-40 pp** cold-start accuracy 提升。
- 7 个 choice dataset 超其他 informed prior。
- 详见 [[2026-10-17-2610.21938-agentic-priors-using-large-language-mod]]

## 简要记录（5 篇）

### 14. **PremiseSQL: Premise Critique in Text-to-SQL** (2610.22158)
- 1,800 flawed NL2SQL queries + 4 类 premise failures + 1,800 原 queries。
- 评测 3 prompting settings 下 premise-aware behavior。
- 揭示**现有 frontier LLMs 在 premise critique 上不足**。

### 15. **Name-Bias in Large Language Models** (2610.22053)
- 6 个本地 LLM，**300,000** responses。
- fill-in-the-blank 任务测量姓名带来的 age / gender / race 偏见。
- 发现一致可测量的 name bias；模型偏好非男性化、年长、popular 的名字。

### 16. **Rating Scale Sensitivity in LLM Text Scoring** (2610.22187)
- 跨 2 formats × 4 ranges × 2 signs × 3 tasks × 2 prompting × 5 LLMs 的扫描。
- 改变单一设计元素 → 归一化分数平均偏移 **0.10**，**~20%** 文本改变类别。
- Toxicity 单极 construct 最敏感；rubric prompting 不降低敏感性。
- 对计算社会科学用 LLM 评分有重要 implications。

### 17. **Multi-sourced AI Tutor for NNES Students** (2610.22163)
- 通用 AI tutor 系统：处理外语文本（聚焦 Mandarin）+ 双语响应。
- 集成 RAG + 术语表生成。

### 18. **Dual-LLM Consensus for Rett Syndrome Treatment** (2610.22062)
- 临床应用：双 LLM consensus pipeline 提取 18 个治疗响应表型（4 AEs + 13 Rett features + refusal）。
- 26,763 notes / 108 patients。
- Frozen pipeline：架构 + prompt 在 diarrhea dev set 选定，冻结后应用到其他 17 表型。
