# NPCBench: A Clinical Apprenticeship Benchmark for Multimodal Care-Pathway Reasoning in Nasopharyngeal Carcinoma

### 核心贡献
1. 提出 NPCBench——面向鼻咽癌（NPC）的「临床学徒（clinical apprenticeship）」基准，把专科训练路径从指南与基础知识、病例规划、纵向复查、CarePath 整合到开放式会诊完整复刻出来。
2. 包含 4,777 道组件题与会诊题，以及一个 100 例患者的 CarePath 队列、417 个带评分的诊断与诊疗任务；采用 episode-level 评测，要求同一诊疗路径下诊断与诊疗答案同时正确。
3. 在 30 个模型上评测后发现「组成性差距（composition gap）」：单项任务强并不保证同一患者的诊断与诊疗答案同时正确；21 个多模态模型中严格 CarePath 成功率最高仅 23%。

### 技术方案
**核心思想**: 用「学徒制 + 连续诊疗轨迹」替代静态问答——把每道分步题挂到患者级 care trajectory 上，让模型必须整合视觉证据、解读病情随时间的变化，并在会诊中满足临床要求。

| 技术 | 说明 |
|------|------|
| 组件与会诊题 | 4,777 component and consultation items |
| 队列规模 | 100-patient CarePath cohort |
| 评分任务 | 417 scored diagnostic and care tasks |
| 评测层级 | episode-level：诊断答案与诊疗答案必须在同一 care pathway 中联合正确（jointly correct） |
| 覆盖层次 | 指南与基础知识 → 病例规划 → 纵向复查 → CarePath 整合 → 开放式会诊 |
| 对照设计 | paired controls 与 physician calibration 进一步检验 evidence grounding、longitudinal revision 与 consultation judging |
| 考察能力 | 是否基于视觉证据做决策、是否解读患者状态变化、是否满足临床要求 |

### 实验结果
- **数据集**: NPCBench 自身（4,777 题 + 100 例 CarePath 队列 / 417 评分任务）
- **基线**: 30 个受评模型（含 21 个多模态模型）；以 physician calibration 作为参照
- **结果**: 观察到 composition gap——单项任务强不能保证同一患者的诊断与诊疗答案同时正确；21 个多模态模型中严格 CarePath 成功率最高仅 23%

### 局限性
- 单一病种（鼻咽癌）、单语言生态（中文临床语境），跨癌种/跨语言泛化未验证
- 队列仅 100 例患者、417 个评分任务，样本量相对有限
- 摘要未给出各模型的逐项得分、模型清单以及 physician calibration 的具体数值
- 会诊类开放式题目的自动评分可靠性（judging）依赖评分流程，摘要未充分说明

### 关键洞见
> 把「诊断正确」与「诊疗正确」拆开评会系统性高估模型：真正的临床能力是二者在同一患者轨迹上同时成立，而 21 个多模态模型的严格 CarePath 成功率封顶只有 23%——单项 SOTA 分数与真实临床胜任力之间存在巨大的「组成性差距」。
