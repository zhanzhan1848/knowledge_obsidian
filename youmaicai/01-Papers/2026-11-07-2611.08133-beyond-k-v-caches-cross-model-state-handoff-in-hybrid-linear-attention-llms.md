# Beyond K/V Caches: Cross-Model State Handoff in Hybrid Linear-Attention LLMs

### 核心贡献
1. 提出 Hybrid State Transfer（HST），首个同时处理 full-attention（FA）K/V cache、线性注意力循环状态（REC）与卷积历史（Conv）三类状态的跨模型状态迁移框架，覆盖混合线性注意力模型的完整状态。
2. 揭示了 Conv 与 REC 交互的关键机制：Conv 扰动会改变循环层中的 keys 和 values，进而改变 REC 更新；虽然 Conv 历史本身会被覆盖，但 REC 的变化仍会持续影响后续输出。
3. 提出「更精确的 REC 重建未必带来更好的续写效果」这一反直觉发现，并据此设计了结构化的 REC 映射表与保持历史顺序的 Conv 对齐机制。

### 技术方案
**核心思想**: 目标模型不重复 prefill 已有上下文，而是直接从源模型继承三类内部状态并续写；关键在于不追求状态的无损重建，而是用目标模型冻结时的输出直接校准适配器。

| 技术 | 说明 |
|------|------|
| HST 三态统一迁移 | 同时迁移 FA K/V cache、REC 循环状态、Conv 卷积历史，覆盖 hybrid linear-attention LLM 的完整推理状态 |
| 结构化 REC 映射表 | 为 REC 更新引入 structured maps，使循环状态可在不同模型之间对齐与迁移 |
| 保序 Conv 对齐 | Conv 历史在目标模型中会被覆盖重写，因此对齐时必须保留历史顺序以维持时间序列语义 |
| 目标输出校准 | 用冻结目标模型在续写（continuation）过程中的输出来校准 adapter，而非依赖代理重建误差 |
| 离线 FA cache 合并 | FA K/V cache map 的更新被放到离线阶段合并，避免在线开销 |

### 实验结果
- **数据集**: 摘要仅提及「五个基准（five benchmarks）」，具体名称摘要未说明
- **基线**: 现有跨模型状态迁移方法（迁移 full-attention K/V cache 的方法）；摘要未给出具体基线名称
- **结果**: Qwen3.5 4B→27B 平均任务保持率 89.88%；9B→27B 平均任务保持率 94.11%；在源 cache 已就绪的前提下，合成 16K 输入上的 handoff body 加速比分别为 21.66× 与 21.91×

### 局限性
- 仅在 Qwen3.5 系列（4B/9B→27B）上验证，跨架构/跨模型族的泛化性摘要未说明
- 依赖源模型 cache 已可用（加速比测速条件），冷启动场景成本摘要未说明
- 目标输出校准需要冻结目标模型在续写时的输出，额外计算开销的量级摘要未说明

### 关键洞见
> 「状态迁移的目标不是让目标模型的状态数值上最接近源模型，而是让目标模型的后续输出最接近它自己在该上下文下本该产生的结果」——精度更高的 REC 重建反而可能因递归误差累积而损害续写质量，说明跨模型状态交接应当以输出行为为校准目标，而非以状态保真度为目标。
