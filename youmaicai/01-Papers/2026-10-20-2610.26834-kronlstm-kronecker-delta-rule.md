## 核心贡献

> 提出 KronLSTM —— 一种基于 Kronecker Delta Rule 的线性注意力架构，是 xLSTM 家族的扩展，专门为长上下文语言建模设计稳定的可联想矩阵记忆。

1. **Kronecker Delta Rule**：一种新的关联矩阵记忆更新规则，纠正目标关联时只沿矩阵空间的单一方向修改记忆
2. **最小侵入式记忆修订**：相比 delta-rule 更新，对已存储信息的干扰显著降低
3. **数学可分析性**：记忆动态可建模为收敛到稳态分布的 Markov chain；期望记忆矩阵范数一致有界
4. **强长上下文表现**：在长上下文 benchmark 上超越 (Gated) DeltaNet 家族等现有线性注意力架构

## 技术方案

### 核心思想

传统 delta-rule 更新会大范围修改记忆矩阵，导致先前存储信息被覆盖。Kronecker Delta Rule 限制修订仅沿一个方向进行，从而保留已有知识；同时记忆动态具有稳态收敛性，不需要额外 normalization 或 stabilization。

### 关键技术

| 技术 | 说明 |
|------|------|
| Kronecker Delta Rule | 矩阵记忆更新规则，仅沿单方向修改记忆 |
| Matrix Memory Revision | 联想式关联存储与检索 |
| Markov Chain Convergence | 记忆动态可证明收敛到稳态分布 |
| Bounded Memory Norm | 无需 normalization 即可保持稳定 |

### 关键公式

Kronecker Delta Rule 的核心更新：

```math
\mathbf{M}_{t+1} = \mathbf{M}_t + \Delta \mathbf{m}_t \mathbf{u}_t^\top
```

其中 $\Delta \mathbf{m}_t$ 为单方向增量，$\mathbf{u}_t$ 为 key，对已存储信息干扰最小化。

期望范数有界：

```math
\mathbb{E}[\|\mathbf{M}_t\|] \leq C, \quad \forall t
```

## 实验结论

### 任务范围

- 语言建模 + 长上下文 benchmark

### 主要对比

- **(Gated) DeltaNet 家族**：作为主要 linear attention baseline
- KronLSTM **competitive with, and often outperforms** 现有架构
- 在长上下文 benchmark 上**特别强**

### 开源资源

- Code: github.com/NX-AI/KronLSTM
- Models: HuggingFace NX-AI/kronlstm collection

---

## 局限性

- 当前发布的模型规模有限，扩展到超大规模 LLM 训练成本与稳定性待验证
- Kronecker Delta Rule 在非语言任务（视觉、多模态）的适用性待研究
- 与全注意力 Transformer 的推理延迟对比需进一步系统评估
