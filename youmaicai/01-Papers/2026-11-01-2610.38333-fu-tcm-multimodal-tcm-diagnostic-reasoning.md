# Fu-TCM: a multimodal large language model that learns traditional Chinese medicine diagnostic reasoning

## 摘要
中医（TCM）以"四诊"（望、闻、问、切）证据判断病位病性、辨证并指导治疗，这一诊断过程本身构成完整的推理链，但现有 TCM LLM 多停留在问答对映射，难以保证模型遵循了中医推理过程。作者提出 **Fu-TCM**：一个多模态中医 LLM，训练数据来自古籍、教材、医书插图、临床病例与公开数据集，初始采集约 **712 万**条样例，經清洗过滤后保留，并进一步用 **Bianzheng-Grounded Policy Optimization (BGPO)** 优化——该方法用响应格式、中间 TCM 推理字段与最终证候预测三类可验证奖励直接针对辨证过程。Fu-TCM-27B 在覆盖 TCM 推理、文本与视觉的六个基准上全部领先，**macro-average accuracy 达 81.01%**，比"六个基准都有完整结果的最强参照模型"高 **7.13 个百分点**，其中最大差距出现在 Fu-bianzheng（**11.90 点**）。病例级分析显示，中间字段准确率与最终证候选择准确率在多数受评模型中正相关。作者结论：中医辨证可能是"可计算可学习"的，结构化推理监督能跨任务提升性能。

## 核心贡献
1. **Fu-TCM 模型**：基于 Qwen3.5-9B 与 Qwen3.6-27B 的全参数 SFT + BGPO 两阶段多模态 TCM 模型，架构为 hybrid decoder（3 Gated DeltaNet + 1 Gated Attention × 16 cycles = 64 层，vocab 248,320，context 262,144，带 MTP head）。
2. **BGPO 奖励设计**：把辨证（bianzheng）中间字段纳入 RL 奖励，而非只用最终证候结果；三个可验证奖励 R_fmt / R_syn / R_bz，权重 0.20 / 0.40 / 0.40。
3. **树状证候相似度奖励**：基于 3,793 节点、深度 ≤ 7 的证候模式树，用 LCA 距离构造 graded credit，使"部分正确"的证候也能获得梯度。
4. **三个自建基准**：Fu-bianzheng（311 例真实临床病例）、Fu-text（1,000 题，8 个知识类别）、Fu-vision（500 题，5 个诊断类别）；并与三个公开基准（Ladder text 9,685 题、Shizhen exam 1,088 题、Shizhen vision 7,204 题）合评。
5. **中间过程与最终结果关联的实证**：模型级 Pearson r = 0.89，四个领域模型内 r = 0.996，病例级 logistic 回归 OR = 1.88（Fu-TCM-27B）。

## 方法与架构
### 1. 数据构建
- 数据源规模（图 1a）：古籍 **704**、教材 **16**、图谱类医书 **2,496**、临床病例经"convert & check"转换；经"clean, parse & validate → mapping tables → clinician review → merge, dedup & split"四步后得到 **5.43M** 文本记录与 **1.35M** 图像，语料为 **83k** 文本语料 + **65k** 视觉语料。
- 训练数据：Text QA **1.53M**、Image-text VQA **8,331**、Case reasoning **1,867**（后者专供 BGPO；另 311 例独立作为 Fu-bianzheng，不参与 BGPO）。测试数据：文本基准 **11,773**、视觉基准 **7,704**、辨证基准 **311**。
- 用 DataFlow 从三类书籍生成 QA 对：文本对只有在答案可由原文支撑时保留；图文对只有在图像与图注正确对齐时保留；临床病例通过"症状→辨证字段"的**医师审核映射表**转为结构化记录。公开基准（Ladder text、Shizhen exam、Shizhen vision）只用于评测，未进入训练，且确认处理后的公开数据不含这些基准的题目。
- 病例结构化表示：输入 $x_i=(e_i^{ins}, e_i^{aus/olf}, e_i^{inq}, e_i^{palp})$，目标 $z_i=(c_i, o_i)$，最终证候集合 $y_i\subseteq S$。$c_i=(c_i^{EI},c_i^{CH},c_i^{DE},c_i^{YY})$ 编码表里寒热、虚实、阴阳（表里项允许表/里/半表半里/表里同病/未定，其余三项允许两极/混合/未定）；$o_i\in\{0,1,2,3\}^{26}$ 编码 **26 个序数字段**（5 个脏腑维度、15 个气血津液维度、6 个六淫维度）。证候命名遵循国家标准 **GB/T 15657-2021**。
- 评测用 **30 个中间辨证字段** = 4 个八纲字段 + 5 个脏腑字段 + 15 个气血津液字段 + 6 个六淫字段。

### 2. 架构
Hybrid decoder：**3 Gated DeltaNet + 1 Gated Attention** 为一个 cycle，重复 **16 次 = 64 层**；vocab **248,320**，context **262,144**；含 vision encoder（image patchify → patch merger → vision tokens）、token embedding、LM head 与 **MTP head**。基座为 Qwen3.5-9B 与 Qwen3.6-27B，全参数微调。

### 3. 阶段一：TCM domain-specific learning（SFT）
目标 token 平均的交叉熵：

```math
\mathcal{L}_{\text{SFT}}(\theta) = -\frac{1}{M}\sum_{n,t} m_{nt}\log \pi_\theta(q_{nt}\mid x_n, q_{n,<t})
```

$m_{nt}=1$ 仅对目标响应 token，prompt、padding 与非目标视觉占位 token 均为 0。

### 4. 阶段二：BGPO
每个 case 采样 **G = 16** 条回复，参考证候与中间字段**保留在 prompt 之外**作为 reward metadata。组相对优势：

```math
A_{ij} = \frac{R_{ij}-\bar{R}_i}{\sigma(R_i)+\delta},\qquad \bar{R}_i=\frac{G-1}{G}\sum_{j=1}^{G}R_{ij}
```

$$\rho_{ijt}(\theta)=\frac{\pi_\theta(q_{ijt}|x_i,q_{ij,<t})}{\pi_{\theta_{old}}(q_{ijt}|x_i,q_{ij,<t})}$$

```math
\mathcal{L}_{\text{BGPO}} = -\mathbb{E}\left[\frac{1}{GT}\sum_{j,t}\min\left(\rho_{ijt}A_{ij},\ \mathrm{clip}(\rho_{ijt},1-\epsilon_c,1+\epsilon_c)A_{ij}\right)+\beta D_{KL}(\pi_\theta\|\pi_{ref})\right]
```

其中 $\delta=10^{-6}$（组内标准化数值稳定项）、$\epsilon_c=0.2$（PPO clip 半径）、$\beta=0.001$。不使用 learned reward 或 value model。回复须使用显式 trace tags 与终端证候 JSON list。

### 5. 奖励函数
总奖励：

```math
R = 0.20 R_{fmt} + 0.40 R_{syn} + 0.40 R_{bz}
```

- **R_fmt**：奖励规定的 section 顺序、字段完整、终端证候 JSON 与有限重复（章节顺序为 Four diagnostic methods → Eight principles → Zang-fu → Qi, blood and body fluids → Six excesses → `</think>` → JSON syndrome list）。
- **R_syn（树状证候奖励）**：完全集合匹配为 1；否则用标准化证候分类体系给 graded credit。基于 LCA 的相似度：

```math
s(a,b) = \frac{2\,d(\mathrm{LCA}(a,b))}{d(a)+d(b)},\qquad
P_s=\frac{1}{|\hat y|}\sum_{a\in\hat y}\max_{b\in y} s(a,b),\quad
Q_s=\frac{1}{|y|}\sum_{b\in y}\max_{a\in\hat y} s(a,b)
```

```math
R_{syn}=\frac{2P_sQ_s}{P_s+Q_s}
```

证候树共 **3,793** 个节点、深度 ≤ 7；同节点相似度 1.0，近邻兄弟在 (0,1)，跨类别为 0。
- **R_bz（30 字段保真度奖励）**：4 个八纲分类字段用精确匹配，26 个序数字段（0–3）用强度加权误差：

```math
B=\frac{1}{4}\sum_{r=1}^{4}\mathbb{1}(\hat c_r=c_r),\qquad
E_w=\frac{\sum_{k=1}^{26}(1+o_k)|\hat o_k-o_k|}{\sum_{k=1}^{26}(1+o_k)}
```

```math
H=\begin{cases}
\frac{\sum_k o_k\mathbb{1}(\hat o_k>0)}{\sum_k o_k}, & \sum_k o_k>0\\
1, & \sum_k o_k=0
\end{cases},\qquad
N=0.70\left(1-\frac{E_w}{\tau}\right)+0.30H,\quad \tau=1.5
```

```math
C_c=\frac{1}{4}\sum_{r=1}^{4}\mathbb{1}(\hat c_r\ \text{parsed}),\quad
C_o=\frac{1}{26}\sum_{k=1}^{26}\mathbb{1}(\hat o_k\ \text{parsed}),\qquad
R_{bz}=(0.30B+0.70N)\times(0.30C_c+0.70C_o)
```

$\tau=1.5$ 是 0–3 序数尺度上最大字段差异的一半；加权误差达到或超过阈值则不获得误差项信用。强度加权误差与非零召回项的设计目的是防止模型"无差别预测零"；当参考不含任何非零序数字段时 $H=1$（无正例可召回），但预测出多余非零字段仍通过 $E_w$ 惩罚。

### 6. 统计方法
Wilson 区间（二项最终证候准确率）；**4,000 次** case-level bootstrap（中间准确率、正确/错误最终答案的差异）；跨六个基准用 **20,000 次**配对 item-level 重采样比较 Fu-TCM-27B 与最强非 Fu-TCM 模型；Pearson 相关（10 模型全体、8 个参照模型、4 个领域模型子集）；每个模型单独做病例级 logistic 回归：

```math
\mathrm{logit}\Pr(Y_i=1)=\alpha+\gamma A^{int}_i,\qquad OR_{0.1}=\exp(0.1\gamma)
```

## 实验设置
- **模型**：Fu-TCM-9B（Qwen3.5-9B 基座）、Fu-TCM-27B（Qwen3.6-27B 基座）。
- **参照模型（11 个）**：Qwen3.5-9B、Qwen3.5-27B、Qwen3.6-27B、DeepSeek-V4-Pro、Kimi-K2.6、Qwen3.7-Max、GLM-5.2、GPT-5.5、Claude-Opus-4.8、HuatuoGPT-3-27B、ShizhenGPT-32B-VL。
- **基准（6 个）**：Fu-bianzheng（311 例）、Fu-text（1,000 题 / 8 类）、Fu-vision（500 题 / 5 类）、Ladder text（9,685 题）、Shizhen exam（1,088 题）、Shizhen vision（7,204 题）。macro-average 只纳入六个基准均有完整结果的模型。
- **判分规则**：单选——所选选项与参考答案一致即正确；多选——需与完整参考答案集合精确匹配。
- **外部验证**：同题平行组设计，参与者为 TCM 医师（主治医师、住院医师、主治/主任）与学生，20 例辨证病例 + 60 道多选题；对比"仅模型作答""独立作答学生""模型辅助学生"三组。
- **伦理**：福建中医药大学附属人民医院伦理委员会批准（SQ2025-161-01），获取知情同意。

## 实验结果
**总体（六个基准 macro-average）**
| 模型 | macro-average (%) |
|---|---|
| **Fu-TCM-27B** | **81.01** |
| Qwen3.7-Max（最强完整结果参照） | 73.88 |
| Fu-TCM 基座 Qwen3.6-27B | 68.76 |
| HuatuoGPT-3-27B | 63.74 |
| ShizhenGPT-32B-VL | 63.40 |

Fu-TCM-27B 相对 Qwen3.7-Max 高 **7.13 pp**；相对自身基座 Qwen3.6-27B 从 68.76% 提升到 81.01%，六个单基准上的提升幅度为 **10.50–14.16 pp**。各基准相对最强非 Fu-TCM 模型的差距：Fu-bianzheng **+11.90**、Shizhen vision **+8.98**、Ladder text **+5.95**、Fu-text **+3.00**、Shizhen exam **+2.48**。

**Fu-bianzheng（311 例）**
| 模型 | 最终证候选择准确率 | 30 字段严格匹配准确率 |
|---|---|---|
| Fu-TCM-27B | **73.63%**（229/311） | **85.05%**（84.20–85.85） |
| Fu-TCM-9B | 70.42%（219/311） | 83.61%（82.81–84.39） |
| Qwen3.7-Max（最强参照） | 61.74%（192/311） | — |
| GLM-5.2（该指标最强参照） | — | 75.08%（73.74–76.33） |

Fu-TCM-27B 对 Qwen3.7-Max 的最终证候差距为 11.90 pp（配对 bootstrap 95% CI 6.75–17.04）；对 GLM-5.2 的中间字段差距为 **+9.97 pp**（Fu-TCM-9B 为 +8.53 pp）。

**证候类别难度（15 个高频证候）**：下焦湿热最易（平均 90.0%，模型区间 62.5%–100.0%）；肝气郁结夹湿热 81.5%、肝脾湿热 79.4%；**肝阴虚最难（平均 27.8%，区间 16.7%–50.0%）**、痰湿阻遏 38.8%（28.0%–52.0%）。Fu-TCM-27B 在 15 类中的 7 类取得最佳或并列最佳，最大类别差距为肝阴虚 16.7 pp、痰热蕴结 14.3 pp、肝气郁结兼脾虚 11.6 pp；在最难的肝阴虚上 Fu-TCM-27B 达 50.0%（最强参照 33.3%）。

**中间字段与最终结果的关联**
- 全部 10 个模型上，中间字段平均准确率与最终证候准确率 Pearson **r = 0.89**（P = 0.0006, n=10）；但 8 个参照模型内部无显著关联（**r = −0.04, P = 0.93**）；4 个领域模型（Fu-TCM-27B/9B、HuatuoGPT-3-27B、ShizhenGPT-32B-VL）内部 **r = 0.996（P = 0.0041, n=4）**。
- 病例级 logistic 回归：10 个模型全部为正关联，9 个达到未校正 P < 0.05；Fu-TCM-27B 与 Fu-TCM-9B 每 10 个百分点中间准确率提升的 OR 分别为 **1.88（1.35–2.63）** 与 **1.52（1.08–2.14）**。
- 最终答对与答错的病例之间，中间字段平均准确率相差 **2.0–7.3 pp**，10 个模型中 9 个的 bootstrap 95% CI 不含 0。
- 字段层面：暑湿、气陷、气闭、表里、血寒、气陷、津液停聚等 10 模型最低准确率均 ≥ 90.0%（均值 94.7%–99.3%）；气滞、痰、肾、湿最难（均值 47.3%–58.0%，无一模型超过 70.4%）。Fu-TCM-27B 在肝、脾、内湿三字段领先最强参照 **22.8 / 18.6 / 19.9 pp**。

**消融（同一 311 例 Fu-bianzheng）**
| 训练目标 | 中间字段非零准确率 | 最终证候选择准确率 |
|---|---|---|
| Domain learning | 68.36% | 68.17% |
| Outcome-only GRPO | 66.70% | 70.10% |
| **Full BGPO** | **76.64%** | **73.63%** |

outcome-only GRPO 提升了最终证候选择却不改善中间字段准确率，full BGPO 同时改善两者，支持"中间辨证奖励具有独立贡献"。

**外部验证（TCM 医师/学生）**：模型辅助学生 3 的中间字段准确率 **78.5%**、多选准确率 **56.7%**，在两项指标上均超过三位参与医师；相对最佳医师高 **8.3** 与 **6.7 pp**，相对最佳独立学生高 **17.0** 与 **11.7 pp**。

**分类级表现**：文本任务中 actions/indications、internal medicine、diagnostics 类表现较好；Fu-TCM-27B 在 8 个 Fu-text 类别中的 5 个排名第一，并在"source and identification"领先 **5.0 pp**、"composition"领先 **6.4 pp**；视觉任务中 TCM Material 一致性最好，TCM Patent/Pulse/Tongue/Eye 更低或波动更大，Fu-TCM-27B 在 5 个 Fu-vision 类别中的 3 个领先，在 8 个 Shizhen vision 类别中的 6 个排名第一。

## 局限性
作者自述：
- 训练用的结构化辨证数据主要来自中医**男科与心血管**，病种谱、证型与临床表现受限；向妇科、儿科、脾胃病等专科的泛化性未验证。
- 推理数据集规模相对较小，未充分覆盖复杂证候、兼证、长尾病例与医师间差异，可能限制复杂临床场景下的稳定性。
- 评测主要依赖固定的辨证字段与多项选择题，无法完整代表开放式问诊、病情随时间变化或临床中四诊的综合判断。
- 部分外部验证参与者数量很少（医师 3 人、学生若干），个案性质的结论需谨慎推广。

我的补充批评：(1) 三个自建基准（Fu-bianzheng/Fu-text/Fu-vision）与训练数据来自同一采集流水线，Fu-bianzheng 的 311 例虽排除在 BGPO 之外，但同源数据的风格泄漏风险未被完全排除；(2) BGPO 的关键消融只做了 "domain learning / outcome-only GRPO / full BGPO" 三档，未拆分 R_fmt、R_syn、R_bz 三项奖励各自的贡献，也未做组大小 G 或 KL 系数 β 的敏感性分析；(3) 中间字段准确率与最终结果的强相关可能部分源于两者共同依赖同一份标注（人工映射表），因此"中间推理被模型使用"的因果解释仍需更强证据（如干预式实验）。

## 评估与建议
- 是否推荐深入阅读：是（作为"把领域专家的推理结构做成可验证 RL 奖励"的完整案例，尤其树状标签相似度奖励与中间字段奖励的设计值得复用）
- 适用场景：医疗/法律/工程等有明确中间推理字段的垂直领域；设计可验证的过程奖励与部分正确的 graded credit；构建多模态专业模型（舌诊、面诊、脉诊等）；人机协同决策支持的外部验证设计。
- 与知识库的关联：与 GRPO/PPO 变体及其奖励设计笔记互补；与"结构化 CoT 监督"类笔记（如 H²R 的中间监督、2610.39934）以及机制可解释性笔记（2610.39182 关于中间状态是否真被使用）形成对照；医学 LLM 评测与安全治理主题相关。
