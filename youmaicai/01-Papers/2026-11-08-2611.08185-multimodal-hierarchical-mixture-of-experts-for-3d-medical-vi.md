# Multimodal Hierarchical Mixture-of-Experts for 3D Medical Vision-Language Modeling

> **arXiv**: [2611.08185](https://arxiv.org/abs/2611.08185)
> **发表日期**: 2026-11-05
> **分类**: cs.CV
> **会议/期刊**: WACV 2027 (Copyright 2027 IEEE; personal use permitted)

## 📋 摘要

医学 3D 扫描与报告本质上是**层级化**的，诊断线索集中在多个组织层级上的特定解剖区域。然而大多数医学视觉语言模型忽略了这种结构，无法聚焦于临床相关的解剖部位。本文提出 **MedHiVE**，将**层级化的视觉-语言 Soft Mixture-of-Experts (SMoE)** 与对比学习相结合，联合建模细粒度解剖结构与全局扫描上下文。据作者所知，MedHiVE 是首个让**视觉 token 与文本 token 同时**经过一个**按解剖尺度组织的两级 SMoE 层级**路由的框架，并将其与报告驱动的解剖层级对比对齐结合用于 3D 医学影像；这取代了既有工作中"静态池化特征的直接 region-text 对齐"与"仅视觉的层级路由"，实现跨解剖尺度的动态、基于 slot 的跨模态信息流动。MedHiVE 通过两级可学习的 token 路由机制运作：局部的图像与文本特征先经 local SMoE 路由，再由 global SMoE 融合为统一的多模态表征；对比学习则在统一空间中同时对齐解剖层级与全局的视觉-语言表征。模型在带有解剖监督的 **25,000+ CT 扫描**上预训练，在 **6 个数据集**的 **3 项任务**（分割、分类、检测）上**持续超越 11 个 state-of-the-art 方法**。代码见 github.com/szczurek-lab/MedHiVE。

## 🎯 核心贡献

1. 提出 **MedHiVE**：首个让**视觉与文本 token 同时**经由**按解剖尺度组织的两级 SMoE 层级**路由的医学视觉语言框架（此前仅有视觉侧的层级路由）。
2. 用**基于 slot 的动态跨模态信息流**取代静态池化特征的直接 region-text 对齐，解决"诊断线索集中在特定解剖区域"的建模难题。
3. 引入**报告驱动的解剖层级对比对齐**，在统一空间中同时对齐解剖层级表征与全局视觉-语言表征。
4. 在 **25,000+ 带解剖监督的 CT 扫描**上预训练，取得强迁移能力。
5. 全面验证：6 数据集 × 3 任务（分割、分类、检测）上**持续超过 11 个 SOTA 方法**；代码已开源。

## 🔧 方法/架构

两级 Soft Mixture-of-Experts 的可学习 token 路由：

- **Local SMoE**：局部图像特征与文本特征在**解剖尺度（anatomical scale）**层面分别路由到不同专家：

```math
\mathbf{h}^{local} = \sum_{k \in \mathcal{K}} G_k(\mathbf{h}^{\text{img}},\ \mathbf{h}^{\text{txt}})\cdot E_k(\mathbf{h}^{\text{img}},\ \mathbf{h}^{\text{txt}})
```

  专家集合 $\mathcal{K}$ 对应不同解剖尺度/层级，门控 $G_k$ 可学习且逐样本动态。
- **Global SMoE**：局部结果再经 global SMoE 跨尺度融合为统一多模态表征：

```math
\mathbf{h}^{multi} = \sum_{j \in \mathcal{J}} \bar{G}_j(\mathbf{h}^{local})\cdot E^{\text{global}}_j(\mathbf{h}^{local})
```

- **对比学习（两级）**：解剖层级对齐 + 全局对齐：

```math
\mathcal{L} = \mathcal{L}_{\text{anatomy-align}} + \mathcal{L}_{\text{global-align}}
```

  其中 $\mathcal{L}_{\text{anatomy-align}}$ 由报告（report）中的解剖学指称驱动，把特定解剖区域的 3D 视觉特征与其报告文本在统一空间中对齐。
- **预训练语料**：25,000+ CT 扫描，附带解剖结构监督（可作 slot/专家划分的依据）。
- **下游任务**：分割、分类、检测（3D 医学影像标准任务族）。

## 📊 实验结果

- **6 个数据集 × 3 项任务**（分割 / 分类 / 检测）：MedHiVE **持续优于 11 个 state-of-the-art 方法**。
- **预训练规模**：25,000+ CT 扫描（带解剖监督）。
- 摘要未披露具体指标数值（如 Dice / mIoU / AUC 等，详见原文实验章节）；涉及基准为 6 个公开 3D 医学影像数据集。

## ⚠️ 局限性

- 摘要未给出任何具体指标数值，"超越 11 个 SOTA"缺少幅度信息。
- 仅在 **CT** 影像上预训练，扩展到 MRI / 超声 / 病理等模态的可行性未验证。
- 两级 SMoE + 对比对齐的训练与推理开销、显存需求未披露；医学影像多序列体数据本身已很吃资源。
- 预训练依赖 **25,000+ 带解剖监督的 CT 扫描**，这类解剖标注获取成本高，数据可复现性受限。
- 报告驱动对齐继承了放射科报告中标注不完整/不准确的噪声。

## 💡 建议

- 是否推荐使用：是（3D 医学多模态方向值得优先阅读，方法可直接复用到非医学层级视觉数据）
- 适用场景：3D CT 报告-影像检索与生成；病灶定位与分割；放射诊断模型的解剖感知的预训练；把层级 MoE 引入视觉语言模型的设计参考。
