## 核心贡献

> 提出 transferable 多 agent LLM 框架（analyst + coder + recorder），在"语义窄、开集"空间中自动调优专家网络关键组件，不改 overall architecture。

1. **三角色分工**: analyst（分析）/ coder（写代码）/ recorder（记录）
2. **沙箱执行 + 实验日志**: 安全试错、跨任务迁移
3. **语义窄开集**: 只生成指定组件代码，保留整体网络结构

---

## 技术方案

### 核心思想

许多 ML 方法是 two-level 的：专家选方法类 → 类内关键组件靠手动。本框架在"类内组件"层自动调优，跨模型类型可迁移。区别于 AutoML 整体脚本优化或离散 NAS。

### 关键技术

| 技术 | 说明 |
|------|------|
| Analyst agent | 分析当前性能、提出改进方向 |
| Coder agent | 生成组件代码 |
| Recorder agent | 维护实验日志、跨 run 知识积累 |
| Sandboxed execution | 安全执行未经验证的 LLM 代码 |
| Narrow semantic space | 只动指定组件，不动整体架构 |

### 验证任务

- **SNN classification** (correlation learning) on MNIST / Digits
- **PINN** for GNLSE / Kuramoto-Sivashinsky equations

---

## 实验结论

- **任务**: 5 个（spiking classification 2 + 边界值 PDE 3）
- **结果**:
  - 5/5 task 上**优于 baseline**
  - 框架 transferable 跨 SNN / PINN 两种截然不同的网络类

---

## 局限性

- 仅在 SNN + PINN 验证；transformer / diffusion 等主流架构未测
- Sandbox 执行 cost 较高
- "组件"语义边界需人工事先定义

---

## 实现建议

- **实现难度**: 中-高（需要 sandbox + experiment log + 三 agent orchestration）
- **预期性能**: 在专用网络类上超 baseline；通用性待验证
- **适用场景**: 垂直网络（SNN/PINN/ODE-Net）调优；专家系统自动化
