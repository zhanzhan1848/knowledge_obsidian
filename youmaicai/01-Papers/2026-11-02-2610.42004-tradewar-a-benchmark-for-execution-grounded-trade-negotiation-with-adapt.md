# TradeWar：执行落地的贸易谈判基准与自适应 LLM Agent

| **摘要** | Multi-turn negotiation remains a challenging problem for large language model (LLM) agents. While LLMs can conduct natural-language dialogue, existing benchmarks predominantly assess only agreement rates, overlooking whether negotiated commitments actually create value once executed. To address this gap, we introduce TradeWar, a multi-country simulation benchmark that translates negotiation dialogues into concrete tariff and trade-share policies, enforces capacity and network constraints during settlement, and evaluates outcomes via an Economic Health Index (EHI). To solve this execution-grounded task, we propose TACTIC (Trade-aware Adaptive Consolidation and Theory-of-mind for International Commerce), an agent that iteratively refines its negotiation strategy across episodes-without updating base LLM weights-by leveraging prior experience, opponent behavior, and past settlement outcomes. Despite using zero-shot chain-of-thought (CoT) prompting, PromptLLM attains a 75% agreement rate but only 57.1 final EHI (*100), whereas TACTIC reaches 68.8. Across 20 sequential episodes and three seeds, TACTIC's final EHI improves from 58.2 to 73.2, compared with 65.2 for an ablation without cross-episode updates. Under technology-controls and energy-crisis shocks, TACTIC also exhibits smaller performance degradation than PromptLLM and MemoryLLM. These results indicate that CoT deliberation and interaction memory alone do not fully address delayed execution feedback, whereas settlement-grounded adaptation improves long-horizon negotiation in TradeWar. |

## 核心贡献

1. 提出 **TradeWar**：多国模拟基准，把谈判对话翻译成**具体的关税与贸易份额政策**，在结算阶段**强制施加产能与网络约束**，并用**经济健康指数（EHI）**评估结果。
2. 现有基准只看**达成率（agreement rate）** —— TradeWar 追问的是"谈成的承诺**真正执行后**是否创造了价值"。
3. 提出 **TACTIC**（Trade-aware Adaptive Consolidation and Theory-of-mind for International Commerce）：跨 episode **迭代精炼策略**（不更新基座 LLM 权重），利用先前经验、对手行为与过往结算结果。
4. **核心数字**：PromptLLM 用零样本 CoT 拿到 **75% 达成率但只有 57.1 的最终 EHI** —— **高达成率与高价值完全脱钩**。TACTIC 达成率更低（68.8）但 EHI 更高。
5. 20 个连续 episode × 3 seed：TACTIC 最终 EHI 从 **58.2 → 73.2**，而**无跨 episode 更新的消融版停在 65.2**。
6. 在**技术管制**与**能源危机**冲击下，TACTIC 退化幅度小于 PromptLLM 与 MemoryLLM。

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| 技术 | 说明 |
|------|------|
| 多国贸易模拟 | 谈判对话 → 关税/贸易份额政策 |
| 产能与网络约束 | 结算阶段的可行性强制 |
| EHI 指标 | Economic Health Index，经济健康指数 |
| TACTIC | 跨 episode 策略精炼 + 对手建模（ToM） |
| 零权重更新 | 通过经验记忆而非参数更新适应 |
| 冲击测试 | 技术管制 / 能源危机场景 |

### 关键发现

- **最重要的结论是"达成率是坏指标"**：75% 达成率对应更低的 EHI。这与 [[daily-2026-11-01]] 那批"评测工具不可靠"的主线直接呼应 —— **指标选错会让优化方向系统性偏离**。
- **延迟反馈是核心难点**：谈判的真正结果只在结算后才显现，而 CoT 深思与交互记忆**都不足以应对延迟反馈**，只有**结算锚定的适应**有效。
- 这与 [[2026-11-02-2610.41604-real-computation-or-merely-naming-a-pre-registered-mechanism-audit-of-25]] 的"名称≠机制"是同一类错误的两个面：这里错的是**指标**，那里错的是**模块**。
- "跨 episode 58.2→73.2 vs 消融 65.2"的差距说明：**经验必须绑定到结算结果**，绑到"对话内容"上没用。

## 实验结果

| 配置 | 达成率 | 最终 EHI (×100) |
|------|------|------|
| PromptLLM（零样本 CoT） | **75.0%** | 57.1 |
| TACTIC | 68.8% | **73.2**（20 episode 后） |
| TACTIC 无跨 episode 更新（消融） | — | 65.2 |
| 冲击（技术管制/能源危机） | — | TACTIC 退化幅度最小 |

## 局限性

- 模拟经济，EHI 与真实贸易结果的相关性未验证
- TACTIC 达成率低于 PromptLLM，方法并非在所有指标上占优
- 场景限于多国关税/贸易份额，谈判结构相对受限
