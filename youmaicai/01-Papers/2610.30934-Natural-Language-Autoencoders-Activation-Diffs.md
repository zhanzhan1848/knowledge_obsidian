## 核心贡献

> 系统评估 **natural language autoencoders (NLA)** 的**泛化性**，围绕四个紧密相关的问题，全部得到**largely positive** 的答案。

1. **四个问题**：
   - (i) NLA 的 verbalization 对其输入是否具有**组合性结构**？
   - (ii) NLA 能否泛化到**它所训练模型的微调版本**？
   - (iii) NLA 能否在 **model diffing** 中**恢复微调目标**？
   - (iv) NLA 能否被**专门化**用于 model diffing？
2. **关键发现**（跨 **3 个模型族、4 个模型**）：
   - **组合类比**：composed analogy 的 activation verbalization **大多能说出目标词，很少提及被减去的词**；
   - **跨微调泛化**：NLA 可**直接复用于**其原模型的**轻量微调版本**，无需重训；重构质量**仅在最大模型上明显下降**；
   - **Model diffing**：对 **Taboo model organisms** 与其原模型的激活差异做 verbalization → **大多数 organism 恢复了被隐藏的秘密词**；在激活差异上做**强化学习**还能在 **held-out organism** 上进一步提升恢复率；
   - **无需生成 token**：NLA 能恢复微调目标，**即使被微调的模型从未生成任何 token** —— 因为**信息量最大的 token 位置出现在 user prompt 之前**；
   - **局限**：在 **emergent misalignment detection** 任务上，NLA **尚未达到 SOTA model diffing 方法**，但**优于 blackbox baseline**。

## 技术方案

| 组件 | 说明 |
|------|------|
| NLA | 通过自然语言 bottleneck 重构激活 |
| 组合性 probe | composed analogy verbalization |
| 跨微调复用 | 不重训，直接应用到 finetune 版本 |
| Model diffing | 原模型 vs 微调模型的激活差异 → 差异文本 |
| RL on differences | 在激活差异上 RL → 提升 held-out 恢复 |
| Pre-prompt 位置 | 利用 prompt 之前的 token 位置 |

### 关键洞见

- "**即使被微调模型不生成任何 token，NLA 也能恢复微调目标**" 是本文最惊艳的一点 —— 微调痕迹存在于**输入侧的内部状态**中，而非仅输出。
- Taboo organism 实验把 interpretability 变成了**可量化的"秘密恢复"任务**，比"看看 verbalization 说了什么"客观得多。
- 与 [[2610.30884]]（subliminal learning tracing）呼应：激活差异是检测"隐性偏好传递"的天然工具。

---

## 实验结论

- **规模**：3 个模型族、4 个模型
- **结果**：
  - 类比 verbalization 大多命名目标；
  - 轻量微调复用无需重训（最大模型除外）；
  - Taboo organism **大多恢复秘密词**；
  - 激活差异上 RL → held-out 恢复进一步提升；
  - **无需模型生成 token**；
  - emergent misalignment detection：优于 blackbox，未及 SOTA。

---

## 局限性

- 需 **white-box activation 访问**；
- 组合性仅在类比任务验证；
- 最大模型上重构质量**明显下降**；
- emergent misalignment detection 落后 SOTA 方法；
- "恢复秘密词"是否为**真正理解**还是**模式匹配**，需谨慎解读。
