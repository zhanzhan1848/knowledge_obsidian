## 核心贡献

> CoSTA 用时间线 + worker/coordinator 双角色协同进化，把时序证据分到独立上下文以消除干扰。

1. 提出 CoSTA（Co-Evolving Self-Play Timeline Agents）：把事实组织成可导航时间线，把调查任务分派给 worker，用 coordinator 综合 worker 的**原始带时间戳观察**。
2. 通过角色条件蒸馏初始化共享策略，再用带最终答案奖励的协同进化自博弈**同时优化两个角色** —— 因为问题分解、子任务调查与证据综合是相互依赖的。
3. 在三个基准上取得 SOTA 总体表现，在复杂多事实问题上增益尤其显著。

## 技术方案

### 核心思想

复杂时间知识图谱问答（TKGQA）的难点不在于检索事实本身，而在于**时间约束的链式依赖**：一条事实的时间戳或有效期区间会约束另一条事实的检索，而多个区间可能共同决定答案。

现有单 agent 方法把这些事实都塞进**同一个推理上下文**，导致两个问题：不同事件历史的证据互相交织，且**干扰项会误导后续检索** —— 一个错误的检索结果会污染推理链的其余部分。

分布式调查的直觉是：把不同事件的调查分配给不同 agent，可以让每个事件相关的证据处于独立上下文中，互不干扰。但论文强调这样做还不够 —— **有效的协作必须被学习**，因为问题分解、子任务调查与证据综合三者相互依赖，不能手工编排。

CoSTA 的设计正是围绕这个依赖关系：
- **时间线组织**：事实被组织成可导航的时间线，而非扁平图
- **worker 角色**：负责调查具体子任务，产出带时间戳的原始观察
- **coordinator 角色**：综合这些原始观察，产出最终答案
- **角色条件蒸馏**初始化共享策略，让两个角色从同一基座快速分化
- **协同进化自博弈**：用最终答案奖励同时优化两个角色 —— 因为一方的进步会改变另一方的最优策略，固定分工训练会陷入次优均衡

### 关键技术

| 技术 | 说明 |
|------|------|
| 时间线化事实组织 | 把事实组织成可导航的时间线，让时间约束显式化 |
| Worker / Coordinator 双角色 | worker 调查并产出原始带时间戳观察，coordinator 综合 |
| 角色条件蒸馏 | 通过角色条件蒸馏初始化共享策略，快速获得角色分化能力 |
| 协同进化自博弈 | 用最终答案奖励同时优化两个角色，避免固定分工的次优均衡 |
| 上下文隔离 | 不同事件历史的证据分处不同 agent 上下文，抑制干扰项污染 |

## 实验结论

- **数据集**: 三个复杂时序知识图谱问答基准
- **基线**: 现有单 agent TKGQA 方法及多 agent 变体
- **结果**: 三个基准上取得 SOTA 总体表现，在复杂多事实问题上的增益最为显著。

- **上下文隔离是主要收益来源** —— 把不同事件历史的证据分开，直接解决了干扰项误导后续检索的问题。
- 「协作必须被学习」这个判断是方法论上的关键：手工编排多 agent 分工通常次优。
- 协同进化自博弈用最终答案奖励同时优化两个角色，避免了角色间相互适应的滞后。
- 角色条件蒸馏是高效冷启动的关键，让共享基座快速分化出两个专门角色。
- 与 TCC-RAG（同批次的另一篇）形成有趣的对照：TCC-RAG 在单 agent 内用因果线索图剪枝，CoSTA 用多 agent 分担 —— 两条路线都在解决「证据过多反而有害」。

## 局限性

['多 agent 架构带来显著的推理成本与协调开销。', '时间线导航的质量依赖事实抽取的准确性，上游噪声会传导。', '协调器的综合能力是瓶颈，任一 worker 的错误观察都可能被放大。', '仅三个基准，且 TKGQA 本身是相对受限的任务域。']

---

## 实现建议

- **实现难度**: 中（需时间线构建、角色蒸馏与自博弈训练循环）
- **适用场景**: 时序知识问答、多 agent 调查与综合、时间敏感型 RAG、企业数据核查
- **建议**: 当证据相互干扰时，**先考虑隔离上下文再考虑增强检索** —— CoSTA 证明把不同事件历史分给不同 agent 比在单一上下文里塞更多线索更有效。角色分工用蒸馏初始化 + 自博弈联合优化，不要手工固定。

## 原始摘要

```
Complex Temporal Knowledge Graph Question Answering (TKGQA) involves more than retrieving facts: the timestamp or validity interval of one fact can constrain the search for another, while multiple intervals may jointly determine the answer. Existing single-agent TKGQA methods typically investigate these facts within a single reasoning context, where evidence from different event histories can become interleaved and distractors can misdirect subsequent retrieval. Distributing investigations across agents can separate event-specific evidence into distinct contexts, but effective collaboration must still be learned because question decomposition, subtask investigation, and evidence synthesis are interdependent. To address these limitations, we propose \textbf{Co}-Evolving \textbf{S}elf-Play \textbf{T}imeline \textbf{A}gents (CoSTA), which organizes facts into navigable timelines, delegates investigations to workers, and uses a coordinator to synthesize their original timestamped observations. CoSTA initializes a shared policy through role-conditioned distillation and jointly optimizes both roles through co-evolving self-play with final-answer rewards. Across three benchmarks, CoSTA achieves state-of-the-art overall performance, with particularly strong gains on complex multi-fact questions, while its compact variants outperform the evaluated closed-source LLM agents.
```
