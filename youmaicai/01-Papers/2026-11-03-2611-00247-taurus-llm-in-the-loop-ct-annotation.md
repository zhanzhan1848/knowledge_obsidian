## 核心贡献
1. **Taurus harness**：把"LLM 审阅自动标注结果"与"自由格式 agent 自己写分割代码"两种范式放在同一评测协议下对比
2. **盲标注恢复评测方法**：扣留 6 个公开数据集（939 个 volume）的人工标注，用各数据集自身的类别体系评分，绕开"公开数据集各标各的结构"带来的不可比性
3. **诚实的迭代记录**：报告了第一版 Taurus 的**失败**（6 个数据集中仅 2 个提升，且提升幅度小于同一病例两次审阅之间的噪声），以及从自由格式 agent 反向移植有效做法后最终追平的完整过程

## 问题背景
主动脉 CT 的稠密标注既慢又有约定差异：可替代的公开主动脉 CT 数据集各自标注不同结构、各用各的约定。LLM agent 现在既能写代码也能读图，但**哪种范式标注更好**没有答案：
- **自由格式 agent**：自己写分割代码
- **harness 模式**：自动 pass 先标注，模型审阅结果

## 方法

### 评测协议：盲标注恢复（Blind Label Recovery）
```text
1. 扣留 6 个公开数据集（939 volumes）的人工标注
2. 各方法独立标注
3. 用「每个数据集自身的类别体系」评分
4. 比较
```
关键设计：**不强行统一不同数据集的标注约定**，而是在各数据集内部评分。

### Taurus harness 的三阶段演进
| 版本 | 做法 | 结果 |
|------|------|------|
| **v1** | 模型审阅自动 pass 的结果 | 仅在 **6 个中的 2 个**数据集上提升主指标，且**提升幅度小于同一病例两次审阅之间的噪声** |
| **v2** | 把自由格式 agent 做得好的部分移入自动 pass | 在 **38 个保留病例**上承载了大部分增益 |
| **v3（最终）** | 用固定规则平滑标注表面；检查自动 pass 惯犯的大错误（如**把动脉瘤画成一半大小**）；每个检查触发时向模型提出**多项选择题**，候选修正 | 追平自由格式 agent，成本减半 |

### 关键设计点
- **固定规则平滑标注表面** —— 规则是确定的，不引入模型方差
- **大错误检查清单** —— 针对已知的、自动化 pass 的系统性失败模式（尺寸错误这类）
- **多项选择题式纠错** —— 把开放式修改转为离散选择，降低模型犯错空间

## 实验结果

### v1 的负面结果（重要）
- 主指标仅在 **2/6** 数据集上提升
- 提升幅度 **小于噪声**（同一病例两次审阅之间的差异）

### v2
- 从自由格式 agent 移植到自动 pass 的做法，在 **38 个保留病例**上承载了**大部分**增益

### 最终版本
- **匹配**在多数数据集上得分更高的自由格式 agent（使用 Claude Opus 5.5）
- **成本为一半**

## 关键洞察
1. **"LLM 在环"（human/LLM-in-the-loop review）并不是自动更优** —— v1 的失败说明，把审阅交给模型但**不针对已知失败模式设计检查**，可能连噪声都跑不过。这是本篇最诚实也最有价值的一条。
2. **最有效的改进来自"从另一种范式反向移植"** —— 自由格式 agent 之所以强，是因为它能自己决定如何切分问题；把这部分能力搬进自动 pass 才带来真实增益。**范式之间的对比不应只做排名，还应该做机制移植。**
3. **已知的失败模式清单比通用能力更重要** —— "动脉瘤画成一半"这类具体检查，比让模型自由审阅有效得多。这与 [[2026-11-02-2610.41803-what-standard-evaluations-hide-about-detectors-of-hijacked-llm-agents-ra]] 的"检测器需要知道攻击面"是同一逻辑。
4. **公开数据集标注约定不一致是个真问题** —— "用各数据集自身类别评分"是绕开这个问题的一种诚实做法，但代价是无法横向比较不同数据集的绝对难度。

## 局限性
- v3 的最终数字未在摘要中给出具体数值
- 6 个数据集、939 volumes 的规模有限；结论是否外推到其他模态（病理、眼底）未知
- "成本减半"的基线是自由格式 agent（Claude Opus 5.5）成本，而非人工标注成本
- v1 的失败结论受限于所用 harness 的实现方式，未必适用于所有"LLM 审阅"设计

## 适用场景
- 医学影像标注工具设计（CT / X 光 / 病理）
- 需要对比"端到端生成"与"生成 + 审阅"两种 AI 辅助范式
- 把自动化流水线的系统性失败模式显式清单化
