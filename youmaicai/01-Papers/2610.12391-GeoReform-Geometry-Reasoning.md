## 核心贡献

> 把"几何形式化"从固定 parser 升级为可优化策略：通过执行 → 收集失败 rollout → 诊断缺陷 → 变异策略的循环，让 MLLM 学会"如何更好地形式化几何"。在 Geometry3K 上把 Qwen3VL-2B 准确率从 42.0% → 56.0%。

1. 指出几何形式化的关键挑战**不是抽取更多几何事实**，而是**组织事实**以支持下游推理。
2. 提出 **GeoReform**：reflective formalization evolution framework，把形式化策略当作 RL-style 的可变策略。
3. 在 Geometry3K 等几何推理基准上证明**形式化质量**对 MLLM 几何推理的影响比 prompt / 模型规模更大。

---

## 技术方案

### 核心思想

传统做法把"几何形式化"当作一次性 parser 输出，但冗余关系会分散模型注意力、模糊指代会引入约束错误。GeoReform 用闭环 rollout–diagnose–mutate 持续改进 formalization policy。

### 关键技术

| 技术 | 说明 |
|------|------|
| Full reasoning pipeline rollout | 把形式化策略嵌入到完整推理链路中评估，不只看形式化正确性 |
| Failed rollout collection | 收集下游推理失败的 rollout，定位形式化阶段的缺陷 |
| Defect diagnosis | 把缺陷分为 4 类：selection / grounding / grouping / presentation |
| Policy mutation | 优化策略以更好选择、ground、group、present 几何实体与关系 |

---

## 公式

形式化策略的优化目标可写为：

```math
\theta^* = \arg\max_\theta \ \mathbb{E}_{x \sim \mathcal{D}, \tau \sim \pi_\theta(\cdot|x)} \big[ R(\text{success}(x, \tau)) \big]
```

其中 $\pi_\theta$ 为形式化策略，$R$ 为下游推理正确性奖励。

## 实验结论

- **数据集**: Geometry3K、多个几何推理 benchmark
- **基线**: Qwen3VL-2B（vanilla prompt）、其他几何形式化方法
- **结果**:
  - Geometry3K：Qwen3VL-2B **42.0% → 56.0%**（+14 pp）
  - 广泛 benchmark 实验证明形式化质量对几何推理影响显著

---

## 局限性

- 主要在几何领域验证，迁移到其它形式化重任务（电路、分子）未验证。
- 策略变异空间较大，训练成本与样本效率未充分讨论。
- 仍依赖 strong backbone MLLM，policy 本身的可解释性有限。

## 实现建议

- **实现难度**: 中-高（需要 rollout + diagnosis 闭环 pipeline）
- **预期性能**: 在几何题基准上 +10–15 pp 提升，无需更大模型
- **适用场景**: 任何"形式化后处理"任务——几何、电路图、分子结构、表格推理
