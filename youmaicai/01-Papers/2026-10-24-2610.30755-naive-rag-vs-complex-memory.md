## 核心贡献

> 对"复杂 agentic memory"提出直接质疑 —— **朴素 RAG 比我们想象的更强**，复杂记忆架构并非总是必要。

1. **质疑对象**：近年大量工作提出复杂的 agentic memory 架构（层次化记忆、图记忆、反思记忆、程序化记忆等）
2. **核心问题**：这些复杂度带来的收益，是**架构本身**带来的，还是**评测设置**带来的？
3. **答案**：在更公平的对照设置下，**朴素 RAG 表现强于预期**
4. **方法论意义**：这篇是一次**对社区默认叙事的压力测试** —— 与 [[MemPABench]] 的"检索式记忆无增益"结论**互相印证**（两篇独立工作，结论方向一致但一个针对交互偏好、一个针对 agentic memory）

## 技术方案

### 对照设计的关键

| 要素 | 复杂记忆的"隐含优势" | 公平对照应有的做法 |
|------|---------------------|-------------------|
| 检索方式 | 定制检索器 + 结构化索引 | 与朴素 RAG **同等检索预算**下对比 |
| 计算预算 | 额外推理调用 | 对齐 **token / 调用次数**预算 |
| 数据 | 可能用额外监督信号 | 对齐**训练数据量** |

只有把这些对齐，复杂架构的增益才是真实的。

---

## 实验结论

> 摘要要点（具体数值需查正文）：
> - 在对齐后的对照设置下，**朴素 RAG 强于多数复杂 agentic memory 方案**
> - 复杂记忆架构的宣称增益**部分源于不对齐的评测设置**
> - 实践建议：先建立**强朴素 RAG 基线**，再判断复杂架构是否值得

**与 MemPABench 的呼应**：MemPABench 发现 Mem0 / MemOS / simple RAG 在交互偏好任务上**都不优于 No Memory**；本文则发现朴素 RAG 在 agentic memory 任务上**比复杂方案强**。两篇合起来看，指向同一个结论 —— **当前 agentic memory 的复杂架构普遍没有被公平地证明其必要性**。

---

## 局限性

- 摘要未给出具体模型、基准与数值
- "朴素 RAG"的定义（切分方式、检索器、rerank）会显著影响结论
- 可能存在特定任务（如超长时程、需要结构化推理的任务）复杂架构仍然占优
- 对照公平性的判断本身有主观性

## 实现建议

- **实现难度**: 低（就是建一个强 RAG 基线）
- **适用场景**: 评估"是否值得引入复杂 memory 架构"时 —— 这应该是**默认应该先回答**的问题
- **建议起点**: 按"切分优化 → 混合检索 → rerank → query 改写"的顺序把朴素 RAG 调强，再决定是否引入复杂架构
- **价值点**: 与 MemPABench 合并阅读，这两篇构成本周最值得注意的**记忆系统祛魅**信号 —— 建议在设计任何 memory 系统前先读
