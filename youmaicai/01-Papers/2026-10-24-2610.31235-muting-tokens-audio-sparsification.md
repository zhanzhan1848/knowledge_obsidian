## 核心贡献

> 对音频 Transformer 的 **token sparsification** 做首个**全面评估**，并提出融合 attention 分数与**频谱线索**的新方法 —— 证明**频率感知**的稀疏化一致优于纯 attention 方法。

1. **研究缺口**：token sparsification 在视觉与语言领域已被广泛研究，但在**音频领域仍欠缺探索**，且已有工作通常只覆盖单一方法 / 单一模型规模 / 单一数据集
2. **全面评估**：跨**多种剪枝与合并策略**、**多个数据集**、**多种模型规模**，且同时覆盖 **post-training** 与 **fine-tuning** 两种设定
3. **新方法**：将 attention scores 与从 token embedding **频率内容**导出的**频谱线索**结合
4. **核心发现**：
   - 基于 **spectral flatness** 与 **low-frequency energy** 的频率感知方法**一致优于**仅用 attention 的方法
   - 基于 **spectrogram patch intensity** 的稀疏化对**更长音频输入尤其有效**

---

## 技术方案

### 频谱线索

从 token embedding 的频率内容导出频域特征：

| 频谱特征 | 捕捉的信息 |
|----------|------------|
| **Spectral flatness** | 信号的噪声特性（平坦 = 噪声样） |
| **Low-frequency energy** | 低频（粗结构/韵律）能量占比 |
| **Spectrogram patch intensity** | 频谱图局部强度（事件性/响度） |

### 与 attention 线索的融合

$$
\text{sparsity\_score}(t) = \alpha \cdot \text{Attn}(t) + (1-\alpha) \cdot \text{Spectral}(t)
$$

**核心论点**：attention 分数只反映"模型看了哪里"，而**频谱线索反映"这个 token 携带什么内容"** —— 二者互补。

---

## 实验结论

| 发现 | 细节 |
|------|------|
| 频率感知 > 纯 attention | **一致优于**（spectral flatness 与 low-frequency energy 尤其突出） |
| 长音频受益更大 | spectrogram patch intensity 方法对**更长音频输入尤其有效** |
| 设定覆盖完整 | post-training 与 fine-tuning 两种设定均评估 |
| 领域空白填补 | 音频领域首个系统性 token sparsification 评估 |

## 局限性

- 论文自述"工作在 2024 年完成，相关工作反映当时文献状态"（作者注）
- 音频领域的剪枝/合并策略可能随时间已有更新
- 未给出与视觉/语言领域 sparsification 方法的直接统一基准对比
- 频率感知特征需额外频域计算，有额外开销成本（论文未详细核算）

## 实现建议

- **实现难度**: 中（频谱特征提取实现简单，与 attention 分数融合即可）
- **适用场景**: 长音频理解 —— 会议录音、播客、音频长上下文模型
- **建议起点**: 在你的音频模型上先做**离线重要性分析**：对比 attention top-k 选出的 token 与频谱特征选出的 token 的重叠率，若重叠低则融合收益大
- **价值点**: "跨模态重要性信号可能需要跨模态的度量" —— 这个思路可直接迁移到视觉与文本
