## 核心贡献

> 证明 LLM 内部的价值表征可以预测窄对齐训练是否会广泛泛化，为部署前的后训练鲁棒性提供诊断工具。

1. 发现 **内部 value representations** 与 alignment generalization 的关联
2. 提出新指标，可在部署前早期检测对齐失败
3. 改变"alignment evaluation = behavior test" 的范式

---

## 技术方案

### 核心思想

后训练（post-training）通常只在少数对齐任务上训练（如 refusal、helpfulness），但实际部署时面对广泛任务。如何预测训练好的对齐是否会泛化？本文发现模型**内部的"价值"表征**——即隐空间中编码的 reward/value 信号——比外部行为更能预测泛化能力。

### 关键技术

| 技术 | 说明 |
|------|------|
| Value representation extraction | 从 hidden states 提取与 reward 一致的方向 |
| Generalization probe | 在窄任务训练后预测 wide-task 表现 |
| Internal-state metric | 比行为指标更早、更稳定的对齐失败信号 |

---

## 公式

```math
\text{AlignmentGen} \approx f(\mathbf{v}_{\text{internal}}, \mathbf{v}_{\text{reward}})
```

其中 $\mathbf{v}_{\text{internal}}$ 是从 hidden states 提取的价值表征，$\mathbf{v}_{\text{reward}}$ 是真实 reward 的隐变量表达。

---

## 实验结论

- **数据集**: 多个对齐 benchmark
- **结果**: 内部 value representations 能预测窄训练任务之外的表现
- **意义**: 部署前可早期检测 alignment generalization 失败

---

## 局限性

- 需要访问 hidden states
- Value 表征本身定义依赖 reward model 设计
- 是否能泛化到非 RLHF 训练范式（如 DPO、constitutional AI）需验证
