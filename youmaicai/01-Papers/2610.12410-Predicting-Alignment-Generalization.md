## 核心贡献

> 首次定义 "Alignment Generalization Prediction" 任务：用模型激活而非文本描述来预测 fine-tuning 一个价值观如何影响模型在未见价值观上的行为，并发现存在跨模型共享的"价值观空间"。

1. 提出 **Alignment Generalization Prediction** 任务：预测在某个 value 上做 SFT 后，模型在 65 个其它 value 上的行为变化。
2. 大规模分析 **66 个价值观** 的泛化效应，发现基于**激活（activations）** 的价值表示显著优于基于文本描述的基线（相关性 0.45 vs 0.05）。
3. 首次实证了**跨模型共享的价值空间**，并基于此构建首个以"经验性泛化动态"为锚点的 LLM 价值分类法。

---

## 技术方案

### 核心思想

把"alignment value"看作模型内部的隐式表征（activation pattern），而不是显式的文本串。微调一个 value 实际上是在激活空间里移动这个表征的位置，其在其它 value 上的"几何距离"决定了泛化效应。

### 关键技术

| 技术 | 说明 |
|------|------|
| Activation-based probing | 把 value 模板注入到 prompt 中，提取模型在该 prompt 下最后一层的 activation 作为 value representation |
| Generalization matrix | 66×66 矩阵，描述微调 value_i 后 value_j 上的行为变化幅度 |
| Multi-value alignment similarity | 用 value representations 的余弦相似度衡量 alignment target 中各 value 之间的"重叠度"，相关性显著影响模型鲁棒性 |
| Model-independent value space | 跨模型做 Procrustes 对齐，证明存在一个近似共享的几何结构 |

---

## 实验结论

- **数据集**: 自构的 66-value alignment generalization matrix
- **基线**: text-description-based value representations
- **结果**:
  - Activations vs descriptions：相关性 0.45 vs 0.05（activation-based 大幅领先）
  - Multi-value alignment robustness：value 相似度与模型鲁棒性显著相关
  - Shared value space：Procrustes 对齐后跨模型表征一致性高

---

## 局限性

- 仅研究 SFT 对齐行为，尚未覆盖 RLHF/RLVR 等更复杂对齐方法。
- "Value" 的枚举受研究者先验选择影响，可能存在选择偏差。
- 跨模型共享空间的"因果含义"未充分验证。

## 实现建议

- **实现难度**: 中（需要 66 个 value 的微调实验 + activation extraction）
- **预期性能**: 在自家模型上可立即复现 alignment generalization matrix
- **适用场景**: 红队评估、alignment 数据集设计、multi-value 对齐冲突检测
