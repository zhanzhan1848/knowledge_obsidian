## 核心贡献
1. 提出 **circuits**（电路）这一结构，把多个 LLM classifier 组织成一条**自适应的查询与决策序列**，以组合不同模型的预测提升可靠性。
2. 给出 **optimal circuit 的刻画**（characterize the optimal circuit），并推出可达准确率的**基本极限**（fundamental limits of achievable accuracy）。
3. 提供实现 optimal circuit 的**实践性洞见**（practical insights on realizing the optimal circuit）。
4. 在 7 个分类任务上验证，相对 routing 与 cascading 基线**改善了 cost-accuracy frontier**。

## 问题动机
用语言模型做分类器非常方便——把待分类样本 prompt 给模型即可。但问题在于：这种分类器的预测**既不确定（neither deterministic）**，在不同样本上的**可靠性也不均匀**。那么问题自然变成：如何组合来自不同模型的预测以提升整体可靠性？论文把目标形式化为一个明确的优化问题——**在给定平均查询成本下最大化平均分类准确率**——并将其视为信息论/决策论意义上的测量问题，而非工程上的模型挑选问题。

## 方法
- **建模视角**：把 LLM classifier 视为对**潜在目标标签（underlying target label）的含噪测量仪器**（noisy measurement instruments）。这一定位使得"组合多个含噪测量"可以直接借用经典测量与决策理论。
- **circuits 结构**：将 LLM classifiers 组织为一个 **adaptive sequence of queries and decisions**（自适应的查询与决策序列）。关键点是"adaptive"——后续查询哪些模型取决于此前的观测结果。
- **理论工作**：(a) 刻画 optimal circuit；(b) 给出 achievable accuracy 的 **fundamental limits**；(c) 讨论如何逼近该最优电路。
- **目标函数**：maximize average classification accuracy at a given average query cost，即在 cost-accuracy 平面上寻找 frontier。

## 关键技术细节
- 优化目标是**双目标**的：平均准确率 vs. 平均查询成本，因此论文报告的核心指标是 frontier 而非单点分数。
- "含噪测量仪器"这一定位暗含：不同 LLM classifier 的可靠性先验需要被估计（可能是每任务、每类别的可靠性），这本身可能带来标注成本——摘要未讨论该成本如何获取。
- circuits 与 cascading 的关键差别在于决策是**自适应、多模型、序列式**的：既可以"路由"到单个模型，也可以对同一模型多次查询再综合。
- 作者团队（Viveck R. Cadambe、Flavio Calmon）来自信息论与通信方向，与本文的理论取向一致。

## 局限性
论文未在摘要中明确声明局限性。谨慎读者需注意：
- **可靠性估计是方法的关键前提**：circuits 的最优性依赖对各 classifier 在各样本/类别上的错误率刻画。若可靠性估计来自少量标注或跨任务迁移，其准确性直接决定 frontier 的实际收益。摘要未说明该估计的获取方式与样本量。
- 7 个任务虽然覆盖面广，但均属**文本分类**形态；对于需要长上下文或多模态输入的分类，query cost 的度量口径可能不再适用。
- LLM classifier 的"非确定性"本身可能是 prompt 采样导致的方差，论文未说明如何在理论上把这一方差并入含噪测量模型（还是通过多次采样平均消除）。
- 摘要未报告 wall-clock 延迟或吞吐，而 cost-accuracy frontier 的"cost"是否指纯 query 次数还是含真实 API 定价，需查正文确认。
