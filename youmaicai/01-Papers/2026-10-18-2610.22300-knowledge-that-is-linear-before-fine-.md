## 核心贡献

> 区分 LM 中的 **active facts**（recall 后支持 generalization）与 **inert facts**（仅 recall 但不 generalize）。**原始 relation 在 pretrained representation 中越 linearly readable → fine-tune 后 generalization 越好**（11 LM × 70 relations, **r = 0.87–0.92** per model）。**Linear readability = generalization 预测器**，远超 recall 本身。

1. **新实验范式**：在原始 relation (Paris → Europe) 上**重新映射 label** (Europe → crab) → fine-tune 部分 subject → 测试 held-out subjects 是否获对应 label (Munich → crab?).
2. **关键预测器**：linear probe accuracy on original relation → predict fine-tune generalization.
3. **强稳健性**：控制 #subjects / #answers / pretrain freq / label re-randomization / seed 等 confounders 后仍成立。
4. **跨语义类别稳健**：动物 label → 13 个其他语义类别也成立。

## 技术方案

### Active vs Inert Facts

| 类型 | 特征 |
|------|------|
| **Active** | 学会后**支持 generalize** 到同 relation 的 held-out subjects |
| **Inert** | 学会后**仅 recall**，**不** generalize |

### 实验设计：Relabeling Paradigm

```
Original relation:  Paris → Europe
                   Munich → Europe
                   Berlin → Europe

Relabeling:        Europe → crab
                   Asia   → zebra
                   
New relation:      Paris → crab  (model is trained on this)
                   Munich → ?    (test: should be "crab" if active)
                   Berlin → ?    (test: should be "zebra" if active)
```

- 模型 fine-tune 在**部分 subjects**上 → 不告诉它 original relation 或 relabeling rule
- 测试 held-out subjects 是否获得对应 label

### Linear Readability 测度

- **Linear probe**：在 pretrained representation 上训练 linear classifier → predict relation answer
- **Accuracy = linear readability score**
- 关键假设：原始 relation 的答案可被 pretrained representation **线性读出** ↔ fine-tune 后 generalization 越好

### 反向验证：Recovered Answers

- 把 fine-tuned 模型的 wrong label → 映射回 original answer（crab → Europe）
- 验证：recovered answers 在 **linear probe top answers** 中**比** pretrained model 自己的 top answers **更常见**
- → linear probe 捕捉了 structure，fine-tune 在该 structure 上 generalize

---

## 实验结果

### 规模

- **11 language models** × **70 relations**
- per-model correlation **r = 0.87–0.92**（relations 之间）

### 控制的 confounders

仍稳健的相关性，separately & jointly 控制：
- ✅ #fine-tuning subjects
- ✅ #answers
- ✅ model accuracy on original relation
- ✅ pretraining frequency of subjects
- ✅ re-randomization of label assignment
- ✅ fine-tuning seed
- ✅ 替换 animal label 为 13 个其他语义类别

### 反向验证

- Recovered answers（错误 label 映射回 original）**多在** linear probe top answers
- **少在** pretrained model 自己的 top answers
- → linear probe 提取了 model **未显式 activate 但可线性读出** 的 structure

## 局限与展望

- 仅在 factual relations 上验证 → procedural / abstract / causal reasoning 是否仍成立？
- 仅 70 relations → 是否覆盖真实 fine-tune 任务的**多样性**？
- linear probe 是否 capture **non-linear structure**？可能遗漏。
- 反向 recovery 实验是 indirect evidence；causal 实验未做。

## 实现建议

- **实现难度**: 低（linear probe + fine-tune + correlation analysis）
- **预期性能**: 不直接提升模型；提供 **fine-tune data selection 工具**
- **适用场景**:
  - **Pre-flight check**：fine-tune 前对 candidate facts 做 linear probe → 筛 active facts
  - **Data augmentation**：优先 augment 在 inert facts 上的 examples（避免死记）
  - **Continual learning**：评估新知识是否会被 generalize
- **不适用**: non-factual knowledge（procedural, common-sense）
- **工程启示**:
  - LM 内置 linear-readable structure **比表面 recall 更重要**
  - **fine-tune 应优先选 active facts**（maximize generalization / token）

---

## 一句话总结

LM fine-tune generalization 取决于**原始 fact 在 pretrained representation 中线性可读性**（r = 0.87–0.92），而非 fact 本身是否可 recall → 给 fine-tune data selection 一个可量化的预测器。
