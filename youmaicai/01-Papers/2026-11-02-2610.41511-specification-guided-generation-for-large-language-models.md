# 规范引导的大语言模型生成

> **原题**: Specification-Guided Generation for Large Language Models

| **摘要** | Large language models (LLMs) can generate structured outputs, but existing constrained-decoding methods mainly enforce syntax and cannot directly enforce satisfaction of a formal specification. We introduce a neuro-symbolic, specification-guided decoding framework that combines LLM generation with symbolic reasoning. At each step, the framework refines the decoding grammar by filtering out values that cannot be extended to an output satisfying the specification. We present a forward-only variant that guarantees specification satisfaction by construction, and a backtracking variant that revises earlier feasible choices when their downstream consequences leave only values that the LLM itself judges unsuitable. The framework is model-agnostic, requires no retraining, and builds on existing grammar-constrained decoding mechanisms. Experiments on configuration and constraint-solving benchmarks show that the forward-only variant reliably produces specification-compliant outputs while reducing repeated LLM inference compared with rejection sampling and incurring modest symbolic-reasoning overhead. The backtracking variant further reduces cases in which the model is forced to select values that it has itself judged unsuitable, thereby substantially improving adherence to the LLM's stated interpretation of the prompt. |

## 核心贡献

1. **问题**：LLM 能生成结构化输出，但**现有约束解码方法主要强制语法**，无法**直接强制满足形式化规范（specification）**。
2. 提出**神经符号的规范引导解码框架**，把 LLM 生成与**符号推理**结合。
3. **核心机制**：**每一步都精炼解码文法（refine the decoding grammar）**，**过滤掉那些无法扩展成满足规范的输出的取值**。
4. **两个变体**：
   - **仅向前（forward-only）**：**构造上保证**规范满足
   - **回溯（backtracking）**：当早期可行选择的下游后果只剩"LLM 自己都认为不合适的取值"时，**回溯修改更早的选择**
5. **特性**：模型无关、**无需重训练**、构建在现有文法约束解码机制之上。
6. **结果**：在**配置生成与约束求解基准**上，仅向前变体**可靠产出规范合规输出**，同时相比**拒绝采样减少了重复 LLM 推理**，只引入适度的符号推理开销。回溯变体进一步减少"模型被迫选择自己都看不合适的取值"的情形，从而**显著改善对提示词既定解释的遵从度**。

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| 技术 | 说明 |
|------|------|
| 逐步精炼解码文法 | 每步剔除不可行扩展的取值 |
| 仅向前变体 | 构造上保证规范满足 |
| 回溯变体 | 下游不可行时回溯修改早期选择 |
| 神经符号 | LLM 生成 + 符号推理 |
| 无需重训练 | 模型无关、即插即用 |

### 关键发现

- **"过滤掉无法扩展成合规输出的取值"** 是本文的技术核心 —— 这把"规范满足"从**后置检查**变成了**生成过程中的约束**，与拒绝采样形成鲜明对比（且**减少了重复 LLM 推理**，这在成本上是硬优势）。
- **"模型被迫选择自己都认为不合适的取值"** 是回溯变体解决的具体失败模式 —— 这是一个**从"合规"走向"忠实地合规"**的改进。很多形式化约束系统只保证前者。
- 与 [[2026-11-02-2610.41604-real-computation-or-merely-naming-a-pre-registered-mechanism-audit-of-25]]（名称≠机制审计）方向相反但同源：都关心"**系统声称的与系统实际做的**"之间的差距 —— 这篇用符号约束**强制**一致，那篇用审计**发现**不一致。
- 与 [[2026-11-02-2610.41129-when-should-ai-agents-ask-clarification-requests-under-limited-human-att]]（agent 何时该问）互补：规范约束是**确定性的事前**，澄清请求是**带成本的协商**。
- 实际价值：凡是"生成的配置/代码/计划必须满足形式化约束"的场景（配置生成、调度、合成代码）都能直接用。

## 实验结果

| 变体 | 规范满足 | LLM 推理次数 | 提示遵从度 |
|------|------|------|
| 仅向前 | **构造上保证** | **低于拒绝采样** | 适中 |
| 回溯 | 构造上保证 | 略高 | **显著更高**（减少被迫选不合适的值） |

## 局限性

- 符号推理开销随规范复杂度增长，摘要仅说"适度"，未见详细分析
- 仅向前变体的"构造上保证"依赖于规范本身可判定（不可判定的规范不适用）
- 回溯变体可能带来指数级回溯深度，未给最坏情况界
- 未与大模型直接遵循提示的能力做充分对照
