## 核心贡献

> 现有评测"测出不可信"，但**说不清哪里不可信**。PhysTrace 让 MLLM 生成"基于历史的物理预期"，再与观测视频窗口对齐，从而**在时间上定位物理违规并给出可解释描述** —— 全程 training-free，无需任务特定探针或分类器。

1. **问题定位**：world action models 越来越依赖预训练视频模型（假设其捕获了物理动力学，用于预测、规划、动作生成），但现有评测只做**合理性**评估、**表征探查**或**预测惊讶度**度量 —— **很少能指出"哪一个基于历史的物理预期与观测冲突"**
2. **提出 PhysTrace**：training-free 框架，将 **MLLM 生成的 history-conditioned expectations** 与**观测视频窗口**对齐
3. **时间定位 + 可解释描述**：不只是给出一个"物理不一致"的标签，而是**定位违规发生的时间区间**并给出文字说明
4. **无任务特定探针/分类器**：全部靠通用 MLLM + 时间对齐
5. **提出 IntPhys2-Timing**：给 IntPhys2 补充**违规时间区间（violation intervals）标注**
6. **应用到真实生成模型**：在**预训练 diffusion/flow-based 视频模型的轨迹**上重建视频，发现**依赖属性（attribute-dependent）与依赖噪声（noise-dependent）**的违规定位模式

## 技术方案

### 核心思想

```
视频片段 + 历史上下文
      ↓
MLLM 生成 history-conditioned physical expectations
   （"在已看到球落地之前，我预期球会向下运动"）
      ↓
与观测视频窗口做时间对齐
      ↓
定位 violation interval（哪一段时间预期与观测冲突）
      ↓
输出可解释描述（哪个物理原则、什么预期、什么观测）
```

### 关键技术

| 技术 | 说明 |
|------|------|
| History-conditioned expectation generation | 让 MLLM **基于已观测历史**生成物理预期 —— 关键是"历史条件"而非泛泛常识 |
| Temporal alignment with observation | 把预期与观测窗口对齐，产出**时间定位**而非全局标签 |
| Training-free | 不训练任何探针或分类器，直接用通用 MLLM |
| IntPhys2-Timing | 在 IntPhys2 基础上**新增违规时间区间标注** |
| Trajectory-based evaluation of generative models | 在 diffusion/flow 视频模型**生成的视频轨迹**上运行（而非在真实视频上） |
| Attribute- / noise-dependent pattern analysis | 分析违规定位结果如何随**属性**与**噪声水平**变化 |

### 两种评测对象的区别

| 对象 | 现有方法 | PhysTrace |
|------|---------|-----------|
| 真实视频的物理一致性 | 合理性、惊讶度 | 预期 vs 观测的时间对齐 |
| 生成视频的物理一致性 | 少有方法 | **在生成轨迹上重建并定位违规区间**，揭示属性/噪声依赖模式 |

## 关键结论

1. **"物理不一致"作为单一标签的信息量太低**。PhysTrace 的核心贡献不是又一个分数，而是**时间定位 + 可解释描述** —— 这让诊断从"这个模型不行"变成"第几秒、违反了哪条原则"。
2. **Hit Rate 最高 70.7%** 意味着方法**远未解决**时间定位问题，仍有约 30% 的违规无法被正确定位 —— 这是 training-free 路线的现实代价。
3. **在生成模型轨迹上的应用更有价值**：能观察到**属性依赖**（某些物理属性更容易被违反）与**噪声依赖**（噪声水平如何影响违规出现时机）的规律，这是**调参与数据增广的直接依据**。
4. **免探针/免分类器**使方法可即插即用于新物理现象类别，但上限受 MLLM 物理常识理解能力约束。

---

## 局限性

- **Hit Rate 仅 70.7%**：时间定位错误率近三成，作为自动筛选器会引入显著噪声
- **依赖 MLLM 的物理预期质量**：若 MLLM 本身预期错，定位会指向错误位置；摘要未评估 MLLM 预期的准确性
- **数值披露不全**：possible-impossible 判别准确率、属性/噪声依赖的具体量级均未给出
- **依赖 IntPhys2 体系**：IntPhys2-Timing 的覆盖限于其物理原则清单，泛化到真实物理场景（流体、接触、多物体交互）未知
- **"重建视频"环节**：在生成轨迹上评估需要能从轨迹重建可观测视频，可能引入重建误差，与物理违规混淆
- **代码已开放但未在摘要提供额外文档链接**

## 实现建议

- **实现难度**: 中高（需要 MLLM 生成结构化预期 + 时间对齐逻辑 + 违规区间标注）
- **适用场景**: 评估视频生成/世界模型的**物理合理性诊断**；以及研究"哪些物理属性/噪声水平最易崩溃"
- **落地步骤**:
  1. 先用现成的 **IntPhys2-Timing** 跑一遍基线（拿到 70.7% 的参照上限）
  2. 在自研视频模型的**生成轨迹**上跑，看违规区间的分布
  3. 做**属性/噪声扫描**：固定物理原则、变噪声级别，定位违规开始时间如何移动 —— 这是最有工程价值的输出
  4. 把定位结果**接入数据筛选**：优先过滤违规集中的时间窗/属性组合，作为训练数据清洗规则
- **与相邻工作区分**: 区别于 2026-10-24 日报中的 RCR（drift 决定何时重选）—— RCR 是**效率**问题（何时刷新 KV），PhysTrace 是**质量**问题（何时物理崩坏）；两者可组合：先用 RCR 省算力，再用 PhysTrace 定位坏片段
- **价值点**: 把视频生成评测从"打分"推进到"**定位 + 解释**"，且提供可即插即用的违规区间标注
