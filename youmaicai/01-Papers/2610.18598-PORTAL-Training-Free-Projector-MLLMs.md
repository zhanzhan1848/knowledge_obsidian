## 核心贡献

> Multimodal LLM 的 projector 训练本质是 *粗对齐*——10-20% 数据即可达到几乎全部增益；不同 projector 之间可线性插值保留性能。基于此提出 **PORTAL**——基于 optimal transport 的 *训练免费* projector 初始化。

1. **Projector 是粗对齐**：用 10-20% 数据即可恢复大部分下游性能
2. **Projector 之间的可插值性**：不同数据集训练的 projector 线性插值后仍保留性能
3. **PORTAL 训练免费**：基于 Gaussian 拟合 + optimal transport，无需 image-caption 对也无需 gradient
4. **6 个 LLM backbone + 2 vision encoder + 16 benchmark**：PORTAL 与 558k 数据训练的 pipeline 持平（甚至 3/7 设置超越），其他 4 个 setting 平均达其 98%

---

## 技术方案

### 核心思想

Projector 训练被广泛认为是 MLLM 训练关键步骤。本文系统研究后发现：

- **数据效率**：仅 10-20% 即可恢复性能 → projector 只做粗对齐
- **可插值性**：不同数据集训练的 projector 线性插值 → 不同 projector 之间差异不大

基于此：可以直接 *绕过* projector 训练，用 *per-modality summary statistics* + optimal transport 做训练免费的初始化。

### 关键技术

| 技术 | 说明 |
|------|------|
| Projector 数据效率分析 | 10-20% 数据足以恢复性能 |
| Projector 线性插值 | 不同 projector 之间平滑过渡 |
| PORTAL: Optimal transport map | 在 shared principal subspace 上匹配 vision & language 分布 |
| Per-modality summary statistics | 无需 paired data |
| 训练免费 | 零 gradient / 零 forward over data pairs |

## 公式

设 vision 特征 $z_v \in \mathbb{R}^{d_v}$，language 特征 $z_l \in \mathbb{R}^{d_l}$。在 shared principal subspace 上用 Gaussian 拟合：

```math
p_v(z) \approx \mathcal{N}(\mu_v, \Sigma_v), \quad p_l(z) \approx \mathcal{N}(\mu_l, \Sigma_l)
```

Optimal transport map：

```math
T(z) = \mu_l + A (z - \mu_v)
```

其中 $A = \Sigma_v^{-1/2} (\Sigma_v^{1/2} \Sigma_l \Sigma_v^{1/2})^{1/2} \Sigma_v^{-1/2}$（Bures 距离意义下的 OT）。

## 实验结论

- **6 LLM backbones + 2 vision encoders + 16 benchmarks**
- **vs 558k paired-data 训练 pipeline**：
  - 3/7 (vision encoder, LLM) 设置 PORTAL 超越
  - 4/7 设置 PORTAL 平均 98% of full pipeline
- **意义**：可以跳过 projector 训练 → 大幅节省 compute & data

---

## 局限性

- 假设 vision / language 分布 Gaussian（可能过于简化）
- 在 OCR / chart 等需要细粒度对齐的任务上可能不够
- Principal subspace 选择影响效果
- Projector 之后的 joint training 仍是必要的（本文不替代）

## 实现建议

- **实现难度**：低（无需 gradient，仅 statistics）
- **预期性能**：替代 projector 训练（数据稀疏或无 paired data 时尤其有用）
- **适用场景**：自建 MLLM 训练 pipeline 的 warm-start；vision encoder 微调实验的 baseline
