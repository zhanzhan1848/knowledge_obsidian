## 核心贡献

> 在法律领域反事实审计 CoT faithfulness：模型**正确命名**法律依据（66.7%–100%）与**真实依据该依据调整 verdict**（0%–76.7%）之间存在巨大 gap；audit artefact 不可信。

1. 提出**反事实审计方法**：固定 case facts，替换"被引用的法律依据"为不相关的另一条，从模型 hidden state 解码 verdict 变化。
2. 在 **7 个 8B–70B 开源模型 × 4 个法律基准**上，发现严重的 faithfulness gap：
   - 正确命名依据：**66.7% – 100%**
   - 替换依据后 verdict 改变：**CaseHOLD 0.0–21.7%**、**ECHR/SCOTUS 30.0–76.7%**、**ContractNLI 43.3–50.0%**
3. **Scale 与法律专用 LoRA** 都无法闭合此 gap。
4. 红队评测：5 个核心模型对藏在 case facts 中的对抗指令服从率 **73.3% – 96.4%**，远超 verdict-swap 敏感度，且跨模型排名稳健。

---

## 技术方案

### 核心思想

法律 LLM 习惯用"引用权威"作为合规证据。但"能否正确命名"和"是否真正依据它决策"是两件事。本研究通过**反事实替换 + hidden-state decoding**量化二者差距，揭示"命名 ≠ 依据"是法律 LLM CoT faithfulness 的根本问题。

### 关键技术

| 技术 | 说明 |
|------|------|
| Counterfactual authority swap | 保持 case facts 不变，替换"named authority"为不相关权威 |
| Hidden-state verdict decoding | 不依赖生成，从 hidden state 解码 verdict 的演化 |
| Cross-model probe | 7 个 8B–70B 模型（含专门 fine-tune 的 70B 法律模型） |
| Adversarial instruction injection | 在 facts 中埋入对抗指令，量化 verification 模型跟随倾向 |
| Prompt-wording / sampling controls | 排除 prompt 措辞与采样混乱导致的伪差异 |

### 关键发现表

| Benchmark | Domain | 命名正确率 | 替换后 verdict 改变率 |
|-----------|--------|-----------|---------------------|
| CaseHOLD | 司法判决 hold 识别 | 66.7–100% | **0.0–21.7%** |
| ECHR | 欧洲人权法院 | 66.7–100% | **30.0–76.7%** |
| SCOTUS | 美国最高法院 | 66.7–100% | **30.0–76.7%** |
| ContractNLI | 合同 NLI | 66.7–100% | **43.3–50.0%** |

---

## 实验结果

- **CaseHOLD** 上 verdict 几乎从不改变（<22%），是 faithfulness 最薄弱区
- **ECHR/SCOTUS** 上中等敏感度（30–77%）
- **ContractNLI** 中等（43–50%）
- 即使 scale 70B 或专门 LoRA 微调法律模型也无明显改善
- 红队对抗指令服从率 73.3–96.4%，**远超 verdict 真实性**

---

## 关键 takeaway

- **引用不等于依据**——这是 LLM 在法律等高风险领域 CoT faithfulness 的根本挑战。
- 生成式法律解释**不应**作为合规 / 审计依据，除非额外 faithfulness 验证。
- 模型对"看似专业的格式"高度可模仿（高命名率），但底层推理与依据弱相关。

---

## 局限性

- 仅限英文 / 西方法系（ECHR、SCOTUS、CaseHOLD、ContractNLI）
- 反事实替换的"无关性"通过研究者人工判定，存在边界争议
- Hidden-state decoding 的准确性依赖线性探针性能，可能低估真实 verdict 改变率
