# CIRCE：从约束结构推断 LLM 任务复杂度

> **原题**: CIRCE Divines LLM Task Complexity from Constraint Structure

| **摘要** | Estimating whether a problem is too complex for a large language model (LLM) before the model attempts it can guide model routing, how to allocate test-time compute, and suggest the need for new tools to aid the agent. While existing estimators rely on the problem text, LLM-annotated task difficulty labels, or signals obtained after a model attempts to solve the problem, such as its hidden states, none explicitly leverage the constraint structure inherent in the problem: the variables to assign and how the constraints over them interact. We introduce CIRCE, which extracts a problem's structure by using a cheap LLM to construct a Constraint Intermediate Representation that deterministically compiles into the constraint graph. Across seven reasoning benchmarks (including SAT, logic, and math) and four LLMs, even a randomly initialized GNN encoder improves predictions of LLM response correctness, reducing negative log-likelihood from 0.465 to 0.423 and increasing AUROC from 0.691 to 0.727 relative to the strongest baseline for each metric. |

## 核心贡献

1. **动机**：**在模型尝试之前**估计一个问题对 LLM 是否太复杂，可以指导**模型路由**、**测试时计算分配**，以及提示**是否需要新工具**。
2. **现有估计器的三种范式与其盲区**：依赖**问题文本**、**LLM 标注的难度标签**、或**模型尝试之后**才获得的信号（如隐藏状态）—— **没有一个显式利用问题内在的约束结构**：要分配的变量，以及变量间约束如何交互。
3. 提出 **CIRCE**：用**廉价 LLM 构造约束中间表示（Constraint Intermediate Representation）**，该表示**确定性地编译成约束图（constraint graph）**。
4. **关键结果**：跨 **7 个推理基准**（含 SAT、逻辑、数学）与 **4 个 LLM**，**即便使用随机初始化的 GNN 编码器**，也能提升对 LLM 回答正确性的预测 —— 相对各指标最强基线，**NLL 从 0.465 → 0.423**，**AUROC 从 0.691 → 0.727**。

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| 技术 | 说明 |
|------|------|
| 约束中间表示 (CIR) | 廉价 LLM 抽取问题结构 |
| 确定性编译 | CIR → 约束图 |
| GNN 编码器 | 约束图编码（**随机初始化即可**） |
| 事前难度预测 | 模型尝试之前 |
| 路由应用 | 按难度分配模型/算力 |

### 关键发现

- **"随机初始化的 GNN 就能带来提升"** 是本文最强的证据 —— 它说明**信号来自约束结构本身，而不是 GNN 的容量或训练技巧**。这与 [[2026-11-02-2610.41754-multimodal-in-context-learning-with-explicit-rule-induction]]（ERIM 的规则归纳）共享同一哲学：**结构即特征**。
- **"确定性编译"** 是设计上的关键取舍：让 LLM 负责*抽取*结构，让编译器负责*保证*结构合法 —— 这把 LLM 的不确定性限制在可控环节内。**LLM 做语义、代码做校验**，这是很干净的分工。
- 与 [[2026-11-02-2610.41618-attention-maps-know-when-to-think-training-free-difficulty-aware-chain-o]]（注意力熵判难度）构成**事前 vs 事中**的互补： CIRCE 靠外部问题结构（不需要跑模型），DA-CoT 靠内部注意力（需要跑到一半）。CIRCE 更适合**路由**，DA-CoT 更适合**同一模型内的算力分配**。
- 与 [[2026-11-02-2610.41375-from-the-zoo-to-the-bullpen-sample-efficient-llm-profiling-via-multi-cha]]（BULLPEN 画像）同属"**事前预测**"家族，但对象是任务而非模型。
- 实际应用价值很高：**把"这个题太难，扔给更大的模型/加工具"变成一个可学习的分类器**。

## 实验结果

| 指标 | 最强基线 | CIRCE |
|------|------|------|
| NLL | 0.465 | **0.423** |
| AUROC | 0.691 | **0.727** |

设置：7 个推理基准（SAT / 逻辑 / 数学）× 4 个 LLM，GNN **随机初始化**。

---

## 局限性

- "廉价 LLM 抽取约束结构"引入了抽取误差，且该误差在不同模型上表现未知
- 7 个基准均属**约束可形式化**的任务，**开放域任务不适用**
- 摘要未给出真实路由场景的端到端收益（如成本下降多少）
