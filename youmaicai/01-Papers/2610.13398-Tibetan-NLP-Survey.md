## 核心贡献

> 首份 peer-reviewed 系统 bibliometric survey：覆盖 2004–2026 年 Tibetan NLP 140 篇出版物，按 venue、研究区域、作者国别、资源发布等维度标注。

1. **覆盖完整 pipeline**: 语料库 → 分词 → 文字 → 语音 → 应用 → **LLM**
2. **趋势**: 84% 出版物自 2018 年以来；中国作者 87%
3. **作为 Global South 低资源范式**: complex script + dialectal diversity + 地理偏远 → 完整 pipeline 范式

---

## 技术方案

### 核心思想

对 Tibetan NLP 22 年的工作进行 bibliometric 梳理，识别 gap（方言覆盖、负责任 NLP、本地化评估、跨社区可见性、资源发布）。

### 关键数据

| 维度 | 数据 |
|------|------|
| 论文总数 | 140 |
| 时间跨度 | 2004–2026 |
| 2018 后占比 | 84% |
| 中国作者比例 | 87% |
| 覆盖研究领域 | 25 个 |
| 资源发布 | 部分 |
| 多数研究区域 | 全 NLP pipeline（corpus → LLM）|

### 研究 gap

- **方言覆盖**: 不全
- **Responsible NLP**: 缺少
- **Native evaluation**: 缺本地可比评测
- **Cross-community visibility**: 跨境可见性差
- **Resource release**: 资源发布率低

---

## 实验结论

- **方法**: bibliometric annotation + 趋势分析
- **关键观察**: 中国作者主导，海外仅集中 Classical Tibetan

---

## 局限性

- 仅 metadata 分析，不做下游 benchmark 对比
- 140 篇样本的覆盖范围依赖 ACL Anthology + DBLP

---

## 实现建议

- **实现难度**: 低（survey 论文）
- **预期性能**: 作为低资源 NLP 范式参考
- **适用场景**: 低资源语言 LLM 路线图设计；Global South NLP 政策
