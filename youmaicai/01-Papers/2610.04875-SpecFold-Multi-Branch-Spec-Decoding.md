## 核心贡献

1. **新冗余维度**：在 dLLM 多分支推测解码中，draft branch 继承父分支大部分 token → **分支间隐藏状态高度相似** → 大量计算冗余。
2. **SpecFold 算法-系统协同设计**：
   - **算法**：token-level residual gating，通过 folded attention + FFN 选择性复用父分支计算，同时保留残差 hidden state。
   - **系统**：Triton kernel 高效实现稀疏多分支执行。
3. **与时间维度的正交性**：SpecFold 与现有 temporal caching（如 Spiffy）正交，可叠加。

## 模型架构 / 方法

- **多分支推测解码**：dLLM 在单次 forward 中验证主分支 + 多个 draft 分支。
- **Branch redundancy**：draft 分支仅少量位置 unmask → 隐藏状态 ≈ 父分支 → 复用父分支计算。
- **Folded Attention / FFN**：在保持残差连接的同时显式复用父分支中间结果。

```python
# 概念示意
hidden_draft = residual + folded_attn(parent_hidden, parent_kv) + folded_ffn(parent_hidden)
```

## 实验结果

| 基准 | 加速 |
|------|------|
| vs Spiffy | up to **1.64×** |
| vs vanilla decoding | up to **1.99×** |
| 模型家族 | 2 个 dLLM 家族，5 个模型 |
| 基准 | 5 个标准基准 |

任务性能（accuracy）与基线相当。

## 局限性

- 主要依赖 Triton kernel，在其他后端（CUDA-only / TPU）上的可移植性未深入讨论。
- 对块大小 / 分支数量的敏感度需进一步分析。
