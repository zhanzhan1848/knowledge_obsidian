# SocialArena: Evaluating Social Intelligence in Large Language Models

## 摘要
LLM 正被部署到心理咨询、陪伴型聊天机器人、教育辅导等社会性交互应用中，但现有评测是碎片化的——多聚焦孤立能力或单一场景，且**评测可靠性几乎未经验证**。本文提出 **SocialArena**：首个系统性定义与评测 LLM 社会智能（social intelligence）的基准。三项贡献：(1) 提出统一的三层能力框架，把社会智能定义为 **role-playing ability（角色扮演）、mental state reasoning（心理状态推理，即 Theory of Mind）、behavioral reasoning（行为推理）** 三个维度，并设计带显式"角色思考"的 role-playing 对话范式以一次性评测三者；(2) 提出 **U-TRIMF** 框架用于合成具有广泛覆盖的社会情境，避免结论被局限在特定场景；(3) 为获得可靠评测，投资 **$132.4K** 招募并培训人工标注者，采用 arena 式人类标注协议——标注者比较模型回复、给出偏好标签并附自然语言批评。数据集共 **5,702** 个社会情境与 **17,676** 条人工投票，评测 **15** 个前沿 LLM（gpt-5.1、qwen3-max、doubao-seed-1.8、claude-sonnet-4.5、gemini-3-pro、minimax-m2.1、kimi-k2.5、glm-5、qwen3.5-397b-a17b、gpt-4o、gemini-3-flash、glm-4.7-flash、qwen3-32b、gpt-oss-20b、olmo-3.1-32b-think），并用 Elo 排名。论文为 EMNLP 2026 oral。

## 核心贡献
1. **三层社会智能定义框架**：Role-playing（保持语言风格、情感基调等角色属性一致）+ Mental state reasoning（推断自己与他人的心理状态）+ Behavioral reasoning（判断何种回应/行动最恰当并有效执行）。定义要点：前两者与场景无关，行为推理高度场景依赖。
2. **U-TRIMF 场景合成框架**：六个正交维度（User Presence / Topological Relation / Relational Model / Interest Structure / Motivational Type / Formality）自顶向下穷举子类别，保证社会情境空间的广泛覆盖。
3. **人类中心 arena 式评测协议**：每对模型打 50–80 场 battle，每场至少 3 名标注者独立标注取多数票，三人全不一致的样本丢弃；强制逐维度（9 个维度）撰写自然语言批评。
4. **SocialArena-RewardBench**：专门评估 LLM-as-a-Judge 在社会智能任务上与人类的一致性——结果显示 LLM judge 显著落后于人类。
5. **细粒度诊断**：从人工批评中构建 **100 条代表性评测 rubric**，揭示"感知强、行动弱"的系统性缺陷与"能力幻觉"（role-playing 表现均衡但推理维度大面积负面）。

## 方法与架构
### 1. U-TRIMF 六维框架
| 维度 | 子类别 | 理论来源 |
|---|---|---|
| User Presence | U1 Real-world（LLM 作为受现实约束的角色，无用户）；U2 User-centered（服务用户特定需求，用户在场并驱动情境演化） | — |
| Topological Relation | T1 Individual（被排除：独处不构成社交）；T2 Dyad（伴侣、医患、师生、买卖双方）；T3 Group（团队、家庭、读书会、同事） | Topology [27] |
| Relational Model | R1 Communal Sharing（母子、恋人、亲子）；R2 Authority Ranking（CEO/员工、顾问/研究生、上级/士兵）；R3 Equality Matching；R4 Market Pricing；R5 Null | Relational Models Theory [15] |
| Interest Structure | I1 Zero-sum；I2 Negative-sum；I3 Positive-sum | Game Theory [17] |
| Motivational Type | M1 Physiological；M2 Safety；M3 Belonging；M4 Esteem；M5 Self-actualization | Maslow 需求层次 |
| Formality | F1 Informal；F2 Formal | Social Formality [24] |

### 2. 情境合成三步流水线（合成模型 Qwen3-235B-A22B-Instruct-2507）
- **Step 1 基础模板构建**：从六个维度各**均匀采样**一个子类别，组合成基础情境模板。
- **Step 2 关键词引导合成**：从大语料中随机采样 **10 个关键词**作为软引导；每个生成样本包含 plot summary（情节概要）、current scene description（当前场景描述，可含角色描述）、dialogue history（对话历史）、next speaker（下一位说话者）。
- **Step 3 质量过滤**：迭代制定覆盖复杂度、逻辑连贯性、安全性、与人类价值观一致性的经验规则做自动初筛，通过后再人工复审（不合格/边界样本丢弃，分歧通过讨论解决）。

### 3. 模型输出格式设计
被测模型须以角色扮演形式生成两部分：**显式角色思考轨迹**（推理参与角色的心理状态并分析当前场景以制定恰当行为）+ **最终行为输出**（回复与动作）。两个提升标注质量的设计：
- **(1) 结构化心理状态推理**：要求模型按 **7 个 ToM 类别**组织心理状态推断——emotions、desires、intentions、percepts、knowledge、beliefs、non-literal communication（采用 Beaudoin et al. 的分类）；不同场景不必覆盖全部七类。
- **(2) 仅结果标注行为**：行为推理只判断最终行为，不论推理步数与推理策略（与 RLVR 的 outcome-reward 范式一致）。试点标注研究发现自由形式的角色思考导致标注质量差——心理状态推断在不同位置任意交错，行为推理可能反复回溯自我修正，导致标注者难以定位相关片段。

### 4. 评测协议
- 社会情境 $S(p,b,h,n)$：$p$ 情节概要、$b$ 当前场景、$h$ 对话历史、$n$ 下一位说话者。两个匿名模型各生成单轮回复 $y_A,y_B$（均以角色 $n$ 身份）。
- 标注者给出偏好标签 $l\in\{A,B,T,G\}$（A/B 表示哪方更好，T 表示两者都好，G 表示两者都差），并附可选的自然语言批评。排行榜由 **Elo** 评分（[13]）从两两对局结果计算。
- **质量保证**：每个样本至少 3 名标注者独立标注，取多数票；三人全不一致的样本**丢弃**。
- **可解释性**：要求标注者**必须**提供自然语言批评，并按 **9 个维度**分别标注——7 个 ToM 心理状态维度（T1–T7）、整体角色思考质量（T）、行为恰当性（B），而非单一整体判断。
- 标注指南（Table 5）要点：Thinking Evaluation 遵循"正确性优先"（任一心理状态推断客观错误即整体落选）、"效用其次"（正确但冗余的分析记 T）；Behavior Evaluation 规定三条例外——长期利益优先（避免因妥协显弱而短期解决、长期埋雷）、坚守道德底线（违法 vs 个人利益冲突时选道德；对方有道德过失如欺骗偷窃时不要共情）、角色一致性（角色被明确描述为心理创伤/极度愤怒/胆怯时不得违背既定特质）；Factual Grounding——场景背景中找不到且无法合理推断的内容计为事实错误并扣分；Conflict Weight——只有一个回复覆盖某心理状态维度时，只有在该覆盖产生"实质性更好的行为"时才在该维度胜出，否则记 T，两者都未覆盖则留空；Comment 要求必须指出 A、B 的具体优缺点，**禁止抽象描述**（如"更全面""更清晰"）。
- **标注者质控**：通过第三方标注供应商招募，母语英语者与母语中文者大致各半；每批次抽取每位标注者少量提交项由内部专家独立复审，**质量通过率低于 75% 的批次其标注被移除**，并给予针对性反馈与再培训。

### 5. 标注一致性分析
在四类标签空间 {A,B,T,G} 上，比较三人一致模式分布与"均匀随机猜测"的理论基线：

```math
p_{full}=\binom{4}{1}\left(\frac{1}{4}\right)^3=6.25\%,\qquad
p_{maj}=\binom{4}{1}\binom{3}{2}\left(\frac{1}{4}\right)^2\frac{3}{4}=56.25\%,\qquad
p_{dis}=\binom{4}{3}\cdot 3!\cdot\left(\frac{1}{4}\right)^3=37.50\%
```

| 一致模式 | 随机基线 | 本文标注 |
|---|---|---|
| 完全一致 (3/3) | 6.25% | **39.18%** |
| 多数一致 (2/3) | 56.25% | 52.54% |
| 完全不一致 (0/3) | 37.50% | **8.29%** |

完全一致率比随机高 6 倍以上，完全不一致率比随机低 4 倍以上。

### 6. 偏差量化
- **长度偏差**：胜者仅在 **51.05%** 的比较中更长，平均长度差 **14.0 tokens**、中位数 **3.0 tokens**，接近随机水平。
- **位置偏差**：投票偏向 B 为 43.63% vs A 的 39.23%，仅轻微位置效应。
- 其他缓解设计：角色扮演输出偏短，迫使标注者关注内容而非文风；不像 LMArena 那样只有单一偏好判断；要求为每个偏好提供理由。

## 实验设置
- **模型（15 个）**：gpt-5.1-2025-11-13、qwen3-max-2026-01-23、doubao-seed-1-8-251228、claude-sonnet-4-5-20250929、gemini-3-pro-preview、minimax-m2.1、kimi-k2.5、glm-5、qwen3.5-397b-a17b、gpt-4o-2024-11-20、gemini-3-flash-preview、glm-4.7-flash、qwen3-32b、gpt-oss-20b、olmo-3.1-32b-think。
- **对局规模**：任意两模型之间进行两两评测，每对 **50–80** 场 battle；每 battle 至少 3 名独立标注者，多数票定胜负；最终用 Elo 排名。
- **数据规模**：5,702 个社会情境、**17,676** 条人工投票；场景原型 **600** 个（对照 Table 1）。
- **SocialArena-RewardBench**：从 SocialArena 随机抽取样本，由 3 名人类专家按同协议标注并交叉验证，产出 **152** 条样本。指标：**ACC@Label**（偏好标签 A/B/T/G 与人类金标准一致）与 **ACC@Critique**（自由文本批评与人类参考批评语义一致，以 F1 相似度 ≥ **0.5** 判定，沿用 Wang et al. 2026 的阈值）。
- **场景级分析**：对每个典型场景随机对半拆分，计算模型排名的成对 **Kendall τ** 相关。

**人类批评的高频维度（Figure 3，Top-10 聚类中心）**：10 个中心中有 **6 个**属于 Behavior Reasoning（成熟社交能力与关系建立、切实解决实际问题与核心关切、用心培养维护人际关系、推动事情真正落地、在冲突中促成降级与破冰、提出兼顾原则与灵活性的可执行方案、务实高效地推动事情完成、影响关系的形成维护与修复），远超 ToM 相关维度；负向批评在几乎所有高频维度上系统性压过正向批评，在"驱动事情真正完成""冲突降级"等长程目标维度上尤为明显；人类评判依据**关系性结果**而非回复正确性，与传统 NLP 评测（helpfulness/harmlessness/factuality 的单轮正确性假设）存在范式错配；Role-playing 维度的正负分布相对均衡，而 Behavior 与 ToM 推理维度几乎全负，作者称之为**能力幻觉**——既有基于角色扮演的社会基准可能系统性高估模型的真实社会智能。

**场景级排名稳定性（Figure 5，Kendall τ 热力图）**：conflict、friendship、strangers、family、superior-sub、roleplay/TRPG、romantic 等场景**内部**排名一致性高但**跨场景**相关性低，说明模型排名确实是场景特异的——既验证了多样场景覆盖对整体排名的必要性，也说明针对特定部署应参考场景专属排名。例外是 workplace、neighbors、business，它们的排名与 conflict 高度相关，原因是与 conflict 标注的互动共现度高、场景重叠大；而 conflict 频率低的场景（romantic、roleplay/TRPG、friendship）与 conflict 排名的相关性明显更弱。

## 关键公式与代码
关键公式为标注一致性的随机基线推导（式 1–3）与 Elo 评分（引用 Elo 1966）。评测平台 **SocialArena-Platform** 计划发布：用户提交真实社交困境、免费使用多个 SOTA LLM 与社区成员作答、以社区点赞与评论作为可扩展评测机制；数据质控包含过滤非社交任务 prompt、套用与基准相同的情境合格标准、沿用 Chatbot Arena 的异常 IP 检测规则。

## 局限性
作者自述：
- **潜在偏差**：对话式 AI 的人类偏好受个人背景、沟通风格与主观期待影响；当前数据集由**母语英语与中文**标注者完成，可能引入偏见。缓解措施是开发并计划发布公开平台 SocialArena-Platform（类似 Chatbot Arena）以纳入更广泛的社区参与，待数据充足后更新结果。
- **多轮对话缺失**：采用单轮评测，因为初步的小规模标注显示多轮设置标注成本更高，而单轮场景已能满足大部分评测需求；待单轮数据积累充足后，将在平台上启用多轮功能以降低成本。
- 其他：情境本身可能含不健康或不安全内容（如违法或不道德材料），平台实施严格过滤机制将其排除在展示与排行榜更新之外。

我的补充批评：(1) 场景合成的六维均匀采样只保证**组合空间**上的均匀，但每个维度的子类别是否等权、生成模型是否引入文化偏置（如中式职场/家庭脚本占主导）未被检验，而英语+中文标注者与英文场景的组合会系统性偏好评判标准；(2) Elo 排名基于 50–80 场/对，顶部三名仅差 1.5 分（1400.0 vs 1398.5），远小于该规模的统计噪声，论文未报告置信区间或显著性，排名不应被过度解读；(3) 只用"角色思考"这一种提示格式来同时暴露三项能力，模型"是否会主动展开思考"本身成为混淆变量——这可能部分解释"行为推理最弱"的结论；(4) 人工标注 $132.4K 的成本换来的样本量（5,702 情境、17,676 票）相对于 15 模型两两比较所需的统计量仍然偏薄。

## 评估与建议
- 是否推荐深入阅读：是（作为"社会智能"的可操作定义、U-TRIMF 场景合成框架与"LLM-as-judge 在此类任务上不可用"的数据证据，都具有直接方法论价值）
- 适用场景：社交/情感/角色扮演类模型的评测设计；心理支持、陪伴、教育辅导 NPC 等应用的模型选型；任何需要"感知—推理—行动"分层诊断的 agent 评测；human preference 数据采集与标注质控设计。
- 与知识库的关联：与 ToM 类基准（OpenToM、ToMATO、SimpleToM）、情感智能基准（EQ-Bench3、SAGE）、角色扮演基准（CoSER、InCharacter、CharacterBench、RMTBench）构成完整谱系（见论文 Table 1 的对照）；与 RLVR 的 outcome-reward 范式呼应（行为只判结果）；可与 2610.39247 之外的 safety/alignment 类"人类偏好是否可靠"讨论并列（如 LMArena 类偏差讨论）。
