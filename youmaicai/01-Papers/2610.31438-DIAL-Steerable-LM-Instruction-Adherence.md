## 核心贡献

> 提出 **DIAL**（Distilled Instruction-Adherence Levels），同时实现**细粒度控制 + 高效 + 可扩展**三条属性 —— 用 **CFG 产生训练信号** + **轻量 steering adapter**。

1. **动机**：用户说"keep it short"时，"多短"是模糊的。Prompting 无法可靠提供**细粒度数值控制**。
2. **三属性**：
   - **细粒度控制**：用 **classifier-free guidance (CFG)** 配合 frozen LLM，为 **on-policy distillation** 提供不同遵从等级的**训练信号**；
   - **高效**：设计**轻量 steering adapter**，用 LLM hidden states 上的**分类器**计算**闭式 steering edit**；
     - 分类器**按 token 自适应**设定 steering 幅度，以匹配目标遵从等级；
     - 同时**考虑 hidden state 的几何**以保持连贯性；
   - **可扩展**：分类器是 **text-conditioned** → 共享 adapter 可支持**新指令**，无需 per-instruction 拟合；训练只需 instruction + request 文本。
3. **数据集**：**SteerIF** — instruction-only，**98,625** 条，涵盖 concept / persona / verifiable / descriptive 四类指令。

---

## 技术方案

| 组件 | 说明 |
|------|------|
| CFG-based signal | frozen LLM + CFG 生成不同 adherence level 的 on-policy 轨迹 |
| Steering adapter | 轻量；hidden state 分类器 |
| Closed-form edit | 分类器 → 闭式 steering 向量（非逐层调参）|
| Token-adaptive magnitude | 每 token 自适应强度 |
| Geometry-aware | 保持 response coherence |
| Text-conditioned classifier | 支持未见指令，共享 adapter |

### 关键洞见

- 与 [[2610.31472 / DIAL-adjacent steering work]] 不同，DIAL 的 steering **不是逐指令拟合**，而是**一个 text-conditioned 分类器** → 泛化到新指令。
- CFG 从 frozen LLM 里"抽出"不同强度档位 —— 这是把连续控制量离散化为可蒸馏档位的实用技巧。

---

## 实验结论

- **跨多个 LLM 家族**评测：
  - 在 **concept expression** 与 **response fluency** 之间取得**竞争性平衡**；
  - **concept score 随 adherence level 单调上升**（可控性验证）；
- **SteerIF 训练后**：
  - 对 **persona** 提供细粒度控制；
  - 与 prompting 结合时**提升 verifiable instruction following**。

---

## 局限性

- 数值等级（1–5 之类）仍是**离散档位**，非真正连续；
- 分类器需 hidden states → **依赖权重访问**（不能用于纯 API 模型）；
- 未评估对 factual accuracy 的影响。

## 实现建议

- **实现难度**：中（需自建 CFG 数据生成 + 训练 adapter）
- **预期价值**：高 — 产品化的"语气/长度/人格"调节需求非常普遍
- **适用场景**：内容生成平台、客服人格配置、可控摘要
- **建议部署**：作为**后置 adapter** 挂在已有模型上，不动 base 权重
