# TASCO: Stability-Aware Test-Time Adaptation for LLM Reasoning

| 标题 | Beyond Confidence: Stability-Aware Test-Time Adaptation for LLM Reasoning |

| 作者 | Bincheng Gu, Min Gao, Zongwei Wang, Yibing Bai, Yulan He, Junliang Yu |
| 链接 | [原文](https://arxiv.org/abs/2609.11393) |

| 领域 | Test-Time Adaptation, LLM Reasoning, Confidence |

## 核心贡献
1. **问题发现**：高置信度 ≠ 正确性，LLM 可能在错误推理轨迹上保持高置信度
2. **核心观察**：高置信度推理在局部扰动下保持稳定时更可能正确
3. **TASCO 框架**：Test-Time Adaptation via Stability-Aware Confidence Optimization，保持 LLM frozen，优化轻量级 task-level prefix
4. **两种扰动策略**：
   - **Random Perturbation**：促进由 nearby perturbed prefixes 诱导的轨迹间分布稳定性
   - **Sharpness-Aware Perturbation**：针对最坏情况局部敏感性

## 方法
```
LLM frozen
  → 给定推理任务 + task-level prefix
  → 在 prefix 上应用 Random/Sharpness-Aware Perturbation
  → 优化 prefix 使 confidence 在扰动下保持稳定
  → 输出稳定的高置信度推理
```

## 实验结果
- 提升 diverse LLMs 和 reasoning benchmarks 的推理准确率和 token 效率
- 行为分析：在局部扰动下保持稳定置信度，不过早集中模型预测分布

## 局限性
- 需要为每个任务学习一个轻量 prefix
- 对不同推理类型的泛化待验证
