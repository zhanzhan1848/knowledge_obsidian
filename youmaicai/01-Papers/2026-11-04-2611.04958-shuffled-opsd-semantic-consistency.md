## 核心贡献
1. 识别出 OPSD 中一个此前被忽视的**独立设计维度**：**student 与 teacher 共享的 problem statement 的语义结构**。既有工作几乎全部聚焦于"teacher 能拿到什么特权信息"（reference 是否正确、暴露多少推理、reference 是否相关），而**共享 problem 通常保持原样**。
2. 提出 **Shuffled OPSD**：先做 **UnrelatedRef**（把 teacher 的 target-associated 解替换为**另一个题目的完整 worked example**，两者都保持完整、只对 teacher 可见），再**打乱 student 与 teacher 共同看到的 problem 的词序**，而 **teacher-only 的 worked example 保持完整**。该变换**保留每个词及其频率**（包括词内的数字与符号串），只破坏顺序。
3. **核心结果**：三个数学推理基准、三个 Qwen3 规模上，Shuffle-1 在三基准平均上分别比 Standard OPSD 高 **3.52 / 1.11 / 1.38 个百分点**（Qwen3-1.7B / 4B / 8B）；比 UnrelatedRef 高 **3.98 / 0.56 / 1.11**。**评测始终使用原始未修改的题目**。
4. 提出并实证**"选择性语义扰动"（selective semantic disruption）原则**：共享 problem 与 teacher-only reference 的结构角色**不对称**——打乱共享 problem 有益，打乱 reference 则有害（AllShuffle-1 比 Shuffle-1 低 **2.41 / 0.65 / 1.57** pp）。
5. **UnrelatedRef 本身几乎无损**：teacher 的 reference 与 target 不配对，三基准平均与 Standard OPSD 的差异**至多 0.55 pp**（1.7B 上 −0.46、4B 上 +0.55、8B 上 +0.27）——这意味着 **OPSD 的"正确配对"并非必要条件**。
6. **保留更大的词块没有优势**：Shuffle-1 > Shuffle-4 > Shuffle-8（1.7B：42.78 vs 41.02 vs 40.65；4B：63.06 vs 62.22 vs 62.87）——**保留更多局部词序并不提升性能**。
7. **CrossShuffle 与 NoTarget 低于 Shuffle-1**：跨题混合词（41.11 / 62.78 / 63.43）与完全去掉题面（41.76 / 61.95 / 62.22）在所有规模上都更差——说明**题目特有的词汇与符号内容比完整句法或连贯表层形式更重要**。
8. **增益来自"更可靠"而非"解更多题"**：1.7B 上 Avg12 38.80 → 42.78、**Vote12 48.89 → 52.22**，而 **Pass12 保持 61.11% 不变**；4B 上 Avg12 62.50 → 63.06、Vote12 67.78 → 72.22，Pass12 变化也很小。
9. **KL 分析揭示"发散幅度 ≠ 性能"**：在相同 Shuffle-1 前缀上，teacher–student 的 $D_{KL}(p^T\|p^S)$（nats，排除首个生成位置）在 thinking 模式下比 non-thinking 高 **+0.1186 ~ +0.1362**；**打乱 reference 会提高 KL 却降低最终准确率**——说明 OPSD 由"在哪里收集监督"与"在那里提供什么 teacher 分布"**共同**决定。

## 问题背景
LLM 的后训练方法（RL、SFT、知识蒸馏）中，**on-policy distillation** 结合了两个有用的性质：student 在**自己策略采样的轨迹**上学习，而 teacher 在这些轨迹上提供**稠密的 token 级监督**。

**On-policy self-distillation (OPSD)** 进一步取消了独立 teacher 模型：teacher 与 student 由**同一 backbone** 在**不同上下文条件下**实例化。Student 只看到题目并生成自己的回答；冻结的 teacher 在看到**特权上下文**（如 worked solution）的情况下对相同前缀打分。

既有 OPSD 工作几乎全部研究 **teacher 能拿到什么特权信息**：teacher 是否需要正确解、暴露多少推理、有用学习在 reference 缺失或无关时是否仍持续（Shrestha & Tessier 2026; Zhang et al. 2026; Shen et al. 2026; Li et al. 2026; Zhao et al. 2026b）。这些结果暗示**更丰富或语义上更相关的 teacher 上下文并不总能转化为更好的 student**。

但**共享 problem 的角色不同**：
- 它决定 student 生成哪些轨迹，因此决定**哪些前缀被监督**；
- 它同时条件化用于计算蒸馏损失的 student 与 teacher 分布；
- 其结构因此同时影响**学习发生在哪里**与**teacher 提供什么反馈**。

作者的提问很直接：**保持共享 problem 的语义结构是否真的能改善 OPSD？刻意破坏它是否可能产生更好的 student？**

论证的关键在于：**OPSD 是通过 teacher 在 student 生成轨迹上的反馈来训练的，而不是直接奖励输入的语义连贯性。** 一个更容易解释的题面，未必能诱导出导向更好学习的轨迹与监督。这引出作者的核心比喻：**把共享 problem 当作一个"训练接口"（training interface），其结构可以不同于推理时使用的完整题目。**

作者也诚实地指出反方向的张力：**破坏词序对数学推理看起来是反效果的**——这正是该实验有趣的地方。

## 方法

### 1. OPSD 形式化
Student 在 mode $m_S$ 下为 target $x$ 生成续写 $\tau$；冻结的 teacher（初始参数 $\theta_{teacher}$）在带 reference $r$ 与 mode $m_T$ 的条件下对**相同前缀**打分：

$$
p^{T}(\cdot \mid x, r, m_T, \tau_{<t}) = \pi_{\theta_{teacher}}\big(\cdot \mid x, r, m_T, \tau_{<t}\big)
$$

$$
p^{S}(\cdot \mid x, m_S, \tau_{<t}) = \pi_{\theta_{student}}\big(\cdot \mid x, m_S, \tau_{<t}\big)
$$

两模型都看到 target，因此 target 是**共享的**。reference 提供**仅对 teacher 可见的上下文**，而不是给 student 模仿的独立输出序列。

训练目标（在受监督位置 $t \in \mathcal{T}$）：

$$
\mathcal{L} = -\sum_{t \in \mathcal{T}} \log \pi_{\theta_{student}}\big(\tau_t \mid x, m_S, \tau_{<t}\big) \cdot \text{(capped signed KL from teacher)}
$$

**关键细节**：该损失在求和前把每个有符号的 teacher→student KL 贡献**从上方截断**（因此**不是普通 KL**）。teacher 输出、采样 token 与采样概率在求导时**全部固定**。

**默认设置**：student 用 **non-thinking mode**，teacher 用 **thinking mode**（按各自 chat template）。

### 2. 两个设计维度的分离
作者区分输入结构的两个层面：
- **(a) reference 是否回答 target 问题**（reference 的**相关性**）；
- **(b) 每个输入内部的**内容组织方式**（reference 与 problem 的**内部结构**）。

论文符号：$x$ = target problem，$r$ = 仅 teacher 可见的 reference，$T$ = 共享 problem 的一个变换。

**变换 $T$ 同时改变 student 的 rollout 分布与两个模型在结果前缀上的预测**；而 **reference 的选择只改变 teacher 的反馈**。因此二者是**可分离的设计选择**。

### 3. UnrelatedRef（第一个干预）
Standard OPSD 把每个 target 与其**关联的解**配对。UnrelatedRef 保留完整题面，但把 reference 替换为**来自另一个题目的完整 worked example**：

$$
r' = (x_{r}, y_{r}), \qquad x_{r} \neq x
$$

$x_r$（reference 题目）与其 worked solution $y_r$ **都保持完整**，且**只对 teacher 可见**。该 reference 配对在训练期间**固定**，并被后续所有共享 problem 的干预复用。

UnrelatedRef 检验的是：**teacher 是否真的需要针对具体 target 问题的解**。它同时也是 Shuffled OPSD 的起点。

### 4. Shuffled OPSD
在 UnrelatedRef 基础上，打乱 student 与 teacher 共同看到的题面，而 teacher 的无关 worked example **保持完整**。

按**空白符边界**切分题目为词，再把词分组为连续的块，每块含 $b$ 个词（最后一块可少于 $b$ 个）。采样一个置换 $\pi$，并**对该样本在训练期间保持固定**：

$$
T(x) = \pi(x) = \text{join}\big(\text{blocks}_{b}(x)[\pi]\big)
$$

**主变体 Shuffle-1** 打乱**单个词**。它**保留每个词及其频率**，包括**词内的数字与符号串**，只破坏顺序。更大的块保留更多局部顺序，用于检验该结构是否有价值。

流程：student 从 $T(x)$ 生成；冻结 teacher 用 $T(x)$ 与 $r$ 作为上下文对同一续写打分；student 用 Equation 5 的损失更新。**损失、优化器与 reference 配对相对 UnrelatedRef 完全不变。推理时 student 接收原始完整题目，不带额外 reference。**

作者把这称为 **selective semantic disruption**：移除 problem 与 reference 的关联、破坏共享 problem 的顺序、**保留 teacher worked example 的内部结构**。

### 5. 对照条件（控制实验）
- **Shuffle-$b$**：改变保留多少局部词序（$b=1,4,8$）。
- **CrossShuffle**：把词在**所有训练题目间**汇集、全局置换，再按各样本**原词数**重新分配。它同时破坏词序与题目归属，但**保持全语料的词数**。
- **NoTarget**：移除具体题面及其 wrapper，**保留通用指令**。
- **AllShuffle-$b$**：对**共享 problem 与 teacher reference 都**施加块置换。
- **AllShuffle-1**：分别置换 target problem、reference question 与 reference solution 中的词。
- **NoTarget-NoRef / NoTarget-SameMode**（Table 2）：在 NoTarget 下分别移除 reference、把 teacher 切到 non-thinking mode。

## 实验结果
- **Dataset/Task**: **Qwen3-1.7B / 4B / 8B**，用 **LoRA** adapter；训练样本来自原始 OPSD 研究使用的 **OpenThoughts 数学推理子集**。**所有条件 50 个 optimizer step**，batch size 16，学习率固定，**训练种子 42**。Teacher 是冻结的初始 backbone（thinking mode），student 用 non-thinking mode 生成，rollout 上限 1,024 token。评测：**AIME 2024 / AIME 2025 / HMMT February 2025**，每基准 30 题，**使用原始未修改题目、无 teacher-only 上下文**；thinking mode 每题采样 12 次，temperature 与 top-p 固定，最多 38,912 新 token。**Avg@12 为主指标**，三基准等权平均。统计：**配对 95% 置信区间**用 **10,000 次 problem-cluster bootstrap**（同一题的所有响应聚在一簇，跨条件用匹配的问题索引）。

## 关键洞察
1. **语义连贯性不是普遍有益的原则。** 全文的"反直觉"核心：把数学题的词序打乱，训练出的模型在**完整题目**上反而更准（1.7B 上 +3.52 pp）。这挑战了"输入应保持语义一致"这一在数据增强中常被默认遵守的假设。
2. **共享输入与特权输入的语义结构扮演不同角色。** 共享 problem 决定**在哪里**收集监督（哪些轨迹被生成、哪些前缀被打分）；reference 决定**在那里提供什么 teacher 分布**。打乱前者有益、打乱后者有害——这个不对称是全文最有价值的结构性发现。
3. **"正确的配对"不是 OPSD 的必要条件。** UnrelatedRef（teacher 拿到的是**另一个题**的解）与 Standard OPSD 的差异**至多 0.55 pp**。这意味着 OPSD 的有效信号**不主要来自 reference 与 target 的对应关系**，而更可能来自 teacher 在 student 轨迹上提供的**稠密 token 级分布监督**本身。
4. **题目特有的词汇/符号内容 > 表层连贯性。** CrossShuffle（跨题混词，保持词数）与 NoTarget（完全去掉题面）在所有规模上都比 Shuffle-1 差。→ **打乱顺序是安全的，替换内容是不安全的**。
5. **保留更多局部结构没有价值。** Shuffle-1 ≥ Shuffle-4 ≥ Shuffle-8——不需要精细的块大小调参，**最激进的扰动反而最好**。
6. **增益来自可靠性而非覆盖度。** Pass12 基本不变而 Vote12 上升 3.3–4.4 pp：模型在**已经能解的题**上变得更少犯"抽签式"错误。这对"用 pass@k 作为唯一指标"的评测习惯是一个提醒。
7. **KL 幅度不是性能指标。** 打乱 reference 使 teacher–student KL 从 0.0419 升到 0.0507（non-thinking）却降低准确率。→ **"监督信号更强"不等于"学习更好"**；分布发散的绝对幅度不能作为选择蒸馏配置的依据。
8. **"训练接口"可以与"推理输入"解耦。** 论文提出的这个概念有超出 OPSD 的普适性：训练时的输入格式可以是一个与推理时不同的"接口"，只要它能诱导出更好的学习信号。这是一个值得被更广泛检验的设计范式。

## 局限性
- **训练极短**：所有条件只跑 **50 个 optimizer step**、batch size 16、**单一训练种子 42**。论文用 10,000 次 problem-cluster bootstrap 给评测做了 CI，但**训练侧的随机性完全未做重复**——3.52 pp 的差异在单一训练种子下可能包含相当大的训练方差成分。
- **只测了 Qwen3 家族**（1.7B/4B/8B）、只测了数学推理（OpenThoughts 子集 → AIME/HMMT），未验证其他模型族、任务类型或更大规模。
- **teacher 必须是 thinking mode、student 必须是 non-thinking mode**——这一模式差异本身可能就是增益来源的一部分（Table 2 显示 SameMode 掉 2.78 pp），论文没有把"打乱题面"与"模式差异"完全解耦到同等强度。
- **评测的 benchmark 规模小**（每基准 30 题），Avg@12 的分辨率有限；AIME 级题目上的 3 pp 差异对应约 1–2 道题。
- **教师上下文被破坏是否会损害较弱的 student** 未测；本文所有 student 都是 ≥1.7B 的指令模型。
- **对其他 OPSD 变体（reference 缺失、trajectory-conditioned teacher、pseudo-solution 等）的交互未验证**——这些研究本身就表明 reference 相关性有影响，本文结果是否与它们兼容未讨论。
- **NoTarget 条件在 4B/8B 上反而不如 Shuffle-1**，说明"完全去掉题面"在更大模型上并非降级——这削弱了"题面内容重要"的推论强度，需要更多规模点来判断趋势。
- **词序置换在中文等无空格语言上不适用**；论文只处理英文数学题。
- **未与更多数据增强方法对比**（如去噪式预训练、指令改写），只与 OPSD 变体对比。
- 置换种子固定但未报告跨种子的方差；block 划分（按空白符）对 LaTeX 公式、代码块等结构的处理未讨论。

## 适用场景
- **适用**：on-policy self-distillation / context distillation 的输入设计；数学推理的小数据后训练（本文仅 50 step + LoRA 就见效）；需要为 student 构造"训练接口"而非直接用推理格式的场景；研究蒸馏中哪些输入结构真正重要的分析型工作。
- **不适用**：**对输入连贯性有硬性要求**的任务（自然语言理解、客服、指令遵循、抽取式任务——打乱题面会破坏可读性且收益未知）；非英语或无空格分词的语言；teacher 必须提供**对应 target 的**正确解才能提供有效监督的场景（本文结论依赖"reference 关联性不重要的"这个前提，而该前提在其他任务上未必成立）。
- **不适用**：追求大样本充分训练（本文只验证了 50 step 的极短训练 regimen，长训练下打乱题面的效果未知，且很可能更接近无增益）。
