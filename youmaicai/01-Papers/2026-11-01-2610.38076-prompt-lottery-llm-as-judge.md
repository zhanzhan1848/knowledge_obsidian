# Prompt Lottery in LLM-as-a-Judge: Measuring and Mitigating Sensitivity to Syntactic Rephrasing

## 摘要
本文提出 **Prompt Lottery** 现象：语义等价的 prompt 改写（paraphrastic rephrasing）在固定评测任务下会产生不同的 LLM-as-a-Judge 判断。作者在 **825 个实验条件**（12 个数据集、6 个 judge family、5 个 backbone 模型、每族 5 个 prompt 变体）上系统研究，发现一致性从近乎完美（Fleiss' κ = 0.89）崩塌到仅"尚可"（κ = 0.24），远大于人类标注者面对同样 paraphrase 时的波动（Δκ ≈ 0.09–0.11），也低于人类研究普遍接受的 κ > 0.61 阈值。变体不仅改变绝对分数，还会在客观 QA 任务上**逆转模型排名**（SQuAD v2 上 Kendall's τ = 0.17，Top-1 翻转率 43.3%）。缓解方面：plurality 聚合（需 >50% 共识）对齐人类最好（Upheld r = 0.63），并用 DeBERTa-v3 分类器做选择性聚合，把 LLM 调用从 5× 降到约 2×（−60%）同时保留全量聚合 86% 的效果。

## 核心贡献
1. **Prompt Lottery 的定义与量化**：paraphrase 不变性（paraphrastic robustness）作为 LLMaJ 的核心可靠性要求，并给出系统度量。
2. **大规模实证**：825 条件 × 12 数据集 × 6 judge family × 5 backbone，跨主观/客观任务的一致性崩塌与排名反转。
3. **人类基线对照**：10 名标注者、650 个数据点的用户研究（κ = 0.71 平均 pairwise），以及温度 T = 10⁻⁵ 下的稳定性上界（κ = 0.86）。
4. **缓解方案**：plurality 聚合 + DeBERTa 选择性聚合（实例级门控），成本 −60%。

## 方法与架构
**Paraphrase 生成与验证**：用 Claude 3 Opus 生成 4 个语义等价变体，人工审核保留任务语义，用 Gemini 1.5 Pro 校验语法。事后归纳出 6 个表层变异维度（role framing、instruction syntax、contextualization、output specification 等）；对 50 个 judge prompt、46 组实验、每组 10,000 次置换的 within-family 置换检验（Holm 校正）显示没有哪个维度能一致地产生更高一致性。

**语义等价性证据**：三个独立 LLM（Kimi-K2.5、Gemini 1.5 Pro、GPT-4o）给出两两 prompt 相似度均值 81% / 84% / 79%；sBERT 语义相似度平均 **0.93**（超过 0.80 阈值），但词汇重叠低（Jaccard 0.38 ± 0.01）。人工任务等价性验证：每对 prompt 由 3 名标注者判定是否同一评测任务，平均 **POMP 76/100**，Cohen's κ = 0.78，Krippendorff's α = 0.81。

**评测指标**：Overlap（判断完全一致率）、Average Pairwise Cohen's κ、Fleiss' κ、Krippendorff's α。主分析聚焦 κ 以便与人类标注研究直接比较。

**基线设定**：
- Human robustness：用户研究得 κ = 0.80（Δ0.07）
- Stability baseline：固定 prompt、5 次独立运行、每模型 100 样本 → 89.8% overlap，Cohen's κ = 0.86，Fleiss' κ = 0.89（T = 0.7 时 Fleiss' κ 降至 0.39）
- 一般可接受阈值：κ > 0.61

**Selective aggregation 期望调用数推导**：

```math
\bar t_{full} > 0.3768\times 3 + 0.2105\times 5 + 0.4127\times 5 = 4.247
```
```math
\bar t_{gated} = \mathrm{TNR}\times 1 + (1-\mathrm{TNR})\times \bar t_{full}
= 0.6942 + 0.3058\times 4.247 \approx 1.99
```
```math
\Delta_{vs.\ full} = 1 - \frac{\bar t_{gated}}{\bar t_{full}} \approx 53\%,\qquad
\Delta_{vs.\ naive} \approx 60\%
```

分类器训练：N = 369,625 训练样本，Optuna 35 次 trial 调参，留出测试集 n = 73,925；目标为最大化 TNR（假阳性仅浪费推理成本，假阴性会污染评测质量）。

## 实验设置
- **配置**：33 个组合（12 数据集 × 6 judge family），5 个 backbone：GPT-4o、gpt-oss-120B、Llama 3.3 (70B Instruct)、Kimi-K2.5(-Instruct)、Qwen3(-VL-30B-A3B-Instruct)；温度 T = 10⁻⁵。论文正文提及 845 条件，实验设置段落给出 825。
- **Judge family**：Dialogue Quality（Binary，PersonaChat/PersonaUSR/DailyDialog/Topical-Chat/ConTurE）、QA Correctness（Likert 1–5，HotpotQA/SQuAD v2/NQ-Open/TopiOCQA/NQ）、QA Groundedness、General Response Quality（Likert 1–10，含 LLM-Arena）、Summary Quality（SummEval）、Semantic Alignment（UPHELD）。
- **排名稳定性实验**：4 个被测模型（GPT-4o、gpt-oss-120B、Kimi-K2.5、Qwen3p6-Plus）× 5 个 prompt 变体，每任务 100 个评测样本，3 折平均。
- **模型消融**：DeBERTa-v3-large（LoRA）、RoBERTa-base、Logistic Regression、SVM、Llama zero-/5-shot。Hyperparameter 在单张 NVIDIA A100 80GB 上用 Optuna 搜索。

## 实验结果
**一致性崩塌**：总体一致性从近完美（κ = 0.89）跌至 κ = 0.24；75% 的 dataset-judge 配置差异显著（p < 0.05）；多数配置低于 κ < 0.61 的通用标注阈值。

**Fleiss' κ by judge family（模型平均）**：Dialogue Quality（Interesting 0.39 / Quality 0.26 / Specific 0.39 / Understandable 0.31）；QA Correctness 0.47；Groundedness 0.69；MT-Bench (Likert 1–10) 0.28；Semantic Alignment-Content 0.39；整体模型平均 0.40。模型间差异：Kimi-K2.5 κ = 0.47、gpt-oss-120B 0.44、GPT-4o 0.42、Llama 3.3 0.34、Qwen3-VL 0.33。

**Binary paradox**：二分类原始 overlap 更高（0.32 vs 0.14），但校正后可靠性更低（Fleiss' κ = 0.214，α = 0.217）vs 非二分类（κ = α = 0.28）。

**语义相似度不能解释**：sBERT 相似度与 κ 的 Pearson r = −0.11（p = 0.157），Spearman ρ = −0.15（p = 0.022）。最优 prompt 因数据集而异（UPHELD 用 P5、Topical-Chat 用 P4、LLM-Arena 用 P5），默认 prompt 仅排第 3–4 名，Δr 仅 0.00–0.02。

**排名稳定性（Table 5）**：

| 任务 | Mean τ | Top-1 Flips | Flip % |
|---|---|---|---|
| MTBench (DailyDial.) | 1.00 | 0/4 | 0.0% |
| MTBench (Persona) | 0.80 | 2/4 | 10.0% |
| QA Correct. (SQuAD v2) | 0.17 | 3/4 | 43.3% |
| Quality (SummEval) | 0.64 | 2/4 | 40.0% |
| G-Eval (Topical-Chat) | 0.83 | 1/4 | 10.0% |

**聚合策略与人类对齐（Pearson r）**：Upheld — Maj 0.47 / Avg 0.54 / Plur **0.63** / PA 0.61；Topical-Chat — 0.44 / 0.55 / **0.62** / 0.51；LLM-Arena — 0.44 / 0.54 / **0.55** / 0.52。

**选择性聚合**：

| 策略 | 计算量 | 达成 plurality 比例 | Worst-case 表现 |
|---|---|---|---|
| Single LLMaJ | 1× | 44% | – |
| Task heuristic | ~4.5× | 74% | 69% |
| DEBERTA-gate | ~2× | 86% | 65% |
| Full aggregation | 5× | 100% | 79% |

DEBERTA-gate 最终分类器 TPR 85.06%、TNR 69.42%；在 Prometheus judge 的留出数据上 TNR 稳定在 66.22%。模型消融（Bal. acc / TNR）：ROBERTA 0.914 / 0.845、Logistic 0.862 / 0.751、SVM 0.854 / 0.742、Llama zero-shot 0.489 / 0.042、5-shot 0.451 / 0.322、DEBERTA 0.836 / 0.854（为最大化 TNR 而选用）。

**共识分布**：非二分类任务中 37.68% 第 3 次判定即达 plurality，21.05% 需全部 5 个，41.27% 始终不收敛；默认 prompt 仅在 44.0% 情况下与 plurality 决策一致。

## 局限性
- 作者自述：仅覆盖保留语义的 paraphrase 变体，不涉及刻意的语义修改；语义等价性靠 sBERT（0.93）与人工判定（κ = 0.78）而非形式化蕴含来验证；仅 5 个模型家族，reasoning-augmented 模型覆盖有限（GPT-4o vs GPT-5.1 预实验 400 例、3 数据集，客观任务 κ = 0.82、对话 0.68、摘要 0.25）。
- 缓解方案只与单 prompt（下界）和全量聚合（上界）比较，未与预算匹配的替代方案（如单 prompt 自一致性采样）或正交鲁棒技术（ensemble、debate、instruction tuning）对比——作者承认收益可能部分来自"重复评判"而非 prompt 多样性本身。
- 我的批判性意见：一致性崩塌（κ 0.89 → 0.24）与排名反转（43.3%）的结论建立在 T = 10⁻⁵ 这一极低温度上，与实际使用中 T ≈ 0.7 的抽样噪声耦合；文中虽给 T = 0.7 的 Fleiss' κ = 0.39，但未把两个方差源做联合方差分解。另一处数字不一致（正文 845 vs 设置段 825）也削弱可信度。

## 评估与建议
- 是否推荐深入阅读：**是**（任何做 LLM-as-a-Judge 评测的人都应知道）
- 适用场景：设计评测流程、选择 judge 模型与 prompt 家族、降低评测成本、解释"为什么我的排行榜变了"
- 与知识库的关联：与 MASEval 等多 agent 评测工作、以及通用"评测可靠性"主题直接相关；可作为自建评测流水线的审计基线
