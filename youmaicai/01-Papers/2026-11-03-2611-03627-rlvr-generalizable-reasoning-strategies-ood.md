# Not All Reasoning Generalizes: A Case Study on Learning Generalizable Reasoning Strategies in RLVR

## 核心贡献
1. 指出 **RLVR（强化学习 + 可验证奖励）** 在**分布内（in-distribution）** 与**分布外（OOD）** 之间存在一个**被忽视的失效模式**：模型在 ID 上准确率高且推理步骤结构化，但 OOD 下**放弃推导、退化为无效的暴力枚举**，准确率断崖式下跌。
2. 澄清该失效**不是**「基座模型能力不足」，也**不是** reward hacking——因为模型在 ID 上确实用对了推理策略。
3. 提出一个**间接干预**且**出人意料地有效**的缓解手段：**与双射反演任务（bijective inversion tasks）共同训练（co-training）**。
4. 给出一个**理论分析**：仅用结果奖励（outcome-only）的 RLVR 也能**隐式地为有效推理策略记功**（implicitly credit effective reasoning strategies），因此无需过程监督也能塑造推理过程。

## 问题背景
RLVR 被广泛认为能让 LLM 推理获得**泛化性**提升。但「泛化」究竟泛化了什么——是答案、还是**推理策略**——在既有工作中很少被分开考察。当测试分布相对训练分布发生偏移时，模型可能只是记住了结果模式而非可迁移的策略：准确率仍在下降，但失败的原因（是策略失效还是知识缺失）往往被归为一谈。此外，当多个候选价值（outcome）对应同一个正确答案时，RLVR 的信号本身是**过程无关**的——这在理论上提示 RLVR 也许能塑造推理过程，但一直没有被系统验证。

## 方法

### 可控的方程求解框架

构造一个**可控的 equation-solving 框架**：给定方程 $f(x) = y$，其中 $f$ 是一个**非双射（non-bijective）的字符串函数**，任务是**找出多个满足方程的输入 $x$**。

关键设计属性：

| 属性 | 说明 |
|------|------|
| 策略可观测 | 求解策略（逐步推导 vs 暴力枚举）在输出中直接可见 |
| 非双射 | 一个 $y$ 对应多个 $x$，天然形成「多解」任务，考察策略而非记忆 |
| 清晰的 OOD 定义 | 可控的难度轴：**解的数量更多**、**$y$ 更长**等 |

### OOD 偏移的定义

论文给出明确的 easy-to-hard OOD 划分方式，摘要中列举了两个维度：

1. **解的数量增加**（more solutions）——目标从找到唯一解变为找到多个解；
2. **$y$ 更长**（longer $y$）——输入串长度增加。

这两类偏移都是「**任务在可控维度上变难**」，而非改变任务类型，因此可以干净地把「策略泛化失败」与「任务本身不可解」区分开。

### 失效模式的刻画

RLVR 训练后的模型表现出**两种截然不同的行为模式**：

- **ID 行为**：准确率高，且输出**结构化的逐步推导（structured step-by-step derivation）**；
- **OOD 行为**：**放弃推导**，**坍缩到无效的暴力枚举（ineffective brute-force enumeration）**，准确率**急剧下降（sharp accuracy drops）**。

这一区分是关键的诊断贡献：它把失败定位在**策略选择层面**（策略在 OOD 下未被保持），而不是能力或奖励层面。

### 缓解：与双射反演任务共同训练

**关键干预（indirect intervention）**：把**双射反演任务（bijective inversion tasks）**与目标任务**共同训练（co-training）**。

- 双射任务的性质：$f$ 是双射，因此 $y$ 唯一确定 $x$，**不存在多解**。
- **反直觉之处**：这些双射任务**并非一致地更难**（not uniformly harder），而且**离非双射的 OOD 评测更远**（even further from the non-bijective OOD evaluation）——按直觉它们不应该有帮助。
- **实际效果**：它们让**推导变得更确定（make derivation more certain）**，从而**大幅恢复** OOD 下的正确策略与准确率。

### 理论分析

论文的结论性论点：**仅基于结果的 RLVR 本身就能通过「隐式地为有效推理策略记功」来塑造推理过程**，即便没有过程监督（process supervision）。这为上述观察提供了理论解释框架：

- 当某个 outcome 对应的**推导过程**比其他（暴力枚举）更容易获得正确结果时，RL 的优势估计会给该**策略**更高的隐式回报；
- 因此，在结果奖励下，**有效推理策略被隐式偏好并强化**；
- 双射任务提供的额外训练信号相当于**进一步扩大了这一隐式信用分配的优势**，使推导策略在 OOD 下不易被覆盖。

## 实验结果

摘要以定性描述为主，核心观察如下：

| 现象 | 结果 |
|------|------|
| RLVR 后 ID 表现 | 高准确率 + 结构化逐步推导 |
| RLVR 后 OOD 表现 | 放弃推导 → 坍缩到暴力枚举 → **准确率急剧下降** |
| 失效归因 | 非基座能力不足；非 reward hacking（ID 上策略正确） |
| 双射反演共同训练 | 有效；**大幅恢复** OOD 下的正确策略与准确率 |
| 任务难度关系 | 双射任务并非一致更难，且离 OOD 评测更远 |
| 理论结论 | outcome-only RLVR 可隐式地为有效推理策略记功并塑造推理过程 |

## 关键洞察
1. **OOD 泛化失败可能是"策略漂移"而非"能力不足"**：模型在 OOD 下选择了**更差但自己更熟悉**的策略（暴力枚举），说明 RLVR 学到的策略绑定在特定输入分布上。这把 RLVR 泛化讨论从「奖励能否泛化」转移到「策略选择在分布偏移下是否稳健」。
2. **最有效的干预是间接的、非分布相近的**：与**双射**任务共同训练——它离评测分布更远、难度不更高——却最能恢复推导策略。这暗示起作用的是**策略层面的信用分配强化**（让推导在训练中更"确定"），而非数据分布的相似性。对 RLVR 实践的直接启示是：混合任务的**策略多样性/难度多样性**可能比数据覆盖更重要。
3. **outcome-only 奖励能够塑造过程**这一理论结论，如果成立，将改变 RLVR 的设计权衡：既然结果奖励本身就隐式奖励有效策略，那么「过程奖励」的增量价值可能主要体现在**分布偏移下的策略保持**上，而非分布内的推理质量。
4. **可观测的推理过程让 RLVR 可以被"读"**：这套框架之所以能发现"策略坍缩"，是因为可控任务让策略直接体现在输出里。对无法观测推理过程的场景（如自由形式的 agent 任务），这类诊断是否可迁移是重要的开放问题。

## 局限性
- 摘要**完全未给出定量结果**（准确率、OOD 偏移幅度、消融表、模型规模），无法评估失效的严重程度与干预的增益量级。
- 任务域极窄：**方程求解（字符串函数反演）**是高度合成的可控任务，其结论对数学推理之外的领域（代码、逻辑、多跳问答）能否迁移未验证。
- 仅用「解的数量」「$y$ 的长度」两类 OOD 轴，其他 OOD 类型（如变量命名变化、干扰项注入）未涉及。
- 双射任务「并非一致更难」这一判断本身依赖于具体的难度度量方式，摘要未说明如何度量难度。
- 理论分析的形式化程度未知：摘要只给出结论性陈述，未说明假设（如策略空间的可辨识性、RL 算法的具体性质）。
- 未讨论奖励设计（是否用过程奖励、是否加 KL 约束、熵正则）在该失效中的作用；也未讨论更强基线（如显式的策略保持正则、课程学习、探索压力）。
- 未涉及模型规模缩放规律——该失效是否主要出现在小模型上未知。

## 适用场景
- **数学/形式推理的 RLVR 训练**：需要在训练配方中加入保持推导策略的机制，避免 OOD 退化为暴力枚举。
- **推理策略鲁棒性诊断方法学**：把「策略可观测」的测试环境设计原则应用到其他领域（代码修复、逻辑推理），构建策略坍缩检测工具。
- **过程奖励 vs 结果奖励的设计取舍**：为 RLVR 团队提供「结果奖励能否塑造过程」的理论依据。
- **课程与混合数据设计**：借鉴「加入看似无关但能强化策略的辅助任务」这一非直觉的数据配比思路。
