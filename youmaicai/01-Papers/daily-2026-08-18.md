## 值得关注的技术点

### InflationAgent
- Token inflation 定义：真实workflow成本/单次调用成本
- CoT Branching Entropy (CBE) 预执行难度信号，AUROC 0.887
- Semantic Exchange Rate (SER) = 预期准确率/预测真实成本
- Fresh-escalation 丢弃失败链再路由

### FPO (Forward-Pass-Only)
- 核心发现：transformer后层输出层预测误差与真实梯度余弦相似度 0.47-0.59
- 无 autograd 图，无层级间信号传播
- OLMo-2-7B, Qwen3-8B, Falcon3-7B 三大家族验证

### SELR
- Answer Loss + CoT Loss 多任务训练
- 无需外部解码器，单模型同时做到高效 + 可解释
- LLM 和 VLM 均验证有效

### Hallucination Snowball
- 四状态马尔可夫链：Raw Fact → Derived → Narrative → Invisible
- 各边界逃逸概率：24.6%, 48.3%, 89.3%
- 最强模型 Qwen3.5-397B-A17B 最终阶段检测率仅 60-65%
