## 核心贡献

> 通过修正 LZW 压缩层与动态词汇层，本文把 zip2zip 的质量 gap 关闭约一半——无需修改预训练 LM。

1. **诊断 4 个失败原因**: 
   - input/output embedding 隐式冲突
   - RoPE 跨多 token 合并被忽略
   - 数字类 token 合并损害下游精度
   - 动态词汇引入分割歧义干扰评估
2. **修复方案**: decoupled in/out embedding、size-aware RoPE、selective merges、multi-view segmentation

---

## 技术方案

### 核心思想

动态词汇 + LZW 压缩可减少 token 数但损害 perplexity 与 reasoning。本文**不修改预训练 LM**，只在压缩层和 codec 上做手术。

### 关键技术

| 技术 | 说明 |
|------|------|
| Decoupled in/out embedding | 输入/输出 dynamic embedding 分离 |
| Size-aware RoPE | 感知合并跨度的位置编码 |
| Selective merge | 选择性合并（跳过数字等敏感 token）|
| Multi-view segmentation | 多视角分割消解歧义 |
| LZW codec modification | 修改后的 LZW 编解码 |

### 关键问题（论文诊断）

```text
1. shared embedding → input/output embedding tension
2. naive RoPE + merged tokens = wrong positional signal
3. digit merges disproportionately hurt accuracy
4. dynamic vocab segmentation ambiguity confounds eval
```

---

## 实验结论

- **数据集**: 多个 corpus + 数学 reasoning
- **模型**: 4 个
- **结果**:
  - 在所有 corpus 上 perplexity 改善
  - 数学 reasoning accuracy 提升
  - **quality gap 关闭约一半**（vs zip2zip 基线，匹配压缩率）

---

## 局限性

- 仅在 4 个模型验证，迁移到全部 LM 未确认
- "Decoupled embedding" 增加参数量
- Multi-view segmentation 增加 inference overhead

---

## 实现建议

- **实现难度**: 中（修改 tokenizer + RoPE 适配）
- **预期性能**: 长上下文 inference 节省 token 20-40% 而 quality loss 减半
- **适用场景**: 长上下文 LLM serving、token 计费优化
