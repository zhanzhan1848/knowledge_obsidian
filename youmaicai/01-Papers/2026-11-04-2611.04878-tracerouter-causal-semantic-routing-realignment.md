## 核心贡献
1. **提出"路由级表示假设"（routing-level representation hypothesis）**：LFM 中的安全关键语义由**分布式、跨层的因果路由电路**编码与传递，而非局部化的单元。骤然切断这些高度纠缠的电路会破坏正交的良性计算。因此应从"刚性节点抑制"转向"沿估计出的路由路径做连续的最优传输驱动的软重对齐"。
2. **Discover–Trace–Realign 三段范式**：(a) **Discover**：用 attention divergence 定位**敏感起始层**（sensitive onset layer），并用 Top-K sparse autoencoder (SAE) 把稠密层激活分解为可解释的稀疏路由特征；(b) **Trace**：把稀疏特征投影回稠密激活空间，用 zero-out 干预量化下游各层的 **feature influence score (FIS)**，重建跨层因果电路；(c) **Realign**：用**约束最优传输 (OT)** 做软路由重对齐，把不安全激活分布重定向到安全参考分布，同时**保留未被选中的坐标**。
3. **敏感起始层的定位方法**：用**敏感注意力 SA**（敏感修饰 token → 目标实体名词的平均注意力）减去**上下文扰动 CD**（无关 token 上的注意力变化）得到**敏感分数 SS**，取 SS 的**第一个局部峰**为起始层。CD 的引入是为了隔离"全局注意力再分配"这一混淆因素。
4. **敏感特征的选择**：SAE 神经元用 **WFS（weighted frequency score）= 激活频率 × 条件均值幅度** 评分，并按**差分** $\Delta\text{WFS}(m) = \text{WFS}_{\text{sens}}(m)-\text{WFS}_{\text{benign}}(m)$ 排序取 Top-K——确保选出的是恶意意图特有信号而非通用语言模式。
5. **因果追踪的 FIS 定义**：
$$\text{FIS}(m) = f_{\text{dense}}(m)\cdot\mu_{\text{dense}}(m)\cdot\Delta_{\text{ablation}}(m)$$
   其中 $\Delta_{\text{ablation}}(m)=\mathbb{E}[|a_m-\hat a_m|]$，$f_{\text{dense}}(m)=P(a_m>0)$，$\mu_{\text{dense}}(m)=\mathbb{E}[a_m|a_m>0]$。每层取 FIS Top-K 并入路径 $\mathcal{P}$。
6. **OT 软重对齐（核心技术）**：对每个被选中的坐标 $k$，用**经验分位映射**
$$T_k(v) = F_{Y_k}^{-1}\big(F_{X_k}(v)\big)$$
   把不安全激活的边缘分布对齐到安全参考的边缘分布（$X$ 为不安全上下文下的激活样本，$Y$ 为安全参考上下文下的激活样本）。路由掩码 $M\in\{0,1\}^d$ 限制修改范围：
$$\tilde h = h + M\odot\big(T(h)-h\big)$$
7. **跨三类架构的全面验证**：LLM（LLaMA3-8B-Instruct、Mistral-7B-Instruct）、MLLM（LLaVA-1.5-7B、MiniGPT-4-7B、DeepSeek-VL2）、扩散模型（Stable Diffusion 1.4、FLUX.1-Dev、AltDiffusion、Show-o2），对比 DeepAug、CB (Circuit Breaker)、DeRTa、HumorReject、LEACE、ESD、UCE、CA、SLD-Med、MACE、RECE、SPM、DuMo、SNCE 等基线。
8. **五种子稳定性**：主表 II–VII 与消融表 VIII–XII 全部以 5 个种子重复，报告 mean±sample SD，标准差在 0.2–1.3 个百分点之间。

## 问题背景
大基础模型（LFM：LLM、MLLM、扩散模型）的部署伴随着对抗性风险。现有的内部干预方法主要依赖**局部性假设**（locality hypothesis），通过抑制孤立的神经元或特征来缓解有害语义。

但 LFM 内部的语义表示本质上是**分布式的**：有害概念很少局限于孤立成分，而是通过复杂的跨层拓扑轨迹传播。因此局部干预如同"孤立的交通路障"，**无法在精密对抗攻击下遏制语义泄漏**；而且强行切断纠缠的神经成分必然破坏良性计算、降低通用能力。

近期的机制可解释性研究从不同角度佐证了同一现象：复杂行为源于拓扑电路而非孤立节点（神经科学证据）；因果中介分析需要计算密集的 activation resampling 来严格防止 OOD 表示偏移，作者明确说明自己用"定向 zero ablation 作为高度可 tractable 且经验稳健的近似"。

论文还引用了一个重要观察（Gu et al. 2025）：attention sink 从 softmax 归一化中涌现，行为类似 softmax 内部加上的 input-independent key bias——这与本文"路由级表示假设"的精神一致（虽然本文未展开该联系）。

## 方法

### 1. 问题形式化：受约束的联合最优传输

设潜在激活向量 $h\in\mathbb{R}^d$，$\mathcal{R}\subset\{1,2,\dots,d\}$ 为被识别为敏感并与有害语义传播因果关联的路由特征索引集。$p_X$ 与 $p_Y$ 分别为不安全激活与安全参考激活的分布。目标是求最优传输映射 $T:\mathbb{R}^d\to\mathbb{R}^d$：

$$\min_T \int_{\mathbb{R}^d} c(x,T(x))\,dp_X(x)\quad \text{s.t.}\quad T_\#p_X = p_Y,\quad [T(x)]_k = x_k,\ \forall k\notin\mathcal{R}$$

即：**传输被严格限制在与恶意路由路径相关的维度内**，从而减少对非选中表示的直接干扰。

### 2. Discover：敏感路由源定位

**敏感注意力**（从敏感修饰 token $T_{\text{sens}}$ 到目标实体名词 token $T_n$ 的头平均注意力）：

$$SA(P,l) = \frac{\sum_{i=1}^{|T_{\text{sens}}|}\sum_{j=1}^{|T_n|}\bar A^{(l)}_{i,j}}{|T_{\text{sens}}|\cdot|T_n|}$$

（对 Stable Diffusion 1.4，$\bar A^{(l)}$ 取自**冻结的 CLIP ViT-L/14 文本编码器**，$l$ 索引其 12 个 transformer block 而非 UNet 的空间层。）

**上下文扰动**（用于隔离"一般 prompt 变化引起的全局注意力再分配"这一混淆）：

$$CD(l) = \frac{1}{|T_{\text{unrelated}}|}\sum_{t=1}^{|T_{\text{unrelated}}|}\|\hat A^{(l)}_{P_{\text{sens}}(t)}-\hat A^{(l)}_{P_{\text{benign}}(t)}\|_1$$

**敏感分数**：

$$SS(l) = \frac{1}{N}\sum_{k=1}^{N}\big[SA_k(P_{\text{sens}},l)-CD_k(l)\big]$$

**敏感起始层** $l^*$ = SS 曲线**第一个高于背景水平的显著局部峰**所在层。

### 3. SAE 特征解耦与敏感特征选择

在 $l^*$ 上训练 Top-K SAE（扩展因子 4，Adam，lr $4\times10^{-4}$，batch 4096，MSE 重建损失）。SAE 神经元 $m$ 的 **WFS**：

$$\text{WFS}(m) = f(m)\cdot\mu(m)$$

差分排序：

$$\Delta\text{WFS}(m) = \text{WFS}_{\text{sens}}(m)-\text{WFS}_{\text{benign}}(m)$$

取 Top-K 为敏感路由特征 $\mathcal{M}_{\text{sens}}$。$K$ 由 **WFS 排名曲线的肘点**确定（该数学阈值标记高响应 hub 特征进入长尾分布的转折点）。

### 4. Trace：因果语义路由追踪

用 SAE 解码器权重 $W_{\text{dec}}$ 把敏感特征投影回 $l^*$ 层的稠密空间：

$$Z^{(l^*)}_{\text{proj}} = W_{\text{dec}}\cdot \mathcal{M}_{\text{sens}}$$

取投影幅度绝对值最大的坐标作为**源路由节点** $S_{\text{src}}$。对每个样本做一次基线前向缓存所有 $l>l^*$ 的 $a^{(l)}_x$，再做一次消融前向（把 $S_{\text{src}}$ 处的激活置零）缓存 $\hat a^{(l)}_x$，逐层计算 FIS 并取 Top-K 构成路径 $\mathcal{P}$ 与二值路由掩码 $M$。

### 5. Realign：OT 驱动的软路由重对齐

**Proposition 1 的条件**：在**因子分解条件与可分离代价条件**下，逐维精确标量最优传输映射的乘积是最优的联合传输映射。作者明确承认："它并不假设学到的路由特征在实际中独立。**精确等价于联合 OT 只在 Proposition 1 所述的因子分解与可分离代价条件下成立**。""对于一般激活分布，经验逐坐标实现**不一定**恢复安全参考的联合分布。因此 Algorithm 3 被视为一个**可 tractable 的逐坐标边缘 OT 近似**。"

实现（Algorithm 3）：对每个 $M_k=1$ 的坐标，估计 $F^k_X$、$F^k_Y$ 的经验 CDF，定义 $T_k(v)=F^{-1}_{Y_k}(F_{X_k}(v))$；$M_k=0$ 的坐标取恒等映射；最后

$$\tilde h = h + M\odot(T(h)-h)$$

## 关键洞察
1. **"局部抑制 vs 路径重定向"的可量化对照是本文最有说服力的部分**。Fig. 8 的粒度消融显示：孤立神经元抑制在标准基准上尚可，但在 Prefill 攻击与 P4D 上 DSR 崩塌——这直接量化了"局部性假设"在何种攻击强度下失效。安全干预的粒度必须与语义传播的粒度匹配。
2. **双向反事实（放大/抑制）比单向 DSR 更能证明因果性**。Table VIII 中 LLaVA 上放大路径使 DSR 从 49.0 升到 78.6、抑制使其降到 18.2——**方向相反的双向效应**说明路径确实在功能上承载安全语义，而非统计相关。
3. **CD（上下文扰动）项是本文一个容易被忽略但重要的方法贡献**。SA 单独会因"一般 prompt 变化引起的全局注意力再分配"而升高；减去 CD 后才得到真正的"恶意特异性"信号。这使得起始层定位从启发式变成有对照的测量。
4. **差分 WFS 排除了"通用语言模式"的混淆**：$\Delta\text{WFS}$ 比较敏感与良性 prompt 集，确保选出的是恶意意图特有信号。这与 CD 项是同一思路在不同层级的应用。
5. **OT 的价值主要体现在"最小化对良性计算的干扰"，而非提高 DSR**。Table IX 显示线性 steering 在 LLaMA3 上也能到 97.4% DSR，但 SD 上掉到 72.2%、FID 升到 16.24；硬干预在 SD 上 FID 高达 19.12；只有 OT realignment 同时拿到最高 DSR 与最低 FID (8.62) 和最小 CLIP 损失 (−0.26)。**软重对齐 > 硬抑制**的论据在此非常清晰。
6. **像素级残差可视化提供了超越指标的效用证据**。基线方法在良性 prompt 下也广泛改动图像——说明它们的"防御"部分来自对生成过程的普遍扰动；而 OT realignment 的残差高度局部化。这对扩散模型安全特别重要，因为 FID 之类的整体指标可能掩盖空间上的破坏。
7. **过度拒答是与安全同等重要的另一面，且基线在这里分化极大**：DeepAug (+36.4) 与 DeRTa (+24.4) 在 LLaMA3 上大幅过度拒答，而 TraceRouter++ 仅 +0.3。安全防御若以通用能力崩塌为代价则无实际价值——这组对比让"安全–效用 Pareto 前沿"有了具体含义。
8. **作者对自己结论的边界相当诚实**：明确写出"这些测量支持有利的安全–效用权衡，但**它们本身并不证明下游良性计算保持不变**"；也明确承认 P4D 上 76.0% 表明**该攻击下仍存在脆弱性**；以及坐标 OT 只是**近似**、不恢复联合分布。这种自我限定在当前安全论文中不常见。

## 局限性
- **坐标 OT 只是联合 OT 的近似**：作者自己指出，精确等价只在**因子分解与可分离代价条件**下成立，而"它并不假设学到的路由特征在实际中独立"——**即 Proposition 1 的条件在实践中并不成立**。因此整个方法的理论根基是条件性的，而实际实现是逐维独立对齐（不保证恢复安全参考的联合分布）。
- **因果追踪用的是 zero ablation 近似**，作者承认严格的因果中介分析需要计算密集的 activation resampling 来防止 OOD 表示偏移。zero ablation 会引入分布偏移，可能高估或低估真实因果效应。
- **模型规模有限**：最大的 LLM 是 LLaMA3-8B、Mistral-7B；MLLM 是 7B 量级。**未在当代前沿规模（数十到数百 B）上验证**，而"有害语义是分布式电路"这一假设在更大模型上可能表现不同。
- **起始层与敏感特征的选择依赖"敏感 prompt 与其良性配对"的构造**：SS 定义需要为每个敏感 prompt 人工/自动构造良性对应物与"无关 token"集合，这限制了方法的自动化程度与可扩展性。
- **评测全部为既有 jailbreak 基准**：AdvBench、HarmBench、JailbreakV-28K、FigStep、I2P、P4D、Ring-A-Bell。**未测试自适应攻击**（即攻击者知晓防御机制并针对性优化）——虽然引用了 defense-aware adaptive GCG 的工作，但主表未纳入。
- **DSR 接近饱和（98–99.7%）使方法间比较的统计效力很低**：多数对比基线的差异在 1 个百分点内，五个种子的 SD 也在 0.2–2.4 之间。核心结论"TraceRouter++ 优于基线"在**多数格子上差异微小**，真正显著的是 Mistral 上从 6.6% 到 98.8% 这种原始模型本身脆弱的情形。
- **效用评测面很窄**：LLM 只用 Global-MMLU-Lite、MLLM 只用 MMBench、DM 只用 CLIP Score 与 FID。**没有长文本生成质量、多轮对话、代码生成、推理任务等更贴近实用的评测**，而 −0.4 点的 MMLU 差异在这些任务上可能放大。
- **没有运行时开销的报告**（主表），仅有 Table XVI 提到可靠性与计算开销；训练 SAE 与 tracing 的成本、可部署性（需要在线修改激活分布）未在主结果中呈现。
- **安全参考分布 $p_Y$ 的构造细节与规模未充分说明**：这决定了 OT 映射的"目标"是什么，不同构造会给出不同的 realignment。
- **对扩散模型用的是 CLIP 文本编码器而非 UNet 空间层**做起始层定位，这一不一致性在跨模态方法的可迁移性上是个隐忧。
- **Fig. 8 的粒度消融未给出完整数字表**，只有图示，难以核查具体差值。

## 适用场景
- **需要在不牺牲通用能力的前提下加固 LLM/MLLM 的推理时安全**：本文相对硬抑制的 ORR 与效用数据（+0.3 vs DeepAug +36.4）支持这一场景。
- **扩散模型的概念擦除/安全生成**：FID 与像素级残差证据显示 OT realignment 的空间破坏远小于 ESD/UCE/SLD/SNCE 等基线。
- **机制可解释性驱动的防御工程**：Discover–Trace–Realign 三段范式可作为"定位语义传播路径 → 干预"的通用流水线，用于任何需要沿因果路径干预而非抑制孤立单元的任务。
- **多模态（视觉注入 + 文本 jailbreak）复合威胁**：JailbreakV-28K 与 FigStep 上的结果表明它对跨模态语义泄漏有效。
- **不适合**：需要在线低延迟部署且无法承担 tracing/SAE 训练成本的场景；模型规模远超 8B 且未重新验证；已有成熟 RLHF/DPO 对齐且追求最低过度拒答的场景；需要对抗自适应攻击下保证的场景；纯文本任务且不需要可解释性组件的轻量级需求。
