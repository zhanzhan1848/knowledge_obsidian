## 核心贡献
1. 提出 **MeMoDecode**：一个 decoding 框架，**联合强制** DSL 的 concrete syntax、abstract syntax（由 metamodel 定义）与 well-formedness constraints。
2. 增量校验机制：每当 LLM 生成一个完整的 metamodel concept，就把当前输出增量映射为一个 **partial model**，并验证它是否仍能被补全为一致的 instance。
3. 设计 **retry mechanism**：检测到不一致时，从「最近一个可完成的 snapshot」恢复解码。
4. 理论性质：在 **sound backend verifier** 假设下，MeMoDecode 在满足自然假设的 alignment metrics 上**不劣于** grammar-constrained decoding。
5. 跨 4 个 DSL、6 个 open-weight LLM（0.6B–70B）验证一致性与 benchmark 表现。

## 问题动机
LLM 正越来越多地被用于生成用 domain-specific language (DSL) 表达的 software engineering artifacts。一个「正确」的 DSL instance 不仅要符合 concrete syntax，还要符合由 **metamodel** 定义的 abstract syntax，并满足附加的 semantic well-formedness constraints。现有 constrained decoding 方法通常只能保证 concrete syntax 的合规，或只能处理少量直接写在生成文本上的语义约束，导致 **metamodel 层面的约束一致性在生成过程中难以强制执行**。这正是 DSL 生成任务区别于普通结构化输出的难点所在。

## 方法
MeMoDecode 的核心循环：

1. **Concrete 层**：沿用 grammar-constrained decoding，保证 token 级语法合法（论文将其作为基线机制叠加，而非替换）。
2. **Abstract / metamodel 层**：每当 LLM 产出一个完整的 metamodel concept，MeMoDecode 将当前输出**增量映射（incrementally map）**为 partial model。
3. **一致性检查**：验证该 partial model 是否存在可完成的、consistent 的 instance 补全。若不可完成，则当前输出已违反 metamodel-level 约束。
4. **Retry**：检测到不一致时，从**最近一个可完成的 snapshot**（completable snapshot）恢复解码继续生成。

论文给出一个保证：在 sound backend verifier 条件下，MeMoDecode 在满足自然假设的 alignment metrics 上**不会比 grammar-constrained decoding 更差**（即后端校验器不会因过度拒绝而损害对齐质量）。

## 实验设置与结果
- 数据/基准: 摘要未点名具体 benchmark 名称，仅说明使用 "benchmark performance" 作为一项指标；DSL 集合为 4 个（具体 DSL 名称摘要未列出）。
- 对比方法: **unconstrained decoding** 与 **grammar-constrained decoding**。
- 主要结果:
  - 一致性（consistency）相对 unconstrained decoding **平均提升 23%**。
  - 一致性相对 grammar-constrained decoding **平均提升 8%**。
  - benchmark performance 同样有所提升。
  - runtime overhead 为 **modest**（摘要未给出具体倍数或延迟数值）。
  - 覆盖 6 个 open-weight LLM，参数量跨度 **0.6B 到 70B**。
