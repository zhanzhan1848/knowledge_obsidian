# SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization

## 摘要
LLM 引导的演化搜索用 AI agent 迭代改进程序以解决数学与计算问题，但过程往往**缓慢** —— 因为 LLM 每轮生成**很长的文本思维链**，且必须**多次重复生成**以维持种群多样性。本文提出 **SwarmEvolve**：一个框架中，**每轮数百个低成本 agent 以蜂群形式工作**，**在隐空间推理而不解码为文本**，并**通过传递 KV cache 共享信息**。每个蜂群从**不同角度**研究问题。一个**新颖性过滤器**通过**直接测量 agent 隐状态向量之间的距离**来保留最独特的 agent 想法。想法的**交叉**自然发生在隐空间中 —— 一个**汇总 agent 接收所有蜂群成员的合并 KV cache**。在 **21 个数学发现与科学计算问题**上，SwarmEvolve 取得**最高平均分**，且只需**中位数 3 到 8 分钟**即可达到其他 SOTA 框架需要 **60 分钟**才能达到的最佳分数。

## 核心贡献
1. 提出 **SwarmEvolve** —— 每轮**数百个低成本 agent 以蜂群工作**，**在隐空间推理而不解码为文本**
2. **通过传递 KV cache 共享信息**（而非文本摘要）—— 交叉在隐空间自然发生（汇总 agent 接收合并 KV cache）
3. **新颖性过滤器**直接测量 **agent 隐状态向量之间的距离**来保留最独特的想法
4. 在 **21 个数学发现与科学计算问题**上取得**最高平均分**
5. **速度**：中位数 **3–8 分钟**达到其他 SOTA 框架需 **60 分钟**才能达到的最佳分数

## 方法与架构
**核心机制**：
```
每轮：数百个低成本 agent（蜂群）
  ├─ 各自从「不同角度」研究问题
  ├─ 在隐空间推理（不解码为文本）
  ├─ 通过 KV cache 共享信息
  └─ 新颖性过滤器：按隐状态向量间距离保留最独特的想法
汇总 agent ← 接收所有成员的合并 KV cache → 产生交叉后的下一代
```

**与传统 LLM 演化搜索的对比**：传统方式每轮生成长文本 CoT 并需多次重生成以维持多样性；本文**完全不生成文本**，用隐状态距离替代语义相似度做新颖性判定。

## 实验结果
- **21 个数学发现与科学计算问题**上取得**最高平均分**
- **速度优势**：中位数 **3–8 分钟**达到竞争框架 **60 分钟**才能达到的最佳分数 → **约 8–20× 加速**
- **数百个低成本 agent 并行** + **隐空间推理**（零文本解码）

## 局限性
- 仅 **21 个问题**（数学发现 + 科学计算），任务域窄；
- 「隐空间推理」依赖模型支持可操作的隐状态表示，闭源 API 模型不适用；
- 隐状态距离作为新颖性度量的可靠性（与语义新颖性的相关性）未验证。

## 值得注意的点
「**在隐空间推理而不解码为文本**」是一个激进但极具经济性的设计 —— 在 LLM 演化搜索中，**长文本 CoT 是主要的 token 成本**。把这部分成本完全消除，等于把演化搜索从「消耗模型」变成「廉价并行搜索」。这个思路与今日 Octopus（隐空间 KV 多 agent RL）是同一族：**把 agent 之间的交流从文本搬到 KV/隐状态**。
