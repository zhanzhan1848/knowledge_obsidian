## 🎯 今日主线

**今天 16 篇论文串起来的主线是同一个转变的三个侧面：LLM 研究的重心正在从「模型能做什么」移向「模型在什么约束下、以什么代价、在什么观察点上做这件事」。**

- **第一条线是「约束」。** 三篇论文不约而同地把一个此前靠拍脑袋设定的量改写成了显式可校准的量：
  - **Safety as a Budget**（2611.16628）把 VLM 安全从「调 reward 权重」改成「给有害协助率和过度拒答率各设一个预算」，用拉格朗日乘子嵌进 GRPO。但论文自己发现标准做法**失败两次**：乘子比较的是评分器的**均值**与预算，而排序型评分器的均值是错的；且 GRPO 在组内对惩罚后奖励做标准化，**把乘子在到达梯度之前就抵消掉了**。作者提出双通道约束 GRPO（基础奖励保留原始分数用于组内比较，惩罚与约束估计过单调映射，优势函数保留乘子），在 Qwen3-VL-2B 上 1,037 条对抗提示的 held-out 有害率从 **8.9% → 4.8%**（未校准预算是 7.6%），且在未见过的 HADES 基准上从 **28.9% → 12.8%**。
  - **Human or Synthetic?**（2611.16895）把「人类标注偏好数据 vs 合成偏好数据」的比较，从**固定样本数**改成**固定美元预算**——这直接改变了结论：合成数据在低到中等预算下成本效率高得多，**\$200–\$400 就能拿到高胜率**；在 helpfulness 上人类数据要**大两个数量级的预算**才追平，在 summarization 上**任何测试预算下都追不平**。更扎人的是：一个人类偏好数据源**显著劣于**另一个，而且这个差距在「领域限制 + 去重」等标准补救后依然存在。
  - **Smart Model Routing**（2611.15911）把成本问题形式化为**成本-质量优化**，推导出最优阈值策略结构、校准 vs 判别之分、级联盈亏平衡条件，并明确指出一个被忽视的坑：**prompt injection 可以注入路由信号**。在给定价格与流量假设下，校准路由器相对「永远用前沿模型」可把混合推理成本降低**约一个数量级**，但报告时区分了「仅路由策略带来的毛降幅」与「计入路由器自身开销后的净数字」。

- **第二条线是「观察点」。** **Where Is Uncertainty Observed?**（2611.15735）这篇是我认为今天最有方法论价值的一篇。现有 UQ 分类法都按「不确定性的来源」或「估计机制」组织，却留下了一个真正要紧的问题没回答：**不确定性是在模型的计算里的哪一处被观测到的？** 作者借用机制可解释性定义四个镜头——结构镜头（组件更新）、表示镜头（隐状态）、分布镜头（token 概率）、语义镜头（语义分布），并通过残差流把四者关联、按携带信息量排序，从而给出**为不同目标选择 UQ 方法的原则**。这个「观察点决定估计器能否恢复目标」的框架，比现有的 source/mechanism 二维分类多了一层结构。

- **第三条线是「代价」与「效率」。** 三篇论文各自削掉了一层不必要的开销：
  - **FOAM**（2611.16905，NeurIPS 2026，Naver AI）问「能否保留 SOAP 的收益、只付 AdamW 的代价」，答案是可以：丢弃输出侧 Kronecker 因子（对角输出曲率下**精确**、近对角下几乎无损），用行列统计的分解式 Adam-moment 估计器替代稠密旋转二阶矩（在 K-FAC 假设下**精确**恢复 SOAP 的稠密二阶矩，实测仅 15–20% K-FAC 违背）。结果：验证损失追平 SOAP 与 Muon，**优化器状态只用 SOAP 的一半**，墙钟时间达到 Muon 级别，124M→760M 参数区间稳定。
  - **CoMem**（2611.16384，WSDM camera-ready）反对「无差别压缩一切」：既然任务相关证据在 query 间差异巨大（局部证据 / 多处远距离片段 / 全文分散），压缩器就应当**同时以文档和 query 为条件**。做法是 Contrastive Compressor Learning + **同上下文硬负样本挖掘**（一份文档配多个 query，逼压缩器按各 query 的证据需求选择性保留）+ 记忆槽间双向注意力（缓解因果掩码的信息流限制）。
  - **Adaptive Computation**（2611.16321）发现 System One 决策信息**集中在中间层**，**最后六层可无损失移除**，而独立训练的小模型大多只是模仿全模型、并**没有发展出专门化的决策能力**——因此效率的关键不是更小的 backbone，而是**跨深度共享计算**。

- **第四条线是「agent 的失败到底出在哪个环节」，今天由三篇论文从三个方向回答：**
  - **Bait**（2611.16369）暴露一个安全漏洞：**\$20 的成本**就能通过多轮有害 agentic RL 完全颠覆一个 LLM 的安全对齐，并且攻击者可以接着用被污染的模型去**利用软件漏洞、发起代码重用攻击**。防御是「主动探测奖励函数」——这个简单防御不仅能充分缓解从有害奖励函数学习，同时**仍能从推动良性 agentic 任务的良性奖励函数中学习**；理论上自适应攻击者无法完美绕过。
  - **SwarmSafe-Delta**（2611.16123）给出了隔离「上游消息是否改变了执行者动作」的**配对可执行协议**：冻结上游计算、变化真实/隐藏/格式匹配的安慰剂投递、按预设预算给单一提交动作打分。真实投递（N=4）产生 **21.4%** 的风险世界违规，安慰剂 **5.0%**，隐藏投递 **1.0%**（配对差 +16.4 / +20.3 个百分点）。作者同时诚实指出：**压制通信会牺牲效用**（真实投递也提升良性任务成功率；需要上游查找路由的场景里真实投递把安全完成率提高 **74.2 个百分点**）。
  - **Experience-Handoff RL**（2611.16409）指出当前 agent 训练的一个结构性浪费：harness 会把过去的经验（playbook 等）交给未来 rollout，但**这些交接物本身的构造没有被学习**。作者固定 Agentic Context Engineering harness，训练一个模型同时充当 action generator / insight reflector / playbook curator 三种角色，**按交接物对未来 rollout 的下游影响来评价候选交接物**。

- **第五条线是「数据与基准到底在测什么」。** **Shortcuts or Memorisation?**（2611.16843）做了一组很扎实的控制实验：八款 LLM + 微调编码器在 GLUE 与三轮 ANLI 上做扰动实验。结论反直觉：**无论是模型大小，所有直接作答的系统在 MNLI 上去掉名词后仍保留 36–72% 的高于随机性能，而在 ANLI 上只保留 14–29%**；只有「先推理再回答」的模型偏离这个模式。他们还检查了污染指标（包括两个模型公开预训练数据中的精确 n-gram 计数），**未发现暴露程度与鲁棒性之间的关联**；并构造了 **368 条人工校验的新题目**（任何模型都不可能见过），结果八款 LLM 在 MNLI 风格题目上去掉名词后保留的性能都**高于**非该风格题目——而当扰动改为去掉承载这些线索的功能词时，优势**反转**。作者由此论证：对熟悉 NLI 基准的扰动鲁棒性反映的是**数据集捷径而非记忆**，它更多告诉你关于基准的事，而不是关于模型的事。

- **第六条线是多语言与表示。** **Lara Mini Base**（2611.16956）以 **6T tokens、45 种语言（含欧盟全部 24 种官方语言）**从零训练，用 **MoE 架构（7.2B 总参数 / 0.6B 激活）**，核心发现是——**44 种非英语语言的 token 总量在训练过程中最终超过英语**，且**MoE 架构降低了语言之间的容量竞争**。在 ≤2B 激活参数的开放基座模型中取得标准英语/多语言/数学/代码基准的**最高平均分**，领先于用 4–6 倍 token 训练的模型；支持 **128k** 上下文；单用户单 GPU 上**未量化**生成速度**至少快 1.8 倍**于任何平均分更高的模型。**Fikiria**（2611.16104）则给出斯瓦希里语数学推理的两段式 SFT+GRPO 配方：奖励 = 格式门控 ×（答案准确度加权的 ChrF++ 相似度加权和对 in-language 参考推理链），**瞄准推理链的表层保真度而非仅仅最终答案**——AfriMGSM 斯瓦希里语上 Fikiria-AfriqueQwen-14B 达 **79.2%**（同固定提示下 GPT-4o 68.0%，部分因格式不合规）。作者诚实标注了局限：**ChrF++ 衡量表层保真度，不衡量单个推理步骤的有效性**，且小规模人工评测中 GPT-4o 输出整体更受偏好。

今天还有两条独立但同样值得记的副线：

- **「角色」与「系统提示」被下沉到激活层。** **Occupational Role Vectors**（2611.15989）用双镜头验证框架：可解释性镜头问「这个向量是不是该角色的稳定、可分离、域一致表示」（跨重跑与温度高度可复现、即使角色非常相近也可分离），控制镜头问「注入这个向量能不能让模型表达该角色并在一段对话中维持」（在 Qwen 上单独注入向量让模型表达目标角色的频率显著高于未引导，但**最好也只是与角色提示打平**；两模型上加向量能加强单轮回答中的角色，但**未能减缓角色在 30 轮内的衰减**）。作者结论很克制也很重要：**两个镜头都需要**——域外时角色只被微妙表达，但激活仍编码了它；而**一个稳定且可分离的向量仍然几乎无法引导行为**。
- **两篇基础设施向的论文**：**ArchSpace**（2611.17332）试图解决「DeepSeek / Qwen / Kimi 这类团队的架构创新哪些成功了、哪些被放弃、为什么，公开报告几乎不记录」以及「学术界的算力受限与基线不一致让改进难以外推到大尺度」这两个问题，做法是 Record + Review + Reference 的公开平台，**用 scaling law 从小实验预测大尺度的模型 loss** 来在昂贵的大规模训练前评估想法，并提供 Qwen3.5 / OLMo3 基线、拟合好的 scaling law 与可复用训练配方。**Verifiable AI 基础设施**（2611.17042）用四层框架（可验证 AI 负载 / 证明系统 / 密码学 kernel / 硬件平台）综述文献并给出 6 个 prover × 7 个 kernel 的原创测量，结论是**主导成本随证明系统与输入长度而变**：低秩微调场景下，对固定模型权重开放承诺的成本在输入长度 64→2048 区间几乎恒定，而与中间值相关的工作量在增长；一个 **13B 参数**的微调配置超出 40GB 显卡容量但在 80GB 设备上可完成——**容量必须与执行时间一起评估**；kernel profiling 还识别出**指令发射与同步限制**，这是纯带宽模型会漏掉的。

| **摘要** | Post-training of large language models typically combines supervised fine-tuning (SFT) with preference-based fine-tuning such as Direct Preference Optimization (DPO). Human-annotated and synthetically generated preference data differ substantially in per-sample cost, but prior work typically holds sample count fixed when comparing the two. In this work, we explicitly study the interplay between cost and performance by comparing the effect of post-training with human and synthetic preference data under a fixed, dollar-matched annotation budget. We train and evaluate multiple base model families across helpfulness and summarization tasks. We also find that human-annotated data varies in reliability: one widely used human preference source substantially underperforms another, and the gap persists even after standard remedies such as domain restriction and deduplication. |

### 3. Where Is Uncertainty Observed? A Mechanistic Understanding of Uncertainty Quantification in LLMs

| 项目 | 内容 |
|------|------|
| **arXiv** | [2611.15735](https://arxiv.org/abs/2611.15735) |
| **分类** | cs.AI, cs.CL, cs.LG |
| **作者** | Xiaoyu Liang, Virginia Ceccatelli, Aliai Eusebi, Tobias Braun, Nils Loose, Carlo Malagnino 等 7 人 |
| **提交日期** | 2026-11-11 |
| **代码** | — |
| **摘要** | Knowing when a large language model's (LLM's) response can be trusted is critical for its safe use. Uncertainty quantification (UQ) can help LLMs recognize if their responses may be unreliable. Existing taxonomies organize UQ methods by uncertainty source or estimation mechanism. They leave unresolved the question of where uncertainty is observed in the model's computation. The answer matters because the observation point determines whether an estimator has access to enough information to recover a given target, and how well it can recover it. Drawing on mechanistic interpretability, we define four mechanistic observation lenses: the structural lens observes component updates, the representational lens observes hidden states, the distributional lens observes token probabilities, and the semantical lens observes distributions over meanings. We relate these lenses through the residual stream and order them by the information they carry, which gives a principle for selecting UQ methods for different targets. We survey existing methods through the four lenses. Furthermore, we distinguish evaluation targets, criteria, and metrics to clarify different UQ evaluation protocols. Finally, we identify open problems and research directions to connect uncertainty estimation to the internal computation and downstream use of LLMs. |

### 4. From Large Language Models to Efficient System One Models via Adaptive Computation

| 项目 | 内容 |
|------|------|
| **arXiv** | [2611.16321](https://arxiv.org/abs/2611.16321) |
| **分类** | cs.CL |
| **作者** | Minh-Anh Nguyen |
| **提交日期** | 2026-11-12 |
| **代码** | — |
| **摘要** | Transferring LLMs into System One decision models typically replaces the language modeling head with a decision head while retaining the full backbone, making every decision pay for all layers. Yet it remains unclear how much depth such decisions require. We find that decision information is concentrated in intermediate layers, with early layers building essential features and the final six layers removable without loss, while independently trained smaller models largely mimic the full model rather than developing specialized decision capabilities. These findings suggest that efficiency requires not simply smaller backbones, but shared computation across different depths. Building on this, we propose \method{}, which jointly trains a full model with prefix sub-models that share its final layers and decision head through self-distillation. A lightweight gate reads the hidden state at each exit to determine whether additional computation is needed, allowing one model to operate at multiple layers. Across seven decision benchmarks, our approach matches or outperforms independently trained models at every depth, while achieving better accuracy-efficiency trade-offs through adaptive computation. |

### 5. Beyond Compressing Everything: Contrastive Memory Learning for Selective Context Compression

| **分类** | cs.AI, cs.CL |

| **摘要** | As large language models (LLMs) advance toward increasingly long inputs, soft context compression offers a promising approach to efficient inference by converting long inputs into compact memory slots. Under limited memory budgets, effective context compression remains challenging because task-relevant evidence varies substantially across queries, ranging from localized evidence to multiple distant spans or information dispersed throughout the full document. Instead of compressing everything indiscriminately, we propose CoMem, a query-guided selective context compression framework that learns memory representations conditioned on both the document and the query. CoMem develops Contrastive Compressor Learning to achieve query-sensitive yet context-preserving memory representations. ### 6. SoScale: Second-Order Scale Search for FP4 Quantization

| 项目 | 内容 |
|------|------|
| **arXiv** | [2611.16426](https://arxiv.org/abs/2611.16426) |
| **分类** | cs.AI, cs.LG |
| **作者** | Pengxiang Zhao, Xing Li, Hui-Ling Zhen, Weizhe Lin, Xianzhi Yu, Zhenhua Dong |
| **提交日期** | 2026-11-12 |
| **代码** | — |
| **摘要** | Low-bit quantization reduces the memory footprint and inference cost of large language models (LLMs), yet accurate FP4 quantization remains challenging. Practical formats such as MXFP4, NVFP4, and HiF4 pair a 4-bit floating-point payload with block-wise or hierarchical scale codes, making accuracy highly sensitive to how each local distribution is scaled. Default maximum-absolute-value scaling preserves dynamic range, but can spend scarce FP4 levels on rarely occupied outlier regions and leave dense tensor values poorly resolved. Existing scale-search methods minimize local element-wise reconstruction error, optimizing tensor fidelity rather than layer-output fidelity. We propose SoScale, a second-order weight scale-code search method for hierarchical FP4 quantization. SoScale searches hardware-valid scale codes under a Hessian-aware layer reconstruction objective and couples this search with GPTQ-style error recovery, selecting scales by their impact on layer outputs. Across Qwen3 models, SoScale consistently reduces downstream quantization degradation under MXFP4, NVFP4, and HiF4. |
