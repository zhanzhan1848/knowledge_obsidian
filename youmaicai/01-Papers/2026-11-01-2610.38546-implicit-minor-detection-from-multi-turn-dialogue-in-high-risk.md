## 核心贡献

> 隐式未成年人检测被重新定义为「弱身份信息下的高风险属性推断」，用 Harness + Maker-Checker 协议约束流程。

1. 把「隐式未成年人检测」形式化为**弱身份信息下的高风险用户属性推断**任务，明确指出文本对话系统缺少账号信息、实名认证、人脸与设备等强身份信号。
2. 提出由 LLM + Harness + Maker-Checker 协议构成的受约束框架：控制推断的触发时机、强制要求与对话关联的结构化证据、对经校验选出的 Harness 修订做版本级复审。
3. 在 8,328 轮受控中文基准上，相比同族模型的直接推断，平均精度与未成年类 F1 分别提升 **7.60** 与 **6.37** 个百分点。

## 技术方案

### 核心思想

在处理高风险文本交互时，系统往往需要判断当前说话者是否为未成年人，以施加年龄条件化的保护措施。但纯文本对话系统缺少强身份信号——没有账号信息、实名验证、人脸或设备数据——只能依赖**跨多轮逐渐浮现的弱线索**。

这篇论文的立场是审慎的：它不把这件事包装成一个「准确识别用户年龄」的 ML 任务，而是明确表述为**高风险用户属性推断**，并把「弱身份信息」写进问题定义。这种措辞本身是重要的：它把评估标准从「准不准」转向「在身份不可靠时是否安全地触发与不触发」。

框架的三部分各司其职：**LLM** 提供弱信号推理；**Harness** 控制流程——何时调用推断、要求输出与对话关联的结构化证据；**Maker-Checker 协议** 则对 Harness 的修订做版本级复审。这套设计的哲学与 Concordat（协议化 agent）一脉相承：**不把合规判断完全交给模型，而是用流程约束它**。

结果是相对同族模型直接推断的显著提升：平均精度 +7.60 个百分点，未成年类 F1 +6.37 个百分点。

### 关键技术

| 技术 | 说明 |
|------|------|
| 受约束推断框架 | LLM + Harness + Maker-Checker 三层，把流程控制从模型判断中剥离 |
| 触发时机控制 | Harness 决定何时调用推断，避免对每一轮对话都做属性判定 |
| 对话关联结构化证据 | 要求证据必须可回溯到具体对话轮次，杜绝无依据的属性断言 |
| Maker-Checker 版本级复审 | Harness 的修订需经独立复审，防止通过修改流程绕过约束 |
| 弱身份信息任务定义 | 显式建模无账号、无实名、无人脸、无设备信号的现实约束 |

## 实验结论

- **数据集**: 受控中文多轮对话基准，8,328 轮
- **基线**: 同一 LLM 家族的直接推断（direct inference）
- **结果**: 平均精度（AP）提升 7.60 个百分点，未成年类 F1 提升 6.37 个百分点。

- **+7.60 AP / +6.37 F1** —— 相对「同一模型直接问」的提升，说明流程约束确实带来了增益而非模型本身的差别。
- 问题定义本身就是贡献：把「隐式未成年人检测」定位为**高风险属性推断**而非普通的分类任务。
- Maker-Checker 版本级复审是容易被忽略但关键的一环 —— 没有它，Harness 会被逐步修改成绕过约束的样子。
- 8,328 轮受控中文基准，实验规模对这类敏感任务而言是合理的。

## 局限性

['受控基准与真实对话分布存在差距，弱线索的真实性存疑。', '中文单语限定，跨语言与跨文化的弱信号差异未讨论。', 'F1 提升 6.37 个百分点在敏感任务上是否足以支撑实际部署，论文未给出阈值分析。', '存在误伤正常用户的风险，论文未系统报告误判的代价。']

## 实现建议

- **实现难度**: 中（需要多轮对话标注与流程约束框架实现）
- **适用场景**: 未成年人保护、年龄分级内容过滤、高风险对话审计、合规审查
- **建议**: 敏感属性推断的设计原则值得抄：**把「是否触发」从模型手里拿出来交给 Harness，把「证据是否可回溯」变成硬要求，并给流程修改本身加复审**。这三件事比换更强的模型更能提升指标。

## 原始摘要

```
In high-risk text interactions, a system may need to estimate whether the current speaker is likely to be a minor before applying age-conditioned safeguards. Many text-based dialogue systems lack strong identity signals such as account information, verified identity, facial data, or device data, and must rely on weak cues that emerge across multiple turns. We formulate implicit minor detection under weak identity information as a high-risk user-attribute inference task and propose a constrained framework comprising a large language model, a Harness, and a Maker-Checker protocol. The framework controls when inference is invoked, requires structured dialogue-linked evidence, and subjects validation-selected Harness revisions to version-level review. On a controlled Chinese benchmark comprising 8,328 multi-turn dialogues, our method improves average precision and minor-class F1 by 7.60 and 6.37 percentage points, respectively, over direct inference using the same LLM family.
```
