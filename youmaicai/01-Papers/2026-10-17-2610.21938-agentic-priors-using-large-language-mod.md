## 核心贡献

> Agent 从用户选择中学习偏好，面临 **cold start 问题**：观察到任何选择前，必须仅依赖 prior。**Informative priors 通常来自历史选择数据**，但**新任务 / 新部署没有数据**。

1. 提出 **Agentic-Priors**：
   - 用 **LLM 的隐式知识**替代历史数据拟合的 prior
   - LLM 以**可解释项**陈述新用户 trade-off：
     - willingness to pay
     - value of time
     - 等
   - 映射到 multinomial logit coefficients 的 prior
2. **Bayesian learner**在观察到选择后 refine prior。
3. 7 个 choice datasets：
   - Cold-start accuracy 优于 uninformed prior **5-40 个百分点**
   - 优于其他 informed-prior baseline

---

## 技术方案

### Agentic-Priors 框架
```
Step 1 (Offline):  LLM 输出新用户的 trade-off statement (text)
Step 2 (Mapping):  text → multinomial logit coefficient prior
Step 3 (Online):   Bayesian update with observed user choices
```

### LLM 输出形式
- 自由文本形式如：
  - "该用户偏好便宜的方案，即使需要更长等待时间"
  - "该用户重视速度，愿为节省 5 分钟多付 $10"
- 解析为 coefficient prior（不是直接喂 latent embedding）。

### 优势
- **可解释**：用户 / 开发者可读可改
- **无需历史数据**：用 LLM 常识替代
- **Bayesian 框架内**：可与历史选择融合

---

## 实验结论

- 7 个 choice dataset（含 transportation、housing、food 等）一致超 uninformed prior。
- Cold-start gain **5-40 pp**。
- 优于其他 informed prior baseline。
- 可解释性获得用户研究认可。

---

## 关键洞察

- **LLM-as-prior-generator** 比 LLM-as-direct-decision 更稳健：
  - 不让 LLM 直接决策（易 bias）
  - 让 LLM 生成 Bayesian prior + 真实选择数据 refinement
- **可解释**是 preference elicitation 在高 stakes 领域的**关键要求**（医疗 / 金融 / 推荐）。
- 未来方向：让 LLM 输出**结构化 prior**（如 hierarchical Bayesian），可与领域知识融合。
