## 核心贡献

> 对两种代表性 self-distillation 方法（SDPO / OPSD）做严格审视：所谓"利用 privileged information"带来的推理提升，主要是 overfit / transfer 现有 reasoning behavior，而非真正使用 privileged info。

1. **In-distribution vs OOD 评估**：报告的提升大多不能泛化到 unseen problems
2. **Gains 解释**：大多是 overfit / transfer 现有 reasoning 而非 effective privileged-info use
3. **Gradient alignment 分析**：self-distillation gradients 与直接优化 expected reward 的 policy gradient 对齐很弱
4. **跨模型验证**：Qwen3 (1.7B-14B) + OLMo-3-7B 均观察到同样问题
5. **结论**：effectively leveraging privileged information 仍是 open challenge

---

## 技术方案

### 核心思想

Self-distillation (SDPO, OPSD) 让模型在 privileged info（如正确答案 / 环境反馈）下训练自己。这些方法报告的 sample efficiency 与 generalization 优势可能并非来自 effective use of privileged info，而是：

- 在 *seen* 问题上 overfit
- 复制现有 reasoning behavior（transfer 而非 exploration）

### 关键技术

| 技术 | 说明 |
|------|------|
| SDPO / OPSD 再审视 | 在 code, science, tool use, math reasoning 多任务上重新评估 |
| In-distribution vs OOD split | 区分 seen / unseen problems |
| Gradient alignment 测量 | 与直接 RL policy gradient 的 cosine similarity |
| 跨模型验证 | Qwen3 系列 + OLMo-3-7B |
| Failure mode 分析 | 量化 overfit / transfer vs privileged-use 的贡献 |

## 公式

Self-distillation 目标：

```math
\mathcal{L}_{\text{SD}}(\theta) = -\mathbb{E}_{x \sim \mathcal{D}_{\text{priv}}} \bigl[ \log p_{\theta}(y^* \mid x, p^*) \bigr]
```

直接 RL 的 expected reward：

```math
\mathcal{L}_{\text{RL}}(\theta) = -\mathbb{E}_{x \sim \mathcal{D}} \bigl[ r(y) \log p_{\theta}(y \mid x) \bigr]
```

两者的梯度余弦：

```math
\cos(\nabla \mathcal{L}_{\text{SD}}, \nabla \mathcal{L}_{\text{RL}}) \approx 0
```

→ 说明 self-distillation 不一定朝 true reward 优化方向走。

---

## 实验结论

- **任务**：code, science, tool use, math reasoning
- **SDPO**：code / math 上的提升主要源于 OOD 泛化失败
- **OPSD**：similar pattern
- **模型规模影响**：Qwen3 1.7B 到 14B 均观察到 overfit pattern
- **OLMo-3-7B**：confirm pattern
- **结论**：existing gains 不能直接归因于 privileged-info use

---

## 局限性

- 仅评估 SDPO / OPSD 两个代表（其他 self-distillation variant 未覆盖）
- OOD split 定义可能影响结论
- 没看到在 multi-modal 或 agentic long-horizon 的评估
- Negative result 的 reproducibility 价值
