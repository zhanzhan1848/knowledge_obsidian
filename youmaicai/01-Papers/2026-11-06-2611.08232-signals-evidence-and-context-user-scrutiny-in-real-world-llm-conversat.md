# Signals, Evidence, and Context: User Scrutiny in Real-World LLM Conversations

## 摘要
LLM 常常给出综合性的答案，却**不提供便于检查的支撑证据**。本文研究答案的特征与用户后续**接受、检查、质疑**行为的关系，数据来自 **ShareChat 与 WildChat 的 489,283 条助手-用户回复对**。关键数字：**31.9%** 的合格回复出现**归因语言（attribution language）**，而**显式 URL 仅占 1.33%** —— 揭示了「**声称有据**」与「**保留可检查的支撑**」之间的巨大落差。归因、不确定性等回复线索通常**同时伴随**检查与质疑；**只有不确定性**显示出统计上可区分的、偏向「检查」的聚合关联。在 Technical Help 子集中，不确定性偏向检查而非质疑；在 Seeking Information 中，**拒答与推理轨迹偏向质疑**。质疑集中在部分对话上；其表面上的**逐轮持续性**在**分离对话级差异与回复顺序后大幅缩小**。结论：支持验证需要关注**哪些证据可被检查**、**用户想解决什么问题**、以及**交互历史**。

## 核心贡献
1. 基于 **489,283 条真实用户-助手回复对**（ShareChat + WildChat）研究回答线索与用户审查行为的关系
2. 量化核心落差：**31.9% 的回复含归因语言 vs 仅 1.33% 含显式 URL** —— 声称有据 ≠ 证据可查
3. 发现**只有不确定性**与「检查」有统计可区分的聚合关联（归因等其他线索无区分度）
4. 揭示**逐轮持续性的测量假象** —— 控制对话级差异与回复顺序后，表面的持续性大幅缩小
5. 细分场景：**Technical Help** 中不确定性偏向检查；**Seeking Information** 中拒答与推理轨迹偏向质疑

## 方法与架构
**数据**：ShareChat + WildChat，**489,283** 条回复对。

**行为标注**：accepting / checking / challenging 三类用户后续行为。

**回复线索**：归因语言（attribution）、不确定性（uncertainty）、显式 URL、拒答（refusal）、推理轨迹（reasoning traces）。

**分析层次**：
- 聚合关联（pooled association）—— 线索与「检查 vs 质疑」的关联；
- 场景细分（Technical Help / Seeking Information）；
- **持续性检验** —— 分别控制**对话级差异**与**回复顺序**后重估逐轮持续性。

## 实验结果
- **31.9%** 合格回复含归因语言；**仅 1.33%** 含显式 URL → **声称有据 vs 证据可查的巨大落差**
- **只有不确定性**显示统计可区分的、偏向「检查」的聚合关联
- **Technical Help**：不确定性偏向检查相对质疑
- **Seeking Information**：**拒答与推理轨迹偏向质疑**
- 质疑集中在部分对话；**分离对话级差异与回复顺序后，表面逐轮持续性大幅缩小**
- 489,283 条回复对

## 局限性
- 观察性研究，无法建立因果（不确定性线索未必导致检查行为）；
- 回复对来自公开数据集，存在选择偏差（用户本就有审查倾向才被记录）；
- 线索的自动抽取可能有误分类误差，摘要未报告抽取可靠性。

## 值得注意的点
**31.9% vs 1.33%** 这组数字是今日最实用的产品洞察：绝大多数「我查了资料」的表述**没有留下任何可核验的痕迹**。而真正能引导用户去核实的行为信号是**不确定性** —— 不是引用，不是详细解释。这也直接说明为什么本批次多篇强调「可验证形式」（SciClaimEval 的证据对、TCSExam 的 Lean 内核、SAUCE 的离散事实）。
