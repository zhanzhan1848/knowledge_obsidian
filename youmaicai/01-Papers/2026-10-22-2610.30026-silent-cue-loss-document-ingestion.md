## 核心贡献
1. 证明**所有主流文档转换器都会静默丢失一层信息**——作者编码在"文本外观"中的含义；且这种丢失让 agent 变得"自信地错误"而非"明显地不完整"。
2. 构建了一个来自 **76 份真实政策文档**的任务：恢复作者特别标记 (singled out) 的要求项。评分使用文件自身的 **OOXML properties** 做**确定性匹配器**，完全不使用 LLM judge，规避 judge 偏差。
3. 用 **span-level leave-one-out** 把损失精确定位到两个 cue：**highlight (+0.302)** 与 **colour (+0.262)**（均 Holm-adjusted $p < 10^{-4}$），而 bold、italic、monospace、strikethrough 的贡献都在 $\pm 0.003$ 以内（近乎为零）。同一不对称性在 PDF 中同样出现。
4. 量化了问题的普遍性与可修复性：**6,460 份文档中 32.8%** 带有刻意的 colour 或 highlight，其中 10.3% 出现在 obligation（义务条款）上；预注册测试显示**主动为 agent 打出 cue 文字**比仅保留它额外带来 **+0.085**（Holm-adjusted $p = 0.049$）。

## 问题动机
企业 agent 是要"按文档行事"的。在 agent 能够遵循政策、回答合规问题或开单之前，必然有一个 **ingestion 层**把 Word 文件或 PDF 转换成 token——而论文指出，正是这一层让真实部署中的 agent 静默地丢失信息。关键在于：丢失的不是文字，而是**排版语义**。作者用高亮、颜色标出的"这条是义务/这条是关键"，在纯文本化后彻底消失。更危险的是这种丢失的表现形式是**静默的**：agent 不会说"我没看到格式信息"，它只会**猜**，从而给出**自信地错误**的答案。这类失效比显式报错更难排查，也解释了为什么现有解析 benchmark 完全没有捕捉到它——**没有任何主流解析 benchmark 对 colour 打分**。

## 方法
### 任务与评测设计
- 语料：**76 份真实政策文档**。
- 任务：恢复作者 singled out 的 requirement（被标记强调的要求）。
- **Ground truth 来源**：文件自身的 **OOXML properties**——即文档 XML 中记录的格式属性，视为确定性真值。
- **评分器**：**确定性 matcher**，明确**不使用 LLM judge**（这是方法论上的关键选择，避免用一个有偏 judge 去评另一个模型的偏差）。
- 指标：micro F1、false-positive rate、leave-one-out 归因、AUC。

### 消融与归因
- **Formatting-blind ingestion**：把格式信息移除后重跑，度量性能崩塌幅度。
- **Span-level leave-one-out**：逐个屏蔽某类 cue，度量该 cue 对性能的边际贡献，用于定位"到底是哪几种格式在起作用"。

### 验证设计
- **跨模态标签验证**：用渲染后的页面图像 (rendered page images) 作为**独立模态**验证标签，一致性 **kappa = 0.72**。
- **纯文字能力上界**：以 AUC 0.664 界定"仅靠 wording 最多能达到什么水平"，从而说明格式信号是**不可被文字替代**的。
- **预注册测试 (pre-registered test)**：检验显式为 agent 打出 cue 文字相对仅保留格式的额外增益。

## 实验设置与结果
- 数据/基准: 自建的 76 份真实政策文档任务；另有 **6,460 份文档**用于统计 colour/highlight 的普遍性。跨两个供应商的 **6 个 answering model**：Claude 系列 5 个（覆盖 Opus、Sonnet、Haiku 三档）与 OpenAI **GPT-5.6**。
- 对比方法: **docling** 与 **plain text** 两种 ingestion 配置；以及带完整格式的 ingestion 作为上界。
- 主要结果（摘要明确给出）:
  - Formatting-blind ingestion 使 micro F1 从 **0.690 崩塌至 0.150（docling）和 0.075（plain text）**；该差距在来自两个供应商的 6 个 answering model 上复现。
  - 无法看到 cue 的 agent 会**猜测**；docling 在"作者未标记的要求"上的**误报率是本文方法的 4 倍**。
  - Span-level leave-one-out 定位：**highlight (+0.302)**、**colour (+0.262)**，均 Holm-adjusted $p < 10^{-4}$；bold / italic / monospace / strikethrough 各在 $\pm 0.003$ 内（约为零）。同一不对称性出现在 PDF。
  - 普遍性：**32.8%** 的 6,460 份文档带有刻意 colour 或 highlight，其中 **10.3%** 落在 obligation 上。
  - 预注册测试：主动打出 cue 文字带来 **+0.085** 额外增益（Holm-adjusted $p = 0.049$）。
  - 跨模态标签验证 **kappa = 0.72**；纯文字上界 **AUC 0.664**。

## 关键技术细节
- 真值来自 **OOXML properties** 而非人工标注，这是整套设计能规模化的前提，也使评测完全确定性、无 judge 噪声。
- 使用 **Holm 校正**做多重比较校正，说明论文对多重假设检验有统计严谨意识（6 个模型 × 多个 cue 的组合必然需要）。
- **docling** 是被点名的对照转换器，代表当前主流文档 ingestion 的水平；其误报率 4 倍于本文方法是很有说服力的实践证据。
- 论文共 28 页、5 幅图。
- 核心结论的操作化含义：**ingestion 而非 reasoning 才是可靠性的胜负手**，且修复方案"便宜且可度量"。

## 局限性
- 语料仅 **76 份政策文档**（虽标注为 real，但领域单一），跨领域泛化性需谨慎对待。
- 真值依赖 OOXML properties，因此仅适用于 Word/.docx 文件；PDF 路径的对应分析在摘要中只提到"出现同样的不对称性"，未给出 PDF 侧的数值。
- 六个 answering model 集中于两个供应商（Anthropic + OpenAI），且 5 个 Claude 模型占多数，跨厂商结论的独立性有限。
- colour/highlight 是"高亮类 cue"；结论能否推广到表格结构、批注、脚注、修订痕迹等其他承载语义的文档元素，摘要未涉及。
- AUC 0.664 与 kappa = 0.72 说明标签本身并非完美，纯文字上界本身也不高，指标解读需谨慎。
- 论文明确给出了 +0.085 的"主动打 cue"增益（Holm-adjusted $p = 0.049$），该 p 值处于临界水平，效应量也较小，属弱证据。
