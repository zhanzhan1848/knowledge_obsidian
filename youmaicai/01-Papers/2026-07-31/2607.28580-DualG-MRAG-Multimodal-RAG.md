## 核心贡献

1. **双层图架构**：提出 DualG-MRAG，首次将多模态 RAG 解耦为宏观推理图和微观匹配图
   - Macro Graph：全局拓扑路由，处理跨文档关系
   - Micro Graph：精确局部验证，保留细粒度视觉证据

2. **Query-Driven GNN Retriever**：首次将 GNN 机制引入多模态 RAG 场景
   - 查询驱动的消息传递，动态对齐异构跨模态证据
   - 克服静态图结构的局限

3. **动态规划路径解码**：从 GNN 前向传播中直接提取显式推理路径
   - 用结构化推理链替代标准独立文档块输入
   - 降低生成模型的结构推理负担

## 三大挑战与解决

### Challenge I: 细粒度表示 vs 检索噪声
- 细粒度视觉特征 → 图快速膨胀 + 视觉检索噪声
- 粗粒度抽象 → 丢弃精确特征验证所需的关键局部证据
- **解法**：双层图分离宏/微观处理

### Challenge II: 静态图结构 vs 动态查询
- 预定义静态拓扑：结构和传播权重与查询无关
- **解法**：Query-driven GNN，查询条件动态控制信息传播

### Challenge III: 缺乏异构证据跨文档显式融合
- 传统方法将多模态文档展平为列表（如 top-K 块拼接）
- 让 MLLM 从碎片化输入中重建复杂关系，负担过重
- **解法**：显式推理路径解码机制

## 框架细节

### Dual-Tier Multimodal Graph

**Macro Graph 𝒯^M = (ℰ^M, ℛ^M)**
- 全局实体 + 关系
- 使用冻结 VLM 生成图像简短事实描述（caption）
- OpenIE 提取三元组 + 基于 Cosine similarity 的等价边

**Micro Graph 𝒯^m**
- 细粒度 4 元组：f = (u, r, v, d)
  - u, v: 头尾节点（文本锚点）
  - r: 关系（包含空间关系、对象属性等细粒度视觉细节）
  - d: 源文档指针（图像文件路径等）

### Query-Driven GNN Retriever
- 查询 + 补充实体初始化动态状态
- 有向消息传递在 Macro Graph 上传播相关性
- 最终输出文档相关性得分

### Dynamic Programming Path Decoding
- 层间动态规划算法
- 从 GNN 前向传播直接提取最优推理路径
- 将多模态拓扑连接序列化，结构化引导 MLLM 生成

## 实验结果
- 在多模态多跳推理基准上，DualG-MRAG 在证据召回率和复杂 QA 准确率均优于基线

- **是否推荐使用**：是
