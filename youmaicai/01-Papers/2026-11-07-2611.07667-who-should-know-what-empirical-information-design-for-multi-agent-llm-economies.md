# Who Should Know What? Empirical Information Design for Multi-Agent LLM Economies

| **发表** | arXiv preprint |
| **链接** | [原文](https://arxiv.org/abs/2611.07667) |

### 核心贡献
1. 提出 **empirical information design（实证信息设计）** 实验框架：在由 LLM agent 构成的经济市场中，**固定交互规则与模型**，系统比较不同 **信息披露策略（disclosure policies）** 对集体结果的影响。
2. 在 **10 个前沿 LLM**、三类市场（multi-resource trade、bilateral bargaining、double auction）上评估，并利用 **ground-truth utilities** 把「识别到的机会」与「实际实现的结果」解耦。
3. 核心发现：**更细粒度的信息披露效果高度依赖模型**——透明化有时提升效率、有时反而制造「透明度悖论」；因此 **模型选择与信息设计必须联合优化（co-optimized）**。

### 技术方案
**核心思想**: 把「信息披露多少」当作经济制度设计变量（information design），在可控的 agent 市场里做受控实验：用真实效用函数把「agent 是否发现了机会」与「是否成功把机会变成收益」拆开，从而定位失败到底来自认知还是来自战略互动。

| 技术 | 说明 |
|------|------|
| Empirical information design | 实验框架：控制交互规则与所用模型不变，仅改变披露策略（披露内容与粒度），做受控对比 |
| 三类 agent 市场 | ① **multi-resource trade**（多资源交易）② **bilateral bargaining**（双边谈判）③ **double auctions**（双向拍卖） |
| Ground-truth utilities 解耦 | 用真实效用函数把「**识别到的机会**」与「**实现的结果**」分开衡量，从而区分「没看见」与「看见但没做成」 |
| 披露粒度对比 | 具体估值（exact valuations）vs. 序数偏好排序（ordinal preference rankings）；谈判中的均衡性；拍卖中的报价行为 |
| 10 个前沿 LLM | 包含 GPT-6 Sol、Claude Sonnet 5、Claude Opus 5.5、Grok 4.7、Gemini 3.1 Pro 等（摘要点名这些） |

### 实验结果
- **数据集**: 三个合成 agent 市场环境：multi-resource trade、bilateral bargaining、double auction（摘要未说明具体数据集名）
- **基线**: 同一模型在不同披露策略下的对照（序数偏好排序 vs. 精确估值；完全披露 vs. 有限披露）；摘要未列出传统博弈论 agent 作为基线
- **结果**:
  - **Trade**：披露精确估值而非序数偏好排序，使 GPT-6 Sol 的实际收益从最大值的 **98% 降到 91%**，却使 Claude Sonnet 5 从 **72% 升到 86%**
  - **Bargaining**：精确信息使 Grok 4.7 产出 **更不均衡**的协议，而 Claude Opus 5.5 则把收益 **对称分配**
  - **Double auction**：完全披露推高要价、引发 **市场崩溃**，福利下降——Gemini 3.1 Pro **97% → 78%**、Claude Opus 5.5 **94% → 64%**、Grok 4.7 **97% → 62%**

### 局限性
- 三个市场都是 **合成环境**（multi-resource trade、bilateral bargaining、double auction），与真实多方市场/法律制度的差距未量化
- 效用为 ground-truth 设定，现实中的偏好学习误差未纳入
- 只改变披露策略这一变量，未系统考察「改变模型」与「改变制度」的联合优化策略
- 摘要未说明每种设定下的样本量、重复次数与显著性检验方式

### 关键洞见
> 透明度并不自动带来更好的集体结果：在双向拍卖里完全披露会推高要价、让市场直接崩溃（福利 94%→64%），而且「披露是否有害」几乎完全由 **模型自身的战略倾向** 决定——同一个制度对 Claude Opus 5.5 是对称分配，对 Grok 4.7 却是不均衡协议。所以 **agent 的「性格」必须成为制度设计的一部分**。
