## 核心贡献
1. **MAP**（Middle-layer Attention Prediction）：预测最佳中间层注意力以指导视觉 token 剪枝
2. **Question Contrastive Teacher Selection**：通过对比原始问题和参考问题下的注意力，识别样本特定的教师层
3. **轻量级预测器**：从多模态输入特征蒸馏注意力到轻量预测器，避免推理时处理大量视觉 token

## 问题背景

### 两个核心问题
1. **层间差异**：不同样本中，对问题最敏感的中间层差异很大，预定义固定层是次优的
2. **计算浪费**：获取中间层注意力需要先把大量视觉 token 通过多个语言模型层处理，此时已消耗大量算力

## 方法

### MAP 架构
```
原始问题 + 参考问题 → 对比注意力 → 样本特定教师层 → 蒸馏到轻量预测器
```

**两个组件：**

1. **Question Contrastive Teacher Selection**
   - 对比原始问题 vs 参考问题的注意力
   - 识别哪个中间层对问题的注意力响应最强
   - 该层即为该样本的"教师层"

2. **Lightweight Predictor**
   - 输入：多模态特征（视觉 + 文本特征）
   - 输出：每个视觉 token 的重要性分数
   - 在第一个 LM 层之前执行剪枝

### 推理时剪枝
- 合并**预测重要性分数** + **多样性准则**
- 在第一个 LM 层之前剪枝视觉 token
- 无需注意力图

## 实验结果
- **基准**：10 个 benchmark，LLaVA-NeXT-7B
- **视觉 token 保留**：仅 5.56% 的视觉 token
- **性能保留**：97.5% 的未剪枝模型性能
- **端到端加速**：**3.09×**
- 可与现有推理加速技术兼容

## 局限性
- 需要额外的蒸馏训练阶段
- 主要在 LLaVA-NeXT-7B 上验证，泛化性待更多实验

## 建议
- **是否推荐**：✅ 是（对 MLLM 部署极具价值）
- **适用场景**：MLLM 部署加速、边缘设备推理、实时多模态应用
- **相关方向**：Multimodal LLM、Efficient Inference、Visual Token Pruning
