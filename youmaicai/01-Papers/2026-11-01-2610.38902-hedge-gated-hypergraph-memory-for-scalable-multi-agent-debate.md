## 核心贡献

> HEDGE 用语义超图 + 三档记忆路由，准确率 +5.0 点的同时内存 -48%、辩论轮数 -34%。

1. 提出 HEDGE：把辩论轨迹表示为**语义超图**的selective memory 框架，超边连接跨 agent 的相关主张，超边内部的关系图保留细粒度论证结构。
2. 学习式记忆选择模块（MSM）经监督学习与强化学习训练，把每个记忆候选路由到 STORE / BACKUP / OMIT 三个动作，在保留有用信息的同时限制冗余。
3. 在 7 个多样基准上一致优于强单 agent、多 agent 与记忆基线，相比最强多 agent 系统（GPT-4o-mini）平均提升 **5.0** 点；冲突密集任务上提升 **8.2** 点，同时**内存使用减少 48%、辩论轮数减少 34%**。

## 技术方案

### 核心思想

多 agent 辩论系统需要在多轮之间保留并重新调取论证，但上下文窗口有限、无结构记忆又让相关信息越来越难找。现有做法中的**扁平记忆**与**成对图记忆**还有一个共同缺陷：它们难以表达**高阶关系** —— 多 agent 之间的认同、冲突证据、以及随轮次演化的共识。

HEDGE 的方案是把辩论轨迹表示为**语义超图**。超边（hyperedge）连接跨 agent 的相关主张（这天然表达了「多方共享同一议题」这种多元关系），而超边内部保留一个关系图以保存细粒度的论证结构（谁反对谁、谁支持谁）。这个双层结构正好对应两类信息：议题级的聚类与论证级的结构。

但有了结构还不够 —— 全存下来会淹没在冗余里。因此 HEDGE 引入**记忆选择模块（MSM）**，通过监督学习 + 强化学习训练，把每个候选记忆路由到三个动作之一：
- **STORE** —— 存下来（重要）
- **BACKUP** —— 备份（有用但可降级）
- **OMIT** —— 丢弃（冗余）

这个三档路由比二元的存/不存更细，也让 MSM 可以直接用强化学习优化「记住多少、记住什么」。最终效果是**准确率与资源占用同时改善** —— 这比单纯的准确率提升更难。

### 关键技术

| 技术 | 说明 |
|------|------|
| 语义超图记忆 | 超边连接跨 agent 相关主张，表达认同 / 冲突 / 共识等高阶关系 |
| 超边内关系图 | 在超边内部保留细粒度论证结构（支持 / 反对关系） |
| 记忆选择模块 (MSM) | 学习式路由器，输出 STORE / BACKUP / OMIT 三档动作 |
| 监督 + 强化学习训练 | MSM 用监督学习初始化并以强化学习优化记忆预算 |
| 辩论轨迹结构化 | 把多轮辩论过程本身建模为可导航的图结构 |

## 实验结论

- **数据集**: 7 个多样基准（覆盖辩论、多 agent 协作与记忆任务，含冲突密集任务）
- **基线**: 强单 agent 系统、GPT-4o-mini 的多 agent 辩论系统、扁平与成对图记忆基线
- **结果**: 一致优于所有基线，相比最强多 agent 系统平均提升 5.0 点，冲突密集任务上提升 8.2 点；同时内存使用减少 48%、辩论轮数减少 34%。

- **准确率与成本同时改善** 是本文最有分量的结果：+5.0 点准确率、-48% 内存、-34% 轮数，三者同时发生通常极难。
- **超图 vs 成对图** 的表达力差异在冲突密集任务上体现最充分（+8.2 点）—— 高阶关系正是成对图缺失的部分。
- STORE / BACKUP / OMIT 三档路由比二元存废更精细，也让 RL 可以直接优化记忆预算。
- 减少辩论轮数意味着**更少的上下文膨胀**，这是多 agent 系统实际的成本痛点。
- 「减少轮数还更准」暗示了低质量轮次的识别 —— MSM 在丢弃冗余论证。

## 局限性

['超图表示的记忆结构对简单任务可能过重，超参与结构构建开销未详述。', '依赖 MSM 的判别质量，冲突密集任务上的提升是否可推广到其他冲突形态未知。', '轮数减少可能部分源于提前终止，若评测以轮数为约束则结论需谨慎解读。', '7 个基准的覆盖面有限。']

---

## 实现建议

- **实现难度**: 中（需超图构建、MSM 训练与辩论循环的完整实现）
- **适用场景**: 多 agent 辩论系统、长期记忆架构、上下文压缩、多 agent 冲突消解
- **建议**: **记忆系统不要只做「存/不存」**。引入三档路由（存 / 备 / 弃）并用 RL 训练选择器，能同时拿到准确率与成本收益。另外，多 agent 关系用超图而非成对图表达 —— 冲突密集场景差距最明显。

## 原始摘要

```
Multi-agent debate systems require agents to retain and revisit arguments across multiple rounds, yet limited context windows and unstructured memories make relevant information increasingly difficult to recover. Existing flat and pairwise-graph memories also struggle to capture higher-order relations, including multi-agent agreement, conflicting evidence, and evolving consensus. We introduce HEDGE, a selective memory framework that represents debate trajectories as semantic hypergraphs. Hyperedges connect related claims across agents, while intra-hyperedge relational graphs preserve fine-grained argumentative structure. A learned memory selection module (MSM), trained through supervised learning and reinforcement learning, routes each memory candidate to STORE, BACKUP, or OMIT, retaining useful information while limiting redundancy. Across seven diverse benchmarks, HEDGE consistently outperforms strong single-agent, multi-agent, and memory baselines, improving accuracy by 5.0 points on average over the strongest multi-agent system with GPT-4o-mini. The gains reach 8.2 points on conflict-heavy tasks, while HEDGE reduces memory usage by 48% and the number of debate rounds by 34%.
```
