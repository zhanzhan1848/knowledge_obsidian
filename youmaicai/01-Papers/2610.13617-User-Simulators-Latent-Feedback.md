## 核心贡献

> 提出带 **latent intrinsic feedback** 的 user simulator：内部 thoughts + reactions + scalar ratings 作为 turn-level 评估信号，无需显式语言表达。

1. **训练方式**: 用真实 user-assistant 交互 log 训练 LLM-based simulator
3. **多 turn RL 提速**: 用 intrinsic feedback 做 RL 奖励，**RL compute 减半** 且匹配外置 judge LLM
4. **相关性**: 评估与人类判断相关性优于同规模 prompted simulator

---

## 技术方案

### 核心思想

user simulator 传统聚焦生成真实 utterance。本文同时让 simulator 持有 **latent evaluation state**（内心 thoughts + reactions + scalar rating），用 first-person user 视角做 turn-level critique。

### 关键技术

| 技术 | 说明 |
|------|------|
| Intrinsic feedback | latent 评估状态（非显式语言）|
| First-person evaluation | 从 user 视角评估 assistant |
| Turn-level rating | 每个 turn 一个 scalar rating |
| Trained simulator | 用真实交互 log 训练（非纯 prompted）|
| Multi-turn RL reward | 用 simulator 的 intrinsic feedback 做 RL 奖励 |

---

## 实验结论

- **数据**: 真实 user-assistant 交互 log
- **结果**:
  - 仿真 realism 与 critiquing 行为优于 prompted simulator
  - Turn-level evaluation（现有 fine-tuned simulator 缺乏）
  - 评估与人类判断相关性更高
  - 多 turn RL 中：替代外部 judge LLM，**RL compute -50%+**

---

## 局限性

- Latent state 可解释性弱（与 mechanistic interpretability 关联未探索）
- 仅在 user-assistant 对话场景验证，task-oriented agent 未覆盖
- Intrinsic feedback 的 reliability 依赖训练 log 质量

---

## 实现建议

- **实现难度**: 中（需要交互 log + 训练框架）
- **预期性能**: RL 训练成本 -50%，相关性与人类判断更接近
- **适用场景**: chatbot RLHF、多 turn 对话训练环境
