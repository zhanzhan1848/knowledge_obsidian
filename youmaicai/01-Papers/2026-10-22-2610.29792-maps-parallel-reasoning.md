## 核心贡献
1. 提出并分析 **search momentum（搜索动量）** 这一新概念，用于刻画 reasoning 过程中 query intent 的演化：它捕获由 sub-query 历史变化沿 reasoning 轨迹**累积的检索倾向**。
2. 通过动量分析发现关键规律：**query 生成过程倾向于沿既有检索轨迹持续演化**（导致 query-intent drift）。
3. 提出 **MAPS（Macro-Adaptive Parallel Reasoning）** 框架，通过两步机制调节 search momentum、抑制 query-intent drift：
   - **状态重置/精炼**：保留检索到的知识与一个 refined reasoning state，从而降低历史 reasoning 轨迹对后续 sub-query 生成的累积影响。
   - **并行推理**：将传统顺序推理扩展为 parallel reasoning。每轮识别互补的检索方向，为各方向并行生成 sub-query 并行检索，再整合证据更新知识与推理状态。
4. 在 **6 个 QA benchmark** 上、跨不同 backbone model 一致优于代表性 RAG 方法。

## 问题动机
interleaved reasoning-and-retrieval 类的 RAG 方法让 LLM 逐步生成 sub-query 并检索外部知识，但存在两类问题：**(i)** 产生冗余或无效的 sub-query；**(ii)** query exploration 的多样性不足。更根本的疑问是：由于推理与检索紧密交织（tightly interleaved），**不断演化的推理过程究竟如何影响 query intent**——此前没有合适的刻画工具。本文引入 search momentum 正是为了量化这一被忽视的机制层面问题。

## 方法
**分析层 —— search momentum**
定义 search momentum 为：沿 reasoning 轨迹，由历史生成的 sub-query 变化所**累积诱导出的检索倾向**（accumulated retrieval tendency）。基于该量的动量分析得到的实证规律是：query 生成会持续沿既有检索轨迹演化，即形成正反馈式的动量累积，最终导致 query-intent drift。

**框架层 —— MAPS，两个机制**

1. **保留精炼状态（Retain refined state）**：保留已检索知识 + 一个 refined reasoning state，降低历史 reasoning 轨迹对后续 sub-query 生成的影响 → 直接抑制动量累积。
2. **并行推理（Parallel reasoning）**：把常规 sequential reasoning 扩展为 parallel reasoning。每次迭代：
   - 识别**互补的检索方向（complementary retrieval directions）**
   - 为各方向生成对应的 **sub-query**，执行**并行检索**
   - **整合（consolidate）**检索到的证据，更新 knowledge state 与 reasoning state

并行化是「宏观（macro）」的补偿机制：既然顺序链条会积累动量造成 drift，就同时开多条互补方向以恢复 query exploration 的多样性。

> 摘要未给出 search momentum 的形式化定义式、动量衰减因子、每轮并行分支数量等参数，故此处不做公式补全。
