## 核心贡献
1. **GxP-Agent**: 多智能体系统，将监管流程ordering编码为有向无环图(DAG)，将整体数据集生成分解为15个领域特定节点
2. **CDISC-Bench**: 新执行基准，基于FDA pilot submission CDISCPilot01 (254 subjects, 49 ground-truth ADSL variables)
3. **领域知识编码为图拓扑**: 不依赖LLM单独推理，而是编码领域流程知识

## 模型架构
- **15个领域特定节点**: worker agents with pharmaverse skill context
- **验证门控(validation gates)**: 每节点输出验证
- **条件重试(conditional retry)**: 失败时自动重试
- **DAG拓扑**: 节点间的依赖关系和执行顺序

## 关键结果
| 方法 | 结构匹配率 |
|------|-----------|
| GxP-Agent + Claude Sonnet 4.6 | **100%** (49/49 variables) |
| GPT-4.1 + DAG topology | 59.2% |
| 其他单/多智能体方案 | 0% |
| Best retrieval-augmented baseline | 59.2% |

- ADAE场景(9-node branching DAG, 55 variables, 1,191 records): 首次尝试即达100%
- DAG拓扑使弱模型也能工作: GPT-4.1在DAG下达59.2%，其他架构下为0%

## 核心洞察
- **关键发现**: 将领域知识编码为图拓扑，而非依赖LLM推理，是实现可靠GxP合规临床试验编程的关键
- 监管流程有明确的ordering约束，适合DAG表示

## 局限性
- 仅测试了CDISC标准场景
- 需要领域专家定义初始DAG结构
