# TopoQuant: Topological Framework to Characterize Behavioral Shifts in Quantized Large Language Models

## 核心贡献
1. **TopoQuant 框架**：首个用**拓扑数据分析（Topological Data Analysis, TDA）**量化 LLM 自注意力权重**结构漂移（structural drift）**，并将其与量化模型**行为变化**建立关联的框架。
2. **揭示阈值效应**：拓扑漂移在**中等压缩率下保持稳定**，但在**低于 4 bit 精度时急剧上升**，且紧密跟随**注意力一致性（attention agreement）**的下降。
3. **轻量预测器**：证明拓扑特征可以**准确预测注意力一致性**，用轻量机器学习模型达到最高 **R² = 0.85**。
4. **实用价值**：通过预测注意力一致性，可在**不运行昂贵下游任务**的前提下评估量化模型的行为一致性——从而**无需大量下游评测即可识别安全的压缩极限**。

## 问题背景
训练后量化（Post-Training Quantization, PTQ）能降低 LLM 的计算成本，但它可能在模型内部引入**结构性与行为变化**，而传统指标（accuracy、perplexity）**捕捉不到**这些变化。原因在于准确率/困惑度是端到端聚合标量，具有严重的"信息压缩"与"滞后性"——需要跑完整评测集才能看到退化，且无法定位退化的结构来源。因此需要一种**廉价的、前置的（early-warning）、且能反映内部结构变化**的量化健康度指标。本文提出从自注意力权重矩阵本身入手：用 TDA 提取其拓扑特征（持续同调类、persistence diagram 等），把这些结构特征作为量化损伤的"指纹"。

## 方法

### 整体流程
```
量化模型 (W_q)  →  提取自注意力权重矩阵
                      ↓
              TDA 拓扑特征提取
              (持续同调 / persistence 结构)
                      ↓
              拓扑漂移度 (topological drift) 量化
              ↓
        轻量 ML 预测器 (预测 attention agreement)
                      ↓
      行为一致性评估 / 安全压缩极限判定
```

### 步骤 1：拓扑漂移的度量
对原始（FP）与量化后的**自注意力权重**做拓扑数据分析（TDA），提取其**持续同调（persistent homology）**信息，得到可比较的拓扑摘要。以**拓扑漂移（topological drift）**作为量化前后该摘要的距离/差异量。

这一选择有明确动机：注意力权重矩阵的结构（聚簇、环、连通分支的层级）比逐元素的数值误差更能反映"功能连接模式"是否被破坏——一个矩阵可能数值上有很多小误差，但拓扑结构完好；也可能数值误差不大，却破坏了关键拓扑特征。

### 步骤 2：关联行为指标
以**注意力一致性（attention agreement）**作为行为侧的行为度量——即量化模型与原始模型在注意力行为上的一致程度。TopoQuant 检验拓扑漂移与注意力一致性的关系。

### 步骤 3：轻量预测器
用提取到的拓扑特征训练**轻量机器学习模型**来预测注意力一致性：

```math
\widehat{\text{agreement}} = f_{\text{ML}}\big(\text{TDA features}(W_q), \text{TDA features}(W_{fp})\big)
```

摘要未披露具体特征集（使用哪种持续同调维度、相似性函数等）、ML 模型族（线性回归 / 树模型 / 小型 MLP）与超参。

### 步骤 4：安全压缩极限识别
由于预测器可作为代理，就能在给定压缩比下**快速估计**注意力一致性退化程度，从而定位**哪些量化位宽仍然安全**，避免为每个候选配置都跑完整下游评测。

## 实验结果

### 实验设置
| 维度 | 设置 |
|------|------|
| 模型家族 | **4 个 LLM 家族** |
| 量化位宽 | 多个量化级别（含 >4bit 与 <4bit 区间） |
| 结构分析对象 | 自注意力权重 |

### 主要结果
| 发现 | 具体数值 |
|------|---------|
| 拓扑漂移 vs 压缩率 | 中等压缩水平下**保持稳定**；**低于 4 bit 精度时急剧上升** |
| 拓扑漂移 vs 注意力一致性 | **强相关**，拓扑漂移的上升紧密跟随注意力一致性的下降 |
| 预测性能（轻量 ML） | 最高 **R² = 0.85** |
| 评测开销 | 无需运行昂贵下游任务即可检测量化诱导退化 |

摘要未给出具体量化方案（如 GPTQ/AWQ/所有标量量化）的对比、具体位宽列表、各家族名称、perplexity/accuracy 的具体数值表格。

## 关键洞察
1. **4 bit 是一个明确的"拓扑相变点"**：拓扑漂移在中等压缩下平稳、跌破 4 bit 后陡增，这比传统"精度随位宽平滑下降"的叙事更有用——它给出一个**可操作的、可被提前检测的悬崖位置**。这对"4 bit 是不是安全线"这一部署决策提供了独立于准确率的证据。
2. **R² = 0.85 的轻量预测器是本文最具工程价值的部分**：把"拓扑漂移"从一个解释性指标转化为一个**代理任务**（预测注意力一致性），意味着量化决策可以在几秒内完成而非几小时。这实质上是一个"量化健康度的快速筛查器"。
3. **拓扑结构比数值误差更能反映行为退化**：这提示注意力权重的**功能拓扑**是模型行为的关键承载层，对它的破坏比 Frobenius 范数之类的数值距离更致命。反过来说，量化算法若能在保持持续同调结构的前提下引入数值扰动，可能比一味做误差最小化更安全——这是摘要未展开但有暗示价值的方向。

## 局限性
- 摘要未指明具体的量化方法（GPTQ/AWQ/SmoothQuant 等）与具体位宽，因此"低于 4 bit 急剧恶化"的结论是否依赖量化算法**未知**。
- **注意力一致性本身不是下游性能**：用注意力一致性代理实际任务退化，中间存在假设跳跃，摘要未验证该代理在 accuracy/perplexity 上的保真度。
- 4 个 LLM 家族不足以确立普适阈值；摘要未说明是否覆盖不同架构（dense vs MoE）与不同规模。
- TDA 本身的开销（持续同调计算在权矩阵上的复杂度）未在摘要中报告，"轻量"的结论主要针对下游 ML 预测器而非特征提取环节。
- 关联性很强但**因果性**未被检验——拓扑漂移与注意力一致性可能同为量化的共同后果，而非互为因果。
- 未考虑量化之外的其他扰动（剪枝、低秩分解、蒸馏）是否适用同一拓扑框架。

## 适用场景
- **量化配置选型**：在部署前筛查哪些位宽/方案是安全的，无需完整跑下游 benchmark。
- **量化算法设计**：作为新的优化目标（保持拓扑结构）或新的评估维度。
- **LLM 压缩研究的度量补充**：与传统 accuracy/perplexity 并列的内部结构诊断工具。
- **模型服务健康监控**：线上模型被量化/替换后快速判断行为漂移。
