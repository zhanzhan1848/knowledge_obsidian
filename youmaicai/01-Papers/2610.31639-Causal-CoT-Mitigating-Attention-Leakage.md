## 核心贡献

> 提出 **CausalCoT** 推理框架：通过 **DAG 原子子问题分解 + 上下文隔离**，消除 attention leakage，使 CoT 中间步骤对最终答案**因果可证**，而非事后合理化。

1. **问题诊断**：标准自回归生成中 dense attention 允许每个推理步骤 attend 全部上下文 → 模型可通过**直接查表**得到答案，同时生成看似合理但**后见之明式**的 justification。CoT 的"解释性"并不保证因果性。
2. **CausalCoT**：把问题分解为**有向无环图**的原子子问题，每个节点在**只含其直接因果父节点**的隔离上下文中求值。
3. **Markovian 结构**：切断通往非父节点内容的 attention 通路 → 下游预测对**局部推理**敏感，而非全局上下文泄漏。
4. **可干预性**：结构化依赖图使 test-time 局部修正能**可预测地向下游传播**。

---

## 技术方案

| 组件 | 说明 |
|------|------|
| 问题分解 | 构造 DAG，每个节点 = 原子子问题 |
| 上下文隔离 | 节点 N 的输入仅含父节点（而非全部历史） |
| Markovian 求值 | 每个节点独立求值，输出作为子节点输入 |
| 因果敏感度指标 | 中间推理步对答案的因果贡献可量化 |
| Test-time 干预 | 修正某节点 → 下游路径确定性地受影响 |

### 关键洞见

- 传统 CoT 的"step-by-step rationale"是 **post-hoc justification** 的高发区。
- CausalCoT 用**信息隔离**换取**因果保真度**，是"解释即证明"的工程化实现。

---

## 实验结论

- **基准**：diverse reasoning benchmark suite
- **结果**：
  - 保持**有竞争力的预测性能**（不因隔离而掉点）；
  - **解释忠实度提升**；
  - 中间推理步的**因果敏感度**相对最强 baseline 平均 **+12 pp，最高 +21 pp**。

---

## 局限性

- DAG 分解的**成本与错误传递**（早期节点错 → 后续全错）未充分说明；
- 与并行/树搜索类推理（ToT / best-of-N）成本对比待评估；
- 对已有强 CoT prompt 工程的叠加效果未知。

## 实现建议

- **实现难度**：中（需子问题分解 + 拓扑调度 + 隔离重放）
- **预期价值**：高 — 适用于需要"可审计推理"的合规/医疗/金融场景
- **适用场景**：agent 决策链解释、模型调试、CoT 质量评估
- **建议部署**：作为**评测/审计层**接入，而非替换生产 CoT
