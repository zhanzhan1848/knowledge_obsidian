# JailBound: FOL-Guided Jailbreak Evaluation for Exploring LLM Behavioral Boundaries

> **arXiv**: [2611.07530](https://arxiv.org/abs/2611.07530)
> **发表日期**: 2026-11-05
> **分类**: cs.CR (Cryptography and Security)
> **会议/期刊**: NeurIPS 2026（40th Conference on Neural Information Processing Systems）

> ⚠️ **Warning**: 本论文包含可能冒犯或有害的攻击样例与越狱提示，请勿直接复用其攻击载荷；仅用于安全研究与防御评测。

## 📋 摘要

随着 LLM 越来越多地作为通用对话助手部署，它们必须在处理多样用户请求的同时可靠拒绝有害请求。Jailbreak 攻击通过构造对抗性指令或对话上下文，在已有安全护栏之下诱导出不安全响应。然而现有 jailbreak 基准多依赖人工设计或收集的 prompt，难以系统性地扩展到新的威胁条件；且现有攻击搜索方法通常只优化攻击成功率（ASR），对「模型行为在安全拒绝与不安全响应之间如何在局部发生变化」提供的洞察有限。为解决这些问题，本文提出 **JailBound**——一个统一的 jailbreak 评估框架，结合了自动化基准构建与**一阶损失（first-order loss, FOL）引导的双分支搜索**。JailBound 按风险类别（risk category）、应用领域（application domain）、攻击类型（attack type）组织威胁；在该分类体系条件下，一个**微调过的 meta-attack generator** 合成跨多样威胁条件的评测 prompt。FOL 被用作**局部敏感度信号**，用于探索「高价值攻击状态」（high-value attack states）与「行为敏感状态」（behavior-sensitive states）。作者在统一实验协议下跨 **13 个模型家族、46 个 LLM** 评测 JailBound。在匹配设置下，High-Value Branch 相对仅用 ZOL（zero-order loss）的基线，在两种评测设置下分别将平均 ASR 提升 **5.1** 与 **4.9** 个百分点。在局部扰动下，Safety-Sensitivity Branch 的状态在所有测试半径上的**行为翻转率**都高于 High-Value Branch 的状态（JailBound 与 S-Eval 均如此），表明由 judge 判定的安全标签具有更高的局部敏感度。

## 🎯 核心贡献

1. **自动化 jailbreak 基准构建流水线**：用「风险类别 × 应用领域 × 攻击类型」的威胁分类法条件化一个**微调的 meta-attack generator**，自动合成覆盖多样威胁条件的评测 prompt，摆脱对人工 prompt 收集的依赖，可系统扩展到新威胁条件。
2. **FOL 引导的双分支搜索**：首次把**一阶损失（first-order loss）** 作为局部敏感度信号用于 jailbreak 搜索，并据此拆成两个互补分支——**High-Value Branch**（探索高价值攻击状态，攻击成功导向）与 **Safety-Sensitivity Branch**（探索安全边界局部敏感状态，边界刻画导向）。
3. **从「ASR 最大化」到「行为边界刻画」的范式转变**：不仅报告攻击成功率，还用**行为翻转率（behavioral flip rate）** 度量模型安全标签在局部扰动下的脆弱性，揭示 judge 判定标签本身的高局部敏感度。
4. **大规模统一评测**：在统一实验协议下覆盖 **46 个 LLM / 13 个模型家族**，并与 S-Eval 等既有工作做同设置对比。

## 🔧 方法/架构

- **威胁分类法（taxonomy）**：威胁按三个维度组织——

  ```math
  \mathcal{T} = \mathcal{R} \times \mathcal{D} \times \mathcal{A}
  \quad (\text{risk category} \times \text{application domain} \times \text{attack type})
  ```

- **Meta-attack generator**：在该分类条件下微调的生成器，负责合成评测 prompt，从而实现威胁覆盖的自动扩展。
- **FOL 作为局部敏感度信号**：一阶损失（近似损失对输入的梯度方向）刻画攻击状态的局部敏感度，用于搜索两类状态：

  ```math
  \nabla_{\mathbf{x}} \mathcal{L}(\mathbf{x}; \theta)\ \text{as local sensitivity signal}
  ```

  - **High-Value Branch**：优化攻击成功率导向的「高价值攻击状态」。
  - **Safety-Sensitivity Branch**：定位安全拒绝/不安全响应边界附近「行为敏感状态」。
- **对照基线**：**ZOL-only baseline**（仅用零阶损失，即仅以 ASR 为目标的搜索）。
- **评估指标**：
  1. **ASR（attack success rate）**：攻击成功率。
  2. **Behavioral flip rate**：在给定扰动半径（radius）下，局部扰动导致安全判定翻转的比例。
- **对比工作**：JailBound 与 S-Eval 两种基准体系下的局部扰动实验。

## 📊 实验结果

- **规模**：**46** 个 LLM，来自 **13** 个模型家族，统一实验协议。
- **ASR 提升（High-Value Branch vs ZOL-only baseline）**：两种评测设置下平均 ASR 分别提升 **+5.1 pp** 与 **+4.9 pp**。
- **行为翻转率**：在所有测试半径上，Safety-Sensitivity Branch 的状态翻转率**一致高于** High-Value Branch 的状态（JailBound 与 S-Eval 两套基准上均成立），说明 judge 判定的安全标签局部敏感度更高。
- **摘要未披露具体数值**（各模型 ASR 绝对值、翻转率绝对数值）——详见原文实验章节。

## ⚠️ 局限性

- ⚠️ **本文包含可能冒犯或有害的示例与攻击 prompt**；使用其生成的攻击载荷需严格限定在授权的红队评估环境中。
- 搜索依赖**梯度信息（FOL）**，对仅能通过 API 访问的黑盒闭源模型不可直接使用（闭源模型评估需另走生成/查询路线）。
- ASR 依赖 judge 判定安全标签，而论文自身表明该标签具有**较高局部敏感度**——即指标本身存在噪声与不稳定性。
- 「局部敏感度」作为新指标，其与真实安全性损害（如实际有害内容危害度）之间的相关性尚不明确。
- 结论在 46 个模型上给出统一平均，但模型间方差与特定家族的行为差异在摘要中未展开。
- 攻击搜索本身具有**双用性**，公开发布的框架可能被滥用于生成更隐蔽的越狱攻击，防御侧价值与滥用风险需平衡评估。
