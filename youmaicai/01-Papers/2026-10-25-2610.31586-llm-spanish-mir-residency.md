## 核心贡献

> 医疗考试准确率常被用作「可用于临床」的证据，但自建硬件运行开源模型的卫生系统需要知道更多：**模型是否知道自己何时可能出错、医学微调是否改善这一能力、正确答案是否建立在合理的临床推理上、模型是否真的用到了给它的图像**。本文在**西班牙 MIR 住院医师考试**上，用**四个 8–27B 开源模型**、**八届共 1,552 道题**、按考试自身规则作答，回答这四个问题。

1. **按 MIR 官方规则完整评测**：**1,552 道题**、**八届（eight editions）**考试，**四个 8B–27B 开源模型**，逐题作答（Answering every question）。
2. **排名结论**：若三个较大模型**答完全部题目**，它们大致可排在**前 600 至 3,000 名考生**之间，且**仍有 41 至 43 个专科**对其开放。
3. **弃答（abstention）从不划算**：因为**即便是模型最不确定的答案，其正确率也高于 25% 的盈亏平衡点（break-even）** —— 校准度不够好到能靠弃答获利。
4. **医学微调的代价**：**降低了过度自信（overconfidence），但以准确率为代价**，且**没有改善「置信度区分对错」的能力**（即校准未真正提升）。
5. **推理与图像使用的两项发现**：**13–38% 的正确答案**是基于**临床上不成立的理由**排除了干扰项，而**置信度并不反映**这一点；**移除或替换所给的上下文图像（contextual images）后准确率不变** —— 说明模型**根本没有真正使用图像**。

## 技术方案

### 核心思想

**「准确率」作为临床部署证据的缺陷**：一个卫生系统要在自有硬件上跑开源模型，需要回答四个层次递进的问题：

| 层次 | 问题 | 对应技术手段 |
|------|------|--------------|
| L1 | 会不会做？ | 按考试规则完整作答 → 排名换算 |
| L2 | **知道自己会不会？** | **置信度 / 不确定性度量 + 弃答策略 vs 盈亏平衡分析** |
| L3 | 对的时候，**理由对不对**？ | **干扰项排除理由的临床合理性审计** |
| L4 | **真的用了图像吗？** | **图像移除/替换消融** |

**评测载体**：西班牙 MIR（Medical Internal Resident）考试 —— 真实的国家级住院医师选拔考试，含**八届**（跨度多年，便于检验时间漂移）、**1,552 题**，题目自带**上下文图像**（影像学病例题）。

**弃答盈亏平衡分析**：对于「是否值得弃答」这一决策，正确比较是
$$\text{弃答收益} = P(\text{对}) - \text{弃答成本}$$
只有当模型最不确定时的正确率**低于 25%**（四选一随机猜的期望）时，弃答才划算。结论是**模型远达不到这个门槛**，所以**弃答策略在本设定下是纯亏损**。

**「图像使用」的因果检验**：把上下文图像**移除或替换**（换成另一题的图），若准确率**不变**，说明模型的答案**根本不依赖图像** —— 这是判定「多模态能力是否真实存在」的标准消融。

**「推理质量」的审计**：不只看答案对错，还看**排除干扰项时给出的理由是否临床上成立（clinically sound）**。一个答对了但理由不成立的答案，在临床中**不可复用**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **MIR examination protocol** | 按考试自身规则作答；八届、1,552 题 |
| **Ranking estimation** | 将全答表现换算为考生排名（约前 600–3,000 名）与可报专科数（41–43） |
| **Abstention break-even analysis** | 比较弃答与猜答的期望收益，以 **25%**（四选一随机）为界 |
| **Confidence–correctness discrimination** | 检验置信度能否区分对错（校准质量，而非平均置信度） |
| **Medical fine-tuning comparison** | 微调前后在过度自信、准确率、校准分离度上的对照 |
| **Distractor-rejection reason audit** | 审计排除干扰项的理由是否临床上成立 |
| **Image removal / swap ablation** | 移除或替换上下文图像，检验答案是否依赖图像 |
| **Confidence–reason mismatch** | 置信度不反映推理缺陷这一发现 |
| **Open-weight models (8B–27B)** | 四个本地可部署模型，对应卫生系统自建硬件场景 |

## 关键实验结果

| 项目 | 结果 |
|------|------|
| **题目数** | **1,552** |
| **考试届数** | **8 届（eight editions）** |
| **模型数** | **4 个**，参数规模 **8B – 27B** |
| **排名（三个较大模型，全答）** | 约在**前 600 到 3,000 名考生**之间 |
| **仍开放的专科数** | **41 – 43 个** |
| **弃答盈亏平衡** | 最不确定的答案正确率**仍高于 25%** → **弃答从不划算** |
| **医学微调的效果** | **降低过度自信**，**但准确率下降**，且**置信度区分对错的能力未改善** |
| **推理缺陷率** | **13 – 38%** 的正确答案基于**临床上不成立的理由**排除干扰项 |
| **置信度与推理质量** | **置信度不反映**这些推理缺陷 |
| **图像消融** | **移除或替换上下文图像后准确率不变** → 模型**未真正使用图像** |

## 关键结论

1. **开源模型在国家住院医师考试上已具竞争力，但「考试排名」不是部署结论。** 全答可排进前 **600–3,000 名**、还有 **41–43 个专科**可报 —— 这确实值得注意；但本文的真正贡献是**说明为什么这还不够**。
2. **不确定性管理在当前模型上不成立 —— 弃答是纯亏。** 连**最没把握**的答案正确率都高于 **25%** 的随机基线，因此**任何形式的弃答/转人工策略在这个模型上都会降低表现**。这是**部署路线设计的关键约束**：不能指望模型自己把疑难病例转出去。
3. **医学微调改善的是「自信的样子」，不是「自信的准头」。** 过度自信下降（听上去是好事）伴随**准确率下降**，且**置信度区分对错的能力没有改善** —— 校准的关键指标（discrimination）没动，说明微调只是**平移**了置信度分布，**没有增加信息量**。这与「微调让模型更谨慎所以更安全」的直觉相悖，值得警惕。
4. **13–38% 的正确答案是「蒙对的」。** 临床不成立的排除理由在置信度上**没有任何体现** —— 因此**置信度不能作为「答案临床可用」的代理指标**，人工复核不能只抽查低置信度样本。
5. **多模态能力可能是不存在的。** 移除/替换图像准确率**完全不变** —— 对影像学考试而言，这意味着这些开源模型在 MIR 上的分数**基本可以由文本部分解释**，图像是被忽略的。

## 局限性

- **模型数量少（4 个）、规模区间窄（8B–27B）**：未覆盖前沿闭源模型，也未覆盖更大开源模型；**结论对更强模型的适用性未知**。
- **单一考试体系（西班牙 MIR）**：题目风格、评分规则、专科设置都是西班牙特有的；**「排名前 600–3,000」不可直接换算到其他国家/其他考试**。
- **「1,552 题 / 8 届」的题目构成未知**（客观题与病例题的比例、图像题占比）—— 而这直接影响第 5 条结论的强度。
- **排名换算是外推而非实测**：考生人数、分数分布、及格线等参照信息未在摘要给出，**排名区间的置信度不明**。
- **不确定性度量方法未披露** —— 摘要只说「模型最不确定的答案」，但**不确定性的来源（logprob？自生成置信度？多次采样一致性？）未说明**，而这**直接决定了弃答分析的结论**（不同度量会得到不同盈亏平衡点）。
- **弃答分析只给了单点结论**：25% 阈值来自四选一，但 MIR 是否全为四选一、**多选题的基线是 20% 还是更低**未澄清。
- **推理审计的评判者与流程未说明**：13–38% 这一区间的**上下界跨度很大**，暗示不同模型差异显著，但**未给出逐模型数字与判定标准**。
- **图像消融只做了移除/替换** —— 未与「仅给图不给文本」等更强对照，**也不能排除图像携带信息量本身很低**这一解释。
- **未评估真实临床任务**：考试题是**知识型**的，与门诊分诊、病历书写等**有交互的真实工作**差距大。

## 实现建议

- **实现难度**：低-中（公开考试题目 + 置信度抽取 + 图像消融；关键是准备好临床审校人力）
- **预期性能**：开源 8B–27B 模型全答约**前 600–3,000 名**、可报 **41–43 专科**；但**弃答无收益**，**图像消融不掉分**
- **适用场景**：**自建算力部署医疗模型的卫生系统 / 医院 IT 选型**；把 LLM 放入**临床辅助流程**（如病例摘要、初步分诊）前的风险评估
- **团队行动（按优先级）**：
  1. **不要设计「低置信度转人工」的流程** —— 弃答在此设定下是亏损；改为用**规则/检索**做转人工判定；
  2. 若产品含影像输入，**先做一次图像移除消融**确认模型真的在用图；
  3. 评测报告**必须包含推理理由的临床合理性审计**（参考 13–38% 这个量级），只报准确率会严重高估可用性
