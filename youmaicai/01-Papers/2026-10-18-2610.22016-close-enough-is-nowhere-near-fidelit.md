## 核心贡献

> Multi-agent LLM 通过 **KV cache 通信**（sender 的 reading → reader）被提议为文本通信的"无损"替代。但实证 **frozen transformer 只能读与自己会写的 cache 相近的子集**（**tolerable set**），**几何相似度不能预测 consumability**。8 种 substitution 方法 × 2 锚点（uninformative baseline / reader 自读）→ **全部 baseline**。**正确方向**：reader **保留自己 cache + 跨 sender cache attends**，**仅微调 queries** → 超越 baseline，且 8 senders pool 后超越 undirected attention。

1. **关键发现**：**KV cache fidelity ≠ consumability**（高保真 ≠ 可用）。
2. **Tolerable set**：frozen reader 仅读**与自身会写 cache 相近**的子集。
3. **8 种 substitution × 2 锚点 = 全部 baseline** → 长期一连串负面结果被整合为一个 outcome。
4. **机制**：competitive attention 解释 — 不在 reader 邻域内 → attends 无效。
5. **可行方案**：reader **保留自己 cache + attends over sender cache as extra context** + **仅微调 queries** → **超 baseline**。
6. **Pooled advantage**：8 senders pool 后超越 undirected attention over same union。

## 技术方案

### Motivation

- Multi-agent LLM 文本通信**有损**：sender 丢掉已读的 reading
- → 用 **KV cache** 直接传输"reading"
- 最吸引人的版本：**两模型都 frozen，sender cache 直接 substitute reader cache，无训练**

### 实证：Substitution 不 work

#### Tolerable Set

- Frozen transformer **仅能读** 与**自己会写的 cache 相近**的子集
- → 超出 tolerable set 的 cache 无法被 consume

#### Failure 模式

- **几何相似度不能预测 consumability**
- Failure **不是渐进的** → "更忠实的 substitute" **不是 remedy**

### 机制解释

- **Competitive attention**：在 reader 自己写的 cache 邻域外，attention 在 sender cache 上**无法 compete** → 无有效 signal

### 实验 Setup

- **8 substitution methods**
- **2 anchors**：
  - Uninformative cache baseline（最低线）
  - Reader 自己读 passage（最高线）
- → 比较各 method 在何处

### 结果

- **All 8 methods at uninformative baseline**（即 0 gain）
- → 长尾负面结果被整合为 **一个 outcome + stated overturning condition**

### 转向：Augment 而非 Substitute

```
┌─────────────────────────────────────┐
│ Reader's own KV cache (frozen)       │
│                                      │
│ + Sender's KV cache (extra context)  │
│   ↑                                  │
│   reader queries (only query adapted)│
└─────────────────────────────────────┘
```

- Reader **保留自己 cache**
- Sender cache 作为 **additional context**
- **仅微调 reader queries**（轻量 adaptation）

#### 收益

- ✅ 超 reader baseline（reader 自己有 cache）
- ✅ 超 undirected attention over union（8 senders pool）

---

## 实验结果

### 8 Substitution Methods × 2 Anchors

| Method | vs Uninformative Baseline | vs Reader Own Read |
|--------|--------------------------|-------------------|
| All 8 methods | **0 gain**（全部 baseline） | **大幅 gap** |

→ 长期负面结果统一为：**KV cache 传输方向不对**。

### Augmentation Method（可行）

| Setting | 超 baseline? |
|---------|------------|
| Reader cache + sender cache attends, only query 调 | ✅ |
| 8 senders pooled + augmented | ✅ |
| Undirected attention over same union | ❌（输给 augmented） |

→ **Adaptive query + augmented cache** 是当前最优。

### 关键洞察

- "更忠实的 substitute" **是 wrong target**
- **Adding cache to what reader already has** 是 promising direction

## 局限与展望

- 仅 1 probe setting 的 characterization → leaderboard claim 不成立。
- 8 substitution methods 未全部详述。
- "Only adapt queries" 微调 cost 未量化。
- 8 senders pool 时 attention 复杂度 → 长 multi-agent 部署 cost 上升。
- 与 prefix caching / prompt caching 的关系未充分讨论。

## 实现建议

- **实现难度**: 中（需要 KV cache extraction + cross-model cache alignment + 仅微调 queries）
- **预期性能**: 单 sender 时 **+X pp** vs no-comm baseline；8 sender pool 时**显著优** undirected
- **适用场景**:
  - **Multi-agent 协作**（避免重复阅读）
  - **Tool result 传递**（agent 间共享 tool output）
  - **Long-context agent**（passage cache reuse）
- **不适用**:
  - 单 agent（无 sender）
  - reader 与 writer **架构差异大**（KV cache 维度不匹配）
- **工程提示**:
  - **仅 query 微调** 是 sweet spot（vs full model adapter）
  - Sender cache 可**异步传输**（reduce latency）
  - Pooled sender cache 需 **attention selection**（避免 O(n²) 退化）

## 一句话总结

KV cache 在 multi-agent 间**直接 substitute 不工作**（fidelity ≠ consumability，competitive attention 阻断）；正确方向是 **reader 保留自己 cache + attends over sender cache as extra context + 仅微调 queries**，8 senders pool 后超越 undirected attention over same union — **给 multi-agent LLM 通信重新定位**。
