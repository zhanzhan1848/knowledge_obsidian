## 核心贡献

> 提出 **DREAM** (Dynamic Reactivation for Engram Attenuation in Memory) —— 受神经科学"弱重激活诱发遗忘"启发，agent-intrinsic / training-free 选择性遗忘被毒化记忆。

1. **训练无关**: 无需 fine-tuning
2. **三阶段 pipeline**: perturbation-induced implicit reactivation → adaptive anomaly diagnosis → dynamic memory repair
3. **强防御**: 对 backdoor poisoning **attack success rate -95%**，保留 benign 性能

---

## 技术方案

### 核心思想

LLM agent 易受 memory-poisoning 攻击；现有防御靠外部模块做静态隔离或在线审计，效率低、开销大。神经科学发现：弱重激活可在缺乏强化时诱发记忆衰减。DREAM 把这一机制搬到 agent 内部做选择性遗忘。

### 关键技术

| 技术 | 说明 |
|------|------|
| Perturbation-induced implicit reactivation | 扰动触发对恶意记忆的结构脆弱性 |
| Multi-dimensional activation diagnosis | 多维激活模式识别拓扑异常 |
| Dynamic memory repair | 选择性抑制恶意 + 强化良性 |
| Agent-intrinsic | 无外部审计模块 |
| Training-free | 无 LLM fine-tuning |

### 三阶段

| 阶段 | 作用 |
|------|------|
| 1. Perturbation-induced reactivation | 揭示 malicious memory 结构脆弱性 |
| 2. Anomaly diagnosis | 拓扑异常检测 |
| 3. Memory repair | 选择性抑制 harmful + 强化 benign |

---

## 实验结论

- **基准**: 多类 attacker + 真实任务
- **结果**:
  - Attack Success Rate **-95%+** against backdoor poisoning
  - Benign performance 强保留
  - 高 memory efficiency + 低 compute overhead

---

## 局限性

- 扰动策略需先验调参
- 对 adaptive attacker（知防御存在）的鲁棒性未充分测试
- "Neuro-inspired" 仅是类比，理论保证缺位

---

## 实现建议

- **实现难度**: 中（agent 内部重激活 + 异常诊断）
- **预期性能**: 部署 LLM agent 时显著提升抗 memory poisoning 能力
- **适用场景**: 长时记忆 agent / Tool-use agent / RAG agent 安全加固
