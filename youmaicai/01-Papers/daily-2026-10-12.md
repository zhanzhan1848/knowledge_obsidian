## 重点论文（13 篇）

### 1. **RSI-Anything: Recursive Self-Improvement with World Models** (2610.13912)
- JEPA-Anything 预测式世界模型替代昂贵 external verifier。
- code repair 26.3% → 31.2%；lab-planning 5 轮迭代 21.80% → 46.01%。
- reaction optimization **96.15%** vs Bayesian 82.16% 同 40 实验预算。
- 详见 [[2610.13912-RSI-Anything-Recursive-Self-Improvement]]

### 2. **When VLMs Destroy What They Know: Spatial Representations Fall Below Lexical Priors** (2610.13910)
- 新指标 EICS + 基准 CASP-VL，揭示 VLM 内部表示对空间关系编码远不如词汇信息。
- 关系在 predicate 自身 token 处可识别，EOS/mean-pool 后丢失。
- 详见 [[2610.13910-VLM-Spatial-Representations-Below-Lexical]]

### 3. **Task Context Shapes Component Roles in Language Models** (2610.13895)
- 5 个 open-weight 模型 (Gemma-2-9B, Qwen3-14B 等) 验证 task-dependent influence 重分布。
- 任务专属 linear response map 比平均 map MSE 降 **53.6% (Gemma)**。
- 详见 [[2610.13895-Task-Context-Component-Roles-LMs]]

### 4. **Can Language Models Learn When to Abstain?** (2610.13821)
- Learned selector > calibrated confidence filter：TriviaQA coverage **20.2% → 30.9%**，error **23.0% → 14.5%**。
- RL 改进不稳定；NQ-Open 上 even always-abstain 更优。
- 详见 [[2610.13821-LMs-Learn-When-Abstain]]

### 5. **QTestBench: LLM-Generated Quantum Code Tests** (2610.13811)
- 跨 PennyLane QHack / Qiskit HumanEval，**5 个 LLM** 测试套件 quality 评估。
- executability ≈ 100% 但 discrimination 滞后；最佳 generator **0.71 / 0.34**。
- 详见 [[2610.13811-QTestBench-LLM-Quantum-Code]]

### 6. **SAFE-QE: Taming Hallucinated Terms in LLM Query Expansion** (2610.13810)
- Subsequence-association 机制解释 + 训练无关过滤。
- nDCG@10 与 Query2doc/HyDE 持平；unsupported terms **4.3 vs 27.8 / 57.5** per query。
- 详见 [[2610.13810-SAFE-QE-Query-Expansion]]

### 7. **Critique-Conditioned On-Policy Self-Distillation for Reasoning** (2610.13744)
- 揭示"只打分 teacher 不能定位错误"的结构失败。
- critique-conditioned signal 推动 backtracking token ("Wait"/"But"/"Actually") 概率上升。
- 详见 [[2610.13744-Critique-Conditioned-Self-Distillation]]

### 8. **Adaptive DHiSparse: Speculative Decoding over KV Hierarchy** (2610.13708)
- GLM-5.3 + DFlash2 @ 100K ctx / conc 128 → **793 output tokens/s/GPU**。
- 同 latency bound 下 up to 4× concurrency、2.3-3.7× output。
- 详见 [[2610.13708-Adaptive-DHiSparse-Speculative-Decoding]]

### 9. **UPTURN: Learning Where to Redirect LLM Reasoning** (2610.13672)
- 130K 参数 MLP head 定位 failed rollout 干预位置；new user turn injection。
- 跨 4 reasoner + 6 math benchmarks 提升；GPQA-Diamond 零训练迁移。
- 详见 [[2610.13672-UPTURN-Learned-Position-Redirect]]

### 10. **Multi-Stream Attention Residuals (MSAR)** (2610.13630)
- AttnRes 单流 depth attention → 多流多头 depth attention。
- 18B/28B MoE 12 个 benchmark consistently outperforms prior residual variants。
- iso-loss compute speedup **1.58×** vs AttnRes 1.35×、mHC 1.30×。
- 详见 [[2610.13630-Multi-Stream-Attention-Residuals]]

### 11. **zip2zip++: Inference-Time Token Compression with Minimal Quality Loss** (2610.13605)
- 4 个失败原因诊断 + 4 个修复方案；预训练 LM 不动。
- perplexity 与 math reasoning 全 corpus 改善；quality gap 关闭约一半。
- 详见 [[2610.13605-zip2zip-Token-Compression]]

### 12. **Training User Simulators with Latent Intrinsic Feedback** (2610.13617)
- simulator 持有 latent evaluation state（thoughts + reactions + scalar rating）。
- 多 turn RL 中替代 external judge LLM，**RL compute 减半**。
- 详见 [[2610.13617-User-Simulators-Latent-Feedback]]

### 13. **Measuring Artifact Reliance in Machine-Generated Text Detectors** (2610.13583)
- 27 superficial features → F1 0.833-0.997；PDF extraction artifact 为最强 cue。
- Format counterfactual 逆转公开 detector **20-27%** 决策。
- Format-normalized training：OOD macro-F1 **0.33 → 0.65**。
- 详见 [[2610.13583-Artifact-Reliance-Detectors]]

### 14. **Can Language Models Play the Wikipedia Game?** (2610.13948)
- 多跳规划/搜索 task；模型在不同 path length 上分层。
- 详见 [[2610.13948-LMs-Play-Wikipedia-Game]]

### 15. **APEX-Harm: Agent Safety in Shared Professional Workspaces** (2610.13623)

- 详见 [[2610.13623-APEX-Harm-Agent-Safety]]

## 关键洞察

1. **"机制解释"成为新热点**: VLM 内部表示审计、任务依赖 influence、网络视角下的 component roles 等都强调"系统诊断而非行为评估"。
2. **Self-distillation 的失败模式被重新审视**: 仅打分不够，必须 critique-conditioned 才能定位推理错误。
3. **Speculative decoding + sparse KV 是 serving 主线**: Adaptive DHiSparse 在长上下文上达到 ~800 tok/s/GPU。
4. **Benchmark artifact 问题被多论文独立审计**: machine text detector、quantum test、Wikipedia Game 等都揭示测评表层失效。
5. **Agent 安全不再是 prompt injection 单点**: workspace-scale 与 task-specific script replacement 攻击显著更有效（81-84% ASR）。
