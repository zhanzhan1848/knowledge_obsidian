## 核心要点
1. **Sable** 是一套论证系统与**单 GPU prover**，用于证明"一个已承诺的、**整数量化**的 transformer 从给定 prompt 逐比特（bit for bit）地产生了给定 token 序列"。它固定一个**完全不含浮点步骤**的整数函数 **F_O**——其中每次舍入、归一化、softmax 与采样决策都由其输入唯一确定——并用一个约束系统证明之，该约束系统的关系**可证明不会在 31 位的 KoalaBear 素数上模回绕**。
2. 证明的**密码学与系统设计**：把 **zerochecks 与 LogUp-GKR 查表批处理为每个域一个 sumcheck**；用**一个由 Reed-Solomon 码、BLAKE3 Merkle 树与 mixed-length BaseFold opening 构成的多线性承诺**承诺所有见证张量与权重；prover 在**一张 GPU 上按层流式处理模型**。在单张 NVIDIA RTX PRO 6000 Blackwell 上，证明 Qwen2.5-32B 全部 **64 层**：**4,096 token 用时 92.5 s，16,384 token 用时 398 s**；同时覆盖 Qwen3-32B 与 MoE 的 Qwen3-30B-A3B（4,096 token 分别为 **121.8 s** 与 **84.7 s**）。
3. **成本与精度权衡**：证明耗时是服务时间的 **41–50 倍**，按公有 GPU 价格折合**每个 4,096-token 请求 6.4 美分**，每参数每 token 时间比 zkLLM **少 40–64 倍**；验证者用编译核心在**单个 CPU 核上 19–56 s** 完成校验，随机预言机模型下交互式证明**逐轮健全性错误为 2^-103**。数值保真方面，F_O 的贪心 token 在 WikiText-2 上与 BF16 模型 **86.3%** 的位置一致，在 Qwen3 上 MMLU 与 GSM8K 与 BF16 相差分别在 **1.6** 和 **1.7 分以内**；证明**非零知识**，因此系统面向**开放权重模型**。代码：https://github.com/moonmath-ai/Sable

## 摘要（原文）
We present Sable, an argument system and single-GPU prover for the statement that a committed, integer-
quantized transformer produced a given token sequence from a given prompt, bit for bit. Sable fixes an integer
function F_O with no floating-point step, in which every rounding, normalization, softmax and sampling decision
is determined by its inputs, and proves it with a constraint system whose relations provably never wrap modulo
the 31-bit KoalaBear prime. The proof batches zerochecks and LogUp-GKR lookups into one sumcheck per domain,
and commits to every witness tensor and weight in one multilinear commitment built from Reed-Solomon codes,
BLAKE3 Merkle trees and a mixed-length BaseFold opening. The prover streams the model layer by layer on one
GPU. On one NVIDIA RTX PRO 6000 Blackwell GPU, Sable proves all 64 layers of Qwen2.5-32B in 92.5 s for 4,096
tokens and 398 s for 16,384 tokens, and covers Qwen3-32B and the mixture-of-experts Qwen3-30B-A3B (4,096 tokens
in 121.8 and 84.7 s). A proof costs 41 to 50 times the serving time, or 6.4 cents per 4,096-token request at
public GPU prices, and 40 to 64 times less time per parameter and token than zkLLM. On WikiText-2, F_O's greedy
token matches the BF16 model's at 86.3% of positions; on Qwen3, F_O is within 1.6 points of BF16 on MMLU and
1.7 points on GSM8K. A verifier with a compiled core checks a proof on one CPU core in 19 to 56 s. In the
random-oracle model, the interactive proof has round-by-round soundness error 2^-103. The proof is not
zero-knowledge, so the system targets open-weight models. Code: https://github.com/moonmath-ai/Sable
