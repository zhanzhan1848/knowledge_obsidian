## 核心贡献
1. **提出"继承 vs 学习"的分离性实验设计（inherited vs. learned）**：通过加入**同数据但无教师**训练的 student（"student trained on the same prompts without a teacher"）作为对照，从混杂中分离出真正"从教师继承"的成分与"从数据自行学习"的成分。
2. **发现蒸馏会改变后门触发的"选择性（selectivity）"——而非单纯继承或抹除**：**随机插入**的触发串在蒸馏后**在全部 9 条 teacher-student 管线中变得更不具选择性**；而**附加在指令后**的触发串在 **Qwen 与 Llama** 上**获得选择性**，在 **Gemma** 上**变化很小**。
3. **给出选择性的量化拆解**：Llama 与 Gemma 的 student **仅凭 150 条被污染样本**就能学会"附加式后门"；**只有 Qwen 的 0.5B student 需要教师**才能学会。
4. **刻画了触发位置的作用域差异**：**Gemma 教师对触发串在任何位置都响应，但其 student 只在触发串被附加时才响应**——教师与学生的"作用域"不匹配。
5. **给出可操作的审计建议**：审计应当**在相同输入上同时比较教师与学生**、**探测多个触发位置**、并**包含一个无教师训练的 student** 作为基线。

## 问题背景
蒸馏是构建小语言模型的标准步骤，而**被植入后门的教师可以把后门传递给 student**。但"传递"这个说法过于粗糙：后门在蒸馏后可能**变得更强、更弱，或改变其触发条件（selectivity）**。既有后门研究多关注"攻击是否成功"（attack success rate），较少关注**后门的触发特异性是否在蒸馏中被扭曲**——例如原本"在任意位置出现即触发"的后门，蒸馏后可能只在某个特定位置生效，这种"作用域收窄"会让只测一种触发位置的审计**低估或误判**风险。此外，后门是"从教师继承"还是"从数据中独立学习"，在纯黑盒评测下无法区分。

## 方法
### 1. 实验设置
- **触发串（trigger）**：一个**罕见字符串**，触发模型输出固定的拒绝（fixed refusal）。
- **关键控制变量**：**保持触发串固定**，只改变其**出现位置**：
  - **随机词边界插入（random word boundary insertion）**
  - **附加到指令末尾（appended to the instruction）**
- **模型族**：**Qwen2.5、Llama 3.2、Gemma 3**。
- **污染比例**：**5% 的 transfer prompts 被触发**。
- **评测集**：**精确触发串（exact trigger）**、**六个控制串（six control strings）**、以及**干净输入（clean inputs）**。

### 2. 三方对照设计（核心方法贡献）
| 被测对象 | 说明 |
|---|---|
| **Teacher（教师）** | 被植入后门的教师模型 |
| **Student（学生）** | 由该教师蒸馏得到 |
| **Student-no-teacher（无教师学生）** | 在**相同 prompts** 上训练、但**没有教师**的对照学生 |

第三个对照是整篇工作的方法论支点：它提供了"若没有教师蒸馏会怎样"的反事实基线，从而把观察到的选择性变化分解为**继承成分**与**数据学习成分**。

### 3. 选择性（Selectivity）的度量
选择性刻画触发串在多大程度上**特异**地触发拒绝行为——即在触发串 vs 控制串 vs 干净输入之间的**区分度**：
- 触发串触发率高 + 控制串触发率低 = **高选择性**（理想的、位置特异的后门）
- 触发串与控制串触发率接近 = **低选择性**（后门泛化到任意罕见串，威胁更大但也更易被通用拒答模型覆盖）

论文比较各模型在这两种位置条件下的选择性变化。

### 4. 样本量实验
- 用**150 条被污染样本**训练 Llama 与 Gemma 的 student，观察其是否习得附加式后门。

## 实验结果
| 观察项 | 结果 |
|------|------|
| 污染比例 | **5%** 的 transfer prompts 被触发 |
| 评测对照 | 精确触发串 + **6 个控制串** + 干净输入 |
| 随机插入触发串 → 蒸馏后 | **变得更不具选择性**，在**全部 9 条 teacher-student 管线**中一致出现 |
| 附加式触发串 → 蒸馏后 | 在 **Qwen 与 Llama** 上**获得选择性**；在 **Gemma** 上**变化很小** |
| 无教师 student 对照 | 表明**大部分变化并非继承所得** |
| 无教师能否学到附加式后门 | **Llama 与 Gemma**：可以，仅需 **150 条污染样本**；**Qwen 0.5B student**：**需要教师**才能习得 |
| Gemma 的教师行为 | 触发串在**任意位置**都响应 |
| Gemma 的学生行为 | 仅在触发串**被附加**时响应 |
| 审计建议 | 同输入比对教师与学生；多位置探测；纳入无教师 student |

## 关键洞察
1. **蒸馏改变的是后门的"作用域"，而非"存在性"**：数据最有价值的一点是"教师在任意位置响应，Gemma 学生只在附加时响应"——教师与学生的触发边界**不一致**。这意味着一个只在**教师**上验证过的触发串，可能在**学生**上完全失效（反之亦然），任何单一触发位置的评测都会产生误导。
2. **选择性可能是双向变化的（双向坍缩/扩张）**：随机插入触发在所有 9 条管线中变得**更不具选择性**（后门泛化），而附加式触发在 Qwen/Llama 上变得**更具选择性**（后门特化）。这意味着蒸馏不是"洗掉"后门的统一过程，而是**按触发位置分化**的过程——不同触发模式在蒸馏中命运相反。
3. **"大部分不是继承的"是一个反直觉但重要的结论**：若无教师 student 对照显示大部分选择性变化可由数据本身解释，那么"教师传递后门"的常见叙事在**触发位置/选择性**这一维度上可能高估了教师的作用——真正稳定的继承（只有 Qwen 0.5B student 必须靠教师才习得附加式后门）反而出现在**小模型**上。
4. **小模型更依赖教师，大模型更能自己学**：Qwen 0.5B 需要教师才能学会附加式后门，而 Llama 与 Gemma 学生仅凭 150 条样本就能学会。这提示**小模型可能对后门更"忠实"于教师的教学信号**，而较大模型有更强的归纳偏置去自行抽取数据中的模式。审计资源应据此分配——小模型蒸馏链是重点风险区。
5. **方法论启示**："无教师 student"对照是廉价且必要的控制项。它把一个看似是"教师行为传递"的观察转化为可分解的科学问题，其价值超出后门场景本身，可迁移到任何"模仿/蒸馏是否导致特定行为"的研究。

## 局限性
- 摘要**未给出**任何具体的触发率/攻击成功率/选择性数值的绝对或相对数值（只有"全部 9 条管线一致"这样的定性强度描述）。
- "6 个控制串"的**构造方式**（长度、频率、语义类别、是否为真实罕见词）摘要**未说明**——控制串的选择直接决定选择性度量是否可信。
- 模型规格**未给出具体尺寸**（除 Qwen 0.5B student 外），教师与学生的配对关系（哪个教师蒸馏哪个学生）摘要未列出。
- 蒸馏方法/流程（序列 KD？top-k logits？数据量？训练超参）摘要**未说明**。
- 触发串为"罕见字符串"，其**具体内容**与长度未给出，**位置敏感性可能与长度或 tokenization 有关**。
- 仅研究**固定拒绝（fixed refusal）**这一种后门行为；**触发动作型后门**（如插入特定网址）、**多触发串**、**组合触发**未覆盖。
- **清洁性（benign utility）**未在摘要中报告——摘要**未给出**干净输入上的模型质量指标，因此无法判断是否存在"后门特异性增强但通用能力受损"的权衡。
- 只研究了**后门选择性**这一个维度，未涉及后门的**可解释性**（student 是否保留了 teacher 的内部特征）或**跨位置迁移攻击**的成功率。
- **9 条管线**的组合（三模型族 × 三种位置/教师组合）的具体列表未在摘要中给出，"全部 9 条"中的一致性因此无法独立核验。

## 适用场景
- **模型蒸馏流水线**的安全审计：教师可能被植入后门，需要判断蒸馏出的 student 是否继承、以及继承了什么形态。
- **后门攻击的评测方法学**：为触发串位置、选择性度量与控制组设计提供模板。
- **小型开源模型**（0.5B–8B）的发布前安全筛查，因为小模型对教师后门的依赖度可能更高。
- **第三方蒸馏 / 知识转移**场景下的责任划分：区分"教师教坏"与"学生自学坏"。
- 研究**知识蒸馏对触发特异性/作用域的影响**的学术工作。
