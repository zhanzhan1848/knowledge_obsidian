# ProQuant: Progressive Quantization-aware Training for Edge MLLMs
### 元信息

| 字段 | 内容 |
|------|------|
| **标题** | ProQuant: Progressive Quantization-aware Training for Edge MLLMs |
| **作者** | Yufei Xue, Yushi Huang, Jiawei Shao, Pingcheng Dong, Yonghao Tan et al |
| **发表** | arXiv preprint |
| **链接** | [原文](https://arxiv.org/abs/2611.08216) |
| **arXiv** | arXiv:2611.08216 |
| **代码** | [GitHub](https://github.com/yufeixue-ai/ProQuant) |

### 核心贡献
1. 提出 ProQuant：面向低比特（low-bit）多模态大模型的 weight-activation QAT 框架，针对 PTQ 在 W4A8 下性能严重退化的问题。
2. 提出 self-relabeling scheme（SRL），通过重采样开源多模态数据集的响应，使有限微调数据集的分布与预训练数据集分布对齐。
3. 首次以「解耦视角」看待多模态理解能力与语言建模能力，提出 progressive block activation（PBA）机制优先恢复多模态理解能力，并引入 vision-sensitive factor $\vec{\tau}$ 有效识别多模态关键层。

### 技术方案
**核心思想**: 低比特量化失败的主要原因有两类——微调数据分布与预训练分布不匹配，以及多模态能力比语言能力更脆弱；SRL 与 PBA 分别针对这两点，且通过 $\vec{\tau}$ 把量化训练资源集中到多模态敏感层。

| 技术 | 说明 |
|------|------|
| ProQuant QAT 框架 | weight-activation 量化感知训练（QAT），专为低比特 MLLM 设计，区别于在 W8A8 尚可但 W4A8 崩溃的 PTQ |
| SRL 自重标注 | self-relabeling scheme：对开源多模态数据集的 response 进行重采样/重标注，使有限微调集的分布贴近预训练分布 |
| 解耦能力视角 | 首次将 MM understanding 与 language modeling 两种能力分开对待，认为两者在低比特下的退化幅度不同 |
| PBA 渐进式分块激活 | progressive block activation：分块渐进地恢复多模态理解能力，优先修复感知侧 |
| Vision-sensitive factor $\vec{\tau}$ | 一个向量形式的敏感因子，用于识别「多模态关键层」，指导量化/训练资源分配 |

### 实验结果
- **数据集**: 多个 benchmark（摘要未列具体名称），覆盖 2B–8B 参数量的模型
- **基线**: 现有低比特量化 / QAT 方法（摘要未逐一列名），含 full-precision 对照
- **结果**: W4A8 的 Qwen3-VL-2B-Instruct 平均准确率提升 6.6%；与 full precision 相比仅约 1% 的性能下降；整体显著优于现有方法

### 局限性
- 仅覆盖 2B–8B 规模的 MLLM，更大模型的结论摘要未说明
- 具体 benchmark 名称、基线模型名称摘要未说明
- QAT 需要可微调数据与训练算力，端侧部署前仍需完整微调流程，训练开销摘要未说明

### 关键洞见
> 在低比特量化下，多模态模型的「感知能力」与「语言能力」是可以被解耦修复的：只要把有限的量化训练资源优先投给多模态敏感层（由 $\vec{\tau}$ 标定），W4A8 的 2B 模型就能追平 full-precision 的表现——这意味着量化误差的主要瓶颈不在模型容量，而在能力模块之间的脆弱性差异。
