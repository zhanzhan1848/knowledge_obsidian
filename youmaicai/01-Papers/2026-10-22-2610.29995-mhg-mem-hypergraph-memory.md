## 核心贡献
1. 提出 **MHG-Mem**，一种多模态**超图记忆**，把 **entity identity、state evolution、provenance（溯源到视觉证据）** 三者联合组织进同一个结构。
2. 记忆表示：将不同的 entity mentions 及其 observed facts 表示为独立节点，通过 **occurrence hyperedges** 把身份一致的 mentions 与 facts 分组。
3. 从分组后的观测中**合成 aspect-specific evolution states**（按侧面划分的演化状态），并通过 **evolutionary hyperedges** 与 **evidential hyperedges** 把它链接回支撑它的 entities、facts 与 source evidence。
4. 提出 **hypergraph-based agentic search**：自适应选择 entry layer、跨记忆层级遍历**带类型的超边**，在需要细粒度校验时回溯检查源观测。
5. 在三个 benchmark 上较最强基线提升 **8.20–9.98%**。

## 问题动机
多模态 agent 的长期记忆是个老大难：它必须**同时**保留细粒度的视觉证据，并跨 session 追踪实体的演化。现有两类方案各有硬伤——**abstraction-based memory** 把图像压缩成文本，常常丢掉视觉上有区分度的细节；而 **pixel-preserving memory** 虽保留原始观测，却难以可靠地把多样观测关联到**持久的实体身份**，也难以追踪其演化状态。也就是说，"记得住画面"与"记得住这个实体变了什么"这两种能力在既有工作中是割裂的。

## 方法
**MHG-Mem 的结构化表示：**

1. **节点**：distinct entity mentions 与它们各自的 observed facts 被表示为独立节点。
2. **occurrence hyperedges**：把身份一致（identity-consistent）的 mentions 与 facts 分组到同一超边中——这是解决"多样观测 ↔ 持久实体身份"关联的关键机制。
3. **evolution states**：从分组后的观测中**合成 aspect-specific（按侧面划分）的演化状态**，即不同侧面（如外观、位置、状态）的变化分别建模。
4. **evolutionary hyperedges**：把演化状态连接到支撑它的 entities 与 facts。
5. **evidential hyperedges**：把上述结构链接回 **source evidence**（源观测），实现 provenance-preserving。
6. **hypergraph-based agentic search**：检索时（a）**自适应选择 entry layer**（从哪一层进入记忆结构）；（b）**跨记忆层级遍历带类型的超边**（typed hyperedges）；（c）当需要细粒度校验时**检查源观测**。

这套设计同时支撑两类能力：**详细的视觉验证**（沿 evidential hyperedges 回溯到像素）与**跨 session 状态变化的推理**（沿 evolutionary hyperedges）。

## 关键技术细节
- 核心创新是用**超图（hypergraph）**而非普通图来承载记忆：一个超边天然对应"一组共享同一身份或同一证据链的 mentions/facts"，避免了 pairwise 边的 N² 爆炸——这是把 entity mention 分组到持久 identity 的天然数据结构。
- **边的类型化（typed hyperedges）** 是检索能够有效遍历的关键：evolutionary 边与 evidential 边语义不同，agentic search 依此选择路径，从而在"推理演化"与"验证视觉细节"两条任务上走不同路径。
- provenance 的保留使得记忆系统的回答**可回溯到原始观测**，这对多模态 agent 的可信度/可审计性有直接价值。
- entry layer 的自适应选择说明记忆结构是**多层**的，检索起点不是固定的。
