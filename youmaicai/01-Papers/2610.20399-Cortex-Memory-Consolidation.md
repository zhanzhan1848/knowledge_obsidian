## 核心贡献

1. **Memory Consolidation (MC) 形式化**：受 biological systems consolidation 启发，internalize context-induced gains + preserve non-target capabilities；统一 context-specified editing / skill learning / behavioral steering
2. **Cortex**：生成 prospective queries + 把 context-conditioned outputs 蒸馏成 mergeable LoRA / structural FFN updates
3. **5-task-family testbed**：测 consolidation + retention under single / batch / sequential updates
4. **Pareto frontier 表现**：4B–120B dense + MoE + text-only + multimodal backbones

## 方法

### Memory Consolidation objective

```math
max: gain_from_context - degradation_non_target
subject to: retention >= threshold
```

### Cortex 算法

```python
# 1. Generate prospective queries
prospective_queries = generate_prospective_queries(context)
# 2. Distill context-conditioned outputs
context_outputs = base_model(prospective_queries, context)
# 3. Merge via LoRA / FFN updates
update = distill_to_update(context_outputs, base_outputs_without_context)
# LoRA or structural FFN
apply_update(model, update)  # mergeable
```

### 两类 update

- **LoRA updates**：轻量 + 容易 merge
- **Structural FFN updates**：更稳定 + 与 model architecture 耦合更深

## 实验结果

| Setting | Cortex 表现 |
|---------|-------------|
| 4B–120B dense + MoE | Pareto frontier |
| Text-only + multimodal | Pareto frontier |
| 50 sequential factual edits (14B) | **88.9% context-induced gain 恢复 + 99.8% 非 target 性能保留** |
| 5-task-family testbed | 全 settings 在 Pareto frontier |

## 局限性

- "Prospective queries" 生成需要 task understanding（domain-specific 设计）
- 50 sequential edits 是中等规模，longer sequences 表现待验证
- Structural FFN updates 需要 model architecture 适配

## 建议

- **是否推荐使用**：是
- **适用场景**：长上下文应用（context 太长不能每次输入）+ 持续学习场景 + 个性化 LLM（context → parametric）
- **运营价值**：避免每次重复输入长 context → 节省 token cost + latency
