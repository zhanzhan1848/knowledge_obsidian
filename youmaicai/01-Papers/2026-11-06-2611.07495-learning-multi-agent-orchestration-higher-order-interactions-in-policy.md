## 方法与架构
**错误假设的形式化**：
```math
\text{WRONG:}\quad A_d = \mathbb{E}[R \mid d] - \mathbb{E}[R \mid \neg d]
\quad\text{(其他决策固定)}
```

**正确分解（IAPO）**：
```math
\mathbb{E}[R \mid \pi] - \mathbb{E}[R \mid \pi']
  = \sum_d \underbrace{\Delta_d}_{\text{个体效应}}
  + \sum_{d,d'} \underbrace{\Delta_{dd'}}_{\text{交互效应}}
```
作者证明**交互项可占可达增益的约一半**。

**优化**：从采样轨迹同时优化个体与交互项；**每次更新带改进性认证**。
