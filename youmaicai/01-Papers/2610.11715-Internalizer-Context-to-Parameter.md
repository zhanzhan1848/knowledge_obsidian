## 核心贡献

> 提出一个可移植的 Context-to-Parameter Mapping hypernetwork，能为冻结的 **284B 参数 DeepSeek v4 Flash** 生成文档特定的 LoRA 适配器——比此前工作大两个数量级。

1. Context-to-Parameter Mapping hypernetwork 规模化到 **284B 参数**目标模型
2. **Model-agnostic trunk + thin per-base entry/exit** 架构：廉价训练，便携部署
3. 在 4096 token 未见文档上 top-1 / top-5 accuracy **84.9% / 97.8%** vs base 63.4% / 83.5%

---

## 技术方案

### 核心思想

Hypernetwork 将上下文直接映射为 LoRA 适配器，让 LLM 把上下文"携带"到权重中。此前工作仅在 14B 模型上验证。本文将这一方法规模化到 284B 模型，且训练便宜、部署便携。

### 关键技术

| 技术 | 说明 |
|------|------|
| Context-to-Parameter hypernetwork | 输入上下文，输出 LoRA 适配器 |
| Model-agnostic trunk | 主体参数在 base model 间共享 |
| Thin per-base entry/exit layers | 每个 base model 仅添加少量薄层 |
| Portable training | 在小模型上训练，然后移植到大模型 |
| One-forward-pass deployment | 单次前向将任何文档转为 adapter |

### 架构示意

```
Context → [Shared Trunk] → [Base-specific thin layers] → LoRA for DeepSeek-v4-Flash-284B
```

---

## 公式

```math
\text{LoRA}_{\text{gen}} = H_\theta(\text{Context}) = (E_b \circ T_\theta \circ E_a)(\text{Context})
```

其中 $T_\theta$ 是 model-agnostic trunk，$E_a, E_b$ 是 thin per-base entry/exit layers。

```math
\text{Accuracy}_{\text{teacher-forced}} = \mathbb{E}_{d \sim \text{unseen docs}}[\mathbb{1}(\text{LM}(x \mid d, \text{LoRA}_{H(d)}) = y^*)]
```

---

## 实验结论

- **目标模型**: DeepSeek v4 Flash（**284B 参数**）
- **数据集**: 未见文档 up to 4096 tokens
- **结果**: 
  - 生成 adapter 达到 **84.9% top-1** / **97.8% top-5** teacher-forced accuracy
  - baseline（context window only）: 63.4% / 83.5%
  - 上下文窗口仅用 3-word instruction
- **效率**: 单次前向即生成 adapter，可独立部署或与文档共存

---

## 局限性

- Hypernetwork 本身需要训练（但在小模型上即可）
- 上下文长度限制（4096 tokens）
- 部署时需要为每个 base model 训练 thin entry/exit

## 实现建议

- **实现难度**: 高（hypernet 训练 + per-base 适配）
- **预期性能**: 比 context window 提供更稳定的 document-specific 行为
- **适用场景**: 文档条件化生成、个性化 LLM、大模型部署成本优化
- **特别价值**: 可移植到不同 base model，仅训练廉价小模型 + thin layers
