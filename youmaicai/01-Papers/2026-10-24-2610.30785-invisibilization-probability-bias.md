## 核心贡献

> 提出 **invisibilization（不可见化）** 这一概率偏差来源：模型因对齐而拒绝使用受保护属性（种族、族裔、性别），进而在信息取舍上**按信息源的身份而非证据本身**决定信不信 —— 这种偏差对只看平均信任度或只看"已评估样本"的审计**完全隐形**。

1. **提出 invisibilization 概念**：因拒绝使用受保护属性而导致的信息贬值（information worthlessness），是一种此前未被命名的偏差机制
2. **可复现的量化实验**：two-urn game + 精确 Bayesian 答案；两个厂商（OpenAI 与 Anthropic）的前沿模型，**6,600 个 session**，报告者描述随机化为十种配置
3. **揭示关键的"拒绝偏差"**：模型常直接拒绝评估报告者，导致按**描述**而非按**证据**设定"信息无价值"的比率 —— Black 描述的报告者被拒绝 **46%**，white 描述者仅 **9%**
4. **偏差具有隐蔽性**：一旦模型确实评估了信息，Black 描述者反而获得略**更多**信任 —— 因此比较平均信任度或只看已评估案例的审计会漏掉它
5. **揭示行为机制**：偏差随 reasoning effort 增长；**跟随词汇而非类别**（模型对 "Black" 会调用 race，但对西班牙语 "negro" 不会，对 "Indigenous" 从不调用）；在从业者最先尝试的 warning 指令下**反而恶化**
6. **给出可操作的缓解方案**：scoring option 显著降低拒绝率偏差 —— 当信任度按多轮 revealed truth 评分时，模型对相同记录给出相同信用；在 Anthropic 与 OpenAI 的**五种配置中有四种**，最后一轮的种族信任差距降至 **0.02 以下**

## 技术方案

### 核心思想

经典偏差审计问"模型对 A 群体的平均信任是否更低"。本文指出还存在一条被完全掩盖的路径：模型先**拒绝评估**（因为报告者身份涉及受保护属性），于是该群体的信息大量在"未评估"状态下被丢弃；而在少数被评估的样本里该群体反而占优 —— 两个相反效应叠加，使平均数看起来正常。

### 关键组件

| 组件 | 说明 |
|------|------|
| Two-urn game | 双瓮博弈设置：模型决定从哪个报告者那里取信息 / 信多少 |
| Exact Bayesian answer | 实验有精确解析解，可直接量化"最优信任"与模型行为的差距 |
| Randomized reporter description | 报告者描述在 **10 种配置**间随机化（跨种族/族裔等） |
| Refusal vs. assessment 分离 | 把"拒绝评估"与"评估后给出的信任度"分开统计 |
| Scoring option | 改为按 revealed truth 打分的多轮评分机制，用于缓解拒绝率偏差 |
| Revealed-truth rounds | 重复轮次下暴露真实答案，使模型校准 |

### 关键公式

总体信任度可分解为"评估概率 × 条件信任度"：

```math
\mathbb{E}[T] = \Pr(\text{assess}) \cdot \mathbb{E}[T \mid \text{assess}]
```

偏差正是藏在这个乘积里：Black 描述者的 $\Pr(\text{assess})$ 低 46% vs 9%，但条件信任度 $\mathbb{E}[T \mid \text{assess}]$ 略高，两者相消使均值看似无偏。

跨轮次的 revealed-truth 校准（使重复记录被同等对待）：

```math
T^{(r)} = \mathbb{E}\!\left[\text{trust} \mid \text{record revealed at round } r\right]
```

## 实验结论

| 指标 | 结果 |
|------|------|
| 实验规模 | **6,600 个 session**，10 种随机化描述配置 |
| 参与模型 | OpenAI 与 Anthropic 两家厂商的前沿 LLM |
| Black 描述报告者被拒绝率 | **46%** |
| White 描述报告者被拒绝率 | **9%** |
| 已评估条件下的信任 | Black 描述者获得**略多**信任 |
| 审计可见性 | 比较平均信任或只看已评估案例的审计**无法发现**该偏差 |
| reasoning effort | 偏差随推理强度**增大** |
| 词汇 vs. 类别 | 对 "Black" 调用 race，对 "negro" 不调用，对 "Indigenous" 从不调用 |
| warning 指令 | 加上从业者最先尝试的警示指令后偏差**恶化** |
| 缓解方案效果 | 5 种配置中 **4 种**在最后一轮种族信任差距 **< 0.02** |

## 局限性

- 实验仅覆盖两个厂商的前沿模型，结论向其他厂商 / 开源模型的外推性未验证
- two-urn game 是高度受控的实验装置，与真实场景（医疗、法律、信贷等高风险判断）的偏差量级不一定可比
- 报告者描述的随机化使用十种配置，描述维度与现实世界中身份交叠（种族 × 族裔 × 性别）的复杂度差距较大
- 未区分"拒绝"是模型主动拒答、输出为空、还是以其他方式回避，拒答的检测口径可能影响数值
- 只测了信任度这一个行为维度，未评估该 invisibilization 是否同样作用于其他受保护属性或其他对齐敏感领域

## 实现建议

- **实现难度**: 中（实验装置本身不复杂，但要做 6,600+ session 的统计功效需要严格的随机化与重复轮次设计）
- **适用场景**: 需要按信息源身份决定"信多少"的系统 —— 风控、内容审核、客服转接、医疗分诊等；也适用于构建 LLM 公平性审计流水线
- **建议起点**: 在现有 bias 评测集中**分开统计"拒答率"与"条件信任度"**两列 —— 这一步就能让大部分被漏掉的 invisibilization 偏差显形
- **价值点**: 提供了一个现成的 mitigation —— revealed-truth scoring option，把拒绝率偏差在 5 个配置中的 4 个压到 0.02 以内；同时警告了"加 warning 指令"这个直觉做法会适得其反
