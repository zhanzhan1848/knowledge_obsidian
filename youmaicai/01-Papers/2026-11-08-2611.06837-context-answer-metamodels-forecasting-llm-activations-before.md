# Context--Answer Metamodels: Forecasting LLM Activations Before the First Answer Token

> **arXiv**: [2611.06837](https://arxiv.org/abs/2611.06837)
> **发表日期**: 2026-11-04
> **分类**: cs.LG (交叉: cs.AI)
> **会议/期刊**: arXiv preprint

## 📋 摘要

在随机解码（stochastic decoding）下，同一 context 可以从语言模型中引出许多不同答案。刻画这种差异通常需要大量昂贵的自回归 rollout，而每次 rollout 只揭示一个实现。本文提问：读取 context 时产生的 **activations** 能否直接预测模型 rollout 期间的 activations。作者训练了 **context–answer metamodels**，把 context 的 activation 序列映射到 mean-pooled answer activations 的**点预测（point forecast）或分布预测（distribution forecast）**。四项发现：(i) 所研究的四类 metamodel 家族都能高保真地预测 mean-pooled answer activations，且分布型 metamodel 还能捕捉 rollout 的变异性；(ii) 性能随训练集规模增长而提升，直至 **500,000 prompts**，并且 metamodel 能**零样本泛化**到域外数据集；(iii) 预测结果保留了**行为预测信号**（behavior-predictive signal）；(iv) **Qwen2.5** 的 context activations 能预测 **Qwen3.5** 与 **Gemma 4** 的 mean-pooled answer activations，提示激活预测可**跨模型迁移**。总体而言，context activation 轨迹可在生成第一个答案 token 之前支撑对 LLM 答案行为的可扩展预测。

## 🎯 核心贡献

1. 提出 **context–answer metamodel** 范式：用"读 context 时的激活序列"直接预测"rollout 期间的平均池化答案激活"，把多次昂贵的自回归 rollout 折叠为一次前向预测。
2. 系统比较 **四类 metamodel 家族**，其中**点预测**高保真拟合均值激活，**分布预测**额外刻画随机解码下的 rollout 变异性。
3. 规模化验证：训练集扩至 **500,000 prompts** 时性能持续提升，且可**零样本泛化到域外数据集**。
4. **跨模型迁移**：Qwen2.5 的 context 激活可预测 Qwen3.5 与 Gemma 4 的答案激活——说明 metamodel 学到的是相对模型无关的行为结构。
5. 证明预测保留了**行为预测信号**，使其不仅是重构性拟合而具有下游可用性。

## 🔧 方法/架构

设模型 $f$ 在 context $c$ 上的答案激活序列为 $\mathbf{A}_{\text{ans}}$，context 编码阶段的激活序列为 $\mathbf{A}_{\text{ctx}}$。

- **Metamodel 目标**：学习映射 $g: \mathbf{A}_{\text{ctx}} \mapsto$ 对 $\mathrm{meanpool}(\mathbf{A}_{\text{ans}})$ 的预测：

```math
\hat{\boldsymbol{\mu}} = g_{\theta}\!\left(\mathbf{A}_{\text{ctx}}\right), \qquad
\hat{\boldsymbol{\Sigma}} = h_{\phi}\!\left(\mathbf{A}_{\text{ctx}}\right)
```

  - 点预测（point）家族：仅输出 $\hat{\boldsymbol{\mu}}$；
  - 分布（distribution）家族：同时输出 $\hat{\boldsymbol{\Sigma}}$，用以刻画随机解码 rollout 的波动。
- **数据构造**：对每个 prompt 采集 context 阶段激活与多次 rollout 的答案激活（mean-pooled），构成训练对。
- **四类家族**：摘要提及"四个 metamodel 家族"（具体架构细节见原文），均以 context 激活为唯一输入。
- **评估维度**：预测保真度、rollout 变异性捕捉能力、域外零样本泛化、行为预测信号保留、跨模型迁移（Qwen2.5 → Qwen3.5 / Gemma 4）。

## 📊 实验结果

- **预测保真度**：四类 metamodel 家族对 mean-pooled answer activations 的预测保真度高；分布型家族同时捕捉 rollout 变异性。
- **数据规模**：训练集增大到 **500,000 prompts** 时性能持续提升（未饱和）。
- **泛化**：metamodel 可**零样本**泛化到域外（out-of-domain）数据集。
- **跨模型迁移**：Qwen2.5 的 context 激活可预测 **Qwen3.5** 与 **Gemma 4** 的 mean-pooled answer activations。
- 摘要未披露具体相关系数/MSE 等数值（详见原文实验章节）；涉及模型为 Qwen2.5、Qwen3.5、Gemma 4。

## ⚠️ 局限性

- 只预测 **mean-pooled** 答案激活，是高度压缩的表征；细粒度逐层/逐 token 行为是否同样可预测未验证。
- 采集训练数据本身需要大量 rollout，"更可扩展"是相对而言（预测 1 次 vs rollout N 次），训练侧成本并未消除。
- 跨模型迁移仅在三个 Qwen/Gemma 家族之间验证，跨架构/跨规模外推性未知。
- 摘要未给出任何定量误差指标，也未说明所预测的"行为预测信号"具体由哪些下游任务度量。
- "四类 metamodel 家族"未在摘要中定义，读者需查原文。

## 💡 建议

- 是否推荐使用：是（做 LLM 行为预测、不确定性估计、可解释性方向的研究者强烈推荐）
- 适用场景：想在生成前预测 LLM 会"怎么说"（如预判风险/风格/拒答概率）；降低评估与采样成本；跨模型行为迁移与对齐分析；作为 harness/agent 的前置行为模型。
