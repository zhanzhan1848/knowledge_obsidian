## 核心贡献
1. **把多图 LVLM 的"图像选择"步骤形式化为 in-context image retrieval（上下文内图像检索）**并给出 head 级别的机制刻画。论文指出这一步是"门控"式的：grounding 到错误图像会让后续计算基于错误的视觉证据。
2. **提出 ICIR-MCQ：一个受控的 head 级检索探针**。每个样本包含 $N$ 张候选图、交错图文上下文、一个指定物体类别的文本 query，以及 4 个候选 caption；要求模型选出最能描述"含被查询类别的那张图"的 caption。构建自 MS-COCO，继承 MM-NIAH 的图像检索任务的交错结构与文本段落，但把原图换成 COCO 自然图像，因此**文本段落按构造与目标图像和选项无关**；干扰 caption 取自含同一被查询类别的其他 COCO 图像，确保模型不能只靠类别线索作答。
3. **Pointer criterion（输入侧）**：用每个 head 在图像 token span 上的注意力质量给图像打分：

$$m^{(l,h)}_i(p) = \sum_{j=s_i}^{e_i} A^{(l,h)}_{p,j}$$

$$s^{(l,h)}_{\text{ptr},i} = \sum_{j=s_i}^{e_i} \tilde{A}^{(l,h)}_{p,j}, \qquad \tilde{A}^{(l,h)}_{p,j} = \mathrm{softmax}\Big(\frac{q^{(l,h)}_p \cdot k^{(l,h)\top}_j}{\sqrt{d_h}}\Big)_j$$

高 R@1 的 head 称为 **pointer heads**。**指针能力极度稀疏且局部化**：最好的 pointer head 在四个 LVLM 上 R@1 达 **0.866–0.922**（chance 为 0.183），而中位 head 接近 chance；强 head 集中在**中段层带**（L21 附近）。
4. **跨 backbone 的高度可复现性**：共享同一 LLM backbone 的 LVLM（即使视觉编码器与训练数据不同）在特定 (layer, head) 索引上高度重合——top-3 pointer head 在每个 backbone 组内**集合完全一致**；8B 两模型共享 top-100 中的 **86** 个，4B 两模型共享 **80** 个。
5. **Pointer heads 可迁移到自然多图基准**：在 Visual Haystacks（haystack size $N=10$）上，单个在 ICIR-MCQ 上发现的 pointer head 的 per-image 检索 R@1 为 **0.787–0.836**（chance 0.1），**超过外部视觉-语言检索器** CLIP（0.573）、SigLIP（0.649）、Qwen3-VL-Embedding-8B（0.751）。
6. **提出 Writer criterion（输出侧），这是本文的核心方法论贡献**。在 cattok 位置，head 的输出是价值加权向量：

$$o^{(l,h)}_p = \sum_{j=1}^{T} A^{(l,h)}_{p,j} v^{(l,h)}_j \in \mathbb{R}^{d_h}, \qquad v^{(l,h)}_j = W^{(l,h)}_v x_j$$

论文的论点是：**注意力模式表明 head "指向"哪里，但不决定它"写入"什么**。value 投影决定哪些信息从被注意的 token 进入输出——即使注意力集中在目标图像上，也不保证 head 输出包含足以识别该图的信息。为此，为每个 head 训练一个**轻量 head-specific 图像检索器**：

$$s^{(l,h)}_{\text{wri},i} = \tilde{f}_{\theta_{l,h}}(o^{(l,h)}_p) \cdot \tilde{g}_{\phi_{l,h}}(e_i)$$

其中 $e_i$ 是候选图像 $i$ 在 **LVLM 自己的语言模型嵌入空间**中 mean-pool 后的投影视觉 token（因此 writer 探针用模型自身的图像表示，而非外部编码器），$\tilde f,\tilde g$ 用 **InfoNCE** 联合训练。
7. **核心实证发现：pointing ≠ writing**。两种排序都集中在中段层带，但 top-100 仅有 **35–47** 个 head 重合。pointer-only 与 writer-only head 集合给出实质不同的排名，"两种标准提供互补且不可互换的排序"。
8. **因果验证：set-partition ablation**。把 pointer top-100 与 writer top-100 的并集划分为三组互不相交的集合——**pointer-writer 重叠**（35–47 个）、**pointer-only 尾**（53–65 个）、**writer-only 尾**（53–65 个）。对每个集合的 top-$K$（$K\in\{5,10,15,20,25,30\}$）做**输出侧零消融**（在 output projection 之前把 head 的输出贡献置零，移除其对残差流的加性写入），并配**同预算的随机 head 对照**，在 haystack size $N\in\{2,3,5,10,20,50\}$ 上评测。**结论：pointer-writer 重叠组的消融造成最一致的准确率下降**；writer-only 组与随机对照几乎无法区分；pointer-only 组有温和但不太一致的效果。

## 问题背景
现代 LVLM（Flamingo、Qwen3-VL、InternVL3.5、Pixtral 等）可以在单一上下文中处理交错文本与多张图像，支撑文档理解与多图问答。在多图上下文中，回答一个图像锚定的问题需要的不仅是视觉识别：模型必须**先判断问题指的是哪张图**。

多图基准（Visual Haystacks、MM-NIAH）显示模型准确率随候选图像数增加而下降，暴露 in-context image retrieval 是核心行为瓶颈。但这些基准只评估输出行为，不揭示 LVLM 内部如何做图像选择、哪些组件承载了检索信号。

**方法论缺口**：head 级别的分析传统上依赖注意力模式（syntax head、induction head、long-context factual retrieval head 都如此识别）。这在实践中有效，但"指向"只是注意力操作的一面——head 的输出是按注意力权重混合 value 向量得到的向量，**下游层消费的是这个输出而非注意力模式本身**。论文假设这一 gap 在 LVLM 的 in-context image retrieval 中尤其关键，因为这里的检索是**跨模态**的：注意力指向视觉 token span，但价值加权输出必须把目标图像信息以**后续语言生成层可用的隐藏表示**携带出来。这造成 pointing 与 writing 的错配——一个 head 可能干净地指向目标图像，却不写入可从其输出中恢复的目标图像信息。

## 方法
### 1. 形式化
交错上下文 $C = (\tau_0, I_1, \tau_1, I_2, \ldots, I_N, \tau_N, u)$，$I_1..I_N$ 是候选图像，$\tau_0..\tau_N$ 是插入的文本段落，$u$ 是任务指令。分词后上下文成为长度 $T$ 的序列，每张图占据连续视觉 token span $[s_i, e_i]$。

head $(l,h)$ 的 post-softmax 注意力矩阵 $A^{(l,h)} \in \mathbb{R}^{T\times T}$。head-level 检索正确性：

$$r^{(l,h)} = \mathbb{1}\Big[\arg\max_i s^{(l,h)}_i = i^\star\Big]$$

报告 head-level R@1（在样本上平均）。

### 2. ICIR-MCQ 的三项设计约束
1. 输入是交错图文上下文，匹配多图 LVLM 的一般输入形式；
2. 插入的文本段落**不泄露**目标图像或正确 caption；
3. 候选图像是自然图像，使 head 级发现不依赖合成视觉构造。

**实现**：从 MS-COCO 构建，继承 MM-NIAH 图像检索任务的交错结构，保留其文本段落不变、替换图像与 caption 为 COCO 内容——因此文本段落**按构造**独立于目标图像与答案选项。用 COCO 类别标注控制 per-image 归属目标：被查询类别只在目标图像中标注、不在任何干扰图像中出现，使目标图像在类别线索下**无歧义**。干扰 caption 从含同一被查询类别的其他 COCO 图像采样，因此模型不能只靠类别线索解题，必须 ground 到正确图像。

**评分位置（cattok）**：在被查询类别**最后一次提及的最后一个 token** 处评分——该位置类别线索刚在文本中出现、且所有候选图像 span 都在因果过去中。目标图像位置与正确答案字母在选项间**均匀平衡**。

### 3. Writer 检索器的训练细节
对每个 head $(l,h)$，在 head 输出 $o^{(l,h)}_p$ 上训练轻量检索器。ICIR-MCQ 按**样本级**划分为互不相交的 train/eval 子集。writer head 发现时，在每个 LVLM 的 **1,200 张 held-out 候选图像池**上评估 Eq. 5，计算目标图像是否排第一的 R@1（称 writer R@1）。

**重要的尺度说明**：pointer R@1 在每个 prompt 内的图像上计算，writer R@1 在 1,200 张 held-out 池上计算，**两者的绝对值不可直接比较**；因此 writer R@1 只被用作**输出侧的排序准则**。

### 4. 因果干预设计
**干预方式**：对选中的 head $(l,h)$，在 output projection **之前**把该 head 的输出贡献置零，从而移除它对残差流的加性写入。论文明确说明这比先前检索头分析中用的 query-side masking **更严格**：query masking 扰动 head "看哪里"但仍可能留下价值加权输出，而本文的干预直接移除 head 的写入本身。

**干预窗口**：只作用于问题的**图像检索 span**（从 anchor 物体第一个 token 到最后一个 prefill 位置；target 物体结束问题，其后只有少量格式 token）。**不在答案生成期间施加干预**。

**为什么用 set partition 而非直接比较 top-K**：直接比较 pointer top-$K$ 与 writer top-$K$ 集合会把因果贡献与它们的部分重叠混淆，因此取两者并集再划分为三个互不相交子集，配合同预算随机 head 对照。

## 实验结果
- **Dataset/Task**:
  - **ICIR-MCQ**（发现探针）：MS-COCO 构建，N 张候选图 + 4 个候选 caption，多选题。
  - **Visual Haystacks**（迁移与因果评测）：每例含多张图与一个 Yes/No 问题，含 **anchor object**（标识目标图）与 **target object**（被查询其是否存在）。haystack size $N\in\{2,3,5,10,20,50\}$。
  - **模型**：四个 LVLM，跨两个家族与两个规模——InternVL3.5-{4B, 8B} 与 Qwen3-VL-{4B, 8B}。两个家族在视觉编码器与训练数据上不同，但 **4B 变体共享同一 LLM backbone，8B 变体亦然**，因此可研究跨 backbone 的 head 级稳定性与同 backbone 内的 head 索引可复现性。

    单个 pointer head 超过全部三个外部检索器。论文明确声明这**不是受控的训练目标对比**（内部 head 与外部检索器工作在不同的表示与条件信号上），而是说明 LVLM 内含一个高度有效的、**上下文条件化**的图像选择信号。4B 变体在此尺寸下匹配甚至略超 8B，说明强 pointer 信号不限于大模型。
  - **Pointing ≠ Writing**：在 top-100 水平，两种准则仅有 **35–47** 个 head 重合（Figure 2 的对角线外点明确展示了这一分离）。
- **Ablations**:
  - **Set-partition 消融（Figure 3）**：在 $K\in\{5,10,15,20,25,30\}$ 与 $N\in\{2,3,5,10,20,50\}$ 上，**pointer-writer 重叠组**造成的准确率下降最一致，且效应随消融预算增长、在 haystack size 2–20 时最明显（此时基线尚有余量）；在更大 haystack size 下基线已接近 Yes/No chance，可下降空间变小故效应减弱。**writer-only 组与随机对照几乎无分离**——说明"仅输出侧可恢复性"不足以识别对标准推理最相关的 head。**pointer-only 组有温和且不太一致的效果**，$K\ge10$ 的平均结果仍弱于重叠组。
  - **跨 backbone 一致性**：pointer 头 top-3 在每个 backbone 组内集合完全一致；8B 组共享 top-100 中的 86 个、4B 组共享 80 个。writer 头 top-5 共享 3–4 个，全部四模型共有 3 个。
  - **干预方式的严格性论证**：论文对比了 query-side masking（先前检索头分析的做法）与本文的 output-side zero-ablation，指出前者扰动"看哪里"但仍留下价值加权输出，本文直接移除写入本身。
  - **随机对照的作用**：与同预算随机 head 的分离说明下降**不是**仅仅因为移除了该序列区域的 head 或减少了总体 head 容量。

## 关键洞察
1. **"指向"与"写入"是两个独立的属性，注意力分析只能看到前者。** 这是本文最具方法论价值的论断，且被定量证实（top-100 仅 35–47 重合）。它意味着传统的 attention-pattern head discovery 在跨模态检索任务上**系统性地不完整**——会选中只指向却不携带目标信息的 head。
2. **"用检索器做探针"是一个可推广的 head 级发现范式。** 与其在输出上定义一个人工指标，不如**在输出上训练一个任务相关的检索器**，用其 top-1 准确率作为"该 head 的输出是否携带目标信息"的度量。这把"可恢复性"变成可测量的量，且天然适用于任何"从中间表示中能否恢复某属性"的问题。
3. **单个注意力 head 就能超过专门训练的外部检索器。** L21H10 在 10 图 haystack 上 R@1 0.79–0.84，vs CLIP 0.573 / SigLIP 0.649 / Qwen3-VL-Embedding 0.751。论文给出的机制解释很到位：外部检索器用全局图像嵌入对比**无上下文**的文本嵌入，而 pointer head 在模型自身的表示空间上用 **patch 级 key**、以 cattok 处**经上下文条件化的 query** 做注意力。这是"生成模型内嵌了检索器"的一个强证据。
4. **同 backbone 的 head 索引高度可复现，即使视觉编码器与训练数据不同。** 4B 组共享 LLM backbone 的 InternVL3.5 与 Qwen3-VL 在 L21H10 等位置给出相同的 pointer head 集合。这说明**图像检索机制主要位于语言 backbone 中，且对视觉前端相对不敏感**——这既是可解释性的好消息（可以跨模型迁移分析），也提示该机制可能是语言模型的通用能力而非视觉特有。
5. **因果上最相关的是"交集"而非任一单边。** 只有同时满足 pointer 与 writer 的 head 集合才与标准推理有稳定因果联系。这给出了一个具体的干预设计原则：**不要只放大对目标图的注意力，要同时确保 value 通路写入目标信息**。论文据此提出未来方向——只重训/steer 一小组已能良好指向的 head 的 value/output projection。
6. **输出侧消融比 query 侧 mask 是更严格的因果测试**，这一点对整个 head 分析文献都有方法论意义：query masking 会同时改变"看哪里"与"写什么"，无法隔离。
7. **稀疏性是共同的**：pointer 的中位 R@1 ≈ 0.20（chance 0.183），writer 的中位 R@1 ≈ 0.08–0.10。检索信号**极度集中**在少数 head 上，这既解释了消融的有效性，也说明机制分析必须精确定位到 head 而非层级。

## 局限性
- **模型覆盖窄**：只测四个近期开源权重 LVLM（两个家族 × 两个规模）。论文自己承认更广的模型覆盖有助于判断 pointer-writer 结构有多普遍。
- **两个 R@1 的评估池不同**（pointer 在 prompt 内图像上，writer 在 1,200 张 held-out 池上），因此**绝对值不可比**，writer 只能作排序准则用。这限制了"writer 能力是否真的强"的定量判断——无法说 pointer 0.92 与 writer 0.59 谁"更强"。
- **单目标检索**：Visual Haystacks 评测只隔离单目标图像检索；论文承认扩展到跨图比较、多目标 grounding、组合推理是自然方向但未做。
- **因果干预只在有限窗口**：消融只施加于问题的图像检索 span（anchor 物体首 token 到最后 prefill），且不在答案生成期间施加。因此结论限于"检索这一步"，不能推断这些 head 在生成阶段的作用。
- **消融效应的动态范围受限**：haystack size 20 与 50 时基线已接近 Yes/No chance，可下降空间小，故大 N 下的分离不清。这限制了因果结论的统计强度。
- **writer 探针依赖 1,200 张图的 held-out 池**且需为每个 head 训练检索器——训练成本与规模（4 个模型 × 数百个 head × 多次训练）在正文中未量化。
- **ICIR-MCQ 是合成式受控探针**：虽然用自然图像与真实 COCO caption，但其"查询类别只在目标图中出现"的构造比真实场景更干净；论文用 Visual Haystacks 做了迁移验证，但 probe-to-transfer 的差距未量化。
- **未检验这些 head 是否被用于回答生成**：论文明确区分了"输出侧可恢复性"（writer 准则）与"模型是否使用该输出"（因果消融），但消融结果是**集合层面**的，未定位单个 head 的具体功能。
- **pointer 与 writer 排名不一致的机制未解释**：论文观察到分离，但未说明为什么某些 head 能干净地指向却不写入（例如 value 投影在该位置是否退化）。

## 适用场景
- **适合**：多图 LVLM 的机制分析与 head 级干预设计；构建"图像检索 head"的诊断工具（可用于解释模型在 haystack 变大时为何退化）；跨模型迁移 head 分析（同 backbone 家族可直接复用发现结果）；任何"从中间表示能否恢复某属性"的探针方法学参考。
- **不适合**：需要单图输入或无交错的场景（本文机制不适用）；结论直接外推到闭源前沿 LVLM（未测）；需要确定"最强检索 head"的绝对能力评估（R@1 口径不同，不可直接比较）；生成阶段的干预设计（本文只覆盖检索阶段）。
