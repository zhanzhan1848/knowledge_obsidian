## 核心贡献

**开源预训练配方**，在消费级 RTX 5090 GPU 上训练 2B 模型，成本 **<$6.9K**，性能接近 Qwen2.5-1.5B。

### 关键技术

| 组件 | 技术 |
|------|------|
| **硬件** | RTX 5090 集群（消费级 GPU） |
| **精度** | Blockwise FP8 混合精度训练 |
| **优化器** | MuonH（Muon + Hyperball 约束） |
| **数据调度** | Curriculum Model Averaging (CMA) |
| **数据选择** | Proxy 实验指导数据集选择和混合设计 |

### 成本细分

| 阶段 | Tokens | GPU Hours | 成本 |
|------|--------|-----------|------|
| Phase 1 | 438.8B | ~ | ~ |
| Phase 2 (uniform) | 960B | - | $4.4K |
| Phase 2 (CMA) | 960B | 22,514 total | $6.9K |

### Puro Cost Scaling Law
训练成本与模型性能的尺度关系：约 **$4.4K** 即可达到 Qwen2.5-1.5B 性能水平。

## Pipeline

```
公开数据集 → 数据选择（Proxy 实验）
    ↓
RTX 5090 集群（24-96 GPUs）
    ↓
Phase 1 (438.8B tokens, 24 GPUs)
    ↓
Phase 2 (960B tokens, 96 GPUs)
    ↓
Curriculum Model Averaging / Uniform
    ↓
Post-training (SFT)
    ↓
评估
```

## 五大效率优化

1. **RTX 5090**： Blackwell 架构，支持高效 FP8，提供良好的 cost-efficiency trade-off
2. **Blockwise FP8**：主 Transformer GEMM 用 FP8，敏感操作和 optimizer states 保持 BF16/FP32
3. **MuonH**：Muon optimizer + hyperball 约束 + 精细学习率 schedule
4. **CMA**：按源本地偏好粗粒度分块数据排序，对最后 6 个 checkpoint 做平均
5. **Proxy 实验**：大数据候选项池的经验信号指导数据集选择

## 实验结果

- $4.4K checkpoint 超过 Qwen2-1.5B 平均性能
- $6.9K checkpoint 接近 Qwen2.5-1.5B
- Phase 2 使用 curriculum 可获得 1.65× 相对 uniform 的 cost-efficiency 提升
- Post-training 后 curriculum/CMA 与 uniform 的差异仍然存在

## 数据配方

- 主要使用公开可访问数据集
- 无需精致的数据评分和筛选
- 通过 proxy 实验进行数据选择
