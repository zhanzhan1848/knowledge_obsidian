## 核心贡献

> 用 **Petri 网**形式化 LLM 与工具之间的执行 harness 为 **supervisory control（监督控制）问题**，在 prompt injection 下给出**可证明安全**且**最小侵入**的架构。

1. **形式化**：
   - **marks（标记）** 表示能力（capabilities）、审批（approvals）与预算（budgets）；
   - **transition（转移）只有在所需 marks 存在时才可触发**；
   - → 一个 precondition 未满足或预算已耗尽的**注入请求，无论措辞如何都会被拒绝**。
2. **理论结果**：
   - 把 tool outcomes 视为**不可控（uncontrollable）** → 采用传统的 **maximally permissive supervisor**（最大允许监督器）来保证安全；
   - 在**四个假设**下，该安全性可**迁移到运行中的系统**；
   - 引入 **replanning closed loop** 概念（agent 可能在被拒后再次提议，每次重试消耗一次 inference 调用）；
   - 在该闭环中，**传统监督器可能比更严格的 safe supervisor 更具侵入性**（arbitrarily more intrusive）；
   - 对给定 proposer model，**maximally permissive least-intrusive supervisor 可刻画为传统监督器的 value-threshold refinement**；
   - 在精确条件下，该 refinement 排序两个并发动作**至多相差一个 monitor place**。
3. **实证**：在 **autonomous release agent** 上，通过 synthesis 发现**安全部署需要一个监督器能在 rollout 启动后仍可否决的步骤**。

## 技术方案

| 概念 | 含义 |
|------|------|
| Petri net mark | 能力 / 审批 / 预算的持有状态 |
| Transition | 工具调用；precondition 缺失 → 拒绝 |
| Maximally permissive supervisor | 在不可控 tool outcome 下的安全上界 |
| Replanning closed loop | 拒绝后 agent 重试，每次重试 = 一次 inference |
| Value-threshold refinement | 最少侵入版本的刻画 |
| Synthesis | 自动寻找安全策略 |

### 关键洞见

- **"措辞无关"的拒绝**是关键设计：注入请求的说服力再强，也无法绕过**marks 检查**。这把安全从"prompt 层"移到"状态机层"。
- **replanning closed loop 的发现很重要**：如果 agent 能反复重试，一个"看起来宽松"的 supervisor 实际可能**更侵入**（更多 inference 成本 + 更多风险）。直觉上"越严格越安全"在这里是错的。
- **"rollout 启动后仍可否决"** 这一步在实践中常被遗漏 —— 只在动作前审查是不够的。

---

## 实验结论

- 形式化保证（4 项假设下的安全性迁移）；
- 最小侵入 supervisor 的刻画：value-threshold refinement，排序差 ≤ 一个 monitor place；
- Autonomous release agent 实证：安全部署**需要** rollout 后可否决的步骤。

---

## 局限性

- Petri 网建模的**表达力与实际 agent 行为**之间有差距；
- "四个假设"在实际系统中的**可验证性**存疑；
- synthesis 结果**如何工程化**（规模可扩展性）未讨论；
- 需较深的控制论背景，落地成本高。

## 实现建议

- **实现难度**：高（需形式化建模 + 控制理论 + 工程实现）
- **预期价值**：高 — 目前 agent 安全层多为启发式（prompt 审查 + 事后过滤），缺形式保证
- **适用场景**：高权限 agent（发布、交易、运维）、多租户 agent 平台
- **建议部署**：
  1. 短期：把"**能力/预算/审批 marks**"显式化（哪怕用简单计数器），替代纯 prompt 审查；
  2. 中期：借鉴 **rollout 后可否决**的设计（预留 kill switch）；
  3. 长期：探索形式化 harness
