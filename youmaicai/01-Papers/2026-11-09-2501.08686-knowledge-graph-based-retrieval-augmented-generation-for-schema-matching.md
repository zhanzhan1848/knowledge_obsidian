# Knowledge Graph-based Retrieval-Augmented Generation for Schema Matching

> **arXiv**: [2501.08686](https://arxiv.org/abs/2501.08686)
> **发表日期**: 2025-01-15（v2 更新于 2026-11-06）
> **分类**: cs.DB (及交叉分类 cs.CL, cs.IR)
> **会议/期刊**: ACM TKDD（To appear）；DOI: 10.1145/3862591

## 📋 摘要

传统的基于相似度的 schema matching 方法，由于缺乏常识知识与领域特定知识，在复杂、领域专用的映射场景中无法消解语义歧义与冲突。与此同时，缺乏足够背景知识的 LLM 又容易产生幻觉，令 schema matching 更加困难。为克服这两点，本文提出 KG-RAG4SM（Knowledge Graph-based Retrieval-Augmented Generation for Schema Matching）。该方法集成了一系列新的检索机制——基于 LLM 的检索、基于向量的检索、基于图遍历的检索以及它们的混合方式——并配合先进的重排序（reranking）方案，从大型外部知识图谱中抽取最相关的子图，从而为 LLM 提供有依据的外部知识上下文。方法无需重新训练即可取得优异结果：在 MIMIC 数据集上，相比 LLM 类的 SOTA 方法（如 Jellyfish-8B），precision 提升 **39.79%**、F1 提升 **30.56%**；在 Synthea 数据集上，相比 PLM 类的 SOTA 方法（如 SMAT），precision 提升 **69.20%**、F1 提升 **21.99%**。此外，KG-RAG4SM 在从常识知识图谱到领域专用图谱的各种 KG 上都能有效扩展；其"指令微调知识排除"（instruction-tuning knowledge exclusion）组件能确保在 KG 上下文相关性不佳的情况下，端到端 schema matching 仍表现真实可靠。实证分析与真实场景案例研究表明，该方案有效缓解了 LLM 在 schema matching 中的幻觉问题。

## 🎯 核心贡献

1. **KG-RAG4SM 框架**：首次把知识图谱增强生成系统性地引入 schema matching，用外部 KG 的结构化常识与领域知识为 LLM 补齐背景知识短板。
2. **多路检索机制**：LLM-based、vector-based、graph traversal-based 以及 hybrid 检索的组合，配合先进 reranking，从大型外部 KG 中抽出最相关子图。
3. **指令微调知识排除组件**：当检索到的 KG 上下文相关性不佳时，主动排除这些知识，保证端到端任务表现"真实"，而不是被噪声上下文带偏。
4. **免重训的显著增益**：在 MIMIC 上相对 Jellyfish-8B precision +39.79% / F1 +30.56%；在 Synthea 上相对 SMAT precision +69.20% / F1 +21.99%。
5. **跨 KG 类型可扩展**：同一套方法在常识型 KG 与领域专用型 KG 上均有效。

## 🔧 方法/架构

- **外部 KG 作为知识底座**：接入大型外部知识图谱（既可用常识 KG 也可用领域专用 KG），把 schema 元素的语义信息扩展到 KG 的结构化上下文中。
- **多路检索（multi-path retrieval）**：
  - *LLM-based retrieval*：由 LLM 直接判断/抽取相关的 KG 实体与关系；
  - *Vector-based retrieval*：把实体/子图向量化做语义近邻检索；
  - *Graph traversal-based retrieval*：沿 KG 的边做多跳遍历以捕获结构关系；
  - *Hybrid*：上述方式的组合，兼顾语义与结构。
- **Reranking**：对候选子图做重排序，筛出真正与待匹配 schema 元素相关的部分。
- **指令微调知识排除（knowledge exclusion）**：通过指令微调让模型在上下文不相关时"弃用"这些知识，避免错误注入与幻觉。

$$
\text{Precision} = \frac{|\text{正确匹配的 schema 对}|}{|\text{模型预测的匹配对}|}
$$

$$
F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
$$

（实验以 precision / recall / F1 三项指标评估 schema 对匹配质量。）

## 📊 实验结果

- **数据集**: MIMIC（医疗）、Synthea（合成医疗），以及跨 KG 类型的扩展评测（常识 KG 与领域专用 KG）。
- **基线**:
  - LLM-based SOTA：Jellyfish-8B
  - PLM-based SOTA：SMAT
- **结果**:
  - **MIMIC**：相对 Jellyfish-8B，precision **+39.79%**，F1 **+30.56%**。
  - **Synthea**：相对 SMAT，precision **+69.20%**，F1 **+21.99%**。
  - 无需重新训练（without requiring re-training）。
  - 摘要未给出各方法的绝对 precision/F1 数值，仅给出相对提升百分比。

## ⚠️ 局限性

- **强依赖外部 KG 的质量与覆盖度**：KG 缺失或过时会导致检索不到有效证据。
- 多路检索 + 重排序的**多阶段流水线延迟较高**，在线实时场景需权衡。
- 精度/召回的绝对水平未在摘要中披露，**仅提供相对提升**，难以评估真实可用性。
- 摘要未说明对**不同规模 schema、跨域 schema**的泛化表现，以及对 KG 规模增长的检索开销曲线。
- "知识排除"组件依赖指令微调，模型规模较小时可能无法稳定执行"弃用噪声知识"这一行为。
- 2025 年 1 月首发、2026 年 11 月更新至 v2，作为 TKDD 论文，其结论基于较早期的基线（Jellyfish-8B、SMAT），与当前更强基线的对比需要重新评估。
