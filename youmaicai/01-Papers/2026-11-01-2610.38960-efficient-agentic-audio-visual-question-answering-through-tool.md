## 核心贡献

> 只需 omni-modal captioning + omni-modal QA 两个工具，AVQA 准确率不降而推理成本降约 70%。

1. 系统研究 Omni-modal agent 的细粒度音视频问答是否真的依赖宽泛的专用工具集，尤其是音频或视觉模态专属工具。
2. 通过分阶段受控实验**剪枝工具集**并把模态专属工具逐步合并为 omni-modal 工具，最终只需两个工具：omni-modal captioning 与 omni-modal QA。
3. 紧凑 agent 在三个常用 AVQA 基准上达到与专用工具 agent 相当甚至更好的准确率，同时**推理成本降低约 70%**。

## 技术方案

### 核心思想

Omni-modal agent 通过自主编排感知工具来主动收集证据，在音频视觉问答上表现强劲。但一个问题始终没有答案：这种主动感知是否**真的需要两个模态各自的专用工具集**？这类系统通常还会带来很长的执行轨迹和可观的推理成本。

论文的思路是做一个**自上而下的减法实验**。起点是完整的专用工具 agent（OmniAgent），然后分阶段推进：先剪枝工具集，再把模态专属工具合并为 omni-modal 工具。每一步都测量性能与成本的变化，从而定位「哪些工具是真正必需的」。

结果导向的结论非常干净：只要保留 **omni-modal captioning** 与 **omni-modal QA** 两个工具，就能达到相当甚至更好的准确率，同时推理成本降低约 70%。这说明专用工具集里存在大量冗余 —— 很多「专用」工具实际提供的信号，可以由通用 omni-modal 工具覆盖。

这个发现的价值在于它是一个**否定性结论的正面应用**：不是「加更多工具」，而是「砍掉大部分工具」。在 agent 工具集设计中，这是一个可迁移的设计原则 —— 工具数量与能力并不同步。

### 关键技术

| 技术 | 说明 |
|------|------|
| 分阶段工具剪枝 | 从完整专用工具集出发逐步删减，每阶段测量准确率-成本曲线 |
| 模态工具合并 (modality consolidation) | 把音频/视觉专属工具统一为 omni-modal 工具 |
| 双工具紧凑 agent | 最终仅保留 omni-modal captioning 与 omni-modal QA |
| 推理成本核算 | 对比完整轨迹长度与推理开销，量化 70% 的成本下降 |
| 三基准验证 | 在三个常用 AVQA 基准上对比专用工具与紧凑 agent |

## 实验结论

- **数据集**: 三个广泛使用的细粒度音视频问答（AVQA）基准
- **基线**: OmniAgent（专用工具集的全量编排 agent）
- **结果**: 双工具紧凑 agent 在三个基准上达到相当或更好的准确率，同时推理成本降低约 70%。

- **成本降 70% 而准确率不降** —— 这是 agent 工具集设计的一个强反直觉结论。
- 「专用工具不一定比通用工具更有信息量」这一点，对所有构建工具型 agent 的团队都有直接价值。
- 分阶段剪枝而非一次性重构，保证每一步的收益都可归因。
- 推理成本的下降主要来自轨迹缩短，对需要严格延迟预算的在线系统意义重大。

## 局限性

['结论限于音频视觉问答域，工具冗余程度在其他域（代码、数据库、网页）可能不同。', '「专用工具」的冗余可能来自具体实现的重叠，而非领域本质。', '剪枝路径依赖作者选定的起点与合并顺序，可能存在更优配置。', '紧凑 agent 在困难样例上的失败模式未详细分类。']

## 实现建议

- **实现难度**: 中（需复现 OmniAgent 工具环境并实现剪枝与合并管线）
- **适用场景**: 多模态 agent 工具集设计、音视频问答系统、推理成本优化、agent 架构精简
- **建议**: **不要默认「多模态就要配模态专属工具」**。按论文的方法做减法：分阶段剪枝 → 合并为 omni-modal 工具 → 测准确率-成本前沿，很可能同样效果下省下大部分工具与 70% 成本。

## 原始摘要

```
Fine-grained audio-visual question answering (AVQA) requires models to resolve complex cross-modal correspondences and temporally grounding from sparsely distributed evidence. Omni-modal agents, which autonomously orchestrate perception tools to actively collect evidence, achieve strong performance, but it remains unclear whether active perception from both audio and visual modalities depends on broad specialized toolsets, especially audio or visual modality-specific tools. Such systems may also introduce long execution trajectories and substantial inference cost. We investigate whether comparable performance can be retained with a compact workflow exposing only essential perceptual capabilities. Starting from the specialized-tool OmniAgent, we conduct staged controlled experiments that prune the toolset and progressively consolidate modality-specific tools into omni-modal tools, motivating a two-tool agent comprising only Omni-modal captioning and Omni-modal QA. Across three widely used AVQA benchmarks, our compact agent achieves comparable or better accuracy than the specialized-tool agent while reducing inference cost by around 70%.
```
