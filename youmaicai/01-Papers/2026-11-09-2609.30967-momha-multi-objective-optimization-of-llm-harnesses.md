# MoMHa: Multi-Objective Optimization of LLM Harnesses over Accuracy, Safety, and Tokens

> **arXiv**: [2609.30967](https://arxiv.org/abs/2609.30967)
> **发表日期**: 2026-09-25（v2: 2026-11-06）
> **分类**: cs.AI
> **会议/期刊**: NeurIPS 2026

## 📋 摘要

多数改进大语言模型的工作把**准确率当作唯一目标**。本文主张：**harness**——即围绕模型、用于构造 prompt、路由调用与解析输出的那层 Python 代码——是一个**一等的设计面（first-class design surface）**，其质量天然是**多目标**的：一个拒绝不了任何不安全请求的准确 harness，或者 token 消耗高出一个数量级的 harness，都不是好 harness。作者提出 **Meta-Harness**：把 harness 设计刻画为**在每个领域三个目标（准确率、行为安全、token 成本）上的搜索**，由一个具备**完整文件系统访问权限**的**agentic proposer（Claude Code）**求解——它可读取既有 harness 源码、执行轨迹与评分产物。核心发现是：**单阶段联合奖励的 proposer（MoMHa）优于所有其他方案**，包括"先准确率后 token"的两阶段消融、仅标量反馈的方案，以及仅优化准确率的基线。实验覆盖 **17 个领域**：**7 个合成能力套件**、**7 个真实公开基准**（**HumanEval、MBPP、Spider、FEVER、MMLU-Pro、LawBench、NuminaMath**）、以及 **3 个源自 U-SafeBench 的用户特定安全领域**，使用横跨 **4 个模型家族**的 **12 模型机队**。结果：合成赛道 MoMHa 的**联合均分达 0.482**，而 10 个基线为 **0.198–0.422**，赢得 **10 个领域列中的 7 个**；真实赛道得分 **0.461**，对比最强基线 **DSPy** 的 **0.377**，赢得 **7 列中的 5 列**——表明 harness 策略**无需在 12 个目标模型中的 8 个上重训即可迁移到未见基准**。MoMHa 取得**最高的行为安全复合分（U-SafeBench，0.781）**，且比两阶段方案**每样本少用 95 个 token**。作者承诺开源全部 harness 代码、评估基础设施与跨模型日志。

## 🎯 核心贡献

1. **提出"harness 是一等设计面"的论点**：harness 的质量必须按**准确率 + 行为安全 + token 成本**三目标联合衡量，单一准确率会奖励出实际有害或资源浪费的 harness。
2. **Meta-Harness 系统**：把 harness 设计形式化为**每领域三目标搜索**，并由拥有**完整文件系统访问权**（既有 harness 源码、执行轨迹、评分产物）的 **agentic proposer（Claude Code）** 求解。
3. **MoMHa：单阶段联合奖励优于两阶段**：核心实证结论——"先优化准确率、再优化 token"的两阶段消融**不如**单阶段联合奖励，联合优化避免了第一阶段为追求准确率而过度消耗 token 的路径依赖。
4. **大规模跨域实证**：**17 个领域**（7 合成 + 7 真实基准 + 3 U-SafeBench 安全域）、**12 个模型**（4 个家族）、**10 个基线**的对比规模在 harness 优化类工作中属罕见。
5. **跨模型迁移性证据**：harness 策略在 **12 个目标模型中的 8 个**上无需重训即可迁移到未见基准，说明学到的 harness 包含**模型无关的策略知识**。

## 🔧 方法/架构

- **三目标联合奖励**（每领域独立）：

```math
R(\text{harness}) = w_{\text{acc}}\, A(\text{harness})
+ w_{\text{safe}}\, S(\text{harness})
+ w_{\text{tok}}\, T(\text{harness}),
\quad T = -(\text{tokens per example})
```

准确率 $A$、行为安全 $S$（U-SafeBench 派生的复合分）、token 成本 $T$ 三者联合，而非分阶段串联。

- **Agentic proposer**：**Claude Code** 作为搜索算子，具备**完整文件系统访问权**——可读既有 harness 源码、过往执行轨迹（execution traces）与评分产物（scoring artifacts），从而把"搜索"实现为对 harness 代码的改写：

```math
h^{(t+1)} = \mathrm{Propose}\big(h^{(t)},\; \text{src},\; \text{traces},\; \text{scores};\ R\big)
\]

- **对照设计（消融）**：
  - **两阶段**："先准确率、后 token"；
  - **仅标量反馈**（scalar-only feedback）；
  - **仅准确率**（accuracy-only baseline）；
  - **DSPy**（最强真实赛道基线）。

- **评估构成**：
  - **合成赛道**：7 个合成能力套件，报告 **10 个领域列**；
  - **真实赛道**：7 个公开基准；
  - **安全赛道**：3 个 U-SafeBench 派生的**用户特定安全领域**；
  - 模型机队：**12 个模型 / 4 个家族**。

## 📊 实验结果

- **基准与规模**：**17 个领域** = 7 个合成能力套件 + 7 个真实公开基准（HumanEval、MBPP、Spider、FEVER、MMLU-Pro、LawBench、NuminaMath）+ 3 个 U-SafeBench 派生安全域；**12 模型**（4 家族）；**10 个基线**。
- **合成赛道**：MoMHa **联合均分 0.482**；基线区间 **0.198–0.422**；赢得 **10 个领域列中的 7 个**。
- **真实赛道**：MoMHa **0.461** vs 最强基线 **DSPy 0.377**；赢得 **7 列中的 5 列**。
- **安全性**：**U-SafeBench 行为安全复合分 0.781**（最高）。
- **效率**：比两阶段方案**每样本少用 95 个 token**。
- **迁移性**：在 **12 个目标模型中的 8 个**上，无需重训即可迁移到未见基准。
- 摘要未给出方差、置信区间与逐领域分数（详见原文表格）；作者承诺开源 harness 代码、评估基础设施与跨模型日志。

## ⚠️ 局限性

- **依赖闭源 proposer**：搜索算子是 **Claude Code**，且需要完整文件系统访问权；复现者需自行准备等价 proposer 与权限环境，搜索行为难以精确重现。
- **安全分与准确分存在潜在冲突**：联合奖励中各目标的权重 $w$ 的设定方式与敏感性分析未在摘要中说明，"最高安全分"可能来自权重倾斜而非帕累托改进。
- **合成赛道占优可能来自过拟合**：在合成能力套件上 0.482 vs 0.422 的差距大于真实赛道 0.461 vs 0.377 的相对优势，摘要未区分哪些增益是真实迁移、哪些是对合成任务的过拟合。
- **与真正的人类偏好脱节**：安全域源自 U-SafeBench 的用户特定安全要求，"安全复合分 0.781" 与真实临床/生产环境的安全需求之间存在代理差距。
- **未报告方差与显著性**：17 领域 × 12 模型的规模很大，但摘要只给点估计，跨 run 稳定性未知。
- **成本与收益比未澄清**：搜索本身消耗大量 LLM 调用（12 模型 × 17 领域），"每样本省 95 token" 的收益需要多少搜索预算才能兑现，摘要未量化。
- **开源承诺尚未兑现**：论文写于 2026-09，当前 v2 未附可用仓库链接（摘要未给出代码地址）。

## 💡 建议

- 是否推荐使用：**是**（把 harness 当作多目标优化对象、并坚持"单阶段联合奖励优于两阶段"这一点，对任何做 agent 框架工程的团队都有直接指导意义）
- 适用场景：LLM agent 框架/harness 的自动化调优；在准确率之外需要同时管控安全与成本的生产系统；需要跨模型迁移的 prompt/路由/解析策略搜索；作为"harness 层优化"这条研究线的代表性文献引用。
