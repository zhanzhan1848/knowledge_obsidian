# SKIM: Pruning Large Language Model Agents via Selective Knowledge Informed Masking

### 核心贡献
1. 指出已有压缩方法与 structured generation 场景之间的根本性错配：在 grammar constraint 下模型输出分布被约束到合法 token，logits 最重要的是决定 agent 动作的少数位置上的值，因此「非结构化生成时代」的剪枝/蒸馏准则并不适用。
2. 提出 SKIM（Selective Knowledge-Informed Masking），首个面向 structured generation 下 LLM agent 的剪枝+蒸馏框架，两个阶段均由 token role 引导。
3. 设计 token 位置的三分类划分（context / decision / format），并将其转化为两条互补的技术轴：类别感知的剪枝显著性评分（保护对 decision 位置最相关的参数）与 on-policy 蒸馏目标（在合法 token 上对齐师生输出）+ 类别感知的特征匹配。

### 技术方案
**核心思想**: 把 LLM agent 在 grammar-constrained 推理中的 token 按功能角色划分为 context、decision、format 三类，让「压缩预算」按角色重要性重新分配——decision 类 token 承载最终动作选择，必须优先保住参数与特征对齐。

| 技术 | 说明 |
|------|------|
| Token role 划分 | 将 token position 划分为 context / decision / format 三类，是两个阶段的共同引导信号 |
| 类别感知剪枝显著性评分（category-aware pruning saliency） | 按 token 所属类别计算参数重要性，保留对 decision positions 最相关的参数 |
| On-policy 蒸馏目标 | 学生与教师在 valid tokens 上对齐，配合 category-aware feature matching 约束隐层特征 |
| Structured generation 视角 | grammar constraint 把输出分布缩减到合法 token 集合，logits 仅在决定 agent 动作的少量位置上最关键 |
| 评测设置 | tool-calling benchmarks + 多步 agent loop，覆盖多个 model scales 与 sparsity levels |

### 实验结果
- **数据集**: tool-calling benchmarks，以及 within multi-step agent loops 的多步代理循环任务（具体 benchmark 名称摘要未说明）
- **基线**: 摘要仅表述为 "baselines"（现有剪枝/蒸馏方法，涵盖 conventional methods），具体基线名单摘要未说明
- **结果**: SKIM 在所有评测中一致提升 accuracy；在 high-sparsity regime 优势最为显著，此时 conventional methods 表现挣扎。摘要未给出具体数值型指标

### 局限性
- 摘要未提供量化数值（accuracy 提升幅度、各 sparsity 水平下的具体分数），也未说明基线方法的具体名称。
- 摘要未说明 grammar 约束由哪种框架施加（grammar-constrained decoding 实现）、决策 token 位置的具体判定规则，以及是否需要额外标注来划分 token role。
- 剪枝与蒸馏两阶段均依赖 token role 划分，该划分在不同 agent 任务上的可扩展性未验证；摘要未涉及跨任务迁移或计算开销的评估。

### 关键洞见
> 常识是「agent 的上下文最重要，剪掉它最亏」，但 SKIM 指出在 grammar-constrained 生成里恰好相反：context 与 format token 的取值空间被语法本身锁死，其 logits 携带的信息量低，而决定动作的那少数 decision 位置才是高信息密度的。这把剪枝从「按频率/幅度删不重要参数」变成了「按语法角色分配预算」，也解释了为什么在 high-sparsity 下分类感知的优势会拉开差距——传统方法在极高稀疏率时优先牺牲的往往正是那批低价值却数量庞大的 context/format 参数。
