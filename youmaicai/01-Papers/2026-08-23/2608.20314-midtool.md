## 核心贡献
1. **MidTool Pipeline**: 开放的 agentic tool-use mid-training 语料构建管道
2. **多源数据融合**: 结合大规模 web、PDF、code 数据与真实工具 API、MCP skills、文档驱动工作流
3. **四项能力培养**: 识别工具 affordances、从上下文提取参数、组合工具调用工作流、从不完整信息恢复

## 核心创新点

### 研究背景
Mid-training 已被证明是塑造 LLM 能力的关键阶段：
- 可强化 math/science 等推理密集型能力
- 可改善软件工程场景的 agentic 能力
- **但 general tool use 尚未被充分探索**

### MidTool-Mix 构成
1. **Web Data**: 大规模网页数据
2. **PDF Data**: 文档数据
3. **Code Data**: 代码数据
4. **Tool API Supervision**: 真实工具 API 合成的监督信号
5. **MCP Skills**: Model Context Protocol skills
6. **Document-grounded Workflows**: 文档驱动的工作流

### 四项核心能力
- **Tool Affordance Recognition**: 识别工具能做什么
- **Argument Grounding**: 从上下文提取参数
- **Workflow Composition**: 组合工具调用序列
- **Incomplete Information Recovery**: 从不完整信息恢复

## 实验结果
在 Qwen3-4B-Base 和 Qwen3-8B-Base 上进行实验：

### Benchmarks
- BFCL (Bento Federal Computer Science License)
- tau2-Bench
- MCP Universe

### 后训练方式
- Supervised Fine-Tuning (SFT)
- Reinforcement Learning (RL)

### 结论
- MidTool-Mix 在 SFT 和 RL 后训练下均显著优于基线
- General tool use 能力与其他重要 LLM 能力一样受益于专门的 mid-training

## 核心结论
> General tool use, like other important LLM capabilities, benefits from dedicated mid-training rather than being left entirely to post-training.
