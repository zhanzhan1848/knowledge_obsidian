## 核心贡献
1. **自适应推理模式选择**: 模型学习为每个问题选择合适的推理 effort
2. **无独立 Router**: 通过 GRPO 内学习模式选择，而非独立路由模块
3. **41% 响应长度减少**，同时保持 MATH500 精度接近基线

## 核心创新点

### 问题背景
现有 reasoning 语言模型通常在**固定 token 预算**下运行：
- 简单问题 → 过度计算 (over-computation)
- 困难问题 → 计算不足 (insufficient computation)

### 三种推理模式
模型在响应首个 token 选择：
- **\texttt{NoThink}**: 尽快回答
- **\texttt{Short}**: 简短推理
- **\texttt{Long}**: 扩展推理

### 训练方法
使用 **Group Relative Policy Optimization (GRPO)**：
- Shaped reward：使每种模式在不同响应长度下有价值
- Hard per-mode token caps：保持模式间的区分度
- **无需独立 router**，选择作为响应第一个 token 学习

## 实验结果

### MATH500 (1.5B distilled model)
| 指标 | 数值 |
|------|------|
| 基线精度 | 0.796 |
| 自适应精度 | 0.782 |
| 平均响应长度减少 | **41%** (4796 → 2811 tokens) |

### 跨基准迁移 (无需 retraining)
| Benchmark | Token 减少 | 精度对比 |
|-----------|-----------|---------|
| GSM8K | **76%** | 高于基线（相似响应长度） |
| MATH500 | 41% | 接近基线 |

### 关键发现
- 三种模式出现且**未坍缩为单一选择**
- **Brief modes (NoThink/Short) 比 Long 更准确**
- 说明 router 按难度而非随机排序问题

## 核心结论
> We build a reasoning model that adaptively chooses how much to reason for each problem.
