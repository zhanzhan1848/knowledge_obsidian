## 核心贡献

> 系统研究**低比特存储 n-gram embedding 表**能否在不损失其性能收益的前提下大幅压缩内存 —— 四比特表可省约 **75%** 表内存，同时保留**超过 99%** 的验证集 loss 改善。

1. **问题定位**：近期开放权重模型广泛使用 n-gram embedding 表（存储 2~3 个连续 token 的短序列表示，推理时检索），但这类表内存占用巨大 —— DeepSeek-V4.1-Flash 为其 Engram n-gram memory 分配了 **1960 亿参数**
2. **系统性量化研究**：跨不同量化方法与不同表的 bit 分配方案做全面对比
3. **四比特是甜点**：四比特表节省约 75% 内存，同时保留 >99% 的"加表带来的验证 loss 改善"
4. **更低位宽可被微调挽救**：更少比特会导致更大性能下降，但一小段 fine-tuning 可挽回其中相当一部分
5. **省下的内存可再投资**：把节省的内存用于扩大表，可以**超过**原始全精度表的性能，同时总内存仍然更少
6. **可直接迁移到现有大模型**：在 DeepSeek-V4.1-Flash 与 Qwen3.8-Flash-Next 上，低比特表节省 **47–55%** 表内存，perplexity 增幅 **< 1.2%**，下游任务性能基本保留

## 技术方案

### 核心思想

n-gram 表本质是一块巨大的可查表（类似静态 embedding + 稀疏扩展）。这类查表结构天然适合低比特量化，因为检索后可以单独反量化；同时因为表的容量可以反哺为更大规模的表，量化收益不止于"省内存"，还可以转化为"更高性能"。

### 关键组件

| 组件 | 说明 |
|------|------|
| N-gram embedding table | 存储短 token 序列（二元/三元）的学习表示，推理时检索 |
| Low-precision storage | 表以低比特（4-bit 及更低）存放 |
| Quantization scheme comparison | 系统比较不同量化方法 |
| Bit allocation | 跨不同表分配不同比特预算 |
| Short fine-tuning recovery | 更低位宽下降后，用短微调阶段恢复性能 |
| Memory reinvestment | 用省下的内存扩大表规模以换取更高性能 |

### 关键公式

验证集 loss 的相对改善保留率（用于量化"加表收益"被保留了多少）：

```math
\rho = \frac{\Delta \mathcal{L}_{\text{low-bit}} - \mathcal{L}_{\text{base}}}{\Delta \mathcal{L}_{\text{fp}} - \mathcal{L}_{\text{base}}}
```

其中 $\Delta \mathcal{L}_{\text{fp}}$ 为全精度表相对基线的 loss 改善，$\Delta \mathcal{L}_{\text{low-bit}}$ 为低比特表的改善；$\rho > 0.99$ 表示保留超过 99% 的改善。

比特预算与显存占用的关系：

```math
M_{\text{table}}(b) \approx \frac{b}{16} \cdot M_{\text{table}}(\text{fp16}), \qquad b \in \{8, 4, 2, 1\}
```

反投资策略（用节省的内存扩大表）：

```math
N_{\text{new}} = N_{\text{orig}} \cdot \frac{16}{b} \quad\Longrightarrow\quad M_{\text{new}} = M_{\text{orig}} \ \text{（内存持平，表更大）}
\]

## 实验结论

### 从零训练的模型（nanochat-、Llama-、GPT-2 系列）

| 指标 | 结果 |
|------|------|
| 四比特表内存节省 | **约 75%** |
| 保留的验证 loss 改善 | **> 99%** |
| 更低位宽（低于 4-bit） | 性能下降更大，短微调可挽回相当一部分 |
| 内存再投资 | 扩大表后**性能超过原始全精度表**，且总内存更少 |

### 现有大模型

| 模型 | 表内存节省 | Perplexity 变化 | 下游任务 |
|------|-----------|------------------|---------|
| DeepSeek-V4.1-Flash | 47–55% | 增幅 **< 1.2%** | 基本保留 |
| Qwen3.8-Flash-Next | 47–55% | 增幅 **< 1.2%** | 基本保留 |

参照点：DeepSeek-V4.1-Flash 为其 Engram n-gram memory 分配了 1960 亿参数。

## 局限性

- 只研究 n-gram embedding 表这一类结构，未验证对常规词表 embedding 或其他稀疏/结构化参数同样有效
- 更低位宽（2-bit 及以下）的性能下降明显，微调恢复幅度取决于具体模型与微调预算，摘要未给出量化
- "内存再投资扩大表"带来的收益在从零训练的小规模实验上测得，迁移到已有大模型时需重新训练表，未验证
- 量化会引入数值误差，对需要精确检索匹配的下游任务（如精确复制、结构化抽取）的影响未单独评估
- perplexity 增幅 < 1.2% 是在两个具体模型上得到的结果，跨模型泛化性未系统检验

## 实现建议

- **实现难度**: 中低（量化表实现成熟，难点在于确定不同表的 bit 分配策略）
- **适用场景**: 拥有大体积 n-gram 表的开放权重模型（DeepSeek 系、Qwen 系），以及自训模型希望在同等内存下放大表容量
- **建议起点**: 先在自训小模型（nanochat / GPT-2 级）上复现 4-bit 方案，确认 loss 改善保留率，再对真实大模型做表级量化并评测下游任务
- **价值点**: 4-bit 是"几乎无损"的甜点；再进一步做内存再投资，把省下的 47–75% 表内存换成更大的表，是提升而非仅仅持平的收益
