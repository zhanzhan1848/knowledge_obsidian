## 核心贡献

> 发现掩码扩散语言模型在"任何 token 生成之前"的掩码响应位置隐状态中就已携带可检测的伤害性信号，与提示表示互补；据此提出免改权重、免改解码的 ReFuse 双视图融合检测器。

1. 识别出 dLLM 特有的安全检测面：自回归解码每步只暴露下一 token 预测状态，而 dLLM 在去噪前就为所有未来掩码响应位置维护隐状态，这些状态条件于输入并表征模型"正在浮现的响应"，因此可从中线性分类器直接检出越狱。
2. 实证两个视图互不支配：提示视图分类器在 HBB/PAIR 上强但对 ReNeLLM/DIJA 弱；响应视图分类器在 DIJA 上强（把 ASR 降到 6.29%）而在 PAIR/ReNeLLM 上弱；两者检出的样本集合与分数差分布（p_R − p_P）方向均不同。
3. 提出 ReFuse（Representation Fusion）：融合两个分类器的 sigmoid 伤害性分数并施加标定阈值，在 LLaDA-8B-Instruct 上把平均 ASR 从 63.29%（未防御）、11.27%（仅提示分类器）降至 3.31%，同时标准效用基准上良性拒答率保持 <1%。

## 技术方案

### 核心思想

扩散大语言模型（dLLM）通过迭代去噪掩码 token 并行生成文本，天然存在两类 dLLM 特有攻击：PAD 在去噪过程中注入对抗 token 引导并行细化走向有害遵从；DIJA 在提示中交错文本与掩码 token 以利用双向掩码补全。现有防御（DiffuGuard、RPO、Self-Reminder 等）都介入去噪过程或需要微调。

本文的出发点是：不改模型行为，而是直接从模型未改动的"解码前状态"中检出伤害性。关键观察是 dLLM 与自回归模型的结构差异——dLLM 在初始状态就为整个响应长度分配掩码位并计算其隐状态，且已有工作发现 dLLM 的"答案早收敛"现象，即模型在去噪完成前很久就已基本确定输出。因此在生成任何 token 之前，掩码响应位置的隐状态已包含关于"模型将要说什么"的安全相关信息——这是自回归解码中不存在的检测面。

方法上，作者用两次前向构造两个视图的表示：提示视图来自不含掩码位的纯提示前向，对提示位置隐状态做均值池化；响应视图来自带掩码序列的前向，取响应位置在去噪步 k 的隐状态做均值池化，其中 z_R^(0) 即"解码前响应表示"（此时所有响应位仍为掩码）。在两个表示上分别训练线性分类器。

实证发现两视图互补而非替代：DIJA 这类交错文本与掩码 token 的攻击削弱了提示侧检测，但响应侧能恢复大量漏检；PAIR 的分数差分布偏负（响应侧打分更高），DIJA 偏正，HBB 集中在零附近，ReNeLLM 跨双向，说明两视图不只是检出集合不同，方向与幅度也不同。

ReFuse 不采用"任一分类器报警即拒"的硬并集（会继承两视图的全部假阳性，XSTest 良性拒答率从 12.22% 升至 20.00%），而是融合连续分数后施加单一阈值：s(x) = λ·p_P(x) + (1−λ)·p_R(x)，当 s(x) ≥ τ 时在解码前返回固定安全拒答，否则生成过程完全不受干预。λ 与 τ 在分类器训练集的验证划分上网格搜索，按有害漏检率与良性误拒率的 Pareto 前沿选平衡点，选定后固定用于所有测试评估。

### 关键公式

```math
% dLLM 全序列解码初始化
\mathbf{x}^{(0)} = \big[x_1,\ldots,x_p \mid M_{p+1},\ldots,M_{p+r}\big]

% 双视图表示（末层隐状态均值池化）
\boldsymbol{z}_{\mathrm{P}}(x) = \frac{1}{|\mathcal{P}|}\sum_{i\in\mathcal{P}}\hat{\boldsymbol{h}}_i^{(L)},\qquad
\boldsymbol{z}_{\mathrm{R}}^{(k)}(x) = \frac{1}{|\mathcal{R}|}\sum_{i\in\mathcal{R}}\boldsymbol{h}_i^{(k,L)}
% z_R^{(0)} 为解码前（全部响应位仍掩码）的响应表示

% ReFuse 分数融合与拒答判定
s(x) = \lambda\, p_{\mathrm{P}}(x) + (1-\lambda)\, p_{\mathrm{R}}(x),\qquad
\text{ReFuse}(x) = \mathbb{1}\{s(x)\ge\tau\}
% \lambda\in[0,1] 控制两视图相对贡献，\tau 为拒答阈值

% 评测指标（越低越好）
\mathrm{ASR} = \frac{\text{未被检测器拒绝且解码后产生伤害性遵从的有害输入数}}{\text{有害输入总数}}
\mathrm{BRR} = \frac{\text{被拒绝或产生拒答的良性输入数}}{\text{良性输入总数}}
```

### 关键组件

- **提示视图分类器**：在纯提示前向的末层隐状态均值池化表示上训练的线性分类器。
- **响应视图分类器**：在掩码序列前向、响应位置隐状态上训练的线性分类器；最佳配置为训练时混合早期去噪状态、评测时用 z_R^(0)。
- **ReFuse 融合**：凸组合 + 单阈值，λ/τ 通过网格搜索在验证集 Pareto 前沿上选取，测试时固定。
- **ReFuse+**：单次掩码前向同时算两路分数的低开销变体（牺牲部分鲁棒性换更低生成前开销）。
- **攻击套件**：HarmBench Behaviors (HBB)、PAIR（自动改写）、ReNeLLM（良性上下文嵌套有害请求）、DIJA（dLLM 特有，交错掩码）；另含 AH、Prefill。
- **评测协议**：WildGuard 判定伤害性遵从与良性拒答；被检测器标记的攻击请求映射为固定拒答并计为攻击失败；无效生成与不确定判定被剔除，故有效样本量随模型与防御变化。
- **效用基准**：ARC-C、MATH-500、MBPP（平均 BRR）；XSTest（单独面板，考察近似不安全请求的过拒）。
- **迁移性实验**：LLaDA-8B-Instruct 与 LLaDA 1.5（VRPO 后训练变体）之间的检测器迁移。

## 局限性

- 检测器需在分类器训练集上训练（线性分类器 + 大量有害/良性样本），并非完全零样本；论文强调的是无需微调 dLLM 本身、无需改动解码。
- 需要两次前向（提示 + 掩码序列），带来生成前开销；ReFuse+ 变体缓解但牺牲鲁棒性。
- 自适应攻击可绕过检测：score-aware PAIR 在 9 次迭代预算下 goal-level ASR 升到 11.11%；论文也承认未评估通过分类器梯度做白盒对抗攻击的情形。
- 在 Dream-7B 上残余 ASR 仍达 13.23%，远高于 LLaDA 系列，说明方法对不同 dLLM 架构的迁移效果不稳定。
- 响应侧视图带来良性过拒代价：仅响应分类器在 XSTest 上过拒升高，需要靠融合标定来平衡。
- WildGuard 作为判分器本身有噪声，且无效生成被剔除使各方法的实际评测样本量不同，严格来说并非完全同基准对比。

## 建议

- **是否推荐使用**：是
- **适用场景**：部署 LLaDA / Dream 等掩码扩散 LLM 时的推理期越狱防护；需要对 dLLM 做轻量级、不改权重的安全审查网关；dLLM 安全研究方向。
- **值得复现**：是（"利用掩码响应位的解码前隐状态做检测"这一思路可直接迁移到其他有并行解码结构的模型）
