## 核心贡献

> 提出 OpenVLHarness —— 一个围绕"能力层 + 持久化多模态记忆"组织的多模态推理框架，专门解决 MLLM 在需要 grounded perception、外部知识与数值测量任务上的能力不足。

1. **能力层 (Capability Layer)**：统一异构工具接口，将后端输出自动渲染为模型可读观测 (evidence rendering)
2. **持久化多模态记忆 (Persistent Multimodal Memory)**：跨推理步骤保留图像、结构化数据与 web 引用为可寻址 artifact
3. **编码接口 (Coding Interface)**：在存储数据上执行生成式程序，支持多工具结果组合计算
4. **强实证结果**：在 22 个 benchmark 上较无工具基线平均提升 9.7-12.6 分，且 token 成本仅为最大推理预算模型的 37%

---

## 技术方案

### 核心思想

MLLM 视觉推理的瓶颈不在模型内部推理能力（单纯的推理预算扩张仅带来有限增益），而在**外部证据的获取、组织与复用**。OpenVLHarness 将这一过程系统化为：能力层 (获取/渲染) + 持久化记忆 (存储/索引) + 编码接口 (计算) 三段式 pipeline。

### 关键技术

| 技术 | 说明 |
|------|------|
| Capability Layer | 任务级工具接口 + evidence rendering，将异构后端输出转为统一可观测 |
| Persistent Multimodal Memory | 跨推理步骤持久化 image/structured data/web references |
| Coding Interface | 让模型生成程序并对存储数据执行计算，组合多工具结果 |
| Iterative Evidence Loop | 获取 → 检查 → 组合 → 再获取的循环过程 |

### 关键公式

```math
\Delta_{\text{score}} = \text{Score}_{\text{harness}} - \text{Score}_{\text{no-tool}}
```

OpenVLHarness 在 22 benchmarks 上的 $\Delta_{\text{score}} \in [9.7, 12.6]$。

## 实验结论

### Benchmark 覆盖

- **22 个 benchmark** 横跨 grounded perception、外部知识、数值测量等多类视觉推理任务
- **8 个 backbone**：开源 (Qwen3-VL-8B 等) 与闭源 (GPT-6 Astra, Kimi K3 等) 并测

### 主要结果

- **Qwen3-VL-8B**: +11.2 平均分
- **Kimi K3**: +9.7 平均分
- **GPT-6 Astra**: +9.9 平均分
- **GPT-6 Luna (medium reasoning)**: 较 base model/Codex/Visual Sketchpad (maximum effort) 提升 7.7-8.5 分，仅消耗 ≤37% token 成本

### 关键发现

> 单纯的推理预算扩张 (test-time scaling) 收益有限，必须借助工具调用 + 持久化记忆才能在复杂视觉任务上获得显著增益。

---

## 局限性

- 仅在所选 22 个 benchmark 上验证，对其他视觉推理领域 (如医学影像、遥感) 泛化性待评估
- 持久化多模态记忆带来额外存储开销
- 编码接口引入了代码执行的安全与正确性风险

## 实现建议

- **实现难度**: 中等 (需要 capability layer、记忆存储、代码沙箱三件套)
- **预期性能**: 在视觉推理任务上较 baseline 提升约 10 分
- **适用场景**: 多步视觉任务、需结合外部工具 (OCR、检测、搜索) 的真实生产力场景
- **集成点**: 可作为 Qwen3-VL / GPT-6 / Claude 等的 harness 外挂
