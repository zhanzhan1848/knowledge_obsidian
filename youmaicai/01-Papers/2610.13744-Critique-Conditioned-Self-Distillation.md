## 核心贡献

> 揭示 on-policy self-distillation 中"只打分、不搜索"teacher 的结构失败：定位推理错误是搜索问题，不是打分问题。

1. **诊断**: full-distribution KL 与 token log-ratio 都无法定位错误、无法将概率推离错误 token
2. **解决方案**: critique-conditioned self-distillation — 先生成 critique，再以 critique 条件打分
3. **效果**: 信号 localizes errors、推动 backtracking 词（"Wait"/"But"/"Actually"）概率上升

---

## 技术方案

### 核心思想

传统 RLVR（verifiable-reward RL）只给 sparse outcome signal；on-policy self-distillation 想给 dense token-level credit，但仅靠"打分 teacher"不能定位错误。**错误定位是搜索问题**——必须显式生成 critique。

### 关键技术

| 技术 | 说明 |
|------|------|
| Full-distribution KL | 标准 self-distillation 信号 |
| Token log-ratio | 另一种 dense credit |
| Critique-conditioned scoring | 先生成 critique，teacher 据此再打分 |
| Backtracking-inducing signal | 提升 "Wait"/"But"/"Actually" token 概率 |
| Cold-start GRPO | 在 verifiable reward 无信号处提供 advantage |

### 关键直觉

定位推理 trace 中的错误 ≈ 局部搜索问题；scoring teacher 从未被要求做这个搜索。同一模型、同一 privileged info，**显式生成 critique 时定位错误显著更好**。

---

## 实验结论

- **任务**: 数学 reasoning rollouts
- **结果**:
  - Critique-conditioned signal **localizes errors** within error spans
  - 在错误位置**推动概率向 backtracking tokens 移动**
  - Test-time 用 critique resume 把"模型采样解不出"的题转成"可解"
  - Cold-start GRPO 中 critique 提供 advantage signal（verifiable reward 失效处）

---

## 局限性

- 依赖 critique 生成质量；critique 本身是新的失败模式来源
- 仅在数学 reasoning 上评估，其他 domain 未验证
- 与 Process Reward Model (PRM) 的边界尚未厘清

---

## 实现建议

- **实现难度**: 中高（需要 critique 数据生成 + 条件化训练）
- **预期性能**: GRPO 在 hard prompts 上的 cold-start 改善
- **适用场景**: 数学/代码 reasoning、GRPO 启动困难任务
