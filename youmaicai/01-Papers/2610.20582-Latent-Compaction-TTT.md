## 核心贡献

1. **把 KV cache 本身当 neural network** → test-time training (TTT) 学 compact doc-specific cache
2. **两阶段训练**：
   - Stage 1：attention outputs + log-normalizers 拟合 full cache（recon-selected entries fixed）
   - Stage 2：整 cache 联合优化（end-to-end distillation from full-cache）
3. **跨 model scale / family transfer**：Qwen3 + MiniCPM5

## 方法

### Latent Compaction 核心 idea

```python
# Frozen model weights
# Optimizable cache entries per document
cache = init(
    reconstruction_importance,
    teacher_attention,
    key_space_diversity
)
# Stage 1: fit attention outputs + log-norm (held entries fixed)
cache.stage1_fit_attention_outputs_and_log_normalizers()
# Stage 2: end-to-end distillation
cache.stage2_joint_optimization_with_distillation()
```

### 关键约束

- **Model weights frozen throughout**
- 仅用 **generic doc prompts**，不见下游 Q/A

### 初始化

```math
cache_init = α * reconstruction_importance
           + β * teacher_attention
           + γ * key_space_diversity
```

## 实验结果

| Benchmark | 提升 |
|-----------|------|
| RULER | 32× compression **96.7% accuracy** vs **KVZip+ 40.0%** |
| LongBench | 全面领先 budget-matched baselines |
| Phonebook Lookup | 全面领先 |
| 跨 model | Qwen3 + MiniCPM5 都 valid |

## 局限性

- TTT 训练需要 prefill 阶段 wall-clock 时间（额外计算）
- 仍需 "generic doc prompts" 设计（domain-specific 文档需重新设计 prompts）
- Cache 优化过程不可解释（黑盒优化）

## 建议

- **是否推荐使用**：是（specific 长上下文 / 长输出场景）
- **适用场景**：长上下文 / 长输出 LLM 部署 / 长文档检索
- **运营价值**：vs PN-Mix（mixed-precision 路线）→ Latent Compaction 是 quality-first，PN-Mix 是 efficiency-first
