## 核心贡献

> 用 **轨迹自身 hindsight** 当 token 级 credit signal，无需 group sampling 也无需 learned critic。

1. **HP-RLVR 框架**：对完成 trajectory 的每个 token，policy snapshot 同时 score 在 causal history 下与 hindsight context（含 realized future + verifier feedback）下的概率。
2. **Jensen-Shannon divergence 归一化**：两视图的归一化 JS divergence 作为 reward weight，bounded token credit 适用于 success / failure 两种情况。
3. **rollout 效率大提升**：在 Qwen3-8B 上相对 GRPO，math **1.21×**, code **1.46×**, ALFWorld **2.30×** 训练加速，每 prompt 仅 **1/8** rollouts。

---

## 技术方案

### 核心思想

RLVR 的痛点：
- 终端 scalar reward 难分到 tokens；
- GRPO 需要 group sampling → rollout 成本爆炸；
- 同一 prompt 多次 rollout 同 outcome → reward-based signal 退化。

HP-RLVR 关键洞察：**完成轨迹的 future + verifier feedback 是免费的 hindsight signal**。用 generating policy snapshot 双视图评分：

```text
w_i ∝ JS( π(· | history_≤i)  ||  π(· | history_≤i, hindsight) )
```

归一化后 w_i ∈ [0, 1]，bounded，可用于 success & failed attempts。无 reference solution、无 learned critic。

### 关键技术

| 技术 | 说明 |
|------|------|
| Hindsight context | 已 realize 的 future + verifier feedback |
| Policy snapshot dual-view | 同 snapshot policy 下两上下文评分 |
| JS divergence normalization | bounded weight ∈ [0,1] |
| Single-rollout | 不需 group sampling |
| Historical baseline | w_i 相对 baseline 归一 |

## 实验结论

- **模型**: Qwen3-4B / 8B（也可能 更大）
- **任务**: mathematics, code generation, ALFWorld
- **基线**: GRPO
- **结果**:
  - 在 100-step schedule：math **1.21×**, code **1.46×**, ALFWorld **2.30×** 加速；
  - rollouts per prompt: **1/8** GRPO；
  - math 三档均胜 GRPO；code / ALFWorld 略落后；
  - ALFWorld 中 **43.2% (4B) / 49.0% (8B) GRPO 梯度范数为 0**，HP-RLVR 无此问题 → GRPO 的稀疏信号问题暴露。

---

## 局限性

- 依赖 verifier 提供 structured feedback，对开放式生成（无 verifier）扩展需设计；
- hindsight signal 在 long horizon 上因果耦合复杂，远端 token 信用是否能有效传递不确定；
- 单 rollout 在 hard exploration（需试错）任务上效果待验证。
