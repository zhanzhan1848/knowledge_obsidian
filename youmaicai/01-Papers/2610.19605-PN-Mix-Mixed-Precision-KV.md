## 核心贡献

1. **RoPE channel-pair level 的 attention logit perturbation 分析** → 揭示 query-key pair-norm product 大的 channel pair 上 quantization error 对 logit variation 贡献大
2. **PN-Mix**：在 prefill 阶段一次识别 salient channel pairs → 解码阶段复用高 precision；其余用低 precision
3. **Pareto 优雅降级**：vs baseline 在 2.25 bit 以下 sharp drop，PN-Mix 平滑降到 1.5 bit

## 方法

### 关键观察

```math
Δlogit ∝ ||q_i|| · ||k_j|| · cos(θ_ij - θ_ij^quant)
# 当 ||q_i|| · ||k_j|| 大时，quantization error Δθ 引起的 Δlogit 大
```

### PN-Mix 算法

```python
# Prefill 阶段
salient_pairs = identify_salient_pairs(
    Q, K,
    metric='pair_norm_product'
)
# 解码阶段
for pair in RoPE_channel_pairs:
    if pair in salient_pairs:
        quantize_to_high_precision(pair)
    else:
        quantize_to_low_precision(pair)
```

### Saliency metric

- 用 query-key **pair-norm product** 而非 key-only statistics
- RoPE channel-pair level（不是 channel level）
- Prefill 阶段识别一次（O(N) cost）

## 实验结果

| 配置 | 平均精度 | 平均 accuracy |
|------|----------|---------------|
| PN-Mix | **2.26-bit** | 相当或更好 |
| Prior mixed-precision | 2.32–2.39-bit | baseline |

- Benchmark：reasoning / code-gen / AIME
- Pareto sweep：PN-Mix **优雅降到 1.5 bit**，baseline 在 2.25 bit 以下 sharp drop

## 局限性

- 仅针对 key cache（不针对 value cache）
- Prefill cost 需要重做（虽然是一次性的）
- 主要针对 RoPE-based decoder-only LLMs（不直接适用其他架构）
- 1.5 bit 下仍可能有 accuracy drop（虽然平滑）

## 建议

- **是否推荐使用**：是
- **适用场景**：长输出 LLM 推理部署 / 2-bit KV cache 但需要保精度的场景
- **运营价值**：vs 4-bit KV cache → memory 减半；vs 1-bit → accuracy 显著提升
- **部署优先级**：在 RoPE-based decoder LLM 上 plug-in 集成成本低
