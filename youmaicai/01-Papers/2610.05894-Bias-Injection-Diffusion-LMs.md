# Noise Out, Bias In: Targeted Bias Injection in Diffusion LMs via Closed-Loop Activation Steering

## 元信息

## 核心贡献

1. **新攻击面发现**：masked dLLM 在每个 denoising 步都暴露答案分布（不像 AR 仅在 commit 时暴露），给对手提供持续可观察的"控制通道"。
2. **针对性偏见注入攻击**：用比例-积分 (PI) 控制器跟踪目标答案概率，实时调整 steering vector 强度。
3. **实验规模**：单 GPU 约 40 分钟完成一次攻击，效率可观。

## 模型架构 / 方法

- **PI 控制器**：
  ```math
  u_{t+1} = u_t + K_p (e_t - e_{t-1}) + K_i \cdot e_t
  ```
  其中 `e_t = p_target - p_current`，`u_t` 为 steering vector 强度。
- **Steering vector**：在 dLLM 内部激活上施加定向扰动，牵引生成向目标答案。
- **目标**：在不修改模型权重的前提下，让 frozen dLLM 输出指定的偏见答案。

## 实验结果

| 设置 | 指标 | 数值 |
|------|------|------|
| BBQ 含糊题（正确答案为弃权）LLaDA-8B-Instruct | 目标人群偏好 | **1.8 → 16.7 pp**（超过最强定强度 steering 基线 3 倍以上）|
| SocialStigmaQA | 污名化答案选择率 | 17.6% → **58.1%** |
| 跨其他人设目标 | 答案偏移 | up to **37 pp** |
| 攻击成本 | 单 GPU 时间 | ~40 分钟 |

**反馈机制是关键**：在 commit 步施加同等平均强度的常量 steering 只能产生小得多的偏移，且 corrupt 输出量近 3 倍。每例独立设定的常量强度仍远逊于 PI 控制。

## 局限性

- 需要访问内部激活（white-box），对纯 API 服务的 dLLM 不适用。
- 攻击针对特定答案分布，对开放式生成任务影响有限。
- 实验模型集中于 LLaDA-8B-Instruct，其他 dLLM 系列可推广性待验证。

## 启示

- dLLM 的去噪过程是一条新的控制通道。
- 呼吁"服务栈级"（serving stack）偏见审计，而非仅审计 frozen 模型。
