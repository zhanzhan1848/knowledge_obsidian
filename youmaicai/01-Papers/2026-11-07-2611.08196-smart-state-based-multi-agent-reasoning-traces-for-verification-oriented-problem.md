# SMART: State-based Multi Agent Reasoning Traces for Verification-oriented Problem-Solving

### 核心贡献
1. 提出多智能体框架 SMART，通过捕获问题上下文中各参与实体的隐式状态（state）来获取求解所需的额外知识，而非依赖检索原始文本片段。
2. 提出结构化的 role-based prompt 策略，让多种 LLM 协同把状态知识整理为「多样、互补且对解法关键（solution-salient）」的前提（premises）。
3. 用真实世界已验证的 curated premises 驱动知识引导的解题推理，在 3 个数据集的复杂科学类 claim 上验证性能最多提升 20%；并证明将前提锚定到真实世界知识是必要的，最多带来 5% 的提升。

### 技术方案
**核心思想**: 在有限上下文下，先由多个 LLM 以角色分工的方式抽取问题中实体的隐式状态并组织成互补的前提集合，再以这些前提为知识源进行验证导向（verification-oriented）的解题推理。

| 技术 | 说明 |
|------|------|
| 隐式状态捕获 | 捕获问题上下文中参与实体（entities）的隐式状态，作为补充知识的来源，替代直接检索 |
| 多 LLM + role-based prompt | 使用多种 LLM 并配合结构化的角色分工提示策略，保证视角多样性 |
| Solution-salient premises | 对状态知识做筛选与重组，使其多样、互补且直接服务于求解 |
| 知识引导推理 | 以收集到的 premises 作为知识底座，驱动解题并以验证为导向产出结论 |
| 真实世界 grounding | 前提锚定到真实世界已验证知识；实验表明这一 grounding 是必要的 |

### 实验结果
- **数据集**: 3 个数据集上的复杂科学类 claim（complex scientific claims）；具体数据集名称摘要未说明
- **基线**: 未锚定真实世界知识的变体（作为消融对照）；具体基线模型摘要未说明
- **结果**: 知识引导的解题推理在验证性能上最多提升 20%；将前提 grounding 到真实世界知识最多额外提升 5%

### 局限性
- 仅覆盖复杂科学类 claim 这一类验证型任务，泛化到其他问题域的效果摘要未说明
- 摘要未说明所用 LLM 的具体型号、数量及计算成本
- 相对提升幅度依赖 curated premises 的人工/流程化构建成本，可扩展性摘要未说明

### 关键洞见
> 对于「上下文不足以支撑推理」的问题，最有效的补充知识来源往往不是检索原始文本，而是把问题中实体的隐式状态显式化——因为隐式状态本来就已存在于问题描述中，只是没有被组织成可推理的形式；这也解释了为何真实世界 grounding 能额外贡献 5%：需要补的不是状态本身，而是状态的真实性。
