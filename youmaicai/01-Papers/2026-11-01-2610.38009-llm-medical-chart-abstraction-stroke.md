# Large Language Models for Accurate Medical Chart Abstraction: Enabling Scalable and Secure Artificial Intelligence Deployment in Stroke

## 摘要
本文在三家医院的 **2,416** 份神经介入急性卒中取栓（thrombectomy）自由文本报告上，系统评估基于 prompt 的 LLM 病历结构化抽取框架，从报告中提取 **8 个**临床变量（颈动脉支架、颈动脉成形、颅内支架、颅内成形、IV 溶栓、TICI 术后分级、NIHSS、闭塞部位）。作者评估了 **22 个**开源 instruction-tuned LLM（LLaMA、Qwen、Gemma、Phi、Mistral、HuatuoGPT、OpenBioLLM 等），采用 Quick Response 与 Chain-of-Thought (CoT) 两种 prompting，并与非专家标注人员及医学专家仲裁对比。结果：**LLaMA3.3-70B 取得最高整体准确率 94.8%**；CoT 显著提升需上下文推断的变量（闭塞部位），而 Quick Response 对直接陈述的操作字段最优。专家仲裁显示 LLaMA3.3-70B (CoT) 在 **8 个变量中的 7 个**优于非专家标注人员（仅颅内成形例外），准确率与初级医学生相当。所有模型均通过 **Ollama 在机构防火墙内的 Nvidia L40s GPU 上本地部署**，无 PHI 外传。

## 核心贡献
1. **多机构真实数据 benchmark**：2,416 份报告 / 3 家医院 / 8 个临床变量，涵盖推断型与直接陈述型两类抽取任务。
2. **22 个开源 LLM × 2 种 prompting 的系统扫描**：按架构、参数规模、生物医学适配三个维度分层比较，量化"模型规模 vs 准确率 vs 延迟"的三角权衡。
3. **专家仲裁的人机对照**：以加权多数投票（按临床经验赋权）裁决 AI 与非专家分歧，量化"AI 优于非专家、持平初级医学生"这一结论。
4. **本地安全部署方案**：全部模型本地推理（Ollama + Nvidia L40s），满足 HIPAA 与机构防火墙约束。

## 方法与架构
**队列与流程**：2015-07-17 至 2024-12-11 期间从三家 Brown University Health 附属医院筛出 **3,624** 例连续急性卒中病例；纳入标准为成人（≥18 岁）行头颈 CTA 后接受血管内取栓（疑似或确诊 LVO）；排除无有效 MRN 或报告缺失者，剩余 **2,416** 份报告用于验证。IRB 编号 2226291-11，豁免知情同意，全部报告去标识化、无 PHI 外传。

**8 个临床变量**的选择标准：(1) 跨机构记录一致；(2) 与标准化临床指标相关。刻意排除的候选变量包括时间指标（穿刺至再通时间）、取栓次数、药物剂量、设备名——因报告格式不一致且常记录在结构化 EMR 字段而非自由文本中。

**Prompting 框架（两种策略）**：
- **Quick Response**：把每个目标变量框架成离散多选题，预设答案选项（如 Yes/No/Unknown 三分类），给出完整报告作为 context，只输出答案索引（0、1 或 None），不显式推理。
- **Chain-of-Thought (CoT)**：相同问答结构，但显式指示模型先识别相关信息、应用临床逻辑、解释决策，再给出最终输出。旨在提升可解释性与对上下文依赖/表述含糊变量的表现。

**评测参考标准的处理（关键方法学设计）**：非专家标注（registry coordinator / data abstractor，经医师培训并在 faculty 监督下工作）作为跨模型参考标准。由于非专家标注时还会参考报告之外的结构化临床表，文本与标签存在两类双向缺失：(1) 有标签但报告中无相关信息；(2) 报告中有可抽取信息但标签表无标注。作者用 **LLaMA3.3-70B (CoT) 的预测作为 surrogate reference**，只保留"最强模型给出有效预测且存在对应参考标签"的 report–variable 对进入其他模型的评测，以减少文本–标签不一致带来的偏倚。

**专家仲裁**：对 AI 与非专家标注不一致的案例，每个变量随机抽 **20 例**；评审小组为 2 名资深卒中医师 + 4 名医学生，采用**加权多数投票**：每位资深医师 0.7、四年级医学生 0.2?——按原文为 0.7（两名资深卒中医师）、0.4（四年级学生）、0.2（二年级学生）、0.1（两名一年级学生）。使用经验证的 web 平台 [25]，去标识化报告 + 结构化多选题。

**统计指标**：Accuracy（预测标签须与参考值完全一致才判对）、Sensitivity、Specificity、Precision、F1、95% 置信区间；专家一致性用 Cohen's κ。

**部署**：所有 LLM（含 LLaMA3.3-70B）经 **Ollama** 在机构 AI 计算服务器内、**每个模型独立占用一张 Nvidia L40s GPU** 部署，位于机构防火墙内以保护数据与计算；采用量化或 FP16 精度。

**模型清单（7 大架构家族、22 个模型）**：LLaMA 系列（3B–70B，以 LLaMA3.3-70B 为参考基线）、Mistral-small3.1-24B、Gemma 3（4B/12B/27B）、Phi-4-14B、Qwen（3B/7B/32B/72B，另有推理优化的 Qwen-Q-32B）、HuatuoGPT-o1-8B（LLaMA3.1-8B 底座）与 HuatuoGPT-o1-7B（Qwen2.5-7B 底座）、OpenBioLLM（LLaMA3.1-8B 底座）、MedGemma3（4B/27B）。规模分组：Tiny (<7B)、Small (7–12B)、Medium (12–30B)、Large (≥30B)。

## 实验设置
- **数据**：2,416 份神经介入卒中手术报告（男 1194 / 49.42%，女 1222 / 50.58%；年龄 ≤65 岁 804 / 33.28%，65–80 岁 816 / 33.77%，≥80 岁 796 / 32.95%）。
- **变量分布**：颈动脉支架 No 2180 / Yes 199 / N/A 37；颈动脉成形 No 2194 / Yes 187 / N/A 35；颅内支架 No 2144 / Yes 73 / N/A 199；颅内成形 No 2181 / Yes 43 / N/A 192；IV 溶栓 No 1543 / Yes 868。
- **对照**：非专家标注（参考标准）、非专家 vs 专家的一致性、专家间一致性热图。
- **硬件**：Nvidia L40s GPU（每模型独立一张）+ Ollama。

## 实验结果
**整体最佳**：LLaMA3.3-70B 整体准确率 **94.8%**（CoT）。

**Prompting 策略**：CoT 在需上下文推断的变量上更优（如闭塞部位）；程序性变量两种策略均高——颈动脉支架、颈动脉成形、颅内支架、颅内成形、IV tPA 的准确率 > 0.94，正确预测比率一致 > 0.95；NIHSS 与闭塞部位准确率较低（0.85–0.87），null/incorrect 比例更高。

**规模效应（Large 组）**：LLaMA3.3-70B 接近天花板——颈动脉支架 0.991、TICI post 0.915、IV tPA 0.955、NIHSS 0.873；Qwen2.5-72B、Qwen3-30B、Qwen-Q 两种策略下通常 > 0.90。Medium 组 Gemma3-27B 与 MedGemma3-27B 强（颅内支架 0.975–0.987；IV tPA 0.955）。Tiny 组（Gemma3-4B、Qwen2.5-3B）在 TICI post、闭塞部位、NIHSS 上常 < 0.70。

**CoT 增益示例**：Qwen3-8B 在闭塞部位上 0.837 → 0.853；HuatuoGPT-o1-8B 在 NIHSS 上 0.616 → 0.747；Gemma3-4B 提升 0.13、Gemma3-27B 提升 0.03。

**延迟-准确率权衡**：

| Prompting | 模型 | 准确率 | 延迟 |
|---|---|---|---|
| Quick | LLaMA3.3-70B、Qwen2.5-72B | 0.938–0.948 | < 10s |
| Quick | Qwen3-30B、Qwen-Q | 高 | ~45–60s（内建推理范式） |
| Quick | MedGemma3-27B、Gemma3-27B、Mistral-Small3.1-24B | ≥ 0.90 | 10–45s |
| Quick | Qwen3-8B、HuatuoGPT-o1-8B | > 0.89 | < 10s |
| Quick | OpenBio-LLaMA3-8B、Phi-4 Mini:8B | ≤ 0.60 | 快 |
| CoT | Qwen3-30B、Mistral-Small3.1-24B、LLaMA3.3-70B | 0.948–0.949 | 接近 190s |
| CoT | Qwen2.5-72B、MedGemma3-27B | > 0.92 | > 130s |
| CoT | Phi-4-14B、Gemma3-12B | 0.91–0.93 | 17–52s |
| CoT | LLaMA3.2-3B、Qwen2.5-3B | < 0.85 | 16–29s（最快） |

**AI vs 非专家（专家共识为 ground truth）**：AI 在绝大多数变量上占优——IV tPA **AI 1.00 vs staff 0.00**；NIHSS **AI 0.95 vs staff 0.05**；TICI Post **AI 0.90 vs staff 0.05**；颈动脉支架 **AI 0.80 vs staff 0.20**；颈动脉成形 **AI 0.70 vs staff 0.30**；颅内支架两者持平 0.50；**颅内成形是唯一例外——staff 0.95 vs AI 0.05**。

**评审者准确率**：资深医师与高年级医学生各变量 ≥ 0.95（IV TPA、NIHSS 上为 1.00）；颈动脉支架上低年级学生降至 0.65；颅内成形上从医师 0.95 到低年级学生 0.50。

**Cohen's κ 一致性**：结构化变量（IV TPA、TICI Post、NIHSS）上所有评审者（含低年级）与 AI 的 κ ≥ 0.82，而与非专家的 κ 低或为零（NIHSS = 0.06，IV TPA = 0）；闭塞部位与 AI 为 0.62–0.75、与 staff 差；颈动脉 PTA 与 AI 仅约 0.30–0.60，与 staff 甚至为负（Student B = −0.48）；颅内成形上 AI 与所有评审者 κ = 0，而 staff 与评审者可达 1.00。

**领域适配收益不均**：生物医学微调模型（HuatuoGPT、OpenBioLLM、MedGemma3）普遍优于对应通用模型，但 OpenBioLLM 提升有限。

## 关键公式与代码
论文无数学公式；核心方法学"公式"是专家仲裁的加权多数投票权重：

```text
vote weight:  senior stroke physician = 0.7
               4th-year medical student = 0.4
               2nd-year medical student = 0.2
               1st-year medical student = 0.1
consensus label = argmax_c  sum_r (w_r * 1[vote_r == c])
```

## 局限性
- 作者自述：① 参考标准主要依赖非专家标注，可能引入标签变异；② 用最强模型作为 surrogate filter 会引入**选择偏倚**（评测子集被对齐到参考模型的行为）；③ 专家仲裁只针对 AI-非专家分歧样本（每变量 20 例），子集不代表全体分布；④ 单一医疗系统内评测，报告模板/术语惯例跨机构可能不同，外部泛化受限；⑤ 未尝试 retrieval-augmented 或 few-shot 等其他 prompting 策略；⑥ 某些 reasoning-tuned 模型（Qwen-Q、Qwen3-30B）即使在 Quick prompt 下也生成冗长推理链，增加延迟与 token 消耗。
- 我的批判性意见：**surrogate filter 用 LLaMA3.3-70B 过滤评测集、再宣称 LLaMA3.3-70B 最优，存在循环论证风险**——它可能在"自己最擅长的样本"上被评判。作者虽承认选择偏倚但未做无过滤的敏感性分析。此外"击败非专家"的结论仅在**分歧子集**上成立（这是最难的一批案例），实际全量部署中 AI 与非专家的差距可能远小于 0.95 vs 0.05 这样戏剧性的数字；颅内成形 0.05 vs 0.95 的失败恰好说明术语异质性是系统性风险而非个别现象。

## 评估与建议
- 是否推荐深入阅读：**是**（临床 NLP / 本地部署 / 人机对照评测设计的优质范例）
- 适用场景：医疗病历结构化抽取流水线选型；私有化部署的 LLM 选型与延迟预算；研究"AI 替代低资历标注者"的混合工作流设计
- 与知识库的关联：与 instruction following、structured output、CoT prompting、domain-adapted model 主题相关；也适合作为"LLM 评测方法学（surrogate filter、专家仲裁、kappa 分析）"的案例收录
