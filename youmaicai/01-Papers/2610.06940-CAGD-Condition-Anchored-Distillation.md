# Stabilizing Language Models under Continual Learning via Condition-Anchored Distillation (CAGD)

## 核心贡献

1. **CAGD 框架**：在持续学习中通过"条件锚定"（condition-anchored）的生成式蒸馏稳定语言模型。
2. **三角色分离**：将传统 replay 混杂的三件事清晰拆开：
   - **Conditions**：选择要保护的行为。
   - **Teacher generations**：定位相关状态。
   - **Soft targets**：规定预测可如何变化。
3. **跨目标统一**：在 AR 与 masked-diffusion 两种语言生成目标下均适用，给出 chain-rule 精确分解。

## 模型架构 / 方法

- **保留少量旧 prompt**。
- **冻结前一个模型作为 teacher**，用它重建 completions 与 generation states。
- **匹配 teacher 的预测分布**（soft targets）同时学习新任务。
- **AR 情形**：teacher-rollout 蒸馏得到精确的 sequence divergence chain-rule。
- **Masked diffusion 情形**：直接控制 teacher-generated completions 上的局部去噪漂移（local denoising drift）。

## 实验结果

| 设置 | 指标 | 数值 |
|------|------|------|
| 219M masked diffusion LM, 4-task 顺序 A | 最终 held-out loss | 2.927 → **1.114** |
| 同上，逆序 | 最终 held-out loss | 2.168 → **0.891** |
| 与 hard replay（同 teacher support） | 最终平均 loss 改善 | **-0.055** |
| 新事实 + 自然指令（SMDM, Qwen3） | 方向 | 一致保持 |
| Qwen, GSM8K | 答案格式合规 | 保留 |
| Qwen, GSM8K | exact-match 保留 | 0.6B 参差不齐，1.7B 恶化 |

## 局限性

- 在大模型（如 1.7B Qwen）上 exact-match 保留变差，规模化能力受限。
- 仍然需要保留旧 prompt 集合（小但非零存储开销）。
- 没有与基于参数正则化（如 EWC）的方法在大规模对比。
