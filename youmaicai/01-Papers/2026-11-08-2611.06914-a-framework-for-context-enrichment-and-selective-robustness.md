# A Framework for Context Enrichment and Selective Robustness in LLM Social Agents

> **arXiv**: [2611.06914](https://arxiv.org/abs/2611.06914)
> **发表日期**: 2026-11-04
> **分类**: cs.LG (交叉: cs.MA, cs.CL)
> **会议/期刊**: SocialAgent Workshop @ NeurIPS 2026 (12 pages, 1 figure, 2 tables)

## 📋 摘要

研究者将 LLM 作为 agent 用于社会模拟，agent 会被提示以观察（observations）与背景信息以塑造其行动。然而已有研究表明 LLM agent 在**语义保持**（meaning-preserving）的提示变体下行为会显著改变，从而给社会模拟带来验证难题。一个合理假设是，这种脆弱性源于**缺乏 grounding**，可以通过丰富 agent 上下文来缓解；但"更丰富的上下文是否提升稳健性"仍不清楚，部分原因是**上下文丰富度与稳健性很少以支持受控比较的方式被定义**。本文以**受控上下文丰富（controlled context enrichment）**回应第一个需求——一组系统地丰富不同类型上下文的提示替换规则：**中性填充（neutral padding）、通用社会背景（generic social background）、描述性决策 grounding（descriptive decision grounding）、规范性决策 grounding（normative decision grounding）**。再以 **selective robustness（选择性稳健）** 回应第二个需求，将其定义为一种验证准则：对语义保持的提示变体**不敏感**，同时对社会中与决策相关的变化具有**方向性响应**（directional response）。作者在一个类囚徒困境（Prisoner's Dilemma-like）博弈中演示该框架，展示如何识别哪些上下文丰富形式产生更可取、更稳健的 agent 行为；发现不同丰富形式产生**不同的行为模式**，且在所测试的两个模型之间存在差异。

## 🎯 核心贡献

1. 提出 **controlled context enrichment** 方法论：一组提示替换规则，系统化地沿四个维度丰富上下文——中性填充、通用社会背景、描述性决策 grounding、规范性决策 grounding。
2. 提出 **selective robustness（选择性稳健）** 作为验证准则，突破"稳健=对一切不变"的旧定义：

```math
\text{Selective Robustness} = \underbrace{\big|f(c) - f(c')\big| \approx 0}_{\text{对语义保持变体不敏感}}
\;+\;
\underbrace{\mathrm{sign}\big(f(c) - f(c'')\big) = \varepsilon}_{\text{对决策相关变化方向性响应}},\quad c' \equiv c,\ c'' \not\equiv c
```

3. 明确指出此前文献的**方法论缺口**：上下文丰富度与稳健性缺少可支撑受控比较的定义。
4. 在类囚徒困境博弈中做实证演示，并给出**可操作的判别流程**：用该框架识别哪些上下文丰富形式产生更可取、更稳健的 agent 行为。
5. 关键观察：四种丰富形式产生**互不相同的行为模式**，且**因模型而异**——不存在普适最优的丰富策略。

## 🔧 方法/架构

- **受控上下文丰富（controlled context enrichment）**：以"提示替换规则"形式定义四种丰富类型，保持被测语义不变（对受控变量做单一维度替换）：
  1. **Neutral padding（中性填充）**：加入语义中性的填充文本，作为"丰富度"对照基线（控制长度效应）。
  2. **Generic social background（通用社会背景）**：加入泛化的社会情境描述。
  3. **Descriptive decision grounding（描述性 grounding）**：加入描述性事实，锚定决策依据。
  4. **Normative decision grounding（规范性 grounding）**：加入规范性/价值取向指引。
- **选择性稳健评估**：双轴检验——(a) 对**保义**改写的不变性；(b) 对**决策相关**世界变化的方向性敏感度。两者需同时满足，避免"把 agent 变笨以求稳健"的退化解。
- **实验载体**：类囚徒困境博弈（Prisoner's Dilemma-like game），产出 1 figure + 2 tables 的行为对比。
- **模型对比**：在两个受测模型上运行，观察丰富形式与模型的交互效应。

## 📊 实验结果

- **类囚徒困境博弈**：四种上下文丰富形式产生**显著不同的行为模式**；不同丰富形式在"可取性"与"稳健性"上的表现不等价。
- **跨模型差异**：行为模式在**两个受测模型之间存在差异**——丰富策略不具模型通用性。
- 摘要未披露具体数值（详见原文实验章节）；涉及基准为 Prisoner's Dilemma-like game，测试模型为两个 LLM（具体型号见原文）。

## ⚠️ 局限性

- 实验仅在**类囚徒困境博弈**这一极简社会场景中验证，推广到更复杂社会模拟（多轮、长期、真实人群）未证。
- 仅测试**两个模型**，摘要未给出型号；结论"行为模式因模型而异"意味着方法结论本身不稳定。
- "受控上下文丰富"的"受控"依赖提示替换规则的严谨性，实际操作中难以完全隔离变量。
- 工作坊论文（12 页，1 图 2 表），实验规模小、无显著性检验的证据。
- 未给出定量鲁棒性指标的定义细节与阈值，方法可复现性依赖原文。
