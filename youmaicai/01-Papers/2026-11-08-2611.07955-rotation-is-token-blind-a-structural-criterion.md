# Rotation Is Token-Blind: A Structural Criterion for Post-Training Quantization of Feed-Forward Geometry Transformers

> **arXiv**: [2611.07955](https://arxiv.org/abs/2611.07955)
> **发表日期**: 2026-11-05
> **分类**: cs.CV
> **会议/期刊**: arXiv preprint

## 📋 摘要

前馈式（feed-forward）3D 模型使用 Transformer 一次性预测相机位姿、深度与结构，避免了迭代式多视图优化。长序列与深层注意力带来高计算与显存开销，促成了对**训练后量化（PTQ）**的部署需求。现有 PTQ 方法主要通过平滑（smoothing）或正交旋转（orthogonal rotation）抑制逐通道离群值。Geometry Transformer 引入了一个不同的挑战：**异质的 token 类型共享同一套激活量化网格（quantization grid）**；少数特殊 token 可能对全局输出具有高杠杆（high leverage），且只被部分模块更新。作者提出 **QMapAnything**，一个结构感知的 PTQ 框架。他们把**保浮点的旋转与平滑**刻画为一个 **token-blind 重参数化群（token-blind reparameterization group）**，并证明它们只带来**共模增益（common-mode gains）**，而不改变**相对 token SNR**。作者进一步引入统计量 $\Gamma$，结合某特殊 token 的**量化劣势（quantization disadvantage）**与**输出杠杆（output leverage）**，用以预测在旋转之外是否**还需要差异化的偏差校正（differentiated bias correction）**。在几何基准上的实验表明 **W4A8** 接近全精度性能；在 **W8A8** 下，相比 FP32 峰值显存下降 **2.2–3.1 倍**，真实硬件上最高 **3.1 倍**加速。

## 🎯 核心贡献

1. **结构性判据（structural criterion）**：证明现有的保浮点旋转/平滑属于"token-blind 重参数化群"，**只能带来共模增益，无法改变 token 之间的相对 SNR**——由此解释了为何旋转在 Geometry Transformer 上不够用（论文标题即结论："Rotation Is Token-Blind"）。
2. **统计量 $\Gamma$**：把某特殊 token 的**量化劣势**与**输出杠杆**结合成一个可计算量，用以**预测**是否需要在旋转之外施加差异化偏差校正——把何时需要额外校正从试错变成可判定的先验条件。
3. **QMapAnything 框架**：结构感知的 PTQ，按 token 类型分层处理量化误差，而非全局统一处理。
4. **部署收益量化**：W4A8 接近全精度；W8A8 相比 FP32 峰值显存降 **2.2–3.1 倍**，真实硬件最高 **3.1 倍**加速。

## 🔧 方法/架构

- **问题设定**：Geometry Transformer 中**异质 token 类型**（如普通 patch token 与少量特殊 token）共享一个激活量化网格；少数特殊 token 对全局输出有高杠杆，但只被部分 block 更新。
- **理论刻画**：
  - 定义 **token-blind 重参数化群** $G_{\text{blind}}$：保浮点的旋转（rotation）与平滑（smoothing）属于该群。
  - 证明结论：该群内的变换只产生**共模增益（common-mode gain）**，**相对 token SNR 保持不变（relative token SNR unchanged）**——即 token 之间的量化差异被保留而非消除。
  - 因此需要 token-aware 的补充机制。
- **判据统计量**：

```math
\Gamma = f(\text{quantization disadvantage of token},\ \text{output leverage of token})
```

  $\Gamma$ 用于判断该 token 是否需要**差异化偏差校正（differentiated bias correction）**。

- **框架组件**：
  1. 保浮点旋转/平滑（token-blind，共模增益）；
  2. 基于 $\Gamma$ 的**差异化偏差校正**（token-aware，仅对高 $\Gamma$ 的特殊 token 施加）。

## 📊 实验结果

- **W4A8**：在几何基准上**接近全精度性能**。
- **W8A8 相比 FP32**：
  - 峰值显存下降 **2.2–3.1 倍**；
  - 真实硬件上最高 **3.1 倍加速**。
- **理论结论**：token-blind 变换（旋转/平滑）→ 共模增益，相对 token SNR 不变；$\Gamma$ 预测是否需要额外差异化偏差校正。

## ⚠️ 局限性

- **依赖"异质 token 类型共享量化网格"这一前提**：若模型已按 token 类型使用独立的量化 scale（如分组/逐 token 量化），本文的核心问题设定不再成立，方法价值需重新评估。
- 理论证明限定在"保浮点重参数化"这一类变换族，对其他 PTQ 家族（如 GPTQ/AWQ 的误差补偿、activation-aware scaling）的作用未讨论。
- 摘要未给出具体几何基准名称（深度估计、位姿估计、3D 重建等）、绝对指标数值，以及"接近全精度"的具体差距幅度。
- $\Gamma$ 的计算需要 token 的输出杠杆估计（类似梯度/激活统计），这部分**校准开销**未在摘要中说明；此外其阈值/超参选择方式也未交代。
- W4A8 表现好于 W8A8 的排序略反直觉（更激进的位宽反而"接近全精度"），摘要表述可能混合了不同实验设置，需查原文确认。
- 前馈式 3D 模型的加速收益依赖具体硬件与实现（真实 kernel 支持），迁移到其他架构不一定成立。

## 💡 建议

- 是否推荐使用：**有条件推荐**
- 适用场景：需要在**边缘设备**上部署前馈式 3D 重建 / 位姿-深度-结构联合预测模型的团队；建议做法是先用本文的 token-blind vs token-aware 视角**诊断**你的模型是否真的受"异质 token 共享量化网格"困扰（若量化已按 token 类型分组，则本文收益有限），再引入 $\Gamma$ 做选择性偏差校正。同时可参考 W8A8 的显存/加速数据作为部署预算规划参考。
