## 重点论文（12 篇）

### 1. **Enhancing Legal Reasoning in Pre-trained Language Models via Knowledge Graph-Guided Multi-Task Pre-training** (2610.13722)
- NSP + KG-Guided Clustering + KG-Aware Paragraph Classification 三任务联合预训练。
- 9 个 Transformer encoder × 324 runs；StVO synthetic QA **+10.3% ~ +155.0%**；LexGLUE **4/7 超 prior SOTA**。
- Austrian 零样本迁移 **+3.4% ~ +15.8%**。
- 详见 [[2610.13722-KG-Guided-Multi-Task-Legal-Pretraining]]

### 2. **UPTURN: Inject a Turn, Not a Token** (2610.13672)
- 130K-参数 MLP head 定位 failed rollout 干预位置，以 **new user turn** 而非 inline token 注入。
- 跨 4 reasoner × 6 math benchmark；GPQA-Diamond 无重训练迁移。
- 详见 [[2610.13672-UPTURN-Learned-Position-Redirect]]

### 3. **Host-Aware Web Crawling for LLM Pretraining Data** (2610.13321)
- 系统研究 crawl budget：跨 host（centrality vs random）+ host 内（probe-and-extend）。
- ~50% quality 变异来源于 host 之间；probe-and-extend 高质量页/fetch **数倍**提升。
- Common Crawl harmonic centrality 在他们模拟下增益**有限甚至更差**。
- 详见 [[2610.13321-Host-Aware-Web-Crawling-Pretraining]]

### 4. **SmartSalesBench: Resistance-Aware Multi-Turn Sales Agent Benchmark** (2610.12975)
- 5 agent × 12 persona × 15 product × 4 experiment × 3 iter = **13,680 sessions**。
- buyer 主动抵抗（最多 20 轮）；RAG-grounded generation。
- LLM-judge 与 human 高度一致（κ=0.71, r=0.81）。
- 详见 [[2610.12975-SmartSalesBench-Multi-Turn-Sales-Agents]]

### 5. **ChemDiffAgent: Masked Diffusion Language Agents for Chemical Reasoning** (2610.13330)
- 首个 **masked diffusion** language agent；interleaved reasoning + tool-use 轨迹的迭代去噪。
- 打破 AR 的 causal attention + left-to-right 限制 → 全局分子理解。
- Two-stage post-training: agentic SFT + agentic RL。
- 详见 [[2610.13330-ChemDiffAgent-Masked-Diffusion-Chemical]]

### 6. **Multi-Agent LLM System for Automated Tuning of Specialized NN Models** (2610.13663)
- analyst / coder / recorder 三角色；只调"组件"不改整体架构。
- 5/5 task 超 baseline；跨 SNN + PINN transferable。
- 详见 [[2610.13663-Multi-Agent-LLM-NN-Tuning]]

### 7. **Towards the Roof of the World: NLP Progress in Tibetan Languages** (2610.13398)
- 140 篇 Tibetan NLP bibliometric survey（2004-2026）。
- 84% 自 2018 后；中国作者 87%；全 pipeline corpus → LLM。
- 提出 Global South 低资源 NLP 范式。
- 详见 [[2610.13398-Tibetan-NLP-Survey]]

### 8. **KnowForge: Locate, Judge, Read — Role-Specialized Tool Agents** (2610.13128)
- 严格 job 分工：Locator-only-search / Judge-bridge / Reader-only-read。
- M3DocVQA F1 **47.5**（+11.0 vs M3DocRAG）；MultiHop-RAG **73.5**。
- MMLongBench-Doc 同模型 **34.8 → 47.0**（≈ GPT-4o reading page 46.3）。
- 详见 [[2610.13128-KnowForge-Role-Specialized-Tool-Agents]]

### 9. **HOA: Humanize Olympiad Agents** (2610.13632)
- 三通道反馈：独立 reviewer + 结构化 wiki + Lean verifier。
- GPT-5.6 Sol 上 **IMO / IPhO / IOI 2026 满分**；672 problems 全解。
- 模型 + 推理栈全公开（区别 Navier-Stokes / Erdős 系统）。
- 详见 [[2610.13632-HOA-Humanize-Olympiad-Agents]]

### 10. **RTI: Rollout-Time Intervention for Agentic RL** (2610.13438)
- Rollout 时用 evaluation rubrics 把错误轨迹转成功 → 突破 on-policy bottleneck。
- 过滤掉 dist-shift 过大的干预轨迹；5 benchmark 一致超 RL baseline。
- Post-trained policy 接近**显著更强** model 的水平。
- 详见 [[2610.13438-RTI-Rollout-Time-Intervention-RL]]

### 11. **DREAM: Neuro-Inspired Memory Repair for Poisoned LLM Agents** (2610.13267)
- 神经科学"弱重激活诱发遗忘"启发；training-free。
- 三阶段：perturbation reactivation → anomaly diagnosis → dynamic repair。
- Backdoor poisoning **ASR -95%+**，保留 benign 性能。
- 详见 [[2610.13267-DREAM-Memory-Repair-Poisoned-Agents]]

### 12. **DRYLAB-Bench: Biosecurity Risk of Agentic LLM Mutation Design** (2610.13116)

## 关键洞察

1. **Agent 训练信号工程化**: RTI 用 rubric 干预 rollout + UPTURN 用 130K head 定位干预位置 + DREAM 用 neuroscience 启发的遗忘机制 —— 三条不同路线都在解决"agent 在 capability boundary 之外学习"。
2. **严格 job 分工胜过统一 agent**: KnowForge 5 组件分工 > single agent 多工具；HOA 多 session + 反馈通道 > 单 session；ChemDiffAgent 全轨迹联合决策 > AR 单向生成。
3. **安全与 dual-use 评估从"知识"转向"实际行为"**: DRYLAB-Bench 评估 agent 真实 mutation 设计能力，DREAM 评估 memory 修复实战效果 —— 安全研究正在贴近真实部署威胁模型。
4. **Pretraining 数据策略被重新审视**: Host-Aware Crawl 显示 probe-and-extend 数倍高效；KG-Guided Legal Pretraining 显示结构知识应注入 objective 而非 inference-time graph；Tibetan Survey 提示 Global South 语言的全 pipeline 范式。
5. **多 session / 多 agent flow 成为长程任务标配**: HOA 与 Multi-Agent NN-Tuning 都验证 multi-session / multi-role 优于 single-session —— 这与 10-12 那批 (APEX-Harm, User-Sim) 形成连贯趋势。
