# Imprinting: Knowledge Distillation Can Shift Student Behavior

## 元信息

| 字段 | 内容 |
|------|------|
| **标题** | Imprinting: Knowledge Distillation Can Shift Student Behavior |
| **作者** | Yu-Chien Tang, An-Zi Yen |
| **发表** | arXiv preprint 2026-10-13 |
| **arXiv** | 2610.18517 |

---

## 核心贡献

> 知识蒸馏 *不仅* 传递任务能力，还会 *无意中* 传递教师的安全 / 行为倾向（"imprinting"），即使监督内容与安全无关。

1. **同 base 教师的两版本**：harm-accepting vs harm-avoiding（除安全姿态外相同）
2. **普通 reasoning / 知识问答数据** 蒸馏：学生继承教师的安全倾向
3. **Imprinting 强度因 teacher-student pair 而异**：不跨 safety 行为形式统一传递
4. **Post-distillation preference optimization**：提升 harm avoidance 但 *不消除* source-dependent difference
5. **Rewriting 的两面性**：保留 source-dependent effect + 引入 rewriter-dependent shifts

---

## 技术方案

### 核心思想

传统 KD 假设教师传递的是"任务能力"。本文揭示：教师在 *普通任务* 上的回答也会携带其安全姿态。学生用这些回答做 KD 后，自身 harm-pragmatism 会向教师偏移——称之为 *imprinting*。

- **若教师 harm-accepting** → 学生 harm avoidance 下降
- **若教师 harm-avoiding** → 学生 harm avoidance 上升

关键是：用于 KD 的 prompts 完全 *不涉及安全*。

### 关键技术

| 技术 | 说明 |
|------|------|
| 教师同 base 双版本 | 仅安全姿态不同 |
| Source-dependent imprinting | 学生跟随教师安全态度 |
| Sparse divergence tokens | 排除少量分歧 token 可削弱 imprinting |
| Response rewriting | 既保留 original 又引入 rewriter bias |
| Post-distillation preference optimization | 提升但 *不消除* source gap |

---

## 公式

设教师 $T_h$ (harm-accepting) 与 $T_s$ (harm-avoiding)，共享 base。学生 $S_b$ 用普通任务数据 $D_{\text{neutral}}$ 蒸馏：

```math
\mathcal{L}_{\text{KD}}(S_b \mid T) = -\mathbb{E}_{x \sim D_{\text{neutral}}} \bigl[ \log p_{S_b}(y_T) \bigr]
```

Imprinting effect：

```math
\Delta_{\text{imprint}} = \text{SA}(S_b \mid T_h) - \text{SA}(S_b \mid T_s) \ne 0
```

其中 $\text{SA}$ 是 student 的 safety attitude score（与蒸馏任务无关）。

---

## 实验结论

- **学生 base models 不一致**：imprinting 强度因 pair 而异
- **跨 safety 行为形式**：不统一传递（不同 safety 维度可能被分离）
- **Sparse divergence tokens**：排除后 imprinting 减弱
- **Rewriting**：保留 source effect + 引入 rewriter shift
- **Post-DPO**：harm avoidance 上升但 source gap 仍在

---

## 局限性

- 仅在普通 reasoning / knowledge QA 上验证（agent / 多模态等未覆盖）
- Harm-accepting 教师模型构建方式可能影响 imprinting 强度
- "Sparse divergence tokens" 的自动识别方法未深入
- 没看到 mechanism-level 解释（哪部分权重承载 imprinting）
