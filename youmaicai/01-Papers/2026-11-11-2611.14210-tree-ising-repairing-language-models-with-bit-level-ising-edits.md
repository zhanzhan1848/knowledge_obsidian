## 核心要点
1. 把权重修复表述为**稀疏离散优化**：前向统计定义目标（削弱循环方向、增强结论方向、保留该层在生产性 token 上的输出）。
2. state-tree 表示下，可容许编辑是**符号翻转与指数偏移**（保留共享组指数与尾数，**无损 BF16 存储是特例**）。
3. 目标**精确分解为逐输出行的独立 QUBO（Ising）问题**，用 GPU 上的模拟退火或量子启发的模拟分岔求解。
4. **零 LLM token、仅 4 次前向请求**，退火配方 GPU 成本约 **$0.90**。
5. 在 agent 修的两层上达 MATH-500 **54.6%**，超过该 agent 的编辑（51.7%）；模拟分岔求解器达 **55.1%**；两者在全部五个数学基准上均超过 agent 编辑（MATH-500 与 GSM8K 经多重比较校正后显著）。
6. **改动权重少 13%–17%，BF16 位翻转减少 2.2–2.3 倍**。Qwen3.5-2B 上仅用基座模型选层与剂量，贪心 GSM8K **21.6% → 69.4%**。

## 摘要（原文）
Weight-space programming, introduced in recent MIT work by Takehi et al., enables a frontier LLM
agent to read a network's weights and write a repair. Their GPT-6 Astra agent corrected the
reasoning loops of Qwen3.5-0.8B without gradients, using 158 agent turns, 89.7 million tokens, and
50 forward-pass requests. Our method, Tree-Ising, casts this repair as a sparse discrete
optimization problem over the model's own BF16 weights. Forward statistics define an objective that
weakens a loop direction, strengthens a concluding direction, and preserves the layer's output on
productive tokens. Within a state-tree representation, where lossless BF16 storage acts as a special
case, the admissible edits are sign flips and exponent shifts that preserve all shared group
exponents and mantissas. We decompose this objective exactly into independent QUBO (Ising) problems,
one per output row, which we solve on a GPU using simulated annealing or quantum-inspired simulated
bifurcation. On the agent's two layers, Tree-Ising achieves 54.6% on MATH-500, outperforming the
agent's edit (51.7%) under the same evaluation protocol, while the base model scores 7.9% as
reported. The simulated bifurcation solver yields a statistically indistinguishable repair at 55.1%.
Both solvers outperform the agent edit across all five math benchmarks, with statistically
significant improvements on MATH-500 and GSM8K after correcting for multiple comparisons. Our
approach modifies 13% to 17% fewer weights and reduces BF16 bit flips by a factor of 2.2 to 2.3. It
requires only four forward-pass requests and zero LLM tokens, with the annealing recipe costing
about $0.90 in GPU time. On Qwen3.5-2B, with layers and dose selected using only the base model, the
same recipe increases greedy GSM8K accuracy from 21.6% to 69.4%. As a proof of concept, we execute
an eight-variable repair subproblem using QAOA on an IBM Heron processor.
