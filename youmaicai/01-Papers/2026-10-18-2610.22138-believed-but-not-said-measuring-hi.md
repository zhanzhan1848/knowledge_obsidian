## 核心贡献

> 实证 multi-agent "peer-check" 假设**几乎不成立**：在 10-agent factual discussion 中，**1 个 adversarial agent** 把 benign agents 接受 false answer 的比率从 0.6% 拉到 **44.8%**；**3 个 attackers** 拉到 **60.5%**。**hidden belief collapse**：benign agents 在 51.6% exposed turns 持 false，但 public 仅 19.7% endorse → **多数影响在表面下传播**，peer-visible discussion 看不到。

1. **最小对抗测试**：10-agent factual discussion，1–3 adversarial agents 反复断言 plausible false answer。
2. **关键 metric 区分**：每轮 probe benign agents 的 **private answer**（独立 call，peers 不可见）+ 单独 label **public stance**。
3. **冲击数据**（6 模型 × 3 QA datasets）：
   - 0 attacker → 0.6% false-answer rate
   - **1 attacker → 44.8%**
   - **3 attackers → 60.5%**
4. **Hidden belief collapse**：3 attackers 时 51.6% 持有 false 但仅 19.7% public endorse → **影响在表面下传播**。
5. **关键反发现**：agents **持 true 的常不捍卫**，false 一旦 adopted → 在 benign 间传播；**baseline knowledge 不能预测 robustness**。

## 技术方案

### Setup

```
10 agents in factual discussion
      ↓
Round 1, 2, 3...
   ↓       ↓
Public   Adversarial agents assert false answer
discussion     ↓
   ↓       ↓
Each round probes each benign agent:
  - Private answer (hidden from peers)
  - Public stance (visible in discussion)
```

### Probe 机制

- **Private probe**：独立 call 给 benign agent，response **不进入 discussion**
- **Public stance label**：基于 benign agent 在 discussion 中的发言判断

→ 可**同时**追踪 "private belief" 与 "public performance"

### Variables

- **# attackers**: 0 / 1 / 3
- **Factual QA dataset**: 3 datasets
- **Model**: 6 models
- **Metric**: % benign agents holding false answer

### Attack

- 反复断言 **plausible false answer**（不需精心构造）
- 仅 adversarial agent 知道是 false（真实 attack 假设）

---

## 实验结果

### 关键数据：False Answer Adoption Rate

| # Attackers | % Benign Holding False Answer |
|-------------|-------------------------------|
| 0 | **0.6%** |
| 1 | **44.8%** |
| 3 | **60.5%** |

→ 1 个 adversarial agent 即触发 **74×** 影响放大。

### Hidden Belief Collapse（3 attackers）

| Layer | % Holding/Endorsing False |
|-------|--------------------------|
| Private belief (exposed turns) | **51.6%** |
| Public endorsement (visible) | **19.7%** |

→ **31.9 pp 隐藏** 在表面下 → peer-visible discussion 不能反映真实 belief。

### Robustness 预测器

- ❌ **Baseline knowledge 不能预测 robustness**
- 持 true 的 agents **常不捍卫**
- 一旦 false 被 adopted → 在 benign 间扩散

### Cross-Model / Cross-Dataset

- 6 模型 × 3 datasets 一致显示该模式
- → 系统级问题，非特定模型缺陷

## 局限与展望

- 仅 factual QA → opinion / reasoning / creative task 中是否仍成立？
- 仅 10 agent 规模 → 大规模 multi-agent (100+) 行为未知。
- Plausible false answer 构造 → 实际攻击可能更复杂（adversarial crafted）。
- Private probe **假设 probe 不被讨论参与者察觉** → 实际 multi-agent system 中未必成立。
- 防御机制未在 paper 中提出。

## 实现建议

- **实现难度**: 中（multi-agent simulation + private/public probe）
- **预期性能**: 不可作为 production improvement；提供 **safety 评估工具**
- **适用场景**:
  - **Multi-agent system 风险评估**（发现 hidden vulnerability）
  - 设计 **private belief monitoring** 机制
  - 训练 **anti-conformity** 或 **robust辩论** 模型
- **不适用**: 提升 agent 任务表现（不直接 gain）
- **工程启示**:
  - Multi-agent discussion 必须**加 belief probe** 而非仅看 discussion transcript
  - Adversarial 防御应针对 **hidden belief** 而非仅 public statement
  - 设计 discussion 时 **降低 peer pressure**（如独立 verification round）

---

## 一句话总结

实证 multi-agent "peer-check" 假设在 1 个 adversary 时即崩塌（44.8% false adoption），且**多数影响在表面下传播**（private 51.6% / public 19.7%），peer-visible discussion **不能**反映真实 belief — multi-agent 部署需私有 belief 监控 + 抗 adversarial 设计。
