# StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inference

## 摘要
**量化**降低 LLM 推理的内存与带宽需求，但可能损害准确率；而**卸载更高精度数据**反而可能拖停生成。本文提出 **StrataFlux** —— 一个挑战这一权衡的框架，通过**恢复量化损失的准确率**同时保留量化的内存与速度优势。它**协同设计**精化表示、选择与投递，让**主机 RAM 与 SSD 成为额外精度来源**。其**选择性精度流式传输（selective precision streaming）**减少传输量、与计算**重叠**、并**跨解码步复用**已取回的精度，使生成**无需等待每次传输完成**。评测覆盖 2–4 bit 权重与 2–3 bit KV cache，独立 GPU 与统一内存平台。**2-bit Llama-3.1-8B-Instruct 权重**：WikiText-2 困惑度从 **9.46 降到 8.40**，同时在 RTX 5090 上保持量化基线 **95.4%** 的吞吐。**2-bit 权重 + KV**：Qwen3-8B 的 **AIME 2024/2025 准确率从 11.0% 提到 47.1%**，**GPU 显存占用不变**。

## 核心贡献
1. 提出 **StrataFlux** —— 协同设计**精化表示 / 选择 / 投递**，把主机 RAM 与 SSD 变成**额外精度来源**
2. **选择性精度流式传输**：减少传输量 + 与计算重叠 + **跨解码步复用**已取回的精度（生成不必等每次传输）
3. **2-bit Llama-3.1-8B-Instruct**：WikiText-2 PPL **9.46 → 8.40**，同时保持量化基线 **95.4%** 的吞吐（RTX 5090）
4. **2-bit 权重 + KV**：Qwen3-8B **AIME 2024/2025 从 11.0% → 47.1%**，**GPU 显存不变**
5. 覆盖 2–4 bit 权重、2–3 bit KV，独立 GPU 与统一内存平台

## 方法与架构
**核心思想**：量化省内存但损精度，卸载高精度会停生成 —— 通过**流式投递精度**同时要到两者。

**三组件协同设计**：
1. **精化表示（refinement representation）** —— 组织可按需取回的高精度增量；
2. **选择（selection）** —— 决定哪些部分值得传输；
3. **投递（delivery）** —— **选择性精度流式传输**：
   - 减少传输量；
   - 与计算**重叠**（overlap delivery with computation）；
   - **跨解码步复用**已取回的精度 → **生成不必等待每次传输**。

**精度来源层级**：GPU（HBM）→ 主机 RAM → SSD。

## 局限性
- 依赖**主机 RAM/SSD 的额外容量与带宽**，在无独立主机内存的边缘设备上不适用；
- AIME 提升 11.0% → 47.1% 是**推理任务**上的恢复，对一般生成任务的普适性未验证；
- 选择策略的开销随模型与序列长度变化，摘要未给出完整开销剖面。

## 值得注意的点
**「AIME 11.0% → 47.1% 而显存不变」** 是今日最有冲击力的单一数字 —— 它说明 2-bit 量化的真实代价**不是可接受的精度损失，而是任务能力的大幅塌陷**（推理任务几乎归零）。StrataFlux 的贡献不只是省显存，而是**证明了「量化必然掉能力」这个默认假设有多贵**。这直接改变了对低比特部署的现实判断。
