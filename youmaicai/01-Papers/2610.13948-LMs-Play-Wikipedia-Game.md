## 核心贡献

> 用 Wikipedia Game（目标：从 start page 通过点击链接到 target page）作为评估 LLM 多步规划与搜索能力的试金石。

1. **任务设计**: 多跳规划、每步需选 link 推进
2. **评测 LLM**: 不同模型在该任务上的成功率与策略差异
3. **发现**: LLM 在多步搜索/规划任务上的具体能力边界

---

## 技术方案

### 核心思想

Wikipedia Game 是经典的图搜索任务，考察 LLM 在**多步决策 + 信息检索**组合下的能力。模型需要在每步读当前页面、规划下一步、点击 link，目标是抵达 target page。

### 关键技术

| 技术 | 说明 |
|------|------|
| Wikipedia graph | 节点=page、边=link |
| Multi-step planning | 每步决策 |
| Web grounding | 用真实 Wikipedia API |
| Path length evaluation | 最短路径长度 vs LLM 实际路径 |

### 评估维度

- **成功率**: 在步数限制内到达 target page 的比例
- **路径效率**: LLM 路径 vs 最短路径长度比
- **策略分析**: LLM 选择 link 的策略（语义相似 vs 结构化）

---

## 实验结论

- **任务**: Wikipedia Game（多跳导航）
- **结果**: (见原文具体数字)
  - 现代 LLM 在该任务上呈现能力分层
  - 长路径难度指数上升
  - 失败模式：循环、语义偏离、近邻陷阱

---

## 局限性

- Wikipedia 链接结构与人脑导航策略不同
- 仅评估 Wikipedia graph，未覆盖其他搜索空间
- 缺乏与人类玩家 baseline 的系统比较
