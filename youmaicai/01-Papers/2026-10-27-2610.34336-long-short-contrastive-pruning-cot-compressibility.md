## 核心贡献

> 诊断出「权重剪枝」与「CoT 压缩」两个降本手段的相互干扰来自两侧各一个盲区，并分别修补：**Contrastive Set-Difference (CSD)** 用同一道题的**长解 vs 短解激活对比**找出富集于冗余推理的神经元并优先剪掉，再把偏好对扩展到剪枝模型「总是做对/从不做对」的题上；在 DeepSeek-R1-Distill-Qwen-7B 剪 20% 的设定下，比「RAC 校准剪枝 + 同样压缩」在四个数学 benchmark 上**少用 8–22% 的 thinking token**，而准确率差异在 **0.5 分以内**。

1. **指出两条降本路线的干扰机制** — Lucas et al. (2026) 已观察到剪枝会让 reasoning model 生成**更多** thinking token 且准确率更低；本文进一步把它拆成两类来源：(a) 模型仍能解的题上产生**冗余推理**（dense 模型本就会在简单题上 overthink，被剪枝放大）；(b) 模型不再能解的题上产生**不完整推理**（跑很久仍得不到正确答案）；并且剪枝还会**降低模型后续的可压缩性**（harder 问题上同样的长度偏好优化对剪枝模型缩短得更少）。
2. **定位两侧盲区** — 剪枝侧：RAC / RESP / LayerTrim 都用**模型自身推理轨迹**算重要性，这种分数**无法区分必要推理与冗余推理**，预算因此有一部分花在冗余神经元上；压缩侧：偏好式 CoT 压缩需要**同一模型在同一题上的对比样本**，而剪枝后的模型往往给不出。
3. **CSD：对比式集合差剪枝准则** — 在同一道题的**长正确解与短正确解**上对比神经元激活，用 log-ratio `κ̂_k` 衡量「该神经元在冗余推理上的富集程度」，再做位置匹配（按绝对位置分箱，bin 边界 512/1024/2048/4096/8192）与 jackknife 显著性检验（问题 hash 成 G=20 组），只剪 `z_k > z_0` 且 `κ̂_k > τ` 的候选中 z 最高的那部分。
4. **精确的「集合差」选择规则** — 每层先定义**受保护集合 P**：`Top 30%` 按基础分数 s_k、`Top 1%` 按 closing ratio e_k（`</think>` 前最后一个段落断点到答案末尾的均方 / 全部生成 token 的均方）、`Top 0.1%` 按 massive activation `m_k = max_t|a_{t,k}|`；候选集 `C = {k ∉ P : z_k > z_0, κ̂_k > τ}`；displaced 集 `D = Top_m({z_k})`，`m = min(|C|, ⌊qB⌋)`；最终删除 `D ∪ (D 外分数最低的 B−|D| 个)`。
5. **剪枝感知的偏好对构造（三个来源）** — Self pairs（沿用 TokenSqueeze）、**Dense-anchored pairs**（剪枝模型从不做对但 dense 做对的题：chosen 用 dense 的最短正确解，rejected 用剪枝模型的失败解）、**Length-anchor pairs**（无 self pair 但剪枝模型有 ≥2 个正确解的题：chosen 用其最短正确解，rejected 用长度至少 γ 倍的正确解）。三者共享同一个冗余定义：**超出最短正确解的余量**。
6. **量化结果** — 20% 稀疏度下，CSD+PLPO 相对 RAC-S+PLPO 在 MATH-500 / GSM8K / AIME 上分别少 **11.1% / 21.7% / 9.6%** thinking token，准确率差 **−0.5 / −0.4 / +0.1 分**；MATH-500 上配对几何均值差距达 **14.5%**；在 log 尺度上**追回 RAC-S 相对 dense 模型损失的 compressibility 的 24%**。
7. **剪枝前即已受益** — CSD 在尚未压缩时就把 MATH-500 的平均 thinking 长度从 3,780 降到 **3,671**（−2.9%，几何均值 −4.4%）、GSM8K 从 799 降到 **735**（−8.0%），准确率差 −0.4 分与 0 分；且**同样的压缩 recipe 在 CSD 上缩短得更多**（每个 benchmark 都成立）。
8. **机制分析：CSD 剪掉的不是「词探测器」** — CSD 在 28 层中共 displace **7,719** 个神经元，其中 **6,456** 个本会被 RAC-S 保留（占被剪 121,464 个中的 **5.3%**）；被 displace 的神经元基础分中位百分位为 **46**（四分位 30/59），它们替换的神经元则在 20–23 百分位。审计 z 最大的 224 个被 displace 神经元（每层 8 个）：**53%** 没有任何单一 token 贡献超过四分之一的富集度，**24%** 的前五大贡献者中含 `Wait` 等 reflection marker，只有 **3%** 有一半富集度来自单个稀有 token；富集主要来自**同样 token 上更强的激活**（中位占 **80%**），而非 token 出现频率。
9. **剪枝侧优于恢复侧（pruning-side > training-side）** — 引 ReCal 对照：Qwen3-8B 用 structured Wanda-sp 剪掉 25% FFN 参数后 AIME 均值准确率从 **61.4% 掉到 2.2%**，恢复后 Wanda-sp 只有 **41.7%**、FLAP **29.0%**；改在 dense 模型响应上重校准后，剪枝模型 **25.7%**、恢复后 **48.5%**。而本文的 RAC-S 在训练前就已把 MATH-500 保在 dense 的 3.1 分内、GSM8K 1.9 分内、AIME 保持 **35.5%**（dense 为 49.5%）。
10. **效率账算清楚了取舍** — 剪枝模型参数 **6.31B vs dense 7.62B**（bf16 下 12.6 vs 15.2 GB），每 token 的 linear 层 FLOPs 与权重读取都是 dense 的 **0.815×**（attention 不变，KV cache 相同，总成本比从 1k token 的 0.82× 升到 16k 的 0.87×）；结合思考长度，CSD+PLPO 在 MATH-500 上只需 dense 解码算力的 **0.59×**（Dense+PLPO 0.55×、TokenSqueeze-7B 0.54×）——即**以略高的解码成本换 17% 更少的参数**。

## 技术方案

### 核心思想

大型 reasoning model (LRM) 的服务成本有两个因子：**单 token 成本**（随模型尺寸增长）与**生成 token 数**。两条降本路线各自打一个：权重剪枝减参数与单 token 算力，CoT 压缩缩短思考链。理想情况下二者相乘叠加。**实践中它们相互干扰。**

本文的关键洞察是把干扰拆成「两侧各一个盲区」，然后用两个可以 drop-in 的组件分别修补：

**盲区一（剪枝侧）**：剪枝准则用模型自身推理轨迹算重要性。问题在于**「冗余推理」同样是该模型的重要激活**——一个在长解里高活跃、在短解里低活跃的神经元，看起来很「重要」，但它承载的是多余的内容。RAC-S 的 base score 因此会保留这类神经元。

**盲区二（压缩侧）**：偏好式 CoT 压缩（如 TokenSqueeze）需要对同一模型在同一题上采多个解、构造「短的对 / 长的错」偏好对。剪枝后的模型在很多题上**采不出足够多样本**，尤其在它已经解不出的题上。

修补方案因此共享同一个**冗余定义**：**超出最短正确解的余量**。

### CSD 的对比目标

定义短正确解流 `D_S` 与长正确解流 `D_L`（同一批题）。移除神经元集合 R 对 MLP 输出的改变（忽略交叉项）：

```
E_X(R) ≈ Σ_{k∈R} ‖W_down[:,k]‖² · M^X_k
```

目标是「保住短解上的计算，折扣长解额外带来的计算」：

```
J_λ(R) = (1+λ)·E_S(R) − λ·E_L(R)
```

由此得到每个神经元的代价 `c_k = ‖W_down[:,k]‖²·M^L_k·g_λ(r_k)`，其中 `r_k = M^L_k / M^S_k`，`g_λ(r) = (1+λ)/r − λ`。对比只通过这个比率进入。

关键直觉：把长解写成「共享核心 K + 构成 ρ 比例 token 的多余部分 R」，若 `M^S_k ≈ M^K_k`，则

```
r_k − 1 ≈ ρ · (M^R_k / M^K_k − 1)
```

即 **`r_k > 1` 表明该神经元在冗余推理上比在共享核心上更活跃**。

这个族包含熟悉的特例：**λ = −1 即只用长解校准 = RAC**；λ = −β ∈ (−1,0) 混合两流；λ = 0 只用短解校准。λ > 0 时 `g_λ` 随 r 递减，并在 `r_k > (1+λ)/λ` 时变负——此时移除该神经元会**降低**目标函数。

但**单一全局 λ 不可用**：对大多数神经元 r_k 是接近 1 的噪声比值；且依赖短解的校准（λ ≥ −1/2）并不优于 RAC；更重要的是，**对所有推理都重要、对得出结论重要、或对模型数值特性重要的神经元不能被 displace**。因此 CSD 改为**逐神经元设定 λ**：对未受保护且显著富集的神经元令 `λ_k → +∞`（强制移除），其余一律 `λ_k = −1`（退回 RAC）。

### 统计估计

- **配对**：同一题内 `y^S` 取最短正确解，`y^L` 从其余正确且正常终止的解中均匀抽取；少于两个正确解的题丢弃。**同题配对控制难度**。
- **位置匹配**：长解占据更靠后的位置，因此按绝对位置分箱（边界 512/1024/2048/4096/8192），用短流在各箱的 token 份额 `π_b` 重归一化后加权得位置匹配均方 `M̂^X_k`。
- **对数比**：`κ̂_k = log(M̂^L_k + δ) − log(M̂^S_k + δ)`，`δ = 0.01 · median_k M^S_k`（按层从未匹配的短流均方设定）。
- **显著性**：问题 hash 成 G = 20 组（同一对保持在同组），留一法重估 `π_b`（`δ` 固定）得 jackknife 标准误，检验统计量 `z_k = κ̂_k / SE_k`。
- **额外成本**：除对短解做一次 teacher-forced 前向、与长解一起穿过被剪层外，无其他开销；**不改变架构与每层预算**。

### 偏好对构造

设 `C̃(x)` 为剪枝模型的正确解集、`F̃(x)` 为失败解集、`C(x)` 为 dense 模型的正确解集。正确解要求：最终答案被验证、正常终止、**恰好含一个 `</think>`**；被验证且正常终止但 `</think>` 数量不是 1 的解被丢弃；**所有截断解都算失败**（其长度记为采样预算长度）。长度 `|y|` 为生成 token 数。

| Pair 类型 | 覆盖的题 | Chosen `y_c` | Rejected `y_r` | 针对的冗余类型 |
|---|---|---|---|---|
| **Self** | `C̃ ≠ ∅` 且 `F̃ ≠ ∅` | `k` 个最短正确解，`k = ⌊0.2·c(1−c/N)⌋+1`，`c=|C̃|` | `y ∈ F̃`，`|y| ≥ |y_c|` | 冗余 + 不完整推理 |
| **Dense** | `C̃ = ∅ ≠ C` | dense 模型的最短正确解 | `y ∈ F̃`，`|y| ≥ |y_c|` | 不完整推理 |
| **Length** | 无 self pair 且 `|C̃| ≥ 2` | 剪枝模型的最短正确解 | `y ∈ C̃`，`|y| ≥ γ|y_c|` | 冗余推理 |

**目标函数**（TokenSqueeze 的 DPO-L 不变）：

```
Δ_θ  = log π_θ(y_c|x)/π_ref(y_c|x) − log π_θ(y_r|x)/π_ref(y_r|x)
Δ_len = log(1+|y_c|) − log(1+|y_r|)
L_DPO-L = −log σ(β[Δ_θ + α·Δ_len])
L_SFT   = −(1/|y_c|)·log π_θ(y_c|x)
L = (1−η)·L_DPO-L + η·L_SFT
```

与 TokenSqueeze 的差异：每题采样更少（其 adaptive depth 会总是选单个最短正确解）、省略 step-wise linguistic refinement、**把截断解算作失败**、并新增 dense-anchored 与 length-anchor 两类偏好对。

### 关键技术

| 技术/方法 | 说明 |
|------|------|
| **Contrastive Set-Difference (CSD)** | 用长解 vs 短解的激活对比识别富集于冗余推理的神经元并优先剪除的准则 |
| **对比目标 J_λ(R)** | `(1+λ)E_S(R) − λE_L(R)`：保短解计算、折长解冗余 |
| **富集比 r_k** | `M^L_k / M^S_k`；`r_k > 1` 表示该神经元在冗余推理上比共享核心更活跃 |
| **位置匹配均方 M̂** | 按绝对位置分箱（512/1024/2048/4096/8192）后用短流 token 份额 `π_b` 加权 |
| **log-ratio κ̂_k 与 jackknife z_k** | 20 组 hash 的留一法标准误，`z_k = κ̂_k / SE_k` |
| **受保护集合 P** | `Top30%(s_k)` ∪ `Top1%(closing ratio e_k)` ∪ `Top0.1%(massive activation m_k)` |
| **候选集 C / displaced 集 D** | `C = {k ∉ P : z_k > z_0, κ̂_k > τ}`；`D = Top_m({z_k})`，`m = min(|C|, ⌊qB⌋)` |
| **基线分数填充** | 删除 `D ∪ (D 外 s_k 最小的 B−|D| 个)`，保持每层预算不变 |
| **退化为 RAC 的情形** | 若某层无神经元通过检验（`D = ∅`），CSD 精确退化为 RAC 校准结构化剪枝 |
| **Closing ratio e_k** | `</think>` 前最后一个段落断点到答案末尾的均方 / 全部生成 token 均方 |
| **Massive activation m_k** | `max_t |a_{t,k}|`，跨全部 calibration token（含 prompt） |
| **Self / Dense-anchored / Length-anchor 偏好对** | 三类来源分别针对冗余、不完整、冗余推理，覆盖剪枝模型「总解对/总解错」的题 |
| **PLPO 目标** | DPO-L（长度奖励项 α=1，β=0.1）与 SFT 按 η=0.5 混合，γ=1.5 |
| **PLPO 训练配置** | 3,983 题；每题 N=8 采样（temp 0.9, top-p 1.0, ≤8192 token）；全参数 1 epoch，batch 32 pairs（约 400 步）；AdamW，lr 5e-6 恒定无 warmup，grad clip 1.0，bf16；reference policy 为冻结起始模型 |
| **TokenSqueeze-7B 公开 checkpoint** | 同 dense 模型训练、每题采样更多并带 step-wise refinement，作为压缩基线 |
| **MATH-500 长度分层分析** | 按 dense 模型 8k-budget 运行的平均 thinking length 分「较短一半 / 50–80 分位 / 最长 20%」，对应解决率 98.6% / 97.8% / 71.0% |

### 4.2 只剪枝（尚未压缩）

- RAC-S 相对 dense：**MATH-500 掉 3.1 分、GSM8K 掉 1.9 分、AIME 掉 14.0 分**（z = −6.5）；平均思考长度在 MATH-500 涨 **15.5%**、AIME 涨 **24.8%**（截断率同时涨 **13.1 分**），GSM8K 上**翻倍**（386 → 799 token）。GSM8K 的新增长度几乎全部来自能正常完成的样本（380 → 751 token），准确率几乎不变——即**模型更弱也更啰嗦，且啰嗦在最简单的题上最严重**。
- CSD 相对 RAC-S：**MATH-500** 几何均值少想 **4.4%**、均值少 **2.9%**（3,671 vs 3,780），准确率差 **−0.4 分**；**GSM8K** 少 **8.0%**（735 vs 799），准确率相同；**AIME** 不缩短（均值 −0.2%，准确率 +0.3 分），但截断率从 **21.4% 升到 24.0%**——缩短效果最大的恰恰是最简单的 benchmark。

| PLPO 对剪枝模型的缩短不如对 dense | RAC-S：MATH-500 **−30.3%**、AIME **−18.3%**；dense：**−44.7%**、**−35.4%**；MATH-500 几何均值 **−42.9% vs −63.9%** |
| GSM8K 是例外 | PLPO 缩短 RAC-S **65.3%** > dense 的 63.5%，准确率代价 3.8 分 vs dense 的 3.0 分；但 RAC-S+PLPO 仍比 Dense+PLPO 长近一倍（277 vs 141 token） |
| **PLPO 在 CSD 上缩短更多（每个 benchmark）** | MATH-500 几何均值 **−48.9% vs −42.9%**；log 尺度上追回 RAC-S 相对 dense 损失的 compressibility 的 **24%** |
| **CSD+PLPO vs RAC-S+PLPO** | MATH-500 / GSM8K / AIME 分别少 **11.1% / 21.7% / 9.6%** thinking token，准确率差 **−0.5 / −0.4 / +0.1 分**；MATH-500 上配对几何均值差距 **14.5%** |

### 5 分析：CSD 到底剪掉了什么

| 观察 | 数值 |
|---|---|
| displace 规模 | 28 层共 displace **7,719** 个神经元；其中 **6,456** 个本会被 RAC-S 保留（即真正改变了 **121,464** 个被剪神经元中的 **5.3%**），另 1,263 个反正也会被删 |
| 分数分布 | 被 displace 的神经元基础分中位百分位 **46**（四分位 30 / 59）；它们替换的神经元在 **20–23** 百分位 |
| 深度分布 | z 最高的前 10% 中，**1/3** 在第 18–23 层，**14%** 仅在第 10 层 |
| 富集分散度 | z 最大的 224 个被 displace 神经元（每层 8 个）中，**53%** 无任何单一 token 贡献超 1/4 富集度；**24%** 的前五大贡献者含 `Wait` 等 reflection marker；仅 **3%** 有 ≥1/2 富集度来自单个稀有 token |
| 富集来源 | 中位 **80%** 来自**同样 token 上更强的激活**，而非 token 出现更频繁 |

| 层 | dense 解决率 | RAC-S 长度变化 | RAC-S 准确率损失 | CSD vs RAC-S 长度变化 |

## 局限性

- **只覆盖一个模型、每个配置一次训练运行** — 作者在结论中明确写道「Our study covers one model and one training run per configuration」。DeepSeek-R1-Distill-Qwen-7B 上的结论能否外推到更大规模或不同架构未验证。
- **方法学上「更短」与「更省」存在取舍** — 剪枝模型每 token 解码成本高于 dense 压缩后的 0.55×（CSD+PLPO 是 0.59×），因此**只有当显存而非解码算力是瓶颈时**这个组合才划算；作者自己把这条写进结论。
- **AIME 上 CSD 剪枝并不缩短推理**，且截断率从 21.4% 升到 24.0%；四项对比中 AIME 的 thinking token 优势最小（9.6%），准确率也基本无差异（+0.1 分）——在难题上收益有限。
- **压缩侧仍依赖 dense 模型的样本** — dense-anchored 偏好对需要 dense 模型的解，这意味着**训练阶段仍需访问原模型**（离线可预先采样，但流程上并未真正摆脱 dense 模型）。
- **CSD 相对 RAC-S 的改变其实很小** — 只改变了被剪 121,464 个神经元中的 **5.3%**（6,456 个），收益却达到 8–22% token 节省，说明效应量对这一小撮神经元的选择高度敏感，稳健性需要多次运行验证（而本文只有一次）。
- **GSM8K 上准确率代价明显** — RAC-S+PLPO 与 CSD+PLPO 的 GSM8K 准确率均为 81.9 / 81.5，相对 dense+PLPO 的 84.6 分别掉 2.7 / 3.1 分；GSM8K 虽有最大 token 节省（21.7%），准确率损失也最集中。
- **对 ReCal 的比较跨越了不同模型与协议** — 作者自己承认「The models and protocols differ from those above」，因此「剪枝侧优于恢复侧」是方向性判断而非严格受控对比。
- **preliminary version** — 论文自述「11 pages. Preliminary version; further experiments and revisions are planned」，附录仅到 Appendix B 附近，且**代码未公开**。
- **位置分箱与显著性检验的敏感性未做** — bin 边界（512/1024/2048/4096/8192）、G=20 组 hash、`δ` 的选取均为工程选择，论文未给出这些超参的敏感性分析。

## 建议

- **是否推荐使用**: 有条件
- **适用场景**: 部署 memory-bound 的 reasoning model 服务时（显存而非解码算力是瓶颈）；以及已经在用「剪枝 + TokenSqueeze 式压缩」组合、希望再压 8–22% token 的团队——两个组件都是 drop-in 的。
- **可借鉴要点**:
  1. **把「冗余」当作一个可测的对比量，而不是一个整体判断**：本文的核心方法学可迁移到任何「模型在某个子集上做无用功」的场景——构造「长解/短解」「成功/失败」「长上下文/短上下文」的配对流，用位置匹配后的 log-ratio + jackknife 显著性筛出富集于冗余路径的单元，再从候选池里优先剔除。
  2. **偏好式压缩必须覆盖模型「总是做对」与「从不做对」的题**：TokenSqueeze 式 self pairs 只在「有对有错」的题上给信号，本文补上的 dense-anchored（从不做对）与 length-anchor（总做对）两类偏好对，正是剪枝后模型最重要也最难覆盖的两端区间。
  3. **先修剪枝侧再谈恢复训练**：RAC-S 在训练前已把 MATH-500 保在 dense 的 3.1 分内、AIME 保 35.5%，而基于 prompt 校准的 Wanda-sp/FLAP 剪完 AIME 只剩 2.2%——**校准数据用模型自己的推理轨迹 vs 用 prompt，差别是数量级的**。
