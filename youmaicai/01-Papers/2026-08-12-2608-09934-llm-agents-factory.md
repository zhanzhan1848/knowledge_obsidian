## 核心贡献
1. **LLM Agents Factory**: 基于检索的框架，从 20K+ 预定 agent profile 库中动态构建领域特定的 Wikipedia-grounded agents
2. **双模式支持**: (1) 基于语义搜索的 agent profile 检索；(2) 蒸馏为紧凑模型进行直接 agent 生成
3. **成本效率**: 在 MMLU、BIG-bench、BIG-bench Hard 上，使用 120B backbone 达到 AutoGen 生成质量，但推理成本显著降低

## 核心方法
- **Agent Profile Repository**: 20K+ 预定义 agent 配置文件
- **语义检索**: 基于语义相似度检索最适合的 agent profile
- **蒸馏模式**: 将检索知识蒸馏到轻量模型中

## 实验结果
- MMLU, BIG-bench, BIG-bench Hard 评测
- 超越非 agent 基线，匹配 AutoGen 生成质量

## 局限性
- 依赖预定义的 agent profile 库，覆盖范围受限于库的设计
- 检索质量受语义编码器影响

## 建议
- **是否推荐使用**: 是
- **适用场景**: 工业级 LLM Agent 部署，需要控制成本的生产环境
- **相关方向**: Agent RAG, Agent 检索, 轻量级 Agent 蒸馏
