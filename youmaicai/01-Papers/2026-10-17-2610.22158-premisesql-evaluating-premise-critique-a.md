## 核心贡献

> 现有 NL2SQL 系统假定 user query 合法可答。但若 query **前提有缺陷**，模型仍会生成可执行 SQL → **误导性输出**。

1. 提出 **premise critique ability**：识别有缺陷 query 并 **abstain**（拒绝生成）。
2. **PremiseSQL** benchmark：
   - **1,800 flawed NL2SQL queries**
   - **4 类** premise failures
   - 配套 **1,800 原始 queries**
3. 评估框架：intrinsic + prompt-induced premise-aware behavior，跨 3 prompting settings。
4. **揭示 frontier LLMs 在 premise critique 能力上不足**。
