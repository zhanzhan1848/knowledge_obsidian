## 核心贡献

1. **Decoupled Marginal Sharpening (DMS)**：把 inference-time sharpening 解耦为 reasoning + answer 两个独立环节
2. **Fully Adapted Annealed SMC (FA-ASMC)**：在 sampler 层结合 annealed power target + locally fully adapted proposals + predictive ancestor resampling
3. **零权更新 / 零外部 reward model** 的 plug-in inference-time scaling SOTA

## 方法

### Target-level 解耦

传统 reward-free power-sampling 定义

```math
π_α(y|x) ∝ p_0(y|x)^α
```

α>1 放大 already-likely completions，但**全序列锐化**会压缩 alternative paths。DMS：

1. 先在 **reasoning 分布**上轻度锐化（α_r 小）鼓励探索 diverse paths
2. marginalize answer 概率 over weighted reasoning population
3. 再在 **answer marginal** 上强锐化（α_a 大）—— 集中到有更多 aggregate support 的 answer

Sampler-level：
- **Annealed sequence of power targets**（避免突然重分布）
- **Locally fully adapted proposals**（局部最优 proposal）
- **Predictive ancestor resampling**（预测式祖先重采样，避免 path collapse）

```python
# Concept
reasoning_exponent = α_r  # mild, ~1.2
answer_exponent = α_a     # strong, ~3-5
# Sample reasoning paths → marginalize → sharpen answer
```

## 实验结果

| Benchmark | DMS vs baseline |
|-----------|-----------------|
| MATH500 | mean pass@1 **最高** |
| GPQA-Diamond | mean pass@1 **最高** |
| HumanEval | mean pass@1 **最高** |
| AIME24 / AIME25 | mean pass@1 **最高** |

3 个 base models 全部胜出。

## 局限性

- 仍需要多个 samples (SMC 形式)，不能单 sample 提升
- 没有回答 reasoning path diversity vs answer confidence 之间的最优权衡曲线
- Plug-in 设计 → 需要 base model 提供概率接口（兼容性受限）

## 建议

- **是否推荐使用**：是
- **适用场景**：reasoning-heavy 任务 + 已有 base model 但需提升 pass@1 / inference-time scaling
- **推荐路径**：替换现有 power-sampling / best-of-N / majority voting pipeline
- **运营价值**：训练免费 + 无 reward model → production 部署友好
