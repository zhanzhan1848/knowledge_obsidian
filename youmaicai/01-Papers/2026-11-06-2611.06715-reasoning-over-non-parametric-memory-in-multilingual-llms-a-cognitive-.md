# Reasoning over Non-Parametric Memory in Multilingual LLMs: A Cognitive-Based Analysis of Relational Knowledge

## 摘要
RAG 假设语言模型能够对**上下文中陈述的关系**进行推理，而不是退回到预训练时记住的关联。本文**隔离**这一「证据条件化的关系推理」—— 事实**直接放在 prompt 中**而非检索得到。**Rel-Bloom** 是一个受控多语言诊断集：**450 道多选题**，构建自 **30 个 Wikidata 关系**；同样的源关系在**五个 Bloom 启发层级**（Remember / Understand / Apply / Analyze / Evaluate）实例化，并在**三种真实性条件**（Factual / Counterfactual / Neutralized）下呈现。跨 **43 个模型、6 种语言、两种多语言设定（226,800 次预测）**，三项发现突出：(1) 在每一个被测的开源权重模型系列中，准确率从 **Apply 到 Analyze 急剧下降**，**Large Granite 桶降幅达 47.2 个百分点**，但**两个 Gemini 模型除外**；(2) **Evaluate 项始终是瓶颈**，即便模型在其他四类任务上接近天花板 —— **Gemini 3.1 Pro 在其他四层平均 99.5%，但 Evaluate 仅 60.7%**；(3) 题级与关系级的难度排序**跨语言一致保持**，表明难度具有语言无关结构。发表于 **COLM 2026**。

## 核心贡献
1. **隔离**证据条件化的关系推理（事实直接给在 prompt 中，排除检索噪声）—— 方法论上比 RAG 评测更干净
2. 发布 **Rel-Bloom**：450 道多选题、30 个 Wikidata 关系、5 个 Bloom 层级 × 3 种真实性条件（Factual / Counterfactual / Neutralized）
3. 大规模：**43 个模型 × 6 种语言 × 2 种多语言设定 = 226,800 次预测**
4. 三项发现：Apply→Analyze 断崖（Large Granite **−47.2 pp**，Gemini 例外）、**Evaluate 是独立瓶颈**（Gemini 3.1 Pro 其他四层 99.5% vs Evaluate **60.7%**）、**难度排序跨语言一致**

## 方法与架构
**Rel-Bloom 构造**：
- 30 个 Wikidata 关系作为源；
- 5 个 Bloom 启发层级实例化：**Remember / Understand / Apply / Analyze / Evaluate**；
- 3 种真实性条件：**Factual / Counterfactual / Neutralized**（后者用于探测模型是否依赖预训练关联而非上下文证据）。

**关键控制**：事实**直接放入 prompt**，不做检索 —— 从而把「基于证据的关系推理」从检索质量中剥离。

**规模**：43 模型 / 6 语言 / 2 多语言设定（226,800 预测）。

**分析**：层级间准确率跃变、题级与关系级难度的跨语言排序一致性。

## 实验结果
- **Apply → Analyze 断崖**：每个开源权重模型系列都出现；**Large Granite 桶降幅 47.2 pp**；**两个 Gemini 模型不受影响**
- **Evaluate 是独立瓶颈**：**Gemini 3.1 Pro 其他四层平均 99.5%，Evaluate 仅 60.7%**
- **难度排序跨语言一致保持**（题级与关系级）→ 难度具语言无关结构
- 43 模型 × 6 语言 × 226,800 次预测
- **COLM 2026** 发表

## 局限性
- 30 个关系 × 450 题，关系类型的覆盖面有限（关系偏结构化、事实性）；
- 多选题形式可能低估真实应用中的自由生成难度；
- 「Bloom 层级」是启发式映射，非严格心理测量学分类。

## 值得注意的点
**「其他四层 99.5% vs Evaluate 60.7%」是今日最戏剧性的单点数字** —— 它说明高 Bloom 层级不是「更难一点的同一件事」，而是**质的转变**：模型能理解、能应用、能分析，但**无法评价**。最可能的解释是：Evaluate 要求在证据不足时给出判断，这与模型的「谨慎回避」倾向冲突。这一发现对任何依赖模型做质量把关的部署都有直接含义。
