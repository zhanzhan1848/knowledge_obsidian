# Generate-then-Rank: Learning Symbolic Goal Interpretation for Embodied Agents

## 摘要
具身 agent 的**目标解释（Goal Interpretation）**要把自然语言指令翻译成规划器可执行的符号化目标 —— 这里的任何错误都会传播到下游每一个规划与动作步骤。本文提出 **generate-then-rank** 两阶段方案：先用 SFT 把 LLM 适配到 EAI（Embodied Agent Interface）的输出约定，再用 **CORE（Candidate-Output Ranking from Errors）** 从模型自己生成的候选中学习偏好。在 EAI Benchmark 的家庭场景上评估了 DeepSeek-V3-chat、DeepSeek-Reasoner、Qwen2.5-7B、Qwen2.5-72B，优于简单 prompting、CoT 以及基于知识图谱的基线。

## 核心贡献
1. 把具身 agent 的目标解释形式化为**两阶段：候选生成 + 候选排序**，并指出该环节的错误会向下游全链路传播
2. 提出 **CORE（Candidate-Output Ranking from Errors）** —— 从模型自身生成的错误候选中学习完整输出的偏好
3. 在 EAI Benchmark 上对 4 个开源 LLM（DeepSeek-V3-chat / DeepSeek-Reasoner / Qwen2.5-7B / Qwen2.5-72B）做系统比较
4. 相对简单 prompting、chain-of-thought、知识图谱方法均有提升

## 方法与架构
**阶段一（SFT）**：对 LLM 做监督微调，使模型输出符合 EAI 的形式化输出约定（符号化目标格式）。

**阶段二（CORE）**：Candidate-Output Ranking from Errors —— 不直接让模型输出唯一答案，而是**生成多个候选完整输出**，再基于「从错误中学习」的偏好信号对候选排序，学习到的是**完整输出的偏好**而非 token 级奖励。

**对比基线**：简单 prompting、chain-of-thought、知识图谱方法。

**评测环境**：Embodied Agent Interface (EAI) Benchmark 的 household scenes。

## 实验结果
- 在 EAI Benchmark household scenes 上，generate-then-rank 方案**全面优于**简单 prompting、CoT 与知识图谱基线
- 覆盖 DeepSeek-V3-chat、DeepSeek-Reasoner、Qwen2.5-7B、Qwen2.5-72B 四个模型
- **ECC 2026** 录用（第 10 届欧中智能数据分析与应用会议）

## 局限性
- 仅在 EAI Benchmark 的家庭场景上评测，跨域泛化性未验证；
- 核心收益来自「排序候选」而非更好的生成，候选数量与排序成本未在摘要中量化；
- 错误传播的严重性虽被指出但未做定量归因分析。

## 值得注意的点
「目标解释错误会传播到每个下游步骤」这一观察，与本批次另一篇 RM-VLM（让 VLM 充当 reward machine 的命题接地预言机）形成对照：两者都在解决**符号接口的可靠性**，但 RM-VLM 把接地交给 VLM，本文则把选择交给排序学习。
