## 核心贡献

1. **FinSkillBench**：评估语言模型 agent 有效使用金融领域技能解决投资管理任务的基准
2. **三大领域**：投资组合构建、风险管理、基本面分析
3. **12 子任务**：2,603 个任务 episodes
4. **技能对比**：no skill vs. curated skill packages vs. self-generated skills

## 基准设置

### 三大领域
1. Portfolio Construction（投资组合构建）
2. Risk Management（风险管理）
3. Fundamental Analysis（基本面分析）

### 输入特点
- Point-in-time inputs
- Hidden ground truth
- Task-specific verifier

## 关键实验结果

| 条件 | 平均分数 |
|------|----------|
| No skill | 0.366 |
| Curated skill packages | 0.528 |
| Self-generated skills | 几乎无提升 |

### 核心发现
- **Curated skills 持续提升性能**，从 0.366 → 0.528
- **投资组合构建和风险管理**收益最大
- **Self-generated skills 成本高但收益有限**

### 独立评估
- Hermes Agent framework（8 models, 5,280 episodes）
- 方向性模式一致，具体幅度因任务和框架而异

## 核心洞察

> 在投资管理 agent 中，**可靠的程序性技能访问**可能和**模型选择**一样重要，而简单的技能自生成通常无效
