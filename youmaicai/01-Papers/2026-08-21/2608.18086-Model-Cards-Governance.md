## 核心贡献

1. **实证分析**：分析了 Hugging Face 上 500 个 model cards
2. **Safety Gap 识别**：现有监管方法的 safety gap，包括 model heritage、alignment provenance、empirically observed behaviors
3. **三层治理框架**：提出整合 model cards + AUPs + licenses 的多层次方法
4. **OSL 问题**：论证标准开源许可证不适合 OWFMs，可能削弱 AUPs 的可执行性

## 三层治理框架

### Component 1: Model Cards
- 现有问题：信息不完整、不一致

### Component 2: Acceptable Use Policies (AUPs)
- 规范性约束
- 现有问题：缺乏法律强制力

### Component 3: Licenses
- 法律维度
- 现有问题：标准 OSL 不适合 OWFMs

## Safety Gap 分析

| Gap 类型 | 描述 |
|----------|------|
| Model Heritage | 模型来源、训练数据谱系 |
| Alignment Provenance | 对齐方法和验证 |
| Observed Behaviors | 实证观察的安全相关行为 |
