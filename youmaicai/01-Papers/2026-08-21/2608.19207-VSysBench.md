# VSysBench: Benchmarking Multimodal LLMs under System Messages

## 元信息
| 标题 | Compliance, Capability, and Conflict: Benchmarking Multimodal LLMs under System Messages |
|------|------|
| 作者 | Juan Yeo, Geewook Kim |
| 链接 | [原文](https://arxiv.org/abs/2608.19207) |
| arXiv | arXiv:2608.19207v1 |

## 核心贡献

1. **问题发现**：现有基准测试仅评估文本约束或将其嵌入用户输入，忽略了多模态场景下的 system-message adherence
2. **VSysBench**：基于 MMVet-v2 构建的基准测试，组织为 5 个主类别、22 个子类别
3. **双轴评估**：通过 JSR (Joint Satisfaction Rate) 和 CCS (Cross-Constraint Sensitivity) 联合评估约束遵守和答案正确性
4. **大规模评测**：覆盖 16 个 MLLM 模型

## 约束类别

### 5 Main Categories
1. Textual directives in visual contexts
2. Fully vision-grounded constraints
3. ... (其他类别)

### 22 Sub-categories
- 每个子类别配有对齐的 counterpart 用于 stress-test 指令层级

## 关键发现

| 发现 | 描述 |
|------|------|
| Base accuracy 下降 | 施加 system messages 后，基础任务准确性大幅下降 |
| Open-weight 模型脆弱 | 在用户冲突下，开放权重模型的 compliance 崩溃 |
| 专有模型稳定 | Top 专有模型保持稳定 |
| Vision-grounded 最难 | 每个模型都在 vision-grounded 约束上表现最差 |

## 评估指标

### JSR (Joint Satisfaction Rate)
约束遵守 + 答案正确性的联合满足率

### CCS (Cross-Constraint Sensitivity)
跨约束敏感性
