# Accelerating Long-Context Decoding in Large-Scale Hybrid LLMs Without Retraining

## 摘要
大模型的**全注意力层**让每个生成 token 都比前一个更贵，在长上下文任务上拖慢速度。混合模型用线性注意力层替换大部分全注意力层以降低成本，但**剩余的全注意力层在长上下文下仍主导解码**。本文**无需训练、不改权重**地加速这些剩余层：每层只关注**最近 token 的滑动窗口** + **固定前缀（pinned prefix）** + **上下文中固定预算的最相关 token**；窗口大小与预算用**多目标搜索算法逐层确定**。在来自三个家族、**4B 到 397B** 的**六个混合模型**上，所选配置在 **21 个长上下文数据集**上保持基线准确率。解码 64k/256k token 提速：**Qwen3.5-4B 达 1.26× / 2.22×**；**Qwen3.5-122B-A10B 达 1.20× / 2.23×**；**Ornith-1.0-397B 达 1.16× / 2.06×**。

## 核心贡献
1. **免训练、免改权重**地加速混合模型中残留的全注意力层
2. 提出三段式稀疏注意力结构：**滑动窗口（近期）+ 固定前缀 + 固定预算的最相关上下文 token**
3. 用**多目标搜索算法逐层**确定窗口大小与预算（不手工设定）
4. 在 6 个混合模型（4B–397B）、21 个长上下文数据集上验证**准确率保持**，64k/256k 解码最高 **2.23×** 提速

## 方法与架构
**每层注意力结构**：
```
Attn(q) = Attn( sliding_window(q, W)      # 近期 token 滑动窗口
             ∪ pinned_prefix(q)        # 固定前缀
             ∪ top_budget(q, ctx) )     # 上下文中固定预算的最相关 token
```

**配置搜索**：**多目标搜索算法**，**逐层**确定窗口大小 W 与预算 B（兼顾速度与准确率）。

**约束**：**不训练、不改权重**。

**评测**：6 个混合模型（3 个家族，4B–397B）× 21 个长上下文数据集；64k 与 256k 解码延迟。

## 实验结果
- **Qwen3.5-4B**：64k **1.26×** / 256k **2.22×**
- **Qwen3.5-122B-A10B**：64k **1.20×** / 256k **2.23×**
- **Ornith-1.0-397B**：64k **1.16×** / 256k **2.06×**
- **21 个长上下文数据集上准确率保持**（与基线持平）
- 免训练、免权重修改

## 局限性
- 加速比随模型规模递减（397B 只有 2.06× @256k），大模型收益有限；
- 「最相关 token」的选取若需在线打分，其开销需计入；摘要未说明是离线预计算还是在线；
- 21 个长上下文数据集上「准确率保持」是均值口径，per-task 退化情况未披露。

## 值得注意的点
**加速比随规模递减**这一趋势值得注意：越大的模型长上下文解码越难加速，说明稀疏化收益主要来自「长上下文中大部分 token 确实无关」这一假设 —— 而超长上下文模型可能正是在利用那些远端信息。
