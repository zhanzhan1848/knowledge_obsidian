## 核心贡献

> 提出 **Delta N-gram** —— 一条**只向前（forward-only）**的写入路径，直接写进语言模型**原生 hash N-gram 表**：**预训练表 T⁰ 永不被修改**，证据写入稀疏 patch **Δ**；一个 **4.1M 参数的 writer** 负责发出 target 与 gate，**block-averaged delta rule** 让每行保持为"旧值与受门控 targets 的凸组合"。

1. **延续前作的问题定位**：前作（arXiv:2610.14921）发现模型的**原生 hashed N-gram 表**是**持续更新扰动基座最小**的地方 —— 但**其写入需要 backpropagation 且会改变预训练表**
2. **核心改进 —— 前向写入 + 不动基座**：
   - **T⁰ 永不被修改**（pretrained table never modified）
   - 证据写入它所触及的**行上的稀疏 patch Δ**
   - **writer 以预训练目标在原始文本上离线训练**
   - **使用时只需前向传播**（forward passes only）
   - **清空 Δ 即恢复原模型**（clearing Δ restores the original model）—— 可逆
3. **记忆保真度大幅超越在线梯度写入**：**0.6B 原型**在回答问题后**二次写入仍保留 16/16 条事实**；而**在线梯度写入只保留 2–4/16**
4. **两种 writer 的行为差异**：
   - **plain writer**：用 **T⁰-only** 模型编码证据
   - **delta writer**：编码时**读取当前记忆**
5. **文档特异性（document specificity）量化**：在 **Qwen3.8-Flash-Next** 上，plain writer 的记忆对文档是特异的 —— **64 个 held-out 新闻事件**上，相对空记忆降低 continuation **NLL 0.068 nats/token**，相对**另一个文档**的记忆只降 **0.024**；经历 **16 篇插入文章**后仍降 **0.063** 与 **0.013**
6. **delta writer 更特异、且抗干扰更好**：**70% vs 54%** 的保留率
7. **长链稳定性**：在**先前七任务链的 35,000 次写入**上两个 writer 都保持稳定，delta writer 漂移更小（**layer-2 数学漂移 176% vs 188%**）
8. **写入的代价与副作用（罕见的诚实披露）**：
   - 后续准确率变化 **−0.26 / −0.52 pp**（梯度更新为 **−7.29 pp**）
   - 小 k_i 漂移 **17.9 / 17.5%**（梯度为 **39.2%**）
   - **获取为负（Acquisition is negative）**
   - **一般输入漂移达 32.8%（20.75%）**
   - **被每个样本读取的 format 行增长到预训练范数的 4–12 倍**
   - **将这类 8 行归零，可移除数学输入上超过 98% 的 layer-2 漂移**，同时保留其 NLL 增益

## 技术方案

### 核心思想

```
预训练 n-gram 表  T⁰   （冻结，永不修改）
        │
        │  读取：h' = (1 - g) · T⁰[row] + g · t        ← delta rule
        ▼
稀疏 patch  Δ[row]  = { (position, hash head) → (target, gate) }
        ▲
        │  写入：writer（4.1M 参数，前向传播即可）
        │
     证据（raw text）

⇒ 清空 Δ ⇒ 完全恢复原模型（可逆、无参数污染）
```

### 关键技术

| 技术 | 说明 |
|------|------|
| **Frozen pretrained table T⁰** | 基座不被改动，所有更新落在稀疏 patch 上 |
| **Sparse patch Δ** | 只在证据触及的行上有内容，**4.1M 参数**的 writer 产生 |
| **Per-(position, hash head) target + gate** | writer 对每个事件发出一个 target 和一个 gate |
| **Block-averaged delta rule** | 使每行保持为**旧值与受门控 targets 的凸组合**（convex combination）—— 保证数值稳定与"不破坏基座" |
| **Forward-only write** | 使用时**只需前向传播**，无需反传 |
| **Reversibility** | **清空 Δ 即恢复原模型** |
| **Offline writer training** | writer 在原始文本上用**预训练目标**训练 |
| **Plain writer vs delta writer** | 前者用 T⁰-only 编码证据；后者**编码时读取当前记忆** |
| **Acquisition / retention / drift 三类指标** | 论文同时报告"获取能力、保留能力、漂移"，而非只报一个 |

### 三类指标的含义

| 指标 | 含义 |
|------|------|
| **Acquisition** | 写入后模型能否**获得**新知识（论文报告 **Acquisition is negative** —— 是个负面结果） |
| **Retention** | 二次写入后能否**保留**先前写入的知识（16/16 vs 2–4/16） |
| **Drift** | 写入对**其他行为**（尤其数学能力与一般输入）的影响 |

## 关键实验结果

### 事实保留（fact retention）

| 条件 | 保留事实数 |
|------|------|
| Delta N-gram（0.6B 原型），二次写入后 | **16 / 16** |
| 在线梯度写入（online gradient writes） | **2–4 / 16** |

### 文档特异性（Qwen3.8-Flash-Next，64 个 held-out 新闻事件）

| 对照 | NLL 降低 |
|------|------|
| plain writer vs 空记忆 | **0.068 nats/token** |
| plain writer vs **另一个文档**的记忆 | **0.024** |
| 16 篇插入文章后 vs 空记忆 | **0.063** |
| 16 篇插入文章后 vs 另一文档记忆 | **0.013** |

### delta writer 的抗干扰优势

| 指标 | 数值 |
|------|------|
| 保留率（保持文档特异性） | **70% vs 54%**（delta vs plain） |

### 长链稳定性（35,000 次写入，七任务链）

| 指标 | delta vs plain vs gradient |
|------|------|
| layer-2 数学漂移 | **176% vs 188%**（delta vs plain） |
| 后续准确率变化 | **−0.26 / −0.52 pp**（梯度：**−7.29 pp**） |
| 小 k_i 漂移 | **17.9 / 17.5%**（梯度：**39.2%**） |

### 副作用（论文诚实披露）

| 副作用 | 数值 |
|------|------|
| **一般输入漂移** | **32.8%**（另一设定 20.75%） |
| **format 行范数膨胀** | 增长到预训练范数的 **4–12 倍** |
| **归零 8 个 format 行** | 移除数学输入上 **>98% 的 layer-2 漂移**，同时保留其 NLL 增益 |
| **Acquisition** | **为负（negative）** |

## 关键结论 / 局限性

### 关键结论

1. **前向写入可以替代梯度写入做持续学习**，且**保真度高一个数量级**（16/16 vs 2–4/16），同时把基座**完全隔离在修改之外**
2. **可逆性是结构性保证而非工程努力**：清空 Δ 即回到原模型 —— 这让"回滚/审计"变成一个操作步骤
3. **记忆应文档特异**：通用记忆（把所有事实揉进一个表示）会导致干扰；delta writer 的"编码时读当前记忆"进一步强化了特异性（**70% vs 54%**）
4. **诚实报告副作用是关键价值**：论文明确写出 **Acquisition is negative** 与 **32.8% 一般输入漂移** —— 这类数字在持续学习论文中常被隐藏

### 局限性

- **Acquisition 为负**：即写入 n-gram 表**本身并不能让模型学会新的问答行为**（保真 16/16 是"记住已学会的东西不被破坏"，而非"学会新东西"）—— 这限制了直接用途
- **副作用显著**：**一般输入漂移 32.8%** 相当大，**format 行膨胀到 4–12 倍**；论文的"归零 8 行"是**事后补丁**而非机制性解决
- **漂移度量用"百分比"表述**（176%、188%、32.8%），但**基线定义不明** —— 相对什么度量难以独立解读
- **单作者工作**（Hao Wu）、**前作后续**，代码开源但生态支持不明
- **规模小**：原型 **0.6B**；主体实验在 **Qwen3.8-Flash-Next** 上，但未在多模型家族上验证
- **writer 需离线训练**（在原始文本上用预训练目标）—— 引入了一个额外训练阶段与数据依赖，且**writer 本身是 4.1M 参数的可训练组件**
- **hash 冲突与行竞争未讨论**：多文档写入同一行时凸组合如何仲裁，摘要未说明
- **无与传统持续学习基线（EWC、Replay、LoRA 等）的直接对比数字**
