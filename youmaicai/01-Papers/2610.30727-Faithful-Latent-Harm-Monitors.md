## 核心贡献

> 对 **Latent Guard** 类"从 activation 判有害"的 latent safety monitor 做系统评测。结论：在 **matched false alarm rate** 下，**忠实潜在监控器不优于模型自身的 refusal 行为**。

1. **背景**：有报告称 LLM 将请求的**有害性与拒绝决策分离编码**；Latent Guard 类方法据此从**内部 activation** 分类 prompt 有害性，意图在模型"顺从"时也能抓住有害意图。
2. **评测设计**：
   - OOD prompt：通过**改写**既有有害/良性请求（surface rewording / persuasive framing / jailbreak-style wrapper）构造；
   - **15 个 instruction-tuned LLM × 38 个 activation-based reader**；
   - 对比对象：TF-IDF、sentence-embedding 分类器、独立训练的安全分类器、**每个模型自身的 refusal**；
   - 读取位置两个：
     - **instruction 末 token**（模型已读完整个请求）；
     - **reply 前最后一个 chat-template token**（计划中的响应可被表示）。
3. **关键发现**：
   - **方法论**：因为不同模型对哪些 prompt 会拒绝**本就不一致** → 可以把"prompt 有害性信号"与"模型拒绝决策信号"**分离开**；
   - 在 instruction 末，representation **大体独立于 refusal 行为**，但**在分布漂移下退化** → **TF-IDF 分类器在我们测的每个模型上都比原始 Latent Guard 排得更好**；linear / MLP probe 与同数据训练的 sentence-embedding 分类器**差不多**；
   - 在生成前一刻检测到更多：matched false-alarm rate 下捕获 **44%** 有害 prompt，**模型自身 refusal 为 32%**；
   - **但该增益跟随 refusal 决策本身**，且部分来自**字符串匹配评估漏掉的 refusal**。

---

## 技术方案

| 组件 | 说明 |
|------|------|
| OOD 构造 | rewording + persuasive framing + jailbreak wrapper |
| Reader 位置 A | user instruction 末 token |
| Reader 位置 B | reply 前最后 chat-template token |
| Baseline 矩阵 | TF-IDF / sentence-emb / independent safety clf / model refusal |
| 匹配条件 | matched false alarm rate |
| 解耦技巧 | 利用模型间 refusal 分歧分离两种信号 |

### 关键洞见

- 这是对 **Latent Guard 主张的直接反驳性证据**：如果 TF-IDF 就能打败你，activation 的"忠实性"叙事就不成立。
- 但论文也给了**建设性结论**：position B 的 44% vs 32% 表明"pre-generation 内部监控"仍有效 —— 只是增益来自 refusal 决策而非独立的"有害性表示"。

---

## 实验结论

| 设置 | 结果 |
|---|---|
| TF-IDF vs Latent Guard | **TF-IDF 在每个模型上都更好** |
| Linear/MLP probe vs sentence-emb clf | 相当（~等于） |
| Pre-generation 位置 B | **44%** vs refusal **32%**（matched FAR） |

---

## 局限性

- OOD 构造可能不覆盖真实 jailbreak 分布；
- 15 个 instruction-tuned LLM，family 覆盖有限；
- 内部监控需 **white-box activation 访问** —— 部署成本未计；
- 44% 的增益"跟随 refusal" —— 对**确实顺从**的模型是否有效仍存疑。

## 实现建议

- **实现难度**：中（需多模型 activation 提取 + 大量 reader 训练）
- **预期价值**：高 — 直接影响安全层选型（别为"忠实"叙事付溢价）
- **适用场景**：安全审核方案选型、guardrail 成本分析、红队评估
- **建议部署**：生产第一版直接用 **strong refusal model / 独立安全分类器**，把 activation monitor 作为**补充**而非主力；论文呼吁的可信结论是"内部分离信号仍值得研究"
