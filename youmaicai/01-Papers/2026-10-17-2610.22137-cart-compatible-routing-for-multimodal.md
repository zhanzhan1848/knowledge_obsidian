## 核心贡献

> 多模态 LLM (MLLM) 在**多模态持续指令微调 (MCIT)** 场景下，传统方法只保护 LM 不遗忘，而**持续更新 projector**，导致 projector 与 LM 失配，加剧灾难性遗忘。

1. 提出 **CART (Compatible Routing)**：在 projector 与 LM 之间**协同适应**，而非让 LM 静默让 projector 跑偏。
2. **任务专属 experts**：projector 和 LM 各保留 task-specific experts，**通过 weighted mixtures** 组合。
3. **权重联合推断**：同时考虑 expert relevance + cross-module compatibility。
4. **Relevance-guided expert consolidation**：合并相似 relevance profile 的 experts，控制模型增长。
5. 实验达到 **MCIT SOTA**。

---

## 技术方案

### 现有问题
- MLLM = visual encoder + **projector** + LLM。
- 持续任务场景：projector **持续更新**，LLM **冻结 / 缓慢更新**。
- 结果：projector representation drift → projector-LLM mismatch → **catastrophic forgetting**。

### CART 方案
```
For task t:
  - Projector experts: P^t_1, P^t_2, ...
  - LLM experts: L^t_1, L^t_2, ...
  - Combined: output = Σ α_i · P^t_i ⊕ Σ β_j · LLM(L^t_j(x))
  
  α, β 由 compatibility scorer 联合推断：
    α, β = f(relevance_i, relevance_j, cross_module_score)
```

### Expert Consolidation
- 对每个 module (projector / LLM) 内 expert，按 relevance profile 在样本上的相似度合并。
- 控制**总 expert 数增长**。

---

## 实验结论

- 在 MCIT 多个任务序列上**平均 SOTA**。
- Projector 与 LLM 的协同显著减少遗忘。
- 模型规模增长通过 consolidation 控制。

---

## 关键洞察

- **MCIT ≠ CL for LLM**：需要把 projector 视为"一等公民"协同优化。
- **专家路由 + 跨模块 compatibility** 是 MLLM continual learning 的天然解。
