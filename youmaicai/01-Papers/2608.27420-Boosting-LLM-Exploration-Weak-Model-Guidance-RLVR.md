## 核心贡献

1. **问题识别**：RLVR（Reinforcement Learning with Verifiable Rewards）会导致策略熵急剧下降，造成 reasoning coverage 收窄，pass@k 性能退化。

2. **跨模型前缀引导**：用弱模型生成的 partial reasoning trajectories 作为前缀，引导目标模型继续推理，而非让目标模型从头生成。

3. **熵基前缀截断**：基于目标基础模型的 step-level 熵动态找到最佳截断点（L* = argmax_L [H̄(s~L) - H̄(s~L+1)]），保留高熵区域最强探索信号。

4. **无需额外 SFT**：不需要额外的监督微调、复杂奖励设计或复杂提示，工程代价低。

## 关键问题：RLVR 的 entropy collapse

RLVR 优化正确响应概率时，策略熵急剧下降：
- 模型对已有推理路径过度自信
- 替代推理路径被忽略
- pass@k（k 大时）性能可能低于 base model

## 方法

### Prefix-Completion RLVR
标准 RLVR：
```math
\theta^* = \arg\max_\theta \mathbb{E}_{q \sim \mathcal{D}, r \sim \pi_\theta(\cdot \mid q)}[R(q, r)]
```
Prefix-completion RLVR：
```math
\theta^* = \arg\max_\theta \mathbb{E}_{q \sim \mathcal{D}, r_{\text{suf}} \sim \pi_\theta(\cdot \mid q, \tilde{r})}[R(q, \tilde{r} \circ r_{\text{suf}})]
```
其中 r~ = {s~1, ..., s~L*} 是弱模型生成的 partial trajectory。

### 熵基截断
```math
L^* = \arg\max_L \left[ \bar{H}_{\theta_0}(\tilde{s}_L) - \bar{H}_{\theta_0}(\tilde{s}_{L+1}) \right]
```
保留熵降最大的点之前的前缀，避免在推理步骤中间截断。

### Mixed Training
以概率 p 附加弱模型前缀，以概率 (1-p) 使用原始问题，实现探索与执行的平衡。

## 实验发现

- 跨模型前缀诱导更高的 step-level 熵，尤其在早期推理步骤
- 这种熵扰动在 RLVR 训练后仍然存在
- 即使弱模型前缀偶尔误导，方法仍有效——说明探索价值来自分布偏移本身

## 局限性

- 仅在数学推理任务验证
- 前缀模型选择（多弱算弱？）未系统研究
- 推理时需要同时部署辅助小模型

## 建议
- **推荐使用**：是
- **适用场景**：需要保持 RLVR 训练后模型多样性的场景、pass@k 性能重要时
- **组合价值**：与 entropy regularization、reward shaping 等方法正交，可叠加
