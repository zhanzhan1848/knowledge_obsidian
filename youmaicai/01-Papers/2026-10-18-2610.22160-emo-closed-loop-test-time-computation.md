## 核心贡献

> 提出 **EMO** —— 受 **EM（Expectation-Maximization）** 启发的**训练免费** test-time compute 框架。**E-step** 用 external judge 改 system context，**M-step** 对比 revised/previous context 下 next-token 分布 → **confidence-constrained logit correction**。理论：通过 target-KL 把 param 与 context opt 联系起来。**8 模型 × 6 benchmark，39/40 setting 优 zero-shot，avg +9.10 pp**。

1. **EM 风格的交替优化**：
   - **E-step**：context estimation（用 textual gradient from external judge，无 gold answer）
   - **M-step**：distribution refinement（confidence-constrained logit correction）
2. **理论保证**：target-KL objective + additive logit representation；**one-round KL decrease** 在小 steering strength 下成立。
3. **Training-free**：frozen LM + logit 操作 → 无需训练。
4. **vs TextGrad**：same judge 下 **+1.53 pp** avg；consistent MMLU-Pro gains。
5. **vs best-of-N**：matched budget 下 Llama 上 EMO 更强；coverage-selection gap 提示应**联合分配 test-time compute 给 candidate generation + verification**。

## 技术方案

### Motivation

- Test-time context optimization (e.g. TextGrad) 调 frozen LM，但**普通 conditional generation 没独立控制 distribution 改变的强度**。
- → 想要 closed-loop 框架，**显式控制** "context update 的力度"。

### EMO 框架

```
                External Judge feedback
                        ↓
       ┌─────── E-step ────────┐
       │ Context estimation    │  ← textual gradient
       │ (update system ctx)   │
       └──────────┬────────────┘
                  ↓
       ┌─────── M-step ────────┐
       │ Confidence-constrained│
       │ logit correction      │  ← revised vs preceding ctx
       └──────────┬────────────┘
                  ↓
            Steered response
                  ↓
       Feedback (next round input)
```

#### E-step

- **Inputs**: current system context + external judge feedback
- **Action**: 用 textual gradient 更新 context
- **No gold answer**（仅 judge signal）

#### M-step

- **Inputs**: revised context + preceding context + shared prefix
- **Action**: 对比 next-token 分布 → 构造 **confidence-constrained logit correction**
- **输出**: steered logits

#### Alternating Update

- E-step 反馈驱动下轮 context 更新
- → 跨 round adaptation + 轮内 intervention 双向耦合

### 理论

```math
\min_{\text{context}, \theta} \text{KL}\big(p_{\theta}(\cdot|x, c^*) \,\|\, p_{\theta^*}(\cdot|x)\big)
```

- $c^*$：optimal context
- $\theta^*$：current LM
- 把 **param optimization** 与 **context optimization** 通过 shared target-KL 联系起来
- Additive logit representation
- **Theorem**：在 context-improvement + faithful-steering 假设下，小 steering strength 时 **one-round target KL decrease**（单调收敛保证）

## 实验结果

### Setting

- **8 models** × **6 benchmarks**
- Greedy decoding
- Training-free（frozen LM）

### 主要结果

| Comparison | Result |
|------------|--------|
| vs zero-shot baseline | **39 / 40 settings 优**，**avg +9.10 pp** |
| vs TextGrad (same judge) | **+1.53 pp avg**，consistent MMLU-Pro gains |
| vs best-of-N (matched budget) | Llama 上 EMO 优；coverage higher；fewer candidates |

### Key Insight

- **Coverage-selection gap**：best-of-N 集中在 candidate generation；EMO 跨 generation + steering
- → Test-time compute 应**联合分配**给 generation + verification

---

## 局限与展望

- "External judge" 假设存在 → 无 judge 场景不可用。
- Steering strength 需调（theorem 保证仅在小 strength 下）→ 实际最优值依赖 task。
- "Context-improvement + faithful-steering" 假设在实际不一定成立。
- MMLU-Pro 上 consistent gains → 但其他 benchmark 是否同样 robust 未量化。
- 与 Best-of-N / MCTS / Tree-of-Thought 等其他 TTS 方法的**联合**未探索。

## 实现建议

- **实现难度**: 中（需要 external judge + logit 操作 + EM-style loop）
- **预期性能**: avg **+9 pp** over zero-shot；+1.5 over TextGrad
- **适用场景**:
  - **High-stakes QA**（judge 可基于 confidence / factuality）
  - **Reasoning task**（可 verify 中间步骤）
  - **Production LLM**（frozen backbone 升级）
- **不适用**: 无 judge 信号场景；超低 latency 场景（multi-round overhead）
- **工程提示**:
  - Judge 可**轻量化**（smaller model + same-domain calibration）
  - Confidence constraint 防 steering over-shoot
  - Logit correction 应**保留 generation diversity**（避免 collapse）

## 一句话总结

EMO 用 EM 启发的 E-step (context via textual gradient) + M-step (confidence-constrained logit correction) 做 closed-loop test-time compute，**training-free + 理论 KL 收敛保证**，8 模型 × 6 benchmark avg +9 pp，是 TextGrad / best-of-N 的强 baseline。
