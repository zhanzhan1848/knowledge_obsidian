## 核心贡献

> 让移动智能体把显式 CoT 内化为连续的潜在推理槽位，并用 Q-Former 世界模型把潜在状态对齐到下一帧视觉特征，从而在大幅减少解码 token 的同时保持甚至提升任务成功率。

1. 提出 MIRAGE（Mobile agents with Implicit Reasoning And Generative world modEls）：把显式文本推理蒸馏进连续隐状态，推理在隐空间完成而非解码成可见文本；配套生成式世界模型目标，将潜在推理向量与未来截图对齐。
2. 提出 APLR（Approximate Parallel Latent Refinement）：利用因果注意力使潜在系统严格下三角，改为 K 轮 Jacobi 式并行精修所有槽位；证明前 K 个槽位精确等于串行解，尾部误差有 $\delta^{(K)} \approx A^K\delta^{(0)}$ 的界。
3. 提出 Q-Former 世界模型头：把末轮隐状态与下一帧冻结视觉编码器特征做对齐，抑制潜在表示坍缩并对 APLR 的尾部误差提供直接梯度；动作交叉熵与下一帧特征对齐损失联合优化。
4. 结果：AndroidWorld 上 4B 消融中以 3–5× 更低的解码 token 预算追平显式 CoT SFT，较同规模指令微调基线提升 10.2 个百分点；AndroidControl 上动作接地提升且生成 token 减少 75% 以上。

## 技术方案

### 核心思想

移动智能体需要从截图与语言目标可靠操作应用，瓶颈在于导航推理：要跟踪任务进度、决定下一个应访问的界面、并预判每个动作会如何改变界面。现有系统常把这类推理外化为长文本思维链或冗长动作轨迹，导致解码变慢、上下文占用高、监督成本大、执行效率低。

MIRAGE 的核心主张是"在模型内部思考"。在交互步 t，模型观测截图 x_t、用户指令 u 与历史 h_t，输出动作 a_t。形式上把显式 CoT 的联合分布分解为"思维 τ_t + 动作 a_t"，然后用连续隐变量 z_t = (z_{t,1},…,z_{t,N}) 取代 τ_t：p_θ(a_t|o_t) = ∫ p_θ(a_t|z_t, o_t) q_θ(z_t|o_t) dz_t。z_t 不在词表内、永不被 detokenize，其推断分布由解码器隐状态隐式计算——因此潜在思维训练不需要理由文本监督。

训练分两阶段。Stage 1 用结构化显式思维数据热身，让骨干学会移动动作空间与"观察/理由/预测"的表达方式；Stage 2 把整个 <THOUGHT> 块替换为 N 个连续潜槽位（共享可学习初始化 e_lat），并继续训练。

技术难点在于：原始 Coconut 式潜在推理是串行计算的——第 i 个槽位依赖前 i−1 个槽位已写入序列，形成因果三角系统上的前代替换，训练需 N 次完整解码器前向，代价高昂。APLR 观察到因果注意力使该系统严格下三角（z_i 不能依赖自身或任何未来 z_j），因此可以像 Jacobi 迭代那样并行更新全部槽位：所有右端都用上一轮的第 k 次旧值，一次前向更新所有槽位。论文证明经过 K 轮后前 K 个槽位精确等于串行解（z_i^(K) = s_i，i ≤ K），未精修的尾部槽位保留结构化残差 δ^(K) ≈ A^K δ^(0)，A 为严格下三角 Jacobian。

第二个缺口是：动作交叉熵只惩罚影响下一个动作 token 的尾部误差方向，并不直接监督关乎环境预测的误差。论文因此引入世界模型视角——结构化思维的 predict 字段描述动作后的界面语义变化。MIRAGE 不生成像素，而是把潜在 CoT 隐状态 C_t 与下一帧截图经冻结视觉塔得到的 stop-gradient 特征 V_{t+1} 用 BLIP-2 式 Q-Former 对齐。这一对齐迫使潜在槽位编码环境动态而非仅当前帧与动作的相关性，并对伤害未来截图预测的尾部误差方向给出直接梯度，同时抑制表示坍缩。

推理时只做潜在替换 + 贪心动作解码，不输出任何理由文本，Q-Former 头仅在训练时使用。

### 关键公式

```math
% 显式 CoT 的分解
p_\theta(\tau_t, a_t \mid o_t) = \prod_{i=1}^{|\tau_t|} p_\theta(\tau_t^{(i)} \mid \tau_t^{(<i)}, o_t)\cdot
\prod_{j=1}^{|a_t|} p_\theta(a_t^{(j)} \mid \tau_t, a_t^{(<j)}, o_t)

% 潜在思维形式化（z 不在词表，永不 detokenize）
p_\theta(a_t \mid o_t) = \int p_\theta(a_t \mid \mathbf{z}_t, o_t)\, q_\theta(\mathbf{z}_t \mid o_t)\, d\mathbf{z}_t

% APLR：Jacobi 式并行精修（所有右端用第 k 轮旧值）
z_i^{(k+1)} = G_i\big(z_1^{(k)}, \ldots, z_{i-1}^{(k)}; c\big),\quad i=1,\ldots,N,\quad k=0,\ldots,K-1
% 串行目标为 s_i = G_i(s_1,\ldots,s_{i-1}; c)

% APLR 误差界：前 K 个槽位精确，尾部残差
z_i^{(K)} = s_i \ \text{ for } i \le K,\qquad \delta^{(K)} \approx A^{K}\delta^{(0)},\ \ A \text{ 严格下三角}

% 动作交叉熵
\mathcal{L}_{\text{ce}} = -\sum_{j=1}^{|a_t|} \log p_\theta\big(a_t^{(j)} \mid \mathbf{z}_t^{(K)}, a_t^{(<j)}, o_t\big)

% 世界模型：潜在状态与下一帧特征对齐
C_t = \mathrm{Gather}\big(H_t^{(K)}, p_1,\ldots,p_N\big)\in\mathbb{R}^{L\times H}
V_{t+1} = \mathrm{sg}\big(f_{\text{vis}}(x_{t+1})\big) = [v_1,\ldots,v_M]\in\mathbb{R}^{M\times H_v}
% 联合目标
\mathcal{L} = \mathcal{L}_{\text{ce}} + \lambda\,\mathcal{L}_{\text{wm}},\quad \lambda = 0.8\ \text{(默认)}
```

### 关键组件

- **结构化思维格式**：`<THOUGHT> [observation] [rationale] [predict] <ACTION_DESC> ... <ACTION> ...`，三维度分别描述可见界面状态、为何采取该操作、预期的下一界面转变。
- **潜槽位序列**：`[ctx];[start];⟨lat⟩×N;[end];⟨ACTION_DESC⟩⋯⟨ACTION⟩`，槽位位置 p_1<⋯<p_N，共享可学习初始化 e_lat。
- **APLR**：默认 K=3 轮并行精修；早期 bootstrap 轮可无梯度，末轮保留经 e_lat 的梯度；末轮前用 mask 重建输入嵌入（潜位用 detached bootstrap 值，非潜位保留到视觉塔与词嵌入的原始梯度链）。
- **Q-Former 世界模型头**：BLIP-2 式自注意力 + 交叉注意力 + 投影到 VLM 特征空间；只训练时使用。
- **模型配置**：Qwen3-VL-4B-Instruct 用 9 个潜槽位 + 3 轮 APLR；Qwen3-VL-8B-Instruct 用 6 个潜槽位 + 3 轮。
- **对比基线**：同尺寸 Qwen3-VL-4B/8B-Instruct、显式 CoT SFT、串行潜在 CoT 参考（观察/理由/预测各对应 3 个潜槽位并按步进课程掩码）、以及 Ferret-UI Lite 等保留的专用 GUI 智能体。

## 局限性

- APLR 的尾部槽位存在近似误差 $\delta^{(K)} \approx A^K\delta^{(0)}$，训练时依赖 Q-Former 目标补偿，K=3 之外的效果未充分探索。
- 潜在推理缺乏可解释性：推理完全在隐空间完成，无法像显式 CoT 那样检查推理链，也不支持"先看理由再决定"的调试流程。
- 世界模型头只在训练时使用，推理不生成未来界面，因此无法直接做"想象-规划"，与真正的像素级 GUI 世界模型（如 UI 世界模型）能力有差距。
- 训练需要显式思维数据热身（Stage 1 依赖带 <THOUGHT> 的标注轨迹），监督成本未真正消除，只是从推理期转移到训练期。
- 论文只提供 Qwen3-VL-4B/8B 两个骨干的实验，跨骨干与跨平台（iOS/Web）的泛化性未验证。
- AndroidWorld 上 8B 模型步数略多于 Qwen3-VL 基线，论文强调收益并非仅来自更短轨迹。

## 建议

- **是否推荐使用**：是
- **适用场景**：移动 GUI 智能体的低延迟部署；需要在保证任务成功率前提下大幅压缩输出 token 与首末 token 延迟的端到端产品；GUI 世界模型研究方向。
- **值得复现**：是（APLR 的 Jacobi 式并行精修与误差界对任何"串行隐状态 CoT"方案都可复用）
