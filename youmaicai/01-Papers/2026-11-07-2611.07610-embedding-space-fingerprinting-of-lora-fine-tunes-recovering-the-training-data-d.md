# Embedding-Space Fingerprinting of LoRA Fine-Tunes: Recovering the Training-Data Domain from the Model Artifact Alone

### 核心贡献
1. 系统研究 LoRA 微调后训练数据域有多少信息会「泄漏」进模型制品（artifact），提出仅凭模型制品即可反推微调域的分类器方法。
2. 构建三档访问权限递减的特征族：white-box 权重、gray-box 激活、black-box 输出，并发现在 Qwen3.5-0.8B 上 36 个 LoRA 微调（18 个公开数据集、5 个域）中，域可恢复率显著高于随机基线 20%——gray-box 激活 61%、black-box 输出 64%、white-box 权重统计 42%。
3. 推翻预注册假设：信号并非从权重→激活→输出单调衰减，激活与输出反而比权重增量统计更有信息量；且 black-box 结果在使用纯生成文本（无 token 概率）时保持 64% 不变。

### 技术方案
**核心思想**: 用「留一数据集」（LODO）协议检验域分类器能否在完全没见过该数据集的情况下识别微调域，并把访问权限分层（white/gray/black box）作为主要自变量。

| 技术 | 说明 |
|------|------|
| LoRA 微调矩阵 | 单一 base model Qwen3.5-0.8B，36 个 LoRA fine-tune，覆盖 18 个公开数据集、5 个域（medical、code、mathematics、non-English text、narrative prose） |
| LODO 协议 | leave-one-dataset-out 协议，在任何结果产生之前预注册冻结，测试对未见数据集训练的微调能否识别其域 |
| White-box 特征 | 直接来自权重增量（weight deltas）的统计量，域准确率 42% |
| Gray-box 特征 | 固定 probe set 上的内部激活，域准确率 61% |
| Black-box 特征 | 模型生成的文本输出，域准确率 64%；仅用生成文本（不含 token 概率）结果不变 |
| 稳健性检验 | 第三个独立数据子采样运行结果稳定；black-box 预测对 LoRA rank（8–64）不敏感 |

### 实验结果
- **数据集**: 18 个公开数据集，划分为 medical、code、mathematics、non-English text、narrative prose 五个域
- **基线**: 随机猜测 20%（五域随机基线）；预注册假设为「权重 > 激活 > 输出」单调衰减
- **结果**: gray-box 61%、black-box 64%、white-box 42%（均远高于 20% 随机基线）；black-box 结果对数据子采样与 LoRA rank 稳健

### 局限性
- 仅基于单一 base model（Qwen3.5-0.8B）与小规模 LoRA 微调（58M–64M 规模学生的类比未涉及），向大模型/全参微调的迁移性摘要未说明
- 仅 5 个域、每域最多 3 次运行，域间混淆与样本量限制使 61% 与 64% 之间的差距不显著
- 仅评估域级别的指纹，未测试是否可进一步恢复数据集身份或敏感样本
- 「泄露」的隐私含义与攻击可行性边界摘要未讨论

### 关键洞见
> 模型制品携带的域指纹信息量并不随访问权限下降而下降——black-box 生成文本（64%）甚至比 white-box 权重增量统计（42%）更能揭示训练域。这说明 LoRA 微调留下的痕迹主要体现在「模型在推理时倾向说什么」，而权重增量本身反而是更嘈杂、噪声更大的证据载体；后果是，一个纯黑盒的 API 用户同样能推断服务方微调所用的数据域。
