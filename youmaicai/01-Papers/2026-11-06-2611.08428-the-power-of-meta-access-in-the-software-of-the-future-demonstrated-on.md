# The Power of Meta Access in the Software of the Future --- Demonstrated on LLM Chat UIs and Chat AI

## 摘要
Chat 仍是许多 LLM 任务的默认交互界面，但**模型看得到当前对话，看不到对话周围的工作区**。本文提出 **meta access** —— 赋予助手一个**结构化、受权限约束的界面视图**，并给出一个**阶梯**：功能引导 → 元数据/设置/偏好访问 → 对摘要与消息的检索 → 经确认的变更 → 完全编排。Meta access 可把一个多屏位的聊天客户端变成**查找、导航、组织、操作的单一入口**，同时引入接地、隐私、**提示注入**与信任方面的风险。作者指出：通用 agentic harness 本身是运行时；由于它们**能修改自己的设置**，meta access 变得**自反（reflexive）**，因而需要一个**独立的控制平面边界**。文中以 **Meta Chat** 原型（Chat AI 客户端）落地：从摘要、设置与相关消息构造有界上下文；把引用链接到会话/主题/persona；支持经确认的可逆变更；提供可浏览的教程库；以 persona 推荐开启用户发起的对话。

## 核心贡献
1. 提出 **meta access** 概念 —— 赋予助手结构化、受权限约束的**界面自身视图**
2. 给出 meta access 的**五级阶梯**：功能引导 / 元数据设置偏好访问 / 摘要与消息检索 / 经确认的变更 / 完全编排
3. 识别 **reflexivity 风险**：能改自己设置的 agent 让 meta access 自反，需**独立控制平面边界**
4. 以 **Meta Chat** 原型落地并讨论接地、隐私、提示注入、信任四类风险

## 方法与架构
**Meta access 阶梯**（自下而上）：
1. feature tutoring（功能引导）；
2. 元数据、设置与偏好访问；
3. 对摘要与消息的检索；
4. 经确认的变更（confirmed mutation）；
5. 完全编排（full orchestration）。

**Meta Chat 原型**：
- 从摘要、设置与相关消息**构造有界上下文**；
- 把引用链接到**会话、主题与 persona**；
- 支持**经确认、可逆**的变更；
- 提供**可浏览的教程库**；
- 以 **persona 推荐**开启用户发起的对话。

**安全性论证**：通用 agentic harness 是运行时；因其可修改自身设置，meta access 具自反性 → 需**独立控制平面**。

## 实验结果
- 提出并实现 **Meta Chat** 原型（Chat AI 客户端）
- 论证 meta access 可把多屏位聊天客户端变成**单一入口**
- 明确列出四类风险：**接地、隐私、提示注入、信任**
- 关键安全论点：meta access 在可自改设置的 agent 上**自反**，需独立控制平面边界（这是本文最具前瞻性的部分）
