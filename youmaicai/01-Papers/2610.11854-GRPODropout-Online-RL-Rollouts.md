## 核心贡献

> GRPO 训练 LLM 推理时常遭遇 entropy collapse（采样多样性损失）。除算法级干预外，从**rollout 使用**角度入手：选择性丢弃少量"高概率正优势 rollout"再 recenter，可"少即是多"——更高 accuracy + 更高 actor entropy + 更少 rollout 样本。

1. 提出 **GRPODropout**：在标准 GRPO 更新前，**选择性丢弃少量高概率正优势 rollout**，再 recenter 剩余优势。
2. 提出 rollout-level 理论分析，引导方法设计与阈值选择。
3. 实验：比原 GRPO **更高 accuracy + 更高 actor entropy + 更少 rollout 样本**用于更新。
4. 验证 "**Less is more**"——移除部分 rollout 反而能改善学习。
5. 代码已开源 [GitHub](https://github.com/hexuandeng/GRPODropout/)。

---

## 技术方案

### 核心思想

GRPO 等 RL 方法训练 LLM 推理时常遭遇 entropy collapse（采样多样性下降 → 探索能力受损 → 训练瓶颈）。已有方案多从算法级入手（reward 改造、entropy/KL 正则、token 级 reweight）。本文换一个角度：从**哪些 rollout 应该用于更新**入手。在同等采样预算下，并非所有 rollout 都对更新有正面贡献，选择性丢弃"高概率正优势"rollout 反而能保留探索、提高精度。

### 关键技术

| 技术 | 说明 |
|------|------|
| Selective rollout removal | 丢弃少量高概率正优势 rollout |
| Advantage recentering | 丢弃后重新居中保留 rollout 的优势 |
| Rollout-level theoretical analysis | 引导方法设计与阈值选择 |
| Cost-free modification | 不改算法主体，仅改 rollout 使用方式 |
| "Less is more" 范式 | 移除部分 rollout 反而提高精度 |

### GRPO → GRPODropout 改动示意

```
GRPO:
  rollouts → update

GRPODropout:
  rollouts → [selective removal of high-prob positive-advantage] → [recenter] → update
```

### 三大支柱

| 支柱 | 体现 |
|------|------|
| **理论** | Rollout-level analysis 给出阈值选择指导 |
| **方法** | 简单选择性丢弃 + recenter，几乎零开销 |
| **效果** | 更高 accuracy + 更高 entropy + 更少样本 |

---

## 实验结果

- 比原 GRPO **更高 accuracy**
- **更高 actor entropy**（抗 entropy collapse）
- **更少 rollout 样本**用于更新（节省）
- 多种 reasoning benchmark 验证（数学、代码）

---

## 关键 takeaway

- **Rollout 不是越多越好**：高质量但相似的 rollout 反而损害探索。
- 训练信号的**筛选**（无论 token-level / rollout-level）已成为 RL 微调 LLM 的关键工程模式。
- 算法级 + rollout-level 双管齐下，比单纯算法改进更有效。

---

## 局限性

- 阈值选择依赖 rollout-level 理论分析，实际部署需调参
- 仅在 GRPO 框架验证，其他 RL 框架（PPO / DPO）的迁移性待研究
- "丢弃多少" 的最优比例与具体任务难度耦合
