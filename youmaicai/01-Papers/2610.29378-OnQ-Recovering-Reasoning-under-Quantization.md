## 核心贡献

> 提出 **OnQ** 低比特恢复流程，融合 **on-policy distillation** 与 **candidate-wise Dynamic KL**，解决 QAT 中"固定 response 监督"导致的**轨迹发散**问题。

1. **问题 1 — 轨迹发散**：既有 QAT recipe 用 full-precision teacher 监督**固定 response 序列**，训练 prefix 与 student 实际生成 prefix 不一致，且**随 response 变长而加剧**。结果是低比特模型在 long-horizon reasoning 上仍失败，且常在 token budget 内**无法终止**。
2. **问题 2 — 分布错配**：在自己的 prefix 上，student 对某些 next-token candidate **低估**、对另一些**高估**；该错配在**高熵 prefix** 上更频繁。
3. **方案 — OnQ**：
   - 从 **block-wise calibration** 起步；
   - 量化 student **自己生成 response**，在**自己的 prefix** 上接受 full-precision teacher 监督（on-policy distillation）；
   - **Candidate-wise Dynamic KL**：按每个 candidate 的 **teacher-student 概率比**加权 forward / reverse KL，**同时纠正低估与高估**。

---

## 技术方案

| 组件 | 说明 |
|------|------|
| Block-wise calibration | 逐块校准，初始化量化权重 |
| On-policy distillation | student 自生成 prefix → teacher 在同 prefix 上监督 |
| Candidate-wise Dynamic KL | 按 p_teacher/p_student 比值对 forward/reverse KL 动态加权 |
| 核心机制 | 低估 → forward KL 加权；高估 → reverse KL 加权 |

### 关键洞见

- 固定 response 监督本质上是**off-policy**，trajectory divergence 随长度放大 → 这是低比特模型"不会停"的直接原因。
- Dynamic KL 的比值加权是**双向**的：单纯 forward KL 只惩罚高估（student 采样到 teacher 禁止区），reverse KL 处理低估。

---

## 实验结论

- **模型**：Qwen3-1.7B / 4B / 8B
- **精度**：2-bit / 3-bit
- **结果**：
  - 九基准平均分**最高**；
  - **增益最大在 long-horizon reasoning 基准**上；
  - **2-bit 下在每个模型规模、每个基准上都超过所有 baseline**；
  - Qwen3-8B 2-bit 平均 **+10.26 pp**（vs 最强 baseline）；
  - 生成**更短**，truncation 与 repetition error **更少**。

---

## 局限性

- 仅在 Qwen3 系列验证，跨架构泛化待确认；
- 依赖 teacher 可访问（不可用于完全闭源场景）；
- Block-wise calibration 本身仍是启发式。
