# Fine-Tuned Language Models Exhibit Improved Information Conveyance

> **arXiv**: [2605.30844](https://arxiv.org/abs/2605.30844)
> **发表日期**: 2026-05-29
> **分类**: cs.CL (及交叉分类 cs.AI, stat.ML)
> **会议/期刊**: NeurIPS 2026（代码：https://github.com/WeiyiTian/canopy-entropy）

## 📋 摘要

微调常被认为会降低大语言模型的不确定性与多样性，但既有分析忽略了**输出长度**这一关键混淆因素，因此未能刻画不确定性在整条生成 rollout 上是如何分布的。为解决这一问题，作者提出 **Canopy Entropy（$\mathrm{CE}^\star$）**：一个把语言生成视为**树**的度量，"canopy" 代表所有可能 rollout 构成的空间，从而使 $\mathrm{CE}^\star$ 自然地量化生成空间的有效规模。$\mathrm{CE}^\star$ 联合刻画了输出长度 $N$ 与生成序列 $Y_{1:N}$ 的不确定性——作者证明它等于总 Shannon 熵 $H(N, Y_{1:N} \mid X)$，其中 $X$ 为 prompt。这一形式化导出了若干可解释指标，其中包括**长度–熵率相关项** $\rho(N, r_N)$（$r_N$ 为熵率），用以量化信息传达效率：更长的输出是否每个 token 更有信息量。实证上，跨任务与模型家族地发现，微调后的模型普遍呈现**更正**的 $\rho(N, r_N)$ 相关性，即便其总熵是下降的。进一步地，在控制模型家族、任务、prompt 与输出长度效应之后，发现微调几乎**三倍**地增强了熵率与**语义多样性**之间的相关强度，提示对齐后的模型能更高效地把 token 级不确定性转化为语义多样性。总体结论：微调并非简单地减少不确定性，而是把不确定性**重组**为更具信息量、更具语义意义的生成。代码已开源。

## 🎯 核心贡献

1. **提出 Canopy Entropy $\mathrm{CE}^\star$**：以"生成树冠层"视角度量生成空间的有效规模，联合刻画输出长度与生成内容的不确定性。
2. **证明 $\mathrm{CE}^\star = H(N, Y_{1:N} \mid X)$**：给出严格的 Shannon 熵等价性，把直觉性指标锚定在信息论基础上。
3. **引入长度–熵率相关项 $\rho(N, r_N)$**：作为可解释的信息传达效率指标，回答"更长的回答是否每 token 更有信息量"。
4. **纠正既有认知**：微调并非只是"降低不确定性"；即使总熵下降，微调模型的 $\rho(N, r_N)$ 相关性反而普遍更正。
5. **控制混淆后更强的结论**：在控制模型家族、任务、prompt 与输出长度效应后，微调使熵率与语义多样性的相关强度**近乎三倍**（almost triples），即对齐模型更高效地把 token 不确定性转化为语义多样性。
6. **开源实现**：https://github.com/WeiyiTian/canopy-entropy。

## 🔧 方法/架构

- **树视角的生成建模**：把一次生成看作一棵 rollout 树，"canopy" = 所有可能生成轨迹构成的叶层空间；$\mathrm{CE}^\star$ 度量该空间的有效规模。
- **联合随机变量**：$X$ 为 prompt，$N$ 为输出长度，$Y_{1:N}$ 为生成序列。核心恒等式：

$$
\mathrm{CE}^\star = H\big(N,\, Y_{1:N} \mid X\big)
$$

- **长度–熵率相关项**：令 $r_N$ 为熵率（entropy rate），则

$$
\rho(N, r_N) = \mathrm{corr}\big(N,\ r_N\big)
$$

用于度量"输出变长时，每个 token 的信息量是否上升"。$\rho$ 越正，说明长输出的边际信息量越高。
- **语义多样性度量**：对同一 prompt 采样多次生成，用语义层面的多样性（如语义相似度分布的离散度）刻画，并与熵率做相关分析。
- **混淆控制**：回归/分层分析中控制模型家族、任务、prompt 效应与输出长度效应，以剥离"微调让模型变长/变短"这一混淆来源。
- **对比设置**：跨任务、跨模型家族比较 base 模型与其微调后版本的 $\mathrm{CE}^\star$ 与 $\rho$。

## 📊 实验结果

- **恒等式**：$\mathrm{CE}^\star = H(N, Y_{1:N} \mid X)$（已证明）。
- **主结果**：微调模型普遍呈现**更正的** $\rho(N, r_N)$ 相关性，即使总熵下降。
- **混淆控制后**：熵率与语义多样性的相关强度**近乎三倍（almost triples）**。
- **一致性修正**："fine-tuning does not simply reduce uncertainty, but fundamentally reorganizes it"。
- **具体数值**：摘要未给出各模型/任务的 $\mathrm{CE}^\star$、$\rho$ 绝对数值（详见原文表格与代码仓库）。

## ⚠️ 局限性

- **熵的估计成本**：需要大量采样以估计 rollout 空间的熵与熵率，计算开销高，摘要未给出估计器与样本量细节。
- **语义多样性的度量依赖具体定义**：不同语义相似度/聚类方法会显著影响"熵率–语义多样性"相关性及三倍强度的结论。
- **长度作为随机变量的处理有争议**：把 $N$ 纳入联合熵在技术上成立，但 $N$ 本身受解码策略（max tokens、提前停止）强烈影响，可能把解码配置差异误读为模型能力差异。
- **"信息传达效率"的语义较窄**：$\rho$ 只刻画长度与熵率的关系，不等于下游任务上的实际效用。
- **任务/模型覆盖**：跨任务与模型族的结论广度未在摘要中量化；是否覆盖 reasoning-heavy 模型未知。
