## 核心贡献

> 提出 **ReflectPO** —— 面向**长时程工具使用任务**中**自主错误恢复**的 RL 框架，用 **Reflection-Guided Sampling** 构造恢复信号，用 **Tree-Structured Credit Assignment** 分配 action 级信用。

1. **问题**：长时程任务含**序列依赖决策**与环境状态变化。**早期执行错误**影响后续 interaction history 与环境状态，效应沿决策链**累积**。
2. **Reflection-Guided Sampling**：利用交互轨迹中的 **branch differences（分支差异）** 与 **repeated visits（重复访问）** 构造错误恢复的 hint —— 即让 agent 学会"识别自己走偏了"。
3. **Tree-Structured Credit Assignment**：把采样轨迹组织成**树**，用 **parent–child reward 差分** + **recovery gain（恢复增益）** 分配 action 级信用。
4. **结果**：两个长时程 tool-use benchmark 上，多数领域**超过多个现有 baseline**，平均性能最佳。分析显示 agent **识别自身偏离**、从错误状态恢复、继续推进的能力均提升。

---

## 技术方案

| 组件 | 说明 |
|------|------|
| Reflection-Guided Sampling | branch diff + repeated visit → 恢复 hint |
| Tree-Structured Credit Assignment | 轨迹成树；parent–child Δreward |
| Recovery gain | 恢复后的增量作为额外信用项 |
| Action-level credit | 信用下沉到 action 而非 trajectory |

### 关键洞见

- 传统 RL 只在**终局**给 reward → 长时程中早期错误**信用稀释**。把轨迹**成树**后，parent–child 差分提供了**局部反事实**信号，这是 credit assignment 的自然解法。
- "repeated visits"作为反思信号非常实用：同一个 state 被反复访问 = 策略在该处**打转**，是需要恢复的强信号。

---

## 实验结论

- **基准**：2 个长时程 tool-use benchmark
- **结果**：
  - 多数领域优于多个 baseline；
  - **平均整体性能最佳**；
  - 自偏离识别 / 错误状态恢复 / 持续推进 三项能力均提升。

---

## 局限性

- Tree 结构构造的**采样开销**（需多分支 rollout）未量化；
- 仅 tool-use 类任务，web/OS agent 泛化待验证；
- 与 process reward / tree-search RAG 思路重叠。

## 实现建议

- **实现难度**：中高（需轨迹树 + 分支采样基础设施）

- **适用场景**：computer-use agent、workflow agent、多步 tool-use
