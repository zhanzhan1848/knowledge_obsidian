## 核心贡献

1. **问题**：dLLM 量化现有方法依赖 calibration 数据，但 dLLM 激活分布在 masking 状态和 denoising 步骤间持续漂移，校准失效。
2. **SoloQ**：将权重和激活映射到归一化的旋转基（K-RPBH），使边际分布可预测 → **无需校准**即可量化。
3. **NVFP4 支持**：post-rotation 分布规整，可直接用于硬件原生 NVFP4 格式。
4. **Block-diffusion 增强**：对 commit-time KV cache 量化，压缩持久状态而不扰动当前正在去噪的 block。

## 模型架构 / 方法

- **结构化 K-RPBH 旋转**：构造归一化旋转矩阵 H，使 XW ≈ H(X) 在新基下分布规整。
- **轻量 rescaling 校正**：补偿旋转后的分布偏差。
- **分布匹配码本 / NVFP4**：基于可预测的边际分布直接量化。
- **Commit-time KV cache 量化**：在 dLLM block 完成时刻量化持久 KV，活跃 block 不被扰动。

## 实验结果

| 模型 | 量化位宽 | 加速 / 内存 |
|------|----------|-------------|
| LLaDA (full-sequence) | 4-bit | 准确率保持 |
| Dream (full-sequence) | 4-bit | 准确率保持 |
| Fast-dLLM v2 (block-diffusion) | 4-bit | 准确率保持 |
| Nemotron-Labs-Diffusion (block-diffusion) | 4-bit | 准确率保持 |

| 关键指标 | 数值 |
|----------|------|
| NVFP4 峰值内存降低 | up to **2.61×** |
| NVFP4 端到端推理加速 | up to **2.24×** |
| 知识/推理密集型基准 | 优于 calibration-based baselines |

## 局限性

- 旋转矩阵构造开销和硬件兼容性未充分讨论（不同 GPU 后端的扩展）。
- 推理时仍需对活跃 block 维持完整精度，KV cache 压缩收益受 block size 影响。
