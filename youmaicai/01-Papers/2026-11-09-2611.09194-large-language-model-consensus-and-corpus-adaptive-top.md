# Large Language Model Consensus and Corpus-Adaptive Topic Modeling for Classifying and Mapping Patent Innovation

> **arXiv**: [2611.09194](https://arxiv.org/abs/2611.09194)
> **发表日期**: 2026-11-06
> **分类**: cs.AI (交叉分类 cs.IR)
> **会议/期刊**: arXiv preprint

## 📋 摘要

专利分析越来越依赖 transformer 表征与大语言模型（LLM），但要把**概念分类、主题形成与解释**三者串联起来，需要对"模型在各阶段扮演什么角色"以及"每阶段保留何种证据"做出明确决策。本文作为一项**设计导向的研究（design-oriented study）**，提出并演示了一条专利分析流水线，把上述任务串联起来，且**每一步决策都保持可审计（auditable）**。具体做法：用**三个 LLM 分别**对每件专利做**新颖性分类（激进 radical / 渐进 incremental）**与**创新类型分类（产品 product / 工艺 process / 服务 service）**；激进标签与创新类型标签**各自需要两票支持**，**渐进（Incremental）作为新颖性的兜底标签**。主题发现通过**聚类 PatentSBERTa 嵌入**完成，聚类参数范围**随语料规模缩放**。专利专属停用词表**仅在主题以类基 TF-IDF（c-TF-IDF）表示时启用**，并由**第二个嵌入模型**支持主题间相似度计算、**层次化细化**与可视化。最后由一个 **LLM 基于每个主题的排序关键词与代表性专利为其打标签**。作者在从 **Lens.org** 检索的 **30,964 件公共部门相关专利**上演示该流水线：在 **5 个类别语料**（规模从 **591 到 29,215** 件）上，流水线产出 **74 个类别特定的主题实例**，**宏平均文档覆盖率 98.1%**，**主题多样性 0.900–1.000**，且**分类输出中返回 UNKNOWN 的比例低于 1%**。由于**每一次模型投票以及每个主题标签背后的证据都被保留**，分析师可以审计并修订输出。该演示确立了流水线的**可行性与可追溯性**；与专家编码对照测试、以及与替代流水线的基准比较被列为后续工作。该流水线为技术情报中的 LLM 辅助专利分析提供了可复用的基础。

## 🎯 核心贡献

1. **一条端到端、可审计的专利分析流水线**：把"新颖性/类型分类 → 主题发现 → 主题解释"三个任务用**明确的模型角色分工**串起来，并全程保留证据链。
2. **多 LLM 投票 + 保守兜底机制**：三个 LLM 独立投票，激进标签与创新类型标签均需**两票**才生效，新颖性以 **Incremental 作为兜底**——在缺乏共识时偏向保守而非激进。
3. **语料自适应（corpus-adaptive）的主题发现**：聚类 PatentSBERTa 嵌入，**参数范围随语料规模缩放**，配合 c-TF-IDF 表示与专利专属停用词表，兼顾大语料与小组的稳定性。
4. **双嵌入模型分工**：主模型（PatentSBERTa）负责聚类，第二嵌入模型负责**主题间相似度、层次化细化与可视化**，避免单一嵌入承担异质任务。
5. **LLM 基于证据的主题命名**：以排序关键词 + 代表性专利作为证据让 LLM 命名主题，而非让 LLM 自由生成标签。

## 🔧 方法/架构

- **流水线**：

```math
\text{Patents} \xrightarrow{\ \text{3-LLM vote}\ }\ (\text{novelty},\ \text{innovation type})
\;\xrightarrow{\ \text{PatentSBERTa + c-TF-IDF clustering}\ }\ \text{topics}
\;\xrightarrow{\ \text{evidence-grounded LLM labeling}\ }\ \text{labeled topics}
```

- **投票与兜底规则**：对每件专利，新颖性（radical / incremental）与创新类型（product / process / service）各由三个 LLM 独立判定；激进新颖性标签与创新类型标签**均需 ≥2 票**方可采纳，否则新颖性回落到 **Incremental**：

```math
\hat{y}_{\text{novelty}} = \begin{cases}
\text{Radical}, & \#\text{votes} \ge 2\\
\text{Incremental}, & \text{otherwise (fallback)}
\end{cases}
\qquad
\hat{y}_{\text{type}} = \begin{cases}
y, & \#\text{votes} \ge 2\\
\text{UNKNOWN}, & \text{otherwise}
\end{cases}
$$

- **语料自适应聚类**：在 PatentSBERTa 嵌入上做聚类，聚类数 $k$ 的候选范围随语料规模 $N$ 线性缩放（例如 $k \propto c\sqrt{N}$ 或 $k \in [\alpha\sqrt{N}, \beta\sqrt{N}]$）；摘要未给出确切公式。

- **主题表示与停用词**：主题以 **c-TF-IDF（class-based TF-IDF）** 表示；**专利专属停用词表仅在此表示下启用**（避免在其他表示上误伤主题词）。

- **第二嵌入模型**：提供主题向量，用于**主题间相似度**、**层次化（hierarchical）主题细化**与**二维可视化**。

- **LLM 主题标注**：输入 = 主题的**排序关键词** + **代表性专利**；输出 = 主题标签。全部输入证据被持久化以供审计。

## 📊 实验结果

- **数据集**：从 **Lens.org** 检索的 **30,964 件公共部门相关专利**（public-sector-related），划分为 **5 个类别语料**，单语料规模 **591 – 29,215** 件。
- **基线**：设计导向研究，**未与替代流水线做基准比较**（作者明确列为后续工作）；也未与专家编码做对照。
- **结果**：
  - 产出 **74 个类别特定的主题实例**。
  - **宏平均文档覆盖率 98.1%**（即几乎所有文档都被分配到主题）。
  - **主题多样性 0.900 – 1.000**（各语料均接近上限）。
  - **分类输出中 UNKNOWN 比例 < 1%**。
- 摘要未给出新颖性/类型分类的准确率或与专家标注的一致性（作者明确说明这属于后续工作）。

## ⚠️ 局限性

- **作者自述的未完成项**：**尚未与专家编码对照验证标签质量**，也**尚未与替代流水线做基准比较**——因此"分类准确"目前无支撑证据，可行性已证但**有效性未证**。
- **无分类/聚类的量化质量指标**：报告的是覆盖率与多样性（且多样性接近上限 1.000，可能反映聚类近乎均匀、主题过碎），而缺少主题纯度、NMI、连贯性等常用主题模型评价指标。
- **强依赖三个 LLM 的判断质量**：投票机制只降低单次错误概率，不纠正系统性偏差（三个 LLM 共享训练数据偏差时，共识本身可能一致地错）。
- **"两票"阈值是硬编码经验值**：无敏感性分析，UNKNOWN < 1% 可能正说明阈值偏松。
- **停用词表与参数缩放规则未公开细节**：专利专属停用词表的构建过程、聚类参数的缩放公式均为实现细节，复现困难。
- **领域单一**：仅公共部门相关专利，未验证在生物医药、化学、半导体等专利密集领域的适用性。
