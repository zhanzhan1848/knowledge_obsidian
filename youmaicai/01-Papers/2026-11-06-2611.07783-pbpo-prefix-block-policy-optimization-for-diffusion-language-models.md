# PBPO: Prefix-Block Policy Optimization for Diffusion Language Models

## 摘要
**PBPO（Prefix-Block Policy Optimization）** 面向扩散式 LLM（dLLM）：dLLM 通常按 block 自回归推进、在每个 block 内迭代去噪多个 token，这使 block 级策略优化成为自回归策略优化的自然对应。但**完成 block 的精确似然是不可解的** —— 它要对中间状态与去噪揭示顺序做边缘化。本文构造 **prefix-block state**，用**单次模型评估**定义 block 似然的**因子化单步 surrogate**；所得 block surrogate ratio 是各 token surrogate ratio 之**乘积**，从而允许单个位置上的变化在 clipping 前**传播整个 block**。PBPO 保留 block 级条件，但**对每个 token 单独**施加 surrogate 重要性加权与 clipping；并通过**重采样 prompt 与已揭示前缀的损坏视图**来增加重复更新的多样性（受 masked-dLLM 预训练启发）。分析表明，block 乘积加权相对 token-local 加权会**放大梯度贡献的方差**。在两个 LLaDA 系初始化、6 个基准、3 种生成长度上，PBPO 取得有竞争力的表现。

## 核心贡献
1. 解决 dLLM **block 级策略优化的精确似然不可解**问题 —— 构造 prefix-block state，用单次模型评估给出因子化单步 surrogate
2. 证明 block surrogate ratio 是 token surrogate ratio 之**乘积**，使单点变化可在 clipping 前传播至整个 block
3. 提出 **PBPO**：保留 block 级条件 + **逐 token 重要性加权与 clipping** + 通过重采样损坏视图增加更新多样性
4. 给出理论分析：block 乘积加权相对 token-local 加权**放大梯度方差**（并明确指出这是其分析假设下的结论）

## 方法与架构
**问题**：dLLM 的 block 级轨迹似然需对中间去噪状态与揭示顺序边缘化 → 不可解。

**prefix-block state + 因子化 surrogate**：
```math
\frac{\text{surrogate}(\pi_\theta \mid s_{\text{prefix-block}})}
      {\text{surrogate}(\pi_{\text{old}} \mid s_{\text{prefix-block}})}
  = \prod_{i \in \text{block}} \frac{r_{t,i}(\theta)}{r_{t,i}(\text{old})}
```
即 block ratio 是 token ratio 之积，单点变化在 clipping 前可传播整个 block。

**PBPO 三个组件**：
1. 保留 block 级条件（不退回纯 token 级）；
2. **逐 token** 施加 surrogate 重要性加权与 clipping（而非对 block 整体 clipping）；
3. **重采样 prompt 与已揭示前缀的损坏视图**以增加重复更新的多样性（动机来自 masked-dLLM 预训练）。

**理论**：在分析假设下，block 乘积加权放大梯度贡献方差。

**实验**：两个 LLaDA 系初始化 × 6 基准 × 3 种生成长度。

## 实验结果
- **两个 LLaDA 系初始化、6 个基准、3 种生成长度**上取得**有竞争力的表现**（competitive）
- 理论侧明确：block 乘积加权相对 token-local 加权**放大梯度方差** —— 这是该设计的已知代价
- 与 masked-dLLM 预训练方式一致（损坏视图重采样）

## 局限性
- 摘要用词为「competitive」而非显著超越，说明增益幅度有限；
- 方差放大的结论**限定在其分析假设下**，实际训练稳定性未充分展示；
- 仅在 LLaDA 系初始化上验证，迁移到其他 dLLM（SD3.5、MMDiT 类）未证实。

## 值得注意的点
这篇的诚实之处在于**同时给出机制与代价**：乘积化 surrogate 让梯度能跨 block 传播，代价是方差放大 —— 论文没有回避这一点。与昨日 MEMENTO / Agent Memory 的「覆盖面 vs 效率分离」同族：**任何让信号传播更远的机制，都要在别处付账**。
