## 核心贡献

> **知识的「时间稳定性」决定了它在整个预训练过程中如何被习得** —— 提出**时间变异性分数（TVS）**：某个知识点在跨年份的模型上，其负对数似然的**变异系数**。高 TVS 的知识**在训练后期提升更快**。

1. **背景**：在跨越多年收集的网页语料上预训练的模型会学到**通用知识与领域知识**。这些不同类型的知识**在预训练进程中的习得方式**尚不清楚。
2. **方法**：利用在**不同年份网页快照**上训练的 **point-in-time 模型**，来探查知识流行度如何随时间变化。
3. **提出 TVS（temporal variability score）**：
   ```math
   \text{TVS}(x) \;=\; \frac{\mathrm{Std}_{m}\big[-\log P_m(x)\big]}{\mathrm{Mean}_{m}\big[-\log P_m(x)\big]}
   ```
   其中 $m$ 遍历各年份的模型。**更高的 TVS 意味着该知识在多年份的网页文本中可能**被**更不一致地表示。
4. **核心发现**：
   - **低 TVS 与高 TVS 的条目在训练早期学得**相似**
   - 但 **高 TVS 条目在后期提升更快**
   - **预训练结束时，高 TVS 条目在 36 个「模型 × 基准」设置中的 34 个上优于低 TVS 条目**，**平均优势为 7.3 个百分点（chance-normalized accuracy）**
   - 该模式**在知识密集型任务上最稳健**，**即使比较的是难度相近的条目**
5. **结论**：**时间变异性为预训练学习动态提供了超出聚合基准分数之外的诊断维度**

## 技术方案

### 核心思想

同一个事实在不同年份的网页上的**流行程度与表述方式**不同。point-in-time 模型（各自在某一年快照上训练）因此对同一知识点给出不同的似然。**这个差异本身就是信号** —— 它衡量的是「这个知识的稳定程度」。

```text
年份:    2020    2021    2022    2023    2024    2025
某知识:  0.05    0.02    0.31    0.08    0.40    0.04   ← 高 TVS（不稳定）
某知识:  0.10    0.10    0.10    0.10    0.10    0.10   ← 低 TVS（稳定）
              ↓
   TVS = 变异系数 = NLL 的 std / mean
```

### 关键技术

| 技术 | 说明 |
|------|------|
| **Point-in-time 模型** | 在不同年份网页快照上分别训练的模型 |
| **TVS（时间变异性分数）** | NLL 跨模型的变异系数 |
| **Chance-normalized accuracy** | 消除猜测基线的准确率度量 |
| **跨模型 NLL 收集** | 对每个知识条目收集所有年份模型的负对数似然 |
| **早/后期学习曲线对比** | 分阶段追踪高/低 TVS 条目的学习速度 |
| **难度匹配分析** | 控制条目难度后仍成立 |

## 公式

```math
\text{时间变异性分数}:\quad
\text{TVS}(x) \;=\; \frac{\displaystyle\sqrt{\frac{1}{M}\sum_{m=1}^{M}\big(-\log P_m(x) - \overline{NLL}(x)\big)^2}}
{\displaystyle\overline{NLL}(x)},
\qquad
\overline{NLL}(x) \;=\; \frac{1}{M}\sum_{m=1}^{M} -\log P_m(x)
```

```math
\text{Chance-normalized accuracy}:\quad
\text{CNA} \;=\; \frac{\text{Acc} - \text{Acc}_{\text{chance}}}{1 - \text{Acc}_{\text{chance}}}
```

```math
\text{学习速度对比}:\quad
\Delta\text{CNA}(x;\, t_1 \to t_2) \;=\; \text{CNA}_{t_2}(x) - \text{CNA}_{t_1}(x)
\qquad
\text{期望（高 TVS）}:\; \Delta\text{CNA}_{\text{high}} > \Delta\text{CNA}_{\text{low}}
\;\text{在后期}
```

```math
\text{知识流行度代理}:\quad
\text{Popularity}(x, y) \;=\; \frac{1}{M}\sum_{m} P_m(x \mid y)
\qquad
\text{TVS 与流行度波动负相关}
```

## 代码片段

```python
# 概念性伪代码：TVS 计算与学习动态追踪
import numpy as np
import torch

def compute_tvs(items, pit_models):
    #     items:       知识条目列表（文本 / 问题）
    #     pit_models:  dict[year] -> model（各年份快照训练的 point-in-time 模型）
    #     返回:        每个条目的 TVS
    nll_per_item = []
    for item in items:
        nlls = []
        for year, model in pit_models.items():
            with torch.no_grad():
                lp = model.log_prob(item)          # -log P_m(x)
            nlls.append(lp.item())
        nll_per_item.append(nlls)

    nll = np.array(nll_per_item)                  # (N_items, M_years)
    mean = nll.mean(axis=1)
    std  = nll.std(axis=1)
    tvs  = std / np.maximum(mean, 1e-9)           # 变异系数
    return tvs


def track_learning_dynamics(items, tvs, checkpoints):
    #     checkpoints: dict[t] -> model（训练过程中的 checkpoint）
    #     比较高/低 TVS 条目在各阶段的 chance-normalized accuracy。
    high = [i for i, v in enumerate(tvs) if v >= np.median(tvs)]
    low  = [i for i, v in enumerate(tvs) if v <  np.median(tvs)]

    curve = {}
    for t, ckpt in checkpoints.items():
        acc = evaluate_accuracy(ckpt, items)          # (N_items,)
        cna = chance_normalize(acc, items)
        curve[t] = {
            "high_tvs_cna": cna[high].mean(),
            "low_tvs_cna":  cna[low].mean(),
            "gap":          cna[high].mean() - cna[low].mean(),
            # 关键观察：gap 随训练推进而扩大
        }
    return curve


def chance_normalize(acc, items):
    # 按每个条目的猜测基线归一化。
    chance = np.array([guess_baseline(it) for it in items])
    return (acc - chance) / np.maximum(1 - chance, 1e-9)
```

## 实验结论

- **模型**: **6 个**，来自多个开源家族（point-in-time 模型）
- **基准**: **6 个**，覆盖多样主题
- **核心结果**:

| 观察 | 结果 |
|------|------|
| **早期（学习速率）** | 高 TVS 与低 TVS **学得相似** |
| **后期（学习速率）** | **高 TVS 提升更快** |
| **预训练结束时的表现** | 高 TVS 条目在 **34 / 36** 个「模型 × 基准」设置中优于低 TVS |
| **平均优势** | **+7.3 个百分点**（chance-normalized accuracy） |
| **最稳健的场景** | **知识密集型任务**（即使匹配难度后仍成立） |

## 局限性

1. **强依赖 point-in-time 模型的存在** —— 需要**在多个年份快照上分别训练的模型**。这类模型不是随处可得（本文作者显然有额外资源）；**多数团队无法复现**
2. **「高 TVS → 学得快」是相关还是因果** —— 摘要只报相关。可能的混淆：TVS 高的条目**可能恰好是罕见的/长尾的**，罕见事实天然更难但也更「值钱」？论文说「即使匹配难度后仍成立」，但难度匹配如何做的未说明
3. **平均优势 7.3 个百分点** —— 方向一致性强（34/36）比幅度更可信
4. **条目与基准的构造** —— 「6 个基准覆盖多样主题」下如何切分条目、条目数多少，均未说明
5. **NLL 跨模型的比较有效性** —— 不同年份模型的 tokenizer 与归一化不同，**跨模型 NLL 直接可比性存疑**
6. **TVS 与「流行度波动」可能只是同一现象的两种说法** —— 未与直接的流行度代理变量做区分
7. **实用价值未充分展开** —— TVS 被提议为「诊断维度」，但**如何用它来改进预训练**（如数据配比、课程设计）没有给出方法
8. **模型规模未知** —— 若都是小模型，知识习得的动态可能不同

## 实现建议

- **实现难度**: 中（TVS 计算简单，难点是获得多年份 point-in-time 模型）
- **预期性能**: 不产生模型性能提升；产出**预训练过程诊断**
- **适用场景**:
  - **有多个年份快照模型的研究团队** —— 可直接复用
  - **做数据配比 / 课程设计的团队** —— TVS 作为一个新维度可能有用
  - **知识时效性研究** —— 时间变异性与「幻觉」可能有联系（值得自行探索）
- **落地注意**:
  1. **先确认能否拿到 PIT 模型** —— 这是硬前提。拿不到的话，TVS 的思路可以对「不同 checkpoint」做类比（近似，但语义不同）
  2. **TVS 本身是个可复用的诊断量** —— 计算成本极低，值得作为常规指标
  3. **注意 NLL 跨模型可比性** —— 如果用不同 tokenizer 的模型，要先做归一化校准
  4. **探索方向：TVS 与知识幻觉的相关性** —— 摘要没提但很自然：不稳定时代表的知识，模型是否更容易「编」？这个假设值得测

## 我的评注

> 这篇的方法很巧：**用一个「本该是噪声的量」来定义「知识的稳定程度」**。
>
> point-in-time 模型系列给出的是同一个事实在不同年份的不同概率。直觉上这像是噪声 —— 但论文说对了：**这个波动本身携带信息**。事实越「新」或越「有争议」，它的 NLL 在年份间波动越大；越稳定的事实（比如「水在 100°C 沸腾」），波动越小。于是 TVS = 变异系数就成了「这个知识点有多稳定」的度量。
>
> 结论也有意思：**早期学得一样，后期高 TVS 跑得快**。这个模式意味着 —— 高 TVS 知识**不是更早被学会，而是被更彻底地学会**。一个可能的解读是：不稳定的事实有更多不同的表述形式，需要模型在多个模式下都覆盖才能稳定输出；而稳定事实学一次就够了。
>
> 最强的证据是**「即使匹配难度后仍成立」**这一句 —— 它排除了「高 TVS 只是碰巧是难条目」的简单解释。而且 34/36 的方向一致性（远超随机）比 7.3 个点的平均幅度更可信。
>
> 保留意见：
> - **可复现性是硬伤**。需要 6 个按年份快照训练的模型 —— 这是**只有少数团队才有的资源**（作者显然有）。对社区的实际影响因此受限。
> - **相关 vs 因果**没完全排除。TVS 高可能与「罕见」「长尾」「新颖」高度相关，而罕见知识天然有独特的习得轨迹。我希望看到更细的控制。
> - **「诊断维度」到「改进手段」之间缺一步**。论文说 TVS 提供超出聚合分数的诊断，但没给「如何用 TVS 改善预训练」的方案。数据配比？课程学习？加高 TVS 内容的采样权重？这些都显然可行，但论文停在诊断。
>
> 有一个想法摘要没提但我觉得很值得追：**TVS 与幻觉的相关性**。如果一个知识在模型里「不稳定」，那么模型在需要它时更可能**编造**而不是正确回忆 —— 这是关于幻觉的一个可操作的假设（现在幻觉研究里有「memGap」「doLa」等相似思路，但都以 token 概率为对象，TVS 给了**跨年份**这个新维度）。值得自测。
