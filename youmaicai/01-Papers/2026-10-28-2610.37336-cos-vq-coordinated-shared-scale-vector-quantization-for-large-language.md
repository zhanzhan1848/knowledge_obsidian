## 核心贡献

> **不靠增加码本维度、而靠「联合优化硬索引 + 共享尺度」来提升低比特 VQ 精度** —— 把 VQ 从「逐点独立编码」变成一个**带全局耦合的组合优化问题**。

1. **指出 VQ 现有做法的代价**：多数 VQ 方法靠**提高有效编码维度（effective coding dimension）**来换精度，但这会**破坏独立查找**与**局部码本更新**两项关键工程属性。
2. **识别核心难点 —— scale-induced coupling（尺度诱导耦合）**：
   - 最优尺度取决于**整个码字组合**，而非单个位置
   - 最优尺度一旦改变，**各位置的候选排序也随之改变**
   - ⇒ **逐点更新（pointwise update）在尺度重优化之后依然会停滞（stall）**
3. **提出 CoS-VQ**：
   - 保持**低维码字**，**联合优化**跨位置的硬索引与其**共享尺度**
   - 在**多个探测尺度（probe scales）**上收集候选
   - 为「残差感知的二次目标」构造**切线可分上界（tangent separable upper bound）**
   - 把候选比较**归约为正尺度域上直线的下包络（lower envelopes of lines）**
   - 从而识别出**有限个代表性区间**用于联合索引-尺度更新，**无需穷举码字组合**
4. **实验验证**：在 Qwen3.8-27B 上**优于 QTIP 与 LLVQ**（语言建模、代码、推理基准）。消融显示：**联合更新的增益大于仅做尺度精调**。

## 技术方案

### 核心思想

传统 VQ 把权重矩阵切成小块，每块独立编码为「码本索引 + 标量尺度」。CoS-VQ 指出：这个分解**不成立** —— 因为尺度是**跨块共享**的，一个块的尺度变化会改变所有块的候选排序。于是问题变成**组合优化**，而贪心逐点更新会卡住。

CoS-VQ 的破解思路：用几何手段把组合搜索**降维成有限区间划分**。

```text
❌ 传统 VQ 逐点更新:
   for 每个位置 p:
       固定 scale → 选最优 index → 固定 index → 重优化 scale → (尺度变了!)
       → 各位置候选排序被全局尺度改变 → 停滞

✅ CoS-VQ 联合更新:
   收集多个 probe scale 下的候选集
   → 构造 residual-aware 二次目标的 tangent separable 上界
   → 候选比较 ⟶ 正尺度域上的直线下包络
   → 划分出有限个代表性区间
   → 在区间上做联合 index–scale 更新（不穷举码字组合）
```

### 关键技术

| 技术 | 说明 |
|------|------|
| **共享尺度（shared scale）** | 跨位置共享的标量尺度，引入全局耦合 |
| **探测尺度（probe scales）** | 在多个尺度上收集候选，避免单一尺度的局部最优 |
| **切线可分上界** | residual-aware 二次目标的松弛上界，把耦合问题可分离化 |
| **直线下包络** | 候选比较归约为正尺度域上线的下包络，求得有限临界区间 |
| **有限区间联合更新** | 在代表性区间内联合求 (index, scale)，避免组合爆炸 |
| **低维码字保持** | 不提升 effective coding dimension，保留独立查找与局部更新 |

## 公式

```math
\text{目标（residual-aware 二次型）}:\quad
\min_{\mathbf{i}, s}\; \Big\| W - \big[\, s \cdot C_{\mathbf{i}} \,\Big] \Big\|_F^2
```

其中 $C_{\mathbf{i}} \in \mathbb{R}^{d \times K}$ 为码本，$s$ 为跨位置共享尺度。

```math
\text{切线可分上界}:\quad
F(\mathbf{i}, s) \;\le\; \sum_{p} \Big[ \, \alpha_p \, \big\| W_p - s\, C_{i_p} \big\|^2 + \beta_p \Big]
```

```math
\text{候选比较归约}:\quad
\big\| W_p - s\, C_{i_p} \big\|^2
\;=\; \underbrace{\|W_p\|^2}_{const} \;-\; 2s\langle W_p, C_{i_p}\rangle \;+\; s^2\|C_{i_p}\|^2
\;\equiv\; \text{直线 } \ell_{p,i_p}(s) \;\text{的下包络}
```

线性化后，对候选集合取 $\min_i \ell_{p,i}(s)$ 即为**下包络**，其断点（斜率变化处）给出**有限个临界尺度区间** —— 这是避免穷举码字组合的关键。

## 代码片段

```python
# 概念性伪代码：CoS-VQ 的联合 index–scale 更新
def joint_update(W, codebook, probe_scales):
    # 1) 在多个 probe scale 上收集候选索引
    cands = []
    for s0 in probe_scales:
        for p in range(W.shape[0]):
            residual = W[p] - s0 * codebook        # (d, K)
            cands[p].append(residual.argmin(axis=1))

    # 2) 构造切线可分上界 → 直线下包络
    #    每个候选对应一条线 ℓ_{p,i}(s) = a·s + b
    lower_env = [lower_envelope(lines) for lines in cands]

    # 3) 找有限个临界尺度区间（断点）
    breakpoints = sorted({bp for env in lower_env for bp in env.breakpoints()})

    # 4) 在每个代表性区间上做联合 (index, scale) 求解
    best = None
    for (lo, hi) in adjacent_intervals(breakpoints):
        idx = argmin_over_interval(lower_env, lo, hi)   # 区间内序不变
        s_star = solve_scalar(idx, lo, hi)              # 区间内闭式解
        cand = evaluate(W, codebook, idx, s_star)
        best = min(best, cand, key=lambda x: x.loss)

    return best.index, best.scale
```

## 实验结论

- **模型**: Qwen3.8-27B
- **基线**: QTIP, LLVQ（现有低比特 VQ 方法）
- **基准**: 语言建模、代码、推理类基准
- **结果**:
  - CoS-VQ **全面优于 QTIP 与 LLVQ**
  - 消融（同初始化）：**联合更新的增益 > 仅尺度精调**
  - 结论：**联合选择是「提高码本维度」之外的一条可行路径**

## 局限性

1. **仅验证单一模型规模**（Qwen3.8-27B）—— 未见在小模型与不同架构上的泛化性证据
2. **切线可分上界引入松弛** —— 上界的紧致程度决定了实际最优性损失，摘要未给松弛误差的量化
3. **「有限个代表性区间」的规模未给** —— 区间数随候选数增长的实际复杂度需读正文
4. **联合优化的实际计算开销**（区间遍历 + 闭式求解）未披露
5. **「保持低维码字」的自始至终代价** —— 摘要未给码本尺寸 / 维度与 QTIP、LLVQ 的直接对照
6. 无 **KV cache 量化**讨论 —— 标题聚焦 weight quantization，推理加速的另一半未覆盖

## 实现建议

- **实现难度**: 高（需要上界推导、线性化、下包络构造、区间化求解）
- **预期性能**: 摘要称优于 QTIP / LLVQ，需自行在目标模型上验证
- **适用场景**: **27B 级以上模型的高比特压缩需求**（显存吃紧的私有化部署、单机推理）
- **落地注意**:
  1. 这是**权重侧**压缩，不解决 KV cache 占用，推理显存优化需配套 KV 量化
  2. 码本初始化与校准集选择影响很大，建议先复现 QTIP 基线再对比
  3. 联合更新的求解是**离线一次性**过程，推理时零开销 —— 这是它相对在线方法的实用优势

## 我的评注

> 这篇的价值在于**把一个工程问题还原成了数学问题**。VQ 量化里「尺度是共享的」这件事一直被当作可忽略的实现细节，CoS-VQ 指出它其实制造了**全局耦合**，导致所有局部贪心方法都有停滞风险。
>
> 最漂亮的一步是**把候选比较归约成直线下包络**。二次目标的线性化在这里几乎是天然的：残差平方展开后正好是关于 $s$ 的二次函数，取候选最小值就成了下包络。而下包络的**断点结构**天然给出「在哪些区间内候选排序不变」—— 于是组合优化被切成有限个互不干扰的小块，每块内闭式求解。这跟用「分块 + 交替优化」硬扛是不同量级的优雅。
>
> 「联合更新 > 单纯加维度」这个结论有方法论意义：它说明当前 VQ 竞赛里**大家默认的「多开维度」其实是绕路**，真正的收益在耦合处理本身。
>
> 保留意见：只测了一个 27B 模型和一个模型家族，上界松弛的紧致性没量化。**这类「精巧的优化技巧 + 窄验证」的组合，需要警惕规模化后的稳定性**。另外它跟 MuonGS（[[2610.37647]]）同批次，一个从优化器侧、一个从压缩侧入手，思路都是「找到那个被默认忽略的耦合结构」—— 这可能是本批次的一个共同审美。
