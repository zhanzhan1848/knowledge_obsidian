## 核心贡献

1. **3 层 typed experience graph**：atomic skills & code snippets / task workflows / generalized meta-frameworks，typed edges 连接
2. **5 个自维护机制共用一个 similarity geometry**：
   - multi-dimensional similarity（按 operation + target 评分）
   - typed reflector（成功 → procedure，失败 → pitfalls）
   - community detection → meta-frameworks
   - pressure-triggered GC + articulation-point 保护
   - **contrast edges**（flag confusable but direction-opposite experiences）
3. **两个 prior memory failure mode 的 explicit isolation + fix**

## 方法

### 3 层结构

```
atomic skills (code snippets)
     ↓ typed edge
task workflows
     ↓ typed edge
meta-frameworks (community-detected)
```

### 5 个 self-maintenance 机制

1. **Multi-dimensional similarity**：`sim(op, target)` 而非 `sim(embedding)`
2. **Typed reflector**：从轨迹中抽取 typed lessons（succ → procedure，fail → pitfall）
3. **Community detection**：induce meta-frameworks from recurring patterns
4. **Pressure-triggered GC**：memory pressure 高时清理冗余，articulation-point 保护
5. **Contrast edges**：标记 confusable but direction-opposite experiences，避免 negative transfer

### 修复的 prior failure modes

- Single-level memory 在 task set 增大时 **sharp drop**
- Single-level concrete memories **catastrophic negative transfer**（similar 反向经验的步骤 verbatim 抄）
- Contrast edges 把 ScienceWorld **78.7 → 96.7**

## 实验结果

- 4 interactive benchmarks：AppWorld / WebArena / ALFWorld / ScienceWorld
- 2 frozen backbones × 7 baselines
- **STRATA 平均分最高 + 最低延迟 + 最少环境 steps**
- 比最强 context-hungry baseline **少 44% injected memory lines**

## 局限性

- 仍是 frozen backbones + memory-only adaptation，未涉及 policy / weights 更新
- Community detection 的 granularity 需要人工设定
- Contrast edges 需 detect "direction-opposite"，对 embedding 噪声敏感

## 建议

- **是否推荐使用**：是
- **适用场景**：long-horizon agent / web agent / interactive agent 自演化 memory backend
- **推荐路径**：替换现有 vector DB / single-level memory 的 agent framework
- **运营价值**：explicit failure mode isolation → 调试与可控性
