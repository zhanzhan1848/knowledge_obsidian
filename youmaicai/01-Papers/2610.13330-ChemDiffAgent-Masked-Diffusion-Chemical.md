## 核心贡献

> 提出 **ChemDiffAgent** —— 首个 masked diffusion language agent，将化学推理重新表述为"interleaved reasoning + tool-use 轨迹的迭代去噪"，打破 autoregressive agent 的 causal attention 与 left-to-right 限制。

1. **首个 masked-diffusion agent**: 工具决策在全轨迹上下文下联合确定
2. **双向分子理解**: 不受 left-to-right 因果 mask 限制
3. **Two-stage post-training**: agentic SFT + agentic RL

---

## 技术方案

### 核心思想

现有化学 agent 几乎都是 autoregressive paradigm，受 causal attention + left-to-right generation 制约，难以处理分子全局结构与多源证据整合。Masked diffusion 允许**双向 / 任意顺序**生成，更契合化学推理。

### 关键技术

| 技术 | 说明 |
|------|------|
| Masked diffusion backbone | 取代 AR LM，支持 infilling |
| Iterative denoising over trajectories | reasoning ↔ tool-use 联合去噪 |
| Full-trajectory tool decision | 决策边界与知识边界对齐 |
| Harder infilling subproblems | 训练时构造更难子任务 |
| Arbitrary-order decoding | 推理时灵活解码 |
| Two-stage post-training | SFT + RL |

### 关键优势

- 不被 causal attention 限制 → 全局协调工具规划
- 多源证据整合（molecular + textual + tool output）
- Decision boundary 与 knowledge boundary 对齐

---

## 实验结论

- **数据集**: 多个化学 reasoning 任务
- **模型**: ChemDiffAgent（masked diffusion base + post-training）
- **结果**:
  - 相对 AR 化学 agent baseline 提升
  - 两阶段 post-training 显著优于纯 SFT

---

## 局限性

- Masked diffusion backbone 仍是新兴架构，工程栈不成熟
- 化学领域外泛化未充分验证
- 推理 compute 成本可能高于 AR（多轮去噪）

---

## 实现建议

- **实现难度**: 高（需要 diffusion LM 训练栈）
- **预期性能**: 化学 reasoning SOTA；理论可推广到材料/生物 agent
- **适用场景**: 需要双向/全局推理的 agentic 任务；多源证据融合
