# BiG-SURE - Bipartite Graph for Semantic Uncertainty and Reliability Estimation of LLMs

> **arXiv**: [2608.30646](https://arxiv.org/abs/2608.30646)
> **发表日期**: 2026-08-31
> **分类**: cs.CL (及交叉分类 cs.AI, cs.LG)
> **会议/期刊**: EMNLP 2026 Main Conference (Oral presentation)

## 📋 摘要

在安全关键场景中部署 LLM/VLM 时，可靠的不确定性估计不可或缺，尤其当模型参数不可访问（黑盒）时，难以直接从 logits 或 logprob 提取置信信号。本文提出 **BiG-SURE**，一种基于"跨温度语义一致性"的黑盒不确定性估计器。其核心思路是：把**低温采样**的回复当作稳定的**语义锚点（anchor）**，把**高温采样**的回复当作**探针（probe）**，并施加**保义输入变换**后，用 NLI 蕴含分数构建 anchor-probe **二部图（BiG）**。置信度被定义为该二部图邻接矩阵的**归一化平方谱能量（normalized squared spectral energy）**，不确定性则为该量的补。BiG-SURE 实质上衡量的是：高温探针是否仍与模型稳定的低温信念保持语义对齐。作者在文本 QA、多语言 QA 与多模态 QA 任务上、跨多个模型族进行了评测，结果显示 BiG-SURE 在平均**弃答 AUROC（abstention AUROC）** 上优于既有黑盒不确定性估计方法，同时保持**简单、无监督、适用于纯黑盒设定**的特性。

## 🎯 核心贡献

1. **BiG-SURE 估计器**：提出一个完全**无监督、无需访问 logits** 的语义不确定性度量，面向纯黑盒 API 场景。
2. **跨温度语义一致性机制**：以低温回复为"信念锚点"、高温回复为"语义探针"，把采样随机性转化为可度量的语义分歧信号，而非依赖概率值。
3. **二部图谱能量建模**：用 NLI 蕴含分数构建 anchor-probe 二部图，把置信度定义为邻接矩阵的**归一化平方谱能量**，不确定性取其补——为语义一致性提供了谱图视角的连续打分。
4. **多任务多模态验证**：在文本 QA、多语言 QA、多模态 QA 上跨多个模型族评测，平均 abstention AUROC 优于既有黑盒估计器。
5. **零训练成本**：方法完全训练无关，可即插即用于已有商业/API 模型，无需访问参数或 logits。

## 🔧 方法/架构

- **锚点-探针采样**：
  - Anchor：从**低温（low temperature）**采样得到的回复，代表模型的稳定语义信念；
  - Probe：从**高温（high temperature）**采样得到的回复，携带模型的不确定性与语义抖动。
- **保义输入变换（meaning-preserving transformations）**：在生成 probe 时对输入施加保持语义的变换，进一步丰富探针视角，迫使模型暴露语义分歧而非表层差异。
- **二部图构建**：以 NLI（自然语言推理）模型计算 anchor 与 probe 之间的**蕴含分数**，作为二部图的边权/邻接矩阵元素；节点一侧为 anchor 集合，另一侧为 probe 集合。
- **置信度定义**：将邻接矩阵的**归一化平方谱能量**作为置信度分数，语义对齐越强，谱能量越高、置信度越高；**不确定性 = 1 − 置信度**。
- **下游用法**：置信度可用于**弃答（abstention）**策略——低置信度时拒答或转人工，是安全关键部署的核心机制。
- **实现形态**：无监督、无需训练参数；依赖一个 NLI 推理器（可与被评估模型解耦）。

```math
\text{Conf}(\text{BiG}) \;=\; \frac{\lambda_1^2\!\left(A^{\top}A\right)}{\sum_i \lambda_i^2\!\left(A^{\top}A\right)}
\quad\text{where } A_{ij} = \text{NLI-entail}(\text{anchor}_i, \text{probe}_j)

\text{Uncertainty} = 1 - \text{Conf}(\text{BiG})
```

## 📊 实验结果

- **数据集/任务**：文本 QA、**多语言 QA**、**多模态 QA**，覆盖多个模型族。
- **基线**：既有的黑盒不确定性估计方法（prior black-box uncertainty estimators）。
- **结果**：**平均 abstention AUROC 优于所有对比基线**；摘要未给出具体 AUROC 数值、各数据集分项分数与模型族清单。
- **资源开销**：训练无关；推理期需低温+高温多次采样与 NLI 判定（摘要未给出额外采样次数）。

## ⚠️ 局限性

- 严重依赖 **NLI 模型**的蕴含判断质量：NLI 本身是模型，引入额外误差源与推理成本；摘要未分析 NLI 误差对最终 AUROC 的敏感性。
- 需要**多次采样**（低温 + 高温，且对每个 probe 施加保义变换），推理开销高于单次前向；对高 QPS 场景可能不经济（摘要未给出采样次数与延迟数据）。
- 高温采样在**部分模型上可能系统性退化**（如输出崩坏或重复），会稀释语义一致性信号，摘要未讨论此鲁棒性。
- 摘要**未给出具体数值**（AUROC 绝对值、各任务分项、模型规模），也未报告在 open-ended 生成（无明确正确答案）场景下的有效性——abstention AUROC 依赖有标注答案的任务。
- 方法本身不区分**"模型不确定"与"任务本身歧义"**，也未与"正确答案概率"类 oracle 信号对比。

## 💡 建议

- 是否推荐使用：**是**（作为黑盒 API 场景下的免训练安全兜底信号，尤其配合 abstention 流程）
- 适用场景：仅能通过 API 调用商用 LLM/VLM（拿不到 logits/参数）的安全关键场景，如医疗、法律、客服转人工的自动拒答决策；也适合需要低成本上线不确定性估计的团队。前提是能接受额外采样 + NLI 推理的开销，并愿意用额外的 NLI 模型承担误差。
