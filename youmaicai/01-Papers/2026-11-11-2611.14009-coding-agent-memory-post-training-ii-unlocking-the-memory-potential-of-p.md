## 核心要点
1. 指出既有 OPD 让记忆控制进入策略，但**依赖的内存工具与压缩协议存在于两个模型的预训练之外**——这**同时削弱了蒸馏两侧**：教师无法在自己没用过的接口上给出有用指导，学生也采样不出足够多的有意义的记忆动作让指导生效。
2. **CAMG-II**：覆盖 Shop / Coding / AutoResearch / General / Visual 五个长程 agentic-RL 环境，除原生任务接口外提供**普通 Bash 访问**与**跨上下文替换保持的 episode 持久工作区**。
3. **CAMP-II**：单一策略跨全部五个环境联合训练，**完全异步的 OPD**，从**对文件操作有先验的冻结教师**学习基于文件的记忆行为。
4. 在 CAMG-II 上取得**最强 OPD 基线 2.97 倍的增益**。
5. 泛化到 **Terminal-Bench 2.1** 与 **SWE-Bench Pro V2**，成功率提升。

## 摘要（原文）
Language-model agents increasingly tackle long-horizon tasks whose interaction histories exceed the
model's active context. They must therefore decide what to write down and what to read back, and
when to do either. Recent work has begun to use on-policy distillation (OPD) to make memory control
part of the policy, relying on memory tools and compaction protocols that lie outside either model's
pre-training. However, this weakens the distillation on both sides: the teacher cannot give useful
guidance on an interface it has never used, and the student samples too few meaningful memory
actions for that guidance to take effect. To study this problem, we introduce Coding Agent Memory
Gym II (CAMG-II), a suite of long-horizon agentic-RL environments spanning Shop, Coding,
AutoResearch, General, and Visual. Alongside each environment's native task interface, CAMG-II
provides ordinary Bash access and an episode-persistent workspace, enabling the policy to create,
revise, search, and reuse files as memory across context replacements. We also introduce Coding
Agent Memory Post-Training II (CAMP-II), which trains a single policy jointly across all five
environments with fully asynchronous OPD to learn this file-based memory behavior directly from a
frozen teacher with a prior for file operations. On CAMG-II, CAMP-II obtains 2.97 times the gain of
the strongest OPD baseline. The memory behavior CAMP-II learns generalizes to two external
benchmarks, Terminal-Bench 2.1 and SWE-Bench Pro V2, with improved success rates.
