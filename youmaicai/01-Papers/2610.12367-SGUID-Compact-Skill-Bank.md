## 核心贡献

> 在 LLM on-policy skill 蒸馏中，<25% 的检索 skill 真正有用；提出 SGUID 选择"6 个有效 skill"匹配 / 超过 11× 大的完整 skill bank，并把 model-skill co-evolution 从不稳定转为稳定增益。
1. 揭示 on-policy skill 蒸馏中**单个 skill 的真实效用被忽略**：< 25% 检索 skill 提供有效蒸馏信号。
2. 提出 **SGUID**：保留"训练中持续产生有效学习信号"的 skill 集合，其余丢弃。
3. 在 4 个 Olmo / Qwen 家族模型上，**6 个 selected skills** 与 **11× 大 full-bank** 蒸馏效果匹配或超越；第 2 轮再加 3 个新 skill 即可在所有 4 模型上超越 full-bank。
4. 关键洞察：**skill 选择是 model-skill co-evolution 稳定性的核心机制**。无筛选会让 Qwen3-4B 退化 0.015%（HMMT25 下降 0.3 pp），有筛选则持续提升（HMMT25 +0.5 pp/+1.1 pp）。
5. **Qwen3-8B** 第 2 轮 SGUID 后从 **64.3% → 66.3%**。

---

## 技术方案

### 核心思想

Skill bank 中并非所有 skill 都对蒸馏有价值。SGUID 把"skill 是否保留"作为**训练中动态决策**，每个训练 step 评估"该 skill 是否贡献有效学习信号"，持续贡献者保留，无效者丢弃。让 model 和 skill 共同演化（co-evolution），但用严格的稳定性筛选保证每次只"内化"少量高质量 skill。

### 关键技术

| 技术 | 说明 |
|------|------|
| On-policy distillation | skill-conditioned policy 作为 teacher，蒸馏到 student |
| Skill utility signal | 训练中观测每个 skill 是否带来有效梯度信号 |
| SGUID selection | 保留"持续有效"的 skill 集合；其余丢弃 |
| Co-evolution loop | 蒸馏一轮 → 用新模型 rollout 重构 skill bank → SGUID 再选 → 再蒸馏 |
| Compact bank | 远小于 full bank（如 6 vs 60+），但效果匹配 / 超过 |

### Co-evolution 流程

```
Round 1: 
  bank_v1 = initial skill bank (e.g. 60 skills)
  selected_1 = SGUID(bank_v1) → 6 skills
  model_v2 = distill(model_v1, selected_1)

Round 2:
  bank_v2 = skills_curated_from(model_v2.rollouts)
  selected_2 = SGUID(bank_v2) → 3 new skills
  model_v3 = distill(model_v2, selected_2)
  ...
```

## 实验结果

- **4 模型 × 2 家族**：Olmo / Qwen 系列
- **Round 1**：6 selected skills 匹配/超过 full-bank（full bank 可达 11× 大）
- **Round 2**：3 new skills 在所有 4 模型上超越 full-bank
- **Qwen3-8B**：64.3% → 66.3%（+2.0 pp）
- **Qwen3-4B SGUID 增益**：HMMT25 +0.5 pp（R1）→ +1.1 pp（R2）
- **Qwen3-4B 无 SGUID 对照**：HMMT25 **-0.3 pp**（稳定性破坏）

---

## 关键 takeaway

- **Skill 数量 ≠ 效果**：skill bank 大小不是越多越好，关键是有效 skill 的密度。
- **选择是稳定 co-evolution 的核心**：没有筛选，每次更新可能引入退化。
- Co-evolution 让 skill bank 与模型能力共同进化，是比"一次性完整 bank 蒸馏"更稳健的路径。

---

## 局限性

- 评估集中于 reasoning 类 benchmark，未覆盖 safety / 多语言 / 长上下文等
- 6 个 selected skills 的具体内容 / 类型分布未深入分析
- 跨家族迁移性（Olmo→Qwen）尚未验证
