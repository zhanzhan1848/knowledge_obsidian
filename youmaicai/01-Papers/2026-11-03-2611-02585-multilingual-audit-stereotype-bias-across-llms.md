## 核心贡献
1. **构建了一个多语言、原生写成的刻板印象审计语料**：**12,000 条本地撰写的 Reddit 帖子**，覆盖**英语、西班牙语、法语、德语**；关键设计是**只翻译检索词（search terms）**，从而保留本地语境。
2. **按语言与刻板印象类别平衡的采样设计**：数据集在语言与类别上平衡，**英语性别类额外按刻板印象效价（valence）平衡**。
3. **引入"双空白"（two-blank）设计以削弱语法性别线索**（grammatical-gender cues）的干扰。
4. **对 3 个开放权重模型 + 3 个专有 API 模型做跨模型跨语言审计**，得到语言 / 国家语境 / 效价三个维度的系统性模式。
5. **关键的自我约束**：明确声明所测指标衡量的是**选择集中度（choice concentration）**，**不是刻板印象认同（stereotype endorsement）**，也**不是因果的国家效应（causal country effects）**——把"测量到什么"与"没测量什么"讲清楚。

## 问题背景
大语言模型正被考虑用于教育、招聘、工作场所决策支持等**后果性应用**，因此部署前的社会偏见检测是必要的。但现有主流基准存在三重缺陷：**以英语为中心或采用翻译（English-centred or translated）**——翻译会破坏语言自身的语法结构、称呼习惯与文化规约；**主要聚焦负面刻板印象（negative stereotypes）**——而正面/负面方向上的不对称本身就是偏见的一种表现形式；**可能遗漏语言与文化变异（linguistic and cultural variation）**——同一类刻板印象在不同语言与国家语境中往往内容不同、甚至不存在。此外，把同一组译本喂给多语言模型，无法区分"模型偏见"与"翻译引入的偏差"。本文因此用**本地原生撰写的语料**做审计，并把测量单位下沉到**国家语境**（澳大利亚 vs 加拿大 vs 墨西哥 vs 西班牙）与**效价**两个更细的维度。

## 方法
### 1. 数据构建

| 维度 | 设计 |
|------|------|
| 规模 | **12,000 条** Reddit 帖子 |
| 语言 | 英语、西班牙语、法语、德语（各原生撰写） |
| 偏见类别 | **性别（gender）、种族（racial）、宗教（religious）** |
| 翻译范围 | **仅翻译 search terms**，帖子正文保持本地原生 |
| 平衡 | 按**语言**与**类别**平衡；**英语性别**额外按**刻板印象效价**平衡 |

**"只翻译检索词"的意义**：检索词是触发刻板印象联想的探针，必须跨语言可比（否则召回的东西根本不同）；而帖子正文携带的是**目标语言的真实文化语境**——这正是翻译式基准丢失的部分。

### 2. 测量设计：双空白（two-blank）设计

- 目的：**减少语法性别线索（grammatical-gender cues）**的影响。
- 逻辑：许多语言（如西/法/德语）中，名词的语法性别会向模型泄漏与刻板印象相关的信号。若提示模板本身携带性别线索，测到的就不是刻板印象联想而是语法信号。
- 因此探针模板把与偏见无关的语法位置**留空**，从源头切断这一混淆变量。

### 3. 被测模型

- **开放权重模型（open-weight）：3 个**
- **专有 API 模型（proprietary API-based）：3 个**
- 共 **6 个模型**。

> 摘要未列出具体模型名称与版本。

### 4. 测量指标及其语义边界（本文最重要的方法论贡献之一）

| 概念 | 定义 | 本文测的是它吗 |
|------|------|----------|
| **Choice concentration（选择集中度）** | 模型的选择在某选项上的集中程度（本文的主指标） | ✅ **是** |
| **Stereotype endorsement（刻板印象认同）** | 模型是否**赞同/断言**该刻板印象 | ❌ 不是 |
| **Causal country effect（因果的国家效应）** | 国家语境**导致**偏见差异 | ❌ 不是 |

这一区分非常重要：choice concentration 只说明模型**倾向于选哪个选项**，不说明模型**相信哪个陈述为真**。而"选择集中度更高"可能是反映刻板印象，也可能是反映语言学/频率/熟悉度等其他因素。

### 5. 分析维度：三个层次

标题即给出分析结构——**Language → Country → Valence**：

1. **语言层**（英语/西/法/德）：哪些语言偏差最大？
2. **国家语境层**：如澳大利亚 vs 加拿大、墨西哥 vs 西班牙的差异（同一语言内部的国家差异）。
3. **效价层**：负面刻板印象条目 vs 正面刻板印象条目的差异（仅在英语性别类上平衡考察）。

## 实验结果
### 主要发现

| 发现 | 细节 |
|------|------|
| **宗教偏差最大** | 宗教在**每一个模型-语言条件**下都具有**最高的绝对选择不平衡（highest absolute choice imbalance）** |
| **性别偏差最高的是西班牙语** | Spanish is highest for gender |
| **种族与宗教偏差最高的是德语** | German is highest for race and religion |
| **API 模型 < 开放权重模型** | 被评测的 API 模型在整个过程中**得分低于**开放权重模型（"score below the open-weight models throughout"） |
| **英语性别类：负面 > 正面** | Negative English-gender items exceed positive items |
| **国家语境差异** | **澳大利亚 > 加拿大**（性别语境）；**墨西哥 > 西班牙**（种族语境） |

### 跨维度模式

| 维度 | 最高偏差的语言 |
|------|--------------|
| 性别 | **西班牙语** |
| 种族 | **德语** |
| 宗教 | **德语** |

- 宗教是**唯一在所有模型-语言条件下都居首**的类别——即这一结论**不依赖于模型或语言的选择**，是最稳健的一条发现。
- 英语性别的**负面条目超过正面条目**：在英语这一性别类别上，模型对负面刻板印象选项的集中度高于正面选项。

### 摘要未给出的定量信息
- 具体的**选择不平衡数值**（各模型-语言-类别组合的绝对值）
- 12,000 条帖子在 4 语言 × 3 类别上的**分布条数**
- **模型名称**（3 个开放权重 + 3 个 API）
- 具体的**国家/地区集合**（除澳大利亚、加拿大、墨西哥、西班牙外的完整清单）
- 正面/负面条目的**比例**与平衡方式
- 测量指标的**具体计算公式**（choice concentration 的定义）
- 统计检验、显著性水平、多重比较校正
- 双空白提示的**具体模板**
- 检索词列表

## 关键洞察
1. **宗教偏差"在每个条件下都最高"这一稳健性，远比具体数值更有价值**：它意味着宗教是**与模型无关、与语言无关**的优先偏差来源。对做部署前审计的团队，这是一个**优先级排序的直接依据**——先查宗教。
2. **"翻译式基准"这一主流做法可能是错的**：只翻译检索词、保留本地正文，恰好把"跨语言可比性"（探针一致）与"文化真实性"（语境本土）分离。若全部翻译，本文的国别差异（如墨西哥 > 西班牙）会被抹平，**基准会低估真实的本地化偏差**——这对欧洲多语言部署尤其危险。
3. **澳大利亚 > 加拿大、墨西哥 > 西班牙：同一语言内部的国家差异被捕捉到了**：这说明"语言"这个标签本身就过粗，偏差的真正单位可能是**文化-国家语境**。标题中 "Language to Country to Valence" 的递进正是这一发现的方法论表达——审计粒度应当逐层下沉。
4. **API 模型在所有条件下得分低于开放权重模型，是一个值得警惕的反直觉结果**：直觉上"最强、最新"闭源模型应更少偏见。可能的解释（摘要未验证、仅供讨论）：API 模型更倾向于"安全化/回避"地选一个看似无害的选项，而这在 choice concentration 指标下恰好被记为不平衡；或者训练数据的偏差治理并不随能力提升而改善。**这直接说明：在多语言偏见上，模型代际不等于对齐代际。**
5. **作者主动划定"测量不到什么"的边界（choice concentration ≠ endorsement ≠ causal effect）是这类审计论文的关键素养**：如果不加这层限定，几乎所有此类结论都会被过度解读为"模型持有刻板印象信念"。特别是"国家差异"最容易被误读为"模型对澳大利亚人/墨西哥人有什么看法"——实际上**没有因果识别**，只是分布上的选择集中差异。
6. **英语性别负面 > 正面，说明偏好在方向上不对称**：即使数据集在英语性别上做了效价平衡，模型仍系统性偏向负面选项——**平衡采样不足以抵消模型端的负面偏好**。

## 局限性
- **纯描述性，无因果**：作者自己声明"these descriptive differences measure choice concentration, not stereotype endorsement or causal country effects"。因此**不能**从本文推出"国家语境导致了偏差"或"模型赞同这些刻板印象"。
- **指标代理的有效性未验证**：choice concentration 与"实际有害的刻板印象使用"之间的相关性没有建立；低选择集中度也可能是模型随机性或选项措辞不平衡造成的。
- **Reddit 作为语料的代表性有限**：Reddit 用户结构在四国间差异很大；平台本身以城市、西方、年轻男性用户为主，**族群与宗教的具体分布不代表总体人口**。帖子的自我选择也引入了幸存者偏差。
- **数据规模分配不明**：12,000 条在 4 语言 × 3 类别 × 多国家语境 × 多效价上的划分未知；某些格子可能样本过小，导致"最高/最低"的排序被噪声驱动——摘要无置信区间。
- **模型覆盖窄**：仅 6 个模型（3 开放权重 + 3 API），且未列出名称；**不含**具体最新闭源前沿模型的话，API 落后于开放权重的结论可能只是所选 API 模型较旧。
- **英语之外的效价平衡缺失**：只有英语性别按效价平衡，因此"负面 > 正面"这一结论**只对英语性别成立**，不能推广到其他语言/类别；这也削弱了跨语言的效价比较。
- **帖子而非提示的设计**：模板中的"双空白"减少了语法性别线索，但帖子正文本身的措辞、上下文长度、话题分布等**未受控**，这些都可能驱动选择集中度。
- **没有报告干预可行性**：审计只做诊断，未提出也未验证任何偏见缓解手段（如平衡 few-shot、拒答策略、系统提示）。
- **单作者预印本**（10 页，会议评审进行中），未经同行评审。

## 适用场景
- **多语言 LLM 部署前的偏见审计基线**：为教育、招聘、职场决策支持等场景提供一份可复制的方法学与数据构造范式（原生语料 + 仅译检索词 + 双空白探针）。
- **多语言内容审核与招聘筛选工具的选型风险评估**：API 模型在所有条件下得分低于开放权重模型，这一发现可直接影响"选开源还是选闭源"的偏见风险论证。
- **欧洲/拉美市场的本地化风险评估**：国别差异（澳大利亚 > 加拿大、墨西哥 > 西班牙）说明按"语言"做一次审核不足以覆盖同一语言内的多市场，需要按国家分层。
- **偏见研究的方法论参考**：本文对"测量什么/不测量什么"的显式界定，以及 choice concentration ≠ endorsement 的区分，可直接用于设计后续审计。
- **不适合**：直接用作"模型持有刻板印象信念"的证据；或用作单个产品的合规结论依据（无因果识别、无干预验证、非代表性语料）。
