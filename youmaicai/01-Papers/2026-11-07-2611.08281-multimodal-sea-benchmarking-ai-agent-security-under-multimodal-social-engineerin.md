# Multimodal-SEA: Benchmarking AI Agent Security under Multimodal Social Engineering Attacks

### 核心贡献
1. 提出 Multimodal-SEA 交互式基准，用于评测个人 AI agent 在「多模态社会工程攻击」下的内在安全性，填补既有评测只关注文本对话的空白。
2. 基准含 608 个专家设计的任务，基于真实诈骗案例，覆盖 14 个领域、152 种攻击场景与四个难度等级，并体现中英文环境各自的社会文化语境。
3. 设计多模态攻击 harness，集成任务信息、攻击进程控制与多模态内容构造，实现受控红队测试；攻击结果以可验证的工具执行日志为依据。

### 技术方案
**核心思想**: 把真实诈骗剧本改造成带图片/多模态载荷的交互式任务，让 agent 在模拟应用中「查看内容—验证请求—执行动作」，再用可审计的工具调用日志判定攻击是否成功。

| 技术 | 说明 |
|------|------|
| 任务规模 | 608 个专家设计任务（expert-designed tasks） |
| 领域覆盖 | 14 个领域（domains），152 种攻击场景（attack scenarios） |
| 难度分级 | 四个难度等级（four difficulty levels） |
| 语言文化 | 覆盖中文与英文环境下的不同社会文化语境 |
| 攻击 harness | 整合任务信息、攻击进程控制（attack progression control）、多模态内容构造 |
| 结果判定 | 基于可验证的工具执行日志（verifiable tool execution logs）作为攻击结果依据 |
| 评测维度 | 七个广泛使用的多模态模型，在六个维度上评估 |

### 实验结果
- **数据集**: Multimodal-SEA 自身（608 个基于真实诈骗案例的任务）
- **基线**: 七款常用多模态模型；比较有无多模态内容、有无更强安全指令等条件
- **结果**: 全部模型均可被攻破，攻击成功率区间 7.1%–34.5%；加入多模态内容后攻击成功率从 19.9% 升至 29.2%（尽管 agent 的主动核验覆盖率同时上升）；更强安全指令能降低攻击成功率，却无法提升对欺骗性多模态内容的识别能力；部分模型攻击成功率较低是因为对合法请求存在过度拒答

### 局限性
- 仅覆盖 14 个领域与 152 种攻击场景，且以中文/英文诈骗案例为主，对其他语言与文化场景的迁移性未验证
- 采用模拟应用与工具日志判定，成功/失败可能与真实部署环境存在差距
- 摘要未说明六个评测维度的具体定义，也未给出各模型逐个的攻击成功率明细

### 关键洞见
> 安全指令只能「降低被攻击的比例」，却完全无法「提升对欺骗性多模态内容的识别能力」——而恰恰是后者才决定 agent 是否会在识破之前就动手；同时多模态载荷在 agent 主动核验覆盖率上升的同时，仍把攻击成功率从 19.9% 推到 29.2%，说明核验动作本身未必发生在真正危险的环节上。
