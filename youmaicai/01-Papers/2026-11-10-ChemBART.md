## 核心贡献

> 以"整体反应表达式（Reactant > Reagent > Product）"上的掩码填充任务做反应中心预训练，单个 BART 模型统一前体/试剂预测、温度-产率回归、分子性质分类，并可通过 SFT+RL 拟合 MCTS 的策略与价值函数实现多步合成路线设计，最终经湿实验验证。

1. 提出反应中心的预训练策略：在反应级 SMILES 句子上做三方向掩码填充（分别掩住 reactant / reagent / product），相比单分子预训练能学到确定的化学规律（消融显示 ChemBART-Mol 单分子版 Top-1 仅 42.5%，ChemBART-M 达 63.2%）。
2. 用统一权重 + 任务特定 token 与头，覆盖前体/试剂/产物预测、反应温度与产率回归、分子性质分类（5 个生化任务中 2 个达 SOTA）等多任务。
3. 通过在 ReSynZ 框架下先 SFT 再 RL 拟合 MCTS 策略与价值函数，实现模板无关（template-free）的多步逆合成路线设计：Retro*-190 基准成功率 65%（ChemBART-M）/ 71%（ChemBART-F），JMC2025 上 beam search 成功率 88.7%。
4. 湿实验验证：PD-L1/VISTA 双靶点抑制剂 P1 的 ChemBART 设计路线总收率 35%，相对文献路线（6.5% 总收率）提升超过 20 个百分点，且路线更短。

## 技术方案

### 核心思想

现有 LLM 化学应用多停留在单分子 SMILES 表示，且局限于孤立单任务（如前体预测）。论文指出单分子预训练有两个根本缺陷：其一，只能学到 SMILES 语法与价态规则，无法获得化学体系知识；其二，掩码单分子时不同取代基与碳链结构会产生多个合理答案，优化困难且难以学到确定性的表示。反应则天然包含原子与官能团相互作用的规则，且掩码反应组件有唯一正确答案。

ChemBART 因此把预训练任务前移到反应级：每个反应写成 SMILES 句子 `reactant > reagent > product`，训练时对三段中之一做掩码、让模型重建。模型为 BART 架构，按原子/映射索引级别做 tokenize。预训练数据来自 USPTO-full 与 USPTO-MIT，得到 ChemBART-F（full）、ChemBART-M（MIT）、ChemBART-R（随机初始化）三个版本，另设 ChemBART-Mol（仅用 USPTO-MIT 中所有单分子 SMILES 预训练）作为对照以验证"反应级 vs 分子级"。

多步规划方面，ChemBART 负责在 MCTS 搜索树的每个节点生成 top-50 前体与试剂候选，用预训练模型的概率打分化学可行性，用微调后的策略/价值函数打分合成难度。为此在 ReSynZ 训练框架下先做第一阶段 SFT、第二阶段 RL，让模型学会拟合 MCTS 的策略与价值函数——论文强调这是纯单分子预训练模型几乎无法获得的能力。策略与价值函数同时达到验证 RMSE 新低时才保存 checkpoint。

论文还做了可解释性分析：计算元素 token（Cl、Br、O、N、C、Na、K）嵌入向量的欧氏距离，发现同族更相似（Cl/Br 1.02、Na/K 0.93）而跨族更远（Cl/Na 1.07），O/Cl 相似度（1.00）高于 O/Br（1.09），C/O/N 形成反映共价成键的独立簇；3D PCA 可视化显示模型学到元素周期趋势。

### 关键公式

```math
% 反应级掩码填充预训练目标（三个方向）
\text{Input}: \ \texttt{[MASK] > reagent > product} \quad / \quad \texttt{reactant > [MASK] > product} \quad / \quad \texttt{reactant > reagent > [MASK]}
\text{Target}: \ \text{被掩码段的完整 SMILES}

% MCTS 节点候选生成与打分
\mathcal{C}_t = \{\text{top-50 (precursor, reagent) pairs}\},\quad
S(c) = \alpha\cdot P_{\text{pretrained}}(c) + \beta\cdot V_{\phi}(s) + \gamma\cdot \pi_{\theta}(s,a_c)

% LoRA 微调（用于分子性质分类等任务）
W' = W_0 + \frac{\alpha}{r} A B,\quad \Delta W = \frac{\alpha}{r} B A \ (\text{论文记法})
\text{LoRA rank } r:\ \text{ClinTox 用 6, 其余任务用 8}
```

### 关键组件

- **反应级掩码填充预训练**：USPTO-full / USPTO-MIT，11 轮预训练后收敛。
- **ChemBART-Mol 对照**：同架构但仅用单分子 SMILES 预训练，用于隔离"反应中心"的贡献。
- **多任务微调头**：前体/试剂/产物生成（beam search）、温度与产率回归（回归头）、分子性质分类（分类头 + LoRA）。
- **MCTS 策略/价值函数拟合**：ReSynZ 框架下 SFT + RL，输出含合成分难度与反应条件。
- **单步逆合成评估**：beam search 生成 top-k；top-k/top-p 采样（k=10, p=0.9）用于提升路线多样性。
- **MCTS 多步搜索**：搜索宽度默认 10，困难步扩至 50 再到 150；单节点生成 top-50 候选。

## 局限性

- 仍落后于两个专门做逆合成的 SOTA（RSGPT、PMSR），虽然差距不大，且 ChemBART 需服务多任务通用性。
- 在成环反应与高复杂度拓扑上表现不佳，论文归因于公开 USPTO 训练集对此类结构覆盖不足；与商业专有软件 Chematica 仍有明显差距（4/11）。
- 单步预测准确率略低于 SOTA，但在多步规划成功率上表现稳健，论文认为二者需权衡。
- 采样引入的多样性伴随幻觉风险：beam search 路线保守，top-k/top-p 更具多样性但幻觉更多。
- 湿实验验证仅一个代表性化合物 P1，实验规模有限；多数反应条件仍需专家优化。
- 预训练模型 ChemBART 约 0.4B 参数，长上下文 15 步路线规划能力受限于模型容量。

## 建议

- **是否推荐使用**：是
- **适用场景**：计算机辅助合成规划（CASP）中的多步路线设计与反应条件预测；前体/试剂生成；反应温度-产率预测；分子性质回归与分类；把 LLM 接入湿实验闭环的合成化学团队。
- **值得复现**：是（"反应级掩码填充"预训练任务可低成本迁移到其他结构化领域；同时提供了 MCTS + RL 的策略/价值函数拟合范式）
