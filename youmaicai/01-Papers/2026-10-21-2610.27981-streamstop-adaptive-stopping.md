## 核心贡献

> 提出 **StreamStop** —— 从「prefix 级动作一致性」**离线学习模型特定的停止策略**。只需一个**冻结的 prefix reader** 读取可见的推理文本，无需访问推理模型的内部信号（hidden states / token probabilities）。

1. **解决实际问题**：推理型 agent 在行动前可能消耗大量计算，而**每个决策所需推理量本就不同**
2. **既有信号不可靠**：置信度、中间答案稳定性在不同推理模型上效果差异大；hidden state / token 概率需内部访问，**API 场景不可用**
3. **方法**：冻结 prefix reader + 轻量 stop head，**黑盒友好**
4. **开源数据**：带 prefix 级动作标注的 agent 推理轨迹数据集
5. **精确优化**：折扣动作一致性目标可精确求解；**在推理时条件于折扣因子即可调节「一致性 vs token」权衡，无需重训**

---

## 技术方案

### 标注设计

每个 prefix 的动作与「完整推理」参考动作对比：

```math
A(p_i, a_{\text{full}}) = \mathbb{1}[\pi_{\text{stop}}(p_i) = a_{\text{full}}]
```

这使得 (a) 不同停止规则可离线对比，(b) 折扣一致性目标可**精确期望回报优化**。

### 目标函数

$$\max_{\pi_{\text{stop}}} \ \mathbb{E}\Big[\sum_{i} \gamma^{\,i} \cdot \mathbb{1}\big[\pi_{\text{stop}}(p_i) = a_{\text{full}}\big]\Big]$$

- $\gamma$（折扣因子）作为 stop head 的条件输入
- 调 $\gamma$ = 调「早停省 token」与「动作正确」的权衡，**推理时即可改**

### 架构

```math
\text{frozen prefix reader}(p_i) \to \text{lightweight stop head}(p_i, \gamma) \to \{\texttt{stop}, \texttt{continue}\}
```

**无需**推理模型的内部状态访问。

## 实验结论

| 基准 | 结果 |
|------|------|
| **WebShop (Qwen3.8-27B)** | 每 episode **少用 42% 推理 token**，观测任务成功率**相近** |
| WebShop / ScienceWorld 闭环评测 | 观测成功率**高于**大多数经验证集挑选的固定预算设置 |
| 相对 Full thinking | **更少**推理 token |

## 局限性

- 需要离线轨迹数据（作者已开源，但换领域需重新构造）
- prefix reader 本身有开销，收益净收益需计入
- 「观测成功率」≠ 真实任务成功率（观测可能高估）
- 依赖「动作可与完整推理参考对齐」的前提 —— 开放式生成任务不适用

## 实现建议

- **适用场景**: 推理型 agent 的**成本优化** —— 尤其 WebShop/工具调用等动作空间明确、token 开销高的场景
- **优势**: **黑盒友好**（无需 hidden states）—— 这对 API 部署是关键区分点，多数同类方法做不到
- **落地建议**: $\gamma$ 作为**运行时旋钮**而非训练超参 —— 先上线 $\gamma=1$（保守），再根据线上数据调高以省更多 token
- **⚠️ 前提检查**: 确认你的任务能定义「动作一致性」信号；开放式写作/对话类 agent 无法直接套用
