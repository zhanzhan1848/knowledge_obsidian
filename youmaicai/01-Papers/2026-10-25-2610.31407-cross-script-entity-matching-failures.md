## 核心贡献

> 多语言模型在**同一个人名用不同文字书写**时会给出**不同的身份判断** —— 这不是分词问题，而是一个可定位到具体层、可用一个共享方向做因果干预的问题。

1. **现象量化**：用 **601 对审计过的身份配对**（具 attested 的天城文与拉丁形式），固定问题与关系，Qwen2.5-7B 的 same-person 准确率在马拉地语 prompt 下**从拉丁文的 35.1% 跌到 8.5%**，而 **different-person 准确率保持在 98% 以上**。
2. **排除分词解释**：**减少 tokenization 碎片化并不能可靠弥合差距** —— 排除掉最省事的解释。
3. **跨文字系统与跨语言家族复现**：在 **374 对马拉雅拉姆语**配对（同一批实体）上复现，same-person 跌至 **5.3%**（约为天城文匹配率的一半），**但 margin 仍以 0.925 AUROC 把匹配排在非匹配之上** —— 模型"知道"排序对，但**决策阈值错了**。
4. **区分两个成分**：**Latin-trained probes 能从天城文状态中恢复标签信息**，在 similarity-matched negatives 下超过 string-feature 基线；**标量校准恢复原始模型-探针平衡准确率差距的 87%**，据此**判定"决策标准位置（criterion placement）"是主要贡献因素**。
5. **因果定位与干预**：**Activation patching 把因果敏感性定位到 Qwen 中层的第二个实体**；**一个共享敏感方向传递约一半的完整状态 margin 修正**；在该位置做**事实无关干预**把留出马拉地语 same-person 准确率**从 6.5% 提升到 33.5%**，同时 different-person 保持 **98.5%**。

## 技术方案

### 核心思想

把"跨文字系统失败"拆成两个可分离的成分，分别测量、分别干预：

```
失败 = (表征层：跨文字系统读不到身份信息)
     + (决策层：读到了但判别标准位置不对)
```

论文的整套实验正是沿这条分解线设计的。

### 关键技术

| 技术 | 说明 |
|------|------|
| **601 对审计身份配对** | 主实验数据集：具 attested 天城文与拉丁形式，问题与关系固定 |
| **374 对马拉雅拉姆语配对** | 复现集：同一批实体，第二个文字系统与语言家族 |
| **similarity-matched negatives** | 控制表面字符串相似度的负例 —— 关键，使 probe 结论不能被"字符串捷径"解释 |
| **Latin-trained probes** | 在拉丁文状态上训练的探针，测试能否从**天城文**状态中解码标签 |
| **标量校准（scalar calibration）** | 只调整判别阈值，检验"是否只是阈值问题" |
| **Activation patching** | 因果定位：在哪些层、哪些 token 位置承载跨文字系统的敏感度 |
| **共享敏感方向（shared sensitivity direction）** | 从 patching 中抽出的单一方向，用于**低成本因果干预** |
| **事实无关干预（fact-independent intervention）** | 不注入任何身份事实，只修正决策标准位置 |

### 实验规模总览

| 维度 | 规模 |
|------|------|
| 主实验配对数 | **601 对**（天城文 vs 拉丁） |
| 复现实验配对数 | **374 对**（马拉雅拉姆语） |
| 评测模型数 | **5 个模型**（"across five models reveals distinct response biases"） |
| 探针训练语言 | 拉丁文（测试能否迁移到天城文） |

## 关键实验结果

### 主现象

| 模型 / 设定 | same-person 准确率 | different-person 准确率 |
|---|---|---|
| Qwen2.5-7B · **拉丁文** | **35.1%** | > 98% |
| Qwen2.5-7B · **天城文**（马拉地语 prompt） | **8.5%** | > 98% |
| 马拉雅拉姆语复现 | **5.3%**（约为天城文的一半） | — |

> **关键不对称**：different-person 一侧**几乎不受影响（>98%）** —— 失败是**特异性地落在"判定为同一人"这一侧**，而不是模型整体看不懂非拉丁文字。

### 分词解释被排除

- **减少 tokenization 碎片化并不能可靠弥合差距** —— 天城文通常被切成更多片段，但片段数与准确率缺口**不构成可靠关系**。

### 表征层 vs 决策层的分解

| 证据 | 结论 |
|---|---|
| Latin-trained probes 从天城文状态中恢复标签信息，且**超过 string-feature 基线**（similarity-matched negatives 下） | **表征层确实携带身份信息** |
| margin 仍以 **0.925 AUROC** 正确排序 | 模型"知道"谁匹配谁，**排序能力尚存** |
| **标量校准恢复 87% 的原始模型-探针平衡准确率差距** | **"决策标准位置"是主要贡献因素** |

### 因果定位与干预

| 干预 | 结果 |
|---|---|
| Activation patching 定位 | **Qwen 中层的第二个实体**（即第二个名字 token）承载因果敏感度 |
| 抽取单个共享敏感方向 | 传递**约一半**的完整状态 margin 修正 |
| 该位置的事实无关干预 | 留出马拉地语 same-person **6.5% → 33.5%**，different-person **98.5%** |

## 关键结论 / 局限性

### 关键结论

1. **跨文字系统实体匹配失败的主因是"判别标准位置"而非"知识缺失"** —— 模型表征里有答案，但阈值放错了位置。这与昨日 [[2026-10-24-2610.30903-cross-identifier-binding-failures]] 中"绑定失败"的判断同源，但本文给出了更细的机制与更强的干预证据。
2. **一个方向的因果干预能恢复大部分性能且几乎不损伤反向准确率**（98.5%）—— 这是极具工程价值的结果：**修复跨文字系统实体匹配可能只需在特定层调整决策标准，而非重新训练**。
3. **失败对文字系统与语言家族都稳健** —— 天城文与马拉雅拉姆语两套独立数据上同向复现。
4. **分词碎片化不是解释** —— 排除了最省事也最常被引用的解释。

### 局限性

- **模型规模小** —— 主结论基于 Qwen2.5-7B；更大的模型是否仍呈现同样的"表征有信息、阈值错位"结构未验证
- **两个文字系统、两个语言家族**（天城文、马拉雅拉姆语）—— 都是印度次大陆语言系统，扩展到**文字系统差异更大**的场景（如西里尔 vs 阿拉伯 vs 汉字）未验证
- **探针为线性且训练于拉丁文** —— 更强的探针或跨文字系统探针可能给出不同的分解比例
- **AUROC 0.925 与准确率 5.3% 的巨大落差**说明分布极不平衡（same-person 负例占绝大多数），**准确率在此设定下是脆弱指标**；论文同时给出 AUROC 是恰当的，但正文中的其他准确率数字需注意这个背景
- **干预的实用边界未明** —— 在 Qwen2.5-7B 中层的一个位置上修正，迁移到其他模型/其他层的可行性未测；且干预方向依赖"探针找到的可迁移方向"，对分布外的实体类型可能失效
- **归因语言家族 vs 文字系统的混淆未完全消除** —— 天城文（马拉地语）与拉丁文（马拉地语 prompt）的对比中，语言与文字系统同时变化
