## 核心贡献

> 提出 **GIFT**，用**梯度几何分解**解决"密集蒸馏监督"与"稀疏 outcome RL"之间的**冲突与分配问题** —— 决定**哪些 teacher 更新该被采纳**。

1. **问题**：复杂推理任务训练依赖两种互补信号：
   - **稀疏、outcome-grounded 的 RL**（正确性）
   - **密集、token-level 的 distillation**（引导）
   但**监督互补 ≠ 优化兼容**：imitation 导向的蒸馏会与 outcome 导向的 RL 目标**冲突**，既有混合方案缺乏**原则性解决方案**。
2. **方法 — token 级几何分析**：把蒸馏梯度分解为
   - **平行分量**（parallel to RL gradient）→ 度量**一阶冲突**，提供 **safety filter**；
   - **正交分量**（orthogonal）→ 量化**新颖的方向性指导**，提供 **value 度量**。
   该分解导出**有原则的 token 级指导排序规则**。
3. **Coverage annealing**：渐进式**收缩接受蒸馏的 token 预算**，确保**冲突最大的更新最先被丢弃**，而**互补性最强的保留满强度** —— 实现从"密集、几何过滤过的引导"到"纯 outcome-grounded 目标"的**平滑过渡**。

---

## 技术方案

| 组件 | 说明 |
|------|------|
| 梯度分解 | 蒸馏梯度 = ∥ 平行分量（冲突/safety）⊥ 正交分量（value）|
| 排序规则 | 基于分解的打分，排序 token 级指导 |
| Coverage annealing | 逐步缩小蒸馏 token 预算 |
| 平滑过渡 | dense-filtered guidance → pure outcome objective |

### 关键洞见

- 这是一个很干净的**多目标优化**思路：把"蒸馏会不会破坏 RL 目标"变成可**逐 token 测量**的量，而不是靠调 loss weight 猜。
- **正交分量 = 新颖信息**这个视角很好：只有与 RL 梯度正交的部分才真正带来新知识；平行部分要么冗余要么冲突。
- annealing 的作用是**自动 curriculum**：训练早期用密集引导（学格式/路径），后期纯 outcome（学正确性）。

## 实验结论

- **基准**：数学与逻辑推理 benchmark（多个模型规模）
- **结果**：
  - **一致优于强 baseline**；
  - 困难数学推理任务上相对增益最高 **9.5%**。

---

## 局限性

- 需计算**逐 token 的梯度分解** → 训练开销显著增加（幅度未量化）；
- 只在 reasoning 任务验证；
- 与 gradient surgery 方法（PCGrad 等）的对比值得补充；
- coverage annealing 的 schedule 需调参。
