## 核心贡献

> 首次把"预测性空间推理（predictive spatial reasoning）"从"读图式感知"中分离出来作为可诊断的 VLM 评测维度；3,862 题、182 真实场景、最强模型仅 58.0% vs 人类 87.2%。

1. 提出"**Predictive Spatial Reasoning**"概念：观察 → 干预 → 推理未观察结果，与现有"读图感知"基准根本区分。
2. 构建 **SpaceCast-Bench**：3,862 问题 / 16 任务 / 3 层级（static perception / local prediction / global prediction）。
3. 评估 21 个 VLM，揭示巨大 gap：最强 58.0% vs 人类 87.2%；空间专用模型几乎随机。
5. **Fine-tuning on programmatic data** 让 Qwen3-VL-4B 从 34.0% → 65.7%，并在 6 个 out-of-domain benchmark 上 macro-average 提升。

---

## 技术方案

### 核心思想

现有空间推理 benchmark 多测"读图"——关系已经在图中可见。但现实世界需要"预测性"空间智能：从观察构建场景，推断一个干预带来的、未观察到的结果。SpaceCast-Bench 把这一能力作为独立维度系统评测。

### 关键技术

| 技术 | 说明 |
|------|------|
| Observe-Transform-Infer 框架 | 评测分三段：观察（obtain scene） → 状态更新（apply transform） → 关系推理（infer unseen outcome） |
| 16 task types × 3 levels | static perception / local prediction / global prediction 递进要求：场景理解、状态更新、未观察结果推理 |
| Bridge views 关键 | 多个分布观察之间的"桥接帧"对整合关键发现至关重要 |
| 3D evidence vs 生成图/视频 | 显式 3D 证据比"生成的输出图像 / 视频"更能稳定提升模型 |
| Programmatic 数据生成 | 用规则生成可扩展的训练集，synthetic-to-real 转移良好 |

### 数据规模

- 3,862 questions
- 182 real-world scenes
- 16 task types
- 3 difficulty levels

---

## 实验结果

- **21 个模型评估**：最强模型仅 58.0%（人类 87.2%）
- 空间专用模型 ≈ random chance
- **Bridge views** 的有无显著影响性能
- 显式 3D evidence > 生成结果图 / 视频
- **Qwen3-VL-4B fine-tune**：34.0% → 65.7%（+31.7 pp）
- macro-average 提升横跨 6 个 OOD benchmark

---

## 关键 takeaway

- "读图感知"和"预测性推理"是两种能力，需要分别评测与训练。
- VLM 在"预测性空间智能"上仍远落后于人类，是下一代 VLM 的关键缺口。
- Programmatic 生成的合成数据可作为 fine-tuning 燃料，且具有 OOD 迁移能力。

---

## 局限性

- 仅 182 真实场景，场景多样性可能不足
- 程序生成数据 vs 真实场景间存在分布 gap
- 评测维度"预测性"具有主观边界，可能与某些任务定义重叠
