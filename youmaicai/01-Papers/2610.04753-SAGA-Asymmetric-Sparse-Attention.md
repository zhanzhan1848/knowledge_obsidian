## 核心贡献

1. **稀疏注意力中的瓶颈转移观察**：在稀疏 attention 下，QK 计算成为瓶颈，QK 中的 key 头数量可减少以加速推理。
2. **SAGA (Sparse Asymmetric Group-Query Attention)**：解耦 key 和 value 头的数量，仅保留更多 value 头以维持模型容量。
3. **Atop-N 稀疏注意力**：简单稀疏注意力方法，与 SAGA 配合研究稀疏度与头数不对称的相互作用。
4. **高效 SAGA 微调**：可将预训练模型快速转换为 SAGA 架构，避免昂贵的从头训练。

## 模型架构 / 方法

- **传统 GQA**：所有头共享相同的 K/V 头数（如 8 query → 4 KV）。
- **SAGA**：Q 头和 K 头数仍配对，但保留全部 V 头（或 V 头数 ≫ K 头数）。
- **理论分析**：证明不对称 K/V 配置在保持稀疏注意力质量的同时显著降低 QK 计算量。
- **Atop-N 稀疏**：仅保留 top-N 注意力权重。

```python
# 概念示意
Q: [q1, q2, ..., qH]               # H query heads
K: [k1, ..., kH//r]                # reduced key heads (group size r)
V: [v1, v2, ..., vH]               # full value heads (asymmetry)
```

## 实验结果

- **1.5B 参数以下模型**：长上下文下端到端解码速度提升 **2×** （相比 full-attention GQA 基线）。
- 训练 SAGA 模型质量接近同等参数 GQA 变体。
- 在所有评估基准上保持可比质量。

## 局限性

- 实验规模限于 1.5B 参数，更大模型下的扩展性需验证。
- 主要在长上下文场景下取得显著加速；短上下文增益有限。
- 微调转换方法的通用性未在多种预训练模型上系统验证。
