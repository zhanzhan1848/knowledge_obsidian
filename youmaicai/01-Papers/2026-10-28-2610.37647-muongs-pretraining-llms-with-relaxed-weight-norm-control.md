## 核心贡献

> **用「累积有效学习率」这一个量，把 Muon 系优化器的范数控制问题讲清楚了** —— 并证明**放松范数约束**（不固定范数、只去掉径向分量）反而能得到**更快的累积**，从而更快的探索。

1. **提出核心度量 —— 累积有效学习率（accumulated effective learning rate）**：
   ```math
   C_T = \sum_{t<T} \eta_t / \|W_t\|_F
   ```
   其中 $\eta_t$ 为名义学习率，$\eta_t/\|W_t\|_F$ 为**相对于权重范数的有效学习率**。
2. **理论结果**：
   - 对有界更新方向，**任意训练区间上的累积都能界定相对权重位移**
   - **vanilla Muon 只能累积对数级（logarithmically）** ⇒ 可能限制探索，**这解释了其经验上进展较慢**
   - **MuonW 与 MuonH 在所述条件下保证至少线性累积**
   - 更进一步：**足够慢的范数增长保证比对数最坏情况更快的累积** ⇒ 打开了**限制更少的优化器设计空间**
3. **提出 MuonGS**：
   - 用 **Gram-Schmidt (GS) 投影**去除每次 Muon 更新中的**径向分量**
   - **但不去固定权重范数**（这正是与 MuonW / MuonH 的区别）
   - **理论保证**：有界更新方向 + 常数名义学习率下，$t$ 步后权重范数**至多按 $\sqrt{t}$ 增长**
   - ⇒ **$C_T = \Omega(\sqrt{T})$**，累积**在训练后期依然持续**
   - 对**光滑的尺度不变目标**，建立 **$O(T^{-1/2})$ 的稳定性（stationarity）保证**
4. **实验**：160M 与 400M 稠密模型 + 135M 激活 / 1B 总参 MoE 上，**长训练时程下 MuonGS 的验证困惑度低于 MuonH**；稠密模型上相对 MuonH 有**最高约 15% 的 token 等效加速**（匹配验证损失下）。

## 技术方案

### 核心思想

「范数控制为什么有用」一直缺一个统一解释。本文提出：**真正重要的是 $C_T$（累积有效学习率），而范数控制只是达成大 $C_T$ 的一种手段**。

- vanilla Muon：$\|W_t\|$ 增长 → $\eta_t/\|W_t\|_F$ 变小 → $C_T$ 只有对数级 → 后期几乎停止探索
- MuonW / MuonH：硬性控制范数 ⇒ 保证 $C_T \ge \Omega(T)$，但**约束过强**
- **MuonGS**：只把更新的径向分量投影掉，**允许范数自然增长**（至多 $\sqrt{t}$）⇒ $C_T = \Omega(\sqrt{T})$，**既保持累积又不受硬约束**

```text
有效学习率:  η_t / ‖W_t‖_F
累积:        C_T = Σ η_t / ‖W_t‖_F

C_T 的增长速度决定「探索速度」

vanilla Muon:  ‖W_t‖ 快增  →  C_T = O(log T)      ← 停滞
MuonW / MuonH: 硬固定 ‖W‖  →  C_T = Ω(T)         ← 约束过强
MuonGS:        GS 去径向   →  ‖W‖ ≤ O(√t) → C_T = Ω(√T)  ← 放松但持续
```

### 关键技术

| 技术 | 说明 |
|------|------|
| **累积有效学习率 $C_T$** | 统一解释范数控制作用的标量度量 |
| **Gram-Schmidt 径向投影** | 去除更新方向中的径向分量（正交于当前权重） |
| **放松范数约束** | 不固定 $\|W\|$，只保证其增长上界 |
| **$\Omega(\sqrt{T})$ 累积保证** | 比对数最坏情况好，比线性保守 |
| **$O(T^{-1/2})$ 稳定性** | 对光滑尺度不变目标 |
| **尺度不变目标处理** | 尺度不变下范数增长不改变函数值 ⇒ 可自由放松控制 |

## 公式

```math
\text{累积有效学习率}:\quad
C_T \;=\; \sum_{t<T} \frac{\eta_t}{\|W_t\|_F}
```

```math
\text{径向投影（GS）}:\quad
\Delta W_t^{\text{GS}} \;=\; \Delta W_t - \frac{\langle \Delta W_t,\, W_t\rangle}{\|W_t\|_F^2}\, W_t
\qquad
\big\langle \Delta W_t^{\text{GS}}, W_t \big\rangle = 0
```

```math
\text{范数增长上界}:\quad
\|W_t\|_F \;\le\; O(\sqrt{t}) \quad\Longrightarrow\quad
C_T \;=\; \sum_{t<T} \frac{\eta}{\|W_t\|_F}
\;\ge\; \Omega(\sqrt{T})
```

```math
\text{稳定性}:\quad
\mathbb{E}\|\nabla f(W_T)\| \;=\; O(T^{-1/2})
\qquad (f \text{ 光滑且尺度不变})
```

```math
\text{对比：vanilla Muon 的对数最坏情况}:\quad
\|W_t\|_F \sim t \quad\Longrightarrow\quad
C_T \;=\; \sum_t \frac{\eta}{t} \;=\; O(\log T)
```

## 代码片段

```python
# 概念性伪代码：MuonGS 的更新规则
import torch

def muon_gs_step(params, grads, lr=0.02):
    #     Muon + Gram-Schmidt 径向投影（不固定权重范数）。
    #     对应论文：MuonGS。
    for W, G in zip(params, grads):
        # 1) Muon 式正交化（Newton-Schulz 近似）
        U = orthogonalize(G)              # U^T U ≈ I

        # 2) GS 径向投影：去掉与 W 平行的分量
        radial = torch.dot(U.reshape(-1), W.reshape(-1))
        U = U - (radial / (W.reshape(-1).norm() ** 2)) * W

        # 3) 尺度：Muon 的谱归一化缩放
        update = -lr * ns_scale(U)

        # 4) 应用更新 —— 注意：不施加任何权重范数投影/约束
        W.add_(update)
        # 对比 MuonW: W.mul_(target_norm / W.norm())   ← 硬约束
        # 对比 MuonH: 软化的硬约束版本
    return params
```

```python
# 监控累积有效学习率（诊断用）
def accumulated_effective_lr(params, lr_history, norms_history):
    # C_T = Σ η_t / ‖W_t‖_F
    C = 0.0
    for eta, nrm in zip(lr_history, norms_history):
        C += eta / max(nrm, 1e-12)
    return C
```

## 实验结论

- **模型**:
  - 稠密 160M、400M
  - MoE：135M 激活 / 1B 总参数
- **基线**: Muon, MuonW, MuonH
- **结果**:
  - **长训练时程下 MuonGS 验证困惑度低于 MuonH**
  - 稠密模型：**匹配验证损失下，相对 MuonH 最高约 15% 的 token 等效加速**
  - 理论：$\|W_t\|_F \le O(\sqrt{t})$，$C_T = \Omega(\sqrt{T})$，$O(T^{-1/2})$ 稳定性

---

## 局限性

1. **规模很小** —— 160M / 400M 稠密 + 1B MoE，**远未验证在 7B+ 规模的实际收益**。15% 的 token 加速在 400M 上的外推性存疑
2. **「长训练时程」的具体长度未给** —— MuonGS 的优势在长时程出现，短训练（主流的 1-2 epoch）下可能无差异甚至更差
3. **理论依赖强假设**：
   - **有界更新方向**、**常数名义学习率**、**光滑且尺度不变的目标** —— 真实 LLM 预训练**全部不完全满足**
   - 尺度不变性是关键的「免费午餐」前提 —— 实际训练目标含权重衰减、含非尺度不变成分
4. **与 MuonH 的比较不公平性可能** —— MuonH 的硬约束在某些场景下更稳定（泛化性），MuonGS 的理论优势未必反映在验证损失上
5. **无大规模对比表** —— 摘要只说「更低验证困惑」，未给具体数值
6. **实现细节缺失** —— GS 投影与 Muon 正交化的顺序、数值稳定性、是否影响与 weight decay 的交互都未说明

## 实现建议

- **实现难度**: 低到中（Muon 已是成熟实现，加一步 GS 投影即可）
- **预期性能**: 小规模长训练下相对 MuonH **最高 ~15% token 等效加速**；主流短训练下**可能无收益**
- **适用场景**: **长时程预训练** —— 大规模持续预训练、模型持续训练（continual pretraining）
- **落地注意**:
  1. **先验证范数假设成立** —— 跑一段训练观察 $\|W\|_F$ 是否真的按 $\sqrt{t}$ 增长，不成立则理论前提失效
  2. **监控 $C_T$ 曲线** —— 这是本文最实用的诊断指标，能直接看出优化器是否进入停滞
  3. **务必与 MuonH 同预算对比** —— 注意 token 等效加速的口径
  4. **不要在 400M 规模做决策** —— 15% 在小规模常被高估

## 我的评注

> 这篇是我今天最喜欢的**理论型工作**，因为它做了一件很少有人做的事：**给一个「大家都在用但说不清为什么」的做法找到了正确的度量。**
>
> 「累积有效学习率 $C_T = \sum \eta_t / \|W_t\|_F$」这个量选得非常漂亮。它把三件看似无关的事串起来了：名义学习率、权重范数、训练进度 —— 而这三者的组合恰好决定了「模型现在还能走多远」。一旦有了这个标量，所有范数控制方法就可以排成一列比较：vanilla Muon 是 $O(\log T)$，MuonW/MuonH 是 $\Omega(T)$，MuonGS 是 $\Omega(\sqrt{T})$。
>
> 而最有价值的一步是**反直觉的那一步**：既然 $C_T$ 才是目标，那就**不必固定范数**。只用 GS 把更新的径向分量投影掉，让范数自然增长到 $O(\sqrt{t})$，就能拿到 $\Omega(\sqrt{T})$ 的累积 —— **放松约束反而比硬约束更好**。这个结论有真正的设计哲学意味：「约束是手段，累积才是目的」。而且它解释了为什么 Muon（无约束）比 Adam 系慢 —— 不是算法差，是范数失控导致累积停滞。
>
> 保留意见集中在**外推性**。三个假设（有界更新方向、常数学习率、尺度不变目标）在真实预训练里都是近似成立的，且尺度不变那个「免费午餐」在含 weight decay 的目标下并不干净。更要命的是 400M 规模 —— 15% 的 token 加速在 400M 上很可能是「长时程 + 小模型」的特例。我见过太多在小规模上漂亮的加速结果在 7B 上缩水一半。
>
> 但**$C_T$ 这个诊断指标本身值得单独采纳**。它只有一行计算，却能把「我的优化器是不是进入停滞了」这个问题变成可测量的。不用等复现 MuonGS，先把这个指标加进训练日志。
