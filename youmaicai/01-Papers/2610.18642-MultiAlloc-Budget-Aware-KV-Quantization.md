## 核心贡献

> 在固定 KV cache memory budget 下，自适应地在 *layer-wise precision* 与 *token-wise preservation* 之间分配量化资源。

1. **Profiling-guided 分配**：离线轻量 profiling → 刻画 layer sensitivity + token importance
2. **自动分配策略**：无 online search，直接由 memory-accuracy 折衷曲线推导出分配方案
3. **跨架构 generalization**：在 Mistral / Llama / DeepSeek-Qwen / QwQ 上均超单粒度 baseline
4. **多 benchmark 一致提升**：reasoning + long-context benchmark 验证

---

## 技术方案

### 核心思想

现有 KV cache 量化方法沿两条独立路线：

- **Layer-wise**：对敏感层用更高 bit
- **Token-wise**：对重要 token 保留更多精度

实战的关键不是"如何压缩"，而是"在固定预算下如何 *分配* 资源"。MultiAlloc 提出 profiling-guided 框架，先 offline profile 找出每层的 sensitivity + 每 token 的 importance，再按 memory-accuracy 折衷曲线自动分配 layer-wise 与 token-wise 的资源比例。

### 关键技术

| 技术 | 说明 |
|------|------|
| Lightweight offline profiling | layer sensitivity + token importance |
| Memory-accuracy 折衷曲线 | 推导 best split ratio |
| Adaptive precision allocation | layer-wise + token-wise 联合优化 |
| 固定 memory budget 下的推理 | 无 online search |
| 跨架构验证 | Mistral / Llama / DeepSeek-Qwen / QwQ |

## 公式

设总 budget $B$，总 layer 数 $L$，平均 token 数 $T$。分配变量：

- $b_p^{(l)}$: layer $l$ 的 precision (bit-width)
- $b_t^{(i)}$: token $i$ 的保留精度 (bit-width)

约束：

```math
\sum_{l} b_p^{(l)} + \sum_{i} b_t^{(i)} \cdot \alpha_i = B
```

目标：

```math
\max_{b_p, b_t} \; \text{Accuracy}(b_p, b_t)
```

其中 $\alpha_i$ 是 token importance 权重（profiled offline）。

## 实验结论

- **基准**：reasoning + long-context benchmark
- **基线**：layer-wise / token-wise / recent multi-granularity KV cache 量化
- **结果**：在 Mistral / Llama / DeepSeek-Qwen / QwQ 上一致超所有 baseline，匹配 memory budget
- **Inference 时无 search**：offline profile → online 应用，零额外 cost

---

## 局限性

- Profile 需 per-model 计算（迁移性未深入）
- 仅在 dense Transformer 验证（MoE / hybrid sparse 未覆盖）
- Token importance profile 是静态的（不能随 sequence 演化）
- 未考虑 prefix-cache / 多 turn 复用的特殊场景
