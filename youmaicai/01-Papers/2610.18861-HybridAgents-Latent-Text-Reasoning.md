## 核心贡献

> 让 agent 在 latent space 和 text space 之间动态切换——一个统一的生成过程既可"内部思考"又可"外部行动"，同时保留可检查性和工具调用能力。

1. **HybridLink**：轻量桥接组件，让文本与 latent 模式无缝过渡
2. **连续 working memory**：跨多 turn 保留 lossless hybrid context
3. **HybridSFT + HybridRL**：专用 post-training，让 backbone 学会 *何时* 在 latent 思考、*何时* 在 text 行动
4. **3 模型规模 × 11 基准一致提升**：math / science / medicine / search / agentic reasoning；**+10.4%** vs SOTA frontier agents，token reduction **35.5%-54.7%**，推理速度 **1.8-2.6×**

---

## 技术方案

### 核心思想

传统 agent 完全在 text 里思考（verbose、可检查、但慢且冗余），latent reasoning 速度快、紧凑、但不可检查且无法调用工具。HybridAgents 把两者融合到一条生成流：

- **何时 latent**：内部 sub-step、reasoning 单元阶段
- **何时 text**：需要调用工具、给出 answer、输出可审计步骤
- HybridLink 维护 latent ↔ text 双向通道；working memory 防止信息跨 turn 丢失

### 关键技术

| 技术 | 说明 |
|------|------|
| HybridLink | 轻量 router/controller，在 latent token 与 text token 之间切换 |
| Continuous working memory | 跨多 turn 的 hybrid context（latent + text tokens） |
| HybridSFT | 让 backbone 学会与 HybridLink 协同 |
| HybridRL | 学习 *何时* 在 latent、*何时* 在 text |
| Tool-integrated latent 模式 | latent 内部思考结束后触发 tool call |

## 公式

设生成过程为 $\{z_1, z_2, \dots, z_T\}$，其中 $z_i \in \mathcal{L} \cup \mathcal{T}$（latent / text token space）。HybridLink 控制模式切换：

```math
p_{\theta}(z_t \mid z_{<t}) = 
\begin{cases}
p_{\theta}^{\text{latent}}(z_t \mid z_{<t}, m_{t-1} = \mathcal{L}), & \text{if } m_t = \mathcal{L} \\
p_{\theta}^{\text{text}}(z_t \mid z_{<t}, m_{t-1} = \mathcal{T}), & \text{if } m_t = \mathcal{T}
\end{cases}
```

```math
m_t \sim \pi_{\text{HybridLink}}(z_{<t}, \text{tool\_state})
```

## 实验结论

- **基准**：11 个，覆盖 math (GSM8K, MATH) / science (GPQA) / medicine (MedQA) / search (HotpotQA) / agentic reasoning (SWE-Bench, ALFWorld)
- **提升**：vs frontier LLM-agents & agentic frameworks（text + latent 两种都对比），**+10.4%** 一致平均
- **效率**：token reduction **35.5% – 54.7%**，inference **1.8-2.6× faster**，cost **2.7-3.7× 节省**
- **3 模型规模**：小到中到大均保持优势

---

## 局限性

- HybridLink 仍是 learned component，需要 tuning
- 跨 turn memory 大小需要管理（否则还是 KV-cache 占用大头）
- 模式切换的可解释性依赖 token-level mode 选择器
- 没看到在 multi-modal 工具（vision / audio）上的验证
