## 核心贡献
1. **Bridging informal ↔ formal reasoning**：将 Lean 4 信号集成到自然语言推理过程中
2. **Magenta pipeline**（training-free agentic）：
   - 给定自然语言问题 → 生成答案 → 表达为 Lean 4 陈述 → 构建机器可检查证明
   - Statement judge 验证 formalization 是否保持原问题语义
   - Error-attribution judge 将失败尝试路由到数学重新推导或局部 Lean 修复
3. **100% 准确率**：在所有评估的奥赛基准上达到 100%（包括 AIME 2025, AIME 2026, HMMT February 2026）
4. **IMO 2026**: 搭配 open-weight K2-Horizon-7B reasoner，解决全部 6 道 IMO 2026 题

## Pipeline 架构
```
Natural Language Problem
  → LLM generates answer
  → Statement Judge (Lean formalization preserves meaning?)
      → if YES: construct machine-checked proof
      → if NO: Error Attribution Judge
          → Math re-derivation OR local Lean repair
```

## 关键发现
- Statement adjudication 对防止 false certificates 至关重要
- Feedback-guided correction 优于 independent resampling（困难问题）

## 局限性
- 依赖 LLM 的自然语言数学能力
- 需要能访问 Lean 4 证明辅助工具
