# KV Cache Quantization for Diffusion Language Models

## 摘要
KV cache 量化在自回归（AR）LLM 上已被充分研究——在因果注意力下缓存的前缀状态是**精确**的，量化本质上只是 cache reconstruction 问题。但 diffusion language model（dLLM）打破了这个前提：Fast-dLLM 式的高效推理会在多个去噪步之间复用 KV 状态，而双向注意力下随着 masked token 被揭示，token 表征会改变，因此**被复用的 cache 在量化之前就已经偏离全量重算结果**。本文在这一"cache-reuse error"背景下研究 KV cache 量化：把 KIVI 与 KVQuant 适配到 Fast-dLLM 的 prefix / dual cache 复用接口，并提出两个新方法——**TRACE**（从 prompt-answer 对重建可行的 dLLM reveal 轨迹，为校准提供与迭代 masked 解码一致的状态）与 **dLLM-KVQ**（依据输出级与 attention 级行为指标，逐层挑选需要保持高精度的 K-cache 条目，同时对 V 使用标准的低比特 quantize-dequantize）。在 LLaDA 与 Dream 上、GSM8K / HumanEval / MATH / MBPP 四个任务、所报告的 4-bit 与 2-bit prefix/dual cache 设置中，dLLM-KVQ 取得所有量化方法中最高的平均分。

## 核心贡献
1. **问题重构**：首次系统性研究 dLLM 的 KV cache 量化，明确把 **cache-reuse error** 与 quantization error 分离，指出 AR 式"重建误差最小"目标在此不充分。
2. **TRACE**：轨迹重建式校准方法，把每个答案 token 分配到一个合法 reveal 步，用 min-cost max-flow 迭代精化，得到与 masked 迭代解码一致的中间状态，无需存储多步 logits/KV。
3. **dLLM-KVQ**：把自适应高精度预算花在 **K 侧**（因为 K 决定 attention 权重分配，量化扰动可把注意力质量在复用区与重算区之间搬移），V 侧走保守低比特 QDQ。
4. **逐层、逐 cache-mode、逐位宽的离散策略选择**：离线用行为指标拟合、在线只用 block-initial 前向可得的信息，不做梯度优化。
5. **实证结论**：dLLM-KVQ 不在每个单项任务上占优，但其**平均分**在所有模型 × cache mode × 位宽组合中最稳定，支持"重建误差不是生成质量的可靠预测量"的分析。

## 方法与架构
### 1. 背景形式化
dLLM 的 block 扩散解码：响应被切分为 blocks $B_1,\ldots,B_B$；在当前 block $B_b$ 内的去噪步 $t$，模型为 masked 位置预测分布并按调度揭示一批高置信度 token：

```math
x_{t+1,i}=\begin{cases}
\arg\max_v p_\theta(v\mid p,x_t,i), & i\in R_{b,t}\\
x_{t,i}, & \text{otherwise}
\end{cases}
```

Fast-dLLM 风格的 cache 复用（$\Gamma_m$ 决定哪些区域复用、哪些重算）：

```math
C^{\ell,reuse}_{t,m}=\Gamma_m\left(C^{\ell,full}_{\tau_b},\ C^{\ell,local}_{t},\ B_b\right),\qquad m\in\{\text{prefix},\ \text{dual}\}
```

其中 prefix 模式复用 prefix 区并重算 active block 与 suffix；dual 模式复用 prefix 与 suffix、只重算 active block；$\tau_b$ 是构造可复用 cache 的 block-initial 步。

### 2. cache-reuse error 的定义与分解
```math
E^{\ell,reuse}_{t,m}=C^{\ell,reuse}_{t,m}-C^{\ell,full}_{t}
```

在 AR 的因果注意力下该项对已缓存前缀 token 为零；在 dLLM 的双向注意力下一般非零（Figure 1(b) 用 K/V 特征分布图展示）。量化施加在**复用后的** cache 上，而希望保持的参考行为来自**全量重算** cache，于是：

```math
\hat C^\ell_{t,m}-C^{\ell,full}_t=\underbrace{C^{\ell,reuse}_{t,m}-C^{\ell,full}_t}_{\text{cache-reuse error}}+\underbrace{Q_\beta(C^{\ell,reuse}_{t,m})-C^{\ell,reuse}_{t,m}}_{\text{quantization error}}
```

因此问题定义从"重建"变为"在复用误差下保持行为"：

```math
\min_{Q_\beta}\ \mathbb{E}_{(p,x_t,m)\sim\mathcal{T}}\left[D_{beh}\left(y^{full}_t,\ \hat y_{t,m}\right)\right]\quad \text{s.t.}\ \mathrm{Mem}(Q_\beta(C))\le \rho\,\mathrm{Mem}(C)
```

$D_{beh}$ 可度量输出 logits、token margin、attention 行为或下游决策。

### 3. TRACE 轨迹校准（Algorithm 1）
输入：prompt $p$、answer $y$、reveal budgets $\{k_t\}$、legal windows $\{W_i\}$、round 数 $R$。
1. 初始化任一 schedule-consistent 的可行分配 $A^{(0)}\in\mathcal{C}$（每个 token 落在其 block 窗口内，每步收到规定数量的 token；约束 $\sum_t k_t=|y|$）。
2. 对第 $r$ 轮：由 $A^{(r)}$ 构造 masked 状态 $\{x^{(r)}_t\}$，计算状态矩阵 $s^{(r)}_{i,t}=\log p_\theta(y_i\mid p,x^{(r)}_t)$（仅对合法的 token-step 对）。
3. 用 **min-cost max-flow**（Edmonds & Karp）求解线性指派问题：边代价为 $-s^{(r)}_{i,t}$，每个答案 token 发一单位流到一个合法 step，每步恰好接收 $k_t$ 单位流：

```math
A^{(r+1)}=\arg\max_{A\in\mathcal{C}}\langle A, S^{(r)}\rangle
```

4. 重复直到分配稳定或达到 $R$ 轮上限。

保存的产物只含 prompt、answer 与 reveal 分配；logits 与 KV cache 按需重算。

### 4. K-cache 策略选择（离线）
候选 $a=(s,p)$：$s$ 为 token 重要性分数类型，$p$ 为每组保持高精度的 K token 数（主实验中取值集合 **{0, 1, 2, 4}**，$p=0$ 即普通低比特 K 量化）。分数类型可为：(i) block-initial 前向的 attention；(ii) 全部 K token 量化时的 K 量化误差；(iii) 二者归一化乘积（hybrid）。策略目标：

```math
L_{m,\ell}(a)=-\sum_q w_q\,\mathbb{E}_{r\in\mathcal{D}_{m,\ell}}\Delta_q(a,r)+\lambda\,\mathbb{E}_{r\in\mathcal{D}_{m,\ell}}B(a,r)
```

```math
a^*_{m,\ell}=\arg\min_{a\in\mathcal{A}_{m,\ell}}L_{m,\ell}(a)
```

$D_{m,\ell}$ 是 cache mode $m$、层 $\ell$ 的诊断记录集（每条记录 = 校准样本 × cache mode × block × 去噪步 × 层）；$w_q$ 为固定指标权重，$\lambda$ 权重为位宽惩罚，$B(a,r)$ 度量有效位宽。行为指标 $q$ 包含 centered score distance、attention KL、top-1 key agreement、top-K key recall——"越小越好"的指标用 baseline 减 candidate，"越大越好"的用 candidate 减 baseline。可行集还含约束：最大有效 K 位宽、score-distance 指标的最低 win rate。策略按 **模型 × cache mode × 目标位宽 × 层** 分别选择，且**不由梯度下降优化**，而是基于轨迹级度量直接选离散部署策略。

### 5. 在线量化
在线只使用 block-initial 前向可得的信息。若分数基于 attention，token 重要性为 active-block query 赋予的平均注意力概率：

```math
I^{attn}_i=\frac{1}{|H||Q_b|}\sum_{h\in H}\sum_{q\in Q_b}A^{init}_{\ell,h,q,i},\qquad
A^{init}_{\ell,h,q,i}=\left[\mathrm{softmax}\left(\frac{q^{init}_{\ell,h,q}(K^{init}_{\ell,h})^\top}{\sqrt{d_h}}\right)\right]_i
```

若基于量化误差：

```math
I^{qe}_i=\left\|K^{init}_{\ell,i}-\left[QDQ^{base}_\beta\left(K^{init}_{\ell,G(i)}\right)\right]_i\right\|_2
$$

KIVI 式分组沿 token 维度分组，组内保留 $I_i$ 最高的 top-$p$ 个 token 为高精度，其余用 min-max QDQ，且**量化范围只用同组中将被量化的 token 估计**（避免高精度离群值撑大低比特 token 的量化网格）。V cache 使用标准连续低比特 QDQ（提交版本无 residual tails、无 clipping）。离线可对比全量重算来选策略，但**在线推理不访问全量重算**。

### 6. 为什么预算花在 K 侧
K 状态进入 query-key score、决定 attention 权重；V 状态只在权重选定后才被读取。因此 K 量化可能在复用位置与重算位置之间搬移注意力质量，而 V 量化只扰动已被选中的位置内容。dLLM-KVQ 因此把自适应高精度预算放在 K，V 走保守低比特路径。

## 实验设置
- **模型**：GSAI-ML/LLaDA-8B-Instruct、Dream-org/Dream-v0-Base-7B。
- **任务与 few-shot**：GSM8K（5-shot）、MATH（4-shot）、HumanEval（0-shot）、MBPP（3-shot），使用 lm-eval task 定义。
- **推理配置**：generation length **256**、block length **32**、Fast-dLLM confidence-threshold parallel decoding 阈值 **0.9**；prefix 与 dual 两种 cache 模式分别评测；4-bit 与 2-bit KV cache 量化（K 与 V 同时量化）。
- **基线**：(1) full attention（no-cache，原始推理参考）；(2) prefix-cache / dual-cache（未量化 cache 参考）；(3) 适配到同一 dLLM cache 接口的 **KIVI** 与 **KVQuant**。
- **校准语料**：C4 / UltraChat / ARC / CodeSearchNet-Python 混合（默认收集 1000 / 500 / 300 / 200 条，带长度过滤）；轨迹校准用 chat-style `mixed_chat` loader，从 instruction、QA、code 三个桶按 **0.50 / 0.25 / 0.25** 权重采样 prompt-answer 对。
- **实现细节**：dLLM-KVQ group size **32**，标准连续 V 侧 QDQ；在线推理使用 block-initial 前向算出的 attention 分数 + 固定策略表。
- **硬件**：NVIDIA H200 140GB。

## 局限性
作者自述：
- 评测覆盖两个代表性 dLLM、两种 Fast-dLLM cache 模式、四个任务、4-bit 与 2-bit 设置，**未穷尽**所有解码调度、序列长度、batch size 或未来的 dLLM 架构。
- dLLM-KVQ 把自适应预算花在 K 侧，V cache 走简单低比特 QDQ；更专门的 V 侧策略可能带来额外收益（尤其在 value reconstruction 而非 attention stability 成为主导因素的场景），但与主要结论正交。
- 论文只报告任务质量与有效位宽核算，**端到端服务速度**取决于融合低比特 attention kernel 与运行时集成（引 vLLM 等）。

我的补充批评：(1) 绝对增益较小——LLaDA prefix 4-bit 平均 45.34 vs cache-only 45.08（+0.26），Dream dual 4-bit 50.09 vs 49.65（+0.44），而 cache-only 与 full attention 之间已存在明显落差（如 LLaDA dual 43.09 vs 45.96），说明真正的问题（cache-reuse 本身的损失）远大于量化带来的损失，量化侧的改进空间有限；(2) 策略是**离线逐层查表**（policy table），部署到新模型/新调度需重新做轨迹校准，方法的实际运维成本未被量化；(3) "行为指标"（centered score distance、attention KL、top-1/top-K agreement）与下游任务分数之间的关联只在 LLaDA 4-bit 上验证，Dream 上没有轨迹级诊断，因此"指标 → 生成质量"的假设在第二个模型上未被检验；(4) 双模型仅用 block length 32、gen length 256 这一组设置，长上下文下的 cache-reuse 误差可能显著更大，结论外推需谨慎。

## 评估与建议
- 是否推荐深入阅读：是（作为"dLLM 推理优化"方向的问题定义与误差分解尤其有价值；TRACE 的轨迹校准思路可迁移到其他需要中间状态校准的场景）
- 适用场景：dLLM（LLaDA/Dream 等）推理服务的 KV cache 压缩；研究"近似 cache 上的量化"这一类问题；需要按层选择混合精度策略的量化工作。
- 与知识库的关联：与 2610.38095（Nemotron 3.5 的 NVFP4/KV cache 量化与 ReplaySSM）形成对照——AR 场景下 KV cache 是精确的、量化纯是重建问题，dLLM 场景则多了一层复用误差；可与 KV cache 压缩类笔记（KIVI、KVQuant、SnapKV、PyramidKV）并列；也提示"量化指标（重建误差）与下游质量的脱钩"这一主题。
