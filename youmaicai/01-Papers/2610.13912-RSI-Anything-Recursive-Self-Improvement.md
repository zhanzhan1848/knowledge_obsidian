## 核心贡献

> 提出基于预测式世界模型 (JEPA-Anything) 的递归自我改进（RSI）框架，用预测可靠性替代昂贵的外部反馈。

1. **领域通用 RSI 框架**: 在代码修复、GUI、实验室规划、反应优化等异质任务上验证递归自我改进
2. **预测式选择**: 用世界模型预测替代外部 verifier；code repair 成功率从 26.3% → 31.2%
3. **保留门控**: component + compatibility 检查决定 policy-model 对是否保留；五轮迭代实验室规划 21.80% → 46.01%

---

## 技术方案

### 核心思想

传统 RSI 依赖昂贵的外部反馈信号（人评、verifier），而 world model 的预测在 policy 演化时会变得不可靠。本文构建 **RSI-Anything**：
- **observed feedback** → 驱动 policy / workflow 改进 & world-model 自适应
- **prediction-driven selection** → 用世界模型预测筛数据
- **retention checks** → 组件+兼容性双层检查决定更新是否保留

### 关键技术

| 技术 | 说明 |
|------|------|
| JEPA-Anything | 基础预测世界模型 |
| Predictive selection | 用模型预测代替 verifier 评分 |
| Conditional WM adaptation | 反馈驱动世界模型动态调整 |
| Component & compatibility check | 决定 policy-model pair 保留与否 |

### 关键公式（条件化世界模型）

```math
p_{\theta_{WM}}(s_{t+1} \mid s_t, a_t; \mathcal{D}_{\text{buffer}})
```

其中 $\mathcal{D}_{\text{buffer}}$ 随 policy 演化而更新。

## 实验结论

- **代码修复** (coder固定): 26.3% → 29.2% (predictive) → 31.2% (WM-adapted)
- **GUI 任务**: 平均动作数 -39.4%
- **实验室规划** (5轮迭代): 21.80% → 46.01%
- **反应优化** (40 实验预算): mean best yield **96.15%** vs Bayesian 82.16%
- **领域跨度**: code / GUI / lab-planning / chemistry / immune-science

---

## 局限性

- 世界模型预测可靠性是天花板，policy 漂移过大时 WM 可能失效
- 组件+兼容性检查阈值需要任务级调参
- 缺少对长链 reasoning-only 任务（如数学）的评估

---

## 实现建议

- **实现难度**: 中等（JEWMPA 已有开源实现）
- **预期性能**: 相对静态 verifier 提升 2-5 pp
- **适用场景**: 外部 verifier 昂贵或不可得的任务；可批量实验的科学发现
