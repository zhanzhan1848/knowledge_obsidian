# MATO: Multi-objective Personalized Alignment with Test-time Optimization for Large Language Models

> **arXiv**: [2605.25342](https://arxiv.org/abs/2605.25342)
> **发表日期**: 2026-05-25
> **分类**: cs.CL (Computation and Language)
> **会议/期刊**: NeurIPS 2026（Accepted by NeurIPS 2026）

## 📋 摘要

让大语言模型同时满足多个相互冲突、且随时间演化的用户偏好，是个性化 AI 系统的核心难题。现有方案要么依赖代价高昂的训练（为每个偏好单独做 RLHF），要么需要为每种偏好预训练一个奖励模型，因此难以跟上偏好的动态变化。纯提示（prompting）虽然免训练，但可控性差：模型往往对某些偏好过度强调、对另一些忽略，在目标冲突时用户无法可靠地调节各目标的相对权重，导致对齐效果不理想。本文提出 **MATO**——一个免训练的多目标个性化对齐框架，把「个性化」重述为**测试时优化**问题：在解码过程中用可控权重引导多个目标的相对重要性，既不改动模型参数，也不依赖外部奖励模型。MATO 包含两个核心模块：**奖励发现模块**从主干 LLM 自身构造由提示导出的代理奖励（surrogate reward），以支持用户用自然语言指定的多种目标；**权重优化模块**则依据用户初始偏好与已生成的部分响应，在生成过程中动态调整各目标的权重以平衡竞争目标。最终，代理奖励与动态权重共同在 token 分布上执行在线优化。在多个数据集与多种主干 LLM 上的实验表明，MATO 一致优于强基线，实现了 Pareto 改进的多目标对齐与更强的可控性（steerability）。作者据此认为，测试时优化是实现可扩展、可控、模型无关个性化对齐的一条有前景的路线。

## 🎯 核心贡献

1. **把多目标个性化重述为测试时优化问题**：不训练、不改参数、不需要外部奖励模型，仅在解码期做在线优化，把「个性化」从训练阶段迁移到推理阶段。
2. **奖励发现（Reward Discovery）模块**：从主干 LLM 自身引导出针对自然语言描述的多种目标的**代理奖励**，绕开了为每个偏好单独训练奖励模型的成本。
3. **权重优化（Weight Optimization）模块**：依据用户初始偏好 + 部分已生成响应，在解码过程中动态调整各目标权重，从而在目标冲突时提供可靠的控制旋钮。
4. **Pareto 改进的多目标对齐**：在多个数据集与多种主干 LLM 上持续优于强基线，同时显著提升 steerability，验证了「测试时优化」作为个性化对齐范式的可行性。

## 🔧 方法/架构

- **问题形式化**：多目标个性化对齐 = 在固定权重向量 $\mathbf{w}$ 下最大化多个目标的加权和；但权重需随生成过程动态变化：

  ```math
  \max_{\mathbf{w}}\ \sum_{i=1}^{m} w_i \cdot R_i(x, y)
  \quad\text{s.t.}\quad
  \mathbf{w} = f\big(\mathbf{w}_0,\ \text{partial}(y)\big),\ \ w_i \ge 0,\ \sum_i w_i = 1
  ```

  其中 $R_i$ 是目标 $i$ 的代理奖励，$f$ 是权重优化模块，$\mathbf{w}_0$ 为用户初始偏好。

- **奖励发现模块**：以主干 LLM 自身作为裁判，针对自然语言描述的目标 $i$ 生成代理奖励 $R_i$，随生成推进实时更新，避免离线预训练奖励模型。

- **权重优化模块**：输入为用户初始偏好 $\mathbf{w}_0$ 与当前部分响应 $\text{partial}(y)$，输出归一化权重向量 $\mathbf{w}$，用于在目标冲突时做在线再平衡。

- **在线 token 级优化**：代理奖励与动态权重共同作用在 token 分布上，形成生成期的在线引导（类似 best-of-n 的连续化版本，但奖励与权重都在生成中持续变化）。

- **免训练特性**：整个流程不触碰模型参数，因此可直接套用在任意主干 LLM 上（model-agnostic）。

## ⚠️ 局限性

- 摘要未给出具体数值结果与消融细节，性能结论的可复现性需查阅全文与代码（论文未在 comment 中提供代码链接）。
- 依赖主干 LLM 自身产生代理奖励，**奖励质量受主干模型能力与自评偏差限制**；对更强/更对齐的主干模型效果是否稳定未说明。
- 解码阶段的在线优化会**增加推理时开销**（多轮奖励计算 + 权重更新），但摘要未报告延迟/成本指标。
- 「天然语言描述的目标」如何被解析为可优化的奖励信号，其歧义性与边界情况未在摘要中说明。
- 实验主要集中在英语与学术/日常对话语料，跨语言、跨文化偏好冲突场景未涉及。

## 💡 建议

- 是否推荐使用：**是**（作为免训练个性化对齐的可控性方案值得重点关注）
- 适用场景：多偏好冲突的用户助手（写作风格 + 内容准确性 + 长度约束等组合）、需要在不重训模型的前提下给用户暴露「偏好权重」旋钮的产品、需要模型无关（可热切换主干）的个性化服务、算力受限无法为每个偏好训练奖励模型的场景
