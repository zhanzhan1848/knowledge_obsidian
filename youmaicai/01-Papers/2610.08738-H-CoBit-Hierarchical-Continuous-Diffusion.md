## 核心贡献

1. **H-CDLM 框架**：联合连续扩散多模态（tokens + 粗粒度 cluster tokens）的层级式连续扩散语言模型。
2. **H-CoBit / H-FLM**：将 H-CDLM 应用到 CoBit 与 FLM 两个连续 diffusion 基座，一致带来提升，证实框架的可推广性。
3. **多模态独立采样调度**：每个模态可独立选择 sampler 与 schedule，提升模态间协同效果。

## 模型架构 / 方法

- 在连续 diffusion 空间中扩散两种模态：
  - **细粒度 token 表征**
  - **粗粒度 cluster 表征**（由预训练 token embedding 聚类得到）
- 每种模态使用独立的 sampler / schedule（per-modality schedulers）。
- 计算/参数开销极小，仅靠引入粗粒度表征通道。

```math
\mathcal{L}_{\text{H-CDLM}} = \mathbb{E}_{t, x_0, x_T}\Big[ \| s_\theta^{(\text{token})}(x_T^{(\text{token})}, t) - \nabla \log p_t(x_0^{(\text{token})}) \|^2 \\
+ \| s_\theta^{(\text{cluster})}(x_T^{(\text{cluster})}, t) - \nabla \log p_t(x_0^{(\text{cluster})}) \|^2 \Big]
```

## 实验结果

| Benchmark | 基座 | 提升 |
|------|------|------|
| LM1B GenPPL | CoBit → H-CoBit | 24.2 点改进（达到 49.4） |
| OWT GenPPL | CoBit → H-CoBit | 20.7 点改进（达到 50.4），超过同等规模 discrete DLMs |
| GSM8K accuracy | H-CoBit | 27.4%，超过之前的连续 diffusion / flow-based 模型 |
| MAUVE | H-CoBit | 提升 |
| FLM → H-FLM | Flow Matching | 一致提升，框架可推广 |

## 局限性

- 聚类质量受预训练 token embedding 限制；不同 tokenizer / 嵌入空间下的鲁棒性需进一步验证。
- 推理时多模态调度增加少量复杂度，需独立调度器协同。
