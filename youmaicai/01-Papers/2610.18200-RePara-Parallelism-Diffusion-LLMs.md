# A Few More Tokens Ahead: Reinforcing Parallelism in Diffusion LLMs

## 核心贡献

> 系统评估 4 个 diffusion LLM 在 parallel generation 下的退化（math / code 在 16 tokens/step 全部 <15%），并提出 *RePara*——用 GRPO 强化 short consecutive token blocks 的并行性，rollout 与 log-prob 成本更低。

1. **Fixed-quota evaluation**：揭示 diffusion LLM parallel 生成在 math / code 上严重退化（16 tokens/step → 全部 <15%）
2. **Token-level probe**：math 文本在局部 prefix 附近有 strong predictive potential
3. **RePara**：GRPO 强化 short consecutive blocks，降低 rollout & recomputation cost
4. **vs JustGRPO**：在 reduced denoising budget 下仍提升 GSM8K / MATH-500
5. **效率**：LLaDA / MATH 设置下 **1.96×** training-step speedup

---

## 技术方案

### 核心思想

Diffusion LLM 的并行优势是"inherent"的假设被实测反驳：4 个模型在 16 tokens/step 下 math / code 退化严重。Token-level probe 显示 math 文本在短 prefix 局部有较强预测势能——*短 consecutive blocks* 是值得强化并行能力的位置。RePara 用 GRPO 强化这些 block 的正确率，同时通过 short-block 选择降低 rollout 与 recomputation 成本。

### 关键技术

| 技术 | 说明 |
|------|------|
| Fixed-quota evaluation | 固定每步 token 数评测并行性 |
| Token-level probe | 测 prefix 局部 predictive potential |
| GRPO on short blocks | 强化 short consecutive blocks |
| Rollout cost reduction | short blocks rollout 更便宜 |
| Log-prob recomputation 优化 | 减少重复计算 |

---

## 公式

设 diffusion LM 输出 token sequence，denoising 步 $t$ 一次预测 $k$ 个 token。RePara 优化目标：

```math
\max_{\theta} \mathbb{E}_{(x, y^*) \sim \mathcal{D}} \bigl[ \sum_{b \in \text{short\_blocks}} \text{reward}_{\text{GRPO}}(\pi_\theta(\cdot \mid \text{ctx}(b))) \bigr]
```

GRPO advantage：

```math
A_i = \frac{r_i - \text{mean}(r)}{\text{std}(r)}
```

reward：short block 内 token 的 matching score。

---

## 实验结论

- **基准**：GSM8K, MATH-500
- **模型**：LLaDA, SDAR
- **vs JustGRPO**：reduced denoising budget 下 RePara 仍胜出
- **训练加速**：LLaDA / MATH **1.96×** step speedup
- **实用性**：short-block 选择使 rollout / log-prob cost 大幅降低

---

## 局限性

- 仅验证 math（GSM8K / MATH-500）；code 评测是否同等收益未充分
- Short-block size 是超参数
- 与 JustGRPO 的对比是否公平（denoising budget 不同）
- Long block 并行性仍然欠佳
