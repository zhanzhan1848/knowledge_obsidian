# An Information Bottleneck for Post-hoc Memorization Mitigation in LLMs

## 摘要
研究表明 LLM 会**记忆并复现受版权保护的训练数据**，引发隐私与知识产权关切。本文研究：能否在**不修改、不重训**底层模型的前提下**缓解记忆**？作者提出一个**模块化、即插即用**的框架，在**冻结的 LLM 骨干**与其语言建模头之间插入一个**非参数变分信息瓶颈（NVIB）**。通过在 token 预测前**压缩最终隐藏表示**，该瓶颈旨在**保留通用语言知识，同时过滤掉高度具体的记忆序列**。在涉及书籍段落的**记忆提取任务**与标准语言建模基准上评估该方法，测量**记忆减少与下游效用之间的权衡**。实验表明 **NVIB 层显著降低可提取性，同时在基准任务上保持有竞争力的表现** —— 说明**加入信息瓶颈提供了一条实用且架构上可插拔的缓解路径**。

## 核心贡献
1. 提出在**冻结骨干与 LM 头之间**插入**非参数变分信息瓶颈（NVIB）**的模块化即插即用框架
2. **无需修改或重训底层模型** —— 记忆缓解从「重训」降级为「加一层」
3. 目标函数明确：**保留通用语言知识 + 过滤高度具体的记忆序列**
4. 在记忆提取任务（书籍段落）与标准 LM 基准上**同时评估记忆减少与下游效用**，量化权衡
5. 结果：**显著降低可提取性，同时保持有竞争力的基准表现**

## 方法与架构
**架构位置**：
```
冻结 LLM 骨干
      ↓ h_final
  ┌──────────────────┐
  │  NVIB（可训练）   │  ← 压缩最终隐藏表示
  │  z = f(h_final)    │
  └──────────────────┘
      ↓
语言建模头（冻结）→ token 预测
```

**机制**：在 token 预测前压缩隐藏表示 → 保留通用语言知识（分布层面的信息），滤除**高度具体的记忆序列**（实例级细节）。

**评测双轴**：
1. **记忆提取任务**（书籍段落）→ 可提取性（应降）；
2. **标准语言建模基准** → 下游效用（应保持）。

## 实验结果
- **NVIB 层显著降低记忆可提取性**（书籍段落提取任务）
- **同时在基准任务上保持有竞争力的表现**（权衡曲线有收益）
- **模块化、即插即用**；**无需重训**底层模型

## 局限性
- 摘要未给出提取率与基准分数的具体数字（需查正文）；
- 「有竞争力的表现」是定性表述 —— 通用能力与专有能力的权衡可能不均衡；
- 非参数瓶颈的容量与训练成本未讨论；
- 依赖**能识别「什么算记忆」**的评估，可能低估了未检出的泄漏。

## 值得注意的点
把记忆缓解做成**「加一层」而非「重训」**是极大的部署优势 —— 对那些无法重训的模型（API 模型、已部署服务），这是唯一可行路径。**信息瓶颈**的选择也很精准：它从理论上保证了「保留可泛化信息、丢弃实例细节」正是它要做的优化，与「正则化压制」这类启发式做法有本质区别。
