## 核心贡献

> 利用 KV cache 中的层间对称性（symmetry），在长上下文场景下压缩显存，且**无需修改模型架构**。

1. 发现 value cache 的跨层相似性（symmetry）
2. 提出无需架构改动的 KV cache 压缩方法
3. 与现有方法（NF4 quantization、key pruning）正交可组合

---

## 技术方案

### 核心思想

Transformer 模型不同层之间存在显著的 symmetry（对称性），意味着 value cache 在层间高度相似。VFold 利用这种对称性做 **cross-layer merging**：将相似层的 value cache 合并/共享，从而压缩显存。

### 关键技术

| 技术 | 说明 |
|------|------|
| Cross-layer symmetry detection | 发现 value cache 的层间冗余 |
| Symmetry-aware merging | 合并相似层的 value 表示 |
| Architecture-free | 不修改模型，可后插拔 |
| Orthogonal composability | 与 NF4 quantization、key pruning 正交可组合 |

### 关键优势

- 无架构 overhead，部署简单
- 长上下文场景（long-context inference）显著受益
- 可与现有压缩方法叠加，进一步节省显存
