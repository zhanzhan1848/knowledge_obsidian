## 核心贡献

> 发现 value cache 中跨层相似性的"对称结构"，提出无需架构修改的 symmetry-aware value cache 合并；可与量化 / key 剪枝组合，达到单方法无法达到的压缩比。

1. 提出 **VFold**：symmetry-aware value cache merging，无需对 LLM 架构做任何修改即可减少 KV cache 内存。
2. 揭示**跨层 value cache 的对称相似性**是 LLM 中"被严重低估的容量"。
3. 与现有方法**正交可组合**：与高比例 quantization、key cache pruning 协同使用。
4. 让长 context 部署在内存受限条件下可行，**无有害性能退化、无架构 overhead**。

---

## 技术方案

### 核心思想

KV cache 在长 context 下主导 LLM 推理内存。已有 KV cache 压缩方法多需要架构修改（如 GQA/MQA）或牺牲性能。VFold 利用跨层 value cache 间的**对称结构相似性**做合并（merging）而非剪枝（pruning），保留全部信息但减少冗余。

### 关键技术

| 技术 | 说明 |
|------|------|
| Symmetry-aware merging | 利用跨层 value cache 间的对称相似性做无损 / 低损合并 |
| Architecture-agnostic | 不修改 LLM 架构（对比 GQA / MQA 需要训练） |
| Cross-layer similarity | 假设相邻层 value 表征存在冗余，合并而非丢弃 |
| 可组合性 | 与 NF4 quantization / KV-key pruning 独立组合 |
| Decoding-friendly | 解码期间几乎无额外开销 |

### 与其他方法对比

| 方法 | 是否需要改架构 | 性能影响 | 压缩方向 |
|------|--------------|---------|---------|
| MQA / GQA | 是（训练） | 中等 | KV head 共享 |
| KV quantization | 否 | 中等（高比例下退化） | bit-width |
| KV pruning | 否 | 中等（关键 token） | 弃低重要性 |
| **VFold** | **否** | **低** | **跨层合并 + 可组合** |

---

## 实验结果

- 与 baseline 比：**无有害性能退化**（perplexity / 任务精度保持）
- 与高比例量化组合：**达到单方法无法达到的压缩比**
- 与 key cache pruning 组合：进一步压缩，最小额外 cost

---

## 关键 takeaway

- **Value cache 的对称结构**是一个被低估的压缩维度，无需动架构即可利用。
- **组合 > 单点**：merging + quantization + pruning 三者独立可组合，累加效应显著。
- 长 context 场景下"无损压缩"的根本方向是**减少冗余**（merging），而非**减少信息**（pruning）。

---

## 局限性

- 跨层相似性假设在某些架构（如 MoE、hybrid SSM）下可能不成立
- 对训练-部署分布偏移的鲁棒性未充分验证
- 与不同量化方案的兼容性边界需进一步测试
