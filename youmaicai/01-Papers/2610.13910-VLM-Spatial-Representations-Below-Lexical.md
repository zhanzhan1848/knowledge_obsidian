## 核心贡献

> 揭示 VLM 的"系统性失败"：尽管在组合基准上表现良好，但内部表示对**空间关系**的编码远不如词汇信息可靠。

1. **新指标 EICS** (Evaluation-Invariant Concept Stability)：在受控单概念干预下测试表示是否稳定
2. **新基准 CASP-VL**：基于 Visual Genome 场景图的因果受控空间扰动
3. **关键发现**：关系在 predicate 自身 token 处可识别，但聚合到 EOS 或 mean pooling 后即丢失

---

## 技术方案

### 核心思想

现有 VLM 评估只看输出，掩盖了内部表示的失败。本文通过因果干预（causal intervention）直接检测**表示层面的空间关系保真度**。

### 关键技术

| 技术 | 说明 |
|------|------|
| EICS metric | 单概念干预下表示稳定性度量 |
| CASP-VL benchmark | 因果受控空间扰动（来自 VG scene graph）|
| Predicate-token analysis | 关系是否在 predicate 自身 token 处被识别 |
| Aggregation collapse | EOS / mean-pool 后空间信息丢失 |

### 核心代码（思路）

```python
# EICS: 概念稳定性
def eics(model, base_input, concept):
    rep_base = encode(base_input)
    rep_pert = encode(intervene(base_input, concept))
    return cosine_sim(rep_base, rep_pert)
```

---

## 实验结论

- **数据集**: Visual Genome 场景图 → CASP-VL
- **被测 VLM**: 多架构
- **关键结果**:
  - 空间关系保真度 << 词汇保真度
  - 即便模型在组合基准上 well-above-chance
  - 关系在 predicate token 处可识别，EOS 处丢失

---

## 局限性

- EICS 仅基于单概念干预，无法刻画多概念组合干扰
- 仅关注空间关系，未涵盖时间/因果等其他关系
- 因果扰动生成依赖 Visual Genome 场景图，扩展到其他领域受限

---

## 实现建议

- **实现难度**: 中等（probing + 干预实验）
- **预期性能**: 可揭示现有 VLM benchmark 评分无法捕捉的失败模式
- **适用场景**: VLM 内部表示诊断、benchmark 设计审计
