# 带显式无偏基线的多检验国家偏见基准

> **原题**: Multi-Test Nation Bias Benchmarking of LLMs with Explicit Unbiased Baselines

| **摘要** | While prior work has highlighted that systematic nation-level bias in large language models (LLMs) can pose operational risks for international relations (IR) applications, many existing evaluations still lack a clearly specified unbiased reference (ground truth), limiting fully quantitative and cross-setting measurement. Using an expanded corpus of 722 official UN Security Council (UNSC) records, we measure nation-level bias with five complementary tests, thereby extending prior approaches to cover a broader set of bias expression channels: opinion ranking (WOW), association sorting (AK+-), vote simulation (PVS), opposition attribution (F-Oppose), and framing (Headliner). To enable grounded bias evaluation, we explicitly define an unbiased status for each test; in particular, for WOW and AK+- where ground truth is difficult to specify, we propose an action-based pseudo unbiased status derived from observable voting behavior to construct a quantifiable baseline. Benchmarking 4 LLMs (GPT-4o-mini, Llama 3.3-70B, Mistral-22B-Small, and Qwen3-30B) across the five permanent members of the UNSC, we find a test-agnostic macro-pattern: relative to the reference baselines defined for each test, model outputs lean toward the opposition (red) side for China and Russia and toward the supportive (blue) side for the U.K., the U.S., and France. These results underscore the need to audit IR-facing LLM deployments with grounded, multi-test benchmarks tied to explicit reference points. |

## 核心贡献

1. **问题**：先前工作已指出 LLM 存在系统性的**国家层面偏见**，可能对国际关系（IR）应用构成运营风险；但许多现有评测**缺少明确指定的无偏参照（ground truth）**，限制了量化与跨设定比较。
2. **数据**：扩展到 **722 份官方联合国安理会（UNSC）记录**。
3. **五种互补检验**（覆盖更广的偏见表达通道）：
   - **WOW** — 意见排序
   - **AK+/-** — 关联排序
   - **PVS** — 投票模拟
   - **F-Oppose** — 对立归因
   - **Headliner** — 框架化
4. **关键方法贡献**：为每个检验**显式定义无偏状态**。特别是 WOW 与 AK+/-（真值难定）中，提出**基于行动（action-based）的伪无偏状态** —— 从**可观测的投票行为**推导出一个**可量化的基线**。
5. **模型与对象**：**4 个 LLM**（GPT-4o-mini、Llama 3.3-70B、Mistral-22B-Small、Qwen3-30B）× **UNSC 五个常任理事国**。
6. **核心发现（test-agnostic macro-pattern）**：相对于各检验自己定义的基线，模型输出**对中国与俄罗斯偏向"对立（红）"一侧，对英国、美国、法国偏向"支持（蓝）"一侧**。

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| 技术 | 说明 |
|------|------|
| WOW / AK± / PVS / F-Oppose / Headliner | 五种偏见表达通道 |
| 显式无偏状态 | 每个检验的参照定义 |
| 行动式伪无偏基线 | 从可观测投票行为构造量化基线 |
| UNSC 722 记录 | 语料 |
| 4 模型 × 5 常任理事国 | 评测矩阵 |

### 关键发现

- **"从可观测投票行为构造伪无偏基线"** 是方法论上最巧的一步：真值（国家的"真实"中立立场）不可知，但**投票记录是可观测的** —— 用它当代理，就把一个无解的哲学问题转成了可计算的问题。
- **test-agnostic macro-pattern**（跨五种检验得出同一宏观模式）是本文最强的证据形式 —— **结论不依赖单个检验的设计选择**，这在偏见研究中非常难得。
- **中俄偏"红"、英美法偏"蓝"** 这个结论本身是政治敏感的，但论文的表述方式是**相对于各自定义的基线**，而非断言任何国家的真实立场 —— 方法上克制。
- 与 [[2026-11-02-2610.40893-qistas-a-pre-registered-portable-protocol-for-fairness-evaluation-of-lar]]（Qistas）形成互补：Qistas 走"程序对称性 + 预注册"路线（不问争议真相），本文走"多检验 + 显式基线"路线（用可观测代理定基线）。**两条路径都在解决"真值不可知"这个共同难题**。
- 与 [[2026-11-02-2610.41391-comparative-evaluation-of-llm-based-review-paradigms-for-academic-paper]]（LLM 评审范式）同属"**先解决校准/基线再谈哪个方法更好**"的方法论家族。

## 实验结果

| 配置 | 结果 |
|------|------|
| 语料 | 722 份 UNSC 记录 |
| 模型 | GPT-4o-mini、Llama 3.3-70B、Mistral-22B-Small、Qwen3-30B |
| 对象 | 中、美、俄、英、法 五个常任理事国 |
| 中国 / 俄罗斯 | 相对基线偏向**对立（红）** |
| 英国 / 美国 / 法国 | 相对基线偏向**支持（蓝）** |
| 宏观模式 | **跨五种检验一致**（test-agnostic） |

## 局限性

- "行动式伪无偏"仍是代理 —— 投票行为本身可能带有偏倚
- 样本限定于 5 个常任理事国，结论外推到其他国家未验证
- 只测 4 个模型（且以小模型为主），前沿闭源模型未纳入
- 五种检验共享部分语料，检验间独立性未论证
