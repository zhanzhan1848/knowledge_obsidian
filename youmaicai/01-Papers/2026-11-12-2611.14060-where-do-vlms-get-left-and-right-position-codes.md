## 核心要点
1. 提出三类可能的左右方向来源：**图像内容在 patch 内的朝向**、**ViT 位置编码（position code）**、以及 **LLM 侧 token 的位置与顺序**。消融实验表明 **ViT 位置编码是必要的**；进一步做**充分性测试——只镜像位置编码**：在 **Qwen2.5-VL-7B、Qwen3-VL-4B 与 InternVL3-2B** 上，镜像 ViT 宽度位置编码可在 **84.3%–93.2%** 的 CV-Bench 左右向问题上复现"图像翻转后的答案"（Qwen2.5-VL-3B 为 **87.5%**，其中部分是"左侧"回退）。
2. 在 ViT 位置编码保持完好时，**LLM 侧的 id 镜像与 token 顺序镜像**在三系列模型上都只改变很少的左右向答案（Qwen2.5-VL 的 id 测试较弱）；在 Qwen2.5-VL-7B 中，该效应集中在**全局注意力（global-attention）的 ViT block**，且**主要在最后几个 block**。在 **What'sUp** 上，**翻转内容与 token 顺序（而非位置编码）**会保留更多"在/在下"答案落在翻转图像答案上的比例。
3. 事后（post hoc）分析限定了结论边界：在 CV-Bench 含定位物体的题目上，**反转物体顺序的随机置换比保持顺序多翻转 18.9–31.0 个百分点的答案**；在 What'sUp 上（Qwen2.5-VL 与 Qwen3-VL），随机置换造成的左右向改变中落到"镜像关系"上的比例**大多低于随机水平**。以"回到原答案"计，What'sUp 上支持关系与左右向关系的对比**只在 InternVL3-2B 上清晰**。其余残余错误多表现为**无论问哪个物体都给出同一关系**，提示修复方向可能在于**关系绑定（relation binding）、物体定位或参照物的使用**。代码：https://github.com/chen4study-hub/where-vlms-get-left-right

## 摘要（原文）
A vision-language model may take left-right direction from the orientation of image content within patches,
its vision transformer's (ViT) position code, or token positions and order in its language model (LLM).
Ablations show the ViT code is necessary; we test sufficiency by mirroring only a position code. In
Qwen2.5-VL-7B, Qwen3-VL-4B and InternVL3-2B, mirroring ViT width positions reproduces the flipped-image answer
on 84.3-93.2% of CV-Bench left-right questions (Qwen2.5-VL-3B: 87.5%, partly a left fallback). With two
options, this also counts disruption; a half-grid shift flips most answers too. With the ViT code intact, LLM-
side id and token-order mirrors change few left-right answers in all three series (a weak id test in
Qwen2.5-VL). In Qwen2.5-VL-7B the effect sits in the global-attention ViT blocks, mostly the last. On
What'sUp, flipping content and token order, not the position code, keeps more on/under than left-right answers
at the flipped-image answer. Post hoc analyses qualify these results. On CV-Bench items with located objects,
random permutations flip 18.9-31.0 points more answers when reversing the objects' order than when keeping it.
On What'sUp, in Qwen2.5-VL and Qwen3-VL, the share of the left-right changes made by random permutations that
land on the mirror relation is mostly below chance. Counted as returns to the original answer, the What'sUp
contrast of support with left-right relations is clear only in InternVL3-2B. Most remaining errors give the
same relation whichever object is asked about, suggesting that repair may target relation binding, object
localization or use of the reference object.
