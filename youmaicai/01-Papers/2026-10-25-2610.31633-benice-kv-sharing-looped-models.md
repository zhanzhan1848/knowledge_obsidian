## 核心贡献

> Looped（循环深度）架构在推理时每次循环都会生成独立的 KV-cache，导致显存随循环次数线性增长；本文提出 **BeNice!** —— 一个两阶段方法（预训练 stochastic depth + 后训练 KV-cache 广播），使得最终循环的 KV-cache 可以无损共享给早期循环，从而闭合 looped 架构「质量高但推理显存贵」的缺口。

1. **提出并定义 KV-shareability 现象**：先前工作发现某些情况下可以把最终 recurrence 的 KV-cache 共享给更早的 recurrence 而不损失质量，但作者指出**其机制仍不清楚**，甚至**训练方式完全相同的 looped 架构也不一致地具备该性质**。本文把「如何使 KV-shareability 可被稳定诱导」作为核心问题。
2. **第一阶段 —— stochastic depth 预训练**：在预训练中使用 **stochastic depth**，诱导出 **contractive residual dynamics（收缩性残差动力学）**，推动各次循环的表征向**共同极限点**靠拢 —— 这是 KV 可共享的表征前提。
3. **第二阶段 —— BeNice! 后训练**：把最终 recurrence 的 KV-cache **广播（broadcast）进第一循环**，并训练模型产出**与被广播 KV 兼容的残差**，同时**保持原模型质量**（validation perplexity 与标准 finetuning 的 unshared 结果持平）。
4. **证明 KV-sharing 与其他 KV 压缩手段正交可组合**：可与 **memory-efficient sequence mixers**（multi-latent attention、Kimi delta attention）和 **低精度 KV-cache 量化**（fp8、mxfp8、nvfp4）叠加使用。
5. **在模拟低显存长上下文推理下给出端到端收益**：cache hit rate 最高 **+31.4%**，throughput 最高 **+23.6%**，**p90 time-to-first-token 最高降低 83.6%**。

## 技术方案

### 核心思想

Looped architecture 的卖点是：**参数固定、质量随深度（循环次数）提升** —— 同一组 layer block 被反复激活。但推理端的代价被长期忽视：**每次 recurrence 都要生成自己的一份 KV-cache**，因此 cache 大小随 recurrence 数**线性增长**。

已有的 KV-sharing 观察（最终 recurrence 的 KV 可直接共享给早期 recurrence）如果成立，就等于把 cache 占用从 O(recurrences) 降到 O(1)，但它并不总是成立。本文的核心洞见是：**KV-shareability 是一种可以通过训练动力学人为诱导出来的性质，而不是架构自动附带的**。

- **阶段一（预训练期）**：使用 **stochastic depth**（随机深度）。随机丢弃残差分支迫使每条子路径的残差流变成**收缩的**（contractive），多次循环后的表征因此**收敛到同一个极限点**，不同循环的 KV 分布趋于一致 —— 为共享提供表征基础。
- **阶段二（后训练期）**：**BeNice!** 把最终 recurrence 的 KV-cache **广播**回第一循环，使第一循环必须在「别人的 KV」条件下生成残差。训练目标即让第一循环产出**兼容残差**，同时通过保持 unshared validation perplexity 来约束不损伤原模型质量。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Looped architecture** | 同一 layer block 被反复通过；参数量固定而质量随深度提升 |
| **KV-shareability** | 最终 recurrence 的 KV-cache 可共享给早期 recurrence 而不损失质量的性质 |
| **Stochastic depth（阶段一）** | 预训练期使用，制造收缩性残差动力学，使各循环表征趋于共同极限 |
| **Contractive residual dynamics** | 残差流在循环间的收缩性，是 KV 分布对齐的机制性解释 |
| **KV-cache broadcast（阶段二）** | 把最终 recurrence 的 KV-cache 注入第一循环，构造「不兼容 KV」训练信号 |
| **Compatible residual training** | 训练第一循环产生与被广播 KV 相容的残差输出 |
| **Quality preservation** | 后训练以 unshared validation perplexity 与标准 finetuning 对齐，防止质量退化 |
| **Orthogonal composition** | KV-sharing 与 MLA / Kimi delta attention / fp8 / mxfp8 / nvfp4 量化可同时使用 |
| **Simulated low-memory long-context inference** | 在模拟的低显存长上下文设定下测 cache hit rate、throughput、p90 TTFT |

## 关键实验结果

| 指标 | 结果 |

| **与 sequence mixer 组合** | 可与 **multi-latent attention、Kimi delta attention** 等 memory-efficient sequence mixer 叠加 |

## 关键结论

1. **Looped 架构的显存瓶颈不在参数，而在 inference 时的 cache 复制。** 反复通过同一 block 意味着参数量不变，但每次 recurrence 生成独立 KV-cache → 线性显存增长。KV-sharing 是绕开这个瓶颈的**结构性解法**，而非量化/压缩类的折中解法。
2. **KV-shareability 不是架构自带的性质，而是训练动力学的产物。** 「训练方式完全相同的 looped 架构也不一致地具备该性质」这一观察本身就说明：分享与否取决于**表征是否收敛到共同极限**，而这可以通过 stochastic depth 人为诱导。
3. **KV-sharing 与既有 KV 效率技术是「正交可组合」的**，而非互斥替代 —— 这是本文最有工程价值的一点：可以在 MLA/量化之上再叠一层。
4. **「更快」的来源是 cache 复用而非算力削减**：cache hit rate 提升 → 更多前缀无需重算 → TTFT 的 p90 大幅下降（最高 83.6%），在低显存长上下文场景下尤其明显。

## 局限性

- 摘要中**未给出具体模型规模、层数、循环次数、benchmark 名称与绝对数值**，所有收益均以「up to」（最高）表述，**缺少分布与平均口径**；评估这些方法的读者需要看正文/附录才能判断典型收益。
- **KV-sharing 的适用边界未在摘要中界定**：摘要强调「in some cases」的先前观察，本文把它推进为「可诱导」，但**哪些任务/架构仍然不适用**（例如需要循环间差异化表征的任务）未说明。
- **后训练阶段需要构造不兼容 KV 的训练信号**，其**额外训练成本与对基座能力的扰动幅度**摘要未报告。
- 端到端收益来自 **simulated** 低显存长上下文推理环境，**与真实生产 serving 栈（vLLM / SGLang 等对 looped 架构的实际支持程度）** 的差距未知。
- 「保持原模型质量」的度量仅以 **unshared validation perplexity** 表述，**perplexity 相等不保证下游任务表现等价**。
- **代码未公开**（摘要未给链接），复现门槛较高。
