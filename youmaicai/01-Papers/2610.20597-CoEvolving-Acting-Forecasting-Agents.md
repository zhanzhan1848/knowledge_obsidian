## 核心贡献

> 把 **多步 action forecast** 作为第三类辅助目标加入 agent RL，让 acting 与 forecasting **co-evolve**。

1. **第三类辅助目标**：除了 value targets（per-step success probability）和 observation targets（next state），再加 multi-step action sequence targets。
2. **时序 ensemble**：每个 action 在每个 preceding history 上都被教 → 共享 backbone 吸收 temporal ensemble。
3. **强 sample efficiency**：在 ALFWorld / ScienceWorld / WebShop / τ²-bench / AppWorld 上，sample efficiency 提升 **1.9× (vs ECHO) / 2.0× (vs GRPO)**。

---

## 技术方案

### 核心思想

Agentic RL 三类中间监督信号各有缺陷：
- **Value targets**：估算 per-step success prob → 来自同一个 scalar 信号；
- **Observation targets**：拟合环境响应 → 长且噪声，只覆盖一步；
- **？**：multi-step action targets → 利用**成功 on-policy 轨迹中未来的 action 序列**。

新方法在成功轨迹上，对每个 history h_i，训练 policy backbone 生成 h_i 之后的 action 序列。每个 action 又可被从前面任一 history forecast → 形成 temporal ensemble，共享 backbone 吸收。

推理仍是逐 action 决策，零额外 overhead。

### 关键技术

| 技术 | 说明 |
|------|------|
| Multi-step action targets | 第三类辅助信号 |
| Temporal ensemble | 多 history 视角训练同一 action |
| On-policy 成功路径 | 只在成功轨迹上构造 |
| Shared backbone 吸收 | 一个 backbone + 多视角 loss |
| Inference 零 overhead | 仍逐 action 生成 |

## 实验结论

- **任务**: 5 benchmarks (ALFWorld, ScienceWorld, WebShop, τ²-bench, AppWorld)
- **基线**: GRPO, ECHO, RL baselines + predictive auxiliary targets
- **结果**:
  - 综合 performance 超过 GRPO + predictive auxiliary baselines；
  - realistic application 上整体性能提升；
  - **ScienceWorld sample efficiency 1.9× vs ECHO, 2.0× vs GRPO**；
  - 单 backbone，无需额外 model / 分离预训练 / 推理开销。

---

## 局限性

- 依赖 on-policy 成功轨迹 → 探索稀疏任务上信号不够；
- multi-step horizon 的 credit assignment 仍不完美；
- ensemble 训练对超参数敏感（horizon 长度、loss weighting）。
