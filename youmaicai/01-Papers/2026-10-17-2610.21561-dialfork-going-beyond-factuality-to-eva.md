## 核心贡献

> Factuality hallucination 已大量研究，但**procedural hallucination** 被忽视——agent 输出**单看流畅 + 事实合理**，但**背离了预期的对话流程**。

1. 提出 **DialFork**：**首个**在 raw dialogue text 上测量 procedural hallucination 的 benchmark。
2. 构建方法：
   - 在 conformant dialogues 的**受控 turn 位置 fork**
   - 注入 4 类 hallucination 之一
   - 30 名人工标注员验证构造质量
3. **36,278 dialogues / 24 tasks / 12 domains**
4. 定义 **3 个评估任务**刻画 procedural deviation，3 个粒度
5. 揭示当前 agent 的 procedural hallucination 普遍性。

---

## 技术方案

### Procedural Hallucination
```
对话应该遵循预定义流程 (state machine / SOP)
但 agent 输出：单看 OK → 联合偏离 → procedural hallucination
```

### 4 类注入的 Hallucination
1. **Premise violation**：agent 接受了错误前提
2. **Skip step**：跳过必要的对话步骤
3. **Out-of-order step**：步骤顺序错乱
4. **Loop / repetition**：循环冗余

### 3 个评估任务（粒度）
1. **Turn-level**：单轮是否合规
2. **Dialogue-level**：整体是否最终到达正确状态
3. **Process-level**：路径是否合理

---

## 实验结论

- 现有 SOTA agent 在 DialFork 上 procedural hallucination **远超 factuality hallucination**。
- 不同任务 / domain 表现差异显著。
- 提供了 4 类 hallucination 各自的频率与难度分析。

---

## 关键洞察

- **Procedural ≠ Factual**：传统 factuality 检查**抓不到**流程偏离。
- **Multi-turn agents** 比 single-turn QA 更需要 process 评估。
- 这对客服 / 教学 / 流程 agent 是**关键质量维度**。
