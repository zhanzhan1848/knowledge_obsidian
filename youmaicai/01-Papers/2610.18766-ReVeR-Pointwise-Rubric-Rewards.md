## 核心贡献

> Reward model 从 *response-induced rubric* 转为 *task-induced rubric*——rubric 不再被 response 候选诱导，并且用工具增强的 judge 给出 pointwise verdict，可直接用于 policy optimization。

1. **Task-only rubric reasoning**：rubric 由 instruction 单独推理得到，不看 response 候选 → 避免 response-induced bias
2. **Hard rules + graded principles**：rubric 同时包含两类
3. **Tool-augmented pointwise judging**：judge 可调工具，避免仅靠 reading 的 mechanical constraint 错误
4. **Label-blind distillation**：preference label 仅用作 filter，仍能扩展到 large-scale trace 数据集 *ReVeR-Traces*
5. **下游 policy optimization**：pointwise verdict 直接可优化；实证显示 preference accuracy 与 downstream policy 解耦

---

## 技术方案

### 核心思想

现有 rubric RM 的两个问题：(1) rubric 从 candidate responses 反推 → bias 候选集；(2) pairwise judge 给的是相对偏好，不直接可优化。ReVeR 解决思路：

- **Rubric 与 verdict 分离**：rubric 只看 instruction → hard rules + graded principles；verdict 单独算 + 工具增强
- **Label-blind distillation**：让 LLM 生成 rubric-reasoning + verdict 序列 → preference label 只做 filter（避免 leakage）
- **Pointwise**：每个 response 给独立 verdict → 可直接训练 policy

### 关键技术

| 技术 | 说明 |
|------|------|
| Task-induced rubric | rubric 推理只用 instruction |
| Hard rules | 硬性约束（如字数、格式） |
| Graded principles | 软性评分维度 |
| Tool-augmented judge | judge 可调用代码 / 搜索 / 验证器 |
| Label-blind distillation | label 不进入 rubric 推理 |
| Pointwise verdict | 单 response 可判独立 verdict |

## 公式

设 instruction $x$，response $y$。Rubric 先由 $M$ 从 $x$ 生成：

```math
r = M(x), \quad r = R_{\text{hard}} \cup R_{\text{soft}}
```

Judge $J$ 用工具 $T$ 给出 verdict：

```math
v(y \mid x) = J(y, r, T)
```

Policy reward：

```math
R(x, y) = v(y \mid x)
```

下游 policy optimization：

```math
\max_{\pi} \mathbb{E}_{x, y \sim \pi(\cdot \mid x)} \bigl[ v(y \mid x) \bigr]
```

## 实验结论

- **vs pairwise rubric RM**：ReVeR 平均 preference accuracy 更优（最显著在 instruction following）
- **Test-time scaling**：随 inference budget 增大效果持续提升
- **下游 policy optimization**：ReVeR 优于 pairwise RM
- **关键发现**：
  1. Generator RL 提升 preference accuracy 但 *降低* rubric fidelity
  2. Higher preference accuracy 不一定对应 better downstream policy
  3. **Rubric fidelity / preference accuracy / downstream utility 是三个独立属性**

---

## 局限性

- 工具增强 judge 的工具集选择影响 verdict 质量
- Graded principles 评分粒度仍由模型决定
- Label-blind distillation 是否有更优 filter 策略待研究
- 没看到在 agent RL（vs 单轮 QA）的 standalone question
