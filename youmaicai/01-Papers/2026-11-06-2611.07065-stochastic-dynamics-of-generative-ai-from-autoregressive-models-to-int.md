# Stochastic Dynamics of Generative AI: From Autoregressive Models to Interacting LLM Networks and Neural SDEs

## 摘要
本文从**随机动力系统**视角统一三类生成式 AI 模型。第一，把 LLM 形式化为**高维非线性自回归模型**，含基于注意力的依赖；该形式化把**条件最大似然预训练**与**逐 token 生成**联系起来，并给出 LLM 运行的概率解释。第二，考虑**相互交互的 LLM 网络**，通过**平均场常微分方程**刻画其集体行为 —— 这为理解**涌现的优先连接（preferential attachment）**与**持续的结构性偏见**（包括**类型依赖的玻璃天花板效应**）提供了框架。第三，把**神经随机微分方程（neural SDE）**作为随机轨迹的连续时间生成模型，包括在**不规则时间间隔**上观测到的轨迹；讨论其训练，特别强调基于**粗糙路径分析（rough-path analysis）的 Wiener 空间 cubature 方法**作为 Monte Carlo 估计的高效替代。三者共同处理：概率预测、信息交换与交互网络中的涌现行为、以及路径空间生成建模。

## 核心贡献
1. 统一视角：**自回归 LLM / 交互 LLM 网络 / 神经 SDE** 三类生成模型的随机动力系统框架
2. 把 LLM 形式化为高维非线性自回归模型，连接**条件最大似然预训练**与**逐 token 生成**
3. 用**平均场 ODE**刻画交互 LLM 网络的集体行为，解释**涌现优先连接**与**类型依赖的玻璃天花板效应**
4. 把神经 SDE 用于随机轨迹（含不规则时间间隔观测），提出基于**粗糙路径分析的 Wiener 空间 cubature** 作为 Monte Carlo 的高效替代

## 方法与架构
**视角一**：LLM = 高维非线性自回归模型（注意力依赖）；
```math
p(x) = \prod_{t=1}^{T} p(x_t \mid x_{<t}), \quad
\text{预训练} \equiv \text{条件最大似然}
```

**视角二**：交互 LLM 网络 → **平均场 ODE**；
```math
\dot{\rho}_i = \sum_j \Phi(\rho_i, \rho_j) - \Gamma \rho_i
```
平均场极限给出涌现的优先连接与持续结构偏见（含玻璃天花板效应）。

**视角三**：神经 SDE 作为连续时间随机轨迹生成模型；
```math
dX_t = b(t, X_t)\,dt + \sigma(t, X_t)\,dW_t
```
训练强调 **Wiener 空间 cubature + 粗糙路径分析**，替代 Monte Carlo。

**组织方式**：概率预测 / 信息交换与涌现 / 路径空间生成建模。

## 局限性
- 综述与形式化框架性质，**缺乏实证验证**；
- 平均场假设在真实多 agent 系统中是否成立（异质性、拓扑结构）未检验；
- 粗糙路径 cubature 的实际加速比与误差界未给出实验数字。

## 值得注意的点
把 LLM 看成**随机动力系统**而非静态函数，是一个有生产力的视角 —— 它能问出「这个系统会收敛到哪」「哪些结构会持续存在」这类问题，而不是只问「这个 prompt 的答案是什么」。玻璃天花板效应的形式化尤其值得工程团队关注：**偏见被建模为系统的吸引子，而非噪声**。
