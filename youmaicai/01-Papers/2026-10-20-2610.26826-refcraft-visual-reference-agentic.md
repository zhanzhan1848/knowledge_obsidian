## 核心贡献

> 提出 **RefCraft** —— 一个针对"视觉参考条件化"agentic 生成的 benchmark，通过 300 个真实网页开发任务揭示当前 frontier (M)LLM 在此能力上的显著不足（最强系统仅 52.12/100）。

1. **聚焦真实工作流**：从 1-5 张参考网页截图 + 自然语言指令生成网页，比纯文本指令更贴近实际
2. **300 个真实任务**：基于自然语言 + 截图输入，要求选择性利用视觉参考
3. **多维评估**：独立可验证 keypoint + 程序化评判 + VLM 评判组合
4. **9 个 frontier (M)LLM 评测**：最强模型仅获 52.12/100，揭示视觉参考条件化仍是开放难题
5. **迭代循环要求**：Agent 需要渲染、视觉检查、迭代优化输出

---

## 技术方案

### 核心思想

现有网页生成 benchmark 多关注纯文本指令或视觉目标重建，忽略了"基于参考示例开发"这一最常见的工作流。RefCraft 显式建模该场景：agent 收到参考截图与指令，需选择性利用参考并迭代优化。

### 关键技术

| 技术 | 说明 |
|------|------|
| 300 Multimodal Tasks | 自然语言 + 1-5 张参考网页截图 |
| Selective Reference Use | Agent 必须判断哪些参考元素有用 |
| Iterative Rendering + Inspection | 渲染 → 视觉检查 → 优化循环 |
| Verifiable Keypoints | 独立可验证的检查点 |
| Programmatic + VLM Judges | 程序化与 VLM 双判互补 |

### 评估协议

```math
\text{Score} = f(\text{keypoints}, \text{program judge}, \text{VLM judge})
```

每个 artifact 在 keypoint 验证 + 程序化测试 + VLM 评判三个维度上打分。

## 实验结论

### 主要结果

| 系统 | 整体分数 (满分 100) |
|------|--------------------|
| **最强 frontier (M)LLM** | **52.12** |
| 其他 8 个系统 | < 52.12 |

### 关键发现

> 视觉参考条件化的 agentic 生成仍是当前模型的实质性挑战。最强系统仅一半得分，说明现有 frontier 在"看图理解 + 选择性参考利用 + 迭代生成"组合任务上能力受限。

---

## 局限性

- 仅聚焦网页开发场景，迁移到其他视觉参考条件化任务（如 UI 设计、文档生成）的泛化性待评估
- 评估依赖 keypoint 设定，可能无法完全覆盖创造性质量
- 300 任务规模相对中等
