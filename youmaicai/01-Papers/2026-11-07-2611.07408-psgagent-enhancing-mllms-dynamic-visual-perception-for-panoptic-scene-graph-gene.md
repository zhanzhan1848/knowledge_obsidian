# PSGAgent: Enhancing MLLMs' Dynamic Visual Perception for Panoptic Scene Graph Generation via Agentic Reasoning

### 核心贡献
1. 诊断出 MLLM 用于 Panoptic Scene Graph generation（PSG）的核心瓶颈是**感知瓶颈**：模型只能作为受固定分辨率视角限制的静态观察者（static observers limited by fixed-resolution views），因此常遗漏与小物体或边缘物体相关的关系，也难以区分复杂场景中的歧义谓词。
2. 提出 PSGAgent：通过 think-act-observe 循环的 agentic 框架，让 MLLM 动态精化视觉感知，配两种工具——Region Zoom-In Tool（局部探索小物体/边界关系）与 Visual Highlight Tool（面向关系的分割，过滤无关上下文噪声）。
3. 构建 error-aware 的 Multimodal Chain-of-Thought（M-CoT）数据集用于冷启动学习，并设计分层奖励机制（hierarchical reward）与 Group Sequence Policy Optimization（GSPO）结合，以实现策略性、自适应的工具调用。
4. 在 PSG 基准上的大量实验表明 PSGAgent 达到 SOTA 表现，兼具全局与细粒度场景理解能力。

### 技术方案
**核心思想**: 把「看图说话」式的一次性感知改造成「看得不够就主动凑近看」的 agentic 闭环——模型先用固定分辨率观察，发现关系可疑或涉及小/边缘物体时，主动调用 zoom-in 或 highlight 工具重新取证，再迭代产出场景图。

| 技术 | 说明 |
|------|------|
| Think-act-observe 循环 | MLLM 在循环中反复推理→调用工具→观察新证据，从而动态精化视觉感知 |
| Region Zoom-In Tool | 对局部区域放大探索，用于小物体与边界（boundary）关系 |
| Visual Highlight Tool | 面向关系（relation-focused）的分割，过滤掉无关的上下文噪声，缓解歧义谓词 |
| Error-aware M-CoT 数据集 | 高质量、含错误感知的 Multimodal Chain-of-Thought 标注，为冷启动（cold-start）学习提供鲁棒监督 |
| 分层奖励机制 | hierarchical reward，与 GSPO（Group Sequence Policy Optimization）结合，用于学习策略性与自适应的工具使用 |
| 任务 | Panoptic Scene Graph generation：全图 + 细粒度对象关系的联合理解 |

### 局限性
- 摘要未提供任何定量结果（无 SOTA 的具体分数、无相对提升幅度），也无基线名单，无法判断增益幅度。
- 方法依赖两阶段训练流程（error-aware M-CoT 数据集构建 + GSPO 强化学习训练），训练成本与所需标注量未说明；error-aware 数据集的构建方式与规模也未披露。
- 需在推理时多轮调用视觉工具，必然增加推理时延与计算开销，摘要未评估效率代价。
- 结论在 PSG 这一任务上验证，向其它密集视觉推理任务（如 video、3D）迁移性未讨论。

### 关键洞见
> 这篇论文把 MLLM 在密集视觉理解上的失败重新归因：**不是「不会推理」，而是「只能看一次」**。固定分辨率的静态观察者注定会漏掉小物体、边缘物体和歧义谓词，因为证据根本不在初始视野里——再强的语义推理也无法凭空补出未观测到的像素。PSGAgent 因此不靠更大模型或更多标注，而靠把「感知」变成 agent 可主动调度的动作序列；换句话说，视觉工具调用的收益不在于「看清了更多」，而在于「看的地方由任务目标引导」——这与 tool-use for reasoning 的整体趋势同源。
