## 核心贡献

> 挑战 agentic OPD 的主流解释「误差累积（compounding error）」，提出真正的问题是 **next-token 打分的短视（myopia of next-token scoring）**，并给出**无需任务奖励**的修复方案 R2S。

1. **反直觉的诊断证据**：从学生偏离教师最多的状态出发，**教师自己接管（takeover）仍能完成任务**，但学生按教师 token 打分训练后**仍会耗尽回合数**
2. **命名问题**：**rollout-scorer gap** —— 教师「做的」与它「评的」之间的差距
3. **根因**：教师逐 token 打分时看不到 episode 结局，因此放行了「安全的、拖延的」动作；outcome-based RL 会给这些零奖励，但 agentic OPD **缺这个惩罚**
4. **方案 R2S**：先修复打分器，再做蒸馏
5. **性能**：3 环境 × 2 教师 × 4 学生 = **12/12 格全胜** 3 个 SOTA 方法，平均 **+12.8 成功率点**

## 技术方案

### 问题：rollout-scorer gap

```math
\underbrace{\pi_{\text{teacher}}(a)} \text{ 完成任务}}_{\text{rollout: capable}}
\qquad\neq\qquad
\underbrace{r_{\text{teacher}}(s, a)} \text{ 允许拖延}}_{\text{scorer: myopic}}
```

主流缓解手段（episode 长度课程、教师引导回合、前缀重放、分歧处干预）都基于「误差累积」解释，本文证明不完整。

### R2S 四步流程

1. **挖掘高分歧状态**：从**未训练**的学生轨迹中找与教师分歧最大的状态
2. **教师接管**：从这些状态运行教师接管轨迹
3. **无奖励筛选**：保留「足够多接管通过」的奖励无关检查状态（**共识** 或 **LLM judge**）
4. **打分器修复**：微调教师，使其**从分歧点起对每个 assistant token 给出「基于自身接管结果」的分数**，且**上下文不含接管轨迹**

修复后的教师**冻结**，作为标准 OPD 的唯一打分器。

> **关键性质**：修复与训练**全程不需要任务奖励**。

## 实验结论

| 指标 | 结果 |
|------|------|
| 覆盖 | 3 环境 × 2 教师 × 4 学生 = **12 格全胜** |
| 平均增益 | **+12.8 成功率点**（相对每格最优基线） |
| 对比基线 | 3 个 SOTA agentic-OPD 方法 |
| 任务奖励需求 | **0**（修复与训练均无需） |

---

## 局限性

- 需要教师能「接管」—— 若教师在分歧状态本身就失败，流程无从下手
- LLM judge / 共识检查引入额外推理成本
- 学生须能产出可评估的 token 级打分（限 auto-regressive 可打分的 agent）
- 3 环境规模有限，跨领域泛化待验证

## 实现建议

- **适用场景**: 正在做 agentic 蒸馏（学生智能体在自身轨迹上训练，教师逐 token 打分）却效果不及预期的团队
- **诊断建议**: 先做**验证实验** —— 从高分歧状态让教师接管，看是否仍能完成。若能，说明是打分器短视而非教师能力不足，R2S 适用
- **落地顺序**: R2S 的步骤 3-4（共识筛选 + 打分器微调）可独立于 R2S 框架使用，作为打分器校准手段
- **⚠️ 注意**: 「无需任务奖励」是成本优势，但在**教师接管普遍失败**的任务上收益有限
