# MultiInpaintCOCO: Fine-Grained Visual Understanding in Multiple Languages

## 核心贡献
1. 将 **InpaintCOCO**（聚焦细粒度视觉细节的英文数据集）扩展到 **13 种类型学多样的语言**（覆盖 **5 个语系**），构建 **MultiInpaintCOCO** —— 一个包含 **953 个最小对（minimal-pair）样例**的多语言基准。
2. 系统评测多个 SOTA 模型在**多语言多模态检索**任务上的表现，兼顾**轻量级 VL CLIP 类编码器**与**大型语言模型**两类模型。
3. 核心经验发现：**低资源语言性能显著下降**，且最强的预测因子是**该语言可用的数据资源**，而**不是与英语的类型学相似度**。
4. 揭示**系统性英语偏置（systematic bias toward English）**：在跨语言检索中，给定「非英语的正确描述」与「英语的错误描述」，模型**倾向于选择英语的那一个**。
5. 量化该偏置**在不同架构间差异显著**：**Gemma 3 偏置最强**，**Qwen 3 偏置最弱**，尽管二者在各语言上的**单语准确率相近**。

## 问题背景
已有研究表明，视觉-语言（VL）模型难以理解**细粒度图像细节**，倾向于关注**整体布局**。更棘手的是，这种英文上的弱点在**多语言设定下会被进一步放大**——英语的弱项叠加多语言的弱项，造成复合性退化。此前缺乏一个同时满足「细粒度细节」与「多语言」两个轴的诊断基准，因此无法分离：性能下降到底来自细粒度视觉理解不足、语言理解不足，还是英语优势带来的偏置。此外，英语的强项还可能在**跨语言检索**中转化为一种隐蔽的**语言选择偏好**，污染评测本身。

## 方法

### 基准构建：MultiInpaintCOCO

以 **InpaintCOCO** 为基础（英文、细粒度视觉细节导向），做多语言扩展：

| 属性 | 取值 |
|------|------|
| 语言数 | **13** 种 |
| 语系覆盖 | **5 个**语言家族 |
| 样例数 | **953** 个**最小对（minimal-pair）**样例 |
| 任务形态 | 多语言多模态检索 |

**最小对（minimal pair）**是核心设计：每个样例是一对仅在**细粒度细节**上不同、其余尽量一致的图像-描述对。例如一对图片仅在「杯子是红色还是蓝色」上有差别，配套的正确/错误描述各一条。最小对把评测焦点**强制**集中在模型容易忽略的局部属性上，从而排除整体布局捷径。

### 评测模型

涵盖两类：
- **轻量级 VL CLIP 类编码器**（对比式双塔，跨语言共享或独立文本编码器）；
- **大型语言模型**（生成式/指令式 VLM）。

统一以**多语言多模态检索**任务形式评测（给定图像与候选描述，选出匹配者），并在**跨语言设置**下构造「正确非英语描述 vs 错误英语描述」的对照对以度量英语偏置。

### 分析维度

1. **按语言的表现**（monolingual / per-language accuracy）；
2. **跨语言检索中的英语选择偏好**；
3. **语言资源量**与**类型学相似度**作为解释变量的对比。

## 实验结果

**基准规模**

| 项 | 值 |
|----|-----|
| 语言数 | 13 |
| 语系数 | 5 |
| 最小对样例数 | 953 |

**主要发现**

| 发现 | 结论 |
|------|------|
| 低资源语言 | 性能**显著下降**（degrades substantially） |
| 最强预测因子 | **语言可用的数据资源量**，而非与英语的**类型学相似度** |
| 跨语言检索偏置 | 模型**系统性偏向英语**：面对「非英语正确描述 + 英语错误描述」，多数模型**优先选择英语描述** |
| 偏置的架构差异 | 差异**相当大**；**Gemma 3 最偏英语**，**Qwen 3 偏置最小**，而两者的**单语准确率相近** |
| 跨语言泛化 | 英文弱点在多语言设定下**被放大** |

## 关键洞察
1. **英语偏置可以与单语能力解耦**：Gemma 3 与 Qwen 3 各语言单语准确率相近，但英语偏好强度差异巨大。这意味着**「英语很强」不等于「英语优先」**——检索任务的选择行为与理解能力是两条独立的能力轴，用单语指标去预测跨语言偏置会失效。
2. **数据资源比类型学相似度更重要**：这一结论对多语言资源投入策略有直接含义——给低资源语言的投入应按**可用数据量**（语料规模、标注规模）来排优先级，而不是按「与英语是否同语系/结构相近」来排。
3. **最小对是暴露 VL 弱点的必要工具**：因为 VL 模型天然偏好整体布局，只有构造「仅细节不同」的最小对，才能把「看到了图」与「看清了图」区分开——这对 VLM 的 captioning、视觉 QA、GUI agent 理解都是必要的评测工具。
4. **多语言评测中的对照设计会污染结果本身**：若候选集中英语描述天然质量更高（因英语数据多），那么「跨语言检索准确率」的一部分其实是**英语文本质量偏置**，而非视觉理解能力——这解释了为什么需要在匹配正确性之外单独构造偏置对照。

## 局限性
- 摘要**未给出任何逐语言准确率或偏置百分比数值**，只能知道方向（低资源更差、英语偏置存在、Gemma 3 > Qwen 3 偏置强度），无法评估效应量。
- 基准规模（953 最小对）偏小，覆盖的细粒度属性类型（颜色、材质、计数、空间关系、细部存在性等）与每类分布未知，可能存在类别集中。
- 13 种语言的选择与 5 个语系的划分标准未说明，语种内部的资源量梯度（是否含极低资源语言）未知。
- 仅评测 CLIP 类编码器与大模型两类，摘要未列出具体模型清单与规模；未覆盖多模态 embedding 模型、专用的多语言 VLM。
- 跨语言检索偏置的度量设计（候选如何配对、是否控制文本质量）未公开，可能高估或低估偏置。
- 结论基于检索任务，能否推广到多模态生成、视觉问答、agent 任务未验证。
- 未探讨偏置的成因（分词器、预训练语料混合比例、对比学习目标中的语言平衡）——是描述性发现而非机制解释。

## 适用场景
- **多语言 VLM 的评测与选型**：用逐语言 + 偏置双指标评估候选模型，避免被「英语强」误导。
- **低资源语言项目立项**：为语种资源投入排序提供「数据资源量优先于类型学相似度」的依据。
- **VL 细粒度理解诊断**：把最小对构造方法移植到自己的视觉 benchmark 中（如产品缺陷检测、医学影像细节、遥感目标识别）。
- **多语言检索系统上线前审计**：检查系统是否在跨语言查询中系统性偏向英语/高资源语言来源。
