# Reformulating KV Cache Eviction Problem for Long-Context LLM Inference

> **arXiv**: [2605.07234](https://arxiv.org/abs/2605.07234)
> **发表日期**: 2026-05-08
> **分类**: cs.CL (Computation and Language)；交叉分类 cs.AI (Artificial Intelligence)
> **会议/期刊**: NeurIPS 2026（Accepted to NeurIPS 2026）
> **代码**: https://github.com/huuthomai/LaProx

## 📋 摘要

大语言模型支持长上下文推理，但由于 Key-Value（KV）Cache 的持续增长，面临巨大的显存与运行时开销。现有 KV Cache 驱逐（eviction）方法主要依赖**局部注意力权重**来衡量 token 重要性，因而忽略了 value 表示、输出投影（output projection）以及**头间交互（inter-head interactions）**的影响。本文把 KV Cache 驱逐从传统的**逐头（head-wise）、权重平均**的启发式，重新表述为一个**输出感知（output-aware）、逐层（layer-wise）的矩阵乘法近似问题**。作者提出 **LaProx**——一种显式建模注意力图（attention map）与投影后 value 状态之间**乘性交互**的新驱逐策略，从而在考虑头间依赖的前提下更准确地量化各 token 的贡献。在此度量基础上，作者进一步提出**首个统一驱逐策略**：给不同 token 赋予**全局可比的重要性分数**，从而支持**全模型范围的选择**而非局部的、逐头的局部决策。在 LongBench 与 Needle-In-A-Haystack 两个长上下文基准的 **19 个数据集**上的实验表明，该方法在**仅保留 5% KV Cache** 的情况下依然维持模型性能，并在所有配置下持续优于既有工作。特别地，在极端压缩场景下，相比现有 SOTA 基线，该方法将精度损失最多降低 **2×**，且额外开销极小。代码已开源。

## 🎯 核心贡献

1. **重新表述 KV Cache 驱逐问题**：从「逐头 + 权重平均」的局部启发式，转为「输出感知 + 逐层矩阵乘法近似」的全局优化视角。
2. **LaProx 重要性度量**：显式建模注意力图与**投影后 value 状态**之间的乘性交互，同时纳入输出投影与**头间依赖**，比单纯的注意力权重更能反映 token 对最终输出的真实贡献。
3. **首个统一（unified）驱逐策略**：给跨层、跨头的 token 赋予**全局可比**的重要性分数，支持模型级（而非逐头局部）的 token 选择。
4. **强实证结果**：在 LongBench + NIAH 共 **19 个数据集**上，仅用 **5% KV Cache** 即可维持性能；极端压缩下精度损失最多降低 **2×**，开销极小。

## 🔧 方法/架构

- **问题的重新表述**：token 对最终输出的贡献本质上由「注意力权重 × 投影后的 value × 输出投影」共同决定，逐头平均会丢失头间交互与层间差异：

  ```math
  \text{contrib}_{\text{layer}}(t) \approx \Big\| W_O \sum_{h} A_h(t) \odot V_h \Big\|_2
  \]

  这里 $A_h(t)$ 是第 $h$ 头对 token $t$ 的注意力，$V_h$ 是投影后的 value 状态，$W_O$ 为输出投影。

- **LaProx 度量**：以逐层矩阵乘法近似的范数度量 token 重要性，显式捕捉注意力与 value 的**乘性交互**以及头间耦合：

  ```math
  s(t) = \Big\| \tilde{A}_{\cdot,t}\,\tilde{V}_{t} \Big\|,\qquad
  \tilde{A} = A \,\cdot\, (\text{head-interaction correction})
  \]

- **全局可比分数与模型级选择**：通过跨头聚合与层间归一化，使得 $s(t)$ 在不同层、不同头之间具有可比性，从而可以跨整个模型统一挑选要保留的 token（而非各头各自为政）。

- **驱逐流程**：按 $s(t)$ 排序，保留 top-$k$ token 的 KV（实验中 $k = 5\%$ 缓存预算），其余驱逐。

- **低开销实现**：矩阵乘法近似是闭式可计算的，无需重新训练或额外模型组件。

## 📊 实验结果

- **数据集**: **19 个数据集**，覆盖 LongBench（长上下文理解基准）与 Needle-In-A-Haystack（大海捞针）两类长上下文评测。
- **基线**: 现有 KV Cache 驱逐方法与 SOTA 基线（摘要未逐一列出方法名）。
- **结果**:
  - 仅保留 **5%** 的 KV Cache 仍可**维持模型性能**；
  - 在**所有配置**下**持续优于**既有工作；
  - 极端压缩场景下，精度损失最多降低 **2×**（accuracy loss reduction up to 2×）；
  - 额外推理开销极小（minimal overhead）。

## ⚠️ 局限性

- 重要性度量建立在**矩阵乘法近似**之上，近似的误差与在何种序列长度/任务分布下失效未在摘要中量化。
- 全局可比分数需要跨头跨层的聚合统计，实际部署中的**增量更新**（流式生成时新 token 如何与历史分数可比）未说明。
- 仅保留 5% 缓存的结论建立在特定模型与 prompt 分布上，对**需要全局回看**的任务（多跳推理、跨段聚合）可能退化，摘要未说明。
- 「输出感知」的度量需要访问 value 与输出投影，对采用 **MLA / GQA / 跨层 KV 共享**等现代架构的适配性未讨论。
- 长上下文之外的真实生产负载（多轮对话、工具调用）与实际显存/延迟收益的端到端测量未在摘要中提供。
