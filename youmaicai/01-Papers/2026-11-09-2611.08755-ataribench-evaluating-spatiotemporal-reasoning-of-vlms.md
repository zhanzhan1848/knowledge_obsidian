# AtariBench: Evaluating Spatiotemporal Reasoning of Vision-Language Models in Atari Gameplay

> **arXiv**: [2611.08755](https://arxiv.org/abs/2611.08755)
> **发表日期**: 2026-11-05
> **分类**: cs.CV (及交叉分类 cs.AI)
> **会议/期刊**: NeurIPS 2026, Evaluations and Datasets Track（26 pages, 14 figures）

## 📋 摘要

视觉语言模型（VLM）在静态视觉理解基准上已取得强劲表现，但它们在动态环境中"采取行动"的能力仍不甚清楚。本文提出 AtariBench，一个受控基准，在 **20 个 Atari 2600 游戏**上评测 VLM，要求模型从高时间分辨率的游戏画面流中做出序列决策。通过把"快速的游戏内动态"与"墙钟推理速度"解耦，AtariBench 聚焦于模型能否感知快速视觉状态变化、对时空动态进行推理，并把动作落到当前观测上。实验揭示了当前 SOTA VLM 的显著局限：模型常常无法推断物体的运动与方向，序列决策非常脆弱，而且即便有新的视觉反馈被追加进来，仍然过度依赖文本形式的交互历史。作者进一步引入**可分性分析（separability analysis）**，用以识别哪些游戏内分数能够可靠地反映模型能力，并利用该基准研究记忆设计与提示词策略如何影响表现。总体而言，AtariBench 揭示了被动视觉感知与主动决策之间持续存在的鸿沟，为开发能在动态环境中推理并行动的 VLM 提供了一个轻量而严谨的试验台。

## 🎯 核心贡献

1. **提出 AtariBench 受控基准**：覆盖 20 个 Atari 2600 游戏，以高时间分辨率画面流驱动 VLM 做序列决策，专门考察时空动态推理而非静态识别。
2. **关键设计：解耦游戏内动态速度与推理速度**：避免"慢推理"被误当作"看不见"，从而让测量结果真正指向时空推理能力而非算力。
3. **系统刻画 SOTA VLM 的三类失败模式**：无法推断物体运动与方向；序列决策脆弱；过度依赖文本交互历史而忽视新追加的视觉反馈。
4. **提出可分性分析（separability analysis）**：识别哪些 in-game score 能可靠区分模型能力，避免用噪声分数误导结论。
5. **研究记忆设计与提示词策略的影响**：在同一基准上对比 memory design 与 prompting 策略对成绩的作用。

## 🔧 方法/架构

- **环境**：20 个 Atari 2600 游戏；模型以高时间分辨率接收游戏画面（帧流）并输出离散动作。
- **任务形式**：序列决策（sequential decision-making），每步动作基于当前观测。
- **评测解耦设计**：把"游戏内动态速度"与"模型推理速度（wall-clock）"分离，使得瓶颈定位在感知/推理而非延迟。
- **可分性分析**：对每个游戏的分数做可分性度量，判断该游戏得分是否能作为模型能力的可靠信号源。
- **消融维度**：memory design（记忆机制）与 prompting strategy（提示策略）作为主要可控变量。

## ⚠️ 局限性

- **游戏分布与真实世界的距离**：Atari 2600 的像素风格、规则性与奖励结构与现代视频/物理环境差距明显，结论外推需谨慎。
- **闭源 API 模型不可完全受控**：温度、采样参数、帧率与是否开启推理链都会显著影响结果，跨论文比较困难。
- **可分性分析本身是必要的负担**：说明部分 in-game score 噪声大或不可区分，意味着该基准中很多游戏带来的信号有限。
- **纯动作空间交互的局限**：真实 agent 还需要长期规划、工具使用与状态管理，本基准只覆盖"感知—动作"这一层。
- **未与专门的 RL 智能体同基准对比**：摘要未说明与人类或强化学习 agent 的分数差距有多大，数值锚点缺失。
