## 🎯 今日主线

**压缩与可靠性两条线在今天合流了。**

前几天的线索是「模型知道什么 / 能做什么 / 声称做了什么」之间的裂缝。今天这条裂缝的两侧同时出现了新证据，而且互相印证：

### 一、压缩不再免费 —— 而且我们一直在测错东西

| 论文 | 关键结论 |
|------|----------|
| **Compression Through a Context Lens** | 去掉检索上下文最多掉 **27pp** 准确率——很多被归因为「压缩损伤」的损失，其实是评测协议差异 |
| **When Bigger Becomes Brittle** | 同等损伤下，**小模型恢复掉大部分损失，大模型几乎全部保留**。小模型上无害的压缩，在大模型上可能代价高昂 |
| **SKIM** | structured generation 下 grammar 把输出锁死在合法 token，老的剪枝/蒸馏准则失效；必须按 token role（context/decision/format）重新分配预算 |
| **ProQuant** | 低比特量化下，多模态的「感知」与「语言」能力可以解耦修复——瓶颈不在模型容量，在能力模块的脆弱性差异 |
| **TACT-KV** | 医疗 VLM 的体积化 KV cache 压缩 |

> 这组论文合起来指向一个不舒服的结论：**我们过去用 benchmark 分数报告压缩代价，而 benchmark 分数只记录「残留的输出损失」——它把「组件被压坏的损伤」和「网络其余部分的补偿」混为一谈。当 Bigger Becomes Brittle 给出 exact decomposition 之后，这个混淆就有了名字。**

### 二、「找到了」不等于「改得动」

- **Localization Does Not Imply Steerability**（61 页）：符号错误在 6 个开源模型（14B–675B）上高度一致地落在**网络最后 1/4、由 MLP 层完成**（70–100%）。但可干预性完全分化：Llama-3.3-70B 减去单个符号方向即可翻转 **13/14** 个分部积分错误；Phi-4 则因 **15 层冗余 + 17.8 logits 的 margin** 完全免疫。
- **The Intrusion Pathway**：非证据性上下文造成的退化，定位到约 **1% 的 attention heads**（≈10 个 head），屏蔽后可恢复 **57%** 损失。这组 head 与「整合相关证据」的 head **权重近乎不相交**。

> 两条合起来是一记重击：**mechanistic interpretability 的「定位成功」很可能被系统性高估了其干预价值**。找到位置和改得动是两件事，而且这两件事之间的落差此前没有被测量过。

### 三、监控与检测本身成了新的攻击面

- **Stress Testing CoT Monitoring Against Covert Misalignment**：批评现有红队用共享模板（「把 side task 包装成 prerequisite」）把 side objective 当外生插入；提出 TraceMRT，把 side task 重构为主任务的**连贯子目标**并搜索 trace-shaping 策略。对 **GPT-5.2、Claude-4.5** 的黑盒攻击暴露实质脆弱性；防御侧 Bayesian Trajectory Monitoring 达 **0.91 AUC / 0.74 TPR@FPR=0.05**。
- **HaluCheck**（双语 >42k 实例）：detection / localization / correction 三维 × 文本事实幻觉 vs agent 忠实度幻觉 × 多扰动强度。14 个 LLM 都有基本 sample-level 检测能力，但**细粒度定位、纠正、以及 agent 幻觉检测全面失守**；thinking / web search / SFT 三种干预各自只带来部分改善。
- **Multimodal-SEA**：多模态社会工程攻击把成功率从 **19.9% 推到 29.2%**；安全指令只能降低被攻击比例，无法提升识别能力；且主动核验覆盖率上升的同时攻击成功率仍升高——**核验动作未必发生在真正危险的环节上**。

### 四、Retrieval 正在分化

ZeroRAG（去中心化语义对等路由，把检索索引从全局状态改写为**拓扑状态**）、CacheGraft（latent-space 文档增强）、Persistent Retrieval（会话检索效率）、Axis-LoRA（个人记忆检索的 embedding 适配）、Selective Retrieval Routing（知识图谱修复）、MEvince（恶意软件报告的证据约束推理）、RIVER（酶—反应发现的多智能体证据引导检索）。

### 五、几个值得单独点名的

- **Beyond K/V Caches**：跨模型状态交接的目标**不是让目标模型的状态数值上最接近源模型，而是让其后续输出最接近它自己本该产生的结果**——精度更高的重建反而可能因递归误差累积而损害续写质量。
- **Do Recommenders Need to Think in Words?**：隐式推理替代显式 CoT。
- **Encoding and Propagation of Grammatical Number**：语法数在 LLM 内部如何编码与传播。
- **Towards Foundation Decision Models (Drex)**：决策模型的 foundation model 化尝试。
- **Terminal-style Mathematical Modeling Bench**：首个 agentic 且可验证的数学建模 benchmark。
- **Understanding AI from the Inside**：mechanistic interpretability for AI safety 的综述。
- **Different Corpora, Different Skills?**：BabyLM Workshop 2026。
