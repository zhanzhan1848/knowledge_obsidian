## 核心贡献

> 提出 **HarnessPro** —— 一种 label-free 的 harness 演化方法，通过递归自我改进同时提升任务性能并降低执行成本，并输出三档 Pareto 解（lite/medium/heavy）覆盖不同部署预算。

1. **Label-Free 评估**：候选 harness 通过 LLM 生成的测试进行评估，无需 ground-truth 或官方测试
2. **Specialized Agents 闭环**：执行轨迹诊断 → 多目标更新规划 → 实现候选 harness
3. **Pareto 多档选择**：用归一化加权平方距离选择提供 lite/medium/heavy 三档 harness
4. **显著 Pareto 改进**：相比 RHO 基线，GPT-5.5+Codex 上平均 pass-rate 提升 2.0 pp，平均每任务成本降低 26.1%

---

## 技术方案

### 核心思想

Harness 决定 agent 能力上限。已有 RSI 方法多关注性能而忽视成本。HarnessPro 用 LLM 生成 tests + specialized agents 迭代改进 harness，并利用 Pareto 选择同时给出三档解。

### 关键技术

| 技术 | 说明 |
|------|------|
| Label-Free Test Generation | 无 ground-truth 条件下用 LLM 生成评估 test |
| Specialized Diagnostic Agents | 诊断执行轨迹、规划更新、实施 harness 改动 |
| Normalized Weighted Squared-Distance Selection | 三档 Pareto 选择（lite/medium/heavy） |
| Recursive Iteration | 候选 harness 评估 → 选择 → 进入下一轮迭代 |

### 工作流程

```
Test Generation → Harness Candidates → Execution → Diagnosis → Update Plan → Implement
                                                                              ↓
                              Pareto Selection (lite/medium/heavy) ← Evaluate
                                                                              ↓
                                                                  Next Iteration
```

## 实验结论

### Benchmark

- Terminal-Bench 2
- SWE-Bench Pro
- ProgramBench

### 模型组合

- GPT-5.5 + Codex
- GLM-5.2 + Claude Code

### 主要结果

| 模式 | pass-rate 提升 | 成本降低 |
|------|--------------|---------|
| Heavy | **+2.0 pp** | **-26.1%** |
| Medium / Lite | Pareto 多档平衡 | - |

> 优势在不同模型组合（GPT-5.5+Codex 与 GLM-5.2+Claude Code）上均成立。
