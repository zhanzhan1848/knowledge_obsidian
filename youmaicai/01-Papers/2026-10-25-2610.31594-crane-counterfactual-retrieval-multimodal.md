## 核心贡献

> **第一个 post-hoc、model-agnostic 的多模态最近邻反事实解释框架**：不去"合成"反事实，而是**从目标类的真实训练样本中检索**，从而**构造上保证合理性（plausibility by construction）**。

1. **识别现有方法的空白**：反事实解释已有 tabular / timeseries / text / image 的专用框架，但**没有为多模态分类器设计的 post-hoc 方法**
2. **指出多模态可解释性的现有做法失效**：现有多模态解释方法对每个输入**独立地做模态特定归因**，产生**不连贯**的解释，且**无法迁移到任意预训练多模态架构**
3. **提出 CRANE**（Counterfactual Retrieval via Agnostic Nearest-neighbour Explanations）：检索目标类的**真实训练样本**作为候选解释
4. **合理性由构造保证**：解释必须是真实数据点
5. **提出 Multimodal Consensus Retrieval (MC-R)**：对各模态的邻居集合取**交集**，找出在**每个模态中都与查询共同接近**的实例
6. **模型无关、可迁移**：post-hoc 框架，不改模型内部，适用于任意预训练多模态架构

## 技术方案

### 核心思想

```
查询 (多模态 x)
      ↓
  各模态分别做近邻检索
  image-neighbours(N_img)  audio-neighbours(N_mod2)  text-neighbours(N_txt)
      ↓
   MC-R: N_img ∩ N_mod2 ∩ N_txt   ← 各模态都共同接近的实例
      ↓
   从目标类的真实训练样本中检索 → 反事实解释
```

**与"合成式"反事实的根本区别**：不生成新样本，所以不存在"生成样本偏离数据分布"的问题 —— **plausible by construction**。

### 关键技术

| 技术 | 说明 |
|------|------|
| Counterfactual Retrieval via Agnostic Nearest-neighbour (CRANE) | 用近邻检索代替生成，作为反事实的解释来源 |
| Real training example retrieval | 候选解释是**目标类的真实训练样本**，保证分布内 |
| Multimodal Consensus Retrieval (MC-R) | 对每模态邻居集合取**交集** —— 要求在**每个模态**上都接近查询 |
| Unimodal strategies | 单模态检索策略，作为对照 |
| Post-hoc / model-agnostic | 不修改被解释模型；接口只要求能拿到各模态的表示 |
| Agnostic design | 不绑定特定架构，可用于任意预训练多模态模型 |

### 各策略对比

| 策略 | 机制 | 特性 |
|------|------|------|
| MC-R（多模态共识） | 各模态邻居集合取交集 | **最强**多模态策略；在 **4 个数据集中的 3 个**取得最优或并列最优 |
| 单模态策略 | 只用一个模态的邻居 | 当**单一模态主导决策边界**时仍然有竞争力 |
| 逐模态独立归因（现有做法） | 各模态分别归因 | 解释**不连贯**，无法迁移到任意架构 —— CRANE 明确针对这两点 |

## 关键结论

1. **多模态反事实解释此前是空白地带**，且现有的"逐模态独立归因"在概念上就不对 —— 独立归因无法表达"两个模态联合起来才做出判断"的情况。
2. **检索式反事实在构造上保证合理性**，避免合成反事实的分布偏移问题；这在医疗、法律等需要"解释必须真实"的应用中尤其重要。
3. **MC-R（交集）是默认强策略**：要求候选在每个模态上都接近，天然对应"联合决策"的语义。
4. **但 MC-R 不是普适最优**：当某个模态主导决策边界时，单模态策略更实用（并且可能更少返回空集）—— 这是一个需要在实际系统里检查的条件。

## 局限性

- **数值未披露**：4 个数据集名称、3 种融合策略均未列出，具体指标值需查正文（7 页会议论文长度）
- **"MC-R 交集"可能为空或过小**：当各模态邻居不一致时，交集可能为空 —— 摘要未说明如何回退（是否退化为单模态或并集）
- **依赖模态表示的可获取性**：虽然是 model-agnostic，但仍需要访问各模态 embedding（对端到端融合模型不总是直接可用）
- **检索成本**：需在训练集上做多模态近邻检索，训练集大时的索引与延迟开销未讨论
- **未与合成式多模态反事实方法对比**（因为不存在这样的 post-hoc 方法），因此优势是"先存在性"而非"实测更好"

## 实现建议

- **实现难度**: 中（需要各模态 embedding + 训练集近邻索引 + 目标类候选过滤）
- **适用场景**: 需要**可审计的真实样本**作为解释的多模态分类系统 —— 医疗影像 + 病历、金融图文审核、内容审核
- **落地步骤**:
  1. 对每个模态单独建近邻索引（FAISS 等）
  2. 过滤到**目标类**的真实训练样本
  3. 实现 MC-R（交集），并**务必实现回退逻辑**：交集为空时退回单模态 top-k
  4. 检查是否存在**主导模态**（把各模态单独跑一遍比较）—— 若有，考虑直接用单模态策略
  5. 解释输出附上"该样本在每个模态上分别有多近"，让用户能判断一致性
- **价值点**: 相比主流的梯度归因/遮蔽方法，**解释本身就是数据**，可直接用于申诉、复盘与相似案例检索
