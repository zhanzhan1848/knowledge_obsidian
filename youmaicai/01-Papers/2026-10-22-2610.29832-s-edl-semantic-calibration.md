## 核心贡献
1. 提出 S-EDL，一种**原生为语义校准而优化** LLM 的 evidential 方法（evidential method），专门面向开放式生成（open-ended generation）。
2. 从模型自身的**序列似然 (sequence likelihoods)** 中提取证据 (evidence)，构造出 prompt-specific semantic classes 上的**可微 Dirichlet prior**。
3. 在该 Dirichlet 先验下优化 evidential loss，得到面向**可变语义类别 (variable semantic classes)** 的 calibration-aware 训练信号，完全绕开对固定 multiple-choice 选项的依赖。
4. 在 4 个开放式 benchmark、3 个模型上验证：显著降低语义校准误差，同时提升准确率。

## 问题动机
在开放式生成场景中对 LLM 做校准格外困难，因为**许多不同的 token 序列可以表达同一个底层含义**——语义等价类的大小和成员随 prompt 而变。现有校准技术要么针对固定候选集的分类置信度，要么针对单个字符串的二元正确性，这两者在本质上都不适合开放式语义结果那种"动态、多字符串"的性质：前者假定候选集合固定，后者把语义正确性退化为字符串匹配。作者要补上的正是这块空白——一个原生面向语义、而非面向字符串正确性的校准框架。

## 方法
S-EDL 把 evidential deep learning (EDL) 的思想迁移到开放式生成的语义校准上，核心是"从序列似然中自取证据 (self-evidence)"。

关键机制：

1. **Eliciting evidence from sequence likelihoods**：不引入外部证据源，而是从模型自身对候选序列给出的 likelihood 中提取 evidential quantities（EDL 框架下的 $\alpha$ 参数）。
2. **Differentiable Dirichlet prior over prompt-specific semantic classes**：为每个 prompt 动态构造语义类别上的 Dirichlet 分布作为可微先验。
3. **Evidential loss under this prior**：在该先验下优化 evidential loss，产生一个 calibration-aware 的训练信号。
4. **Variable semantic classes**：语义类别集合随 prompt 变化，因此完全不需要预设 multiple-choice 选项列表。
