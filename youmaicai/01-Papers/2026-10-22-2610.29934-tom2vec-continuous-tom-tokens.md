## 核心贡献
1. 提出 **ToM2Vec**：通过**固定预算的连续推理 token（continuous reasoning tokens）**，让 LLM agent 在一个**丰富的隐空间（rich latent space）**中形成抽象的 theory-of-mind。
2. **训练监督来自伙伴的真实想法**：ToM token 被训练去"抽象并匹配"（abstract and match）对手 agent 实际的内心思考，从而学到对 partner state 的抽象表征。
3. **测试时 ToM token 作为 conditioner**：由每个 agent 生成，作用于该 agent 自身的思考与动作，形成隐式的推理—行动闭环。
4. **隐空间推理是必要的**：实验表明当把推理表达为**文本**时性能显著下降（latent reasoning is critical）。
5. **跨模型族泛化**：训练后的 ToM2Vec 可泛化到训练时未见过的 partner model family，包括**专有模型 GPT-5.4**。
6. **机制性验证**：ToM2Vec 的 token 能直接提升 agent 回答关于 partner 的信念、意图与下一步动作问题的能力，说明这些 latent token 编码的确实是 ToM，而非任务特定信息。

## 问题动机
形成准确的 theory-of-mind 是多智能体协作成功的关键，它要求在**不确定性下推理**、同时容纳多个可能的伙伴状态（而非认定单一状态）。但这在 LLM agent 原生的**文本表示空间**中很难做到——文本天然倾向于描述一个确定的伙伴状态，难以承载"多个候选状态"的并行表征。本文正是针对这一表征空间与任务需求之间的错配。

## 方法
学习连续 ToM token 的方法要点：

- **表示**：在固定预算（fixed budget）的连续推理 token 中编码抽象 ToM，位于丰富隐空间中。
- **训练目标**：监督信号来自 **partner 的真实 thoughts**（即另一个 agent 实际生成的想法），ToM token 通过抽象并匹配这些想法来学习。
- **推理流程**：测试时，agent 先生成 ToM tokens，再以其作为 conditioner 驱动自身的 thoughts 与 actions。
- **对照设计**：将隐空间推理与文本形式推理直接对比，以验证 latent representation 的必要性。

## 关键技术细节
- 连续 token 数量为**固定预算**（fixed budget），意味着推理开销可控且与任务长度解耦
- 训练信号是 **partner's thoughts** 本身（跨 agent 监督），而非环境回报的端到端信用分配
- 测试时是 **self-conditioning** 形式：agent 自己的 ToM token 影响自己的后续推理
- 支持零样本迁移到闭源模型（GPT-5.4）作为 partner
- 涵盖 5 个环境 × 3 类互动动机（cooperative / competitive / mixed-motive），覆盖度较广
