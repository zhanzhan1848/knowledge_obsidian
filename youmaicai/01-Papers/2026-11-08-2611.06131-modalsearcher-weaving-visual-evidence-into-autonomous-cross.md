# ModalSearcher: Weaving Visual Evidence into Autonomous Cross-Modal Deep Search

> **arXiv**: [2611.06131](https://arxiv.org/abs/2611.06131)
> **发表日期**: 2026-11-04
> **分类**: cs.AI (Artificial Intelligence)
> **会议/期刊**: arXiv preprint（29 pages）

## 📋 摘要

静态且不完整的参数化知识限制了多模态大语言模型（MLLM）在新知识与知识密集型任务上的表现，尤其是需要多跳（multi-hop）证据获取的任务。现有的多模态 agentic search 方法往往把视觉证据**固定在输入端或预定义轨迹位置**，导致 agent 难以随着信息需求的变化而选择搜索模态，也难以处理复杂的真实世界查询。作者把这一能力定义为**自主跨模态搜索（autonomous cross-modal search）**：agent 在直接推理、文搜文（text-to-text search）、文搜图（text-to-image search）、以图搜图（reverse-image search）之间自主选择，在恰当时机主动引入视觉证据，并在多跳之间切换与整合模态。作者提出 **ModalSearch-Pipeline**——一个可扩展的交错多模态知识图谱构建流程：它采样具有多样深度与模态组合的路径，并采用**反向问题构造（backward question construction）**来遮蔽会暴露推理捷径的实体名与图像目标，同时保留必要的消歧线索，从而产出纯文本、图像初始化以及任意交错的多跳问题。作者在**真实 Web 环境**中用监督微调与强化学习训练了 **ModalSearcher Agent**，并构建了 **ModalSearch-Bench**。实验表明：在相同 agentic workflow 下，**ModalSearcher-8B** 在五个多模态知识密集型 QA 基准上的平均准确率比 **Qwen3-VL-8B** 提升 **16.2** 个百分点，并在独立构建的主动视觉搜索基准上取得一致增益。

## 🎯 核心贡献

1. **提出并形式化「自主跨模态搜索」能力**：明确 agent 应在直接推理 / 文搜文 / 文搜图 / 以图搜图四种模态间自主选择，随信息需求演化动态引入视觉证据并跨多跳整合模态——填补了「视觉证据固定在输入端或固定轨迹位置」的既有范式缺陷。
2. **ModalSearch-Pipeline**：可扩展的**交错多模态知识图谱**构建流程，采样多样深度与模态组合的路径，并通过**反向问题构造**消除推理捷径（遮蔽实体名与图像目标、保留消歧线索），从而生成纯文本、图像初始化与任意交错的多跳训练/评测问题。
3. **真实 Web 环境下的 SFT + RL 训练**：在**live Web**（而非离线模拟/静态语料）中联合使用监督微调与强化学习训练 ModalSearcher Agent，使搜索能力对齐真实开放网络环境。
4. **ModalSearch-Bench**：配套评测基准；在**相同 agentic workflow** 这一严格对照下，ModalSearcher-8B 相对 Qwen3-VL-8B 平均准确率 **+16.2 pp**，并在独立构建的主动视觉搜索基准上验证一致增益（排除对特定基准的过拟合）。

## 🔧 方法/架构

**（A）能力定义 —— 自主跨模态搜索**

agent 在每个决策点从四种动作空间中选：

```math
\mathcal{A} = \{\text{direct reasoning},\ \text{text-to-text search},\ \text{text-to-image search},\ \text{reverse-image search}\}
```

并可在多跳之间切换与整合模态，视觉证据的引入时机由信息需求演化决定，而非固定在输入或固定轨迹位。

**（B）数据引擎 —— ModalSearch-Pipeline**

1. 构建**交错多模态知识图谱**（interleaved multimodal knowledge graph），节点/边携带文本与图像模态。
2. **路径采样**：采样深度（hop count）与模态组成（text-only / image-initialized / interleaved）多样的路径。
3. **反向问题构造（backward question construction）**：从路径末端反向生成问题，同时——
   - **遮蔽**：抹去实体名与图像目标等会暴露「推理捷径」的显式线索；
   - **保留**：保留必要的消歧线索（distinguishing clues），确保问题仍可解。

   ```math
   q = \text{BackwardConstruct}\big(\text{path}\big),\quad
   \text{clues}(q) \subseteq \text{path},\ \text{entities}(q) \cap \text{shortcuts} = \emptyset
   \]

**（C）训练 —— ModalSearcher Agent**

- **监督微调（SFT）**：在构造的多跳多模态问题上学习跨模态搜索轨迹与工具调用格式。
- **强化学习（RL）**：在**真实 Web 环境**中优化端到端任务成功率。
- 基座为 8B 级别 VLM（对比基线 Qwen3-VL-8B）。

**（D）评测 —— ModalSearch-Bench**

在**相同 agentic workflow**（同一套工具、同一 prompt 框架）下与基线对比，隔离模型能力差异；另在**独立构建**的主动视觉搜索基准上做交叉验证。

## 📊 实验结果

- **核心结果（相同 agentic workflow，五个多模态知识密集型 QA 基准）**：ModalSearcher-8B 平均准确率较 **Qwen3-VL-8B 提升 16.2 个百分点**。
- **交叉验证**：在独立构建的主动视觉搜索基准上取得**一致增益**。
- **训练范式**：SFT + RL，训练与评测均在**真实 Web 环境**中进行。
- **数据规模**：摘要未披露具体数值（知识图谱规模、路径数、基准题量——详见原文实验章节）。

## ⚠️ 局限性

- 依赖**真实 Web 环境**训练与评测，存在搜索结果漂移、页面改版、访问限制导致的可复现性问题。
- RL 在开放网络上训练成本高、样本效率与稳定性问题未在摘要中说明。
- 提升数字（+16.2 pp）基于 8B 模型与特定基线（Qwen3-VL-8B），向更大规模模型迁移的收益是否保持未知。
- 「自主模态选择」可能带来不可控的工具调用成本与延迟，摘要未讨论推理开销/时延。
- 反向问题构造虽抑制了实体名捷径，但可能引入模板化痕迹，模型可能学到新的捷径而非真正推理。
