## 核心贡献

> 揭示 AdamW 二阶矩量化中"state 误差小 ≠ preconditioner 误差小"这一关键不对称性，提出在 **preconditioner space** 而非 state space 做 rounding 的 ZIP-SR 与 ZE-EDEN 方案，把 4-bit AdamW 与 32-bit 的 validation loss gap 最大缩小 70%。

1. 提出 **Rounding Space** 视角：量化误差在 AdamW 的状态空间小，不代表在更新方向（preconditioner space）小。
2. **ZIP-SR**（Zero-Inclusive Preconditioner-space Stochastic Rounding）：保留 0 在 codebook 中，stochastic rounding 在 preconditioner 空间计算概率。
3. **ZE-EDEN**（Zero-Excluding EDEN calibration）：去掉 0 后做 rescaling 缓解 positive quantization floor 引起的 preconditioner 畸变。

---

## 技术方案

### 核心思想

AdamW 的更新方向是 $m_t / (\sqrt{v_t} + \epsilon)$。state 空间里 $v_t$ 量化误差小，并不意味着 $\sqrt{v_t}$ 的导数（即 preconditioner 增益）误差小。因此 rounding 必须在 preconditioner 空间做。

### 关键技术

| 技术 | 说明 |
|------|------|
| Local cell analysis | 对 0 邻域的量化 cell 做局部展开，分析 state 误差 → preconditioner 误差的放大 |
| 1D quadratic construction | 用一维二次构造说明 state-space vs preconditioner-space rounding 的动力学差异 |
| ZIP-SR | codebook 包含 0；在 $1/\sqrt{v_t}$ 空间算 stochastic rounding 概率 |
| ZE-EDEN | codebook 不含 0；在量化后做 rescaling block 修正 floor 畸变 |
| LM-head SR | 最后 10% 训练步对 LM-head 一阶矩做 targeted stochastic rounding |

### 公式（preconditioner 空间视角）

```math
u_t = \frac{m_t}{\sqrt{v_t} + \epsilon}, \quad \frac{\partial u_t}{\partial v_t} = -\frac{m_t}{2(v_t^{3/2} + \epsilon \sqrt{v_t})}
```

放大因子在小 $v_t$ 处大 → 必须保证小 $v_t$ 处的 rounding 精度。

## 代码片段（核心 ZIP-SR stochastic rounding）

```python
# Preconditioner-space stochastic rounding for second moment
def zip_sr_round(v_block, codebook, eps=1e-8):
    # Compute reconstruction levels in preconditioner space: 1/sqrt(x)
    inv_sqrt_levels = 1.0 / (torch.sqrt(codebook) + eps)
    v_inv_sqrt = 1.0 / (torch.sqrt(v_block) + eps)
    # Find adjacent levels and compute SR probabilities
    dist = torch.abs(v_inv_sqrt.unsqueeze(-1) - inv_sqrt_levels)
    lower = torch.argmin(dist, dim=-1)
    upper = torch.clamp(lower + 1, max=len(codebook)-1)
    p = (v_inv_sqrt - inv_sqrt_levels[lower]) / (inv_sqrt_levels[upper] - inv_sqrt_levels[lower] + eps)
    rand = torch.rand_like(p)
    chosen = torch.where(rand < p, upper, lower)
    return codebook[chosen]
```

## 实验结论

- **数据集**: GPT-/Llama-style 预训练，130M → 2.7B 参数
- **基线**: TorchAO 4-bit AdamW、32-bit AdamW
- **结果**:
  - 验证 loss gap 最大缩小 **70%** vs TorchAO
  - 在所有评估模型规模上均优于 TorchAO
  - Full-parameter SFT 上验证 loss 优于 TorchAO，downstream task 接近 32-bit AdamW

---

## 局限性

- 仅在 130M–2.7B 模型上验证，更大规模（如 70B+）未涵盖。
- 仅覆盖 AdamW，其它自适应优化器（Lion、Sophia）未迁移验证。
- 最后 10% 的 LM-head SR 策略在不同数据集上的最优窗口可能不同。
