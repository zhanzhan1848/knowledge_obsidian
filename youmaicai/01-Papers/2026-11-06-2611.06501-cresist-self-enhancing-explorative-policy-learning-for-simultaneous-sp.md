# CRESiST: Self-Enhancing Explorative Policy Learning for Simultaneous Speech Translation

## 摘要
**CRESiST** 面向同时语音翻译（SimulST）—— 需在翻译质量与延迟间取得平衡。当前 LLM-based SimulST 系统主要依赖**前缀增量生成（prefix-incremental generation）**，这带来两个瓶颈：**冗余的 KV cache 重计算**，以及必须依赖**外部 VAD** 来处理无界流。本文提出端到端的**交错读写（interleaved read-write）**框架，构建在 **omni-modal LLM** 之上：通过交错语音 chunk 与文本 token，实现**完全 KV cache 复用**，原生支持**无分段、无限长度推理**。为在没有刚性离线对齐的情况下学到最优流式策略，提出新的 **Actor-Critic 自增强管线**：RNN-T Actor 动态采样读写轨迹，LLM-based Critic 通过内在的**语义奖励与延迟奖励**评估这些路径，再把最优策略蒸馏回 Actor。在 FLEURS、CoVoST2（句级）与 MuST-C、ACL 60/60（文档级）基准上建立了新的**质量-延迟 Pareto 前沿**，大幅超越现有方法。

## 核心贡献
1. 端到端**交错读写**架构，基于 omni-modal LLM，实现**完全 KV cache 复用**
2. 原生支持**无分段、无限长度推理**，**消除对外部 VAD 的依赖**
3. 提出 **Actor-Critic 自增强管线**：RNN-T Actor 采样读写轨迹 + LLM Critic 以**语义奖励与延迟奖励**评估并蒸馏回 Actor（无需刚性离线对齐）
4. 在句级（FLEURS、CoVoST2）与文档级（MuST-C、ACL 60/60）基准上建立新的**质量-延迟 Pareto 前沿**

## 方法与架构
**架构**：omni-modal LLM 上交错语音 chunk 与文本 token → 全量 KV cache 复用 → 无分段无限长推理。

**流式策略学习（无刚性离线对齐）**：
```
RNN-T Actor  动态采样 read-write 轨迹
      ↓
LLM Critic   用内在语义奖励 + 延迟奖励评估路径
      ↓ (蒸馏)
RNN-T Actor  获得最优流式策略
```

**评测**：句级（FLEURS、CoVoST2）+ 文档级（MuST-C、ACL 60/60）。

## 实验结果
- 建立新的**质量-延迟 Pareto 前沿**，在句级与文档级基准上**大幅超越**现有 LLM-based SimulST 系统
- **完全 KV cache 复用**（消除前缀增量生成的冗余重计算）
- **无需外部 VAD**，原生支持无分段无限长推理
- **NeurIPS 2026** 录用

## 局限性
- 需要专用硬件支持流式推理（推测为低延迟解码场景），部署成本未讨论；
- LLM Critic 作为评估器引入额外 LLM 调用成本，其自身延迟计入端到端延迟的方式摘要未说明；
- 仅在英语↔多语（CoVoST2/FLEURS 覆盖）方向验证。

## 值得注意的点
「**完全 KV cache 复用 + 无需外部 VAD**」是本篇的工程核心 —— 两个约束被同一个交错架构同时消除，而不是各自打补丁。这类「一个架构改动同时解掉两个瓶颈」的方案，通常比逐项优化更有价值。
