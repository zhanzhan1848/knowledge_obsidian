## 核心贡献

> 揭示 LLM agent 对 interface 的脆弱绑定，并提出 **Cross-Interface Policy Regularization (CIPR)** 自监督修复。

1. **Interface-fragility 问题**：post-training 把 agent 能力绑定到训练时的 interface 名 / 符号；semantic-preserving perturbation（rename / notation change）会让性能下降 ~25%。
2. **CIPR 自监督目标**：同一 training sample 在两个 interface 下呈现，KL 约束 action 分布 → policy 必须 interface-invariant。
3. **效果显著**：在 agentic function calling 上，恢复 **+10.5%**（在 held-out perturbation），原 interface accuracy 不损。

---

## 技术方案

### 核心思想

当前 post-training pipeline 把 agent 训练到某个**特定 interface**（action 名 / 格式）。这造成：
- OOD interface perturbation → performance drop；
- 单纯 interface randomization 仅把依赖扩展到 interface 集合，对真正 OOD 仍然脆弱。

CIPR 自监督：
1. 把 training sample 在两个 interface 下呈现（action 名替换为 uninformative identifier），其中 equivalent actions 通过构造对齐；
2. KL 散度约束两 interface 下的 action 分布；
3. 强迫 policy **interface-invariant**。

### 关键技术

| 技术 | 说明 |
|------|------|
| Action name → uninformative ID | 切断表面 cue |
| Equivalent actions aligned by construction | 两 interface 对齐 |
| KL penalty between interfaces | interface consistency |
| SFT + RL 双兼容 | plug-in to SFT/RL |
| Held-out perturbation eval | 真 OOD 验证 |

---

## 实验结论

- **任务**: agentic function calling
- **基线**: standard post-training
- **结果**:
  - held-out interface perturbation accuracy 降低近 **25%**；
  - CIPR 恢复 **+10.5%**；
  - unchanged interface accuracy 保持不变；
  - SFT 与 RL 后训练均有效。

---

## 局限性

- 仅在 function calling 任务验证；
- KL coefficient 需要调优；
- 极复杂 interface（嵌套、参数化）扩展性待检验。
