# Towards Real-Time Full-Waveform LiDAR Transformers via Intensity-Guided Token Reduction and Physics-Aware Augmentation

> **arXiv**: [2611.07613](https://arxiv.org/abs/2611.07613)
> **发表日期**: 2026-11-05
> **分类**: cs.CV
> **会议/期刊**: NeurIPS 2026 (Main)

## 📋 摘要

LiDAR 是自动驾驶与机器人领域的核心传感器，但在雾、雨、透明物体与低反射率表面等恶劣条件下依然脆弱。Full-waveform LiDAR (FWL) 通过将完整回波波形记录为直方图来缓解这些问题，保留了包括多径回波与弱信号在内的丰富反射特性。虽然近期基于 Transformer 的方法在 FWL 数据上展现出前景，但仍存在两个根本瓶颈：低强度背景区域带来的冗余 token 导致高昂计算成本；以及标注训练数据稀缺导致的泛化受限。作者通过利用 FWL 数据内在的物理结构同时攻克这两个瓶颈。第一，提出 **FWL-ToPM**——一种 token 剪枝与合并（pruning and merging）机制，利用强度分布（intensity distributions）选择性地削减 token，同时保留关键波形内容。第二，提出 **FWLAug**——一个被设计为**正则化方法**的数据增强框架，在保留每条射线的 Time-of-Flight 波形与视锥（frustum）几何结构的前提下增强数据，以提升对未见场景的泛化能力。在 **Ghost-FWL** 基准上评测，FWL-ToPM 在达到实时吞吐的同时实现**超过 8 倍加速**，并相较此前 SOTA 取得**近 9 个点的 F1 提升**，确立了首个同时提升精度的实时 FWL Transformer。FWLAug 进一步在标准基准与一个"未见场景"的 OOD 测试集上改进性能。这些方法共同推动基于 FWL 的感知走向实际部署。代码与 OOD 数据集已公开。

## 🎯 核心贡献

1. **FWL-ToPM**：利用**强度分布**引导的 token 剪枝 + 合并机制，精准削减低强度背景区域的冗余 token，同时保住关键波形内容（多径回波、弱信号）。
2. **FWLAug**：保持物理一致性的数据增强框架——保留每条射线的 **ToF 波形**与**视锥几何**，作为**正则化器**而非简单破坏性增广，用于缓解标注稀缺导致的过拟合。
3. **首个同时提升精度与实时的 FWL Transformer**：在 Ghost-FWL 上取得 **>8x 加速**（实时吞吐）且 **F1 提升近 9 个点**（相对此前 SOTA）。
4. **OOD 泛化验证**：发布未见场景的 OOD 测试集，FWLAug 在其上仍带来增益。
5. **开源**：代码与 OOD 数据集公开（https://keio-csg.github.io/FWL-ToPM）。

## 🔧 方法/架构

- **FWL 表示**：每条射线记录完整回波波形为直方图，保留反射特性（多径回波 multi-path echoes、弱信号 weak signals）。
- **FWL-ToPM（Token pruning & Merging）**：
  - **打分**：以每 token 的**强度分布**衡量信息量——低强度背景区域（雨雾、远空、弱反射表面）的 token 冗余度高
  - **剪枝**：移除低价值 token
  - **合并**：将相邻/同质 token 合并为一个代表 token，在保留关键波形内容的同时压缩序列长度
  - 由于 token 数下降，Transformer 的计算量随之近似二次下降，从而在保持精度的同时达到实时吞吐
- **FWLAug（physics-aware augmentation as regularization）**：生成式增强施加两项硬约束——
  - 每条射线的 **Time-of-Flight 波形结构**保持一致（波形形态不被任意破坏）
  - **视锥几何（frustum geometry）**保持一致（射线在空间中的几何分布）
  在此约束下合成新场景，用于提升对未见场景的泛化，而非仅做常规增广

## 📊 实验结果

- **Ghost-FWL 基准**：
  - FWL-ToPM：**>8x 加速**，达到实时吞吐
  - F1 **提升近 9 个点**（vs. 此前 SOTA）
  - 首个"同时提精度 + 实时"的 FWL Transformer
- **FWLAug**：在标准基准与 **OOD 测试集（未见场景）** 上均有进一步提升
- 具体数值摘要未披露（详见原文实验章节）；代码与 OOD 数据集已公开

## ⚠️ 局限性

- 强度引导的剪枝假设"低强度 ⇒ 低信息量"，但在强反射但语义无关的物体（如反光牌、车牌、玻璃）上可能误删，反而伤害检测。
- 合并操作引入信息损失，其与 Transformer 位置编码/几何编码的相互作用未在摘要中展开。
- 实时吞吐依赖特定硬件与实现（Keio-CSG 项目页），跨平台泛化未验证；"8x 加速"的基线模型与分辨率设置未披露。
- OOD 测试集为作者自建，"未见场景"的定义与真实世界长尾（如罕见天气组合）的差距未量化。
- 属于视觉/感知领域的 Transformer 效率工作，与语言模型的 token 压缩机制（如 KV cache 剪枝）机制不同，迁移价值有限。
- 摘要未讨论夜间、雨雾极端条件下的定量结果。
