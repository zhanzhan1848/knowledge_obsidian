## 核心贡献

1. **PrismaForge**：hierarchical data pipeline + synthesized rubric，把 multimodal code 的质量（program correct / well built / visually right）分解为 checkable criteria
2. **Rubric 双角色**：filter（curate SFT corpus）+ reward（drive visual-coding RL）
3. **PrismaCoder-2M 数据集**（最大 + 最 diverse open multimodal code）+ **PrismaCoder-9B / 35B** 模型

## 方法

### PrismaForge 数据 pipeline

```
code artifacts → rubric criteria → check correctness / structure / visual
                                                  ↓
                                            (a) filter SFT corpus
                                            (b) reward for RL
```

### Rubric 双角色

- **Filter role**：筛选 SFT 训练样本（rubric-passing samples）
- **Reward role**：驱动 visual-coding RL（rubric score as reward）

### 训练 pipeline

- Stage 1：SFT on rubric-filtered corpus
- Stage 2：RL with rubric reward

## 局限性

- Rubric design 需要 domain expertise（program + visual 双领域）
- Rubric criterion 数量 vs 模型可学习性之间需要 trade-off
- 主要 focus 在 visual coding（charts / webpages / animations），不覆盖更广 code 任务

## 建议

- **是否推荐使用**：是
- **适用场景**：open multimodal code 数据合成 + 模型训练；任何 visual + code 双领域训练 pipeline
- **运营价值**：rubric 同时 filter + reward → 减少 dual pipeline 维护成本
