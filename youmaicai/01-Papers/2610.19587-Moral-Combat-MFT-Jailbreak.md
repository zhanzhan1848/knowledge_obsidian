## 核心贡献

1. **Moral Foundations Theory (MFT) 启发的 multi-agent jailbreak framework**：
   - Step 1：diagnose 违反哪个 moral foundation
   - Step 2：identify 该 prompt 在哪个 foundation 下显得 virtuous
   - Step 3：rewrite prompt 到 virtuous framing
   - Step 4：reinforce 用 generated precedents of comparable moral reframing
2. **Safety benchmarks 的 MFT imbalanced 发现**：concentrate 在 model 已 bias 的 foundation 上

## 方法

### Moral Foundations Theory (MFT)

6 个 moral foundations（Haidt）：
- Care / Harm
- Fairness / Cheating
- Loyalty / Betrayal
- Authority / Subversion
- Sanctity / Degradation
- Liberty / Oppression

### Multi-agent pipeline

```python
def jailbreak(prompt):
    # Agent 1: Diagnose violated MF
    violated_mf = diagnose(prompt)
    # Agent 2: Identify virtuous framing
    virtuous_mf = identify_virtuous(prompt)
    # Agent 3: Rewrite
    rewritten = rewrite(prompt, virtuous_mf)
    # Agent 4: Reinforce with precedents
    reinforced = add_precedents(rewritten)
    return reinforced
```

## 实验结果

- 5 个 open-source + proprietary models
- 3 个 well-known jailbreak datasets
- **High single-trial jailbreak success rate**
- **Repeated attempts 进一步上升**
- **Safety benchmarks imbalanced**：concentrate 在 model 已 bias 的 foundations

## 局限性

- 仅在 5 个 models + 3 datasets 上验证
- MFT framework 的 6 foundations 可能不覆盖所有价值维度
- Red team 工具同时被防御方学习 → adversarial 演化
- 没有覆盖所有道德框架（仅 MFT）

## 建议

- **是否推荐使用**：是（用于 red team / safety evaluation）
- **适用场景**：LLM safety red team / safety benchmark 设计 / 对抗 safety 训练
- **运营价值**：揭示 safety evaluation 的 imbalanced → 改进 safety benchmark 覆盖度
