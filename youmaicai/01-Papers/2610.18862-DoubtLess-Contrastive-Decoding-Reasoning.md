## 核心贡献

> 小模型通过两次 CoT 阅读（brief thinker / verbose thinker）的 logit 差分，引导大模型走向更精炼的推理链，无需任何额外训练。

1. **训练免费的对比解码框架**：用 *小型 reasoning 模型* 作为对比信号源，引导大模型缩短 CoT。
2. **跨家族泛化**：在 Qwen3-32B / 其他两个模型族上保持精度不变；CoT 缩短 31%。
3. **可与训练型压缩叠加**：对已经为 brevity 训练过的模型进一步缩短 CoT。
4. **Self-debugging 编码 agent 中**：单 turn thinking token 减少 20%，任务性能不变。

---

## 技术方案

### 核心思想

**对比解码的两条路径**：让一个小型 reasoning 模型对大模型当前的 CoT 进行两次"前向阅读"——一次被提示为 brief thinker（倾向简短），一次被提示为 verbose thinker（倾向啰嗦）。把两次 logits 之差乘以强度系数 $s$，加到大模型的 logits 上作为干预信号：

```math
\ell_{\text{intervene}} = \ell_{\text{large}} + s \cdot (\ell_{\text{brief\_small}} - \ell_{\text{verbose\_small}})
```

### 关键技术

| 技术 | 说明 |
|------|------|
| Brief / Verbose 双提示 | 用 prompt 切换同一小模型的两种推理倾向 |
| Logit 差向强度 $s$ | 控制干预强度（保留大模型原有精度） |
| 小模型 token 特征 | 利用小模型已有的 reasoning 能力作为"cost-free 监督" |
| 训练免费 | 仅在 inference 时计算差分，无 gradient / SFT / RL |

---

## 公式

```math
\Delta \ell_t = s \cdot \bigl(\ell^{M_{\text{small}}}_{\text{brief}}(y_t \mid x, y_{\le t-1}) - \ell^{M_{\text{small}}}_{\text{verbose}}(y_t \mid x, y_{\le t-1})\bigr)
```

```math
y_t \sim \text{Softmax}\bigl(\ell^{M_{\text{large}}}(y_t \mid x, y_{\le t-1}) + \Delta \ell_t\bigr)
```

## 实验结论

- **基准**：7 个 competition math / graduate-level science / competitive programming benchmark
- **主结果**：Qwen3-32B CoT 缩短 **31%**，accuracy 不变；超过 5 个 inference-time baselines
- **Self-debugging 编码 agent**：per-turn thinking token -20%，任务性能持平
- **跨家族**：两个其他模型族（具体见原文）保持 accuracy
- **叠加效果**：与 training-based 压缩模型叠加，进一步缩短 CoT
- **消融**：节省的 token 主要来自"正确答案首次出现之后"的反复 checking

---

## 局限性

- 依赖小模型存在（仍是工程需求）
- $s$ 强度是超参数，需要 task-level tuning
- 当大、小模型分布差异巨大时效果可能不稳定
- 仅验证了 math / science / coding；通用对话 / creative 写作未覆盖
