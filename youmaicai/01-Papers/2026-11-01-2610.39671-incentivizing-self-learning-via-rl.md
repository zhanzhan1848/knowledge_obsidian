# Incentivizing Self-Learning in Large Language Models via Reinforcement Learning

## 摘要
本文研究 LLM 的 **self-learning** 能力：在解题过程中自主地从长篇参考材料（教科书）中检索、学习并应用知识。作者构建了一个 textbook-based 数学证明任务：模型必须浏览教材的章节化叙述，学习并应用相关定理，为练习题构造自己的证明，而参考解答对模型不可见。作者提出 **BookNavigator** 接口（目录浏览、关键词检索、分节阅读三类动作），并用带细粒度奖励的强化学习（GRPO + 退火探索奖励 + 轮级工具信用分配）激励自学习。结果：Intern-S2-Preview-35B 的整体证明准确率从 51.5% 提升到 79.5%（+28.0pp），超过最强的 RL 训练固定检索基线（Top-kSections, 73.1%）6.4pp；策略还能迁移到未见教材（85.2%）、未见学科（86.7%），并在 BrowseComp-Plus（51.9%，+1.7pp）与 CL-bench（17.1%，+2.3pp）上取得最佳成绩。

## 核心贡献
1. **任务形式化**：把 self-learning 定义为在单次 episode 内交错"推理"与"教材学习"，知识获取与推理互为条件，而非检索-聚合或预置上下文学习。
2. **BookNavigator 接口**：模型与教材之间的唯一接口，支持 `get_toc` / `search_index` / `read_section` 三类动作。
3. **细粒度 RL 奖励**：把 GRPO 扩展为"正确性门控的退火探索奖励 + 轮级工具信用再分配"，用冻结的初始策略副本做 tool judge。
4. **系统性泛化证据**：在 ID-Book / OOD-Book / OOD-Subject 三个切分上均领先，且迁移到 BrowseComp-Plus 与 CL-bench 两个外部长上下文基准。

## 方法与架构
**任务与轨迹定义**：给定证明问题 $q$ 与结构化教材 $\mathcal{B}$，非终止轮 $t$ 先生成推理 $z_t$，再选动作 $a_t\in\mathcal{A}$ 获得观察 $o_t$：

```math
(z_t, a_t) \sim \pi_\theta\left(\cdot \mid q, (z_i,a_i,o_i)_{i=1}^{t-1}\right)
```

轨迹 $\tau=(z_1,a_1,o_1,\dots,z_{T-1},a_{T-1},o_{T-1},z_T,\hat{y})$。LLM-as-judge $J_{sol}$ 对照被隐藏的参考解答 $y^\star$ 判定：

```math
r(\tau)\sim J_{sol}(q,y^\star,\hat{y})\in\{-1,1\}
```

**教材表示**：章节化序列 $\mathcal{B}=(s_1,\dots,s_K)$，每节 $s_k=(\pi_k,\ell_k,x_k)$（节标识、标题、保留文本）。

**BookNavigator 动作空间**：① `get_toc` 返回全部目录（$\pi_k,\ell_k$）；② `search_index` 做关键词检索，基于加权词覆盖率、词邻近、精确短语匹配与标题相关度打分排序返回节 id 与片段；③ `read_section` 返回整节保留文本。

**RL 奖励**（两项）：

```math
R_n(\tau)=r(\tau)+\beta_n b(\tau)\mathbb{I}[r(\tau)=1]
```
其中 $b(\tau)=1$（至少一次成功工具调用），$\beta_n$ 按 cosine schedule 从 1 衰减到 0.25（50 个 rollout step）。

轮级工具信用由冻结的 tool judge $J_{tool}$ 给出三分类标签（useful / neutral / harmful），映射为 $c_t=0.5$（harmful）、$c_t=1$（useful 或 neutral）：

```math
\bar c=\frac{\sum_{t=1}^T m_t c_t}{\sum_{t=1}^T m_t},\qquad
\tilde A_t=A+\alpha|A|\,(c_t-\bar c),\qquad \alpha=1
```

$m_t$ 为第 $t$ 轮未被 mask 的策略生成 token 数。工具观察不计入策略 loss。

**GRPO 目标**：

```math
\mathcal{J}(\theta)=\mathbb{E}_{\tau\sim\pi_{\theta_{old}}}\left[\frac{1}{\sum_t m_t}\sum_{t=1}^{T}\sum_{j=1}^{m_t}\min\{\rho_{t,j}(\theta)\tilde A_t,\ \mathrm{clip}(\rho_{t,j}(\theta))\tilde A_t\}\right]
```

## 实验设置
- **数据**：158 本本科/研究生数学教材（分析、代数、数论、几何等），解析出 **5,183** 道证明题；每本教材平均 56 节、约 208k tokens。训练集 4,557 题 / 132 本教材。
- **评测切分**：ID-Book（205 题 / 4 本已见教材）、OOD-Book（155 题 / 7 本未见教材）、OOD-Subject（266 题 / 19 本概率统计教材）。
- **协议对比**：Self-Learning（最多 8 轮交互，总长上限 64k tokens）、No-Book、Top-$k$Sections、Long-Context、Oracle Section（基线均为 64k 输入预算、单次生成、最长输出 64k）。
- **RL 配置**：基座 Intern-S2-Preview-35B，GRPO 训练 50 rollout steps；解答正确性由 GLM-5.2 用 **8-shot pessimistic verification** 判定（8 次独立评审全判对才给 $r=1$）；tool judge 为初始模型的冻结副本。
- **指标**：proof accuracy，每题采样 4 个独立解取均值。
- **外部基准**：BrowseComp-Plus（用 BM25 检索，遵循原推理协议）、CL-bench（直接从给定上下文生成，不用工具），均使用原论文的 judge。

## 实验结果
| 协议 | ID-Book (Base→+RL) | OOD-Book (Base→+RL) | OOD-Subject (Base→+RL) | Overall (Base→+RL, Δ) |
|---|---|---|---|---|
| No-Book | 39.0 → 53.8 | 68.9 → 78.4 | 60.8 → 74.1 | 55.7 → 68.5 (+12.9) |
| Top-kSections | 43.7 → 56.6 | 73.1 → 81.0 | 70.2 → 81.3 | 62.2 → 73.1 (+10.9) |
| Long-Context | 39.6 → 57.1 | 69.4 → 80.8 | 62.1 → 77.5 | 56.7 → 72.2 (+15.5) |
| Oracle Section | 43.2 → 54.4 | 70.7 → 77.6 | 69.0 → 79.9 | 60.9 → 71.0 (+10.0) |
| **Self-Learning** | 33.9 → **65.5** (+31.5) | 65.2 → **85.2** (+20.0) | 56.8 → **86.7** (+29.9) | 51.5 → **79.5** (+28.0) |

**归因实验（Table 2，整体准确率）**：Base / +RL 在 Paired Textbook 下为 51.5 / 79.5；No-Book 为 55.7 / 71.7；Topic-Matched Textbook 为 49.6 / 75.2；Source Removal（移除来源节及其前后各 4 节，共 9 节）为 49.0 / 74.6；Non-Source Removal（随机移除 9 节对照）为 53.0 / 79.8。Source Removal 比 Non-Source Removal 低 5.2pp，说明退化取决于移除内容的位置而非节数。

**跨任务泛化（Table 3）**：BrowseComp-Plus Base 50.2，Self-Learning **51.9**（+1.7），其余 RL 协议均下降（No-Book 48.6、Top-k 49.9、Long-Context 49.4、Oracle 48.2）。CL-bench Overall Base 14.8，Self-Learning **17.1**（+2.3）；分项 DKR 19.0（+4.5）、RSA 17.5（+1.2）、PTE 15.9（−0.6）、EDS 12.6（+5.0，与 No-Book 持平）。所有 RL 协议在 PTE 上都低于 Base。

## 局限性
- 作者自述：证据来自单一任务域（数学证明）与单一基座（Intern-S2-Preview-35B，35B）；judge 使用 GLM-5.2 的 8-shot pessimistic verification，本身是强模型偏置来源；Self-Learning 的 Base 表现反而低于所有基线，说明该协议对基座能力敏感。
- 迁移收益并不均匀：CL-bench 的 Procedural Task Execution 上所有 RL 变体都劣于 Base，作者推测 proof-oriented 训练与严格流程执行不匹配。
- 我的批判性意见：OOD-Subject 只有 266 题、19 本教材，且题源同构；"未见学科"与"未见教材"可能高度重叠（概率统计教材也算 analysis），跨学科泛化的证据强度有限。此外探索奖励的形状 $b(\tau)$ 只是 0/1 指示函数，$\beta_n$ 的 1→0.25 cosine schedule 是经验设定，缺乏敏感性分析。

## 评估与建议
- 是否推荐深入阅读：**是**（agentic RL 与长上下文自学习方向必读）
- 适用场景：构建 tool-augmented 长上下文 agent、设计过程奖励（process reward）与探索激励、评估"检索 vs. 交错学习"的对照实验
- 与知识库的关联：与 Agentic RL 细粒度信用分配（HCAPO、StepSearch、IG-Search）、长上下文推理、教材式自监督数据构建相关
