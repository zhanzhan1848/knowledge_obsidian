## 核心贡献
1. 提出 **Iris-mini (35B-A3B)** 和 **Iris-pro (397B-A17B)** 两个搜索 Agent
2. **数据管道**：从网页超链接结构反向构建任务——多跳推理链 + 描述性引用重写（防止字符串匹配）
3. **SFT-RL Climbing**：交替 SFT 和 RL 阶段，RL 使用 live search 优化，reward judge 和 observation summarizer 在训练集群内
4. 超长 rollouts 在 request 级别中断，下一步从 committed prefix 恢复

## 性能
- Iris-mini: BrowseComp 82.2, BrowseComp-ZH 84.8, DeepSearchQA 86.9, HLE 52.3
- Iris-pro: 88.6/85.1/92.9/56.4
- 同参数规模开源搜索 Agent 最强

## 关键洞察
- 推理时上下文管理比大多数系统间差异更有价值
- 所有结果来自单一 ReAct agent，无子 Agent，无 test-time verification
