# VERGE: Verification-Enhanced Refinement for Grounded Extraction of Early-Onset Colorectal Cancer Symptoms

## 核心贡献
1. 提出 **VERGE**：Agentic RAG 工作流，用于从临床笔记提取早发性结直肠癌警示症状
2. 提取六种红旗症状 + 家族史风险状态

## 工作流
```
初始标签+证据（RAG） → 有界验证-精炼循环
  → 检查文本 grounding 和临床有效性
  → 修正并重新检查，直到解决或达到限制
  → 未解决的升级人工审核
```

## 性能
- 4033 对临床标签笔记
- 精度：0.764 → 0.849
- MCC：0.681 → 0.730
- 仅 1.5% 的 claims 需要人工审核
