# Aligning Large Language Models for Safety in African Languages: A Case Study of Hausa

## 摘要
本文研究安全对齐（safety alignment）在低资源语言 Hausa（豪萨语，使用人口超 2 亿，主要分布于尼日利亚北部、尼日尔与加纳）上的表现。作者基于 PKU-SafeRLHF 构建了 HausaSafeLM 数据集：共 10,000 条 prompt，分为人工校正的 gold 层 3,000 条与机器翻译的 silver 层 7,000 条，覆盖六大类伤害宏类别（由 19 类中保留的 15 类归并而成，丢弃 Copyright Issues、Privacy Violation、White-Collar Crime、Animal Abuse 四类）。以 Qwen2.5-7B-Instruct 为基座，对比 SFT 与 SFT+DPO 在两种数据配置下的表现，在 500 条有害 Hausa prompt 与 200 条良性 Aya Hausa prompt 上评测。核心发现是：未微调基座模型的 refusal rate 已达 1.000，但这源于 Hausa 生成能力不足而非真实对齐（96.2% 的拒答被判定为低质量，SafeQ=0.021）；SFT 显著提升拒答流畅度与精度且从更大更噪的 silver 数据中获益显著，而 DPO 提升拒答精度但以几乎与数据量无关的语言质量代价为代价。作者强调：在低资源语言场景中，仅用 refusal rate 衡量安全性是不可靠的信号。

## 核心贡献
1. **HausaSafeLM 数据集**：首个 Hausa 安全偏好数据集之一，10,000 条 prompt（gold 3,000 / silver 7,000），按伤害类别分层抽样，同时支持 SFT 格式 (prompt, chosen) 与 DPO 格式 (prompt, chosen, rejected)。
2. **受控对比实验**：在 gold-only 与 gold+silver 两种数据regime 下系统比较 SFT 与 SFT+DPO，评测维度从单一 refusal rate 扩展到 refusal precision (FRR)、helpfulness (HR) 与语言质量 (SafeQ/AyaQ)。
3. **揭示"对齐税"权衡面（trade-off surface）**：SFT 提升流畅度与覆盖度，DPO 提升拒答精度但相对偏好目标对流畅度无激励；没有任何单一配置同时实现安全、有帮助与流畅。
4. **阶段性数据规模结论**：对模仿式 SFT 而言更大更噪的 silver 数据收益巨大（FRR 0.405→0.245，HR +0.080，SafeQ +0.112），而对 DPO 的对比偏好目标几乎无用（SafeQ 仅 +0.013，HR −0.020）。

## 方法与架构
- **基座模型**：Qwen2.5-7B-Instruct，零样本评测后用 LoRA 微调，作用于 attention 的 query / key / value / output 投影层，硬件为 2×NVIDIA A100 80GB。
- **五组配置**：Base（zero-shot）、SFT-G（gold 3,000）、SFT-GS（gold+silver 10,000）、DPO-G（在 SFT-G 上）、DPO-GS（在 SFT-GS 上），各自独立训练与评测。
- **DPO 目标函数**（论文公式 1）：

```math
\mathcal{L}_{DPO}(\theta) = -\mathbb{E}\left[\log\sigma\left(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_\theta(y_l|x)} - \beta\log\frac{\pi_{ref}(y_w|x)}{\pi_{ref}(y_l|x)}\right)\right]
```

- **gold 层四遍人工后编辑协议**：(1) fluency（语法与地道性）、(2) meaning（恢复 rejected response 的伤害意图、确认 chosen 确实是正确拒答，因 MT 会软化有害语言）、(3) register（正式度对齐真实用法）、(4) localization（替换西方特有的机构/情境为本地化替代）。
- **翻译方式**：Google Translate 逐字段翻译（prompt / chosen / rejected 分开），避免跨字段污染；silver 层不做任何人工后编辑，与 gold 层来自同一过滤池，从而隔离"翻译噪声"这一变量。
- **敏感度标签**：low 40%、medium 40%、high 20%（high 表示可能直接导致现实伤害）。
- **评测**：500 条 held-out 有害 Hausa prompt（按伤害类别与数据层分层）+ 200 条良性 prompt（取自 Aya dataset 的 Hausa 部分），统一用 Gemini 作为 LLM judge，配合结构化 rubric，从 SAFE/UNSAFE、HELPFUL/PARTIAL/REFUSED、HIGH/MEDIUM/LOW 三个轴打分。
- **五个指标**：

```math
RR = \frac{\#\text{correctly refused harmful}}{\#\text{harmful}},\quad
FRR = \frac{\#\text{incorrectly refused benign}}{\#\text{benign}}
```

```math
HR = \frac{N_{helpful} + 0.5\,N_{partial}}{N},\qquad
SafeQ = \frac{N_{high} + 0.5\,N_{medium}}{N},\qquad
AyaQ = \frac{N_{high} + 0.5\,N_{medium}}{N}\ (\text{benign})
```

作者刻意不报告 ASR，因为它定义上等于 1 − RR，在已报告 RR 后不提供额外信息。

## 实验设置
- 模型：Qwen2.5-7B-Instruct（唯一基座），LoRA 参数高效微调；未尝试更大模型或其他模型族。
- 数据：HausaSafeLM（PKU-SafeRLHF 派生）；训练用 gold 3,000 / gold+silver 10,000；评测用 500 有害 + 200 良性（Aya Hausa）。
- 指标：RR、FRR、HR、SafeQ、AyaQ（另有 Figure 6 五维雷达图：RR、HR、1−FRR、SafeQ、AyaQ，轴向均调整为"面积越大越好"）。
- Judge：Gemini（单一 LLM judge，非多名母语者标注）。

## 实验结果
| Variant | RR ↑ | FRR ↓ | HR ↑ | SafeQ ↑ | AyaQ ↑ |
|---|---|---|---|---|---|
| Base | 1.000 | 0.096 | 0.256 | 0.021 | 0.165 |
| SFT-G | 1.000 | 0.405 | 0.180 | 0.238 | 0.2025 |
| DPO-G | 1.000 | 0.110 | 0.255 | 0.023 | 0.1425 |
| SFT-GS | 1.000 | 0.245 | 0.260 | 0.350 | 0.2675 |
| DPO-GS | 1.000 | 0.110 | 0.235 | 0.036 | 0.1325 |

关键观察：
- Base：RR=1.000 但 96.2% 拒答为低质量、仅 0.4% 为高质量；良性 prompt 上 74.4% 的时间无帮助（HR=0.256）、AyaQ=0.165。
- SFT-G：32% 的拒答被评为 HIGH/MEDIUM；SFT-GS 提升到 45%；但 SFT-G 过保守，FRR=0.405、HR=0.180。
- DPO-G / DPO-GS：FRR 均降至 0.110 且 RR 保持 1.000，但 SafeQ 掉到 0.023–0.036，94–95% 拒答为低质量，与 base 相当（SafeQ 下降 85–90%）。
- 良性 Aya prompt 上所有配置（含 base）以 LOW 为主（base 73% LOW），仅 SFT-GS 的 HIGH 比例显著更高（20%）。
- SFT-GS 是作者认为最平衡的配置（SafeQ 与 HR 均为最高，FRR 明显低于 SFT-G），但其 FRR 仍高于 DPO 变体。
- Table 3 中四个训练变体的 AyaQ 数值原文标注为 "pending confirmation against raw evaluation logs"。

## 局限性
作者自述：
- 仅使用一个 7B 基座模型，结论未必能推广到更大模型或可能在偏好优化中保留更高 Hausa 流畅度的其他模型族。
- 安全/有用性/质量判断由单一 LLM judge (Gemini) 完成而非多名母语者标注；自动判定低资源语言的流畅度与恰当性本身可能出错。
- 仅 500 条有害 + 200 条良性 prompt，虽足以检出效应（如 DPO 导致 SafeQ 下降 85–90%），但配置间的小差异需谨慎对待，建议后续使用 bootstrap 置信区间与显著性检验。
- 数据集由英文 PKU-SafeRLHF 翻译改编而来，而非本土豪萨语原生采集，本地特有伤害可能仍被低估。

我的补充批评：仅用 Gemini 单 judge 且该 judge 本身对 Hausa 的判别力未做校验，是全文最脆弱的一环——毕竟全文核心结论正是"指标可能误导"，而评测指标本身的可靠性未被验证；此外 base 模型"因语言能力弱而安全"的解释未与"因理解而拒答"做因果区分（如可加入多语言平行 prompt 或能力对照实验）。

## 评估与建议
- 是否推荐深入阅读：是（作为低资源语言安全对齐的实证与方法论警示，尤其适合 safety metric 设计者）
- 适用场景：低资源语言的安全评测与对齐实验设计；构建非英语安全数据集与 rubric；讨论 refusal rate 指标有效性的论文。
- 与知识库的关联：可与 2610.39590（Yoruba/Nigerian Pidgin 红队研究）、AfriGuard / UbuntuGuard 等非洲语言安全基准互为佐证；与"alignment tax"、over-refusal 主题（如 2610.39802）直接相关。
