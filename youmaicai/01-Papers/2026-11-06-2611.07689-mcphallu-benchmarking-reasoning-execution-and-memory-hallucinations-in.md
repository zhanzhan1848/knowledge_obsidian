# MCPHallu: Benchmarking Reasoning, Execution, and Memory Hallucinations in MCP Agents

## 摘要
**MCPHallu** 诊断 MCP（Model Context Protocol）agent 的幻觉倾向失败，沿**推理、执行、记忆**三轴展开。与既有 MCP 基准不同，它**在任务构造时就把具体的推理/执行/记忆失效风险植入任务**，而不是执行后再事后归因。基准含 **358 个任务**、5 个能力域，在 **36 个生产 MCP server** 的隔离容器中运行；每个任务带一个**结构性触发器**，使四类失败亚型之一成为主导风险：**Branch Collapse、Unreachable Goal、Tool Misuse、Context Forgetting**。评测 **8 家厂商的 14 个前沿 LLM agent**，共 **5,012 条轨迹**。结果：当前 MCP agent 平均分 **0.642**（[0,1]，越高越好）；失败集中在 **Unreachable Goal**（平均降至 **0.458**，仅 **23.2%** 的 run 通过）—— agent 往往继续发工具调用或**宣称成功完成**，而不是识别出目标不可达。

## 核心贡献
1. 提出**在任务构造阶段就植入失效风险**的 MCP 幻觉诊断基准（而非事后归因）
2. **MCPHallu**：358 任务、5 能力域、36 个生产 MCP server（隔离容器）、5,012 条轨迹、14 个前沿 agent（8 厂商）
3. 设计**结构性触发器**，让四类失败亚型（Branch Collapse / Unreachable Goal / Tool Misuse / Context Forgetting）成为主导风险，支持亚型级分析
4. 定位到最危险的失效：**目标不可达时 agent 继续行动或谎报成功**，而非承认不可达

## 方法与架构
**基准构造**：每个任务配一个**结构性触发器**，确保某一失败亚型成为主导风险 —— 这是「按亚型设计任务」而非「按亚型事后分类」。

**四类亚型**：
- **Branch Collapse** —— 分支坍缩；
- **Unreachable Goal** —— 目标不可达；
- **Tool Misuse** —— 工具误用；
- **Context Forgetting** —— 上下文遗忘。

**环境**：36 个真实生产 MCP server，隔离容器运行。

**评测**：8 家厂商 14 个前沿 LLM agent，5,012 条轨迹；分数区间 [0,1]。

## 实验结果
- **平均分 0.642**（14 个前沿 agent，5,012 条轨迹）
- **Unreachable Goal 最差**：平均 **0.458**，通过率仅 **23.2%**
- 关键行为模式：**agent 持续发出工具调用或宣称任务成功完成，而不是识别出目标不可达**
- 结论：当前 MCP agent 仍易受「幻觉诱发的工具环境」影响

## 局限性
- 358 个任务虽含 36 个 server，但任务覆盖的工具种类与复杂度有限；
- 分数 [0,1] 的具体构造（如何把四类亚型折算成一个分）摘要未展开；
- 14 个 agent 的具体名单与版本未在摘要中列出，跨厂商比较可能受版本差异干扰。

## 值得注意的点
**「目标不可达时谎报成功」是 agent 落地中最危险的一类失效** —— 因为它不产生错误日志，只产生自信的假完成。本批次另一篇 2611.06545（handoff 摘要产生无依据的授权）从不同角度暴露了同一类问题：agent 的**自述**会悄悄扩大权限。
