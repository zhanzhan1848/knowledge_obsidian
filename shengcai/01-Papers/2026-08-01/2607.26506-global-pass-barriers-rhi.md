## 核心贡献

> 无需逐资源追踪的全局 Pass 屏障：跨 6 GPU 厂商研究，揭示 GPU 屏障放置优化空间

1. 提出 Blade：保持 Vulkan images 为 GENERAL，无逐资源状态追踪，发布全局 pass-boundary 屏障
2. 跨 4 厂商 6 GPU 测试（包括 Apple/Metal 探索性结果）
3. 移除 15 个冗余屏障：RTX 5070 减少 29.3% GPU span，RX 7900 XT 减少 32.3%
4. 从 pass 种类推导全局屏障范围，无需资源追踪：NVIDIA 图形链减少 5.0%，AMD 计算链减少 6.7%

---

## 技术方案

### 核心思想

显式图形 API 暴露内存依赖、逐资源访问和图像布局。wgpu 重建和验证状态；Blade 保持 Vulkan images 为 GENERAL，不追踪逐资源状态，只发布全局 pass-boundary 屏障。

关键发现：
- 命令数量不能预测这些代价：广泛全局依赖扩展为多个 flush/invalidate 请求
- 持久 GENERAL 在测量条件下保留 DCC 但禁用 FMASK
- Blade 方向：轻量级聚合 pass-kind 状态在无追踪 RHI 中

### 关键技术

| 技术 | 说明 |
|------|------|
| Global Pass Barriers | 全局 pass 级屏障 |
| Pass-Kind State | pass 种类聚合状态 |
| GENERAL Layout | 避免 layout 转换 |
| Cross-Vendor Testing | 6 GPU 跨厂商测试 |

## 实验结论

### 独立计算 Pass（16 个）
| GPU | Span 减少 |
|-----|-----------|
| RTX 5070 | 29.3% |
| RX 7900 XT | 32.3% |

### 独立渲染 Pass
| GPU | Span 减少 |
|-----|-----------|
| RTX 5070 | 32.4% |
| RX 7900 XT | 7.3% |
| Radeon 780M | +42.4% (负面影响) |

### 全局屏障范围优化
- NVIDIA 图形链：减少 5.0%
- AMD 计算链：减少 6.7%

---

## 局限性

- 特定于渲染图架构
- 对某些集成 GPU 可能有负面影响
- 依赖上游 render graph 选择全局依赖切割

---

## 实现建议

- **实现难度**: 高（需 RHI 层重构）
- **预期性能**: 独立 pass 30%+ 提升
- **适用场景**: 游戏引擎渲染后端、低级图形 API 优化
- **优先级**: ⭐⭐⭐⭐ (渲染管线底层优化)
