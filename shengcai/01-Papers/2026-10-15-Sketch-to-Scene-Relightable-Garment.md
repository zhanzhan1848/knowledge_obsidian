## 核心贡献

> 让设计师用**带稀疏标注的草图**（⭐ = 高光位置，🌙 = 阴影位置）直接生成**可重光照的服装 3D 场景**——把"阴影"从烘焙进纹理的死像素，变成由**位移场弯曲表面**产生的真实阴影。

1. **提出 marked sketch（标注草图）作为意图输入**：草图天然包含"高光和阴影该出现在哪"的空间意图，而当前 sketch-to-3D 管线**没有接收这种意图的接口**——它们把画出来的明暗**烘焙成深色油漆进纹理**，导致光无法移动。
2. **⭐ / 🌙 双符号标注**：来自对艺术学生的**启发式研究（elicitation study）**，这两个符号是学生提案中出现频率最高的。
3. **联合预测方向光 + 位移场**：从标注草图中**分别**预测场景的方向光，以及一个**位移场（displacement field）**，让 🌙 标记的区域在**该光源下真正落入阴影**，而不是在纹理里被涂黑。
4. **端到端产出可编辑场景**：粗略服装草图 + 简短文本描述纹理 → 带纹理的 3D 网格 + **显式方向光**，生成后可**重新打光与编辑**。

## 技术方案

### 核心思想

问题诊断非常锐利：现有 sketch-to-3D（含草图生纹理）管线把**用户画出的明暗当作 albedo 的一部分**（bake the drawn shading into the texture as dark paint）。后果是**光照被"烧死"了**——纹理里那些深色区域永远深色，无论光从哪来。

论文的解法是**区分"着色意图"与"材质"**：
- **⭐ 高光标注** → 转化为对**方向光方向**的约束（把光对准，使该处产生高光）
- **🌙 阴影标注** → 转化为对**几何（位移场）**的约束（把表面弯过去，让它在当前光下**真的**被遮蔽），而**不是**画进 albedo

这样生成结果在物理上是自洽的、可重光照的。

### 关键技术

| 技术 | 说明 |
|------|------|
| **意图 elicitation** | 先做用户研究确定最有表达力的符号，再据此设计输入格式——**HCI 方法论与渲染技术的结合**，符号选择有实证依据。 |
| **方向光预测** | 从草图整体光照分布（尤其 ⭐ 位置）回归方向光的方向（+ 强度）。 |
| **位移场预测** | 生成一个稠密位移场 $d(\mathbf{p})$，弯折表面几何，使 🌙 区域在该光下进入自阴影。这是**几何层面的阴影，而非纹理层面的伪影**。 |
| **可重光照输出** | 输出显式方向光 + 几何 + 材质 → 生成后可直接重新打光、编辑（区别于烘焙式管线）。 |
| **文本提示补充** | 草图 + 短文本提示（描述纹理）联合输入，弥补草图无法表达材质细节的不足。 |

## 公式

论文核心为学习式预测，摘要未给出显式公式。可确定的物理关系为**位移场产生阴影**的约束：

```math
\text{阴影判据:}\quad
\exists\,\mathbf{p}\text{ 被 }\boldsymbol{\omega}\text{ 遮挡}
\iff
\forall\,\mathbf{q} \in \mathrm{Ray}(\mathbf{p},\boldsymbol{\omega}):\
   d_{\text{surface}}(\mathbf{q}) < h_{\mathbf{p}}(\boldsymbol{\omega})
```

即：🌙 标记点 $\mathbf{p}$ 处的表面沿光线 $\boldsymbol{\omega}$ 方向被自身（经位移场 $d$ 弯曲后的）几何所遮挡，使出射光线被切断从而产生阴影。这与"在 albedo 中写入低值"在物理上根本不同——前者随光源移动而变化，后者是恒定的。

## 局限性

- **需要显式标注**：⭐/🌙 必须由用户手动标记，增加了交互负担；对不熟悉该约定的用户有学习成本。
- **仅方向光**：只预测方向光（directional light），不支持点光、面光、环境光（HDRI）。
- **仅服装（garment）**：几何先验与位移场假设针对布料褶皱，未验证其他物体类型。
- **位移场的表达能力上限**：位移场只能弯折表面，**无法表达自遮挡所需的拓扑变化或层叠结构**（如袖口翻折、层叠布料）。
- **草图的信息量瓶颈**：粗略草图 + 短文本 → 完整可重光照材质，中间仍需大量生成模型先验，细节保真度受限。
- **定量评测薄弱**：作为系统/HCI 论文，缺少与现有可重光照重建方法的定量对比。

## 实现建议

- **实现难度**：**中**（依赖已有草图生 3D 底模 + 位移场预测头的训练）。
- **预期性能**：11 页系统论文，无明确性能指标；生成质量取决于底模。
- **适用场景**：
  - 服装电商的**快速可重光照预览**（设计师标注高光/阴影意图 → 直接得到可打光结果）
  - 概念设计阶段的快速服装原型
  - 需要"意图可控"的创作工具
- **对 @墨鱼丸 的建议**：
  1. **核心洞见值得单独记住**：*"把用户画的明暗烘焙进 albedo 是错的；高光意图应转为光照约束，阴影意图应转为几何（位移场）约束。"* 这是一条**通用的可重光照资产生成原则**，与具体草图输入无关，可用于任何"用户绘制明暗 → 3D 资产"的管线设计。
  2. 若我们做布料/服装资产，可考虑采纳"**用位移场实现设计师指定的阴影**"这一手段——它让阴影可随光移动，是烘焙式做法无法达到的。
  3. 实际落地时建议**扩展符号集**（如三角形=材质粗糙度、箭头=光照方向），论文只做了 2 个符号。
- **优先级**：**低–中**。属于交互工具型研究，洞见有价值但工程量与直接渲染管线关联较弱。
