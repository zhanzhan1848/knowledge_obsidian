# Reverse-Sweep Adjoints for Block Implicit Simulation

## 基本信息

| 标题 | 值 |
|------|-----|
| 作者 | Lei Shu et al. |
| 发表 | arXiv cs.GR (2026-08-09) |
| 链接 | [arXiv:2608.08559](https://arxiv.org/abs/2608.08559) |
| PDF | [PDF](https://arxiv.org/pdf/2608.08559) |

## 核心贡献

1. **求解器级微分** - 不是微分收敛方程，而是微分实际执行的求解器
2. **反向扫描公式** - 离散伴随通过反向应用相应的伴随更新获得
3. **局部求解** - 反向传递由局部 3×3 伴随求解组成，无全局系统
4. **高效记忆** - 比展开自动微分快 33 倍，内存少 71 倍

## 技术方案

### 核心方法

```
前向传递: 局部块求解 → 有序局部求解 (近似逆)
                                    ↓
反向传递: 反向局部伴随求解 ← 反向扫描
```

### 关键创新

1. **块隐式更新求解器** - Vertex Block Descent 的反向彩色高斯-赛德尔扫描
2. **精确匹配自动微分** - 在每个求解器深度与自动微分精度匹配
3. **无全局系统** - 构造无全局系统
4. **扩展性**: 弹性动力学 → 投影动力学 → 扩展位置动力学

### 性能对比

| 方法 | 速度 | 内存 |
|------|------|------|
| 方程级伴随 | - | - |
| 展开自动微分 | 1x (基准) | 1x (基准) |
| 反向扫描伴随 | 33x | 71x 减少 |

### 应用规模

- **100万接触耦合软体** (800万顶点)
- **单 GPU**

## 可行性分析

- **创新性**: ⭐⭐⭐⭐⭐ - 求解器级微分的新范式
- **实用性**: ⭐⭐⭐⭐ - 对可微渲染和逆问题求解有重要价值
- **难度**: 高 - 需要深入理解求解器结构和伴随方法
- **渲染相关性**: 可微渲染的基础设施，对逆渲染有影响

## 推荐度

**推荐关注** - 可微模拟是神经渲染和逆渲染的关键基础设施。这项工作提出的反向扫描伴随方法对构建高效可微渲染器有重要参考价值。
