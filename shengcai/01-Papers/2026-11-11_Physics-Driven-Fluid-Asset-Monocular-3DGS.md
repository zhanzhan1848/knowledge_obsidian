## 核心贡献

> **流体是「开放系统」** —— 物质不断进出场景、拓扑自由变化、**不存在稳定的点对应**。因此逐帧形变场（deformation field）范式在物理上是错的。本文改为**优化流体模拟器的参数**，让前向模拟复现视频中的动力学。

1. **问题重构**：把「单视图视频 → 3D 流体资产」**从重建问题重构为物理参数优化问题**。不拟合逐帧形变，而是求解**物理流体求解器的模拟参数**（粘性、密度、边界条件、进出流速度等），使其前向模拟复现观测到的动力学。
2. **四阶段流水线**（几何 → 表面运动 → 体积速度场 → 可微 APIC 参数优化）。
3. **主流引导 + 2D 散度约束的速度修正算法**：从光流中恢复运动向量，用**由不可压缩条件导出的 2D 散度约束**修正失效区域。
4. **可微网格速度演化**：在 **APIC**（Affine Particle-In-Cell）基础上，用 **PeRCNN**（PDE-Net 风格的卷积核拟合 + 外层循环结构模拟隐式求解器迭代）实现**对模拟参数可微**的速度演化。
5. **产物是可重模拟的资产**：天然支持新视角渲染、交互、时间延展、直观参数编辑；**兼容 Blender / Unreal Engine** 标准图形引擎。

## 技术方案

### 核心思想

**为什么逐帧重建不行**（论文的核心论证）：

| 闭合系统（弹性体、人脸、铰接物体） | 开放系统（流体） |
|---|---|
| 每个物质点在整个序列中持续存在 | 物质通过流入/流出**进出场景** |
| 拓扑稳定 | 拓扑通过**飞溅、合并、碎裂**自由变化 |
| 逐顶点跟踪有意义 | **不存在稳定的点对应** |
| 逐帧形变场范式有效 | 形变场**无法表达**开放系统 |

> 若把逐像素重建套到流体上，就得**跟踪场景中并不持续存在的物质**。即使对训练相机拟合成功，得到的模型也**无法泛化** —— 形变场只解释了观测视角，**不保证从其他角度产生物理正确的 3D 运动**。

**本文的取舍**：优先保证**物理动力学**而非逐像素外观。逐像素重建能获得高图像相似度，但那是**伪物理（pseudo-physical）**的，既不保证新视角泛化，也不保证下游可编辑性。

### 关键技术

| 技术 | 说明 |
|------|------|
| **生成式 3DGS** | 上游用生成模型（**TRELLIS** / TriplaneGaussian 等）从单视图得到初始几何**（含未见表面）** |
| **几何一致性预处理** | 生成模型**不保证跨帧几何一致** —— 相邻帧可能产生差异很大的背面几何。做法：**去噪 + 致密化 + 求并集（union）**；主要处理**背面几何（河床、地面）与轮廓边缘（河岸）** —— 这些地方生成预测跨帧变化最大。并集保留这些粒子，但它们在别的帧无速度，故不影响下游模拟；**朝向相机的流体表面不被并集改变**，保留自然的表面变化 |
| **主流插值（Mainstream interpolation）** | 对地形约束的流动（河流）：边缘检测 → 连通轮廓追踪 → 传播流动方向 → 得到**与河道几何对齐的平滑主流** |
| **2D 散度约束修正** | 由不可压缩条件导出 2D 散度约束；因失效区域的光流不构成适定边界，**迭代求解器**：用主流插值初始化，逐步松弛以满足约束。散射表面附近深度变化小 → 右端趋于零 → 恢复近似 2D 不可压缩性 |
| **壁面函数（Wall functions）** | 估计近壁速度：采用**层流边界层的三阶多项式近似** $\delta$ 由流体类型动态设定（河流用较大 $\delta$ 捕捉河床的渐进速度梯度；自由表面流体 $\delta$ 限制在亚格子尺度，引入最小阻尼） |
| **散度自由投影** | 对每个网格单元施加 $(\nabla\cdot\mathbf{v})_i=0$，迭代更新速度；修正量由所有影响 $\mathbf{v}_j$ 的约束的梯度累积，松弛参数 $\epsilon$ 保证稳定收敛。**与 Chorin 投影不同**：直接把速度投影到散度自由流形上，**不构造中间压力场** |
| **APIC** | 混合 Eulerian-Lagrangian 格式，同时守恒**线动量与角动量**（仿射速度传递） |
| **PeRCNN** | **PDE-Net 思想**（卷积核权重可拟合有限差分格式的微分算子）+ **外层循环结构**（每层更新潜在压力 $P^{(k)}$、边界条件、速度）。整个前向是标准可微操作（卷积、激活、逐元素算术）→ 梯度**自动反传**得到 |
| **PeRCNN 数值验证** | 部署前拟合卷积核权重与偏置以匹配**二阶 Laplacian 离散格式**；配对数据由重建速度场生成（隐式求解器前后的压力作为训练目标） |
| **可优化的参数集 $\Theta$** | $\Theta=\{\mathbf{v}_{\text{in}},\tilde{\mathbf{v}}_{\text{in}},\mathbf{v}_{\text{out}},\rho,\nu,(b,d)|_{\text{B.C.}},\mathbf{g},\Delta t\}$：进出流速度、进出流波动、密度、运动粘度、边界弹跳/阻尼系数、重力、时间步 |
| **物理约束的损失** | L2 速度幅值差 + 额外**方向对齐项**；在区分「表面/遮挡」「运动/静止」「占据/空」的网格掩码上施加 |
| **可微网格速度演化** | 粒子速度通过 P2G 转移到规则网格（仿射矩阵 $\mathbf{C}$ 初始化为 0）；网格表示的优势：① 通过固定网格坐标高效跟踪帧间流体动力学；② 使流体方程与网格对流**对模拟参数可微** |
| **对流离散** | 对流后速度 $\mathbf{v}$ 与对流前 $\mathbf{v}'_i$ 的关系用**一阶迎风格式（upwind scheme）**做空间离散以增强稳定性 |

## 公式

**Navier-Stokes 方程（控制方程）**：

```math
\frac{\partial \mathbf{v}}{\partial t} + (\mathbf{v}\cdot\nabla)\mathbf{v} = -\frac{1}{\rho}\nabla p + \nu\nabla^2\mathbf{v} + \mathbf{g}
```

（$\nabla p$ 为压力梯度，$\rho$ 密度，$\nu$ 运动粘度，$\mathbf{g}$ 重力等体力加速度）

**2D 散度约束修正**（式 7）：由不可压缩条件导出

```math
\nabla\cdot\mathbf{u}_{2D} = 0
```

**散度自由投影的迭代更新**（式 9）：

```math
C_i : (\nabla\cdot\mathbf{v})_i = 0
```

```math
\Delta\mathbf{v}_j \leftarrow \Delta\mathbf{v}_j + \epsilon\,\sum_{i:\,j\in\text{neigh}(i)} \nabla C_i
```

**损失函数**（式 10）：

```math
\mathcal{L}=\underbrace{\lVert \mathbf{v}_{\text{pred}}-\mathbf{v}_{\text{ref}}\rVert_2^2}_{\text{幅值 L2}}+\lambda\,\underbrace{\bigl(1-\cos(\mathbf{v}_{\text{pred}},\mathbf{v}_{\text{ref}})\bigr)}_{\text{方向对齐}}
```

（施加于区分表面/遮挡、运动/静止、占据/空的网格掩码上）

**APIC 粒子-网格转移**（式 1）：$\mathbf{v}_i$ 与仿射矩阵 $\mathbf{C}$ 转移到网格；反之，网格速度与更新后的仿射矩阵转移回粒子作为 $n+1$ 时刻的状态。

## 实验结论

- **场景**: 4 个实拍场景 + 2 个合成测试视频（**红色河流**、**蜂蜜倾倒**）；不同 3DGS 生成器
- **基线**: 未优化参数的模拟 vs 优化后模拟；逐阶段消融
- **工具链**: OpenCV + OpenGL + **Taichi**（并行加速）

### 四阶段流水线

| 阶段 | 内容 |
|---|---|
| **Stage 1** | 生成式 3DGS 初始几何 + 预处理（去噪 / 致密化 / 并集） |
| **Stage 2** | 光流估计表面运动向量 + 主流修正 + **2D 散度投影** |
| **Stage 3** | 边界层估计（近壁速度）+ 约束投影求解**散度自由体积速度场** |
| **Stage 4** | 通过**可微 APIC 速度演化**优化模拟参数 |

### Table I — 优化前后的代表性模拟参数与输出

| 参数 | 优化前 | 优化后 |
|---|---|---|
| $\vec{v}_{3D}$ [m/s] | $\times 10^{-1}$ | $\times 10^{-3}$ |
| $p$ [Pa] | $\times 10^{1}$ | $\times 10^{-3}$ |
| $\vec{v}_{in}$ [m/s] | $\times 10^{-2}$ | $\times 10^{-3}$ |
| $\vec{v}_{out}$ [m/s] | $\times 10^{-2}$ | $\times 10^{-3}$ |
| bouncing [·] | $\times 10^{-1}$ | $\times 10^{-1}$ |
| $\mathbf{g}$ [m/s²] | $\times 10^{-2}$ | $\times 10^{-3}$ |
| $dt$ [s] | $\times 10^{-2}$ | $\times 10^{-1}$ |

（几何尺度：$10^{-2}$ m）

> **从物理上合理的初始化出发，优化器一致收敛到稳定值**。对照：**未优化的参数即使在同一几何上也会溢出、发散**（Fig. 16(b)）；即便初始参数尺度相近，**微小差异会在连续步中累积**。

### 阶段消融（Fig. 18，相对完整流水线的比率）

- **去掉屏幕空间运动检测**：几乎什么都不剩（**corr = 0.15**）
- **各几何阶段**各自使相关性降低 **0.3–0.5**
- **已有场的精修阶段**影响较小
- **去掉体积填充**：观测区保持在 **0.56**，但**未见内部跌到 0.06**
- **由于 77% 的流体从未被观测**，这些阶段让输出成为**体积场**而非表面场

> 每个消融主要**损害自己阶段对应的区域**而不影响其他区域 → 阶段职责清晰。

### 逐阶段验证的关键结论

- **方向对齐项的必要性**（Fig. 16）：仅用 L2 损失时，**单个速度分量接近，但局部流向可能显著不同**；加入方向项后，场在数值与视觉上都与参考一致
- **合成场景速度精度**（Fig. 17）：从表面运动提取 + 体积构建的估计速度**捕获了中尺度动力学但表面仍有噪声**；参数优化后**更平滑、更物理一致**，能恢复细节 —— 河流中的**边界诱导减速**、蜂蜜入流区的**应变发展**

### 鲁棒性（Fig. 21–24）

- **对初始化鲁棒**：每个参数组的初值扫过**三个数量级**，几乎每次运行都收敛到**相同的最终损失** —— 起点决定**收敛耗时**而非**收敛结果**
- **但物理上不合理的起点会破坏优化**：灰色轨迹（把入口指出场景）**永远无法恢复**，尽管其初始损失看起来普通（入口只覆盖少量单元）→ **制表常量在这里恰好很有帮助**（把优化放进正确的吸引盆）
- **超参敏感性**：光流求解器设置**基本平坦**；本文引入的量各显示**平台而非尖锐最优** → 默认值**可跨场景迁移，无需逐场景调参**
- **依赖关系温和**：输入视频中的遮挡可以容忍（只要生成器把流体放在遮挡物后面）；**非理想的背面几何被边界条件优化吸收**（除中间深度外）；后续速度构造对前阶段**稳健地响应**
- **参数组不可互换**（Fig. 24）：材料项 $\rho,\nu$ 给出流体**内聚性与沉降时的增稠**；驱动项 $\mathbf{v}_{in},\mathbf{g}$ 给出到达时的**动量**

### 运行时（Fig. 28）

| 阶段 | 耗时 |
|---|---|
| 预处理（几何去噪/致密化/并集） | **< 1 分钟** |
| 体积速度构建 | **< 1 分钟** |
| 光流计算 + 边界检测（地形提取、壁面函数） | 略长 |
| **可微参数优化** | **占总成本 > 94%** |

> 优化成本主要随两个因素缩放：**输入视频帧数**（决定训练集大小与窗口长度 $N$）与**网格分辨率**（影响模拟步成本与压力求解）。
> 对稳态流动场景，**更长的优化窗口不会成比例增加成本**（动力学收敛很快）；高动态场景则需要更细网格与更短时间步。
> **参数优化完成后，前向 APIC 重模拟以交互速率运行**（GPU 并行）。

### 编辑能力

用户可修改流体材料（密度/粘度）、加入交互固体、延展模拟时长、改变视角 —— **全部通过用更新后的参数或场景几何重新模拟自动实现**（Fig. 1、Fig. 26）。红色河流资产被集成到含建筑与桥梁的数字场景中，并修改外观、粘度、重力以适配不同视觉风格。

## 局限性

1. **不支持大相机运动**（需要 3D 配准与自运动补偿）
2. **完全没有可测运动的场景**：主流插值无从延展（但无可见运动的场景也限制了「结果能有多离谱」）
3. **飞溅与泡沫**涉及**超出单相网格的空气夹带** → 需要更细分辨率 + 界面处的 **volume-of-fluid** 处理
4. **亚网格细节不可恢复**：当前分辨率下能恢复大涡结构，**子网格细节不能**；而细化代价高（模拟与压力求解随单元数缩放）
5. **外观不如运动可靠**：反射/透明流体**几乎没有可跟踪的纹理**；且流体是开放的、大部分在内部 → 新的与新暴露的粒子**没有观测颜色** → **统一纹理是务实选择**。通用学习估计器帮不上忙（训练数据几乎没有流体）→ **需要领域专用模型**
6. **参数不具备唯一可辨识性**：几何是**生成**而非度量重建，因此 $\Theta$ 是**重建场景的有效模拟参数**，而非真实流体的唯一可辨识常数
7. **训练成本高**：8×H100 级别的论文级算力（本文未给具体数字，但 PeRCNN 80 层 × 25 步 × N 窗口的开销可观）
8. 流水线是**分阶段**的，后一阶段依赖前一阶段（好处是可逐阶段改进，坏处是误差会传播）

## 实现建议

- **实现难度**: **高**。四个阶段各自都不简单：① 生成式 3DGS + 跨帧几何一致化；② 光流 + 主流引导 + 2D 散度约束迭代求解；③ 壁面函数 + 无压力场的散度自由投影；④ PeRCNN 可微压力求解 + APIC 可微演化
- **预期性能**:
  - 初始化鲁棒性：参数初值扫过 **3 个数量级**均收敛到同一损失
  - 速度精度：优化后场比优化前**更平滑、更物理一致**（合成场景验证）
  - 运行时：**优化占 >94% 成本**；前向重模拟**交互速率**
  - 消融：去掉运动检测 → 相关性跌至 0.15；去掉体积填充 → 未见内部跌至 0.06
- **适用场景**:
  - ✅ **从单视图视频生成「可模拟」的流体资产**（游戏/虚拟制片资产生产）
  - ✅ 需要**可编辑、可交互、可延展**的流体（重建式方法无法提供）
  - ✅ 粘性流体（蜂蜜、熔岩）—— 材料参数 $\rho,\nu$ 起主导作用，收敛最稳
  - ✅ 主流明确的河道/管道流动（主流插值提供强先验）
  - ⚠️ **飞溅/泡沫**、**反射/透明流体**（外观不可靠）—— **不适用**
  - ⚠️ **大相机运动**的视频 —— **不适用**
  - ⚠️ 无 GPU 算力预算 —— PeRCNN 成本高
