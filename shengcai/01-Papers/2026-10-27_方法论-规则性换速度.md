# CVTSplat — 空间离散化的"规则性换速度"范式

> 本条目是 [[2026-10-27_CVTSplat-Adaptive-Centroidal-Voronoi-Tessellation]] 的**方法论提炼**，用于跨论文索引。

## 一句话

**主动约束表示的规则性（近质心 Voronoi、固定 32 邻居、piecewise-linear SDF），换取整条 GPU 管线的可专门化空间。**

## 三个可迁移的工程手法

| 手法 | 做法 | 收益 |
|------|------|------|
| **约束形状换专门化** | 近质心（near-centroidal）分布 → 只需 32 近邻、单元小而近各向同性 → 可写专门 kernel | Voronoi 构造快 5–10× |
| **闭式解换离散化** | 每单元内用**仿射** SDF（而非插值） → 体积积分有闭式解 | 免去四面体网格构建与逐样本插值 |
| **并行 + 早退协议** | chunked rasterizer + 逐 tile atomic CAS 维护 $T_c/D_c$ | 端到端 280s → 147s（≈2×） |

## 关键公式（速查）

```math
\mathcal{L}_{\mathrm{CVT}} = \sum_i \frac{1}{s_g(r_i)}\left\|x_i - s_g(\bar x_i - \beta_i r_i n_i)\right\|_2^2,
\qquad \beta_i = a\tanh\!\big(\hat f_i/(2b)\big)
```
```math
C_i = \Big\{x:\;(x-x_i)\cdot(x_j-x_i) \le \tfrac12\|x_j-x_i\|_2^2,\ \forall j\neq i\Big\}
\quad\text{（邻接测试 = 2D LP 可行性，Seidel 增量算法）}
```
```math
C = \sum_i c_i(1-\alpha_i)\prod_{j<i}\alpha_j,
\qquad \alpha_i = \frac{1+e^{-s\hat f(t_i^-)}}{1+e^{-s\hat f(t_i^+)}}
```
