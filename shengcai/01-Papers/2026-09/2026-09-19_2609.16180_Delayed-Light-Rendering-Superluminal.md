# Delayed-Light Rendering for Superluminal Objects

## 元信息

## 核心贡献

1. **超光速物体实时渲染**：提出在非相对论设定下对有限信号速度场景的实时渲染方法
2. **精确图像枚举**：不近似超光速物体的多种同时图像，通过对发射条件求根精确计算每一点的效果
3. **图像对创生与湮灭**：描述图像对在焦散闪光中创建和湮灭的过程，部分分支在时间中向后播放
4. **已部署于RTS游戏**：方法已部署在发布的实时策略游戏中，实现交互速率运行

## 技术方案

### 核心思想
信号速度 c 是成像信号的性质（非因果速度极限），物体可超光速运动。

### 关键算法
```
发射条件 → 二次方程判别式 → 检测图像对创生
分段线性历史 → 每段求根 → 分类播放方向/速率/亮度
```

### 渲染特性
- **延迟景观**：观察事件的后向光锥上包络
- **单调发射钳制**：保证画面从不倒退到比已显示更旧的图像
- **逐顶点求解**：剪切跨延迟梯度的物体

## 实现细节

- 平面导出和实现（发射条件与维度无关）
- 3D 可见性/遮挡问题超出范围
- 优化实现交互速率
- 参考实现测量算法性能

## 局限性

- 仅平面情况：发射条件和每段求解是范数条件，与维度无关
- 3D 可见性和遮挡问题待解决
- 移动观察者存在一个近似
