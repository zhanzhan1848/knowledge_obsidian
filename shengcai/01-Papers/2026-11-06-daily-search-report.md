### 🥇 1. HIBS — 用 beta 核当几何置信度旋钮
**[[2026-11-06_HIBS-Hierarchical-Incremental-Beta-Splatting]]** · arXiv 2611.08288 · **WACV 2027**

> **在线重建的真正约束不是算力，是「只生成一次、只优化几十步」。** 本文不改优化策略，而是改**基元本身**：把高斯换成 **beta 核**，用形状参数 $\beta$ 当**几何承诺度**的连续旋钮——**有证据的地方生成硬表面片，没证据的地方生成软探针**。

**核心技术点**：

$$\alpha = o\,(1-x)^{\beta(b)},\quad \beta(b)=4e^{b},\quad x=r^2/9\ \text{(支撑}\ r\le 3)$$

- $b=0$（$\beta{=}4$）→ 类高斯；$\beta$ 减小 → **平顶近不透明 solid surfel**；$\beta$ 增大 → 软 blob
- **置信度必须来自几何证据，不能是光度证据**：紧凑近不透明的基元若深度错，**会阻断透射率并抑制其后的梯度**；光度误差低也不保证几何对（基线小的时候许多深度同样好地解释视图）

**双几何线索交叉验证**：

```math
c_z=\operatorname{clamp}\!\left(\frac{B/z}{\theta_0},0,1\right),\ \theta_0=2^\circ
```

```math
c_{\mathrm{mvs}}=\operatorname{clamp}\!\left(1-\frac{|i_{\mathrm{mvs}}-i_{\mathrm{mono}}|}{r_{\mathrm{mvs}}},0,1\right)
```

$$c=(c_{\mathrm{mvs}}\cdot c_z)^{\gamma}\ (\gamma=4)\ \Rightarrow\ o_{\mathrm{spawn}}=o_0+(o_1-o_0)c,\quad \beta_{\mathrm{spawn}}=\beta_{\mathrm{soft}}-(\beta_{\mathrm{soft}}-\beta_{\mathrm{solid}})c$$

**闭式矩匹配（保留实体度的合并）**：

$$\xi(\beta)=\frac{4.5}{\beta+2.5},\qquad \kappa(\beta)=\frac{15(\beta+2.5)}{\beta+3.5},\qquad \beta=\frac{15}{15-\kappa}-3.5$$

> **KL 合并在有界核上不适用**——父支撑外任何非零质量 → KL 发散。

**beta 专属 tile 剔除界（正确性修复，不只是加速）**：

$$x_{\text{cut}}=\max\!\left(0,1-(255o)^{-1/\beta(b)}\right)$$

> **标准 3DGS 高斯阈值对 solid、低不透明度的 beta 核不充分，会丢掉含非零贡献的 tile** → 这是 **bug 而非优化**。

**主结果**：

| 数据集 | i3DGS | **HIBS** |
|--------|-------|---------|
| MipNeRF360 (otf) | 26.66 dB / 2:09 | **27.47 dB / 1:18** |
| StaticHikes | 22.17 dB / 2:53 | **22.49 dB / 2:02** |
| TUM | 25.36 dB / 1:24 | **25.94 dB / 1:44（LongSplat PSNR 略高但慢 50×）** |
| CityWalk（大场景） | 22.03 dB / 45:20 | **25.81 dB** |

**消融（九个 otf 场景）**：完整 25.30 dB → 去置信度 25.14 → 去固化 25.15 → 去重定位 25.09 → 去正则 24.98 → i3DGS 24.73。核消融：i3DGS 24.73 → 高斯 25.09 → beta 完整 **25.30**（**+0.2 dB 且更快**）。融合光栅器 **−16% 时间**（Garden 287→170 ms）。**去矩合并 → CityWalk −2.27 dB**（多层场景收益最大）。
**相关度**: ⭐⭐⭐⭐⭐ 在线重建 / 光栅化 / 置信度建模

### 🥈 2. 广义神经纹理上采样 — 把 MLP 塞进纹理采样器
**[[2026-11-06_Neural-Texture-Upscaling-Generalized-MLP]]** · arXiv 2611.07289 · **TOG（AMD）**

> **离线神经上采样太贵、NTC 要逐资产训练且 GPU 执行发散。** 本文训练**一个泛化 MLP** 集成进**纹理采样阶段** → **不改纹理数据、不改资产管线、不逐资产训练**，且共享权重 → **GPU 永不发散**。

- **位置**：直接**替换现有游戏的纹理采样器**即可接入，存量资产零改动
- **架构**：$n{=}1,m{=}1$ → $3\times3\times3$ 输入、$2\times2\times3$ 输出；$d{=}256$、$L{=}4$ 残差块；**解析双线性 + 学习残差**（双线性给低频，MLP 只学高频 → 学习问题被简化、收敛更快）；残差块后把值钳制 ≤ 1
- **训练**：Adam lr $10^{-3}$、**L1 损失**（比 MSE 更锐利）、可选 cosine 退火到 $10^{-6}$

**LPIPS 对比（越低越好）**：

| 数据集/类别 | 本文 | bilinear | bicubic | Lanczos | PFT |
|----------|------|----------|---------|---------|-----|
| Poly Haven Diffuse | **0.239** | 0.396 | 0.369 | 0.383 | 0.224 |
| Hangar Diffuse | **0.075** | 0.193 | 0.156 | 0.157 | 0.043 |
| Hangar Normal | **0.023** | 0.088 | 0.067 | 0.065 | 0.014 |
| Museum Diffuse | **0.052** | 0.142 | 0.107 | 0.107 | 0.048 |

**渲染端 FLIP**：Hangar Cam1 **0.0519** vs bicubic 0.0573 / bilinear 0.0626（差异在**光泽反射**处最明显）

**方法论亮点（重要）**：
> **PSNR/SSIM 不适合评价纹理上采样** —— 上采样结果不保证逐像素准确，而 PSNR 只看逐像素误差。论文明确指出**很多情况下模糊纹理的 PSNR 高于锐利纹理但视觉上更差** → **以 LPIPS 为主指标**。

**两个实用结论**：
1. **隐藏维 $d\ge64$ 后收益饱和**（$d{=}8$ 反而优于 $32/64$ → 明显过拟合）
2. **漫反射反射的顶点可直接跳过 MLP** —— 因为输入是 texel 本身；**NTC 做不到**（latent grid 必须先解码）。这是论文写了但没做的免费优化

**相关度**: ⭐⭐⭐⭐ PBR / 纹理压缩 / 实时渲染管线 / GPU 发散问题

### 🥉 3. T²-Splat — 拓扑自适应与外观精修解耦
**[[2026-11-06_T2-Splat-Adaptive-Topology-Mesh-Splatting]]** · arXiv 2611.06974 · **NeurIPS 2026**

> **三角形泼溅接回了传统图形管线，但往往需要过量细分才能保住外观细节。** Stage I 动态分配三角形预算，Stage II 在**固定网格**上注入高频外观。

**可微光栅化的收敛设计（工程价值最高的一点）**：

$$I(p)=\left(\operatorname{ReLU}\!\left(\frac{\phi(p)}{\phi(s)}\right)\right)^{\sigma},\qquad \alpha_i=\alpha_{\text{floor}}+(1-\alpha_{\text{floor}})\operatorname{sigm}(a_i)$$

> 训练时 $\sigma$ 从 **1.0**（平滑梯度、利于梯度流）**线性退火到 0.0001**，同时 $\alpha_{\text{floor}}\to1$ → **平滑收敛到实心不透明三角形**。
> 末端简化为 $C=c_{T_n}(p,d)I(p)$，**每像素只需一次求值** → **over-drawing 归零**，显著加速，**原生兼容标准游戏引擎**。

**两阶段**：
- **Stage I**：Safe RDT（按到输入汤的距离 / 无符号法向一致性 / 三角形质量过滤排序，贪心生长出朝向一致表面，保证无重复面、每边至多两面、每顶点单一连通面扇；**只改连接与绕序，保留顶点属性与优化器状态**）+ **DTE**（**QEM 边折叠**处理平坦区 + **梯度驱动顶点分裂**处理复杂区 + **优化器状态拼接**）
- **Stage II**：**零初始化逐面残差 Mip-texture** + 尺度自适应过滤 + 三线性采样 → **把高频外观注入而不扰动已优化几何**

**主结果**：

| 指标 | MeshSplatting | **T²-Splat** |
|------|---------------|-------------|
| Mip-NeRF360 PSNR | — | **+0.71 dB** |
| OpenGL 渲染（Garden, M3 MacBook） | 126 FPS | **236 FPS（1.87×）** |
| 网格文件大小 | 152 MB | **62 MB（−59%）** |
| 50% 面预算 | 7.3M 面 | **1.4M 面且三指标全优** |
| 10% 面预算 | — | 0.3M 面，PSNR 23.93 |

**消融（差值口径）**：DTE 单独 **+0.31 dB**（+14 min）；$4^2$ 精修 **+0.31 dB**；完整配置 **+0.83 dB**。$8^2$ vs $4^2$ 仅 +0.06 dB → **$4^2$ 是性价比拐点**。对照：GOF 需 **92.1M** 面、MiLo 需 **14.9M** 面才保真度。
**相关度**: ⭐⭐⭐⭐ 网格泼溅 / 可微光栅化 / 游戏引擎接入

### 4. P-MGS — 感知优先于几何
**[[2026-11-06_P-MGS-Perceptual-Gaussian-Allocation]]** · arXiv 2611.07979

> **现有网格高斯方法给每面分配固定数量高斯 = 误把「网格细分密度」当「表达容量需求」。**

**需求分数的推导（干净）**：局部线性信号下，**常值 cell 的积分平方误差** ∝ 梯度能量 × cell 面积² → 跨视图平均得

$$Q_f=\frac{1}{V}\sum_{v=1}^{V}A_{fv}^{2}\bar\rho_{fv}$$

**分配问题（带逐视图负载约束）**：

$$\min_{\mathbf{n}}\mathcal{E}(\mathbf{n})=\sum_{f\in\mathcal{P}}\frac{Q_f}{n_f}\quad\text{s.t.}\ \sum_fn_f=B,\ \ell_f\le n_f\le u_f,\ \sum_fn_fT_{fv}\le W_v\ \forall v$$

> **逐视图负载约束很实用**：投影足迹不同 → 同样的高斯总数在不同视图上负载不同，只看总容量会牺牲某些视图。用**拉格朗日负载定价** $S_f(k)=Q_f/k-\sum_v\lambda_vT_{fv}/W_v$ 贪心求解。

**错配的量化证据（最有说服力的部分）**：

| 场景 | GaMeS(Mesh-Init) vs 3DGS |
|------|--------------------------|
| Chair | **−5.12 dB** |
| Hotdog | **−4.29 dB** |
| Lego | −2.58 dB（**尽管用了 10,176K 高斯 = 3DGS 的 8.5×**） |
| Drums / Ship | −0.82 / −1.57 dB（几何多、外观简单 → 差距小） |

> **Lego 用 8.5× 高斯仍低 2.58 dB → 问题在分配方式，不在容量。**

**主结果**：NeRF-Synthetic **34.00 dB / 545K 高斯**（vs Mani-GS +0.75 dB 且高斯少 **79.7%**）；DTU **32.36 dB / 191K**（GaMeS△ 30.91/603K、Mani-GS 30.79/316K）→ **全指标最优且高斯数最少**
**相关度**: ⭐⭐⭐⭐ 网格高斯 / 可编辑场景

### 5. EDGAR — 用合成失败驱动扩散精修高斯化身
**[[2026-11-06_EDGAR-Diffusion-Gaussian-Avatar-Refinement]]** · arXiv 2611.07909 · **TOG（KAIST）· 代码开源**

> **单目训练的化身天然欠约束，但 SDEdit 式精修「没有关于化身该长什么样的知识」→ 保不住身份。** EDGAR 用**合成的失败**造配对监督，再把 2D 精修**蒸馏回 3D**。

- **EDGAR-SET**：三元组 $(I_f, I_{gt}, I_r)$，**400K 高分辨率图 / 数千身份**；真实源 NeRSemble + RGBAvatar，合成源 CAFCA + 原始 3DGS；视角数分组 1 / 2–4 / ≥5 占 **23% / 51% / 26%**
- **可恢复性过滤**：用 LPIPS 丢弃差异过大的对 → **明确划定「可恢复的外观伪影」这一适用域**
- **身份条件化**：$I_r$ 过 **Sapiens** → 特征投影注入 cross-attention 的 **K/V**，扩散特征作 **Q**
- **单步骨干**：**SD-Turbo**，冻结 residual block 与 cross-attention（负责 timestep/prompt 注入），**只训 self-attention**（负责像素间关系）+ **LoRA 零初始化残差解码器**
- **MoE** 应对退化类型/严重程度多样性；**表达式一致性损失**保面部动态
- **3D 蒸馏**：精修后多视角渲染作**伪目标**优化单个高斯化身 → **推理期零扩散开销，保持 Base 速率**

**关键证据 —— SDEdit 基线反而更差**：

| 方法（CAP4D, 1 view） | CLIP↑ | L1↓ | LPIPS↓ | PSNR↑ |
|---------------------|-------|------|--------|--------|
| CAP4D (Base) | **0.9369** | 0.0584 | **0.2133** | 17.57 |
| +SDEdit | 0.9078（**更低**） | 0.0581 | 0.2728（**更差**） | 17.77 |

**用户研究选择率**：vs CAP4D 偏好 **96.67%**；vs CAP4D+SDEdit **98.0%**。RGBAvatar 上 Large pose L1 **0.0889→0.0612**、LPIPS **0.1785→0.1440**。

**诚实之处**：CAP4D 上 L1 略退化；**GaussianAvatars 的 tWE 反而上升** → 空间保真度提升**不一定**转化为时序稳定性
**相关度**: ⭐⭐⭐⭐ 数字人 / 扩散精修 / 数据工程

### 6. 4DPS — 毫米波雷达微多普勒可微渲染
**[[2026-11-06_4DPS-mmWave-Radar-Micro-Doppler-Rendering]]** · arXiv 2611.08342

> **现有可微雷达渲染器全假设静态、每点每帧只评估一个相位 → 没有慢时间轴 → 无从定义速度。** 本文把**速度作为可微参数**。

- 点直接泼溅进 **range + Doppler bin**（而非逐 chirp 重渲染）→ **成本不再随 chirp 数线性增长**，首次实现数据集规模拟合
- **输出原始复数回波** → 复用**完全相同**的 DSP → 得到任意表示（range profile / micro-Doppler）→ 训练任意下游模型
- **架构分工**：同步相机定几何，渲染器定**毫米波物理属性**（材质 ITU-R P.2040 + 法线 + 速度）
- **效率**：单 H100，HuPR **5.7 min/序列**、RT-Pose 12.9 min

| 指标 | HuPR | RT-Pose |
|------|------|---------|
| range–azimuth 相关性 | 0.940 | 0.830 |
| range–Doppler | 0.829 | 0.695 |
| **micro-Doppler** | **0.988** | **0.966** |

**下游 sim2real**：RT-Pose 姿态模型在真实数据上 **21.9 cm MPJPE**（真实训练 16.7 / RF-Genesis **127.6**）→ 误差降约 **5.8×**。且论文展示**渲染训练与真实训练学到几乎相同的特征** → 证明差距是**数据覆盖**问题而非表示失配。
**相关度**: ⭐⭐⭐ 传感器可微渲染（跨领域架构价值高）

## 四、技术趋势观察

### 趋势 1：**「核/基元本身」正在成为主要创新载体**
- **HIBS**：把高斯换成 beta 核，让**形状参数**承载**几何置信度**语义
- **T²-Splat**：把三角形的 $\sigma$ 平滑度与不透明度**退火**到标准实心三角形
- 共同点：**不是改优化策略，而是改基元的表达能力与语义承载**

→ **可推广的判据**：当「优化预算不足」是主要瓶颈时，**给基元更多语义**比「调优化器」更有效。

### 趋势 2：**「几何证据 vs 光度证据」的分离正在成为显式设计原则**
- **HIBS**：置信度必须来自**多视图深度一致性 + 三角化角**的**交叉验证**，明确指出「光度误差低不保证几何正确」
- **P-MGS**：需求分数来自**梯度能量 × 可见覆盖**，而非网格细分密度
- **4DPS**：相机只定几何，**毫米波属性（材质/法线/速度）单独拟合**
- 共同点：**用独立的、可解释的几何量来初始化/约束那些「无法靠优化恢复」的东西**

→ 这与 11-05 观察到的「**显式告知可解析计算的低阶量**」是同一趋势的深化：**不仅告知，还要交叉验证**。

### 趋势 3：**「通用模型 + 无发散执行」正在击败「逐资产最优」**
- **神经纹理上采样**：泛化 MLP → **GPU 不发散 + 零管线改动**；代价是压缩率不如 NTC
- **EDGAR**：泛化精修器 → 作用于**任意**高斯化身；且**蒸馏回 3D** → 推理期零开销
- 共同点：**用一个通用模型覆盖异构资产**，把「逐资产优化」的收益让渡给**部署的简单性**
→ 这是**从论文指标到产品落地**的典型权衡，值得在自研方案里认真评估。

### 趋势 4：**「训练期可微 / 推理期退化」是神经方法进实时管线的通用套路**
- **T²-Splat**：$\sigma$ 退火 → 末端成为**标准实心三角形**，over-drawing 归零，**原生兼容游戏引擎**
- **EDGAR**：扩散只在优化期用 → 蒸馏回 3D，**推理期零扩散开销**
- **HIBS**：融合光栅器 + 闭式矩合并 → **显存/时间有界**
→ **三篇不同领域的工作用了同一个架构模式**，这是本轮最值得内化的方法论。

### 趋势 5：**评测方法论本身持续成为一等贡献**
- **神经纹理上采样**：明确论证 **PSNR 会偏好模糊纹理** → 改用 LPIPS 为主指标
- **HIBS**：给出**「重建过程中」的质量曲线**（而非只报最终结果）+ 逐视角「注册后是否继续改善」的对角线图 → 证明**无灾难性遗忘**
- **EDGAR**：如实报告 **tWE 上升**、CAP4D 上 L1 退化 → 明确「空间保真度 ≠ 时序稳定性」
- **P-MGS**：给出**错配的量化证据**（Lego 8.5× 高斯仍低 2.58 dB）→ 把「直觉」变成可验证命题

### 趋势 6：**网格 + 高斯/泼溅的融合仍是热点，且出现了两条互补路线**
- **T²-Splat**（NeurIPS 2026）：**三角形**基元 + 残差 Mip-texture + 拓扑自适应 → 目标是把结果**接回传统图形管线**
- **P-MGS**：**高斯**基元 + 事后绑定 + 感知分配 → 目标是**保住网格可编辑性**
- 共同洞察：**网格提供拓扑与可编辑性，高斯/纹理提供表达力**，难点全在**两者的分配与解耦**
