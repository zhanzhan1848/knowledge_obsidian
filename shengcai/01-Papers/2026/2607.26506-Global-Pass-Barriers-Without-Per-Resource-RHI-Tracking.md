## 核心贡献
1. 研究显式图形 API 中的全局 pass 边界 barrier 放置策略
2. 对比 Blade（Vulkan 图像保持 GENERAL，无逐资源状态跟踪）和 wgpu
3. 在 6 个 GPU（4 个厂商）上进行跨供应商测量，包括 Apple/Metal 探索性结果

## 技术方案

### 背景
- 显式图形 API 暴露内存依赖、逐资源访问、图像布局
- wgpu 重建和验证状态；Blade 保持 Vulkan 图像为 GENERAL，无逐资源跟踪

### 关键发现
- 移除 16 个独立计算通道中 15 个冗余 barrier：
  - RTX 5070 GPU 占用减少 29.3%
  - RX 7900 XT 减少 32.3%
- 独立渲染 pass 减少 32.4% (RTX) 和 7.3% (AMD)
- 从 pass 类型推导全局 barrier 范围（无资源跟踪）节省 5.0% (NVIDIA) 和 6.7% (AMD)

### Blade 方向
- 轻量级聚合 pass 类型状态，无跟踪的 RHI
- 上游渲染图选择全局依赖切割
- 别名、跨队列使用、异常布局、任意逐资源 DAG 边缘由资源感知引擎处理

## 实验数据
- 6 GPU 测试：4 厂商
- RADV 源码显示命令数不能预测成本
- 持久 GENERAL 在测量 RDNA 条件下保留 DCC 但禁用 FMASK

## 可行性分析
- 实现难度：高（涉及 RHI 设计和渲染图优化）
- 性能预期：显著 GPU 占用减少
- 适用场景：游戏引擎、实时渲染系统底层优化
