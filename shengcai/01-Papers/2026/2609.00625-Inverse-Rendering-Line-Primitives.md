## 核心贡献
1. **逆渲染方法**：用显式线段重建模糊几何（头发、毛皮、纤维、纺织品）
2. **线段可微光栅器**：subpixel grid 上渲染线段再现半透明外观
3. **随机可微光栅器**：产生关于顶点位置、属性和离散连通性的信息性梯度
4. 完全基于显式几何，与标准图形管线无缝集成

## 技术方案

### 问题背景
真实世界物体（头发、毛皮、纤维、纺织品）具有模糊、各向异性结构，难以高效实时可视化。

现有 radiance field 方法（如 3DGS）使用半透明体积图元，限制了对标准深度测试光栅化、反射建模和物理仿真的兼容性。

### 核心方法
1. **线段作为图元**：用显式线段替代体积 primitives
2. **Subpixel Rasterization**：线段在 subpixel grid 上光栅化以实现反锯齿半透明外观
3. **随机可微光栅器**：优化众多线段图元以匹配目标图像

关键挑战：优化线段 primitives 面临梯度问题——需要关于顶点位置、属性和离散连通性的信息性梯度。

### 技术细节
```
线段渲染：每条线段贡献覆盖区域内像素
梯度：∂L/∂vertex_position 提供优化方向
连通性梯度：支持线段连接的动态变化
```

## 实验结论
- 合成和真实数据集验证
- 捕捉模糊边界优于 surface-based 方法
- 与体积表示质量相当
- 支持跨平台渲染、各种着色模型和物理仿真

## 局限性
- 优化收敛可能慢于体积方法
- 复杂场景需要大量线段

## 可行性分析
- 实现难度：高（需可微光栅器）
- 性能预期：实时光栅化
- 适用场景：毛发/头发渲染、织物仿真、纤维可视化
