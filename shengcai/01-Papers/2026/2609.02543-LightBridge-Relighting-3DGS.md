## 核心贡献
1. **LightBridge**：前馈生成式框架，单次 pass 完成完整 3DGS 资产的**可控重照明**
2. **Multi-Illumination Relighting Dataset**：大规模配对源-目标观测数据集
3. **Latent Bridge Relighting Diffusion (LBRD)**：在 latent space 中建模源到目标的光传输，实现 2D visual tokens 单步提取（无需迭代扩散采样）
4. **Gaussian Propagation Transformer (GPT)**：点 transformer + 稀疏 image-to-point 自注意力 + point-to-image 交叉注意力

## 技术方案

### 问题背景
- 3DGS 实现高质量实时新视角合成，但资产光照被"烘焙"，难以重照明
- 逆渲染方法为每个场景优化简化反射/光照模型，效率和质量受限
- 现有生成式方法需要额外的 per-scene 优化阶段

### 核心方法
1. **前馈 relighting**：无需 per-scene 优化，单次前馈预测完整重照明 3DGS 资产

2. **LBRD 模型**：
   - 将重照明建模为 latent space 中的源到目标传输
   - 单步提取 2D visual tokens，无需迭代扩散采样

3. **Gaussian Propagation Transformer**：
   - Point transformer 处理 3DGS 点云
   - 稀疏 image-to-point 自注意力
   - Point-to-image 交叉注意力
   - 避免对所有 image 和 Gaussian tokens 的全注意力

### 关键设计
```
输入: 源图像 + 目标光照描述
     ↓
LBRD: Latent space 传输
     ↓
GPT: 点云注意力传播
     ↓
输出: 完整重照明 3DGS 资产
```

## 实验结论
- 竞争性的重照明质量
- 高效单次 pass 预测
- 无需场景特定优化

## 局限性
- 需要大规模配对数据集
- 生成式方法可能存在 hallucination 风险

## 可行性分析
- 实现难度：高（需要 diffusion model + transformer 训练）
- 性能预期：单次前馈，效率高
- 适用场景：电影制作、游戏资产重照明、AR/VR 场景适配
