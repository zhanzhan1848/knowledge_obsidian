## 核心贡献

> 用**文本条件**预测**空间变化**的物理参数（杨氏模量 E、泊松比 ν、密度 ρ），通过 **FiLM 式跨模态调制** + **体素场表示**，在 Text2PhyX 上把平均物理误差降到 **0.059**（Pixie 最好 0.078、NeRF2Physics 0.841），同时 PSNR 达 **26.012**（比 Pixie 高约 2.6 dB）。

1. **解决视觉歧义**：纯视觉输入无法区分"橡胶的刚度"与"橡胶的外观"——本文用**文本作为条件信号**注入语义先验，把这一固有歧义显式化并消解。
2. **体素场形式化**：把物理参数预测放在体素场中，保证与 **mesh / point cloud / Gaussian splatting** 等多种 3D 表示的兼容性（同一参数场可喂给不同求解器）。
3. **可自动扩展的数据管线**：**Text2PhyX**（1,700 资产 × 8 种文本条件变体），通过"部件级可控数据生成"解决"文本条件训练数据不可得"的根本障碍。

## 技术方案

### 核心思想

4D 物理模拟需要与材料属性一致的参数赋值。已有路线各有缺陷：

- **逐场景优化**（PhysDreamer、DreamPhysics）：计算代价高
- **纯视觉前馈预测**（Pixie、VoMP）：**固有歧义**——外观相同但物理不同的物体（如新鲜水果 vs 塑料复制品、橡胶 vs 硬木树干）无法区分
- **VLM 直接查询**（NeRF2Physics、Gemini）：依赖模型内部物理知识，**未校准**，且存在幻觉

**本文策略**：**先写文本、再据文赋参**（generate text first to guide the property assignment），并把参数预测建模为**体素场回归**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **3D OpenCLIP 体素** | 提取 3D OpenCLIP 体素表示；**用体渲染显式处理自遮挡**（比 VoMP 的朴素多视角平均更严谨） |
| **内部体素判定** | 向无穷远投射多条射线，若所有射线的表面交点计数**一致为奇数**则判定为内部体素 → 稳健处理复杂凹陷 |
| **层级分类填充** | Condition 1 做粗略包围，Condition 2 做细分（补充材料） |
| **FiLM 跨模态调制** | 文本经**冻结的 OpenCLIP 文本编码器**得稠密语义嵌入 $e_{text}$；因 3D 视觉体素与文本嵌入**同源于 OpenCLIP 潜空间**，天然对齐，**无需跨模态投影** |
| **多层调制** | $e_{text}$ 过 MLP 预测逐层缩放 $\gamma_i$ 与偏移 $\beta_i$，**交错**在 3D U-Net 各层做通道级仿射调制 |
| **零初始化残差头** | 保证网络从恒等映射起步，训练稳定 |
| **体素场回归** | 三个性质 $K = \{E, \nu, \rho\}$ 在每个占用体素上回归 |
| **物理损失** | 仅在占用体素集合 $G$ 上计算监督 |
| **多采样部件分割** | 每资产渲染 **15 张上半球视图** → VLM 生成部件关键词 → 与 OpenCLIP 体素余弦相似度分割 → **重复 5 次**并由 VLM 选出最佳 |
| **权威数据库接地** | 物理属性查询**锚定到权威在线数据库**（而非仅靠 VLM 内部知识），抑制幻觉 |

### 关键公式

```math
% FiLM 跨模态调制（核心）
F'_i = γ_i(e_text) · F_i + β_i(e_text)
（F_i = 3D U-Net 第 i 层中间体素特征图；γ, β 由 e_text 经逐层 MLP 预测）

% 物理损失（仅在占用体素上监督）
L_phys = (1/N_occ) Σ_{p∈G} Σ_{k∈K} || k̂(p) - k_GT(p) ||_2^2
K = {E, ν, ρ}  （杨氏模量、泊松比、密度）

% 评估：E 与 ρ 在 log 空间（log10）计算误差
% 理由：E 跨材料跨多个数量级，原始绝对误差会被刚性材料主导，
%        从而低估"小绝对变化即可显著改变动力学"的软材料

% 内部体素判定（奇偶规则，稳健处理凹陷）
对每条射向无穷远的射线统计表面交点数：
  若所有射线的交点数一致为奇数 → 该体素为内部

% ABO-500 的 MnRE（避免系统性高/低估偏差，对离群点不敏感）
MnRE = (1/N) Σ_{i=1}^{N} min( y_i/ŷ_i , ŷ_i/y_i )
```

## 实验结论

- **数据集**: **Text2PhyX**（自建，1,700 个 3D 资产，每个配 **8 种**文本条件物理变体；1,575 训练 / 125 测试）；**ABO-500**（真实世界质量估计，OOD 泛化测试）
- **基线**: DreamPhysics、OmniPhysGS、NeRF2Physics、Gemini（5 次查询取平均）、Pixie（重训以公平对比）
- **下游渲染**: 用 **PhysGaussian**（GS）与 **Isaac Sim**（mesh）渲染预测属性后的模拟结果，再算 PSNR/SSIM/LPIPS

## 局限性

- **VLM 依赖**：数据生成仍依赖 Gemini 做部件分割与属性检索；虽用多采样 + 数据库接地缓解，但**引入外部模型的不确定性**
- **"体素场"的表达瓶颈**：物理参数在体素分辨率上表达，无法表达比体素更细的空间变化；且**体素分辨率直接决定存储与推理成本**
- **体渲染用于 OpenCLIP 体素提取**本身有误差（多视角自遮挡处理的残留误差）
- **评估依赖下游模拟渲染**：PSNR/SSIM/LPIPS 通过 PhysGaussian / Isaac Sim 的模拟渲染间接测得，**引入了模拟器差异的噪声**
- **数据集为合成资产**：1,700 个资产来自 Objaverse 等来源，类别分布偏"物体"而非"场景"；ABO-500 提供了部分 OOD 验证，但覆盖有限
- **仅支持 3 个物理属性**：E、ν、ρ，未覆盖黏塑性、断裂、各向异性等
- **文本条件的取值空间有限**：每个资产 8 种变体，未验证细粒度连续控制
- **预印本 / SIGGRAPH 2026 格式但未见接收声明**

## 实现建议

- **实现难度**: **中**（网络结构简单：3D U-Net + FiLM；但**数据生成管线成本高**——1,700 资产 × 8 变体，需 VLM 多轮调用 + 数据库查询）
- **预期性能**: Text2PhyX 平均物理误差 **0.059**、PSNR **26.012**；ABO-500 ADE **9.433**（比 NeRF2Physics 低 20.2%）
- **适用场景**: 需要**可语义控制物理属性**的下游任务——机器人操作策略训练（可按文本枚举"合理物理变体"提升鲁棒性）、仿真资产快速赋参、可微物理的前置模块
- **与渲染的交叉点**（**本库关注重点**）：
  1. **体素场形式化是最可迁移的部分**——把物理/材质属性放在体素场中，可直接喂给 PhysGaussian 等 GS 物理模拟器、或转成 mesh 属性 → **参数场与表示解耦**这一思路同样适用于 **PBR 材质场**、**光照/BRDF 场**
  2. **FiLM 多层调制是通用的文本条件注入范式**——本库若做"文本驱动材质/着色"，可直接复用（零初始化残差头保证训练稳定）
  3. **log 空间评估的必要性**：E 与 ρ 跨数量级，评估必须用 log10 空间；**本库做材质/PBR 误差对比时同样适用**
  4. **"先写文本再赋参"** —— 对本库的启示：文本条件能消解视觉歧义，这在 **inverse rendering / 材质反推** 中同样成立（例如"木门"vs"塑料门"外观近似但 BRDF 差异巨大）
- **优先级**: **中**（主线在物理仿真而非渲染，但"体素场 + FiLM 文本调制"两个技术点对渲染有直接迁移价值）
