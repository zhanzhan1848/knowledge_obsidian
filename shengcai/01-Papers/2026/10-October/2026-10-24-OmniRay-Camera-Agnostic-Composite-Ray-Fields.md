## 核心贡献

> 提出**复合 ray field（composite ray field）**：把相机几何的复杂度视为**层级**，用「单调径向基 + 球谐残差 + 自由形式残差」三级组合表示每像素的视线方向，在**训练时完全未见**的 GoPro 鱼眼与 Nayar 猫眼反射相机上取得 SOTA，**推理时无需任何相机内参或相机类型输入**。

1. **层级 ray 表示**：三个分量在球面上以**连续旋转**复合（指数映射），而非共享单一固定基——解决了 camera-aware 模型用单基同时表达"整体投影"与"精细变化"的表达力瓶颈。
2. **单调径向基保证注入性**：径向基被限制为**半径到入射角的单调映射**（不重复角度），且**不设 90° 上限** → 天然覆盖跨越赤道的广角/全景镜头。
3. **Camera-agnostic**：单模型跨 pinhole / GoPro / fisheye / catadioptric / panoramic 五类相机工作，**其中 GoPro 与 catadioptric 配置完全排除在训练之外**。

## 技术方案

### 核心思想

**问题**：单目 3D 重建模型多数假设 **pinhole 相机**，在鱼眼/全景广角图上产生扭曲几何。解法通常是"先标定再去畸变为 pinhole"——但 **pinhole 无法表达距光轴 90° 及以外的视线**，去畸变必然裁掉视场或强烈拉伸边缘。

**本文主张**：相机几何存在**表示复杂度的层级**：
1. **径向对称结构**（中心相机的基本形态）→ 单调径向基
2. **偏离径向的平滑变化**（图像覆盖大部分视球时）→ 球谐残差
3. **剩余局部变化** → 自由形式残差

三者以**球面上的连续旋转**复合 → 无需模型选择或路由即可适应各种相机几何。

**关键工程决策**：**先做去畸变再重建**这条主流路线被弃用，改为**直接在广角域中预测 ray field**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **中心相机假设** | 所有视线过单一光学中心 → 每个 3D 点 = ray 方向 + 沿 ray 距离 |
| **单调径向基** | 头预测 $K+8$ 个值：$K$ 个增量 $s \in \mathbb{R}^K$（经 softplus 保证正）、主点偏移 $c$、轴角旋转 $\omega$、上三角映射 $A(a)$（各向异性缩放 + 剪切） |
| **K=16 节点** | 跨 $r \in [0, 1.3]$（半对角单位）；节点高度累积 + 线性插值 |
| **不设 90° 上限** | 基能产生的最大角度 = 各增量之和 → **天然支持跨越赤道的镜头** |
| **球谐残差** | 头预测单一系数矩阵 $W_1 \in \mathbb{R}^{(L+1)^2 \times 3}$（实球谐基，最大阶 $L$），**全像素共享**；$L=7$ → 每图 192 个系数 |
| **逆立体投影提升** | 通过 inverse-stereographic lift 把归一化像坐标映射到 $S^2$ 上的地址 |
| **自由形式残差** | 轻量卷积解码器从稠密特征图 $F$ 预测修正图 $w_2(u)$；空间细节受 $F$ 分辨率限制 |
| **零初始化残差头** | 组合从径向基起步，**无需模型选择或路由**即可让表示自适应 |
| **深度监督 (deep supervision)** | 对 $d_0$、$d_1$ 加阶段权重 $\gamma_0, \gamma_1 > 0$ 的深监督 → 每个阶段只负责其表达的结构，防止"正确的最终 ray 靠任意基凑出来" |
| **区域加权损失** | $\lambda_c \bar{e}(C) + \lambda_p \bar{e}(Q) + \lambda_t \bar{e}(T)$：内区 C、外区 Q、误差最大的 5% 像素尾部 T；$\lambda_p$ 最大（**广角 FOV 的误差集中在边缘**） |
| **区域定义** | 按像半径 $\|m\|$ 相对最大值设阈值 → 同时适配圆形鱼眼与矩形画幅，且**不随预测主点移动** |
| **点云损失** | 联合监督 ray 与距离；每个 cloud 按自身平均点范数归一化 |
| **随机镜头增强 (AUG)** | 从全景图随机采样合成中心相机（视角 + 单调径向剖面 + 传感器区域）→ 单一族覆盖从 pinhole 到广角；**接近保留几何的采样被拒绝**，确保保留相机及其邻域完全不在训练中 |
| **Distance Module** | 复用同一编码器，融合 4 个中间块 + DPT 解码器 → softplus 得 $\rho(u) > 0$ |

### 关键公式

```math
% 径向基：单调半径→角度映射
m' = A(a)(m - c)                    % 各向异性缩放 + 剪切 + 主点校正
r = ||m'||, φ = atan2
θ_k = Σ_{j≤k} softplus(s_j),  θ_0 = 0
θ(r) = lerp( clip(r; r_0, r_K); {r_k}, {θ_k} )     % 节点间严格递增，区间外恒定
（K = 16，r ∈ [0, 1.3] 半对角单位）

% 径向基对应的视线
d_0 = R(ω) [ sin θ(r) cos φ,  sin θ(r) sin φ,  cos θ(r) ]^T
% 最大角度 = 各增量之和 → 不封顶 90°

% 球谐残差（逆立体投影提升 + 实球谐基）
b(m) = [ 2m / (1 - ||m||^2),  (1 + ||m||^2)/(1 + ||m||^2) ]   % inverse-stereographic lift
w_1(u) = W_1^T Φ_L [ b(m(u)) ]
（L = 7 → 192 系数 / 图）

% 球面上的指数映射（旋转）
对任意 d，只有 w 中正交于 d 的分量是切向：t = w - ⟨w, d⟩ d
n = ||t|| 为旋转角（弧度）
exp_d(w) = cos(n) d + sin(n) (t / n)
（球面上的指数映射；沿 d 的大圆方向转 n 弧度）

% 复合 ray field（三个分量依次旋转）
d_1 = exp_{d_0}(w_1)
d   = exp_{d_1}(w_2)
（t_1 是 w_1 在 d_0 处的切向分量，t_2 是 w_2 在 d_1 处的切向分量）

% 距离预测
ρ(u) = softplus(f_ρ(u)) > 0
最终 3D 点 = ρ(u) · d(u)
```

> **表示能力的量化对比**（论文表 3 附近的"参数量"列）：Radial(K=16) 用 24 参数、误差 0.002 / 22.802 / 0.104；SH(L=7) 用 195 参数、误差 0.276 / 0.641 / 0.295；**Radial16 + SH7 residual（本文）216 参数，误差 0.075 / 0.217 / 0.174**；Free field 76.8k 参数、误差 0.005 / 0.013 / 0.015。

## 实验结论

- **数据集**: 全景 + 鱼眼 + pinhole 混合训练；评估集包括**训练中完全排除的两种相机**（GoPro 鱼眼、Nayar 猫眼反射）+ **两个未见数据集**（PanoCity 户外街景、CO3Dv2 物体中心）
- **指标**: Ang.（平均视线角度误差，度，↓）、CD（相对 Chamfer 距离，按各场景平均点范数归一化，↓）；**按测试图像宏平均**，所有方法使用 per-image median scale alignment

| GeoCalib | 30.997 | – | 119.662 | – | 14.126 | – | 47.132 | 3.713 |
| AnyCalib | 28.655 | – | 107.129 | – | 10.031 | – | 42.335 | 2.711 |

| UniK3D | 6.336 | 0.0760 | 75.702 | 0.5948 | 6.342 | 0.0454 | 21.220 | 0.2120 |

- **Held-out 相机上角度误差从 UniK3D 的 75.702° 降到 1.120°**（约 68×）
- **AUG（随机镜头增强）的贡献极大**：去掉后 Held-out Cam 角度误差 30.867° → 有 AUG 后 1.118°（**约 28×**）
- **RG（ray guidance）** 在 held-out 相机上进一步提升（0.356 vs 1.385，seen camera），但在 held-out domain 上略降（5.180 vs 5.533——实际上 RG 更优）；最终 OmniRay（无 RG）在 aggregate 上最佳

| Ray 表示 | 训练 | Panorama | Fisheye | Pinhole | Catadioptric† | GoPro† |
|----------|------|---------|--------|---------|--------------|--------|
| Radial base | – | 21.825 | 1.761 | 0.788 | 6.039 | 5.377 |
| Spherical base | – | 5.088 | 1.540 | 0.790 | 13.327 | 5.962 |
| Radial + SH residual | – | – | – | – | – | – |
| Free field | – | – | – | – | – | – |

**关键解读**（论文原文论证）：
- **径向基**在 fisheye（1.761°）与 pinhole（0.788°）上表现好，但**全景上高达 21.825°**——因为单调径向剖面对每个图像半径只分配一个入射角，而**全景投影并不遵循这种排序**（论文 Fig. 3b：2:1 equirect 投影中，离图像中心更近的点 A 却有更高的入射角）
- **球面基**把全景误差降到 5.088°，但**在猫眼反射相机上反而恶化到 13.327°**
- **自由形式场**在全景、鱼眼、pinhole 上均最好
- **径向基 + SH 残差的组合**（本文方案）通过在保持"单调径向"结构的同时施加球面修正，取得最佳平衡

## 局限性

- **中心相机假设**：所有视线过单一光学中心；**排除非中心相机**（如双鱼眼、全景拼接多相机）
- **Held-out domain 仍是瓶颈**：Aggregate 角度误差 2.967° 远好于基线，但**在 PanoCity / CO3Dv2 上 5.533° 仍明显高于 seen camera 的 0.140°**——说明**域外泛化仍是主要误差来源**
- **RG 的收益不稳定**：在 held-out domain 上 OmniRay（无 RG）5.533 反而略差于 OmniRay + RG 的 5.180（版本表格），说明**ray guidance 的作用与域相关**
- **自由形式残差受特征图分辨率限制**：空间细节上限为 $F$ 的分辨率；而 Free field 参数量 76.8k，是 Radial+SH（216）的 **355 倍**——精度与成本需权衡
- **未报告绝对尺度**：只预测 up-to-scale 距离（每图像 median scale alignment）
- **主要面向 3D 重建而非渲染**：虽与 novel-view synthesis / inverse rendering 高度相关，但论文主要评估几何指标（角度误差、Chamfer），**未报告新视角合成质量（PSNR/SSIM/LPIPS）**
- 预印本，未见接收声明

## 实现建议

- **实现难度**: **中**（架构清晰：单编码器 + 3 个头；数学主要是球面指数映射与球谐求值）
- **预期性能**: Seen camera 0.140° / Held-out camera 1.120° / Held-out domain 5.533°；Aggregate 2.967° / CD 0.0380（基线 UniK3D 为 21.220° / 0.2120）
- **适用场景**: 广角/全景数据驱动的 3D 重建、AR/VR 内容创作、360° 采集、机器人视觉
- **对渲染线的直接价值**（**本库关注重点**）：
  1. **"ray field"是逆渲染的前置量**——任何 inverse rendering / novel-view synthesis / NeRF 前馈化流程，第一步都是"给定像素 → 世界空间方向"。本文提供了**相机无关的 ray 预测器**，可直接替换现有 pipeline 中的相机标定+去畸变步骤
  2. **单调径向基 + 90° 不封顶** —— 对**广角/鱼眼镜头下的 PBR 渲染**与**全向光照采样**有直接价值：多数相机模型假设针孔且 FOV ≤ 90°
  3. **"复合/层级表示"是通用思路**——把复杂量（相机几何、材质、光照）拆成"结构基 + 平滑残差 + 局部残差"三层，并用**连续旋转/混合**复合，比单一固定基表达力强且参数量可控（216 vs 76.8k）。这个范式可迁移到 **BRDF 建模、神经材质、方向相关外观** 的表示设计
  4. **零初始化残差头 + 深监督** —— 保证"正确的最终输出不能靠任意基凑出来"，这是训练稳定的通用技巧
  5. **AUG 的价值被量化**：本文显示"合成随机相机增强"对未见相机泛化的贡献达 **28×**。若本库要训任何相机相关的模型，这是必须复制的配方
- **风险**: 中心相机假设排除多相机系统；域外泛化（5.5°）仍不理想
- **优先级**: **中-高**（对"广角/全景场景下的渲染与重建"这条线价值明确；对墨鱼丸而言是**相机模型层的可复用模块**）
