## 核心贡献

> 用 PPO 强化学习在 **1D Hill 型肌肉代理**上自动发现逐肌肉激活，再由**共享同一本构定律**的 **3D 体积肌肉**（XPBD + **几何多重网格**）产生最终形变——**18 ms/frame**（RTX 4090），比 Houdini 生产级 Otis 求解器（20.8 s/frame）快约 **1155×**。

1. **两阶段共享本构定律**：RL 控制回路内保留 1D Hill 模型作**快速代理**，最终形变由 3D 体积模拟给出；两阶段用**同一个** Hill 型本构关系，因此"驱动运动的力"与"产生形变的力"完全一致（而非优化出来的外挂驱动）。
2. **面向四面体网格的几何多重网格**（核心算法贡献）：粗四面体笼 + 重心坐标延拓 + **Petrov–Galerkin 限制**，在四面体网格上**闭合完整 V-cycle**——填补了 HPBD 只支持布料且不闭合 V-cycle 的空白。
3. **EMG 先验**把冗余激活解**导向真实人体募集模式**（人类表面肌电图）。

## 技术方案

### 核心思想

现有 RL 肌肉控制器止步于 **1D 肌肉**（线段 Hill 模型），只能恢复关节运动，**无法产生体积肌肉形变**。本文进一步：把 1D 模型留在 RL 控制回路内当**快速代理**（降低 RL 采样成本），用 3D 体积模拟出最终形变。

**关键设计**：两阶段共享同一 Hill 型力-长度关系 → 注入到 3D XPBD 作为**基于能量的纤维约束**。这与"用优化反解肌肉激活再驱动"的做法本质不同：本文的激活**就是**驱动运动的力。

### 关键技术

| 技术 | 说明 |
|------|------|
| **问题定位：肌肉逆问题** | 从观测运动中恢复隐藏的肌肉激活信号。生产管线现有的两种做法都不物理：**tension line**（绑线收缩到阈值以下即触发）与**keyframing**（直接 K 帧激活曲线）——都是"为了视觉合理而选激活"，而非物理合理 |
| **前向动力学求解逆问题** | 搜索那些"一旦模拟就能复现目标运动"的激活；而非优化式反解 |
| **PPO 协同训练** | 单个 PPO 回路内联合训练策略网络 $\pi_\phi$ 与肌肉网络 $\mu_\theta$；1D 资产 284 条肌肉 → 3D 资产 194 条肌肉 |
| **1D Hill 代理** | RL 探索在 1D Hill 模型上进行（MuscleVAE 式架构），单次 rollout 极快 |
| **3D XPBD 体积模拟** | 约束集：体积保持、形状保持、**各向异性纤维收缩**、附着、碰撞 |
| **几何多重网格（GMG）** | 粗四面体笼 + 重心坐标 prolongate + Petrov–Galerkin restrict，**闭合 V-cycle** |
| **矩阵自由 (matrix-free)** | 不显式构造大稀疏矩阵 $P$、$R$；$P^\top P$ 沿肌肉**块对角** → 每块肌肉一个小稠密求解 |
| **预计算** | 逐肌肉伪逆块 $(P^\top P)^{-1}P^\top$ **预先算好存储**，运行时 restriction 退化为块对角矩阵-向量乘 |
| **可关闭的多重网格** | 跳过 restriction / coarse-solve / prolongation 即退化为经典 XPBD（便于消融） |
| **EMG 协同组均值匹配** | 表面电极匹配到**协同肌组均值**而非单纤维（按生理横截面积加权） |
| **步态周期对齐** | 按相位 $\phi$ 折叠到 0–100% 周期，对齐右跟触地 $\phi_{hs}=0.254$ |
| **GPU 全并行** | NVIDIA **Warp** 实现，全 GPU 加速，单张 RTX 4090 |

### 关键公式

```math
% XPBD 更新
Δλ = -(C - α̃ λ) / (Σ_i w_i ||∇C||^2 + α̃)
Δx_i = w_i ∇C Δλ
（α̃ = 1/(k Δt^2) 为柔度；k 为约束刚度，Δt 为时间步）

% 几何多重网格：延拓（prolongation）
x_f = x_f^0 + Σ_{i=1}^{4} w_i Δx_c^i
（w_1..w_4 为细顶点相对粗四面体的重心坐标，w_4 = 1 - Σ_{i=1}^{3} w_i）
每个四面体的 4 个权重构成 prolongator P 的一行；延拓的是粗修正 Δx_c 而非粗解 x_c

% 几何多重网格：限制（Petrov–Galerkin）
x_c = argmin_{x_c} ||P x_c - x_f||_2^2
法方程给出: x_c = (P^T P)^{-1} P^T x_f = R x_f
由于 P 满列秩，R 是 P 的左伪逆 → R P = I（精确恢复粗向量）
% 作者明确：选 Petrov–Galerkin 而非 Galerkin (R = P^T) 正是因为 RP = I 这一性质

% 多目标损失（协同肌组均值 + 步态对齐）
L = L_track + L_torque + w_reg Σ a^2 + λ L_emg
其中 torque scale κ=100, w_reg=0.01

% EMG 协同组均值
ā_c = Σ_{m∈G_c} ω_{c,m} a_m^M,   ω_{c,m} = f_{0,m} / Σ_{m'∈G_c} f_{0,m'}
f_{0,m} = σ_0 A_m^M（最大等长力 = 最大等长应力 × 生理横截面积）
σ_0 在肌肉间统一 → 权重退化为横截面积之比

% 步态周期对齐
φ = fmod(t, T)/T ∈ [0,1)
对齐位置: ((φ - φ_hs) mod 1) * 100,   φ_hs = 0.254（由参考脚的正向运动学标定）
```

## 实验结论

- **数据集**: 自建 1D 肌肉骨骼资产（**284 条**肌肉）与 3D 体积肌肉资产（**194 条**肌肉）；参考动作 4 段（周期行走 / 单腿支撑的平衡性踢球 / 自由漂浮游泳 / 深蹲）；测量 sEMG 来自 Moreira et al.（4 个右腿电极）
- **基线**: Houdini **Otis** 生产级体积肌肉求解器（CPU + OpenCL）；Han et al. (Epic) 神经肌肉模型；Lee et al.（**因优化式控制器在控制回路内反复重跑体积求解器导致优化不收敛而被排除**）

### 与生产级求解器对比

- **Otis (Houdini)**：逐顶点距离大部分身体在**几毫米**内（蓝–绿），大腿/肩部等局部区域偏差较大；**成本差异巨大**：本文 GPU 求解器 **18 ms/frame** vs Otis CPU OpenCL **20.8 s/frame**（同款 Ryzen 9 5950X）→ **约 1155×**
- **Epic (Han et al.)**：躯干大部分偏差小，前臂与腹部中段偏差较大（两者肌肉建模差异处）

## 局限性

- **拓扑与边界条件依赖强**：1D→3D 肌肉映射（284→194）需要人工对应，论文承认需要映射
- **仅支持特定动作类型**：验证集中于下肢步态类动作（行走、踢球、深蹲、游泳），EMG 先验的标定基于**右腿步态周期**
- **EMG 采样密度极低**：仅 4 个表面电极（对应 4 个协同肌组），且需**折叠到共同步态周期**比较形状与时序而非幅值——这限制了对精细肌肉募集的约束力
- **对比基线不完整**：Lee et al. 因其自身优化不收敛被排除（论文明确说明，但这是有利的对比选择）
- **求解器质量依赖 GPU**：CPU 路径未评估
- **18 ms/frame** 是模拟时间，不含 USD 导出（32 ms/frame）
- 预印本状态，**未见同行评审**

## 实现建议

- **实现难度**: **高**（RL + 体积 XPBD + 多重网格 + GPU 并行，四层都需要实现；但 Warp/MuJoCo 降低了基础设施成本）
- **预期性能**: 468K 四面体 / 172K 顶点，**18 ms/frame**（RTX 4090，约 55 fps 实时）；多重网格使收敛步数减少 **11.7×**
- **适用场景**: 需要**物理真实肌肉形变**的角色动画（影视级角色、特效）；不适合需要极低延迟的实时游戏角色
- **可直接借鉴的算法洞察**（**与渲染无关但对 GPU 求解器高度可迁移**）：
  1. **几何多重网格 + Petrov–Galerkin 限制（$RP = I$）** 是本篇最可复用的技术：任何"高刚度、大规模、GPU 求解"的问题（体积流体、软体布料、可微物理）都可以套用
  2. **重心坐标 prolongate 粗修正而非粗解** —— 保证细网格初值不被粗网格污染
  3. **矩阵自由 + 块对角预计算伪逆**：细顶点按所属粗笼分组，运行时只剩小稠密块乘
  4. **"共享本构定律"的设计模式**：RL 代理与最终模拟用同一物理模型 → 避免"训练-推理物理不一致"
  5. **方法论**：多目标损失的**物理先验注入**（EMG 引导冗余解）—— 冗余解的稀疏正则化不等于物理合理，这是通用思路
- **优先级**: **中**（不在渲染主线上，但几何多重网格技术可迁移到可微渲染/物理仿真；对墨鱼丸的价值在"GPU 高刚度求解"这一通用工具）
