## 核心贡献

> 证明了 **Tutte 嵌入定理的"流"版本**：在球面拓扑网格上求解离散 Laplace 方程得到的调和函数，其 **90° 旋转梯度**定义的向量场**自动诱导注入流**（任意两条轨迹不相交）——且与 Tutte 嵌入一样，**只需解一个稀疏线性系统**。

1. **定理 1（注入性）**：旋转梯度向量场 $u_t = R_{90°}\nabla_t z$ 定义的流是注入的。
2. **核心洞察**：双射叶状化（bijective foliations, [CSZ16]）的**组合注入条件**与离散调和 1-型的 **Poincaré–Hopf 指标刻画**（[GGT06]）在数学上平行——本文证明了这一平行关系，并据此把组合条件转为调和函数条件。
3. **可微参数化**：Laplacian 的边权改变 → Laplace 方程改变 → 向量场与流**可微地**改变。因此可以**在保持注入性的前提下**做无约束梯度优化。

## 技术方案

### 核心思想

**问题背景**：确保流（flow）注入性有两种思路。

- **连续向量场**：要求 Lipschitz 即可（Picard–Lindelöf 定理）
- **离散面基向量场**：分段常数且不连续 → 注入性是**脆弱的组合性质**，需要满足基于三角形的组合规则 [CSZ16]

**本文的桥梁**：
- [CSZ16] 给出向量场满足注入性的**组合条件**（此前只能组合式/算法式地构造）
- [GGT06] 给出离散调和 1-型的 **Poincaré–Hopf 指标定理**（Tutte 嵌入推广到其他拓扑）
- **本文证明两者等价**，于是可以用**调和函数**构造满足组合条件的向量场

**几何直觉**：旋转后的梯度向量场指向调和函数 $z$ 的**等值线的切向**；因此每条轨迹**始终停留在 $z$ 的某个固定等值线上**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **离散调和函数** | 在球面拓扑网格上解 Laplace 方程，边界条件：一源一汇（source & sink） |
| **旋转梯度向量场** | 每个三角形 $t$ 上定义 $u_t = R_{90°}\nabla_t z$（式 9） |
| **通量 / 1-型等价（Lemma 1）** | 边 $e$ 上的通量 $F_e$ **恰等于** 1-型 $\delta_e$ 的符号：$F_e = \text{sign}(\delta_e)$（式 10） |
| **Petrov–Hopf 对应** | 1-型的反对称性 $\delta_e = -\delta_{\bar e}$ 直接给出**边注入性** $F_e = -F_{\bar e}$ |
| **顶点注入性（Theorem 2）** | 顶点处指标为 +1（源）与 −1（汇），其余为 0，满足 [CSZ16] 的顶点注入条件 |
| **稀疏线性求解** | 同 Tutte：一次稀疏线性系统求解（cotangent Laplacian 或 MVC Laplacian，任意**正边权**皆可） |
| **可微边权优化** | 对 Laplacian 边权直接做梯度下降，自动保持注入性 |
| **Piecewise-linear 流** | 向量场在三角形上分段线性 → 流可**简单、快速、精确**计算，无需对连续场做数值积分 |
| **离散时间相关流** | 在不同时段切换不同调和函数 → 更复杂的流（不同时间点的轨迹可相交，不违反注入性） |
| **对称化限制（symmetrization）** | 论文提到以对称化限制处理逆映射时的不连续 |

### 关键公式

```math
% 旋转梯度向量场（式 9）
u_t = R_{90°} ∇_t z

% 定理 1（主结果）
由式 (9) 定义的向量场 u 所诱导的流是注入的。

% Lemma 1（通量 / 1-型等价，式 10）
F_e = sign(δ_e)
（边 e 上的通量恰等于 1-型 δ_e 的符号）

% 边注入性
F_e = -F_ē   ⟺   δ_e = -δ_ē   （由 δ 的反对称性直接得出）

% Theorem 2（顶点注入性）
设 M 为球面拓扑网格、z 为其上的离散调和函数（一源一汇边界条件），
则式 (9) 定义的向量场是顶点注入的。

% 几何直觉
每条轨迹位于 z 的某个固定等值线（level set）上；
源点与汇点成为两个涡点（流绕其旋转、该点静止）。

% 注入性的充分条件（连续情形，用于对比）
连续向量场：Lipschitz 连续 ⟹ 注入（Picard–Lindelöf 定理）

% 数值精度（往返一致性验证）
沿流前进再倒退应回到出发点。
报告：MAE 与 MXE；平均无误差超过 10^{-8}，最大不超过 10^{-5}。
```

> **精度注意**：论文明确指出**面积很小或接近退化的三角形**会导致精度下降——原因是调和方程/梯度算子的数值误差造成**穿越边所需时间计算出现漂移**。

## 实验结论

- **数据集**: 三个网格模型 —— **Spot**（5,856 面）、**Cow**（8,626 面）、**Homer**（12,000 面）
- **基线/对照**: 不同 Laplacian（cotangent [PP93]、Mean Value Coordinates [Flo03b]、随机权重、优化的权重）

### 表 1：往返一致性误差（数值精度）

| 网格 | 面数 | MAE (10⁻⁹ m) | MXE (10⁻⁶ m) |
|------|------|--------------|--------------|
| Spot | 5,856 | < 0.001 | < 0.001 |
| Cow | 8,626 | < 0.001 | < 0.001 |
| Homer | 12,000 | < 0.001 | < 0.001 |

### 实验内容

1. **不同 Laplacian 类型产生不同流**：cotangent Laplacian（钳位为正权）与 MVC Laplacian 都给出沿调和等值线的光滑流；**任意正权 Laplacian 都保证注入性**（定理 1 的直接推论）
2. **随机 / 优化权重的 Laplacian** → 更振荡的向量场与轨迹，**仍然注入**
3. **可微优化实验 1（逼近非注入场）**：从随机初始化的注入场出发，优化以最小化与目标非注入场（由 [CDS10] 生成）的**逐面目标向量 MSE** → 得到保持注入性的场，且贴合目标的整体方向趋势
4. **可微优化实验 2（满足稀疏约束）**：优化以拟合 10 个用户定义的方向约束（仅在约束面上计算 MSE）→ 初始场在任意约束处自然偏离，优化后达到**近乎完美对齐**（有时路径相当扭曲）

### 优化配置

- 实现：PyTorch（自动微分）
- 优化器：**Adam**，固定 step size **0.1**，**5000 次迭代**
- 被优化的量：Laplacian 的边权

## 局限性

论文在结论中明确列出：

1. **拓扑与边界条件受限**：方法仅适用于特定拓扑（球面拓扑）与特定边界条件（一源一汇）。作者认为**可推广到其他特定边界条件与特定域**，但尚未完成
2. **同 Tutte 嵌入**：注入性扩展到其他拓扑**仍待解决**
3. **数值退化**：小面积/近退化三角形导致精度下降（调和方程与梯度算子的数值误差 → 跨边时间计算漂移）
4. **主要贡献是理论性的**：实用价值目前仅"初步验证"级别（作者原话 preliminary demonstrations）
5. **可微优化的结果未给出定量指标**——只给图示（Fig. 10、Fig. 11），**没有报告 MSE 下降的数值**

> **额外观察（论文自身指出）**：在**其他拓扑**（非球面）上使用同一技术会得到**非注入**的例子（论文 Figure 3 明确展示了这一失败案例）。

## 实现建议

- **实现难度**: **低-中**（核心就是解一个稀疏线性系统 + 三角形上的旋转梯度；可微优化用 PyTorch 即可）
- **预期性能**: 求解 = 一次稀疏线性系统；数值误差平均 < 10⁻⁸、最大 < 10⁻⁵（往返一致性）
- **适用场景**:
  1. **四边形网格生成的零奇异初始化**——[DKG05] 用调和梯度生成四边形网格但**不考虑注入性**；本文提供注入保证
  2. **流形上的纹理/坐标流场设计**（surface flows for texture transport、stochastic texture sampling）
  3. **参数化/变形场的可微初始化**——"保持注入性的无约束优化"这个性质很有用
  4. **形变/动画的方向场**——作为方向场的合法初值
- **对渲染线的直接价值**（**本库关注点**）：
  1. **可微注入流 = 可微变形的天然先验**——若做 3D 形变、网格动画、非刚体配准，注入性保证形变不产生自交，**而这在可微管线中通常只能靠惩罚项近似**
  2. **分段线性流 → 精确低成本的沿流积分**——比神经连续流（需数值积分、昂贵且有误差）快得多
  3. **Laplacian 边权作为可优化参数**——本库若做**网格重划分/自适应**，边权优化是天然的参数化接口
  4. **本库已有 [[Geometric-Queries-Tessellation-Free-Displaced-Surfaces]]、[[TopGen-Quad-Mesh-Generation]]、[[TreeON-3D-Tree-Point-Clouds]] 等几何处理线工作**——本文可直接作为**四边形网格生成的注入性初始化**方法补充
- **风险提示**: 拓扑与边界条件限制严格（球面 + 一源一汇），不能直接套用到高亏格网格；论文自己给出了失败案例
- **优先级**: **中**（理论价值高，落地需注意拓扑限制；对几何线（黄喉）价值 > 对渲染线）
