## 核心贡献
1. 提出基于标准 Zakharov 公式的非线性、色散 2D 波浪模型
2. 设计了 2D-3D 界面的正则（canonical）双向耦合方案，消除接缝伪影
3. 2D 求解器比 SWE、BEM、Airy 基线在波高误差上降低 1.7-5 倍
4. 整体系统比纯 GPU NB-FLIP 快 4 倍以上

## 技术方案
**问题**：大规模自由水面模拟中，将局部 3D 流体求解器与更便宜的 2D 表面模型耦合时，面临波浪动力学不匹配问题——高效的 2D 波浪模型通常是线性或非色散的，与强非线性 3D 求解器耦合会产生明显反射和伪影。

**解决方案**：
- 采用 Hamiltonian 结构的 2D 波浪模型（表面高度 η 和表面势 ψ 为正则变量对）
- 正则结构确保 2D-3D 界面信息平滑传递
- 耦合实验包括色散匹配和 Kelvin 船舶波测试

**性能数据**：
- 波高误差降低 1.7-5× (vs SWE, BEM, Airy)
- 比 BEM 快 10³+ 倍
- 比纯 GPU NB-FLIP 快 4+ 倍

## 公式
Zakharov 公式核心：表面高度 η 和表面势 ψ 形成正则变量对，由波能控制。

## 实验结论
- 成功消除 2D-3D 界面处的可见接缝伪影
- 在色散匹配和 Kelvin 船舶波测试中表现优异
- 速度优势明显，适合大规模水体模拟

## 局限性
- 适用于特定场景（大尺度自由水面）
- 具体参数调优依赖场景
- 需结合水面渲染才能呈现最终效果

## 可行性分析
- 实现难度：高（需实现 Zakharov 波浪模型 + 耦合框架）
- 性能预期：实时/近实时水体模拟
- 适用场景：游戏/影视水体渲染、船舶流体可视化
