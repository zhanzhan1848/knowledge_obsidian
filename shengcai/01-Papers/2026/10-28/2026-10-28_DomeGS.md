## 核心贡献

> 把「天空盒」从无限远的平面背景壳，变成 3DGS 场景中**有真实几何半径的高斯集合**，同时满足辐射一致性与运动视差两个必要条件。

1. **统一的无界 3DGS 场景扩展示范**：三阶段流水线（全景提取与外绘 → 场景自适应数据集制备 → 统一天空高斯优化），把「背景补全」从 2D 后处理变成 3DGS 场景本身的一部分，输出单一 `.ply` 资产，在任意 HMD 位姿下可联合光栅化。
2. **360° 感知生成式 outpainting → 高斯 skydome 落地**：用 360° ERP 专用扩散模型（FLUX.2-klein-base-9B + 360 ERP LoRA）补全全景，再反投影为**有限半径球壳上的种子高斯**，通过光度 + 壳层 + 平面度三重损失微调，实现与前景的高光度对齐、无缝融合。
3. **N=36 被试内（within-subjects）用户研究**：相对传统 skybox 基线，显著提升背景一致性、临场感（IMM）、空间临场感（IPQ SP）与体验真实感（REAL）；行为学指标经 TOST 验证等价（任务难度未混淆）。

## 技术方案

### 核心思想（三阶段流水线）

```
原始 3DGS 场景 G0  ──►  Stage I 全景提取+360°外绘 ──► 无缝等距柱状全景
                              │
                              ▼ Stage II  场景自适应数据集制备 ├─ 几何参数估计: 壳半径 R, 最优俯仰 ψ*, 剔除背面浮点
                    └─ 合成多视角监督集 Isup(α合成 / 角色相关目标)
                              │
                              ▼
                    Stage III 统一天空高斯优化
                    └─ 种子高斯 Gseed + 光度/壳层/平面度损失
                              │
                              ▼
                    统一场景 G = G' ∪ Gbg（单一3DGS 资产）
```

**核心洞见**：3DGS 在无界室外场景失败的原因是远场缺乏多视差与几何地标，深度三角化不可靠；而 skybox 是无限远、无平移视差、与前景光照/色彩不匹配。DomeGS 把 skydome 概念**变成有真实几何半径的高斯集合**，从而同时满足两个必要条件：
- **辐射一致性 (Radiometric Coherence)**：背景必须无缝匹配 G0 中烘焙的照明、色调、色彩平衡 → 由生成式外绘 + 光度损失实现。
- **运动视差 (Kinematic Parallax)**：背景必须在平移时保留深度一致的视差 → 由有限半径球壳实现（这正是 skybox 缺失的）。

### 关键技术

| 阶段 | 技术 | 做法 | 目的 |
|------|------|------|------|
| **I. 全景提取** | 排除球剔除 | 在轨迹质心 `e` 处排除半径 `r` 内的所有高斯（含其最大尺度 `smax`） | 只保留远场内容，避免前景遮挡污染全景 |
| | 等距柱状渲染 | 从 `e` 渲染 equirectangular 图 `I0`，构造二值补全掩码 `M` | 标记未观测天空/空洞区域 |
| | 全局 outpainting | 360°-aware latent diffusion（FLUX.2-klein-9B + 360° ERP Outpaint LoRA）以 `I0+M` 为条件 | 生成初始全景 `I(1)` |
| | Wrap-Seam 调和 | 将 `I(1)` 循环位移 180° 重新居中 → 新接缝处加竖条掩码 `M_seam` → 二次扩散 inpaint | 消除 360° 经线接缝 |
| **II. 数据集制备** | 壳半径估计 `R` | `R = m · Quantile_q({‖μ_i−e‖₂ : i∈V_cube})`，`q=98%`，`m=1` | 壳包住所有前景且不与近场相交 |
| | 最优基准俯仰 `ψ*` | 最大化可见前景密度、惩罚未观测天空空洞的优化目标，`λ_ψ=0.3` | 抵消手持采集的垂直视角不对称 |
| | 背面浮点剔除 | 放置 yaw 翻转 180°、俯仰偏离主场景的 "look-back" 探针相机，剔除可见的 `G_lb` | 清除 frustum 外的退化低不透明度高斯，防止污染新背景 |
| | 多视角监督合成 | 在分层相机环上采样：`p_down`（地面）、`p_scene`（水平过渡）、`p_bg`（天空） | 不同视角带承担不同监督角色 |
| | **α 合成**（几何一致性核心） | 中间带/天空带目标 = `I_G'(T) + I_bg(T) ⊙ (1 − α(T))` | 前景轮廓与远景按物理 α 合成，消除地平线接缝，**无需网格分割** |
| **III. 统一优化** | 种子初始化 | 上半球壳均匀采样：`d_j ~ Unif(S²₊)`，`r_j ~ Unif([γR, R])`，`γ=0.99` | 覆盖整个远场，厚度极薄 |
| | 前景冻结 | 冻结 `r_f = max_k ‖t_k − e‖₂` 内的全部高斯；该半径外保持可训练但**保护免于** pruning / size-culling / opacity reset | 保留已捕获的前景结构不降级 |
| | 背景保护策略 | `Gseed` 本身免于剪枝；但 densification 新生高斯**不**豁免，允许细节化与去冗余；所有背景高斯禁用基于尺度的剔除 | 兼顾「结构稳定」「细节丰富」「空间覆盖」 |
| | 三项损失 | `L = L_photo + λ_shell·L_shell + λ_plan·L_plan` | 光度 + 几何 |
| | 壳层正则 | 惩罚离开 `[γR, R]` 球壳的高斯（双向 hinge） | 保持有限半径壳几何 |
| | 平面度正则 | 惩罚最短轴与径向的对齐误差 + 细长比 `smax/smin` | 抑制「尖刺状」高斯，使背景呈片状/球面一致 |

## 公式

```math
% 壳半径估计（98% 分位数）
R = m \cdot \mathrm{Quantile}_{q}\Big(\big\{\|\boldsymbol{\mu}_i - \mathbf{e}\|_2 : i \in V_{\text{cube}}\big\}\Big),
\qquad q = 98\%,\; m = 1
```

```math
% α 合成（无需网格分割的前景/远景融合）
I_{\text{target}}(T) = I_{G'}(T) + I_{\text{bg}}(T)\odot\big(1 - \alpha(T)\big)
```

```math
% 种子高斯的球壳均匀采样
\mathbf{d}_j \sim \mathrm{Unif}(S^2_+),
\qquad
r_j \sim \mathrm{Unif}([\gamma R,\, R]),
\qquad \gamma = 0.99
```

```math
% 总损失：光度 + 壳层正则 + 平面度正则
\mathcal{L} = \mathcal{L}_{\text{photo}} + \lambda_{\text{shell}}\,\mathcal{L}_{\text{shell}}
+ \lambda_{\text{plan}}\,\mathcal{L}_{\text{plan}}
```

```math
% 壳层正则（双向 hinge，惩罚离开 [γR, R]）
\mathcal{L}_{\text{shell}} = \sum_i \Big[(\gamma R - r_i)_+^2 + (r_i - R)_+^2\Big],
\qquad r_i = \|\boldsymbol{\mu}_i - \mathbf{e}\|_2
```

```math
% 平面度正则：最短轴与径向的对齐误差 + 细长比惩罚
\mathcal{L}_{\text{plan}} = \sum_i \big(1 - |\hat{\mathbf{n}}_i \cdot \hat{\mathbf{r}}_i|\big) + \lambda_{\text{slender}}\sum_i \Big(\frac{s_i^{\max}}{s_i^{\min}} - 1\Big)
```

## 代码片段

```python
# 壳层正则与平面度正则（依论文描述重构）
def shell_regularization(mu, center, R, gamma=0.99):
    r = np.linalg.norm(mu - center, axis=-1)          # (N,)
    lower = np.maximum(gamma * R - r, 0.0) ** 2        # 双向 hinge: 太靠内
    upper = np.maximum(r - R, 0.0) ** 2                # 双向 hinge: 太靠外
    return np.sum(lower + upper)

def planarity_regularization(mu, scales, center):
    r_hat = mu - center
    r_hat /= np.linalg.norm(r_hat, axis=-1, keepdims=True) + 1e-8
    # 最短轴与径向的对齐误差（背景应呈片状/球面一致，而非尖刺）
    s_min_idx = np.argmin(scales, axis=-1)
    n_hat = extract_min_axis(mu, scales, s_min_idx)
    align_err = 1.0 - np.abs(np.sum(n_hat * r_hat, axis=-1))
    # 细长比惩罚
    s_max = scales.max(axis=-1); s_min = scales.min(axis=-1)
    slender = s_max / (s_min + 1e-8) - 1.0
    return np.sum(align_err) + lam_slender * np.sum(slender)

# α 合成（无需网格分割）
def alpha_composite_target(foreground_render, background_render, alpha):
    return foreground_render + background_render * (1.0 - alpha)
```

## 实验结论

- **数据集 / 场景**：手持采集的无界室外场景（unbounded outdoor），3DGS 重建 + 背景补全。
- **基线**：传统 **skybox**（带纹理的立方体/球体）。
- **用户研究**：N=36 被试，**内被试设计（within-subjects）**。
  - 背景一致性 SKY：Δ = **+1.24**，Cohen's d = **0.85**，**p < 0.001**
  - 临场感 IMM：Δ = **+0.44**，d = **0.35**，**p < 0.001**
  - IPQ 空间临场感 SP：**1.73 vs 1.41**，Δ = **+0.32**，**p = 0.042**
  - 体验真实感 REAL：**0.36 vs −0.07**，Δ = **+0.44**，**p = 0.042**
  - 行为学指标经 **TOST（等价性检验）** 验证等价 → 任务难度未被混淆。

## 局限性

- 依赖生成式扩散模型做外绘 → **需要额外的 FLUX.2-klein-9B + 360° ERP LoRA 推理算力**（离线可接受）。
- 需手工排除球、估计壳半径、剔除背面浮点 —— **非全自动**，但流程化程度高于 GraftRay 的人工标注。
- 壳半径与场景尺度强耦合，同一算法跨场景需重新估计（`R` 依赖 `Quantile_98%`）。
- 生成式外绘可能引入**几何上不存在**的远处结构（本就在预期内，但存在「幻觉地标」风险）。
- 用户研究 N=36，统计功效有限（p=0.042 的两项指标接近显著性阈值）。

## 实现建议

- **实现难度**：**中偏高**。三阶段流水线本身不复杂，但需要：360° ERP 扩散模型推理、视图合成监督集构造、以及对 3DGS 训练器的冻结/保护性改造（前景冻结 + 背景免剪枝）。
- **预期性能**：用户研究上背景一致性（d=0.85）与临场感（p<0.001）显著优于 skybox；空间临场感与真实感 p=0.042 边缘显著。
- **适用场景**：
  1. **VR / XR 的无界室外场景重建** —— 这是最直接的落点；
  2. 任何需要「天空/远景与前景无缝融合」的 3DGS 资产制作管线；
  3. 训练数据合成（合成外景数据集）。
- **行动建议**：**推荐作为「3DGS 场景补全」的参考实现**。其两条**可直接复用**的设计：
  1. **α 合成而非网格分割**（`I_fg + I_bg·(1−α)`）——在自有 3DGS 管线里做背景融合时可省掉分割步骤，**优先级：高**；
  2. **前景冻结 + 背景免剪枝** 的训练期保护策略 —— 增量训练时避免既有结构被剪枝掉，**优先级：高**（这个技巧对任何增量式 3DGS 训练都成立）。
