## 核心贡献

> 把全局光照解表示为 **13D 高斯混合模型**，并**直接最小化渲染方程残差**——不走 Neumann 级数（路径追踪）路线，而是把「解方程」变成「解最小二乘不动点问题」。

1. **13D 高斯混合 + 渲染方程残差最小化**
   - 求解 `L = E + T L` 的不动点：`θ* = argmin ‖r_θ‖²`，`r_θ = L_θ − E − T L_θ`。
   - 与 Neural Radiosity（Hadadan et al. 2021）的「核方法化」替代：后者网络隐式定义核、位置固定在预定义网格上；本文**同时学习**核权重、13D 中的位置 `m_k`、形状（协方差 `Σ_k`）**以及核的数量**。
2. **把场景属性并入高斯输入空间，显著降低所需函数数量**
   - 13D = 位置(3) + 方向(3) + 法线(3) + albedo(3) + roughness(1)。
   - 高斯**不被限制在表面上**，因此可自然处理法线与材质的局部变化，**无需把表示绑定到网格几何**。
   - 复杂度随解**自适应**，不受场景几何离散化约束——这是对比 Neural Radiosity 统一网格（5D grid、内存爆炸）的关键优势。
3. **世界空间 tile-based 层级剔除 (culling)**，使分钟级优化与实时渲染同时可行
   - 相比 Neural Radiosity + Vertex Features：训练快 **10.0–23.4×**，渲染快 **2.2–4.5×**，模型仅 **1.0–5.9 MB**。

## 技术方案

### 核心思想

**三维管线：**
1. **初始化**：在场景表面随机采样位置与方向，生成 **10K** 个低强度 13D 高斯。
2. **优化**：最小化渲染方程残差（半梯度 Monte Carlo），配合 **split / spawn / prune** 调整高斯数量。
3. **渲染**：两种模式
   - **GS**：直接在主光线命中点查 `L_θ`，无需二次光线；
   - **GS + MC**：打一跳二次光线，用 `L_θ` 作为入射辐照度做 MC 积分。

> **关键洞察**：由于模型只在**光线追踪命中点**被查询，「第一个可见表面」自动生效，**可见性无需显式处理**——这与 NeRF/3DGS 的 view-dependent 表示形成鲜明对比。

### 13D 维度构成

`q = (x, ω, n, a, r) ∈ R¹³`

| 子空间 | 维度 | 说明 |
|--------|------|------|
| 位置 x | 3 | 场景空间位置 |
| 方向 ω | 3 | 出射方向，plunge 进 R³（球面参数化） |
| 法线 n | 3 | 表面法线，plunge 进 R³ |
| 材质 albedo a | 3 | RGB 反射率 |
| 粗糙度 r | 1 | 单维标量 |
| **合计** | **13** | |

- albedo 与法线、方向**无旋转**（对角协方差表示）。
- 该变量集合**不限制场景可用材质范围**，只是让高斯更好地适配光照变化。
- 好处：空间中**不连续但 albedo/roughness 相同**的区域可以共享同一个高斯。

### 各向异性协方差的实现（关键工程 trick）

**朴素做法**：`Σ = LᵀL`（13×13 下三角 Cholesky），则 `vᵀΣ⁻¹v = ‖L⁻¹v‖²`，每次求值 = 解一次 13D 三角线性方程组。

**本文方案**：把 13D 高斯**分解为低维子空间上独立高斯的乘积**（block-diagonal / 乘积形式），忽略跨子空间相关性：

```text
G_k(q) = G_x(x) · G_ω(ω) · G_a(a) · G_n(n) · G_r(r)
```

- 各子空间独立：position、direction、material、normal 分开处理。
- 代价：无法捕捉跨子空间相关性。论文称对收敛质量**影响相对很小**，但显著提升性能并保持 3D 空间局部性。
- position 与 direction 分量再按 3DGS 方式分解：`Σ = R S Sᵀ Rᵀ`（旋转 R + 缩放 S）。
- 高斯颜色与协方差尺度均用**指数激活**（值域 `[0, ∞)`）。
- 副产品：可分离结构使**可分离剔除判据**成为可能（各子空间独立算 Mahalanobis 距离后累加）。

### Culling 策略（论文最关键的工程贡献）

训练与 GS+MC 渲染中的查询是**在位置与方向上随机采样**的，**没有屏幕空间相干性**，因此无法用 3DGS 那种 tile / screen-space 分块。论文改用**世界空间 tile**：

1. **Morton code 分块**：每个查询基于「所属 shape 的索引 + 3D 位置」计算一个 **64-bit Morton code**；按 code 排序后截断固定前缀长度分组成 tile → 保证空间局部性 + 内存访问连贯。
2. **保守包围盒**：对每个 tile，在**全部 13 个输入维度**上做并行归约，得到各维度的保守范围。
3. **高斯/tile 相交测试**：若预期指数低于阈值则丢弃该高斯对 tile 的贡献（等价于把每个核**截断为有限支撑域**）。
4. **可分离版本（渲染时）**：利用高斯指数在去相关子空间上可加的性质：
   - 先对 **1D 子空间**（roughness）做 Mahalanobis 距离测试 → 廉价高效的早期拒绝；
   - 再对 **3D 空间与方向分量**用 tile 包围盒做类似测试。
   - 3D 保守 Mahalanobis 距离的计算方式：先算高斯到包围盒**中心**的 Mahalanobis 距离，再**减去中心到某个角点的最大距离**。
5. **效果**：Bedroom 场景下平均每像素只需评估 **76 个高斯核**（总数 22K）。

### 训练数据

**纯合成，无 live capture。** 训练完全由 **Mitsuba 3** 路径追踪器提供：
- 表面点 `x_j`、出射方向 `ω_j`、入射方向 `ω'_j` 按适配过的概率密度函数 `p(x, ω)` 采样；
- 每个出射方向采样 `Q = 32` 个**入射方向** + `Q = 32` 个**显式光源样本**（降低直接光照贡献带来的方差）；
- 参考图是路径追踪 ground truth，评估用 **HDR-FLIP**。

> 也就是说：**没有使用真实采集数据**，模型是「解方程」而不是「拟合图像」——这是与 3DGS/NeRF 路线的根本区别。

### Densification / Pruning 三件套

| 机制 | 触发条件 | 动作 |
|------|------|------|
| **Split** | 某子空间内梯度大（说明欠分辨） | 沿该子空间主轴分裂；子高斯沿主轴正负偏移 `d = 0.5 × 主尺度`，该轴协方差缩放 `k = 0.8`。**每次只沿一个子空间分裂，空间维度优先** |
| **Spawn**（残差驱动新增） | split 无法覆盖无覆盖区域 | 在计算残差时选贡献最大的 top-k 样本，在对应 `q(x_j, ω_j)` 处初始化新高斯；初始系数 `c_k = E(x,ω) + T L_θ(x,ω)`（残差右端项，自然估计 `L_θ`） |
| **Prune** | 相对归一化贡献 `r_k` 低于阈值 | 积分域限制在高斯有效支撑域 `D_k`（指数 > `β = −14`）；`r_k` 低于 `τ = 8×10⁻³` 则删除。按**相对能量贡献**而非绝对量 → 亮区与暗区被一致对待 |

**调度**：每 400 iter split 一次，每 500 iter spawn 500 个新高斯；split 与 spawn 在 **iter 15000 后停止**；每 2000 iter prune 一次。Adam，学习率 `(m, R, S, c) = (3e-4, 1e-3, 5e-3, 1e-2)`，**全部场景同一组超参**。

## 公式

**渲染方程与算子形式：**

```math
L(x,\omega) = E(x,\omega) + \int_{\Omega} L_i(x,\omega')\, f(x,\omega,\omega')\, n\cdot\omega'\, d\omega'
```

```math
L = E + \mathcal{T}L,
\qquad
\theta^\star = \arg\min_\theta \lVert r_\theta\rVert^2,
\quad r_\theta = L_\theta - E - \mathcal{T}L_\theta
```

**13D 高斯混合：**

```math
L_\theta(x,\omega) = \sum_{k=1}^{M} c_k\, G_k\big(q(x,\omega)\big),
\qquad
G_k(q) = G_x(x)\,G_\omega(\omega)\,G_a(a)\,G_n(n)\,G_r(r)
```

**可分离指数（用于可分离剔除）：**

```math
\exp\big(-v^\top\Sigma_k^{-1}v\big)
= \prod_{s \in \{x,\omega,a,n,r\}} \exp\big(-v_s^\top\Sigma_{k,s}^{-1}v_s\big)
```

**保守 Mahalanobis 距离（tile 剔除）：**

```math
d_{\text{cons}}(k,\text{tile}) = d_{\text{Mah}}(k,\text{center}) - \max_{\text{corner}}\big\| \text{center} - \text{corner} \big\|_{\Sigma_k^{-1}}
```

**Prune 判据（相对能量贡献）：**

```math
r_k < \tau = 8\times 10^{-3} \;\Rightarrow\; \text{delete},\qquad
\text{support}: \ \exp\big(-v^\top\Sigma_k^{-1}v\big) > \beta = -14
```

## 代码片段

```cpp
// 13D 高斯的可分离求值（每子空间独立，避免 13x13 三角求解）
__device__ __forceinline__ float eval_gaussian_separable(
    const float vx[3], const float vw[3], const float va[3],
    const float vn[3], const float  r,
    const Gaussians13D& g, int k)
{
    // 各子空间的指数独立相乘
    float e = 0.0f;
    e += mahalanobis2(vx, g.sigma_x[k], g.mu_x[k]);   // 位置（可分解 R S S^T R^T）
    e += mahalanobis2(vw, g.sigma_w[k], g.mu_w[k]);   // 方向
    e += mahalanobis2(va, g.sigma_a[k], g.mu_a[k]);   // albedo（对角）
    e += mahalanobis2(vn, g.sigma_n[k], g.mu_n[k]);   // 法线（对角）
    e += (r - g.mu_r[k]) * (r - g.mu_r[k]) / (g.sigma_r[k] * g.sigma_r[k]);
    return __expf(-0.5f * e);
}

// 可分离剔除：先做廉价的 1D（roughness）早期拒绝
__device__ __forceinline__ bool reject_early(float r, const Gaussians13D& g, int k)
{
    float d = (r - g.mu_r[k]) / g.sigma_r[k];
    return (d * d) > kEarlyRejectThreshold;   // 1D Mahalanobis，代价极低
}

// 3D 保守 Mahalanobis（tile 包围盒测试）
__device__ __forceinline__ float conservative_mahalanobis(
    const float3 center, const float3 half_extent,
    const float3 mu, const Mat3 inv_sigma)
{
    float d_center = mahalanobis2(center - mu, inv_sigma);
    // 减去中心到最远角点的最大距离（保守下界）
    float d_corner = mahalanobis2(half_extent, inv_sigma);
    return d_center - d_corner;
}
```

## 实验结论

- **数据集**：6 个实拍室内场景（living room / bedroom / dining room / veach ajar / staircase / chair / rings）。
- **硬件**：单张 **RTX 4080 SUPER**。
- **基线**：**Neural Radiosity**（Hadadan et al. 2021），含两种特征编码——Müller et al. 的**多分辨率哈希网格** 与 Su et al. 的**顶点特征**（顶点特征为 SIGGRAPH Asia 2025 论文），训练 1.5–4.5 小时。
- **结果**：

| 场景 | GLT 高斯数 | 模型大小 | 训练时间 | FLIP（GLT） | FLIP（NR 哈希网格） | NR 哈希网格模型 |
|------|------------|----------|----------|-------------|---------------------|----------------|
| living room | 38.4K | 5.8 MB | 11m30s | **0.1177** | 0.1326 | 35.7 MB |
| bedroom | 28.7K | 4.4 MB | 10m48s | **0.0824** | 0.0967 | 35.7 MB |
| dining room | 35.2K | 5.4 MB | 9m17s | **0.0831** | 0.2455 | 35.7 MB |
| veach ajar | 27.1K | 4.1 MB | 12m08s | **0.0641** | 0.1978 | 35.7 MB |
| staircase | 42.2K | 6.4 MB | — | — | — | — |
| chair | 28.2K | 4.3 MB | — | — | — | — |
| rings | 6.5K | 1.0 MB | — | — | — | — |

- **训练加速**：**10.0–23.4×**（vs NR）。
- **渲染加速**：**2.2–4.5×**（vs NR）。
- **内存**：仅 **1.0–5.9 MB**（NR 哈希网格恒为 35.7 MB；NR 顶点特征 0.9–26.4 MB）。
- **渲染帧时**：**10–17 ms @ 1 spp，1920×1080，单张 RTX 4080 SUPER**。
- **渲染质量**：64 spp、1920×1080；能捕捉 **焦散、镜面/光泽表面、纹理**。
- **优化设置**：所有场景统一 **30K iterations**。

## 局限性

- **半梯度优化**引入未量化的偏差（第三方评述指出这是主要隐忧）。
- **弱局部**分解（忽略跨子空间相关性）对收敛质量影响「相对很小」——是工程折中，非零代价。
- **需要路径追踪器生成训练数据**（Mitsuba 3）→ 无法用于无法离线烘焙的动态/交互式场景；训练仍需分钟级。
- 采样训练分布依赖适配过的 PDF `p(x, ω)`，换场景需重新适配。
- 渲染的 GS 模式在**镜面/焦散**处的表现依赖 MC 模式（GS+MC）的采样数。

## 实现建议

- **实现难度**：**高**（理论部分中等，剔除策略部分是真正的难点）。
  - 训练侧：半梯度残差最小化 + split/spawn/prune 调度，规模可控；
  - 渲染侧：**世界空间 Morton tile + 13 维保守包围盒 + 可分离剔除**，需自行实现 BVH/tile 数据结构。
- **预期性能**：
  - 训练 10–23× 快于 Neural Radiosity（分钟级）；
  - 渲染 10–17 ms @ 1080p 1 spp（≈60–100 FPS），2.2–4.5× 快于 NR；
  - 模型 1–6 MB（比 NR 小一个数量级）。
  - **FLIP 全面优于 NR**（尤其 dining room 0.0831 vs 0.2455，差距 3×）。
- **适用场景**：
  1. **离线烘焙的全局光照缓存**（游戏/影视资产的一次性 GI 求解，分钟级、兆字节级、可实时查询）；
  2. 需要**视角无关**的 GI（一次求解，多视角复用）；
  3. 作为**神经辐射缓存的替代方案**——显式高斯混合 vs 隐式网络，可解释性与内存都更优。
- **行动建议**：**推荐实现**。这是本期**最值得落地的论文**：
  - 它给出的是一条**「解方程而非拟合图像」**的第三路线——与 3DGS/NeRF 的「拟合图像」路线正交；
  - **「世界空间 Morton tile + 保守包围盒剔除」是可直接迁移到任何高斯/神经表示渲染器的通用加速手段**（不限于本文模型）——**优先级：高**；
  - **「可分离协方差 → 可分离剔除」**的工程思路对任何需要大量高斯求值的场景（3DGS 渲染器、辐射缓存）都有参考价值，**优先级：高**；
  - 完整模型复现优先级：**中高**（需自建路径追踪训练数据管线 + 剔除数据结构）。
