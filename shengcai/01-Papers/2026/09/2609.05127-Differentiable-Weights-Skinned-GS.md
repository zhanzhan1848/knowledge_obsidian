# Differentiable Weights for Skinned Gaussian Splat Deformation

## 基本信息
| 项目 | 内容 |
|------|------|
| 作者 | Nina Vesseron |
| 发表 | arXiv cs.GR |
| 链接 | [arXiv:2609.05127](https://arxiv.org/abs/2609.05127) |

## 核心贡献
1. **完全无网格变形流程**：使用 skinning weights 的空间梯度为 Gaussian Splats 提供完整的无网格变形管道
2. **拉伸问题解决**：更准确地拉伸 splats，同时保持与实时渲染能力的完全兼容性
3. **WebGL 查看器演示**：在 WebGL 查看器中实时渲染演示
4. **自适应重采样**：可选的自适应重采样方案，分裂仍然产生伪影的 splats

## 技术方案

### 问题背景
- 3DGS 不提供连接信息，刚性变换点不足以防止拉伸时产生孔洞
- 现有方法对 mesh 的 skinning deformation 无法直接应用于 Gaussian Splats

### 解决方案
- 利用 skinning weights 的空间梯度
- 评估用户创建 rig 结构时这些梯度的计算方式
