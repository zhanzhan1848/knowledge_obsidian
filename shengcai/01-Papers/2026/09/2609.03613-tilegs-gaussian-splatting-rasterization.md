# Tile-Local Depth Binning for Gaussian Splatting Rasterization

## 元信息

|------|---------------------------------------------------------------|
| 作者 | Wei Tan |

| PDF | [pdf](https://arxiv.org/pdf/2609.03613) |

## 核心贡献
1. **Tile-Local重组织**：将长tile范围转换为短深度局部范围序列
2. **前向顺序光栅化**：按深度从前到后光栅化这些范围
3. **选择性修复**：在粗排序不足以匹配基线合成时应用选择性修复

## 技术方案

### 问题背景
标准3DGS光栅化遍历全局排序的tile流，创建长的per-tile范围和大量几何属性传输。

### TileGS方法
```
全局tile范围 → 深度局部范围序列 → 前向顺序光栅化 → 选择性修复
```

### 性能结果 (RTX 4090)
- 光栅内核加速：**1.44x**
- 端到端帧加速：**1.069x** (RTX 4090) / **1.094x** (RTX 1000 Ada)
- PSNR差异：< 0.001 dB
- SSIM差异：< 0.001
- LPIPS差异：< 0.001

### 性能分析
- SM吞吐量降低但更快
- 活跃warp占用率降低但更快
- DRAM流量增加但更快
- 总SASS线程指令减少1.26x
- 几何属性占光栅流量的85.8%

## 关键洞察
TileGS通过**减少有效光栅遍历工作**提升性能，而非减少字节量、改善合并、提高占用率或直接减少warp分歧。
