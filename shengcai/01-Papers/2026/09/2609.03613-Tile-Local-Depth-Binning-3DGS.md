# Tile-Local Depth Binning for Gaussian Splatting Rasterization

## 基本信息
| 项目 | 内容 |
|------|------|
| 作者 | Wei Tan |
| 发表 | arXiv cs.GR |
| 链接 | [arXiv:2609.03613](https://arxiv.org/abs/2609.03613) |

## 核心贡献
1. **TileGS**：将 Gaussian splatting 重组织为 tile-local 结构
2. **深度局部范围排序**：将每个长 tile 范围转换为较短的深度局部范围序列，以前向顺序光栅化这些范围
3. **选择性修复**：在粗排序不足以匹配基线合成时应用选择性修复

## 技术方案

### 性能结果（RTX 4090）
- 默认 No-GW 变体：平均 1.44x raster-kernel 加速
- 端到端帧加速：1.069x (RTX 4090), 1.094x (RTX 1000 Ada)
- 输出质量与 gsplat 匹配：|ΔPSNR| < 0.001 dB, |ΔSSIM| < 0.001, |ΔLPIPS| < 0.001

### 关键发现
- TileGS 通过减少有效光栅遍历工作来提高光栅性能，而非减少字节量、改善合并、提高占用率或直接减少测量到的 warp 分歧
- 几何属性主导剩余内存压力（光栅总流量的 85.8% 和多余扇区的 88.6%）
