## 核心贡献

> **角色体型变了，姿态就会穿模。** 躯干变宽、肢体变粗，原本合法的动作会让手插进胸口、手臂穿过腹部。本文给出**免训练（training-free）的实时后处理**：先做姿态修正，再做有界的皮肤压缩。

1. **两层可插拔架构**：**Layer 1 顶点级姿态层**（局部二次规划，纯 C、单 CPU 核）+ **Layer 2 无状态接触变形器**（作用在宿主的最终蒙皮网格上）。
2. **模型无关的宿主接口**：只需「原生角色包」与「目标角色包」兼容，**无需访问模型内部**；角色包离线由绑定与蒙皮构建，**不含训练**。
3. **部件相关的软组织预算**：在姿态与皮肤之间**用静态约定分配修正量**；源穿模**不贡献额外余量**（防止误差累积）。

## 技术方案

### 核心思想

**「姿态优先、皮肤兜底」的分层修正**：
- **Layer 1（姿态层）**：在加性指数坐标增量空间解一个**盒约束凸 QP**，用 hinge 项表达穿透与接触的**软代价**，用部件盒约束表达**硬约束**。
- **Layer 2（皮肤层）**：在宿主完成蒙皮之后，用接触变形器做**几何压缩**（无摩擦、无弹性动力学、无体积守恒）。

### 局部目标函数

**盒约束 QP**：

$$\min_{\underline{x}\le x\le \overline{x}}\;\frac{1}{2}x^{\top}Hx+g^{\top}x+\frac{1}{2}\sum_{r}\omega_{r}[b_{r}-A_{r}x]_{+}^{2}$$

> 每个 hinge 引入一个上界为 $b_r - A_r x$ 的非负松弛量 → 构成凸 QP。实现中**直接求值 hinge**。
> **碰撞与接触是软代价；部件盒在本次求解内是硬约束。**

**角度部分**（$d$ 为上一帧残差，$x$ 为本次增量，残差为 $d+x$，**不是两次增量旋转的复合**）：

$$E_{\rm ang}(x)=\frac{1}{2}\Big(w_{r}\|d+x\|_{W}^{2}+m(u)w_{v}\|x\|_{W}^{2}+m(u)w_{a}\|x-(d-d^{-})\|_{W}^{2}\Big)$$

**笛卡尔部分**（末端执行器 $e$，$r_e = p_e(d)-p_e(0)$，$J_e$ 为 $d$ 处雅可比）：

$$E_{\rm cart}(x)=\frac{1}{2}\sum_{e\in\mathcal{E}_{p}}w_{e}\|r_{e}+J_{e}x\|^{2}+\frac{m(u)}{2}\sum_{e\in\mathcal{E}_{c}}\Big(w_{pv}\|r_{e}+J_{e}x-r_{e}^{-}\|^{2}+w_{pa}\|r_{e}+J_{e}x-2r_{e}^{-}+r_{e}^{--}\|^{2}\Big)$$

> $\mathcal{E}_p$ = 踝、脚、腕；$\mathcal{E}_h$ = 腕；$\mathcal{E}_c$ = $\mathcal{E}_p$ + 肩 + 肘。
> $r_e^-, r_e^{--}$ 是**前一次修正输出处的实际残差**（含输入姿态的变化）。

**权重矩阵**（$W_j = \nu_j c_j I_3$，脊柱/颈节点乘子 $c_{\rm spine}$）：

$$(\nu_{1},\ldots,\nu_{21}) = (2,2,8,2,2,8,3,3,8,3,3,8,4,4,8,1,1,1,1,2,2)$$

> **脊柱/颈节点组 $\{3,6,9,12,15\}$ 的残差代价显著更高**（$\nu=8$）——这正是「躯干不许乱动」的结构性表达。

### 穿透行：软组织预算

**最近顶点 / 法平面测试**（不是网格有符号距离场）：

$$g_{ab}=\begin{cases}\phi, & o_a\le r_n \ \text{且}\ \phi-D_{\mathsf{p}(b)}>0\\ d_{ab}, & \text{否则}\end{cases},\qquad B_{ab}=\rho_{\mathsf{p}(a),\mathsf{p}(b)}(s_a+s_b)$$

其中 $R_s=0.04$、$r_n=0.012$、$\eta_n=0.7$；$o_a$ 为查询点到碰撞部件 AABB 的欧氏距离；$\phi=(c_a-c_b)^{\top}n_b$。

> **关键性质**：被拒绝的负平面会变成**正的欧氏距离**。软厚度只抵消负间隙，**不放大正间隙**。

**源穿模不额外放行**：

$$a_{t,k}=a_{k}^{0}+\sigma_{\rm src}[-e^{s}_{t,k}]_{+},\qquad a_k^{0}=\begin{cases}0.04, & \zeta_k=6\\ 0.003, & \text{否则}\end{cases}$$

> **冻结参数中 $\sigma_{\rm src}=0$** —— 即源穿模**完全不贡献额外余量**。这防止了「复制动作自带穿模 → 系统给它更多空间 → 误差逐帧累积」的恶性循环。

### 求解器：坐标下降 + 保护性 Newton

- 原生求解器做 **8 次循环 sweep**（从零投影入盒开始）
- 逐坐标的一维导数与曲率：

$$f_i^{\prime}(z)=h_i+H_{ii}z-\sum_{r:\,r_r-A_{ri}z>0}\omega_r A_{ri}(r_r-A_{ri}z)$$

$$f_i^{\prime\prime}(z)=H_{ii}+\sum_{r:\,r_r-A_{ri}z>0}\omega_r A_{ri}^{2}$$

- 每个坐标**至多 8 次保护性 Newton 更新**，在 $[\underline{x}_i-x_i,\ \overline{x}_i-x_i]$ 内**括住标量最小值**
- 提议的坐标变化若使目标函数增量超过数值容差则被拒绝；接受后**增量更新** $Hx+g$ 与每个 hinge 残差
> **所有求解迭代都满足盒约束；固定 sweep 次数并不声称收敛到精确 QP 最小值。**（作者诚实标注）

### 皮肤层：加权平面接触变形

对 patch 质心 $q$，在局部搜索范围 $R_d=0.12$ + patch 半径内找最近对立顶点。宽对立面用**加权平面**，手部保留**精确最近点与法向**。

$$K(z)=(1-z)^{3}(1+3z)\,\mathbf{1}_{0\leq z<1}\qquad\text{(Cubic Hermite 型衰减)}$$

$$\bar{c}=\frac{\sum_j K(z_j)c_j}{\sum_j K(z_j)},\quad \bar{n}=\frac{\sum_j K(z_j)n_j}{\|\sum_j K(z_j)n_j\|},\quad \bar{s}_B=\frac{\sum_j K(z_j)s_j}{\sum_j K(z_j)}$$

**逐成员权重**（$\phi_i$ 为成员相对 patch 质心沿法向的偏移，$f_i=[-n_i^{\top}\bar{n}]_{+}$ 为背面项）：

$$\lambda_i=f_i^{2}\mu_{ik},\qquad w_i=\exp(-\phi_i/t_d)\lambda_i,\qquad t_d=0.004$$

其中 $\mu_{ik}$ 为部件对缝掩码（seam mask）。

### 关键技术

| 技术 | 说明 |
|------|------|
| Epoch 无关的两层管线 | 姿态修正（QP）→ 皮肤压缩（几何变形） |
| 加性指数坐标增量 | 残差是 $d+x$ 而非旋转复合 → 线性化简单 |
| 盒约束凸 QP | 部件盒为硬约束，穿透/接触为软 hinge |
| 坐标下降 + 保护性 Newton | 每坐标至多 8 次更新括住标量最小值，增量更新梯度 |
| 部件相关软预算 | $\rho,\rho_h,\rho_f$ 区分手/前臂/其他 |
| 源穿模零放行 | $\sigma_{\rm src}=0$ 切断误差累积链 |
| 加权平面接触变形 | Hermite 衰减 + 背面项 + 缝掩码加权 |
| 脏区（dirty region）跳过 | 干净且未激活的帧在原生接口上**帧精确直通** |

## 实验结论

- **数据集**: 320 个未见过的动作片段 × 3 种体型
- **主结果**: 手—躯干穿透深度 > 20 mm 的帧比例
  - 复制原动作：**15.53%**
  - 本文处理后：**0.00%**
  - 全部帧的最大穿透深度 **9.3 mm**
- **性能**: 平均姿态层 **1.11 ms**，皮肤层 **1.18 ms**，合计 **2.29 ms**（亚帧级）
- **动作保真**: 关节速度高频比（中位数）相对复制目标动作 = **1.008**（几乎未引入抖动）

## 局限性

1. **无可行性证书**：穿透与 pull 是软代价，求解器用固定工作量，**不能保证消除任意深度或全局交叉**。
2. **仅局部修正**：采样最近顶点法平面只是碰撞代理；预设的部件对**不覆盖所有可能的相交**。
3. **根平移、绝对解剖学关节限制、平衡、环境接触都在修正问题之外**。
4. **不受控的局部旋转（含手指）被直接复制**，虽然其世界变换继承被修正的祖先。
5. **皮肤压缩是纯几何的**：无摩擦、无弹性动力学、无体积守恒。
6. **静态预算约定不传递剩余余量**：姿态层用部件相关比例与固定对余量，皮肤层用全局比例且独立检测接触。
7. **模型无关不等于零准备**：仍需为运动模型提供原生角色包、为每个皮肤提供目标包，两者都必须提供兼容的语义关节与碰撞对。
8. **Layer 1 使用采样几何 + 截断蒙皮影响** → 宿主若使用不同蒙皮或附加形变，产生的表面可能不同。Layer 2 直接观察提供的最终顶点。
9. **布料厚度/顺应性只修改选定的姿态碰撞测试**；既不模拟服装，也不改变 Layer 2 的身体皮肤预算。
10. **短前瞻会引入缓冲延迟**，且只检查目标端点而非整条中间轨迹。

## 实现建议

- **实现难度**: **中**（纯 C、坐标下降、盒约束 QP，无需 GPU；但 QP 部分的边界处理细节多）
- **预期性能**: 单核 CPU，**2.29 ms/帧**（亚帧）；深度模态无 atomic，LiDAR 类场景才需 atomicAdd
- **适用场景**:
  - **动作重定向 / 体型变更后的姿态修复**
  - 任何「生成动作 → 蒙皮 → 渲染」管线中的**最后一道清洗**
  - 实时角色系统（VR/游戏）中防止穿模
- **落地路径**:
  1. **作为后处理模块**挂在「蒙皮输出 → 渲染」之间，**不改动作生成器**（这是本文最大的工程价值）
  2. **角色包离线构建**（从绑定 + 蒙皮生成），运行时零训练
  3. 复用本文的**「软预算 + 源穿模零放行」**约定，防止长序列误差累积
  4. **脊柱/颈节点残差权重放大**（$\nu=8$）是可直接照搬的廉价先验
