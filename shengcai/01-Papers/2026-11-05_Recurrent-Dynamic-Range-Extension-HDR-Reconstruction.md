## 核心贡献

> **先学一个简单任务——把裁剪图的动态范围「扩展 1 档曝光（1 EV）」**，然后**递归执行**该网络来恢复完整 HDR。任务**曝光不变**、**输出域有界**（$[0,2]$），因此可以**用海量 RAW 数据训练**（而非稀缺的曝光 bracketing HDR 数据），再叠加**循环训练**从真实 HDR 中学到高光的连续分布。

1. **单 EV 扩展任务**：裁剪线性图 $I_L\in[0,1]$ → 扩展图 $I_E\in[0,2]$。**与输入的名义曝光值和初始动态范围无关**（曝光不变），**输出有界**（设计使然）。
2. **线性空间训练**：输出域有界 → **无需压缩目标域**，可直接在**线性空间**训练，不会梯度爆炸；从而能使用**常见的感知损失**（LPIPS + GAN）增强真实感。
3. **RAW 数据当训练源**：RAW 虽不含完整动态范围，但保留了远多于 8-bit LDR 的辐射信息；利用曝光不变性，**从单张重曝光 RAW 照片导出多组训练对** → 训练分布大幅丰富，泛化到野外照片。
4. **Memory Replay 支持循环训练**：把 NLP 领域的 Memory Replay 策略**迁移到图像域**，使**全 ResNet 架构能跨多个推理阶段反传**而不牺牲分辨率或网络容量。
5. **推理时步数自适应**：由内容决定——当输出最大值不再触及阈值 1.8 时停止。**平均执行 5 步，动态范围档数翻倍以上**。

## 技术方案

### 核心思想

**数据瓶颈**：HDR ground truth 通常靠**多曝光 bracketing** 获得 → 需要静态场景、精确对齐、三脚架固定 → 耗时且易错，导致真实 HDR 数据**稀缺且多样性不足**。

**解法（任务分解）**：把「重建完整动态范围」这个**无界目标域**问题，分解成一串**有界的 1 EV 扩展**问题。

**关键设计对比**：
- 既有多曝光方法（DrTMO / Multi-Exp Gen. / CEVR / DiffSyn / GaSLight / BracketDiffusion / LEDiff）：**生成不同曝光的 LDR 再合并** → 学到的不只是填补像素，还会**主动移除有效内容**去造新的欠曝/过曝区（由 cycle-consistency 损失鼓励）→ 在 SI-HDR 等 HDR 基准上反而不如直接回归方法
- 本文：**渐进扩展动态范围**，每步减少歧义，**不移除有价值信息**

### 关键技术

| 技术 | 说明 |
|------|------|
| **单 EV 扩展网络** | 裁剪线性图 $I_L\in[0,1]$ → $I_E\in[0,2]$。网络恢复被饱和像素的值；**若高光超出新上界则仍保持裁剪**（渐进式） |
| **曝光不变性** | 输出范围与输入的名义曝光值、初始动态范围无关 → 同一模型可处理不同曝光的输入，**按场景自适应**而非按步数用专用集成 |
| **推理循环** | 每步输出**除以 2** 后作为下一步输入，重复直到无裁剪（输出最大值 < 经验阈值 1.8） |
| **软掩码混合** | 用 $M=\max(0,I_L-0.5)/0.5$ 把结果**线性混合回输入图像**，补偿阴影区的重建伪影 → 最终 HDR 估计 $\hat{I}_H$ |
| **对抗监督** | 遵循 Huang et al. 2024（NeurIPS, "The GAN is dead; long live the GAN!"）的方案；**两个判别器** $\mathcal{D}_E$（保证 $I_E$ 真实）与 $\mathcal{D}_R$（保证 $I_R$ 合理）；$\mathcal{D}_E$ 以输入图 $I_L$ 为条件 |
| **RAW 数据增强** | 现代传感器 14-bit 处理的 RAW 提供比最终 LDR 更宽的动态范围；经颜色再现后即可作扩展训练目标；**从单张 RAW 导出多个训练对** |
| **循环训练** | $I_E^n=f(\psi,I_E^{n-1})$，每步中间预测都由对应 HDR GT 监督；梯度**贯穿整条推理链反传** → 权重更新反映早期误差对后续扩展的影响，模型学会**修正早期错误** |
| **Memory Replay** | 循环梯度计算超出常规 GPU 显存 → 迁移 NLP 的 Memory Replay（Wu et al. 2022）策略，大幅降低循环反传计算量，**不牺牲分辨率与网络容量** |
| **递增训练步数** | 从 $N=1$（单 EV 预训练）开始，每次 $N$ 加 1 并固定步数继续训练，重复 3 次至 $N=4$；每次增量后训 100 epochs。$N>4$ 时训练数据中有效像素不足以提供有意义的监督 |
| **完全卷积网络** | 与架构无关，可在高分辨率运行；**4K 图像高光重建半秒**完成 |

## 公式

**训练损失**：

```math
\mathcal{L}=\mathcal{L}_{LPIPS}+\mathcal{D}_{E}+\mathcal{D}_{R}
```

**单 EV 扩展映射**：

```math
I_{L}\in[0,1]\;\longmapsto\;I_{E}\in[0,2]
```

**递归执行（推理）**：

```math
I_{E}^{(n)}=f\big(\psi,\;I_{E}^{(n-1)}\big),\qquad I_{E}^{(n-1)}=I_{E}^{(n)}/2
```

**软掩码与最终合成**：

```math
M=\max(0,I_{L}-0.5)/0.5,\qquad \hat{I}_{H}=\text{blend}(I_{L},\;I_{E}^{\text{final}},\;M)
```

**停止条件**：

```math
\max(I_{E}^{\text{out}})<1.8
```

## 代码片段

```text
// 训练流程（论文 Sec 3）
Phase 1 — 单 EV 扩展预训练 (N=1)
  输入: 线性裁剪图 I_L ∈ [0,1]，来自 RAW 重曝光
  目标: I_E ∈ [0,2]（相差 1 EV）
  损失: L = L_LPIPS + D_E + D_R
  D_E 以 I_L 为条件

Phase 2 — 循环训练 (N=1→2→3→4)
  for N in [2, 3, 4]:
     重复应用网络 N 步，输出除以 2 后作为下一步输入
     每步中间预测 I_E^n 由对应 HDR GT 监督
     梯度贯穿整条链反传（Memory Replay 降低显存）
     训 100 epochs

// 推理
I = I_L
while max(I) >= 1.8:
    I = f(ψ, I) / 2
M = max(0, I_L - 0.5) / 0.5
I_H = blend(I_L, I, M)   # 软掩码补偿阴影伪影
```

## 实验结论

- **数据集**:
  - **训练**: 多个公开 RAW 集合（Dang-Nguyen 2015 / Bychkovsky 2011 / Chen 2018 / Hasinoff 2016 / Liang 2021 / Conenna 2019 / Prabhakar 2021）——**规模与多样性远超 HDR 数据集**
  - **评测**: **SI-HDR**（Hanji et al. 2022，户外为主）与 **BtP-HDR**（Bolduc et al. 2023，源自 Laval Indoor HDR，含明亮光源）→ 两者对本文与基线均为**零样本**（唯一例外：GaSLight 在 BtP-HDR 上训练过）
- **基线**:
  - 直接回归 HDR：HDR-CNN、ExpandNet、HDRUnet、Mask-HDR、Single-HDR、IntrinsicHDR
  - 多曝光生成 + 合并：DrTMO、Multi-Exp Gen.、CEVR、DiffSyn
  - 扩散模型微调：GaSLight、BracketDiffusion、LEDiff
- **评价指标**: 6 种
  - PSNR、VSI（在**感知均匀的 PU21 色彩空间**中计算，与人类偏好更吻合）
  - **HDR-VDP3**、**short VDP3**（模拟人类感知的 HDR 指标）
  - **ColorVideoVDP (CVVDP)**（额外关注 HDR 色彩还原）
  - **FLIP**（跨曝光计算重建误差，适合评估完整动态范围含明亮高光）
  - **PSNR-H (P-H)**（**专门评估高光区域**）
- **关键结果**:
  - **动态范围增益**（SI-HDR，输入 LDR 动态范围 256:1 = 8 档）：加上循环训练 + 完整 HDR 监督后，性能**显著变化**；**平均执行 5 个推理步，档数增加一倍以上**，**超过最强基线**
  - **高光特异性指标 P-H 上表现突出**：其他方法过早饱和或在玻璃反射高光处产生伪影；本文**忠实还原镜面高光亮度**，并同时可信地补绘裁剪区丢失的纹理
  - **定性案例（Glass）**：LDR 输入中书本封面的太阳反射高光与封面亮度差因裁剪丢失 → 基线**整体提亮整个裁剪区**、无法重现高光点，且因在压缩动态范围上训练而**过早饱和**，产生平坦灰区；本文**忠实匹配镜面高光亮度**，补绘纹理，并恢复封面与高光之间的对比
  - **对比扩散类方法**（DiffHDRSyn、LEDiff、GaSLight）：多曝光重建需多次推理，易累积误差与伪影
- **相对既有方法的定位**（作者论证）：
  - vs 生成式方法：生成能力代价是**大网络 + 分钟级推理 + 分辨率受限**；本文方法**架构无关、全卷积、线性域训练、4K 半秒**
  - vs 多曝光 LDR 生成：**不主动移除有效内容**，每步歧义更少
  - vs 循环训练先例：先前计算摄影的循环方法因反传负担而**限于低分辨率与浅循环**；本文用 Memory Replay 突破

## 局限性

- **训练步数上限 N=4**：$N>4$ 时训练数据中有效像素不足以提供有意义的监督信号
- **依赖 RAW 数据**：需要 RAW 采集能力；纯 8-bit LDR 数据无法提供扩展目标
- **仍是单图方法**：无多视图约束，深度线索完全依赖学习先验
- **循环推理的固有风险**：多次前向可能累积误差；本文用循环训练缓解但未根除
- **高光是「合理重建」而非「真实测量」**：本质仍是猜测，论文用 GAN 损失鼓励真实感而非保证物理正确
- **停止阈值 1.8 是经验值**：对极暗/极亮场景可能需要调整
- **阴影区仍可能有伪影**（用软掩码 $M$ 补偿，非真正解决）

## 实现建议

- **实现难度**: **中**（网络本身不复杂；难点在 **Memory Replay 循环反传**的工程实现与 RAW 数据管线）
- **预期性能**: 4K 图像高光重建**半秒**；平均 5 步推理；模型规模小（全卷积）
- **适用场景**:
  - ✅ **单图 HDR 重建 / 高光恢复**（计算摄影、影像后期）
  - ✅ 训练数据稀缺场景：**用 RAW 替代 bracketing HDR**
  - ✅ 高分辨率需求（4K+ 实时性）
  - ✅ 需要**不破坏原图内容**的曝光扩展（相比多曝光合并路线）
  - ❌ 需要物理精确的高光测量
  - ❌ 视频（逐帧处理，无时序一致性）
- **落地建议**:
  1. **「把无界目标域问题分解为有界子问题」是本文最通用的思想**：任何「输出域无界导致难训」的问题都可套用——先定一个有界的单步操作，再用循环覆盖全域
  2. **曝光不变性 → RAW 数据复用**是极高性价比的数据工程技巧：一张 RAW 可导出多组训练对，训练分布多样性直接翻倍
  3. **Memory Replay 从 NLP 迁移到图像**值得单独实现为工具：这是让「全 ResNet 跨多阶段反传」可行的关键，其他循环图像任务（视频超分、时序去噪）同样适用
  4. **PU21 空间的 PSNR/VSI + P-H（高光专属）**应纳入自建 HDR 评测——普通 PSNR 对高光质量的区分度很低
  5. 若只想拿「高光恢复」能力，**可直接复用论文的推理流程**（无需循环训练），精度会下降但速度快得多
