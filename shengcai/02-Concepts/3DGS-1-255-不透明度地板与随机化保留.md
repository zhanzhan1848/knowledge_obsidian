# 3DGS 的 1/255 不透明度地板与随机化保留

## 定义

标准 3D Gaussian Splatting 的 rasteriser 使用 **8-bit alpha 混合/写缓冲**，因此存在一个**量化地板**：

```math
\alpha < \frac{1}{255} \approx 0.0039 \;\Rightarrow\; \text{splat 被直接跳过 (discard)}
```

`.spz` 等紧凑格式同样以 8-bit 存储不透明度，低于 `1/255` 的值在**存储阶段**同样被截断为零。

## 核心原理

### 问题现象：薄层「整体可见、个体不可见」

对于**极薄**的半透明结构（如 CT 皮肤层的最外层软组织），**单个 cell/splat 的 α 全部低于地板**，但沿斜射线**许多个这样的 splat 累加起来**会形成一层可见的「纱 veil」。

若直接丢弃这些淡 splat，**整层都消失**——表现为外层软组织缺失、**肋骨透过皮肤层显示**。

> 定量证据（CTBakeGS）：skin-and-bone 传输函数的 wide view，去掉淡 splat 保留后 **PSNR 从 29.8 dB 崩到 23.8 dB**。

### 解法：随机化不透明度量化（stochastic opacity quantization）

**不直接丢弃淡 splat，而是以概率保留并抬高其不透明度**：

- 判据：`α_splat < α₀`（`α₀ = 0.01`，约为 2.5/255，是抗锯齿补偿后仍能高于地板的最小值）；
- 以概率 `p = τ_splat / τ₀` **保留**该 splat，其中 `τ_splat = -ln(1-α_splat)`，`τ₀ = -ln(1-α₀)`；
- 保留时把不透明度**抬高到 `α₀`**。

**关键性质：期望光学深度不变**：

```math
p\cdot\alpha_0
= \frac{\tau_{\text{splat}}}{\tau_0}\cdot\alpha_0
= 1 - \exp(-\tau_{\text{splat}})
= \alpha_{\text{splat}}
\quad\text{（在期望意义上）}
```

即：**总体的光学厚度保持不变**，但每个 splat 都能通过 8-bit 地板，且 splat 总数更少。

### 确定性

用 **cell 索引的哈希**（而非随机数流）决定是否保留 → 整个转换过程**可复现**。

## 公式

```math
\alpha_0 = 0.01,
\qquad
\tau_0 = -\ln(1-\alpha_0)
```

```math
p = \frac{\tau_{\text{splat}}}{\tau_0},
\qquad
\alpha_{\text{splat}}' =
\begin{cases}
\alpha_0 & \text{以概率 } p \text{ 保留} \\
0 & \text{否则}
\end{cases}
```

**相关：光学深度守恒的不透明度解析映射**（CTBakeGS，用于「体数据 → splat」转换）

高斯 splat 需要**伸出 cell 边界**以免产生缝隙/波纹 → 相邻 splat 重叠、光线穿过多个 → 必须缩放：

```math
\tau_{\text{splat}} = \tau_{\text{cell}}\cdot\frac{h^2}{2\pi s^2},
\qquad s = 0.55\,h
\quad\Rightarrow\quad
\alpha_{\text{splat}} = 1 - \exp(-0.526\,\tau_{\text{cell}})
```

其中 `s = 0.55h` 是「使间距为 `h` 的高斯点阵沿各轴光学深度恒定误差 <1%」的最窄宽度。

## 代码实现

```glsl
// 淡 splat 的随机保留（确定性：哈希 cell 索引）
float stochastic_opacity_keep(float tau_splat, float alpha0, uint cell_hash)
{
    float tau0 = -log(1.0 - alpha0);
    float p    = clamp(tau_splat / tau0, 0.0, 1.0);
    float r    = hash_to_float(cell_hash);   // 确定性哈希，非随机数流
    if (r < p) return alpha0;                // 保留：抬高到 alpha0
    return 0.0;                              // 丢弃
}
```
