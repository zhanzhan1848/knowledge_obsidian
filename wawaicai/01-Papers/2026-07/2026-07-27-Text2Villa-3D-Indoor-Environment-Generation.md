# Text2Villa: Hierarchical 3D Indoor Environment Generation

## 核心方法

**Text2Villa** - 基于物理感知的层次化 3D 室内场景生成框架。

### 关键创新点

1. **Macro Level: 建筑结构生成**
   - 多楼层数据集
   - 自回归布局生成器
   - 多边形边界 + 垂直连通性

2. **Micro Level: 物理感知摆放**
   - **Affordance-driven Physical-Semantic Scene Graph (A-PSSG)**
   - 物理支持表面、容纳空腔 → 节点属性
   - 几何 + 语义边约束

3. **约束闭环优化**
   - 几何碰撞检测引擎 + MLLM 语义推理
   - 观察-评估-修改机制
   - 解决：碰撞、浮空、容纳失败

### 技术流程
```
文本 → 建筑基础（多边形边界）
    ↓
A-PSSG 图约束
    ↓
物理感知闭环优化
    ↓
Mesh 碰撞解决
```

## 几何处理相关

1. **Mesh 碰撞检测**: 集成底层碰撞引擎
2. **浮空检测**: 物理定律强制
3. **网格修复**: 解决 penetrations
