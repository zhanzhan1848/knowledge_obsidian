# WildFab: Multi-Axis 3D Printing from Models in the Wild

## 核心方法

多轴 3D 打印几何处理框架。处理真实世界几何（常包含 solid-shell 组合和非流形结构），无需耗时的几何修复。

关键创新：**Hybrid query representation**
- **Neural UDF** (unsigned distance field) - 可微分表面距离和方向查询
- **Regularized GWN** (generalized winding number) - 表面定位和 solid-void 判断

## 算法要点

```
Pipeline:
1. Hybrid representation (UDF + reg-GWN)
   - UDF: 不同表面距离和方向
   - reg-GWN: near-surface ambiguity 解决

2. High-precision spatial toolpath computation
   - iterative projection between guidance-field level sets
   - reg-GWN gradient-magnitude ridges

3. Coarse-to-fine collision checking
   - UDF-based rejection: identify potential collisions
   - reg-GWN verification: accurate resolution

支持的输入类型：
- non-manifold parametric surfaces
- voxelized topology-optimization results
- implicit models
- raw scanned point clouds
- non-watertight meshes
```

## 复杂度分析
- 时间：需计算 UDF + collision checking
- 空间：UDF MLP + reg-GWN field
