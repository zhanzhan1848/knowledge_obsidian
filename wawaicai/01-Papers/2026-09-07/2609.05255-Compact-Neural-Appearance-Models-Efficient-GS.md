# Compact Neural Appearance Models for Efficient Gaussian Splatting

## 核心方法

比较 3DGS 中不同 appearance 模型（SH vs 新型球面模型），提出隐式替代方案：

- 使用 tiny shared MLP 解码 per-primitive latent codes
- 替代 3DGS 默认的 spherical harmonics (SH)

## 算法要点

```
对比评估：
1. Spherical Harmonics (SH) - 3DGS 默认
2. 近期球面 appearance 模型
3. 神经隐式表示 (本文提出)

神经表示优势：
- 最 compact: 192 bytes → 28 bytes per-primitive (3-degree SH)
- 优化加速 1.3x
- 重建质量提升

发现：
- recent spherical models 提供最佳 quality-efficiency trade-off
- MLP 方案最 compact 但效率略低

分析：
- appearance parametrization 对优化的影响
- expressive models 吸收非静态内容的趋势
```

## 复杂度分析
- 时间：tiny MLP 推理
- 空间：28 bytes/primitive (vs 192 bytes 3-degree SH)
