# Differentiable Weights for Skinned Gaussian Splat Deformation

## 核心方法

本文解决 3D Gaussian Splatting (3DGS) 在骨骼动画变形中的问题。传统方法对 Gaussian 点进行刚性变换，在拉伸时会产生空洞。作者提出使用**空间梯度权重**实现无网格变形：

1. **权重空间梯度** - 利用 skinning weight 的空间梯度指导 splat 拉伸
2. **自适应重采样** - 可选方案分裂仍产生瑕疵的 splats
3. **实时渲染兼容** - WebGL 展示

## 算法要点

```
关键创新：
- 梯度权重评估：用户创建 rig 时评估梯度
- 自适应重采样：split artifacts 仍存在的 splats
- mesh-free deformation pipeline
```
