# Improved 3D Gaussian Splatting via Truncated Gradient Updates

## 核心方法

Pacific Graphics 2026 论文。解决 3DGS 优化中的**梯度消失问题**：

- 远处像素对 Gaussian 属性的梯度衰减
- 导致场景重建次优

提出 **piecewise truncated gradient formulation**：
- 改善优化稳定性和初始化鲁棒性
- 适用于 static 和 dynamic Gaussian Splatting

## 算法要点

```
核心问题：gradient vanishing
- 远处 pixel 对 Gaussian primitive 的梯度消失

解决方案：piecewise truncated gradient
- 分段截断梯度更新
- 提升优化稳定性

额外贡献：
- 动态场景 benchmark 局限性分析
- 新的 synthetic 3D 动态场景数据集
```
