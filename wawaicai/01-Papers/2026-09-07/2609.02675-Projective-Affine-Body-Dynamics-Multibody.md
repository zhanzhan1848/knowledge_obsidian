# Projective Affine Body Dynamics for Multibody Systems

## 核心方法

GPU 并行多体动力学模拟算法。创新点：

将约束多体动力学重新表述为**变分形式**，使用 **peridynamic bonds** 连接仿射体。

## 算法要点

```
创新：
1. 变分形式 reformulation
   - treat system as affine bodies + peridynamic bonds

2. unified model:
   - affine body dynamics
   - constraints
   - contact

3. semi-implicit successive substitution method
   - 解决非线性优化的 global-local iterative manner

优势：
- 无需组装 global Hessian
- GPU 高效实现
- real-time 刚体/柔性体交互模拟
```

## 复杂度分析
- 时间：GPU 并行
- 空间：per-body 局部数据
