# LightBridge: Feed-Forward Generative Relighting for 3D Gaussian Splatting

## 核心方法

解决 3DGS 资产 baked-in illumination 问题。传统 inverse rendering 方法需要 per-scene optimization，效率低。

提出 **LightBridge**：
- 前馈生成框架，single pass 完成 relighting
- 无需 per-scene optimization

## 算法要点

```
核心创新：
1. Multi-Illumination Relighting Dataset
   - 成对 source/target observations

2. Latent Bridge Relighting Diffusion
   - latent space 中的 source-to-target transport
   - one-step 2D visual token extraction

3. Gaussian Propagation Transformer
   - point transformer with sparse image-to-point self-attention
   - point-to-image cross-attention
   - 避免 full attention over all image/Gaussian tokens

结果：competitive quality + single-pass prediction
```

## 复杂度分析
- 时间：single-pass (feed-forward)
- 空间：latent codes + transformer
