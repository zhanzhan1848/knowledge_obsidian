## 核心贡献

> 手内物体扫描（IHOS, In-Hand Object Scanning）用**消费级手机的单目视频**实现三维数字化，门槛极低、潜力极大，但**长期缺乏真实数据集与系统基准**。本文从头剖析该问题，并给出**数据集 + 位姿估计 + 表面重建**的完整方案。

1. **ToysRUs 数据集**：高质量数据集，**多样化的手办（figurines）**，由 **4K UHD 单目视频**拍摄
2. **SfM 位姿估计的两个关键瓶颈的识别**：① 相邻帧间**基线过小**；② 大视角、长距离帧之间**特征匹配稀疏**，再叠加**动态手部遮挡**加剧
3. **子序列 SfM + 迭代拼接**：在**足够角间隔**处采样的视频子序列上做 SfM，再把子轨迹**迭代拼接**成统一全局轨迹
4. **遮挡感知 2D 高斯泼溅（occlusion-aware 2DGS）**：引入不透明度渲染，并**在手部区域省略不透明度损失**
5. **全面超越基线**：在几何精度与光度保真度上显著优于**神经隐式表示**与 **3D 基础模型**

## 技术方案

### 核心思想

单目手内扫描的两大难点与对应解法：

| 难点 | 现象 | 解法 |
|---|---|---|
| **小基线** | 相邻帧相机位移小 → 三角化病态、SfM 退化 | **按角间隔采样的子序列**上做 SfM |
| **稀疏匹配** | 大视角/长距离帧之间对应点稀少 | **迭代拼接**多条子轨迹为全局轨迹 |
| **手部遮挡** | 手在物体前方，动态遮挡破坏静态场景假设 | **遮挡感知 2DGS**：不透明度渲染 + **手部区域不施加不透明度损失** |

**遮挡感知 2DGS 的关键**：手是**动态前景**，若把手也当作带不透明度的实体来优化，模型会把手"烙"进重建里。因此在**手部区域放弃不透明度损失**，让该区域的 alpha 保持透明（不贡献几何），只让物体区域参与不透明度优化。

### 关键技术

| 技术 | 说明 |
|------|------|
| **ToysRUs 数据集** | 多样化手办 + 4K UHD 单目视频 |
| **角间隔子序列采样** | 保证每段子序列内部有足够的**旋转/平移基线** → SfM 可解 |
| **子轨迹迭代拼接** | 把多段局部轨迹合并为统一全局轨迹；利用子序列间的**大视角重叠**做匹配 |
| **遮挡感知 2DGS** | 不透明度渲染（opacity rendering）；手部 mask 区域**不施加 opacity loss** |
| **表面重建** | 基于优化好的 2DGS 表示提取表面 |

## 实验结论

- **数据集**：ToysRUs（4K UHD 单目视频，多样化手办）
- **基线**：现有 IHOS 方法、**神经隐式表示**、**3D 基础模型**
- **结果**：在**几何精度**与**光度保真度**两方面**显著超越**上述基线
- **关键组件**：SfM 子序列策略 + 遮挡感知 2DGS

## 局限性

> ⚠️ 摘要未列局限性，以下为基于方法结构的推断（需正文核实）：

1. **仍是单目** → 尺度不可观测（需借助已知尺寸物体或额外先验）
2. **依赖子序列切分策略** → 角间隔阈值是超参，对不同运动速度/不同物体的鲁棒性需验证
3. **依赖手部分割** → 手部 mask 质量直接决定不透明度损失的施加范围；mask 失败即重建失败
4. **数据集规模与多样性有限** —— "多样化的手办"，但类别覆盖仍窄
5. **动态手部与静态场景假设的冲突** —— 遮挡感知 2DGS 是缓解而非根本解决

## 实现建议

- **实现难度**：⚠️ **中高** —— SfM 子序列切分与拼接有工程量，但**都是成熟技术的组合**（COLMAP + 位姿图优化）；2DGS 需要实现遮挡感知改造
- **适用场景**：**消费级扫描**（手机拍一圈手办）、AR 资产获取、个性化玩具/纪念品数字化、考古/藏品记录
- **预期性能**：SfM 部分在消费级算力上可行；2DGS 优化需 GPU
- **落地建议**：
  - **子序列 SfM 策略可独立复用** —— 即使不做手内扫描，"小基线 + 稀疏匹配"的通用单目视频位姿估计也直接受益
  - **遮挡感知 loss 的 mask 阈值要谨慎** —— 手部 mask 泄漏到物体表面会直接损坏几何
  - 若已有可靠的物体 mask，**可跳过手部建模**，把遮挡问题转化为已知前景/背景分离，流程显著简化
- **可视化建议**：建议并列展示「输入帧 + 深度图 + alpha 权重图 + 提取表面」，让手部区域在 alpha 上的失效一目了然

## 🤢 可行性分析：单目手内物体扫描

### 算法复杂度

- **SfM 部分**：每条子序列 $O(F_{\text{key}} \cdot F_{\text{ext}} \cdot R_{\text{BA}})$（$F$ = 帧数，$R_{\text{BA}}$ = 光束法调整代价），子序列数 $S$ → 约 $O(S \cdot F_{\text{sub}} \cdot \cdots)$
- **位姿拼接**：$O(S^2)$ 级别的匹配与图优化（实际用图优化近似）
- **2DGS 优化**：$O(N_{\text{GS}} \cdot T_{\text{iter}})$，$T_{\text{iter}}$ 典型 7k–30k
- **空间复杂度**：$O(N_{\text{GS}} + F_{\text{frames}})$ + SfM 特征与轨迹存储

### 实现难度

- **算法复杂度**：中（SfM + 图优化）、中高（遮挡感知 2DGS）
- **数值稳定性**：⚠️ 需注意 —— SfM 在小基线段会退化（必须靠子序列切分规避）；不透明度损失在 mask 边界处可能不稳定
- **依赖项**：COLMAP / SfM 库、2DGS 实现（需改造不透明度损失）、手部分割模型

### 推荐结论

⚠️ **谨慎评估** —— **工程上高度可落地**（全是成熟技术组合），但**单目尺度歧义**与**对手部 mask 的依赖**是硬约束。建议优先实现「子序列 SfM + 位姿图拼接」这一独立可复用的模块。
