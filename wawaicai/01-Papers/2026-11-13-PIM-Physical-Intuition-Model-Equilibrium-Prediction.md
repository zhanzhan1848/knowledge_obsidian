## 核心贡献

> 用**一次前向传播直接预测多物体交互后的平衡态网格**，取代自回归 rollout。与几何处理的关系在于：**用局部 KNN 注意力编码物体内部几何、用锚点跨物体注意力建模物体间交互、用"平移 + 逐顶点残差"双分支解码器输出变形后的网格**——是一套干净的"网格 ↔ 注意力"建模范式。

1. **直接平衡态预测**：从初始网格几何、运动学与物理属性出发，一次前向输出完整平衡态。避免 rollout 的**误差累积**与**长时延**。
2. **局部 KNN 注意力**：在**初始空间**固定的 KNN 图上做注意力，编码物体内部几何（局部形变结构）。
3. **锚点式跨物体注意力**：每个物体用**确定性 FPS** 采样初始几何锚点，目标顶点 attend 其他物体的锚点——把"物体级交互"压缩到少量锚点上，成本远低于全顶点互注意。
4. **双分支解码器**：分支 A 预测**物体级平移**，分支 B 预测**逐顶点残差位移**（减去物体内均值）。零初始化输出层，训练初期精确复现输入网格。
5. **三项监督**：坐标 L1、质心 L2、**边长保真损失**（edge loss）——后者是保持局部形状不畸变的关键，也是本文相对纯几何学习工作的亮点。

## 技术方案

### 核心思想

**问题**：从初始条件预测物体交互结果。现有方法的两个困境：
- **刚体级状态表示太粗**——无法表达局部形变
- **自回归 rollout**——误差随预测时长复合累积

**PIM 的定位**：不预测过程，只预测**终态**（平衡态）。这在几何处理上是典型的"几何 → 物理 → 几何"往返问题。

### 关键技术

| 技术 | 说明 |
|------|------|
| **输入编码** | 相对坐标 $r^0_{i,p}=x^0_{i,p}-c^0_i$、半径 $s^0_{i,p}=\|r^0_{i,p}\|_2$、中心 $c^0_i$、物体条件 $o_i$、场景条件 $g=[\mu^t_{surf},\mu^s_{surf},\mu^r_{surf},g_z/10]\in\mathbb{R}^4$，各经独立投影后融合 + LN |
| **局部 KNN 注意力** | 固定在**初始空间**的 KNN 图 $N_i(p)$ 上聚合；query/key 做 L2 归一化 ⇒ 余弦 logit，无温度缩放 |
| **锚点 FPS** | 每个物体 $j$ 从顶点 0 出发确定性 farthest-point sampling：$\pi_{j,l}=\arg\max_q \min_{r<l}\|x^0_{j,q}-x^0_{j,\pi_{j,r}}\|_2^2$，共 $a$ 个锚点 |
| **跨物体注意力** | 目标顶点 attend **所有其他物体**的锚点，消息 $Z^{cross}_i=\frac{1}{M-1}\sum_{j\neq i}Z_{i\leftarrow j}$，走残差更新 |
| **双分支解码** | $\Delta c_i=\mathrm{MLP}_c(\text{mean-pool}(H))$；$\Delta r_{i,p}=\mathrm{MLP}_r(H_{i,p})-\frac{1}{n_i}\sum_q \mathrm{MLP}_r(H_{i,q})$ |
| **零初始化输出** | 输出层零初始化 ⇒ 初始时 $\hat y_i=x^0_i$ |

### 公式

**最终顶点**

```math
\hat{y}_{i,p} = x^0_{i,p} + \Delta c_i + f\,\Delta r_{i,p}
```

**三项损失**

```math
\mathcal{L} = \mathcal{L}_{coord} + \lambda_{cen}\mathcal{L}_{cen} + \lambda_{edge}\mathcal{L}_{edge}
```

- $\mathcal{L}_{coord}$：逐顶点 L1（平均）
- $\mathcal{L}_{cen}$：物体质心 L2（按物体等权）
- $\mathcal{L}_{edge}$：KNN 边长变化与目标边长的 L1 差——**允许形变**（目标用终态网格的边长）

**评测指标**

```math
\epsilon_{vtx}=\frac{1}{\sum_i n_i}\sum_{i,p}\|\hat{y}_{i,p}-y_{i,p}\|_2,\qquad
\epsilon_{cen}=\frac{1}{M}\sum_i\|\hat{c}_i-c_i\|_2
```

$$
\epsilon_{edge}=\frac{\sum_{i,p}\sum_{q\in N_i(p)}|\ell^{pred}_{i,p,q}-\ell^{target}_{i,p,q}|}{\sum_i n_i k_i}
$$

## 实验结论

### 数据集（每个 MuJoCo 场景训练一个 PIM）

| 场景 | 物体数 | 顶点数 | 训练/验证/测试 |
|------|--------|--------|---------------|
| Flat（9 球 + 平面） | 9 | 5,778 | 30,000 / 1,000 / 1,000 |
| Bumpy（9 球 + 不规则面） | 9 | 5,778 | 30,000 / 1,000 / 1,000 |
| Jenga（8 块塔倒塌） | 10 | 2,116 | 40,000 / 2,000 / 2,000 |
| Deformable（2 刚性球 + 1 可变形盒） | 3 | 1,577 | 5,000 / 200 / 200 |

MuJoCo 时间步 0.002 s，前 0.05 s 施加外力。目标网格取终止时刻（Flat/Bumpy/Jenga ≤10 s，Deformable ≤8 s），当最大广义速度绝对值持续 0.2 s 低于 $10^{-3}$ 时提前终止。**受控 Flat 对比用固定 2 s 目标**。划分使用不相交的随机数流与独立种子；物体顺序与网格拓扑在场景内固定。样本按 Flat/Bumpy 的多次冲击、Jenga 的冲击倒塌、Deformable 的刚软接触且形变可测进行筛选。

## 局限性

1. **每个场景一个模型**：评估使用**场景特定模型**，固定物体对应关系与拓扑
2. **泛化到新物体数量、拓扑、更大形变仍未解决**——作者明确列为开放问题
3. **未来工作**：显式环境建模、联合多场景训练

## 实现建议

- **实现难度**：**中**。架构是标准 Transformer（local attention + cross attention + FFN），无自定义 CUDA kernel；难点在数据生成（需要跑 MuJoCo 采集终态网格）与 KNN 图的构建与预处理
- **数值稳定性**：**中**。几何量纲混杂——位移、米级误差、微米级边长误差同时存在，损失加权（$\lambda_{cen},\lambda_{edge}$ 从 (1,5) 到 (0.1,20)）对尺度敏感。作者报告的 $10^{-3}$ 边长误差量级说明尺度分离处理得当，但复现时需仔细校准
- **对几何处理的价值**：
  - ✅ **"局部 KNN 注意力 + 锚点跨物体注意力 + 平移/残差双分支"是一套可迁移的网格建模模板**，可直接用于网格变形预测、角色动画的接触驱动形变、碰撞后形变估计
  - ✅ **边长保真损失（edge loss）值得引入任何顶点级预测任务**——本文证明去掉它会造成 3.27× 的局部形状畸变，而顶点/质心误差几乎看不出来
  - ✅ **锚点 FPS 压缩跨物体交互**是物体数量多时的实用降本手段
  - ⚠️ 严重依赖**固定拓扑与固定物体顺序**——几何处理管线中这往往是硬约束，迁移需重新设计对应关系机制
  - ❌ 不适合需要**中间过程**（不只是终态）的场景
- **落地建议**：若目标只是预测交互终态（而非轨迹），PIM 的"一次前向"范式在延迟上是碾压性的（Deformable 场景 9,692× 于 MuJoCo）。但需为每个场景单独训练，**场景数多时维护成本高**——此时应评估作者提出的"联合多场景训练"方向
