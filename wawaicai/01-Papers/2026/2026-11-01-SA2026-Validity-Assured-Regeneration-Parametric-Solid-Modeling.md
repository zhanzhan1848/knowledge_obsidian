# Validity-Assured Regeneration of Parametric Solid Modeling

> 📌 **SA2026（papers_1665）**。这是一篇**CAD / 几何内核**方向的工作：特征参数化建模每次改参数都要**重放整条特征序列**（regeneration），能否**局部复用**已算结果？这篇的关键贡献不是"更快"，而是**「什么情况下复用的结果才是对的」—— 一个此前被忽视但足以产生错误模型的理论问题**。

## 技术概述

### 背景：特征建模与"再生"

**基于特征的参数化建模（feature-based parametric modeling）** 仍是**产品建模的主流方法**：

```
建模过程 = 一串带参数的特征（feature）
   例如：草图 → 拉伸 → 倒角 → 孔 → 阵列 …
   每个特征有参数（深度、半径、数量 …）

用户改参数  →  重放整条特征序列  →  得到新模型
                  ↑ 这就叫 regeneration（再生）
```

**为什么再生重要**：
> **「再生在模型编辑期间被频繁触发，因此其效率对产品设计至关重要。」**

**为什么这个问题在学术上被忽略**：
> **「尽管其实践意义显著，再生在学术文献中受到的关注有限。」**

⟹ 这是一篇**「把工业界常识问题理论化」**的论文 —— 这类论文在 SIGGRAPH Asia 这样的场合并不常见，也正因如此有独立价值。

### 问题核心：复用的"有效性"（validity）

**增量再生的思路**（工业界早已在用）：
- 改了一个孔的参数 ⟹ 只有这个孔之后的部分需要重算
- 前面的特征结果**可以复用**

**但"哪些结果可以复用"的判定本身就是难点**，而且：

> **「现有的、用于判定先前计算数据可否复用于再生的准则，可能导致错误结果，因此有效性至关重要。然而在先前的再生方法中，有效性很少被讨论或给出理论论证。」**

**这是本文的靶心**。翻译成具体表述：

| 概念 | 含义 |
|------|------|
| **Reuse（复用）** | 跳过重算，直接用上次的结果 |
| **Locality criterion（局部性准则）** | 判定"哪些先前结果可复用"的规则 |
| **Validity（有效性）** | 复用出来的结果是否**与完整重算一致** |

**核心风险**：
- 一个**看起来合理**的局部性准则 ⟹ 可能**静默地**产生错误模型
- **静默错误**是最糟糕的失败模式：在 CAD 里，一个错了几微米的孔可能直到出图或装配时才被发现

### 方法：有效性保证的再生

> **「我们提出一种有效性保证的方法，加速再生。具体而言，我们 (i) 提出了两个新的局部性准则，在其下……」**（摘要在此处截断）

**已知的方法骨架**：

| 要素 | 内容 |
|------|------|
| **(i) 两个新的局部性准则** | 判定"哪些先前计算结果可以安全复用"的规则 |
| **有效性保证** | 复用结果与完整重算**结果一致**（这正是要证明的命题） |
| **加速** | 在保证正确的前提下减少重算量 |

**「两个」准则的意义**：
- 一个**保守准则**（surely-safe）：只复用**肯定有效**的部分 ⟹ 加速有限但**绝不出错**
- 一个**激进准则**（possibly-safe）：复用范围更大 ⟹ 加速更多但需要**附加条件**才保证有效

⟹ **两个准则的组合很可能构成"可调的正确性-速度旋钮"**，这是这类工程论文的典型结构。

**摘要截断处的诚实说明**：准则的**具体形式**、**有效性的理论证明**、**加速比数值**、**实验规模**均**未获取到**。

## 复杂度与性能

- **摘要未给出**复杂度公式与实测加速比
- 可推断的复杂度结构：

| 环节 | 复杂度 |
|------|--------|
| **完整再生**（基线） | O(Σ 特征序列的操作代价) — 通常**各向同性布尔 + 修剪**主导，是重放链条中的主要开销 |
| **局部性判定的开销** | 应为 **O(特征数)** 或更低的**依赖图局部查询** ⟹ 判定本身必须**远便宜于**重算，否则收益被抵消 |
| **复用的收益** | 重算量从 O(全序列) 降到 O(受改动影响的后缀/子图) ⟹ 加速比 ≈ **受影响特征占比的反比** |
| **理论难点** | 有效性的**证明**往往涉及**特征之间的依赖关系传播**（改动一个草图可能影响后续所有引用它的特征）⟹ 需要**依赖图 + 影响传播分析** |

> **关键工程指标**应该是：**判定开销 / 被省下的重算开销**。若判定本身接近重算成本，方法无意义 —— 摘要未提供此对比。

## 数值稳定性

### ✅ 优势
- ✅ **有效性被显式论证** ⟹ 这是最本质的贡献：把「复用」从**工程经验**提升为**有证明的规则** ⟹ **理论上排除了静默错误**
- ✅ **两个准则给出可调性** ⟹ 「保守/激进」的分层让使用者可以按**错误代价**选择（原型设计用激进，出图用保守）
- ✅ **依赖关系是显式的**（而非隐式地藏在操作顺序里）⟹ 判定可以**局部化**，只需分析改动点**下游的受影响子图**
- ✅ **复用只改变计算顺序，不改变几何语义** ⟹ 只要准则正确，结果**与完整重算逐位等价**，这是最强的正确性承诺
- ✅ **契合 CAD 内核的既有架构**：许多内核（OpenCascade、ACIS）本来就有**依赖图 / 特征历史**⟹ 落地成本相对低

### ⚠️ 风险点
- ⚠️ **几何内核本身带浮点误差**：即使"有效"的复用，其结果与完整重算**也可能有微小浮点差异**（因为部分中间量来自不同计算路径）⟹ **"结果一致"是精确一致还是近似一致，摘要未澄清** ⟹ 这直接影响能否用于**制造级**输出
- ⚠️ **准则的保守性难以自动验证**：新算子（倒角、抽壳、打磨）可能**隐式依赖全局几何**（如"找到所有相切边"）⟹ **局部性准则的完备性很难证明**，实践中容易出现"漏了某个依赖"的漏洞
- ⚠️ **拓扑变化是全局性的**：某次编辑让特征**从相切变为相交**（或反之）⟹ 拓扑结构改变 ⟹ **之前缓存的"拓扑状态"（如边的配对、面的邻接）全部失效** ⟹ 这正是有效性问题最尖锐的地方，也是"必须论证"的难点所在
- ⚠️ **容差（tolerance）与布尔鲁棒性的耦合**：CAD 内核普遍使用**容差模型（tolerance）**⟹ 复用路径与重算路径在不同容差历史下可能产生**不同的容差传播** ⟹ 有效性的定义必须考虑容差
- ⚠️ **摘要信息不足，无法判断实用价值**：两个准则的**具体形式**、**加速幅度**、**实验模型规模**全部缺失 ⟹ 无法评估真实收益（工业界经验：特征序列越长加速越明显，但短序列上判定开销可能占优）

## 推荐结论

✅ **推荐**（工程价值明确，但非图形学核心议题）

### 理由
1. **补上了一个真实的理论空白**：「再生中哪些数据可复用」这个问题在工业界被大量实践、却在文献里**既无形式化也无证明** ⟹ 本文提出**两个局部性准则**并论证有效性，是**扎实的贡献**
2. **"静默错误"是这类系统里最贵的 bug**：CAD 用户信任模型 ⟹ 复用出错会导致**错误图纸 / 错误加工** ⟹ 用理论排除它，产业价值极大
3. **两个准则的分层设计**是正确的产品形态（可调正确性-速度），也说明作者理解工程语境
4. 与本库已有的 **Topology-First BRep Meshing**、**FlowAR（BRep 交错 AR）**、**SIGGRAPH2026-Autoregressive-BRep-Parametric-Surfaces** 共同构成本库的 **CAD / B-Rep 主题簇** ⟹ 本文是其中"**历史/重放**"这一环的重要补充
5. **对本库的启示**：几何工具链里的任何"增量/缓存/复用"设计，都应该像本文一样**显式论证有效性** ⟹ 这是可直接搬到我们自己的工具链设计上的工程原则

### 与相关工作的定位
- **vs 经典 CAD 内核的重放机制**（BRep 历史的重算、参数化重算）：这是**工业界实际做法**，本文是它的**理论化** ⟹ 关系类似"论文 vs 产品"
- **vs 依赖图 / 影响分析**（CAD 中的 dependency graph、feature graph 研究）：本文的局部性准则**建立在依赖关系之上**，但**给出的判定规则更细**
- **vs 拓扑优先 B-Rep 生成**（本库已有）：那一侧关注**如何生成拓扑正确的 B-Rep**；本文关注**参数改动后如何正确复用** ⟹ 互补
- **vs 几何内核的容差/鲁棒布尔研究**：内核侧解决"单次运算的正确性"；本文解决"多次运算间的**一致性**" ⟹ **两者都需要**
- **vs 通用增量算法 / 缓存一致性**：本文是**几何领域**的具体化，且**结论可证明**（比一般缓存一致性理论更强）

### 落地建议
- **直接价值**：若我们有 **CAD / 参数化建模 / B-Rep 工具链**，可参考其**依赖图 + 局部性准则**的判据设计，把"能复用多少"变成可预测的量
- **工程要点**：
  1. **先画依赖图**：每个特征声明它**依赖哪些几何量**（草图几何、拓扑、容差）⟹ 影响分析只在图上做
  2. **区分「几何依赖」与「拓扑依赖」**：拓扑依赖（如面-面邻接变化）常常比几何依赖传播得更远 ⟹ 保守准则必须把拓扑变化视为**全失效**
  3. **把容差历史纳入状态**：复用不仅要记录几何，还要记录**产生它的容差状态** ⟹ 否则容差漂移会静默破坏一致性
  4. **提供"全量重算"作为对比与校验**：在工具里保留一键全量重算，用**差分检测**验证准则的正确性 ⟹ 这是最有说服力的自我验证手段
  5. **准则分级暴露给用户**（保守/激进/自定义）⟹ 把正确性-速度的权衡交给用户
