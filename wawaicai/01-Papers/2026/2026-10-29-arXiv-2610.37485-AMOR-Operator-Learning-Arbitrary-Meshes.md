# AMOR: Adaptive Modal Operator Refinement for Operator Learning on Arbitrary Meshes and Irregular 3D Geometries

> 📌 面向**不规则网格**的几何数值算子学习方法。核心贡献是**把 FNO 的傅里叶谱卷积换成降阶基（reduced-basis）块**，从而摆脱对结构化网格的依赖 —— 这对**任意三角网格 / CAD 边界网格上的 PDE 求解**有直接价值。

## 技术概述

### 问题：FNO 的结构化网格假设在几何处理场景下不成立

Fourier Neural Operator（FNO）是算子学习的默认选择，但它的**傅里叶谱卷积依赖结构化（规则）网格**才能用快速张量核。

而**几何处理与科学计算的真实场景**恰恰相反：
- 网格是**三角网格 / 四面体网格 / CAD 边界网格**，不规则；
- 几何可能有**孔洞、复杂边界**。

→ FNO **无法直接套用**。

### 核心思想：用「降阶基块」替换「傅里叶谱卷积」

**AMOR (Adaptive Modal Operator Refinement)** 的做法：

| | FNO | AMOR |
|---|---|---|
| 谱参数化 | 傅里叶基（依赖结构化网格） | **降阶基块（reduced-basis blocks）** |
| 网格假设 | 需要规则网格 | **任意网格，直接可用** |
| 基的来源 | 固定（傅里叶） | **数据驱动** 或 **预先给定**（统一 encode/decode 接口） |
| 维度扩展 | 谱权重随模态数 m 增长为 **m³**（3D） | **无张量积维度依赖**，3D 下扩展性更好 |

关键设计：**统一的 encode/decode 接口**，使得「学出来的基」和「外部指定的基」可以互换 —— 这在工程上很重要，因为有时我们**已经有一个好的基**（例如来自几何构造的 POD 基、谱基、RBF 基）。

**理论保证**：论文证明了 AMOR 是**连续算子的万能逼近器**（universal approximator of continuous operators）。

## 关键结果

| 场景 | 结果 |
|------|------|
| **2D 结构化网格基准** | 与 FNO **整体相当**，**超过 PCANet**；在**非线性扩散**与**Helmholtz**问题上**优于 FNO** |
| **2D 时间相关 Kolmogorov flow** | ⚠️ **不如 FNO** —— 作者归因于「静态快照基（static snapshot basis）」的局限 |
| **3D 线性弹性静力学** | 精度**追平或超过 FNO**，且**推理成本更低** |
| **3D 湍流 lid-driven cavity** | ⚠️ **落后于 FNO** |
| **3D 高容量问题** | **扩展性明显更好**（得益于无 m³ 张量积依赖） |
| **不规则网格（vs Geo-FNO 扩展）** | 相对 L2 误差**降低 31%（机翼 airfoil）**、**降低 42%（弹性）** |
| **3D 拓扑非平凡飞机肋骨网格**（三种物理上不同、实验驱动的加载工况） | **持续保持强性能** → 证明对**真实复杂几何**的适用性 |

## 算法复杂度

| 项 | 分析 |
|----|------|
| **时间（训练）** | 降阶基块卷积，无张量积 → 相比 FNO 的 m³ 权重增长，3D 优势明显 |
| **时间（推理）** | 论文报告在 3D 线性弹性上**推理成本低于 FNO** |
| **空间** | 参数主要来自基的展开长度与基函数数量，**不随空间维数立方增长** |
| **关键工程优势** | 网格无关 → 不需要网格重采样 / 光栅化 / 邻接重排（这是 FNO 迁移到三角网格的最大工程成本） |

## 推荐结论

✅ **推荐收录**

**理由**：
- **「不规则网格 + 几何处理」正是我们的场景**。FNO 在三角网格上不好用，FEM 又慢 —— AMOR 填了这个空。
- **统一 encode/decode 接口**这一设计，说明这套方法**可以接入我们已有的几何基**（如谱基、特征函数基），工程价值高。
- 有代码 + 有数据，**可复现**。

**局限提示**：
- 时间相关问题（Kolmogorov flow）上**静态快照基不够** —— 若我们的场景涉及时变场，需要注意这个已知短板。
- 湍流问题上仍落后 FNO。

**推荐度**：⭐⭐ 推荐收录
