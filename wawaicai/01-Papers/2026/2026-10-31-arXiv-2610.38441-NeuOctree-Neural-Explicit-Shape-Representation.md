# NeuOctree: Neural Explicit Shape Representation

## 一句话总结

用**稀疏八叉树的体素角点共享特征** + **一个共享的轻量 MLP 解码器**，**直接预测「光线是否命中表面、命中位置、法向、反照率」**——既不需要网格提取、也不需要纹理烘焙，**同时支持逐物体压缩与跨物体前馈构建**（50 ms/次），是「神经隐式表示」与「光线追踪所需显式表面查询」之间的一座桥。

## 技术概述

### 问题：现有神经 3D 表示各有盲区

| 类别 | 代表 | 盲区 |
|------|------|------|
| 隐式场（SDF / Occupancy） | DeepSDF, Occupancy Networks | **密度/占用值不直接给出交点、法向、材质**，需额外表面定位或网格提取；level-set 形式**依赖 inside–outside 约定**，对开放/非水密表面不友好 |
| NeRF 系 | NeRF, Plenoxels, Instant-NGP | 同上，且是 radiance 场非表面场 |
| 神经网格压缩 | Neural Geometry Fields (NGF), Neural Progressive Meshes | 逐网格优化；**固定粗拓扑**；外观靠单独的 texture baking |
| 神经 BVH | **N-BVH** | **最接近**（直接预测光线求交 + 外观），但仍是**逐物体优化** |

**核心诉求三连**：
1. 光线追踪器需要**显式表面查询**（交点 + 法向 + 材质）
2. 需要**可跨物体共享网络**预测的结构化输出空间
3. 训练/压缩成本要低

### 核心思想：把「光线-表面求交」当作表示的**主接口**

> 不再把几何表示成「需要再解析的场」，而是**直接把它表示成一台可查询的光线求交器**。

#### ① 结构化神经表面表示

**稀疏八叉树 + 连续特征场**

- 从输入点云构建八叉树，保留**被占用的叶节点体素**
- 相邻体素**共享角点特征** ⟹ 角点即「唯一顶点特征」
- 在体素局部坐标 $\mathbf{q}\in[0,1]^3$ 处做**三线性插值**得到连续场：

$$\boldsymbol{\phi}_v(\mathbf{q})=\sum_{i,j,k\in\{0,1\}} w_{ijk}(\mathbf{q})\,\mathbf{f}_{v,ijk}$$

- 关键性质：**跨体素边界连续**（因为角点特征是同一份）
- 存储单元 = 顶点特征表（逐物体优化）或 octree CNN 的预测（前馈模式）

**光线查询解码器**（两个分支，权重在所有体素/光线间共享）：

$$(\mathbf{a},\mathbf{z},s_h)=G_\theta\big(\boldsymbol{\phi}_v(\mathbf{q}),\mathbf{q},\mathbf{d},\text{state}\big),\qquad \mathbf{c}=\sigma\big(M_\theta(\boldsymbol{\phi}_v(\mathbf{q}),\mathbf{q},\mathbf{d},\text{state})\big)$$

- $\mathbf{a}\in\mathbb{R}^3$：位置参数（ray-local）
- $\mathbf{z}\in\mathbb{R}^3$：归一化后作为**法向**
- $s_h$：命中 logit ⟹ $h=\sigma(s_h)$
- $\mathbf{c}\in[0,1]^3$：反照率
- $\mathbf{d}=\mathrm{norm}(\mathbf{p}_{\mathrm{out}}-\mathbf{p}_{\mathrm{in}})$：体素内局部光线方向

**位置参数化的两种形式**（重要工程细节）：

| 变体 | 公式 | 用途 |
|------|------|------|
| **段内参数化**（segment-bounded） | $\widehat{\mathbf{p}}=\mathbf{p}_{\mathrm{in}}+\alpha(\mathbf{p}_{\mathrm{out}}-\mathbf{p}_{\mathrm{in}})$，$\alpha=\sigma(\mathbf{a})_1$ | 前馈渲染配置 |
| **光线投影参数化** | 把预测局部点投影到当前光线**直线**上（开启段界限时投影到当前段） | 逐物体几何压缩协议 |

> ⚠️ 两种形式都保持同一个关键性质：**解码器预测的是「交点」而非「密度 level set」**。
> 报告配置**未使用 Fourier 位置特征**。

#### ② 递归相交精化（Recurrent Intersection Refinement）⭐

**问题**：只在体素边界采样，采样点可能离表面很远；且**边界点依赖视角**——同一表面点从不同视角进入体素的位置不同 ⟹ 迫使解码器学一个**不必要的视角相关映射**。

**做法**：用上一轮预测的交点来放置下一轮的查询位置

$$\mathbf{q}_{k+1}=\Pi_{\mathrm{ray}}(\widehat{\mathbf{p}}_k)$$

- $\Pi_{\mathrm{ray}}$：光线直线投影（或其段内受限版本）
- **pooled 变体**（用于报告的压缩与采样实验）：
  - 把 entry / exit 点当作普通特征集成员
  - 第一次内部查询初始化在**段中点**
  - 后续查询由前一次读出自适应放置
  - 每轮 hidden 增量**取平均**后由共享输出头预测最终属性
  - **3 次自适应迭代 ⟹ 每个体素段 5 次特征读取**（entry、exit、3 次自适应查询）
- 消融组使用**相同的解码器模块**，只把自适应位置替换为预定位置

**收益**（相对均匀采样）：位置误差 **-7.7%**，法向误差 **-9.4%**；相对仅端点采样：**-12.0% / -17.0%**。

#### ③ 前馈表示构建（Octree U-Net）

- 基座：**O-CNN**（Wang et al. 2017）的 octree-based CNN
- 编码器：**3D U-Net**（多尺度 octree 特征 + skip connection + octree 残差块）
- 输入：彩色点云 ⟹ 预测每个被占用体素的 **8 个角点槽位**
- **共享顶点聚合**：指向同一几何顶点的槽位**取平均** → 得到与逐物体优化**完全一致的共享特征场**
- 训练：特征提取器 + 解码器**联合**用渲染损失训练
- 额外可选：**体素局部残差特征** + 池化的输入颜色先验（材质分支用）

## 复杂度与性能

| 项 | 数值 |
|----|------|
| 八叉树遍历 | 跳过空体素 ⟹ 只在被占用体素上求值 |
| 每体素段特征读取 | **5 次**（3 次自适应迭代） |
| **前馈构建耗时** | **50 ms**（单资产，从彩色点云） |
| 前馈训练总成本 | **19.5 小时**（一次性，跨所有物体摊销） |
| 对比：N-BVH 逐物体拟合 | **约 3 分钟/物体** |
| 对比：VQAD 逐物体拟合 | **数十分钟/物体** |
| 前馈构建 vs N-BVH | **≈ 4200× 加速** |

## 实验结论

### 几何压缩（7 个网格 × 4 个存储预算 = 28 组）

- 网格：Armadillo, Buddha, Dragon, Einstein, Lucy, Metatron, XYZ-Dragon（Stanford 3D Scanning Repository + Thingi10K）
- 协议：16 个固定相机，512×512，60° FOV，相机距离 2.5（最长包围盒边归一化到 2）
- 指标：$d_{pm}$（归一化坐标下光线-表面位置误差 ×10³）、$d_{norm}$（有向法向误差，度）

**结果**：
- **24/28 组取得最低位置误差**
- 赢下 81–244 KiB 全部 **21/21** 组；823 KiB 赢 3/7（其余 4 组由 QNDF 拿下）
- **法向误差赢 12 组**；NGF 在最小预算上领先，QNDF 仅在最大预算上有竞争力
- **关键观察**：最强基线**随预算变化**（NGF 小预算强、QNDF 大预算强），而 NeuOctree 的位置精度**最稳定**

### 几何 + 外观联合压缩（30 Objaverse + 30 ShapeNet）

| 对比 | $d_{pm}$ 改善 | $d_{norm}$ 改善 | PSNR |
|------|--------------|--------------|------|
| 相对 VQAD（Objaverse） | **-85.5%** | **-37.8%** | **+1.11 dB** |
| 相对 VQAD（ShapeNet） | **-95.8%** | **-32.6%** | **+9.33 dB** |

- Objaverse：最佳法向精度 + 最佳 PSNR
- ShapeNet：**三项指标全部最佳**

### 开放表面重建（open glass pane，823 KiB）

- 设置：镜像正视相机对，反投影深度图，测面法向方向上的分离量 $d_z$
- **NeuOctree：$d_z = 0$**（与 GT 中位数一致）
- **VQAD：$d_z = 0.059$**（世界单位）⟹ 存在**系统性双侧偏移**
- ⟹ 验证「不需要 inside–outside 标注」的优势

### 前馈模型

- 训练：Objaverse 随机 32k 资产子集
- 测试：30 个未见 Objaverse + 30 个 ShapeNet
- Objaverse：位置误差远优于 VQAD，但 VQAD 在法向与 PSNR 上更强
- ShapeNet：**三项指标全面超过 VQAD**
- **跨数据集泛化**：Objaverse 训练 → ShapeNet 直接测试，**无需重训**即超过逐物体优化的 VQAD 与 N-BVH

### 应用

- **直接光线追踪渲染**：reshading、reflection、refraction、fisheye 投影，无需网格提取或纹理烘焙
- **原生 3D 生成**：稀疏八叉树 VAE 压缩节点特征 + flow-matching DiT 预测 occupancy 与 latent ⟹ 直接解码为可渲染几何与外观；支持图像条件生成

---

## 局限性（作者自述）

1. **高保真逐物体拟合仍然昂贵**（前馈是替代方案但精度有差距）
2. **只建模反照率**，不支持视角相关材质（BRDF）
3. **生成部分仍是概念验证**
4. 未来工作：加速八叉树构建、扩展到更丰富材质/光照/动力学、把 NeuOctree 作为 3D 生成模型的原生输出空间

## 实现难度与数值稳定性

### 算法复杂度
- **高**（但模块清晰）
  - 八叉树构建 + O-CNN 前向 + 递归解码 + 渲染损失联合训练
  - **不需要** per-object optimization 即可用（前馈模式）⟹ **上手门槛显著低于 N-BVH / VQAD**

### 数值稳定性
- ✅ **位置参数化天然把交点约束在光线（段）上** ⟹ 不会出现「预测点跑到光线外」的病态
- ✅ **不含 level set 求根** ⟹ 无符号翻转 / 零交叉问题
- ✅ **共享角点特征 + 三线性插值** ⟹ 跨体素边界连续
- ⚠️ **段内参数化下，跨越体素边界的真实交点可能被截断** ⟹ 依赖八叉树分辨率自适应（这是精度上限的主要来源）
- ⚠️ **递归精化存在收敛风险**：若首轮预测偏离很远，后续查询会持续偏离 ⟹ 论文用「3 次迭代 + pooled hidden 平均」作为折中，而非严格不动点迭代
- ⚠️ **前馈模式下角点槽位取平均**会引入几何-光学校准偏差 ⟹ 法向精度弱于逐物体优化（论文自述）
- ⚠️ **开放表面**虽然不用 inside–outside 标注，但**双侧一致性**仍依赖训练分布覆盖 ⟹ 极端薄片仍可能漂移

### 依赖项
- PyTorch + O-CNN（octree CNN）
- 八叉树构建：`o-cnn` / 自研（论文提到需加速构建，是未来工作）
- 渲染损失：需可微的光线求交渲染器（自研）
- 参考实现：**N-BVH**（同作者组的对立路线）、VQAD、NGF

## 推荐结论

⚠️ **谨慎推荐 / 观察项，但「表示层设计」值得单独借鉴**

### 理由
1. **最大价值在设计范式，而非模型精度**：
   - 「把光线-表面求交当作表示的主接口」这一思路，**跳出了「SDF → 网格提取」的二阶依赖**
   - 「共享角点特征 + 三线性插值」把**空间结构化的存储**与**神经化的局部解码**干净解耦 ⟹ 这是**可迁移的表示设计**
2. **对几何处理的意义**：
   - 它提供了一个**「既保留神经场灵活性、又保留显式表面可查询性」的第三条路**
   - 未来若要「生成 → 直接渲染」闭环（不落地网格），这是**当前最完整的方案**
3. **不建议整体复现的原因**：
   - 逐物体拟合路径与 N-BVH 复杂度相当，收益边际
   - 前馈路径精度尚不及逐物体方法
   - 生成部分仅概念验证
4. **落地建议**：如果我们的场景是「**网格 → 光追资产**」或「**需要处理非水密/开放几何**」，本文的开放表面双侧一致性实验（$d_z=0$ vs VQAD 的 0.059）**很有说服力**，值得做一个小型对照实验

### 对我们的启发
- **[[神经网格压缩]]** 的一条新路线：把「压缩」重新表述为「设计一个可查询的表示」
- **[[八叉树表示]]**：稀疏体素 + 共享角点 ⟹ 天然支持 LOD 与渐进式细化
- **[[光线表面求交]]**：把求交当作**一等公民接口**，而不是「先表示再求交」
- **[[开放表面与非水密几何]]**：level set 的 inside–outside 约定是硬伤；本文给出实证替代方案
- **[[递归采样精化]]**：用上一轮预测引导下一轮查询——这个模式可迁移到**任何「在连续场上定位特征」的问题**（如距离场极值定位）
