# Strips as Tokens: Artist Mesh Generation with Native UV Segmentation

## 核心方法

使用 **UV strips 作为 token** 实现原生 UV 分割的网格生成。

### 关键创新点
- **UV Segmentation First**：先分割 UV，再生成网格
- **Artist-Friendly**：符合艺术家工作流程
- **Native UV**：保持 UV 分割的原生性

## 关键词
- UV Segmentation
- Mesh Generation
- Artist-Friendly
- Strip-based

## 应用场景
- 游戏资产制作
- 影视特效
- 实时渲染
