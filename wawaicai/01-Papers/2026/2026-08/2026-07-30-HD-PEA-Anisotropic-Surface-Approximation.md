# Learning Manifolds in High-D Point Embedding for Anisotropic Surface Approximation from Unstructured Point Clouds

## 论文信息
- **arXiv ID**: [2607.28855](https://arxiv.org/abs/2607.28855)
- **作者**: Zichun Zhong et al.
- **日期**: 2026-07-30
- **会议**: -
- **主题**: 点云、各向异性曲面近似、高维嵌入、流形学习

## 核心方法

### 问题定义
密集 3D 传感器产生的点云在实时处理中具有几何冗余。现有方法难以高效处理大规模点云并保持几何保真度。

### 核心创新
1. **HD-PEA**: 高维点嵌入各向异性曲面近似框架
2. **高维欧几里得点嵌入**: 将输入点云映射到高维流形嵌入空间
3. **Patch-based Meta-embedding**: 无需重训练和微调处理大规模点云
4. **切向子空间估计**: 高维嵌入流形近似和各向异性重建

### 算法流程
```
输入点云 → 高维流形嵌入 → 切向子空间估计 → 各向异性流形重建 → 曲面网格
```

## 技术细节

### 关键创新
- **高维嵌入**: 提高点云表示能力
- **各向异性优化**: 替代各向同性和自适应网格
- **Riemannian 曲率张量估计**: 从点云直接估计

### 评估数据集
- Thingi10K
- AIM@SHAPE
- Stanford 3D Scanning Repository
- ScanNet

## 复杂度分析
- **时间**: 可扩展深度学习框架
- **空间**: 高维嵌入 O(d×n)
