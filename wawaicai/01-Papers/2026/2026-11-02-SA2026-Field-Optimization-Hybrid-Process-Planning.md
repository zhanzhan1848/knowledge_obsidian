# Field Optimization for Scalable and Distortion-Aware Process Planning in Hybrid Additive-Subtractive Manufacturing

## 一句话总结

面向**混合增材-减材制造（3D 打印 + 铣削）**的**工艺规划**：用**连续场（continuous fields）**而非离散体素表示制造状态 ⟹ 天然适配**大尺寸 + 细几何特征**的模型；并把工艺规划表述为**多目标数值优化**（最终形状符合度、中间结构强度、制造时间、自支撑、无碰撞），产出**失真感知（distortion-aware）**的工艺序列，**额外支撑材料体积最多减少 72.6%**。

## 技术概述

### 问题：现有工艺规划的三个缺陷

| 缺陷 | 后果 |
|------|------|
| **确定性 / 离散化表述** | ① **制造时间未优化**；② **对体素分辨率敏感**（换分辨率结果就变） |
| **不显式考虑失真** | 中间结构（部分打印状态）的**制造失真**（翘曲、残余应力、收缩）未进入优化 ⟹ 计划不可行 |
| **未显式建模自支撑与碰撞** | 悬空结构无法制造；刀具/工装碰撞 |

### 方法：连续场 + 多目标优化

**① 连续场表示制造状态**

- 制造状态（每个时刻的中间形状）用**连续场**表达，而非**体素网格**
- 收益：
  - **尺度无关**（scalable）⟹ 大尺寸模型不炸内存
  - **细几何特征保留**（fine geometric features）⟹ 不受体素分辨率限制
  - 制造序列更**平滑**

**② 工艺规划 = 多目标数值优化**

目标函数包含：

| 目标 | 含义 |
|------|------|
| **最终形状符合度** | 成品与目标形状的差异 |
| **中间结构强度** | 每个中间状态必须**可制造**（不失稳） |
| **制造时间** | 加材/减材工时 |
| **自支撑（self-supporting）** | 悬垂区域需支撑或需分阶段打印 |
| **无碰撞（collision-free）** | 减材阶段的刀具可达性 |

**③ 失真感知（distortion-aware）**

⟹ 计划不仅满足几何与工艺约束，还**把制造失真纳入评估** ⟹ 产出**可行**而非仅几何正确的计划。

### 结果

- 在多种模型上生成**失真感知的工艺计划**
- **额外支撑材料体积最多减少 72.6%** ⟹ 成本与工时的主要来源之一被大幅优化

## 复杂度与数值稳定性

### 算法复杂度
- **中–高**
  - 连续场求值 + 多目标优化（通常是带约束的非线性规划）
  - 场表示若为**隐式场 / SDF**：分辨率可调，内存 $O(\text{voxel count})$ 但可稀疏化
  - 碰撞与自支撑判定需要对场做**多方向投影/切片分析** ⟹ $O(\text{场分辨率} \times \text{方向数})$

### 数值稳定性
- ✅ **连续场相对体素更稳定**：分辨率不再是离散化误差来源 ⟹ 「对分辨率敏感」问题被**根本性缓解**
- ⚠️ **多目标加权**：各目标量纲不同（形状误差 mm / 时间 min / 支撑体积 cm³）⟹ **归一化与权重设置敏感**，需仔细处理
- ⚠️ **失真模型本身**：失真依赖材料与工艺参数 ⟹ **模型误差会传导到计划可行性** ⟹ 需区分「优化误差」与「物理模型误差」
- ⚠️ **自支撑判定**：临界角度附近（如 45° 悬垂极限）判定**二值化**会不稳定 ⟹ 宜用**连续惩罚**而非硬约束
- ⚠️ **全局最优性**：工艺规划本质是**组合 + 连续**问题 ⟹ 实际用启发式/局部搜索 ⟹ 结果依赖初值

### 依赖项
- 连续场表示：**libigl**（SDF、距离场、Marching Cubes）、**CGAL**（多面体、布尔、点包含测试）
- 自支撑分析：常见的**悬垂角**分析（类似切片器 3D Printability）
- 碰撞：网格/场级相交测试
- 制造模拟：失真模型需材料数据

## 推荐结论

⭐⭐ **推荐收录（制造业落地导向，几何方法有借鉴价值）**

### 理由
1. **「连续场取代体素」是一个可迁移的方法论决策**：本文明确论证了连续场在**大尺度 + 细特征**上的优势 ⟹ 这个论证对**任何用体素做中间表示的几何管线**都成立（如体素化建模、体素雕刻、SDF 体渲染、稀疏体素 CNN）⟹ **值得单独建立概念条目**
2. **多目标约束清单是模板化的**：形状符合度 / 中间可制造性 / 时间 / 自支撑 / 无碰撞 ⟹ 这套约束**可直接套用到其他制造与装配场景**（尤其「混合工艺」类问题）
3. **72.6% 支撑材料削减**是硬指标，说明**连续场 + 优化**确实带来了实打实的工程收益
4. **失真感知**是很多工艺规划论文忽略的维度，本文明确定位并解决

### 谨慎之处
- ⚠️ 摘要**未给出**具体的优化算法、场表示细节、对比基线 ⟹ 需查正文确认方法新颖度
- ⚠️ 领域偏**制造工艺**，而非通用几何处理 ⟹ 对本库主线是「**方法论可迁移**」而非「算法可直接复用」
- ⚠️ 失真模型的准确性依赖材料数据库，**跨材料迁移性存疑**

### 对我们的启发
- **[[连续场 vs 体素表示]]**：表示选择本身就是一项几何决策；本文给出了一份「何时选连续场」的论证 ⟹ 可用于方案评审 checklist
- **[[自支撑性与可打印性分析]]**：悬垂角分析是几何与制造的交界 ⟹ 独立概念条目
- **[[多目标几何优化]]**：几何符合度 + 工艺可行性 + 成本 ⟹ 通用范式
- **[[工艺规划]]**：增材制造中的「几何 → 操作序列」映射问题
- **[[失真与制造误差]]**：几何理想形状 ≠ 实际制造形状 ⟹ 需在几何管线中保留「理想/实际」两套坐标
