# Reading the Room: Scale-ambiguous Semantic Registration of Sparse VSLAM Maps to Floor Plans

## 一句话总结

把**稀疏语义 VSLAM 地图**配准到**楼层平面图（floor plan）**这一"跨模态 + 尺度未知 + 场景未建成"的难问题，用**单一鲁棒、可微、类别平衡的语义-几何能量函数**统一驱动全局初始化与局部精化，在 3 个在建工地、33 条序列上把平均轨迹绝对误差相对最强基线改善 **4.5×**（给锚点时 **7.6×**）。

## 核心贡献

1. **统一能量函数**：单个**鲁棒、可微、类别平衡的语义-几何能量**支配整条管线（全局 + 局部）
2. **两类全局初始化**：(a) 利用单个（可能不准的）用户对应关系；(b) 用**跨模态匹配网络**做全局估计
3. **明确处理四大困难**（以往方法最多同时处理两个）：
   - VSLAM 几何只在**未知相似变换**下恢复（尺度模糊）
   - 稀疏点云与**符号化平面图**是**跨模态**的
   - 采集时工地**仅部分建成**
   - 工地视觉**高度重复**，地图质量退化且区分性特征被移除
4. **实验**：3 个在建工地 33 条序列，ATE 显著改善

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| **尺度模糊相似变换** | VSLAM 输出 up-to-scale；需同时估计相似变换（含尺度 s） |
| **跨模态匹配网络** | 从稀疏语义点云 → 平面图符号元素的匹配网络，用于全局初始化候选生成 |
| **类别平衡能量** | 对语义类别加权，避免高频类（墙/地面）主导能量 |
| **鲁棒核** | 对不可靠匹配/离群对应使用鲁棒损失（如 Cauchy / Geman-McClure） |
| **可微能量 + 局部精化** | 能量对变换参数可微 → 梯度法精化 |
| **地标/角点对应** | 利用平面图中的墙角等强几何特征作为对应锚点 |

### 核心公式

**相似变换**：

$$\mathbf{p}' = s\, R\,\mathbf{p} + \mathbf{t}, \qquad s > 0,\ R \in SO(3)$$

**统一语义-几何能量**：

$$E(\mathcal{T}) = \sum_{(i,j) \in \mathcal{C}} w_{c_i} \, \rho\!\left( \frac{\|\,\mathcal{T}(\mathbf{p}_i) - \mathbf{q}_j\,\|^2}{\sigma^2} \right) + \lambda E_{\text{sem}}(\mathcal{T})$$

其中 $c_i$ 为语义类别，$w_{c_i}$ 为类别平衡权重，$\rho(\cdot)$ 为鲁棒核。

**尺度模糊下的对称性**：因 $s$ 未知，平面对称歧义（沿轴向的镜像/旋转）需由语义与结构打破：

$$E(\mathcal{T}_1) = E(\mathcal{T}_2) \quad \text{当仅尺度-旋转复合不同时}$$

→ 必须借助类别语义 + 墙体拓扑打破退化。

## 实验结论

- **数据**：3 个在建工地，33 条序列
- **指标**：**ATE**（平均轨迹绝对误差）；基线为经典与学习类方法
- **结果**：
  - 通用无约束设定：ATE 相对最强基线改善 **4.5×**
  - 提供锚点对应时：改善 **7.6×**
- **消融**：全局初始化方式、类别平衡权重、鲁棒核的影响
- **工程意义**：支撑施工进度自动监控（把今日采集与历史平面图对齐）

---

## 局限性

- 依赖**平面图**存在且为符号化 2D 表示；纯点云地图不适用
- 工地**几何高度重复**时仍会退化（论文承认此为根本困难）
- 需要足够语义（墙/柱/门窗分类）→ 依赖语义地图质量
- **全局初始化**仍可能落入局部极小；网络泛化到新工地未充分验证
- 尺度估计依赖平面图有**绝对尺寸**（否则尺度仍不可观测）

## 实现建议

### 可行性分析：跨模态语义配准

**算法复杂度**
- 全局初始化：候选生成 O(K · n) + 网络前向 O(n·d)
- 局部精化：每次迭代 O(m)（m 为对应数），收敛需 O(iters) 迭代
- 总体：O(K·n + iters·m)，对稀疏地图很轻量

**实现难度**
- 算法复杂度：**中高**（跨模态匹配网络需训练；能量设计需调）
- 数值稳定性：**中** — 尺度与旋转的**对称退化**是主要风险，需要好初始化 + 鲁棒核
- 依赖项：**Open3D**、**PyTorch**、**g2o / GTSAM**（含尺度的位姿图优化）、**语义分割模型**

**推荐结论**：✅ **推荐实现（若业务涉及施工/建筑场景）**

### 工程价值

1. **"单一能量函数统一全局与局部"** 是很好的工程范式：避免了多阶段各自优化导致的误差累积与调参困难
2. **类别平衡权重** 是跨模态匹配的**必备**技巧（频率偏斜严重时，不加权的能量会被地面/墙主导）
3. **可微 + 鲁棒核 + 尺度作为优化变量** 三件套可直接复用

**开源参考**
- Open3D: `o3d.pipelines.registration`、全局优化
- GTSAM: `gtsam.Pose3` + `gtsam. Similarity3`（含尺度的位姿图）
- G2O / Ceres: 鲁棒核实现
- SuperPoint + LightGlue: 跨模态特征匹配（但平面图是合成图 → 需域适配）

**适用场景**：施工进度自动监控、机器人与建筑蓝图定位、室内/园区场景与 CAD 平面图对齐、既有建筑改造的现状-图纸配准
