## 核心贡献

> **把「时间参数化」也变成可学习的：不是「固定阶数的多项式」，也不是「均匀分段」，而是「每个高斯自己学一套非均匀分段的三次 Bézier 样条」—— 运动快的地方给多几段，慢的地方省几段。**

1. **自适应非均匀分段三次 Bézier 样条**建模**每个高斯**的运动轨迹
2. **联合学习两样东西**：
   - **Bézier 控制点**
   - **该高斯轨迹的时间分段（temporal partition）**
   > 「这种自适应表示**把更多时间容量分配给高动态区域**，同时在近静态区域保持紧凑轨迹。」
3. **$G^1$ 连续性约束**：在相邻 Bézier 段之间施加**基于反射（reflection-based）的控制点约束**
   - 目的：**兼顾全局平滑运动与局部自适应**
   - 效果：产生**平滑、全可微**的轨迹，**同时保留非均匀时间参数化的灵活性**
4. **工程友好**：**直接集成进标准 3DGS 优化与致密化（densification）管线，无需辅助网络**
5. **实证**：在 **Neural 3D Video（N3DV）**、**Google Immersive**、合成场景上，对**高度非均匀、困难动态**的场景显著提升重建质量；对一般动态场景保持与 SOTA 4DGS 竞争

## 技术方案

### 与现有路线的对比

| 路线 | 局限 |
|------|------|
| **全局变形（global deformations）** | 表达力受限 |
| **固定阶数多项式（fixed-order polynomials）** | 时间分辨率固定，无法自适应 |
| **均匀参数化样条** | 时间容量平均分配 → 浪费在静态段，浪费不起在动态段 |
| **本文：自适应非均匀分段三次 Bézier** | ✅ 动态段多给、静态段省给 |

### 关键设计

| 组件 | 说明 |
|------|------|
| **分段三次 Bézier** | 每个高斯一条轨迹 |
| **可学习时间分段** | 与控制点**联合学习**；**固定段数预算**下按运动快慢分配时间分辨率 |
| **$G^1$ 连续性约束** | 用**反射式约束**作用于控制点；**不限制局部运动速度** |
| **无辅助网络** | 直接进标准 3DGS 优化 + 致密化管线 |

### 消融（论文 Table 2）：均匀 vs 非均匀分段

| 样条阶数 | 均匀 PSNR / SSIM / LPIPS | 非均匀 PSNR / SSIM / LPIPS |
|---------|--------------------------|----------------------------|
| 2 | 31.71 / 0.9459 / 0.0537 | **32.08 / 0.9481 / 0.0540** |
| 3 | 30.83 / 0.9441 / 0.0565 | **31.74 / 0.9469 / 0.0551** |
| 4 | **31.61 / 0.9454 / 0.0579** | 31.61 / 0.9446 / **0.0572** |

> 📌 **两个关键结论**：
> 1. **非均匀分段在各阶数下都优于或持平均匀分段**
> 2. **提高阶数收益很小**（2→3 有增益，3→4 基本持平）⇒ **关键是「非均匀」，不是「高阶」**

## 实验结论

### 定量结果（论文 Table 1）

**场景**：2 个合成（checker sphere、soft contact）+ 3 个真实（cook spinach、coffee martini 来自 N3DV；flames 来自 Google Immersive）

| 方法 | checker sphere PSNR↑ / SSIM↑ / LPIPS↓ | soft contact | cook spinach | coffee martini | flames |
|------|--------------------------------------|------------|--------------|----------------|--------|
| Gaussian-Flow | 37.42 / 0.9875 / 0.0495 | 31.10 / 0.9829 / 0.0308 | 24.65 / 0.8771 / 0.2293 | 23.42 / 0.8571 / 0.2398 | 21.69 / 0.7453 / 0.3878 |
| STG | 34.78 / 0.9920 / 0.0198 | 23.42 / 0.9623 / 0.0551 | 31.93 / 0.9516 / 0.1393 | 26.80 / 0.9066 / 0.1628 | 23.96 / 0.8888 / 0.1680 |
| SplineGS | 40.37 / 0.9953 / 0.0375 | 24.55 / 0.9805 / 0.0336 | 32.67 / 0.9528 / 0.2007 | 27.73 / 0.9059 / 0.2188 | 21.39 / 0.7309 / 0.4742 |
| **GaussianSpline（本文）** | **41.18 / 0.9956 / 0.0151** | **26.84 / 0.9845 / 0.0289** | **32.92** / 0.9522 / **0.1531** | **27.99 / 0.9087 / 0.1743** | **27.42 / 0.9068 / 0.1498** |

> 📌 **PSNR 上全面领先**：checker sphere **+0.81** over SplineGS；soft contact **+2.29** over SplineGS、**+5.74** over STG；flames **+5.46** over Gaussian-Flow、**+3.46** over STG、**+6.03** over SplineGS。
> **flames 场景提升最大**（21.39 → 27.42，+6.03 dB）—— 这是典型的高度动态场景。

### 定性结果

- **自适应时间分配的收益**：均匀样条（中间列）产生**模糊或不完整的细节**；自适应样条（右列）更好地恢复：
  - **checker sphere**：球体几何、纹理、阴影
  - **cook spinach**：手、手指、夹爪（gripper）
- 说明**自适应时间分配把表示容量集中到了真正需要的地方**

## 局限性（论文 §5 明确）

1. **高度瞬态（highly transient）的动态难以处理**：
   > 「在 **Soft Contact** 中，**快速碰撞在极短间隔内产生大加速度，用固定的少量样条段难以准确捕捉**。」
2. **提出的方向 —— 自适应段插入（adaptive segment insertion）**：
   > 「一个有前景的方向是**由局部曲率或重建残差引导的自适应段插入**，以动态调整段数。」
   （即：当前版本仍是**固定段数**，只是段宽可学；段数本身的自适应是未来工作）

## 实现建议

- **实现难度**：**中**。Bézier 求值本身简单（de Casteljau），难点在：
  - **可学习的分段**如何参数化（段边界作为可学参数，用 softmax/累积软分配？）
  - **$G^1$ 反射约束**如何写进优化（约束项 or 参数化消解？）
  - 与 3DGS 致密化管线的集成
- **数值稳定性**：**中**。Bézier 求值天然稳定（有界控制点 → 有界曲线），**但分段边界的可学参数化容易在优化中塌缩**（段宽退化为 0 或某个值爆炸）→ 建议加**单调性约束 + 段宽下限**。
- **依赖项**：
  - **3DGS**（原版或 `gsplat`）
  - **PyTorch** + CUDA
  - Bézier 求值：**自写**（de Casteljau，几十行）；或 `tinycudann` 的样条工具
  - 评估：PSNR / SSIM / LPIPS（`lpips` 包）
- **适用场景**：
  - ✅ **动态场景重建中运动高度非均匀**（火焰、碰撞、双手操作）
  - ✅ **需要时间维度的紧凑、可微表示**
  - ✅ **接入现有 3DGS 管线**（无需辅助网络）
  - ❌ **完全瞬态的瞬变事件**（碰撞瞬间）→ 需段数自适应
  - ❌ 需要严格 $C^1$ 以上的更高阶连续性（仅 $G^1$）
- **性能预期**：未显著改变 3DGS 的训练成本（无辅助网络）；**增益在高动态场景最大（+3~6 dB）**。

## 备注

> **这篇的核心思想对几何处理有直接迁移价值：把「参数化的方式」也变成可学习的。**
>
> 传统的样条/曲线表示假设「参数化方式是先验给定的」（均匀分段、固定阶数）。本文把这个假设**放开**了 —— 让模型自己决定「在时间轴上哪里多花容量」。这个思路在我们的几何管线里完全可以用：
> - **网格细分**：不同区域用不同细分密度（而非全局均匀）
> - **曲线参数化**：弧长参数化 vs 弦长参数化 vs 几何参数化 —— 让优化选
> - **重网格化**：自适应边长而非全局目标边长
>
> 另一个值得记的点是消融的结论：**「非均匀」比「高阶」重要**（3→4 阶几乎无收益，但非均匀化在所有阶数都赢）。**在表达力预算有限时，把预算花在「哪里」而不是「用什么形式」上，更划算。**
>
> 与今日 [[2610-34766-FG-CPAB]] 的共同点：**两者都在「参数化结构」上做文章** —— FG-CPAB 让剖分分辨率可扩展，GaussianSpline 让时间分段可自适应。**自适应分配有限预算**是今天的一个共同主题。
