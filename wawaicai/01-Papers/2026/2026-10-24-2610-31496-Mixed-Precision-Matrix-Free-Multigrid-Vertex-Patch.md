# Mixed-Precision Coalesced Matrix-Free Multigrid with Vertex-Patch Smoothing

## 一句话总结

三维 Poisson 方程的**几何多重网格**求解器：用**乘性顶点块 Schwarz 平滑**（精确局部求解）替代经典平滑子，所有场以**逐单元持久化存储**（每单元持有一份共享自由度的副本），GPU 上 patch 更新**在寄存器中计算、warp shuffle 交换**，几乎不用共享内存；配合**快速对角化 + 合并变换 + patch 反射对称**，单次 sweep 的数据搬运降到设备拷贝带宽的 **87%**；通过**双精度重平衡**消除舍入导致的残差相消破坏，单 A100 上超过 **4 亿自由度/秒**。

## 核心贡献

1. **顶点块 Schwarz 平滑子**：乘性、精确局部求解 → 得到**连续**解，**无需单元间数据交换**
2. **逐单元持久化存储**：每个单元持有各共享自由度自己的副本 → 消除原子操作与竞争
3. **寄存器内 patch 更新**：一单元一线程，patch 内单元用 **warp shuffle** 交换数据 → **几乎完全避开共享内存**
4. **算术量削减**：快速对角化 + 合并变换 + **patch 反射对称**，把算术降到单次 sweep 数据搬运的 **87% 带宽**
5. **混合精度 + 双精度重平衡**（关键）：单精度层做内迭代，**在舍入前**用双精度完成相消的共享自由度副本交换 → 收敛性与双精度一致，且**与网格规模无关**
6. **性能**：单张 NVIDIA A100 上 **> 4×10⁸ 自由度/秒**

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| **几何多重网格** | 基于网格几何（顶点、单元邻接）的层次粗化；本文的粗化算子为几何化实现 |
| **顶点块 Schwarz** | 以顶点为单位的重叠子域；每个 patch 内部做**精确**局部求解 |
| **逐单元持久化 (cell-wise persistent)** | 共享自由度在每个相邻单元各存一份 → 无原子操作、无竞争写 |
| **Warp shuffle** | 用 `__shfl_*` 指令在 warp 内交换 patch 数据 → 绕开 shared memory |
| **快速对角化** | 对 patch 内小矩阵做快速对角化 → 减少算术 |
| **合并变换** | 把多个 patch 的操作合并 → 提升并行度与算术密度 |
| **反射对称** | 利用 patch 的几何对称性复用计算 |
| **双精度重平衡** | 核心数值技巧：舍入会破坏共享自由度**相反符号副本之间的相消**；先在双精度交换副本完成相消，再舍入 → 对偶向量不变 |

### 核心公式

**顶点块 Schwarz 平滑（乘性形式）**：

$$x^{(k+1)} = x^{(k)} + \sum_{p \in \mathcal{P}} \tilde{M}_p^{-1} r^{(k)}\big|_p$$

其中 $\tilde{M}_p$ 为 patch $p$ 上的局部（块）矩阵，局部求解**精确**。

**双精度重平衡（核心）**：

$$\text{朴素: } \quad \mathrm{round}\big(a + b\big) \ne \mathrm{round}(a) + \mathrm{round}(b), \quad a \approx -b$$
$$\text{重平衡: } \quad \mathrm{round}\big(\underbrace{(a+b)}_{\text{双精度相消}} + c\big)$$

**残差在单元副本上的相消关系**：

$$\sum_{c \in \mathcal{C}(v)} r_c(v) = 0 \quad \forall v \in V$$

其中 $\mathcal{C}(v)$ 为共享自由度 $v$ 的相邻单元集合 —— 这正是舍入会破坏的结构。

**算术强度**（数据搬运 vs 算术）：

$$\frac{\text{bytes moved}}{\text{FLOPs}} \quad \xrightarrow{\text{快速对角化+合并+对称}} \quad \text{sweep 带宽降至设备拷贝的 } 87\%$$

## 实验结论

- **问题**：三维 Poisson 方程，连续**三次（cubic）单元**
- **收敛性**：经重平衡后，循环**收敛行为与双精度一致**，且**独立于网格规模**；误差以**最优速率**收敛直到求解精度下限
- **性能**：单 A100 **> 4 亿自由度/秒**；patch 更新算术接近 **FP32 峰值**（尽管占用率低）
- **带宽**：单次 sweep 的数据搬运为普通设备拷贝带宽的 **87%**
- **精度策略**：层次内部单精度 + 外层双精度迭代

---

## 局限性

- 仅 **Poisson 方程** + **连续三次单元**（特定问题类型）
- 反射对称假设**限制了几何通用性**（一般网格无对称性，只能用快速对角化 + 合并变换部分）
- 低占用率（occupancy）设计 → 在**非 patch 规则**网格上可能退化
- 混合精度**外层双精度迭代**削弱了一部分加速收益
- 需要 CUDA 级别的底层实现（shuffle、寄存器驻留），**移植到非 NVIDIA 平台成本高**

## 实现建议

### 可行性分析：几何多重网格求解器

**算法复杂度**
- 单次 V-cycle：O(N)，N 为自由度
- 收敛率：约 O(N^{-2/3})（三次单元的 GMG 最优率）
- 目标吞吐：> 4×10⁸ DOF/s（单 A100）

**实现难度**
- 算法复杂度：**高**（几何粗化算子 + patch 划分 + Schwarz 乘性求解 + 零共享内存访存）
- 数值稳定性：**极好** — 双精度重平衡是本文最值得学的一点，它**从根上消除了混合精度的相消破坏**
- 依赖项：**CUDA**、**ViennaCL / PETSc**（AMG 基线）、**Gmsh**（网格生成）

**推荐结论**：✅ **推荐实现（若我们做仿真后端求解）** / ⚠️ 全量复现门槛高

### 值得单独抽取的可迁移技术

1. **双精度重平衡（最高价值）**
   - 这是一个**通用**的混合精度数值技巧：凡是用"每单元持有共享量副本"的做法（volume-of-fluid、嵌入式网格、局部刚体求解器）都可能有同样的相消问题
   - 落地成本低：**在相消发生前用双精度完成副本交换即可**

2. **逐单元持久化 + warp shuffle 的零共享内存模式**
   - 适用于所有"patch 内局部求解"类算法：几何多重网格、局部刚性变形、嵌入式网格求解
   - 收益：完全消除原子操作竞争

3. **「几何多重网格 vs 代数多重网格」的选型**
   - 本文是 GMG 的又一有力案例：几何粗化算子保留几何信息（网格平滑性），在**光滑解**问题（Poisson）上显著优于 AMG
