# Neural Field Processing on Surfaces

> 📌 **SA2026（papers_2056）**。这篇把**隐式神经表示**和**内在几何计算**这两条主线拧到一起：不再需要参数化、不再需要拓扑相关的离散化，所有曲面 PDE 都变成**笛卡尔坐标下的变分优化问题**。这是「神经表示」从「表达形状」升级到「表达并计算几何」的标志性尝试。

## 技术概述

### 问题：内在几何计算的两难

**曲面几何处理**（surface geometry processing）的核心任务几乎全是**内在（intrinsic）**的：
- 曲面 PDE 求解（热方程、标量扩散）
- Laplace 特征函数计算（谱分析）
- 流体模拟（reduced fluid simulation）
- 四边形重网格化的**cross-field** 设计

而经典做法各有各的痛点：

| 传统路线 | 痛点 |
|---------|------|
| **参数化 + 贴图空间计算**（LSCM/ABF++ 展开后做二维计算） | 需要**显式参数化**；接缝处导数不连续 ⟹ 结果不精确；展开有失真 |
| **内在离散化**（cotangent Laplace、有限元） | 依赖**拓扑相关的离散**（图 Laplace、稀疏三角网格）⟹ 与神经场的连续表示不兼容 |
| **逐任务训练网络** | 每个任务、每个形状都要**单独训练** ⟹ 无法统一、无法泛化 |

### 核心思想：Cartesian-only 的内在计算

> **「我们结合隐式神经表示与最近点法（CPM），使得内在曲面计算完全在笛卡尔坐标下完成 —— 无需显式参数化，也无需依赖拓扑的离散化。」**

**这是本文的立论核心**。它的含义：

- **不用展开曲面** ⟹ 没有接缝、没有参数化失真
- **不用网格邻接** ⟹ 算子与三角化无关
- **一切在 XYZ 空间表达** ⟹ 可以直接被 GPU / 物理仿真 / 渲染管线消费

### 三大技术贡献

#### ① 用 Hodge 分解把向量场化为标量势 ⭐⭐

> **「我们利用 Hodge 分解，仅用神经标量势来表示曲面向量场，使单一统一架构能同时处理标量场与向量场，无需帧场（frame-field）选择，也无需逐元素离散化。」**

**为什么这是关键？**

**向量场在曲面上的表示难题**：
- 平面上向量场需要**全局坐标系**（x, y 分量）
- 曲面上**没有全局坐标系** ⟹ 需要**切空间标架（tangent frame）** ⟹ 而**标架本身需要选择**（这是 frame-field 设计的由来，也是重网格化的一大难题）
- 更糟的是：**标架在曲面某些点无法全局连续存在**（拓扑障碍、亏格问题）⟹ 必然出现**奇点（singularity）**

**Hodge 分解的解法**：
```
任意切向量场 v  =  ∇φ  +  curl ψ  +  harmonic part
                   ↑       ↑          ↑
               梯度场    旋度场     调和场（拓扑决定，不可消除）
```
- **梯度分量**由标量势 φ 给出 ⟹ 用一个**标量网络**就能表示
- **旋度分量**由另一个标量势 ψ 给出
- **调和分量**是纯拓扑量（取决于亏格），**与场本身无关**

⟹ **用两个标量网络 + 一个拓扑项就能表示任意切向量场**，完全绕开 frame field。

> 这对**四边形重网格化**意义巨大：cross-field 设计的全部难点就是「如何无奇点地表示切向量场」。本文说不需要 frame-field choices ⟹ **直接消掉了奇点问题**。

**统一架构**：
- 标量场 ⟹ 一个标量网络
- 向量场 ⟹ 两个标量势网络（梯度 + 旋度）
- **同一套架构** ⟹ 不需要为标量/向量分别设计网络

#### ② 管状邻域扩张（Tubular extension）⭐⭐

> **「我们将曲面场扩张到管状邻域，使其沿曲面法向保持数值不变，从而可以用对应的笛卡尔算子直接求值内在微分算子。」**

**问题**：内在算子（曲面梯度、旋度、拉普拉斯）只在**曲面上**定义。但神经场是**定义在三维空间的连续函数** ⟹ 要在三维里求值，需要把场的值从曲面"抬"到周围空间。

**管状邻域扩张**的做法：
- 沿曲面**法向**（normal bundle）把场的值**外推**到管状区域
- **关键性质**：沿法向外推时，场的值**保持不变**（保持沿法向的"常值"）

**为什么这让内在算子可用**：

考虑笛卡尔梯度 ∇F（3D）与曲面梯度的关系。若 F 沿法向方向常值（即 ∂F/∂n = 0），那么：
- 笛卡尔梯度中，**法向分量为零** ⟹ ∇F 自动**落在切空间内**
- 此时 ∇F 就是**曲面梯度**的笛卡尔表示

同理：
- **保持沿法向常值** ⟹ 笛卡尔 Laplacian 的**法向二阶导为 0** ⟹ 笛卡尔 Laplacian **退化为曲面 Laplacian**
- **保持法向一阶常值（梯度无 n 分量）** ⟹ 笛卡尔旋度的**法向分量恒为 0** ⟹ 旋度自动是**切向旋度**

⟹ **一个精心设计的管状扩张，把内在微分几何运算"翻译"成了普通的三维笛卡尔微分运算**。这是全文最精巧的一步。

#### ③ 法丛（normal bundle）输入提升 ⭐

> **「为处理近退化几何，例如具有间距很近的平行面的薄结构，我们将网络输入提升到法丛，以减少跨邻近表面的泄漏。」**

**问题**：隐式神经表示用**位置坐标 x ∈ ℝ³** 作为输入。问题是：**位置本身无法区分「空间中同一点附近的不同表面」**。

典型失效场景：
- **薄板 / 薄壁**：上下两个面相距 ε，输入 x 无法区分"我属于上表面还是下表面" ⟹ 网络输出会**泄漏（leakage）**：把两面混在一起，产生"中间态"的伪值
- **近距离平行面**（如管道内壁与外壁、薄叶片堆叠）

**法丛输入**：
- 不只喂 x，而是喂 **(x, n(x))** —— 位置 **+ 该点的法向**
- 或等价地，喂**法向坐标下的 (切向分量, 法向距离)**

⟹ 网络能**区分朝向不同的邻近表面**，泄漏被显著抑制。

> 这是隐式神经表示（NeRF / Neural SDF）领域已知的 "**ambiguity / multi-solution 问题**"在曲面几何语境下的解决方案 —— 把"位置"升级为"位置 + 局部标架"。

#### 统一框架带来的能力：一切都是变分优化

> **「在这一形式化下，曲面 PDE 求解、Laplace 特征函数计算、简化的流体模拟、以及用于四边形重网格化的 cross-field 设计等几何处理任务，都归约为由神经场优化求解的变分问题。」**

| 几何任务 | 传统形式 | 本文形式 |
|---------|---------|---------|
| 曲面 PDE 求解 | 稀疏线性系统 | 神经场优化的**变分问题** |
| Laplace 特征函数 | 广义特征值问题 | 变分问题（Ritz 原理） |
| 简化的流体模拟 | 低维降阶 + 离散算子 | 变分问题 |
| Cross-field 设计 | 帧场 + 奇点消除 | **Hodge 势 + 变分优化**（无 frame field） |

**另一个实用特性**：
> **「将任务参数或形状参数作为额外输入，进一步允许单个网络处理多个任务/形状。」**

⟹ **条件化（conditioning）**：一个网络，多任务、多形状，**不再逐任务训练**。这是相对传统离散求解器最大的「易用性」红利。

## 复杂度与性能

- **摘要未给出**复杂度公式与运行时间数值
- 可推断：
  - **单次查询**：前向传播成本 = 网络评估成本 × 查询点数，与网格规模**无关**
  - **优化阶段**：每次迭代需要（梯度 / Hessian-向量积），若用隐式微分或邻域采样 ⟹ 迭代成本与**采样点数量**成正比，与**网格面数无关**
  - **内存**：只存网络权重 ⟹ **与网格规模解耦** ⟹ 内存占用极小
- **与传统离散求解器的本质对比**：
  - 传统：预处理 O(N log N)（稀疏 Cholesky）+ 每次求解 O(N)
  - 本文：训练/优化成本高（需迭代），但**推理期极轻**，且**多任务多形状共享一个模型** ⟹ 摊薄后有优势

## 数值稳定性

### ✅ 优势
- ✅ **Hodge 分解在理论上消除了奇点问题**：向量场表示不再依赖标架 ⟹ **拓扑奇点从表示层面就不存在** ⟹ 这是相对 frame-field 方法的根本稳定性优势
- ✅ **管状扩张保证了算子的一致性**：沿法向常值 ⟹ 笛卡尔算子与内在算子**严格等价**（在精确扩张下）⟹ 避免了"用 3D 算子近似 2D 算子"带来的系统偏差
- ✅ **法丛输入显著抑制薄结构泄漏**：这是针对已知失效模式的**定向修复**，且**不需要改变网络架构**
- ✅ **无网格依赖**：没有 cotangent Laplace 这类依赖**网格质量/各向异性**的离散算子 ⟹ **不存在网格质量下降导致算子退化**的问题
- ✅ **变分形式通常条件良好**：最小二乘型变分问题的 Hessian 半正定 ⟹ 配合恰当的优化器（如 Gauss-Newton / L-BFGS）收敛稳定

### ⚠️ 风险点
- ⚠️ **管状邻域的宽度是超参数**：管太窄 ⟹ 网络在管外无定义、边界条件人为；管太宽 ⟹ 相邻曲面（如薄板两侧）互相干扰、泄漏回来 ⟹ **存在一个不可回避的尺度权衡**
- ⚠️ **法丛输入需要可靠的法向**：若底层隐式场（Neural SDF）的法向估计在**薄板 / 尖点 / 特征边附近不准**，法丛输入会把法向误差**直接注入**网络输入 ⟹ 误差放大
- ⚠️ **Hodge 分解的调和分量是拓扑的**：对亏格 > 0 的曲面（如环面、带洞曲面），**调和场无法被标量势消去** ⟹ 必须在损失里显式处理这一项；若实现遗漏 ⟹ **结果只在单连通域上正确**
- ⚠️ **优化型方法的病态风险**：变分问题的 Hessian 在**高阶能量**（如高阶 Laplacian 特征函数、cross-field 的高阶正则）下**病态严重** ⟹ 需要强正则 / 预条件 / 多重网格策略
- ⚠️ **采样密度影响结果**：优化是基于**Monte Carlo 采样点**的 ⟹ 采样不足时变分解会有**统计噪声** ⟹ 需多次采样或确定性采样，否则结果不可复现
- ⚠️ **神经场的「高保真 vs 光滑」张力**：网络容量不足时会被迫光滑 ⟹ 尖锐特征（特征边、高曲率处）被抹平 ⟹ Laplacian 特征函数这类**对几何细节敏感**的任务误差可能被显著放大

## 推荐结论

✅ **强烈推荐**

### 理由
1. **统一框架的雄心**：把四类本质不同的任务（曲面 PDE、谱分析、流体模拟、cross-field 设计）统一成「变分 + 神经场优化」⟹ 这是**范式级**的贡献，不是单点技术改进
2. **Hodge 分解绕开 frame field** 是一个**真正的洞见**：它不是工程 trick，而是利用了微分几何的结构性质
3. **管状扩张 + 法丛输入** 是两个针对**具体数值失效模式**的定向设计，说明作者对隐式表示的病态情形有实践认知
4. **条件化支持多任务多形状** ⟹ 训练成本可摊薄，实用价值高
5. 与本库已有的 **MeRM（神经几何 token）**、**RBF-SDF 插值**、**Rotation Equivariant Neural Jacobian Fields** 共同构成本库「**神经表示 + 几何计算**」这条线的核心图景

### 与相关工作的定位
- **vs 传统离散几何处理**（cotangent Laplace / FEM）：本文**不依赖网格拓扑**，用神经网络替代离散算子 ⟹ 适合网格质量差 / 网格缺失的场景
- **vs 参数化方法**（LSCM + 贴图空间计算）：本文**完全不做参数化** ⟹ 接缝问题消失
- **vs Neural Jacobian Fields / Neural Deformation**：那些是**学习特定映射**；本文是**框架**，把多任务都归约成变分优化 ⟹ 更通用但可能单任务精度不如专用模型
- **vs NeRF / Neural SDF 类隐式表示**：那些做**形状表达与渲染**；本文做**在形状上的计算** ⟹ 互补而非竞争
- **vs 变分几何处理（VG / 几何处理变分框架）**：变分框架提供「问题表述」，本文提供「神经求解器」⟹ 二者可组合

### 落地建议
- **最值得试的场景**：**网格质量差 / 无结构网格**的几何处理（医学影像重建的表面、CAD 转换面片、扫描点云表面化后的处理）
- **落地路线（务实版）**：
  1. **先做单任务验证**：选**曲面热扩散 / Laplace 特征函数**（有 ground truth 可比）⟹ 检验范式可行性
  2. **法向估计质量是前置依赖**：先用现成的可靠法向估计（梯度场 + 局部平面拟合）⟹ 再接法丛输入
  3. **管宽设为可调**：用多尺度管宽并行训练或推理时选优，避开单一超参
  4. **离散解作为基准**：始终保留传统稀疏求解器作为 fallback（尤其拓扑非单连通时）
  5. **拓扑项显式化**：实现 Hodge 调和分量的显式处理（可通过计算调和场基并投影残差）
