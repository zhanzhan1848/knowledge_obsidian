# TORO Curves: G² Interpolating Curve with Maximum Curvature Control

> 📌 提供一族 **G² 连续的插值样条**，支持**精确的局部曲率控制**，且**无需全局优化**。方法的关键是一条**基于偏移曲线的解耦策略** —— 用偏移曲线的性质把**几何**与**曲率幅值**分离。

## 技术概述

### 问题：G² 插值 + 曲率控制难以兼得

在几何设计中，曲线插值需要满足：
- **位置**（插值指定点）
- **G² 连续**（曲率连续 → 光滑）
- **曲率控制**（指定点的曲率，用于让曲线精确通过圆弧、椭圆等基本图元）

既有方法的矛盾：**全局优化**能同时满足这三项，但**慢、且不适合交互编辑**；局部方法快，但**无法精确控制曲率**。

### 核心思想：偏移曲线解耦（Offset-based Decoupling）

> 我们框架的一个**核心支柱是基于偏移的解耦策略**：通过利用**偏移曲线**的性质，我们**把几何与曲率幅值解耦**，从而能够在控制点上**灵活指定曲率**。

**为什么偏移曲线能做到这件事？**

偏移曲线（offset curve）`c_offset(t) = c(t) + d · n(t)`（沿法向平移固定距离 `d`）的性质：
- 偏移曲线的**曲率**满足 `κ_offset = κ / (1 + d·κ)`
- 关键：**给定一条目标曲率的曲线，它的偏移曲线**有一个**显式的闭式解**

所以：

> 想要一条曲率 `κ(t)` 的曲线 ⇒ 取一条**直线/圆弧**（易构造），其某个**偏移**恰好具有目标曲率。

这就是解耦：**几何形状**由「基础曲线 + 偏移量」决定，**曲率幅值**由「偏移量」单独控制。

### 两类基元线段

本文组装两种基元线段，**每种的曲率最大值只出现在其两端的圆弧上**：

| 线段 | 用途 | 特征 |
|------|------|------|
| **TO（Triangular Offset，三角偏移）线段** | 处理**拐点（inflection）** | 曲率变号 |
| **RO（Rational Bézier Offset，有理贝塞尔偏移）线段** | 处理**曲率符号恒定**的区域 | 曲率极值在两端圆弧 |

### 关键技术

| 技术 | 说明 |
|------|------|
| **偏移曲线解耦** | 核心：几何与曲率幅值分离 |
| **TO 线段** | 三角偏移，处理拐点 |
| **RO 线段** | 有理贝塞尔偏移，曲率符号恒定区 |
| **二次方程求解** | **每个线段通过简单的二次方程求解** —— 确定性、局部 |
| **有理贝塞尔权重直推** | **权重直接由几何量确定** —— 无需迭代 |
| **自适应曲率配置** | 在形变下保证鲁棒性与视觉连续性 |

**「确定性 + 局部」是本文最大的实用价值**：

> 这个构造是**确定性的**且**局部的**；每个线段通过**简单的二次方程**求解，而**有理贝塞尔权重直接由几何量确定**。这带来了**局部支撑**与**交互编辑时的即时更新**。

## 复杂度分析

- **构造**：每个线段 = 解一个二次方程 ⇒ **O(1)**；n 个控制点 ⇒ **O(n)**
- **求值**：**O(1)** per 点（分段求值）
- **编辑**：修改一个控制点 ⇒ **O(1)** 局部重算（局部支撑的直接体现）
- **对比**：全局优化方法的复杂度通常远高（且需迭代收敛）

## 实现难度与数值稳定性

- **算法复杂度**：**低~中**。构造清晰，核心是偏移曲线与曲率的解析关系；需要仔细处理 **C¹/C² 连续性的装配条件**。
- **数值稳定性**：**中**。二次方程求根在**判别式接近 0** 时不稳定（相切配置）；自适应曲率配置正是为应对此而设计。
- **依赖项**：几乎无外部依赖 —— 这类「几何构造类」论文通常自研实现。

## 实验结论

- **结果**：TORO 曲线能**表示复杂形状**，同时**准确复现基本图元**（圆弧、椭圆）
- **价值**：比既有方法**更高效、更有表达力**
- **交互性**：局部支撑 ⇒ 编辑时**即时更新**

## 局限性

- **仅 2D 曲线**（摘要未提 3D；偏移曲线解耦在 3D 中需要用**可展曲面**的对应物，更复杂）。
- **曲率极值只在线段两端**是设计限制 —— 意味着**曲率剖面的形状空间受限于两种基元的组合**，无法表达任意曲率剖面。
- **无全局优化 ⇒ 无法保证全局最优的「光滑度」**。曲线在密集控制点区域可能仍有可见的波动（自适应配置只能缓解）。
- 摘要未给出与 Bézier / G² B-spline / F-curves 的定量对比。

## 实现建议

- **实现难度**：**低~中**
- **预期性能**：**实时**（O(1) 局部更新）
- **适用场景**：
  - **需要精确曲率控制的曲线设计**（CAD、字体轮廓、图标、动画路径）
  - **交互式曲线编辑工具**
  - **需要精确复现圆弧/椭圆的场合**
- **对团队的直接价值**：**高（可直接实现）**。这是一个「可脱离论文单独使用」的几何构造：**偏移曲线解耦 + 两种基元 + 二次方程求解**。我们可以把它作为一个轻量的 G² 曲线库实现，用于参数化、曲面重建的引导线设计等场景。

## 可直接抄的工程结论

1. **偏移曲线是控制曲率的有力工具**：`κ_offset = κ / (1 + dκ)` 是闭式的 ⇒ 曲率幅值可以被**独立地、解析地**指定。
2. **用「几何 + 偏移量」两个参数换取一个自由度** —— 这是解耦的标准模式：把耦合的两个量映射到两个独立参数。
3. **局部 + 确定性 + 闭式权重 = 交互性**。曲线构造类方法若要能交互编辑，必须避免全局优化与迭代求解。
4. **用两段基本图元复现复杂剖面**（圆弧、椭圆）是验证构造正确性的好方法。
