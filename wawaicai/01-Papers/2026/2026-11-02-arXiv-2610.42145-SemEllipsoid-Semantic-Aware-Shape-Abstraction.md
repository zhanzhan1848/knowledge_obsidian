# SemEllipsoid: Semantic-aware Shape Abstraction with Ellipsoid

## 一句话总结

给形状抽象引入**语义约束**：用**椭球图元**拟合 3D 形状，同时通过**可微的「投影–混合–评估」方案**把多视角语义 mask 的约束**注入到图元优化里**，交替求解「整数标签分配 + 连续图元参数」，产出**几何忠实且语义一致、不跨语义边界**的抽象结果——**非学习方法**，无需训练数据。

## 技术概述

### 问题：几何感知的形状抽象不够用

| 现状 | 目标 | 缺陷 |
|------|------|------|
| **几何感知抽象**（Marching-Primitives、Superquadrics 拟合、PrimitiveAnything、PartGen） | 用最少图元近似输入形状，**几何保真** | **忽略语义一致性** ⟹ 图元跨越多个语义部件 |
| **部件生成**（PartGen / AutoPartGen / PartCrafter / PartPacker / LLM-Primitives / OmniPart） | 生成语义部件 | 部件可**相互重叠** ⟹ 同样语义违规；且依赖特定数据集 |
| **共分割**（Shu 2016 等） | 同类形状群组内分部件 | 需成组输入；结果**未必符合人类语义** |

**论文动机实例**（Fig.2）：Marching-Primitives 对椅子的输出中，一个 superquadric 同时跨越**椅腿**与**椅背**；后续做「加宽椅腿」的部件级编辑时，必然连带影响椅背 ⟹ **下游编辑伪影**。

### 新任务定义：语义感知的形状抽象

$$\mathbf{S}_a=\boldsymbol{\psi}\big(\mathbf{S},\,\mathbf{g},\,\{\mathbf{p}_{\text{box}},\mathbf{p}_{\text{ellips}},\mathbf{p}_{\text{sphere}},\ldots\}\big)$$

**硬约束**：每个图元必须**绑定唯一语义区域**，**不得跨语义标签**（no cross-semantic placement）。

论文的具体设定：
- **只使用椭球** $\mathbf{p}_i$（可微解析表达 + 表示力足够）⟹ 参数化为中心 $\mathbf{c}_i$ + 协方差矩阵 $\mathbf{M}_i$
- **语义信号** $\mathbf{g}$ = **多视角 2D 语义 mask**（$\mathcal{I}_i$，$i=1..M$），已知标签集 $\mathbf{L}_a$，各视角粒度一致

### 语义从哪来？——基础模型

借用 **SAM**（Kirillov 2023）与 **DINO**（Zhang 2022）产生**类别无关、开放词表**的部件语义。

### 怎么注入？——投影–混合–评估三段式

这是本文**最核心的技术贡献**。

## 算法详解

### 总目标函数（Eq.3）

$$\boldsymbol{\theta}^{\star},\boldsymbol{\Pi}^{\star}=\arg\min_{\boldsymbol{\theta},\boldsymbol{\Pi}}\underbrace{\mathcal{L}_g(\boldsymbol{\theta},\mathbf{S})}_{\text{几何保真}}+\lambda\underbrace{\mathcal{L}_s(\boldsymbol{\theta},\boldsymbol{\Pi},\mathbf{S})}_{\text{语义一致}}+\mu\underbrace{\mathcal{L}_c(\boldsymbol{\theta})}_{\text{紧凑性}}$$

- $\boldsymbol{\theta}=\{\theta_i\}$：连续变量（椭球参数）
- $\boldsymbol{\Pi}=\{l_{i,j}\}$：**整数变量**（图元→标签分配）
- ⟹ **混合整数非凸问题**，用交替优化求解

### ① 几何逼近项 $\mathcal{L}_g$（SDF 占据场）

对每个椭球用 **Quilez (2008) 的解析 SDF 近似**，再转成软占据：

$$O^{i}(x)=w_{i}\cdot \mathrm{Sigmoid}(-\eta\, d^{i}(x))$$

- $w_i$：**图元的开关权重**（与几何参数一起优化 ⟹ 可自动剪枝）
- $\eta$：Sigmoid 锐度

整个抽象体的占据场用 **softmax 聚合**（温度 $\psi$）：

$$O_{\text{abs}}(x)=\sum_{i=1}^{N}O^{i}(x)\cdot\frac{e^{O^{i}(x)/\psi}}{\sum_{j=1}^{N}e^{O^{j}(x)/\psi}}$$

$$\mathcal{L}_g=\frac{1}{|\Omega_s|}\sum_{x\in\Omega_s}\|O_s(x)-O_{\text{abs}}(x)\|_2^2$$

### ② 语义一致项 $\mathcal{L}_s$（本文技术核心）

#### (a) 可微投影

把椭球 $\mathbf{p}_i$ 正交投影到 mask 图像平面，得到**椭圆**。

关键推导：视线 $\vec{v}$ 与椭球相切 ⟹
1. 椭球面方程 $(x-c)^TM(x-c)=1$
2. 切向条件 $\nabla f(x)\cdot\vec{v}=0$
3. ⟹ 得**过椭球中心**的交平面 $\vec{v}^TM(x-c)=0$（Eq.9）

二维点 $x_{2d}$ 对应 3D 点 $\mathbf{x}=[e_1,e_2]\cdot x_{2d}+c$，视线 $r=x+t\vec{v}$ 与该平面交于：

$$\mathfrak{p}^{*}=(x-c)-\frac{\vec{v}\vec{v}^TM}{\vec{v}^TM\vec{v}}(x-c)+c$$

代入椭球方程得**投影椭圆方程**（Eq.11）：

$$g(x_{2d})=x_{2d}^{T}[e_1,e_2]^{T}\Big(I-\frac{\vec{v}\vec{v}^TM}{\vec{v}^TM\vec{v}}\Big)^{T}M\Big(I-\frac{\vec{v}\vec{v}^TM}{\vec{v}^TM\vec{v}}\Big)[e_1,e_2]x_{2d}-1$$

再复用一阶近似 $d_{2d}=g/\|\nabla g\|$ → 二维占据 $\mathcal{O}_{2d}$。

> ⚠️ **数值稳定性注意**：论文明确选择**正交投影**而非透视投影，理由是「透视版本需要仔细实现以避免数值不稳定（Eberly 1999）」。这是可直接借鉴的工程结论。

#### (b) Alpha blending（解决遮挡死锁）

**问题**：图元分布在形状体积**内部**，互相遮挡。若用常规 **z-less**（取最近表面渲染），被完全遮挡的图元**永远得不到梯度** ⟹ 优化死锁。

**解法**：把「深度可见性」软化为 **Softmax 深度混合**：

$$\widetilde{\mathcal{O}}_{2d}^{i}=\mathcal{O}_{2d}^{i}(x_{2d})\times \mathrm{Softmax}\big(\mathbf{z}/\beta\big)(i)$$

- $\mathbf{z}=(z_1,\ldots,z_N)$：各图元前表面深度
- $\beta$：温度
  - **高温** → 概率分布「软」⟹ 所有图元都获得梯度（各向可见）
  - **低温** → 「硬」⟹ 退化为 z-less

#### (c) 语义惩罚

图元 $i$ 贴标签 $j$ 的惩罚 = 其投影椭圆与**其它标签**像素的重叠：

$$\mathcal{L}_{\text{sem}}[i,j]=\sum_{m=1}^{M}\mathbb{E}_{x_{2d}\sim U([-1,1]^2)}\Big[\sum_{k\neq j}\mathcal{I}_{m,k}(x_{2d})\cdot\widetilde{\mathcal{O}}_{2d}^{i,m}(x_{2d})\Big]$$

$$\mathcal{L}_s=\frac{1}{N\times\mathbf{L}_a}\sum_{i,j}^{N,\mathbf{L}_a}\mathcal{L}_{\text{sem}}[i,j]\times\mathcal{A}[i,j]$$

### ③ 紧凑性项 $\mathcal{L}_c$（自动剪枝）

$$\mathcal{L}_c=\frac{1}{N}\sum_{i=1}^{N}w_i$$

优化结束后**丢弃 $w_i<0.5$ 的图元**。

### ④ 交替优化

**Step I — 标签分配（整数线性规划）**

$$\boldsymbol{\Pi}^{*}=\arg\min_{\mathcal{A}}\sum_{ij}\mathcal{A}[i,j]\times\mathcal{L}_{\text{sem}}[i,j]$$

约束：① 每个图元**恰好一个**标签；② 每个标签**至少一个**图元；③ 总惩罚最小。

- 变量数仅 $N\times\mathbf{L}_a$ ⟹ **开销很小**
- 用 **SciPy**（封装 **HiGHS** 求解器）

**Step II — 图元优化（连续梯度）**

$$\mathcal{L}=\frac{1}{|\Omega_s|}\sum_x\|O_s(x)-O_{\text{abs}}(x)\|^2+\frac{\lambda}{\mathbf{L}_a N}\sum_{i,j}\mathcal{L}_{\text{sem}}[i,j]\mathcal{A}[i,j]+\frac{\mu}{N}\sum_i w_i$$

- 优化器：**RAdam**
- 下一轮用**上一轮的图元配置**去重解标签 ⟹ 交替迭代至最大迭代数

### ⑤ 预处理（GMM 初始化）

1. 在形状体积内**均匀采样 10 万点**
2. **GMM 聚类**（$K=20\sim60$）⟹ 粗粒度椭球簇
3. **细长结构处理**：计算每个簇的**最长轴/最短轴比**，超过阈值（10.0）则**递归用 $K=2$ 细分**，直到满足条件（处理细桌腿）
4. 每簇估计一个椭球

### ⑥ 后合并（Post-merging）⟹ 多层级抽象

1. 每个语义标签内做**连通分量检测**（如椅子的 4 条腿 ⟹ 4 个连通分量）
2. 连通分量内**递归合并**：若合并后 OBB 体积 / 体积和 **< 2.0**，则合并
3. 对合并后的簇重新初始化椭球，跑 **~500 步** Step II（保持各自标签）

- 默认阈值 ⟹ 约 **3× 图元数削减**
- 调阈值 ⟹ 得到**多层级抽象**

## 评估指标（本文也提出了新指标）

**几何保真**：`IoU (↑)`、`Chamfer-L1 (↓)`

**语义一致性（新指标 `SV`，Semantic Violation）**：
- 每个图元均匀采样 $K=2000$ 点，每个点取形状表面上**最近点所属标签**
- 若所有 $K$ 点同标签 ⟹ 该图元语义一致
- **阈值 $Q$** 语义一致率：低于 $Q\%$ 则判为不一致
- `SVp-Q%`：**图元级**不一致图元占比
- `SVc-Q%`：**部件级**不一致部件占比
- `SVs-Q%`：**形状级**含至少一个不一致图元的形状占比
- 实验用 $Q=80,90,95$

### 消融（Table 2，95% 一致性水平）

| 变体 | 影响 |
|------|------|
| **去掉语义损失项**（$\lambda$） | IoU 明显下降（如 chair 0.908→0.854）；`SVp-95%` **灾难性恶化**（chair 0.006→0.320，knife 0.006→0.160）⟹ **语义项是核心** |
| **去掉 alpha blending 调度**（改用 z-less） | `SVp-95%` 同样大幅上升（chair 0.030→0.085）；说明**遮挡处理对优化成功率至关重要** |
| **去掉多视角 mask**（只用单视角） | 一致性显著下降（table `SVc-95%` 0.061→0.221） |
| $\lambda$ 调度（10→200） | **优于**固定 $\lambda=10$ 或 200 |

> ✅ **消融结论清晰**：语义项、alpha blending、多视角三者**缺一不可**，且 $\lambda$ 的**指数调度**显著优于固定值。

## 局限性（作者自述）

1. **图元数量固定**（经验设定），不支持**动态增删**；未来方向：初始化大量图元 + 增加「存在性」整数变量联合优化
2. **只做 2D→3D 投影**；作者认为「**把语义掩膜反投影到 3D 图元上、在 3D 空间计算语义偏差**」是更有前景的替代方案
3. **未结合内部结构分析**（骨架、中轴）⟹ 计划与 interior/skeleton/medial axis 分析结合
4. **依赖多视角语义 mask 的一致性**：SAM 单视角质量高，但**多视角标签一致性常需人工介入** ⟹ 需要更强的多视角基础模型

## 实现难度与数值稳定性

### 算法复杂度
- **中**
  - 无需训练、无需数据集标注 ⟹ **上手门槛远低于 PrimitiveAnything / PartGen**
  - 三个可复用模块：GMM 初始化（~10 s）、可微投影 + alpha blending 损失、ILP 标签分配
  - **最重的部分在 CPU 端**：ILP（HiGHS）+ 每轮 16k×N 的占据场计算

### 数值稳定性
- ✅ **正交投影**（论文明示为避免透视投影的数值不稳定）—— 可直接照抄
- ✅ **Sigmoid + softmax 软化**取代 hard min/max ⟹ 全程可微、无梯度断裂
- ✅ **softmax 温度 $\psi$ 从 5 增至 40、$\eta$ 从 40 增至 600** ⟹ 初期「软」便于探索，后期「硬」提升精度（典型的 annealing 策略）
- ✅ **alpha blending 的 $\beta=0.01$ 很小** ⟹ 接近 z-less 但保留梯度
- ✅ **权重调度（$\lambda$ 10→200, $\mu$ 0.01→0.1）** ⟹ 先保几何再压语义/剪枝，避免早期剪枝破坏拟合
- ⚠️ **$\vec{v}^TM\vec{v}$ 分母**：若视线方向与椭球某轴近乎平行（细长椭球），分母趋近 0 ⟹ 需 eps 保护（论文未详述，**实现时需自行加保护**）
- ⚠️ **ILP 的「每标签至少一个图元」约束**在 $N<\mathbf{L}_a$ 时**不可满足** ⟹ 需保证初始图元数 ≥ 标签数
- ⚠️ **$w_i$ 剪枝阈值 0.5** 是硬编码启发式；若 $\mu$ 调度不当会导致**过早剪枝**（掉形状 ⟹ 几何项被破坏）

### 依赖项
- PyTorch（可微渲染/可微几何）
- SciPy → **HiGHS**（整数线性规划）
- scikit-learn（GMM）
- 外部：SAM / DINO（语义 mask 来源）
- 开源参考：无直接前身库（Marching-Primitives、PrimitiveAnything、PartGen 为对照方法）

## 推荐结论

✅ **推荐实现**

### 理由
1. **「语义一致性」是被忽视但真实存在的几何处理约束**：现有形状抽象方法在下游部件编辑时必然出伪影，本文把这个问题**形式化 + 可微化 + 可求解**，这是**方法论层面的空缺填补**
2. **projection-blending-evaluation 三段式是可迁移的通用技术**：任何「需要在 3D 图元优化中注入 2D 观测约束」的场景都能用（不止形状抽象）
3. **非学习方法的工程友好度**：无数据集、无训练、无预训练权重依赖 ⟹ 集成到现有 CAD/网格管线成本低
4. **消融扎实**：语义项 / alpha blending / 多视角 / $\lambda$ 调度四个消融都指向同一结论，**方法可信度高**
5. **运行成本低**：单形状 ~1 min / 2 GB VRAM ⟹ 可做离线批处理

### 实现优先级建议
| 优先级 | 内容 |
|--------|------|
| **P0** | GMM 初始化 + 可微投影 + alpha blending 语义项 + RAdam 连续优化（**先不做 ILP**，用贪心「取最小惩罚标签 + 冲突回退」替代，工程量减半） |
| **P1** | ILP 标签分配（HiGHS），替换贪心 |
| **P2** | 后合并 + 多层级抽象 |
| **P3** | 3D 反投影的语义项（作者自述的更优方向） |

### 对我们的启发
- **[[形状抽象]]**：把「几何保真」升级为「几何保真 + 语义保真」的双目标范式
- **[[可微图元拟合]]**：SDF-based 软占据 + softmax 聚合，是图元拟合的标准做法（可复用到 capsule/box/CSG 图元）
- **[[可微投影]]**：椭球→椭圆的解析投影公式（Eq.11）**可直接编码复用**，不限于形状抽象
- **[[遮挡处理与软可见性]]**：alpha blending 深度混合 ⟹ 「被遮挡图元拿不到梯度」这个问题在所有「体积内多图元」优化中通用（如神经 SDF 的多壳层拟合）
- **[[交替优化与混合整数问题]]**：整数标签 + 连续参数 ⟹ 交替优化的经典范式（对照 [[2610.14113-Autoregressive-Topology-Repair-Meshes]] 的拓扑修复思路）
- **[[语义分割作为几何先验]]**：SAM/DINO 提供类别无关语义 ⟹ 可作为参数化/修复的自动约束来源
