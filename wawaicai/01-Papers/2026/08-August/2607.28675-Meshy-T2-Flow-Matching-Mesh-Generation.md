# Fast Native Mesh Generation with Flow Matching (Meshy T2)

## 核心方法

Meshy T2 是一个基于 Flow Matching 的快速原生网格生成框架。核心创新点：

1. **Vertex-set Mesh VAE**: 将网格编码为每个顶点一个连续潜变量，在单次前向传播中解码顶点、边连接和面缠绕顺序，无需顶点量化或焊接

2. **Coarse-to-Fine 级联生成**: 
   - Image-conditioned voxel flow 首先生成粗略占用脚手架
   - Mesh flow 填充每个顶点的潜变量，受图像、脚手架和顶点预算条件控制

3. **关键特性**:
   - 并行基于流的综合实现交互式生成速度
   - 通过顶点预算有效控制面数
   - 原生支持多部件资产生成

## 算法复杂度

- 端到端图像到网格生成中位时间：**6秒**
- 比自回归基线快一个数量级

## 创新点

- 保留高精度几何和艺术级拓扑
- 无需顶点量化或焊接
- 支持多部件资产生成（部件从生成的连接中直接出现）
