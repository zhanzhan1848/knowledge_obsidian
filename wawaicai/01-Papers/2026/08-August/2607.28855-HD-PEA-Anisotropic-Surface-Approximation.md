# Learning Manifolds in High-D Point Embedding for Anisotropic Surface Approximation

## 核心方法

HD-PEA (High-Dimensional Point Embedding Anisotropic) 是一个高效的基于学习的各向异性曲面近似框架：

1. **高维欧几里得点嵌入**: 将输入点云映射到高维流形嵌入空间

2. **Patch-based Meta-embedding 方案**: 无需重新训练或微调即可处理大规模点云

3. **切线子空间估计**: 用于高维嵌入流形近似和各向异性流形重建

## 主要贡献

- 提出可扩展深度学习框架，从点云构建高维欧几里得点嵌入空间
- 用于3D各向异性曲面网格近似和黎曼曲率张量估计
- 在 Thingi10K、AIM@SHAPE、Stanford 3D Scanning Repository、ScanNet 数据集上验证

## 算法特点

- 相比各向同性和自适应网格：更高保真度、更少元素、更好数值稳定性
- 几何对齐的曲面表示
- 可扩展到大规模点云

## 数据集

- Thingi10K dataset
- AIM@SHAPE
- Stanford 3D Scanning Repository
- ScanNet dataset
