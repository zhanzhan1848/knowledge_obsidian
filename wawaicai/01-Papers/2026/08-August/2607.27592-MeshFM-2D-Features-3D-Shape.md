# MeshFM: 2D Features Are All You Need for 3D Shape Understanding

## 核心方法

MeshFM 是一个高效的前馈框架，从3D输入提取丰富特征：

1. **2D 特征蒸馏**: 从视觉基础模型中提取2D特征到3D

2. **两阶段训练策略**:
   - 第一阶段：仅使用2D特征监督优化3D特征场
   - 第二阶段：训练网络回归该特征场

3. **无需3D注释**: 依赖2D基础模型中的强大信息

## 应用场景

- 部件分割 (Part segmentation)
- 密集对应 (Dense correspondence)
- 网格变形 (Mesh deformation)

## 创新点

- 训练仅需2D监督
- 性能与使用3D监督的方法相当
- 无需任务特定微调
- 对输入对象极端旋转具有鲁棒性

## 与 libigl/CGAL 的关系

特征可应用于下游几何处理任务，如网格变形和对应
