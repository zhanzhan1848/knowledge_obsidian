# Iskra: A System for Inverse Geometry Processing

## 核心方法

Iskra 是一个通过几何处理问题解进行梯度的系统：

1. **可微几何处理**: 对广泛的几何算法求导，利用现有的针对特定问题的快速方案（local-global 和 ADMM 求解器）

2. **与机器学习框架兼容**: 开启逆几何处理新应用

3. **Scatter-gather 方法**: 将网格处理与基于张量的工作流结合

4. **伴随方法**: 应用于用户指定的命令式代码，生成高效的 backward pass

## 应用场景

演示了以下应用的可微性：
- Mean curvature flow
- Spectral conformal parameterization
- Geodesic distance computation
- As-rigid-as-possible deformation

## 创新点

- 无需重新表述现有几何处理算法
- 低实现工作量
- 快速运行时间和更低内存需求
- 比非专为几何处理设计的可微优化工具更优

## 开源实现

- 兼容 PyTorch、TensorFlow 等 ML 框架
