# Learned Smoothing in Operator-Adapted Multigrid: Controlled Accuracy Gains and Computational Limits

## 一句话总结

对「学习型多重网格」做**冷静的对照评估**：在**固定迭代预算**下比较学习型 V-cycle 与经典循环会混淆「局部近似增益」与「实际求解器效率」。结论是——学习型平滑子在导电通道问题上把能量误差降 5.7–6.1 倍，但在绝缘障碍上只有 1.38–1.45 倍；且当经典平滑预算增加到 8–14 步（通道）/ 5–8 步（障碍）时，**经典方案反超**；实测 CPU 实现**无计算优势**。

> 一篇「泼冷水」的高质量评估论文，对当前热火的"学习求解器"是重要的现实校准。

## 核心贡献

1. **方法论澄清**：区分「局部近似质量增益」与「端到端求解器效率」，指出固定迭代预算对比方法的缺陷
2. **学习型 V-cycle 的完整构造**：算子依赖的传递算子、Galerkin 粗算子、近核 deflation、能量范数安全阀（safeguard）；**仅平滑子被训练**
3. **结构性结论**：网络架构表示一个**固定多项式平滑子**的类，且对载荷**正齐次**（positively homogeneous）
4. **关键量化结果**：
   - 导电通道：单次学习 pass 相对「四步 Jacobi 预条件 CG 平滑」的同一循环，能量误差降 **5.7–6.1 倍**
   - 绝缘障碍：仅 **1.38–1.45 倍**
   - 经典平滑预算增加到 **8–14 步**（通道）/ **5–8 步**（障碍）时，几何平均精度**交叉反超**
5. **诚实的负面结论**：实测 CPU 实现**相对被测经典求解器无计算优势**；载荷变化与**浮岛（floating islands）**进一步限制精度

## 技术方案

### 关键技术

| 技术 | 说明 |
|------|------|
| **算子自适应多重网格** | 传递算子依赖算子（几何/代数），粗算子由 Galerkin 投影生成 |
| **近核 deflation** | 用近核（近似奇异的）低秩修正加速收敛 |
| **能量范数安全阀** | 监控能量范数下的迭代行为，必要时回退 |
| **只训平滑子** | 保持多重网格整体结构不变 → 学习部分可控 |
| **固定多项式平滑子类** | 网络架构的正齐次性 → 保证对载荷缩放不变 |
| **浮岛 (floating islands)** | 高对比度问题中，孤立区域在多重网格层级间不被有效传递 → 限制精度 |

### 核心公式

**能量范数误差**：

$$E(\mathbf{u}) = \|\mathbf{u} - \mathbf{u}_h\|_A^2, \qquad \|\mathbf{v}\|_A^2 = \mathbf{v}^\top A \mathbf{v}$$

**经典 vs 学习，同一循环的能量误差比**：

$$\text{ratio} = \frac{E_{\text{learned}}}{E_{\text{classical}}} = \begin{cases} 5.7 - 6.1 \times 10^{-1} & \text{导电通道} \\ 1.38 - 1.45 \times 10^{-1} & \text{绝缘障碍} \end{cases}$$

**正齐次性**（保证载荷缩放不变）：

$$f(\alpha \mathbf{b}) = \alpha\, f(\mathbf{b}), \quad \alpha > 0$$

**近核 deflation**：

$$A_{\text{defl}} = A + \sum_{i=1}^{r} \sigma_i \, \mathbf{u}_i \mathbf{u}_i^\top$$

## 实验结论

- **问题类型**：高对比度椭圆问题（high-contrast elliptic），**非结构化有限元网格**
- **测试集**：全新生成的导电通道问题（fresh conductive-channel problems）+ 绝缘障碍问题
- **关键对照**（固定输入测试）：在 100 个新输入上，每个位置与训练初始化上，细网格学习平滑子的能量范数误差**小于其自身输入在五维 Krylov 空间上的精确最小值**，比例达 **97–100/100**
  - ⚠️ 但论文明确指出：这**并未**确立其优于**所有**多项式平滑循环
- **交叉点**：经典平滑预算增加时，经典在 **8–14 步**（通道）与 **5–8 步**（障碍）超过学习循环
- **效率**：实测 CPU 实现对被测经典求解器**无计算优势**
- **鲁棒性**：载荷变化与浮岛进一步限制精度

## 实现建议

### 可行性分析：学习型平滑子是否值得上

**算法复杂度**
- 每次平滑：学习版 O(n · c) + 推理开销（网络前向）；经典版 O(n · s)（s 步）
- 交叉点：s ≈ 8–14（通道）、s ≈ 5–8（障碍）时经典反超 → **经典在 s ≤ 8 时已具竞争力**

**实现难度**
- 算法复杂度：**中**（需在多重网格框架内训练平滑子）
- 数值稳定性：**有隐患** — 论文明确指出**浮岛**问题与**载荷变化**会限制精度 → 训练分布外泛化差
- 依赖项：**PyTorch**（训练）+ **PETSc / hypre**（求解器框架）

**推荐结论**：⚠️ **谨慎评估 — 不建议直接替换经典平滑子**

### 工程建议（可直接采纳的评估方法论）

本文最大的价值其实是**评估框架**，建议我们内部对任何"学习方法替换经典几何/数值组件"的提案采用同样方法：

1. **不要用固定迭代预算对比** —— 必须对比"达到同一精度所需的总计算量"
2. **必须报告交叉点** —— "经典方案加多少步就追平？"（本文：8–14 步）→ 这才是可决策的信息
3. **必须在分布外测试** —— 论文用「全新生成的问题」测试，这比训练集上的表现有意义得多
4. **必须测试最坏情况** —— 绝缘障碍场景只有 1.38–1.45 倍增益，说明**增益高度依赖问题结构**
5. **浮岛问题需要专门诊断** —— 这是高对比度几何的固有问题，纯数据方法难以自动解决

**适用场景（真正适合学习型平滑子的）**：解算器在 GPU 上运行且经典平滑器受限于**非规则内存访问**（非结构化网格）；此时经典的"多步平滑"成本被访存主导，学习的一次平滑可能有真实收益。
