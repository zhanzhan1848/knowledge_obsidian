## 核心贡献

> **CPAB（连续分片仿射）微分同胚一直卡在「反向传播」上。本文把梯度计算复杂度从 O(dTN) 降到 O(TN + dC) —— 2D 梯度快 10⁴×、显存省 500× —— 首次让细网格 CPAB 在 2D/3D 变得可用。**

1. **提出 FG-CPAB（factorized-gradient CPAB）**：通过**把轨迹积分与参数空间投影解耦**，把梯度计算复杂度从 **O(dTN)** 降到 **O(TN + dC)**
   - $T$ = 积分步数，$N$ = 被变换点数，$C$ = 网格单元数，$d = \dim(\theta)$
2. **核心洞察**：把敏感度（sensitivity）**重组为与参数无关的几何统计量（parameter-independent geometric statistics）**，最后再通过**稀疏 CPA 基**投影回参数空间
   > 「虽然伴随法（adjoint methods）对一般 ODE 是标准技术，但**线性 CPA 基允许精确分解为 cell-local moments（单元局部矩）**，这是先前通用伴随求解器无法利用的。」
3. **配套的显存优化**：**分段检查点（segmented checkpointing）** 实现内存高效的伴随反向传播 —— 改变中间前向状态的物化方式，**不改变反向扫描本身**，故不改变因子化梯度。
4. **表达力解锁**：细网格 CPAB 首次在 2D/3D 变得实用 → **表达力显著提升**，且**网格分辨率越高配准越好**（单调趋势直到测试上限）。
5. **实测加速**：
   | 维度 | 前向 | 反向（梯度） | 峰值显存 |
   |------|------|-------------|---------|
   | **2D** | 最高 **75×** | 最高 **10⁴×** | **>500×** 降低 |
   | **3D** | 最高 **60×** | **4,477×** | **180×** 降低 |
   | 1D | — | **301×** | — |

## 技术方案

### 背景：CPAB 是什么

- **微分同胚（diffeomorphism）**：可微、可逆、且逆也可微 → 天然保证**保拓扑、无折叠、无撕裂、无自交**
- 用途：配准（registration）、空间对齐、几何变形 —— 折叠/撕裂/自交会产出**几何无效**的变形
- 常规路线：SVF（常速度场）或 LDDMM（时变速度场）积分 —— 但**依赖稠密网格离散化**
- **CPAB**（Freifeld et al., ICCV 2015 / TPAMI 2017）：用**关于给定剖分（tessellation）分片仿射的连续速度场**参数化微分同胚族
  - ⭐ **关键优势**：$d = \dim(\theta)$ **只取决于剖分的精细度，与数据分辨率无关**

### 瓶颈与解法

```
❌ 旧做法：轨迹积分 与 对 θ 的梯度计算 紧耦合
   → 复杂度 O(dTN)：参数维度 d 直接进入 kernel launch 几何
   → 标准 libcpab 在 2D 跑不过 N_tess = 12

✅ FG-CPAB：分离「积分」与「参数空间投影」
   → 复杂度 O(TN + dC)
   → 2D 网格 C = 4·N_tess² 个三角形单元
   → 可持续 scale 到更细分辨率
```

**技术组件**：

| 组件 | 说明 |
|------|------|
| **伴随因子化（adjoint factorization）** | 通过**矩累加（moment accumulation）**实现 |
| **梯度恢复（gradient recovery）** | 因子化梯度的恢复公式（Eq. 12） |
| **分段检查点（segmented checkpointing）** | 内存高效的伴随实现；**不改变渐近复杂度，但常数很重要** —— 减少寄存器压力与局部内存流量可显著提升 GPU 占用率 |
| **节点稀疏基（nodal sparse basis）** | 基 $\mathbf{B}$ 通过 CPA 速度场的**节点参数化**高效构造；先在剖分顶点上表示速度场，再在节点空间施加 CPAB 约束 → 得到与约束式构造**张成同一空间**的稀疏基 |
| **稀疏基消融（Basis sparsity）** | 论文 §4.7 消融 |

### 数值一致性（附录 C 论证）

- 论文**明确承认**：前向与反向离散化**并非代数等价**，梯度应理解为「对矩阵指数前向计算之导数的**近似**」
- 但：
  - 单元内失配是 **高阶**的 —— 固定单元矩阵、有限积分区间内，局部积分器不匹配 **O(h³)** → 全局 **O(h²)**，**高于**单元分配不一致导致的 **O(h)** 误差
  - **与先前 CPAB 实现使用相同的前向与梯度离散化**，以确保公平比较（对比引入不同积分方案作为额外性能/精度差异来源）
- **实证梯度校验**：与矩阵指数前向计算的**中心有限差分**梯度对比
  - 标准设置（**50 个 solver 步**）下：**余弦相似度 > 0.998**，**相对误差 < 0.05**

### 分段长度 S 的选择（Table 7，checkpoint 段长扫描）

| 段长 S | 段数 | 前向 (ms) | 反向 (ms) |
|--------|------|----------|-----------|
| 2 | 25 | 0.898 | 4.161 |
| 3 | 17 | 0.885 | 3.977 |

### 应用场景与设置

**① 3D 可变形配准（IXI 脑 MRI）**
- 数据：**IXI brain MRI**（CC BY-SA 3.0），cropped、仿射对齐、**FreeSurfer 分割**、归一化到 $[0,1]$，分辨率 **160×192×224**
- **115 个测试被试**，直接评估（**无需离线训练**）
- 固定图 = TransMorph IXI 数据的公共 atlas（原出自 CycleMorph protocol）+ 对应分割；从 atlas 配准到每个病人，用 **MRI 强度**优化，**解剖标签仅用于评估**
- **Dice**：TransMorph protocol 的 **30 个解剖标签**
- CPAB 配置：**20×20×20 剖分**；composed 变体每步顺序应用多个 CPAB 变换
- **每个被试独立拟合参数**：**Adam，200 次迭代**
- 损失：**LNCC**（窗口 9，步长 2，权重 1.0）+ **扩散正则**（位移场的 L2 梯度，权重 3.0）

**② 作为神经算子的低维几何编码**
- 基准：**DIMON** 反应-扩散基准（MIT License，commit a22ed33）
- 保持 DIMON 的数据生成、transport 管线与算子架构不变，**只改几何表示**
- **DIMON 基线**：几何用 LDDMM 变形表示的 **PCA** 编码
- **本文变体**：从参考域到每个目标域拟合一个 CPAB 微分同胚，**直接用 CPAB 参数作几何编码**；**6×6 剖分 → 122 个参数**
- 公平对比：**DIMON 基线也设为 122 个 PCA 系数** → 差异反映**几何参数化质量**，而非编码维度

**③ 非定常速度场的 CPAB 复合（§4.6）**

### 其他实验设置

- **Fig. 1 基准**：单张 **RTX A6000** GPU，**125,000 个 2D 点**，batch size **16**
- **求解器步数**：全文用 **50 步**（除非另注）
  > 「精度在低步数时快速提升，约 **50 步**后**基本趋于平台**，而运行时继续增长」→ 支持用 50 步作稳健默认值
- **剖分分辨率消融**（Fig. 8）：**提高剖分分辨率持续改善配准质量，直到测试的最大分辨率** → 证实细网格提供更多局部灵活性
  > 「这直接印证：**梯度因子化带来的可扩展性直接与模型质量挂钩** —— 不仅因为更快，而是因为它让人进入**更具表达力的剖分区间**。」

## 实验结论

| 维度 | 前向加速 | 反向加速 | 峰值显存降低 |
|------|---------|---------|-------------|
| **2D** | 最高 75× | **10⁴×** | **>500×** |
| **3D** | 最高 60× | **4,477×** | **180×** |
| **1D** | — | **301×** | — |

**标量能力对比**：
- 标准实现（libcpab）在 2D 下**不支持 $N_{\text{tess}} > 12$**（因反向传播把参数维度直接耦合到 kernel launch 几何 —— 附录 A.1 专门分析「为什么标准反向传播停止扩展」）；**FG-CPAB 可持续扩展到更细分辨率**
- 3D 情况类似

**梯度质量**：余弦相似度 **> 0.998**，相对误差 **< 0.05**（50 步）。

**表达力**：剖分分辨率 ↑ → 配准质量 ↑（真实与合成配准设定下均成立）。

## 局限性（论文 §5 Discussion 明确）

1. **不消除剖分式模型的维数限制**：
   - 因子化可推广到任意空间维 $K$（$K(K+1)$ 矩，参数依赖仅在最终投影）
   - **但单元数随 $K$ 指数增长**
   - ⇒ **本文实证结论仅限 $K \leq 3$**；更高维需额外结构（可分离、低秩、或自适应细化的速度场）
2. **梯度是近似**：前向与反向离散化非代数等价（但失配高阶，且与先前 CPAB 实现一致）
3. 依赖 CPAB 本身的固有局限（速度场分片仿射的表达力上限）

## 实现建议

- **实现难度**：**高**。数学不难（伴随法 + 矩累加 + 稀疏基投影），但**GPU 实现细节（分段检查点、寄存器压力、kernel launch 几何）是主要工程量**。
- **数值稳定性**：**中-高**。梯度是近似的（但高阶失配，cos-sim > 0.998 实证可信）；单元分配不一致是 **O(h)** 主误差源；建议沿用 50 步。
- **依赖项**：
  - **PyTorch**（可微 + 自定义 CUDA kernel）+ **CUDA**
  - **libcpab**（基线对比，非必需）
  - **VoxelMorph** / **torch-lddmm**（基线）
  - 配准：LNCC 可用 **MONAI** 或自写；Adam 用 PyTorch
  - 分割/预处理：**FreeSurfer**；数据 **IXI**
- **适用场景**：
  - ✅ **需要拓扑保证的变形建模**（配准、形变、几何 warp）—— 折叠/自交是硬约束的场景
  - ✅ **参数维度与数据分辨率解耦**的场景（低维参数、细网格表达力）
  - ✅ **神经算子的几何条件编码**（122 维几何码 vs PCA 122 维的公平对比范式可直接借用）
  - ✅ **端到端可微的几何管线**（CPAB 本身可微）
  - ❌ **高维空间**（K ≥ 4）—— 单元数指数爆炸
  - ❌ 需要最高表达力的任意形变（CPAB 的分片仿射假设是限制）
- **性能预期**：2D 反向快 10⁴×、显存省 500×；3D 反向快 4,477×、显存省 180×。**在细网格区间的优势最大**。
- **移植建议**：**建议先做 2D POC**。核心洞察（敏感度 → 参数无关几何统计量 → 稀疏基投影）**可以迁移到我们自己的可微几何管线**：任何「参数维度进入 kernel launch 几何」的慢反向传播，都值得做同样的因子化尝试。

## 备注

> **与 [[2610-35347-CVTSplat]] 的共同主题 —— 「利用几何规整性换取计算效率」**：
> - CVTSplat：CVT 的**几何规整性** → 邻居少 → KNN 候选集小 → 近似构造快 → 光栅化器可特化
> - FG-CPAB：CPAB 的**线性基结构** → 敏感度可分解为单元局部矩 → 梯度计算与参数维度解耦
>
> **共同的方法论**：**「表示本身的数学结构可以被用来降低其计算成本」** —— 这比「换个更快的实现」高一个层次。建议把这条作为我们审视自身管线的一个检查项：**我们的表示有什么可利用的代数结构？**
>
> 另外注意：FG-CPAB 的第 4.5 节（神经算子几何编码）**方法论价值极高** —— 「用 122 个 CPAB 参数 vs 122 个 PCA 系数作公平对比」的实验设计，把「表示质量」与「编码维度」干净地解耦了。**这个对比范式值得抄。**
