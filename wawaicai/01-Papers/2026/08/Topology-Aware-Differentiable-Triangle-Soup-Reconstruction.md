# Topology-Aware Differentiable Triangle-Soup Reconstruction

## 核心贡献
首次将**拓扑信息**纳入可微分三角形汤重建的目标函数，解决传统光度/几何损失无法捕捉拓扑错误（环、孔洞）的问题。

## 问题背景

### 传统方法缺陷
- 现有可微分重建使用 Chamfer 距离等光度/几何损失
- **无法测量拓扑**: 塌陷环、穿孔封闭空腔的得分与正确拓扑相同
- 实验显示: Chamfer 探针中，拓扑错误图的在瓶颈距离差异达 35-40x

### 现有补救失效
- 导向型重采样prior无法解决拓扑问题
- 受控实验中，拓扑感知prior与等宽随机prior性能相当
- 所有prior都无法修复环结构

## 核心方法

### 可微分持久同调损失
```
目标: 比较演化表面图与固定目标图
梯度流: 通过配对冻结反向传播
```

### 关键创新

1. **配对冻结反向传播 (Pair-Frozen Backward)**
   - 将匹配的出生/死亡单纯形表达为**闭式半径**
   - 招募项恢复缺失特征的梯度

2. **单一旋钮校准**
   - 一个比率参数平衡损失与光度梯度
   - 无需课程学习

3. **验证方法**
   - 每条声明通过通道控制判决
   - 损失在相同梯度通道击败非拓扑基线

## 实验结果

| 拓扑特征 | 误差改善 |
|----------|----------|
| 封闭空洞 | 4.0-7.9x更低 |
| 环形结构 | 2.3x改善 |
| 组件计数(H0) | 空结果 |

- 8个外部已知亏格网格验证
- 组均值: 环1.52x, 空腔4.87x
- 噪声下优雅降级
- 无需逐形状调参

## 几何算法关联

| 算法 | 角色 |
|------|------|
| 持久同调 | 拓扑特征提取 |
| 三角网格汤 | 输入表示 |
| Chamfer距离 | 基础损失 |
| 优化匹配 | 梯度计算 |

## 数学基础

### 持久同调损失
- 目标图固定（已知先验）
- 演化图持续更新
- 通过拓扑图的瓶颈距离差异监督

### 闭式半径梯度
- 出生/死亡单纯形配对
- 梯度通过配对冻结反向传播
- 招募项补偿缺失特征

## 局限性与未来工作
- 所有证据为合成数据、单机器
- 目标图预先已知
