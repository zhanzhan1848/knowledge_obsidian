## 核心贡献

> **首个**针对扩散/流匹配式艺术家网格生成器的后训练方法：**不需要任何艺术家制作的 ground truth**，仅用生成器自己的采样 + 一个"艺术家网格奖励"（含轮廓 IoU、深度一致性、四边形条带/镶嵌、针状三角形、顶点价数、微小/游离碎片、面数上界）打分，再通过**多负样本流匹配偏好优化**把奖励直接传递给流模型。

1. **自奖励的艺术家网格奖励（Artistic Mesh Reward）**：9 项加权奖励，兼顾"与稠密输入的形状一致性"（轮廓 IoU + 深度 L1，渲染对比）与"艺术家结构"（quad strips / tessellation / sliver / valence / tiny-stray / face-count bound）。**在没有任何艺术家网格的情况下**，用稠密输入的渲染充当"真值代理"。
2. **门控算法（Gating Algorithm）**：一组 16 个样本中，先剔除"相对同组不可信"的样本（CD/HD 超中位数、翻面过多、微小组件过多、真实部件被融合、解码失败），再选出唯一赢家；落败样本按"奖励落差"加权。另有 4 条成对过滤器，防止偏好信号教模型牺牲保真度、覆盖率、面数或居中性。
3. **多负样本流偏好优化（Multi-Negative Flow Preference Optimization）**：用 Diffusion-DPO 式的"重加噪去噪误差"作为对数似然代理，用**冻结参考模型的误差作边际**（只看微调带来的真实变化），配合 RPO 项防止"双方误差一起上升"。
4. **实测结果**：2.53 s/网格（vs. 自回归基线 26.98–471.84 s），在 QS 上**全场最高**，CD/HD 最低，盲评 VLM（Claude Opus 5.5）对全部基线胜率 62.5%–92.5%。

## 技术方案

### 核心思想

艺术家网格（artist mesh）是**紧致的、以四边形为主、沿 edge loop 排布**的可编辑网格。当前两条路线各有短板：

| 路线 | 代表 | 优点 | 缺点 |
|------|------|------|------|
| 自回归（AR） | MeshAnything / V2, Mesh Silksong, FastMesh | 质量高 | **逐 token 解码**，数十至数百秒/网格；且有 token 上限截断（Mesh Silksong 17%、MeshAnything V2 27% 的输出未完成） |
| 扩散/流匹配 | MeshFlow, PolyDiff, TriFlow, MeshCraft | **并行生成，快** | 质量不够：**长针状三角形、碎片化部件** |

关键洞察：**缺陷存在于"解码之后"的网格里**，而 flow-matching loss 只在潜空间上回传，**根本看不到这些缺陷**。所以必须把奖励直接送进模型。

PostMesh 的路线：**自训练（self-training）** —— 不收集昂贵艺术家网格，模型用自己的采样当训练数据。

### 关键技术

#### 1. 艺术网格奖励（9 项加权）

$$
r = \underbrace{0.2(t_{sil} + t_{depth})}_{\text{形状一致性}} + \underbrace{0.15\,t_{QS} + 0.1\,t_{TS}}_{\text{四边形结构}} + \underbrace{0.05\,t_{sliver} + 0.05\,t_{val}}_{\text{三角形质量}} + \underbrace{0.1(t_{frag-n} + t_{frag-stray})}_{\text{碎片}} + \underbrace{0.15\,r_{dens}}_{\text{面数预算}}
$$

**(a) 轮廓 IoU（形状一致性）**

$$
t_{sil} = \frac{|S_O \cap S_I|}{|S_O \cup S_I|}
$$

在固定视角渲染输出与输入，惩罚缺失部件（椅腿、把手）与多余凸起。**局限**：只看外轮廓，看不到内部偏移与翻面。

**(b) 深度一致性（形状一致性）**

$$
t_{depth} = \frac{1}{|S_O \cap S_I|}\sum_{p \in S_O \cap S_I} |d_O(p) - d_I(p)|
$$

以包围盒对角线为单位，惩罚"凹陷的坐面、鼓出的侧面、厚度不对"。与轮廓 IoU 组合后覆盖了"外轮廓相同但表面推入/推出"的情况。

**(c) Quad Strips（QS）—— 奖励 edge loop 连续性**

先把相邻三角形对合并为四边形：两三角形在 **10° 内共面**，且并集是凸四边形、各角在 **[45°, 135°]** 内，按最小角降序贪心合并。

对每个四边形 q 建两个节点（对应两组对边）。两节点连边当且仅当：对应四边形共享一条边、该边同时属于两节点的边对、且该边**恰好被两个四边形共享**。连通分量即"条带 π"；若 |π| ≥ 3 个节点且每节点度为 2，则为**环（ring）**。

$$
QS = \frac{|\{q \in Q : \pi \in \Pi \text{ 是环，或 } |\pi| \ge 4\}|}{|Q|}
$$

**关键点**：QS 衡量的是**大范围的连接性**；一个网格可以有大量四边形但 QS 仍然很低（如果四边形散落在三角形中）。

**(d) Tessellation（TS）—— 奖励四边形本身形状良好**

沿用 Mesh-RFT 的拓扑分数：

$$
TS = 0.4\tau_1 + 0.2\tau_2 + 0.3\tau_3 + 0.1\tau_4
$$

- $\tau_1 = |Q|/\max(1, |Q|+|T|)$：四边形占比
- $\tau_2 = 1 - \frac{1}{|Q|}\sum_q \sum_{k=1}^{4} |\theta_{q,k} - 90^\circ| / 360^\circ$：直角程度
- $\tau_3$：对边相等 + 四边长度接近（用 $\rho_q$ 度量长宽比）
- $\tau_4$：相邻四边形形状相似度（用 $\rho$ 的差异衡量）

**TS 与 QS 互补**：TS 是"局部"（单个四边形好不好），QS 是"全局"（四边形是否连成条带/环）。

**(e) 针状三角形（Sliver）**

$$
s_{sliver} = \frac{\sum_{f \in T,\ \alpha_f < 5^\circ A_f} A_f}{\sum_{f \in F} A_f}
$$

只统计**未被合并进四边形的剩余三角形 T**，$\alpha_f$ 是三角形最小角。**度量的是面积占比而非个数** —— 长针状三角形代价远大于几个小针。

**(f) 顶点价数（Valence）**

$$
s_{val} = \frac{|\{v \in V : \deg(v) \le 2 \text{ 或 } \deg(v) \ge 10\}|}{|V|}
$$

- $\deg \ge 10$：**pole**（极点），通常是细三角形扇形的中心
- $\deg \le 2$：属于单个三角形的**松散角点**

两者都会打断 edge loop、在细分下夹断表面、动画时形变难看。**只惩罚极端价数** —— 艺术家确实会在角点放极点。

**(g) 微小与游离碎片**

- $t_{frag-n} = \log(1 + n_{tiny})$：面数 ≤ 4 的组件个数
- $t_{frag-stray}$：游离组件的面积占比（面积 < 1% 表面 **且** 有边界边 **或** ≤ 4 面）

两项互补：个数项对"很多小斑点"敏感（即使面积可忽略），面积项对"少数较大漂浮块"敏感。**注意：融合真实部件不被奖励** —— 艺术家网格本来就是多部件的，靠门控算法拒绝部件数远少于同组的样本。

**(h) 面数上界**

$$
r_{fc} = \text{clip}\left(1 - \frac{|\log_2(F/F_t)|}{b}, 0, 1\right), \quad b = 2.5
$$

目标 $F_t = \exp(4.60 + 0.471 \ln F_{ref8})$，其中 $F_{ref8}$ 是预训练模型在该输入上采样 8 次的面数中位数。$b = 2.5$ 意味着面数偏离 22.5×（约 5.7×）时该项归零。**作用是防止策略"脱面"**（训练中确实出现）**以及防止直接复制稠密输入**。

#### 2. 门控算法（Gating）

规则**相对于同组样本**比较 → 自动适配"这个输入有多难"。

| 门 | 检查 | 阈值 |
|---|---|---|
| CD gate | 保真度 | CD 到 I ≤ 1.15× 组中位数 |
| HD gate | 保真度/离群 | HD 到 I ≤ 1.15× 组中位数 |
| Flip gate | 朝向 | 翻面比例 ≤ 组中位数 + 0.02 |
| Tiny-component gate | 碎片化 | 微小组件数 ≤ 1.5× 组中位数 + 5 |
| Part-floor gate | 防止融合真实部件 | 非游离部件数 ≥ 0.5× 组中位数 |
| Decode gate | 有效性 | 能解码为网格 |

**成对过滤器**（防止偏好信号教模型牺牲某些属性）：

| 过滤器 | 条件 |
|---|---|
| Fidelity | $CD_I(w) \le 1.02\,CD_I(l)$ |
| Coverage | 未覆盖面积 $uncovered_I(w) \le uncovered_I(l) + 0.002$ |
| Face | $faces(w) \ge 0.70\,faces(l)$ |
| Centre-offset | $off(w) \le off(l) + 0.001$ |

规则：赢家 = 门控通过样本中奖励最高者；落败样本 = 所有门控失败样本（$\omega = 1$，**与奖励无关**） + 明显低于赢家的门控通过样本（$r(l) < r(w) - 0.5\,std(r)$）。门控通过的落败样本权重 $\omega$ = 奖励落差 / 组内最大落差。

**跳过条件**：奖励标准差 < 0.01 的输入、没有任何落败样本的输入。

#### 3. 偏好损失

**(a) Flow-matching 误差作为似然代理**（Diffusion-DPO 风格）

$$
\ell_\theta(z_0) = \frac{1}{|z_0|}\left\|v_\theta(z_\sigma, \sigma, c) - (\epsilon - z_0)\right\|^2
$$

每个输入共享**同一个** $(\epsilon, \sigma)$，因此差异只来自样本本身而非噪声。

**(b) 相对于冻结参考的边际**

$$
d_j = \left[\ell_\theta(w) - \ell_{ref}(w)\right] - \left[\ell_\theta(l_j) - \ell_{ref}(l_j)\right]
$$

$d_j < 0$ 表示微调对赢家的拟合改善多于对落败者的改善。**只有"真正的变化"参与训练** —— 一开始模型就会的样本不贡献梯度。

**(c) 多负样本加权**

$$
L_{DPO} = \frac{\sum_j \omega_j\, \phi(d_j)}{\sum_j \omega_j}, \qquad \phi(d) = \text{softplus}\left(\frac{\beta}{2}d\right) = -\log\sigma\left(-\frac{\beta}{2}d\right)
$$

$\beta = 2000$ 控制"翻转"的锐度。每次更新每个输入最多用 **3 个**落败样本（**随机重抽**）。

**(d) RPO 项**

$$
L = L_{DPO} + \gamma\,\ell_\theta(w), \quad \gamma = 1.0
$$

DPO 只看 w 与 $l_j$ 的差距，可能被"双方误差一起上升"满足。RPO 项直接惩罚 $\ell_\theta(w)$，保住赢家本身的似然。**作者诚实指出：去掉 RPO 项的一次训练结果不确定，其收益未被完全确立。**

> **QEM 与各向同性重网格化的 DFF 极低（0.024 / 0.014）**，因为它们严格保持稠密网格结构、碎片为零 —— 但 **QS 显著更低（0.321 / 0.169）**。这说明：**经典算法忠实保留形状，但无法产生艺术家偏好的 edge loop 布局**。这是本文方法的核心价值主张。

### 消融实验（200 个独立物体）

| 变体 | ΔQS | ΔTS | ΔDFF | ΔFrag. |
|------|------|------|------|------|
| **完整设置** | QS=0.746 | TS=0.672 | DFF=0.111 | Frag.=0.663 |
| − tess./sliv./val. | −0.201 | −0.066 | +0.033 | −0.045 |
| − strips/tess. | −0.142 | −0.044 | +0.018 | +0.047 |
| − silhouette | −0.055 | −0.020 | −0.008 | −0.025 |
| − depth | −0.097 | −0.033 | +0.013 | +0.035 |
| − tiny/stray | −0.045 | −0.011 | +0.039 | +0.017 |
| SFT only | −0.206 | −0.055 | +0.091 | +0.137 |
| RAFT | −0.323 | −0.099 | +0.182 | +0.205 |
| Flow-GRPO | −0.298 | −0.095 | +0.102 | +0.145 |

**结论**：

1. **结构奖励项（strips/tessellation/sliver/valence）影响最大**
2. **一致性项（轮廓/深度）不可省** —— 去掉它们 QS/TS 也会下降（说明一致性约束起了正则化作用）
3. **SFT only 损失了绝大部分 QS 增益**（−0.206）→ **是偏好损失而非样本选择本身在起作用**
4. **RAFT 与 Flow-GRPO 远低于完整设置**（QS 低 0.32 / 0.30）→ 通用 RL 后训练方法无法迁移到这个场景

### 盲评 VLM 测试

- 判官：**Claude Opus 5.5**（论文作者说明选择理由：VLM critic 必须能模拟专业图形艺术家）
- 协议：60 个独立物体（不与 300 测试集重叠），A/B 两选一，**两种顺序都评**，每物体 4 视图（方位角 30°/120°/210°/300°，仰角 25°），平直着色 + 1px 线框 + 背面染红
- 判官标准（prompt 中显式列出）：edge flow 与拓扑、三角形质量（少 sliver、密度合理）、洁净度（无漂浮碎片/孔洞/翻面）、形状保真度
- 结果：**对全部基线胜出**，对 Mesh Silksong 62.5%（最接近）

## 局限性与作者自述

- **"艺术家网格"没有唯一标准** —— 艺术家诉求不同，奖励不是普适金标准
- 评估本身**主观**；自动指标 + VLM 研究都不是完美的艺术家质量度量
- 碎片化（Frag. 0.647）仍高于多数 AR 基线 —— **未解决**
- ECD（锐边保持）落后于面数更多的基线
- **RPO 项的收益未被完全确立**（去掉后一次训练结果不确定）
- **流模型的种子敏感性**：输出可能随随机种子变差（作者在失败案例 Fig. 7 中指出）
- 存在不平衡网格与微小组件的失败案例

## 🧾 可行性评估

### 算法复杂度

| 项 | 复杂度 |
|---|---|
| 奖励计算（单样本） | O(F log F)（渲染 8 视角 O(1) per 视角；四边形合并 O(F log F)；条带/环检测 O(F)） |
| 门控（单组） | O(G · F)，G = 组大小 16 |
| 每样本对流匹配的 DPO 项 | O(1) 次前向（重加噪）+ O(1) 次前向（去噪误差） |
| 训练 | 2 轮 × 1000 步 × 4 输入 × ≤3 负样本 ≈ 2.4 万次前向 |
| **总训练成本** | **约 10 GPU·h（L40S）** |
| 推理 | **2.53 s/网格**（含渲染 0.135 s） |

### 实现难度

- 算法复杂度：**中** —— 奖励项本身都是经典网格分析（合并四边形、找条带/环、算价数），但**每个细节的阈值都需要调**（10° 共面、45°–135° 角、5° sliver、deg≤2 / ≥10 等）
- 数值稳定性：**好** —— 奖励全部是归一化到 [0,1] 的有界量；唯一的对数是 $\log_2(F/F_t)$ 与 $\log(1+n_{tiny})$，都做了钳制
- 依赖项：**MeshFlow 基座（必需）+ pymeshlab/xatlas（仅评测）**；无 CGAL 级别依赖
- 门槛：**必须有 MeshFlow 权重**（作者未开源），否则无法复现

### 推荐结论

✅ **推荐实现（作为方法论参考）** —— 但要清楚它**不是一个可直接用的几何算法库**，而是**一套"把几何质量指标转成生成模型后训练信号"的方法范式**。

**最有迁移价值的点**（与我们的几何工具链直接相关）：

1. **奖励项本身可独立复用** —— 轮廓 IoU / 深度一致性 / 四边形条带 / sliver 面积占比 / 顶点价数 / 碎片检测 / 面数预算，这 **7 项几何分析可以脱离生成模型**，直接作为**网格质量的程序化校验器**或**作为重建/简化算法后处理的优化目标**。特别地，**QS（条带/环检测）是评估"edge loop 是否连续"的现成指标**，社区里很少有可直接用的实现。
2. **"缺陷在解码后、loss 看不到"的论证对 DiffSimp 类工作同样成立** —— 我们已入库的 [[2026-11-24-DiffSimp-Differentiable-Mesh-Simplification]] 关注的正是"简化误差脱离上游优化"的问题。PostMesh 的奖励可直接作为 DiffSimp 的附加损失项。
3. **多负样本 + 冻结参考边际**是通用的偏好优化技巧，可用于任何"无 token 似然、只有可微/不可微输出质量"的后训练场景。
4. **门控 + 成对过滤器的思想**（相对同组自适应阈值 + 显式防止"为了结构牺牲保真"）在我们做自动网格修复 / 退化检测时可直接借鉴。

**注意事项**：

- 训练成本极低（10 GPU·h），但**依赖未开源的 MeshFlow** 是硬门槛
- 碎片化指标未解决，说明**纯奖励驱动的后训练难以同时满足所有拓扑要求** —— 可能需要更结构化的表示（如 Mesh Silksong 的分层拓扑）
- 评测用了 **Claude Opus 5.5 做艺术家盲评** —— 这个"用强 VLM 当领域专家 critic"的模式对我们的方案评估也有参考价值

**建议动作**：

- [ ] 把 QS / TS / sliver / valence / 碎片检测这 5 项实现成**独立的网格质量校验工具**（Python + libigl 或 pymeshlab），用于现有管线的自动化质检
- [ ] 把**轮廓 IoU + 深度一致性**接入我们的重建评测管线（目前多靠 CD/HD）
