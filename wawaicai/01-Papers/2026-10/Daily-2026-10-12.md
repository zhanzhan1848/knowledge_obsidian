## 🎯 今日新增论文

### 1. 🆕 3DRAG (本日新增)
**3D-Native Object Drag Editing with Generative Models**

- **arXiv**: 2610.13216 (2026-10-09)
- **领域**: 3D 几何编辑 + Generative Models + Training-free
- **核心创新**:
  - 3D 位移场扩展（2D drag → 3D）
  - OA-WTA (Occupancy-Aware Winner-Takes-All) 处理稀疏几何
  - Generative latent editing（latent 层 token 融合）
  - Logits-Level Token Fusion 高保真源信息迁移
- **关键优势**: 训练免费（无 SDS 优化）、多视角一致、无拓扑伪影
- **新基准**: 多资产 + 复杂多点 drag 指令数据集
- **推荐度**: ⭐⭐⭐⭐ — 实用工具属性强
- **文件**: `2026-10-09-3DRAG-3D-Native-Drag-Editing.md`

### 2. 🆕 FeatureZ (本日新增)
**A General Framework for Feature-Preserving Compression via Pointwise Bounds and Consistent Star Classification**

- **arXiv**: 2610.12371 (2026-10-08) | cs.GR + cs.IT
- **领域**: 科学体数据压缩 + 拓扑特征保持（isosurface / merge tree / Morse-Smale）
- **核心创新**:
  - 通用框架：点级 upper/lower bounds + 一致 star 分类
  - Augmentation Layer 架构（不替换现有压缩器）
  - 两阶段：量化强制 bounds → 迭代修复 star 分类
- **关键优势**: 广泛适用（医学、气候、材料、天文）
- **推荐度**: ⭐⭐⭐ — 思路优雅，但需扩展到非结构化 mesh
- **文件**: `2026-10-08-FeatureZ-Topology-Preserving-Volumetric-Compression.md`
