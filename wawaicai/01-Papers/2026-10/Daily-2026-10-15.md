## 🎯 今日新增论文

### 1. 🆕 Q-MAGIC (本日新增)
**Quad-only Mesh Autoregressive Generation via Singularity-Aware Circular Relative Offset Tokenization**

- **arXiv**: 2610.19777 (2026-10-14)
- **领域**: 四边网格自回归生成 / Tokenization / Transformer
- **核心创新**:
  - **Singularity-aware 串行化**：每个新 quad 至少 2 个新顶点 → 优先从奇异点开始 wire traversal
  - **Circular Relative Offset Tokenization**：用局部相对偏移编码几何 → 序列更紧凑
  - **Autoregressive Transformer**：next-token prediction 建模 quad mesh 分布
  - **无歧义 de-serialization**：token → 唯一 mesh
- **结果**: 序列更紧凑，几何保真度 + mesh quality 一致优于 SOTA
- **推荐度**: ⭐⭐⭐⭐ — quad mesh 自动化的新范式
- **文件**: `2026-10-14-QMAGIC-Quad-Only-Mesh-Autoregressive.md`

### 2. 🆕 GLoD-LVSM (本日新增)
**Learning Geometry-Grounded Continuous-LoD Scene Representations for Large View Synthesis Models**

- **arXiv**: 2610.20254 (2026-10-14)
- **领域**: 大型视角合成模型 (LVSM) / 连续 LoD / 几何引导压缩
- **核心创新**:
  - **Continuous anchor field**：替代固定 scene anchor，按预算灵活初始化
  - **End-to-end condenser**：场 + 聚合器联合训练
  - **Geometry-grounded attention**：推断 reference-token 与 anchor 几何，引导注意力
  - **Frustum culling**：解码阶段启用屏幕外剔除
- **结果**:
  - token 减 33.4%，渲染加速 1.23×（无质量损失）
  - token 减 85.5%，渲染加速 3.00×（允许少量质量损失）
  - **涌现**：view-synthesis 监督下场景深度自然涌现，anchor 自组织到纹理复杂区
- **推荐度**: ⭐⭐⭐ — LVSM 压缩 + LoD + 几何 grounding 三位一体
- **文件**: `2026-10-14-GLoD-LVSM-Geometry-Grounded-Continuous-LoD.md`

### 3. 🆕 Construction of Simple Quadrangulations at Skeletal Joints (本日新增)
**Construction of Simple Quadrangulations of the Sphere at Skeletal Joints**

- **arXiv**: 2610.17803 (2026-10-13)
- **领域**: 球面四分 / 关节体积建模 / truss-based lattice
- **核心创新**:
  - **方向集 → 简单球面四分**：n 个无序方向向量 → 无交叉简单 quad
  - **Dual graph enumeration**：优先选 convex + regular 拓扑
  - **Conflict-constrained assignment + lazy cyclic-order separation**：解决球面无交叉实现
  - **Bézier 体积**：primal graph 直接转精确有理 Bézier shell + column 体
  - **多关节装配**：truss-based lattice 在 3D 域装配
- **结果**: 在 Fibonacci 采样方向集（3-20 个方向）下稳定生成高质量简单四分
- **推荐度**: ⭐⭐⭐ — 关节资材 / lattice 设计领域的实用工具
