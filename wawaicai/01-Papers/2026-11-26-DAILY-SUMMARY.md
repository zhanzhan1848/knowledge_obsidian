### ⭐⭐ 2. Resolution-free Neural Surrogates for Geometric Parameterization and Mapping — 同组的「神经加速姊妹作」

| 项 | 内容 |
|---|---|
| **arXiv** | [2605.28551](https://arxiv.org/abs/2605.28551)（**v2, 2026-11-25**） |
| **作者** | Yanwen Huang, Lok Ming Lui, Gary P. T. Choi |
| **状态** | ⚠️ **版本更新**（v1 = 2026-05-27）→ **知识库全新入库** |
| **核心** | 参数化/映射的传统解法（变分模型 / 扩散 / 椭圆 PDE）**每次求解高分辨率系统都很贵**。本文提出**分辨率无关神经代理**：以「参数场的坐标增广采样」为条件输入（而非固定网格张量），网络因此学到**算子**而非某个离散解 ⇒ **同一权重可跨网格尺寸推理，无需重训练**。**完全无标签训练**（几何感知约束：变分能量 + 扩散式密度均衡 + 准共形理论）。含**边缘感知卷积算子**保证高畸变下的双射性，训练后有**低维权重精修步**（0.6–1.7 s） |
| **结果** | Beltrami 重建：mean\|Δd\| 0.0032–0.0094，耗时 ~0.18 s。**分辨率无关性验证**：N=48/64/80/96 同一权重推理，耗时 0.22–0.28 s。**代价**：分辨率越高误差越大（N=48→96，mean\|Δd\| 0.00192→0.00381），原因是**固定卷积模板在细网格上物理支撑变小** + 导数估计对网格间距敏感。DEM/DEQ 在 2D 与 3D 均验证有效 |

| **结论** | ⚠️ **谨慎评估** —— 核心承诺（分辨率无关 + 无标签 + 近实时）非常吸引人，但**代码未公开**、几何约束设计是知识门槛。**建议先做 2D Beltrami 重建最小验证**（~1–2 人周） |

### ⭐⭐ 3. A Mesh for Every Moment (MEMO) — 动态场景逐帧网格

| 项 | 内容 |
|---|---|
| **arXiv** | [2611.34939](https://arxiv.org/abs/2611.34939)（**2026-11-25 当日新投**） |
| **作者** | Roy Or-El, Jeong Joon Park, Ira Kemelmacher-Shlizerman（UW / UMich） |
| **项目页** | https://memo-4d.github.io |
| **核心** | 现有动态 GS 方法**要么只建模外观、要么只能对前景 mask 隔离的物体出网格**，且都用 TSDF 融合 / Poisson 重建 → **固定网格限制细节**。MEMO 用**逐高斯时序运动模型**（受 GP 启发，时间高斯核的加权和，核覆盖全时间轴 ⇒ 每 Gaussian 在每帧都是有效表面元素、opacity/scale 恒定）让**几何在所有时刻有定义**。**轨式初始化**（卡尔曼滤波连 SfM 点成 3D 轨迹 + **闭式拟合**初始运动）解决「大而快的运动无法靠光度梯度学习」这一被普遍忽视的难点。网格用 **Gaussian Wrapping** 的 pivot 提取（四面体化 + vacancy field 0.5 等值面） |
| **指标洞见** | **joint F-score**：位置误差 < 包围盒对角线 1% **且** 法向夹角 < 20°。作者明确论证**单用 Chamfer 距离不够** —— 点距离几乎不惩罚表面噪声，噪声网格会得分虚高 |
| **结果** | 在 Blender-Moments（**新基准，9 场景逐帧 GT 网格**）+ Neural 3D Video + SelfCap 上，**法向精度与 joint F-score 均最佳**，网格最干净（D-2DGS 留噪声空洞，DG-Mesh 过度平滑，MEMO 保留面部特征与 Lego 凸点）。**即使把 MEMO 的网格也用 TSDF 融合，仍超越所有基线** → 优势同时来自表示与提取两者 |
| **局限** | **逐帧独立提取 ⇒ 相邻帧网格不保证共享顶点/面**；依赖初始轨迹 ⇒ 细长快动部件会拖影；**每 Gaussian 存一份运动 ⇒ 模型最大**；反照率-着色歧义与窄基线 |
| **结论** | ⚠️ **谨慎评估** —— 方法论清晰、**指标设计值得学习**，但代码未公开、三大模块工程量大。**可先落地其中的网格提取部分** |

## 🎯 本批主题信号

**1. 「目标域自适应」正在取代「固定标准域」**
从 2D 曲面参数化到 3D 体参数化，从固定矩形/球到**随输入几何与质量分布自适应的目标域**。这条线在 Choi 组的两篇姊妹作里体现得最完整（变分数值解 + 神经代理加速）。**几何处理里"标准域"这个概念正在被重新定义。**

**2. 动态/时序几何从"事后重建"转向"表示即定义"**
MEMO 的核心不是更好的提取算法，而是**让几何在所有时刻都有定义**（逐高斯时序核）。这与传统"训练完再融合/再提取"的范式有本质区别。

**3. 表征不再被网格格式绑死，但代价是"失配"**
MöbiuString 用元胞复形、FoundSurface 用 ray field、神经代理用算子 —— 都在脱离传统网格/点云表示。但每种都付出了代价：MöbiuString 的专用性、FoundSurface 对 pointmap 的依赖、代理的分辨率-误差负相关。

**4. 拓扑正确性正在被当作一等公民**
MEMO 报告 overlap=0、体参数化报告 overlap=0 且专门设计两阶段折叠校正、FoundSurface 强调 surface 拓扑。**"看起来对"不再够用，必须证明双射/无折叠。**

**5. 指标设计本身成为贡献**
MEMO 的 joint F-score（位置 + 朝向双阈值）、体参数化的 $C^{ρ}_{1\%}$（偏差最大 1% 单元的贡献占比）—— 都是针对"Chamfer 距离掩盖噪声"这一老问题的直接回应。
