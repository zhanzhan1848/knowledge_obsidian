## 核心贡献

> **提出并求解「互锁平铺（interlocking tiling）」问题：在有限三维域上用少量全等原型砖（prototile）精确铺满，同时保证装配互锁稳定**——克服了既有方法「原型砖数量少」与「结构稳定」不可兼得的困境。

1. **新问题定义：互锁平铺（interlocking tiling）**：3D K-hedral 平铺 = 用 $K$ 种全等原型砖无重叠无缝隙地覆盖有限域。两个实用要求：
   - **$K$ 要小**（降低制造成本，如复用模具；简化拆装）
   - **结构稳定**，特别是**互锁**——除关键砖（key）外，所有砖都被几何排列固定
   - 既有方法**必然二选一**
2. **两级层次化分解的求解方法**：
   - **域级（domain-level）**：把输入域划分为**互锁的部件**
   - **部件级（part-level）**：再把每个部件划分为**互锁的砖**
3. **带规则结构的新图表示**：用于指导部件级划分，**既保证生成的砖形状相同，又保证它们互锁**——这是论文的技术核心。
4. **输入**：三维有限域以**体素网格**表示；输出：精确覆盖输入域的互锁平铺。

## 技术方案

### 核心思想

**互锁（interlocking）**是制造与装配的核心概念：一组零件仅靠几何形状互相约束，无需胶水或紧固件。

问题难点在于**两个目标的冲突**：
- 想要**少的原型种类** $K$ → 每种砖的形状必须复杂（能以多种朝向拼出不同结构）
- 想要**互锁稳定** → 砖的形状必须包含**榫卯结构**（tab-and-slot）

论文的解法是**层次化**：先把大域拆成大部件（部件之间互锁），再在部件内部拆砖（砖之间互锁）。这样**复杂度被分解**，每级只需处理局部。

### 关键技术

| 技术 | 说明 |
|------|------|
| **K-hedral 平铺** | 用 $K$ 种全等原型砖覆盖域，$K$ 越小制造成本越低 |
| **互锁平铺约束** | 除关键砖外所有砖被几何固定 → 装配稳定、可承力 |
| **体素域表示** | 输入为体素网格 → 天然离散、便于组合操作 |
| **域级划分** | 把域划分为一组互锁部件 |
| **部件级划分** | 每个部件再划分为互锁的砖 |
| **规则图表示** | 新提出的图结构，**同时编码「相同形状」与「互锁」两个约束** |
| **关键砖（key）** | 互锁体系中的「钥匙」——唯一可自由取放的砖，其余被固定 |
| **精确覆盖保证** | 输出砖精确铺满输入域（无缝隙、无重叠） |

### 公式

**K-hedral 平铺定义**

```math
\mathcal{D} = \bigsqcup_{k=1}^{K} \bigsqcup_{i=1}^{n_k} g_k\big(\mathbf{T}_{ki}\,\mathbf{p}_k\big)
```

> $\mathcal{D}$ 为域，$g_k$ 为第 $k$ 种原型砖（凸包或 signed distance 表示），$\mathbf{T}_{ki}$ 为其刚体变换。$\bigsqcup$ 表示**不相交并**（精确覆盖）。

**互锁条件**

```math
\text{互锁}\iff \forall\, j \neq \text{key}:\quad
\text{砖 } j \text{ 无法沿任何单轴方向平移脱离其邻居}
$$

$$\text{约束表述：}\quad \forall\, j\neq\text{key},\ \exists\, \text{ 邻居 } n: \;
\big\| \mathbf{n} \big\| \cdot (\mathbf{p}_j - \mathbf{p}_n) < \text{overlap depth}$$

> 关键砖是体系中的「钥匙」——是装配的入口，也是唯一可自由取放的砖。

**两级层次分解**

```math
\mathcal{D} = \bigsqcup_{p=1}^{P} \mathcal{B}_p
\quad (\text{域级：部件互锁}), \qquad
\mathcal{B}_p = \bigsqcup_{i=1}^{m_p} g\big(\mathbf{T}_{pi}\,\mathbf{p}\big)
\quad (\text{部件级：砖互锁})
$$

> **层次化是本文的核心结构**——把全局的 $K$ 优化问题分解为局部的划分子问题。

**规则图表示（部件级指导）**

```math
G = (V, E), \qquad \text{约束：}\; \text{相邻节点对应砖的接触面互相匹配}
$$

$$\text{同形约束：}\quad \forall\, (u,v)\in E,\; \text{shape}(u) \cong \text{shape}(v)\ \text{（经刚体变换）}$$

> **规则结构**（regular structure）使得同形约束在图上一致传播——从少数几个「种子」砖的形状，可以推导出整块区域的形状，避免逐砖求解。

### 复杂度

- **域级划分**：图划分 / 组合优化 → 取决于域大小，最坏情况指数（NP-hard 性质）
- **部件级划分**：每个部件独立求解 → 规模小得多
- **图表示构造**：与体素数线性相关 $O(|V_{\text{vox}}|)$
- **覆盖验证**：精确覆盖检查 $O(\#\text{bricks} \cdot |\text{vox}|)$ 或用哈希
- **输出规模**：$O(\#\text{bricks})$ 个刚体变换 + $K$ 个原型形状

## 实验结论

- **输入**：体素网格表示的三维有限域
- **输出**：**小原型砖集合**，其实例精确覆盖输入域，且构成**互锁装配**
- **对比目标**：既有 3D K-hedral 平铺方法（只能在「$K$ 小」与「结构稳定」间二选一）
- **方法特点**：**同时满足两个要求**——这是论文声称的主要贡献
- **论文重点在问题定义与算法框架**，实验规模在摘要层面未充分披露

---

## 局限性

1. **域级划分本质上是组合优化 / NP-hard**——大规模域的实际可行性需评估（摘要未给规模与耗时）
2. **互锁的严格性**：论文用「无法沿单轴平移脱离」刻画互锁，但**真实结构稳定性涉及多轴 + 扭转 + 载荷**，这个定义可能过弱
3. **体素分辨率限制**——体素域只能表达轴对齐的砖，**斜面砖、圆弧界面无法表达**；而互锁结构常需要非轴对齐特征
4. **K 的最优性未保证**——论文说「compute a small prototile set」，但最优 $K$ 是 NP-hard
5. **实际制造可行性未验证**——未做 3D 打印实物验证，也未讨论公差（tolerance）——互锁结构对制造误差极敏感
6. **域级与部件级之间的互锁可能冲突**——部件之间的互锁约束如何传递到部件内的砖，论文表述不够细
7. **未开源**（摘要未提及代码）

## 实现建议

- **实现难度**：**高**。需要：
  - 体素域的处理（IoU / 覆盖检查）
  - 组合优化求解器（域级划分 + 部件级划分）——ILP / SAT / CP-SAT
  - 规则图表示的构造与同形约束求解
  - 互锁性验证器（平移可达性分析）
  - **难点**：① **互锁的自动验证**——需要判断砖是否能沿任意方向脱离，本质是几何可达性/配置空间问题；② 同形约束在图上的一致性求解；③ NP-hard 问题的规模控制
- **数值稳定性**：**好**（离散组合问题，无浮点迭代）；但**制造公差**的鲁棒性分析需要引入容差带，转化为近似问题
- **适用场景**：
  - ✅ **免胶装配的可打印结构**（玩具、家具模块、传感器外壳）
  - ✅ **需要复用模具**的制造场景（$K$ 小 → 模具成本低）
  - ✅ **建筑互锁结构**（Asensio 路线）
  - ⚠️ 大规模 / 复杂形状域（求解时间可能爆炸）
  - ❌ 需要曲面/自由形状的装配（体素表示表达力不足）
- **落地建议**：
  1. **层次化分解是本文最可复用的核心思想**——即使不做互锁平铺，「先分大件、再分小件」的两级划分也能大幅简化很多组合几何问题
  2. 求解器建议用 **OR-Tools CP-SAT** 或 **Z3**（体素离散天然适合 SAT）
  3. **互锁验证器建议用配置空间的简化判据**：沿 6 个主轴 + 若干斜向做平移可达性测试（离散体素下可直接用 BFS on free-space）
  4. 若考虑实际制造，**先加入公差模型**（把榫槽做成带余量的形状）——否则理论互锁在实物上会失效
  5. 输出建议导出 **STL + 分件清单**，可直接进 3D 打印切片软件验证可打印性
