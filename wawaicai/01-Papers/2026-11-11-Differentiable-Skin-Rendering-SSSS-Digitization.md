## 核心贡献

> 跳过「离线路径追踪 → 物理参数 → 近似着色器」这条有损链路，**直接优化实时渲染管线真正使用的参数**（Burley 归一化扩散的散射距离），实现单灯单视角的轻量级皮肤采集。

1. **可微 SSSS 框架**：把屏幕空间多次散射算法**张量化**并实现可微版本，支持对**空间变化的基底纹理 + 散射距离图**做联合优化。
2. **参数直接对齐生产管线**：不使用消光系数等离线物理量，而是优化 **scattering distance $d=1/s$**（单位平均自由程假设），直接产出可用于游戏引擎的资产。
3. **面部区域 profile blending**：先对每个皮肤斑块优化**均匀**散射距离，再按**厚度图**插值生成**空间变化**的散射距离图，捕捉耳、鼻等薄皮肤区域。
4. **轻量采集装置**：消费级**投影仪 + 单反相机**，无需偏振/高光谱/多相机，投影仪距被摄约 20 cm、仰角 30°，相机距被摄约 50 cm（近同轴）。
5. **包容性验证**：**45 名被试**覆盖 **Monk Skin Tone Scale** 全色阶（而非 Fitzpatrick），验证人群泛化能力。
6. **厚度几何估计**：无实测厚度图时，用 **inverted-normal SSAO** 自动近似局部厚度 —— 翻转法线使 AO 半球朝向物体内部，内向采样遇到邻近表面越近 → 该处越薄。

## 技术方案

### 核心思想

**BSSRDF 基础**：采用 **Burley 归一化扩散 profile**（实时 PBR 皮肤着色的标准），在扩散模型基础上引入 subsurface scattering 参数 $s$。

$$\text{scattering distance}\ d=\frac{1}{s}\qquad(\text{单位平均自由程假设})$$

**问题定位**：该参数与材质外观**强耦合**，且**没有直接视觉参考**，手动调参极其困难 → 论文直接**从照片优化散射距离贴图**。

### 两阶段管线

```
阶段 A（斑块拟合）:
  照片 + 深度图 + 光掩码
        ↓  可微光栅化器
  优化 Burley 15 纹理栈 + 均匀散射距离 d

阶段 B（面部合成）:
  均匀 d（各解剖区域）  ⊗  厚度图（blending weight）
        ↓  profile blending
  空间变化散射距离图
```

### 采集装置与数据

| 组件 | 规格 |
|------|------|
| 被测支撑 | 刚性水平平台，被试将特定面部区域（脸颊/额头）放置在固定标记上 → **位置可重复** |
| 光源 | 投影仪，发射**高对比结构化条纹** + 均匀白光；距被摄 **~20 cm**，相对表面平面**仰角 30°**（低角度 → 强化 SSS 效应） |
| 成像 | 高分辨率 RGB 相机（DSLR），装在投影仪**后方** **~50 cm**（近同轴 → 最小几何畸变） |
| 标定 | **不做**投影仪-相机标定、不做结构光三角化；改用**单目深度估计**，映射网络归一化输出到 **2 cm** 物理深度范围，锚定于实测相机-被摄距离 **47 cm** |

**四张照片序列**（每斑块）：

| # | 图案 | 作用 |
|---|------|------|
| 1 | 黑色图案 | 记录**环境光残留**，从后续帧中减去以隔离直接照明 |
| 2 | 竖直条纹 | 条纹照明，显示皮肤方向性响应 |
| 3 | **互补**竖直条纹 | 反相条纹 |
| 4 | 全白均匀 | 提供均匀照明参考，用于估计 albedo，**解耦着色与几何变化** |

> 竖直线条（而非复杂图案）是为**最小化投影仪色差与彩色条纹**；简单线性图案**减少光谱干扰** —— 这对波长相关的 SSS 尤为关键。

### 光掩码生成

$$\text{diff} = I_{\text{stripe}} - I_{\text{inverse}}$$

→ **Otsu 阈值**（最大化类间方差自动定阈）二值化 → **形态学膨胀 + 开运算 + 闭运算**（保证空间连贯）。

产出**两个不同版本**：

| 掩码 | 处理 | 用途 |
|------|------|------|
| **Loss Mask** $\mathcal{M}$ | 反相、**严格二值**、阴影区为 1 | 聚焦优化损失。**硬二值边缘至关重要** —— 优化中任何模糊都会改变光照图案边缘，**破坏散射晕估计** |
| **Rendering Mask** $\mathcal{M}_{\text{smooth}}$ | 非反相、11×11 **高斯滤波** | 模拟投影仪散焦，防止最终渲染硬边伪影；平滑过渡处叠加高光 |

### 张量化可微 SSSS

把逐像素 shader 操作转为**批量张量计算**，需处理：

1. **批处理** —— 整图 + 全部散射采样点同时作为高维张量处理
2. **视空间重建** —— 用深度 + 相机内参**重建每个像素的 3D 位置**，而非依赖 2D 屏幕空间近似（保证与渲染引擎 1:1 一致）
3. **可微采样** —— 离散纹理查找替换为**可微双线性插值**，使梯度能穿过散射输入传播
4. **显存优化** —— 沿维度广播操作以最小化循环开销

散射辐照度张量：

$$\mathbf{L}_T=\mathcal{M}_{\text{smooth}}\odot(\mathbf{n}\cdot\mathbf{l})$$

（用平滑渲染掩码滤除入射光照后再扩散）

## 实验结论

### 验证设计

论文采用**三重验证**：

| 验证类型 | 目的 |
|------|------|
| **真实数据** | 45 名被试，Monk Skin Tone Scale 全色阶 → 人群泛化 |
| **合成数据** | 用渲染引擎生成**已知真值参数**的参考图 → 验证优化程序本身 |
| **多灯配置** | 验证**单灯假设**的有效性 |
| **倾斜视角配置** | 验证**角度一致性** |

补充材料另含：优化各阶段的贴图演进图、倾斜视角验证、Monk 色阶数据集、RAW 处理与色彩标定、albedo 初始化、GPU shader 实现、**Burley 多次散射的可微张量化实现**细节。

### 核心结论

- 从**低成本单灯单视角**输入有效恢复散射参数
- 产出的皮肤外观**直接兼容标准实时着色器**
- 覆盖全肤色区间的**人口统计学泛化**得到验证
- **WebGL + Babylon.js** 实现保证跨平台（含低端设备）的可部署性

## 局限性

- **单光假设**：主方法基于单灯；多灯验证是**事后验证**，非联合求解。
- **深度依赖单目估计**：不做投影仪-相机标定、不做结构光三角化 → 深度来自单目网络估计，误差直接传导到 SSS 与厚度估计。
- **面部区域手工分区**：厚度图与可选的解剖区域图都需要准备（厚度靠 inverted-normal SSAO **近似**，非实测）。
- **未处理动态表情**：论文提到传统方法难以覆盖多样表情与肤色，但未在本方法中显式解决表情变化下的采集。
- **参数仍偏经验**：虽借 Burley 的物理基础，但仍是**归一化扩散近似**，非完整体渲染。

## 实现建议

- **实现难度**：🟡 中（渲染工程量大，但技术路径清晰）。
- **数值稳定性**：⚠️ 中。
  - Burley 多次散射的张量化实现需注意**大核下的显存与数值范围**
  - Loss Mask 必须保持**严格二值**，优化中任何平滑都会破坏散射晕估计（论文明确警告）
  - 散射距离 $d=1/s$ 的优化在 $s\to0$ 时梯度可能病态，需参数化/裁剪
- **依赖项**：
  - `Babylon.js` + `WebGL2`（论文所用渲染引擎）；或 `three.js` + `WebGPU`
  - 可微光栅化：`nvdiffrast`（论文扩展自 [17]）、`pytorch3d`、`redner`、`dr.jit`
  - 单目深度：`Depth-Anything` / `Metric3D` 等
  - 图像处理：`opencv`（Otsu、形态学）
  - 色彩标定：`colour-science`、`rawpy`（补充材料含 RAW 处理细节）
- **适用场景**：
  1. **数字人/游戏角色皮肤采集** —— 产出物直接是引擎可用的参数图
  2. **移动端/低端设备** —— 论文明确以跨设备可部署为设计目标
  3. **多肤色人群的资产生产** —— Monk 色阶锚定是有价值的工程规范
  4. 作为**通用「面向生产着色器的可微反演」范式**，迁移到毛发、树叶、蜡、皮肤等
- **几何相关性**（本 agent 关注点）：
  - **inverted-normal SSAO 估厚度** —— 这是把**几何邻近关系**转为**次表面散射参数**的直接手段，可复用于任何「局部厚度影响外观」的场景
  - **视空间 3D 位置重建**（深度 + 内参）保证可微渲染与引擎 1:1 —— 这是几何与渲染正确性对齐的关键工程细节
  - **profile blending**（均匀参数 + 厚度权重 → 空间变化图）是一种**廉价的几何引导参数化**思路
- **可复用模块**：
  1. **可微 SSSS 张量化实现**（补充材料 5.4 节给出细节）
  2. **单灯 + 投影仪结构化条纹** 的低成本采集配方
  3. **inverted-normal SSAO 厚度近似** —— 几何处理 agent 可独立评估其精度
  4. **「直接优化生产参数」而非物理参数** 的逆渲染方法论
- **落地建议**：
  1. 先在**单一区域**（如前臂）上验证：采集 4 张照片 → 优化单一散射距离 → 与全路径追踪参考对比
  2. 验证**厚度图**质量：比较 inverted-normal SSAO 与实测厚度的偏差
  3. 再做区域 profile blending 与多肤色扩展

## 关键技术点速览

1. **参数对齐生产管线** —— 优化散射距离而非消光系数，避免「物理正确但工程无用」的中间层。
2. **双掩码设计** —— Loss Mask 严格二值（保图案边缘，用于准确估计散射晕），Rendering Mask 高斯平滑（模拟散焦，防硬边伪影）。这个「同源不同处理」的设计很关键。
3. **Otsu + 形态学** 的自适应光掩码，无需人工调阈。
4. **张量化可微 SSSS** —— 视空间 3D 重建保证与引擎一致；可微双线性插值让梯度穿过采样传播。
5. **inverted-normal SSAO 估厚度** —— 用几何邻近关系编码局部厚度，是几何→外观的廉价桥梁。
6. **Monk Skin Tone Scale** 锚定 —— 用感知均衡的肤色尺度替代 Fitzpatrick，保证人群覆盖。
7. **单目深度替代结构光三角化** —— 牺牲绝对精度换取极低部署成本，是工程取舍的典范。
