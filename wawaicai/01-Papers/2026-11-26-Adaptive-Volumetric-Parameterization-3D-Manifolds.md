## 核心贡献

> 已有体参数化方法几乎都把 3-流形映射到**固定标准域（如实心球）**，无视输入形状 → 对细长/极端形状引入**巨大几何畸变**。本文把**目标域 Ω 提升为优化变量本身**，建立统一变分模型**联合控制局部形状畸变与质量畸变**，并给出三种目标域灵活度递增的设定。

1. **目标域自适应变分模型**：联合优化映射 $f: \mathcal{M} \to \Omega$ 与目标域几何 $\Omega$
2. **三种渐进灵活的设定**：预定椭球 → 体积归一化自适应椭球（半径可变）→ 海域嵌入自由边界域
3. **统一的算法骨架**：三种设定共用「3D 拟共形形状更新 + 扩散式密度均衡更新 + 消除元素折叠的几何校正」
4. **可直接复用的应用**：多分辨率与局部自适应**体网格重划分**、**体配准**、**体变形（morphing）**

## 技术方案

### 核心思想

```
传统：  M ──f──► Ω = 固定实心球        （标准但畸变大）

本文：  M ──f──► Ω（Ω 是变量）         （目标域随输入形状与质量分布自适应）
         └──► A = 可容许目标域族（决定灵活度）
```

### 能量函数

$$E(f,\Omega) = \alpha \int_{\mathcal{M}} |\log K_f|^2 + \beta \int_{\Omega} |\nabla \rho_{f,\Omega}|^2$$

- **$E_{\text{shape}}(f)$** —— 局部形状畸变项，$K_f$ 为 **3D 拟共形膨胀**（quasi-conformal dilation）
- **$E_{\text{mass}}(f,\Omega)$** —— 质量畸变项，$\rho_{f,\Omega}$ 为规定质量测度在 $f$ 下的**推前密度（push-forward density）**
- $\alpha, \beta \ge 0$ 平衡两项。特例：$\alpha=1,\beta=0$ → 纯形状；$\alpha=0,\beta=1$ → 纯密度均衡；两者皆正 → 联合

优化问题：$\min_{\Omega \in \mathcal{A},\, f:\mathcal{M}\to\Omega} E(f,\Omega)$

**推广关系**：本文自然地**扩展了 3DDEQCMap [Lyu et al.] 的公式化**，把 $\Omega$ 从固定量变为变量。

### 3D 拟共形性

对 $J_f(x) = R(x)D(x)$（修正极分解，$R \in SO(3)$，$D$ 对称），特征值 $\lambda_1 \ge \lambda_2 \ge \lambda_3$：

$$K(\lambda_1,\lambda_2,\lambda_3) = \begin{cases} \lambda_1/\lambda_3, & \det(J_f) \ne 0 \\ \infty, & \det(J_f) = 0 \end{cases}$$

- $K \approx 1$ → 局部形状畸变小
- $K > 0$ → 局部保向；$K$ 的**符号编码朝向**
- 共形 $\iff \lambda_1 = \lambda_3$

### 质量守恒条件

$$f_*\omega = k_\Omega dV, \qquad k_\Omega = \frac{\omega(\mathcal{M})}{\mathrm{Vol}(\Omega)}$$

等价于 $\rho_{f,\Omega}(x) = k_\Omega$。此时 $E_{\text{mass}} = 0$。

### 三种可容许目标域族 $\mathcal{A}$

| 设定 | $\mathcal{A}$ | 自由度 | 用途 |
|---|---|---|---|
| **① 预定椭球** | $\{E_{a_0,b_0,c_0}\}$ | 固定 | 提供**通用标准域**供跨模型比较 |
| **② 体积归一化自适应椭球** | $\{E_{a,b,c} : abc = P_0\}$ | 半径可变，**体积固定** | 椭球**长宽比**随输入几何与质量分布自适应 |
| **③ 海域嵌入自由边界** | $\{\Omega \subseteq \bar\Omega : \Omega \text{ 与 } \mathcal{M} \text{ 同胚}\}$ | 边界完全自由 | 目标域最贴合输入局部形状与密度分布 |

**② 的约束技巧**：$|E_{a,b,c}| = \frac{4\pi}{3}abc$，固定 $abc$ 即固定体积。用两个对数半径变量参数化：

$$a = \gamma e^{u}, \quad b = \gamma e^{v}, \quad c = \gamma e^{-u-v}, \qquad \gamma = P_0^{1/3}$$

自动满足 $abc = P_0$ → 目标域形状更新降为 **(u,v) 平面的二维优化**，只改变长宽比不改变尺度。

**③ 的无界缩放问题（Remark 1）**：若 $\Omega \to s\Omega$，则 $f \to sf$，则

$$E(f_s,\Omega_s) = \alpha E_{\text{shape}}(f) + \beta s^{-5} E_{\text{mass}}(f,\Omega)$$

即**质量畸变项可通过扩大目标域无界下降** → 必须用包含约束 $\Omega \subseteq \bar\Omega$（固定外层计算椭球）消除该方向。

## 算法流程

### 三段式骨架

```
① 3D 拟共形形状更新    → 控制局部形状畸变
② 扩散式密度均衡更新   → 控制质量畸变
③ 几何校正（消除折叠）  → 保证双射性
```

### 形状/质量更新耦合（第 3.1.4 节）

把质量能量的下降方向从物理空间**变换到 3D 拟共形场**：用扩散过程得到辅助映射 $\hat{f}^{n+1}$ 及其拟共形 $\hat{q}^{n+1}$，取 $dq_2 = \hat{q}^{n+1} - q_n$，然后

$$dq_n = \alpha\, dq_1 + \beta\, dq_2, \qquad \bar{q}_{n+1} = q_n + \delta_t\, dq_n$$

$\delta_t$ = 时间步长，$\bar{K}_{n+1}$ 由更新后特征值极值 $\bar{\lambda}_1/\bar{\lambda}_3$ 计算。

⚠️ **重要诚实说明**：论文明确指出「**该更新不保证每次迭代都降低完整能量**」，实际结果中会有**偶发的局部上升**，但整体趋势下降。

### 几何校正（消除折叠）

分两个阶段：

1. **边界折叠**：对 $\partial E^n_{a,b,c}$ 应用 EDEM 的**拟共形截断**，强制 $\|\mu\|_\infty < 1$，再把校正后的边界映射回去
2. **内部折叠**：对四面体网格 $E^n_{a,b,c}$，通过**修改 3D 拟共形场并求解带边界条件的稀疏线性系统**，重建对应的拟共形映射。**校正后的边界映射作为第一阶段的边界条件**
3. 若网格含退化或翻转单元，**重复校正直到得到无折叠网格**，然后在更新后的网格上重新计算能量

$K$ 由重建后四面体网格的 Jacobian 计算。

### 初始化

1. 边界椭球参数化 $f^0_{\partial}$ —— 用 **EDEM（椭球密度均衡映射）** 方法把 $\partial\mathcal{M} \to \partial E_{a,b,c}$
2. 内部映射 —— 解 **Laplace 方程**

> **注**：当 $a=b=c=1$ 时，预定椭球模型**精确退化为 3DDEQCMap**，数学形式与数值实现均一致。

### 参数与终止

| 参数 | 值 |
|---|---|
| 时间步 $\delta_t$ | 0.1 |
| 停止阈值 $\epsilon$ | $10^{-3}$ |
| 最大迭代 $n_{\max}$ | 100 |

### ② 的非对称迭代频率

映射更新（子问题 1）**执行多次**以充分变形网格顶点 → 再执行**一次**半径优化（子问题 2）调整目标域。

## 实验结论

### 模型与数据集

- **测试模型**：Vase、Igea、David、Skull、Hippocampus、Lung、Multi-lobed ball
- **医学形状**：Skull（颅骨）、Hippocampus（海马）、Lung（肺）—— 展示了跨域通用性
- **基线**：3DDEQCMap（固定球）、volumetric harmonic map [Wang et al.]、optimal mass transport (OMT) [Su et al.]

### 主要结果

| 发现 | 细节 |
|---|---|
| **自适应椭球与自由边界在所有算例上同时降低密度畸变与局部形状畸变** | 相对 3DDEQCMap 基线 |
| **自由边界模型显著降低 $K$ 的标准差** | 三个算例（Vase / Igea / David）均如此 → 局部形状畸变控制有效 |
| **所有结果映射的 overlap 数为 0** | 即**全部无折叠** |
| **自由边界模型的 $C^{ρ}_{1\%}$ 显著更低** | 定义为偏差最大的 1% 单元对总平方偏差的贡献 → 密度误差**不再被少数单元主导** |
| **总能量整体显著下降**，但非单调 | 自由边界模型下降最快，之后维持低位 |
| **体积畸变 $D_{vol}$ 可降至 0** | 在 Igea 模型上（Table 2） |

### 耗时

- 迭代数远低于 $n_{\max}=100$（收敛良好）

## 局限性

1. **仅限单连通 3-流形**（simply connected）—— 多连通/带孔拓扑未覆盖
2. **能量不保证单调下降** —— 作者自己明确承认存在局部上升
3. **自由边界模型需要足够多的海层（sea layers）** —— Table 10 显示海层数增加初期改善，但有饱和点；层厚参数 $\kappa$ 亦敏感（Table 11）
4. **对初始化敏感** —— Table 8/9 显示自适应椭球与自由边界模型对初始化有敏感性
5. **依赖 LAPACK/稀疏线性求解器的规模** —— 体网格规模受内存限制
6. **变形应用中 $K$ 累积明显** —— 长时间跨拓扑变形会退化
7. **代码未公开**

## 实现建议

- **实现难度**：⚠️ **高** —— 需要实现：3D 拟共形场更新、扩散式密度均衡、拟共形截断、稀疏线性系统求解的映射重建、**两阶段折叠校正**
- **适用场景**：
  - **体网格重划分**（四面体质量分布控制）—— 最有实用价值
  - **医学体数据**（颅骨/海马/肺）配准与变形
  - **形状分析**：把复杂 3D 形状映射到**各向异性椭球**以获得比标准球更好的规范化
- **预期性能**：单算例约 **30–40 s / <100 迭代**；内存受四面体网格规模限制
- **落地建议**：
  - **优先落地"预定椭球"设定** —— 它退化为 3DDEQCMap，工程量最小，且已包含完整的折叠校正机制
  - **自适应椭球的 2D 对数半径优化是低成本高收益的改进** —— 建议在固定椭球版本稳定后再加
  - **自由边界模型收益最大但实现最复杂**（需要海层构造 + 边界拓扑维护）
  - **与神经代理结合**：本文的解法与 [[2026-11-26-Resolution-Free-Neural-Surrogate-Parameterization]] 是同一作者组的姊妹工作（前者是变分数值解，后者是其神经加速替代）。**若做体参数化，两者应联合考虑**

## 🤢 可行性分析：自适应体参数化（v3）

### 算法复杂度

- **每迭代**：形状更新 $O(N)$（$N$ = 四面体单元数）+ 密度均衡 $O(N \log N)$（扩散求解）+ 映射重建 $O(N \cdot k)$（$k$ = 迭代次数的稀疏求解）
- **总时间**：$O(n_{\text{iter}} \cdot N \cdot k)$，实测 $n_{\text{iter}} \le 100$，$k$ 为重建内部迭代
- **空间复杂度**：$O(N)$（四面体网格 + 拟共形场 + 稀疏矩阵）

### 实现难度

- **算法复杂度**：高
- **数值稳定性**：⚠️ 需重点关注：
  - 质量项可被扩大目标域**无界降低**（Remark 1）→ 自由边界模型**必须**有包含约束
  - 能量非单调 → 需要良好的步长控制（$\delta_t = 0.1$）
  - 折叠校正需**迭代到无折叠**为止，可能出现修正振荡
  - $K$ 在 $\det(J_f)=0$ 时为 $\infty$ → 需要 $\epsilon$-正则
- **依赖项**：稀疏线性求解器（Eigen / SuiteSparse）、微分几何工具（3D 拟共形分解）、四面体网格处理库

### 推荐结论

✅ **推荐实现** —— 这是今日**几何核心度最高**的一篇。变分模型清晰、三个设定可增量落地、实验覆盖医学形状与应用闭环完整、约 30 s 的运行时间完全可接受。**建议从"预定椭球"起步逐步扩展。**
