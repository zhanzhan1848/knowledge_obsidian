## 核心贡献

> 让文本生成的**可变形物体**（布料、毛绒玩具、绳索）成为**物理有效、可直接仿真**的物体，并与支撑它的家具达成**无穿插接触**。

1. **首个支持可变形体的物理增强文本到 3D 场景生成框架**。现有物理增强流水线只仿真刚体。
2. **从流水线已有信息中构造仿真所需的全部输入**：静止形状（rest shape）、材料模型（material model）、可接受的初始状态（admissible initial state）——这正是文本到 3D 生成返回的几何无效网格所缺失的。
3. **静止形状来自物体的制造方式**，而非生成的「物理不一致的变形后构型」。
4. **材料库**为每个可变形体赋初始弹性参数，之后可优化。
5. **遮挡支撑体重生成并转为水密碰撞网格**。
6. **统一接触模型下驱动整个场景到静力平衡**，用几何检查 + 视觉-语言模型双重验证完成度。
7. **失败时网格搜索摆放位置修正**；网格搜索失败的用**可微仿真的伴随法**（adjoint of a differentiable simulation）达成目标。
8. **多体场景在单次仿真中同时平衡**，管线也可仅从文本 prompt 端到端运行。
9. **65 个 prompt 上零非期望互穿**，而其他所有系统都会出现。

## 技术方案

### 核心思想

文本到 3D 生成返回的网格**几何无效**（可能自交），且没有：

- **rest shape**（静止形状）
- **material model**（材料模型）
- **admissible initial state**（可接受的初始状态）

而这恰好是**可变形仿真**的必需输入。论文的核心贡献就是从流水线中已有的信息里把这三样补齐。

关键洞察：**静止形状应来自物体如何被制造**，而不是来自生成的、已经处于物理不一致变形状态的构型。这在几何上意味着——生成的是"垂坠后"的布料，而布料本身的自然形状是"平铺裁片"。

### 关键技术

| 技术 | 说明 |
|------|------|
| **静止形状恢复** | 由制造工艺（裁剪/缝合模式）反推，与生成构型解耦 |
| **材料库** | 为布料、毛绒玩具、绳索等类别赋予初始弹性参数（可微仿真可用），后续可优化 |
| **支撑体重生成** | 遮挡的支撑家具重新生成，转为**水密碰撞网格** |
| **可接受初始状态** | 每个物体从「prompt 指定支撑部件之上」的可优化摆放位置释放 |
| **统一接触求解** | 整个场景在**单一接触模型**下驱动到静力平衡，多体一次仿真完成 |
| **完成度验证** | 几何检查 + **视觉-语言模型**双重验证 |
| **网格搜索修正** | 场景不满足 prompt 时，网格搜索摆放位置修正 |
| **可微仿真伴随法** | 网格搜索无法达成时，用同一接触能量的**可微仿真伴随**（adjoint）直接优化到目标，并联合摆放多个刚体、恢复并优化材料参数 |
| **几何有效性保证** | 65 个 prompt 上**零非期望互穿**（无论物体之间、物体与支撑面之间、还是自交） |

## 实验结论

- **数据集**：65 个文本 prompt（涵盖"几件衣服乱七八糟地扔在布艺沙发的靠背和座面上"这类复杂场景）
- **核心指标**：非期望互穿发生率 —— **本文 0/65，所有对比系统均出现**
- **对比系统**：现有物理增强流水线（把生成的衣服当刚体仿真）
- **定性**：先前工作的衣服会**漂浮在沙发上方或与沙发相交**；本文结果中每件衣物都** resting 在沙发上且无相交**
- **仿真序列**：释放 → 首次接触 → 落地 → 堆积 → 松弛 → 平衡，整个过程在**一次仿真**中完成
- **可用性**：结果直接支持**场景编辑**与**机器人操作**（同一求解器即可）

---

## 局限性

- 静止形状的恢复依赖**制造工艺先验**（裁剪/缝合模式），对制造方式未知或高度非典型的物体不适用
- 65 个 prompt 的规模偏小，多样性有限
- 材料库需要预先定义类别
- 可微仿真伴随法对接触求解器的可微性有要求，仍受限于接触求解器本身的不连续性

## 实现建议

- **实现难度**：**高**。需要：可微布料仿真器（DiffCloth / ChainQueen / IPC 类）、接触求解器、文本到 3D 生成后端、以及静力平衡求解的收敛控制。
- **数值稳定性**：
  - 布料自碰撞是最大难点；水密碰撞网格 + 厚度模型是必需而非可选
  - 静力平衡求解用隐式积分 + 阻尼；需要检查残余动能而非只看位移
  - 生成网格的自交必须在**进入仿真前**修复，否则接触求解会发散 —— 这是几何处理的核心环节
- **依赖项**：DiffCloth / IPC / Taichi（含可微仿真）、NVIDIA Omniverse / Isaac Sim（刚体+接触）、自研生成后端
- **适用场景**：
  - 机器人操作训练数据生成（生成可直接仿真的场景）
  - 具身 AI 的场景合成
  - 家居/服装内容创作
- **对几何处理的意义**：**生成网格的修复（去自交、水密化、厚度化）是物理仿真的前置条件**。这篇论文把"几何有效性"提升为一等公民，对做网格修复的人来说是明确的用武之地——修复后的网格质量直接决定仿真能否收敛。
