## 核心贡献

> 装配体重建的**离散物理约束**问题：不仅要让零件"看起来在正确位置"，还要让它们**真的连接上**。本文用 **SE(3) 流模型**学装配先验，再用**解析的连通性场（connectivity field）**在测试时把预测拉向真正连通的解。

1. **集合条件的 SE(3) 流模型**：基于 **DiT**（无 SE(3)-等变层），在**无序零件集合**上做流匹配。每个零件一个 token（类型嵌入 + 当前位姿编码 + 可选材质嵌入），**不用位置编码**（因为库存无序）。
2. **解析连通性场**：把装配看作**电网络**——零件是节点，候选连接座（seat）是电导。定义**有效电阻**能量 $E(X)$，**当且仅当装配真正连通且坐到位时 $E$ 与其梯度都为零**。
3. **测试时能量引导**：不需要重训或辅助网络，在采样过程中用 $\nabla E$ 修正采样状态，把分布倾斜向连通装配。
4. **精确的位姿距离度量**：用**单位质量二阶矩**把平移与旋转误差统一到同一量纲（LDU），并处理重复零件置换、零件内对称性与全局旋转的不变性。

**为什么这篇与几何处理相关**：这是一篇"**离散约束嵌入连续优化**"的漂亮范例——几何上连续的位姿空间，被一个**解析可微的拓扑能量**（电网络连通性）约束。而且作者证明了该能量在合法解处**精确为零**（不是近似），这是一个很少见的强性质。

## 技术方案

### 核心思想

**任务**：给定一组已知零件 $\mathcal{P}=\{(p_i,m_i)\}_{i=1}^N$（类型 + 材质）和**可选**的一张已装配物体的图像 $I$，预测每个零件的 6-DoF 刚体变换 $X=\{T_i\}_{i=1}^N$，$T_i\in SE(3)$。

**与传统单目 3D 重建的本质区别**：必须满足**离散物理约束**——零件要真的接得上，不碰撞。这些约束**提供结构但使问题组合化且对小位姿误差高度敏感**。

**难点**：
- 学到的流捕捉**全局结构**但不强制**连通性**
- 图像条件的微调数据昂贵（渲染 1M 装配 ≈ 1% 预训练数据量已经算便宜）

### 关键技术

| 技术 | 说明 |
|------|------|
| **SE(3) 流匹配插值** | 平移线性插值 $x_i(t)=(1-t)x_i^0+tx_i^1$；旋转走 $SO(3)$ 测地线 $R_i(t)=R_i^0\exp(t\log((R_i^0)^\top R_i^1))$，速度恒定 $v_i=x_i^1-x_i^0$，$\omega_i=\log((R_i^0)^\top R_i^1)^\vee$ |
| **噪声端点构造** | $t=0$：平移从各向同性高斯采样并平移到零质量加权质心（标准差仅依赖零件数 $N$）；旋转从 $SO(3)$ 均匀采样 |
| **最优置换配对** | 因库存无序 + 零件可对称，$X_0$ 与 $X_1$ 通过近似最小化 $\sum_i\mu_i d^2(T_i^0,T_{\pi(i)}^1)$（枚举重复零件置换、内在对称、全局旋转）来配对 |
| **惯性加权旋转损失** | $(\hat\omega_i-\omega_i)^\top J_i\frac{1}{\mu_i}(\hat\omega_i-\omega_i)$，$J_i$ 为惯性张量；$w(t)=\left(\frac{1-t}{1-\min(t,0.9)}\right)^2$ 在数据端点附近降权 |
| **Heun 采样 + 旋转调度** | 50 步 Heun；旋转不直接用插值的 $\Delta t/(1-t)$ 更新（会发散），改为朝 $\hat R_i^1$ 走测地线的 $\kappa\Delta t$ 比例，$\kappa=25$。该调度使无引导有效率**翻倍以上** |
| **图像条件** | 冻结 **DINOv3-L**（24 层中取**第 18 层**）→ **Perceiver resampler**（256 latents，6 层）压缩 CLS+patch token → 每个 DiT 块中通过**解耦 cross-attention** 注入 |
| **关键点头** | 预测每个零件质心的图像投影，用 **β-NLL** 损失（权重 10）。图像 10% dropout 以支持 classifier-free guidance（推理强度 2） |
| **候选座误差 $c_h$** | 质量加权的均方位移：$\min_{\theta,Q}\frac{\mu_a d_a^2+\mu_b d_b^2}{\mu_a+\mu_b}$，$\theta$ 遍历连接器族自由坐标（stud 旋转、axle 滑动），$Q$ 是两者的公共刚体运动（闭式解）。**完美配合 $c_h=0$** |
| **电网络构造** | 零件 = 节点；候选座贡献电导 $g_h=\frac{w_h}{\rho+q(c_h)}$。$w_h$ 是五次 smoothstep taper（<12 LDU 时为 1，>16 LDU 时为 0）。同对零件的候选座合并为 $G_{ab}=(\sum_h g_h^4)^{1/4}$（让最优候选主导），另有弱电导 $G_{weak}=\frac{1}{16N}$ 保证网络连通 |
| **有效电阻能量** | $E(X)=\frac{1}{N-1}\sum_{a<b}\phi(\Omega_{ab}-(N-1)\rho)$，$\Omega_{ab}$ 是零件 $a,b$ 间的**有效电阻** |
| **平滑铰链** | $q(c)=\tau H\left(\frac{c-\tau}{\tau}\right)$，$\phi(x)=\Omega_0 H\left(\frac{x}{\Omega_0}\right)$，$\Omega_0=(N-1)\rho$，$H(x)=\frac{x^3}{x^2+1}$（$x>0$），否则为 0；$\rho=\tau=10^{-8}\ \text{LDU}^2$ |
| **测试时引导** | $X_{t+\Delta t}\leftarrow X_{t+\Delta t}-\gamma M^{-1}\nabla_{X_t}E(\hat X_1(X_t))$，$\gamma=2$；修正以各零件质心的 twist 施加，$M$ 按转动惯量平方加权；**每零件修正裁剪到 1 LDU**；移除质量加权平均平移以保持质心 |
| **最终吸附（snapping）** | 若 RMS 位移 ≤0.8 mm / 2 LDU、角位移 ≤10°、不丢失连接、不引入新碰撞，则精确吸到座上 |

### 公式

**位姿距离（统一平移与旋转误差量纲）**

```math
d^2(T,T')=\|x-x'\|^2+\operatorname{tr}\!\left((R-R')\Sigma(R-R')^\top\right)
```

$\Sigma$ 为零件单位质量的二阶矩。单位是 LDraw 单位（LDU，20 LDU = 一个 stud 宽）。

**能量为零的性质**（作者在 1,000 个 held-out 程序化装配上验证：**能量与梯度对合法连通装配精确为零**）

若精确坐位的连接把所有零件连成一体，则任意两零件间存在至多 $N-1$ 个座电阻 $\rho$ 的路径，故 $\Omega_{ab}\leq(N-1)\rho$，于是 $E$ 与 $\nabla E$ 都为零。**由 Rayleigh 单调性**，额外电导只会降低有效电阻，所以松散接触与冗余连接**不会扰动已连通的装配**；而脱离的零件组因高有效电阻被拉向可达的候选座。

**能量倾斜分布**

$$
\tilde{p}(X_1)\propto p(X_1)\exp(-\beta E(X_1))
$$

因 $E\geq0$，$\exp(-\beta E)\in(0,1]$ 是"观测到装配连通"的合法似然，故 $\tilde p$ 即该观测下的后验。实现沿用 **DPS**（Chung et al., 2023）的思路。

## 实验结论

### 数据（ProcBrick 程序化生成）

- **LEGO 几何**：LDraw 系统；**连接器有效性**：BrickNet 类型化连接器系统（stud–hole、hinge、axle、ball-joint、fixed）
- **程序化生成**：自回归生长——采样种子件 → 识别兼容连接器位 → 尝试放置 → 拒绝或按概率拒绝碰撞
  - 朴素拒绝采样偏向稀疏装配（放进开放空间很少碰撞）→ 改为**随机接受无碰撞放置 + 偏向打包密度 + 约束每个新增件的连接数与邻居数**（范围取自人类设计模型）
  - 因生成序列的**每个前缀都合法**，训练时可用可变前缀长度
- **预训练数据**：**1 亿**程序化装配，全量预训练用 100 件装配，训练时暴露 **2–100 件前缀**；**6,339 个几何类**（按相同碰撞体与连接器接口定义）
- **图像条件数据**：额外 **100 万** ProcBrick 结构（= 预训练的 **1%**），Blender 渲染，零件数在 2–100 间平衡，1024×1024 透明背景渲染后再增强；**12,663 种不同渲染外观**，**260 种渲染材质**，外观频率拟合自 **53,431 个人类设计模型**
  - 渲染配置：964 张环境贴图，10% 用影棚布光，随机相机 roll/zoom/offset，随机擦除，光度抖动，传感器噪声，合成到 ImageNet 或纯色背景

### 优化设置

| 设置 | 预训练 | 图像微调 |
|------|--------|---------|
| 数据 | 100 M 装配 | 1 M 渲染装配 |
| 零件数 | 2–100 前缀 | 2–100 平衡 |
| 训练步数 | 1 M | 200 k |
| Batch size | 4,096 | 2,048 |
| Muon LR (S/B/L) | 2.4/1.2/0.9 ×10⁻³ | 7.1/3.5/2.7 ×10⁻⁴ |
| AdamW LR | 4×10⁻⁴ | 1.4×10⁻⁴ |
| 流时间分布 | logit-normal, $\mu=1.2,\sigma=1.5$ | logit-normal, $\mu=0,\sigma=1.5$ |
| 图像编码器 | — | DINOv3-L 第 18 层 |
| Resampler | — | Perceiver, 256 latents, 6 层 |
| 图像 dropout / 材质 dropout | — | 10% / 25% |
| 关键点损失 | — | β-NLL，权重 10 |

两阶段均用 **Muon**（隐藏矩阵）+ **AdamW**（其余参数）+ 逆平方根学习率调度。

- **DPS（连通性场引导）在所有 12 个配置上单调提升 Valid**，最高提升 **+7.2 个百分点**（BrickNet / IC DiT-L：30.5 → 35.1）；同时 Comp. 下降、Coll. 下降

- **Valid 指标**：解析后的连接器图只有一个连通分量，且任意两零件碰撞不超过 1.1 LDU

### 超参敏感性

在 ProcBrick 评价集子集上：$\gamma$ 从 1 到 4、裁剪从 0.5 到 2 LDU 或去掉裁剪、$t_{\text{start}}$ 从 0 到 0.8 —— **Valid 变化最多 2.1 个百分点**。超参鲁棒。

### 吸附的作用

吸附提升 Valid、降低碰撞，**质量加权位移变化最多 0.07 LDU**。所有主结果均为吸附后。

## 局限性

论文明确列出的（主要来自摘要与正文可见部分）：

1. **要求每个零件都被使用**，且必须满足连接器定义的离散约束——问题本质是组合化的
2. **对小的位姿误差高度敏感**（约束提供结构但使问题组合化）
3. **人类设计的 BrickNet 装配上 Valid 仅 35.1%**——离实用还有距离
4. **图像微调只用了 1% 的数据量**（1 M 渲染装配），渲染成本高
5. 每个引导步需要**额外一次反向传播**（Sec. F）；推理延迟高于无引导模型
6. 评测依赖 **BrickNet 的连接性/碰撞检查**（Kulits and Schmid, 2026）——与训练数据的生成器同源，可能有偏

## 实现建议

- **实现难度**：**中—高**。神经网络部分（DiT 流匹配）相对标准；**难点在连通性场**：需要 (a) 连接器族的解析定义与闭式刚体配合求解；(b) 电网络有效电阻的高效可微计算（$\Omega_{ab}$ 通常需要稀疏线性求解或 Laplacian 伪逆）；(c) 每步引导的反向传播开销
- **数值稳定性**：**好但需注意尺度**。$\rho=\tau=10^{-8}\ \text{LDU}^2$ 非常小，$\phi$ 的 $H(x)=x^3/(x^2+1)$ 在 0 附近光滑——设计上避免了奇异；能量在合法解处**精确为零**（作者在 1,000 个 held-out 装配上验证）。实际风险在于 $c_h$ 求解中 $\theta$ 遍历（stud 旋转是连续域，axle 滑动是连续域）的最小化精度
- **对几何处理的价值**：
  - ✅ **"离散约束 → 连续可微能量 → 测试时引导"是装配/拓扑约束重建的通用范式**，可迁移到其他有离散连接约束的场景（管线拼接、模块化家具、人体关节连接、机械装配）
  - ✅ **有效电阻作为连通性度量**是一个优雅且可复用的工具——与拓扑学的连通性判据天然契合
  - ✅ **"能量在合法解处精确为零"（而非近似）**是极难得的强性质，值得作为设计目标学习
  - ✅ **惯性加权损失 + 统一量纲的位姿距离**（$d^2$ 用二阶矩 $\Sigma$）是刚体位姿回归的正确做法，值得直接借用
  - ✅ **旋转采样用 $\kappa\Delta t$ 替代 $\Delta t/(1-t)$**——测地线 ODE 在数据端点必然发散，这是流匹配采样的通用陷阱，值得记入技术备忘
  - ⚠️ 需要为每个零件族手写连接器族定义与解析配合——**没有现成通用库**
  - ❌ 有效电阻能量需要稠密的 $N\times N$ 分析（能量对所有 $\binom{N}{2}$ 对求和），$N=100$ 时每步 5,000 对，规模再大成本迅速上升
- **落地建议**：若要复现，优先级应为：① 先实现 $c_h$（候选座误差）与电网络有效电阻的离线计算并验证"合法装配能量精确为零"；② 再接 DiT 流模型；③ 最后加 DPS 引导（因为引导带来的提升最大且**不需要重训**）。项目页已提供模型与数据，可直接下载权重做推理验证
