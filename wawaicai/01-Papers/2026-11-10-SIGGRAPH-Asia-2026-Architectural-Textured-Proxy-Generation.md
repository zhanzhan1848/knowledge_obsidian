## 核心贡献

> 把「几何抽象」与「纹理映射」从**串行解耦**改为**联合约束**：代理模型的几何在生成阶段就被航拍图像的结构线索约束，使结构特征（立面、棱边、交点）天然跨视图对齐，纹理映射退化为「聚合一致的观测」而非「修复不一致」。

1. **Image-Guided Proxy 范式**：首个面向**纹理-几何对齐**的代理生成方法，从无纹理密集重建出发即可产出对齐的纹理代理。
2. **建筑导向的相机位姿精化**：利用单目法向（MoGe）与重建网格渲染法向的一致性，优化相机位姿，修正 SfM 全局合理但局部不准的误差。
3. **平面先验提取管线**：2D 平面结构分割（ProxySAM）→ 投影到密集网格 → 3D 平面区域生长，得到平面/非平面面的划分。
4. **PlaneSet 基准 + ProxySAM 模型**：面向城市航拍图像的平面结构分割基准（基于东京数据集 ~3.62 km² 渲染约 1000 视角），并用 LoRA 微调 SAM3 得到 ProxySAM。
5. **全局 + 局部双引导的法向场**：平面面用全局引导（球面 K-means 主方向），非平面面用局部引导（one-ring patch 面积加权法向 + 联合双边滤波）。

## 技术方案

### 核心思想

**问题诊断（Figure 2 的三类几何缺陷）**：

现有流水线的结构性缺陷在于——几何抽象阶段**完全不看图像**，导致：

1. **边缘错位（edge misalignment）**：相机估计误差 + 几何抽象误差 + 投影误差累积
2. **平面区域破碎（fragmentation）**：密集模型局部噪声使平面结构被切碎
3. **跨视图纹理冲突**：不同视图的纹理相互矛盾

由于几何结构在纹理阶段已不可恢复，texturing 只能做**补偿性修正**，往往失败。

**解法**：把共享的**结构信号**同时注入两个环节——

- 相机位姿由「图像法向 vs 网格渲染法向」的一致性驱动
- 代理几何由「图像法向引导场」驱动

这样结构特征在构造时就已经对齐，下游纹理映射只需聚合。

### 关键技术

| 技术 | 说明 |
|------|------|
| **初始化** | ContextCapture 商业软件跑标准 SfM + MVS + 表面重建，得到 $\mathcal{D}=(\mathcal{F},\mathcal{V})$（网格流形，无自交）与相机 $\{\mathcal{C}_k\}$；用二值激活掩码 $\{\mathcal{A}_k\}$ 标记目标建筑区域 |
| **法向先验** | 单目法向估计模型 **MoGe** 估计 $\{\widehat{\mathcal{N}}_k\}$ |
| **可微渲染** | **Nvdiffrast** 渲染 $\mathcal{N}_k$，与 $\widehat{\mathcal{N}}_k$ 构成法向一致性损失 |
| **相机正则** | 采用 Carlone 等 2015 的 SE(3) 正则：平移 L2 + 旋转 $\log(R^\top R_0)$ 的 L2 |
| **PlaneSet 基准** | 东京数据集（MLIT, 2023）~3.62 km²，用提供的平面代理渲染约 1000 个航拍视角；region growing（法向相似）聚合面；**Stable Diffusion 3.5** 以 Depth + Canny 双 ControlNet 条件生成写实渲染，得到平面结构掩码 |
| **ProxySAM** | 用 **LoRA** 微调 **SAM3**，输入文本 prompt "facade plane" 预测各平面实例掩码；掩码在后续阶段**固定不变** |
| **2D 平面掩码质量** | $Q$ 由三方面衡量：面法向一致性、面平面性、连通性 |
| **3D 平面先验** | 每个 2D 实例掩码投影到密集网格得三角形面集；对高频观测的面用 **Jaccard 相似度**（考虑掩码集与相对质量）做 region growing，聚合为 3D 平面区域；最终划分 $\mathcal{F}$ 为平面面 $\{f\}_p$ 与非平面面 $\{f\}_{np}$ |
| **全局引导（平面面）** | 对平面实例的法向做**球面 K-means**（$K=3$）得主方向 $\{u\}$（含反向）；面法向初始化为实例平均法向 $\bar{n}$，若与某 $u$ 的余弦相似度 > $\tau=0.95$ 则替换为该主方向。**实验发现不强制主方向正交反而更贴合重建形状与纹理** |
| **局部引导（非平面面）** | 选最连贯的 one-ring patch $p_i$，剔除与 $n_i$ 法向距离小于 $\tau_n=0.95$ 的面（简化了 Zhong 等 2021 的 patch refinement），求面积加权平均法向 $g_i$；再用**联合双边权重**聚合邻域法向得到 $\mathbf{G}_i$ |
| **代理优化** | 迭代优化密集模型顶点位置 $L_{Proxy} = L_{Planar} + \lambda_l L_{Lap} + \lambda_r L_{PReg}$，$\lambda_l=1$、$\lambda_r=100$，Adam lr $=10^{-5}$、指数衰减 $\gamma=0.995$；每轮迭代后更新 3D 先验与引导场 |
| **重网格化** | 每 10 次迭代做一次**自适应各向同性重网格化**（Pietroni 等 2009），目标边长设为当前网格平均边长的 **110%** |
| **模型逼近** | 法向差小于阈值的相邻三角形用 region growing 合并为代理多边形 $\{p\}$，再三角化（Botsch 等 2010）得到紧凑分段平面代理网格 $\mathcal{P}$ |
| **纹理重映射** | 直接复用 DiffTex（Xiong 等 2025a）的基于平面的纹理重映射；因相机与代理已在同一坐标系，无需 BLOD 式手工对齐 |

### 关键公式

```math
// 相机优化目标
L_{Camera} = L_{Normal} + L_{Reg}
```

```math
// 法向一致性损失（仅在目标建筑区域）
L_{Normal} = \frac{1}{|\mathcal{A}_k|}\big\|\mathcal{A}_k \odot (\widehat{\mathcal{N}}_k - \mathcal{N}_k)\big\|_2^2
```

```math
// SE(3) 正则项，惩罚相对初始位姿的过大偏离
L_{Reg} = \|\bm{t}_k - \bm{t}_k^0\|_2^2 + \|\log(\bm{R}_k^\top \bm{R}_k^0)\|_2^2
```

```math
// 代理几何优化目标
L_{Proxy} = L_{Planar} + \lambda_l L_{Lap} + \lambda_r L_{PReg}, \qquad \lambda_l=1,\ \lambda_r=100
```

```math
// 平面性损失：面法向对齐引导法向
L_{Planar} = \frac{1}{|\mathcal{F}|}\sum_i \|\bm{n}_i - \bm{G}_i\|_2^2
```

```math
// Laplacian 损失，防止退化（倒角、翻面）
L_{Lap} = \frac{1}{|\mathcal{V}|}\sum_{v_j \in \mathcal{V}}
\Big\| v_j - \frac{\sum_{m \in H_j} v_m}{|H_j|} \Big\|_2^2
```

```math
// 逐迭代正则，防止顶点漂移
L_{PReg} = \frac{1}{|\mathcal{V}|}\sum_{v_j \in \mathcal{V}}\|v_j^t - v_j^{t-1}\|_2^2
```

## 实验结论

### 实现环境

- 相机标定：ContextCapture 商业软件；目标建筑重建为网格流形 $\mathcal{D}$（无自交）
- **Nvdiffrast**（相机精化 + 代理生成）+ **CGAL**（代理生成）
- 硬件：Intel i9-14900K @3.0GHz / 128GB RAM / NVIDIA RTX 4090

### 数据集

- **合成集**：6 个不同布局与复杂度的模型（来自 Xiong 等 2025b）
- **真实场景**：Bank、Hisense 等，来自公开源（Xiong 等 2023）

### 代理模型定量对比（Bank 场景）

| 方法 | #V | #F | #p | Error↓ | Comp(%)↑ | ECD↓ | EF1↑ | SSIM↑ | LPIPS↓ |
|------|------|------|------|------|------|------|------|------|------|
| QEM | 1026 | 1993 | 427 | 0.017 | 99.24 | 0.194 | 0.610 | (0.645, 0.595, 0.560) | (0.447, 0.429, 0.503) |
| VSA | 673 | 1316 | 203 | 0.048 | 96.20 | 0.213 | 0.457 | (0.311, 0.385, 0.300) | (0.493, 0.399, 0.516) |
| PolyFit | 400 | 412 | 26 | 0.064 | 88.25 | 0.259 | 0.353 | (0.625, 0.567, 0.556) | (0.573, 0.488, 0.551) |
| KSR | 767 | 1530 | 221 | 0.044 | 88.12 | 0.210 | 0.408 | (0.634, 0.575, 0.597) | (0.498, 0.495, 0.534) |
| BLOD | 263 | 505 | 93 | 0.061 | 88.12 | 0.248 | 0.418 | (0.638, 0.584, 0.589) | (0.476, 0.489, 0.521) |
| **Ours** | 652 | 1036 | **203** | **0.027** | **99.88** | **0.188** | **0.713** | **(0.722, 0.634, 0.608)** | (0.311, 0.311, 0.430) |

> 指标说明：Error（Smith 等 2018 / Xiong 等 2025b，代理逼近真值模型的误差）、Comp（完整度）、ECD（棱边检测率）、EF1（F1）、SSIM/LPIPS 为三个放大视角的取值。

**关键结论**：

- **本文 Error 最低（0.027）**，且在几乎相同顶点数（652 vs VSA 673）下，**完整度 99.88%** 远高于所有基线
- **EF1 最高（0.713）**，SSIM 三个视角全面最优
- **LPIPS 反而不是最优**（Bank 场景 QEM 0.447 优于本文 0.311–0.430 的区间上界，但本文三个视角分别 0.311/0.311/0.430 已优于 VSA 的 0.300 边界情况）——需要注意 LPIPS 并非全面领先
- VSA 通过变分表面聚类得到紧凑逼近，但**区域边界有明显锯齿伪影**
- PolyFit / BLOD 恢复出更规整的平面，但作为纯几何方法，对**弱几何线索的台阶或凹陷结构会过度简化**，重建平面会跨越不同结构层
- Hisense 场景结论一致：相机精化后所有方法的 SSIM / LPIPS 均显著提升，验证相机精化本身的有效性

### 消融：全局 vs 局部引导

- **仅局部引导**：整体平滑且保留锐边，但局部引导只看局部面，**无法区分平面结构**，会把小尺度平面结构混为一谈，无法鼓励大尺度平面性
- **仅全局引导**：保留主导平面结构与局部结构，但**残留小尺度噪声**
- **全局 + 局部**：结构忠实且分段平面（Fig. 9 第四列，曲率着色）

## 局限性

1. **未识别物体（如植被）会被保留**：算法不认识树叶，代理模型里会留着树。作者计划引入更多语义信息以移除用户指定物体。
2. **无层级 LOD**：目前不生成支持 LOD 的分层平面结构，列为未来工作。
3. **几何与图像未联合优化**：本文仍是先优化几何再优化相机的序列流程，作者承认「联合优化几何与图像一步到位」是挑战性方向。
4. 依赖商业软件 ContextCapture 做初始标定，闭源。

## 实现建议

- **实现难度**：**中**。核心部件都是成熟的：
  - 相机精化：可微渲染 + Adam 优化（1000 iter/view，lr 0.005，每 100 iter 衰减 $\gamma=0.995$）
  - 平面先验：SAM3 + LoRA 微调（需 GPU 训练，但推理只需一次 forward）
  - 代理优化：顶点位置梯度下降 + 每 10 次迭代重网格化（最耗时的部分）
  - 平面合并：CGAL region growing
- **数值稳定性**：
  - $L_{Reg}$ 的 $\log(R^\top R_0)$ 在旋转接近 $\pi$ 时有奇异（SO(3) 对数映射在 $\pi$ 处不唯一），需注意
  - $L_{PReg}$ 权重 100 相对 $L_{Lap}$ 权重 1 很大，若换掉 $L_{PReg}$ 会导致顶点跳变；消融在补充材料
  - $L_{Planar}$ 直接最小化法向差 $\|n - G\|^2$，在法向接近球面反极点时梯度退化
  - 重网格化每 10 步触发会重置拓扑，代理优化与重网格化交替的收敛性需要监控（论文以「最大顶点位移可忽略」为收敛判据）
- **依赖项**：Nvdiffrast（必须）、CGAL（平面合并/三角化）、PyTorch、segment-anything（SAM3 + LoRA）、MoGe
- **预期性能**：单场景单 GPU（RTX 4090），代理优化迭代数未在正文明确给出（论文以最大位移判收敛），估计为百次量级
- **适用场景**：
  - 城市航拍影像 → 紧凑建筑代理（LOD 化建筑模型、城市孪生）
  - 大规模场景的轻量化（比 QEM 更结构化）
  - 纹理烘焙前的几何准备（消除跨视图纹理冲突）
  - 建筑 CAD 重建流水线中的平面结构提取

### 对几何处理研究者的价值

这篇论文的**方法论转变**值得单独关注：**"几何抽象阶段引入图像证据"** 是一个可推广到其他域的思路——不只建筑代理，任何"几何简化 + 纹理/语义烘焙"的流水线（法线贴图烘焙、语义分割网格化、AR 资产压缩）都面临同样的耦合问题。

另外三个可直接复用的技术点：

1. **法向一致性驱动的相机精化** — 对任何"重建 + 图像"配准问题都适用
2. **全局/局部双引导法向场** — 兼顾大尺度平面性与小尺度锐边的结构化网格优化范式
3. **PlaneSet 基准** — 城市航拍平面分割的公开基准
