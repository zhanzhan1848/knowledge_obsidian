# Perception Over Geometry: Rethinking Gaussian Allocation in Mesh-based Splatting (P-MGS)

> **核心主张**：网格提供**结构可控性**，但**不决定**表示容量；高斯数量应由**外观感知复杂度**而非网格细分密度决定。

## 核心贡献

> 现有 mesh-based splatting（如 GaMeS）给每个三角形面**固定分配 K 个高斯**，隐含假设「网格细分密度 = 外观复杂度」——这在几何密集但视觉简单的区域浪费容量，在纹理丰富但网格粗糙的区域表现不足。P-MGS 用**多视角感知复杂度引导的分配**替代固定分配，并把「重建」与「操作」**解耦**（先无约束优化，后绑定网格）。

1. **Perception Over Geometry 原则** —— 网格管拓扑与可控性，感知复杂度管表示容量。
2. **多视角感知复杂度估计 + 拉格朗日工作量定价的分配算法** —— 在共享初始化预算下求解带逐视角工作量约束的分配问题。
3. **解耦重建与操作** —— 无约束 3DGS 优化（含自适应致密化）后**后验绑定（post-hoc binding）** 到网格，保留 vanilla 3DGS 的自适应细化能力。
4. **局部仿射形变传递（local affine deformation transfer）** —— 形变时同步更新高斯中心与协方差，消除非刚性编辑下的漂浮伪影与错位。

## 技术方案

### 核心思想

**问题诊断**（论文 Fig. 2）：

| 区域类型 | 网格细分 | 外观复杂度 | 固定分配的后果 |
|---------|---------|-----------|--------------|
| 几何密集、视觉简单 | 密 | 低 | **高斯冗余浪费** |
| 纹理丰富 | 粗 | 高 | **表示不足** |
| 几何细节多、外观简单（Drums/Ship） | 密 | 低 | 差距小（0.82 / 1.57 dB） |
| 几何简单、外观丰富（Chair/Hotdog） | 疏 | 高 | 差距大（**5.12 / 4.29 dB**） |

> 反例最有说服力：**Lego 上 GaMeS（Mesh-Init）用了 10,176K 高斯（约为 3DGS 的 8.5×），PSNR 反而低 2.58 dB** —— 说明「单纯堆容量」无法克服固定分配的错配。

### 关键技术

| 技术 | 说明 |
|------|------|
| **多视角感知复杂度估计** | 逐像素定义 `h_fv(p) = χ_fv(p)·a_v(p)`（面 f 是否为射线首个交点 × 前景 alpha）；局部外观变化 `ρ_v(p) = (1/3)Σ_{c∈{R,G,B}}‖∇I_{v,c}(p)‖² + ε` |
| **面-视角覆盖面积** | `A_fv = Σ_p h_fv(p)`；平均梯度能量 `ρ̄_fv = Σ_p h_fv(p)ρ_v(p) / A_fv`（`A_fv=0` 时置 0） |
| **需求系数** | `Q_f = (1/V)Σ_v A_fv²·ρ̄_fv` —— 平方覆盖项捕捉单元尺寸效应，梯度能量捕捉外观变化；**多视角误差 ∝ Q_f / n_f** |
| **分配问题（带工作量约束的整数规划）** | `min Σ_{f∈P} Q_f/n_f s.t. Σ_f n_f = B, ℓ_f ≤ n_f ≤ u_f, Σ_f n_f T_fv ≤ W_v ∀v` |
| **拉格朗日工作量定价** | 每次将 `n_f` 从 k 增到 k+1 的收益：`S_f(k) = Q_f/[k(k+1)] − Σ_v λ_v T_fv/W_v`；按此排序贪心分配，再按归一化工作量残差更新视角价格 `λ_v`；在所有可行候选中保留 `E` 最低者 |
| **无约束 3DGS 优化** | 初始化后**释放所有网格约束**，用标准 3DGS 管线自由优化（含自适应致密化）；预算与工作量约束**仅作用于初始化** |
| **后验网格绑定** | 优化后确定每个高斯的参考面 `f_i`；用**重心坐标 + 有符号法向偏移**表达中心：`µ⁰_i = Σ_k w_ik v⁰_{f_i,k} + d_i n⁰_{f_i}`，其中 `Σ_k w_ik = 1`，`w_ik` 由中心投影到面平面求得，`d_i` 保留有符号距离 —— **不强制高斯贴在网格表面上** |
| **局部仿射形变传递** | 逐面构造 `E_f^a = [v^a_{f,2}−v^a_{f,1}, v^a_{f,3}−v^a_{f,1}, n^a_f]`，`J_f^t = E_f^t (E_f^0)⁻¹`；中心与协方差同步更新 `µ^t_i = Σ_k w_ik v^t_{f_i,k} + d_i n^t_{f_i}`，`Σ^t_i = J^t_{f_i} Σ⁰_i (J^t_{f_i})ᵀ`；**刚性运动下退化为刚体变换** |

### 关键公式

**高斯空间分布**

$$
G_i(x) = \exp\left(-\frac{1}{2}(x-\mu_i)^\top \Sigma_i^{-1}(x-\mu_i)\right),
\qquad \Sigma_i = R_i S_i S_i^\top R_i^\top
$$

**感知需求系数**

$$
Q_f = \frac{1}{V}\sum_{v=1}^{V} A_{fv}^{2}\,\bar{\rho}_{fv}
$$

**分配问题**

$$
\min_{\mathbf{n}\in\mathbb{Z}^{|\mathcal{F}|}_{\ge 0}} E(\mathbf{n}) = \sum_{f\in\mathcal{P}} \frac{Q_f}{n_f}
\quad \text{s.t.}\quad \sum_f n_f = B,\;\; \ell_f \le n_f \le u_f,\;\; \sum_f n_f T_{fv} \le W_v
$$

**定价后的边际收益**

$$
S_f(k) = \frac{Q_f}{k(k+1)} - \sum_{v=1}^{V}\lambda_v \frac{T_{fv}}{W_v}
$$

**后验绑定的中心表示**

$$
\mu_i^{0} = \sum_{k=1}^{3} w_{ik} v^{0}_{f_i,k} + d_i n^{0}_{f_i}
$$

**局部仿射传递**

$$
J_f^{t} = E_f^{t}\,(E_f^{0})^{-1}, \qquad
\mu_i^{t} = \sum_{k=1}^{3} w_{ik} v^{t}_{f_i,k} + d_i n^{t}_{f_i}, \qquad
\Sigma_i^{t} = J_{f_i}^{t}\Sigma_i^{0}(J_{f_i}^{t})^{\top}
$$

| Allocation | Binding Strategy | PSNR↑ | SSIM↑ | LPIPS↓ |
|-----------|-----------------|-------|-------|--------|
| Uniform (K=3) | Early binding | 30.10 | 0.950 | 0.0476 |

> **两个贡献各自独立有效**：
> - 感知分配：early binding 下 30.10 → 31.36（**+1.26 dB**）；post-hoc 下 33.29 → 34.00（**+0.71 dB**）
> - 后验绑定：uniform 下 30.10 → 33.29（**+3.19 dB**）；perceptual 下 31.36 → 34.00（**+2.64 dB**）
> - **后验绑定的贡献更大** —— 说明「解除网格约束」比「更聪明的分配」更关键

### 定性结果

- **静态渲染**：Chair 上绿色布料更平滑连贯、纹理细节保留、颗粒噪声更少；Building 上 GaMeS△ 窗户出现假颜色、Mani-GS 窗框模糊局部不连续，P-MGS 保留窗色与结构边界
- **网格驱动编辑**：GaMeS△ 与 Mani-GS 在形变后出现明显**漂浮高斯伪影与网格错位**（编辑区尤为严重）；P-MGS 在大尺度、局部、关节式、非刚性形变下均保持更好对齐

## 复杂度分析

- **感知复杂度估计**：逐像素遍历 → O(|V_pixels|)，需在训练图像上做光栅化（可复用 3DGS 的渲染 pass）
- **分配求解**：拉格朗日迭代，每次贪心排序 O(|F| log|F|)；总 O(iter · |F| log|F|)
- **无约束 3DGS 优化**：标准 3DGS 成本，但**去掉了网格约束** → 理论上自由度更高，收敛更好（消融中 PSNR +2.64~3.19 dB）
- **后验绑定**：一次性，O(N_G · |F|) 空间匹配 + 逐高斯重心坐标投影 O(1)
- **形变传递**：逐面构造 `E_f` 与 `J_f` → O(|F|)（3×3 求逆）；逐高斯更新 O(N_G)。**编辑时可实时**
- **存储**：545K 高斯 × (中心+旋转+缩放+不透明度+颜色) ≈ 数十 MB；**无网格约束**意味着无需为每个面保存对应表

## 数值稳定性

- **重心坐标 + 有符号法向偏移的绑定**：避免把高斯强制吸附到网格表面（会破坏无约束优化带来的自由度），同时保留法向方向信息 —— 这是「既解耦又不丢失对齐」的关键设计
- **局部仿射帧 `E_f`**：两条边向量 + 单位法向构成局部 3D 帧，**不引入额外的法向缩放**（避免法向方向被拉伸）
- **协方差更新 `Σ^t = J Σ⁰ Jᵀ`**：对任意 `J`（含剪切）都保持正定 —— 因为 `J Σ⁰ Jᵀ` 在 `Σ⁰` 正定时必然正定
- **刚性退化一致性**：刚性运动下 `J` 为旋转 → `Σ^t` 保持形状与尺度（仅旋转）
- **后验绑定是「冻结」的**：面分配、重心权重、法向偏移在绑定后固定 → 后续编辑无需再优化，数值上完全确定
- **工作量约束的稳定性**：`W_v` 从均匀参考初始化校准，避免分配向某视角倾斜

## 局限性

- **需要参考网格**：实验中用 NeuS 提取；对无网格的场景仍需外部重建步骤
- **操作后无法定量评估**：编辑后的真值图像不可得 → **仅定性比较**（这是该领域评测的共性短板）
- **分配优化是启发式的**：拉格朗日定价 + 贪心是近似解，非全局最优
- **训练开销**：感知复杂度估计需额外渲染 pass（但可与训练共享）
- 未报告在大规模场景（城市级）上的表现
- 面分配的**空间匹配规则**在附录中，摘要与正文未详述 → 复现需读附录

## 实现建议

- **实现难度**: **中**（核心是分配求解 + 后验绑定 + 仿射传递三块，逻辑清晰；难点在感知复杂度估计需要多视角光栅化）
- **预期性能**: 545K 高斯 / 34.00 dB（NeRF-Synthetic 均值）；DTU 191K 高斯 / 32.36 dB；编辑时形变传递 O(|F|+N_G)，可实时
- **适用场景**:
  - **需要「网格可编辑」但又要「外观高质量」的资产** —— 正是数字孪生、角色资产、机器人仿真的核心需求
  - **从 3DGS 迁移到网格管线** —— 先无约束优化再绑定，规避了 mesh-constrained 优化的收敛问题
  - **非刚性网格动画** —— 局部仿射传递在保持对齐上明显优于 GaMeS△/Mani-GS
- **工程注意**:
  - **后验绑定顺序不可颠倒** —— 必须先完成无约束优化再绑定，否则会退回 early binding 的性能
  - 重心坐标 + 法向偏移的分解要严格保持 `Σw = 1`，`d_i` 保留符号（负值表示在面内侧）
  - `E_f` 中的法向用**单位化**向量，否则协方差会被法向长度缩放
  - 分配参数 `B`（总预算）、`W_v`（逐视角工作量）、`ℓ_f`/`u_f`（面上下界）需按场景标定；`u_f` 由可见像素观测限定
  - 建议同时报告 **PSNR 与高斯数量** —— 本文的说服力正来自「更好 + 少 79.7%」的组合
- **依赖项**: PyTorch + 3DGS 官方实现（`diff-gaussian-rasterization`）；`libigl` 可用于网格读取与形变操作；无需自写渲染核心
