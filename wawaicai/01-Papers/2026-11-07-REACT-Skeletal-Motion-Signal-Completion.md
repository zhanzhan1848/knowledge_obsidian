# REACT: Towards Real-Time Completion of Skeletal Motion Signals

> 面向交互/沉浸式应用的**因果（causal）逐帧**骨骼动作补全：把当前被污染的观测（Ref）、物理式短时外推（Phys）、长时程数据驱动生成（Data）三路估计，在**四元数空间做分层融合**，并用**可靠性估计**决定信任谁。

## 核心贡献

> 廉价动捕系统在**标定误差、遮挡、传感器漂移、高频噪声**下会产生不自然动画。REACT 是一个**交互式在线动作补全框架**，**因果逐帧**运行、**无 lookahead**，并暴露若干**可解释的内部信号**。

1. **自适应输入滤波** —— alpha-beta-gamma 跟踪滤波 + **因果五帧滑动中值** + One-Euro 滤波，由 MLP 学习**时变融合 logits**
2. **双头 S4 骨干** —— 共享输入表示 + 两个专门化 S4 分支：**Phys**（ODE 式参数化，精确反应式外推）与 **Data**（长时程上下文，生成连贯多帧延续）。两支都在**连续 6D 表示**上回归关节旋转并**正交化**为旋转矩阵
3. **可靠性感知协作融合** —— 逐关节逐帧估计观测可靠性，据此决定信任 Ref / Phys / Data 多少；执行**四元数空间的分层插值**而非无约束分支混合
4. **SO(3) 感知的时间修正** —— PCAF 式滚动缓冲更新，抑制突变、保持旋转几何
5. **可解释内部信号** —— 滤波残差、混合权重、逐关节可靠性、聚合先验

## 技术方案

### 核心思想

**流式公式**：第 $t$ 帧原始输入 $X_t \in \mathbb{R}^{J\times F}$（$J=23$ 关节，$F=6$ 的 6D 旋转表示），输出 $Y_t \in \mathbb{R}^{J\times F}$。

维护三个历史缓冲：

$$
O_t = \{X_{t-T+1},\ldots,X_t\} \in \mathbb{R}^{T\times J\times F}
$$

$$
P_t = \{Y_{t-T+1},\ldots,Y_{t-1}, X_t\} \in \mathbb{R}^{T\times J\times F}
$$

$$
L_t = \{Y_{t-(6k+\delta)} \mid k\in\{0,\ldots,T-1\}\} \in \mathbb{R}^{T\times J\times F},\qquad \delta = 1 + (t \bmod 6)
$$

> **关键细节**：$P_t$ 的当前项**刻意置为 $X_t$ 而非 $Y_t$** —— 防止训练时**目标泄漏**。

配置：$T=31$，帧率 **60 Hz**，短历史约 **0.5 s**，长缓冲为 31 个 10 Hz 采样（≈ **3 s** 记忆）。

### 关键技术

| 技术 | 说明 |
|------|------|
| **自适应滤波融合** | MLP 学习**时变**融合 logits；滤波残差与混合权重成为可靠性估计的辅助线索 |
| **Phys 分支（物理启发）** | 改编欧拉–拉格朗日形式 $M\ddot q + C_{\text{bias}} = G$，**直接回归差值** $GC \equiv G - C_{\text{bias}}$ 而非分别估计 $G$ 与 $C_{\text{bias}}$。加速度用有限差分，姿态外推 $q_t = \ddot q_t \Delta t^2 + 2q_{t-1} - q_{t-2}$，$\Delta t = 1/60$ s。运行时 $M_t$ 通过 **Cholesky 分解**构造以保证**正定**。**当前原始观测被排除在 Phys 预测之外**，避免污染帧泄漏 |
| **Data 分支** | **唯一**显式预测多帧未来姿态的分支。首个预测姿态参与当前帧补全，其余提供合理延续。**目标不是长时程精确重建**，而是「观测持续缺失、Phys 自回归误差累积时」的稳定合理候选 |
| **分层四元数融合** | 融合 MLP 输出 $Z_{\text{agg}} \in \mathbb{R}^{T\times J\times 4}$，4 个 logits **分成两对、各自 softmax** → 两级「一对一」插值决策。示例顺序：先 Phys 与 Data 插值，再与 Ref 比较：$Y = \beta Y_{\text{Ref}} + (1-\beta)[\alpha Y_{\text{Phys}} + (1-\alpha)Y_{\text{Data}}]$。有效权重 $w_{\text{Ref}}=\beta$，$w_{\text{Phys}}=(1-\beta)\alpha$，$w_{\text{Data}}=(1-\beta)(1-\alpha)$ |
| **零速度延拓** | Phys 与 Ref 是单帧候选，在时间维重复 → 相当于零速度延拓。**只有 Data** 为远处未来帧提供不同的修正 |
| **可靠性估计（反应式分类器）** | 逐帧二分类器预测每个关节观测不可靠的概率，用 BCE 对**增强时生成的真实遮挡掩膜**训练。输入含：Phys 与 Data 的角度差、滤波模块输出、滤波残差、滤波混合权重、**detach 的历史缓冲副本** |
| **可靠性估计（Defiance 缓冲）** | 逐关节**持久状态**累积不可靠证据；更新幅度依赖分类器置信度 → 引入**时间记忆与滞回**，避免逐帧误报/漏报造成的突变 |
| **聚合先验 + softmax 温度** | 用**硬约束的指数衰减**（指定半衰期）+ 小的动态预测修正来约束聚合权重：持续低可靠性 → 逐步压制 Ref；缺失持续越久 → Phys 相对 Data 被逐步压制；序列远处 → Data 越来越受偏爱。softmax 温度由候选旋转间的**测地距离分歧**调节：分歧大 → 决策更锐利；分歧小 → 融合更平滑 |
| **PCAF 式滚动修正** | $P_t = P_{t-1} + U\,\tanh\big(f_\theta(X_t, C_t) - P_{t-1}\big)$，$U$ 为不确定性相关的时间加权函数。把网络输出**重参数化为对滚动缓冲的有界修正**，而非对上一帧的无约束替换 |

### 关键公式

**S4 状态空间模型**

$$
\dot{x} = Ax + Bu,\qquad y = Cx + Du
$$

**Phys 分支（欧拉–拉格朗日）**

$$
M\ddot q + C_{\text{bias}} = G \;\Rightarrow\; \ddot q = M^{-1}(G - C_{\text{bias}})
$$

$$
\ddot q_t = \frac{q_t - 2q_{t-1} + q_{t-2}}{\Delta t^2},\qquad q_t = \ddot q_t \Delta t^2 + 2q_{t-1} - q_{t-2}
$$

**分层融合**

$$
Y = \beta\,Y_{\text{Ref}} + (1-\beta)\big[\alpha\,Y_{\text{Phys}} + (1-\alpha) Y_{\text{Data}}\big]
$$

**可靠性视角一致性指标**

$$
\bar e^2 / (\bar e^2 + \sigma_e^2) < 0.5
$$

**PCAF 式滚动修正**

$$
P_t = P_{t-1} + U\,\tanh\big(f_\theta(X_t, C_t) - P_{t-1}\big)
$$

## 实验结论

### 数据集与训练

- **CMU dataset**（Holden et al. 2016 预处理）：**2,423 个动画**，**2,082,000 帧 @ 60 Hz**；动作含 walking / running / dancing / boxing / digging
- 划分（按动画）：**50% 训练 / 20% 验证 / 30% 测试**；每 epoch 随机采样约 **15%** 训练集
- 固定归一化骨架拓扑与形态（无 retarget、无形态变化）
- 训练：**17 epoch**，batch 32，AdamW，初始 LR 1e-4（每 4 epoch 减半 + 逐步三角循环调度）
- 损失权重：$L_{\text{rec}}$ = MPJPE(1) + MPJAE(0.1) + MPJLAE(0.01) + MPJPVE(0.001) + MPJAVE(0.001)；$L_{\text{bce}}$(0.1) 遮挡分类器；教师–学生 Frobenius 蒸馏项(1)；$\ell_1$(1e-6) + weight decay(0.01)（**不施加于 S4 状态矩阵**）；$L_{\text{regu}}$ 最大幅度 ≈0.001
- **掩膜增强**：目标比例 $m \sim U(M_{\min}, M_{\max})$，$M_{\min}=0$，$M_{\max}\in\{25\%\ldots100\%\}$；**60% 的掩膜按解剖区域选取**，其余独立选取；时间上持久的掩膜，随机时长与重置

### 消融与敏感性

**(A) 融合顺序消融** —— 即 `-r`/`-p`/`-d` 三变体。`-r`（Ref 放最后）在多数旋转指标与体制指标上最佳；`-d`（Data 放最后）**MPJPE 最低（7.7±6.4 cm）**；姿态级差异普遍很小。

**(B) 掩膜严重度鲁棒性**（Fig. 4，4×4 网格 = 16 个 checkpoint/架构）
- MPJPE 主要由 $M_{\max}^{\text{test}}$ 驱动；对多数架构 MPJPE 也随 $M_{\max}^{\text{train}}$ 上升，但幅度更小
- GRU 系存在权衡：训练严重度低 → 轻度测试掩膜下 MPJPE 更低但 **AUJ_max 更大**；训练严重度高 → 更新更平滑但逐帧重建更差
- **RPM 取得最低 AUJ_max，代价是更高 MPJPE**
- **`-r` 变体在所有设置下 MPJPE 与 AUJ_max 都低**，且固定 $M_{\max}^{\text{test}}$ 时 MPJPE 随 $M_{\max}^{\text{train}}$ 变化**相对较小**（对训练掩膜严重度**不敏感**）

**(C) 融合权重分析**（Fig. 5）—— `-r` 变体在 "Occluded" / "Observable" 两种条件下的逐关节平均融合权重。**遮挡时 Ref 贡献一致下降，而预测候选（主要是 Phys）权重上升**。

## 复杂度分析

- **推理延迟**：1.10M 参数下 **21.94 ms (P50) / 23.71 ms (P95)** @ RTX 3090 → 约 45 fps；旋转转换等几何运算占 17.6%
- **训练**：17 epoch × 每 epoch 15% 采样 ≈ 2.5 epoch 等效；batch 32
- **显存**：222 MB（推理）；S4 状态空间 + 三个长度 31 的缓冲（$31\times23\times6$）
- **蒸馏学生**：0.38M 参数，0.62 ms → **>500 fps**，代价是精度下降约 2.8 cm MPJPE

---

## 数值稳定性

- **Cholesky 分解保证 $M_t$ 正定** —— Phys 分支的 $M^{-1}$ 才有意义
- **目标泄漏防护**：$P_t$ 当前项置 $X_t$ 而非 $Y_t$
- **当前观测排除在 Phys 之外**：避免污染帧直接进入反应式外推
- **Defiance 缓冲的滞回**：防止逐帧误报导致的融合权重抖动
- **softmax 温度按测地分歧自适应**：候选高度一致时用软融合（更稳），分歧大时用锐利决策（更准）—— 抑制「在两个都不确定的候选间乱跳」
- **PCAF 的 $\tanh$ 有界修正**：网络输出被限制在对滚动缓冲的**有界**修正内，任何单帧噪声预测的影响被**天然限幅**
- **聚合先验的硬约束指数衰减**：先验是**硬约束**而非软正则 → 不会在极端观测条件下失效

## 局限性

1. **因果性的固有限制** —— 无法用未来帧；**无法精确恢复其必要信息只在后来才出现**的动作段；**当前遮挡的持续时长未知**
2. **长时程本质歧义** —— Data 分支目标是「合理且稳定」，**不保证**是用户真实动作
3. **自回归误差累积** —— Phys 分支在长时间遮挡下会累积误差（这正是需要 Data 分支互补的原因）
4. **物理启发 ≠ 物理模拟** —— $M$、$G$、$C_{\text{bias}}$ 是**学习到的归纳偏置**，不应解释为有物理意义的惯量或力估计
5. **依赖合成损坏** —— 遮挡与高频噪声通过训练期增强模拟；在这些模拟分布下的鲁棒性**不保证**泛化到所有真实传感器失效模式
6. **固定骨骼拓扑** —— 刻意隔离了补全与形态/重定向/拓扑变化；**不同骨架尺寸或结构的泛化未处理**
7. **可靠性估计的失效模式** —— 置信度估计错误会导致：不可靠观测被过度信任、有效观测被压制、关节重现时突变、短暂「眨眼」遮挡后恢复延迟。Defiance 缓冲缓解但**不能消除**
8. **融合与优化复杂度高** —— 多 S4 分支 + 多滤波 + 门控 MLP + 可靠性估计 + 正则 + 先验调制 softmax + 滚动缓冲修正，**训练与维护复杂**
9. **性能低于沉浸式目标** —— 45 fps < 60–90 Hz 目标；旋转转换占 17.6% 是不小的固定开销
10. **仅重建导向评估** —— 无感知/生物力学指标

## 实现建议

- **实现难度**: **中-高**（S4 分支实现不难，难在多层滤波 + 分层四元数融合 + 可靠性/先验的联合调参）
- **预期性能**: 1.1M 参数 / 22 ms 每帧 @ RTX 3090；蒸馏后 0.38M / 0.62 ms
- **适用场景**:
  - **VR/AR 遥操作**中廉价动捕的**在线动作补全**
  - 需要**因果、无 lookahead** 的实时动画管线
  - **网格绑定/蒙皮**的上游信号修复（骨骼信号 → 蒙皮动画）
- **最值得复用的技术点**:
  1. **分层（两级 softmax）四元数融合** —— 把「信任观测 vs 信任预测」和「信任短时 vs 信任长时」**解耦成两个独立决策**，比一次性混合 3 个权重更可解释、更可调
  2. **Defiance 缓冲（滞回）** —— 任何逐帧二分类置信度都应加一层时间滞回，否则会出现抖动
  3. **softmax 温度按测地分歧自适应** —— 通用技巧，适用于任何多候选几何/旋转融合
  4. **PCAF 有界修正** —— 用 $\tanh$ 把网络输出重参数化为「对上一状态的有界修正」，天然抗单帧噪声
  5. **「$P_t$ 当前项置 $X_t$」式防泄漏** —— 自回归/流式模型的通用防泄漏技巧
- **依赖项**: PyTorch + S4 实现（可参考官方 minimal S4 库）；旋转运作用 PyTorch3D / scipy.spatial.transform
- **注意**: 若目标含 60 Hz+，需先做**旋转转换优化**（占 17.6%）或直接蒸馏到学生模型
