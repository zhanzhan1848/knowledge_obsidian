### ⭐⭐⭐ 1. PostMesh: Self-Rewarded Preference Post-Training for Flow-Based Artist Mesh Generation

| 项 | 内容 |
|---|---|
| **arXiv** | [2611.34319](https://arxiv.org/abs/2611.34319)（v1, 2026-11-25, cs.CV） |
| **作者** | Gihyun Kwon（Amazon） |
| **核心** | **首个**面向扩散/流匹配式艺术家网格生成器的后训练方法，**不需要任何艺术家 ground truth**：模型用自己的 16 个采样 + 9 项"艺术网格奖励"打分，再通过**多负样本流匹配偏好优化**（Diffusion-DPO + RPO）把奖励直接传递给流模型 |
| **奖励设计** | 形状一致性：**轮廓 IoU**（渲染对比）+ **深度 L1**；结构：**Quad Strips (QS)**（edge loop 连续性）+ **Tessellation (TS)**（Mesh-RFT 拓扑分）；质量：**sliver 面积占比**（未合并四边形的针状三角形）+ **顶点价数**（pole / 松散角）；清洁：**微小 + 游离碎片**；预算：**面数 log 上界**（防止脱面与复制稠密输入） |
| **算法亮点** | **门控算法**：相对同组自适应阈值剔除不可信样本（CD/HD 超中位数 1.15×、翻面、微小组件、部件融合、解码失败）+ 4 条成对过滤器（保真/覆盖/面数/居中性）防止"为结构牺牲保真"。**偏好边际只用与冻结参考的差** ⇒ 只有"真正的变化"贡献梯度 |
| **结果** | **2.53 s/网格**（vs AR 基线 26.98–471.84 s）；**QS 全场最高 0.804**；**CD/HD 最低**；盲评（Claude Opus 5.5）**对全部基线胜出**，对最强的 Mesh Silksong 62.5%；奖励项之外的独立验证：Loop 细分后翻面减半（1.10→0.51%）、自交面降 56%、非流形边降 57% |
| **诚实之处** | **碎片化仍未解决**（Frag. 0.647 高于多数 AR 基线）；ECD 锐边保持落后于面数更多的基线；**RPO 项收益未被完全确立**；**第 1 轮训练用的是不含轮廓/深度项的旧版奖励**；流模型对种子敏感 |
| **结论** | ✅ **推荐实现（作为方法论）** —— 7 项几何分析可脱离生成模型，成为**独立网格质量校验器**；奖励项可作为 DiffSimp 的附加损失 |

### ⭐⭐ 2. Spe3DUp: Faithful Trajectory Distillation for Fast Image-to-3D Generation

| 项 | 内容 |
|---|---|
| **arXiv** | [2611.34141](https://arxiv.org/abs/2611.34141)（v1, 2026-11-25, cs.CV） |
| **作者** | Liangchao Xu, Jiaye Fu, Youtian Lin, Feihu Zhang, Yao Yao（南京大学 / 北京大学 / Envision） |
| **核心** | 三层加速：**① 轨迹蒸馏 FTD**（CFG 折叠 + 区间端点回归，**配对轨迹监督**：师生共享同一初始潜变量与同一条件）→ **② 跨分辨率标量场复用 + 关键区域重算** → **③ 区域并行 QEM 网格简化** |
| **动机** | 参考驱动的任务（游戏资产、产品数字化）要求生成几何**忠实复现输入指定的物体**，加速不能只保 CD/F-score 而牺牲"输入一致性" |
| **结果** | 粗/细化 DiT **10.0× / 19.9×** 加速；**端到端 576.6 s → 74.5 s（7.74×）**；粗生成 CD 15.4 vs 老师 15.3（**几乎无损**），完整级联 CD 15.2 vs 15.7（**更好**）；DMD 同条件 28.7/29.1 |
| **工程亮点** | **解码优化分解**（本文最实用的一段）：场复用 25.6→11.1 s 但引入 6.59×10⁻⁴ 偏差 → **关键区域重算** +1.2 s 把偏差**降 77%** 至 1.52×10⁻⁴。**并行 QEM：16 workers，53.2 → 7.8 s（6.83×）**，法向一致性 0.973 |
| **诚实之处** | **主动把 DMD 续训到同等预算（1,400 vs FTD 1,300 A800 GPU·h）→ DMD 完整级联 CD 反而从 29.1 恶化到 46.9**，证明差距不是训练量造成的；未报告参数量、三角形数、水密性 |
| **结论** | ⚠️ **谨慎评估（分层）** —— FTD 本身与我们相关性低，但**区域并行 QEM 强烈推荐实现**；场复用/重算谨慎评估 |

### ⭐⭐ 3. Approximate Minimum Triangle Partitions

| 项 | 内容 |
|---|---|
| **arXiv** | [2611.31146](https://arxiv.org/abs/2611.31146)（v1, 2026-11-23, **cs.CG**） |
| **作者** | Guilherme D. da Fonseca（Aix-Marseille Université, LIS） |
| **核心** | 简单多边形最小三角形剖分 $\rho(P)$（允许 Steiner 点）**是否多项式可算至今未知**，已知最好近似比是 **3**。本文**两步改进**：**① 定理 9：Steiner 点至多省一半**（$\rho_0(P) \le 2\rho(P)-2$，紧）⇒ 已有 $O(n^3)$ 算法成为 **2-近似**；**② 定理 19：5/3-近似**（$O(n^{12})$），**首个优于 3 的近似比** |
| **理论基石** | **角和恒等式**：$|T| = n - 2 - \mu + \sum_p s_p$（$\mu$ = 被吸收顶点数，$s_p$ = Steiner 点代价：内点 2 / 边界点 1）—— **"每吸收 1 个顶点省 1 个三角形，每引入 1 个 Steiner 点花 1–2 个"** 的通用记账法 |
| **紧性构造** | **风车（pinwheel）**：单个 Steiner 点每条射线吸收一个顶点 ⇒ $n = 2m$，$\rho = m$，$\rho_0 = 2m-2$。**含义：任何输出无 Steiner 点剖分的算法都不可能优于 2 倍近似** |
| **突破方法** | 保留而非删除 Steiner 点：只在"最优剖分 Steiner 点少、每个点周围三角形多"时才接近 factor-2 ⇒ 保留**位于两条顶点对直线上、且能直线连到 $P$ 顶点**的 Steiner 点（候选集 $|C| = O(n^4)$），DP 扩展为"顶点对 + 候选点"，用 Knuth 算法 ⇒ $O(n^{12})$ 时间、$O(n^8)$ 空间 |
| **附带结论** | **带洞**：$\rho_0 \le 2\rho + h - 1 \le \frac{5}{2}\rho$（$O(n^{3+2h})$），改进三角剖分的 $3+6h/n$。**覆盖（cover）负面结果**：最坏情形 $\rho/\kappa = \Theta(\alpha(n))$ ⇒ **任何剖分都无法常数因子近似允许重叠的覆盖**，覆盖的常数因子算法必须输出重叠三角形 |
| **结论** | ⚠️ **谨慎评估** —— 5/3 的 $O(n^{12})$ 不可用；但 **2-近似（$O(n^3)$，直接复用 Asano-Asano-Pinter 1986 DP）推荐实现**；**角和恒等式与风车强烈推荐作为理论参考** |
| **笔记** | [[2026-11-28-Approximate-Minimum-Triangle-Partitions]] |

## 🧭 本轮跨论文洞见

**① "网格质量"正在从"度量"变成"可优化信号"**

PostMesh 把轮廓 IoU、深度一致性、条带连续性、sliver 占比、顶点价数、碎片这些**传统的几何质量度量**重新包装成**生成模型的后训练奖励**。这三篇论文合起来指向一个趋势：**几何处理的质量指标正在被"奖励化"，从而可以端到端地优化，而不是只做事后评测**。

对我们的直接价值：这 7 项分析可以**脱离生成模型**，做成我们管线的**程序化网格质检器**。

**② 加速方法的评价标准正在变严**

Spe3DUp 做了一个我们非常认同的动作：**主动把基线续训到同等计算预算**（DMD 1,400 GPU·h vs FTD 1,300），发现基线反而退化 ⇒ 证明差距不是训练量造成的。这应当成为我们评估任何近似/加速方法时的**规范**。

**③ 理论侧的"记账"思想可迁移**

角和恒等式把"减面"精确分解为"吸收收益 − Steiner 代价"。这个**摊还式记账**（把损失归因到具体局部结构再做摊还分析）在我们的几何工具设计中是可迁移的分析范式。

**④ 一个对我们管线的直接警示**

本文明确**不假设一般位置** —— 共线顶点正是"吸收"机会的来源。⇒ **不要过早清理共线/退化结构**，它们可能是减面的机会。这与已入库的 [[2026-11-24-Periodic-BSpline-Interlacing-Knots]] 保留结构节点的思路一致。
