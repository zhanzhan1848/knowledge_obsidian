## 核心问题

大规模自由水面流体模拟中，将局部3D求解器与更廉价的2D表面模型耦合时存在**波动力学不匹配**问题：
- 传统2D波模型（SWWE、BEM、Airy等）要么是线性的，要么是非色散的
- 与强非线性3D求解器耦合时，在2D-3D接口处产生明显的反射和伪影

## 核心方法

### 非线性色散2D波模型（Zakharov formulation）

基于**典范Zakharov formulation**构建2D波模型，其中：
- 表面高程 $\eta$ 和表面势 $\psi$ 构成典范对（canonical pair）
- 由波能量控制

### 双向耦合方案（Two-Way Coupling）

 Hamiltonian 结构使2D和3D求解器之间能够**典范一致地传递信息**，使波在2D-3D界面处平滑过渡。

## 核心公式

典范对关系：
$$(\eta, \psi) \rightarrow \text{由波能量控制}$$

## 性能数据

| 指标 | 结果 |
|------|------|
| 平均波高误差 | 比 SWE/BEM/Airy 基线低 **1.7–5×** |
| BEM 加速比 | 比 BEM 快 **>10³×** |
| GPU NB-FLIP 加速 | 比纯 GPU NB-FLIP 快 **>4×** |

## 实验验证

- **色散匹配实验**（dispersion-matching）
- **Kelvin 尾迹测试**（Kelvin-wake tests）

两端耦合均成功抑制了接口处的可见接缝伪影。

## 技术亮点

1. **典范Zakharov formulation** → 保证2D/3D Hamiltonian 一致性
2. **非线性 + 色散** → 同时保留非线性效应和波的色散特性
3. **双向信息传递** → 界面处无反射、无伪影
4. **实用性** → 比纯3D模拟快4倍以上，适合大规模海洋场景
