# 核心贡献

本文提出了一种**哈密顿二维-三维耦合方法**，用于大规模自由水面模拟。该方法将局部 3D 流体求解器与更便宜的 2D 表面模型耦合，解决了传统方法中的波动力学不匹配问题。

## 创新点

1. **非线性色散 2D 波模型**：基于 Zakharov 公式的规范形式构建
2. **双向耦合**：2D 与 3D 求解器之间的信息平滑传递
3. **规范一致性**：以水面高度和表面势能作为规范对 (η, ψ)

## 技术方法

### 波模型
- **2D Solver**：比 SWE、BEM 和 Airy 基线减少平均波高误差 1.7-5 倍
- 比 BEM 快 10³ 倍以上
- 提供更大的非线性精度和耦合保真度

### 耦合系统
- 与 3D Navier-Stokes 求解器耦合
- 抑制 2D-3D 界面处的可见接缝伪影
- 比同等域上的纯 GPU NB-FLIP 模拟快 4 倍以上

### 实验验证
- 色散匹配实验
- Kelvin 船波测试
- 各种非线性场景

# 笔记

这是 SIGGRAPH Asia 2026 的论文，提出了一种创新的水面与流体耦合方法。核心价值在于通过 Hamiltonian 结构保证 2D 和 3D 求解器之间的数学一致性，从而消除界面处的视觉伪影。对于流体渲染研究者来说，这种方法在保持视觉质量的同时大幅提升性能是非常有价值的。
