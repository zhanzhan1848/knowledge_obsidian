## 核心贡献

> 提出 **MG-CD-MPM**：在 MPM（物质点法）框架上做**工具中心局部化**的连续损伤力学扩展，用统一的**逐粒子本构层**覆盖软固体、脆性材料、颗粒介质与**黏塑性/半流体介质**，并通过双向刚性工具耦合把材料阻力直接暴露给 RL 策略。

1. **局部化的损伤求解**：隐式 **Ginzburg–Landau 相场损伤系统**在**局部 patch** 上求解，用**预处理共轭梯度（PCG）+ 几何多重网格 V-cycle 预条件**加速。
2. **均匀背景离散**：背景 MPM 离散保持均匀，**仅损伤求解被局部化**——这是性能可接受的关键设计取舍。
3. **双向刚性工具耦合**：把 MPM 接触冲量转换为工具上的**力与力矩**，使策略能**直接感知材料阻力**。
4. **统一逐粒子本构层**：一个 Gym 风格模拟器同时覆盖**软固体、脆性材料、颗粒介质、黏塑性/半流体介质**。
5. **任务演示**：6 个场景中的切割/舀取/铲取，结合脚本化工具运动与在两个切割任务上训练的 **PPO 策略**。

## 技术方案

### 核心思想

多状态材料（会经历大变形、拓扑改变、工具-材料双向接触）的模拟需要同时满足三件事：**拓扑改变能力**、**双向接触**、**足够快以驱动在线 RL**。传统 FEM 难以满足速度要求，MPM 天然适合大变形与拓扑改变，但缺少损伤/塑性本构。

本文的切入点是**局部化**：完整的相场损伤求解太贵，因此只在**工具附近的局部 patch** 上做精细损伤求解，背景保持均匀离散。这是一种"**在需要的地方精确，在别处便宜**"的工程折中。

### 关键技术

| 技术 | 说明 |
|------|------|
| **CD-MPM（连续损伤 MPM）** | 物质点法 + 连续损伤力学的结合基座 |
| **Ginzburg–Landau 相场损伤** | 用序参量场描述损伤的弥散化，避免显式裂纹面 |
| **局部 patch 损伤求解** | 仅在工具周围求解损伤方程，背景 MPM 离散保持均匀 |
| **几何多重网格 V-cycle 预条件** | 作为 PCG 的预条件子，加速隐式相场方程求解 |
| **双向刚性工具耦合** | MPM 接触冲量 → 工具的力/力矩，闭合力学回路 |
| **统一逐粒子本构层** | 软固体 / 脆性 / 颗粒 / 黏塑性（半流体）由同一粒子级本构切换 |
| **Gym 风格接口** | 可直接接 PPO 等 RL 算法在线训练 |

## 实验结论

- **数据集 / 算例**：6 个场景（切割 cutting、舀取 scooping、铲取 shoveling）；两个切割任务上训练 PPO 策略。
- **基线**：CD-MPM（本文为其局部化扩展 MG-CD-MPM）。
- **结果**：
  - 局部化损伤求解 + 多重网格预条件 → **速度足以驱动在线 RL** ✅
  - 双向耦合让策略**能感知材料阻力**（切割力反馈）✅
  - 统一本构层覆盖四类介质 ✅
  - 脚本化工具运动 + PPO 学习任务耦合成功 ✅

## 局限性

- 面向**机器人操作**与 RL，非渲染。
- 局部 patch 的**边界条件处理**与工具快速移动时的失效细节未见详述。
- 逐粒子本构层的切换逻辑与参数标定需查代码。

## 与流体渲染的关系 ⭐⭐⭐

1. **"半流体介质"是流体渲染的近邻**：黏塑性/半流体介质在**效果制作**中常被当作"介于固体与流体之间"的特例处理（糖浆、胶状物、奶油、沥青）。本文的逐粒子本构层提供了**可直接参考的本构模型与切换策略**——这些正是本库多篇工作（[[2026-10-25-Divisor-Dynamics-Surface-Fluid]] 的表面流体、[[2026-10-29-Colour-Field-Particle-Categorization-Solid-SPH]] 的 SPH 固体分类）触及但未解决的边界地带。
2. **粒子级本构统一的思路**：[[2026-10-29-Colour-Field-Particle-Categorization-Solid-SPH]] 用**颜色场**在 SPH 粒子间区分固体/流体；本文则用**逐粒子本构层**统一多介质。二者思路可对照——前者是**空间分区**，后者是**参数化统一**，后者更容易实现连续过渡（粘-弹性、剪切变稀）。
3. **局部化求解的性能策略**：对渲染而言，"**只在视线/交互焦点处精确**"的思路与渲染本身的 LOD 哲学同源——可用于**流体模拟的局部高精度（如飞溅区、撞击区）**。
4. **PBD/MPM 混合路线参考**：[[2026-10-19-Make-It-Flow-Water-Animation-3DGS]] 走的是"免物理模拟"路线，本篇则展示了"**物理模拟 + RL 优化动作**"的另一极端——对自动探索流体表现（如"如何让火焰更有爆发力"）有启发。

## 实现建议

- **实现难度**：🔴 高（MPM + 相场损伤 + 几何多重网格 + 双向接触耦合）
- **预期性能**：局部化 + 多重网格预条件后达到"可在线 RL"的实时性量级（具体帧率未在摘要中给出）
- **适用场景**：
  - ✅ 黏塑性/半流体介质的**本构模型参考**
  - ✅ 多介质统一粒子框架的设计参考
  - ✅ 局部高精度求解策略（渲染 LOD 哲学）
  - ⚠️ 直接用于渲染（RL 训练成本高）
