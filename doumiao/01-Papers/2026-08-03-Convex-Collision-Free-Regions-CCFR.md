# Convex Collision-Free Regions (CCFR)

**日期**: 2026-08-03
**arXiv**: [2607.26901](https://arxiv.org/abs/2607.26901)
**关键词**: 碰撞处理, 粒子系统, XPBD, 布料模拟, 头发模拟

---

## 📌 核心创新点

CCFR 是一种碰撞处理方法，通过**显式表示局部凸可行区域**来强制执行非穿透约束。与现有方法不同，本方法：

1. **次级碰撞和余维接触** - 天然支持
2. **独立于物理响应模型** - 几何约束与物理响应解耦
3. **兼容 XPBD** - 无需 Hessian 评估或刚度调参
4. **高度并行化** - 每顶点独立处理

---

## 🔬 技术细节

### 可行域定义

对于每顶点 v，其可行域 K 定义为所有半空间的交集：

```
K = ⋂_{c∈C} { x' | g_c(x') ≥ 0 }
g_c(x') = n_c^⊤ x' - b_c
```

其中每个约束定义一个半空间，表示与其他图元的非穿透条件。

### 碰撞处理三阶段

1. **定义局部凸可行域** - 编码非穿透约束
2. **基于投影的更新强制执行可行性** - 投影到凸区域边界
3. **XPBD 内的排斥和摩擦响应** - 物理响应独立处理

### 投影算法

采用 Plesník (2007) 的代数投影方法：
- 增量构建活动超平面跨度的仿射子空间
- 确保先前满足的约束保持满足
- 有限步收敛，有效抑制振荡行为

### 与其他方法对比

| 方法 | 特点 |
|------|------|
| IPC | CCD 感知线搜索，保守更新 |
| OGC | 距离信任域，可能过度限制 |
| CCFR | 局部凸可行域，自适应位移限制 |

## 🎯 应用场景

1. **布料自碰撞** - 复杂褶皱和自交
2. **头发模拟** - 线状结构碰撞
3. **线缆模拟** - 细长物体
4. **粒子系统** - 大规模粒子碰撞
5. **余维接触** - 点边接触、面边接触
