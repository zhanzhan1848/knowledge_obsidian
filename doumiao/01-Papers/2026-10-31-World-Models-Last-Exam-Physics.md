## 核心贡献

> 提出一个**基于测量**（而非参考视频/模型判断）的物理一致性基准，覆盖 40 项受控任务、7 大物理域（含**流体**与**表面张力**），用于检验视频世界模型的物理正确性——8 个视频生成模型在 1280 个视频上的最佳成绩仅为 **57.76/100**。

1. **测量式评测范式**：每项任务配**初始图像 + 生成提示词 + 预定义物理判据**，从而可**解释地测试可观测物理关系**，**不需要参考视频**。
2. **双层评估器**：结合**任务可观测性筛查**（task-observability screening）与**任务特定定量物理测量**。
3. **广泛物理域覆盖**：力学、光学、**流体**、热与相变、电磁、**表面张力**等。
4. **人体一致性验证**：与直接视觉-语言模型基线相比，评估器在**任务内排序**与**成对比较**上均取得更高的人类判断一致性。

## 技术方案

### 核心思想

现有视频世界模型评测的三大缺陷：
- 依赖**模型判断**（另一个 LLM 打分）→ 主观且循环
- 依赖**参考视频**（需要真实拍摄）→ 成本高、覆盖有限
- 只测**力学**（抛物线、碰撞）→ 物理盲区大

本文的替代方案：**给定初始状态与生成提示，从生成视频中直接测量物理量是否守恒**。

```
初始图像 + 提示词 → 视频世界模型 → 生成视频
                                 ↓
              ① 任务可观测性筛查（该物理量在视频中可测吗？）
                                 ↓
              ② 任务特定定量物理测量（守恒律/比例关系是否成立？）
                                 ↓
                        可解释的物理一致性评分
```

> 💡 **为什么这对流体渲染重要**：流体是**难以用参考视频判定对错**的典型对象——同一个"烟雾上升"可以有很多正确形态。**基于守恒律/比例关系的判据**（如体积守恒、扩散宽度 $\propto \sqrt{t}$、浮力加速度 $\propto g$、表面张力的平衡形状）恰好能给流体提供**无需参考**的正确性锚点。

### 关键技术

| 技术 | 说明 |
|------|------|
| **基于测量的判据** | 每任务预定义物理关系 → 可解释、可审计 |
| **任务可观测性筛查** | 过滤掉"物理量在生成视频里根本不可观测"的无效评分 |
| **任务特定定量测量** | 针对每任务设计物理量提取与判据 |
| **7 大物理域 40 任务** | 含流体、表面张力、热与相变 |
| **人体一致性评估** | 验证测量模块比 VLM 直接打分更可信 |
| **合成视频对照实验** | 已知真实物理关系 → 验证测量模块本身的有效性 |

## 公式

**可观测性筛查**（示意）：

```math
\mathcal{O}(\tau) = \mathbb{1}\!\left[\text{物理量 } q_\tau \text{ 可从视频像素中被测量}\right]
```

**流体类任务的典型判据**：

```math
\text{扩散宽度：}\quad \sigma(t) \propto \sqrt{D\,t}
\qquad
\text{浮力：}\quad a_z \propto g\frac{\Delta \rho}{\rho}
\qquad
\text{体积守恒：}\quad V(t) = V_0 \quad (\text{密闭容器})
```

**总体评分**：

```math
S_{\text{overall}} = \frac{1}{|\mathcal{T}|}\sum_{\tau \in \mathcal{T}} \mathcal{O}(\tau)\cdot s_\tau
\]

## 实验结论

- **规模**：40 项受控任务；8 个视频生成模型；**1280 个生成视频**。
- **主结果**：存在**持续性的物理不一致**，且跨任务差异显著；最佳模型总体得分 **57.76 / 100**。
- **验证**：在已知物理关系的**合成视频**上，测量模块的行为符合预期 → 证明测量模块本身有效（不只是噪声）。
- **人类一致性**：与人类判断的一致性**高于直接 VLM 基线**（任务内排序 + 成对比较两种方式均成立）。

---

## 局限性

- 40 项任务**覆盖面有限**，不可能覆盖全部流体现象。
- 测量法**依赖物理量能从视频中被提取** → 许多真实流体效应（如复杂涡旋结构、破碎飞沫）难以定量测量，任务可观测性筛查会将其排除。
- 单次生成、无多次采样平均 → 无法区分"偶发"与"系统性"错误。
- 与人类判断的一致性是**相对提升**，绝对一致性未量化到很高水平。
