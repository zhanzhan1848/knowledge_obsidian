## 核心贡献

> 证明**带常涡量的二维周期重力-毛细水波**在**自由面局部施加压力反馈**下可**指数稳定**——为"如何用少量外部作用把水面平静下来"提供了严格的理论保证。

1. **指数稳定结果**：二维周期、有限深度、带常涡量的重力-毛细水波，使用**定位于自由面上的外部压力**可实现指数衰减。
2. **控制律形式**：压力 = **非负截断函数（cut-off）× 表面高度的时间导数** $\partial_t \eta$ —— 形式简洁，可直接实现。
3. **证明工具**：能量耗散恒等式 + 乘子法（multiplier method）+ **周期 Pohozaev 恒等式**；由**线性化方程的唯一延拓性**（unique continuation）+ 紧性论证消除涡量带来的低阶项。
4. **不需要**解的偶对称性，也不假设涡量小。

## 技术方案

### 核心思想

**问题**：水面的涡量（背景流旋转）会持续注入波动，使水面难以平息。

**控制机制**：在自由面上施加一个**空间定域的压力反馈**

$$
p(t) = \chi(\mathbf{x}) \cdot \partial_t \eta(\mathbf{x}, t),
\qquad \chi \ge 0 \text{ 非负截断函数}
$$

$\partial_t\eta$ 是表面高度的时间导数（自由面速度）。这构成一个**反馈控制器**：表面在动 → 施加压力 → 抑制运动。

**条件**：截断函数 $\chi$ 与重力 $g$、表面张力 $\sigma$ 需满足一个关系条件。

### 关键技术

| 技术 | 说明 |
|------|------|
| **能量耗散恒等式** | 建立相对于**平坦 Couette 流**的能量耗散关系 |
| **乘子法（Multiplier Method）** | 处理涡量带来的低阶项 |
| **周期 Pohozaev 恒等式** | 获得加权能量泛函 |
| **唯一延拓性（Unique Continuation）** | 线性化方程的唯一延拓性质 → 紧性论证消除低阶项 |
| **时间加权各向异性能量泛函层级** | 去除 $s\to1$ 时需加权泛函的限制 |

### 衰减结论

在解于 Sobolev 范数下保持一致小的区间上，**相对于平坦 Couette 流的相对能量指数衰减**。

## 渲染价值分析（豆苗视角）

### 🩸 可行性分析：让水面"静下来"的一行公式

**这是一篇纯理论论文，但它给出了一个极其简单、可直接落地的水面稳定控制器。**

### 三个具体的渲染影响

1. **"水面平静下来"是高频渲染需求**：
   - 角色走到湖边/船靠岸 → 需要水面从扰动平滑到平静
   - 特效"时间冻结/时间倒流"过渡 → 需要水面**可逆地**趋于平静
   - 场景切换（切到室内）→ 需要水面**快速静下来**
   - 大型水面（游戏/影视）→ 需要**全局耗散**而非逐点衰减

2. **控制律的形式极其适合 GPU**：
   - $\partial_t\eta$ = **自由面高度的时间导数** → 渲染管线里通常已有（前一帧与当前帧的高度差）
   - $\chi$ = **非负截断函数** → 空间定域遮罩（GPU 上就是一个纹理）
   - **压力** → 施加到自由面动力学方程 → 在 VOF/level-set 求解器里就是给自由面加一个法向压力项
   → **落地成本极低**：一个额外的纹理乘积 + 一个投影步的修正项。

3. **"涡量是水面不平静的根源"这一结论**：
   论文的核心即是**常涡量背景流**如何阻碍稳定。→ 对渲染的提示：
   - 若场景里有**背景涡/旋转流**（旋涡特效、涡流场、旋转水面），**单纯加粘性阻尼是不够的**，因为涡量会持续供能
   - 需要的是**定域的、与表面运动耦合的反馈**，而非全局阻尼
   → **实操**：水面反馈项的作用范围 $\chi$ 应与**局部涡量尺度**匹配——在涡量强的地方给更强的反馈

### 适用场景表

| 场景 | 适用性 |
|------|--------|
| 湖面/海面静置 | ✅ 极佳 |
| 泳池/水池涟漪衰减 | ✅ 极佳（有界域，$\chi$ 可取全域） |
| 船/浮体尾迹消散 | ✅ 好 |
| 火焰/烟雾扰动消散 | ⚠️ 需推广（毛细-重力 → 火焰-浮力对） |
| 涡旋特效（要保留涡量） | ❌ 不适用（会破坏涡） |

### 实现建议

- **着色器复杂度**：**低**（一次纹理乘积）
- **管线要求**：需要自由面高度的时间历史（通常已有）+ 压力投影支持外加压力源
- **推荐度**：✅ 推荐（低成本高收益，**尤其适合实时游戏水面**）

### 落地配方

```
# 每个时间步，在自由面动力学中加入压力源：
p_ext = chi_mask * d_eta_dt        # chi_mask ≥ 0，空间定域
# 在 VOF/level-set 投影步中，把 p_ext 加入压力方程 RHS
# 注意：chi 的支撑尺度应 ≥ 局部涡量尺度，否则反馈不足
# 注意：不要加到需要保留涡结构的区域
```

## 局限性

- **纯理论**，无实现、无性能数据、无可视化。
- 假设**常涡量**（真实场景涡量随时间变化）。
- 二维、周期、有限深度——不直接覆盖 3D 开放域。
- 指数衰减的**收敛条件依赖 Sobolev 范数一致小** → 实际应用中可能需要分段/渐进施加。
- 需**自由面动力学方程的适定性**保证。
