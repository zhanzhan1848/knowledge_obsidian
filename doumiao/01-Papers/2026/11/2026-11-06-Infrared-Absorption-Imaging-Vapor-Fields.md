## 核心贡献

> **建立了一种"红外吸收成像"方法，把宽带中红外衰减定量转换为**蒸气摩尔分数场**，从而在**蒸发流动**中实现**全场、无示踪剂**的浓度测量。标定后的物面采样达到 **30.5 μm/pixel**。

1. **测量原理**：宽带中红外衰减 → 用**光谱加权吸收系数**转换为摩尔分数。
2. **受控基准**：垂直放置的 **Hele-Shaw 池**提供近似**一维**的蒸发基准。
3. **一维化验证**：测得二维场先确认**中心区域横向浓度变化很小** → 支撑把二维场降为轴向浓度剖面。
4. **严格对照**：用**规范 Stefan 蒸发问题**作为场级基准。
   - 5 条剖面（不同保留气相区间长度）× 3 种烃类液体
   - **只用测得的区间长度与端点浓度**去对照，**不拟合内部浓度数据**（避免循环论证）
5. **结果**：
   - **n-pentane**（较高蒸气负载）：分辨出**非线性 Stefan 浓度剖面**，可与线性扩散极限区分
   - **n-hexane / n-heptane**（较低负载）：剖面**逐步趋近**稀薄极限
   - 归一化 RMS 偏差 **0.0055–0.0185**
   - 经**对数 Stefan 变换**后，全部剖面**塌缩到预测的恒等关系**上

## 技术方案

### 测量链条

```
宽带中红外辐射衰减（成像）
  → 光谱加权吸收系数 α̃(ν)
  → 蒸气摩尔分数场 x(y)
  → 轴向剖面
  → 对数 Stefan 变换
  → 与解析预测的恒等关系对照
```

### 关键模型

| 概念 | 内容 |
|------|------|
| **Stefan 传输** | 蒸发界面的非线性浓度剖面（高负载时的正确描述） |
| **线性扩散极限** | 低负载时的稀薄极限（可分离线性扩散） |
| **对数 Stefan 变换** | 把非线性剖面映射到线性恒等关系——**这是数据塌缩的关键** |

### 标定与验证

- **吸收系数标定**：光谱加权吸收系数的独立标定
- **一维近似验证**：横向浓度变化量级评估
- **对照 Stefan 传输**：仅用区间长度与端点浓度，不拟合内部 → **结论可信**

## 渲染价值分析（豆苗视角）

### 🩸 可行性分析：蒸气/烟雾密度的"定量标定"方法论

**这篇论文表面上是实验测量学，但它给渲染提供了一件很稀缺的东西：一个把"看不见的浓度场"变成"可定量、可验证的标定目标"的方法。**

### 三个具体的渲染影响

1. **给烟雾/蒸气渲染一个"物理可信"的标定基准**：
   - 渲染中，**蒸气/烟雾密度场的定量正确性几乎从未被验证**——大家都靠眼睛调。
   - 本文提供了一个**有解析解（Stefan 传输）可对照的浓度场基准**，并给出了**量化的偏差指标**（RMS 0.0055–0.0185）。
   - → **落地建议**：在我们的蒸气渲染管线上建一个"Stefan 蒸发"测试场景，量化密度场误差。这类似 [[2026-11-06-Certified-Neural-Water-Waves-Lean-Verification]] 给海面做的校准——**方法论同构**。
   - **价值**：让"烟雾看起来对不对"从主观变成可回归测试。

2. **"对数 Stefan 变换"→ 烟雾密度的正确可视化/着色方式**：
   - 本文发现：非线性 Stefan 剖面经**对数变换**后才塌缩到线性恒等关系。
   - → 这暗示：**蒸气浓度在对数空间才有线性结构**。在着色/可视化时，对数域的等值线比线性域更均匀。
   - → **落地建议**：烟雾/蒸气的密度场可视化、等值面提取、或用于合成密度纹理的噪声采样，**在 log 域做**更均匀、不易出现"低浓度区全糊成一片"。这是一个具体的、有依据的调参建议。
   - 同时，低负载趋近线性极限 → **小尺度蒸气近似可以用简单扩散模型**，不必上复杂求解器。

3. **"低负载 → 线性扩散极限"的分层建模策略**：
   - → **落地建议（架构层面）**：**分级求解**——
     - 稀疏/微弱的蒸气（低负载）→ **解析/线性扩散近似**（极快）
     - 密集的蒸气（高负载）→ 完整非线性求解
   - 这直接对应渲染里的"**LOD 分级**"：远处/淡薄的烟用便宜的近似，近处/浓烟用完整模拟。
   - **本文给了这个分级的物理依据**，而不只是工程直觉。

4. **"横向均匀性"→ 1D 降维的适用判据**：
   - 本文通过实验确认：在某条件下，二维浓度场可以安全降为一维剖面。
   - → **落地建议**：这是一个**可复用的诊断工具**——若实测的烟羽横向梯度足够小，就可以用 1D 模型驱动整个截面，**大幅降本**。
   - → 把它做成"**投影/降维决策工具**"：先测横向不均匀度，再决定 1D/2D/3D 求解。

### 实现建议

- **着色器复杂度**：低到中（取决于密度场求解层级）
- **管线要求**：
  - **纯方法论**：不需要实装论文的测量系统
  - 需要的是：**把 Stefan 基准场景加入回归测试** + **在 log 域做密度场可视化** + **按负载分级选择求解器**
- **推荐度**：✅ **推荐（作为标定方法论与可视化调参依据）**；⚠️ 实装 IR 成像系统本身对渲染无意义

### 渐进式落地路径

| 阶段 | 做法 | 收益 |
|------|------|------|
| **1. log 域可视化/采样** | 密度场在 log 域做等值线/纹理采样 | 中，立即可用，改善低浓度区表现 |
| **2. Stefan 基准回归测试** | 建立密度场误差测试 | 中高，质量保障 |
| **3. 分级求解** | 低负载走解析扩散近似 | **高**，性能收益直接 |
| **4. 横向均匀度诊断** | 决定 1D/2D 降维 | 中高，降本 |

## 实验结论

| 项 | 结果 |
|------|------|
| 物面采样 | 标定后 **30.5 μm/pixel** |
| n-pentane（高负载） | 分辨出**非线性 Stefan 剖面**，与线性扩散极限可区分 |
| n-hexane / n-heptane（低负载） | 逐步趋近**稀薄线性极限** |
| 与 Stefan 预测的一致性 | 归一化 RMS 偏差 **0.0055–0.0185** |
| 对数 Stefan 变换后 | 全部剖面**塌缩到恒等关系** |

## 局限性

- **一维近似**（Hele-Shaw 池），只验证了轴向剖面。
- **三种烃类液体**（n-pentane / n-hexane / n-heptane），未覆盖水或酒精。
- **实验测量学论文**，无渲染实现、无 GPU 相关内容。
- 标定依赖特定的光谱加权吸收系数。
