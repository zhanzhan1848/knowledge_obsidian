## 核心贡献

> 为**海上升力塔 / 平台立柱**这类穿水圆柱提供**高效非线性时域波浪绕射求解器**——用**伪谱（pseudo-spectrum）+ Fredholm 第二型积分方程 + Legendre 多项式**。

1. **高非线性时域数值伪谱模型**，基于**势流理论（potential flow）**。
2. **高效求解器**：利用 **Fredholm 第二型积分方程**与 **Legendre 多项式**，高效计算**圆柱表面速度势**与**自由面竖直速度**。
3. **验证**：与基于**傅里叶变换的直接方法**及**小陡度均匀波散射的既有理论模型**对比验证。
4. **收敛性与计算效率**均已展示。
5. **Part II**（预告）：高非线性瞬态水波的模型验证。

## 技术方案

### 核心思想

**场景**：海上风电单桩（monopile）风机、海洋平台立柱遭遇**极端海浪**（steepness 极高的非线性波）时的**波浪载荷**计算。

**为什么需要新方法**：
- 线性势流理论（Bessel 展开）只在**小陡度**下有效。
- 高陡度（steepness $\to$ 1，接近破碎）时自由面高度非线性，必须用**时域势流 + 边界元/谱方法**。
- 既有方法计算昂贵 → 难以做**大规模集合预报**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **时域伪谱法（pseudo-spectrum）** | 水平方向（切向）用傅里叶谱、竖直方向（径向）用 Chebyshev 配点 → 处理大变形自由面 |
| **势流理论** | 无粘、不可压、边界条件：固壁法向速度为零 + 自由面运动学/动力学条件 |
| **Fredholm 第二型积分方程** | 圆柱表面速度势的求解框架 |
| **Legendre 多项式展开** | 圆柱面（圆柱坐标）上的角度方向展开，**收敛快**（相比 Chebyshev 在极点） |
| **通量—竖直速度分离输出** | 直接给出圆柱面通量与自由面竖直速度（用于载荷与自由面渲染） |

### 圆柱绕射的两套公式

| 理论 | 适用范围 | 方法 |
|------|---------|------|
| **线性势流（Bessel / Hӧfer）** | 小陡度波、线性化自由面 | 傅里叶级数 + 圆柱面本征函数 |
| **非线性时域伪谱（本文）** | 高陡度、瞬态、有限振幅 | Legendre 展开 + 伪谱配点 + 时间推进 |

## 渲染价值分析（豆苗视角）

### 🩸 可行性分析：海洋/港口场景的"可信水面交互"

**这篇论文属于"工程 → 渲染"的逆向输入类型**：它不解决渲染问题，但**定义了海洋场景里水-结构交互的物理真相**，而这正是实时海洋渲染最难"骗人"的部分。

### 三个具体的渲染影响

1. **穿水柱体/立柱的"水痕带"（waterline / run-up band）**：
   论文直接输出**圆柱表面通量**——这正是渲染"**立柱表面被水打湿的高度范围**"和"**沿柱面下泄的水流（run-down streak）**"所需的物理量。
   → **实用建议**：实时海洋渲染中，立柱水痕带的高度与随时间变化应由**通量积分**决定，而不是美术手 K 一条贴图。高陡度波下，水痕带可远超平均海平面——静态贴图必然穿帮。

2. **"柱子把浪劈开"的高频细节应来自哪**：
   论文验证的高非线性绕射场（伪谱）包含圆柱前的**驻波增强 + 沿柱面的加速流 + 分离后的横向涡**。
   → 对渲染的直接含义：**柱体两侧的水面应该更快、更陡、方向偏转**。若用纯 Gerstner 波叠加而无绕射场，立柱附近的水会显得"死板"。

3. **"透空"立柱（open-top / hollow column）的漏涡**：
   穿水圆柱若为**中空/透空**结构（海上风电基础常见），水体从内部**向上涌出形成涡系**——这是渲染中非常常见但难以做对的特效。可用本文框架（内部自由面 + 环形边界条件）扩展。

### 实现建议

- **着色器复杂度**：高（需时域伪谱求解器 + 谱→网格重采样）
- **管线要求**：实时渲染中**不可能跑完整伪谱求解器**（Part I 的目标是工程载荷计算，通常离线/准实时）。**建议路径**：
  1. 用本文求解器**离线预计算**一组典型场景（波高、波向、入射谱）的**局部绕射场修正量**
  2. 实时渲染时用**低成本近似**：柱前波面抬升 + 柱面加速带 + 横向涡（预烘焙的涡图案）
  3. 实时用 Gerstner/FFT 海面 + 局部绕射贴图叠加
- **推荐度**：⚠️ **作为离线参考与"真值"来源**，非实时算法

### 可落地建议

| 交付物 | 说明 |
|--------|------|
| **柱前水面抬升场** | 预烘焙到局部网格，作为 Gerstner 波的局部修正 |
| **水痕带高度历史** | 通量积分随时间的曲线 → 驱动材质湿润度 |
| **分离涡图案** | 横向涡的位置/强度时间序列 → 驱动粒子/烟雾 |

## 局限性

- **Part I 仅为公式与验证**，高非线性场景的实际结果在 Part II（尚未见）。
- 势流理论：**忽略粘性、破碎、气泡、浪花飞沫**——而这些恰恰是渲染最需要的视觉元素。
- 圆柱假设（单柱、垂直、无运动）——不覆盖运动平台、船体升沉。
- 未涉及频谱（真实不规则波）与 CFD 的耦合。
