## 核心贡献

> **在 Cahn–Hilliard–Navier–Stokes (CHNS) 方程中引入一个"宇称奇"的毛细应力（parity-odd capillary stress）**，它产生**垂直于常规毛细力的界面切向力**，且**不做功守恒平衡**（不做变分、非变分式）。

1. **破缺宇称对称性的界面力学响应**——不同于已有的**奇粘度（odd viscosity，手性流体）**和**奇弹性（odd elasticity）**。
2. **切向力偶极（tangential force-dipole）结构**：对于平行于 x 轴的平面界面 $\phi=\phi_0(y)$，$\epsilon_{xy}=1$ 时：

$$\bm{\Sigma}^{\rm odd}=\frac{3}{2}\widetilde{\sigma}\,\varepsilon\,[\phi_0'(y)]^2\begin{pmatrix}0&1\\1&0\end{pmatrix}$$

其散度给出**纯切向力密度**（无 $y$ 分量）：
$$f_x^{\rm odd}=\frac{3}{2}\widetilde{\sigma}\,\varepsilon\,\frac{d}{dy}[\phi_0'(y)]^2$$

对平衡扩散界面剖面 $\phi_0(y)=\tanh[y/(2\varepsilon)]$：
$$f_x^{\rm odd}(y)=-\frac{3\widetilde{\sigma}}{4\varepsilon^2}\operatorname{sech}^4\!\left(\frac{y}{2\varepsilon}\right)\tanh\!\left(\frac{y}{2\varepsilon}\right)$$

**关键性质**：力密度**关于界面反对称**，**零阶矩消失，但一阶法向矩有限** → 这是"力偶极"而非"体力"的数学确证。

3. **三项 DNS 发现**：
   - **① 域粗化（coarsening）停滞**：$\chi=\widetilde{\sigma}/\sigma$ 越大，粗化越慢；$\chi=2,4,10$ 出现**粗化停滞**，停滞长度随 $\chi$ 减小。
   - **② 维持湍流但无常规惯性级联**：能量注入主要由粘性耗散平衡（**没有传统惯性能量级联**）。
   - **③ 动力学停滞的乳液**：非对称混合物中，奇毛细驱动的变形与破碎**中断液滴增长**，产生**成分超均匀（composition hyperuniformity）** + **大尺度涡量涨落被抑制**。

4. **与变分关系的决裂**：奇应力做功**不被二元流体自由能变化平衡** → 本质上是一个非变分耦合。

### 数值设置

- **二维周期方形域** $2\pi$，**1024²** 配点
- **傅里叶伪谱法** + **指数时间差分（ETD）**
- 初始：近均匀混合物 $\phi(\bm{x},0)=\phi_0+\delta\phi(\bm{x})$

## 渲染价值分析（豆苗视角）

### 🩸 可行性分析：给液体一个"可控的界面张力梯度"

**这篇论文给渲染器提供了一件此前不存在的工具：一个可调的、破坏宇称性的界面切向应力。它能直接驱动界面沿特定方向流动——这是制造"流动的、拉伸的、方向性的液体表面"的物理手段。**

### 三个具体的渲染影响

1. **"界面自己会流" → 方向性表面张力**：
   - 常规毛细力垂直于界面，只会让界面**变平**。
   - 奇毛细力**沿界面** → 界面会**主动沿着自己的方向流动**。
   - → **渲染价值**：可以做"熔岩表面向一个方向流淌"、"油膜自发向一侧聚拢"、"水面上的油污顺流迁移"——**这些在常规流体渲染里非常难做**（通常要用粒子/贴图作弊）。
   - **落地建议**：在已有的 VOF / level-set / FLIP 求解器里，加一项形如 $\nabla\cdot(\bm{\Sigma}^{\rm odd})$ 的源项。**这是一项局部改动**（只影响界面梯度平方大的区域），不是重写求解器。

2. **粗化停滞 → 可控的"纹理冻结"**：
   - 普通 CHNS/相分离模型中，两相会**粗化**（小球变大、大球变小）→ 液滴数量越来越少，形态越来越简单。
   - 奇毛细**让粗化停滞** → **液滴尺寸和数量可以被冻结在任意时刻**。
   - → **渲染价值极高**：美术想要的"一滩固定的油污 / 特定的斑点图案 / 冻结的破碎纹理"，用奇毛细就能**保持住**，而不是几秒后自动演化没了。
   - **落地建议**：给 CHNS 类求解器加 $\widetilde{\sigma}$ 参数，用一个滑条控制"图案保持时长"。

3. **"无级联的湍流" → 可控的持续翻腾**：
   - 奇毛细能**维持湍流运动，但没有传统惯性级联**（能量注入被粘性耗散平衡）。
   - → 这是一种**"有结构的、持续的翻涌"**：不像常规湍流那样级联到小尺度碎掉，而是停留在某个尺度上翻腾。
   - → **渲染价值**：非常适合"油、水、颜料在容器里被持续搅拌但不会碎成泡沫"的场景；也适合做"熔岩/岩浆表面持续涌动但不飞溅"的质感。
   - 同时：湍流由界面应力维持 → **不需要外部力场**（不需要风场/搅拌器）。

4. **成分超均匀 → 可控的"均匀质感"**：
   - 超均匀态（hyperuniformity）意味着**没有特征尺度的均质分布**——看起来像"完全均匀的颗粒感"。
   - → 可用于做"细腻无特征的介质外观"（如浓雾/膏体），避免"看得见颗粒大小"的廉价感。

### 实现建议

- **着色器复杂度**：中（新增一个应力张量项 + 一个散度）
- **管线要求**：
  - **求解器侧**：需要**成分场 $\phi$ + 化学势 $\mu$ + 速度 $\mathbf{u}$** 三场耦合（标准 CHNS 框架）
  - 新增：$\chi = \widetilde{\sigma}/\sigma$ 一个标量参数
  - **渲染侧**：**零改动**——奇毛细只改变流体的运动，密度场/温度场照常输出
  - **可以后处理式集成**：即使不做完整 CHNS，也可以只加切向力项到已有的两相流求解器
- **推荐度**：✅ **推荐（中等工程量，高创意回报）**；⚠️ 若项目不需要方向性界面张力则不必做

### 渐进式落地路径

| 阶段 | 做法 | 收益 |
|------|------|------|
| **1. 概念验证（着色器级）** | 在现有两相流里加切向力项 $\propto \nabla[\phi_0']^2$，手工实现（不必严格按论文） | **高**，可以快速看到"界面自己流"的效果 |
| **2. 完整 CHNS + 奇毛细** | 按论文方程实现，含粗化停滞 | 高 |
| **3. 参数化调优** | $\chi$ 作为美术可调参数 | 中高，控制力提升 |
| **4. 超均匀/乳液分析** | 统计量作为质量指标 | 低 |

> ⭐ **强烈建议从阶段 1 开始**：用简化形式（甚至手工近似）加一个切向力源项，就能在现有流体管线里得到"流体会自发定向流动"的独特质感。改动量小，视觉独特性强。

## 实验结论

| 现象 | 结果 |
|------|------|
| **域粗化** | $\chi=0$ 时 $L(t)\sim t$（线性粗化）；$\chi$ 增大 → 粗化受抑；$\chi=2,4,10$ **粗化停滞**，停滞长度随 $\chi$ 递减 |
| **湍流性质** | 维持湍流运动但**无常规惯性级联**，能量注入主要由粘性耗散平衡 |
| **乳液动力学** | 非对称混合物中奇毛细驱动变形与破碎**中断液滴增长** → **动力学停滞乳液** + 成分超均匀 + 大尺度涡量涨落被抑制 |

## 局限性

- **二维**（2D 二元流体），未做 3D。
- **模型极简**：只加了应力项，其余是标准 CHNS。
- **宇称破坏是人工引入的**：不是从更基本的理论推导出来的 → 属于"演示一种机制"，非"解释某种真实材料"。
- **未讨论渲染/图形应用**。
