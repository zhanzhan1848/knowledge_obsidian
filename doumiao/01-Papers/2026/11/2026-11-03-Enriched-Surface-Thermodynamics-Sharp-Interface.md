## 核心贡献

> **给锐界面流体模型（VOF / level-set / SPH 界面）补上"界面热力学"**：让界面不仅承载几何，还能承载**成分表面质量密度**与**厚度描述符**，从而保留未解析的流体过渡区里的材料与结构信息。

1. **局部热力学框架**：各向同性界面可携带**成分表面质量密度** + **厚度描述符**。
2. **关键区分**：**加性成分的密度**（additive contents 的密度）vs **内部描述符**（internal descriptors）→ 决定**面积共轭量**（area conjugate）、**可逆表面应力**、**Gibbs–Duhem 关系**。
3. **厚度有压力型共轭量**：单位面积体积（volume-per-area thickness）具有**类压力共轭量**、**机械功贡献**、以及**独立的演化方程**。
4. **三种厚度需不同运动学**：**独立（independent）**、**受约束（constrained）**、**快速平衡（rapidly equilibrating）** 的厚度对应**不同的运动学与降阶形式**。
5. **材料存储可不带表面惯性**：material storage can be retained without retaining surface inertia。
6. **移动面片（moving surface patch）的可用自由能恒等式**（available-free-energy identity）给出机械功的完整记账。

## 技术方案

### 核心思想

**现状问题**：锐界面方法（VOF / level-set / MPM 界面）把界面当作**纯几何对象**（一个等值面）→ **丢弃了过渡区的全部物理信息**：
- 界面厚度的分布（决定泡沫/飞沫的生成）
- 各成分在界面上的富集（如表面活性剂的富集、污染物聚集）
- 界面的"材料记忆"

**本文框架**：把界面升级为**携带状态的热力学对象**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **成分表面质量密度** | 每种成分在界面上的质量面密度 → 面积共轭量不同 |
| **厚度描述符 $h$** | 单位面积体积（vol/area）→ **压力型共轭量**（类表面张力） |
| **可逆表面应力** | 由自由能泛函对面积/厚度的变分给出 |
| **Gibbs–Duhem 关系** | 界面相平衡条件（类 Young–Laplace + 成分平衡） |
| **三种厚度运动学** | 独立演化 / 受约束 / 快速平衡（降阶为代数关系） |
| **可用自由能恒等式** | 移动面片上的机械功完整记账 |

### Gibbs–Duhem 扩展

经典界面：$\sigma = \partial f / \partial A$（表面张力 = 自由能对面积导数）。
本文扩展为：**面积共轭 + 厚度共轭 + 成分共轭** 的多元关系 → 界面上同时存在
- 表面张力（面积方向）
- 类压力项（厚度方向）
- 成分交换驱动力（成分方向）

## 渲染价值分析（豆苗视角）

### 🩸 可行性分析：泡沫 / 飞沫 / 界面材质的"状态化"建模

**这篇论文解决了特效制作中一个长期靠美术手搓的问题：界面不是几何，而是有状态的物理对象。**

### 三个具体的渲染影响

1. **泡沫与飞沫的生成判据（最直接的价值）**：
   论文给出"界面厚度 $h$ + 体积变化率"的**独立演化方程**与**压力型共轭量**。
   → **落地公式（近似）**：当局部厚度 $h$ 被压缩到临界以下、或体积分数的压缩率超过阈值时，**触发泡沫生成事件**。
   → 这把"哪里该冒泡"从**美术判断**变成**物理判据**，且判据是**局部的、逐帧的**。

2. **"两个相向撞的液体"应该有白沫，而不是硬边合并**：
   经典 VOF 会把两片液体直接合并成一个光滑界面。真实情况：撞击区**厚度骤降 → 破碎 → 生成泡沫与飞沫**。
   → 有了本文的厚度场，就可以在着色/粒子生成阶段**依据厚度梯度**驱动泡沫粒子系统——**泡沫位置自动出现在真正发生破碎的地方**。

3. **界面厚度 → 着色（体积渲染直接可用）**：
   厚度 $h$ 本身就是**光学厚度**。在体积渲染里，界面区域的消光系数应随 $h$ 变化，而不是用统一的密度场。
   → **实用建议**：把厚度场作为独立通道传到渲染端：
   - 厚界面 → 高消光、不透明（厚的水墙）
   - 薄界面 → 半透明、有透光（薄水膜、水花片）
   - **这直接改善了"水花看起来像塑料片"的问题**

4. **"表面活性剂/污染"界面材质**：
   成分表面质量密度 → 界面张力随成分变化 → **水面局部"更紧/更皱"**。这在美术上对应"部分区域水面张力不同"的效果（油膜、水面上的污渍）。

### 实现建议

- **着色器复杂度**：中（需在求解器里增加厚度与成分场通道）
- **管线要求**：
  - 求解器侧：每个界面单元额外存 $h$（厚度）与 $\rho^\Gamma_\alpha$（成分密度）
  - 渲染侧：需要**厚度场通道**直通 → 需要扩展网格数据布局（通常是多一层 3D 纹理或 mip 链）
- **推荐度**：✅ 推荐（**泡沫/飞沫/水花类效果的可控性提升显著**）；⚠️ 若项目只有简单水面，可先只在**局部破碎区**启用

### 渐进式落地路径

| 阶段 | 做法 | 收益 |
|------|------|------|
| **1. 纯渲染侧（零求解器改动）** | 用 level-set 的**梯度模长**（$\|\nabla\phi\|$）作为"界面薄厚"的代理量 → 驱动泡沫与消光系数 | 中等，立即可用 |
| **2. 简化厚度场** | 求解器里追踪一个"界面厚度"标量场（可由 level-set 变化率 + 局部体积分数近似） | 较高 |
| **3. 完整热力学框架** | 厚度 + 成分密度 + 可逆应力 | 高，但实现成本大 |

> ⭐ **阶段 1 强烈推荐**：用 $\|\nabla\phi\|$ 做泡沫生成与消光调制，是**零成本**拿到大部分收益的方法。

## 实验结论

理论框架论文（平衡方程 + 熵产生 + 可用自由能恒等式），无数值实验。

## 局限性

- **纯理论**，无实现与性能数据。
- 未涉及**离散化**：如何在这个连续框架下构造稳定的数值格式（对 VOF/SPH 而言这是最难的部分）。
- "三种厚度运动学"的区分需要**建模者判断**（独立/受约束/平衡），选择错误会导致能量不守恒。
- 未讨论**与粒子系统（SPH 界面）**的结合。
