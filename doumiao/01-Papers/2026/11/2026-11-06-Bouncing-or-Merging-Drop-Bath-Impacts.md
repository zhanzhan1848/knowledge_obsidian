## 核心贡献

> **液滴撞击液面时，到底是"弹开"还是"合并"，取决于两者之间那层被夹住的极薄空气膜是否破裂。** 本文给出第一个能**用独立测得的材料参数**预测临界撞击速度的模型，与实验达成定量一致。

1. **空气膜的润滑（lubrication）描述**：夹在液滴与液池之间的气膜因**巨大曲率**而发生形变，用薄膜润滑方程描述。
2. **需要微观/纳米尺度物理**：
   - **van der Waals 驱动的 disjoining pressure**（分离压力）
   - **依赖气体平均自由程的动理学效应**（gas-kinetic effects）
3. **首次定量吻合实验**：仅用独立测量的材料参数，得到区分 bounce/merge 的**临界撞击速度**。
4. **低压环境行为**：探索低环境气压下的撞击。
5. **bounce–merge–bounce–merge 转变**：随液池深度减小，阈值行为发生**交替相变**（浅池与薄膜）。

## 技术方案

### 物理链条

```
液滴撞击液池
  → 液面变形，夹住一层薄气膜
  → 气膜内出现巨大曲率 → 薄膜润滑流
  → 薄膜内压力下降 → disjoining pressure（van der Waals）上升
  → 若气膜内压力 < 0（负压）→ 气膜破裂
     ├─ 未破裂 → 液滴弹开（bounce）
     └─ 破裂   → 液滴与液池合并（merge）
```

### 关键无量纲量

| 量 | 作用 |
|------|------|
| **气膜平均自由程 $\ell$** | 决定动理学效应是否显著（Knudsen 数） |
| **disjoining pressure 尺度** | van der Waals 相互作用能 $\sim A/r^6$ |
| **临界撞击速度 $U_c$** | bounce/merge 分界，**本文的最终可交付量** |
| **Weber 数** | 惯性 vs 表面张力 |

### 数值方法

- **有限元框架（finite-element）**
- **薄膜润滑近似**嵌入其中（气膜用 1D 薄膜方程，液池用完整有限元）
- **气膜破裂判据**：负压判据（当薄膜内压力降到蒸气压以下 → 破裂）

## 渲染价值分析（豆苗视角）

### 🩸 可行性分析：滴液撞击的"弹 vs 合"判据

**这篇论文解决特效制作中长期靠美术手调的问题：雨滴落进水面，到底应该"弹起来"还是"直接融进去"。**

### 三个具体的渲染影响

1. **"弹开"与"合并"是两种完全不同的视觉语言，必须有物理判据**：
   - 现实：**小而轻的雨滴** → 弹开（产生微小涟漪 + 一圈气垫）
   - **大雨滴/高速撞击** → 合并（产生冠状水冠 + 飞溅）
   - → 落地判据可以用 **Weber 数 $We = \rho U^2 D/\sigma$** 近似：
     - $We \lesssim$ 某阈值 → 弹开
     - $We \gtrsim$ 阈值 → 合并
   - **实用价值**：把"这个雨点该弹还是该吞"从美术感觉变成一个可调阈值参数。

2. **弹开时的"气垫"是可见的**（薄气膜在液滴底部形成可见的空气层，接触面积小）：
   - 弹开瞬间的接触面**极小** → 产生一个**尖锐的"噗"形水花冠**，而不是宽的冠状水冠。
   - → 渲染上：弹开路径应使用**窄、尖、低水墙**的飞溅模板；合并路径使用**宽、厚、多飞沫**的模板。
   - **这是本文最直接可落地的一条**：决定飞溅模板的"选哪一套"。

3. **浅池 / 薄膜 → bounce–merge–bounce–merge 交替**：
   - 同样的撞击速度，在**不同深度的水洼**里会得到**完全相反**的结果（弹/合交替）。
   - → 渲染上：\**水洼深度应成为撞击结果的输入变量**\*。这修正了很多"所有水洼表现一样"的偷懒做法。
   - 落地建议：飞溅模板查找表从 1D（按速度）升级为 **2D（速度 × 液池深度）**。

4. **气膜破裂的时间尺度 → "接触瞬间的延迟"**：
   - 现实中小液滴撞击后，**接触点先保持一小段时间**（气垫支撑），然后才合并或弹开。
   - → 渲染上：撞击后应有**几十毫秒的"悬空"延迟**，而不是瞬间合并。这是个很便宜的改进（延迟一个关键帧），视觉提升明显。

### 实现建议

- **着色器复杂度**：低（只是选模板 + 一个阈值）
- **管线要求**：
  - **纯渲染侧即可**：不需要改求解器。只需要一个"撞击结果分类器"（速度 + 液滴半径 → bounce/merge）
  - 若有物理求解器：可在求解器里加一个 disjoining pressure 判据项
- **推荐度**：✅ **强烈推荐**（低成本、高感知收益——雨滴/水滴撞击是极高频的视觉元素）

### 渐进式落地路径

| 阶段 | 做法 | 收益 |
|------|------|------|
| **1. Weber 数分类（零成本）** | $We$ 阈值 → 选飞溅模板 | **高**，立即可用 |
| **2. 加液池深度维度** | 模板查找表改为 (速度 × 深度) | 高，修正浅水洼表现 |
| **3. 加接触延迟** | 撞击后 30–80ms 的悬空期 | 中高，细节真实度 |
| **4. 完整 disjoining 判据** | 求解器内负压判据 | 高，但成本大，非必要 |

> ⭐ **强烈建议从阶段 1 + 阶段 3 做起**：一个阈值 + 一个延迟，就能让雨滴从"通用水花"变成"会弹、会悬停的雨滴"。

## 实验结论

- 用**独立测得的材料参数**（液体表面张力、气体平均自由程、van der Waals 常数）得到**首次与实验的定量一致**（临界撞击速度）。
- 探索了低环境气压下的行为。
- 发现液池深度减小时存在 **bounce–merge–bounce–merge 转变**。

---

## 局限性

- **纯理论 + 实验对比**，无渲染/游戏侧实现。
- 依赖**微纳米尺度物理**（平均自由程、van der Waals），**在实时渲染的分辨率下几乎不可能直接模拟**。
- 但——**临界速度是可用的降阶输出**，这正是渲染需要的（不需要模拟气膜本身，只需要知道结果）。
- 未涉及 3D 液池的复杂几何。
