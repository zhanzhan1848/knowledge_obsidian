## 核心贡献

> **深度学习可以从海面高度 (SSH) 直接回归出完整的表层流速矢量与 50 m 深度流速，并恢复涡量、散度与谱能量通量等导数量** —— 在 SWOT 时代（50 km 以下分辨率）绕开地转平衡近似的限制。

1. **完整速度矢量的学习回归**：不是近似标量地转流速，而是从 SSH + 环境数据直接预测**水平速度矢量**（surface 与 50 m 两个深度层）。
2. **恢复导数量诊断 (derivative-based diagnostics)**：相对涡量、散度，以及**谱能量通量 (spectral energy flux)**。
3. **突破地转近似的量级优势**：在 50 m 处，最佳模型的**速度 RMSE 为 0.049 m/s，比地转近似低 29%**；**相对涡量相关系数 0.93**（地转近似为 0.75）；**散度相关系数 0.66**（而地转速度**按定义无散度**）。
4. **超参数/训练策略的四条实证结论**（对自建管线有直接指导价值）：
   - **SSH 梯度优于原始 SSH** 作为输入；
   - **风应力 (wind stress) 是总速度预测最有用的协变量**；
   - **SST（海表温度）的收益随季节变化**；
   - **把涡量与散度纳入损失函数可提升精度**。
5. **面向 SWOT 的迁移路径**：为把高保真仿真物理迁移到 SWOT 应用提供途径——公里级 SSH 快照中**叠加了平衡与非平衡信号**，而传统平衡假设无法分离二者。

## 技术方案

### 核心思想

**问题设定**：海面高度 (SSH) 是遥感可观测的，但**海洋上层流速**不可直接观测（除了昂贵的现场仪器与 Argo 剖面）。传统做法依赖**地转平衡 (geostrophic balance)** 或** cyclogeostrophic balance** 的解析近似：
$$\mathbf{u}_g = \frac{1}{f}\,\mathbf{k}\times\nabla\eta$$
其中 $f$ 为科氏参数、$\eta$ 为 SSH。但这个近似隐含强假设：**小 Rossby 数、平衡态、流场无辐散**。随着 **SWOT (Surface Water and Ocean Topography)** 任务把观测分辨率推进到 **50 km 以下**，这些假设越来越站不住——SSH 图中**平衡分量与非平衡分量（潮、内波、锋面、涡旋、惯性与波致流）叠加在一起**，而地转近似会把它们**全部丢弃**。

**本文的思路**：既然 SSH 的信息不足以解析分解平衡/非平衡分量，就让**数据自己学**——用深度学习从 (SSH, SST, 风应力) 回归完整的流速矢量。

**网络结构**：**U-Net encoder–decoder**。选 U-Net 的理由很自然：
- **encoder** 提供多尺度感受野（全局 SSH 分布 → 局地涡旋结构）；
- **decoder** 配合跳跃连接保留空间细节，对**涡量/散度这类导数量**的重建至关重要（导数量对空间分辨率极其敏感，浅层特征不能丢）。

**训练数据**：LLC4320 全球海洋模拟（MIT 的 4320² 全球涡分辨模拟）的 **pre-SWOT Cape Basin** 提取，逐小时场，**1.5 km 网格间距**，空间范围 **11.8–15.8°E, 41–45°S**（南大西洋的开普海盆，是强涡旋与锋面活跃区）。
- **输入**: SSH、SST、wind stress
- **目标**: surface 与 **50 m** 处的水平速度。选择 50 m 是因为**风的影响在 50 m 显著减弱**——这个深度更像"背景地转流 + 残余涡旋"，是检验模型能否超越平衡近似的干净战场；同时也训练地表层，风驱直接相关。

**恢复导数量**：模型输出速度场后，**涡量与散度由预测速度场做空间导数得到**。这正是本文的亮点：地转速度**按定义为无散度**（$\nabla\cdot\mathbf{u}_g = 0$），而真实海洋流场是有辐散的（Ekman 抽吸、锋面辐合、涡旋挤压）。模型能恢复**相关系数 0.66 的散度**，意味着它**学到了地转近似结构上无法表示的成分**——这是对"超越平衡假设"的直接证据，而不是仅仅"数值上更准"。

**谱能量通量**的恢复进一步说明：模型不仅还原了瞬时流速，还还原了动能在尺度间传递的结构（这需要正确的涡旋尺度与旋转方向信息）。

### 关键技术

| 技术 | 说明 |
|------|------|
| **U-Net encoder–decoder** | 多尺度编码 + 跳跃连接，保证导数量重建所需的空间分辨率 |
| **SSH 梯度作为输入** | 优于原始 SSH；与地转平衡的物理结构一致（流速 ∝ SSH 梯度） |
| **SST 协变量** | 刻画锋面与层结信息，收益具季节性 |
| **Wind stress 协变量** | 对总速度预测最有用（风驱表层流 + Ekman 输运） |
| **双深度目标 (surface + 50 m)** | 表层含风驱直接响应；50 m 风影响减弱、更接近平衡背景 |
| **导数量监督 / 后处理** | 由预测速度做空间导数，得涡量、散度、谱能量通量 |
| **LLC4320 pre-SWOT 提取** | 1.5 km 网格，逐小时，覆盖 Cape Basin |
| **对比地转/cyclogeostrophic 平衡** | 传统基线 |

## 公式

```math
% —— 地转平衡近似 (传统基线) ——
f\,\mathbf{u}_g = \mathbf{k}\times\nabla\eta,
\qquad
\mathbf{u}_g = \frac{1}{f}\,\mathbf{k}\times\nabla\eta,
\qquad f = 2\Omega\sin\varphi

% —— cyclogeostrophic 平衡 (含离心修正) ——
f\,\mathbf{u}_{cg} = \mathbf{k}\times\nabla\eta + \frac{|\mathbf{u}_{cg}|^2}{R}\,\hat{\mathbf{e}}_{R}

% —— 相对涡量与散度 (由预测速度场导数得到) ——
\zeta_{\text{rel}} = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y},
\qquad
\nabla\cdot\mathbf{u} = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}
\qquad
(\text{地转速度: } \nabla\cdot\mathbf{u}_g \equiv 0)

% —— 谱能量通量 (涡旋输运的尺度传递) ——
\Pi(k) = -\tfrac{1}{2}\Re\!\left\langle \hat{u}^*(k)\,\hat{\mathbf{u}}(k)\cdot\nabla\hat{\mathbf{u}}(k)\right\rangle,
\qquad
\Pi(k)=\Pi_0\varepsilon^{2/3}k^{-5/3}\ \ (\text{惯性区})

% —— 涡旋拉伸 (次级不稳定) ——
\frac{D\omega}{Dt} = (\boldsymbol{\omega}\cdot\nabla)\mathbf{u}
= \underbrace{\boldsymbol{\omega}\cdot\mathbf{S}}_{\text{拉伸}}
+ \underbrace{\boldsymbol{\omega}\times\boldsymbol{\omega}}_{\text{转动}}
+ \nu\nabla^2\boldsymbol{\omega},
\qquad
\boldsymbol{\omega}=\nabla\times\mathbf{u}

% —— 网络目标与损失 (含导数量辅助项) ——
\mathcal{L} = \big\|\mathbf{u}_{\text{pred}}-\mathbf{u}_{\text{true}}\big\|^2
+ \lambda_z\big\|\zeta_{\text{pred}}-\zeta_{\text{true}}\big\|^2
+ \lambda_d\big\|\nabla\!\cdot\!\mathbf{u}_{\text{pred}}-\nabla\!\cdot\!\mathbf{u}_{\text{true}}\big\|^2

% —— SSH 梯度输入 (优于原始 SSH) ——
\mathbf{g}_{\text{SSH}} = \nabla\eta \quad (\text{与地转结构直接对应})

% —— 误差指标 ——
\text{RMSE}_{\text{speed}} = \sqrt{\frac{1}{N}\sum_i \big(\|\mathbf{u}_{\text{pred}}^{(i)}-\mathbf{u}_{\text{true}}^{(i)}\| - \|\mathbf{u}_{\text{true}}^{(i)}\|\big)^2},
\qquad
\text{Corr}(\zeta) = \frac{\langle \zeta_{\text{pred}}\zeta_{\text{true}}\rangle-\langle\zeta_{\text{pred}}\rangle\langle\zeta_{\text{true}}\rangle}{\sigma_{\zeta_{\text{pred}}}\sigma_{\zeta_{\text{true}}}}
\end{math}
```

## 实验结论

- **数据集**: LLC4320 海洋模拟的 **pre-SWOT Cape Basin 提取**；逐小时场；**1.5 km 网格**；范围 **11.8–15.8°E, 41–45°S**；输入 SSH / SST / wind stress；目标为 surface 与 50 m 的水平速度
- **基线**:
  - **地转近似 (geostrophic approximation)**
  - cyclogeostrophic 近似（隐含）
  - 不同训练策略变体（输入组合、损失项）
- **结果**:
  - **50 m 处速度 RMSE = 0.049 m/s，比地转近似低 29%**
  - **相对涡量相关系数 0.93**（地转近似 **0.75**）
  - **散度相关系数 0.66**（地转速度按定义无散度）
  - 能恢复**谱能量通量**（导数量诊断）
  - **训练策略四结论**：
    1. **SSH 梯度 > 原始 SSH** 作为输入；
    2. **风应力是最有用的协变量**（对总速度预测）；
    3. **SST 的收益随季节变化**（冬季/夏季不同）；
    4. **在损失中加入涡量与散度可提升精度**。

## 局限性

- **模拟数据的域偏移 (domain shift)**：训练与测试都在 LLC4320（模拟）上完成，**迁移到真实 SWOT 观测**尚未验证；模拟与真实观测在噪声、混叠、误差结构上差异显著（SWOT 实际还需处理内潮、混叠、相关噪声）。
- **区域局限**：仅在 Cape Basin 一个强涡区（南大西洋）验证，跨海盆/跨流区的泛化性未知。
- **物理约束缺失**：纯数据驱动的 U-Net **不保证**质量守恒、无穿透、涡量守恒等；缺乏对科氏/压力平衡的结构性偏置。
- **仅水平二维**：不输出垂向速度剖面，也不预测次表层三维结构（对水下光线折射、声学等下游用途不足）。
- **时间维度**：从逐小时场训练，但**未建模时间连续性**（不是序列模型），逐帧独立预测可能缺乏时间一致性（若用于动画需额外约束）。
- **"50 m 风影响减弱"是简化**：真实 50 m 处仍有显著的 Ekman 输运分量与混合层结构。
- **代码/数据未公开**（摘要未给出仓库链接）。

## 渲染价值评估

**⭐⭐⭐⭐（4/5）—— 海面渲染"从位移反推速度"的直接技术供给**

1. **核心命题：海浪渲染最难的一步是"从位移场反推速度场与涡量"** ⭐⭐⭐⭐⭐
   美术/程序化给出的海面通常只有**高度图**（顶点位移）。但要让海面"动得像海"，需要的不只是顶点上下运动，而是：
   - 表面质点的**水平漂移**（波浪轨道运动，决定泡沫被拖曳的轨迹）；
   - 局部**旋转**（决定波峰的卷曲与碎裂）；
   - **涡量场**（决定涡旋与剪切带，决定白浪的分布）。
   本文证明：**U-Net 可以从 SSH 直接回归出完整速度矢量与导数量**。
   *落地*：渲染管线中把"位移图 → 速度/涡量场"这一步交给一个轻量网络（或其蒸馏版本），即可让水面从"高度图动画"升级为"有真实运动学的水面"。

2. **涡量 → 泡沫/白浪 (whitecaps) 的驱动源** ⭐⭐⭐⭐⭐
   **相对涡量相关系数 0.93**（远高于地转近似的 0.75）。
   *渲染映射*：白浪/泡沫的生成标准判据就是**波峰处的波陡度 + 涡量强度**。用预测涡量场做 foam mask，泡沫会自然出现在**真正发生破碎的地方**，而不是简单地"波高超过阈值就变白"。视觉上这是"泡沫跟着流体走"而非"泡沫跟着高度走"——差别极大。
   *具体*：foam intensity ← f(|ζ|, 涡量梯度, 波陡度)，配合一个"泡沫生成—衰减"的寿命缓冲，得到自然的斑驳而非硬阈值。

3. **散度 → 表面辐聚/辐散** ⭐⭐⭐⭐
   **散度相关系数 0.66**，而地转速度**按定义无散度**。
   *渲染映射*：正散度 = 表面被拉伸（可用于拉伸纹理/泡沫线）；负散度 = 辐聚（可用于汇聚流动的泡沫与碎屑聚集）。散度场可用于驱动**表面纹理（normal map）的各向异性拉伸**（辐散方向纹理被拉长），这是让海面"有流动感"的重要细节。
   *进一步*：负散度区（水汇聚）也是**破碎最易发生**的位置，可以把散度与涡量组合成破碎概率场。

4. **风应力协变量 → 风驱表层流与风向一致性** ⭐⭐⭐⭐
   论文的第二条训练结论：**风应力是总速度预测最有用的协变量**。
   *渲染映射*：海面流向必须与**风向一致**（风吹的方向决定波纹与泡沫拖曳方向）。传统高度图海面很容易出现"浪往一个方向推、泡沫往另一个方向漂"的违和感。把风应力作为显式输入或至少作为**全局朝向约束**，能保证泡沫拖尾、浪纹方向、漂移方向三者一致——这是廉价且高收益的修正。

5. **"SSH 梯度 > 原始 SSH" → 网络输入设计的直接指导** ⭐⭐⭐⭐
   第一条训练结论。
   *渲染映射*：若自建模型做"高度图 → 流速/涡量"回归，**输入高度图的梯度/法线**比输入原始高度更有效。这与渲染中的常识一致——梯度 = 法线 = 光照响应，天然携带更多信息。同时也提示：**可以直接把渲染用的法线图当作网络输入**，省去额外预处理。
   *推广*：同理，"曲率/拉普拉斯"（对应高度图的二阶导）是破碎判据的重要分量，值得一并作为输入通道。

6. **导数量入损失 → 保证场是"物理上可用"的** ⭐⭐⭐⭐
   第四条训练结论：在损失中加入涡量与散度项。
   *渲染映射*：如果网络只回归速度场 RMSE，导数量可能很差（误差在空间中相互抵消），而导数量恰恰是渲染最需要的量（法线扰动、泡沫判据、涡旋拉伸）。**必须显式监督导数量**。这一条几乎是"自建此类模型"的必做项。

7. **谱能量通量 → 波谱尺度分布的校验/生成** ⭐⭐⭐
   *渲染映射*：谱能量通量描述了能量在波数间的传递方向与强度，可用于：
   - **校验**渲染出的波谱是否合理（是否出现不真实的谱斜率）；
   - 作为**波谱参数化**的先验（从能量通量反推谱形），约束程序化波浪（Gerstner 分量集合的振幅/频率分布），避免"看起来像海浪但谱不对"。
   对需要物理可信度的影视/工程级渲染，这提供了比"肉眼调参"更硬的判据。

8. **50 m vs surface 双深度目标 → 分层流结构的暗示** ⭐⭐
   论文同时训练两个深度层，其差异隐含了**风驱表层与背景地转流的分离**。
   *渲染映射*：可用于**双层海面渲染**（表层细节 + 次表层大尺度涌动），或作为"波高与流速不共面"的建模工具（横浪/斜浪）。

**实时 vs 离线**：推理成本极低（U-Net 单次前向），**完全实时可行**（甚至可在 GPU 上逐帧跑）。但**训练成本高**（需要高分辨率海洋模拟配对数据），属于"离线训练 + 在线推理"的典型模式。

**给算法 agent 的具体建议**：
1. **最小可行管线**：准备配对数据（高分辨率海面模拟 或 合成解析波场 + 物理边界条件）→ 训练 U-Net，输入 `[SSH, ∇SSH, SST, wind stress]`，输出 `[u_surface, u_50m]`；损失 = 速度 MSE + λ·涡量 MSE + μ·散度 MSE。
2. **网络选型**：若数据量不大，U-Net 是稳妥选择（跳跃连接对导数量必要）；若追求实时极致，可考虑蒸馏到轻量 FNO/小 U-Net（参考 [[2026-03-26-NeuralFVM-Turbulent-Flows]] 的神经算子路线）。
3. **消费端优先级**：涡量 → foam mask；散度 → 破碎概率 + 纹理拉伸；速度 → 泡沫拖曳方向 + 波峰切变。**先做 foam**，收益最大。
4. **保真度边界**：明确本文结论是在**模拟数据**上得到的，直接用于真实 SWOT 观测需做域适应；作为**渲染用代理**则完全够用（渲染本身也不需要绝对真实，只需统计可信）。
5. **与 3DGS 水面方案组合**：本文提供的是**流场/涡量**，与 [[2026-10-19-Make-It-Flow-Water-Animation-3DGS]] 类方法（3DGS 水面动画）互补——前者给"动"的物理量，后者给"看起来像水"的表示。建议组合而非二选一。
