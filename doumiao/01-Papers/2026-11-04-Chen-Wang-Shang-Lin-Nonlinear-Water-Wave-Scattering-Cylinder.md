## 核心贡献

> **提出一个基于势流理论的高非线性时域数值伪谱 (pseudo-spectrum) 模型** —— 用 **Fredholm 第二类积分方程 + Legendre 多项式** 高效求解圆柱表面速度势与自由面垂向速度，为大直径圆柱结构（单桩风机、平台立柱）的高阶波绕射与水动力载荷提供新的求解框架。

1. **高非线性时域伪谱模型**：在**势流理论 (potential flow)** 框架下，处理**高阶非线性瞬态波**的绕射问题。
2. **Fredholm 第二类积分方程 + Legendre 多项式的谱方法求解器**：一个**高效且独立**的求解器，用于计算**圆柱表面的速度势**与**自由面垂向速度**。
3. **严谨验证**：与基于 **Fourier 变换的直接方法 (direct approach)** 以及**已建立的波动理论模型**（针对**小陡度均匀波 (small steepness uniform waves)** 的散射）进行对比验证。
4. **收敛性与计算效率**：给出收敛性分析与效率演示。
5. **工程意义**：为**海上/近海结构**（大直径圆柱，如单桩海上风机与平台立柱）的**非线性波载荷**预测提供稳健方案 —— 这类结构的载荷评估长期受制于高阶波绕射问题求解的困难。
6. **Part II 预告**：新模型对**高度非线性瞬态水波**的验证将在 Part II 报告。

## 技术方案

### 核心思想

**工程背景**：极端海浪（极端海洋波）对海洋工程与航行安全构成重大威胁。对**大直径圆柱结构**（单桩海上风机基础、平台立柱）的**非线性波载荷**进行准确预测，需要对**高阶波绕射问题 (high-order wave diffraction problem)** 给出稳健解。这类结构的特点是：直径相对波长很大（D/L 量级大），**绕射效应显著**，且**自由面与刚体边界同时存在**，因此经典的线性势流（linear potential flow, 绕射系数法）精度不足——而真实的非线性效应（波的陡化、破碎前的强非线性、波群）又远超线性理论能描述的范围。

**本文方法**：在**势流理论**假设下（不可压缩、无粘、无旋），求解"**自由面 + 表面贯穿圆柱**"的相互作用问题。与经典 Green 函数法（image 法、边界元 + 离散积分方程）不同，本文采用**伪谱 (pseudo-spectrum)** 路线：

**核心数学工具**：
- **Fredholm 第二类积分方程 (Fredholm integral equation of the second kind)**：把波动边界条件转化为一个**非齐次第二类 Fredholm 方程**，其解可通过**谱展开**求取：
  $$a(\theta)\phi(\theta) + \int_{S}\!\!K(\theta,\theta')\,\phi(\theta')\,d\theta' = f(\theta)$$
  其中 $\phi$ 是待求的未知势分布（在圆柱表面或自由面上），$K$ 为由 Green 函数导出的核函数（Fredholm 第二类的核心特征是**待求量出现在积分号内外**）。
- **Legendre 多项式 (Legendre polynomials)**：把解在球面上展开为**勒让德谱**，从而：
  - 避免处理奇异积分方程的数值困难（**谱方法对光滑解收敛极快**）；
  - 使圆柱表面的角向依赖被**代数精度**地表示；
  - 便于与自由面的展开（如 Fourier 或 Chebyshev）耦合。

**时域处理**：由于模型定位于**瞬态 (transient)** 波，采用**时域推进**——每个时间步求解上述 Fredholm 方程，更新自由面高程与速度势，从而可以处理**任意波包、入射波列**而非仅单色波。

**验证策略**：
1. **与 Fourier 变换的直接方法对比**——检验新求解器本身的正确性（两条独立的技术路线互校是很有说服力的验证方式）；
2. **与已建立的波动理论模型对比**——在**小陡度均匀波**的极限下，应能退化到经典解，此时有解析或高可信的参照；
3. **收敛性与效率分析**——谱截断阶数、网格/时间步的收敛测试，以及相对现有方法的计算开销对比。

**Part I 的范围界定**：Part I 侧重**求解器的构建与验证（小陡度、均匀波极限下的正确性与收敛性）**；对**高度非线性瞬态波**的完整验证留给 **Part II**。

### 关键技术

| 技术 | 说明 |

## 公式

```math
% —— 势流控制方程 ——
\nabla^2\phi = 0 \quad \text{(内部域)},
\qquad
\phi \to 0 \quad (|\mathbf{x}|\to\infty)

% —— 自由面运动学与动力学边界条件 ——
\frac{\partial\eta}{\partial t} = \frac{\partial\phi}{\partial z}\Big|_{z=\eta},
\qquad
\frac{\partial\phi}{\partial t} + g\,\eta
+ \nabla_{\!h}\phi\cdot\nabla_{\!h}\eta
+ \frac{1}{2}\left|\nabla\phi\right|^2 = 0
\quad (z=\eta)

% —— 圆柱表面不可穿透条件 (Neumann) ——
\frac{\partial\phi}{\partial n} = \mathbf{U}\cdot\mathbf{n}
\quad \text{on } S_{\text{cyl}}

% —— 圆柱表面 (球坐标) 速度势的 Fredholm 第二类积分方程 ——
a(\theta)\,\phi(\theta)
+ \int_{0}^{2\pi}\!\!\int_{0}^{\pi}\!
K(\theta,\theta',\varphi')\,G(\mathbf{x}(\theta',\varphi'),\mathbf{x}_0)\,
\phi(\theta')\,d\varphi'\,d\theta'
= f(\theta),
\qquad \mathbf{x}_0 \in S_{\text{cyl}}

% —— Legendre 谱展开 (球向角依赖) ——
\phi(\theta) = \sum_{n=0}^{N} a_n\, P_n(\cos\theta),
\qquad
P_n: \text{Legendre 多项式}, \qquad
\|f - \mathcal{N}P_N f\|_{\infty} \sim N^{-(m+1)},\; f\in C^{m}

% —— 线性化极限: 小陡度均匀波 + 绕射系数解 (验证基准) ——
\eta^{(0)}(\theta) = A\cos(kR\cos\theta - \omega t),
\qquad
\frac{H(\theta)}{H_i} = \sum_{n=0}^{\infty} i^n e^{i n \pi/2} J_n(kR\cos\theta)\,(\ldots),
\qquad \omega^2 = gk\tanh(kh)

% —— 水动力载荷 (圆柱表面压力积分) ——
p = -\rho\,\frac{\partial\phi}{\partial t},
\qquad
F_x = -\oint_{S_{\text{cyl}}} p\, n_x\, dS,
\qquad
M_y = -\oint_{S_{\text{cyl}}} p\, n_x\, z\, dS
\end{math}
```

## 实验结论

- **模型体系**: 势流框架下的时域伪谱求解器；Fredholm 第二类积分方程 + Legendre 多项式谱展开
- **基线/对照**:
  - 基于 **Fourier 变换的直接方法**（独立技术路线）
  - **已建立的波动理论模型**（小陡度均匀波散射）
- **结果**:
  - 新求解器与 Fourier 直接法**一致**，与既有理论模型在**小陡度均匀波**下吻合
  - **收敛性**得到验证（谱阶数/时间步收敛）
  - **计算效率**优于/可比于对照方法
  - 成功计算**圆柱表面速度势**与**自由面垂向速度**
  - **高度非线性瞬态波的完整验证留待 Part II**

## 局限性

- **Part I 范围有限**：非线性瞬态波的验证在 **Part II** 才报告，本篇主要贡献是**求解器与收敛性**。
- **势流假设的固有局限**：不可压缩、无粘、无旋 —— **不含粘性耗散、破碎、气泡、浪花、湍流**，也不含**波-流耦合**与**底部摩阻**；破碎前的高非线性极限（如接近破碎的陡峭波）势流本身不再准确。
- **仅线性入射 + 弱非线性扩展**：多数工业应用关心**大幅涌浪 + 风浪叠加 + 随机波列**，本模型对极端工况的稳健性待验证。
- **色散关系的处理**：数值频域到时域的转换通常受数值色散误差限制，长时间推进可能积累相位误差。
- **垂向速度而非完整速度场**：给出的是自由面垂向速度与圆柱表面势，**自由面内的完整速度场与内部流动结构**未作为主要输出，这限制了向"波与结构相互作用细节渲染"的直接迁移。
- **复现成本高**：数值伪谱 + Fredholm 积分方程的实现门槛很高（需要严格的 Green 函数、边界处理与谱理论）；且论文未开源。
- **与渲染需求的距离**：面向工程载荷评估，而非视觉逼真度；不提供任何可直接用于渲染的感知度量。

## 渲染价值评估

**⭐⭐⭐（3/5）—— 面向"物体与波浪相互作用"的物理依据，偏工程但可迁移**

1. **最直接的价值：绕桩/立柱水面的物理参考解** ⭐⭐⭐⭐
   渲染中"水绕着桩流、桩前波堆高、桩后有尾迹"是极常见的镜头。绝大多数渲染做法是手工摆几张涟漪贴图或用简单的径向衰减，完全没有物理依据。
   *本文提供*：一个可求解"**入射波 + 大直径圆柱 + 自由面**"的数值框架，可以**离线烘焙出绕桩水面高程场与垂向速度场**（甚至圆柱表面的压力分布），作为渲染的**参考/驱动数据**。
   *落地*：离线跑一遍求解器 → 导出 (a) 桩周水面高程图（贴图或 heightfield）、(b) 桩周垂向速度场（驱动泡沫与飞溅）、(c) 桩身各高度的压力/载荷剖面（驱动桩身水线附近的泡沫与湿痕）。渲染端把高程图做极坐标采样即可贴合任意桩径。

2. **自由面垂向速度 → 飞溅与泡沫的触发源** ⭐⭐⭐⭐
   论文明确把**自由面垂向速度**作为求解目标之一，这与渲染直接相关：**飞溅/白沫的生成应由局部水面垂向速度驱动**（而非由波高驱动）。
   *渲染映射*：泡沫/飞溅强度 ← f(|w|, ∂w/∂t, 波陡度)。在桩前波堆区，垂向速度大 → 泡沫与飞溅爆发；桩后尾迹区垂向速度小 → 只有缓慢的条纹泡沫。这与真实现象吻合，且能自动随波况变化。

3. **势流 → 正确的水面运动学（波轨道）** ⭐⭐⭐⭐
   势流理论给出自由面的**运动学条件** $\partial_t\eta = \partial_z\phi$，即水面质点的垂向运动由势决定，而非美术手写的正弦叠加。这给渲染端一个正确的"波不只是上下动，而是按轨道走"的基础。
   *落地*：离线求解得到的势场 $\phi(x,y,z,t)$ 可以在渲染时反解**水面质点的水平位移** $\Delta x = \int \partial_x\phi\, dt$，从而得到**正确的波轨道与表面纹理拉伸**（即 Gerstner 波的效果，但来自求解器而非解析公式）。

4. **大直径结构 = 强绕射 → 阴影区与立柱"背水"效应** ⭐⭐⭐
   论文强调的工程场景（大直径圆柱、单桩风机）恰好对应渲染中"**大尺度物体挡在海里**"的镜头。绕射会让结构背水侧波高显著降低、两侧出现绕射波。
   *渲染映射*：可以用一个**近似解（考虑绕射的 Helmholtz 消元/解析绕射系数）**实现在线效果，而非每次跑求解器；把论文的数值解当作**校准基准**来调这个近似解。

5. **方法论可迁移：Fredholm 第二类 + 谱展开 = "绕几何体的边界条件求解"范式** ⭐⭐⭐
   这是本文最可迁移的**算法思想**：把"边界上未知量"写成积分方程，并用**Legendre 等正交基做谱展开**。
   *渲染迁移*：任何"需要在一张网格上解一个耦合边界条件"的渲染问题都可以套这个模式——例如：
   - **水面与浮体/船体的湿边界**（湿痕线、爬升水位）；
   - **水体与固体遮挡物的交界速度场**；
   - **极坐标/球面上的边界问题**（如全景天空、水滴表面）。
   谱展开的好处是**高阶平滑问题只需极少项**，适合在 GPU 上用少量纹理查表实现。

6. **"用独立技术路线交叉验证"的工程态度** ⭐⭐⭐
   本文用 **Fourier 直接法 + 既有理论模型** 双重交叉验证。对渲染 ML/物理混合管线的启示：**当引入物理先验时，必须有一条独立的数值基准线做交叉校验**，否则无法判断是新方法错了还是参考错了。[[2026-11-04-Yaradoddi-Wang-Serghine-Sea-Surface-Height-to-Velocity-ML]] 用地转近似做基线是同一思路。

**实时 vs 离线**：**纯离线**。求解器是 CPU 密集、每时间步迭代的，不适合逐帧实时。**推荐用法**：离线烘焙出绕桩水面的高程/速度/泡沫场，作为查表纹理；或用论文的数值结果**校准一个实时近似解**（例如带绕射修正的 Gerstner 波叠加）。

**给算法 agent 的具体建议**：
1. **不要试图在渲染管线里实时跑这个求解器**——成本完全不匹配。定位为**离线参考解生成器**。
2. **优先落地的是泡沫/飞溅驱动**：用（近似的）绕桩水面高程+垂向速度场驱动泡沫遮罩，比手工涟漪贴图的可信度高一个量级。
3. **若要在线近似**：采用"**解析绕射 + 经验修正**"路线——用经典绕射系数解（小陡度极限，论文已有）作为基线，再叠加一个由论文数值解标定的修正项（尤其桩前波堆与背水侧减幅）；绕射系数的 Legendre 展开本身就很接近可实时计算的矩阵/查表形式。
4. **若真需要绕物体解边界问题**：借鉴本文的 **Fredholm 第二类 + 正交基谱展开** 框架，可推广到任意几何（球、胶囊、复杂形状用形状基函数），并写成 GPU 上的预计算矩阵乘法。
5. **等待 Part II**：该文明确 Part II 将报告高度非线性瞬态波的验证，届时可再评估其在"大浪冲击结构"场景的渲染价值；建议**在知识库中预留后续笔记位**。
