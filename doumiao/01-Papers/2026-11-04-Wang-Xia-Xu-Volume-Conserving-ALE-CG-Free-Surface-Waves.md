## 核心贡献

> **一句话点题：给二维全非线性自由面势流设计了一套**体积守恒的 ALE 连续 Galerkin 有限元法**——用"基于残差的 Dirichlet-Neumann 通量"驱动自由面演化，配合兼容网格运动、表面投影与求积，在**半离散层面严格保持离散流体体积**。**

1. **等参有限元 + 残差通量的双场结构**：
   - **内部势**用等参（isoparametric）有限元在**当前流体域**上计算。
   - **表面演化**由**基于残差的 Dirichlet-Neumann 通量**驱动。
2. **全局离散平衡（global discrete balance）**：残差通量满足一个继承自内部变分形式的**全局离散平衡**——这是体积守恒的数学根源。
3. **体积守恒证明**：当与**兼容网格运动、表面投影、求积**三者结合时，该平衡导出**半离散层面的离散流体体积守恒**。
4. **可选的高阶表面耗散**：**六阶**（sixth-order）表面耗散项用于**控制高频振荡**（在不损伤低频波的前提下抑制数值噪声）。
5. **四阶 Runge-Kutta 时间推进**：表面方程用 **4 阶 RK** 积分，**每个 RK stage 都更新网格与内部解**（保证全域一致性）。
6. **数值验证**：
   - 线性自由面波：**期望的空间收敛阶**得到确认。
   - 非线性波：**网格敏感性显著降低**（在平坦底部与曲面上均验证）。
   - **旋转造波机（rotating wavemaker）算例**：演示了对**移动固体边界**的处理能力。

## 技术方案

### 核心思想

自由面水波模拟在图形学与 CFD 中都是核心问题，但**数值模拟自由面波有一个众所周知的困难：体积守恒**。

问题的本质：自由面是**运动边界**。你用网格跟踪它，网格变形就会引起计算域体积的数值误差；而对于不可压势流（体积即流体体积），**体积误差直接变成水位误差**，长时间积分会漂移。

主流应对方案：
- **Level set / 相场（phase field）**：显式引入相场变量追踪界面，守恒靠相场方程保证，但引入弥散界面与额外参数。
- **ALE（任意拉格朗日-欧拉）**：网格随流体运动，边界条件精确，但**网格畸变**是致命伤（长时间后单元质量崩溃）。

本文的解法是 **ALE + 连续 Galerkin + 残差通量**，三件事必须配套才能成立：

**（1）ALE + 等参有限元处理内部势。**
内部满足 Laplace 方程 $\nabla^2\phi = 0$，无旋无散。用等参连续 Galerkin 在**当前变形后的流体域**上离散：单元节点随边界移动，因此网格能精确贴合自由面。

**（2）残差型 Dirichlet-Neumann 通量处理自由面运动。**
这是本文最核心的技术。自由面演化方程本质上是**边界上的输运/对流方程**，需要通量。Dirichlet-Neumann 方法（在波动方程/椭圆-双曲混合系统中）通常是这样做的：
- **Dirichlet 部分**给出自由面上的势 $\phi$（从内部解插值得到）。
- **Neumann 部分**给出自由面的法向速度 $\partial\phi/\partial n$。
- 两者结合产生自由面的运动。

**"基于残差"** 的关键在于：用**内部方程的离散残差**来构造通量，而不是用外部直接指定一个通量函数。好处是——这样得到的通量**自动满足与内部变分形式的相容性**，从而产生**全局离散平衡**。这个平衡正是体积守恒的来源。

**（3）兼容网格运动 + 表面投影 + 求积。**
体积守恒需要三个额外条件同时满足：
- **兼容网格运动**：网格速度必须与流体速度在边界处一致（否则边界条件与运动学条件冲突）。
- **表面投影**：把节点投影到光滑自由面上，避免网格噪声累积。
- **求积**：用高阶求积规则计算体积积分，避免几何近似误差。

三者齐备 + 残差通量给出的全局离散平衡 ⇒ **半离散体积严格守恒**。

**（4）高阶表面耗散。**
自由面演化方程含高阶导数，容易激发高频数值振荡。六阶耗散项 $\varepsilon \nabla^6 \eta$ 的特点是：**对低频波几乎无影响**（$\nabla^6$ 在低波数下被强力抑制），但对高频噪声强力耗散——这是"选择性耗散"的标准做法。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Isoparametric CG on deforming domain** | 等参连续 Galerkin，单元节点随自由面移动，网格精确贴合界面 |
| **Residual-based Dirichlet-Neumann flux** | 用内部离散残差构造自由面演化通量，保证与内部变分形式相容 |
| **Global discrete balance** | 残差通量满足继承自内部变分形式的全局平衡 → 体积守恒的数学基础 |
| **Compatible mesh motion** | 网格速度与流体速度在边界相容（运动学 + 动力学条件一致） |
| **Surface projection** | 节点投影至光滑自由面，防止网格噪声累积 |
| **6th-order surface dissipation** | $\varepsilon\nabla^6\eta$，选择性抑制高频振荡而不损伤低频波 |
| **4th-order RK with per-stage mesh update** | 每个 RK stage 同步更新网格与内部解，保证全域一致 |
| **Rotating wavemaker** | 移动固体边界的算例验证 |

## 公式

**控制方程**（二维全非线性自由面势流，不可压无旋）：

$$\nabla^2 \phi = 0 \quad \text{in } \Omega(t)$$

**运动学条件**（自由面运动）：

$$\partial_t \eta + \mathbf{u} \cdot \nabla \eta = u_z\big|_{z=\eta}, \qquad
u = \nabla\phi$$

**动力学条件**（等压面）：

$$\partial_t \phi + \frac{1}{2}|\nabla\phi|^2 + gz = 0 \quad \text{at } z = \eta$$

**内部变分形式**（等参 CG 的基础）：

$$\int_\Omega \nabla v \cdot \nabla\phi \, d\mathbf{x} = 0, \qquad \forall v \in \mathcal{V}$$

**残差型 Dirichlet-Neumann 通量**（核心构造，抽象形式）：
由内部离散方程在边界上的残差 $r$ 出发，构造边界面上的通量项 $\hat{q}$，使其满足：

$$\oint_{\partial\Omega} \hat{q}\, v \, ds = \oint_{\partial\Omega} r \, v \, ds$$

——即边界通量是内部残差的**自然延拓**。由此得到的 $\hat{q}$ 与内部离散解**相容**，从而产生全局离散平衡。

**全局离散平衡 → 体积守恒**：

$$\frac{d}{dt} V_h(t) = 0, \qquad
V_h(t) = \sum_{K \in \mathcal{T}_h(t)} \int_K \mathbf{x} \cdot \nabla \psi_K \, d\mathbf{x}$$

（$\psi_K$ 为单元形函数；兼容网格运动 + 表面投影 + 求积共同保证 $\frac{d}{dt}V_h = 0$。）

**六阶表面耗散**：

$$\partial_t \eta \;\supset\; -\varepsilon\, \nabla^6 \eta$$

低波数 $k$ 下耗散强度 $\propto \varepsilon k^6$，故对低频波几乎无损、对高频噪声强抑制。

**时间推进**：4 阶 Runge-Kutta，每个 stage：
$$\eta^{(s+1)} \leftarrow \eta^{(s)} + \frac{\Delta t}{6}(k_1 + 2k_2 + 2k_3 + k_4), \qquad \text{并同步更新网格 } \mathcal{T}_h \text{ 与 } \phi$$

## 实验结论

- **数值验证 1（线性自由面波）**：确认**期望的空间收敛阶**
- **数值验证 2（非线性波）**：在**平坦底部**与**曲面底部**两种地形上，**网格敏感性显著降低**
- **数值验证 3（旋转造波机）**：演示对**移动固体边界**的处理
- **体积守恒**：半离散层面严格成立（理论证明 + 数值确认）

## 局限性

1. **仅势流（potential flow）**：完全**无旋、无粘**。真实水体有粘性耗散、波浪破碎、湍流——本文方法无法模拟。对**游戏/动画级写实水景**（需要破碎、白沫、飞溅）是根本性限制。
2. **仅二维**：三维扩展需要处理涡度输运（势流在三维不可推广为简单形式），复杂度显著上升。
3. **无破碎/拓扑变化**：自由面拓扑变化（浪尖卷曲、飞沫脱离）不在处理范围内。
4. **仅势流理论**，未涉及任何渲染相关内容——对**流体渲染**的价值在于提供高质量的**表面高度场与速度场**，渲染端仍需自建（法线生成、菲涅尔、反射折射、次表面散射、泡沫遮罩）。
5. **论文为纯数值方法（math.NA）**：无实验对比基线（未与 SWASH / Basilisk / 商业 CFD 比较），也未给网格/时间步收敛的实际数值表（需查正文）。
6. **代码未声明**：复现成本较高。

## 实现建议

- **实现难度**: 高（ALE + CG + 残差通量 + 表面投影 + 兼容网格运动，工程量大）
- **预期性能**: 摘要未给；理论上线性波空间收敛阶达标，非线性波网格敏感性降低
- **适用场景**:
  - ✅ **高保真、无破碎的长周期波浪模拟**（海洋场景、浮标/船体响应、造波机实验）
  - ✅ 需要**严格体积守恒**的水面（如长时间积分不漂移的仿真）
  - ✅ **移动边界**问题（旋转造波机、船体入水）
  - ✅ 作为**水面高度场的高质量数据源**，供渲染端消费
  - ⚠️ 实时渲染（ALE 网格变形 + CG 求解成本高）
  - ❌ 写实海面（需破碎、白沫、湍流细节）——应配合其他方法

**给 @墨鱼丸 的可行性判断**：**作为渲染端的数据源有价值，作为渲染方法本身不适用**。适合的定位是：**离线或半离线生成高质量水体运动场（高度场 + 速度场），再交给实时渲染管线**。对**写实海洋/湖泊场景**，可考虑与 FFT（Gerstner 波）方案对比——FFT 更快更稳但无体积守恒保证；本文方法更"物理"，适合需要与浮体/结构物耦合的场合。建议：不建议自研这套 ALE CG（实现成本过高），优先评估商用/开源求解器（SWASH、B Basilisk）或 Houdini 的海洋解算器，渲染端专注在**着色与交互**上。
