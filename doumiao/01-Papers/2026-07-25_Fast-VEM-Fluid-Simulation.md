## 核心贡献

> 高保真流体-边界交互的快速边界贴合流体模拟框架

1. **Virtual Element Method (VEM) 离散化**: 在不规则边界贴合网格上鲁棒地强制执行不可压缩性和边界条件
2. **VEM 多项式空间 PIC 方案**: 用于平流的重采样策略
3. **凸性保留切割网格策略**: 构建对模拟友好的边界贴合网格
4. **Galerkin 几何多重网格求解器**: 压力投影阶段加速最高 **100倍**

---

## 技术方案

### 核心思想

复杂边界几何的精确求解需要通过切割单元方法构建的边界贴合网格，但这往往导致压力投影阶段的线性系统条件差，计算成本高。

FastVEM 通过协调一致的**自顶向下设计**实现高效计算：
- 数值离散化
- 网格构建
- 线性求解器

### 关键技术

| 技术 | 说明 |
|------|------|
| Virtual Element Method | 在不规则边界贴合网格上强制执行不可压缩性和边界条件 |
| VEM-PIC 平流 | 多项式空间 Particle-in-Cell 方案处理平流 |
| 凸性保留切割网格 | 构建模拟友好的身体贴合网格 |
| Galerkin 几何多重网格 | 扩散无关延长算子 + 嵌套边界感知网格层次 |
| 扩散无关延长算子 | 防止粗级矩阵密化 |
| 嵌套边界感知网格层次 | 确保粗级自由度放置的适定性 |

---

## 实验结论

- **压力投影加速**: 最高 **100倍** 相比先前切割单元流体模拟器
- **边界几何处理**: 能够鲁棒处理更具挑战性的边界几何
- **时间步长**: 支持非常大的时间步长
