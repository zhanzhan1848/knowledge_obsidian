> **收录理由**：这是**唯一一篇从体积力学第一性原理严格推导薄壳能量**的工作。它揭示了一个长期被忽视的物理错误：**KL 薄壳在厚度方向是"无限刚"的各向异性材料**，即使在小变形下也无法复现体积材料的泊松收缩。这对任何涉及**薄壁容器盛流体**、**可变形外壳包裹流体**的场景（如流体-结构耦合、软体水箱）都是直接的物理正确性问题。

---

## 🎯 核心问题：KL 薄壳的物理错误

### KL 壳的三个限制性假设

KL 薄壳假设**初始垂直于中面的材料线，在变形后仍保持：**
1. **直线**（straight）
2. **垂直于中面**（perpendicular）
3. **不拉伸**（unstretched）

这**虚假地阻止了厚度方向的松弛**（through-thickness relaxation）。

### 后果

**KL 壳本质上表现为一种各向异性材料：在厚度方向无限刚，在面内方向柔顺。**

具体表现（论文 Fig. 7 单轴拉伸基准）：
- 单位正方形壳（1 m×1 m, h=0.01 m），两侧位置约束、ρ 约束为 1，单轴拉伸而横向自由收缩
- **体积方法与本文方法都收缩厚度**（本文通过变量 `ρ`），而 **KL-Shell 与 KL-Shell++ 完全无法收缩**（对它们而言 ρ 实际上全局恒为 1）
- **泊松比 ν = 0.45 时，厚度收缩超过 50%**
- 论文强调：这种不匹配**不仅体现在弹性能量与力上，还体现在形变形状的明显视觉差异上**

**最直观的视觉案例（论文 Fig. 1）**：把硅胶薄壳**裹在六角螺栓上**。六角螺栓与薄壳接触时薄壳被拉伸；由于**泊松效应**，薄壳在厚度方向收缩，**导致六角螺栓重新可见**。本文方法正确捕捉了这一效应，**KL 壳（含改进版 KL-Shell++）做不到**。

### KL-Shell++ 为何不够

KL 壳的小变形行为可以通过**改换杨氏模量/泊松比到拉梅参数的转换公式**来打补丁：使用 2D 公式 `λ̄_2D = Eν/(1−ν²)` 而非标准 3D 公式 `λ̄ = Eν/((1+ν)(1−2ν))`（Chen et al. 2018）。作者称之为 **"KL-Shell++"**。

**但**：它只改参数，**没有修复底层物理问题**（在 Fig. 1, 6, 7, 8, 10 中都可见偏差）。

## 🔬 方法

### 1. 核心思路

**从 3D 固体力学的第一性原理严格推导薄壳能量**，放弃 KL 的几何启发式与限制性假设。

### 2. 厚度方向本征模态（Through-Thickness Modes）

用**变分法**把厚度方向变形按壳厚 `h` 展开为 **Taylor 级数**，得到厚度的"自然模态"：

对**初始平直**的薄壳、**小变形**情形，解析导出前导模态。记 `γ = ν/(1−ν)`（泊松比），`S = â₁₁ + â₂₂ − 2`（面内伸长度量），`W = w⁽²⁾_u − w⁽¹⁾_v`（曲率组合），`eᵢ` 为标准基（论文 Eq. 28–32）：

```
φ₀(ξ̂) = (1 − γS)·ξ̂·e₃                    [O(h)  线性法向模态]
φ₁(ξ̂) = −(γW/2)(1 − γS)(ξ̂² − 1/12)·e₃     [O(h²) 二次法向模态]
φ₂(ξ̂) = (ξ̂/8 − ξ̂³/6)·c₂ + (1 − γS)(γW)²/12·ξ̂·e₃   [O(h³) 三次法向 + 2 个横向剪切模态]
```

其中 `c₂ = (1 − γS)·M̂⁻¹(K̂ − γW·D̂)·e₃`。

**物理含义**（论文 §5.5 原文）：
- **φ₀ (O(h))** = "KL ansatz **加上泊松效应**：当壳面内拉伸时厚度线性变化" → **KL 与泊松效应同等重要，均在 O(h) 阶**
- **φ₁ (O(h²))** = "弯曲引起的厚度变化"（纯法向）
- **φ₂ (O(h³))** = "三次法向变化与首批横向剪切模态"（e₁、e₂ 切向分量）

> **论文强调的新颖性排序**：厚度拉伸 O(h)、弯曲-厚度耦合 O(h²)、横向剪切 O(h³) —— 相对于既有流体力学工作。

### 3. 运动学 ansatz

最终形变参数化（论文 Eq. 33）：

```
x(u,v,ξ) = y(u,v) + [ ρ(u,v)·ξ + ζ(u,v)·(ξ² − h²/12) ] · n(u,v)
```

- `ρ(u,v)` = 厚度缩放（激活 φ₀），有效厚度 ≈ ρh
- `ζ(u,v)` = 激活 φ₁（弯曲模态），**可静态凝聚（statically condensable）**
- φ₂ 及以上默认丢弃（论文 §6/Fig. 9：原则上可通过加三个三次模态引入）

### 4. 几何框架

对变形后曲面 `y(u,v) ∈ ℝ³`，切向量 `y_u, y_v` 张成切平面但**未必正交**，故做 **QR 分解**得正交切向量 `q̂₁, q̂₂`：

```
[y_u, y_v] = [q̂₁, q̂₂] · [[â₁₁, â₁₂], [0, â₂₂]]      (Eq. 9)
```

上三角矩阵关联于变形后第一基本形式 `a`（Eq. 10）。单位法向 `n = q̂₁ × q̂₂`。

厚度坐标 `ξ̂ = ξ/h ∈ [−1/2, 1/2]` 处的材料点变形为（Eq. 11）：

```
x(u,v,ξ̂) = y(u,v) + [q̂₁(u,v), q̂₂(u,v), n(u,v)] · [η₁(u,v,ξ̂), η₂(u,v,ξ̂), η₃(u,v,ξ̂)]ᵀ
```

> **KL 假设对应特例**：`η₁ = η₂ = 0`, `η₃ = h·ξ̂`

### 5. 能量泛函与约束

壳能量密度为体积能量沿厚度的积分（平直静止形状下 H=K=0）：

```
ψ_shell[η] = h · ∫_{−1/2}^{1/2} ψ(F(η(ξ̂))) dξ̂            (Eq. 12)
```

**约束条件（Eq. 13）**：中面保持在 `y(u,v)`：

```
∫_{−1/2}^{1/2} η(ξ̂) dξ̂ = 0
```

> 这个约束避免了"同一个变形薄壳既可由修改 `y(u,v)` 又可由修改 `η(ξ̂)` 达成"的歧义 —— 是计算力学中的标准做法。

### 6. 变形梯度

框架随曲面旋转，其导数由**旋转速率** `ω_u, ω_v ∈ ℝ³` 给出（Eq. 14–15）：

```
∂/∂u [q̂₁,q̂₂,n] = [q̂₁,q̂₂,n][ω_u]×
∂/∂v [q̂₁,q̂₂,n] = [q̂₁,q̂₂,n][ω_v]×
```

变形梯度（Eq. 16–17）：

```
F(u,v,ξ̂) = [y_u, y_v, 0] + [q̂₁,q̂₂,n] · F̃
F̃ = [[â₁₁, â₁₂, 0], [0, â₂₂, 0], [0, 0, 1]] + [ω_u×η, ω_v×η, hη′]
```

**第一项捕捉面内拉伸，第二项捕捉弯曲与厚度拉伸引起的框架旋转。**

由于各向同性材料的旋转不变性，能量可写成（Eq. 20）：

```
ψ_shell[η] = h · ∫_{−1/2}^{1/2} ψ( F̃(η(ξ̂), (1/h)η′(ξ̂)) ) dξ̂
```

其中 `â₁₁, â₁₂, â₂₂, ω_u, ω_v` 全部由中面 `y(u,v)` 计算，且在 `ξ̂` 上视为常数。

旋转速率由 Eq. 18–19 给出。

### 7. 能量形式

从**任意各向同性超弹性能量密度 `ψ`** 出发：
- 展开变形梯度（穿过厚度）
- **解析积分**体积能量

得到**闭式壳能量**，且：
- **拉伸与弯曲贡献分离**
- **无需体积网格化**（no volumetric meshing）
- **无需厚度方向数值求积**（no through-thickness quadrature）
- **只依赖中面量**（第一基本形式 `a` 与形状算子 shape operator）加上 `ρ` 与 `ζ`

论文还提供了**可直接实现**的能量、梯度、Hessian 公式，包括**主伸长率相等时可去奇点的系统性处理**（这是实现层面的关键细节）。

#### 7.1 能量展开（论文 Eq. 40–43）

因 ansatz 满足 `F = F₀ + F₁ + F₂ + O(h³)` 的结构分解（F₀ 与 ξ 无关，F₁ 对 ξ 线性，F₂ 至多 ξ²），**Wen & Barbič (2023) 的 Taylor 展开公式可直接套用而不需修改** —— 只是被积函数变了。

```
ψ_shell = h·ψ_stretch + (h³/12)·ψ_gradρ + (h³/12)·ψ_bend + O(h⁵)
```

**拉伸项**：

```
ψ_stretch = (1 + h²K̃/12)·ψ(λ₁, λ₂, ρ)
```

其中 `(λ₁, λ₂, ρ)` 是 **F₀ 的三个主伸长率** —— 注意 **ρ 现在是第三个主伸长率**，因此材料是在**真正的三维伸长三元组**上求值的。`K̃` = 静止高斯曲率。

**厚度梯度项（本文新引入）**：

```
ψ_gradρ = ½ ∇ρᵀ P⁻¹ [[K⁺₁₃, 0], [0, K⁺₂₃]] P⁻ᵀ (∇ρ)
```

这是一个关于 `∇ρ` 的 **SPD 二次型**，惩罚厚度缩放的空间变化。

#### 7.2 主伸长率计算：免 SVD（关键工程贡献）

论文**不构造 F₀，也不做 3×3 SVD**，而用 **2×2 广义特征值求解**：

```
a·wᵢ = λ²ᵢ·A·wᵢ        （a = 变形后第一基本形式, A = 静止第一基本形式）
```

特征值有闭式解（Eq. 87）：

```
λ²_{1,2} = ½·det(A)⁻¹·[ (a₁₁A₂₂ + a₂₂A₁₁ − 2a₁₂A₁₂)
                        ± √( (a₁₁A₂₂ + a₂₂A₁₁ − 2a₁₂A₁₂)² − 4·det(a)·det(A) ) ]
```

以及 A-正交归一特征向量（Eq. 88），由此得 `P = wᵀA`, `P⁻¹ = w`, `p = diag(λ₁,λ₂)·P`（Eq. 49）。

> **为何重要**（论文 §9/附录 D 原文）："计算它们需要做 SVD……本方法**便于导数计算与奇异性处理**。它**暴露并解决了 SVD 中本会存在的奇异性**；例如 `∂λᵢ/∂a` 从 SVD 出发很难稳健计算。"

#### 7.3 可去奇异性的系统性处理

基于主伸长率的能量形式在**两个主伸长率重合**时存在**可去奇点（removable singularities）**。论文系统处理：

| 位置 | 奇点 | 处理方式 |
|------|------|---------|
| `K⁺ᵢⱼ`, `K⁻ᵢⱼ` | `σᵢ = σⱼ` 时 0/0 | 由 L'Hôpital，极限存在为导数的**差商**（divided differences）· Eq. 75 |
| `ψ_gradρ` | `λ₁ = ρ`、`λ₂ = ρ` | Taylor 展开 · Eqs. 90–91 |
| `ψ_bend` | `λ₁ = λ₂` | 变量代换 `r₀=r₁₁+r₂₂`, `r₁=r₁₁−r₂₂`, `r₂=r₁₂+r₂₁`, `r₃=r₁₂−r₂₁`（及 `s₀`,`s₁`）并因式分解；系数 C₁…C₉ 见 Eqs. 95–99，C₃/C₅/C₇/C₉ 的 Taylor 分支见 Eqs. 107–114。**切换阈值 ε = 10⁻³**（基于 `|λ₁ − λ₂|`） |

**弯曲能量的 8 项形式**（Eq. 94）：

```
ψ_condensed_bend = C₁r₀² + C₂r₃² + C₃r₀r₁ + C₄(r₀²+r₃²−4det(r)) + C₅r₂²
                  + C₆(s₀−2Hr₀) + C₇(s₁−2Hr₁)
                  − ½·∂₃₃ψ·(2H·∂₃ψ + C₈r₀ + C₉r₁)²
```

> 注：`det(r) = λ₁λ₂·det(L − ρℓ)` 是**非奇异**的。

### 8. 离散化与实现要点（论文第 10 节）

**自由度**：
- 每**顶点** i：位置 `xᵢ ∈ ℝ³` + 厚度缩放 `ρᵢ ∈ ℝ`（无量纲标量）
- 每**边** j：角度 `θⱼ ∈ ℝ`（弯曲自由度，Grinspun et al. 2006）

**求积**：每个**三角形重心**单点求积，以未变形三角形面积加权。因中面量逐三角形分段常数，`ψ_shell` 也是分段常数 → **求积是精确的**，且**空间离散误差由网格分辨率控制，与 O(h⁵) 的厚度方向截断误差相互独立**。

**离散第二基本形式**：由逐边角度 θⱼ 通过 **libshell**（Etienne Vouga 2019）的 **"MidedgeAngleThetaFormulation"** 计算（匹配 Grinspun et al. 2006）。作者也试过 Sin/Tan 变体，"输出无实质差异"。

**隐式积分**：
- 逐元素 Hessian 通过**取特征值绝对值**变为半正定
- **Gauss–Newton 近似**：省略离散第二基本形式二阶导数的几何 Hessian 项，其余二阶项精确；两者都不影响能量与力
- 时间步进：`Mü + Du̇ + f_int(u) = f_ext(t)`，通过 **IPC**（Li et al. 2020）+ 隐式积分（Baraff & Witkin 1998）求解。约束：双边（钉扎顶点、给定轨迹）与单边（接触）
- **接触使用体积外推的当前厚度曲面**；对 CCD，通过微分中面自由度到 slab 顶点位置的映射获得预测运动

**质量矩阵**（附录 G）：

```
𝔴₀ = h + K̃h³/12 ,  𝔴₁ = −Hh³/6 ,  𝔴₂ = h³/12 + K̃h⁵/80
M_yy = h(1 + K̃h²/12)·C ,   M_ρρ = (h³/12 + K̃h⁵/80)·C ,   M_yρ = −Hh³/6 · C·n
```

其中 `C = A_ijk·ρ_mass/12 · [[2,1,1],[1,2,1],[1,1,2]]`。ζ 的贡献被丢弃（静态凝聚）。**边自由度 θⱼ 不进入质量矩阵**（它们只影响第二基本形式，不影响位置）。

**梯度/Hessian**：**补充材料（52 页）提供完整精确的闭式梯度与 Hessian**，按 9 维参数向量 `q = (a₁₁,a₁₂,a₂₂, ρ, ℓ₁₁,ℓ₂₁,ℓ₁₂,ℓ₂₂)` 分块组织。对称 2×2 矩阵用压缩向量化 `ω = (Ω₁₁, Ω₁₂+Ω₂₁, Ω₂₂) ∈ ℝ³`，使 a-Hessian 块从 4×4 缩到 3×3。

### 9. 支持的材料模型

公式接受**任意各向同性超弹性能 `ψ(F)`** 并继承其性质。论文明确列为即插即用兼容：

- **Stable Neo-Hookean (SNH)**（Smith et al. 2018）
- **S-invariant / lower-invariant 形式**（Smith et al. 2019）
- **基于主伸长的艺术家友好能量**（Xu et al. 2015，基于 Valanis & Landel 1967）
- **补充材料 FD 验证套件用的七种各向同性材料**：StVK、Linear Corotational (LC)、Neo-Hookean (NH)、Symmetric Dirichlet、Symmetric ARAP、Hencky、SNH

**论文实验实际使用**（Table 3）：SNH、LC、StVK

**归约一致性检查**（重要）：
> "当限制到小应变下的 StVK，我们的公式**逐项归约到** [Chen et al. 2018] 的形式。"
> "当厚度自由度冻结（ρ ≡ 1）且弯曲引起的厚度修正（ζ 项）禁用时，我们的能量**归约为 Kirchhoff-Love 壳**。"

> **注意**：**CoVol 未被引用**；Mooney–Rivlin、VIGA、TetGen、材料点法均未出现。体积对比基准是 **Abaqus 风格 C3D10 二阶四面体**。

## 📊 实验结果

### 验证基准

- **体积参考**：Abaqus 记法的 **C3D10**（二阶四面体），厚度方向 1 层单元（m=1）。论文测试过更大 m，对结果无实质影响；也与 C3D20 二阶砖单元对比，结果几乎完全一致
- **交叉验证**：本文的体积 C3D10 实现与 **CalculiX**（自由固体力学库）对照，结果吻合
- **不使用 C3D4**（一阶四面体）：论文测试确认 C3D4 高度不准确，因此不用作参考

### 对比方法

| 方法 | 说明 |
|------|------|
| Volumetric (C3D10) | 体积参考基准 |
| **KL-Shell** (Wen & Barbič 2023) | 标准 KL 壳 |
| **KL-Shell++** (Chen et al. 2018) | 改进参数换算的 KL 壳 |

### 空间收敛性（Cook 膜基准，Fig. 12）

网格从 12 逐级减半到 1.5（**8× 加密跨度**，N = 4, 8, 16, 32 子分），对比细分的 C3D10 参考（N=64）：

- 相对 **L2 位置误差单调下降：55.9% → 30.9% → 11.8% → 3.7%**（观测收敛率 ≈ **1.5**）
- 弹性能量与竖直尖端挠度均收敛到体积极限
- 最细分辨率下归一化尖端挠度 `δ = tip_y·E·t/F = 23.77`，与经典收敛的 Cook 膜参考值 **≈ 23.9 相差 0.5% 以内**

### 曲面静止构型验证（Fig. 13）

三个曲面静止构型，各自内部充气到约 2 倍静止体积（稳定 Neo-Hookean，静态求解）：

| 形状 | 曲率特征 | 相对 L2 误差 |
|------|---------|-------------|
| **球** | 常曲率 | **0.4%**（对 C3D10，+106% 体积） |
| **椭球** | 平滑变曲率 | **< 0.09%**（+108% 体积） |
| **蚂蚁** | 空间变曲率 + 细管结构 | **0.3% ~ 0.5%**（直到 p = 1200 Pa） |

对比了三种体积单元类型：二阶四面体（C3D10）、二阶三角棱柱（C3D15）、减缩积分线性三角棱柱（C3D6R），全部使用与 VC-Shell **相同的中面网格**，故位置误差为精确的逐顶点距离。

> 只有在蚂蚁模型**最极端充气（2.2× 静止体积）**时才出现较大偏差 —— 此时各体积单元类型**彼此之间的分歧量级相当**，且 C3D10 参考本身也无法收敛。这证实了论文第 6 节的说法：**为平直静止形状推导的多项式厚度轮廓，对曲面静止几何仍保持合理准确**。

## ⚠️ 局限（论文第 12 节）

- 能量是按厚度 `h` 的**展开**。对于**厚壳**，可以改用厚度方向数值求积，仍能受益于本文的模态与 `ρ, ζ` 运动学变量
- 本文模拟**面内剪切**，但**不包含横向剪切**（法向方向剪切）
- 不过论文**推导了最低阶横向剪切模态**（第 5 节）；这是 **O(h³) 效应**，与把 Cosserat director 作为**主阶**运动学的方法形成对比
- **保证的边界**：这是**局部最大原理型保证**，对耦合求解器的全局稳定性**并非定理**

## 🩸 可行性分析：体积原理推导的薄壳模型

### 渲染方法
- **类型**：表面渲染 / 体积渲染（物理层）
- **技术**：从 3D 固体力学第一性原理解析推导的薄壳能量 + 厚度本征模态 ansatz（`ρ`, `ζ`）+ 闭式能量/梯度/Hessian

### 视觉质量
- **逼真度**：⭐⭐⭐⭐⭐（**物理正确性上的显著提升** —— 这是本次检索中物理保真度最高的一篇）
- **风格化支持**：不适用（面向物理仿真保真）

### 性能预期
- **帧率**：相比体积仿真快 **2.6× ~ 4.6×**（CPU，多线程）
- **GPU 需求**：论文实现为 CPU（Newton 迭代 + 稀疏线性求解）；移植到 GPU 需自行工程化
- **内存占用**：只存中面网格 + 每顶点 `ρ, ζ`，**远低于体积网格**

### 实现建议
- **着色器复杂度**：不适用（CPU 求解器）
- **管线要求**：需要稀疏线性求解器 + Newton 迭代 + 接触处理（论文用 **IPC**）；论文提供了**可直接实现**的能量/梯度/Hessian 公式，含主伸长率重合时的可去奇点处理
- **推荐度**：✅ **推荐** —— 相比 KL 壳，物理正确性有数量级的提升（泊松收缩从"完全缺失"到"误差 <0.5%"），且仍有 2.6~4.6× 的体积仿真加速比

### 对本库算法 Agent 的落地建议
1. **凡涉及薄壁可变形体包裹流体的场景**（软体水箱、柔性容器、薄膜变形），KL 壳会**系统性低估厚度收缩**，导致**流体-结构耦合的接触几何错误** → 应改用 VC-Shell
2. 实现路径：按论文的 Eq. 11–20 建立 `η(ξ̂)` 的模态展开，**不需要**厚度方向数值求积
3. 注意 **`ρ` 约束**（∫η dξ̂ = 0 中面保持）与**去除主伸长率重合奇点**这两个实现要点
4. 与 **IPC 接触**配合良好（论文实测），可直接沿用现有接触管线
5. 与流体渲染的结合点：**柔体容器中的液体晃动**、**可变形管道/血管内的流动**、**薄膜吹塑成型** —— 这些都需要正确的泊松收缩来预测自由面形状
