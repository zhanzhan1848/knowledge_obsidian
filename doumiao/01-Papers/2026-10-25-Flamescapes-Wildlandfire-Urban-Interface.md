## 核心贡献

> 首个把**语义化的城市三维结构**与**化学驱动的交互式燃烧求解器**耦合起来的野火-城市界面（WUI）火灾模拟框架 —— 建筑物的**每一个语义原子模块（墙板、门、窗、屋顶）都能独立燃烧并消失**，火可以沿着楼层、跨过街道、跨越防火隔离带传播。

1. **物理化燃烧求解器**：基于**化学基的混合 Eulerian–Lagrangian 火焰求解器**，建模材质相关的加热、传导、热解(pyrolysis)、氧化、燃料耗尽与余烬(ember)生成。
2. **四条火蔓延通道**：直接火焰接触、热辐射（ray-based）、余烬输运、显式火焰前沿传播 —— 完整覆盖 WUI 火灾的主导暴露路径。
3. **层次化燃料图 (Fuel Graph)**：把建筑拆成 **atomic modules → wall panels/studs → 完整墙体 → 整栋房屋** 四级层次结构，耦合语义场景结构与求解器的固体燃料网格，支持**子构件级网格退化**（窗先烧掉、然后墙板、然后整面墙）。
4. **程序化城市生成**：从 OpenStreetMap 建筑轮廓 + 街道中心线出发，用 **SDF + WFC (Wave Function Collapse) + SSA** 生成带材质与燃料标注的可燃三维建筑。
5. **体积渲染输出**：最终场交给**体积流体渲染器** (volumetric fluid renderer) 出图。

## 技术方案

### 核心思想

传统火灾模拟（如 FDS）面向的是**均匀介质中的火焰传播**；而真实 WUI 火灾的关键在于**"结构"**——一栋楼不是一团燃料，而是**由不同可燃性/热物性的构件组装起来的层级结构**。火从植被烧到房屋、从房屋烧到房屋，其路径完全由结构决定。

Flamescapes 的洞见：**燃烧的"燃料"应该是带语义的、可独立退化/独立热传导的结构化实体，而不是均匀的体素燃料**。

### 建模管线

**初始化阶段（实线箭头）：**

### 求解器结构：固体-气体混合燃烧

| 组件 | 表示 | 物理过程 |
|------|------|----------|
| **固体燃料** | 体素固体燃料网格 (solid fuel grid) | 热解 + 固体燃烧 → 产生余烬与气态燃料 |
| **气态燃料** | 气体燃料网格 (gas fuel grid) | 气体燃烧 + **火焰前沿传播** |
| **热演化** | — | 通过**平流、对流、传导、辐射**耦合固体与气体 |
| **化学演化** | — | 通过**平流与扩散**处理 |
| **余烬 (embers)** | **粒子系统** | 跨域的**离散输运机制**（离散输运机制） |
| **渲染** | 体积流体渲染器 | 每个更新步输出 |

### 关键技术

| 技术 | 说明 |
|------|------|
| **Chemistry-based Hybrid Eulerian–Lagrangian Solver** | 固体用 Eulerian 体素网格，气体用 Eulerian 网格，余烬与火焰前沿用 Lagrangian 粒子 —— 混合架构兼顾效率与细节 |
| **Hierarchical Fuel Graph** | 四级结构：atomic module → wall panel/stud → wall → house。支持在多个语义/空间分辨率上评估热传导、点火、质量损失 |
| **Ray-based Radiation** | 射线追踪式的热辐射：可**向下和向侧向传热**，但衰减快且被遮挡物阻挡 |
| **Flame-front Particles** | 火焰前沿粒子维持**连贯的火焰形状**，即使在低网格分辨率下火焰仍**附着于燃烧物体** |
| **Ember Particles** | 余烬粒子更分散，能**跨越大距离并绕过遮挡物**输运能量 |
| **Procedural Urban Generation (WFC+SSA+SDF)** | 从真实地理数据生成可燃城市结构 |
| **Sub-component Mesh Degradation** | 按语义层级逐级移除几何（门→窗→墙板→整墙→整栋） |
| **Volumetric Fluid Renderer** | 最终输出通道 |

### 公式

固体燃料的热解与燃烧（化学基模型，示意）：

```math
\frac{\partial (\rho_s Y_i)}{\partial t} + \nabla\cdot(\rho_s \mathbf{u} Y_i)
= -\underbrace{S_i^{\text{pyr}}}_{\text{热解消耗}}
  + \underbrace{S_i^{\text{ox}}}_{\text{氧化生成}}
  + \underbrace{\nabla\cdot(\rho_s \mathbf{D}_i \nabla Y_i)}_{\text{扩散}}
```

辐射传热（射线基）：

```math
q_{\text{rad}}(\mathbf{x}) = \int_{\Omega} I(\mathbf{x}, \omega)\,
\sigma\, T^4\,(\omega\cdot\mathbf{n})\,d\omega
,\qquad
\mathbf{q} = -\nabla \int I\,d\omega
```

火焰前沿与余烬的输运（粒子基）：

```math
\dot{\mathbf{x}}_p = \mathbf{u}_{\text{gas}}(\mathbf{x}_p) + \mathbf{w}_{\text{wind}} + \mathbf{a}_{\text{buoyancy}},
\qquad
T_p \leftarrow T_p + \dot{T}_p\,\Delta t
```

## 实验结论

### 演示场景

| 场景 | 结论 |
|------|------|
| **城市程序化生成** | 从 OSM 生成与真实地理位置相似的城市（俯视图 + 房屋特写） |
| **层次退化可视化** | 建筑级（整墙移除）→ 墙板/立柱级 → **原子模块级（门、窗、屋顶独立燃烧消失）**，并附温度切片图展示内部热量发展 |
| **城市野火时间演化** | 小簇房屋燃烧 → 扩大 → **蔓延至多个街区的房屋群** |
| **风与生物量影响** | 高风速下火线呈**舌状 (tongue-like)** 且产生大量余烬；低风高生物量则**弥散发展、温度更高** |
| **余烬消融** | 开启余烬：风把炽热粒子带到火焰前沿**之前**，引发点火，**甚至能跨越街道这样的燃料隔离带**；关闭余烬：火灾局限本地 |
| **蔓延通道消融** | 仅火焰接触 → 火必须接触建筑表面才蔓延；加辐射 → 立面与屋顶预热，起火更快更持久；去掉火焰接触与辐射 → 火困在植被中不蔓延；仅辐射 → 可跨越植被与建筑的间隙点火；余烬 → 屋顶的非局部飞火点；全开 → 最强最持久 |
| **植被清除对比** | 密集植被提供连续燃料 → 蔓延到建筑并点燃；建筑周围无植被打断燃料连续性 → **阻止点火**（"防御空间"效应） |
| **NIST 实验对比** | 干冷杉树的燃烧演化（点火 → 火焰增长 → 峰值释热），与 NIST 实验对照验证 |

### 关键机制对比表（论文原图结论）

| 机制 | 传热方向 | 衰减 | 遮挡 | 粒子特性 |
|------|---------|------|------|---------|
| **辐射** | 向下 + 侧向 | 快 | 被遮挡物阻挡 | — |
| **火焰前沿** | 主要向上 | — | — | 保持连贯形状，低分辨率下仍附着于燃烧物 |
| **余烬** | 任意方向 | 跨大距离 | **可绕过遮挡物** | 分散，跨域输运 |

## 局限性

- **依赖 OSM 数据质量**：建筑轮廓的语义/材质/燃料标注依赖上游数据，OSM 缺失或错误会直接传导。
- **WFC+SSA 程序化生成是近似的**：生成的结构在几何上合理，但不保证与真实建筑的结构连接方式一致（这会影响传热路径的真实性）。
- **体积渲染成本**：体素燃料网格 + 辐射射线 + 粒子 + 体积渲染，属于重负载，论文未给出实时性数据。
- **验证范围有限**：仅与部分真实燃烧实验（如 NIST 干冷杉）对比。
- **无 arXiv 预印本**：截至 2026-10-25 尚未公开，细节需待 TOG 正式版。

### 🌱 豆苗评注

**这篇最值得借鉴的不是燃烧物理，而是"燃料图"这个数据结构抽象。**

一般的体积渲染火焰模拟中，"燃料"是一个标量场（火势/温度）。Flamescapes 把它升级成**带语义的层级实体** —— 门、窗、墙板、屋顶各有各的热物性和耐久性。这带来一个渲染侧的巨大好处：**退化是几何级的，不是体素级的**。门烧掉之后，**那里就真的有洞**，光线可以穿过去看到室内。这在常规体积渲染里几乎做不到（体素燃料烧光只是变透明，火还在原地飘）。

对**渲染工程**的启发可以提炼成三条：

1. **材质/属性分层（Layered Materials）**：把火焰的颜色、发光强度、烟灰生成率也做成**按燃料类型分发的属性**，而不是全局统一参数。这样不同燃料（木材 / 塑料 / 植被）的火焰颜色和烟量自然不同 —— 这是纯体积渲染很难做出来的真实感。
2. **几何退化与视觉退化解耦**：燃烧时**几何先消失**，火焰和烟**滞后一小段时间**才开始出现在那个位置。这个时间差是真实火场的关键视觉特征 —— 很多 CG 火灾看起来"假"，正是因为火焰和物体是同步消失的。
3. **余烬作为独立的渲染通道**：余烬粒子是**小而亮、会飞、会越过遮挡物**的。这和火焰粒子在**渲染上是完全不同的材质**（余烬偏橙红点状、硬、有运动模糊；火焰是软、体积、向上）。把两者分成不同通道渲染，成本极低但真实感提升明显。

如果要在现有管线里做一个**轻量版**，推荐的最小可行方案：

> 数值求解器（可简化的格子燃烧模型）产出温度场 + 燃料场 + 烟密度场 → 三个场分别驱动**发光通道**（黑体辐射着色）、**吸收/散射通道**（烟，参与 ray marching 的 extinction）、**余烬粒子通道**（独立 additive billboard + 运动模糊）→ 用简单的 ray marching 合成。

这个方案不需要完整的化学模型，但保留了三通道结构，视觉收益占大头。

## 🩸 可行性分析：多通道体积火灾渲染

## 渲染方法
- 类型：体积渲染（主）+ 粒子渲染（余烬，加色）
- 技术：Ray Marching 三通道合成 —— 发光（黑体辐射）/ 吸收散射（烟）/ 加色粒子（余烬）

## 视觉质量
- 逼真度：⭐⭐⭐⭐☆（单场体积渲染能到 4 星；几何退化 + 分层燃料可到 5 星）
- 风格化支持：⭐⭐⭐⭐⭐（黑体辐射着色天然支持风格化调色）

## 性能预期
- 帧率：离线 1–10 fps（256³ 网格，64 步 ray march）；实时需降分辨率 + 半分辨率体积 + 深度感知上采样
- GPU 需求：中–高（显存取决于网格数 × 通道数）
- 内存占用：中（3 个 float 场 @ 256³ ≈ 192 MB/场，注意压缩）

## 实现建议
- 着色器复杂度：中（标准 ray march + 3 通道合成）
- 管线要求：求解器输出层（温度/燃料/烟/余烬）→ 体积纹理 → 渲染 pass → 粒子 pass
- 推荐度：✅（三通道结构是低成本高收益的改进）
