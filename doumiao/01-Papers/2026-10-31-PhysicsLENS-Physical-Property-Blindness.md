# PhysicsLENS: Diagnosing Physical Property Blindness in Video Generation Models

## 核心贡献

> 诊断视频生成模型的**"物理属性盲区"**：模型能生成**看起来合理**的视频，却**完全忽略**场景描述中明示的物理属性（重量、黏度、摩擦）。**47 个匹配场景对中 34 个（72%）忽略了指定属性**，且**在描述里写明属性几乎不改善合理性**。

1. **匹配场景对设计**：保持**相同条件帧与相同任务**，只改变场景描述中的**底层物理属性**——形成严格的 A/B 对照。
2. **7 大物理域标注**：碰撞、重力、动量、摩擦、形变、**流体（fluid）**、因果。
3. **核心发现**：合理外观与属性正确性**脱钩**；模型**在描述中明说属性**只让合理性**轻微下降**（即提示词基本无效）。
4. **规模**：4 个视频生成模型，**400+ 条人工标注**。

---

## 技术方案

### 核心思想

现有视频生成评测**只评"保真度"（看起来对不对），不评"物理准确性"（实际物理对不对）**——因为很多物理属性（重量、黏度、摩擦）是**视觉上被隐藏的**。

本文用**匹配场景对**把"看起来对"和"物理对"解耦：

```
条件帧（相同）+ 任务（相同）
     ├── 场景描述 A："黏稠的液体"  → 生成视频 A
     └── 场景描述 B："稀薄的液体"  → 生成视频 B
                    ↓
        人工标注：哪个视频体现了所述属性？
```

> 💡 **关键结论的严重性**：模型在 47 个场景对中**有 34 个（72%）忽略了明确写出的属性**，而"在提示词中写明属性"只让合理性**略微且不显著地下降**——说明模型**不是没被告知，而是物理属性根本没有进入其表征**。这对流体尤为致命：黏度、密度、表面张力这类属性**完全不可见**，模型只能靠外观统计猜，而猜错时画面依然"像流体"。

### 关键技术

| 技术 | 说明 |
|------|------|
| **匹配场景对** | 固定条件帧与任务，仅改物理属性描述 → 隔离属性变量 |
| **7 域标注体系** | 碰撞/重力/动量/摩擦/形变/**流体**/因果 |
| **人工标注** | 400+ 条，判断"视频是否体现所述属性" |
| **属性盲区 vs 保真度的分离** | 两个正交维度分别评测 |

## 公式

**匹配场景对的属性差分**：

```math
\mathcal{S} = \{(I, T, \phi_1, \phi_2)\},\quad
I = \text{条件帧（相同）},\ T = \text{任务（相同）},\ \phi \neq \phi' \text{为物理属性}
```

**属性忽略率（核心指标）**：

```math
\text{Ignore Rate} = \frac{\#\{\text{未体现所述属性的样本}\}}{\#\{\text{样本}\}}
= \frac{34}{47} \approx 72\%
```

**提示词中明说属性的影响（近零）**：

```math
\Delta\text{plausibility}\big|_{\text{属性明说 vs 未明说}} \approx 0 \quad (\text{不显著})
```

## 实验结论

- **设置**：4 个视频生成模型，400+ 条人工标注。
- **主结果**：
  - **34 / 47**（约 **72%**）的样本中，模型**忽略了明确指定的物理属性**；
  - 在场景描述中**写出该属性**，仅使合理性**轻微下降**且**不显著**。
- **结论**：现有视频生成模型存在**系统性的物理属性盲区**，而非"提示词工程不足"。

---

## 局限性

- 场景来自**公开机器人视频源**，域偏机器人操控，非 VFX 流体。
- 人工标注成本高，规模受限（400+ 条）。
- "合理性"与"属性体现"的判定本身带主观性。
- 4 个模型样本量偏小，未覆盖 Sora / Veo 等最新闭源模型。

## 实现建议

- **实现难度**：低（评测设计，非渲染方法）
- **适用场景**：**流体视频生成模型评测**、**属性可控性研究**
- **推荐度**：✅
- **落地价值**：⭐⭐⭐⭐
- **对流体渲染的直接启发**：
  1. **流体属性是"隐变量"** —— 黏度、密度、表面张力、张力系数都无法从像素直接读出。渲染侧的对应做法是**把它们作为显式可控参数暴露**（Houdini 的 viscosity / Blender Mantaflow 的 viscosity 与 surface tension），而非指望模型隐式理解。
  2. **"明说属性无效"对提示词工程的警示** —— 对生成式流体，**用参数化条件（显式数值输入）比用自然语言描述属性更可靠**。
  3. **可把"匹配场景对"作为流体生成的标准测试单元** —— 同一场景，只改黏度（0.01 / 0.1 / 1.0 Pa·s），看形态差异是否可辨识。若模型无法区分，说明其流体表征是**形态模板记忆**而非物理理解。
