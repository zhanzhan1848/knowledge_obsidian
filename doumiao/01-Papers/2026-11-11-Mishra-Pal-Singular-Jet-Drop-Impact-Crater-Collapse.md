## 核心贡献

> **一句话点题：用 2D 轴对称 DNS 首次厘清了"奇异射流"的形成机制——它源于坑底近圆柱形凹坑（dimple）的形成与快速塌缩，并据此更新了夹带区（entrainment region）的 We–Fr 相图边界。**

1. **用 2D 轴对称 DNS（Basilisk）** 对液滴撞击坑的塌缩过程做高保真模拟，采用**自适应网格加密（AMR）** 捕捉精细流动结构。
2. **实验验证**：直径 3.64 mm 的液滴在常压下，数值结果在不同撞击条件下与实验**吻合良好**。
3. **识别出多种定性不同的凹坑形态**，包括**凹坑下方困住的气泡（entrapped bubble）**。
4. **奇异射流情形的定量结果**：圆柱形凹坑（cylindrical dimple）塌缩期间，得到**困住气泡直径 ~210 μm**、**射流速度 61.7 m/s**。
5. **形态判据**：坑演化中的细微形态变化可区分射流区（jetting regime），奇异射流情形下**坑侧壁与其底部之间的临界角为 109.2°**。
6. **内部流场机理解释**：压力与速度场显示，高射流速度与**近圆柱形凹坑的形成与快速塌缩**相关联；由此产生的压力分布**驱动凹坑底部附近的强向上流动**，而**近乎平行的凹坑侧壁把径向液体运动重定向至轴线**。
7. **扩展到后夹带区（post-entrainment region）**：发现**另一个奇异射流**位于夹带区上边界附近，射流速度达 **63.93 m/s**，形态特征与第一个奇异射流情形相似。
8. **构建相图（regime map）**：覆盖 **Weber 数 100–200**、**Froude 数 45–92**；基于奇异射流形成给出的夹带区**下、上边界更新为**
   $$\mathrm{We} = 45.5\,\mathrm{Fr}^{0.237} \qquad\text{与}\qquad \mathrm{We} = 53.5\,\mathrm{Fr}^{0.251}$$

## 技术方案

### 核心思想

**现象背景**：液滴撞击液面形成的坑（crater）在塌缩过程中有两种命运——通常会在轴心处发生**夹断（pinch-off）奇异性**，形成经典的 Worthington 型射流；而**绕过了夹断奇异性**的那一支，会产生异常细、异常快的射流，被称为**奇异射流（singular-jet）**。这类射流的动力学与常规射流不同：它更细、速度更高，且伴随独特的气体夹带结构。

**方法**：作者用 **Basilisk**（基尔文件基于 Basilisk 框架的 CFD 库）做 **2D 轴对称直接数值模拟（DNS）**，核心是**自适应网格加密**——液滴撞击后的坑壁、凹坑、薄射流与被困气泡都是跨尺度的强梯度结构，均匀网格无法同时解析粗尺度的液滴与细尺度的射流，AMR 保证了这一点。

**验证与参数**：以直径 **3.64 mm** 的液滴在常压条件下为基准，数值结果在**不同的撞击条件**下与实验**吻合良好**——这为后续的机理解读和相图绘制提供了可信度。

**形态多样性**：模拟显示在坑塌缩过程中会形成**定性不同的凹坑形态**（dimple shapes），其中一个关键形态是**在凹坑下方困住一个气泡**（entrapped bubble）。这提示奇异射流的形成路径依赖于坑壁演化历史的"形态记忆"。

**定量标定（奇异射流情形，圆柱形凹坑塌缩）**：
- 困住气泡直径 **~210 μm**
- 射流速度 **61.7 m/s**

**形态判据**：坑演化中的**细微形态变化**（morphological changes）足以区分是否进入射流区。具体的判据是**坑侧壁与坑底之间的角度**：奇异射流情形下该临界角为 **109.2°**。这个角度判据把"是否会产生奇异射流"变成了可从**单帧几何**直接读出的量，对实验与渲染中的实时判别都非常实用。

**机理（本文最重要的科学贡献）**：借助于 DNS 提供的**内部流场**（这是实验难以直接观测的部分），作者指出高射流速度与**近圆柱形凹坑的形成及随后的快速塌缩**直接关联。其力学链条是：
1. 近圆柱形凹坑塌缩产生特定的**压力分布**；
2. 该压力分布**驱动凹坑底部的液体强烈向上（轴向）流动**；
3. **近乎平行的凹坑侧壁**（圆柱形壁）**把原本的径向流动重定向到轴线**；
4. 汇聚的轴向流动被压缩成极细射流 → 速度极高（>60 m/s）→ 形成奇异射流。

也就是说，奇异射流并不主要来自"细颈的收缩"（那是常规 pinch-off 射流），而来自**几何把径向动量转换为轴向动量**的定向机制。

**后夹带区的第二个奇异射流**：作者把模拟推进到**后夹带区（post-entrainment region）**，在那里又发现一个奇异射流，位置接近**夹带区（entrainment region）的上边界**，速度 **63.93 m/s**，形态与第一个奇异射流相似。这说明奇异射流是**可重复出现的机制**，而非偶然。

**相图**：综合 We ∈ [100, 200]、Fr ∈ [45, 92] 的模拟扫描，构建了相图，并把**夹带区的下、上边界依据"奇异射流形成"重新界定**为两条幂律线。这是本文最可直接被工程与实验采用的定量产出。

## 公式

摘要直接给出了两条经验边界式。此外，以下为**示意性**公式（用于表达本文涉及的物理量与本文自述的机理链条）：

**1. 奇异射流的经验相图边界（**摘要原文给出**）**

$$\boxed{\;\mathrm{We}_{\text{lower}}(\mathrm{Fr}) = 45.5\,\mathrm{Fr}^{0.237}\;},\qquad \boxed{\;\mathrm{We}_{\text{upper}}(\mathrm{Fr}) = 53.5\,\mathrm{Fr}^{0.251}\;}$$

两条曲线之间即夹带区（entrainment region），奇异射流在其边界附近形成。

**2. 无量纲数定义（示意）**

$$\mathrm{We} = \frac{\rho\, U^2\, D}{\sigma},\qquad \mathrm{Fr} = \frac{U}{\sqrt{g\,D}}$$

其中 $U$ 为撞击速度，$D$ 为液滴直径，$\sigma$ 为表面张力，$g$ 为重力加速度。摘要未说明相图中 We 与 Fr 所用的特征速度定义，此处为通用示意。

**3. 表面张力主导的长度尺度（示意）**

$$\ell_{\text{cap}} = \sqrt{\frac{\sigma}{\rho g}} \quad(\text{capillary length})$$

此尺度常用于判定射流细颈的粗化（Rayleigh–Plateau）与射流是否在断裂前被拉伸。

**4. 奇异射流的细长比（示意）**

$$\Lambda = \frac{L_{\text{jet}}}{d_{\text{jet}}},\qquad L_{\text{jet}} = \frac{U_{\text{jet}}\, T_{\text{flight}}}{U_{\text{jet}}} = T_{\text{flight}}$$

摘要未给出射流长度与细度的具体测量值，仅给出速度 61.7 m/s 与 63.93 m/s。

**5. 机理链条的示意表达（基于摘要陈述的定性机理）**

近圆柱形凹坑塌缩 → 压力分布 $p(r,z,t)$：

$$p_{\text{base}} > p_{\text{far}} \;\Rightarrow\; \text{凹坑底部强向上流动}\quad (\mathbf{u}_z > 0 \text{ 于底面附近})$$

径向动量的重定向（近乎平行的侧壁）：

$$\mathbf{u} = u_r\,\hat{\mathbf{e}}_r + u_z\,\hat{\mathbf{e}}_z \;\xrightarrow{\ \text{parallel sidewalls}\ }\; \mathbf{u} \approx u_z\,\hat{\mathbf{e}}_z \quad(\text{在轴线附近汇聚})$$

轴向动量汇聚 → 细长射流：

$$\frac{d}{dt}\big(r^2 u_z\big) = 0 \quad(\text{柱坐标下不可压缩流的轴向通量守恒，理想化})$$

$$U_{\text{jet}} \sim \frac{Q}{\pi r_{\text{jet}}^2},\qquad Q = 2\pi \int_0^{r_{\text{jet}}} r\,u_z(r)\,dr$$

（以上为示意性表达，非摘要原文公式。）

**6. 临界角判据（示意）**

$$\theta_c = \angle\big(\text{坑侧壁},\ \text{坑底}\big),\qquad \theta_c = 109.2^\circ \quad (\text{奇异射流情形})$$

$$\theta \gtrsim \theta_c \Rightarrow \text{进入射流区 (jetting regime)}$$

**7. 困住气泡的尺度估计（示意）**

$d_{\text{bubble}} \approx 210\ \mu\text{m}$，与射流速度 $U_{\text{jet}} = 61.7\ \text{m/s}$（奇异射流情形，圆柱形 dimple 塌缩）。

## 局限性

- **仅 2D 轴对称**：无法解析真实三维中的**非轴对称不稳定性**（射流的破碎、卷曲、卫星滴），而这些恰恰决定可视化中射流的最终形态；对渲染与特效制作而言这是重要限制。
- **DNS 代价与分辨率未说明**：AMR 的层级上限、最小网格尺寸、总计算时间与算力开销摘要未给出，难以复现。
- **自由表面算法未说明**：界面捕捉方法（level-set / VOF / immersed boundary）、表面张力处理（CSF / 水平集曲率）摘要未说明。
- **实验对照细节不足**：实验装置、液滴物性（黏度、密度、表面张力具体值）、撞击参数范围、误差量化指标摘要未给出，仅称"吻合良好"。
- **相图仅覆盖有限范围**：We ∈ [100,200]、Fr ∈ [45,92]，两条幂律边界在该区间外的外推有效性未知。
- **两条边界式的拟合不确定度**：回归精度、样本量、判定"奇异射流形成"的数值阈值摘要未说明。
- **临界角 109.2° 的普适性**：该判据在何种撞击条件范围内有效、是否随 We/Fr 变化，摘要未说明。
- **困住气泡与射流速度为单一算例值**：摘要给出的是特定情形（圆柱形 dimple）下的数值，未给出散布或依赖关系。

  - ✅ **实时程序化射流/射流的"物理正确"外观**：用 $U_{\text{jet}} \approx 61.7$–$63.9$ m/s 的速度量级设定射流初速与细长比，避免"看起来不对"的射流。
  - ✅ **作为解析式/降阶模型的标定数据**：把相图边界与临界角拟合进简化的射流生成器（可结合 [[2026-10-31-Masuda-Drop-Decomposition-Cylindrical-Curvature]] 的曲率分析）。
