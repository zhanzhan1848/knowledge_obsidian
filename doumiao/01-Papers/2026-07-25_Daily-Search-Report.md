### 1. Fast VEM Fluid Simulation ⭐ 直接相关

| 字段 | 内容 |
|------|------|
| **标题** | Fast VEM Fluid Simulation |
| **arXiv** | [2607.17725](https://arxiv.org/abs/2607.17725) |
| **发表** | ACM Transactions on Graphics, Vol. 45, No. 4, July 2026 |
| **作者** | Runze Zhang |
| **日期** | 2026-07-20 |

**核心贡献**:
- 提出 FastVEM，一种高效的边界贴合流体模拟框架
- 采用 Virtual Element Method (VEM) 离散化
- 提出 VEM 多项式空间 Particle-in-Cell 方案
- 开发 Galerkin 几何多重网格求解器
- 压力投影阶段加速最高 **100倍**

**技术亮点**:
- 凸性保留的切割网格策略
- 扩散无关的延长算子
- 嵌套、边界感知的网格层次结构
- 支持复杂边界几何

**渲染相关**:
- 边界-流体交互的精确求解
- 高保真流动-边界交互可视化
