## 关键发现

### 🔬 1. DAVOF —— VOF 界面重构的范式转变（2610.38863）

- **首次**在 VOF 中把**面浸润面积分数 $\alpha_f$ 作为被输运状态**，与体积分数 $\alpha_k$ 同步对流
- **闭式单元内恢复法向与位置**：散度定理一次求和得法向、二次应用得平面位置，**无邻居、无迭代**
- **对比**：plicRDF 在平面可精确表示的场上也**不收敛**（误差 $2.5\times10^{-4}$–$3.5\times10^{-3}$，最大值 0.47）；gradAlpha/isoAlpha 停在 $10^{-1}$；DAVOF 达舍入误差（$10^{-13}$）
- **曲率收敛**：参考实现（paraboloid 拟合、重建距离函数）在静态基准上呈**零阶（完全不收敛）**，DAVOF 的一圈二次曲面拟合**收敛**（椭球上 1.55 阶）
- **理论**：面分数精度阶 $q$ 决定法向精度阶；平面界面即使精确定位也只给一阶，**$O(h^3)$ 接近界面的曲面才给二阶**
- **开放问题（作者自述）**："输运中二阶法向"仍是研究目标；回路阶数 = 输入法向阶数
- 🔗 **代码开源**：`github.com/tmaric/TwoPhaseFlow` (branch `davof`)、`github.com/leia-openfoam/leia`

### 🔬 2. 动能线性稳定性理论 (kLST) —— 首次用完整 Boltzmann 算子（2610.38714）

- **首次**将**完整硬球 Boltzmann 碰撞算子**用于壁面约束剪切流的特征值问题，且在**实用雷诺数 $10^2$–$10^5$**（此前全部工作在弛豫模型上）
- 四种算子（硬球/BGK/ES-BGK/Shakhov）**共享同一离散**，可直接对比
- **首次建立动能非模态理论**：含 Chu 扰动能量的能量范数 + **动能 Reynolds–Orr 方程** → 平均剪切是唯一能量源
- **不存在能量稳定性雷诺数**：碰撞在局部平衡不耗散扰动 → 任意 $Re$ 下能量都增长（N-S 的 $Re_{es}=20.7$ 无对应物）；额外增长限于 $O(\mathrm{Ma}\cdot\mathrm{Kn})$
- **精度**：Orr–Sommerfeld 特征值与连续介质吻合到 $10^{-7}$（弛豫模型）/ $10^{-6}$（完整算子）；瞬态增长与 resolvent 范数复现到 **0.1%**
- **解决 Zou et al. (2023) 的非收敛问题**：伪谱对分支交汇处病态模态不敏感
- **关键数值细节**：moment-consistent 速度导数**必需**（否则产生虚假不稳定展向不变模态）；弱壁面条件比强条件收敛快一个数量级

### 🔬 3. PINN 的浮力失效机理 —— $B^2$ 梯度放大（2610.38889）

- **无量纲化是决定性因素**，非网络结构：在**完全相同**的网络/损失/权重/种子下
  - **自由落体标度**（$B=1$）：$Ra\le10^4$ 时 $\overline{Nu}$ 误差 **<1.1%**
  - **热扩散标度**（$B=Ra\cdot\mathrm{Pr}$）：误差 **157%–650%**，$Ra=10^5$ **完全发散**（NaN）
- **机理（核心推导）**：$\mathrm{mom}_v=R-B\theta$ → 平方损失梯度 $\partial\mathcal{L}_v/\partial w \approx 2B^{2}\theta\,\partial\theta/\partial w$ → **浮力系数进入梯度两次**
- **直接梯度测量证实**：$Ra=10^4$ 时热扩散标度的 $y$-动量残差梯度比边界条件梯度**大 $8.35\times10^8$ 倍**，全程不衰减；放大因子 $B^2$ 每升一个 $Ra$ 数量级增两个数量级
- **两个常用缓解手段失效**：稀疏数据同化（$\overline{Nu}$ 误差仍 >600%，且**流拓扑被破坏**、热壁/冷壁热流不满足稳态平衡）；自适应损失加权（可能把浮力主导项压到 $7.8\times10^{-6}$）
- **硬约束的价值**：温度 Dirichlet 软罚项下会收敛到平凡解 $\theta\approx0$

### 🔬 4. 深腔 PINN 的分区评估协议（2610.38814）

- **核心论点：体相速度吻合是不完整的评估**
- 内部速度偏差 5.13%–7.85%，**但采样涡量偏差高达 41.1%–53.1%**（差一个数量级）
- 腔底相对速度偏差 <5%，**但绝对 RMS 低至 $1.255\times10^{-10}U$** —— 信号本身极弱，"看起来对"不等于"被正确解析"
- **压力需分解**：$(e^{\rm global})^2=b_f^2+(e^{\rm shape})^2$；腔底全局 RMS 几乎全由区域偏移主导（形状 RMS 低至 $8.7\times10^{-12}$）
- **配置排名依赖观测量**：$Re=1000$ 的 control 速度偏差最小（5.130%）但涡量偏差最大（53.085%）
- **方法学贡献**：硬约束流函数+深度包络、$1/E$ 残差缩放、区域化平衡采样（50/30/15/5）、SOAP + self-scaled Broyden、参考解自敏感性（0.054%/0.065%/0.000312%）、求导网格诊断
- ⚠️ **作者自述归因不清**：改进工作流是**累积工作流**比较，不隔离区域采样的单独贡献

### 🔬 5. 几何曲率改变液滴破碎机制（2610.39154）

- **曲率不仅降低临界 $Re$，还改变破碎机制本身**
- 三种几何 $\kappa_{\mathrm{F}}=d/R_i$ = 0.52 / 0.72 / 1.04（平面为 0）
- **曲率诱导迁移机制**：$u_\theta\propto 1/r$ 的非线性使液滴内侧面局部速度大于外侧面 → 液滴向内圆柱方向迁移
- 形貌转变：平面**对称二分裂** → Type 1 **不对称 + 1 个卫星滴** → Type 3 **周向细丝 + 多碎片多卫星滴**
- 内部流动：从"颈部对称回流" → "前部回流消失" → "整体周向拉伸流主导"
- **伸长速率斜率**：平面 0.44 → Type 1 1.28 → Type 2 1.96 → **Type 3 4.8**
- **$Re_{\text{cr}}$ 随曲率下降**，但**临界条件下的 $L^{*}_{\max}$ 反而随曲率增大** → 曲率对伸长的影响**不能仅由 $Re_{\text{cr}}$ 下降解释**
- ⚠️ 黏度比与密度比均为 1（简化）；$Re_{\text{cr}}$ 扫描步长仅 0.1；网格敏感性显著（破碎时刻 $R_d/16$ vs $R_d/20$ 差 36%）

### 🔬 6. 可微分 Schwarz + agentic AI 反演（2610.38672）

- **首次**把**拉伸壁法坐标**（$\eta=y/\delta$）用于**含分离/再附着**的薄边界层 Schwarz 耦合，两个子域都保留完整对流–扩散方程
- **完全可微分**（FEniCS + dolfin-adjoint，离散伴随）+ **硬约束反演** → 精度只受数据量与前向离散误差限制
- **跨子域伴随传播**：测量在一个子域、未知在另一个子域
- **双向耦合是必要的**：单向（无反馈）方法在**所有**配置下均未达 1% 目标（收敛到约 $-11.1$）
- **成本**：Schwarz 总 DOF 比单域多 6.3%–7.0%，但**内层网格划分数与 $D$ 无关**
- **LLM/agent 优化器**：
  - 被动（Qwen3-8B，30 次）：一维问题上 **87–88/90 成功**，但**墙钟时间普遍慢于 Brent/Newton/secant**
  - 主动（GPT 5.6 Terra，5 次）：inner 数据 15/15 成功，overlap 数据 14/15 且散布更大
  - **函数基 + agent 扩充库**是最佳路径：75 epoch 达 **0.152%** 误差（仅 2 个基函数项），而 Adam 需 1200 epoch 才达 13.02%
- ⚠️ **"迭代更少 ≠ 墙钟更快"**：实验 4 的 19.8 min 仍贵于 Adam 的 12.9 min
