## 核心贡献

> 为 Richards 方程（变饱和多孔介质流）构造**质量守恒的混合虚拟元（HVEM）**：只有节点水头是全局自由度，每个多边形单元内假设一个 Darcy 通量并凝聚；**单元质量平衡在任意迭代、任意时间步下逐项恒等成立**，且**无需稳定化参数**。

1. **通量构造**：无散部分 + 特定线性散度场（吸收储水项与源项）→ 单元水量平衡**恒等**成立
2. **无稳定化参数**：无散场取**按旋转行为排序的调和多项式**，给出通量参数个数的闭式规则（在规则多边形上推导，在扭曲单元与悬挂节点上数值验证）
3. **Kirchhoff 势的 Darcy 定律**：把传导率从扩散项中移除，同时水头在材料界面保持连续
4. **Kirchhoff 平均传导率** → 静水平衡与重力排水在**任意网格**上**精确**成立
5. **单元算子全部化为边界积分** → 非线性迭代只需节点值

## 技术方案

### 核心思想

**Richards 方程的数值困难**（作者列举）：
- 传导率在干湿土之间**变化几个数量级** → 湿润锋锋利，前锋推进进入近乎不透水介质
- 储水项依赖未知量，且在饱和时**消失** → 方程在该点丧失抛物型
- 重力驱动的流动与压力梯度驱动的同等重要；**分层土壤中重力跨越传导率突变的界面**
- **渗出面（seepage face）**的边界条件事先未知，在给定水头与不透水边界之间**切换**

**质量守恒的既有思路**：Celia et al. 指出把储水写成含水量的增量可保守恒。但本文更进一步，追求**单元级的**恒等守恒。

**核心构造**：
- 全局自由度**只有节点水头**
- 每个多边形单元内假设一个 **Darcy 通量**，凝聚掉
- 通量 = **无散部分** + **特定线性散度场**（后者吸收储水与源）
- → 每个单元的水量平衡在**任意迭代、任意时间步**下**恒等成立**；整个域在收敛时同样成立

**无需稳定化参数的做法**：VEM 的经典问题是虚拟节点自由度不足导致秩亏，需要稳定化项。本文通过**限制无散场的选取**（调和多项式 + 旋转排序）来保证秩充分，从而**完全免除稳定化参数**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **混合虚拟元方法 (HVEM)** | 虚拟节点自由度少，混合化使局部混合问题可解 |
| **Kirchhoff 势** | 在 Kirchhoff 势上写 Darcy 定律 → 传导率不出现在扩散项；水头在材料界面连续 |
| **Kirchhoff 平均传导率** | 使静水平衡与重力排水在任意网格精确 |
| **调和多项式无散场** | 按旋转行为排序；给出通量参数个数的**闭式规则** |
| **单元算子 → 边界积分** | 非线性迭代只需节点值 |
| **集中式储水** | 权重由假设通量提供 |
| **多边形/裁剪网格 + 悬挂节点** | 支持局部加密（cut grid） |
| **Julia 实现** | — |

### 公式

**通量分解**：

$$\bm{q}=\bm{q}_{\text{div-free}}+\bm{q}_{\text{particular}},\qquad \nabla\cdot\bm{q}_{\text{particular}}=\text{（储水项与源项）}$$

**通量参数个数的闭式规则**：无散场取**调和多项式**，按其在旋转下的行为排序 → 规则多边形上可闭式导出，扭曲单元与悬挂节点情形数值验证。

**Kirchhoff 势**：以 $\phi$ 为势（传导率 $\kappa(\psi)$ 依赖压力头 $\psi$），Darcy 定律写成

$$\bm{q}=-\kappa(\psi)\nabla\phi$$

→ 扩散项中不含 $\kappa$，而 $\psi$ 在材料界面连续。

## 实验结论

- **验证工况**：
  - 闭式解（Gardner 土壤稳态流、van Genuchten 土壤非稳态流）
  - 已发表基准
  - **均质边坡**与**分层边坡**上的降雨入渗（独立解交叉验证）
  - 渗出面与局部加密
- **结果**：
  - 水头在多边形网格与局部加密网格上**二阶收敛**，**即使重力主导时也成立**
  - **每个测试都闭合水量收支**
  - **分层边坡**上，沿表层加密带状区域的 cut grid，用**约 40% 的节点数**达到均匀网格两倍加密的精度
  - 秩充分性：规则多边形推导 + 扭曲单元、悬挂节点数值验证

## 局限性

1. 单篇作者工作，方法未经第三方复现
2. **瞬态**为主；长时间大时间步下的稳定性分析有限
3. 剪切变稀/非牛顿本构未涉及
4. 耦合分析（与边坡稳定性）只在结构上「适合」，本文未做实际耦合算例
5. Julia 实现的性能与 OpenFOAM/传统 FE 求解器相比未做基准
6. 渗出面切换的实现细节依赖具体算法，稳健性未系统测试

## 实现建议

- **实现难度**：中（VEM 框架本身复杂，但**不需要稳定化参数**这一点大幅简化实现）
- **预期性能**：二阶收敛；水量收支逐测试闭合；局部加密效率高（40% 节点达到 2 倍加密精度）
- **适用场景**：
  - **降雨入渗 + 边坡稳定性预警**（作者明确的工程动机，早期预警系统需要流速）
  - **非规则几何**（多边形、裁剪网格、悬挂节点）——这是 VEM 的主场
  - 干湿界面剧烈变化的多孔介质
- **落地建议**：若工程代码库是 Julia 生态可直接复用；若是 C++ 系，VEM 的实现门槛偏高，**更务实的路线是移植其「Kirchhoff 平均传导率 + 逐单元恒等守恒」的构造思想**到传统 FE/FV
