## 核心贡献

> 一个**可定向的主动粒子**在**定常的二维多涡流场**中运动，其**实际空间轨迹**竟然勾勒出 Lorenz 式的混沌吸引子

1. 反直觉之处：流场**严格时间无关**，但粒子位置与朝向的耦合构成**三维非线性动力系统**
2. 对合适的粒子形状与游动速度，轨迹自组织为**双叶几何**结构，形似经典 **Lorenz 吸引子**
3. 混沌性证据三重：**结构化的一阶回归映射**、**正的最大 Lyapunov 指数**、**宽带功率谱**
4. 改变游动速度，展现**丰富的动力体制序列**：自推进逐渐突破流线约束并重组粒子运动
5. 结论：内部**朝向自由度**使混沌动力学**在物理空间中直接可见**——单个主动粒子即可在定常流场中描出混沌吸引子

## 技术方案

### 核心思想

经典混沌吸引子画在抽象相空间里。本文把"相空间"实化为 (x, y, θ) 三维——其中 θ 是粒子的自推进朝向。因为流场定常、粒子非惯性，被迫自主运动学构成自治的 3D 非线性系统，可以产生混沌。

### 关键技术

| 技术 | 说明 |
|------|------|
| 多涡定常流场 | 若干静止涡旋构成的流场 |
| 粒子-流场耦合动力学 | 位置-速度-朝向三自由度 |
| 一阶回归映射 | 从轨迹构造 first return map，检查单值性 |
| Lyapunov 指数 | 最大 Lyapunov 指数为正 → 混沌 |
| 功率谱 | 宽带谱 → 混沌而非准周期 |
| 游动速度扫描 | 揭示体制转捩序列 |

## 公式

```math
粒子运动学（非惯性，主动游动）:
  dr/dt = v_swim · n(θ) + u_fluid(r)
  dθ/dt = Ω(θ, r)          (朝向自转 + 流场诱导转矩)
  n(θ) = (cos θ, sin θ)

三维自治系统:
  (x, y, θ)  →  混沌吸引子（在物理空间 x-y 上表现为双叶结构）

混沌判据:
  λ_max > 0                 (最大 Lyapunov 指数)
  first return map 单值且分段线性
  功率谱 S(ω) 宽带（无尖锐主峰）

Lorenz 双叶结构对照:
  经典 Lorenz: ẋ = σ(y - x), ẏ = x(ρ - z) - y, ż = xy - βz
  → 翼片在 z ≈ ρ 附近交替盘旋，形成双叶
```

import numpy as np
from scipy.integrate import solve_ivp

def multi_vortex_velocity(x, y, vortices):
    """定常多涡流场速度（点涡叠加）"""
    u = np.zeros_like(x); v = np.zeros_like(y)
    for (xc, yc, G) in vortices:
        dx = x - xc; dy = y - yc
        r2 = dx**2 + dy**2 + 1e-12
        u += G * (-dy) / (2*np.pi*r2)
        v += G * ( dx) / (2*np.pi*r2)
    return u, v

def particle_dynamics(t, state, vortices, v_swim, omega_body):
    x, y, th = state
    u, v = multi_vortex_velocity(x, y, vortices)
    return [v_swim*np.cos(th) + u, v_swim*np.sin(th) + v, omega_body]

def lyapunov_exponent(traj, dt):

## 实验结论

- **数据集**: 定常二维多涡流场中的单个主动粒子轨迹（9 页 3 图）
- **基线**: 经典 Lorenz 系统（相空间结构对照）
- **结果**:
  - 轨迹形成**双叶几何**，形似 Lorenz 吸引子
  - **一阶回归映射结构化**、**最大 Lyapunov 指数为正**、**功率谱宽带** → 三重证实混沌
  - 游动速度扫描展现**丰富的动力体制序列**：自推进突破流线约束 → 重组粒子运动
  - 核心洞见：**朝向这一内部自由度**足以把定常流场变成混沌发生器

---

## 局限性

- 极简模型（理想点涡、非惯性粒子），无粘性耗散项
- 仅 2D 空间 + 1 维朝向构成 3D 自治系统，推广到真实 3D 复杂流场未验证
- 定量指标（Lyapunov 指数、回归映射）依赖长时间积分精度
- 与真实主动粒子的尺度效应、形状记忆等差异较大
