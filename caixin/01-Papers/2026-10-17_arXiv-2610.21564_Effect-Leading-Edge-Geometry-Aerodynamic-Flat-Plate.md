## 核心贡献

> 在低雷诺数（Re = 1000）下，系统比较**带半球凸起前缘**与**简单平板**的 2D 平板气动性能，给出涡脱落、脱落频率、气动力的对比，为 UAV / UUV 等小型飞行器设计提供依据

1. **问题背景**：平板前缘的几何形状（厚度、曲率）显著影响**流动分离**与**剪切应力**分布，进而影响**非定常气动力**
2. **研究对象**：
   - 简单平板（simple flat plate）
   - 带半球凸起前缘（hemispherical leading-edge curvature）
3. **参数扫描**：
   - 攻角 \(\alpha \in [0°, 25°]\)
   - Re = 1000（低 Re）
4. **关键发现**：
   - **凸起前缘**：涡脱落起始于 \(\alpha = 5°\)
   - **简单平板**：涡脱落延迟到更高 \(\alpha\)
   - **凸起前缘**在 \(\alpha = 0°\) 时 glide ratio = 1
   - **简单平板**在中等攻角（5°/10°/15°）下 glide ratio 更优
   - 高攻角时两种板都出现**多频特性**（multiple frequencies in force coefficients）

---

## 技术方案

### 核心思想

用 2D CFD 模拟在 Re = 1000 下比较两种前缘几何的平板，重点关注**涡脱落起始攻角**与**glide ratio**（升阻比）的折中关系。

### 关键技术

| 技术 | 说明 |
|------|------|
| 2D incompressible CFD simulation | 低 Re 平板绕流 |
| Vortex shedding analysis | 涡脱落起始、脱落频率 |
| Temporal force coefficients | 时序升力 / 阻力系数 |
| FFT spectral analysis | 多频特性检测 |
| Glide ratio evaluation | 升阻比（飞行器性能指标） |
| Parametric α-sweep | 攻角扫描 0°–25° |

### 控制方程

标准的不可压缩 Navier-Stokes：

```math
\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \nu \nabla^2 \mathbf{u}, \quad \nabla \cdot \mathbf{u} = 0
```

### 关键结果

| 几何 | 涡脱落起始 | 高 α 力频谱 | Glide ratio |
|------|-----------|------------|-------------|
| Simple flat plate | 较晚 | 多频 | 中等 α 优 |
| Hemispherical LE | \(\alpha = 5°\) | 多频 | \(\alpha = 0°\) 时 = 1 |

## 实验 / 验证

- **方法**：纯 2D 数值模拟
- **Re** = 1000（低 Re 不可压缩）
- **网格 / 时间步**：未明确给出（应查看原文）
- **结果**：
  - 凸起前缘在板附近形成**更厚的涡区**
  - 多频特性在高 α 时显现（涡-涡相互作用）
  - 升阻比对比揭示**几何-性能折中曲线**

---

## 局限性

- **2D 简化**：未考虑展向（spanwise）三维效应
- **单 Re = 1000**：未扫描 Re 范围
- **单几何**：仅 1 种凸起尺寸（半球），其他曲率半径未涵盖
- **无实验验证**：未与 PIV / 力传感器实测对比
- **网格无关性**：未明确给出 GCI（grid convergence index）分析
