## 核心贡献

> 整理 Luis Vega 一周授课内容：binormal flow 作为三维不可压缩涡丝动力学的 toy model

1. 给出 binormal flow 与 Schrödinger map、1D cubic NLS 之间的等价联系
2. 阐明该 toy model 既能表达漩涡丝真实物理又能给出可分析/数值刻画的低维结构
3. 作为教程笔记，对 turbulence 数学研究入门有较高参考价值

---

## 技术方案

### 核心思想

把三维涡丝中线视作 1D 曲线 X(s,t)，其法平面内的旋转由 binormal 矢量 B = T × T_{ss}/|T_{ss}| 给出时间演化 → 1D 演化方程，其方程形式耦合 1D cubic NLS 与 2D Schrödinger map。

### 关键技术

| 技术 | 说明 |
|------|------|
| 局部诱导近似 (LIA) | V = Γ κ B 单参数形式 |
| Schrödinger map 联系 | 复数化 X' 后视为 map(R, C²) |
| 1D cubic NLS 逼近 | 沿小尺度近似的可积结构 |
| 解析解谱分析 | 解的存在性 / blow-up 现象 |

---

## 公式

```math
∂_t X = Γ κ B   (LIA / binormal flow)
X_t ~ i ε² X_{sss} + small terms (curvature expansion)

对应 1D cubic NLS:
i ψ_t + ψ_{ss} + μ |ψ|² ψ = 0
```
