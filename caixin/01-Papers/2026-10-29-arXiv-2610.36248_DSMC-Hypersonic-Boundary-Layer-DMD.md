## 核心贡献

> 首次证明 **DSMC 的有限粒子随机涨落场本身可作为可测量的扰动输入**，在**不施加任何入口波、壁面信号、模态形状或扰动谱**的前提下，通过 DMD 直接反演出 LST 全部模态量（频率、波数、相速度、模态位置、放大包络），实现「数据驱动的失稳动力学」而非「给定扰动的响应分析」。

1. **把「感受性（receptivity）幅度」从「预设量」变成「可测量量」**：LST/DNS/实验在给定扰动后能给出成熟描述，**唯独感受性输入的幅度是猜的**。本文指出 DSMC 中压力/密度/温度/速度的有限体积采样本质上是有限分子样本，其涨落水平由粒子权重决定——这是一个**内禀的、可复现的扰动源**。
2. **粒子权重作为独立的数值控制参数**：改变 DSMC 粒子数可在**不改变时间平均边界层**的前提下设定**可预测的有限粒子噪声本底**。这就把「扰动幅度」与「平均流态」解耦了。
3. **DMD → LST 量的一一映射**：DMD 特征值给频率与时域增长/衰减，模态场给波数/波长/相速度/壁法向结构/包络；沿边界层轨迹 $y=y_e(x)$ 提取模态迹线再做 FFT，识别主空间频率。
4. **LST 降级为「事后检验」而非「输入」**：LST 中性曲线（Ozgen et al.）在数据提取**之后**才使用，仅用于检验 DSMC 导出的结构是否落在第二模态带内。
5. **可推广性论证**：同一 DSMC-DMD 流程可用于**没有可靠模态先验**的场景——稀薄前缘、激波层–熵层相互作用、钝体效应、壁面运动耦合等连续介质稳定性假设不完整的非平衡绕流。

## 技术方案

### 核心思想

DSMC 是玻尔兹曼方程的动理学求解器，气体由计算粒子的运动与随机碰撞表示。有限体积内采样到的宏观量是**有限分子样本**，涨落水平取决于该样本所代表的独立分子状态数。计算粒子权重（每个计算粒子代表的真实分子数）即控制这一采样水平。

### 关键技术

| 技术 | 说明 |
|------|------|
| DSMC 求解器 | SMILE-DSMC；Variable Hard Sphere (VHS) 碰撞模型；majorant frequency 碰撞采样格式 |
| 数据驱动模态分析 | Dynamic Mode Decomposition (DMD)，秩 $r=30$，$M=1000$ 快照 |
| 事后稳定性检验 | LST 中性曲线（Ozgen et al. Mach 6 平板结果） |
| 平均流验证 | 零压力梯度可压缩 Blasius 相似解（Crocco 形式）+ Howarth–Dorodnitsyn 变换 |
| 涨落量化 | 逐点 RMS + 有限频带滤波 RMS（20–100 kHz） |

### 计算与采样参数

| 项目 | 值 |
|------|-----|

## 公式

### 1. DMD 线性推进算子

```math
\mathbf{q}_{k+1}\approx\mathbf{A}\mathbf{q}_{k}
```

```math
\begin{gathered}
\mathbf{X}=[\mathbf{q}_{1}\ \mathbf{q}_{2}\ \cdots\ \mathbf{q}_{M-1}],\qquad
\mathbf{Y}=[\mathbf{q}_{2}\ \mathbf{q}_{3}\ \cdots\ \mathbf{q}_{M}],\\
\mathbf{X}=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{*},\qquad
\tilde{\mathbf{A}}=\mathbf{U}^{*}\mathbf{Y}\mathbf{V}\boldsymbol{\Sigma}^{-1},\qquad
\tilde{\mathbf{A}}\mathbf{W}=\mathbf{W}\boldsymbol{\Lambda}.
\end{gathered}
```

保留秩 $r=30$，完整模态 $\boldsymbol{\Phi}=\mathbf{U}\mathbf{W}$。

### 2. 离散特征值 → 连续时间行为（关键映射）

```math
\Omega_{j}=\frac{\ln(\lambda_{j})}{\Delta t_{\rm snap}}=\sigma_{j}+i\omega_{j}
```

```math
\sigma_{j}=\frac{\ln|\lambda_{j}|}{\Delta t_{\rm snap}},\qquad
\omega_{j}=\frac{\theta_{j}}{\Delta t_{\rm snap}},\qquad
\omega_{j}^{*}=\frac{\omega_{j}}{2\pi}
```

### 3. 涨落场的时频重建

```math
u^{\prime}(x,y,t)=\text{Re}\left(\sum_{j}\hat{u}_{j}(x,y)\,e^{i\,\omega_{j}t}\right),
\qquad \hat{u}_{j}=[\boldsymbol{\phi}_{j}]_{u}
```

### 4. 局部 RMS 涨落定义

```math
\bar{q}=\frac{1}{N_{t}}\sum_{t=1}^{N_{t}}q_{t},\qquad
q^{\prime}_{\rm rms}=\left[\frac{1}{N_{t}}\sum_{t=1}^{N_{t}}\left(q_{t}-\bar{q}\right)^{2}\right]^{1/2}
```

```math
\%\left(q^{\prime}_{\rm rms}\right)=100\,\frac{q^{\prime}_{\rm rms}}{\bar{q}}
```

### 5. 有限频带滤波（实用测量带定义）

```math
H_{m}=\begin{cases}1, & 20\ \mathrm{kHz}\le\omega_m^*\le 100\ \mathrm{kHz}\\ 0, & \text{otherwise}\end{cases},
\qquad
q^{\prime}_{B,t}=\mathcal{F}^{-1}\{H_{m}Q_{m}\}_{t}
```

### 6. 粒子采样噪声标度律（自洽性检验）

```math
\frac{q^{\prime}_{\rm rms,coarse}}{q^{\prime}_{\rm rms,5B}}
\approx\sqrt{\frac{FNUM_{\rm coarse}}{FNUM_{5B}}}
=\sqrt{\frac{2.88\times10^{11}}{8.525\times10^{10}}}=1.84
```

### 7. 可压缩 Blasius 相似方程（Crocco 形式）

```math
C=\frac{\rho\mu}{\rho_{e}\mu_{e}}=g^{\sigma-1},
\qquad f^{\prime}(\eta)=\frac{u}{U_{e}},\quad g(\eta)=\frac{T}{T_{e}}
```

```math
\left(Cf^{\prime\prime}\right)^{\prime}+ff^{\prime\prime}=0
```

```math
\left(Cg^{\prime}\right)^{\prime}+Pr\,fg^{\prime}+Pr\,C(\gamma-1)M_{e}^{2}\left(f^{\prime\prime}\right)^{2}=0
```

边界条件：$f(0)=0$，$f'(0)=0$，$g(0)=T_w/T_e$，$f'(\infty)=g(\infty)=1$。

### 8. 广义拐点判据（可压缩拐点条件）

```math
\frac{d}{dy}\left(\rho\frac{dU}{dy}\right)=0
\quad\Longleftrightarrow\quad
\frac{d}{d\eta}\left(\frac{f^{\prime\prime}}{g^{2}}\right)=0
```

### 9. LST 法向模态（对照组）

```math
\mathbf{q}^{\prime}(x,y,t)=\mathrm{Re}\left\{\hat{\mathbf{q}}(y)\,A(x)\,
\exp\left[i\left(\alpha x-\omega t\right)\right]\right\}
```

```math
\lambda_{x}=\frac{2\pi}{\alpha},\qquad c_{p}=\frac{\omega}{\alpha}
```

### 10. DMD 模态的 LST 量分解

```math
\mathbf{q}^{\prime}(x,y,t_{k})\approx\mathrm{Re}\left\{\sum_{j}b_{j}\,\boldsymbol{\phi}_{j}(x,y)\,
\exp(\Omega_{j}t_{k})\right\}
```

```math
\boldsymbol{\phi}_{j}(x,y)=\hat{\mathbf{q}}_{j}(y;x)\,\mathcal{A}_{j}(x)\,\exp[i\theta_{j}(x)]
```

```math
\alpha_{j}=\frac{d\theta_{j}}{dx},\qquad
\frac{d\ln\mathcal{A}_{j}}{dx}=\text{局部空间增长/衰减}
```

### 11. 沿边界层轨迹的模态迹线与空间频率

```math
s_{j}(x)=\mathrm{Re}\left[\boldsymbol{\phi}_{j}(x,y_{e}(x))\right],
\qquad
\theta_{j}(x)=\arg[\hat{u}_{j}(x,y_{e}(x))],\quad
a_{j}(x)=|\hat{u}_{j}(x,y_{e}(x))|
```

```math
\lambda_{x,j}=\frac{1}{\kappa_{x,j}},\qquad
\alpha_{j}=2\pi\kappa_{x,j},\qquad
c_{p,j}=\omega_{j}^{*}\lambda_{x,j}
```

### 12. N 因子型包络（DMD 类比）

```math
N(x,\omega^{*})=\int_{x_{0}}^{x}-\alpha_{i}(\xi,\omega^{*})\,d\xi,\qquad
e^{N(x,\omega^{*})}=\frac{A(x,\omega^{*})}{A_{0}(\omega^{*})}
```

```math
E_{j}(R)=\frac{\mathcal{A}_{j}(R)}{\mathcal{A}_{j}(R_{0})},\qquad
N_{j}(R)=\ln E_{j}(R)
```

## 实验结论

### 平均流验证

- 粗算例与 5B 算例**均复现同一层流可压缩 Blasius 型边界层**（$x=30$ 与 $100$ mm 处 $T$ 与 $U_x$ 剖面）
- 粗算例粒子数约为 5B 的 1/4，**平均层流剖面已收敛**
- 广义拐点层：$Y_i^{*}=y\sqrt{Re_x}/x\approx 12.6$

### 有限粒子涨落本底（自由流采样点 $(x,y)=(1,2)$ mm）

| 量 | 平均值 | 粗算例 RMS（宽带） | 5B RMS（宽带） | 粗算例 RMS（20–100 kHz） | 5B RMS（20–100 kHz） |
|---|---|---|---|---|---|
| $p'_{\rm rms}$ [Pa] | 828.2 | 4.465 (0.54%) | 2.421 (0.29%) | 0.568 (0.07%) | 0.284 (0.03%) |
| $\rho'_{\rm rms}$ [kg/m³] | $5.58\times10^{-2}$ | $2.47\times10^{-4}$ (0.44%) | $1.37\times10^{-4}$ (0.25%) | $3.60\times10^{-5}$ (0.06%) | $1.47\times10^{-5}$ (0.03%) |
| $u'_{\rm rms}$ [m/s] | 860.57 | 0.553 (0.06%) | 0.290 (0.03%) | 0.075 (0.01%) | 0.054 (0.01%) |
| $T'_{\rm rms}$ [K] | 50.00 | 0.150 (0.30%) | 0.083 (0.17%) | 0.020 (0.04%) | 0.010 (0.02%) |

**粒子数一致性检验**：实测粗/5B 宽带 RMS 比 = **1.84（压力）、1.80（密度）、1.91（速度）、1.81（温度）**，与理论值 1.84 高度吻合 → 证实涨落由粒子采样主导，而非平均流改变。

**实用噪声水平**：5B 算例在 20–100 kHz 有限带下的压力涨落为 $p'_{\rm rms}/\bar p = 0.03\%$。

### DMD 提取的 LST 量（代表性 $\omega^*=247$ kHz 密度模态）

| 量 | 提取值 |
|---|---|
| 维数频率 $\omega_j^{*}$ | **246.86 kHz**（完全由 DMD 特征值给出，未由稳定性计算强制） |
| 主流向空间频率 $\kappa_{x,j}$ | **0.3165 cycles/mm** |
| 波长 $\lambda_{x,j}$ | **3.16 mm** |
| 波数 $\alpha_{j}$ | **1.99 rad/mm** |
| 相速度 $c_{p,j}$ | **≈ 780 m/s** |

采样带 20 kHz–10 MHz，Nyquist 5 MHz，远高于目标第二模态带 $\omega^*=100$–500 kHz。

## 局限性

1. **秩敏感性**：DMD 秩固定为 $r=30$，作者明确将秩敏感性作为**局限而非唯一性主张**处理。
2. **N 因子只是「类比」**：$N_j(R)=\ln E_j(R)$ 是从模态包络提取的空间幅度度量，**与真正的转捩预测 N 因子不同**，不含 LST 增长率。
3. **单点采样**：涨落测量为单格点（$0.05\times0.05$ mm）DSMC 采样，非实际探头响应或飞行仪表模型；文中已说明「实用压力测量带宽远低于 10 MHz，感测面积为毫米量级」。
4. **流动范围有限**：仅 Mach 6 平板层流边界层，无激波入射、无钝体、无壁面运动。
5. **计算成本高**：主算例 5×10⁹ 粒子、3840 MPI rank、采样步 65–70 万步。
6. **LST 对照基于他人已发表结果**（Ozgen et al.）重新换算，而非本文自行求解中性曲线。

## 实现建议

- **实现难度**：中–高（DSMC 计算成本极高，数据分析本身不难）。
- **预期性能**：DMD 分析部分极快（$1501\times63$ 场 × 1000 快照，秩 30）；成本几乎全在 DSMC 主算例。
- **适用场景**：
  - 稀薄/高超速气动中**感受性幅度的定量标定**
  - 无可靠模态先验的非平衡绕流稳定性分析
  - 数据驱动稳定性评价方法学示范
- **落地建议**：
  1. **最小复现路径**：用开源 DSMC 代码跑 Mach 6 平板（约需 $10^8$ 粒子量级起步）→ 存宏观场快照 → 标准 DMD（`PyDMD`）→ 沿 $y_e(x)$ 提迹线做 FFT 读主空间频率 → 与 $\lambda_x$、$c_p$ 公式对齐
  2. **验证顺序**：先复现可压缩 Blasius 平均剖面 → 再验证 RMS 粒子标度律（粗/细比 ≈ $\sqrt{FNUM_{\rm coarse}/FNUM_{\rm fine}}$）→ 最后做 DMD 模态提取与 LST 对照
  3. **关键检查点**：DMD 特征值到连续频率的换算 $\omega_j^*=\ln(\lambda_j)/(2\pi\Delta t_{\rm snap})$——采样间隔错了频率就全错
  4. **可直接迁移的方法论**：把「有限粒子权重 → 噪声本底 → 可复现扰动幅度标度」这一思路，用于任何**随机数/蒙特卡洛型求解器**（SPH 的粒子噪声、随机 DNS 扰动、RANS 入口湍流合成），把「感受性幅度」从拍脑袋变成可测量量
  5. 对本知识库的启发：与 [[Vortex-Step-Method]]（2610.37313）同属「**先给收敛性/可重复性规范，再谈物理结论**」的方法论路线
