## 核心贡献

> 提出基于集合卡尔曼反演（EKI）的数据驱动框架，对 LES 的谱涡粘性闭合进行在线无导数标定，可处理多维参数空间。

1. **谱涡粘性闭合的在线标定**：使用 EKI 在 LES 运行中迭代更新 16 维波数依赖涡粘性函数。
2. **无导数框架**：相比传统梯度优化，EKI 仅需前向模型运行，无需雅可比矩阵。
3. **数据驱动多参数闭合**：相比传统单标量涡粘系数（如 Smagorinsky），该方法刻画整个谱空间。

---

## 技术方案

### 核心思想

将谱涡粘性参数化为波数依赖函数 $\nu(k)$（16 维向量）。每个 EKI 迭代：
- 将候选参数集合并行传入粗分辨率 LES
- 与 DNS 参考能谱在 LES 解析波数范围内比较
- 通过集合统计更新参数以最小化谱不匹配

### 关键技术

| 技术 | 说明 |
|------|------|
| 谱涡粘性闭合 | 涡粘性是波数函数 $\nu(k)$，而非空间局域量，更适合各向同性湍流 |
| EKI（集合卡尔曼反演） | 源自数据同化领域，用于反问题的无导数贝叶斯优化 |
| 强制 2D 湍流 | 测试场景为周期性强制 2D 湍流 |
| 谱空间收敛度量 | 比较 LES 与滤波 DNS 在谱空间的差异 |

## 公式

\`\`\`math
\nu(k): \text{16-dimensional parameterized spectral viscosity function}
\`\`\`

谱闭合模型：通过最小化
$$
\mathcal{L} = \sum_k \|E_{\text{LES}}(k) - E_{\text{DNS}}(k)\|^2
$$
迭代更新参数向量。

---

## 实验结论

- **测试场景**: 强制 2D 湍流（DNS 提供参考谱）
- **基线**: 固定参数谱粘性 / 简单常值涡粘
- **结果**: EKI 在线标定能有效降低谱不匹配，标定后的 LES 谱与滤波 DNS 一致
- **优势**: 无导数、易并行、可扩展到更高参数维度

---

## 局限性

- 仅在 2D 强制湍流上验证，未测试 3D 和壁湍流
- 依赖 DNS 参考谱，实际复杂几何难以获得
- 参数化为 16 维有限基底，限制了表达能力

---

## 实现建议

- **实现难度**: 中
- **预期性能**: 与传统 LES 同一数量级运行成本，增加集合运行开销
- **适用场景**: 周期性 / 同质湍流 LES；可扩展至地球系统模型中的次网格参数化
- **代码建议**: 基于 JAX/PyTorch + LES 求解器实现 EKI 主循环
