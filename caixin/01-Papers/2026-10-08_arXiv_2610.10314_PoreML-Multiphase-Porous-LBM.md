## 核心贡献

> 统一多孔介质多相流机器学习研究的开源框架：GPU-LBM 求解器 + 3.3TB 数据集 + 评估协议

1. **GPU-native LBM 求解器**：基于格玻尔兹曼方法的孔隙尺度两相流模拟器，已验证解析解与已发表实验
2. **大规模数据集**：3.3 TB / 560 模拟 / 158,546 时间步，覆盖合成结构与 micro-CT 真实几何 + 不同润湿性与黏度比
3. **统一学习与评估协议**：一步预测 + 自回归滚动评估，物理一致性专属指标，并提供合成→真实结构的迁移挑战

---

## 技术方案

### 核心思想

孔隙尺度多相流（CO₂ 储能、燃料电池、芯片封装）的 ML 研究受限于缺乏统一数据与评估协议。PoreML 提供端到端流水线：LBM 生成数据 → 多场景数据集 → 多架构模型统一评测。

### 关键技术

| 技术 | 说明 |
|------|------|
| GPU-native LBM | 大规模孔隙网络两相流求解器 |
| micro-CT 几何 | 真实材料结构的孔隙尺度数据 |
| 多润湿性 + 多黏度比 | 覆盖 CCUS、燃料电池等真实工况 |
| 自回归滚动评估 | 模拟实际预测场景，避免单步误差累积 |
| 物理一致性指标 | 接触角保持、质量守恒、相界面位置等 |
| 迁移挑战 | 合成→真实、不同尺寸域的可迁移性 |

---

## 实验结论

- **数据集**: 3.3 TB / 560 模拟 / 158,546 步（合成结构 + micro-CT 几何）
- **基线**: 5 种不同架构模型
- **结果**: 框架提供统一对比，未给出单一最优模型结论（旨在建立研究基础）

---

## 局限性

- 主要关注两相流，三相流（油/气/水）未涵盖
- 物理一致性指标仍以统计量为主，尚未涉及严格守恒律硬约束
- 迁移到全新物理场景（极端润湿性、新材料）能力待评估
