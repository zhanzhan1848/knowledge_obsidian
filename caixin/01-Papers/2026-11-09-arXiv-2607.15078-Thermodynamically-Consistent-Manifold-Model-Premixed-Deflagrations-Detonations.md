## 核心贡献

> 提出一套基于流形（manifold）的湍流燃烧模型，通过迭代过程确保模型与流动求解器之间的**热力学状态完全一致**，从而在单一框架内同时准确描述预混燃烧的**爆燃（deflagration）与爆轰（detonation）**，克服了现有依赖低马赫微扰或查表 ZND 爆轰、却缺乏热力学一致性的方法在预测温度、活性基团与源项分布上的缺陷。

1. **迭代式热力学一致性流程**：在流形模型与流动求解器之间迭代，使局部热力学状态（温度、密度、组分）与热化学状态严格匹配
2. **单一框架同时覆盖爆燃与爆轰**：不依赖低马赫微扰假设，因此无需为爆轰另设模型
3. 验证表明该模型**一致优于现有方法**，在广泛的压缩火焰工况下均成立
4. 复现关键量：温度、活性自由基（radical species）分布、源项（source term）分布
5. 为旋转爆轰发动机（RDE）等**超音速燃烧系统**的 LES 提供统一工具与理论基础

## 技术方案

### 核心思想

预混可压缩火焰的建模难点在于**热化学状态与局部热力学状态之间的强耦合**。火焰中每个网格单元的实际热力学状态（温度 T、密度 ρ、压力 p）决定了该处能达到的化学组成与反应速率；而热化学状态又反过来决定热力学状态如何演化。传统的**流形（manifold）方法**把复杂的多组分化学简化为少数几个低维参数（通常取混合分数与温度，或一个反应进度变量），从而让 LES 负担得起。但现有的流形模型存在一个致命缺陷：**流形上的化学状态与求解器中的热力学状态往往不一致**。

具体地说，现有做法有两类问题：
- **低马赫微扰类模型**：假设流场是"基态 + 微扰"，化学反应主要改变热力学状态而不显著改变密度。但这个假设在爆轰中失效——爆轰中密度与压力变化剧烈且强耦合。
- **查表 ZND 爆轰模型**：用一维 ZND 结构查表给出爆轰波后的状态，但这种表通常不满足完整的热力学闭合方程组，与求解器的状态方程可能冲突。

本文的做法是**在流形与求解器之间插入一个迭代的一致性过程**：每一步（或若干步）内，检查流形给出的状态与求解器当前持有的（T, ρ, p, 组分）是否满足状态方程与热力学关系；不满足则调整流形参数或做修正，直到一致。作者称之为"完全一致（fully consistent）"的热力学状态。

这样做的结果是：流形不再是一个"近似查表"，而是求解器状态方程组的**闭合解**，因此无论流动是亚音速爆燃还是超音速爆轰，模型都能给出自洽的密度、温度与源项。

### 关键技术

| 技术 | 说明 |
|------|------|
| **流形（manifold）降维化学** | 把多组分化学投影到低维参数空间，大幅降低 LES 成本 |
| **迭代式热力学一致性** | 在流形与求解器间迭代求解，使 (T, ρ, p, 组分) 满足状态方程组 |
| **ZND 查表的替代** | 不依赖无一致性的查表，直接由流形保证闭合 |
| **源项闭合** | 由一致性状态计算化学反应源项（质量、能量、组分） |
| **单一框架处理 DDT** | 爆燃→爆轰过渡在同一模型内自然发生 |
| **LES 验证矩阵** | 一维算例 + 高保真 RDE-like 数据 |

## 摘要要点

> Accurate modeling of compressible premixed flames, encompassing both deflagrations and detonations, remains a significant challenge for predictive Large Eddy Simulation (LES) due to the strong coupling between the thermochemical state and the local thermodynamic state. This work presents a manifold-based turbulent combustion model that ensures a fully consistent thermodynamic state between model and flow solver through an iterative procedure. The framework reproduces critical quantities including temperature, radical species, and source term profiles, addressing limitations of existing approaches that rely on low-Mach perturbations or tabulated ZND detonations without thermodynamic consistency. Validation is performed against one-dimensional and high-fidelity RDE-like data, demonstrating that the thermodynamically consistent model consistently outperforms existing approaches across a broad range of compressible flame regimes - including both deflagration and detonation. The results highlight the importance of fully accounting for the thermodynamic state to achieve accurate predictions. By capturing both deflagrative and detonative behavior within a single framework, the model provides a unified, versatile tool for LES of high-speed reacting flows and offers a foundation for future studies of compressible reacting flows, including applications to rotating detonation engines and other supersonic combustion systems.

## 公式 / 理论要点

```math
% 预混燃烧控制方程（守恒形式，LES 滤过）
\partial_t(\bar\rho \bar Y_k) + \nabla\cdot(\overline{\rho \mathbf{u} Y_k})
  = \nabla\cdot(\bar\rho \bar D_k \nabla\bar Y_k) + \bar\omega_k, \qquad k=1,\dots,N_s
\partial_t(\overline{\rho e}) + \nabla\cdot(\overline{\rho \mathbf{u} e} + \overline{p\mathbf{u}})
  = -\nabla\cdot\overline{\mathbf{q}} + \nabla\cdot(\overline{\tau\cdot\mathbf{u}}) + \sum_k \overline{h_{s,k}\bar\omega_k}

% 理想气体状态方程（一致性的判据）
p = \rho R T \sum_k \frac{\bar Y_k}{MW_k}

% 流形参数化：热化学状态由少数参数决定
\mathbf{Y} = \mathbf{Y}(\mathbf{z}), \qquad
\mathbf{z} = (z_1, z_2, \ldots, z_{N_p}), \quad N_p \ll N_s
% 常用参数：混合分数 / 反应进度变量 / 焓-温度关系

% 流形与求解器的一致性条件（迭代求解）
\begin{cases}
p(\rho, T, \mathbf{Y}(\mathbf{z})) = p_{\text{solver}} \\
e(\rho, T, \mathbf{Y}(\mathbf{z})) = e_{\text{solver}} \\
\rho(\rho, T, \mathbf{Y}(\mathbf{z})) = \rho_{\text{solver}}
\end{cases}
% 迭代更新 z 直到残差收敛

% 简化闭合关系：混合分数模型下的温度-焓耦合
\bar h = \bar h(\bar Y_F), \qquad \bar T = T(\bar Y_F)
% 一致性流程保证了在爆轰区该关系与状态方程同时成立

% 燃烧源项（由一致状态导出）
\bar\omega_k = \dot{\omega}_k\big(\bar T, \bar p, \bar Y_k\big), \qquad
\dot\omega_{\text{energy}} = \sum_k \bar h_{s,k}\bar\omega_k
```

## 实验与结果

- **算例/数据集**: 一维预混火焰算例；高保真 **RDE-like（旋转爆轰发动机类）** 数据
- **对比基线**: 现有流形/燃烧模型 —— 依赖低马赫微扰的方法；使用无热力学一致性查表 ZND 爆轰的方法
- **主要结果**:
  - 迭代式一致性流程使模型与求解器间的热力学状态**完全一致**
  - 准确复现**温度、活性自由基（radical species）、源项分布**三项关键量
  - 在包括爆燃与爆轰在内的**广泛压缩火焰工况**下，**一致优于**现有方法
  - **单一框架**同时捕捉爆燃与爆轰行为，无需切换模型
  - 为旋转爆轰发动机（RDE）与超音速燃烧系统的 LES 奠定基础

## 局限性

- **迭代带来的计算代价**：每步（或每若干步）求解一致性非线性方程组，对 LES 内层时间步的推进效率构成压力；摘要未给出相对现有方法的算例成本对比
- **流形维数与适用域**：低维流形在远离训练域的工况（极端压力、贫燃/富燃极端、富氢燃料）可能失效，需重建流形
- **化学机理依赖**：流形基于某一详细化学机理构建，机理的不确定性会传递到 LES 结果
- **一维 + RDE-like 验证**，未系统展示三维全尺度算例的定量能力
- 摘要未披露一致性迭代的**收敛判据与残差量级**，工程复用时难以判断收敛质量
- 湍流-化学相互作用（tabulation 加权、亚格子火焰模型）在本工作中的处理方式未在摘要中说明

## 实现建议

- **实现难度**: 高 — 需要同时掌握详细化学机理、流形构造（PCA/化学计量）、可压缩 LES 求解器与热力学一致性求解
- **预期性能**: 一致性求解增加每步开销；但省去 ZND 查表与多套模型的维护成本；LES 相比 DNS 的成本优势依然巨大（这是本工作的主要卖点）
- **适用场景**:
  - **旋转爆轰发动机（RDE）**、超音速燃烧、冲压发动机燃烧室的高保真 LES
  - 预混火焰的爆燃→爆轰（DDT）过渡研究——单一框架的优势在此最明显
  - 工业燃烧器（炉窑、燃气轮机）燃烧场的热-化学耦合预测
  - **可作为数值方法的强检验基准**：温度/源项剖面的精确匹配要求求解器同时正确处理可压缩性、能量方程与化学源项耦合
- **可复用要点**:
  1. **"迭代一致性"作为闭合模型的通用范式**：任何"降阶模型 + 主求解器"的耦合（化学流形、热力学、辐射模型、多相流相变模型）都可以照此插入一个一致性迭代层，把"近似闭合"升级为"严格闭合"
  2. **状态方程组作为闭合判据**：一致性不是靠惩罚项逼近，而是**精确求解方程组**——这是数值上更干净的做法，值得迁移到其他物性耦合问题（如超临界流体的 [[2611.09831]] EoS 兼容性问题）
  3. **"单一框架覆盖多工况"的设计目标**：避免为不同流动状态维护多套模型，这在工程代码维护上是巨大优势
  4. **流形 + 源项闭合的组合**：为 LES 中昂贵化学的降维提供了一套经验证的范式，与 [[2512.19936 GIMLET]] 属于同一"结构性保证优于拟合精度"的方法论
