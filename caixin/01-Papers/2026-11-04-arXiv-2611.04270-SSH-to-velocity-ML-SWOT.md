## 核心贡献

> 在 **1.5 km 分辨率的 LLC4320 全球海洋模拟**上训练 **U-Net 编码器-解码器**，从 **SSH + 环境数据**直接预测**完整速度矢量**，并在 **50 m 深度**取得 **RMSE = 0.049 m/s**（比地转近似**低 29%**），相对涡度相关系数 **0.93**（地转近似仅 0.75），且能产生**非零辐散度**（相关 0.66）—— 地转近似按定义辐散度为零。更关键的是：**U-Net 正确再现跨尺度能量级联的谱能量通量，而地转近似会错误表征该级联**。

1. **超越平衡态限制**：传统方法受**地转/循环地转平衡假设**限制，在 SWOT 可观测的 $<50$ km 尺度上失效（Rossby 数 $Ro=U/(fL)$ 在强锋面、涡旋、西边界流、赤道区可达 $O(1)$）。
2. **U-Net 并不天然优于地转** —— 这是本文最重要的"负面"发现：**标准 U-Net 与地转近似无异**。必须通过特定的训练策略才能泛化。
3. **四个关键训练策略**（消融实验结论）：
   - **(a) SSH 梯度优于原始 SSH** 作为输入；
   - **(b) 风应力 (wind stress) 是总速度预测最有用的协变量**；
   - **(c) 加入 SST 的收益随季节变化**；
   - **(d) 在损失函数中加入涡度与辐散度项可提升精度**。
4. **泛化能力的四个必要条件**：**旋转与裁剪增强 (augmentation)**、**预测相对地转的偏差 (departure from geostrophy)** 而非绝对速度、**涡度/辐散度惩罚项**、**适度容量 (moderate capacity)**。
5. **物理一致性评估**：不止看 RMSE，还看**涡度、辐散度、涡度-应变联合分布**，以及**谱动能通量**。
6. **能量级联的诊断价值**（本文最有流体力学意义的结论）：比较真实速度、地转速度与预测速度的**谱能量通量**，显示**地转近似错误地表征跨尺度能量级联**，而 U-Net 能再现它。

## 技术方案

### 核心思想

**问题**：卫星测高给出 SSH，但速度难以反演。水平动量方程：

$$\frac{\partial\boldsymbol u}{\partial t}+\boldsymbol u\cdot\nabla\boldsymbol u+f\hat{\boldsymbol z}\times\boldsymbol u=-g\nabla\eta+\boldsymbol r$$

其中 $\boldsymbol r$ 为残余项（摩擦、未解析垂向结构等）。保留非线性平流、忽略时间导数与残余项得**稳态非线性平衡**；写成自然坐标 $(V,\hat s,\hat n)$：

$$V\frac{\partial V}{\partial s}=-g\frac{\partial\eta}{\partial s},\qquad \kappa V^2+fV=-g\frac{\partial\eta}{\partial n}$$

第二式即**梯度风 (gradient wind) 平衡**；当曲率项 $\kappa V^2$ 小时退化为地转。**因此即使在平衡动力学内，SSH 梯度也无法唯一确定速度** —— 还需要流线几何、流向、动力学区制的信息。

**非平衡运动**（线性/有限振幅内重力波、内潮、近惯性运动）叠加在 SSH 上，与中尺度、次中尺度在波长上**重叠**。单个快照 $\eta(x,y,t_0)$ 无法给出时间导数、波动相位、垂向模态结构、平衡/非平衡分量划分 —— **两个物理上不同的速度场可以对应几乎相同的 SSH 快照**。这种非唯一性**不能靠更灵活的回归模型消除**，只能靠物理假设、统计先验、训练数据或额外观测来正则化。

## 公式

```math
% ===== 地转近似（基线）=====
\boldsymbol u_g=\frac{g}{f}\hat{\boldsymbol z}\times\nabla\eta
=\left(-\frac{g}{f}\frac{\partial\eta}{\partial y},\ \frac{g}{f}\frac{\partial\eta}{\partial x}\right)

% ===== 水平动量方程 =====
\frac{\partial\boldsymbol u}{\partial t}+\boldsymbol u\cdot\nabla\boldsymbol u
+f\hat{\boldsymbol z}\times\boldsymbol u=-g\nabla\eta+\boldsymbol r

% ===== 梯度风（循环地转）平衡 =====
V\frac{\partial V}{\partial s}=-g\frac{\partial\eta}{\partial s},
\qquad
\kappa V^2+fV=-g\frac{\partial\eta}{\partial n}

% ===== Rossby 数（适用性判据）=====
\mathrm{Ro}=\frac{U}{fL}
\qquad
\text{当 }\mathrm{Ro}\sim 1\ \text{时非线性平流成为领头项；赤道 } f\to 0 \text{ 时地转式奇异}

% ===== 关键结果 =====
\text{50 m 速度: }\mathrm{RMSE}_{\rm speed}=0.049\ \mathrm{m\,s^{-1}}\quad(-29\%\ \text{vs 地转})
\text{相对涡度相关: }0.93\quad(\text{地转 } 0.75)
\text{辐散度相关: }0.66\quad(\text{地转 } \equiv 0)

% ===== 谱动能通量（能量级联诊断）=====
E(k)=\frac12\int|\hat{\boldsymbol u}(\boldsymbol k)|^2\,\delta(\boldsymbol k-\boldsymbol k')\,d\boldsymbol k',
\qquad
\Pi(k)=\text{谱能量通量}
% 地转近似：\Pi(k)\ \text{错误}；U-Net 预测：\Pi(k)\ \text{与真实一致}
```

```python
import torch
import torch.nn as nn

class UNet(nn.Module):
    """U-Net 编码器-解码器：SSH(+梯度) + SST + 风应力 -> 水平速度 (u,v)"""
    def __init__(self, in_ch=5, out_ch=2, base=32):
        super().__init__()
        def block(i, o):
            return nn.Sequential(nn.Conv2d(i, o, 3, padding=1), nn.BatchNorm2d(o),
                                 nn.ReLU(inplace=True),
                                 nn.Conv2d(o, o, 3, padding=1), nn.BatchNorm2d(o),
                                 nn.ReLU(inplace=True))
        self.enc = nn.ModuleList([block(in_ch, base), block(base, base*2),
                                  block(base*2, base*4)])
        self.dec = nn.ModuleList([block(base*4+base*2, base*2),
                                  block(base*2+base, base)])
        self.out = nn.Conv2d(base, out_ch, 1)

    def forward(self, x):
        skips = []
        for e in self.enc:
            x = e(x); skips.append(x); x = nn.functional.max_pool2d(x, 2)
        x = nn.functional.interpolate(x, size=skips[-1].shape[-2:], mode='bilinear')
        for i, d in enumerate(self.dec):
            s = skips[-(i+2)]
            x = d(torch.cat([x, s], 1))
        return self.out(x)

def geostrophic(ssh, g=9.81, f=None):
    """地转基线：u_g = (g/f) z x grad(eta)"""
    deta_dy, deta_dx = np.gradient(ssh, axis=(1, 2))
    u_g = -g/f * deta_dy
    v_g =  g/f * deta_dx
    return np.stack([u_g, v_g], -1)

def loss_with_physical_penalties(pred, target, ssh_grad, lam_vort=0.1, lam_div=0.1):
    """数据损失 + 涡度/辐散度惩罚项（消融显示可提升精度）"""
    l_data = nn.functional.mse_loss(pred, target)
    # 涡度/辐散度由速度梯度算得
    du_dy = torch.gradient(pred[..., 0], dim=1)[0]
    dv_dx = torch.gradient(pred[..., 1], dim=2)[0]
    vort = dv_dx - du_dy
    div  = du_dy + dv_dx
    l_phys = lam_vort*(vort**2).mean() + lam_div*(div**2).mean()
    return l_data + l_phys

def random_rotation_crop(field, rng):
    """旋转 + 裁剪增强 —— 泛化的必要条件之一"""
    k = rng.integers(4)
    field = np.rot90(field, k, axes=(1, 2))
    H, W = field.shape[1:3]

    y0 = rng.integers(0, H-h); x0 = rng.integers(0, W-w)
    return field[..., y0:y0+h, x0:x0+w]
```

## 实验结论

- **数据集**：LLC4320 全球海洋模拟（1.5 km），pre-SWOT Cape Basin 提取，$11.8°$–$15.8°$E、$41°$–$45°$S，逐小时场。
- **基线**：地转近似（$f$-平面）；文献前作（Sinha & Abernathey 2021、Xiao et al. 2023、NeurOST 等）。
- **结果**：
  - **50 m 速度**：最佳模型速度 RMSE = **0.049 m/s**，比地转近似**低 29%**；
  - **相对涡度**：相关系数 **0.93**（地转近似 0.75）；
  - **辐散度**：相关系数 **0.66**（地转近似按定义为 0）；
  - **标准 U-Net 与地转近似无异** —— 必须靠以下策略才能泛化：旋转/裁剪增强、**预测地转偏差**、涡度/辐散度惩罚、**适度容量**；
  - **四项消融结论**：SSH 梯度 > 原始 SSH；风应力是最有用协变量；SST 收益随季节变化；加入涡度与辐散度损失提升精度；
  - **谱动能通量**：地转近似**错误表征跨尺度能量级联**，U-Net 能**正确再现**；
  - 采用"直接预测速度矢量"而非"平衡/非平衡分解"，因为次中尺度下平衡分量难以干净分离。

## 局限性

- **训练在模拟数据上、评估也在模拟数据上**（后期留出时段），**未用真实 SWOT 观测验证** —— 论文明确指出这是通往 SWOT 应用的"路径"，而非已完成的成果。
- **存在性限制（论文强调的诚实声明）**：两个物理上不同的速度场可对应几乎相同的 SSH 快照 → 速度从 SSH **并非严格可辨识**；ML 的成功依赖训练分布、内波振幅、纬度、Rossby 数、SSH 噪声、目标定义、以及**验证数据是否与训练数据共享平衡假设**。
- **单一区域**（Cape Basin）、单一模拟（LLC4320）、单一分辨率（1.5 km）；未做跨海盆/跨分辨率泛化。
- **未做 3D 速度场重建**，只做水平速度（表层与 50 m）。
- U-Net 仍可能学到**区域特定的相关性**而非普适物理映射。
- 谱能量通量的"正确再现"在**训练区域内**成立；跨区域泛化未验证。

## 实现建议

- **实现难度**：✅ 中等。U-Net 是标准组件；真正的工作在**数据准备**（LLC4320 提取、SSH 梯度计算、地转偏差目标构造）与**物理一致性评估**（涡度/辐散度/谱通量）。
- **预期性能**：
  - 训练：LLC4320 单区域逐小时场，1.5 km 网格；U-Net 基础通道 32；单 GPU 可训；
  - 推理：毫秒级/窗口；
  - **注意**：这是"代理模型"成本极低而传统反演（地转 + 涡度反演）成本也低的场景 —— 价值不在速度而在**能给出地转给不出的辐散度与正确级联**。
- **适用场景**：
  - ✅ SWOT 任务的**速度场快速反演**（含非平衡成分）
  - ✅ 海洋能量级联的诊断（地转近似会误导）
  - ✅ 作为**物理一致诊断工具**（涡度/辐散度/谱通量），而非纯黑盒预测
  - ❌ 不适合跨海盆/跨数值模拟的直接迁移
- **落地建议**：**对流体力学读者最有价值的不是这个模型，而是"谱能量通量作为检验指标"的做法** —— 用它来检验任何 ML/代理模型的物理正确性，比 RMSE 有信息量得多。其次，"预测**相对基线**的偏差而非绝对量"是提升泛化的通用技巧，建议迁移到其他 ML-for-CFD 任务（如 PINN 的基线解残差学习）。
