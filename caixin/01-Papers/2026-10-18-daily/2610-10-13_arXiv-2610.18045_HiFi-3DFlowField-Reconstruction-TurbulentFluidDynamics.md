## 核心贡献

> 将湍流流体动力学先验（连续性方程、Navier-Stokes 约束）嵌入到深度学习重建框架中，从稀疏或粗粒度数据重建高保真 3D 湍流场。

1. **物理驱动重建**：不再依赖纯数据驱动的 GAN / Diffusion 模型，而是用 PDE 残差作为额外损失约束。
2. **3D 全场重建**：从 2D 切片或低分辨率 3D 场重建完整 3D 湍流速度场。
3. **高效替代 DNS / 实验测量**：相比 DNS / PIV 实验显著降低获取成本。

---

## 技术方案

### 核心思想

将湍流物理（Navier-Stokes 动量方程 + 不可压连续方程）作为软约束嵌入重建损失：

$$
\mathcal{L} = \mathcal{L}_{\text{data}} + \lambda \mathcal{L}_{\text{PDE}}
$$

其中 PDE 损失包括动量残差和连续性残差。

### 关键技术

| 技术 | 说明 |
|------|------|
| 物理驱动深度学习 | PDE 残差作为损失约束 |
| 3D 卷积架构 | 处理体积湍流数据 |
| 稀疏采样重建 | 从 2D 切片 / 稀疏点云重建全场 |
| Navier-Stokes 约束 | 动量方程 + 不可压约束的自动微分实现 |

---

## 公式

Navier-Stokes 动量残差：

```math
\mathcal{R}_m = \frac{\partial u_i}{\partial t} + u_j \frac{\partial u_i}{\partial x_j} + \frac{1}{\rho}\frac{\partial p}{\partial x_i} - \nu \nabla^2 u_i
```

不可压约束残差：

```math
\mathcal{R}_c = \frac{\partial u_i}{\partial x_i}
```

PDE 损失：

```math
\mathcal{L}_{\text{PDE}} = \|\mathcal{R}_m\|^2 + \|\mathcal{R}_c\|^2
```

## 实验结论

- **数据集**: 标准湍流基准（forced HIT、channel flow、Taylor-Green vortex 等）
- **基线**: 双线性 / 双三次插值；纯数据驱动 3D CNN / U-Net
- **结果**:
  - 物理驱动方法在能量谱恢复上显著优于纯数据驱动
  - 高波数（耗散区）特征保持更好
  - 对稀疏输入的鲁棒性更强

---

## 局限性

- 自动微分计算 PDE 残差增加显存开销
- 对超长时序演化（>10 时间单位）的稳定性未充分验证
- 主要针对简单几何（立方体 / 平板），复杂几何扩展性待研究

- **实现难度**: 中高（需要自动微分 + 3D CNN + PDE 残差）

- **适用场景**: 实验测量加速、稀疏传感器数据重建、湍流数据增广
- **开源工具**: PyTorch + PhiFlow / DeepXDE 可作起点
