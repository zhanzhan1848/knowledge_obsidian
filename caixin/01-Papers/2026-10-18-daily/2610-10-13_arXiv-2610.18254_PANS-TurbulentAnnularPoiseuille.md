## 核心贡献

> 在湍流环状 Poiseuille 流（换热器典型工况）中，验证 PANS（Partially-Averaged Navier–Stokes）方法作为 RANS–LES 桥接方案相对于传统 DNS / 解析基准的精度与计算成本。

1. **方法验证**：PANS 方法对内壁横向曲率（η = Rᵢ/Rₒ）影响的捕捉效果与 DNS 基准对比。
2. **尺度分辨模拟**：填补 RANS 不能解析瞬态涡结构、LES 又过于昂贵的中间地带。
3. **工程应用导向**：针对热交换器等工程典型工况，评估 PANS 在精度-成本权衡上的实用性。

---

## 技术方案

### 核心思想

PANS（Partially-Averaged Navier–Stokes）通过控制参数 fₖ、fε 来调节"被解析"和"被模拟"的湍动能比例：
- fₖ → 1：等价于 RANS（全场模拟）
- fₖ → 0：等价于 LES（全场分辨）

这样可以在不显著增加计算成本的前提下，按需解析关键涡结构。

### 关键技术

| 技术 | 说明 |
|------|------|
| PANS 模型 | 在传统 k–ε 模型基础上引入 fₖ、fε 控制参数 |
| Annular Poiseuille 流 | 内/外壁横向曲率 η = Rᵢ/Rₒ |
| DNS 基准 | 已有文献提供的直接数值模拟结果作为参考 |
| 横向曲率修正 | 内壁曲率影响湍流结构，PANS 需捕捉 |

## 公式

PANS 控制方程（动量方程）：

```math
\frac{\partial \bar{u}_i}{\partial t} + \bar{u}_j \frac{\partial \bar{u}_i}{\partial x_j} = -\frac{1}{\rho}\frac{\partial \bar{p}}{\partial x_i} + \frac{\partial}{\partial x_j}\left[(\nu + \nu_t)\frac{\partial \bar{u}_i}{\partial x_j}\right]
```

PANS 涡黏性（带 fₖ 控制）：

```math
\nu_t = f_k \frac{k^2}{\varepsilon}
```

未分辨动能比例：

```math
k = f_k k_{u}, \quad \varepsilon = f_\varepsilon \varepsilon_{u}
```

其中 kᵤ、εᵤ 为完全未分辨的湍动能/耗散率。

## 实验结论

- **数据集**: 已有 DNS 文献提供的湍流环状 Poiseuille 流基准（η 多种）
- **基线**: DNS 结果（高精度参考）；传统 k–ε RANS（低精度对照）
- **结果**:
  - PANS 在精度上显著优于标准 RANS
  - 计算成本远低于 LES/DNS
  - 对内壁横向曲率效应的捕捉与 DNS 趋势一致

---

## 局限性

- 仅在环状 Poiseuille 流上验证，未推广到其它复杂几何
- PANS 参数 fₖ、fε 的最优选择仍依赖经验
- 未给出与 LES 在相同精度下的直接计算成本对比
