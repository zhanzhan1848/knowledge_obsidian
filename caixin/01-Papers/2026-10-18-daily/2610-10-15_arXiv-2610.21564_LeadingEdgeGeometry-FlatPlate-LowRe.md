## 核心贡献

> 在低雷诺数（Re=1000）下系统比较了半球形前缘曲率（凸起）与简单平板前缘的涡脱落、升阻力特性，给出小型 UAV / 水下载具的设计参考。

1. **前缘曲率效应**：凸起前缘在低 Re 下产生更厚的涡层分离区，5° 攻角即出现涡脱落（平板前缘则延迟）。
2. **多频分量**：高攻角下平板出现多个涡脱落频率。
3. **设计指导**：低 Re 工况下，简单平板在中高攻角（5°–15°）的滑翔比优于凸起前缘；零攻角则相反。

## 技术方案

### 核心思想

低雷诺数下平板绕流的分离行为对前缘几何极敏感。通过 2D 数值模拟对比凸起前缘与简单平板在不同攻角下的涡脱落特性，目标是小型 UAV / 水下载具的低 Re 巡航设计。

### 关键技术

| 技术 | 说明 |
|------|------|
| 2D 数值模拟 | 低 Re 平板绕流 |
| 攻角扫描 | 0° – 25° |
| Re = 1000 | 低雷诺数巡航工况 |
| 涡脱落频率分析 | FFT / 时序信号 |

## 公式

升力系数 / 阻力系数：

```math
C_L = \frac{F_L}{\frac{1}{2}\rho U^2 c}, \quad C_D = \frac{F_D}{\frac{1}{2}\rho U^2 c}
```

滑翔比：

```math
G = \frac{C_L}{C_D}
```

斯特劳哈尔数：

```math
St = \frac{f_s c}{U}
```

## 实验结论

- **数据集**: 2D 平板绕流（凸起 vs 简单前缘）
- **基线**: 简单平板前缘
- **结果**:
  - 凸起前缘在 5° 攻角出现涡脱落，简单平板则在更高攻角才脱落
  - 高攻角下平板出现多个涡脱落频率（多模态）
  - 0° 攻角：凸起前缘 G=1，优于平板
  - 5°–15° 攻角：平板前缘 G 优于凸起
