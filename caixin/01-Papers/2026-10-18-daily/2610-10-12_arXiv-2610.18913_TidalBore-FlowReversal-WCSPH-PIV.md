## 核心贡献

> 通过 PIV 实验 + WCSPH 数值模拟多帧分析，明确指出潮汐涌潮（tidal bore）的流动反转分类必须**显式依赖参考系**——局部反转与全局反转需明确区分。

1. **多帧测量方法**：将 PIV（粒子图像测速）扩展到时间序列多帧分析，捕捉潮汐涌潮传播过程中的瞬态流动反转。
2. **WCSPH 数值验证**：使用 Weakly Compressible SPH 方法复现实验，给出与 PIV 一致的局部反转特征。
3. **参考系显式分类**：当河水流量在涌潮通过后未完全反向时，潮汐涌潮的"流动反转"必须分类为局部而非全局反转。

## 技术方案

### 核心思想

潮汐涌潮是河流逆流传播的非线性激波状涌浪（step-like surge）。在涌潮通过时，局部区域可能发生流动反转，但全局河流动量可能仍保持原方向。本研究通过结合实验和 SPH 模拟，提出显式的参考系分类方案。

### 关键技术

| 技术 | 说明 |
|------|------|
| PIV 多帧测量 | 高速摄像 + 互相关算法，跟踪时间序列速度场 |
| WCSPH | 弱可压 SPH，自由表面与激波天然适合 |
| 参考系分类 | 区分局部反转（laboratory frame）和全局反转（river frame）|
| 激波跟踪 | 涌潮前沿位置随时间的传播曲线 |

## 公式

SPH 粒子近似（密度求和）：

```math
\rho_a = \sum_b m_b W(r_{ab}, h)
```

动量方程（弱可压形式）：

```math
\frac{du_a}{dt} = -\sum_b m_b \left(\frac{p_a}{\rho_a^2} + \frac{p_b}{\rho_b^2}\right) \nabla_a W_{ab} + \nu \nabla^2 u_a + F
```

状态方程（弱可压 Monaghan 形式）：

```math
p = \frac{c_0^2 \rho_0}{\gamma}\left[\left(\frac{\rho}{\rho_0}\right)^\gamma - 1\right]
```

## 实验结论

- **数据集**: 实验室尺度潮汐涌潮通道 + 现场观测
- **基线**: 单帧 PIV 测量（历史方法）
- **结果**:
  - 多帧分析显示流动反转是**时空局部**现象，非全局
  - WCSPH 复现了 PIV 观察的局部反转结构
  - 全局河流动量在某些工况下不发生反转

---

## 局限性

- 实验室尺度与现场真实尺度仍存在显著差距
- WCSPH 对湍流的解析精度受限（亚格子模型未充分讨论）
- 仅在 2D 模拟中进行，3D 效应（横向二次流）未涉及
