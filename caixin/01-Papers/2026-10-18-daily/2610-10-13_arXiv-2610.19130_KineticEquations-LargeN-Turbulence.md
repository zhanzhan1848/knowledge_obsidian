## 核心贡献

> 将大 N 展开技术应用于强耦合远平衡场论，导出含动量依赖相互作用的 O(N) 对称矢量模型和 SYK 类模型的**动力学方程**，揭示这些模型与流体湍流的深层数学相似性。

1. **大 N 动力学方程**：证明 O(N) 矢量模型 + SYK 类模型的动力学满足标准动力学方程，散射幅由推迟传播子给出。
2. **湍流类比**：建立强耦合场论与流体湍流的非平庸对应，扩展 Navier-Stokes 湍流的理论框架。
3. **跨学科方法**：将统计物理（动力学方程）工具引入到湍流研究。

---

## 技术方案

### 核心思想

流体湍流理论长期受困于非线性项的处理。强耦合场论中发展出的大 N 展开 + 准经典近似技术，可用于推导有限温度/远平衡的动力学方程。本研究将这一框架应用于：
- O(N) 矢量模型（带任意动量依赖相互作用）
- SYK（Sachdev-Ye-Kitaev）类模型

并明确这些动力学方程在数学结构上与流体湍流的对应关系。

### 关键技术

| 技术 | 说明 |
|------|------|
| 大 N 展开 | 1/N 为小参数的控制性展开 |
| 准经典近似 | 高维极限下主导动力学 |
| 动力学方程（Kinetic equation）| 粒子分布函数的演化方程 |
| 推迟传播子 | 散射幅的计算 |
| 强耦合场论 | O(N) / SYK 模型 |

## 公式

O(N) 矢量模型的动力学方程（粒子分布函数 f(p, t)）：

```math
\frac{\partial f(\mathbf{p})}{\partial t} = \mathcal{C}[f] = \frac{1}{2}\int d\mathbf{p}_2 d\mathbf{p}_3 d\mathbf{p}_4 \, |\mathcal{M}|^2 \delta^4(\text{energy-momentum}) \left[f_3 f_4 - f_1 f_2\right]
```

散射幅：

```math
|\mathcal{M}|^2 \propto G_R(\omega, \mathbf{k})^2
```

其中 G_R 是模型的推迟传播子。

与流体湍流的类比（Kraichnan 模型）：

```math
\frac{\partial u_\alpha(\mathbf{k})}{\partial t} = M_{\alpha\beta\gamma}(\mathbf{k}) \sum_{\mathbf{p}+\mathbf{q}=\mathbf{k}} u_\beta(\mathbf{p}) u_\gamma(\mathbf{q}) - \nu k^2 u_\alpha(\mathbf{k}) + f_\alpha(\mathbf{k})
```

## 实验结论

- **数据集**: 解析推导（无直接数值实验）
- **基线**: Boltzmann 方程；弱耦合微扰论
- **结果**:
  - 大 N 极限下 O(N) 模型严格满足动力学方程
  - SYK 类模型的散射幅由推迟传播子给出
  - 强耦合场论可作为流体湍流的玩具模型

---

## 局限性

- 纯理论工作，缺乏直接 CFD 应用案例
- 类比性结论需要进一步量化验证
- 大 N 极限在标准 Navier-Stokes 湍流中并不直接适用
