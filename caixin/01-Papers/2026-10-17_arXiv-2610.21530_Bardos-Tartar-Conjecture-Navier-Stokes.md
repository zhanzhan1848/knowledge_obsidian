## 核心贡献

> **证明** Bardos-Tartar 猜想在二维情形下成立，并推广到 Guo-Titi 的**超粘性 (hyperviscous)** NSE；同时揭示 NSE 解的**黏度敏感性**——初值要么对所有粘度 \(\nu>0\) 均可向后延拓，要么仅对**零测集**的粘度可延拓

1. **Bardos-Tartar 猜想（2D）**：
   - **内容**：在任意给定正时刻 \(t>0\)，**周期边界条件 + 时无关外力**下，2D NSE 解集合在强 \(L^2\) 范数下**稠密**于零均值无散度向量场 Hilbert 子空间
   - **状态**：**已证明**
2. **超粘性 NSE 推广**（Guo-Titi）：同样的稠密性结论
3. **黏度敏感性**：
   - 任意给定初值，要么
     - (i) 对**所有 \(\nu > 0\)** 可向后延拓；或
     - (ii) 仅对**零测集**的 \(\nu\) 可延拓
   - (i) 情形下，初值与外力必须**实解析**（属于 \(D(e^{\sigma A})\)，\(\sigma > 0\)，A 为 Stokes 算子）
4. **不稳定结果**：(i) 在扰动下**极端不稳定**——任意初值扰动两个 Fourier 模式即可破坏 (i) 性质

## 技术方案

### 核心思想

把 NSE 解集稠密性问题转化为**傅里叶 / 谱空间的几何分析**：每个傅里叶模式都是独立的演化单元，Bardos-Tartar 猜想等价于证明解空间在谱意义下"填满"所有可能初值。

### 关键技术

| 技术 | 说明 |
|------|------|
| Spectral / Fourier analysis | 傅里叶模式解耦 |
| Stokes operator A | 谱问题基础 |
| Real-analytic initial data | 实解析类 \(D(e^{\sigma A})\) |
| Backwards uniqueness | 向后唯一性（黏度敏感性） |
| Hyperviscous extension | \((-\Delta)^\alpha u\) 项推广 |
| Perturbation instability | 微扰敏感性 |
| Lebesgue-null set | 零测集拓扑论 |

### 控制方程

2D/3D 不可压缩粘性 NSE（周期边界）：

```math
\partial_t u + (u \cdot \nabla) u = \nu \Delta u - \nabla p + f, \quad \nabla \cdot u = 0
```

**超粘性推广**：
```math
\partial_t u + (u \cdot \nabla) u = -\nu (-\Delta)^\alpha u - \nabla p + f
```

### 主要定理（数学陈述）

**定理 1（Bardos-Tartar 2D）**：
\[
\overline{\{u_t : u \text{ solves 2D NSE at time } t\}}^{L^2} = L^2_{\sigma, \mathrm{div}}
\]

**定理 2（超粘性推广）**：对 \(\alpha \geq 1\) 同样成立。

**定理 3（黏度敏感性）**：任意 \(u_0\) 满足 (i) 或 (ii)。

**定理 4（不稳定）**：\(\forall u_0, \forall \delta > 0, \exists u_1^{(2)} \in B_\delta(u_0)\) 使得 \(u_1\) 满足 (ii)。

## 局限性

- **2D 局限**：主要结论仅对 **2D** 有效；3D NSE 是**千禧问题**之一，本工作未触及
- **周期性边界**：实际物理边界条件下的稠密性未涵盖
- **不直接给出构造**：证明存在性，不显式构造稠密序列
- **应用范围**：作为基础数学结论，对**工程应用**无直接数值算法贡献

## 笔记

**@墨鱼丸 实现建议**：本工作为**纯数学理论**，对**工程 CFD**无直接借鉴价值，但对**算法设计哲学**有启发：
- **黏度敏感性定理**：在数值算法中，应意识到 NSE 解对**网格黏性 / 人工粘性 / 数值格式粘性**的极端敏感性——微小数值扰动可能导致解的**根本性偏离**
- **超粘性推广**：为 LES / 超粘性正则化模型提供数学基础（\(\alpha = 1, 2\) 等）
- **实解析初值**：在实际仿真中，初值通常不严格实解析，但**光滑性假设**仍可为**自适应网格 / 自适应时间步**提供数学依据
- **对算法的启发**：
  - 用谱方法时需注意**数值粘性**对模式的衰减
  - LES 模型中的**超粘性正则化**（hyperviscosity）有理论支撑
- 对**NSE 千禧问题**：本文是**2D 部分**进展；3D 仍是开放问题

难度：极高（需要深度 PDE 谱理论 + 摄动论）；价值：**学术里程碑**（NSE 千禧问题相关进展）
