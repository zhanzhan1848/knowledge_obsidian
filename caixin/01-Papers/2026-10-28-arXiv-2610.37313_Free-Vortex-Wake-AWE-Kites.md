## 核心贡献

> 把**涡步法（vortex step method）**与**时间推进的自由涡尾迹**结合，配以集中质量系绳、作动盘旋翼（释放涡环）以及多风筝共享同一尾迹系统，首次给出风筝自由涡尾迹的收敛性研究规范。

1. **方法学闭环**：vortex step method + free wake + lumped-mass tether + actuator-disc rotors（释放涡环）+ 多 kite 共用尾迹，构成完整的风筝尾迹动力学框架。
2. **首次报告风筝尾迹的收敛性研究**：给出尾迹长度、时间步长、涡核半径三个关键参数的**运行前可确定**的定量准则（此前风筝领域从未按网格收敛研究的规范报告过）。
3. **发现滑流管近翼处理决定旋翼影响的符号**：同一组旋翼，未变形的滑流管使升力 **+1.9%**，被机翼偏折的滑流使升力 **−3.5%**——符号由近翼处理方式决定，且该效应数倍于风筝自身尾迹损失。
4. **量化的机群尾迹损失**：下游机组在 1 个环径下游损失 0.51% 升力 / 2.2% 空气动力功率；2 个环径处为 0.80% / 3.2%。

## 技术方案

### 核心思想

Loyd 侧风公式给出 $P \propto C_L^3 / C_D^2$，故 1% 的系数误差会带来 2–3% 的功率估计误差。但该公式忽略了风筝对来流的**诱导减速**——在涡描述中，这个减速正来自风筝自己留下的尾迹。

与风力机不同，风筝的尾迹形状由其**横风闭合轨迹**决定（圆形轨迹 → 环形螺旋尾迹，每环一圈；八字轨迹 → 自交薄片），而非由旋转轴上的叶片决定。

### 关键技术

| 技术 | 说明 |
|------|------|
| 方法 | Vortex step method + free wake (VSM-F)；每面板 1 个束缚涡段 + 1 个未知环量；3/4 弦长处闭合条件（Weissinger 型），载荷点置于束缚涡上 |
| 涡系 | 四边形涡环格点：束缚涡行、尾缘行、尾迹行 $m=1..n$；相邻环共享涡丝携带环量差 |
| 尾迹推进 | 节点为物质点，$\dot{\mathbf X} = \mathbf U_\infty + \mathbf u(\mathbf X;\bm\Gamma)$；半隐式 Euler；显式 Euler 平流 + 尾迹行平移 |
| 尾迹步长 | $\Delta t$ 同时决定尾迹流向分辨率：相邻行相隔 $U_\infty\Delta t$ |
| 涡核正则化 | Lamb–Oseen：$F_\nu = 1-\exp(-\alpha_O\eta^2)$，$\alpha_O=1.25643$；$h>2.82r_c$ 时置 1；基准 $r_c=0.15$ m |
| 黏性涡核增长 | $r_c^2 = r_{c,0}^2 + 4\alpha_O\delta\nu\tau$ |
| 旋翼 | 作动盘释放涡环；分自由涡环与"未变形滑流管"两种滑流表示 |
| 系绳 | 集中质量（lumped-mass）模型 |
| 多机 | 多个升力面共享同一环量系统与同一尾迹 |
| 翼型极曲线 | $C_l(\alpha)$、$C_d(\alpha)$、$C_m(\alpha)$ 线性插值，不外推 |

## 公式

### 1. 诱导速度（Biot–Savart + Lamb–Oseen 核）

```math
\mathbf{u}(\mathbf{x}) = \sum_k F_\nu\left(\frac{h_k}{r_{c,k}}\right)\frac{\Gamma_k}{4\pi}\,\mathbf{K}_k
```

```math
\mathbf{K}_k = \frac{(r_1+r_2)(\mathbf{r}_1\times\mathbf{r}_2)}{r_1 r_2 (r_1 r_2 + \mathbf{r}_1\cdot\mathbf{r}_2)}
```

```math
F_\nu(\eta) = 1 - \exp(-\alpha_O\eta^2), \qquad \alpha_O = 1.25643
```

### 2. 半隐式微分代数系统（指数 1）

```math
\frac{\mathrm{d}\mathbf{X}}{\mathrm{d}t} = \mathbf{U}_\infty + \mathbf{u}(\mathbf{X};\bm\Gamma),
\qquad
\mathbf{R}(\bm\Gamma;\mathbf{X}) = \mathbf{0}
```

时间推进（显式 Euler 平流 + 尾迹行释放）：

```math
\mathbf{X}^{n+1} = \mathbf{X}^n + \Delta t\left[\mathbf{U}_\infty + \mathbf{u}(\mathbf{X}^n;\bm\Gamma^n)\right]
```

```math
\Gamma_j^{(1)} = \Gamma_j^{n+1}, \qquad
\Gamma_j^{(m+1)}\big|_{t_{n+1}} = \Gamma_j^{(m)}\big|_{t_n}, \quad m\ge1
```

尾缘净环量为零（OLAF 形式的 Kutta 条件），脱落涡量 $\Gamma_j^{n+1}-\Gamma_j^n$ 位于尾迹第 1 行的展向涡丝上。

### 3. 面板几何

```math
\mathbf{b}_k = \mathbf{x}^{\rm le}_k + \tfrac14\mathbf{c}_k, \qquad
\mathbf{c}_k = \mathbf{x}^{\rm te}_k - \mathbf{x}^{\rm le}_k
```

```math
\mathbf{x}^{l}_j = \mathbf{b}(s^*_j), \qquad
\mathbf{x}^{c}_j = \mathbf{x}^{l}_j + \tfrac12\,\mathbf{c}(s^*_j)
```

展向站位用 van Garrel 全余弦分布（OLAF 所用）。

## 实验结论

### 验证（Sec. III）

| 检验项 | 结果 |
|---|---|
| 对独立涡步法开源代码（M600 刚翼） | 复现到 $10^{-9}$ |
| TU Delft V3 前缘充气风筝 | 升力 0.3% 内、阻力 0.9% 内 |
| 与 RANS 升力对比 | 3.1% 内 |
| 静止空气中平移的风筝 vs 反向风中的固定风筝 | 一致到 $10^{-12}$ |
| 相距 20 km 的两个风筝 vs 两个独立计算 | 一致到 $10^{-9}$ |
| 树形代码（tree code） | 保持在预设误差预算内；GPU 上复现到 $4\times10^{-6}$ |

### 关键判据（运行前即可确定）

1. **尾迹长度**：有限尾迹的升力亏损即其起始涡的远场。由此可在运行前由参考面积与风筝升力响应确定所需精度的尾迹长度：
   - M600：**49 弦长**（升力误差 0.1%）
   - V3：**16 弦长**
   - 高升阻比机翼的阻力需求约长 3 倍；自由涡尾迹约长 1.2 倍
2. **涡核半径**：只要 $r_c$ 低于最小展向面板宽度（含尾翼），涡步闭合适定；超过后闭合 Jacobian 最小奇异值**下降两个数量级**，计算失败（可在运行前用起始步 Jacobian 检验）。
   - 涡核翻倍 → M600 俯仰力矩变化 **38%**（经尾翼载荷），V3 升力变化 **2.7%**
   - 尾迹黏性涡核增长 → 载荷变化 ≤0.3%（故核心敏感性是**闭合的近场属性**）
3. **时间步长**：0.2–0.3 弦长的行进距离，升力保持在最细层级的 0.02% 内。

### 主结果

- **M600 横风环线**：两圈后每圈载荷重复性 0.1% 内；尾迹为一对反向旋转的翼尖螺旋涡（间距接近 Betz 间距），涡间速度亏损达风速的 0.4；每个环径下降约 0.02，收缩缓慢，约两圈后失去有序性。
- **诱导效应**：5、9、13 m/s 下降低升力约 **0.5%**；解析螺旋尾迹模型预测的损失从 1.1% 降到 0.19%。
- **旋翼效应**：作动盘自由涡环穿过机翼束缚涡核内，旋翼对升力系数的影响**不随时间步长收敛**。未变形滑流管在两条件满足时收敛：(a) 环间距 ≤ 半个表面涡核（仅在这些点细分涡环）；(b) 表面涡核 ≤ 这些点到管壁距离的一半。此时 8 个旋翼抽取 527 kW 轴功率，升力 **+1.9%**（随推力近似线性、随推力变号，由穿过机翼与尾翼的管壁携带）。机翼偏折滑流时，同样 527 kW 轴功率使升力 **−3.5%**。旋翼从运动中取走约 640 kW，超过机翼在规定环线上可提供的 435 kW。
- **下游机组损失**（上游机组翼尖涡对的尾流中）：

| 下游距离 | 升力损失 | 空气动力功率损失 |
|---|---|---|
| 1 环径 | 0.51% | 2.2% |
| 2 环径（尾迹仍有序） | 0.80% | 3.2% |
| 1 环径 + 侧向偏移半环径 | 0.09% | 0.43% |

旋翼对上述损失的影响 ≤0.03%（升力）/ 0.12%（功率）；上游的滑流管对下游无可测效应 → **机间相互作用由机翼尾迹携带**。

## 局限性

1. **自由涡环（旋翼）表示不随时间步长收敛**，必须改用滑流管表示才有可用的收敛性。
2. **闭合 Jacobian 在涡核过大时退化**，需运行前检验。
3. 滑流管表示依赖机翼**不使滑流变形**这一前提；真实机翼偏折会使滑流管收敛性失效且符号反转。
4. 被困核心（trapped core）模型未涉及。
5. 未来工作：完整陆基机组的闭环飞行 + 湍流风中多机组尾迹相互作用。

## 实现建议

- **实现难度**：中–高。需要：面板涡步法 + 尾迹格点管理 + 3/4 弦长非线性闭合求解（Newton）+ 时间推进 + 涡核正则化 + 翼型极曲线插值。
- **预期性能**：作者提供 GPU 树形代码加速（可复现到 $4\times10^{-6}$）。核心计算是 $O(N_{\rm filament})$ 求和 + $O(N_{\rm panel})$ 闭合。
- **适用场景**：气动弹性/尾迹相互作用的快速工程评估；风力机与风筝的尾迹干扰；无需 CFD 网格的快速迭代设计。
- **落地建议**：
  1. 先按 §III 的三条判据确定尾迹长度、涡核半径、时间步长——**都可在运行前用解析量确定**，避免盲目加密
  2. 若要模拟近翼旋翼，必须用"未变形滑流管 + 局部涡环细分"表示，不能用自由涡环
  3. 闭合求解器需监测 $\partial\mathbf{R}/\partial\bm\Gamma$ 的最小奇异值作为适定性监测
- **开源复用**：OpenFAWE 的气动模块可直接使用；与本文同组的 OLAF / AWSM / UnPaM / QBlade / DUST 是相关替代方案（见论文对比表）。
