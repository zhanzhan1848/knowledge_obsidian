## 核心贡献

> 提出 CoPiT：以 Position-induced Transformer (PiT) 为几何骨干，通过**多阶段 FiLM** 注入全局条件向量，使参数化调制显式化

1. 指出现有架构缺陷：全局参数（来流状态、设计变量）与逐点输入**拼接**，导致其对中间特征的影响是**隐式**的
2. CoPiT 用 **FiLM（Feature-wise Linear Modulation）** 多阶段注入全局条件向量，使参数化调制**显式**，同时**保留基于几何的注意力权重**
3. 在 2D AirfRANS 翼型场（含小数据与外推工况）与 3D BlendedNet++ 混翼体表面验证
4. 性能：AirfRANS 全数据测试集上，相比 Transolver，表面损失降低约 **54%**、体积损失降低约 **24%**；BlendedNet++ 上取得所有对比基线中**最低的归一化测试 MSE**
5. 匹配消融显示 FiLM 条件化普遍优于输入拼接，但**最优插入位置依赖任务**

## 技术方案

### 核心思想

算子学习（neural operator）需要从"几何 + 工况"映射到流场。几何依赖由 PiT 的位置编码注意力处理；工况/设计变量的全局影响则用 FiLM 逐层调制特征，显式地让网络"知道"当前工况。

### 关键技术

| 技术 | 说明 |
|------|------|
| PiT 几何骨干 | Position-induced Transformer，非结构网格上的几何注意力 |
| 多阶段 FiLM | 每个阶段用全局条件向量对特征做仿射调制 (γ, β) |
| 全局条件编码器 | 来流状态 + 设计变量 → 条件向量 |
| 非结构网格算子学习 | 直接在网格点/单元上预测，无需规则化网格 |
| 匹配消融 | 等价容量下对比 FiLM vs 拼接 |

## 公式

```math
FiLM 调制（特征级仿射变换）:
  FiLM(h, c) = γ(c) ⊙ h + β(c)
  其中 γ, β: 条件向量 c → 缩放/偏移参数

CoPiT 前向:
  h_0 = Encoder(x_geom, c)              # 逐点几何 + 全局条件
  for l = 1..L:
      h_l = PiT_Block_l(h_{l-1})         # 几何注意力，权重只依赖几何
      h_l = FiLM(h_l, c)                 # 多阶段显式参数化调制
  u_hat = Decoder(h_L)

与拼接方式的对比:
  拼接: h = f([x_geom, c])   →  c 对中间特征的影响隐式
  FiLM: h = γ(c)⊙f(x_geom) + β(c)  →  影响显式、可控
```

## 代码片段

```python
import torch
import torch.nn as nn

class FiLMBlock(nn.Module):
    """特征级线性调制：由全局条件向量生成缩放/偏移"""
    def __init__(self, cond_dim, feat_dim):
        super().__init__()
        self.to_gamma = nn.Linear(cond_dim, feat_dim)
        self.to_beta  = nn.Linear(cond_dim, feat_dim)

    def forward(self, h, cond):
        gamma = self.to_gamma(cond).unsqueeze(-2)   # (B, F, 1)
        beta  = self.to_beta(cond).unsqueeze(-2)
        return gamma * h + beta

class CoPiT(nn.Module):
    def __init__(self, cond_dim, feat_dim, n_stages=4):
        super().__init__()
        self.pit_blocks = nn.ModuleList([PiTBlock(feat_dim) for _ in range(n_stages)])
        self.films = nn.ModuleList([FiLMBlock(cond_dim, feat_dim) for _ in range(n_stages)])

    def forward(self, geom_pts, cond):
        h = self.encoder(geom_pts)               # 逐点几何编码
        for pit, film in zip(self.pit_blocks, self.films):
            h = pit(h)                           # 几何注意力（权重仅依赖几何）
            h = film(h, cond)                    # 多阶段显式参数化调制
        return self.decoder(h)
```

## 实验结论

- **数据集**: AirfRANS（2D 翼型 RANS 场，含 full-data / 小数据 / 外推工况）、BlendedNet++（3D 混翼体表面场）
- **基线**: Transolver（PiT 前作）及其他神经算子基线
- **结果**:
  - AirfRANS 全数据测试集：**表面损失 ↓约 54%**，**体积损失 ↓约 24%**（相对 Transolver）
  - BlendedNet++：**所有对比基线中最低的归一化测试 MSE**
  - 匹配消融：**FiLM 条件化普遍优于输入拼接**
  - FiLM 的**最优插入位置依赖任务**（无通用最优）

---

## 局限性

- FiLM 插入位置需按任务调参，缺少自适应机制
- 训练仍需高质量 RANS 数据；外推能力依赖训练分布
- 摘要未报告推理成本、参数量与显存占用
- 主要针对气动外形场，泛化到更复杂多物理场未验证
