## 核心贡献

> 用**逐步加宽频带**的新一轮实验室水槽实验证明：只要把 NLS 方程**按需要推广**（放宽窄带假设），就能准确重现宽频带水波的演化；窄带 NLS 的失效并非方程本身错误，而是**频带假设**在宽谱条件下不成立。

1. **可控加宽频带的新实验系列**：报告一组新实验，通过**逐步增大波列的频带宽度**（broadbandedness），系统地扫过"窄带 → 宽带"的过渡区。
2. **NLS 推广形式的验证**：把标准（窄带）NLS 逐级推广为**含高阶非线性/色散修正的广义 NLS**，并证明这些推广形式能**准确建模**宽频带实验数据。
3. **模型适用边界的定量刻画**：明确指出既有 NLS 类模型"通常假设波列由窄频带构成"这一前提，实验则直接攻击该前提。
4. **物理意义**：风暴生成的波列经频散后形成可跨数千公里传播的**涌浪 (swell)**；涌浪在真实海洋中本就是宽频带（风谱宽、方向谱宽），因此本文为**真实海洋长波演化的建模**提供了实验依据。

## 技术方案

### 核心思想

**背景**：深水重力波的频散关系 $\omega^2=gk$ 是**强非线性**的——长波传播快、短波传播慢。窄带波列因此可以用**慢变包络 (envelope)** 描述，包络满足 NLS：

```math
i\left(A_t+c_g A_x\right)+\tfrac{1}{2}\beta A_{xx}+\tfrac{1}{2}\alpha\lvert A\rvert^{2}A=0
```

其中 $\alpha$ 为非线性系数、$\beta=1/2$（深水）、$c_g=\frac{1}{2}\sqrt{g/k_0}$。这一形式**内含**了 Benjamin–Feir 调制不稳定性、孤立子、畸形波 (rogue wave) 等经典现象。

**窄带假设的代价**：把 NLS 写成上式，需要
- 波列的**载波频率集中**在一个窄频带内（谱峰锐）；
- 慢变包络的时间尺度 $\sim 1/\beta k_0^2$ 远长于载波周期。

一旦波列**频带变宽**：
- 长短波分量以不同群速分离，**包络不再慢变**；
- 同一波列内不同频率分量各自的非线性演化速率不同；
- 简单的二阶 NLS **系统性地预测错误的**调幅、调相与破碎行为。

**推广路线（方法层面）**：把 NLS 形式**展开到更高阶**（保留更多关于 $A_x$、$\lvert A\rvert^2 A_x$、$A_{xxx}$ 等的非线性与色散项），即得到**广义（高阶）NLS**；高阶项在窄带极限下自动退化为标准 NLS，因此可以**连续插值**从窄带到宽带。

**实验路线**：在水槽中用造波机产生受控波列，**逐步加宽**输入频谱（改变造波谱的带宽参数），用波高计/相机记录自由面演化，再把观测与各级 NLS 模型的预测对比。

### 关键技术

| 技术 | 说明 |
|------|------|
| **深水色散关系** | $\omega^2=gk$；深水条件 $\omega_0/k_0$ 深、$k_0h\gg1$，无量纲水深参数 $k_0h$ 需足够大 |
| **包络 (envelope) 提取** | 由窄带解析信号 (Hilbert 变换) 或在载频带内做带通 + 相位提取，得到 $A(x,t)$ |
| **标准二阶 NLS** | 保留到 $O(\epsilon)$ 的完整非线性 Schrödinger 型方程 |
| **高阶/广义 NLS** | 展开到更高阶：含高阶色散 ($A_{xxx}$) 与高阶非线性（$A\lvert A\rvert^2 A_x$ 等）修正项 |
| **频带宽度参数** | 定量刻画波列的谱宽（如相对带宽 $\Delta k/k_0$ 或无量纲频带参数），作为实验自变量 |
| **调制不稳定性 (MI) 判据** | 广义 NLS 下 MI 增长率依赖于波陡度与频带宽度；宽频带会改变 MI 的增长率与饱和形态 |
| **孤立子与畸形波** | 高阶 NLS 中高阶项修正了孤立子剖面（尤其当 $k_0h$ 不够大时的偏离）与畸形波的出现阈值 |
| **波高计 / 光学剖面测量** | 自由面时间序列的高精度获取；波陡度高时需考虑测量分辨率与破碎后的多相流 |
| **数值求解包络方程** | 谱方法（Chebyshev/Fourier）求解 NLS，配合谱向量的非线性项伪谱处理 |

## 公式

> 以下为**方法层面的本质形式**：标准 NLS 与其高阶推广的结构。**具体高阶项的系数取决于深度参数与色散展开的阶数**，原文的具体系数需以论文为准，此处不伪造。

### 1. 深水频散与群速（所有归一化的基准）

```math
\omega(k)=\sqrt{gk},\qquad
c_g(k)=\frac{d\omega}{dk}=\frac{1}{2}\sqrt{\frac{g}{k}},
\qquad
c_p=\frac{\omega}{k}
```

无量纲化：取载波数 $k_0=1$、重力 $g=1$、深水极限 $\omega_0=1$，则 $c_g=1/2$。

### 2. 标准（窄带）NLS

```math
i\left(A_t+c_g A_x\right)+\frac{1}{2}\beta A_{xx}
+\frac{1}{2}\alpha\lvert A\rvert^{2}A=0,
\qquad \beta=\frac{1}{2}\ (\text{深水})
```

系数（深水、纯重力波的标准形式，本质形式）：

```math
\alpha=\tfrac{1}{2}k_0^{2}\omega_0\ \ (\text{按 } A\ \text{的归一化约定}),
\qquad
\varepsilon=\tfrac{1}{2}k_0^{2}A_0^{2}\ \ (\text{非线性小参数})
```

### 3. 高阶/广义 NLS（结构形式）

把自由面运动学-动力学系统对 $\epsilon$ 做**渐近展开**并保留到 $O(\epsilon^{2})$，包络方程的一般结构为：

```math
i\left(A_t+c_g A_x\right)
+\frac{1}{2}\beta A_{xx}
+\frac{1}{2}\alpha\lvert A\rvert^{2}A
+\underbrace{\text{高阶色散项}}_{A_{xxx}\ \text{等}}
+\underbrace{\text{高阶非线性项}}_{A\lvert A\rvert^{2}A_x\ \text{等}}
+\cdots=0
```

**要点**：
- 高阶色散项来自 $\omega(k)$ 在 $k_0$ 附近的**非线性展开**（深水中 $\omega$ 关于 $k$ 是 $k^{1/2}$，展开系数非零）；
- 高阶非线性项来自**运动学方程的有限振幅修正**（比例律 $A^{2}A_x$）；
- **窄带极限**（$\Delta k/k_0\to0$、$k_0h\to\infty$）下这些项自动消失，退化为标准 NLS。

### 4. 调制不稳定性的增长判据（标准 NLS 层面）

```math
\text{线性化扰动增长率（NLS 极限）:}\quad
\sigma_{\rm MI}(k)\ \approx\ \alpha\,\varepsilon\,\frac{1}{2}k^2 c_g
\left(1-\tfrac{2}{k^2}\right)\Big|_{k\to k_0}
```

```math
\text{判据:}\quad
\alpha\,\varepsilon\,c_g\,\tfrac{1}{2}>0
\;\Rightarrow\;\text{调制不稳定（Benjamin--Feir）}
```

**广义 NLS 下**，高阶项对 $\sigma_{\rm MI}$ 有实质修正：孤立子的**稳定性阈值**、**畸形波出现概率**与**破碎判据**都会移动。

### 5. 孤立子解（标准 NLS）

```math
A(x,t)=A_0\,\mathrm{sech}\!\left[\xi(x-c_g t)\right]e^{i\Omega t},
\qquad
\xi=\sqrt{\frac{\alpha A_0^{2}}{2\beta}}
```

```math
\text{相速度（深水）:}\quad
c_{\rm sol}=\frac{1}{2}\left(c_g+\sqrt{c_g^{2}+4\alpha A_0^{2}/(4\beta)}\right)\ (\text{形式})
```

### 6. 畸变波 (rogue wave) 的极端值统计（与频带的相互作用）

```math
\text{第三阶矩判据（Peregrine 近似）:}\quad
\frac{\langle H^{3}\rangle}{\langle H\rangle^{3}}>3
\;\Rightarrow\;\text{出现极端波的风险显著}
```

宽频带会改变能量在波列中的分布，从而改变波高分布的**高阶矩**与极端值统计——这是宽频 NLS 推广在工程上最直接的收益（设计波/生存度评估）。

### 7. 宽带谱的描述

```math
E(k)\ \text{为能量谱},\qquad
\text{相对带宽}\ \frac{\Delta k}{k_0}
\ \text{与无量纲}\ 
\delta=\frac{\Delta\omega}{\omega_0}
\]

窄带条件即 $\delta\to0$；实验通过**造波谱带宽**控制该参数。

## 代码片段

```python
# 概念性伪代码：广义 NLS 的谱方法求解 + 与实验对比

import numpy as np

# ---------- 1) 谱离散（Chebyshev/Fourier 空间） ----------
Nx = 1024
Lx = 512.0
x  = np.linspace(-Lx/2, Lx/2, Nx, endpoint=False)
k  = 2*np.pi*np.fft.fftfreq(Nx, d=Lx/Nx)          # 空间波数

# ---------- 2) NLS 系数（深水, 归一化 g=k0=1） ----------
cg   = 0.5          # 群速
beta = 0.5          # 色散系数
alpha = 0.5         # 非线性系数（按 A 的归一化约定）
dt   = 1e-4

def nls_rhs(A, k, cg, beta, alpha, order=2):
    """标准 NLS (order=1) 与广义/高阶 NLS (order>=2) 的 RHS"""
    Ax = np.fft.ifft(1j*k*np.fft.fft(A))
    Axx = np.fft.ifft(-(k**2)*np.fft.fft(A))
    RHS = 1j*(beta*Axx + 0.5*alpha*np.abs(A)**2*A)   # 左侧空间项
    if order >= 2:
        Axxx = np.fft.ifft(-1j*(k**3)*np.fft.fft(A))
        # 高阶色散项（系数取决于深度/展开阶数，此处为占位）
        RHS += 1j*gamma_hs*Axxx
        # 高阶非线性项（运动学有限振幅修正）
        RHS += 1j*delta_hl*(A*np.abs(A)**2*Ax)
    # 时空推进项: A_t + cg A_x
    Ax_x = np.fft.ifft(1j*k*np.fft.fft(A))
    return -cg*Ax_x + 1j*RHS

def integrate(A0, T, order):
    A = A0.copy(); t = 0.0
    while t < T:
        A = RK4_step(lambda Z: nls_rhs(Z, k, cg, beta, alpha, order), A, dt)
        t += dt
    return A

# ---------- 3) 由自由面时序提取包络（窄带分析） ----------
def envelope(eta):
    """Hilbert 变换取解析信号 -> 慢变包络"""
    from scipy.signal import hilbert
    return np.abs(hilbert(eta))

# ---------- 4) 实验对比：逐级提高频带宽度 ----------
for delta in [0.02, 0.05, 0.10, 0.20, 0.35]:      # 相对带宽
    A0    = initial_envelope_from_wavemaker_spectrum(delta)
    A_std = integrate(A0, T=200.0, order=1)        # 标准 NLS
    A_gen = integrate(A0, T=200.0, order=2)        # 广义 NLS
    eta_std = reconstruct_surface(A_std); eta_gen = reconstruct_surface(A_gen)
    print(delta,
          "std NLS  err =", err(eta_std, eta_measured),
          "| generalized NLS err =", err(eta_gen, eta_measured))
    # 预期：随 delta 增大，标准 NLS 误差上升；推广形式保持准确

## 实验结论

- **数据集/算例**：**新的实验室水槽实验系列**，波列的**频带宽度（broadbandedness）被逐步增大**，系统扫描窄带 → 宽带的过渡；测量对象为深水波列的自由面演化。
- **基线/对照**：**标准（窄带）NLS** 作为基线模型；**NLS 的各级推广形式**（放宽窄带假设、含高阶修正）作为改进模型。
- **结果**：
  - 随着实验波列的频带**逐步加宽**，**标准 NLS 的预测准确性下降**（窄带假设被破坏）。
  - **NLS 的推广形式能够准确重建这些宽频带实验测量**——即"放宽频带假设"是恢复精度所需且充分的修正方向。
  - 该结果支持把 NLS 类模型用于**真实海洋涌浪**（本质为宽频带）的建模，同时也明确了标准 NLS 的适用边界。
  - 摘要未给出具体的误差数值、带宽范围与实验参数（造波谱型、水深/波数比、测量手段），这些需查阅正文图表。

## 局限性

1. **摘要未披露定量范围**：具体加宽到的相对带宽、实验水深与 $k_0h$、误差指标与数值均未在摘要给出 → 模型的定量适用区间需查正文。
2. **仍是"深水、单向、无风、无流"的理想化**：真实涌浪包含**方向谱展宽**（斜向波列）、风应力强迫、有限深度与**底摩擦/破碎耗散**，NLS 推广只处理"频带展宽"这一个维度。
3. **破碎未纳入**：波陡度超过阈值后的破碎涉及**破碎尺度**（$k_0h$ 效应）以上的物理，任何包络方程（包括高阶 NLS）都只能描述破碎前的演化。
4. **高阶项的适用阶数受限**：高阶 NLS 的更高阶项只有在 $\epsilon=k_0^2A_0^2$ 很小、但又不小到让二阶项可忽略时才有效——存在**中间尺度**（$O(\epsilon^1)$）的行为，需要**完整的水波方程**而非任何有限阶包络方程。
5. **实验到海洋的外推**：水槽是有限长、有限宽，边壁反射、造波机的二次谐波污染与测量噪声在宽带条件下更显著。
6. **与理论侧的对照可补充**：本文的"推广 NLS 有效"是数值/实验证据；而 [[2026-10-30-arXiv-2610.39000-benjamin-feir-suppression-constant-vorticity]] 从完整方程严格证明了**涡量背景下 BF 判据的阈值**。两者的"严格性 vs 适用性"构成互补，但**涡量背景 + 宽频带**的联合情形目前尚无严格理论。
7. **无公开代码/数据**（摘要未提供），复现实验成本高。

## 实现建议

- **实现难度**：🟡 中（包络方程的谱方法求解是标准工作；主要工作在**高阶项系数的正确推导**与**从自由面数据提取包络**上）。
- **预期性能**：
  - 谱方法求解 NLS：$O(N_x\log N_x)$ 每次 FFT，对 $N_x\sim10^3\!-\!10^4$ 实时性充裕；
  - 高阶项引入的伪谱非线性（$\lvert A\rvert^2 A_x$、$A_{xxx}$）**需要 3/2 法则去混叠**，否则高阶项会制造假增长——这是实现中最常见的坑；
  - 与实测对比时，**包络提取的带宽选择**与模型假设同源，宽带下需做**多带宽一致性检验**以排除循环论证。
- **适用场景**：
  - **海洋/港湾长波与涌浪演化预测**（广谱输入、公里级传播）；
  - **设计波与极端波风险评估**（畸形波的第三阶矩判据）；
  - **CFD 中的自由面破碎子模型标定**：宽频 NLS 给出破碎前的波幅/相位演化，可作为 VOF/Level-Set 自由面求解器的入波边界条件或破碎判据参考。
- **落地建议**：
  1. **先做窄带极限回归测试**：在 $\delta\to0$ 时，高阶 NLS 必须退化到标准 NLS（高阶项系数置零即可复现）；这一致性测试能挡住大部分实现错误。
  2. **高阶项系数从自由面方程严格推导**，不要从文献中直接抄系数（不同文献的振幅归一化不同，混用会导致量纲错误）。
  3. **务必加 3/2 去混叠**，并做收敛性扫描（$N_x$ 与非线性项阶数同时变）。
  4. **实验/观测对比要避免循环论证**：不要用同一带宽假设提取包络再与模型对比；应改用**谱矩法**从原始谱提取等效带宽参数。
  5. **工程落地优先级**：宽频 NLS 更适合作为**波浪传播/破碎前阶段的快速模型**；一旦波陡度进入破碎区，必须切换到自由面 CFD（VOF/Level-Set + 破碎子模型），包络方程不再适用。
