# Tandem Jets in Crossflow: Enclosed-Recirculation Momentum Exchange

**arXiv**: [2610.31417](https://arxiv.org/abs/2610.31417) · **提交**: 2026-10-22 15:18 UTC
**作者**: Xunchen Liu
**方法**: 40 kHz time-resolved PIV（实验）

## 实验设置

- **构型**：crossflow 中 tandem twin jets（前射流 + 后射流）
- **参数范围**：spacing–velocity ratio，`L = 2d–4d`，`r ≈ 3–7`
- **样本量**：68 组 twin cases + 11 组 single-jet reference
- **采样率**：40 kHz 时间分辨 PIV

## 核心发现 1：前射流被稀释 (dilution)

- 前射流轨迹**低于**单射流参考线
- 近场段**最多缩短 40%**
- 速度比降至有效值 `r_eff < r`
- 被屏蔽的后射流则**高于**参考线

## 核心发现 2：封闭回流区是动量交换的载体

**机制链条**：
```
后射流堵塞 (blockage)
    ↓
闭合 gap recirculation（缝隙回流区）
    ↓
反向流把两侧 gap 剪切层置入 counter-current configuration
    ↓
经典增强夹卷路径 (enhanced entrainment)
```

**定量结果**：

| 指标 | 增强倍数（vs 单射流背风区，同条件） |
|------|------|
| Zone peak | 最高 **1.5×** |
| Area-integrated | 最高 **2.8×**（在 r ≈ 7） |

**关键机制判别**：
- ✅ 增益来自**增大的混合尺度 (mixing scale)**
- ❌ 而非来自更陡的剪切 (steeper shear)
- 前射流近场缩短**跟随绝对交换量**，而非 twin/single 增强比

## 核心发现 3：动量收支

- **湍流项 > 压力项**（9 个工况中的 8 个）
- 通量收支读出：稀释 = 有限质量注入 + 向 crossflow 的动量损失
- ⚠️ 证据仍为**观测性**（实验），非直接数值验证

## 核心发现 4：交换由对流涡列承载

- gap 侧剪切层保持**对流不稳定**
- **DMD**（动态模态分解）与 **SPOD** 在可分辨频带与记录长度内**未发现增长模态**
- → 排除自激全局模态机制
- → 交换由**行进涡列 (convecting vortex trains)** 承载

## 数值方法评估

| 维度 | 评价 |
|------|------|
| 诊断工具 | PIV (40 kHz) + DMD + SPOD |
| 场类型 | 实验瞬时速度场，非仿真 |
| RANS/LES 对照 | ❌ 未提供 |
| 参数化价值 | 混合尺度放大机制可用于 LES/RANS 亚模型约束 |

## 推荐结论

⚠️ **谨慎（工程需谨慎，机制可借鉴）**：
1. 机制清晰且有 **DMD+SPOD 双重否定证据**排除全局不稳定模态 —— 方法学严谨
2. 但缺乏数值验证，若要用于 LES 亚模型，建议先做 RANS/LES 对照实验
3. `r ≈ 7` 时面积积分增益 2.8× 是最值得复现的点
