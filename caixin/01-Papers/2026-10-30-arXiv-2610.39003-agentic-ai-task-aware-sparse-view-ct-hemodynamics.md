## 核心贡献

> 在**稀疏视角 CT 采集**中，把采样视角的选择从"为重建图像服务"改造为"为下游物理推断服务"：用 FNO 直接从稀疏投影预测**壁面剪切应力 (TAWSS)**，并证明 **agentic AI 选择器**与 **Soft top-K** 在极端稀疏下显著优于固定均匀/黄金角采样——同时证明**任务最优采集 ≠ 重建最优采集**。

1. **任务感知的采集范式**：传统 CT 采样策略为重建优化，本文直接为**下游物理量推断**优化采集，目标是稀疏投影 → 血流动力学场的端到端映射。
2. **双目标 FNO**：训练 FNO 同时预测**空间分辨的 TAWSS 场**与**空间平均 TAWSS**（标量），并与最优输入选择耦合（simultaneous optimal sampling and training）。
3. **三种任务感知选择器对比**：Gumbel-Softmax（可微采样松弛）、Soft top-K、以及**agentic AI 选择器**（带推理过程的自主选角）。
4. **关键科学发现**：为血流动力学预测优化的采样掩膜**重建图像质量差** → 采集目标与重建目标在本质上分叉，为"按物理量设计稀疏采集"提供依据。
5. **agentic 推理可解释性分析**：对 AI agent 的选角决策做了详细分析，理解其为何优于固定采样。

## 技术方案

### 核心思想

**上游（CFD 数据生成）**：对**颅内动脉瘤 (intracranial aneurysm, IA)** 几何做 CFD 求解，得到壁面剪切应力场，再沿 **fan-beam CT 几何**做射线投影（ray transform）生成合成投影。

**下游（代理模型 + 采样选择）**：FNO 输入为稀疏投影集合（带掩膜的多通道输入），输出为 IA 壁面上的 TAWSS。采样掩膜的优化与网络训练**交替/联合进行**（可微松弛 + 松弛退火）。

**"Agentic" 环节**：用一个具备推理能力的 AI agent 直接**提出离散选角方案**，其决策依据包括但不限于：哪些视角穿过高 WSS 区域、瘤体与载瘤动脉的连接处、几何曲率剧烈处、以及几何投影的"信息互补性"。

### 关键技术

| 技术 | 说明 |
|------|------|
| **CFD 求解（IA 血流）** | 非定常不可压 Navier–Stokes，入口脉动速度波形驱动，壁面无滑移；壁面剪切应力 $\tau_w=\mu(\nabla\mathbf{u}+\nabla\mathbf{u}^{T})\cdot\mathbf{n}$ |
| **合成扇束投影** | fan-beam 射线投影，射线–网格求交（SIDON 类 / 体渲染积分）生成正弦图 |
| **FNO** | Fourier Neural Operator：在频域做截断乘法 + 逆 FFT 实现谱卷积，通道维用线性层，网格无关 |
| **可微选角（Gumbel-Softmax）** | 对连续角度松弛为概率分布，训练时用 straight-through / 温度退火得到离散掩膜 |
| **Soft top-K** | 按打分保留 top-K 视角，权重用 softmax 重归一化，比 Gumbel-Softmax 硬性更强 |
| **Agentic AI 选择器** | 由 LLM/推理 agent 结合几何理解选择视角集合，天然产生**离散且多子集**的掩膜 |
| **双目标损失** | 空间分辨 TAWSS 的 L2/L1 误差 + 空间平均 TAWSS 的相对误差 |
| **视图预算扫描** | 在不同 view budget 下对比各方法，考察极端稀疏区的表现 |

## 公式

### 1. 血流动力学控制方程（数据生成端）

```math
\rho\left(\frac{\partial\mathbf{u}}{\partial t}
+\mathbf{u}\cdot\nabla\mathbf{u}\right)
=-\nabla p+\mu\nabla^{2}\mathbf{u}+\mathbf{f},\qquad \nabla\cdot\mathbf{u}=0
```

壁面剪切应力（WSS 是 TAWSS 的瞬时值）：

```math
\boldsymbol{\tau}_w(t)=\mu\left(\nabla\mathbf{u}+\nabla\mathbf{u}^{\mathsf T}\right)\cdot\mathbf{n}
\quad\text{on }\Gamma_{\rm wall},
\qquad
\mathrm{TAWSS}=\frac{1}{T}\int_{0}^{T}\boldsymbol{\tau}_w(t)\,\mathrm{d}t
```

空间平均 TAWSS（下游标量目标）：

```math
\overline{\mathrm{TAWSS}}=\frac{1}{|\Gamma_{\rm wall}|}\int_{\Gamma_{\rm wall}}\lVert\boldsymbol{\tau}_w\rVert\,\mathrm{d}S
```

### 2. 扇束 CT 投影（Radon 变换的 fan-beam 版本）

```math
p(s,\beta)=\int_{\mathcal{L}(s,\beta)}\mu(\mathbf{x})\,\mathrm{d}\ell
```

其中 $\mathcal{L}(s,\beta)$ 为从源点出发、角度 $\beta$、探测器坐标 $s$ 对应的射线；射线积分在 CFD 网格上用线积分近似（sum of voxels along ray）。

### 3. FNO 层（谱卷积的**方法本质形式**）

```math
\mathcal{K}(v)=\mathcal{F}^{-1}\!\left[
R_{\text{trunc}}\!\left(\mathcal{F}(v)\right)\cdot
\mathcal{F}(W)\right],
\qquad
z_{\ell+1}=\sigma\!\left(W_{1}z_{\ell}+\mathcal{K}(z_{\ell})\right)
```

$FNO 的关键数值性质：**谱截断 $m$ 决定可分辨的空间尺度**（保留模态数 $m$ 对应约 $m$ 个网格点的分辨率），训练需注意 Nyquist 与 padding（周期性 padding vs 零填充 + 局部线性）。

### 4. 可微选角（Gumbel-Softmax 松弛）

```math
y_i=\operatorname{softmax}\!\left(\frac{s_i+g_i}{\tau}\right),\qquad
g_i=-\log(-\log u_i),\ u_i\sim\mathcal{U}(0,1)
```

$\tau$ 为温度（退火 $\tau\to0$ 硬化为 one-hot）；straight-through 估计器把前向离散化、反向用软梯度。

### 5. Soft top-K 选择

```math
\mathcal{S}_K=\operatorname{TopK}(s),\qquad
\tilde{y}_i=
\begin{cases}
\dfrac{\exp(s_i/\tau)}{\sum_{j\in\mathcal{S}_K}\exp(s_j/\tau)}, & i\in\mathcal{S}_K\\[4pt]
0, & \text{otherwise}
\end{cases}
```

### 6. 掩膜加权的投影输入与损失

```math
\mathbf{p}_{\rm sel}=\mathbf{y}\odot\mathbf{p}\quad(\text{逐视角 0/1 掩膜}),
\qquad
\mathcal{L}=\lambda_{1}\,\lVert \widehat{\mathrm{TAWSS}}-\mathrm{TAWSS}\rVert_{2}^{2}
+\lambda_{2}\,
\frac{\lVert \overline{\widehat{\mathrm{TAWSS}}}-\overline{\mathrm{TAWSS}}\rVert}
{\lVert \overline{\mathrm{TAWSS}}\rVert}
```

## 代码片段

```text
# 概念性伪代码：任务感知选角 + FNO 联合训练

# ---------- 阶段 A: CFD 数据与合成投影 ----------
for geom in aneurysm_cases:
    sol = run_CFD(geom, inlet_waveform=cardiac_pulse)      # 非定常 NS
    tau_w = wall_shear_stress(sol, wall_faces)              # WSS 场
    TAWSS_field = time_average(tau_w, cardiac_period)
    TAWSS_avg   = area_average(|tau_w|)
    for view in full_angle_set:                             # 完整视角网格
        sino[view] = fan_beam_project(geom.mesh, density_field, view)

# ---------- 阶段 B: 采样选择器 ----------
# 1) Gumbel-Softmax（可微）
mask = gumbel_softmax(scores, tau=0.5, hard=True)          # straight-through

# 2) Soft top-K
mask = soft_topk(scores, k=view_budget, tau=0.1)

# 3) Agentic AI 选择器（离散、多子集）
reasoning = agent.reason(                       # LLM/agent 推理
    geometry=mesh_summary,                     # 曲率、瘤体/瓶颈位置
    wss_heatmap=TAWSS_field_hint,              # 物理先验提示
    budget=view_budget)
mask = agent.select_views(reasoning, view_budget)

# ---------- 阶段 C: FNO 联合训练 ----------
p_in = stack([sinogram[view] * mask[view] for view in views])
loss = lambda1 * mse(fno(p_in, mask), TAWSS_field) \
     + lambda2 * rel_err(mean(fno(p_in, mask)), TAWSS_avg)
opt.zero_grad(); loss.backward(); opt.step()                # 梯度穿过 mask

# ---------- 阶段 D: 诊断 ----------
recon = standard_CT_reconstruction(sino * mask)             # 用同一掩膜做重建
compare(recon_quality, hemodynamics_accuracy)               # 二者不相关 -> 核心结论
```

## 实验结论

- **数据集/算例**：**颅内动脉瘤 (IA)** 的 CFD 仿真生成合成扇束 CTA 投影；目标是空间分辨 TAWSS 场与空间平均 TAWSS。
- **基线**：
  - **固定均匀采样**（等角度间隔）
  - **黄金角采样**（golden-angle，CT 重建的经典非均匀策略）
  - **任务感知**：Gumbel-Softmax、Soft top-K、**agentic AI 选择器**
- **结果**：
  - **空间分辨 TAWSS**：Agentic 与 Soft top-K 取得**最低平均误差**（Agentic 略优），在**极端稀疏**条件下显著优于固定采样。
  - **空间平均 TAWSS**：优化选择在**极度稀疏的采集**下才变得重要（说明标量目标比场目标对采集密度更鲁棒）。
  - **掩膜分析**：选出的掩膜呈现**多个不同的子集**，且集中于**信息量大的区域**（而非单一连续角度弧）。
  - **关键结论**：为**血流动力学预测**优化的掩膜**给出差的图像重建** → 任务最优采集与重建最优采集在根本上不同。
  - 对 agent 决策过程做了详细分析以理解其推理与表现。

## 局限性

1. **算例规模与几何多样性**：仅基于颅内动脉瘤的合成 CFD 数据，结论能否迁移到其他"物理推断型"成像任务（灌注、辐射剂量分布、电场）尚未验证。
2. **CFD 数据为数值真值**：合成投影无真实 CT 的噪声、束硬化、散射、运动伪影；实际临床采集的退化会改变"哪些视角更有用"的结论。
3. **agentic 选择器不可微**：其决策本质是离散的、推理驱动的，难以像 Gumbel-Softmax 那样做梯度联合优化；与网络训练的耦合方式（是否交替、是否需要预热）是方法上的关键实现细节。
4. **误差绝对水平**：摘要以"相对固定采样的优势"表述，未给出绝对误差量级；无法判断 FNO 预测是否达到可用于临床决策的精度。
5. **视角分布的多样性 vs 物理冗余**：掩膜出现"多个不同子集"说明存在**解的多重性**（多个同样有效的选角方案），这既是优点（鲁棒）也说明优化问题非凸、结果依赖初始化。
6. **TAWSS 之外的物理量未覆盖**：如压力分布、振荡剪切指数 (OSI)、壁面退化区域面积等同样重要的血流动力学指标未纳入双目标。

## 实现建议

- **实现难度**：🔴 高（CFD + 射线投影 + FNO + 三类选择器 + 重建诊断五条链）。
- **预期性能**：FNO 单次推理为 FFT 主导（$O(N\log N)$），可在 GPU 上实时；瓶颈在 CFD 数据生成与选角搜索的迭代次数。
- **适用场景**：
  - **辐射剂量受限的 CTA 采集协议设计**（本文的直接动机）
  - **稀疏投影 → 物理场反演**的其他任务（灌注成像、CT 引导放疗剂量分布、电场反演）
  - **"任务感知"传感器布置**的一般化框架
- **落地建议**：
  1. **先复现"重建 vs 物理"的解耦结论**：用同一掩膜做 FBP 重建与物理预测，验证二者误差确实不同步——这是全文最有迁移价值、也最容易验证的一点。
  2. **先用 Soft top-K 作为基线**：其可微性与鲁棒性优于 Gumbel-Softmax，且与 agent 输出形式一致（都是硬掩膜），便于公平比较。
  3. **给 agent 的先验要谨慎**：直接提供 WSS 热图会让 agent 失去"发现"的意义，也把上游 CFD 误差带入下游；建议只用几何信息（曲率、瓶颈位置）作为提示。
  4. **误差预算**：把 CFD 网格/时间步长误差与投影角分辨率一并纳入扫描表，否则稀疏下的优势可能来自欠收敛的 CFD 真值。
  5. **对本知识库的价值**：这是"AI 设计采集 → CFD/物理作为真值 → 代理模型评估"的完整闭环范式，可与 [[2026-10-29-arXiv-2610.37485_AMOR-Adaptive-Modal-Operator-Refinement]]（算子学习）与 [[2026-10-30-differentiable-Schwarz-solver-agentic-AI-inverse]]（agentic AI 用于反向问题）对照阅读，共同构成"agentic AI × CFD"主题簇。
