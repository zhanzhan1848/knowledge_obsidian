## 核心贡献

> 用 **CP 分解的 Tensor Neural Network (APTNN)** 求解 3D3V 高场动理学方程：**方程残差保持 CP 分解形式**，从而高维损失积分可化为**一维积分的组合**，计算与存储成本从**指数增长降为多项式增长**；并通过**引入一阶矩方程**增强 AP loss，直接约束极限通量闭合。

1. **CP 分解降低维度灾难**：分布函数在 6D 相空间 + 时间（3D 问题共 7 个变量）；CP 分解使损失积分**按维分解**
2. **残差保持分解形式**：这是能把高维积分降维的**关键性质**（并非显然成立）
3. **增强 AP loss**：在基线 AP loss 上加入**一阶矩方程**，直接约束高场极限下的通量闭合，减小近似误差
4. **UQ 支持**：初值/边界/模型参数的不确定性引入额外随机变量；3D3V VPFP 多随机输入问题**单 GPU 训练 < 30 分钟**

## 技术方案

### 核心思想

**高场动理学方程**（VPFP、Boltzmann–Poisson）描述电场加速与碰撞松弛主导的粒子输运，是等离子体与半导体器件模拟的基础。

**两大挑战**：
1. **高维**：分布函数定义在相空间 + 时间，3D 问题 7 个变量；全张量积离散 → 网格点数**指数增长**（维度灾难）；UQ 的随机变量进一步加剧
2. **多尺度**：特征尺度变小时数值分辨代价过高

**AP（asymptotic-preserving）思想**：让离散格式在 $\Delta t\to 0$ 时**自动过渡到极限方程**（高场极限下的流体/通量闭合），避免需要分辨小尺度。

**CP 分解的运用**：TNN 用 CP 分解近似解 → 残差**保持**该分解形式 → 高维损失积分 $\int_{\Omega^{6}}\text{（乘积形式）}$ 可写成一维积分的乘积。

**增强 AP loss**：基线 AP loss 只在动力学层面约束；加入**一阶矩方程**后，可**直接约束极限通量闭合**，在高场 regime 显著提升精度。关键在于**该增强项仍可按维评估**（不破坏分解结构）。

### 关键技术

| 技术 | 说明 |
|------|------|
| **CP 分解** | 规范多项式分解；张量神经网络的基础结构 |
| **残差分解保持性** | 使高维积分可按维求值（本文的核心技术论点） |
| **AP loss** | 渐近保持：$\Delta t\to0$ 时过渡到极限方程 |
| **增强 AP loss** | 加入一阶矩方程约束极限通量闭合 |
| **异方差/UQ** | 随机输入下的不确定度量化 |
| **维度分离积分** | 计算与存储从指数 → 多项式 |

### 公式

**VPFP 系统**：$\partial_t f+v\cdot\nabla_x f-E(f)\cdot\nabla_v f=0$，$E(f)=-\nabla_x\phi$，$-\Delta\phi=\rho(f)+1$

**CP 分解**：$f(t,x,v)\approx\sum_{r=1}^{R}\prod_{d=1}^{6}A^{(d)}_r(x_d,v_d)$

**维度分离的高维积分**：若被积函数保持乘积形式，

$$\int_{\Omega^{6}}\prod_{d=1}^{6}g_d\,dx_1\cdots dx_6=\prod_{d=1}^{6}\int g_d\,dx_d$$

**成本缩减**：网格点数 $O(N^{6})$（指数）→ $O(RN)$ 或多项式级。

## 实验结论

- **问题**：3D3V Vlasov–Poisson–Fokker–Planck (VPFP)，含多个随机输入（UQ 场景）
- **结果**：
  - 高场 regime 下精度**优于基线 AP loss**
  - 计算成本与存储**显著降低**
  - 3D3V VPFP 多随机输入问题：**单 GPU 训练 < 30 分钟**
- **对比**：基线 AP 方法 vs 增强 AP loss 的 APTNN

---

## 局限性

1. **依赖残差分解保持性**这一性质——并非所有动理学方程/损失构造都满足
2. AP 性质的理论保证（严格的一致性/稳定性分析）未充分展开
3. 一阶矩方程的增强是在**给定高场极限**下工作，其他 regime 的收益未验证
4. 精度与 CP 秩的关系（秩自适应）未讨论（对比 [[2026-11-07-arXiv-2611.07107-low-rank-Vlasov-6D]] 的物理量驱动秩自适应）
5. UQ 部分只展示可行性，未做严格的收敛/校准分析

## 实现建议

- **实现难度**：高（需要 TNN + CP 分解 + AP 理论 + 动理学方程实现）
- **预期性能**：3D3V 问题单 GPU < 30 min；这是**动理学方程 6D 模拟首次进入「单卡可跑」区间**的量级
- **适用场景**：
  - 等离子体输运、半导体器件高场输运
  - 需要在动理学框架上做**不确定度量化**（UQ 会再引入随机维度，CP 分解是必需）
- **落地建议**：若已有成熟动理学求解器，**低秩数值方法（[[2026-11-07-arXiv-2611.07107-low-rank-Vlasov-6D]]）比神经网络更易落地**；APTNN 的价值在于「无需选网格 + 可微分 + 可做反问题」
