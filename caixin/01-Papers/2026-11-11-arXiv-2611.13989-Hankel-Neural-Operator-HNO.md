## 核心贡献

> 从**解算子（solution operator）的数学结构**出发提出 **Hankel 神经算子 (HNO)**：证明良态线性常系数边值问题的解算子是 **Toeplitz 算子 + 有限秩 Hankel 型算子**；HNO 据此构造**非周期因果卷积**、**Lur'e 闭环算子**与**有理 Fourier 乘子**三种实现（FNO 为其特例）；在 9 个 LNO 基准 + Burgers/Darcy/Navier–Stokes 上取得最低平均测试误差，且 Darcy 误差**从 $85^2$ 到 $421^2$ 网格几乎不变**（FNO 增长 8 倍）。

1. **理论刻画**：证明良态线性常系数边值问题在区间上的解算子是 **Toeplitz 算子（有理核）+ 有限秩 Hankel 型算子（承载边界信息）**；并引用 **Kronecker、Nehari、Adamyan–Arov–Krein** 经典结果刻画该核类：**稳定极点、有限 Hankel 秩、与区间长度无关的范数界**。
2. **三种算子实现**：
   - **非周期卷积**（用 FFT 求值，**因果形式**）；
   - **Lur'e 闭环算子**（用于**无衰减记忆**的动力学系统）；
   - **有理 Fourier 乘子**（**包含 FNO 作为特例**）。
3. **诊断 FNO 的两个结构性缺陷**：FNO **没有显式处理边界、初始态与瞬态的机制**；其误差在**无阻尼振子**上很大，且**随网格加密而增长**。
4. **经验结果**：在全部 9 个 LNO 基准与 FNO 的 Burgers/Darcy/Navier–Stokes 基准上**平均测试误差最低**；其中两项差异以及与参数匹配 FNO 的 Navier–Stokes 对比**不具统计显著性**（作者诚实标注）。
5. **网格无关性**：Darcy 误差从 $85^2$ 到 $421^2$ **几乎不变**，而 FNO 增长 **8 倍**。
6. **ODE 问题**：在 6 个 ODE 问题上把最优基线的平均误差**降低 2.1–5.2 倍**。

## 技术方案

### 核心思想

**Fourier 神经算子 (FNO)** 的核心假设是：PDE 的解算子可以表示为**傅里叶域中的核积分算子**，在周期网格上求值。这个假设带来三个已知问题：

1. **边界**——傅里叶基天然是周期的，不匹配边界条件；
2. **初始态与瞬态**——FNO 没有显式的机制处理它们；
3. **无阻尼振子**——这类问题的解算子在傅里叶域是**奇异**的（极点纯虚），FNO 的傅里叶乘子结构无法表达。

**Laplace 神经算子 (LNO)** 试图用极点–留数符号（pole–residue symbols）补救，但存在两个问题：极点**不受约束**，且仍在离散傅里叶网格上求值。

**HNO 的出发点是：不猜结构，而是从解算子本身导出结构。**

对良态线性常系数边值问题（区间上），其解算子可分解为：
- **Toeplitz 部分**：由有理核给出——核的傅里叶变换是**有理函数**（因而在傅里叶域是"有限维极点结构"）；
- **Hankel 部分**：**有限秩**，承载**边界信息**（这正是 FNO 缺失的部分）。

而经典理论（Kronecker / Nehari / Adamyan–Arov–Krein）保证：这样的核类具有**稳定极点、有限 Hankel 秩、与区间长度无关的范数界**——这解释了为什么该结构对边界、初值、瞬态都自然兼容。

HNO 由此实现三种形态：
- **非周期卷积**（FFT 实现，**因果**形式）——处理边界与初值；
- **Lur'e 闭环算子**——把"记忆"做成反馈回路，能表达**无衰减记忆**（无阻尼振子正是此类）；
- **有理 Fourier 乘子**——FNO 是其特例（在极点取单位圆上无约束退化的情形）。

这套推导的实践意义是：**HNO 的误差随网格加密而保持平稳**，因为它的核结构（有理 + 有限秩）与网格分辨率解耦；而 FNO 的离散傅里叶网格采样会随网格变化而引入误差放大。

### 关键技术

| 技术 | 说明 |
|------|------|

## 公式 / 理论要点

```math
% 良态线性常系数边值问题
\mathcal{L}u = f,\qquad u|_{\partial\Omega}=g
```

```math
% 解算子的结构定理：Toeplitz（有理核）+ 有限秩 Hankel（边界信息）
\mathcal{S} = \mathcal{T}_{\text{Toeplitz}} + \mathcal{H}_{\text{Hankel}},
\qquad
\operatorname{rank}\mathcal{H}_{\text{Hankel}} = K < \infty
```

```math
% Toeplitz 核：傅里叶变换为有理函数（稳定极点）
\hat{k}(\xi) = \sum_{m=1}^{M}\frac{c_m}{\xi - z_m},
\qquad \operatorname{Re}(z_m) > 0 \text{（稳定）}
```

```math
% Hankel 部分：承载边界数据（有限秩 → 可参数化为低秩矩阵）
\mathcal{H}_{\text{Hankel}} = \Phi\,\Psi^{T},
\qquad \Phi\in\mathbb{C}^{n\times K},\ \Psi\in\mathbb{C}^{n\times K}
```

```math
% 三种 HNO 实现之一：有理 Fourier 乘子（FNO 为其特例）
\widehat{\mathcal{S}u}(\xi)
= \left[\sum_{m=1}^{M}\frac{c_m}{\xi-z_m}\right]\hat{u}(\xi)
+ \widehat{(\Phi\Psi^{T}u)}(\xi)
```

```math
% 非周期因果卷积核（时域）
k(t) = \sum_{m=1}^{M} c_m\, e^{-z_m t}\,\Theta(t),
\qquad \Theta(t)\ \text{为因果性（Heaviside）因子}
```

```math
% Lur'e 闭环算子（表达无衰减记忆）
\mathcal{S}u = \Phi\,\mathcal{K}\,\Psi^{T}u,
\qquad
\mathcal{K} = \mathcal{K}_0 + \mathcal{K}_1 * \mathcal{K}_2 * \cdots
```

## 实验与结果

- **算例/数据集**: 9 个 **LNO 基准**（Laplace 神经算子论文的标准算例集）；**FNO 基准**中的 **Burgers、Darcy、Navier–Stokes**；6 个 **ODE 问题**。
- **对比基线**: FNO、LNO、两者变体、以及"参数匹配的 FNO"（为 Navier–Stokes 对比专门构造）。
- **主要结果**:
  - **9 个 LNO 基准 + Burgers/Darcy/N-S 上平均测试误差最低**。
  - **诚实的统计显著性标注**：其中**两项差异不显著**，以及与参数匹配 FNO 的 Navier–Stokes 对比**不显著**——这是本文值得学习的报告纪律。
  - **网格无关性**：Darcy 误差从 $85^2$ 到 $421^2$ **几乎恒定**；FNO 误差**增长 8 倍**。
  - **ODE 问题**：平均误差比最优基线**降低 2.1–5.2 倍**。
  - **FNO 缺陷诊断**：FNO 在无阻尼振子误差大，且误差随网格加密**增长**。
  - **消融实验**：支持各组件（Toeplitz 部分、Hankel 部分、Lur'e 分支）的独立贡献。

## 局限性

- **理论适用范围有限**：结构刻画针对**线性常系数**边值问题；对**非线性** PDE（Navier–Stokes、Burgers 强非线性段）只有经验结果，无理论保证。
- **部分优势不具统计显著性**：作者自陈——与参数匹配 FNO 的 Navier–Stokes 对比无显著差异，因此"超越 FNO"的强主张只在**边界问题/ODE/网格无关性**上成立。
- **秩 $K$、极点数 $M$ 等结构参数**需要选择，摘要未说明超参敏感性。
- **训练成本**：三种形态（尤其 FFT + 低秩项 + Lur'e 回路）的超参搜索空间更大，训练数据需求未知。
- 代码与数据的具体获取方式需查 PDF 正文。

## 实现建议

- **实现难度**: 中高 — 数学结构清晰但实现细节多（稳定极点参数化、Hankel 低秩构造、Lur'e 回路、因果核的 FFT 求值）；建议先在 ODE + 1D 线性 BVP 上复现核心结论。
- **预期性能**: 网格无关性是最实用的一点——**同一模型在不同分辨率下无需重训**；ODE 上 2–5 倍误差降低。
- **适用场景**:
  - **边界主导**的 PDE 求解（带 Dirichlet/Neumann 边界、初值问题）；
    - **无阻尼或弱阻尼**动力学系统（振子、波动方程）；
  - 需要**跨网格分辨率泛化**的代理模型（如实时仿真、参数扫描）；
  - 作为**神经算子家族的基线**——任何新算子都应与 HNO 对比，因为 HNO 重新定义了"算子应该长什么样"的理论标准。
- **可复用要点**:
  - **"从解算子结构出发构造模型"**是本文的方法论内核，比"从数据拟合结构"高一个层次。建议在自己的算子工作中先做**解算子的数学刻画**，再设计网络参数化。
  - **FNO 的三个缺陷清单**（无边界机制、无初值/瞬态机制、无阻尼振子失效、网格加密反而变差）可作为**评估任何神经算子时的检查项**。
  - **网格无关性应成为神经算子的标准报告项**：目前大量论文只报固定分辨率下的误差，掩盖了分辨率敏感性；建议在自建评测中固定加入 $85^2 \to 421^2$ 式的分辨率扫描。
  - **报告不显著差异的纪律**值得学习——本文主动标注两项"不显著"，比只报最好数字的论文更可信。
