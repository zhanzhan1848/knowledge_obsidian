## 核心贡献

> 提出 **NCUGKS**（nonequilibrium-capturing unified gas-kinetic scheme）用于**多频辐射输运**：辐射强度在离散角空间的正交基上展开，**角自由度的数量按每个单元、每个频组、每个象限的局部非平衡程度自适应**；在光学厚极限下每象限**只保留 1 个角自由度**，相比原始 DO-UGKS 实现**内存降低 21.7–154 倍、加速 24.87–257.9 倍**。

1. **问题定位**：传统离散坐标 (DOM/S$_n$) 方法使用**固定**角自由度数量，在**接近平衡**的区域造成无谓的计算开销 —— 而辐射输运中大部分区域恰恰接近平衡。
2. **核心机制**：通过**界面演化耦合输运与碰撞**（UGKS 的多尺度能力），辐射强度在离散角空间的**正交基**上展开，展开系数即角自由度。
3. **自适应维度**：角自由度的数量**独立地在每个（单元，频组，象限）内**按局部非平衡程度调整。
4. **选择准则**：每个时间步用**上一步的指数衰减贡献**与**界面输运要求**共同决定要演化的系数个数。
5. **宏观量修正**：被选系数用有限体积推进后，**先修正以匹配宏观辐射能量**，再按给定的**相对尾部容差**丢弃更高阶系数。
6. **极限行为**：光学厚极限下每象限**仅保留 1 个角自由度**。
7. **框架的普适性**：作者明确指出该方法为**其他离散坐标方法**自适应角自由度提供了框架。

## 技术方案

### 核心思想

辐射输运的经典困境：**角分辨率的全局统一分配** vs **局部非平衡程度的巨大空间差异**。

- 在**光学厚**区域：辐射接近各向同性（平衡），高阶角模态几乎无贡献 → 用高阶是浪费。
- 在**稀薄/强梯度**区域：强非平衡，高阶模态承载全部输运信息 → 必须保留。

NCUGKS 的解法：**把角空间离散成"可增删的正交基展开"**，而非固定的 S$_n$ 离散方向。

这是一个漂亮的想法：传统 DOM 的角方向是**固定的、不可增删的**；这里角自由度变成**一组可按需启用/停用的基系数**，且停用有**定量准则**（相对尾部容差）与**物理依据**（指数衰减贡献 + 界面输运需求）。

### 关键技术

| 技术 | 说明 |
|------|------|
| **UGKS 界面演化** | 耦合输运与碰撞，保留多尺度能力；相比传统 UGKS 的核心改进 |
| **角空间正交基展开** | 辐射强度 = 基函数线性组合，系数 = 角自由度 |
| **逐 (单元, 频组, 象限) 自适应** | 角自由度数量三维独立自适应 |
| **指数衰减贡献准则** | 用上一步各系数的时间衰减量判断哪些系数仍需演化 |
| **界面输运需求** | 界面演化要求的高阶信息也参与系数选择 |
| **宏观能量修正** | 演化后先修正以匹配宏观辐射能量（保证守恒/矩条件） |
| **相对尾部容差** | 丢弃高阶系数的定量阈值 |
| **多频处理** | 频组独立自适应 → 每个频组可用不同角分辨率 |
| **光学厚极限** | 每象限 1 个角自由度 |

## 公式 / 理论要点

```math
% 辐射强度在离散角空间的正交基展开
I(\mathbf{n},\mathbf{x}) = \sum_{m=0}^{M(\mathbf{x})} c_m(\mathbf{x})\,\psi_m(\mathbf{n}),
\qquad \langle\psi_m,\psi_{m'}\rangle = \delta_{mm'}
```

```math
% 角自由度数的三维自适应
M = M\!\left(\text{cell},\ \text{frequency group},\ \text{quadrant}\right)
\quad\text{各自独立决定}
```

```math
% 系数选择准则（上一步衰减 + 界面输运需求）
\mathcal{S} = \Big\{m:\ e^{-\lambda_m\Delta t}\ \text{未低于阈值}\Big\}
\ \cap\ \Big\{m:\ \text{界面演化需要}\Big\}
```

```math
% 宏观量修正 → 矩条件（守恒）
\sum_m c_m(\mathbf{x})\,E_m = E_{\mathrm{macro}}(\mathbf{x})
\quad\Longrightarrow\quad
\text{先修正，后截断}
```

```math
% 相对尾部容差截断
\frac{\left|\sum_{m>M} c_m \psi_m\right|}{\left|\sum_m c_m \psi_m\right|}
< \varepsilon_{\mathrm{tail}}
\quad\Longrightarrow\quad \text{丢弃 } m>M
```

```math
% 光学厚极限
I \text{ 接近各向同性} \quad\Longrightarrow\quad M = 1 \ \text{（每象限）}
```

```math
% 性能收益（vs DO-UGKS）
\text{内存降低}: 21.7 \sim 154.0\ \times,
\qquad
\text{加速}: 24.87 \sim 257.9\ \times
```

## 实验与结果

- **方法**: NCUGKS，多频辐射输运；正交基角展开 + 自适应角自由度 + 宏观能量修正 + 尾部容差截断。
- **验证**: 跨越不同**光学状态**（optical regimes）的数值测试，与参考解吻合良好，验证精度。
- **性能**（相对原始离散坐标 UGKS）：
  - **内存**降低 **21.7 – 154.0 倍**；
  - **加速** **24.87 – 257.9 倍**。
- **极限行为确认**: 光学厚极限下每象限仅保留 1 个角自由度。

## 局限性

- **仅辐射输运**（不含流体对流-辐射耦合的完整流固热耦合）。
- 自适应维度带来**网格/时间步相关的算法复杂度**（动态分配、跨步状态管理）。
- 宏观能量修正保证了矩条件，但**更高阶矩**是否守恒需查正文。
- 摘要未给出误差-速度折衷的具体曲线、并行效率、内存占用的绝对数值。
- 极端**各向异性散射**或**强非线性吸收**下的表现未说明。

## 实现建议

- **实现难度**: 中高。核心是"角空间的正交基展开 + 动态维度管理"，而非传统固定 S$_n$ 方向。
- **预期性能**: 在接近平衡占主导的真实辐射问题中，速度与内存收益可达**数量级**；但在高非平衡主导问题中收益趋近于 1（因为本来就几乎全部保留）。
- **适用场景**:
  - **辐射传热仿真**（燃烧、反应堆、热处理、玻璃熔炉）—— 这类问题通常大片区域接近平衡；
  - **多频辐射**（谱辐射）—— 每频组独立自适应是天然优势；
  - 作为**其他 DOM 方法自适应化**的框架模板。
- **可复用要点**:
  - **"固定离散 → 正交基 + 自适应维度"**是一条通用的降本路线：**任何离散对象集合都可以按局部需要增删成员**，只要能定义正交基和丢弃准则。
  - **"先修正宏观量，再截断高阶"**这个顺序很关键：保证守恒类性质不被截断破坏。这个"**修正优先于截断**"的原则可迁移到任何"降阶 + 保持矩条件"的场景。
  - **丢弃准则的构造**：用"上一步的指数衰减贡献"来预测当前是否还需要该模态 —— 这是一个**时间外推式的活跃集策略**，在很多稀疏化/自适应问题中可复用。
