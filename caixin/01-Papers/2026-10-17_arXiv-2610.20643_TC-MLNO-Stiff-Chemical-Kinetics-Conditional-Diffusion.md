## 核心贡献

> 提出 **TC-MLNO（热化学约束多尺度 Laplace 神经算子）** + **条件扩散采样** 框架，在 1D/2D/3D 反应流中以 **90%+ 速度** 替代 CVODE 求解化学 ODE，同时精度优于 DeepONet baseline

1. **问题背景**：反应流仿真中**刚性化学动力学**（stiff chemical kinetics）是计算瓶颈；数据驱动求解器对**训练状态覆盖**和**化学动力学跨度**敏感
2. **方法框架**：
   - **条件扩散模型**：学习**当量比条件**下温度与物种的联合分布，用于数据增强
   - **TC-MLNO**：多尺度 Laplace 神经算子，分快 / 中 / 慢物种到独立分支
3. **关键创新**：
   - **Laplace 神经层**（pole-residue）表示**瞬态非周期响应**
   - **多尺度分支**：快 / 中 / 慢物种分别学习
   - **热化学约束损失**：质量守恒 + 元素守恒 + 放热率
4. **性能**：
   - 扩散采样：vs 随机采样，第 95 百分位距离 ↓ 37.5%，后验误差 ↓ 92.7%
   - TC-LNO vs DeepONet：84.9% 模式误差更小
   - **vs CVODE**：化学 ODE 时间 ↓ 90.1%，总解时间 ↓ 62.6%

## 技术方案

### 核心思想

把**刚性化学动力学**的 ODE 求解看作一个**分布匹配 + 函数逼近**问题：
- **扩散模型**生成**物理一致的样本**（约束在火焰流形上）
- **Laplace 神经算子**学习**ODE 积分器**（多尺度结构）

### 关键技术

| 技术 | 说明 |
|------|------|
| Conditional diffusion model | 条件扩散采样（生成数据） |
| Laplace Neural Operator (LNO) | 极点-留数 Laplace 变换层 |
| Multiscale branching | 快 / 中 / 慢物种分离 |
| Thermochemical constraint loss | 守恒律硬约束 |
| Stiff ODE integration | 替代 CVODE |
| 1D / 2D / 3D flame cases | 多维验证 |

### 数学框架

**TC-MLNO**：每个 Laplace 层：
\[
\mathcal{L}u(t) = \sum_{k=1}^{K} \frac{r_k}{s - p_k}
\]
其中 \(p_k\) 是极点，\(r_k\) 是留数。

**多尺度分支**：
```
[T(t), Y(t)] input
        ↓
    [快物种分支] (小时间尺度)
    [中物种分支] (中间时间尺度)
    [慢物种分支] (大时间尺度)
        ↓
    [输出：dT/dt, dY/dt]
```

**热化学约束损失**：
```math
L = L_{\mathrm{data}} + \lambda_1 L_{\mathrm{mass}} + \lambda_2 L_{\mathrm{element}} + \lambda_3 L_{\mathrm{heat\ release}}
```

### 关键结果

| 框架 | 95th-percentile error | 速度 vs CVODE |
|------|---------------------|--------------|
| 随机采样 + DeepONet | 0.372 (基准) | 3× |
| 扩散采样 + DeepONet | 0.233 | 3× |
| 扩散采样 + TC-LNO | 0.081 | **10×** |

## 实验 / 验证

- **样本**：
  - 1D 预混火焰
  - 2D 发展射流
  - 3D 湍流燃烧器火焰
- **训练数据**：低维火焰数据 + 条件扩散增广
- **结果**：
  - 反应区位置保持
  - 放热结构保持
  - 化学敏感物种（自由基、含氮物种）误差 ↓ 88.0-88.9%

---

## 局限性

- **训练数据分布依赖**：扩散模型仍需**真实火焰数据**训练
- **当量比范围有限**：未涵盖极贫 / 极富燃条件
- **化学机理固定**：仅验证若干机理，未涵盖全部燃烧化学
- **3D 验证单例**：仅 1 个 3D 燃烧器火焰，普适性需更多验证
- **新物种加入**：迁移到新化学机理需重新训练
