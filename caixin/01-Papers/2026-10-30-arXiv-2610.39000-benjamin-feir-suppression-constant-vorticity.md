## 核心贡献

> 在**完整自由面水波方程**（而非形式化 NLS 近似）框架下**严格证明**：均匀常涡量背景可以把 Benjamin–Feir 调模不稳定性**完全抑制**，临界涡量为 $\gamma_c=2/\sqrt{3}$；当 $\gamma$ 越过该值，长波纵向扰动谱稳定。

1. **严格的稳定性-不稳定性跃迁定理**：对任意固定 $\gamma<2/\sqrt{3}$，证明充分小振幅的 Stokes 波**是 Benjamin–Feir 不稳定的**；对任意固定 $\gamma>2/\sqrt{3}$，证明这些波**对纵向长波扰动谱稳定**。
2. **从形式 NLS 提升到完整方程**：此前 Thomas、Kharif 与 Manna 的结论来自**形式非线性 Schrödinger 近似**（形式展开、未控制余项）；本文在**完整水波 Cauchy 问题**上完成证明，**在远离临界值处严格确认**了该形式预测的跃迁。
3. **临界值 $2/\sqrt{3}$ 的第一性来源**：该值是把重力与载波波数归一化后，均匀涡量背景对**群速度 / 调制方程**影响的精确阈值——不是经验拟合。
4. **对 CFD/自由面模拟的指导意义**：给出了"何时 Stokes 波列会失稳破碎、何时稳定"的**可计算判据**，可用于自由面 VOF/Level-Set 求解器中波列破碎子模型的开关准则。

## 技术方案

### 核心思想

**问题设定**：无限深水体，均匀常涡量 $\gamma$ 背景，背景流为剪切流

```math
\mathbf{u}_{0}(y)=-\gamma y\,\mathbf{e}_{x}
\quad\Longrightarrow\quad
\nabla\times\mathbf{u}_0=-\gamma\,\mathbf{e}_{z}\;\;(\text{或按约定 }+\gamma)
```

自由面 Stokes 波为**右行波**（沿 $+x$）。重力 $g$ 与载波波数 $k$ 归一到 1。

**物理直觉**：Benjamin–Feir 不稳定性的本质是**调模（modulation）不稳定性**——波列的振幅/相位受到长波慢变扰动而指数增长。当波在**有涡量（剪切）的背景流**上传播时：
- 剪切背景使 Stokes 波的**群速度**发生本质改变（不再等于无涡量时的 $\frac{1}{2}\sqrt{g/k}$）；
- 调制方程中**实部**（非线性频移系数与群速度的比值）因此改变符号；
- Benjamin–Feir 判据本质上就是"该比值符号为负"，于是**涡量可以在某个阈值以上翻转这个符号**，从而关闭不稳定性。

**为什么需要严格证明**：形式 NLS 展开是**渐近展开**，其误差在接近临界值（$\gamma\to\gamma_c$）时会与主项同阶，因此**形式结果在临界邻域内不可信**。本文的做法是：对完整自由面方程做**精确的线性化与谱分析**，在 $\gamma\neq\gamma_c$ 时通过符号论证直接得到结论。

**分析路线（方法本质）**：
1. 以 Stokes 波（精确解）作为基本解，写出自由面问题的线性化方程（扰动高度 $\xi$ 与速度势 $\phi$）；
2. 分离**纵向长波扰动**（平行于波传播方向，长波包络尺度）与高频载波，构造作用在 $\xi$ 上的**演化算子**；
3. 在紧化（compactified）无限深水带状区域上定义**加权函数空间**，分析算子的**谱**，判断是否存在指数增长的谱分支；
4. 关键引理把谱行为与一个**标量符号判据**联系起来，该判据在 $\gamma=2/\sqrt{3}$ 处变号——从而在临界值两侧分别落入不稳定/稳定两支。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Miles 自由面公式** | 带涡量背景流的标准自由面表述（运动学 + 动力学 Bernoulli），把涡量流化为表面边界值问题 |
| **Stokes 波精确解** | 深水线性波 $\eta=a\cos(kx-\omega t)$，$\omega^2=gk$（归一后 $\omega=1$） |
| **背景剪切 $-\gamma y\,\mathbf{e}_x$** | 均匀涡量背景；这是本文唯一的涡度参数，控制跃迁 |
| **调制/包络方程（NLS 形式）** | 慢变包络 $A(x,t)$ 的非线性演化方程；BF 判据落在其**实部系数**的符号上 |
| **群速度修正** | 涡量背景下 $c_g$ 相对无涡情形的偏离，是翻转判据的物理机制 |

| **临界值符号论证** | $\gamma_c=2/\sqrt{3}$ 两侧的符号引理，绕过 NLS 余项控制难题 |

## 公式

> 以下为**方法层面的本质形式**（自由面表述、调制方程结构、谱判据），系数符号与归一化约定以原文为准；论文的证明细节（49 页）依赖精确的系数，本文不复制其系数。

### 1. 带涡量背景的自由面表述（Miles 形式）

```math
\text{运动学（自由面 }z=\eta\text{）:}\quad
\eta_t+\mathbf{u}\cdot\nabla\eta=w\big|_{\eta}
```

```math
\text{动力学（表面 Bernoulli）:}\quad
\phi_t+\tfrac{1}{2}\lvert\nabla\phi\rvert^{2}
+g\eta+\tfrac{1}{2}\lvert\mathbf{U}\rvert^{2}
+\boldsymbol\omega\cdot\bigl(\mathbf{U}\cdot\nabla\phi\bigr)
=\text{const},
\qquad \mathbf{u}=\nabla\phi+\mathbf{U}
```

其中 $\mathbf{U}$ 为背景流、$\boldsymbol\omega$ 为其涡量；$\phi$ 为扰动速度势。

### 2. 背景流与涡量

```math
\mathbf{U}(y)=-\gamma y\,\mathbf{e}_x,\qquad
\nabla\times\mathbf{U}=-\gamma\,\mathbf{e}_z,
\qquad g=1,\; k=1
```

### 3. Stokes 波（线性化背景上的精确解）

```math
\eta^{(0)}(x,t)=a\cos(kx-\omega t),\qquad
\omega^{2}=gk\;\Rightarrow\;\omega=1,\qquad
\phi^{(0)}\propto e^{kz}\sin(kx-\omega t)
```

### 4. 调制方程的结构（形式 NLS 层面）

慢变包络 $A(x,t)$ 满足的**一般结构**（本节为方法本质形式，非原文精确系数）：

```math
\frac{\partial A}{\partial t}
+c_g(\gamma)\,\frac{\partial A}{\partial x}
+\,\mathrm{i}\,\frac{\varepsilon_{0}}{2}\,\frac{c_g(\gamma)}{c}\lvert A\rvert^{2}A
+\;\text{(色散修正)}\;=0
```

**Benjamin–Feir 判据**落在**实部系数的符号**上：

```math
\varepsilon_{0}\,\frac{c_g(\gamma)}{c}<0
\;\Longrightarrow\;\text{BF 不稳定},
\qquad
\varepsilon_{0}\,\frac{c_g(\gamma)}{c}>0
\;\Longrightarrow\;\text{调制稳定}
```

涡量 $\gamma$ 正是通过修正 $c_g(\gamma)$ 而改变该符号；**符号翻转的阈值**为

```math
\gamma_{c}=\frac{2}{\sqrt{3}}
\approx 1.1547\ \ (\text{归一化 }g=k=1)
```

### 5. 线性化自由面方程（谱分析的算子来源）

```math
\text{扰动高度:}\quad
\frac{\partial\xi}{\partial t}
=\frac{\partial\phi}{\partial z}\bigg|_{z=0}
+\bigl(\text{背景流与涡量引入的线性耦合项}\bigr)
```

```math
\text{扰动势（线性化 Euler）:}\quad
\Bigl(\partial_t+\mathbf{U}\cdot\nabla\Bigr)\nabla\phi
+\nabla\Bigl(\tfrac{1}{2}\lvert\nabla\phi\rvert^{2}+g\xi\Bigr)=0,
\qquad \nabla\cdot(\nabla\phi)=0,\quad \phi\to0\ (z\to-\infty)
```

### 6. 谱稳定判据（方法本质）

```math
\mathcal{L}_{\gamma}\xi=\lambda\,\xi
\quad\Longrightarrow\quad
\max_{\lambda\in\sigma(\mathcal{L}_{\gamma})}\operatorname{Re}\lambda
\begin{cases}
>0 & \Rightarrow \text{BF 不稳定}\\[2pt]
<0 & \Rightarrow \text{谱稳定（长波纵向扰动）}
\end{cases}
```

判据中的**符号引理**把 $\operatorname{sgn}\operatorname{Re}\lambda_{\max}$ 与 $\gamma-\gamma_c$ 的符号联系起来，从而在 $\gamma\neq\gamma_c$ 处直接得到结论（**不依赖 NLS 展开的余项控制**）。

## 实验结论

- **数据集/算例**：**不适用**（这是一篇严格的数学分析论文，无算例/实验；配套 Mathematica 文件用于符号推导与判据的数值佐证）。
- **基线/对照**：**形式非线性 Schrödinger 近似**（Thomas、Kharif 与 Manna 的 NLS 判据）作为对照理论；本文在完整方程上给出严格版本。
- **结果**：
  - **定理 A（不稳定性）**：对每个固定 $\gamma<2/\sqrt{3}$，**充分小振幅**的 Stokes 波是 Benjamin–Feir 不稳定的。
  - **定理 B（稳定性）**：对每个固定 $\gamma>2/\sqrt{3}$，这些 Stokes 波**对纵向长波扰动谱稳定**。
  - 两定理在**远离临界值处严格确认**了形式 NLS 近似所预测的稳定性跃迁。
  - 临界值 $\gamma_c=2/\sqrt{3}$（在 $g=k=1$ 归一化下）；临界点本身（$\gamma=\gamma_c$）的情形不在本文定理覆盖范围内。
  - 背景设定：右行波 + 均匀常涡量 $\gamma$ + 背景剪切流 $-\gamma y\,\mathbf{e}_x$；重力与载波波数归一为 1。

---

## 局限性

1. **临界值处未闭合**：$\gamma=2/\sqrt{3}$ 恰好是判据变号的点，本文定理只覆盖 $\gamma\neq\gamma_c$。临界点附近会出现**调制不稳定性与谱稳定性的"退化/临界"行为**（增长率趋零、可能的临界标度），需要额外的精细分析。
2. **仅"充分小振幅"**：不稳定性定理是**渐近于小振幅**的结论；对有限振幅的非线性（波陡化、破碎前非线性相互作用）不作断言。
3. **无限深 + 均匀涡量的理想化**：真实的**有限水深、涡量分布非均匀（分层/剪切层）、背景流随时间演化**都会改变判据；本文结果不自动适用。
4. **只覆盖纵向长波扰动**：横向/斜波扰动与**有限波数**扰动的稳定性（以及与涡结构的相互作用）未在结论范围内。
5. **单向右行波**：左行波、双向波列、以及与涡旋相互作用的波-涡相互作用问题未处理。
6. **严格证明的成本**：49 页的泛函分析 + 谱论证，**复现门槛极高**；配套 Mathematica 文件仅为辅助，核心证明不可机器验证。
7. **与 CFD 的接口未建立**：本文给出的是连续介质的解析判据，**未与自由面数值求解器的破碎子模型（如 WHITE/THINC/VoG 等）对接**，也未量化判据在离散网格上的失效边界。

  - **自由面 CFD 的波列破碎子模型开关**：在 Stokes 波列模拟中，以 $\gamma$ 与波陡度联合判定是否触发破碎（避免无条件启用破碎模型带来的能量不守恒）。
  - **海洋/水池大尺度长波模拟**的背景流设定参考（涡量背景的稳定性分区）。
  - **稳定性分析的理论基准**：为任何"涡量背景下的波-流耦合"数值模拟提供可信的对照结论。
- **落地建议**：
  1. **实现层面只需实现判据**：把 $\gamma_c=2/\sqrt{3}$（按 $g,k$ 重新归一化）为阈值，在自由面求解器中比较背景涡量与该阈值，决定是否启用破碎子模型与破碎后饱和。

  4. **与本知识库的另一篇 NLS 水波论文（2610.38679，广频带 NLS 推广）对照阅读**：一篇是"严格性"，一篇是"模型适用性"，共同界定了 NLS 系列模型在自由面问题中的可信区间。
  5. **CFD 层面的落地检查**：在含涡量背景的自由面算例（如旋涡破碎、水槽剪切）中做网格/时间步收敛，确认数值解在 $\gamma>\gamma_c$ 时确实不出现虚假破碎——这是判据的实用反证。
