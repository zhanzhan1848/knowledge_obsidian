## 核心贡献

> 为可压缩流-固耦合的**弥散界面（diffuse-interface）+ hypoelastic** 模型构造 HLLD Riemann 求解器，通过"锚定双次求值"把剪切系数 ρ(G+τ_xx) 纳入特征结构

1. 指出本模型的核心难点：应力演化是**非守恒**的，且不像 Kapila 类模型的体积分数项那样可以在 Riemann 求解之外处理
2. 剪切波一旦被解析，其阻抗由 **ρ(G+τ_xx)** 设定 → 该系数必须**进入** Riemann 求解的特征结构
3. 提出 **anchored HLLD**：在每个面**两次**求值 HLLD 扇，分别以相邻的单元中心态为锚；每个单元都从**锚定到自身状态**的通量推进
4. 建立 **HLL → HLLC → anchored HLLD** 三级波解析层次，统一在同一框架内
5. 证明局部结构性质：重构阶数下一致性、精确组分质量守恒、光滑场上切向动量/能量漂移在重构面跳跃阶数下消失

## 技术方案

### 核心思想

传统 HLLC 假设应力演化守恒或可外置。对 hypoelastic 弥散界面模型，**剪切系数进入特征结构**，无法外置。Anchored HLLD 通过在每个面用两个相邻单元态各求一次 HLLD 扇，把剪切波正确纳入。

### 关键技术

| 技术 | 说明 |
|------|------|
| Anchored HLLD | 面双次 HLLD 求值，各自锚定一侧单元中心态 |
| 三级波解析层次 | HLL（无接触）/ HLLC（仅接触）/ anchored HLLD（接触+剪切波）|
| Hypoelastic 客观率律 | 偏差应力在守恒律之外用客观率律推进 |
| 弥散界面 | 无单独计算的界面，避免显式界面追踪 |
| 结构性质证明 | 一致性、组分质量守恒、漂移收敛性 |
| 3D 激波-椭球相互作用 | 六个应力分量全部激活的验证算例 |

## 公式

```math
本构与守恒律:
  ∂/∂t (ρu) + ∇·(ρu⊗u) = -∇·σ + f
  ∂/∂t (ρE) + ∇·((ρE+p)u) = ∇·(σ·u)

偏差应力（守恒律之外，客观 hypoelastic 率律）:
  σ = -p I + τ,   τ ̇ = objective_rate(τ, D) - (G + τ:...) τ

剪切波阻抗 → 特征结构:
  ρ(G + τ_xx)  ∈  特征结构（不可外置）

Anchored HLLD 面通量:
  F_face = ½ [ F(U_L^anchored) + F(U_R^anchored) ] - ½ Σ a_k ΔU
  其中 U_L^anchored 以左单元中心态为锚，U_R^anchored 以右单元中心态为锚
  每个单元的推进: U_i^{n+1} = U_i^n + (dt/dx)(F_{i-1/2} - F_{i+1/2})
  且 F_{i-1/2} 锚定到 U_i^n（自身态），F_{i+1/2} 锚定到 U_{i+1}^n
```

## 代码片段

```cpp
// anchored HLLD 面通量骨架（MFC 风格）
template <typename T>
void anchored_hlld_flux(const T& UL, const T& UR, T& F) {
    // 每个面求两次 HLLD 扇
    HLLD_fan fan_L = solve_hlld_fan(UL, UR);   // 以 UL 为锚
    HLLD_fan fan_R = solve_hlld_fan(UR, UL);   // 以 UR 为锚

    // 剪切系数进入特征结构（不可外置）
    const double shear_L = UL.rho * (UL.G + UL.tau_xx);
    const double shear_R = UR.rho * (UR.G + UR.tau_xx);

    // 每个单元从锚定到自身状态的通量推进
    F = 0.5 * (fan_L.F(UL) + fan_R.F(UR)) - 0.5 * (fan_L.dF(UL) + fan_R.dF(UR));
}
```

## 实验结论

- **数据集**: 一维解析/半解析测试 + 二维生产算例（MFC 求解器）+ 三维激波-椭球相互作用
- **基线**: HLLC（仅解析接触间断）、HLL（两者都不尖锐解析）
- **结果**:
  - **anchored HLLD 同时解析材料接触间断与剪切波**；HLLC 仅解析接触；HLL 两者都不尖锐
  - 细化研究显示 anchored HLLD **收敛到精确解或半解析解**
  - 不连续场上展示**一阶漂移收敛性**
  - 光滑场上切向动量与能量漂移在重构面跳跃阶数下消失
  - 三维激波-椭球算例展示六个应力分量全部激活

---

## 局限性

- 一维/局部 Riemann 求解器，跨多材料界面的多相界面精度需更多测试
- Hypoelastic（而非 hyperelastic）模型，无法描述强大变形下的应力自洽性
- Diffuse-interface 厚度与网格强耦合，界面过薄导致分辨率不足
- 证明为局部结构性质，全局稳定性/收敛阶的严格理论尚未给出

## 实现建议

- **实现难度**: 高（Riemann 求解器 + hypoelastic 本构 + 客观率律三者耦合）
- **预期性能**: 每步成本约为 HLLC 的 1.3–1.6 倍（面双次 HLLD 求值），换来剪切波的解析精度
- **适用场景**: 冲击载荷下流-固耦合（ FSI 打靶、固体侵彻、爆炸）、可压缩多相材料界面
- 推荐结论：✅ 推荐实现；若需解析接触+剪切波同时存在，anchored HLLD 是当前最合适的层级
