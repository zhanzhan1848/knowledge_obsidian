## 核心贡献

> 系统量化**几何曲率**对剪切流中液滴变形与破碎的影响：几何 VOF（plicRDF 重构 + isoAdvector 输运 + AMR）在三种圆几何下与平面剪切流对照，发现曲率不仅移动破碎阈值（$Re_{cr}$ 随 $\kappa_F$ 增大而**降低**），还根本改变破碎前的变形形态（从对称颈缩变为非对称周向拉长与细丝断裂）。

1. **方法组合**：几何 Volume-of-Fluid + plicRDF 界面重构 + isoAdvector 界面输运 + 自适应网格加密 (AMR)。
2. **对照设计**：三种不同无量纲几何曲率 $\kappa_F$ 的圆形几何 vs 平面剪切流系统。
3. **形态学差异**：
   - 平面系统：液滴经历**相对对称**的颈缩 (neck thinning)；
   - 圆形系统：液滴出现**非对称变形**与明显的**周向拉长**；
   - 更高曲率下：液滴形成**细丝**并随后碎裂，产生**多个卫星液滴 (satellite drops)**。
4. **阈值与尺度律**：
   - 固定 $Re$ 与 $Ca$ 下，**临界破碎 Reynolds 数 $Re_{cr}$ 随曲率 $\kappa_F$ 增大而下降**；
   - 相反，$Re = Re_{cr}$ 时破碎前的**最大无量纲拉伸长度随 $\kappa_F$ 增大而增加**。
5. **内部流场诊断**：通过内部速度场与**变形率张量 (rate-of-deformation tensor) 量级**的分析，识别出与不同破碎行为对应的不同流动与变形结构。

## 控制方程

不可压缩两相流（空气 + 液滴）：

```math
\nabla \cdot \mathbf{u} = 0
$$

$$\rho\left(\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u}\cdot\nabla)\mathbf{u}\right) = -\nabla p + \mu\left(\nabla^2\mathbf{u} + \nabla(\nabla\cdot\mathbf{u})\right) + \mathbf{f}_{\rm surf}$$

**几何 VOF 的界面输运**：

```math
\frac{\partial \alpha}{\partial t} + \mathbf{u}\cdot\nabla\alpha = 0
$$

其中 $\alpha$ 为液相体积分数；$\mathbf{f}_{\rm surf}$ 为界面张力力（由重构曲率给出）：

$$\mathbf{f}_{\rm surf} = \sigma\,\kappa\,\delta(\alpha)\,\nabla\alpha$$

**无量纲参数**：

| 参数 | 含义 |
|------|------|
| $Re$ | Reynolds 数 |
| $Ca$ | Capillary 数（$Ca = \mu U/\sigma$） |
| $\kappa_F$ | **无量纲几何曲率**（几何引入的特征量） |

**变形率张量**（用于诊断拉伸结构）：

$$\mathbf{D} = \frac{1}{2}\left(\nabla\mathbf{u} + (\nabla\mathbf{u})^{\mathsf T}\right),\qquad \text{量级} \sim \|\mathbf{D}\|$$

## 数值方法

| 技术 | 说明 |
|------|------|
| **方法** | 几何 Volume-of-Fluid (VOF)，两相流 |
| **界面重构** | **plicRDF**（piecewise-linear interface reconstruction on locally-reconstructed Delaunay triangulation） |
| **界面输运** | **isoAdvector**（等值面输运，anti-diffusive） |
| **网格** | 自适应网格加密 (**AMR**)，带曲率加细 |
| **几何** | 三个圆几何（不同 $\kappa_F$）+ 平面剪切流对照 |
| **力学** | 固定 $Re$ 与 $Ca$，扫描 $Re$ 以确定 $Re_{cr}$ |
| **诊断** | 内部速度场 + 变形率张量量级 |

## 实验结论

- **破碎形态**：平面 → 对称颈缩；圆几何 → 非对称变形 + 周向拉长；高曲率 → 细丝 + 碎裂 + 多卫星液滴。
- **$Re_{cr}$ 随 $\kappa_F$ 增大而降低**（在所考察的各个 $Ca$ 值下均成立）。
- **破碎前最大无量纲拉伸长度在 $Re = Re_{cr}$ 时随 $\kappa_F$ 增大而增加**——说明曲率同时改变**阈值**与**通向破碎的变形路径**。
- 内部流场与 $\mathbf{D}$ 量级显示，不同破碎行为对应不同的流动/变形结构（周向拉伸主导 vs 局部颈缩主导）。

---

## 局限性

- 圆形几何曲率 $\kappa_F$ 的取值范围有限，仅三个几何 + 一个平面基准。
- $Ca$ 的取值范围未在摘要中给出具体跨度；$Ca$ 与 $\kappa_F$ 的耦合交互未系统扫描。
- 未考虑**旋转轴线**本身的影响（同心反向旋转 vs 平行旋转等），剪切率沿周向的空间不均匀性被"几何曲率"这一单一变量吸收。
- 二维假设未明确说明（若为二维计算则卫星液滴的统计意义受限）。
- isoAdvector 的 anti-diffusive 特性在强拉伸细丝阶段的稳健性依赖 AMR 策略，本文未详细讨论细化的判据。

## 实现建议

- **实现难度**：★★★☆（plicRDF + isoAdvector + AMR 的组合在 OpenFOAM/基础库中已有实现；但曲率几何下的 AMR 判据与破碎时刻的准确捕捉需要细致调参）
- **预期性能**：2D/3D 两相流 AMR 计算，破碎事件需要细网格与细时间步（拉伸薄片阶段 CFL 限制主导）
- **适用场景**：
  - **弯曲剪切流 / 微流道中的液滴破碎**（流体型生物流体、细胞剪切、液滴微反应器）
  - 几何曲率对界面张力主导流动的影响评估
  - 几何 VOF 方法的基准验证算例
- **可迁移点**：
  1. "$Re_{cr}$ 随几何曲率降低" 是可迁移的**定性设计规律**——微流道设计中，弯道会提前液滴破碎
  2. **变形率张量**是比速度场更直接的破碎前兆诊断量，可用于在线破碎判据
  3. plicRDF + isoAdvector + AMR 是当前两相流开源实现的实用组合，DAVOF 的后续版本可作为几何内核的替换
