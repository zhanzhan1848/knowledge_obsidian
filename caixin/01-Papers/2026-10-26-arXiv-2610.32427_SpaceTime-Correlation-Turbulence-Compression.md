## 核心贡献

> 用"空-时相关算子"替代 snapshot POD 做湍流场压缩，并首次用模态 TKE 能量预算作为"合格性认证"指标

1. 压缩的相关系数矩阵跨**空间+时间**，比 snapshot POD 大**两个数量级**（时间维带来大量额外基）
2. 用**随机化区间查找器**（randomized range finder）+ **通信规避层次 QR**（communication-avoiding hierarchical QR）提取主范围，GPU 加速、分布式可扩展
3. 提出**分级诊断体系**：瞬时重构 → 二阶统计量 → 模态 TKE 预算 → 非线性尺度间传递；证明**预算项对压缩误差远比场误差/单点误差敏感**
4. 给出可压缩率的定量标度：线性预算项 ∝ 丢弃能量^0.8，三重传递 ∝ 丢弃能量^（>1）

---

## 技术方案

### 核心思想

传统 snapshot POD 只在单快照上做空间相关，无法捕捉时间演化。本文把相关系数矩阵扩展到时空联合空间，得到指数上远多的基向量，从而在同样保留能量下获得更低的空间误差。

### 关键技术

| 技术 | 说明 |
|------|------|
| 空-时相关矩阵 | C(空间坐标对 × 时间坐标对)，规模比 snapshot POD 大 ~10² 倍 |
| 随机化区间查找器 | randomized range finder，随机采样+幂迭代，低通信量 |
| 通信规避层次 QR | CAQR，分布式 SVD 的核心，避免全局同步 |
| 模态 TKE 预算认证 | 用能量预算闭合性作为压缩质量判据 |
| 尺度间三重传递 | 三非线性相互作用项，最敏感的诊断量 |

## 公式

```math
时空相关算子:
C_{(x,t),(x',t')} = ⟨ u'(x,t) ⊗ u'(x',t') ⟩ / (σ_u σ_u)

模态 TKE 预算:
∂/∂t K(k) + P(k) = ε(k) - D(k)
  K(k) = ½|û(k)|²            (模态动能)
  P(k) = 压缩项 → 三重传递 T(k)
  D(k) = 粘性耗散（近壁主导）

误差标度:
  线性预算项误差 ∝ (丢弃能量)^{0.8}
  三重传递误差   ∝ (丢弃能量)^{1+ε},  ε > 0
```

## 代码片段

```python
# 随机化区间查找器 + 层次 QR 的分布式低秩分解骨架
def randomized_range_finder(A, omega, n_power_iter=2):
    Y = A @ omega                      # 随机采样（行分布）
    Q, _ = np.linalg.qr(Y)
    for _ in range(n_power_iter):      # 幂迭代加强
        Q, _ = np.linalg.qr(A.T @ Q)
        Q, _ = np.linalg.qr(A @ Q)
    return Q

def compress_space_time(U, n_modes, rank):
    """U: (space*time, n_fields) 大矩阵"""
    # 时空重排 + 分块 CAQR，避免单点稠密奇异值分解
    A = build_space_time_correlation(U)
    Q = randomized_range_finder(A, omega=sample_block(), n_power_iter=2)
    B = Q.T @ A
    Uhat, S, Vt = ca_qr_svd(B)        # 通信规避层次 QR
    return Uhat[:, :n_modes], S[:n_modes], Vt[:n_modes]
```

## 实验结论

- **数据集**: 受控扩散式压气机叶栅 (diffusion compressor cascade) 的两套 DNS——层流进口 / 湍流进口
- **基线**: snapshot POD（仅空间相关）
- **结果**:
  - **预算项比场误差/单点误差敏感得多**：激进压缩下所有单点统计量仍在几个百分点内，但近壁耗散与尺度间传递**误差恶化一个数量级**
  - 近壁耗散与尺度间传递退化最严重，**共同决定可接受的压缩上限**
  - 耗散误差**局限于粘性底层**，随边界层发展而增长，且由**高阶模态**携带
  - 保守压缩下预算项保持准确；一旦放松保留能量阈值即急剧退化

---

## 局限性

- 仅测试受控压气机叶栅（含壁面边界层），未覆盖自由剪切/衰减湍流
- 线性化低秩假设对强非线性场（如激波、界面）可能失效
- 随机化区间查找器的秩估计依赖采样质量，理论保证弱于确定性 SVD
- 时间维扩展使矩阵规模急剧上升，虽然分布式缓解但内存仍是瓶颈

## 实现建议

- **实现难度**: 高（分布式 + GPU + 层次 QR 实现复杂）
- **预期性能**: 相比 snapshot POD，同等保留能量下空间误差显著降低；但时空矩阵内存占用是主要瓶颈
- **适用场景**: 大规模 DNS 数据归档、LES/DES 数据后处理、长期 DNS 数据库压缩
- 推荐结论：✅ 推荐作为 DNS 数据压缩的**认证标准流程**——用 TKE 预算闭合性而非场误差来判断压缩是否可接受
