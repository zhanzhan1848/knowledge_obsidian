## 核心贡献

> **静电驱动微梁的挤压膜 (squeeze-film) 阻尼**同时**引入阻尼与附加刚度**，且**膜的动力学可与微梁的非线性响应相互作用**。本文将基于**耦合流固问题复特征模态 (complex modes)** 构建的**降阶模型 (ROM)** 扩展到**周期响应及其稳定性**的计算（针对**双端固支 (clamped-clamped)** 微梁）：**在频域中延拓周期轨道**，并由 **Floquet 乘子**确定其稳定性；用**吸引子盆 (basins of attraction)**、**完整性度量 (integrity measures)** 与**动态 pull-in 图 (dynamic pull-in maps)** 在激励参数平面内评估响应的**鲁棒性**。模型对照**微开关 (microswitch) 的实测与计算频响**得到验证。推导了**流体弛豫模态的闭式表达**及**强耦合膜的修正项**，并定义了一个**刻画膜所处状态 (regime) 的参数**。**关键结论**：对所有被模拟的器件，**单个流体模态是必要且充分的**；**增加耦合模态不能替代它**——无论流体模态是**准静态响应**还是**携带自身动力学**。**去掉流体模态**会：**移动界定 pull-in 带的两个分岔**、**改变吸引子盆的尺寸与吸引子在盆中的位置**、**漏掉激励增大时安全盆的突然侵蚀**、以及**整体平移动态 pull-in 区域**。该**降阶模型仅需三个实未知量**，使**全耦合流固系统的全局分析成为可能负担得起**。

1. **物理机制**: 静电驱动微梁与基底之间的**挤压膜**：
   - 提供**阻尼**；
   - 同时**增加刚度**；
   - **膜自身的动力学**与微梁的**非线性响应**相互作用。
2. **方法扩展**: 把基于**耦合流固问题复特征模态**的降阶模型扩展到**周期响应与稳定性**（此前主要用于线性频响）。
3. **周期轨道延拓**: **在频域中延拓周期轨道**——避免时域 shooting 的初值敏感性。
4. **稳定性判定**: 由 **Floquet 乘子 (Floquet multipliers)** 确定周期轨道稳定性。
5. **全局鲁棒性评估**（本文最有价值的部分）：
   - **吸引子盆 (basins of attraction)**
   - **完整性度量 (integrity measures)**
   - **动态 pull-in 图**（在激励参数平面内）
6. **验证**: 对照**微开关的实测与计算频响**。
7. **理论贡献**:
   - 推导**流体弛豫模态的闭式表达**；
   - 给出**强耦合膜的修正项**；
   - 定义一个**刻画膜所处 regime 的参数**。
8. **核心结论（模型阶数的判据）**:
   - 对**所有被模拟的器件**：**单个流体模态是必要且充分的**；
   - **增加耦合模态不能替代它**——无论流体模态是**准静态**响应还是**携带自身动力学**；
   - **去掉流体模态**会**同时**：
     - **移动界定 pull-in 带的两个分岔**；
     - **改变吸引子盆的尺寸**与**吸引子在盆中的位置**；
     - **漏掉激励增大时安全盆的突然侵蚀 (abrupt erosion of the safe basin)**；
     - **整体平移动态 pull-in 区域**。
9. **工程价值**: 降阶模型**仅需三个实未知量**，使**全耦合流固系统的全局分析**变得**负担得起 (affordable)**。

## 技术方案

### 核心思想

**背景：MEMS 微梁与挤压膜**

**静电驱动微梁 (electrostatic microbeam)**：微梁两端固定，受静电吸引；梁与基底之间的间隙流体被**挤压**，产生**挤压膜阻尼 (squeeze-film damping)**。

**挤压膜阻尼的特性**：
- 间隙 $h(t)$ 减小时，膜的**排流阻力剧增** → 强阻尼；
- 膜还像"气体弹簧"一样提供**附加刚度**（体积压缩导致的压力恢复）；
- 关键的物理参数是**压缩数 (squeeze number)**：
  $$S = \frac{12\mu\omega a^2}{p_\infty h^3}$$
  - $S \ll 1$：膜**准静态**（流体来得及调整）
  - $S \sim 1$：**过渡区**
  - $S \gg 1$：流体**来不及响应**，膜呈**惯性主导**，行为像"固体/不可压缩"
  - **本文定义了一个参数来刻画膜所处的 regime**（这正是那个 regime 参数）

**为什么难**

**静电–机械–流体三重耦合**：
1. 静电力 $\sim 1/gap^2$ → **强非线性**；
2. 流体膜有**自己的动力学**（弛豫模态）；
3. 微梁的**大挠度** → 几何非线性；
4. **动态 pull-in**：静电负刚度超过机械正刚度时，微梁**跳下吸附**（传统 pull-in 是静态失稳，这里是动态的）。

**完整系统的全局分析不可行**（全耦合 CFD + 固体力学 + 电路，时间尺度跨越多个量级）。

**本文的降阶策略**

**复特征模态 (complex modes)**：耦合流固问题的特征值问题是**非自伴的 (non-self-adjoint)** → 特征值是复数 → 特征向量不构成正交基 → **标准模态降阶失效**。

**复模态降阶 (CMA)**：用复特征向量（加上其共轭）构造**二阶实数 ODE** 描述流固耦合系统：
$$\begin{bmatrix}\ddot{q}\\ \dot{q}\end{bmatrix} = \boldsymbol{A}\begin{bmatrix}\dot{q}\\ q\end{bmatrix},\qquad \boldsymbol{A}\in\mathbb{R}^{2N\times2N}$$

**降阶**：只保留**关键的少数模态**（本文：**1 个流体模态** + 微梁的少数模态）→ **三个实未知量**。

**频域周期轨道延拓**

对于周期解 $\boldsymbol{x}(t)=\hat{\boldsymbol{x}}e^{i\omega t}$，代入降阶 ODE 得到**代数特征值问题**：
$$\left[\boldsymbol{A} - (i\omega)\boldsymbol{I}\right]\hat{\boldsymbol{x}} = \boldsymbol{0}$$

**为什么频域延拓比时域 shooting 好？**
- **时域 shooting**：需要猜初值 → 对周期解**极其敏感** → 收敛困难；
- **频域延拓**：周期解由**代数方程**给出 → 用**伪弧长延拓 (pseudo-arclength continuation)** 沿激励参数扫过 → 稳定、可追踪分岔点。

**Floquet 稳定性**

周期轨道 $\boldsymbol{x}_p(t)$ 的稳定性由**变分方程**的**单周期映射 (monodromy matrix)** 决定：
$$\boldsymbol{M} = \boldsymbol{\Phi}(T),\qquad T = \frac{2\pi}{\omega}$$
Floquet 乘子 = $\boldsymbol{M}$ 的特征值。若所有 $|\lambda_i|<1$ → 稳定。

**全局鲁棒性：三个工具**

| 工具 | 回答的问题 | 意义 |
|------|----------|------|
| **吸引子盆 (basins of attraction)** | 哪些初始条件最终落到哪个稳定态？ | 抗扰动能力 |
| **完整性度量 (integrity measures)** | 吸引子盆的大小/形状如何随参数变化？ | 结构化度量 |
| **动态 pull-in 图 (pull-in maps)** | 在**激励参数平面**内，pull-in 区域在哪里？ | 设计安全边界 |

**为什么必须包含流体模态？（本文的核心论证）**

这是一个**降阶模型保真度的判据问题**，本文给出了非常清晰的答案：

**去掉流体模态**（即把膜当作纯静态弹簧/阻尼）会**同时**破坏**四类**东西：
1. **界定 pull-in 带的两个分岔的位置** → 分岔点位置错误 = 阈值预测错误；
2. **吸引子盆的尺寸**与**吸引子在盆中的位置** → 抗扰动能力估计错误；
3. **激励增大时安全盆的突然侵蚀** → **完全漏掉一个非线性现象**（不是精度问题，是**现象缺失**）；
4. **整体平移动态 pull-in 区域** → 整个安全区判错。

**而增加更多耦合模态不能替代那一个流体模态**——无论膜是准静态还是有自己的动力学。

这个论证的**方法论价值极高**：
> **降阶模型的阶数不应由"贡献能量的大小"决定，而应由"被捕获现象的完整性"决定。**

一个贡献能量很小的模态，可能承载着**现象的存在与否**（如"安全盆的突然侵蚀"）——这种定性现象**无法由"增加精度"得到**，只能由"保留正确的模态"得到。

## 公式 / 理论要点

```math
% 静电驱动微梁（含大挠度几何非线性）
EI\,\partial_x^4 w
= \rho A\,\partial_t^2 w
+ \frac{1}{2}\epsilon_0 A V^2\,\frac{\partial^2}{\partial x^2}
\left(\frac{1}{(g_0-w)^2}\right)
- N_{\text{mem}}(t)
```

```math
% 挤压膜的线性化（Fluid-Structure Interaction）
\frac{\partial p}{\partial t}
+ \frac{1}{r^2}\frac{\partial}{\partial r}
\left(r^2\frac{\partial p}{\partial r}\right)
= \frac{\partial}{\partial z}\left(\frac{h^3}{12\mu}\frac{\partial p}{\partial z}\right),
\qquad
N_{\text{mem}} = \pi R^2 p(0,t)
```

```math
% 压缩数（膜的 regime 判据，本文定义了对应参数）
S = \frac{12\mu\,\omega\,a^2}{p_\infty\,h^3},
\qquad
\begin{cases}
S\ll 1: & \text{准静态流体}\\
S\sim 1: & \text{过渡}\\
S\gg 1: & \text{惯性主导}
\end{cases}
```

```math
% 复模态降阶：二阶实数 ODE
\frac{d}{dt}\begin{bmatrix}\dot{q}\\ q\end{bmatrix}
= \boldsymbol{A}\begin{bmatrix}\dot{q}\\ q\end{bmatrix},
\qquad
\boldsymbol{A} = \begin{bmatrix} \boldsymbol{M} & \boldsymbol{K}\\ -\boldsymbol{I} & 0\end{bmatrix}
```

```math
% 频域周期轨道：代数特征值问题（避免 shooting 的初值敏感性）
\left[\boldsymbol{A} - (i\omega)\boldsymbol{I}\right]\hat{\boldsymbol{x}} = \boldsymbol{0},
\qquad
\boldsymbol{x}_p(t)=\Re\!\left[\hat{\boldsymbol{x}}e^{i\omega t}\right]
```

```math
% Floquet 稳定性（单周期映射）
\boldsymbol{M} = \boldsymbol{\Phi}(T),\qquad T=\frac{2\pi}{\omega},
\qquad
|\lambda_i(\boldsymbol{M})| < 1 \iff \text{周期轨道稳定}
```

```math
% 拉格朗日乘子形式的伪弧长延拓（追踪分岔）
\boldsymbol{G}(\boldsymbol{x},\lambda) = \boldsymbol{0},
\qquad
\boldsymbol{G}'(\boldsymbol{x},\lambda)\cdot\dot{\boldsymbol{z}} = 0
\quad\Longleftrightarrow\quad
\text{沿参数平面追踪解支}
```

```math
% 降阶保真度判据（本文核心）
\text{单个流体模态} \ \text{必要且充分},
\qquad
\text{去掉它} \Rightarrow
\begin{cases}
\text{两个界定 pull-in 带的分岔位置改变}\\
\text{吸引子盆尺寸与吸引子位置改变}\\
\text{安全盆的突然侵蚀 (定性现象) 丢失}\\
\text{动态 pull-in 区域整体平移}
\end{cases}
```

## 实验与结果

- **方法**: 基于**复特征模态**的降阶模型，扩展到**周期响应 + Floquet 稳定性 + 全局分析**。
- **器件**: **双端固支 (clamped-clamped)** 静电微梁 + 挤压膜。
- **验证**: 对照**微开关 (microswitch)** 的**实测频响**与**计算频响**。
- **理论成果**:
  - **流体弛豫模态的闭式表达**；
  - **强耦合膜的修正项**；
  - **刻画膜 regime 的参数**。
- **核心结论**:
  - 对**所有被模拟的器件**，**单个流体模态是必要且充分的**；
  - **增加耦合模态不能替代它**——无论流体模态是**准静态**还是**携带自身动力学**；
  - **去掉流体模态**的**四项后果**（分岔位置、吸引子盆尺寸/位置、安全盆突然侵蚀、pull-in 区域平移）如上。
- **工程结论**: 降阶模型**仅需三个实未知量** → **全耦合流固系统的全局分析负担得起**。
- **参数扫描范围**: 涵盖**流体模态在振荡时间尺度上弛豫**的情形（$S\sim1$）。

## 局限性

- **梁模型简化**：膜的轴向变化（$z$ 方向）被简化，膜按**轴对称径向流动**处理；真实微梁的膜几何与间隙分布非均匀。
- **膜流体假设**：不可压牛顿流体、间隙内充满气体；**真实 MEMS 气体有可压缩性**（Knudsen 数、稀薄效应）未涉及。
- **仅双端固支**：其他边界条件（简支、悬臂）未讨论。
- **周期响应假设**：只处理**周期激励**；**准静态/瞬态响应**（如冲击、阶跃）未涉及。
- **降阶的固有局限**：模态截断的误差未被系统量化（只通过"与实测频响对照"间接验证）。
- **未做完整的实验测量**：验证是对照已有微开关的实测频响，本文未报告新的实验。
- **未讨论数值计算稳定性**：吸引子盆计算需要大量初值扫描，成本虽低但非零。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — 挤压膜模型 + 复模态降阶 + 伪弧长延拓 + Floquet 计算 + 吸引子盆扫描。每一环都有成熟方法，但**组合起来**需要仔细的数值设计。
- **预期性能**: ROM 只有**三个实未知量** → 单次轨道求解极快；**吸引子盆**需要大量初值（$10^4$–$10^6$），但在降阶模型上仍可行。这正是本文的核心工程主张。
- **适用场景**:
  - **MEMS 可靠性与设计**：微开关、RF MEMS、压力传感器的动态 pull-in 阈值与安全裕度；
  - **流固耦合的全局稳定性分析**：本文是"全耦合系统的全局分析负担得起"的一个具体证明；
  - **降阶模型阶数的选择方法**：本文的论证范式可推广到任何"要不要保留某个模态"的决策；
  - **与流体仿真结合**：可作为"高精度 CFD 校准低阶 ROM"的典型案例。
- **可复用要点**:
  - **"降阶的充分性判据 = 现象完整性，而非精度"** 是本文最值得归档的方法论：
    > 一个模态若承载了**定性现象的存在与否**（如"安全盆突然侵蚀"），它就是**必要的**，无论其能量贡献多小。
    > 而**增加更多同类型的模态**（如再加几个流体模态）**不能**替代它。
    这条原则应写入本知识库"数值方法/降阶模型"目录，并在自建 ROM 时作为**验收检查项**。
  - **频域延拓 + Floquet** 是周期系统全局分析的**稳健路线**，避免了时域 shooting 的初值敏感性——这个技术组合适用于所有周期系统的分岔追踪。
  - **"完整性度量"作为吸引子盆的结构化描述**比单纯的盆面积更有信息量，适合作为设计判据。
  - **压缩数 $S$ 是挤压膜 regime 的通用判据**，在 MEMS/润滑/密封问题中广泛使用，值得作为独立知识条目。
  - **与本轮 [[2026-11-12-arXiv-2611.12045-Variational-Principles-Dissipative-Continua]] 关联**：后者讨论耗散连续体的变分原理，本文是**耗散（膜阻尼）在降阶框架中的体现**——变分/能量视角可解释为何膜的耗散特性对稳定性至关重要。
