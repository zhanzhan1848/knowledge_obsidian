## 核心贡献

> 针对**快波**（波速快于近地面风，**临界层缺失**）的风-波动量传递，建立了一个**解析框架**：在波跟随坐标下对粘性 Orr–Sommerfeld 方程做 **WKBJ 渐近展开**，把波致气流分解为携带主导运动的**外层 Rayleigh 模态** + 提供相移的**薄粘性 Stokes 层**，从而给出压力型应力 (form stress) 的显式渐近表达式（$\propto R^{-1/2}$），并通过**长波展开 (LW)** 处理近壁强剪切区、用**常应力有效粘性**对接壁模型。

1. **两模态 WKBJ 解**：外层 Rayleigh 模态 + 内层粘性 Stokes 层；Stokes 层提供产生压力型应力所需的**相位滞后**。
2. **显式形式应力渐近式**：主导阶上 form stress 按**波 Reynolds 数的平方根倒数**标度，系数由外层响应的**积分**决定；动量从**波**传给**空气**。
3. **指数型平均剖面的闭式解**：WKBJ 近似对指数剖面给出**闭式表达**。
4. **LW–WKBJ 匹配**：为真实壁面束缚剖面的近表面剧烈变化，发展**按 $k^2$ 幂次的长波展开**保留完整的平均速度变化，并与外层 WKBJ 模态**匹配 (matching)**。
5. **壁模型兼容**：对壁模型模拟（第一解析层位于粘性底层之上），将 Stokes 层中的**分子粘性替换为常应力有效粘性 (constant-stress effective viscosity)**。
6. **两阶段验证**：(a) 与粘性 Orr–Sommerfeld 方程的**数值解**对比（分离出渐近误差）；(b) 与**壁面分辨**和**壁模型 LES** 的波致场对比（检验约化动力学）。
7. **有效性诊断**：给出仅依赖平均剖面与波参数的**判据**，指示外层近似在何处可用。

## 控制方程

### 1. 波跟随坐标系与几何变换

波跟随坐标 $\xi = x - ct$；非正交曲线变换：

$$\zeta = Z + G(\zeta)\eta(\xi),\qquad G(0) = -1,\qquad G(\zeta)\to 0\ \ (\zeta\to\infty)$$

可逆性要求 $1 - \eta G'(\zeta) > 0$。小陡度假设 $ak \ll 1$。

**表面高程与线性轨道速度**：

$$\eta(\xi) = a\sin(k\xi),\qquad \widetilde{u}_s(\xi) = akc\sin(k\xi),\qquad \widetilde{w}_s(\xi) = -akc\cos(k\xi)$$

$$c = \left(\frac{g}{k}\right)^{1/2}\quad\text{（深水波相速度）}$$

**Fourier 约定**：

$$\widetilde{f}(\xi,\zeta) = 2\,\mathrm{Re}\left\{\widehat{f}(\zeta)e^{ik\xi}\right\}$$

### 2. 粘性 Orr–Sommerfeld 方程（波跟随形式）

$$\frac{\partial}{\partial t}\mathbf{u} + \mathbf{u}\cdot\nabla\mathbf{u} = -\nabla p + \nu\nabla^2\mathbf{u},\qquad \nabla\cdot\mathbf{u} = 0$$

相位平均后化为单方程（垂直速度振幅）：

$$\frac{\partial \hat{w}}{\partial t} = \frac{\nu}{ik}\left(\frac{d^2}{d\zeta^2} - k^2\right)^2\hat{w} - \left[(\overline{U}-c)\left(\frac{d^2}{d\zeta^2}-k^2\right) - \frac{d^2\overline{U}}{d\zeta^2}\right]\hat{w} + \text{(几何源项)}$$

**无量纲化**（长度 $\sim k^{-1}$，速度 $\sim c$）：

$$z = k\zeta,\qquad \overline{u}(z) = \frac{\overline{U}(\zeta)}{c},\qquad w(z) = \frac{\hat{w}(\zeta)}{c},\qquad R = \frac{c}{k\nu}$$

$$\frac{i}{R}\left(w'''' - 2w'' + w\right) + (\overline{u}-1)(w''-w) - \overline{u}''w = \frac{1}{R}F(z)$$

**几何源项**：

$$F(z) = (k\hat{\eta})\left\{G(z)\overline{u}''(z)\right\}'' = -\frac{iak}{2}\left\{G(z)\overline{u}''(z)\right\}''$$

**波 Reynolds 数**：

$$R = \frac{t_\nu}{t_a},\qquad t_\nu = (\nu k^2)^{-1},\qquad t_a = (kc)^{-1}$$

$R \gg 1$ 时，$R^{-1}$ 乘在最高阶导数上 → **奇异摄动的四阶方程**（这是 WKBJ 展开的出发点）。

### 3. 快速波的定义

$$\Delta(z) = 1 - \overline{u}(z) = \frac{c - \overline{U}(\zeta)}{c},\qquad V(\zeta) = \overline{U}(\zeta) - c = -c\,\Delta(k\zeta)$$

**快波条件**：$\Delta > 0$（即 $V < 0$）在整个波耦合区内成立 → Rayleigh 算子**无临界层奇异性**。

**边界条件**：

$$w(0) = w_s = -\frac{ak}{2},\qquad w'(0) = w_s' = \frac{ak}{2}\left[\overline{u}'(0) - 1\right],\qquad w, w' \to 0 \ (z\to\infty)$$

### 4. 响应分解

$$w = w_h + w_F$$

$$\mathcal{L}_R[w] \equiv \frac{i}{R}(D^2-1)^2 w + (\overline{u}-1)(D^2-1)w - \overline{u}''w,\qquad D \equiv \frac{d}{dz}$$

| 分量 | 方程 | 边界条件 |
|------|------|---------|
| 齐次响应 $w_h$ | $\mathcal{L}_R[w_h] = 0$ | 携带表面条件 $w_h(0)=w_s,\ w_h'(0)=w_s'$，$z\to\infty$ 衰减 |
| 受迫修正 $w_F$ | $\mathcal{L}_R[w_F] = \frac{1}{R}F(z)$ | 齐次边界：$w_F(0)=w_F'(0)=0$，$z\to\infty$ 衰减 |

### 5. WKBJ 构造

$$w_h(z) = \exp\left[\int^z q(s)\,\mathrm{d}s\right],\qquad q(z) = \frac{w_h'(z)}{w_h(z)}$$

利用恒等式：

$$\frac{w_h''}{w_h} = q' + q^2,\qquad \frac{w_h''''}{w_h} = q''' + 4qq'' + 3(q')^2 + 6q^2q' + q^4$$

代入 $\mathcal{L}_R[w_h]=0$ 并除以 $w_h$，把四阶线性方程化为关于对数导数 $q$ 的**三阶非线性方程**（标准 WKBJ 过程，参照 Drazin & Reid 2004）。

## 数值方法 / 验证矩阵

| 阶段 | 内容 |
|------|------|
| **阶段 1（渐近误差隔离）** | 与**粘性 Orr–Sommerfeld 方程的数值解**对比，使用**规定剖面**与**模拟导出的剖面** |
| **阶段 2（约化动力学检验）** | 与**壁面分辨 (wall-resolved) LES** 和**壁模型 (wall-modelled) LES** 的波致场对比 |
| **数据来源** | Cao & Shen (2021, CS21) 的壁面分辨 LES 的平均剖面；Zhang et al. (2025, ZLD25) 的**气-海耦合 DNS** 的平均剖面 |
| **壁模型模拟** | **WRF** 模型 (Weather Research and Forecasting)；**常应力有效粘性**替代 Stokes 层中的分子粘性 |
| **波致湍流应力** | 在本文考虑的高波龄区间**次要**，故从 Orr–Sommerfeld 方程中**略去**波致 Reynolds 应力的散度（引 Åkervik & Vartdal 2019；Cao & Shen 2021） |
| **诊断量** | 仅由**平均剖面与波参数**即可计算的外层近似适用性判据 |

## 关键结果

1. **形式应力渐近标度**：

$$\tau_{\rm form} \sim C \cdot R^{-1/2},\qquad C \text{ 由外层响应的积分决定}$$

其中 $R = c/(k\nu)$ 为波 Reynolds 数。**动量从波传给空气**。

2. **指数剖面的闭式解**：对 $F(z)$ 形式的指数平均剖面，WKBJ 给出波致速度/压力的**闭式表达**。

3. **LW–WKBJ**：对真实壁面束缚剖面，近表面 $\overline{u}$ 剧烈变化使外层 WKBJ 失效；引入按 $k^2$ 展开的**长波 (long-wave) 展开**保留完整平均速度变化，再与外层 WKBJ 模态**匹配**。

4. **验证结论**：
   - LW–WKBJ **复现**数值解与模拟数据中的主导波致**速度与压力**；
   - 预测的**形式应力系数**与已有 LES 估计**吻合良好**。

5. **物理意义**：卫星观测显示平缓涌浪的衰减符合**层流空气侧 Stokes 层**中的耗散（引 Dore 1978；Pérignon et al. 2014）——本框架从第一性原理支持"**分子（而非湍流）应力控制近表面响应**"。

## 局限性

- **线性化**：在平均风之上做线性化，忽略波致 Reynolds 应力散度（在高波龄下次要，但向中间波龄推广时失效——如 Narasimhan et al. 2026 所指出）。
- **规定波**：波为给定（不与气流动态耦合），未处理波的增长/衰减反馈。
- **单色波**：单频深水波，未含波谱展宽。
- **二维/垂向**：一维垂向问题（水平均匀），忽略侧向（spanwise）波致结构与波斜率。
- **解析平均剖面**：需要外部提供 $\overline{U}(\zeta)$；框架本身不预测平均剖面（需与边界层模型耦合）。
- **渐近判据依赖剖面**：外层 WKBJ 要求平均剖面在外层响应衰减长度内**缓变**，对强剪切剖面需 LW 补丁，两者切换的严格条件未完全形式化。
- 壁模型情形用**常应力有效粘性**近似 Stokes 层，忽略了真实壁模型中亚网格应力闭合的更多结构。

## 实现建议

- **实现难度**：★★★★☆（WKBJ 渐近 + 长波展开 + 匹配是解析工作量大但**计算成本极低**；实现需仔细处理 $R^{-1}$ 奇异摄动与内外层匹配的边界层余项）
- **预期性能**：与完整 Orr–Sommerfeld 数值解或 LES 相比，成本可忽略（单次剖面求值）；适合嵌入**气候模式的参数化**或**LES 的波致应力子模型**
- **适用场景**：
  - **快波 / 高波龄**风-波相互作用（涌浪、海气动量交换、低空急流生成）
  - 气候模型中风-波耦合的参数化（替代经验公式）
  - 风-波界面层的约化模型与 LES 子网格应力项
- **可迁移点**：
  1. **"外层渐近 + 内层边界层 + 匹配"**是处理多尺度奇异摄动问题的通用范式，可迁移到其它粘性-无粘双重结构的问题
  2. **几何源项**（波跟随坐标变换产生的 forcing）的显式表达可复用于任何非正交坐标变换的线性化
  3. **仅由剖面与波参数计算的适用性判据**——是"何时可信"的工程化工具，比框架本身更实用
  4. **常应力有效粘性**替换 Stokes 层粘性，是把壁模型 LES 与解析框架对接的标准做法
  5. 与 Oceananigans / WRF / LES 耦合的接口：只需提供 $\overline{U}(z)$ 与波参数 $(a, k, c)$
