## 问题定义
- 标量 DUGKS 受限于**固定 Pr 数**
- 本文：**矢量 DUGKS (V-DUGKS)**，质量、动量、总能量用耦合分布函数表示，可调 Pr

## 方法细节
- 平衡分布**截断至 2 阶 Hermite**
- 仅需 2 阶速度矩恢复可压 NS → **4 阶 Gauss-Hermite 求积即可精确求矩**
- 消除 3 阶 Hermite 项 → **紧凑离散速度集**统一所有分布函数
- 有限体积格式 + 基于特征的通量 + 梯形碰撞积分

## 验证算例
| 算例 | 类型 |
|------|------|
| 激波管 | 1D Riemann |
| Shu-Osher | 1D 激波-扰动相互作用 |
| 2D Riemann | 复杂激波结构 |
| 3D Taylor-Green 涡 | 衰减湍流基线 |

## 关键优势
- **3D Taylor-Green 涡**：相同 CFL 约束下**加速 2.2–2.9×**
- 数值参考温度敏感性降低 → 稳定性更好
- 比标量 DUGKS 更紧凑、高效

## 计算成本
- 与常规 NS 求解器相当
- 求积节点数减少（无需 3 阶矩）→ 每时间步 O(N) 加速
- 内存：紧凑离散速度集降低

## 推荐结论
✅ **推荐关注**（离散格式创新）：
- 适合可压缩多物理（高 Mach、激波-湍流相互作用、燃烧）
- 与 caixin [[kinetic-scheme]], [[LBM-family]], [[compressible-flow]] 关联
- 可作为 OpenFOAM / 自研 CFD 求解器的高效组件
