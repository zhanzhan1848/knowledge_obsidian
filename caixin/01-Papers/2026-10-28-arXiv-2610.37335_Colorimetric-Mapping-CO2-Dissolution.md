## 核心贡献

> 首次系统量化**实验域、几何维度、指示剂混合浓度**对空间比色法（spatial colorimetry）测量 CO₂ 对流溶解过程中 pH 与溶解无机碳 $C_T$ 可靠性的影响，给出可操作的选择准则。

1. **建立测量可靠性框架**：区分自由流体域与多孔介质域、2D 与 3D、指示剂浓度三组因素对 pH/$C_T$ 反演的影响。
2. **两种色度模型的适用性判据**：
   - **Hue（色相）模型在所有域中均可靠**
   - **球坐标 $(\theta,\phi)$ 模型仅在自由流体域中可靠**；在多孔域中其标定受噪声影响程度是 Hue 的 **33 倍**
3. **噪声量化**：时间 pH 噪声 < 0.01 单位；空间噪声导致域平均 $C_T$ 变化 **0.6–4.4%**。
4. **几何影响**：两种色度模型对 CO₂ 羽流边界分辨率不同（$\theta$-$\phi$ 更锐利）；时间演化的两模型一致性 **2D 优于 3D**。

## 技术方案

### 核心思想

地质封存中溶解度俘获机制的理解，取决于量化 CO₂ 富集水体的溶解与浮力驱动输运。但：

- **类比流体**（如 NaCl 溶液）的密度驱动对流实验**无法代表 CO₂ 溶解化学**，也不满足水相 CO₂ 密度–浓度的单调关系
- **X 射线断层成像**对溶解态 CO₂ 的对比度不足，无法直接测量
- **空间比色法**（spatial colorimetry）是一种低成本替代：映射 pH，并通过碳酸盐平衡假设反演总溶解无机碳 $C_T$

### 关键技术

| 技术 | 说明 |
|------|------|
| 比色模型 1 | **Hue**（色相） |
| 比色模型 2 | **球坐标 $(\theta,\phi)$** |
| 反演 | 由 pH 经碳酸盐平衡假设推 $C_T$ |
| 域类型 | 自由流体 / 多孔介质 |
| 几何 | 2D / 3D |
| 指示剂 | 不同混合浓度（低/高） |

## 公式

### 碳酸盐平衡（$C_T$ 反演依据）

```math
C_T = [\mathrm{CO_2(aq)}] + [\mathrm{HCO_3^-}] + [\mathrm{CO_3^{2-}}]
```

由 pH 与 $K_1, K_2$ 得碳酸盐分数：

```math
[\mathrm{HCO_3^-}] = \frac{K_1}{[\mathrm{H}^+]}[\mathrm{CO_2(aq)}], \qquad
[\mathrm{CO_3^{2-}}] = \frac{K_1 K_2}{[\mathrm{H}^+]^2}[\mathrm{CO_2(aq)}]
```

（二氧化碳水溶液含溶解态 $\mathrm{CO_2}$、碳酸氢根与碳酸根三形态；其余以 $C_T$ 守恒式给出。）

### 羽流浮力驱动对流

浮力源来自溶解 CO₂ 导致的**密度降低**，形成浮力驱动的自然对流羽流；在多孔介质中该对流受达西定律约束。

## 实验结论

### 指示剂浓度的影响

| 域 | 效应 |
|---|---|
| 自由流体 | **较低**指示剂浓度 → **提高**低 pH 区的色度灵敏度 |
| 多孔介质 | 低指示剂浓度**不足以**产生 pH 标定与映射所需的对色对比度 |

### 色度模型可靠性

| 模型 | 自由流体 | 多孔介质 |
|---|---|---|
| Hue | 可靠 | 可靠 |
| $\theta$-$\phi$ | 可靠 | **不可靠**（标定受噪比 Hue 高 33 倍） |

### 噪声与分辨率

- 时间 pH 噪声：**< 0.01 单位**
- 空间噪声 → 域平均 $C_T$ 变化：**0.6–4.4%**
- 两种模型均能分辨自由流体中的 CO₂ 富集羽流；**$\theta$-$\phi$ 的羽流边界更锐利**
- 时间演化一致性：**2D 优于 3D**

---

## 局限性

1. **$C_T$ 反演依赖碳酸盐平衡假设**——不适用于超出该假设的化学环境（强离子强度、额外缓冲物种）。
2. **指示剂本身会扰动系统**（低浓度时更明显）。
3. **多孔域下 $\theta$-$\phi$ 模型不可用**，限制了三维高分辨羽流成像在该类实验中的可行性。
4. **空间噪声引起的 $C_T$ 偏差 0.6–4.4%** 对需要更高精度的定量研究是限制。
5. 类比流体实验与真实 CO₂ 溶解化学的差距未被完全消除。
6. 未涉及溶解速率与反应动力学，仅为溶解/输运的定性定量映射。

## 实现建议

- **实现难度**：中（实验方法学 + 简单反演），但**对 CFD 实践的价值主要在于提供验证数据来源**。
- **预期性能**：不需要性能；成本在于图像标定与信噪比控制。
- **适用场景**：
  - 为 CO₂ 地质封存的**自然对流羽流 CFD 模拟**提供实验基准
  - 地质储层封盖完整性评估
- **落地建议**：
  1. **若要设计比色实验**：自由流体域用 Hue 或 $\theta$-$\phi$ 均可；**多孔介质域必须用 Hue**，且指示剂浓度需足够高以产生 pH 标定的对色对比度
  2. **若要用这些数据做 CFD 验证**：注意 $C_T$ 的空间噪声本底为 0.6–4.4%，验证误差低于此量级没有意义
  3. **建模启示**：本工作说明「用类比流体替代真实化学」会在**密度–浓度单调性**这一关键点上失效——这是 CO₂ 溶解模拟区别于常规驱替模拟的本质困难，建模时不可沿用盐水的经验关系
  4. 复现建议：优先建立 2D 自由流体算例（$C_T$ 时间演化一致性最好），再扩展至 3D 与多孔域
