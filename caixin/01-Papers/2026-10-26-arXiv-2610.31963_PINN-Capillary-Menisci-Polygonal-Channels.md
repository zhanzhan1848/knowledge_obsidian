## 核心贡献

> 给 PINN 在毛细弯液面问题中的**内/壁面残差损失**建立了几何下界，并据此定位"PINN 静默失败"的结构性原因

1. 理论：**经典毛细通量平衡给出内区+壁面残差损失的下界**，且对任意正的采样密度成立
2. 在**不存在跨越解**的参数区间（低于临界接触角数度），独立评估的网络损失是下界的 **1.6–1.9 倍**；多项式最小二乘对比支持同一几何解释
3. **PINN 仍返回光滑、有限轴向长度的图像（graph）**，尽管所设定的平衡问题**根本没有跨越解**
4. 机制：小内区残差与**壁面通量亏损**共存——拐角处相邻接触角条件要求的通量超过有限斜率图像所能提供的
5. 残差在临界角两侧均变化，而下界在固定壁面权重下**一致趋于零**于阈值处

## 技术方案

### 核心思想

零重力圆柱容器内，液面只能以方/等边三角形截面跨越，条件是接触角分别不低于 **Concus-Finn 临界角 45°（方形）与 60°（三角形）**。低于此，物理上不存在跨越平衡解——但 PINN 仍会输出一个"看起来很光滑"的解。

本文不是提出新 PINN，而是给出**诊断下界**，让使用者能识别这种静默失败。

### 关键技术

| 技术 | 说明 |
|------|------|
| 毛细通量平衡下界 | 由经典几何/平衡律导出的残差损失下界 |
| 强形式 PINN | 固定配点与优化预算下的强形式残差 |
| 独立评估 | 分别评估内区与壁面残差，避免单一聚合损失掩盖问题 |
| 多项式最小二乘对照 | 用不同函数族复现同一几何现象，验证解释的普适性 |
| 壁面权重扫描 | 固定壁面权重时观察下界行为 |

## 公式

```math
Concus-Finn 临界角:
  方形截面: θ_c = 45°,  等边三角形: θ_c = 60°
  跨越存在条件: θ ≥ θ_c

下界（非跨越区）:
  L_interior + L_wall  ≥  L_bound(θ, Δx, w_wall)
  任意正采样密度下成立

壁面通量亏损（拐角处）:
  所需通量 φ_required > φ_available(有限斜率图像)
  → 内区残差小 + 壁面残差大 = 隐蔽的失败模式

阈值行为:
  固定壁面权重 w_wall 时,  L_bound → 0  当 θ → θ_c
```

## 代码片段

```python
import numpy as np

def capillary_flux_balance_bound(theta_deg, theta_c, dx, w_wall):
    """
    非跨越区的残差损失下界（几何量纲）
    """
    deficit = max(0.0, theta_c - theta_deg)
    # 下界随亏损量增长, 并在 theta -> theta_c 时一致趋于 0
    return w_wall * (deficit ** 2) / dx

def diagnose_pin_failure(loss_interior, loss_wall, bound):
    """
    独立评估内外残差, 判定是否落入"静默失败"区间
    """
    ratio = (loss_interior + loss_wall) / bound if bound > 0 else np.inf
    silent_failure = (ratio < 2.0) and (loss_interior < 1e-3) and (loss_wall > loss_interior)
    return dict(ratio=ratio, silent_failure=silent_failure)
```

## 实验结论

- **数据集**: 零重力容器中方形/等边三角形通道的毛细弯液面（强形式 PINN，固定配点与优化预算）
- **基线**: 多项式最小二乘拟合
- **结果**:
  - 非存在区（低于临界角数度）：网络损失为下界的 **1.6–1.9 倍**
  - 多项式最小二乘给出**一致的几何解释**
  - PINN 在**无解问题**上仍返回光滑、有限轴向长度的图像
  - 失败根因：拐角处**相邻接触角条件要求的通量**超过有限斜率图像可提供的量 → 形成**壁面通量亏损**（与小的内区残差共存）
  - 下界在阈值处一致趋于零，残差在临界角两侧均变化

---

## 局限性

- 仅零重力、静态平衡、简单多边形通道
- 仅强形式 PINN；弱形式 PINN 与传统有限元毛细求解器未对比
- 下界的实用价值依赖用户是否做独立评估（聚合损失仍会掩盖问题）
- 数值实验规模较小
