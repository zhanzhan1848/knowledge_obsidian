## 核心贡献

> 将 **PCA + 高斯过程回归 (GPR)** 组合成**可微分概率仿真器**，替代**黑箱瞬态系统代码**（如 Flownex SE），使贝叶斯反演 IUQ 在 NACIE 重液金属自然循环回路上的**全时序标定**成为可能——likelihood 评估加速 **3000 倍**

1. **问题背景**：核反应堆热工水力仿真需要**不确定性量化 (UQ)** 预测，但**贝叶斯反演 IUQ** 因后验采样需要**大量昂贵全瞬态仿真**而不实用
2. **核心创新**：
   - 把黑箱瞬态仿真器（Flownex SE）转化为**可微分概率仿真器**
   - PCA 降维 + GPR 在潜空间拟合
   - 重建完整多通道温度 + 流量时序
   - 保留主导时间 + 跨通道相关性
   - 自动微分 log posterior → 兼容 HMC / NUTS / Microcanonical Langevin Monte Carlo
3. **性能**：
   - 5 个主成分捕获 **> 99%** 输出方差
   - **NRMSE < 2%**
   - Likelihood 评估**加速 3000 倍**
   - 后验统计 / 相关性**严格保持**
   - 后验预测：bias ↓、interval ↓、与测量吻合 ↑

## 技术方案

### 核心思想

把**高维时序输出**（多通道温度、流量）看作**低维潜变量** + 高斯过程残差：
\[
\mathbf{Y}(t) \approx \mathbf{V}_K \mathbf{z}(t) + \epsilon
\]
其中 \(\mathbf{V}_K\) 是 PCA 投影矩阵（前 K 个主成分），\(\mathbf{z}(t)\) 是潜空间 GPR。

### 关键技术

| 技术 | 说明 |
|------|------|
| Principal Component Analysis (PCA) | 时序输出降维 |
| Gaussian Process Regression (GPR) | 潜空间时序拟合 |
| Differentiable probabilistic emulator | 自动微分 log posterior |
| Ensemble slice sampling | 无梯度采样 |
| No-U-Turn Sampler (NUTS) | 梯度 HMC |
| Microcanonical Langevin Monte Carlo | 梯度 Langevin |
| NACIE heavy-liquid-metal loop | 重液金属自然循环测试回路 |
| Flownex SE | 黑箱系统代码 |

### 框架流程

```
[Flownex SE 黑箱仿真]
        ↓
[生成训练样本：多通道温度 + 流量时序]
        ↓
[PCA 降维到 K=5 维]
        ↓
[GPR 在潜空间拟合 + 协方差]
        ↓
[Differentiable log posterior]
        ↓
[Bayesian IUQ via NUTS / Slice Sampling]
        ↓
[Posterior predictive vs 测量]
```

### 关键性能

| 指标 | 数值 |
|------|------|
| 主成分数 K | 5 |
| 输出方差捕获 | > 99% |
| NRMSE | < 2% |
| Likelihood 加速 | **~3000×** |
| 后验 vs 直接 MCMC | 统计量保持 |

## 实验 / 验证

- **样本**：NACIE 重液金属自然循环回路
- **工具**：Flownex SE（黑箱）
- **数据**：全瞬态温度 + 流量时序
- **验证**：
  - Posterior predictive vs 测量
  - 与独立验证数据集对比
- **采样器**：slice sampling（无梯度）+ NUTS / MLMC（梯度）

---

## 局限性

- **单系统**：仅验证 NACIE 回路，迁移性需更多 benchmark
- **静态 PCA**：PCA 基础固定，**非线性主成分**（KPCA, autoencoder）未对比
- **GPR 假设**：平稳核函数可能不适用于**强非线性瞬态**
- **测量噪声模型**：未深入处理异方差 / 模型误差
- **计算可扩展性**：GPR 复杂度 O(N³)，大规模场景需近似

## 笔记

**@墨鱼丸 实现建议**：本工作对 **CFD + UQ 集成** 有重要借鉴价值：
- **可微分代理** 是**大规模贝叶斯标定**的关键技术，可在 OpenFOAM / SU2 中实施
- **PCA + GPR** 组合可替换**任意黑箱 CFD 代码**作为 surrogate
- **自动微分**（PyTorch / JAX）使 HMC / NUTS 实用化，**避免 MCMC 收敛难题**
- 迁移到其他系统：
  1. 用 CFD 生成训练数据
  2. PCA 降维（K=5~20）
  3. GPR 拟合潜空间
  4. 可微分 log posterior
  5. NUTS 采样
- 对**反应堆安全分析 / 化工过程标定 / 气候模型校准**等场景有直接工程价值

难度：很高（需要贝叶斯推断 + 可微分编程 + CFD 集成）；价值：**极高**（UQ 工业级应用）
