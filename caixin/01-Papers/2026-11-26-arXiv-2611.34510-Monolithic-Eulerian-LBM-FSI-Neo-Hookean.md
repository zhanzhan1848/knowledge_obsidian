## 核心贡献

> 提出**完全欧拉的、单调（monolithic）格子玻尔兹曼 FSI 框架**：单一笛卡尔网格上同时求解不可压流体与不可压 neo-Hookean 弹性固体（密度不相等），全部更新**显式且局部**；通过**两项独立校正**分别消除"平移不精确"与"固体质量长期漂移"两个误差源。

1. **压力基动理学格式推进混合物动量**（pressure-based kinetic scheme），而非传统 LBM 的碰撞-松弛格式 —— 这是能处理**高密度比**的关键。
2. **多项式 MTHINC 重构**输运固体体积分数，**闭式通量**（无需迭代），保持体积分数有界。
3. **左 Cauchy–Green 张量**给出弹性应力（neo-Hookean 的数值实现）。
4. **所有更新显式且局部** → 天然并行，无全局求解器。
5. **两项独立校正**（本文最关键的技术贡献）：
   - **格点链路校正（lattice-link correction）**：使**匀速平移成为任意密度比下的精确离散解**，验证至舍入误差级别，$\rho_s/\rho_f = 1000$。
   - **压力模态校正（pressure-mode correction）**：由格式的**渐近分析**导出，消除**坐标系相关的缺陷**（该缺陷会导致固体质量的**长期漂移** secular drift）。
6. **误差来源分离**：格式在**固定界面厚度**下对弥散界面解**二阶**；当界面厚度随网格缩放时对锐界面解**一阶** —— 与界面截断误差的估计一致。
7. **基准验证**：Turek–Hron FSI2 / FSI3 基准，密度比 1 与 10；Taylor–Green 与 lid-driven-cavity 中的可变形圆盘。

## 技术方案

### 核心思想

传统 LBM 处理 FSI 的两大痛点：
1. **高密度比**：固体与流体密度差异大时，LBM 碰撞-松弛格式出现"格点不连续"（lattice discontinuity），平移固体时产生虚假力；
2. **质量漂移**：固体体积分数输运与动量推进不守恒耦合，长期积分后固体质量漂移。

本文的应对：
- 用**压力基动理学格式**（推进混合物动量）替代碰撞-松弛 → 天然适合高密度比；
- 用**MTHINC 多项式重构**输运体积分数 → 闭式、有界、无迭代；
- 用**两个独立的、机制上分离的校正**分别处理上述两个不同的误差源 → **不混为一谈**。

这是一个很好的"**机制分离**"范例：两个误差来自完全不同的物理/数值机制，因此用两个正交的、分别有明确理论依据的校正，而不是一个笼统的"修复项"。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Pressure-based kinetic scheme** | 推进混合物动量的格子玻尔兹曼变体，适合密度比悬殊的场景 |
| **MTHINC 重构** | Multi-Threshold Analytic Interface Construction；多项式重构出锐界面通量的闭式表达 |
| **Left Cauchy–Green 张量** | $\mathbf{C}=\mathbf{F}\mathbf{F}^T$ 的离散化，给出 neo-Hookean 弹性应力 |
| **格点链路校正** | 强制匀速平移为精确解，密度比无关 |
| **压力模态校正** | 由渐近分析导出，消除坐标系相关的固体质量长期漂移 |
| **显式局部更新** | 无全局线性求解 → 完美并行 |
| **弥散界面 vs 锐界面** | 两种极限下的收敛阶被明确区分（二阶 vs 一阶） |
| **FSI2 / FSI3 基准** | Turek–Hron 社区标准算例 |

## 公式 / 理论要点

```math
% neo-Hookean 弹性应力（用左 Cauchy–Green 张量）
\mathbf{C} = \mathbf{F}\,\mathbf{F}^{T},
\qquad
\mathbf{S} = \mu\left(\mathbf{C}-\mathbf{I}\right)
+ \frac{\lambda}{2}\left(\operatorname{tr}\mathbf{C}-3\right)\mathbf{I}
```

```math
% 体积分数的 MTHINC 闭式通量
\sum_{\theta}\sum_{\zeta} a_{\theta\zeta}\,\mathrm{flux}
\quad\text{由多项式重构直接给出（无迭代）}
```

```math
% 固体质量守恒（压力模态校正消除漂移后）
\frac{d}{dt}\int_{\Omega_s}\rho_s\,dV = 0
\qquad\text{（逐时间步精确）}
```

```math
% 匀速平移的精确离散解（格点链路校正）
\rho_s/\rho_f = 1,\ 10,\ 1000
\quad\Longrightarrow\quad
\text{平移误差} = 0\ \text{（至舍入误差）}
```

```math
% 界面截断误差估计 → 预测收敛阶
\text{固定界面厚度 } \delta:\ \mathcal{O}(h^2)
\qquad
\delta \sim h:\ \mathcal{O}(h)
```

## 实验与结果

- **方法**: 全欧拉单体 LBM + MTHINC + neo-Hookean；单一笛卡尔网格；显式局部更新。
- **基准**: Turek–Hron **FSI2**、**FSI3**；密度比 $\rho_s/\rho_f = 1$ 与 $10$。
- **附加算例**: Taylor–Green 流与 lid-driven-cavity 中的**可变形圆盘**。
- **定量结果**:
  - 平移精度：密度比至 **1000** 仍保持舍入误差级别（格点链路校正）；
  - 固体质量**无长期漂移**（压力模态校正）；
  - 收敛阶：固定 $\delta$ 时二阶；$\delta\sim h$ 时一阶（与估计一致）。

---

## 局限性

- **显式格式** → 时间步受 CFL 严格限制；高密度比 FSI 通常刚性强，显式步长会很小。
- **弥散界面**（diffuse interface）：界面厚度是数值参数，不是物理量 → 界面厚度的选择需要与网格分辨率协调（本文明确指出此二难）。
- 固体限于**不可压 neo-Hookean**，不覆盖大塑性变形、塑性、黏弹性。
- 摘要未给出 CPU 时间、网格规模、并行效率等工程指标。

---

## 实现建议

- **实现难度**: 中高。需要同时实现：压力基动理学 LBM、MTHINC 通量、neo-Hookean 本构、两项校正。
- **预期性能**: 全显式局部更新 → 并行性极好；但受 CFL 限制，适合中等密度比（1–10）的 FSI；密度比 1000 时显式步长会非常小（尽管校正保证了平移精确性）。
- **适用场景**:
  - **笛卡尔网格上的 FSI 基准研究**（Turek–Hron 类）；
  - 含**自由变形固体 + 复杂几何**的问题（避免动网格/ALE 的网格畸变问题）；
  - 作为**"误差源分离"**的范例：两个独立的数值缺陷 → 两个正交校正 → 分别归因与验证。
- **可复用要点**:
  - **"格点链路校正"这个技巧可直接迁移**到任何"平移/旋转应为零体力"的 FSI 或多相流格式 —— 它是一个通用的一致性修补。
  - **"压力模态校正由渐近分析导出"**是比"经验调参"更可靠的路径；这类坐标相关性缺陷在斜网格、旋转坐标系中更常见。
  - **明确区分弥散界面解与锐界面解的收敛阶**是接口捕捉类方法的标准做法，本文给出了完整的误差分解论证。
