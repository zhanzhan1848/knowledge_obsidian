## 核心贡献

> 在 Ludwieg 隧道中开展 **Mach 6** 条件下**轴对称开口空腔**（装于半顶角 $48^\circ$ 锥体上）的系统实验研究，系统考察了**腔长深比 $L/D$**、**后壁高度深比 $h/D$** 与**Re 数**对流场与**表面换热**的影响；核心发现是：**腔长深比增大使下游 Stanton 数 $St_d$ 降低**，但在**最长腔 $L/D=6$** 时下游 Stanton 数**反超上游** $St_u$，表明该区域换热被增强。

1. **系统参数扫描**：$L/D \in \{0.5, 1.0, 2.0, 4.0, 6.0\}$，$h/D \in \{-0.25, 0, 0.5\}$，$Re_D \in [23000, 74000]$。
2. **流场与换热同步表征**：结合 **schlieren（纹影）** 与**平面激光瑞利散射 (PLRS)** 光学诊断，以及**表面压力**与**热流测量**。
3. **核心换热规律**：$L/D$ 增大 → **下游 Stanton 数 $St_d$ 降低**；但 $L/D=6$ 时出现**反转**——$St_d > St_u$，即空腔下游区域换热增强。
4. **轴对称几何的独特价值**：轴对称开口空腔相比平面空腔具有不同的激波系结构（中心线处的三维汇聚效应），提供了平面实验无法覆盖的数据。

## 技术方案

### 核心思想

高超声速开口空腔（open cavity）是典型的**热流陷阱**：腔体前缘的激波系会在腔内形成强烈的热载荷集中，直接威胁飞行器结构（窗口、传感器凹坑）。虽然平面（2D）开口空腔的高超声速热流数据已有较多积累，但**轴对称**开口空腔（装于锥体上）在真实飞行器构型中更常见（例如头锥上的仪器舱、天线罩凹陷），其三维激波汇聚效应会改变热流分布。

本文在 **Ludwieg 隧道**（管式激波管，驻点型）中做 Mach 6 实验。Ludweig 隧道的优势在于**驻点驻定**（hypersonic shock tunnel with a nominally stationary test section）——能够提供远长驻留时间的大尺度高超声速流，适合做换热测量而非仅流场显示。

实验的三个设计维度覆盖了空腔热流问题的核心几何参数：
- **$L/D$（腔长深比）**：控制激波在腔内的反射位置与加热区长度；
- **$h/D$（后壁高度深比）**：$h/D<0$ 表示后壁低于基准面（"下沉"式空腔），$h/D>0$ 表示后壁抬升——这会改变后缘激波的起跳位置，从而重塑下游热流；
- **$Re_D$**：控制边界层厚度与激波/边界层相互作用强度。

### 关键技术

| 技术 | 说明 |
|------|------|
| Ludweig 隧道 | 管式激波管，驻点驻定，适合换热驻留测量 |
| Mach 6 自由来流 | 高超声速试验条件 |
| 轴对称开口空腔 | 装于半顶角 $48^\circ$ 锥体，三维激波汇聚效应 |
| Schlieren 纹影 | 激波系与边界层可视化 |
| 平面激光瑞利散射 (PLRS) | 密度扰动（流场结构）非定常测量 |
| 表面压力测量 | 壁面压力分布（激波压力峰位置） |
| 表面热流测量 | 换热率分布 |
| Stanton 数 | $St = h/(\rho c_p U_\infty)$，无量纲换热指标 |
| 参数扫描 | $L/D$、$h/D$、$Re_D$ 三维参数空间 |

## 公式 / 理论要点

```math
% Stanton 数与 Nusselt 数
\mathrm{St}_d = \frac{h_d}{\rho_\infty\,c_{p,\infty}\,U_\infty},
\qquad
\mathrm{St}_u = \frac{h_u}{\rho_\infty\,c_{p,\infty}\,U_\infty}
```

```math
% 空腔特征 Reynolds 数
\mathrm{Re}_D = \frac{\rho_\infty U_\infty D}{\mu_\infty}
```

```math
% 空腔几何参数
\frac{L}{D}\in\{0.5,1.0,2.0,4.0,6.0\},
\qquad
\frac{h}{D}\in\{-0.25,\ 0,\ 0.5\}
```

```math
% 激波入射马赫数（与锥面半顶角相关）
\theta_c = 48^\circ
\quad\Longrightarrow\quad
M_{2,\text{shock}} = M_\infty\,\sqrt{\frac{1+\gamma\sin^2\theta_c}{2+\gamma-\gamma\sin^2\theta_c}}
```

```math
% 边界层对激波的位置影响（控制后缘激波起跳）
\delta_{\mathrm{BL}} \sim \frac{0.37\,x}{\mathrm{Re}_x^{1/5}}
```

## 实验与结果

- **实验设施**: Ludweig 隧道，Mach 6 自由来流，轴对称开口空腔安装于半顶角 $48^\circ$ 锥体上。
- **参数矩阵**: $L/D = 0.5, 1.0, 2.0, 4.0, 6.0$；$h/D = -0.25, 0, 0.5$；$Re_D = 23000 \sim 74000$。
- **测量手段**: schlieren 纹影 + 平面激光瑞利散射（流场）；表面压力 + 热流（壁面载荷）。
- **主要结果**:
  - **$L/D$ 增大 → 下游 Stanton 数 $St_d$ 降低**（主流效应）。
  - **关键反转**：最长腔 $L/D = 6$ 时，**下游 Stanton 数超过上游**（$St_d > St_u$），即空腔下游区域**换热增强**——这与"腔越长下游越冷"的直觉相反，很可能与长腔内的激波多次反射/汇聚与边界层相互作用有关。
  - $h/D$ 改变了后缘激波起跳几何，从而重塑下游热流分布。
  - $Re_D$ 的影响通过边界层厚度（影响激波起跳位置）起作用。

## 局限性

- **单一来流条件**：仅 Mach 6；未覆盖 Mach 5/7 等其他高超声速状态，也未做稀化效应评估。
- **实验测量精度**：表面热流测量（薄膜/应变计类）在高热流密度下的不确定度与空间分辨率受限；PLRS 在静态工况下（本文为定常）信息量有限。
- **几何单轴对称**：未研究倾斜、侧壁存在、或多腔组合构型。
- **仅壁面平均载荷**：未给出腔内流场的定量（如回流区长度、剪切层位置）以支撑 CFD 对比。
- **没有给出与 CFD 的定量对比**（摘要未提），而这是此类实验论文最重要的产出之一。

## 实现建议

- **实现难度**: 中 — 实验复现难度高（需 Ludweig 隧道或等效设备），但**作为 CFD 验证算例**的实现难度中等：几何明确（$48^\circ$ 锥 + 轴对称空腔），主流参数（$M_\infty$、$Re_D$）已给出。
- **预期性能**: 若用高超声速 RANS/激波层模型对比，需注意 $L/D=6$ 的下游换热反转对**湍流模型与壁面热流模型敏感**；PLRS/纹影可用于定性校验激波系位置。
- **适用场景**:
  - 高超声速飞行器**开口空腔的热防护设计**（窗口、传感器、天线凹坑）；
  - 高超声速风洞**验证算例库**的扩充；
  - 湍流模型与激波/边界层相互作用（SBLI）预测能力的评估。
- **可复用要点**:
  - **$St_d$ 反转现象是一个很好的模型判别案例**：如果 CFD 不能复现"长腔下游换热增强"，很可能说明壁面热流模型或湍流模型在 SBLI 区失效。这是一个**高信息量的验证指标**，比只对比压力分布更难糊弄。
  - **参数矩阵的组织方式**（$L/D$、$h/D$、$Re_D$ 各自独立扫描）值得作为自建验证算例库的模板——几何参数与流态参数**解耦扫描**，便于归因。
  - 由于本文是**纯实验**，很适合用来给 AI 生成的 CFD 案例提供**真值数据**（这也符合当前神经算子训练对"实验级真值"的迫切需求，见 [[2026-11-11-arXiv-2611.14276]] 的 DNS 真值路线）。
