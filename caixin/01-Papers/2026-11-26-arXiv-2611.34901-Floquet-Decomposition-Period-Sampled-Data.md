## 核心贡献

> 把 Schmid 在 DMD 原始论文中提出的一个**观察**（"以振荡流的周期采样快照可辨识 Floquet 矩阵"）**发展为一套方法并给出严格分析**：**Floquet 分解 (FD)** 与**集合 Floquet 分解 (EFD)**；对线性时变周期系统二者**精确**，EFD 在**部分测量**下仍成立；同时精确刻画了 **Hankel（延迟嵌入）DMD 与 EFD 的关系** —— 用同一数据矩阵、不同列移位。

1. **FD（Floquet Decomposition）**：对**定频采样**、**每周期抽一帧**的数据做 DMD。
2. **EFD（Ensemble Floquet Decomposition）**：把**每个周期内的所有快照堆叠成一列**，得到**一组 Floquet 乘子**与**相位分辨的模态**。
3. **精确性条件**（对线性时变周期系统）：
   - FD 精确 ⟺ **某一瞬时的测量能确定状态**；
   - EFD 精确 ⟺ **一个周期内的测量能确定状态** → 因此 **EFD 在部分测量（partial measurements）下仍然成功**。
4. **Hankel-DMD 与 EFD 的精确关系**：二者使用**同一个数据矩阵**，区别仅在**列之间的移位方式**。当每周期有 $p$ 个样本时，**Hankel-DMD** 把每个 Floquet 模态返回为**载波 + 边带**（即其乘子的 $p$ 次根构成的梳状谱），而**周期移位**把这个梳**塌缩到乘子本身**。
5. **诚实的负面结论**：在假设之外（非线性或含噪数据），估计出的**模**是**有偏的**，且**不是衰减率**。
6. **应用**：旋流稳定燃烧器 (swirl-stabilized combustor) 中速度、标量与**声压**的实测，演示周期、秩与数据缩放的选择。

## 技术方案

### 核心思想

DMD 的基本前提是"**存在一个常数线性算子**"。但有一大类流体问题不满足这个前提：

- **参数激励流**（参数随时间周期性变化，如阀门周期性开合、脉动来流）；
- **观察视角周期性变化**（旋转结构在固定坐标系下观看，如旋转机械、旋翼）。

此时不存在常数算子，稳定性由 **Floquet 乘子**（一个周期映射的特征值）决定。

Schmid 在 DMD 原始论文中指出"以周期采样可辨识 Floquet 矩阵"，本文把这个观察做成了**完整方法 + 误差分析**。

**关键洞察（本文最漂亮的一步）**：EFD 与 Hankel-DMD 用的是**同一个数据矩阵**，差别只是**列移位**。Hankel（延迟嵌入）DMD 会把每个 Floquet 模态展开成"载波 + 边带梳"，而周期移位把梳**塌缩**回乘子 —— 这解释了为什么 EFD 在部分测量下更稳健：**它利用了周期内的全部信息，而非仅周期边界的瞬时信息**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **DMD（动态模态分解）** | 基础工具：拟合单一常数线性算子 |
| **FD（Floquet Decomposition）** | 定频数据 + 每周期抽一帧 → DMD → Floquet 乘子 |
| **EFD（Ensemble Floquet Decomposition）** | 周期内快照堆叠成一列 → 乘子 + 相位分辨模态 |
| **Floquet 乘子** | 一个周期映射的特征值；模 < 1 → 稳定 |
| **Floquet 模态** | 含相位的时变模态（区别于常系数 DMD 的静态模态） |
| **Hankel / 延迟嵌入 DMD** | 同一数据矩阵，列移位不同 |
| **边带梳结构** | Hankel-DMD 中 Floquet 模态的载波-边带分解 |
| **部分测量鲁棒性** | EFD 的核心优势：周期内部分采样仍精确 |
| **秩与数据缩放选择** | 应用中的实际调参维度 |

## 公式 / 理论要点

```math
% Floquet 结构：线性时变周期系统
\dot{\mathbf{x}} = \mathbf{A}(t)\,\mathbf{x},
\qquad
\mathbf{A}(t+T) = \mathbf{A}(t)
```

```math
% 周期映射与 Floquet 乘子
\boldsymbol{\Phi}(t_0+T) = \mathbf{F}\,\boldsymbol{\Phi}(t_0),
\qquad
\sigma_i(\mathbf{F}) = \mu_i
\quad\Longrightarrow\quad
|\mu_i|<1 \Rightarrow \text{稳定}
```

```math
% FD：定频采样，每周期抽一帧
\mathbf{Y}_{\mathrm{FD}} = \left[\mathbf{x}(t_0),\ \mathbf{x}(t_0+T),\ \mathbf{x}(t_0+2T),\dots\right]
```

```math
% EFD：周期内快照堆叠成一列（相位分辨）
\mathbf{Y}_{\mathrm{EFD}} = \left[
\begin{bmatrix}\mathbf{x}(t_0)\\ \mathbf{x}(t_0+\Delta t)\\ \vdots\\ \mathbf{x}(t_0+(p-1)\Delta t)\end{bmatrix},
\begin{bmatrix}\mathbf{x}(t_0+T)\\ \vdots\\ \mathbf{x}(t_0+T+(p-1)\Delta t)\end{bmatrix},
\dots
\right]
```

```math
% 精确性条件
\begin{cases}
\text{FD 精确} & \Longleftrightarrow \text{瞬时测量确定状态}\\
\text{EFD 精确} & \Longleftrightarrow \text{周期内测量确定状态（可部分测量）}
\end{cases}
```

```math
% Hankel-DMD 的载波-边带梳
\text{Hankel-DMD}: \ \mu^{1/p}\,\omega_k,\quad \omega_k = e^{2\pi i k/p},\ k=0,\dots,p-1
\quad\Longrightarrow\quad \text{梳状谱}
```

```math
% 周期移位把梳塌缩回乘子
\text{周期移位}: \ \big\{\mu^{1/p}\omega_k\big\}_{k=0}^{p-1}
\ \xrightarrow{\ \text{周期折叠}\ }\ \mu
```

```math
% 假设之外的诚实警告
\text{非线性/含噪} \Longrightarrow
\text{估计模 } |\mu_i| \text{ 有偏，且 } \neq \text{衰减率}
```

## 实验与结果

- **方法**: FD 与 EFD；对已知乘子做验证（数值算例）。
- **应用**: **旋流稳定燃烧器**（swirl-stabilized combustor）实测，测量量为**速度、标量、声学压力**。
- **演示内容**: **周期的选择**、**秩（截断阶数）的选择**、**数据缩放**的选择对结果的影响。
- **结论**: 在假设内精确；假设外（噪声/非线性）模有偏，**不能当作衰减率解读**。

---

## 局限性

- **假设较强**：线性、时变周期、精确周期已知。非线性流动（含湍流、燃烧）严格来说不满足。
- **周期必须已知**：实验中周期通常需先辨识（自相关、频谱、互相关）。
- **噪声下模有偏**：作者明确承认，且强调估计的模**不是衰减率** —— 这限制了在真实工程问题中的定量使用。
- **"部分测量"** 要求测量在空间上足够覆盖状态（虽然要求低于"瞬时确定状态"）。
- 摘要未给出具体算例的乘子误差数值。

---

## 实现建议

- **实现难度**: **低**。这是纯后处理方法，不涉及新的求解器；只需 DMD 的矩阵分解（截断 SVD）。
- **预期性能**: 内存与计算量与 DMD 同量级；核心价值在**分析能力**而非速度。
- **适用场景**:
  - **参数激励/非定常工况的稳定性分析**（脉动来流、周期阀、旋转机械）；
  - **从现有仿真或实验数据中提取"一个周期的稳定性判据"**；
  - 作为**旋转机械/旋翼**流固耦合问题的模态分析工具。
- **可复用要点**:
  - **"用周期内全部信息（EFD）而非仅边界瞬时（FD）"**是一个通用鲁棒性原则：把稀疏采样问题转化为"周期内采样"。
  - **Hankel-DMD 与 EFD 共享数据矩阵**这一事实提供了一个**免费的诊断工具**：若两者结果不一致，说明数据不满足假设。
  - **"估计的模 ≠ 衰减率"** 这个警告应当写进任何基于 DMD 的稳定性分析报告的必写项 —— 这是很容易被误用的地方。
  - **秩（截断阶数）的选择**往往比方法本身更影响结果 → 应作为必报项。
