## 核心贡献

> 首次系统刻画**科学基础模型 (SciFM)** 在两阶段 sim-to-real 微调中的**灾难性遗忘**：先在圆柱绕流模拟数据上微调，20 个 epoch 就让预训练任务上的一步误差劣化 **35 倍**；再适配实验数据进一步侵蚀模拟任务性能——而仅在真实数据微调中**回放 1% 的模拟数据**即可恢复大部分损失的模拟性能。

1. **遗忘的量化**：Walrus-1.3B（连续动力学 SciFM）在两阶段微调中的性能崩塌轨迹。
2. **35 倍劣化**：仅在模拟数据上微调 **20 epoch**，预训练数据集上的 rollout 一步误差即上升至 **35×**。
3. **第二阶段加剧**：适配真实实验数据后，模拟任务性能**进一步**退化。
4. **驱动因素分析**：刻画遗忘的潜在驱动——**数据集依赖性 (dataset dependence)** 与**任务表征相似度 (task representation similarity)**。
5. **轻量回放有效**：真实数据微调期间**回放仅 1% 的模拟数据**，即可恢复大部分损失的模拟性能，同时**保持对实验动力学的有效适配**。
6. **实践定位**：把灾难性遗忘确立为 SciFM sim-to-real 适应的**实际障碍**，并给出低成本对策。

## 技术方案

### 两阶段 sim-to-real 工作流

```math
\text{Stage 0 (预训练):}\quad \text{Walrus-1.3B} \xrightarrow[\text{预训练数据集}]{\text{pretraining}} \theta_0
```

$$\text{Stage 1:}\quad \theta_0 \xrightarrow[\text{模拟绕流数据}]{\text{finetune}} \theta_1 \quad\Longrightarrow\quad \text{误差} \times 35$$

$$\text{Stage 2:}\quad \theta_1 \xrightarrow[\text{实验绕流数据}]{\text{finetune}} \theta_2 \quad\Longrightarrow\quad \text{模拟任务性能进一步侵蚀}$$

### 回放缓解

$$\mathcal{L}_{\rm replay} = \lambda\,\underbrace{\mathbb{E}_{(\mathbf{x},\mathbf{y})\sim \mathcal{D}_{\rm sim}}\big[\ell(f_{\theta}(\mathbf{x}),\mathbf{y})\big]}_{\text{仅 1\% 的模拟数据}} + (1-\lambda)\,\underbrace{\mathbb{E}_{(\mathbf{x},\mathbf{y})\sim \mathcal{D}_{\rm real}}\big[\ell(f_{\theta}(\mathbf{x}),\mathbf{y})\big]}$$

| 组成 | 说明 |
|------|------|
| $\mathcal{D}_{\rm sim}$ | 预训练/模拟数据（**仅采样 1%**） |
| $\mathcal{D}_{\rm real}$ | 实验数据（主任务） |
| $\lambda$ | 回放比例超参 |

### 遗忘驱动因素分析框架

| 因素 | 度量思路 |
|------|---------|
| **数据集依赖 (dataset dependence)** | 模型在预训练集上的性能随微调步数的衰减曲线（rollout 误差） |
| **任务表征相似度 (task representation similarity)** | 模拟任务与实验任务的潜表征/解空间相似性度量，预测遗忘程度 |

## 数值方法 / 评估设置

| 技术 | 说明 |
|------|------|
| **模型** | Walrus-1.3B（连续动力学科学基础模型） |
| **算例** | 圆柱绕流（模拟数据 + 实验数据），同一物理系统 |
| **评估指标** | **一步误差 (one-step error)** 与 **rollout 性能**（在原始预训练数据集上） |
| **阶段 1** | 模拟数据微调 20 epoch，记录误差演化至 35× |
| **阶段 2** | 实验数据适配，记录模拟任务性能的二次侵蚀 |
| **缓解实验** | 加入 1% 模拟数据回放，比较恢复程度与真实任务适配质量 |

## 实验结论

- **遗忘是快速且严重的**：20 epoch 的模拟数据微调 → 预训练任务一步误差 **↑ 35×**。
- **sim-to-real 会复合遗忘**：真实数据适配不是修复，而是**进一步**侵蚀模拟任务性能。
- **回放是低成本有效对策**：1% 模拟数据回放恢复**大部分**损失的模拟性能，**同时**保持对实验动力学的有效适配。
- 遗忘程度可由**数据集依赖**与**任务表征相似度**解释——这两者可作为微调前的**预判指标**。

## 局限性

- 单个物理系统（圆柱绕流）+ 单个模型（Walrus-1.3B）；结论在其它 SciFM 与任务上的普适性待验证。
- 遗忘严重程度依赖于模拟与实验的**差异幅度**（噪声、几何偏差、参数偏差）；论文用"表征相似度"描述，但未给出普适阈值。
- 回放比例 1% 是经验最优还是最优未系统扫描。
- 遗忘的**机理**（是权重层面的 catastrophic forgetting、还是架构/表示层面的）未做权重级分析（如参数重要性/EWC 类对比）。
- 未与其它抗遗忘方法（EWC、LoRA 冻结、参数高效微调）做横向对比。
- **rollout 性能**的评估依赖测试轨迹长度，长时稳定性未充分考察。

## 实现建议

- **实现难度**：★★☆（回放是标准技巧，1 行数据管道改动；难点在 SciFM 微调基础设施）
- **预期性能**：1% 回放即可恢复大部分性能 → 存储与算力开销近乎可忽略
- **适用场景**：
  - 任何 SciFM / PDE 基础模型的 sim-to-real 迁移流水线
  - 多任务微调（一个预训练模型适配多个物理系统）
  - 需要在真实实验数据上适配但又想保留合成数据泛化能力的场景
- **可迁移点 / 实践清单**：
  1. **微调前先建立"模拟任务回归测试"**：把预训练集的一步误差 + rollout 误差当作**守护指标**
  2. **默认开启 1% 回放**，成本极低、收益极大
  3. 用**任务表征相似度**做微调前的风险预判：相似度低 → 预期遗忘重 → 提高回放比例或冻结部分层
  4. sim-to-real 应视为**两阶段**（模拟 → 实验）联合规划，而非单阶段迁移
  5. 遗忘是**架构无关**的现象（任何神经架构都有），因此不能靠"换个架构"绕过
