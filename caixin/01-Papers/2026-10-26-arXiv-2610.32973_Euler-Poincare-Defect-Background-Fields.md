## 核心贡献

> 用 **Euler-Poincaré 变分框架**（连续动力学）+ **拓扑缺陷的规范理论**（gauge theory）结合，建立缺陷与背景场**守恒耦合演化**的统一建模框架

1. 现状：缺陷位置的追踪方法众多，但**缺陷与背景场量耦合演化**的动力学模型仍具挑战
2. 关键：含移动缺陷的系统的整体行为**强烈受缺陷-场相互作用影响**
3. 框架组合：
   - **规范理论** → 克服**缺陷密度定义中的固有歧义**（这是缺陷动力学建模的经典难题）
   - **Euler-Poincaré 方法** → 在**无缺陷重连（reconnection）**假设下提供统一的建模途径
4. 两个案例研究：**Gross-Pitaevskii 量子流体理论** 与 **Ericksen-Leslie 向列液晶模型**

## 技术方案

### 核心思想

流体力学中的 Euler-Poincaré 变分结构是"对称性群作用下的守恒动力学"的通用语言。把它搬到缺陷动力学上：缺陷作为动量映射（momentum map）的像，用规范自由度处理其定义歧义。

### 关键技术

| 技术 | 说明 |
|------|------|
| Euler-Poincaré 变分动力学 | 处理对称性约化下的守恒演化 |
| 规范理论 (gauge theory) | 消除缺陷密度的定义歧义 |
| 动量映射 (momentum map) | 缺陷密度作为群作用的动量映射 |
| 耦合演化方程 | 缺陷密度场与背景场的守恒耦合系统 |
| Gross-Pitaevskii | 案例一：量子流体 |
| Ericksen-Leslie | 案例二：向列液晶 |

## 公式

```math
Euler-Poincaré 结构:
  给定李群 G 上的右不变（或左不变）拉格朗日量 L(g, ġ)
  → 守恒演化方程:
    d/dt (∂L/∂ġ · ξ) = ...    （动量映射守恒）
  标准形式:
    d/dt (J_f · Ad*_{g^{-1}} μ) + Ad*_{g^{-1}} (μ · ▽_e J_f) = 0

缺陷密度的规范处理:
  缺陷密度 ρ_def 由动量映射 J_f 给出
  通过规范等价类消除 "缺陷密度定义歧义"

GKP (Gross-Pitaevskii):
  iψ_t = -½Δψ + V(x)ψ + g|ψ|²ψ - i w(∇²|ψ|²)
  （含量子压力 w 项，w → 0 为经典 GP）

Ericksen-Leslie 液晶:
  ρ(D_t n + Ω n) = σ H + f
  ρ D_t m + ... = ...
  n·m = 1,  m = γ⁻¹(ν n + λ n⊗n) + κ n×(n×(∇²n))
```

## 代码片段

```python
import numpy as np

def euler_poincare_eom(lagrangian_gradient, momentum_map, Ad_inv_mu, mu):
    """
    通用 Euler-Poincaré 演化方程右端
    d/dt (J_f · Ad*_{g^{-1}} μ) = -Ad*_{g^{-1}}(μ · ▽_e J_f)
    """
    lhs_coeff = momentum_map(mu)          # J_f
    rhs = -Ad_inv_mu(mu)                  # -Ad*_{g^{-1}} μ
    return rhs, lhs_coeff

def defect_density_from_momentum_map(J_f, g, xi):
    """缺陷密度作为动量映射在无穷小群作用下的像 → 消除定义歧义"""
    return float(J_f(g) @ xi)

def gkp_schrodinger(rho, psi, V, g, w, dx):
    """含量子压力的 Gross-Pitaevskii 演化一步（谱空间）"""
    lap_psi = fftn(psi) * (-(2*np.pi)**2 * get_k2(psi.shape, dx))
    lap_rho = fftn(rho) * (-(2*np.pi)**2 * get_k2(rho.shape, dx))
    rhs = -0.5*lap_psi + V*psi + g*np.abs(psi)**2*psi - 1j*w*lap_rho*psi
    return ifftn(fft(psi) + 1j*dt*rhs)
```

## 实验结论

- **数据集**: 两个解析算例体系——Gross-Pitaevskii 量子流体、Ericksen-Leslie 向列液晶
- **基线**: 各自领域既有的缺陷动力学模型（各自单独处理缺陷或场）
- **结果**:
  - 建立统一的**守恒耦合演化**框架，同时推进缺陷密度与背景场
  - **规范理论成功消除缺陷密度的定义歧义**（经典难题）
  - **Euler-Poincaré 方法在无缺陷重连条件下**给出统一建模途径
  - 两类体系（量子流体、液晶）共用同一框架

## 局限性

- **无缺陷重连假设**：重连事件是液晶/超流中的真实现象，此时框架失效
- 案例为理想化模型，未含耗散、驱动、外场等复杂因素
- 纯理论工作，未提供数值实现与算例验证（摘要未提代码与算例）
- 变分构造的推导细节在全文，本笔记基于摘要
