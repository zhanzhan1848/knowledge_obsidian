## 核心贡献

> 评估**可压缩性近似**对**大气内重力波**特征的影响：模拟大气边界层与风电功率预测时常用**不可压 Boussinesq 形式**求解 N-S（密度仅作为位温的函数变化）；本文通过在**钟形山丘 (bell-shaped hills)** 上的**分层流动**建模，用**三种控制方程形式**——**线性化不可压 Boussinesq**、**完整不可压 Boussinesq**、**完全可压缩**——比较模拟的**内重力波特征**。三种形式都预测**定性相似的波结构**，但**可压缩方程预测更高的空气团位移（更高海拔处）、更大的表观波长变化，以及更大的波角差异，尤其在低 Froude 数下**；这些差异归因于**可压缩性与非线性效应**，在**低 Froude 数区**尤为关键，并可能导致**风电性能预测**与**风电场诱发重力波特征**预测的差异。

1. **问题背景**: 大气重力波是常见现象，对理解**风电发电**至关重要。常见来源是**地形上的分层流动**或**风电场前的风减速**。
2. **实践惯例**: 模拟大气边界层条件与风电功率时，常用**不可压 Boussinesq 形式**求解 N-S——它允许密度**仅作为位温的函数**变化。本文评估**这个简化有多重要**。
3. **对比的三种方程形式**:
   - **线性化不可压 Boussinesq**（linearized incompressible Boussinesq）
   - **完整不可压 Boussinesq**（full incompressible Boussinesq）
   - **完全可压缩**（fully compressible）
4. **算例**: **钟形山丘上的分层流动**（建模内重力波）。
5. **核心结论**:
   - 三种形式都预测**定性相似的波结构**；
   - 但**可压缩方程**预测：
     - **更高海拔处更大的空气团位移 (parcel displacements)**
     - **更大的表观波长变化 (apparent wavelength variations)**
     - **更大的波角差异 (wave angle differences)**
   - 这些差异**尤其在低 Froude 数下**显著。
6. **归因**: **可压缩性**与**非线性效应**。
7. **物理含义**: 差异在**低 Froude 数区域**变得尤为重要；进而可能导致**风电性能预测**与**风电场诱发重力波特征**的预测不同——凸显在**强分层环境**中准确捕捉流动行为时**可压缩性效应的重要性**。

## 技术方案

### 核心思想

**背景：大气边界层模拟与 Boussinesq 近似的普遍性**

风电功率预测依赖大气边界层 (ABL) 的模拟。工业界主流做法是**不可压 Boussinesq** 形式：
- 密度变化只通过**位温 (potential temperature)** 体现；
- 动量方程保留浮力项，但**忽略**压缩性引起的额外效应。

**这个近似在什么情况下会失效？**

Boussinesq 近似的两个基本假设：
1. **密度变化很小**（$\Delta\rho/\rho \ll 1$）—— 真实大气通常满足；
2. **流动是非定常、地转调整过的**—— 这是关键！

在 Boussinesq 框架下，**声波被过滤掉了**，只保留**内重力波**。但对于**大尺度、非定常、地转平衡的流动**，真正的控制方程是**原始方程 (primitive equations)**，其中**压缩性是本质的**（浮力直接改变压力场，而非通过位温间接影响）。

**低 Froude 数是关键区域**

Froude 数 $\mathrm{Fr} = U/\sqrt{gH}$ 衡量**惯性与浮力的相对重要性**：
- $\mathrm{Fr} \ll 1$（低 Froude）→ **浮力主导** → 流动强烈分层 → **压缩性效应显著**
- $\mathrm{Fr} \sim 1$ 或更大 → 惯性主导 → Boussinesq 近似较好

风电场景恰好常常是**低 Froude 数**（稳定边界层、低风速、大尺度地形）。

**三种形式的差异**

| 形式 | 声学 | 密度处理 | 适用 |
|---|---|---|---|
| **线性化不可压 Boussinesq** | 滤除 | 密度仅随位温线性变 | 小振幅波动 |
| **完整不可压 Boussinesq** | 滤除 | 密度是位温的**完整非线性函数** | 非线性但不可压 |
| **完全可压缩** | 保留 | 完整状态方程 + 声学 | 原始方程/大尺度 |

**三种形式都给出定性相似的波结构**——这本身是个重要结论，说明 Boussinesq 在**定性预测**上不太会出错。

**但定量上差异显著**：
- **空气团位移 (parcel displacement)**：可压缩预测在**更高海拔处**有更大的位移
  - 物理：压缩性允许**密度层结的非线性反馈**——上升的空气团膨胀、密度下降、进一步上升（**增强浮力反馈**）
- **表观波长变化**：可压缩下波长变化更大
- **波角差异**：低 Froude 数时差异最大
  - 物理：**地转调整 + 压缩性**改变波的结构（线性 Boussinesq 理论只给出简单形式）

**为什么这对风电重要？**

1. **风电场诱发的重力波**：大农场会向上推送空气团、产生重力波。这些波向上传播并可能**影响下风向的风机**（"wakes interacting with the atmosphere"）。
2. **功率预测**：波结构影响**低空急流 (low-level jet)** 的形成与强度 → 直接影响功率。
3. **两种效应的预测误差会叠加**。

### 关键技术

| 技术 | 说明 |
|------|------|
| Boussinesq 近似 | 滤除声学、密度随位温变化 |
| 线性化 vs 完整 Boussinesq | 非线性程度的区分 |
| 完全可压缩 / 原始方程 | 保留声学与完整压力-密度耦合 |
| 钟形山丘分层流动 | 产生内重力波的经典地形 |
| 内重力波特征 | 空气团位移、表观波长、波角 |
| Froude 数 | 区分浮力主导/惯性主导的关键参数 |
| 位温 (potential temperature) | Boussinesq 框架下的密度代理变量 |
| 风电性能预测 | 最终应用目标 |
| 风电场诱发重力波 | 应用场景 |

## 公式 / 理论要点

```math
% 线性化不可压 Boussinesq
\partial_t\boldsymbol{u} + \boldsymbol{u}\cdot\nabla\boldsymbol{u}
= -\frac{1}{\rho_0}\nabla p + \nu\nabla^2\boldsymbol{u}
+ \frac{g}{\theta_0}(\theta' - \theta_b')\hat{\boldsymbol{z}},
\qquad
\nabla\cdot\boldsymbol{u} = 0
```

```math
% 完整不可压 Boussinesq（密度为位温的非线性函数）
\rho(\theta') = \rho_0\left(1-\frac{\theta'}{\theta_0}\right),
\qquad
\partial_t\boldsymbol{u}+\boldsymbol{u}\cdot\nabla\boldsymbol{u}
= -\frac{1}{\rho(\theta')}\nabla p + \nu\nabla^2\boldsymbol{u}
+ g\frac{\theta'}{\theta_0}\hat{\boldsymbol{z}}
```

```math
% 完全可压缩（原始方程形式，含声学）
\partial_t\rho + \nabla\cdot(\rho\boldsymbol{u}) = 0
```

```math
% 动量（含压力梯度与浮力耦合）
\partial_t(\rho\boldsymbol{u}) + \nabla\cdot(\rho\boldsymbol{u}\otimes\boldsymbol{u})
= -\nabla p + \nabla\cdot\boldsymbol{\tau} + \rho g\hat{\boldsymbol{z}}
```

```math
% 内重力波的基本关系（可压缩下含附加项）
\frac{N^2}{1} = \frac{g}{\theta}\frac{\partial\theta}{\partial z},
\qquad
\omega^2 = N^2 k_z^2 / k^2 \quad\text{（Boussinesq）}
```

```math
% 可压缩修正：N^2 随高度非线性变化，且波的非线性更显著
N^2(z) = \frac{g}{\theta(z)}\frac{d\theta}{dz},
\qquad
\text{parcel displacement: }
\frac{\Delta z}{z}\sim \frac{\Delta\theta}{\theta}
\quad\Longrightarrow\quad
\text{压缩性增强浮力反馈}
```

```math
% Froude 数：判别可压缩性是否重要
\mathrm{Fr} = \frac{U}{\sqrt{gH}},
\qquad
\mathrm{Fr}\ll 1 \;\Longrightarrow\; \text{浮力主导、压缩性显著}
```

## 实验与结果

- **算例**: **钟形山丘上的分层流动**，模拟**内重力波**。
- **对比**: 三种控制方程形式（线性化 Boussinesq / 完整 Boussinesq / 完全可压缩）。
- **主要结果**:
  - **定性一致**: 三种形式都预测**定性相似的波结构** → Boussinesq 用于定性分析**基本可靠**；
  - **定量差异**（可压缩 vs Boussinesq）：
    - **更高海拔处更大的空气团位移**；
    - **更大的表观波长变化**；
    - **更大的波角差异**；
  - **差异在低 Froude 数下最大**；
  - **归因**: **可压缩性** + **非线性效应**；
  - **应用含义**: 在**低 Froude 数**（强分层）区差异尤为重要 → 导致**风电性能预测**与**风电场诱发重力波特征预测**的不同 → 凸显**可压缩性效应在强分层环境中的重要性**。
- **风格**: 属于**实践性评估 (assessment)** 型工作——问题导向，面向工程决策。

## 局限性

- **单一地形**：仅**钟形山丘**一种地形；真实地形（山地、海陆过渡、森林）的地形谱与粗糙度处理差异很大。
- **大气边界层湍流处理**：摘要未说明是否包含**完整湍流模型**（LES/DNS vs 线性化处理）。若是线性化，结论的适用范围会受限。
- **理想化来流**：稳定/不稳定层结的强度、风速范围、**地表热通量**等关键参数是否系统扫描未说明。
- **可压缩形式的实际可行性**：完全可压缩的 LES 在风电尺度上**极其昂贵**（需极小时间步长解析声学），所以结论虽正确但**可实施性受限**——论文若未讨论如何在实际成本下利用这些认识，会留下落地缺口。
- **未量化对风电功率预测的实际误差**：结论是"可能导致不同"，但没有给出**功率误差的量级**。
- **波角/波长/位移的具体数值**需查正文。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 高 — 完全可压缩的 ABL LES 需要极小 CFL 声学时间步长 + 精细网格（这是工业界"用可压缩 LES 做风电"的真实瓶颈）；三套模拟（线 Bouss / 完整 Bouss / 完全可压缩）需分别配置。
- **预期性能**: 完全可压缩成本可达 Boussinesq 的**一到两个数量级**；实际工业界常用"**准可压缩 (quasi-compressible)**"或"**低马赫 (low-Mach) 修正**"折中。
- **适用场景**:
  - **风电场尾流–大气相互作用**（大农场诱发的重力波、低空急流）——本文的直接应用；
  - **稳定边界层的低 Froude 数流动**；
  - **地形诱发的内重力波的定量预测**；
  - **数值方法选型**：为"Boussinesq 够不够用"提供定量依据。
- **可复用要点**:
  - **"定性一致、定量有别"是近似评估的标准结论模板**：这条表述本身很值得学习——它既不否定 Boussinesq 的价值，又指出了必须警惕的定量偏差。
  - **Froude 数作为可压缩性重要性的判据**——建议归档为一条通用规则：**低 Froude + 强分层 = 压缩性不可忽略**。
  - **可压缩性增强浮力反馈的物理链条**（上升 → 膨胀 → 密度降低 → 更强上升）可推广到所有**分层流中的非线性位移估计**。
  - **可压缩性的代价-收益权衡**：工业上更实际的路线可能是**低马赫修正的可压缩形式**或"**Boussinesq + 事后可压缩性修正**"（如用本文的定性结论修正空气团位移与波角）。这是值得探索的工程折中。
  - 建议与本轮 [[2026-11-12-arXiv-2611.12007-Phase-Resolved-Turbulence-Pulsatile-Pipe-Flow]] 对照：后者是**脉动管流的相位分辨湍流**，本文是**分层大气重力波的方程形式对比**。两者共同点：**"选哪种方程形式"会改变定量结论**。
