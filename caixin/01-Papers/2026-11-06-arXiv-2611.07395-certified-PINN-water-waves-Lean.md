# 近机器精度非线性水波的严格认证神经网络计算

## 核心贡献

结合**机器学习发现** + **严格计算机辅助数值认证** + **形式化验证**的完整流水线：

1. 用**物理信息神经网络（PINN）作为搜索机制**，从控制方程直接学习：
   - 波剖面
   - 波速
   - **延续实验中的表面张力**（无需训练数据）
2. **分阶段训练与精化**流程 → 即使在**强非线性区**，神经网络也达到**近机器精度**的方程残差
3. **单一公式**覆盖：
   - 高振幅 **Stokes 波**
   - **Crapper 波**
   - **Wilton 波纹（ripples）**
4. 从**高振幅 Wilton 波纹**出发做**表面张力延续** → 发现**新的高振幅候选解**
5. **区间算术**对候选解给出**一致残差上界**，考虑：
   - 浮点舍入
   - Fourier 截断
   - 混叠（aliasing）
   - 网格到连续体的误差
6. **在 Lean 中形式化**认证论证 → 机器检验从认证数值界到残差定理的推导
7. **重要声明**：区间认证与形式化的开发过程大量借助 LLM，但**结果有效性独立于 LLM** —— 数值界由区间算术严格围闭，数学推导由 Lean 内核检验

## 方法

### PINN 求解重力-毛细行波
**控制方程**（周期重力-毛细行波）：
$$
\eta_{tt} + \nabla\cdot\left[\left(g\nabla\eta + \nabla\sigma\frac{\nabla^2\eta}{\sqrt{1+|\nabla\eta|^2}}\right)\right] = 0
$$
其中 $\sigma$ 为表面张力（**在延续实验中由网络学习得到**）。

**Phase-field / level set 形式**（避免尖锐界面问题）：
$$
\phi_{tt} + \nabla\cdot\left[\left(g\nabla\phi + \sigma\nabla(\nabla\cdot(\nabla\phi/\sqrt{1+|\nabla\phi|^2}))\right)\right] = 0
$$

### 分阶段训练与精化
1. **粗训练**：获得解的粗略形状
2. **精化**：以粗解为初值，逐步提升精度
3. 目标：方程残差 $\to$ 机器精度量级（$\sim 10^{-16}$）

### 严格认证流程
```
PINN 候选解 → 冻结为显式有限表示
             → 区间算术计算残差上界（含舍入/截断/混叠/离散误差）
             → Lean 形式化：从认证界推导出残差定理
             → Lean 内核机器检验
```

**认证要素**：
- **浮点舍入误差**（interval arithmetic 自动处理）
- **Fourier 截断**（谱方法截断误差估计）
- **混叠**（dealiasing 处理）
- **网格到连续体误差**（离散-连续误差界）

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 方法 | PINN（无训练数据，纯方程约束） |
| 精度 | ✅ **近机器精度**残差 |
| 验证方式 | **区间算术 + Lean 形式化**（双保险） |
| 数据需求 | ✅ **零训练数据** |
| 泛化 | ✅ 单一公式覆盖 Stokes/Crapper/Wilton 波 |
| 新发现 | ✅ 表面张力延续 → 新高振幅候选解 |
| 计算成本 | PINN 训练较贵，但**一次训练可覆盖多解**（延续） |

## 局限性

- **区间认证的严格性依赖于完备的误差预算**：若遗漏某类误差源，认证可能失效
- Lean 形式化**工作量大**（论文说"L substantial assistance from LLM"）→ 可复现性门槛高
- PINN 训练的**超参数敏感性与收敛性**问题仍然存在（只是结果事后被严格认证）
- **候选解的完备性未证明**：认证证明"这是解"，但**不能证明"没有其他解"**
- 只能处理**周期性行波**这一特定问题族

## 实现建议

- **实现难度**：🔴 高。需要：PINN 框架（PyTorch/JAX）+ 区间算术（mpmath/Arb）+ **Lean 4** 形式化
- **预期性能**：训练成本中等（GPU）；认证成本高（区间算术 + 形式化）
- **适用场景**：
  - **需要严格保证**的自由表面/波动问题（水波、界面波）
  - **实验难以验证**的场景（深海波、极端非线性波）
  - **数学形式化验证**在科学计算中的可行性示范
  - 新型**已认证求解器**的范式参考
- **落地建议**：
  - 阶梯式采用：
    1. 先用 PINN 得候选解（不要求认证）
    2. 用**区间算术单独**认证残差（不必做 Lean）
    3. 仅在关键场景补 Lean 形式化
  - 建议**先做低维周期问题**（1D 行波），再扩展 2D
  - 与 [[2026-11-06-arXiv-2611.07395]] 中的 Wilton 波发现对照：可尝试**独立复现**新候选解
  - 工具：Lean 4 + `Mathlib`；区间算术用 `Arb`（FLINT）或 `mpmath.iv`
