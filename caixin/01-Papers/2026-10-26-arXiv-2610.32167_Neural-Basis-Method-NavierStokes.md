## 核心贡献

> 提出 **Neural Basis Method (NBM)**，用"表示-再投影"原则替代主流 PINN 范式：固定神经基定义表示空间，用控制方程投影决定展开系数

1. 直击主流 PINN 两大缺陷：**小 PDE 残差不蕴含小解误差**（无保证）、**随问题规模增长而扩展性差**
2. NBM：固定神经基 → 定义表示空间；对控制方程**投影** → 确定展开系数
3. 同一组基同时定义参数化解流形的**公共坐标**，把算子学习重构为**参数→系数映射**，从而**去除显式空间依赖**（可扩展性的关键）
4. 对不可压流动给出**仅速度**的表述，其残差提供**后验（a posteriori）速度误差估计** → 建立**认证的、无需数据的**系数学习目标
5. 理论分析与数值实验证明精度、效率、泛化性与可扩展性均优于基线

## 技术方案

### 核心思想

传统 PINN：网络直接输出场 u(x,t)，损失 = PDE 残差。问题：残差小 ≠ 解误差小，且网络要"记住"空间结构，规模一大就崩。

NBM 两步走：

1. **表示**：固定一组神经基 {φ_k(x, t)}（可训练或预训练），解写为 u = Σ_k c_k φ_k
2. **投影**：把控制方程投影到基张成的空间上，得到关于系数 c_k 的（常微分）方程组

因为基固定且共享，参数化解流形上的每个解有同一组坐标 → 算子学习退化为参数→系数的映射，网络不再需要处理空间坐标，可扩展。

### 关键技术

| 技术 | 说明 |
|------|------|
| 神经基展开 | u(x,t) = Σ_k c_k(x,t) φ_k(x,t)，φ 固定 |
| 控制方程投影 | Galerkin 型投影，得到系数方程组 |
| 不可压仅速度形式 | 通过投影掉压力，残差可解释为速度误差 |
| 后验误差估计 | 残差 → 速度误差上界，无需真值标签 |
| 参数化解流形公共坐标 | 同组基 → 系数空间中的低维流形 |
| 认证训练目标 | data-free / certified objective |

## 公式

```math
表示:
  u(x, t) = Σ_{k=1}^{K} c_k(x,t) φ_k(x,t)

投影（Navier-Stokes 变分形式）:
  ⟨ ∂_t u + u·∇u + ∇p - ν∇²u ,  φ_k ⟩ = 0
  →  M_{kj} ∂_t c_j + N_k(c) + P_k(c) = ν L_{kj} c_j

不可压仅速度形式（投影掉压力）:
  对 φ_k 取 (∇·) 检验, 压力项消失 → 只剩速度系数方程

后验误差估计:
  ‖u - u_h‖ ≤ C · ‖残差(û_h)‖   (证书, 无需数据)

算子学习重述:
  u_μ = Σ_k c_k(μ) φ_k    →    网络学习映射 μ ↦ c(μ)
  (空间依赖被吸收到固定的 φ 中)
```

## 代码片段

```python
import torch

def nbm_coefficients(u_basis, rhs_proj):
    """
    u_basis: (K, X)        固定神经基矩阵 φ_k 在采样点的值
    rhs_proj: (K, ...)     投影后的右端（粘性项 + 非线性投影）
    求解系数方程组的对角质量矩阵形式（若 M 为对角）
    """
    M_diag = torch.diagonal(u_basis @ u_basis.T)   # M_kk
    # 显式/指数时间推进系数
    d_c = rhs_proj / M_diag
    return d_c

def certify_velocity_error(residual_norm, C):
    """后验速度误差证书（无需真值标签）"""
    return C * residual_norm
```

## 实验结论

- **数据集**: Navier-Stokes 基准问题（Navier-Stokes 求解 + 学习任务）
- **基线**: 主流 PINN / 神经算子变体
- **结果**:
  - **精度**：优于基线
  - **效率**：显著优于基线
  - **泛化性**：优于基线
  - **可扩展性**：去除显式空间依赖后，**随问题规模增长而扩展性大幅改善**
  - 不可压情形的残差可**直接转化为速度误差上界**（认证）

---

## 局限性

- 神经基的选取/训练策略未充分展开，基的秩 K 如何设定是关键超参
- 投影仍需组装大规模系统（M, N, L），"去除空间依赖"在实现层面不完全彻底
- 后验误差常数 C 的普适性依赖问题类型与边界条件
- 摘要未给出具体算例规模与硬件开销，需查全文
