# 液滴-液池撞击：反弹还是融合？

## 核心贡献

建立**液滴-液池撞击的判别模型**，**首次与实验达到定量一致**（分离反弹/融合的临界撞击速度）：

1. **润滑理论**描述形变困住的**气膜**，考虑其**显著曲率**
2. 在**有限元框架**内实现
3. 关键在于捕获**微纳米尺度物理**：
   - **van der Waals 驱动的 disjoining 压力**
   - **依赖气体平均自由程的气体动理学效应**
4. **仅用独立测量的材料参数**即获得与实验的定量一致
5. 拓展研究：低环境气压下的行为；浅池与薄膜上的**弹跳-融合-弹跳-融合**转变（随池深减小）

## 物理机制

液滴撞击液池时：
1. 液滴形变，在滴与池之间**困住一层薄气膜**
2. 气膜**泄压（drainage）** → 曲率增大 → 产生**薄膜间吸力**
3. 两条竞争路径：
   - 气膜完整 → 液滴**反弹（bounce）**
   - 气膜**破裂（rupture）** → 液滴**融合（merge）**

## 数值方法

### 气膜的润滑描述
气膜厚度 $h$ 的演化由 Reynolds 润滑方程控制（Reynolds 方程，忽略惯性）：
$$
\frac{\partial h}{\partial t} = \frac{1}{3}\frac{\partial}{\partial x}\left(h^3 \frac{\partial p}{\partial x}\right) + \text{(其他源项)}
$$
压力 $p$ 由润滑理论给出，结合：
- **曲率项**（气膜显著曲率时不可忽略）
- **disjoining 压力**（van der Waals + 短程排斥）：
$$
\Pi(h) = -\frac{A_H}{6\pi h^3} + \frac{B}{h^{n}} \quad \text{(典型 vdW 形式)}
$$

### 气体动理学修正
- 气体稀薄时，**平均自由程 $\lambda$ 与气膜厚度可比** → 连续介质假设失效
- 采用 **Knudsen 边界条件**（或滑移函数）处理气体动理学效应
- 这是"纳米尺度物理"的体现：**$\lambda \sim 10$–$100$ nm，而气膜厚度 $h$ 可低至 $\sim 100$ nm**

### 有限元框架
- 有限元求解气膜方程 + 液滴/池变形的耦合
- 与界面输运（VOF/ALE 类）耦合追踪液滴外形

### 参数策略
**仅用独立测量的材料参数**（不调参拟合临界速度）→ 这是"定量一致"的关键可信度指标。

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 离散化 | 有限元（气膜薄层问题）+ 界面追踪 |
| 物理模型 | 润滑理论 + vdW disjoining 压力 + Knudsen 气体动理学 |
| 尺度跨度 | 需同时解析宏观液滴形变与纳米气膜 → **跨尺度耦合是主要难点** |
| 稳定性 | 润滑方程刚性 → 需隐式 + 稳定时间步 |
| 边界条件 | 关键是 Knudsen 边界（依赖平均自由程） |

## 实验/结论

| 情景 | 结果 |
|---|---|
| 基准（正常气压） | **首次**与理论驱动实验定量一致（临界撞击速度） |
| 低环境气压 | 行为改变（气膜更易破裂 → 更多融合） |
| 浅池 / 薄膜 | 出现**弹跳→融合→弹跳→融合**的**多重转变**（随池深减小） |

## 局限性

- 平面/局部模型，未考虑**完整三维液滴形变**
- 需要 $\lambda$ 与 $h$ 的**可靠估计**（实验测量困难）
- 材料参数（$A_H$, $B$）从独立实验获取，存在**测量误差传递**
- 弹性/惯性变形与气膜的强耦合处理简化

## 实现建议

- **实现难度**：🔴 高。需要：薄层/润滑方程的专用有限元 + 纳米尺度 disjoining 压力项 + Knudsen 边界 + 与界面方法的耦合
- **预期性能**：相比 DSMC/分子动力学（纳米尺度必要）**代价低数个数量级**，且能覆盖完整撞击过程
- **适用场景**：
  - **液-液撞击**、液滴合并/反弹判别
  - **打印/涂布/雾化**工艺中的液滴动力学
  - **涂层润湿与自清洁**表面（防污涂层设计）
  - 微流控中的液滴-通道相互作用
- **落地建议**：
  - 与 **Basilisk VOF**（知识库已有）配合：宏观形变用 VOF，局部气膜用薄层模型嵌入（重叠网格 / 子模型耦合）
  - 关键参数：液膜厚度量级需与 Knudsen 数 $\mathrm{Kn}=\lambda/h$ 匹配 → 网格分辨率至少能分辨 $\lambda$
  - 参数敏感性：$A_H$（Hamaker 常数）是主导参数
- **对比方案**：纳米尺度直接用 MD 模拟（更准但极贵），本文方法在中间尺度最划算
