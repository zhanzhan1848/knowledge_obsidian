## 核心贡献

> 通过**直接数值模拟 (DNS)** 系统扫描螺旋涡（helical vortex）中的**椭圆 (elliptic) 与曲率 (curvature) 两种短波不稳定性**，首次在同一框架下划分出**弱非线性饱和区**与**超出弱非线性区**两个演化区，并给出后者的**新物理解释**：增长率越大，需要更大的扰动幅值才能让非线性效应与线性增长相平衡。

1. **双参数扫描**：系统变化**归一化涡核半径**与**归约螺距 (reduced pitch)**，覆盖宽范围的线性增长率 $\sigma$。
2. **两类非线性演化**：
   - **弱增长率** → 椭圆与曲率不稳定性都表现为**弱非线性饱和**，涡结构与不稳定模态结构**大体保持**；
   - **大增长率** → 不稳定性达到更高能量水平，**超出弱非线性区**，涡结构与不稳定模态结构发生**显著变形**。
3. **弱非线性饱和的普适性**：结合此前对其他涡构型（Taylor 柱、螺旋涡等）的结论，确立**弱非线性饱和是短波不稳定性的普遍特征**。
4. **大增长率区的物理解释**：线性增长率越大 → 平衡所需扰动幅值越大 → 此时**高阶非线性效应**与**弱非线性分析中被截断的模态分量**变得重要，这是偏离弱线性区的物理根源。
5. **工程价值**：螺旋涡是旋转叶片**叶尖涡 (tip vortex)** 的模型，结果对**风机叶尖涡控制**、**尾迹恢复加速**从而提升风机性能具有指导意义。

## 技术方案

### 核心思想

**螺旋涡 (helical vortex / helical mode)** 是轴向流动中一种空间螺旋状的结构（如斯廷森螺旋、旋翼桨尖涡的螺旋化核心），其横截面沿轴向旋转。

在此基础上叠加**短波 (short-wave) 二维不稳定性**：

- **椭圆不稳定性 (elliptic instability)**：由涡横截面**椭圆化**触发的不稳定性——当涡在旋转的各向异性背景下，截面被拉伸为椭圆，短波沿长轴/短轴方向选择性放大。经典来源：旋转锥体流动中的倾斜扰动（Conlon & Ye 1997 型）、与 Taylor 柱的倾斜波类似。
- **曲率不稳定性 (curvature instability)**：由涡轴**空间曲率**引起的短波不稳定性，是自激过程（弯曲波耦合螺旋度）的一部分。

**弱非线性理论**假设扰动幅值足够小，使得：
- 线性增长率 $\sigma$ 与非线性饱和率（$\sim \epsilon^2$，其中 $\epsilon$ 为扰动幅值）可以在 $\sigma \sim \epsilon^2$ 的标度下相平衡；
- 高阶非线性项与模态间三波/四波耦合可忽略。

本文的贡献正是**找到这一假设的失效边界**并给出解释。

### 关键技术

| 技术 | 说明 |
|------|------|
| **直接数值模拟 (DNS)** | 三维瞬态 Navier-Stokes 求解；螺旋涡内短波的时间尺度远小于涡整体演化，需高时间分辨率 |
| **涡结构度量** | 归一化涡核半径 $\epsilon_v$ 与归约螺距 $\kappa$（或等效的螺距比）作为构型参数；需定义涡核的定量判据（涡量/切变率阈值或涡量等值面） |
| **线性增长率标定 $\sigma$** | 在每个构型下先做线性特征值分析或极小的非线性扰动模拟确定 $\sigma$，作为分类依据 |
| **非线性饱和观测** | 在线性阶段与非线性阶段之间追踪扰动能量的非线性增长率变化，判断饱和是否出现 |
| **弱非线性理论对比** | 与既有的弱非线性分析（$\sigma \sim \epsilon^2$ 标度、高阶项截断）逐项比对，定量标出偏离处 |
| **椭圆/曲率两类不稳定性对比** | 相同参数扫描下分别推进两类不稳定性，比较结构演化的差异 |
| **跨度比 (spanwise ratio) / 流向坐标** | 螺旋涡通常在展向采用周期边界、流向下游发展；展向周期长度与螺旋波长需匹配 |
| **网格与时间步** | 短波波长需要跨流向与展向的充分分辨率；CFL 限制由局部最大速度与最小网格尺寸共同决定 |

## 公式

```math
\text{归一化涡核半径（构型参数）}:\quad
\epsilon_v = \frac{R_c}{L_x}
\quad (R_c:\ \text{涡核半径},\ L_x:\ \text{流向特征长度})
\]

```math
\text{归约螺距（reduced pitch）}:\quad
\kappa = \frac{\text{螺距}}{\text{涡核直径}}
\quad\Longrightarrow\quad
\text{小 }\kappa \ \text{= 强缠绕（紧螺旋）}
```

```math
\text{扰动演化的动力学方程（结构）}:\quad
\frac{\partial \bm{q}}{\partial t}
= \mathcal{L}\bm{q}
+ \mathcal{N}_2[\bm{q},\bm{q}]
+ \mathcal{N}_3[\bm{q},\bm{q},\bm{q}]
+ \cdots
\quad\Longrightarrow\quad
\dot{\epsilon} \sim \sigma \epsilon - c\,\epsilon^{2}\ (\text{弱非线性}) - \cdots
```

```math
\text{弱非线性饱和的标度假设}:\quad
\sigma \sim \epsilon^{2}
\quad\Longrightarrow\quad
\sigma \sim \varepsilon^{2}\ \text{平衡}\ \Rightarrow\ \varepsilon \sim \sigma^{1/2}
\quad\text{（对 }\sigma\text{ 敏感，故大 }\sigma\text{ 时 }\varepsilon\text{ 必然变大）}
```

```math
\text{三波非线性相互作用的本质形式（模态耦合）}:\quad
\partial_t \bm{a}_n \supset \sum_{m+k=n}\bm{a}_m^{*}\bm{a}_k
\quad\Longrightarrow\quad
\text{弱非线性分析仅保留低阶（三波）耦合，高阶（≥四波）被截断}
```

```math
\text{线性特征值问题}:\quad
\mathcal{L}\bm{q} = \sigma \bm{q} + i\omega \bm{q}
\quad\Longrightarrow\quad
\sigma + i\omega:\ \text{增长率与频率}
```

> 注：原文弱非线性分析的具体系数（$\sigma \sim c\epsilon^2$ 中的 $c$）、椭圆/曲率不稳定性各自的增长率表达式与临界参数取值需参照正文；摘要未披露具体数值，此处仅给出方法层面的控制方程与标度关系。

```python
# 线性特征值分析（用于标定 sigma）与弱非线性标度检验的概念性接口
def linear_growth(base_flow, perturbation_type, n_modes=3):
    """求解 base_flow 上的线性特征值问题，返回增长率 sigma 与频率 omega"""
    # L q = (sigma + i omega) q  ->  时间推进法/谱法求主特征值
    sigma, omega = dominant_eigenvalue(L_op(base_flow, perturbation_type))
    return sigma, omega


def weak_nonlinear_consistency(sigma, eps_measured):
    """检验 sigma ~ eps^2 的弱非线性标度是否成立

    弱非线性预测: eps_sat ~ sqrt(sigma / c)
    若实测 eps_sat 明显偏离，或需保留 >=4 波耦合，则判定超出弱非线性区
    """
    eps_pred = (sigma / c) ** 0.5
    return abs(eps_measured - eps_pred) / eps_pred

## 实验结论

- **数据集/算例**：带轴向流的螺旋涡基流，叠加**椭圆不稳定性**与**曲率不稳定性**两类短波扰动；DNS 扫描**归一化涡核半径**与**归约螺距**两个构型参数，以获得宽范围的线性增长率 $\sigma$。
- **基线**：既有的**弱非线性分析理论**（用于判定偏离）。
- **结果**：
  - **较小增长率**：椭圆与曲率不稳定性均出现**弱非线性饱和**，螺旋涡结构与不稳定模态结构**大体保持**。
  - **较大增长率**：不稳定性达到更高能量水平，**超出弱非线性区**，涡结构与不稳定模态结构**显著变形**。
  - 与弱非线性分析对比表明：**增长率越大，平衡所需的扰动幅值越大**；在这样的大幅值下，**高阶非线性效应**与**弱非线性分析中被截断的模态分量**变得日益重要——这是偏离弱非线性区的物理解释。
  - 结合其他涡构型的已有结论：**弱非线性饱和是短波不稳定性的普遍特征**。

## 局限性

- **数值成本**：螺旋涡 + 短波的三维 DNS 需要在流向、展向、径向同时解析短波，空间步长极小、时间步受严格 CFL 限制；参数扫描点的计算量巨大。
- **线性增长率的获取精度**：$\sigma$ 本身由数值特征值分析得到，其误差直接污染"弱/强"分界的判定；分界位置是定性结论而非精确临界值。
- **涡构型的单一性**：仅研究"带轴向流的螺旋涡"这一类构型，结论向真实叶尖涡（存在强三维端部效应、复杂来流切变、叶片几何的展向变化）的外推需要谨慎。
- **单一流体/单一工况**：未讨论粘性效应、Re 数、来流湍流度、Ma 数对弱非线性边界的移动；涡核定义方式会影响 $\epsilon_v$ 与 $\kappa$ 的具体数值。
- **扰动类型的局限**：仅考察椭圆与曲率两种短波不稳定性，其他类型（如粘性-表面波耦合不稳定性、方位不稳定性）未纳入。
- **"结构保持"的判据主观**：涡与模态结构是否"保持"缺乏统一的定量指标，结论有一定定性成分。
- **工程转化的距离**：从机理认识直接到"叶尖涡控制策略"之间还缺一步：需要可控参数（如螺旋涡螺距、涡核强度）与不稳定增长率之间的可操作映射。

## 实现建议

- **实现难度**：🔴 高。需要高精度的三维非定常 DNS 求解器（谱元/高阶有限体积），螺旋涡初场构造与短波扰动的可控注入，以及可靠的 $\sigma$ 提取（线性特征值分析）。
- **预期性能**：单个算例成本很高（DNS 级别，流向步数常需数千步以上以覆盖非线性演化）。可考虑的降本路线：先用**线性特征值分析 + 弱非线性模态展开**做粗筛，只对分界附近与典型点做完整 DNS；展向采用周期以降低域尺寸；并行上流向方向可强并行（周期展向 + 流向分块），MPI 扩展性中等偏好（通信面较多）。
- **适用场景**：旋转机械（风机、燃气轮机、螺旋桨）叶尖涡的稳定性与控制设计；螺旋流动传质/传热强化；以及更一般的**短波不稳定性弱非线性饱和的普适性检验**。
- **落地建议**：先把**分类判据做扎实**——在同一个 $\sigma$ 下对比"结构保持"与"结构变形"的定量度量（如涡核椭圆度、螺距的时间方差、模态能量谱的次谐波成分），再谈普适性；工程应用侧建议把 DNS 得到的 $\sigma(\epsilon_v,\kappa)$ 与真实叶尖涡的可测几何量（由 PIV 测量）关联，才能指导主动涡控制。

## 数值实现补充（2026-10-31 深挖 arXiv HTML 全文）

### 求解器与离散格式
- **空间离散**：
  - 径向 $r$：**六阶紧致格式**（Lele 1992）
  - 周向 $\theta$、轴向 $z$：**Fourier 谱方法**
  - 非均匀拉伸径向网格（Hattori et al. 2019）
- **时间离散**：**Crank-Nicolson**（粘性项）+ **二阶 Adams-Bashforth**（其余项）
- 线性化 N-S 方程采用相同空间与时间离散

### 网格与时间步
- 域：$0\le r\le R_{far}=100R$，$0\le\theta<2\pi$，$0\le z<2\pi L$
- **网格**：$G_r\times G_\theta\times G_z=565\times896\times256$（$L/R=0.3$）；$L/R=0.5,\ 0.55$ 时 $G_z=448$
  - 涡附近 $\Delta r\approx7.14\times10^{-3}R$（$r\lesssim1.5R$），向外渐变到 $\Delta r\approx2R$（$r=R_{far}$）
  - $G_\theta$、$G_z$ 的选取使涡附近物理网格间距 ≈ 最小径向间距
- **时间步**：$\Delta t=7.5\times10^{-4}R^2/\Gamma$
- **无量纲化**：长度 $R$，时间 $R^2/\Gamma$

### 边界条件
- 径向外边界 $r=R_{far}=100R$：**滑移**（足够远，影响可忽略）
- $\theta$、$z$ 方向：**周期**

### 局部坐标系（Frenet-Serret 标架）
```math
\boldsymbol{e}_\xi=\boldsymbol{e}_r(\theta_P),
\qquad
\boldsymbol{e}_B=\left(1+\frac{r^{2}_P}{L^{2}}\right)^{-1/2}
\left[\frac{r_P}{L}\boldsymbol{e}_\theta(\theta_P)+\boldsymbol{e}_z\right],
\qquad
\boldsymbol{e}_\eta=\boldsymbol{e}_B\times\boldsymbol{e}_\xi
```
```math
\boldsymbol{e}_\rho=\cos\psi\,\boldsymbol{e}_\xi+\sin\psi\,\boldsymbol{e}_\eta,
\qquad
\boldsymbol{e}_\psi=-\sin\psi\,\boldsymbol{e}_\xi+\cos\psi\,\boldsymbol{e}_\eta
```
> 由于**螺旋对称性**，基流的局部结构与 $P$ 的选取无关。

### 数值流程（三步法）
1. **(i)** 用 Batchelor 型涡构造初值，积分 N-S 至**准定常态**（螺旋涡在沿 $z$ 平移的坐标系中匀速传播）
2. **(ii)** 求解线性化 N-S 方程，获得短波不稳定模态
3. **(iii)** 基流 + 该模态，考察非线性演化

> 非线性演化中基流**冻结**（沿用 Schaeffer & Le Dizès 2010 的处理），目的是**隔离非线性扰动动力学**并便于与弱非线性理论直接对比；有效性在附录 7 中检验。
> 单一失稳模态扰动下，高次谐波（$\mathbf{u}'_{2N},\mathbf{u}'_{3N}$）会生成，但**非谐波分量不会生成** —— 因此不涉及 Mason & Kerswell 类三元非谐波交互。
