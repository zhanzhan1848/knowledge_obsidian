# POD-based ML Framework for MHK Turbine Wake Prediction in Natural Waterways

**arXiv**: [2610.31547](https://arxiv.org/abs/2610.31547) · **提交**: 2026-10-22 16:53 UTC
**作者**: Mustafa Meriç Aksen, Hossein Seyedzadeh, Mehrshad Gholami Anjiraki, Ali Khosronejad (UIC)

## 工程背景

**海洋水动力涡轮机 (MHK)** 阵列布局优化在**天然河道**中远比海上风电困难：
- 复杂河床地形 (bathymetry)
- 平面几何不规则
- 背景湍流强（淹没尾流信号）

传统 LES 成本过高，无法做大规模布局优化扫描 → 需要代理模型。

## 方法流程

```
1. 真实潮汐站点 LES（落潮 ebb tide 条件）
        ↓
2. POD 分解瞬时 LES 场 → 空间模态
        ↓  （选择性过滤：抑制背景涨落）
3. 选定模态 → 训练 3D 卷积 encoder-decoder
        ↓
4. 预测时间平均速度场（mean flow field）
```

## 关键发现

| 指标 | 结果 |
|------|------|
| POD 过滤 vs 未过滤 | **MSE 降低 3 个数量级** |
| 网络规模 | 相同 |
| 训练成本 | 相同 |
| 场地 | 真实世界潮汐河道站点 |

**同等算力预算下，POD 选择性过滤带来 1000× 误差下降。**

## 数值方法评估

| 维度 | 评价 |
|------|------|
| 底层求解器 | LES（瞬时场） |
| 降阶 | POD（线性正交分解）+ 3D CNN |
| 空间维度 | 三维 |
| 训练数据 | 单工况（落潮）单站点 |
| 泛化性 | ⚠️ 未验证跨站点/跨潮相/跨布置 |

## 稳定性与代价

- LES 网格需求高（河床地形需解析），但仅需一次 → 成本可摊销
- POD 截断模态数是关键超参：过少丢尾流，过多引入背景噪声
- 代理模型推断成本 ≈ 0 → 可支撑大规模布局优化搜索

## 推荐结论

✅ **推荐实现**（工程落地价值高）。三点提醒：
1. **POD 过滤是核心贡献**，不是 CNN 本身 —— 这也解释了为何误差能降 3 个数量级
2. **泛化性未验证**：换河道/换潮相/换机组数时 POD 基底会变，需重新训练或迁移
3. 与 [[2610.31605]]（同日）互补：后者回答"何时值得用非线性"，本篇展示"POD 过滤即已足够"
