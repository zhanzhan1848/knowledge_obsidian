## 核心贡献

> 在**统一气体动力学格式 (UGKS)** 基础上发展 **CLUGKS（复数线性化 UGKS）**：对离散 UGKS 残差做一阶扰动并施加**时谐假设 + 复振幅**，把扰动方程转化为**稳态椭圆系统**，用**伪时间推进 + LU-SGS 加速**求解；从而**无需混合耦合**，kinetic 激波结构、壁面滑移、温度跳跃与非 Fourier 热流全部被内蕴捕捉。

1. **CLUGKS 线性稳定性框架**：一阶扰动 + 时谐复振幅 → 扰动方程成为**稳态椭圆系统**（pseudo-time marching + LU-SGS 加速求解），避免了时间推进线性稳定性的成本。
2. **无需混合耦合的动理学非平衡**：kinetic 激波结构、壁面**速度滑移**、**温度跳跃**、**非 Fourier 热流**全部**内蕴于格式**（而非外挂 Navier–Stokes/DSMC 耦合）。
3. **三个基准验证**：等温壁驻波；Mach 2 法向激波 + 斜入射声波；高超声速钝楔的自由来流**声学感受性 (receptivity)**。
4. **40 km vs 50 km 等效高度对比（关键物理结论）**：
   - **40 km**：UGKS 与 Navier–Stokes 的**壁面响应（周期与相位）吻合良好**；但 UGKS 显示壁面滑移使下游维持**弱正空间增长率**。
   - **50 km**：稀化增强，产生 **kinetic 温度前驱 (temperature precursor)** 与**增厚、合并的激波层**；壁压响应仍接近，但**温度与热流扰动出现显著偏差**。
5. **核心论断**：**中等稀化下连续介质模型足以捕捉主导的壁压特征**，但在**更高高度**，解析激波中的**动理学非平衡（特别是其热足迹）**是必需的。

## 技术方案

### 核心思想

近空间（near-space）流动中，前缘激波与壁面附近存在**局部稀化（local rarefaction）**，导致基于 Navier–Stokes 的稳定性与感受性分析失真——因为连续介质假设无法描述**速度滑移、温度跳跃**与**非平衡输运**。

**UGKS（统一气体动力学格式）** 本身是一个多尺度动理学格式，能在连续区到稀薄区之间连续过渡。但 UGKS 原先是**时间推进的定常/非定常求解器**，要用于**线性稳定性分析**，传统做法是做一个**线性化的定常求解器**并伴随时间推进——代价高昂且难以在复数域中实现。

本文的创新在于 **CLUGKS**：把 UGKS 的离散残差做**一阶扰动展开**，扰动量写成 $\hat{\boldsymbol{u}}' = \mathrm{Re}[\hat{\boldsymbol{u}}\,\exp(-i\boldsymbol{k}\cdot\boldsymbol{x}+i\omega t)]$ 形式。由此：
- 一阶方程在频域中**消去了时间导数**，化为**稳态椭圆问题**；
- 求解可以用**伪时间推进**（pseudo-time marching）+ **LU-SGS 加速**——这是 CFD 中处理稳态隐式系统的标准武器；
- 由于 UGKS 的动理学结构在离散层面被完整保留，**滑移、温度跳跃、非 Fourier 热流自然出现在线性化方程中**，不需要额外的边界处理或混合模型。

这使得**动理学尺度的线性稳定性分析**变得可行——此前这类分析通常只能借助于 DSMC 或混合 Navier–Stokes/DSMC 方法。

### 关键技术

| 技术 | 说明 |
|------|------|
| UGKS 统一气体动力学格式 | 连续-稀薄统一的多尺度动理学求解器 |
| CLUGKS 复数线性化 | 残差一阶扰动 + 时谐复振幅 → 稳态椭圆系统 |
| 伪时间推进 + LU-SGS | 稳态隐式线性系统的加速求解策略 |
| 时谐（time-harmonic）假设 | 复振幅表示，频域化消除时间导数 |
| 声学感受性 (receptivity) | 自由来流扰动在边界层的放大机制 |
| 壁面速度滑移 | UGKS 内蕴的稀化边界效应 |
| kinetic 温度前驱 | 激波内动理学非平衡的先行温度信号 |
| 非 Fourier 热流 | 稀化区热流的非傅里叶特征 |
| 等效高度对比 | 40 km / 50 km 稀化程度的系统对比 |

## 公式 / 理论要点

```math
% UGKS 界面分布函数（非 Maxwellian 假设，允许非平衡）
f(\boldsymbol{x},\boldsymbol{\xi},t)
= \sum_{k=0}^{\infty} f_k(\boldsymbol{x},\boldsymbol{\xi},t),
\qquad
f_0 = n g(\boldsymbol{\xi};\boldsymbol{u},T),\quad
f_1 = -\tau(\boldsymbol{\xi}\cdot\nabla)g + \cdots
```

```math
% CLUGKS：一阶扰动展开（复数线性化）
f = f^{(0)} + \delta f, \qquad
\delta f(\boldsymbol{x},\boldsymbol{\xi},t)
= \mathrm{Re}\!\left[
\hat{f}(\boldsymbol{\xi})\,e^{-i\boldsymbol{k}\cdot\boldsymbol{x}+i\omega t}
\right]
```

```math
% 时谐代换后的稳态椭圆形式（时间导数被消掉）
-i\omega\,\hat{f}
+\boldsymbol{\xi}\cdot\nabla_{\boldsymbol{x}}\hat{f}
= \hat{S}[\hat{f}]
\quad\Longrightarrow\quad
\mathcal{L}(\boldsymbol{k},\omega)\,\hat{f}=0
```

```math
% 壁面滑移条件（UGKS 内蕴，非外加）
\boldsymbol{u}_{\text{wall}}\cdot\boldsymbol{n}\neq 0
\ \text{at}\ \text{wall}\quad(\text{滑移速度由格式自动给出})
```

```math
% 感受性：扰动增长率（空间增长率）
\alpha(\boldsymbol{k}) = \mathrm{Re}\!\left[
\frac{\partial_{\xi}\,\mathrm{Im}(\omega)}{\partial k_\xi}
\right]
\quad\text{或}\quad
\alpha = -\frac{\mathrm{Im}(\omega)}{\mathrm{Re}(c_{\text{phase}})}
```

```math
% 非 Fourier 热流（动理学热通量）
\boldsymbol{q} = \sum_{\boldsymbol{\xi}}\frac{1}{2}\boldsymbol{\xi}\,m\,\xi_n f\,d\boldsymbol{\xi},
\qquad
\boldsymbol{q}\neq -k\nabla T\ \text{（稀化区）}
```

## 实验与结果

- **算例/数据集**:
  1. **基准 1**：等温壁前驻波（standing acoustic wave）；
  2. **基准 2**：Mach 2 法向激波与斜入射声波相互作用；
  3. **基准 3**：高超声速钝楔的自由来流声学感受性；
  4. **应用**：氩气（argon）钝楔流，等效高度 **40 km** 与 **50 km**。
- **对比基线**: **Navier–Stokes（连续介质）**解 vs **UGKS/CLUGKS（动理学）**解。
- **主要结果**:
  - **三个基准**均通过验证（与解析/参考解一致）。
  - **40 km**：UGKS 与 Navier–Stokes 的**壁面响应（周期与相位）吻合良好**；UGKS 显示**壁面滑移维持下游弱正空间增长率**。
  - **50 km**：稀化强烈 →
    - 出现 **kinetic 温度前驱（temperature precursor）**；
    - **激波层增厚并合并**；
    - **壁压响应仍与 NS 接近**；
    - **温度与热流扰动出现显著偏差**。
  - **核心论断**：中等稀化下连续介质模型能捕捉**主导壁压特征**；更高高度则必须解析激波中的**动理学非平衡（尤其热足迹）**。

## 局限性

- **仅二维/单钝楔构型**：未覆盖多维效应、真实钝体流场、真实大气成分（用**氩气**代替空气）。
- **线性稳定性**：未做非线性演化与转捩预测；感受性只是线性指标。
- **UGKS 本身的限制**：需要网格分辨动理学尺度，在高超声速壁面边界层仍相当昂贵；CLUGKS 的伪时间推进对**低频/近中性模态**可能收敛缓慢。
- **LU-SGS 加速**在强非对称动理学矩阵上效率有限。
- 未与 DSMC 结果做直接交叉验证（摘要未提）。
- **伪时间推进的收敛判据/稳定性**在复数域中的处理细节未展开。

## 实现建议

- **实现难度**: 高 — 需要已有 UGKS 实现（在 OpenCL/CUDA 上并行化良好），本工作主要是线性化层的实现；复数线性化、伪时间推进与 LU-SGS 的耦合是主要工程量。
- **预期性能**: 伪时间推进避免了时间步进线性稳定性分析的巨大成本；相对 DSMC 大幅降低算量；相对 Navier–Stokes 则显著增加。
- **适用场景**:
  - **高超声速/近空间飞行器**的边界层转捩预测；
  - **稀化效应显著**的再入与高超声速舵面气动特性评估；
  - **动理学非平衡**对壁面热流（烧蚀、催化效应）影响的研究；
  - 连续介质模型失效区的**基准参考解**生成。
- **可复用要点**:
  - **"复数线性化 + 伪时间推进"是把频域线性稳定性问题塞进既有稳态求解器框架的通用技巧**——凡是已有稳态 CFD 求解器的地方都可以尝试复用，比实现专门的时域线性稳定性框架省事得多，值得推广到其他动理学/化学动力学格式。
  - **"内蕴 vs 外挂"的判别标准**：本文指出连续介质模型在中稀化时仍能给出主导壁压特征，但在高稀化时温度/热流失真。这是一个**有层次的模型适用性判据**——不要因为动理学更"真实"就一律替换，而应**按观测量选择模型**。
  - **kinetic 温度前驱**可作为**稀化程度的判别信号**：如果计算/实验中在激波内观测到温度先行于密度/压力的信号，说明已进入动理学非平衡区，需要切换模型或提高格式阶数。
  - 该方法与知识库中的 [[2026-11-11-arXiv-2611.14224]]（共形映射去远场任意量）、[[2026-11-11-arXiv-2611.14348]]（守恒写法内蕴 SBT）共同体现了本轮的一个趋势：**把正确的物理结构编入方法本身，而不是事后修正**。
