## 研究问题

Kolmogorov-Arnold Networks (KANs) 以可学习激活函数替代 MLP 固定节点激活，提供更好的可解释性。本工作提出 **PI-KAN** 框架求解黏弹性流体方程的正问题。

## 方法

**Physics-Informed Kolmogorov-Arnold Network (PI-KAN)**:
- 可学习激活函数在边上（而非固定节点激活）
- 损失函数含控制方程残差（NS 类黏弹性方程）

**黏弹性模型**: 广义流体动力学模型 (generalized hydrodynamic model)，在 dusty plasma 领域建立

**基准问题**: Taylor-Green (TG) 流动 + 修正 Taylor-Green 流动

## 参数范围

黏弹性参数 τ_m = 1–20（覆盖宽范围黏弹性效应）

## 系统研究内容

1. **网络架构**对精度和收敛性的影响
2. **超参数**的影响
3. **配置点分布**的影响
4. **随机种子初始化**对训练结果的影响

## 创新点

1. 首个 PI-KAN 求解黏弹性流体方程的工作
2. KAN 的可解释性用于流体物理
3. 系统量化架构/超参数/配置点/随机种子影响
4. 为 KAN 在复杂流体中的应用提供实用指导

## 关键词

KAN, Kolmogorov-Arnold Network, physics-informed, viscoelastic, Taylor-Green, fluid dynamics

## 与 PINN 比较

KAN 优势: 可学习激活函数 → 更好地捕捉非线性映射 → 更高精度和可解释性
