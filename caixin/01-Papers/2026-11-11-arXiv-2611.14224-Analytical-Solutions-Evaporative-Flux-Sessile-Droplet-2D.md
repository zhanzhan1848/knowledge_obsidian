## 核心贡献

> 用**共形映射**给出了**任意接触角**下二维（圆柱帽）蒸发液滴的**蒸发通量显式解析表达式**，并将其与液滴内部的 **Stokes 流**耦合，刻画**三相点**附近的流动；消除了此前工作中"在任意远场距离施加边界条件"这一**人为任意量**。接触角 < 90° 时，二维几何的**幂律发散**与三维（球帽）完全一致。

1. **消除远场任意距离**：以往工作为规避二维 Laplace 问题的**基本解奇异性**（2D 远场 $\ln r$ 发散），被迫在距液滴"任意距离"处施加远场边界条件。本文沿用 Yariv (PRE 107, L063101, 2023) 对细长液滴（零接触角）的思路，**推广到任意接触角**，彻底去掉这个任意量。
2. **任意接触角的蒸发通量显式解**：通过**共形映射**得到显式表达式，并**用数值模拟验证**。
3. **三相点附近的流动分析**：将蒸发通量耦合到液滴内部的 Stokes 流，用**局部分析**刻画三相点（triple point）附近的流动结构。
4. **二维与三维的幂律一致性**：接触角 < 90° 时，二维几何的蒸发通量具有与三维（球帽）**相同的幂律发散形式**，三相点附近的流动也具有**相同的幂律依赖**。
5. **表达式简洁**：蒸发通量与液滴内流动的解**不含任何特殊函数**，为接触线驱动机制提供了清晰的物理解释。

## 技术方案

### 核心思想

蒸发液滴（sessile droplet）的定量分析一直是接触线研究的基础。核心困难在于**二维 Laplace 方程的基本解在远场对数发散**：

- 三维球帽问题中，Laplace 方程的基本解是 $1/r$，在无穷远衰减，因此可以自然地施加"无穷远零通量"边界条件；
- 二维平面问题中，基本解是 $\ln r$，在无穷远**不衰减**——若强加"无穷远零通量"，方程在数学上不自洽。

以往做二维工作时的常见变通是：**在离液滴某个有限距离 $R$ 处施加远场边界条件**。但 $R$ 是**任意的**，引入了一个不可控的建模误差——换个 $R$ 就换一套答案，且难以解释实验中的有限尺寸液滴。

本文的做法是**回到共形映射**：把复杂液滴几何映射到一个简单区域，在映射平面中 Laplace 方程的解是标准形式；再把解**映射回来**，通过选择映射使得远场行为**自动正确**。Yariv (2023) 已对细长（零接触角）液滴完成此工作，本文把结论推广到**任意接触角**——这正是实验中最常见的情形。

随后，把蒸发通量（作为液滴表面的蒸发驱动）耦合到液滴内部的 Stokes 流，用局部幂律分析刻画**三相点**——蒸发的驱动力正是在三相点附近通过蒸发通量的奇异性施加到液体上的，这解释了为什么蒸发液滴会产生接触线运动（Marangoni 驱动的经典机制）。

### 关键技术

| 技术 | 说明 |
|------|------|
| 共形映射 (conformal mapping) | 把液滴几何映射到简单区域，规避 2D Laplace 远场奇异性 |
| 显式解析表达式 | 不含特殊函数，可直接代入工程计算 |
| 任意接触角推广 | 从 Yariv (2023) 的零接触角推广到 $0<\theta<180^\circ$ |
| 蒸发通量–Stokes 流耦合 | 把解析通量作为边界驱动求解液滴内流动 |
| 三相点局部幂律分析 | 刻画接触线附近的流动奇异性结构 |
| 数值模拟验证 | 独立数值解验证解析表达式 |
| 二维/三维幂律一致性检验 | 确认维度效应不改变发散阶数 |

## 公式 / 理论要点

```math
% 蒸汽扩散的 Laplace 方程与边界条件
\nabla^2 c = 0
\quad\text{in}\quad \Omega
```

```math
% 液滴表面：蒸散发散通量（Stefan 条件）
-\boldsymbol{n}\cdot\nabla c = \frac{\dot{m}''}{D_v\,\rho_v}
\quad\text{on}\quad \partial\Omega_{\text{drop}}
```

```math
% 固体基底：不透水
\boldsymbol{n}\cdot\nabla c = 0
\quad\text{on}\quad \partial\Omega_{\text{solid}}
```

```math
% 远场：扩散通量随距离趋于零（无外流时的自然条件）
\boldsymbol{n}\cdot\nabla c \to 0 \quad\text{as}\ r\to\infty
```

```math
% 共形映射（去奇异性）
z = w(\zeta), \qquad
\nabla_z^2 c = 0 \;\Longleftrightarrow\; \nabla_\zeta^2 \tilde c = 0
```

```math
% 三相点附近的幂律发散（θ < 90°，与三维球帽同阶）
\dot{m}''(s) \sim A\,s^{-1/3}\,(1+\mathcal{O}(s)),
\qquad s \to 0^+
```

```math
% 三相点附近的 Stokes 流动幂律
u_i \sim B\,s^{\alpha}\,f_i(\theta_{\text{angle}}),
\qquad \alpha = \tfrac{1}{3}\ \text{（二维与三维同阶）}
```

```math
% 液滴内 Stokes 方程
\nabla\cdot\boldsymbol{\sigma} = 0,
\qquad
\nabla\cdot\boldsymbol{u} = 0,
\qquad
\boldsymbol{\sigma}=-p\boldsymbol{I}+\eta\left(\nabla\boldsymbol{u}+(\nabla\boldsymbol{u})^T\right)
```

## 实验与结果

- **研究对象**: 二维（圆柱帽）几何下的**蒸发驻留液滴**（sessile droplet），任意接触角。
- **对比基线**: (i) Yariv (PRE 107, L063101, 2023) 的零接触角/细长液滴解析解；(ii) 三维球帽几何的经典幂律结果；(iii) 独立的数值模拟验证。
- **主要结果**:
  - **任意接触角的蒸发通量显式表达式**（含共形映射推导），经数值模拟验证。
  - **去除远场任意距离**：无需在有限距离 $R$ 施加远场条件，规避了人为误差。
  - **接触角 < 90° 时**：二维圆柱帽的蒸发通量幂律发散**与三维球帽一致**（同为 $\sim s^{-1/3}$ 型），三相点附近的流动幂律依赖**亦一致**。
  - **接触角 ≥ 90°**：行为与 < 90° 不同（发散结构改变），隐含在任意接触角通式中。
  - **解的形式简洁**：不含特殊函数 → 可作为**教学级/工程级**的闭式模型直接使用。

---

## 局限性

- **二维近似**：真实液滴是三维的。二维幂律发散与三维同阶是重要结论，但**积分通量本身**仍与三维不同（二维结果不能直接当作三维实验值使用）。
- **无接触角滞后 (contact-angle hysteresis)**：真实的接触线有滞后，导致蒸发通量与接触角解耦，理想模型的接触线移动速率预测会偏离实验。
- **未包含**蒸发冷却导致的**温度场**、以及由温度梯度驱动的**Marangoni 应力**——而三相点附近的流动恰恰会被 Marangoni 显著改变。
- 假设**纯扩散**传质，忽略自然对流（真实蒸发液滴上方存在热羽流，会强化传质）。
- 假设**静态接触角**，未讨论接触线运动中的动力学（即使不滞后，动态接触角依赖 $\mathrm{Ca}$ 数）。

## 实现建议

- **实现难度**: 低 — 闭式表达式，可直接编码；数值验证可用任何常规有限元/有限体积求解 Laplace 方程。
- **预期性能**: 解析式为 O(1) 计算，可嵌入任意多相流求解器作为界面解析模型。
- **适用场景**:
  - **蒸发冷却/喷雾蒸发**的界面传质建模；
  - **印刷涂布、咖啡渍、蒸发自组装**的斑图预测；
  - 蒸发驱动**自组装/结晶**中的通量场；
  - 作为多相流求解器的**解析基准**（benchmark）来校验数值界面传质算法。
- **可复用要点**:
  - **"人为远场边界"是一个隐蔽的误差源**——本文的教训是：当问题的基本解不满足朴素的无穷远条件时，正确做法是**改变几何表示（共形映射）**而非**在有限距离截断**。这一原则可推广到任何 2D 奇异问题。
  - **维数对比是廉价而有力的检验**：把 2D 与 3D 的奇异结构对比（指数是否一致）可以在没有实验的情况下判断降维模型的适用边界。
  - **显式解作为基准 (benchmark)**：这类闭式解非常适合用来验证数值求解器的界面处理精度，建议纳入知识库"解析基准"目录。
  - 若要做更真实的预测，下一步的自然扩展是加入 **Marangoni 应力**与**蒸发冷却温度场**，二者都会改变三相点附近的流动（进而改变蒸发通量），是一个有明确切入点的课题。
