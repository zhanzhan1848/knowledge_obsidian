## 核心贡献

> 一句话总结这篇论文的核心创新点：证明了二维周期通道中无粘 Boussinesq 方程的定常解必为"层状剪切流（stratified shear flow）"，并揭示了密度单调性方向这一关键结构——与 Euler 方程形成鲜明对比，Boussinesq 方程允许存在层流、非定常、非剪切型的定常解。

1. **定常解的完全分类**：证明无粘二维 Boussinesq 方程在周期通道中的定常层流速度场（对应**闭合的不可压缩流线**）与**非减密度分层**耦合时，必然构成层状剪切流（stratified shear flow）。
2. **密度单调性方向的基础性作用**：明确指出密度沿等值线单调递增/递减的方向是本质性的结构约束，而非可忽略的技术条件。这一方向性区分了 Boussinesq 与 Euler 的行为。
3. **与 Euler 方程的对比性结果**：与 Euler 方程情形形成鲜明对照——论文构造出了 Boussinesq 方程中**层流的、非定常的（non-stagnant）、非剪切型**的定常解，这类解在 Euler 方程框架下不存在。
4. **灵活性与刚性定理（flexibility & rigidity）**：在层状剪切流附近，论文给出两类结论——根据定常解**驻点（stagnation points）**的分布，可以判定该解是"层流持续存在（laminar persistence）"还是"邻近非剪切解的出现（appearance of islands）"。这本质上是解空间结构随小参数变化的分岔刻画。
5. **统一的 Crandall-Rabinowitz 简单分岔定理**：作为副产品建立了**一致的（uniform）Crandall-Rabinowitz 分岔定理**，作者认为其本身具有独立价值。

## 技术方案

### 核心思想

**Boussinesq 方程（密度变量形式）**：在 Boussinesq 近似下（密度变化只进入浮力项，粘性系数视为常数），二维无粘 Boussinesq 方程为

$$\partial_t \boldsymbol{u} + (\boldsymbol{u}\cdot\nabla)\boldsymbol{u} = -\nabla p + e_2 \rho, \qquad \nabla\cdot\boldsymbol{u} = 0$$
$$\partial_t \rho + \boldsymbol{u}\cdot\nabla\rho = 0$$

（无粘版本不含耗散项；有粘版本含 $\nu \Delta\boldsymbol{u}$。）

**"层状剪切流"的含义**：定常解中速度场为单值流函数 $\psi(x_2)$，只依赖横向坐标 $x_2$，密度为 $\rho(x_2)$ 也只依赖 $x_2$：

$$\boldsymbol{u} = (u_1(x_2), 0), \qquad \rho = \rho(x_2)$$

此时流线是**平行直线**，不闭合；而论文研究的定常解是**闭合的不可压缩流线**（non-contractible / closed fluid trajectories），即流体做绕环流，密度沿闭合轨道被输运。

**核心矛盾**：在一个闭合轨道上，密度 $\rho$ 被物质守恒输运（沿轨道循环），但稳定定常又要求密度场不随时间变化。若密度沿轨道单调（非减），则绕行一周后密度必须一致，迫使单调性在轨道上退化为常数——这正是"非减密度分层"这一条件的作用机制。

**与 Euler 的区别**：Euler 方程中定常解有更强的刚性（Kelvin 定理族、压强常值条件等），导致层流非剪切定常解几乎不可能；Boussinesq 中浮力项 $\rho e_2$ 提供了额外的压力梯度自由度，使得**非剪切层流定常解存在**。

**"驻点"的作用**：在层状剪切流附近，$\psi(x_2)$ 的极值点（即驻点/临界点）是分岔的"种子"——驻点的性质（数目、类型、位置）决定邻近解是否从这些点"生长"出非剪切解（islands），即刚性 vs 灵活性的判据。

**Crandall-Rabinowitz 定理的统一性**：CR 定理是简单特征值分岔的标准工具。论文将其推广到统一的（uniform）版本，使得在 Boussinesq 定常解族附近，可以系统地追踪分岔曲线。

## 公式

以下为**方法本质形式**（Boussinesq 方程的标准控制方程与本文分析所依赖的结构性关系，不伪造原文的具体常数或误差估计）：

二维无粘 Boussinesq 方程（本质形式）：

```math
\partial_t \boldsymbol{u} + (\boldsymbol{u}\cdot\nabla)\boldsymbol{u} = -\nabla p + \rho\, e_2,
\qquad \nabla\cdot\boldsymbol{u} = 0,
\qquad \partial_t \rho + \boldsymbol{u}\cdot\nabla\rho = 0
```

流函数表示（无散约束自动满足）：

```math
\boldsymbol{u} = \nabla^\perp \psi = (\partial_2\psi,\,-\partial_1\psi),
\qquad \Delta \psi = \omega
```

定常层状剪切流（结论性结构）：

```math
\psi = \psi(x_2), \qquad \rho = \rho(x_2), \qquad
u_1 = u_1(x_2) = -\,\psi'(x_2), \qquad u_2 = 0
```

其中 $\rho(x_2)$ 沿 $x_2$ **非减**（密度单调性方向条件）。

定常性条件（密度在闭合轨道上的相容性，本质形式）：

```math
\boldsymbol{u}\cdot\nabla\rho = 0
\quad\text{且}\quad
\rho \text{ 沿闭合轨道非减}
\;\Longrightarrow\;
\rho|_{\text{orbit}} \equiv \text{const}
```

功能/能量关系（Boussinesq 的位能耗散形式）：

```math
\frac{d}{dt}\int \rho\, z\,dx = -\int \rho\, u_2\,dx = 0
\quad (\text{周期通道中 } \int \rho u_2 dx \text{ 为准恒量/约束})
```

（无粘 Boussinesq 的位能 $\int \rho z$ 在无外力做功下守恒；密度的非线性分布由此受约束。）

Crandall-Rabinowitz 分岔（统一版本，本质形式）：

```math
\text{若 } F(u,\lambda) = 0, \quad
F_u(u_0,\lambda_0)\, \varphi = 0 \text{（一维核）},\quad
\operatorname{Range}(F_u) \text{ 闭},
\]
\[
\text{则存在 }\ \gamma \neq 0 \text{ 与连续分支 } (\lambda(s), u(s)),\quad
u(s) = u_0 + s\varphi + O(s^2)
```

本文的"uniform"性体现在：核空间的生成元 $\varphi$ 与余核条件 $\langle \psi, F_\lambda\rangle \neq 0$ 的估计在所考察的参数范围内一致成立。

# 分岔与存在性的数值探查（方法层面伪代码）
def classify_steady_boussinesq(u, rho, domain, tol=1e-10):
    """
    u    : 速度场 (2, Nx, Ny)
    rho  : 密度场 (Nx, Ny)
    检查定常解是否满足：闭合轨道 + 非减密度分层 => 层状剪切流
    """
    # 1) 提取流函数与涡量
    psi = streamfunction(u)
    omega = laplacian(psi)

    # 2) 拓扑检查：流线闭合性（非契约性流线数）
    n_closed = count_closed_orbits(psi, domain)

    # 3) 沿每条闭合轨道检查密度单调性方向
    for orbit in closed_orbits(psi, domain):
        s = arclength_param(orbit)
        rho_along = rho_on_curve(orbit)
        d = gradient(rho_along, s)
        mono = all(d >= -tol) or all(d <= tol)
        if not mono:
            return {"type": "excluded", "orbit": orbit, "monotonicity": "none"}

    # 4) 若所有闭合轨道密度单调，则定常解必为分层剪切流
    if n_closed > 0:
        # 分层剪切流判定：u1 仅为 x2 的函数，rho 亦仅为 x2 的函数
        is_shear = test_functional_dependence(u, rho, axis="x2", tol=tol)
        assert is_shear, "violates stratified-shear classification"
        return {"type": "stratified_shear", "stagnation_points": find_stagnation(psi)}
```

# Crandall-Rabinowitz 分岔的数值追踪
def trace_cr_bifurcation(F, u0, lam0, lambda_range, n_steps=50):
    """
    F(u, lam) = 0 残差算子（离散流函数-密度定常方程）
    返回分岔曲线 (lam(s), u(s)) 与刚性/灵活性判据
    """
    # 线性化：计算 F_u 的核（一维）
    A = linearize(F, u0, lam0)
    phi, sigma = eig_one_smallest(A)
    assert abs(sigma) < 1e-8, "kernel not one-dimensional"

    # 分岔方向与步长参数 s
    gamma = inner(phi, F_lambda(F, u0, lam0))     # 非退化性条件
    assert abs(gamma) > 1e-12

    branch = []
    for s in np.linspace(-0.1, 0.1, n_steps):
        lam = lam0 + s**2 * lam2 + ...            # 二次分岔的抛物线参数化
        u = solve_newton(F, u0 + s*phi, lam)      # 牛顿法解修正方程
        branch.append((lam, u))
    return branch
```

## 实验结论

- **数据集/算例**: 本论文为**解析数学工作**，无实验数据集；共 3 幅图（应为定常解结构、驻点配置与分岔分支的示意图）。
- **基线**: 对比基线为 **Euler 方程**的定常解结构理论（Kelvin 环流定理族、压强函数条件等）；以及经典的分层剪切流（stratified shear flow）理论。
- **结果**:
  1. **分类定理**：二维周期通道中，定常层流速度场（闭合不可压缩流线）+ 非减密度分层 ⟹ **必为分层剪切流**；
  2. **密度单调性方向是本质性的**：单调性方向（递增 vs 递减）不是技术性限制，而是决定解存在性的核心结构；
  3. **与 Euler 的对比**：与 Euler 方程截然不同，Boussinesq 中**存在**层流、非定常（non-stagnant）、非剪切型的定常解；
  4. **灵活性/刚性判据**：在分层剪切流附近，按驻点（stagnation points）分布可判定——层流解持续存在（laminar persistence）或出现邻近的非剪切解（appearance of islands）；
  5. **副产品**：建立了**一致的（uniform）Crandall-Rabinowitz 分岔定理**，可能具有独立的数学价值。

## 局限性

- **限于二维**：所有分类结果建立在二维无粘 Boussinesq 上。三维情形下闭合流线的拓扑（Knot 类问题）、密度分层的退化机制都需要重新处理，结论不能直接外推。
- **无粘假设**：论文研究的是 inviscid 方程。粘性项引入后，密度不再严格沿轨道守恒输运，整个"闭合轨道 + 单调性"的分类机制需要重新论证；而有粘 Boussinesq 才是分层对流/混合的物理模型。
- **Boussinesq 近似的适用范围**：忽略密度变化对惯性项的影响，仅在密度涨落远小于参考密度时成立；强分层（大 Rayleigh 数、显著温度差）下需回到完整的 Boussinesq–Oberbeck 或可压缩形式。
- **未量化**：摘要与图注信息（3 图）不足以评估解空间的几何结构的具体刻画深度；关于"islands"的出现条件仅给出了按驻点分类的定性框架。
- **未涉及稳定性**：定常解的存在性不蕴含稳定性；论文未讨论这些定常解（尤其非剪切层流解）的稳定性/Lyapunov 或非线性稳定性，这对流体力学应用至关重要。
- **分岔定理的统一性**：uniform CR 定理的适用参数范围、误差估计的显式常数未在摘要中体现，复现需要完整正文（63 页）。
- 通道几何为周期性条带；非周期、有侧壁或变形的通道几何不在讨论范围内。

## 实现建议

- **实现难度**: 高（理论层面）。需要掌握：功能分析、椭圆型 PDE 理论、分岔理论（CR 定理及其推广）、拓扑流线分析。
- **预期性能**: 结论为**定性/结构性**的（存在性、分类、刚性-灵活性判据），不直接给出可量化的误差精度或计算加速。
- **适用场景**:
  - 大气/海洋分层流动中**定常**环流结构的理论刻画（如地转流、准地转平衡的非定常解）；
  - 分层对流不稳定（Rayleigh–Taylor、convective instability）分析的基础；
  - 非定常 Boussinesq 数值模拟中**定常解作为初值/参考解**的选取依据；
  - 数值求解器中检验"解是否应趋于某个分层剪切流"作为收敛性判据。
- **技术路线**:
  1. 若目标是**数值层面**利用本文结论：把"分层剪切流"作为大涡/尺度分离模拟的低阶基底（span），在分层流问题中先求解 $\psi=\psi(x_2)$、$\rho=\rho(x_2)$ 的一维平衡态作为初值与参考，可显著加速收敛并避免混沌解；
  2. 定常求解器：采用流函数-涡量-压力三分量格式的**伪时间推进 + 分块（overset）网格**处理周期通道；平衡态求解可做一维直接积分（若含非线性项需 Newton 迭代）；
  3. 驻点检测是工程上可直接落地的一步：对定常 $\psi$ 场做 Morse 理论式的临界点提取（数量、指标、退化类型），作为"该解附近是否存在分岔分支"的判据，可用于自动化流场分类（如判断数值解是否处于"层流持续"区）；
  4. 检验"闭合轨道 + 单调密度"是否为**数值解**的固有性质（而非精确解）：这本身是一个很好的**网格收敛性/数值耗散诊断器**——若数值解在细网格上满足该结构而在粗网格上不满足，说明数值耗散破坏了真实的定常结构；
  5. 分岔追踪：对数值解做参数延拓（continuation）时，可用 CR 线性化作为牛顿-延拓的初值预测器，加速参数扫掠。
- **风险提示**: 直接把"定常解必为分层剪切流"当作数值模拟的强约束会过度简化；本文只针对**无粘、定常、层流**情形，有粘与湍流情形需另行论证。
