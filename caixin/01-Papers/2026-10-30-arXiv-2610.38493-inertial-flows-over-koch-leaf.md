## 核心贡献

> **在单一 Koch 叶形空腔通道中首次系统性地隔离出"多孔介质惯性感"，并指出惯性使能量向主流集中、回流区反而扩大，同时建立了表观渗透率与迂曲度的幂律关系。**

1. **单通道作为可控多孔介质**：孔隙率极高（$\varphi \approx 1$）的 Koch 叶（level-6）空腔通道，兼具有序性、可重复性与代表性，同时具备复杂多尺度结构与非平凡的水动力相互作用——相当于一个"极稀疏多孔介质"的天然模型。
2. **摩擦因子分析**：通过与 Darcy 定律的偏离量度量非线性惯性效应，发现该偏离**极其微妙**（即使在惯性区也很小），说明 Darcy 型线性化在单通道尺度上依然高度有效。
3. **流动结构的惯性重排**：**participation number $\pi$ 随 $Re$ 降低**（动能向主流集中），**回流占比 $\varphi^-$ 随 $Re$ 升高**（叶形空腔内滞留区扩大）——与无序多孔介质的定性行为相反。
4. **迂曲度非单调变化，表观渗透率下降**；在惯性区二者满足幂律关系，**指数与天然岩石中观测到的量级相当**。
5. **局部动能分布**：在最低与最高 $Re$ 两端，局部动能均服从幂律分布 $P(\varepsilon)\propto\varepsilon^{-m}$，跨越数个数量级且**指数相同**（$m\approx 0.83$）——惯性只改变分布的**尾部**，不改变标度结构。

## 技术方案

### 核心思想

多孔介质中"惯性修正 Darcy 定律"是一个经典问题，但真实多孔介质（岩石、土壤）的孔隙几何高度随机，难以把几何无序性与惯性效应分离。本文的策略是**用一个几何完全可控、且高度自相似的单通道**（Koch 叶空腔）替代随机多孔介质，从而：

- 用 $Re$ 作为**唯一的惯性强度控制参数**；
- 用 Koch 叶的**分形自相似性**把"通道尺度"与"分形层级"解耦，从而可做尺度律推广。

Koch 叶 level-6 被选中正是因为它同时满足：规则性（可重复）、代表性（多尺度 + 非平凡相互作用）、复杂度足够。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Koch 叶（level-6）空腔几何** | 分形自相似边界，级数可调；孔隙率 $\varphi\approx1$ |
| **Darcy 定律偏离分析（friction factor）** | 以摩擦因子相对 Darcy 标度的偏移量化非线性（惯性）效应 |
| **Participation number $\pi$** | 动能参与度指标，度量流动"通道化"程度 |
| **回流占比 $\varphi^-$** | 反向流体积分数，量化滞留/回流区占比 |
| **迂曲度（tortuosity）vs $Re$** | 几何+动力学迂曲度演化，非单调 |
| **表观渗透率 $k_{app}$ vs $Re$** | 惯性区的Darcy偏离，指数幂律 |
| **局部动能幂律分布 $P(\varepsilon)\propto\varepsilon^{-m}$** | 跨 $Re$ 不变的标度指数，$m\approx0.83$ |
| **Lattice Boltzmann / 谱元直接数值模拟（隐含）** | 处理分形边界与高 $Re$ 下的大规模通道——需无滑移壁面处理与足够的网格分辨率 |

## 公式

```math
\text{Darcy 标度（惯性为零时的基准）:}\quad
\frac{\Delta p}{L} = \frac{\mu}{k}\, U,
\qquad \text{偏离量}\;\delta_f \sim \mathcal{O}\!\left(Re_\text{loc}\right)
```

```math
\text{惯性区渗透率–迂曲度幂律（本文核心定性关系）:}\quad
k_{app}(Re) \propto \tau(Re)^{\,\beta},
\qquad \beta \sim \text{天然岩石中观测到的指数量级}
```

```math
\text{局部动能标度律:}\quad
P(\varepsilon)\ \propto\ \varepsilon^{-m},
\qquad m \approx 0.83
\quad\text{（$Re$ 最高与最低端一致，惯性仅改变尾部）}
```

> 注：以上为方法层面的本质形式（判据/标度关系）；原文未给出可复制的精确闭合系数或数值。

## 代码片段

```text
# 计算流程（概念性伪代码）
# 1) 几何：Koch 叶 level-6 空腔通道
cavity = koch_leaf(level=6)              # 分形边界点集
domain = channel_with_cavity(cavity)

# 2) 网格：对分形壁面做局部加密（壁面分辨率须 ≥ 分形最小尺度）
mesh = fractal_wall_refined_mesh(domain, wall_res=1e-3)

# 3) 求解：扫掠 Re
for Re in [Re_lo ... Re_hi]:
    u, p = solve_steady_ns(mesh, Re=Re, nu=1.0)   # LBM 亦可

    # 4) 惯性指标
    f_fric  = friction_factor(u, p)               # 与 Darcy 标度的偏离
    pi      = participation_number(u)             # 动能参与度
    phi_minus = backward_flow_fraction(u)         # 回流占比
    tau     = tortuosity(u)                       # 迂曲度
    k_app   = apparent_permeability(u, p, dPdx)

    # 5) 局部动能统计
    eps = 0.5 * |u|^2
    m, C = powerlaw_fit(P_eps, eps, range="tail")   # 期望 m ≈ 0.83
```

## 实验结论

- **数据集/算例**：Koch 叶 level-6 空腔通道流动，扫掠 Reynolds 数（最低端与最高端对比），孔隙率 $\varphi\approx1$。
- **基线**：Darcy 定律（线性渗流标度）；天然岩石中迂曲度–渗透率幂律指数的经验关系；无序多孔介质的惯性行为作为定性对照。
- **结果**：
  - 摩擦因子相对 Darcy 定律的偏离**非常微妙**（惯性非线性在小通道中不显著）。
  - $\pi$ 随 $Re$ **下降**（动能集中于主流）；回流占比 $\varphi^-$ 随 $Re$ **上升**（叶形空腔内滞留扩大）——与无序多孔介质相反。
  - 迂曲度随 $Re$ **非单调**；表观渗透率**下降**。
  - 惯性区 $k_{app}$ 与 $\tau$ 满足幂律，指数与天然岩石**量级相当**。
  - 局部动能幂律 $P(\varepsilon)\propto\varepsilon^{-m}$，$m\approx0.83$，在 $Re$ 两端**指数相同**，惯性只改尾部。

---

## 局限性

- **单一几何族**：仅 Koch 叶一种分形，结论向真实随机多孔介质的外推需谨慎（作者自己也定位为"极稀疏多孔介质"研究）。
- 孔隙率接近 1，与真实岩石/土壤（$\varphi \ll 1$）差别大，惯性起始的 $Re_c$ 判据不同。
- 只关注宏观输运指标（$\pi$、$\varphi^-$、$\tau$、$k_{app}$），对**局部瞬态结构**（如二次流、涡脱落）刻画有限。
- 未涉及**多相流/可压缩性/壁面粗糙度**等实际复杂因素。
- 侧壁与壁面边界条件的实现（尤其分形壁面的分辨率收敛性）细节未在摘要中说明。

## 实现建议

- **实现难度**：🟡 中等。几何生成分形边界容易，难点在**分形壁面网格质量**与**无滑移壁面处理**（ALE/浸没边界/格点壁面函数），以及稳态收敛性的把控。
- **预期性能**：level-6 Koch 叶在 $Re$ 较低时可接受，惯性区需高分辨率 + 高效求解器（GPU LBM 或 PETSc 谱元）；统计量 $\pi$、$\varphi^-$、$k_{app}$ 需逐场积分，成本中等。
- **适用场景**：
  - **多孔介质湍流/惯性修正**的基准算例（几何完全可控）；
  - 催化剂填料、芯片微通道、过滤介质等**规则化多孔结构**的输运建模；
  - **尺度律推广**：分形级数 $n$ 变化 → 研究通道尺度与分形层级对 $Re_c$ 的影响。
- **落地建议**：推荐作为**验证/基准算例**收录进知识库——它为"何时可以放心用 Darcy 定律"提供了一个判据：即便存在强分形壁面，单通道中惯性偏离仍很微弱，可支撑工程中 Darcy 近似的使用边界。
