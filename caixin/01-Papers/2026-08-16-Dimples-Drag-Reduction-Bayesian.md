# 基于贝叶斯优化和地形探索的凹坑减阻研究

- **arXiv**: [2608.12826](https://arxiv.org/abs/2608.12826)
- **日期**: 2026-08-13
- **作者**: Sangjoon Lee
- **期刊**: physics.flu-dyn
- **关键词**: #LES #凹坑减阻 #贝叶斯优化 #MixMOBO

## 研究问题
凹坑 (dimples) 可减阻，但浅凹坑的净效益**敏感依赖于形貌**，需系统探索设计空间。

## 方法
- **优化框架**: MixMOBO (混合变量贝叶斯优化器)
- **CFD**: 浸入边界 LES (通道流, Re_τ = 180)
- **设计变量**: 4 变量混合空间
  - 凹坑类型
  - 深度
  - 面内尺度
  - 流向拉伸

## 最优设计
| 参数 | 最优值 |
|------|-------|
| 类型 | 菱形 |
| 深度 | 相对较深 |
| 覆盖率 | 完全填充 |
| 流向拉伸 | 纵向拉伸 |
| **减阻效果** | **13.2%** (优于先前报道) |

## 敏感性分析 (高斯过程代理模型)
- **拓扑类型** → **主导因素**
- 覆盖率、拉伸 → 主要通过交互作用影响
- 深度本身 → 无普适符号

## 近壁流动分析
- **优良设计**: 沟壑式完全附壁流动
- **较差设计**: 局部流动分离 → 形状阻力增加

## 🥢 可行性分析：凹坑形貌贝叶斯优化

## 控制方程
- 通道湍流 LES (浸入边界)
- 常流量条件

## 数值方法
- **LES**: 亚格子模型
- **浸入边界**: 复杂几何
- **优化**: MixMOBO (混合变量)

## 计算成本
- LES Re_τ=180 → 适度规模
- 贝叶斯优化需多次迭代评估
- 总体计算量大，建议使用 HPC

## 推荐结论
✅ **推荐实现**

### 理由
1. **13.2% 减阻** → 工程价值显著
2. 系统性方法论可推广至其他粗糙元
3. 敏感性分析揭示设计准则

### 实现路径
1. 建立凹坑参数化几何
2. 实施浸入边界 LES
3. 集成 MixMOBO 或类似贝叶斯优化器
4. 挖掘设计空间 → 验证最优解
