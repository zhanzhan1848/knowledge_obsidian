## 核心贡献

> **分层贝叶斯模型**汇聚多组测量，但若**前向模型置于似然中**，**每次后验评估都要为每个 cell 付一次前向求解**。本文引入一个**基于模拟的推断 (simulation-based inference)** 框架：**训练一次**的**三角传输映射似然 (triangular transport-map likelihood)** **服务所有 cell**。应用于**从薄膜中稳定孔洞的照片反演润湿性质 (wetting properties)**：孔洞半径通过**非线性 Young–Laplace 方程**依赖于**接触角**与**毛细长度**；单张照片只给出**秩一 (rank-one)** 信息，故在**分层模型**中汇聚多张（每个 cell = 一种体积设置下的基底，共享装置几何与噪声尺度）。在**合成验证设计**上，映射后验与**直接采样前向模型**在润湿性质上一致；**在该设计下映射比"无梯度系综采样器 + 直接采样"少用数百倍前向评估**，在 **200 个后验的标定研究**中少用**约五个数量级**。**基于模拟的校准 (SBC)** 检测显示**无任何参数偏离**。**离线训练**后，摊销映射能把**新照片直接变成后验，无需前向求解**——这是**原位测量润湿性质而不扰动液体**的重大一步。

1. **问题**: 分层贝叶斯模型中，若似然中含前向模型，则**每次后验评估 = 每个 cell 一次前向求解** → 成本随 cell 数与迭代数**相乘**，不可接受。
2. **方法**: **基于模拟的推断 (SBI)** 框架 + **三角传输映射似然 (triangular transport-map likelihood)**，**每个设计只训练一次**，**服务所有 cell**。
3. **应用案例——润湿性质反演**:
   - **物理**: 薄膜中**稳定孔洞 (stable hole)** 的半径通过**非线性 Young–Laplace 方程**依赖于**接触角 (contact angle)** 与**毛细长度 (capillary length)**；
   - **信息结构**: **一张照片只给出秩一信息**（只约束一个组合），因此必须**汇聚多张**；
   - **分层模型**: 每个 **cell = 一种体积设置下的基底**，**共享**装置几何与**噪声尺度**；
   - **设计 (design)** 固定：基底数量、体积设置、每 cell 的照片数。
4. **验证结果**:
   - 映射后验与**直接采样前向模型**在**合成验证设计**上的润湿性质一致；
   - 在**更大的合成标定设计**上一致性**较差**（诚实的负面结果）；
   - **SBC 检测在验证设计上显示无任何参数偏离**。
5. **成本收益（核心卖点）**:
   - 验证设计下：**数百倍**更少的前向模型评估（对单个后验）；
   - **200 个后验的标定研究**：**约五个数量级**更少；
   - **离线训练**后，**新照片 → 后验，零前向求解**。
6. **应用意义**: 向**原位测量润湿性质而不扰动液体**迈出重大一步。

## 技术方案

### 核心思想

**分层贝叶斯反问题的成本困境**

**分层模型 (hierarchical model)** 的结构：
- **观测单元 (cell)** $i$：一组特定条件下的数据（如一种体积设置下的基底 + 其照片）
- **群级参数 (group-level)**：所有 cell 共享的参数（装置几何、噪声尺度）
- **单元级参数**：每个 cell 自己的参数（该基底的接触角、毛细长度）

用**贝叶斯**方法反演时：
$$\pi(\theta_1,\dots\theta_C, \psi)\propto \prod_{i=1}^{C}\pi(y_i\mid\theta_i)\,\pi(\theta_i\mid\psi)\,\pi(\psi)$$
每个 $\pi(y_i\mid\theta_i)$ 都含**前向模型** $\mathcal{F}^{-1}$（给定参数产生观测）。

**成本灾难**：一次后验评估需要 $C$ 次前向求解。NUTS 等采样器需要 $10^3$–$10^5$ 次评估，**总成本 $C\times10^3$–$10^5$**。标定研究（如 200 个后验）更糟。

**解法：摊销似然 (amortized likelihood)**

**核心思想**：**把"前向求解 + 似然评估"这两步合并成一个可离线训练的映射**。

**三角传输映射 (triangular transport map)**：
- 目标：构造一个**可逆 (invertible)、三角 (triangular)** 的变换 $T$，把**先验分布** $p(\boldsymbol{\theta})$ 变为**后验分布** $p(\boldsymbol{\theta}\mid\boldsymbol{y})$；
- **三角结构**保证可**逐维、逐步**（sequential）求逆 → 只需 $C$ 次一维/低维变换，而非 $C$ 维联合变换；
- **训练方式**：用**基于模拟的推断 (SBI)** —— 生成大量 (参数, 观测) 样本对，让神经网络学习 $T$；
- **关键**: 训练是**离线**的、**一次性的**；**推理时零前向求解**。

**为什么是"训练一次，服务所有 cell"？**

因为分层模型的结构：**群级参数相同** → 似然的**函数形式相同** → 传输映射的**结构相同**。训练时把 cell 索引（或群级参数）作为**条件输入**，训练一个**条件传输映射**：
$$T(\boldsymbol{\theta};\,\text{cell context}) \;\longrightarrow\; \text{变换后的样本}$$

这样同一个模型服务所有 cell，**摊销了训练成本**。

**秩一信息与分层结构的巧妙匹配**

这是本文最漂亮的一点：

> **单张照片只给出接触角与毛细长度的某个组合（秩一）的信息。**

这正是分层模型的用武之地：每个 cell 提供一个**方向**（秩一约束），多个 cell 的约束合起来**张成整个二维参数空间**。

- **群级参数共享**（装置几何）→ 各个 cell 的约束方向**相关但不完全相同** → 联合起来才有足够的秩；
- **设计 (design)** 的作用：固定基底数量、体积设置、每 cell 照片数 → 设计直接决定**后验的紧致程度**。

**这个结构的教学价值**：它展示了**"信息结构（秩）"如何决定实验设计**——不是"多拍照"，而是"**从多少个不同方向拍**"。

### 关键技术

| 技术 | 说明 |
|------|------|
| 三角传输映射 (triangular transport map) | 可逆三角变换，逐维求逆 |
| 基于模拟的推断 (SBI) | 用 (参数, 观测) 样本对训练映射 |
| 摊销似然 (amortized likelihood) | 训练一次，推理时零前向求解 |
| 条件传输映射 | 以 cell 上下文为条件，服务所有 cell |
| 分层贝叶斯模型 | 群级 + 单元级参数 |
| Young–Laplace 方程 | 连接接触角/毛细长度与孔洞半径 |
| 秩一信息结构 | 单张观测只给一个方向 |
| 基于模拟的校准 (SBC) | 检验后验是否正确（无参数偏离） |
| Matheron 路径式采样 | 生成联合轨迹样本 |
| 合成验证设计 / 标定设计 | 两级评估：单设计验证 + 200 后验标定 |

## 公式 / 理论要点

```math
% Young-Laplace 方程：薄膜中稳定孔洞的半径
\Delta p = \frac{2\gamma\cos\theta}{R}
\quad\Longrightarrow\quad
R = f(\theta,\;\ell_c),\qquad
\ell_c = \sqrt{\frac{\gamma}{\rho g}}
\quad(\text{毛细长度})
```

```math
% 单张观测的秩一信息结构
\boldsymbol{y} = h(\boldsymbol{\theta}) + \boldsymbol{\epsilon},
\qquad
\boldsymbol{h}:\mathbb{R}^2\to\mathbb{R}^{1}
\quad\Longrightarrow\quad
\operatorname{rank}\frac{\partial h}{\partial\boldsymbol{\theta}} = 1
```

```math
% 分层贝叶斯模型（成本困境的形式化）
\pi(\boldsymbol{\theta}_{1:C},\boldsymbol{\psi})
\propto \prod_{i=1}^{C}
\underbrace{\pi(\boldsymbol{y}_i\mid\boldsymbol{\theta}_i)}_{\text{每次评估 } C \text{ 次前向求解}}
\cdot \pi(\boldsymbol{\theta}_i\mid\boldsymbol{\psi})\,\pi(\boldsymbol{\psi})
```

```math
% 三角传输映射（可逆 + 三角）
\boldsymbol{z} = T(\boldsymbol{\theta};\,\boldsymbol{c}),
\qquad
T = T_N\circ\cdots\circ T_1,
\qquad
T_k \text{ 依赖 } (\theta_1,\dots,\theta_k)
\quad\Longrightarrow\quad
\text{逐维求逆}
```

```math
% 摊销似然：先验 → 后验的映射
p_{\text{post}}(\boldsymbol{\theta}\mid\boldsymbol{y},\boldsymbol{c})
= \left|\det \frac{\partial T^{-1}}{\partial\boldsymbol{\theta}}\right|
\cdot p_{\text{prior}}(T^{-1}(\boldsymbol{z};\boldsymbol{c}))
$$

```math
% 成本收益（本轮核心数字）
\text{单个后验}:\quad
\frac{N_{\text{forward}}^{\text{SBI}}}{N_{\text{forward}}^{\text{direct}}}
\sim 10^{2}\!-\!10^{3},
\qquad
\text{200 后验标定}:\quad
\frac{N_{\text{forward}}^{\text{SBI}}}{N_{\text{forward}}^{\text{direct}}}
\sim 10^{5}
```

```math
% 基于模拟的校准（SBC）检验
\text{SBC rank 统计量：}
\boldsymbol{r}(\boldsymbol{\theta}^{(m)}) = \sum_j
\mathbb{1}\!\left[\theta_j^{(m)} < \theta_j^{\text{draw}}\right]
\quad\stackrel{H_0}{\sim}\ \text{Uniform}
```

## 实验与结果

- **框架**: SBI + 三角传输映射似然，**每设计训练一次**，**服务所有 cell**。
- **应用**: 从**薄膜中稳定孔洞的照片**反演**润湿性质**（接触角 + 毛细长度）。
- **物理关系**: 孔洞半径经**非线性 Young–Laplace 方程**依赖于接触角与毛细长度。
- **信息结构**: 单张照片 = **秩一**信息 → 分层模型汇聚（cell = 体积设置下的基底，共享装置几何与噪声尺度）。
- **验证结果**:
  - **合成验证设计**：映射后验与**直接采样前向模型**在润湿性质上**一致**；
  - **更大的合成标定设计**：一致性**较差**（**诚实的负面结果**）；
  - **SBC 检测**：在验证设计上**无任何参数偏离** → 后验**校准正确**。
- **成本结果**:
  - **验证设计**：单个后验比"直接采样 + 无梯度系综采样器"**少数百倍**前向评估；
  - **200 后验的标定研究**：**少约五个数量级**；
  - **离线训练后**：新照片 → 后验，**无前向求解**。
- **意义**: 向**原位测量润湿性质而不扰动液体**迈出重大一步。

## 局限性

- **"更大的标定设计上一致性较差"** 是作者**主动报告的负面结果**（值得称道的诚实度）。这说明传输映射的**外推能力有限**——训练设计覆盖不足时精度下降。摘要未给出差距的量级。
- **摊销似然的适用性依赖"设计固定"**：一旦实验条件改变（不同基底数、不同体积设置范围），**需要重新训练**。这是"离线训练"路线的固有代价。
- **传输映射的高维困难**：虽然这里是 2 维参数 + 分层结构，但推广到高维参数（如完整接触角场、多材料界面）时三角结构的构造与训练难度急剧上升。
- **未讨论主动学习 (active learning) 的可能**：自然的下一步是**根据当前后验自动选择下一个 cell**（最大化信息增益），以减少所需照片数。本文用**固定设计**，未做此优化。
- **物理案例较简单**：单一孔洞几何 + 单一润湿体系；真实的粗糙表面、接触角滞后、动态润湿都更复杂。
- **可微前提**：SBI 框架通常要求前向模型**可微**或至少可批处理——Young–Laplace 前向满足，但推广需注意。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — 传输映射的构造与训练（需要可微框架）、三角约束的实现、SBC 检验的工程化；前向模型本身（Young–Laplace）很简单。
- **预期性能**: 训练成本 = 前向模型批处理次数（可并行）；**推理成本接近零**（仅网络前向）。这是摊销路线的全部价值所在。
- **适用场景**:
  - **原位/非侵入测量**：不能扰动被测系统时（本文的润湿案例），前向求解是"破坏性"的；
  - **分层参数的联合反演**：多组实验共享群级参数（材料批次、装置几何、仪器漂移）；
  - **材料表征**：表面能、接触角、润湿参数的标定；
  - **实验设计的前置工具**：先用摊销似然评估不同设计的精度，再决定实际拍照方案。
- **可复用要点**:
  - **"秩一信息 → 分层模型"是本文的核心结构洞见**：当单次观测只能给出低秩约束时，不要试图单次观测解决，而是**设计多个不同方向的观测并用分层模型汇聚**。这个"信息秩"视角应当成为实验设计的第一问。
  - **"设计固定、训练一次"是摊销方法的前提条件**：因此**设计必须先想清楚**。反过来说，**摊销方法把"设计"从后验变成前置决策**——这是重要的工程约束。
  - **SBC 作为后验正确性的标准检验**：本文用它证明"不只是点估计对，后验形状也对"。建议把 SBC 纳入任何摊销/神经后验方案的**验收清单**。
  - **诚实的负面结果（标定设计上一致性较差）是重要的边界信息**——说明摊销似然在**设计外推**时不可靠。这个警示应一并归档。
  - **与本轮 [[2026-11-12-arXiv-2611.11540-Hydrograd-v2-Differentiable-Shallow-Water-Adjoints]] 形成方法论对照**：
    - Hydrograd：**可微正演 + 伴随** → 提供**梯度**，适合**连续参数**的反演；
    - 本文：**摊销似然** → 提供**完整后验**，适合**分层/多单元**结构；
    - 二者结合是当前的强做法：**用摊销映射给初值与后验，用伴随梯度精修**。
