## 核心贡献

> **Hydrograd v2.0**：一个**完全可微 (differentiable)** 的二维浅水方程求解器（Python + JAX），运行在**生产级非结构网格**（SRH-2D、HEC-RAS 2D）上，采用**良平衡 (well-balanced) + 正定性保持 (positivity-preserving) 有限体积格式**并支持**干湿 (wet/dry) 边界**。关键设计是**梯度按问题类型定制**：定常问题用**牛顿法 + 精确稀疏 Jacobian**（梯度只需一次线性求解），非定常问题用**反向模式 + 检查点**或**隐式时间积分器**（梯度成本约两次前向）。**定常闭合学习比"对时间推进求导"快 96 倍**，且**损失更低**；反演入流过程线峰值误差 **2%**；**灵敏度 SVD 分析**揭示测站水位对河道**总阻力**的敏感度是对**沿程分布**的 **70–160 倍**。

1. **非结构网格上的生产级 SWE 求解器**：直接跑在 SRH-2D、HEC-RAS 2D 的实际网格上，而非玩具网格——这使得标定结果可直接用于工程。
2. **良平衡 + 正定性保持有限体积**：同时满足两个困难要求——**良平衡**保证静水平衡不被破坏（ Lake-at-rest 问题），**正定性保持**保证水深、速度不出现负值（在干湿边界尤其关键）。
3. **干湿边界处理**：处理 wetting/drying（潮汐、洪水溃决、河床露出的边界条件）。
4. **梯度按问题类型定制**（本文最核心的设计理念）：
   - **定常**：牛顿法 + **通过图着色 (graph colouring) 得到的精确稀疏 Jacobian**；梯度由**隐函数定理**给出，**代价仅一次线性求解**；
   - **非定常**：反向模式 + **检查点 (checkpointing)**；或用**隐式时间积分器**，其**梯度成本约为两次前向运行**。
5. **梯度正确性验证**：所有梯度与**有限差分**一致，**定常情形达到约 $10^{-8}$**。
6. **工程验证（Savannah River）**：定常水面与 SRH-2D 相差 **4.7 mm (RMS)**。
7. **定常闭合学习加速**：**比"对时间推进求导"快 96 倍**，且**达到更低的损失**——这是本文最具冲击力的数字。
8. **反演能力**：从**水位记录反演入流过程线 (hydrograph)**，**峰值误差 2%**。
9. **灵敏度结构发现**：在非定常糙率标定中，**灵敏度矩阵的 SVD 分析**显示测站水位对**总阻力**的敏感度是对**各糙率区间分布**的 **70–160 倍**；这**解释**了为什么只有**每个区间都布设测站**的布局才能恢复全部五个糙率值。
10. **性能**：单 GPU 上 **51.2 万单元**网格，前向运行 **7.6 s**，梯度计算 **51 s**。

## 技术方案

### 核心思想

**问题**：把物理模型变成"**可微的**"，是当前 AI4Science / 数据同化 / 闭合模型学习的主流路线。难点在于：流体求解器（尤其是带干湿边界的 SWE）包含大量**非光滑**（min/max 限制器、干湿判据）和**隐式**（牛顿法）结构，直接套自动微分会：
- **梯度错误**（JAX 的反向模式对分支选择敏感）
- **内存爆炸**（存储整条时间轨迹）
- **梯度昂贵**（每个时间步都要保存中间状态）

**Hydrograd v2.0 的答案是"按问题类型定制梯度"**——这是全文的哲学：

| 问题类型 | 正向求解 | 梯度路径 | 梯度成本 |
|---|---|---|---|
| **定常** | 牛顿法（精确稀疏 Jacobian） | **隐函数定理** | **一次线性求解** |
| **非定常** | 显式/隐式时间推进 | 反向模式 + 检查点 / 参数化 AR | **约两次前向** |

**定常情形的优雅之处**：

定常状态满足残量方程 $F(u;\theta) = 0$。牛顿法求出的 $u^*(\theta)$ 满足 $F(u^*;\theta)=0$。

对目标 $J(\theta) = \mathcal{L}(u^*(\theta))$ 求导，由**隐函数定理**：
$$\frac{du^*}{d\theta} = -\left(\frac{\partial F}{\partial u}\right)^{-1}\frac{\partial F}{\partial\theta}$$
于是
$$\frac{dJ}{d\theta} = \frac{\partial J}{\partial u}\cdot\left(\frac{\partial F}{\partial u}\right)^{-1}\cdot\frac{\partial F}{\partial\theta}$$

**这意味着梯度不需要对牛顿迭代做反向传播**——只需一次**线性求解**。这把"梯度成本"从"$\times$牛顿迭代次数"降到"$\times$1"。

**图着色 (graph colouring) 的作用**：有限体积格式的 Jacobian 是**稀疏**的，但可能含**长程耦合**（非结构网格 + 限制器会把远处的单元耦合起来）。图着色把**不冲突的单元分组成一组**，每组可以**并行**求解，从而用**直接稀疏求解器**（或可并行的预条件迭代）高效求解，且**不需要组装完整的稀疏矩阵**（只需逐颜色组装并求解）。这在 JAX 下用 `lax` 的循环实现非常自然。

**为什么定常标定比非定常快 96 倍？**

这是本文最重要的量化结论，也是最容易被忽视的工程洞见：

- **非定常路径**：必须对整条时间轨迹做反向传播 → 存储 $\mathcal{O}(N_{\text{steps}})$ 个场 → 梯度成本高，且**受时间步长刚性限制**；
- **定常路径**：牛顿法收敛到定常解，梯度只需一次线性求解 → **成本几乎与模拟时长无关**。

含义：**如果关心的是闭合参数/糙率等稳态量，用定常伴随（steady adjoint）比非定常伴随便宜两个数量级**。这是对整个"可微流域"社区都有价值的实践建议。

**SVD 灵敏度分析的价值**：

在非定常糙率标定中，作者没有只报告"拟合得好不好"，而是**分析灵敏度矩阵的结构**。结论非常实用：

- 灵敏度矩阵 $S = \partial h/\partial \theta$（$h$ = 测站水位，$\theta$ = 各糙率区间参数）
- SVD：$S = U\Sigma V^T$
- 发现：$\|h\|$ 对**总阻力**（$\sum_i \theta_i$）的敏感度，比对**各区间分布**的敏感度高 **70–160 倍**

于是得到一个**可操作的结论**：只有**每个糙率区间都布设测站**（而不是集中在总流量敏感区），才能**恢复全部五个糙率值**。这是把数值灵敏度直接翻译成**传感器布置设计**的范例。

### 关键技术

| 技术 | 说明 |
|------|------|
| 良平衡 (well-balanced) 格式 | 保证静水（lake-at-rest）平衡解被精确保留 |
| 正定性保持 (positivity-preserving) | 保证水深/速度非负，干湿边界必备 |
| 干湿 (wet/dry) 处理 | wetting/drying 边界条件 |
| 精确稀疏 Jacobian | 由**图着色**组装，支持并行直接求解 |
| 隐函数定理梯度 | 定常梯度 = 一次线性求解 |
| 反向模式 + 检查点 | 非定常梯度，平衡内存与速度 |
| 隐式时间积分器的梯度 | 成本约两次前向 |
| 参数条件自回归模型 | 非定常 ROM 的时间外推 |
| 灵敏度矩阵 SVD | 识别参数的可辨识性结构 |
| JAX (XLA) | GPU 加速，编译型执行 |
| SRH-2D / HEC-RAS 2D 网格 | 生产级非结构网格 |
| 有限差分梯度校验 | 定常达到 $10^{-8}$ |

## 公式 / 理论要点

```math
% 二维浅水方程（SWE）
\partial_t h + \nabla\cdot(h\boldsymbol{u}) = 0
```

```math
% 动量方程
\partial_t (h\boldsymbol{u})
+ \nabla\cdot\left(h\boldsymbol{u}\otimes\boldsymbol{u}
+ \frac{1}{2}gh^2 I\right)
= -gh\,\nabla z_b - \boldsymbol{f}_{\text{fric}}
```

```math
% 底摩阻（Manning / Chezy 形式）
\boldsymbol{f}_{\text{fric}}
= \frac{g n^2 |\boldsymbol{u}|}{h^{1/3}}\,\boldsymbol{u}
```

```math
% 定常状态的隐函数梯度（核心公式）
F(u^*;\theta) = 0
\quad\Longrightarrow\quad
\frac{dJ}{d\theta}
= \frac{\partial J}{\partial u}\cdot
\left(\frac{\partial F}{\partial u}\right)^{-1}\cdot
\frac{\partial F}{\partial\theta}
\quad\text{（代价 = 一次线性求解）}
```

```math
% 图着色：把无冲突单元分组并行求解
\text{color}(i) \neq \text{color}(j)\ \text{when}\ |\boldsymbol{x}_i - \boldsymbol{x}_j| < r,
\qquad
J = \prod_{c=1}^{N_c} J_c \quad\text{（各 } J_c \text{ 并行）}
```

```math
% 良平衡：静水平衡处的残量精确抵消
\boldsymbol{u}_0 = 0,\ h_0 = h^{\text{eq}}(\boldsymbol{x})
\quad\Longrightarrow\quad
S_{\text{well-balanced}} \equiv 0
```

```math
% 灵敏度矩阵与 SVD（可辨识性分析）
S = \frac{\partial \boldsymbol{h}}{\partial \boldsymbol{\theta}}
= U\Sigma V^T,
\qquad
\text{敏感度比} \approx
\frac{\|\partial h/\partial (\sum_i\theta_i)\|}
     {\|\partial h/\partial \theta_i\|}
= 70 \sim 160
```

```math
% 非定常梯度成本（隐式积分器）
\text{cost}(\text{gradient}) \approx 2 \times \text{cost}(\text{forward})
```

## 实验与结果

- **算例 1（Savannah River，生产级）**:
  - 定常水面与 **SRH-2D** 相差 **4.7 mm (RMS)**；
  - 网格 **512,000 单元**，单 GPU：**前向 7.6 s，梯度 51 s**。
- **算例 2（梯度正确性）**: 所有梯度与有限差分一致，**定常情形约 $10^{-8}$**。
- **算例 3（定常闭合学习）**: **比"对时间推进求导"快 96 倍**，且**损失更低**。
- **算例 4（入流反演）**: 从水位记录反演入流过程线，**峰值误差 2%**。
- **算例 5（非定常糙率标定）**:
  - **灵敏度 SVD**：测站水位对**总阻力**的敏感度是对**沿程分布**的 **70–160 倍**；
  - **推论**：只有**每个区间都布设测站**的布局才能恢复全部**五个**糙率值。
- **性能汇总**: 512k 单元 / 单 GPU / 前向 7.6 s / 梯度 51 s。

## 局限性

- **仅二维浅水方程**：不含动量方程中的完整对流项涡度、平流的三维效应；不含泥沙输运、水质等实际模块。
- **非结构网格的完整耦合与多模块**：只实现了 SWE 核心；对真实河流模型还需集成大量其他物理模块，会增加梯度复杂度。
- **图着色求解器依赖稀疏直接分解**：超大规模下可能需要迭代求解器 + 预条件，届时"一次线性求解"的成本优势需重新评估。
- **单 GPU 未说明多 GPU/多节点扩展**：512k 单元 / 7.6 s 的可扩展性未讨论。
- **定常伴随的前提是问题确有定常解**：对非定常现象（如洪水波、非定常糙率变化）不可用。
- **灵敏度分析的适用性**：SVD 结论依赖于具体的测站布局与几何，不能直接外推到其他河道。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — 需要 SWE 有限体积（良平衡 + 正定性 + 干湿）、稀疏 Jacobian 组装与图着色、JAX 下的自定义 VJP（隐函数定理路径）、检查点机制。工作量大但路径清晰。
- **预期性能**: 单 GPU 512k 单元前向 7.6 s / 梯度 51 s；定常梯度仅为一次线性求解（远低于上述 51 s，因为后者是非定常路径）。
- **适用场景**:
  - **洪水与河流水动力标定**（糙率、入流过程线反演）——本文的直接应用；
  - **闭合模型学习**：如浅水方程中的**涡黏/混合参数**、底摩阻参数；
  - **数据同化与贝叶斯反演**：可微前向 + 梯度是 4D-Var/EnKF 的基础；
  - **传感器/测站布置优化**：灵敏度 SVD 分析直接服务于观测网络设计；
  - **实时预测与数字孪生**：定常路径的梯度成本几乎与模拟时长无关，利于多查询优化。
- **可复用要点**:
  - **"梯度按问题类型定制"** 是本文最值得推广的设计理念。**通用做法**（一律对时间推进反向传播）通常最简单但最贵；**按定常/非定常分流**能带来两个数量级收益。这个分流思路可推广到任何**含隐式求解的 PDE**：定常 → 隐函数定理 + 稀疏 Jacobian；非定常 → 检查点/伴随法。
  - **"隐函数定理路径"避免对牛顿迭代反传**，是隐式求解器可微化的标准做法。
  - **灵敏度 SVD → 传感器布置**：把数值灵敏度直接翻译成观测网络设计建议（"只布在总阻力敏感区不够，必须覆盖分布"），这是**可辨识性分析**的标准范式。
  - **良平衡 + 正定性 + 干湿**是浅水格式的"三件套"，自建求解器时应作为验收清单。
  - **定常伴随 96× 加速**这一条应当写入本知识库的"数值方法/可微计算"目录，作为选型的首要判据。
