## 核心贡献

> 首次定量测量**植被密度对极端波统计（excess kurtosis / 超越概率）衰减能力**的影响，结论与直觉相反：**在浅水与陡波条件下，即使远超天然盐沼密度的植被也无法抑制极端波非线性**——显著的波高衰减（significant wave height decay）**不是**极端波衰减的可靠代理。

1. **填补文献空白**：此前研究只关注植被对**体波属性**（$H_{\rm rms}$ 等）的衰减，或在 Rayleigh 分布假设下讨论波高衰减。**没有任何研究量化过植被密度对极端波统计的影响**，而这正是海岸防护真正关心的量。
2. **非线性波分布的转变**：在非平衡条件下（陡坡/陡护岸、非常驻/非均匀流），波高分布会**脱离 Rayleigh 形式**，转变为 Weibull 与标准极值分布都无法描述的修正形状——这类转变对相对水深与波陡度高度敏感，即使存在破波耗散仍然存在。
3. **反直觉的核心发现**：
   - **中间水深**下，植被密度单调增加 → 极端波统计几乎单调下降（存在低密度**饱和区** + 极高密度快速下降区）
   - **浅水**或**高波陡度**下 → **完全不缓解**极端波危害
   - 最高实验密度（$N=3550$ stems/m²，**远超多数天然盐沼密度**）仍不足以在所有工况下驯服峰度
4. **峰度衰减与波高衰减的解耦**：定量证明两者的相关系数可从 **+0.99（正相关）到 −0.56（负相关）**，取决于波陡度与浅水效应。
5. **工程启示**：混合结构（植被 + 灰色结构如防波堤/海堤）的最优组合位置应在**中间水深**而非浅水。

## 技术方案

### 核心思想

在波浪水槽中于**突变水深（ADT, abrupt depth transition）之前**布置人工盐沼，用波高统计量（超越概率）与**超峰度（excess kurtosis）**两种度量刻画极端波，并系统扫描植被密度。

### 关键技术

| 技术 | 说明 |
|------|------|
| 实验设施 | 波浪水槽，长 35 m（造波板下游 32.8 m），末端 8 m 1:18 缓坡 + 2 m 海绵消波；15 个波高计沿程布置 |
| 突变水深 | 6 个相邻亚克力箱，每个 0.5 m，合计 3 m，位于 $x=11.8$–$14.8$ m（竖直台阶） |
| 植被 | 人工盐沼叶片，长度超过所有工况水深；静止时茎丛 71 cm，波作用下叶片变形可伸展至 100 cm |
| 植被密度 | D090 → $N=90/0.06745\approx1330$ stems/m²（90 茎 × 15 叶）；最高 $N=3550$ stems/m²；典型天然密度 $N\lesssim2000$ stems/m² |
| 波浪条件 | 不规则长峰波，小振幅，覆盖线性与弱非线性区；每工况 10 次实现 × 1000 波 |
| 阻力模型 | Dalrymple et al. 圆柱模型（不规则波版本），$C_D\approx1.7$ |
| 统计度量 | excess kurtosis $\mu_4$、归一化峰高超越概率 $H_c/H_s$、最大波峰追踪 |

### 工况配置（Case A–F）

变化维度：波陡度、相对水深（$h$ 与 $k_ph$）、水深台阶物理深度。物理水深与叶片长度固定，仅调无量纲参数。

## 公式

### 1. 植被波高衰减模型（Dalrymple et al. 圆柱模型，不规则波）

```math
\frac{H_{\mathrm{rms}}}{H_{\mathrm{rms},0}}=\frac{1}{1+\alpha x}
```

```math
\alpha=\frac{1}{3\sqrt{\pi}}C_{D}DN(k_{p}H_{\mathrm{rms},0})
\left[\frac{\sinh^{3}(k_{p}h)+3\sinh(k_{p}h)}{(\sinh(2k_{p}h)+2k_{p}h)\sinh(k_{p}h)}\right]
```

其中 $N$ 为茎密度（stems/m²），$C_D$ 为阻力系数，$k_p$ 为峰值波数，$h$ 为水深。

### 2. 浅水下界的渐近形式（$k_ph\to 0$）

```math
\alpha\rightarrow\left(\frac{C_{D}DNH_{\mathrm{rms},0}}{3\sqrt{\pi}}\right)\cdot\left(\frac{3}{4h}\right)
```

### 3. 超峰度衰减系数（本文新定义）

```math
\alpha_{\mu 4}=\left[\left(\frac{\mu_{4,0}}{\mu_{4}}\right)-1\right]\Big/\Delta x
```

$\mu_{4,0}$ 为上游测点（G2）的四阶矩，$\mu_4$ 为下游测点（G4，超峰度峰值位置）的四阶矩。$\Delta x$ 为测点间距。

### 4. 超峰度定义

```math
\mu_{4}-3=\frac{\mathbb{E}\big[(H-\bar{H})^{4}\big]}{\big(\mathbb{E}\big[(H-\bar{H})^{2}\big]\big)^{2}}
```

（Gauss 分布下 $\mu_4=3$；$\mu_4<3$ 为次高斯（sub-Gaussian）。）

### 5. 峰高超越概率（归一化）

```math
\beta=\frac{H_{c}}{H_{s}}
```

超越概率 $P(H_c>\beta H_s)$ 与 Rayleigh 分布对比，用于量化「偏离 Rayleigh 的间隙」。

### 6. Keulegan–Carpenter 数

```math
KC=\frac{U_{\rm max}T}{D_{\rm veg}}
```

## 实验结论

### 植被密度 vs 极端波统计

| 工况 | 相对水深/波陡度 | 峰度衰减 | 说明 |
|---|---|---|---|
| **C–F** | 中间水深 | 最高密度 $N=3550$ stems/m² 使相对超峰度**降到 0 以下** → 进入**次高斯区** | 人工盐沼在极高密度下表现极佳 |
| **A, B** | 浅水 / 陡波 | 即使极高密度**也无法完全缓解**极端海况 | — |
| **E** | 中间水深 + 小波陡度 | 唯一观察到**显著**超峰度衰减的工况 | — |
| **F** | 最陡波 | **无峰度衰减**，尽管有效波高衰减最强 | 陡波 + 浅水效应解耦两者 |

### 峰度衰减 vs 波高衰减的相关性

- 工况 **B–D**：两者**同时增加**，强正相关 **$r=0.99$**
- 全工况合起来（含 A、E–F）：**负相关 $r=-0.56$**
- 结论：波陡度与浅水效应可使**峰度衰减与波高衰减彻底解耦**

### 有效波高衰减

- 最大 $\alpha$（工况 C、D、F）→ 有义波高衰减 **25%**
- 最小 $\alpha$（工况 A）→ 衰减 **13%**

### 归一化峰高超越概率 vs Rayleigh

- 工况 **A、E**：所有 $\beta=H_c/H_s$ 下超越概率**分层**，随植被密度单调缩小与 Rayleigh 曲线的间隙
- 工况 **B–C–D**：同样单调缩小，**但尾部（$\beta>1.2$）除外**
- 工况 **F**：**间隙无缩小**（与无峰度衰减一致）
- 天然密度（$N\approx1330$–2000$ stems/m²）下的间隙缩小**极小**，仅工况 E 例外

### 最大波峰追踪（工程最关心）

- 工况 **C–E**：人工盐沼使极端波峰显著降低 **40–50%**
- 工况 **A–B、F**：即使 $N=3550$ stems/m² 也仅有**边缘缓解（$\lesssim20\%$）**；天然条件密度（$N=1330$ stems/m²）下**无可察觉缓解**

## 局限性

1. **仅人工盐沼**，且叶片长度超过所有工况水深（近 emerged 条件）；未覆盖真实盐沼的叶片柔性、密度分布与泥沙耦合。
2. **不规则长峰波、小振幅**，仅覆盖线性到弱非线性区；极端非线性区未测。
3. **单一波陡度/相对水深组合有限**（工况 A–F），且**不改变物理水深**，仅变波数——因此水深效应是与波陡度耦合考察的。
4. **未考虑破波耗散对极端波衰减的贡献**（作者列为未来工作）。
5. **未考虑非均匀/非常驻条件**：潮流、离岸流、海平面上升、风暴潮、侵蚀——作者指出这会进一步削弱植被的极端波缓解效果。
6. **未评估累计波荷载**（不仅是最大荷载，还包括极值荷载的发生频率）以及「高密度短距离 vs 低密度长距离」的权衡。
7. 植被阻力系数取自圆柱模型且 $C_D\approx1.7$，为常数。

## 实现建议

- **实现难度**：实验研究（计算成本低，但水槽实验周期长）。
- **预期性能**：不涉及数值模拟；若要复现统计结论，1D 非线性浅水方程（Boussinesq 类）配合植被阻力项即可。
- **适用场景**：
  - **海岸防护设计的评估指标选择**（关键结论）
  - 风暴潮/极端波条件下的植被防护效能评估
  - 极端波统计（超越概率、峰度）的实验测量方法
- **落地建议**：
  1. **若做 CFD/数值模拟**：1D 非线性浅水方程 + Dalrymple 圆柱阻力模型（本文公式直接可用），参数 $C_D\approx1.7$、$N$ 为茎密度
  2. **评估指标务必区分**：**不要用有效波高衰减 $H_{\rm rms}$ 衰减作为极端波防护效果的代理**——本文证明两者相关系数可从 +0.99 变到 −0.56
  3. **推荐同时监控**：超峰度 $\mu_4$ + 归一化峰高超越概率 + 最大波峰高
  4. **设计准则**：混合结构（植被 + 灰色结构）应把植被段布置在**中间水深区**；浅水段不能指望植被抑制极端波
  5. **对数值方法的启示**：本文指出非线性波分布**偏离 Rayleigh**，而 Weibull 与标准极值分布也无法描述 → 若用极值分布模型拟合波高，需检验其适用性（本库 [[Melt-Lubricated-Sliding]] 等涉及非高斯分布的工作可参考这条）
