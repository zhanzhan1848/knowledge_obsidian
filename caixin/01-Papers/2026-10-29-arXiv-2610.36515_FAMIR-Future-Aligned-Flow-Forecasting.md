## 核心贡献

> 学习到的流动代理模型都是**递归**部署的（每次预测成为下一步的输入），相位/幅值/输运误差逐步累积。但**训练时真实的下一状态是已知的**。FAMIR 用这个"只存在于训练期的真实未来"去塑造**驱动状态更新的信号本身**（而不只是作为预测目标）：在冻结自编码器的隐空间网格上，一个**未来条件教师**与一个**仅历史学生**各自推断"运动张量"，共同条件化**一个共享的残差转移**；训练完只部署学生。

1. **未来对齐的运动（motion）表述**：把"状态"与"状态如何变化"分离。运动张量 $\mathbf{m}_t\in\mathbb{R}^{16\times H_z\times W_z}$ 定义在隐网格上，**不强行等同于物理速度或力**——它由其在转移中的角色定义。教师 $Q_\eta(\mathcal{H}_t,z_{t+1})$ 看得见真实下一态，故其运动编码"实际发生的变化"；学生 $P_\omega(\mathcal{H}_t)$ 只看历史，是部署分支。
2. **PPMA（Posterior–Prior Motion Alignment）**：在同一观测历史上**双向对齐**教师（后验）与学生（先验）运动，**梯度同时流向两个编码器**——即教师也被塑造成"学生能逼近"的运动；这与"向固定教师蒸馏"（one-way PPMA）形成对照，后者被证明在 PlanetSWE 上**更差**（1.874% vs 1.036%）。
3. **prediction-fed 多步目标**：学生**在自己的滚动预测上**训练（保留跨展开的梯度），使其输入分布与部署时一致；这是防止误差累积的关键（PlanetSWE 上单步训练使误差 **+258.3%**）。
4. **统一在解码后的物理场上评测**：所有精度比较都在**解码物理场**上做，并额外用 $\mathcal{L}^S_{\rm frm}$ 监督解码场——因为隐空间误差与物理解码误差的对应关系**逐流而异**（$R_s$ 分别为 0.92 / 0.68 / 0.17）。
5. **三个流动系统上的全面领先**（complete-prefix NRMSE）：

   | 系统 | 10 步 | 20 步 | 最强直接隐空间预测器 |
   |---|---|---|---|
   | VF（粘弹性通道流） | **1.003%** | **1.661%** | latent FNO 1.416% / 1.979% |
   | RBC（Rayleigh–Bénard 对流） | **1.055%** | **1.683%** | latent AFNO 1.074% / latent FNO 1.890% |
   | PlanetSWE（行星浅水） | **0.620%** | **1.036%** | latent FNO 0.856% / 1.617% |

   相对最强直接预测器的优势：10 步 **-29.2% / -1.8% / -24.7%**；20 步相对 latent FNO **-16.1% / -10.9% / -35.9%**。
6. **消融诊断的深度**：固定状态干预（教师/组均值/组内乱序/零运动/持久性）、运动标量路径的增量几何（方向余弦 $c$ 与幅值比 $q$）、CKA 对齐链（学生↔教师 0.989/0.984/0.997；学生运动↔观测增量仅 0.696/0.363/0.569；预测增量↔观测增量 0.9997/0.9956/0.9898）——**证明运动不是增量的拷贝，而是与状态"共同阅读"的编码**。

## 技术方案

### 核心思想

三个问题被明确分离：

1. **流场如何被表示**？→ 冻结的卷积自编码器，映射到**保留空间邻接关系**的隐网格（不是全局模态向量）。
2. **什么信号驱动这一表示的变化**？→ 一个**空间运动张量**，它与当前状态一起决定隐空间的增量。
3. **只有过去已知时如何推断该信号**？→ 学生编码器 + prediction-fed 训练。

关键假设（原文）：*"递归预测的改进来自——更新被一个转移表示所条件化，该表示在训练期锚定于真实未来、在部署期可从历史推断、并在自生成的预测历史上训练。"*

FAMIR 相对主流方法的定位：

- **vs. FNO/AFNO/Transformer/算子学习**：那些方法的更新仅由过去状态推断，未来只作为"要匹配的目标"进入训练；FAMIR 让未来**塑造更新所消费的信号**。
- **vs. Scheduled Sampling / Professor Forcing / Pushforward / 知识蒸馏**：那些策略改变"模型看到哪些历史"或"输出如何被监督"；FAMIR 改变的是**驱动更新的空间信号本身**，且该信号是隐状态网格上的**确定性场**（不同于 PlaNet/DreamerV2 的随机隐变量）。
- **与 DreamerV2 的 KL balancing 的关系**：把学生蒸馏到**分离（detach）**的教师，等价于 KL balancing 中"后验不被拉向先验"的极限；原文在 3.3 节对比了两种选择。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Stage 1：冻结自编码器** | 卷积栈：宽度 32 stem，$L_s$ 个 stride-2 阶段，$1\times1$ 投影到 16 通道；解码器镜像（双线性上采样 + $3\times3$ 输出卷积）。VF 用 $L_s=4$（通道宽 64/128/128/192，零填充），RBC/PlanetSWE 用 $L_s=3$（64/128/128，水平/经度循环填充、壁法向/纬度复制填充）。隐状态：VF $16\times20\times64$，RBC/PlanetSWE $32\times64$ |
| **Stage 2：双运动编码器** | 学生 6 帧、教师 7 帧隐历史沿通道拼接 + 2 个归一化坐标通道 $\xi_x,\xi_y$ → Lift → **4 个 Fourier 块** → Proj → $3\times3$ 卷积输出 16 通道运动。谱卷积 $\mathcal{S}_\ell$ 在截断低模态上逐模态混合（每个谱块第一轴保留 5 个正/负模态、第二轴 16 个非负实 FFT 模态） |
| **共享残差转移** | 单一 $F_\vartheta(z_t,\mathbf{m}_t)$ 被两个分支共用：$3\times3$ 卷积处理 $[\mathbf{z}_t,\mathbf{m}_t]$ → **3 个残差块**（$\mathcal{C}=\text{GELU}\circ\text{GN}\circ\text{Conv}_{3\times3}$，宽度 96）→ $3\times3$ 卷积输出 $\widehat{\Delta z}_t$ → $F_\vartheta=\mathbf{z}_t+\widehat{\Delta z}_t$。**只有当前状态 $\mathbf{z}_t$ 进入转移**，历史其余部分通过 $\mathbf{m}_t$ 起作用 |
| **PPMA** | $\mathcal{L}_{\rm PPMA}=\frac{1}{2\sigma_m^2}\frac1K\sum_k\operatorname{mean}[(\bar m^T_k-\bar m^S_k)^2]$，$\sigma_m=0.05$；平方先逐元素再对 batch/通道/隐网格平均；**梯度同时进入两个编码器** |
| **教师运动噪声** | 在教师条件的转移前给 $\bar m^T_k$ 加高斯噪声 $\epsilon_k$，标准差从 0 线性升到 0.05（VF）/ 0.03（RBC）/ 0.02（PlanetSWE），前 50 个 epoch 内爬升；**PPMA 使用无噪声教师运动** |
| **Prediction-fed 滚动** | $\hat z_{t+k}=F_\vartheta(\hat z_{t+k-1},P_\omega(\hat{\mathcal{H}}_{t+k-1}))$，历史从 6 个观测起，逐步被学生自己的预测填充；**跨展开保留梯度** |
| **四项回归损失** | $\mathcal{L}^S_{\rm lat}$（隐空间）、$\mathcal{L}^S_{\rm frm}$（解码物理场）、$\mathcal{L}_{\rm prior}$（参考历史上的一步学生）、$\mathcal{L}_{\rm post}$（参考历史上的一步教师，含噪声） |
| **权重调度** | $\mathcal{L}_e=a_{\rm pr}(e)[\mathcal{L}^S_{\rm lat}+20\mathcal{L}^S_{\rm frm}+0.3\mathcal{L}_{\rm prior}]+\mathcal{L}_{\rm post}+a_{\rm ppma}(e)\mathcal{L}_{\rm PPMA}+\mathbf{1}_{\rm SWE}\mathcal{L}_{\rm seam}$；$a_{\rm ppma}$ 在 50 epoch 内从 0 线性升到 1；**VF 的 $a_{\rm pr}$ 同节奏爬升，RBC/PlanetSWE 恒为 1**；滚动长度 $K$ 在 100 epoch 内从 1 增到 5 |
| **训练配置** | Stage 1：AdamW + 混合精度 + 重构 MSE，最多 3000 epoch；batch 8（VF）/ 64（RBC, PlanetSWE）；PlanetSWE 额外 0.1 权重的经度缝惩罚。选中检查点 epoch 为 2980 / 2980 / 1246。Stage 2：AdamW 300 epoch，weight decay $2\times10^{-4}$，梯度裁剪 norm 1，学习率 10 个 epoch 内从 $10^{-5}$ 线性升到 $10^{-4}$ 后余弦衰减到 0；mini-batch 4（VF）/ 16（RBC, PlanetSWE）；检查点 epoch 295 / 128 / 229 |
| **对照模型** | latent FNO（4 个宽度 68 块，模态 (5,16)）、latent AFNO（4 个宽度 96 块）、轴向 Transformer（3 层 8 头宽 288，时间注意力 + 坐标嵌入空间注意力 + 4× 扩张 GELU 前馈）、POD–Hankel DMD（6 延迟线性算子，POD 秩 VF 699/36-555、RBC 1399、PlanetSWE 354/4000/4000） |
| **部署规模** | FAMIR 时序模型 **5.82 M** 参数（不含教师）；对照为 5.96–6.03 M；含冻结自编码器则 6.32–6.78 M vs 6.46–6.99 M |
| **模型区间（时间采样）** | VF 1.2 模拟单位、RBC 64 个 LBM 步、PlanetSWE 约 4 模拟小时。由功率覆盖率判据 $\mathcal{C}(\delta)=\frac{\int_0^{1/(2\delta)}P(f)df}{\int_0^{f_{N,\rm dense}}P(f)df}$ 选出，分别覆盖 VF 速度功率 **96.5%**、RBC 温度功率 **99.967%**、PlanetSWE 纬向速度功率 **99.996%** |

## 公式

### 1. 隐空间表示

```math
x_t^{s}=\mathcal{N}_s(X_t^{s}),\qquad
z_t^{s}=E_{\phi_{s}}(x_t^{s}),\qquad
\mathcal{H}_t^{s}=(z_{t-5}^{s},\ldots,z_t^{s}),\qquad
\widetilde{X}_t^{s}=\mathcal{N}_s^{-1}(D_{\psi_{s}}(z_t^{s}))
```

### 2. 编码器/解码器结构

```math
h_t^{(0)}=\operatorname{Stem}(x_t),\qquad
h_t^{(\ell+1)}=\operatorname{GELU}\!\left(\operatorname{GN}\!\left(\operatorname{Conv}^{(\ell)}_{3\times3,s=2}(h_t^{(\ell)})\right)\right)
```

```math
z_t=\operatorname{GELU}\!\left(\operatorname{GN}\!\left(\operatorname{Conv}_{1\times1}(h_t^{(L_s)})\right)\right),\qquad
D_\psi(z)=\operatorname{Conv}_{3\times3}\!\left(\mathcal{U}_{L_s}\circ\cdots\circ\mathcal{U}_1(z)\right)
```

### 3. 双运动编码器（未来对齐的核心）

```math
m_t^{S}=P_{\omega}(\mathcal{H}_t),\qquad
m_t^{T}=Q_{\eta}(\mathcal{H}_t,z_{t+1})
```

（学生=先验 prior，教师=后验 posterior；两者都是确定性编码器，权重独立）

### 4. 谱块

```math
v^{(0)}=\operatorname{Lift}([\mathcal{H}_t,\xi_x,\xi_y])
```

```math
v^{(\ell+1)}=\operatorname{GELU}\!\left(\operatorname{GN}\!\left(W_\ell v^{(\ell)}+\mathcal{S}_\ell(v^{(\ell)})\right)\right),\quad \ell=0,\ldots,3
```

```math
\widehat{[\mathcal{S}_\ell(v)]}_{b,o,k_y,k_x}=\sum_{i=1}^{C_{\rm in}}M_{\ell,oi,k_y,k_x}\,\widehat{v}_{b,i,k_y,k_x}
```

```math
m_t=\operatorname{Conv}_{3\times3}\!\left(\operatorname{Proj}(v^{(4)})\right)
```

### 5. 共享残差转移

```math
r_t^{(0)}=\operatorname{GELU}\!\left(\operatorname{GN}\!\left(\operatorname{Conv}_{3\times3}([z_t,m_t])\right)\right)
```

```math
r_t^{(j+1)}=\operatorname{GELU}\!\left(r_t^{(j)}+\operatorname{GN}\!\left(\operatorname{Conv}_{3\times3}\mathcal{C}(r_t^{(j)})\right)\right),\quad j=0,1,2
```

```math
\widehat{\Delta z}_t=T_\vartheta(z_t,m_t)=\operatorname{Conv}_{3\times3}(r_t^{(3)}),\qquad
F_\vartheta(z_t,m_t)=z_t+\widehat{\Delta z}_t,\qquad \Delta z_t=z_{t+1}-z_t
```

### 6. PPMA

```math
\mathcal{L}_{\mathrm{PPMA}}=\frac{1}{2\sigma_m^{2}}\frac{1}{K}\sum_{k=1}^{K}\operatorname{mean}_{b,c,y,x}\left[\left(\bar m^{T}_k-\bar m^{S}_k\right)^{2}\right],
\qquad \sigma_m=0.05
```

### 7. Prediction-fed 滚动

```math
\widehat{z}_{t+k}=F_\vartheta\!\left(\widehat{z}_{t+k-1},P_{\omega}(\widehat{\mathcal{H}}_{t+k-1})\right)
```

### 8. 四项回归损失

```math
\mathcal{L}_{\mathrm{lat}}^{S}=\frac{1}{K}\sum_{k=1}^{K}\operatorname{mean}_{b,c,y,x}\left[(\widehat{z}_{t+k}-z_{t+k})^{2}\right]
```

```math
\mathcal{L}_{\mathrm{frm}}^{S}=\frac{1}{K}\sum_{k=1}^{K}\operatorname{mean}_{b,c,y,x}\left[(D_\psi(\widehat{z}_{t+k})-x_{t+k})^{2}\right]
```

```math
\mathcal{L}_{\mathrm{prior}}=\frac{1}{K}\sum_{k=1}^{K}\operatorname{mean}_{b,c,y,x}\left[(F_\vartheta(z_{t+k-1},\bar m^{S}_k)-z_{t+k})^{2}\right]
```

```math
\mathcal{L}_{\mathrm{post}}=\frac{1}{K}\sum_{k=1}^{K}\operatorname{mean}_{b,c,y,x}\left[(F_\vartheta(z_{t+k-1},\bar m^{T}_k+\epsilon_k)-z_{t+k})^{2}\right]
```

### 9. 总目标

```math
\mathcal{L}_{e}=a_{\rm pr}(e)\big[\mathcal{L}_{\rm lat}^{S}+20\mathcal{L}_{\rm frm}^{S}+0.3\mathcal{L}_{\rm prior}\big]
+\mathcal{L}_{\rm post}+a_{\rm ppma}(e)\mathcal{L}_{\rm PPMA}+\mathbf{1}_{\rm SWE}\mathcal{L}_{\rm seam}
```

### 10. 评测指标

```math
\mathrm{NRMSE}_{i,c}^{(H)}=\frac{1}{R_c}\left[\frac{1}{HN_c}\sum_{h=1}^{H}\|\widehat{X}_{i,c}^{(h)}-X_{i,c}^{(h)}\|_{2}^{2}\right]^{1/2}
```

```math
\mathrm{PSNR}=-20\log_{10}\!\left(\mathrm{NRMSE}_{i,c}^{(H)}\right)
```

```math
e_X=\frac{1}{C_s}\sum_{c=1}^{C_s}\left[\frac{\sum_{y,x}(\widehat{X}_{c,y,x}-X_{c,y,x})^{2}}{\max(\sum_{y,x}X_{c,y,x}^{2},10^{-12})}\right]^{1/2}
```

### 11. 诊断量

```math
r_i=\|F_\vartheta(z_i,m)-z_{i+1}\|_2\big/\|F_\vartheta(z_i,m_i^{S})-z_{i+1}\|_2
```

```math
\frac{\|\widehat{\Delta z}-\Delta z\|_2}{\|\Delta z\|_2}=(q^{2}-2qc+1)^{1/2}
\qquad(q=\text{幅值比},\ c=\text{方向余弦})
```

```math
\mathrm{CKA}(A,B)=\frac{\|A^{\mathsf{T}}B\|_{F}^{2}}{\|A^{\mathsf{T}}A\|_{F}\,\|B^{\mathsf{T}}B\|_{F}}
```

```math
\delta_m=\|m^{S}-m^{T}\|_2\big/\|m^{T}\|_2,\qquad
e_z=\|\widehat{z}_{t+1}-z_{t+1}\|_2\big/\|z_{t+1}\|_2
```

```math
\mathcal{C}(\delta)=\frac{\int_{0}^{1/(2\delta)}P(f)\,df}{\int_{0}^{f_{N,\mathrm{dense}}}P(f)\,df}
```

### 12. 物理系统控制方程（附录）

**VF（FENE-P）**：

```math
\partial_t\boldsymbol{u}+\boldsymbol{u}\cdot\nabla\boldsymbol{u}
=-\nabla p+\frac{\beta}{Re_s}\nabla^{2}\boldsymbol{u}+\frac{1-\beta}{Re_s}\nabla\cdot\boldsymbol{\tau}_p+\boldsymbol{f}
```

```math
\partial_t\boldsymbol{C}+\boldsymbol{u}\cdot\nabla\boldsymbol{C}
=(\nabla\boldsymbol{u})\boldsymbol{C}+\boldsymbol{C}(\nabla\boldsymbol{u})^{T}-\boldsymbol{\tau}_p,
\qquad
\boldsymbol{\tau}_p=Wi_s^{-1}\big[f_P(\boldsymbol{C})\boldsymbol{C}-\boldsymbol{I}\big],
\quad f_P=\frac{L^{2}-2}{L^{2}-\operatorname{tr}\boldsymbol{C}}
```

**RBC（Boussinesq）**：

```math
\partial_t\boldsymbol{u}+\boldsymbol{u}\cdot\nabla\boldsymbol{u}
=-\rho_0^{-1}\nabla p+\nu\nabla^{2}\boldsymbol{u}+g\alpha_T(T-T_0)\boldsymbol{e}_z,\qquad
\partial_tT+\boldsymbol{u}\cdot\nabla T=\kappa\nabla^{2}T
```

**PlanetSWE（球面浅水）**：

```math
\partial_t\boldsymbol{v}+\boldsymbol{v}\cdot\nabla_S\boldsymbol{v}+f\boldsymbol{e}_r\times\boldsymbol{v}
=-g\nabla_Sh-\nu_4\nabla_S^4\boldsymbol{v}
```

```math
\partial_th+\nabla_S\cdot[(H_0+h)\boldsymbol{v}]=F_h-\nu_4\nabla_S^4h
```

| Latent AFNO | 2.085 | 43.77 | 0.8843 | 1.988 | 34.28 | 0.9225 | 2.069 | 33.90 | 0.8908 |
| Axial transformer | 2.374 | 39.68 | 0.8793 | 2.192 | 33.35 | 0.9079 | 1.756 | 35.30 | 0.8981 |
| **FAMIR** | **1.661** | 44.86 | **0.9195** | 1.683 | **35.57** | **0.9334** | **1.036** | **40.12** | **0.9579** |

- VF 20 步的 POD–Hankel DMD **PSNR 最高（45.31 dB vs FAMIR 44.86 dB）但 NRMSE 最高、SSIM 最低**——因为 PSNR 是对每个 origin/field 的**对数误差**平均，少数低误差 origin 可以抬高 PSNR 而不降低平均 NRMSE。这是评测指标选择的重要教训。
- VF 20 步使用的是**所有方法共享的 525 个 origin**。

### 物理场演化与统计保真度

- 残差位置：VF 集中在 $C_{xx}$ 的**薄构象带**（小位移造成大点误差）；RBC 沿**羽流上升/下降的边缘**；PlanetSWE 沿**偏移的纬向流结构**。
- 末 lead 单场单步 NRMSE（FAMIR vs 对照）：VF $t+10$ 为 **4.47% vs 5.77%**；RBC $t+20$ 为 **2.45% vs 3.00%**；PlanetSWE $t+20$ 为 **1.36% vs 3.22%**。误差是**沿同一界面减弱**，而非转移到别处 → 结构定位更准。
- **40 步自主预测的统计量**（相对廓线误差 / PDF 误差）：

  | 系统 | FAMIR 廓线 / PDF | 直接预测器范围 |
  |---|---|---|
  | VF | **12.05% / 19.03%** | 16.4–37.0% / 34.3–41.8% |
  | RBC | **4.09% / 11.27%** | 12.8–58.3% / 39.0–50.2% |
  | PlanetSWE | **12.37% / 3.22%** | 16.8–28.5% / 3.43–10.44% |

  差异主要在**廓线极值与 PDF 尾部**：多个直接预测器高估 VF 在 $|y/h|\approx0.65$ 处的涨落峰、RBC 近板峰，并拓宽 RBC 温度尾部；FAMIR 低估 VF 下部峰约 14%（0.0135 vs 0.0157）。在 3 条历史的重复检验中，**FAMIR 在 18 个（历史×统计量）配对中的 17 个取最低误差**，且每个系统的每个统计量的三历史均值都最低。

### 训练配置消融（Table 2，complete-prefix NRMSE）

| 配置 | VF（10 步） | RBC（20 步） | PlanetSWE（20 步） |
|---|---|---|---|
| **FAMIR（完整）** | **1.003** | 1.683 | **1.036** |
| No posterior guidance（去掉教师） | 1.333 (+32.9%) | **1.648 (−2.1%)** | 1.064 (+2.7%) |
| One-way PPMA（教师侧梯度被切断） | 1.280 (+27.6%) | 1.634 (−3.0%) | 1.874 (**+80.9%**) |
| Single-step training | 1.284 (+28.0%) | 1.747 (+3.8%) | 3.712 (**+258.3%**) |

- **PlanetSWE：prediction-fed 训练是决定性因素**（单步训练 +258.3%）；**单向对齐比完全不用教师还糟**（+80.9% vs +2.7%）。
- **VF：所有对照都在完整 FAMIR 之上 27.6%–32.9%**。
- **RBC：所有对照都在完整 FAMIR 的 4% 以内** → 20 步精度对训练配置不敏感。
- **第 1 步**：单步训练（直接优化该误差）反而**更准**——VF 0.275% vs 0.326%，RBC 0.246% vs 0.258%，PlanetSWE 0.266% vs 0.287%；RBC 的 no-posterior-guidance 为 0.231%。**prediction-fed 训练用更大的首步误差换更慢的误差累积**。
- **即使去掉教师**，no-posterior-guidance 也优于最强直接预测器：VF 1.333% vs 1.416%，RBC 1.648% vs 1.890%，PlanetSWE 1.064% vs 1.617%。→ **"把历史编码与状态更新分离"本身在三个流中都有效**（此时 16 通道运动是无监督中间表示，模型成为"谱历史编码器 + 局部卷积更新"的两段式预测器）。

### 运动的功能性诊断（固定状态干预）

| 干预方式 | VF 中位比值 | RBC | PlanetSWE |
|---|---|---|---|
| 换成教师运动 | ≤1.2%（几乎无影响） | 同 | 同 |
| 组均值替换（留一） | 1.26 | 1.10 | 1.34 |
| 组内乱序替换 | 1.55 | 1.28 | 1.61 |
| 零运动 | 3.59 | 3.47 | **16.67** |
| 持久性（不更新） | 7.93 | 2.37 | 2.17 |

- 排序 **配对 < 组均值 < 组内乱序** 在三个系统中都成立 → 运动携带**状态特异**信息，超出其物理组的典型运动。
- 持久性比值的倒数给出"增量相对误差"：**VF 的更新误差仅占隐空间变化的约 13%**，RBC 约 **42%**，PlanetSWE 约 **46%**。
- **零运动在 VF 中低于持久性**（状态输入本身已把预测推向目标）；**在 RBC 与 PlanetSWE 中高于持久性**——PlanetSWE 的零运动中位比值接近持久性的 8 倍 → **在这两个流中，"没有运动的更新"比"完全不更新"更糟**。
- 增量几何（$q$ 幅值比、$c$ 方向余弦）：

  | 系统 | 零运动（$\alpha=0$） | 满运动（$\alpha=1$） | 解读 |
  |---|---|---|---|
  | VF | $c=0.90,\ q=1.09$ | $c=0.99$ | 零运动已近正确；运动只做精修 → 零运动落在持久性等值线内 |
  | RBC | $c=0.28,\ q=1.41$ | $c=0.91$（$\alpha\ge0.5$ 时 $q\in[0.96,0.99]$） | **运动主要设定方向** |
  | PlanetSWE | $c=0.29,\ q=7.9$ | $c=0.89,\ q=0.93$ | 运动**既转向又去除多余幅值** |

- 反向运动（$\alpha=-1$）的比值：8.29 / 12.32 / 19.65；RBC 与 PlanetSWE 的增量几乎与观测变化**正交**。
- 响应对称性：VF 近似对称（$\alpha=0.5$ 时 1.78，$\alpha=1.5$ 时 1.69）；RBC（1.51 / 1.22）与 PlanetSWE（3.64 / 1.32）**不对称**——削弱运动比增强运动代价更大（更小的 $\alpha$ 落向糟糕的零运动响应）→ **更新会读取运动的幅值与符号，而不仅是其图样**。

### 从隐空间到物理精度

- **CKA 链**：学生↔教师运动 0.989 / 0.984 / 0.997（几何几乎相同）；学生运动↔观测增量仅 **0.696 / 0.363 / 0.569**；但**预测增量↔观测增量 0.9997 / 0.9956 / 0.9898** → **运动不是增量的拷贝，而是与状态共同阅读的编码**（CKA 对整体缩放不变，幅值误差由 13–46% 的增量误差单独度量）。
- **教师 vs 学生的一步精度几乎相同**：隐状态误差中位数 VF 0.01458 vs 0.01478、RBC 0.02844 vs 0.02861、PlanetSWE 0.03163 vs 0.03207；每 origin 的学生/教师比值中位 1.001 / 1.000 / 1.012 → **部署时去掉教师不损失任何一步精度**；教师通过训练发挥作用。
- **单向 PPMA 造成"更像但更差"**：VF/RBC 的运动距离 $\delta_m$ 从 0.016→0.003、0.010→0.003（更像），但一步误差变差（VF 0.0146→0.0222，RBC 0.0284→0.0366）；PlanetSWE 反而 $\delta_m$ 0.008→0.026 且一步误差 0.0316→0.0500。**"更紧地模仿教师"不等于"更好的更新"**。
- **解码改变了跨系统的排序**：物理相对误差 $e_X$ 中位数为 VF **0.0885**、RBC **0.0123**、PlanetSWE **0.0258**；VF 的隐状态误差最小却**解码误差最大**（$e_X$ 按通道能量各自归一化后等权平均，VF 有 5 个这样的通道）。
- **隐/物理误差的关联逐流不同**：RBC 强单调（Spearman $\rho_s=0.92$），VF 正相关（0.68）但中间 bin 非单调，PlanetSWE 弱（0.17，其最低隐误差 bin 的物理误差中位数反而高于最高隐误差 bin）→ **必须在解码物理场上评测**。

## 局限性

1. **只在外推参数上评测**：测试历史来自"训练条件下的保留时刻"（VF、RBC）或"训练参数下的保留轨迹"（PlanetSWE）。**未见参数、见新几何、三维流、更长 lead** 均未验证。
2. **代码与数据不公开**：除 PlanetSWE（The Well）外，VF 与 RBC 的数据、实现、检查点、评估数据"需向通讯作者索取"——**复现门槛高**。
3. **RBC 只学 2D 中心切片的温度扰动**：不预测速度，也不预测三维温度场；因此"流场预测"的成色在三个系统中并不对等。
4. **运动没有物理解释**：作者明确定义"motion 由其在转移中的角色界定，不等同于物理速度或力"，这既是优点（无偏）也是局限（不可解释）。
5. **教师带来额外训练成本但无部署参数**：5.82 M 部署参数（教师不计）低于对照模型，但**训练时需同时跑两个编码器 + 两个分支的一步损失**，总训练开销更高（论文未给训练墙钟时间）。
6. **标量路径的对称性说明响应非线性**：响应依赖 $\alpha$ 的方式在 RBC/PlanetSWE 中不对称，说明运动的作用不是简单的"线性缩放"，模型行为难以用简单解析描述。
7. **单一随机种子**：所有比较似为单次训练，未见种子间方差——0.5%–2% 量级的差异（如 RBC 上各配置相差 <4%）可能落在训练噪声内。
8. **论文自陈的展望**：Teacher–student 结构提示了一条**不确定性估计**的路线——未来信息运动与历史推断运动之间的距离可度量"历史对下一步更新的决定程度"；但本文未实现。

## 实现建议

- **实现难度**：中—高。**架构本身不复杂**（冻结自编码器 + 两个 4 层 FNO 式运动编码器 + 3 残差块的共享转移），**真正的门槛在数据与训练纪律**：
  - 需要三套高质量 DNS 数据（本文自产了 VF 与 RBC）；
  - 需要保留跨滚动展开的梯度（显存开销大）；
  - 需要在**解码物理场**上做多步监督与评测（解码器冻结但必须前传梯度）。
- **预期性能**（在同等数据与算力下）：
  - 10 步 NRMSE：VF ~1.0%、RBC ~1.05%、PlanetSWE ~0.62%；20 步：~1.66% / ~1.68% / ~1.04%；
  - 部署参数量 **5.82 M**（+ 冻结自编码器 0.50–0.96 M）；
  - **更关键的是误差增长速率**：优势主要来自"递归时误差累积更慢"，而非单步更准——对长时间在线预测/控制而言这才是决定性的。
- **适用场景**：
  1. **长 lead 的自主流场预测**（如实时湍流代理、参数扫描、代理模型集合预报）；
  2. **递归部署的代理模型**（预测再输入）——这是 FAMIR 的目标场景；
  3. **需要保真统计量**（涨落谱、PDF）而不只是快照的场景（40 步统计检验）；
  4. **有大量离线 DNS 数据、可承受训练期双分支开销**的团队。
- **推荐结论**：✅ **推荐实现（方法论价值高，但需自行获取数据）**
  - **落地建议**：
    1. **最值得先复刻的最小闭环**：把"分离历史编码与状态更新"（即使不做教师）先做出来——消融显示**仅此一项**就优于同等规模的直接隐空间预测器（1.333% vs 1.416%、1.648% vs 1.890%、1.064% vs 1.617%）。这是**成本最低、收益最直接**的一步。
    2. **prediction-fed 训练是必须项**：单步训练在 PlanetSWE 上 +258.3%。务必让模型在**自己生成的预测**上训练，并保留跨展开梯度。
    3. **不要做单向蒸馏**：向固定教师蒸馏在 PlanetSWE 上比完全不用教师更差（1.874% vs 1.064%）。若要做对齐，**必须双向**（PPMA），让教师也被塑造成"可从历史逼近"的运动。
    4. **评测务必在解码物理场上做，且看廓线/PDF 而非仅看 NRMSE**：隐空间误差与物理误差的关联在 PlanetSWE 上几乎无关（$\rho_s=0.17$）；同时注意 PSNR 是对数平均，会被少数低误差 origin 抬高（VF 20 步 POD–Hankel DMD 的 PSNR 最高但 NRMSE 最差）。
    5. **模型区间要按功率覆盖率选**：本文用 $\mathcal{C}(\delta)$ 判据选 1.2 模拟单位 / 64 LBM 步 / 4 小时，分别覆盖 96.5% / 99.967% / 99.996% 的参考功率——**若采样过粗，隐空间就无法表示被丢掉的快变结构**，再好的模型也白搭。
    6. **流体内禀结构要对齐**：粘弹性构象带、RBC 羽流、行星纬向急流都是**尖锐且窄**的结构；编码器必须保留空间邻接（隐网格而非全局模态向量），且训练与评测都要覆盖这些结构所在的位置。
    7. **本库关联**：与 [[2025-Fluid-Intelligence-AI-Foundation-Models-CFD]]（本库已有）、[[Dynamic-Mode-Decomposition]]、[[Proper-Orthogonal-Decomposition]] 构成"降阶/代理模型"主题簇；本篇与本库已收录的 DSMC/旋转对流/DMD 系列笔记共同构成 2026-10-29 批次。
