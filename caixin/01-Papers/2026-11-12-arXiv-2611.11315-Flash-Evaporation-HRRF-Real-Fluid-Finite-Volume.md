## 核心贡献

> 推导**快速蒸发 Riemann 问题 (Flash evaporation Riemann problem, FeRP)** 在**有限速率相间传热传质**下的**非平衡 Riemann 问题**控制方程（机械平衡演化方程），并据此发展**无振荡 Homogeneous Relaxation Real Fluid (HRRF) 有限体积法**：除带质量弛豫的 Euler 方程外，**额外演化"内能–压力仿射参数"与"蒸气体积分数"的守恒型对流方程**，从而**消除守恒格式固有的数值压力振荡**，同时**保留相变引起的压力变化**，并在**超临界流动中一致退化为完全压力平衡格式**。

1. **问题重构**：经典 FeRP 描述的是**汽–液均相平衡极限**下的波结构。但**物理上的快速蒸发涉及有限速率的相间传热与传质**，这会使波结构**偏离平衡态**。
2. **推导核心方程**：在弛豫系统中推导**机械平衡演化的控制方程**（governing equation of mechanical equilibrium evolution）——这是 HRRF 格式的立论基础。
3. **提出 HRRF 有限体积法**（Oscillation-Free Homogeneous Relaxation Real Fluid）：
   - 演化 **Euler 方程 + 质量弛豫**；
   - **额外**演化 **内能–压力仿射参数**（internal energy–pressure affine parameters）的**对流方程**；
   - **额外**演化**蒸气体积分数**的对流方程。
4. **解决的核心矛盾**：守恒格式存在**固有数值压力振荡**；HRRF 通过引入仿射参数的对流演化**消除该振荡**，同时**保留相变引起的压力变化**（不牺牲物理效应）。
5. **一致性退化**：在**超临界流动**中，HRRF **一致退化为完全压力平衡 (completely pressure-equilibrium) 方法**——这保证了格式在无相变区的正确极限行为，是数值方法可信度的关键。
6. **系统性物理解析**：用 HRRF 全面评估**热力学弛豫如何影响 FeRP 解**，得到以下结论：
   - **非经典的膨胀激波**随弛豫时间增大**丧失行波特征**，**连续退化**为**自相似稀疏波 (self-similar rarefaction wave)**；
   - 相比平衡极限，**质量传递弛豫时间增大**会**平滑膨胀分支**、**降低中间压力与速度**、引发稀疏波的**伪分裂 (pseudo-splitting)** 以及相变起始点的**伪提前 (pseudo-advance)**；
   - **传热弛豫时间**则**主要决定汽液混合物中的温差**，进而调节**液体过热 (liquid superheat)**，并最终影响**质量传递速率**。

## 技术方案

### 核心思想

**闪蒸 (flash evaporation)** 是低温液体瞬时接触热壁面或低温壁面时的剧烈蒸发过程——工业上用于**低温推进剂贮存**（LNG/LOX）、**核燃料乏燃料池冷却**、**低温制冷**。

**经典 FeRP 的理想化**：假设汽液两相瞬间达到**均相平衡**（温度、压力、密度一致），此时蒸发潜热直接驱动压力上升。这个极限下的 Riemann 解有漂亮的解析结构（经典的膨胀激波 + 相变波）。

**现实的偏离**：真实闪蒸是**有限速率**的相间传热传质：
- 液相内部需要**过热**（superheat）才能提供汽化潜热——热量从壁面传到界面需要时间；
- 汽相形成后需要**扩散离开**——质量传递有限速率。

因此波结构**偏离平衡态**。这就要求一个**非平衡 Riemann 问题**的数值处理。

**核心难点：压力振荡**

守恒型有限体积（直接求解 Euler 方程）在相变界面附近会产生**数值压力振荡**。原因：
1. 相变界面两侧**声速、密度、焓剧烈不连续**；
2. 质量弛豫项（引入或移除质量）导致**能量与质量不再守恒地对应**；
3. 守恒变量在相变界面上的"跳跃"与波动捕捉格式的**数值耗散**相互作用 → 产生非物理的压力波（常见是**棋盘格/锯齿状振荡**）。

**HRRF 的解法思路 —— "仿射参数"是关键**

这是本文最精巧的部分。HRRF 不只是直接更新 $p$ 和 $\rho$，而是引入**内能–压力的仿射参数**，把状态方程的**局部线性化**显式地写进演化方程：

设状态方程在单元内近似为**仿射关系**（affine）：
$$p = p_{\mathrm{ref}} + a\,\Delta e$$
其中 $a = (\partial p/\partial e)_v$ 是**等容压力-内能导数**（真实流体 EOS 的局部斜率）。

于是演化两个额外的守恒量：
- **$a$**（或等价地，仿射参数）：对流输运
- **$\alpha$**（蒸气体积分数）：对流输运

再配合**质量弛豫**方程，得到压力与体积分数的**自洽演化**。

**为什么这能消除振荡？**

因为守恒格式的振荡根源是：**当质量在相变界面被"注入/移除"时，能量方程与压力更新之间的耦合是通过非线性的 EOS 隐式完成的**，这个隐式耦合在强非平衡下容易过冲/振荡。

HRRF 的做法是把 EOS 的**局部线性化显式化**：
- 每个单元的 $a$ 由对流方程独立演化（它"记住"了这个单元的局域热力学状态）
- 压力更新变成 $p = p_{\mathrm{ref}} + a\Delta e$ —— **一次线性关系**，不会有非线性过冲
- 体积分数 $\alpha$ 独立演化 → 界面位置与相分数的一致性更好

**"保留相变引起的压力变化"** 是关键卖点：很多消除振荡的做法（如简单的压力松弛到等压）会**把相变的物理效应也一起抹掉**。HRRF 保留之。

**"超临界一致退化"** 是数值方法的关键检验：在没有相变、流动超临界的区域，HRRF 应当**精确退化为**完全压力平衡格式（压力由 EOS 直接给出，不独立演化）。这确保格式不会在普通区域引入额外误差。

## 公式 / 理论要点

```math
% 带质量弛豫的 Euler 方程组（HRRF 的核心）
\partial_t \rho + \nabla\cdot(\rho\boldsymbol{u}) = 0
```

```math
% 质量弛豫（相变的有限速率表示）
\partial_t \rho + \nabla\cdot(\rho\boldsymbol{u})
= -\dot{m}_{\text{evap}} + \dot{m}_{\text{cond}},
\qquad
\dot{m}_{\text{evap}} = h_m\,(\alpha^* - \alpha),
\qquad
\alpha^* = \text{相平衡饱和体积分数}
```

```math
% 内能 - 压力仿射参数（HRRF 的关键构造）
p \approx p_{\mathrm{ref}} + a\,\Delta e,
\qquad
a = \left(\frac{\partial p}{\partial e}\right)_{v}
\quad\Longrightarrow\quad
\text{仿射参数 } a \text{ 独立对流演化}
```

```math
% 额外演化方程
\partial_t a + \nabla\cdot(a\boldsymbol{u}) = 0
\quad(\text{或带源项形式})
```

```math
% 蒸气体积分数演化
\partial_t \alpha + \nabla\cdot(\alpha\boldsymbol{u}) = \dot{m}_{\text{evap}}
```

```math
% 能量方程（HRRF 中不做压力松弛）
\partial_t (\rho E) + \nabla\cdot\big[(\rho E+p)\boldsymbol{u}\big]
= -\nabla\cdot\boldsymbol{q} + \nabla\cdot(\boldsymbol{\tau}\cdot\boldsymbol{u})
+ h\,\dot{m}_{\text{evap}}
```

```math
% 双弛豫时间（本文物理解析的核心参数）
\tau_{\text{mass}} \quad\Rightarrow\quad
\text{膨胀分支平滑、压力/速度下降、稀疏波伪分裂、}
\qquad
\tau_{\text{heat}} \quad\Rightarrow\quad
\text{汽液温差、液体过热、进而影响传质速率}
```

## 实验与结果

- **类型**: 数值方法开发 + Riemann 问题物理解析。
- **方法验证**: HRRF 有限体积法在闪蒸 Riemann 问题上：
  - **消除数值压力振荡**（相对守恒格式）；
  - **保留相变引起的压力变化**；
  - **超临界一致退化**为完全压力平衡方法。
- **物理解析结论**（FeRP 的非平衡结构）:
  - **非经典膨胀激波随弛豫时间增大 → 丧失行波特征 → 连续退化为自相似稀疏波**；
  - **传质弛豫时间 $\tau_{\text{mass}}$ 增大**（相对平衡极限）：
    - 平滑 **膨胀分支 (expansion branch)**；
    - **降低中间压力与速度**；
    - 引发稀疏波的**伪分裂 (pseudo-splitting)**；
    - 相变起始点**伪提前 (pseudo-advance)**；
  - **传热弛豫时间 $\tau_{\text{heat}}$**：
    - **主要决定汽液混合物中的温差**；
    - 调节**液体过热 (superheat)**；
    - 进而**影响质量传递速率**。
- **算例**: Flash evaporation Riemann problem（含超临界对照）。

## 局限性

- **仅一维 Riemann 问题**：HRRF 的核心验证是一维 Riemann 问题。多维复杂相变流动（池沸腾、闪蒸喷雾、大面积界面）中的表现需要另作验证。
- **仿射线性化的适用范围**：$p \approx p_{\mathrm{ref}} + a\Delta e$ 是**局部线性化**；在强非平衡、跨相大跳变区，仿射参数需要频繁更新或限制，单一 $a$ 可能不足。
- **真实流体 EOS 的处理**：真实气体 EOS（如 Peng–Robinson）本身有解析体积分数的饱和状态，但**非平衡下的相分数**需要额外处理（如本文用对流方程），这引入额外的建模选择。
- **松弛参数 $\tau_{\text{mass}}, \tau_{\text{heat}}$ 的确定**：物理取值依赖于界面传热传质模型（含湍流增强、界面面积变化），本文的解析结果是在给定参数下的。
- **单网格相变界面捕获**：仍依赖显式/隐式的网格尺度界面重构，未涉及**几何界面重构 (PLIC/VOF)** 与 DG 等前沿格式的结合。

## 实现建议

- **实现难度**: 中高 — HRRF 本身是对现有守恒格式的**结构性修改**（增加两个演化方程 + 修改压力更新），不需重写求解器框架，但**压力更新与相分数的一致性处理**需要仔细设计。
- **预期性能**: 额外两个标量场的对流演化，成本增量约 10–20%；远低于"加密网格 + AMR"的代价。
- **适用场景**:
  - **低温推进剂贮存与管路**（闪蒸、LNG 泄漏）；
  - **低温流体（液氢、液氧）加注过程**的数值模拟；
  - **核乏燃料池冷却 / 失水事故瞬态**（快蒸发 + 压力波动）；
  - **任何有强相变、压力敏感的过程**：HRRF 提供了"既要无振荡又要保物理"的实用折中；
  - **TVD/TVF 限制器兼容性**：两个新变量同样需要限制器。
- **可复用要点**:
  - **"把非线性隐式关系显式线性化"的格式设计范式**：当守恒格式出现振荡时，除了加限制器/加松弛，还有第三条路——**引入仿射参数把 EOS 的局部斜率变成独立演化的守恒量**。这是一个比"压力松弛"更物理的方案，值得推广。
  - **一致性退化的自检清单**：新格式必须能证明它在特殊极限下退化为已知正确的格式（本文：超临界 → 压力平衡格式）。这是**格式可信度的最低要求**。
  - **双弛豫时间解耦分析**：当一个物理过程含两个时间尺度时（传热 vs 传质），分别扫描并解耦其作用，是诊断复杂非平衡机制的通用手段。
  - **"非经典波 → 自相似波"退化路径**是很好的验证锚点：参数极限下的解析结构必须能被数值格式重现。
