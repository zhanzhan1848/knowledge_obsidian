# 稀聚合物动力学中格子 Fokker-Planck 方法的水动力相互作用

## 核心贡献

扩展**聚合物哑铃（dumbbell）的 BGK 型动力学模型**及其**格子玻尔兹曼实现**，纳入**流体动力学相互作用（hydrodynamic interaction, HI）**：

1. 准确恢复由 **Smoluchowski 方程**支配的**慢变量动力学**
2. **相比布朗动力学（BD）方法的优势**：
   - BD 需要在**每个时间步**计算**依赖构型（configuration-dependent）的扩散张量的平方根** → 计算代价高昂
   - 本动力学方法**实现直接**，**完全避免**这一开销
   - → **计算成本显著降低**
3. 在**定常与瞬态剪切流**中验证，成功捕捉**流体动力学相互作用在体相流变性质上的不同特征**

## 方法

### BGK 型聚合物动力学
哑铃模型（两个珠子 + 弹簧）的位置分布 $f(\bm{r}_1,\bm{r}_2)$ 满足带 HI 项的 Fokker-Planck 方程。

### Lattice Fokker-Planck (LFP) 实现
- 用**格子玻尔兹曼方法**求解 Fokker-Planck 方程（而非随机粒子方法）
- 关键：HI 项的**相互作用力**在 LBM 框架中通过格点动量交换自然实现

### HI 的处理
HI 对应链单体之间的**流体流体力**耦合（Oseen/Burchard 型）。在 LFP 中：
- 单体的阻力/速度受周围流体速度影响
- 通过 LBM 的格子速度场 + 动量交换计算单体间流体力

### 慢变量极限
HI 强时，链构象分布服从 **Smoluchowski 方程**（过阻尼极限的 Langevin 方程描述单体位置）：
$$
\frac{\partial f}{\partial t} = \nabla\cdot\left(D(\{\bm{r}\})\cdot\nabla f\right)
$$
其中 $D(\{\bm{r}\})$ 是**依赖构型的扩散张量**。

**关键工程点**：BD 方法需对 $D$ 求**平方根**（因为 BD 需要对角化/分解扩散张量）→ $O(n^3)$ 级别开销；LFP 直接求解 FPE，**无需平方根**。

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 离散化 | LBM（BGK）+ Fokker-Planck |
| 求解方式 | 确定性 PDE 求解（非随机） |
| 计算成本 | ✅ 显著低于布朗动力学（省去扩散张量平方根） |
| 时间步长 | LBM 稳定性（CFL） |
| 平行性 | ✅ 优秀（格点并行） |
| 验证 | 定常剪切流 + 瞬态剪切流 |

## 实验/验证结论

| 算例 | 结果 |
|---|---|
| 定常剪切流 | ✅ 复现 HI 对体相流变的不同影响 |
| 瞬态剪切流 | ✅ 同上 |
| 目标物理 | ✅ 准确恢复 Smoluchowski 慢变量动力学 |

## 局限性

- **哑铃模型**：只有 2 个单体 + 弹簧，无法描述**真实链的半柔性、有限伸长、多体相互作用**
- **稀溶液**假设（HI 对平均浓度不敏感 → 不含**排除体积**）
- **高斯链 / 理想链**假设（实际链在良溶剂中偏离高斯）
- BGK 是**单松弛时间** → 分子量依赖的**动力学非普适性**（最长松弛时间不标度）——这是 LBM 在聚合物动力学的已知缺陷
- 剪切流为**简单剪切**（不含延伸流场的复杂瞬态）

## 实现建议

- **实现难度**：🟡 中高。需实现：LBM 求解器 + FPE 耦合 + HI 力计算 + 弹簧势
- **预期性能**：相对 BD 有数量级优势（省去 $O(n^3)$ 张量分解）
- **适用场景**：
  - **稀聚合物溶液流变**（高分子增稠、聚合物驱油、涂料）
  - **胶体/悬浊液**（蛋白、多糖溶液的粘弹性）
  - **软物质**模拟（与 [[2026-11-06-arXiv-2611.07139-lattice-Boltzmann-machine]] 的"三个性质"框架配套）
- **落地建议**：
  - 优先复现**定常剪切流的黏度提升（viscosity enhancement）曲线**作为验收标准
  - 可考虑升级为 **FCHC 多松弛时间**以修复动力学非普适性
  - 与 **OpenFOAM 的 `polyMesh` 框架** 或自建 LBM 耦合；注意 HemeLB/waLBerla 亦可作为 LB 底座
  - 若关注"熵稳定性"，LFP 的 BGK 碰撞天然具有耗散性但非严格熵稳定 —— 可参考 [[2026-11-06-arXiv-2611.08395-ESE-entropy-variable-rarefied-NSF]] 的熵变量思路
