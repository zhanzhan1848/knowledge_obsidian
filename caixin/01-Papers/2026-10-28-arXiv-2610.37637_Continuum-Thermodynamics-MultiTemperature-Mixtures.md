## 核心贡献

> 构建化学反应的**多速度、多温度流体混合物的 Class-III 连续介质热力学模型**，用单一熵密度闭合各组分的部分平衡，并导出 Saha 型电离关系。

1. **单一熵密度闭合多组分平衡**：熵密度同时依赖各组分的质量密度与非动能内能密度，其偏导数直接给出**各组分温度 $1/T_i$** 与化学势 $-\mu_i/T_i$。
2. **加强熵原理给出加权 Euler 关系**：约束各组分的热力学分压 $p_i$，但只约束 $\sum_i p_i/T_i$ 的加权和而非单项。
3. **完整的本构关系构造**：粘性、热传导、Maxwell–Stefan 动量交换、热弛豫、非线性反应动力学，全部满足熵不等式；含热扩散及其互易耦合，并给出各向同性 co-factor 类内的完整互易补全。
4. **恢复 Saha–Eggert 关系**：在分辨电子能级的电离网络中，于共同温度下导出 Saha 型电离关系与 Boltzmann 激发比。

## 技术方案

### 核心思想

采用 Hutter & Jöhnk 的 **Class-I/II/III 层级**：

| 类别 | 质量平衡 | 动量平衡 | 能量平衡 | 温度 | 扩散通量 |
|---|---|---|---|---|---|
| Class I | 部分 | 混合物单一 | 混合物单一 | 共温 $T$ | 允许 |
| Class II | 部分 | 部分（分辨） | 混合物单一 | 共温 $T$ | 允许 |
| **Class III** | 部分 | 部分 | **部分（分辨）** | **各 $T_i$** | 允许 |

本文构造 **Class-III** 模型：各组分有独立的速度 $\bm{v}_i$、温度 $T_i$ 与内能 $e_i$。

### 关键技术

| 技术 | 说明 |
|------|------|
| 原始热力学变量 | 非动能内能密度 $\rho_i e_i$（熵共轭 $1/T_i$）；扩散动能 $\frac12\sum_i\rho_i\|\bm{u}_i\|^2$ 计入机械自由度而非热能 |
| 熵结构 | 非加性（可依赖全部组分能量与质量密度）；在稳定性与正性假设下，温度局部参数化热状态 |
| 熵通量 | 选定熵通量 + 独立处理体积形变 → 加强熵原理给出加权 Euler 关系 |
| 压强区分 | **力学分压** $P_i = -\tfrac13\mathrm{tr}\bm{S}_i$ vs **热力学分压** $p_i$（由零速率标量应力响应定义的额外状态函数） |
| 交叉效应 | 热扩散 + 其互易耦合；通过"熵不变混合 + 二元乘积非负闭合"实现 |
| 反应源项 | 每个已分辨的基元反应/能量交换过程同时给出正/逆速率、组分变化、每摩尔进度零和的目标能量增量 |
| 电离示例 | 分辨电子能级的电离网络，在详细平衡假设下导出 Saha–Eggert 关系 |

## 公式

### 1. 各组分平衡（质量、动量、总能量）

```math
\partial_t \rho_i + \operatorname{div}(\rho_i\bm{v}_i) = r_i
```

```math
\partial_t(\rho_i\bm{v}_i) + \operatorname{div}(\rho_i\bm{v}_i\otimes\bm{v}_i - \bm{S}_i)
= \rho_i\bm{b}_i + \bm{f}_i
```

```math
\partial_t\left(\rho_i e_i + \tfrac12\rho_i\|\bm{v}_i\|^2\right)
+ \operatorname{div}\left[\left(\rho_i e_i + \tfrac12\rho_i\|\bm{v}_i\|^2\right)\bm{v}_i
- \bm{S}_i\bm{v}_i + \bm{q}_i\right]
= \rho_i\bm{b}_i\cdot\bm{v}_i + k_i
```

总守恒要求：

```math
\sum_i r_i = 0, \qquad \sum_i \bm{f}_i = \bm{0}, \qquad \sum_i k_i = 0
```

### 2. 反应路径与质量产生

```math
\sum_i \alpha_i^a A_i \rightleftharpoons \sum_i \beta_i^a A_i,
\qquad
\nu_i^a := \beta_i^a - \alpha_i^a, \quad a=1,\dots,N_R
```

```math
r_i = M_i\sum_{a=1}^{N_R}\nu_i^a R_a, \qquad R_a = R_a^f - R_a^b
```

化学计量矩阵：$\bm{r} = S\bm{R}$，$S_{ia} := M_i\nu_i^a$。

**线性反应不变量**：$\ell\in\ker S^{\sf T}$ 时 $\sum_i \ell_i r_i = 0$。

### 3. 混合量定义

```math
\rho:=\sum_i\rho_i, \qquad \rho\bm{v}:=\sum_i\rho_i\bm{v}_i, \qquad
\bm{u}_i:=\bm{v}_i-\bm{v}, \qquad \bm{j}_i:=\rho_i\bm{u}_i
```

```math
\sum_i \rho_i\bm{u}_i = \bm{0}, \qquad \sum_i \bm{j}_i = \bm{0}
```

### 4. 热能与扩散动能分解（关键区别）

```math
\rho e := \sum_i \rho_i e_i \quad\text{（热能）},
\qquad
\tfrac12\sum_i\rho_i\|\bm{u}_i\|^2 \quad\text{（扩散动能，属机械自由度）}
```

### 5. 应力分解与两类分压

```math
\bm{S}_i = -P_i\bm{I} + \bm{S}_i^\circ, \qquad
P_i := -\tfrac13\operatorname{tr}\bm{S}_i, \qquad \operatorname{tr}\bm{S}_i^\circ = 0
```

**力学分压** $P_i$ 来自应力张量；**热力学分压** $p_i$ 是额外的状态函数（由零速率标量应力响应定义）。

### 6. 加权 Euler 关系（加强熵原理的产物）

共同膨胀/压缩给出约束：

```math
\sum_i \frac{p_i}{T_i}
```

——**只约束加权和，不约束单项** $p_i$。

### 7. Saha–Eggert 关系（共同温度极限）

在分辨电子能级的电离网络中，于详细平衡假设下得到 Saha 型电离关系与 Boltzmann 激发比，**在共同温度下恢复 Saha–Eggert 关系**。

## 实验结论

- 本文为**理论框架论文**，无数值实验。
- 关键验证性结果：
  1. 熵共轭的一致性由 **Liu 方法**（附录 C）独立复核——恢复熵共轭与残余不等式。
  2. 电离网络在共同温度下**恢复 Saha–Eggert 关系**，构成对模型正确性的强检验。
  3. 竞争性的电子过程与重粒子过程可在**不同规定温度**的组间维持稳态种群并传递能量。
- 适用域限制：$\rho_i > 0$，$T_i > 0$，在论文规定的热力学域内。

---

## 局限性

1. **边界本构关系与辐射/电磁场平衡不在本文范围**（明确声明）。
2. 数值标定需要**动力学理论、实验或材料信息**——连续介质模型本身不给出交换系数。
3. **热力学分压 $p_i$ 仅被加权和约束**，单项自由 → 存在不可辨识性，需要额外本构假设。
4. 互易补全仅在**"规定的各向同性 co-factor 类"内**线性给出，不是最一般的形式。
5. 与**分子动理学**的衔接（决定交换系数）尚需外部输入。
6. 与之前文献的关系已梳理：Müller 的共温理论、RET 中的多温 Euler 混合系、Rajagopal–Tao 的相互作用组分理论——本文的 Class-III 设定与之不同。

## 实现建议

- **实现难度**：高（理论框架，无现成代码）。落地需自行推导具体本构形式并做离散。
- **预期性能**：不适用（无算法性能问题）；难点在**模型闭合的一致性证明**而非计算效率。
- **适用场景**：
  - 非平衡多组分反应流（等离子体、电弧、强激波、多温度气体）
  - 需要严格熵一致性保证的闭合模型开发
  - Class-III → Class-II → Class-I 的降阶理论框架（作者后续论文的方向）
- **落地建议**：
  1. 若要数值实现，建议先用**基线模型**（粘性 + 热传导 + Maxwell–Stefan + 热弛豫 + 非线性反应），交叉效应（热扩散互易）作为可选模块
  2. 求解层面：Class-III 有 $N$ 套部分动量/能量方程 → 方程数与刚性显著增加；建议先做无反应、无相互作用的极限验证
  3. 用 **Liu 方法**复核熵共轭是廉价的自检手段
  4. 电离示例可作为验证算例（应自动复现 Saha–Eggert 关系）
- **后续关联**：作者指出本模型是后续论文的基础（识别满足 RET 通量–势兼容性的子类，做固定通量刚性、退化主子系统、Class-III→II→I 系统降阶）。
