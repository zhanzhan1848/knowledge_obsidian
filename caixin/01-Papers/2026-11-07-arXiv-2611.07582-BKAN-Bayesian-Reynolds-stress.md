## 核心贡献

> 用「可检查的样条边函数 + 变分贝叶斯后验」的 BKAN 同时解决数据驱动 RANS 闭合的两个痛点：**可解释性**与**预测置信度**，并把二者拆分为可传播的 epistemic / aleatoric 两分量。

1. **BKAN 闭合框架**：把张量基（Basis）表示与 Kolmogorov–Arnold 网络结合，网络边上是**可学习的单变量 B 样条**，可逐条可视化，形状简单时可符号化蒸馏为闭式表达式。
2. **不确定性严格二分**：通过异方差似然 + 后验采样，按全方差定律分解为 epistemic（训练数据有限导致的可约不确定性）与 aleatoric（高保真目标本身的不可约散布）。
3. **张量基硬约束**：伽利略不变性、旋转不变性、对称性、无迹性由张量基**构造性保证**；物理 realizability（特征值 ∈ [-1/3, 2/3]）则**单独软正则**处理。
4. **求解器级不确定性传播**：后验样本冻结场（frozen-field propagation）注入 RANS 求解器，得到风电场尾流的速度/湍流强度不确定度边界。

## 技术方案

### 核心思想

传统 RANS 闭合（线性涡黏）的问题**不是系数误差，而是结构性缺失**：分离、强流线曲率、二次运动等流动中，线性涡黏形式根本无法表达。数据驱动闭合可以补上这一块，但落地受限于两点——神经闭合「难以检视」，且「只给点预测、没有可靠不确定度」。

BKAN 的架构选择正好对症：
- **KAN 而非 MLP**：边上放可学习的一维函数 $\varphi(x)$，天然是一维的，**可以直接逐条画出来看**；形状简单时可符号回归。MLP 的内部映射是多层非线性纠缠，无法拆解。
- **Bayesian 而非确定性**：BNN 的内部难解释，BKAN 保留 KAN 的可检视结构，同时获得预测分布。
- **张量基而非原始坐标**：不变性由基本身编码，不需要靠损失项「惩罚」去学。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Pope 张量基** | $b_{ij}=\sum_{n=1}^{N} g_n T_{ij}^{(n)}$；不变性/对称/无迹**构造性保证**，基本身固定，只学系数 $g_n$ |
| **KAN 边函数** | $\varphi(x)=w_b b(x)+w_s\varphi_s(x)$，$\varphi_s(x)=\sum_c \theta_c B_c(x)$，$B_c$ 为给定节点网格上的 B 样条基函数，$\theta_c$ 可训练 |
| **变分贝叶斯** | 均值场高斯后验 $q_\psi$，$\psi=\{(\mu_i,\sigma_i)\}_{i=1}^P$；最大化 ELBO（Bayes-by-backprop, Blundell 2015） |
| **局部重参数化** | $\theta_k\sim\mathcal{N}(\mu_k,\sigma_k^2)$，因样条对系数线性，样条输出本身为高斯：均值 $\sum_k B_k(x)\mu_k$，方差 $\sum_k B_k(x)^2\sigma_k^2$，**无需逐系数采样** |
| **异方差高斯似然** | $\mathrm{NLL}=\tfrac12\sum_{c=1}^{d}\big[\log\sigma_c^2(\bm{\lambda})+(b_c-\hat b_c)^2/\sigma_c^2(\bm{\lambda})\big]$；方差头预测 aleatoric |
| **Realisability 软罚** | $R=\big\langle\max(0,\lambda_{\max}-2/3)^2+\max(0,-1/3-\lambda_{\min})^2\big\rangle$，权重 $\alpha$ 可调 |
| **双头共享骨干** | 共享 KAN 表征 → 一个头出 $g_n$，一个头出异方差 $\sigma_c^2$ |
| **Frozen-field 传播** | 独立抽后验样本 → 在计算网格上求值得**固定**修正场 → 每个场各跑一次 RANS 收敛；修正场在求解过程中**不重算** |
| **符号蒸馏** | 沿用 Liu et al. 2024 的符号回归流程对单条低维 KAN 边函数做逼近 |

### 公式

**预测方差分解**（全方差定律）：

$$\underbrace{\mathrm{Var}\big[b_{ij}\big]}_{\text{predictive}}=\underbrace{\mathrm{Var}_{s}\big[b_{ij}^{(s)}\big]}_{\text{epistemic}}+\underbrace{\mathbb{E}_{s}\big[\sigma_{ij}^{2}(\bm{\lambda})\big]}_{\text{aleatoric}}$$

**ELBO**：

$$\mathcal{L}(\psi)=\underbrace{\mathbb{E}_{q_{\psi}}\!\left[\log p(\mathcal{D}\mid\bm{\theta})\right]}_{\text{expected log-likelihood}}-\underbrace{D_{\mathrm{KL}}\!\left(q_{\psi}(\bm{\theta})\,\|\,p(\bm{\theta})\right)}_{\text{KL divergence}}$$

**KAN 边函数（局部重参数化后输出为高斯）**：

$$\phi(x)=w_{b}\,b(x)+w_{s}\,\phi_{s}(x),\qquad \phi_{s}(x)=\sum_{c}\theta_{c}\,B_{c}(x)$$

$$\mathbb{E}[\phi_s(x)]=\sum_k B_k(x)\mu_k,\qquad \mathrm{Var}[\phi_s(x)]=\sum_k B_k(x)^2\sigma_k^2$$

**Realisability 罚项**：

$$R(b_{ij})=\big\langle\max(0,\lambda_{\max}-\tfrac{2}{3})^{2}+\max(0,-\tfrac{1}{3}-\lambda_{\min})^{2}\big\rangle$$

## 实验结论

- **数据集/工况**：
  - 受控回归基准（controlled regression benchmark）——评估精度、标定、贝叶斯参数化选择
  - **Periodic hill**（DNS 参考）：分离剪切层 + 回流区
  - **Square duct**（DNS 参考）：二次流由 Reynolds 应力各向异性驱动（$\partial_x$ 法向应力差 + $b_{23}$ 生成流向涡量）
  - **三维风电场尾流**：转移学习到**未见过的布局**；$U_\infty=8$ m/s；剖面取第一台风机下游 $4D$ 尾流中心
- **基线**：匹配的**张量基 BNN**（均值场变分 MLP + 同样张量基重构 + 同样方差头 + 同样罚项 + 同样训练协议）；另有确定性基线与更大容量 BNN
- **结果**：
  - Periodic hill：各向异性 RMSE **0.046 ± 0.001**（3 个随机种子），种子敏感性低
  - Square duct：成功复现驱动二次流的剪切分量 $b_{23}$ 的空间结构与符号
  - **标定**：BKAN ECE ≈ **0.06**，小 BNN ≈ 0.09，宽 BNN ≈ 0.13。**增大 BNN 容量并未提升精度，反而标定更差**
  - 贝叶斯参数化选择：**把后验放在样条系数上**（spline coefficients）在精度/标定/参数成本/可解释性上综合最优
  - 风电场：基线 RANS 的尾流亏损偏弱，传播 BKAN 修正后尾流中心速度显著改善；修正量可**跨未见布局迁移**
  - 不确定度传播：aleatoric 分量以**空间相关场**形式注入（相关长度由训练工况残差场推断）

## 局限性

1. **几何外推下过度自信**（最重要的限制）：换到训练集没有的几何时，epistemic 不确定度**确实增大，但不足以覆盖误差增长**，出现明显 under-coverage 与误差排序恶化。→ **epistemic 增大本身不能当作「仍保持标定」的证据**；插值内可用，几何外推需谨慎。
   - 可能原因：均值场变分近似忽略后验相关性，偏离训练分布时低估 epistemic
   - 改进方向：后验 tempering、独立训练的多 BKAN 集成、低秩/全协方差/归一化流变分族、扩充训练集
2. **Realisability 只是被正则化，不是被保证**：无罚项时不可实现预测比例已经很小，在该训练预算下罚项**并未实质降低该比例或改善误差**。张量基保证不变性/对称/无迹，但**不约束特征值范围**。要严格保证需换参数化（如重心坐标约束到单纯形、或谱表示按构造限幅）。
3. **求解器级只做 frozen propagation**：修正场在 RANS 收敛期间**冻结不重算**，非全耦合 a posteriori 部署；aleatoric 的空间相关长度来自训练工况残差场，**其敏感性未考察**。
4. **符号蒸馏只针对单条低维 KAN 边函数**：不意味着完整张量基闭合总能化为紧凑解析式——尤其当张量基系数**不唯一可辨识**时。

## 实现建议

- **实现难度**：中高。需要 PyTorch + 自写样条基与局部重参数化 + 张量基重构 + 变分推断（可用 `torch.distributions` 或 `pyro`）
- **预期性能**：Periodic hill 级别工况（DNS ~1e7 网格点）在单 GPU 上可完成训练与后验采样；S=50~100 次后验采样在线累加矩（不存储 $O(S\times N)$ 数组）
- **适用场景**：
  - 需要**可审查**的 RANS 闭合（航空、汽轮机、风电 CFD 审稿场景）
  - 需要把闭合不确定度**传到求解器输出**（尾流亏损、载荷不确定度）
  - **不适用**于几何差异极大的外推场景，除非配合主动学习扩充训练集
- **推荐改进**：若要真正支持外推，优先做「后验 tempering + 多模型集成 + 训练集几何多样性扩充」三件套，而不是单纯加宽网络
