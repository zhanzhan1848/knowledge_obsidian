## 核心创新点

### 问题瓶颈
1. **单一神经网络无法同时解析近壁面边界层与远场势流**
2. **压力积分计算壁面速度梯度时数值不稳定，导致力预测不准确**

### DD-RNO 解决方案
- **区域路由机制 (Domain Routing)**：将流场分为无粘区、边界层区、尾迹区，由专用解码器处理
- **可学习规范求积 (LCQ)**: 用学习到的积分权重替代不稳定的压力积分

## 技术细节

### 架构
- **谱几何编码器 (Spectral Geometry Encoder)**
- **区域路由机制**: 可微分，物理引导
- **学习积分权重 (LCQ)**: 端到端预测升力/阻力

### 性能提升 (AirfRANS 基准)
| 指标 | 提升倍数 |
|------|---------|
| ux 场 MSE | 17x |
| uy 场 MSE | 12x |
| 分布外 Re 推算 | 23x |
| 阻力 MSE | 7.5x |
| 阻力等级相关 | 0.250 → 0.997 |
| 推理速度 | ~144 ms/sample (10,000x RANS) |

### 消融实验
- 移除区域路由 → 速度误差增加 8.2x
- 移除 LCQ → 相对阻力误差增加 40x+
