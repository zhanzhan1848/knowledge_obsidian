# 湍流中沉降椭球的取向与滑移统计

## 核心贡献

在小椭球（惯性数 $\ll 1$）湍流沉降的**过阻尼极限**下，描述取向与滑移统计：

1. **过阻尼取向动力学 = 球面上的精确梯度流**
   - 势能关于倾角余弦是**二次型**，仅被**迁移率各向异性**缩放
   - 取向在**二次势阱**中做过阻尼随机游走
   - 各向同性高斯白噪声 → **精确的 Boltzmann 分布**
2. **有限相关时间强迫**下的闭合：保持该形式，宽度由**线性响应**确定
   - 恢复"沉降消失 → 均匀密度"极限
   - 恢复"固定取向强迫统计"下**快速沉降理论的对齐系数**
   - 误差最大处是**过渡区**
3. **横向滑移 RMS**：
   - 峰值出现在**对齐率接近 Kolmogorov 率**处
   - 机制：更快沉降在给定倾角下增强侧向漂移，但抑制倾角
   - **近似形状无关的比值**（张量强迫模拟复现）→ 可用实测峰值**约束扭矩系数或耗散率**
4. **耗散间歇性** → Boltzmann 分布的**对数正态叠加**
   - 增厚尾部，但**不改变主导对齐的平均平方倾角**
   - 成功复现**平板取向分布的形状**（单个 Boltzmann 分布失败）
   - 已发表矩验证了**弱扭矩范围之外的展宽**；强对齐时实测四阶倾角矩**介于两种预测之间**

## 方法

### 取向动力学：梯度流

椭球在过阻尼极限（Stokes 阻力）下的取向动力学：
$$
\partial_t \bm{n} = -\nabla_{\bm{n}} U(\bm{n}), \qquad U(\bm{n}) = \frac{\tau_0}{2}\left(1 - \kappa\,(\bm{n}\cdot\hat{\bm{z}})^2\right)
$$
其中 $\bm{n}$ 为颗粒长轴方向单位矢量，$\hat{\bm{z}}$ 为重力方向，$\kappa$ 由迁移率各向异性与惯性扭矩决定。

**关键结构**：势能关于 $\cos\theta$ 是**二次型** → 随机游走于二次阱 → 精确 Boltzmann 分布：
$$
P(\theta) \propto \exp\left(-\frac{U(\theta)}{T_\text{eff}}\right)
$$

**白噪声情形**：各向同性高斯白噪声下，$P(\theta)$ 精确为 Boltzmann 分布（这在一般随机 ODE 中并不成立，此处因二次势而特殊）。

### 有限相关时间强迫的闭合
- 强迫时间 $\tau$ 有限 → 不是 Markov 过程
- 闭合后仍保持 Boltzmann 形式，**宽度由线性响应确定**
- 极限验证：
  - 沉降速度 $\to 0$ → 均匀密度
  - 固定取向强迫统计 → 快速沉降理论（rapid-settling theory）的对齐系数

### 横向滑移
$$
\text{RMS lateral slip} = \text{函数}(\text{对齐率}, \text{耗散率})
$$
- 峰值条件：**对齐率 $\approx$ Kolmogorov 耗散率**
- 形状无关比值（shape-independent ratio）是被 tensor-forcing 模拟复现的关键可检验预测

### 耗散间歇性
- 耗散率的间歇性 → Boltzmann 分布族的**对数正态叠加**：
$$
P(\theta) = \int p_\text{lnorm}(\epsilon)\, P_\text{Boltz}(\theta; \epsilon)\,d\epsilon
$$
- 效果：**尾部增厚**，但主导对齐的平均平方倾角不变

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 类型 | 解析理论 + 统计力学闭合 |
| 随机性 | 精确 Boltzmann 分布（白噪声）；线性响应宽度（有限相关时间） |
| 数值需求 | 仅需 Monte Carlo 采样 $\theta$ 的扩散过程 |
| 验证数据 | DNS 平板取向分布 + 已发表矩 + 张量强迫模拟 |
| 物理覆盖 | 过阻尼极限（惯性数 $\ll 1$） |

## 实验/验证结论

| 检验 | 结果 |
|---|---|
| 平板取向分布形状 | ✅ 叠加模型成功，单 Boltzmann 失败 |
| 已发表矩（弱扭矩外） | ✅ 展宽被确认 |
| 强对齐四阶倾角矩 | 介于两种预测之间 |
| 形状无关比值 | ✅ 张量强迫模拟复现 |
| 快速沉降理论对齐系数 | ✅ 被恢复 |

## 局限性

- **仅过阻尼极限**：惯性数 $\gg 1$ 或中间区未覆盖
- **板状/球状形状参数化**：单一 $\kappa$ 描述各向异性，中等长宽比（$1:3$）可能需更细
- 有限相关时间闭合是**近似**（过渡区误差最大）
- 对数正态叠加假设耗散间歇性可用对数正态刻画（实际多重间歇性可能更复杂）
- 未考虑**有限 Re 惯性**、**形状记忆效应**（如柔性颗粒）

## 实现建议

- **实现难度**：✅ 低（解析模型 + Monte Carlo）
- **预期性能**：可作为**颗粒取向 PDF 的快速前向模型**，嵌入 DEM/欧拉-欧拉多相流框架
- **适用场景**：
  - 湍流中**纤维/椭球/片状颗粒**的取向预测（化学工业、造纸、颗粒输运、藻类输运）
  - 颗粒**沉降速度与侧向漂移**估算
  - 大气中花粉/沙尘的取向统计（本文作者关联 physics.ao-ph）
- **落地建议**：
  - 与 [[2026-11-06-arXiv-2611.07666-SINDy-Rayleigh-Taylor]] 类似思路：本文模型本身即"物理约束的统计闭合"，可嵌入 SINDy 框架自动发现更复杂依赖
  - 在 OpenFOAM 的 **MPPIC / MPPICFoam** 中作为取向亚模型
  - 关键可检验预测：**横向滑移峰值位置**（对齐率 ≈ Kolmogorov 率）与**形状无关比值** → 适合实验设计
