## 创新点

- **PASSC 框架** (PINN-Augmented SUPG with Shock-Capturing)：在 SUPG 稳定化解的基础上，用 PINN 后处理修正
- **保守空间-时间控制体形式** + 宏观守恒窗口 + 熵容许性惩罚
- **可激波加权数据一致性损失**：将有限元解作为 PINN 的锚点

## 数值方法

| 项目 | 内容 |

| 约束 | 控制体守恒 + 熵容许性 + 边界条件 |

## PASSC 架构
```
FEM solution (SUPG stabilized)
    → Physics-informed NN correction
    → Shock-weighted data-consistency loss
    → Entropy penalty + BC constraints
```

## 评估

- 修正目标：减少激波附近离散化振荡和网格尺度锯齿
- 保持与解析/半经验基准的吻合
- 物理约束深度集成是该方法的核心优势

**评估：✅ 推荐实现**

适用于高马赫数气体动力学问题，PINN 修正层提供数据驱动的激波平滑而不破坏守恒性。
