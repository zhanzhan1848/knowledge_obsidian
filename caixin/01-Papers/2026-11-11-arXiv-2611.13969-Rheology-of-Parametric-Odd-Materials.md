## 核心贡献

> 提出并刻画了一类**平台无关的奇黏弹性材料 (odd viscoelastic material)**：其复杂响应来自对**内部转动自由度**的**参数化控制**，并由**法向应力与剪切应力的耦合**触发；进一步发现该耦合可以诱导**转动驱动的流变 (rotation-driven fluidisation)**，使材料从**弹性主导**转变为**黏性主导**；并证明**奇扇区与偶扇区的相互作用**在**大幅振荡剪切 (LAOS)** 下增强非线性响应——最终给出**可编程非互易流变的 Floquet 元流体**路线。

1. **奇黏弹性材料模型**：提出平台无关的"odd viscoelastic"体系——此前文献多聚焦于**奇黏性 (odd viscosity)** 或**奇弹性 (odd elasticity)**，完整的**奇流变 (odd rheology)** 模型稀缺。
2. **参数化驱动机制**：复杂响应的来源是**内部转动自由度的参数化控制**，可经由**参数化驱动**或**参数化非线性反馈**实现。
3. **应力耦合触发**：法向应力与剪切应力的**耦合**是触发复杂响应的机制。
4. **转动驱动流变 (rotation-driven fluidisation)**：应力耦合可诱导该转变——材料从**弹性主导**过渡到**黏性主导**。这是一个**相变式的流变状态切换**。
5. **LAOS 中的奇偶相互作用**：奇扇区与偶扇区的相互作用增强**大幅振荡剪切**下的非线性材料响应（奇偶耦合是非线性性的来源）。
6. **Floquet 元流体**：给出通过 **Floquet 工程**实现**可编程非互易流变**的路径。

## 技术方案

### 核心思想

**奇 (odd) 物质**的标志是**手性 (chirality)**：在三维中，绕轴旋转的粒子会引入一个与转动轴同向的额外力矩，其大小与角速度成正比。经典结果：

- **奇黏性 (odd viscosity)**：$\boldsymbol{\tau}^{\text{odd}}_{ij} = \eta_o\,(\boldsymbol{\omega}\cdot\boldsymbol{\delta}_{ij}- \boldsymbol{\epsilon}_{ijk}\omega_k)$——在三维中贡献一个**纯扭矩**，不改变净力。
- **奇弹性 (odd elasticity)**：角动量作为广义坐标的弹性势能。

但**完整的"奇流变"**——即同时包含奇黏性与奇弹性、并能产生可测复杂响应的**完整本构框架**——此前缺失。这正是本文要补的。

本文的关键设计是**参数化 (parametric)** 驱动：**奇**物质需要**转动的内部自由度**（微观转子/陀螺）。但如何**主动控制**这些自由度？答案不是靠外部流动被动激励，而是**参数化调制**：周期性地改变体系参数（转动惯量、耦合强度、驱动频率等），使系统进入**准周期 (Floquet) 动力学**。

而**法向应力–剪切应力耦合**是触发复杂响应的关键通道：在常规材料中，法向应力与剪切应力在时间上是"错开"的（相位差 $\pi/2$，如线性黏弹性中储能/耗能模量的分离）。通过参数化调制**打破这一时间对称性**，两种应力分量就能直接耦合，从而激发真正的非线性响应——这是 Floquet 驱动产生非互易性的典型机制。

**转动驱动流变 (rotation-driven fluidisation)** 是本文最有意思的现象：当参数化调制与应力耦合共同作用时，材料内部的转动自由度被充分激发，系统的耗散结构改变，行为从**弹性主导**（储能主导，回复性）转变为**黏性主导**（耗散主导，流动化）。这类似于"转子驱动流化"在颗粒介质中的类比。

### 关键技术

| 技术 | 说明 |
|------|------|
| 奇黏弹性本构 | 同时含奇黏性 + 奇弹性的完整本构框架 |
| 内部转动自由度 | 奇性的微观来源（转子/陀螺） |
| 参数化驱动 (parametric driving) | 周期调制体系参数，进入 Floquet 动力学 |
| 参数化非线性反馈 | 参数化控制的另一种实现路径 |
| 法向–剪切应力耦合 | 触发复杂响应的核心通道 |
| 转动驱动流变 (fluidisation) | 弹性主导 → 黏性主导的相变式切换 |
| LAOS 分析 | 大幅振荡剪切下的应力–应变响应（分解为弹性/塑性、奇/偶） |
| 奇偶扇区相互作用 | 非线性响应的来源 |
| Floquet 工程 | 可编程非互易流变的实现路径 |
| 平台无关性 | 模型不依赖具体实现（转子类型、驱动方式） |

## 公式 / 理论要点

```math
% 奇黏性应力（纯扭矩，不改变净力）
\boldsymbol{\tau}^{\text{odd}}_{ij}
= \eta_o\left(\boldsymbol{\omega}\cdot\boldsymbol{\delta}_{ij}
-\epsilon_{ijk}\omega_k\right)
```

```math
% 奇弹性：角动量为广义坐标的势能
E_{\text{odd}} = \frac{1}{2}\,\kappa_{\text{odd}}\,
|\boldsymbol{J}-\boldsymbol{\Omega}_{\text{int}}|^2
\quad\Longleftrightarrow\quad
\boldsymbol{\tau}^{\text{odd,el}} \propto
\boldsymbol{\epsilon}_{ijk}J_k
```

```math
% 参数化驱动：周期调制参数（Floquet）
\boldsymbol{\Omega}_{\text{int}}(t) \ \text{由}\ 
\mu(t),\, \kappa(t),\, \omega_d(t)\ \text{调制}
\qquad \text{其中}\ \mu(t+T)=\mu(t)
```

```math
% 法向应力–剪切应力耦合（触发通道）
\big\langle \sigma_{nn}\,\tau_{xy}\big\rangle \neq 0
\qquad\text{（常规材料：}\langle \sigma_{nn}\tau_{xy}\rangle=0\text{）}
```

```math
% 转动驱动流变：弹性主导 → 黏性主导
\text{储能模量占比} G'/(G'+G'') \ \text{下降},
\qquad
\text{耗散占比} G''/(G'+G'') \ \text{上升}
```

```math
% LAOS 分解（弹性/塑性 + 奇/偶分量）
\boldsymbol{\sigma}(t)
= \boldsymbol{\sigma}_{e}(t)+\boldsymbol{\sigma}_{p}(t),
\qquad
\boldsymbol{\sigma}_{e}:\ \text{弹性（可回复）},\ \
\boldsymbol{\sigma}_{p}:\ \text{塑性（耗散）}
```

```math
% 非互易性：正反加载响应不对称
\boldsymbol{\sigma}(\gamma)\neq \boldsymbol{\sigma}(-\gamma)
\quad\Longrightarrow\quad
\text{非互易流变（手性）}
```

## 实验与结果

- **研究对象**: 参数化驱动的奇黏弹性材料（平台无关的建模框架）。
- **对比基线**: 常规（偶）黏弹性材料；纯奇黏性或纯奇弹性模型。
- **主要结果**:
  - **完整奇流变框架建立**：给出含奇黏性 + 奇弹性的统一本构，填补"奇流变模型稀缺"的空白。
  - **参数化控制**：通过参数化驱动或参数化非线性反馈实现对转动自由度的控制。
  - **法向–剪切耦合触发复杂响应**：$\langle \sigma_{nn}\tau_{xy}\rangle \neq 0$ 是复杂响应出现的标志。
  - **转动驱动流变**：实现**弹性主导 → 黏性主导**的状态切换。
  - **LAOS 非线性增强**：奇扇区与偶扇区的相互作用增强非线性响应。
  - **Floquet 元流体**：给出**可编程非互易流变**的工程路线。

## 局限性

- **建模层面**：本文是**建模与机制研究**，未提供具体材料的制备方案或实验装置。
- **平台无关性**是优点也是代价：具体平台的参数（转子惯量、驱动频率范围）差异大，结论的可量化转移需重新标定。
- **线性化假定**：奇黏弹性框架通常建立在小变形/线性区；强非线性（有限应变、显著惯性）的推广未涉及。
- **耗散与稳定性**：参数化驱动会引入净能量注入，"流变"状态是否热力学上自洽（熵产非负）未在摘要中讨论。
- 未涉及**实际流变测量**（如 LAOS 实验的应力分解验证）与**微观结构表征**。

## 实现建议

- **实现难度**: 中 — 建模层面为主；数值实现需在分子动力学或连续体本构框架中耦合转动自由度与参数化调制。
- **预期性能**: 机制可解释、参数可控（Floquet 参数即控制旋钮）；适合做**参数扫描**式的响应面设计。
- **适用场景**:
  - **主动材料与超材料设计**（可编程黏弹性、非互易器件）；
  - **微流控中的手性输运**（转子驱动的手性泵/阀）；
  - 生物模拟：**奇黏性是细菌悬液中运动自发性的标准模型**，本文的参数化奇流变扩展提供了新的操控维度；
  - **软物质流变学教学**（奇扇区的引入顺序）。
- **可复用要点**:
  - **"法向–剪切应力耦合的非零平均"是一个可计算的"复杂度开关"**：任何线性黏弹性体系该平均恒为零，一旦在实验或模拟中测到非零，说明存在超出线性理论的结构（本文为参数化驱动，也可能是非线性本构）。这是一个很好的**判别指标**，可推广到任何黏弹性表征流程中。
  - **"弹性主导→黏性主导"的流变相变**提供了超出传统粘弹谱图的**状态判据**：仅看 $G'$、$G''$ 不足以描述这类体系，需引入**能量注入/耗散比**。
  - **Floquet 调制是一种通用的"可控非互易"工具**：其思路（用周期参数调制打破时间反演对称性）可迁移到其他需要手性/非互易响应的系统设计，与本轮 [[2026-11-11-arXiv-2611.14104]] 中"本构模型的瞬态响应决定失稳存在性"的结论互相呼应——**瞬态与参数调制是很多体系的关键自由度**。
