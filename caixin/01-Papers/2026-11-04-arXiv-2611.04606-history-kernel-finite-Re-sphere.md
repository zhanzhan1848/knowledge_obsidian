## 核心贡献

> 系统地从**轴对称 Navier-Stokes 直接数值模拟**中提取固定球体在**有限雷诺数**下的**历史核（history kernel）**，建立"滞后时间 + 源时刻雷诺数"的二维核函数 $K(s,\mathrm{Re})$，超越 Basset 蠕流极限，并在中高 Re 下揭示核函数的**非单调行为**（对应边界层与尾流的延迟调整）。该核无需逐算例标定即可显著优于文献中的已有公式。

1. **有限 Re 历史力模型**：保留纯滞后卷积形式，但雷诺数取**源时刻**（source time）而非观测时刻：
   $$\mathbf F_H(t)=\Phi\int_0^t a_\infty(t-s)K(s,\mathrm{Re}(t-s))\,ds$$
   这是与既有文献公式的关键区别。
2. **核的归一化与极限约束**：$R(s,\mathrm{Re})=K(s,\mathrm{Re})/K_B(s)$，要求 $R\to 1$ 当 $s\to 0$ 且 $R\to 1$ 当 $\mathrm{Re}\to 0$（自动满足 Basset 极限与蠕流极限）。
3. **数值提取方法**：从有限时长的加速/减速 ramp 的轴对称 NS 仿真中反演核面，**远尾用尾流渐近式外推**（解决有限滞后窗口问题）。
4. **Leibniz 法则处理 Re 依赖**：对含 $\partial K/\partial\mathrm{Re}$ 的卷积项，通过**同时拟合带符号的加速与减速 ramp 并外推到零加速度**消去该项。
5. **非单调核的物理解释**：高 Re 下核在**中等滞后**区间非单调，来源于**边界层与尾流的延迟调整**（delayed adjustment of boundary layer and wake）。
6. **免标定预测能力**：对有限 ramp、振荡强迫、非周期复合速度历程均优于文献公式，**无需逐算例调参**。

## 技术方案

### 核心思想

在**有限雷诺数**下，颗粒的历史力（history force）不再满足简单的 Basset 卷积形式。既有公式（如 Elghorra 等）通常只对特定速度历程标定过。本文的核心思路是：

**把"流体的记忆"参数化为一张核面 $K(s,\mathrm{Re})$，其中 $s$ 是滞后时间、$\mathrm{Re}$ 是源时刻雷诺数**。然后通过**系统设计的加速/减速 ramp 仿真**反演这张核面。

关键洞察：对 ramp 历程 $u_\infty(t-s)=u_0+\alpha(S-s)$，雷诺数沿轨迹线性变化 $\mathrm{Re}(t-s)=\mathrm{Re}_0+\Gamma(S-s)$，$\Gamma=2\alpha$。由 Leibniz 法则：

$$\frac{1}{\alpha}\frac{dF_H}{dS}=K(S,\mathrm{Re}_0)+\Gamma\int_0^S\frac{\partial K}{\partial\mathrm{Re}}(s,\mathrm{Re}_0+\Gamma(S-s))\,ds$$

第二项可通过**加速/减速符号对称拟合**外推消去，从而**逐点提取** $K$。

### 关键技术

| 技术 | 说明 |
|------|------|
| 轴对称 NS 求解 | 不可压 NS，无旋（swirl-free）假设；球体固定于原点 |
| 稳定化等阶 FEM | 速度与压力用 $P_1P_1$；全隐式二阶 BDF；阻尼 Newton 法 |
| 网格 | 三角单元为主 + 球面附近四边形边界层单元；$M/M_1/M_2$ 三区渐进加密；约 $6.1\times10^4$ 单元 |
| 线性求解器 | PARDISO 直接法（双精度），约 $9.5\times10^4$ 自由度 |
| Ramp 设计 | 有限时长常加速 ramp；**51 个初始 Re**（0.2–200）；每个 Re 至少 6 个带符号增量（≥3 正 ≥3 负）|
| 尾流渐近外推 | 超出解析滞后窗口的核值用远尾渐近式延拓 |
| 核归一化 | $R(s,\mathrm{Re})=K(s,\mathrm{Re})/K_B(s)$，$K_B(s)=1/\sqrt{\pi s}$ |

## 公式

```math
% ===== Basset 型历史力 =====
\boldsymbol F_H(t)=\Phi\int_0^t\boldsymbol\alpha(\tau)K_B(t-\tau)\,d\tau,
\qquad \boldsymbol\alpha(\tau)=\frac{d}{d\tau}[\boldsymbol u(\tau)-\boldsymbol v(\tau)],
\qquad \Phi=6\pi r\mu

% ===== 有限雷诺数核（本文核心）=====
\boldsymbol F_H(t)=\Phi\int_0^t a_\infty(t-s)K(s,\mathrm{Re}(t-s))\,ds,
\qquad \mathrm{Re}(t-s)=\frac{\rho_f d\,|u_\infty(t-s)|}{\mu},\ d=2r

% ===== 无量纲化 =====
\hat t=\frac{\nu_f t}{r^2},\quad \hat s=\frac{\nu_f s}{r^2},\quad \hat u=\frac{ru}{\nu_f},\quad
\mathrm{Re}(t)=2|\hat u_\infty(t)|

% ===== 核的直接反演 =====
K(S)=\frac{1}{\alpha}\frac{dF_H}{dS}

% ===== ramp 情形下 Re 随滞后线性变化 =====
F_H(S)=\alpha\int_0^S K\big(s,\mathrm{Re}_0+\Gamma(S-s)\big)\,ds,\qquad \Gamma=2\alpha

% ===== Leibniz 分解（Re 依赖项的消去依据）=====
\frac{1}{\alpha}\frac{dF_H}{dS}=K(S,\mathrm{Re}_0)+\Gamma\int_0^S\frac{\partial K}{\partial\mathrm{Re}}\big(s,\mathrm{Re}_0+\Gamma(S-s)\big)\,ds

% ===== 归一化核与极限 =====
R(s,\mathrm{Re})=\frac{K(s,\mathrm{Re})}{K_B(s)},\qquad K_B(s)=\frac{1}{\sqrt{\pi s}}
R\to 1\ (s\to 0),\qquad R\to 1\ (\mathrm{Re}\to 0)

% ===== 粘性耗散尺度预测（湍流类比）=====
\eta\omega_k^2/\ell_k\sim\epsilon \Longrightarrow \ell_\eta\propto\eta^{1/3}
```

## 代码片段

```python
# 伪代码：核反演（ramp 历程）
def extract_kernel(FH_history, alpha, S, Re0, Gamma):
    """由 ramp 仿真历史反演 K(S, Re0)。
    加速与减速各一组，用于消去 ∂K/∂Re 卷积项。"""
    dFH_dS = np.gradient(FH_history, S)
    K_acc  = dFH_dS / alpha                    # 含 ∂K/∂Re 项
    K_dec  = dFH_dS_dec / (-alpha)             # 反号加速
    # 对加速度做外推到 0：K = 1/2 (K_acc - K_dec) （符号对称消去）
    K_extrap = 0.5 * (K_acc - K_dec)
    # 归一化到 Basset 核
    R = K_extrap / (1.0/np.sqrt(np.pi*S))
    return R

# 轴对称 NS 求解设置（OpenFOAM/FEM 均类似）
mesh:
  domain:   axisymmetric r-z, sphere at origin
  elements: 6.1e4 (tri + quad BL layers)
  BL:       6 layers, first layer height 5e-4 r, growth 1.2, surface 0.005 r
discretization: P1P1 stabilised, fully implicit BDF2, damped Newton
linear_solver:    PARDISO (direct, double precision), ~9.5e4 DOF
```

## 实验结论

- **数据集/算例**：固定球体在空间均匀非定常流中；有限时长加速/减速 ramp；初始 Re 从 0.2 到 200（51 个值）。
- **基线**：文献中已有的历史力公式（针对特定历程标定）。
- **结果**：
  - 提取的核面在**短滞后**恢复 Basset 极限，在**蠕流极限**恢复 $\mathrm{Re}\to 0$ 行为；
  - **高 Re 下核在中等滞后区间非单调** —— 反映边界层/尾流的延迟调整；
  - 对有限 ramp、振荡强迫、非周期复合速度历程，本文核**无需逐算例标定**即显著优于文献公式；
  - 结论：**滞后时间与雷诺数两个参数即可刻画主导的记忆响应**。

---

## 局限性

- **轴对称、无旋假设**：所有算例需低于球体尾迹的首个对称性破缺分岔（$\mathrm{Re}\approx 212$），本文最高到 Re=200，恰好卡在边界上；Re > 212 时该假设失效。
- **球体固定**：未处理球体自身的运动（运动球体的附加质量/加速度问题）。
- 核的**远尾延拓依赖渐近假设**，在中等 Re 下的精度受限。
- 数值求解使用**直接法（PARDISO）**，自由度增长后不可扩展到大规模 3D 算例。
- 加速/减速 ramp 的"外推到零加速度"是一种**外推技巧**，对复杂历程（如强非线性加速）的推广性未验证。

## 实现建议

- **实现难度**：✅ 中等偏上。需要：轴对称 NS 求解器（FEM 或 FV）+ 设计 ramp 仿真矩阵 + 核反演与外推 + 与文献公式对比。
- **预期性能**：一次核面提取（51 Re × 6 ramp = ~300 个算例）后，可**零成本**复用到任意速度历程的历史力计算。核本身只是一张查表。
- **适用场景**：
  - ✅ 颗粒/气泡在非定常流中的历史力（FSI、多相流、沉降）
  - ✅ 需要跨 Re 范围迁移（不做逐算例标定）
  - ✅ 作为**解析修正项**嵌入 CFD 求解器（比直接解析球体流更省）
  - ❌ 不适用于高 Re（>212）尾迹非对称场景
- **落地建议**：可直接作为 CFD 中的**球体阻力/升力历史力子模型**接入。需要注意的是：高 Re 下核非单调，插值必须**保形**（单调三次样条），否则会引入非物理的负阻力。
