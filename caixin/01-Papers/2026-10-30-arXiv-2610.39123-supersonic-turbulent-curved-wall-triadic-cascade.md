## 核心贡献

> 用**尺度分辨 TKE 预算 + 三波能量传递双谱 (bispectrum) + SPOD + 全局 resolvent 分析**四条工具链，厘清**凸/凹曲面**上超声速湍流边界层中**线性放大机制**与**非线性三波级联**的分工，并提出一个关键论断：凹曲面上外层能量流向的是**流流向涡破碎 (streamwise vortex breakdown)**，而**不是**三维逆向级联。

1. **四工具联合诊断**：尺度分辨的 TKE 预算、三波能量传递双谱、SPOD、全局 resolvent 分析——分别提供"能量收支""非线性耦合结构""相干结构识别""线性放大与拓扑"四类互补信息。
2. **凹曲面（失稳曲率）**：
   - 失稳的曲率**增强压力-应变 (pressure-strain) 再分配**，把近壁湍流推向**双分量 (two-component)** 状态；
   - 诱导出**低展向波数下的剪切驱动外层生成峰 (shear-driven outer-layer production peak)**；
   - 双谱与 SPOD 揭示外层能量向**基本大尺度与展向均匀模态**做**结构化的多步三波传递**，物理上表现为**流流向涡破碎**，而非三维逆向级联。
3. **凸曲面（稳定化曲率）**：
   - 稳定化曲率与**膨胀 (dilatation)** **削弱压力涨落**、**抑制压力-应变再分配**，**打断近壁湍流循环**；
   - 能量被困在**拉长的单分量流流向条纹 (one-component streamwise streaks)** 中；
   - 局部的 **resolvent wavemaker** 为下游恢复区提供能量。
4. **线性 vs 非线性的分工**：非线性三波相互作用**选择主导尺度的幅值**，而相干结构的**空间拓扑**由**线性平均流感受性 (receptivity)** 与**空间发展对流不稳定性**决定。
5. **可压缩性与压力梯度的区分**：方法同时分离了可压缩性效应与压力梯度效应。

## 技术方案

### 核心思想

超声速湍流边界层的能量传递涉及两个正交的问题：

- **非线性问题**：能量如何在湍流尺度之间传递（三波相互作用 / 广义能量级联）；
- **线性问题**：哪些模态能被平均流放大、由什么机制放大（感受性 + 对流不稳定性）。

本文的主张是：**这两者不是同一回事**。非线性三波耦合决定"哪个尺度获得多少能量"，而"这个能量在空间上如何组织"由线性机制决定。

在**曲面壁面**上，二者被解耦得特别清楚：

- **凹曲面**：曲率使外层流线发散 → 压力下降 → 压力-应变项加强近壁的**再分配**，把近壁两分量湍流向单分量/双分量状态推；同时外层出现低展向波数的**剪切生成峰**。这份外层能量通过**多步三波耦合**流向大尺度、展向均匀的模态——表现为**流流向涡破碎**（streamwise vortex breakdown），即流流向涡管在近壁处被拉伸、倾斜并最终破碎。
- **凸曲面**：曲率使外层流线收敛 → 压力上升 → 压力涨落被削弱，近壁压力-应变再分配被抑制 → **近壁湍流自持循环被打断** → 能量被困在拉长的单分量条纹里；同时局部线性机制（resolvent 的 wavemaker）向下游恢复区泵入能量。

### 关键技术

| 技术 | 说明 |
|------|------|
| **直接数值模拟 (DNS)** | 三维可压缩瞬态 Navier-Stokes；超声速壁面湍流需要壁面分辨（$y^+ \approx 1$）与极小时间步 |
| **尺度分辨 TKE 预算 (scale-resolved TKE budget)** | 对每个波数 $k$ 逐项闭合生产、输运、耗散、压力-应变，得到**局地点谱能量收支**——区分线性（平均流）与非线性（三波）贡献 |
| **压力-应变相关 $m_{ij}$** | 湍流动量输运方程中的关键项，控制近壁两分量/单分量状态的转换；曲率通过其改变而发挥作用 |
| **三波能量传递双谱 (triadic energy-transfer bispectrum)** | $B(k_1,k_2,k_3)$ 三波耦合谱，识别能量如何从一个波数对流向第三个波数；区分**相向传递**与**相斥传递** |
| **SPOD (谱本征正交分解)** | 提取相干结构（大尺度模态、展向均匀模态）；在相干结构上做时频分析识别破碎事件 |
| **全局 resolvent 分析** | 求解线性响应算子的 SVD，得到最不稳定响应 $\psi$ 与对应激励（wavemaker）；**wavemaker 的位置即线性放大源区** |
| **线性平均流感受性 (receptivity)** | 特定扰动在平均流中的增长率与空间结构；决定相干结构拓扑 |
| **空间发展对流不稳定性** | 沿流向放大的二维/准二维模态（如文丘里/边界层对流失稳），在凸面下游恢复区起主导作用 |
| **可压缩性 vs 压力梯度解耦** | 密度梯度引起的膨胀/压缩效应与壁面曲率引起的压力梯度效应在诊断中分别隔离评估 |
| **超声速边界：壁面热传导** | 绝热壁或温度壁面条件影响壁面层结构（超声速边界层可能存在温度层与速度层的竞争） |

## 公式

```math
\text{可压缩 TKE 方程（尺度分辨形式，方法层面）}:\quad
\partial_t k + \bm{u}\cdot\nabla k
= \underbrace{P_k}_{\text{平均流生成}}
- \underbrace{\epsilon}_{\text{耗散}}
- \underbrace{\Pi}_{\text{压力输运}}
+ \underbrace{T_k}_{\text{湍流输运}}
\ \ \Longrightarrow\ \
\text{对每个波数 } k \text{ 逐项闭合}
```

```math
\text{压力-应变相关（控制两分量/单分量状态）}:\quad
m_{ij}
= \overline{\left(u_i' u_j'\,\frac{\partial \overline{u}_i}{\partial x_j}
+ \overline{u_i' u_j' u_k'\frac{\partial u_k'}{\partial x_j}\right)}
\quad\Longrightarrow\quad
\overline{u_i'u_i'}\,\delta_{ij}-m_{ij}:\ \text{射动张量的各向异性}
\]

```math
\text{三波能量传递双谱（三波耦合的本质形式）}:\quad
B(k_1,k_2,k_3),\qquad
\underbrace{k_1+k_2+k_3=0}_{\text{波矢闭合}}
\quad\Longrightarrow\quad
\text{能量从 }(k_1,k_2)\text{ 流向 }k_3
```

```math
\text{三波耦合对模态幅值的动力学贡献（形式）}:\quad
\frac{d|\bm{a}_n|^{2}}{dt}
= 2\sigma_n|\bm{a}_n|^{2}
- \sum_{m,k}\!{}' \left(\text{三波耦合项}\right)
\quad\Longrightarrow\quad
\text{非线性作用决定"哪个尺度拿到多少能量"}
```

```math
\text{全局 resolvent 分析}:\quad
\bm{z} = \mathcal{R}\,\bm{f}
\quad\Longrightarrow\quad
\max_{\|\bm{f}\|=1}\|\mathcal{R}\bm{f}\|
\ \text{ 的 SVD：}\ \psi_1\ (\text{最优响应}),\ \phi_1\ (\text{wavemaker})
```

```math
\text{感受性（线性放大，拓扑决定）}:\quad
\frac{\partial \bm{q}}{\partial t}
= \mathcal{L}_{\text{mean}}\bm{q},
\qquad
\mathcal{L}_{\text{mean}}\bm{q} = (\sigma + i\omega)\bm{q}
\quad\Longrightarrow\quad
\text{决定相干结构的空间拓扑}
```

```math
\text{曲率的两种效应（凸 vs 凹）}:\quad
\begin{cases}
\text{凹（发散）}: & \text{压力下降} \;\Rightarrow\; \text{压力-应变增强} \;\Rightarrow\; \text{近壁趋于两分量 + 外层剪切生成峰} \\[2pt]
\text{凸（收敛）}: & \text{压力上升} \;\Rightarrow\; \text{压力涨落削弱} \;\Rightarrow\; \text{近壁循环中断 + 单分量条纹被困}
\end{cases}
```

> 注：原文双谱的具体归一化、TKE 预算的谱分解方式、resolvent 的算子构造与特征值需参照正文；摘要未披露具体系数，上式为方法层面的本质表达。

```python
# 概念性伪代码：曲面超声速湍流边界层的 DNS + 四工具诊断
import numpy as np

def run_curved_wall_dns(curvature, U_inf, M_inf, T_inf, wall_bc="adiabatic"):
    """
    curvature: "concave" | "convex"，以壁面法向曲率 κ_w 设定
    """
    # --- 几何：圆柱面段（凹/凸），壁面法向变化产生曲率效应 ---
    mesh = build_wall_bounded_domain(curvature_type=curvature,
                                    kappa_w=kappa_w, Lx=..., Ly=..., Lz=...,
                                    wall_resolution="y+~1")

    # --- 边界 ---
    bc = {
        "wall":    wall_bc,                  # 温度壁面 / 绝热壁
        "freestream": (T_inf, U_inf, M_inf),
        "outflow": "characteristic_based",   # 超声速出流需特征边界
    }

    solver = CompressibleDNS(mesh, scheme="6th-order-central", MUSCL_optional=False)
    u, T = init_bl_profile(), init_T_profile()

    for n in range(n_steps):
        u, T = solver.step(u, T, dt=cfl_based(u_max, sound_speed, dx_min))
        # 记录用于谱分析的快照（等时间间隔，满足 Nyquist）
        if n % snapshot_stride == 0:
            snapshots.append(field_snapshot(u, T))

    return snapshots, mesh


# --- 工具 1: 尺度分辨 TKE 预算 ---
def scale_resolved_tke_budget(snapshots, mesh, filter_widths):
    """
    对每个滤波尺度/波数闭合 TKE 预算，分离：
      - 平均流生成 P_mean（线性）
      - 非线性输运（隐含于过滤后的非线性项）
      - 压力-应变再分配 m_ij
    """
    for k in filter_widths:
        k_flux = filter_energy_flux(snapshots, k)
        P_k     = mean_flow_production(snapshots, k)
        Pi      = pressure_strain(snapshots, k)
        eps_k   = dissipation(snapshots, k)
        budget[k] = dict(flux=k_flux, production=P_k, pressure_strain=Pi, diss=eps_k)
    return budget


# --- 工具 2: 三波能量传递双谱 ---
def triadic_bispectrum(snapshots, kx_range, ky_range, kz_range):
    """
    B(k1,k2,k3) 满足 k1+k2+k3=0；正/负号区分相向与相斥传递
    """
    B = np.zeros((len(kx_range), len(ky_range), len(kz_range)))
    for i, k1 in enumerate(kx_range):
        for j, k2 in enumerate(ky_range):
            k3 = -(k1 + k2)
            k3_idx = nearest_index(kz_range, k3)
            if k3_idx is None: continue
            B[i, j, k3_idx] = triadic_transfer(snapshots, k1, k2, k3)
    return B


# --- 工具 3: SPOD ---
def spod(snapshots, n_modes=20):
    """SPOD 模态 + 其时间系数的时频分析（用于识别 vortex breakdown 事件）"""
    S = spatial_snapshots_matrix(snapshots)
    L, Q = spod_decomposition(S, n_modes)          # L: 模态, Q: 时频能量
    return L, Q


# --- 工具 4: 全局 resolvent 分析 ---
def global_resolvent(snapshots, mean_flow, Lx, Ly, Lz):
    """
    线性响应算子 R: f -> z，输出最优响应 psi1 与 wavemaker phi1
    wavemaker 位置 = 线性放大源区
    """
    R = build_linear_response_operator(mean_flow, Lx, Ly, Lz)   # 可压缩算子需线性化
    psi1, sigma1, phi1, freq = resolvent_svd(R, n_modes=4)      # 交替方向法求主奇异方向
    return dict(response=psi1, growth=sigma1, wavemaker=phi1, freq=freq)


# --- 综合诊断 ---
def interpret(curvature, budget, B, spod_modes, resolvent):
    findings = []
    # 凹: 压力-应变增强 -> 两分量近壁；外层低展向波数剪切生成峰
    if curvature == "concave":
        assert budget["pressure_strain"]["near_wall"]["anisotropy_boost"] > 0
        # 双谱: 外层能量 -> 大尺度展向均匀模态（多步传递）
        assert np.all(B["outer_to_large_scale"] > 0)
        # SPOD: 检测到流流向涡破碎事件
        assert detect_streamwise_vortex_breakdown(spod_modes)
        findings.append("streamwise vortex breakdown (NOT 3D inverse cascade)")
    else:
        assert budget["pressure_strain"]["near_wall"]["anisotropy_boost"] < 0
        assert resolvent["wavemaker"]["location"] in "downstream recovery region"
        findings.append("one-component streaks + localized resolvent wavemaker")
    return findings

## 实验结论

- **数据集/算例**：连续施加**凹曲面**与**凸曲面**壁面曲率的**超声速湍流边界层** DNS。
- **基线/对照**：两种曲率构型之间的对比（凹 vs 凸）；非线性机制（三波双谱）与线性机制（resolvent、感受性）之间的对比。
- **结果**：
  - **凹壁面**：失稳曲率增强压力-应变再分配 → 近壁湍流趋向**双分量状态**；诱导**低展向波数下的剪切驱动外层生成峰**。双谱与 SPOD 表明外层能量经**结构化的多步三波传递**流向**基本大尺度与展向均匀模态**，物理表现为**流流向涡破碎**，而**不是三维逆向级联**。
  - **凸壁面**：稳定化曲率与膨胀**削弱压力涨落**、**抑制压力-应变再分配** → **近壁湍流循环被打断** → 能量被困在**拉长的单分量流流向条纹**中；**局部 resolvent wavemaker** 为**下游恢复区**注入能量。
  - **分工结论**：非线性三波相互作用**决定主导尺度的幅值**，而相干结构的**空间拓扑**由**线性平均流感受性**与**空间发展对流不稳定性**决定。
  - 方法同时分离了**可压缩性**与**压力梯度**的各自作用。

## 局限性

- **DNS 代价与参数空间**：超声速湍流边界层的壁面分辨 DNS 时间步由声速限制（Courant 数需很小），流向/展向/法向均需巨大网格；"连续施加曲率"意味着存在多个曲率段构型，算例量庞大。
- **双谱的统计噪声**：三波双谱需要大量互不相关的样本（每对 $(k_1,k_2,k_3)$ 都要累加），高波数区的置信度差；相位平均与周期平均的选择会影响"相向 vs 相斥"的判定。
- **"非逆向级联"论断的检验强度**：区分"三波级联"与"逆向级联"依赖谱通量的精细分析，而"流流向涡破碎"与"逆向级联"在某些谱区间上会产生相似的能量流向特征，需要 SPOD 与双谱的一致性来支撑；该判断的普适性依赖所选波数范围。
- **resolvent 的线性化偏差**：全局 resolvent 分析基于平均流的**线性化**，忽略非线性反馈与湍流本底（需用 resolvent-DMD 或本征算子近似修正）；凸面结论中"wavemaker 位置"的可靠性受此限制。
- **壁面热条件的敏感性**：超声速壁面湍流中温度层与速度层的相互作用强烈依赖壁面热条件（绝热 vs 等温），摘要未指明采用的设定，直接影响两分量/单分量状态的形成机制。
- **上游/下游条件**：壁面曲率起始点之前需要有已充分发展/充分湍流化的来流，结果依赖于"给定入口湍流度"；下游的恢复区长度取决于出口处理。
- **工程相关性**：真实的高超声速飞行器表面曲率是三维、渐变且与激波/分离/再附强烈耦合的；本文的纯壁面曲率构型是理想化机制研究，距离实际气动热环境仍有距离。
- **"压力-应变增强"的归因**：曲率既通过平均流梯度直接改变线性生成项，也通过压力场改变非线性再分配，两者在 TKE 预算中的分离依赖滤波尺度选择，存在尺度依赖性。

## 实现建议

- **实现难度**：🔴 极高。需要：可压缩壁面分辨 DNS（含特征边界出流、热壁处理）、尺度分辨 TKE 预算的滤波/分解实现、3D 双谱的高效计算（$O(N_k^2)$ 样本累加）、SPOD 时频分析、以及线性化响应算子的构建与交替方向法（ADM）求解。任一环节的实现细节都会显著影响结论。
- **预期性能**：DNS 为主瓶颈（$dt \sim dx/a$，墙元尺度需极小）。降本路线：(a) 用 RANS/LES 产出的快照做**后处理诊断**（TKE 预算、双谱、SPOD），仅在关键机制点上做 DNS 标定；(b) 双谱在同向/均匀展向的**二维化截面**上计算可把 $O(N_k^3)$ 降到 $O(N_k^2)$；(c) resolvent 用**降阶模型 + ADM**，避免直接对全三维算子做 SVD。
- **适用场景**：高超声速飞行器表面曲率效应与热流预测；机翼/钝头体再附与恢复区分析；层流-湍流转捩控制（传感器布置）；以及更一般地，**"线性放大 vs 非线性级联"分工诊断**的方法学，可推广到任何存在强壁面几何效应的湍流边界层（亚声速压缩性边界层同理）。
- **落地建议**：先把**曲率效应的归因做分离**——同一算例中分别扫描"平均流曲率梯度（线性）"与"压力-应变再分配（非线性）"的贡献，验证"凹壁面外层生成峰"究竟是线性驱动还是非线性驱动；壁面热条件应作为独立参数扫描（绝热 vs 等温）；结论引用时务必带上"具体壁面热条件 + 曲率段长度 + 入口湍流度"这三个前提，否则跨构型外推风险大。

## 数值实现补充（2026-10-31 深挖 arXiv HTML 全文）

### 求解器与离散格式
- **求解器**：**BASIC (2026.10)** —— 模块化高保真 **Python** 流求解器，作者自研，近期扩展到曲线坐标并**全 GPU 加速**（Volpiani 2026）
- **空间离散**：优化的 **11 点中心差分**（Volpiani 2024），宽波数范围内**形式六阶精度**
- **滤波**：优化的 **11 点六阶空间滤波**（非耗散中心格式的稳定化），抑制网格间振荡而不损 DNS 保真度
- **时间推进**：显式**五阶低存储 Runge-Kutta**（优化系数），最小化数值耗散、色散与内存占用
- **网格生成**：**双曲线（hyperbolic）网格生成器**，强制近壁正交性 → $\xi$ 与 $\eta$ 方向分别与曲面相切/法向

### 控制方程（广义曲线坐标）
```math
\frac{\partial \mathbf{Q}}{\partial t}
=\frac{1}{\mathcal{J}}\left(
-\frac{\partial \hat{\mathbf{F}}}{\partial \xi}
-\frac{\partial \hat{\mathbf{G}}}{\partial \eta}
-\frac{\partial \hat{\mathbf{H}}}{\partial \zeta}
+\frac{\partial \hat{\mathbf{F}}_{v}}{\partial \xi}
+\frac{\partial \hat{\mathbf{G}}_{v}}{\partial \eta}
+\frac{\partial \hat{\mathbf{H}}_{v}}{\partial \zeta}
\right)
```
守恒变量 $\mathbf{Q}=[\rho,\rho u,\rho v,\rho w,E_t]^T$；$\mathcal{J}=\det(\partial(x,y,z)/\partial(\xi,\eta,\zeta))$。

**无量纲化**：长度 $\delta_i$，速度 $c_\infty$（故非无量纲来流速度 = 马赫数），密度 $\rho_\infty$，粘性 $\mu_\infty$，压力 $\rho_\infty c_\infty^2$，温度 $(\gamma-1)T_\infty$。
**流场条件**：$M_\infty=2.0$，$Re_{\delta_i}=7894$，$\gamma=1.4$，$Pr=0.368$（层流），完全气体。

### 网格与边界条件
- **平板基线**：$2668\times384\times324$ 网格点，域长 $100\delta_i\times18\delta_i\times10\delta_i$
- **壁面单位分辨率**：$\Delta\xi^+=5.94$，$\Delta z^+=4.76$，$\Delta\eta^+=0.46$（首个壁法向点）
- $\Delta\xi^+$ 在壁面与边界层边缘间变化 **< 2%**
- **4 个曲率构型**：$r/\delta_i=\pm150$（凹/凸）后接**直线恢复段**
- **进口**：合成湍流入口，**数字滤波技术（digital filter technique）**，从白噪声合成满足给定长度尺度与参考雷诺应力的湍流
  - 流向/法向/展向扰动积分长度尺度：**$0.6\delta_i$、$0.3\delta_i$、$0.3\delta_i$**
  - 基于 Volpiani et al. (2018) 的 $Re_\tau=140$ DNS 数据库
- **出口/顶部**：**曲坐标版 NSCBC**（Landmann et al. 2010）
- **壁面**：无滑移
