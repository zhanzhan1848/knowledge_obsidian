## 核心贡献

> 用**折射率匹配**的硅油–糖水系统实现**同步 PIV + PLIF 相分辨测量**，首次系统刻画**不可混液射流从过渡到湍流**（$Re=125$–1700）的主导不稳定机制切换，并把**液滴聚并**引入 1D 群体平衡模型（PBM），显著改善液滴尺寸分布预测。

1. **主导失稳机制的系统性切换**（POD 分析 PLIF 体分数场）：
   - 低 $Re$：**轴对称 Rayleigh–Plateau 模态**主导
   - 过渡区：**正弦（sinuous）与卵形（varicose）模态共存**
   - 高 $Re$：**Kelvin–Helmholtz 驱动的剪切层破碎**主导
2. **CNN（U-Net）语义分割**提取液滴尺寸，稳健处理失焦背景结构。
3. **过渡区的双峰液滴尺寸分布**：反映**剪切诱导破碎与 Rayleigh–Plateau 不稳定共存**；$Re$ 升高后分布**收敛为单峰且特征尺寸更小**。
4. **PBM 加入聚并**：显著改善与实验的吻合，**对大液滴尤其明显**。
5. **相分辨（油/水）平均速度与雷诺应力统计**。
6. **连续相粘度比 $\mu_d/\mu_c$ 的参数研究**：低 $\mu_d/\mu_c$ → 分布更平、大液滴更多；高 $\mu_d/\mu_c$ → 偏向小液滴。

## 技术方案

### 核心思想

不可混液射流破碎的**竞争机制**：Rayleigh–Plateau（毛细主导）vs Kelvin–Helmholtz（剪切主导）——密度比 $\rho_d/\rho_c\approx1.20$ 接近 1，两者势均力敌，故 $Re$ 提升会主导机制切换。

### 关键技术

| 技术 | 说明 |
|------|------|
| 折射率匹配 | 硅油 PDMS (RI 1.4004) + 39% w/v 糖水 (RI 1.4002) |
| 同步测量 | PIV（532±5 nm 窄带）+ PLIF（560 nm 长通，Nile Red 染料） |
| 光学 | 高速 Nd:YLF 激光 (DM30-527)；双 Phantom VEO 640L；**Δt 脉冲间隔 500 μs**；1000 fps；2560×1600 px；FoV 140×87 mm；**≈18 px/mm**；激光片厚 ≈0.5 mm |
| 标定 | 双平面靶标（黑底白点阵）+ 微动位移台 |
| POD | 快照法（Sirovich 1987），$N_s=2000$ 张 PLIF 快照（$Re=125,600,1000$） |
| 液滴分割 | **U-Net**（200 张人工标注 + 增强）+ MATLAB regionprops |
| 条纹去除 | 变分方法（Rottmayer et al. 2025） |
| PBM | Aiyer & Meneveau (2020) 1D 模型 + **聚并扩展**（本工作） |

## 公式

### 1. 无量纲群

```math
\mathrm{Re}=\rho_dV_{mean}D/\mu_d,\qquad
\mathrm{We}=\rho_cV_{mean}^2D/\sigma,\qquad
\mathrm{Oh}=\frac{\mu_d}{\sqrt{\rho_d\sigma D}}
```

额外群：$\rho_d/\rho_c$、$\mu_d/\mu_c$。

### 2. POD（快照法）

```math
\bm{C}=\frac{1}{m}\bm{X}'^{\top}\bm{X}',\qquad \bm{C}\bm{v}_j=\sigma_j^2\bm{v}_j
```

```math
\bm{\phi}_j=\frac{1}{\sqrt{m}\,\sigma_j}\bm{X}'\bm{v}_j,\qquad
\langle\bm{\phi}_i,\bm{\phi}_j\rangle=\delta_{ij},\qquad
E_j=\frac{\sigma_j^2}{\sum_{k=1}^m\sigma_k^2}
```

### 3. 相分辨统计

```math
\Phi(r,z,t)=\begin{cases}1,&\text{oil present}\\0,&\text{water present}\end{cases}
```

```math
V_{i,o}(r,z)=\frac{1}{\langle\Phi\rangle N}\sum_{k=1}^{N}\Phi(r,z,t_k)v_i(r,z,t_k),\qquad
V_{i,w}(r,z)=\frac{1}{N-\langle\Phi\rangle N}\sum_{k=1}^{N}[1-\Phi(r,z,t_k)]v_i(r,z,t_k)
```

```math
\langle v_{i,o}'v_{j,o}'\rangle=\frac{1}{\langle\Phi\rangle N}\sum_{k=1}^{N}\Phi\,v_i'v_j',\qquad
\langle v_{i,w}'v_{j,w}'\rangle=\frac{1}{N-\langle\Phi\rangle N}\sum_{k=1}^{N}[1-\Phi]v_i'v_j'
```

### 4. 分布定义

```math
P_n=\frac{n_i}{N\times\Delta d},\qquad
P_v(d)=\frac{d^3P_n(d)}{\int_0^\infty d^3P_n(d)\,dd}
```

### 5. PBM：浓度与输运

```math
\tilde{c}(z,r)=\sum_{k=1}^{M}\tilde{n}_k\Omega_k,\qquad \Omega_k=\frac{\pi}{6}D_k^3
```

```math
v\frac{\partial(\tilde{n}_k\Omega_k)}{\partial z}+u\frac{\partial(\tilde{n}_k\Omega_k)}{\partial r}
=\left(\mathcal{B}_k+\mathcal{C}_k\right)\Omega_k
+\frac{\mathcal{D}_t}{r}\frac{\partial}{\partial r}\!\left(r\frac{\partial(\tilde{n}_k\Omega_k)}{\partial r}\right)
```

```math
\frac{V_{exit}}{V_c(z)}=\frac{1}{C_m}\left(\frac{z}{D}-\frac{z_v}{D}\right),\qquad r_{1/2}(z)=K(z-z_v)
```

### 6. 中心线约化

```math
\frac{d\tilde{n}_{c,k}}{dz}=\left[\mathcal{B}_k(z,0)+\mathcal{C}_k(z,0)\right]\frac{z}{V_{exit}C_mD}-\frac{\tilde{n}_{c,k}(z)}{z}
```

```math
\sum_{k=1}^{M}(\mathcal{B}_k+\mathcal{C}_k)\Omega_k=0
```

### 7. 破碎源项

```math
\mathcal{B}_k(z,0)=\sum_{l\ge k}\lambda(z,0,D_l)\tilde{n}_{c,l}\big[\Phi_b(D_k,D_l)+\tilde{\Phi}_b(D_k,D_l)\big]-\lambda(z,0,D_k)\tilde{n}_{c,k}
```

### 8. 子液滴概率与表面能

```math
\Phi_b(D_k,D_l)=\frac{E_{\min}+(E_{\max}-E(D_k))}{\sum_{m=1}^{l-1}[E_{\min}+(E_{\max}-E(D_m))]}
```

```math
E_{\max}=\pi\sigma D_l^2(2^{1/3}-1),\quad
E_{\min}=\pi\sigma[(D_l^3-D_{\min}^3)^{2/3}+D_{\min}^2-D_l^2],\quad
E(D_k)=\pi\sigma[(D_l^3-D_k^3)^{2/3}+D_k^2-D_l^2]
```

$D_{\min}=10\ \mu$m。

### 9. **聚并源项（本工作新增）**

```math
\mathcal{C}_k(z,0)=\frac{1}{2}\sum_{i=1}^{M}\sum_{j=1}^{M}w_k\big(\tilde{D}_{ij}\big)C(D_i,D_j)\tilde{n}_{c,i}\tilde{n}_{c,j}
-\tilde{n}_{c,k}\sum_{j=1}^{M}C(D_k,D_j)\tilde{n}_{c,j}
```

```math
\tilde{D}_{ij}=(D_i^3+D_j^3)^{1/3}
```

（因子 ½ 防止重复计数。）

### 10. 聚并速率

```math
C(D_i,D_j)=K_cA_{ij}(v_i^2+v_j^2)^{1/2}P_{ij};\qquad A_{ij}=\frac{\pi}{4}(D_i+D_j)^2
```

```math
v_i=1.03(\varepsilon D_i)^{1/3}
```

### 11. 聚并效率与接触时间

```math
P_{ij}=\exp(-t_{ij}/\tau_{ij});\qquad
\tau_{ij}=\frac{r_{ij}^{2/3}}{\varepsilon^{1/3}};\qquad
r_{ij}=\frac{1}{2}\left(\frac{2}{D_i}+\frac{2}{D_j}\right)^{-1}=\frac{D_iD_j}{4(D_i+D_j)}
```

```math
t_{ij}=\left(\frac{r_{ij}^3\rho_c}{16\sigma}\right)^{1/2}\ln\!\left(\frac{h_0}{h_f}\right)
```

$h_0=1\times10^{-4}$ m，$h_f=1\times10^{-8}$ m。

### 12. 空间变化的聚并系数

```math
K_c(z)=K_{c,\infty}+(K_{c,0}-K_{c,\infty})\exp\!\left(-K\frac{z-z_0}{D}\right),\qquad z_0=C_mD
```

### 13. 中心线浓度与耗散率

```math
\tilde{c}_c(z)=\frac{Q_i\beta^2(2\mathrm{Sc}_T+1)}{\pi V_c(z)(z-z_v)^2},\qquad
\beta^2=(\sqrt{2}-1)/K^2,\qquad \mathrm{Sc}_T=0.7
```

```math
\varepsilon(z)=C_\varepsilon\frac{V_{exit}^3}{D}\left(\frac{z}{D}-\frac{z_v}{D}\right)^{-4},\qquad C_\varepsilon=65
```

### 14. 谱耗散估计（修正 PIV 探测窗滤波）

```math
\tilde{E}_{11}(k_1)=|\hat{G}(k_1)|^2E_{11}(k_1),\qquad E_{11}(k_1)=\frac{\tilde{E}_{11}(k_1)}{|\hat{G}(k_1)|^2}
```

```math
E_{11}(k_1)=\frac{18}{55}C_k\varepsilon^{2/3}k_1^{-5/3},\qquad
\varepsilon=\left(\frac{55}{18C_k}k_1^{5/3}E_{11}(k_1)\right)^{3/2}
```

（$C_k=3/2$；方法源自 Xu & Chen 2013。）

### 15. 破碎闭合（附录 B）

```math
\lambda(D_k)=K_s\int_0^{D_k}\frac{\pi}{4}(D_k+\phi_e)^2u_e(\phi_e)P_b(D_k,\phi_e)\,dn_e(\phi_e)
```

```math
\mathcal{F}(r)=C_2\varepsilon^{2/3}r^{2/3}\left[1+\left(\frac{r}{\gamma_2\eta_k}\right)^{-2}\right]^{-2/3}\quad\text{(Batchelor)}
```

```math
P_b(D_k,\phi_e)=\exp\!\left[-\frac{E_\sigma(D_k)+E_\nu(D_k)}{E_e(\phi_e)}\right]
```

```math
E_\sigma(D_k)=0.0702\pi\sigma D_k^2,\qquad
E_\nu(D_k)=\frac{\pi}{6}\alpha\varepsilon^{1/3}D_k^{7/3}\mu_d\sqrt{\frac{\rho_c}{\rho_d}},\qquad
E_e(\phi_e)=\frac{3}{2}\frac{\pi}{6}\rho_c\phi_e^3\mathcal{F}(\phi_e)
```

**无量纲形式**：

```math
\lambda=\frac{K^*}{\tau_{b,k}}\int_0^1r_e^{-11/3}(r_e+1)^2\left[1+\left(\frac{r_eRe_k^{3/4}}{\gamma_2}\right)^{-2}\right]^{-1/3}P_b(Oh_k,Re_k,\Lambda;r_e)\,dr_e
```

```math
P_b=\exp\!\left[-\frac{\Lambda\psi}{Re_k}\left[1+\left(\frac{r_eRe_k^{3/4}}{\gamma_2}\right)^{-2}\right]^{2/3}r_e^{-11/3}\right],\qquad
\psi=0.14\frac{\Lambda}{Re_k\cdot Oh_k^2}+0.583
```

常数：$C_2\approx2.1$，$\gamma_2=(15C_2)^{3/4}\approx13$，$\alpha\approx2$，$\tau_{b,k}=\varepsilon^{-1/3}D_k^{2/3}$，$Re_k=\varepsilon^{1/3}D_k^{4/3}/\nu$，$\Lambda=(\mu_d/\mu_c)\sqrt{\rho_c/\rho_d}$，$n_e\propto\phi_e^{-3}$。

### 16. 相似性解（附录 A）

```math
\frac{\partial v}{\partial z}+\frac{1}{r}\frac{\partial(ru)}{\partial r}=0,\qquad
v\frac{\partial v}{\partial z}+u\frac{\partial v}{\partial r}=\nu_T\frac{1}{r}\frac{\partial}{\partial r}\!\left(r\frac{\partial v}{\partial r}\right)
```

```math
v(z,r)=V_c(z)f(\eta),\quad \eta=\frac{r}{z-z_v},\qquad f(\eta)=\frac{1}{(1+\beta^2\eta^2)^2}
```

### 17. Sauter 平均直径

```math
D_{32}=\frac{\sum_i n_iD_i^3}{\sum_i n_iD_i^2}
```

### 数值实现

- **$M=40$ 个对数分布尺寸分箱**（$M=20$–60 的网格无关性研究：40→60 变化可忽略但成本显著增加）
- **$N_z=5000$** 个均匀轴向点，$z$ 从 $C_mD$ 到 $0.3$ m；**一阶显式欧拉**沿 $z$ 推进
- 每个站位局部计算 $\varepsilon(z)$ 与 $K_c(z)$；分箱依次经破碎、聚并更新
- **体积守恒分箱**：落在分箱间的子液滴/合并液滴体积按**体积空间线性插值**重分配到相邻两个分箱，精确守恒油体积
- $D_{\min}=10$ μm（所有工况均小于 Kolmogorov 长度）；$D_{\max}=2^{1/3}D\approx12.6$ mm
- 数值稳定、网格无关；**每个轴向位置的油总体积守恒到舍入精度**
- $z_v/D$ 估计值：0.31 (Re=1000)、0.62 (1400)、0.42 (1700) → 均 < 1D，取 $z_v=0$

### 关键定量结果

| 观察 | 结果 |
|---|---|
| **破碎长度** vs Re | **非单调**：Re=600→1000 增长，之后单调减小 |
| **自相似性** | 平均速度剖面在 $z/D\gtrsim6$ 塌到共同类高斯曲线；雷诺应力剖面在 $z/D\gtrsim10$ 塌合（高阶统计需更长发展区）；破碎下游 $V_c\sim z^{-1}$；$r_{1/2}$ 线性增长 |
| **破碎位置** | $z/D\approx5$–6；$L\approx r_{1/2}\approx4$–5 mm；$D_{\max}\approx12.6$ mm > L |
| **DSD @ z/D=20** | Re=600 → $P_n$ 延伸到 **d/D = 1.5**（比 Re=1000 的大液滴更多）；Re=600 的 $P_v$ **明显双峰**（主峰 = 剪切诱导破碎，次峰 = 弱湍流下幸存的 Rayleigh–Plateau 液滴）；Re=1000 的 $P_v$ **塌为单峰** |
| **PBM RMSE** @ z/D=20 | **7%（Re=1000）、9%（Re=1400）、9.5%（Re=1700）** |
| **聚并的作用** | 明显改善吻合，分布更宽、中/大液滴概率略高；影响在 z/D=20 比 z/D=12 更明显 |
| **$D_{32}$** | 随 $z$ 单调下降；含聚并模型给出系统性**更大**的 $D_{32}$，更快趋于渐近值 |
| **聚并/破碎比** $R(z)=\sum_k|\mathcal{C}_k|/\sum_k|\mathcal{B}_k|$ | **0.08–0.2**（破碎主导，聚并低约一个数量级；与 Kewalramani et al. 2022 相符） |
| **耗散验证** | PIV 谱估计在远场（$z/D\gtrsim15$）与式 33 吻合（Re=1000, 1400, 1700） |
| **粘度比研究**（Re=1700, We=1229） | 低 $\mu_d/\mu_c$（连续相粘度高）→ DSD 更平、大液滴更多；高 $\mu_d/\mu_c$ → 偏向小液滴。机制：$\mu_c$ 越高，KH 不稳定增长被抑制、TKE 耗散更快 → 破碎率降低 |

### 液滴检测细节

- **条纹去除**：变分方法分离无条纹与方向性条纹分量，保留前者（**$10^{-4}$ 量级的 RI 失配即足以引入伪影**）
- **U-Net**：200 张人工标注 + 增强（缩放、错切、旋转、弹性变形）
- **滤波**：面积约束排除连续射流；**偏心率 > 0.8 剔除**；**圆度 $C=4\pi A/P^2\le0.5$ 剔除**；截断直径 **2 像素**（≈100 μm）
- 停留时间 ≈ **10 个连续帧（1000 Hz）**（由液滴场的帧间互相关确定）；超过该间隔的序列被子采样；尺寸分布由 **1000 张不相关处理图像**计算
- 分箱宽 **500 μm**
- **收敛偏差**：尾部（最大液滴，$d/D\gtrsim0.7$）存在计数偏差

## 局限性（作者第 4.3 节详述）

1. **局部各向同性湍流闭合**：涡时间尺度 $\tau_{b,k}=\varepsilon^{-1/3}D_k^{2/3}$ 仅在 $D_k\ll L(z)$ 时有效；当 $D_k\gtrsim L(z)$ 正确时间尺度应为 $\tau=L/u'=\varepsilon^{-1/3}L^{2/3}$。近破碎区（$z/D\approx5$–6）$L\approx4$–5 mm 但 $D_{\max}\approx12.6$ mm > L → 仅在下游 $r_{1/2}>D$（$z/D\gtrsim20$）才自洽。
2. **有限停留时间**：源项局部求值假设破碎/聚并事件期间 $V_c$ 与 $\varepsilon$ 恒定。对 $D_i=D_j=6$ mm：$t_{ij}\approx8.5$ ms；Re=1700（$V_{exit}=2.2$ m/s，$C_m=4.8$）在 $z/D=20$ 处 $V_c\approx0.53$ m/s → $\Delta z\approx4.5$ mm ≈0.45D，期间 $\varepsilon\propto z^{-4}$ 下降 **~9%**。对 $D_i=D_j\approx3.78$ mm（Sauter 平均）：$t_{ij}\approx4.2$ ms，$\Delta z\approx2.2$ mm ≈0.22D，$\varepsilon$ 降 **~4%**。
3. **近场不匹配** @ $z/D=12$：模型假设完全解体，但射流核心在近场继续碎裂，最大液滴超过积分长度尺度。
4. 用 $D_k\to\min(D_k,L)$ 修正有限 $L$ **并不能捕捉这些液滴的破碎物理**——$D_k>L$ 时它们主要被大尺度应变与平均剪切变形，而非涡碰撞 → 作者指出需要**基于剪切的破碎核 + 历史相关源项**（未来工作）。
5. **PIV 谱耗散仅在远场有效**（$z/D\gtrsim15$）；近喷嘴区强平均剪切与各向异性湍流违反局部各向同性。
6. 雷诺应力中忽略密度加权（$\rho_c/\rho_d\approx1.20$）。
7. DSD 尾部收敛偏差（$d/D\gtrsim0.7$）。

## 实现建议

- **实现难度**：中–高（实验部分重；PBM 部分为 1D ODE，沿 z 一阶显式推进，计算极轻）。
- **预期性能**：PBM 计算几乎免费（$M=40$ 分箱 × $N_z=5000$ 站位）；实验成本高。
- **适用场景**：
  - 油泄漏/溢油的环境影响建模
  - 液–液萃取工艺的液滴尺寸预测
  - 射流破碎 CFD 的 **PBM 闭合参数标定**
- **落地建议**：
  1. **PBM 实现要点**：
     - 破碎 + 聚并**双源项**，聚并是本文的主要增量
     - **体积守恒分箱**（体积空间线性插值重分配）必须做，否则油体积不守恒
     - 聚并率 $C(D_i,D_j)=K_cA_{ij}(v_i^2+v_j^2)^{1/2}P_{ij}$，其中 $P_{ij}=\exp(-t_{ij}/\tau_{ij})$ 用**薄膜排液**模型
     - $K_c(z)$ 的空间衰减（$K_{c,0}=0.2$ → $K_{c,\infty}=5\times10^{-4}$，衰减长度 $z_0=C_mD$）是必要的
  2. **关键标定参数**：$C_m$、$K$（PIV 拟合）、$C_\varepsilon=65$、$K^*=0.18$、$\mathrm{Sc}_T=0.7$ —— 可直接取用
  3. **与 CFD 耦合的接口**：$\varepsilon(z)$ 与 $V_c(z)$ 需来自 DNS/LES 或 PIV；本文验证了 $\varepsilon(z)\propto z^{-4}$（$z/D\gtrsim15$）的可用性
  4. **实验方法学可复用**：折射率匹配 + 同步 PIV/PLIF 是测量**不可混液相流**的黄金标准（$10^{-4}$ 的 RI 失配即产生条纹伪影 → 必须严格配平）
  5. **机器学习提取**：U-Net + regionprops + 形状滤波（偏心率 >0.8、圆度 ≤0.5 剔除）是液滴检测的实用配方，可直接迁移到其他气泡/液滴成像任务
  6. **物理机制判断准则**：$\rho_d/\rho_c\approx1.2$ 时，**Rayleigh–Plateau 与 KH 竞争**；提高 $Re$ 使 KH 主导 —— 这个「密度比接近 1 时机制切换」的判据对设计 CFD 案例很有用
  7. **PBM 的适用边界（作者明确给出）**：仅在 $D_k\ll L(z)$（即 $z/D\gtrsim20$）时自洽；近场需基于剪切的破碎核
  8. **与本库其他条目对照**：与 [[ATF-Flame-Thickening]]（2610.37577）同属「**多相/多机制竞争需分开建模**」的主题；与 [[Target-Omega-Interfacial-Damping]]（2610.37376）共同指向「**界面/近场结构处理方式决定物理结论**」
