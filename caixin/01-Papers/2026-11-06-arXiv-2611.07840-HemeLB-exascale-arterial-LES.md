# Exascale-ready HemeLB：全身动脉血流的 LES

## 核心贡献

**首次实现人体全身动脉树的准星座级格子玻尔兹曼（LB）LES 模拟**：

1. **HemeLB + Smagorinsky LES** 组合，在 AMD / Intel / NVIDIA GPU 上保持相同扩展行为
2. **约 10 TLUPS**（10 万亿格点更新/秒）在 Frontier 与 Aurora 两台准星座超算上均可持续
3. **狭窄主动脉流验证**：5× 与 10× 粗于 20 μm DNS 的 LES 复现壁面压力与截面压力/速度；平面平均压力与 DNS 偏差 **≤ 0.75 mmHg（< 1% 局部压力）**
4. **100 μm 分辨率下，全人体模拟成本相对 DNS 降低约 625 倍**
5. **全身模型**：2.95 亿流体格点、主动脉根部入口 + 432 个 Windkessel 出口，**每个心动周期 15–18 节点·小时（2 个 Frontier 节点）**
6. 单次模拟**同时解析全身所有区域**（从脑动脉到足部动脉）
7. **生理学验证**：脉压波沿主动脉向足部放大；剪切应力集中于分支而非主动脉；脉搏到达出口的时间随距心脏距离递增；**腿部/足部血流呈三相波形**（与人体腿部多普勒测量一致）

## 背景：为什么需要 LES

全身动脉树 DNS 受限于需推进的格点数（人体动脉树约需 20 μm 分辨率 → 数十亿格点），超算无法承受。LB 天然适合此类大规模并行。

## 方法

### HemeLB 求解器
- 格子玻尔兹曼方法（LBM），专为主机+GPU 混合平台上超大规模并行设计
- **GPU 支持**：AMD、Intel、NVIDIA 三家 GPU 保持相同扩展行为
- 吞吐量：**约 10 TLUPS**（Frontier、Aurora）

### 亚格子模型：Smagorinsky LES
$$
\nu_t = (C_s \Delta)^2 |\nabla \bm{u}|
$$
- Smagorinsky 常数 $C_s$（典型 $C_s = 0.1\sim0.16$）
- 在 LES 中加入涡黏性项（VLES / Smagorinsky 强制项）

### 边界处理：432 个 Windkessel 出口
每个出口接一个**三参数 Windkessel 模型**（电阻 $R$、电容 $C$、电感 $L$）：
$$
p_\text{out} = R Q + L\frac{dQ}{dt} + \frac{1}{C}\int Q\,dt
$$
模拟外周动脉的阻抗特性。

### 模型规模
| 项目 | 数值 |
|---|---|
| 流体格点数 | **2.95 亿** |
| 入口 | 1 个（主动脉根部） |
| 出口 | **432 个 Windkessel** |
| 计算资源 | Frontier 2 个节点 |
| 心动周期耗时 | **15–18 节点·小时** |
| 分辨率 | 100 μm（DNS 的 1/5） |
| 成本降低 | 相对 20 μm DNS 约 **625×** |

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 离散化 | LBM 有限差分（BGK 碰撞） |
| 亚格子模型 | Smagorinsky LES |
| 求解器 | 分布式 GPU 加速 + 异步 IO |
| 时间步长 | 由 LBM 稳定性（CFL，$u/c_s$）约束；准定常流场下用大时间步 |
| 精度 | 平面平均压力 < 1% 局部压力（vs DNS） |
| 并行性 | ✅ 极佳：几何分解 + GPU 占用 ✅ 准星座实测 |
| 可扩展性 | ✅ 10 TLUPS @ Frontier/Aurora |

## 计算成本分析

| 方案 | 格点数（估算） | 代价 |
|---|---|---|
| 20 μm DNS | ~数十亿 | 基准 |
| **100 μm LES** | 2.95 亿 | **1/625** |
| 5× 粗 LES | — | 压力/速度复现良好 |

作者指出这为**患者特异性（patient-specific）全身 LB 模拟**铺路，并使**集合模拟（ensemble simulation，通向标准人体模型）**成为可能。

## 实验/验证结论

1. **狭窄主动脉流**：LES（5×、10× 粗）复现壁面压力、截面压力与速度分布
2. **压力波传播**：脉压波从主动脉向足部逐渐放大（与外周动脉顺应性递减一致）
3. **剪切应力分布**：集中于**分支处**而非主动脉主干
4. **脉搏到达时间**：随距心脏距离递增（传播延迟）
5. **腿部三相波形**：与多普勒超声测量一致（舒张期反向血流特征）

## 局限性

- **Smagorinsky 模型**本身有已知的缺陷：过度耗散于壁面（对壁面剪切应力偏低）、无法表示各向异性应力、非局部性丢失；本模型未使用壁面模型（wall model）
- 100 μm 分辨率仍**无法解析最小动脉**与血管内皮层（血管内皮功能依赖亚毫米尺度）
- Windkessel 出口是 0D 集总模型，**不回流**（无 Wave Reflection），丢失下肢外周反射波
- 全身模型需要大量高质量的**个体特异性几何数据**（CT/MRI），数据获取成本高
- 湍流部分在主动脉弓的二次流/涡旋可能需要更细分辨率

## 实现建议

- **实现难度**：🔴 高（需 GPU 优化 + 超算作业调度 + 医学几何网格生成）
- **预期性能**：✅ 已实证在 Frontier/Aurora 上 10 TLUPS
- **适用场景**：
  - 患者特异性血流动力学评估（动脉瘤、狭窄、主动脉瓣膜疾病）
  - 全身血流模拟与脉搏波传播研究
  - 血流动力学数字孪生
  - 血流与药物输运耦合
- **落地建议**：
  - 若无准星座资源，可用 HemeLB 的 CPU 版本做降分辨率（~200 μm）研究
  - 建议配合 **OpenFOAM** 或 **NekRS** 做交叉验证（OpenFOAM 已在知识库中）
  - 关注 HemeLB 后续是否加入壁面模型与回流边界
- **注意**：HemeLB 是独立于 OpenFOAM 的专用 LB 代码，其网格（笛卡尔 + 几何边界处理）与 OpenFOAM 的多面体网格不互通
