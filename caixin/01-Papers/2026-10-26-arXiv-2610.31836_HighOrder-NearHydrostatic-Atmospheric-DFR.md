## 核心贡献

> 针对"近静力背景主导 + 低马赫数扰动"的大气流动，提出 AUSM⁺-upH 通量 + 偏差（deviation-based）格式的高阶 DFR 框架，同时解决数值耗散过大与静力平衡破坏两个问题

1. 提出改进的 AUSM⁺-up 通量 **AUSM⁺-upH**，降低低马赫数下的声速型耗散
2. 引入偏差式（deviation）变量分解，把变量写成"静力平衡背景 + 扰动"，从根本上抑制离散静力平衡残差
3. 在 3D 压缩 Euler + 重力框架下验证：低马赫结构保持能力显著优于 Rusanov 通量，且偏差格式把平衡残差压低**数个量级**

## 技术方案

### 核心思想

两阶段解耦：

- **耗散端**：传统迎风格式（Rusanov 等）在低马赫区引入与声速相关的过量耗散 → 用 AUSM⁺-upH 通量替代
- **平衡端**：离散化误差破坏静力平衡（hydrostatic balance）→ 变量做偏差分解，强制背景态精确满足平衡方程

空间离散为 **Direct Flux Reconstruction (DFR)**（高阶有限元型），时间推进为**三阶指数时间积分器**。

### 关键技术

| 技术 | 说明 |
|------|------|
| AUSM⁺-upH 通量 | 在 AUSM⁺-up 基础上按静力背景修正压力/速度分裂，低马赫耗散更低 |
| 偏差式格式 | u = u_hydrostatic + u'，仅对 u' 演化，从源头消除平衡残差 |
| DFR | 高阶 Direct Flux Reconstruction，节点间自由度 |
| 三阶指数积分器 | 处理含重力源的刚性部分，显式处理非刚性 |
| 分层测试算例 | 理想化大气算例族，逐级检验 |

## 公式

```math
∂/∂t (ρ' u) + ∇·(ρ' u ⊗ u) + ∇p' = 0,   p' = p - p_hydro(z)
∂/∂t ρ' + ∇·(ρ' u) = 0
```

静力背景满足（理想平衡）：

```math
∇p_hydro = -ρ_hydro(z) g
```

偏差变量下的残差：

```math
R_hydro = |∇·(ρ_hydro u_hydro) + ∂p_hydro/∂z + ρ_hydro g|  →  0
```

低马赫极限下的耗散标度：

```math
ε_diss ∝ (Δa)²/Ma²  →  0  as Ma → 0   （AUSM⁺-upH 通过压力分裂抵消）
```

## 实验结论

- **数据集**: 分层的理想化大气测试算例（低马赫 + 近静力）
- **基线**: Rusanov 通量（更耗散）
- **结果**:
  - AUSM⁺-upH 比 Rusanov **更好地保持低马赫流动结构**
  - 代价：耗散降低后对离散静力平衡残差**更敏感**
  - 偏差格式把平衡残差压低**数个量级**；**地形（orography）上方流动改善最显著**
  - 组合（AUSM⁺-upH + 偏差格式）在全部测试算例上**鲁棒性最佳**

---

## 局限性

- 仅 3D 压缩 Euler，无粘性项（真实大气为 Navier-Stokes）
- 测试算例为理想化，未含真实地形数据、湿度、辐射
- 指数积分器的刚性处理依赖参数选取，CFL 条件需谨慎
- 偏差格式要求背景态可解析表示，非静力或强非线性背景需推广
