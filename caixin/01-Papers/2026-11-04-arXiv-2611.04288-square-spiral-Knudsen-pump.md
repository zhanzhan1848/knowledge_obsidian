## 核心贡献

> 提出**方形螺旋 (square-spiral) 结构的新型 Knudsen 泵**，在**单一固定欧拉网格**上耦合**热渗流 (thermal transpiration)** 与 **Poiseuille 流**：微通道内温度梯度把气体从低温区推向高温区（产生压升），主流道内压力梯度又反向输运，形成闭合循环。通过**串联/并联级数**的数值参数研究，量化了两种机制各自的贡献。

1. **双机制耦合的循环构型**：
   - 微通道（沿螺旋）：温度梯度驱动 → 气体由**低温→高温**，压升 + 热渗流；
   - 主流道（含弯段）：压力梯度驱动 → 气体由**高温→低温**，形成 Poiseuille 流。
   - 二者构成闭合输运回路。
2. **串联 vs 并联的相反效果**（本文最有价值的定量结论）：
   - **增加串联级数** → 微通道上的**压力负荷降低** → 整体输运性能提升：10 级串联比 4 级提升 **3.35%**，达到 $3.10\times10^{-7}\ \mathrm{kg/(m\cdot s)}$；
   - **增加并联级数** → 同样降低压力负荷，但**同时增强气体稀薄化** → 热渗流更强：5 级并联比 2 级提升 **70.80%**，达到 $3.07\times10^{-7}\ \mathrm{kg/(m\cdot s)}$。
   - 即：**并联的收益远大于串联**（70.80% vs 3.35%），但两者最终流量几乎相同（$3.10$ vs $3.07\times10^{-7}$）—— 说明存在**最优构型**。
3. **弯段的非线性效应**：主流道的**弯段导致压力与温度的非线性变化**，以及**弯曲区域的流动减速**。
4. **面向制造**：提出方形螺旋结构以兼顾**高效输运**与**可制造性/系统集成**（多级配置的工程可实现性）。

## 技术方案

### 核心思想

**背景**：Knudsen 泵依靠温度梯度驱动气体从冷端到热端，是气体分离与输送的重要方案。但其性能强烈受**结构设计、系统集成、制造复杂度**影响 —— 需要**高效且可制造的多级配置**。

**设计思路**：把两个输运机制放在**串联的热力学回路**里：

```
低温区 ──微通道(温度梯度驱动: 热渗流)──> 高温区 (压升)
   ^                                        |
   └──── 主流道(压力梯度驱动: Poiseuille流) ─┘
```

**方形螺旋**的作用：让主流道在有限平面面积内获得**足够长的路径**以产生必要的压降，同时弯段提供空间紧凑性。

### 关键技术

| 技术 | 说明 |
|------|------|
| 稀薄气体输运 | 滑移流（Knudsen 数 $>0.01$，混合区）|
| 热渗流 | $Q=-\frac{\mu T}{p}\nabla T$ 形式（Chapman-Enskog 一阶）|
| Poiseuille 流 | 压力梯度驱动的粘性流 |
| 数值方法 | 单一欧拉网格上的稀薄气体求解（论文以"numerical methods"表述，具体方法需查正文）|
| 参数研究 | 串联级数 $n_{\rm series}$、并联级数 $n_{\rm parallel}$ |
| 输运量 | 质量流量 $\dot m$（单位 $\mathrm{kg/(m\cdot s)}$，即单位截面质量通量）|

## 公式

```math
% ===== 热渗流（Chapman-Enskog 一阶）=====
\boldsymbol q_{\rm therm}=-\frac{\mu T}{p}\nabla T
\qquad\text{（气体沿温度梯度反向输运）}

% ===== Poiseuille 流（压力驱动）=====
\boldsymbol u_{\rm Pois}=-\frac{1}{\eta}\left(\nabla p-\underbrace{\boldsymbol f}_{\rm 外力项}\right)
\qquad\text{（或 } \nabla^2\boldsymbol u=\frac{1}{\eta}\nabla p \text{）}

% ===== 稀薄度判据 =====
\mathrm{Kn}=\frac{\lambda}{L}>0.01\ \Rightarrow\ \text{滑移流区（热渗流 + Poiseuille 耦合有效）}

% ===== 性能指标 =====
\dot m_{\rm series}:\quad 10\ \text{级}=3.10\times10^{-7}\ \mathrm{kg/(m\cdot s)}
\quad\Longrightarrow\quad +3.35\%\ \text{vs}\ 4\ \text{级}
\dot m_{\rm parallel}:\quad 5\ \text{级}=3.07\times10^{-7}\ \mathrm{kg/(m\cdot s)}
\quad\Longrightarrow\quad +70.80\%\ \text{vs}\ 2\ \text{级}
```

import numpy as np

def coupled_knudsen_pump(T_hot, T_cold, p_in, p_out,
                         n_series=4, n_parallel=2, geom=None):
    """方形螺旋 Knudsen 泵：热渗流（微通道）+ Poiseuille 流（主流道）耦合。
    返回：质量通量, 压力分布, 温度分布
    """
    # --- 微通道：温度梯度驱动（热渗流），沿螺旋路径 ---
    # Chapman-Enskog 一阶：热渗流质量通量
    q_therm = -mu(T_hot, T_cold) * (T_hot - T_cold) / p_mid / L_micro   # 沿温度梯度

    # --- 主流道：压力梯度驱动（Poiseuille），沿主流路径 ---
    # 压升由微通道产生，主通道消耗
    dp_micro = q_therm * (p_mid / mu_T) * L_micro          # 微通道产生的压升

    # --- 级数效应 ---
    # 串联：压力负荷降低 -> 性能小幅提升 (+3.35% for 4->10 级)

def series_gain(n):
    """串联级数增益（来自论文数值结果插值）"""
    ref = {2: 1.0, 4: 1.0, 10: 1.0335}
    return ref.get(n, 1.0)

    ref = {2: 1.0, 5: 1.7080}
    return ref.get(n, 1.0)

## 实验结论

- **数据集/算例**：方形螺旋 Knudsen 泵，氢气为工质；4 级与 10 级串联、2 级与 5 级并联的对比。
- **基线**：不同级数配置的互相对比。
- **结果**：
  - **串联**：级数增加 → 微通道压力负荷降低 → 整体性能提升；10 级比 4 级 **+3.35%**，达 $3.10\times10^{-7}\ \mathrm{kg/(m\cdot s)}$；
  - **并联**：级数增加 → 压力负荷降低 + **气体稀薄化增强** → 热渗流增强；5 级比 2 级 **+70.80%**，达 $3.07\times10^{-7}\ \mathrm{kg/(m\cdot s)}$；
  - 两种路径的最终流量几乎相同（$3.10$ vs $3.07$）→ 提示存在**最优级数配置**；
  - 主流道**弯段**引起压力与温度的**非线性变化**，并导致**弯曲区流动减速**。

- **数值方法细节不足**：论文摘要仅称"numerical methods employed"，具体是滑移边界条件的 FVM/FEM、稀薄气体的具体处理（如是否用 DSMC/Boltzmann 或 NS+滑移）需查正文。
- **未给出压升比/压缩比 (PR)** 与效率等 Knudsen 泵的关键性能指标（摘要中不可见）。
- **级数增益的机理未完全分离**：并联的 70.80% 提升中，"压力负荷降低"与"稀薄化增强"两个贡献**未分别量化**。
- **氢气专用**：结论对其他工质（He、Ne、CO$_2$）的适用性未验证（稀薄气体热渗流系数与分子质量相关）。

## 实现建议

- **实现难度**：✅ 中等。滑移流区（$\mathrm{Kn}>0.01$）用 **Navier-Stokes + Maxwell 滑移/温度跳跃边界条件**即可；$\mathrm{Kn}$ 更大时需 Boltzmann 求解器。
- **预期性能**：
  - 空间：通道尺度（微米级），网格需在壁面加密（滑移层厚度 $\sim\lambda$）；
  - 时间：稳态求解（定常输运），无时间步限制；
  - 成本：低 —— 这是**设计型研究**，不是大规模仿真。
- **适用场景**：
  - ✅ 真空微器件气体输运（分子泵、吸附解吸、真空工艺）
  - ✅ 气体分离（氢气提纯、同位素分离）
  - ✅ MEMS/微流控器件设计
  - ❌ 不适合高压稠密流动
- **落地建议**：这篇的价值在**设计规则**而非新物理：**(a) 并联优于串联**（因为同时提升稀薄度 → 增强热渗流）；**(b) 级数存在最优值**（因为最终流量趋于饱和）。做微器件设计时应把这两条作为参数扫描的起点。此外，**主流道弯段是性能损失点**（非线性压降 + 减速），设计时应尽量用直段或大半径弯。
