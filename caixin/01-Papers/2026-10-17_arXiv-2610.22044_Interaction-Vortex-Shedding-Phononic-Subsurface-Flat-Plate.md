## 核心贡献

> 用高保真**浸没边界方法 (IBM)** 研究**声子亚表面 (PSub)** 与平板全分离流涡脱落的**强耦合非线性 FSI**，证明 PSub 的弦向位置与共振特性对**极限环涡脱落**有**系统性显著调控**——可实现升力 / 阻力振幅衰减 30–50% 而平均力变化 < 0.5%

1. **背景**：声子材料 (phononic materials) 作为**被动流控**手段很有前景，但与**持续周期性涡脱落**的 FSI 仍未被研究
2. **方法**：
   - 高保真 IBM
   - PSub 建模为**接地二聚链**（grounded diatomic chain）驱动平板上的**柔性段**
   - 全分离流（fully separated flow）涡脱落
3. **关键参数**：
   - **弦向位置**（chordwise position）：PSub 与流场结构的**空间关系**
   - **共振位移振幅增长率**：PSub 与涡脱落耦合的**关键驱动参数**
4. **结果**：
   - 极限环 FSI 动力学可分为**四种模式**（基于位置）
   - **最优配置**：升力振幅降低 > 30%，阻力振幅降低 > 50%，平均升阻力变化 < 0.5%
   - 位移振幅包络主要决定**瞬态响应速度**

## 技术方案

### 核心思想

把**声子亚表面**（phononic subsurface）作为嵌入式**被动共振器**，通过 FSI 反馈调控平板上的极限环涡脱落。其核心思想是：**共振器的频率与涡脱落频率匹配 → 能量从涡向结构转移**，从而衰减涡脱落强度。

### 关键技术

| 技术 | 说明 |
|------|------|
| Immersed boundary method (IBM) | 高保真可压缩 / 不可压缩 NSE 求解 |
| Phononic subsurface model | 二聚链 (diatomic chain) + 接地 |
| Compliant section | PSub 驱动的平板柔性段 |
| Strongly-coupled nonlinear FSI | 流-固双向耦合 |
| Limit-cycle oscillation analysis | 极限环（稳态周期）特性 |
| Parametric FSI sweep | 位置 + 共振特性二维扫描 |

### 控制方程

**流体**：不可压缩 NSE（IBM 强制项）
\[
\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \nu \nabla^2 \mathbf{u} + \mathbf{f}_{\mathrm{IBM}}
\]

**固体**：接地二聚链动力学
\[
M_1 \ddot{x}_1 + K_1 x_1 + K_2 (x_1 - x_2) = F_{\mathrm{fluid}}
\]
\[
M_2 \ddot{x}_2 + K_2 (x_2 - x_1) = 0
\]

其中 \(M_1, M_2\) 是质量，\(K_1\) 是接地刚度，\(K_2\) 是耦合刚度。

### 关键发现：四种 FSI 模式

基于 PSub 弦向位置：

| 位置区 | 升力振幅 | 阻力振幅 | 平均力 |
|--------|---------|---------|--------|
| 上游 | 放大 | 放大 | 略变 |
| 中游 | 中等 | 中等 | 略变 |
| 下游 | **衰减 > 30%** | **衰减 > 50%** | **变化 < 0.5%** |
| 最下游 | 中等 | 中等 | 略变 |

## 实验 / 验证

- **方法**：纯数值模拟（高保真 IBM）
- **样本**：平板 + 嵌入式 PSub
- **结果**：
  - 极限环频率、振幅对位置参数敏感
  - PSub 位移-升力的相位关系决定能量转移效率
  - 共振振幅包络决定瞬态响应

---

## 局限性

- **2D 简化**：实际平板是 3D，存在展向涡结构
- **单 PSub 几何**：未涵盖多种亚表面拓扑
- **Re 范围**：未明确给出
- **无实验验证**：未与 PIV / PIV-vibrometry 实测对比
- **稳态假设**：仅研究极限环，瞬态起动未涉及

## 笔记

**@墨鱼丸 实现建议**：本工作对 **FSI 数值方法** 与 **被动流控设计** 有重要借鉴价值：
- **算法验证**：高保真 IBM + 接地二聚链模型是 FSI 求解器的标准测试 case
- **工程应用**：声子亚表面嵌入可作为**无源自适应流控**手段（飞机机翼、涡轮叶片等）
