## 核心贡献

> 用**直接数值模拟**研究**分层湍流 (stratified turbulence)** 中沿流体质点轨迹的**动能交换的时间不对称性**，并**按局部速度梯度拓扑分类**（4 类）进行条件统计，发现分层使 Lagrangian 功率的**标准偏度更负（不对称性增强）**，尽管其**方差反而下降**；并进一步识别出压力贡献的偏度转变是这一现象的关键动力学来源。

1. **三个同时发生的变化**（本文的组织框架）：
   - **Lagrangian 功率不对称性增强**（标准化偏度更负，尽管全局功率方差减小）
   - **压力介导的能量再分配被改变**（非分层时几乎对称的压力贡献在分层下显著负偏）
   - **示踪剂对局部流结构的时序采样改变**（持久时间分布的尾部与尺度随拓扑类不同）
2. **拓扑条件化揭示异质响应**：
   - **轴向拉伸主导 (axial-strain-dominated)** 区域：在**所有分层强度**下总功率偏度最负；
   - **双轴拉伸主导 (biaxial-strain-dominated)** 区域：偏度**从正变负**（符号翻转）；
   - 水平与垂直分量功率响应不同 → **方向依赖性**。
3. **能量条件化的压力统计**：进一步表明压力介导的能量再分配被改变。
4. **示踪剂持久时间**：分布呈**指数尾**，时间尺度随拓扑类而异，且对分层响应不同。
5. **因果关系未建立**：作者明确指出这三个共现特征**只是同时出现**，其**因果关系尚待确立** —— 这是一个诚实的科学边界声明。

## 技术方案

### 核心思想

**问题**：稳定分层重组织湍流，抑制垂直运动，改变涡旋主导 vs 应变主导结构的平衡。这种重组如何影响**沿流体质点轨迹**的动能交换的时间不对称性？

**方法**：不做整体统计，而是**按局部速度梯度拓扑分类**，再在每个类别内做条件统计 —— 这样能分离出不同局部流结构对分层的不同响应。

### 关键技术

| 技术 | 说明 |
|------|------|
| DNS | 齐次 Boussinesq 湍流（homogeneous Boussinesq turbulence）|
| 分层参数 | 3 个非零分层强度 + 1 个无分层参考算例 |
| 拓扑分类 | 按局部速度梯度分 4 类（轴向拉伸、双轴拉伸、以及涡旋/应变主导类）|
| Lagrangian 功率 | 沿流体质点轨迹的动能交换率 $p=\frac{d}{dt}\frac{1}{2}|\boldsymbol u-\boldsymbol u_{lc}|^2$ 的统计 |
| 统计量 | 全局功率方差、标准化偏度（skewness）、条件化偏度 |
| 动力学分解 | 功率的**压力贡献** vs 速度贡献；能量条件化的压力统计 |
| 示踪剂分析 | 持久时间 (persistence time) 分布，检验指数尾 |

## 公式

```math
% ===== Boussinesq 分层湍流（示意）=====
\frac{\partial \boldsymbol u}{\partial t}+(\boldsymbol u\cdot\nabla)\boldsymbol u
=-\nabla p+\nu\nabla^2\boldsymbol u-\frac{\rho'}{\rho_0}g\hat z
\frac{\partial \rho}{\partial t}+(\boldsymbol u\cdot\nabla)\rho=\kappa\nabla^2\rho

% ===== Lagrangian 功率定义（示意）=====
p(t)=\frac{d}{dt}\left(\frac{1}{2}|\boldsymbol u(\boldsymbol X(t),t)-\boldsymbol u_{lc}(t)|^2\right)
\Big|_{\text{Lagrangian}}
\qquad \boldsymbol u_{lc}=\text{局部坐标平均（过滤）速度}

% ===== 动力学分解：压力项 =====
p_{\rm press}\sim -\boldsymbol u\cdot\nabla p
\quad\Longrightarrow\quad
\text{非分层: } p_{\rm press}\ \text{近乎对称}
\qquad
\text{分层: } p_{\rm press}\ \text{显著负偏}

% ===== 统计量 =====
\text{方差: }\ \sigma_p^2=\langle p^2\rangle-\langle p\rangle^2
\text{标准化偏度: }\ S_p=\frac{\langle(p-\langle p\rangle)^3\rangle}{\sigma_p^3}
\quad\Longrightarrow\quad S_p<0\ \text{随分层增强而更负}
```

## 代码片段

```python
import numpy as np

def velocity_gradient_topology(G):
    """按局部速度梯度的相对不变张量分类。
    G: (..., 3, 3) 速度梯度
    返回 4 类标签（轴向拉伸主导 / 双轴拉伸主导 / 涡旋主导 / 应变主导）
    """
    # 相对不变张量 S = G @ G.T 的特征分解
    w, V = np.linalg.eigh(G @ np.transpose(G, (-1, -2, -3)))
    w = w[..., ::-1]                       # 降序
    # 判别不变量: I1 = trace(S), I2, I3
    I1 = w.sum(-1)
    I2 = w[..., 0]*w[..., 1] + w[..., 1]*w[..., 2] + w[..., 2]*w[..., 0]
    I3 = w[..., 0]*w[..., 1]*w[..., 2]
    disc = I1**2 - 3*I2                     # 判别式
    # 基于不变量比值的分类（参考 Baldini & Laforgia 拓扑分类）
    q = 0.5*(I1**2 - 3*I2)
    r = I3 - I1**3/27 + I1*I2/3
    theta = np.arccos(np.clip(r/(-2*q**1.5 + 1e-30), -1, 1))/3
    labels = classify_by_invariants(I1, I2, I3, disc)
    return labels

def conditioned_skew(power, labels, target_label):
    """按拓扑类做条件统计：返回该类的标准化偏度"""
    m = labels == target_label
    p = power[m]
    mu, sd = p.mean(), p.std()
    return ((p - mu)**3).mean() / sd**3, p.var()

def persistence_time_distribution(tracer_records):
    """示踪剂持久时间：检验指数尾"""
    tau = [len(r) for r in tracer_records]
    tau = np.array(tau)
    # 与指数尾比较：P(tau > T) vs exp(-T/scale)
    return tau
```

## 实验结论

- **数据集/算例**：齐次 Boussinesq 湍流 DNS；3 个非零分层强度 + 1 个无分层参考；4 个局部速度梯度拓扑类。
- **基线**：无分层参考算例（Unstratified）。
- **结果**：
  - **全局**：分层增强 → 功率**方差下降**，但**标准化偏度更负**（不对称性增强）。
  - **拓扑条件化**：
    - 轴向拉伸主导区：**所有分层强度下**总功率偏度最负；
    - 双轴拉伸主导区：偏度**从正翻转为负**；
    - 水平/垂直分量功率响应不同 → 方向依赖。
  - **压力贡献**：非分层时近乎对称；分层下**显著负偏**。能量条件化的压力统计进一步表明压力介导的能量再分配改变。
  - **示踪剂**：持久时间分布**指数尾**，时间尺度随拓扑类不同且对分层响应不同。
  - 三个特征**同时出现**，但**因果关系未确立**。

## 局限性

- **因果关系未建立**：作者明确声明三个共现特征的因果联系尚待研究 —— 这是本文最大的科学限制。
- **分层强度覆盖有限**：仅 3 个非零分层强度 + 1 个参考。
- **拓扑分类方法未在摘要中给出细节**：具体判据与阈值需查阅正文。
- **齐次 Boussinesq 假设**：真实海洋/大气分层湍流常有**非均匀层结**与**Ekman 边界层**，结论的普适性受限。
- **纯诊断性研究**：无模型、无预测能力、无工程应用出口。
- 未给出**实验验证**（全为 DNS 诊断）。

## 实现建议

- **实现难度**：⚠️ 高。主要成本在 **DNS 本身**（齐次 Boussinesq 湍流需高分辨率 + 长时间统计）；**拓扑分类**与**Lagrangian 追踪**是额外实现负担。
- **预期性能**：
  - DNS：$Re$ 至少 $10^3$–$10^4$，网格 $512^3$–$1024^3$ 量级（分层湍流需要解析小尺度）；
  - 统计：Lagrangian 功率的偏度估计需**大量示踪粒子**（$10^5$–$10^6$）与长时间平均；
  - 后处理：拓扑分类可**向量化**（逐点特征分解），成本可接受。
- **适用场景**：
  - ✅ 分层海洋/大气湍流的**诊断分析**
  - ✅ Lagrangian 输运模型验证（是否正确再现各拓扑类的贡献）
  - ✅ 湍流各向异性（方向依赖性）的基础研究
  - ❌ 不适合工程预测
- **落地建议**：这篇的价值在**方法论组合**：**拓扑分类 + 条件统计 + 动力学分解（压力项）**。这套组合可迁移到任何 Lagrangian 诊断问题上（如 LES 的亚格子输运诊断）。若做 Lagrangian 粒子模型，建议直接复用"拓扑分类 + 压力项分离"的诊断框架 —— 它能告诉你模型在**哪类局部结构上失真**。
