## 核心贡献

> 提出了**功率曲线感知的风轮致动盘模型 (PCADM)**，取代传统的恒系数致动盘 (CCADM)，并在漂浮式海上风电场 LES 中系统考察平台纵摇运动对平均/脉动功率的影响；揭示 CCADM 会产生"非物理功率过冲"，且同相纵摇使风场尺度波动最大。

1. **提出 PCADM**：由制造商 $C_T(U_\infty)$ 曲线出发，经感应因子 $a$ 的分段解析反演，得到可直接在 LES 中使用的**局部**系数 $C_T'(U_d)$ 与 $C_P'(U_d)$，覆盖 Region 1/2/3 与停机区间（$U_{ci}$, $U_{tr}$, $U_{co}$）。
2. **发现 CCADM 的非物理行为**：当纵摇导致的相对风速周期性超过额定风速时，恒系数模型会产生功率过冲（超出实际运行包线）；PCADM 消除了这些虚假偏移。
3. **量化纵摇的双向效应**：依运行区间不同，平台纵摇既可能**提高**也可能**降低**平均功率（此前文献结论冲突的主因之一是恒系数假设）。
4. **同相 (IP) 纵摇最强**：在所考察的相对相位中，同相运动因更强的风机-风机相关性产生最大的风场尺度功率波动；反相 (OP) 与非整周期相 (IC) 次之。
5. **波浪相位贡献可分离**：通过对比不同底边界波浪表示法，隔离出波浪相位与风机纵摇各自的贡献。

## 控制方程

### 1. 致动盘受力（Calaf 局部分式）

```math
\mathbf{F}_{\rm d} = -\frac{1}{2}\rho\,C_T'\,U_{\rm d}^{2}\,A_{\rm d}\,\hat{\mathbf{n}}
```

$$U_{\rm d} = \iiint_{\mathcal{R}} \mathbf{u}(\mathbf{x})\cdot\hat{\mathbf{n}}\,d^3\mathbf{x}$$

其中 $\mathcal{R}(\mathbf{x})$ 为归一化滤波函数（盘内恒为 1，盘外为 0，部分重叠单元按面积占比线性插值）——这是 LES 中避免"远上游取样距离难定"的标准做法。

### 2. 分段推力系数曲线（PCADM 核心）

```math
C_T(U_\infty) = \begin{cases}
0, & U_\infty \le U_{\rm ci} \\
C_{T,\rm op}, & U_{\rm ci} < U_\infty \le U_{\rm tr} \\
\dfrac{C_{T,\rm op}}{1+\alpha\left(U_\infty/U_{\rm tr}-1\right)}, & U_{\rm tr} < U_\infty \le U_{\rm co} \\
0, & U_{\rm co} < U_\infty
\end{cases}
```

### 3. 感应因子与倾角修正

```math
a = \frac{1}{2}\left(1 - \sqrt{1 - C_T \cos\theta}\right)
```

$$\text{致动盘关系：}\quad U_\infty = \frac{U_{\rm d}}{1-a}$$

**Region 3 分支代入后化为关于 $a$ 的二次方程**，取物理解 $0<a<1/2$：

```math
a(U_d,\theta) = \frac{1}{2}\begin{cases}
0, & U_{\rm d}\le U_{\rm d,ci} \\
1-\sqrt{1-C_{T,\rm op}\cos\theta}, & U_{\rm d,ci}<U_{\rm d}\le U_{\rm d,tr} \\
1-\dfrac{\alpha}{\alpha-1}\dfrac{U_{\rm d}}{U_{\rm tr}} + \sqrt{\left(1-\dfrac{\alpha}{\alpha-1}\dfrac{U_{\rm d}}{U_{\rm tr}}\right)^{2} + \dfrac{C_{T,\rm op}\cos\theta}{\alpha-1}}, & U_{\rm d,tr}<U_{\rm d}\le U_{\rm d,co} \\
0, & U_{\rm d,co}<U_{\rm d}
\end{cases}
```

$$U_{\rm d,tr} = U_{\rm tr}\,\frac{1}{2}\left(1+\sqrt{1-C_{T,\rm op}\cos\theta}\right)$$

> **关键点**：LES 中已知的是盘面速度 $U_d$ 而非远场速度 $U_\infty$，而 $C_T$ 曲线以 $U_\infty$ 给出。上式通过 $a(C_T,\theta)$ 的解析反演完成了 $C_T(U_\infty) \to C_T'(U_d)$ 的映射——这是 PCADM 可用的前提。

### IEA 15 MW 拟合参数

$$C_{T,\rm op} = 0.804,\quad \alpha = 7.413,\quad U_{\rm ci}=3\ \mathrm{m/s},\quad U_{\rm tr}=10.59\ \mathrm{m/s},\quad U_{co}=25\ \mathrm{m/s}$$

（功率系数曲线的 Region 2→3 转换点 $U_{\rm tr1} = 6.98\ \mathrm{m/s}$；Region 1.5 因 $C_T$ 近似恒定而并入 Region 2；Region 2 下对应 CCADM 的 $C_T' = 1.545$。）

## 数值方法

| 技术 | 说明 |
|------|------|
| **方法** | 大涡模拟（LES），充分发展风轮阵列边界层 |
| **边界条件** | 流向 (x) 与展向 (y) **周期**；顶部无应力；底部采用 **MOSD**（Moving Surface Drag，脉动移动底面）与对照的 **EQWM**（等效波浪模型） |
| **控制** | 压力梯度力施加 PI 控制器，维持域顶参考速度 $U_{\rm ref}$ |
| **域尺寸** | $L_x \times L_y \times L_z = 3840\ \mathrm{m} \times 1920\ \mathrm{m} \times 700\ \mathrm{m}$ |
| **网格（主）** | $N_x\times N_y\times N_z = 192\times96\times128$，$\Delta = 20\times20\times5.4\ \mathrm{m}$ |
| **网格（细）** | $384\times192\times256$，$\Delta = 10\times10\times2.7\ \mathrm{m}$（用于短波长工况 FB-SW-12 / OP-SW-12） |
| **波浪分辨率** | 网格保证每个波长至少 8 个网格点（MOSD 实现要求） |
| **时间步** | 固定 CFL = 0.0625（自适应） |
| **统计量** | 样本数 $n_{\max}$ 最高 1,500,000；总物理平均时长 $t_{n_{\max}} \approx 8\times10^4$ |
| **收敛性** | 附录含平均功率趋势的统计收敛误差分析 |

### 风场布置

- 6 台 IEA 15 MW 风机，**两列三行**，转子直径 240 m，轮毂高 150 m。
- 通过调整波长 $\lambda$ 与风机间距 $S_x$ 之比，实现行间相对纵摇相位：**同相 IP / 反相 OP / 非整周期相 IC**。
- 平台：UMaine VolturnUS-S（IEA 15 MW 参考平台）。
- 纵摇：与代表性海洋波频率匹配的**谐波**纵摇运动。
- 对照组 FB（固定基础，同样波浪条件）。

## 实验结论

- **CCADM → 非物理功率过冲**：当纵摇引起的相对风速周期性超过额定风速时，恒系数模型给出超出实际运行包线的功率；PCADM 彻底消除。
- **纵摇对平均功率的双向性**：取决于风机所处运行区间——纵摇可提高亦可降低平均输出。这是此前文献结论相互矛盾的重要原因。
- **同相 (IP) 波动最大**：因风机-风机尾流相关性最强；OP 与 IC 依次减弱。
- **波浪相位可分离**：用不同底边界波浪表示法（MOSD vs EQWM）对比，可分离波浪相位与纵摇的各自贡献。

---

## 局限性

- 纵摇为**规定式谐波**而非由气动-水动-伺服-弹性（AHSE）耦合求解；真实平台的纵摇幅值/相位由波浪-结构相互作用决定，存在双向反馈缺失。
- 未含变桨（blade pitch）控制与转矩控制策略，实际风机的额定风速切换会主动抑制过冲。
- 只有**两列三行**的对齐阵列，未研究非对齐布局、尾流偏转与尾流-尾流叠加的非线性效应。
- IEA 15 MW 的 ROSCO 数据在 Region 2→3 的转换点附近为拟合而非原始数据，误差未系统量化。
- 细网格工况仅用于短波长算例，统计收敛长度有限。

## 实现建议

- **实现难度**：★★★☆（PCADM 的 $C_T(U_\infty)\to C_T'(U_d)$ 映射需要仔细处理 Region 边界连续性与感应因子二次方程的可解分支；LES 本身用现有 CFD 求解器即可）
- **预期性能**：PCADM 相比 CCADM 几乎无额外计算开销（仅一次分段函数求值 + 二次方程解析解），是**性价比极高的模型升级**
- **适用场景**：漂浮式海上风电场 LES、浮式平台运动-尾流-功率耦合、气动-水动耦合敏感性分析
- **可迁移点**：
  - "远场量 → 局部量"的反演技巧（$U_\infty = U_d/(1-a)$ + $a(C_T,\theta)$）可推广到任何以远场曲线为输入的致动盘类模型
  - 倾角修正 $\cos\theta$ 是处理偏航/倾斜的标准做法
  - MOSD 底面波浪实现（保证每波长 ≥ 8 网格点）可复用于海面边界层 LES
