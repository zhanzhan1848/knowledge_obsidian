## 核心贡献

> 建立了一个分析**任意状态方程**下黏性分层流动线性稳定性的**数学框架**：允许 $p=\Phi(T,\rho)$ 或 $\rho=\phi(T)$ 形式的状态方程、**不受限制的密度分层**（可研究非 Boussinesq 效应）、并用**低马赫数近似**滤除声学现象；应用于**平面 Couette 流**的两个黏性分层构型（三层密度剖面支撑 **Taylor–Caulfield 失稳 (TCI)**，以及差异加热超临界流体的一种不同机制），给出新结论：**非 Boussinesq 效应削弱黏性 TCI，而黏性可以进一步**加剧**超临界流体失稳——这与浮力的稳定化作用方向相反**。

1. **通用框架**：容纳 $p=\Phi(T,\rho)$ 与 $\rho=\phi(T)$ 两类状态方程，加上一组无量纲控制参数。
2. **不受限的密度分层**：允许研究**非 Boussinesq 效应**（密度变化与速度梯度同量级时的浮力–惯性竞争）。
3. **低马赫数近似**：滤除声学现象，把问题聚焦到分层剪切层的不稳定性。
4. **验证与新结果**：框架先对既有参考研究做验证，然后给出新结论——**非 Boussinesq 效应削弱黏性 TCI**；**黏性加剧超临界流体失稳**（与浮力的稳定化作用**方向相反**）。
5. **JFM 接收**：表明该框架的严谨性与实用价值已获同行认可。

## 技术方案

### 核心思想

分层剪切流（stratified shear flow）的稳定性是海洋与大气流动的核心问题，其经典框架是 **Taylor–Caulfield 失稳 (TCI)**：在均匀密度（中性）剪切层中，**黏性**通过与有限振幅内波的相互作用触发失稳。

但经典分析通常建立在 **Boussinesq 近似**上——即假设密度变化足够小，只在浮力项中保留密度差异，其余项用参考密度替代。Boussinesq 近似在海洋分层中通常成立，但当**密度分层很强**（如**超临界流体**——接近临界点的流体，$\partial \rho/\partial T$ 极大）时，Boussinesq 假设失效，**浮力项与其他惯性项的相对权重改变**，稳定性结论可能定性反转。

此外，**状态方程**的选择会直接影响问题：海洋流体常用 $\rho=\phi(T)$，工业流体常用 $p=\Phi(T,\rho)$。一个**能同时处理任意状态方程**的框架，价值在于可以**统一比较**不同工质下的稳定性行为。

本文的框架设计要点：
- **低马赫数近似**滤除声学模态——在弱可压缩流动中，声学与分层剪切模态的频率尺度可能重叠，混在一起会污染稳定性图谱；
- **不受限的密度分层**保留完整的非 Boussinesq 效应（密度梯度进入惯性项）；
- 通过**无量纲参数组**组织结果，使其可用于不同状态方程的对照。

两个应用构型：
1. **三层密度剖面**（支撑经典 TCI）——作为方法验证与基线；
2. **差异加热的超临界流体**——表现出一种**不同的失稳机制**，且黏性在其中起**不稳定**作用。

第二个结论特别值得注意：在超临界流体中，**黏性与浮力的作用方向相反**——黏性不是稳定因素，反而加剧失稳。这意味着经典"Taylor–Caulfield 机制中黏性通过耗散诱发失稳"的图像在超临界条件下被**放大**而非抑制。

## 公式 / 理论要点

```math
% 黏性分层流动的控制方程（含非 Boussinesq 密度变化）
\frac{\partial \boldsymbol{u}}{\partial t}
+\boldsymbol{u}\cdot\nabla\boldsymbol{u}
= -\frac{1}{\rho}\nabla p
+\nabla\cdot\left(\mu\left(\nabla\boldsymbol{u}+(\nabla\boldsymbol{u})^T\right)\right)
-\frac{1}{\rho}\,\frac{D\rho}{Dt}\,\boldsymbol{u}
```

```math
% 温度输运
\frac{DT}{Dt}=\boldsymbol{u}\cdot\nabla T
+\kappa\nabla^2 T
\qquad(\text{Pr}\text{ 为普朗特数})
```

```math
% 通用状态方程（两种形式）
p = \Phi(T,\rho)
\qquad\text{或}\qquad
\rho = \phi(T)
```

```math
% 低马赫数近似下的线性扰动方程组
\frac{\partial \theta}{\partial t} + \boldsymbol{u}_1\cdot\nabla \bar{T}
= \nabla\cdot(\kappa\nabla\theta)
-\frac{D\bar{T}}{Dt}\ \text{(背景项)}
```

```math
% 浮力–惯性耦合（非 Boussinesq 效应的来源）
\frac{\partial \boldsymbol{u}_1}{\partial t}
= -\frac{1}{\bar{\rho}}\nabla p_1
-\frac{1}{\bar{\rho}^2}\left(\frac{\partial\bar{\rho}}{\partial T}\right)
\theta\,(\text{浮力项，保留完整线性化})
+\nabla\cdot(\mu\nabla\boldsymbol{u}_1)
```

```math
% 特征值问题（稳定性判据）
\max_{\boldsymbol{k}\neq 0}\ \mathrm{Re}\left[\omega(\boldsymbol{k})\right] < 0
\quad\Longleftrightarrow\quad \text{线性稳定}
```

```math
% Rayleigh–Taylor 型分层剪切判据中的关键无量纲组合
\mathrm{Ri} = \frac{N^2}{(\partial U/\partial z)^2},
\qquad
N^2 = -\frac{g}{\rho}\frac{\partial \rho}{\partial z}
```

## 实验与结果

- **研究对象**: 黏性分层平面 Couette 流中的线性稳定性。
- **两个构型**:
  1. **三层密度剖面**——支撑经典 **Taylor–Caulfield 失稳 (TCI)**，用作框架验证与基线；
  2. **差异加热的超临界流体**——呈现一种**不同的失稳机制**。
- **对比基线**: 既有文献中的 Boussinesq 近似结果与参考研究（用于验证框架）；浮力稳定化效应（标准图像）。
- **主要结果**:
  - **框架验证**：在 Boussinesq 极限下复现既有参考研究的 TCI 结果。
  - **新结论 1**：**非 Boussinesq 效应削弱黏性 TCI**（强密度分层反而抑制 TCI）。
  - **新结论 2**：在超临界流体中，**黏性进一步加剧失稳**——与浮力的稳定化作用**方向相反**（标准图像中黏性是耗散、稳定因素）。
  - **低马赫近似的作用**：滤除声学模态后得到干净的分层剪切稳定性图谱。

---

## 局限性

- **理论/线性层面**：仅分析层流态的线性稳定性，未涉及非线性演化、转捩、二维/三维次级失稳（TCI 之后的非线性过程）。
- **纯黏性剪切**：未考虑旋转、科氏力、真实地球边界层的地形/Ekman 层影响。
- **Couette 流几何**：真实海洋剪切（Ekman 层、射流）边界条件不同，结论的可迁移性需重新推导。
- **低马赫假设**：对强可压缩或高马赫流动不适用。
- **超临界流体**的强非线性物性（如热膨胀系数的奇异行为）在真实临界点附近可能破坏本文的线性展开假设。

## 实现建议

- **实现难度**: 中低 — 线性稳定性框架是标准工具（Chebyshev 配点或谱方法 + 广义特征值）；难点在于**任意状态方程的数值处理**与**非 Boussinesq 项的正确线性化**。
- **预期性能**: 特征值扫描成本低；参数扫描可并行。
- **适用场景**:
  - **海洋分层与内波稳定性**研究；
  - **超临界流体**（CO$_2$、水合物）管道/反应器流动的失稳预测；
  - **工业设备的分层两相/分层混合流动**失稳分析；
  - 工业 CFD 代码中**分层两相流稳定性判据**的理论依据。
- **可复用要点**:
  - **"黏性与浮力作用方向相反"**是一个极易被误用的结论——任何用 Boussinesq 近似做超临界/强分层稳定性计算的工程师都应检查这一点。建议把这张"结论—适用条件"对照表纳入知识库，供查询时先看适用条件再套用结论。
  - **低马赫近似滤除声学模态**是所有"弱可压缩分层流"稳定性分析的必要第一步，应作为标准前置步骤写入流程（与本轮 [[2026-11-11-arXiv-2611.13727]] CLUGKS 中显式处理声学/动理学的做法形成对照）。
  - **框架设计可迁移**：把状态方程做成**可插拔接口**、把结果组织成**无量纲参数组**，使得同一套求解器能覆盖 $\rho=\phi(T)$ 与 $p=\Phi(T,\rho)$ 两族工质——这是做**跨工质对比研究**的实用工程模式。
