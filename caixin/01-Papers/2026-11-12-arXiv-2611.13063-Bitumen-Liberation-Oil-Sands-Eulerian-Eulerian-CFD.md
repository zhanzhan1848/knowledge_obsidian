## 核心贡献

> 用**三维 Eulerian–Eulerian (E-E) CFD + k-ω SST 湍流模型**研究油砂管道水力输送中**沥青 (bitumen) 从油砂块 (lump) 的动态剥离**。机制性结论：**沥青脱附是剪切驱动的 (shear-driven)**——只有当流动施加在块体表面的**剪切应力超过某一临界阈值**时才会发生；**脱附率随颗粒雷诺数 $Re_p$ 升高、随块体直径 $D$ 减小而增大**（局部剪切力增强 + 颗粒屏蔽减弱）。据此提出**半经验剪切驱动模型 (semi-empirical shear-driven model)**，对实验脱附数据的预测**误差小于 8.3%**。

1. **应用背景**：黏性油–固聚集体的**动态剥离与消解 (liberation and digestion)** 是多相化学过程中的关键输运现象——涉及**浆体输送、土壤修复、工业开采**。油砂水力输送 (oil sands hydrotransport) 是主要工业应用：管道同时输送与提取沥青。
2. **方法**：**三维 Eulerian–Eulerian (E-E) CFD** 框架，耦合 **k-ω SST 湍流模型**，研究沥青从复杂固体基质中的**剥离动力学**。
3. **算例规模**: **6 个数值算例**，覆盖 **块体直径 $D = 4$ 与 5 cm**，**颗粒雷诺数 $Re_p \in [2000, 4000]$**。
4. **核心机制结论**: **沥青脱附是剪切驱动的过程**——**仅当流动施加于块体表面的剪切应力超过一个临界阈值值时才发生**。
5. **参数依赖**:
   - **$Re_p$ 升高 → 脱附率增大**（**局部剪切力增强**）；
   - **$D$ 减小 → 脱附率增大**（**颗粒屏蔽减弱**）。
6. **半经验模型**: 基于上述机制性认识，提出**新的半经验剪切驱动模型**。
7. **验证精度**: 对**实验脱附数据**的预测**误差小于 8.3%**。

## 技术方案

### 核心思想

**工程问题的本质**

油砂开采（油砂水力输送）：把沥青（黏度极高的重油）与砂石一起，用水在管道中输送到分离设备。问题在于——**沥青黏附在砂粒/块体上，需要被水力剪切剥离下来才能分离**。

工程上需要知道的是：**在什么流量/流速下，沥青能被有效剥离？** 这直接决定：
- 管道设计（管径、泵能耗）
- 分离效率
- 回收率

**为什么这是真正的多相流难题**

沥青在常温下的**黏度极高**（$10^3$–$10^6$ Pa·s 量级），与水的黏度相差 **6–9 个数量级**。因此：
- **不能用 DPM/VOF 的常规 Lagrangian 或相场方法**——界面张力主导的界面捕获方法在如此大的黏度比下完全失效（界面宽度会巨大化）；
- **Eulerian–Eulerian (E-E)** 方法把两相都视为连续介质，在相场方程中引入**滑移速度**与**有效黏度**，是目前工业界处理高黏比多相流的标准路线。

**核心机制：剪切驱动**

本文最有价值的结论是**机制性的**而非仅仅是拟合：

沥青脱附不是"被冲走"，而是**被剪切剥离**。判据是**块体表面的剪切应力是否超过临界值**：
$$\tau_{\text{surface}} > \tau_c$$

这与直觉的"流量越大冲刷越强"不同——真正起作用的是**局部剪切应力**，而剪切应力依赖：
- 局部流速梯度（由 $Re_p$ 决定）
- 块体尺寸（决定绕流边界层厚度与局地剪切分布）

**两个参数的相反效应**：
- **$Re_p \uparrow$** → 流动更强 → **局部剪切力增强** → 脱附率↑
- **$D \downarrow$** → 块体更小 → **颗粒屏蔽 (particle shielding) 减弱**（小颗粒周围的水流更容易"钻进"颗粒间隙，直接冲刷表面）→ 脱附率↑

这两个效应**同向**，因此脱附率对 $Re_p$ 和 $D$ 都是单调的。

**半经验模型的构造逻辑**

因为机制清楚（剪切驱动 + 临界阈值），模型可以写得很简单：脱附率应该是**剪切应力超过阈值后的某个函数**：

$$\dot{m}_{\text{lib}} = f(\tau_{\text{surface}} - \tau_c;\, \text{其他参数})$$

这解释了为什么模型能做到 **8.3% 以内的误差**——它不是黑箱拟合，而是**建立在正确机制上的低维关系**。

## 公式 / 理论要点

```math
% Eulerian-Eulerian 两相流（体积分数形式）
\partial_t (\rho_i \alpha_i) + \nabla\cdot(\alpha_i \rho_i \boldsymbol{u}_i)
= - \nabla\cdot\alpha_i \rho_i \boldsymbol{u}_i + S_i,
\qquad i \in \{\text{水}, \text{沥青+砂}\}
```

```math
% E-E 的相间动量交换（滑移 + 有效黏度）
S_i = \beta \frac{\rho_i\rho_j}{(\rho_i+\rho_j)}
\left[(\boldsymbol{u}_j - \boldsymbol{u}_i) - \frac{d}{3}(\boldsymbol{u}_j - \boldsymbol{u}_i)\right]
- \frac{3}{4}\,\frac{\mu_{\text{eff}}(\alpha_i)}{d}\,\frac{\rho_i\rho_j}{(\rho_i+\rho_j)}
\left|\boldsymbol{u}_j-\boldsymbol{u}_i\right|\,(\boldsymbol{u}_j-\boldsymbol{u}_i)
```

```math
% 有效黏度（E-E 处理高黏度比的标准做法）
\mu_{\text{eff}}(\alpha) = \mu_i \frac{\alpha_i \mu_j + (1-\alpha_i)\mu_i}
                                   {\alpha_i\mu_j + (1-\alpha_i)\mu_i - \alpha_i(1-\alpha_i)(\mu_j-\mu_i)}
```

```math
% k-ω SST 湍流模型
\frac{\partial(\rho k)}{\partial t} + \nabla\cdot(\rho\boldsymbol{u}k)
= \nabla\cdot\left[\left(\mu_t+\frac{\mu}{\sigma_k}\right)\nabla k\right]
- \rho\omega k + P_k
```

```math
% 剪切驱动脱附判据（本文核心机制）
\tau_{\text{surface}}(\boldsymbol{x}) = \mu_{\text{eff}}
\left.\frac{\partial \boldsymbol{u}_t}{\partial n}\right|_{\text{surface}},
\qquad
\text{脱附发生} \iff \tau_{\text{surface}} > \tau_c
```

```math
% 半经验脱附率模型
\dot{m}_{\text{lib}}
= \mathcal{A}_{\text{surface}}\,C\,\Psi\!\left(\tau_{\text{surface}} - \tau_c\right),
\qquad
\Psi(\Delta\tau) = \max(0,\Delta\tau)^{\,n}
\quad(\text{或等价的超线性响应})
```

```math
% 颗粒雷诺数与屏蔽的定性关系
Re_p = \frac{\rho_f U D}{\mu_f},
\qquad
\frac{d}{dD}\dot{m}_{\text{lib}} < 0
\quad\Longleftrightarrow\quad
\text{屏蔽效应随 } D \text{ 减小而减弱}
```

## 实验与结果

- **方法**: 三维 **Eulerian–Eulerian (E-E) CFD** + **k-ω SST** 湍流模型。
- **算例**: **6 个数值算例**，$D \in \{4, 5\}$ cm，$Re_p \in [2000, 4000]$。
- **机制性结论**:
  - **沥青脱附是剪切驱动的**，**仅当块体表面剪切应力超过临界阈值**才发生；
  - **$Re_p \uparrow$ → 脱附率↑**（局部剪切力增强）；
  - **$D \downarrow$ → 脱附率↑**（颗粒屏蔽减弱）。
- **半经验模型**: **预测误差 < 8.3%**（对照实验脱附数据）。
- **价值**: 澄清了控制沥青脱附的**流–固相互作用机制**，并提供了预测工业水力输送**回收效率**的物理基础工具。

## 局限性

- **模型简化**：E-E 方法把沥青–砂聚集体的**内部结构完全抹平**（视为一个连续相），无法描述**块体内部的降解、孔隙中沥青的滞留、表面薄膜的剥离动力学**。
- **未显式追踪沥青相的输运**：本文关注"从块体剥离"这一局部事件，但剥离后沥青在管道中的**分散、团聚、再附着**未涉及。
- **半经验模型的参数依赖**：$\tau_c$、$C$、$n$ 等参数需要针对**具体油砂样品/温度**标定，**跨油砂源/跨温度的可迁移性未验证**。
- **k-ω SST 的适用性**：块体表面的绕流分离与尾迹用 SST 描述，是否足以捕捉"剪切驱动剥离"的局地机制值得检验。
- **几何简化**：块体尺寸 $D = 4$、5 cm 相当大，与实际油砂团块（多为厘米级以下的团聚体）差距明显；结论向更小尺度的外推需要论证。
- **温度**：沥青黏度对温度**极敏感**，本文未见温度参数化讨论。
- **二维/三维与网格依赖性**：3D E-E + 复杂几何的网格要求高，网格无关性验证未在摘要中提及。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — E-E 两相流框架（OpenFOAM 有 interFoam 系类模型，但需要针对超高黏度比做滑移与有效黏度标定）；真实块体几何需几何清理 + 网格生成（snappyHexMesh）。
- **预期性能**: 3D E-E 计算成本中等（无界面捕获要求，比 VOF 便宜）；6 算例属中等规模。
- **适用场景**:
  - **油砂/重油水力输送与管道设计**：本文给出的"临界剪切应力"判据可直接用于**流量下限设定**；
  - **浆体输送 (slurry transport)**、**稠油管道**、**土壤修复 (electrokinetic/chemical mobilization)**：同一机制可推广；
  - **黏性包裹体剥离的通用研究**：如聚合物涂层剥离、食品颗粒去衣、食品加工中的脱壳 (de-shelling)；
  - **E-E 数值方法的案例参考**：本文是"何时不该用 VOF/DPM"的示范。
- **可复用要点**:
  - **"黏度比 6–9 个数量级 → 必须用 E-E"** 是选型的硬规则。建议把这条写入本知识库的多相流方法选择清单。
  - **"机制 → 低维半经验模型"的工作流**：先做机制识别（本文：剪切驱动 + 临界阈值），再构造模型，因而能达到 <8.3% 误差。这比直接黑箱拟合更可靠、更可解释、更易迁移。
  - **临界判据 $\tau > \tau_c$ 的工程用法**：给出**"有效 vs 无效"的清晰分界**，便于工程决策（如最低流量设定），比连续拟合曲线更实用。
  - **"两个效应同向"的参数分析结论**（$Re_p$ 与 $D$）应归档为"多相剪切剥离"的通用参数规律。
  - 建议与本轮 [[2026-11-12-arXiv-2611.11138-Odd-Darcy-Law-Odd-Viscosity-Edge-Currents]]（多孔介质中的手性输运）对照：两者都涉及**多孔/颗粒介质中的输运**，可归入同一知识条目簇。
