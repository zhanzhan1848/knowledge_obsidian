## 核心贡献

> 通过 Multi-Fidelity EnKF 把 RANS + HRL 双保真仿真与 PIV 实验对齐，再用其结果训练 ML 体积力源项，并以 Mixture-of-Experts 解决 blade-tip 等局部超差。

1. **MFEnKF（Multi-Fidelity Ensemble Kalman Filter）**：用 PIV 实验数据校正"稳态 RANS（粗网格）+ 动网格 unsteady hybrid RANS/LES（HRL）"双保真仿真
2. **双保真+实验** 数据库训练 **ML 体积力源项 $F_{\text{ML}}(U,\nabla U,\nu_t)$**：直接加在 NS 离散形式中
3. **Mixture-of-Experts (MoE)** 路由：分类不同流区，调用对应 ML 子模型，解决 blade-tip 等局部误差抬头
4. MoE 修正后模型与实验偏差 **系统性低于 baseline RANS**，且 **接近 MFEnKF 但无须实验输入**

## 技术方案

### 核心思想

把"PIV 实验 → DA 校正 CFD → 训练 ML 修正项"做成可剥离 **DA 环节**的离线工具：在线部署只需 RANS + ML 修正。

### 关键技术

| 技术 | 说明 |
|------|------|
| Multi-Fidelity EnKF | 协方差矩阵耦合 RANS（低保真）与 HRL（高保真），节省 80%+ 高保真样本 |
| ML 体积力源项 | MLP 输入 $(U, \nabla U, \nu_t)$ → 输出体积力 $F$，并入 NS 残差 |
| Mixture-of-Experts 路由 | 不同 flow region（吸力面/压力面/blade-tip/wake）调用不同 expert |
| Hybrid RANS/LES（HRL） | RANS 区 + LES 区混合，DDES / SA-IDDES 形式 |

## 公式

### NS 加 ML 体积力

$$
\frac{\partial U}{\partial t} + \nabla\cdot\!\left(U\!\otimes\! U\right) = -\nabla p + \nabla\!\cdot\!\boldsymbol{\tau} + F_{\text{ML}}(U,\nabla U,\nu_t)
$$

### MFEnKF 状态更新

$$
x^a = x^f + K\left(y - \mathcal{H}x^f\right),\quad K = P^f H^\top \left(HP^fH^\top + R\right)^{-1}
$$

- 上标 $a$: analysis, $f$: forecast, $H$: observation operator, $R$: 观测协方差
- 双保真耦合：$P^f = \rho_{LF} P^{LF} + \rho_{HF} P^{HF}$

### MoE 输出

$$
F_{\text{ML}}(x) = \sum_{i=1}^{N_E} g_i(x)\, F_{\text{ML},i}(x)
$$

- $g_i(x)$：路由门（softmax over flow-region classifier）

## 实验结论

- **数据集**：轴流压气机级 PIV 实验数据 + CFD 双保真数据库
- **基线**：
  - Baseline 稳态 RANS
  - MFEnKF（须实验在线输入）
  - 全局单一 ML 模型
- **结果**：
  - **全局精度**：ML 与 MFEnKF 接近
  - **局部精度**（blade-tip）：单一 ML 在 tip 区域误差反超 baseline RANS；MoE 把 tip 误差拉回
  - **工程意义**：MoE 模型部署时 **无须实验输入**，速度与 RANS 持平

---

## 局限性

- 单个组件（轴流压气机）单工况；**多工况/多转速通用性未验证**
- MoE gate 训练集依赖 MFEnKF 输出，泛化到新拓扑仍需重训
- 论文无开源代码 → **复现成本高**

## 实现建议

- **实现难度**：**极高**（三模块：MFEnKF 在 OpenFOAM/SU2 上重写、ML 训练流水、MoE routing 训练）
- **预期性能**：
  - 在线：与 RANS 同样的 wall-clock（推理）
  - 离线训练：MFEnKF 一次性 cost，符合工业 12–24 月刷新节奏
- **适用场景**：
  - 轴流/离心叶轮机械 RANS 精度补偿
  - 涡轮叶片气膜冷却、喘振裕度评估
  - 任何"PIV/CFD 双信源 + ML"工业场景
- **集成路径**：
  1. `pimpleDyMFoam` 作高保真，`simpleFoam` 作低保真
  2. DAFOAM / OpenFOAM-MFR 容器化 MFEnKF
  3. PyTorch 训练 MLP + MoE
  4. TFOAM-style UDF 把 $F_{\text{ML}}$ 注入 `UEqn.H`
- **风险**：MoE router 在新工况失稳；建议保留 DA 路径做 drift 监控
