## 核心贡献

> 提出"**先敏感性分析、再参数反演**"的两步 PINN 框架，用 KdVB 方程反演起泡液体的物理参数

1. **前向**：PINN 复现 Korteweg-de Vries-Burgers (KdVB) 方程（描述起泡液体中弱非线性波传播）的参考解；初始时刻预测误差近乎为零，确认初值被精确施加
2. **敏感性分析**（关键创新）：在反演**之前**，量化 8 个物理参数各自对 KdVB 方程的**系数级**与**解级**影响 → **事先评估每个参数的反演难度**
3. **反演**：基于敏感性评估结果，对 8 个中的 7 个做**单参数反演**
4. 结果：液体粘性、气泡初始半径、液体密度、声速、液体压力误差 **0.8–2.1%**；**多方性指数仅部分收敛**；**表面张力系数完全无法估计**——与敏感性分析的预判**完全一致**

## 技术方案

### 核心思想

盲目对所有参数做反演是浪费且容易失败的。先做敏感性分析，可以**预测哪些参数本来就不可辨识**，从而避免在不可能的任务上浪费时间，并给结果赋予可信的解释。

### 关键技术

| 技术 | 说明 |
|------|------|
| KdVB 方程 | 弱非线性耗散色散波，起泡液体超声传播模型 |
| 强形式 PINN | 把 KdVB 残差写入训练损失 |
| 系数级 + 解级敏感性 | 双重敏感性度量 |
| 单参数反演 | 逐个参数独立反演，避免参数耦合 |
| 8 参数集 | 粘性、气泡初始半径、密度、声速、压力、多方性指数、表面张力等 |

## 公式

```math
Korteweg-de Vries-Burgers (KdVB):
  u_t + a u u_x - ν u_xx + β u_xxx = 0
  弱非线性 + 耗散 + 色散

KdVB 中的物理参数:
  a  ← 与液体密度 ρ_l、声速 c  相关
  ν  ← 液体粘性 μ / 密度
  β  ← 表面张力 σ（色散项）
  γ  ← 多方性指数（气泡内部气体状态）

敏感性（解级）:
  S_i = ∂ ||u_θ(θ)||² / ∂θ_i  在 θ_i 归一化方向上的梯度范数
  (亦做系数级: 直接看 θ_i 进入方程的方式)

反演误差:
  e_i = |θ_i^est - θ_i^true| / |θ_i^true|
```

## 代码片段

```python
import torch
import torch.nn as nn

class KdVBPINN(nn.Module):
    """KdVB 方程的强形式 PINN"""
    def __init__(self, n_params=8):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(2, 64), nn.Tanh(),
                                 nn.Linear(64, 64), nn.Tanh(),
                                 nn.Linear(64, 1))
        self.log_params = nn.Parameter(torch.zeros(n_params))  # 待反演参数

    def residual(self, x, t):
        u = self.net(torch.cat([x, t], dim=-1))
        u_x = torch.autograd.grad(u, x, grad_outputs=torch.ones_like(u),
                                  create_graph=True)[0]
        u_xx = torch.autograd.grad(u_x, x, grad_outputs=torch.ones_like(u_x),
                                   create_graph=True)[0]
        u_xxx = torch.autograd.grad(u_xx, x, grad_outputs=torch.ones_like(u_xx),
                                    create_graph=True)[0]
        u_t = torch.autograd.grad(u, t, grad_outputs=torch.ones_like(u),
                                  create_graph=True)[0]
        a, nu, beta = self.log_params[0], self.log_params[1], self.log_params[2]
        return u_t + a*u*u_x - nu*u_xx + beta*u_xxx

def sensitivity_analysis(model, x_eval, t_eval, param_idx, eps=1e-3):
    """系数级 + 解级敏感性"""
    base = model.net(torch.cat([x_eval, t_eval], dim=-1)).detach()
    with torch.no_grad():
        p = model.log_params[param_idx].clone()
        model.log_params[param_idx] = p + eps
        pert = model.net(torch.cat([x_eval, t_eval], dim=-1))
        model.log_params[param_idx] = p
    return float(((pert - base)**2).mean())
```

## 实验结论

- **数据集**: KdVB 方程参考解 + 起泡液体超声传播波形
- **基线**: 无敏感性预分析的盲目反演
- **结果**:
  - 前向 PINN 复现参考解，**初始时刻预测误差近乎为零**（初值精确施加）
  - 敏感性分析成功**事先**判定各参数的反演难度
  - 反演精度：粘性、气泡初始半径、密度、声速、压力误差 **0.8–2.1%**
  - **多方性指数仅部分收敛**
  - **表面张力系数完全无法估计** —— 与敏感性分析结论一致，验证了"敏感性预判"的可靠性

---

## 局限性

- KdVB 是弱非线性单方程模型，未完全刻画真实起泡液体的多相/耗散细节
- 仅单参数反演，未演示多参数同时反演（参数耦合问题未解决）
- PINN 训练成本随参数数上升，且强形式 PINN 本身有已知困难
- 超声场景与高频、衰减等实际因素未纳入
