## 核心贡献

> 系统比较了 Dubreil-Jacotin-Long 方程神经求解器中的"能量选择"与"残差驱动"两类目标函数：基于 Turkington 变分原理与非线性 APE 的约束 Deep Ritz 目标能恢复出物理 mode-1 内孤立波，而强/弱形式残差目标在所有精确解处均取零值、无法区分物理解，一轮下降即丢失预设 APE；并据此提出残差精修策略，扩展计算四种分层下的 mode-2 内孤立波，核心形态复现南海陆架观测的双瓣结构。

1. 揭示了残差型损失函数的根本缺陷：残差在每个精确解处都为零，因此不区分物理解与其余根（平凡态、振荡波列、展宽近解），无法完成"先选波、再解波"的任务。
2. 用精确的 virial 分解证明每个定域波携带的动能都超过其 APE，因而二次型 APE 目标会偏好展宽场；非线性 APE 增强（计算波中达 1.27–2.06 倍）反转了这一序，但被偏好的波宽仍只是弱选择。
3. 提出并验证了**两阶段求解策略**：先以受约束 Deep Ritz 目标完成波的选择，再在精确 APE 约束下做残差精修，从而满足全部验收准则并缓解"高频误差不被能量罚项惩罚"导致的欠分辨问题。
4. 通过在试函数空间中**结构性排除 mode 1**，成功计算四种分层下的 mode-2 内孤立波，其核部定性再现南海陆架观测到的双瓣结构。

## 技术方案

### 核心思想
DJL 方程描述两层流体界面上的内孤立波，它是一个多解问题：除了物理的单孤立波，还存在平凡解、振荡波列以及展宽的"近解"。因此求解器面临的首要任务是**选择**而非求解——必须先把物理波从解族中挑出来。论文采用 Turkington 变分原理：该原理以可用势能（APE）的非线性作为选择器。关键的 virial 精确分解表明，任何定域波的动能都大于 APE，这意味着用二次型 APE 会偏向展宽场；而非线性 APE 的增强反转了动能–APE 的排序，从而锁定物理波，但波宽只是被弱选择。之后以 KdV 导出的初值作为共同的起点，对比两种损失设计：受约束的 Deep Ritz（能量/APE 目标 + 约束）与强/弱形式残差目标（PINN 类）。实验表明残差目标在所有精确根上取零，因而无选择能力，一步下降即偏离预设 APE；且其恢复的波欠分辨，因为残差由能量几乎不惩罚的高波数误差主导。最后以残差精修（保持 APE 精确）补足分辨度。对 mode-2，采用在试空间中结构性去掉 mode-1 分量的手段强迫求解器进入第二分支。

### 关键技术

| 技术 | 说明 |
|------|------|
| Turkington 变分原理 | 以非线性可用势能作为波的选择机制 |
| 非线性 APE | 选择性判据；增强后反转动能–APE 排序，锁定物理波 |
| 精确 virial 分解 | 证明定域波动能 > APE，推翻二次型 APE 的偏好 |
| 受约束 Deep Ritz 目标 | 能量型损失 + 显式 APE 约束，成功恢复 mode-1 波 |
| 强形式/弱形式残差目标 | PINN 风格损失；因在所有精确解处为零而丧失选择能力 |
| 残差精修 (residual refinement) | 在固定精确 APE 前提下用残差降低欠分辨的高频误差 |
| 结构性排除 mode 1 | 从试函数空间消去第一分支以计算 mode-2 波 |
| KdV 派生初值 | 为各目标函数提供共同的初始解，确保比较公平 |
| 线性化模态估计 | 对已分辨波做线性估计，评估相对 mode-1 辐射强度 |

## 摘要要点

> Neural solvers offer structural flexibility for the Dubreil-Jacotin-Long (DJL) equation of internal solitary waves, which also admits the trivial state, oscillatory wavetrains and broadened near-solutions. A solver must select the physical wave before resolving it. Turkington's variational principle selects the wave through the nonlinearity of the available potential energy (APE). An exact virial partition shows that every localized wave carries more kinetic energy than APE, so a quadratic APE would favour a broadened field. The nonlinear APE enhancement, $1.27$--$2.06\times$ for the computed waves, reverses this ordering, although the preferred width remains weakly selected. From a shared KdV-derived start, a constrained Deep Ritz objective recovers the mode-1 wave, whereas strong- and weak-form residual objectives, which vanish at every exact solution and therefore do not favour the physical wave over other root, lose the prescribed APE within one descent round. The recovered wave is under-resolved because its residual is dominated by high-wavenumber error that the energy barely penalizes, and a residual refinement at exact APE then meets every acceptance criterion. Structurally excluding mode 1 from the trial space, we compute mode-2 waves on four stratifications. A computed wave core qualitatively reproduces the two-lobe structure observed on the South China Sea shelf. In the deep basin, the selected core misses the residual criterion, and residual refinement widens it with little change in the energy objective. The two resolved linear estimates suggest weaker relative mode-1 radiation at larger ratios of wave half-width to resonant wavelength.

## 公式 / 理论要点

```math
% 背景方程：Dubreil-Jacotin-Long (DJL) 方程（二层流体内孤立波）
\frac{\partial^2 \eta}{\partial t^2}
+ (\boldsymbol{u}_1-\boldsymbol{u}_2)\cdot\nabla\left(\frac{\partial^2 \eta}{\partial t^2}
+ \nabla\cdot\left(\boldsymbol{u}_1-\boldsymbol{u}_2\right)\nabla\eta\right)=0
```

```math
% Turkington 变分原理：以非线性 APE 作为选择判据
\delta \mathcal{E}_{\mathrm{APE}}\big[\eta\big]=0,
\qquad
\mathcal{E}_{\mathrm{APE}} = \mathcal{E}_{\mathrm{kin}} - \mathcal{E}_{\mathrm{pot}}
```

```math
% 精确 virial 分解：定域波动能恒大于 APE
\mathcal{E}_{\mathrm{kin}} > \mathcal{E}_{\mathrm{APE}}
\quad\Longrightarrow\quad
\text{二次型 APE 偏好展宽场}
```

```math
% 非线性 APE 增强因子（反转动能–APE 排序）
\Gamma_{\mathrm{APE}}
= \frac{\mathcal{E}_{\mathrm{APE}}^{\mathrm{nonlinear}}}{\mathcal{E}_{\mathrm{APE}}^{\mathrm{quadratic}}}
= 1.27 \text{--} 2.06
```

```math
% 受约束 Deep Ritz 目标（能量型损失 + APE 约束）
\mathcal{L}_{\mathrm{Ritz}}
= \mathcal{E}_{\mathrm{kin}}[\eta] - \mathcal{E}_{\mathrm{pot}}[\eta]
+ \Lambda\left(\mathcal{E}_{\mathrm{APE}}[\eta] - \mathcal{E}_{\mathrm{APE}}^{\mathrm{target}}\right)^2
```

```math
% 强形式与弱形式残差目标（对任何精确解都为零 → 无选择能力）
\mathcal{L}_{\mathrm{strong}} = \left\|\,\frac{\partial^2 \eta}{\partial t^2}
+ (\boldsymbol{u}_1-\boldsymbol{u}_2)\cdot\nabla\left(\frac{\partial^2 \eta}{\partial t^2}
+ \nabla\cdot(\boldsymbol{u}_1-\boldsymbol{u}_2)\nabla\eta\right)\right\|^2
```

```math
% 高波数误差主导残差而能量几乎不惩罚 → 欠分辨
\left\|R\right\| \sim O(k_{\max}^{p}), \qquad
\frac{\partial \mathcal{E}_{\mathrm{kin}}}{\partial k_{\max}} \approx 0
```

```math
% 相对 mode-1 辐射的线性估计指标（波半宽 / 共振波长之比）
\eta \sim A\,\mathrm{sech}^2\!\left(k\,x\right), \qquad
\frac{h_{\mathrm{wave}}}{\lambda_{\mathrm{res}}}
\quad\Longrightarrow\quad \text{相对 mode-1 辐射减弱}
```

## 实验与结果

- **算例/数据集**: DJL 方程内孤立波问题；mode-1 波在共享的 KdV 派生初值上求解；mode-2 波在四种分层（stratification）构型下求解，并与南海陆架（South China Sea shelf）观测到的双瓣结构对照。
- **对比基线**: 三类目标函数在**同一 KdV 导出初值**下的对比——受约束 Deep Ritz（能量/APE 目标）、强形式残差、弱形式残差；以及各方法的"残差精修"版本。
- **主要结果**:
  - **选择能力的理论刻画**：精确 virial 分解表明任何定域波动能 > APE，二次型 APE 会偏好展宽场；非线性 APE 增强 1.27–2.06 倍后该排序被反转，但被偏好的波宽仍只是**弱选择**。
  - **目标函数对比**：受约束 Deep Ritz 成功恢复 mode-1 物理波；强/弱形式残差目标因在所有精确解处均消失而不偏好物理解，**在一轮下降之内**即丢失预设的 APE 值。
  - **欠分辨诊断与补救**：恢复出的波欠分辨，因为残差由能量几乎不惩罚的高波数误差主导；在保持精确 APE 的条件下做残差精修后，满足全部验收准则。
  - **mode-2 应用**：结构性排除 mode 1 后，在四种分层上计算出 mode-2 波；其波核定性再现了南海陆架观测到的双瓣结构；深水盆地情形下所选波核未满足残差准则，残差精修使其变宽而能量目标几乎不变。
  - **辐射评估**：两个已分辨波的线性估计表明，在波半宽与共振波长之比更大时，相对 mode-1 辐射更弱。

## 局限性

- 仅针对 DJL 方程这一特定非线性波动方程，结论向其他多解 PDE 的推广性需另行验证。
- 变分原理的选择性本质上是间接的：APE 的非线性增强只给出**弱选择**，波宽仍存在退化。
- mode-2 在深水分层下未满足残差准则，说明残差精修与能量目标之间存在实际冲突，两阶段策略并非总是充分。
- 深水盆地情形中残差精修"变宽但能量目标几乎不变"，暗示能量型验收准则在某些分层下判别力不足。

## 实现建议

- **实现难度**: 中 — 需实现 DJL 求解（可借浅水/两层框架）、Turkington 变分原理的 APE 计算与非线性增强、Deep Ritz 与残差两种损失、mode-1/mode-2 结构性排除；均为标准深度学习组件，物理后处理是关键。
- **预期性能**: 受约束 Deep Ritz + 残差精修的两阶段流程可在多数情形下给出满足全部验收准则的解；但 mode-2 在深水分层下仍可能不达标，需要额外诊断（线性模态估计、谱诊断）而非单纯加密。
- **适用场景**: 内孤立波（内潮波、密度流界面波）求解与判别、多解非线性方程的物理解选择、深学习求解器中"损失函数选取"的方法学讨论、海洋内波与水交换建模。
- **可复用要点**:
  - **"残差目标无法选择物解"**是 PINN 类方法的一个根本性限制（残差在所有精确根处为零），对任何存在多解的问题都成立。这一判据应写入 PINN 设计规范：多解问题必须辅以能量/熵型选择器。
  - **"先选择、后精修"的两阶段求解范式**（变分/能量目标定分支 → 固定能量做残差精修）是可迁移的通用策略，能同时兼顾分支判别与分辨精度，适用于任何含多分支的非线性方程求解。
  - **用非线性量而非二次型量做选择器**的思路可迁移到其他能量/熵判据的设计中；二次型退化导致的"偏好展宽解"是常见陷阱。
  - **结构性排除错误分支（正交投影/掩码）**以强制求解器进入目标分支，是处理多解问题的实用工程手段。
