## 核心贡献

> 用**分段圆弧 + 尖点（corner/cusp）facet** 扩展 VOF 界面重构表示：接口用线性 facet、圆弧、以及由两条线或弧在**单单元内**接合成的 corner facet 表示；通过**图上的方向约束传播 + 单元合并**解决多解性，把**拓扑一致性作为一等约束**处理；在变曲率界面上达到**facet-gap 误差三阶收敛**、**曲率误差约一阶收敛**。

1. **表示能力的扩展**：经典 PLIC 只能表示平面；LVIRA/ELVIRA 用二次曲面但难以保持尖锐特征。本方法允许一个单元内的界面同时包含**平面段、圆弧段和尖点段**，从而在粗网格上保留角点与曲率。
2. **拓扑一致性作为一等约束**：先通过图传播局部方向约束，再合并单元消除歧义——这是与"逐单元独立拟合"方法的根本区别。
3. **保守的 $C^0$ 连续性精修**：可选的精修步骤在**保持局部体积约束**的前提下改善 $C^0$ 连续性。
4. **模块化开关**：圆弧 facet、corner facet、单元合并、连续性精修可**独立启用**，在精度与算力成本之间自由取舍。
5. **竞争性基线**：最简配置（仅线性 facet + 局部拟合）即提供与 SOTA PLIC 方法竞争的**快速局部直线拟合**。
6. **静态基准验证**：在粗、扰动的 Cartesian 网格上，可辨识的直线、圆与充分分辨的角点都能**重构到数值精度**；变曲率界面 facet-gap 三阶、曲率一阶；保证**全局体积守恒**。

## 技术方案

### 核心思想

几何 VOF 的核心矛盾：**体积分数 $\alpha_k$ 是单元级的标量积分信息，而界面几何（法向、位置、曲率、角点）是高阶局部信息**。PLIC 用一个平面（2 个自由度）去匹配一个体积分数，在曲面上必然产生 $O(h)$ 的弦高缺陷。

本方法的思路是**扩展 facet 的几何类型**：
- 平面 facet（线性）→ 覆盖平坦界面；
- 圆弧 facet → 覆盖柱面/球面等常曲率片段；
- corner facet（两条线或两条弧在单单元内接合）→ 覆盖棱线、锥尖、液滴接触点。

**关键在于歧义消除**：一个单元的体积分数 $\alpha_k$ 可以被无穷多种界面几何解释（例如一个"角"可以是锐角也可以是钝角、圆弧可以朝内也可以朝外）。传统方法靠模板匹配或梯度法在局部猜测，误差会沿界面累积。本方法把问题建模为**图上的约束满足**：

1. 每个界面单元产生**局部方向约束**（候选 facet 的法向/朝向）；
2. 沿界面邻接关系**传播**这些约束；
3. 当约束冲突时**合并单元**（把两个单元视为一个更大的区域共同求解），使几何自洽；
4. 拓扑一致性（界面连通性、无孤岛、无法向翻转）作为硬约束而非事后检查。

### 关键技术

| 技术 | 说明 |
|------|------|
| **圆弧 facet** | 界面片段用圆弧表示（法向 + 位置 + 曲率半径 3 个自由度），比平面的 2 个自由度多 1 阶，可匹配柱面/球面 |
| **Corner facet** | 单元内两段（线-线、线-弧、弧-弧）在一点接合，表示角点/尖点；需要额外的拓扑信息决定内角 |
| **图传播方向约束** | 在界面邻接图上传播局部朝向约束，把局部歧义变为全局一致问题 |
| **单元合并（cell merging）** | 约束冲突时合并相邻单元扩大求解域，消除局部歧义；这是拓扑一致性的实现手段 |
| **保守精修** | 在不破坏体积分数（每单元体积精确匹配）的前提下调整 facet 位置以改善 $C^0$ 连续性 |
| **PLIC 基线** | 对比方法：标准面片切割 + 体积分数反解 |
| **LVIRA / ELVIRA** | 对比方法：用二次曲面重建界面以捕获曲率 |
| **Detrixhe–Aslam** | 对比方法：单元内二次曲面拟合取曲率 |
| **facet-gap error** | 误差度量：重构界面与真界面之间的间隙（几何保真度主指标） |
| **曲率误差** | 误差度量：重构曲率与真曲率之差 |
| **静态基准** | 标准几何基准（平面、圆柱、球、角点组合）用于验证可辨识性与精度 |

## 公式

```math
\text{单元内体积约束（PLIC 核心）}:\quad
\alpha_k = \frac{1}{|\Omega_k|}\int_{\Omega_k}\chi(\bm{x})\,dV,
\qquad
\int_{\Omega_k}\chi(\bm{x})\,dV = V_{\text{liquid}}
\quad\Longrightarrow\quad
\text{界面几何须精确匹配 } V_{\text{liquid}}
```

```math
\text{平面 facet 的自由度与匹配（PLIC）}:\quad
\bm{n}\cdot(\bm{x}-\bm{x}_0) = p
\quad\text{（2 个自由度：}\bm{n}\text{ 方向 + }p\text{ 位置）}
```

```math
\text{圆弧 facet 的自由度}:\quad
(\bm{n},\;p,\;R)
\quad\text{（3 个自由度，多出的 1 个用于匹配曲率）}
```

```math
\text{corner facet 的约束数}:\quad
\text{两段接合} \Rightarrow \text{自由度增加 1，接合点位置被体积约束固定}
```

```math
\text{方向约束传播（图上的 CSP）}:\quad
\forall\, e=(i,j)\in E_{\text{interface}}:\quad
\mathcal{C}_i \wedge \mathcal{C}_j \neq \emptyset
\quad\text{（邻接单元的法向候选集必须相容）}
```

```math
\text{保守精修（保持体积）}:\quad
\delta V_k = 0\ \ \forall k
\quad\text{s.t.}\quad
\text{精修后 facet 的几何误差 } \downarrow,\ \text{体积误差不变}
```

```math
\text{收敛性（变曲率界面）}:\quad
\text{facet-gap 误差} \sim O(h^3),
\qquad
\text{曲率误差} \sim O(h)
```

## 代码片段

```python
# 概念性伪代码：方向约束传播 + 单元合并 + 保守精修
import numpy as np

class PiecewiseInterfaceReconstructor:
    """
    接口表示：linear facet | circular arc facet | corner facet
    依赖：仅体积分数 alpha[k]
    """

    def __init__(self, alpha, cell_centers, cell_sizes, level_set=None):
        self.alpha = alpha                # 体积分数 (ncells,)
        self.xc = cell_centers            # 单元中心 (ncells,3)
        self.h = cell_sizes               # 单元尺寸 (ncells,3) 或 (3,)
        self.level_set = level_set        # 可选：用于界面单元筛选（不是必需）

    # ---------- 1. 界面单元筛选 ----------
    def interface_cells(self):
        """界面单元：体积分数既不接近 0 也不接近 1"""
        eps = 1e-12
        return np.where((self.alpha > eps) & (self.alpha < 1.0 - eps))[0]

    # ---------- 2. 局部 facet 候选 + 方向约束 ----------
    def local_constraints(self, k):
        """
        对单元 k 枚举可行的 facet 配置，产生方向约束集合：
          - 线性 facet: 2 参数 (n, p)
          - 圆弧 facet: 3 参数 (n, p, R)
          - corner facet: 两段接合
        每个配置需满足：精确匹配 alpha[k] 的体积约束
        """
        candidates = []
        # 线性 facet：法向候选来自邻域梯度方向的对称集
        for n_dir in self.candidate_normals(k):
            n = n_dir / np.linalg.norm(n_dir)
            p = self.solve_plane_offset(k, n, self.alpha[k])
            if p is not None:
                candidates.append({
                    "type": "linear", "n": n, "p": p,
                    "residual": abs(self.cut_volume(k, n, p) - self.alpha[k])
                })
        # 圆弧 facet：增加曲率自由度 R，对 R 做一维搜索
        for n_dir in self.candidate_normals(k):
            n = n_dir / np.linalg.norm(n_dir)
            R = self.solve_arc_radius(k, n, self.alpha[k])
            if R is not None:
                p = self.solve_plane_offset(k, n, self.alpha[k])
                candidates.append({
                    "type": "arc", "n": n, "p": p, "R": R,
                    "residual": abs(self.cut_volume_arc(k, n, p, R) - self.alpha[k])
                })
        return candidates

    # ---------- 3. 图传播 + 单元合并 ----------
    def resolve_topology(self, constraints, neighbors):
        """
        在界面邻接图上传播方向约束；
        冲突处合并单元（扩大求解域）直到相容。
        拓扑一致性为硬约束：连通性、不翻转、无孤岛。
        """
        merged = {}
        for k, cands in constraints.items():
            merged[k] = cands
        changed = True
        while changed:
            changed = False
            for k, j in neighbors.items():
                if k not in merged or j not in merged:
                    continue
                if not self.compatible(merged[k], merged[j]):
                    # 冲突 -> 合并为联合求解组
                    grp = self.merge_cells(k, j, merged, neighbors)
                    merged.pop(j, None)
                    changed = True
        return merged

    # ---------- 4. 保守 $C^0$ 精修 ----------
    def conservative_refine(self, facets, max_iter=5):
        """
        在保持每单元体积精确的前提下调整 facet 参数，
        最小化相邻单元之间的 $C^0$ 不连续量。
        """
        for _ in range(max_iter):
            grad = self.continuity_gradient(facets)   # d(discontinuity)/d(params)
            for k in facets:
                # 约束方向切空间 + 体积约束方向
                dV = self.volume_gradient(facets, k)
                # 解一个带约束的最小二乘步
                step = self.constrained_ls_step(grad, dV, facets[k])
                facets[k] = self.apply_step(facets[k], step)
        return facets

    # ---------- 5. 组装输出 ----------
    def reconstruct(self):
        cons = {k: self.local_constraints(k) for k in self.interface_cells()}
        nbrs = self.build_interface_graph()
        resolved = self.resolve_topology(cons, nbrs)
        if self.enable_refinement:
            resolved = self.conservative_refine(resolved)
        return self.assemble_facets(resolved)
```

## 实验结论

- **静态基准（平面/圆柱/球/角点组合）**：在粗、扰动的 Cartesian 网格上，可辨识的直线、圆与**充分分辨的角点**可重构到**数值精度**。
- **变曲率界面**：**facet-gap 误差三阶收敛**，**曲率误差约一阶收敛**。
- **最简配置**：仅线性 facet 的快速局部直线拟合，与 SOTA PLIC 方法**竞争**。
- **体积守恒**：保证**全局体积守恒**（保守精修不破坏局部体积约束）。
- **模块化**：圆弧、corner、合并、精修可独立开关 → 精度/成本可调。

---

## 局限性

- **角点可辨识性有前提**：只有当角点**充分分辨**（相对于网格尺度）时才能重构到数值精度；未分辨的角点无法恢复——这是信息论限制而非算法缺陷。
- **曲率仅一阶**：曲率误差约一阶收敛，弱于 facet-gap 的三阶，说明**曲率的提取仍是瓶颈**（与 [[2026-10-30-DAVOF-dual-area-volume-of-fluid-interface-normal]] 中"一圈曲率"的阶数天花板一致）。
- **拓扑合并的计算代价**：单元合并会扩大求解域，**最坏情况下的复杂度与网格拓扑相关**，论文未给出完整的复杂度上界分析。
- **依赖界面单元筛选**：方法需要可靠的界面单元识别（本文用体积分数阈值；若纯 VOF 无 level set 则阈值敏感）。
- **未涉及输运**：本文主体是**静态重构**；与时间推进的耦合（几何 VOF 的输运回路）未系统讨论。
- **网格限制**：验证集中在 Cartesian（含扰动）网格，**非结构多面体网格上的表现未验证**。
- **与现有 SOTA 的横向对比有限**：主要对比 PLIC 类，对 LVIRA/ELVIRA 的完整复现细节未充分展开。

## 实现建议

- **实现难度**：🔴 高。图约束传播 + 单元合并是算法核心但概念清晰；corner facet 的拓扑判定（内角 vs 外角）是**最难的部分**。
- **预期性能**：facet-gap 三阶优于 PLIC 的一阶；但**曲率仅一阶**，若下游依赖曲率（毛细力），收益有限——**建议先做线性的 PLIC 替代，再逐模块打开**。
- **适用场景**：
  - **粗网格 + 强曲率界面**（液滴、破碎、界面张力主导的多相流）；
  - **需要保留几何特征**（棱线、锥尖、接触线）的界面；
  - **CPU 成本敏感**时可用"最简配置"（快速局部直线拟合）先替代部分 PLIC 实现。
- **落地建议**：
  1. **渐进式启用**：先只开 corner facet（最直接的精度收益），再评估圆弧；
  2. **务必做拓扑一致性测试**（连通性、无孤岛）——这是本方法相对逐单元拟合的核心优势；
  3. **合并策略需按问题调整**：合并可能造成局部过约束，论文未给出何时停止合并的通用准则；
  4. **直接复用作者的 GitHub release**（含代码与基准数据），可省去大量验证工作。
