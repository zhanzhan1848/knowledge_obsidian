## 核心贡献

> **空中拖曳系统 (aerial towing)** 的**螺旋绞合缆 (helically stranded cables)** 遭遇**斜向入流 (oblique inflow)**，但常被建模为**光滑圆柱**，忽略了**三维横向耦合**与**表面纹理**。本文对**光滑圆柱**与**四种绞合缆**（**四种倾角 $22.5^\circ$–$90^\circ$，全部静止，$Re\approx1.0\times10^4$**）进行**大涡模拟 (LES)** 与**谱 POD (SPOD)**。结论：**气动差异主要由横截面对称性与股线尺度沟槽深度支配**；**力源分解显示表面压力贡献平均法向力的 94.9%–98.3%，并主导平均侧向力**；**高对称、近圆形包络维持周向压力平衡**，而**深沟槽、低对称的三叶几何产生非对称分离与持续的侧向压力不平衡**；尾流中，**高对称缆在中高倾角下维持展向同步的卡门脱落**，把脉动能量集中于**一个占优的低秩模态**；**深沟槽破坏脱落相干性、使回流区侧偏，并把能量摊到宽频带尺度上**。**平均侧向力与侧向力脉动是解耦的**：近圆形 $(1\times19)$ 缆**平均侧向力最小但周期性脉动强**，而深沟槽 $(3\times7)$ 缆**脉动弱但平均侧向力可观**。

1. **工程背景**: 螺旋绞合缆在**空中拖曳系统**（如海上拖缆、系泊锚链）承受**斜向入流**。
2. **常见简化的问题**: 常被建模为**光滑圆柱** → 忽略**三维横向耦合 (cross-stream coupling)** 与**表面纹理 (surface texture)**。
3. **方法**: **大涡模拟 (LES)** + **谱 POD (SPOD)**。
4. **算例**: **光滑圆柱** + **四种绞合缆**（$(1\times19)$、$(3\times7)$ 等）× **四种倾角** $22.5^\circ$–$90^\circ$，**全部静止 (stationary)**，**$Re\approx1.0\times10^4$**。
5. **几何主导因素**: 气动差异主要由**横截面对称性**与**股线尺度沟槽深度**支配。
6. **力源分解 (force-source decomposition)**:
   - **表面压力贡献平均法向力的 94.9%–98.3%**；
   - **表面压力主导平均侧向力**。
7. **对称性效应**:
   - **高对称、近圆形包络** → **维持周向压力平衡**；
   - **深沟槽、低对称三叶几何** → **非对称分离** + **持续的侧向压力不平衡**。
8. **尾流结构**:
   - **高对称缆**（中高倾角）→ **展向同步的卡门脱落** → 脉动能量集中在**一个占优的低秩模态**；
   - **深沟槽缆** → **破坏脱落相干性**、**回流区侧偏**、能量**摊到宽频带尺度**。
9. **核心工程结论（平均 vs 脉动解耦）**:
   - **近圆形 $(1\times19)$ 缆**：**平均侧向力最小**，但**周期性脉动强**；
   - **深沟槽 $(3\times7)$ 缆**：**脉动弱**，但**平均侧向力可观**。
10. **意义**: 结果支持**基于构造的缆索选择**与**气动载荷建模**。

## 技术方案

### 核心思想

**工程问题：绞合缆 vs 光滑圆柱**

现实中的缆索不是光滑圆柱，而是**由若干股 (strands) 螺旋绞合**而成。这带来两个本质差别：
1. **横截面不是圆**（取决于绞合方式，如 $1\times19$ 近圆，$3\times7$ 三叶）
2. **表面有股间沟槽**（groove），呈螺旋纹理

在**斜向入流**下，这两点都会产生**侧向力**——而侧向力正是缆索拖曳系统最关心的（可能导致**走偏、缠绕、疲劳**）。

**为什么必须做 LES + SPOD？**

- **定常 RANS 无法给出尾流结构**：卡门脱落的相干性、能量分布模态都需要非定常统计；
- **SPOD 能回答"能量在哪些相干结构上"**：这直接决定了缆索的**疲劳载荷**（低频相干模态 → 大幅周期载荷 → 疲劳破坏）。

**本文的分析逻辑链**

$$\text{几何（对称性 + 沟槽）} \longrightarrow \text{流动分离模式} \longrightarrow \begin{cases}\text{力（平均 + 脉动）}\\\text{尾流相干性}\end{cases}$$

**对称性 → 压力平衡**

近圆形包络（$1\times19$）：各方向**几何对称** → 绕流分离点大致对称 → **周向压力分布平衡** → **侧向力小**。

三叶几何（$3\times7$）：几何**低对称** → 分离点在三个瓣上**不等价** → **非对称分离** → **持续的侧向压力不平衡** → **平均侧向力可观**。

**沟槽深度 → 脱落相干性**

深沟槽引入**三维非定常的表面扰动** → 破坏卡门涡街的**展向相干性** →
- 能量从**单一低秩模态**摊散到**宽频带**；
- **脉动强度下降**（相干涡脱落是脉动的主要来源）；
- **回流区侧偏**（与不对称分离一致）。

**核心洞见：平均侧向力与侧向力脉动由不同几何因素主导，且相互独立**

| | 平均侧向力 | 侧向力脉动 |
|---|---|---|
| **主导因素** | **横截面对称性** | **表面沟槽深度（相干性）** |
| **近圆 $(1\times19)$** | **最小** | **强**（周期性、展向同步） |
| **深沟槽 $(3\times7)$** | **可观** | **弱**（非相干、宽频） |

这是本文最具工程价值的结论——因为**工程需求常常是二选一或多目标**：
- 若关心**长期漂移/走偏**（平均力）→ 选**高对称**缆；
- 若关心**疲劳寿命**（脉动载荷）→ 选**深沟槽**缆（破坏相干性 → 降峰值脉动）；
- **没有一种缆两者兼优**。

**力源分解的价值**

把总力分解为**表面压力贡献**与**粘性剪切贡献**：
- **表面压力占平均法向力的 94.9%–98.3%**；
- 这意味着：**粘性贡献可忽略** → 建模时可**大幅简化**（忽略粘性、只算压力分布）→ 计算成本大降。

这是一个非常实用的**降阶/简化依据**。

### 关键技术

| 技术 | 说明 |
|------|------|
| 大涡模拟 (LES) | 非定常绕流、脱落与相干性 |
| 谱 POD (SPOD) | 尾流相干结构的能量分解，低秩模态识别 |
| 力源分解 | 压力贡献 vs 粘性剪切贡献 |
| 横截面对称性 | 几何主导因素之一 |
| 股线沟槽深度 | 几何主导因素之二 |
| 卡门脱落相干性 | 高对称 vs 深沟槽的关键差别 |
| 展向同步 (spanwise-synchronized) | 相干性的空间特征 |
| 低秩模态 vs 宽频带 | 两种能量分布状态 |
| $Re \approx 10^4$、静止、定常入流 | 计算条件 |
| 斜向入流 (oblique inflow) | 侧向力产生的条件 |

## 公式 / 理论要点

```math
% 力源分解：压力项 vs 粘性项
\boldsymbol{F}_{\text{normal}}
= \underbrace{\int_S (-p\,\boldsymbol{n})\,dS}_{\boldsymbol{F}_{\text{press}}}
+ \underbrace{\int_S (\boldsymbol{\tau}\cdot\boldsymbol{n})\,dS}_{\boldsymbol{F}_{\text{visc}}},
\qquad
\frac{\|\boldsymbol{F}_{\text{press}}\|}{\|\boldsymbol{F}_{\text{normal}}\|}
= 94.9\% \sim 98.3\%
```

```math
% 侧向力（斜向入流下）
\boldsymbol{F}_{\text{lateral}}
= \int_S (-p\,\boldsymbol{n} + \boldsymbol{\tau}\cdot\boldsymbol{n})\,dS
\quad\text{（由周向压力不平衡产生）}
```

```math
% 对称性 → 周向压力平衡
\boldsymbol{n}_{\text{sym}}(\theta) \text{ 旋转对称}
\;\Longrightarrow\;
\int_S p\,\boldsymbol{n}\,dS \approx 0 \quad(\text{侧向力} \to 0)
```

```math
% 沟槽深度 → 脱落相干性破坏（SPOD 低秩性下降）
\frac{\lambda_1}{\sum_j \lambda_j}
= \text{主导模态能量占比}
\quad\begin{cases}
\text{高对称}: & \text{占比高（低秩、展向同步）}\\
\text{深沟槽}: & \text{占比低（宽频带摊散）}
\end{cases}
```

```math
% 绞合缆几何参数化
\text{绞合方式 } (n\times m)\ (\text{如 } 1\times19,\ 3\times7),
\qquad
\text{沟槽深度} \propto \frac{d_{\text{strand}} - d_{\text{core}}}{2}
```

## 实验与结果

- **方法**: **LES** + **SPOD**。
- **算例**:
  - **1 个光滑圆柱** + **4 种螺旋绞合缆**；
  - **4 种倾角**：$22.5^\circ$ – $90^\circ$；
  - 全部**静止 (stationary)**；
  - **$Re\approx1.0\times10^4$**；
  - **斜向入流**。
- **主要结果**:
  1. **几何主导因素**：**横截面对称性**与**股线尺度沟槽深度**。
  2. **力源分解**：**表面压力贡献平均法向力的 94.9%–98.3%**，并**主导平均侧向力**。
  3. **对称性效应**：高对称近圆包络**维持周向压力平衡**；深沟槽低对称三叶几何**产生非对称分离与持续侧向压力不平衡**。
  4. **尾流相干性**：
     - 高对称缆在中高倾角下**维持展向同步的卡门脱落**，脉动能量**集中于一个占优的低秩模态**；
     - 深沟槽**破坏脱落相干性**、**使回流区侧偏**、能量**摊到宽频带尺度**。
  5. **核心解耦结论**：
     - **近圆 $(1\times19)$**：**平均侧向力最小，但周期性脉动强**；
     - **深沟槽 $(3\times7)$**：**脉动弱，但平均侧向力可观**。
  6. **工程意义**：支持**基于构造的缆索选择**与**气动载荷建模**。
- **结构**: 几何 → 流动 → 力与尾流的因果链清晰。

## 局限性

- **仅圆柱形缆**：实际缆索可能是**非圆截面**（如扁平编缆）、**有预张力变形**、**在流载下变形**（柔性缆的形态变化会显著改变阻力）——本文全部**刚性、静止**。
- **静止 (stationary) 约束**：真实的拖曳缆有**缓慢的涡激振动 (vortex-induced vibration)** 与**运动学**，本文排除了这一最重要的实际效应。
- **$Re\sim10^4$ 单一雷诺数**：真实海洋缆可能在 $10^4$–$10^6$，分离点位置与脱落模态会变。
- **无波流耦合**：真实海洋环境有**波浪、浮升力、方向变化**。
- **SPOD 的低秩性是定常入流下的统计**，非定常载荷下的时变模态未做。
- **沟槽几何的建模精度**：真实绞合表面是**三维螺旋**，数值几何的简化程度影响分离行为。
- **未给出侧向力的定量预测公式**：结论是**定性的方向性指导**，不是可直接用于选型的定量准则。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — LES + 复杂三维几何（螺旋股线）+ SPOD 后处理。几何生成是主要工作量。
- **预期性能**: $Re\sim10^4$ 的 LES 成本中等；**SPOD 后处理**需存储大量瞬时场（成本可接受）。
- **适用场景**:
  - **海洋工程与拖曳系统设计**：缆索选型（抗漂移 vs 抗疲劳）；
  - **电缆/脐带缆 (umbilical) 的水动力评估**；
  - **倾斜入流下的圆柱/管件绕流**（支架、管线）；
  - **"表面纹理对绕流影响"的参数化研究**：本文的结论（对称性 vs 沟槽深度的分工）可直接推广到**仿生表面/减阻纹理**设计。
- **可复用要点**:
  - **"平均量与脉动量由不同因素主导"是绕流研究中极有价值的解耦结论**——这个分析框架（把平均力与脉动力分开追溯几何根源）应作为绕流/阻力研究的**标准分析步骤**。
  - **力源分解给出简化依据**：压力占 94.9%–98.3% → **粘性项可忽略** → 可显著简化建模与加速计算。这是一个直接可用的工程简化。
  - **SPOD 主导模态能量占比 $\lambda_1/\sum\lambda_j$ 是相干性的定量指标**，可作为判断"结构化 vs 宽带"的标准标量，建议归档。
  - **"几何对称性 → 周向压力平衡 → 侧向力"** 的因果链是**横截面优化**的基本原理，可用于任何非圆截面设计（如建筑外形、管道支架）。
  - 建议与本轮 [[2026-11-12-arXiv-2611.12028-SPOD-GPR-Parametric-Spatio-Temporal-ROM]] 联读：本文用 SPOD 做**相干结构分析**，那篇用 SPOD 做**降阶建模**。两篇合起来覆盖 SPOD 的两大用法。
