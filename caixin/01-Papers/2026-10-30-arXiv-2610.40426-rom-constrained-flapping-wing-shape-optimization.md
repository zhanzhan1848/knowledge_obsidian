## 核心贡献

> 一句话总结这篇论文的核心创新点：提出一个物理约束的数据驱动框架，把 PDE 约束的大规模非线性形状优化问题投影为 Hilbert 空间中的系统动力学优化问题（ROM 约束），从而规避前向灵敏度函数的不稳定性，并在 2D 扑翼形状优化上把时间平均推力提升 37%、推进效率提升 40%。

1. **物理约束的 ROM 代理模型框架**：为 PDE 约束优化构造 Reduced Order Model（ROM）代理，并将其**物理约束化**（physics-constrained），而非纯粹的数据插值拟合，从而在降阶后仍保留流动物理的内在结构。
2. **优化问题的重新投影**：将原本的大规模非线性约束优化**投影为 Hilbert 空间中的系统动力学优化问题**。这一变换带来三重收益：提高优化过程的数值稳定性、显著降低内存需求、降低计算成本。
3. **规避前向灵敏度的不稳定性**：传统 PDE 约束优化依赖伴随（adjoint）法计算梯度，而伴随法受**前向灵敏度函数不稳定性**（在非定常/混沌流动中尤为严重）制约。本方法通过 ROM 化后的系统动力学形式绕开这一瓶颈。
4. **定量验证**：应用于 $Re=2400$ 的二维扑翼翼型剖面形状优化（流动含混沌结构），时间平均推力提升 **37%**、推进效率提升 **40%**；并进一步测试 3D 扑翼，验证了该方法向更复杂航空器设计的推广潜力。

## 技术方案

### 核心思想

**问题设定**：扑翼（flapping wing）的气动外形优化是一个典型的 PDE 约束优化问题：

$$\min_{d} \; \mathcal{J}(d, u) \quad \text{s.t.} \quad \mathcal{R}(d, u) = 0$$

其中 $d$ 为设计变量（翼型几何参数，如形状函数系数），$u$ 为流场解，$\mathcal{R}$ 为 Navier-Stokes 残差（离散后为 $A(d)\,u - b(d) = 0$），$\mathcal{J}$ 为目标（时间平均推力、推进效率等）。

**核心困难**：
- 直接对全阶流场做梯度型优化（伴随法 / 离散伴随）需要保存整个时间-空间历史，**内存需求巨大**；
- 非定常混沌流动的前向灵敏度 $\partial u/\partial d$ 不稳定，导致伴随梯度噪声大、收敛困难；
- 每个设计迭代需要一次完整的高分辨率 CFD 计算，成本高。

**本文的解法**：
1. **降阶代理**：用 ROM 近似设计变量 $d$ 到流场响应（如推力、效率）之间的映射 $d \mapsto \mathcal{J}_{\text{ROM}}(d)$；
2. **系统动力学化**：把优化目标写成"系统状态"的动力学的终端代价/积分代价形式，即在 Hilbert 空间中把优化写成**系统动力学优化问题**（控制论式的最优控制表述）；
3. **物理约束**：ROM 的降阶基或约束条件嵌入流动物理（如动量守恒、几何闭合条件、不可压约束），使降阶模型在训练域外更稳健，并避免纯数据驱动模型的非物理外推；
4. **迭代求解**：在 ROM 约束下求解优化问题，再用求得的 $d^*$ 回到全阶 CFD 验证（伴随式验证/线搜索校正），必要时迭代更新 ROM。

**为什么 Hilbert 空间投影能提升稳定性**：
- 把 PDE 约束优化映射为一个**无穷维控制问题**，其线性算子在适当范数下有界；
- 目标泛函在该空间上可微性更好，避免了以离散网格为参数化时灵敏度算子的病态放大；
- 伴随方程的"反向传播"被 Hilbert 空间中的对偶/投影替代，数值上以矩阵-向量积与最小二乘迭代实现，**只需存储投影后的低维状态**，内存从 $O(N_{\text{grid}}N_t)$ 降到 $O(N_r N_t)$，$N_r$ 为 ROM 阶数。

### 关键技术

| 技术 | 说明 |
|------|------|
| **POD/降阶模型（ROM）** | 将高维流场/时程映射到低维子空间，把设计-性能关系压缩到低维参数化空间 |
| **物理约束 ROM** | 在降阶框架中嵌入守恒律、几何约束或控制方程残差约束，抑制非物理外推 |
| **Hilbert 空间投影** | 将优化问题等价为无穷维系统动力学（最优控制）问题，提升适定性 |
| **系统动力学优化** | 把目标写成状态轨迹的代价泛函（积分 + 终端项），优化变量转为"控制/初值"而非直接网格值 |
| **伴随灵敏度稳定性问题** | 明确识别前向灵敏度在混沌非定常流中的不稳定性为传统方法瓶颈 |
| **二维/三维扑翼算例** | $Re=2400$ 二维翼型剖面 + 三维扑翼，评估方法可扩展性 |
| **目标函数设计** | 时间平均推力系数与推进效率（Froude efficiency）的同时优化 |

## 公式

以下为**方法本质形式**（不伪造原文未公开的具体实现细节）：

PDE 约束优化问题的原始形式：

```math
\min_{d \in \mathcal{D}} \; \mathcal{J}(d) \quad
\text{s.t.}\quad \mathcal{A}(d)\,u - b(d) = 0
```

Hilbert 空间投影后的系统动力学形式（最优控制表述）：

```math
\min_{v(\cdot)} \; \int_0^T \mathcal{L}\!\left(z(t), v(t)\right)\,dt + \Psi\!\left(z(T)\right)
\quad \text{s.t.}\quad
\dot{z}(t) = \mathcal{F}\!\left(z(t), v(t)\right), \quad z(0) = z_0
```

其中 $z(t) \in \mathcal{H}$ 为 Hilbert 空间中的状态（低维嵌入的流场模态系数或性能指标时间序列），$v$ 为控制量（对应设计变量在 ROM 参数化空间中的增量）。

ROM 的物理约束形式（本质形式）：

```math
\mathcal{R}_{\text{ROM}}(z; d) = 0
\quad \text{with}\quad
\mathcal{R}_{\text{ROM}} = \Pi_{\text{modes}} \mathcal{A}(d)\, z - \Pi_{\text{modes}} b(d) \;+\; \underbrace{\mathcal{C}_{\text{phys}}(z,d)}_{\text{守恒/几何约束}}
```

目标函数（时间平均推力与推进效率）：

```math
\bar{C}_T = \frac{1}{T}\int_0^T C_T(t)\,dt, \qquad
\eta = \frac{\bar{P}_{\text{thrust}}}{\bar{P}_{\text{input}}}
```

非定常扑翼的时序推进效率本质形式：

```math
\eta = \frac{\langle T(t)\, U(t)\rangle_t}{\langle P_{\text{input}}(t)\rangle_t},
\qquad U(t) = \text{instantaneous streamwise speed}
```

**稳定性判据（方法层面）**：前向灵敏度的一致性要求

```math
\left\|\frac{\partial u}{\partial d}\right\| \le C \;\Rightarrow\;
\text{adjoint gradient error} \sim O(\varepsilon_{\text{CFD}} / C)
```

其中 $C$ 为灵敏度放大因子；混沌流动中 $C$ 随时间无界增长，即为本文要规避的病态。

```python
# 1) 训练 ROM：从离线 CFD 数据库建立设计变量 -> 性能的降阶模型
rom = build_reduced_order_model(
    design_db=offline_cfd_designs,        # (d_k, u_k) 快照集合
    basis="POD",                          # 降阶基（模态/静态或动态）
    physics_constraints=[                 # 物理约束
        "momentum_balance",
        "geometric_closure",
        "incompressibility_projection",
    ],
    order=n_modes,                        # ROM 阶数 N_r
)

# 2) 把优化问题投影为 Hilbert 空间中的系统动力学优化
opt = project_to_system_dynamics(
    objective=make_time_averaged_thrust_and_efficiency,
    rom=rom,
    cost_functional=integral_plus_terminal,   # L(z,v) + Psi(z(T))
    dynamics=rom.step,                         # dz/dt = F(z, v)
    state_metric=hilbert_inner_product(rom.basis),
)

# 3) 在 ROM 约束下求解（可用投影梯度 / L-BFGS / SQP）
d_rom = opt.solve(initial_guess=baseline_wing, constraints=design_box)

# 4) 回代全阶 CFD 验证（line search / trust region 校正）
d_star = trust_region_refine(
    design=d_rom,
    full_order_solver=run_fluid_solver,      # 2D/3D 扑翼 CFD
    evaluate=lambda d: compute_Ct_avg_and_eta(run_fluid_solver(d)),
    objective_sign="maximize",
)

# 5) 若需迭代，采样新设计点并更新 ROM
rom.update(collect_new_samples(d_star))
```

## 实验结论

- **数据集/算例**:
  - **二维扑翼翼型剖面**：$Re=2400$，非定常、含混沌流结构；优化参数为翼型几何（形状函数参数化）。
  - **三维扑翼**：用于测试方法对更复杂外形的推广能力（给出潜在性结论）。
  - 附带离线 CFD 快照数据库，用于训练 ROM（规模未在摘要中披露）。
- **基线**: 传统基于伴随法（adjoint）的 PDE 约束形状优化方法，以及未投影的直接 ROM 优化方案；对比维度包括内存占用、每迭代成本、梯度稳定性。
- **结果**:
  1. 时间平均推力提升 **37%**；
  2. 推进效率提升 **40%**；
  3. 相对传统方法，优化过程**更稳定**（不稳定性被消除/显著缓解）、**内存需求更低**、**计算成本更低**；
  4. 3D 扑翼算例表明该方法可推广到更复杂的航空最优外形设计。

## 实现建议

- **实现难度**: 高。需要同时掌握：非定常 CFD 求解器（建议自带 PETSc/FEniCS 或 OpenFOAM 定制）、快照采集与 POD 降阶、伴随/灵敏度分析、Hilbert 空间投影的构造、以及非线性优化求解。
- **预期性能**:
  - 单次 ROM 优化迭代的成本 ≈ 一次低维优化（毫秒-秒级），相比全阶 CFD（小时级）有数个数量级加速；
  - 内存占用从 $O(N_{\text{grid}}N_t)$ 降至 $O(N_r N_t)$，$N_r \ll N_{\text{grid}}$；
  - 精度损失主要来自 ROM 的重构误差与时间平均统计误差，二者需分别控制。
- **适用场景**:
  - 非定常/湍流外形优化（伴随法梯度不可靠的场合）；
  - 迭代次数受限、内存受限的高保真优化（如集群超参调优）；
  - 扑翼、水翼推进器、涡脱落体型优化、微型飞行器设计；
  - 需要"设计空间快速扫描"的早期概念设计阶段。
- **技术路线**:
  1. **训练阶段**：先用低保真（网格/时间步粗化）或代理模型生成初始设计样本，再逐步插入高保真点（多保真流程），降低训练成本；
  2. **ROM 选择**：非定常混沌流建议用 **Dynamic Mode Decomposition (DMD)** 或 **Hankel-DMD / Subspace Identification** 捕捉时序结构；若需保证守恒，尝试带守恒投影的 POD（cPOD）；
  3. **物理约束**：优先约束动量通量积分与几何不可压性；约束项宜以罚函数软约束，避免破坏优化问题的光滑性；
  4. **稳定性保障**：在线做**前向灵敏度监控**（比较 ROM 与全阶的局部响应斜率），一旦偏离阈值立刻切换到降阶梯度 + 全阶校正的混合策略；
  5. **全阶验证循环**：每次 ROM 优化后必须做全阶 CFD 复核，并统计验证窗口涨落；
  6. **并行性**：快照生成阶段可大并行（全阶 CFD 天然并行）；ROM 训练（POD 协方差 + SVD）可分布式；优化阶段若用梯度法可对伴随梯度做预条件并行。
- **风险提示**: ROM 在优化轨迹上外推是主要风险——建议在优化路径上**在线重采样**（trust-region 采点），并对 ROM 给出可信度区间用于线搜索。
