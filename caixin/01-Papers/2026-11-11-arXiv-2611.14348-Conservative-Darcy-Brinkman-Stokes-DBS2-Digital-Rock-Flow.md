## 核心贡献

> 证明了**不需要对第二 Brinkman 项（SBT）做单独离散化**——只要把 Darcy-Brinkman-Stokes（DBS）方程写成守恒形式并用标准中心差分有限体积离散，完整 DBS 方程形式（DBS2）就会**自然保留**；该格式在保持 DBS1 计算效率的同时达到 DNS 级精度。

1. 提出 **DBS2 守恒格式**：将 DBS 方程改写为守恒形式，配合标准中心差分有限体积离散，**自动**保留第二 Brinkman 项与孔隙率梯度粘性扩散项，无需额外算法模块。
2. 定量揭示简化格式 **DBS1 的系统性误差**：DBS1 忽略 SBT 与孔隙率梯度粘性扩散项，在相同离散下**系统性高估渗透率 14.1%–37.9%**。
3. 在三个基准算例（微通道流、2D 非均质微观模型、Bentheimer 砂岩 3D micro-CT）上验证：DBS2 在微通道中**精确复现 DNS 速度场**，在微观模型与砂岩中**渗透率误差仅 1.5%–3.8%**。
4. 工程实现基于 **GeoChemFoam**（OpenFOAM 框架下的开源 CFD 模拟器），使守恒格式可直接用于体素化 micro-CT 图像上的**孔隙尺度模拟**。

## 技术方案

### 核心思想

孔隙尺度（pore-scale）DNS 是估计岩石渗透率与流体分布的金标准，但它要求在**完全解析的几何体上生成边界贴合（boundary-conforming）网格**——这对真实 micro-CT 岩石几何是内存杀手，计算规模常常不可行。

DBS 框架的吸引力在于：它可以在**体素化（voxelized）的 micro-CT 图像**上直接求解，无需生成贴合网格。但业界常用的简化版 DBS1 存在两个已知缺陷：
- 漏掉 **第二 Brinkman 项 (Second Brinkman Term, SBT)**——该项是捕捉孔壁**粘性边界效应**（viscous boundary effects）的关键物理；
- 漏掉**孔隙率梯度引起的粘性扩散项**（porosity-gradient viscous-diffusion term）。

由于孔隙率在体素化图像上处处不连续，梯度粘性扩散项恰恰是不可忽略的——它正对应真实岩石中孔隙尺度上的粘性剪切损耗。

本文的核心洞察是：**这两个遗漏并非必须靠"额外离散化模块"来修补**。只要把方程写成**守恒形式**（conservative form），粘性应力项以散度形式出现，中心差分有限体积离散在离散层面就自动保留了完整的 DBS 动力学。这是"离散格式即物理保证"的典型案例——不是加补丁，而是换个写法让物理自己浮现。

该守恒处理还有一个额外好处：**保持了 DBS1 的计算效率**（没有引入额外的迭代或子迭代），却达到了 DNS 级精度。

### 关键技术

| 技术 | 说明 |
|------|------|
| Darcy-Brinkman-Stokes (DBS) 方程 | 统一描述粘性主导区（Stokes）与惯性/渗流主导区（Darcy）的多孔介质流动 |
| 守恒形式离散 | 粘性应力以散度形式进入，控制体积分形式保证局部动量守恒 |
| 第二 Brinkman 项 (SBT) | 提供孔壁粘性边界效应修正，是 DBS1 遗漏的关键物理项 |
| 孔隙率梯度粘性扩散项 | 捕捉体素化图像中孔隙率不连续引起的粘性损耗 |
| 中心差分有限体积 | 标准格式，无需专用 SBT 离散模块 |
| 体素化 micro-CT | 直接在 CT 图像体素网格上建模，避免边界贴合网格生成 |
| GeoChemFoam (OpenFOAM) | 开源 CFD 求解器载体，格式可在既有 OpenFOAM 生态中复用 |
| 渗透率反演 | 通过压差–流量关系提取有效渗透率，与 DNS 对标 |

## 公式 / 理论要点

```math
% Darcy-Brinkman-Stokes 方程（守恒形式）
\rho\left(\frac{\partial \boldsymbol{u}}{\partial t}
+ \boldsymbol{u}\cdot\nabla\boldsymbol{u}\right)
= -\nabla p + \nabla\cdot\left(
\eta\,\nabla\boldsymbol{u}
\underbrace{+\;\boldsymbol{u}}_{\text{SBT: 第二 Brinkman 项}}
\right)
+ \frac{\eta}{K}\boldsymbol{u}
- \underbrace{\nabla\cdot\left(\eta\,\boldsymbol{u}\,\nabla\phi\right)}_{\text{孔隙率梯度粘性扩散}}
+ \rho\boldsymbol{f}
```

其中 $\phi$ 为孔隙率，$K$ 为渗透率。写成守恒形式后，粘性应力与 SBT 都以**散度**形式出现，中心差分有限体积离散下自动保留完整动力学。

```math
% 有限体积控制体离散（守恒形式下动量通量自动守恒）
\frac{d}{dt}\int_{V_c}\rho\boldsymbol{u}\,dV
= -\oint_{\partial V_c} p\,\boldsymbol{n}\,dS
+ \oint_{\partial V_c}\left(
\eta\,\nabla\boldsymbol{u}
+ \boldsymbol{u}
\right)\cdot\boldsymbol{n}\,dS
- \int_{V_c}\frac{\eta}{K}\boldsymbol{u}\,dV
+ \int_{V_c}\nabla\cdot\left(\eta\,\boldsymbol{u}\nabla\phi\right)dV
```

```math
% 渗透率提取（压差–流量关系）
K_{\text{eff}} = -\frac{\eta\,L}{A\,\Delta P}\,Q
```

## 实验与结果

- **算例/数据集**:
  1. 微通道流（microchannel flow）——几何完全解析，作为 DNS 精确对照；
  2. 2D 非均质微观模型（heterogeneous micromodel）；
  3. 3D micro-CT 图像（Bentheimer 砂岩）。
- **对比基线**: 孔隙尺度 **DNS**（边界贴合网格真值）vs **DBS1**（简化格式）vs **DBS2**（本文守恒格式）。
- **主要结果**:
  - **微通道**：DBS2 **精确复现 DNS 速度场**（逐点吻合）。
  - **2D 微观模型 / 3D 砂岩**：DBS2 渗透率与 DNS 误差 **1.5%–3.8%**（空间分辨率匹配条件下）。
  - **DBS1 系统性偏差**：同离散下**高估渗透率 14.1%–37.9%**。
  - **效率**：守恒粘性应力处理**保持 DBS1 的计算效率**，无额外迭代开销。
  - **关键对照**：DBS1 vs DBS2 使用**完全相同的离散格式**，唯一差别是方程的守恒写法——干净地隔离出 SBT + 孔隙率梯度项的物理贡献。

## 局限性

- 数值基准以渗透率与速度场为主，对**多相流、溶质运移、毛细压力**等孔隙尺度现象的验证未在摘要中体现。
- 结果依赖 micro-CT 分辨率：分辨率不足时体素化本身带来的几何误差会与格式误差混淆（论文采用"匹配空间分辨率"对比，即在同分辨率下比较 DBS2 与 DNS）。
- 未涉及**各向异性渗透率张量**与**非牛顿流体**扩展。
- 摘要未提供 GeoChemFoam 的公开仓库地址与许可证信息，实际可获取性需另行确认。

## 实现建议

- **实现难度**: 中低 — 对已有 OpenFOAM 求解器用户，主要工作是**改写方程为守恒形式 + 调整粘性应力/对流项装配**，而非新增数值算法。若从零实现则属中等难度。
- **预期性能**: 与 DBS1 持平；相比边界贴合网格 pore-scale DNS，**内存与网格生成成本大幅下降**（体素化网格）。
- **适用场景**:
  - 数字岩心（digital rock）渗透率快速估计；
  - 非常规储层（致密砂岩、碳酸盐岩）孔隙尺度流动评估；
  - 多相渗流与毛管驱替的初步筛选；
  - 作为**几何筛选工具**先做粗筛，再对少数候选做昂贵 DNS。
- **可复用要点**:
  - **"守恒写法即物理保证"**是一个可迁移的设计原则：当已有格式"缺项"时，先检查是否可以通过改变方程的数学形式让物理项自然进入离散，而不是急着加补丁模块。本文的对照实验设计（只改写法、不改离散）使结论归因干净，值得作为方法论范式借鉴。
  - **DBS1 高估渗透率 14–38%** 这一量化结论本身具有警示价值：任何使用 DBS1 的数字岩心研究都应重新检查其渗透率结论的偏差方向与量级。
  - 若需实现数字岩心流程，建议将 **DBS2（快速筛选）+ 边界贴合 DNS（关键样本验证）** 组成两级工作流，用 DBS2 的 1.5–3.8% 误差带作为是否升级到 DNS 的判据。
