## 核心贡献

> 把"不可压缩流体混合"问题形式化为基于连续性方程的最优传输问题，建立几何流体力学与最优传输之间的并行理论

1. **流体混合最优控制形式化**：被动标量输运 + 不可压约束 + 控制目标，给出诱导 Wasserstein 风格度量
2. **几何框架**：最优控制问题诱导可达状态上的度量，控制目标为内积时携带形式 Riemannian 结构
3. **目标函数选择影响方程族**：
   - 动能 → 不可压 Euler 方程（连接 Arnold 几何水动力学）
   - 涡量拟能 → Euler-Poincaré (EPDiff) 测地线方程（右不变 H¹ 度量）
4. **广义 Helmholtz 分解 + Clebsch 表示**：在不可压流框架内重新推导

---

## 技术方案

### 核心思想

把混合视为"用最小努力把初始标量分布搅匀"的最优控制问题，用几何流体力学与最优传输几何共同刻画。在动力学上对应体积保持微分同源群上的右不变度量流。

### 关键技术

| 技术 | 说明 |
|------|------|
| 连续性方程 | 被动标量输运动力学 |
| 不可压约束 | div u = 0 |
| Wasserstein 类度量 | 由控制目标诱导 |
| 形式 Riemannian 结构 | 控制目标为内积时存在 |
| Arnold 几何水动力学 | 不可压 Euler 即流-凯线性动能的测地线 |
| EPDiff 方程 | 涡量拟能对应右不变 H¹度量下的 Euler-Poincaré |
| Otto calculus 类比 | 与经典最优传输微分结构对应 |

## 实验结论

- **数据集**: 解析推导 + 数值仿真
- **基线**: 动能混合 (ill-posed)
- **结果**: 涡量拟能作为控制目标更自然，给出 Euler-Poincaré 测地线与梯度流数值模拟

---

## 局限性

- 主要为理论框架，数值实验相对初步
- 动能作为控制目标不适定（ill-posed）
- 与实际工程混合设备设计的对应关系尚需建立
