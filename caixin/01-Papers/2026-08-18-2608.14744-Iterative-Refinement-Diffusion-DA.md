## 创新点

- **迭代精化 (IR) 框架**：分层 forecast-analysis 操作，而非单次粗到细重建
- **多分辨率层级**：分解为分辨率级别的 forecast-analysis 操作
- **共享神经算子 + 共享条件扩散修正器**
- **分辨率相关谱模式切片** (spectral mode slicing)

## 验证结果：Kraichnan 湍流 (256×256)

| 方法 | RMSE | SSIM |
|------|------|------|
| IR (本文) | **0.184** | **0.836** |
| 谱上采样 | - | - |
| 单次扩散超分 | - | - |
| 增强深度超分 | - | - |
| 自回归预测器 | - | - |

- **36× 推理加速**（相比参考 CFD）

## 物理意义

- **湍流数据同化**：从稀疏低分辨率观测恢复高分辨率湍流场
- **时序约束**：利用历史状态而非单次映射
- 对强多尺度、欠驱动 regime 特别有效

## 关键公式
```
多分辨率层级：
coarse → fine
forecast-analysis → diffusion correction
每一层：共享神经算子 + 条件扩散修正器
```

## 评估：✅ 推荐实现

**理由**：扩散模型在流体力学数据同化中表现突出；多分辨率分治策略显著优于单次方法；在 Kraichnan 湍流上验证充分；36× 加速具有实用价值。
