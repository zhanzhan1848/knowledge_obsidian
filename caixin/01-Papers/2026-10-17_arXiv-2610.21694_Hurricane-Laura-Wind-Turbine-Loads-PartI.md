## 核心贡献

> 用 LES 在三个网格分辨率下模拟 Hurricane Laura (2020)，并将 LES 输出作为**气弹模拟的直接入口条件**，评估**怠速风电机**（idling wind turbine）的极端载荷响应

1. **问题背景**：热带气旋（tropical cyclones）在边界层下部产生**极端风**，对风电基础设施构成高风险
2. **研究方法**：
   - **第一阶段**：LES 模拟 Hurricane Laura
   - **第二阶段**：LES 输出 → 气弹模拟入口条件
3. **网格分辨率敏感性**：
   - Coarse: \(\Delta x = 55.55\,\mathrm{m}\)
   - Intermediate: \(\Delta x = 25\,\mathrm{m}\)
   - Fine: \(\Delta x = 10\,\mathrm{m}\)
4. **关键发现**：网格分辨率显著影响平均风场、湍流结构与**气弹响应**——**必须用高分辨率入口数据**才能准确预测极端载荷

## 技术方案

### 核心思想

用**嵌套 LES** 模拟飓风尺度的湍流结构，再用 LES 输出作为**风电机气弹模拟的精确入口边界条件**，避免传统工程模型（Mann turbulence box / Kaimal spectrum）对极端风的低估。

### 关键技术

| 技术 | 说明 |
|------|------|
| Large-eddy simulation (LES) | 飓风尺度湍流模拟 |
| Multi-resolution LES | 55.55 m / 25 m / 10 m 网格对比 |
| Aeroelastic simulation | 风电机叶片动力学 |
| Turbulent inflow coupling | LES → 气弹模拟直接数据传递 |
| Hurricane Laura 2020 | 真实个例 |
| Mean flow / turbulence diagnostics | 平均风速、湍流强度、相关长度 |

### 控制方程（LES）

滤波后的不可压缩 NSE + SGS（亚格子）模型：

```math
\frac{\partial \bar{u}_i}{\partial t} + \bar{u}_j \frac{\partial \bar{u}_i}{\partial x_j} = -\frac{1}{\rho}\frac{\partial \bar{p}}{\partial x_i} - \frac{\partial \tau_{ij}^{\mathrm{sgs}}}{\partial x_j} + f_i
```

### 多尺度耦合（LES → aeroelastic）

```
Hurricane LES (Δx ~ 10-55 m)
        ↓
Time-resolved inflow velocity at turbine location
        ↓
Aeroelastic solver (FAST / OpenFAST / HAWTDyn2)
        ↓
Blade loads, tower loads, drivetrain loads
```

## 实验 / 验证

- **数据源**：Hurricane Laura (2020) 实测 + 高分辨率 LES
- **验证方法**：
  - 平均风速剖面 vs. 观测
  - 湍流强度 vs. 观测
  - 叶片载荷 vs. SCADA（未明确）
- **结果**：
  - Coarse 网格对**极端阵风**捕捉不足
  - Fine 网格揭示了**湍流相干结构**对叶片瞬态载荷的强相关
  - Part II 将研究**不同风暴位置**的响应

---

## 局限性

- **单例研究**：仅 Hurricane Laura 一个 case，结论普适性需要更多风暴验证
- **怠速状态**：仅考虑 idling turbine（停机），正常运行状态未涉及
- **LES 入口条件**：自身依赖于初始 / 边界条件（从更大尺度模式驱动）
- **叶片气弹模型简化**：未提及叶片柔性 / 气动失速细节
