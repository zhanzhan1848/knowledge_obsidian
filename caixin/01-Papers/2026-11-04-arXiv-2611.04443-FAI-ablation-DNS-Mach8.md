## 核心贡献

> 对 **Mach 8、15° 压缩斜坡**的烧蚀流动做**直接数值模拟 (DNS)**，用**两套独立开发的 CFD 求解器 (INCA 与 CHAMPS)** 交叉验证同一个流-烧蚀耦合模型，定量再现风洞实验中的加热条纹，并首次系统研究**加速烧蚀凹坑 (accelerating recession)** 如何改变扰动演化与层流-转捩过程。

1. **两求解器交叉验证**：INCA（AFRL/UT）与 CHAMPS（TUM）使用**共同的气-固界面 (GSI) 接口**实现**同一物理模型**，在热流、质量吹拂率、凹坑形状上**高度一致** —— 这是本文最强的可信度证据。
2. **稳定性计算 + 扰动叠加**：先用 CHAMPS 的时谱求解器做二维基流稳定性分析，扰动由上游局域体积源注入（模拟 Dwivedi 等的最优定常涡强迫），壁面法向积分扰动动能在分离到域末**增长约 4 个数量级**。
3. **烧蚀模型**：樟脑 (camphor) 单组分升华；**Knudsen-Langmuir 升华律** + **壁面能量平衡**（升华焓 + 固体显热 + 辐射再发射）+ **法向动量连续**。
4. **凹坑加速技术**：材料凹坑速度远慢于流体时间尺度，故几何凹坑速度乘以加速因子 $F$，而**气-固热质交换本身不加速**（保证物理一致）。
5. **初始化策略**：樟脑壁面先保持刚性，待流动调整到樟脑吹拂状态**一个流通时间**后才启用凹坑，避免虚假的速度尖峰。
6. **新发现**：烧蚀凹坑的**加速演化**显著改变扰动增长率与相变位置 —— 烧蚀表面并非被动边界，而是参与转捩动力学的活跃因素。

## 技术方案

### 核心思想

**流体-烧蚀相互作用 (FAI)** 的核心是**双向耦合**：烧蚀改变了壁面几何 → 改变边界层 → 改变回流与条纹；条纹的热负荷 → 改变烧蚀速率 → 再反馈。

本文的数值策略是：**用两套独立求解器 + 同一套物理模型**，从而把"数值误差"与"模型误差"分离开。

### 关键技术

| 技术 | 说明 |
|------|------|
| INCA | 块笛卡尔 AMR；五阶 WENO；HLLC 无粘通量；二阶中心粘性通量；显式三阶 RK；**cut-cell 浸入边界**处理运动烧蚀面 |
| CHAMPS | 笛卡尔块结构 AMR；五阶 WENO；Rusanov 通量；不规则固体边界处**局部稳定化有限差分模板**；非烧蚀用 BDF1 隐式；引入烧蚀后改用 **SSP 四段三阶显式 RK** |
| 时谱稳定性求解器 | CHAMPS 内置；直接求解给定（时间频率，展向波数）的定常扰动态 |
| GSI 接口 | 求解器 ↔ 材料响应解算器的共享接口（INCA 直接实现，CHAMPS 耦合）|
| 网格 | 二维中等网格 $\Delta h_x=3.2\times10^{-5}$ m，$\Delta h_y=1.65\times10^{-5}$ m；三维展向 64 点，$\Delta h_z=4.7\times10^{-5}$ m |
| CFL | 0.5 |
| 展向范围 | 恰好一个最不稳定定常条纹波长 $\lambda_z=3.0$ mm |

## 公式

```math
% ===== 组分壁面质量平衡 =====
\rho D\left.\frac{\partial y_i}{\partial \eta}\right|_{\rm wall}+\dot\omega_i=\dot m_w y_{i,w},
\qquad i=1,\dots,N

% ===== 总质量吹拂率 =====
\dot m_w=\sum_i\dot\omega_{i,w}=\rho_w u_w=\rho_s v_{\rm wall},
\qquad \rho_s=990\ \mathrm{kg\,m^{-3}}\ (\text{樟脑})

% ===== 法向动量连续 =====
p_\eta=p_f+\rho_f u_f^2=p_w+\rho_w u_w^2

% ===== 壁面状态解析求解 =====
p_w=\frac{p_\eta+\sqrt{p_\eta^2-4RT_w\dot m_w^2}}{2},\qquad
\rho_w=\frac{p_w}{RT_w},\qquad
u_w=\frac{2RT_w\dot m_w}{p_\eta+\sqrt{p_\eta^2-4RT_w\dot m_w^2}}

% ===== 表面能量平衡 =====
k\left.\frac{\partial T}{\partial \eta}\right|_{\rm wall}
=\dot m_w\Delta h_{\rm subl}+\dot m_w\Delta h_{\rm solid}
+\varepsilon\sigma\left(T_w^4-T_\infty^4\right),
\qquad \Delta h_{\rm solid}=h_{s,w}-h_{s,0}

% ===== Knudsen-Langmuir 升华律 =====
\dot\omega_c=\alpha\left(p_v-p_c\right)\sqrt{\frac{M_c}{2\pi RT_w}},
\qquad \alpha=0.18,\ \ p_v(T_w)\ \text{由 Antoine 型关联式给出}

% ===== 物理凹坑律与加速 =====
v_{\rm wall}=\frac{\dot m_w}{\rho_s},\qquad
v_{\rm wall,applied}=F\frac{\dot m_w}{\rho_s}
\quad(\text{仅几何加速，热质交换不加速})

% ===== 扰动强迫（三维）=====
S(x,y,z)=f(x)\exp[\cdots]
```

        #    k * dT/deta|wall = m_dot*dh_sub + m_dot*dh_solid + eps*sigma*(Tw^4 - Tinf^4)
        T_w = solve_T_from_energy_balance(...)
        # 2) Knudsen-Langmuir -> 产气速率
        omega_c = alpha * (p_v(T_w) - p_c) * sqrt(M_c/(2*pi*R*T_w))
        # 3) 组分守恒 -> 各组分壁面分数
        y_w = solve_species_balance(y_gas, T_w, omega_c, ...)
        # 4) 法向动量连续 -> p_w, rho_w, u_w
        p_eta = p_f + rho_f*u_f**2
        p_w   = 0.5*(p_eta + sqrt(p_eta**2 - 4*R*T_w*m_dot**2))

        u_w   = 2*R*T_w*m_dot/(p_eta + sqrt(p_eta**2 - 4*R*T_w*m_dot**2))
        # 5) 收敛判据
        if converged(y_w, m_dot, T_w): break
    return dict(y_w=y_w, m_dot=m_dot, T_w=T_w, p_w=p_w, u_w=u_w)

## 实验结论

- **数据集/算例**：复现 Chuvakhov 等的风洞实验 —— Mach 8、$p_\infty=355$ Pa、$T_\infty=55$ K、15° 压缩斜坡；平板长 $L=0.05$ m；斜坡 $x=0.05\to0.20$ m；三维展向宽 0.003 m；非烧蚀基流壁温 $T_w=293$ K。
- **基线**：风洞实验的加热条纹 + 两求解器互为基线。
- **结果**：
  - 层流基流上**成功复现**实验特征加热条纹；
  - INCA 与 CHAMPS 在**热流、质量吹拂率、凹坑形状**上高度一致；
  - 准确预测**烧蚀凹坑演化**；
  - 揭示烧蚀凹坑**加速**对扰动演化的影响（新发现）。

---

## 局限性

- **只做了三维、单一展向波长**（恰为最不稳定条纹波长 $\lambda_z=3$ mm），未覆盖完整展向发展。
- **烧蚀材料单一**（樟脑），化学计量简单；真实材料（如 PICA、碳酚醛）的多组分升华与热解未涉及。
- **两求解器共用同一 GSI 物理模型** —— 交叉验证的是**数值实现**而非**物理模型本身**；模型本身只在风洞实验尺度上验证。
- 几何凹坑加速（$F$ 因子）本身是**数值加速手段**，其对瞬态流动的影响未完全排除。
- 未涉及烧蚀与**层流转捩**的完整耦合参数空间（只做了一组扰动振幅/加速比）。

## 实现建议

- **实现难度**：⚠️ 较高。需实现或对接：高阶 WENO 有限体积 + AMR + 浸入边界/cut-cell + GSI 迭代 + 材料升华模型。
- **预期性能**：
  - 空间：五阶 WENO + AMR，二维中等网格 $\sim 10^{-5}$ m 量级；CFL=0.5；
  - 时间：显式三阶 RK（INCA）/ SSP 四段三阶（CHAMPS）；
  - 成本：三维展向 64 点是**主要算例瓶颈**（展向分辨率不足会限制扰动展向演化）。
- **适用场景**：
  - ✅ 高超声速热防护系统烧蚀评估
  - ✅ 需要跨求解器验证可信度的研究
  - ✅ 层流-转捩 + 烧蚀耦合的基础研究
  - ❌ 不适合工程级长时间烧蚀预测（成本过高）
- **落地建议**：若已有高阶 WENO + AMR 框架，接入 GSI 接口的成本主要是**表面模型迭代求解**，可控。强烈建议照搬本文做法：实现**两套独立求解器**做交叉验证，这在耦合建模中能有效区分模型误差与数值误差。
