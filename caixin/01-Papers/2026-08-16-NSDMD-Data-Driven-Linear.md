# 非线性减去动态模态分解 (NSDMD)

## 论文信息
- **arXiv**: [2608.13373](https://arxiv.org/abs/2608.13373)
- **日期**: 2026-08-13
- **期刊**: physics.flu-dyn, math.DS
- **关键词**: #DMD #数据驱动 #非线性系统 #流体力学

## 研究背景
- **DMD**: 数据驱动提取相干结构和动力学
- **瓶颈**: 线性回归核心 → 无法准确建模非线性动力学

## NSDMD 创新

### 核心思想
已知**非线性项**、未知**线性算子**时，从数据中提取线性算子。

### 适用场景
1. 非线性项在控制方程中已知
2. 线性算子含不确定材料属性
3. 线性算子闭合未解析动力学
4. 黑盒模拟器可输出非线性项

### 数学框架
```
原始数据快照 → 减去已知非线性贡献 → 低秩线性算子逼近
```

## 验证案例
1. **混沌系统**: 准确提取线性化算子
2. **部分观测**: 欠定系统
3. **平流主导**: 对流问题
4. **高维动力学**: 大规模系统

## 🥢 可行性分析：NSDMD 用于流体力学数据分析

## 方法本质
- 数据驱动，监督式
- 需提供非线性项快照

## 应用场景
- PIV/PTV 实验数据分析
- CFD 模拟后处理
- 流场降阶建模 (ROM)

## 计算成本
- 矩阵分解: O(n³) 或 SVD
- 规模依赖数据维度

## 推荐结论
✅ **推荐参考**

### 理由
1. **泛化 DMD**: 适用范围更广
2. **物理约束**: 利用已知非线性项
3. 可与 CFD/实验数据无缝结合

### 实现路径
1. 从 OpenFOAM/收集非线性项快照
2. 调用 NSDMD 提取线性算子
3. 用于稳定性分析/控制设计
