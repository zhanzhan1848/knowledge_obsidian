## 核心贡献

> 对**准不可压缩热 Maxwell-Stefan-Navier-Stokes 系统**（多组分混合物在准不可压约束下的对流-扩散输运）构造了**两个保持结构的离散格式**：半隐式 Euler（**熵产生 + 逐点满足准不可压约束**，但数值耗散总能量）与**连续 Petrov-Galerkin**（额外**精确守恒总能量**且支持**任意多项式阶**）。

1. **改用熵平衡而非能量平衡做变分基础**——这是能同时构造两个结构保持格式的关键。论文指出：采用**逆温度 $\vartheta$** 做离散化变量更有利。
2. **Scheme I（半隐式 Euler + FEM）**：保证熵产生、逐点满足准不可压约束（无条件或带时间步条件），但**数值耗散总能量**。
3. **Scheme II（连续 Petrov-Galerkin 时间离散）**：同样产生熵、逐点满足约束，**且精确守恒总能量**，并允许高阶时间逼近。
4. **统一的变分框架**：引入**辅助变量作为测试函数的离散投影**，使连续层的守恒律与耗散不等式在离散层自动恢复（作者近期提出的通用策略）。

## 控制方程

### 守恒形式（$\Omega\subset\mathbb{R}^d$，$d\in\{2,3\}$）

```math
\partial_{t}\rho_{i}+\operatorname{div}(\rho_{i}\bm{u})=-\operatorname{div}\bm{J}_{i},\qquad i=1,\ldots,N
```

```math
\partial_{t}(\varrho\bm{u})+\operatorname{div}(\varrho\bm{u}\otimes\bm{u})=\operatorname{div}\bm{\sigma}
```

```math
\partial_{t}(\varrho e)+\operatorname{div}(\varrho e\bm{u})=-\operatorname{div}\bm{J}_{e}+\bm{\sigma}:\mathrm{D}\bm{u}
```

总质量密度 $\varrho:=\sum_{i=1}^{N}\rho_{i}$。

### 准不可压约束

组分比容 $V_i$ 为常数，混合物无空隙：

```math
\sum_{i=1}^{N}V_{i}\rho_{i}=1
```

将质量方程乘 $V_i$ 求和即得**散度的闭合刻画**：

```math
\operatorname{div}\bm{u}=-\sum_{i=1}^{N}V_{i}\operatorname{div}\bm{J}_{i}
```

**这个约束完全由扩散通量决定**——即"准"不可压的由来。压力 $p$ 作为 Lagrange 乘子进入化学势。

### 状态方程与热力学关系

Legendre 关系 $\varrho e=\varrho F+\vartheta\varrho s$；熵密度与温度互为对偶：

```math
\varrho s=-\,\partial_{\vartheta}(\varrho F)(\vec{\rho},\vartheta),\qquad
\vartheta=\partial_{\varrho s}(\varrho e)(\vec{\rho},\varrho s)
```

化学势**包含压力**（Lagrange 乘子）：

```math
\mu_{i}=\partial_{\rho_{i}}(\varrho F)(\vec{\rho},\vartheta)+V_{i}p=\partial_{\rho_{i}}(\varrho e)(\vec{\rho},\varrho s)+V_{i}p
```

### Onsager 通量（Maxwell-Stefan + 热扩散）

```math
\bm{J}_{i}=-\sum_{j=1}^{N}M_{ij}(\vec{\rho},\vartheta)\nabla\frac{\mu_{j}}{\vartheta}+c_{i}(\vec{\rho},\vartheta)\nabla\frac{1}{\vartheta}
```

```math
\bm{J}_{e}=-\sum_{j=1}^{N}c_{j}(\vec{\rho},\vartheta)\nabla\frac{\mu_{j}}{\vartheta}+K(\vec{\rho},\vartheta)\nabla\frac{1}{\vartheta}
```

**完整 Onsager 矩阵**（对称、半正定）：

```math
\bm{L}(\vec{\rho},\vartheta)\coloneqq\begin{pmatrix}\bm{M}(\vec{\rho},\vartheta)&-\,\bm{c}(\vec{\rho},\vartheta)\\-\,\bm{c}(\vec{\rho},\vartheta)^{\top}&K(\vec{\rho},\vartheta)\end{pmatrix}
```

约束：$\bm{M}$ 对称半正定、$K>0$、且 $\sum_j M_{ij}=0$、$\sum_i c_i=0$（总质量守恒要求总通量为零）。

### 熵平衡与熵产生

```math
\partial_{t}(\varrho s)+\operatorname{div}(\varrho s\bm{u})=-\operatorname{div}\bm{J}_{s}+\mathcal{P}(\vec{\rho},\vartheta,\vec{\mu},\mathrm{D}\bm{u})
```

```math
\bm{J}_{s}\coloneqq-\sum_{i=1}^{N}\frac{\mu_{i}}{\vartheta}\bm{J}_{i}+\frac{1}{\vartheta}\bm{J}_{e}
```

```math
\mathcal{P}=\frac{1}{\vartheta}\mathbb{S}:\mathrm{D}\bm{u}+\begin{pmatrix}\nabla\frac{\vec{\mu}}{\vartheta}\\ \nabla\frac{1}{\vartheta}\end{pmatrix}^{\top}\!\!\!\bm{L}\begin{pmatrix}\nabla\frac{\vec{\mu}}{\vartheta}\\ \nabla\frac{1}{\vartheta}\end{pmatrix}\geq 0
```

### 全局结构（Lemma 3.2，光滑解）

| 结构 | 结论 |
|---|---|
| 偏质量守恒 | $\dfrac{\mathrm{d}}{\mathrm{d}t}\int_\Omega\rho_i\,\mathrm{d}x=0$ |
| **总能量守恒** | $\dfrac{\mathrm{d}}{\mathrm{d}t}\int_\Omega\left(\varrho e+\frac{\varrho}{2}\|\bm{u}\|^2\right)\mathrm{d}x=0$ |
| 熵单调增 | $\dfrac{\mathrm{d}}{\mathrm{d}t}\int_\Omega\varrho s\,\mathrm{d}x=\int_\Omega\mathcal{P}\,\mathrm{d}x\geq0$ |

## 数值方法

### Scheme I：半隐式 Euler + 有限元

- **时间**：半隐式 Euler。$\rho_i^*$ 取 $\rho_i^n$（隐式）或 $\rho_i^{n+1}$（显式）两种选择。
- **空间**：合适有限元，配合**混合变分形式**用压力作 Lagrange 乘子逐点施加约束。
- **耗散/扩散通量的离散梯度**采用特殊"离散商"形式（保证对称性）：

```math
\nabla_{h}\frac{\mu_{jh}^{n+1}}{\vartheta_{h}^{n+1}}\coloneqq\frac{1}{\vartheta_{h}^{n+1}}\nabla\mu_{jh}^{n+1}-\frac{\mu_{jh}^{n+1}}{\vartheta_{h}^{*}\vartheta_{h}^{n+1}}\nabla\vartheta_{h}^{n+1}
```

```math
\nabla_{h}\frac{1}{\vartheta_{h}^{n+1}}\coloneqq-\,\frac{1}{\vartheta_{h}^{*}\vartheta_{h}^{n+1}}\nabla\vartheta_{h}^{n+1}
```

- **离散全局结构（Theorem 5.3）**：

| 性质 | 离散结论 |
|---|---|
| 偏质量守恒 | $\int_\Omega\rho_{ih}^{n+1}=\int_\Omega\rho_{ih}^{n}$（精确）|
| **总能量** | $\int_\Omega\frac{1}{2}\varrho_h^{n+1}\|\bm{u}_h^{n+1}\|^2+\varrho e(\cdot)\ \leq\ \int_\Omega\frac{1}{2}\varrho_h^{n}\|\bm{u}_h^{n}\|^2+\varrho e(\cdot)$（**单调下降 = 数值耗散**）|
| 熵产生 | $\int_\Omega(\varrho s)_h^{n+1}=\int_\Omega(\varrho s)_h^{n}+\tau\int_\Omega\mathcal{P}_h^n$，且 $\mathcal{P}_h^n\geq0$ |

- **准不可压（Theorem 5.4）**：
  - **Case (i)** $\rho_i^*=\rho_i^n$：**无条件**满足 $\sum_i V_i\rho_{ih}^n(\bm{x})=1$（逐点）。
  - **Case (ii)** $\rho_i^*=\rho_i^{n+1}$：需满足时间步条件 $\tau\|\operatorname{div}\cdots\|<\cdots$。

### Scheme II：连续 Petrov-Galerkin（CPG）

- **时间**：连续 Petrov-Galerkin。未知量分两类空间：

```math
\Pi_{\mathrm{disc}}^{k}(\mathcal{I}_{\tau};\mathcal{U}_{h})=\{v\in L^{1}([0,T];\mathcal{U}_{h}):v|_{I_{n}}\in\mathbb{P}_{k}(I_{n};\mathcal{U}_{h})\}
```

```math
\Pi_{\mathrm{cts}}^{k}(\mathcal{I}_{\tau};\mathcal{U}_{h})=\Pi_{\mathrm{disc}}^{k}(\mathcal{I}_{\tau};\mathcal{U}_{h})\cap C^{0}([0,T];\mathcal{U}_{h})
```

**连续未知量**（$\vec\rho_\sigma,\bm m_\sigma,(\varrho s)_\sigma$）在 $\Pi_{\rm cts}^k$ 中（时间连续、$k$ 阶多项式）；**其余未知量**（$\vec\mu_\sigma,\bm u_\sigma,p_\sigma,\vartheta_\sigma$）在 $\Pi_{\rm disc}^{k-1}$ 中（允许间断，$k-1$ 阶）。

- **关键机制**：连续未知量的时间导数落在 $\Pi_{\rm disc}^{k-1}$ 中，**因此可以直接作为测试函数**——这是能量守恒得证的技术核心。
- **加权速度** $\bm m=\sqrt{\varrho}\bm u$ 作为额外变量，其变分定义 $\langle\bm m,\bm w\rangle=\langle\sqrt{\varrho}\bm u,\bm w\rangle$。
- **离散全局结构（Theorem 5.6）**：

| 性质 | 离散结论 |
|---|---|
| 偏质量守恒 | 精确 |
| **总能量** | $\mathcal{E}_\sigma(t^{n+1})=\mathcal{E}_\sigma(t^{n})$（**精确守恒**）|
| 熵产生 | $\int(\varrho s)_\sigma(t^{n+1})=\int(\varrho s)_\sigma(t^{n})+\int_{I_n}\!\!\int_\Omega\mathcal{P}(\cdot)\,\mathrm{d}x\,\mathrm{d}t$ |

其中 $\mathcal{E}_\sigma(t)=\int_\Omega\left[\frac{1}{2}\|\bm m_\sigma(t)\|^2+\varrho e(\vec\rho_\sigma(t),(\varrho s)_\sigma(t))\right]\mathrm{d}x$。

- **测试函数映射（Lemma 4.6）**：偏质量用 $\psi_i=1$；能量用 $\psi_i=\mu_i-V_ip$、$\zeta_i=\partial_t\rho_i$、$\bm v=\bm u$、$\bm w=\partial_t\bm m$、$q=p$、$\omega=\vartheta$、$\gamma=\partial_t(\varrho s)$；熵用 $\omega=1$。

## 公式

熵产出的离散形式（保证 $\geq0$ 的关键）：

```math
\mathcal{P}_{h}^{n}=\frac{1}{\vartheta_{h}^{n+1}}\mathbb{S}(\cdot):\mathrm{D}\bm{u}_{h}^{n+1}+\begin{pmatrix}\nabla_{h}\frac{\vec{\mu}_{h}^{n+1}}{\vartheta_{h}^{n+1}}\\ \nabla_{h}\frac{1}{\vartheta_{h}^{n+1}}\end{pmatrix}^{\top}\!\!\!\bm{L}^{*}\begin{pmatrix}\nabla_{h}\frac{\vec{\mu}_{h}^{n+1}}{\vartheta_{h}^{n+1}}\\ \nabla_{h}\frac{1}{\vartheta_{h}^{n+1}}\end{pmatrix}\geq 0
```

内部能量差的上下界（Lemma 2.1，用于证明能量耗散）：

```math
(\varrho e)_{+}-(\varrho e)_{-}\leq\sum_{i=1}^{N}\partial_{\rho_{i}}(\varrho F)(\vec{\rho}_{+},\vartheta_{+})[\rho_{i+}-\rho_{i-}]+\vartheta_{+}[(\varrho s)_{+}-(\varrho s)_{-}]
```

（要求 $\varrho F$ 对 $\vec\rho$ **凸**、对 $\vartheta$ **凹**。）

## 实验结论

### 实现

- NGSolve（单元方测试）+ Firedrake（应用算例）+ **Irksome**（CPG 时间离散自动生成）
- Newton 法求解每步非线性系统：NGSolve 用 $L^2$ 增量范数绝对容差 $10^{-11}$；Firedrake 用残差欧氏范数 $10^{-11}$。

### 空间收敛测试（$\Omega=(0,1)^2$，$N=2$，$T=0.1$，$\tau=10^{-4}$，网格 $h_k\approx2^{-k}$，$k=1..6$）

Georgiadis–Jüngel 混合能、$M_{ij}=\bar M\left(\delta_{ij}\rho_i-\frac{\rho_i\rho_j}{\varrho}\right)$、$K=10^{-2}$、$\eta=\bar\eta$、$\lambda=0$。

**两方案共同结论**：
- $\vec\rho$、$\vartheta$、$\varrho s$ 在 $L^\infty(0,T;L^2)$ 下**二阶收敛**
- 压力 $p$ 在 $L^2(0,T;L^2)$ 下**二阶收敛**
- $\vartheta$、$\vec\mu$ 在 $L^2(0,T;H^1)$ 下**一阶收敛**

**Scheme I 收敛率（Table 1，误差随 $k$）**：

| $k$ | err($\vec\rho$) | EOC | err($\bm u$) | EOC | err($\vartheta$) | EOC |
|---|---|---|---|---|---|---|
| 3 | $4.86\times10^{-2}$ | 1.59 | $3.90\times10^{-2}$ | 1.40 | $1.31\times10^{-2}$ | 1.00 |
| 4 | $1.13\times10^{-2}$ | 2.11 | $9.58\times10^{-3}$ | 2.03 | $3.56\times10^{-3}$ | 1.89 |
| 5 | $2.67\times10^{-3}$ | 2.08 | $1.24\times10^{-3}$ | 2.95 | $9.12\times10^{-4}$ | 1.96 |
| 6 | $6.41\times10^{-4}$ | 2.06 | $1.29\times10^{-4}$ | 3.27 | $2.29\times10^{-4}$ | 1.99 |

**Scheme II（Table 2）**：err($\vec\rho$) 在 $k=4,5,6$ 为 $1.02\times10^{-2}\to2.56\times10^{-3}\to6.41\times10^{-4}$，EOC 1.93/2.00/2.00；err($\bm m$) 的 EOC 更高（2.03/2.60/2.16），反映 $\mathcal{X}_h$ 更高多项式次数。

### 结构保持测试（$N=3$，$T=0.1$，$\tau=10^{-4}$，$h=2^{-7}$）

初始条件含层状结构（$A_y,A_x,B_1,B_2$）与圆盘（$C$），被旋转流场输运并被扩散平滑。

| 量 | Scheme I (半隐式 Euler) | Scheme II (CPG) |
|---|---|---|
| 总能量 $\mathcal{E}(t)$ | **单调下降**（Theorem 5.3 保证）| **守恒到 $\sim10^{-13}$**（Theorem 5.6 保证）|
| 总熵 $\int_\Omega\varrho s$ | 增加 | 增加 |
| 偏质量守恒误差 | $\sim10^{-13}$ | $\sim10^{-13}$ |
| 准不可压约束误差 $\|\sum_iV_i\rho_i-1\|_{L^\infty}$ | $\sim10^{-14}$ | $\sim10^{-14}$ |

### 应用算例：苯–环己烷微流体容器（$N=2$）

- 域：无量纲坐标 $\hat x\in[0,4]$、$\hat y\in[-1,1]$，参考长度 $L_{\rm ref}=2$ mm
- 边界：苯入口（左上）、环己烷入口（左下）、出口（右侧）、壁面
- 入口给定**总质量通量** $(\rho_i\bm u+\bm J_i)\cdot\bm n=\bm G_{i,k}\cdot\bm n$ + 速度一致性条件 $\bm u=\frac{1}{\varrho}\sum_i\bm G_{i,k}$
- 出口 do-nothing（$\bm J_i\cdot\bm n=0$、$\bm\sigma\cdot\bm n=0$）；壁面无滑移 + 零扩散通量
- **热边界**：入口用 Robin 条件（作用于总熵通量 $\varrho s\bm u+\bm J_s$）近似强制 $\vartheta\approx\vartheta_{\rm inlet}$；壁面与出口 $\nabla\vartheta\cdot\bm n=0$
- **自由能**：**Margules 模型**（含非理想混合贡献，参数 $A_{12},A_{21}$）
- **Maxwell-Stefan 迁移率**由 Maxwell-Stefan 关系求逆得到：

```math
\bm{M}=\frac{\mathscr{D}_{12}\rho_{1}\rho_{2}m_{1}m_{2}}{R\varrho(m_{1}x_{1}+m_{2}x_{2})}\begin{pmatrix}1&-1\\-1&1\end{pmatrix},
\qquad K=(k_{1}x_{1}+k_{2}x_{2})\vartheta^{2}
```

- **材料参数**：$m_1=0.078$、$m_2=0.084$ kg/mol；$\rho_1/V_1=876$、$\rho_2/V_2=773$ kg/m³；$c_{p,1}=135.69$、$c_{p,2}=156.00$ J/(K mol)；$k_1=0.14$、$k_2=0.11$ W/(m K)

## 局限性

1. **⚠️ 关键陷阱（Remark 4.4）**：在近不可压设定下，热力学强迫项 $-\left\langle\sum_i\rho_i(\nabla\mu_i-V_i\nabla p)+\varrho s\nabla\vartheta,\bm v\right\rangle$ 可能**主导动量平衡**。无量纲化后乘以 Lagrange 数 $\mathrm{La}$——苯–环己烷混合物中 $\mathrm{La}\approx10^{15}$！
   - 若 $\varrho F$ 对 $\vec\rho$ **一次齐次**（如 Georgiadis–Jüngel 混合能），该项在连续层为零，可移除并得到一致的 Maxwell-Stefan 离散。
   - **但能量稳定性结果随之失效**（Lemma 4.2 不再成立），并传导到全离散格式（Theorem 5.3）与 Scheme II（Lemma 4.6、5.6）。质量守恒、熵产生、准不可压性不受影响。
2. **Scheme I 数值耗散总能量**——这是与连续模型的本质差异，对长时间积分与能量敏感的输运问题不利。
3. **Scheme II 更昂贵**——需要连续 Petrov-Galerkin 时间离散（Irksome 生成），每个时间步的全局耦合非线性系统规模更大。
4. **CPG 使用精确时间积分**（Remark 5.7）：实际实现中若用数值求积，能量守恒可能被破坏。
5. 凸性假设：能量耗散证明要求 $\varrho F$ 对 $\vec\rho$ 凸、对 $\vartheta$ 凹。
6. 粘性耗散强制性要求 $\eta$ 一致下界且 $d\lambda+\eta\geq0$（Korn 不等式）。
7. 推导中为简化取 $c_i=0$（热扩散交叉项），扩展到 $c_i\neq0$ 论文称"直接"但未展开。

## 实现建议

- **实现难度**：高（需变分推导 + 混合有限元 + CPG 时间离散生成）
- **预期性能**：二阶空间收敛；结构保持精度达机器精度级（$10^{-13}$–$10^{-14}$）
- **适用场景**：
  - **多组分输运**：燃烧、电池、膜分离、微混合器、蒸馏塔、萃取
  - **热 Maxwell-Stefan**：温度依赖扩散系数、**热扩散（Soret）效应**显著的场景
  - **准不可压混合流体**：组分比容差别大时（对比可压单相）
- **选型建议**：
  | | Scheme I (半隐式 Euler) | Scheme II (CPG) |
  |---|---|---|
  | 成本 | 低 | 高 |
  | 熵产生 | ✅ 保证 | ✅ 保证 |
  | 准不可压逐点 | ✅ 保证 | ✅ 保证 |
  | 总能量 | ⚠️ 数值耗散 | ✅ **精确守恒** |
  | 时间阶 | 1 | **任意 $k$** |
  | 推荐场景 | 大规模长时间积分、能量不敏感 | 能量敏感（如绝热过程、焓升计算）、需要高阶时间精度 |

- **落地建议**：
  - 用**熵平衡**而非能量平衡做变分基础，并考虑以**逆温度**作为离散变量
  - 苯–环己烷这类 $\mathrm{La}\sim10^{15}$ 的体系**必须警惕热力学强迫项主导**；若移除该项需重新验证能量稳定性
  - CPG 实现可直接用 **Irksome** 自动生成时间离散
