## 核心贡献

> 建立**张拉整体 (tensegrity) 预应力的逆问题**求解框架：用**物理信息神经网络 (PINN)** 在**约束笛卡尔坐标**下训练，**保持"只受拉" (tension-only) 缆索律**，因此能够处理**张紧-松弛转变 (taut–slack transition)** 这一非光滑动力学；同时用 **Fisher 信息分析**在反演**之前**就告诉你**一条记录能确定哪些构件参数**。

1. **逆问题的 PINN 表述**：位移网络 $\boldsymbol q_\theta(\tau)$ + 约束乘子网络 $\lambda_\phi(\tau)$ 共同训练；**预应力（力密度）、阻尼、轴向刚度作为可训练参数**。
2. **约束笛卡尔坐标的三大优势**：
   - 质量矩阵 $\boldsymbol M$ **恒定** → 训练稳定；
   - 缆索力密度**线性进入**残差 → 参数灵敏度**闭式可得**；
   - 与 Goyal-Skelton 表述（STEDY 代码实现）一致。
3. **保持"只受拉"律**：$T_k\geq 0$，$g_k\geq 0$，$T_kg_k=0$。用**平滑 (softplus) 缆索律**实现，并在**相同记录**上与两个替代方案对比：
   - **Fischer–Burmeister 互补残差**（严格等于零当且仅当只受拉条件成立）；
   - 在转变附近**加密配点 (collocation points)**。
4. **可辨识性分析（本文的第二大贡献）**：用 **Fisher 信息矩阵**与 **Cramér–Rao 下界 (CRLB)** 在**反演之前**量化：一条记录能确定哪些构件参数、精度如何。**力密度的线性进入**使得"记录无法确定的构件"一目了然。当参数集病态时，**把构件分组 (grouping)** 可恢复良定性 —— 而这些组恰好就是用于作动的**簇状缆索 (clustered cables)**。
5. **数值结果**：
   - 单模块框架：可辨识力密度在**半个自由坐标**的含噪加速度下恢复到 **1.5%** 以内，**无论记录是否含张紧-松弛转变**；
   - **含转变的记录能确定纯张紧记录无法确定的构件**；
   - 五模块框架（16 缆两跨桥）：中位力密度误差升至 **4.2%**；
   - 实测记录：识别的弹簧刚度与独立测量值平均相差 **0.1%**；张拉整体单纯形在 **13 个预应力水平**下与缆索力传感器吻合 **2.9% RMS**。

## 技术方案

### 核心思想

**问题**：张拉整体的**预应力 (prestress)** 决定其刚度、固有频率与传力路径，但：
- **不可直接观测**（无法从稀疏测量反推）；
- 服役中会因**徐变、锚固滑移、热循环**而下降 → 关键损伤模式；
- 几何不变但结构行为已变（因为刚度和频率随自应力缩放）。

**难点三连**：(a) 预应力是**分布式**的（存在多个独立自应力态时，不再由几何唯一确定）；(b) 缆索是**单侧的**（只受拉，强激励下松弛 → 动力学**非光滑**）；(c) 仪器**稀疏**。

**核心思想**：把 PINN 的"前向问题"用法**翻转**成"逆问题" —— 已知参数 → 预测响应 变成 已知响应 → **推断参数**。因而在**约束坐标**中让力密度**线性进入**残差，得到闭式灵敏度，从而能用 Fisher 信息做可辨识性分析。

### 关键技术

| 技术 | 说明 |
|------|------|
| DAE 形式 | 索引-3 DAE，积分到索引-1（加速度级）**鞍点形式** |
| 鞍点系统 | $\begin{bmatrix}\boldsymbol M&-\nabla R(\boldsymbol q)^{\top}\\-\nabla R(\boldsymbol q)&0\end{bmatrix}\begin{bmatrix}\ddot{\boldsymbol q}\\\boldsymbol\lambda\end{bmatrix}=\begin{bmatrix}\boldsymbol f_s+\boldsymbol f_d+\boldsymbol G+\boldsymbol f_{\rm ext}\\\boldsymbol\kappa\end{bmatrix}$ |
| 只受拉缆索律 | $\sigma_k(\boldsymbol q)=K_k(1-L_{0k}/\lVert\boldsymbol s_k\rVert)$ 若 $\lVert\boldsymbol s_k\rVert>L_{0k}$，否则为 0 |
| 平滑缆索律 | softplus，锐度 $\beta$ |
| Fisher 信息 | $\boldsymbol J=\boldsymbol S^{\top}\boldsymbol\Gamma^{-1}\boldsymbol S$，$\boldsymbol S$ 为传感器加速度灵敏度 |
| CRLB | 由 $\boldsymbol J$ 给出参数估计的理论下界 |
| 传感器分组 | 病态时把构件绑定成组（用已有的簇状缆索）|
| 能量/约束检查 | $\boldsymbol E$、$\boldsymbol W$、位置级与速度级约束残差 $\|R(\boldsymbol q)\|$、$\|\nabla R(\boldsymbol q)\dot{\boldsymbol q}\|$ |

## 公式

```math
% ===== 约束笛卡尔动力学（鞍点形式）=====
\boldsymbol M\ddot{\boldsymbol q}
=\nabla R(\boldsymbol q)^{\top}\boldsymbol\lambda+\boldsymbol f_s(\boldsymbol q)
+\boldsymbol f_d(\boldsymbol q,\dot{\boldsymbol q})+\boldsymbol G+\boldsymbol f_{\rm ext}(t)

\begin{bmatrix}\boldsymbol M&-\nabla R(\boldsymbol q)^{\top}\\-\nabla R(\boldsymbol q)&0\end{bmatrix}
\begin{bmatrix}\ddot{\boldsymbol q}\\\boldsymbol\lambda\end{bmatrix}
=\begin{bmatrix}\boldsymbol f_s+\boldsymbol f_d+\boldsymbol G+\boldsymbol f_{\rm ext}\\\boldsymbol\kappa\end{bmatrix}

% ===== 只受拉缆索律 =====
\sigma_k(\boldsymbol q)=
\begin{cases}
K_k\left(1-\dfrac{L_{0k}}{\lVert\boldsymbol s_k\rVert}\right),&\lVert\boldsymbol s_k\rVert>L_{0k}\\[4pt]
0,&\text{otherwise}
\end{cases}
\qquad
\boldsymbol f_s=-\sum_k\sigma_k\boldsymbol Y_k^{\top}\boldsymbol Y_k\boldsymbol q

% ===== 位置/速度级约束 =====
\boldsymbol q^{\top}\boldsymbol X_k^{\top}\boldsymbol X_k\boldsymbol q=\bar L_k^2,
\qquad
\boldsymbol R(\boldsymbol q)=0,\qquad \nabla R(\boldsymbol q)\dot{\boldsymbol q}=0,
\qquad \nabla R(\boldsymbol q)\ddot{\boldsymbol q}+\boldsymbol\kappa(\boldsymbol q,\dot{\boldsymbol q})=0

% ===== 有效质量（只受拉的非光滑接触）=====
\boldsymbol M_{\rm eff}=\boldsymbol M+\sum_k m_k\boldsymbol Y_k^{\top}\boldsymbol Y_k
\quad\text{（缆索张紧时增加等效惯量；松弛时该项消失）}

% ===== Fisher 信息与 CRLB =====
\boldsymbol J=\boldsymbol S^{\top}\boldsymbol\Gamma^{-1}\boldsymbol S,
\qquad
\mathrm{Cov}(\hat{\boldsymbol p})\succeq\boldsymbol J^{-1}
\qquad
\boldsymbol S=\frac{\partial\boldsymbol a_{\rm sensor}}{\partial\boldsymbol p}

% ===== 能量与功（物理一致性检查）=====
E=\tfrac12\dot{\boldsymbol q}^{\top}\boldsymbol M\dot{\boldsymbol q}+V_g+V_s,
\qquad
W=\int\boldsymbol f_{\rm ext}^{\top}\dot{\boldsymbol q}\,dt
```

## 代码片段

```python
import torch
import torch.nn as nn

class TensegrityInversePINN(nn.Module):
    """位移网络 + 约束乘子网络；力密度/阻尼/刚度为可训练参数"""

    def __init__(self, n_dof, n_cable, n_bar, n_param):
        super().__init__()
        self.q_net   = nn.Sequential(nn.Linear(1, 128), nn.Tanh(),
                                     nn.Linear(128, 128), nn.Tanh(),
                                     nn.Linear(128, n_dof))
        self.lam_net = nn.Sequential(nn.Linear(1, 128), nn.Tanh(),
                                     nn.Linear(128, 128), nn.Tanh(),
                                     nn.Linear(128, n_bar))
        # 可训练物理参数：缆索力密度 sigma_k、阻尼 c_k、轴向刚度 EA
        self.sigma = nn.Parameter(torch.zeros(n_cable))
        self.c_damp = nn.Parameter(torch.zeros(n_cable))
        self.EA = nn.Parameter(torch.ones(n_cable))

    def forward(self, tau):
        q = self.q_net(tau)
        lam = self.lam_net(tau)
        dq = torch.autograd.functional.jacobian(lambda t: self.q_net(t), tau, vectorize=True)
        return q, dq, lam

def smooth_tension_only(L, L0, EA, beta):
    """平滑 (softplus) 只受拉缆索律 —— 保持 T>=0 且 T*g=0 的近似"""
    # g = L - L0 (slackness); 仅当 L > L0 时承载拉力
    delta = L - L0
    # softplus 型：T = EA * (1 - L0/L) * sigmoid(beta * delta) 的平滑版本
    T = EA * (1.0 - L0/L) * torch.sigmoid(beta * delta)
    return T

def eom_residual(model, tau, M, Y, X, Lbar, g):
    """EOM 残差 + 硬约束（softplus 缆索律），供 PINN 训练"""
    q, dq, lam = model(tau)
    d2q = torch.autograd.grad(dq, tau, grad_outputs=torch.ones_like(dq),
                              create_graph=True)[0]
    # 缆索内力（力密度线性进入 -> 闭式灵敏度）
    for k in range(n_cable):
        s_k = Y[k] @ q
        L = torch.linalg.norm(s_k)
        T = smooth_tension_only(L, L0[k], model.EA[k], beta)
        f_cable -= T * (s_k / L)
    # 约束残差
    r_bar = torch.einsum('bi,ij,bj->b', q, X, X) - Lbar**2
    # 乘子项: grad R(q)^T lambda
    r_eom = M @ d2q - (gradR_T @ lam) - (f_cable + f_damp + G + f_ext)
    return r_eom, r_bar

def fisher_information(model, sigma_noise):
    """Fisher 信息矩阵：反演前判断哪些构件参数可辨识"""
    S = compute_sensor_sensitivities(model)      # d a_sensor / d p
    J = S.T @ inv(sigma_noise**2 * I) @ S
    return J

def crlb(J):
    """Cramér-Rao 下界：参数估计精度下界"""
    return inv(J)
```

## 实验结论

- **数据集/算例**：
  - **仿真**：平面张拉整体框架，1/2/3/5 个 Snelson X-模块（最大为 **16 缆两跨桥**）；三维三联棱柱；有重力与零重力预应力序列；
  - **实测**：六边形张拉整体棱柱（模态频率）、仿生腿（chirp 记录，弹簧刚度独立测量）、**全尺寸张拉整体单纯形**（冲击记录，每缆一个力传感器，**13 个预应力水平**）。
- **基线**：既有方法（网格上的预应力依赖动力学跟踪、模态更新、贝叶斯滤波、力平衡恢复）—— 均限于**线性化张紧区**。
- **结果**：
  - 单模块框架：**1.5%** 以内（仅用**半数自由坐标**的含噪加速度，含与不含张紧-松弛转变的记录皆然）；
  - **含转变的记录能确定纯张紧记录无法确定的构件**（重要信息增量）；
  - 五模块 16 缆两跨桥：中位力密度误差 **4.2%**；
  - 实测：弹簧刚度识别与独立测量**平均相差 0.1%**；单纯形 13 个预应力水平与力传感器**吻合 2.9% RMS**；
  - Fisher 分析在反演**之前**给出哪些构件可确定、精度如何；病态时构件分组可恢复良定性。

## 局限性

- **张紧-松弛处理仅在仿真记录上验证** —— 作者明确声明：**所有实测记录都不含松弛缆索**。实测只验证了重建模型、小振动识别与时域残差。
- **缆索阻尼是建模选择**（为可微性）；实测张拉整体的耗散主要来自**节点摩擦** —— 论文在实测数据上展示了这个不匹配的后果并在讨论中说明。
- **张力-松弛边界依赖平滑参数 $\beta$**（软化引入偏差）；虽与 Fischer–Burmeister 残差及加密配点做了对比，但仍是近似。
- **传感器噪声模型为对角** $\boldsymbol\Gamma$（白噪声）；实际传感器可能有空间相关噪声。
- **限于线性弹性缆索 + 张紧节点**；不含节点滑移、塑性、腐蚀等其他退化机制。
- 44 页 + 补充材料，方法论完备但**工程落地路径未给出**（不做健康监测系统设计）。

## 实现建议

- **实现难度**：⚠️ 较高。需要：约束笛卡尔 DAE 求解器（可参考 STEDY）、PINN 框架（DeepXDE/自建）、softplus 非光滑处理、闭式灵敏度、Fisher/CRLB 分析。
- **预期性能**：
  - 单次训练：44 页论文的规模，PINN 训练时间在 GPU 上小时级；
  - 关键效率提升：**力密度线性进入残差** → 灵敏度闭式 → Fisher 分析**无需多次前向扰动**（相对有限差分/自动微分灵敏度大幅加速）；
  - 求解器侧：鞍点系统每次 RHS 求值一次；仿真器与 STEDY 复现到相对精度 $10^{-14}$。
- **适用场景**：
  - ✅ 张拉整体/索网结构的**预应力健康监测**（预应力不可测且会退化）
  - ✅ **稀疏传感器**下的参数反演（只需半数坐标）
  - ✅ 非光滑（接触/松弛）系统的 PINN 逆问题范式
  - ❌ 不适合线性张紧、参数已知的常规结构
- **落地建议**：**本文最可迁移的三个方法论**：(1) **PINN 做逆问题**时选"参数线性进入残差"的坐标形式 → 灵敏度闭式、CRLB 可算；(2) **可辨识性分析前置** —— 先问"这条记录能定什么"，再决定要不要加传感器（本文直接给出"含转变的记录信息量更大"这一工程结论）；(3) **Fisher 病态 → 构件分组**，且**分组最好对齐物理上本就被捆绑的簇**。这三条对任何"从稀疏数据反演结构参数"的问题都适用。
