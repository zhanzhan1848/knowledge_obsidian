## 核心贡献

> 推导并数值验证**多孔介质中手性活性流体的"奇 Darcy定律" (odd Darcy law)**：**反对称渗透率张量**诱导出**横向于压力梯度方向**的流动。识别出导致这一"奇响应"的**两种不同机制**——**流体自身的奇黏性 (odd viscosity)**，或**边缘电流 (edge currents) 与惯性的非线性耦合**——并进一步展示**横向输运如何依赖孔隙率、边界摩擦与手性 (chirality)**。

1. **奇 Darcy 定律的建立**：在多孔介质中，**反对称的渗透率张量**诱导出**垂直于所施加压力梯度的流动**（横向输运）。
2. **两种机制的识别与区分**（本文的核心分析）：
   - **机制 A：奇黏性**——流体本身携带手性（角动量），产生反对称应力；
   - **机制 B：边缘电流与惯性的非线性耦合**——骨架/固体界面的**边缘电流**通过与流体惯性的**非线性**相互作用，产生同号的横向响应。
3. **数值验证**：对推导出的奇 Darcy 定律进行**数值验证**。
4. **参数依赖分析**：横向输运依赖
   - **孔隙率 (porosity)**
   - **边界摩擦 (boundary friction)**
   - **手性 (chirality)**

## 技术方案

### 核心思想

**背景：手性与"奇"响应**

**手性 (chirality)** 指体系缺乏镜像对称性。流体中的手性来源：
- **活性流体中的内禀自旋**（如手性分子、主动旋转的颗粒）
- **自旋–轨道锁定**的粒子（粒子自旋被流场剪切锁定，典型例子：磁性微球在磁场中）

**奇黏性 (odd viscosity)** 是手性流体的标志性现象。应力张量中出现**反对称部分**：
$$\sigma_{ij} = \sigma^{\text{sym}}_{ij} + \sigma^{\text{odd}}_{ij},\qquad \sigma^{\text{odd}}_{ij} = -\sigma^{\text{odd}}_{ji}$$

在无界流体中，奇黏性通常**不改变流动**（因为 $\nabla\times(\nabla\times\boldsymbol{u})=0$ 对不可压流成立）。但它**改变能量耗散**（产生 $\eta_o(\nabla\times\boldsymbol{u})^2$ 项）。

**然而在多孔介质中，奇黏性变得"可见"**——这是本文的出发点。

**为什么多孔介质"点亮"了奇黏性？**

关键在于**边界条件**。在多孔介质的孔隙壁上，不可压条件被**破坏**：
- 孔隙壁面不透流 → $\nabla\cdot\boldsymbol{u}=0$ 不再全局成立
- 存在**压力梯度驱动的穿流 (percolation)** 与**局部速度梯度**
- 于是 $\nabla\times(\nabla\times\boldsymbol{u}) \neq 0$ → **奇黏性项产生净力**

数学上，可以证明：在多孔介质中，即使外部驱动力（压力梯度）是**纯轴向（even）**的，奇黏性也会诱导出**横向（odd）**的流动。

**"奇 Darcy 定律"的形式**

普通 Darcy 定律：
$$\boldsymbol{u} = -\frac{\boldsymbol{K}}{\mu}\nabla p,\qquad \boldsymbol{K} = \boldsymbol{K}^{\text{sym}}$$

**奇 Darcy 定律**：$\boldsymbol{K}$ 允许有**反对称部分**：
$$\boldsymbol{K} = \boldsymbol{K}^{\text{sym}} + \boldsymbol{K}^{\text{odd}},\qquad \boldsymbol{K}^{\text{odd}}_{ij} = -\boldsymbol{K}^{\text{odd}}_{ji}$$

于是在**纯压力梯度**下产生**横向流动**：
$$\boldsymbol{u}_\perp \propto \boldsymbol{K}^{\text{odd}}\nabla p$$

这就是**手性的输运指纹**——手性体系能把"轴向驱动"变成"横向输运"，而**非手性体系不能**。

**两种机制的区分（本文最有价值的部分）**

在多孔介质中，横向响应可以由两条完全不同的物理路径产生：

**机制 A：奇黏性（流体本征）**
- 流体携带内禀自旋 → 应力有反对称部分 → 奇黏性在孔隙边界破坏不可压性处产生净横向力

**机制 B：边缘电流 + 惯性非线性耦合（界面本征）**
- **边缘电流 (edge current)**：在**固–液界面**上，由于**对称性破缺**（如 chiral surface），会自发流动——这是**拓扑边缘态**的连续介质对应
- 边缘电流**与流体惯性非线性耦合** → 产生横向流动

**为什么必须区分？**

因为二者的**标度律不同**：
- **奇黏性机制**主导时，横向流速 $\sim$ 奇黏性系数（**线性、小**）
- **惯性耦合机制**主导时，涉及**二次非线性**（$\sim v^2$ 或 $\sim$ 边界摩擦的耦合）

在实验中（尤其**介观尺度**：颗粒尺度的多孔介质），**惯性耦合可能主导**，因为它不要求流体真的有内禀自旋——只要求**界面有手性**。这**扩大了手性输运的实验可实现性**。

**参数依赖**

横向输运 $\sim f(\text{孔隙率},\, \text{边界摩擦},\, \text{手性强度})$。直觉：
- **孔隙率 $\phi \uparrow$** → 流动更"连通"，奇效应更容易传递（但也可能有非单调性）
- **边界摩擦 $\uparrow$** → 边界层更厚，不可压性破坏的影响改变
- **手性 $\uparrow$** → 反对称成分线性增强

### 关键技术

| 技术 | 说明 |
|------|------|
| 奇黏性 (odd viscosity) | 反对称应力张量，产生额外耗散 |
| 反对称渗透率张量 | $\boldsymbol{K}^{\text{odd}}$，手性的输运载体 |
| 奇 Darcy 定律 | 压力梯度 → 横向流动 |
| 边缘电流 (edge current) | 手性界面上的自发流动（拓扑边缘态的连续介质对应） |
| 非线性惯性耦合 | 边缘电流与流体惯性的相互作用 |
| 孔隙尺度数值验证 | 孔隙几何内的流动模拟 |
| 孔隙率依赖 | 孔隙网络连通性对奇效应传递的影响 |
| 边界摩擦 | 壁面摩擦对奇效应的调制 |
| 手性强度参数 | 奇黏性或界面手性的量度 |

## 公式 / 理论要点

```math
% 奇应力张量与奇黏性耗散
\sigma_{ij} = \sigma^{\text{sym}}_{ij} + \sigma^{\text{odd}}_{ij},
\qquad
\sigma^{\text{odd}}_{ij} = \eta_o\,\epsilon_{ijk}\,\partial_k u_j
```

```math
% 奇黏性附加耗散（无界流体中为净力，但多孔边界处不为零）
E_{\text{odd}} = 2\eta_o\,(\nabla\times\boldsymbol{u})\cdot(\nabla\times\boldsymbol{u})
\]

```math
% 奇 Darcy 定律：允许反对称渗透率
\boldsymbol{u} = -\frac{1}{\mu}\left(\boldsymbol{K}^{\text{sym}} + \boldsymbol{K}^{\text{odd}}\right)\nabla p,
\qquad
\boldsymbol{K}^{\text{odd}}_{ij} = -\boldsymbol{K}^{\text{odd}}_{ji}
```

```math
% 横向输运（手性指纹）
\boldsymbol{u}_\perp
= -\frac{1}{\mu}\boldsymbol{K}^{\text{odd}}\nabla p
\quad\text{（在纯轴向压力梯度下产生）}
```

```math
% 不可压性破坏是奇效应的前提（孔隙边界）
\nabla\cdot\boldsymbol{u} \neq 0 \quad \text{at pore walls}
\quad\Longrightarrow\quad
\nabla\times(\nabla\times\boldsymbol{u}) \neq 0
\quad\Longrightarrow\quad
\text{奇黏性产生净横向力}
```

```math
% 边缘电流（手性界面上的自发流动）
\boldsymbol{j}_{\text{edge}} \propto \chi\,\boldsymbol{n}\times\boldsymbol{e}
\quad\Longrightarrow\quad
\text{非线性惯性耦合：}
\boldsymbol{u}_\perp \propto \underbrace{\chi}_{\text{手性}}
\times\underbrace{\eta}_{\text{边界摩擦}}
\times\underbrace{|\boldsymbol{u}|^2}_{\text{惯性非线性}}
\]

```math
% 参数依赖
\boldsymbol{u}_\perp = f\!\left(\phi,\, \eta_{\text{wall}},\, \chi\right),
\qquad
\phi = \text{孔隙率},\ \eta_{\text{wall}} = \text{边界摩擦},\ \chi = \text{手性}
```

## 实验与结果

- **类型**: 理论推导 + **孔隙尺度数值验证**。
- **主要结果**:
  1. **奇 Darcy 定律**的推导：多孔介质中允许**反对称渗透率张量**，其在**纯压力梯度**下诱导**横向流动**。
  2. **两种机制的识别与区分**：
     - **流体本征的奇黏性**；
     - **边缘电流与惯性的非线性耦合**。
  3. **数值验证**该定律成立。
  4. **参数依赖**：横向输运依赖**孔隙率、边界摩擦、手性**。
- **物理解释**: 手性体系把轴向驱动转化为横向输运——这是**手性的输运指纹**，可用于区分手性/非手性体系并**测量手性强弱**。

## 局限性

- **孔隙尺度模拟成本高**：需要在真实孔隙几何（CT 扫描重构）上求解，成本显著高于均质多孔介质模型。
- **边缘电流机制的建模简化**：真实的边缘电流是**量子/拓扑态**现象，连续介质处理是近似；实验中如何制备具有确定手性的界面本身就困难。
- **参数范围的普适性**：孔隙率、边界摩擦、手性三者对结果的**联合依赖可能是非单调的**，摘要只说"展示依赖关系"，具体趋势需查正文。
- **单一驱动力类型**：只研究压力梯度驱动的横向响应，**外加电场/磁场、剪切驱动的耦合**未涉及。
- **未讨论实际应用**：如手性分离（对映体分离）、手性催化、多孔介质中的手性输运器件——这些是本文结论显然指向的应用方向，但未展开。
- **"数值验证"的算例规模与网格无关性**未在摘要中说明。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — 需要在孔隙几何上求解带奇黏性项的流动（体力项 $\eta_o\nabla\times(\nabla\times\boldsymbol{u})$，需特别处理不可压性的破坏），并可能需要加入边缘电流的源项模型。
- **预期性能**: 孔隙尺度 3D 计算成本高；若用均质多孔介质模型（Darcy 尺度）则极低成本但会丢失孔隙结构对奇效应的影响。
- **适用场景**:
  - **手性输运与手性分离**：对映体分离是天然应用（手性环境导致横向迁移差异）；
  - **主动物质/手性介质**：手性自旋流体、自旋–轨道锁定颗粒；
  - **多孔介质中的拓扑边缘态连续介质类比**：把量子边缘态现象推广到经典流体；
  - **材料设计**：手性界面涂层的输运调控；
  - **与本轮 [[2026-11-12-arXiv-2611.12862-Odd-Viscosity-Navier-Stokes-Global-Regularity-Three-Torus]] 配套**：后者是奇黏性在**连续介质**中的正则性，本文是奇黏性在**多孔介质**中的输运。二者构成奇黏性理论的两条主线（稳定性 + 输运），应归档为同一知识簇；
  - 另与 [[2026-11-12-arXiv-2611.11138]] 同类的 [[2026-11-11-arXiv-2611.13969-Rheology-of-Parametric-Odd-Materials]]（奇材料流变）相关。
- **可复用要点**:
  - **"反对称渗透率张量"是描述手性输运的简洁载体**：不必引入完整的手性流体本构，只需在输运定律中允许 $\boldsymbol{K}^{\text{odd}}$——这是**低阶建模**的范例，可在许多输运问题中推广（如热传导、扩散）。
  - **"机制必须分离"的诊断原则**：同一现象（横向输运）可能来自两条不同物理路径（流体本征 vs 界面本征），二者的**标度律与实验要求不同**。做机理判断时**必须先分离机制**，否则会用错误的本构去解释数据。
  - **边缘电流是"经典流体中的拓扑边缘态"**：这个类比在超材料与声学/弹性波系统中正在成为独立研究方向，值得作为交叉主题跟踪。
  - **不可压性破坏是产生横向效应的必要条件**——这个判据可推广：**任何"反对称耦合 + 边界几何"的组合**都可能产生类似的手性响应。
