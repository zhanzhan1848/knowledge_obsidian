## 核心贡献

> 在**闭超曲面**上把切向 Stokes / 瞬态切向 Stokes / 瞬态切向 Navier-Stokes 方程的**散度方程替换为压力 Poisson 方程**，从而**绕开鞍点结构**——使得一致的（conforming）有限元离散**不再需要离散 inf-sup 条件**。

1. **压力 Poisson 重构**：对动量方程作用 $-\mathrm{div}_\Gamma$ 并代入 $\mathrm{div}_\Gamma\bm{u}=f$，得到含压力的显式二阶方程。
2. **交换子恒等式**：切向散度与表面扩散算子 $\Delta_S$ 的交换子，其低阶项由 **Ricci 曲率**给出——这正是重构能化简的原因。
3. **压力无需边界条件**（因为 $\Gamma$ 是闭的）——这是绕开鞍点的关键。
4. **适定性等价定理**：每个重构**当且仅当**原问题适定时适定；用任意数据求解重构 = 用**修正后的散度数据**求解原问题。

## 控制方程

### 统一形式（切向流体问题）

设 $\Gamma\subset\mathbb{R}^{d+1}$（$d\geq2$）是**平稳、连通、闭**（紧且无边界）的超曲面。给定数据 $(\bm{f}_0,\bm{f},f)$，求速度-压力对 $(\bm{u},u)$：

```math
\begin{cases}
\alpha_{1}\partial_{t}\bm{u}+\alpha_{2}\bm{u}\cdot\nabla_{\Gamma}\bm{u}-2\mu\Delta_{S}\bm{u}+\nabla_{\Gamma}u&=\bm{f},\\
\operatorname{div}_{\Gamma}\bm{u}&=f,\\
\alpha_{1}\bm{u}(0)&=\alpha_{1}\bm{f}_{0}.
\end{cases}
```

- $\mu>0$：表面粘性系数；$\alpha_1,\alpha_2\in\{0,1\}$ 分别为瞬态与对流项的指示函数
- $\Delta_S$：**表面粘性算子**——对协变梯度的对称部分施加切向散度并投影回切空间（物理上相关的选择）
- ⚠️ **散度数据 $f$ 不必为零**——这在分析中是关键工具

**三族问题**：TS（定常切向 Stokes，$\alpha_1=\alpha_2=0$）、TTS（瞬态切向 Stokes，$\alpha_1=1,\alpha_2=0$）、TTNS（瞬态切向 Navier-Stokes，$\alpha_1=\alpha_2=1$）。

## 数值方法

### 核心思想

在原始变量（速度、压力）下，这些方程具有**鞍点结构**，稳定离散一般需要**离散 inf-sup 条件**，这限制了有限元空间的选取。

**关键洞见**：**闭超曲面没有边界**，所以压力可以由一个**不需要边界条件**的压力 Poisson 方程确定。

### 关键技术

| 技术 | 说明 |
|------|------|
| **压力 Poisson 方程** | $-\Delta_\Gamma u-\alpha_2\operatorname{div}_\Gamma(\bm{u}\cdot\nabla_\Gamma\bm{u})+2\mu\,\operatorname{div}_\Gamma(\bm{R}\bm{u})=-\operatorname{div}_\Gamma\bm{f}+\alpha_1\partial_t f-2\mu\Delta_\Gamma f$ |
| **交换子恒等式** | $(\Delta_S\bm{v},\nabla_\Gamma\phi)=(\nabla_\Gamma\operatorname{div}_\Gamma\bm{v}+\bm{R}\bm{v},\nabla_\Gamma\phi)$（$C^3$ 曲面，$\bm{v}\in\bm{H}^2_t$）|
| **Ricci 曲率映射** | $\bm{R}=\operatorname{tr}(\bm{W})\bm{W}-\bm{W}\bm{W}$，$\bm{W}$ 为 Weingarten 映射。**$d=2$（$\mathbb{R}^3$ 中的曲面）时 $\bm{R}$ 就是乘以 Gauss 曲率** |
| **数据映射 $\mathcal{D}$（块三角）** | $\mathcal{D}=\left[\begin{array}{cc}\operatorname{id}&0\\M&L\end{array}\right]$，其中 $M=-\operatorname{div}_\Gamma$，$L$ 为对角块：TS 是 $-2\mu\Delta_\Gamma$（Poisson），TTS/TTNS 是热算子 $L_r f:=(f(0),\partial_tf-2\mu\Delta_\Gamma f)$ |
| **初值松弛** | 用零均值的 Lagrange 乘子 $u_0$ 松弛初值：$\bm{u}(0)+\nabla_\Gamma u_0=\bm{f}_0$，等价于 $-\Delta_\Gamma u_0=f(0)-\operatorname{div}_\Gamma\bm{f}_0$。**目的是让数据空间成为完整乘积空间**（否则对偶空间难描述）|

## 公式

### 压力 Poisson 方程（重构的核心）

```math
-\Delta_{\Gamma}u-\alpha_{2}\operatorname{div}_{\Gamma}(\bm{u}\cdot\nabla_{\Gamma}\bm{u})+2\mu\,\operatorname{div}_{\Gamma}(\bm{R}\bm{u})=-\operatorname{div}_{\Gamma}\bm{f}+\alpha_{1}\partial_{t}f-2\mu\Delta_{\Gamma}f
```

### 交换子恒等式（Lemma 4）

```math
(D_{\Gamma}\bm{v},D_{\Gamma}(\nabla_{\Gamma}\phi))=(\operatorname{div}_{\Gamma}\bm{v},\Delta_{\Gamma}\phi)-(\bm{R}\bm{v},\nabla_{\Gamma}\phi)
```

```math
(\Delta_{S}\bm{v},\nabla_{\Gamma}\phi)=(\nabla_{\Gamma}\operatorname{div}_{\Gamma}\bm{v}+\bm{R}\bm{v},\nabla_{\Gamma}\phi),
\qquad
\operatorname{div}_{\Gamma}(\Delta_{S}\bm{v})=\Delta_{\Gamma}(\operatorname{div}_{\Gamma}\bm{v})+\operatorname{div}_{\Gamma}(\bm{R}\bm{v})
```

### 块三角数据映射（Lemma 7）

```math
\mathcal{D}:=\left[\begin{array}{cc}\operatorname{id}&0\\M&L\end{array}\right],
\qquad
\mathcal{D}^{-1}=\left[\begin{array}{cc}\operatorname{id}&0\\-L^{-1}M&L^{-1}\end{array}\right]
```

求解 $\mathcal{D}y=z$ 即**块前代**：$y_1=z_1$，然后 $Ly_2=z_2-Mz_1$。因此**用任意数据求解重构 = 用修正的散度数据求解原问题**，修正量由单个线性辅助问题确定（TS 是 Poisson，TTS/TTNS 是热问题）。

### 适定性等价（Proposition 6）

设 $\mathcal{B}=\mathcal{D}\circ\mathcal{A}$，$\mathcal{D}$ 是线性同胚，则 $\mathcal{B}$ 是同胚 $\iff$ $\mathcal{A}$ 是同胚，且 $\mathcal{B}^{-1}=\mathcal{A}^{-1}\circ\mathcal{D}^{-1}$。

## 实验结论

**本文为纯理论工作，无数值实验。** 论证的核心结构：

1. **形式推导**（§4.1）：对动量方程作用 $-\operatorname{div}_\Gamma$，代入散度约束。
   - 切向散度与**时间导数可交换**（因为 $\Gamma$ 平稳）
   - 切向散度与 $\Delta_S$ **仅差一个低阶曲率项** $\operatorname{div}_\Gamma(\bm{R}\bm{u})$
2. **抽象框架**（§4.2）：Proposition 6（适定性转移）+ Lemma 7（三角数据映射）
3. **函数空间设定**（§4.3）：三种问题的 Banach 空间设定，$\mathcal{D}$ 统一为 Lemma 7 的三角形式，$M=-\operatorname{div}_\Gamma$
4. **验证**（§4.4）：在三种设定下统一验证 $\mathcal{B}=\mathcal{D}\circ\mathcal{A}$
5. **主结果**（§4.5）：**每个重构当且仅当原问题适定时适定**

**正则性阈值**：对 $C^2$ 曲面、压力 Poisson 数据在 $H^{-1}$ 中，切向 Stokes 重构可在 **$H^1$-based 空间**中提出——**为不需要离散 inf-sup 条件的一致离散铺平道路**。

---

## 局限性

1. **要求 $\Gamma$ 闭（紧且无边界）**——这是压力无需边界条件的来源，也直接排除了**开曲面**（薄液膜、开口边界）的情形。
2. **曲面正则性要求**：交换子恒等式的强版本需 $C^3$（弱版本 $C^2$）；最弱版本需 $C^4$ 且 $\bm{v}\in\bm{H}^3_t$。
3. **静止曲面**——切向散度与时间导数可交换的前提；移动曲面未处理。
4. **无边界条件**——既然 $\Gamma$ 无边界，也就无法处理壁面边界条件。
5. **未涉及可压缩、湍流建模、多相流**。
6. **对数性**：纯理论，未给数值验证或误差估计。

## 实现建议

- **实现难度**：高（需曲面微分几何 + 变分分析）
- **适用场景**：
  - **薄膜/表面流体**：生物膜、液晶 nematic、界面流、微流控
  - **浅水方程的曲面推广**：地球大尺度流（球面）
  - 任何**原始变量（速度-压力）鞍点格式**受限的场景
- **落地建议**：
  - **若计算域是闭曲面**，可考虑用压力 Poisson 重构替代混合速度-压力格式，**从而摆脱 inf-sup 约束对有限元空间配对的限制**
  - 重构的数值实现 = 先解压力 Poisson（只需网格上的 Laplace-Beltrami），再代回动量方程
  - **注意**：论文强调重构是**适定性等价**的，不是近似——精度不受影响，只是求解路径不同
  - 开边界问题仍需传统鞍点方法 + 稳定化（如 PSPG/LSES）
