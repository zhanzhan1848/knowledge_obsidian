## 核心贡献

> 当**热**与**溶质**同时使**快速旋转流体**失稳时，它们的**浮力是否相加**？**共密度 (codensity) 模型**假定相加，给出**笔直的起始对角线**；而**球壳**显示出**弯曲且带折点的阈值**。本文研究 **Busse–Simitev 旋转环 (rotating annulus)**，其**法向模态服从精确的复三次色散关系**。结合 **Bilharz 判据**与**中性曲线包络**，在**快速旋转极限**下给出显式的**燕尾 (swallowtail) 波前**（Arnold 意义），它随**扩散率比降低**把共密度对角线弯曲成**光滑阈值、再成带折点的阈值**。

1. **核心问题**：热浮力与溶质浮力同时失稳时，二者是否**叠加**？
   - **共密度 (codensity) 模型**：假设二者可以合并为单一标量 → **笔直的起始对角线**；
   - **球壳 (spherical shells)**：显示出**弯曲且带折点 (kinked)** 的阈值。
   - 本文用旋转环几何**精确刻画**了这个差异。
2. **方法学基础**: **Busse–Simitev 旋转环**，其**法向模态服从精确的复三次色散关系**——这是少见的**精确可解**的旋转流体系统。
3. **数学工具组合**: **Bilharz 判据** + **中性曲线包络 (neutral-curve envelope)** → 快速旋转极限下的显式**燕尾波前**。
4. **几何结构**（Arnold 意义的**奇异点**理论应用）:
   - **燕尾 (swallowtail)**：一条三维波前曲面，其**尖点 (cusp) 边**位于**不稳定域内部**，其**暴露的折点 (exposed kink)** 终止于**燕尾奇点 (swallowtail singularity)**；
   - 这些是**波数选择 (wave-number selection)** 的奇点，**不涉及时间特征值的合并 (coalescence)**——这个区分很重要，它说明这里是**模式选择问题**而非**稳定性退化问题**；
   - **燕尾扩散率比**具有**解析的小 Prandtl 数与大 Prandtl 数极限**。
5. **折点处的物理**: 在**折点**处，**宽而快的热 Rossby 波**与**窄而慢的组分 Rossby 波**同时变为中性。
6. **隐藏弧 (hidden arcs)**: 标记**不稳定波数带的诞生与合并**。
7. **非线性选择 (nonlinear selection)**:
   - **平均标量反馈**通过**中性弧法向 (neutral-arc normals)** 与**标量响应**起作用；
   - 因此**平均剖面的共存边界 (coexistence margin)** 随**折点角 (kink angle)** 增大而**消失**（随波合并）；
   - **完整三次系数**预测在**参考角点**处稳健共存，在**合并附近**存在**窄的双稳区间**。
8. **验证**: **精确有限旋转角点 (exact finite-rotation corners)** 与**周期单元模拟 (periodic-cell simulations)** 确认了**共存波**及其**入侵阈值 (invasion thresholds)**。

## 技术方案

### 核心思想

**背景：快速旋转流体中的浮力失稳**

**Busse–Simitev 旋转环**是研究快速旋转流体中浮力不稳定性的经典系统：圆柱形环内充满流体，上下壁温差驱动**对流**。

**旋转引入的关键效应**：
- 科里奥利力把对流约束为 **Taylor–Proudman 列**（流动在旋转轴方向上均匀）；
- 在 $\beta$ 平面（考虑行星涡度梯度）上，对流波有**两种模式**：
  - **热 Rossby 波 (thermal Rossby wave)**：宽、快
  - **组分 Rossby 波 (compositional Rossby wave)**：窄、慢
- 二者有**各自的**中性曲线。

**核心争议：共密度模型合法吗？**

如果只考虑**一种**标量（纯热），问题很简单。但现实中有**多个**标量（热 + 盐 + 浓度……），每个都有浮力。

**共密度模型 (codensity model)** 假想：把多个标量加权合并成**单一等效标量** $s = \sum_k \alpha_k s_k$，浮力合并为**单一浮力** $\propto s$。若成立：
- 起始阈值应是**各浮力的线性叠加** → **笔直的对角线**

但**球壳**中的数值/实验显示：阈值是**弯曲的**，甚至**带折点**的。原因：**不同标量的浮力以不同方式影响对流模式**——它们不能简单地合并。

**本文的几何刻画**

旋转环的法向模态满足**精确的复三次色散关系**：
$$\lambda^3 + a\lambda^2 + b\lambda + c = 0$$
（$\lambda$ 是增长率，系数依赖扩散率比 $\kappa = \nu/\kappa_T$ 与无量纲浮力参数）

这个三次关系的系数结构允许用 **Bilharz 判据**（关于**稳定/不稳定根分布**的代数判据）直接分析何时失稳。

**燕尾波前的构造**

把 **Bilharz 判据**（代数条件）与**中性曲线包络**结合：
- 中性曲线 $\lambda = 0$ 在参数空间中的**包络**给出**起始边界**；
- 快速旋转极限下，这个包络的**三维结构**呈现出 **Arnold 意义的燕尾 (swallowtail)**——一种标准的**奇异点族**。

**燕尾的几何要素**：
- **尖点边 (cusp edges)**：位于**不稳定域内部**——意味着在那些参数处有**两个中性模态同时中性**（简并）
- **暴露折点 (exposed kink)**：终止于**燕尾奇点**
- **隐藏弧 (hidden arcs)**：标记**不稳定波数带**的诞生与合并

**关键的物理区分（本文的学术自觉）**：

> 这些是**波数选择 (wave-number selection)** 的奇点，**不涉及时间特征值的合并 (temporal eigenvalue coalescence)**。

这个区分至关重要：
- **时间特征值合并** = 动力学系统退化 = 真正的稳定性丧失（Landau 型）
- **波数选择奇点** = 在参数空间中，**哪个波数最先失稳**这一选择的拓扑结构发生改变

后者是**选择问题**而非**稳定性问题**。作者明确指出这一点，避免了误读。

**折点的物理意义**

在折点处，**宽而快的热 Rossby 波**与**窄而慢的组分 Rossby 波**同时中性。这意味着：
- 两种模式**竞争**
- 中性曲线**交叉**（对角线弯折）

**非线性选择与共存**

线性理论说"两个波同时中性"，但非线性会打破这个对称性。机制：
- **平均标量反馈 (mean-scalar feedback)**：非线性生成的平均标量场反过来作用于扰动；
- 这个反馈通过**中性弧的法向**与**标量响应**起作用；
- 结果：**平均剖面的共存边界**随**折点角**增大而**消失**（随着两个波合并）；
- 完整的三次系数可以预测：
  - **参考角点**处**稳健共存**；
  - **合并附近**存在**窄的双稳区间 (narrow bistable interval)**。

**验证**：**精确有限旋转角点**（有限 $\mathrm{Ro}$ 的精确角点计算）+ **周期单元模拟**确认共存波与入侵阈值。

## 公式 / 理论要点

```math
% 法向模态的精确复三次色散关系
\lambda^3 + a\,\lambda^2 + b\,\lambda + c = 0,
\qquad
\lambda = \text{增长率}
```

```math
% 中性条件 λ = 0 与包络
c(\boldsymbol{\mu}) = 0,\qquad
\text{起始边界} = \text{包络}\ \bigl(\nabla c \perp \text{中性面}\bigr)
```

```math
% Bilharz 判据（三次方程根分布）
\text{Bilharz}: \ \ \lambda \text{ 分布稳定} \iff \text{某组代数不等式成立}
\quad\Longrightarrow\quad \text{失稳区在参数空间中的显式边界}
```

```math
% 燕尾波前（快速旋转极限）
\text{在 }(\boldsymbol{\mu}_1,\boldsymbol{\mu}_2,\kappa)\text{ 空间中：}
\quad \text{起始面呈燕尾形（Arnold 意义）}
```

```math
% 尖点边在不稳定域内部 → 两模式同时中性
\text{cusp edge} \subset \text{unstable domain}
\quad\Longleftrightarrow\quad
\lambda_1 = 0 \ \wedge\ \lambda_2 = 0
\quad(\text{波数选择简并，非时间特征值合并})
```

```math
% 扩散率比的两端极限（解析）
\kappa \to 0 \ (\text{大 Pr}),\qquad \kappa \to \infty \ (\text{小 Pr})
\quad\Longrightarrow\quad
\text{燕尾扩散率比的解析极限}
```

```math
% 平均标量反馈 → 共存边界随折点角消失
\text{coexistence margin} \to 0
\quad\text{as}\quad
\text{kink angle} \to \text{merge angle}
```

```math
% 共密度模型（被检验的对照假设）—— 笔直对角线
s = \sum_k \alpha_k s_k,
\qquad
\text{起始}: \ \sum_k \alpha_k f_k = \text{const}
\quad\Longrightarrow\quad \text{直线}
```

## 实验与结果

- **类型**: 解析（色散关系 + 代数判据 + 奇点理论）+ 数值验证。
- **主要结果**:
  1. **共密度模型的"笔直对角线"被证伪/修正**：热与溶质浮力**不能简单相加**，阈值是**弯曲且带折点**的。
  2. **显式燕尾波前**（快速旋转极限），由 Bilharz 判据 + 中性曲线包络导出。
  3. **几何结构**: **尖点边在不稳定域内部**；**暴露折点终止于燕尾奇点**；**隐藏弧标记不稳定波数带的诞生与合并**；燕尾扩散率比有**解析的小/大 Pr 极限**。
  4. **奇点的性质**：**波数选择奇点**，**不涉及时间特征值合并**。
  5. **折点物理**：宽而快的热 Rossby 波与窄而慢的组分 Rossby 波**同时中性**。
  6. **非线性选择**: 平均标量反馈通过中性弧法向与标量响应起作用；**共存边界随折点角消失**；完整三次系数预测**参考角点的稳健共存**与**合并附近的窄双稳区间**。
  7. **验证**: 精确有限旋转角点 + 周期单元模拟确认**共存波**与**入侵阈值**。
- **意义**: 为**多层浮力不稳定**提供了**精确的几何框架**，并明确指出共密度近似的失效区域。

## 局限性

- **短文（10 页）**：内容极其精炼，**推导细节在补充材料中**，不利于独立复核。
- **仅旋转环几何**：虽然弧的几何有精确三次色散关系，但**球壳**（实际地球/行星）没有精确色散关系——作者以弧的结果**解释**球壳的弯曲/折点现象，属于**类比+定性对应**，不是严格证明。
- **渐近性**：燕尾结构是**快速旋转极限**（$\mathrm{Ro}\to 0$）下的结果；有限旋转下结构会变形（作者用"精确有限旋转角点"做了部分修正，但未系统处理）。
- **线性–非线性衔接**：共存与入侵阈值来自**周期单元模拟**，属于**弱非线性/有限振幅**框架，**强非线性**（对流非线性饱和、混合层深度变化）未处理。
- **扩散率比**：扩散率比是本文的核心参数，但**实际海洋**中的扩散率比范围可能不在所讨论的区间内。
- **未涉及真实海洋的复杂背景流**（剪切、非均匀旋转、赤道）。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — 三次色散关系的参数化与 Bilharz 判据的代数实现较直接；**非线性部分**（平均标量反馈、中性弧法向、周期单元模拟）需要实际的旋转环对流模型求解。
- **预期性能**: 线性分析近乎零成本；非线性验证需在旋转环（或周期单元）中做对流的非线性模拟——成本中等。
- **适用场景**:
  - **海洋/大气对流稳定性理论**：多标量（热+盐）分层系统的失稳判据；
  - **行星/恒星内部对流**：对流开始条件（发电机启动、对流翻涌）的判据；
  - **双组分扩散系统**（热扩散 + 溶质扩散）：本文的框架可直接套用；
  - **作为"多标量不可加性"的教科书级参考**：这是本文最持久的价值。
- **可复用要点**:
  - **"波数选择奇点 ≠ 时间特征值合并"** 是本文最值得学习的**概念纪律**。在做参数空间结构分析时，必须明确区分这两类事件——前者是模式选择拓扑，后者才是稳定性丧失。这个区分适用于所有"多个失稳模态竞争"的问题。
  - **"用精确可解系统（Busse–Simitev 环）揭示复杂系统（球壳）的结构"** 的方法论：当目标系统的色散关系不可精确求解时，找一个**结构同构的可解代理系统**，先在代理上把几何关系（弯曲、折点、奇点）搞清楚，再论证迁移。这是一条高效路线。
  - **"共密度模型的可加性假设必须被检验"**：多标量问题中默认"可以合并"是常见但危险的简化。本文的定量结论可作为审查类似假设的依据。
  - **奇点几何（燕尾、尖点、折点）是参数空间结构的通用语言**：可用于组织任何"两个竞争机制 + 一个比值参数"的相图。
  - 建议与本轮 [[2026-11-12-arXiv-2611.12433-N-Layer-QG-Modons-Vertically-Sheared-Flow]]（多层 QG modon）配套：两者同属**快速旋转/准地转**理论线，一个讲**波动与失稳**，一个讲**涡解构造**。
