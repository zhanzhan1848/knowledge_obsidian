## 核心贡献

> ADER-DG 配 LST-DG 预测器求解**带刚性源项的双曲方程**时，自发表现出 IMEX 格式的性质；本文给出**任意基多项式阶 N 的严格稳定性理论**，并把稳定条件化简为关于 Courant 数的一个**多项式方程**。

1. **刚度参数化**：用 `z = ν Δt^n < 0` 度量源项刚性（n = 源项非线性阶）。
2. **稳定域规律**：
   - 强刚度 `|z| ≫ 1`：`CFL_max(z) ~ |z|` **线性增长**（刚源项反而放宽时间步）
   - 弱源项 `|z| ≪ 1`：退化为已知的无源项 `CFL_max(0)` 结果
   - 过渡区 `|z| ~ 1`：发现**不显著的 CFL 下降**区间
3. **失稳判据（线性情形）**：**当且仅当**矩阵某个特征值达到 `λ = −1` 时违反稳定性，**与数值解的相位 θ 无关**。
4. **收敛性证明**：直接证明逼近阶 `p = N + 1`（任意 N）。
5. **数值验证**：线性对流–反应方程 + **二组分反应介质 Euler 方程组**双算例验证理论。

## 技术方案

### 核心思想

ADER-DG 家族（原始 ADER、ADER-DG、ADER-DG-MHD、ADER-DG-SERV、ADER-DG-HV 等）本质上是"**预测子 + 校正**"结构，可统一理解为：

```
预测器（Predictor）：用时间 Taylor 展开
  u_i^{n+1} = Σ_{j=0}^{N} Δt^j/j! · (d/dt)^j u_i(x, t_n)
  → 展开中的时间导数用 DG 半离散的空间导数 + 源项递推代替

校正器（Corrector）：LST-DG（Low-Storage Time-Integration）
  → 用局部 Lax-Friedrichs (Rusanov/LF) 通量 + MUSCL 限制器 + 前向欧拉（Euler-FV）时间推进
```

**核心论点**：当方程含**刚性源项**（如化学反应的刚性源、化学平衡、辐射冷却等）时，**预测器天然承担了 IMEX 的"隐式"角色** —— 预测器中的源项递推是无条件稳定的；刚源项实际上**放宽**了时间步限制（`CFL_max` 随刚度线性增长），这是 ADER 相对 RK 显式格式的核心优势。

### 关键技术

| 技术 | 说明 |
|------|------|
| 刚度参数 | `z = ν Δt^n < 0`；ν 为源项刚度、n 为源项非线性阶 |
| 线性稳定性 | 特征值分析；失稳**精确发生**于 `λ = −1`，与相位 θ 无关 |
| 稳定条件化简 | 化为关于 `CFL` 的**多项式方程**求解 |
| 逼近阶 | 严格导出 `p = N + 1`（N = 基多项式阶），与数值实验一致 |
| 数值验证 1 | 线性**对流–反应**方程 `∂_t u + ∂_x (a u) = S(u)` |
| 数值验证 2 | **二组分反应介质 Euler 方程组**（含压力耦合与刚性放热反应） |
| 实现语言 | C++ / Fortran，源项、ADE、DG、网格、输入输出、$\LaTeX$ 输出（含所有图表的 LaTeX 源码） |

## 公式

```math
刚度参数：
  z = ν Δt^n < 0        (ν: 源项刚度；n: 源项非线性阶)

稳定域随刚度的行为：
  |z| ≪ 1 :  CFL_max(z) → CFL_max(0)            (无源项已知结果)
  |z| ~ 1 :  过渡区，存在不显著的 CFL 下降
  |z| ≫ 1 :  CFL_max(z) ~ |z|                   (线性增长)

线性情形失稳判据：
  失稳 ⟺ ∃ 矩阵特征值 λ = −1                   （与相位 θ 无关）

稳定条件（化简形式）：
  对 CFL 求解一个多项式方程 → CFL_max(N, z)

逼近阶：
  p = N + 1             (N = 基多项式阶，任意 N)

ADER 预测器的 Taylor 展开结构：
  u_i^{n+1} = Σ_{j=0}^{N} (Δt^j / j!) (d^j u_i / dt^j)
  时间导数 → 用 DG 空间导数 + 源项递推展开
```

## 实验结论

- **数据集**: 线性对流–反应算例；二组分反应介质 Euler 方程组算例
- **基线**: 无源项 ADER-DG 的已知 `CFL_max(0)` 结果；线性稳定性理论
- **结果**:
  - 理论预测的 `CFL_max(N, z)` 依赖关系与数值实验**吻合良好**
  - 线性算例中失稳精确对应 `λ = −1`，与相位 θ 无关
  - 刚源项下 CFL 随刚度**线性放宽**（`|z| ≫ 1`）
  - 二阶逼近 `p = N + 1` 得到数值确认

## 局限性

- **93 页高密度理论**，核心贡献为**稳定性理论**而非新格式 —— 实用价值在于给出可信的步长选取准则，而非算法本身
- 稳定性分析针对**线性情形**给出精确 `λ = −1` 判据；非线性耦合下的行为未给同等强度的结论
- `CFL_max(N, z)` 需**求解一个关于 CFL 的多项式方程**，落地时需要预计算表或数值求根 —— 不能闭式快速求值
- 验证算例为**一维线性对流–反应**与**二组分反应介质**，未覆盖多维高马赫、可压缩湍流等复杂工况
- 稳定性增益（`CFL_max ~ |z|`）的物理意义需谨慎解读：这是"刚性源项允许更大时间步"，但**更大时间步**对**对流/声学**部分仍受 CFL 约束 —— 实际可用的步长取两者较小者
- 论文强调"完整谱与边界分析超出范围"式限定在 ADER-DG 框架下同样适用（边界条件对稳定域的影响未系统给出）

## 实现建议

- **实现难度**: **高**（理论）／**中**（代码复现）
  - 复现稳定性理论需要严格的线性稳定性分析推导（von Neumann / 特征值分析）
  - 复现代码则可直接使用作者提供的 Fortran/C++ 实现（含源项、ADE、网格、LaTeX 输出）
- **预期性能**: 相比显式 RK 配刚性源项，**同一步长下稳定**（IMEX 效应）；等价地说，刚性源项下可用**约 |z| 倍**的时间步
- **适用场景**:
  - **刚性化学反应流**（预混燃烧、SMR 化学反应器、爆轰 detonation）—— `76N30`、`76V05` MSC 码即指此类
  - 辐射输运 / 冷却 / 电离平衡等刚性源项
  - MHD 与多组分反应介质
- **落地建议**:
  1. **最实用的部分**：把 `CFL_max(N, z)` 做成**离线预计算查表**（按 N 与 z 对数网格），供在线查表选取步长 —— 这是零成本收益
  2. 线性稳定性判据 `λ = −1` 可作为**单元测试断言**：对纯刚性反应问题，扫 z 找临界点，验证失稳点与理论预测一致
  3. 使用时注意：真实可用步长 = min(CFL_对流约束, CFL_刚性放宽值) —— 不要误以为刚性放宽后可以无限放大步长
  4. 建议直接取用作者实现作为 ADER 家族的基线分支，与现有 FVM/OpenFOAM 算例做交叉验证
- 推荐结论：✅ **推荐实现**（作为**步长选取准则**与**验证基准**引入；格式本身若已有 ADER 实现则不必替换）
