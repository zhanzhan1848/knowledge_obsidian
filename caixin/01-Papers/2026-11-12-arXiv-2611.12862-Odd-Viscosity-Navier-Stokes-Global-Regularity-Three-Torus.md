## 核心贡献

> 三维**奇黏性 (odd viscosity)** Navier–Stokes 方程在立方三环面上的**全局强解定量正则性**结果：奇黏性系数足够大时任意 $H^2$ 无量纲零均值初始数据（及独立定常力）都有唯一全局强解；无外力时正解光滑。关键是**加权格点计数 + 带符号修正能量估计**，给出奇黏性与普通黏性之比的**多项式充分界**。三个主定理**全部在 Lean 4 + Mathlib 中形式化验证**。

1. **充分阈值定理**：立方三环面上，常数奇黏性算子取为**旋度的垂直导数**。任意实、无量纲零均值、无散初始数据与独立定常力（均在二阶 Sobolev 空间 $H^2$）——只要**某一个固定奇黏性系数的绝对值**达到一个与范数一致的充分阈值，即存在唯一全局强解。
2. **无外力情形的正则性提升**：无外力时，解在正时间处光滑（强解 → 光滑）。
3. **定量阈值**：加权格点计数与**带符号的修正能量估计**给出**奇黏性/普通黏性比**的充分界——对固定归一化力半径，该界是归一化初始数据半径的**多项式**；另给出一个独立的**力主导区域 (force-dominated regime)** 的界。
4. **显式有界数据/力区域**：直接动能与加权涡量障碍也给出**对所有系数**在显式有界数据与力区域内的正则性，包括：
   - 无外力的**闭球**：齐次二阶 Fourier–Sobolev 半径 $\frac{97}{40}\times$（黏性）
   - **七个闭的受迫矩形 (forced rectangles)**
5. **方法论澄清**：明确区分「**最小化一个充分公式**」与「**原方程的锐性 (sharpness)**」——不宣称多项式指数或前因子是最优的；原方程的**锐黏性阈值仍然开放**。
6. **形式化验证**：明确说明**有限证书 (finite certificates) 如何进入解析论证**，且**三个主定理全部在 Lean 4 with Mathlib 中形式化验证**。

## 技术方案

### 核心思想

经典三维 Navier–Stokes 的全球光滑性是千禧年问题。本文的巧妙之处在于：**引入奇黏性后，色散关系改变**，使得快速旋转流体的**共振平均 (resonant averaging)** 框架可以被"改造移植"过来，从而在**足够大的奇黏性**下得到正则性。

**奇黏性 (odd viscosity)** 的物理背景是角动量的手性输运：流体携带内禀自旋（手性），导致应力张量中出现反对称部分：

```math
% 奇黏性应力的反对称部分
\sigma^{\text{odd}}_{ij}
= \eta_o\, \epsilon_{ijk}\,\partial_k u_j
```

对应的额外耗散项为 $2\eta_o\,(\nabla\times u)\cdot(\nabla\times u)$，在二维中这一项恰好为**零**（因此本文必须用三维），而在三维中它是**非局部涡量-涡量耦合**。

**算子的选择**：本文取奇黏性算子为**旋度的垂直导数**，即 $\nu_o\, \partial_z(\nabla\times u)$。这个选择的两个理由：
1. 它在立方三环面上与 **Fourier 模态**的离散结构相容（$\partial_z$ 在环面上是谱算子）；
2. 它给出的色散关系与快速旋转流体（Rossby 波）**同类但不同**——正是这一点让"改造 resonant averaging"成为可能。

**共振平均框架**的移植是本文的技术核心。原框架用于快速旋转流体：旋转引入 $\pm 2\Omega$ 的频率劈裂，使得三次非线性项中某些谐波被"平均掉"（resonantly averaged），从而使涡量方程获得一个有效的 $2\Omega^2$ 型稳定性。在本文设定下，奇黏性产生类似但**不同的色散劈裂**，需要重新计算哪些谐波三阶共振。

**为什么要"修正能量 (corrected energy)"带符号？** 因为奇黏性项本身是反对称的，其对能量的贡献不是纯耗散，而依赖于涡量与应变的耦合。直接用动能估计会被这个反对称部分破坏。修正能量的思路是：构造一个**非平凡的组合量**（动能 + 加权涡量 + 力的修正项），使反对称贡献要么被吸收、要么因"带符号"的格点计数而被控制在可接受的范围内。

### 关键技术

| 技术 | 说明 |
|------|------|
| 奇黏性算子 $\nu_o\partial_z(\nabla\times u)$ | 旋度的垂直导数；三维中才有非平凡作用 |
| 共振平均框架（改造移植） | 原用于快速旋转流体，此处适配奇黏性色散 |
| 加权格点计数 (weighted lattice counts) | 估计 Fourier 模态组合的密度，控制非线性共振 |
| 带符号修正能量估计 (signed corrected-energy) | 处理奇黏性反对称贡献对能量估计的破坏 |
| 无量纲化 | 归一化初始数据半径、归一化力半径，使阈值可陈述为范数一致形式 |
| 动能障碍 + 加权涡量障碍 | 对所有系数在显式有界区域给出正则性 |
| 有限证书进入解析论证 | 明确论证链条中哪些步骤是"可检验的有限证书" |
| Lean 4 + Mathlib 形式化验证 | 三个主定理的机器验证 |

## 公式 / 理论要点

```math
% 带奇黏性的三维不可压 Navier-Stokes（立方三环面 \mathbb{T}^3）
\partial_t u + (u\cdot\nabla)u
= -\nabla p + \nu\,\Delta u
+ \nu_o\,\partial_z(\nabla\times u)
+ f,
\qquad \nabla\cdot u = 0
```

```math
% 奇黏性应力与耗散
\sigma^{\text{odd}}_{ij} = \eta_o\,\epsilon_{ijk}\partial_k u_j,
\qquad
E_{\text{odd}} = 2\eta_o\,(\nabla\times u)\cdot(\nabla\times u)
```

```math
% 无量纲化后的阈值形式（定性）
\eta_o \;\ge\; C\,
\frac{R_{\text{data}}^{\,p}\,(1+R_{\text{force}}^{\,q})}{R_{\text{force}}^{\,r}}
\quad\Longrightarrow\quad
\text{全局强解存在}
```

```math
% 无外力情形的显式闭球（充分条件，非锐）
\|u_0\|_{H^2_{\text{hom}}} \;\le\; \frac{97}{40}\,\nu
\quad\Longrightarrow\quad
\text{对任意系数 }(\nu,\nu_o)\text{ 均有正则性}
```

```math
% 二维不适用性（本文为何必须三维）
\text{在 } d=2:\quad
(\nabla\times u) = \partial_x u_y - \partial_y u_x = \omega\,\hat z
\;\Rightarrow\;
\partial_z(\nabla\times u) = 0
\;\Rightarrow\;
\text{奇黏性项恒为零}
```

## 实验与结果

- **类型**: 纯理论（解析定理 + 形式化验证），无数值实验。
- **主定理一（充分阈值）**: 存在范数一致的常数阈值，当**某一个固定奇黏性系数**的绝对值超过该阈值时，任意 $H^2$ 无量纲零均值无散初值 + 独立定常力 → 唯一全局强解；无外力时正解在 $t>0$ 光滑。
- **主定理二（定量界）**: 加权格点计数 + 带符号修正能量 → 奇黏性/普通黏性比的**多项式充分界**（固定归一化力半径时），外加一个独立的**力主导区域**界。
- **主定理三（显式区域）**: 动能与加权涡量障碍 → 对**所有系数**，在无外力闭球（齐次二阶 Fourier–Sobolev 半径 $\frac{97}{40}\nu$）与**七个闭受迫矩形**内成立。
- **诚实性声明**: 不宣称多项式指数/前因子最优；原方程锐阈值开放；明确区分"充分公式的最小化"与"原方程锐性"。
- **形式化验证**: 三个主定理**全部**在 Lean 4 with Mathlib 中验证通过。

---

## 局限性

- **充分 vs 必要**：本文给的是**充分条件**，作者明确声明**不主张最优性**；原方程的**锐黏性阈值仍然开放**。
- **力主导区域的界是"分开的"（separate bound）**，与多项式界不是统一形式，覆盖范围可能存在缝隙。
- **几何限制**：立方三环面 + 常数奇黏性算子（$\partial_z$ 方向）。推广到一般边界、非恒定系数需要额外工作。
- **奇黏性项的三维必要性**：二维下该项恒为零，因此本文的结论**不可直接降维使用**。
- **形式化验证的范围**：验证的是定理陈述与证明骨架，而非数值实现；不直接对工程求解器给出可操作结论。
- **"在正时间光滑"与 3D N-S 开放问题的关系**：本文**没有解决**经典 3D N-S 全球光滑性问题（因为阈值要求奇黏性足够大，即方程已被"修正"过）。宣传时不应混淆。

## 实现建议

- **实现难度**: 高（理论部分）；中（复现形式化验证，需 Lean 4 + Mathlib 环境）。
- **预期性能**: 不适用（定理无数值成本）。
- **适用场景**:
  - **奇黏性流动的稳定性判据**：为含手性（细胞、胶体、主动流体）的模拟提供"何时线性/非线性稳定"的理论支撑；
  - **对比本轮 [[2026-11-12-arXiv-2611.11138-Odd-Darcy-Law-Odd-Viscosity-Edge-Currents]]（Odd Darcy Law）**：后者是奇黏性在**多孔介质**中的输运版本，本文是**连续介质**中的正则性版本，可串联归档；
  - **与 [[2026-11-12-arXiv-2611.12045-Variational-Principles-Dissipative-Continua]]（耗散连续体变分原理）**配套阅读：后者讨论 Rayleighian 极小原理在 N-S 族中的适用性，本文提供 N-S 的正则性结果；
  - **形式化验证工作流参考**：本文是"把流体力学定理送进 Lean 4"的一个完整样例，含"有限证书如何嵌入解析论证"的说明——对做**可验证 CFD** 的团队是直接的流程模板。
- **可复用要点**:
  - **"改造移植而非重新发明"**：把快速旋转流体成熟的共振平均框架移用到奇黏性色散，是处理"新的耗散机制"的高性价比路线。
  - **带符号修正能量**：处理反对称（耗散不单调）贡献的通用技术，值得推广到其他含非对称应力项的模型（如 Cosserat 流体、奇弹性）。
  - **"充分 vs 锐性"必须在论文中显式区分**——本文的诚实表述值得作为本知识库笔记的写作规范。
  - **有限证书化**：把解析证明的关键步骤表达为可有限验证的证书，是让物理理论可机器审计的实用接口。
