## 核心贡献

> 首次让**无数据、连续时间 PINN** 在对称圆柱绕流中**自发产生涡脱落**（此前总是收敛到定常对称解）；并把窗口间压力的不连续性**归因于不可压 N-S 的 DAE 结构（指标 2）**，给出"隐藏约束" $\nabla\cdot\partial_t\mathbf{v}=0$ 的修正方案，使升力系数的跳跃**缩小 20 倍**。

1. **突破对称性陷阱**：连续时间 PINN 训练于关于尾流中心线对称的域上时，训练总是收敛到**定常对称解**。作者用**解析的、无散度初值**打破对称性，从而在 Re=100 下得到涡脱落。
2. **不使用参考数据、不做时间离散**（纯连续时间 PINN），却仍得到脱落。
3. **精度**：Strouhal 数与平均阻力系数与**同域的 OpenFOAM 解**吻合在 **0.5%** 以内。
4. **发现并解释窗口不连续性**：压力在窗口接缝处**不连续**，升力系数呈**阶梯状**。作者将其追溯到不可压 N-S 方程在空间离散后的**微分-代数方程（DAE）结构，指标为 2**。
5. **隐藏约束的发现**：
   - 显式约束：$\nabla\cdot\mathbf{v}=0$（速度无散）；
   - **隐藏约束**：$\nabla\cdot\partial_t\mathbf{v}=0$，其中 $\partial_t\mathbf{v}$ 由动量方程给出，**压力由此确定**。
6. **关键区分**：仅在接缝处**施加压力**可使解**连续但不一致**（consistent ≠ continuous）。作者的修正 = **在接缝处施加压力 + 把隐藏约束加入损失函数**。
7. **量化效果**：在 5 个脱落周期内，升力系数的跳跃**缩小 20 倍**。

## 技术方案

### 核心思想

这是一篇**方法论优先**的论文。它揭示了一个常被忽略的事实：

> **连续时间 PINN 并不是一个纯粹的"优化问题"，而是一个微分-代数方程 (DAE) 问题。**

不可压 N-S 的压力 $p$ 是**代数变量**（无自己的时间导数方程），由不可压条件确定。空间离散后，整个系统是**指标 2 的 DAE**：
- 状态变量 $\mathbf{v}$ 满足微分方程；
- 压力 $p$ 满足代数约束；
- 且 $\partial_t\mathbf{v}$ 本身也被隐式约束（由动量方程定义），从而 $\nabla\cdot\partial_t\mathbf{v}=0$ 成为**二阶约束**。

当用**滑动时间窗口**训练连续时间 PINN 时，每个窗口的初值必须**一致地**满足这两条约束，否则窗口接缝处会留下不连续。而**只匹配压力**等于只匹配了 DAE 的一个投影，不足以保证一致性。

这一诊断的普适性很高：**任何把连续时间问题切成窗口/多阶段训练的方案**（PINN、算子学习、序列建模）都面临同样的"跨阶段一致性"问题。

### 关键技术

| 技术 | 说明 |
|------|------|
| **连续时间 PINN（无时间离散）** | 不做时间离散，直接在连续时间域上训练 |
| **DAE 指标 2 分析** | 空间离散后不可压 N-S 的微分-代数结构 |
| **显式约束 $\nabla\cdot\mathbf{v}=0$** | 常规加入损失的散度约束 |
| **隐藏约束 $\nabla\cdot\partial_t\mathbf{v}=0$** | 本文的发现：二阶一致性约束 |
| **解析无散度初值** | 对称性破缺手段（而非随机扰动或噪声） |
| **滑动时间窗口训练** | 逐窗口训练，窗口间需一致传递状态 |
| **接缝处压力约束** | 施加压力使解连续（但不充分） |
| **OpenFOAM 交叉验证** | 同域、同网格对照 |

## 公式 / 理论要点

```math
% 不可压 N-S（连续时间 PINN 的物理约束）
\partial_t \mathbf{v} + (\mathbf{v}\cdot\nabla)\mathbf{v}
= -\nabla p + \nu \nabla^2\mathbf{v},
\qquad
\nabla\cdot\mathbf{v}=0
```

```math
% 显式约束（阶 1）
\nabla\cdot\mathbf{v} = 0
```

```math
% 隐藏约束（阶 2）—— 本文的发现
\nabla\cdot\partial_t\mathbf{v}=0,
\qquad
\partial_t\mathbf{v} = -(\mathbf{v}\cdot\nabla)\mathbf{v} + \nabla p - \nu\nabla^2\mathbf{v}
```

```math
% 修正后的损失 = 物理残差 + 显式散度 + 隐藏约束 + 接缝压力匹配
\mathcal{L} = \mathcal{L}_{\mathrm{N--S}}
+ \lambda_1\|\nabla\cdot\mathbf{v}\|^2
+ \lambda_2\|\nabla\cdot\partial_t\mathbf{v}\|^2
+ \mathcal{L}_{\mathrm{junction}}
```

```math
% 精度（vs 同域 OpenFOAM）
\left|\mathrm{St}_{\mathrm{PINN}} - \mathrm{St}_{\mathrm{OpenFOAM}}\right| < 0.5\%,
\qquad
\left|\overline{C_d}^{\mathrm{PINN}} - \overline{C_d}^{\mathrm{OpenFOAM}}\right| < 0.5\%
```

```math
% 接缝跳跃的改善
\frac{\Delta C_l^{\text{before}}}{\Delta C_l^{\text{after}}} \approx 20
\quad\text{（5 个脱落周期内）}
```

## 实验与结果

- **算例**: 圆柱绕流，Re = 100，域关于尾流中心线对称；连续时间 PINN，逐时间窗口训练。
- **无参考数据、无时间离散**。
- **对称性破缺**: 解析的、无散度的初始条件（非噪声注入）。
- **结果**:
  - 成功产生**涡脱落**（此前连续时间 PINN 从未做到）；
  - St 与平均 $C_d$ 与 OpenFOAM 相差 **< 0.5%**；
  - 未修正时：压力在窗口接缝**不连续**，$C_l$ 呈**阶梯**；
  - 修正后：5 个周期内 $C_l$ 跳跃**缩小 20 倍**。

## 局限性

- **窗口训练仍是必需的**：本文没有解决"单次训练覆盖整个脱落周期"的连续时间 PINN 难题——窗口切分反而是问题的来源之一（作者通过一致性约束化解，而非消除）。
- 依赖**空间离散后的 DAE 结构分析** → 换成边界元、无网格等框架时，隐藏约束的形式需重新推导。
- Re=100 单算例；**更高 Re、湍流、复杂几何**未验证。
- 压力匹配与隐藏约束的**权重 $\lambda_1,\lambda_2$** 依赖调参。
- 摘要未给出训练时间、网络规模等工程指标。

---

## 实现建议

- **实现难度**: 中。实现成本主要在**损失函数设计**与**自动微分二阶导数**（$\partial_t\mathbf{v}$ 的散度需要 $\partial_t^2$）。
- **预期性能**: 相对 OpenFOAM 误差 < 0.5%（相当高精度）；但训练成本未知。
- **适用场景**:
  - **数据稀缺的绕流问题**（实验难以测量完整流场）；
  - **窗口化训练的通用设计准则**：任何多阶段/滚动窗口求解器都应检查"跨阶段一致性约束"；
  - **DAE 视角**是分析 PINN 失败原因的强工具。
- **可复用要点**:
  - **"连续 ≠ 一致"** 是一个应写进任何分窗求解器验收清单的检查项。
  - **DAE 指标分析**是诊断"求解器在阶段边界出现跳变"的通用方法论：把偏微分方程系统化为代数约束系统，看指标数，就知道需要几阶的一致性条件。
  - **对称性破缺用解析构造而非随机噪声** —— 更可控、更可复现，且不引入训练随机性。
  - 这条思路可迁移到 **算子学习、神经 ODE、多阶段 PINN** 等一切"把连续过程切成阶段"的方案。
