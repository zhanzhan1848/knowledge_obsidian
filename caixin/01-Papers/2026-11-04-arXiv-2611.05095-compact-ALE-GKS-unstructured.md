## 核心贡献

> 在三维非结构网格上发展**紧致高阶气体动理学格式（HGKS）**，通过**低秩最小二乘二次多项式重构**替代传统高阶重构中的大量矩阵求逆，大幅降低 ALE 移动网格每步重算几何信息的开销；配合 **GENO 限制器 + 梯度压缩因子** 保证强间断下的鲁棒性，并用 **CUDA + MPI 多 GPU** 实现加速。

1. **内存缩减重构策略**：通过"微分候选多项式"把二次项系数转化为**目标单元及其邻居的平均梯度最小二乘问题**，避免显式求逆 $3\times3$ 系数矩阵。在三维非结构网格上每单元仅需存 1 个 $3\times3$ 系数矩阵 + 4 次最小二乘。
2. **线性最小二乘重构**：$a_{11}=b_1$、$a_{22}=c_2$、$a_{33}=d_3$（对角直接取线性斜率），混合项 $a_{12}=(b_2+c_1)/2$ 等由斜率线性组合给出；剩余线性系数通过最小二乘求解。
3. **GENO 非线性限制器 + 梯度压缩因子**：以 $R(x)=\chi P_2(x)+(1-\chi)\widetilde P_1(x)$ 混合高低阶重构，$\chi(\alpha)=\tanh(20\alpha)/\tanh(20)$，由 $IS_L$、$IS_H$、$IS_\tau$ 三个光滑性指标控制。
4. **重映射无关的直接 ALE 形式**：网格速度 $\boldsymbol u_g$ 直接进入动理学通量 $(\boldsymbol u-\boldsymbol u_g)\cdot\boldsymbol n$，跳过传统"拉格朗日推进 → rezoning → remapping"三步流程，并保证 GCL（几何守恒律）。
5. **两段四阶时间离散**：对 $d(|\Omega|Q)/dt=L(\Omega,Q)$ 给出两段 RK 型推进，配合界面通量的时间线性化 $F_p(t)=F_p^n+(\partial F_p^n/\partial t)(t-t_n)$。
6. **CUDA + MPI 多 GPU 实现**：cell-level 并行，4 类 kernel（重构 / 面通量 / 解更新 / 网格移动）；多 GPU 需额外同步节点坐标与网格速度。

## 技术方案

### 核心思想

气体动理学格式的核心是**用一个分布函数同时描述 Euler / Navier-Stokes / 输运过程**：

$$\frac{\partial f}{\partial t}+(\boldsymbol{u}-\boldsymbol{u}_g)\cdot\nabla f=\frac{g-f}{\tau}$$

其中 Chapman-Enskog 展开自动给出连续极限：

$$f=g \Rightarrow \text{Euler},\qquad f=g-\tau(u g_x+v g_y+w g_z+g_t)\Rightarrow\text{Navier-Stokes}$$

网格速度 $\boldsymbol u_g$ 自由：$\boldsymbol u_g=0$ 退化为 Eulerian，$\boldsymbol u_g=\boldsymbol u$ 退化为 Lagrangian。**ALE 的"直接"含义**就是让 $\boldsymbol u_g$ 连续变化而不需要重映射。

### 关键技术

| 技术 | 说明 |
|------|------|
| 紧致二次多项式重构 | $P_2(x)=Q_0+\sum_{|\boldsymbol n|=1}^{2}a_{\boldsymbol n}p_{\boldsymbol n}(x)$，基函数在目标单元上零均值（中心化处理） |
| 单元中心梯度 | Gauss 定理：$|\Omega_i|(\nabla Q)_i=\sum_{p\in N(i)}[\sum_m\omega_{p,m}\int\psi f\,d\boldsymbol\Xi]\tau/|\Gamma_p|$ |
| 最小二乘斜率 | 线性多项式 $L_x^{(1)}$ 的单元均值匹配 $\frac{1}{|\Omega_k|}\iiint_{\Omega_k}L_x^{(1)}\,dV=(Q_x)_k$ |
| GENO 限制器 | $\chi=\tanh(C\alpha)/\tanh(C)$，$C=20$；$\alpha_H,\alpha_L$ 由 $IS$ 指标构造 |
| 梯度压缩因子 | $\phi=\prod_{p,m}\phi_{p,m}$，$\phi_{p,m}=1/(1+A^2)$，$A$ 由压力/Mach 跳跃构造 |
| 两段四阶时间推进 | 需 $\partial L/\partial t$，通过两条积分通量方程解出 $F_p^n$ 与 $\partial F_p^n/\partial t$ |
| Strang 型几何一致性 | 移动体积 $|\Omega|^{n+1}Q^{n+1}$ 出现在更新式中；几何通量并入界面通量保 GCL |

## 公式

```math
% ===== ALE BGK 方程 =====
\frac{\partial f}{\partial t}+(\boldsymbol{u}-\boldsymbol{u}_g)\cdot\nabla f=\frac{g-f}{\tau}

% ===== 移动体积有限体积形式 =====
\frac{d(|\Omega_i|Q_i)}{dt}=-\sum_{p\in N(i)}F_p(t),
\qquad
F_p(t)=\int \psi f\,(\boldsymbol{u}-\boldsymbol{u}_g)\cdot\boldsymbol n\,d\boldsymbol\Xi

% ===== 两段四阶时间离散 =====
|\Omega^*|Q^*=|\Omega^n|Q^n+\tfrac{1}{2}\Delta t L^n+\tfrac{1}{8}\Delta t^2\frac{\partial L^n}{\partial t}

|\Omega^{n+1}|Q^{n+1}=|\Omega^n|Q^n+\Delta t L^n+\tfrac{1}{6}\Delta t^2\left[\frac{\partial L^n}{\partial t}+2\frac{\partial L^*}{\partial t}\right]

% ===== 界面通量时间线性化 =====
F_p(t)=F_p^n+\frac{\partial F_p^n}{\partial t}(t-t_n)

% ===== 紧致二次多项式 =====
P_2(x)=Q_0+\sum_{|\boldsymbol n|=1}^{2}a_{\boldsymbol n}p_{\boldsymbol n}(x),
\qquad
p_{\boldsymbol n}(x)=(x-x_0)^{n_1}(y-y_0)^{n_2}(z-z_0)^{n_3}-\frac{1}{|\Omega_0|}\iiint_{\Omega_0}(\cdot)\,dV

% ===== 斜率与二次项的耦合关系 =====
a_{11}=b_1,\quad a_{22}=c_2,\quad a_{33}=d_3,
\qquad
a_{12}=\frac{b_2+c_1}{2},\quad a_{13}=\frac{d_1+b_3}{2},\quad a_{23}=\frac{d_2+c_3}{2}

% ===== GENO 混合 =====
R(x)=\chi P_2(x)+(1-\chi)\widetilde P_1(x),
\qquad
\chi(\alpha)=\frac{\tanh(C\alpha)}{\tanh(C)},\ C=20

% ===== 时间步 =====
\Delta t=\mathrm{CFL}\min_i\frac{\Delta r_i}{|\boldsymbol U_i|+a_i},
\qquad \mathrm{CFL}\in[0.1,0.3]

% ===== 碰撞时间 =====
\text{无粘:}\ \tau=\epsilon\Delta t+C\left|\frac{p_l-p_r}{p_l+p_r}\right|\Delta t,\ \epsilon=0.1,\ C=5
\text{有粘:}\ \tau=\frac{\mu}{p}+C\left|\frac{p_l-p_r}{p_l+p_r}\right|\Delta t
```

## 代码片段

```cuda
// CUDA kernel 划分（论文结构）——4 类 kernel，cell-level 并行
// 1) spatial_reconstruction_kernel : 计算单元中心梯度 + 最小二乘斜率 + GENO 混合
// 2) face_flux_kernel             : 界面通量 F_p^n 与 ∂F_p^n/∂t
// 3) solution_update_kernel       : 两段 RK 更新（含移动体积 |Ω|）
// 4) mesh_movement_kernel         : 网格移动 + 几何量更新（GCL）

// 多 GPU 注意：除流变量外，还必须同步节点坐标与网格速度
// MPI: 界面 halo 交换包含 nodal coordinates + mesh velocities
__global__ void face_flux_kernel(const real* grad, const real* Q, real* F, real* dFdt, int nfaces)
{
    int p = blockIdx.x*blockDim.x + threadIdx.x;
    if (p >= nfaces) return;

    // 通量的时间线性化系数
    F[p]   = flux_now(grad, Q, p);
    dFdt[p] = flux_deriv(grad, Q, p);   // 用于 ∂L/∂t

    // ∂F_p^n/∂t 的积分形式（两条方程联立）
    // F_p^n Δt + ½ ∂F_p^n/∂t Δt² = ∫_{t_n}^{t_n+Δt} F_p dt
    // ½ F_p^n Δt + ⅛ ∂F_p^n/∂t Δt² = ∫_{t_n}^{t_n+Δt/2} F_p dt
}
```

## 实验结论

- **数据集/算例**：强间断流动、拍动翼 (pitching wing)、直升机旋翼 (helicopter rotor) 等经典 ALE 验证算例。
- **基线**：传统高阶 GKS（显式矩阵求逆重构）与低阶格式。
- **结果**：
  - 紧致重构在**三维非结构网格**上取得良好精度；
  - **GENO + 梯度压缩**在强间断下无明显振荡；
  - CUDA + MPI 多 GPU 加速显著降低大算例耗时；
  - 相比非紧致版本，**每步几何信息重算的开销大幅下降**（ALE 场景的核心痛点）。

---

## 局限性

- 论文明确指出：**分布函数层面的简单更新** $f^{*}=f^n+\frac{1}{2}\Delta t f_t^n$ 在测试中只达到**约三阶精度**（低于时间推进器标称的四阶）。
- **完全显式**（fully explicit），时间步受 CFL 严格限制；大网格/高马赫数下步长受限。
- 加速框架目前只基于 **cell-level 并行**（未做 load balancing / 网格自适应并行化）。
- GCL 处理沿用作者先前的 ALE-GKS 工作，**几何通量的详细公式未在本文中完整给出**。
- 边界重构用镜像法造 ghost cell，对复杂运动边界/多物质界面的处理未展开。

## 实现建议

- **实现难度**：⚠️ 较高。需要同时实现：BGK 动理学求解器、非结构网格二阶/三阶 FV、高阶紧致重构 + GENO、ALE 网格移动 + GCL、两段四阶时间推进、CUDA/MPI 并行。工程量大。
- **预期性能**：
  - 空间：非结构网格上四阶精度（紧致重构），强间断下靠 GENO 保稳定；
  - 时间：两段格式名义四阶，但分布函数更新拖低到约三阶；
  - 并行：cell-level 完美并行（无 stencil halo 对角依赖），MPI 通信仅在面/顶点，是较友好的并行结构。
- **适用场景**：
  - ✅ 大变形运动边界（内爆、超燃冲压发动机流场、烧蚀材料表面）
  - ✅ 强间断 + 高阶精度需求（激波-边界层相互作用）
  - ✅ 需要 GPU 加速的三维非结构网格 CFD
  - ❌ 不适合长时间定常积分（显式 + 严格 CFL）
- **落地建议**：若目标是 GPU 原生 ALE 高阶求解器，这篇是目前最完整的方法学参考；建议优先复现"紧致最小二乘重构 + GENO"部分，再叠加网格移动。
