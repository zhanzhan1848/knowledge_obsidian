## 核心贡献

> 为**混凝土介观结构**中的**三维应变局部化张量场**（36 分量）训练 U-Net 代理模型，建立**网络规模与问题复杂度的缩放律**：**只需缩放网络宽度与深度**，而若干**常规 U-Net 设计选择（如下采样后加倍通道数）对该问题是次优的**；最终网络在验证/测试集上 MAE **1.118%**，在 **H100** 上相对 FFT 求解器**加速 8.7 倍**；并提出用内部特征图的 **MMD 指标**做**无需参考计算的分布外 (OOD) 检测**。

1. **代理模型目标**：预测体素化混凝土介观结构中**完整的 36 分量应变局部化张量场**（而非标量场或单方向应力），分辨率最高至 $256^3$。
2. **真值生成**：使用 **FFT 线性弹性求解器**生成训练用的局部化张量（体素化 RVE 的快速代理）。
3. **系统性超参优化与缩放律**：给出**网络宽度与深度的缩放规则**与**精度–速度权衡分析**。
4. **反直觉的架构结论**：**仅需缩放宽度与深度**；而**下采样后通道数加倍等常规 U-Net 设计选择对该问题次优**。
5. **性能指标**：验证集与独立测试集 **MAE = 1.118%**；**H100 上推理加速约 8.7×**。
6. **泛化性**：跨骨料体积分数（aggregate volume fraction）的**迁移能力**实验，凸显**在多样形态上训练**的重要性。
7. **可靠性保障**：提出基于**内部特征图的 MMD（最大均值差异）指标**，用于**检测分布外微结构**，**无需昂贵的参考计算**。

## 技术方案

### 核心思想

**计算均质化 (computational homogenization)** 与耦合多尺度模拟需要反复求解代表体积单元 (RVE) 上的力学场——对于高分辨率三维微结构，这个成本是**主导瓶颈**。代理模型（这里是 U-Net）可以加速，但此前工作大多：
- 只预测**固定宏观载荷**下的场（无法处理载荷变化）；
- 不给**架构缩放指南**（用户不知该把网络做多大）。

本文的核心贡献是**方法论层面的**：在"预测完整 36 分量张量场"这个**高维输出**的任务上，系统地做超参优化，得出**缩放律**——**只有宽度和深度需要随问题复杂度缩放**，而**其他 U-Net 结构超参（通道增长比、跳跃连接配置等）的影响很小甚至次优**。这实际上是在说：**在这个任务上，标准 U-Net 超参的"经验配方"是从图像分割任务继承来的，并不适用于物理场预测**。

第二个要点是**OOD 检测**：代理模型在训练分布外的微结构上会给出**看起来合理但错误**的结果，这在工程应用中很危险（比明显发散更糟）。本文的方案是：不重新跑 FFT 参考解，而是在**网络内部特征图**上计算 MMD 分布差异——一次前向传播即可给出"是否在分布内"的判据。这是一个非常实用的工程设计。

### 关键技术

| 技术 | 说明 |
|------|------|
| U-Net 代理模型 | 三维体素场 → 36 分量应变局部化张量场 |
| FFT 线性弹性求解器 | 训练真值生成（RVE 上的快速求解） |
| 计算均质化 | 宏观材料响应的多尺度耦合框架 |
| 36 分量张量场预测 | 高维多通道输出（非标量场） |
| 超参优化与缩放律 | 宽度/深度的缩放规则 + 精度–速度权衡 |
| 骨料体积分数泛化 | 跨微结构参数迁移测试 |
| MMD 分布外检测 | 基于内部特征图，无需参考计算 |
| H100 GPU 推理 | 8.7× 加速的部署评估 |

## 公式 / 理论要点

```math
% RVE 上的线弹性问题（FFT 基求解）
\boldsymbol{\sigma} = \mathbb{C}:\boldsymbol{\varepsilon},
\qquad
\nabla\cdot\boldsymbol{\sigma} = 0
\quad\text{in}\ \Omega_{\text{RVE}}
```

```math
% FFT 求解：等体积力/等位移边界条件
\hat{\boldsymbol{u}}(\boldsymbol{k})
= -\frac{i\boldsymbol{k}\left[\boldsymbol{k}\cdot\hat{\boldsymbol{\varepsilon}}^{\mathrm{inc}}(\boldsymbol{k})\right]
-\hat{\boldsymbol{f}}(\boldsymbol{k})}
{|\boldsymbol{k}|^2\,\hat{C}}
```

```math
% 应变局部化张量（36 分量输出）
\mathcal{A}_{ij} = \frac{\langle \varepsilon_{ij}\,\varepsilon_{kl}\rangle_V}
{\langle \varepsilon_{kl}\rangle_V^2}
\qquad
(i,j,k,l \in \{1,2,3\}) \ \Rightarrow\ 3^4 = 81 \text{（对称化为 36）}
```

```math
% 损失函数（多分量张量场）
\mathcal{L}
= \frac{1}{N}\sum_{\boldsymbol{x}}\sum_{c=1}^{36}
w_c\,\big|A_c(\boldsymbol{x}) - A_c^{\text{true}}(\boldsymbol{x})\big|
```

```math
% 最大均值差异（OOD 检测，基于内部特征图）
\mathrm{MMD}^2(\boldsymbol{P},\boldsymbol{Q})
= \left\|\frac{1}{n}\sum_{i}\boldsymbol{\phi}(\boldsymbol{z}_i)
-\frac{1}{m}\sum_{j}\boldsymbol{\phi}(\boldsymbol{z}'_j)\right\|_{\mathcal{H}}^2
```

```math
% 缩放律（本文核心结论）
\text{Accuracy} = f\!\left(W(\text{complexity}),\,D(\text{complexity})\right),
\qquad
W\sim c_1\,C,\ \ D\sim c_2\,\log C
\quad\text{（宽度线性、深度对数增长）}
```

## 实验与结果

- **算例/数据集**: 体素化**混凝土介观结构**（骨料 + 砂浆基体），分辨率最高 $256^3$；真值由 **FFT 线性弹性求解器**生成。
- **对比基线**: FFT 参考求解器（真值 + 速度基准）；常规 U-Net 配置 vs 优化后配置。
- **主要结果**:
  - **MAE = 1.118%**（验证集与独立留出测试集上均达到）。
  - **推理加速 ~8.7×**（相对 FFT 求解器，Nvidia **H100**）。
  - **缩放律**：**仅宽度与深度需要随复杂度缩放**；**下采样后通道加倍等常规 U-Net 做法次优**。
  - **泛化**：跨骨料体积分数可迁移；**在多样形态上训练**对泛化至关重要。
  - **OOD 检测**：内部特征图的 **MMD 指标**可在**无参考计算**的前提下识别分布外微结构。

---

## 局限性

- **任务单一**：仅混凝土介观结构的**线弹性**应变局部化张量场；不涉及塑性、非线性、多相或时间演化。
- **固定宏观载荷**：真值由单一宏观载荷工况生成（论文提到"多数现有方法只预测固定宏观载荷下的场"，但本文似乎沿用了这一设定）。
- **OOD 阈值未标定**：MMD 作为检测器需要标定阈值与假阳性率，摘要未说明。
- **加速比仅 8.7×**：相对 FFT 已可观，但相比真正的"多尺度耦合加速"需求（往往需成千上万次 RVE 求解）仍有限——加速比受限于单次 RVE 求解成本占比。
- 加速是**单次推理**加速；**批量求解**时的吞吐与显存占用未报告。

## 实现建议

- **实现难度**: 中 — 标准 U-Net + FFT 弹性求解器（体素化 FFT 弹性力学有成熟实现，如 Peter voxel FEM、MATLAB `voxelFEM`、FEniCS）。
- **预期性能**: 单次 RVE 力学求解 8.7× 加速；精度 1.1%；跨骨料体积分数可迁移。
- **适用场景**:
  - **混凝土/多孔材料的计算均质化加速**（土木工程材料设计）；
  - **随机微结构的力学性质预测**（如岩石、复合材料）；
  - 作为**大规模参数扫描**（微结构形态 → 有效刚度）的工具。
- **可复用要点**:
  - **"只有宽度与深度需要缩放"** 是极其实用的结论，可直接用于自建代理模型的预算规划——不必纠缠通道增长比等次要超参，把算力集中投入宽/深。
  - **"常规 U-Net 配方来自分割任务，不适用于物理场预测"** 是一个值得记住的警告：迁移任务时必须重新做超参研究，不要沿用默认值。
  - **基于内部特征图的 MMD 做 OOD 检测**是一个**成本极低、可立即落地**的可靠性机制。建议在任何物理场代理模型部署前加入该检查——**静默的错误预测比显式崩溃危险得多**。
  - 更大范围的可迁移启示：**代理模型的评估报告应包含"架构缩放律"与"OOD 行为"两项**，而不仅是单点精度指标。这与本轮 [[2026-11-11-arXiv-2611.13989 HNO]] 中强调的**网格无关性**报告项属于同一类"应成为标准"的报告纪律。
