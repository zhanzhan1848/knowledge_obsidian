## 核心贡献

> 提出面向空化云两相测速的领域自适应深度光流框架 RAFT-CloudCav：以 RAFT 架构为基础、在 OpenFOAM 多相仿真渲染的合成图像对上微调，无需示踪粒子即可在空化条件下恢复速度场；其在 Venturi 试验段 30 与 48 L/min 工况下积分流量最接近涡轮流量计实测值（47.75 vs 48.0 ± 0.5 L/min），跨流向站位流量波动仅 2.0%（经典方法 6–7%），并首次可靠捕获近壁逆向回流 −0.71 m/s。

1. 明确指出 PIV 在空化流中的两大失效根源：示踪粒子无法穿透汽化结构（成核不均导致种子稀疏），以及变形界面两侧折射率失配产生虚假速度矢量。
2. 构建 RAFT-CloudCav：基于 Recurrent All-Pairs Field Transforms 架构，在由 OpenFOAM 多相仿真渲染的合成图像对上微调，实现无需示踪粒子的两相测速。
3. 设计无需实验真值的**三重验证方案**：与涡轮流量计比对的积分流量、依质量守恒应为零的液相速度散度、跨流向站位的流量离散度；不确定度由图像残差事后估计并保守传播。

## 技术方案

### 核心思想
空化云（cloud cavitation）内的两相流动是经典测量的禁区：传统 PIV 依赖均匀示踪播种与无畸变粒子图像，而空化恰好同时违背这两条——示踪粒子无法进入汽化核内部（种子不均），且汽液界面随时间变形导致折射率突变、成像系统引入虚假的视位移。论文的思路是绕开粒子本身，转而估计**图像运动的本质**，即用深度光流法直接求解表观运动场。为此，先用 OpenFOAM 求解真实的两相空化流动，再从渲染的图像对中合成大量训练样本，把通用 RAFT 微调到"带折射界面形变与汽相遮挡"的多相光流域，形成 RAFT-CloudCav。验证端刻意不依赖难以获得的实验真值，而是选取三个"自洽型"物理量作为判据：整体积流量（对标涡轮流量计）、液相速度散度（质量守恒要求其为零）、以及沿流向不同站位之间流量的自洽性。此外对非空化工况做空间分辨率的收敛性检验（51 μm/pixel 下边界层几乎无法解析，13 与 19 μm/pixel 相互吻合）。

### 关键技术

| 技术 | 说明 |
|------|------|
| RAFT (Recurrent All-Pairs Field Transforms) | 轻量级光流架构，无需训练即可泛化；用作骨干网络 |
| 领域自适应微调 | 在合成多相图像对上微调通用预训练 RAFT，得到 RAFT-CloudCav |
| OpenFOAM 合成数据渲染 | 由多相仿真渲染图像对，构造与目标流场匹配的监督训练集 |
| 折射/畸变鲁棒性 | 摆脱对无畸变粒子图像的依赖，容忍汽液界面变形引起的表观运动 |
| 无示踪粒子测速 | 直接由图像光流恢复速度场，避免粒子播种问题 |
| 无真值三重验证 | 积分流量、液相散度、站间流量离散度三个自洽判据 |
| 事后不确定度估计 | 由图像残差（inconsistency）估计不确定度，并做保守传播 |
| 空间分辨率收敛检验 | 用 51 / 19 / 13 μm/pixel 对照评估边界层分辨能力 |

## 摘要要点

> Time-resolved velocimetry inside cloud cavitation remains a fundamental measurement problem. Particle image velocimetry (PIV) requires uniform tracer seeding and undistorted particle images, and cavitating flow violates both, because tracers do not penetrate vapor structures and refractive index mismatch across deforming interfaces produces spurious vectors. We present a domain-adapted deep optical flow framework for two-phase velocimetry, built on a Recurrent All-Pairs Field Transforms (RAFT) architecture fine-tuned on synthetic image pairs rendered from multiphase OpenFOAM simulations (RAFT-CloudCav). It is evaluated against a pre-trained generalist RAFT model, Farnebäck and OpenPIV on 130,000 frames/s recordings of a Venturi test section at 30 and 48 L/min. As no experimental ground truth exists, validation uses three quantities that require none, namely the integrated flow rate against a turbine meter, the liquid-phase velocity divergence, which mass conservation requires to vanish, and the station-to-station spread of the flow rate. RAFT-CloudCav recovers 47.75 L/min against a metered 48.0 ± 0.5 L/min, the closest of the four methods, and its flow rate varies by 2.0% across four streamwise stations, versus 6-7% for the classical methods. It returns a coherent near-wall reverse flow of -0.71 m/s, the time-averaged signature of the upstream-propagating re-entrant jet, where OpenPIV returns none. In the non-cavitating control, at 51 μm/pixel only three grid points fall inside a 0.68 mm boundary layer and the peak wall-normal gradient is under-predicted more than thirtyfold, while 13 and 19 μm/pixel agree with each other. The mean field is recovered without tracer particles at roughly three times the per-frame uncertainty. Uncertainties are estimated a posteriori from the image residual and propagated conservatively.

## 公式 / 理论要点

```math
% 光流约束（背景方程）：图像 I_2(x+d) = I_1(x)
\mathbf{u} = \frac{d\boldsymbol{x}}{dt}, \qquad
I_2(\boldsymbol{x}+\boldsymbol{u}\,\Delta t) = I_1(\boldsymbol{x})
```

```math
% 灰度守恒方程（可展开为光流基本方程）
I_x u + I_y v + I_t = 0
```

```math
% RAFT 特征相关与多尺度查询（骨干网络核心量）
C_{ij}(\boldsymbol{x}) = \langle f(\boldsymbol{x}+\boldsymbol{d}_i),\, g(\boldsymbol{x}+\boldsymbol{d}_j)\rangle,
\qquad \boldsymbol{v}^{(k)} = \sum_{i,j} C_{ij}^{(k)}\,\boldsymbol{d}_i
```

```math
% 背景方程：不可压缩两相流中的液相连续性（质量守恒 → 散度为零）
\nabla\cdot\boldsymbol{u}_l = 0
```

```math
% 积分流量校验（对标涡轮流量计）
Q = \int_{A}\,\boldsymbol{u}_l\cdot\boldsymbol{n}\,dA, \qquad
\varepsilon_Q = \frac{\left|Q_{\mathrm{station\,i}} - Q_{\mathrm{station\,j}}\right|}{\overline{Q}}
```

```math
% 站间流量离散度与不确定度保守传播
\sigma_Q = \sqrt{\sum_k \left(\frac{\partial Q}{\partial q_k}\sigma_{q_k}\right)^2},
\qquad \text{保守取}\,\sigma_Q^{\mathrm{upper}} = \sum_k \left|\frac{\partial Q}{\partial q_k}\right|\sigma_{q_k}
```

```math
% 边界层分辨能力的空间判据
\frac{\delta_{BL}}{\Delta x} = \frac{0.68\ \mathrm{mm}}{\Delta x},
\qquad
\left|\frac{\partial u_n}{\partial n}\right|_{\max} \text{ 低估} \gg 1
```

## 实验与结果

- **算例/数据集**: Venturi 试验段的 130,000 frames/s 时间分辨记录，空化工况 30 L/min 与 48 L/min；另有非空化对照工况用于分辨率收敛检验；训练数据为 OpenFOAM 多相仿真渲染的合成图像对。
- **对比基线**: 预训练通用 RAFT、Farnebäck 经典稠密光流、OpenPIV（互相关法）——共四种方法同台比较。
- **主要结果**:
  - **积分流量**：RAFT-CloudCav 恢复 47.75 L/min，对比涡轮流量计实测 48.0 ± 0.5 L/min，为四种方法中最接近者。
  - **站间自洽性**：流量沿四个流向站位的变化仅 **2.0%**，而经典方法为 **6–7%**。
  - **近壁逆向回流**：RAFT-CloudCav 给出连贯的近壁逆向流 **−0.71 m/s**，这是上游传播的再入射射流（re-entrant jet）的时间平均特征；OpenPIV 在此处完全无结果。
  - **分辨率收敛检验（非空化对照）**：在 51 μm/pixel 下，0.68 mm 边界层内仅落入三个网格点，峰值壁法向梯度被低估超过三十倍；而 13 与 19 μm/pixel 的结果彼此吻合，说明高分辨率下结果收敛可信。
  - **不确定度**：平均场在无示踪粒子条件下被恢复，其不确定度约为逐帧不确定度的三倍；不确定度由图像残差事后估计并作保守传播。
  - **验证范式**：在缺乏实验真值的情况下，采用积分流量（对标涡轮流量计）、液相速度散度（质量守恒要求为零）、站间流量离散度三个不依赖真值的量完成校验。

## 局限性

- 依赖 OpenFOAM 合成图像对做微调，训练数据与真实成像之间的"域差距"（渲染光学特性 vs 真实相机/照明）未被完全量化，存在域迁移风险。
- 非空化对照下 51 μm/pixel 分辨率仍不足以解析 0.68 mm 边界层，说明方法本身不能弥补空间采样不足；边界层量级测量对设备要求苛刻。
- 无真实实验真值（无示踪粒子参考场），三项自洽判据只能保证内部一致性，不能保证绝对精度。
- 验证限于单一 Venturi 试验段与两种流量工况；推广到其他空化构型（如螺旋桨、阀件）需要重新验证。

## 实现建议

- **实现难度**: 中 — 需搭建 OpenFOAM 多相空化算例与图像渲染管线、复现并微调 RAFT、实现 Farnebäck/OpenPIV 基线与三重自洽验证；软件栈成熟（RAFT、OpenCV、OpenFOAM）但流程较长。
- **预期性能**: 积分流量误差最小（47.75 vs 48.0 ± 0.5 L/min），站间一致性提升约 3 倍（2.0% vs 6–7%），可恢复经典 PIV 完全丢失的近壁回流结构；平均场不确定度约为逐帧的 3 倍。
- **适用场景**: 空化/空泡流场的两相时间分辨测速、折射率突变界面（汽液、液液）流场测量、无示踪粒子条件下的速度场获取、多相流 PIV 的替代或补充方案。
- **可复用要点**:
  - **"合成渲染 + 领域自适应"**是把通用视觉模型迁移到流体测量领域的低成本范式：无需真实标注，仅需可信的相场仿真即可微调专用模型。
  - **"自洽型验证量"**是缺乏实验真值时的通用验证策略——质量守恒类不变量（散度、跨截面守恒量）可作为无真值条件下的代理真值，该思路可直接迁移到任何难以获得参考解的流动测量问题。
  - **"分辨率收敛自检"**应成为所有边界层/壁面梯度测量研究的必检项：只有当多个像素尺度结果相互吻合时，梯度量才可信。
  - **用光流替代互相关**摆脱了对示踪粒子密度、成像畸变的依赖，可作为困难多相测速中 PIV 的强备选方案。
  - **由图像残差做事后不确定度估计并保守传播**，为无真值测速提供了可审计的误差条，对工程应用的可信度至关重要。
