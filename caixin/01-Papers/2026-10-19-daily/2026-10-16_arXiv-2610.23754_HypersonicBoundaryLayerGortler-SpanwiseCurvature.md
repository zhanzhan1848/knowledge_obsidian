## 核心贡献

> 在保持流向凹曲率不变、仅增大展向凸曲率的曲壁平板上，使用 DNS+Mach 7 风洞实验系统地研究了三维壁面曲率对 Görtler 不稳定性驱动的超声速边界层过渡转换路径的影响。

1. **展向凸曲率延迟过渡**：增加展向曲率使边界层变薄，降低等效 Görtler 数，从而抑制离心放大
2. **主导破碎路径不变**：即使绕过 Görtler 涡减弱，正弦型二次不稳定性始终是通往 breakdown 的首要路径
3. **第二 Mack 模态频率上移**：边界层变薄导致声波不稳定性向更高频率迁移，但仍然是次主导
4. **实验-DNS 一致性**：低频涡动力学（通过谱 POD）证实仍是控制过渡的主要频段

## 技术方案

### 核心思想

保持流向凹曲率（诱导 Görtler 不稳定）恒定，扫描展向凸曲率 `κ_z`，从而在单一参数空间中隔离 3D 壁面曲率对离心不稳定边界层过渡的影响。DNS 提供全流场，POD 提取频段结构，Mach 7 风洞提供实验验证。

### 关键技术

| 技术 | 说明 |
|------|------|
| DNS | 高阶间断 Galerkin (HDG) 数值方法 (Peraire 课题组) |
| 实验 | Mach 7 高超声速风洞，NPLS 测量 |
| 谱 POD | 频域本征正交分解识别主导模态 |
| Görtler 数 G | `G = (U_g θ / ν_u) √(2θ/R_c)`，`R_c` 流向曲率半径 |
| 稳定性分析 | 二次不稳定性、second Mack mode 共存 |

---

## 公式

```math
G = \frac{U_\infty \theta}{\nu_\infty}\sqrt{\frac{2\theta}{R_c}}
```

边界层动量厚度 `θ` 随展向凸曲率增大而减小 → `G_eff` 减小 → Görtler 涡放大被削弱。

---

## 实验结论

- **数据集**：Mach 7 风洞实验（4 个 spanwise curvature level）+ DNS
- **基线**：流向凹曲率单独存在（无展向曲率）作为对照
- **结果**：
  - 展向凸曲率↑ → boundary layer thinning → G_eff↓ → Görtler 涡尺度↓、贴近壁面
  - secondary sinuous instability 是 principal pathway to breakdown
  - second Mack mode 频率 ↑，但仍 subdominant
  - 实验与 DNS 在 transition location 与频谱上一致

---

## 局限性

- 仅 Mach 7 单一高超声速工况，未涵盖 Ma 4-6 / 8-12
- Görtler 不稳定性依赖流向凹曲率；纯展向曲率下的离心稳定性未深入讨论
- 实验 NPLS 仅提供瞬态场，难以给出三维谱 POD 的完整验证
