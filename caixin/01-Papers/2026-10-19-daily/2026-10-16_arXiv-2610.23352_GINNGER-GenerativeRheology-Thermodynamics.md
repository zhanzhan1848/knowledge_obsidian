## 核心贡献

> 提出 GINNGER (GENERIC-Informed Neural Network for GEnerative Rheology) 框架，将构成方程发现重构为对热力学生成元的学习，并使用构象张量的本征谱作为运动学无关的状态空间，使单一模型可跨剪切/拉伸/混合流变形协议。

1. **构成方程 → 生成元学习**：从学习高维构成算符转向学习底层的热力学生成元 (GENERIC 算子)
2. **物理一致性内建**：第一/第二定律自动满足，无需先验唯象假设
3. **构象张量本征空间**：在 polymer conformation tensor 的本征谱空间做构成发现，运动学解耦
4. **跨协议泛化**：单一模型适用于 shear / extensional / mixed flow
5. **复杂度大幅降低**：仅学习生成元 → 比学习高维构成算符的参数少 ~10-100×

## 技术方案

### 核心思想

传统 rheology 建模 (Oldroyd-B, Giesekus, Phan-Thien-Tanner) 依赖先验唯象。GINNGER 通过 GENERIC 形式化 (Grmela & Öttinger 1997) 把发现任务变为：在 polymer 构象张量本征空间中学习生成元 `L` 和梯度项 `M`，使约束自动满足热力学一致性。

### 关键技术

| 技术 | 说明 |
|------|------|
| GENERIC 框架 | "General Equation for Non-Equilibrium Reversible-Irreversible Coupling" — Öttinger 2005 |
| Conformation tensor C | polymer 构象 (3×3 对称正定张量) |
| 本征谱分解 | `C = Σ λᵢ eᵢeᵢᵀ` → 用 `(λ₁, λ₂, λ₃)` 做本征空间参数化 |
| Neural ODE | 生成元参数化为神经网络，时间积分用 ODE-Net |
| 跨协议数据合并 | 单一损失函数融合 shear / extensional / mixed 流数据 |

## 公式

```math
\frac{dx}{dt} = L(x) \cdot \frac{\delta E}{\delta x} + M(x) \cdot \frac{\delta S}{\delta x}
```

`x` 状态变量 (含 C), `E` 总能量, `S` 熵, `L` 可逆算子, `M` 不可逆算子。神经网络近似 `L`, `M`；约束：

```
L = -L^T  (反解作用)
M ≥ 0  (正定，保证熵增)
```

## 实验结论

- **数据集**：合成 microstructural flow (Brownian dynamics + ESPResSo)
- **基线**：Oldroyd-B, Giesekus, Phan-Thien-Tanner
- **结果**：
  - 在本征谱空间中，GINNGER 用 ~100 参数即拟合多协议数据；Giesekus 需 1 个唯象参数 + 手动调
  - 单一模型同时描述 shear thinning + elongational thickening
  - 训练数据中加入 mixed flow → 模型泛化能力显著提升
  - 物理约束 (L 反对称, M 正定) 自动满足 → 不需要罚项

---

## 局限性

- 仅适用于温和剪切率范围（远离 coil-stretch transition 的极端拉伸）
- 本征谱分解假设 C 正定；强延伸 / 屈服时 C 退化
- ESPResSo + BD 数据 vs 实验 rheometry 数据的 domain gap
