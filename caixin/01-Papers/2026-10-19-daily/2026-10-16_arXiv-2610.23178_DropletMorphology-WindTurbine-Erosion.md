## 核心贡献

> 通过 FSI (流体-结构耦合) 模型耦合不可压缩多相流仿真与有限元 (FE) 叶片材料分析，系统量化非理想液滴形貌 (任意形状 + 朝向) 对叶片前缘侵蚀 (LEE) 载荷的影响，并提出基于投影面积的普适标度律。

1. **打破"理想球形"假设**：从传统的完美球面 + 垂直入射 → 任意形貌 + 朝向
2. **FSI 框架**：incompressible multiphase flow + FE 应力耦合
3. **投影面积标度律**：峰值冲击压力 / 关键区域 / 冲击力 均由液滴的 projection area（仅取决于初始形态 + 朝向）单一参数决定
4. **峰值力时间反比**：基于动量守恒，peak force time 与投影面积呈反比
5. **LEE 预测改进**：提升工程 LEE 模型精度

## 技术方案

### 核心思想

工业 LEE 模型假设完美球形 + 垂直入射，与实际工况（雨、雾、海浪花喷雾）不符。通过 FSI + FE 系统扫描液滴形状 + 朝向空间，提炼一个 projection-area 唯参数化标度律。

### 关键技术

| 技术 | 说明 |
|------|------|
| 多相流 CFD | VoF + Level Set, incompressible |
| FSI | 单向 / 双向耦合, OpenFOAM + ANSYS Mechanical |
| FE 叶片分析 | 各向异性复合材料层合板 |
| 投影面积 `A_π` | 沿冲击方向投影的横截面积 |
| 标度律拟合 | 量纲分析 + 多工况数据拟合 |

---

## 公式

```math
p_{\text{peak}} \propto \frac{\rho U^2 A_\pi}{A_{\text{ref}}}
```

```math
F_{\text{peak}} \propto \rho U^2 A_\pi, \quad t_{\text{peak}} \propto \frac{D_{\text{eff}}}{U}
```

```math
A_\pi = A_\pi(\text{shape}, \text{orientation})
```

投影面积 `A_π` 由初始液滴几何 (形状 + 朝向) 唯一决定，与液滴体积 / 黏度解耦。

---

## 实验结论

- **数据集**：数值 FSI 案例，5+ 液滴形状 × 5+ 朝向
- **基线**：理想球形 + 垂直入射 (经典 LEE 模型)
- **结果**：
  - 峰值冲击压力、`A_peak`、峰值力 ↔ `A_π` 正相关
  - `t_peak` ↔ `A_π` 反相关 (动量守恒)
  - 单一标度律 `f(A_π)` 拟合决定系数 R² > 0.95
  - 改进 LEE 预测 ~ 20-40% (vs 经典球形)

---

## 局限性

- 不可压缩 NS；可压缩效应（高速冲击）未涵盖
- 无相变（液滴在冲击前蒸发 / 凝固）
- 单个液滴 → 真实工况是连续液滴流（间隔、群效应）
- 实验验证有限（主要为数值）
