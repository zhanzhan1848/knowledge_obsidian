## 核心贡献

> 提出一种保留所有相关对称性的随机流体动力学 (stochastic NS) 正则化方案，证明其 UV 有限且具有连续的极限；并对 2D 和 3D 不可压缩流体的剪切粘度进行了非微扰重整化群 (RG) 计算，与 lattice DNS 互相验证。

1. **对称性保持的随机流体正则化**：正则化构造保留时空平移、转动、不可压缩、Galilean 不变性
2. **UV 有限性显式证明**：不可压缩下，理论可解析至连续，无发散
3. **统一离散与连续方法**：同一理论同时适用于 lattice DNS 与连续泛函积分
5. **剪切粘度的非微扰 RG 重整化**：首次对 stochastic NS 的剪切粘度做 RG-improved 微扰论 + 非微扰 lattice 验证
6. **2D vs 3D 反常维度差异**：通过 RG 计算揭示 2D 与 3D 在反常维度上的不同

## 技术方案

### 核心思想

经典 Navier-Stokes 在紫外发散 → 引入正则化 (lattice 或 momentum cutoff)；保留关键对称性 → UV 有限；通过 RG-improved 微扰论计算物理量（剪切粘度）的反常维度 → 与 lattice DNS 直接比较。

### 关键技术

| 技术 | 说明 |
|------|------|
| 随机 NS 方程 | `∂t u + (u·∇)u = -∇p + ν∇²u + ξ` ， ξ 是 Gaussian 随机力 |
| Symmetry-preserving regularization | 保证不可压缩约束、对称性不被破坏 |
| RG-improved 微扰论 | Wilson-Fisher 风格的重整化群改进 |
| Lattice DNS | 直接数值离散验证 |
| 反常维度 γ_ν | 描述粘度的标度律修正 |

## 公式

```math
\partial_t u_i + u_j \nabla_j u_i = -\nabla_i p + \nu \nabla^2 u_i + \xi_i
```

```math
\nabla_i u_i = 0, \quad \langle \xi_i(x,t) \xi_j(x',t')\rangle = 2 T \nu_0 \delta_{ij} \delta^4(x-x')
```

```math
\nu(\mu) = \mu^{-\gamma_\nu} \nu_0 \quad \Rightarrow \quad \nu(\mu) \propto \mu^{-\gamma_\nu}
```

`μ` 是 RG scale；`γ_ν` 是反常维度，是该论文要计算的非微扰数值。

## 实验结论

- **数据集**：lattice DNS, 2D / 3D, 多种 Re 数
- **基线**：经典 Kolmogorov K41 理论
- **结果**：
  - 2D 与 3D 的 `γ_ν` 显著不同 (2D 反常更大)
  - RG-improved 微扰论 + lattice 数据在 3D 高度一致
  - 2D 显示出强反常，与涡拟序能 (enstrophy cascade) 有关

---

## 局限性

- 仅针对不可压缩 + 随机强迫 NS，未涵盖可压缩
- 随机力的关联函数选择特定形式（白噪声）；其他色噪声未讨论
- 2D 极限的严格 UV 不完整；连续极限下仍需 lattice 截断

## 实现建议

- **实现难度**：极高（理论 + 高性能 lattice DNS）
- **预期性能**：lattice 网格 `~256^3 ~ 10^7` cell/step，Re 需 `^3` 量级资源
- **适用场景**：湍流统计理论、湍流涨落反常、湍流粘度的微观起源
