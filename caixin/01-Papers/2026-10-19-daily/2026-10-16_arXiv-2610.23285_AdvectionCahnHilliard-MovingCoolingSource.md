## 核心贡献

> 使用对流 Cahn-Hilliard-Cook 模型耦合空间时变温度场，研究运动冷却源 + 外部材料流对二元流体相分离形貌的影响，发现"热历史"编码非平衡相分离路径并可通过流速选择最终形貌。

1. **空间异质热历史**：移动 Gaussian 冷却源让相分离在不同位置"不同年龄"启动 → 各向异性形貌
2. **冷却源速度方向选择**：增加冷却源速度 → 对称结构 → spiral → 窄长条
3. **对流与热竞争**：低流速 → 流向层 + 垂直层共存；高流速 → 完全流向对齐
4. **非平衡空间记录**：移动热历史可在空间上"记录"非平衡相分离路径
5. **可控形貌工程**：通过冷却源速度 + 外部流场主动选择相分离形态

## 技术方案

### 核心思想

在传统 Cahn-Hilliard 框架下引入：(a) 移动冷却源带来的空间异质温度场 `T(x,t)`；(b) 外加材料流场 `u(x,t)`。两者共同驱动相分离路径，解析其对最终形貌的调控。

### 关键技术

| 技术 | 说明 |
|------|------|
| Advective Cahn-Hilliard-Cook | 相场 + 对流项 + 热噪声 |
| 移动 Gaussian 冷却源 | `T(x,t) = T_0 - ΔT exp(-(x-v_s t)²/2σ²)` |
| 外部材料流 | Poiseuille-like 速度场叠加 |
| 谱方法 / 有限差分 | 数值求解 PDE |
| 各向异性统计 | 形貌的方向关联函数、定向直方图 |

## 公式

```math
\frac{\partial \phi}{\partial t} + \mathbf{u} \cdot \nabla \phi = M \nabla^2 \mu + \sqrt{2 M T \xi}
```

```math
\mu = -a \phi + b \phi^3 - \kappa \nabla^2 \phi
```

```math
T(\mathbf{x}, t) = T_0 - \Delta T \exp\left(-\frac{(\mathbf{x} - \mathbf{v}_s t)^2}{2\sigma^2}\right)
```

`φ` 序参量；`μ` 化学势；`u` 外加流场；`v_s` 冷却源速度。

## 实验结论

- **数据集**：2D 数值模拟，扫描冷却源速度 / 外流速
- **基线**：均匀淬火（无移动源、无外流）
- **结果**：
  - 无流时：对称 (低速) → spiral (中速) → 窄长条 (高速)
  - 低外流速：热与对流竞争 → 流向对齐 + 垂直层共存
  - 高外流速：完全流向对齐
  - 形貌由"局部淬火年龄"+"流动剪切"二者决定

---

## 局限性

- 仅 2D 模拟；3D 形貌（如层状 vs 棒状 vs 双连续）未涉及
- 无真实热扩散-流体耦合 (advective-Cahn-Hilliard 与 Navier-Stokes 弱耦合)
- 热噪声项的统计意义在小 Re 时被放大
