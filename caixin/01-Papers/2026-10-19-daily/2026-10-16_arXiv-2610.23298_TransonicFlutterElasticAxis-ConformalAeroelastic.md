## 核心贡献

> 通过非定常 Euler + 高斯过程 (GP) surrogate + 主动学习 + 分裂共形预测 (split conformal prediction) 在 Isogai's case A 翼型及其弹性轴族上首次量化"弹性轴位置对跨声速颤振边界折叠"的影响，并以能量收支闭合解析折叠机理。

1. **弹性轴位置量化**：颤振边界折叠仅在弹性轴 > 0.4 chord 前于前缘时出现，0.39-0.33 chord 之间折叠关闭
2. **三种时域阻尼标签失败模式**：识别出三种在残差中不留痕的失败模式 (首次文献系统化)
3. **0.5° 平均入射偏差**：常用的 1° 起始网格残留 0.5° 平均入射偏差，使颤振速度升高 2.8%
4. **80 次 GP-active-learning 即可高精度**：80 仿真 + GP surrogate 标签化 64/65 独立运行；1.6% 错误率
5. **能量收支闭合**：翼弦能量预算与解算器负载 / 增长率吻合至 < 几 % 误差
6. **分裂共形预测 + 主动学习**：把 GP surrogate 转成分布无关 (distribution-free) 的稳定性判决

## 技术方案

### 核心思想

跨声速气动弹性的颤振边界复杂（多分支折叠），但直接 CFD 仿真耗资昂贵。作者用 GP + active learning 高效采样 + 共形预测给出统计性判决；同时通过能量收支解析折叠机理。

### 关键技术

| 技术 | 说明 |
|------|------|
| 非定常 Euler CFD | 无粘流, 频域时间推进 |
| Isogai A 翼型 | pitch-plunge 2DOF 经典气弹 benchmark |
| Gaussian Process surrogate | 阻尼系数回归 + 不确定性量化 |
| Batch active learning | 选择下一次最有信息的 (Mach, EA 位置) |
| Split conformal prediction | Vovk et al. (2005) 给出统计保证 |
| Chordwise energy budget | `W_KE = ∫ (p ∂h/∂t) dx` 沿翼弦 |

## 公式

```math
\mathbf{M}\ddot{\mathbf{q}} + \mathbf{C}\dot{\mathbf{q}} + \mathbf{K}\mathbf{q} = \mathbf{Q}(M, U, t)
```

```math
E_{\text{budget}} = \oint p \frac{\partial u_{\text{wall}}}{\partial t} \, dx + \frac{d}{dt}\int \frac{1}{2}\rho|\mathbf{u}|^2 dV
```

```math
\text{conformal set: } \mathcal{C}(x) = \{y : |y - \hat{f}(x)| \le \hat{q}_{1-\alpha}\}
```

`\hat{q}` 是共形分位数；覆盖保证 `(1-α)` distribution-free。

## 实验结论

- **数据集**：193 仿真 + 40 校准；扫 Mach (0.6-0.95), elastic axis (0-0.5 chord), U (颤振速度)
- **基线**：传统时间域阻尼标签法（无 conformal correction）
- **结果**：
  - 80 仿真后 GP 标签化 64/65 独立运行（98.5% 正确）
  - 共形校准后错误率 ≤ 1.6% (1-α = 90%)
  - 折叠分支仅在 EA > 0.4 chord 存在
  - 上分支：激流冲击基频变化；下分支：约化频率不变但激流相位变

---

## 局限性

- 仅 2D Isogai A (pitch-plunge)；未涵盖 3D 或耦合俯仰-弯曲
- 无粘 Euler → 粘性边界层 / 湍流反馈忽略
- GP surrogate 维度受限 (3-5)，更高维需要 deep GP / Bayesian NN
- 共形预测假设独立同分布 (i.i.d.)，但相邻 (Mach, EA) 仿真强相关
