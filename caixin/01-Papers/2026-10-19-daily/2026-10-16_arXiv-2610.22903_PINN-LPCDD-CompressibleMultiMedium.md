## 核心贡献

> 将 Sharp Interface Method (SIM) 嵌入 PINN 框架，提出 PINN-LPCDD（Learnable and Physically Consistent Domain Decomposition），通过可学习子网络自动定位界面，为强支撑（NIS）、高压力比多介质可压缩流提供 PINN 解法。

1. **每个介质一个子网络**：每个介质一个独立子网络 + 可学习界面参数，自动定位界面位置
2. **接触间断自然清晰**：物理一致分解 → 接触间断 (CD) 是 naturally sharp
3. **人工粘性 Euler**：在介质内求解带人工粘性的 Euler 方程，提高对激波的鲁棒性
4. **尺度不变性利用**：利用 Euler 方程的尺度不变性，处理高压力比 (stiffness 差异)
5. **多工况验证**：air-air / air-helium / air-water / air-R22 等基准测试

## 技术方案

### 核心思想

经典 PINN 在 multi-medium flow 中界面模糊、激波 + 接触间断难以同时刻画。PINN-LPCDD 把物理 domain decomposition (sub-domain per medium) 嵌入神经网络架构，并通过 SIM sharp interface 处理界面条件。

### 关键技术

| 技术 | 说明 |
|------|------|
| PINN | Raissi et al. 2019 物理信息神经网络 |
| Sharp Interface Method (SIM) | 在 interface 两侧显式物理约束 |
| 域分解 + 可学习 | 每个介质子网络 + 界面隐式学习 |
| 人工粘性 Euler | `(E)` + `+ ν_art ∇² u`，抑制激波附近 Gibbs 现象 |
| 尺度不变性 | Euler 方程 `(x,t,ρ,u,p) → (λx, λt, ρ, u, λ²p)` 用以归一化高压力比 |

## 公式

```math
\partial_t \mathbf{U} + \nabla \cdot \mathbf{F}(\mathbf{U}) = 0, \quad
\mathbf{U} = (\rho, \rho u, \rho E)^T
```

```math
\mathbf{U}^{\text{med}_i}_\text{net}(x,t;\theta_i) \quad \text{with sharp interface at } \Gamma(x,t;\theta_\Gamma)
```

```math
\mathbf{U}^\text{total}(x,t) = \sum_i \mathbb{1}_{\Omega_i(x,t)} \mathbf{U}^{\text{med}_i}
```

损失包含：PDE residual + 界面条件 + 初/边值。

## 实验结论

- **数据集**：1D Riemann / 2D 多介质 shock-bubble / 3D 喷射
- **基线**：传统 PINN（不分域）+ Sharp Interface WENO5
- **结果**：
  - air-air Sod 激波管：相对 L2 误差 < 1%
  - air-helium, air-water, air-R22：激波位置 + 界面位置误差 < 2 cells
  - 高压力比 (1000:1) 仍能稳定求解
  - 比 PINN-without-decomposition 精度高 ~ 5-10×

---

## 局限性

- 多介质子网络数量随介质数线性增长，≥ 4 介质时计算 / 内存压力大
- 2D/3D sharp interface 的几何复杂度（特别是拓扑变化：合并 / 分裂）未涵盖
- 人工粘性参数 `ν_art` 需调，对强激波有敏感性
