## 核心贡献

> 在 100.7 GW（2050 北海规划情景）下，使用 HARMONIE-AROME 中尺度模拟、ASPIRE 大涡模拟 (LES)、以及 Jensen/Bastankhah/TurbOPark 三种工程尾流模型进行全年风工况的尾流影响对比。

1. **工程模型系统性偏置**：三种工程尾流模型在 10–40 km 下游均预测偏高风速，bias 0.60–0.70 m/s
2. **LES = 中尺度精度**：LES 与 HARMONIE-AROME 都能准确表示局地自由流风况
4. **模型偏差随状态切换**：Bastankhah 在所有风速/稳定度下均为正偏差；Jensen / TurbOPark 在不稳定 / 中性为低估，稳定 + 8–12 m/s 下为高估
3. **年度容量因子掩盖时空差异**：年 CF 一致，但空间 / 时间 / 大气状态下的局部差异巨大
5. **区域风能评估必须纳入模型敏感性**

## 技术方案

### 核心思想

将 LES (高保真, 算力约束于代表性样本)、中尺度气象 (全天候, 物理真实但分辨率粗)、工程尾流模型 (快速, 物理简化) 三种尺度拼接，量化其在 100 GW 大规模海上风电集群情景下的偏差。

### 关键技术

| 技术 | 说明 |
|------|------|
| ASPIRE LES | 大涡模拟, 网格分辨率 O(10 m) |
| HARMONIE-AROME | 中尺度数值天气预报模型, 分辨率 ~2-3 km |
| Jensen 模型 | 经典线性尾流扩展 (Rotor disc + Gaussian decay) |
| Bastankhah Gaussian | 线性/抛物尾流 + Gaussian 衰减 |
| TurbOPark | 湍流强度修正版本 |
| 大气稳定度 | Obukhov 长度分类 |

## 公式

```math
\Delta u_j(r) = \left(1 - \sqrt{1 - \frac{C_T}{8}\left(\frac{D}{D + 2 k_w x}\right)^2}\right) \quad \text{(Jensen)}
```

```math
\frac{\Delta U}{U_\infty}(x, r) = A \exp\left(-\frac{r^2}{2\sigma_w^2(x)}\right) \quad \text{(Bastankhah Gaussian)}
```

`k_w` wake decay coefficient; `A` Bastankhah 幅值参数。

## 实验结论

- **数据集**：100.7 GW 北海 2050 风电情景，全年 12 个月逐月评估
- **基线**：LES (ASPIRE) 为参考高保真解
- **结果**：
  - 三种工程模型在 10–40 km 下游 bias +0.60–0.70 m/s
  - Bastankhah 全工况正偏差
  - Jensen / TurbOPark 在 8–12 m/s 稳定条件下翻转 (从负偏差到正偏差)
  - 年 CF 评估掩盖了空间 / 季节 / 大气态差异

---

## 局限性

- 仅 2050 北海一种情景，未涵盖其他海域 / 地形
- 工程模型参数 `k_w`, wake decay 未按机型优化
- 未考虑耦合大气稳定度 (ABL) 反馈
- LES 样本量有限；全年 LES 不可行
