# 高超声速锥体流中侧向喷注相互作用的动理学方法研究

## 核心贡献

研究**高超声速锥体绕流与侧向喷注（side jet）**的相互作用：

1. 产生**多重回流区** + 分离、再附着 + **弓形激波**
2. 明确识别为 **Edney Type IV 激波-激波干扰（shock-shock interaction）**
3. 使用 **DSMC（直接模拟蒙特卡洛）**方法证明可**良好捕获多尺度结构**
4. **关键物理判断**：虽然自由流是连续介质态，但**激波与喷注膨胀处的强梯度导致连续介质失效（continuum breakdown）** → 必须用动理学方法
5. 时序 DSMC 捕获了激波结构中的**非定常性（unsteadiness）**
6. 该非定常性**局部影响**表面参数：**传热系数**与**表面摩擦**
7. 预测出与文献一致的**低频非定常性**

## 方法

### DSMC 数值设置
- **粒子法**：直接模拟蒙特卡洛，直接在相空间离散 Boltzmann 方程
- **时序 DSMC**（time-accurate）：允许捕获激波结构的非定常性
- 捕获的物理：
  - Edney-IV 型激波-激波干扰
  - 多重分离/再附着回流区
  - 弓形激波

### 为什么必须用 DSMC
| 判据 | 结果 |
|---|---|
| 自由流马赫数/密度比 | 连续介质态（continuum-like） |
| 激波区梯度 | 强梯度 → **连续介质失效** |
| 喷注膨胀区 | 强梯度 → **连续介质失效** |
| 结论 | 即使自由流连续，局部强梯度也需动理学 |

**关键教训**：**自由流稀薄度不是唯一判据**——局部梯度才是选择 DSMC 的决定因素。

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 方法 | DSMC（粒子法，直接相空间离散） |
| 优势 | 天然处理连续介质失效；无需闭包关系 |
| 劣势 | 计算代价极高（∝ 1/ε），大算例难承受 |
| 非定常性 | ✅ 时序 DSMC 捕获激波非定常 |
| 表面量 | ✅ 传热与摩擦的局部非定常被正确反映 |

## 实验/验证结论

| 检验 | 结果 |
|---|---|
| 激波结构（Edney-IV） | ✅ DSMC 良好捕获 |
| 多回流区 / 分离再附着 | ✅ 捕获 |
| 激波非定常 | ✅ 与先前工作一致 |
| 表面传热与摩擦 | ✅ 反映局部非定常性 |
| 低频非定常频率 | ✅ 与文献值一致 |

## 局限性

- **DSMC 代价高昂**：本研究的计算资源需求极大
- 喷注几何与工况单一
- 湍流建模缺失（DSMC 本身是湍流方法）
- 论文已发表于 2023 → **非最新进展**，作为"DSMC 应用范式参考"价值更高

## 实现建议

- **实现难度**：🔴 极高（需 Monte Carlo 粒子模拟 + 自适应网格细化 + 表面碰撞模型）
- **预期性能**：远慢于 CFD；仅在高保真校验/基准中使用
- **适用场景**：
  - **高超声速含喷流干扰**（机动飞行器侧向控制喷注）
  - 稀薄气体 + 强激波的流动
  - **连续介质失效区域**的校验算例
- **落地建议**：
  - 用 DSMC 数据**校验**连续介质求解器（OpenFOAM 密度基求解器 / SU2）
  - 加速策略：GPU 上的 DSMC、混合 DSMC-CFD（自适应区域切换）
  - 与 [[2026-11-06-arXiv-2611.08395-ESE-entropy-variable-rarefied-NSF]] 对比：ESE 试图用**宏观多矩模型**替代 DSMC，是"低成本 vs 高精度"的两端
  - 与 [[2026-11-06-arXiv-2611.07738-diffusive-compressible-Euler-dcE]] 一起阅读，构成本批的"稀薄气体三连"
