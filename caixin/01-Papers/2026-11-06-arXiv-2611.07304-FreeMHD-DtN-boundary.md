# 有限磁雷诺数下有限体积 MHD 的逐分量球面 Dirichlet-to-Neumann 闭合

## 核心贡献

**有限磁雷诺数（finite $Rm$）下**的 MHD 需要外边界条件处理"导体外部的衰减场"。MHD 代码普遍使用**伪真空（pseudo-vacuum）**或**有限半径截断** —— **两者对真空外部都不物理正确**，而精确替代方案要么代价高，要么仅适用于简单几何。

本文提出：

1. **固定包围球面上的 Dirichlet-to-Neumann（DtN）闭合**
2. **逐分量**匹配矢量磁位到其**衰减外部解** → **保留全部三个衰减矢量 Laplace 族**
3. **网格化真空缓冲区**连接非球形导体与球面
4. **开源发布**为多区域有限体积求解器 **FreeMHD** 的一部分

## 验证

| 算例 | 验证内容 |
|---|---|
| **制造解（manufactured modes）** | 闭合本身正确性 |
| **球体自由衰减（sphere free decay）** | 衰减解 |
| **球体发电机（sphere dynamo）** | 阈值、增长率 |
| **扁椭球发电机（oblate dynamo）** | 阈值收敛 |
| **自由制动转子（freely braking rotor）** | 转矩 vs 精确暂态参考 |

**关键结果**：
- 网格加密下，**扁椭球发电机阈值**与**球体增长率**收敛到**独立的谱参考值**
- **转子转矩**与**精确暂态参考**吻合
- **在同一球面上，伪真空与截断给出更大的误差** —— 正如其外部模型所预测的

## 方法

### 外边界的物理需求
有限 $Rm$ 下，移动的导电流体/固体产生的磁场**延伸到开放空间** → 有限网格需要外边界条件表示**衰减外部场**。

### DtN 闭合的构造
- 在**固定包围球面**上施加 DtN 边界条件
- **逐分量**（componentwise）处理矢量磁位 $\bm{A}$
- 匹配到**衰减外部解** $\bm{A}^{\text{ext}}$，保留**三个衰减矢量 Laplace 族**（即 $\nabla,\nabla\times,\nabla\times\nabla\times$ 的组合）
- **网格化真空缓冲区**：非球形导体 → 球面之间用网格化真空区填充，实现几何灵活性

### 对比
| 边界条件 | 物理正确性 | 代价 | 几何限制 |
|---|---|---|---|
| 伪真空 | ❌ | 低 | 无 |
| 有限半径截断 | ❌ | 低 | 无 |
| **DtN（本文）** | ✅ | 中 | 需包围球 + 缓冲网格 |
| 精确替代 | ✅ | 高 | 仅简单几何 |

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 离散化 | 有限体积，多区域 |
| 边界处理 | DtN（球面）+ 网格化真空缓冲 |
| 求解器 | FreeMHD（开源） |
| 收敛性 | ✅ 网格加密收敛到独立谱参考 |
| 几何灵活性 | ✅ 通过真空缓冲支持非球形导体 |
| 代价 | 中等（高于伪真空/截断，远低于精确解） |

## 局限性

- 仍需**包围球**（几何上必须能被球覆盖）→ 对细长/复杂几何成本上升
- **真空缓冲区网格**引入额外离散误差与网格质量要求
- 未讨论与**近场（非局部）**求解器的耦合代价对比
- 物理约束：假设外部为**真空**

## 实现建议

- **实现难度**：🟡 中高。可直接使用 **FreeMHD**（开源），或在自己的 MHD 代码中实现 DtN 球面边界
- **预期性能**：✅ 误差显著低于伪真空/截断；网格加密收敛性好
- **适用场景**：
  - **发电机动力学**（行星发电机、旋转发电机）
  - **液态金属 MHD**（核反应堆冷却、冶金连铸、铝电解）
  - **磁场重联**模拟（需正确外部场）
  - 任何**有限 $Rm$ 下需要外边界**的 MHD 问题
- **落地建议**：
  - 优先评估 **FreeMHD** 本身（研究用代码，需确认许可证与维护状态）
  - 与 **OpenFOAM 的 `electroMagFoam`** 对比：OpenFOAM 无原生 DtN，需要自行实现
  - 与 SU2 的 MHD 能力对比（SU2 在知识库关注列表中）
  - 验证套路：先做**球体自由衰减**（解析解可对照）→ 再做发电机
