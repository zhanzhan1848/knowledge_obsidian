## 核心贡献

> 用 **DSMC 粒子动力学**研究强分离高超声速压缩-膨胀斜坡的非定常性，**首次把 SPOD 应用于 DSMC 流场并与 DMD 对比**；发现单回流区的稳定性对**壁温与来流速度**的敏感性**高于对物理斜坡角的敏感性**，且 triple-deck 理论给出的**标度角**虽能预测大趋势但不足以刻画流动复杂性；通过 POD/DMD/SPOD 提取出三类非定常机制。

1. **DSMC 的非定常应用**：用时间精确的 DSMC（而非稳态平均）捕捉强激波-剪切层-回流区相互作用；粒子数需求远高于稳态算例。
2. **标度角 (scaled angle) 不足以完全刻画**：triple-deck 理论给出标度角 $\alpha=\alpha^*\dfrac{Re_L^{1/4}}{0.332^{1/2}C^{1/4}(M_\infty^2-1)^{1/4}}$，能预测"次级回流区出现"等一般趋势，但**流动太复杂，无法仅用标度角刻画**。
3. **关键排序发现**：回流区单回流区的稳定性（以次级分离区出现为判据）对 **壁温 $T_w$** 和 **来流速度 $U_\infty$** 的敏感性**高于**对**物理斜坡角 $\alpha^*$ 的敏感性。
4. **SPOD vs DMD 首次对比**：两者给出**相似的频率成分与模态形状**；对平稳流动 SPOD 与 DMD/resolvent 给出相同模态，而 SPOD 计算量更低，适合数据量有限场景。
5. **三类非定常机制识别**：
   - **再附激波的振荡**（reattachment shock oscillation）
   - **剪切层的 Kelvin–Helmholtz 型不稳定**
   - **分离泡的 c 形模态**（c-shaped mode of the separation bubble）
6. **方法论新意**：SPOD 首次应用于 DSMC 生成流场。

## 技术方案

### 核心思想

**问题**：压缩斜坡（Edney-IV 流动）在**大分离泡**时会出现次级回流区导致非定常。但：(a) 稳态 NS 求解器难以捕捉强梯度区的非定常；(b) 传统上靠"探针"只能看到局部扰动；(c) 需要**空间全局相干结构**来理解非定常。

**策略**：DSMC（无连续介质假设、时间精确、天然捕捉激波）生成流场 + **模态分解**（SPOD / DMD）提取**时空相干结构**。

### 关键技术

| 技术 | 说明 |
|------|------|
| SUGAR-3D 求解器 | Scalable Unstructured Gas-dynamic Adaptive mesh Refinement |
| DSMC 参数 | 约 $200\times10^6$ 粒子；采样格 ≥150 粒子/格；碰撞格 20 粒子/格/步（典型稳态 DSMC 仅需 ~4）|
| 网格/时间 | 采样格 0.2 mm；时间步 $5.0\times10^{-8}$ s（所有构型统一）|

## 公式

```math
% ===== triple-deck 标度角 =====
\alpha=\alpha^*\frac{Re_L^{\frac{1}{4}}}{0.332^{\frac{1}{2}}C^{\frac{1}{4}}(M_\infty^2-1)^{\frac{1}{4}}},
\qquad C=\frac{\mu_wT_\infty}{\mu_\infty T_w},
\qquad Re_L=\frac{\rho_\infty U_\infty L}{\mu_\infty}

% ===== DSMC 基本量 =====
\text{FNUM}=\frac{\text{真实粒子数}}{\text{模拟粒子数}}\gg 1
L_{Kn}=\frac{\text{局部平均自由程}}{\text{碰撞格尺寸}}\sim 1
\qquad \text{每碰撞格}\ge 4\ \text{模拟粒子}

% ===== SPOD 协方差谱分解（形式化）=====
S_{ff}(\omega)=\sum_j \overline{\hat\phi_j(f,\omega)\hat\phi_j(f,\omega)^*},
\qquad
L S_{ff}(\omega)=\omega S_{ff}(\omega)L^T
```

## 代码片段

```python
import numpy as np
from scipy.linalg import svd

def spod(snapshots, n_modes=20, n_blocks=8):
    """SPOD: 分块 Welch 平均 + 特征值分解 (TowNSpan/MODAL 方法)。
    snapshots: (N_snapshots, N_dof)
    """
    # 1) 分块（overlap 50%），每块内做 FFT
    N = snapshots.shape[0]
    seg = N // (n_blocks * 2 - 1)
    blocks = []
    for b in range(n_blocks):
        s = snapshots[b*seg : b*seg + 2*seg]
        blocks.append(np.fft.fft(s, axis=0)[:seg])
    blocks = np.concatenate(blocks, axis=0)

    # 2) 谱密度矩阵
    omega = 2*np.pi*np.fft.fftfreq(seg)
    S = np.zeros((snapshots.shape[1], snapshots.shape[1], seg), dtype=complex)
    for j in range(seg):
        C = blocks[:, j, :].conj().T @ blocks[:, j, :]
        S[:, :, j] = C / blocks.shape[0]

    # 3) 特征值分解 -> 模态与频率
    phi = np.zeros((snapshots.shape[1], n_modes, seg), dtype=complex)
    for j in range(seg):
        w, v = np.linalg.eig(S[:, :, j])
        idx = np.argsort(-w.real)[:n_modes]
        phi[:, :, j] = v[:, idx]
    return omega, phi

def dmd(X, r=None):
    """标准 DMD: 快照矩阵 X (n_snap x n_dof)"""
    U, s, Vh = np.linalg.svd(X.T, full_matrices=False)
    r = r or (s.shape[0])
    U, V = U[:, :r], Vh[:r, :].conj().T
    A = U.conj().T @ X @ V
    w, W = np.linalg.eig(A)
    modes = U @ W                       # 空间模态
    # 频率: omega_j = log(w_j) / (2*pi*dt)
    omega = np.log(w.astype(complex)) / (2*np.pi)
    return omega, modes

# SPOD vs DMD 一致性检验（论文核心对比）
# 平稳流中: SPOD 模态 ≈ DMD 模态 ≈ resolvent 模态
```

## 实验结论

- **数据集/算例**：同一几何下 **4 种来流条件**（不同 $U_\infty$、$T_\infty$、$T_w$），压缩-膨胀斜坡；DSMC 时间精确。
- **基线**：triple-deck 标度角预测 + 文献中类似回流构型。
- **结果**：
  - 标度角能预测"次级回流区出现"等**一般趋势**；
  - 但**稳定性对壁温和来流速度比对斜坡角更敏感**；
  - SPOD 与 DMD 给出**相似的频率成分与模态形状**；
  - 三类非定常机制：**再附激波振荡**、**剪切层 K-H 型不稳定**、**分离泡 c 形模态**；
  - 首次将 SPOD 应用于 DSMC 流场。

## 局限性

- **仅二维**：明确说明只做二维（虽然文献指出大分离泡可能在三维失稳）；未验证这些二维次级回流区是否在三维中发展为三维效应。
- **标度角不充分**：论文的核心"否定性"结论 —— 单一参数（标度角）无法刻画流动复杂性。
- **DSMC 成本极高**：$200\times10^6$ 粒子、每格 ≥150 粒子、20 粒子/碰撞格/步，远超常规 DSMC。
- DSMC 流场的**随机性**（事件概率、Maxwellian 采样、acceptance-rejection）要求大量快照才能做可靠的模态分解；快照数与模态质量的关系未系统讨论。
- 物性固定（氮气 + VHS），未做化学非平衡对比。
- 论文是 *Phys. Fluids* 已发表版本，arXiv 版为 accepted manuscript。

## 实现建议

- **实现难度**：⚠️ DSMC 部分极高（需 SUGAR-3D 等专业代码或自研）；SPOD/DMD 部分低（有成熟库，如 `pod`/`dmd`）。
- **预期性能**：
  - DSMC：$200\times10^6$ 粒子、$5\times10^{-8}$ s 步长 —— 需要大规模并行（HPC 级）；
  - SPOD：$O(M\log M)$ 分块 FFT，比 DMD 更适合大数据量；
  - DMD：$O(N_{\rm snap}^3)$ SVD —— 快照数受限。
- **适用场景**：
  - ✅ 高超声速强分离流动的非定常机理研究
  - ✅ DSMC 流场的**去噪**与相干结构提取（方法论可迁移）
  - ✅ 用数据驱动方法补充物理诊断（本文明确指出这一范式）
  - ❌ 工程级设计（DSMC 成本不可接受）
- **落地建议**：**最可迁移的成果是"SPOD/DMD 用于随机粒子流场"这一方法论**。若做的是 DSMC 或 SPH 等带随机性的求解器，SPOD 的分块 Welch 平均天然适合处理非平稳随机信号，且计算量低于 DMD。建议在自有 DSMC/SPH 代码中实现 SPOD 后处理流程。
