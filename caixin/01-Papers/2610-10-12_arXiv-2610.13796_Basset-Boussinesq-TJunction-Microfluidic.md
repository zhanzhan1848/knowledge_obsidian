## 核心贡献

> 在方形微流控 T 型结的涡流中首次系统考虑 Basset-Boussinesq 历史力对惯性颗粒动力学的影响

1. Re=500 → steady vortex pair；Re=570 → Hopf 分岔产生 helical 呼吸
2. 历史力放大颗粒螺旋轨道径向宽度，并延长轴向，缩小 trapping basin
3. 通过 SPOD 量化 Re=570 时涡与颗粒相互作用的相位依赖性

---

## 技术方案

### 核心思想

单相数值模拟未受扰动的基底流，结合颗粒力平衡方程（含 Basset-Boussinesq 历史项）积分。关注的参数空间：(Re, St, ρ/ρ_f)。

### 关键技术

| 技术 | 说明 |
|------|------|
| Navier-Stokes 单相 DNS | 基底流 Re=500, 570 |
| Basset-Boussinesq 力 | 历史项 F_B = √(9ρ_f μ/(πρ r²)) ∫₀ᵗ (du_f/dτ - du_p/dτ)/√(t-τ) dτ |
| SPOD | 谱 POD 分析涡呼吸相位 |
| 颗粒力概率密度函数 | trapping probability |

---

## 公式

```math
m_p du_p/dt = F_drag + F_pressure + F_gravity + F_Basset-Boussinesq + ...
     F_B ~ √(9 ρ_f μ / (π ρ r²)) · ∂/∂t ∫₀ᵗ Δu(τ)/√(t-τ) dτ
Re=570: ψ(x,y,t) = ψ_0(x,y) + ε [a(t) ψ_a(x,y) + b(t) ψ_b(x,y)]
```

## 实验结论

- **数据集**: 微流控 T 型结数值模拟，参数扫描 (Re ∈ {500, 570}, St, ρ)
- **基线**: 仅 Stokes drag 的传统颗粒模型
- **结果**: 
  - 历史力削弱 vortex core trapping
  - basin of attraction 减少
  - Re=570 时颗粒注入相位强烈影响轨迹

---

## 局限性

- 仅 2 Re 数 (500, 570)，未覆盖转捩完整范围
- 单分散球形颗粒假设
- 仅方形 T 型结，T 型几何变化的影响未涉及
