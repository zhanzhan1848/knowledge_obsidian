## 核心贡献

> 实验级膜蒸馏（DCMD）模块的入口效应不仅强度、连**方向**都随 Re_in 变化——Re 数低时增强温度极化（TP），Re 数高时反而削弱 TP。

1. **3D CFD 系统研究**：在 Re_in = 10–1000 范围内对 DCMD 模块全 3D 仿真，聚焦侧腔长度与主通道高度。
2. **反旋转流向涡识别**：主通道入口处存在一对反向旋转的流向涡（streamwise counter-rotating vortices），所有几何下均出现。
3. **Re 数-几何耦合效应**:
   - 低 Re：涡在中通道前衰灭 → 入口 TP **增强**
   - 高 Re：涡持续到下游 → 入口 TP **削弱**
4. **设计指南**：侧腔加长抑制入口二次流，主通道加厚强化 TP。

## 技术方案

### 核心思想

膜蒸馏实验中常用经验传热关联式来提取膜性能。但实验室级模块的入口几何（侧腔、主通道高度）会在 Re 数变化时**方向性翻转** TP 偏差，使经验关联式无法用单一修正系数描述。

### 关键技术

| 技术 | 说明 |
|------|------|
| 3D CFD 全模块仿真 | 含侧腔 + 主通道 + 多孔膜壁 |
| 参数扫描 | Re_in ∈ [10, 1000]；侧腔长度、主通道高度 |
| 二次流 KE 分析 | streamwise vortex 强度量化 |
| 温度极化 (TP) | TP = (T_bulk - T_membrane)/(T_bulk - T_feed) |
| 直接接触膜蒸馏 (DCMD) | 热水侧与冷水侧直接接触膜壁 |

### 关键发现

```
入口二次流强度 vs Re_in
  ┌──────────────────────────────────────┐
  │ 低 Re (10):  涡快速衰灭  → 强 TP     │
  │ 中 Re (100): 涡贯穿主通道 → 中等 TP   │
  │ 高 Re (1000): 涡向下游输运 → 弱 TP   │
  └──────────────────────────────────────┘
```

## 公式

温度极化系数：

```math
\tau = \frac{T_{b,m} - T_{m}}{T_{b,m} - T_{f}}
```

其中 T_{b,m} 为膜侧主体温度，T_m 为膜面温度，T_f 为进料温度。

入口流向涡稳定性参数（Dean-like）：

```math
De = \frac{\rho U D_h}{\mu} \sqrt{\frac{D_h}{2R_c}}
```

## 实验结论

- **数据集**: 3D 仿真参数空间 — 5 个 Re_in × 多几何组合
- **基线**: 直通道无侧腔的 TP 分布
- **结果**:
  - 所有几何下均出现反向旋转流向涡对（典型 Dean 涡）
  - 侧腔长度增加 → 入口 KE 减弱 → TP **增强**
  - 主通道高度增加 → 主流速度下降 → 边界层增厚 → TP **增强**
  - Re 数翻转：低 Re 下 TP 偏差**正向**，高 Re 下 TP 偏差**反向**

---

## 局限性

- 仅 DCMD 配置，未覆盖空气隙膜蒸馏（AGMD）、气扫膜蒸馏（SGMD）
- 膜视为多孔介质界面，未显式模拟蒸汽侧传质阻力
- 入口涡的形成机制（Dean 涡 vs 入口涡）未深度解析
- 仅稳态分析，瞬态入口不稳定性未研究
