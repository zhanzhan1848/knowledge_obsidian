## 核心贡献

> 极端超分辨率（×32、×64）下，仅凭**单一**高分辨率湍流实现即可训练 WDSR 网络，准确重建未见过的同质湍流场。

1. **单实现学习范式**：突破传统 SR 模型需要大量训练样本的假设，证明单实现 patch 重叠训练足以捕捉跨尺度结构统计。
2. **极端放大比**：在 ×32 和 ×64 这种**严重欠分辨**场景下重建相干涡结构和精细尺度特征，优于传统插值。
3. **空间冗余 vs. 样本量消融**：与使用 1 / 25 / 50 / 100 个完整快照训练的 WDSR 对比，证明局部学习（patch-based）的优势远超增加样本量。

## 技术方案

### 核心思想

均匀各向同性湍流（HIT）在空间上具有**跨区域重复的多尺度结构**。这意味着单一高分辨率场内的 patch 已包含足够的统计信息用于 SR 学习。通过 WDSR（宽激活深度超分网络）+ Hann 窗重叠相加（OLA）实现 patch 级预测的无缝拼合。

### 关键技术

| 技术 | 说明 |
|------|------|
| WDSR (Wide-activation Deep SR) | EDSR 改进型，使用宽激活特征提取 + 全局残差 |
| Patch-based training | 从单张 HR 场中抽取大量重叠 patch 作为训练集 |
| Hann-window OLA | 加窗重叠相加重建，平滑 patch 边界伪影 |
| 2D HIT 数据集 | 二维均匀各向同性湍流场 |
| 极端 SR 因子 | ×32 和 ×64，远超常规 ×2/×4 |

### 网络结构

```
输入 LR (低分 patch)
   ↓
Conv (宽激活通道数 ×6)
   ↓
残差块堆叠 (大感受野)
   ↓
亚像素卷积上采样 ×32 / ×64
   ↓
输出 HR patch
   ↓
Hann-窗加权 OLA 拼接 → 全场 HR 重建
```

## 公式

能量谱恢复指标（高频段）：

```math
E(k) = \int \hat{u}(\mathbf{k}) \hat{u}^{*}(\mathbf{k}) \, d\Omega(\mathbf{k})
```

SR 重建误差（PSNR / SSIM）：

```math
\text{PSNR} = 10 \log_{10}\left(\frac{\text{MAX}^2}{\text{MSE}}\right)
```

## 实验结论

- **数据集**: 2D 均匀各向同性湍流（forced DNS 单场）
- **基线**: 双线性 / 双三次插值；WDSR-1, WDSR-25, WDSR-50, WDSR-100（全快照训练）
- **结果**:
  - 单实现 patch 训练在 ×32 / ×64 下视觉上恢复相干涡结构
  - 高波数能量谱恢复优于传统插值
  - 与 WDSR-100 相比，单实现方法在数据效率上**显著占优**（100× 数据缩减）

---

## 局限性

- 仅在 2D HIT 验证，**未推广到 3D 真实湍流**
- 仅单一湍流统计（均匀各向同性），复杂边界层、剪切流、APG 流未验证
- 物理守恒律（散度自由、能量守恒）未显式约束
- 网络外推性（未见 Re 数 / 强制尺度）未讨论

## 实现建议

- **实现难度**: 中（PyTorch + 标准 SR 框架 + Hann 窗 OLA）
- **预期性能**: ×32 单实现训练 ≈ ×4 多快照训练的视觉保真度
- **适用场景**:
  - 实验测量湍流场（PIV）的稀疏 HR 标定
  - LES / RANS 欠分辨输出的后处理
  - 单一 DNS 实现的数据高效重建

🥢 **推荐实现**：✅ 适合作为湍流 SR 工具链的低数据版本，与传统 SR 形成互补。实验流体研究者可直接使用。
