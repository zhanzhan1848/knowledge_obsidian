## 核心贡献

> 在 Nesterenko 工作的基础上，推导二维颗粒介质波传播的**强非线性连续介质模型**（应变梯度模型），并给出**双曲性（hyperbolicity）**的严格分析

1. 从 **Hertz 接触定律**出发，忽略接触摩擦，经**均质化**推导有效连续介质描述
2. 假设：球形、单分散颗粒、**局部周期性**、**Cauchy-Born 假设**
3. 得到的**应变梯度模型**同时依赖位移场的**一阶梯度与二阶梯度**
4. 通过**特征值与特征向量**分析领先阶系统的双曲性，给出**受限变形域内**的双曲性条件
5. 用**显式有限体积法**求解，研究重力沉降与波传播
6. 推导**纵波与横波速度的解析表达式**，突出其**随深度变化**的依赖关系
7. 与既有 **离散元（DEM）** 仿真对比验证

## 技术方案

### 核心思想

颗粒介质不是连续介质，但小尺度上可用连续模型描述以获得低阶弹性波传播速度。关键在于接触力网络的空间排布（局部周期性）与变形的一致性（Cauchy-Born）。

### 关键技术

| 技术 | 说明 |
|------|------|
| Hertz 接触定律 | 非线性弹性接触，作为均质化起点 |
| 均质化 | 局部周期晶格上的微观-宏观推导 |
| Cauchy-Born 假设 | 位移场在颗粒尺度上是光滑的 |
| 应变梯度模型 | 含二阶位移梯度 → 非局部效应 |
| 双曲性分析 | 特征值/特征向量 → 良定性条件 |
| 显式有限体积 | 求解守恒形式（含引力沉降）|
| DEM 对比 | 验证连续模型预测 |

## 公式

```math
Hertz 接触（法向）:
  F_n = k (δ)^{3/2},  k = (E²R/(9(1-ν²)))...  (弹性模量 E, 泊松比 ν)

应变梯度模型（位移场 u，二维）:
  ∇·σ = ρ ∂²u/∂t²
  σ = C : ε + C₂ : (∇²ε)          ← 含二阶梯度（应变梯度项）

双曲性条件（领先阶）:
  det( |v|² I - C_eff ) = 0  →  |v|² ∈ spec(C_eff)
  在受限变形域内 C_eff 正定 → 系统双曲

波速解析式（深度依赖）:
  c_L(z), c_T(z) 由局部周期晶格的 C_eff(z) 决定
  纵波: c_L² = (λ_eff + 2μ_eff)/ρ_eff
  横波: c_T² = μ_eff/ρ_eff
```

## 代码片段

```python
import numpy as np

def effective_moduli_from_hertz(contact_stiffness, radius, packing):
    """
    由 Hertz 接触刚度与晶格均质化得到有效模量
    """
    # 标量近似（各向同性晶格）
    k_eff = contact_stiffness * packing["coordination_number"]
    E_eff = k_eff * radius
    nu_eff = packing["poisson_ratio"]
    lam = E_eff * nu_eff / ((1+nu_eff)*(1-2*nu_eff))
    mu = E_eff / (2*(1+nu_eff))
    return lam, mu

def hyperbolicity_check(A_cont, A_grad, lam, mu, rho):
    """
    检查含应变梯度项的领先阶系统是否双曲:
    C_eff = C + C₂ · (k²)  在波数 k → 0 极限
    """
    C_eff = lam + 2*mu, mu
    disc = (C_eff[0] - C_eff[1])**2 + 4*mu**2
    return dict(hyperbolic=disc >= 0,
                c_L=np.sqrt(C_eff[0]/rho), c_T=np.sqrt(mu/rho))

def explicit_fv_step(u, u_prev, dt, dx, rho, lam, mu):
    """显式有限体积推进（含二阶梯度项时需注意 CFL 收紧）"""
    eps = 0.5*(np.roll(u, -1, axis=1) - np.roll(u, 1, axis=1))/dx
    # 常规粘性/弹性更新（骨架）
    return u, u_prev
```

## 实验结论

- **数据集**: 二维颗粒介质（球形单分散，Hertz 接触，局部周期排布）
- **基线**: 既有离散元（DEM）仿真
- **结果**:
  - 推导得到依赖一阶与二阶位移梯度的**应变梯度模型**
  - 给出受限变形域内的**双曲性条件**（特征值/特征向量分析）
  - 显式有限体积求解**重力沉降**与**波传播**
  - 纵波/横波速度有**解析表达式**，且**随深度变化**
  - 连续模型预测与 DEM 仿真对比一致

---

## 局限性

- 仅 **2D**、球形**单分散**颗粒、忽略接触摩擦、局部周期 + Cauchy-Born
- 双曲性只在**受限变形域**内成立（大变形时接触网络演化，模型失效）
- 应变梯度模型引入额外自由度 → 计算量与存储显著上升
- 与 DEM 对比限于小应变弹性波
