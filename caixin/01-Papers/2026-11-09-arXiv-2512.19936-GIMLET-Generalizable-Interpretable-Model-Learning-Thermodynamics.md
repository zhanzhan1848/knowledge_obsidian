## 核心贡献

> 提出 GIMLET 框架，在非平衡热力学变分原理下把流体方程中未知的本构闭合项直接识别为神经网络，通过参数化自由能与耗散泛函并用自动微分求泛函导数，实现**热力学一致性由构造保证**，且识别出的模型可跨数据集迁移并具物理解释性。

1. **变分原理 + 神经网络** 的模型发现框架：自由能与耗散泛函用神经网络参数化，闭合项由泛函导数经自动微分得到
2. **热力学一致性由设计保证**：总自由能单调衰减、熵产生非负，无需事后惩罚项
3. **不依赖预设函数库**：与稀疏回归（SIND-R 类）不同，避免人为选择候选基函数的偏差
4. **可迁移性**：从一组数据识别出的泛函可迁移到受同一底层方程支配的另一组数据集
5. **物理可解释性**：推断出的自由能与耗散函数直接给出学习到的动力学
6. 在 **黏性 Burgers、Kuramoto–Sivashinsky、不可压 Navier–Stokes（牛顿与非牛顿流体）** 上验证

## 技术方案

### 核心思想

传统"闭合项识别"方法的困境是：残差型方法需要预先选定一组候选本构函数（稀疏回归），而惩罚型方法（把物理约束写进损失）只提供软约束，两者都不保证所识别模型的热力学一致性。

GIMLET 的做法是**换一个出发点**：不从方程残差出发，而是从**非平衡热力学的变分原理**出发。流体动力学方程可以被写成"自由能泛函的梯度流 + 耗散泛函的梯度流"的形式：

$$\partial_t \rho + \nabla\cdot(\rho\mathbf{u}) = \nabla\cdot\left(\frac{\partial \mathcal{D}}{\partial (\nabla \rho)}\right)$$

其中未知本构项（如粘性张量、闭合应力）**不是自由参数，而是自由能泛函与耗散泛函对状态变量的泛函导数**。由于自由能泛函对状态变量是二次的，物理上要求它为**凸函数**；由于耗散泛函对耗散通量是二次的，物理上要求**熵产生非负**。这两个约束正好对应物理上合理的结构。

具体实现上，把自由能泛函 $\mathcal{F}[\rho]$ 与耗散泛函 $\mathcal{D}[\rho,\nabla\rho]$ 用神经网络参数化（输入是状态变量，输出是泛函的值或其可学习系数），然后用**自动微分**求出 $\partial\mathcal{D}/\partial(\nabla\rho)$ 等闭合项，送入求解器。由于整个构造建立在变分原理上，热力学一致性（自由能单调下降、熵产生非负）是**结构性保证**，而非拟合精度的副产品。

方法还特别强调：发现的对象**只是本构关系**——时间导数、对流输运项、压力梯度项在方程中是已知的、被显式给定的。这意味着需要提供实测的速度场（或标量场）作为观测。

### 关键技术

| 技术 | 说明 |
|------|------|
| **非平衡热力学变分原理** | 方程写成 $\partial_t\rho = -\nabla\cdot(\partial\mathcal{D}/\partial(\nabla\rho))$ 的梯度流结构 |
| **神经网络参数化的泛函** | $\mathcal{F}$、$\mathcal{D}$ 用网络表示，泛函导数经自动微分获得 |
| **凸性 / 非负耗散的结构保证** | 自由能凸性、耗散泛函正定 → 自由能单调衰减、熵产非负 |
| **闭合项 = 泛函导数** | 不预设候选函数库，避免稀疏回归的函数选择偏差 |
| **数据驱动的闭合项识别** | 只需速度场/标量场观测，时间导数等已知项显式给定 |
| **跨数据集迁移** | 识别出的泛函是方程级对象，可迁移到同方程的不同数据集 |

## 摘要要点

> We develop a data-driven framework for discovering constitutive relations in models of fluid flow and scalar transport. Under the assumption that velocity and/or scalar fields are measured, our approach infers unknown closure terms in the governing equations as neural networks. The target to be discovered is the constitutive relations only, while the temporal derivative, convective transport terms, and pressure-gradient term in the governing equations are prescribed. The formulation is rooted in a variational principle from non-equilibrium thermodynamics, where the dynamics is defined by a free-energy functional and a dissipation functional. The unknown constitutive terms arise as functional derivatives of these functionals with respect to the state variables. To enable a flexible and structured model discovery, the free-energy and dissipation functionals are parameterized using neural networks, while their functional derivatives are obtained via automatic differentiation. This construction enforces thermodynamic consistency by design, guaranteeing monotonic decay of the total free energy and non-negative entropy production. The resulting method, termed GIMLET (Generalizable and Interpretable Model Learning through Embedded Thermodynamics), avoids reliance on a predefined library of candidate functions, unlike sparse regression or symbolic identification approaches. The learned models are generalizable in that functionals identified from one dataset can be transferred to distinct datasets governed by the same underlying equations. Moreover, the inferred free-energy and dissipation functions provide direct physical interpretability of the learned dynamics. The framework is demonstrated on several benchmark systems, including the viscous Burgers equation, the Kuramoto--Sivashinsky equation, and the incompressible Navier--Stokes equations for both Newtonian and non-Newtonian fluids.

## 公式 / 理论要点

```math
% 变分原理形式（封闭模型的基本方程）
\partial_t \rho + \nabla\cdot(\rho\mathbf{u}) = \nabla\cdot\left(\frac{\delta \mathcal{D}}{\delta(\nabla\rho)}\right)

% 未知闭合项 = 泛函导数
\boldsymbol{\tau}^{cl} = \frac{\delta \mathcal{D}}{\delta(\nabla \mathbf{u})}, \qquad
\boldsymbol{q}^{cl} = -\frac{\delta \mathcal{D}}{\delta(\nabla T)}

% 自由能与耗散泛函的网络参数化（示意）
\mathcal{F}[\rho] = \int_\Omega f_{\theta}(\rho)\;dV,
\qquad
\mathcal{D}[\rho,\nabla\rho] = \frac{1}{2}\int_\Omega \nabla\rho^{T}\mathbf{K}_{\phi}(\rho)\nabla\rho\;dV

% 泛函导数由自动微分获得
\frac{\delta \mathcal{D}}{\delta(\nabla\rho)} = -\nabla\cdot\left(\mathbf{K}_{\phi}(\rho)\nabla\rho\right)
% 对称性 K = K^T  => 熵产生非负

% 热力学一致性（结构性保证）
\frac{d\mathcal{F}}{dt} = -\frac{\delta \mathcal{D}}{\delta(\nabla\rho)}\cdot\nabla\rho \;\le\; 0,
\qquad
\dot{S}_{gen} = \frac{1}{T}\boldsymbol{\tau}:\nabla\mathbf{u} \;\ge\; 0

% 牛顿流体极限：K -> 2\mu \mathbf{I}
% 非牛顿流体：K(\rho) 依赖状态变量 => 剪切变稀/增稠等非牛顿行为被自动识别

% 最小二乘目标（数据驱动部分）
\min_{\theta,\phi}\; \big\| \rho_t^{obs} + \nabla\cdot(\rho\mathbf{u})^{obs} - \nabla\cdot(\tfrac{\delta\mathcal{D}_{\phi}}{\delta\nabla\rho}) \big\|^2
```

## 实验与结果

- **算例/数据集**: 三个基准系统 —— 黏性 Burgers 方程；Kuramoto–Sivashinsky 方程；不可压 Navier–Stokes（牛顿流体与非牛顿流体两类）
- **对比基线**: 稀疏回归 / 符号识别类方法（SIND-R 路线）；以及仅依赖残差的普通机器学习闭合
- **主要结果**:
  - 成功将 Burgers、KS、N-S 中**未知的闭合项识别为神经网络**
  - 识别出的自由能与耗散泛函**按构造满足热力学一致性**：总自由能单调衰减、熵产生非负，无需额外惩罚
  - **不依赖预设候选函数库**，规避了稀疏回归的函数选择偏差
  - 从一个数据集识别出的泛函可**迁移到受同一底层方程支配的另一数据集**
  - 对**非牛顿流体**同样适用，识别出的 $\mathbf{K}(\rho)$ 自动反映非牛顿流变特征
  - 识别结果提供**直接的物理可解释性**：自由能与耗散函数本身即为学习到的动力学的说明

## 局限性

- 需要**实测的速度场或标量场**作为观测数据（"measured" 是前提），无观测则无法运行；这限制了纯数值模拟数据的适用性
- 摘要未涉及**从噪声数据反演时间导数**时的病态问题——时间导数的高频放大是该类方法的经典数值陷阱
- 泛函导数的自动微分在**高维网格上**成本高昂（需存储整个场的导数场），与直接训练一个闭合网络相比未必更快
- 论文摘要未说明**凸性/正定性如何被强制**（是架构约束如 softplus，还是事后投影），这直接决定理论保证是否真正成立
- 与 [[2611.09567 TurtLES]] 这类基准数据集的结合尚未展示，闭环（代理模型 + 闭合识别）尚需验证
- 对**可压缩流、跨声速、多相流**等含强非线性与相变的过程，梯度流结构是否仍适用存疑

## 实现建议

- **实现难度**: 中 — 变分原理 + 自动微分 + 神经网络的组合，实现路径清晰；难点在数据准备与泛函导数的内存开销
- **预期性能**: 训练成本主要在离线阶段；推断时闭合项求值是逐点网络前向，与普通闭合模型相当。泛函导数若用反传实现，显存需求随网格自由度线性增长
- **适用场景**:
  - 从实验或高保真 DNS 数据中**发现未知的亚格子闭合项**（LES SGS 模型）
  - 非牛顿流变的本构识别（辨识 $\mathbf{K}(\rho)$ 或更一般的流变核）
  - 标量输运（被动标量、浓度场）的闭合识别
  - 作为**机器学习闭合模型的"可信度框架"**：给出比"残差小"更强的正确性判据（自由能单调性、熵产非负性可作为后验检验量）
- **可复用要点**:
  1. **把闭合项写成泛函导数而非独立网络**：这是本方法最核心的可迁移技巧。任何"残差型"机器学习闭合（DNSNet、NeuroTurbulence 等）都可以改写成梯度流形式，从而白拿热力学一致性
  2. **熵产非负性与自由能单调性作为 a posteriori 检验量**：这是评估任何闭合模型（包括纯 PINN/Neural Operator 类）物理正确性的低成本强判据，比 L2 误差更可信
  3. **凸性/正定性的架构内嵌技巧**：若用 softplus / $\exp$ 参数化耗散核的对角元，即可保证熵产非负——这是实现层面的具体做法，值得作为模板复用
  4. **只发现本构项、不碰已知项**的设计，降低了学习难度，与"全黑箱 surrogate"路线形成互补
