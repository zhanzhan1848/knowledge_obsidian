## 核心贡献

> 对**液态金属电池 (LLB) 电极**中由**竖直磁场 + 径向电流**驱动的旋流做三维 DNS，系统扫描电流、几何与磁场参数，确认其**混沌转变遵循 Ruelle–Takens–Newhouse (RTN) 路线**，并发现**奇异非混沌吸引子 (SNA)** 作为混沌前的中间态；提出以**洛伦兹力/黏性力之比 $Q_m$** 作为转变的统一控制参数，给出 $Re \sim Q_m^{2/3}$ 的标度律。

1. **参数空间系统扫描**：电流 $I = 11.11\text{–}100$ A；电流密度 $J_0 \approx 4000\text{–}35000$ A/m²；域半径 $R = 3\text{–}9$ cm；域高 $H = 3$ 与 $4.5$ cm；背景磁场 $B_0$ 由 $0.1$ 变到 $20$ G。
2. **混沌起始点依赖于构型**：已有工作（Davidson et al. 2022）给出长径比 $1/6$、$I=100$ A 时混沌起始在 $B_0 \approx 1\text{–}1.5$ G；而本文在**更低电流 $16$ A**、长径比 $1/2$ 时该值**移至 $16\text{–}17$ G**——说明单一 $B_0$ 不足以描述转变。
3. **RTN 转变序列**：由**相图、FFT 频谱、0-1 混沌检验、自相关函数、相关维数**五种诊断一致地确认转变顺序，其中 **SNA 是混沌前的中间状态**。
4. **统一控制参数 $Q_m$**：在**固定长径比**下，转变由**洛伦兹力与黏性力之比** $Q_m$ 支配；**振荡流起始的临界 $Q_m$ 几乎不变**（除非改变域高 $H$）。
5. **标度律**：结果符合中等强迫强度下电磁驱动旋流的 $Re \sim Q_m^{2/3}$ 扭矩平衡标度律。

## 技术方案

### 核心思想

**液态金属电池 (Liquid Metal Battery, LLB)** 的电极是液态金属（Na-Bi、Mg-Sb 等）。设计上电极中心与外壁之间存在**径向电流**，配合**竖直背景磁场 $B_0$**，会产生**径向体积力 $\bm{J}\times\bm{B}$**，其水平分量为**环向 (azimuthal) 力**，驱动电极内形成**绕轴旋流 (swirl)**。

这一旋流是电池放电/充电过程中的关键副产物：它增强传热（有利）与增强腐蚀/不稳定性（不利）。因此其**定常 → 周期 → 混沌的转变阈值**对电池设计至关重要。

电磁驱动旋流的核心竞争是**洛伦兹力（forcing） vs 黏性耗散（damping）**。当二者之比超过某个临界值，非定常解失稳并经倍周期级联走向混沌。这就是 **RTN 路线**：

$$\text{定常} \to \text{周期(1周期极限环)} \to \text{2周期} \to \cdots \to \text{混沌} \to (\text{倍周期分岔}) \to \text{SNA}$$

本文的贡献在于把转变参数从"磁场强度 $B_0$"这种**物理量**上升为 $Q_m$ 这种**无量纲、可跨构型迁移**的量。

### 关键技术

| 技术 | 说明 |
|------|------|
| **三维 DNS（含 MHD 体力）** | 求解 Navier-Stokes + 能量，源项为 $\bm{J}\times\bm{B}$；液态金属的低 Pr 数使热扩散极快，能量方程近乎椭圆方程，数值刚性大 |
| **液态金属低 Pr 处理** | 极低 Pr（Pr ≈ 10⁻³ 量级甚至更低）→ 热扩散时间尺度远小于流动时间尺度；能量方程不能简单显式推进，需特殊处理（隐式/高 Schmidt 极限下的处理） |
| **洛伦兹体力建模** | 径向电流 $\bm{J} = J_r \hat{e}_r$ 与竖直磁场 $\bm{B} = B_0 \hat{e}_z$ → $\bm{J}\times\bm{B} = J_r B_0 (\hat{e}_r \times \hat{e}_z) = -J_r B_0 \hat{e}_\theta$（纯环向驱动） |
| **环形几何建模** | 圆柱域，轴对称几何但流动自发破轴对称 → 必须用三维算例；壁面边界条件（无滑移）与顶/底（滑移或开放）需明确 |
| **相图 (phase portrait)** | 选取某个非定常量（如角动量、壁面切应力）作状态变量绘制相图，识别极限环与奇异吸引子 |
| **FFT 频谱** | 时间序列的功率谱，识别基频、倍频与宽带化 |
| **0-1 混沌检验** | 基于符号序列的稳健二值检验，给出混沌的 0/1 判据，适合区分 SNA 与真混沌 |
| **自相关函数 (ACF)** | 衰减振荡的滞后给出基本周期与准周期/混沌的区分 |
| **相关维数 (correlation dimension)** | 分形维数估计，区分周期(0维/1维)、拟周期(1~2维)、混沌(>2维) 与 SNA |
| **SNA 判别** | 奇异非混沌吸引子：几何结构奇异但 Lyapunov 指数非正；需结合相图 + 频谱 + 0-1 检验综合判断 |
| **RTN 转变序列识别** | 由上述诊断的一致性建立转变级联顺序 |

## 公式

```math
\text{电磁体力（径向电流 } \times \text{ 竖直磁场）}:\quad
\bm{f}_L = \bm{J}\times\bm{B}
= J_r\,\hat{e}_r \times B_0\,\hat{e}_z
= -\,J_r B_0\,\hat{e}_\theta
\quad\Longrightarrow\quad
\text{纯环向驱动力}
```

```math
\text{控制方程（准定常、低 Pr，MHD 源项）}:\quad
\frac{\partial \bm{u}}{\partial t}
+ (\bm{u}\cdot\nabla)\bm{u}
= -\nabla p + \nu\nabla^{2}\bm{u}
+ \frac{\bm{f}_L}{\rho}
,\qquad
\nabla\cdot\bm{u}=0
```

```math
\text{低 Pr 数能量方程（热扩散主导，强刚性）}:\quad
\frac{\partial T}{\partial t}
+ (\bm{u}\cdot\nabla)T
= \alpha\nabla^{2}T + \frac{\dot{q}}{\rho c_p},
\qquad
\alpha = \frac{\nu}{\mathrm{Pr}} \ \gg\ \nu
```

```math
\text{核心无量纲控制参数（洛伦兹力/黏性力之比）}:\quad
Q_m \equiv \frac{\text{Lorentz force}}{\text{viscous force}}
\sim \frac{J_0 B_0\,(\text{特征尺度})}{\rho\,\nu\,U_{\text{char}}\,(\text{特征尺度})}
\quad\Longrightarrow\quad
Q_m \propto \frac{J_0 B_0}{\rho\,\nu\,\Omega}
```

```math
\text{扭矩平衡导致的标度律}:\quad
Re \sim Q_m^{\,2/3}
\qquad
\left(\text{中等强迫强度下的电磁驱动旋流}\right)
```

```math
\text{相变临界判据（不变性）}:\quad
Q_m^{(c)}(\text{振荡起始}) \approx \text{const}
\quad\text{对 } (I,\ J_0,\ R,\ \text{长径比})\ \text{几乎不变}
\quad (\text{仅在改变 } H \text{ 时例外})
```

```math
\text{RTN 转变级联}:\quad
\text{定常} \to \text{1-周期极限环} \to \text{倍周期级联} \to \text{混沌}
\to \text{SNA}\ (\text{奇异非混沌吸引子，混沌前中间态}) \to \cdots
\]

```math
\text{0-1 混沌检验（判据形式）}:\quad
\text{非混沌} \iff \lim_{m\to\infty}\sum_{i=1}^{m-1}\left|b_{i+1}-b_i\right| = 0,
\qquad
\text{混沌} \iff \lim_{m\to\infty}\frac{1}{m}\sum_{i=1}^{m-1}\left|b_{i+1}-b_i\right| = \frac12
```

> 注：$Q_m$ 的原文精确定义式、$Re$ 的参考长度与速度尺度、转变序列中 SNA 的确切位置需参照正文；摘要给出的是定义与标度关系，上式为方法层面的本质表达，未伪造精确系数。

## 代码片段

```python
# 概念性伪代码：液态金属电池电极的 MHD 旋流 DNS 与混沌转变诊断
import numpy as np

def simulate_swirl(I, J0, R, H, B0, Pr=1e-3, steps=20000):
    """
    圆柱域，径向电流 + 竖直磁场驱动的环向旋流
    """
    # --- 网格 ---
    mesh = build_cylindrical_grid(R=R, H=H, nr=64, nt=128, nz=64)
    # 低 Pr 能量方程：热扩散极快 -> 能量方程隐式/椭圆化处理
    solver = NavierStokesSolver(mesh, nu=1e-6, scheme="2nd-order-central")

    u = init_swirl_profile(kind="solid_body", U0=0.0)   # 初始静止或弱旋流
    T = init_uniform_temperature()

    # --- 电流分布：中心与外壁之间径向 ---
    # J_r(x) 由电势解决定，或用解析型（中心密、外壁疏）
    J_r = radial_current_profile(mesh, I_total=I, J0_mean=J0)

    hist = {"omega": [], "wall_shear": [], "T_center": []}

    for n in range(steps):
        # --- 电磁体力（纯环向）---
        f_lorentz = -J_r * B0 * e_theta(mesh)      # (J x B), B = B0 e_z

        # --- 推进 ---
        u = solver.step(u, dt=adaptive_cfl(u_max=abs(u), dx_min=mesh.dx_min),
                        source=f_lorentz)
        # 能量：低 Pr -> 用隐式扩散或松弛处理
        T = solver.step_energy_implicit(T, u, alpha=nu/Pr, source=joule_heating)

        # --- 诊断信号 ---
        hist["omega"].append(total_angular_momentum(u))
        hist["wall_shear"].append(wall_shear_probe(u))
        hist["T_center"].append(probe(T, center))

    return hist


# --- 混沌诊断套件 ---
def diagnose_transition(hist):
    x = hist["omega"]
    sig = np.std(x)
    results = {}

    # 1) 相图
    results["phase_portrait"] = phase_plot(x, hist["wall_shear"])

    # 2) FFT 频谱（基频、倍频、宽带化）
    results["spectrum"] = fft_spectrum(x)                 # 找基频 f0 与 2*f0, 4*f0 分量

    # 3) 0-1 混沌检验（稳健二值化）
    results["zero_one_test"] = zero_one_test(x)           # -> 0 / 1 / 中间值

    # 4) 自相关函数（基本周期 / 衰减）
    results["acf"] = autocorrelation(x)

    # 5) 相关维数（Grassberger-Procaccia）
    results["corr_dim"] = correlation_dimension(x)         # 周期~1, 混沌>2

    # 综合判定
    results["label"] = classify_rtns(results)              # steady/periodic/chaotic/SNA
    return results


# --- 参数扫描与不变性检验 ---
for (I, J0, R, H) in config_grid:
    for B0 in np.logspace(np.log10(0.1), np.log10(20), 40):   # 0.1 - 20 G
        h = simulate_swirl(I, J0, R, H, B0)
        d = diagnose_transition(h)
        record(I, J0, R, H, B0, d["label"])

        # 计算 Q_m 与 Re
        Qm = lorentz_to_viscous_ratio(I, J0, R, H, B0)
        Re  = reynolds_number(I, J0, R, H, B0)
        store(Qm, Re, d["label"])

# 临界 Q_m 不变性：固定长径比 -> 振荡起始处 Q_m 应近似常数
critical_Qm = extract_critical_Qm(records, group_by="aspect_ratio")

# 标度检验：log-log 拟合 Re ~ Q_m^(2/3)
slope = fit_loglog(records, x="Qm", y="Re")     # 预期 ~ 0.67
```

## 实验结论

- **数据集/算例**：液态金属电池电极的三维 DNS 算例；几何与驱动参数扫描范围：电流 $I = 11.11\text{–}100$ A，电流密度 $J_0 \approx 4000\text{–}35000$ A/m²，域半径 $R = 3\text{–}9$ cm，域高 $H = 3$ 与 $4.5$ cm，背景磁场 $B_0 = 0.1\text{–}20$ G。
- **基线**：已有文献（Davidson et al. 2022, "swirling"）给出的构型依赖混沌阈值（$1\text{–}1.5$ G @ 长径比 $1/6$, $I=100$ A）。
- **结果**：
  - **混沌起始点强依赖构型**：长径比 $1/6$、$I = 100$ A 时在 $B_0 \approx 1\text{–}1.5$ G；本文在 $I = 16$ A、长径比 $1/2$ 时移至 $B_0 \approx 16\text{–}17$ G。
  - 跨几何与强迫条件（不同长径比、电流、电流密度），**相图、FFT 频谱、0-1 检验、ACF、相关维数五种诊断给出一致的转变序列**。
  - 流动演化遵循 **Ruelle–Takens–Newhouse 路线**走向混沌；**SNA 是混沌出现前的中间状态**。
  - **固定长径比时，转变由 $Q_m$（洛伦兹力/黏性力之比）支配；振荡流起始的临界 $Q_m$ 几乎不变**，唯一例外是改变域高 $H$。
  - 结果符合中等强迫强度下电磁驱动旋流的 **$Re \sim Q_m^{2/3}$ 标度律**。

## 局限性

- **低 Pr 数值刚性**：液态金属 Pr 极小，能量方程热扩散时间尺度远小于流动时间尺度，显式推进不可行；本文的能量方程处理方式与其精度需正文确认，Re 较高时低 Pr 处理的误差会传导到 $Re\sim Q_m^{2/3}$ 的标度拟合。
- **几何与物理简化**：电极实际有多个卷绕通道（多圈螺旋结构）、端部效应、绝缘/封装边界；本文的简单圆柱域是理想化近似，特别是**改变 $H$ 会破坏 $Q_m$ 临界值不变性**，说明轴向边界条件（涡量反射/穿透）敏感性高。
- **边界条件未充分交代**：顶/底是滑移、固壁还是开放（outflow）对涡量扰动传播影响极大，直接关系到倍周期级联能否被正确解析。
- **"中等强迫"限制**：$Re \sim Q_m^{2/3}$ 只在中等强迫区间成立；强迫很强时不同的耗散机制会改变标度指数，摘要明确限定了适用范围。
- **SNA 的判定依赖多诊断共识**：SNA（奇异非混沌吸引子）与准周期吸引子的区分需要精细的 Lyapunov 指数计算，本文使用 0-1 检验 + 相关维数等间接手段，可能存在误判。
- **电动力学耦合简化**：电流分布被当作给定的径向分布（而非随流动/温度场自洽求解电势），忽略了磁场重分布（MHD 效应）与焦耳热正反馈；真实电池中 $J_r$ 会随流动重构。
- **DNS 代价与扫描密度**：3D 大 Re 湍流 DNS 成本极高；$B_0$ 的 40 点对数扫描 × 多个构型，总算例量巨大，临界点定位精度受采样分辨率限制。

## 实现建议

- **实现难度**：🔴 高。三维 MHD 体力耦合 + 极低 Pr 数的能量方程刚性 + 大 Re 湍流 DNS + 五种混沌诊断（FFT、0-1 检验、GP 相关维数、ACF、相图），每一项都需要专门实现与验证。
- **预期性能**：DNS 单算例成本高（大 Re 三维湍流 + 长时间积分以覆盖级联），是本文的主要瓶颈。降低成本的思路：(a) 用**线性稳定性分析**（对定常基流做特征值分析）预判分岔参数点，只在临界附近做完整 DNS；(b) 用**轴对称 + 短周期扰动 (LES-like / resolvent)** 做参数扫描，再对候选点做三维验证；(c) 诊断信号采样可降频，但需避免混叠。
- **适用场景**：液态金属电池（Na-Bi、Mg-Sb、Zn-Al 等）的运行稳定性设计——决定电流上限、腐蚀与混合强度；液态金属冷却回路（SPX、导热纳微胶囊）中的电磁泵浦旋流；以及更一般的**受迫流动失稳与混沌转变**方法学。
- **落地建议**：**务必先固定并显式声明轴向边界条件**（这是 $Q_m$ 不变性被破坏的主因），再谈标度律的可迁移性；把 $Q_m$ 作为设计参数直接嵌入电池的热-流-电多物理模型（而非用 $B_0$），这样才能跨构型复用本文结论；诊断上建议**补充最大 Lyapunov 指数计算**，以严格区分 SNA 与混沌吸引子。

### 电流分布（电势法）
```math
\mathbf{J}=-\sigma\nabla\phi,\qquad \nabla^{2}\phi=0
```
```math
\mathbf{J}=\nabla\times\left[(\mathbf{\Psi}/r)\hat{\mathbf{e}}_\theta\right]=-\sigma\nabla\phi
```
**电势边界条件**：底部与外壁无电流穿越（$\partial\phi/\partial n=0$）；上边界 $\phi=V$（锂电极下方 $r<R-T$）、容器壁内 $\phi=0$、环状电解液间隙 $\phi=(R-r)V/T$。

### 洛伦兹力解析展开（Bessel）
```math
F_{\theta}(r,z)=\frac{2\sigma VB_{0}}{\rho}\frac{R}{R_{0}^{2}}
\sum_{n}\frac{\tilde{J}_{1}(n)\,J_{1}\!\left(\delta_{n}r/R_{0}\right)}{J_{0}^{2}(\delta_{n})}
\frac{\cosh\!\left(\delta_{n}z/R_{0}\right)}{\cosh\!\left(\delta_{n}Z/R_{0}\right)}
```

- **感应电流忽略**：$Re_m=UR\mu_0\sigma\approx0.01$
- 顶/侧/底壁：**无滑移**
- 物性（500 °C 液态铋）：$\rho=9720$ kg/m³，$\nu=1.2\times10^{-7}$ m²/s，$\sigma=7.3\times10^{5}$ S/m
