## 核心贡献

> 将 SPH 对可压缩 Euler 方程的严格收敛理论**从二次压力（γ=2）推广到任意非线性压力律 ρ^γ（γ≥2）**，并首次在 γ>2 区域给出 **ε 与粒子数 N 之间的代数（而非指数）关系**，同时给出密度在 Wasserstein 距离与负 Sobolev 范数下、以及动量在 flat metric 下的定量收敛率。

1. **统一的"测度值解"框架**：证明针对 **measure-valued 密度** ρ ∈ ℳ⁺（即把连续体解与粒子解放在同一框架下），连续体 SPH（非局部 Euler）与粒子 SPH 共用同一套相对熵估计，无需单独分析粒子动力学——这与 Di Lisio–Grenier–Pulvirenti（2018）的做法不同，后者必须分别处理粒子与连续体两条路径。
2. **关键创新：能量结构保持的非局部压力算子**。采用 $\rho^{\gamma-1}\approx(\rho*L_\varepsilon)^{\gamma-1}*L_\varepsilon$，这一"卷积-幂-再卷积"的形式是整个证明成立的前提——它使得非局部系统拥有**精确的能量平衡**（exact energy balance），从而允许构造二次相对能量泛函并做 Grönwall 估计。
3. **代数而非指数的 ε–N 关系**。此前 Di Lisio–Grenier–Pulvirenti 的稳定性估计中常数随 ε 呈**负幂指数增长**（非局部算子导数范数在 ε→0 时必然爆炸），导致 ε 与 N 之间只能有**对数关系**——实践中极不友好。本文通过非线性项的精细分解与 **Riesz 变换估计**绕开了 Plancherel/Fourier 分析，得到纯代数依赖。
4. **定量收敛率（ℝ^d, γ=2, N = k^{d+1}）**：
   - $W_2^2(\rho_t^{N,\varepsilon}, r_t)\ \le\ C_{tot}\big(W_2^2(\rho_0^{N,\varepsilon}, r_0) + \varepsilon^{-(2+d)}k^{-\frac{2\delta}{2+\delta}} + \varepsilon\big)$
   - flat metric 动量误差满足同阶：$d_f^2(\rho_t^{N,\varepsilon}u_t^{N,\varepsilon}, r_tU_t)\le C_{tot}(\cdots)$
   - 负 Sobolev 范数：$\|\rho_t^{N,\varepsilon}-r_t\|^2_{H^{-m}}\le C_{tot}(\varepsilon^{-(2+d)}k^{-\frac{2\delta}{2+\delta}}+\varepsilon)$
   - 其中 $\delta>0$ 来自初值矩条件 $\int |x|^{2+\delta}\,dr(x)<\infty$
5. **定量收敛率（𝕋^d, γ≥2, N = k^d）**（这是本文对 γ>2 的**全新结果**）：
   - $W_2^2(\rho_t^{N,\varepsilon}, r_t)\ \le\ C_{tot}\big(k^{-2} + k^{-1}\varepsilon^{-(2d+1)} + \varepsilon\big)$
   - $d_f^2(\rho_t^{N,\varepsilon}u_t^{N,\varepsilon}, r_tU_t)\ \le\ C_{tot}(k^{-2}+k^{-1}\varepsilon^{-(2d+1)}+\varepsilon)$
   - $\|\rho_t^{N,\varepsilon}-r_t\|^2_{H^{-m}}\ \le\ C_{tot}(k^{-1}\varepsilon^{-(2d+1)}+\varepsilon)$
   - 附加条件 $r_0\ge r_*>0$（密度有正下界），$m\ge d+1$
6. **非局部→局部收敛定理**（Theorem 1.1, ℝ^d, γ=2）给出 Grönwall 型不等式：$\mathcal{E}_{rel}^\varepsilon(t)+\frac12\mathrm{tr}(\mu_t^\varepsilon) + \kappa\int_0^t\!\!\int|u^\varepsilon-U|^2 d\rho^\varepsilon \le e^{C_1t}(\mathcal{E}_{rel}^\varepsilon(0)+C_2\varepsilon)$。**当 κ<0（激波形成/负压缩）时**，指数变为 $e^{(C_1-2\kappa)t}$，把黏性/摩擦项显式吸收入指数——这是处理激波（shock）形成的重要技术手段。

## 技术方案

### 核心思想

SPH 方法（Lucy 1972 / Gingold & Monaghan 1977 / Monaghan 1985 起，自引力流体数值模拟发展而来）通过**卷积逼近非线性压力项**来保留能量结构：

$$\rho^{\gamma-1}\ \approx\ (\rho * L_\varepsilon)^{\gamma-1} * L_\varepsilon$$

其中 $L_\varepsilon$ 是对称光滑核，$\varepsilon\to0$ 时逼近 Dirac 分布。关键洞察是：**这个特定形式使得非局部系统保留原系统的能量结构**，包括精确的能量平衡。这是相对熵方法能用的前提——若换成其他近似形式，整个证明框架就会崩塌。

论文把分析拆成**两步**：
1. **粒子 → 非局部 Euler**（N→∞，固定 ε）
2. **非局部 Euler → 局部 Euler**（ε→0）

但本文的贡献在于：不再把这两步割裂处理，而是**先建立针对测度值解的统一估计**，粒子收敛率直接由一般性估计作为推论得出。

### 关键技术

| 技术 | 说明 |
|------|------|
| **能量结构保持的非局部压力算子** | $\rho^{\gamma-1}\mapsto(\rho*L_\varepsilon)^{\gamma-1}*L_\varepsilon$，保证精确能量平衡 |
| **Bessel 势核** | $K(x)=L_m*L_m(x)$，$m>\max\{d,2\}$，$\hat{L}_m(\xi)=(1+4\pi^2|\xi|^2)^{-m/2}$，$K_\varepsilon(x)=\varepsilon^{-d}K(x/\varepsilon)$，$\hat{K}_\varepsilon(\xi)=(1+4\pi^2\varepsilon^2|\xi|^2)^{-m}$ |
| **周期域的周期化核** | $L^{per}_{m,\varepsilon}$，用于 $\mathbb{T}^d$ 上的 $\gamma\ge2$ 情形 |
| **相对熵泛函** | $\mathcal{E}_{rel}^\varepsilon(t)=\frac12\int|u^\varepsilon-U|^2 d\rho^\varepsilon_t + \frac12\int|L_{m,\varepsilon}*(d\rho^\varepsilon-dr)|^2 dx$ |
| **测度值解定义** | 引入对称矩阵值 Radon 测度 $\mu\in\mathcal{M}^+(\Omega;\mathbb{R}^{d\times d}_{sym})$，同时容纳连续体解与粒子解 |
| **Riesz 变换估计** | γ>2 时无法用 Plancherel 估计相对熵，改用非线性项分解 + Riesz 变换技巧 |
| **negative Sobolev 范数** | 密度误差在 $H^{-m}(\mathbb{R}^d)$ 下的平方范数界（低正则性控制） |
| **flat metric** | 动量误差 $d_f$ 度量（附录 C 定义），对密度的粗糙性免疫 |
| **激波处理** | κ<0 时指数修正为 $e^{(C_1-2\kappa)t}$ |

## 公式

### 1. 局部可压缩 Euler 方程（目标极限）

```math
\partial_t \rho + \mathrm{div}_x(\rho u) = 0,
\qquad
\partial_t(\rho u) + \mathrm{div}_x(\rho u\otimes u)
+ \rho \nabla_x \rho^{\gamma-1} + \kappa \rho u = 0.
```

### 2. 非局部（SPH）系统

```math
\text{(NLE)}\quad
\begin{cases}
\partial_t \rho + \mathrm{div}_x(\rho u) = 0,\\
\partial_t(\rho u) + \mathrm{div}_x(\rho u\otimes u)
+ \rho\nabla_x(K_\varepsilon \star \rho) + \kappa \rho u = 0.
\end{cases}
```

### 3. 粒子 SPH 动力学（ℝ^d，γ=2）

```math
\dot{X}_i(t) = V_i(t),
\qquad
\dot{V}_i(t) = -\sum_{j=1}^{N} m_j \nabla K_\varepsilon(X_i(t)-X_j(t)) - \kappa V_i(t).
```

### 4. 粒子 SPH 动力学（𝕋^d，γ≥2）

```math
\dot{X}_i(t) = V_i(t),
\qquad
\dot{V}_i(t) = -\int_{\mathbb{T}^d}\nabla_x L^{per}_{m,\varepsilon}(X_i(t)-y)
\left(\sum_{k=1}^{N} m_k L^{per}_{m,\varepsilon}(y-X_k(t))\right)^{\gamma-1} dy - \kappa V_i(t).
```

### 5. 核函数构造

```math
K(x) = L_m \star L_m(x), \quad m > \max\{d,2\},
\qquad
\widehat{L}_m(\xi) = \frac{1}{(1+4\pi^2|\xi|^2)^{m/2}},
\qquad
K_\varepsilon(x) = \varepsilon^{-d} K(x/\varepsilon),
\qquad
\widehat{K}_\varepsilon(\xi) = \widehat{K}(\varepsilon\xi) = \frac{1}{(1+4\pi^2\varepsilon^2|\xi|^2)^{m}}.
```

### 6. 相对熵与 Grönwall 不等式（Theorem 1.1）

```math
\mathcal{E}_{rel}^{\varepsilon}(t)
:= \frac{1}{2}\int_{\mathbb{R}^d}|u^\varepsilon-U|^2\,\mathrm{d}\rho_t^\varepsilon(x)
 + \frac{1}{2}\int_{\mathbb{R}^d}|L_{m,\varepsilon}\star(\mathrm{d}\rho^\varepsilon - \mathrm{d}r)|^2\,\mathrm{d}x,
```

```math
\kappa \ge 0:\quad
\mathcal{E}_{rel}^{\varepsilon}(t) + \frac{1}{2}\mathrm{tr}(\mu_t^\varepsilon(\mathbb{R}^d))
+ \kappa\int_0^t\!\!\int |u^\varepsilon-U|^2\,\mathrm{d}\rho_\tau^\varepsilon
\le e^{C_1 t}\left(\mathcal{E}_{rel}^{\varepsilon}(0) + C_2\varepsilon\right),
```

```math
\kappa < 0:\quad
\mathcal{E}_{rel}^{\varepsilon}(t) + \frac{1}{2}\mathrm{tr}(\mu_t^\varepsilon(\mathbb{R}^d))
\le e^{(C_1-2\kappa)t}\left(\mathcal{E}_{rel}^{\varepsilon}(0)+C_2\varepsilon\right).
```

```math
\text{推论：}\quad
W_2^2(\rho_t^\varepsilon, r_t) \le C_3\big(W_2^2(\rho_0^\varepsilon,r_0) + \mathcal{E}_{rel}^\varepsilon(0) + \varepsilon\big),
\qquad
\|\rho_t^\varepsilon-r_t\|^2_{H^{-m}(\mathbb{R}^d)} + \|\mu_t^\varepsilon\|_{TV} \le C_4 e^{C_1t}\big(\mathcal{E}_{rel}^\varepsilon(0)+C_2\varepsilon\big).
```

### 7. SPH 定量收敛率（Theorem 1.3）

```math
\text{(ℝ^d, γ=2, } N=k^{d+1}\text{):}\quad
\begin{aligned}
W_2^2(\rho_t^{N,\varepsilon}, r_t) &\le C_{tot}\Big(W_2^2(\rho_0^{N,\varepsilon},r_0)
+ \varepsilon^{-(2+d)}\,k^{-\frac{2\delta}{2+\delta}} + \varepsilon\Big),\\
d_f^2(\rho_t^{N,\varepsilon}u_t^{N,\varepsilon}, r_tU_t) &\le C_{tot}\Big(\cdots\Big),\\
\|\rho_t^{N,\varepsilon}-r_t\|^2_{H^{-m}(\mathbb{R}^d)} &\le C_{tot}\Big(\varepsilon^{-(2+d)}\,k^{-\frac{2\delta}{2+\delta}} + \varepsilon\Big).
\end{aligned}
```

```math
\text{(𝕋^d, γ\ge2, } N=k^{d}\text{):}\quad
\begin{aligned}
W_2^2(\rho_t^{N,\varepsilon}, r_t) &\le C_{tot}\big(k^{-2} + k^{-1}\varepsilon^{-(2d+1)} + \varepsilon\big),\\
d_f^2(\rho_t^{N,\varepsilon}u_t^{N,\varepsilon}, r_tU_t) &\le C_{tot}\big(k^{-2}+k^{-1}\varepsilon^{-(2d+1)}+\varepsilon\big),\\
\|\rho_t^{N,\varepsilon}-r_t\|^2_{H^{-m}} &\le C_{tot}\big(k^{-1}\varepsilon^{-(2d+1)}+\varepsilon\big).
\end{aligned}
```

### 8. 测度值解的动量方程（含振荡分量 μ）

```math
\int \phi(t)\cdot u\,d\rho_t - \int \phi(0)\cdot u_0\,d\rho_0
= \int_0^t\!\!\int \big(u\cdot\partial_t\phi + u\otimes u:\nabla_x\phi - \kappa u\cdot\phi
- \nabla_x(K_\varepsilon\star d\rho)\cdot\phi\big)d\rho_\tau\,d\tau
+ \int_0^t\!\!\int \nabla_x\phi : d\mu_\tau\,d\tau.
```

### 9. 对称矩阵值测度的变差控制

```math
\text{Proposition 1.5:}\quad
\mu\in\mathcal{M}^+(\Omega;\mathbb{R}^{d\times d}_{sym})
\ \Longrightarrow\ |\mu|(\Omega) \le C\,\mathrm{tr}\big(\mu(\Omega)\big),
\quad C \text{ 与 } \mu \text{ 无关}.
```

## 理论与结果

### 非局部→局部收敛（Theorem 1.1，ℝ^d，γ=2）

- 假设 $(r,U)$ 是 (E) 的光滑解，且 $r>0$、$\nabla_x^2 r\in L^\infty((0,T)\times\mathbb{R}^d)$、$U\in L^\infty(0,T;W^{2,\infty}(\mathbb{R}^d))$；初值满足 $\int r_0 dx = 1$、$\int|x|^2 r_0 dx<+\infty$。
- 结论：$W_2(\rho_t^\varepsilon,r_t)\to0$、$d_f(\rho_t^\varepsilon u_t^\varepsilon, r_tU_t)\to0$、$\rho_t^\varepsilon\to r_t$ 在 $H^{-m}(\mathbb{R}^d)$ 中成立（几乎所有 $t$）。
- "良准备"条件：$\mathcal{E}_{rel}^\varepsilon(0)\to0$ 且 $\|u_0^\varepsilon\|_{L^2(d\rho_0^\varepsilon)}$ 关于 ε 一致有界。
- **超线性衰减是新的**：$O(\varepsilon)$ 的误差项（而非 Di Lisio 等的指数型）。

### 非局部→局部收敛（Theorem 1.2，𝕋^d，γ≥2）

- 周期域上推广到任意 γ≥2，需要 $r_0\ge r_*>0$ 与 $m\ge d+1$。
- 这是 γ>2 情形收敛性的**首个严格结果**（此前 Danchin–Mucha 的 Besov 估计仅限 γ=2）。

### SPH 收敛率（Theorem 1.3）

- **统一性**：粒子收敛结论直接来自测度值解的一般估计（Proposition 2.3 证明粒子解是无浓度分量的测度值解，$\mu=0$），**无需对粒子动力学单独分析**。
- **ε–N 关系**：$N=k^d$（𝕋^d）或 $N=k^{d+1}$（ℝ^d），误差由三项平衡决定：
  - $k^{-2}$：粒子采样误差（Wasserstein/flat metric 的初始误差衰减）
  - $k^{-1}\varepsilon^{-(2d+1)}$：**代数耦合项**——这是新结果的核心，对比 Di Lisio 等的对数关系
  - $\varepsilon$：非局部→局部的固有偏差
- **负 Sobolev 范数**只含 $k^{-1}\varepsilon^{-(2d+1)}+\varepsilon$ 两项（无初始误差项），因为 $H^{-m}$ 范数对初始误差不敏感。

### 与既有工作的对比

| 工作 | 压力形式 | ε–N 关系 | 主要局限 |
|------|---------|----------|---------|
| Di Lisio–Grenier–Pulvirenti (2018, 2020) | γ=2 | **对数**（常数随 ε 指数增长） | 实践中极不友好 |
| Danchin–Mucha | γ=2 | — | 仅 Besov 估计 |
| Oelschläger (2005) | γ=2 | 代数 | 依赖 Euler 解光滑 |
| Franz–Wendland (2013, 2017) | γ=2 | 代数 | 二次压力；核选取可提升阶 |
| **本文** | **γ≥2** | **代数** | γ>2 需 Riesz 变换技巧 |

## 局限性

- **光滑解假设**：所有定理均假设局部 Euler 方程存在光滑解（$(r,U)$ 光滑）。对激波形成后的**熵解**未给结论——这是 SPH 收敛理论最核心的未解问题。
- **周期域 / 全空间**：仅证明于 $\mathbb{R}^d$ 与 $\mathbb{T}^d$，**固体壁面边界条件未处理**（工业 CFD 中最关键的场景）。
- **正压强（$r_0\ge r_*>0$）**：γ≥2 的 𝕋^d 情形要求密度正下界，物理上对应"压力处处非负"，在真空/自由表面区域不成立。
- **仅 γ≥2**：γ=1 等容（isobaric）与 γ<2 的情况未涵盖。
- **常数 $C_{tot}$ 依赖强解的范数**：实际计算中这些范数未知，因此**误差界不是可操作的先验估计**（a posteriori 才可用）。
- **核函数固定为 Bessel 势**：未研究 Franz–Wendland 那样通过更高阶矩条件提升收敛阶；作者明确指出这是未来方向。
- **无实验验证**：纯理论工作，未做数值算例验证收敛阶。
- **未处理 κ=0**：黏性/摩擦项 $\kappa$ 取 0 时的边界情况未单独讨论（黏性为正是 SPH 的常用设定）。

## 实现建议

- **实现难度**: 中（理论）/ 低（工程）。作为**分析工具**可直接用于评估 SPH 求解器的收敛行为。
- **预期性能**:
  - 定理给出的**收敛阶指导粒子数与核宽度的联合选择**：
    - 𝕋^d, γ≥2：总误差 $\sim k^{-2}+k^{-1}\varepsilon^{-(2d+1)}+\varepsilon$。要使三项平衡，最优取 $\varepsilon\sim k^{-1/(2d+2)}$，此时误差 $\sim k^{-2/(d+1)}$。
    - 例如 d=3 时：$\varepsilon\sim k^{-1/8}$，误差 $\sim k^{-1/2}$。**这意味着粒子数增加 100 倍只换来 10 倍精度**——一个相当悲观但重要的现实警示。
    - 对比 3D 常用 $N\sim10^6$（$k=100$）：$\varepsilon\sim 100^{-1/8}\approx 0.56$。
  - **实践含义**：ε 增大可减少粒子数需求，但 ε 过大时"粒子分布 ≠ 连续介质"的建模误差上升。这条理论量化了工程上的经典 trade-off。
- **适用场景**:
  - **SPH 求解器验证**：给定粒子数 N 与核宽度 h，可给出误差上界，用于验证实现是否达到理论收敛阶（**收敛阶验证的黄金标准**）；
  - **网格/粒子数预算**：在给定精度目标下反推最小粒子数；
  - **代码正确性检查**：若实测误差阶显著低于理论阶，说明粒子初始化（Lemma 5.1 的 $r^0_N$ 构造）或核实现有误；
  - **非局部→局部极限的数学基础**：为设计"混合"求解器（近场用 SPH 粒子、远场用欧拉网格）提供误差依据。
- **可复用要点**:
  - **"ε 与 N 的关系"这一量级是评估任何 SPH 变体的核心指标**——比"是否收敛"这个是非判断更有信息量。
  - 能量结构保持的近似形式（$\rho^{\gamma-1}\mapsto(\rho*L_\varepsilon)^{\gamma-1}*L_\varepsilon$）是**可推广到其他 SPH 变体的设计准则**。
  - μ<0 时指数修正 $e^{(C_1-2\kappa)t}$ 是处理激波的通用技巧。
  - 相对熵方法 + Riesz 变换估计的组合，是绕过 Plancherel 限制处理非线性压力的一项可复用技术。
