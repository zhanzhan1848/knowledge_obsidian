## 核心贡献

> 首次证明**旋转内加热对流（RIHC）在带侧壁的圆柱容器中确实存在"贴壁模态"（wall mode）**：即使双周期层在同参数下已被旋转完全稳定（$E\lesssim2\times10^{-5}$），圆柱仍能靠这个贴壁行波持续输运热量，直到 $E=5.62\times10^{-6}$。这意味着**从横向周期域推断出的稳定性极限与热输运结论，在有侧壁时必须重新评估**。

1. **贴壁模态的存在性与持续性**：$R=10^8$、$Pr=1$、$\Gamma=1/2,1,2$ 的圆柱中，侧壁模态在 $E\lesssim2.3\times10^{-5}$（$Ro^{-1}\gtrsim4.3$）区间持续输运热量；双周期层在 $E=1.78\times10^{-5}$ 已完全转为导热态，圆柱却保持 $0.05\lesssim\overline{\langle wT\rangle}\lesssim0.11$，直到 $E=5.62\times10^{-6}$（约为周期层导热边界的 **1/4**）才熄灭；$E=3.16\times10^{-6}$ 全部静止。
2. **模态的空间结构**：
   - 附着在侧壁上的**行波**，径向厚度约 **0.03 层深**（与 $\Gamma$ 无关），内部流体几乎静止（$z=3/4$ 处内部动能比侧壁峰值低 **4 个数量级**）；
   - 强度峰值位于上半（不稳定）层 $z\approx0.8$，但**向下贯穿整个稳定下半层**（$z=1/4$ 仍有衰减后的叶瓣；$K_w$ 在中深度仍保留约 **2/3** 峰值，下半层平均比上半层小约 **3.3 倍**）；
   - 归一化竖直剖面对 $\Gamma=1/2,1,2$ **塌缩到同一条曲线**。
3. **稳定分层被保留**：模态虽深入下半层，但 $0.1\le z\le0.4$ 区间内 $\partial_z\langle T\rangle_\theta$ 在**所有径向位置保持为正**；在轴线上保留导热梯度的 **84%**，近侧壁处保留 **62%** → 局部削弱但未破坏稳定分层。
4. **方位角结构与漂移**：
   - 方位波数 $m$ **正比于 $\Gamma$**（$E=10^{-5}$ 时：$m=1,3,7$ 对应 $\Gamma=1/2,1,2$），壁面平行波长 $\lambda=\pi\Gamma d/m\approx0.9$–$1.05\,d$（$\Gamma\ge1$）；
   - 模态**逆行（retrograde / 抗气旋）漂移**，$\omega=-1.9\times10^2,\,-78,\,-36$（单位 $\kappa/d^2$，共转参考系）；漂移**在更宽的圆柱中更慢**；
   - 过壁频率 $m|\omega|$ 对 $\Gamma$ 依赖很弱（$1.9\times10^2,\,2.3\times10^2,\,2.5\times10^2$）；
   - 降低 $E$ 到 $5.62\times10^{-6}$ 时，$\Gamma=1,2$ 的 $m$ 各 **+1**（4 和 8），$\Gamma=1/2$ 保持 $m=1$；漂移速度按 $E$ 下降的同一比例（1.78 倍）减慢。
5. **与 RRBC 贴壁模态的定量对照**：RRBC 线性渐近理论给出 $m\approx\left[\frac{\pi}{2}(2+\sqrt3)^{1/2}-17.49E^{1/3}\right]\Gamma$，$E\to0$ 时 $m\approx3\Gamma$；本文观测到同样的线性比例但斜率略陡。模态径向厚度 $0.03\,d$ 与 RRBC 的 Stewartson 边界层尺度 $E^{1/3}\approx0.02$、$E^{1/4}\approx0.06$ 可比；归一化漂移 $\omega/\Omega\approx3.9\times10^{-3},\,1.5\times10^{-3},\,7.3\times10^{-4}$ 与 RRBC 起始值 $\approx1.0\times10^{-3}$ 同量级。

## 技术方案

### 核心思想

旋转对流中的**横向边界会局部放宽 Taylor–Proudman 约束**，使得受限容器中的首次失稳不是体模态，而是附着在侧壁上的波。RRBC 中这一"贴壁模态"已被充分研究，但 RIHC 的热驱动机制完全不同：

- RRBC：加热在边界，水平与时间平均的竖直通量**随高度恒定**；
- RIHC：**均匀体加热** + 两块等温固定温度板 → 导热态温度在**中深度取极大**，上层不稳定分层、下层稳定分层。

因此贴壁模态面临一个 RRBC 没有的抉择：**要么被困在不稳定的上半层，要么必须向下贯穿稳定层**——而后者由旋转 + 分层共同支撑的**惯性重力波（inertial gravity wave）**提供机制。本文用 DNS 回答三个问题：(i) 贴壁模态是否存在、能否在体相已稳定时持续？(ii) 它被限制在上半层还是贯穿下半层？(iii) $E$ 与 $\Gamma$ 如何选择方位波数与进动漂移？

### 关键技术

| 技术 | 说明 |
|------|------|
| **求解器** | **AFiD** 二阶有限差分（van der Poel et al., 2015）+ 其柱坐标版本（Verzicco & Orlandi, 1996） |
| **时间推进** | 非线性项三阶 Runge–Kutta；线性项二阶隐式 Crank–Nicolson |
| **坐标奇点处理** | 圆柱轴 $r=0$ 处求解**径向通量变量** $q_r=r\,u_r$（Verzicco & Orlandi, 1996） |
| **网格** | 方位向均匀，径向/轴向在刚性壁面附近加密；$(N_\theta\times N_r)$ 分别为 $128\times64$（$\Gamma=1/2$）、$256\times64$（$\Gamma=1$）、$512\times128$（$\Gamma=2$）；$N_z\in[128,384]$ 随 $E$ 减小而增加 |
| **分辨率依据** | 既解析水平 Ekman 层（厚度 $O(E^{1/2})$）也解析贴壁模态所在的侧壁边界层；网格密度沿用 Ostilla-Mónico & Arslan (2025) 的空间分辨率判据 |
| **数值精度校验** | **精确全局平衡**：$\overline{\langle|\nabla\mathbf{u}|^{2}\rangle}=R\,\overline{\langle wT\rangle}$ 与 $\overline{\langle|\nabla T|^{2}\rangle}=\overline{\langle T\rangle}$（导热态为 0、$1/12$） |
| **初始化策略** | 每个算例从**同 $R$、同 $\Gamma$ 的充分发展非旋转对流态**出发，**冲击式（impulsively）加入旋转**，积分至对流瞬态衰减、统计平稳 |
| **收敛判据** | 平稳窗口后半段的时间平均 $\langle wT\rangle$ 与整个平稳窗口之差 **< 1%** |
| **模态识别** | $z=3/4$ 水平面上、沿最大强度半径做垂直速度 $w$ 的**方位 Fourier 谱**提取主波数 $m$；壁层区（$\Gamma=1$ 时 $r\ge0.4$）内的体积归一化 $K_w$ |
| **漂移频率 $\omega$** | 对主 Fourier 分量做**时空相干性最大化**，寻找使行波模式 $\cos(m\theta-m\omega t)$ 相干性最高的频率；$\omega>0$ 为顺行 |
| **采样** | 约 **200 个瞬时快照**，间隔一个自由落体时间 $d/U_{ff}$（$U_{ff}=\sqrt{R\,Pr}\,\kappa/d$，即 $10^{-4}d^2/\kappa$），覆盖约 $0.02\,d^2/\kappa$ |
| **对照几何** | 笛卡尔双周期层 $L_x=L_y=\pi$（等效 $\Gamma=\pi$，此处量已与 $\Gamma$ 无关），结果直接取自 Ostilla-Mónico & Arslan (2025)，**同方法、同边界条件、同 $R$** |

## 公式

### 1. 控制方程（Boussinesq，旋转内加热）

```math
\nabla\cdot\boldsymbol{u}=0
```

```math
\partial_{t}\boldsymbol{u}+\boldsymbol{u}\cdot\nabla\boldsymbol{u}
+\mathit{Pr}\,E^{-1}\,\boldsymbol{e}_{z}\times\boldsymbol{u}
=-\nabla p+\mathit{Pr}\nabla^{2}\boldsymbol{u}+\mathit{Pr}\,R\,T\,\boldsymbol{e}_{z}
```

```math
\partial_{t}T+\boldsymbol{u}\cdot\nabla T=\nabla^{2}T+1
```

### 2. 控制参数

```math
R=\frac{g\alpha H d^{5}}{\rho c_{p}\,\nu\,\kappa^{2}},\qquad
E=\frac{\nu}{2\Omega d^{2}},\qquad
\mathit{Pr}=\frac{\nu}{\kappa}=1
```

```math
Ro=E\sqrt{R/\mathit{Pr}}
```

（本文 $R=10^8$ 固定，$E$ 与 $\Gamma$ 变化；$E\in[3.16\times10^{-6},\,3.16\times10^{-2}]$ 另加一个非旋转参考算例）

### 3. 导热态（两板等温、均匀体加热）

```math
T_c(z)=\frac{1}{2}z(1-z)
```

```math
T_c^{\max}=\frac{1}{8}\ \text{at}\ z=\frac{1}{2},\qquad
\langle\overline{T_c}\rangle=\frac{1}{12}
```

（导热态水平均匀且不依赖 $r$ → 绝热侧壁不改变导热态，**任何水平结构完全来自流动**）

### 4. 热量分配

```math
F_T=\frac{1}{2}+\overline{\langle wT\rangle},\qquad
F_B=\frac{1}{2}-\overline{\langle wT\rangle},\qquad F_T+F_B=1
```

（导热基线：$\overline{\langle wT\rangle}=0$，$\overline{\langle T\rangle}=1/12$）

### 5. RRBC 贴壁模态的线性渐近理论对照式

```math
m\approx\left[\frac{\pi}{2}(2+\sqrt{3})^{1/2}-17.49\,E^{1/3}\right]\Gamma
\ \xrightarrow{E\to0}\ m\approx3\Gamma
```

```math
\omega_{dc}/\Omega\approx\frac{4\pi^{2}[3(2+\sqrt{3})]^{1/2}E^{-1465}E^{4/3}}{\mathit{Pr}}
\approx1.0\times10^{-3}
```

### 6. 壁面平行波长与过壁频率

```math
\lambda=\frac{\pi\Gamma d}{m},\qquad f_{\text{pass}}=m|\omega|
```

### 7. 归一化漂移角速度

```math
\Omega=\frac{1}{2E},\qquad \frac{\omega}{\Omega}=2E\,\omega
```

### 8. 稳定分层保持判据

```math
\partial_z\langle T\rangle_{\theta}>0\quad \forall r,\qquad 0.1\leq z\leq0.4
```

## 实验结论

### 计算工况

| 参数 | 取值 |
|---|---|
| 瑞利数 $R$ | $10^8$（固定） |
| 普朗特数 $Pr$ | 1（固定） |
| 埃克曼数 $E$ | $3.16\times10^{-6}\sim3.16\times10^{-2}$（对数间隔）+ 非旋转参考 |
| 长径比 $\Gamma=D/d$ | $1/2,\ 1,\ 2$ |
| 边界条件 | 上下板等温 $T=0$，侧壁绝热 $\partial_rT=0$，所有刚性壁面无滑移 |
| 对照几何 | 双周期层 $L_x=L_y=\pi$（等效 $\Gamma=\pi$），取自 Ostilla-Mónico & Arslan (2025) |

### 三个动力学区间

| 区间 | 判据 | 行为 |
|---|---|---|
| **弱旋转** | $E\gtrsim1.2\times10^{-3}$（$Ro^{-1}\lesssim0.083$） | $\overline{\langle wT\rangle}$ 与 $\overline{\langle T\rangle}$ 接近非旋转值。非旋转基线：$\Gamma=1$ 为 0.238、$\Gamma=2$ 为 0.227、$\Gamma=1/2$ 为 **0.259**（窄柱受限反而更高，反映大尺度结构被约束） |
| **旋转影响区** | 中等 $E$ | $\Gamma=1,2$ 圆柱像周期层一样**增强热输运、降低平均温度**：$E=3.16\times10^{-4}$ 时 $\overline{\langle wT\rangle}\approx0.253$–$0.256$，$\overline{\langle T\rangle}\approx0.0241$；$\Gamma=1/2$ **无此增强**（其非旋转输运已达更大域的峰值） |
| **贴壁模态区** | $E\lesssim2.3\times10^{-5}$（$Ro^{-1}\gtrsim4.3$） | 周期层在 $E=1.78\times10^{-5}$ 已纯导热；圆柱仍有 $0.05\lesssim\overline{\langle wT\rangle}\lesssim0.11$，且 $\overline{\langle T\rangle}$ 低于导热值；持续到 $E=5.62\times10^{-6}$ 后随 $E$ 减小**单调衰减**，$E=3.16\times10^{-6}$ 全静 |

**关键标度**：贴壁模态区内 $\overline{\langle wT\rangle}$ 随 $\Gamma$ **系统性递减**——与热输运局域在侧壁、体积占比按 $1/\Gamma$ 缩放的图像一致。

### 模态空间结构（$\Gamma=1$，$E=10^{-5}$）

- $z=3/4$ 水平面：垂直速度形成**侧壁周边环状的交替叶瓣**，主方位波数 $m=3$，中央核心静止；
- $z=1/4$：**同一色标下**叶瓣仍存在但幅值减弱；
- 径向–竖直截面（过速度峰）：贴壁边界层，**上半层强度最大**，但向下延伸远超中深度；
- $K_w$ 竖直剖面：峰值在 $z\approx0.8$，向下降平滑衰减；中深度保留约 **2/3** 峰值；下半层平均比上半层小约 **3.3 倍**；
- $E=1.78\times10^{-5}$ 剖面几乎不变；$E=5.62\times10^{-6}$ 时幅值下降、峰上移到 $z=0.84$，中深度能量降至峰值的一半；
- **内部静止程度**：$z=3/4$ 处内部动能比侧壁峰值低 **4 个数量级**；
- **厚度**：以 $K_w$ 超过峰值 10% 定义的活跃壁层，径向厚度在所有 $\Gamma$ 下恒为约 **0.03**；只有绝对幅值随几何变化（$\Gamma=1/2\to1$ 增大约 4 倍，$\Gamma=2$ 饱和）。

### 平均温度场（$\Gamma=1$，$E=10^{-5}$）

- 远离侧壁等温线基本水平；轴线上中心线剖面紧贴导热抛物线 $T_c(z)=\frac12 z(1-z)$，仅峰值略降；
- $0.1\le z\le0.4$ 区间 $\partial_z\langle T\rangle_\theta$ **在所有径向位置为正**：轴线上保留导热梯度的 **84%**，近侧壁保留 **62%**；
- 结论：**模态深入稳定下半层，但稳定平均分层在所测下半层区间被保留**，只在边界附近产生局部衰减。

### 方位结构与漂移

| $E$ | $\Gamma$ | $m$ | 主波数功率占比 | $\omega$（$\kappa/d^2$，共转系） | $m|\omega|$ | $\lambda$ | $\omega/\Omega$ |
|---|---|---|---|---|---|---|---|
| $10^{-5}$ | $1/2$ | 1 | 90% | $-1.9\times10^{2}$ | $1.9\times10^{2}$ | $1.6\,d$ | $3.9\times10^{-3}$ |
| $10^{-5}$ | 1 | 3 | 83% | $-78$ | $2.3\times10^{2}$ | $\approx1.05\,d$ | $1.5\times10^{-3}$ |
| $10^{-5}$ | 2 | 7 | 97% | $-36$ | $2.5\times10^{2}$ | $\approx0.9\,d$ | $7.3\times10^{-4}$ |
| $5.62\times10^{-6}$ | $1/2$ | 1 | 75% | $-1.1\times10^{2}$ | $1.9\times10^{2}$ | $1.6\,d$ | $1.2\times10^{-3}$ |
| $5.62\times10^{-6}$ | 1 | 4 | — | $-47$ | $1.8\times10^{2}$ | $\approx0.79\,d$ | $5.3\times10^{-4}$ |
| $5.62\times10^{-6}$ | 2 | 8 | — | $-23$ | $1.8\times10^{2}$ | $\approx0.79\,d$ | $2.6\times10^{-4}$ |

- 主波数在大多数情形占涨落功率的 **97%–98%**（在 $E=5.62\times10^{-6}$ 降至 $\Gamma=2,1,1/2$ 对应的 90%、83%、75%）；
- 所有算例中模态都是**刚性旋转的相干行波**，时间相干性 **> 0.99**；
- 漂移在所有 $\Gamma$ 下均为**逆行（$\omega<0$）**；更宽的圆柱漂移更慢；
- $E$ 从 $10^{-5}$ 降到 $5.62\times10^{-6}$ 时漂移按 1.8、1.6、1.6 倍减速，与 $E$ 下降的 1.78 倍几乎一致。

## 局限性

1. **未确定线性起始阈值**：算例从非旋转态出发并冲击加旋，**只能证明模态的存在与有限幅值持续性，不能定位线性临界值**；若主失稳是**次临界（subcritical）**的，实际的最小 $E$ 可能与线性阈值不同。线性稳定性分析被作者明确留作未来工作。
2. **单一 $R$ 与 $Pr$**：全部结论基于 $R=10^8$、$Pr=1$，对 $R$、$Pr$ 的依赖未探讨。
3. **仅绝热侧壁**：其他侧壁热条件（导热/定温）未考察。
4. **仅三个长径比**（$\Gamma=1/2,1,2$），$m\propto\Gamma$ 的线性标度在更大/更小 $\Gamma$ 是否保持未知。
5. **无高 $E$ 侧的 RRBC 式渐近对照**：由于 RIHC 需要定义"有效瑞利数"，作者指出与 RRBC 渐近理论的**严格定量比较超出本文范围**。
6. **球形几何未覆盖**：旋转内加热流在球壳中的相关研究（Jones et al. 2000；Kaplan et al. 2017；Seeley et al. 2025）尚未与本文平板—侧壁构型打通。
7. **模态的物理起源未定性**：虽然"稳定层中的惯性重力波"是 RRBC 的解释，RIHC 中模态贯穿下半层的**具体波传播机制**未做诊断（如层结 Brunt–Väisälä 频率的显式计算）。
8. **无实验验证**：作者指出贴壁模态会"使实验比较复杂化"，但本身未提供实验对照。

## 实现建议

- **实现难度**：中—高。需要 AFiD 或等价的柱坐标高阶有限差分求解器；**关键难点在 $r=0$ 处的坐标奇点**（必须用径向通量变量 $q_r=r\,u_r$ 求解）以及侧壁附近需要的极细网格（$N_\theta$ 达 512，$N_r$ 达 128，$N_z$ 随 $E$ 降到 384）。
- **预期性能**：本文的 DNS 规模为 $10^8$ 级 $Ra$ 下的三维柱坐标瞬态/统计求解，属 HPC 级别；**关键在于能否同时解析 Ekman 层 $O(E^{1/2})$ 与贴壁模态的 $\sim0.03\,d$ 薄层**——后者对 $r$ 方向分辨率要求远高于常规 RRBC。
- **适用场景**：
  1. **行星/恒星内部对流**（含自转、内部加热）——本文明确提及的应用背景；
  2. **旋转对流的稳定性判据修正**：凡是用横向周期 DNS/实验来推断"失稳阈值"的，都必须检查侧壁效应；
  3. **受限容器的对流实验设计**（尤其 $E\lesssim10^{-4}$ 的快速旋转）；
  4. **陀螺仪/旋转冷却系统**中的贴壁行波。
- **推荐结论**：✅ **推荐实现/推荐纳入认知**
  - 这是一篇**物理发现型**论文，价值在于一个反直觉的结论：**"贴壁模态可以让已经稳定的体相对流在有侧壁时继续输运"**。
  - **落地建议**：
    1. **实验/数值对照的必备检查项**：任何声称"旋转稳定了内加热对流"的结论，若实验容器有侧壁，就必须在文中说明侧壁构型——否则很可能把贴壁模态的能量输运误读为体相对流。
    2. **不需要解析完整三维也可以捕捉该模态**：模态主波数占涨落功率 90%–98%，若只需判断"贴壁模态是否存在及其漂移"，可考虑**降低方位分辨率但保留 $r$ 方向壁面加密**的降阶策略。
    3. **与 RRBC 壁模态的类比要谨慎**：虽然 $m\propto\Gamma$、逆行漂移、$\sim E^{1/3}$–$E^{1/4}$ 边界层尺度都相似，但 RRBC 的渐近公式针对**线性起始**且热驱动机制不同（RRBC 的壁模态贯穿全深度，本文的只在上半层被驱动）——论文明确说"不期待精确一致"。
    4. **竖直剖面 $\Gamma$ 无关性**是可利用的强结论：可以只在 $\Gamma=1$ 上标定剖面，再按 $1/\Gamma$ 的体积占比外推热输运。
