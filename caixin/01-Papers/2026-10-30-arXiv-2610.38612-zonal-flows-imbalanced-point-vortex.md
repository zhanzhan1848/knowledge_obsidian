## 核心贡献

> 在**不平衡（imbalance）的 Onsager 点涡气体**中，用**保持不平衡的湮灭-再注入 (AR)** 机制模拟外力与耗散，系统会**自组织**为：**低不平衡 → 大尺度相干偶极子 (dipole)**；**高不平衡 → 带状流 (zonal flow)**；并给出以 $(e,\mu,\eta)$ 描述的**非平凡平衡相图**，指出这一拓扑转变由**流体动力学剪切不稳定性**驱动。

1. **平衡相图**：在能量 $e$、角动量 $\mu$、涡量不平衡 $\eta$ 三参数空间中刻画 **dipole ↔ zonal** 的转变，是非平凡（存在三相区或特殊临界结构）的平衡图。
2. **AR 机制保持不平衡**：通过"相反符号涡旋接近到愈合长度以内即湮灭，随后在随机位置重新注入"的机制，**在破坏能量与角动量守恒的同时严格守恒不平衡 $\eta$**——这是与常规热力学"热浴"模型的关键区别。
3. **准绝热演化论证**：虽然 AR 破坏了守恒量，作者论证系统**沿平衡相空间准绝热地演化**（每个 $(e,\mu,\eta)$ 切片上先快速混合到局域平衡，再慢速漂移）。
4. **统计与流体力学双重视角**：既用 Onsager 统计力学（熵、混合区）刻画，又用**流体动力学剪切不稳定性**解释偶极子与带状流之间的选择。
5. **线性理论的意外适用性**：**Joyce–Montgomery 平均场理论**在"弱非均匀态"附近线性化得到的**强混合 (strong mixing)** 区内的线性结果，与带 AR 的数值模拟**出人意料地吻合**——作者明确指出线性理论在这里"surprising relevant"。

## 技术方案

### 核心思想

**Onsager 点涡模型**：二维无旋流由 $N$ 个点涡描述，涡旋强度 $\Gamma_i\in\mathbb{R}$（正负即旋向），动力学为 Hamiltonian 系统：

```math
\dot{z}_i=\frac{1}{2\pi}\sum_{j\neq i}\Gamma_j\,\frac{z_j-z_i}{\lvert z_j-z_i\rvert^{2}}
```

**不平衡 $\eta$**：同号涡与异号涡数量之差（归一化）。$\eta=0$ 为"平衡"气体，$|\eta|>0$ 意味着宏观**旋转/角动量**的偏好。

**Onsager 统计**：二维涡的熵可按相空间体积定义；**混合区**（同类涡相空间不发生交换的区域）与**不混合区**（有序态）对应 Onsager 的两类宏观行为。

**问题**：真实系统（旋转 Bose–Einstein 凝聚体）的外力（旋转）与耗散无法简单地由 Hamiltonian 描述；而**热浴（thermal bath）**式的单涡随机注入-消除会**破坏不平衡**，使问题退化。

**AR 机制（本文的关键建模选择）**：
- 取一个**愈合长度** $r_h$（物理上对应涡旋对的量子愈合长度）；
- 当一对**相反符号**涡旋靠近到 $r<r_h$ 时，二者**湮灭**；
- 随后在域内**随机位置**重新注入一对相反符号涡旋。
- 这样，涡旋对成对生灭 → **不平衡 $\eta$ 严格守恒**；而能量与角动量被随机化 → 模拟外力与耗散。

**自组织结果**：
- 在**正能量**（$e>0$）下，系统自组织为两种构型：
  - **低不平衡**：**大尺度相干偶极子**（一个大的正涡 + 一个大的负涡组成的对，携带整体旋转）；
  - **高不平衡**：**带状流 (zonal flow)**（沿某方向的**轴向对称**流动，中心线为偶极子的连线，垂直于平均旋转方向——即类似"甜甜圈"流型）。
- 偶极子↔带状流的转变被刻画为**$(e,\mu,\eta)$ 相空间中的拓扑转变**，且转变的物理机制被识别为**流体动力学剪切不稳定性**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Onsager 点涡动力学** | 2D 无旋流的降阶模型，$O(N^2)$ 直接求和，$O(N\log N)$ 用快速多极子 (FMM) |
| **AR（湮灭-再注入）** | 保持不平衡的耗散/驱动注入机制；成对湮灭 + 随机再注入 |
| **愈合长度 $r_h$** | AR 的空间尺度参数；控制涡旋对的湮灭概率与再注入的稀释效应 |
| **Joyce–Montgomery 平均场理论** | 点涡气体的宏观动力学理论（宏观密度场 + 守恒律的流体形式） |
| **弱非均匀态线性化** | 在 Joyce–Montgomery 理论关于弱非均匀态的线性化，得到"strong mixing"区内的线性演化 |
| **强混合 (strong mixing) 区** | 相空间中涡量分布高度混合的区域，允许使用统计力学描述 |

| **剪切不稳定性** | 带状流 vs 偶极子选择的物理机制（对应"极向不稳定"的经典猜想） |
| **流体极限** | 点涡系统到宏观 2D 无旋流（Euler）极限的连接 |

## 公式

### 1. 点涡动力学（Onsager，$\Gamma_i$ 可正可负）

```math
\dot{z}_i=\frac{1}{2\pi}\sum_{j\neq i}\Gamma_j\,\frac{z_j-z_i}{\lvert z_j-z_i\rvert^{2}},
\qquad z_i\in\mathbb{C},\quad \Gamma_i\in\mathbb{R}
```

### 2. 守恒量与不平衡

```math
E=-\sum_{i<j}\Gamma_i\Gamma_j\ln\frac{\lvert z_i-z_j\rvert}{L},
\qquad
L=\sum_{i<j}\Gamma_i\Gamma_j
```

```math
M=\frac{1}{2\pi}\sum_{i<j}\Gamma_i\Gamma_j
\ln\frac{\lvert z_i-z_j\rvert}{L},
\qquad
\eta=\frac{\lvert N_{+}-N_{-}\rvert}{N}\ \ (\text{不平衡})
```

其中 $L$ 是**Casimir**（Onsager 型 Casimir：$\sum_i\Gamma_i f(\Gamma_i)$ 为守恒），用于固定 $\sum\Gamma_i$、$\sum\Gamma_i^2$ 等。

**AR 机制的作用**：$\Gamma$ 的**对偶（pair）**湮灭与再注入保持 $\sum\Gamma_i$ 与 $\sum\Gamma_i^2$（因此 $\eta$）守恒，但**破坏 $E$ 与 $M$** → 系统被"热化"到给定 $(e,\mu,\eta)$ 切片。

### 3.  Joyce–Montgomery 平均场理论的流体形式（本质形式）

点涡的宏观极限给出类似 Euler 的守恒律（用宏观角速度场 $\omega(\mathbf{x},t)$ 与密度场 $\rho(\mathbf{x},t)$ 表示）：

```math
\text{质量（旋量）守恒:}\quad
\partial_t\omega+\mathbf{u}\cdot\nabla\omega=0
\quad \text{（无粘）}
```

```math
\text{动量:}\quad
\partial_t\mathbf{u}+(\mathbf{u}\cdot\nabla)\mathbf{u}
=-\nabla P
+\nabla\!\cdot\!\left(\mu_{\rm eff}\nabla\mathbf{u}\right)
+\text{体力}
```

```math
\text{涡粘性（散度部分）:}\quad
\partial_t\omega+\mathbf{u}\cdot\nabla\omega
=\nu_{\omega}\nabla^{2}\omega
+\text{(非线性涡拉伸项)}
```

带状流对应的宏观结构是**轴对称的**：$\partial_\theta\omega=0$ 且 $\omega$ 在轴向变化 → 形成"甜甜圈"型环流。

### 4. Onsager 熵与平衡态

```math
S_{\rm Onsager}\ \propto\ \sum_{\alpha}\Omega_{\alpha}\,\Phi(\alpha),
\qquad
\Omega_{\alpha}=\text{相空间中宏观密度为 }\alpha\text{ 的区域面积},
\qquad
\Phi(\alpha)=\alpha\ln\alpha-\alpha
```

最大熵原理：在给定 $(e,\mu,\eta)$ 下最大化 $S$ → 得到平衡宏观态；相图中的**相界**即为偶极子态与带状流态的分界。

### 5. 剪切不稳定性（线性化，判据层面）

对带状流背景 $\omega_{\rm zonal}(r)$ 做扰动 $\omega'=\phi(r)e^{i(m\theta-\omega_{\rm fr}t)}$，得到极向（剪切）不稳定性的特征值问题：

```math
\frac{d}{dr}\!\left[r\,\frac{d\phi}{dr}\right]
-\left[\frac{m^{2}}{r^{2}}+\frac{r}{\nu_\omega}\frac{d\omega_{\rm zonal}}{dr}\right]\phi
+\frac{m^{2}}{r^{2}}\,\frac{\omega_{\rm zonal}}{?}\cdots
=-\frac{\omega_{\rm fr}}{\nu_\omega}\phi
```

（此处仅给出**结构**：剪切不稳定性由背景涡度梯度 $\partial_r\omega_{\rm zonal}$ 与涡粘性 $\nu_\omega$ 共同控制；**具体特征值方程的形式与判据以原文为准**。）

**核心结论的形式化表达**：

```math
(e,\mu,\eta)\ \text{跨越相界}
\;\Longrightarrow\;
\text{偶极子态}\ \longleftrightarrow\ \text{带状流态},
\qquad
\text{驱动机制}=\text{流体动力学剪切不稳定性}
\]

### 6. 准绝热演化（AR 下的两时间尺度分离）

```math
\tau_{\rm mix}\ \ll\ \tau_{\rm drift},
\qquad
\text{快: 每个 }(e,\mu,\eta)\text{ 切片上混合到局域平衡};
\qquad
\text{慢: 沿相图慢速漂移}
```

### 7. 熵与自由能的一阶变分（弱非均匀态线性化）

在 Joyce–Montgomery 理论中，弱非均匀态的演化由自由能的一阶变分驱动：

```math
\partial_t\omega=\delta\mathcal{F}[\omega],
\qquad
\delta\mathcal{F}[\omega]=\nabla\cdot\!\left(\frac{\delta S_{\rm Onsager}}{\delta\omega}\,\nabla P_{\rm therm}\right)
+\text{(涡动量通量项)}
```

**弱非均匀态附近做线性化** → 给出"strong mixing"区内的**线性演化算子**，本文发现它与 AR 数值结果相符。

## 代码片段

```python
# 概念性伪代码：带 AR 机制的 Onsager 点涡模拟 + 相图扫描

import numpy as np

# ---------- 1) 点涡积分器（Barnes-Hut / 直接 O(N^2)） ----------
def integrate_point_vortices(z, Gamma, dt, healing_length=None, seed=None):
    """
    z: (N,2) positions; Gamma: (N,) signed circulations
    返回演化一步后的 (z, Gamma)；若启用 AR 则在核内做湮灭-再注入
    """
    N = len(z)
    rng = np.random.default_rng(seed)

    # --- 点涡速度（O(N^2)；大规模改用 FMM/Barnes-Hut）---
    dz = z[None,:,:] - z[:,None,:]                 # (N,N,2)
    r  = np.linalg.norm(dz, axis=-1)
    np.fill_diagonal(r, np.inf)                    # 排除自作用
    inv_r3 = 1.0/r**3
    v = np.einsum('j,ij,ijk->ik', Gamma, inv_r3, dz)   # i 涡的速度
    z = z + dt * v

    if healing_length is None:
        return z, Gamma

    # --- AR: 相反符号涡靠近到 r_h 以内 -> 成对湮灭 ---
    keep = np.ones(N, dtype=bool)
    removed_pairs = []
    for i in range(N):
        if not keep[i]: continue
        for j in range(i+1, N):
            if not keep[j]: continue
            if Gamma[i]*Gamma[j] < 0 and np.linalg.norm(z[j]-z[i]) < healing_length:
                keep[i] = keep[j] = False
                removed_pairs.append((Gamma[i], Gamma[j]))
    z, Gamma = z[keep], Gamma[keep]

    # --- AR: 随机位置再注入同量相反符号的一对（保持不平衡 eta）---
    for (g1, g2) in removed_pairs:
        # 在域内均匀随机位置注入；强度取被湮灭涡的平均强度，保持 sum(Gamma^2) 量级
        p1 = rng.uniform([0,0], domain_size)
        p2 = rng.uniform([0,0], domain_size)
        z     = np.vstack([z, p1, p2])
        Gamma = np.concatenate([Gamma, [g1, g2]])   # 符号相反 -> eta 严格守恒
    return z, Gamma

# ---------- 2) 观测量的定义 ----------
def observables(z, Gamma, domain_size):
    # 角动量（对质心）与能量
    zc = np.average(z, weights=Gamma**2, axis=0)
    r  = np.linalg.norm(z - zc, axis=1)
    E  = -np.sum(Gamma[:,None]*Gamma[None,:]*np.log(r[:,None]/r[None,:] + 1e-12)) / 2
    M  = np.sum(Gamma[:,None]*Gamma[None,:]*np.log(r[:,None]/r[None,:] + 1e-12)) / (4*np.pi)
    eta = abs((Gamma>0).sum() - (Gamma<0).sum()) / len(Gamma)
    return E, M, eta

# ---------- 3) 相图扫描：识别 dipole vs zonal ----------
def classify(z, Gamma, domain_size):
    """
    偶极子: 宏观角速度呈 (正,负) 偶极对；带状流: 宏观角速度轴对称(环状)
    -> 用粗分箱平均角速度后检查: 偶极 -> 反对称分量占优; zonal -> 关于某轴的轴对称
    """
    omega_field = bin_angular_velocity(z, Gamma, nbins=32)
    dip = symmetry_measure_dipole(omega_field)
    zon = symmetry_measure_axial(omega_field)
    return "dipole" if dip > zon else "zonal"

# ---------- 4) 主循环：沿 (e, mu, eta) 扫描 ----------
for eta_target in [0.05, 0.1, 0.2, 0.4]:
    for e_target in np.linspace(-0.5, 0.5, 11):
        z, Gamma = initial_condition(N=2000, eta=eta_target)
        for step in range(n_steps):
            z, Gamma = integrate_point_vortices(z, Gamma, dt=1e-3,
                                                healing_length=r_h)
            # 可选：能量/角动量的 Berendsen 型控制以沿相图切片漂移
        state = classify(z, Gamma, domain_size)
        record((e_target, mu_target, eta_target), state)

# ---------- 5) 与线性理论对照 ----------
# 在 Joyce-Montgomery 弱非均匀态线性化得到的算子上做相同初值的线性演化，
# 比较宏观角速度场的时间演化，与 AR 非线性模拟的偏差做定量对照

## 实验结论

- **数据集/算例**：**圆盘域内**不平衡 Onsager 点涡气体；正能态下的自组织演化；扫描 $(e,\mu,\eta)$ 相空间。
- **基线/对照**：
  - **Joyce–Montgomery 平均场理论**（弱非均匀态线性化，"strong mixing" 区的线性理论）作为解析对照；
  - **无 AR 的 Hamiltonian 点涡**（纯守恒）作为对照，用于显示耗散/驱动机制的必要性。
- **结果**：
  - **正能量下**：低不平衡 → **大尺度相干偶极子**；高不平衡 → **带状流 (zonal flow)**。
  - AR **破坏能量与角动量守恒**，但作者论证系统**沿平衡相空间准绝热演化**（混合快、漂移慢）。
  - **拓扑转变**在 $(e,\mu,\eta)$ 相图中被从**统计**与**流体力学**两个视角同时刻画；相图是**非平凡的**（不是简单的相界）。
  - 在"strong mixing"区（对 Joyce–Montgomery 理论关于弱非均匀态做线性化）内，**线性理论与带 AR 的数值模拟结果出人意料地相符**。
  - 偶极子/带状流之间的选择，被归因于**流体动力学剪切不稳定性**。
  - 动机来自**旋转 Bose–Einstein 凝聚体**实验（涡旋对合并、角动量转移）。

## 局限性

1. **AR 是人为的耗散/驱动代理**：虽然它保持了不平衡，但**真实 BEC 的物理**（涡旋对在愈合长度内的合并、涡旋-声子耦合、边界驱动）并不等价于"随机位置再注入"；随机再注入丢失了涡旋对的**角动量与相对位形**信息。
2. **"准绝热"是论证而非定理**：$\tau_{\rm mix}\ll\tau_{\rm drift}$ 的时间尺度分离依赖 AR 速率与混合速率的比值，论文未给出系统的参数扫描以界定该分离成立的区域。
3. **线性理论的适用性是经验性发现**：作者自承"surprising"； Joyce–Montgomery 线性化在弱非均匀态附近成立，但相图中**远离该区域**的行为仍需非线性处理，二者的边界未被系统刻画。
4. **宏观量的识别与分类**（dipole vs zonal）依赖数值后处理（分箱角速度场的对称性分析），**判据的客观性**依赖分箱分辨率；多涡团构型的分类可能有歧义。
5. **未与实验定量对照**：动机来自 BEC 实验，但摘要未报告与 BEC 图像/统计量的直接比较（缺乏可比的宏观诊断量，如密度分布的时间序列）。
6. **统计力学与流体极限的连接是单向的**：从点涡到宏观流的极限假定**空间尺度分离**良好；点涡数不足或涡核尺寸不可忽略时，$\eta$ 的宏观意义会退化。
7. **未涉及无旋/可压耦合与三维**：模型限于二维无旋；真实海洋/旋转流的三维可压效应不在范围内。

- **实现难度**：🟡 中（点涡积分 + AR 机制 + 后处理分类；核心难点在**守恒量监测**与**宏观分类的客观化**）。
- **预期性能**：
  - $O(N^2)$ 直接求和：$N\sim10^3\!-\!10^4$ 单核可接受；$N\ge10^5$ 需 **Barnes-Hut / FMM**，代价 $\sim O(N\log N)$；
  - AR 的湮灭检测若用双重循环会成为瓶颈，建议用**空间哈希/网格加速**找邻近反号涡对；
  - 建议用 **Cython/numba** 加速内层循环，Python 纯循环在 $N=10^4$ 时每次步进会到秒级。
- **适用场景**：
  - **旋转系统中动量输运的机制研究**（BEC 涡旋合并、超流体湍流、旋转几何约束下的 2D 湍流）；
  - **极向/剪切不稳定性的可控模型平台**（可调 $\eta$、$r_h$、$N$）；
  - **点涡数值方法的基准算例库**。
- **落地建议**：
  1. **每次步都监测 $E$、$M$、$\eta$**：$E$、$M$ 应当平稳随机游走（AR 耗散的特征），而 $\eta$ 应当**严格不变**——这是 AR 实现正确性的第一道检验。
  2. **成像对注入保持 $\Gamma$ 的符号与量级**：再注入时应使用被湮灭涡的强度（而非随机新值），否则 $\eta$ 虽守恒但 $\sum\Gamma^2$ 会漂移，改变混合速率。
  3. **做愈合长度扫描** $r_h\in\{0.01,0.05,0.1\}R$：这是 AR 的唯一空间控制参数，直接决定涡核（愈合区）密度与耗散强度；相图的定性结论应对 $r_h$ 稳健。
  4. **分类判据要客观化**：不要只用目视；建议用宏观角速度场的**多极展开**（$l=1$ 偶极分量 vs $l=0$ 单极/环状分量）之比作为标量指标，并报告其置信区间。
  5. **复现"线性理论够用"这一发现**：在弱非均匀态附近把 Joyce–Montgomery 线性化算子数值积分，与 AR 模拟对比宏观场的时间演化；若二者确实吻合，则可**大幅降低相图扫描的成本**（先线性、后非线性）。
  6. **对本知识库的价值**：与 [[2026-10-30-arXiv-2610.39064-dye-tracking-vortex-filament-geometry]]（涡丝几何 → 整体动力学量）和 [[2026-10-30-arXiv-2610.38743-reynolds-stress-attribution-nonorthogonal-vortex-representations]]（结构 → 动量通量装配）构成同一主题簇：**"用涡结构的统计/几何来组织动量输运"**。三篇分别从实验测量、湍流应力与准无旋统计三个层次切入，建议作为一组对照阅读。
