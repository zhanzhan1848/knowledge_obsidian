## 核心贡献

> 建立含**可溶性表面活性剂 + 弱黏弹性 + 温度梯度**的下降液膜模型：先用 **Orr–Sommerfeld 型**特征值问题 + 长波极限解析式分离出热 Marangoni、溶质 Marangoni 与弹性记忆三者对失稳阈值的**独立贡献**，再用**五场加权残差（weighted-residual）模型**描述有限振幅演化，并给出**守恒的体相-表面通量配对**（保证合并投影表面活性剂库存严格守恒）。

1. **三个物理机制在阈值中解耦**：长波增长率系数
   $$\mathcal{G}=\tfrac{2}{15}ReF^2-\tfrac{F\cot\beta}{3}+\tfrac{Re\,\Upsilon F^2}{3}-\tfrac{3ReM_1\Gamma_e d}{4+3d}+\tfrac{ReM_2Bi}{2(1+Bi)^2}$$
   ——**热 Marangoni 失稳、溶质 Marangoni 稳定、弹性记忆失稳**三项显式可分离。
2. **临界 Reynolds 数的三次方程形式**（给定 $\mathcal A$）：
   $$\mathcal{A}y^3+(Re/Fr^2)^{1/3}\Upsilon_\nu y-\cot\beta=0,\qquad Re_c=y^3$$
   → $\mathcal A>0$、$\Upsilon_\nu\ge0$、$0<\beta<\pi/2$ 时**存在唯一正根**。
3. **两个 Marangoni 应力作用方式不同（本文最重要的物理结论）**：
   - **溶质 Marangoni**（$M_1$）：抬高阈值、**缩小不稳定波数带**、降低最大增长率并将其移向长波；非线性上降低主峰高度、减小波幅。
   - **热 Marangoni**（$M_2$）：**提高最大增长率**，但**高波数端的截断反而缩短** → 「更强放大」与「更宽不稳定带」**不等价**。
4. **弹性记忆的效应依赖于边界条件**：清洁膜（$M_1=M_2=0$）中随 $\Upsilon_\nu$ 增大长波起始点降低，但**中性曲线在更高 Re 处交叉**——即「降低起始点」并不描述整条中性边界；加入 Marangoni 后（$M_1=0.2,M_2=2$）交叉现象消失。
5. **守恒性**：体相与表面输运方程写成**相容通量**形式，使合并投影库存
   $$\partial_t(\chi+hc)+\partial_x\!\left(\tfrac{33}{40}\tfrac{q\chi}{h}+cq\right)=\dots-\tfrac{3}{Pe_b}\tfrac{\chi}{h^2}-\dots$$
   在周期域上**精确解析守恒**。

## 技术方案

### 核心思想

**热-溶质耦合**：表面张力同时依赖表面活性剂浓度 $\Gamma$ 与温度 $T$：
$$\sigma=\sigma_0-\sigma_\Gamma(\Gamma-\Gamma_e)-\sigma_T(T-T_\infty)$$
两种依赖各自产生一个 Marangoni 应力：**溶质型**（$\propto\nabla_s\Gamma$）与**热型**（$\propto\nabla_s T$）。它们对界面运动的反馈方向**相反**。

**弱黏弹性**：应力响应用 **Walters 液体 B″（短记忆）**模型：
$$\bm\tau=2\mu\bm D-2\mu\frac{\Upsilon_0}{\mu}\left(\frac{\partial}{\partial t}+u\cdot\nabla\right)\bm D+\dots$$
短记忆要求材料时间与变形率/频率的乘积很小。

**可溶表面活性剂需要两套浓度**：体相 $C(x,z,t)$ 与表面 $\Gamma(x,t)$，通过 Langmuir 吸附-脱附交换：
$$J_{bs}=k_1\left(1-\tfrac{\Gamma}{\Gamma_\infty}\right)C_s-k_2\Gamma,\qquad J_{bs}=-D_b\nabla C\cdot\bm n$$

### 关键技术

| 技术 | 说明 |
|------|------|
| 无量纲化 | 长波尺度：$x^*=2\pi x/\hat\lambda$、$z^*=z/\hat h_N$；$\varepsilon=2\pi\hat h_N/\hat\lambda\ll1$；特征速度取 Nusselt 速度 $\hat V=g\sin\beta\,\hat h_N^2/(2\nu)$ → **$Re/Fr^2=2$ 被固定** |

| 线性稳定性 | Orr–Sommerfeld 型广义特征值问题，Chebyshev 谱配置（Gauss–Lobatto 点 $\xi_j=-\cos(j\pi/N_z)$，$D_z=2D_\xi$），矩阵阶数 $3N_z+5$，QZ 分解 |

## 公式

### 1. 控制方程（无量纲，长波尺度）

```math
\varepsilon Re\left(\frac{\partial u}{\partial t}+u\frac{\partial u}{\partial x}+w\frac{\partial u}{\partial z}\right)
=\frac{Re}{Fr^{2}}+\left(\varepsilon^{2}\frac{\partial\tau_{xx}}{\partial x}+\frac{\partial\tau_{xz}}{\partial z}\right)
```

```math
\varepsilon^{2}Re\left(\frac{\partial w}{\partial t}+u\frac{\partial w}{\partial x}+w\frac{\partial w}{\partial z}\right)
=-\frac{Re}{Fr^{2}}\cot\beta+\varepsilon\left(\frac{\partial\tau_{zx}}{\partial x}+\frac{\partial\tau_{zz}}{\partial z}\right)
```

### 2. 表面张力与 Marangoni 应力（切向条件）

```math
\sigma=\sigma_{0}-\sigma_{\Gamma}(\Gamma-\Gamma_{e})-\sigma_{T}(T-T_{\infty})
```

```math
\left[\left(1-\varepsilon^{2}h_x^{2}\right)\tau_{xz}+\varepsilon^{2}(\tau_{zz}-\tau_{xx})h_x\right]\left[1+\varepsilon^{2}h_x^{2}\right]^{-1/2}
=-\varepsilon Re\left[M_{1}\Gamma_x+M_{2}\left(T_x+T_z h_x\right)\right]
```

### 3. 表面活性剂输运（界面 + 交换）

```math
\varepsilon\left[\frac{\partial(s_\varepsilon\Gamma)}{\partial t}+\frac{\partial(s_\varepsilon\Gamma u_s)}{\partial x}\right]
=\frac{\varepsilon^{2}}{Pe_s}\frac{\partial}{\partial x}\left(\frac{1}{s_\varepsilon}\frac{\partial\Gamma}{\partial x}\right)+s_\varepsilon k_s\left[\kappa(1-\Gamma)C-\Gamma\right]
```

```math
\frac{1}{Pe_b\sqrt{1+\varepsilon^{2}h_x^{2}}}\left(\varepsilon^{2}h_x C_x-C_z\right)=k_s\left[\kappa(1-\Gamma)C-\Gamma\right]
```

### 4. Orr–Sommerfeld 型特征值问题（含弱黏弹修正）

```math
\left[1-ik\frac{Re^{1/3}\Upsilon_{\nu}}{(Re/Fr^{2})^{2/3}}\left(U_{B}-\alpha\right)\right]\left(D^{2}-k^{2}\right)^{2}\psi
=ikRe\left[\left(U_{B}-\alpha\right)\left(D^{2}-k^{2}\right)-D^{2}U_{B}\right]\psi
```

```math
\left[\left(D^{2}-k^{2}\right)-ikPe_{b}\left(U_{B}-\alpha\right)\right]\mathcal{C}=0,
\qquad
\left(D^{2}-k^{2}\right)\Theta-ikRePr\left[\left(U_{B}-\alpha\right)\Theta-DT_{B}\psi\right]=0
```

### 5. 长波增长率系数与阈值

```math
\lambda(k)=-ik\alpha(k)=-iFk+\mathcal{G}k^{2}+O(k^{3})
```

```math
\mathcal{G}=\frac{2}{15}ReF^{2}-\frac{F\cot\beta}{3}+\frac{Re\,\Upsilon F^{2}}{3}
-\frac{3ReM_{1}\Gamma_{e}d}{4+3d}+\frac{ReM_{2}Bi}{2(1+Bi)^{2}},\qquad d=\kappa(1-\Gamma_{e})^{2}
```

（$\mathcal{G}=0$ 为长波中性条件；热项**失稳**，溶质项**稳定**。）

```math
Re_{c}=\frac{\cot\beta}{\frac{2}{5}\left(\frac{Re}{Fr^{2}}\right)+\frac{\left(\frac{Re}{Fr^{2}}\right)^{1/3}\Upsilon_{\nu}}{Re_{c}^{2/3}}+\left(\frac{Re}{Fr^{2}}\right)^{-1}\left[\frac{3M_{2}Bi}{2(1+Bi)^{2}}-\frac{9M_{1}\Gamma_{e}(1-\Gamma_{e})^{2}\kappa}{4+3(1-\Gamma_{e})^{2}\kappa}\right]}
```

```math
\mathcal{A}Re_{c}+\left(\frac{Re}{Fr^{2}}\right)^{1/3}\Upsilon_{\nu}Re_{c}^{1/3}=\cot\beta
\quad\Longleftrightarrow\quad
\mathcal{A}y^{3}+\left(\frac{Re}{Fr^{2}}\right)^{1/3}\Upsilon_{\nu}y-\cot\beta=0,\quad Re_{c}=y^{3}
```

Newtonian 无表面活性剂极限：$Re_c=\tfrac52(Re/Fr^2)^{-1}\cot\beta=\tfrac54\cot\beta$。

### 6. 基态

```math
U_{B}(z)=\frac{Re}{Fr^{2}}\left(z-\frac{z^{2}}{2}\right),\qquad P_{B}(z)=-\frac{\cot\beta}{Fr^{2}}(z-1),\qquad h_B=1
```

```math
T_B(z)=1-\frac{Bi\,z}{1+Bi},\qquad C_B=C_e=\frac{\Gamma_e}{\kappa(1-\Gamma_e)},\qquad \Gamma_B=\Gamma_e
```

```math
\Gamma_e=\frac{1}{2}\left[1+S_t+\frac{1}{\kappa}-\sqrt{(S_t-1)^{2}+\frac{2}{\kappa}(S_t+1)+\frac{1}{\kappa^{2}}}\right],\qquad S_t=C_e+\Gamma_e
```

（$\kappa\to\infty$ 时 $\Gamma_e\to\min(S_t,1)$、$C_e\to\max(S_t-1,0)$——**强吸附本身并不等于不溶性表面活性剂极限**。）

### 7. 非线性五场模型（闭合系统）

```math
h_t+q_x=0
```

```math
q_t+\partial_x\!\left[\frac{9}{7}\frac{q^{2}}{h}+\frac{5}{12Re}\left(\frac{Re}{Fr^{2}}\right)\cot\beta\,h^{2}+\frac{5}{4}\left(M_{1}\Gamma-2M_{2}\frac{\phi}{h}\right)\right]=\frac{1}{7}\frac{q}{h}q_x+\frac{5Ka}{6Re^{5/3}}\left(\frac{Re}{Fr^{2}}\right)^{1/3}h\,h_{xxx}+\frac{5}{2Re}\left(\frac{1}{3}\left(\frac{Re}{Fr^{2}}\right)h-\frac{q}{h^{2}}\right)+\cdots
```

```math
\phi_t+\partial_x\!\left(\frac{27}{20}\frac{q\phi}{h}\right)=\frac{7}{40}\frac{\phi}{h}q_x-\frac{3}{RePr}\left[Bi\left(-\frac{1}{2}+\frac{\phi}{h}\right)+\frac{\phi}{h^{2}}\right]+\cdots
```

```math
B_t+\partial_x F_b=-\frac{3\chi}{Pe_b h^{2}},\qquad
\Gamma_t+\partial_x F_s=\frac{3\chi}{Pe_b h^{2}}
```

（两式相加即得合并库存守恒。）

```math
\phi=\int_{0}^{h}[T(x,z,t)-\theta(x,t)]\,dz=\frac{1}{2}(1-\theta)h,\qquad \theta=1-\frac{2\phi}{h}
```

```math
a_q(h)=1-\frac{5\Upsilon}{2h^{2}}=1-\frac{5\Upsilon_{\nu}}{2(FRe)^{2/3}h^{2}}\neq 0
```

（显式解出 $q_t$ 所需的代数条件，**与短记忆限制是不同的事**。）

### 8. 短记忆有效性判据

```math
Wi=\frac{\Upsilon_{0}}{\mu}\frac{\hat V}{\hat h_N}=Re\,\Upsilon=\frac{\Upsilon_{\nu}Re^{1/3}}{F^{2/3}},\qquad FWi\ll1
```

## 实验结论

### 6.1 弹性记忆（$M_1=M_2=0$）

- **增大 $\Upsilon_\nu$ 降低长波起始点**（与 Eq. (49) 中弹性项符号一致）。
- 但在**更高 Reynolds 数处中性曲线发生交叉** → 交叉之后，增大弹性参数反而**降低极限不稳定波数**。
- $Re=30$ 的增长率曲线（$\Upsilon_\nu=0,0.2,0.4$）：较大弹性参数**增大最大放大率**，对 $k\approx0.2$ 附近的零交叉**影响很小**，但在更高波数上同一排序给出**更强的衰减**。
- 结论：弹性记忆在本比较中**促进长波表面不稳定性**，但对短波耗散的影响方式**不同**。

### 6.2 两个 Marangoni 应力（$Re=30$）

| 机制 | 对峰值增长率 | 对不稳定波数带 | 对阈值 |
|---|---|---|---|
| **热** $M_2=0,2,5$（$M_1=0$，$\Upsilon_\nu=0.2$） | **增大** | 高波数端**变短**（带变窄） | 降低 |
| **溶质** $M_1=0,0.2,0.5$（$M_2=0$，$\Upsilon_\nu=0.2$） | **减小**，且峰值**移向长波** | **缩小** | **抬高** |

- 明确强调：**「更强放大」与「更宽不稳定带」不是等价描述**。热强迫增强了最被放大的扰动，但**并未把不稳定性延伸到更短的波**。
- 溶质机制解释：扰动产生的表面浓度梯度所产生的 Marangoni 应力**反抗**了导致进一步放大的界面运动。
- 在最大的 $M_1$ 下**仍保留正的长波增长率** → 膜**未被完全稳定**。
- 两者同时存在（$M_1=0.2,M_2=2$）：增大 $\Upsilon_\nu$ 在所示 Re 范围内降低起始点**并抬高中性波数**，且**不出现交叉**——说明弹性记忆的效应**不能**与界面输运条件脱耦来一句话概括。

### 6.3 非线性波发展（参考算例 $\Upsilon_\nu=0.4,M_1=0.2,M_2=2$）

- 初期：表面扰动增长，最大/最小厚度分离；随后增长放缓，**极值趋于近似恒定**（**振幅饱和**）。
- 空间剖面：**显著的主峰 + 薄侧的较小毛细波纹**；主峰在不同快照间位移与**向下游传播**一致。
- 流量峰值伴随表面主峰；表面与体相表面活性剂分布强烈非均匀（平流 + 扩散 + 吸附-脱附交换的联合结果）。
- **界面温度沿波变化，但其相对变化小于浓度场** → 即使高度极值已近饱和，**热场仍在为局部 Marangoni 应力做贡献**。
- **重要限定**：近似静止的极值只表明**显示区间内的振幅饱和**，**不表明每个场都以同一常速平移**；永久行波需要共同的移动窗剖面或等价的行波方程残差检验 → 作者只称之为「已发展的非线性波」。

### 6.4 Marangoni 应力对已发展剖面的影响

- **$M_1=0.2,0.3,0.5$**：$M_1$ 增大 → 主峰更低、波谷更浅、**毛细波纹减弱**；流量峰值与表面活性剂库存峰值均下降。与线性上对表面波分支的抑制一致（但**线性增长率本身不决定最终波幅**）。
- 大 $M_1$ 案例中界面温度变化更弱——这**不应**被解读为壁面加热的改变（$M_1$ 控制的是溶质对表面应力的贡献），而应理解为「改变一种界面应力如何修改耦合的水动力与输运场」。
- **$M_2=2$ vs $M_2=0$**：非零 $M_2$ 案例有**更大的高度范围**与**更大的流量/库存峰值** → 热 Marangoni 应力**强化**了非线性响应（与线性峰值增长率的增加一致，但**不意味着所有热效应都可归结为线性增长率的改变**）。
- **$M_2=0$ 并不等于等温膜**：$M_2=0$ 只移除温度对表面应力的贡献，**热平衡方程仍在、温度仍非均匀**。这一区分对解读温度面板与残余溶质 Marangoni 应力是必要的。

### 6.5 弹性贡献与模型适用范围（关键的自我限定）

- $\Upsilon_\nu=0.4$ 案例发展出**更大的表面变形**、更强的流量与浓度峰值、更显著的毛细结构；高度历史趋于**不同的后期水平**。
- **但**：在 $Re=15$、$F=2$、$\Upsilon_\nu=0.4$ 下，$Wi\simeq0.62$、$FWi\simeq1.24$，**后者并不小**。因此这些非线性结果是**所保留本构模型的形式性预测**，而不是对弱记忆液体在这些参数下的渐近受控计算。
- **守恒 ≠ 精度**：通量构造确保吸附/脱附只**重新分配**表面活性剂而不凭空产生；它**不**确立所假定的深度剖面、长波截断或某一离散化的精度。波形的近似吻合本身也**不能**检验合并库存。

## 局限性

1. **短记忆近似在所用参数下已被突破**：$FWi\simeq1.24\not\ll1$（$Re=15$，$\Upsilon_\nu=0.4$）。作者明确把大弹性参数结果称为「被截断的本构方程的**形式性预测**」，而非「对强弹性流的受控延拓」。
2. **长波截断**：$\varepsilon=2\pi\hat h_N/\hat\lambda\ll1$，保留 $O(\varepsilon)$ 惯性、$O(\varepsilon^2)$ 粘性扩散、$O(\varepsilon^3)We$ 毛细项；不适用于短波主导的场。
3. **永久行波未被证实**：仅观察到振幅饱和，**没有**共同的移动窗剖面或行波残差检验；作者明确不做行波速度推断（剖面对比亦「未指定共同快照时间」）。
4. **守恒性只在解析层面建立**：论文未提供库存随时间的数值历史，因此**不推断**数值守恒到某一容差。
5. **参数为「无量纲比较族」而非特定聚合物溶液的标定**：有量纲实现需要相容的热、表面活性剂与流变系数。
6. **界面温度在 $M_2=0$ 时仍非均匀**，容易被误读为「等温」；只有去掉整个热方程才是等温极限。
7. **$M_1$ 增大会降低最终波幅**，但这只是「所考察算例」的结果，不能直接外推为普适单调性。

## 实现建议

- **实现难度**：中高。线性部分（Chebyshev + QZ）实现直接；非线性五场模型需实现长波降阶、加权残差投影、相容通量与 $q_t$ 的隐式求解（含代数条件 $a_q(h)\neq0$）。
- **预期性能**：线性增长率 $k\alpha_i$ 与中性曲线在 $Re=30$ 下与理论一致；临界 $Re_c$ 由三次方程显式给出（唯一正根）；非线性在 $L=300$、$N_x=1024$、$\Delta t=2\times10^{-4}$ 下给出稳定的振幅饱和剖面（主峰 + 毛细波纹）。
- **适用场景**：
  1. **涂布/涂层工艺稳定性分析**：含表面活性剂与温降的下降液膜（如平板涂布、壁纸涂层、薄膜浇铸）的对流失稳预测。
  2. **含表面活性剂的减阻/传热液膜**：评估 Marangoni 应力对传质与波动的调控。
  3. **弱黏弹性聚合物流膜的失稳阈值评估**：如处理液、涂层流变。
  4. **作为 Marangoni 数值基线**：本文明确是 D'Alessio 等 (Newtonian、纯热溶质) 的推广。
- **落地建议**：
  1. **务必先检查短记忆判据 $FWi\ll1$**。本文在 $Re=15,\Upsilon_\nu=0.4$ 下已经 $FWi\simeq1.24$，此时结论只能作定性/形式性使用。若要定量，必须降低 $\Upsilon_\nu$ 或提高 $Re$ 使 $FWi$ 变小。
  2. **必须沿表面波分支（$k\to0$ 时 $\alpha\to F$）连续化特征值**，而不是在整个谱上无约束最大化 $k\alpha_i$——否则会选到超出本构有效范围的快模态。这是本文反复强调的一点。
  3. **区分「$M_2=0$」与「等温」**：前者只去掉温度的 Marangoni 贡献，热方程仍在；解读温度面板时必须记住。
  4. **同时报告相对误差与绝对误差**（本文在 FNO 那篇中的做法）——此处对应地，要同时报告「增长率」和「波幅」，因为**线性增长率不决定最终波幅**。
  5. **不要用剖面对比推断行波速度**：本文明确说明不同算例的剖面对比「未指定共同快照时间」，故不可用于波速推断。
  6. **守恒性需独立数值检验**：解析恒等式 $B_t+\partial_xF_b$ 与 $\Gamma_t+\partial_xF_s$ 的耦合保证了守恒，但若要验证具体离散实现的守恒精度，需另外做库存历史测试（论文未做）。
  7. **与本库关联**：与 [[FNO-Standing-Waves-Solution-Operator]]（2610.36747）同为「自由面/界面流体」的机器学习与解析建模代表——一篇用 FNO 学解算子，一篇用加权残差做长波降维，正好构成「数据驱动 vs 物理降阶」的方法论对照。

## 推荐结论

> **⚠️谨慎**（方法学扎实、物理结论清晰，但弹性部分的定量解释受短记忆近似限制）。
>
> - 支持：三个物理机制在长波阈值中解耦、临界 $Re_c$ 有闭式三次方程、两个 Marangoni 机制的作用方式差异明确（溶质稳定、热失稳但带宽变窄）、体相-表面通量配对给出严格的守恒性——这些结论对设计含表面活性剂的液膜工艺是可直接使用的。
> - 关键保留：参考算例中 $FWi\simeq1.24$，**不满足短记忆判据**，因此 $\Upsilon_\nu=0.4$ 的非线性结果是「被截断本构方程的形式性预测」；永久行波与数值守恒到指定容差**均未建立**。用于工程设计时，请把 $M_1$、$M_2$、$\Upsilon_\nu$ 的结论限制在定性层面，或重新标定以满足 $FWi\ll1$。
> - 落地建议：优先复用「长波阈值 + 分支连续化 + 加权残差五场模型 + 相容通量」这一整套结构；最需要本地复核的是短记忆有效性区间与守恒性的数值验证。
