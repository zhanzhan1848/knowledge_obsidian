## 技术要点分组

### 🔧 数值方法（Riemann 求解器 / 高阶格式 / 有限体积）

**Anchored HLLD**（2610.31958）
- 核心：hypoelastic 弥散界面模型中，剪切系数 **ρ(G+τ_xx)** 进入特征结构，**无法**像 Kapila 类模型的体积分数项那样外置
- 方法：面双次 HLLD 扇求值，各自锚定相邻单元中心态；每单元从**锚定到自身状态**的通量推进
- 层次：**HLL → HLLC → anchored HLLD**（波解析能力递增）
- 证明：重构阶一致性、精确组分质量守恒、光滑场上切向动量/能量漂移消失
- 实现：开源求解器 **MFC**；3D 激波-椭球算例验证全部六个应力分量

**AUSM⁺-upH + 偏差格式**（2610.31836）
- 双问题拆解：① 低马赫下迎风格式声速型过耗散 ② 离散化破坏静力平衡产生虚假运动
- 解法：改进 AUSM⁺-up 通量（AUSM⁺-upH）+ 变量偏差分解（背景静力态 + 扰动）
- 框架：**3D 压缩 Euler + 重力**、**高阶 DFR**、**三阶指数时间积分器**
- 效果：静力平衡残差降低**数个量级**，**地形上方改善最显著**

**应变梯度颗粒介质模型**（2610.31738）
- Hertz 接触 → 均质化（局部周期 + Cauchy-Born）→ 含一阶+二阶梯度的连续模型
- 双曲性分析：特征值/特征向量，给出**受限变形域内**的良定性条件
- 纵/横波速度解析式，**随深度变化**；与 DEM 对比验证

### 📊 数据压缩与湍流后处理

**空-时相关压缩**（2610.32427）
- 突破：相关系数矩阵跨空间+时间，比 snapshot POD **大两个数量级**
- 算法：随机化区间查找器 + **通信规避层次 QR（CAQR）**，GPU 加速、分布式
- **核心洞见**：**模态 TKE 预算项比场误差/单点误差敏感得多**
- 定量标度：线性预算项 ∝ 丢弃能量^0.8；三重传递 ∝ 丢弃能量^(>1)
- 近壁耗散与尺度间传递退化最严重 → **共同决定可接受压缩上限**
- 耗散误差局限于**粘性底层**，由**高阶模态**携带

### 🤖 机器学习与代理模型

**Neural Basis Method (NBM)**（2610.32167）
- 直击两大缺陷：小 PDE 残差 **≠** 小解误差；随规模增长扩展性差
- 原则："**表示-再投影**"——固定神经基定义表示空间，控制方程投影决定系数
- 同一组基 = 参数化解流形的**公共坐标** → 算子学习变为参数→系数映射，**去除显式空间依赖**
- 不可压仅速度形式 → 残差提供**后验速度误差估计** → **认证的、无需数据的**训练目标

**CoPiT**（2610.32299）
- PiT 几何骨干 + **多阶段 FiLM** 注入全局条件向量（使参数化调制**显式化**）
- vs Transolver：AirfRANS **表面损失 ↓54%、体积损失 ↓24%**；BlendedNet++ 归一化测试 MSE **全场最低**
- 消融：FiLM 普遍优于拼接，但**最优插入位置依赖任务**

**PINN 自引力湍流**（2610.32840）
- 关键量化：**训练成本 128³ → 1024³ 仅增 < 25%**（成本-分辨率解耦）
- 对标 Athena++，覆盖 2D/3D、亚声速/超声速、多个自由落体时间

**"湍流要算对：空间与时间"**（2610.32601）
- 28 TB 级单次 DNS + 神经网络双重探针
- **空间评估与时间评估可能相互矛盾**（对数值记录和"学习到的表示"皆然）
- 诉求：ML 社区应把 (3+1) 维湍流当作**四维现象**

### 🔬 实验诊断与反问题

**CBTV 彩色豆追踪测速**（2610.31883）
- 致密颗粒流中帧间位移接近/超过颗粒间距 → 常规 PTV 身份丢失
- 方法：**先匹配邻接彩色颗粒"星座"（星团级）**，**再逐个分配残余**；互相关运动先验引导
- 对标 **12 种基线**（经典 linker / GNN / Transformer）× **15 组 DEM 仿真 59 算例**（精确 ground truth）
- 优势区间：每帧位移 **0.5–2 倍颗粒间距**；> 2–3 直径/帧则体运动补偿型更优
- 收益：**显著降低对超高帧率的硬件要求**，且免训练

**PINN 毛细弯液面**（2610.31963）
- 理论下界：经典毛细通量平衡给出**内区+壁面残差损失的下界**，任意正采样密度下成立
- 关键发现：**非存在区（低于 Concus-Finn 临界角 45°/60°）网络损失仅为下界的 1.6–1.9 倍** → PINN **静默失败**
- 机制：小内区残差与**壁面通量亏损**共存（拐角处相邻接触角要求的通量超过有限斜率图像所能提供）
- 实践要求：**内区残差与壁面残差必须分开评估**，否则误判收敛

**敏感性引导的 PINN 参数反演**（2610.32668）
- 两步法：**先敏感性分析（系数级+解级）→ 再反演**，事先判定各参数反演难度
- KdVB 方程 + 8 个物理参数；粘性/气泡初始半径/密度/声速/压力误差 **0.8–2.1%**
- **表面张力系数完全无法估计、多方性指数仅部分收敛** —— 与敏感性预判**完全一致**
- 方法论价值：应作为 PINN 反问题的**标准实践**

**Sobol 不确定度分析（街道峡谷）**（2610.32631）
- PCA + MLP 代理使 **24 参数全局 Sobol** 可承受
- 典型不确定度：**湍流封闭常数 + 进口湍流剖面**主导三场变异性
- 弱通风：其余不确定度减半 → **太阳强迫**主导温度；减至四分之一 → 主导浓度
- **强通风下冠层永不超过封闭常数**（即使主导常数已知到 ±5%）
- 空间峰值：路面高度 + 峡谷壁面

### 🛠️ 工具与其他

- **IMRFit**（2610.32119）：惯性微空化流变测量的交互式反演平台（Python 桌面应用），内置 Neo-Hookean KV + 广义 Maxwell-Ogden，支持 JSON 描述符 + Python 求解器扩展
- **热涡度三元组**（2610.32140）：ω = ∇×q 分解为轨道旋转 R + 自旋 S；提出 **BHVF**（边界热涡度通量），2D 稳态下完全归因于净热流切向分量偏离 Fourier 热流
- **主动粒子 Lorenz 吸引子**（2610.32640）：定常多涡流场中，位置-朝向耦合构成 3D 自治系统 → 物理空间直接可见混沌
- **Euler-Poincaré + 规范理论**（2610.32973）：缺陷-背景场守恒耦合演化；规范理论消除缺陷密度定义歧义
