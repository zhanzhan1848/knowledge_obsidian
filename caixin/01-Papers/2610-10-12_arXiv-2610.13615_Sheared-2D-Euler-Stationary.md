## 核心贡献

> 提出非平衡统计力学框架，**不显式求解时变 Euler 方程**即可预测剪切 2D Euler 流体的渐近涡量分布

1. 构造 Vlasov 方程的 self-consistent ansatz 直接得到 stationary 流函数
2. 揭示剪切 2D 流体弛豫的"核-晕"结构：core 被高能态完全填充，halo 占据低能区
3. 为 Kelvin-Helmholtz 不稳定性的饱和提供统计基础

---

## 技术方案

### 核心思想

把连续涡量场视为大量离散涡旋量子的统计系综。借鉴涡旋气体动力学，通过构造 Vlasov 的稳态解绕过时间演化。

### 关键技术

| 技术 | 说明 |
|------|------|
| Vlasov 框架 | 涡量场 f(x,y,t) 的相空间输运方程 |
| self-consistent ansatz | 直接构造 f 的稳态形式 |
| 能量填充分析 | 高能态 occupation inversion |
| 核-晕结构 | core + halo 的双区模型 |

---

## 公式

```math
∂f/∂t + {ψ, f} = 0 (Vlasov)
ψ stationary: ∇² ψ = -ω(x,y)
ansatz: f = Θ(E_max - E(μ,J)) → 分布满填充
```

---

## 实验结论

- **数据集**: 解析框架 + 与 2D KH 模拟比对
- **基线**: 时间依赖 Euler 数值积分
- **结果**: 
  - 预测 core 完全占据（population inversion）
  - halo 占据低能态
  - core-halo 普遍性：2D 湍流饱和的统计结果
  - 应用：木星大红斑、KH 云系

---

## 局限性

- 仅 inviscid 2D Euler，未覆盖 Navier-Stokes 黏性效应
- 稳态假设存在性依赖于初始剪切分布
- Vlasov 不显式给出时间到达 stationarity 的动力学路径
