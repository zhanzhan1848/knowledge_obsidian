## 核心贡献

> 在**简化 Phan-Thien-Tanner (sPTT)** 黏弹性流体的**通道流与管流**中，发现了**纯弹性中心模态失稳（purely elastic centre-mode instability）**——在**宽范围的聚合物浓度**与**远低于 Oldroyd-B/FENE-P 预测的 Weissenberg 数**下即可出现；由于 sPTT 与 FENE-P 具有**完全相同的定常流变与层流剖面**，这一对比表明**中心模态失稳的存在性由流体的瞬态流变响应决定，而非定常流变**。

1. **在管流中也发现纯弹性失稳**：此前 Oldroyd-B / FENE-P 模型预测该类失稳仅限通道流中的**超稀溶液 + 极高 Weissenberg 数**，且**管流中从未报道过纯弹性失稳**；本文在 sPTT 的**通道与管流两种几何**中均发现。
2. **失稳发生条件大幅放宽**：跨越**宽范围的聚合物浓度**，且在**显著更低的 Weissenberg 数**下即可出现（相对 Oldroyd-B 的预测门槛）。
3. **关键对照实验（模型判别）**：sPTT 与 FENE-P **定常流变与层流剖面完全相同**，但对失稳给出**相反的预测**——由此得出结论：**中心模态失稳的存在与否由瞬态（时间依赖）流变响应决定**。
4. **实验可达性论断**：结果提示纯弹性中心模态失稳**在现实流动条件下可被观测**（不局限于极端参数）。
5. **提供 constitutive model 判别工具**：该失稳的存在性可作为**区分不同本构模型**的实验判据。

## 技术方案

### 核心思想

黏弹性流体在压力驱动平行剪切流中的**纯弹性失稳**（purely elastic instability）是"弹性湍流"（elastic turbulence）研究的核心现象之一。近年工作识别出**空间局域化的中平面应力结构**（midplane stress structures）作为压力驱动黏弹性流中混沌行为的**构造基元**，并推测这些相干结构源自层流态的一个**线性中心模态失稳**（linear centre-mode instability）——中心模态（centre mode）是一种特殊的中性稳定模态：所有特征值为**纯虚数**（实部为零），失稳通过**模态相互作用**实现。

困难在于：在**惯性可忽略**的低 Re 弹性流极限下，经典 **Oldroyd-B** 与 **FENE-P** 模型预测该失稳只出现在：
- 通道流中，且必须是**超稀聚合物溶液**；
- 且要求**极大的 Weissenberg 数** $\mathrm{Wi} = \lambda U/L \gg 1$。

而**管流中从未被报道过**纯弹性失稳——这本身就是一个悬而未决的问题：管流在几何上比通道流更"圆"，其应力分布与中心模态结构不同。

本文改用**简化 Phan-Thien-Tanner (sPTT)** 模型。sPTT 的特点：聚合物应力满足
$$\boldsymbol{\tau} + \lambda \left(\frac{\partial \boldsymbol{\tau}}{\partial t} + \boldsymbol{u}\cdot\nabla\boldsymbol{\tau}\right) = \eta_p\left(2\boldsymbol{D} + \frac{\alpha}{\mathrm{Wi}}\boldsymbol{\tau}\right)$$
其中 $\alpha$ 项是**非线性应力松弛**（$\boldsymbol{\tau}$ 随其自身大小加速松弛）。

本文最漂亮的一点是**模型判别实验的设计**：sPTT 与 FENE-P 在**定常（稳态）流变与层流速度剖面上完全相同**——两者只在**瞬态响应**上有差别（sPTT 有应力幅值依赖的松弛，FENE-P 也有，但形式不同）。因此在**相同层流剖面**下两者给出**不同的稳定性预测**，就唯一地把差异归因到**瞬态流变响应**上。这是一个非常干净的"控制变量"实验设计。

### 关键技术

| 技术 | 说明 |
|------|------|
| 线性稳定性分析 | 广义特征值问题，求解中心模态 |
| 中心模态 (centre-mode) 追踪 | 特征值为纯虚数的特殊中性模态，用 continuation 跟踪 |
| sPTT 本构模型 | 含非线性应力松弛的简化黏弹性模型 |

| 线性稳定性 → 混沌的模态相互作用 | 解释相干结构的生成机制 |
| 与 Oldroyd-B / FENE-P 的定量对比 | 明确门槛差异（浓度、Wi） |
| 本构模型判别用途 | 失稳存在性作为区分模型的实验判据 |

## 公式 / 理论要点

```math
% 简化 Phan-Thien-Tanner 本构方程（非线性应力松弛）
\boldsymbol{\tau}
+\lambda\left(
\frac{\partial\boldsymbol{\tau}}{\partial t}
+\boldsymbol{u}\cdot\nabla\boldsymbol{\tau}
\right)
=
2\eta_p\,\boldsymbol{D}
+\frac{\eta_p\,\alpha}{\mathrm{Wi}}\,\boldsymbol{\tau}
```

```math
% 动量方程
\rho\left(\frac{\partial\boldsymbol{u}}{\partial t}
+\boldsymbol{u}\cdot\nabla\boldsymbol{u}\right)
= -\nabla p+\nabla\cdot\left(2\eta_s\boldsymbol{D}+\boldsymbol{\tau}\right)
```

```math
% 零惯性极限（弹性失稳的核心极限）
\rho\boldsymbol{u}\cdot\nabla\boldsymbol{u} \to 0
\quad\Longrightarrow\quad
\text{纯弹性失稳分析}
```

```math
% 线性稳定性：广义特征值问题
\boldsymbol{A}(\boldsymbol{k})\,\hat{\boldsymbol{u}}
= \omega\,\boldsymbol{B}(\boldsymbol{k})\,\hat{\boldsymbol{u}}
```

```math
% 中心模态：所有特征值为纯虚数（实部为零）
\operatorname{Re}(\omega) = 0
\quad\text{（中性稳定，通过模态相互作用失稳）}
```

```math
% 纯弹性失稳判据
\max_{\boldsymbol{k}\neq 0}\operatorname{Re}\!\left[\omega(\boldsymbol{k})\right] > 0
\quad\text{at}\quad \mathrm{Re}\to 0
```

```math
% Weissenberg 数
\mathrm{Wi}=\frac{\lambda U}{L}
\qquad
\text{（Oldroyd-B 需要 Wi}\gg 1\text{，sPTT 在低 Wi 即可失稳）}
```

## 实验与结果

- **算例/数据集**: sPTT 黏弹性流体在**通道流**与**管流**中的线性稳定性分析；跨越聚合物浓度范围与 Weissenberg 数范围；与 Oldroyd-B、FENE-P 预测对比。
- **对比基线**: Oldroyd-B 与 FENE-P 的线性稳定性预测（文献已有结果）；通道流 vs 管流的几何对比。
- **主要结果**:
  - **通道流与管流中均存在纯弹性中心模态失稳**——管流中的纯弹性失稳是**新发现**。
  - **条件大幅放宽**：跨越**宽范围聚合物浓度**，且在**远低于** Oldroyd-B 预测门槛的 Weissenberg 数下出现。
  - **模型判别结论**：sPTT 与 FENE-P 定常流变与层流剖面相同，但稳定性预测相反 ⇒ **中心模态失稳的存在性由瞬态流变响应决定**。
  - **实验可达性**：作者论断该失稳**在现实流动条件下可观测**（对实验设计有直接指导意义）。
  - **可作为模型判别实验**：测量是否存在中心模态失稳，即可区分 sPTT 类与 FENE-P 类本构模型。

## 局限性

- **纯线性分析**：只证明**层流态**存在失稳；未做非线性演化模拟，未展示失稳后形成的相干结构与弹性湍流。
- **未包含**惯性与非线性流变在高 $\mathrm{Wi}$ 下的更强耦合效应（本文聚焦纯弹性极限）。
- **仅两类几何**（通道、管），未系统考察曲率、旋转、边界粗糙度等。
- sPTT 本身是**简化模型**（忽略分子伸展非线性），其结论向真实高分子（高分子量分布、缠结）的外推需谨慎。
- 论文篇幅较短（10 页），摘要未给出具体临界参数（临界浓度、临界 Wi）的数值表。

## 实现建议

- **实现难度**: 中 — 线性稳定性框架（Chebyshev 配点 / 谱方法离散 + 广义特征值求解 + 中心模态 continuation）是标准工具箱；难点在于**中心模态的稳定追踪**（需处理中性模态的数值敏感性）。
- **预期性能**: 特征值求解成本低（通道流基函数约 20–50 个），中心模态 continuation 需数百次特征值求解；总体可在单机数分钟内完成参数扫描。
- **适用场景**:
  - 黏弹性流稳定性图谱绘制（浓度–Wi–几何参数）；
  - **本构模型的实验判别设计**（本文最直接的用途）；
  - 弹性湍流相干结构起源的基础研究；
  - 聚合物加工（吹塑、纤维纺丝、注塑）中的流动稳定性评估。
- **可复用要点**:
  - **"定常流变相同、瞬态流变不同"的模型对照设计**是极具价值的实验设计范式：当你怀疑某个现象由某类响应决定时，应构造**在其他所有方面尽量相同**的对照组。本文用 sPTT vs FENE-P 做这件事，结论干净。
  - **纯弹性失稳的门槛（Wi 与浓度）本质上是"瞬态松弛"而非"稳态黏度"的检验**——这提示在工程建模中，只匹配定常流变的本构模型替换可能在瞬态工况下产生定性错误的预测。
  - 建议在阅读该文时**关注其临界参数的数值**，用于评估"现实条件下可观测"这一论断的强度（摘要未提供）。
  - 若要在自己代码中复现，建议先做**验证性对照**：在 Oldroyd-B + 通道流的已知临界值上校核框架（应复现"极高 Wi + 极稀溶液"的结果），再跑 sPTT。
