## 核心贡献

> 球面浅水的**二阶半隐式投影时间步**：把对流算子与波动算子分裂，**DG-upwind SSPRK3** 处理对流、**$H(\mathrm{div})$ 一致有限元隐式**处理波动；三步**对称分裂**保证全局二阶精度，并把稳定性限制**单独约束在对流步的 CFL** 上。

1. **三步对称分裂**：显式半步 → 完整对流步 → 隐式半步（**同时把速度投影回 $H(\mathrm{div})$ 空间**）
2. **波动部分用 hybridisation 高效求解**（$H(\mathrm{div})$ 一致有限元 + 混合化 → 鞍点问题化为小问题）
3. **步长可超出对流 CFL 限制**：通过**对流子循环（subcycling）**，且**不增加隐式求解次数**
4. **兼容有限元（compatible FEM）** 框架：基于有限元外微分，构造离散 de Rham 复形

## 技术方案

### 核心思想

**NWP 的核心矛盾**：快速声波/重力波与慢 Rossby 波、非线性对流共存的**跨数量级波速差**。时间积分方案必须同时满足效率、精度、稳定、大规模并行可扩展。

**主流范式**：
- **半隐式**（现行业务预报主流）：快波模态隐式 → 去掉步长上限；慢动力学显式或半显式
- 半隐式 + 半拉格朗日对流（SISL）：步长远超对流 CFL
- 其他：HEVI（水平显式垂直隐式）、split-explicit（快模态子循环）

**本文的切入点**：兼容有限元（基于**有限元外微分**）已由 Cotter & Shipton 提出并发展，速度落在 $H(\mathrm{div})$ 一致空间、深度/压力落在不连续 $L^2$ 空间，镜像连续方程结构，从而可构造**关键的向量演算的离散类比**。

**格式设计**：
- **对流部分**：DG-upwind + SSPRK3（显式）
- **波动部分**：$H(\mathrm{div})$ 一致隐式离散 + **hybridisation**（把约束问题转为更小、更好条件的系统）
- **时间步**：三步**对称分裂**——这是保证**全局二阶精度**的关键。对称性使得投影步骤与波动步的误差互相抵消，而不是同号累积

**为什么这样能突破 CFL**：稳定性限制被**局限在对流步的 CFL**（显式部分）；波动部分隐式无限制。若需要更大步长，用**子循环**处理对流步即可，**不需要额外的隐式求解**——这是相对 split-explicit 的优势。

### 关键技术

| 技术 | 说明 |
|------|------|
| **兼容有限元 / de Rham 复形** | 速度 $H(\mathrm{div})$ 一致空间、深度 $L^2$ 不连续空间；镜像连续结构，保证离散 Helmholtz 投影等性质 |
| **DG-upwind SSPRK3** | 对流部分的空间离散与三阶强稳定 RK 时间推进 |
| **$H(\mathrm{div})$ 一致隐式离散** | 波动部分；满足离散 div-curl 恒等式 |
| **Hybridisation** | 把混合空间问题化为更小系统，高效求解 |
| **三步对称分裂** | 显式半步 / 完整对流步 / 隐式半步（**含投影**） |
| **投影步** | 隐式半步中**同时**将速度投影回 $H(\mathrm{div})$ 空间 |
| **对流子循环** | 突破 CFL 时只加密对流子步，不增加隐式求解 |
| **Firedrake** | 实现平台；并行扩展性好 |

### 公式

**三步对称分裂**：

$$\text{① 显式半步}\;\longrightarrow\;\text{② 完整对流步 (DG-upwind SSPRK3)}\;\longrightarrow\;\text{③ 隐式半步（含 }H(\mathrm{div})\text{ 投影）}$$

对称性保证全局二阶精度，且稳定性限制仅为对流步的 CFL 条件。

**命名约定**：`rk($s$)` = $s$ 级 Radau IIA；`dg($k_t$)` = 时间多项式次数 $k_t$。

## 实验结论

- **验证基准**（标准球面浅水基准组）：
  - **Williamson 5**：孤立山地上的纬向流（zonal flow）
  - **Galewsky et al.** 斜压不稳定（barotropic instability）测试
  - **非定常刚体旋转**：解析解，用于收敛分析
  - **并行性能**测试
- **结果**：
  - 二阶有限元 + **2 次对流子循环**下，**Courant 数可达 1** 仍稳定
  - **二阶收敛**
  - **良好的并行扩展性**
- **实现**：Firedrake

---

## 局限性

1. **仅球面**（cubed-sphere 类型）；平面与旋转带几何未涉及
2. 对流子循环的**并行负载不均**（同一物理步内子循环有依赖）——文中提到并行扩展良好但细节有限
3. 波动部分完全隐式 → 每个物理步需要一次隐式求解，**步长不能无限增大**
4. 无「半拉格朗日」成分，因此与业务 NWP 的 SISL 范式不直接可比
5. 未讨论湿/干界面、真实地形等实际复杂性
6. 与 $[2611.08429]$ 同属时空分离路线，但本文是**兼容有限元**而非 Taylor–Hood
