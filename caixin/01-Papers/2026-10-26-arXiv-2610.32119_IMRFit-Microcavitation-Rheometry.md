## 核心贡献

> 把惯性微空化流变测量（IMR）的"反复前向仿真 + 本构模型辨识"整合进一个交互式开源桌面应用

1. **问题**：IMR 用高速成像获得气泡半径时序 R(t)，再与"气泡动力学 + 周围介质本构描述"的耦合仿真比对来反演材料参数；这需要**反复前向仿真**并精细控制实验输入、材料参数与拟合设置
2. **IMRFit** 提供一站式交互环境：导入实验 R(t) 数据、选择气泡动力学公式与本构模型、查看仿真响应、拟合材料参数、组织**批量拟合与参数扫描任务**
3. 内置 **Neo-Hookean Kelvin-Voigt** 与 **广义 Maxwell-Ogden** 等本构模型，并可通过 **JSON 描述符**与 **Python 求解器入口**扩展
4. 集成拟合窗口选择、可视化与数据导出

---

## 技术方案

### 核心思想

这是**工具型**论文：把一个原本靠脚本手工驱动的反演流程，做成可交互、可扩展、可批量化的应用。

### 关键技术

| 技术 | 说明 |
|------|------|
| 气泡动力学求解 | 空化泡半径演化方程（Rayleigh-Plesset 类）|
| 本构模型库 | Neo-Hookean Kelvin-Voigt、广义 Maxwell-Ogden 等 |
| JSON 描述符扩展 | 新本构模型可配置化接入，无需改核心代码 |
| Python 求解器入口 | 任意自定义求解器的接入点 |
| 拟合窗口选择 | 指定时间区间参与拟合，处理 R(t) 噪声段 |
| 批量拟合 / 参数扫描 | 任务化管理 |

## 公式

```math
气泡动力学（Rayleigh-Plesset 型）:
  ρ_l (R R̈ + 3/2 Ṙ²) = (p_∞ - p_v - p_∞(t)) - 2σ/R - 4μ Ṙ/R - 介质本构应力项

Neo-Hookean Kelvin-Voigt 本构:
  σ = μ (λ tr(E) I + 2E)  ,  E = ½(∇u + ∇uᵀ)
  + 粘性项 η ∂E/∂t

广义 Maxwell-Ogden（广义 Maxwell 模型）:
  σ = Σ_{k=1}^{N} σ_k ,  σ_k + τ_k ∂σ_k/∂t = 2η_k ∂E/∂t
  (多时间尺度松弛谱)

拟合目标:
  min_θ  ∫_{t∈W} | R_sim(t; θ) - R_meas(t) |² dt
```

## 代码片段

```python
# IMRFit 的可扩展本构模型接口示意
{
  "name": "my_constitutive_model",
  "type": "maxwell-ogden",
  "params": {"tau": [0.01, 0.1], "eta": [0.2, 0.5]},
  "solver": "my_package.my_solver.solve_bubble"   # Python 求解器入口
}

def fit_material_parameters(R_meas, window, model, solver_entry):
    """窗口内最小二乘拟合 + 可选的参数扫描"""
    from scipy.optimize import least_squares
    def residual(theta):
        R_sim = solver_entry(R_meas[0], theta, t=window.t)
        return R_sim - R_meas[window.mask]
    return least_squares(residual, x0=model.initial_guess())
```

## 实验结论

- **数据集**: 惯性微空化实验的高速成像 R(t) 数据
- **基线**: 手工脚本驱动的逐次拟合流程
- **结果**:
  - 交互式环境统一了前向仿真、参数辨识与本构模型比较
  - 内置两类本构模型（Neo-Hookean KV、广义 Maxwell-Ogden），并支持 JSON + Python 扩展
  - 批量拟合与参数扫描任务化，大幅降低实验工作量

---

## 局限性

- 摘要未给出定量的拟合精度对比
- 气泡动力学公式可选择性带来模型一致性风险（不同公式适用工况不同）
- 桌面 GUI 的批处理效率不如纯脚本
- 仅针对惯性微空化（高应变率软材料）场景
