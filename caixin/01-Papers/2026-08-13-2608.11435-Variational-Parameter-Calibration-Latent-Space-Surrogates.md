# Variational Parameter Calibration with Physics-Aware Latent-Space Surrogates

**arXiv:** [2608.11435](https://arxiv.org/abs/2608.11435)  
**Authors:** Qiyao Zhou, Xuji a Zhu, Pierre Joli, Yu Cong, Sibo Cheng  
**Categories:** cs.LG, physics.comp-ph, physics.data-an, physics.flu-dyn  
**Published:** 2026-08-11  

---

## 创新点 (Key Innovations)

- **端到端可微分的降阶 surrogate + 变分参数估计耦合框架**
- **物理感知的自编码器**：将物理参数映射到流场预测的隐表示
- **可观测监督**：鼓励隐变量保留与系统参数相关的信息
- **在线逆问题求解**：通过surrogate诱导的观测算子在参数空间求解

## 核心问题

重建精度对逆建模不充分，原因：
1. 缺乏端到端可微分性
2. 缺乏物理感知

## 框架架构

```
物理参数 → Encoder → 隐表示 → Decoder → 流场预测
                ↑
         可观测监督
                ↓
参数空间 ← 逆问题 ← 观测数据
```

## 核心发现

1. **隐空间可分离性**：可观测监督改善了案例级隐空间分离
2. **时序组织**：改善了隐表示的时间组织
3. **鲁棒性**：对噪声、低分辨率、随机掩码、区块部分观测有效
4. **标定误差降低**：相比标准surrogate模型

## 评估基准

两个CFD benchmark测试：
- 流场重建
- 参数标定

## 方法论亮点

- **Offline训练**：可观测监督
- **Online逆问题**：变分参数估计
- **Surrogate-induced观测算子**：桥接隐空间和物理参数

## 隐空间分析

可观测监督改善：
- 案例级可分离性
- 时间一致性
- 物理参数与隐变量的对应关系
