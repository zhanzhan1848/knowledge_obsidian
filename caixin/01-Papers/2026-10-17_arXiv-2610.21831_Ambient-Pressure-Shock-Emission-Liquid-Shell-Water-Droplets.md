## 核心贡献

> 实验研究**纳秒激光诱导击穿**在水微滴（μm 量级）内产生的**冲击波**与**液壳膨胀**，揭示**环境气压**对冲击波传播与液滴形态演化的**差异化影响**

1. **实验设计**：纳秒激光诱导击穿，**有限光束模式** \(D_0/D_b \sim 2\)，扫描环境气压
2. **同步测量**：液滴变形 + 冲击波同步测量（区分气相 / 液相动力学）
3. **关键能量阈值**：
   - 低能 \(E_l < 1\,\mathrm{mJ}\)：后界面 plasma → 界面气泡 → 薄膜不稳定 → 表面张力塌缩
   - 高能 \(E_l > 1\,\mathrm{mJ}\)：液壳**爆炸式形成** + 多冲击波前沿（超声速膨胀）
4. **理论框架**：
   - 冲击波：**强爆炸波理论**（strong blast wave theory）
   - 液壳膨胀：**内部 plasma 膨胀驱动的压力载荷**（ballistic 运动 → 完全雾化）
5. **环境气压效应**：
   - 冲击波传播**强烈依赖**环境气体密度
   - 液滴形态与膨胀动力学**几乎不变**（内部压力载荷主导）

## 技术方案

### 核心思想

通过激光-液滴相互作用的**能量阈值**将液滴破裂模式分为两类（界面气泡模式 vs 液壳爆炸模式），并展示**环境气压只影响外传冲击波，不影响内部液壳动力学**。

### 关键技术

| 技术 | 说明 |
|------|------|
| Laser-induced breakdown (LIB) | 纳秒激光聚焦于液滴内部 |
| High-speed imaging | 同步记录液滴变形与冲击波 |
| Synchronized measurement | 时间分辨双通道 |
| Strong blast wave theory (Sedov-Taylor) | 冲击波传播建模 |
| Plasma expansion model | 内部压力载荷建模 |
| Finite-beam regime \(D_0/D_b \sim 2\) | 激光光斑与液滴直径之比 |

### 控制视角

- **几何**：球形液滴，曲面前界面聚焦
- **能量平衡**：
  - plasma 形成 → 内压上升 → 液壳形成 / 界面气泡
  - 表面张力：薄膜不稳定 → 塌缩 / 雾化
  - 外部气体：冲击波向外传
- **无量纲**：
  - Weber 数（plasma 驱动 vs 表面张力）
  - Reynolds 数（液体膨胀）
  - Mach 数（冲击波传播）

### 关键物理图像

```
[低能] laser → 后界面 plasma → 界面气泡 → 薄膜
                                              ↓
                                          表面张力塌缩
                                          + 外部冲击波（依赖环境气压）

[高能] laser → 轴向烧蚀 → 液壳 + 多冲击波
                                    ↓
                            超声速膨胀 → 完全雾化
                            （液壳由内部压力载荷驱动）
```

## 实验 / 验证

- **方法**：纳秒激光 + 高速成像 + 同步冲击波测量
- **样本**：μm 量级水微滴
- **参数**：环境气压扫描（多档）
- **结果**：
  - 液壳膨胀与冲击波**解耦**（不同物理机制）
  - 强爆炸波理论定量描述冲击波
  - 内 plasma 压力载荷定量描述液壳动力学

---

## 局限性

- **单工质（水）**：未涵盖其他液体（油、有机溶剂等）
- **激光波长未细化**：可能影响 plasma 形成机制
- **球形液滴假设**：真实喷雾中液滴形状偏离球形
- **理论仅适用于强爆炸波极限**：低 Mach 区域需其他模型
