## 核心贡献

> 研究热方程与波动方程在二维**初边值问题**中，界面形状受到**小扰动**时**当前边界扰动的高阶渐近展开项**；推导经**场展开 (field expansion)** 方法形式化推导、并由**层位势 (layer potential) 技术**严格证明；并把已有的"小体积非均匀性"结果**推广到形状扰动**，从而给出**基于边界测量的反演算法**来反推非均匀性的形状。

1. **高阶渐近展开的推进**：针对 $C^2$-光滑边界非均匀性的**形状小扰动**，推导当前（current）边界扰动的**高阶渐近展开项**——即边界测量量对形状扰动的**高阶灵敏度级数**。
2. **形式推导 + 严格证明双轨**：推导经**场展开 (FE) 方法**做形式化处理，**严格性**由**层位势技术**给出。
3. **从体积扰动到形状扰动的推广**：把已有的**小体积非均匀性 (small-volume inhomogeneity)** 结果**推广到形状扰动**这一新的设定。
4. **反演算法的落脚点**：最终目标是**高效算法**——**仅依据边界测量量**即可确定非均匀性（障碍/界面）形状的某些性质。
5. **适用方程**：**二维热方程与波动方程**的初边值问题。

---

## 技术方案

### 核心思想

这是一个**反问题 (inverse problem)**：域内有一个形状未知的非均匀性（障碍物或材料界面），我们只能测量**边界上的量**（例如热方程中的边界温度/热流，或波动方程中的边界响应），希望反推出非均匀性的**形状**。

难点在于**不适定性**：边界测量对形状扰动的响应非常"弱"——形状的小变化引起测量量的变化是**高阶小量**，且形状扰动一般**不是**扰动空间中的"小体积"分量（形状扰动改变的是边界几何，而非域内的源项分布）。

本文采用的路径是**渐近展开**：
- 用**场展开 (field expansion)** 方法，把解在"小参数"（扰动幅度）下展开成层级：$\boldsymbol{u} = \boldsymbol{u}_0 + \epsilon\boldsymbol{u}_1 + \epsilon^2\boldsymbol{u}_2 + \cdots$；
- 逐阶匹配方程，**提取出边界测量量对形状参数的各阶导数（灵敏度）**；
- 这些灵敏度构成一个**渐近级数**，可直接反演形状参数。

而**层位势技术**是处理这一问题的自然工具：无论源在域内还是界面形状未知，Green 函数与界面条件都可用**单层/双层位势**表示，从而把"几何问题"转化为**边界积分方程**问题，其可解性与误差分析也更为直接。

这个方向的**应用价值**很高：形状反演对应于**几何参数辨识**——例如从边界温度场反推隔热层的厚度/形状、从声场反推管道内障碍物的几何、或在医学成像中从边界测量反推组织界面。

### 关键技术

| 技术 | 说明 |
|------|------|
| 场展开 (field expansion) | 按小参数逐阶展开解，形式化推导 |
| 层位势 (layer potential) 技术 | 严格性证明与 Green 函数表示 |
| 初边值问题 | 二维热方程与波动方程 |
| 形状扰动渐近展开 | 边界测量量对形状参数的高阶灵敏度级数 |
| 形状反演算法 | 依据边界测量反推界面形状性质 |
| $C^2$ 边界正则性 | 形状扰动的基本假设 |

## 公式 / 理论要点

```math
% 二维热方程的初边值问题（域内含非均匀性 $\Omega\setminus\Omega_\varepsilon$）
\frac{\partial T}{\partial t} = \Delta T
\quad\text{in}\ \Omega\setminus\Omega_\varepsilon
```

```math
% 场展开（核心方法）
\boldsymbol{u}
= \boldsymbol{u}^{(0)}+\varepsilon\boldsymbol{u}^{(1)}
+\varepsilon^2\boldsymbol{u}^{(2)}+\varepsilon^3\boldsymbol{u}^{(3)}+\cdots
```

```math
% 逐阶匹配得到的递推关系
\mathcal{L}\boldsymbol{u}^{(0)} = 0,
\qquad
\mathcal{L}\boldsymbol{u}^{(k)}
= -\boldsymbol{F}^{(k)}\big[\boldsymbol{u}^{(0)},\ldots,\boldsymbol{u}^{(k-1)}\big]
```

```math
% 形状扰动参数化（$C^2$ 边界）
\boldsymbol{x}(s) = \boldsymbol{x}_0(s) + \varepsilon\,\boldsymbol{\xi}(s),
\qquad s\in[0,L)
```

```math
% 边界测量量对形状扰动的高阶灵敏度
\mathcal{M}[\boldsymbol{u}] = \mathcal{M}_0
+\varepsilon\,\delta\mathcal{M}^{(1)}[\boldsymbol{\xi}]
+\varepsilon^2\,\delta\mathcal{M}^{(2)}[\boldsymbol{\xi}]
+\varepsilon^3\,\delta\mathcal{M}^{(3)}[\boldsymbol{\xi}]+\cdots
```

```math
% 层位势表示（严格性的技术基础）
u(\boldsymbol{x})
= \int_{\Gamma} G(\boldsymbol{x},\boldsymbol{y})\,\phi(\boldsymbol{y})\,ds_{\boldsymbol{y}}
\quad\text{（单层位势）}
```

```math
% 反演：由边界测量确定形状参数
\boldsymbol{\xi} = \arg\min_{\boldsymbol{\xi}}
\left\|\mathcal{M}_{\text{meas}}-\mathcal{M}[\boldsymbol{u}_{\boldsymbol{\xi}}]\right\|^2,
\qquad \text{在}\ \varepsilon\text{ 的低阶渐近近似下}
```

## 实验与结果

- **研究类型**: 理论工作（偏微分方程与反问题的数学分析）。
- **设定**: 二维**热方程**与**波动方程**的初边值问题；$C^2$-光滑边界非均匀性；**小形状扰动**。
- **主要结果**:
  - 推导了当前边界扰动的**高阶渐近展开项**（形状扰动而非体积扰动设定下）。
  - 形式推导（场展开）+ 严格证明（层位势）双轨完成。
  - 把已有的**小体积非均匀性**结果**推广到形状扰动**设定。
  - 给出**高效算法**：依据边界测量量确定非均匀性形状的某些性质。

---

## 局限性

- **二维**：未推广到三维（位势方法在三维更复杂但也可行）。
- **线性方程**：标题中的 "dynamic linear equations" 限定在线性方程（热、波动），非线性流固耦合未涉及。
- **小扰动假设**：只在小扰动渐近框架内有效；大变形形状反演（典型的几何tomography问题）不适用。
- **单界面/单个非均匀性**：多界面问题未讨论。
- **反演的实际验证**：摘要未提数值实验（反演算法的效果验证是这类论文最关键的产出）。
- **与流体的关系间接**：属于形状反演/边界观测问题，与 CFD 的直接关联主要是**几何辨识与边界条件反演**。

## 实现建议

- **实现难度**: 中高（数学门槛高，工程实现中等）— 位势方法 + 渐近展开 + 伴随/优化反演。
- **预期性能**: 渐近展开对小扰动（$\varepsilon\ll1$）**每阶修正成本低**，且低阶展开即可给出形状的一阶/二阶近似——这正是"高效算法"的来源。
- **适用场景**:
  - **几何参数辨识**：从边界响应反推内部障碍/界面形状；
  - **反问题中的形状优化**：基于边界观测的形状设计（如散热器翅片布局、管道阻流器）；
  - **模型验证/校准**：用实测边界数据反推计算模型中的几何参数。
- **可复用要点**:
  - **"小体积扰动"与"小形状扰动"是两类本质不同的反问题**：形状扰动不改变域的体积分布，只改变几何；对应的灵敏度级数结构不同（涉及曲率与法向的变分）。做反问题设计时应先明确属于哪一类。
  - **渐近灵敏度级数**是高效反演的通用路线：与基于伴随梯度或全局优化的黑箱方法相比，**解析灵敏度**在小扰动区间既快又可解释。建议把这类"灵敏度级数"作为反问题求解器设计的一个标准选项。
  - **边界观测反演**在工程上有独特优势（只需在边界布点，无需内部传感器），值得在实验设计（传感器布置）中作为选项考虑——例如本文的渐近展开暗示**特定位置的边界测量对特定方向/曲率的形状扰动最敏感**，可用于指导传感器布置。
