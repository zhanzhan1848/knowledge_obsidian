## 核心贡献

> 指出当前 CFD 代理模型的基准测试存在**根本性缺陷**——每个数据集只在一个几何族、一个流动域内变化，导致模型只需做"形状→场"的映射而非求解 PDE；并据此提出 **AeroZoo**：一个包含 **3,815 个完整"适定"（well-posed）非定常 RANS 问题**的基准与预训练语料，覆盖 7 个几何族、8 种封闭域、Re 从 10³ 到 10⁸，其中 2,816 个时间均值稳定的样本构成标准基准，配 22 组几何/封闭域/边界条件/Re 区间全部不相交的冻结划分。

1. **量化了现有基准的规模天花板**：在 DrivAerML 上，Transolver 从 20M 扩到 354M 参数，表面压力误差变化 < 3%；算力翻 4 倍误差仅降约 4%；只有增加训练样本有效——**每翻倍降约 12%**，且在 400 样本处已接近数据集级地板。
2. **提出"适定样本"（well-posed sample）范式**：每个样本封装完整边值问题——按条件类型分组的边界网格、面级规定值、流体物性（密度、运动粘度）。这样学习任务退化为**求解 PDE 解算子**，而非形状插值。
3. **22 组冻结划分**系统性地留出几何族、封闭域、边界条件排布与雷诺数区间，用于测量真正的分布外泛化。
4. **揭示边界条件 token 的巨大价值**：在随机划分上，加入边界条件 token 将 GeoTransolver 的中位速度误差从 **76.9% → 8.4%**（入口速度归一），纯均匀来流基线为 11.0%——**9 倍改善**。
5. **提出四环节"误差堆叠"（error stack-up）框架**：把代理模型误差分解为建模误差、离散化/平均窗口误差、分布内代理误差、分布外附加误差，并证明**代理误差远大于数值敏感度**（ISLA 5.3% vs 网格加密 1.2%）。
6. **量化了"新边界条件"才是泛化的真正瓶颈**：留出封闭域使 ISLA 误差增至 2.4 倍，留出 crossflow / dual-inlet 布局则增至 **5.5 倍和 9.2 倍**，而留出几何族几乎无影响（1.0–1.2 倍）。

## 技术方案

### 核心思想

本文的批评极为精准：现有 CFD 代理基准（如 DrivAerML 的 500 个轿车形态）**同时固定了边界条件**，于是"输入几何 → 输出流场"是一个良定义的映射问题，网络只需做同族插值，训练到饱和也无法获得 PDE 解算子的能力。而一个真正的"气动基础模型"必须能回答：**同一辆车体，在不同封闭域、不同边界条件下，流场是什么？**

作者用图 1 说明：一辆车在四种封闭域（开放箱、地面效应箱、封闭箱、双入口箱）中，**在相同入口速度与雷诺数下产生四个完全不同的流场**。任何只学过"开放域轿车"的模型，在其他三种封闭域下都是外推。

因此 AeroZoo 的每个样本都是一个**完整的适定流体力学问题**，而非一个流场快照。

### 关键技术

| 技术 | 说明 |
|------|------|
| **DomainMesh schema** | 每个样本含 4 类边界网格（`inlet`, `outlet`, `no_slip`, `slip`）、面级规定值、`kinematic_viscosity`、`density` |
| **张量角色分离** | 输入（构成 PDE）/ 查询点 / 目标 / 权重 / 事实 / 标度（仅评分用）——只有 PDE 输入与查询坐标进入模型 |
| **非定常 RANS + 转捩模型** | 求解的是**带转捩模型**的非定常 RANS，取时间均值作为目标 |
| **7 个几何族** | blobs、CAD 零件、汽车、飞机、流线体 + 161 个无体风道 |
| **8 种封闭域配置** | 开放箱、地面效应箱、封闭箱、双入口箱等；含光滑/凸起球体对置壁面 |
| **Re 跨度 10³–10⁸** | 尺度从 2 cm 到 20 m，覆盖工业雷诺数 |
| **22 组冻结划分** | 留出几何族 / 封闭域 / 边界条件排布 / Re 区间，四类正交不相交 |
| **稳定性标签** | 2,816 个时间均值稳定的样本构成"canonical benchmark" |
| **误差堆叠分析** | 四环节误差分解 + 求解器数值敏感度标定 |
| **体/面加权指标** | 内部任务按体积分量，边界任务按面积加权（壁面剪切等） |

## 公式 / 理论要点

```math
% 适定性：RANS 问题由三件事完全确定
% (1) 流体域边界  (2) 每部分边界上施加的条件类型及其规定值  (3) 流体密度与运动粘度
```

```math
% 评分尺度（模型不可见，仅用于评分）
\varepsilon_U = \frac{\|u_{\text{pred}} - u_{\text{ref}}\|}{\|u_{\text{ref}}\|},
\qquad
\varepsilon_{C_F} = \frac{|C_F^{\text{pred}} - C_F^{\text{ref}}|}{|C_F^{\text{ref}}|}
```

```math
% 四环节误差堆叠（Figure 6）
\varepsilon_{\text{total}} = \underbrace{\varepsilon_{\text{modeling}}}_{\text{方程与现实之差}}
+ \underbrace{\varepsilon_{\text{discretization}}}_{\text{离散化+有限平均窗口}}
+ \underbrace{\varepsilon_{\text{surrogate,in-dist}}}_{\text{同分布代理误差}}
+ \underbrace{\varepsilon_{\text{surrogate,OOD}}}_{\text{分布外附加误差}}
```

```math
% 求解器数值敏感度标定（网格/重跑/平均窗口）
\text{网格加密 1.5×}: \ \Delta u \text{ 中位 } 1.2\%
\qquad
\text{重跑（另一集群）}: \ \Delta u \text{ 中位 } 0.0002\%
\qquad
\text{壁面解析首层}: \ \Delta u \text{ 中位 } 0.7\%
```

```math
% 边界条件 token 的贡献（随机划分）
\varepsilon_U(\text{GeoTransolver}) :
\ \underbrace{76.9\%}_{\text{无 BC token}}
\ \longrightarrow\
\underbrace{8.4\%}_{\text{有 BC token}}
\qquad (\text{均匀来流基线 } 11.0\%)
```

## 实验与结果

- **数据集**: 3,815 个适定非定常 RANS（带转捩模型）问题，23.8B 单元；7 几何族 × 8 封闭域；Re 10³–10⁸；尺度 2 cm–20 m；其中 2,816 个样本时间均值稳定 → canonical benchmark；每样本含完整 DomainMesh（4 类边界网格 + 面级规定值 + 物性）。
- **任务**: 内部任务（4.2M 单元查询点）与边界任务（壁面剪切等）；两个任务；22 组冻结划分。
- **对比基线**: Transolver、GeoTransolver、ISLA（[[ISLA 坐标无关 Transformer]]）、自由来流（uniform flow, 11.0%）。
- **主要结果**:
  - **规模天花板**：Transolver 20M→354M 参数，表面压力误差变化 < 3%；算力 ×4 仅降误差约 4%；训练样本每翻倍降约 12%，400 样本处触底。
  - **BC token 的决定性作用**：GeoTransolver 中位速度误差 76.9% → 8.4%（≈9×）；ISLA 四种子 5.3%，约为网格加密带来变化的 **4 倍**。
  - **误差堆叠**：ISLA 中位 ε_U = 5.3% vs 网格加密 1.2% ⇒ 代理误差约为数值敏感度的 4.5 倍（GeoTransolver 8.4% ≈ 7 倍）。仅在对置球体（2.3%）与开放箱（2.8%）中进入 2.5 倍以内。
  - **积分体力更敏感**：网格加密下 ε_C_F 中位 3.7%，壁面解析首层 6.9%。
  - **泛化瓶颈在边界条件而非几何**（留出后误差倍率）：blob 1.1×、CAD 零件 1.0×、Re ≥ 10⁶ 1.2×、非箱式封闭域 2.4×、**crossflow 5.5×、dual-inlet 9.2×**。
  - **数值敏感度标定**：两半平均窗均值差 0.13% U_ref；重跑 0.0002%；网格加密 1.2%（释出样本 1.4%）；壁面首层 0.7%。

## 局限性

- 仅覆盖**非定常 RANS + 转捩模型**，非 LES/DNS；目标为时间均值，丢失非定常细节。
- 目标本身带离散化与有限平均窗口误差（虽然已标定为小量）。
- 单一冻结数值配方，跨求解器泛化未验证。
- "适定"仅针对所声明的固定湍流封闭（作者明确指出"固定封闭的不可压 RANS 问题由三件事确定"）。
- ISLA 的 OOD 性能在**新封闭域/新边界条件排布**上仍可能放大 5.5–9.2 倍，远未解决。
- 数据集尚未正式发布（标注"即将发布"）。

## 实现建议

- **实现难度**: 中 — 核心是数据打包规范（DomainMesh）与划分设计，不涉及新数值方法；求解部分由既有非定常 RANS+转捩求解器承担。
- **预期性能**: 作为基准，其价值在于**可证伪的误差分解**：任何新模型都应同时报告 ① 四环节误差分解 ② 22 组划分上的泛化 ③ 相对数值敏感度（网格加密 1.2%）的比值。
- **适用场景**:
  - 评估任何**代理 CFD 模型**是否值得用于新几何/新封闭域；
  - 气动基础模型的预训练语料；
  - 作为"边界条件是否被正确建模"的判别器（BC token 消融是廉价而锐利的探针）。
- **可复用要点**:
  - **"输入是否构成完整边值问题"应成为任何 PDE 代理模型数据集的设计检查项**——这是本文最有价值的普适结论。
  - **误差堆叠分解**是评估代理模型的通用范式：先标定求解器自身的数值敏感度（网格、重跑、平均窗），再衡量代理误差相对于它的倍数，比单纯报绝对误差更有意义。
  - **用"新边界条件"而非"新几何"作为 OOD 主轴**，与直觉相反但更贴近工程实际（改封闭域、改入口排布比改车模更常见）。
  - 冻结划分（22 组）避免了对测试集的反复调参——这是代理模型基准被污染的常见途径。
