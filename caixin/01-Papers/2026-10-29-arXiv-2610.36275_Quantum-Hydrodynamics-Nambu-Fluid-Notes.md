## 核心贡献

> 从 Nambu 未发表笔记《A New Look at Fluid Dynamics》出发建立**有限维量子流体动力学**：**同一个经典动理学度规**同时决定经典测地线与 Laplace–Beltrami 量子哈密顿量；**消失的机械连接给出精确无噪声的动量符号子系统**；而任何改善 Euler 方程兼容性的流动方向**必然引入非零连接曲率**，从而带来符号依赖的退相干。

1. **经典–量子统一**：Nambu 的体积保持型动能作用量诱导的动理学度规 $G_{rs}$ 既是经典运动（测地线）的度规，也是量子哈密顿量（Laplace–Beltrami 算子）的度规。
2. **精确相干保持判据**：对循环观测坐标 $q$，混合度规分量定义机械连接 $A_a$。动量符号量子比特是**精确无噪声子系统**当且仅当符号依赖耦合消失：
   $$A=0 \iff B=0 \iff \widehat H(p)=\widehat H(-p),\qquad p\neq0$$
3. **经典残差与量子曲率的同源**：Christoffel 系数（对称部分）决定经典 Euler 残差，**反对称部分**决定机械连接曲率：
   $$F_{ab}=\frac{T_{b|qa}-T_{a|qb}}{G_{qq}}-\frac{G_{qb}\partial_aG_{qq}+G_{qa}\partial_bG_{qq}}{G_{qq}^{2}}$$
4. **显式两剪切流模型**：两个耦合剪切模态产生只依赖未观测坐标的度规，哈密顿量仅通过 $p_q^2$ 依赖观测动量 → **$p_q$ 的符号被精确保护**。
5. **Euler 修正的量子代价**：加入两个生成流抵消两剪切轨迹的初始 Euler 残差，**同一批流同时产生非零连接曲率** $\Rightarrow$ 环境对观测动量符号敏感。
6. **有限读出区间的态制备判据**：在等平均能量下，针对主导耦合流适配的态可把**初始二次退相干系数压低 3 个数量级以上**（$0.23 \to 2.23\times10^{-5}$），但该优势在条件演化下逐渐衰减，**最终退相干曲线发生交叉**——初始系数小并不意味着有限读出区间内相干保持更好。

## 技术方案

### 核心思想

Nambu 的构造把不可压流表示为**无散流场的复合**（由标量函数对生成），动理学度规诱导测地线方程，度规同时给出量子哈密顿量。把集体坐标分为**观测模态 $S$** 与**未观测模态 $E$**（环境），对 $E$ 部分求迹即得观测系统的退相干动力学。

### 关键技术

| 技术 | 说明 |
|------|------|
| 约束作用量 | Nambu 体积保持约束 $J_X=1$ |
| 生成流 | $w_r=\nabla\phi_r\times\nabla\chi_r$（无散） |
| 动理学度规 | $G_{rs}=\rho_0\int_M \partial_rX_q\cdot\partial_sX_q\,d^3a$ |
| 量子化 | Laplace–Beltrami 算子 $\Delta_G$，Friedrichs 实现 |
| 几何分解 | $ds^2=G_{qq}(dq+A)^2+h_{ab}dy^ady^b$（Stäckel 分解） |
| 条件哈密顿量 | 固定观测动量 $p$，用 $\partial_q\to ip/\hbar$ |
| 退相干分析 | 条件重叠 $f_\Sigma(t)$、解码信道、退相干损失 |
| 状态制备 | 乘积制备 vs 连接适配（connection-adapted）制备 |

## 公式

### 1. Nambu 约束动能作用量

```math
S_N=\int dt\int_M d^3a\left[
\frac{\rho_0}{2}\left|\partial_tX\right|^2-U(X)+\lambda(a,t)(J_X-1)\right],
\qquad J_X=\det(D_aX)
```

变分 $\lambda$ 给出不可压条件 $J_X=1$；变分 $X$ 给出 Euler 方程：

```math
\rho_0\left(\partial_t v+(v\cdot\nabla)v\right)=-\nabla U-\nabla P,\qquad \nabla\cdot v=0
```

### 2. 生成流与复合流

```math
w_r=\nabla\phi_r\times\nabla\chi_r,\qquad
\partial_s\Phi_r^s=w_r\circ\Phi_r^s,\qquad \Phi_r^0=\mathrm{id}
```

```math
X_q=\Phi_m^{q_m}\circ\cdots\circ\Phi_1^{q_1},\qquad J_{X_q}=1
```

```math
v_{q,\dot q}=\sum_r \dot q_r\,\partial_rX_q\circ X_q^{-1}
```

### 3. 动理学度规与经典/量子哈密顿量

```math
L_N^{(m)}=\frac12 G_{rs}(q)\dot q_r\dot q_s,\qquad
G_{rs}(q)=\rho_0\int_M \partial_rX_q\cdot\partial_sX_q\,d^3a
```

```math
p_r=G_{rs}\dot q_s,\qquad H_N^{(m)}=\frac12p_rG^{rs}(q)p_s
```

```math
\mathcal H_N^{(m)}=L^2(Q_m,d\mu_G),\qquad d\mu_G=\sqrt{\det G}\,d^mq
```

```math
\widehat H_N^{(m)}=-\frac{\hbar^2}{2}\Delta_G,\qquad
\Delta_G=\frac{1}{\sqrt{\det G}}\partial_r\left(\sqrt{\det G}\,G^{rs}\partial_s\right)
```

### 4. 观测/未观测分裂与约化动力学

```math
W\Psi=(\det G)^{1/4}\Psi
```

```math
\mathcal E_N^t(\rho_S)=\operatorname{Tr}_E\left[U_N(t)(\rho_S\otimes\sigma_E)U_N(t)^\dagger\right],
\qquad U_N(t)=e^{-it\widehat H_{\mathrm{flat}}/\hbar}
```

### 5. 机械连接（Stäckel 分解）

```math
ds^2=G_{qq}(dq+A)^2+h_{ab}\,dy^a dy^b,\qquad
A_a=\frac{G_{qa}}{G_{qq}},\qquad
h_{ab}=G_{ab}-\frac{G_{qa}G_{qb}}{G_{qq}}
```

```math
G^{ab}=h^{ab},\quad G^{qa}=-h^{ab}A_b,\quad
G^{qq}=\frac{1}{G_{qq}}+A_ah^{ab}A_b,\quad \mu=\sqrt{G_{qq}\det h}
```

### 6. 条件哈密顿量（符号依赖耦合的来源）

```math
\widehat H_\mu(p)=-\frac{\hbar^2}{2\mu}D_a^{(p)}\left(\mu h^{ab}D_b^{(p)}\right)
+\frac{p^2}{2G_{qq}}+V_0,\qquad
D_a^{(p)}=\partial_a-\frac{ip}{\hbar}A_a
```

```math
\widehat H(p)=\widehat H_E+\frac{p^2}{2}G^{qq}+pB
```

```math
\widehat H_E=-\frac{\hbar^2}{2}(\partial_a+l_a)h^{ab}(\partial_b-l_b)+V_0,\quad
l_a=\frac12\partial_a\log\mu
```

```math
B=\frac12\{c_a,\pi_a\}=-i\hbar c_a\partial_a+\frac12\partial_ac_a,\qquad
c_a=-h^{ab}A_b,\quad \pi_a=-i\hbar\partial_a
```

**唯一随 $p\to-p$ 变号的项就是 $pB$。**

### 7. 精确相干保持判据

```math
A=0\ \Longleftrightarrow\ B=0\ \Longleftrightarrow\
\widehat H(p)=\widehat H(-p),\qquad p\neq0
```

### 8. 坐标重定义与曲率障碍

```math
q'=q+\Lambda(y),\qquad
\psi'_p(y)=e^{-ip\Lambda(y)/\hbar}\psi_p(y),\qquad A'=A-d\Lambda
```

- $A=d\Lambda$：在可缩合同胚域上可**局部**移除耦合
- $F=dA\neq0$：局部移除被**阻碍**
- 多连通域：全局移除还需 $A$ 的周期为零

### 9. 连接曲率

```math
F_{ab}=\frac{T_{b|qa}-T_{a|qb}}{G_{qq}}
-\frac{G_{qb}\partial_aG_{qq}+G_{qa}\partial_bG_{qq}}{G_{qq}^{2}}
```

## 实验结论

### 两剪切流模型（4 坐标族）

- 初始两模态变分方程给出 $\ddot q=\ddot r=0$，物质加速度：

```math
\mathcal A_2=\alpha\beta\,(0,\,0,\,\sin(2y)\cos x\cos z)
```

- Euler 残差（$\psi=\sin(2y)\cos x\sin z/6$）：

```math
R_E(0)=\alpha\beta W,\qquad
W=\left(\frac{\sin x\sin(2y)\sin z}{6},\;
-\frac{\cos x\cos(2y)\sin z}{3},\;
\frac{5\cos x\sin(2y)\cos z}{6}\right)
```

- 加入两个生成流（$\phi_3=\frac13\cos(2y)\cos z,\ \chi_3=\sin x$；$\phi_4=\frac16\sin x\cos z,\ \chi_4=-\frac12\cos(2y)$）使 $W=w_3+w_4$，且新增切向量在恒等处与原剪切正交 →

```math
\mathcal A_4=\mathcal A_2-\alpha\beta W=\alpha\beta\nabla\psi,\qquad R_E^{(4)}(0)=0
```

- 轨迹误差由 $X_2-X_E=\frac12t^2R_E(0)+O(t^3)$ 降为 $X_4-X_E=O(t^3)$
- 压力 $P=-\rho_0\ell^2\alpha\beta\psi$ 提供剩余的梯度加速度

### 连接曲率（符号依赖性的来源）

- 恒等点处曲率 $F_0=\frac13\,dr\wedge ds_3+\frac1{12}\,dr\wedge ds_4 \neq 0$ → **局部移除耦合被阻碍**
- $T_A|_{BC}$ 与初速度的收缩给出经典载荷（对应式 4.7），**其反对称部分给出 $F_0$**——同一组动理学积分既决定经典修正也决定量子曲率

### 等平均能量下的态制备对比（$\vartheta=\pi/4$，$k_0=p_{r_0}=1$，$\Delta k=0.25$）

| $E/(\hbar^2/I)$ | 乘积制备 $C_\tau$ | 连接适配制备 $C_\tau$ | 抑制比 |
|---|---|---|---|
| **1000** | 0.23 | **1.63×10⁻⁴** | **7.3×10³** |
| **0.23** | 0.23 | **2.23×10⁻⁵** | — |

- 两种制备共享相同相位 $e^{ir}$、相同动量幅度分布 $|g(k)|^2$，仅调整宽度以**匹配全非线性度规下的平均能量** → 隔离出振幅形状的效应
- 适配制备的等值线**沿主导耦合流方向** $(\alpha\vartheta s, -\beta\vartheta r)$ 恒定
- 剩余leading贡献来自相位项

### 有限读出区间

- 退相干损失曲线**初始优势逐渐衰减直至交叉**（$G(\tau)$ 从远大于 1 降到 1 以下）
- 交叉后出现**部分恢复（partial revivals）**
- **适配态虽初始二次系数小得多，却在显示区间内达到更大的最大采样损失**
- 结论：**初始系数不决定哪种制备在有限读出区间内更好地保持相干**

## 局限性

1. **纯理论**，无实验验证；数值算例仅在高度简化的两剪切流族上。
2. **未观测模态被当作环境并求迹**——假设环境初态 $\sigma_E$ 独立制备且与逻辑输入无关；真实系统中未必满足。
3. **坐标重定义 $q'=q+\Lambda(y)$ 混合了观测与未观测坐标**，因此制备与读出必须随态一起搬运，否则定义的是不同的实验——这是概念上的微妙之处。
4. **多连通域下全局移除还需 $A$ 的周期为零**，论文只给出局部移除的完整判据。
5. **Frobenius 型的连接曲率判据**在零曲率时给出局部移除，但全局拓扑障碍需另行处理。
6. **数值算例规模小**（四坐标族、有限模式截断、Dirichlet 基），精度依赖附录 C 的分辨检验。
7. $U=0$ 的简化（无外势）。
8. 与流体力学主流问题（湍流、边界层、多相流）无直接关联，属**几何/量子流体交叉领域**。

## 实现建议

- **实现难度**：高（几何力学 + 量子信息 + 数值线性代数多门交叉）。
- **预期性能**：算例规模小（4 坐标、有限模式），普通 CPU 可跑。
- **适用场景**：
  - 量子化流体模型的理论基础
  - 「经典自由度与量子环境耦合」的几何表述
  - 退化/相干性分析的方法论参考
- **落地建议**：
  1. **复现顺序**：先复现 Nambu 作用量变分给出 Euler 方程 → 再实现度规 $G_{rs}$ 的数值积分 → 验证 $X_2-X_E$ 的 $O(t^2)$ 与 $X_4-X_E$ 的 $O(t^3)$ 误差阶 → 再做 DMD/量子退相干
  2. **关键检查点**：$A_a=G_{qa}/G_{qq}$ 与 $B=\frac12\{c_a,\pi_a\}$ 的计算；$F_0$ 是否非零决定符号相干性
  3. **最实用的结论**：$A=0 \iff B=0 \iff \widehat H(p)=\widehat H(-p)$ —— 这是一条**可直接用于数值检验的判据**：算出条件哈密顿量的 $p$ 依赖部分，若为奇函数则符号为精确无噪声子系统
  4. **对流体力学的间接启发**：Euler 残差作为「投影到无散场的不可压加速度残差」是一个可直接用于**数值验证**的工具——若某数值格式的 $\mathcal A$ 减去 $\alpha\beta\nabla\psi$ 后残差为零，说明该格式在该工况下精确满足 Euler 兼容（Nambu 笔记 pp.5–6 的判据）
  5. 注意附录 C 提供了初始系数、有限时间损失与交叉时刻的**分辨检验**，复现时应一并核对
