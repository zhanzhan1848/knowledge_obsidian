## 核心贡献

> 当 PDE 代理模型的**参数就是流场域本身**时，注意力模型的 key/value 集必须编码这个域。CARS 把**患者自身的中心线**用作注意力 focal set，把几何融合成本从 `O(N²)` 降到 `O(N·n_f)`。

1. **几何锚定的 tiered attention**：两阶段 transformer —— Stage 1 用中心线 token 作 focal set 做几何融合（中心线 token 用完即弃），Stage 2 用体积 token 随机子采样作 anchor 做场细化。
2. **求值点作为映射的"参数"**：推理时给定求值点，同一套权重可在任意求值密度下工作（4,096 → 65,536 点，压力误差变化 ≤ 0.004，在 0.005 等价容差内）。
3. **流量以 FiLM（特征级线性调制）方式乘性进入** —— 与该工况下近似线性的压力–流量标度一致。
4. **性能**：单例 **87 ms** vs 求解器 572–1,063 s（8 MPI 秩）；压力相对 ℓ₂ 误差 LCA 0.120 / RCA 0.063；速度 0.149 / 0.119。
5. **功能性验证**：由预测压力导出的 **FFR** 与 CFD 标签 Pearson r = 0.941 / 0.993，**FFR ≤ 0.8 决策在 97.7% / 96.3% 的留出案例中复现**。
6. **消融**：学习式注意力级坐标嵌入比无参 3D rotary 编码降误差 27–30%（仅 +0.3% 参数）；中心线 anchor 优于学习式 inducing points 与表面离散 anchor；**精度在 focal 数以下 8 倍即饱和**。

## 技术方案

### 核心思想

冠脉血流预测 = 评估一个**参数化解映射**，而**参数就是流场域本身**：

- 域族**低维性缺失**：分支拓扑、终端分支数与口径、曲率与挠率、局灶狭窄位置形态均变化，没有小规模形状参数集可描述。
- 投影类 ROM 失效：需要共同参考构型 + 正则形变族，而分支数/连通性不同的冠脉树**不满足**该前提。
- 学习型代理在固定网格上失效：管腔体积既非结构化也非定长。
- 注意力代理在体积上失效：注意力成本 `O(N_v²)`，而冠脉体积需要大量点（分辨率由最窄狭窄喉部决定，但关心量只是跨狭窄压差）。

**关键洞察**：域族虽作为形状集合不可压缩，但由**低维对象生成** —— 血管是曲线周围的管，该曲线 + 逐点管腔半径已承载解所依赖的大部分几何信息。

### 关键技术

| 技术 | 说明 |
|------|------|
| Tiered attention | 查询来自全部 N 个 token，key/value 仅来自 n_f 个 focal token；得分矩阵 N×n_f。N×n_f 上块为 intra-focal attention（区别于普通 cross-attention）；其余 N−n_f 行为 context 行（只读 focal，不被读） |
| 两阶段结构 | Stage 1 几何融合：中心线 `X_c` 作 focal，用完丢弃，仅 `X_v` 传入 Stage 2。Stage 2 场细化：均匀随机体积 token 子采样作 anchor；运行点 `N_va = N_v` 时退化为全自注意力 |
| 位置编码 | 学习式**注意力级坐标嵌入**（投影后的 query/key 上的可学习偏置），对照 RoPE3D |
| 通道结构 | pre-LayerNorm 多头 tiered attention → GELU 前馈 → 残差连接 |
| FiLM 流量调制 | 入口流量 Q 以特征级线性调制作用于 Stage 2 后的体积特征 |
| 读出 | 单一线性层读出逐点静压 p̂_j 与三分量速度 û_j |
| 参考解 | OpenFOAM 有限体积，**固定 4000 次 SIMPLE 迭代**，六面体网格，分辨六面体网格 |
| 数据集 | 两个 territory 各 3,300 解（合计 6,600），含**合成局灶病变**；每 territory 留出 300 例测试 |
| 基线 | 四个**参数匹配**的神经算子 + 替代 focal 表示（学习式 inducing points、表面离散 anchor） |
| 泛化三义 | G1–G3（域内 / 拓扑内 / 跨 territory）分别检验 |

## 公式

```math
代理映射（几何 → 场）：
  输入：中心线 X_c（带逐点管腔半径 r_j）、标量入口流量 Q、求值点 {x_j}
  输出：静压 p̂_j，三分量速度 û_j

注意力成本（几何融合）：
  O(N_v · n_f)  而非  O(N_v²)      （n_f = 中心线 focal 数）

tiered attention 得分矩阵形状：
        [ n_f × n_f  ]   ← intra-focal（tiered 独有）
  S  =  [              ]
        [ (N−n_f) × n_f ] ← context 行：读 focal，但不被 focal 读

FiLM 流量调制：
  h ← h ⊙ (1 + W_q · Q) + b_q

FFR（分数血流储备）：
  FFR = p_distal / p_proximal      (充血态下远端/近端静压比)
  决策阈值：FFR ≤ 0.8  → 狭窄具血流限制意义

评价：
  相对 ℓ₂ 误差 ‖û − u_ref‖₂ / ‖u_ref‖₂
```

## 代码片段

```python
# CARS 两阶段 tiered attention（伪代码）
# --- Stage 1: 几何融合，focal = 中心线 token ---
Xc = centerline_tokens          # [n_f, d_c]  含逐点管腔半径
Xv = volume_tokens             # [N,   d_v]  体内求值点
h  = embed(Xv) + pos_bias(Xv)  # N 个 query
focal = embed(Xc) + pos_bias(Xc)  # n_f 个 key/value

# key/value 只取自 focal 行；含 focal 上块 intra-focal attention
S = Q(h) @ K(focal).T / sqrt(d)      # [N, n_f]
S[:n_f, :] = S[:n_f, :] + intra_focal_bias
h = h + MHA(h, focal, focal, S)      # 只保留 query 侧的 N 行
# 中心线 token 用完即弃，不进入 Stage 2

# --- Stage 2: 场细化，focal = 体积 token 随机子采样 ---
anchors = Xv[random_subset(n_va)]   # 运行点 n_va = N 时为全自注意力
h2 = h + MHA(h, anchors, anchors)
h2 = h2 + FFN(GELU(LN(h2)))

# --- FiLM: 入口流量乘性调制 ---
h2 = h2 * (1 + W_q * Q) + b_q

# --- 读出 ---
p_hat, u_hat = Linear(h2)          # 静压 + 三分量速度
```

## 实验结论

- **数据集**: 6,600 例 OpenFOAM 稳态有限体积解（左冠 LCA + 右冠 RCA 两个 territory），含合成局灶病变；各 300 例留出测试
- **基线**: 四个参数匹配的神经算子；替代 focal 表示
- **结果**:
  - 压力相对 ℓ₂：**LCA 0.120 / RCA 0.063**；速度：LCA 0.149 / RCA 0.119
  - 成本：**87 ms/例** vs 求解器 **572 s（RCA 中位）/ 948–1,063 s（LCA）**，8 MPI 秩
  - **FFR 功能性**：Pearson r = 0.941（LCA）/ 0.993（RCA）；**FFR ≤ 0.8 决策复现率 97.7% / 96.3%**
  - 参数量与基线在 **3% 以内**，相同划分
  - 求值密度 4,096 → 65,536（16×）时压力误差变化 ≤ 0.004
  - 消融：注意力级坐标嵌入降误差 27–30%（+0.3% 参数）；中心线 anchor 优于学习式 inducing points 与表面 anchor；精度在 focal 数**以下 8 倍即饱和**
  - 生理区间 LCA 端点分析子集：**286 例**

## 局限性

- **预测速度不满足连续性方程到足够精度**，因此不能用于导出量（作者明确声明）
- **权重是 territory 专属**（每 territory 单独训练），跨 territory 泛化未验证
- 消融**未隔离核心假设**：作者自陈"关键在于 focal set 依附于生成域的对象，而非 focal token 数量或它们承载的几何"——但每个移动 focal set 的分支同时也改变了几何通道或位置处理，**因果未分离**
- 位置编码存在**频率尺度混淆**（作者注明）
- 上游几何（ImageCAS）与 OpenFOAM 流水线固定，域族变化超出本文范围
- 与同组姊妹论文（各向异性径向基解码器）共享 ImageCAS 源与 OpenFOAM 流水线族，但**数据集、权重、图表无共享**
- 代理目标是**稳态**不可压 NS，不含脉动与湍流

## 实现建议

- **实现难度**: **中高** — 核心是标准 transformer（tiered attention + FiLM），但需自建 OpenFOAM 批量参考解流水线（6,600 例 × 4000 SIMPLE 迭代），数据生成成本是主要门槛
- **预期性能**: 单例推理 87 ms（fp32）；参考解生成按 8 秩并行计约 6,600 × ~800 s ≈ 146 CPU-小时（**一次性成本**）
- **适用场景**:
  - 冠脉 ct-FFR 无创评估（临床价值最高，已有 RCT 验证基础）
  - **参数即域**的代理问题：血管网络、鳃/肺支气管树、树枝状结构、多孔介质通道网络
  - 几何优化 / 反问题：狭窄位置与形态的快速评估（流动率 × 几何参数 → 压降）
- **落地建议**:
  1. 核心洞察可推广：**focal set 应当依附于生成域的低维生成对象**（曲线 + 半径剖面），而非域的采样点
  2. `O(N·n_f)` 的复杂度优势在求值点很多时才有意义 —— 若目标场景求值点少（如仅测压差），收益有限
  3. **必须验证连续性**：速度场不满足连续性则不可用于导出量，若下游需要流量守恒量，应改为预测压力 + 标量流量，或加入连续性投影损失
  4. 建议**先做基线对齐**：与四个参数匹配神经算子的对比说明"几何锚定"确有增益，不是单纯参数量差异
- 推荐结论：✅ **推荐实现** —— 本窗口内**最完整的一份"ML-for-CFD"工程范式报告**（数据 → 架构 → 消融 → 功能性决策验证 → 成本）。**"用功能性阈值而非范数评价代理模型"**这一点值得直接抄进我们的 CFD 代理评估流程。
