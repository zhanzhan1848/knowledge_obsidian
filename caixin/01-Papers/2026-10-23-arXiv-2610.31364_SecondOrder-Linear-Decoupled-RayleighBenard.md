# Second-Order Linear Decoupled Scheme for Rayleigh-Bénard Convection

**arXiv**: [2610.31364](https://arxiv.org/abs/2610.31364) · **提交**: 2026-10-22 14:41 UTC
**作者**: Matthew McCurdy · **篇幅**: 38 页，10 图

## 方法：零能量松弛变量

**核心技巧**：把非线性项显式处理，但乘以一个**精确取值为 1 的标量**，且该标量**不向连续问题贡献能量**。

结果：
```
每个 BDF2 步（配 rotation pressure correction）
    → 只解 常系数线性问题（constant-coefficient linear）
```

| 属性 | 状态 |
|------|------|
| 时间精度 | 二阶（BDF2） |
| 线性性 | ✅ 完全线性 |
| 完全解耦 | ✅ 旋转压力修正 |
| 非线性处理 | 显式 |
| 单元类型 | Taylor–Hood |

## 稳定性分析（理论证明）

| 条件 | 结论 |
|------|------|
| 壁面**等温** | 对**任意时间步长**，能量**衰减**（在热权重条件满足下） |
| 从下方加热 | 能量在有限时间区间**有界** |
| 标量向 1 松弛 | 上述两个估计**均保持** |

**松弛 vs 未松弛**：
- **能量稳定性**：使用松弛标量 ✓
- **精度**：使用未松弛值（=1）计算速度与温度场

**偏差标度**：`O( (E/C)(δt/τ)³ )`
- `E` = 动能
- `τ` = 流动时间尺度
- `C` = 标量方程权重
- `δt` = 时间步长

→ 取 `C ~ E` 可使偏差保持小值。

## 验证结果

| 验证项 | 结果 |
|--------|------|
| 时间收敛阶 | 二阶 ✓ |
| 临界 Rayleigh 数 | 恢复 ✓ |
| Nusselt 数 | 与已发表结果吻合 **0.5% 以内** |
| 最大时间步（稳态卷 rolls，10⁻⁸ 相对差） | **加倍** |
| 三维实现 | 通过对应验证测试 |

**边界条件**：Navier-slip walls（自由滑移 + 摩擦）

## 数值方法评估

| 维度 | 评价 |
|------|------|
| 离散化 | Taylor–Hood FEM + BDF2 |
| 求解器 | 全线性 → **可用直接法/预条件并行**（无需非线性迭代） |
| 线性系统系数 | 常数（关键优势：可预因子化/预条件复用） |
| 稳定性 | 理论证明（等温衰减 + 加热有界） |
| 精度控制 | 能量稳定 ⇏ 标量精度，需 `C ~ E` 调参 |
| 适用性 | 对流稳定性问题（Rayleigh–Bénard）|

## 推荐结论

✅ **推荐实现**。这是**数值稳定性 + 计算效率**兼优的方案：
1. **完全线性**意味着可复用因子分解 → 大规模 3D 计算成本显著低于非线性隐式格式
2. 理论稳定性证明严格（任意步长/有限区间），不靠经验 CFL 调参
3. ⚠️ 唯一调参是 `C`（标量权重），取 `C ~ E` 即可；`C` 同时控制精度与最大可用步长
4. 验证精度（Nusselt 0.5%）达到可用于基准算例的标准
5. 三维已验证 → 可直接迁移至湍流对流/混合对流
