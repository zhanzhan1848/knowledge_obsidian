# Bridging the Lattice Boltzmann Method and Moment Methods

**arXiv**: [2610.26631](https://arxiv.org/abs/2610.26631) · **v2**: 2026-10-20 22:48 UTC (v1: 2026-10-19)
**作者**: Jinhua Lu, Song Zhao, Pierre Boivin, Pierre Sagaut, Nikolaus A. Adams
**机构**: Aix Marseille Univ (CNRS, Centrale Med, M2P2) · TU Munich (TUM)
**篇幅**: 6 页，2 图 · **MSC**: 76P05 · **APS/123-QED**（PRL 格式 Letter）
**资助**: Humboldt Foundation · 法国 COLIBRI 项目 (DGAC) · ANR LIBERTY 工业椅 (ANR-23-CHIN-0005)

## 一句话总结

推导出**与 LBM 严格等价的离散矩方程**，并由此**显式识别出所有 DVBE 类动理学方法共享的通用矩闭合**，从而建立统一矩框架，使经典矩方法（moment methods）得以覆盖**全 Knudsen 数区间**（含高 Kn 下本不可行的数百元耦合方程），同时保留 LBM 的低声学耗散、独立碰撞步（矩依赖输运系数）、非结构网格与离格速度集能力。

---

## 背景：矩方法的两难

基于 Boltzmann 方程的两大动理学方法族：

| 族 | 代表 | 优势 | 痛点 |
|----|------|------|------|
| **矩方法** (moment methods) | Grad 13/26-moment, Burnett | 高阶非平衡矩有显式演化律 | **闭合困难** + **高 Kn 复杂度爆炸**（数百耦合方程） |
| **DVBE 类** | DVM, UGKS, DUGKS, **LBM** | 高 Kn 有效，壁面处理强 | 分布函数表示，难以直接写高阶矩演化 |

**矩闭合的三条既有路线及其失败**：
1. **Chapman–Enskog 逐级展开**：Burnett / super-Burnett 方程**不适定**；模耦合理论与数值模拟表明相关输运系数在热力学极限**发散** → 梯度修正非解析，正则 CE 展开无法表示
2. **Grad 13-moment（Hermite 截断）**：**非全局双曲**，可能给出非物理解；regularized moment 需额外 CE 项
3. **熵基闭合**（H-函数最小化）：隐式求解，成本高

**既有结论**：矩方法实际应用被限制在**中低阶模型（13/26-moment）+ 中等 Kn**。

> 早期工作 [3]（Ansumali et al., PRL 2007）已用 LBM 分布函数作矩闭合，解析求解了二维 D2Q9/D2Q16 稀fied 平面 Couette 流，但**未提炼出 DVBE 通用闭合原理**，也未揭示该闭合在 LBM 完全离散矩方程中如何运作，未推广到非定常流、复杂几何与高 Kn。

## 核心贡献

### 1. LBM 的严格等价离散矩方程

**Step A — DVBE 离散速度 Boltzmann 方程**

$$\partial_t f_i + e_{i\alpha}\partial_\alpha f_i = \Omega_i(\ket{f})$$

**Step B — 特征线梯形积分**（二阶时空精度）

$$f_i(\mathbf{x}+\mathbf{e}_i\delta t, t+\delta t) - f_i(\mathbf{x}, t) = \frac{\delta t}{2}\big[\Omega_i(\mathbf{x}+\mathbf{e}_i\delta t, t+\delta t) + \Omega_i(\mathbf{x}, t)\big]$$

**Step C — 变量替换消去显式碰撞项**：$\bar f_i = f_i - \Omega_i \delta t/2$

$$\bar f_i(\mathbf{x}+\mathbf{e}_i\delta t, t+\delta t) - \bar f_i(\mathbf{x}, t) = \Omega_i(\mathbf{x}, t)$$

这正是 LBM 求解的三步（碰撞 → 迁移 → 变量更新）。

**Step D — 投影到主矩**（D2Q9 情形）

$$M_{x^m y^n} = \sum_i e_{ix}^m e_{iy}^n \bar f_i, \qquad \ket{M} = [P]\ket{\bar f}, \qquad [P]_{ji} = e_{ix}^m e_{iy}^n$$

投影矩阵 $[P]$ **可逆** → 9 个 DVBE **无损**改写为 9 个主矩方程。

**Step E — 连续形式矩迁移方程**

$$M_{x^m y^n}(\mathbf{x}, t+\delta t) = \sum_{p,q=0}^{+\infty} \frac{(-\delta t)^{(p+q)}}{p!q!}\partial_x^p\partial_y^q M_{x^{(m+p)} y^{(n+q)}}^{\text{col}}$$

**Step F — 完全离散形式**（关键）：用 $3\times3$ 模板上的 **Taylor 展开 + 可逆矩阵 $[W]$** 将连续高阶导数替换为模板上的**近似导数**

$$M_{x^m y^n}(\mathbf{x}, t+\delta t) = M_{x^m y^n}^{\text{col}} + \sum_{\substack{p,q=0\\(p,q)\neq(0,0)}}^{N-1}\frac{(-\delta t)^{(p+q)}}{p!q!}\underline{\left(\partial_x^p\partial_y^q M_{x^{(m+p)} y^{(n+q)}}^{\text{col}}\right)}$$

> **本文与既有「从 LBM 导出矩方程」工作的区别**：既有工作（Bellotti et al., Le Clainche, 等）一般会**修改隐式矩闭合**；本文**显式保留全部高阶矩**，这是揭示底层闭合的前提。

### 2. 识别出的通用矩闭合

高阶矩由主矩的**线性组合**给出：

$$M_{x^m y^n} = \bra{A^{(m,n)}}[P]^{-1}\ket{M}, \qquad \text{for } m > N-1 \text{ or } n > N-1$$

**Remark 1 — 普适性**：闭合仅依赖两个要素 —— (a) 矩定义，(b) 分布函数 ↔ 线性无关主矩集之间的**可逆变换**。二者对**任何有限离散速度集**成立 → 该闭合同样适用于 DVBE 及其他 DVBE 类方法：

$$\partial_t M_{x^m y^n} + \partial_x M_{x^{m+1} y^n} + \partial_y M_{x^m y^{n+1}} = \Omega(\ket{M})$$

**Remark 2 — 不同速度集 = 不同闭合**：

| 速度集类型 | 特点 |
|-----------|------|
| **半区间 Gauss–Hermite** | 精确捕捉壁面效应（off-lattice） |
| **全区间 Gauss–Hermite** | 以最少离散速度数达高阶积分精度 |
| **Newton–Cotes** | 适合强非平衡效应 |

**选择原则**：在**粒子速度空间高概率区域**提供足够分辨。

**Remark 3 — 闭合的固有偏差**：高阶矩作为主矩线性组合**一般偏离精确值**。Gauss–Hermite 系速度集可精确恢复某些高阶**平衡**矩，但**不能**精确恢复高阶**非平衡**矩；半区间 GH 甚至给出完全非精确的高阶矩。但高阶 LBM / DVBE 方法的成功应用表明偏差影响**沿矩层级被约束**，不主导物理解。

> **方法论意义**：新路线**不需要精确重构高阶矩**，而是**控制高阶矩误差对低阶矩的影响** —— 这大幅拓宽了既有「追求越来越精确的高阶矩表示」的闭合策略。

### 3. 两个保证全 Kn 稳定的离散特性

**(a) Lax–Wendroff 型格式**：二阶时间导数转为二阶空间导数，产出物理一致的耗散项以稳定计算。零阶矩方程：

$$\rho(t+\delta t) = \rho - \delta t\,\partial_\alpha(\rho u_\alpha) + \frac{\delta t^2}{2}\partial_\alpha\partial_\beta(p\,\delta_{\alpha\beta} + \rho u_\alpha u_\beta) + O(\partial^3)$$

等价于 $\rho - \delta t\partial_t\rho + \frac{\delta t^2}{2}\partial_t^2\rho + O(\delta t^3)$。

**(b) 时间积分同时考虑粒子对流与碰撞**（Eq. 4）—— 连续介质区碰撞时间尺度远短于流动时间尺度时，此项**必需**。

---

### 4. MEGKS：矩方程版气体动理学格式

**MEGKS** (moment-equation-based gas-kinetic scheme) = 解 LBM 离散矩方程的**有限体积**格式，保留 LBM 的碰撞与迁移步。

- **局部碰撞步**与 LBM **完全相同**（Eq. 11）
- **迁移步**写成有限体积形式（Eq. 21），含控制体 $\delta V$、外法向 $\mathbf{n}=(n_x,n_y)$、面面积 $\delta S$
- 对一般 $N\times N$ 离散速度集，系统为 $N^2$ 个主矩方程

**验证：全 Kn 区间平面 Couette 流**

- 两平行板间距 $H$，壁面速度 $\pm u_w$，**漫反射散射边界条件**，流向周期
- 修正 Knudsen 数 $k = (\sqrt{\pi}/2)\,\mathrm{Kn}$，**$k$ 从 0.001（连续区）扫到 100（自由分子区）**
- $\mathrm{Kn} = \lambda_F/H = \frac{\mu}{p}\sqrt{\frac{\pi RT}{2}}$
- 速度集：**D2Q18²**（半区间 Gauss–Hermite 张量积）→ **324 个闭合矩方程**
- 结果：与 **DUGKS** 和 **DSMC** 数据**全 Kn 区间吻合良好**

> **意义**：显式推导并求解数百耦合方程在传统矩方法中**代价不可承受**；本框架高效处理此类高阶系统。

## 框架带来的四大能力扩展

| # | 能力 | 说明 |
|---|------|------|
| **1** | **LBM 完全等价性** | 均匀速度集下与 LBM **严格等价**，保留均匀网格上低阶 LBM 的**极低声学耗散**特性（Suppl. Sec. IV 验证） |
| **2** | **矩依赖输运系数** | 继承 LBM 半显式离散 → **独立碰撞步** → 可按所选分子碰撞模型设置**各矩独立弛豫率**。<br>对比：DUGKS 等将输运与碰撞耦合演化，常被迫用 BGK（所有非守恒矩单一时标）；Shakhov 模型 / 椭球统计模型只修正热流与应力的弛豫，**无法给高阶矩独立弛豫率**。这对**高 Ma 稀fied 流**至关重要 |
| **3** | **非结构网格 + 离格速度集** | 解除 LBM 的网格与速度集约束（如 Couette 测试中的半区间 GH 离格速度集） |
| **4** | **局部自适应速度集** | 见下 |

### 局部自适应速度集

**动机**：为最大化精确恢复的高阶平衡矩数量（提升物理保真度同时**减少离散速度数与计算成本**），用局部流速平移、用局地温度缩放 GH 节点：

$$\mathbf{v}_i = \mathbf{u}_{\rm ref} + \mathbf{e}_i\sqrt{T_{\rm ref}/T_L}$$

其中 $\mathbf{u}_{\rm ref}$、$T_{\rm ref}$ 为局部宏观量，$T_L$ 为格点温度。

**对比现有做法**：
- *particles-on-demand LBM* 需要在不同局部速度集之间**反复投影分布函数**（受矩不变性约束）
- *多尺度模拟* 中速度集按局部 Kn 自适应以提效，同样有投影问题

**本框架的解法**：信息交换**直接在矩空间进行**，**避免在不同动理学表示之间反复投影分布函数**。

- 低阶 → 高阶：缺失的高阶平衡矩是**精确 Maxwell 矩**，非平衡矩用 Eq. 19 重构
- 高阶 → 低阶：所需主矩**直接取得**

**概念验证**：多尺度 Couette 流（$k=0.1$）
- 中心区：**D2Q3²**（全区间 GH 节点）
- 近壁区：**D2Q4²**（半区间 GH 节点）
- 与 DSMC / DUGKS 参考吻合 ✓

## 数值方法评估

🥢 **可行性分析：LBM 与矩方法的统一框架**

### 控制方程
Boltzmann 方程（等温）：
$$\partial_t f(\mathbf{x}, \bm\xi, t) + \xi_\alpha\partial_\alpha f(\mathbf{x}, \bm\xi, t) = \Omega(f)$$

### 数值方法
- **离散化**：D2Q9 演示 → 投影矩阵 $[P]$ 可逆；完全离散通过 $N\times N$ 模板上的 Taylor 展开 + 可逆矩阵 $[W]$
- **求解器**：MEGKS（有限体积），局部碰撞步 = LBM 碰撞步；**无分布函数存储需求** → 矩空间操作
- **稳定性**：Lax–Wendroff 型耗散项 + 同步对流/碰撞时间积分 → 全 Kn 稳定

### 计算成本
| 维度 | 评估 |
|------|------|
| 存储 | 矩空间（$N^2$ 主矩）替代完整分布函数 → **非结构网格下优势巨大** |
| 方程数 | D2Q18² → 324 耦合方程（传统矩方法不可行） |
| 时间步 | 半显式（碰撞 + 迁移分离），精度二阶 |
| 并行性 | 有限体积框架 → 天然单元并行；碰撞步局部、迁移步需全域移流 |

### 边界条件
- **漫反射散射**（diffuse-scattering）用于壁面 —— 正确处理壁面诱导非平衡效应
- 流向周期

### 稳定性分析
- Lax–Wendroff 格式 → 物理一致耗散
- 关键：**不依赖 CE 逐级展开**，避免 Burnett/supar-Burnett 不适定问题
- Remark 3 承认高阶矩偏差影响**尚未严格分析**（开放问题）

### 适用场景
- **稀fied 气流动力学**（全 Kn）
- 高 Ma 稀fied 流（需矩依赖输运系数）
- 壁面受限高 Kn 流（离格速度集）
- 多尺度/自适应速度集模拟

## 推荐结论

✅ **强烈推荐实现（研究性价值极高，工程落地需评估）**

**理由**：
1. **概念突破级**：首次严格推导 LBM 的等价离散矩方程，并**显式识别 DVBE 通用矩闭合** —— 这是连接两大动理学方法族的缺失环节
2. **突破高 Kn 瓶颈**：324 个耦合矩方程在传统矩方法中不可行，本框架可高效处理 → 填补「矩方法止步中等 Kn」的空白
3. **保真 LBM 优势**：均匀网格下与 LBM 严格等价 → **保留低声学耗散**；独立碰撞步 → 支持**真实分子碰撞模型的各矩独立弛豫率**（BGK/Shakhov/ESM 都做不到）
4. **解除 LBM 约束**：非结构网格 + 离格速度集，打破 LBM 对壁面受限高 Kn 流的适用性限制
5. **多尺度投影问题的优雅解**：在矩空间直接交换信息，避免分布函数反复投影
6. **验证扎实**：全 Kn 区间与 DSMC（gold standard）+ DUGKS 双重对照

**风险与成本**：
- ⚠️ 论文仅 6 页（PRL Letter 格式），**实现细节与高阶 MEGKS 简化版在 Supplementary Material**，完整复现需取得 SI
- ⚠️ Remark 3 承认**高阶矩偏差对低阶矩的影响尚未严格分析** —— 理论完备性有缺口
- ⚠️ **324 方程系统的线性求解器**是实际瓶颈：直接法不可行，需块结构预条件 + Krylov
- ⚠️ 极短篇幅 → 数值验证案例有限（仅 Couette 流），复杂几何 / 非定常 / 三维的鲁棒性待验
- ⚠️ 依赖 `${SUPPL}` 补充材料，工程可复现性存疑

**对 @墨鱼丸 的实现建议**：
1. **优先级**：先做 **D2Q9 (9 方程) 版本**的 MEGKS 复现 —— 方程数少，可在 CPU 上快速验证与 LBM 的严格等价性
2. **验证顺序**：① 与原 LBM 在均匀网格逐点对比（验证等价性）→ ② 平面 Couette 流扫全 Kn 对比 DSMC → ③ 加半区间 GH 离格速度集 + 非结构网格 → ④ 多尺度自适应
3. **数值工具**：矩方程组建议 **块 Jacobi + 预条件 GMRES**；利用 LBM 碰撞步的**局部性**做空间并行
4. **里程碑判据**：能复现 Fig. 1 的 $\tau_{xy}/\tau_\infty$ 全 Kn 曲线 + k=0.1/1/10 速度剖面，即达成论文核心声明
