## 核心贡献

> 用 PCA+MLP 代理模型让 24 参数的**全局 Sobol 分析**变得可行，量化"边界条件不确定性"与"热效应/植被效应"在街道峡谷流场中的竞争关系

1. 方法：RANS 仿真训练代理（**PCA + 多层感知机**）→ 使 **24 参数的全局 Sobol 分析**可承受
2. 考察两种通风机制（弱通风 / 强通风），逐步**收紧其余输入的不确定度**，观察热效应与植被参数的方差贡献何时占据主导
3. **典型不确定度下**：**湍流封闭常数**与**进口湍流剖面**主导速度、温度、浓度三个场的变异性
4. **弱通风**：其余不确定度减半后，**太阳强迫**成为温度变异的主要来源；减到四分之一后成为浓度方差的主要来源（主导封闭常数 ±11%、排放率 ±12%）
5. **植被**在典型不确定度下有显著贡献；但**强通风下，冠层在任何情况下都无法超过封闭常数**，即使主导常数已知到 ±5%
6. 空间上，**两种效应在路面高度与峡谷壁面处达到峰值**（影响室外暴露与室内渗透）

## 技术方案

### 核心思想

实践者常忽略热效应与植被，但它们可能被**其他输入的不确定度**所掩盖。本文回答：需要把模型参数与边界条件知道多精确，这些效应才能主导输出不确定度？

### 关键技术

| 技术 | 说明 |
|------|------|
| RANS 代理 | PCA 降维 + MLP 非线性映射，用于 Sobol 采样 |
| 全局 Sobol 分析 | 24 参数，一次性给出各参数方差贡献 |
| 不确定度逐级收紧 | "其余输入不确定度减半/减至四分之一"的扫描设计 |
| 两种通风机制 | 弱通风（热效应显著）vs 强通风（机械通风主导）|
| 空间分辨诊断 | 定位峰值区域（路面、峡谷壁）|

## 公式

```math
Sobol 指数（全局）:
  S_i = Var_{X_i}( E_{X_{\i}}(Y) ) / Var(Y)

代理模型:
  Y(x) ≈ MLP( PCA(u; x) )
  PCA: u ∈ R^{N_dof} → z ∈ R^K
  MLP: z → Ŷ

不确定度收紧扫描:
  for σ_level ∈ {typical, /2, /4}:
      固定 X_i (i ∈ 热效应 ∪ 植被) 不确定度
      其余 X_j 噪声水平置为 σ_level
      重算 S_i

通风机制判据:
  弱通风: 浮力驱动,  Richardson 数高
  强通风: 机械/几何通风主导, 风速大
```

## 代码片段

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.neural_network import MLPRegressor
from SALib.sample import sobol as sobol_sample
from SALib.analyze import sobol as sobol_analyze

def build_surrogate(runs_u, runs_y, n_components=32):
    """runs_u: (N, D) 输入参数样本, runs_u_field: (N, Ndof) 场"""
    pca = PCA(n_components=n_components).fit(runs_u_field)
    Z = pca.transform(runs_u_field)
    mlp = MLPRegressor(hidden_layer_sizes=(256, 256), max_iter=2000).fit(Z, runs_y)
    return pca, mlp

def run_sobol_sweep(surrogate, param_names, sigma_levels, thermal_idx, veg_idx):
    for sigma in sigma_levels:
        problem = {"num_vars": len(param_names), "names": param_names,
                   "bounds": [[0, 1]] * len(param_names)}
        X = sobol_sample.sample(problem, 4096)
        # 按 sigma_level 设定其余参数噪声
        X = apply_noise_levels(X, thermal_idx, veg_idx, sigma)
        Y = surrogate.predict(X)
        S = sobol_analyze.analyze(problem, Y)
        yield sigma, S
```

## 实验结论

- **数据集**: 2D 街道峡谷 RANS 仿真（24 参数，代理模型驱动）
- **基线**: 无代理的直接 Sobol（不可承受）
- **结果**:
  - **典型不确定度**：湍流封闭常数 + 进口湍流剖面主导三场变异性
  - **弱通风**：其余不确定度减半 → 太阳强迫主导温度；减至四分之一 → 主导浓度
  - **植被**：典型水平下贡献显著；**强通风下永不超过封闭常数**（即使主导常数已知到 ±5%）
  - 空间峰值：路面高度 + 峡谷壁面（影响室外暴露与室内渗透）

---

## 局限性

- 仅 **2D** 街道峡谷（真实街道峡谷为 3D，且建筑几何非理想）
- 代理模型引入了自身误差，Sobol 指数对代理精度敏感
- 湍流模型固定为 RANS（k-ε 类），结论对 LES/DNS 的迁移性未知
- 植被模型为参数化简化，未含真实植被风影与热效应耦合
