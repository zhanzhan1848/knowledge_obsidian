## 核心贡献

> 用 **Fourier Neural Operator (FNO)** 学习无穷深、无粘、无旋自由面驻波的**解算子** $\mathcal{S}_\theta:(\eta_0,\tau)\mapsto(\eta,\varphi,\mu)$，在训练区间内相对 $L^2$ 误差 $<10^{-3}$；并通过两个精心设计的 **OOD 实验**（分别外推到自由落极限与线性极限）+ **控制方程残差**诊断，区分出「误差大但动力学仍然自洽」与「已经不再代表驻波」两类外推失效。

1. **解算子（而非降阶基）的直接学习**：一次前向评估直接给出任意归一化时刻 $\tau$ 的完整状态（自由面高度 $\eta$、表面速度势迹 $\varphi$、偶极密度 $\mu$），**不做时间步进**、**不投影到模态基**，且评估代价与 $\tau$ 无关。
2. **两个方向相反的 OOD 实验**：Experiment I（$\varepsilon\to 0$，自由落极限）与 Experiment II（$\varepsilon\to 1$，线性极限）各扣留一端连续 10 个解，暴露出**两种性质完全不同的误差来源**——前者是谱截断（尖峰分辨率不足），后者是标准化归一化导致的相对误差放大。
3. **参考解无关的残差诊断**：由预测的 $\eta,\varphi$ 直接构造控制方程残差 $R$，可在**无参考解**的探索性预测中用于评估候选驻波；这是本文最具方法论价值的设计。
4. **参数化的关键选择**：引入无量纲波峰加速度 $\varepsilon=1-A_c/g$ 作为一维参数，它在数据集上**单调递减**，而波高 $h$ 不是单调的（在 idx=209 处有极大值），因此是划分 train/ID/OOD 的正确坐标。

## 技术方案

### 核心思想

驻波问题：二维无穷深、无粘、不可压、无旋流体的自由面做**时空周期**运动。参考解由 Wilkening & Yu 的**过定射击法**（overdetermined shooting method）以谱精度算出——每次求解一个非线性边值问题，代价由 Jacobian 计算主导，**从线性端的秒级到自由落端的数小时**，且每次运行只给出一个参数点。

本文把学习目标定为**解算子**而非解：
$$\mathcal{S}_\theta:(\eta_0,\tau)\longmapsto(\eta,\varphi,\mu)(\cdot,\tau T/4),\qquad \tau\in[0,1]$$
其中 $\eta_0=\eta(\cdot,0)$ 是静止时刻的波形，$T=T(\eta_0)$ 是周期（作为输出被排除在学习问题之外，需要物理时间时再转换）。所有成员共享从静止态（$\tau=0$）到平表面态（$\tau=1$，四分之一周期）的共同区间。

**为什么 FNO 特别合适**（作者列出三条硬理由）：
1. 空间域是**周期**的、数据在**均匀网格**上 → 不需要边界处理或 padding；
2. 线性驻波只有基频（$\cos x\cos t$），非线性驻波含高次谐波 → 与 FNO 的 Fourier 多重子结构天然匹配；
3. Dirichlet–Neumann 算子 $G(\eta)$ 在**平表面极限下退化为 Fourier 乘子** $G(0)\varphi=\sum_k|k|\hat\varphi_ke^{ikx}$ → 与 FNO 的谱卷积形式同构。

**数据与对称性**：数据集 140 个解（idx=101–240），每个解在 $[0,T/4]$ 上 201 个时间快照，在 $[0,\pi]$ 上 257 个空间点采样 $\eta,\varphi,\mu$；利用关于 $x=0$ 的偶反射（不重复端点）得到 $(-\pi,\pi]$ 上 **512** 个均匀点。训练用 $M=101$ 个归一化时刻（每两个存储时刻取一个）。

### 关键技术

| 技术 | 说明 |
|------|------|
| 参考数据生成 | Wilkening (2011) 的谱精度解；Wilkening & Yu (2012) 的过定射击法；Levenberg–Marquardt 迭代，每个未知量一次线性化积分组装 Jacobian；参数延拓（continuation）沿解族推进 |
| 自由面变量形式 | $(\eta,\varphi)$ 动力学 + $\mu$ 作为辅助变量；$G(\eta)\varphi$ 通过第二类 Fredholm 积分方程 $\tfrac12\mu+K(\eta)\mu=\varphi$ 计算（$K$ 由流体域 Laplacian 的周期 Green 函数构成） |
| 网络架构 | 4 通道输入 $a(x)=(\eta_0(x),\tau,\cos x,\sin x)$ → 点态线性升维 $P$ → **$L=8$ 层 Fourier 层**（宽度 $d_v=64$，截断波数 $k_{\max}=64$，GELU 非线性）→ 点态线性投影 $Q$ 输出 3 通道 $(\eta,\varphi,\mu)$ |
| 谱卷积层 | $\widehat{\mathcal K v}_k = R_k\hat v_k$（$|k|\le k_{\max}$），否则为 0；实值场要求共轭对称 $R_{-k}=\overline{R_k}$；512 点网格上 257 个非负波数中保留 64 个 |
| 训练 | 标准化（训练集均值/方差固定适用于 ID/OOD）+ Adam，1000 epochs，初始 lr $10^{-3}$，余弦退火；固定随机种子（同时决定数据顺序） |
| 误差度量 | 相对 $L^2$ 误差 $E(u)$（跨解集先求和再取比值，大振幅解主导平均）+ 绝对 RMS 误差 $A(u)$（区分「精度下降」与「参考幅值变化」） |
| 残差诊断 | 免参考解的残差 $R$，由 $\eta,\varphi$ 的谱/差分导数直接构造；参考解在同一网格上给出的**离散化基线**为 $10^{-5}$ 量级 |

## 公式

### 1. 控制方程（自由面变量形式）

```math
\eta_t = G(\eta)\varphi,\qquad
\varphi_t = -g\eta-\frac{1}{2}\varphi_x^2+\frac{(G(\eta)\varphi+\eta_x\varphi_x)^2}{2(1+\eta_x^2)}
```

```math
\tfrac{1}{2}\mu+K(\eta)\mu=\varphi
```

### 2. 波峰加速度参数

```math
A_c=-\eta_{tt}(0,0)=g-\rho^{-1}p_y(0,\eta(0,0),0),\qquad
\varepsilon=1-\frac{A_c}{g}=\frac{p_y(0,\eta(0,0),0)}{\rho g}
```

$\varepsilon$ 在数据集上从 idx=101 的约 **0.99** 单调降至 idx=240 的 **0.012**。

### 3. 线性极限的领头阶解

```math
\eta(x,t)\approx h\cos x\cos t,\qquad \varphi(x,t)\approx-h\cos x\sin t,\qquad
A_c\approx h\approx 1-\varepsilon,\quad T\to 2\pi
```

### 4. 谱卷积层与网络层

```math
\widehat{\mathcal Kv}_k=\begin{cases}R_k\hat v_k,&|k|\le k_{\max}\\ 0,&|k|>k_{\max}\end{cases},
\qquad R_{-k}=\overline{R_k}
```

```math
v_{\ell+1}(x)=\sigma\!\left(W_\ell v_\ell(x)+(\mathcal K_\ell v_\ell)(x)\right),\quad \ell=0,\dots,L-1
```

### 5. 相对 $L^2$ 误差与绝对 RMS 误差

```math
E(u)=\left(\frac{\sum_{j=1}^{M}\sum_{i=1}^{N}|\hat u_{ij}-u_{ij}|^2}{\sum_{j=1}^{M}\sum_{i=1}^{N}|u_{ij}|^2}\right)^{1/2},
\qquad
A(u)=\left(\frac{1}{MN}\sum_{j=1}^{M}\sum_{i=1}^{N}|\hat u_{ij}-u_{ij}|^2\right)^{1/2}
```

### 6. 控制方程残差（免参考解）

```math
R=\varphi_t+g\eta+\frac{1}{2}\varphi_x^2-\frac{(\eta_t+\eta_x\varphi_x)^2}{2(1+\eta_x^2)}
```

相对残差（除以 $\varphi_t$ 与 $g\eta$ 两个线性主导项的 RMS）：

```math
r=\left(\frac{\sum_{j=1}^{M}\sum_{i=1}^{N}R_{ij}^2}{\sum_{j=1}^{M}\sum_{i=1}^{N}\left[((\varphi_t)_{ij})^2+g^2\eta_{ij}^2\right]}\right)^{1/2}
```

### 7. 导数离散化

```math
(u_x)_{\cdot j}=\mathcal{F}^{-1}\!\left(ik\,\mathcal{F}u_{\cdot j}\right),\quad k=-\tfrac{N}{2}+1,\dots,\tfrac{N}{2}
\quad(\text{Nyquist 模态系数置零})
```

```math
(u_t)_{ij}=\frac{u_{i,j-2}-8u_{i,j-1}+8u_{i,j+1}-u_{i,j+2}}{12\Delta t^\varepsilon},\quad
\Delta t^\varepsilon=\frac{T^\varepsilon}{4(M-1)}
```

时间端点用二阶前/后向公式。

## 实验结论

### 数据划分

| 参数集 | 规模 | Experiment I（自由落极限） | Experiment II（线性极限） |
|---|---|---|---|
| $\mathcal{E}_{\rm tr}$ | **125** | $\subset[0.030,\,0.992]$ | $\subset[0.012,\,0.904]$ |
| $\mathcal{E}_{\rm ID}$ | **5** | $\subset[0.061,\,0.87]$ | $\subset[0.039,\,0.76]$ |
| $\mathcal{E}_{\rm OOD}$ | **10** | $\subset[0.012,\,0.028]$ | $\subset[0.913,\,0.992]$ |

关键：ID 值在参数轴上**互不相邻且不与 OOD 块相邻**（故 ID 误差衡量「在邻近训练解之间的插值精度」）；OOD 块严格位于训练区间之外。**用 $\varepsilon$ 而非 $h$ 划分是必需的**——OOD 解的 $h$ 值与 $h$ 极大值另一侧的训练解重叠，只有 $\varepsilon$ 严格落在训练范围外。

### 误差结果

| Field | Exp I ID | Exp I OOD | Exp II ID | Exp II OOD |
|---|---|---|---|---|
| $\eta$ | $6.81\times10^{-4}$ | $3.58\times10^{-3}$ | $7.3\times10^{-4}$ | $1.23\times10^{-2}$ |
| $\varphi$ | $5.79\times10^{-4}$ | $1.95\times10^{-3}$ | $5.9\times10^{-4}$ | $3.94\times10^{-2}$ |
| $\mu$ | $6.36\times10^{-4}$ | $2.02\times10^{-3}$ | $6.1\times10^{-4}$ | $4.10\times10^{-2}$ |
| **All fields** | $6.35\times10^{-4}$ | $2.35\times10^{-3}$ | $6.3\times10^{-4}$ | $3.75\times10^{-2}$ |

- **Exp I（自由落极限）**：OOD 误差对 $\eta$ 放大约 **5 倍**，对 $\varphi,\mu$ 约 **3 倍**。逐解误差 $E^\varepsilon(\eta)$ 从 $\varepsilon=0.028$ 的 $2.41\times10^{-3}$ 单调升至 $\varepsilon=0.012$ 的 $4.82\times10^{-3}$。误差**同时在空间上（$x=0$ 附近尖峰）和时间上（$t=0$，最陡时刻）局域**。几何证据：OOD 集上波峰高度仅从 0.8217 升到 0.8245，而最大斜率从 0.95 升到 1.13 → **主导几何变化是尖峰锐化**。机理：最陡剖面的 Fourier 谱在 $k_{\max}=64$ 以上仍有可观内容，而谱卷积无法直接表示。
- **Exp II（线性极限）**：平均 OOD 误差显著更大（$\eta$ 约 3 倍，$\varphi,\mu$ 及合并场**超过一个数量级**）。逐解 $E^\varepsilon(\eta)$ 从 $\varepsilon=0.913$ 的 $4.5\times10^{-3}$ 升至 $\varepsilon=0.992$ 的 $1.16\times10^{-1}$。**但绝对 RMS 误差反而下降**（$4.6\times10^{-4}\to1.8\times10^{-4}$，且不高于 ID 水平）。原因：波幅按 $\propto(1-\varepsilon)$ 衰减，比绝对误差衰减更快；标准化常数由大振幅训练解决定，损失函数不给「绝对量小但相对显著」的偏差额外权重。
- **ID 误差对 $\varepsilon$ 无系统趋势** → 插值精度由算子逼近能力主导，而非解族上的位置。

### 残差结果

| | ID | OOD |
|---|---|---|
| Experiment I | $6.10\times10^{-3}$ | $6.43\times10^{-3}$ |
| Experiment II | $7.45\times10^{-3}$ | $7.90\times10^{-2}$ |

- 参考解在同一时间分辨率下的残差基线：**$0.9\times10^{-5}$–$1.7\times10^{-5}$，均值 $1.35\times10^{-5}$**（反映时间差分截断误差，而非参考解失真）。因此 $r\sim10^{-5}$ 的预测在此诊断下与参考解**不可区分**。
- 即使 ID 预测，残差也比基线高 **2–3 个数量级**（残差含导数，对小尺度预测误差比 $L^2$ 更敏感）。
- **Exp I 的 OOD 残差仅为 ID 的 1.05 倍**（对比 $\eta$ 的 $L^2$ 误差放大 5.3 倍）→ 自由落极限的预测「在波峰附近失去精度，但仍与控制方程相容」。
- **Exp II 的 OOD 残差是 ID 的 10.6 倍**，逐解从 $\varepsilon=0.913$ 的 $2.86\times10^{-2}$ 升到 $\varepsilon=0.992$ 的 $5.26\times10^{-1}$——后者约等于主导线性项 RMS 的**一半**，标志**被检验的动力学平衡被严重破坏**。

### 探索性预测（无参考解）

对数据集最陡的 10 个解（$\varepsilon\in[0.012,0.028]$）在 $\varepsilon$ 上做逐点二次外推，构造 $\varepsilon\in\{0.010,0.008,0.006\}$ 的候选静止剖面（波峰高度 0.8251→0.8263，最大斜率 1.167→1.296）。两个独立训练的算子（不同训练段）给出残差：

| $\varepsilon$ | Exp I $r$ | Exp II $r$ |
|---|---|---|
| 0.010 | $6.81\times10^{-3}$ | $7.84\times10^{-3}$ |
| 0.008 | $6.90\times10^{-3}$ | $7.89\times10^{-3}$ |
| 0.006 | $7.00\times10^{-3}$ | $7.95\times10^{-3}$ |

在周期外推（$\varepsilon\in[0.012,0.028]$ 二次外推）得到的 $T$ 下评估，对周期做百分比级扰动时残差变化 **<1%**。两个算子的**一致性**被用作模型不确定性的廉价代理。

## 局限性

1. **探索性预测不构成新的驻波解**：候选静止剖面由**光滑二次外推**构造，无法捕捉 Wilkening (2011) 报告的自由落极限下**越来越细的振荡结构**；谱截断在尖峰锐化时也更严格限制表达。作者明确声明：这只是对「光滑连续假设」的评估。
2. **截断波数的影响未量化**：$k_{\max}=64$ 与自由落极限的谱衰减之间的相互作用只是**一致性论证**（OOD 谱在 $k_{\max}$ 以上仍有内容），并未做 $k_{\max}$ 扫描实验。
3. **残差的作用域有限**：残差只检验 (3)–(4) 的一个必要后果，**不涉及 $\mu$**（$\mu$ 只通过 $L^2$ 误差评估），也不检验运动学条件 (3)。
4. **$\varepsilon$ 并非全局参数化**：作者明确声明不主张 $\varepsilon$ 参数化整个解集；且参考数据止于 $\varepsilon=0.0123$，**不是数学上已确立的端点**。
5. **训练范围有限**：只学习一个一参数族的对称驻波，且只在四分之一空间-时间胞内；作者提出未来需扩展到有限深、三维、以及含表面张力的毛细-重力波。
6. **相对误差在零振幅极限是奇异的**：$\varepsilon\to1$ 时 $h\to0$，相对误差必然发散，绝对误差才是有意义的指标——这限制了用相对误差评估线性极限的适用性。

## 实现建议

- **实现难度**：中（训练本身标准；真正的门槛在**参考数据生成**——过定射击法 + 扩展精度算术，自由落端每个解需要数小时）。
- **预期性能**：训练区间内三个场的相对 $L^2$ 误差 $\sim6\times10^{-4}$；一次前向评估给出任意 $\tau$ 的完整三场状态，**无时间步进**，评估成本与 $\tau$ 无关（相比参考解的分钟到小时级加速）。残差 $r\sim10^{-3}$（基线 $10^{-5}$）。
- **适用场景**：
  1. **自由面波/驻波的参数化代理**：需要在大参数空间上反复评估波形演化、且只需中等精度时。
  2. **为传统求解器提供初猜**：本文明确建议把 FNO 预测作为过定射击法的初始猜测，再由传统求解器精修与验证——这是**最稳妥的落地方式**。
  3. **作为探索工具**：用残差筛选「可能是新驻波」的候选演化，把昂贵的数值求解留给最终确认。
- **落地建议**：
  1. **必须用 $\varepsilon$（或类似的单调物理参数）划分 train/OOD，不能用波高**——波高在解族上非单调，用它划分会得到「OOD 其实落在训练范围内」的假象。这是本文最可复用的方法论。
  2. **误差报告必须同时给相对与绝对两个指标**：零振幅极限下相对误差是奇异量，单看相对误差会误判模型退化。
  3. **残差基线必须先标定**：在参考解上用同样的离散格式算一次残差，得到离散化本底（本文 $1.35\times10^{-5}$），否则预测的 $10^{-3}$ 残差无法解读。
  4. **两个独立划分训练的算子做交叉验证**是评估「无参考解」预测不确定性的低成本实用手段。
  5. **OOD 误差的空间-时间局域性诊断**（本例：$x=0$、$t=0$ 附近）比单一标量误差更能定位失效机理（谱截断 vs 归一化失配）。
  6. **与本库关联**：本篇与 [[DSMC-Hypersonic-Boundary-Layer-DMD]]（2610.36248）都体现了「物理残差/模态诊断作为独立于参考解的证据链」的思路；也与 [[Physics-Constrained-Symbolic-Regression-Turbulent-BL]]（2610.35276）形成互补——前者是**数据驱动算子学习**，后者是**物理先验约束的符号回归**。

## 推荐结论

> **✅推荐实现**（作为特定场景下的代理与探索工具），但**不可**用于外推到自由落极限附近或线性极限的定量结论。
>
> - 支持：训练区间内相对 $L^2$ 误差 $<10^{-3}$，一次前向评估替代昂贵边值求解；残差诊断为无参考解场景提供了可信的独立判据。
> - 关键保留：自由落极限的误差源自谱截断（可通过增大 $k_{\max}$、采用波峰自适应坐标或多分辨率架构缓解）；线性极限的相对误差放大源于标准化而非模型精度本身（可通过振幅自适应归一化或按解的相对误差加权损失缓解）。最佳实践是把 FNO 当作「初猜生成器 + 候选筛选器」，最终结果交由谱精度数值求解器验证。
