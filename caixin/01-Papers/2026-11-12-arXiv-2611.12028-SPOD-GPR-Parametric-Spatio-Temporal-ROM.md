## 核心贡献

> 提出 **SPOD-GPR**：一种**非侵入式、参数化、时空**降阶模型 (ROM)，把 **POD + 谱 POD (SPOD) + 高斯过程回归 (GPR)** 结合起来。参数依赖通过 **Grassmann 流形上的局部图** + **Procrustes 对齐**建模；SPOD 模态系数既学为**参数的显式函数**，也学为**参数条件自回归模型**（支持超出训练窗口的**时间外推**）；高斯过程用 **Matheron 条件化做联合路径式采样**，保证每个预测实现都带有与后验一致的不确定度。**在全部四个算例中，SPOD-GPR 的归一化 MAE 均低于 POD-GPR 基线**，且**不确定性标定显著改善——尤其在流动算例中，POD-GPR 严重过度自信 (overconfident)**。

1. **参数化 POD**：先把高维状态投影到低维子空间（参数化 POD）。
2. **窗口化 + 频域截断**：降阶轨迹被**切分为窗口化片段**，**变换到频域**，**截断到最有能量的频率**。
3. **逐频率独立 SPOD**：在每个保留频率上**独立**执行 SPOD，得到**时间相干 (temporally coherent)** 的模态与系数。
4. **Grassmann 流形上的 GPR**：
   - POD 与 SPOD 基的**参数依赖**用 GPR 建模；
   - 关键：子空间是 **Grassmann 流形**上的对象（不是欧氏向量），必须先做 **Procrustes 对齐**；
   - GPR 建立在**局部图 (local chart)** 上。
5. **双重模态系数学习**：
   - **显式函数**：SPOD 系数作为参数的显式函数学习；
   - **参数条件自回归模型**：允许**超出训练窗口的时间外推**。
6. **Matheron 条件化的联合路径式采样**：高斯过程**联合且按路径 (pathwise)** 采样，确保**每个预测实现都携带与后验分布一致的不确定度**——这是对"预测均值不错但不确定度错"的直接修补。
7. **验证设计**：四个参数化算例，**参数值与预测时域都在训练数据之外**（严格外推）：
   - 2D 各向异性 **Kuramoto–Sivashinsky (KS)** 方程（时间周期型 + 行波型），分别以两个系数参数化；
   - **圆柱绕流**，以 **Re** 参数化；
   - **椭圆绕流**，以其**半轴**参数化。
8. **结论**：所有算例中 **SPOD-GPR 的归一化 MAE 优于 POD-GPR**，且**改善了预测不确定度的标定，在流动算例中尤为明显（POD-GPR 严重过度自信）**。作者指出这**开启了面向多查询与实时应用的、谱化的、不确定性感知 ROM** 之路（如**数字孪生**）。

## 技术方案

### 核心思想

**ROM 的两个痛点**：

1. **参数化降维**：传统 POD 只对一个参数值（一个快照集）降维。参数变化时，基会变。POD-GPR 把基作为参数的函数来学习。
2. **不确定性**：确定性 ROM 给出的预测没有不确定度信息，无法判断"这个预测可信吗"。而**代理模型在训练分布外必然退化**（OOD），若不报不确定度，使用者无从察觉。

**本文的两个结构改进**：

**改进一：时空降阶（SPOD）**

普通 POD 只做**空间**降维，得到的是时间序列的快照基。SPOD（谱 POD，Schmidt 2015）做的是**时空**分解：

$$\mathbf{Z}(\boldsymbol{x},t)\approx\sum_{j=1}^{r}\hat{\boldsymbol{Z}}_j(\boldsymbol{x})\,a_j(t)$$

其中 $(\hat{\boldsymbol{Z}}_j, a_j)$ 由求解**时空相关矩阵的最大特征对**得到。这带来**时间相干性 (temporal coherence)**：每个模态对应一个明确的频率，因此模态在物理上有清晰含义（比如"周期脱落模态"）。

实现上：轨迹 → 切窗口 → 频域变换 → 逐频率独立 SPOD。

**改进二：Grassmann 流形上的 GPR**

这是本文的技术核心，值得展开：

POD 基 $\{\boldsymbol{u}_i\}_{i=1}^r$ 的真正对象不是"一组向量"，而是它们张成的**子空间**。在参数空间中：
- 子空间随参数连续变化，但**子空间的表示有任意性**——同一个子空间可以有无穷多组基（旋转、正交变换等）；
- 因此**不能**对基向量直接做 GPR 回归（目标不唯一，回归结果没有几何意义）。

正确的做法：
1. 把子空间视为 **Grassmann 流形** $\mathrm{Gr}(r, n)$ 上的点；
2. 用 **Procrustes 分析**把不同参数下的基**对齐到共同参考**（消除任意旋转自由度）；
3. 在 **Grassmann 流形的一个局部图 (local chart)** 上做 GPR —— 因为流形是**弯曲**的，不能直接用欧氏核函数；
4. 预测时再映射回流形。

这个"对齐 → 局部图 → 流形回归"三步是**子空间族降阶 (interpolated/parametric reduced-order models)** 的标准范式，本文把它用在了 SPOD 基上。

**改进三：Matheron 条件化**

GP 预测的标准做法是给均值和协方差。但下游若要做**轨迹级**的采样（例如蒙特卡洛传播），需要**联合采样**而非独立逐点采样。

- **朴素做法（独立采样）**：逐时间点独立从边缘分布采样 → 破坏时间相关性 → 轨迹在物理上不合理
- **Matheron 条件化**：在**条件先验**（条件于观测点的 GP 样本）下采样 → 保持联合结构，且**每个实现都携带正确的不确定度**

**改进四：双路径系数学习**

- **显式参数函数**：$a_j(t) = \sum_k \alpha_{jk}(\boldsymbol{\mu})$ —— 参数 $\boldsymbol{\mu}$ 的显式函数
- **参数条件 AR 模型**：$a_j(t+\Delta t) = f(a_j(t), \boldsymbol{\mu})$ —— 支持**超出训练窗口**的时间外推

这两条路径互补：显式函数在**插值**上准确，AR 模型在**外推**上可用。

### 关键技术

| 技术 | 说明 |
|------|------|
| 参数化 POD | 基作为参数的函数 |
| 窗口化 + 频域截断 | 把轨迹切成窗口、变到频域、保留主频 |
| SPOD (谱 POD) | 逐频率的时空分解，产生时间相干模态 |
| Grassmann 流形 | 把降维基视为子空间（流形点）而非向量 |
| Procrustes 对齐 | 消除基的旋转任意性（子空间回归的前提） |
| 流形局部图 | 在弯曲流形上定义核函数与回归 |
| GPR | 高斯过程回归 |
| Matheron 条件化 | 联合路径式采样，保持时间相关性 + 正确不确定度 |
| 参数条件自回归模型 | 支持训练窗口外的时间外推 |
| 归一化 MAE + 不确定度标定 | 双指标评估 |

## 公式 / 理论要点

```math
% POD 降维（参数化）
\boldsymbol{u}(\boldsymbol{x},t;\boldsymbol{\mu})
\approx \sum_{i=1}^{r} a_i(t;\boldsymbol{\mu})\,\boldsymbol{\phi}_i(\boldsymbol{x};\boldsymbol{\mu}),
\qquad
\boldsymbol{\phi}_i(\boldsymbol{x};\boldsymbol{\mu}) \in \mathbb{R}^n
```

```math
% SPOD：时空相关系数矩阵的最大特征对
\hat{\boldsymbol{Z}}_j(\boldsymbol{x}),\ a_j(t)
\quad\Longleftrightarrow\quad
\text{eigenpair of}\ 
\boldsymbol{S}(\omega_j) = \int \boldsymbol{Z}(\boldsymbol{x},t)\,\overline{\boldsymbol{Z}(\boldsymbol{x},t-\tau)}\,d\tau
```

```math
% Grassmann 流形与子空间表示
\mathrm{Gr}(r,n) = \{ \text{\(r\)-维子空间} \subset \mathbb{R}^n \},
\qquad
d_{\mathrm{Gr}}(\Pi_1,\Pi_2) = \|\boldsymbol{\Pi}_1-\boldsymbol{\Pi}_2\|_F
```

```math
% Procrustes 对齐（消除旋转任意性）
\boldsymbol{\Phi}^{(k)} \leftarrow \boldsymbol{\Phi}^{(k)}\boldsymbol{R}^{(k)},
\qquad
\boldsymbol{R}^{(k)} = \arg\min_{\boldsymbol{R}\in O(r)} 
\|\boldsymbol{\Phi}^{(k)}\boldsymbol{R} - \boldsymbol{\Phi}^{(0)}\|_F
```

```math
% Grassmann 上的核函数（需满足流形几何）
k_{\mathrm{Gr}}(\Pi_a,\Pi_b)
= \exp\!\left(-\frac{\|\log(\Pi_a^\top \Pi_b)\|_F^2}{2\ell^2}\right)
\quad(\text{或 Procrustes 距离诱导核})
```

```math
% Matheron 条件化：联合路径式采样
\boldsymbol{Z}^{\text{cond}}
= \boldsymbol{f} + \boldsymbol{A}\boldsymbol{u}_{\text{cond}},
\qquad
\boldsymbol{u}_{\text{cond}}\sim\mathcal{N}(0,\boldsymbol{\Sigma})
\quad\Rightarrow\quad
\text{每个实现携带与后验一致的不确定度}
```

```math
% 参数条件自回归模型（时间外推）
a_j(t+\Delta t) = f_j\big(a_j(t),\,\boldsymbol{\mu}\big)
```

## 实验与结果

- **算例（四个，参数值与预测时域均在训练数据之外）**:
  1. 2D 各向异性 **KS 方程 — 时间周期型**（以其中一个系数参数化）；
  2. 2D 各向异性 **KS 方程 — 行波型**（以另一个系数参数化）；
  3. **圆柱绕流**（以 **Re** 参数化）；
  4. **椭圆绕流**（以**半轴**参数化）。
- **基线**: **POD-GPR**（只做 POD，不做 SPOD）。
- **主要结果**:
  - **全部四个算例**：SPOD-GPR 的**归一化 MAE 均低于** POD-GPR；
  - **不确定性标定显著改善**，**尤其在流动算例（圆柱/椭圆）中，POD-GPR 严重过度自信**，而 SPOD-GPR 修正了这一偏差；
  - 结论：这开启了**面向多查询与实时应用的、谱化的、不确定性感知 ROM**（如数字孪生）的道路。
- **指标**: 归一化 MAE（精度）+ 不确定度标定（可靠性）。

## 局限性

- **算例均为低维/二维**：2D KS、2D 圆柱绕流、2D 椭圆绕流。**三维工业流动**（湍流、复杂几何）上的表现未验证——这恰恰是数字孪生最关心的场景。
- **时间外推能力有限**：AR 模型的外推质量未给出定量指标（摘要只说"允许外推"）。
- **Grassmann 局部图的适用性**：参数范围大时流形覆盖广，**单个局部图可能不够**，需要多个图的拼接/切换（流形上的 chart atlas），摘要未提及。
- **SPOD 频率截断的阈值选择**：需要人为给定能量截断比例，属于超参数。
- **不确定性标定缺乏定量指标**：摘要称"改善标定"，但未给出覆盖概率（coverage）或校准曲线等定量结果，需查正文。
- **线性性依赖**：SPOD-GPR 建立在**线性** POD/SPOD 展开之上，强烈非线性的流动可能需要非线性基（结合本轮 [[2026-11-12-arXiv-2611.12862]] 提到的 HNO 类算子思路）。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — 需要实现 SPOD（含窗口化与频域处理）、Grassmann 流形上的 GP 回归（含 Procrustes 对齐与局部图构造）、Matheron 条件化采样。几何/线性代数部分是主要工作量。
- **预期性能**: 高（ROM 本身即为主动降阶）；GP 回归的预测成本随训练集大小增长，超大参数空间需稀疏 GP 或近似。
- **适用场景**:
  - **参数化流动的快速评估**：如设计优化中的 Re/几何参数扫描（本文的圆柱绕流、椭圆绕流）；
  - **实时/多查询代理**：数字孪生、控制系统设计；
  - **与本轮 [[2026-11-12-arXiv-2611.11540-Hydrograd-v2-Differentiable-Shallow-Water-Adjoints]] 互补**：Hydrograd 提供**梯度**（可微正演，用于反演），SPOD-GPR 提供**快速代理 + 不确定度**（用于多查询）。二者组合是"可微正演 + 快速代理"的标准架构；
  - **流固/流热耦合的周期性响应**：SPOD 的时间相干性特别适合处理周期脱落、振荡类问题。
- **可复用要点**:
  - **子空间族回归的三步法（Procrustes 对齐 → 局部图 → 流形回归）** 是做参数化降阶的**必备步骤**，跳过 Procrustes 会得到无几何意义的回归结果。这是最值得记住的技术点。
  - **"过度自信"是一个需要主动检测的失效模式**：确定性 ROM 在 OOD 区必然过度自信。本文把它作为一个独立的评估维度（而不是只看 MAE）——**建议把这个"可靠度指标"加入本知识库的代理模型评测清单**。
  - **Matheron 条件化 vs 独立边缘采样**：只要下游需要轨迹级采样，就必须用前者。这在很多 GP 应用中被忽略。
  - **显式函数 + AR 双路径**：插值靠显式、外推靠 AR，这个分工模式适用于所有"参数 + 时间"双外推问题。
  - **与 [[2026-11-11-arXiv-2611.13989-Hankel-Neural-Operator-HNO]] 对照**：HNO 是**算子学习**（学习解算子本身），SPOD-GPR 是**谱降阶 + 参数回归**（学习基与系数）。二者可组合：HNO 提供物理正确的算子核，SPOD-GPR 提供参数化的谱分解。
