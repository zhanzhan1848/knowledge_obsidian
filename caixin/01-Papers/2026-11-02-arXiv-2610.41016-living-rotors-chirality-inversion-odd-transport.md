## 核心贡献

> 发现**活的**手性流体与**外驱动**的手性流体有本质区别：单细胞藻类**全部顺时针自旋**，但它们的簇却**逆时针**公转——微观与宏观涡量**反号**。理论与模拟表明，**手性反转与渗流都是细胞"内部驱动"这一性质的直接后果**；渗流又重塑输运：**奇/偶扩散率**对涌现网络拓扑的响应截然不同。

1. **手性反转 (chirality inversion)**：细胞个体顺时针自旋（~4 Hz），但细胞对、簇**逆时针**公转（~0.01 Hz）——微观/宏观涡量**反号**。
2. **机制**：低 Re 且无外部驱动时，细胞**不能**对周围流体施加净力或净力矩；要向一侧自旋，就必须向另一侧推流体。这个**反向旋转的螺旋流**把邻居向相反方向输运，同时把它们拉近。
3. **与外驱动系统的对比**：
   - 旋转胶体磁体（外驱动）→ 纯方位角流（单 rotlet）→ **无手性反转、无吸引**；
   - 螺旋鞭毛拍打（本工作）→ 涡旋与**反向涡同时出现**于观测平面 → 手性反转；
   - 纺锤体细菌 → 体/鞭力矩沿转轴分离 → 每个细胞体周围**单个表观涡**；
   - Volvox 群落 / 海星胚胎（数千纤毛）→ 方位角流与体旋转补偿 → 实验系中流**纯径向**，吸引**非内禀**而来自界面邻近的 3D 环流。
4. **自组装为流体状簇**：即使稀悬浊液也含旋转簇；对 (N=2) 有 $\Omega \sim r_{\rm eq}^{-7}$；三四元组稳健；$N\ge5$ 出现频繁邻居交换 → **流体态**。
5. **模拟揭示流体化条件**：**噪声或尺寸多分散性是必需的**——单分散 + 无噪声会锁成**持久稳定构型**（MPD 恒定）。
6. **渗流 (percolation)**：密集悬浊液渗流，属 **2D 渗流普适类**（$R_g \sim N^{48/91}$，簇周长 $P\sim R_g^{3/4}$），临界体积分数 **$\phi_c \simeq 0.08$**；$g(r)$ 除最近邻外**无位置序**。
7. **"空液体"结构**：即使在致密渗流态仍可见无颗粒区域。
8. **始终保持高动态性**：$C_B(\tau)$ 在所有 $\phi$ 都衰减到零（局部环境持续更新）；拟合**拉伸指数**；$\tau_{\rm bond}$ 从 >100 s 降到 ~10 s，$\beta$ 饱和于 ~0.8。
9. **奇输运**：粒子**不自驱动**，孤立时静止 → 输运**完全由水动力相互作用驱动**；MSD 从**超扩散** $t^{1.5}$（短时）到**扩散**（长时）——经典**搅拌渗流**（stirred percolation）结果；**$D_\parallel$（偶）随 $\phi$ 线性增加**；**$D_\perp$（奇）非单调，在渗流阈值附近达最大**，且**符号与细胞自旋方向相反**。

## 技术方案

### 核心思想

活体旋转子（rotor）**没有外部驱动**：其角动量变化完全来自内部（鞭毛）驱动，因此力与力矩平衡**强制**其远场流动具有**反向涡**结构，从而在微观（自旋）与宏观（公转）层面产生手性反转。这一"内部驱动"性质进一步使簇结构**易被横向力打散**，从而在致密体系中导向 2D 渗流。

| **腔室** | Ibidi µ-Slide VI 0.1 / 0.4 微流控腔，腔高 **100 µm 或 400 µm**（远大于细胞半径 $a\approx5$ µm） |

### 水动力模型（单细胞）

遵循 Fily–Baskaran–Marchetti 的**极简主动二维转子**：一个有效拍打推力 **F** 距体心 **l**、角 **α**，由阻力 $-F$ 与主动力矩 $\tau$ 平衡；含**镜像法**壁面修正（Blake/Chwang 镜像系：反向力 + Stokes 偶极子 + 源偶极子；反向强度镜像 rotlet）。

### 关键技术

| 技术 | 说明 |
|------|------|
| **旋转平均远场速度** | $u_r \propto r^{-4}$（径向，向内），$u_\theta \propto r^{-6}$（方位角）；$u_\theta$ 在 $r \simeq 3a$ **变号** |
| **壁面/2D 限制** | 衰减比三维体内（$u_\rho\sim\rho^{-2}, u_\theta\sim\rho^{-4}$）陡一个幂次 |
| **完整模型 (SI Eq. 9)** | rotlet(R=0) + Blakelet(R=0) + Blakelet(R=l)，含完全椭圆积分 $K(m), E(m)$ |
| **轨道（相位）平均** | $(\cdot) = \frac{1}{2\pi}\int_0^{2\pi}(\cdot)\,\mathrm{d}\psi$ |
| **WCA 短程排斥** | $\bar{u}^{\rm rep}_{ij} = 24\varepsilon\left[2(d_{ij}/r_{ij})^{12} - (d_{ij}/r_{ij})^6\right]\hat{r}_{ij}/r_{ij}^2$（$r_{ij}<2^{1/6}d_{ij}$）；$d_{ij}=\lambda(L_i+L_j)$ |
| **噪声** | $\zeta_{ij}$（近场，$r_{ij}<2^{1/6}d_{ij}$）+ $\xi_i$（背景，独立） |
| **积分器** | Euler–Maruyama |
| **簇分析** | DBSCAN（邻域半径 **28 µm** = $g(r)$ 第一极小，minPoints=2）；边缘排除 $d_{\rm edge}=28$ µm |
| **扩散率** | Green–Kubo：$D_{ij}=\int_0^\infty\langle v_i(t)v_j(0)\rangle\,\mathrm{d}t$；2D 张量 $D_{ij}=D_\parallel\delta_{ij}+D_\perp\epsilon_{ij}$ |
| **对数螺旋法** | 绘制 $C_{yx}$ vs $C_{xx}$ 得**以 $(D_\parallel,D_\perp)$ 为心的对数螺旋** → **免拟合**直接测量两个系数 |
| **结构度量** | MSPD、$C_B(\tau)$、$R_g$、簇尺寸分布、簇周长 |

## 公式

### 旋转平均远场速度（主文 Eq. 1）

$$\mathbf{u}(r,\theta) = \frac{F}{8\pi\mu l}\left[\frac{12h^2l^2}{r^4}\cos\alpha\;\hat{\mathbf{r}} + \frac{45h^2l^4}{4r^6}\sin\alpha\;\hat{\boldsymbol{\theta}}\right]$$

$$\Rightarrow\quad u_r \propto r^{-4},\qquad u_\theta \propto r^{-6},\qquad u_\theta \text{ 在 } r\simeq 3a \text{ 变号}$$

### 粒子更新（Euler–Maruyama，Eq. 14）

$$\mathbf{x}_i^{n+1} = \mathbf{x}_i^n + \Delta t\sum_{j\neq i}\left[\bar{\mathbf{u}}_j(\mathbf{r}_{ij}) + \bar{\mathbf{u}}_{ij}^{\rm rep}\right] + \sqrt{\Delta t}\left[\bar{A}_{\rm near}\sum_{j\neq i}\boldsymbol{\zeta}_{ij} + \bar{A}_{\rm far}\boldsymbol{\xi}_i\right]$$

### 结构度量

$$\text{MSPD}(\tau) = \frac{1}{2a^2}\left\langle\left[\mathbf{r}_{ij}(t+\tau)-\mathbf{r}_{ij}(t)\right]^2\right\rangle$$

拟合：$N\le4$ 用 $k\tau$（刚性转动）；$N\ge5$ 用 $A(e^{k\tau}-1)$（内部重排）。

$$C_B(\tau)\sim e^{-(t/\tau_B)^\beta},\qquad \tau_{\rm bond} = \tau_B\,\Gamma(1/\beta)/\beta$$

$$R_g \sim N^{48/91}\quad\text{（2D 渗流普适类）}$$

$$P(N)\sim N^{-\alpha}e^{-N/N^*}\ \text{（低 $\phi$，截断幂律）}\qquad\longrightarrow\qquad P(N)\sim N^{-\alpha}\ \text{（近 $\phi_c$，无标度幂律）}$$

### 扩散率与奇偶分解

$$D_{ij} = D_\parallel\,\delta_{ij} + D_\perp\,\epsilon_{ij}$$

$$D_\parallel = \text{偶扩散率（普通）},\qquad D_\perp = \text{奇扩散率（驱动垂直于密度梯度的通量）}$$

$$\text{位置-速度关联：}\quad C_{xx}=\langle\Delta r_x(t)\,v_x(0)\rangle \to D_\parallel;\qquad C_{yx}=\langle\Delta r_y(t)\,v_x(0)\rangle \to D_\perp$$

### 成对公转频率

$$\Omega = \frac{2u_\theta(r_{\rm eq})}{r_{\rm eq}} \sim r_{\rm eq}^{-7}$$

### WCA 排斥与噪声

$$\bar{\mathbf{u}}_{ij}^{\rm rep} = 24\varepsilon\left[2\left(\frac{\bar d_{ij}}{\bar r_{ij}}\right)^{12} - \left(\frac{\bar d_{ij}}{\bar r_{ij}}\right)^6\right]\frac{\bar{\mathbf r}_{ij}}{\bar r_{ij}^2},\qquad \bar d_{ij}=\lambda(\bar L_i+\bar L_j)$$

$$\boldsymbol{\zeta}_{ij}=\boldsymbol{\xi}_{ij}\ \ (r_{ij}<2^{1/6}d_{ij}),\quad 0\ \text{否则};\qquad \boldsymbol{\xi}_{ij},\boldsymbol{\xi}_i \sim \mathcal{N}(0,1)\ \text{(2D)}$$

## 实验结论

1. **手性反转是内禀且普适的**：个体顺时针自旋 → 对/簇逆时针公转。$r_{\rm eq}\approx20$ µm **落在外层反向涡内** → 邻居被向相反方向输运。无需像其它机制（齿轮式立体耦合、边界效应、动力学不稳定）那样精细调节密度/约束/活性。
2. **固定手性的来源**：鞭毛拍打的**面外分量**（野生型左手螺旋轨迹的原因）诱导细胞绕主轴的**弱左手滚转** → 细胞贴壁时从流体侧看**鞭毛在左** → 几乎唯一的顺时针自旋。
3. **自组装**：N=2 的 $\Omega\sim r_{\rm eq}^{-7}$（与模型方位角流预测一致）；三四元组稳健；$N\ge5$ 频繁邻居交换 → 流体态（MSPD：$N\le4$ 不增长，$N\ge5$ 发散）。
4. **模拟**：**噪声或多分散性是流体化的必要条件**；单分散+无噪声 → 粒子锁成持久稳定构型（MPD 恒定）；增大 $\bar\sigma$ 或 $\bar A_{\rm near}$ → 持续 MPD 波动；足够高的 $\bar A_{\rm near}$ 可暂时打散已形成簇（随后重组）。**背景噪声 $\bar A_{\rm far}$ 的作用是抵消长程吸引；短程噪声的作用是打破锁定簇**。
5. **渗流**：$g(r)$ 显示最近邻之外**无位置序**；最近邻距离**几乎不随密度变化**（≈20 µm）→ 密度增加提高**连通性**而非减小间距；簇尺寸分布从截断幂律 → 近 $\phi_c$ 变为无标度幂律；平均有限簇尺寸发散；**$R_g\sim N^{48/91}$**；$\phi_c\simeq0.08$。
6. **"空液体"结构**：致密渗流态仍可见无颗粒区。
7. **始终高动态**：$C_B(\tau)$ 在所有 $\phi$ 衰减到零；拉伸指数拟合；$\tau_{\rm bond}$：远离渗流 >100 s（簇小、孤立）→ 近/高于渗流降到 ~10 s（一个数量级），$\beta$ 饱和于 ~0.8。
8. **奇输运**：
   - MSD 短时**超扩散** $\langle\Delta r^2\rangle\sim t^{1.5}$ → 长时**扩散**（所有 $\phi$）——经典**搅拌渗流**（簇间随机跳跃）；
   - **$D_\parallel$ 随 $\phi$ 线性增加**（邻居"绕行"而非互相阻塞 → 类似**碰撞增强自扩散**）；
   - **$D_\perp$ 非单调，在 $\phi_c$ 附近达最大**：$\phi_c$ 以下簇边界周长随密度增加 → 边缘流增强 → 奇扩散增加；**$\phi_c$ 以上可用周长减少**；
   - **$D_\perp$ 符号与细胞自旋方向相反**（与集体层面的反转一致）；
   - MSD 用 $\langle R_g\rangle$ 标度后**在所有 $\phi$ 塌缩** → 交叉即"簇内公转"与"跳到另一簇"的转变；
   - 与经典图像（跨渗簇伴随输运系数突增）相反：这里**奇扩散在阈值之上反而下降**；
   - 簇周长 $P\sim R_g^{3/4}$（分形 2D 渗流）vs 圆形/线形簇的斜率 1。
9. **渗流机制（假说）**：横向力持续打散簇——在有吸引的奇系统中这一机制**缺乏理论描述**。

## 局限性

- **严格二维**：细胞束缚在单一壁面；上下壁群体相距太远不相互作用；镜像系统的面外速度分量被承认但"整体效应可忽略"。
- **点转子近似**：忽略细胞自身半径的圆轨道；远场模型仅对 $r\gtrsim 3a$ 有效（近距离需考虑有限体尺寸——实验上因鞭毛**立体排斥**阻止细胞靠得更近而缓解）。
- **模型参数手工拟合**（$F,l,\alpha,h$）；阻力与力矩是导出而非独立测量。
- **模拟是定性目的**（作者明示）：WCA 排斥 + 噪声是**现象学**项，非从鞭毛碰撞物理导出。
- **密集悬浊液成像偏倚**：在**顶壁**成像（能动的亚群），致密态可能不代表体相。
- **渗流转变无理论模型**（奇/吸引系统中）。
- 提出但未解决的开放问题：$D_\perp$ 在临界体积分数处极大值的**普适性**；致密网络中**奇弹性**的可能涌现；**边缘流 (edge currents)**；自由表面附近的**奇粘性效应**。

## 实现建议

- **实现难度**：★★★★☆（2D Stokes 点粒子模型 + 椭圆积分 + 图像相关；椭圆积分的向量化实现与长时间积分稳定性是主要工程难点）
- **预期性能**：$N \le 99$，Euler–Maruyama，每步 O($N^2$) 交互；50 次实现 × 多组参数完全可行（普通笔记本）
- **适用场景**：
  - 主动物质 (active matter) 的手性与自组织
  - 微尺度旋转子/纤毛/鞭毛系统的水动力建模
  - 奇输运 (odd transport)、渗流网络、边缘流的实验判据设计
  - 微生物悬浮体的流变与输运性质
- **可迁移点**：
  1. **对数螺旋法**测量 $D_\parallel, D_\perp$：免拟合、直接读出偶/奇扩散率——任何需要分离奇偶输运的实验都应采用
  2. **"内部驱动 → 反向涡 → 手性反转"**的逻辑链可推广到任何自驱动转子（磁驱动会破坏它，外驱动不产生反转）——这是一个**区分内外驱动**的诊断
  3. **WCA + 双尺度噪声**（近场打破锁定、远场抵消长程吸引）是模拟主动流体"何时流体化"的实用配方
  4. **$g(r)$ 最近邻距离不随密度变化** 是判断"是连通性驱动还是间距驱动"的标准诊断
  5. 镜像法 + 完全椭圆积分的 Stokes 流动实现，是处理"平行壁中的转子"的标准工具，可复用于任何微尺度平面对流问题
