## 核心贡献

> 发布了九种钝体形状在 Re = 10,000 下湍流尾流的交叉验证数据集，同步提供壁面解析直接数值模拟（谱元求解器）与时间分辨平面 PIV（MIT 智能拖曳水池）结果，包含相平均场、载荷历史与瞬态三维快照；DNS 设置在 Re = 3900 下以参考圆柱数据验证，并逐场对比 DNS 与 PIV，为跨几何的数据驱动湍流封闭、降阶模型与尾流稳定性研究提供基准。

1. 覆盖九种钝体构型（圆柱、2:1 椭圆圆柱 0°/90°、上下游朝向的短长等腰三角形、方柱 0°/45°），统一在 Re = 10,000 下研究不同分离行为。
2. DNS 与实验 PIV 在同一坐标系下双源产出，时间平均与相平均场一一匹配，实现真正的 cross-validated 数据集。
3. DNS 求解器在 Re = 3900 下与经典参考圆柱数据比对验证，并在 Re = 10,000 下与 PIV 逐场比较，形成数值—实验的量化一致性链条。

## 技术方案

### 核心思想
该工作聚焦钝体绕流这一经典但几何效应强烈的分离流动问题。核心设计是"双源同框"：一方面用谱元法（spectral-element）求解器做壁面解析 DNS，直接解析壁面边界层与分离泡结构；另一方面在 MIT Intelligent Towing Tank 用时间分辨平面 PIV 测量同一工况，实现实验验证。相平均处理以升力信号为相位参考，构造 24 个相位 bin，从而把非定常尾流转换为可重复的相位锁定数据集，兼容涡脱落频率与相位锁定等分析。数据集同时包含时间/展向平均的速度、压力与雷诺应力，拖曳力与升力历史，以及每种物体一个三维瞬时快照，从而既能用于统计平均规律研究，也能作为降阶模型的训练/测试源。

### 关键技术

| 技术 | 说明 |
|------|------|
| 谱元直接数值模拟 (spectral-element DNS) | 高阶插值的谱元基函数，边界层解析；用于生成高保真参考场 |
| 壁面解析 (wall-resolved) | 不使用壁面模型，直接解析近壁粘性尺度，保证分离点与再附预测准确 |
| 时间分辨平面 PIV | 试验段内平面测量，配合相同坐标框架实现与 DNS 逐场对比 |
| 升力相位平均 (phase-averaging) | 以升力信号为相位基准，划分 24 个相位 bin，提取相位锁定结构 |
| 展向平均 | 对三维流动取展向（spanwise）平均，提取二维化统计量 |
| 雷诺应力分解 | 提供时间/展向平均的雷诺应力张量分量，用于闭合模型开发 |
| Re = 3900 参考验证 | 借用经典圆柱绕流基准数据校核 DNS 设置可信度 |

## 摘要要点

> We present a cross-validated dataset of turbulent wakes behind nine bluff bodies at Reynolds number Re = 10,000: a circular cylinder, a 2:1 elliptical cylinder at 0° and 90°, short and long isosceles triangles with the apex upstream or downstream, and a square cylinder at 0° and 45°. Each body was studied by wall-resolved direct numerical simulation (DNS) with a spectral-element solver and by time-resolved planar particle image velocimetry (PIV) in the MIT Intelligent Towing Tank. The DNS records contain time- and spanwise-averaged velocity, pressure and Reynolds stresses, 24-bin phase-averaged fields keyed to the lift signal, drag and lift histories, and one three-dimensional instantaneous snapshot per body; the PIV records contain the matching time-mean and phase-averaged fields in the same coordinate frame. The DNS set-up is verified against reference cylinder data at Re = 3900, and DNS and PIV at Re = 10,000 are compared field by field. The dataset supports the development and testing of data-driven turbulence closures, reduced-order models, and wake-stability analyses across geometries with distinct separation behavior.

## 公式 / 理论要点

```math
% 背景方程：不可压缩 Navier-Stokes（DNS 直接求解）
\frac{\partial \boldsymbol{u}}{\partial t}
+ (\boldsymbol{u}\cdot\nabla)\boldsymbol{u}
= -\frac{1}{\rho}\nabla p + \nu \nabla^2 \boldsymbol{u},
\qquad
\nabla\cdot\boldsymbol{u}=0
```

```math
% 雷诺分解与雷诺应力（本数据集重点提供的量）
\boldsymbol{u} = \overline{\boldsymbol{u}} + \boldsymbol{u}', \qquad
\tau_{ij} = \rho\left(\overline{u_i u_j} - \overline{u_i}\,\overline{u_j}\right)
```

```math
% 相平均（以升力信号为相位键）
\boldsymbol{u}(\boldsymbol{x},t)
= \langle \boldsymbol{u}\rangle(\boldsymbol{x})
+ \sum_{n=1}^{N}\boldsymbol{u}_n(\boldsymbol{x})\, e^{i\phi_n(t)}, \qquad N = 24
```

```math
% 无量纲化与载荷
Re = \frac{U_\infty D}{\nu}, \qquad
C_D = \frac{2F_D}{\rho U_\infty^2 D}, \qquad
C_L = \frac{2F_L}{\rho U_\infty^2 D}
```

```math
% 展向平均
\overline{\boldsymbol{u}}^{\,s}(\boldsymbol{x}) = \frac{1}{L_z}\int_0^{L_z}\boldsymbol{u}(\boldsymbol{x},y,z)\,dz
```

## 实验与结果

- **算例/数据集**: 九种钝体在 Re = 10,000 下的尾流数据集——圆柱、2:1 椭圆圆柱（0°、90°）、短/长等腰三角形（顶点朝上游或下游）、方柱（0°、45°）。每种物体分别进行壁面解析 DNS（谱元求解器）与时间分辨平面 PIV（MIT Intelligent Towing Tank）。
- **对比基线**: Re = 3900 下的参考圆柱绕流数据（验证 DNS 设置）；以及 Re = 10,000 下的 DNS 与 PIV 逐场互比（实验验证）。
- **主要结果**:
  - DNS 侧产出时间与展向平均的速度、压力、雷诺应力，24 个相位 bin 的相平均场（以升力信号为相位键），拖曳力与升力历史，以及每种物体一个三维瞬时快照。
  - PIV 侧产出同一坐标系下匹配的时间平均场与相平均场，实现 DNS–PIV 的直接可比性。
  - DNS 设置在 Re = 3900 下经参考圆柱数据验证；在 Re = 10,000 下 DNS 与 PIV 逐场比较，为数据集提供数值—实验双重可信度支撑。
  - 数据集覆盖具有不同分离行为的几何族，可直接用于数据驱动湍流封闭、降阶模型与尾流稳定性分析。

## 局限性

- 固定在单一雷诺数 Re = 10,000，未提供雷诺数扫描，跨 Re 的泛化能力受限。
- PIV 为平面测量，展向与法向信息缺失，只能与 DNS 的展向平均量对应，无法验证三维结构。
- 每种物体仅提供一个三维瞬时快照，无法支撑瞬态三维统计（如展向相干模态）的严格验证。
- 相平均仅使用单一升力信号作相位键，对非升力主导或强三维非定常构型的适用性有限。

---

## 实现建议

- **实现难度**: 高 — 壁面解析 DNS 需极高网格分辨率与严格的时间推进精度；相平均处理与实验 PIV 的时间/空间对准则需精确标定。
- **预期性能**: DNS 与 PIV 逐场比较一致，构型数据在相平均层面具备良好一致性；数据可直接支撑降阶模型的训练与验证，无需再处理几何归一化。
- **适用场景**: 钝体绕流分离机制研究、跨几何泛化的降阶模型与湍流封闭开发、涡脱落相位锁定与尾流稳定性分析、流动体识别（body wake fingerprinting）。
- **可复用要点**:
  - **"同一坐标系下的 DNS+PIV 双源数据集"**是验证数据驱动湍流模型是否真正学到物理（而非学到模拟器偏差）的有力范式，值得作为 CFD 代理模型验证的标准做法。
  - **以载荷信号为相位键的多 bin 相平均**可把非定常分离流动转成可统计的相位锁定场，是研究涡脱落相干性的通用后处理技术。
  - **展向平均 + 三维瞬时快照并存的混合数据集组织方式**，兼顾统计量与拓扑结构两类下游需求，可迁移到任何需要兼顾统计与结构的三维流动数据发布中。
