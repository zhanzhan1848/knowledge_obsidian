# 耦合 LBM 海冰孔隙尺度糊状层模型

## 核心贡献

两个**方法学创新** + 一个应用：

1. **Link-based Volume-of-Pixel (VOP)** 格式：相变速率在**每条界面链路（link）上单独求解**，而非节点上单值 → 解析方向依赖的界面运动
2. **广义 Robin 边界处理**：把 Huang et al. 的 2D 格式推广到 **3D (D3Q19)**，并把适用界面位置范围扩展到**整个单元跨度**（ melting 与 solidification 全程）
3. 应用：海冰盐水通道的孔隙尺度糊状层动力学

## 问题背景

**糊状层（mushy layer）**：固体骨架被多组分液体渗透，通过热-质耦合维持局部热力学平衡。存在于海冰、岩浆房、内外核边界、金属铸造。

**海冰特殊性**：二相二组分反应多孔介质（淡水冰晶 + 盐水）。
- 外部温度梯度 → 热扩散（冰 + 盐水双相）
- 冻结**排盐**、融化**释放淡水稀释**
- 局部热力学耦合 → 反复重分配热与盐 → 改变局部平衡态 → **重塑孔隙几何**

## 数值方法

### LBM 框架
- **BGK** 碰撞格式
- **D2Q5**（2D 验证）+ **D3Q19**（2D/3D 生产）
- 格子间距 $\Delta x=1$，格子声速 $c_s=1/\sqrt{3}$
- 浓度弛豫时间：$D=c_s^2(\tau_C-0.5)$

### 界面运动学（相变）
VOP 几何：节点液相分数 $\alpha_j$，界面归一化位置
$$\gamma_{i,j}(t)=\alpha_j(t)+\alpha_{j+1}(t)-0.5$$

**方向依赖相变速率（本文创新）**：
- 节点各向同性形式（式 47）：所有链路共用节点值
- **链路式形式（式 48）**：每条正交界面链路 $i=1..N_O$ 用各自的界面温度 $\theta_{b,i}$ 和浓度 $c_{b,i}$ 求解

无量纲化：
$$\tilde R'=\tilde R/L,\qquad t'=Dt/L^2$$
$$\frac{d\tilde R'}{dt'}=Da\,[\theta(\tilde R')-c(\tilde R')],\qquad Da=\frac{B\Delta T\,L}{D}$$

即界面速度 $\frac{d\tilde R}{dt}=k_r[\theta(\tilde R)-c(\tilde R)]$，$k_r=(D/L)Da=B\Delta T$（单位 $\mathrm{m/s}$）。

D3Q19 中 $A_2$ 需区分正交链路与对角链路：对角方向投影 $A_2=(\mathbf{e}_i/\|\mathbf{e}_i\|)\cdot(d\mathbf{R}_i/dt)$。

### Robin 边界（广义化）
- 原 Huang et al. 格式限定界面位置在链路的**受限区间**
- 本文推广至**完整单元跨度**
- 收敛率：部分区间达**二阶**，其余介于**一阶与二阶之间**

### 算法流程
```
初始化 → 计算宏观量 (T, C) → 更新界面位置 γ → 
评估界面速率 A2 → LBM (平衡/碰撞/输运) → 
Robin 边界 (用 γ, A2) → VOP 更新 (V_l, V_s, α) → 循环
```
**关键**：溶质边界处理与 VOP 演化的耦合**通过 $\gamma_{i,j}$ 和 $A_2$ 中介**。

### 验证算例
1. **一维半无限 Stefan 问题**（2D 矩形网格 **200×10**）
   - $T_i^*=2$，$T_f^*=1$，冷边界 $T_w^*=0$
   - 潜热 $L^*=0.5$，$c_{p,s}^*=0.42$，$c_{p,l}^*=1$
   - 变热扩散比 $\kappa_s^*/\kappa_l^*\in\{1,2,4\}$
   - VOP 相变率由焓基估计适配为锐界面形式：$A_2=f_i\,\partial\phi/\partial t$，$f_i=[(\partial\phi/\partial n)_i]^{-1}$

## 应用：海冰孔隙尺度糊状层

- 纯扩散区（忽略流体运动与对流输运）——为隔离新格式而作的有意简化
- 假设：相内热物性常数；固液密度差忽略（$\rho_s=\rho_l$）；亚共晶二元溶液
- 相图：NaCl-水二元系统液相线分支

**结论**：
- 在适当尺度分离下恢复**理想糊状层行为**
- 在海冰相关浓度比下，热扰动引起**相当大的盐水浓度变化** → **冻结而非融化**以**非均匀方式重塑孔隙几何**
- 框架提供了解析耦合温度、溶质再分配与相边界动力学的孔隙尺度工具

## 假设与局限

⚠️ **纯扩散假设**：忽略对流——海冰演化早期（慢速脱盐、对流起始前）适用，但不普遍成立
⚠️ 忽略固液密度差 → 不处理浮力对流（海冰中这很重要）
⚠️ Robin 处理收敛率非处处二阶（部分区间一阶）

## 评估

✅ **方法学扎实**：VOP 几何 + LBM 输运 + 广义 Robin 的耦合设计干净，且有 benchmark 层级
✅ Robin 格式的推广（2D→3D、全区间）是可直接复用的贡献
⚠️ 收敛率"一阶到二阶之间"略低于理想；工程上仍可接受
⚠️ 应用算例简单（局部孔隙段），未做长时间积分验证
⚠️ 与 Maggiolo 2611.06239（同一作者，同批）配合阅读：后者用 LBM 做填充床混合，正好是本文 LBM 框架的另一应用
