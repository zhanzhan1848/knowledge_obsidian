## 核心贡献

> **首次将深度学习用于二维声门内 PIV 的声带自动分割，系统比较架构与 ImageNet 预训练的影响，发现预训练对 Transformer 系的边界质量提升尤为显著（Swin-UNet 约为 4 倍）。**

1. **问题定义**：二维声门内 PIV (intraglottal PIV) 体外声带发声实验可定量给出声带中面运动与声门内流场，但依赖**人工分割**——残留眩光 (glare)、组织—流体对比度低示踪粒子散斑 (speckle) 共同遮蔽了声带边界。
2. **首次应用**：据作者所知，这是**首个将深度学习用于二维声门内 PIV 声带分割**的研究，并提供了在**噪声光学条件或强可变形目标**下分割实验流场图像的参考框架。
3. **六条 pipeline 的基准对比**（三类架构 × 预训练与否）：
   - CNN 类：**UNet**、**UNet++**；
   - 混合 CNN–Transformer：**TransUNet**；
   - 纯 Transformer：**Swin-UNet**；
   - 后两者分别在**从头训练 (from scratch)** 与 **ImageNet 预训练权重**下训练。
4. **预训练的效应**：预训练**显著改善** TransUNet 与 Swin-UNet 的**边界 F1 (BF1)** 与 **95 百分位 Hausdorff 距离 (HD95)**，其中 **Swin-UNet 的提升约为 4 倍**。预训练后两者表现相近，尽管 **Swin-UNet 的可训练参数量仅约为其 1/4**。
5. **无预训练时的反转结论**：**从头训练**时，TransUNet 的 BF1 显著高于两个 CNN pipeline、HD95 显著更低，且 HD95 > 50 像素的图像占比约为 CNN 方案的一半。
6. **统计显著性与协议严谨性**：16,344 张专家标注图像（来自 227 次切除犬喉发声试验），五条随机种子，标准化训练协议，在 50 个留出试验上用**试验级 Wilcoxon 符号秩检验 + Holm 校正**做比较。

## 技术方案

### 核心思想

这是一篇**方法学基准 (methodological benchmark)** 论文，核心问题是：在**退化成像条件**下（眩光、低对比度、粒子散斑、目标强变形），深度架构与预训练对分割边界质量的影响如何？

分析框架：

- **DSC 饱和 → 用边界指标区分**：平均 Dice 相似系数在 0.9734–0.9764 之间极窄区间，说明所有方案在**区域重叠**上几乎无差别；差异只体现在**边界保真度**上，因此必须用 **BF1 与 HD95** 才能分辨优劣。
- **架构 × 预训练的 2×3 设计**：把"归纳偏置"（CNN 局部性 vs Transformer 全局注意力 vs Swin 的局部窗口注意力+移位）与"迁移学习"两个因素解耦。
- **试验级统计**：同一试验内的多帧图像不独立 → 统计单元必须是**试验**而非图像，故用 Wilcoxon 符号秩检验 + Holm 多重比较校正。

### 关键技术

| 技术 | 说明 |
|------|------|
| **UNet / UNet++（CNN）** | 局部感受野强，归纳偏置适合对齐良好的小目标 |
| **TransUNet（CNN-Transformer 混合）** | CNN 提特征 + ViT 全局注意力 |
| **Swin-UNet（纯 Transformer）** | 层次化移位窗口注意力，参数量最省 |
| **ImageNet 预训练 vs 从头训练** | 迁移学习的核心变量 |
| **DSC (Dice 相似系数)** | 区域重叠指标 |
| **BF1 (边界 F1)** | 容差带内的边界精度 |
| **HD95 (95% Hausdorff 距离)** | 边界极端偏差的稳健度量 |
| **试验级 Wilcoxon + Holm 校正** | 非参数配对检验，处理多帧非独立问题 |
| **5 随机种子** | 量化训练随机性 |
| **流体图像分割参考框架** | 迁移到一般噪声流场图像（粒子图像、PIV、密集颗粒） |

## 公式

```math
\text{Dice 相似系数（区域重叠）:}\quad
\mathrm{DSC}=\frac{2|A\cap B|}{|A|+|B|},
\qquad
A=\text{预测掩膜},\ B=\text{专家标注}
}
```

```math
\text{边界 F1（容差带内的边界精度，本质形式）:}\quad
\mathrm{BF1}
= 2\,\frac{|\partial A \cap \partial B|_{\delta}|}
{|\partial A|_{\delta}| + |\partial B|_{\delta}|},
\qquad
\delta=\text{边界容差（像素）}
}
```

```math
\text{Hausdorff 距离与其 95\% 稳健版本:}\quad
\mathrm{HD}_{95}(A,B)
=
\max_{p\in\partial A}\Big\{\,
\min_{q\in\partial B}\|\mathbf{p}-\mathbf{q}\|
\ \Big\}_{95\%\ \text{分位}}
}
```

```math
\text{非参数配对统计检验（试验级）:}\quad
H_0:\ \mathrm{median}\bigl(\mathrm{Diff}_\text{method A,B}\bigr)=0,
\qquad
\text{Holm 校正控制 family-wise error rate}
}
```

> 注：以上为标准指标的规范形式；原文摘要未给出 $\delta$ 取值、DSC/HD95 的具体样本分布细节。

## 实验结论

- **数据集/算例**：16,344 张专家标注的高速摄影 (high-speed) 图像，来自 **227 次切除犬喉 (excised canine larynx) 体外发声试验**；在 **50 个留出试验**上评估；每条 pipeline **5 个随机种子**。
- **基线**：UNet、UNet++（纯 CNN）；TransUNet（混合）；Swin-UNet（纯 Transformer）；预训练 vs 从头训练。
- **结果**：
  - 平均 DSC 跨方案仅 **0.9734–0.9764** → 差异主要在**边界保真度**。
  - **预训练**显著提升 TransUNet 与 Swin-UNet 的 BF1 与降低 HD95；**Swin-UNet 的改善约为 4 倍**。
  - **预训练后** TransUNet 与 Swin-UNet 表现相近，但 **Swin-UNet 可训练参数仅约 1/4**。
  - **未预训练时**，TransUNet 的 BF1 显著高于两个 CNN pipeline，HD95 显著更低，HD95>50 px 的图像占比约为 CNN 方案的一半。
  - 统计检验：试验级 Wilcoxon + Holm 校正。

## 局限性

- **物种与几何单一**：仅**犬**切除喉，喉部解剖与人类差异明显；结论向人体声带迁移需谨慎。
- **二维**：仅 2D 声门内 PIV 平面；三维声门几何/多平面 PIV 未涵盖。
- **分割而非流动**：只分割声带边界，不做流场重建/粒子速度求解（但为后续 PIV 速度场自动处理打下基础）。
- **数据集规模**：227 次试验、50 个留出试验，样本数对深度模型而言偏小（虽有 16k 图像，但独立样本是试验）。
- **未见领域迁移**：所有训练/测试均来自同一成像系统（同一相机、同一实验装置），跨设备/跨实验室泛化未评估。
- **架构范围有限**：仅 4 个架构（其中 2 个做预训练对照），未包含 Diffusion-based 分割器、ConvNeXt/MaxViT 等更新的骨干；"ImageNet 预训练有益"的结论对自监督预训练（MAE/DINOv2）是否成立未检验。

## 实现建议

- **实现难度**：🟢 低。标准分割代码库（MONAI / nnU-Net / segmentation_models_pytorch）即可复现；主要工作在**数据组织**（16k 图像的 IO 与增广）与**严格的评估协议**。
- **预期性能**：单卡（显存 12–24 GB 足够，2D 灰度图）在 227 次试验量级数据上，每条 pipeline × 5 seeds 的训练为数小时；推理 ~ms/帧。
- **适用场景**：
  - **PIV / 粒子图像的自动化后处理**：本工作框架可**直接迁移**到任何"低对比度 + 强变形 + 噪声"的流场图像分割任务（如流线界面、粒子团、液滴轮廓、稀疏流场中的固壁）；
  - 作为**实验流场图像分割的参考基准**（作者明确以"参考框架"定位）。
  - **方法学决策工具**：当 DSC 已饱和（>0.97）时，用 BF1/HD95 而非 DSC 来选模型——这是本文最可迁移的方法论。
- **落地建议**：**推荐落地**，并附带三条经验：
  1. **不要用 DSC 选模型**——它已饱和，必须看 BF1 与 HD95；
  2. **有预训练就用预训练**——对 Transformer 系（尤其纯 Swin）收益最大（约 4 倍），且 Swin-UNet 在同等质量下参数量最少；
  3. **统计单元用试验/视频级**，而非帧级，否则 p 值会被严重高估。
