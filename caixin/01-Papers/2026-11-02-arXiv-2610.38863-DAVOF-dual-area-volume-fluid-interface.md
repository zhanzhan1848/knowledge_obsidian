## 核心贡献

> 在 VOF 中首次实现**单元内封闭解**的界面法向与位置恢复：同时输运每个单元的体积分数与每个面的湿润面积分数，二者结合后**无需邻居、无需迭代**即可用闭式方程精确恢复界面法向与位置，从而在非结构多面体网格上根治几何 VOF 的方向估计退化与毛细流寄生电流问题。

1. **双分数协同输运**：与体积分数一致性地输运每个面的**湿润面积分数**（face area fraction），与既有的 face volume fraction 互补。
2. **闭式恢复公式（首创）**：
   - 界面**法向**由单元自身各面的面积分数**一次求和**得到；
   - 界面**位置**由液体子体积的**散度定理**得到；
   - 二者均为**两个独立恒等式**，不含邻居、不需迭代。
3. **精确性**：两个恒等式对六面体、扰动（perturbed）网格与多面体单元上的**平面界面均精确成立**。
4. **收敛阶**：球面与椭球上，法向误差阶为面分数阶（order of the face fractions）；**位置为二阶精度**，对所有状态与网格均成立；通过单环法向的二次曲面拟合给出**收敛的曲率**，而参考模型（plicRDF / isoAdvector）此处无法给出。
5. **输运实现（初步）**：带平面裁剪（plane clipping）的输运、环法向、同一恒等式在单元环上的应用，使球体状态稳定并在 **3.3 个直径**内保持有界与守恒。
6. **一单元一抛物面**的初步输运实现：法向定义其坐标系，环给出曲率张量，体积分数给出位置；在 $N=32 \to 128$ 的分辨率阶梯上保持有界守恒。

## 技术方案

### 核心思想

几何 VOF 在非结构多面体网格上通过**邻居单元的体积分数 stencil** 重建界面方向；在不规则单元与"细丝 (wisp)"存在时该方法退化，而**建立在其上的曲率**又驱动了毛细流的**寄生电流 (parasitic currents)**。DAVOF 的思路是：既然体积分数是单元级守恒量，就让**面积分数也获得同等级的守恒输运**，使界面几何可以纯粹由**单元自身**的信息闭式恢复。

### 关键技术

| 技术 | 说明 |
|------|------|
| **面面积分数输运** | 与体积分数一致地输运每个面的湿润面积分数 |
| **法向恢复（恒等式 A）** | 对单元自身各面的一次求和直接给出界面法向 |
| **位置恢复（恒等式 B）** | 对液体子体积应用散度定理直接给出平面位置 |
| **环法向 (ring normal)** | 单环恢复法向 → 二次曲面拟合 → 曲率 |
| **输运** | 平面裁剪 + 环法向 + 环上的同一恒等式 |
| **高级方案** | 一单元一抛物面：法向定坐标系、环给曲率张量、体积分数给位置 |

## 公式

```math
\text{法向：}\quad \mathbf{n} = \mathcal{F}\!\left(\sum_{\text{faces } f \in \partial \Omega} a_f\,\hat{\mathbf{n}}_f\right)
```

$$\text{位置：}\quad \mathbf{x}_{\rm plane} = \mathcal{G}\!\left(\text{divergence theorem on liquid sub-volume}\right)$$

**精度陈述**：
- 法向：误差阶 = 面分数的阶（order of the face fractions）
- 位置：**二阶精度**（对所有状态、所有网格）
- 环二次拟合的曲率：收敛；参考模型（plicRDF / isoAdvector）此处无定义

**输运稳定性**（球体算例）：

| 实现 | 表现 |
|------|------|
| 平面裁剪 + 环法向 | 球体在 **3.3 个直径**行程内保持有界与守恒（一阶，面分数裁剪律所预测）；达到 plicRDF 的位置与形状误差水平 |
| 一单元一抛物面（初步） | 在分辨率阶梯 $N=32 \to 128$ 上有界守恒；精确法向下面分数约 **2.8/周期**，环二次曲面法向下约 **2.1/周期** |

> **关键自洽性**：该输运回路的收敛阶**等于其输入法向的收敛阶**——二阶法向即二阶输运，这是作者明确指出的后续研究目标。

## 实验结论

- **平面界面**：两个恒等式在六面体、扰动单元、多面体单元上**精确**。
- **球面/椭球**：法向为面分数阶，位置为二阶；环二次拟合给出收敛曲率（参考模型失效）。
- **球体输运**：带平面裁剪的输运在 3.3 直径内保持有界与守恒，达到 plicRDF 精度。
- **抛物面方案**：分辨率阶梯 $N=32\to128$ 上保持有界守恒。
- **寄生电流**：由于曲率现在可以由收敛的环二次拟合给出（而非退化邻居估计），毛细流寄生电流问题获得根治路径。

## 局限性

- **一单元一抛物面的输运仍为"初步实现"**：论文明确称本文档为"further development of the method"的基础文档。
- 输运回路的阶数受限于输入法向的阶数（当前一阶），二阶法向输运尚未实现。
- 圆盘/球体的曲率由单环二次拟合给出，高曲率区域（细丝、断裂前沿）的稳健性未充分验证。
- 尚无大型并行算例与工业级几何的验证。
- 与 plicRDF / isoAdvector 的定量对比目前限于球体等简单算例。

## 实现建议

- **实现难度**：★★★★☆（闭式公式本身不难，难在**面面积分数的守恒输运实现**，以及在 OpenFOAM 的非结构网格上嵌入该几何内核；同时需要处理单元几何缓存、面交点计算、单元环构造）
- **预期性能**：几何恢复是 O(N_faces) 的纯局部代数运算，代价可接受；相比需要邻居 stencil 的方案反而可能更便宜（无邻接访问）
- **适用场景**：
  - 非结构多面体网格上的两相流（OpenFOAM 的典型场景）
  - 毛细流/表面张力主导问题（寄生电流敏感）
  - 精细界面几何需求（断裂、雾化、液滴变形）
- **可迁移点**：
  - "守恒量与几何量协同输运"的思想可推广到其它 VOF 变体（如锐界面相场耦合）
  - 局部闭式恢复避免了邻居 stencil，对 GPU/非结构网格缓存不友好架构友好
  - 环二次拟合曲率是通用的局部曲率估计器
  - 与 LEI/PLIC 框架的兼容性：可直接替换 plicRDF 的几何内核
