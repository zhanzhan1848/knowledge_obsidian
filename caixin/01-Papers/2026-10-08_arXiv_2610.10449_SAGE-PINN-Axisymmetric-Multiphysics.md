## 核心贡献

> 针对圆柱坐标系下轴对称多物理流，提出无奇异性的几何编码 PINN 框架

1. **几何编码消除奇异性**：通过 s=r² 守恒变换与修正流函数，从结构上消除 1/r 奇异性项
2. **解析边界拟合 ansatz**：边界条件被精确满足，无需松弛/惩罚项
3. **耦合稳定性训练策略**：分段动量-热-联合训练 + 残差归一化 + Péclet/Richardson 数延拓 + 物理尺度漂移守护

---

## 技术方案

### 核心思想

圆柱坐标系下 r→0 处 N-S 算子奇异导致 PINN 训练崩溃，SAGE-PINN 通过 s=r² 变量变换把 r=0 处的 1/r 因子从被优化残差中彻底抹掉，配合流函数保证质量守恒恒等，再用边界拟合解析函数严格满足壁面条件。

### 关键技术

| 技术 | 说明 |
|------|------|
| s=r² 守恒变量 | 移除显式 1/r 项，保留奇点处的真实物理正则性 |
| 流函数表示 | 质量守恒自动满足，无需连续性损失 |
| 边界解析 ansatz | 入口、出口、壁面 BC 精确满足，避免软约束误差 |
| 分段训练 | 动量阶段 → 耦合阶段 → 浮力阶段，逐步释放热-动耦合 |
| Residual Normalization | 平衡各项损失项量级，避免某项主导 |
| 数量延拓 | Pe/Re 由小到大扫描，规避非凸优化局部极小 |
| 漂移守护 | 物理尺度监测，防止网络输出非物理解 |

## 公式

轴对称圆柱坐标系下不可压缩 N-S 方程，控制方程通过 s=r² 与流函数 ψ(s,z) 重写后所有 1/r 因子消失。

```math
u_r = -\frac{1}{r}\frac{\partial \psi}{\partial z}, \quad
u_z = \frac{1}{r}\frac{\partial \psi}{\partial r}, \quad
u_\theta = 0
```

流函数定义下连续方程恒等成立，残差仅剩动量与能量方程。

## 实验结论

- **数据集**: 狭窄动脉(stenosed artery)稳态纳流体流动与传热，参考有限元解
- **基线**: 传统 PINN / 标准 FEM 解
- **结果**:
  - 质量守恒保持到单精度舍入误差
  - 轴向速度相对 L2 误差 ≤ 1.6%
  - 温度相对 L2 误差 ≤ 9.1%
  - 强浮力低流速 + 高 Peclet 强对流区精度退化

---

## 局限性

- 强浮力主导的慢速流、高对流传热极限区误差仍较大
- 未涉及瞬态/非稳态问题
- 对几何先验 (s=r²) 的依赖限制了非轴对称场景的推广

- **实现难度**: ⚠️ 中等（需要熟悉 N-S 方程的圆柱坐标形式与 PINN 训练技巧）
