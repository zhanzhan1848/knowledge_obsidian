## 核心贡献

> 用流体力学视角研究固体导热：把热流涡度分解为**轨道旋转 R**与**自旋 S**，构成**热涡度三元组 (R, S, ω)**，突破单一涡度研究范式

1. 定义**热涡度 ω = ∇ × q**（热流场的旋度），并分解为轨道旋转 **R** 与自旋 **S**
2. 示例：基于 **Peierls-Boltzmann 方程**（Callaway 双弛豫时间近似）数值求解 **2D 多孔固体**中的动理学声子输运
3. 分析不同动理学区制（N 正常散射 / R 电阻散射）相图下热涡与热涡度三元组的物理特征
4. 在**流体力学极限**下，基于截断 **Chapman-Enskog** 展开导出的 **Guyer-Krumhansl (G-K) 方程**阐明**边界涡度生成机制**
5. 提出新概念 **BHVF**（Boundary Heat Vorticity Flux），描述固体边界处热涡度的局部生成率
6. 关键结论：2D 稳态流体力学声子输运下，BHVF **完全归因于净热流切向分量偏离经典 Fourier 热流**；控制体内的总涡度来自 BHVF 的时空累积，并由 R 散射产生的**记忆核加权**

## 技术方案

### 核心思想

把流体力学的"涡度分解"范式迁移到固体热输运：热流场也有旋度，也有轨道/自旋分量。边界是涡度的源——这与流体中涡量生成机制平行。

### 关键技术

| 技术 | 说明 |
|------|------|
| 热涡度三元组 (R, S, ω) | ω = ∇×q，分解为轨道旋转与自旋 |
| Peierls-Boltzmann 方程 | 动理学声子输运，含 Callaway 双弛豫时间近似 |
| N/R 散射相图 | 正常散射 vs 电阻散射区制 |
| G-K 方程 | 由 Chapman-Enskog 截断展开导出，流体力学极限 |
| BHVF（边界热涡度通量） | 新提出的边界涡度生成率概念 |

## 公式

```math
热涡度分解:
  ω = ∇ × q        (q 为热流矢量)
  ω = R + S        (轨道旋转分量 R, 自旋分量 S)

Peierls-Boltzmann（Callaway 双弛豫时间）:
  ∂f/∂t + v·∇f + F/ℏ·∇_k f = (f₀ - f)/τ_N + (f_eq^R - f)/τ_R

Guyer-Krumhansl 方程（流体力学极限）:
  τ ∂²q/∂t² + q = -λ ∇(∇·q) - κ∇²q + ...   (G-K 形式)

边界热涡度通量 (BHVF):
  BHVF = 边界处热涡度的局部生成率
  2D 稳态: BHVF ∝ 净热流切向分量相对 Fourier 热流的偏差

记忆核加权:
  总涡度 = ∫∫ BHVF(位置, 时间) × K_R(t - t')  dt dt'
  K_R 为 R 散射产生的记忆核
```

## 代码片段

```python
import numpy as np

def heat_vorticity_triplet(q, dx):
    """
    q: 热流场 (..., dim=3)
    返回 轨道旋转 R, 自旋 S, 总涡度 omega
    """
    omega = np.gradient(q, axis=-3)   # curl(q)
    R = np.zeros_like(omega)
    S = np.zeros_like(omega)
    # 轨道/自旋分解（投影到梯度部分与反对称部分）
    for i in range(3):
        grad_part = np.stack([np.gradient(q[..., i], axis=-3+i) for i in range(3)], axis=-1)
        R += grad_part * (np.eye(3)[i] @ omega) / (np.sum(omega**2, axis=-1, keepdims=True) + 1e-12)
    S = omega - R
    return R, S, omega

def bhvf_at_boundary(q_normal, q_tangential, fourier_heat_flux):
    """边界热涡度通量：切向净热流相对 Fourier 热流的偏差"""
    return (q_tangential - fourier_heat_flux)
```

## 实验结论

- **数据集**: 2D 多孔固体结构的动理学声子输运（Peierls-Boltzmann 数值解）
- **基线**: 单一涡度研究范式（无分解）
- **结果**:
  - 建立了完整的**热涡度三元组 (R, S, ω)** 框架
  - 在 N/R 散射相图的不同区制下，热涡与三元组呈现不同的物理特征
  - 流体力学极限下，**边界涡度生成机制**由 G-K 方程阐明
  - 提出并严格推导了 **BHVF** 的通用表达式
  - 2D 稳态流体力学声子输运：**BHVF 完全归因于净热流切向分量相对 Fourier 热流的偏差**
  - 控制体内总涡度来自 BHVF 的时空累积，经 **R 散射记忆核加权**

---

## 局限性

- 2D 多孔固体示例为主，向三维推广需补充
- 依赖 Peierls-Boltzmann + Callaway 近似的适用范围
- 流体力学极限（G-K）结论在极低温/极短尺度失效
- 与经典流体涡度理论的对偶关系仍属类比性质，未建立严格映射
