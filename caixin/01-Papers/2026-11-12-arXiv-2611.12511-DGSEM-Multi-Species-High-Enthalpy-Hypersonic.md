## 核心贡献

> 用**不连续 Galerkin 谱元方法 (DGSEM)** 做**二维超声速冲压发动机 (scramjet)** 内**多组分高焓流动**模拟，验证该高阶格式在**激波–激波相互作用 (shock-shock interaction)** 这种强非定常、含大量耗散结构的复杂场景下与参考**有限体积 (FVM)** 求解器结果一致——证明 DGSEM 实现正确、且适用于高焓多组分流动。

1. **问题设定**：高超声速飞行器数值模拟中，**二阶有限体积 (FVM)** 是 CFD 的既有标准方法，但**耗散开销大 (cost of high dissipation)**，因此在可承受的网格上需要**大幅加密**或使用**自适应网格加密 (AMR)** 才能得到准确结果。
2. **替代方案**：**高阶不连续 Galerkin 方法**，特别是 **DGSEM**（不连续 Galerkin 谱元法），一旦在**单元局部多项式基**上达到更高的**形式精度阶**，就能以更少的自由度获得同等精度。
3. **验证对象**：**二维 scramjet 配置**，其中发生**激波–激波相互作用**——这是包含复杂波系、多重马赫反射与起动/解起动现象的**高难度**算例。
4. **验证结论**：结果与参考 FVM 求解器**一致**，从而**验证了代码实现的正确性**。

## 技术方案

### 核心思想

这是典型的**高阶格式验证论文 (verification/validation)**，其价值在于回答一个非常实际的工程问题：

> "二阶 FVM 是高超声速 CFD 的既有标准，但它太耗散。可否用 DGSEM 高阶格式，在**不增加甚至减少自由度**的前提下达到同等精度？"

**为什么高超声速是 DGSEM 的"压力测试"**：

高超声速流动中，格式的耗散特性直接决定结果对错：
- 二阶 FVM 的**数值耗散**通常被视为"有益的阻尼"——它能抑制激波后的不稳定振荡
- 但在**激波–激波相互作用**、**马赫反射**、**边界层分离/再附**等场景下，这种耗散会**涂抹掉真实的物理波系**，导致
  - 激波位置偏移
  - 起动/解起动（starting/unstarting）阈值预测错误
  - 加热长度预测错误

高阶 DG 的**低耗散**特性在波系复杂的场景中既是优势（能解析细结构）也是风险（可能产生虚假振荡）。因此这个算例是检验 DGSEM 实现是否稳健的理想试金石。

**DGSEM 的基本构造**：

DG 方法把计算域划分为若干单元，每个单元上用**$p$ 阶多项式**表示解：

```math
% 单元内的 DG 近似
\boldsymbol{u}_h(\boldsymbol{x}) \in \mathcal{P}_p(K)^n,
\qquad K \text{ 为一个网格单元}
```

- **弱式（弱形式）**：由分部积分把一阶/二阶导数转到弱形式，从而单元内部获得**高阶精度**
- **数值通量 (numerical flux)**：单元间通过**数值通量**耦合，是**唯一**的耗散来源
  - 因此 DGSEM 的耗散**完全由通量选择控制**——与 FVM 中"格式阶数决定耗散"不同
  - 这意味着在激波处**可以**用低阶（如 Lax–Friedrichs）通量，在光滑区用高阶通量

**多组分高焓的额外挑战**：

- **多组分输运**：各组分的**热扩散系数差异极大**（电子、离子、重粒子），导致**刚性输运方程**
- **化学非平衡 (CNE)**：高焓流动中**振动激发、离解、解离、复合**同时进行，时间尺度相差数个量级
- **热力学状态更新**：$\rho$、各组分 $Y_k$、$T$、$p$ 之间有**强非线性耦合**（状态方程 $p = p(\rho, Y_k, T)$），求根是**刚性**的
- 这些在 DGSEM 中都比 FVM 更难处理，因为高阶基函数上的非线性项会带来**更多耦合点**

### 关键技术

| 技术 | 说明 |
|------|------|
| DGSEM (不连续 Galerkin 谱元法) | 单元局部多项式基，可达任意**形式精度阶** |
| 形式精度阶 vs 实际精度 | 论文明确区分"达到更高形式精度阶"与"实际解精度" |
| 数值通量作为唯一耗散源 | DG 耗散可控性的根源 |
| 二维 scramjet 基准 | 激波–激波相互作用场景 |
| 参考 FVM 求解器对比 | 交叉验证 |
| 多组分高焓流 (multi-species high-enthalpy) | 化学非平衡、刚性输运、热力学状态更新 |
| 耗散–精度权衡 | 二阶 FVM 耗散 vs 高阶 DG 低耗散 |
| 自适应网格加密 (AMR) 作为 FVM 替代路径 | 论文将其列为既有替代方案，说明 DG 的价值在于"不改流程也能准" |

## 公式 / 理论要点

```math
% 多组分守恒方程组（高焓，含化学非平衡）
\partial_t \rho_k + \nabla\cdot(\rho_k\boldsymbol{u})
= \nabla\cdot\left(\rho_k\boldsymbol{d}_k\right)
+ \dot{\omega}_k,
\qquad k = 1,\dots,N_s
```

```math
% 能量方程（含焓升、辐射、化学源）
\partial_t (\rho E) + \nabla\cdot\left[(\rho E + p)\boldsymbol{u}\right]
= -\nabla\cdot\boldsymbol{q}
+ \nabla\cdot(\boldsymbol{\tau}\cdot\boldsymbol{u})
- \sum_k h_k\,\dot{\omega}_k
+ \dot{q}_{\text{rad}}
```

```math
% 刚性输运系数（多组分高焓的典型量级差异）
\boldsymbol{d}_k
= -D_k\nabla Y_k
+ \rho_k\,\boldsymbol{d}^{\text{thermal}}_k,
\qquad
\frac{D_{\text{electron}}}{D_{\text{heavy}}} \sim 10^{3}\!-\!10^{4}
```

```math
% DG 弱形式（单元 K 上的强形式弱化）
\int_K \frac{\partial \boldsymbol{u}_h}{\partial t}\,\boldsymbol{\psi}_h\,d\boldsymbol{x}
= \oint_{\partial K} \boldsymbol{u}^*\cdot\boldsymbol{n}\,\boldsymbol{\psi}_h\,dS
- \int_K \boldsymbol{u}_h\cdot\nabla\boldsymbol{\psi}_h\,d\boldsymbol{x}
- \int_K \boldsymbol{S}_h\cdot\boldsymbol{\psi}_h\,d\boldsymbol{x}
```

```math
% 数值通量：DG 中唯一的耗散来源
\boldsymbol{u}^* = \frac{1}{2}\left(
\boldsymbol{u}^{-}\boldsymbol{n} + \boldsymbol{u}^{+}\boldsymbol{n}
- \alpha\,\boldsymbol{g}(\boldsymbol{u}^{-}-\boldsymbol{u}^{+})
\right)
```

## 实验与结果

- **算例**: 二维 scramjet 配置，含**激波–激波相互作用**。
- **对比基线**: 参考 **FVM 求解器**（二阶有限体积）。
- **主要结果**:
  - DGSEM 结果与参考 FVM 求解器**一致**（agreement），从而**验证了 DGSEM 代码实现的正确性**。
  - 论文目标被明确表述为"**test and verify the applicability of the DGSEM approach**"——即验证 DGSEM 在复杂高超声速场景下的**适用性**。

## 实现建议

- **实现难度**: 高 — DGSEM 从零实现需要：单元内高阶多项式基与操作、映射（笛卡尔/曲线）、数值通量、限制器/熵稳定化、多组分输运与状态方程求根、以及 GPU 上的高性能核。
- **预期性能**: DG 的优势在**同等精度下自由度更少**；但单自由度成本远高于 FVM，且**并行需用单元内任务划分 + 面元并行**。二维验证阶段成本可控；三维高焓是主要成本瓶颈。
- **适用场景**:
  - **高超声速飞行器流场（内流/外流）**：激波系复杂、耗散敏感的场景；
  - **高焓化学反应器/燃烧室**：多组分 + 刚性 + 强耗散；
  - **钝体绕流的激波–激波相互作用**：DGSEM 能解析二次激波与马赫反射的真实波系；
  - **与 AMR-FVM 的路线对比**：本文把 AMR 列为 FVM 的替代方案，实际是在论证"**不必依赖 AMR，换成 DG 即可**"。
- **可复用要点**:
  - **DGSEM 实现的检查清单**（从本文这类验证论文可提炼）：单元内基函数操作 → 守恒量映射 → 面元数值通量 → 强/弱形式组装 → 单元内非线性项求值 → 时间积分（含刚性处理）→ 状态方程求根。逐项与 FVM 对照即可定位实现错误。
  - **"高阶格式 + 简单几何"是最低成本的 DG 正确性验证路径**——本文用二维 + 已知 FVM 结果，比直接上三维复杂几何安全得多。这是可复用的**验证策略**。
  - **耗散可控性**是 DG 相对 FVM 的结构性优势：可分区（激波用低耗散通量、光滑区用高阶通量），这在**激波–激波相互作用**中尤其有价值。
  - 建议与本轮 [[2026-11-12-arXiv-2611.11315-Flash-Evaporation-HRRF-Real-Fluid-Finite-Volume]] 对照阅读：后者是**FVM 路线**上处理相变数值振荡的结构化改进（HRRF），两篇合起来代表两条技术路线（FVM 精细化 vs DG 高阶化）解决同一类问题——**激波/相变区的数值振荡**。
