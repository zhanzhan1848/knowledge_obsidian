## 核心贡献

> 用 200+ 组二维 DNS 系统性扫描"喷流-锐边"(jet–labium) 相互作用的几何与流动参数，首次在**无共鸣腔**的简化竖笛吹口几何中分离出边缘音(edge-tone)的水动力失稳机制，定量标定各几何参数对振荡阶段(Stage I/II)与频率的支配作用。

1. **参数化规模空前**：200+ 组二维 DNS（浸入边界法），同时变化嘴距 W、哨唇角 α、竖直偏移 s、Reynolds 数 Re 四个参数；以往研究或只做理想对称楔形，或做含共鸣腔的完整乐器（声学主导、掩盖水动力）。
2. **St ≈ 0.07 的几何控制频率**：基线构型以几乎纯周期的 Stage I 边缘音振荡，Strouhal 数在 Re ≥ 330 与全部哨唇角下**几乎不变**——证明频率由几何而非粘性决定（支持经典指数 1 而非早期理论的 3/2）。
3. **嘴距 W 是唯一能激发第二振荡阶段的参数**，且 Stage I 频率与 W 成反比（复现 Brown 经验关系）；第二阶段在 W=5、6 弱存在，W≥6.5 明确建立，W=8 时占主导并强烈调制幅值。
4. **哨唇角不改变失稳机制**（仅影响几何扰动形态），竖直偏移主要调节振荡强度：偏移 0.5 个风道高度时幅值显著降低。
5. 识别出用于后续气动声学耦合研究的**基线构型**。

## 控制方程

二维不可压缩 Navier–Stokes（无量纲形式，特征长度 2h = 风道高度，速度尺度为射流中心线峰值 Û）：

```math
\nabla \cdot \mathbf{u} = 0
```

$$\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u}\cdot\nabla)\mathbf{u} = -\nabla p + \frac{1}{Re}\nabla^2 \mathbf{u}$$

```math
Re = \frac{\hat{U}(2\hat{h})}{\hat{\nu}}
```

> 无量纲化约定：$h = \hat h/2$，$L = \hat L/(2\hat h)$，$W = \hat W/(2\hat h)$，$s = \hat s/(2\hat h)$，风道高度 $2h = 1$ 恒成立；$\hat U = (3/2)\bar U$。

**诊断量**：labium 上的横向力 $F_y = \iint_{\text{labium}} \mathbf{f}\cdot\hat{\mathbf{e}}_y\, dS$ —— 这是驱动射流-哨唇反馈环的单点面积分量，且 $F_y$、$u$、$v$、$p$ 的主频一致（在 Welch 频率分辨率 $\Delta St = 0.005$ 内），因此单用 $F_y$ 即可刻画流场动态。

## 数值方法

| 技术 | 说明 |
|------|------|
| **方法** | 直接数值模拟（DNS），不可压缩 N-S |
| **离散化** | 浸入边界法（Immersed Boundary Method），Taira & Colonius 投影法实现 |
| **求解器** | IBMOS（Immersed Boundary Method for Optimization and Stability analysis），开源求解器 |
| **维度** | 二维；域为正方形，$x\in[-L_{xu}, L_{xd}]$，$L_y = 0.5(L_{xd}+L_{xu})$ |
| **入流边界** | 抛物线 Dirichlet 速度型（真实竖笛中粘性通道自然产生），沿入口通道保持，使风道出口处为充分发展抛物线型（避免均匀型假设在射流边界人为堆积涡量） |
| **网格** | 近场/远场双分辨率 $(n_1, n_2) = (24, 6)$ 为标准分辨率；网格无关性检验用 $(24,6)\to(36,12)\to(48,18)$，$n_1,n_2$ 同步加密 |
| **时间步** | 自适应 CFL；采样时长 1600 个无量纲时间单位 |
| **谱分析** | Welch 平均功率谱：记录切为 8 段（每段 200 时间单位），50% 重叠 → 15 段，Hann 窗，频率分辨率 $\Delta St = 0.005$ |
| **稳定性** | 低 Mach 数下不可压缩假设合理（与既有边缘音研究一致） |

## 参数扫描范围

| 参数 | 取值 | 物理含义 |
|------|------|----------|
| **嘴距 W** | 3, 4, 5, 6, 6.5, 7, 8, 12 | 射流出口到哨唇尖端水平距离（= 经典文献 nozzle-to-edge distance） |
| **哨唇角 α** | 15°, 30°, 60° | 竖笛约 15°，横吹长笛约 60° |
| **竖直偏移 s** | −0.5, −0.2, −0.1, 0, 0.1, 0.2, 0.5 | 射流中心线与哨唇尖端位移（正=尖端在射流中心线上方） |
| **Reynolds 数 Re** | 200, 330, 500, 700 | 基于风道几何（对应经典 nozzle height 尺度） |

基线几何：$L=7$，$L_{xu}=5$，$L_{xd}=50$（保证入流、相互作用区、出口充分分离）。

## 实验结论

- **基线构型**：以占主导的周期 Stage I 边缘音振荡，$St \approx 0.07$。
- **Re 依赖性**：$St_1 \approx 0.07$ 在 $Re \ge 330$ 几乎不变 → 频率由几何设定，非粘性主导。
- **W 依赖性（最强）**：唯一引入第二振荡阶段的参数；$St_1 \propto 1/W$（指数 ≈ 1，吻合 Vaik–Paál 的实验与数值结论）；W=5,6 第二阶段弱；W≥6.5 明确建立；W=8 第二阶段占主导、强幅值调制；W=12 时力信号高度不规则。
- **s 依赖性**：小偏移不改变振荡；中等偏移使振荡更易变；$s = 0.5$ 风道高度时幅值大幅降低。
- **α 依赖性**：不改变潜在失稳机制。
- **网格无关性**：三套网格的 $F_y$ Welch 谱几乎不可分辨，主峰稳定在 $St_1 \approx 0.07$。

---

## 局限性

- 二维、不可压缩：无法覆盖真实竖笛的三维展向不稳定性与声学反馈（马赫数相关的可压缩效应）。
- 未含共鸣腔：真实乐器的柱腔声学反馈会改变所选振荡阶段与幅值，本文的阶段划分只是"纯水动力"基线。
- 单侧斜边几何在 $s=0$ 时并非几何对称（与经典对称楔形文献不可直接对比）。
- 频率-距离指数的争议（早期理论 3/2 vs 实验 ≈ 1）在本工作为数值侧证据。
