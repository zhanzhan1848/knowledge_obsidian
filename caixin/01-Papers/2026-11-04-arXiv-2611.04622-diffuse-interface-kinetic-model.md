## 核心贡献

> 提出**弥散界面动理学模型 (DIKM)**：在**单一固定欧拉网格**上用**一个动理学格式**同时描述稀薄气体输运与气-固界面相互作用（包括**任意吸收概率**的表面吸收），通过**局部化分子通量算子**把边界交互直接嵌入动理学方程；并用**匹配渐近分析**证明在锐界面极限下**严格恢复**对应的**部分吸收漫反射边界条件**。

1. **单网格单方程统一建模**：光滑**序参量** $\phi\in[0,1]$ 表示固体几何，**局部化分子通量算子** $\mathcal B$ 直接进入动理学方程，无需显式追踪界面。
2. **任意吸收概率 $\beta\in[0,1]$**：入射分布按 $\beta$ 在"吸收"与"漫反射再发射"之间分配。$\beta=0$ → 无净质量传递 + 非穿透；$\beta=1$ → 完全吸收；$0<\beta<1$ → 部分吸收漫反射。
3. **严格的通量平衡**：壁面密度由**入射-反射-吸收通量平衡**确定
   $$\rho_\Gamma=\frac{(1-\beta)\int_{c_n<0}|c_n|f^-\,d\boldsymbol\eta d\boldsymbol\zeta}{\int_{c_n>0}c_n\widehat f_{M,\Gamma}\,d\boldsymbol\eta d\boldsymbol\zeta}$$
   分母解析可得 $\sqrt{RT_\Gamma/(2\pi)}$。
4. **匹配渐近分析证明锐界面极限正确**：拉伸法 $z=r/\epsilon$ 下的内展开证明，入射分布与发射分布**逐点恢复**锐界面 BC（$f^-=f^-$、$f^+=\rho_\Gamma\widehat f_{M,\Gamma}$）。
5. **数值格式**：**Strang 分裂** —— 序参量加权的**离散统一气体动理学格式 (DUGKS)** 输运子步 + 界面源的**保正性 (positivity-preserving)** 更新。
6. **几何与物理耦合闭环**：序参量按**带退化迁移率的 Cahn-Hilliard 方程**演化，实现薄膜生长的相场模拟（不同入射角 → 不同表面轮廓）。

## 技术方案

### 核心思想

**问题**：稀薄气体与**复杂运动边界**（含吸收/反应）的耦合建模，传统路线要么用 DSMC（贵），要么用"界面几何 + 边界条件"两段式（几何与物理解耦，且难处理移动界面）。

**DIKM 思路**：把界面几何**平滑化为序参量场**，并把界面交互**写进动理学方程的源项**，让几何与输运**在同一套方程、同一网格**上演化。

### 关键技术

| 技术 | 说明 |
|------|------|
| Shakhov 方程 | 体相输运：$\partial_t f+\boldsymbol\xi\cdot\nabla f=Q_S(f)$，$Q_S(f)=-f+f_S/\tau$ |
| 序参量正则化 | $\phi=\frac12[1+\tanh(3r/\epsilon)]$；$\phi=1$ 气体，$\phi=0$ 固体；界面为 $\phi=1/2$ 等值面 |
| 正则化面 delta | $\delta_\epsilon=|\nabla\phi|=\frac{6}{\epsilon}\phi(1-\phi)$（coarea 构造，积分为 1）|
| 局部化分子通量算子 | $\mathcal B=-\chi_-|c_n|f+\chi_+c_n\rho_\epsilon\widehat f_{M,\epsilon}$，区分入射/发射 |
| 运动壁牵引分解 | $\boldsymbol t_\epsilon=-\boldsymbol m_\epsilon+\boldsymbol u_\epsilon j_\epsilon$（分离"被吸收质量携带的动量"）|
| Strang 分裂 | 输运子步（序参量加权 DUGKS）+ 界面源子步（保正性更新）|
| 表面能模型 | Knudsen-Langmuir 升华律 + 壁面能量平衡（焓 + 辐射）|

## 公式

```math
% ===== DIKM 主方程 =====
\frac{\partial(\phi f)}{\partial t}+\boldsymbol\xi\cdot\nabla(\phi f)
=\phi Q_S(f)+\delta_\epsilon\mathcal B

% ===== 局部化分子通量算子 =====
\mathcal B=-\chi_-|c_n|f+\chi_+c_n\rho_\epsilon\widehat f_{M,\epsilon}

% ===== 序参量正则化 =====
\phi(\boldsymbol x,t)=\frac12\left[1+\tanh\left(\frac{3r(\boldsymbol x,t)}{\epsilon}\right)\right],
\qquad \delta_\epsilon=|\nabla\phi|=\frac{6}{\epsilon}\phi(1-\phi)

% ===== 通量平衡确定壁面密度 =====
\rho_\epsilon=\frac{(1-\beta)\int_{c_n<0}|c_n|f\,d\boldsymbol\eta d\boldsymbol\zeta}
{\int_{c_n>0}c_n\widehat f_{M,\epsilon}\,d\boldsymbol\eta d\boldsymbol\zeta},
\qquad \int_{c_n>0}c_n\widehat f_{M,\epsilon}\,d\boldsymbol\eta d\boldsymbol\zeta=\sqrt{\frac{RT_\Gamma}{2\pi}}

% ===== 吸收通量 =====
J_{\mathrm{abs}}=\beta\int_{c_n<0}|c_n|f^-\,d\boldsymbol\eta d\boldsymbol\zeta

% ===== 加权形式（表明表面项抵消）=====
\phi\left[\frac{\partial f}{\partial t}+\boldsymbol\xi\cdot\nabla f-Q_S(f)\right]
=\delta_\epsilon(\mathcal B-c_nf)-fE_\phi,
\qquad E_\phi=\frac{\partial\phi}{\partial t}+\boldsymbol u_\epsilon\cdot\nabla\phi

% ===== 界面质量/动量/能量交换 =====
\begin{bmatrix}j_\epsilon\\ \boldsymbol m_\epsilon\\ e_\epsilon\end{bmatrix}
=\int\begin{bmatrix}1\\ \boldsymbol\xi\\ (\xi^2+\eta^2+\zeta^2)/2\end{bmatrix}\mathcal B\,d\boldsymbol\eta d\boldsymbol\zeta

% ===== 壁面牵引与能量（分离吸收质量携带项）=====
\boldsymbol t_\epsilon=-\int(\boldsymbol\xi-\boldsymbol u_\epsilon)\mathcal B\,d\boldsymbol\eta d\boldsymbol\zeta
=-\boldsymbol m_\epsilon+\boldsymbol u_\epsilon j_\epsilon

q_\epsilon=-\frac12\int\left(|\boldsymbol\xi-\boldsymbol u_\epsilon|^2+\eta^2+\zeta^2\right)\mathcal B\,d\boldsymbol\eta d\boldsymbol\zeta

% ===== 匹配渐近：内层运动学相容条件 =====
E_\phi=o(\epsilon^{-1})\ \Longrightarrow\ V_{n,\Gamma}=\boldsymbol u_\Gamma\cdot\boldsymbol n_\Gamma

% ===== 匹配渐近：入射/发射分布 =====
c_n\partial_z(\Phi_0F_0)=\Phi_0'\mathcal B_0
\Longrightarrow\ F_0=f^-\ (c_n<0),\qquad F_0=\rho_\Gamma\widehat f_{M,\Gamma}\ (c_n>0)

% ===== 界面动量守恒形式 =====
\frac{\partial}{\partial t}\begin{bmatrix}\phi\rho\\ \phi\rho\boldsymbol u\\ \phi\rho E\end{bmatrix}
+\nabla\cdot\begin{bmatrix}\phi\rho\boldsymbol u\\ \phi\rho\boldsymbol u\boldsymbol u+\phi\boldsymbol P\\ \phi\rho E\boldsymbol u+\phi\boldsymbol P\cdot\boldsymbol u+\phi\boldsymbol q\end{bmatrix}
=\delta_\epsilon\begin{bmatrix}j_\epsilon\\ \boldsymbol m_\epsilon\\ e_\epsilon\end{bmatrix}
```

# Strang 分裂伪代码（输运子步 + 界面源子步）
def strang_step(f, phi, dt):
    # ---- 子步 1: 序参量加权 DUGKS 输运 ----
    f = DUGKS_transport(f * phi, dt)          # 序参量加权
    # ---- 子步 2: 界面源（保正性更新）----
    c_n   = (xi - u_eps) @ n_eps
    chi_m = (c_n < 0); chi_p = (c_n > 0)
    inc_flux = integrate(|c_n| * f * chi_m)            # 入射通量
    rho_eps = (1 - beta) * inc_flux / sqrt(R*T_eps/(2*pi))
    B = -chi_m*|c_n|*f + chi_p*c_n*rho_eps*fM_eps       # 局部化分子通量算子
    f = positivity_preserving_update(f, delta_eps * B, dt)  # 保正性
    return f

# 界面几何更新（Cahn-Hilliard, 退化迁移率）
phi = cahn_hilliard(phi, mobility='degenerate', dt=dt)

## 实验结论

- **数据集/算例**：平面与曲面边界；静止与运动边界；不同吸收概率；薄膜生长。
- **基线**：锐界面部分吸收漫反射 BC 的经典 DSMC 结果。
- **结果**：
  - 弥散格式在 $\epsilon\to 0$ 时**精确恢复**部分吸收漫反射 BC（匹配渐近 + 数值双重验证）；
  - 正确再现**稀薄度依赖的速度滑移 (velocity slip)** 与**壁面换热**；
  - 正确再现**吸收驱动的流动**（$\beta>0$ 时的净质量注入）；
  - 正确再现**气体作用力与固体平动/转动的双向反馈**（$\dot M_\epsilon,\boldsymbol F_\epsilon,\boldsymbol T_\epsilon,\dot Q_\epsilon$）；
  - 薄膜生长在不同入射角下给出**不同表面轮廓**。

## 局限性

- **潜热、结合能、固体内部导热需另接材料能量模型**（论文明确声明本文不含）。
- 序参量按 **Cahn-Hilliard + 退化迁移率**演化，意味着界面是**扩散型**而非严格刚体平移；与真正的刚体运动有本质差别（匹配渐近仅对"表面速度 = 流体法向速度"给出相容条件）。
- DUGKS 输运子步 + 界面源子步的分裂引入**分裂误差**，激波强间断处的精度受限。
- 稀薄气体的**热化学非平衡**（多组分反应）不在本文范围内。
- 计算成本仍高于连续介质方法（分布函数自由度多）。

## 实现建议

- **实现难度**：⚠️ 高。需要：Shakhov 方程求解器（可复用 DUGKS）、序参量场（相场）演化、锐界面-弥散界面映射、Strang 分裂与保正性投影、以及表面能量模型。
- **预期性能**：
  - 空间：界面厚度 $\epsilon$ 控制精度/成本权衡；越薄越准但需更细网格；
  - 时间：显式分裂，$\Delta t$ 受输运子步限制；
  - 物理：正确性由匹配渐近保证，$\epsilon$ 足够小时可与 DSMC 对齐。
- **适用场景**：
  - ✅ 微纳器件中气体-结构耦合（薄膜沉积、催化剂表面反应）
  - ✅ 含吸收/反应的移动边界（等离子体刻蚀、烧蚀、蒸发）
  - ✅ 稀薄 + 复杂几何，需要避免显式界面追踪的场景
  - ❌ 不适合宏观稠密流动（连续介质方法更高效）
- **落地建议**：若已有 DUGKS 代码库，这篇的增量主要是"序参量加权 + 局部化通量算子"两块，改造成本可控。建议**先用平面壁 + 已知解析滑移**做单元测试，再上复杂几何。
