## 核心贡献

> 对**平底 + 自由表面**的两层流体系统，给出**全部物理非平凡共轭流（conjugate flows）的完整显式参数化**——仅用有理函数，且物理参数区域是一个由**单一符号条件** $(x+y-2)(y-1)<0$ 切出的**多边形域**；同时在共轭流层面就**排除单调内波（monotone bore）的存在性**。

1. **完整且显式的参数化**：用两个下游/上游速度比 $(x,y)$ 作为独立变量，$(B,R,D,H,F^2)$ 全部是 $(x,y)$ 的**有理函数**——这是本文最核心的技术突破。文献中此前（Dias & Il'ichev 2001, Appendix A）对同类问题的描述**主要靠数值获得**。
2. **物理参数区域的惊人简洁**：$\hat\Omega=\{(x,y)\in\mathbb{R}_+^2:(x+y-2)(y-1)<0\}$，恰有**两个连通分支**，被单点 $(1,1)$ 隔开（重参数化后该点展开为**一维临界平凡共轭流族** $\Gamma_{D=1}$）。
3. **在共轭流层面排除单调波**：证明所有非平凡共轭流满足 $(D-1)(B-H)<0$，即**自由面与内部界面（温跃层）的位移方向永远相反**。这与 Chen–Walsh–Wheeler 的已知结论一致，但**本篇在更早的层次上就已排除**，且严格性更强。
4. **严格单调性**：以 $(t,R)$ 为参数时，$D,H,B,F^2,y^2F^2,y$ 严格**递减**，$x,x^2F^2$ 严格**递增** → $\Omega_*$ 与 $(H,R)\in(0,1)^2$ 一一对应（证明了 Dias & Il'ichev 的一个猜想，但该对应**非显式**，需解七次方程）。
5. **锐界（sharp bounds）**：给出所有流动量的 $R$-无关锐界，例如 $\Omega_{D>1}$ 上 $D<3/2$、$4/9<H,B<1$、$F^2<1$。

## 技术方案

### 核心思想

**共轭流分析**（Benjamin 1966/1971）：两个均匀状态若能被一个**无耗散内波（dissipationless bore）**连接，则必须同时满足质量、动量（通过 flow force）和能量守恒。反过来，共轭流也是大振幅孤立波**展宽（broadening / table-top）极限**的约束。

本文研究**自由面下的两层系统**（脱离刚性盖假设），因为刚性盖无法刻画内波与表面波的耦合（如潮汐内波）。

**核心代数机制**（作者自承「运气不错」）：五方程七变量系统中存在**两段互补的线性结构**——
1. 以 $x,y$ 为未知量时，前三个方程对 $(D,H,F^2)$ 是**线性的**，可解出有理函数（唯一退化情形 $x=1$ 只产生平凡解）；
2. 剩下两个方程对密度比 $R$ 是**线性的** → 只需**一次关于 $R$ 的结式（resultant）**即可闭合消元。
3. 该结式**关于 $B$ 完全分解**为四个因子，其中三个或强制平凡解、或符号固定，**仅存一个因子**给出显式解。

### 关键技术

| 技术 | 说明 |
|------|------|
| 变量选择 | $H\coloneqq H_1$（下层高度比）、$B\coloneqq\bar H_1$、$x\coloneqq \bar F_2/F$、$y\coloneqq \bar F_1/F$（下游/上游 Froude 数比）；无量纲化用 $R=\rho_2/\rho_1$、$D=(\bar h_1+\bar h_2)/(h_1+h_2)$ |
| 消元策略 | 线性子系 → 有理函数；再对 $R$ 取结式 → 关于 $B$ 的完全分解 → 排除平凡因子 → 显式解出 $B,R,D,H,F^2$ |
| 符号判别 | 引入 $\hat s(x,y)=m(x)y+n(x)$（$m(x)=x^2+2x-1$、$n(x)=x^3-x^2-x-1$）与 $\hat w(x,y)=2xy^2-2(x+1)y-n(x)$；物理区域条件化简为单一不等式 |
| 重参数化 I | 过 $(1,1)$ 点的直线束：$x=1+X$、$y=1-tX$（$t$ 为斜率），使奇点展开为线段 $\tilde\Gamma_{D=1}=(1,0)\times\{0\}$，参数化**光滑延拓到边界** |
| 重参数化 II | 用 $R$ 替换 $X$：$X=\breve X(t,R)$，仍保持有理性，且**关于 $t$ 严格单调** |
| 特殊族识别 | 计算 $\partial_y\hat\Phi$、$\partial_y\hat D$ 发现 $x=3$ 处单调性反转 → $x=3$ 上 $\hat D=3/7$、$\hat\Phi=1/7$ 恒定；用结式法证明这是**唯一**的「两个及以上变量恒定」的族 |
| 平凡解引理 | 若 $x=y$、$x=1$、$y=1$、$D=1$、$H=B$ 中任一成立，则必为平凡解（$x=y=1,D=1,H=B,F^2>0$） |

## 公式

### 1. 无量纲化

```math
H_j=\frac{h_j}{h_1+h_2},\quad \bar H_j=\frac{\bar h_j}{h_1+h_2},\quad
\bar F_j^2=\frac{\bar c_j^2}{g(h_1+h_2)},\quad
R=\frac{\rho_2}{\rho_1},\quad F^2=\frac{c^2}{g(h_1+h_2)},\quad D=\frac{\bar h_1+\bar h_2}{h_1+h_2}
```

其中 $H_1+H_2=1$、$\bar H_1+\bar H_2=D$、$0<R<1$。

### 2. 非线性共轭流系统（五个方程）

```math
\begin{cases}
H = y B & \text{(下层质量守恒)}\\
1-H = x(D-B) & \text{(上层质量守恒)}\\
\tfrac12 F^2+1 = \tfrac12 x^2F^2+D & \text{(自由面 Bernoulli)}\\
\tfrac12 F^2+H+R(1-H) = \tfrac12 y^2F^2+B+R(D-B) & \text{(界面压力连续)}\\
F^2(H+R(1-H))+\tfrac12\bigl(H^2+R(1-H^2)\bigr) = F^2\bigl(y^2B+x^2R(D-B)\bigr)+\tfrac12\bigl(B^2+R(D^2-B^2)\bigr) & \text{(动量守恒)}
\end{cases}
```

### 3. 显式有理参数化（核心结果）

```math
\hat B(x,y)=\frac{(x-1)^2(y+1)}{(x-y)\hat s(x,y)},\qquad
\hat R(x,y)=\frac{(y-1)^3(y+1)}{(x-1)\hat w(x,y)}
```

```math
\hat D(x,y)=\frac{2xy+x^2-3}{\hat s(x,y)},\qquad
\hat H(x,y)=\frac{(x-1)^2(y+1)y}{(x-y)\hat s(x,y)},\qquad
\hat\Phi(x,y)=F^2=\frac{2(x+y-2)}{\hat s(x,y)}
```

其中

```math
\hat s(x,y)=m(x)y+n(x),\quad m(x)=x^2+2x-1,\quad n(x)=x^3-x^2-x-1,\quad
\hat w(x,y)=2xy^2-2(x+1)y-n(x)
```

### 4. 结式分解

```math
a_1b_0-b_1a_0=(x-1)^2(y-1)\bigl[B(x-y)-(x-1)\bigr](1-By)\bigl[B(x-y)\hat s(x,y)-(x-1)^2(y+1)\bigr]
```

### 5. 物理参数区域

```math
\hat\Omega=\{(x,y)\in\mathbb{R}_+^2:(x+y-2)(y-1)<0\}
=\hat\Omega_{D>1}\cup\hat\Omega_{D<1},\qquad
\hat\Omega_{D\gtrless1}=\{(x,y)\in\mathbb{R}_+^2:2-x\gtrless y\lessgtr 1\lessgtr x\}
```

辅助恒等式（用于化简）：

```math
\hat w=(x+y-2)\bigl[(x+y+2)(y-1)-(x^2-1)\bigr]-(y+1)(y-1)^2
```

```math
\hat s=(1+x+x^2+y)(x+y-2)-(y^2-1),\quad
x-y=(x+y-2)-2(y-1),\quad x-1=(x+y-2)-(y-1)
```

### 6. $(t,R)$ 重参数化（严格单调）

```math
t=\frac{1-y}{x-1},\qquad
X=\breve X(t,R)=\frac{2t^3-2R\bigl(1+t(1-t)\bigr)}{t^4-R(2t^2-1)}
```

```math
\Pi_{\ell,0.2}(Re_\tau)\text{ 型边界函数（此处为共轭流对应的 }R\text{ 边界）:}\quad
R_{H=0}(t)=\frac{t^4}{1+2t(1-t^2)},\quad
R_{D=1}(t)=\frac{t^3}{1+(1-t)t},\quad
R_{H=1}(t)=\frac{t^3(2+t)}{1+2t},\quad
R_{D=3/7}(t)=\frac{t^3}{2+3t}
```

```math
R_{H=0}(t)<R_{D=1}(t)<R_{H=1}(t)<t^2\qquad (0<t<1)
```

```math
\breve X(t,R)=\frac{2t^3-2R(1+t(1-t))}{t^4-R(2t^2-1)},\qquad
t^4-R(2t^2-1)=(t^2-R)^2+R(1-R)>0
```

### 7. 单调性（核心推论）

```math
\partial_t\breve D,\ \partial_t\breve H,\ \partial_t\breve B,\ \partial_t\breve\Phi,\ \partial_t(\breve y^2\breve\Phi),\ \partial_t\breve y < 0
```

```math
\partial_t(\breve x^2\breve\Phi),\ \partial_t\breve x > 0
```

### 8. 锐界

```math
\text{on }\hat\Omega_{D>1}:\quad
1<D<\tfrac32,\quad \tfrac49<H,B<1,\quad 0<F^2<1,\quad
0<\bar F_1^2<\tfrac14(11\sqrt{33}-59),\quad 0<\bar F_2^2<\tfrac12,\quad 0<x<1,\ 1<y<2,\ 0<R<1
```

```math
\text{on }\hat\Omega_{D<1}:\quad
0<D<1,\quad 0<H,B<\tfrac12,\quad 0<F^2<\tfrac12,\quad 0<\bar F_1^2<\tfrac12,\quad 0<\bar F_2^2<2,\quad 1<x<\infty,\ 0<y<1
```

### 9. 临界平凡共轭流族（$t,0$ 上）

```math
\tilde D=1,\quad \tilde H=\tilde B=\frac{1}{(2-t)(1+t)},\quad
\tilde R=\frac{t^3}{1+t(1-t)},\quad \tilde\Phi=\frac{1-t}{2-t},\quad \tilde x=\tilde y=1
```

## 实验结论

本篇是**纯解析论文**，无数值实验，可"验证"的是以下结构性结论：

| 论断 | 内容 |
|---|---|
| **完整性** | $\Omega$ 是显式有理映射 $(x,y)\mapsto(B,R,D,H,F^2)$ 在 $\hat\Omega$ 上的图像；除平凡解外**没有其他物理非平凡共轭流** |
| **连通性** | $\hat\Omega$ 恰有两个连通分支 $\hat\Omega_{D>1}$、$\hat\Omega_{D<1}$，被单点 $(1,1)$ 分隔（重参数化后为 $\Gamma_{D=1}$ 一维族） |
| **方向二分** | $\hat\Omega_{D>1}$ 上 $D>1$ 且 $B<H$；$\hat\Omega_{D<1}$ 上 $D<1$ 且 $B>H$。**统一地**：$(D-1)(B-H)<0$ → 自由面与温跃层位移方向永远相反 |
| **单调波排除** | 因 $(D-1)(B-H)<0$ 恒成立，**单调内波（共轭流层面的）不存在**。与 Chen–Walsh–Wheeler (2016) 和 Sinambela (2021) 的结论一致，但本篇在更早层次即已排除 |
| **与展宽现象的吻合** | Woolfrenden 等 (2011) 观察到展宽只在「**反相（out-of-phase）**」孤立波中出现；本篇的 $(D-1)(B-H)<0$ 正是「反相」的共轭流层面表述 |
| **特殊族唯一性** | $(D,F^2,x)=(3/7,\,1/7,\,3)$ 是 $\Omega$ 上**唯一**能让两个及以上变量保持常数的族；沿 $x=3$ 有 $\hat D=3/7$、$\hat H=2y/[7(3-y)]$、$\hat B=2/[7(3-y)]$、$\hat R=(1-y)^3/[4(7-3y)]$、$\hat\Phi=1/7$ |
| **与 Dias–Il'ichev 猜想** | $\Omega_*$ 与 $(H,R)\in(0,1)^2$ 一一对应且关于 $H$ 单调 → 证明了 Dias & Il'ichev (2001) 的一个猜想，但该对应**需解七次方程**，非显式 |
| **物理一致性** | 上游 Froude 数 $F$ 的锐界与共轭流的经典行为一致（如 $\Omega_{D>1}$ 上 $\bar F_1^2$ 上界**略大于** 1） |

## 局限性

1. **只是必要条件，不是存在性**：共轭流是内波存在的**必要**条件。本文的完整参数化**不提供任何 heteroclinic 轨道**（连接共轭状态的实际内波解）。作者明确指出这是「迈向该目标的重要垫脚石」，而非终点。
2. **刚性/分层简化的边界**：假设两层不可压、密度不同、均匀来流、平底；不含连续分层（Benjamin 的原始框架覆盖连续分层）、旋转或可压缩效应。
3. **七次方程的不可显式性**：$(H,R)$ 参数化虽有一一对应性与单调性，但求解需解**七次方程**——实用价值受限。$(x,y)$ 参数化是显式的，但奇点在 $(1,1)$。
4. **二维性**：所有结论限于**一维**（水平）无耗散内波，未涉及二维几何或侧向不均匀性。
5. **「conjugate flow」术语歧义**：文献中该词有时也指更广义的**耗散型**情形，本篇仅指能量守恒情形。
6. **数值描述已有替代**：Dias & Il'ichev (2001) 曾用数值给出描述，本篇的价值在于**显式性与完整性**，而非新现象。

## 实现建议

- **实现难度**：低（全部为闭式有理函数，无需数值求解器）；若要走 $(t,R)$ 单调参数化则需解七次方程，难度中等。
- **预期性能**：给定 $(x,y)\in\hat\Omega$，**一次闭式求值**即可得到 $(B,R,D,H,F^2)$；显式、无迭代、无奇异性（除 $(1,1)$）。这是论文的主要实用价值。
- **适用场景**：
  1. **内波/潮汐涌浪的可行性预判**：给定上下游状态，先判断是否属于共轭流集合，再判断属于哪个分支（$D>1$ 或 $D<1$），从而判断「自由面与温跃层同向抬升」的构型是否物理允许——这是设计观测/实验方案时的第一道筛子。
  2. **孤立波展宽极限的分析**：研究大振幅内孤立波的 table-top 极限时，共轭流给出两端状态的必要约束。
  3. **数值求解器的初值/边界生成**：为内波追赶求解器构造满足守恒律的上下游状态。
  4. **作为教科书级的代数消元案例**：线性结构 + 一次结式 + 完全因式分解的模式可迁移到其他多相流守恒系统的共轭流分析。
- **落地建议**：
  1. **实务上优先用 $(x,y)$ 参数化**（显式），只有在需要单调性保证（如证明解族的唯一性、或做一维参数扫描）时才转向 $(t,R)$。
  2. **务必检查 $(x,y)$ 是否落在 $\hat\Omega$ 内**：物理条件 $(x+y-2)(y-1)<0$ 极简，但 $\hat s,\hat w$ 在某些位置为零会导致 $\hat B,\hat R,\hat D,\hat H,\hat\Phi$ 发散——需显式排除 $\hat s=0$、$\hat w=0$、$x=y$、$x=1$、$y=1$、$x+y=2$。
  3. **注意「平凡解」陷阱**：$x=y$、$x=1$、$y=1$、$D=1$、$H=B$ 任一成立即为平凡解（上下游完全相同），此时结式的其他因子会给出虚假根——必须显式排除。
  4. **特殊族 $x=3$ 值得单独检查**：它是唯一使 $D$ 与 $F^2$ 同时恒定的族（$D=3/7$、$F^2=1/7$），可作为数值实现的**单元测试基准点**。
  5. **本篇与本库关联**：可与 [[Conjugate-Flow-Stratified-Bore]] 类笔记对照；也与本库中关于内波/水跃的条目形成「必要条件 → 数值求解」的完整链条。

## 推荐结论

> **✅推荐实现**（作为解析工具与可行性判据），但**不可**据此断言内波存在。
>
> - 支持：完整、显式、纯有理函数；物理区域为一个极简符号条件；给出严格单调性与锐界；数学结构干净、可直接编码为验证模块。
> - 关键保留：共轭流只是**必要条件**；本篇不构造任何 heteroclinic 轨道。要判定某个上下游状态对是否真能由无耗散内波连接，仍需后续的存在性理论或数值追踪。
> - 附加价值：$(D-1)(B-H)<0$ 这一结论在共轭流层面就排除了单调内波，比 Chen–Walsh–Wheeler 的原结论更强，可作为「反相孤立波才展宽」的定量依据。
