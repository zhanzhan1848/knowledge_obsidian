## 核心贡献

> 系统评估 **XPINN（Extended PINN）** 在激波主导 Burgers 方程中的**域分解设计、overlap 宽度、局部网络容量**对解精度的影响，给出可操作的分解设计准则

1. **背景**：PINN 在**激波主导**问题（sharp gradients）上表现不佳；XPINN 通过**域分解**缓解，但分解策略的影响未充分表征
2. **研究对象**：1D 粘性 Burgers 方程 \(\nu = 0.01/\pi\)
3. **方法对比**：
   - 标准 PINN
   - 常规 XPINN
   - **激波聚焦 XPINN**（含激波子域内**网络容量增大**）
   - **重叠 XPINN**（多种 overlap 宽度）
4. **训练协议**（统一）：
   - Adam 优化
   - L-BFGS 精修
   - 10 轮 **RAR (Residual-based Adaptive Refinement)**
5. **评估指标**：
   - 全域 / 激波区 \(L_2\) 和 \(L_\infty\) 误差
   - 最大 PDE residual
   - 界面连续性误差

### 关键结论

| 策略 | 效果 |
|------|------|
| 标准 XPINN | 中等改善 |
| 激波聚焦 XPINN（容量 ↑） | **最低总体误差** |
| 重叠 XPINN | **最小 overlap 最佳**，大 overlap 退化 |
| RAR 早期 | 精度**单调提升** |
| RAR 后期 | 精度**非单调变化** |

**核心 insight**：**局部网络容量增加比 overlap 增大更有效**

## 技术方案

### 核心思想

把 PDE 求解器中传统的**激波捕捉**（shock capturing）与神经网络中的**域分解 + 容量分配**统一：在激波区域用更大网络（更多神经元 / 更高阶激活），在光滑区域用普通网络。

### 关键技术

| 技术 | 说明 |
|------|------|
| Physics-Informed Neural Networks (PINN) | 物理信息神经网络，PDE residual 作为 loss |
| Extended PINN (XPINN) | 多子域分解，每子域独立网络 |
| Domain decomposition | 空间域分成多个子域 |
| Overlap coupling | 子域之间重叠区，连续性约束 |
| Residual-based Adaptive Refinement (RAR) | PDE residual 大的点加密采样 |
| Adam + L-BFGS | 训练优化器组合 |
| Shock-focus XPINN | 激波区网络容量（神经元数）增大 |

### 控制方程（1D Burgers）

```math
\frac{\partial u}{\partial t} + u \frac{\partial u}{\partial x} = \nu \frac{\partial^2 u}{\partial x^2}, \quad \nu = \frac{0.01}{\pi}
```

初始 / 边界条件：典型正弦波 + 周期性边界。

### XPINN 架构

```
[全域 D]
    ├── 子域 D_1 (光滑区) → 小网络 N_1
    ├── 子域 D_2 (过渡区) → 中网络 N_2
    └── 子域 D_3 (激波区) → 大网络 N_3

overlap: D_i ∩ D_{i+1} ≠ ∅
loss: PDE_residual + interface_continuity + boundary + initial
```

### 关键发现

- **激波聚焦 XPINN > 重叠 XPINN**：局部网络容量是**主导因素**
- **小 overlap 优于大 overlap**：减少参数耦合，提高训练稳定性
- **RAR 早期收益最大**：前 3-5 轮 RAR 显著提升，后期震荡

## 实验 / 验证

- **方法**：数值实验（多个 XPINN 配置对比）
- **样本**：1D Burgers, \(\nu = 0.01/\pi\)
- **基线**：参考解（高精度有限体积 / WENO）
- **结果**：
  - 激波区误差、界面连续性、max PDE residual 全维度对比
  - 不同 overlap 宽度（窄 / 中 / 宽）的消融实验

---

## 局限性

- **1D 简化**：未涵盖 2D / 3D 复杂流场
- **单方程（Burgers）**：未涵盖完整 NSE / Euler
- **单 ν 值**：仅 \(\nu = 0.01/\pi\)，不同粘性 / 激波强度的稳健性未验证
- **网络架构固定**：未涵盖 transformer / 傅里叶特征等先进架构
- **训练成本**：未深入对比 GPU 时间 vs 精度 trade-off

## 笔记

**@墨鱼丸 实现建议**：本工作对 **CFD + ML 混合求解器** 有直接借鉴价值：
- 在传统 CFD 框架内嵌入 PINN / XPINN 子模块，可作为**激波区域修正器**
- 激波聚焦策略（局部容量增大）可移植到其他 shock-dominated PDE（Euler, MHD 等）
- 设计准则：
  - 优先**局部网络容量 ↑**，而不是 overlap 增大
  - 训练时用**RAR 早期 3-5 轮**，后期监控震荡
  - 重叠宽度选**最小可连接值**
- 与传统 CFD 耦合：XPINN 可作为 WENO / FV 求解器的**局部加密替代**
- 对 OpenFOAM 集成：在敏感区域（激波、分离点）调用 XPINN 子模型

难度：高（需要 PINN 实现 + 域分解 + RAR）；价值：高（shock-dominated 问题的 ML 求解器设计）
