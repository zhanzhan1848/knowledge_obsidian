## 核心贡献

> 针对水-空气翅片管换热器（FTHE），把曲面矩形涡流发生器（RVG）的**四个几何参数**做成"共轭数值模型 + 响应面 + 遗传算法"的完整优化闭环，量化了"只最大化换热"与"换热-压降联合权衡"两种目标下的收益。

1. **共轭数值模型（conjugate model）**：以全尺寸换热器的一小段为计算域，水侧入口给定**充分发展速度与温度剖面**，完成网格/边界条件无关性验证后作为优化代理模型。
2. **四参数设计空间**：攻击角（attack angle）、曲率角（curvature angle）、流向轴向位置（axial position）、高度（height）——构成 RVG 的完整几何自由度。
3. **三类目标函数**：一个基于 **Colburn 因子 j**（纯换热最大化），两个联合 **Colburn 因子与摩擦因子 f**（换热 + 压降权衡），后者对应换热器**面积品质因子 (area goodness factor)** 与**体积品质因子 (volume goodness factor)**。
4. **响应面 + 遗传算法**：用**回归分析**与**中心复合试验设计 (CCD)** 得到非线性回归多项式并嵌入目标函数，再用**遗传算法 (GA)** 完成寻优。
5. **定量结论**：纯换热目标下 **Colburn 因子提升 53.1%**；折中目标下一组参数使**面积品质因子提升 14.4%**，另一组使**体积品质因子提升 26.5%**。

## 技术方案

### 核心思想

翅片管换热器中，圆柱尾流区是典型的低效换热死区（wake zone）：速度亏损、边界层再生受阻。**涡流发生器 (VG)** 通过在尾流中诱导二次流与横向掺混来强化对流换热，但代价是附加压降。

- **曲面矩形 RVG** 相比平板/直矩形 VG，在相同的下游长度内具有更优的二次流组织能力；其几何参数（攻击角、曲率角、轴向位置、高度）相互耦合——单独优化任一参数没有意义。
- 因此本文路线是：**共轭 CFD 代理模型 → 设计空间采样 → 响应面建模 → GA 寻优 → 与基准（光翅 FTHE）对比**。

这是一个典型的 **surrogate-assisted multi-objective optimization** 范式，在换热器强化传热领域应用广泛（强化管、翅片开孔、粗糙度、扭曲片等均属同一套路）。

### 关键技术

| 技术 | 说明 |
|------|------|
| **共轭传热 (conjugate heat transfer)** | 流体域 + 固体翅片/管壁域联合求解，含壁面导热与界面连续性条件；管壁导热系数来自经验关联式 |
| **局部代表性计算域** | 取全尺寸换热器的一小段（截面 + 有限流向长度），大幅降低网格量，同时保留充分发展剖面入口条件 |
| **充分发展入口剖面** | 水侧给定 fully developed velocity/temperature profiles，避免长直段计算，代价是结果依赖入口剖面与几何周期性假设 |
| **中心复合设计 (CCD)** | 中心点 + 轴向点 + 环形点，可估计二次项，用于拟合含交互作用的高阶响应面 |
| **回归响应面** | 拟合 j、f 的非线性多项式，替代高成本 CFD，降低优化迭代开销 |
| **遗传算法 (GA)** | 作用于归一化后的设计空间，处理多目标（如 Pareto 前沿或加权标量化） |
| **Colburn 因子 j / 摩擦因子 f** | 无量纲换热/摩擦性能指标，用于跨工况可比性评估 |
| **面积/体积品质因子** | 换热器工程经济性指标，把换热增益与占地面积/体积代价耦合，是本文"折中目标"的物理落点 |

## 公式

```math
\text{Colburn 因子:}\quad
j = \frac{Nu}{Re\,Pr^{1/3}}
= \frac{h\,L}{c_p\,U_\infty\,Pr^{1/3}}
```

```math
\text{摩擦因子（Fanning 型，基于特征速度）}:\quad
f = \frac{\Delta p\,D_h/2}{\tfrac{1}{2}\rho U_\infty^{2}\,L}
```

```math
\text{面积品质因子（示意形式）}:\quad
\eta_{\text{area}} \propto \frac{Q_{\text{transfer}}\ \text{(面积相关收益)}}{\text{附加占地/面积}}
```

```math
\text{体积品质因子（示意形式）}:\quad
\eta_{\text{vol}} \propto \frac{Q_{\text{transfer}}\ \text{(体积相关收益)}}{\text{附加体积}}
```

```math
\text{响应面（CCD 拟合，形式为二次多项式 + 交互项）}:\quad
j(\theta) = \beta_0 + \sum_k \beta_k \theta_k + \sum_{k<l}\beta_{kl}\theta_k\theta_l + \sum_k \beta_{kk}\theta_k^2
```

> 注：以上为方法层面的本质形式；原文给出的具体回归系数、目标函数权重与无量纲化方式需参照正文，摘要中未披露具体数值。

## 代码片段

```python
# 概念性伪代码：代理模型驱动的 RVG 几何优化
# 1) 定义四个设计变量及其物理范围
params = {
    "attack_angle_deg":      (0, 60),
    "curvature_angle_deg":   (0, 90),
    "axial_position_m":      (0, L_max),
    "height_mm":             (0, h_max),
}

# 2) CCD 采样 + 共轭 CFD 评估（代理模型生成）
for run in ccd_design(params, n_center=..., n_axial=..., n_ring=...):
    geom = build_rvg(**run)                     # 曲面矩形涡流发生器几何
    case = build_conjugate_fthe(geom)           # 局部代表性计算域 + 共轭网格
    case.set_inlet(fully_developed_profiles)    # 水侧充分发展速度/温度剖面
    case.run(turbulence_model="k-omega SST", y_plus_target=30)
    j, dp = case.colburn_factor(), case.pressure_drop()
    record(run, j, dp)

# 3) 回归响应面
resp_j = fit_polynomial(design_points, targets_j, degree=2)   # 含交互项
resp_f = fit_polynomial(design_points, targets_f, degree=2)

# 4) 目标函数（三种）
obj_pure_heat = lambda x: -resp_j(x)                                  # 仅最大化 j
obj_area      = lambda x: -(resp_j(x) / area_penalty(x))               # 面积品质因子
obj_volume    = lambda x: -(resp_j(x) / volume_penalty(x))             # 体积品质因子

# 5) 遗传算法寻优
best_pure = genetic_algorithm(obj_pure_heat, params)
best_area = genetic_algorithm(obj_area,      params)
best_vol  = genetic_algorithm(obj_volume,    params)

# 6) 与基准对比
baseline = evaluate(plain_fins_reference_case)   # 无 VG 的光翅 FTHE
print(compare(best_pure.j, best_area.eta, best_vol.eta, baseline))
```

## 实验结论

- **数据集/算例**：水-空气翅片管换热器（FTHE）的共轭数值算例；取全尺寸换热器的一段为计算域，水侧入口给定充分发展速度与温度剖面；优化后配置与**光翅基准 FTHE** 对比。
- **基线**：无涡流发生器的光翅翅片管换热器（plain fins）。
- **结果**：
  - **仅最大化换热**（j）的最优 RVG 配置：Colburn 因子 **提升 53.1%**。
  - **换热 + 压降联合目标**：一组最优参数使 FTHE **面积品质因子提升 14.4%**。
  - 另一组最优参数使 **体积品质因子提升 26.5%**。
  - 说明纯换热最优解与经济性最优解**并不重合**，压降惩罚会显著改变最优几何。

## 局限性

- **计算域代表性**：只取换热器的一小段并强制充分发展入口剖面，忽略了整体换热器内的三维流动发展、二次流沿程衰减与入口/出口效应；结论对"下游可用长度"较敏感。
- **代理模型精度受 CCD 采样点数限制**：二次多项式在强非线性区（高攻击角、大曲率角）外推可靠性下降；GA 若跑出设计域会产生无物理意义的极值。
- **目标函数的物理简化**：j 因子基于某一特征速度与定性对流换热区定义，忽略了轴向导热、物性随温度变化、翅片效率下降等实际因素。
- **湍流模型依赖**：共轭 CFD 的精度受 RANS 模型与近壁网格 ($y^+$) 制约；对尾流掺混机理本身的分辨有限。
- **单工况优化**：优化在给定 Re/Pr/风速下进行，参数最优性随工况漂移，稳健性（多工况鲁棒优化）未涉及。
- **几何可行性约束弱**：攻击角、曲率角、高度的组合可能出现加工不可行或自相交，摘要未说明是否施加制造约束。

## 实现建议

- **实现难度**：🟡 中。核心工作是搭一套可信的共轭传热算例（网格、$y^+$ 控制、网格无关性、湍流模型选择），后续 CCD/回归/GA 部分是标准工具链。
- **预期性能**：单次共轭算例成本远低于全尺寸模型（局部代表性域），使"优化—再算"的迭代闭环可行；GA 每代评估只需查响应面多项式，单次评估近零成本，瓶颈全部落在响应面生成所需的 CFD 采样上。
- **适用场景**：翅片管/翅片板式换热器的几何强化设计；水-空气两相换热、霜层/冷凝敏感场合（压降与结霜敏感性使折中目标更重要）。
- **落地建议**：先做**网格与模型无关性**（至少 3 套网格 + 2 种湍流模型交叉验证）再信任 j/f 响应面；优化完成后必须用**全尺寸或更长计算域**复算最优配置，检验局部域结论的可迁移性；工程上建议同时给出 Pareto 前沿而非单点，以便权衡占地与风机能耗。

## 数值实现补充（2026-10-31 深挖 arXiv PDF 全文）

### 求解器与离散格式
- **求解器**：**ANSYS Fluent**
- **压力–速度耦合**：**SIMPLE**
- **空间离散**：扩散项**二阶中心**；对流项**二阶上风格式**
- **湍流模型**：**SST $k$–$\omega$**（两方程）
- **稳态**；收敛判据（缩放残差）：连续性与动量 **< 1×10⁻⁶**；$k$ 与 $\omega$ **< 1×10⁻⁵**；能量 **< 1×10⁻⁹**

### 网格
- 结构化六面体（空气上/下游）+ 结构化与**非结构六面体混合**；多区域（block decomposition）网格；近壁加密
- **网格质量**：平均正交性 **0.99**，平均偏斜度 **0.037**
- **网格无关性研究**（4 套）：**0.74 M / 1.15 M / 1.62 M / 2.09 M** 控制体；1.62 M → 2.09 M 时 $T_{a,out}$ 与 $\Delta p_a$ 误差 **< 1%**
- **壁面分辨率**：平均 $y^+$ 从 **0.99 → 0.26**；最大 $y^+$ 从 **10.43 → 2.55**；所有网格平均 $y^+<1$
- **选定网格：1.62 百万控制体**

### 边界条件
- 空气入口 $T_{a,in}=295$ K，$w_{a,in}$ = 0.455 / 0.755 / 1.03 m/s；水入口 $T_{w,in}=313$ K，$w_{w,in}=0.76$ m/s
- **水侧入口剖面用 UDF 迭代生成充分发展速度与温度剖面** —— 先用均匀入口跑一次，把出口场回收为入口边界条件，温度按流路温降平移，重复直至充分发展
- 空气：上下游 $T=T_{a,in}$，$\partial T/\partial n=0$；水：抛物线剖面 $w_w(x,y)$，$\partial w_w/\partial n=0$
- 流–固界面：$T$ 与法向热流连续；壁面无滑移
