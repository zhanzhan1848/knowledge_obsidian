## 核心贡献

> **仅靠"惯性层级 + 刚性约束的几何非线性"**（不含不可压缩性、不含涡拉伸、不含速度空间场）就能复现湍流的全部奇异特征：**恒通量级联、统计局部性、时间不可逆性、间歇性、耗散异常（黏性趋零时耗散率饱和）、以及微观涨落的有限时间上尺度放大**。湍流因此成为**可在实验室中被"设计"的可测量现象**。

1. **最小模型**：平面刚性摆链，长度与质量按几何级数递减（$\ell_{k+1}=\ell_k/\gamma$，$m_{k+1}=m_k/\gamma$），**仅通过最近邻约束耦合**（无壳层局部耦合、无三元组耦合）。
2. **刚性约束产生非局部耦合**：虽然只约束最近邻，但惯量矩阵 $A_{kj}=M_{kj}\ell_k\ell_j\cos(\theta_j-\theta_k)$ 稠密 —— 每根杆承载其下所有小杆的惯量。约束张力因此**在尺度上非局部**，**类比不可压流中的压力**。
3. **精确能量通量**：$\Pi_k=\lambda_k\dot{\boldsymbol r}_k\cdot(\boldsymbol r_k-\boldsymbol r_{k-1})$，$\frac{de_k}{dt}=\Pi_k-\Pi_{k+1}$，边界 $\Pi_1=\Pi_{N+1}=0$。统计定常时 $\langle\Pi_k\rangle\simeq\epsilon$。
4. **精确耗散异常**：跨**十个数量级**的黏性范围内，平均耗散趋向有限平台 $\bar\epsilon\simeq0.34$。因为 $\epsilon=\eta\langle\omega^TD\omega\rangle$，有限极限要求 $\langle\omega^TD\omega\rangle\sim\eta^{-1}$ —— **小杆之间的相对转动必须越发暴力**。
5. **隐藏尺度对称性**：普通自相似性被间歇性破坏，但经**非线性归一化** $C_k=(\sum_{j<k}\omega_j^2)^{1/2}$ 与内在时钟重标定后，$\pi_k=\Pi_k/(m_k\ell_k^2C_k^3)$ 与 $\sigma_k=C_{k+1}/C_k$ 的分布在惯性区**塌缩**（用 Jensen-Shannon 散度量化）。
6. **统计局部但动力学非局部**：$\Pi_k=\sum_{j\ge k}Q_{k,j}$；无符号贡献 $|\langle|Q_{k,k+n}|\rangle|$ 依然很大，但**净贡献** $|\langle Q_{k,k+n}\rangle|\propto 2^{-n}$ 几乎精确抵消。
7. **时间不可逆性自发选择**：即使唯一显式不可逆项（黏性项）系数趋零，归一化通量偏差 $\chi_k=\langle\Pi_k\rangle/\langle|\Pi_k|\rangle$ 仍趋于非零的惯性区轮廓 —— **级联自身选择了时间箭头**。
8. **涨落的逆向放大**：热噪声从小尺度先达到热平衡（$\langle|\omega_k|^2\rangle_{\rm th}\sim\ell_k^{-3}$），再**向上尺度传播**（与能量级联方向相反），约 $0.3\tau_0$ 即可从小尺度传播到最大尺度。

## 技术方案

### 核心思想

**问题**：湍流的哪些特征是"本质"的？流体中不可压缩性、涡拉伸、空间速度场与湍流的奇异特征**总是同时出现**，难以分辨因果。

**本文策略**：把流体完全换成**最简力学系统**，只保留三个要素：

1. **惯性层级**（提供分离的空间与时间尺度）
2. **跨层级的非线性耦合**（在此仅由刚性约束的几何非线性提供）
3. **注入与耗散的分离**（大尺度注入，小尺度耗散）

若这三者足以复现全部奇异特征，则不可压缩性、涡拉伸等**不是必需的**。

### 关键技术

| 技术 | 说明 |
|------|------|
| 约束 Lagrange 形式 | $L=\frac12\sum m_k|\dot{\boldsymbol r}_k|^2+\sum\lambda_k(|\boldsymbol r_k-\boldsymbol r_{k-1}|^2-\ell_k^2)$ |
| 自动参数化 | $\boldsymbol r_k=\boldsymbol r_0+\sum_{j\le k}\ell_j(\sin\theta_j,-\cos\theta_j)$ → 纯动能 Lagrange 量 $L=\frac12\boldsymbol\omega\cdot A(\boldsymbol\theta)\boldsymbol\omega$ |
| 耗散算子 | $\boldsymbol\omega^{\rm T}D\boldsymbol\omega=\sum_{k=2}^N(\omega_k-\omega_{k-1})^2/\ell_k$；$D_1=0$（均匀刚体转动不耗散）|
| 恒功率强迫 | $\boldsymbol\tau=\epsilon_0(\omega_1-\omega_2)/\sqrt{(\omega_1-\omega_2)^2+\omega_r^2}$ |
| 时间反演对称强迫 | $\boldsymbol\tau=a_f\cos(\omega_ft)(\boldsymbol e_1-\boldsymbol e_2)$，$a_f=0.1$，$\omega_f=0.01$ |
| 涨落-耗散平衡 | $A\,d\boldsymbol\omega=[\boldsymbol b-\eta D\boldsymbol\omega+\boldsymbol\tau]dt+\sqrt{2\eta\Theta}G^{\rm T}d\boldsymbol W$，$\langle d\boldsymbol\Gamma d\boldsymbol\Gamma^{\rm T}\rangle=2\eta\Theta D\,dt$ |
| 两层集合法 | 双层 ensemble 传播微观涨落的上尺度放大 |

## 公式

```math
% ===== 几何层级 =====
\ell_{k+1}=\frac{\ell_k}{\gamma},\qquad m_{k+1}=\frac{m_k}{\gamma},
\qquad \text{基本模型: }\gamma=2,\ m_1=1,\ \ell_1=2,\ N=20

% ===== 约束 Lagrange 量 =====
L=\frac12\sum_{k=1}^N m_k|\dot{\boldsymbol r}_k|^2+\sum_{k=1}^N\lambda_k\big(|\boldsymbol r_k-\boldsymbol r_{k-1}|^2-\ell_k^2\big)

% ===== 惯量矩阵（稠密 → 非局部耦合）=====
A_{kj}=M_{kj}\ell_k\ell_j\cos(\theta_j-\theta_k),\qquad M_{kj}=\sum_{i\ge\max(k,j)}m_i

% ===== 运动方程 =====
\dot{\boldsymbol\theta}=\boldsymbol\omega,\qquad
\dot{\boldsymbol\omega}=A(\boldsymbol\theta)^{-1}\big[\boldsymbol b(\boldsymbol\theta,\boldsymbol\omega)+\boldsymbol\tau-\eta D\boldsymbol\omega\big]
b_k=\sum_j M_{kj}\ell_k\ell_j\sin(\theta_j-\theta_k)\omega_j^2

% ===== 耗散算子 =====
\boldsymbol\omega^{\rm T}D\boldsymbol\omega=\sum_{k=2}^N\frac{(\omega_k-\omega_{k-1})^2}{\ell_k}

% ===== 精确能量通量（级联核）=====
e_k=\frac{m_k}{2}|\dot{\boldsymbol r}_k|^2,\qquad
\frac{de_k}{dt}=\Pi_k-\Pi_{k+1},\qquad
\Pi_k=\lambda_k\dot{\boldsymbol r}_k\cdot(\boldsymbol r_k-\boldsymbol r_{k-1})
\Pi_1=\Pi_{N+1}=0

% ===== 临界层级标度 =====
u_k=\ell_k|\omega_k|\sim\ell_k^0,\quad |\omega_k|\sim\ell_k^{-1},\quad e_k\sim\ell_k,\quad \tau_k\propto\ell_k
\ell_\eta\propto\eta^{1/3}

% ===== 间歇性与精细相似性 =====
\langle|\omega_k|^p\rangle\propto\ell_k^{-\zeta_p},\qquad
\langle|\Pi_k|^{p/3}\rangle\propto\ell_k^{-\tau_p/3},
\qquad \frac{\tau_p}{3}=\zeta_p-p
\zeta_p=p\ (\text{自相似}),\quad \zeta_p-p\ (\text{反常修正})

% ===== 隐藏尺度对称性（非线性归一化）=====
C_k=\Big(\sum_{j<k}\omega_j^2\Big)^{1/2},\qquad
\pi_k=\frac{\Pi_k}{m_k\ell_k^2C_k^3},\qquad \sigma_k=\frac{C_{k+1}}{C_k}

% ===== 耗散异常 =====
\lim_{\eta\to 0}\bar\epsilon(\eta)=\epsilon_*>0,\qquad \bar\epsilon\simeq0.34,
\qquad \epsilon=\eta\langle\omega^TD\omega\rangle\Rightarrow\langle\omega^TD\omega\rangle\sim\eta^{-1}

% ===== 涨落-耗散平衡（热噪声）=====
A\,d\boldsymbol\omega=\big[\boldsymbol b-\eta D\boldsymbol\omega+\boldsymbol\tau\big]dt+\sqrt{2\eta\Theta}\,G^{\rm T}d\boldsymbol W
\langle d\boldsymbol\Gamma\,d\boldsymbol\Gamma^{\rm T}\rangle=2\eta\Theta D\,dt
\langle|\omega_k|^2\rangle_{\rm th}\sim\ell_k^{-3},\qquad
\langle|\omega_k|^2\rangle_{\rm turb}\sim\ell_k^{-2}

% ===== 统计局部性 =====
\Pi_k=\sum_{j\ge k}Q_{k,j},\qquad Q_{k,j}=m_j\ddot{\boldsymbol r}_j\cdot\dot{\boldsymbol r}_k
|\langle Q_{k,k+n}\rangle|\propto 2^{-n}

% ===== 时间不可逆性 =====
\chi_k=\frac{\langle\Pi_k\rangle}{\langle|\Pi_k|\rangle}\to \chi_*\neq 0\ (\eta\to 0)

% ===== 可调层级指数 =====
m_k\propto\ell_k^\alpha \Rightarrow u_k\sim\ell_k^{h_c},\qquad h_c=\frac{1-\alpha}{3}
\quad(\alpha=0\Rightarrow h_c=1/3;\ \text{基本模型 }\alpha=1\Rightarrow h_c=0)
```

## 代码片段

```python
import numpy as np

def build_inertia_matrix(theta, ell, m):
    """A_{kj} = M_{kj} l_k l_j cos(theta_j - theta_k)，稠密 → 非局部耦合"""
    N = len(ell)
    M = np.zeros((N, N))
    for k in range(N):
        M[k, k:] = m[k:].sum()      # M_{kj} = sum_{i>=max(k,j)} m_i
    return M * np.outer(ell, ell) * np.cos(theta[None, :] - theta[:, None])

def derivative_dissipation_matrix(N):
    """D: 对称半正定三对角；D_1 = 0（均匀刚体转动不耗散）"""
    D = np.zeros((N, N))
    for k in range(1, N):
        D[k, k]     += 1.0 / ell[k]
        D[k-1, k-1] += 1.0 / ell[k]
        D[k, k-1]   -= 1.0 / ell[k]
        D[k-1, k]   -= 1.0 / ell[k]
    return D

def step(theta, omega, ell, m, A, D, eta, tau):
    b = np.einsum('kj,kj,j->k', A, np.sin(theta[None,:]-theta[:,None]), omega**2) * 0  # placeholder
    b = np.sum(A * np.sin(theta[None,:]-theta[:,None]) * np.outer(ell,ell) * omega**2, axis=1)
    omega_dot = np.linalg.solve(A, b + tau - eta * (D @ omega))
    return theta + omega*dt, omega + omega_dot*dt

def energy_flux(theta, omega, lam, r, ell):
    """Pi_k = lambda_k * rdot_k . (r_k - r_{k-1})；正号 = 由大尺度传向小尺度"""
    rdot = omega[:, None] * np.stack([np.cos(theta), -np.sin(theta)], axis=1)
    dr   = np.diff(r, axis=0)
    return lam[1:] * np.einsum('ij,ij->i', rdot[1:], dr)

def hidden_symmetry_norm(Pi, omega, ell, m):
    """pi_k = Pi_k / (m_k l_k^2 C_k^3)，C_k = sqrt(sum_{j<k} omega_j^2)"""
    C = np.sqrt(np.cumsum(omega**2))
    return Pi / (m[1:] * ell[1:]**2 * C[1:]**3), C[1:]/C[:-1]
```

## 实验结论

- **数据集/算例**：平面摆链，$N=20$，$\gamma=2$，$m_1=1$，$\ell_1=2$；恒功率强迫 + 时间反演对称周期强迫；黏性跨 10 个数量级扫描。
- **基线**：流体湍流的唯象学（Kolmogorov 标度、精细相似性、多重间歇性、耗散异常）。
- **结果**：
  - 级联**统计局部**（净跨尺度贡献 $\propto 2^{-n}$）但动力学**非局部**；
  - **时间不可逆**自发出现（$\chi_k$ 在 $\eta\to0$ 时趋于非零常值）；
  - **间歇性**：通量矩与速度矩给出**相同的反常修正**，且在 $p=3$ 附近几乎消失（符合定常通量要求），高阶增长；
  - **隐藏尺度对称性**：非线性归一化后分布塌缩（Jensen-Shannon 散度）；
  - **耗散异常**：$\bar\epsilon\to0.34$ 有限平台；
  - **涨落上尺度放大**：饱和前沿逐尺度推进，每级到达时间 ~ 局部 turnover 时间，$0.3\tau_0$ 足够从小尺度传到最大尺度；
  - 层级指数 $\alpha$ **可调**级联正则性：$h_c=(1-\alpha)/3$，$\alpha$ 越大级联越粗糙/奇异（**流体中不可调**）。

## 局限性

- **不是流体**：不可压缩性、涡拉伸、空间速度场**全部缺失**。本文论证的是"这些**不是必需的**"，但不是说"它们不重要"—— 它们塑造湍流的**具体唯象学**。
- 摆链是**确定性 Hamiltonian 系统 + 黏性 + 热噪声**，与流体（Navier-Stokes）的可控性/适定性不同。
- 代码与数据**尚未公开**（"will be made available upon publication"）。
- 耗散算子 $D$ 的具体形式（相邻杆相对转动阻尼）**人为选定**，并非从第一性原理导出。
- 交互式仿真仅在网页提供（https://andremfreitas.github.io/pendulum-web/），**无 Python/C 包**。
- 分支层级、时间层级、弹簧/重力耦合链、电机械实现等**均为提案**，未实现验证。

## 实现建议

- **实现难度**：✅ 较低。只需解约束多体动力学（$N=20$，ODE 积分，密集 $20\times20$ 线性求解）。CPU 秒级可跑。
- **预期性能**：
  - 单次轨迹：$N=20$，显式/隐式 RK 均可，步长受限 stiff 程度（$A$ 随层级缩小而放大）；
  - 统计量：需长时间平均（级联通量矩要求大样本）；
  - 黏性扫描（10 个数量级）需并行。
- **适用场景**：
  - ✅ **湍流现象的"最小可复现系统"** —— 教学、概念验证、检验自己的湍流理论
  - ✅ 耗散异常、间歇性、涨落放大等**普适现象的受控实验**
  - ✅ 探索"级联可调性"（$h_c$ 随 $\alpha$ 变化）—— **流体中不可调，这是独特价值**
  - ✅ 电机械实现 → 真正的实验室湍流模拟器
  - ❌ 不能替代真实流体 CFD
- **落地建议**：这是一篇**概念性突破**论文，实用价值在于**建立直觉与可证伪的最小模型**。对做 LES/DNS 的人：它提示"级联的**统计局部性**来自层级结构本身，而非流体的连续性"，这与 LES 的**局部尺度模型假设**直接相关 —— 可用于设计更有依据的亚格子模型。强烈建议复现（$N=20$ 的实现量很小）。
