## 核心贡献

> 为二维 **MHD-α 湍流模型**构造了**结构保持的有限元方法**：在长度尺度 α 上过滤输运速度的同时**保留原 MHD 方程的理想不变量**（能量换为 α-依赖能量），并用**增广拉格朗日预条件 + 单体几何多重网格**求解，对过滤宽度 α 与雷诺数均鲁棒。

1. **α-模型与结构保持的兼容**：MHD-α 模型在输运方程中用 $\bar{u}=u-\alpha^2\nabla\times\nabla\times u$ 过滤速度，但原始 MHD 的三个守恒量（能量、磁螺度、磁位平方平均）不再守恒。本文引入**α-依赖能量** $E_\alpha$，使离散系统重新满足耗散律。
2. **逐点精确守恒**：质量守恒与**磁高斯定律** $\nabla\cdot B=0$ 在离散层面**逐点**成立（非仅弱形式），这是低阶 FEM 求解 MHD 的关键难点。
3. **离散耗散律**：能量、交叉螺度、磁位平方平均的离散耗散律在理想极限（粘性→0）下退化为**精确守恒**。
4. **求解器鲁棒性**：增广拉格朗日预条件器 + 单体几何多重网格，对 α 宽度、雷诺数、小时间步长下的网格尺寸均鲁棒。
5. **最优收敛阶** + 与原 MHD 方程的**傅里叶伪谱 DNS** 在大尺度上一致。
6. **长时程模拟再现选择性衰减（selective decay）**：包括向 **Arnold 型界**的弛豫、以及磁位平方平均的**逆级联**。

## 技术方案

### 核心思想

MHD-α 模型的困难在于：**它破坏了 MHD 的 Hamiltonian 结构**，因此标准的能量-涡度拟守恒格式（energy-enstrophy conserving schemes）不再适用。

本文的路线是"**修改守恒量以适配模型**"：不去强求原始能量守恒，而是重新定义一个**与 α-过滤一致的守恒量族**，使得：
- 逐点守恒的是**质量**与**磁高斯定律**（不可约约束）；
- 耗散的是**正确的能量泛函** $E_\alpha$（而非原始 MHD 能量）；
- 理想极限下耗散律退化为守恒律。

这与"加人工耗散凑稳定性"的路线有本质区别：**耗散是被建模出来的，不是被惩罚出来的**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **MHD-α 湍流模型** | 输运速度 $\bar u = u - \alpha^2\nabla\times\nabla\times u$，在长度 α 上滤除小尺度 |
| **α-依赖能量 $E_\alpha$** | 使离散耗散律在 α 模型下依然成立 |
| **逐点磁高斯定律保持** | 通过特殊单元/混合 FEM 自由度设计保证 $\nabla\cdot B=0$ 逐点成立 |
| **增广拉格朗日预条件器** | 处理低阶 FEM 下质量矩阵与刚度矩阵的不匹配 |
| **单体几何多重网格** | 与增广拉格朗日预条件器耦合；几何 MG 依赖真实网格层次（嵌套/AMR） |
| **交叉螺度（cross helicity）耗散律** | MHD 的第二个守恒量族 |
| **磁位平方平均** | 第三守恒量族，关联逆级联 |
| **Arnold 型界** | 2D MHD 能量-螺度可达集的上界 |
| **选择性衰减** | 能量与螺度差异衰减，MHD 的标志性现象 |

## 公式 / 理论要点

```math
% MHD-α 输运速度（Helmholtz 投影过滤）
\bar{u} = u - \alpha^2 \nabla\times\nabla\times u
```

```math
% 逐点保持的两条硬约束
\text{mass:}\quad \partial_t \rho + \nabla\cdot(\rho u) = 0
\qquad\text{(逐点)}
```

```math
\text{Gauss:}\quad \nabla\cdot B = 0
\qquad\text{(逐点)}
```

```math
% 三条离散耗散律（理想极限下退化为守恒律）
\frac{dE_\alpha}{dt} = -\mathcal{D}_\alpha \le 0
\qquad
\frac{d}{dt}\langle u\cdot B\rangle = -\mathcal{D}_h \le 0
\qquad
\frac{d}{dt}\langle A^2\rangle = -\mathcal{D}_A \le 0
```

```math
% 理想极限（粘性、电阻率 → 0）
\mathcal{D}_\alpha,\ \mathcal{D}_h,\ \mathcal{D}_A \to 0
\quad\Longrightarrow\quad
E_\alpha,\ \langle u\cdot B\rangle,\ \langle A^2\rangle \ \text{精确守恒}
```

```math
% 选择性衰减：向 Arnold 型界弛豫
E(t) \to E_{\mathrm{Arnold}},\qquad
\langle A^2\rangle \ \text{逆级联（向大尺度输运）}
```

## 实验与结果

- **模型**: 2D MHD-α 湍流；有限元离散 + 增广拉格朗日预条件 + 单体几何多重网格。
- **验证**: 与**傅里叶伪谱直接数值模拟**（原 MHD 方程）在大尺度上一致。
- **数值行为**:
  - 收敛于**最优阶**；
  - 求解器对 α、Re、小步长下的网格尺寸鲁棒；
  - **欠分辨流**: 未过滤格式**无数值耗散** → 能量在网格尺度累积；启用过滤可缓解该累积，α 越大谱越紧凑。
- **长时程**: 再现选择性衰减、向 Arnold 界弛豫、磁位平方平均的逆级联。

---

## 局限性

- 仅二维（3D MHD-α 的结构保持离散仍有相当难度）。
- 依赖**几何多重网格** → 需要真实嵌套网格（或 AMR），对非结构网格的实现有额外成本。
- α-依赖能量是**被修改的守恒量**，与原始 MHD 能量不同 → 跨模型比较需谨慎。
- 摘要未给出具体收敛阶数值、α 与网格数的定量关系、CPU 时间。

---

## 实现建议

- **实现难度**: 高（结构保持 FEM + AL 预条件 + 几何 MG 三者耦合）。理论参考价值高于直接实现价值。
- **预期性能**: 最优阶收敛；AL 预条件使低阶 FEM 的条件数可控；几何 MG 在嵌套网格上给出近线性标量并行效率。
- **适用场景**:
  - **2D MHD 湍流的长时间模拟**（如太阳发电机、地磁发电机、实验室旋转导电流体）；
  - 研究**选择性衰减与逆级联**的机制（需要长时间积分且守恒量不被数值耗散污染）；
  - 作为**结构保持离散**的模板：把"修改守恒量族以适配模型"这一思路迁移到其他带过滤项的模型（如带人工耗散的 LES）。
- **可复用要点**:
  - **"改守恒量而非加耗散"**——当模型本身破坏了 Hamiltonian 结构时，重新定义一族与模型兼容的守恒量，是比人工耗散更干净的路子。
  - **逐点约束 vs 弱形式约束**：磁高斯定律逐点保持比弱形式保持更能防止拓扑错误（磁力线"泄漏"）。
  - 增广拉格朗日 + 单体几何 MG 的组合是**低阶 FEM 处理刚性对流-扩散**的通用配置。
