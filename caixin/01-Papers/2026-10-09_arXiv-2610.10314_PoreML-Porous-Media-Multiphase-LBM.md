# PoreML: 多孔介质多相流机器学习统一框架

## 元信息

| 字段 | 内容 |
|------|------|
| **标题** | PoreML: A Data-Driven Framework for Learning Multiphase Flow in Porous Media |
| **作者** | Chunyang Wang, Mingrui Zhang, Yuyan Zhang, Linqi Zhu, Xin Ju, Edo Sicco Boek, Martin J. Blunt, Gege Wen |
| **发表** | arXiv preprint, 2026-10-07 (43.6 MB, 含 3.3 TB 数据集) |
| **链接** | [arXiv:2610.10314](https://arxiv.org/abs/2610.10314) |
| **应用** | CO₂ 封存、燃料电池、倒装芯片封装 |

---

## 核心贡献

> 提供开源统一框架，集成 GPU-native LBM 求解器、超大规模数据集、领域特定评估协议，专门服务多孔介质多相流机器学习研究。

1. **GPU-native LBM 求解器**：验证过解析解与公开实验，可重现数据生成。
2. **3.3 TB 多相流基准数据集**：560 次模拟，158,546 时间步，覆盖 4 类应用场景。
3. **领域评估协议**：包括单步预测与自回归 rollout，物理一致性检查。
4. **迁移挑战**：从合成结构向 micro-CT 真实结构；从小域向大域迁移。

---

## 技术方案

### 核心思想

构建端到端 pipeline：
```
LBM Solver (GPU) → 数据集 (3.3 TB) → 学习框架 → 评估协议
```

### 关键技术

| 组件 | 说明 |
|------|------|
| LBM 求解器 | GPU-native，多相，润湿性可变，粘性比可变 |
| 4 类场景 | CO₂ 存储、燃料电池多孔电极、芯片封装、合成/真实孔隙结构 |
| 5 个基准模型 | 不同架构（CNN/Transformer/FNO 等）评估 |
| 迁移评估 | 合成 → micro-CT；小 → 大域 |

## 实验场景与数据集

| 场景 | 物理量 | 数据规模 |
|------|--------|----------|
| **场景 1**: CO₂ 地质封存 | 毛细捕获、相对渗透率演化 | 数百运行 |
| **场景 2**: 燃料电池多孔电极 | 液滴动力学、接触角影响 | 数百运行 |
| **场景 3**: 芯片底填料流动 | 焊点润湿、毛细驱动 | 数百运行 |
| **场景 4**: 微反应器 | 反应-流动耦合 | 数百运行 |

**数据集统计**:
- 560 simulation runs
- 158,546 stored time steps
- 3.3 TB
- 含 micro-CT 真实孔隙几何扫描

---

## 局限性

- 仍是基于当前 ML 架构的基准评估，尚未展示显著超越传统 LBM 的代理模型
- 3.3 TB 数据集分发挑战
- 多相流接触角动力学在 ML 中难以准确学习
- 自回归 rollout 误差累积问题待深入研究

---

## 实现建议

- **实现难度**: 高（构建完整 pipeline）
- **预期性能**: LBM 直接模拟是 ground truth；ML 代理需 <10% 误差才能实用
- **适用场景**: 
  - CO₂ 地质封存快速风险评估
  - 燃料电池设计优化
  - 芯片制造过程数字孪生
- **代码/数据**: 关注后续作者开源仓库
- **结合点**: 与 FNO / U-Net / Transformer 的兼容性已预留评估接口
