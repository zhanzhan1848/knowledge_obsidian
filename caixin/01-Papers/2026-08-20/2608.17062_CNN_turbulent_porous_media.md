# Turbulent Microscale Flow Field Prediction in Porous Media Using CNN

**arXiv:** [2608.17062](https://arxiv.org/abs/2608.17062)  
**Category:** physics.flu-dyn  
**Published:** 2026-08-17  
**Authors:** Vishal Srikanth, Ching-Wei Huang, Ryan Harradine, Andrey V. Kuznetsov

## 核心创新点

- 使用 **CNN 卷积神经网络**预测多孔介质中湍流的微观流场
- 孔尺度 Reynolds 数 = 300（湍流）
- 多孔介质：圆形圆柱固体障碍物的方形排列
- **孔隙率变化范围 0.45 - 0.92**（60 个步长）

## 数值方法

- **微观流场模拟**：大涡模拟（LES）+ 紧凑六阶有限差分法
- **神经网络**：CNN

## 关键成果

- CNN 模型预测精度：**全局误差 < 10%**
- **速度提升**：O(10^6) 倍于 LES
- 仅损失 10% 精度换取巨大加速
- 可变孔隙率训练样本数量研究

## 多孔介质类型

工程多孔介质：
- 热交换器
- 超材料
- 燃烧室

## 宏-微观耦合

- 微观流场 → CNN → 宏观模型
- 实现实时系统性多孔介质流动模拟
