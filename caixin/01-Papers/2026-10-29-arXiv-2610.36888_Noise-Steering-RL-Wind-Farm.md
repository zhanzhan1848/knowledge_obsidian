## 核心贡献

> 首次把**偏航控制（wake steering）与噪声指向性（acoustic directivity）联合**作为降噪自由度，用无模型强化学习在满足局部噪声约束的前提下最大化风电场功率，相对工业标准 NRO 降噪运行把功率损失从 **17% 降到 2%**。

1. **识别出被忽视的降噪自由度**：既有降噪策略只降功率（不利用机位间尾迹互作用与噪声指向性），导致策略过度保守、发电量白白损失。而**偏航同时改变尾迹互作用与噪声辐射方向**（风机噪声近似为与转子轴对齐的偶极子），因此偏航是除功率降额之外的**第二个独立自由度**。
2. **Noise Steering**：联合优化各风机偏航角 $\bm{\gamma}_t$ 与功率设定 $\mathbf{P}_S$，目标为最大化全场功率、同时约束受保护区 $\mathcal{R}$ 内最大声压级。
3. **低保真声学模型耦合 FLORIS**：FLORIS 无噪声模型且不提供叶片内信息（无法用 Class II 半经验模型），故实现 **Class I 解析模型**（Hagg 模型 + 强制偶极指向性），并与 FAST.Farm 的 **BPM（Brooks-Pope-Marcolini）** 模型对标，模型偏差约 **1 dB**。
4. **训练–部署分离的跨仿真器迁移**：仅在 FLORIS（稳态、低成本）上训练策略，**不重训**直接部署到高保真动态仿真器 FAST.Farm，在稳态与湍流来流下均保留性能。
5. **FLORIS→FAST.Farm 显式标定**：用 16 组 FAST.Farm 仿真标定 FLORIS 高斯尾流模型，使两仿真器功率偏差的 MAPE 从 **15% 降到 2%（对齐工况）/ 7%（全数据集）**。

## 技术方案

### 核心思想

风电场控制问题形式化为约束优化：

```math
\max_{\mathbf{u}}\;P_{\mathrm{farm}}(\mathbf{u})\quad\text{s.t.}\quad
\max_{\bm{x}\in\mathcal{R}}L_{p}^{F}(\bm{x},\mathbf{u})\leq L_{p,\mathrm{thr}}
```

其中 $\mathbf{u}$ 含功率与偏航设定，$L_p^F$ 为 dB 声级，$\mathcal{R}$ 为控制区。

### 关键技术

| 技术 | 说明 |
|------|------|
| RL 算法 | PPO（Proximal Policy Optimisation），actor-critic |
| 状态向量 | $\mathbf{s}=[U_{\infty},\mathbf{P},\bm{\gamma}_{t}]$（自由流风速、各机功率、各机偏航角） |
| 动作空间 | $\Delta\bm{\gamma}_{t}^{i}\in[-5^\circ,5^\circ]$（限幅 $\bm{\gamma}_{t}^{i}\in[-40^\circ,40^\circ]$）；$\Delta\mathbf{P}_S\in[-1,1]$ MW（限幅 $[0,5]$ MW） |
| 声学模型 | Hagg 解析模型 + 强制偶极指向性 $\mathcal{D}(\bm{x})=\cos\theta$；Class I 模型 |
| 噪声约束 | 控制区内 $100\times100$ 规则网格取最大值 |
| 标定 | 差分进化（differential evolution）优化器标定 FLORIS 高斯尾流模型 |
| 跨仿真器 | wfcrl Python 接口（Monroc et al.） |

### 算例设置

| 项目 | 值 |
|------|-----|
| 风机 | NREL 5MW 参考风机，转子直径 $D=126$ m |
| 布置 | 2 排 × 3 台，间距 4D |
| 控制区 | 距上排 4D，地面高度 |
| 噪声限值 | 40 dB（欧洲法规典型值，比该场最大声级低 4 dB） |
| 训练风速范围 | 8–15 m/s |
| 训练量 | 300k 步（FLORIS 交互），episode 长 500 步 |
| RL 动作周期（FAST.Farm） | $\Delta t_{\rm RL}=3$ s |
| 标定数据集 | 16 组 FAST.Farm 仿真（偏航 0°/10°/20°/30°，多风速） |

## 公式

### 1. 控制问题

```math
\max_{\mathbf{u}}\;P_{\mathrm{farm}}(\mathbf{u})\quad\text{s.t.}\quad
\max_{\bm{x}\in\mathcal{R}}L_{p}^{F}(\bm{x},\mathbf{u})\leq L_{p,\mathrm{thr}}
```

### 2. 奖励函数

```math
r=\frac{\sum_{i}P_{i}}{P_{\mathrm{greedy}}}
-\underbrace{\alpha\,\mathrm{ReLU}\left(\hat{L}_{p}-L_{p,\mathrm{thr}}\right)}_{\text{Noise threshold penalty}}
-\underbrace{\beta_{1}\lVert\Delta\bm{\gamma}_{t}\rVert_{2}
-\beta_{2}\lVert\Delta\mathbf{P}_{S}\rVert_{2}
-\beta_{3}\lVert\mathbf{P}-\mathbf{P}_{S}\rVert_{2}}_{\text{action penalties}}
```

动作越界（偏航超范围）时赋 $r=-3$。

### 3. Class I 声学模型（Hagg + 偶极指向性）

```math
L_{p,A}(\bm{x})=C_{1}\mathrm{log}_{10}V_{\mathrm{tip}}
+C_{2}\mathrm{log}_{10}\Big(n_{B}{\frac{A_{B}}{A_{R}}}\Big)
+C_{3}\mathrm{log}_{10}C_{T}
+C_{4}\mathrm{log}_{10}\Big({\frac{D}{\lvert\bm{x}\rvert}}\Big)
-C_{5}\mathrm{log}_{10}D-C_{6}
+10\log_{10}\mathcal{D}(\bm{x})
```

其中 $V_{\mathrm{tip}}=\Omega R$，实度 $\sigma=n_BA_B/A_R$，指向性 $\mathcal{D}(\bm{x})=\cos\theta$。

Hagg 标定系数：$C_1=63.3$，$C_2=11.5$，$C_3=2.5$，$C_4=20$，$C_5=10$，$C_6=27.5$。

### 4. 全场噪声对数叠加

```math
\hat{L}_{p}=\max_{\bm{x}\in\mathcal{R}}L_{p}^{F}(\bm{x})
=\max_{\bm{x}\in\mathcal{R}}10\log_{10}\left(\sum_{i=1}^{N}10^{L_{p,A}^{i}/10}\right)
```

### 5. 转速反演（FLORIS 无转速输出）

```math
\Omega(\hat{U})=\min\left(\lambda^{*}\hat{U}/R,\Omega_{\mathrm{rated}}\right),
\qquad \lambda^{*}=7.5
```

### 6. 湍流来流合成（TurbSim + 幂律切变）

```math
u(y,z,t)=\mathcal{U}(t)\left(\frac{z}{z_{\mathrm{ref}}}\right)^{\alpha_{\text{PL}}}
+\sigma(\mathcal{U}(t))u^{\prime}(y,z,t)
```

```math
\sigma=\mathcal{U}(t)\,\mathrm{TI},\qquad \alpha_{\text{PL}}=0.2,\qquad \mathrm{TI}=6\%
```

```math
u_{\mathrm{ref}}=\mathrm{mean}(\mathcal{U}(t))
```

### 7. FLORIS 高斯尾流模型标定参数（标定前 → 标定后）

| 参数 | FLORIS 默认 | 标定后 |
|------|-------------|--------|
| $\beta_g$ | 0.38 | 0.31 |
| $d_m$ | 0.004 | 0.0024 |
| $b_d$ | 0.58 | 0.99 |
| — | 0.077 | 0.149 |
| — | 1.0 | 0.893 |
| — | 0.0 | 0.00699 |

## 实验结论

### FLORIS 训练与稳态评估（风速 8–15 m/s，步长 0.5 m/s）

| 策略 | 平均功率缺额（相对 greedy） | 噪声约束满足情况 |
|---|---|---|
| **Noise Steering（RL）** | **2%**（高风速下 7.7%） | 全风速范围满足 40 dB |
| NRO（工业标准降噪运行） | **17%** | 设计上满足 |
| Greedy（无约束） | 0（基准） | 风速 >10 m/s 时**超限** |

- NRO 在 10 m/s 时功率设定 4 MW，15 m/s 时 3.4 MW；15 m/s 时约 20 MW，仅为可用功率的 **2/3**
- 最高风速（15 m/s）处 Noise Steering 功率缺额 7.7%，同时噪声降低 4 dB
- 三个策略差异最大处在 14 m/s 平台段：greedy 约 28 MW 但超限 4 dB；NRO 降至约 19 MW 仍瞬时超限近 2 dB；**Noise Steering 约 25 MW（缺额约 10%）且满足约束**

### FAST.Farm 部署（稳态）

- greedy 与 NRO 的功率在两个仿真器间**高度吻合**（得益于标定）
- 声级差异在 1 dB 声学模型误差内
- **NRO 在 14 m/s 以上超限**（均匀降额量在 FLORIS 上优化后直接迁移）
- Noise Steering 功率输出与 FLORIS 相当；12 m/s 以上功率缺额增大但仍优于 NRO
- **FAST.Farm 噪声普遍低于 FLORIS 预测，最大差 2.5 dB（11 m/s）** → 策略在 FAST.Farm 中次优（模型失配），作者指出可通过跨仿真器微调改进
- 仅最高风速处 RL 策略超出噪声约束

### FAST.Farm 湍流来流评估（$\mathcal{U}(t)$：10 → 14 → 8 m/s）

| 策略 | 超限时间占比 | 功率缺额（相对 greedy） | 峰值声级 |
|---|---|---|---|
| Greedy | **53.0%** | 0 | 44.1 dB |
| NRO | **30.5%** | 18.1% | — |
| **Noise Steering** | **8.3%**（即 91.7% 时间满足） | **7.4%** | 41.0 dB（瞬时） |

- 控制前留 **200 s 初始化期**让尾迹充分发展
- 14 m/s 平台段起始处策略短暂超限至 41.0 dB，**在 2 个 RL 步（6 s）内迅速降到 39.4 dB**
- 湍流会增强尾迹恢复、削弱尾流转向的增益 → 进一步增加模型失配

## 局限性

1. **策略在 FAST.Farm 中次优**：模型失配导致噪声预测偏低（最多 2.5 dB），策略未充分利用噪声余量；作者明确指出可通过在 FAST.Farm 中微调解决（本文未做）。
2. **仅 6 台风机**的测试风电场，规模小，结论外推到大规模机群需验证。
3. **仅限稳态风训练**（风向恒定对齐机排）；未训练多风向策略。
4. **Class I 声学模型**：球面扩展、无大气传播/地形效应，仅球面扩展 $1/|\bm{x}|$；与 BPM 模型对标偏差 1 dB，但真实近场/复杂地形下误差更大。
5. **FLORIS 无叶片内信息**，无法用 Class II 半经验模型，牺牲了精度。
6. **NRO 基线依赖逐风速迭代寻优**（为满足 40 dB 逐步下调功率设定），实际工业中会用工况表，作者说明该基线偏保守。
7. **湍流来流为合成**（TurbSim + 常数湍流强度 6%），未覆盖实测湍流谱。
8. 未考虑噪声约束的**时间平均 vs 瞬时**语义差异（RL 惩罚项为瞬时超限）。

## 实现建议

- **实现难度**：中（RL 部分现成，核心工作量在声学模型耦合与跨仿真器标定）。
- **预期性能**：FLORIS 单步极快，300k 训练步可在单机数小时内完成；FAST.Farm 评估慢但仅需部署评估。
- **适用场景**：
  - 陆上风电场近居民区噪声合规的**发电量最大化**
  - 多约束（噪声 + 尾迹损失）风电场控制的通用范式
- **落地建议**：
  1. **最小复现路径**：FLORIS v4 + 自建 Class I 声学模块（Hagg 系数 + $\cos\theta$ 指向性）→ wfcrl 封装成 Gym 环境 → PPO → 先在 FLORIS 训练 → 再接 FAST.Farm 评估
  2. **先做标定再训策略**：FLORIS 尾流参数用 16 组 FAST.Farm 数据做差分进化标定，可把功率 MAPE 从 15% 压到 7%（这一步收益最大）
  3. **奖励函数调参要点**：$\beta_1,\beta_2,\beta_3$ 三个动作惩罚项不是可选项——去掉会显著增加振荡；噪声惩罚用 ReLU 是关键（不惩罚未饱和区）
  4. **迁移失配的处理**：本文只做了「零样本迁移」，实践上应加 **FLORIS→FAST.Farm 少量微调**（作者亦如此建议）
  5. **对 CFD 实践的启发**：本文示范了「**低保真训练 + 高保真验证 + 显式标定**」的三段式工作流，这套流程可直接套用到任何多保真 CFD 代理建模问题（湍流模型降阶、多相流界面方法、壁面模型标定）
