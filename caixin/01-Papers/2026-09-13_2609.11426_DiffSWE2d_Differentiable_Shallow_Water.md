## 核心贡献
开源 PyTorch 实现的可微分浅水方程求解器, 支持端到端洪水和海啸建模, 通过自动微分计算参数/输入梯度。

## 方法

### 技术路线
```
浅水方程 → PyTorch 可微分数值格式 → 自动微分计算梯度
                    ↓
         梯度反传优化 (如波形反演)
```

### 关键特征
- **可微分**: 时间推进作为计算图, 梯度直接反传
- **GPU加速**: PyTorch原生支持
- **端到端优化**: 支持与机器学习/优化方法结合
- **验证**: 两个标准benchmark case

### 应用场景
1. **海啸波形反演**: 从观测数据推断海底位移
2. **洪水演进优化**: 参数标定、地形反演
3. **数据同化**: 与观测结合

## 控制方程
二维浅水方程:
```
∂h/∂t + ∂(hu)/∂x + ∂(hv)/∂y = 0
∂(hu)/∂t + ∂(hu² + gh²/2)/∂x + ∂(huv)/∂y = -gh ∂z/∂x
∂(hv)/∂t + ∂(huv)/∂x + ∂(hv² + gh²/2)/∂y = -gh ∂z/∂y
```
其中 h = 水深, u,v = 流速, z = 地形

- **时间推进**: PyTorch autograd 支持的数值格式

- 网格: 2D笛卡尔网格, 规模视应用
