## 核心贡献

> 在 $Re=100$ 下用 **PPO 深度强化学习**控制椭圆圆柱（长宽比 $Ar=a/b$ 从 1 到 0.1）表面上的两枚**合成射流**，实现阻力降低 13.4%–32.2%；关键方法论贡献是**状态增强（state augmentation）**：对极端细长几何（$Ar=0.1$），单靠超参调优无法抑制涡脱，而**引入时间历史（二维状态）+ Kalman 滤波状态估计**后达到**完全涡脱抑制**。

1. **系统性的长宽比扫描**：$Ar=1,\,0.75,\,0.5,\,0.25,\,0.1$，用同一套框架（**无任何超参调整**）揭示 DRL 主动流控的能力边界——阻力降低率随 $Ar$ 减小**单调升高**（13.41% → 32.2%），但**涡脱抑制能力单调下降**。
2. **三个状态表征的消融对比（$Ar=0.1$）**：
   - Case A（一维状态，仅控制周期末的压力）：阻力降低 **15.1%**，周期性涡结构仍存；
   - Case B（二维状态，50 步中取 25 步时间序列）：阻力降低 **24.3%**，涡脱仍可观测；
   - **Case C（Kalman 滤波 + 原始观测拼接）：阻力降低 32.2%，完全抑制涡脱，$C_L$ 周期振荡几乎完全消除**。
3. **反直觉发现：加密探针反而有害**。Case D 在保持时间分辨率的同时**加密探针分布**，阻力降低仅 **21.4%**，涡脱抑制**弱于** Case B——作者归因于**过拟合**。这是对「传感器越多越好」直觉的重要修正。
4. **能量效率的定量分析**：控制动作（射流质量流量）均值极小（$|Q_{i,\rm Mean}|\lesssim0.164$），说明低能耗下取得高阻力降低。

## 技术方案

### 核心思想

**闭环主动流控**：智能体在每个控制周期 $t_c$ 通过布设在圆柱与尾迹中的**观测探针**获取状态 $s_t$，策略网络 $\pi_\theta$ 输出动作 $a_t$（两枚合成射流的**单位质量流量**），作用到 CFD 环境得到新的流场并计算奖励 $r_t$。这是典型的**侵入式（intrusive）DRL-CFD 框架**。

**几何**：椭圆圆柱长轴 $2b$、短轴 $2a$，特征高度 $D=2a$，长宽比 $Ar=a/b$。取 $Ar=1$（圆）、0.75、0.5、0.25、0.1。计算域 $20D\times4.1D$。

**控制执行**：合成射流的径向速度剖面为余弦型

$$u_{\text{jet}}(\alpha,Q_i)=\frac{\pi}{\omega D}Q_i\cos\!\left(\frac{\pi}{\omega}(\alpha-\alpha_0)\right),\qquad \omega=10^\circ$$

两枚射流位于 $\alpha_0=90^\circ$ 与 $270^\circ$（主分离点两侧），交替吹/吸形成周期调制。为满足质量守恒，**净质量流量为零**：$Q_1+Q_2=0$。

**核心创新点——状态增强**：常规状态观测在维数与时间分辨率上都受限。作者引入三种递进表征：

| 表征 | 符号 | 维度 | 说明 |
|---|---|---|---|
| 一维 | $\mathbf z_{\rm 1D}\in\mathbb{R}^n$ | $n$ | $n$ 个探针在**控制周期最后时刻**的观测值（速度、压力等） |
| 二维 | $\mathbf Z_{\rm 2D}\in\mathbb{R}^{n\times k}$ | $n\times k$ | $n$ 个探针在**控制周期内 $k$ 个时刻**的观测（编码时间信息） |
| 增强二维（滤波） | $\mathbf Z_{\rm stacked}\in\mathbb{R}^{k\times(n+m)}$ | $k\times(n+m)$ | 原始观测 $\mathbf z_t\in\mathbb{R}^n$ 与 Kalman 滤波状态估计 $\mathbf x_{t|t}\in\mathbb{R}^m$ **沿时间维拼接** |

### 关键技术

| 技术 | 说明 |
|------|------|
| RL 算法 | **PPO** with clipped objective；策略梯度 $J(\theta)=\mathbb{E}_\pi[\sum_t\gamma^tR_{t+1}]$，$\nabla_\theta J=\mathbb{E}_\pi[\nabla_\theta\log\pi_\theta(a|s)Q^\pi(s,a)]$；$\mathcal L^{\rm CLIP}$ 取 $\min(r_t\hat A_t,\ \mathrm{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t)$ 的最小值 |
| 奖励函数 | $r_{T_i}=C_{D,0}-(C_D)_{T_i}-0.1\,|(C_L)_{T_i}|$（惩罚系数 **0.1** 抑制升力波动） |
| 状态估计 | **实时 Kalman 滤波**：$\hat{\mathbf x}_t=\mathbf A\hat{\mathbf x}_{t-1}+\mathbf K_t(\mathbf z_t-\mathbf H\mathbf A\hat{\mathbf x}_{t-1})$，$\mathbf K_t=\mathbf P_t^{-}\mathbf H^T(\mathbf H\mathbf P_t^{-}\mathbf H^T+\mathbf R)^{-1}$ |
| 数值求解 | OpenFOAM `pimpleFoam`；有限体积法；空间/时间离散格式见论文 Table 2（Backward 时间格式、Gauss linear 梯度、`snGradSchemes` = Corrected、laplacian `Gauss linear corrected`） |
| 网格无关性 | 对 $Ar=0.1$、$Re=100$ 做三档网格测试：Fine 28,142 单元 / Medium 22,142 / Coarse 14,424；结论：中网格已收敛，选 Medium 用于全部算例 |
| 评估指标 | 阻力降低率、$C_L$ 波动抑制率、$C_D$ 的 PSD 峰抑制、涡量场相图、控制能量（$Q_{i,\rm Mean}$） |

## 公式

### 1. 控制方程（Navier–Stokes）

```math
\frac{\partial\mathbf u}{\partial t}+\mathbf u\cdot\nabla\mathbf u=-\nabla p+\frac{1}{Re}\nabla^2\mathbf u,\qquad \nabla\cdot\mathbf u=0
```

```math
Re=\frac{\bar U L}{\nu},\qquad
C_D=\frac{2F_D}{\rho\bar U^2D},\qquad C_L=\frac{2F_L}{\rho\bar U^2D}
```

### 2. 合成射流边界条件

```math
f_{Q_i}=u_{\text{jet}}(\alpha;Q_i),\qquad
u_{\text{jet}}(\alpha,Q_i)=\frac{\pi}{\omega D}Q_i\cos\!\left(\frac{\pi}{\omega}(\alpha-\alpha_0)\right),\quad \omega=10^\circ
```

```math
Q_1+Q_2=0 \quad \text{(净质量流量为零，保证控制体内总质量不变)}
```

### 3. PPO 策略梯度与 clipped 目标

```math
J(\theta)=\mathbb{E}_{\pi}\!\left[\sum_{t=0}^{\infty}\gamma^t R_{t+1}\right],\qquad
\nabla_\theta J(\theta)=\mathbb{E}_{\pi}\!\left[\nabla_\theta\log\pi_\theta(a|s)Q^\pi(s,a)\right]
```

```math
\mathcal L^{\rm CLIP}_{\theta_k}(\theta)=\mathbb{E}_{\tau\sim\pi_k}\!\left[\sum_{t=0}^{T}\min\!\left(r_t(\theta)\hat A_t^{\pi_k},\ \mathrm{clip}\!\left(r_t(\theta),1-\epsilon,1+\epsilon\right)\hat A_t^{\pi_k}\right)\right]
```

### 4. 奖励函数

```math
r_{T_i}=C_{D,0}-\left(C_D\right)_{T_i}-0.1\left|\left(C_L\right)_{T_i}\right|
```

### 5. 状态表征

```math
\mathbf z_{\rm 1D}=\left[z_{t_c,1},z_{t_c,2},\ldots,z_{t_c,n}\right]^T
```

```math
\mathbf Z_{\rm 2D}=\begin{bmatrix}
z_{t_1,1}&z_{t_2,1}&\cdots&z_{t_k,1}\\
z_{t_1,2}&z_{t_2,2}&\cdots&z_{t_k,2}\\
\vdots&\vdots&\ddots&\vdots\\
z_{t_1,n}&z_{t_2,n}&\cdots&z_{t_k,n}
\end{bmatrix}
```

```math
\mathbf Z_{\rm stacked}=\begin{bmatrix}\mathbf z_1&\mathbf x_{1|1}\\ \mathbf z_2&\mathbf x_{2|2}\\ \vdots&\vdots\\ \mathbf z_T&\mathbf x_{T|T}\end{bmatrix}=\begin{bmatrix}\mathbf z_t&\mathbf x_{t|t}\end{bmatrix}_{t=1}^{T}
```

### 6. Kalman 滤波递推

```math
\hat{\mathbf x}_t=\mathbf A\hat{\mathbf x}_{t-1}+\mathbf K_t\left(\mathbf z_t-\mathbf H\mathbf A\hat{\mathbf x}_{t-1}\right)
```

```math
\mathbf K_t=\mathbf P_t^{-}\mathbf H^T\left(\mathbf H\mathbf P_t^{-}\mathbf H^T+\mathbf R\right)^{-1}
```

（$\mathbf P_t^{-}$ 大而 $\mathbf R$ 小时 $\mathbf K_t$ 增大，更依赖观测；反之更依赖预测。）

## 实验结论

### 主结果表（$Re=100$）

| $Ar$ | $C_{D,\rm CFD}$ | $C_{D,\rm Mean}$ | 阻力降低率 (%) | $C_{L,\rm Mean}$ | $Q_{i,\rm Mean}$ |
|---|---|---|---|---|---|
| 1.00 | 1.494 | 1.294 | **13.41** | 0.041 | −0.042 |
| 0.75 | 1.696 | 1.356 | **20.08** | 0.007 | −0.007 |
| 0.50 | 2.047 | 1.497 | **26.88** | −0.005 | 0.006 |
| 0.25 | 2.593 | 1.806 | **30.37** | 0.107 | −0.164 |

**$Ar=1$ 的附加结果**：$C_D$ 周期振荡**完全消除**；$C_L$ 的基流周期振荡被抑制 **99%**；射流质量流量在初始剧烈振荡后迅速稳定在最小值附近（能效良好）。

**训练收敛性（关键的负面信息）**：$Ar=0.5$ 需要 **4800 episodes** 才收敛，$Ar=0.25$ 需要 **6000 episodes**——长宽比越小收敛越慢。

**流场/频谱定性结论**：
- $Ar=1,0.75$：基流呈典型卡门涡街；受控后涡脱被有效抑制，尾迹变为流线型，$C_D$ 的 PSD **主峰完全压制**，谱能量宽带化。
- $Ar=0.5,0.25$：受控流出现**多级（multi-stage）涡脱**——回流区拉长、尾迹转入更复杂的分级涡脱态。PSD 出现**多个峰**，控制虽降低了谱能量但**无法压制主峰**，低频残余能量明显。
- 控制后压力场分布更均匀（基流中存在交替高压/低压区），说明非定常气动力被削减。

### $Ar=0.1$ 极细长案例：状态增强消融

| Case | 状态表征 | 阻力降低率 | 涡脱抑制 |
|---|---|---|---|
| A | 一维（末时刻压力） | **15.1%** | 部分抑制，周期性涡结构仍存 |
| B | 二维（50 步中取 25 步时间序列） | **24.3%** | 明显改善，但仍可观测振荡 |
| C | **Kalman 滤波 + 原始观测拼接** | **32.2%** | **完全抑制**，$C_L$ 周期振荡几乎消除，尾迹完全稳定化 |
| D | 探针加密（保持时间分辨率） | 21.4% | **弱于 Case B**（过拟合） |

- Case C 的累积奖励**最高、收敛最快**；射流质量流量在控制初期较高后**持续渐降**（自适应且能效）。
- Case B / D 中 $C_D$ 仍有显著波动，尾迹呈复杂涡脱形态。
- **$Ar=0.1$ 基流网格无关性**：$C_{D,\rm Max}$ = 2.672 / 2.784 / 2.842（Fine/Medium/Coarse），$C_{D,\rm Mean}$ = 2.657 / 2.683 / 2.722，$C_{L,\rm Max}$ = 0.301 / 0.312 / 0.427，$St$ = 0.497 / 0.502 / 0.542（Coarse 明显偏离）。
- 详细流场：控制初期分离区附近近尾迹涡结构强度下降；控制末期尾迹转为**平滑延展的回流区**，无相干涡脱。

### 与已有工作的对比

- Zhang 等 (DRL+PPO，$Re=100$，二维)：本文 $Ar=1$ 的结果与之量级一致；Zhang 等进一步把二维训练的策略迁移到三维不同展向长度，策略仍保有强控制能力——本文未做此扩展。
- Wang & Xu 的数据驱动策略在 $Re=100/200/300/400$ 分别取得约 14.4%/26.4%/38.9%/47.0% 阻力降低。

## 局限性

1. **仅二维、仅 $Re=100$**：作者明确承认「未完全捕捉真实三维湍流尾迹的复杂性」。三维效应（二次不稳定性、展向涡结构）完全缺失。
2. **算例数量有限**：每个 $Ar$ 仅一个 Re；未做 Reynolds 数扫描。
3. **$Ar=0.5,0.25$ 未能完全抑制涡脱**：尽管阻力降低率高（26.88%、30.37%），尾迹进入多级涡脱态，低频残余能量明显。作者称此为「性能边界」。
4. **「探针加密有害」的结论依赖单一实现**：Case D 的负结果被归因于过拟合，但未做交叉验证或多次随机初始化来确认；也未区分「探针数量」与「探针位置」两个变量。
5. **状态估计器为线性 Kalman 滤波**：$\mathbf A,\mathbf H$ 的构造与过程/观测噪声协方差 $\mathbf R$ 的设定细节未充分展开（仅在附录给出核心方程）；在强非线性、非高斯观测下线性 KF 的最优性不再成立。
6. **控制代价未纳入优化目标**：奖励函数只惩罚 $C_D$ 与 $|C_L|$，**不含控制能量项**；能效只是事后报告（$Q_{i,\rm Mean}$），未做帕累托权衡。
7. **无实验验证**：全部结论基于 OpenFOAM 数值模拟，无风洞或实验验证。

## 实现建议

- **实现难度**：中高。需要 OpenFOAM 侵入式耦合（每步同步射流边界条件与探针输出）+ PPO 训练循环；$Ar\le0.25$ 时需 4800–6000 episodes 收敛，训练成本可观。
- **预期性能**：$Ar=1$–$0.25$ 阻力降低 13.4%–30.4%，$Ar=0.1$ 达 32.2% 且完全涡脱抑制；控制能量指标 $|Q_{i,\rm Mean}|\le0.164$（相对 $C_D$ 归一化）。$C_L$ 波动抑制可达 99%（$Ar=1$）。
- **适用场景**：
  1. **钝体减阻与尾迹稳定化**：海上升降体、桥梁缆索、换热器管束等钝体尾迹控制。
  2. **极端细长几何的流控**：本文的核心价值恰在于 $Ar=0.1$ 这种传统方法失效的场景。
  3. **状态表征设计的通用经验**：即便不采用 RL，「时间历史 + 滤波状态估计」这一组合也可迁移到其他基于观测的控制问题。
- **落地建议**：
  1. **状态增强的优先级顺序应复现本文**：时间历史（二维状态）→ Kalman 滤波 → **不要**先加密探针。本文的 Case D 明确显示加密探针会因过拟合而**劣化**控制效果——这是最反直觉也最值得内部复现的结论。
  2. **合成射流必须满足 $Q_1+Q_2=0$**：否则会向计算域注入净质量，长时间积分会污染流场与力系数。
  3. **奖励函数中升力惩罚系数 0.1 是一个可调的超参**：过大会压制有意义的气动力响应，过小则尾迹不稳定。本文未做该系数的敏感性分析，落地时值得扫描。
  4. **用 PSD 主峰抑制而非单看阻力降低率来评价控制质量**：本文显示 $Ar=0.25$ 时阻力降低率最高（30.37%）但涡脱控制最差——**阻力降低率与流场稳定化是两个不同的目标**，不应混用。
  5. **极细长几何需要网格加密的判据**：$Ar=0.1$ 下 Coarse 网格的 $C_{L,\rm Max}$（0.427 vs 0.301）与 $St$（0.542 vs 0.497）明显偏离，中网格才收敛。
  6. **与本库关联**：本篇与 [[DSMC-Supersonic-Cylinder-Unsteadiness]]（2610.37048）在「卡门涡脱的抑制与频谱诊断」上形成对照——那篇是钝体绕流的非定常性分析（DSMC + DMD/PSD），本篇是主动控制（OpenFOAM + PPO + PSD），可共享 PSD 主峰抑制的评估语言；也与 [[State-Augmented-RL-Active-Flow-Control-Elliptical-Cylinder]] 的孪生条目互相印证状态增强方法论。

## 推荐结论

> **✅推荐实现**（作为长宽比无关的主动流控框架），但**必须**配套状态增强与频谱级评估，不可只看阻力降低率。
>
> - 支持：同一套框架无需超参调整即可覆盖 $Ar=1$–$0.1$，阻力降低 13.4%–32.2%；状态增强（时间历史 + Kalman 滤波）在 $Ar=0.1$ 上实现完全涡脱抑制，是可迁移的方法论贡献。
> - 关键保留：结论限于二维、$Re=100$、无数值实验验证；$Ar\in[0.5,0.25]$ 区间只能部分抑制涡脱；控制能量未纳入优化目标。
> - 落地必做：以 PSD 主峰抑制 + $C_D$/$C_L$ 时程 + 涡量场三者联合判定控制质量；对极细长几何先用网格无关性测试锁定网格。
