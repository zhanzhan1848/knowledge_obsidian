## 核心贡献

> 在**隐式大涡模拟（ILES）**中，粘性与磁阻率不再是可显式设定的输入，而是由数值格式的**截断误差**隐式决定；本文证明**只需对流场与磁场采用不同阶数的重构格式**，就能在**不引入显式耗散**的情况下把有效磁普朗特数 $\mathrm{Pm}_{\text{eff}}$ 改变 **20 倍以上**，从而在单一代码内探索 $\mathrm{Pm}\not\simeq 1$ 的物理。

1. **核心洞见**：有限体积代码通常对流场与磁场使用**相同**的重构格式；但两者在原则上可以接收**不同的数值耗散**，因此可以通过"重构阶数配对"来调控有效 $\mathrm{Pm}$。
2. **定量标定**：用 AthenaPK，5 对重构格式组合 × 4 个分辨率（$128^3$–$1024^3$）共 **20 组模拟**，通过**壳层间能量传递分析**反测有效粘性 $\nu_{\text{eff}}$、电阻率 $\eta_{\text{eff}}$ 与 $\mathrm{Pm}_{\text{eff}}$。
3. **单调规律**：磁场重构阶数**高于**流体重构阶数 → $\mathrm{Pm}_{\text{eff}}$ 升高；反之降低。
4. **量级**：在 $N=1024$ 时，仅靠重构配对就能把 $\mathrm{Pm}_{\text{eff}}$ 从 **0.26 变到 5.4（约 21×）**，同时覆盖**亚单位与超单位两个区间**。
5. **验证**：与"匹配显式耗散"的 DNS 对比，在这些 $\mathrm{Pm}$ 值下**结果一致**，说明 ILES 达到的有效耗散是可信的。
6. **无需显式耗散**：ILES 的时间步只受**对流稳定性**限制，比 DNS 便宜，且网格点不必浪费在分辨耗散区。

## 技术方案

### 核心思想

**背景**：天体等离子体的磁普朗特数跨越多个数量级（恒星对流区 $\mathrm{Pm}\sim10^{-5}$–$10^{-2}$，星系团介质 $\mathrm{Pm}\gtrsim10^{14}$）。$\mathrm{Pm}=\mathrm{Rm}/\mathrm{Re}=\nu/\eta$ 决定了粘性与电阻耗散尺度的相对位置，因而深刻影响**湍流发电机（dynamo）**的增长率与磁场结构。

- **DNS**：显式积分粘性与电阻，耗散尺度被分辨，$\mathrm{Pm}$ **直接选**。
- **ILES**：不加显式耗散，由格式截断误差在网格尺度附近移除能量。$\mathrm{Pm}_{\text{eff}}$ **由格式继承**，不可控——这是 ILES 的主要缺点。

**本文的解法**：重构格式决定了各场在网格尺度附近被"平滑"的强度。对流场与磁场用**不同阶数**的重构 → 两者得到**不同的数值耗散** → $\nu_{\text{eff}}\neq\eta_{\text{eff}}$ → $\mathrm{Pm}_{\text{eff}}$ 可调。

**符号约定**（论文定义）：
$$\Delta(\text{order}) = \text{order}_{\text{mag}} - \text{order}_{\text{hydro}}$$
- $\Delta > 0$：磁场重构阶数更高 → $\mathrm{Pm}_{\text{eff}}$ **升高**
- $\Delta < 0$：反之 → **降低**

## 公式

```math
\text{控制参数}:\quad
\mathrm{Re} = \frac{UL}{\nu},\qquad
\mathrm{Rm} = \frac{UL}{\eta},\qquad
\mathrm{Pm} = \frac{\mathrm{Rm}}{\mathrm{Re}} = \frac{\nu}{\eta}
```

```math
\text{有效耗散（反测）}:\quad
\mathrm{Re}_{\text{eff}} = \frac{u_{\text{rms}}L_f}{\nu_{\text{eff}}},\qquad
\mathrm{Rm}_{\text{eff}} = \frac{u_{\text{rms}}L_f}{\eta_{\text{eff}}},\qquad
\mathrm{Pm}_{\text{eff}} = \frac{\nu_{\text{eff}}}{\eta_{\text{eff}}},
\quad L_f = 2\pi/k_f = L/2
```

```math
\text{能量传递函数（壳层间）}:\quad
\mathcal{T}_{XY}(Q,K),\qquad X,Y\in\{\mathrm{U},\mathrm{B}\}
\]
- $\mathcal{T}_{\mathrm{UU}}$：动能级串
- $\mathcal{T}_{\mathrm{BB}}$：磁能级串
- $\mathcal{T}_{\mathrm{UB}}$：动能 → 磁能
- $\mathcal{T}_{\mathrm{UBT}}$：经磁张力；$\mathcal{T}_{\mathrm{UBP}}$：经磁压
- $\mathcal{T}_{\mathrm{PU}}$：经压强梯度的内部→动能
- $\mathcal{T}_{\mathrm{FU}}$：机械强迫注入

```math
\text{壳层动能预算}:\quad
\frac{\partial E^{\mathrm{K}}_{\text{kin}}}{\partial t}
= \int\sum_Q \bigl(\mathcal{T}_{\mathrm{UU}} + \mathcal{T}_{\mathrm{BUT}} + \mathcal{T}_{\mathrm{BUPC}}\bigr)\,\mathrm{d}Q
- \nu_{\text{eff}}\,(\cdots)
```

```math
\text{重构阶数差与有效 Pm 的关系（本文核心）}:\quad
\Delta(\text{order}) > 0 \Longrightarrow \mathrm{Pm}_{\text{eff}} \uparrow,
\qquad
\Delta(\text{order}) < 0 \Longrightarrow \mathrm{Pm}_{\text{eff}} \downarrow
```

```math
\text{模拟设置}:\quad
\gamma = 1.0001\ (\text{近等温}),\quad \rho=1,\ p=1,\ c_s\approx 1,\quad
\beta_0 = 2\times10^4,\quad
\mathcal{M}_s = \frac{u_{\text{rms}}}{c_s} \le 0.25
```

```math
\text{耗散系数拟合区间}:\quad kL/2\pi \ge 8
\qquad (\text{论文表格中的拟合条件})
```

## 实验结论

**20 组模拟**（5 对重构 × 4 个分辨率 $128^3,256^3,512^3,1024^3$），全部为驱动、亚声速、齐次 MHD 湍流。

**$\mathrm{Pm}_{\text{eff}}$ 标定结果（论文 Table 1 摘录）**：

| 重构对 | $N=128$ | $N=256$ | $N=512$ | $N=1024$ |
|---|---|---|---|---|
| **3P-3P** | 0.247 ± 0.012 | 0.261 ± 0.004 | 0.267 ± 0.005 | 0.262 ± 0.006 |
| **2L-2L** | 0.650 ± 0.030 | 0.742 ± 0.023 | 0.857 ± 0.021 | 0.943 ± 0.012 |
| **2L-3P** | 2.48 ± 0.13 | 3.58 ± 0.07 | 4.73 ± 0.08 | **5.45 ± 0.08** |
| **2L-3Z** | 2.08 ± 0.14 | 2.65 ± 0.05 | 3.15 ± 0.06 | 3.44 ± 0.02 |
| **1C-3P** | 48.2 ± 3.9 | 248 ± 60 | — | — |

**关键结论**：
- 在 $N=1024$ 时，仅重构配对就使 $\mathrm{Pm}_{\text{eff}}$ 从 **0.26 变到 5.4（≈21×）**；
- **亚单位（<1）与超单位（>1）两个区间在单一代码内均可到达**；
- 1C-3P 极端组合可达 $\mathrm{Pm}_{\text{eff}}\sim 48$–248，但 $N\ge512$ 时拟合出的电阻率为负 → 无法可靠测量（说明该组合数值耗散过强）。
- **DNS 对照**：与"匹配显式耗散"的 DNS 在这些 $\mathrm{Pm}$ 值下**结果一致**，验证 ILES 有效耗散的可信度。
- 各运行的 $\mathcal{M}_s\le0.25$（全亚声速）、$\mathcal{M}_A\approx1.1$–4.2。
- 分析窗口取 dynamo 饱和后的 **15 个快照**，跨度 3.3–5.9 个涡翻转时间。

## 局限性

- **单一代码、单一流动构型**：论文明确声明这是"**概念验证**（proof of concept）"，**不是通用标定**。
- **$\mathrm{Pm}_{\text{eff}}$ 依赖于分辨率**：同一重构对在 $N=128\to1024$ 间 $\mathrm{Pm}_{\text{eff}}$ 明显漂移（如 2L-3P：2.48 → 5.45），说明**格式耗散本身随网格变化**，跨分辨率比较需谨慎。
- **强耗散组合下反测失效**：1C-3P 在 $N\ge512$ 时 $\eta_{\text{eff}}<0$，无法给出 $\mathrm{Pm}_{\text{eff}}$——反测方法在高耗散区不可靠。
- **仅理想可压缩 MHD**：未涉及磁流体与辐射/焦耳加热的自洽耦合。
- **诊断法本身的模型依赖**：壳层传递函数反测耗散系数依赖对耗散形式（线性 $\nu$、$\eta$）的假设；非线性耗散（如激波处的选择性耗散）会使反测偏差。
- **工程折中**：高阶磁场重构（PPM/WENO-Z）本身更贵；作者只报告了"单步耗时"，未系统讨论"$\mathrm{Pm}$ 扫描的总成本"。
- **亚格子模型的缺失**：未引入任何显式亚格子模型，$\mathrm{Pm}$ 的作用完全体现在格式耗散上。
- **未验证收敛性**：$\mathrm{Pm}_{\text{eff}}$ 的"正确值"随分辨率漂移，意味着不能简单地宣称某分辨率下的 $\mathrm{Pm}_{\text{eff}}$ 就是物理 $\mathrm{Pm}$。
