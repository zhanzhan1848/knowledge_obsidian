## 核心贡献

> 提出**深腔回流问题不能只看整体速度吻合**的评估框架：深顶驱动腔中盖板下流动强、深处回流弱，因此整体速度误差会**掩盖**深处回流区的旋转误差；以硬约束流函数 PINN 配合区域化配点，在 $D/W=5$、$Re=100\sim1000$ 下给出分区误差基线，并与独立 $hp$ 谱参考解对比。

1. **区域化评估**：区分"内部区 (interior)"与"底部区 (floor region)"的误差，揭示整体一致 ≠ 旋转场一致。
2. **硬约束流函数 (hard-constrained streamfunction) 形式** + **规定的区域化配点 (regional collocation)** + **迁移初始化 (transferred initialization)** + 精选的**残差缩放**与**包络 (envelope)** 变体，构成完整工作流。
3. **独立谱/$hp$ 参考**：用带高斯正则化盖板速度的独立 $hp$ 计算生成参考场（非用 CFD 黑盒结果凑）。
4. **有限预算对比的诚实结论**：改进来自**累积训练工作流**（工作流对比），**并未分离出区域采样的单独贡献**；配置排名**同时依赖区域与观测量**。

## 控制方程

二维定常不可压缩流，深顶驱动腔：

```math
\nabla \cdot \mathbf{u} = 0
```

$$\frac{\partial \mathbf{u}}{\partial t} = 0,\qquad (\mathbf{u}\cdot\nabla)\mathbf{u} = -\nabla p + \frac{1}{Re}\nabla^{2}\mathbf{u}$$

**硬约束流函数形式**（消去连续性方程，$u = \partial\psi/\partial y$，$v = -\partial\psi/\partial x$）：

$$\frac{\partial}{\partial x}\left(\frac{1}{Re}\frac{\partial^2\psi}{\partial x^2} + \frac{\partial\psi}{\partial x}\frac{\partial^2\psi}{\partial x\partial y}\right) + \frac{\partial}{\partial y}\left(\frac{1}{Re}\frac{\partial^2\psi}{\partial y^2} + \frac{\partial\psi}{\partial y}\frac{\partial^2\psi}{\partial x\partial y}\right) = 0$$

**盖板边界**：高斯正则化（Gaussian-regularized）速度剖面，用于流函数硬约束。

## 数值方法

| 技术 | 说明 |
|------|------|
| **方法** | 无数据 PINN（data-free physics-informed neural network），二维定常不可压缩 |
| **硬约束** | 流函数形式：连续性方程**精确**满足，不进入损失 |
| **配点** | 区域化（regional）配点：内部区与底部区分别指定 |
| **初始化** | 迁移初始化（transferred initialization），跨算例复用 |
| **损失变体** | 精选的残差缩放（residual-scaling）与包络（envelope）变体 |
| **参考解** | 独立谱/$hp$ 计算（spectral/$hp$），高斯正则化盖板 |
| **评估网格** | 公共 $121\times605$ 网格；精细评估另用 $161\times801$ |
| **参数范围** | 深宽比 $D/W = 5$；$Re = 100, 250, 500, 1000$ |

## 实验结论

### 主评估（$121\times605$ 公共网格，$D/W=5$）

| 区域 | 相对速度偏差 |
|------|-------------|
| **内部区 (interior)** | **5.130% – 7.850%** |
| **底部区 (floor)** | **< 5%** |

底部区绝对 RMS 偏差：$1.255\times10^{-10}U$ 至 $2.332\times10^{-9}U$（$U$ 为盖板速度尺度）。

### 精细评估（$161\times801$，$Re=1000$）

| 指标 | 基准工作流 | 改进工作流 | 改善 |
|------|-----------|-----------|------|
| 内部区相对速度偏差 | 5.624% | **2.658%** | ↓ 2.97 pp |
| 规范对齐压力 RMS 偏差 | $2.793\times10^{-3}\rho U^2$ | **$1.167\times10^{-3}\rho U^2$** | ↓ 2.4× |

### 诚实性声明

- 改进是**累积训练工作流**的对比结果，**未隔离区域采样的独立效应**。
- 配置排名**同时依赖区域与被观测量**（同一配置在内部区与底部区、在速度与压力上排名不同）。
- 有限预算对比建立的是"工作流在何处与参考一致、在何处旋转场偏差仍显著"。

## 局限性

- **有限预算**：所有对比在有限训练预算下完成，非收敛极限。
- **工作流混淆**：区域采样、残差缩放、包络、迁移初始化**未做正交分离**，结论的因果归因受限。
- **二维**：深腔 $D/W=5$ 的三维结构（角涡、次级回流）未涉及。
- **定常**：未处理非定常转捩（$Re>1000$ 腔流开始失稳）。
- **参考解自身**：$hp$ 谱方法在 $Re=1000$ 的角区精度未做独立验证。
- 压力需规范对齐（gauge alignment）后才能比较，基准选择本身引入自由度。

## 实现建议

- **实现难度**：★★★☆（硬约束流函数 PINN 需处理盖板高斯剖面的解析约束构造；$hp$ 谱参考解需独立实现，工作量不小）
- **预期性能**：内部区 2.7–5.1% 相对速度偏差、底部区 < 5%；绝对 RMS 达 $10^{-9}U$ 量级——说明 PINN 在**光滑区域**的精度已相当高，瓶颈在角区与强梯度带
- **适用场景**：
  - 深腔/长通道类**分层回流**问题的 PINN 评估
  - 需要**区域化精度报告**而非单一整体误差的对比研究
  - 作为 PINN 的**独立参考解**生成手段（$hp$ 谱）
- **可迁移点**：
  1. **硬约束流函数**消除连续性误差，是深腔 PINN 的稳健起点
  2. **区域化配点 + 分区误差报告**应成为 PINN 论文的标准评估范式（整体误差掩盖角区/深处误差）
  3. **迁移初始化**在多 $Re$ 序列扫描中可显著省算力（$Re=100\to1000$ 连续扫描）
  4. 用 $hp$ 谱解而非商业 CFD 做参考，可避免参考解本身的离散误差被误判为 PINN 误差
