## 核心贡献

> 系统量化人工加厚火焰（ATF）对热扩散不稳定贫氢火焰的影响，得到 $Ka_f^F = Ka_f\sqrt{F}$、$Da_f^F = Da_f/F$ 两条标度律，并提出**必须隐式求解**的效率因子修正。

1. **首次分离量化 ATF 对两个通道的相反影响**：加厚通过 $Ka_f^F=Ka_f\sqrt F$ **增强**平均局部火焰传播速度，通过 $Da_f^F=Da_f/F$ **削弱**火焰褶皱；两者方向相反，必须同时修正，只修正褶皱是不够的。
2. **建立 collapse 判据**：在匹配 $Ka_f^F$、$Da_f^F$、$\Lambda_f^F$ 的条件下，不同 $F$ 的算例数据塌缩到同一曲线；一旦加厚火焰厚度逼近积分尺度或几何尺度，塌缩失效。
3. **提出隐式效率因子修正**：由于效率因子 $E$ 本身会反馈改变有效的 $Ka_f^{F,E}$ 与 $Da_f^{F,E}$，修正方程是非线性的、必须隐式求解——直接（显式）修正是不足的。

## 技术方案

### 核心思想

ATF（人工加厚火焰，Butler–O'Rourke 1977）通过「扩散系数 ×$F$、化学源项 ÷$F$」使加厚火焰在粗网格上可解析，同时保持层流火焰速度不变。问题是它**改变了火焰与湍流的相互作用**。

本文用 200+ 组三维火焰解析 DNS（FIAB + HIT，**不加任何效率函数**，从而暴露 ATF 的直接效应）系统扫描 $Ka_f$、$Da_f$、$L_{\rm int}$、$F$，建立标度律与修正方案。

## 公式

### 1. 湍流–火焰相互作用参数

```math
\Upsilon_r = \frac{u'}{s_r}, \qquad \Lambda_r = \frac{L_{\rm int}}{l_r}
```

```math
K_{a_r} = \sqrt{\left(\frac{u'}{s_r}\right)^3 \frac{l_r}{L_{\rm int}}} = \sqrt{\frac{\Upsilon_r^3}{\Lambda_r}},
\qquad
D_{a_r} = \frac{L_{\rm int}}{l_r}\frac{s_r}{u'} = \frac{\Lambda_r}{\Upsilon_r}
```

火焰尺度 Karlovitz 数（Aspden 2019 形式，用耗散率 $\varepsilon$ 表达，与 Kolmogorov 定义不同）：

```math
K_{a_r}^2 = \frac{\varepsilon l_r}{s_r^3}
```

### 2. 消耗速度分解

```math
\frac{s_c}{s_l} = I_0 \Psi,
\qquad
I_0 = \frac{s_s}{s_l}, \qquad
\Psi = \frac{A}{A_0} = \frac{s_c}{s_s}
```

$I_0$ 表征**平均局部火焰速度**的改变，$\Psi$ 表征**火焰褶皱**。

### 3. 平均局部火焰速度经验关联式（Howarth et al. 2023）

```math
\frac{s_s}{s_f} = 1 + 0.26\exp(-0.038\,\omega_2)\sqrt{K_{a_f}}
```

### 4. 火焰褶皱的 SSL / LSL 标度（Peters 2000）

```math
\frac{\Psi^{-1}}{\Upsilon_r} =
\begin{cases}
\gamma_r D_{a_r}^{1/2}, & \mathrm{SSL} \\
\alpha_r, & \mathrm{LSL} \\
2\alpha_r\left(\sqrt{\xi_r^2+\xi_r} - \xi_r\right), & \mathrm{Peters}
\end{cases}
\qquad
\xi_r = \frac{D_{a_r}}{\beta_r}, \quad \beta_r = \frac{4\alpha_r^2}{\gamma_r^2}
```

### 5. **加厚火焰的核心标度律**（本文结论）

```math
K_{a_f}^{F} = K_{a_f}\sqrt{F}, \qquad D_{a_f}^{F} = \frac{D_{a_f}}{F},
\qquad \Lambda_f^{F} = \frac{L_{\rm int}}{F l_f}
```

### 6. 效率因子与隐式修正

效率因子放大有效火焰速度：$s_f^E = E\,s_f$，同时乘到扩散项与化学源项上。

**关键点**：单一效率因子**无法**同时把 $K_{a_f}$ 与 $D_{a_f}$ 恢复到未加厚的值；而 $E$ 又会反馈改变有效参数：

```math
K_{a_f}^{F,E} = K_{a_f}^{F}\sqrt{E}, \qquad D_{a_f}^{F,E} = \frac{D_{a_f}^{F}}{E}
```

因此修正方程是**非线性隐式条件**（论文式 19），必须隐式求解。

### 7. 网格规模估算式

```math
N = \frac{L}{\Delta x} = \left(\frac{l_f}{\Delta x}\right)\left(\frac{L_{\rm int}}{l_f}\right)\left(\frac{L_{\rm domain}}{L_{\rm int}}\right) = N_f\,\Lambda_f\,\Omega
```

## 实验结论

### 仿真数据库

| 数据库 | 设定 | 目的 |
|---|---|---|
| **A** | $\Lambda_f^F = 2$，$K_{a_f}^F\in\{1,4,12,36\}$ | 验证不同 $F$、不同 $K_{a_f}$、不同域尺寸在匹配 $K_{a_f}^F,\Lambda_f^F$ 后行为一致 |
| **B** | 固定 $K_{a_f}$，变 $F$ 与 $\Lambda_f$（保持 $\Lambda_f^F=2$） | 隔离 ATF 对火焰传播的直接影响 |
| **B⋆** | $F=1$ 的对照算例 | 匹配 B 组的有效 $K_{a_f}$ 与 $\Lambda_f$ |
| **L** | 减小湍流/几何尺度使 $\Lambda_f^F$ 趋近 1 | 检验长度尺度极限 |

### 主要结论

1. **加厚修改有效 Karlovitz 数**：$K_{a_f}^F = K_{a_f}\sqrt F$。固定 $K_{a_f}^F$ 与 $\Lambda_f^F$ 时，$F$ 与 $K_{a_f}$ 变化剧烈的算例，其平均局部火焰速度 $s_s$ 几乎不变 → **$K_{a_f}^F$ 而非给定的 $K_{a_f}$ 控制局部火焰速度响应**。

2. **局部火焰速度增强 ≈ $F^{1/4}$ 依赖**：结合 $s_s/s_f \propto \sqrt{K_{a_f}}$ 与 $K_{a_f}^F=K_{a_f}\sqrt F$，得 $\sqrt{K_{a_f}^F} = K_{a_f}^{1/2}F^{1/4}$。当 $K_{a_f}^F$ 落在关联式有效范围内时，仿真确认该标度。

3. **长度尺度效应**：固定 $L_{\rm domain}$、$L_{\rm int}$ 增大 $F$，当 $Fl_f$ 超过 $L_{\rm int}$ 后，局部火焰速度增强被逐步抑制并趋近 1D 层流极限。用周期 forcing 让 $L_{\rm domain}$ 与 $L_{\rm int}$ 独立变化的补充算例证明：**单纯增大计算域无法恢复大积分尺度下的火焰速度增强**（积分尺度本身仍是限制因素）。⚠️ 但此时加厚火焰厚度已落在惯性子区间之外，$K_{a_f}^F$ 不再是可靠的定量度量。

4. **褶皱标度**：给定的 $D_{a_f}$ 会造成显著散点；用 $D_{a_f}^F = D_{a_f}/F$ 归一后数据**强烈塌缩**，且与 Damköhler (1940) 的 **SSL 褶皱模型**吻合良好（系数取自 Hunt & Aspden 2025）。

5. **隐式修正优于显式修正**：显式修正（不计入 $E$ 的反馈）在 $F$ 较大时失效；隐式形式（式 19）在各 $F$、$K_{a_f}$、$D_{a_f}$ 组合下都能自洽。

6. **隐式修正是普适需求**：即使对 $Le=1$ 的火焰（加厚对平均局部火焰速度影响可忽略），效率因子仍会改变有效湍流–火焰参数进而改变褶皱 → 仍需隐式求解。

### 数值设置细节

- $N_f = 12$（火焰厚度解析单元数），基网格 + 1 级 AMR
- 附加 1 级 AMR 的分辨率检验：**无显著差异**（补充材料 Fig. S.1），说明 $N_f=12$ 已收敛
- 加厚算例中 $Fl_f$ 同样保持 $\ge 12$ 单元解析
- $F$ 取空间常数（不用火焰传感器）

---

## 局限性

1. **隐式效率修正仅由标度律推导，尚未在完全耦合的 ATF 仿真中验证**是否真正恢复未加厚的消耗速度（作者明言为 future work）。
2. 当 $\Lambda_f^F < 1$（加厚火焰厚度超出惯性子区间）时，$K_{a_f}^F$ 定义的前提失效，不再是可靠的定量指标。
3. **单一效率因子无法同时恢复 $K_{a_f}$ 与 $D_{a_f}$**——这是模型本身的结构性限制。
4. **未处理 RANS 场景**：文中指出当湍流尺度被完全建模（如 RANS）时该框架的适用性需另行研究。
5. 单一工作点（$\phi=0.4$、300 K、1 atm），标度律的普适性需更多工况验证。
6. 忽略 Soret 扩散（作者论证其在所选条件下非主导阶贡献）。

## 实现建议

- **实现难度**：中–高。方法论本身清晰，但隐式求解 + 反馈校正需要仔细实现。
- **预期性能**：隐式方程可用 1D Newton（对 $E$ 求导）在线求解，或**预计算成 $F$–$K_{a_f}$–$D_{a_f}$ 的表/拟合函数**，避免每个网格点在线非线性求解（作者明确建议此实用路径）。
- **适用场景**：
  - 贫氢预混湍流燃烧的 LES（燃机、ICE、氢能燃烧器）
  - 需要 ATF 但担心 TD 不稳定性的场合
  - **局部/时变 $F$ 或 $K_{a_f}$、$D_{a_f}$ 时必须在线隐式求解**；若为全局常数则预制表即可
- **落地建议**：
  1. 先实现 $K_{a_f}^F$ / $D_{a_f}^F$ / $\Lambda_f^F$ 的正确计算（这是所有后续修正的基础）
  2. 用 $D_{a_f}^F$ 归一验证褶皱数据是否塌缩到 SSL 模型
  3. 再引入 $E$ 的隐式求解，注意 $E$ 同时进入扩散项与化学源项
- **代码参考**：PeleLMeX 已有 PeleLMeX 的 ATF 实现基础；复现可参考 Howarth et al. (2023)、Hunt & Aspden (2025) 的模型。
