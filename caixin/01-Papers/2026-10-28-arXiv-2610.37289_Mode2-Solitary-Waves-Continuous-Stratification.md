## 核心贡献

> 直接离散 DJL 方程（而非用变分能量最小化），首次计算出**不关于水深中点对称**的连续分层中的 mode-2 内孤立波。

1. **绕开变分法的模式限制**：Turkington et al. (1991) 方法只能给出 mode-1 波（高阶模是鞍点而非极小点），除非采用 Boussinesq 近似且分层关于中点对称。本文用**直接有限差分离散 DJL 方程**，对垂直结构不加任何限制。
2. **两种新分层下的 mode-2 解**：双温跃层（double pycnocline）平滑化的三层模型；以及**表层混合层 + 指数分层**（典型上海洋）——证明 embedded mode-2 孤立波并非双温跃层独有。
3. **新发现**：发现一种**单驻点**（而非壁面上的两点）界定的被困核心（trapped core），此前未有报道。
4. **延续 Doak et al. (2022)**：三层模型中的多峰 ESW、层流速度可超 mode-1 长波速等特征在温跃层具有有限厚度时**依然存活**。

---

## 技术方案

### 核心思想

连续分层流体的稳态 Euler 解满足 **DJL（Dubreil–Jacotin–Long）方程**。但绝大多数计算采用 Turkington 的能量最小化方法——该方法因变分结构的限制**无法产生 mode-2 波**（除非中点对称）。

本文改用经典的**直接有限差分**方法（源自 Davis & Acrivos 1967、Tung et al. 1982），直接在矩形 $(x,z)$ 域上求解 DJL 方程。

### 关键技术

| 技术 | 说明 |
|------|------|
| 方程 | Boussinesq 近似下的 DJL 方程（流函数形式与位移形式） |
| 离散 | 二阶中心差分，$x$ 方向周期边界 |
| 域长度 | 取足够长，使无尾解对进一步加长不敏感 |
| ESW 定位 | 施加**余曲率约束**：计算域周期边缘（中深，$\psi_x=0$）处流线曲率 $K\approx\psi_{xx}=0$ → 保证无振荡尾 |
| 求解自由度 | 引入一个分层参数作为额外未知量（双温跃层用下层厚度 $H_3$；混合层用混合层深度 $z_0$） |
| 延拓 | 从已知 ESW 出发沿分支做 continuation |
| 初始猜测 | 由 Doak et al. (2022) 三层解重建流函数并跨界面平滑（界面处速度不连续），调整平滑宽度试凑收敛 |
| 归一化 | $g=1$、$H=1$、$\rho_0=1$；长度以 $H$ 标度，速度以 $\sqrt{gH}$ 标度 |

## 公式

### 1. DJL 方程（流函数形式）

```math
\nabla^2\psi = -\frac{g}{\rho_0}\left(z-\frac{\psi}{c}\right)F'(\psi),
\qquad
\psi(x,0)=\psi(x,H)-cH=0
```

流函数定义：$(u,w)=(\psi_z, -\psi_x)$；由质量守恒 $\rho=F(\psi)$；远场条件

```math
\psi\to cz, \qquad \rho\to\rho_0\bar\rho(z) \quad (x\to\pm\infty)
\quad\Longrightarrow\quad
F(\psi)=\rho_0\bar\rho(\psi/c)
```

### 2. DJL 方程（流线位移形式，涡量方程）

```math
\nabla^2\eta + \frac{N^2(z-\eta)}{c^2}\,\eta = 0,
\qquad
\eta(x,0)=\eta(x,H)=0
```

```math
N^2 = -g\,\frac{\mathrm{d}\bar\rho}{\mathrm{d}z},
\qquad
\rho(x,z)=\rho_0\bar\rho(z-\eta(x,z))
```

### 3. 线性长波特征值问题（模态分类）

```math
\phi'' + \frac{N^2(z)}{c^2}\phi = 0, \qquad \phi(0)=\phi(H)=0
```

特征值 $c_0^{(1)} > c_0^{(2)} > \dots$ 为 mode 1, 2, … 的线性长波速度；第 $n$ 个特征函数有 $n-1$ 个内部零点。**mode-2 孤立波 $c < c_0^{(1)}$ 落在 mode-1 连续谱内**，可与线性波共振 → 通常表现为带 mode-1 振荡尾的广义孤立波（GSW）。

### 4. 变分法（本文不用，但对比说明）

```math
KE = \frac{\rho_0 c^2}{2}\iint_D |\nabla\eta|^2\,\mathrm{d}x\,\mathrm{d}z,
\qquad
APE = \rho_0\iint_D\int_0^\eta \xi\,N^2(z-\xi)\,\mathrm{d}\xi\,\mathrm{d}x\,\mathrm{d}z
```

$c$ 是 APE 约束的 Lagrange 乘子。Turkington et al. (1991) 证明对 $x$ 对称的解极小点可取为单号 → 只能是 mode-1 垂直结构。

### 5. 双温跃层分层（式 7）

```math
N^2(z) = \frac{\alpha\Delta}{2}\sech^2\left(\alpha(z-H_3)\right)
+ \frac{\alpha\Delta}{2}\sech^2\left(\alpha(z-H_3-H_2)\right)
```

其中 $\Delta=0.01$ 为每个温跃层的密度跃变，$\alpha$ 为温跃层宽度倒数（$\alpha\to\infty$ 回到三层界面模型）。层厚：$H_1$（上层）、$H_2$（中层）、$H_3$（下层），$H_1=1-H_2-H_3$。

### 6. 表层混合层分层（式 8）

$r_0=0.1,\ 0.3,\ 0.5$ 对应不同混合层深度 $z_0$；典型上海洋结构。

## 实验结论

### 双温跃层（$H_2=0.15$，薄温跃层 $\alpha=80$）

- 存在一条**关于中点对称**的解分支，位于 $H_3=0.425$（上下层等厚）处
- 其两侧为一系列**多峰 ESW 分支**：随 $E=KE+APE$ 增大，分支渐近趋于 $H_3=0.425$，波形展宽为**桌面型孤立波**叠加共轭态上的附加振荡；随 $E$ 减小，温跃层移向上/下壁，振幅趋小
- 另发现**两条带被困核心的分支**：核心边界流线**只有一个驻点**（位于核心上方），而非两点对称 → 据作者所知此前未报道
  - 模式-1 ISW 的核心必贴壁、由壁面上有两个驻点的流线界定，故这种核心不可能出现在静止流体的 mode-1 ISW 中

### 双温跃层（$H_2=0.8$）

三层极限下支持**凹型** mode-2 孤立波（上温跃层下移、下温跃层上移），既有 $c<c_0^{(1)}$ 的 ESW，也有 $c>c_0^{(1)}$ 的常规 mode-2 ISW（速度超过 mode-1 长波速）。

### 温跃层厚度的影响（$\alpha=80 \to 30$）

$\alpha$ 减小时温跃层变宽，多峰分支**由分离转为彼此连通**；沿分支由解 (a) 到 (c)，中心脉冲上**额外增加一次振荡**。

### 表层混合层 + 指数分层

**embedded mode-2 孤立波并非双温跃层分层所特有**——这是首次在非中点对称的连续分层中计算出的 mode-2 孤立波。

### 被困核心的处理说明

DJL 方程的远场条件 (1) 假定每条流线源自 $x\to-\infty$，这对被困核心是不必要的限制。求解全域相当于把远场关系延拓进核心，得到的核心是**静力不稳定**的（密流体覆盖轻流体）。更物理的核心模型（Helfrich & White 2010、Carr et al. 2012）时间积分后仍不稳定，核心内正确流动形式仍是开放问题。

---

## 局限性

1. **被困核心内的分层是静力不稳定的**——求解全域是"最简单延拓"，物理上不成立。核心内正确流动形式为开放问题。
2. **mode-2 核心的界定流线难以确定**：mode-2 且非中点对称时，核心可能位于域内部，识别其边界流线非平凡（mode-1 则容易，因核心必贴壁）。
3. **未处理辐射/边界条件**：边界本构关系与辐射场不在本文范围。
4. 部分分支在低 $E$ 区域求解器不收敛，分支端点去向不明。
5. 仅在 Boussinesq 近似 + 刚性盖 + 无粘假设下成立。
6. 求解器为自建 FD 代码，无公开发布。

## 实现建议

- **实现难度**：中。二维椭圆型 PDE（DJL）+ Newton/continuation 非线性求解 + 无尾约束（附加未知量）。
- **预期性能**：$z$ 方向用二阶中心差分，$x$ 方向周期；域需足够长（$L_x$ 远大于波宽）。continuation 是主要成本。
- **适用场景**：
  - 海洋内孤立波（mode-2）的存在性与结构研究
  - 验证"ESW 作为 GSW 族余维 1 子集"的分支结构
  - 分层流的稳定性/波传播基准算例
- **落地建议**：
  1. 直接从 DJL 方程入手，不要用 Turkington 变分法（它给不出 mode-2）
  2. ESW 的无尾约束用「周期边缘中深处 $\psi_{xx}=0$」实现，并引入分层参数作额外自由度
  3. 建议按 Doak et al. (2025) 的自由液面处理方式扩展到非定常涡量问题
  4. 与 DJLES（Dunphy et al. 2011，Turkington 谱方法）互补：DJLES 稳健但受变分限制，本文方法受限少但需手工构造初始猜测
