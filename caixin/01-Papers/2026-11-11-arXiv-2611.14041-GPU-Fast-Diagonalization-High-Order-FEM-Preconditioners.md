## 核心贡献

> 为**高阶连续有限元**离散的椭圆问题开发了**分布式 GPU** 上同时降低"迭代次数"与"单次迭代成本"的算法：**分布式直接快速对角化 (FD) Poisson 求解器**（张量积网格上给精确解，作为精确粗求解器）、**两层混合 Schwarz (HS-FD)** 预条件（扩展到 2:1 悬挂节点八叉树）、以及 **$p$-多重网格 (CJ-$p$MG)**（Chebyshev–Jacobi 光滑）；直接求解器比 Jacobi-PCG **快 2–3 个数量级**，HS-FD 在 8–1024 个 MI250X 上**11 次迭代收敛**。

1. **分布式直接 FD Poisson 求解器**：对**张量积网格 + 方向加密 (direction-wise grading) + 沿单一坐标方向变化的系数**给出**精确解**；张量数据保持分布式，通过**集体转置**在 slab 布局间搬移，或用 **Schur 补**方法原地保持。
2. **精确粗求解器角色**：FD 求解器同时可作为 Schwarz 预条件中的**精确粗层**。
3. **HS-FD 混合 Schwarz**：两层混合 Schwarz 预条件 + FD 单元求解，**扩展到 2:1 悬挂节点八叉树**并采用**精确局部单元逆**。
4. **CJ-$p$MG 预条件**：$p$-多重网格 + Chebyshev–Jacobi 光滑，在**每个层级**用融合核 (fused kernels) 解析悬挂节点约束。
5. **FP32 混合精度利用**：在单元形状与系数允许处利用 FP32，**但迭代主体保持 FP64 共轭梯度**——精度与速度的务实折中。
6. **自适应参数**：自动在复制式/分布式粗层间选择，支持多右端项块求解，**所有参数由算子本身确定，无需案例特定调参**。
7. **广泛对比**：与 Jacobi-PCG、**MFEM、nekRS、deal.II** 比较，覆盖均匀/加密/八叉树网格、分层系数，以及 **NVIDIA / AMD / Intel** 三家 GPU。

## 技术方案

### 核心思想

本文针对的是 CFD 与结构力学中的**核心内核问题**：求解椭圆型 Poisson 方程（$\nabla\cdot(\kappa\nabla u) = f$）。迭代求解器的时间由两部分决定：

$$T_{\text{total}} = N_{\text{iter}} \times T_{\text{iter}}$$

**大多数工作只优化其中一项**：要么改预条件器减少迭代次数，要么改内核提高单次迭代速度。本文明确地**同时优化两者**——这决定了它的系统性。

在**高阶连续有限元**离散下，情况又更复杂：
- 装配矩阵需要**全局耦合**（高阶节点共享），天然稀疏且**难以矩阵自由地局部求解**；
- **悬挂节点 (hanging nodes)** 出现在非结构化/八叉树网格上，给出**分层约束**，破坏了多重网格的"嵌套光滑"假设；
- **方向加密 (direction-wise grading)** 的张量积网格打破了标准张量分解的对称性假设。

本文的应对：
- **FD（快速对角化）**：对张量积结构，通过沿坐标方向的**谱/多项式分解**（fast diagonalization）把 $d$ 维问题化为若干 $d$ 维张量积的一维算子，从而**精确求解**（对特定系数结构）。这既给出**快速直接解**，又能作为**预条件器的精确粗层**。
- **Schur 补原地策略**：避免为了 slab 布局做昂贵的集体转置通信——在分布式 GPU 上，通信往往才是瓶颈。
- **精确局部单元逆**用于 Schwarz 的局部子问题：这是高阶有限元下让 Schwarz 有效的关键（否则局部子问题本身也难解）。
- **CJ-$p$MG 用融合核处理悬挂节点约束**：把约束消解与光滑融合进同一个 kernel，避免额外的数据移动。

### 关键技术

| 技术 | 说明 |
|------|------|
| Fast Diagonalization (FD) | 张量积结构的谱分解，精确解 |
| 分布式 slab 布局 + 集体转置 | 张量数据在布局间搬移 |
| Schur 补原地策略 | 避免集体转置通信开销 |
| 混合 Schwarz + FD 单元求解 (HS-FD) | 两层 Schwarz，精确局部单元逆 |
| 2:1 悬挂节点八叉树 | 自适应非结构网格支持 |
| $p$-多重网格 (CJ-$p$MG) | Chebyshev–Jacobi 光滑 + 层级约束消解 |
| 融合核 (fused kernels) | 约束与光滑在同一 kernel 内完成 |
| FP32/FP64 混合精度 | 单元形状与系数允许处用 FP32，迭代主体 FP64 |
| Matrix-free | 免装配，适配 GPU |
| 统一后端抽象 | CUDA / HIP / SYCL 三后端 |
| 精确粗层 | FD 求解器作为精确粗求解器 |
| 自适应粗层选择 | 复制式 vs 分布式，按算子特性自动选 |

## 公式 / 理论要点

```math
% 椭圆算子（一般形式）
-\nabla\cdot(\kappa(\boldsymbol{x})\,\nabla u) = f
\qquad\text{in}\ \Omega,\quad u = 0 \text{ on}\ \partial\Omega
```

```math
% 张量积网格上的快速对角化：分离为 d 个一维算子
\mathcal{A} = \bigotimes_{k=1}^{d}\mathcal{A}_k
\quad\Longrightarrow\quad
\mathcal{A}^{-1} = \bigotimes_{k=1}^{d}\mathcal{A}_k^{-1}
\quad\Longrightarrow\quad
\text{精确解（无迭代）}
```

```math
% 方向加密网格上的谱分解（各向异性算子）
\mathcal{A}_k = \sum_{m}\lambda^{(k)}_m\,|P^{(k)}_m\rangle\langle P^{(k)}_m|
\qquad
\text{（按方向选择不同阶数的 Chebyshev 多项式）}
```

```math
% Schur 补（块结构分解，避免通信）
\begin{pmatrix} A_{11} & A_{12}\\ A_{21} & A_{22}\end{pmatrix}
^{-1}
=
\begin{pmatrix}
S^{-1} & -S^{-1}A_{12}A_{22}^{-1}\\
-A_{22}^{-1}A_{21}S^{-1} & A_{22}^{-1}+A_{22}^{-1}A_{21}S^{-1}A_{12}A_{22}^{-1}
\end{pmatrix},
\quad S = A_{11}-A_{12}A_{22}^{-1}A_{21}
```

```math
% 两层混合 Schwarz 预条件
\mathcal{P}^{-1} = \mathcal{P}_1^{-1}
+\left(I-\mathcal{P}_1\mathcal{A}_{\Omega_1}^{-1}\mathcal{A}\right)
\mathcal{P}_0^{-1}
\left(I-\mathcal{P}_0\mathcal{A}_{\Omega_0}^{-1}\mathcal{A}\right)
```

```math
% Chebyshev–Jacobi 光滑（p-多重网格层级）
\boldsymbol{x}^{(k+1)}
= \boldsymbol{x}^{(k)}
+\alpha\,\mathcal{D}^{-1}\boldsymbol{r}^{(k)}
+\beta\,\mathcal{D}^{-1}\mathcal{T}_{\ell}\mathcal{D}^{-1}\boldsymbol{r}^{(k)}
```

```math
% 悬挂节点约束的层级消解（融合核内）
\boldsymbol{x}_{H}\ \text{由}\ \boldsymbol{x}_{L}\ \text{插值约束}
\quad\Longrightarrow\quad
\text{约束自由度先投影，光滑后延拓}
```

## 实验与结果

- **算例/数据集**: 高阶连续有限元离散的椭圆问题；**均匀网格 / 方向加密网格 / 2:1 悬挂节点八叉树**；**分层系数**（沿单一坐标方向变化的 $\kappa$）；**四个应用算例**。
- **对比基线**: **Jacobi-PCG**、**MFEM**、**nekRS**、**deal.II**。
- **硬件**: **NVIDIA**（GPU）、**AMD**（MI250X）、**Intel** GPU。
- **主要结果**:
  - **直接 FD 求解器**：在均匀网格上比 **Jacobi-PCG 快 2–3 个数量级**（exact solution，零迭代）。
  - **HS-FD 收敛**：八叉树广义 Poisson 问题在 **8 → 1024 个 MI250X** 上**均 11 次迭代收敛**（**近乎与规模无关的迭代数**，这是极好的可扩展性表现）。
  - **与主流库对比**：相对 MFEM、nekRS、deal.II 有竞争力或更优（按网格结构与系数分布给出选型指南）。
  - **FP32 混合精度**：在允许的单元形状与系数下利用 FP32，FP64 CG 迭代保持精度。
  - **无需案例调参**：所有预条件参数由算子本身确定。
  - **多右端项块求解**支持。

## 局限性

- **FD 求解器的适用性受限**：要求**张量积网格 + 方向加密 + 系数沿单一坐标方向变化**——即结构高度规则的算子。真实 CFD 的复杂几何需靠 Schwarz/$p$-MG 分支。
- **奇异或几何不规则问题**未覆盖。
- **线性问题**：未讨论非线性（NS 耦合）下的表现（迭代次数会变化）。
- **"两个数量级"是在均匀网格的 Poisson 问题上**取得，与高超声速/湍流等实际 CFD 场景的差距需自行评估。
- 69 页（含 43 页补充）体量巨大，实际可用性需按需查阅。

## 实现建议

- **实现难度**: 高 — 需要同时实现 FD 求解、Schur 补、混合 Schwarz、$p$-多重网格、Chebyshev 光滑、悬挂节点约束消解，并跨 CUDA/HIP/SYCL 三后端；建议先只做 MPI+CUDA。
- **预期性能**: 直接 FD 在规则网格上 2–3 个数量级加速；HS-FD 迭代数近乎规模无关；这是**线性代数层面的加速**，可直接转化为 CFD 全流程的加速。
- **适用场景**:
  - **CFD 主求解器的 Poisson/椭圆求解器**（OpenFOAM 的 `PCG`/`PBiCGStab` 替换）；
  - 声学、电磁、传热等椭圆子问题；
  - 不可压流动的**压力泊松方程**——这是 CFD 中最耗时的部分之一；
  - 需要在**异构 GPU 集群**上统一部署的求解器栈。
- **可复用要点**:
  - **"迭代次数 × 单次迭代成本"** 这个分解应当成为**任何求解器优化工作的显式框架**——只优化一头往往收益有限。
  - **迭代数与规模无关**（HS-FD 在 8–1024 GPU 上都是 11 次）是**强扩展性**的标杆指标，建议作为自建求解器的验收标准之一。
  - **"所有参数由算子本身确定，无需案例调参"** 是极其重要的工程属性——调参成本常常是求解器落地的真正瓶颈。这与本轮多篇论文"结构化保证优于调权重"的倾向一致。
  - **Schur 补替代集体转置**是分布式 GPU 通信瓶颈的通用解法，值得推广到其他需要张量数据重排的算法（如本轮的 [[2026-11-11-arXiv-2611.14348]] DBS2 在体素网格上也有类似的布局问题）。
  - **选型指南**（网格结构 × 系数分布 → 求解器）可直接用于自建代码的分支逻辑设计。
