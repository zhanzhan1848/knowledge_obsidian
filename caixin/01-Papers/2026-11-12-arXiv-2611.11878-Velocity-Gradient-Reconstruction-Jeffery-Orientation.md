## 核心贡献

> 提出一种**从非球形示踪粒子（薄片、杆）的取向重构速度梯度张量**的方法：基于 **Jeffery 型方程**，证明对**不可压流**，速度梯度张量的**全部分量**可由**参考点邻域内 4 个示踪粒子的取向及其时间导数唯一确定**。该方法**既不用位置、也不用空间差分**，因此只需**参考点附近**的取向测量（而非整个三维区域的测量），噪声只通过**时间差分**放大，因而**最小可达误差随噪声 $\sigma$ 按 $\sigma^{1/2}$ 标度**，优于"位置 PTV + 差分"方案的 $\sigma^{1/3}$。数值测试显示**涡量**的重构精度明显优于位置法，而**应变率**精度相当。应用于**球面 Couette 流**时发现：**相邻示踪粒子取向对齐处重构失效（反问题病态）**，且该退化恰好表现为流场可视化中**特征性的明暗图案**。

1. **问题**：速度梯度张量是**局域量**，但用球形示踪粒子的速度做**空间差分**来获得它会**放大测量噪声**。
2. **方法**：改用**非球形示踪粒子**（薄片 flake、杆 rod）的**取向**信息，基于 **Jeffery 型方程**重构速度梯度张量。
3. **唯一性定理**：对**不可压流**，速度梯度张量的**所有分量**由**参考点邻域内 4 个示踪粒子的取向 + 其时间导数**唯一确定。
4. **优势**：
   - **不用位置**，**不用空间差分**；
   - 只需**参考点附近**的取向测量，**不需要覆盖整个三维区域**；
   - 噪声**只通过时间差分放大**。
5. **噪声标度优势**：最小可达误差 $\propto \sigma^{1/2}$，优于位置法 (PTV + 差分) 的 $\sigma^{1/3}$。
6. **精度分布**：**涡量**的重构比位置法**更准**；**应变率**精度**相当**。
7. **失效模式的可视化特征**：应用于**球面 Couette 流**，发现重构在**相邻示踪粒子取向对齐处失败**（反问题病态/ill-conditioned），且**该退化恰好表现为流场可视化中特征性的明暗图案**——这是一个极具实用价值的诊断结果。

## 技术方案

### 核心思想

**背景：速度梯度张量为什么重要**

速度梯度张量 $\boldsymbol{A} = \nabla\boldsymbol{u}$ 是流体力学的**核心局域量**：
- 它完整刻画**局地流的应变与转动**；
- 它的**对称部分（应变率）**决定黏性耗散与形状演化；
- 它的**反对称部分（涡量）**决定转动与输运；
- 它是所有**雷诺应力闭合、颗粒受力、条纹动力学、微流控**模型的输入。

**传统方法的困境：空间差分放大噪声**

PIV（粒子图像测速）给出的是**粒子位置**场 $\boldsymbol{x}_p(t)$。球形示踪粒子在流体中跟随速度（Stokes 假设），所以
$$\frac{d\boldsymbol{x}_p}{dt} = \boldsymbol{u}(\boldsymbol{x}_p(t))$$
要得到速度梯度，必须做**空间差分**：
$$\boldsymbol{A}_{ij} = \frac{\partial u_i}{\partial x_j}\approx\frac{u_i(\boldsymbol{x}+\Delta\boldsymbol{e}_j)-u_i(\boldsymbol{x})}{\Delta}$$

**问题所在**：空间差分把**位置测量噪声**（$\sigma_{\text{pos}}$）放大为
$$\sigma_A \sim \frac{\sigma_{\text{pos}}}{\Delta}\quad\text{（差分放大）}$$
同时，位置噪声本身还会通过**粒子轨迹拟合**放大到速度：$\sigma_u \sim \sigma_{\text{pos}}/\Delta t$。

结果是：**噪声被放大两次**（差分 + 时间差分），实测中速度梯度张量的精度远低于速度本身。

**本文的洞见：换个可观测量**

**非球形示踪粒子**（薄片、杆、纤维）在流中不只是被动跟随，还会**转动**。其取向 $\boldsymbol{n}(t)$（单位向量）满足 **Jeffery 型方程**：

$$\dot{\boldsymbol{n}} = \boldsymbol{A}\,\boldsymbol{n} - (\boldsymbol{n}\cdot\boldsymbol{A}\,\boldsymbol{n})\,\boldsymbol{n} + \boldsymbol{\Omega}\times\boldsymbol{n}$$

其中 $\boldsymbol{\Omega}$ 是流体的**角速度**（本征旋转）。对不可压流，$\boldsymbol{\Omega} = \frac{1}{2}\boldsymbol{\omega}$。

这个方程的妙处在于：
1. 它**直接**包含 $\boldsymbol{A}$（我们要求的量）；
2. 它**不含位置**——只有取向；
3. 它的**时间导数**（$\dot{\boldsymbol{n}}$）可以通过**时间差分**获得，噪声放大规律**优于**空间差分。

**为什么 4 个示踪粒子就够？**

设 4 个粒子的取向为 $\boldsymbol{n}_1,\dots,\boldsymbol{n}_4$。每个满足 Jeffery 方程。未知量是 $\boldsymbol{A}$（$3\times3$，但不可压约束去掉 1 个分量 → **8 个独立分量**，加上 $\boldsymbol{\Omega}$ 的 3 个分量…… 但对不可压流 Jeffery 方程可重写为**纯 $\boldsymbol{A}$ 形式**）。

实际上，不可压流的 Jeffery 方程有更简洁的形式：
$$\dot{\boldsymbol{n}} = \boldsymbol{S}\boldsymbol{n} + \boldsymbol{\omega}\times\boldsymbol{n} - \frac{3}{2}\left(\boldsymbol{n}\cdot\boldsymbol{S}\boldsymbol{n}\right)\boldsymbol{n}$$
其中 $\boldsymbol{S}$ 是对称应变率。**不可压性**（$\nabla\cdot\boldsymbol{u}=0$）是关键：它把**对称/反对称部分与取向演化的耦合**简化，使得**取向的瞬时演化足以确定 $\boldsymbol{A}$**。

从 4 个取向各自的时间导数（共 $4\times3=12$ 个方程）可以求解 $\boldsymbol{A}$ 的 8 个独立分量——**超定**（over-determined），因此：
- 天然具备**噪声平均**能力；
- 可以做**最小二乘**并给出**条件数**（用于检测病态）。

**噪声标度优势从何而来？**

- 位置法：速度噪声 $\sim \sigma_{\text{pos}}/\Delta t$（时间差分），梯度噪声 $\sim \sigma_{\text{pos}}/(\Delta t \cdot \Delta x)$（**空间 + 时间双重放大**）
- 取向法：$\dot{\boldsymbol{n}}$ 的噪声 $\sim \sigma_{\text{ang}}/\Delta t$（**仅时间放大**），且 Jeffery 方程对 $\boldsymbol{A}$ 的反演是**良态**的（不涉及空间差分）

最终结论：**最小可达误差 $\propto \sigma^{1/2}$（取向法）vs $\sigma^{1/3}$（位置法）**。这个指数差异在低信噪比实验中意义重大。

**失效模式：取向对齐**

Jeffery 反演的病态条件出现在：**两个相邻示踪粒子的取向趋于平行（或反平行）**。此时两者的取向演化方程提供的信息**高度相关**，反问题矩阵接近奇异。

**这个发现最妙的地方**：该退化**恰好表现为流场可视化中特征性的明暗图案**——因为可视化本身就是靠示踪粒子的取向/散射强度成像的。于是：

> **看到那个明暗图案，就知道重构在哪里不可靠。**

这是一个**自诊断 (self-diagnosing)** 的测量方案——极其优雅的实验设计。

## 公式 / 理论要点

```math
% Jeffery 型方程（非球形示踪粒子的取向动力学）
\dot{\boldsymbol{n}}
= \boldsymbol{A}\boldsymbol{n}
- (\boldsymbol{n}\cdot\boldsymbol{A}\boldsymbol{n})\,\boldsymbol{n}
+ \boldsymbol{\Omega}\times\boldsymbol{n},
\qquad |\boldsymbol{n}| = 1
```

```math
% 不可压流的等价形式（仅用对称应变率 S 与涡量 ω）
\dot{\boldsymbol{n}}
= \boldsymbol{S}\boldsymbol{n}
+ \boldsymbol{\omega}\times\boldsymbol{n}
- \frac{3}{2}\left(\boldsymbol{n}\cdot\boldsymbol{S}\boldsymbol{n}\right)\boldsymbol{n},
\qquad
\boldsymbol{\Omega} = \frac{1}{2}\boldsymbol{\omega}
```

```math
% 4 示踪粒子 → 超定系统（12 个方程 / 8 个独立未知量）
\begin{bmatrix}
\mathcal{J}(\boldsymbol{n}_1)\\
\mathcal{J}(\boldsymbol{n}_2)\\
\mathcal{J}(\boldsymbol{n}_3)\\
\mathcal{J}(\boldsymbol{n}_4)
\end{bmatrix}
=
\begin{bmatrix}
\dot{\boldsymbol{n}}_1\\
\dot{\boldsymbol{n}}_2\\
\dot{\boldsymbol{n}}_3\\
\dot{\boldsymbol{n}}_4
\end{bmatrix},
\qquad
\boldsymbol{J} = \min_{\boldsymbol{A}}\|\boldsymbol{R}(\boldsymbol{A})\boldsymbol{y}-\boldsymbol{d}\|_2
```

```math
% 位置法（对照）：空间 + 时间双重噪声放大
\boldsymbol{A}_{ij}\approx\frac{\boldsymbol{u}(\boldsymbol{x}+\Delta\boldsymbol{e}_j)-\boldsymbol{u}(\boldsymbol{x})}{\Delta},
\qquad
\sigma_u\sim\frac{\sigma_{\text{pos}}}{\Delta t}
\quad\Rightarrow\quad
\sigma_A\sim\frac{\sigma_{\text{pos}}}{\Delta t\,\Delta}
```

```math
% 取向法：仅时间放大
\dot{\boldsymbol{n}}\sim\frac{\sigma_{\text{ang}}}{\Delta t},
\qquad
\sigma_A^{\min}\sim\sigma^{1/2}\ \text{（取向法）}
\quad\text{vs}\quad
\sigma_A^{\min}\sim\sigma^{1/3}\ \text{（位置法）}
```

```math
% 病态条件：相邻示踪粒子取向对齐
\boldsymbol{n}_i \times \boldsymbol{n}_j \to 0
\quad\Longrightarrow\quad
\det\boldsymbol{R}(\boldsymbol{A}) \to 0
\quad\Longrightarrow\quad
\text{反演 ill-conditioned}
```

## 实验与结果

- **方法**: 基于 **Jeffery 型方程**的取向反演。
- **唯一性结果**: 对**不可压流**，速度梯度张量**所有分量**由**参考点邻域内 4 个示踪粒子的取向 + 时间导数**唯一确定；**不使用位置、不使用空间差分**。
- **数值测试**:
  - **涡量**重构精度**优于**位置法 (PTV + 差分)；
  - **应变率**重构精度与位置法**相当**；
  - 最小可达误差标度：$\sigma^{1/2}$（取向）vs $\sigma^{1/3}$（位置）。
- **实验应用（球面 Couette 流）**:
  - 重构在**相邻示踪粒子取向对齐处失效**（反问题病态）；
  - **该退化表现为流场可视化中特征性的明暗图案**——即可视化图案是重构可靠性的**指示器**。
- **测量范围优势**: 只需**参考点附近**的取向测量，**无需整个三维区域的测量**。

## 局限性

- **需要非球形示踪粒子**：依赖 flake/rod 的取向测量，需要专门制粒与成像系统（偏振片 + 滤波等），**不能直接沿用现有的球形 PIV**。
- **取向测量的时间分辨率**：需要取向的时间序列来估计 $\dot{\boldsymbol{n}}$ → 对帧率有要求；高速流场下可能受限。
- **不适用于球形粒子**：这是与主流 PIV 生态的兼容性代价。
- **不可压假设**：唯一性定理依赖不可压条件；**可压流**需扩展。
- **未处理粒子惯性与 Brown 运动**：真实粒子有惯性（尤其大粒子、高流速），Jeffery 方程的 Stokes 假设会偏离；Brown 涨落在极小尺度下也会引入噪声。
- **需要追踪同一批粒子并识别其身份**（跨帧对应），这是 PIV 4D 追踪的常见难点。
- **"邻域内 4 个粒子"是局部量**：本文是**局域**测量方法，不给全场。若需全场 $\nabla\boldsymbol{u}$ 场，必须在每个区域布置足够粒子。

## 实现建议

- **实现难度**: 中 — 数学核心（Jeffery 方程 + 超定最小二乘 + 条件数）是直接的线性代数；主要工作在**实验侧**（非球形示踪粒子的制备与取向成像、跨帧身份关联）。
- **预期性能**: 极好——计算量微不足道（每帧只需解一个 12×8 的最小二乘）；全部收益来自**可观测量**的改变。
- **适用场景**:
  - **微流控与低雷诺数流动**：空间差分在微观尺度上尤其不可靠，取向法优势最大；
  - **高信噪比困难的实验**：$\sigma^{1/2}$ vs $\sigma^{1/3}$ 的差异在弱照明、低粒子密度下决定性；
  - **速度梯度张量的直接测量**：绕流体力、颗粒受力、应变率驱动的形变/聚合、应变率驱动的相分离；
  - **旋转流（球面 Couette、旋转 Couette）**：涡量的准确测量尤其有价值（本文显示涡量精度优于位置法）；
  - **与本轮 [[2026-11-12-arXiv-2611.12007-Phase-Resolved-Turbulence-Pulsatile-Pipe-Flow]] 配套**：后者分析湍流结构生成，本文提供**测量这些结构所需的局域梯度张量**的工具。
- **可复用要点**:
  - **"换可观测量比改善算法更有效"**：同样的测量精度下，"从位置差分"改为"从取向演化反演"，噪声标度从 $\sigma^{1/3}$ 改善到 $\sigma^{1/2}$。这是**方法论层面**的启示——遇到空间微分放大噪声的问题时，先问"有没有更直接携带该信息的可观测量"。
  - **超定设计 (12 方程 / 8 未知)** 是天然的抗噪结构，比方阵反演更稳健，且条件数可直接用于**可信度加权**。
  - **"失效区与可视化特征一一对应"** 是极好的实验设计原则：让**诊断信息内嵌在数据本身**，避免额外的验证实验。本文这一条应推广为自建测量方案的标准检查项。
  - **Jeffery 方程在其他流动中的用途**：非球形示踪子的取向也可用于反推**局部剪切率**（例如在聚合物流变学中测量局部应变率历史）。
