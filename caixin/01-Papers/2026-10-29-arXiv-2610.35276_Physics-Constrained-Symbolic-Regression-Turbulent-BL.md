## 核心贡献

> 用**物理约束符号回归（PCSR）**在**零压梯度湍流边界层**中构造**全剖面解析式**：把经典的对数律与 Prandtl 混合长度作为**物理先验**固定下来，让 PySR 只去识别（i）满足渐近约束的近壁过渡函数、（ii）随 Reynolds 数变化的外层修正。结果是一组**紧致、可解释、可闭式求值**的公式，涵盖 $Re_\tau$ 从 **252 到 72,526** 的 **35 条** DNS/LES/实验剖面。

1. **六阶段渐进式 PCSR**：把「渐近结构」（人为规定）与「函数依赖」（数据识别）严格分离——内层用 $Re_\tau=1272$ 的 DNS，外层 Reynolds 系数用 DNS(492,1272) + LES(957,1561,2118)。
2. **平均速度关系**（显式可写）：
   $$U^+(y^+,Re_\tau)=U_{\rm in}^+(y^+)+\frac{2\Pi_u(Re_\tau)}{\kappa}W(\eta),\qquad W(\eta)=\sin^2\!\frac{\pi\eta}{2}$$
   其中
   $$U_{\rm in}^+(y^+)=\Big[\tfrac{1}{\kappa}\ln(1+\kappa y^+)+B_1\Big]\tanh\!\big[0.14y^+(y^++0.94)^{-0.15}\big],\quad B_1=B-\tfrac{\ln\kappa}{\kappa}=7.175$$
   $$\Pi_u(Re_\tau)=0.67\tanh\!\big(0.0076\,Re_\tau^{0.76}\big)$$
3. **有效混合长度关系**：
   $$\ell^+(y^+,Re_\tau)=\kappa y^+f_{\ell,\rm in}(y^+)f_{\ell,\rm out}(\eta,Re_\tau)$$
   $$f_{\ell,\rm in}(y^+)=0.46\big[\tanh(0.035y^+)+0.48\big]^2\tanh\!\big[\sqrt{y^+}\sqrt{0.25y^++0.57}\big]$$
   $$f_{\ell,\rm out}(\eta,Re_\tau)=\tanh\!\left[\frac{\Pi_\ell(\eta,Re_\tau)}{\eta+0.0267}\right]$$
   $$\Pi_{\ell,0.2}(Re_\tau)=0.229+\tanh\!\left[\left(\frac{180.01}{Re_\tau+34.10}\right)^{3}\right],\qquad
   \Pi_\ell(\eta,Re_\tau)=0.229+\big[\Pi_{\ell,0.2}-0.229\big]\tanh\!\left[\left(\tfrac{0.3}{\eta}\right)^{4}\right]$$
4. **渐近一致性被显式验证**：$U^+/y^+\to1.01$（要求 1）；$f_{u,\rm in}\to1$（对数区）；$W(\eta)=O(\eta^2)$；$\ell^+$ 近壁指数 **3/2**（$\approx0.080\sqrt{y^+}$，DNS 估 0.075、van Driest 型估 0.092）；$f_{\ell,\rm in}\to1.008\approx1$。
5. **单文件、可解释、无需机器学习运行时**：相比 POD/神经网络代理，符号回归给出的是**闭式解析式**，可直接嵌入 CFD 求解器或 RANS 闭合。

## 技术方案

### 核心思想

**问题**：ZPG 湍流边界层的近壁区、过渡（重叠）区、外层区有**不同的标度行为**；要构造**全剖面**解析式，必须同时满足三处渐近约束，而中等 Reynolds 数下尺度分离不完全，重叠区有限，使连续全剖面关系难以构造。此外，**平均速度相似性并不蕴含 Reynolds 剪切应力相似性** → 有效混合长度的标度不能从平均速度相似性推断。

**思路**：把经典标度关系当作**物理先验**（不可由数据改变的部分），只把「过渡函数」与「外层修正」交给符号回归。即：

- **规定**（人工）：对数律结构、Coles 尾流形状、近壁线性律指数、混合长度近壁 3/2 次幂、外层衰减形式。
- **识别**（数据）：过渡函数的具体形式与系数、外层修正的 Reynolds 依赖。

### 关键技术

| 技术 | 说明 |
|------|------|
| 符号回归框架 | **PySR**（进化搜索：选择、变异、交叉、常数数值优化）；表达式树；复杂度与精度同时考量 |
| 候选算子 | 一元：$\tanh(x_i),\ln(x_i),\exp(x_i),\sqrt{x_i},(1+x_i)^{-1}$；二元：$x_i+x_j,\ x_i-x_j,\ x_ix_j,\ x_i/x_j,\ x_i^{x_j}$ |
| 损失函数 | $\mathcal L=\alpha_1\langle(Y_{\rm pred}-Y_{\rm data})^2\rangle+\alpha_2\langle|(Y_{\rm pred}-Y_{\rm data})/Y_{\rm data}|\rangle+\alpha_3\mathcal L_C$，软约束搜索中 $\alpha_1=\alpha_2=1$、$\alpha_3=10$；表达式复杂度由 PySR 单独处理 |
| 物理信息三途径 | (i) **规定解析结构**保留渐近标度；(ii) 阶段特异的**软惩罚** $\mathcal L_C$；(iii) 拟合后**检查适用极限** |
| 六阶段流程 | ① 速度内层 ② 混合长度内层 ③ 速度外层（Coles 尾流）④ 混合长度外层（乘性衰减）⑤ 速度 $Re_\tau$ 修正（提取 $\Pi_u$）⑥ 混合长度 $Re_\tau$ 修正（提取 $\Pi_\ell$）。**配对阶段共享同一训练数据** |
| 尾流标定 | Coles 形状**不**参与符号搜索，而是以最小二乘标定 $\Pi_u\approx0.67$（$Re_\tau=1272$ DNS，$0.1<\eta<1$）——这是「物理结构优先」的体现 |
| 训练数据 | 内层：DNS $Re_\tau=1272$，$y^+<30$；外层：同剖面 $0.1<\eta<1$；$Re_\tau$ 系数：DNS(492,1272) + LES(957,1561,2118) |
| 参考数据库 | 35 条剖面：DNS 10 条（$Re_\tau$ 252–1272，Schlatter & Örlü）、LES 11 条（457–2479，Eitel-Amor et al.）、NSTAP 实验 7 条（2622–72,526）、Pitot 实验 7 条（2841–65,129），均取自 Vallikivi et al.；混合长度仅用 21 条数值剖面（实验无剪切应力） |
| 坐标约定 | $y^+=yu_\tau/\nu$、$U^+=U/u_\tau$、$\eta=y/\delta$、$Re_\tau=u_\tau\delta/\nu$；$\delta$ 由 $U(\delta)=0.99U_e$ 定义；绘图分区边界 $y^+=5,\ y^+=30,\ \eta=0.3$（仅可视化，非物理锐变） |

## 公式

### 1. 无量纲化

```math
y^{+}=\frac{yu_{\tau}}{\nu},\qquad U^{+}=\frac{U}{u_{\tau}},\qquad
\eta=\frac{y}{\delta},\qquad Re_{\tau}=\frac{u_{\tau}\delta}{\nu},\qquad \eta=\frac{y^{+}}{Re_{\tau}}
```

### 2. 有效混合长度定义（由 Reynolds 剪切应力与速度梯度反演）

```math
\ell^{+}=\left[\frac{-\overline{u'v'}^{+}}{\left(\mathrm{d}U^{+}/\mathrm{d}y^{+}\right)^{2}}\right]^{1/2},
\qquad \overline{u'v'}^{+}=\frac{\overline{u'v'}}{u_{\tau}^{2}}
```

### 3. 物理约束符号回归的损失

```math
\mathcal{L}=\alpha_{1}\left\langle\left(Y_{\mathrm{pred}}-Y_{\mathrm{data}}\right)^{2}\right\rangle
+\alpha_{2}\left\langle\left|\frac{Y_{\mathrm{pred}}-Y_{\mathrm{data}}}{Y_{\mathrm{data}}}\right|\right\rangle
+\alpha_{3}\mathcal{L}_{C}
```

### 4. 平均速度：正则化对数基线 + 近壁乘子 + Coles 尾流

```math
U_{\rm r}^{+}(y^{+})=\frac{1}{\kappa}\ln(1+\kappa y^{+})+B_{1},\qquad
B_{1}=B-\frac{\ln\kappa}{\kappa}=7.175\quad(\kappa=0.41,\ B=5.0)
```

```math
f_{u,\rm in}(y^{+})=\tanh\!\left[0.14y^{+}(y^{+}+0.94)^{-0.15}\right]
\quad\left(\sim 0.14\,(y^{+})^{0.85}\ \text{在近壁}\right)
```

```math
U^{+}(y^{+},Re_{\tau})=U_{\rm in}^{+}(y^{+})+\frac{2\Pi_{u}(Re_{\tau})}{\kappa}W(\eta),\qquad
W(\eta)=\sin^{2}\!\left(\frac{\pi\eta}{2}\right)
```

```math
\Pi_{u}(Re_{\tau})=0.67\tanh\!\left(0.0076Re_{\tau}^{0.76}\right)
```

渐近核验：

```math
\lim_{y^{+}\to0}\frac{U^{+}}{y^{+}}\approx1.01\ \ (\text{要求为 }1),\qquad
\tanh\!\big(0.14(y^{+})^{0.85}\big)\to1,\qquad W(\eta)=O(\eta^{2})
```

### 5. 平均速度：有效尾流系数的反演

```math
\Pi_{u}^{\rm eff}(\eta,Re_{\tau})=\frac{\kappa\left[U_{\rm data}^{+}-U_{\rm in}^{+}\right]}{2W(\eta)}
```

### 6. 有效混合长度：内层乘子

```math
\ell_{\rm in}^{+}(y^{+})=\kappa y^{+}f_{\ell,\rm in}(y^{+})
```

```math
f_{\ell,\rm in}(y^{+})=0.46\left[\tanh(0.035y^{+})+0.48\right]^{2}\times\tanh\!\left[\sqrt{y^{+}}\sqrt{0.25y^{+}+0.57}\right]
```

```math
f_{\ell,\rm in}(y^{+})\sim0.46(0.48)^{2}\sqrt{0.57}\,(y^{+})^{1/2}\approx0.080\,(y^{+})^{1/2}
\quad\Longrightarrow\quad \ell^{+}\sim (y^{+})^{3/2}
```

```math
y^{+}\to\infty:\quad f_{\ell,\rm in}\to1.008\approx1
```

### 7. 有效混合长度：外层乘性衰减 + Reynolds 依赖

```math
\ell^{+}(y^{+},Re_{\tau})=\kappa y^{+}f_{\ell,\rm in}(y^{+})f_{\ell,\rm out}(\eta,Re_{\tau})
```

```math
f_{\ell,\rm out}(\eta,Re_{\tau})=\tanh\!\left[\frac{\Pi_{\ell}(\eta,Re_{\tau})}{\eta+0.0267}\right]
```

```math
\Pi_{\ell}^{\rm eff}(\eta,Re_{\tau})=(\eta+0.0267)\operatorname{arctanh}\!\left[\frac{\ell_{\rm data}^{+}}{\kappa y^{+}f_{\ell,\rm in}(y^{+})}\right]
```

```math
\Pi_{\ell,0.2}(Re_{\tau})=0.229+\tanh\!\left[\left(\frac{180.01}{Re_{\tau}+34.10}\right)^{3}\right]
```

```math
\Pi_{\ell}(\eta,Re_{\tau})=0.229+\left[\Pi_{\ell,0.2}(Re_{\tau})-0.229\right]\tanh\!\left[\left(\frac{0.3}{\eta}\right)^{4}\right]
```

（$\eta\to0$ 时第二个 $\tanh$ 取 1；$Re_\tau\to\infty$ 时 $\Pi_\ell\to0.229$。）

### 8. 经典参照式

```math
U^{+}=\kappa^{-1}\ln y^{+}+B,\qquad \ell^{+}=\kappa y^{+},\qquad
\ell^{+}=\kappa y^{+}\left[1-\exp(-y^{+}/A)\right]\ \text{(van Driest, }A_1=17\text{)}
```

## 实验结论

### 渐近核验表

| 极限/核验 | 要求行为 | 本文表达式 | 参考值 |
|---|---|---|---|
| $y^+\to0$：$U^+/y^+$ | $\to1$ | **1.01** | — |
| 对数区：$f_{u,\rm in}$ | $\to1$ | $\tanh(0.14(y^+)^{0.85})\to1$ | — |
| 内层尾流：$W(\eta)$ | $o(\eta)$ | $O(\eta^2)$ | — |
| $y^+\to0$：$f_{\ell,\rm in}/\sqrt{y^+}$ | — | **0.080** | DNS ≈ 0.075；van Driest 型 ≈ 0.092 |
| $y^+\to0$：$\ell^+$ 指数 | 3/2 | 3/2 | 3/2 |
| 重叠区：$f_{\ell,\rm in}$ | 1 | **1.008** | — |

**近壁 3/2 次幂的推导链**：近壁 Reynolds 剪切应力 $-\overline{u'v'}^{+}=O((y^{+})^{3})$、且 $\mathrm dU^+/\mathrm dy^+\to1$ → 由混合长度定义反演得 $\ell^+\sim(y^+)^{3/2}$ → 要求 $f_{\ell,\rm in}\propto(y^+)^{1/2}$。**指数由物理决定，过渡函数与前导幅值由符号回归决定**（论文明确区分）。

### Reynolds 数依赖

- **速度尾流系数**：单剖面最小二乘给 $\Pi_u\approx0.67$（$Re_\tau=1272$）。用 $\eta=0.9$ 处提取的各剖面系数与拟合式 (8) 对比：NSTAP 与 Pitot 估计在高 $Re_\tau$ 仍**可区分**。软惩罚（权重 10）在 $2000\le Re_\tau\le20000$ 的对数等距点上把系数导向 0.67；多剖面表示在 $Re_\tau=1272$ 给出 **0.630**（因标定目标不同）。
- **混合长度外层系数**：$Re_\tau=1272$ 参考剖面上拟合得 $\Pi_\ell=0.229$，被**采纳为高 $Re_\tau$ 的规定极限**（非独立确立的普适常数）。向该区制的过渡**名义上**置于 $Re_\tau\approx1200$。软惩罚权重 10，**不强制** $Re_\tau>1200$ 以上的平台。
- **单系数近似的适用性核验**：$\Pi_u^{\rm eff}(\eta,Re_\tau)$ 与 $\Pi_\ell^{\rm eff}(\eta,Re_\tau)$ 在壁法向上的变化证明**每条剖面用一个系数**是一个近似：低 $Re_\tau$ 下变化明显（$0.2<\eta<0.8$ 上递减，但既非严格线性也非跨算例一致）；$\eta<0.2$ 时外因子已接近 1，推断系数影响很弱；$\eta>0.8$ 时速度梯度变小，**剪切-梯度反演变得敏感**。选取内部区间 $\eta=0.2,0.4,0.6$ 的推断值构成参考系数。

### 拟合/验证策略的诚实性说明

- **训练集**：DNS $Re_\tau=1272$（$y^+<30$ 内层；$0.1<\eta<1$ 外层）+ DNS(492,1272) 与 LES(957,1561,2118) 用于 Reynolds 系数。
- **其余剖面为 out-of-fit 对比**，但论文明确指出**它们不构成统计独立的验证集**（"not a statistically independent validation set"）。
- **比较结果**：完整速度关系对 35 条剖面（DNS/LES/NSTAP/Pitot）总体吻合良好，但**外层实验数据仍存在偏差**。混合长度关系捕捉到 21 条 DNS/LES 剖面的**主要壁法向趋势**（评价为**定性**）。

### 常数与结构说明

- $\kappa=0.41$、$B=5.0$ 被明确声明为**建模输入**，不是本文独立确定的普适常数；$0.67$、$0.229$ 同理。

## 局限性

1. **常数是建模输入而非普适量**：$\kappa=0.41$、$B=5.0$、高 $Re_\tau$ 的 $\Pi_u\to0.67$ 与 $\Pi_\ell\to0.229$ 均为**规定值**，本文未独立验证。
2. **「out-of-fit」不等于独立验证**：训练用的 DNS/LES 剖面与用于对比的剖面来自同一批数据库，分割方式并非按独立实现划分 → 泛化性证据弱于真正的留出验证。
3. **混合长度关系的评估是定性的**：论文明确写「assessment is qualitative and limited to the datasets considered here」；混合长度的前导系数（0.080）与 DNS 估计（0.075）和 van Driest 估计（0.092）**存在明显偏差**。
4. **每条剖面一个外层系数是近似**：$\Pi^{\rm eff}$ 在壁法向上明显变化，尤其低 $Re_\tau$；$\eta>0.8$ 处反演病态。
5. **未做 a posteriori 耦合湍流闭合评估**：论文明确「does not constitute an a posteriori evaluation of a coupled turbulence closure」——公式的稳定性、收敛性、与数值格式的交互**完全未检验**。
6. **仅限不可压 ZPG 边界层**：不含压力梯度、粗糙壁、可压缩性、三维效应。
7. **未量化超参敏感性**：软惩罚权重（10）、约束评估点、算子集合的选择对最终表达式的影响未做消融。
8. **正则化对数基线的形状选择是先验**（$\ln(1+\kappa y^+)$），这一选择本身未与其他正则化形式对比。

## 实现建议

- **实现难度**：低到中。PySR 搜索本身成本可控（离线），最终产物是**闭式解析式**——运行期零依赖、零推理开销，只需几十行代码即可实现全部公式。
- **预期性能**：$Re_\tau\in[252,\,72526]$ 范围内的平均速度全剖面与 35 条 DNS/LES/实验剖面总体吻合（外层实验有残余偏差）；有效混合长度捕捉 21 条数值剖面的主要趋势；渐近指数 $U^+\sim y^+$、$\ell^+\sim(y^+)^{3/2}$、$f\to1$ 均被满足（$U^+/y^+\to1.01$、$f_{\ell,\rm in}\to1.008$、$f_{\ell,\rm in}/\sqrt{y^+}\approx0.080$）。
- **适用场景**：
  1. **RANS 闭合的混合长度模型**：直接替代 van Driest + 常数外层衰减的经典写法，且**保持可解释与可审查**。
  2. **湍流边界层的快速解析评估**：作为工程近似替代 $y^+$ 插值表（如 Wilson 拟合）。
  3. **教学与机理教学工具**：公式短小、物理意义清晰，每个系数都有对应的渐近约束来源。
  4. **作为 AI 湍流模型的对照基线**：比黑箱代理更严格，可检验「可解释性是否以精度为代价」。
- **落地建议**：
  1. **用本文范式而非端到端回归**：这是全文的核心可迁移性。**先规定渐近结构（人工），再让符号回归只填函数依赖**。直接对数据做无约束符号回归几乎必然得到违反渐近的表达式。
  2. **公式可即插即用**，但落地前必须做两件事：(a) 用**自己的**剖面（目标 $Re_\tau$、目标粗糙度）重新标定 $\Pi_u$ 与 $\Pi_\ell$；(b) 检查渐近极限（$U^+/y^+$、$f\to1$、3/2 指数）。
  3. **必须区分「内层乘子」与「外层乘子」两个阶段**，且外层修正必须**乘性**（保持内层函数不变）；若与内层耦合求解，会破坏已识别的渐近结构。
  4. **软惩罚的权重（10）与评估点位置是重要的建模决策**，落地时应对权重做敏感性扫描。
  5. **不要声称这是通用关系**：论文自己强调 $\kappa$、$B$、$0.67$、$0.229$ 是建模输入。若要迁移到压力梯度流、粗糙壁或可压缩边界层，需重新做约束设计与标定。
  6. **若要把它当作 CFD 闭合使用，必须补做 a posteriori 稳定性与收敛性评估**——这是本文明确未做的部分，也是最容易被忽略的坑。
  7. **与本库关联**：与 [[Physics-Constrained-Symbolic-Regression-Turbulent-BL]] 的姊妹篇关系；与 [[Generative-AI-in-Turbulence]]（2610.35123）中「物理先验 + 数据驱动」的哲学一脉相承（后者主张物理信息可通过损失罚项、条件化、引导、投影算子等嵌入生成模型）——可视为「物理先验」在符号回归与生成模型两条路线上的平行实践。

## 推荐结论

> **✅推荐实现**（作为可解释的解析壁湍流关系与 RANS 混合长度闭合的起点），但**不可**直接当作已验证的通用闭合。
