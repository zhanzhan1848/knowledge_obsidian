# 多粒径泥沙输运与分选：LES 耦合框架

**arXiv**: [2610.29072](https://arxiv.org/abs/2610.29072) · **提交**: 2026-10-21 01:53 UTC
**篇幅**: — · **类别**: Fluid Dynamics (physics.flu-dyn); Geophysics (physics.geo-ph)

## 一句话总结

**LES + 多粒径泥沙输运模块**耦合框架：追踪多个粒径级、各级在**推移质层内的局部占比**与河床演变 —— 相比均匀粒径模型，最大冲刷深度误差从 **37.98% 降到 3.83%**，最大淤积高度误差从 **48.35% 降到 11.54%**。

---

## 核心贡献

1. **多粒径输运框架**：同时处理多个粒径级、推移质层内的局部粒径分布、床面演变
2. **实验验证**：水槽试验（多粒径床料），用实测粒径分布与床面高程验证
3. **定量对比统一粒径模型**：误差大幅下降
4. **大尺度应用**：弯曲河道中再现**粒径分选图式** —— 粗颗粒富集于冲刷凹槽，细颗粒富集于点坝（point bar）

## 数值方法评估

🥢 **可行性分析：LES 耦合多粒径泥沙输运**

### 控制方程
- **流体**：不可压缩 N-S，**大涡模拟 (LES)**（亚格子模型未在摘要披露）
- **泥沙**：多相流（流体 + 多个粒径级的固体相），相间耦合含浮力、拖曳、举升
- **床面**：形态动力学（morphodynamics）—— 床面高程随输沙通量演化
- **关键额外状态量**：各级泥沙在**推移质层内的局部占比**（这是多粒径模型的核心，均匀粒径模型没有）

### 数值方法
- **离散化**：有限体积 + 泥沙输运模块；床面演变用 Exner 型方程
- **求解器**：⚠️ 未披露；LES 需显式时间推进 + SGS 模型
- **稳定性**：床面演变是**双曲-椭圆混合**问题（冲刷可致发散）→ 需负体积修正/床面坡度限制

### 计算成本
| 维度 | 评估 |
|------|------|
| 网格 | 大尺度弯曲河道 → 大域；近床需加密以解析推移质层 |
| 时间步 | LES CFL + 床面演化步长（形态动力学通常需**长时间积分**，与 LES 短时步冲突 → 常用**形态动力学加速 (morphodynamic acceleration)**） |
| 相数 | 相数 = 1 流体 + N 粒径级 → N 越大成本越高 |
| 并行性 | 显式推进 → 良好 |

### 适用场景
- 弯曲河道形态动力学、桥墩冲刷
- 河口/海岸泥沙分选
- 防洪工程与基础设施保护

## 推荐结论

✅ **推荐实现**

**理由**：
1. **定量收益极大**：冲刷深度误差 **10× 改善** —— 这是 CFD 工程中罕见的大幅提升，说明「多粒径」不是细节而是决定性因素
2. **实验 + 数值双重验证**，可信度高
3. **物理图式合理**：粗颗粒留在冲刷槽、细颗粒被带到点坝 → 与现场观测一致
4. **可迁移**：多粒径思想适用于任何「颗粒级配影响输运」的问题（滑坡、泥石流、选矿）

**注意事项**：
- ⚠️ **LES + 形态动力学的步长冲突**是最大工程障碍 → 需确认论文是否用了 morphodynamic acceleration
- ⚠️ SGS 模型未在摘要披露 → 需查全文（对近床输运影响大）
- ⚠️ 「推移质层内局部占比」的建模（分层假设）是经验性的，不同泥沙可能需重新标定

**对 @墨鱼丸 的实现建议**：
1. **适合作为 OpenFOAM 扩展的验证算例**：OpenFOAM 有 `sedimentFoam` / `multiphaseEulerFoam` 基础
2. **实施难度高**：相数多 + 床面耦合 + 长时积分
3. **建议路径**：先做**二维直槽**多粒径 vs 均匀粒径对比 → 复现误差改善趋势 → 再上弯曲河道
4. **判据**：复现最大冲刷深度误差从 ~38% 降至 ~4% 量级
