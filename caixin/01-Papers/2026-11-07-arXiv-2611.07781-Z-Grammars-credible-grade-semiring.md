## 核心贡献

> **⚠️ 注意：本文属于 `cs.FL`（形式语言与自动机理论），与流体力学无关。** 这是本分类的**持续误标问题**。

1. 模糊文法与加权自动机通常给每个词一个**单一等级**（grade），记录该词被生成的强度，但**不记录该记录有多可信**
2. 引入 **Z-number 启发的标量「等级-可靠性」对**：顺序组合乘两个分量；聚合按**可信等级**（grade × reliability）选择推导，并列时以 grade 决胜
3. 规范载体上（零 grade 或零 reliability 都归零）该结构是**交换选择半环**，同构于字典序乘积的子半环；其可信等级投影是到 **Viterbi 半环**的同态
4. 证明**正可信等级截断**与**选中运行可靠性滤波**对有限自动机是**正则且可有效构造**的
5. 展示了标量投影**看不到**的区别

## 技术方案

### 核心思想

**动机**：加权文法/自动机的一个词只带一个标量等级，无法表达「这个判断有多可靠」。

**Z-number 启发**：权重是标量对（grade, reliability）。组合规则：
- **顺序组合**：两个分量都相乘
- **聚合**：按**可信等级** = grade × reliability 选择推导，并列时以 grade 决胜

**规范载体**：零 grade 或零 reliability 都识别为零 → 得到交换选择半环（commutative selective semiring），同构于字典序乘积的一个子半环。

**投影**：`credible-grade` 投影是到 Viterbi 半环的**同态**。

**标量投影看不见的三类区别**（论文的实质贡献）：
1. 某个可靠性滤波**无法**由同一台单状态自动机的标量重加权实现
2. 在添加运行（run）时**非单调**
3. 一个无歧义自动机**没有确定性等价物**，尽管其标量投影是确定性的

### 关键技术

| 技术 | 说明 |
|------|------|
| **Z-number 对权重** | (grade, reliability) 标量对 |
| **可信等级** | grade × reliability（聚合选择依据） |
| **规范载体** | 零 grade 或零 reliability ≡ 0 |
| **交换选择半环** | commutative selective semiring |
| **Viterbi 半环同态** | 可信等级投影 |
| **有理刻画** | 加权自动机的标准结果给出 rational characterization + 闭包性质 |
| **正则性定理** | 正可信等级截断、选中运行可靠性滤波 → 正则且有效可构造 |
| **实例** | 基于计数的例子展示文法规则的「attestation penalty」 |

### 公式

**权重**：$w=(g,r)\in\mathbb{R}\times\mathbb{R}$，grade $g$，reliability $r$

**顺序组合**：$(g_1,r_1)\otimes(g_2,r_2)=(g_1g_2,\ r_1r_2)$

**可信等级**：$\text{cg}(g,r)=g\cdot r$

**聚合（选择）**：$\oplus$ 选出可信等级最大者，**并列时以 grade 决胜**

**规范载体**：$(0,r)\equiv(g,0)\equiv 0$

**投影**：$\pi_{\text{cg}}:(\text{grade},\text{rel})\mapsto g\cdot r$ → 到 Viterbi 半环的同态
