## 核心贡献

> 提出 **CBTV**（Colour Bean Tracking Velocimetry）：免训练的多遍追踪方法，用**多色粒子**的邻域星团上下文解决致密颗粒流中身份丢失问题

1. 动机：致密颗粒流中，帧间位移可**接近甚至超过颗粒间距**，要求极高帧率；且碰撞后常规速度预测失效
2. 方法：**先把相邻彩色颗粒的"星座（constellation）"整体匹配为单元**（由互相关运动先验引导），**再**对剩余颗粒逐个分配
3. 评估：与 **12 种基线追踪器配置**对比（经典 linker、GNN、Transformer），测试 **15 组仿真离散元颗粒流的 59 个算例**，具有精确 ground truth（位移 0.006–9 直径/帧）
4. 结果：CBTV 在**冲击碰撞**场景下于所有位移上**匹配或超过**全部被测追踪器
5. 优势区间：**每帧位移约为颗粒间距的 0.5–2 倍**（帧间关联歧义区）；超过约 2–3 个直径/帧后，依赖体运动补偿的追踪器更准

## 技术方案

### 核心思想

致密流动中，单颗粒的速度预测在碰撞后失效——这是 PTV 失败的根本原因。CBTV 引入**颜色**作为额外信息维度：彩色颗粒的**邻域配色星座**在运动中保持更强的可辨识性，先做星团级匹配，大幅降低歧义，再做个体分配。

### 关键技术

| 技术 | 说明 |
|------|------|
| 多遍（multi-pass）匹配 | 第一遍星团级，第二遍个体级 |
| 星座匹配 | 邻接彩色颗粒集合作为整体单元匹配 |
| 互相关运动先验 | 由图像互相关给出全局/局部运动引导 |
| 颜色松弛追踪器 | 同类思路的对照实现（同样利用邻域上下文） |
| 12 种基线 | 从经典 linker 到 GNN/Transformer 追踪器 |

## 公式

```math
第一遍（星团级）:
  对每个候选星团 C_i（邻接彩色颗粒集合）与上一帧候选星团 C_j:
  匹配分数 S(i,j) = α·S_color(i,j) + β·S_geom(i,j) + γ·S_motion(i,j)
  S_color  基于颜色标签一致性
  S_geom  基于相对几何构型
  S_motion 基于互相关运动先验
  求解一对一匹配（匈牙利 / 贪心）

第二遍（个体级）:
  对未匹配的剩余颗粒, 用常规 PTV 速度预测 + 最近邻分配

判别准则:
  密实度参数 = 每帧位移 / 颗粒间距
  CBTV 优势区间 ≈ [0.5, 2]
```

## 代码片段

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def build_constellations(positions, colors, adjacency_radius):
    """构建邻接彩色颗粒星座（星团）"""
    constellations = []
    n = len(positions)
    for i in range(n):
        d = np.linalg.norm(positions - positions[i], axis=1)
        neigh = np.where((d < adjacency_radius) & (d > 1e-9))[0]
        constellations.append((i, tuple(sorted(neigh)), tuple(colors[neigh])))
    return constellations

def match_pass1(constellations_prev, constellations_cur,
                motion_prior, w_color=1.0, w_geom=1.0, w_motion=1.0):
    """星团级匹配：颜色+几何+运动先验的综合打分 + 一对一指派"""
    cost = np.zeros((len(constellations_cur), len(constellations_prev)))
    for j, c in enumerate(constellations_cur):
        for i, p in enumerate(constellations_prev):
            s_color = color_match_score(c[2], p[2])
            s_geom  = geom_match_score(c[1], p[1])
            s_mot   = motion_prior(j, i)
            cost[j, i] = -(w_color*s_color + w_geom*s_geom + w_motion*s_mot)
    r, c = linear_sum_assignment(cost)
    return dict(cur2prev=r, prev2cur=c)

def match_pass2(remaining_cur, remaining_prev, velocity_pred):
    """个体级匹配：速度预测 + 最近邻（碰撞后失效，故仅用于未匹配残余）"""
    cost = np.linalg.norm(remaining_cur[:, None, :] -
                          remaining_prev[None, :, :] - velocity_pred[:, None, :], axis=2)
    r, c = linear_sum_assignment(cost)
    return r, c
```

## 实验结论

- **数据集**: 15 组仿真离散元（DEM）颗粒流，59 个算例，**精确 ground truth**；位移范围 0.006–9 直径/帧
- **基线**: 12 种追踪器配置（经典 linker、GNN、Transformer 等）
- **结果**:
  - **冲击碰撞**场景：CBTV 在**所有位移**上匹配或超过全部追踪器
  - 优势区间：每帧位移 **0.5–2 倍颗粒间距**（关联歧义区）
  - 搅拌剪切流（agitated shear flow）：**颜色松弛追踪器**匹配或略微超过 CBTV（同用邻域上下文）
  - 关联明确时 CBTV 接近最佳追踪器
  - 超过约 **2–3 个直径/帧**后，**补偿体运动的追踪器更准确**（超出 CBTV 的运动先验范围）

---

## 局限性

- 需要颗粒**有颜色区分**，实验上需制备彩色颗粒
- 每帧位移 > 2–3 直径时优势丧失（运动先验范围限制）
- 纯算法型（免训练）方法，在极端密集下不及学习型方法
- 仅二维仿真 DEM 验证，真实三维实验验证待做

## 实现建议

- **实现难度**: 中（多遍匹配 + 星团构建 + 指派求解）
- **预期性能**: 免训练、免 GPU；星团级匹配显著降低关联歧义，计算量与候选对数量线性相关
- **适用场景**: 致密颗粒/颗粒-流体混合流的实验诊断，可**显著降低对超高帧率的硬件要求**
- 推荐结论：✅ 推荐实现——若已有（或可制备）彩色颗粒，CBTV 是低成本高回报的实验诊断改进
