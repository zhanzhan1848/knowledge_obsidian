# 流体–孔弹性结构相互作用 FEM 模型（耗散界面）

## 核心贡献

扩展作者先前工作（两孔弹性域之间界面条件）到**多孔弹性域 ↔ 纯流体**的情形：

1. **混合理论（mixture theory）** 描述可变形多孔介质，各组分单独满足自己的平衡方程，通过**相间动量交换（阻力）项**耦合
2. **ALE（任意拉格朗日–欧拉）格式** 同时用于流体域与多孔域
3. **耗散界面**：界面动量跳跃条件由 Hamilton 原理导出，纳入预设耗散行为

## 建模选择对比：为什么用混合理论而非 Biot

| | Biot 理论 | 混合理论（本文） |
|---|---|---|
| 多孔流体描述 | 单一有效压力 + Biot–Willis 耦合系数 | 各相独立速度场与应力状态 |
| 优点 | 紧凑、研究充分 | **能解析各组分的独立动力学与动量交换** |
| 局限 | **只给体平均速度与单压力场** | 复杂度更高 |

**混合理论的优势在界面处最突出**：两个多孔弹性混合物相互作用、或生物组织/工程支架用双相模型时，混合理论能自然给出所需的界面条件形式。

## 界面条件体系（三类）

### 1. 法向通量连续（最常用）
自由流体速度法向分量 = 孔弹性域离开的总通量法向分量。直接来自界面质量守恒（界面不储存/不产生流体）。

### 2. 法向应力（微妙）
- **经典版**（Showalter）：自由流体的**总 Cauchy 应力**与孔弹性介质总应力平衡
- **严格两尺度均质化版**：**压力不要求连续**，存在压力跳跃，取决于渗透率与自由流体界面切向应变率（已由孔隙尺度 DNS 证实）

### 3. 切向条件（历史上最有争议）
- **Beavers–Joseph 条件**：经验式，通道流实验导出，把自由流体切向剪切应力与（切向自由流体速度 − 切向过滤速度）之差联系起来，比例系数为依赖孔微观结构的无量纲滑移系数
- **Saffman 条件**：不同标度假设下的一致版本

## 本文的接口建模

- 流体速度与压力场**允许在界面间断**
- 定义**全局连续的位移场**，同时代表多孔介质固体骨架变形与纯流体域的网格运动
- 界面条件：
  - **过滤速度法向连续** → 通过 **Lagrange 乘子**强制
  - **混合物动量跳跃条件** → 将流体侧牵引力传递给多孔域
  - **耗散行为**：界面被赋予耗散特性，动量跳跃条件由 Hamilton 原理导出并纳入该预设行为
- 耗散项：与**过滤速度跳跃的范数**成正比 → 可理解为对该跳跃的惩罚
- 增大参数 $\mu_{\mathcal{S}}$ → 解趋向过滤速度连续的情形

## 数值方法

| 项 | 设置 |
|---|---|
| 软件 | **COMSOL Multiphysics®**（FE 编程环境） |
| 耦合方式 | **monolithic 求解器**（单体） |
| 时间推进 | 变步长、变阶 **BDF** |
| 网格 | 相容（conformal）界面：由单元边界构成 |
| 网格运动 | **ALE + 准静态弹性等效实现**；纯流体域用**可压缩 Yeoh 超弹性**网格模型：$\hat{\Psi}_s^+=c_1(\bar I_1^+-3)+c_2(\bar I_1^+-3)^2+\frac{1}{2}K(J_s^+-1)^2$，$c_1=1$ Pa，$c_2=2.5$ Pa，$K=1$ Pa |
| 非线性求解 | **Newton 法**，自动阻尼因子 |
| 线性求解 | **MUMPS** 直接求解器 |
| 收敛判据 | 解基与残基估计相对误差取小；相对容差 $10^{-3}$，残差缩放因子 $10^3$ |

### 有限元空间选择（本文的实用贡献）

| 场 | 插值 |
|---|---|
| 全局连续位移场 | **2 阶 Lagrange（P2）** |
| 流体速度（孔隙域 + 自由流体） | **2 阶 Lagrange（P2）**（因界面间断，不要求连续） |
| 压力 $p$ | **1 阶 Lagrange（P1）**（界面间断） |
| 界面乘子 $\mathfrak{p}$ | **1 阶 Lagrange（P1）** |

### 验证
- **制造解法（MMS, Salari & Knupp 2000）**：纯流体域叠在孔弹性域之上的 2D 几何
- **网格**：全等三角形，**5 级均匀加密**，初始 $h=2.5$ mm
- 时间积分：2 阶 BDF，最大常步长 $5\times10^{-4}$ s
- 报告 $L^2$ 范数与 $H^1$ 半范数的相对误差（按各量定义域分别积分）
- **收敛率与 Navier–Stokes 问题典型收敛率相当**（作者注明尚无最优性严格分析）

### 算例（界面模型对比）
- 网格：全等三角形 $h=1.56\times10^{-1}$ mm，界面附近加 **8 层边界层**，拉伸因子 1.2
- 最大步长 $10^{-2}$ s
- 对比**惰性界面（inert）** 与**完全耗散界面**
- **经典跳跃条件基准问题**：成功复现解析解

## 主要结论

1. MMS 经验证确立**收敛性**，并给出**一组实用的稳定有限元空间**
2. 通过调节界面处规定的本构响应，复现了"刚性多孔介质流动"经典问题的多项既定结果
3. **界面模型的选择对系统行为有显著影响** ← 这是本文最实用的提醒

## 评估

✅ **实用价值**：给出了可直接复用的 FE 空间选择（P2/P2/P1）、ALE 网格运动的 Yeoh 实现、COMSOL+MUMPS 技术栈
✅ **方法学严谨**：MMS 验证 + 基准解析解双重确认
✅ **界面耗散建模是原创贡献**：Hamilton 原理导出的耗散跳跃条件
⚠️ 用 COMSOL 专有环境 → 复现需自行实现（作者团队另有 febio 实现的系列工作）
⚠️ 未给最优收敛率的严格分析（作者自述）
⚠️ 耗散项是唯象模型，参数 $\mu_{\mathcal{S}}$ 需实验标定
