## 核心贡献

> 对**液态水**（而非空气）的湍流强制对流做了首个系统的 DNS 研究，纳入**随温度变化的粘性与热导率**；发现实验关联式偏离 DNS 达 **26%**；并给出一个基于平均动量/能量平衡**积分变换**的修正方法，能在 **2%** 内预测摩擦与换热（除最低雷诺数外），且该修正代入 Spalart–Allmaras 模型可将其摩擦误差**减半**。

1. **建立了水的通道湍流对流 DNS 基准**：覆盖壁面加热与冷却、mean-to-wall 温度比 0.83–1.3、壁温 277–360 K、壁面 Prandtl 数 2–12。
2. **量化了物性随温度变化的影响**：相对同 bulk Re 下的常物性算例，摩擦系数变化 **−39% ~ +32%**，以壁面 Prandtl 数归一的换热系数变化达 **2.3 倍**；已有经验关联式偏离 DNS 达 **26%**。
3. **揭示了近壁结构的统一尺度**：近壁速度与温度条带在用**局部粘性长度**标度后具有**共同的间距**——说明温度与速度的近壁结构在同一尺度上耦合。
4. **提出并验证了积分变换预测方法**：通过从平均动量与能量平衡导出的**积分变换**把变物性剖面映射到常物性剖面，经 DNS 标定的涡粘/涡扩散经验修正后，预测摩擦与换热**误差在 2% 内**（最低 Re 除外）。
5. **成果可直接迁移到湍流模型**：同一套修正代入 Spalart–Allmaras 模型后，其摩擦误差**减半**。

## 技术方案

### 核心思想

CFD 中的湍流换热关联式几乎全部是**为空气**标定的（经典的 Dittus–Boelter、Colburn、Sieder–Tate 等）。但在液冷系统（数据中心、电子器件、电池热管理、核反应堆）中，工质是水——其物性随温度的变化规律与空气**根本不同**：

- **空气**：Prandtl 数 $\mathrm{Pr}\approx 0.7$ 且**几乎恒定**，粘性与导热系数同步随温度变化；
- **水**：Prandtl 数随温度**显著变化**（277 K 时 Pr≈7，360 K 时 Pr≈2.5），且**导热系数不与粘性系数成正比**（空气中两者近似同一温度律，因此一个普适函数即可；水中不行）。

本文直接对水做 DNS，建立真值基准，量化"常物性假设"在液体中的失效程度，并给出可落地的修正路径。

方法上最巧妙的一步是**积分变换**：变物性解与常物性解之间存在由平均动量平衡与平均能量平衡导出的映射关系，因此不必重新积分输运方程，只需做剖面变换 + 涡粘/涡扩散修正标定，即可复用现成的常物性预测框架。作者明确指出这一方法此前**是为空气建立的，本文首次推广到液体**（因为水的导热系数不与粘性成正比，且 Pr 数沿通道变化）。

### 关键技术

| 技术 | 说明 |
|------|------|
| DNS (直接数值模拟) | 通道湍流对流全分辨率真值基准 |
| 温度相关粘性/导热系数 | $\mu(T)$、$k(T)$ 随局部温度更新，Pr 数沿展向变化 |
| 壁面加热 + 冷却双工况 | 同时考察热边界条件符号的影响 |
| Mean-to-wall 温度比 | $T_{mw}/T_w$ 变量，覆盖 0.83–1.3 的加热/冷却强度 |
| 壁面 Prandtl 数 | 2–12 范围，覆盖工程水冷工况 |
| 积分变换法 | 由平均动量/能量平衡导出的剖面映射 |
| 涡粘与涡扩散经验修正 | 标定于 DNS 数据，闭合变换残差 |
| Spalart–Allmaras 模型修正 | 将同一套修正代入湍流模型以改善摩擦预测 |
| 壁面摩擦雷诺数诊断 | 说明其对湍流尺度范围的表征能力不足 |
| 局部粘性长度标度 | 统一近壁速度/温度条带间距的尺度 |

## 公式 / 理论要点

```math
% 变物性通道流 N-S 与能量方程
\frac{\partial \boldsymbol{u}}{\partial t}
+\boldsymbol{u}\cdot\nabla\boldsymbol{u}
= -\nabla p+\nabla\cdot\left(\mu(T)\left(\nabla\boldsymbol{u}-(\nabla\boldsymbol{u})^T\right)\right)
-\frac{2}{3}\nabla\cdot\left(\mu(T)\nabla\cdot\boldsymbol{u}\right)
```

```math
\frac{\partial T}{\partial t}+\boldsymbol{u}\cdot\nabla T
= \nabla\cdot\left(k(T)\nabla T\right)
```

```math
% 壁面 Prandtl 数（沿通道变化，因 k 与 mu 温度律不同）
\mathrm{Pr}_w = \frac{\mu(T_w)\,c_p(T_w)}{k(T_w)}
```

```math
% 平均动量/能量平衡导出的积分变换（核心）
% 平均速度剖面：变物性剖面 → 等效常物性剖面
\bar{u}_{\text{eq}}(y) = \bar{u}(y)
-\int^{y}\frac{1}{\rho\,\bar{u}}\frac{d}{dy'}\left(
\bar{u}\,\frac{d\bar{u}}{dy'}
+\overline{u'u'}-\nu_{\text{t}}\frac{d\bar{u}}{dy'}
\right)dy'
```

```math
% 换热（以壁面 Prandtl 数归一）
\mathrm{Nu}_w = \frac{h_w\,D}{k(T_w)}, \qquad
\mathrm{St} = \frac{h_w}{\rho\,c_p\,\bar{u}}
```

```math
% 摩擦系数与壁面摩擦雷诺数
C_f=\frac{\tau_w}{\frac{1}{2}\rho\bar{u}^2},
\qquad
\mathrm{Re}_\tau=\frac{u_\tau\,\delta_\nu}{\nu(T_w)},
\qquad
\delta_\nu=\frac{\nu(T_w)}{u_\tau}
```

## 实验与结果

- **算例/数据集**: 平面通道内液态水的湍流强制对流 DNS；壁面加热与冷却两种工况；mean-to-wall 温度比 0.83–1.3；壁温 277–360 K；壁面 Prandtl 数 2–12；按 bulk Re 匹配常物性对照算例。
- **对比基线**: 同 bulk Re 的**常物性 DNS**；现有**经验关联式**（工业标准换热关系式）；**Spalart–Allmaras 湍流模型**（修正前/后）。
- **主要结果**:
  - **摩擦系数变化 −39% ~ +32%**（相对常物性同 bulk Re 算例）。
  - **换热系数（以壁面 Prandtl 数归一）变化达 2.3 倍**。
  - **经验关联式偏离 DNS 达 26%** —— 直接说明现有换热关联式在水工况下不可靠。
  - **壁面摩擦雷诺数误判湍流尺度范围**：用单一 $\mathrm{Re}_\tau$ 表征对变物性工况不再覆盖正确的尺度区间。
  - **近壁结构统一性**：速度与温度条带在局部粘性长度标度下具有**共同间距**。
  - **积分变换预测精度**：摩擦与换热预测**误差在 2% 内**（最低 Re 附近除外）。
  - **模型改进**：同一套修正代入 Spalart–Allmaras，**摩擦误差减半**。
  - **密度恒定** ⇒ 核心区（core）的平均速度亏损与温度亏损与常物性流一致（变物性效应主要体现在壁区与物性梯度区）。

## 局限性

- 仅研究**充分发展、湍流、恒密度**的通道流，未覆盖入口/发展段、转捩、分离流、几何复杂性。
- **最低 Re 附近**积分变换预测失效（误差超出 2%）。
- 涡粘/涡扩散修正系数是**基于本文 DNS 标定的经验式**，向其他 Pr 数区间或通道几何的外推需重新验证。
- 未涉及**相变**（沸腾/冷凝）与**湍流对流换热中温度梯度的各向异性**（水在通道内 Pr 数沿程变化已处理，但未推广到强非均匀温度场）。

## 实现建议

- **实现难度**: 中低 — 核心创新（积分变换 + 修正）可直接实现在既有 CFD 求解器中；工作量集中在物性表插值与涡粘/涡扩散修正项的标定。
- **预期性能**: 预测精度 2% 以内（多数工况），远优于现有 26% 偏差的关联式；代入 SA 模型可立即减半摩擦误差。
- **适用场景**:
  - 液冷系统（数据中心、电池热管理、IGBT 散热）换热器设计；
  - 核反应堆冷却剂管道热工水力分析；
  - 任何以水为工质的强制对流热设计（**不要直接沿用空气标定的关联式**）；
  - 低 Pr 数熔盐/液态金属冷却的类比参考。
- **可复用要点**:
  - **"先查关联式的标定工质"应成为设计流程的第一步**：本轮 26% 的偏差直接来自关联式是为空气标定的。
  - **积分变换 + 经验修正** 是把昂贵物性效应引入低成本工程模型的通用范式：不必重新求解完整方程组，而是把变物性剖面映射到已知框架。
  - **涡粘/涡扩散修正**的标定方式（基于 DNS 而非实验）使方法可迁移到缺少实验数据的工况。
  - **局部粘性长度作为统一标度**这一发现提示：在变物性条件下，用**局部**而非全局粘性尺度来组织近壁数据，是更稳健的建模策略。
