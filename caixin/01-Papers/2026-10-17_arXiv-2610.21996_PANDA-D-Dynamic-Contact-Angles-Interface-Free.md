## 核心贡献

> 提出 **PANDA-D** 方法，从分子模拟中**无界面提取**动态接触角——通过**密度轮廓 + 层状质心位移联合拟合**，同时得到**前进角与后退角**，消除传统方法中界面阈值与近壁切线外推的任意性

1. **背景**：分子模拟中动态接触角通常从 2D 液-气轮廓 + 近壁切线拟合提取；阈值选择与外推引入系统误差
2. **PANDA-D 创新**：
   - **无界面提取**：仅用密度分布 + 层状质心位移
   - **联合拟合**：自动判定**哪个 meniscus 是前进**
   - 圆形 meniscus 模型映射 → 前进角 / 后退角 / 近壁偏移
3. **性能**：
   - 合成 roll 验证：重建误差 **0.29° RMS**
   - 力驱动 Lennard-Jones roll：**0.84° RMS**（与独立 circle-fit 一致）
   - 4 种壁-液吸引下：后退角 ↓、前进角 ↑（近似线性，力范围内）

## 技术方案

### 核心思想

把**动态接触角测量**从"提取界面 + 切线拟合"两步法改为**密度-位移联合拟合**——用**层状质心**作为**前进方向的判定器**，消除界面提取的任意性。

### 关键技术

| 技术 | 说明 |
|------|------|
| Density profile analysis | 占据层宽度测量 |
| Layerwise center-of-mass displacement | 层状位移 |
| Joint density-displacement fitting | 联合拟合 |
| Circular meniscus model | 圆形 meniscus 模型映射 |
| Force-driven LJ roll | 力驱动测试 |
| Wall-fluid attraction scan | 4 种吸引强度 |

### PANDA-D 算法

```
[分子模拟轨迹]
    ↓
[密度轮廓 ρ(z)] → 占据层宽度
    ↓
[层状质心位移 δcm(t)] → 前进方向判定
    ↓
[联合拟合密度 + 位移]
    ↓
[圆形 meniscus 模型 → θ_advancing, θ_receding]
```

### 关键公式

**密度轮廓**：
\[
\rho(z) = \rho_{\mathrm{liq}} \cdot H(z - z_{\mathrm{meniscus}})
\]

**层状质心**：
\[
\delta z_n(t) = \frac{1}{M_n}\sum_i z_i(t) \cdot \mathbb{1}[\text{particle in layer } n]
\]

**圆形 meniscus 模型**：
\[
z(r) = z_0 - R(\cos\theta - \cos\theta_0)
\]

### 关键结果

| 操作 | 重建误差 |
|------|---------|
| 合成 roll（预设角） | 0.29° RMS |
| 力驱动 LJ roll | 0.84° RMS |
| 密度单独拟合 | **可能错配不对称性** |
| 联合拟合 | **同时复现两个轮廓** |

## 实验 / 验证

- **方法**：分子动力学模拟（MD）
- **样本**：力驱动的 Lennard-Jones 液 roll
- **壁面**：4 种吸引强度（不同壁-液相互作用）
- **结果**：
  - 后退角随力增加而 ↓
  - 前进角随力增加而 ↑
  - 二者呈近似线性关系（所研究范围内）

---

## 局限性

- **2D roll 简化**：实际 3D 接触线几何未涵盖
- **球形壁面**：未涵盖粗糙 / 化学异质壁
- **LJ 工质**：其他分子势能未验证
- **线性范围**：仅在所研究力的范围内呈线性，极端力可能虚化

## 笔记

**@墨鱼丸 实现建议**：本工作对**微纳尺度多相流**与**分子模拟-连续介质桥接**有重要价值：
- **分子模拟验证**：PANDA-D 可作为 MD 接触角的自动化、稳健测量方法
- **多相流 CFD 输入**：前进角 / 后退角是 VOF / Phase-field 的关键输入参数
- **接触角滞后建模**：明确前进 / 后退角有助于建立**接触角滞后 + 线张力**模型
- 迁移到其他分子类型：
  - 水（SPC/E, TIP4P）
  - 有机溶剂
  - 离子液体
- 对 OpenFOAM `contactAngle` 字典的输入参数标定有直接帮助

难度：中（需要 MD 模拟 + 自定义分析脚本）；价值：中（多相流基础物理 + 模拟工具）
