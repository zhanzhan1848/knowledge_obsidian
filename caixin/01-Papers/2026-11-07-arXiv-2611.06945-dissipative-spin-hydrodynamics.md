## 核心贡献

> 扩展**完美自旋流体动力学**以包含自旋扇区耗散：能量-动量张量的**反对称部分**引入后产生两重效应——(i) 成为自旋张量的源项，实现自旋-轨道角动量交换；(ii) 进入能量与线动量守恒律，间接影响自旋动力学。

1. **反对称能量-动量张量**的形式来自 Navier–Stokes 或 Israel–Stewart 理论，引入**先验未知的动理学系数与弛豫时间**（假设随熵密度标度）
2. **两重效应**：反对称部分既做自旋张量源项（耗散性自旋-轨道相互作用），又出现在能量/线动量守恒律中
3. **数值结果**：两个 boost-invariant 膨胀几何——1D 纵向运动（Bjorken 模型）与 2D boost-invariant 轴对称膨胀；表明自旋极化张量**趋向热涡度（thermal vorticity）**
4. **关键观察**：Israel–Stewart 动力学在趋向局部平衡的过程中**先经过 Navier–Stokes 区域**

## 技术方案

### 核心思想

**自旋极化/取向**现象在实验上引起广泛关注，在理论上推动了**自旋流体动力学**框架——把自旋自由度纳入相对论流体动力学形式体系（重离子实验解释的基本工具）。

**本文的出发点**：完美自旋流体动力学的耗散扩展。

- 存在耗散 → 必须考虑能量-动量张量的**反对称部分**
- 其形式来自 **Navier–Stokes** 或 **Israel–Stewart** 理论
- 两者都引入**先验未知的动理学系数**（假设随熵密度标度，考察不同比例常数）与弛豫时间

**框架层面的结论**：
- Israel–Stewart 形式**天然有助于一致地组合**线动量与角动量守恒律
- 而 **Navier–Stokes 框架本身会破坏方程结构**——因为会引入**阶数高于一**的导数项

### 关键技术

| 技术 | 说明 |
|------|------|
| **反对称能量-动量张量** | 源项：自旋-轨道相互作用；也进入能量/动量守恒律 |
| **Israel–Stewart 理论** | 二阶耗散，引入弛豫时间 $\tau$ |
| **Navier–Stokes 理论** | 一阶耗散，但引入高阶导数，破坏方程结构 |
| **动理学系数标度假设** | 系数 ∝ 熵密度；考察不同比例常数 |
| **Bjorken 模型** | 1D 纵向 boost-invariant 膨胀 |
| **2D boost-invariant 轴对称膨胀** | 柱对称 |
| **热涡度对比** | 自旋极化张量趋向 thermal vorticity 的检验 |

### 公式

**反对称能量-动量张量**（Navier–Stokes / Israel–Stewart 型）：

$$T^{\mu\nu}_{\text{antisym}}\propto \Delta^{\mu\nu}_{\pi}\,\pi_{\alpha\beta}\sigma^{\alpha\beta}+\Delta^{\mu\nu}_{\omega}\,\omega^{\mu\nu}$$

**自旋张量演化（含源项）**：

$$\partial_t s^{\mu\nu}+\nabla_\mu(s^{\mu\nu}u^\nu)=\frac{\theta}{2}(s^{\mu\nu}-u^\mu u^\nu)\sigma^{\alpha\beta}+\cdots+\underbrace{\text{antisym }T\text{ 源项}}_{\text{自旋-轨道交换}}$$

**Israel–Stewart 弛豫**：$\tau\,\dot{\pi}^{\mu\nu}+\pi^{\mu\nu}=\beta\sigma^{\mu\nu}$；$\tau\,\dot{\omega}^{\mu\nu}+\omega^{\mu\nu}=\Omega^{\mu\nu}$

## 实验结论

- **数值结果**：对**不同动理学系数与弛豫时间**的组合，自旋极化张量**趋向热涡度**
- **关键观察**：Israel–Stewart 动力学在走向局部平衡的路径上，**先经过 Navier–Stokes 区域**
- **几何**：1D 纵向（Bjorken）、2D boost-invariant + 柱对称

---

## 局限性

1. 动理学系数与弛豫时间**无实验约束**，全靠假设（∝ 熵密度）+ 参数扫描
2. 仅验证 boost-invariant 膨胀（高度对称、非一般初始条件）
3. 推论「Navier–Stokes 破坏方程结构」是形式层面的，未做具体数值对比
4. 未与实验数据（如重离子碰撞中 Λ 自旋极化）定量对照
5. 反对称张量源项的具体系数（假设空间）单一
