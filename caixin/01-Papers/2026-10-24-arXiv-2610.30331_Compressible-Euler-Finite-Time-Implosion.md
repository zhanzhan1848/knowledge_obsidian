## 核心贡献

> 把**一维可压缩 Euler 内爆（implosion）**的 Guderley 型有限时奇性分析**推广到多维径向对称情形**，发现有限远场截断（finite far-field cutoff）会引发**复合型 blowup**（复合自相似奇性），并给出配套的**拉格朗日 AMR 高分辨率数值方法**。

1. **初始数据**：径向对称 **Kidder 自相似内爆解**，但在有限半径处施加**连续常数密度截断**（避免无穷远非紧致数据）。
2. **波的涌现**：从截断点发出**膨胀波（expanding wave）**，其两端分别沿双曲守恒律系统的 **imploding 特征速度**与 **exploding 特征速度**传播。波结构比一维情形下精确的**非中心稀疏波（rarefaction wave）**复杂得多。
3. **复合 blowup**：与一维不同，多维情形下**在膨胀波 "imploding" 侧与 Kidder 解的连接点处发生 blowup**，形成具有渐近自相似形式的**复合奇性**，可用 **Guderley 型自相似结构**解释。
4. **数值方法**：必须用**拉格朗日格式**（避免 Eulerian 格式固有的数值扩散），采用 **leapfrog 时间推进 + blowup 区域递归网格加密（AMR）**，可解析自相似 blowup 多个数量级。
5. **严格结论一致**：blowup **不涉及质量集中**，密度集中存在临界 **$L^p$ 空间**，$p$ 依赖空间维数（$n=0$ 平面 / $n=1$ 柱 / $n=2$ 球）。

## 技术方案

### 核心思想

经典 Guderley 内爆解**以带激波初值起手**，因此"内爆能否从连续甚至光滑初值演化出来"长期悬而未决。本文的 Kidder 自相似连续初值 + 有限远场截断提供了一个具体构造路径，并揭示出**多维内爆奇性结构与一维本质不同**。

物理背景：空化（cavitation）、声致发光（sonoluminescence）、星系气体吸积、恒星形成、**惯性约束聚变（ICF）** 内爆。

### 控制方程

径向对称可压缩 Euler（等熵，初始熵恒定 → 压力仅是密度函数 $P(\rho)=C\rho^\gamma$）：

$$
\begin{aligned}
&\frac{\partial \rho}{\partial t} + v\frac{\partial \rho}{\partial r} + \rho\frac{\partial v}{\partial r} + \frac{n\rho v}{r} = 0 \\
&\frac{\partial v}{\partial t} + v\frac{\partial v}{\partial r} + C\gamma\rho^{\gamma-2}\frac{\partial \rho}{\partial r} = 0
\end{aligned}
$$

- $n$ 为空间维数指标：$n=0$ 平面、$n=1$ 柱、$n=2$ 球
- 若再假设无旋（径向对称自动满足）→ **势流方程（potential flow equations）**
- 局部声速：$c = \sqrt{C\gamma}\,\rho^{(\gamma-1)/2}$
- Full Euler 额外含熵方程 $\partial_t \ln(P\rho^{-\gamma}) + v\partial_r \ln(P\rho^{-\gamma}) = 0$

### 关键技术

| 技术 | 说明 |
|------|------|
| Kidder 自相似内爆 | 连续、严格正压力的径向自相似解，作为内爆初值骨架 |
| 有限远场截断 | 在有限半径施加常数密度截断，使初值紧致；截断点成为膨胀波源 |
| 拉格朗日 leapfrog + 递归 AMR | 在拉格朗日坐标下推进，blowup 区域递归加密，实现多数量级分辨率 |
| 渐近相似解分析 | 与数值互证，识别复合自相似 blowup 的 Guderley 型结构 |
| 临界 $L^p$ 分析 | 质量不集中、密度集中的临界空间随维数变化 |

## 实验结论

- **数据集**: 数值自造 —— Kidder 自相似内爆 + 有限远场截断初值
- **基线**: 一维情形下的精确非中心稀疏波（作为对照，其内爆侧无 blowup）
- **结果**:
  - 膨胀波从截断点发出，两端分别遵循 imploding / exploding 特征速度
  - 内层 Kidder 解在接近奇性时刻被膨胀波**吞没**（与一维一致）
  - **多维特有**：膨胀波 imploding 侧与 Kidder 解的**连接点处发生 blowup**，构成复合型奇性
  - blowup 过程解析了**多个数量级**的相似解标度
  - 与先前严格结果一致：**无质量集中**，密度集中有临界 $L^p$（$p$ 依赖维数）

---

## 局限性

- 限于**等熵、径向对称**的简化设定（无真实 EOS、无辐射、无相变）
- 数值结果依赖高精度 AMR 拉格朗日格式，计算成本高
- 渐近分析针对特定自相似族，不构成一般性存在性/稳定性定理
