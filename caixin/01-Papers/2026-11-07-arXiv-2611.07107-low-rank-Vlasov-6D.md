## 核心贡献

> 提出**首个以 PDE 物理可观测量（而非纯矩阵量）驱动秩选择**的 HPC 导向低秩自适应策略，用于 6D Vlasov–Poisson 模拟：相比 state-of-the-art 的自适应 BUG 积分器，**内存占用显著降低、运行时间减少**。

1. **三种秩自适应判据**：
   - `df`：分布函数（用最小奇异值 $\lambda_r$）
   - `ef`：**电场**（$\|E-E_{\text{red}}\|_{L^2}$）
   - `ee`：**电场能量**（$|\delta-\delta_{\text{red}}|$）
2. **扩展 projector-splitting DLR 积分器**：基于物理量自适应调秩
3. **GPU 友好**：只需存储 rank $r$ 个对象，中间低秩对象**比 BUG 更小**
4. **算法细节**：每步最多调整 1 档秩（防止震荡）；升秩时**拒绝当前步并重启**时间积分

## 技术方案

### 核心思想

**6D Vlasov–Poisson 的困境**：3D 空间 + 3D 速度 = 6 维相空间。全网格离散不可行，即便在超算上也只是勉强可行。

**低秩的思路**：把分布函数近似在秩 $r$ 流形上，把动力学约束在该流形的切空间内：
$$f(t,x,v)\approx\sum_{i,j}^{r}X_i(t,x)\,S_{ij}(t)\,V_j(t,v)$$

**固定秩的问题**：达到给定精度所需的最小秩事先通常未知，且随时间显著变化。例如两流不稳定性中，初始电场能量的指数增长阶段与非线性饱和阶段**需要不同的秩**。

**本文的洞见**：以往秩自适应基于矩阵量（奇异值），本文改为**基于 PDE 的物理可观测量**——因为电场/电场能量往往才是真正关心之物；用物理引导的秩选择给出**更有针对性的近似**，而不是把模型当作通用矩阵微分方程处理。

**作者声明**：秩自适应在 DLR 文献中不新鲜，但本文据作者所知是**首个 HPC 导向、直接以 PDE 物理可观测量为基础的秩选择策略**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **Dynamical Low-Rank (DLR)** | 秩 $r$ 流形上的切空间约束；投影分裂（projector-splitting）积分器 |
| **CP 型分解** | $X(x)$、$S$（系数）、$V(v)$ 分离，空间/速度分离结构 |
| **SVD 截断判据** | $S^\tau=A\Lambda B^{\sf T}$，$\Lambda$ 降序；`df` 判据用 $\lambda_r$ |
| **`ef` 电场判据** | 去掉最小奇异值对应的行/列得 $S^\tau_{\text{red}}$，算 $E_{\text{red}}$，误差 $\alpha=\|E-E_{\text{red}}\|_{L^2}$，尺度 $\ell=\|E\|_{L^2}$ |
| **`ee` 能量判据** | $\alpha=\|\delta-\delta_{\text{red}}\|$，$\ell=\delta$（$\delta$ = 电场能量） |
| **混合绝对-相对容差** | 降秩：$\alpha\le\epsilon^{\text{abs}}_{\text{decr}}+\ell\epsilon^{\text{rel}}_{\text{decr}}$；升秩：$\alpha\ge\epsilon^{\text{abs}}_{\text{incr}}+\ell\epsilon^{\text{rel}}_{\text{incr}}$ |
| **升秩拒绝并重启** | 当前时间步被拒绝，秩增加后重启时间积分（保证精度） |
| **每步最多调 1 档** | 防止震荡的实用保护 |
| **Ensign 框架** | C++/CUDA；GPU 加速 |

### 公式

**Vlasov–Poisson 系统**：

$$\partial_t f+v\cdot\nabla_x f-E(f)\cdot\nabla_v f=0,\qquad E(f)=-\nabla_x\phi,\qquad -\Delta\phi=\rho(f)+1$$

**低秩表示**：

$$f(\tau,x,v)\approx\sum_{i,j}^{r}X_i^{\tau}(x)\,S_{ij}^{\tau}\,V_j^{\tau}(v)$$

**SVD 截断**：$S^\tau=A\Lambda B^{\sf T}$，$\Lambda=\text{diag}(\lambda_1,\dots,\lambda_r)$ 降序；令 $\Lambda_{\text{red}}$ 把 $\lambda_r$ 置零 → $S^\tau_{\text{red}}=A\Lambda_{\text{red}}B^{\sf T}$

**`ef` 判据**：

$$\alpha=\big\Vert E-E_{\text{red}}\big\Vert_{L^{2}},\qquad \ell=\big\Vert E\big\Vert_{L^{2}}$$

**`ee` 判据**：

$$\alpha=\big|\delta-\delta_{\text{red}}\big|,\qquad \ell=\delta$$

**`df` 判据**：$\alpha=\lambda_r$，$\ell=0$

## 实验结论

- **基准（标准 6D）**：
  - 线性 Landau 阻尼
  - **非线性** Landau 阻尼
  - 两流不稳定性（two-stream instability）
  - 峰尾不稳定性（bump-on-tail instability）
- **结果**：
  - 稳健捕捉相关等离子体动力学，同时保持紧凑低秩表示
  - 相比 rank-adaptive **BUG** 积分器：**显著节省内存 + 缩短运行时间**
  - 一阶自适应 BUG vs PS 的墙钟时间对比（示例，秒）：

| 阶段 | BUG (GPU) | PS (GPU) | BUG (CPU) | PS (CPU) |
|---|---|---|---|---|
| 初始化 | 0.722 | 0.716 | 0.841 | 0.878 |
| 时间积分 | $4.52\times10^2$ | $3.73\times10^2$ | $8.55\times10^3$ | $6.86\times10^3$ |
| 秩选择 | 11.7 | **7.77** | 65.2 | 24.8 |
| **总计** | $4.64\times10^2$ | $3.81\times10^2$ | $8.62\times10^3$ | $6.88\times10^3$ |

- **GPU vs CPU**：GPU 上时间积分快约 **19 倍**；主要瓶颈是 QR 分解与「$\mathsf{L}$/$\mathsf{K}$ 步 + QR」
- **物理量驱动秩 vs 奇异值驱动秩**：前者通常给出**更低的秩**与更小的计算负担

## 局限性

1. **秩调整策略的数值安全性依赖经验容差**，理论上缺乏严格误差界（升秩重启保证了精度但代价未定界）
2. 与 BUG 的比较限于特定基准与实现；通用性未验证
3. 只针对 Vlasov–Poisson；带碰撞项（Fokker–Planck）的推广未做
4. 秩上调后**重启时间步**带来的额外开销未系统量化
5. `ee` 判据只用一个标量（电场能量），无法分辨误差的空间分布

## 实现建议

- **实现难度**：中高（需 DLR 理论 + projector-splitting 实现 + CUDA）
- **预期性能**：GPU 上比自适应 BUG 快约 18%（墙钟），内存占用更优；6D 模拟在 GPU 上可行
- **适用场景**：
  - 6D Vlasov–Poisson 等离子体模拟（Landau 阻尼、两流、峰尾不稳）
  - GPU 显存受限场景（这是**核心卖点**：中间低秩对象更小）
- **落地建议**：**优先尝试 `ee`（电场能量）判据**——物理意义最直接、通常给出最低秩；若模拟中电场能量变化平缓但结构复杂，可改用 `ef`；`df` 作为保守基线
- **配套**：可与 [[2026-11-07-arXiv-2611.07364-APTNN-high-field-kinetic]] 对比——低秩法更易落地，神经网络法无需选网格
