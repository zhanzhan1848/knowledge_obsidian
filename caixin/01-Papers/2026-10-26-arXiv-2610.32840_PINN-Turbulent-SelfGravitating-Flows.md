## 核心贡献

> 将 PINN 应用于**湍流 + 自引力**耦合的等温分子云，验证其在多维度、多马赫数下恢复全局流动演化，且**训练成本对空间分辨率几乎不敏感**

1. 场景：分子云中由**湍流、自引力、气体压力**共同驱动的复杂多尺度动力学——传统网格方法随维数与分辨率增长而成本激增
2. PINN 作为**无网格替代方案**，把控制方程直接写入训练目标
3. 在**等温分子云**上应用 PINN，初始条件取**天体物理学上有依据的湍流速度场**
4. 覆盖**亚声速与超声速**演化、**二维与三维**
5. 与有限体积代码 **Athena++** 对标验证
6. 关键量化结果：PINN 在**多个自由落体时间**上准确恢复全局流动演化（跨湍流实现、马赫数、维度）；**训练成本从 128³ 到 1024³ 仅增加不到 25%**
7. 结论：PINN 能建模比以往探索**更真实的**自引力湍流流动，是研究此类系统的**有前景的互补框架**

## 技术方案

### 核心思想

传统网格 CFD 在三维高分辨率下成本极高。PINN 的空间无关性（隐式场表示）理论上带来分辨率成本递减。本文用最苛刻的场景之一（自引力湍流，含多尺度）检验这一优势是否真的成立。

### 关键技术

| 技术 | 说明 |
|------|------|
| PINN 训练目标 | 连续性方程 + 泊松引力方程 + 初始/边界条件残差 |
| 等温分子云 | 等温 EOS → 压力与密度直接耦合 |
| 湍流初始化 | 有天体物理依据的随机湍流速度场 |
| Athena++ 对标 | 有限体积参考解，2D/3D |
| 多马赫数扫描 | 亚声速 (M<1) 与超声速 (M>1) |
| 多自由落体时间 | 检验长期演化稳定性 |

## 公式

```math
等温分子云控制方程:
  ∂ρ/∂t + ∇·(ρu) = 0
  ∂u/∂t + (u·∇)u = -∇Φ - c_s² (1/ρ)∇ρ
  ∇²Φ = 4πGρ

自由落体时间:
  t_ff = 1/√(G ρ₀)

亚声速/超声速判据:
  M = |u| / c_s ,  c_s = 声速

PINN 损失:
  L = λ_ρ ‖∂ρ/∂t + ∇·(ρu)‖²
    + λ_u ‖∂u/∂t + (u·∇)u + ∇Φ + c_s²∇ln ρ‖²
    + λ_Φ ‖∇²Φ - 4πGρ‖²
    + λ_ic ‖u(x,0) - u₀(x)‖²
```

## 代码片段

```python
import torch

class AstroPINN(torch.nn.Module):
    """等温自引力流的 PINN 残差"""
    def __init__(self, G=1.0, c_s=1.0):
        super().__init__()
        self.net = torch.nn.Sequential(
            torch.nn.Linear(3, 128), torch.nn.Tanh(),
            torch.nn.Linear(128, 128), torch.nn.Tanh(),
            torch.nn.Linear(128, 128), torch.nn.Tanh(),
            torch.nn.Linear(128, 5))   # (rho, u, v, w, Phi)
        self.G, self.c_s = G, c_s

    def residuals(self, xyz, t):
        z = torch.cat([xyz, t], dim=-1)
        out = self.net(z)
        rho = out[..., 0:1]
        u   = out[..., 1:4]
        Phi = out[..., 4:5]
        # 对空间坐标求导得到 ∂t 与 ∇
        rho_t = d(rho, t)
        cont  = rho_t + d(dot(rho, u, xyz), xyz)
        mom   = d(u, t) + jac_mlp(u, xyz) @ u + d(Phi, xyz) \
                + self.c_s**2 * d(torch.log(rho), xyz)
        lap_Phi = laplacian(Phi, xyz)
        poisson = lap_Phi - 4*np.pi*self.G*rho
        return cont, mom, poisson
```

## 实验结论

- **数据集**: 等温分子云的 2D/3D PINN 仿真，初始为天体物理湍流场
- **基线**: 有限体积代码 **Athena++**
- **结果**:
  - PINN 在**多个自由落体时间**上准确恢复流动的**全局演化**
  - 跨**多个湍流实现、马赫数、维度**均成立
  - **训练成本对空间分辨率弱依赖**：128³ → 1024³ 仅 **< 25%** 增长
  - 结论：PINN 可建模比以往更现实的自引力湍流流动

---

## 局限性

- 等温分子云（单温、简化 EOS），非真实星云（含辐射、冷却、磁场）
- PINN 的"全局演化准确"≠ 场结构精确；摘要未给出细尺度精度指标
- 3D 1024³ 训练仍需可观算力（成本增长小 ≠ 成本低）
- 自引力 + 湍流的长时间积分对 PINN 的优化稳定性有要求
- 与流体领域主流问题（边界层、分离、涡脱落）关联弱

## 实现建议

- **实现难度**: 中高（多重耦合残差 + 长时间积分稳定性）
- **预期性能**: 训练成本随分辨率缓增（< 25% / 128³→1024³），但绝对成本仍高；单次训练为数 GPU·天量级
- **适用场景**: 自引力天体流体、流体-引力耦合问题的"零网格起步"方案；**不宜**替代生产级 CFD
- 推荐结论：⚠️ 谨慎——方法论价值（成本-分辨率解耦）明确，但流体工程落地价值有限；建议作为**概念参考**而非实用方案
