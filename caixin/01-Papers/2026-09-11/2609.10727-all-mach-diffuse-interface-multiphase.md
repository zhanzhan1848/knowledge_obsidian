## 核心创新点

提出一个**鲁棒的有限体积框架**，用于模拟宽 Mach 数范围内的可压缩多相流与表面张力。核心贡献：

1. **双压六方程扩散界面模型**：通过连续表面力 (CSF) 公式纳入黏性、重力和毛细效应
2. **广义 Riemann 不变量分析**：开发了考虑毛细压跃的 HLLC Riemann 求解器
3. **低 Mach 数修正**：提出改进的标度策略，克服传统近似 Riemann 求解器在低 Mach 区域的过度数值扩散
4. **Laplace 压跃保持**：修改瞬时压力弛豫程序

## 控制方程

- 双压六方程扩散界面模型
- 连续性方程 + 动量方程
- 能量方程（两相）
- 体积分数方程
- CSF 表面张力模型

## 数值方法

- **离散化**: 有限体积法 (FVM)
- **Riemann 求解器**: HLLC（广义）
- **界面追踪**: 扩散界面方法
- **压力弛豫**: 瞬时弛豫程序（修改版）
- **低 Mach 修正**: 改进标度策略

## 关键算法细节

```
毛细压跃处理 → 广义 Riemann 不变量 → HLLC 求解器
低 Mach 区域 → 修正标度策略 → 稳定高精度
```
