## 核心贡献

> 用二维固定圆形界面上的全非线性模型研究电场中表面活性剂覆盖液滴的界面动力学：表面活性剂引起 Marangoni 应力几乎完全抑制 Taylor 环流（界面"僵滞"），而 Quincke 自转又能重新"激活"界面并恢复显著的应变环流。

1. 建立了含表面活性剂的漏介质液滴在均匀电场中的二维全非线性界面模型，可同时处理弱表面扩散与体相交换两种传输机制
2. 揭示了竞争机制：表面活性剂的再分配产生浓度梯度，其 Marangoni 应力可**几乎完全**抑制 Taylor 环流；而 Quincke 旋转能够"再激活"该近僵滞界面
3. 发现表面活性剂不仅平移临界起转场强，还能改变起始的**亚临界/超临界**性质；并指出表面活性剂浓度的空间分布可作为区分"表面扩散"与"体相交换"两种传输机制的额外信息

## 技术方案

### 核心思想

实际流体界面几乎不可能是"干净"的——表面活性剂的存在会强烈改变界面动力学。表面活性剂被界面流重新分配，形成浓度梯度，产生 Marangoni 应力，可以使界面近乎"僵滞"（immobilised）；反之，表面扩散（surface diffusion）或与体相的交换（exchange with bulk）能够削弱梯度并恢复界面运动。本文以二维模型研究这一竞争：漏介质液滴置于均匀电场中，界面固定为圆形（在实验室/数值框架下是一种常见的界面几何近似）。电应力驱动经典的 Taylor 环流——此时液滴不发生自转；在更强场下，界面电荷的对流会破坏该状态，进入 Quincke 区，表现为自发的平均旋转。作者采用固定界面上的全非线性模型求解：弱表面扩散时 Marangoni 应力几乎完全压制 Taylor 环流（界面近于 arrestated）；进入 Quincke 旋转后界面被"再激活"，恢复出显著的应变环流，且其取向随外加场变化。表面活性剂还会移动旋转的临界场强，并可能把起始从超临界变为亚临界。最后，本文比较了"表面扩散"与"与充分混合体相储库交换"两种机制：二者可产生相似的流动响应与旋转阈值，但其表面活性剂的空间分布不同，因而可作为区分两者的判据。

### 关键技术

| 技术 | 说明 |
|------|------|

## 摘要要点

> Fluid--fluid interfaces are seldom clean due to the presence of surfactants, which can strongly modify their dynamics. Interfacial flow redistributes surfactant, creating concentration gradients whose Marangoni stresses can immobilise the interface. By contrast, surface diffusion or exchange with the bulk can reduce these gradients and restore interfacial motion. We study this competition using a two-dimensional model of a surfactant-covered leaky-dielectric drop in a uniform electric field. Electric stresses drive the classical Taylor circulation, in which the drop remains non-rotating. At stronger fields, convection of interfacial charge can destabilise this state and produce the Quincke regime, characterised by spontaneous mean rotation. Using a fully nonlinear model on a fixed circular interface, we show that weak surfactant diffusion allows Marangoni stresses to suppress the Taylor circulation almost completely. Quincke rotation remobilises this nearly arrestated interface and restores a substantial straining circulation, whose orientation varies with the applied field. Surfactant also shifts the critical field for rotation and can change the onset from subcritical to supercritical. Surface diffusion and exchange with a well-mixed bulk reservoir can produce similar flow responses and rotation thresholds despite different surfactant distributions. The spatial variation of surfactant concentration therefore provides additional information for distinguishing the two transport mechanisms.

## 公式 / 理论要点

```math
% —— 背景方程：二维漏介质液滴内部 Stokes 流动 + 电场 ——
\nabla\cdot\mathbf{u} = 0,\qquad \nabla p = \mu\nabla^2\mathbf{u}
\mathbf{E} = -\nabla\phi,\qquad \nabla\cdot(\varepsilon\mathbf{E}) = 0
\text{漏介质本构：}\ \mathbf{T} = \mathbf{T}_M + \mathbf{T}_E,\quad
\mathbf{T}_E = \varepsilon\left(\mathbf{E}\mathbf{E}
-\tfrac{1}{2}|\mathbf{E}|^2\mathbf{I}\right)

% —— 界面法向应力平衡（含 Maxwell + 曲率 + Marangoni）——
[\mathbf{T}\cdot\mathbf{n}]_{\rm in}^{\rm out}
= \gamma\,\kappa\,\mathbf{n} + \nabla_s\!\cdot\!\left(\nabla_s\gamma\right)

% —— Marangoni 切向牵引（表面活性剂梯度的直接后果）——
\mathbf{t}_{\rm Mar} = \nabla_s\gamma = \gamma_0\left(1-2\beta\Gamma\right)\nabla_s\Gamma
%  弱扩散时 |\nabla_s\Gamma| 大 \Rightarrow 切向牵引强 \Rightarrow 界面近于 arrestated

% —— 界面表面活性剂输运：平流 + 扩散 + 体相交换 ——
\frac{\partial\Gamma}{\partial t} + \nabla_s\!\cdot(\mathbf{u}_s\,\Gamma)
= \nabla_s\!\cdot\!\left(D_s\,\nabla_s\Gamma\right)
+ k_{\rm ex}\left(\Gamma_\infty - \Gamma\right)
%  D_s \gg 0：表面扩散；k_{\rm ex} > 0：与充分混合体相储库交换

% —— 旋转的临界场与起始性质 ——
E_c = E_c^{(0)}\!\left(1 + \Delta E_c(\Gamma,\beta,D_s,k_{\rm ex})\right),
\qquad \text{亚临界 / 超临界由 } E_c \text{ 处的失稳特征值符号决定}
```

## 实验与结果

- **算例/数据集**: 二维漏介质液滴（固定圆形界面）在均匀电场中，全非线性数值模拟；参数扫描覆盖表面活性剂扩散强度 $D_s$、体相交换速率 $k_{\rm ex}$、表面活性剂初始浓度与外加场强
- **对比基线**: 干净界面（无表面活性剂）情形下的经典 Taylor 环流与 Quincke 起始行为；两种表面活性剂传输机制（表面扩散 vs 体相交换）之间的相互对照
- **主要结果**:
  - 电应力驱动的**经典 Taylor 环流**中，液滴保持非旋转状态
  - 更强场下界面电荷对流使该状态失稳，进入 **Quincke 区**（自发平均旋转）
  - **弱表面扩散**下 Marangoni 应力几乎完全压制 Taylor 环流，界面处于近僵滞（near-arrestated）状态
  - **Quincke 旋转反过来再激活**该近僵滞界面，恢复出可观的**应变环流**，且环流取向随外加场变化
  - 表面活性剂**移动临界起转场强**，并能够把起始性质从**亚临界改为超临界**（反之亦然）
  - 表面扩散与体相交换可产生**相似的流动响应与旋转阈值**，但表面活性剂**空间分布不同**，故浓度分布可作为区分两种传输机制的额外判据

## 局限性

- 界面固定为圆形（stationary circular interface），未包含界面形变/破碎自由度，无法描述真实液滴的形变与破碎耦合
- 二维模型，无法刻画三维纯扭转场与轴向对称性破缺
- 摘要未给出具体的临界场数值、临界表面活性剂浓度阈值与环流取向角数值
- 表面活性剂采用单一组分理想化模型，未考虑溶胀（swelling）、表面活性剂对界面张力的复杂状态依赖与 Gibbs 弹性（dilatancy）效应
- 体相交换假定储库"充分混合"，与真实有限体积体相交换的差异未讨论

## 实现建议

- **实现难度**: 中 — 需漏介质电动力学 + 界面应力平衡 + 表面活性剂输运的耦合求解；固定界面降低了几何复杂度，但强非线性与多物理场耦合带来收敛挑战
- **预期性能**: 二维固定界面问题规模小，单次参数点求解可在数秒至数分钟内完成，适合大规模参数扫描（$D_s$、$k_{\rm ex}$、$E$、$\Gamma$）
- **适用场景**: EHD 驱动的含表面活性剂液滴动力学分析；Marangoni 效应对界面湍流/混合的抑制或促进评估；EHD 液滴在药物递送、Pickering 乳化、化妆品与电解加工中的应用；界面活性剂分布作为输运机制诊断量的实验设计
- **可复用要点**: 「Marangoni 应力 + 电应力」在同一界面应力平衡中的耦合处理范式，可直接迁移到其他**受表面活性剂污染的**两相界面问题（气液、液液、界面活性剂驱动的薄膜破裂）；「用输运量的空间分布反推输运机制」的诊断思路，是从模拟走向可观测性设计的通用策略；固定界面 + 全非线性 + 参数扫描的分层求解框架适合做机制筛查，再交由更复杂几何验证
