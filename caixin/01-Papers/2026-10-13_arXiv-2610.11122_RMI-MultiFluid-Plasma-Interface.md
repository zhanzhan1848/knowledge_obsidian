## 核心贡献

> 在**多流体等离子体 (MFP) 模型**框架下比较三类密度界面（热、种类、同位素）的 Richtmyer-Meshkov 不稳定性发展，发现仅当电子-流体界面密度比 ≠ 1 时才出现显著放大——这是单流体模型完全无法揭示的多流体耦合效应

1. 用五矩 MFP 模型模拟单模扰动在三种界面（热/种类/同位素）的演化
2. 与单流体 Atwood 数等价的预测对照，揭示 MFP 框架的新物理学
3. **决定性物理量**：电子-流体的密度比（而非总密度 Atwood 数）
4. 同位素界面：电子界面密度比为 1，行为接近单流体；热与种类界面：电子密度非平衡 → 严重 RMI 放大
5. 增加电磁耦合强度（缩短等离子体非维皮肤深度）→ 三类界面行为趋同于单流体模型

## 技术方案

### 核心思想

惯性约束聚变 (ICF) 中烧蚀层界面（DT 冰 / 气体）常发生 RMI；单流体模型认为 Atwood 数等价时三类界面行为相同。MFP 框架下电子/离子解耦，物理本质突变。

### 关键技术

| 技术 | 说明 |
|------|------|
| 五矩多流体模型 | 离子+电子各自密度/动量/能量守恒 |
| 单模扰动初始 | 三角函数界面扰动 + 撞击激波 |
| 三类界面 | 热（T1≠T2）、种类（同密度不同元素）、同位素（同元素不同质量）|
| 电磁耦合 | 通过 Hall 参数 / 皮肤深度控制 |
| Atwood 数对照 | 在三组 MFP 参数下匹配 Atwood 数对比单流体预测 |

## 公式

MFP 模型：离子与电子各为带电流体，通过自洽电场/磁场耦合。

```math
∂ρ_i/∂t + ∇·(ρ_i u_i) = 0
ρ_i (∂u_i/∂t + u_i·∇u_i) = -∇p_i + q_i n_i (E + u_i × B) + R_i
∂E_e/∂t + ... = -p_e ∇·u_e + Q_visc + Q_joule
```

电子-流体密度比（决定 RMI 严重度的核心量）：

```math
A_e = (ρ_e,2 - ρ_e,1) / (ρ_e,2 + ρ_e,1)
```

## 实验结论

- **基准**：单模 RMI，理想离子-电子等离子体
- **结果**：
  - 热与种类界面：最严重 RMI 响应（次级不稳定 + 主模增长）
  - 同位素界面：行为接近单流体模型
  - 自洽电磁场 (A_e ≠ 0) 是放大增强的根源
  - 增强耦合 → 行为趋同单流体，等离子体非维皮肤深度是关键控制参数
- **应用**：ICF 烧蚀层 DT 界面稳定性、XENON / AR ↔ 玻璃界面分类

---

## 局限性

- 仅单模扰动，多模宽带谱未涵盖
- 五矩模型无粘性-热传导-电阻率封闭
- 未涵盖 radiative cooling
- 几何限于 1D/2D
