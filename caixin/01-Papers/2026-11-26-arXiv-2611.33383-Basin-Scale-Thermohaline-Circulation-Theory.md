## 核心贡献

> 从**示踪物守恒**出发提出统一框架：表层通量由**耗散输运**与**平流输运**平衡，用**大尺度示踪物梯度**与**输运效率**（衡量环流把示踪物场从无流动"传导态"移开的程度）来表达通量平衡；该框架**统一了箱模型分岔结果与连续方程**，并**区分了崩塌阈值与恢复阈值的主导机制**。

1. **统一框架的来源**：不同海洋模型给出相似的分岔结构 → 提示模型层级之下存在**共同动力学**。本文从示踪物守恒出发建立这一共同框架。
2. **核心量：输运效率（transport efficiency）** —— 衡量环流把示踪物场从其**无流动"传导态"（conductive state）**移开的强度。这把"环流强度"细化为**更物理的输运量**。
3. **机制分离（关键发现）**：在三维海盆模型中：
   - **崩塌阈值**由**非线性盐度平流**主导；
   - **恢复阈值**由**线性耗散**主导。
   这两个阈值的主导机制**不同** —— 这是分岔分析中少见的清晰结论。
4. **热 vs 盐的差异**：温度额外有**表面恢复（surface restoring）**带来的耗散 → **热通量比盐通量更耗散主导**。
5. **输运 regime**：给定环流产生的示踪物对比与边界层 → 产生**不同的输运 regime**：**弱流时约二次（quadratic）**，**强流时线性（linear）**。
6. **与经典理论的一致性**：用简单的**环流闭合**代入通量平衡后，**退化回箱模型（box model）的长期分岔结果**（弱流与强流两个 regime）。
7. **对临界点预报的意义**：该框架暴露了**平衡变化强迫的输运过程**，因此提供了**单靠翻转强度（overturning strength）无法给出的**对温盐环流状态及其向临界点趋势的**约束**。

## 技术方案

### 核心思想

温盐环流（THC / AMOC）的分岔分析长期依赖**箱模型**：把海洋分成几个箱，用几个平均量描述。这是 powerful 但粗糙的。

本文的思路是：**从连续方程出发，构造一个"通量平衡"的表述，使箱模型成为其特例**。

关键构造：
- **传导态（conductive state）**：无流动时，由表面通量驱动的纯扩散（传导）解。这是自然的参考态。
- **输运效率**：度量环流把示踪物场从传导态移开的强度 —— 这是"环流强度"的**更物理版本**。
- **通量平衡**：表面通量 = 耗散输运 + 平流输运。

一旦有了这个平衡，**崩塌与恢复就对应于不同的输运项占优**。

这与本知识库反复观察到的"**机制分离**"主题一致：把混在一起的东西分开看 —— 崩塌与恢复、弱流与强流、热与盐。

### 关键技术

| 技术 | 说明 |
|------|------|
| **示踪物守恒框架** | 一切分析的出发点 |
| **传导态（conductive state）** | 无流动参考态 |
| **输运效率（transport efficiency）** | 核心无量纲量；环流移开示踪物场的强度 |
| **大尺度示踪物梯度** | 与输运效率共同构成通量平衡 |
| **通量平衡** | 表面通量 ← 耗散输运 + 平流输运 |
| **环流闭合（circulation closure）** | 简单闭合使框架退化为箱模型 |
| **弱流二次 / 强流线性** | 两种输运 regime |
| **表面恢复耗散** | 温度特有的额外耗散项 |
| **临界点（tipping point）** | Part II 的预报对象 |

## 公式 / 理论要点

```math
% 示踪物守恒（温度/盐度）
\partial_t T + \mathbf{u}\cdot\nabla T = \nabla\cdot(K\nabla T) - \mathcal{R}(T)
```

```math
% 传导态（无流动参考解）
K\nabla^2 T_c = \mathcal{R}(T_c)
```

```math
% 输运效率：环流把示踪物场移离传导态的程度
\eta = \frac{\|\mathbf{u}\cdot\nabla T\|}
{\|\nabla T\| \ \text{或等价的归一化输运量}}
\quad(\text{衡量"环流把场从传导态移开"的强度})
```

```math
% 通量平衡
\underbrace{F_{\mathrm{surface}}}_{\text{表面通量}}
=
\underbrace{F_{\mathrm{diss}}}_{\text{耗散输运}}
+
\underbrace{F_{\mathrm{adv}}}_{\text{平流输运}}
```

```math
% 两种 regime
\eta \ll 1\ (\text{弱流}):\quad F \sim \eta^{2},
\qquad
\eta \gg 1\ (\text{强流}):\quad F \sim \eta
```

```math
% 阈值的主导机制（关键发现）
\text{崩塌阈值}:\ \text{非线性盐度平流主导}\ (F_{\mathrm{adv}})
\qquad
\text{恢复阈值}:\ \text{线性耗散主导}\ (F_{\mathrm{diss}})
```

```math
% 温度 vs 盐度
T:\ F_T = F_{\mathrm{diss}} + F_{\mathrm{adv}} + \underbrace{F_{\mathrm{surface\,restoring}}}_{\text{额外耗散}}
\quad\Longrightarrow\quad F_T \ \text{更耗散主导}
```

```math
% 一致性检验：环流闭合 → 箱模型
\text{简单闭合代入通量平衡}
\quad\Longrightarrow\quad
\text{退化为箱模型的弱流/强流分岔结果}
```

## 实验与结果

- **模型**: 三维海盆（ocean-basin）模型 + 示踪物守恒框架。
- **主要发现**:
  1. **崩塌阈值**由**非线性盐度平流**主导；
  2. **恢复阈值**由**线性耗散**主导；
  3. **温度**因表面恢复耗散 → **热通量比盐通量更耗散主导**；
  4. **弱流二次 / 强流线性**两种输运 regime，由环流产生的示踪物对比与边界层决定；
  5. 用简单环流闭合 → **退化回箱模型**的长期分岔结果（弱流与强流 regime）。
- **意义**: 连接了箱模型洞见与连续方程；提供了单靠翻转强度无法给出的临界点约束。

## 局限性

- **Part I 仅为理论**，Part II 才给预报闭合 → 当前尚无完整的临界点预报能力。
- 框架的核心（输运效率）是**概念量**，如何在实际海洋观测中直接估计是未解决的。
- 三维海盆模型的**理想化配置**（边界条件、强迫形式）会影响具体阈值数值。
- 抽象数（示踪物对比、边界层）如何映射到**真实海洋的异质性**未讨论。

---

## 实现建议

- **实现难度**: 中（理论层面）。落地为数值实现需要设计输运效率与通量分解的**离线诊断量**。
- **预期性能**: 作为**分析框架**，主要价值在解释与诊断；Part II 是其预报能力的兑现。
- **适用场景**:
  - **AMOC 稳定性与临界点分析**；
  - **多模型分岔结构比对**（不同模型的相似分岔结构 → 寻找共同机制）；
  - **通量归因诊断**（把观测到的通量变化分解为耗散项与平流项 → 判断逼近何种临界）。
- **可复用要点**:
  - **"从连续方程构造框架，使离散模型成为特例"**是一条极具价值的建模路线 —— 它把"箱模型 vs 高分辨率模型"的争论转化为"同一框架的不同近似"。
  - **"崩塌与恢复由不同机制主导"**应当成为临界点研究的**标准检查项**：只分析崩塌而不分析恢复，会得出片面结论。
  - **"输运效率 = 相对某个自然参考态（传导态）的偏离"**是一种**通用的物理化归一化技巧**：与其直接使用"环流强度"（一个诊断量），不如用"环流相对无流动状态做了多少功"，后者有更明确的物理含义。这条可迁移到任何"用强度量描述状态"的场合。
