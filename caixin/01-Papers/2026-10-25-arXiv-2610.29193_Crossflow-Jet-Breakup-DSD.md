# 横向气流中液柱射流破碎与液滴粒径分布动力学

**arXiv**: [2610.29193](https://arxiv.org/abs/2610.29193) · **提交**: 2026-10-21 04:28 UTC
**类别**: Fluid Dynamics (physics.flu-dyn)

## 一句话总结

用**高速阴影图 + 数字线内全息 (DIH)** 同步测量射流形貌与**体积液滴粒径分布**，揭示破碎机制的**下游演进**：近场**袋状破裂 (bag rupture)** → 下游**边缘、液带、节点解体**，对应特征长度尺度各异，粒径分布**逐向下游变宽、变多分散**；进一步系统扫描液柱/气流 Weber 数，建立**柱状破碎 / 孤立袋状破碎 / 相互干涉袋状**三区**regime map**，并纳入 **Rayleigh–Taylor 与 Rayleigh–Plateau 不稳定性**建立跨流向喷射雾化的理论框架。

---

## 核心贡献

1. **实验方法**：高速阴影图 + 数字线内全息 → 同时获得**射流形貌**与**体积粒径分布**
2. **破碎机制的明确演进路径**：
   - 近场：**袋状破裂 (bag rupture)**
   - 下游：**边缘 (rim) → 液带 (ligament) → 节点 (node) 解体**
   - 各机制对应**不同特征长度尺度**
3. **粒径分布演化**：向下游**变宽、变得多分散**（相对近场）
4. **Regime map**：系统扫描 Weber 数，划分**柱状破碎 / 孤立袋状破碎 / 相互干涉袋状**三区
5. **理论框架**：把 Rayleigh–Taylor（柱、袋、多袋模式）与 Rayleigh–Plateau 不稳定性纳入，**把不稳定性波长与特征液滴尺寸关联**，合理捕捉实验趋势

## 关键物理结论

| 结论 | 方向 |
|------|------|
| 更强的气动力 | 破碎**更早**发生 |
| 更强的气动力 | 不稳定性特征长度尺度**减小** |
| 更强的气动力 | 产生**更细**的液滴，分散在**更宽**的空间区域 |

## 数值方法评估

🥢 **可行性分析：横向气流中的液柱射流破碎与雾化**

### 控制方程
- 液柱：不可压 N-S（表面张力主导，惯性比 → Weber 数 $We = \rho_g U_g^2 D/\sigma$）
- 界面：VOF / Level Set / 尖锐界面（sharp interface）
- 破碎机制：Rayleigh–Plateau（毛细）、Rayleigh–Taylor（惯性剪切）

### 数值方法
- **离散化**：VOF（体积分数）或 Level Set；高阶界面捕捉（PLIC / 高阶 VOF）→ 分辨薄膜破裂
- **求解器**：显式推进 + 表面张力 CSF 力
- **稳定性**：VOF 界面输运有界性（boundedness）→ 需压缩/混合；表面张力时间步限制 $\Delta t \lesssim \sqrt{\rho \Delta x^3/\sigma}$

### 计算成本
| 维度 | 评估 |
|------|------|
| 主导开销 | **界面分辨率**（薄膜破裂需 ~10 单元/直径）→ 网格量级 $10^7$–$10^8$ |
| 时间步 | 表面张力限制 → 极小 |
| 域 | 单次射流事件 → 短时程，但细网格长时程成本高 |
| 并行性 | 强扩展（AMR 收益大：破碎区局部加密） |
| 后处理 | DIH 体积粒径分布 → **实验与 CFD 可直接对比** |

### 适用场景
- 燃油喷射雾化（燃烧、发动机）
- 冷却塔/喷淋/洗涤塔
- 海水淡化与气液接触
- 工业喷雾干燥

## 推荐结论

✅ **推荐实现（VOF 射流破碎是经典基准，实验对照数据价值高）**

**理由**：
1. **实验数据可直接对照**：DIH 提供的**体积液滴粒径分布**是罕见的定量基准 → 仿真结果有明确验证指标（不只看形貌）
2. **Regime map 实用**：We 数三区划分可直接用于工程选区
3. **理论框架可落地**：不稳定性波长 ↔ 液滴尺寸的关联式 → 可做**降阶预测模型**（无需 CFD 即估 DSD）
4. **数值方法成熟**：VOF 射流破碎有大量先例（OpenFOAM interFoam / Basilisk / FSPy），复现门槛可控

**注意事项**：
- ⚠️ **界面分辨率是主要成本** → 建议 AMR 或 level set（比 VOF 更省分辨率）
- ⚠️ 破碎后期**液滴-液滴相互作用、二次破碎**通常需**欧拉-拉格朗日混合方法**（VOF 难处理）→ 论文的 regime map 覆盖到哪一阶段需确认
- ⚠️ 实验中液柱来自特定喷嘴（条件流态）→ 与喷嘴几何强相关
- ⚠️ 理论框架「合理捕捉趋势」而非精确 → 定量精度有限

**对 @墨鱼丸 的实现建议**：
1. **适合做 VOF/Level Set 求解器的验证算例**
2. **实施路径**：
   - Step 1: 用 Basilisk（level set + AMR）或 FSPy 复现近场袋状破裂
   - Step 2: 扫 We 数复现 regime map 边界
   - Step 3: 加欧拉-拉格朗日粒子追踪做下游 DSD 对比
3. **判据**：复现近场袋状破裂形貌 + 三个 We 区边界位置 + 下游 DSD 展宽趋势
4. **可与 2610.30407（SAW 液滴喷射）形成互补**：一个是被动破碎，一个是主动驱动
