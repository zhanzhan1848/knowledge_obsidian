## 核心贡献

> 首次在**真实 IBM 量子硬件**（而非经典量子模拟器）上对一维量子格子玻尔兹曼方法 (QLBM) 做系统基准：量化了碰撞与输运算子的门数/深度开销，识别出它们是当前硬件的**首要可扩展性瓶颈**，并提出**基于采样的测量策略**直接重建宏观密度场，把全量子态层析 (tomography) 的高昂开销降到可接受范围。

1. **真机基准**：在三台不同的 IBM Quantum 硬件上执行转译后的 QLBM 电路，而非以往几乎完全依赖经典量子模拟器的研究。
2. **电路设计**：对**对流-扩散方程**构造量子电路，含**振幅编码 (amplitude encoding)**、**BGK 型碰撞算子**、**周期边界条件的输运步 (streaming step)**。
3. **性能量化**：评估转译后的**双比特门数**、**总电路深度**、**运行时间**。
4. **精度指标**：**最大绝对误差 ($L_\infty$ 范数)** 与 **RMSE**。
5. **瓶颈识别**：**碰撞与输运算子主导整体成本**，成为当前硬件上的首要可扩展性瓶颈。
6. **测量策略创新**：引入**基于采样的测量方法**，直接从**计算基测量**重建宏观密度场——大幅降低测量开销，同时在硬件上保持预期的对流-扩散动力学。

## 控制方程

### 1. 经典 LBM 演化（被量子化的对象）

**碰撞步 (collision)**：

$$\mathbf{f}^{*}_i(\mathbf{x},t) = \mathbf{f}_i(\mathbf{x},t) - \frac{1}{\tau}\Big(\mathbf{f}_i(\mathbf{x},t) - \mathbf{f}_i^{(eq)}(\mathbf{x},t)\Big)$$

$$\mathbf{f}^{(eq)}_i = w_i\,\mathbf{f}\left[1 + \frac{\mathbf{e}_i\cdot\mathbf{u}}{c_s^2} + \frac{(\mathbf{e}_i\cdot\mathbf{u})^2 - c_s^2|\mathbf{u}|^2}{2c_s^4}\right]$$

**输运步 (streaming)**：

$$\mathbf{f}_i(\mathbf{x}+\mathbf{e}_i,t+\Delta t) = \mathbf{f}^{*}_i(\mathbf{x},t)$$

$$\text{宏观量：}\quad \rho = \sum_i \mathbf{f}_i,\qquad \rho\mathbf{u} = \sum_i \mathbf{f}_i\,\mathbf{e}_i$$

### 2. 一维对流-扩散方程（基准测试对象）

$$\frac{\partial u}{\partial t} + u\,\frac{\partial u}{\partial x} = \nu\frac{\partial^2 u}{\partial x^2}$$

（QLBM 的 1D 情形，用于硬件验证与误差量化。）

### 3. 量子态编码

**振幅编码 (amplitude encoding)**：将 $2^n$ 个格点上的密度（或分布函数）映射为 $n$ 量子比特的振幅：

$$\lvert\psi\rangle = \sum_{j=0}^{2^n-1}\alpha_j\lvert j\rangle,\qquad \alpha_j \propto u_j$$

> 振幅编码的代价是**制备态需要 $\sim 2^n$ 深度的电路**——这是 QLBM 可扩展性的根源困难之一。

## 实验结论

- **碰撞与输运算子主导总成本**，是当前 NISQ 硬件上 QLBM 的**首要可扩展性瓶颈**。
- 转译后的双比特门数与电路深度是限制实际可模拟系统规模的核心指标。
- 采样式测量在硬件上**保持了预期的对流-扩散动力学**，同时大幅削减测量开销——验证了"只测物理可观测量"的可行性。
- 精度以 $L_\infty$ 与 RMSE 量化，展示了 NISQ 噪声下的误差水平。

---

## 局限性

- **仅一维**；未涉及二维/三维（振幅编码的状态数与门数将呈指数增长）。
- 仅对流-扩散方程；**未验证 Navier-Stokes** 完整不可压缩方程。
- **NISQ 阶段**：无错误纠正，噪声随深度累积，深度上限严格受限。
- 振幅编码的态制备开销未在本基准中充分优化（存在已知改进方案如近似态制备 / 经典-量子态准备协议）。
- 采样式测量只恢复**密度场**，损失了分布函数的高阶信息；对需要完整 $f_i$ 的分析（如非平衡诊断）是限制。
- 未与经典 LBM 的**同等规模**做直接速度对比（量子硬件的 wall-clock 优势在当前阶段尚未体现）。

## 实现建议

- **实现难度**：★★★★☆（Qiskit 电路构造 + 振幅编码态制备 + 噪声模型 vs 真机执行 + 采样后处理，工作量大且调试困难）
- **预期性能**：NISQ 条件下可处理**很小**的一维系统（十几个格点量级）；优势在于**量子硬件的并行采样**可在统计误差下降上获益
- **适用场景**：
  - 量子计算流体的**可行性评估与瓶颈定位**（研究阶段）
  - 教学/综述用途：明确指出 QLBM 的真实瓶颈在哪
  - 采样式测量策略可迁移到其它"只需可观测量"的量子 PDE 求解器
- **可迁移点**：
  1. **采样式重建可观测量**代替全态层析——这是量子 PDE 求解的通用节省技巧，应成为标准做法
  2. **把碰撞/输运算子成本作为首要优化目标**，而不是纠缠或编码——本文的结论对量子流体力学的路线图有直接指导意义
  3. 振幅编码的态制备是指数瓶颈，任何改进（近似制备、经典-量子混合制备）都应优先投入
  4. 与 FLUCS 这类 GPU 原生框架形成对照：**经典路线在可预见期内仍是主力**，量子路线属于长期探索
