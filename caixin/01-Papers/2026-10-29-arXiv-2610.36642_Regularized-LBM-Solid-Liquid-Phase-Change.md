## 核心贡献

> 在**正则化格子玻尔兹曼（RLB）**框架内求解**总焓方程**以精确追踪固液界面并抑制数值扩散，同时在标准 **D3Q27** 上发展 **MRT-RLB** 流场模型；配套高效 **CUDA C 多 GPU 实现**（z 向一维域分解 + 通信计算重叠）。

1. **总焓法 + 正则化碰撞**：在 RLB 框架内求解总焓方程，实现**固液界面厚度限制在一个格距内**——相比 LBGK 有「显著更大」的界面厚度（关键反扩散结果，效果可与 MRT/TRT 魔数相当）。
2. **MRT-RLB 流场模型**：在作者前期高阶晶格正则化碰撞模型基础上，建立标准 D3Q27 上的**多弛豫时间**流场解算器，含 Boussinesq 浮力。
3. **首次把高级正则化碰撞模型同时用于流场与焓变控制方程**（固液相变）。
4. **高效多 GPU 实现**：SoA 布局、融合 collision+streaming 核、z 向一维域分解、halo/ghost 交换与 **两次 CUDA event 同步**实现通信–计算重叠。
5. **四级验证**：一维两相导热熔化（解析解）、二维半无限角点凝固（解析+数值）、二维方腔对流熔化（FVM 对比）、三维长方体熔化（高 Ra）。

## 技术方案

### 核心思想

以**总焓 $En=h+\Delta En$**（$h=c_pT$，$\Delta En=f_lL_a$）为控制变量，用焓的区间判断固相/糊状区/液相，从而**无需显式追踪界面**即可精确定位相变前沿。

### 关键技术

| 技术 | 说明 |
|------|------|
| 热场求解 | 正则化 LBM，D2Q5 / D3Q7，$c_{s,T}^2=1/4$ |
| 流场求解 | **MRT-RLB**，D3Q27，$\theta=1$ 递归 Hermite 展开 |
| 平衡态 | 6 阶递归 Hermite 展开 |
| 非平衡态 | 4 阶正则化 |
| 边界条件 | **Guo 外推法**（无滑移 + 定温壁）、单边有限差分（Nusselt） |
| 固液界面 | **体积边界条件**（Huang & Wu 2016） |
| GPU | CUDA C，SoA，融合核，多 GPU z 向分解 |

## 公式

### 1. 总焓方程

```math
\frac{\partial\rho En}{\partial t}+\nabla\cdot(\rho En\,\bm{u})=\nabla\cdot(\lambda\nabla T)
```

```math
En=h+\Delta En,\qquad h=c_pT,\qquad \Delta En=f_lL_a
```

简化式：

```math
\frac{\partial\rho En}{\partial t}+\nabla\cdot(\rho h\,\bm{u})=\nabla\cdot(\lambda\nabla T)
```

### 2. 由焓求温度（三段式）

```math
T=\begin{cases}
\dfrac{En}{c_{ps}}, & En\le En_s\\[4pt]
T_s+\dfrac{En-En_s}{En_l-En_s}(T_l-T_s), & En_s<En<En_l\\[4pt]
T_l+\dfrac{En-En_l}{c_{pl}}, & En\ge En_l
\end{cases}
```

### 3. 液相分数与物性插值

```math
f_l=\begin{cases}0,& En\le En_s\\[2pt]\dfrac{En-En_s}{En_l-En_s},& En_s<En<En_l\\[2pt]1,& En\ge En_l\end{cases}
```

```math
\lambda=(1-f_l)\lambda_s+f_l\lambda_l
```

### 4. 流动方程（Boussinesq 浮力）

```math
\frac{\partial\rho}{\partial t}+\nabla\cdot(\rho\bm{u})=0
```

```math
\frac{\partial(\rho\bm{u})}{\partial t}+\nabla\cdot(\rho\bm{u}\bm{u})=-\nabla p+\nabla\cdot\left[\mu(\nabla\bm{u}+\nabla\bm{u}^{T})\right]+\bm{F}
```

```math
\bm{F}=-\rho_{ref}\beta\bm{g}(T-T_{ref})
```

### 5. 无量纲群

```math
\mathrm{Pr}=\frac{\nu_l}{\kappa_l},\qquad
\mathrm{Ra}=\frac{\beta_l g(T_h-T_l)L_c^{3}}{\nu_l\kappa_l},\qquad
\mathrm{Ste}=\frac{c_{pl}(T_h-T_m)}{L_a},\qquad
\mathrm{Fo}=\frac{\kappa_l t}{L_c^{2}}
```

### 6. RLB 平衡态

```math
g_{i}^{eq}(\bm{x},t)=\begin{cases}
En-(1-w_0)c_{p,ref}T, & i=0\\[4pt]
w_i c_{p,ref}T+w_i c_p T\dfrac{\bm{e}_i\cdot\bm{u}}{c_{s,T}^{2}}, & i\neq0
\end{cases}
```

- **D2Q5**：$\bm{e}_x=[0,1,0,-1,0]$，$\bm{e}_y=[0,0,1,0,-1]$；$w_i=[\tfrac12,\tfrac18\times4]$；$c_{s,T}^2=1/4$
- **D3Q7**：$\bm{e}_x=[0,1,-1,0,0,0,0]$，$\bm{e}_y=[0,0,0,1,-1,0,0]$，$\bm{e}_z=[0,0,0,0,0,1,-1]$；$w_i=[\tfrac14,\tfrac18\times6]$；$c_{s,T}^2=1/4$

### 7. 正则化非平衡态

```math
g_i(\bm{x}+\bm{e}_i\delta_t,t+\delta_t)=g_i^{eq}+\left(1-\frac{1}{\tau_g}\right)g_i^{neq,reg}
```

```math
g_i^{neq,reg}=w_i\sum_{n=0}^{1}\frac{1}{c_{s,T}^{2n}n!}\bm{a}^{(n)}_{neq}:\mathcal{H}^{(n)}(\bm{e}_i),\qquad
\bm{a}^{(0)}_{neq}=0,\ \bm{a}^{(1)}_{neq}=\sum_i[g_i-g_i^{eq}]\bm{e}_i
```

```math
g_i^{neq,reg}=w_i\frac{1}{c_{s,T}^{2}}\bm{a}^{(1)}_{neq}:\bm{e}_i
```

### 8. 含源项的完整演化

```math
g_i(\bm{x}+\bm{e}_i\delta_t,t+\delta_t)=g_i(\bm{x},t)-\frac{1}{\tau_g}\left[g_i-g_i^{eq}\right]+\delta_t S_i
```

```math
=g_i^{eq}+\left(1-\frac{1}{\tau_g}\right)\frac{w_i}{c_{s,T}^{2}}\left[\bm{a}^{(1)}_{neq}:\bm{e}_i\right]
+\delta_t\left(1-\frac{1}{2\tau_g}\right)\frac{w_i}{c_{s,T}^{2}}\bm{e}_i\cdot\frac{\partial(c_pT\bm{u})}{\partial t}
```

源项矩条件：$\sum_i S_i=0$；$\sum_i S_ie_i=\left(1-\frac{1}{2\tau_g}\right)\frac{\partial(c_pT\bm{u})}{\partial t}$。
**⚠️ 论文中该源项在实际模拟中被直接忽略**（时间导数用显式欧拉离散）。

### 9. Chapman–Enskog 恢复（多尺度展开）

```math
\partial_t=\epsilon\partial_{t_1}+\epsilon^2\partial_{t_2},\qquad \nabla=\epsilon\nabla_1,\qquad
g_i=g_i^{(0)}+\epsilon g_i^{(1)}+\epsilon^2 g_i^{(2)},\qquad S_i=\epsilon S_i^{(1)}
```

```math
O(\epsilon^0):\ g_i^{(0)}=g_i^{eq}
```

```math
O(\epsilon^1):\ (\partial_{t_1}+\bm{e}_i\cdot\nabla_1)g_i^{(0)}=-\frac{1}{\delta_t\tau_g}\frac{w_i}{c_{s,T}^2}[\bm{a}^{(1)}_{neq}:\bm{e}_i]+S_i^{(1)}
```

```math
O(\epsilon^2):\ \frac{\partial g_i^{(0)}}{\partial t_2}+\left(\partial_{t_1}+\bm{e}_i\cdot\nabla_1\right)\left(1-\frac{1}{2\tau_g}\right)\frac{w_i}{c_{s,T}^{2}}[\bm{a}^{(1)}_{neq}:\bm{e}_i]=-\frac{1}{\delta_t\tau_g}g_i^{(2)}-\frac{\delta_t}{2}\left(\partial_{t_1}+\bm{e}_i\cdot\nabla_1\right)S_i^{(1)}
```

二阶结果：

```math
\partial_{t_2}En=\nabla_1\cdot[\delta_t(\tau_g-\tfrac12)c_{p,ref}c_{s,T}^2\nabla_1T]
```

```math
\frac{\partial En}{\partial t}+\nabla\cdot(c_pT\bm{u})=\nabla\cdot(\lambda\nabla T),\qquad
\frac{\lambda}{\rho c_{p,ref}}=\delta_t c_{s,T}^{2}\left(\tau_{g}-\frac{1}{2}\right)
```

### 10. MRT-RLB 递归碰撞（$\theta=1$）

```math
\bm{a}^{(2)}_{\Omega}=\left(1-\frac{1}{\tau_2}\right)\left(\bm{a}^{(2)}_1-2\bm{u}\bm{a}^{(1)}_1\right)+\bm{F}\bm{u}
=\bm{a}^{(2)}_1-\left(\frac{1}{\tau_{21}}\bm{a}^{(2,1)}_1+\frac{1}{\tau_{22}}\bm{a}^{(2,2)}_1\right)
+\bm{a}^{(2)}_{\bm{F}}-\left(\frac{1}{2\tau_{21}}\bm{a}^{(2,1)}_{\bm{F}}+\frac{1}{2\tau_{22}}\bm{a}^{(2,2)}_{\bm{F}}\right)
```

其中 $\bm{a}^{(2,1)}_1$ / $\bm{a}^{(2,2)}_1$ 为二阶非平衡矩的无迹 / 有迹分量。

### 11. 力的 Hermite 系数

```math
\bm{a}^{(0)}_{\bm{F}}=0,\quad \bm{a}^{(1)}_{\bm{F}}=\bm{F},\quad
\bm{a}^{(2)}_{\bm{F}}=2\bm{F}\bm{u},\quad
\bm{a}^{(3)}_{\bm{F}}=3\bm{F}\bm{u}\bm{u},\quad
\bm{a}^{(4)}_{\bm{F}}=4\bm{F}\bm{u}\bm{u}\bm{u}
```

### 12. 固液界面体积边界条件（Huang & Wu 2016）

```math
f_{i}^{+}=f_l f_i+(1-f_l)f_i^{eq}(\rho,\bm{u}_s),\qquad
\rho=\sum_i f_i^{+},\qquad
\rho\bm{u}=\sum_i f_i^{+}\bm{e}_i+\frac{\delta_t}{2}\rho\bm{F},\qquad \bm{u}_s=0
```

### 13. 弛豫时间与性能指标

```math
\tau_g=\frac{1}{\omega_g}=\frac{\kappa}{c_{s,T}^2\Delta t}+\frac12
```

```math
\mathrm{MNUPS}=\frac{xDim\,yDim\,zDim}{\text{clocktime}\times10^6}\cdot\text{timestep}
```

```math
\text{Bytes-per-node}=(2Q+5+4+2QT+3+3)\times8
```

## 实验结论

### 基准 1：一维两相导热熔化（半无限）

解析解（Hu & Argyropoulos 1996）：

```math
T(x,t)=\begin{cases}
T_h-\dfrac{T_h-T_m}{\erf(\eta)}\erf\!\left(\dfrac{x}{2\sqrt{\kappa_l t}}\right), & 0\le x\le X(t)\\[8pt]
T_i+\dfrac{T_m-T_i}{\erfc(\eta\sqrt{\kappa_l/\kappa_s})}\erfc\!\left(\dfrac{x}{2\sqrt{\kappa_s t}}\right), & x>X(t)
\end{cases}
```

```math
X(t)=2\eta\sqrt{\kappa_l t}
```

参数：$T_h=1$，$T_m=0$，$T_i=-1$；$c_{pl}=c_{ps}=1$；$\kappa_s=0.02$；$\mathrm{Ste}_l=1.0$；$\kappa_l/\kappa_s\in\{1,2,3,5\}$；$\tau_{g,l}\in\{0.58,1.0,2.5,4.5,10.5\}$；$\tau_\nu=1.0$；网格 **448×6**；$\mathrm{Fo}=\kappa_s t/L_c^2=0.01$，$L_c=448$。

**结果**：所有 $\kappa_l/\kappa_s$ 下与解析解「excellent agreements」。**RLB 把界面厚度限制在一个格距内**，而 LBGK 产生「显著更大」的界面厚度。

### 基准 2：二维半无限角点凝固

$T_i=0.3$，$T_m=0$，$T_c=-1.0$，$T_s=-0.01$，$T_l=0.01$；$c_{pl}=c_{ps}=1$，$\kappa_l=\kappa_s=0.2$，$\mathrm{Ste}=4.0$；$L_x=L_y=128$，$L_c=0.5L_x$；对比时刻 $\mathrm{Fo}=0.25$；参考 = Rathjen & Jiji (1971) 解析 + Lin & Chen (1997) 数值。

**结果**：固液界面吻合良好；等温线（$T=-0.8$ 到 $0.2$，间隔 0.2）与参考数值一致。

### 基准 3：二维方腔对流熔化

$T_h=1$，$T_m=0$，$T_{ref}=0$，$T_s=T_l=T_m$；$c_{ps}=c_{pl}=1$，$\kappa_s=\kappa_l=0.2$。

| 工况 | Ra | Pr | Ste | 网格 |
|---|---|---|---|---|
| Case 1 | 2.5×10⁴ | 0.02 | 0.01 | 128², 256², 512² |
| Case 2 | 2.5×10⁵ | 0.02 | 0.01 | 同上 |

采样间隔 20,000 步，总计 **9,750,000 步**；参考 = Mencinger (2004) FVM。

**结果**：左（加热）壁面平均 Nusselt 数与总液相分数与 FVM 吻合极好，三种网格均验证了网格收敛性。Case 2 验证聚焦于全局液相分数（因 Mencinger 的基准 Nusselt 数有剧烈振荡，难以数字化）。

### 基准 4：三维长方体熔化

z 壁面无滑移 + 绝热；x/y 壁面同二维。

| 工况 | Pr | Ste | Ra | 网格 |
|---|---|---|---|---|
| Case 1 | 0.02 | 0.4 | 2.5×10⁴ | 192×192×64, 384×384×128 |
| Case 2 | 10 | 0.4 | 2.5×10⁴ | 同上 |
| Case 3 | 10 | 0.4 | 1.0×10⁶ | 256×256×128, 512×512×256 |

参考：Li et al. (2017)。**结果**：Case 1/2 定量吻合；Case 3 初期吻合很好，后期偏差归因于高 Ra 下**剧烈的对流主导流动**。每工况两套网格确认网格无关性。

- 弱扩展：256×256×1024 节点/卡，8 GPU 内接近 **100% 并行效率**

## 局限性

1. **物理假设**：可压性忽略；Boussinesq 浮力；忽略体积膨胀；各相内热物性恒定；**忽略粘性耗散与压力功**。
2. **源项 $S_i$ 在实际模拟中被直接忽略**（只有 $O(\epsilon)$ 一阶项有贡献）。
3. Case 3（高 Ra）后期与参考存在偏差（且该参考本身未与其他文献对比）。
4. 每工况仅两套分辨率做网格无关性。
5. **无代码/数据公开声明**。
6. 温度导数用显式欧拉（时间二阶精度受限）。

## 实现建议

- **实现难度**：中–高（两个 LBM 子模型 + 相变耦合 + 多 GPU 通信）。
- **预期性能**：512³ 单卡 1833 MNUPS（59.69% 带宽效率）；8 GPU 近 100% 弱扩展效率。
- **适用场景**：
  - 固液相变（熔化/凝固）的三维大规模模拟
  - PCM（相变储能）热管理
  - 冰层融化、海冰热力学
- **落地建议**：
  1. **先复现基准 1（一维解析解）**——这是验证「界面厚度限制在一个格距」最干净的检验，LBGK 与 RLB 的差异一目了然
  2. **不要忽略源项的含义**：论文忽略 $S_i$ 是因为只有 $O(\epsilon)$ 贡献；但若做**高 Pr/高 Ste 的定量精度工作**，需评估该项
  3. **GPU 实现优先级**：融合 collision+streaming 核 → SoA → z 向一维分解 + halo/ghost 交换 → event 重叠。Guo BC 核占 10% 时间，是后续优化的首要目标
  4. **占用率调优**：`__launch_bounds__(256)` + `-maxrregcount=168` 是本文给出的实测有效组合（8 → 12 warps/SM）
  5. **界面处理**：焓法的「三段式 $T(En)$」是核心——不要用相场或 VOF 追踪界面，否则失去正则化带来的锐利界面优势
  6. **与 [[MRT-Total-Enthalpy-LBM]]（2610.36575）对照阅读**：那篇是**液–汽**相变 + 伪势 LBM 多相，本文是**固–液**相变 + 正则化 LBM 单相；两篇的「总焓 + 多弛豫时间」路线高度同源，可对照学习相变建模的两种分岔
  7. **与 [[Curvilinear-D3Q27-Cumulant-LBM]]（2610.36971）对照**：本文流场用 D3Q27 + MRT-RLB；那篇用 D3Q27 + 累积量 + 曲线几何——**累积量碰撞 + 曲线几何**可作为本文流场模块的升级方向
