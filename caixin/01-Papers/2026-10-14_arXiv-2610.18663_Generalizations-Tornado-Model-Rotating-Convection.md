## 核心贡献

> 把龙卷风视为 **Schwarzschild 对流不稳定** 驱动的旋转对流系统，从最简模型到完整模型给出三层层级化解析框架

1. **Schwarzschild 不稳定** 作为龙卷风生成的物理机制（过冷却云气下沉 + 超绝热地表气上升）
2. **三层模型**：
   - **最简模型 (Simplest model)**：仅流函数方程，初始涡度生成阶段
   - **精化模型 (Refined model)**：理想流体旋转对流，引入环向速度与密度变化
   - **完整模型 (Full model)**：流函数 + 环向速度 + 密度方程全耦合，贯穿瞬态到准稳态
3. **解析构造**：最简模型下，水平方向 8 段线性依赖组合出闭式解析解
4. **两涡眼结构 (two-eyed tornado)** 与单涡眼对比，给出**径向汇流 + 顶部 outflow** 的拓扑
5. **生成判据**：最大垂直速度不在轴上而在某半径处；最大环向速度位于龙卷"壁面"

## 技术方案

### 核心思想

把龙卷风当作**理想流体旋转对流**的准稳态终态，用 Schwarzschild 对流不稳定性作为初始驱动，通过角动量守恒实现涡度放大。三层结构对应物理复杂度的渐进扩展。

### 关键技术

| 技术 | 说明 |
|------|------|
| Schwarzschild 对流不稳定判据 | 超绝热梯度 → 上下双向对流启动 |
| 流函数 - 环向速度 - 密度全耦合 | 完整 Boussinesq-like 系统（无密度层高估时） |
| 解析构造（最简模型） | 8 段线性依赖水平叠加；闭式解 |
| 角动量守恒 | \(L = \rho v_\theta r\) 守恒 → 径向收缩时 \(v_\theta\) 放大 |
| 单涡眼 vs 双涡眼 | 拓扑分类；后者有内壁 outflow |
| 边界条件 (no-slip / far-field) | 引入局部 / 整体旋转差异 |

### 控制方程 (完整模型)

流函数 \(\psi(r,z)\) 与环向速度 \(v_\theta(r,z)\)、密度扰动 \(\rho'(r,z)\)：

```math
\frac{\partial}{\partial t}(\nabla^2 \psi) + \frac{1}{r}\frac{\partial(\psi, \nabla^2 \psi)}{\partial(r,z)} = -2\omega \frac{\partial v_\theta}{\partial z} + g \alpha \frac{\partial T'}{\partial r}
```

```math
\frac{\partial v_\theta}{\partial t} + \frac{1}{r}\frac{\partial(\psi, r v_\theta)}{\partial(r,z)} = 0  \quad \text{(角动量近似守恒)}
```

```math
\frac{\partial T'}{\partial t} + \frac{1}{r}\frac{\partial(\psi, T')}{\partial(r,z)} = -\frac{N^2}{g\alpha}\,w
```

其中 \(N^2\) 为 Brunt-Väisälä 频率，\(\alpha\) 为热膨胀系数，\(\omega\) 为系统旋转。

### 关键闭式结果 (最简模型)

```math
\psi(r,z) = \sum_{k=1}^{8} a_k(z)\, r^k
```

8 段线性 \(\times\) 高度依赖组合，环向速度：

```math
v_\theta(r, z) = \frac{L(r,z)}{r}, \quad L = \text{angular momentum conserved along streamline}
```

## 实验 / 验证

- **方法**：纯解析（无 DNS / 实验对照）
- **结果**：
  - 单涡眼龙卷：径向汇流至轴心，顶部 outflow 至"壁面"和外围
  - 双涡眼：内壁 outflow 分流，最大 \(w\) 在某 \(r_c\) 处
  - 最大 \(v_\theta\) 在龙卷"壁面"（梯度极值点）
  - 生成判据：Schwarzschild 数 \(S = N^2/(\mathrm{superadiabatic\ gradient}) > 1\)

---

## 局限性

- **理想流体假设**：忽略粘性扩散，旋涡耗散机制未涵盖
- **解析模型仅最简层**：完整模型仍依赖数值积分（虽然公式齐备）
- **无湍流闭合**：实际龙卷为强湍流，本框架仅准稳态终态
- **环境场简化**：假设轴对称 + 静力平衡背景场，无背景风切变
