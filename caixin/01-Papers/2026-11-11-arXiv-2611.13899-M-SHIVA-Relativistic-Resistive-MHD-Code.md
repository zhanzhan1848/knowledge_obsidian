## 核心贡献

> 发布 **M-SHIVA 1.0**：(2+1) 维**相对论电阻磁流体力学**求解器，用于重离子碰撞，支持**笛卡尔与 boost-invariant Milne 坐标**；采用 **IMEX Runge-Kutta** 处理刚性电导依赖项，配**原始变量恢复程序**与 **GLM 散度清洁**；通过标准基准验证后，用于研究 QGP 中的**动量各向异性与焦耳加热**，结论是：**焦耳加热与膨胀冷却之比在所有体系中都小 7–10 个数量级**，因此对动量各向异性**无可观影响**。

1. **求解器实现**：**(2+1) 维相对论电阻 MHD**，覆盖 Cartesian 与 boost-invariant **Milne 坐标**（重离子碰撞的天然坐标）。
2. **数值方法**：**IMEX Runge-Kutta (RK)** 显式–隐式混合，处理**刚性**的电导率依赖项（电阻率 $\propto 1/\sigma(T)$，低温时 $\sigma\to 0$ 导致刚性剧增）。
3. **完备的辅助组件**：**原始变量恢复 (primitive variable recovery)** 程序 + **GLM 散度清洁 (divergence cleaning)** 处理磁场散度约束。
4. **标准基准验证**：激波管、柱状爆轰波、相对论转子（rotor）三个标准基准全部复现。
5. **物理应用结论**：
   - 电磁场对总动量各向异性的影响**主要通过直接贡献横向应力张量**实现，而物质各向异性仅**弱受影响**；
   - 将电磁功分解为**机械洛伦兹力功**与**不可逆焦耳加热**；
   - **焦耳加热/膨胀冷却之比**：Pb+Pb @ 2.76 TeV 为 $10^{-14}$–$10^{-11}$；Au+Au @ 200 GeV 为 $10^{-8}$–$10^{-5}$；Au+Au @ 62.4 GeV 为 $10^{-7}$–$10^{-4}$；
   - **无明显电导率依赖**；焦耳加热随碰撞能量降低**增长数个数量级**，但**对所有体系仍远小于纵向膨胀冷却**。

## 技术方案

### 核心思想

在**重离子碰撞**中，初始纵向动量的各向异性（$\langle p_y\rangle/\langle p_x\rangle \approx 0$）是 QGP 的标志性特征。标准解释是**流体初始条件**（Landau 流体化）产生的粘性耗散。但还存在着另一种可能机制：**初始电磁场**在强导电介质中产生**焦耳加热**，从而在物质中引入动量各向异性。

要评估这一机制，需要一个**自洽求解**的相对论电阻 MHD 代码——因为电流是**随时间演化并反馈回流体**的（电导率随温度变化，而温度被焦耳加热影响），无法用单次估算。

**M-SHIVA**（SHIVA = **S**elf-consistent **H**ydrodynamical **I**nteraction with **V**iscous **A**nomalous fluxes 的首字母缩写）正是这一用途的代码，本版本 (1.0) 加入了**电阻**（resistive）MHD 能力。

关键的数值困难是**刚性**：电阻 MHD 中的欧姆定律
$$\boldsymbol{j} = \sigma(T)\,(\boldsymbol{E}+\boldsymbol{v}\times\boldsymbol{B}),\qquad \boldsymbol{E} = -\boldsymbol{v}\times\boldsymbol{B}-\frac{1}{\sigma}\boldsymbol{j}$$
在**低温区**（离子相，QGP 初期）电导率 $\sigma(T)$ 极小，$\sigma^{-1}$ 极大，导致显式求解的时间步被 $\Delta t \sim \sigma/|\boldsymbol{B}|^2$ 限制——这是一个**硬刚性**问题。本文用 **IMEX Runge-Kutta**：把刚性项（$\boldsymbol{j}$ 的弛豫）隐式处理，把其余（流体演化）显式处理，从而在保持稳定的同时允许大步长。

### 关键技术

| 技术 | 说明 |
|------|------|
| 相对论电阻 MHD | $(2+1)$ 维，含欧姆耗散 |
| Milne 坐标 | boost-invariant 坐标，重离子碰撞的标准坐标 |
| IMEX Runge-Kutta | 显式–隐式混合，处理刚性电导项 |
| GLM 散度清洁 | 保持 $\nabla\cdot\boldsymbol{B}=0$ 的约束满足 |
| 原始变量恢复 | 从守恒变量 $(\rho, \boldsymbol{E},\boldsymbol{B})$ 恢复原始变量 $(D,\boldsymbol{v},p,\gamma)$ |
| 温度依赖电导率 | 采用格点 QCD 结果启发的 $\sigma(T)$ |
| 光学 Glauber 物质分布 | 初始物质剖面 |
| 旁观者生成的电磁场 | 初始电磁场来源 |
| 标准基准集 | 激波管、柱状爆轰波、相对论转子 |

## 公式 / 理论要点

```math
% 相对论电阻 MHD 守恒形式
\frac{\partial D}{\partial t} + \nabla\cdot(D\boldsymbol{v}) = 0
```

```math
% 动量（含粘性与电阻修正）
\frac{\partial \boldsymbol{S}}{\partial t}
+ \nabla\cdot\left(\boldsymbol{S}\otimes\frac{\boldsymbol{v}}{D}+\boldsymbol{P}\right)
= \nabla\cdot\left(\eta\,\nabla\boldsymbol{v}+\frac{4}{3}\eta\,\nabla\cdot\boldsymbol{v}\,\boldsymbol{I}\right)
+ \boldsymbol{j}\times\boldsymbol{B}
```

```math
% 能量方程（含粘性耗散 + 焦耳加热）
\frac{\partial E}{\partial t}+\nabla\cdot\left((E+p)\boldsymbol{v}\right)
= -\nabla\cdot\left(\boldsymbol{h}\otimes\boldsymbol{v}\right)
-\nabla\cdot\left[\eta\,\nabla\boldsymbol{v}\cdot\boldsymbol{v}
+\frac{4}{3}\eta(\nabla\cdot\boldsymbol{v})^2\boldsymbol{I}\right]
+\boldsymbol{j}\cdot\boldsymbol{E}
```

```math
% 麦克斯韦方程 + 欧姆定律（电阻 MHD）
\frac{\partial \boldsymbol{B}}{\partial t}
= -\nabla\times(\boldsymbol{v}\times\boldsymbol{B})
+\frac{1}{\sigma}\nabla\times\big(\nabla\times\boldsymbol{B}\big),
\qquad
\boldsymbol{j}=\sigma(\boldsymbol{E}+\boldsymbol{v}\times\boldsymbol{B})
```

```math
% 刚性来源：欧姆弛豫时间（低温区极小）
\tau_{\text{Ohm}} \sim \frac{\sigma}{|\boldsymbol{B}|^2},
\qquad
\Delta t_{\text{explicit}} \lesssim \tau_{\text{Ohm}}
\quad\Longrightarrow\quad
\text{IMEX：隐式处理}\ \frac{1}{\sigma}\nabla\times\nabla\times\boldsymbol{B}
```

```math
% 动量各向异性
\delta = \frac{\langle p_y\rangle-\langle p_x\rangle}{\langle p_y\rangle+\langle p_x\rangle}
\qquad
\left(\frac{\langle p_y\rangle}{\langle p_x\rangle}\right)_{\text{initial}}\approx 0
```

```math
% 焦耳加热 vs 膨胀冷却（核心判据）
\frac{\dot{E}_{\text{Joule}}}{\dot{E}_{\text{expansion}}}
\approx 10^{-14}\!-\!10^{-4}
\quad\Longrightarrow\quad
\text{焦耳加热可忽略}
```

## 实验与结果

- **算例/数据集**:
  - **基准验证**：激波管、柱状爆轰波、相对论转子；
  - **物理应用**：椭圆火球 (elliptic fireball) 构型；Au+Au @ $\sqrt{s_{NN}}=62.4$ 与 200 GeV；Pb+Pb @ $\sqrt{s_{NN}}=2.76$ TeV。
- **参数设定**: **光学 Glauber 物质分布**；**旁观者生成的电磁场**；**温度依赖电导率**（格点 QCD 启发）。
- **对比基线**: 各向异性流体初始条件（Landau 流体化）作为标准解释；无电磁场情形。
- **主要结果**:
  - **三个标准基准全部复现**。
  - **电磁场主要通过直接贡献横向应力张量**影响总动量各向异性；**物质各向异性仅弱受影响**。
  - **电磁功分解**：机械洛伦兹力功 vs 不可逆焦耳加热。
  - **焦耳加热/膨胀冷却比**：
    - Pb+Pb @ 2.76 TeV：$10^{-14}$–$10^{-11}$；
    - Au+Au @ 200 GeV：$10^{-8}$–$10^{-5}$；
    - Au+Au @ 62.4 GeV：$10^{-7}$–$10^{-4}$。
  - **电导率无明显影响**（对物质与总动量各向异性均然）。
  - **趋势**：焦耳加热随碰撞能量下降**增长数个数量级**，但**对所有体系仍远小于纵向膨胀冷却**。

## 局限性

- **(2+1) 维**：无横向（$\eta$ 方向）空间分辨——而横向涨落正是 QGP 初始态各向异性的核心。
- **线性粘性 + 理想流体**：未包含非线性粘性、磁粘性、bulk viscosity、耗散反演 (DREAM) 等。
- **电磁场来源简化**：用旁观者模型生成初始场，未自洽地包含碰撞中实际产生的电磁辐射（这恰恰是真实机制）。
- **电导率模型简化**：温度依赖 $\sigma(T)$ 采用格点 QCD 启发形式；实际电导率还受磁场的朗道阻尼影响。
- **未包含重离子碰撞的初始碰撞几何复杂性**（光学 Glauber 是最简模型）。

## 实现建议

- **实现难度**: 高 — 相对论电阻 MHD + Milne 坐标 + IMEX-RK + GLM 清洁 + 原始变量恢复，是多组件强耦合的代码工作；但可基于既有 SHIVA 代码库扩展（作者即 SHIVA 开发者）。
- **预期性能**: IMEX 使低温高刚性区可用大时间步；结论（本体系焦耳加热可忽略）意味着**该机制的物理重要性低**。
- **适用场景**:
  - **重离子碰撞初始态动量各向异性**的机理研究；
  - **磁流体（MHD）求解器**在强电场/高导电介质中的数值方法参考；
  - 教学：**IMEX-RK 处理刚性欧姆项**是一个可迁移的数值技术范例（也可用于含磁压低、电阻扩散的磁流体问题，如磁重联、太阳物理）。
- **可复用要点**:
  - **IMEX 处理"低温 → 高刚性"结构**的思路可推广：任何存在"参数在某区域急剧变化导致刚性剧增"的方程（如电阻等离子体、磁重联、低温等离子体输运）都适用。
  - **GLM 散度清洁**是磁流体代码的标准组件，任何 $\nabla\cdot\boldsymbol{B}$ 约束的数值实现都应考虑。
  - **"把电磁功分解为机械功与不可逆耗散"** 是一个值得学习的能量账目分析方法——它把"电磁场是否驱动各向异性"这个问题从定性变定量，且结论（比值 7–10 个数量级）具有**否证力**，可直接用于排除机制。
  - 本文与本轮 [[2026-11-11-arXiv-2611.13727 CLUGKS]] 同属"**动理学/磁流体新格式 + 严格基准验证**"路线，但物理问题域不同（重离子碰撞 vs 高超声速），可对照阅读格式层面的共性。
