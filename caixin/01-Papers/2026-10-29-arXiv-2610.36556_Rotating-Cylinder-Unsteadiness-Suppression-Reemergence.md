## 核心贡献

> 在 $Re_\infty=3800$、$M_\infty=0.1$ 的二维可压缩绕流中，系统扫描 $0.1\le\Omega\le10$ 的**130 组高保真仿真**，首次刻画出：**常规卡门涡脱在 $\Omega=2.2$–2.8 的窄过渡区被抑制**（FFT 幅值从 0.35 降到 <0.007，近两个数量级），但**高转速下失稳以完全不同的间歇性多尺度形式重新出现**——这不是卡门涡脱的恢复，而是本质不同的不稳定机制。

1. **130 组系统数据库**：$\Omega$ 每 0.1 采样（$0.1\le\Omega\le7.0$），$7.0<\Omega\le10$ 每 0.05 采样（因 $C_d$ 在此区间快速变化）。
2. **窄过渡区识别**：$\Omega=2.2$（持续 $f\approx0.19$ 大幅振荡）→ $\Omega=2.3$（幅值降至 0.06）→ $\Omega=2.4$（间歇波包，0.03–0.04）→ $\Omega=2.5$（近静止，<0.007）→ $\Omega\in[2.6,3.4]$ 同样被抑制 → $\Omega=3.5$（**两个**不同频率的峰，≈0.05 与 ≈0.035）。
3. **重新出现的失稳本质不同**：间歇性、多尺度特征，**不是**低转速模式的延续。
4. **转速产生局部 Ma ≈ 0.5**：尽管 $M_\infty=0.1$，$M_{\rm local}$ 最大达 **0.51**（$M_\infty$ 的约 5 倍）→ 自由流马赫数不足以判断可压缩性效应。最大值**不随 $\Omega$ 线性增长**。
5. **气动载荷重分布**：最小 $C_p$ 从 −10（$\Omega=2.5$）→ −25（$\Omega=5$）→ **−47**（$\Omega=10$）；阻力呈**非单调**响应；升力最大值**单调**增加。
6. **涡量 POD 的结构重组**：捕获 99% 总涡量所需的模态数从 **90**（$\Omega=0.1$）→ **6**（$\Omega=2.5$）→ **37**（$\Omega=5$）→ **66**（$\Omega=10$）；高转速下结构从「尾流主导」变为「绕圆柱的环形/缠绕结构」。

## 技术方案

### 核心思想

二维可压缩 Navier–Stokes 的**强守恒形式**，在贴体 O 型网格上用**谱精度通量格式 + 人工粘性 + 三阶段 RK** 求解。

### 关键技术

| 技术 | 说明 |
|------|------|
| 空间格式（对流通量） | **OUCS3**（Optimized Upwind Compact Scheme，3 阶）——宽波数范围内近谱分辨率 |
| 空间格式（粘性通量） | 非均匀显式中心差分 |
| 人工粘性 | **4 阶 Jameson 人工扩散**，系数 **0.0150** |
| 时间推进 | **OCRK3**（Optimized 3-Stage Runge–Kutta），无量纲 $\Delta t=1.25\times10^{-5}$ |
| 网格 | 贴体 **O 型**网格（Pointwise 双曲网格生成），**401（周向 $\xi$）× 450（径向 $\eta$）** |
| 径向聚集 | 双曲正切拉伸，$r_{max}=30D$，$\beta=3$ → $\Delta r_{wall}=0.0005D$ |
| 并行 | 自研 MPI + **NOHAP**（non-overlapping high-accuracy parallel）域分解，无接口误差 |
| 边界 | 圆柱无滑移 + **绝热**壁面；远场 **30D**，**基于特征**的边界条件 |
| 后处理 | FFT 升力谱、涡量探针、涡量 POD |

## 公式

### 1. 可压缩 NS（强守恒形式）

```math
\frac{\partial\hat{Q}}{\partial t}+\frac{\partial\hat{E}}{\partial x}+\frac{\partial\hat{F}}{\partial y}
=\frac{\partial\hat{E}_v}{\partial x}+\frac{\partial\hat{F}_v}{\partial y}
```

```math
\hat{Q}=[\rho,\;\rho u,\;\rho v,\;e_t]^T
```

```math
\hat{E}=[\rho u,\;\rho u^2+p,\;\rho uv,\;(\rho e_t+p)u]^T;\qquad
\hat{F}=[\rho v,\;\rho uv,\;\rho v^2+p,\;(\rho e_t+p)v]^T
```

```math
\hat{E}_v=[0,\;\tau_{xx},\;\tau_{xy},\;(u\tau_{xx}+v\tau_{xy}-q_x)]^T
```

```math
\hat{F}_v=[0,\;\tau_{yx},\;\tau_{yy},\;(u\tau_{yx}+v\tau_{yy}-q_y)]^T
```

### 2. 无量纲化

```math
Pr=\frac{\mu_\infty C_p}{\kappa},\qquad
Re_\infty=\frac{\rho_\infty U_\infty D}{\mu_\infty},\qquad
M_\infty=\frac{U_\infty}{\sqrt{\gamma R^*T_\infty}}
```

```math
\gamma=1.4,\qquad R=R^*T_\infty/U_\infty^2,\qquad
p_\infty=\rho_\infty R^*T_\infty,\qquad p=\rho RT,\qquad
e_t=C_vT+\frac12(u^2+v^2)
```

```math
q_x=-\frac{\mu}{Pr\,Re_\infty(\gamma-1)M_\infty^{2}}\frac{\partial T}{\partial x},\qquad
q_y=-\frac{\mu}{Pr\,Re_\infty(\gamma-1)M_\infty^{2}}\frac{\partial T}{\partial y}
```

体粘性（Stokes 假设）：$\lambda=-\frac{2}{3}\mu$；$\mu(T)$ 用 **Sutherland 定律**。

### 3. 贴体坐标变换

```math
\bm{Q}=\hat{Q}/J;\qquad
\bm{E}=(\xi_x\hat{E}+\xi_y\hat{F})/J;\qquad
\bm{F}=(\eta_x\hat{E}+\eta_y\hat{F})/J
```

```math
\bm{E}_v=(\xi_x\hat{E}_v+\xi_y\hat{F}_v)/J;\qquad
\bm{F}_v=(\eta_x\hat{E}_v+\eta_y\hat{F}_v)/J
```

```math
J=\frac{1}{x_\xi y_\eta-x_\eta y_\xi};\qquad
\xi_x=Jy_\eta,\ \xi_y=-Jx_\eta,\ \eta_x=-Jy_\xi,\ \eta_y=Jx_\xi
```

### 4. 转速定义

```math
U_s^*=\Omega^*D/2,\qquad \Omega=\frac{U_s^*}{U_\infty}=\frac{\Omega^*D}{2U_\infty}
```

### 5. 径向网格聚集

```math
r(\eta)=0.5+r_{\max}\left[1-\frac{\tanh\left\{\beta\left(\frac{N_\eta-\eta}{N_\eta-1}\right)\right\}}{\tanh(\beta)}\right]
```

$r_{max}=30D$，$\beta=3$ → $\Delta r_{wall}=0.0005D$。

### 6. 涡量 POD

```math
\omega'(\bm{X},t)=\sum_{m=1}^{M}a_m(t)\phi_m(\bm{X})
```

```math
R_{ij}=\frac{1}{M}\int_{S}\omega'(\bm{X},t_i)\,\omega'(\bm{X},t_j)\,dS,\qquad
a_i(t)=\frac{\int_S\omega'(\bm{X},t)\phi_i(\bm{X})dS}{\int_S\phi_i^2(\bm{X})dS}
```

## 实验结论

### 计算设置

| 项目 | 值 |
|---|---|
| 流动 | 空气，$T_\infty=288.15$ K，$\rho_\infty=1.2256$ kg/m³，$Pr=0.71$ |
| 工况 | $Re_\infty=3800$，$M_\infty=0.1$，$0.1\le\Omega\le10$ |
| 网格 | 401 × 450（O 型贴体） |
| 时间步 | $\Delta t=1.25\times10^{-5}$（无量纲） |
| 人工粘性 | 4 阶 Jameson，系数 0.0150 |
| 网格无关性 | 三种 $\Delta r_{wall}$：0.0005D / 0.001D / 0.002D，**最细两种给出几乎相同的 $C_l$** |
| 仿真数 | 130 组 |
| 并行验证 | NOHAP 域分解与串行结果吻合到**机器精度** |
| 算力 | 约 130 万核时 |

### 升力谱与相变（FFT）

| $\Omega$ | 升力谱特征 | FFT 幅值 |
|---|---|---|
| 0.1 | 宽带，能量集中在 $f\approx0.1$–0.3 | — |
| **2.2** | 尖锐峰 $f\approx0.19$，持续大幅 $O(1)$ 振荡 | **≈0.35** |
| **2.3** | 主成分仍在 $f\approx0.21$ 附近 | **≈0.06**（降近一个数量级） |
| **2.4** | 间歇波包 | **≈0.03–0.04** |
| **2.5** | $C_l$ 近乎恒定 | **<0.007**（较 $\Omega=2.2$ 衰减近两个数量级） |
| 2.6–3.4 | 与 $\Omega=2.5$ 定性相似（抑制覆盖**有限区间**而非单一临界值） | — |
| **3.5** | 持续波动重新出现，但有**两个不同频率**的峰 | ≈0.05 与 ≈0.035 |
| 5 | 间歇爆发，$f\approx0.1$–0.2 附近活动增强 | — |
| 10 | 宽谱，最强成分在低/中频 | — |

### 局部马赫数

| $\Omega$ | $M_{\max}$ |
|---|---|
| 0.1 | 0.18–0.21 |
| 2.5 | ≈0.32 |
| 5 | **≈0.49–0.50**（约为 $M_\infty$ 的 5 倍） |
| 10 | 0.44（起始）→ **≈0.51** |

全部保持亚声速，**无激波**。$M_{\max}$ **不随 $\Omega$ 线性增长**。

### 表面压力系数 $C_p$

| $\Omega$ | $C_{p,\min}$ |
|---|---|
| 0.1 | 弱、适度周向变化 |
| 2.5 | ≈**−10** |
| 5 | ≈**−25** |
| 10 | ≈**−47** |

⚠️ $|C_p|>1$ 是**物理的**：$C_p$ 用自由流动压归一化，而局部速度是 $U_\infty$ 的数倍。

### 皮肤摩擦 $C_f$

- 随 $\Omega$ 增大，正负极值**渐进增大**
- 低 $\Omega$ 下出现符号变化
- 高 $\Omega$ 下在正峰下游形成**扩展的负 $C_f$ 区域**
- 极值与过零位置随转速系统性移动

### 全局系数

- $\max(C_l)$ 随 $\Omega$ **单调**增加，$\Omega\approx2$ 之后增长显著
- $\max(C_d)$ **非单调**：低/中 $\Omega$ 适中，$\Omega\approx7$ 之后急剧上升且波动大
- 失稳**起始时间**随 $\Omega$ 急剧增加，高转速下超过 **300**，随后饱和

### 涡量探针

| $\Omega$ | 特征 |
|---|---|
| 0.1 | 持续波动，摆幅 ≈**−40 到 +30** |
| 2.5 | 暂态后振荡主要在 $\omega'\approx\pm3$ |
| 5 | 明显间歇，爆发达 $\omega'\approx\pm6$–8 |
| 10 | 最间歇，峰值超 $\pm10$，接近 **$\pm15$** |

### 涡量 POD（$400\le t\le800$，$M=801$ 快照）

**捕获 99% 总涡量所需模态数**：

| $\Omega$ | 模态数 |
|---|---|
| 0.1 | **90** |
| 2.5 | **6** |
| 5 | **37** |
| 10 | **66** |

- $\Omega=0.1$：$\phi_1$–$\phi_2$ 构成相位移动对，$\phi_3$ 最丰富；$a_1(t)$ 主要 $\pm0.05$，$a_2(t)$ 摆幅 $\pm0.1$，模态 3–6 在 $\pm0.05$–0.08；**$a_1$ 与 $a_2$ 之间无清晰的 ~90° 相位差**（不同于经典周期尾流）
- $\Omega=2.5$：模态局限于**单一定向下偏尾流**内；六个系数全在 ≈$\pm0.05$；区间内无增长
- $\Omega=5$：**绕圆柱的环形涡量**；模态幅值在 $\pm0.1$ 内，$\phi_4$–$\phi_6$ 最大（±0.1–0.13）；间歇幅值调制；可能存在配对（$\phi_1,\phi_2$）与（$\phi_3,\phi_4$）
- $\Omega=10$：**闭合的环形结构**；$400\lesssim t\lesssim620$ 内幅值 $\pm0.03$（$a_1$）、$\pm0.1$（$a_2$–$a_4$）、最高 $\pm0.15$–0.18（$a_5,a_6$）；**$t\approx620$ 处显著突变**（快速涨落基本消失）；无持续的相位锁定对

## 局限性

1. **仅二维**；需三维模拟才能评估相变在三维框架下的持续性。
2. **全局稳定性分析**被列为未来工作——高转速区失稳的确切机制尚未确定。
3. **POD 模态被解释为主导结构的「特征」，不是失稳增长率或波长的直接测量**。
4. $\Omega=5$ 的模态配对仅是「提示性」的，确定性识别需要相位关系或互相关分析。
5. 高 $\Omega$ 下 $C_p$ 远超 1 需附带说明（用自由流动压归一化，而局部速度是 $U_\infty$ 的数倍）。
6. **无公开代码**，数据集需申请。
7. 130 万核时的高成本意味着**参数扫描的密度受限**（$\Omega>7$ 加密到 0.05 是妥协）。

## 实现建议

- **实现难度**：高（可压缩 NS + 贴体网格 + 谱精度格式 + MPI 并行，自研求解器）。
- **预期性能**：单算例 401×450 ≈ 18 万网格点；130 组共约 130 万核时 → 平均每组约 1 万核时。
- **适用场景**：
  - 旋转体绕流（螺旋桨、涡轮叶片、圆柱陀螺仪）
  - 卡门涡脱的主动抑制
  - 旋转机械的气动弹性与颤振分析
- **落地建议**：
  1. **格式选型**：OUCS3（对流）+ 中心差分（粘性）+ Jameson 4 阶人工粘性（系数 0.0150）+ OCRK3，是「近谱分辨率 + 稳健性」的实用组合——这是本文可复现的核心数值配方
  2. **边界条件是成败关键**：圆柱绝热壁面 + **基于特征的远场条件**（30D），可避免声学反射污染升力谱。若升力谱出现高频尖峰，先怀疑边界反射
  3. **网格聚集**：双曲正切拉伸、$\beta=3$、$\Delta r_{wall}=0.0005D$；作者验证了 0.001D 与 0.0005D 的 $C_l$ 几乎一致 → **0.001D 足够**，可省算力
  4. **物理检查清单**：
     - $M_{\max}$ 是否达 0.5（验证局部可压缩性效应）
     - $C_{p,\min}$ 是否达 −47 量级
     - FFT 幅值是否呈现 0.35 → 0.06 → 0.03 → <0.007 的**逐级衰减**
  5. **并行实现**：NOHAP（无重叠高精度域分解）可消除接口误差到机器精度，是大网格算例的可靠选择（代价是更复杂的实现）
  6. **参数扫描策略**：$\Omega$ 扫描密度需按响应量自适应——本文在 $C_d$ 快速变化的 $\Omega>7$ 加密到 0.05，是很好的示范
  7. **POD 分析用涡量而非速度**是本文的选择，能突出环向结构；但模态数达 90（$\Omega=0.1$）说明经典卡门尾流的 POD 收敛很慢
  8. **对本知识库的启发**：与 [[DSMC-Supersonic-Cylinder-Unsteadiness]]（2610.37048）对照——后者是**稀薄气动 + DSMC**，本文是**可压缩连续介质 + 谱精度 FD**；两者都用 FFT/模态分析刻画非定常性，但物理机制与数值工具完全不同
