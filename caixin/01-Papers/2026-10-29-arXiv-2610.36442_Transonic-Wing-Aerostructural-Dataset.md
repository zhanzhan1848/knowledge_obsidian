## 核心贡献

> 构建并公开首个**高保真跨声速机翼气动–结构耦合数据集**（2471 个分布内样本 + 3 个分布外样本），填补现有公开机翼数据集「只关心气动、不含结构」的关键缺口，为多物理场 ML 代理模型提供基准。

1. **填补关键空白**：现有用于 ML 机翼设计的公开数据集**几乎只含气动性能**，很少考虑支配实际飞机设计的**多学科相互作用**。高效机翼设计必须**同时**权衡气动性能与结构完整性，但此前**没有任何公开数据集以高保真方式捕捉这种耦合的气动结构行为**。
2. **21 参数化设计空间**：机翼平面形状（展长、后掠、上反角、翼尖弦长、翼尖扭转）+ CST 翼型（上下表面各 6 个 CST 系数）+ 飞行条件（马赫数、攻角、高度）+ 结构载荷因子。
3. **静态气动结构分析（static aerostructural analysis）**：CFD 与结构有限元在 **MDA 迭代循环**中耦合求解。
4. **ML 效用验证**：训练 SOTA 模型预测**气动表面量**（$C_p$、$C_f$）、**积分气动性能量**（$C_L$、$C_D$、$C_M$）与**翼盒失效分布**（failure distribution）。

## 技术方案

### 核心思想

参数化机翼几何 + 参数化飞行条件 → 批量高保真 MDA → 结构化数据集 → 训练多物理场 ML 代理模型。

### 关键技术

| 技术 | 说明 |
|------|------|
| 参数化几何 | **OpenVSP**（开源参数化几何建模器） |
| 翼型参数化 | **CST（Class-Shape Transformation）** 方法，上下表面各 6 个系数；全展长同一翼型 |
| 气动求解器 | **ADFlow**（GPU 高保真 CFD） |
| 结构求解器 | 翼盒有限元分析 |
| 耦合方式 | **MDA（Multidisciplinary Analysis）迭代循环** |
| 采样 | 2500 点采样计划，批大小 10，并行运行 |
| 数据格式 | 每样本含表面/体场 CGNS（体积与表面 CGNS 原始输出未公开，可申请） |

### 21 个参数及范围

| 类型 | 参数 | 下限 | 上限 |
|------|------|------|------|
| 流动 | 马赫数 $M_\infty$ | 0.75 | 0.90 |
| 流动 | 攻角 $\alpha$ | $2^\circ$ | $5^\circ$ |
| 流动 | 高度 $h$ | 10,668 m (35,000 ft) | 12,192 m (40,000 ft) |
| 平面形状 | 展长 $b$ | 13 m | 18 m |
| 平面形状 | 前缘后掠 $\Lambda_{LE}$ | $25^\circ$ | $32^\circ$ |
| 平面形状 | 上反角 $\Gamma$ | $2^\circ$ | $6^\circ$ |
| 平面形状 | 翼尖弦长 $t_c$ | 1 m | — |
| 平面形状 | 翼尖扭转 $\alpha_t$ | — | — |
| 结构 | 载荷因子 $n$ | — | — |
| 翼型 | CST 系数（上/下各 6 个） | — | — |

翼根弦长固定 **5 m**。翼型几何边界取自 UIUC 翼型坐标数据库。

## 公式

### 1. 误差指标（逐网格点 NRMSE）

```math
NRMSE^{xyz}=\frac{\sqrt{\frac{1}{N}\sum_{n=1}^{N}(\hat{w}^{xyz}_{n}-w^{xyz}_{n})^{2}}}{\max(w^{xyz})-\min(w^{xyz})}
```

其中 $w^{xyz}$ 为待预测场量（$C_p$、$C_f$ 或失效分布）。$R^2$ 按**逐样本**计算后跨样本平均；NRMSE 按**逐网格点**计算后跨网格点平均。

### 2. 载荷因子定义

```math
n=\frac{L}{W}
```

### 3. 翼尖速度（推力/功率约束的隐含量）

```math
V_{\rm tip}=\Omega R
```

### 4. 参数化几何（CST 形式）

翼型上下表面由 class-shape transformation 描述：

```math
\frac{z}{c}=\sum_{i=1}^{n}\alpha_i\,x^i+\sum_{i=1}^{n-1}\beta_i\,x^{i/2}(1-x)
```

（$n=6$ 对应本文上下表面各 6 个 CST 系数的配置。）

## 实验结论

### 数据集生成

| 项目 | 值 |
|------|-----|
| 采样计划 | 2500 点（批大小 10） |
| 失败样本 | **29 个**（网格变形/warping 问题未收敛） |
| 最终数据集 | **2471 个分布内样本** + **3 个分布外样本** |
| 单样本计算成本 | 64 核（AMD Epyc 7763 "Milan"），平均 **10 分钟**完成整个 MDA 迭代循环 |
| 总耗时 | 640 核总计约 **40 小时** |

### ML 模型性能

| 学科 | 模型 | NRMSE | $R^2$ |
|------|------|-------|--------|
| 气动（表面量） | SOTA ML 模型 | **≤ 0.0309** | — |
| 气动（积分量） | SOTA ML 模型 | **≤ 0.0309** | — |
| 结构（失效分布） | **Autoencoder** | **0.1138** | 0.8339 |
| 结构（失效分布） | **POD** | **0.1189** | 0.7641 |

**关键结论**：
- ML 模型能**准确捕捉表面与积分气动量**（$C_p$、$C_f$、$C_L$、$C_D$、$C_M$）
- 但**难以准确捕捉失效分布**——作者明确指出仍有改进空间（例如通过超参数优化选择网络架构）
- 结果为多随机种子下的**中位数**

### 数据内容（每样本文件）

包含：表面与体场的 $C_p$、$C_f$、马赫数 $M$、积分气动系数 $C_L/C_D/C_M$、翼盒失效分布。原始体积与表面 CGNS 输出未在线公开（体积数据量大），**可向通讯作者合理申请**。

## 局限性

1. **仅巡航工况**：不考虑机动飞行（此时翼盒应力更大）。
2. **结构材料单一**：翼盒用**铝**，而现代客机机翼多用**碳纤维复合材料**。
3. **结构学科参数过少**：除载荷因子 $n$ 外无其他结构参数（无厚度、铺层、材料属性等）。
4. **翼盒厚度沿展向假设简单线性变化**——未必总是成立。
5. **29/2500 样本因网格变形失败**（约 1.2%），说明参数空间边缘的几何鲁棒性不足。
6. **体积 CGNS 数据不公开**，限制了体场级 ML 研究。
7. 翼型**全展长统一**（单翼型机翼），未覆盖展向变弦/变弯度。
8. 失效分布预测精度（NRMSE 0.11–0.12）明显低于气动量（0.031）。

## 实现建议

- **实现难度**：中（数据已公开，直接下载训练即可；自行生成需 640 核 × 40 小时）。
- **预期性能**：训练在消费级 GPU 上即可完成（数据规模适中）。
- **适用场景**：
  - 多物理场 ML 代理模型的**基准评测**
  - 跨声速机翼**气动–结构快速设计优化**
  - 激波位置/载荷再分布的代理预测
- **落地建议**：
  1. **直接下载** HuggingFace 数据集（CC-BY-4.0），先复现论文的 NRMSE 数值作为 sanity check
  2. **复现顺序**：先做气动表面量 $C_p$ 代理（NRMSE 应能到 0.03 量级）→ 再做积分量 → 最后攻失效分布（预期最差）
  3. **失败分布建模建议**：论文用 autoencoder 与 POD 两种方法均只到 0.11–0.12，可尝试「**POD + 神经网络系数映射**」或**分类式失效判据**（把连续分布转为多标签失效模式分类，通常比直接回归分布更稳健）
  4. **对本知识库的启发**：这篇「**公开基准数据集 + 明确 NRMSE 门槛**」的范式，与本库 [[Generative-AI-in-Turbulence]]（2610.35123）的 benchmarks 思路一致——**领域正在从「刷单点结果」转向「提供可复现的基准」**
  5. 注意 29 个失败样本的分布偏倚：训练时若按原始分布采样，边缘几何区域可能欠代表
