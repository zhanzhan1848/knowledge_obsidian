## 核心贡献

> 用**独立的动力学松弛时间 τ_nh** 弛豫"二阶 Hermite 应力扇区之外的完整补空间"，得到一个**两点可调的 reduced-MRT 碰撞算子**，在 BGK 与 RLBM 之间连续插值，无需完整 MRT 基底即可放大稳定域。

1. **构造**：把非平衡分布投影为应力承载部分 `f^(1)`（由非平衡应力张量重构）与补空间 `f^(>1)`，分别用 τ 与 τ_nh 松弛。
   - τ_nh = τ → 退化为 **BGK**
   - τ_nh = Δt → 退化为原始 **RLBM**（补空间碰撞后归零）
2. **Chapman–Enskog 定理**：等温 NS 方程的**运动粘度 ν = c_s²(τ − Δt/2) 与 τ_nh 完全无关**；τ_nh 只影响高阶截断误差。
3. **四阶超粘误差系数**对 b = τ_nh − 1/2 **严格仿射**，且在 τ_nh ∈ [τ, Δt] 区间内**每个传播方向都严格落在 BGK 与 RLBM 之间**。
4. **稳定性**：Taylor–Green 与绕矩形障碍物稳定性图显示，适当 τ_nh **显著扩大稳定参数域**（最优 τ_nh ≈ 0.6–0.8，且与问题/分辨率相关）。
5. **精度**：三种算子均二阶收敛；E-RLBM 误差比 BGK 高约 6%，比 RLBM 低约 40%；Re=80000 双剪切层中 E-RLBM 跟随 RLBM 收敛曲线。

## 技术方案

### 核心思想

BGK 用**单一松弛时间**弛豫所有非守恒矩，把水动力学模态（质量、动量、应力）与动力学模态（高阶动理学模态）耦合在一起 —— 低粘度或欠分辨流动时稳定性差。

- **MRT**：分别控制不同矩，但需要完整矩基底 + 基变换。
- **TRT**：两个速率，但按**奇偶**分组分离，而非"应力扇区 vs 其补空间"。
- **RLBM**：把非平衡分布投影到二阶 Hermite 扇区（由应力张量重构），丢弃其余 —— 稳定性好，但**丢弃模态的弛豫被固定**（碰撞后置零），不可调。
- **E-RLBM（本文）**：**保留完整补空间**，给它一个独立弛豫时间 τ_nh。无需高阶 Hermite 重构，也无需格点专属矩基底。

> 与 Yu et al. 的 two-relaxation-time regularized 方案对比：后者重构**选定的更高阶**非平衡 Hermite 张量并用附加速率控制边界滑移；本文直接作用于二阶投影的**完整补空间**。

### 关键技术

| 技术 | 说明 |
|------|------|
| 二阶 Hermite 正则化投影 | `f^(1)_i = (w_i / 2c_s⁴)(c_iα c_iβ − c_s² δ_αβ) Π^neq_αβ`，`Π^neq_αβ = Σ_i f^neq_i c_iα c_iβ` |
| 投影算子 | `P f^neq = f^(1)`（应力扇区）、`Q f^neq = f^(>1)`（补空间）、`Q = I − P`；内积 `⟨f,g⟩ = Σ_i f_i g_i / w_i` |
| 双速率碰撞 | `Ω_i = −(Δt/τ)(P f^neq)_i − (Δt/τ_nh)(Q f^neq)_i` |
| 局部阻尼条件 | `\|1 − Δt/τ_nh\| < 1` ⟹ **τ_nh > Δt/2**（必要非充分条件） |
| Chapman–Enskog 展开 | 给出 ν、`E^GI_α`（二阶平衡态的三次速度缺陷，低 Ma 下相对阶 Ma²）、三阶贡献、四阶修正 |
| 四阶超粘系数 | 轴向 `κ₄ = (a/9)[a(2b−a) − 1/4]`；对角 `κ₄(π/4) = (a²/18)(b−2a)`；一般角 `κ₄(θ) = κ̄₄ + Δκ₄ cos⁴θ`，`κ̄₄ = (a/36)(5ab−4a²−1/2)`，`Δκ₄ = (a/72)(6ab−1)` |
| 仿射性 | `κ₄(θ) = κ₄^RLBM(θ) + (b − 1/2)·∂κ₄/∂b`，`∂κ₄/∂b = (a²/36)(5 + 3cos⁴θ) > 0` |
| 各向同性条件 | 仅当 `b = 1/(6a)` 时四阶项各向同性；BGK 对应 `τ = 1/2 + 1/√6` |
| 模态计数 | d 维：守恒 d+1 模态；二阶对称 `d(d+1)/2` 模态用 τ；其余 `q − (d+1) − d(d+1)/2` 模态用 τ_nh |
| 稳定性图 | Taylor–Green：L=16，0.05 ≤ Ma ≤ 1，10⁻⁵ ≤ ν ≤ 10⁻²，400×400 参数网格；100T 内动能超初值 2 倍判为失稳（每 100 步检查） |
| 障碍物流 | Ma = 0.1，横轴 τ_nh，纵轴 log₁₀ν |
| 收敛测试 | Taylor–Green Re=50（τ=0.62, τ_nh=0.65）；双剪切层 Re=80000 |

## 公式

```math
碰撞算子（reduced MRT，Q = I − P）：
  f_i^* = f_i^eq + (1 − Δt/τ) f_i^(1) + (1 − Δt/τ_nh) f_i^(>1)
  Ω_i   = −(Δt/τ)(P f^neq)_i − (Δt/τ_nh)(Q f^neq)_i

宏观极限（Chapman–Enskog，附录 A）：
  ∂_t ρ + ∂_α(ρ u_α) = O(ε³)
  ∂_t(ρ u_α) + ∂_β(ρ u_α u_β) = −∂_α p + ∂_β[μ(∂_α u_β + ∂_β u_α)] + E_α^GI + O(ε³)
  p = ρ c_s²,   ν = μ/ρ = c_s²(τ − Δt/2)          ← 与 τ_nh 无关

线性横向剪切（bulk modified equation，格点单位）：
  ∂_t u_y = ν ∂_x² u_y + κ₄ ∂_x⁴ u_y + O(∂_x⁶)
  κ₄ = (a/9)[a(2b − a) − 1/4],   a = τ − 1/2,  b = τ_nh − 1/2      (轴向)
  κ₄(π/4) = (a²/18)(b − 2a)                                          (对角)

各向异性分解：
  κ₄(θ) = κ̄₄ + Δκ₄ cos⁴θ
  κ̄₄ = (a/36)(5ab − 4a² − 1/2),  Δκ₄ = (a/72)(6ab − 1)

对 τ_nh 的仿射性（固定 τ）：
  ∂κ₄/∂b = (a²/36)(5 + 3cos⁴θ) > 0
  ⇒ BGK (b=a) 与 RLBM (b=1/2) 是同一直线上的两点，τ_nh ∈ [τ, Δt] 时严格内插

Taylor–Green 相对粘度误差（扩散标度）：
  −κ₄(π/4)K²/ν = a(2a − b)K²/6
  E-RLBM 系数 − BGK 系数 = a²(b − a)/18
  E-RLBM 系数 − RLBM 系数 = a²(b − 1/2)/18
```

## 代码片段

```python
# E-RLBM 碰撞步（格点单位 Δx = Δt = 1）
# 1) 计算非平衡分布与应力张量
f_neq = f - f_eq
Pi_neq = np.einsum('...i,...ia,...ib->...ab', f_neq, c, c)   # Π^neq_αβ

# 2) 二阶 Hermite 正则化重构（P 投影）
f1 = 0.5 / cs4 * (np.einsum('...ab,...i->...i', Pi_neq,
                             np.einsum('...ia,...ib->...iab', c, c))
                              - cs2 * Pi_neq)                  # f^(1)

# 3) 补空间（Q = I − P）
f_gt1 = f_neq - f1                                        # f^(>1)

# 4) 双速率碰撞：τ（应力扇区）与 τ_nh（动力学模态）
f_new = f_eq + (1.0 - dt / tau)   * f1 \
              + (1.0 - dt / tau_nh) * f_gt1

# 端点校验：
#   tau_nh = tau        -> BGK
#   tau_nh = dt (=1)    -> 原始 RLBM（f_gt1 碰撞后归零）
# 约束：tau_nh > dt/2   （|1 − dt/tau_nh| < 1）
```

## 实验结论

- **数据集**: Taylor–Green 衰减涡（L=16 稳定性图 / Re=50 收敛）+ 绕矩形障碍物流（Ma=0.1）+ Re=80000 双剪切层
- **基线**: BGK、原始 RLBM、四个参数匹配的神经算子（不适用，此为数值格式）
- **结果**:
  - **稳定性**：E-RLBM (τ_nh=0.65) 相对 RLBM 显著扩大稳定域；障碍物流最优区间 **τ_nh ≈ 0.6–0.8**（过松弛动力学扇区），但最优值**依赖问题与分辨率**，无单一值通用
  - **精度**：三者均二阶收敛；E-RLBM 误差 ≈ BGK 误差 × 1.06，≈ RLBM 误差 × 0.60
  - **误差机理**：差异完全由超粘系数 κ₄ 解释 —— BGK/E-RLBM 的负 κ₄ 部分抵消 Ma² 误差，RLBM 的正 κ₄ 反而叠加
  - **Re=80000**：E-RLBM (τ_nh = 0.65, 0.75) 跟随 RLBM 收敛曲线
  - **理论验证**：线性区测得相对粘度误差与 `a(2a−b)K²/6` 吻合在 4% 内

---

## 局限性

- **稳定性增益无法由长波超粘项解释**：τ_nh 从 1 → 0.65 使 Δκ₄ = −0.7ν²（轴向），在 ν=10⁻³ 时仅占 |κ₄| 的 0.85%；且 κ₄ 随 τ_nh **单调**变化，而稳定域是**有界窗口**。增益必然来自**有限波长的碰撞–传播动力学**（及障碍物测试中的边界处理），作者明言"完整谱与边界分析超出本文范围"。
- 角落区（Ma≲0.13, log₁₀ν≲−4.4）有 **451/160000** 个参数点仅 RLBM 稳定，且不稳定增长缓慢、接近 100T 判定阈值，**分类对舍入误差敏感**（重编译代码会改变部分点的分类）。
- **不提供独立体黏度控制**：非平衡应力的迹属于二阶扇区，其弛豫绑定在 τ 上。
- **不等价于标准 MRT**：D3Q19 上高阶 Hermite 多项式与二阶不正交（`Σ_i w_i H_xxyy,i H_zz,i = −1/27`），补空间需先投影；E-RLBM 继承正则化的矩结构而非标准 MRT 的矩结构。
- 仅验证线性剪切超粘项，非线性总误差未由该分析界定。
- D3Q19 准二维算例因正则化涉及 zzzz 分量，与 D2Q9 在 RLBM/E-RLBM 下**不等价**。

## 实现建议

- **实现难度**: **中** — 相对 BGK 仅多一次应力张量投影 + 一次补空间构造（O(N) 额外存储与计算），无需矩基变换
- **预期性能**: 碰撞算子开销约为 BGK 的 1.2–1.5×（多一个 τ_nh 松弛项 + 投影），**内存增加约 2×**（需保留 f^(1) 或直接重算）
- **适用场景**: 高雷诺数/低粘度/欠分辨 LBM 流动（绕障、湍流衰减、多相界面）—— 稳定域扩大是核心价值
- **落地建议**:
  1. 先在现有 BGK LBM 代码上实现 `f^(1)` 重构（这是 RLBM 的标准操作，多数代码库已有）
  2. 把 τ_nh 作为**新的可调参数**暴露出来，默认取 `0.5 + 3ν`（BGK 轨迹）或 `0.65`
  3. **必须做稳定性扫描**：论文明确指出最优 τ_nh 与问题/分辨率相关，不可盲目套用
  4. 边界处理是未解问题 —— 障碍物案例的稳定性增益可能部分来自边界，需单独标定
- 推荐结论：✅ **推荐实现** —— 这是本窗口内**唯一直接命中 "LBM" 关键词**的论文，且构造简单、可即插即用到现有 RLBM 代码，稳定性收益明确。建议以 OpenFOAM `lib` 或独立 LBM 求解器的形式落地。
