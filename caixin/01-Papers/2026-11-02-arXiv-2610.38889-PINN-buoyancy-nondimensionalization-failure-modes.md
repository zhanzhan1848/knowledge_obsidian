## 核心贡献

> 指出 PINN 在浮力驱动流中的失败**并非"模型容量不足"或"采样策略不当"，而是无量纲化方式造成的**损失梯度失衡**：采用自由落体速度标度可把平均 Nusselt 数误差压到 1.1% 以内，而热扩散标度误差高达 157–650% 并在 $Ra=10^5$ 发散——差异根源是浮力项对损失梯度的贡献按 $(Ra\cdot Pr)^2$ 标度。

1. **无量纲化是 PINN 训练的关键设计变量**（此前文献多归因于损失权重/采样，本工作给出梯度层面的定量机理）。
2. **量化对比**：同一训练条件下，Pr=0.71、$Ra = 10^3 \sim 10^5$ 的差分加热方腔（differentially heated square cavity）：
   - **自由落体标度**（浮力系数 = 1）：$Ra \le 10^4$ 时平均 Nusselt 数误差 **< 1.1%**；
   - **热扩散标度**（浮力系数 = $Ra\cdot Pr$）：误差 **157–650%**，且在 $Ra = 10^5$ **发散**。
3. **梯度失衡机理**：识别出**系数诱导的梯度失衡**，浮力相关的主导损失梯度贡献按 $(Ra\cdot Pr)^2$ 标度——通过**直接梯度测量**证实。
4. **排除性结论**：**稀疏数据监督**与**自适应损失加权**在所测条件下**均不能**解决热扩散标度下的训练困难。
5. **非定常对流的能力边界**：自由落体 PINN 能准确预测**长时**热传递，但**无法捕捉瞬态 Nusselt 数过冲 (overshoot)**。

## 控制方程

标准 Boussinesq 方程组（方腔，$Pr=0.71$）：

```math
\nabla \cdot \mathbf{u} = 0
```

$$\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u}\cdot\nabla)\mathbf{u} = -\nabla p + \sqrt{\frac{Ra}{Pr}}\,\nabla^2\mathbf{u} + Ra\,T\,\hat{\mathbf{z}}$$

$$\frac{\partial T}{\partial t} + (\mathbf{u}\cdot\nabla)T = \sqrt{\frac{1}{Pr}}\nabla^2 T$$

**两种无量纲化的浮力系数对比**（本文核心）：

| 标度方案 | 速度尺度 | 浮力系数（浮力项前的系数） | 主导梯度标度 |
|---------|---------|--------------------------|-------------|
| **热扩散标度 (thermal-diffusive)** | $\kappa/H$ | $Ra \cdot Pr$ | $(Ra\cdot Pr)^2$ |
| **自由落体标度 (free-fall)** | $\sqrt{g\beta\Delta T\,H}$ | $1$ | $O(1)$ |

> 自由落体标度使得浮力系数为 1，从而在 $Ra = 10^5$ 时仍能保持梯度量级平衡；热扩散标度则使浮力项在损失梯度中被放大 $(Ra\cdot Pr)^2$ 倍，造成优化病态。

## 数值方法

| 技术 | 说明 |
|------|------|
| **方法** | 物理信息神经网络 (PINN)，全数据驱动（data-free） |
| **网络** | 标准 PINN 架构（Raissi et al., JCP 2019） |
| **无量纲化** | 对照组：热扩散速度标度 vs 自由落体速度标度；**其余训练条件完全相同**（identical training conditions） |
| **判据** | 平均 Nusselt 数（Nu）误差作为主要评估量；浮力驱动流的标准基准量 |
| **梯度诊断** | 对损失函数各分量的**梯度直接测量**（direct gradient measurements），验证 $(Ra\cdot Pr)^2$ 标度 |
| **对照干预** | (a) 稀疏数据监督；(b) 自适应损失加权 (adaptive loss weighting) |
| **算例范围** | $Pr = 0.71$，$Ra = 10^3, 10^4, 10^5$；定常与非定常对流 |

## 实验结论

| 配置 | 平均 Nu 误差 |
|------|------------|
| 自由落体标度，$Ra \le 10^4$ | **< 1.1%** |
| 热扩散标度，$Ra = 10^3 \sim 10^5$ | **157 – 650%**（$Ra=10^5$ 发散） |

- 梯度测量证实：浮力主导的损失梯度贡献 ∝ $(Ra\cdot Pr)^2$。
- 稀疏数据监督**无效**；自适应损失加权**无效**（在所测条件下）。
- 非定常对流：自由落体 PINN 长时热传递准确，但**瞬态 Nu 过冲捕捉失败**（欠分辨瞬态动力学）。

## 局限性

- 单一几何（差分加热方腔）与单一工质参数（$Pr=0.71$）；结论在强 $Pr$ 依赖、多相流、复杂几何中的普适性待验证。
- 未与"扩大网络规模 / 更多采样点 / 更好的优化器 (L-BFGS vs Adam)"等基线充分对比；性能差距可能部分来自优化器细节而非纯无量纲化。
- 非定常情形的瞬态过冲缺失可能源于网络的时间表达能力限制，未单独剥离。
- 梯度失衡的 $(Ra\cdot Pr)^2$ 标度是在方腔 + Boussinesq 假设下导出的，对强非线性浮力流（如对流主导的混合层）可能失效。

## 实现建议

- **实现难度**：★★☆（PINN 框架成熟；核心工作是把无量纲化当作**一等设计变量**做对照实验，并做损失梯度的分项测量）
- **预期性能**：自由落体标度在 $Ra\le10^4$ 达到 <1.1% Nu 误差，与高精度 CFD 对比可用
- **适用场景**：
  - 浮力驱动流的 PINN 训练（方腔、混合层、腔流、自然对流）
  - PINN 失败排查的**第一检查项**：先换标度，再调权重/采样
  - 高 $Ra$ 问题的 PINN 可行性预评估
- **可迁移点 / 实践清单**：
  1. **默认用自由落体速度标度**处理浮力主导问题（浮力系数 = 1）
  2. 若必须用热扩散标度，需对浮力残差项做 $\sim (Ra\,Pr)^{-2}$ 量级的损失权重预缩放
  3. 训练前先做**损失梯度分量测量**——这是比"看总 loss 曲线"更灵敏的诊断
  4. 稀疏数据监督与自适应权重**不是**此场景的解药（不要浪费时间）
  5. 非定常瞬态特征（Nusselt 过冲）需另行处理（时间窗嵌入 / 时序网络）
