## 核心贡献

> 系统量化 **压力旋流喷嘴 (pressure-swirl nozzle)** 喷雾中**液滴尺寸**对**测量距离 L** 的依赖，提出 We–L 联合标度律，分离压力与距离效应

1. **测量协议问题**：激光衍射测量的 D_v50 与喷嘴-测量站距离 L 强相关，过去文献的不同距离下的前因子 (factor prefactor) 不可直接比较
2. **距离标度律**：单喷嘴下 \(D_{v50} \sim L^{-0.18}\)（液滴形成区之后）
3. **联合标度律（两喷嘴融合）**：
   \[
   D_{v50}/d_0 \sim \mathrm{We}^{-0.31}\,(L/d_0)^{-0.21}
   \]
   其中 \(d_0\) 是喷孔直径，\(\mathrm{We}\) 是 Weber 数
4. **远场一致性**：固定距离下两个喷嘴塌缩到 Kooij et al. (2018) 的 \(\mathrm{We}^{-1/3}\) 标度
5. **工程建议**：喷雾应在**实际使用距离**下表征，否则 D_v50 测量无意义

## 技术方案

### 核心思想

把**压力旋流喷雾**的液滴形成看作**旋流片破碎**（sheet → ligaments → drops）的级联过程，建立 We 与 L 之间的显式依赖关系，纠正过往文献中"忽略 L"的标度律误用。

### 关键技术

| 技术 | 说明 |
|------|------|
| Laser diffraction (激光衍射) | 空间、浓度加权粒径分布的标准测量方法 |
| High-speed imaging (高速成像) | 直接观测 sheet 破碎过程 |
| Weber number scaling | We = ρ U² d / σ，无量纲惯性-表面张力比 |
| Volume-median diameter D_v50 | 50% 体积分数对应直径 |
| Power-law fitting | 距离依赖用幂律拟合 \(D_{v50} \sim L^{\alpha}\) |
| Joint scaling collapse | 多喷嘴融合到 We–L 联合标度 |

### 关键标度律

```math
D_{v50} \sim L^{-0.18}  \quad \text{(单喷嘴，距离依赖)}
```

```math
\frac{D_{v50}}{d_0} \sim \mathrm{We}^{-0.31}\,\left(\frac{L}{d_0}\right)^{-0.21}  \quad \text{(双喷嘴联合)}
```

```math
D_{v50}/d_0 \sim \mathrm{We}^{-1/3}  \quad \text{(固定 L，Kooij et al. 2018 极限)}
```

### 控制方程视角

- **Sheet breakup**：惯性-毛细不稳定 (inertia-capillary)
- **Weber number** 定义：\(\mathrm{We} = \rho U^2 d_0 / \sigma\)
- **Far-field asymptotic**：液滴形成后纯弹道运动 + 蒸发，尺寸仅随距离缓慢变化

---

## 实验 / 验证

- **方法**：实验测量 + 经验标度律
- **样本**：2 个 full-cone pressure-swirl nozzles
- **参数扫描**：
  - 距离：多个 L（喷嘴-测量站）
  - 压力：多个供气压
  - 朝向：多个喷嘴角度
- **结果**：
  - L 依赖指数 −0.18（单喷嘴）/ −0.21（联合）
  - We 依赖指数 −0.31（与远场 We⁻¹/³ 接近但不完全相同）
  - 近-远场 prefactor 偏移可由距离依赖部分解释

---

## 局限性

- **实验样本有限**：仅 2 个喷嘴，结论的普适性需要更多 nozzle geometry 验证
- **工质限制**：未明确覆盖高粘度或非牛顿流体喷雾
- **距离区间**：未给出液滴形成区的完整演化（仅给出"形成区之外"的幂律）
- **未考虑蒸发/凝并**：液滴之间的相互作用被忽略
