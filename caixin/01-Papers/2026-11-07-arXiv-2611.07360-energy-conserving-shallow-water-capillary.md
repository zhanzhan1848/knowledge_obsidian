## 核心贡献

> 为带毛细效应的浅水/薄膜模型构造**完全离散的能量守恒格式**：能量守恒两点通量 + SBP 有限差分 + Crank–Nicolson 型时间离散，且**不分裂**双曲项与毛细项，因而可给出严格的离散能量守恒证明。

1. **能量守恒两点数值通量 + SBP 有限差分** → 可证明能量守恒的半离散格式
2. **Crank–Nicolson 型时间离散**（基于与系统能量相关的特殊时间平均状态）→ 完全离散能量守恒
3. **非分裂处理**双曲项与毛细项——这是与既有工作的关键区别：既有分裂格式的离散能量守恒**尚未有严格证明**
4. **统一框架**：广义静水势 + 二次/完全非线性毛细能，一维与二维皆可

## 技术方案

### 核心思想

**动机来自聚变工程**：磁约束聚变中，液态金属包层被研究用于屏蔽面对等离子体部件的高热流。液态金属薄膜受强磁场作用，自由表面 MHD 流动可用**约化的浅水型框架**建模；此时**毛细效应不可忽略**。

**为什么毛细难以处理**：
- 浅水近似中，长波尺度下垂直动量方程给出「垂直压力梯度 = 重力」的平衡，深度积分得压力 = 静水部分 + 自由表面贡献
- 标准做法假设「自由表面压力 = 环境压」，这**只在表面张力可忽略或界面平坦时成立**
- 液态金属的毛细效应不可忽略 → 必须保留自由表面处的**毛细压力跃变**
- 该跃变通过 **Hamilton 原理**自然纳入 → Euler–Lagrange 方程含**三阶空间导数**
- 三阶算子的离散化困难，常导致**严重不稳定与虚假网格尺度振荡**，且离散层面保持总能量平衡同样困难

**为何需要能量守恒**：能量守恒可防止长时间积分中的虚假能量增长，并让色散毛细波能在**不依赖人为耗散**的前提下被分辨。

**为何用增广形式**：Bresch et al. 引入**缩放深度梯度**作为辅助变量，得到二阶增广系统，且使毛细能变为**二次型**；本文沿用该形式（而非 Dhaouadi et al. 的双曲松弛一阶形式，后者带刚性源项且松弛参数需用户选择）。理由：**二次能量可视为增广系统的凸熵**，从而可用 Tadmor 的熵稳定性框架。

### 关键技术

| 技术 | 说明 |
|------|------|
| **缩放深度梯度增广** | Bresch et al. 形式；把三阶导数降到二阶 |
| **熵稳定性框架** | Tadmor；总能量充当增广系统的凸熵 |
| **能量守恒两点通量** | 与 SBP 有限差分结合 → 半离散能量守恒可证 |
| **SBP 有限差分** | Summation-by-Parts |
| **Crank–Nicolson 型时间离散** | 基于与系统能量相关的**特殊时间平均状态** → 完全离散能量守恒 |
| **非分裂双曲/毛细** | 相比 operator splitting（[4]），有严格离散能量守恒证明 |
| **矩阵自由 GMRES + PETSc** | 完全隐式非线性系统；牛顿法 |
| **步长选取** | 基于**双曲 CFL 条件**而非更严格的色散限制 |

### 公式

**增广系统的总能量（二次毛细能形式）**：

$$\mathcal{E}(h,\bm{q})=\underbrace{\frac12 gh^2}_{\text{经典浅水势能}}+\underbrace{\frac{\sigma}{2}\int|\bm{q}|^2}_{\text{二次毛细能}}$$

其中 $\bm{q}$ 为缩放深度梯度辅助变量。

**Crank–Nicolson 型时间平均状态**（基于系统能量的特殊时间平均）：

$$h^{n+1/2}=\frac{1}{2}\left(h^n+h^{n+1}\right)+\text{（与能量相关的修正项）}$$

**经典浅水势能**：$\tfrac12 gh^2$；薄膜流的势能取更一般的多项式形式。

## 实验结论

- **工况**：
  - 一维、二维 **Gaussian bump** 问题（经典浅水）
  - **falling liquid films**（下落液膜）
  - 二次毛细模型与完全非线性毛细模型各一组
- **结果**：
  - 二次模型：**二阶收敛**
  - 非线性模型：收敛率**趋近二阶**
  - 总能量守恒到**机器精度**
  - 色散毛细波被正确捕捉（不依赖人为耗散）
  - 步长由双曲 CFL 决定，**不受色散限制**
- **计算成本**：主要在非线性求解器（牛顿法 + 矩阵自由 GMRES）

---

## 局限性

1. **非分裂带来刚性**：完全隐式的非线性系统需要大量 GMRES 迭代，是方法的主要成本
2. 只验证了 1D/2D 简单几何；3D 与复杂地形未涉及
3. 增广形式依赖 Bresch et al. 的缩放深度梯度，对自由表面拓扑变化（干湿前沿）处理未讨论
4. 完全非线性毛细模型收敛率只是「趋近二阶」，未达到严格二阶
5. 与真实液态金属包层的磁场耦合（表面张力 + MHD）不在本文范围

## 实现建议

- **实现难度**：中高（需要熵稳定性与 SBP 理论）
- **预期性能**：二次模型二阶收敛 + 机器精度能量守恒，适合长时间积分
- **适用场景**：
  - **液态金属包层/聚变热水力**（本文明确动机）
  - 薄膜流与自由表面 MHD 约化模型
  - 需要长时间积分且**不能靠人为耗散**压制数值噪声的色散波问题
- **落地建议**：如果只关心浅水 + 毛细且不需要严格能量守恒，**更简单的分裂格式**（如 operator splitting）成本更低；本文的价值在「可证明守恒」
