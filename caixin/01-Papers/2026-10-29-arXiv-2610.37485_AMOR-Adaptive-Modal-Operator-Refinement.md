## 核心贡献

> 用**降阶基块（reduced-basis blocks）取代 FNO 的 Fourier 谱卷积**，通过统一的 encode/decode 接口同时支持输入/输出各自的基，从而在**任意非结构网格**上原生工作，并证明其是连续算子的**通用逼近器（universal approximator）**。

1. **网格无关的自适应跨基算子（C1）**：用降阶基块替换 FFT 谱卷积，在**网格节点上直接求值**，通过一个稠密学习张量 $T^{(\ell)}$ 耦合所有保留模态；无需结构化网格、任意基（数据驱动或预设）都可经同一接口接入。
2. **无坐标输入的通用性证明（C2）**：定理 4 证明 AMOR 在"基连续、点分离、含常数模态"的条件下可一致逼近紧集上的任意连续算子。**关键洞见**：跨模态耦合把常数通道解码成分离点模态值，从而**内部隐式提供了位置编码**——不需要显式拼接坐标。
3. **三维可扩展的降阶表示（C3）**：AMOR 的谱参数化**无张量积维度依赖**，避免 FNO 的 $m^d$ 增长；在三维高容量问题上相对 FNO 具备算力优势。

## 技术方案

### 核心思想

设 $\Omega\subset\mathbb{R}^d$ 为有界 Lipschitz 域，学习算子 $\Psi^\dagger:\mathcal{U}\to\mathcal{V}$（$\mathcal{U}=L^2(\Omega;\mathbb{R}^{C_{\rm in}})$，$\mathcal{V}=L^2(\Omega;\mathbb{R}^{C_{\rm out}})$）。

**有限正交归一系统** $\{\varphi_m^{\rm in}\}_{m=1}^{k_{\rm in}}\subset\mathcal{U}$ 与 $\{\varphi_n^{\rm out}\}_{n=1}^{k_{\rm out}}\subset\mathcal{V}$ 即"降阶基"，$\langle a,\varphi_m^{\rm in}\rangle$ 为模态系数。**输入基与输出基可独立选取**——这是与 PODNO 的关键区别。

编码/解码算子逐列作用，且互为伴随：

```math
(\bm{\varphi}^{\mathrm{in}}Z)_{\cdot,j}=\sum_{m=1}^{k_{\mathrm{in}}}Z_{m,j}\varphi_{m}^{\mathrm{in}},\qquad
\bigl((\bm{\varphi}^{\mathrm{in}})^{*}h\bigr)_{m,j}=\langle h_{\cdot,j},\varphi_{m}^{\mathrm{in}}\rangle
```

于是 $\Pi_{\rm in}=\bm{\varphi}^{\rm in}(\bm{\varphi}^{\rm in})^{*}$、$\Pi_{\rm out}=\bm{\varphi}^{\rm out}(\bm{\varphi}^{\rm out})^{*}$ 是到降阶空间的**正交投影**。

### 关键技术

| 技术 | 说明 |
|------|------|
| **降阶基积分算子** | $\mathcal{K}_{\rm RB}^{(\ell)}h=\bm{\varphi}_{\rm dec}^{(\ell)}\!\left[T^{(\ell)}(\bm{\varphi}_{\rm enc}^{(\ell)})^{*}h\right]$，其中 $T^{(\ell)}\in\mathbb{R}^{k_{\rm dec}\times k_{\rm enc}\times d_v\times d_v}$。其核 $\kappa^{(\ell)}(x,y)_{(c,i),(c',j)}=\sum_{n,m}T^{(\ell)}_{n,m,i,j}\varphi^{\rm dec}_{n,c}(x)\varphi^{\rm enc}_{m,c'}(y)$ —— **既非平移不变，也非卷积核** |
| **分层基配置** | $\ell=0$ 用 (in, in)，$\ell=1$ 用 (in, out)，$\ell\geq2$ 用 (out, out)，让输入模态在首层被编码、输出模态在末层被解码 |
| **门控残差块** | $h^{(\ell+1)}=h^{(\ell)}+\sigma\!\big(g_\ell[W^{(\ell)}h^{(\ell)}+\mathcal{K}_{\rm RB}^{(\ell)}h^{(\ell)}+b^{(\ell)}]\big)$（$\ell\neq1$）；$\ell=1$ 处**无跨跃迁残差连接** |
| **因子化系数权重** | $T_{n,m,i,j}=\mathsf{B}_{n,m,i}\mathsf{A}_{m,i,j}$，参数量从 $d_v^2 k_{\rm enc}k_{\rm dec}$ 降到 $d_vk_{\rm enc}(d_v+k_{\rm dec})$（约 $1/k_{\rm dec}+1/d_v$ 倍）|
| **Gram 矩阵内积** | $\langle\underline{u},\underline{v}\rangle_M=\underline{u}^{\top}M\underline{v}$，$M=I_C\otimes M_x$。参考网格上 $\Phi^{*}\Phi=\Phi^{\top}M\Phi=I_k$，编码器即解码器的 $M$-伴随 |
| **参考偏移（仿射路径）** | $\mathcal{K}^{\mu,\rm(\ell)}_{\rm RB}h=\bm{\varphi}^{(\ell)}_{\rm dec}T^{(\ell)}(\bm{\varphi}^{(\ell)}_{\rm enc})^{*}(h-\mu_{\rm enc})+\mu_{\rm dec}$，$\mu$ 取训练集均值 |
| **FiLM 条件化** | 标量物理参数 $\bm{\pi}\in\mathbb{R}^{d_\pi}$ 经一层隐层映射到 $(\gamma,\beta)$，$\mathrm{FiLM}(h)_{c,j}=(1+\gamma_j)h_{c,j}+\beta_j$ |
| **基的多样性** | 数据自适应（POD / 学习基）、导数信息（DIS）、几何内在（Laplacian 本征基）、预设（多项式：Jacobi / Chebyshev / Legendre）|

### 通用性定理（Theorem 4）

> 设 $K\subset\mathcal{U}$ 在 $L^2$ 中紧，$\sup_{a\in K}\max_c\|a_c\|_{L^\infty}\le M_\infty<\infty$，$\Psi^\dagger:K\to\mathcal{V}$ 连续。取两组**有限、连续、点分离、且含归一化常数模态** $(C|\Omega|)^{-1/2}\mathbf{1}$ 的正交基。则对任意 $\varepsilon>0$，存在 AMOR 网络 $\Psi_\theta$（任意深度 $L\ge2$，有限宽度 $d_v,d_q$）使
> $$\sup_{a\in K}\|\Psi^\dagger(a)-\Psi_\theta(a)\|_{\mathcal{V}}<\varepsilon$$
> 且宽度可取 $d_q=d_v$。

证明基于"平均化局部特征"逼近论证（[39]）：**非对角模态耦合把常数通道转成分离点的模态值**，从而在无需坐标输入的情况下供给位置编码。

## 公式

```math
\mathcal{K}_{\mathrm{RB}}^{(\ell)}h=\bm{\varphi}_{\mathrm{dec}}^{(\ell)}\bigl[T^{(\ell)}(\bm{\varphi}_{\mathrm{enc}}^{(\ell)})^{*}h\bigr],
\qquad (TZ)_{n,i}=\sum_{m=1}^{k_{\mathrm{enc}}}\sum_{j=1}^{d_{v}}T_{n,m,i,j}Z_{m,j}
```

```math
h^{(\ell+1)}=h^{(\ell)}+\sigma\!\left(g_{\ell}\left[W^{(\ell)}h^{(\ell)}+\mathcal{K}_{\mathrm{RB}}^{(\ell)}h^{(\ell)}+b^{(\ell)}\right]\right),\quad \ell\neq 1
```

```math
Z=E_{\mathrm{enc}}H,\qquad Z'_{n,i}=\sum_{m,j}T_{n,m,i,j}Z_{m,j},\qquad \widetilde{H}=B_{\mathrm{dec}}Z'
```

```math
T_{n,m,i,j}=\mathsf{B}_{n,m,i}\mathsf{A}_{m,i,j}
\quad\Longrightarrow\quad
Z'_{n,i}=\sum_{m}\mathsf{B}_{n,m,i}\sum_{j}\mathsf{A}_{m,i,j}Z_{m,j}
```

**关键对比**：AMOR 与 PCANet **共用同一 PCA 基**，故 AMOR 全面胜过 PCANet 的差距纯粹来自"重复的非局部块 + 物理空间非线性"。FNO 在 Kolmogorov 流上全面胜出——因为该流是周期、统计均匀的，**匹配 FNO 的平移等变性**，且其一步增量**无法被静态快照基表示**。

**扩展性**（Elastostatics 数据集）：
- FNO 推理时间在 $m\approx22$ 前平坦于 6.4–6.9 ms/sample，$m=48$ 时飙至 **25.2 ms/sample**（印证 $m^3$ 增长）；AMOR 近似**线性**增长（$\mathcal{O}(d_vDk)$ 主导）。
- 宽度扫描：FNO 从宽度 8→64 由 5.1 增至 **55.9 ms/sample（11×）**；AMOR 由 5.0 增至 **26.1 ms/sample（5.3×）**。
- ⚠️ 模式预算**未对齐**（FNO $m=32$/轴 = 17,408 个 Fourier 系数 vs AMOR 32 个基函数），因此该比较对 FNO **保守**。等 $L^2$ 误差下 FNO $m=32$ 对应 AMOR $k_{\rm in}=10, k_{\rm out}=5$。

## 局限性

1. **静态基在输运主导问题上失效**：当解流形需要大量全局线性模态（输运主导、移动前沿、强多尺度耦合），基于方差截断的效率优势丧失。Kolmogorov 流是具体例证——即使网络预测 Euler 残差、输出 PCA 拟合到 $\Delta u$，固定全局基仍落后于 Fourier 模态。**可能需要动力学感知构造**（轨迹窗 PCA、联合训练的非线性编码器、多步损失）。
2. **输入/输出基分别拟合**可能错过"对算子简单、对单张快照不简单"的结构（分岔族、复合族）。论文提出但**未测试**：耦合特征值问题或输入-输出配对快照的联合 SVD。
3. **网格迁移**需一次性的基延拓 + 目标网格 Gram 加权对偶编码器构造——FNO 的分辨率无关 Fourier 基不需要这一步。
4. **稠密系数张量 $T^{(\ell)}$** 在二维基准上通常比 FNO 参数更多（因 PCA 截断保留模态多于 FNO 的逐轴截断）；三维中该关系反转。
5. **失去平移等变性**（Remark 1）——若算子本身有平移对称性，AMOR 必须从数据中学习。
6. 常数模态增广在实验中**未改善精度**，故被省略。

## 实现建议

- **实现难度**：中高（需要 POD/学习基构造、网格间基延拓与 Gram 对偶编码器）
- **预期性能**：三维高容量问题上推理时间相对 FNO 优势明显（宽度 64 时 2× 于 FNO）；非规则网格上误差显著优于 Geo-FNO
- **适用场景**：**复杂几何 CFD 代理模型**（翼型、机身肋骨、非结构网格、多孔介质）、需要跨网格分辨率泛化的大规模参数扫描、配合贝叶斯优化做设计优化
- **落地建议**：
  - 结构网格 + 输运主导问题 → 仍优先 FNO
  - 非规则网格 + 几何主导问题 → AMOR 优先
  - 训练数据稀缺时 → 用 Laplacian 或多项式等**免拟合预设基**
  - 基的选择应**按问题匹配**，不要默认 PCA
