# 连续时空有限元：大幅边界运动与周期性的生物医学流动

## 核心贡献

提出**轴对称连续单纯形时空有限元方法（continuous simplex space-time FEM）**用于不可压流动，三个关键优势：

1. **大边界运动**：运动被并入时空几何 → **无需重网格、无需投影解**
2. **时间周期解直接求解**：**无需模拟多个周期**
3. **时间维可分区 → 时间并行**

演示：**刚性管内的主动脉内球囊反搏（IABP）**，球囊膨胀按实测数据建模，含沿球囊传播的行波。

## 方法

### 连续时空离散
- **单纯形（simplex）单元**的非嵌套时空网格
- 时空几何中直接编码边界运动 → 天然处理拓扑不变但边界大幅移动的场景
- 不可压约束通过 **Lagrangian 乘子 / 混合变分形式**施加（文中实现细节见原论文）

### 周期性求解
- 时间周期解作为**单次时空求解**的边界约束给出，而非通过前一周期的时间延拓
- 避免了启动瞬态的收敛迭代

### 并行性
- 时空网格**沿时间方向切分为 time slabs**
- 弱扩展测试至 **960 ranks**，**每次求解迭代的代价近似恒定**
- **时间 slab 分区比"同时切空间与时间"的分区方式改善了线性求解器的收敛性**

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 离散化 | 连续时空单纯形有限元（非嵌套） |
| 不可压处理 | 混合变分形式（Lagrangian 乘子） |
| 求解器 | 线性求解器（时间 slab 分区改善收敛） |
| 稳定性 | ✅ 收敛性经加密研究验证 |
| 时间步长 | 隐式，步长由时空单元大小决定（不需 CFL 严格限制） |
| 网格需求 | **无需重网格** → 大幅减少人工干预 |
| 并行性 | ✅ 空间并行 + **时间并行**（time slabs），960 ranks 弱扩展 |

## 计算成本分析

| 项目 | 结果 |
|---|---|
| 弱扩展上限 | **960 ranks** |
| 每迭代代价 | 近似恒定（弱扩展良好） |
| 时间并行增益 | 时间 slab 分区 > 空间时间混合切分（收敛性改善） |
| 相比"步进法 + 重网格" | 节省建模人力与投影误差 |

## 局限性

- **轴对称假设**限制了几何复杂度（真实主动脉与 IABP 非轴对称）
- **刚性管**几何过于理想，真实 IABP 在弯曲主动脉中
- 时间并行需**空间与时间同时分区**，通信模式更复杂
- 收敛研究基于单个算例，泛化性待验证
- 论文属 math.NA 交叉，医学验证（与临床数据对比）尚未涉及

## 实现建议

- **实现难度**：🟡 中高。需实现：连续时空单纯形 FEM 求解器 + 混合不可压约束 + 时间 slab 分布式并行
- **预期性能**：大边界运动场景下相对传统步进法省去重网格；时间并行带来近线性加速
- **适用场景**：
  - 心脏/瓣膜等**剧烈周期运动**（IABP、心脏泵、隔膜泵）
  - FSI 中边界位移大、拓扑不变的问题
  - 需要**周期稳态**而非瞬态的工业流动
- **落地建议**：
  - 可优先在**一维/二维轴对称**上做原型验证，再考虑三维
  - 与 OpenFOAM 的**动网格（dynamicMesh）**方案对比：CM 方法的优势在于"大位移 + 周期稳态"两个特定场景
  - 若仅需稳态周期解，也可考虑"伪时间步进 + 周期收敛"这一更简单的替代路线
- **相关开源参考**：FEniCS / Firedrake 的时空单元支持，deal.II 的时空自适应
