## 核心贡献

> 提出**物理信息贝叶斯优化 (PIBO)**：把已知的物理**标度关系**通过**搜索空间的非线性变换**并入贝叶斯优化流程，有效重建高次谐波转换效率的复杂能 landscapes；**阈值型采集策略**不仅定位最优点，更能识别**扩展的高效率操作区域**。

1. **物理信息化的搜索空间变换**：通过**已知的物理标度关系**对搜索空间做**非线性变换**，将物理先验**内嵌**进 BO 的探索机制——而非仅在代理模型的损失函数里加惩罚项。
2. **二维验证**：在 pressure–length 二维空间中，由于**穷举网格扫描可行**，用直接扫描做**详细验证**。
3. **四维扩展**：在四维中穷举不可行，**引入脉冲持续时间标度关系**与**转换效率的平方根变换**，显著提升 landscape 重建精度（对照独立参考数据集验证）。
4. **阈值型采集策略**：用**基于阈值的采集函数**来识别**扩展的高效率区域**，而非孤立的最优点。
5. **物理背景**：高次谐波 (HHG) 转换效率受**微观单原子偶极响应**与**宏观相位匹配**共同制约；效率 landscape 含**双曲脊线**等复杂结构。

## 技术方案

### 核心思想

**高次谐波发生 (High-order Harmonic Generation, HHG)** 把红外驱动激光频率上转换到极紫外 (EUV) 波段，是**阿秒科学**的关键光源。转换效率受两个尺度悬殊的因素制约：

1. **微观**：单原子偶极响应（单原子产生 EUV 光子的能力）；
2. **宏观**：**相位匹配**（宏观介质中各原子产生的辐射是否相干叠加）。

这导致转换效率 landscape 在 (压力, 长度) 空间中呈现**双曲脊线 (hyperbolic ridge)** 这样的复杂结构——常规贝叶斯优化在这种"脊线"结构上表现不佳：它会沿脊线跳来跳去，采样预算被浪费在脊线两侧的低效区域。

本文的思路：**把已知的物理标度关系写进搜索空间的几何结构**。例如：
- 脉冲持续时间 $\tau_p$ 与转换效率之间存在已知标度（效率 $\propto \tau_p^{\text{已知幂次}}$）；
- 转换效率本身与某物理量呈平方根关系。

把这些关系做成**坐标变换**（如效率取平方根、持续时间按幂次缩放），BO 的探索就在**变换后的空间**中进行——此时物理 ridge 变成了简单形状，BO 的标准假设（平滑、近单峰）重新成立。

这是与"物理信息神经网络 (PINN)"截然不同的思路：**PINN 把物理放进损失函数，PIBO 把物理放进搜索空间的几何**。后者的优势是物理知识的作用更强、更直接，且不增加网络训练负担。

另一个实用点是**阈值型采集策略**：工程上真正需要的是"**一片高效工作区域**"（如 EUV 光源需要稳定输出，不是某个脆弱的最优点），因此用"超过阈值的概率"作为采集信号，比标准的"期望提升 (EI)"更贴近工程需求。

### 关键技术

| 技术 | 说明 |
|------|------|
| 贝叶斯优化 (BO) | 代理模型 + 采集函数的序贯优化框架 |
| 物理信息搜索空间变换 | 通过非线性坐标变换把物理标度律并入探索 |
| 脉冲持续时间标度关系 | 已知幂次律 $\eta \propto \tau_p^{\gamma}$ 的利用 |
| 转换效率平方根变换 | 压缩效率动态范围，重塑 landscape 形状 |
| 阈值型采集策略 | 以"超阈值概率"为采集信号 |
| 双曲脊线结构 | 相位匹配在 $p$–$L$ 空间产生的脊线 |
| 2D → 4D 扩展 | 探索维度提升后的策略 |

## 公式 / 理论要点

```math
% 单原子偶极响应（微观尺度）
D(t) = \langle \Psi(t)|\hat{\mu}|\Psi(t)\rangle,
\qquad
\text{EUV 谱} = \left|\int dt\,D(t)e^{-i\omega t}\right|^2
```

```math
% 相位匹配条件（宏观尺度，宏观与微观贡献的耦合）
\Delta k\,L - \Delta\phi_{\text{prop}} = 0
\quad\Longrightarrow\quad
\text{几何上的 (p, L) 脊线（双曲）}
```

```math
% 物理标度关系：脉冲持续时间
\eta_{\mathrm{HHG}} \propto \tau_p^{\,\gamma},
\qquad \gamma \ \text{由物理推导给出}
```

```math
% 搜索空间的非线性变换（核心）
\boldsymbol{z} = \boldsymbol{\Phi}(\boldsymbol{x}),
\qquad
\Phi:\ \text{物理标度关系} \;\to\; \text{标准搜索空间}
\quad\text{（如}\ \eta'=\sqrt{\eta},\ \tau_p'=\tau_p^{\gamma}\text{）}
```

```math
% 贝叶斯优化循环
\boldsymbol{x}_{n+1}
= \arg\max_{\boldsymbol{x}\in\Omega}\,
\alpha(\boldsymbol{x}\mid\mathcal{D}_n),
\qquad
\mathcal{D}_n = \{(\boldsymbol{x}_i, y_i)\}_{i\le n}
```

```math
% 阈值型采集函数（识别扩展高效区）
\alpha_{\text{thr}}(\boldsymbol{x})
= \Pr\!\left[y(\boldsymbol{x}) > y_{\text{thr}}\mid \mathcal{D}_n\right]
\quad\text{（而非 EI 等最优点导向的采集）}
```

## 实验与结果

- **算例/数据集**: 气体中高次谐波转换效率 landscape；**二维 (压力–长度)** 空间用直接网格扫描做详细验证；**四维**空间（加入脉冲参数等）用独立参考数据集验证。
- **对比基线**: 常规（无物理信息的）贝叶斯优化；二维中的直接穷举网格扫描。
- **主要结果**:
  - **二维**：直接扫描给出真值 landscape；物理信息变换后的 BO 能准确重建，含双曲脊线结构。
  - **四维**：穷举扫描不可行；**引入脉冲持续时间标度 + 效率平方根变换**后，landscape 重建精度**明显提升**（对独立参考数据集验证）。
  - **阈值采集**：成功识别**扩展的高效率操作区域**，而非仅孤立最优点。
  - **结论**：**把物理知识并入 BO 能改善多维 HHG landscape 的探索与重建**，其能力不止于"定位单个最优点"。

---

## 局限性

- **依赖已知标度关系**：需要预先知道正确的物理标度律；若标度关系有误或只近似成立，变换可能引入偏差（论文未量化对标度律误差的鲁棒性）。
- **任务特定**：变换是针对 HHG 效率 landscape 设计的，迁移到其他问题需重新推导标度律。
- **代理模型**：仍依赖 GP/代理模型的质量，维度升高后（4D 以上）BO 的样本效率仍有限。
- 未涉及**多目标优化**（如同时优化效率与稳定性/光束质量），而这在实验中很常见。
- **实验验证**：摘要仅提数值验证，未说明是否有实际实验对比。

## 实现建议

- **实现难度**: 低 — 贝叶斯优化框架成熟（BoTorch、Ax、Optuna 等）；核心工作是推导并实现搜索空间变换。
- **预期性能**: 四维中 landscape 重建精度明显提升；阈值采集可输出"高效工作区"而非单点。
- **适用场景**:
  - **实验参数寻优**（激光参数、气体压力、腔长）；
  - 任何"**landscape 有脊线/强结构且已知部分标度律**"的优化问题；
  - **与仿真昂贵**的场景（每次评估成本高 → BO 的样本效率至关重要）。
- **可复用要点**:
  - **"物理进搜索空间" vs "物理进损失函数"** 是一条值得推广的方法论分界。搜索空间变换是**强先验**（几何层面），通常比软惩罚更有效且更省算力。特别适合标度律明确的问题。
  - **阈值型采集函数**是一个"需求驱动"的选择，工程上几乎总是比 EI/UCB 更贴近真实目标（"要一片好区域"而非"要一个最优点"）。建议在所有实验寻优中优先考虑。
  - **标度律本身是最高价值的资产**：一旦某个问题的标度律被建立，就能反复用于加速优化。建议把标度律显式存入知识库（如"标度律"目录），作为可复用组件。
  - 与本轮 [[2026-11-11-arXiv-2611.14104]]（sPTT vs FENE-P 用"定常相同、瞬态不同"隔离瞬态响应）的方法论呼应：**用已知结构做对照/变换以隔离未知机制**是本轮反复出现的思路。
