## 核心贡献

> 给出在**垂直剪切背景流**中寻找 **modon (偶极涡) 解析解**的**半解析方法**，基于**多层准地转 (multi-layer quasi-geostrophic, QG)** 框架。该方法适用于**任意多流体层 (N-layer)**，并建立在此前多层 modon 研究的基础上。通过**三个算例**说明**层间相对位势流速**变化与**深度依赖的位涡 (potential vorticity) 梯度**（源于表面变形与速度剪切）的影响。

1. **modon 的定义**：由**两个反向旋转区域**组成、在**自平流 (self-advection)** 下整体传播的**涡解**（偶极涡）。
2. **物理重要性**：modon 是**上层海洋**的常见特征，可**长期保持稳定**，从而**大距离输运流体**（对海洋输运、涡旋与生态相互作用有意义）。
3. **方法**: 在**垂直剪切背景流**中，用**多层准地转框架**寻找 modon 解的**半解析方法**。
4. **一般性**: 方法适用于**任意层数 N**，并**扩展**了作者此前的多层 modon 研究。
5. **算例**: 给出**三个背景流中的 modon 算例**，展示：
   - **层间相对位势流速 (relative potential velocity between layers)** 变化的影响；
   - **深度依赖位涡梯度**的影响——该梯度**源于表面变形 (surface deformation)** 与**速度剪切 (velocity shear)**。

## 技术方案

### 核心思想

**modon 是什么**

**modon**（也叫 **dipole vortex / modon**）是准地转动力学中的一个特殊解：
- 由**两个反向旋转的涡量斑块**组成，彼此"背靠背"；
- 由于自平流的精确平衡，这个双涡**整体以恒定速度平移**而不变形；
- 因为不经历拉伸变形，它**保持稳定**（普通涡会拉伸变形）。

**为什么重要**

真实海洋中（尤其是中尺度涡、**偶极涡 (dipole eddies)**）确实观测到类似的成对涡结构。它们能**长距离输运流体**（热量、盐度、营养盐、生物），因此在海洋输运研究中有实际意义。

**为什么需要半解析方法**

真实海洋是**连续分层**的（垂向连续），而 modon 理论最常用的是**多层 (multi-layer)** 离散——每层有独立的位涡与厚度。连续分层 modon 的理论极其困难，而多层框架可以在**任意层数**下系统地构造解析族。

**多层 QG 方程**

准地转（QG）框架基于**小 Rossby 数** $\mathrm{Ro} = U/(fL) \ll 1$ 与**小 Froude 数**分层。控制量：
- **位涡 (potential vorticity)** $q = \frac{f+\beta y + \partial_z u}{\partial_z \psi}$（各层）
- **位势 (potential)** $\psi$（各层）
- 厚度方程 + 位涡输运方程，通过**非诊断 (non-diagnostic) 位涡**耦合

**多层 modon 的核心机制**

modon 存在的关键是**自平流的精确平衡**：
- 两个涡斑的**自诱导速度 (self-induced velocity)** 与**相互诱导速度 (mutual-induced velocity)** 恰好抵消，使整体平移；
- 这要求特定的关系：**层间的位势差/相对位势流速**必须满足精确条件。

**背景剪切如何进入？**

真实海洋的背景流 $\bar{u}(z)$ 通常**随深度剪切**。这引入两个新效应：

1. **速度剪切 (velocity shear)** 直接改变各层的位涡梯度结构；
2. **表面变形 (surface deformation)** ——在上层海洋，**自由面**会响应于流动，产生**有效位涡梯度**的变化（通过 $f+\beta y$ 与拉伸项的耦合）。

这两者共同决定**深度依赖的位涡梯度** $q'(z)$，而 modon 的稳定性与结构**直接依赖**这个梯度剖面。

**本文的推进**

- 作者此前已做**多层 modon**（无剪切背景）；
- 本文加入**垂直剪切背景流**，并把方法推广到**任意 N 层**；
- 通过**三个算例**系统展示**层间相对位势流速**与**深度依赖位涡梯度**的效应。

### 关键技术

| 技术 | 说明 |
|------|------|
| 多层准地转 (multi-layer QG) | 核心理论框架 |
| 非诊断位涡 (non-diagnostic PV) | 多层耦合的关键处理 |
| modon 自平流平衡 | 两涡反向旋转 + 相互诱导抵消 |
| 半解析解构造 | 解析 + 数值求解的混合 |

| 深度依赖位涡梯度 $q'(z)$ | 由表面变形 + 速度剪切共同决定 |
| 层间相对位势流速 | 决定 modon 结构的关键参数 |
| 任意 N 层的一般性 | 方法的系统性 |

## 公式 / 理论要点

```math
% 多层准地转：位涡方程（各层 k = 1..N）
\partial_t q_k + \boldsymbol{u}_k\cdot\nabla q_k = 0,
\qquad
q_k = \frac{f+\beta y - \partial_z^2\psi_k}{\partial_z\psi_k - \partial_z H_k}
```

```math
% 厚度方程
\partial_t(\partial_z\psi_k - \partial_z H_k)
+ \boldsymbol{u}_k\cdot\nabla(\partial_z\psi_k - \partial_z H_k) = 0
```

```math
% modon 的自平流平衡条件
\boldsymbol{u}_{\text{self}}(\boldsymbol{x}_0) + \boldsymbol{u}_{\text{mutual}}(\boldsymbol{x}_0)
= \boldsymbol{U}_{\text{prop}},\qquad
\frac{d\boldsymbol{x}_0}{dt} = \boldsymbol{U}_{\text{prop}}
```

```math
% 垂直剪切背景流
\boldsymbol{u}(z) = \bar{u}(z)\,\hat{\boldsymbol{x}},
\qquad
\frac{d\bar{u}}{dz} \neq 0
\quad\Longrightarrow\quad
q'(z) = \frac{d q}{dz} \text{ 深度依赖}
```

```math
% 表面变形对有效位涡梯度的贡献
\frac{\partial}{\partial z}(f+\beta y) \ \text{经自由面条件}\ \Rightarrow\ \Delta q'(z)
```

```math
% 层间相对位势流速（结构参数）
\Delta \psi_{k+1} - \Delta\psi_k,\qquad
\Delta\boldsymbol{u}_{\text{pot}}^{(k+1)-k}
\quad\Longleftrightarrow\quad
\text{modon 结构与存在条件}
```

## 局限性

- **短文（12 页 3 图）**：内容聚焦在方法构造与示例，**未做系统的稳定性分析**、参数扫描或长时间数值验证。
- **仅 3 个算例**：不足以覆盖参数空间。
- **QG 假设的适用性**：
  - **小 Rossby 数**（$U/(fL)\ll 1$）——海洋中尺度涡满足，但**极小尺度涡**不满足；
  - **小 Froude 数 / 静力稳定**——表层与深层的强层结需满足；
  - **$f$ 平面 vs $\beta$ 平面**：真实海洋的 $\beta$ 效应（行星涡度梯度）通常重要，摘要未说明是否包含。
- **层数与分辨率**：QG 多层模型中的"层"是**离散化**，而非真实分层；**层数 $N$ 与物理分辨率的收敛性**未讨论。
- **剪切剖面的形式**：只考虑了特定形式（线性/指数？）的 $\bar{u}(z)$，一般剖面的处理未说明。
- **未与数值模型 (LES/非结构 QG 模型) 对比验证**。
- **海洋生态/输运的定量应用未展开**。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中 — 多层 QG 的线性/非线性求解是标准（每层一个 Poisson 方程 + 隐式时间步进）；难点在 **modon 解的半解析构造**（需要符号推导）。
- **预期性能**: 成本极低（层数少、方程小），可做大规模参数扫描。
- **适用场景**:
  - **海洋中尺度涡动力学**：偶极涡/双涡输运机制的解析基线；
  - **涡旋–地形相互作用**：modon 经过地形时的演化；
  - **作为数值方法的解析基准**：半解析解可用于验证 QG 求解器或非结构涡度输运模型；
  - **参数化涡旋模型**：modon 是最简单的可参数化涡旋解，可用于粗粒化模型；
  - **与本轮 [[2026-11-12-arXiv-2611.11719-Thermochemical-Rossby-Waves-Swallowtail]] 配套**：后者研究**快速旋转**系统中的 Rossby 波与热–化学分层相互作用，本文是**同一大框架（QG/快速旋转）下的涡解构造**。二者合起来覆盖"快速旋转流体的波动与涡旋"两面。
- **可复用要点**:
  - **"半解析方法 + 任意层数"** 是处理分层介质解析解的通用路线：**用多层框架离散连续分层，用解析结构处理非线性平衡**。这个范式可推广到**分层剪切流、大气边界层、稳定性问题**。
  - **"自平流平衡条件"是构造可解析涡解的通用抓手**：寻找使非线性项精确抵消的**参数条件**，即可得到稳定的传播解。这个技巧不仅限于 modon。
  - **"表面变形 + 剪切 → 有效位涡梯度"** 是 QG 中的标准机制，但在很多教程中被略过；建议把"位涡梯度的三个来源（β、剪切、变形）"作为 QG 建模的检查清单项。
  - **modon 作为解析基准**的价值：任何声称能模拟海洋涡旋的模型（含大涡模拟、非结构 QG 模型）都可以用 modon 的传播速度与形状保持性做**定量验证**。建议归档到"数值方法/验证基准"目录。
