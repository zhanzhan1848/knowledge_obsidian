## 核心贡献

> **相位分辨 (phase-resolved)** 的 DNS 揭示了**心动周期驱动的脉动管流**中湍流动力学随相位的演化：响应遵循**四个阶段的湍流–湍流重组**。核心发现：**流速–法向应力 (streamwise–normal) 产生在压力–应变重分布与径向动量输运之前恢复**，使能量得以累积成**拉长的条带 (streaks)**；**早期减速阶段**近壁高速条带以 **Q4 扫掠 (sweeps)** 相关的**畸变型 (varicose)** 扰动为主，而外缓冲区低速条带以 **Q2 喷射 (ejections)** 相关的**正弦型 (sinuous)** 扰动为主；两种响应在**阻力最小与恢复最大之间重叠**。低流量平台期延长衰减并削弱传递给下一加速阶段的湍流。

1. **相位分辨 DNS**：四个算例（**有/无低流量平台期** × **两个雷诺数区间**），采用**心动周期启发 (cardiac-cycle-inspired)** 的脉动波形驱动管流。
2. **四阶段湍流–湍流重组**：响应呈现清晰的阶段结构（见下表）。
3. **恢复次序 (recovery ordering) 的关键发现**：
   - **强加速抑制**横向脉动与涡结构活动；
   - **加速期与早期减速期**：**流速–法向应力产生**先于**压力–应变重分布**与**径向动量输运**恢复 → 允许能量累积成**拉长条带**。
4. **Q2/Q4 的空间分工**（非常具体的结果）：
   - **早期减速阶段**，**近壁高速条带**主要发展**畸变型 (varicose)** 扰动 → 关联 **Q4 扫掠 (sweeps)**；
   - **外缓冲区低速条带**主要发展**正弦型 (sinuous)** 扰动 → 关联 **Q2 喷射 (ejections)**。
5. **径向次序 (radial sequence)**：
   - **Q2 型局部起始 (onset)** 向壁面**渐进地更晚**发生；
   - **Q4 型起始**在**粘性底层与缓冲区几乎同时**，但**峰值依次向外**移动。
6. **重叠区**：两种响应在**阻力最小 (drag minimum)** 与**恢复最大 (recovery maximum)** 之间**重叠**，此时**再分配显著加剧、多尺度动量输运快速恢复**。随后**湍流衰减、尺度重新调整**。
7. **平台期的作用**：若存在平台期，它**延长衰减**并**削弱传递给下一加速阶段的湍流**；进一步**延迟局部失稳**、**延长剪切贡献的起始–峰值间隔**。
8. **非定常阻力分解**：把上述相位依赖动力学与**阻力响应**联系起来，凸显**"湍流剪切恢复的延迟"在维持低阻力区间中的作用**。

## 技术方案

### 核心思想

**问题背景**：血流是典型的**脉动管流**（心动周期驱动）。而工业上越来越受关注的是**脉动流中的减阻**——例如血流动力学中的**管路阻力优化**。

核心矛盾：
- **周期性脉动流中，湍流强度显著高于相同平均雷诺数的定常流**（这在工业管道中是常识——脉动增加损失）
- **但脉动流也能产生"低阻力区间"**——某些相位上阻力远低于定常值

**为什么需要相位分辨 (phase-resolved)？**

传统的**周期平均 (phase-averaged)** 分析把一个心动周期内的所有相位混在一起。这会**掩盖**关键的相位结构：
- 加速期的湍流被减速期的湍流"抵消"
- 条带的形成与衰减的**先后次序**被抹平
- 而**恰恰是次序决定了因果**——是"应力产生先恢复"导致"能量累积成条带"，还是反过来？

本文坚持做**相位分辨**分析，把一个心动周期切成**阶段**，逐阶段追踪**各湍流产生/输运/耗散项**的时间行为。

**四阶段框架**：

| 阶段 | 特征 |
|---|---|
| **强加速** | **抑制**横向脉动与涡结构活动 |
| **加速期 + 早期减速期** | **流速–法向应力产生先恢复**，能量累积成拉长条带 |
| **早期减速期** | Q4 扫掠（畸变型）vs Q2 喷射（正弦型）的空间分工 |
| **衰减期** | 湍流衰减、尺度重新调整；平台期延长此阶段 |

**Q2/Q4 的物理含义回顾**：

在壁面坐标系中，$Q_2$ 与 $Q_4$ 是雷诺应力分量：
$$Q_2 = -\overline{u'u'},\qquad Q_4 = -\overline{w'w'}$$
（在常见的 $x$–$u$–$r$ 标注约定下，$u'$ = 流向脉动、$w'$ = 流向速度）。它们刻画**壁面剪切应力 (skin friction)** 的产生：
- **Q2（流向–流向）** 与 **Q4（径向–径向）** 的**相对大小**决定壁面剪切应力的方向
- **Q2 主导（$Q_2 > Q_4$）** → 剪切应力指向流向 → **减速**（friction drag）
- **Q4 主导（$Q_4 > Q_2$）** → 剪切应力反向 → **加速**（piston-like effect，对应低速流体被"推"过加速段）

因此本文的发现"**Q2 型起始向壁面渐进更晚，Q4 型起始几乎同时**"是一个**定量的阻力时序**结论——直接决定了**何时出现低阻力区间**。

**为什么"流速–法向应力产生先恢复"这么重要？**

能量收支的时序决定了累积效率：
- 若所有应力项**同时**恢复 → 能量不会在特定结构中累积 → 条带形成缓慢
- 若**产生项先恢复**（能量注入），而**再分配（压力–应变）与输运（径向动量）滞后** → 能量**先被存进流速场、拉伸成长条带**，然后再慢慢被传递到速度梯度场

这正是**流向脉动与速度梯度之间相位差 (phase lag)** 的动力学后果，也是**周期流中条带不稳定 (streak instability)** 的经典机制。脉动流把这个机制推到了极端。

### 关键技术

| 技术 | 说明 |
|------|------|
| 相位分辨 DNS | 按心动周期相位逐阶段分析，不做周期平均 |
| 心动周期启发波形 | 真实心电/血流波形形态，含（或不含）低流量平台期 |
| 非定常阻力分解 (unsteady friction decomposition) | 把湍流动力学与瞬时阻力关联 |
| Q2/Q4 事件分类 | 扫掠 (sweeps, $Q_4$) vs 喷射 (ejections, $Q_2$) |
| 畸变型 (varicose) / 正弦型 (sinuous) 条带扰动 | 低速带与高速带的特征扰动形态 |
| 压力–应变重分布 (pressure–strain redistribution) | 能量在应力分量间的转移 |
| 流速–法向应力产生 | 能量注入项 |
| 径向动量输运 | 壁面动量扩散 |
| 起始–峰值间隔 (onset-to-peak interval) | 时序参数 |
| 低阻力区间 | 脉动流中阻力低于定常值的相位段 |

## 公式 / 理论要点

```math
% 管流基本方程（圆柱坐标）
\partial_t \boldsymbol{u}
+ \boldsymbol{u}\cdot\nabla\boldsymbol{u}
= -\nabla p + \nabla\cdot\boldsymbol{\tau},
\qquad
\nabla\cdot\boldsymbol{u} = 0
```

```math
% 雷诺分解与壁面应力分量
\boldsymbol{u} = \langle\boldsymbol{u}\rangle + \boldsymbol{u}',
\qquad
Q_2 = -\overline{u_x'u_x'},\qquad
Q_4 = -\overline{u_r'u_r'}
```

```math
% 壁面剪切应力的方向由 Q2/Q4 相对大小决定
\tau_{xr}\ \propto\ (Q_2 - Q_4)
\quad\Rightarrow\quad
\begin{cases}
Q_2 > Q_4: & \text{摩擦减速}\\
Q_4 > Q_2: & \text{活塞式加速 (piston-like)}
\end{cases}
```

```math
% 动能收支（揭示"产生先恢复"的时序）
\frac{dE}{dt}
= \underbrace{-\overline{u'_i u'_j \partial_j u_i}}_{\text{产生 (production)}}
- \underbrace{\Pi}_{\text{耗散}}
- \underbrace{\nabla\cdot(\overline{u'_i\boldsymbol{u}'\boldsymbol{u}})}_{\text{输运}}
+ \underbrace{\text{pressure--strain redistribution}}_{\text{再分配}}
```

```math
% 非定常阻力分解（时变项 + 时均值项）
D(t) = \overline{D}
+ \underbrace{\Delta D(t)}_{\text{相位依赖波动}}
+ \underbrace{D_{\text{inertial}}(t)}_{\text{惯性项}}
```

```math
% 相位分辨的径向起始次序
\text{Q2 onset}: \quad t_{\text{onset}}(r) \ \text{向壁面渐进更晚}
\qquad
\text{Q4 onset}: \quad t_{\text{onset}}(r) \ \text{几乎同时，峰值依次向外}
```

## 实验与结果

- **方法**: 直接数值模拟 (DNS)，**相位分辨**。
- **算例**: **4 个**——**有/无低流量平台期** × **两个雷诺数区间**。
- **驱动**: 心动周期启发波形。
- **主要结果**:
  - **四阶段湍流–湍流重组**（见核心贡献的阶段表）。
  - **恢复次序**：流速–法向应力**产生**先于**压力–应变重分布**与**径向动量输运**恢复 → 能量累积成**拉长条带**。
  - **Q4/Q2 空间分工**（早期减速期）：
    - 近壁**高速条带** → **畸变型**扰动 → **Q4 扫掠**；
    - 外缓冲区**低速条带** → **正弦型**扰动 → **Q2 喷射**。
  - **径向次序**：Q2 局部起始向壁渐进更晚；Q4 起始几乎同时但峰值向外依次出现。
  - **重叠区**：两响应在**阻力最小与恢复最大之间**重叠，此时再分配加剧、多尺度动量输运快速恢复；随后湍流衰减、尺度重新调整。
  - **平台期效应**：延长衰减、削弱传递给下一加速阶段的湍流、延迟局部失稳、**拉长起始–峰值间隔**。
  - **非定常阻力分解**把上述与阻力响应联系起来，凸显**延迟的湍流剪切恢复在维持低阻力区间中的作用**。
- **产出形式**: 20 图 + 2 表 + **3 补充影片**（相变动画对直观理解阶段结构极有价值）。

## 局限性

- **仅圆管**：没有研究几何非圆截面（生理动脉是脉动的）、弯曲段、扩张段。
- **心动周期波形是"启发式"**：真实血流波形受血管顺应性、周围组织、外部驱动等影响，本文用简化波形，结论对波形的敏感性未系统探讨。
- **DNS 成本限制**：雷诺数区间受限（典型医学血流 Re ~ 数千），更高 Re 或更长周期未覆盖。
- **单一流体**：全部是单相牛顿流体；血液是**非牛顿**且**多相**（血浆/血细胞），本文结论不能直接移植。
- **壁面条件**：光滑壁（DNS 需要），未包含**血管内皮纹理、血流脉动壁面**等。
- **"低流量平台期"** 是波形的一个特征，真实波形是否普遍含此段需医学验证。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 中高 — DNS 管道流 + 严格的**相位分辨后处理**。求解本身是标准（OpenFOAM Fluent/自建管道 DNS 均可），主要工作在**后处理**：按相位分箱、各阶段的事件分类（Q2/Q4 sweep/ejection 检测）、条带识别（低速/高速条带定义 + varicose/sinuous 判据）、非定常阻力分解。
- **预期性能**: DNS 成本高；四阶段分析需**长时间积分**（足够多的心动周期以达到周期统计稳定）。
- **适用场景**:
  - **血流动力学**：血管阻力、脉动流下的壁面剪切分布（对血管内皮功能、动脉粥样硬化研究有意义）；
  - **脉动管道输运**：化工/能源管道中的脉动流减阻设计；
  - **"相位分辨 vs 周期平均"的方法学**：本文是**必须做相位分辨**的强有力案例——周期平均会抹掉产生-输运-再分配的**时序因果**。这个论证模式值得作为标准检查项；
  - **与减阻研究衔接**：Q2/Q4 时序结论为**主动减阻（通过控制脉动波形）**提供了机理依据。
- **可复用要点**:
  - **"产生先恢复 → 能量累积成条带"** 是可迁移的时序因果范式：任何非定常系统中，只要产生项与输运项的恢复存在**相位差**，就会产生结构化累积。这可用于设计**最优时变激励**。
  - **Q2/Q4 事件的时序分析** 可直接迁移到**定常流中的条纹/带状结构演化**（其他条纹生成机制）。
  - **非定常阻力分解**（相位依赖项 + 惯性项）是把湍流动力学与宏观性能挂钩的标准工具。
  - **"平台期削弱传递给下一阶段的湍流"** 这一结论在**多相/多阶段循环过程**中有普遍意义——如往复机械、脉动燃烧。
  - 建议与本轮 [[2026-11-12-arXiv-2611.11953-Elastic-Frontogenesis-Smooth-Elastic-Turbulence-Spectra]]（弹性湍流的组织原则）、[[2026-11-12-arXiv-2611.11878-Velocity-Gradient-Reconstruction-Jeffery-Orientation]]（从示踪粒子取向重构速度梯度）**三篇联读**：本篇给出流动结构，本文给出测量手段，弹性湍流篇给出另一类多尺度组织机制。
