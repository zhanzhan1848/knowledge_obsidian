## 核心贡献

> 澄清**耗散连续体的变分原理**两大族之间的关系：最小原理 (Helmholtz/Kirchhoff/Prigogine，描述非平衡定态) 与最大原理 (Ziegler/Hackl/Fischer，描述连续介质力学中的弛豫)。**极值性质由"机制 (regime)"决定**——冻结状态下的弛豫（闭系统，**最大耗散**）vs 受驱动的定态（开系统，**最小耗散**）——而**底层 Rayleighian 泛函是凸的，且在两种情形下都被极小化**。同时考察 **Reynolds 输运定理**与**惯性**的角色：**带惯性时必须在变分过程中固定驱动力**，这比无惯性情形（驱动力是状态函数）不够优雅；把能量率写成"率 × 驱动力"仍能给出正确方程，而**只要冻结的力不依赖于被变分的率，极值陈述依然成立**——这对**非定常 Stokes 流直接成立**，对 **Navier–Stokes 流在改换到物质坐标后成立**（此时粒子加速度是状态的二阶时间导数，Euler 描述中非变分的对流项不再出现）。

1. **两族变分原理的统一定理**：最小原理族与最大原理族的区别**由机制决定，而非由泛函形式决定**：
   - **闭系统 + 冻结状态下的弛豫** → **最大耗散原理 (maximum dissipation)**；
   - **开系统 + 受驱动的定态** → **最小耗散原理 (minimum dissipation)**；
   - **两种情形下底层 Rayleighian 泛函都是凸的，且都被极小化**。
2. **这一定理在扩散情形下已被精确化**，本文将其推广到一般耗散连续体。
3. **Reynolds 输运定理 (transport theorem)** 的考察：它是**固定连续体能量率**的有用工具。
4. **惯性的角色**：近期有观点认为惯性**超出了 Rayleighian 原理的适用范围**。本文给出一个明确的技术条件来界定边界。
5. **带惯性时的变分限制**：**必须在变分过程中固定驱动力**——比无惯性情形（驱动力是状态函数）**不够优雅**。
6. **方程正确性的保持**：把能量率写成"**率 × 驱动力**"的形式**仍然给出正确的运动方程**。
7. **极值陈述的存活条件**：**只要冻结的力不依赖于被变分的率，极值陈述就依然成立**。
8. **适用范围逐级验证**：
   - **非定常 Stokes 流**：**直接成立**；
   - **Navier–Stokes 流**：**改换到物质坐标 (material coordinates) 后成立**——因为此时粒子加速度是状态的**二阶时间导数**，而 Euler 描述中**非变分的对流项不再出现**。
9. **测试体系**: **Navier–Stokes 族**（Stokes、非定常 Stokes、Navier–Stokes，**按复杂度递增**）与**耗散拉格朗日力学**。

## 技术方案

### 核心思想

**背景：耗散的变分描述**

变分原理是流体力学最有力的工具之一——它把方程的求解变成能量泛函的驻值问题。但"耗散"（不可逆）让事情复杂：不可逆过程不能由作用量极小化描述。

历史上有两大族：

**A. 最小原理族（描述非平衡定态）**
- **Helmholtz**（1868）、**Kirchhoff**（1894）、**Prigogine**
- 共同结构：给定热力学"力"（驱动力）$\boldsymbol{F}$，系统趋向使**耗散率最小**的定态
  $$\mathcal{D} = \frac{1}{2}\sum_i F_i \dot{x}_i \;\longrightarrow\; \text{minimize}$$
- 物理图像：**封闭系统已达平衡**（此时 $\dot{x}=0$，耗散为零，故"最小"= 零）；或**开放系统受驱动**时在定态达到最小耗散

**B. 最大原理族（描述连续介质力学中的弛豫）**
- **Ziegler**、**Hackl**、**Fischer**
- 共同结构：给定初始状态，系统趋向使**耗散率最大**的弛豫终态
  $$\mathcal{D} = \frac{1}{2}\sum_i F_i \dot{x}_i \;\longrightarrow\; \text{maximize}$$
- 物理图像：**初始条件被冻结**（不可逆过程不改变初态），系统"尽最大可能"耗散能量

**本文的核心贡献：这两族不是对立的，而是同一个 Rayleighian 泛函在不同机制下的两种极值表现**

关键洞察是**机制 (regime)** 决定了极值的方向：

| 机制 | 系统 | 驱动力 | 变分时 | 极值 |
|---|---|---|---|---|
| **闭系统弛豫** | 封闭 | 由状态决定 | **力被冻结** | **最大耗散** |
| **开系统受驱动定态** | 开放 | 外加 | **力可变** | **最小耗散** |

**Rayleighian 泛函本身是凸的，并且在两种情形下都被极小化**。差别在于**哪些变量被变分**：
- 最小原理：变分**力**（在给定状态下的最小耗散）
- 最大原理：变分**率**（在给定力下的最大耗散）—— 这里"冻结状态"是最大化条件成立的前提

这个统一表述极其优雅，因为它**解释**了为什么两类原理在不同文献里看起来矛盾。

**惯性的技术难点**

Rayleighian 方法的标准做法：写能量率为"率 × 驱动力"的形式
$$\frac{dE}{dt} = \sum_i \underbrace{\dot{x}_i}_{\text{率}} \underbrace{F_i(x)}_{\text{驱动力（状态函数）}}$$
然后对**率**做变分。

- **无惯性**：驱动力 $F_i = F_i(x)$ 是**状态函数**，变分过程干净
- **有惯性**：惯性使驱动力依赖于**历史**与**加速度**，而加速度又依赖变分后的率 → **变分变得循环**

**本文的处理**：**带惯性时必须在变分过程中固定驱动力**。这"不够优雅"，但可行。而**方程仍然正确**，因为把能量率写成"率 × 驱动力"的结构没变。

**极值陈述何时仍然成立？** 条件是：**冻结的力不依赖于被变分的率**。

- **非定常 Stokes 流**：直接成立（无对流项，无惯性耦合）
- **Navier–Stokes 流**：在 **Euler 描述**中，惯性来自**对流项** $\boldsymbol{u}\cdot\nabla\boldsymbol{u}$，它是**非变分的**（在 Eulerian 描述下，动量方程的对流项不是变分项）。但直接用 Euler 描述做 Rayleighian 变分不直接。
- **改换到物质坐标 (Lagrangian/material coordinates)**：此时
  - **粒子加速度 = 状态的二阶时间导数** $\ddot{\boldsymbol{X}} = \partial_t^2 \boldsymbol{X}$
  - **对流项不再出现**（它已隐含在物质坐标的时间导数中）
  - 于是**惯性项变成了状态函数**，变分结构重新变得清晰 ✓

**这是本文最漂亮的技术点**：**通过换坐标系把非变分的对流项吸收进惯性项**，从而让 Rayleighian 变分原理对完整 N-S 成立。

### 关键技术

| 技术 | 说明 |
|------|------|
| Rayleighian 泛函 | 耗散率的标准变分表述，**凸** |
| 最小–最大对偶 | 两族变分原理的统一 |
| 机制 (regime) 判据 | 闭系统弛豫 vs 开系统受驱动定态 |
| 冻结状态 (frozen state) | 最大原理成立的前提 |
| 冻结力条件 | 极值陈述存活的判据 |
| Reynolds 输运定理 | 固定连续体能量率的工具 |
| 物质坐标 (material coordinates) | 吸收对流项、恢复 Rayleighian 结构的坐标系 |
| 应力张量与应变率的功共轭 | 标准变分配对 |
| Stokes → 非定常 Stokes → N-S 递进 | 按复杂度递增的验证体系 |
| 耗散拉格朗日力学 | 力学侧的对照验证 |

## 公式 / 理论要点

```math
% Rayleighian 泛函（耗散率的标准形式）
\mathcal{R}(\boldsymbol{x}, \dot{\boldsymbol{x}})
= \frac{1}{2}\sum_i F_i(\boldsymbol{x})\,\dot{x}_i,
\qquad
\boldsymbol{F} = -\frac{\partial \Psi}{\partial \boldsymbol{x}}
\quad(\Psi = \text{能量泛函})
```

```math
% 能量率 = 率 × 驱动力（Rayleighian 表述的核心）
\frac{dE}{dt}
= \sum_i \underbrace{\dot{x}_i}_{\text{率}} \underbrace{F_i}_{\text{驱动力}}
\quad\Longrightarrow\quad
\text{变分 } \dot{x}_i \text{ 得 Euler-Lagrange 方程}
```

```math
% 凸性 + 两种极值（本文的统一表述）
\mathcal{R}\ \text{凸},\qquad
\begin{cases}
\text{闭系统弛豫（冻结状态）}: & \max_{\dot{x}}\ \mathcal{R} \quad\Rightarrow\ \text{最大耗散}\\[4pt]
\text{开系统受驱动定态}: & \min_{\boldsymbol{F}}\ \mathcal{R} \quad\Rightarrow\ \text{最小耗散}
\end{cases}
```

```math
% 极值陈述的存活条件（本文关键判据）
\text{极值陈述成立}
\quad\Longleftrightarrow\quad
\boxed{\ \boldsymbol{F}_{\text{frozen}}\ \perp\ \text{被变分的率}\ }
\qquad
(\boldsymbol{F}\ \text{不依赖于被变分的率})
```

```math
% 惯性处理：带惯性时冻结驱动力
\frac{dE}{dt} = \sum_i \dot{x}_i\,F_i^{\text{frozen}}
\quad\Rightarrow\quad
\text{方程仍正确（率 × 驱动力 结构不变）}
```

```math
% 物质坐标：吸收对流项
\text{Euler:}\quad
\partial_t\boldsymbol{u} + \underbrace{(\boldsymbol{u}\cdot\nabla)\boldsymbol{u}}_{\text{非变分对流项}}
= -\nabla p + \nu\Delta\boldsymbol{u}
```

```math
% 物质坐标下：加速度 = 状态的二阶时间导数，对流项消失
\boldsymbol{X}(\boldsymbol{a},t),\qquad
\ddot{\boldsymbol{X}} = \partial_t^2\boldsymbol{X},
\qquad
\underbrace{(\boldsymbol{u}\cdot\nabla)\boldsymbol{u}}_{\text{被吸收}}
\;\Rightarrow\; \text{Rayleighian 变分重新成立}
```

```math
% 连续介质力学的功共轭配对
\frac{dE}{dt} = \int_\Omega \boldsymbol{\sigma}:\boldsymbol{D}\,dV
-\ \text{heat/other fluxes},
\qquad
\boldsymbol{D} = \frac{1}{2}(\nabla\boldsymbol{u}+\nabla\boldsymbol{u}^T)
```

## 实验与结果

- **类型**: 理论（变分原理的澄清与统一），**22 页 2 图**，无实验。
- **主要结果**:
  1. **两族变分原理的统一**：极值性质**由机制决定**（闭系统弛豫 → 最大耗散；开系统受驱动定态 → 最小耗散）；**Rayleighian 泛函凸且在两种情形下都被极小化**。这一区分在扩散情形下已被精确化，本文推广到一般耗散连续体。
  2. **Reynolds 输运定理**作为固定连续体能量率工具的作用得到澄清。
  3. **惯性的处理**：带惯性时**必须在变分中冻结驱动力**（不如无惯性优雅）；**方程仍然正确**；**极值陈述存活的条件**是**冻结的力不依赖于被变分的率**。
  4. **适用范围验证**：
     - **非定常 Stokes 流**：极值陈述**直接成立**；
     - **Navier–Stokes 流**：**改换到物质坐标后成立**（对流项被吸收，粒子加速度成为状态的二阶时间导数）。
  5. **测试体系**: **Stokes → 非定常 Stokes → N-S** 复杂度递进 + **耗散拉格朗日力学**对照。
- **抽象性**: 论文是**理论澄清型**，结论以命题/定理形式给出。

## 局限性

- **理论澄清而非算法产出**：没有给出可直接实现的数值方法或算法。
- **Rayleighian 方法的实用性限制**：即便变分原理成立，**直接最小化 Rayleighian 泛函通常比直接求解方程更困难**（变分问题的解问题）。本文未讨论数值实现收益。
- **条件"冻结的力不依赖于被变分的率"的适用范围**：这在非线性粘性流、状态依赖本构（弹塑性、黏弹性）中未必满足；本文主要在牛顿流体框架下讨论。
- **物质坐标的实际代价**：换到物质坐标在理论上优雅，但**实践中不可行**（需要跟踪粒子/Lagrangian 网格），因此这个"修正"更像是**理论上的**而非可操作的方法。作者应当清楚这一点（摘要未讨论）。
- **两个图**（22 页只有 2 图）表明内容以命题陈述为主。
- **未涉及多场耦合、多相、湍流闭合**。
- **代码链接未在摘要给出**。

## 实现建议

- **实现难度**: 低（理解）/ 中（若有变分算法需求）。
- **预期性能**: 不适用（无算法）。
- **适用场景**:
  - **理论层面**：为"到底哪个变分原理对"提供明确答案——对**模型开发**（如结构化本构模型、有限元变分实现）是重要的概念澄清；
  - **有限元弱形式推导**：N-S 的变分形式（弱 Galerkin）本质上就是 Rayleighian 变分，本文澄清了它的适用边界（尤其是**惯性项在物质坐标下的处理**），对**编写高阶变分有限元**有直接指导；
  - **与本轮 [[2026-11-12-arXiv-2611.12862-Odd-Viscosity-Navier-Stokes-Global-Regularity-Three-Torus]] 配套**：后者用**带符号修正能量估计**处理奇黏性的反对称贡献，本文从**变分原理**角度审视同一类问题（Rayleighian 泛函在耗散连续体中的统一）。两者合起来覆盖"耗散的变分 vs 耗散的估计"两个视角；
  - **与 [[2026-11-12-arXiv-2611.13399-Lift-Element-Network-Vortex-Gust-Airfoil]] 的输入输出/变分思想相关**。
- **可复用要点**:
  - **"机制决定极值方向"这一统一表述**：可作为解释"为何两派文献结论冲突"的通用工具，也提醒我们在**应用任何变分原理前先确认机制**。
  - **"冻结力不依赖于被变分的率"** 是一个**可直接检查的判据**——建议作为使用 Rayleighian 方法前的检查清单项。
  - **"换坐标系吸收非变分项"** 是一个通用的数学技巧：在做变分/能量分析时，若某项在当前描述下无法变分，考虑换描述（如物质坐标、拉格朗日坐标、随流坐标）看能否把它吸收进状态函数。这个技巧的可迁移性很强。
  - **凸性 + 极值点的存在性** 提供了"变分问题良定"的理论基础，对**梯度下降法求解耗散泛函**（如拓扑优化中的耗散正则项）有意义。
  - **本知识库写作规范呼应**：本文对"最小 vs 最大"的辨析提醒我们，在写**可行性分析**时若引用变分原理，必须注明适用机制。
