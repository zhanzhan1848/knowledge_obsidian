## 核心贡献

> 提出基于**标记链（marker chains）的 X-Mesh 框架**处理不可压 **N 相流**：界面由 **Lagrangian 标记链**显式跟踪，而计算网格**变形**使选定网格边贴合被跟踪的几何（**拓扑连接不变**），从而在**无需网格加密**的情况下，用**高度畸变甚至近退化**的单元捕捉精细界面特征。

1. **X-Mesh 网格策略**：网格**几何变形**（而非拓扑重划分）使选定网格边与跟踪界面贴合——**保持网格连通性不变**，这是与常规 ALE 重网格化的根本区别。
2. **极低网格需求**：允许**高度畸变、近退化单元**，在**相对粗糙的网格**上捕捉精细界面特征，**无需加密**。
3. **显式 Lagrangian 标记链界面表示**：界面几何被**显式跟踪**（marker-based），而非隐式水平集/相场。
4. **压力场的相间间断**：ALE 有限元求解器中，压力在**每一相内连续、在拟合界面间断**（符合多相流的正确弱解结构）。
5. **变分膜 (variational membrane) 表面张力**：压力跳跃**无需预设曲率相关修正项**即被解析解析出；并用 **Young 壁面能量**处理流体–流体–固体**三相点**。
6. **几何化拓扑变化处理**：拓扑变化直接从**标记表示**中几何地处理；并可用**基于标记的特征尺寸判据**控制拓扑变化的发生位置与时机。

## 技术方案

### 核心思想

多相流界面捕捉的主流路线有三类：

1. **固定网格 + 隐式界面表示**（Level Set / VOF / 相场）：网格不变，界面靠场函数隐式描述。优点是网格简单；缺点是界面几何不是显式的，**难以保证几何精度**，且表面张力（曲率）需要额外的微分/光滑操作。
2. **ALE + 网格贴界面（body-fitted）**：网格随界面移动，界面几何精确；但**拓扑变化（合并、破裂）时网格退化/失效**，需要重网格化。
3. **前沿跟踪 / 标记点法**：界面显式点集 + 网格重划分。

本文的 **X-Mesh** 属于第 2 类的一个精巧变体：**网格拓扑冻结，几何自由变形**。关键洞察是：**拓扑变化不需要改变网格拓扑**——只需要改变网格点的位置，让不同的标记链交换"角色"（哪个标记链占据哪个单元区域）。也就是说，界面合并/破裂在**标记层**发生，而网格仅做几何调整。

这带来两个直接好处：
- 网格始终保持有效（不会因为界面合并而出现退化单元）——只是**单元变得高度畸变甚至近退化**，但仍可计算；
- **界面几何是显式的**，因此**曲率是自然量**，无需 level set 式的 $\delta$ 函数光滑算子。

表面张力用**变分膜 (variational membrane)** 处理，这是本文第二个技术要点：把界面张力能量写成关于曲率的泛函，界面法向应力与压力跳跃**由变分原理自然导出**，因此**不需要人为添加曲率修正项**（这是很多 level set/VOF 格式里常见的"补丁"：一个 $\sigma\kappa$ 的显式修正加上一个补偿项）。三相点则通过 **Young 壁面能量**（三相接触线处表面能平衡）处理。

### 关键技术

| 技术 | 说明 |
|------|------|
| X-Mesh | 网格拓扑冻结、几何变形的贴界面策略 |
| Marker chain 界面表示 | Lagrangian 标记链，显式跟踪界面几何 |
| ALE 有限元求解器 | 任意拉格朗日–欧拉有限元框架 |
| 压力相间断弱解 | 压力在相内连续、界面间断，匹配多相流结构 |
| 变分膜表面张力 | 由变分原理导出压力跳跃，无需曲率修正补丁 |
| Young 壁面能量 | 流体–流体–固体三相点的接触角/平衡处理 |
| 几何化拓扑变化 | 从标记表示直接提取合并/破裂，无需网格拓扑操作 |
| 标记特征尺寸判据 | 控制拓扑变化的位置与时机（h-refinement 式的自适应） |

## 公式 / 理论要点

```math
% ALE 有限元运动学：网格点位置随界面移动，拓扑不变
\boldsymbol{x}(\boldsymbol{\xi},t) = \boldsymbol{X}(\boldsymbol{\xi},t)
\quad\text{with}\quad
\text{topology of }\boldsymbol{\xi}\text{ frozen}
```

```math
% 网格变形约束：选定网格边贴合标记链（拟合界面）
\left|\boldsymbol{x}_{i+1} - \boldsymbol{x}_i\right|
= \left|\boldsymbol{\Gamma}_{\text{marker}}^{(i+1)} - \boldsymbol{\Gamma}_{\text{marker}}^{(i)}\right|
```

```math
% 变分膜：表面张力能量泛函（曲率的二次泛函）
E_{\sigma}[\Gamma] = \sigma\int_{\Gamma}\kappa^2\,dS
\quad\Longrightarrow\quad
\delta E_{\sigma} \;\Rightarrow\; \text{界面法向应力与压力跳跃}
```

```math
% 压力跳跃条件（由变分膜导出，非人为修正）
[\![p]\!] = \sigma\,\kappa
\quad\text{（以曲率相关形式自然出现，无额外补丁项）}
```

```math
% 三相点：Young 平衡（通过 Young 壁面能量变分）
\boldsymbol{\sigma}_{ff}\,\boldsymbol{n}_{ff}
+\boldsymbol{\sigma}_{fs}\,\boldsymbol{n}_{fs}
+\boldsymbol{\sigma}_{sf}\,\boldsymbol{n}_{sf} = \boldsymbol{0}
```

```math
% 多相流的正确弱解结构：压力在相间断
p = p^{(k)} \ \text{on}\ \Omega^{(k)}, \qquad
[p] = 0 \ \text{across}\ \Gamma_{kl}\ \text{（仅由表面张力引起）}
```

```math
% 标记驱动的拓扑变化判据（特征尺寸）
\text{if}\ \ell_{\text{marker}} < \ell_{\text{feature}}:
\quad\text{触发}\ \text{merge/split}\ \text{于}\ \Gamma
```

## 实验与结果

- **算例/数据集**: 不可压 N 相流数值实验；复杂界面的**输运**（translation/advection）；**拓扑变化**的控制（合并、破裂）；三相点处理。
- **对比基线**: 常规 ALE（需重网格化）与固定网格隐式界面方法（level set / VOF）的能力对比。
- **主要结果**:
  - **复杂界面输运**：标记链显式跟踪使界面几何输运保持高保真，**无需网格加密**即可在粗网格上捕捉精细界面特征。
  - **高度畸变/近退化单元可用**：这是本文方法的独特能力——畸变单元被**主动利用**而非回避。
  - **拓扑变化的几何化处理**：合并/破裂直接从标记表示提取，**不触碰网格拓扑**。
  - **拓扑变化可控**：通过**标记特征尺寸判据**指定拓扑变化的发生位置与时机。
  - **表面张力自然解析**：压力跳跃由变分膜导出，**无曲率修正补丁**；三相点由 Young 壁面能量处理。

---

## 局限性

- **单元畸变是双刃剑**：虽然畸变单元"可算"，但其条件数恶化，隐式求解的收敛性与线性求解器效率会下降（摘要未报告线性求解策略）。
- **压力相间断**的实现带来额外的线性系统结构（非连续 Galerkin 风格的压力空间），可能需要特定的求解器配置。
- **显式标记链**需要**重参数化/重分布**以避免标记点聚集或稀疏——这是前沿跟踪方法的经典负担，本文摘要未详述。
- 未涉及**多相流中的传热传质**、**相变**、以及**大变形下的网格质量定量退化上限**。
- 数值实验规模有限（摘要仅称"Numerical experiments illustrate..."），未展示大规模/工业级算例。

## 实现建议

- **实现难度**: 中高 — 需要 ALE 有限元框架（含网格几何更新）、标记链管理、变分膜表面张力、压力间断空间、拓扑变化逻辑；建议在现有 ALE/LOFT 类代码框架上实现，而非从零搭建。
- **预期性能**: 相比固定网格 level set/VOF，界面几何精度更高、表面张力无需补丁项；相比常规 ALE（重网格化），**避免重网格化开销**。代价是网格质量下降带来的线性代数成本上升。
- **适用场景**:
  - 自由表面（破碎、飞溅、液滴合并）的高精度模拟；
  - 多相管流中的界面演化；
  - 相变过程中的界面推进（凝固/熔化前沿）；
  - **需要几何精度**的场合（如表面张力主导的界面张力测量、微流控）。
- **可复用要点**:
  - **"拓扑冻结 + 几何自由"** 是本文最可迁移的思想：它在很多问题里替代了昂贵的重网格化。值得推广到其他 ALE 类问题（如 FSI 的接触面处理）。
  - **变分原理消除补丁项**（曲率修正）的方法论价值与本轮其他论文（[[2026-11-11-arXiv-2611.14224]] 的共形映射、[[2026-11-11-arXiv-2611.14348]] 的守恒写法）一致——**让物理从结构的正确写法中自然浮现，而不是靠事后修正**。
  - **标记特征尺寸判据**是界面自适应的简洁实现，可作为粗-细界面双分辨率方法的粗网格层判据。
  - 评估该方法时，建议同时监控**网格最小/最大畸变率**与**线性求解器迭代数**，以量化"避免重网格"带来的净收益。
