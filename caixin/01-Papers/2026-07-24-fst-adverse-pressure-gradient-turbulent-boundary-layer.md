## 核心贡献

> 发现自由流湍流(FST)对翼型上中等逆压梯度湍流边界层有显著影响，且其效应随压梯度的增加而增强

1. 风洞实验系统研究FST对APG湍流边界层的影响
2. FST水平0.15%-6%范围内对边界层发展的系统性影响
3. 大尺度运动穿透边界层的机制揭示

---

## 技术方案

### 实验设置

| 参数 | 值 |
|------|------|
| 翼型 | NACA 0015 |
| 攻角 | 2° 和 4° |
| Reynolds数 (基于弦长) | ~250,000 |
| FST水平 | 0.15% - 6% |
| 测量位置 | x/c = 0.400-0.625 |
| 测量技术 | 热线风速仪 |

### 关键技术

| 技术 | 说明 |
|------|------|
| 热线风速仪 | 边界层速度统计测量 |
| 频谱分析 | 湍流结构特征分析 |
| 形状因子分析 | 边界层状态评估 |

---

## 实验结论

- 增加FST降低形状因子，部分抑制APG诱导的平均速度剖面中的尾迹
- 增加FST使摩擦系数趋近于ZPG规范行为
- 流向速度方差在内区和外区均增大
- 特征波长 λx/δ ≈ 13 的大尺度运动穿透边界层
- FST是翼型APG湍流边界层发展的主导参数
