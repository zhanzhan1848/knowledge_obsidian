## 核心贡献

> 提出三维**曲线坐标格子玻尔兹曼方法**，在光滑贴体网格上**保持均匀计算格子上的一对一无插值精确迁移（exact one-to-one streaming）**，并彻底**消除几何锁定的数值模态（geometry-locked numerical modes）**——这是 Chen 的有限链路（finite-link）构造无法做到的。

1. **几何通过三个局部构件进入模型**：
   - **度量–高斯平衡态（metric-Gaussian equilibrium）**：在曲线基底中定义各向同性压力张量
   - **矩空间中的 Christoffel 连接源项（projected in moment space）**：几何惯性项
   - **齐次态扰动迁移（homogeneous-state perturbation streaming）**：动态重构参考态，**只对偏差做格点迁移**，迁移步无需插值
2. **几何锁定模态的消除**：Chen 的有限链路构造会残留**曲率锁定的密度/速度残差**；本文的完全节点局部构造将其压到浮点精度。
3. **与前人工作的关系**：结合了 Mendoza 等人的黎曼度量/连接动力学结构与 Chen 的守恒体积曲线坐标布居更新，但采用**完全不同的离散构造**（全节点局部，无有限链路源项重构）。
4. **碰撞算子无关性（collision-operator agnostic）**：几何部分与碰撞模型解耦——cumulant、BGK、定基 Hermite-MRT、TRT 在已分辨流动上给出**相同结果**。
5. **扩展到壁面、ALE（动网格）与双向 FSI**：壁面有界域采用「静止参考态」保证无穿透；ALE 通过组合逆变力项处理网格运动。
6. **双精度守恒**：曲线周期算例中全局质量与动量保持到**舍入精度**。

## 技术方案

### 核心思想

目标方程是**曲线坐标下的弱可压缩等温 Navier–Stokes**：

```math
\frac{\partial\rho}{\partial t}+\frac{1}{J}\frac{\partial}{\partial q^{i}}\left(J\rho U^{i}\right)=0
```

```math
\frac{\partial\left(\rho U^{i}\right)}{\partial t}+\frac{1}{J}\frac{\partial}{\partial q^{j}}\left(J\Pi^{ij}\right)+\Gamma^{i}{}_{jk}\Pi^{jk}=0,\qquad
\Pi^{ij}=\rho U^{i}U^{j}+pG^{ij}-\tau^{ij},\qquad p=\rho c_s^2
```

几何量：

```math
B^{p}{}_{i}=\frac{\partial x^{p}}{\partial q^{i}},\quad H^{i}{}_{p}=(B^{-1})^{i}{}_{p},\quad
G_{ij}=B^{p}{}_{i}B^{p}{}_{j},\quad G^{ij}=(G^{-1})^{ij},\quad J=\det(B^{p}{}_{i})
```

### 关键技术

| 技术 | 说明 |
|------|------|
| 晶格 | **D3Q27**，$c_s^2=1/3$ |
| 碰撞 | **累积量（cumulant）** 碰撞算子 |
| 平衡态 | 度量–高斯型 $K_{\rm eq}^{ij}=\rho c_s^2G^{ij}$（**非** $\delta^{ij}$） |
| 连接 | Christoffel 符号 $\Gamma^{r}{}_{ij}$，源项在**矩空间**投影 |
| 迁移 | 分离迁移（split streaming）+ 扰动迁移 |
| 边界 | 曲线壁面上的 bounce-back（分离形式）+ 无穿透通量条件 |
| ALE | 动网格 $\bm{x}=\bm{x}(\bm{q},t)$，组合逆变力 |
| FSI | Newmark 结构积分，与流体步交错 |

## 公式

### 1. 演变量与宏观量恢复

```math
\overline{N}_{\alpha}=J\overline{f}_{\alpha}=J\left(f_{\alpha}-\frac{1}{2}R_{\alpha}\right)
```

```math
\rho=\sum_{\alpha}\overline{f}_{\alpha},\qquad
\overline{m}^{\,i}=\sum_{\alpha}c_{\alpha}^{i}\overline{f}_{\alpha},\qquad
U^{i}=\frac{\overline{m}^{\,i}+\frac{1}{2}R_{1}^{i}}{\rho},\qquad
R_{1}^{i}=\sum_{\alpha}c_{\alpha}^{i}R_{\alpha}
```

**速度恢复是局部隐式的**（$R_1^i$ 依赖 $U^i$）→ 逐节点不动点迭代，无全局求解。

### 2. 矩与度量–高斯平衡态

```math
M_{\bm{\beta}}=\sum_{\alpha}f_{\alpha}\prod_{i=1}^{3}\left(c_{\alpha}^{i}\right)^{\beta_{i}},\qquad
K_{\bm{\beta}}=\sum_{\alpha}f_{\alpha}\prod_{i=1}^{3}\left(c_{\alpha}^{i}-U^{i}\right)^{\beta_{i}}
```

```math
\Sigma^{ij}=c_{s}^{2}G^{ij},\qquad c_{s}^{2}=\frac{1}{3},\qquad K_{\rm eq}^{ij}=\rho c_{s}^{2}G^{ij}
```

**关键点**：笛卡尔分量下 $P^{pq}_{eq}=p\delta^{pq}$，逆变分量下 $P^{ij}_{eq}=pG^{ij}$ → 除笛卡尔极限外**不能**用 $\rho c_s^2\delta^{ij}$。

### 3. 碰撞与粘性

```math
f_{\alpha}^{\mathrm{post}}=\mathcal{C}_{\mathrm{cum}}\left(f_{\alpha},\rho,U^{i},G^{ij},\bm{\omega}\right),\qquad
\nu=c_{s}^{2}\left(\frac{1}{\omega_s}-\frac{1}{2}\right)
```

累积量弛豫层级：二阶 $K_{xx},K_{yy},K_{zz}$ 以 $\omega_s$；三阶 $K_{120}\pm K_{102}$ 以 $\omega_3,\omega_4$；$K_{111}$ 以 $\omega_5$；四阶 $A=\mathcal{C}_{220}-2\mathcal{C}_{202}+\mathcal{C}_{022}$（$\omega_6$）、$B=\mathcal{C}_{220}+\mathcal{C}_{202}-2\mathcal{C}_{022}$（$\omega_6$）、$S=\mathcal{C}_{220}+\mathcal{C}_{202}+\mathcal{C}_{022}$（$\omega_7$）、$\mathcal{C}_{211,121,112}$（$\omega_8$）、$\mathcal{C}_{221,212,122}$（$\omega_9$）、$\mathcal{C}_{222}$（$\omega_{10}$）。**仅 $\omega_s$ 进入leading-order粘性**。

### 4. Christoffel 连接与源项

```math
\Gamma^{r}{}_{ij}=H^{r}{}_{p}\frac{\partial B^{p}{}_{i}}{\partial q^{j}}
```

```math
\nabla_{j}\Pi^{ij}=\frac{1}{J}\frac{\partial}{\partial q^{j}}\left(J\Pi^{ij}\right)+\Gamma^{i}{}_{jk}\Pi^{jk}
```

```math
\mathcal{G}_{\bm{\gamma}}(\rho,U,G^{ij})=\rho\left\langle\prod_{i=1}^{3}\left(c^{i}\right)^{\gamma_{i}}\right\rangle_{G}
```

```math
\mathcal{C}_{\bm{\beta}}\left(\rho,U,G^{ij},\Gamma^{r}{}_{ij}\right)=\sum_{d,b,c=1}^{3}\beta_{d}\Gamma^{d}{}_{bc}\,\mathcal{G}_{\bm{\beta}-\bm{e}_{d}+\bm{e}_{b}+\bm{e}_{c}}\left(\rho,U,G^{ij}\right)
```

```math
R_{\bm{\beta}}=-\left[\mathcal{C}_{\bm{\beta}}(\rho,U,G^{ij},\Gamma)-\mathcal{C}_{\bm{\beta}}(\rho_{\mathrm{ref}},U_{\mathrm{ref}},G^{ij},\Gamma)\right]+R_{\bm{\beta}}^{E},\qquad R_{000}=0
```

D3Q27 对角三阶矩缺陷修正：

```math
\Delta E^{i}=\rho\left[\left(1-G^{ii}\right)U^{i}-\left(U^{i}\right)^{3}\right]
-\rho_{\mathrm{ref}}\left[\left(1-G^{ii}\right)U_{\mathrm{ref}}^{i}-\left(U_{\mathrm{ref}}^{i}\right)^{3}\right]
```

### 5. 参考态与分离迁移

```math
\overline{\rho}=\frac{\sum_{\bm{q},\alpha}\overline{N}_{\alpha}}{\sum_{\bm{q}}J},\qquad
\overline{u}^{\,p}=\frac{\sum_{\bm{q}}B^{p}{}_{i}\sum_{\alpha}c_{\alpha}^{i}\overline{N}_{\alpha}}{\sum_{\bm{q},\alpha}\overline{N}_{\alpha}}
```

```math
\delta N_{\alpha}^{\,\star}=J\left[\overline{f}_{\alpha}^{\,\star}-f_{\alpha,\mathrm{ref}}\right],\qquad
\overline{N}_{\alpha}(\bm{q}+\bm{c}_{\alpha},t+1)=N_{\alpha,\mathrm{ref}}(\bm{q}+\bm{c}_{\alpha},t)+\delta N_{\alpha}^{\,\star}(\bm{q},t)
```

### 6. 壁面条件

```math
\sum_{\alpha\in\mathcal{W}}\left(N_{\alpha,\mathrm{ref}}-N_{\bar{\alpha},\mathrm{ref}}\right)=0
```

**参考态规范（gauge）**：周期域用平均速度 $\overline{u}^p$；**壁面有界域用静止参考 $u^p_{ref}=0$**（由对称性满足无穿透）。

### 7. ALE 扩展

```math
\bm{x}=\bm{x}(\bm{q},t),\quad w^{p}=\partial_t x^{p};\qquad
u^{p}=B^{p}{}_{i}U_{\mathrm{rel}}^{i}+w^{p},\quad U_{\mathrm{rel}}^{i}=H^{i}{}_{p}(u^{p}-w^{p})
```

```math
a_{\mathrm{ALE}}^{p}=-\frac{\partial w^{p}}{\partial t},\qquad a_{\mathrm{ALE}}^{i}=H^{i}{}_{p}a_{\mathrm{ALE}}^{p}
```

```math
\mathcal{G}^{i}=H^{i}{}_{p}(g^{p}+a_{\mathrm{ALE}}^{p})
```

```math
U^{i}=\frac{\overline{m}^{\,i}+\tfrac{1}{2}R_{1}^{i}+\tfrac{1}{2}\rho\mathcal{G}^{i}}{\rho}
```

```math
\mathcal{F}_{\alpha}=\left(1-\tfrac{1}{2}\omega\right)t_{\alpha}\rho\frac{\delta_{ij}c_{\alpha}^{i}\mathcal{G}_{j}}{c_{s}^{2}}
```

### 8. Chapman–Enskog 应力

```math
\tau^{ij}=-\left(1-\frac{\omega_s}{2}\right)\Pi_{(1)}^{ij}=\rho\nu\left(\nabla^{i}U^{j}+\nabla^{j}U^{i}\right)+\mathcal{O}(\mathrm{Ma}^{2}\epsilon,\epsilon^{2})
```

```math
\nabla^{i}U^{j}=G^{ik}\left(\frac{\partial U^{j}}{\partial q^{k}}+\Gamma^{j}{}_{k\ell}U^{\ell}\right)
```

### 9. 有效粘性与能量判据

```math
\mathcal{D}^{*}=-\frac{1}{2\nu}\frac{dE_{\mathrm{kin}}}{dt},\qquad
\nu_{\mathrm{eff}}=-\frac{1}{2\mathcal{E}}\frac{dE_{\mathrm{kin}}}{dt}
```

### 10. FSI 附加质量

```math
m_{\mathrm{add}}=\rho/(k\tanh kH),\quad k=2\pi/n_x;\qquad
f_{\mathrm{wet}}=\frac{f_{\mathrm{dry}}}{\sqrt{1+m_{\mathrm{add}}/\rho A}}
```

### 分辨率 / 变形 / 碰撞敏感性

- $N\in\{16,32,64,128\}$（$\varepsilon_w=0.01$）：16³/32³ 分辨不足；64³ 仍低估涡量峰值；128³ 跟随参考
- $\varepsilon_w=0.03$ vs 0.01（128³）：峰值涡量更高、衰减率更大、后期动能更低、有效粘性下移
- **碰撞算子无关性**（螺旋波，N=64，$\varepsilon_w=10^{-2}$）：cumulant、BGK、Hermite-MRT、TRT **全部**给出 $\mathcal{E}_u=1.67\times10^{-4}$、$|\rho-1|=1.5\times10^{-8}$，$E_{pert}/E_0$ 一致到 **0.1% 以内**

### 曲线壁面 Poiseuille

- 笛卡尔（$\varepsilon_w=0$）：误差**二阶收敛**
- 曲线（$\varepsilon_w=10^{-2}$）：误差成为**几何锁定本底**，几乎与 $N$ 无关，残差 ≈ 正比于变形幅值
- N=64：$\varepsilon_w\in\{0,\,5\times10^{-3},\,10^{-2},\,2\times10^{-2}\}$ → $\mathcal{E}_u\approx\{7\times10^{-5},\,3.8\times10^{-3},\,7.8\times10^{-3},\,1.7\times10^{-2}\}$；**最小二乘斜率 ≈ 0.87**，截距可忽略 → **曲线壁面处约 1% 的本征精度**
- $|\Delta M/M_0| < 10^{-12}$

### ALE 蠕动泵

- 润滑理论参考：$Q_{lub}=3cH_0\phi^2/(1+\phi^2/2)$
- $Q/Q_{lub}$ 随阻塞比变化在 **1.5% 内**恒定：$\phi=0.1$→**1.027**，$\phi=0.2$→**1.021**，$\phi=0.3$→**1.012**（$n_x=128$）
- $\delta=k_wH_0=0.123$ 时与二维润滑理论吻合在 **5% 内**
- 相对质量漂移 **< 3×10⁻¹²**

### ALE 力隔离测试

- 启用 $\mathbf{a}_{ALE}=-\partial_t w$：$\max|u_{lab}|=1.5\times10^{-6}$（网格速度 ~10⁻³）
- 移除该力：$\max|u_{lab}|=1.9\times10^{-3}$ → **相差约 1300 倍**

### 双向 FSI 附加质量

- 实测 $f_{wet}=4.27\times10^{-4}$ vs $f_{dry}=5.42\times10^{-4}$（**2.4% 频移**）
- 无粘预测 $f_{pred}=4.37\times10^{-4}$，$m_{add}=27.0$
- 反推附加质量 $\rho A[(f_{dry}/f_{wet})^2-1]=30.8$ —— **比无粘值高约 14%**（非定常粘性 Stokes 层贡献）
- 相对质量漂移 **< 10⁻¹⁴**

## 局限性

1. **曲线壁面 Poiseuille 的 ~1% 残差是 bounce-back 封闭本身的本征误差**，网格加密无法降低。
2. **静态映射的 Chapman–Enskog 三阶修正 $R^E_{\bm\beta}$ 未用于时变映射**（时变度量引入额外的时间相关项到离散一致性方程中）；动网格形式被当作静态核心的 ALE 扩展处理。
3. **碰撞模型差异只在分辨率不足时可见**（高阶非流体力学矩）。
4. **晶格分辨率研究被明确解释为「分辨率敏感性研究」而非形式阶数估计**（粗网格在渐近 DNS 区域之外；参考解非解析）。
5. **FSI 算例是「最小概念验证」**，未推广到复杂三维 FSI。
6. 静止参考与平均参考的体精度代价被量化，但该选择是**规范（gauge）选择**，不改变目标连续介质方程。
7. **无公开代码仓库**，数据需向作者申请。
8. 速度恢复需逐节点不动点迭代（局部隐式），存在额外开销。

## 实现建议

- **实现难度**：高（几何构造 + 累积量碰撞 + ALE/FSI，65 页篇幅）。
- **预期性能**：128³ 三维算例为常规 HPC 规模；吞吐 7.3–7.5 steps/s（对比 Chen 有限链路高约 20%）。
- **适用场景**：
  - 贴体网格上的弱可压缩流（航空 CFD、管道流、旋转机械）
  - 需要严格守恒（质量/动量到舍入精度）的几何复杂问题
  - **动网格 / FSI** 的 LBM 实现路线
- **落地建议**：
  1. **几何构造优先级**：本文最关键的实现点是**平衡态必须是 $K_{\rm eq}^{ij}=\rho c_s^2G^{ij}$ 而非 $\delta^{ij}$** —— 这一条搞错会直接引入压力各向异性误差
  2. **源项在矩空间投影**（$\mathcal{C}_{\bm\beta}$ 形式）而非在布居空间做有限链路重构——这是消除几何锁定模态的**根本原因**，不可省略
  3. **分离迁移 + 扰动迁移**必须成对实现：参考态做格点迁移、只有偏差 $\delta N^\star$ 做迁移
  4. **壁面参考态用静止参考**（$u^p_{ref}=0$）——这既是无穿透要求也是曲面上 bounce-back 的必要条件
  5. **先做无曲率的 Poiseuille 验证**：确认笛卡尔下二阶收敛，再开启变形（此时误差会转为几何锁定本底，属正常）
  6. **ABC 算例是最好的几何精度体检**：$\chi_\Gamma\approx0.137$（Christoffel 项占比）与压力相关系数 0.999937 是两个必查指标
  7. **ALE 实现要点**：把网格加速度 $a_{ALE}=-\partial_t w$ 并入**组合逆变力** $\mathcal{G}^i=H^i{}_p(g^p+a^p_{ALE})$，不要单独加到动量方程上；时间中心化恢复速度
  8. 对本知识库的启发：与 [[Regularized-LBM-Solid-Liquid]]、[[MRT-Total-Enthalpy-LBM]] 共同构成本批次的 **LBM 方法学三连**，建议对照阅读比较「几何处理」「相变处理」「热场处理」三条路线的取舍
