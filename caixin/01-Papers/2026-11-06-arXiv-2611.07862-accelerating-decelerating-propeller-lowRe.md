# 低雷诺数下悬停加速/减速旋翼的气动特性

## 核心贡献

研究小型 UAV **通过快速改变转速调节推力**时的气动响应（低 Re 悬停状态）：

1. **实验设置**：商用双叶旋翼，定制叶夹具，3 个附加**桨距偏置** $\Theta = 0°, 5°, 10°$，在 **3000–5000 RPM** 间加速/减速，**开环阶跃响应**
2. **无量纲加速/减速数 < 0.011 与 < 0.007** → 结论：**加速效应可忽略**
3. **相位锁定 PIV（phase-locked PIV）** 在转子半径 **40%、60%、80%** 处及**子午面**测量，结合载荷测量
4. **推力系数响应**：
   - $\Theta = 10°$ 时**准稳态**
   - 更高桨距偏置下**出现迟滞**：加速时**低于**稳态值，减速时**高于**稳态值
   - **该趋势与动态入流理论（dynamic inflow theory）的预期相反**
5. **偏差幅度**：
   - $\Theta = 5°$：加速 **8%**、减速 **5%**
   - $\Theta = 10°`：加速 **4%**、减速 **3%**
6. **PIV 揭示**：
   - 转子盘**入流**、**叶片变形**、**剖面环量** → 基本**准稳态**
   - **速度脉动**、**叶尖涡环量**、**叶尖涡** → **剧烈变化**
   - 最大偏差出现在**低转速**时，而非峰值加/减速时

## 物理机制

### 迟滞的方向异常
传统**动态入流理论**（dynamic inflow / Leishman 模型）预测：
- 加速时诱导入流**滞后**建立 → 有效迎角小 → **推力偏低**
- 减速时入流**过量** → 有效迎角大 → **推力偏高**

本文实验发现**趋势相反**：
- 加速时推力系数**低于**稳态
- 减速时推力系数**高于**稳态

**解释**：低 Re 下**粘性效应主导**。加速时桨距偏置改变导致叶片攻角变化，转子盘环量建立需时间；粘性（边界层）滞后效应与入流滞后效应竞争，**净效果反转**。

### 与动态入流理论的冲突
| 特征 | 动态入流理论 | 本文实验 |
|---|---|---|
| 加速时推力 | 偏低 | **偏低**（巧合一致）|
| 减速时推力 | 偏高 | **偏高**（一致）|
| **桨距偏置依赖** | 不应如此强 | **强依赖**（$\Theta$ 越大迟滞越弱）|

→ 关键差别在于**迟滞对桨距偏置的强依赖**，这不在标准动态入流框架内。

## 数值方法评估

| 维度 | 评价 |
|---|---|
| 方法 | **实验**（相位锁定 PIV + 载荷测量） |
| 测量位置 | 转子半径 40%/60%/80%，子午面 |
| 无量纲加速数 | < 0.011（加速），< 0.007（减速） |
| 推力系数 | 动态入流理论的**定性**趋势一致，但**桨距依赖**不符 |
| 旋翼层流/叶尖涡 | 强非定常，无准稳态对应物 |

## 实验/验证结论

| 检验 | 结果 |
|---|---|
| 加速效应量级 | ✅ 可忽略（< 1.1%） |
| 准稳态入流/变形/环量 | ✅ PIV 确认 |
| 非定常脉动与叶尖涡 | ✅ 强变化 |
| 迟滞方向 | ✅ 与动态入流理论定性一致 |
| 迟滞幅度的桨距依赖 | ❌ **与理论不符**（新发现） |

## 局限性

- **单一旋翼**（商用双叶桨）+ **3 个桨距** → 构型覆盖有限
- 低 Re 悬停状态**不代表**前进飞行状态
- 相位锁定 PIV 仅能测**周期平均场**，无法捕捉真正的非定常（需非定常 PIV）
- 未做 CFD 交叉验证（论文为实验导向）
- **桨距偏置是通过叶夹具实现**，可能引入几何改变（与真实变桨不同）

## 实现建议

- **实现难度**：🟡 中。需：相位锁定 PIV（同步触发 + 相位分箱）+ 载荷测量 + 低 Re 旋翼仿真
- **预期性能**：可复现迟滞现象
- **适用场景**：
  - **小型 UAV 旋翼**（微小型无人机、扑翼过渡）
  - **低雷诺数螺旋桨**（小型无人艇、水下无人机、管道内推进）
  - **旋翼动态响应建模**（控制律设计、瞬态推力预测）
- **落地建议**：
  - **数值验证路线**：OpenFOAM 旋转区域（MRF 或滑移网格）+ 低 Re 湍流模型（SA 或 SST），做**加速/减速瞬态**
  - 关键物理：低 Re 下**层流分离**与**粘性滞后**必须在模型中体现 → 建议先用层流模型（Re_tip 约 $10^4$–$10^5$，多数为过渡）
  - 建模建议：若需预测推力迟滞，**动态入流模型需加粘性/分离修正**
  - 对比 [[2026-11-06-arXiv-2611.07914-DSMC-hypersonic-cone-side-jet]]：本文强调**低 Re**的粘性主导，与高超声速的稀薄效应形成两个极端
