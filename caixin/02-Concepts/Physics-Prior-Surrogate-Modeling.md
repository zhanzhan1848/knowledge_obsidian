# 物理先验嵌入代理模型的两种范式

## 背景

CFD 驱动的设计优化受限于**高保真评估次数**。核心矛盾：

- 评估越贵 → 可承受的次数越少 → 训练数据越稀疏
- 数据越稀疏 → 纯数据驱动的代理模型越不可靠

解决思路：**把已知的物理结构注入代理模型**。但注入方式的选择决定了适用性。

## 范式对比

| | **均值函数注入** | **特征/架构注入** |
|---|---|---|
| 做法 | 把物理基线作为 GP 的**均值函数** $g(\bm{z})$，GP 只建模残差 $\bm{f}-g$ | 把物理量作为**输入特征**，或设计受物理约束的**网络架构** |
| 稀疏数据表现 | ✅ 好——物理基线已捕捉主要趋势，GP 只需学残差 | ⚠️ 需大量数据才能学到物理结构 |
| 物理基线不准确时 | ✅ **仍可工作**（去趋势化，不要求基线本身准确）| ❌ 网络须自己发现物理 |
| 可解释性 | ✅ 高——基线物理意义明确 | 低 |
| 典型代表 | 图信息 Kriging（GIK）| GNN / FNO / AMOR |

## 关键洞见

### 1. 物理基线不必是好的重建

[[2026-10-29-arXiv-2610.36751_iFLEX-Generative-Temporal-Interpolation]] 的 Model D 实验：线性插值 RFNE 高达 **43.96%**，但以它为基线学习残差仍把误差降到 **10.48%**——**优于直接生成完整场（13.73%）**。

> 原因：同一估计既定义训练目标、又定义最终重建，给了模型一个不同的学习对象。

### 2. BO 的有效性不要求代理模型全局高精度

[[2026-10-29-arXiv-2610.35975_Graph-Informed-Kriging-Wind-Farm]] 中图先验的一阶项（$m=1$）与二阶项（$m=2$）在**代理精度上差别明显**，但**最终优化结果几乎相同**。

> 推论：BO 只需**正确排序**候选区域，即可有效引导序贯采样。这重新界定了对代理模型精度的预期——**不必把代理做成高精度回归器**。

### 3. 物理先验应在"低维空间"构建，再装配到高维问题

GIK 的做法：先在**两两相互作用**的低维空间（分离距离 $s$ + 方位角 $\theta$）离线构建数据库与代理，再通过**图结构**装配成农场尺度的均值。

> 低维数据库一次构建、全程复用。CFD 算例中 2160 次双风机 ADM-RANS 仿真（64 核约 12 小时）支撑了整个优化过程。

## 落地清单

1. 问：**手头最可靠的物理近似是什么？**（基线、解析解、守恒量、简化模型）
2. 把它做成**均值函数**或**残差基线**，而不是塞进特征
3. 验证时**分两层**：基线本身准不准（不必准）→ 残差学得好不好
4. BO 中只要求**排序能力**，不要过度追求全局精度
5. 低维物理数据库的构建成本要**摊薄**到整个优化过程上
